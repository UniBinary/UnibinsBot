* *铜块（Block of Copper）**是一种由[铜锭](铜锭.md)合成的能够[氧化](氧化.md)的金属[方块](方块.md)。

# 生成
斑驳的铜块、锈蚀的铜块、氧化的铜块、涂蜡的斑驳铜块、涂蜡的锈蚀铜块不会生成在世界中，只能通过[氧化](氧化.md)机制生成。

# = 自然生成 =
铜块、涂蜡的铜块、涂蜡的氧化铜块会作为[试炼密室](试炼密室.md)的一部分生成。

# 破坏
挖掘铜块的合适工具是镐。铜块需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

铜块被破坏后会掉落自身。

# 用途
铜块能作为装饰方块使用，也可以用于储存[铜锭](铜锭.md)，以此来节约空间。

# = 生成铜傀儡 =

|铜傀儡生成图示}}
铜块可以用来建造[铜傀儡](铜傀儡.md)。将[雕刻南瓜](雕刻南瓜.md)或[南瓜灯](南瓜灯.md)放置在铜块的任意一面，铜傀儡就会在放置雕刻南瓜或南瓜灯的位置上生成。由此生成的铜傀儡的氧化程度与铜块相同。生成铜傀儡后，铜块会转变为对应的[铜箱子](铜箱子.md)。使用涂蜡的铜块生成铜傀儡时，铜傀儡不会被涂蜡。<ref></ref><ref></ref>

# = 氧化 =

铜块受氧化机制影响，能够在不同变种之间转化。
