# 虚弱药水

*页面ID: 180157* | *来源: Minecraft Wiki*

* *虚弱药水**是提供[虚弱](虚弱.md)状态效果的[药水效果](药水效果.md)。

该药水效果可以制成[药水](药水.md)**虚弱药水（Potion of Weakness）**、[喷溅药水](喷溅药水.md)**喷溅型虚弱药水（Splash Potion of Weakness）**、[滞留药水](滞留药水.md)**滞留型虚弱药水（Lingering Potion of Weakness）**和[藥水箭](藥水箭.md)**虚弱之箭（Arrow of Weakness）**。

此药水效果有对应的延长版。

# 生成
# = 生物 =
[女巫](女巫.md)会对3格以内没有虚弱状态效果的攻击目标投掷喷溅型虚弱药水。

[焦骸](焦骸.md)会发射虚弱之箭；焦骸會直接發射帶虛弱狀態效果的箭，而不是发射虚弱之箭。

# = 礼物 =

# = 自然生成 =
[雪屋](雪屋.md)地下室的[酿造台](酿造台.md)中有一瓶喷溅型虚弱药水。

[沼泽小屋](沼泽小屋.md)的[炼药锅](炼药锅.md)内可能装有虚弱药水。

# = 箱子战利品 =

# = 掉落物 =
焦骸會掉落虛弱之箭。

# = 炼药锅 =

对装有虚弱药水的炼药锅使用[玻璃瓶](玻璃瓶.md)可获得虚弱药水、喷溅型虚弱药水或滞留型虚弱药水，具体形式取决于炼药锅内容物。

对装有虚弱药水的炼药锅使用[箭](箭.md)可获取虚弱之箭，最大数量随内容物水位增加依次为16、32和64。
