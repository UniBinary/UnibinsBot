# Java版19w35a

*页面ID: 47123* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w35a**是[Java版1.15](Java版1.15.md)的第2个快照，发布于2019年8月28日<ref name="article_19w35a"></ref>，修改了蜂巢的生成机制，并修复了许多漏洞。

# 更改
# = 方块 =
* *[蜂巢](蜂巢（方块）.md)**
* 现在更加少见。
* 如果与蜂巢正面相邻的方块不是[空气](空气.md)，那么蜂巢将不会生成。
* 使用[树苗](树苗.md)种植出的树不再会生成蜂巢。
* [蜂箱](蜂箱.md)和蜂巢现在是可燃的。

# = 物品 =
* *[蜂蜜瓶](蜂蜜瓶.md)**
* 现在饮用蜂蜜瓶可以去除[中毒](中毒.md)效果。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 现在会尝试躲避[水](水.md)。

* *[史莱姆](史莱姆.md)、[岩浆怪](岩浆怪.md)、[豹猫](豹猫.md)和[铁傀儡](铁傀儡.md)**
* 现在使用[属性](属性.md)。

* *[村民](村民.md)**
* 傻子村民现在不再拥有显示职业等级的徽章。

# = 游戏内容 =
* *[进度](进度.md)**
* 现在完成“成双成对”进度还需要繁殖蜜蜂。
* 现在完成“均衡饮食”进度还需要使用蜂蜜瓶。

* *[极限模式](极限模式.md)**
* 玩家现在在死亡时“删除世界”按钮被“标题画面”按钮取代。

* *[睡眠](床.md)**
* 如果村民躺在一张床上，而玩家尝试在该床上睡觉，那么现在村民会被赶下床。

# = 常规 =
* *[战利品表](战利品表.md)**
* 在先前没有的部分情况下，实体被设置在了方块战利品表中。
