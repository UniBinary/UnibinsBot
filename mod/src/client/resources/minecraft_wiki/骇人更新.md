# 骇人更新

*页面ID: 9027* | *来源: Minecraft Wiki*

[缩略图|400px|1.4发布海报<ref>http://mojang.com/2012/10/minecraft-pretty-scary-update/</ref>](File:Pretty Scary Update Poster.png.md)

* *骇人更新（Pretty Scary Update）**，是[Java版](Java版.md)的一次主要更新，发布于2012年10月25日<ref name="12w40a blog post">http://www.mojang.com/2012/10/minecraft-snapshot-12w40a</ref>。此次更新的官方名称在[12w36a](12w36a.md)中被公布。<ref>http://www.mojang.com/2012/09/minecraft-snapshot-12w36a/</ref>该更新加入了许多不同的怪物和变种，可穿戴和放置的[头颅](头颅.md)，一个新的Boss[凋灵](凋灵.md)、[命令方块](命令方块.md)与[信标](信标.md)等。

此次更新的开发始于[12w32a](12w32a.md)，其发布于2012年8月9日。

# 重要特性

此次更新最大的更新是新加入的Boss：[凋灵](凋灵.md)。其他的重大特性有[铁砧](铁砧.md)、[信标](信标.md)与[命令方块](命令方块.md)等。

* *新内容**:
* 信标
* 胡萝卜钓竿
* 物品展示框、花盆
* 马铃薯、胡萝卜、南瓜派
* 铁砧
* 僵尸会感染村民
* 凋灵、凋灵骷髅
* 蝙蝠、女巫
* 怪物可以捡起物品、武器与盔甲
* 命令方块

# 跟进版本
* 1.4.4加入了命令，并修复了1.4.2的许多错误。
* 1.4.5继续修补了1.4.4的错误。
* 1.4.6在2012年12月发布，主要加入了烟花火箭，附魔书以及荆棘魔咒。
* 1.4.7修复了1.4.6引入的崩溃和错误。

# 你知道吗
* 在宣传海报中，马铃薯被写成“potatos”（正确的写法是“potatoes”）
* 骇人更新本来计划包含官方[Mod](Mod.md) API，但与新的[光照](光照.md)系统、[红石](红石电路.md)特性、渲染系统随后一同宣布推迟。<ref></ref><ref></ref><ref></ref><ref></ref>
* [Dinnerbone](Dinnerbone.md)在12w40a中宣布了1.4正式版的发布日期为2012年10月24日。<ref>http://www.mojang.com/2012/10/minecraft-snapshot-12w40a/</ref>但随后由于1.4.1以及1.4.2的更新，发布日期被推迟到10月25日。
