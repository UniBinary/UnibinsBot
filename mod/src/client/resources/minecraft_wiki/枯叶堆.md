# 枯叶堆

*页面ID: 138807* | *来源: Minecraft Wiki*

* *枯叶堆（Leaf Litter）**是一种装饰性方块。

# 生成
# = 自然生成 =
枯叶堆可以自然生成在[森林](森林.md)、[黑森林](黑森林.md)和[疏林恶地](疏林恶地.md)。

# 获取
# = 烧炼 =

# 破坏
枯叶堆被挖掘时会立刻被破坏。

枯叶堆被破坏后会掉落自身，掉落个数等于方块内枯叶堆数。

# 用途
枯叶堆可以放置在所有[顶面支撑形状完整](判定箱#方块支撑形状.md)的方块的上表面，每个方块最多可以放置4个。放置时按逆时针的顺序依次放置。

# = 燃料 =
枯叶堆能用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个枯叶堆可以烧炼0.5个物品。

# = 堆肥 =
将枯叶堆放入[堆肥桶](堆肥桶.md)中有30%的概率增加一层堆肥层。

# = 颜色列表 =

放置在世界中的枯叶堆会根据生物群系着色，详情参见上述条目。
