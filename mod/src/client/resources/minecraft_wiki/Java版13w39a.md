* *13w39a**是[Java版1.7.2](Java版1.7.2.md)的第8个快照，发布于2013年9月26日<ref></ref>，加入了红沙和命令方块矿车，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[红沙](红沙.md)**
* 会在[恶地](恶地.md)底层表面生成。
* 性质与普通沙子相同。
* 可以烧炼成[玻璃](玻璃.md)和用于合成[TNT](TNT.md)，但不能制成[砂岩](砂岩.md)。

# = 非生物实体 =
* *[命令方块矿车](命令方块矿车.md)**
* 只能通过（物品ID 422或者<code>minecraft:hopper_command_block</code>）或者（实体名称<code>MinecartCommandBlock</code>）获得。
* 通过[激活铁轨](激活铁轨.md)激活。
* 在被充能时将每隔一段时间执行命令 - 以最高速度通过单个激活铁轨会执行命令3次。
* 可以通过在[探测铁轨](探测铁轨.md)和[红石比较器](红石比较器.md)的组合成功被探测到（就像[运输矿车](运输矿车.md)和[漏斗矿车](漏斗矿车.md)那样检查）。

# 更改
# = 物品 =
* *[附魔书](附魔书.md)**
* 现在可以获得多重魔咒了。

# = 世界生成 =
* *[恶地](恶地.md)**
* 橙色[染色陶瓦](染色陶瓦.md)现在会替代[恶地](恶地.md)里的砂岩生成，但不是以相同的形式。

# = 常规 =
* *日志**
* 现在将通过Log4j2完成。
* * 默认的日志位置将改为，较旧的日志将在内通过GZIP压缩的存档，其中，年为4位数字，月、日均为2位数字，次为当日启动次数，当天第一次启动时次为1，每次启动将增加。
* * 日志保存的方式也能够改变了，如：HTML页面、数据库、仅包含错误或根本没有日志。
