# 基岩版1.21.0.26

*页面ID: 119980* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.0.26**（ChromeOS/Android）、**Preview 1.21.0.26**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.0](基岩版1.21.0.md)的第7个测试版，发布于2024年5月15日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[不祥试炼刷怪笼](不祥试炼刷怪笼.md)**
* 再次调整了发射弹射物的战利品表以匹配。
* * 将[缓降之箭](缓降之箭.md)替换为[迟缓之箭](迟缓之箭.md)IV。
* * 将[伤害之箭](伤害之箭.md)II替换为[剧毒之箭](剧毒之箭.md)。

* *[不祥宝库](不祥宝库.md)**
* 将普通战利品表中的缓降之箭替换为迟缓之箭IV，以匹配。

* *[宝库](宝库.md)**
* 将普通战利品表中的伤害之箭II替换为剧毒之箭，以匹配。

# = 世界生成 =
* *[试炼密室](试炼密室.md)**
* 更改了补给箱的战利品表以匹配。
* * 将伤害之箭II替换为剧毒之箭。
* * 将[迅捷之箭](迅捷之箭.md)II替换为迟缓之箭。

# = 游戏内容 =
* *[掉落物](掉落物.md)**
* 更改了生物掉落装备的概率以匹配。
* * 更改了[抢夺](抢夺.md)魔咒增加的装备掉落概率。
* ** 杀死装备掉落概率为0%的生物时，抢夺不再能够增加装备掉落概率。
* ** 每级抢夺增加的装备掉落概率由4%降低至1%。
* * 生物的附魔装备不再会以双倍概率掉落。

# = 技术性 =
* *[附加包](附加包.md)和脚本引擎**
* 修复了粒子效果生命周期事件时间线不会按预期触发事件的问题。

* *[资源包](资源包.md)**
* 现在[沼骸](沼骸.md)的纹理文件位于专门的文件夹中，以与[骷髅](骷髅.md)的其他变种保持一致。（）

# 修复
* *试炼密室**
* 生物不再会自然生成于试炼密室中。（）

* *试炼刷怪笼**
* 修复了反复开启和关闭游戏规则后，试炼刷怪笼不再会生成生物的漏洞。（）
* 修复了不祥试炼中随机射下的箭带有瞬间伤害II或缓降效果而非中毒或缓慢IV效果的漏洞。

* *战利品**
* 修复了可以从不祥宝库中找到缓降之箭而非迟缓之箭IV的漏洞。
* 修复了可以从宝库和试炼密室补给箱中找到伤害之箭II而非剧毒之箭的漏洞。（）

* *重锤**
* 使用三叉戟发动激流攻击后将三叉戟换成重锤时不再会自动触发重锤猛击。（）

* *物品**
* 旗帜现在再次可以通过配方书获取。（）

* *魔咒**
* 修复了抢夺魔咒可能导致掉落概率为0%的装备（如恼鬼的铁剑或不祥试炼中的生物装备）仍会掉落的漏洞。

* *Realms**
* 修复了打开Realms故事时可能会出现的错误。

* *更衣室**
* 修复了导致角色创建器皮肤被移除眼睛进而破坏皮肤纹理加载的漏洞。（）</onlyinclude>
