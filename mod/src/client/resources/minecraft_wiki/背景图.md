# 背景图

*页面ID: 92849* | *来源: Minecraft Wiki*

* *背景图（Background）**是一类显示在诸如[胜利屏幕](胜利屏幕.md)和维度传送屏幕的背景上的图片。

# 背景图列表
# = 泥土背景 =

此背景用于[胜利屏幕](胜利屏幕.md)和[鸣谢与著作权说明屏幕](鸣谢与著作权说明屏幕.md)。

除玩家传送至[主世界](主世界.md)时出现的背景外，其余各处仍然使用的是泥土的旧纹理，即使在[携带版0.2.0](携带版0.2.0.md)中泥土的纹理更新后也是如此。<ref></ref>

# = 末地石背景 =

# = 下界传送门背景 =
[thumb|基岩版下界传送门背景](File:Nether Portal background.png.md)
<!--[thumb|Java版下界传送门背景](File:Nether Portal Background JE1.gif.md)-->
此背景在玩家进入或离开下界时显示。显示的是动态且明亮的[下界传送门方块](下界传送门方块.md)的纹理。

此背景在玩家加入[Realms Plus](Realms Plus.md)时显示。显示的是静态且较暗的[下界传送门](下界传送门.md)的纹理。

# = 末地传送门背景 =

<!--[thumb|Java版末地传送门背景](File:End Portal Background JE1.gif.md)-->
此背景在玩家从非下界维度进入末地时、从末地前往非下界维度时或在胜利屏幕中显示。显示的是[末地传送门方块](末地传送门方块.md)的动态纹理。
