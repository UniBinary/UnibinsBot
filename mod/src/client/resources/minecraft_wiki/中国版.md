* *我的世界：中国版（*Minecraft: China Edition*）**，官方表述为**《我的世界》中国版**，是[Minecraft](Minecraft.md) 的中国本地化版本，由[Mojang Studios](Mojang Studios.md)、[Xbox Game Studios](Xbox Game Studios.md)和网易联合开发，由上海网之易吾世界网络科技有限公司发行。截至2025年4月3日已有8亿注册用户。<ref name="devcon-2025"></ref>

中国版主要包括[手游版](中国版:手游版.md)和[端游版](中国版:端游版.md)，提供游戏。中国版是网易开发的手游/端游启动器和启动器内所包含Minecraft游戏的总称，启动器同时具有[多人游戏](中国版:联机游戏.md)、[组件](中国版:组件.md)管理等功能。

# 平台
# = 手游版 =

* *手游版（我的世界：移动版）**是主要运行于移动平台的中国版版本，提供特定版本的游戏。

手游版打开游戏后首先进入启动器，由启动器跳过基岩版主菜单进入游戏内。除启动游戏外，手游版还包括[资源中心](中国版:资源中心.md)、[商城](中国版:商城.md)、社交社区等功能。

手游版于2017年10月12日开始公测，于2017年9月15日在App Store上线。2024年12月27日起，因合作运营策略调整，各大渠道服版本开始逐步关闭。

# = 端游版 =

* *端游版**是运行于PC平台的中国版版本，分为基岩互通版和Java经典版，提供特定版本的游戏。

# 开发

我的世界中国版自2017年发布以来仍在持续更新中。

# 组件

* *组件**是中国版加入新内容或修改原有内容的资源的统称，具有附加包、资源包、加载器Mod、皮肤等类型，包括基岩版、Java版支持的各类扩展资源和中国版独有类型资源。

# 媒体

中国版在中国大陆地区开展了一系列线上、线下社区活动，在主要网络平台建立了官方社交账号、玩家社区，通过多种渠道发布各类衍生内容。

# 开发者

* *《我的世界》中国版创造者计划**是中国版的一项认证开发者计划。

# 漏洞
[漏洞追踪器](漏洞追踪器.md)**不受理**中国版启动器、游戏内出现的漏洞。以下提供了对应问题的几种反馈方式：
* 手游版出现的漏洞可反馈至主界面左侧边栏客户/BUG&建议反馈或直接发送BUG至客服后台，点击下方“建议通道”可提交工单，处理后会收到反馈。
* 端游版出现的漏洞可反馈至主界面右上角客服中心。
* 组件/网络游戏遇到的漏洞可在相关页面寻找开发者联系方式并直接反馈，组件页面有专用通道允许已购买的玩家向开发者发送反馈。官方反馈渠道不受理组件漏洞，在组件评论区里反馈漏洞也不会直接传达至开发者。
* 游戏相关问题均可反馈至官方QQ频道“我的世界玩家频道”的子频道“小镇居委会”。
* [网易游戏客服中心](https://gm.163.com)同时受理端游、手游的账号问题、违规举报等事项，进入后需登录网易账号提交工单。

# 你知道吗
* 中国版代理期限曾被多次延长。2016年5月，[Mojang](Mojang.md)同网易首次签订独家运营协议，授权的代理期限持续到2022年；2019年5月，双方将授权期限至了2023年8月；2023年，双方再次延长代理期限，但此次延期的截止日期未知。<ref>[网易2021年年度报告](https://ir.netease.com/node/13466/html)</ref><ref>[网易2023年年度报告](https://ir.netease.com/node/14456/html)</ref>
* 曾任Mojang Studios中国客户业务与全球合作项目总监的Jeremy Snook表示，中国版上线后，中国大陆地区的盗版率降低了90%，月活跃用户超4000万，这为微软创造了可观的收入，同时提供了监管严格市场可扩展的运营和合规框架。<ref>[Jeremy Snook的领英页面](https://www.linkedin.com/in/jeremysnook/)</ref>
