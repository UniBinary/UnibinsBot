* *传送门底座（Pedestal）**是一种可以生成[马铃薯传送门](马铃薯传送门.md)的方块。

# 生成
# = 自然生成 =
传送门底座会自然生成于平原[村庄](村庄.md)和[马铃薯村庄](马铃薯村庄.md)的会合点、[要塞](要塞.md)的传送门房间中心、[废弃马铃薯传送门](废弃马铃薯传送门.md)和[角斗场](角斗场.md)。

# 获取
传送门底座不能在生存模式中正常获得，但可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)获得。

# 破坏
没有工具可以加速对传送门底座的挖掘。

传送门底座被破坏后不会掉落。

# 用途
# = 马铃薯传送门 =
对着[主世界](主世界.md)或[马铃薯维度](马铃薯维度.md)中的传送门底座[毒马铃薯](毒马铃薯.md)后，如果传送门底座上方是可替代的方块，则会生成马铃薯传送门，并消耗一个毒马铃薯。

# = 活塞推动行为 =
传送门底座无法被[活塞](活塞.md)推拉，但可被[悬浮马铃薯推进器](悬浮马铃薯推进器.md)推动。
