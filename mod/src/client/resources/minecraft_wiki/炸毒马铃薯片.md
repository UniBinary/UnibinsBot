* *炸毒马铃薯片（Poisonous Potato Chips）**是一种能被[玩家](玩家.md)食用的[食物](食物.md)类[物品](物品.md)。

# 获取
# = 烹饪 =
[生毒马铃薯片](生毒马铃薯片.md)能在[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或[营火](营火.md)中被烹饪成炸毒马铃薯片。

# 用途
# = 食物 =

手持炸毒马铃薯片按住键即可食用，每个炸毒马铃薯片可以回复。

食用炸毒马铃薯片有独特的[音效](#音效.md)。

# 音效
<br><small>Crispy crunch!</small>
