# Java版13w48b

*页面ID: 33605* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w48b**是[Java版1.7.4](Java版1.7.4.md)的第7个快照，发布于2013年11月26日<ref></ref>，添加了1个命名牌的特性，并修复了[13w48a](13w48a.md)里的漏洞和崩溃。

# 更改
# = 生物 =
* *[绵羊](绵羊.md)**
* 给羊命名为“jeb_”会使羊的颜色以各种染料的颜色依次呈现（像彩虹一样）。
* * 剪羊毛后仍会得到本来的颜色的羊毛。

# 修复
