# 基岩版1.2.9

*页面ID: 33436* | *来源: Minecraft Wiki*

* *1.2.9**是的一次次要更新，发布于2018年1月16日<ref></ref>，修改了世界选项，并修复了一些漏洞。

# 更改
# = 生物 =
* *常规**
* 提高了友好生物的生成概率，使它们更容易被发现。

# = 常规 =
* *[设置](设置.md)**
* 现在“[坐标](坐标.md)显示”“火焰蔓延”“[TNT](TNT.md)爆炸”“生物战利品”“物品掉落”“生物自然生成”世界选项可以在不启用作弊的情况下切换。
* 现在安全区画面拥有独立的水平和垂直选项，可在各平台上单独设置。

# 修复
* *修复了19个漏洞**<br>
* *崩溃/性能**
* 修复了在Android设备上登录Xbox Live账户时发生的崩溃。
* 修复了使用Pocket UI在信标或附魔台中移动物品时发生的崩溃。
* 修复了加载区块时发生的崩溃。
* 修复了渲染月亮以及游戏时间为负数时发生的崩溃。
* 修复了编辑超过6个字符长度的世界或Realms的名称时发生的崩溃。

* *常规**
* 修复了重新进入世界后，玩家的物品、经验等级和位置有时会发生变化的漏洞。

* *游戏内容**
* 苦力怕现在会在其即将爆炸时停止行走。
* 苦力怕不再会在玩家离开其视野范围后爆炸。
* 玩家现在又可以在潜行时连续放置方块了。
* 凋灵骷髅现在又会生成于下界要塞了。
* 现在玩家手持食物站在栅栏外或栅栏内时，动物会被正确吸引。
* 动物现在又会在不平坦的地形上正确被食物吸引，而不会失去兴趣了。
* 在告示牌上输入新的一行后，文本输入光标不再会停留在第一行。
* 修复了告示牌中带有格式符号时无法换行的问题。

* *图形/音频**
* 现在安全区画面拥有独立的水平和垂直选项，可在各平台上单独设置。
* 现在Pocket UI能够适配安全区界面，并且修复了iPhone X上的默认安全区界面问题。
* 骑猪时，相关图形界面不再会显示在分屏画面上。
* 修复了菜单上的“返回”按钮的标签问题。
* 现在使用自然纹理包时书与笔会被正确读取。
