* *繁殖（Breeding）**是一种允许[生物](生物.md)繁殖出新个体的游戏机制。

# 机制
[缩略图|一只被玩家手持的小麦吸引的牛](File:New Cattle.png.md)
可繁殖生物都有对应的繁殖用[食物](食物.md)。当动物注意到玩家持有其对应的食物时，便会跟随玩家，直至玩家超出范围（/以内）、玩家不再手持该食物或动物开始进入繁殖过程。幼年个体也会出现跟随行为。值得注意的是，动物对[地上的食物](物品（实体）.md)不感兴趣。要繁殖一只幼年个体，双亲需要各食用一份食物，手持食物对其可喂食。

如果该生物是可驯服的生物，如[猫](猫.md)、[狼](狼.md)、[马](马.md)、[驴](驴.md)、[羊驼](羊驼.md)、[鹦鹉螺](鹦鹉螺.md)，则需要被[驯服](驯服.md)后方可繁殖。[豹猫](豹猫.md)需要信任玩家后方可繁殖。

# = 求爱模式 =
当生物吃下特定的食物后，便会进入“求爱模式”。

进入“求爱模式”的生物会或。两只相距8格内的同物种生物进入求爱模式后，便会寻路到彼此身边，在“亲吻”后在其中一方脚下生成一只相同物种的[幼年动物](#幼年动物.md)，并结束求爱模式。在繁殖出幼年个体时还会掉落。

一些生物有特殊的繁殖机制而不完全遵循上述机制。例如：[海龟](海龟.md)不会在结束求爱模式后立刻生成幼年海龟，而是走到它的生成位置产下[海龟蛋](海龟蛋.md)；[嗅探兽](嗅探兽.md)则会掉落一个[嗅探兽蛋](嗅探兽蛋.md)物品。

繁殖后的生物在/内无法再进入求爱模式。不过，在冷却期内手持繁殖用食物仍然能吸引这些动物，包括幼年个体。

# = 村民 =

[缩略图|右|200px|一群幼年村民在玩追逐游戏](File:ChildrenTag.png.md)

[村民](村民.md)被给予食物时不会繁殖。村民的繁殖取决于其自身意愿（且自行选择时间），并受区域中有效[床](床.md)的数量以及村民的意愿影响。如果村民的物品栏内有3个[面包](面包.md)、12个[胡萝卜](胡萝卜.md)、12个[马铃薯](马铃薯.md)或12个[甜菜根](甜菜根.md)，村民可能会有繁殖的意愿。与玩家进行[交易](交易.md)也会使村民产生繁殖意愿。当村民繁殖时，会产生一个体型较小的村民，不同于大部分幼年动物，幼年村民的头不大，看起来像是成年村民的缩小版。幼年村民会在村庄范围内跑动，玩追逐游戏。根据难度的不同，被僵尸击杀的幼年村民可能会生成幼年[僵尸村民](僵尸村民.md)。

# = 繁殖公式 =
若要了解达成某项目标需要的动物数量，譬如：在拥有牛栏的情况下，使用[皮革](皮革.md)合成用于建造最高等级的带书架附魔台的[书](书.md)（需要46个皮革）、打造全套[皮革盔甲](皮革盔甲.md)（24个皮革），可以在提供初始动物数量、在所有动物处于成年状态下，参考以下公式进行相关计算（对村民不成立）：

<math>n+1</math>代的动物总量<math>X_{n+1} = X_n + \left\lfloor \frac{X_n}{2} \right\rfloor</math>

若初始动物数量为X，要使动物数量达到至少为Y，则需要繁殖至少<math>\left\lceil \log_{1.5}\frac{Y}{X} \right\rceil</math>代。

# 幼年生物
# = 幼年村民和动物 =
[缩略图|右|300px|幼年绵羊的毛色为双亲毛色混合的示例](File:SheepBreedingColor.png.md)
幼年动物是其双亲的缩小版，大多身体较小、头部较大、叫声更尖、移动更快，同时缺失成年动物的一部分功能，例如幼年绵羊无法剪毛，幼年鸡无法下蛋，幼年牛、幼年哞菇和幼年山羊无法挤奶等。幼年动物（嗅探兽、狼、猫、村民除外）在成年前会跟随其双亲，双亲不存在后会选择周围一个同物种的成年动物跟随。幼年狼和幼年猫在其双亲不在附近或被命令坐下时跟随主人；幼年狼会像成年狼一样攻击敌对生物。绝大多数幼年动物不会掉落[物品](物品.md)和[经验值](经验值.md)，但幼年[疣猪兽](疣猪兽.md)除外。

拥有多种花色的动物的幼年个体出生时，它们的外表颜色通常是随机选择父母中任意一方的外表的颜色。绵羊的毛色、猫和狼的项圈颜色为父母颜色的[有效混色](染料#混色机制.md)。

对着相应的动物[刷怪蛋](刷怪蛋.md)可以生成幼年动物。

使用命令生成<code>Age</code>标签对应值为负数的动物也可得到幼年动物。例如，{{cmd|summon sheep ~ ~ ~ {Age:-100} }}命令会在命令执行者的位置生成一只幼年绵羊，并会在100[刻](刻.md)后成年。

生成的幼年动物（嗅探兽除外）会在20分钟后长大，而幼年嗅探兽会在40分钟后长大。其生长速度可以通过喂食繁殖用食物来轻微加速。
* 对于大部分幼年动物，设成年剩余时间为<math>t</math>，每份食物可以减少<math>\left\lfloor\frac{t}{200}\right\rfloor\times20</math>刻成长时间（这意味着当成年剩余时间小于200刻时，喂食不再能加速成长但仍然消耗食物）。
* 对于[马](马.md)、[驴](驴.md)、[骡](骡.md)、[羊驼](羊驼.md)和[行商羊驼](行商羊驼.md)，喂食不同食物有不同的加速效率且不受成年剩余时间影响。

对多数幼年动物（详见）[金蒲公英](金蒲公英.md)可以阻止其成长，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年动物无法被喂食除金蒲公英外的其他物品。

尽管[骡](骡.md)、[北极熊](北极熊.md)、[骷髅马](骷髅马.md)、[僵尸马](僵尸马.md)、[鱿鱼](鱿鱼.md)、[发光鱿鱼](发光鱿鱼.md)、[海豚](海豚.md)、[快乐恶魂](快乐恶魂.md)和都存在幼年个体，但这些生物都无法繁殖。

[蝌蚪](蝌蚪.md)较为特殊，其成年形态为青蛙，外形相差较大。虽然它也具有很多幼年生物的行为，但游戏内部将其视为和青蛙不同的两种生物，故拥有不会主动跟随青蛙，且无法对青蛙设置<code>Age</code>标签获得蝌蚪等特殊行为。

# = 幼年怪物 =
幼年[僵尸](僵尸.md)、幼年[尸壳](尸壳.md)、幼年[溺尸](溺尸.md)、幼年[僵尸村民](僵尸村民.md)、幼年[猪灵](猪灵.md)、幼年[僵尸猪灵](僵尸猪灵.md)和幼年[僵尸疣猪兽](僵尸疣猪兽.md)常被视为其成年的变种而非幼体，它们与幼年动物的区别在于：
* 没有跟随所谓“双亲”的行为模式。
* 不会随时间流逝长大为成年个体。
* 拥有掉落物，且被玩家或已驯服的狼杀死时会掉落经验值。
* 使用命令生成<code>IsBaby</code>标签为1的怪物或使用生成事件<code>minecraft:as_baby</code>来生成幼年怪物。
