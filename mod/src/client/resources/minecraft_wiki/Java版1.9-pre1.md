# Java版1.9-pre1

*页面ID: 20378* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.9-pre1**是[Java版1.9](Java版1.9.md)的首个预发布版，发布于2016年2月17日<ref name="blogspot_1.9-pre1"></ref>，修复了一些漏洞。

# 更改
# = 物品 =
* *[盾牌](盾牌.md)**
* 盾牌的耐久度从181增加到337。

# = 世界生成 =
* *[末地](末地.md)**
* 重新加入了保护末地水晶的[铁栏杆](铁栏杆.md)（这个特性曾经在[16w07a](16w07a.md)中被移除了）。

# 修复
</onlyinclude>

# 你知道吗
* 该版本的发布日期在官方博客上[16w06a](16w06a.md)发布的配图中提示。图片中羊毛数据值是（1，7，0，2，2，0，1，6），很有可能意味着“17-02-2016”。
