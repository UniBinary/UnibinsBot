# 用途
# = 存放物品 =
展示架正面有3个槽位，可存放最多3组物品。与任意槽位交互时，[玩家](玩家.md)的主手物品会与所交互槽位的物品交换。若玩家处于[创造模式](创造模式.md)则不会进行物品交换，而是将所交互槽位中的物品替换为玩家的主手物品。

类似于[物品展示框](物品展示框.md)，展示架会在正面展示其包含的所有物品。但与之不同的是其内部物品不可旋转。

方块实体数据控制了展示架槽位中展示物品的位置。其值为（默认值）时，物品位置居中；其值为时，物品置于底部隔板上方。无法通过[命令](命令.md)以外的其他方式修改其值。

# = 激活 =
展示架可以被红石信号激活，此时其正面纹理会随之改变，槽位之间的“隔板”会消失。激活的展示架可以相互连接，最多可以连接3个，相互连接的展示架连接处的“隔板”会消失。此时，展示架的行为如下：
* 与单个展示架交互时，其包含的所有物品会与玩家快捷栏右起3个物品交换。
* 与两个相连接的展示架交互时，其包含的所有物品会与玩家快捷栏右起6个物品交换。
* 与三个相连接的展示架交互时，其包含的所有物品会与玩家快捷栏的所有物品交换。

# = 红石比较器 =
[红石比较器](红石比较器.md)可以从背面检测展示架内的物品排布，并输出相应强度的红石信号，范围为。计算方式类似于二进制：
* 所有槽位均无物品时，信号强度为0；
* 左、中、右槽位有物品时，信号强度分别增加1、2、4；

# = 容器交互 =
[漏斗](漏斗.md)可以为展示架放入或取出物品，[投掷器](投掷器.md)和[合成器](合成器.md)可以为展示架放入物品，[漏斗矿车](漏斗矿车.md)可以为展示架取出物品。无论位于展示架的哪一侧，它们总是会与满足条件的左起第一个槽位交互，即以从左到右的顺序放入或取出物品。

多个展示架相连接时，这些方块只会与其直接连接的展示架交互，而无法与连接的其他展示架交互。

# = 燃料 =
竹质和主世界木质展示架能用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料。每个展示架可以烧炼1.5个物品。
