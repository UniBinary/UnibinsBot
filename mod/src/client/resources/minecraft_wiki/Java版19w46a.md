# Java版19w46a

*页面ID: 49369* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w46a**是[Java版1.15](Java版1.15.md)的第14个快照，发布于2019年11月13日<ref name="19w46a"></ref>，加入了3个新的[进度](进度.md)及[进度触发器](进度#JSON格式.md)，修改了在创造模式中食用食物的表现，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[进度](进度.md)**
* 加入了[进度触发器](进度#JSON格式.md)。
* 加入了进度“”，获得方法为贴着[蜂蜜块](蜂蜜块.md)的侧面下滑。
* * 位于“冒险”标签下。
* 加入了进度“”，获得方法为在一个[蜂巢](蜂巢（方块）.md)下放置营火，然后安全地采集蜂蜜。
* * 位于“”标签下。
* 加入了进度“”，获得方法为使用带有[精准采集](精准采集.md)魔咒的工具采集一个包含3只蜜蜂的蜂巢。
* * 位于“”标签下。
* 三个新加入的进度都是“普通”进度。

# 更改
# = 物品 =
* *[食物](食物.md)**
* 所有食物（包括蛋糕）现在都可以在创造模式下食用。

* *[刷怪蛋](刷怪蛋.md)**
* [溺尸](溺尸.md)、[尸壳](尸壳.md)、[僵尸](僵尸.md)和[僵尸村民](僵尸村民.md)现在可以通过对成年实体使用刷怪蛋来生成对应的幼年实体。
* * 目前不适用于[僵尸猪人](僵尸猪人.md)。<ref></ref>

# = 实体 =
* *[蜜蜂](蜜蜂.md)**
* 现在蜜蜂只会从蜂巢或蜂箱的正面出巢。

* *[经验球](经验球.md)**
* 当一个实体被杀死时，经验球现在会与战利品在同一时刻出现在相同的位置。
* 现在再次被渲染为半透明。

# = 常规 =
* *[纹理](纹理.md)**
* [32px](File:Dragon Fireball JE2.png.md) 更改了[末影龙火球](末影龙火球.md)的纹理。类似于[火焰弹](火焰弹.md)在[纹理更新](纹理更新.md)后的版本。
