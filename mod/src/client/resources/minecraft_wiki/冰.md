# 冰

*页面ID: 478* | *来源: Minecraft Wiki*

</ref>||Marsh Davies Mojang avatar.png}}

* *冰（Ice）**是会融化的半透明固体方块。

# 生成
# = 自然生成 =
冰可以在积雪生物群系里结冰的湖、河流和海洋表面找到。

冰也会作为[雪屋](雪屋.md)的“窗户”生成。

冰还会自然生成于[远古城市](远古城市.md)的冰窖中。

# = 结冰 =

在[寒冷生物群系](生物群系#温度.md)和部分生物群系的可[降雪](降雪.md)区域中，[水源](水源.md)在满足以下条件后可以结冰：

* 上方没有任何可阻挡雪的方块遮挡；
* 所处位置的[方块光照](方块光照.md)等级小于10。
* 四周至少有一个非水方块或非[含水](含水.md)方块与之相邻。

结冰现象可以在任意时间和天气条件下发生。[游戏规则](游戏规则.md)（默认为<code>3</code>）设置为*n*时，每游戏刻一个方块结冰的概率是；每个区块中每个游戏刻会选取*n*次满足条件的方块，每次有的概率结冰。

# = 冰弹 =

丢入水中的[冰弹](冰弹.md)会将周围3×3×3区域内的水源和流动水变为冰。

# 获取
冰只能通过破坏冰获得。

# 破坏
挖掘冰的合适工具是镐。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，冰被破坏后不会掉落，并且在下界以外的维度中正下方为方块时会变成[水](水.md)。

被具有精准采集的工具挖掘破坏时，冰被破坏后会掉落自身。

# 用途
# = 储水 =
正下方为[固体方块](固体方块.md)（不包含[蜘蛛网](蜘蛛网.md)和[竹笋](竹笋.md)）或液体方块（[水](水.md)、[熔岩](熔岩.md)）的冰被玩家使用非[精准采集](精准采集.md)的工具破坏时会产生水源。由方块产生的、亮度等级高于11的光照射在冰的任意-{}-面上</ref>}}或会使之融化而变成水源，且无论冰下方是否存在方块都会如此，但阳光并不会使冰融化。

冰在下界由[环境属性](环境属性.md)<code>gameplay/water_evaporates</code>控制。}}不会产生水。

由于冰的最大堆叠数为64，冰可以被用于作为[水桶](水桶.md)的替代物，用于携带大量的水。

# = 合成材料 =

# = 滑行 =
冰比较滑，包括物品在内的大多数[实体](实体.md)（[矿车](矿车.md)除外<ref></ref>）可以在冰上滑动。在水流下放置冰亦可加快物品在水流中的速度，但生物不会在底部有冰的水流上滑的更快。

玩家在冰上疾跑并频繁跳跃可极大提高移动速度。[船](船.md)在冰上滑行的速度可达40格/秒。

若在冰上的方块高度不超过0.5格，其上表面会和冰一样光滑，这是开发者有意为之的。<ref></ref>

# 你知道吗
* 大多数实体都可以在冰面上滑行，因此玩家在冰上划[船](船.md)或骑[猪](猪.md)时，速度会变得很快。
* 在地面由冰组成、2格高的隧道内，一边[疾跑](疾跑.md)一边跳跃，可以在1秒内移动16格，几乎是[矿车](矿车.md)最大速度的两倍。如果在隧道内顶部放置[活板门](活板门.md)，可以在54秒内穿过1000个方块，速度为18.518方块/秒。但是玩家的饥饿值也会快速消耗，每秒会消耗一个单位饥饿值。
* 如果尝试用[打火石](打火石.md)在冰上打火，不会有[火](火.md)出现，但是打火石还是会减少[耐久度](耐久度.md)。
