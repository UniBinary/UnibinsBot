# Java版1.14.4-pre1

*页面ID: 44945* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14.4-pre1**是[Java版1.14.4](Java版1.14.4.md)的首个预发布版，发布于2019年7月3日<ref name="article_1.14.4-pre1"></ref>，为命令加入了新的参数，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 加入了。
* * 用于在调试性能时获取更详细的信息，例如每个维度中区块和方块实体的列表。
* ** 将信息以一个<samp>.zip</samp>文件保存在<samp>[.minecraft](.minecraft.md)/debug</samp>文件夹下。

# 更改
# = 生物 =
* *[村民](村民.md)**
* 现在不再频繁地补货了。
* 现在会自主捡起[物品](物品（实体）.md)了。

# = 物品 =
* *[谜之炖菜](谜之炖菜.md)**
* 由虞美人合成的谜之炖菜现在会给予玩家[夜视](夜视.md)效果而不是[迅捷](迅捷.md)。

# = 常规 =
* *性能**
* 性能优化
