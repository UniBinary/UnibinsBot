* *可可豆（Cocoa Bean）**是一种能够种植在[丛林原木](丛林原木.md)上的[食物](食物.md)材料。

* *可可果（Cocoa）**是种植在丛林原木上的作物方块，成熟时能掉落可可豆。

# 生成
# = 自然生成 =
在丛林[生物群系](生物群系.md)当中，可可果会自然生成在正常大小的丛林树树干上。

# 获取
# = 箱子战利品 =

# = 钓鱼 =

在[丛林](丛林.md)、[竹林](竹林.md)和[稀疏丛林](稀疏丛林.md)里[钓鱼](钓鱼.md)时，可可豆可作为垃圾被钓上来。

# 破坏
挖掘可可果的合适工具是斧和剑。

生长阶段没有达到第三阶段的可可果被破坏后会掉落1个可可豆。

生长阶段达到第三阶段的可可果被破坏后会掉落3个可可豆。

# 用途
# = 种植 =

把可可豆放置在[丛林原木](丛林原木.md)、[丛林木](丛林木.md)和它们的去皮变种的侧面即可种植新的可可果。

可可果有三个生长阶段：

* 第一阶段，可可果很小，呈浅绿色；
* 第二阶段，体积比第一阶段稍大，呈深黄色；
* 第三阶段，可可果最大，呈橘色。

[骨粉](骨粉.md)能够将可可果催熟到下一生长阶段。若接触水或，可可果会掉落。活塞推动后可可果会作为方块移动，若移动后没有附着在原木或木头上，可可果会掉落；若生长可可果的原木或木头被移除，可可果也会掉落。

不像大多数方块，可可果在放置时不会检查实体碰撞<ref></ref>，因此在玩家头部处种植可可果可以使玩家进入[爬行](爬行.md)状态。

# = 合成材料 =
可可豆在合成配方（给[旗帜](旗帜.md)添加图案除外）中可被用作[棕色染料](棕色染料.md)。

# = 堆肥 =
可可豆有65%概率将[堆肥桶](堆肥桶.md)堆肥等级增加1。

# 你知道吗
* 每个生长阶段的可可果都有不同的碰撞箱，然而其碰撞箱总是比其所在原木顶部低0.25格。
* 如果可可果在生长时玩家在它旁边站着，玩家不会被推开，且可以穿过它。
* 成熟的可可果顶部纹理只有7格像素宽，而侧面有8格像素宽。<ref></ref><ref></ref>
