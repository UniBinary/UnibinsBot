# Java版Indev 20100212-1210

*页面ID: 35407* | *来源: Minecraft Wiki*

<onlyinclude>

* *Minecraft Indev**的一个版本发布于2010年2月12日12:10（UTC），加入了新的[盔甲](盔甲.md)和合成配方。

# 新内容
# = 物品 =
* *[盔甲](盔甲.md)**
* 加入了[羊毛](羊毛.md)质、锁-{}-链质、铁质、金质和钻石质盔甲，即[头盔](头盔.md)、[胸甲](胸甲.md)、[护腿](护腿.md)和[靴子](靴子.md)的羊毛、锁-{}-链、铁质、金质和钻石质变种。
* 目前没有实际用途。
* 可分别由羊毛、[火](火.md)、[铁锭](铁锭.md)、[金锭](金锭.md)或[钻石](钻石.md)来合成对应等级的盔甲。

# = 世界生成 =
* *[星星](星星.md)**
* 仅有装饰性用途，会在夜空中出现。

# 更改
# = 方块 =
* *[水](水.md)、[火](火.md)和[熔岩](熔岩.md)**
* 放置在具有相同方块ID的位置时不再会被消耗。

* *[火把](火把.md)**
* 不再能悬空。
* 悬空放置的非固体方块现在会掉落自身。
* 不再根据周围的方块旋转。
* * 现在玩家可以选择火把的朝向。
* * 这导致现存世界的火把不再附着任何方块。<ref name="Forum4">https://www.minecraftforum.net/forums/archive/alpha/alpha-survival-single-player/796830-farms-dying-and-torches-reset</ref>

* *[沙子](沙子.md)和[沙砾](沙砾.md)**
* 现在悬空放置时会立刻下落。

* *[玻璃](玻璃.md)**
* 被破坏后不再会掉落自身。

# = 非生物实体 =
* *[物品（实体）](物品（实体）.md)**
* 现在物品会被沿直线扔出与以往有些许差异。

# = 游戏内容 =
* *[昼夜更替](昼夜更替.md)**
* 现在昼夜更替为20分钟，白天和黑夜各10分钟。

* *[雨](雨.md)**
* 被移除。

* *[光照](光照.md)**
* 阴暗处现在变得更暗了。

* *[暂停菜单](暂停菜单.md)**
* 现在游戏暂停时，[火](火.md)燃烧的动画会停止。

* *[物品栏](物品栏.md)**
* 移除了玩家模型。
* * 然而[盔甲](盔甲.md)仍然能够显示。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 加入了“L”（亮度更新）参数。

* *[粒子](粒子.md)**
* 修改了水花粒子的纹理。

* *[控制](控制.md)**
* 按不会再下雨了。</onlyinclude>
