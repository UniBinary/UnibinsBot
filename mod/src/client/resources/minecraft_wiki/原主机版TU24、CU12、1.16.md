# 原主机版TU24、CU12、1.16

*页面ID: 81110* | *来源: Minecraft Wiki*

* *TU24/CU12/1.16**是[原主机版](原主机版.md)的一次更新，发布于2015年4月26日至29日期间，修复了一些漏洞。<ref></ref><ref></ref>

# 新内容
# = 常规 =
* *[皮肤](皮肤.md)**
* PS3、PS4、PSV：加入了辛普森一家皮肤包试用内容。
* 加入了Alex和一些默认皮肤的变种。

# = 游戏内容 =
* *[成就](成就/原主机版与New Nintendo 3DS版.md)**
* XB360：加入了新成就。
* *[音乐](音乐.md)**
* XB360：加入新的音乐。

# 更改
# = 游戏内容 =
* *[音乐](音乐.md)**
* XBONE、PS3、PS4、PSV：更改了在创造模式和菜单屏幕中的背景音乐，以匹配Java版。

# 物品
* *[灌木](灌木.md)<!--原文Shrubs，原主机版独有-->**
* PS3、PS4、PSV：可以放在花盆里。

# 修复
* *修复了1个漏洞**
* PS3：修复了停止蒸汽朋克纹理包工作的漏洞。
