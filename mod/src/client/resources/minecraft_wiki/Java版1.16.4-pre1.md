# Java版1.16.4-pre1

*页面ID: 71054* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.16.4-pre1**是[Java版1.16.4](Java版1.16.4.md)的首个预发布版，发布于2020年10月15日<ref></ref>，加入了社交屏幕，并修复了一个世界生成的严重漏洞和一个纹理漏洞。

# 新内容
# = 常规 =
* 加入了社交屏幕。
* * 允许玩家与特定玩家的聊天，并由此隐藏从这些玩家收到的。
* * 可快捷键打开，默认为。
* * 当玩家重新加入服务器时，隐藏聊天玩家列表会重置。
* * 只能在多人游戏中使用，在单人游戏下试图进入社交屏幕时会提示“”。

# 更改
# = 物品 =
* *下界合金护腿**
* 更改了下界合金护腿应用于3D模型的纹理。

# = 常规 =
* *选项**
* 在options.txt文件中加入了“joinedFirstServer”选项。

* *服务器**
* 当服务器与的版本不兼容时，会显示“”的提示，而非“”或“”。

* *技术性内容**
* 新的网络协议方案，现在在高（第30位）会设置一个给快照版本使用。每个快照的协议版本会增加1，但是网络协议兼容时，完整发布版的协议版本可能会和之前的完整发布版一样。
* 向崩溃日志中加入了更多由于性能低下导致崩溃的。
