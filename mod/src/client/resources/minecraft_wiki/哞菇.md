* *菇|哞菇|蘑菇牛}}（Mooshroom）**是自然生成于[蘑菇岛](蘑菇岛.md)的类似于[牛](牛.md)的友好生物，体表上生长着多个蘑菇。

# 生成
# = 自然生成 =
当[光照等级](光照等级.md)不低于9时，红色哞菇会生成在[蘑菇岛](蘑菇岛.md)生物群系的[菌丝体](菌丝体.md)上。其中生成的哞菇中有5%会是幼年哞菇。

# = 闪电 =
当被[闪电](闪电.md)击中时，红色哞菇会变为棕色哞菇，棕色哞菇则会变为红色哞菇。

# 掉落物
成年哞菇[死亡](死亡.md)时掉落：

* （只会在被[玩家](玩家.md)或驯服的[狼](狼.md)杀死时掉落）

用[剪刀](剪刀.md)为哞菇剪除蘑菇会掉落5个对应颜色的[蘑菇](蘑菇.md)，同时发出[爆炸](粒子#largeexplode.md)的粒子效果，哞菇会变成牛，且无法再变回哞菇。

与其他幼年动物相似，杀死幼年哞菇不会掉落任何物品或经验。

# 行为
哞菇会缓慢而漫无目的地走动，偶尔会呼吸并发出哞哞声。它们躲避悬崖、[火](火.md)、[熔岩](熔岩.md)，但不会试图远离[水](水.md)。

# = 铁桶 =
对成年哞菇[铁桶](铁桶.md)可以获得[奶桶](奶桶.md)。

# = 碗 =
对成年哞菇[碗](碗.md)可以获得[蘑菇煲](蘑菇煲.md)。

# = 花 =
成年棕色哞菇可以被喂食[小型花](小型花.md)，使得下一次对其[碗](碗.md)时获得[谜之炖菜](谜之炖菜.md)而非蘑菇煲。

哞菇提供谜之炖菜后，下一次对其使用碗会获得蘑菇煲，除非继续对其喂食花。

被喂食过花的棕色哞菇如果变成红色哞菇，仍可以提供谜之炖菜。

对成年棕色哞菇喂食花时会使其发出少许或。对幼年棕色哞菇和已喂食过花的棕色哞菇花时会喂食失败，。

# = 繁殖 =

哞菇会跟随/手持[小麦](小麦.md)的玩家。

给两只哞菇喂食小麦会使之[繁殖](繁殖.md)，繁殖/后才能再次喂食。哞菇不能与牛互相繁殖。

两只红色的哞菇在繁殖时有的概率生成棕色幼年哞菇，反之亦然。

红色和棕色的哞菇共同繁殖时，其后代生成红色幼年哞菇和棕色幼年哞菇的可能性各占。

幼年哞菇的背上没有蘑菇，成年之后才会出现蘑菇。幼年哞菇会在20分钟后长大，每次喂食小麦可减少它们约10%的剩余成长时间。

对幼年哞菇[金蒲公英](金蒲公英.md)可以阻止其成长为成年哞菇，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年哞菇无法被喂食除金蒲公英外的其他物品。

# 你知道吗
* 简体和台湾繁体中文的“哞-{}-菇”一词是将[牛](牛.md)的叫声“哞”和“[蘑菇](蘑菇.md)”两个词结合而成的混成词，其对应英文原名“Mooshroom”亦为英文相同含义的“Moo”与“Mushroom”的混成词。
* 存在着一种身上长着[毛茛](MCE:毛茛.md)的变种哞菇，名为“[哞花](MCE:哞花.md)”。<ref></ref>在[Minecraft Live 2020](Minecraft Live 2020.md)的生物投票中，哞花在第一轮中以28.3%的得票率被淘汰。
* * 还存在着另一种身上长着[粉红雏菊](MCE:粉红雏菊.md)的变种，名为“[哞金香](MCE:哞金香.md)”。
* [哞菇](Minecraft Dungeons:哞菇.md)是一种敌对生物。
