# 压力板

*页面ID: 7650* | *来源: Minecraft Wiki*

[thumb|所有的压力板](File:All Pressure Plates.png.md)
* *压力板（Pressure Plate）**是一种可以用来探测[玩家](玩家.md)、[生物](生物.md)等[实体](实体.md)的[方块](方块.md)。

# 用途
[缩略图|压力板的放置和行为](File:Pressure plate as power source.png.md)
[缩略图|栅栏上的压力板](File:Pressure plate.png.md)

压力板必须于[方块支撑形状](方块支撑形状.md)上表面中心完整或边缘完整的方块上方（包括[漏斗](漏斗.md)、[栅栏](栅栏.md)、[侦测器](侦测器.md)等），不能放置于任何方块的侧面与底部。

尝试在无效的表面放置压力板会使其“滑入”这块空间内最近的有效附着表面。如尝试在地面上的栅栏侧面放置压力板会使其附着到栅栏周围地面方块的顶部。

当压力板附着的方块变动（移动、破坏、替代等），不再允许附着时或有[活塞](活塞.md)试图推动它或将方块推入其位置时，压力板会掉落为方块物品。

[沙子](沙子.md)或[沙砾](沙砾.md)这类受重力影响的方块正下方为压力板时不会开始下落。下落到压力板的位置时，它会掉落为方块物品。

# = 红石元件 =

压力板可探测其上方的实体（玩家，生物，[物品实体](物品实体.md)等）。

# == 开启 ==
压力板上方（具体为在压力板所在方块的（0.125,0,0.125）到（0.875,0.25,0.875）这个长方体区域内）有符合对应压力板要求的[实体](实体.md)时（即使实体的碰撞箱只有一小部分在其中），压力板会被**开启**。

# == 行为 ==
当开启时压力板会：
* 激活毗邻的[红石粉](红石粉.md)，四周背对压力板的[红石比较器](红石比较器.md)或[红石中继器](红石中继器.md)。
* 强充能压力板下方任何[红石导体](红石导体.md)至相应等级。
* 激活毗邻的[机械元件](红石电路#机械元件.md)。

压力板没有碰撞箱，不会阻碍实体移动。压力板附着的方块能在它下面提供一个固体阻碍（让生物走过，让物体落在上面等等），但压力板放置在碰撞箱较小（如栅栏）的方块上时，实体可能在开启压力板时穿过压力板。因此压力板可以用来探测实体而不阻碍它们的运动。

压力板关闭时高0.0625个方块（方块的），开启时高0.03125个方块（方块的），但它没有碰撞箱，所以不会影响它上方的实体（如压力板上的玩家其实是站在它下面的方块上）。
