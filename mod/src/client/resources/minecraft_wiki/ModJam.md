# ModJam

*页面ID: 49497* | *来源: Minecraft Wiki*

* *ModJam**是由[Searge](Searge.md)和MMD团队（Minecraft Mod Development）的其他成员举办的Minecraft年度活动。玩家必须在有限的时间内创建一个地图或一个[Mod](Mod.md)来赢得比赛。目前，它有几种类型：ModJam、Spooky Jam和Winter Jam。它通过提交的Mod的得分来评估结果。得分可通过玩家投票给他们喜爱的Mod来获得。

# Spooky Jam
# = Spooky Jam 2017 =

# Winter Jam
# = Winter Jam 2018 =
Winter Jam 2018是ProxyNeko和MMD团队在2018年12月举办的第一届Winter Jam。这是一个Mod制作活动而不是比赛。Mod必须与季节或假期有关。
