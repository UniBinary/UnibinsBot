# 烟花棒

*页面ID: 34792* | *来源: Minecraft Wiki*

* *烟花棒（Sparkler）**是一种当点燃时会发射粒子的物品。粒子可能是橙色、蓝色、红色、紫色或绿色的。

# 用途
烟花棒是中少数几个可以放在副手使用的[物品](物品.md)之一。手持烟花棒，通过按住键即可将其点燃。点燃的烟花棒的纹理会发生变化。

未点燃的烟花具有与[火把](火把.md)相似的正常光照，而点燃的烟花棒被手持时会发出与其颜色相同的彩色[粒子](粒子.md)，并在纹理上发光，但不会影响环境的实际亮度，类似于[荧光棒](荧光棒.md)。手持点燃的烟花棒时，其耐久度会逐渐减少。耐久度耗尽时，手中的烟花棒随即消失。物品形式的烟花棒亦有相似的行为，但不会消耗耐久度。

玩家手持点燃的烟花棒完全浸入水中时，烟花棒会消失，而未点燃的烟花不会发生变化。物品形式的烟花棒会在水中正常燃烧。

当玩家在点燃烟花棒的同时使用其他物品时，烟花棒的耐久度会暂停消耗。

# 你知道吗
* [耐久](耐久.md)魔咒和不可破坏标签（目前用修改器可获得）对烟花棒无效，但是如果让烟花棒被其他[实体](实体.md)拾取、丢弃为物品实体的形式都可以暂停烟花棒的[耐久度](耐久度.md)消耗，而且[经验修补](经验修补.md)魔咒也对烟花棒有效。
* 实际上用于合成烟花棒的五种氯化物中只有氯化钙在现实世界中被用于制作烟花，现实中制作红色、绿色和蓝色烟花通常使用氯化锶、氯化钡和氯化铜；而紫色烟花则是使用氯化锶和氯化铜混合制作的。
