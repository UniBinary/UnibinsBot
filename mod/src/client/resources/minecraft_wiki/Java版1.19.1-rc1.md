# Java版1.19.1-rc1

*页面ID: 96971* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.19.1-rc1**是[Java版1.19.1](Java版1.19.1.md)的首个发布候选版本，发布于2022年6月23日<ref></ref>，修改了聊天举报的部分举报类型，并修复了一些漏洞。

* “Blending”行现在在玩家处于使用新地形生成器生成的区块时消失，而非显示<code>Blending: New</code>。
