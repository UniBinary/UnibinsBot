# 火把

*页面ID: 5807* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *火把（Torch）**是一种可以提供亮光的非固体方块。

# 生成
# = 自然生成 =
火把的生成位置如下：
* 在[废弃矿井](废弃矿井.md)的走廊中随机生成；
* 在[要塞](要塞.md)的各种房间中生成；
* 在[雪屋](雪屋.md)的地下室中生成；
* 在[村庄](村庄.md)的灯柱（[雪原](雪原.md)村庄除外）、农田（仅[针叶林](针叶林.md)村庄）、一些房屋、会合点、牲畜栏等结构上生成；
* 在[掠夺者前哨站](掠夺者前哨站.md)的瞭望塔中生成；
* 在[林地府邸](林地府邸.md)的[一些房间](林地府邸/结构.md)中生成；
* 在[远古城市](远古城市.md)的小型前哨站上生成；
* 在[返回传送门](返回传送门.md)中央的[基岩](基岩.md)柱上生成；
* 在[奖励箱](奖励箱.md)的周围各处高度相同时生成在其周围。

# 破坏
火把被挖掘时会立刻被破坏。

火把被破坏后会掉落自身。

# 用途
# = 放置 =
[缩略图|在雕纹石砖上的各种火把摆放位置](File:Torches.png.md)

火把必须在[方块支撑形状](方块支撑形状.md)上表面中心完整的方块上方或侧面完整的方块侧面，不能放置于任何方块的底部。

尝试在无效的表面放置火把会使其“滑入”这块空间内最近的有效附着表面。如尝试在地面上的[栅栏](栅栏.md)侧面放置火把会使其附着到栅栏周围地面方块的顶部。

当火把附着的方块变动（移动、破坏、替代等）而不再允许附着时、有[水](水.md)或[熔岩](熔岩.md)流过或有[活塞](活塞.md)试图推动它或将方块推入其位置时，火把会掉落为物品形式。

# = 光源 =
[thumb|火把融化附近的冰](File:Torch and Ice.png.md)

火把会发出[亮度](亮度.md)为14级的光，能融化[曼哈顿距离](曼哈顿距离.md)2格内的[雪](雪.md)和[冰](冰.md)。
