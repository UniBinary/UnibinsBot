# 披风

*页面ID: 8434* | *来源: Minecraft Wiki*

[thumb|150px|穿着[[MINECON 2011](File:Steve_Skin_MINECON_2011_Cape.png.md)披风的[Steve](Steve.md)]]
* *披风（Cape）**是一种装饰物品，可装备在玩家的皮肤后面。

# 机制
[thumb|100px|minecraft.net上的披风菜单](File:MinecraftCapes Profile.png.md)
与[皮肤](皮肤.md)不同，披风不能由玩家自定义制作，而只能通过一些特殊的活动或事件来获取。部分披风能在社交媒体（如TikTok和Twitch）的限时活动和的[活动服务器](活动服务器.md)中获得。也有少量披风需要参加线下活动来获取。

目前多数新披风被玩家获取后会同步到和中，在两个版本中均可使用。

所有向公众开放获取的披风都只能在活动限定日期内获取，活动结束之后无法获得，但是披风的兑换并不限时。

可以前往[Minecraft账户页面](https://www.minecraft.net/msaprofile/mygames/editskin)或在[启动器](启动器.md)上选择要穿着的披风。

可以在[角色创建器](角色创建器.md)处选择要穿着的披风。

在和中，某些皮肤包或自定义皮肤会自带披风。

一部分客户端[Mod](Mod.md)可能会提供其自定义的披风，但这些披风除了对玩家自己或其他安装了相同客户端Mod的玩家以外通常是不可见的。

# = 外观 =
披风会在玩家下落、向前和侧向侧向移动时飘起，飘起的幅度与玩家移动的速度有关。披风飘起的幅度和最高高度比高。披风会在玩家横向移动时略微向另一侧斜向飘起。

# = 鞘翅 =

当玩家同时装备了披风和鞘翅时，披风就会隐藏，且玩家装备的鞘翅会有与披风外观相适应的纹理。

# = 未使用的披风设计 =
[thumb|200px|MINECON 2011候选披风](File:Cloakvote.png.md)
; MINECON 2011
MINECON 2011候选披风投票展示了5个披风。红色苦力怕披风在MINECON 2011中以42%的选票胜出，蓝镐披风则获得33%的选票，后来用在了MINECON 2012上。除此之外还设计了其他11个仍未被使用的披风，但可能会在未来出现。<ref>https://www.mojang.com/2011/09/minecon-swag-cloaks</ref>

; 基岩版皮肤包
这些披风来自基岩版[皮肤包](皮肤包.md)，但目前并没有在任何皮肤包中使用。
