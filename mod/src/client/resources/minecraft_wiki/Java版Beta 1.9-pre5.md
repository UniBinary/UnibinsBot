# Java版Beta 1.9-pre5

*页面ID: 32290* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.9-pre5**是[Java版1.0.0](Java版1.0.0.md)的第5个预发布版，发布于2011年10月27日<ref></ref>，加入了新的成就，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[成就](成就/Java版.md)**
* 加入了10个新成就：**（Overkill）**、**（Enchanter）**、**（Librarian）**、**（Diamonds!）**、**（We Need to Go Deeper）**、**（The End?）**、**（The End.）**、**（Local Brewery）**、**（Into Fire）**和**（Return to Sender）**。

# = 常规 =
* *调试特性**
* 按下会导致玩家“卡屏”，直到再次按下为止，这导致玩家看起来像方块一样。
* 按下导致视角无法移动，这允许在第三人称模式下使玩家模型旋转。
* 滚动鼠标的滚轮（包括打开物品栏时）会旋转向前，向左，向右和向后的方向。
* 按下、、、、、、、、和会以各种方式改变视角的位置，同时按下两个功能相同的按键（例如 + ）会恢复至普通的视角。

# 更改
# = 方块 =
* *[水](水.md)**
* 向下流动时会创建一个水源方块，而不是流动的水。

* *[荧石](荧石.md)、[下界岩](下界岩.md)、[钻石块](钻石块.md)、[金块](金块.md)、[沙砾](沙砾.md)、[木板](木板.md)、[石头](石头.md)、[泥土](泥土.md)、[草方块](草方块.md)和[铁块](铁块.md)**
* 更改了纹理。

* *[栅栏](栅栏.md)**
* 选择框现在类似于它们的碰撞箱。

# = 物品 =
* *[铁桶](铁桶.md)**
* 在创造模式中，使用空桶移除流体时不再装满桶。

# = 生物 =
* *常规**
* 敌对生物不会对创造模式中的玩家敌对。
* 减小了实体打击有效范围。

* *[史莱姆](史莱姆.md)**
* 史莱姆现在生成在0-40层而不是0-16层，使其变得常见。

* *[末影龙](末影龙.md)**
* 末影龙现在拥有一个新的死亡动画虽然它们不会生成，并且它们的生命值被改成来测试这个动画。

* *[僵尸猪灵](僵尸猪灵.md)**
* 现在可以被[喷溅型治疗药水](喷溅型治疗药水.md)伤害，也会被[喷溅型伤害药水](喷溅型伤害药水.md)治愈。同时对[中毒](中毒.md)免疫，[喷溅型再生药水](喷溅型再生药水.md)无效果。
* 附魔[亡灵杀手](亡灵杀手.md)魔咒的剑现在会造成额外的伤害。

# = 常规 =
* *选项**
* 加入了云的开关。

# 修复
* *修复了8个漏洞**
* 刷怪笼不再能通过附有精准采集魔咒的镐子获取了。
* 菌丝体和末地石现在会出现在创造物品栏中了。
* 台阶上脚步现在能正常显示了。
* 现在，睡莲在物品栏中有正确的颜色和名称标签了。
* 末地石现在有名称标签了（之前是“未命名”）。
* 西瓜现在会再次掉落正确数量的西瓜片了。
* 修复了使用附魔剑格挡时出现数据错误的漏洞，现在可以用附魔剑格挡了。
* 多人游戏中的幼年动物现在能正常工作了。</onlyinclude>
