# 沉重核心

*页面ID: 114608* | *来源: Minecraft Wiki*

* *沉重核心（Heavy Core）**是一种从[试炼密室](试炼密室.md)的[不祥宝库](不祥宝库.md)中获得的方块，可用于合成[重锤](重锤.md)。

# 生成
沉重核心不会生成在世界中。

# 获取
# = 箱子战利品 =

# 破坏
挖掘沉重核心的合适工具是镐。<ref></ref>

沉重核心被破坏后会掉落自身。

# 你知道吗
* 沉重核心必须通过[不祥宝库](不祥宝库.md)战利品才能实现可再生。这是因为宝库可以被每个玩家打开无限次数<ref></ref>，且[不祥试炼钥匙](不祥试炼钥匙.md)是[可再生资源](可再生资源.md)。
