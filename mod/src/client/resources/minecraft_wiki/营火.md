# 营火

*页面ID: 39263* | *来源: Minecraft Wiki*

* *营火（Campfire）**是一种可用于烹饪[食物](食物.md)的方块，可以作为[光源](亮度#光源.md)或烟雾信号源使用。

# 生成
# = 自然生成 =
营火可以自然生成在和}}村庄中。生成在[僵尸村庄](僵尸村庄.md)的营火总是熄灭的。

[远古城市](远古城市.md)的营地结构中会自然生成点燃或熄灭的营火。

[古迹废墟](古迹废墟.md)的部分结构中会自然生成熄灭的营火。

# 破坏
挖掘营火的合适工具是斧。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，营火被破坏后会掉落2个[木炭](木炭.md)和内容物。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，营火被破坏后会掉落自身和内容物。

# 用途
# = 点燃与熄灭 =
营火放置时默认是点燃的。

以下操作可将熄灭的营火点燃：
* ：[打火石](打火石.md)（可用[发射器](发射器.md)发射）、[火焰弹](火焰弹.md)。
* 向其发射[着火](着火.md)的[弹射物](弹射物.md)（如[箭](箭.md)和[三叉戟](三叉戟.md)）。
*

以下操作可使点燃的营火熄灭：
* 使营火变为[含水](含水.md)方块。
* 向其投掷[喷溅型水瓶](喷溅药水#喷溅型水瓶.md)或[滞留型水瓶](滞留药水#滞留型水瓶.md)。
* 对其[锹](锹.md)。
* 。

类似于[台阶](台阶.md)，水流并不会自然流进营火。营火不会因下雨而熄灭。

熄灭的营火与[灵魂营火](灵魂营火.md)在外观上没有任何区别，但重新点燃后仍会变回熄灭前的状态。

# = 烟雾信号 =
点燃的营火会持续产生上飘约10格后消失的烟雾粒子。若营火下方有[干草捆](干草捆.md)，烟雾上飘的高度将会增加至约25格。

上方1.5格内的[固体方块](固体方块.md)会部分阻挡烟雾粒子。距离营火越远，阻挡越多，直到上方1.5格时完全阻挡。

# = 伤害 =
点燃的营火每游戏刻会对位于方块中的生物造成的[火焰伤害](火焰伤害.md)，但[受击后伤害免疫](受击后伤害免疫.md)会使生物每半秒受到一次伤害。穿着带有[冰霜行者](冰霜行者.md)的靴子可以免疫营火伤害。

# = 烹饪 =
[right](File:Campfire (Cooking).gif.md)

对着点燃的营火生的食物可将其放到营火上。一个营火最多能放置4个食物。在营火上的食物会发出小的黑色粒子，这表明它们正在被烹饪。

在营火上，食物需要来烤熟，且不需要消耗燃料。烹饪结束后，熟的食物会掉落为物品。若使用营火同时烹饪4个食物，那么营火将比[熔炉](熔炉.md)的效率更高（每烹饪4个比在熔炉中少10秒，且无需燃料）。

# = 光源 =
营火会发出[亮度](亮度.md)为15级的光。与其他大多数光源一样，它可以融化3格内的[雪](雪.md)和[冰](冰.md)。

# = 蜜蜂 =
当[蜂巢](蜂巢（方块）.md)或[蜂箱](蜂箱.md)正下方6格内存在点燃的营火，并且二者之间无其他方块阻挡时，玩家采集[蜜脾](蜜脾.md)或[蜂蜜瓶](蜂蜜瓶.md)时不会激怒[蜜蜂](蜜蜂.md)（但此时若使用无[精准采集](精准采集.md)魔咒的工具破坏[蜂巢](蜂巢（方块）.md)或[蜂箱](蜂箱.md)仍会激怒蜜蜂）。
