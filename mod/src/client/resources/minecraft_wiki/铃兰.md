# 铃兰

*页面ID: 41815* | *来源: Minecraft Wiki*

* *铃兰（Lily of the Valley）**是一种[小型花](小型花.md)。

# 生成

# = 自然生成 =
铃兰会在和[繁花森林](繁花森林.md)生物群系自然生成。

# = 骨粉 =
在和[繁花森林](繁花森林.md)生物群系中对[草方块](草方块.md)[骨粉](骨粉.md)后，铃兰有概率代替[矮草丛](矮草丛.md)生成。

对着不[含雪](含雪.md)的铃兰使用骨粉会出现更多的铃兰，而不会出现草丛。

# 破坏
铃兰被挖掘时会立刻被破坏。

铃兰被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 谜之炖菜 =

使用铃兰合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家11s的[中毒](中毒.md)效果。

# = 堆肥 =
将铃兰放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
