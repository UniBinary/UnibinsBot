# 携带版0.13.0.b4

*页面ID: 18940* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.13.0 alpha build 4**是[v0.13.0 alpha](携带版0.13.0.md)的第4个测试版，发布于2015年11月9日<ref>http://pocketbeta.minecraft.net/2015/11/changelog-for-013-build-3.html?m=0</ref>，加入了新的[皮肤包](皮肤包.md)，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[皮肤包](皮肤包.md)**
* 加入了[生物群系定居者皮肤包 1](皮肤包#生物群系定居者皮肤包 1（Biome Settlers Pack 1 Skin pack）.md)。

# 更改
* 降低像素以减少延迟。
* 更新了所有门的纹理。
* 现在会生成更多的[恶魂](恶魂.md)和[史莱姆](史莱姆.md)了。

# 修复
* *修复了5个漏洞**
* “新”按钮现在会被正确翻译。
* 骷髅现在会在阳光下燃烧。
* 食用苹果不再使玩家中-{}-毒。
* 紧邻固体方块而放置的铁轨上的矿车现在会正确移动。
* 探测铁轨现在会正确保存红石激活状态。</onlyinclude>
