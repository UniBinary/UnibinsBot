* *玩家列表（Player Tab Overlay）**用于显示玩家的-{}-头像、名称与等信息。

玩家列表在第三方服务器中、有两名以上玩家或使用了<code>list</code>位置的[记分板](记分板.md)时按住“”键（默认为）时展示。玩家列表会在查看服务器在线人数、服务器在线玩家、自己和其他玩家的延迟状态时发挥很大用处。

玩家列表始终会在暂停菜单中展示，无论是否为多人游戏。

# 显示位置
# = Java版 =
[thumb|的单人游戏中使用了<code>list</code>位置记分板的玩家列表](File:Player tab overlay in singleplayer.png.md)
玩家列表会显示在屏幕上方中心，距离屏幕顶部有一定距离，与[Boss栏](Boss栏.md)同时存在时会挡住BOSS栏的一部分。

# = 基岩版 =
玩家列表会显示在[暂停菜单](暂停菜单.md)右侧。

# 显示内容
玩家列表可以有多列，每列不超过20名玩家，从左到右分别显示玩家头像<ref group="注">在服务器未启用正版验证时不显示。</ref>、玩家在服务器中的名称（颜色会显示为该玩家的队伍颜色）、玩家的记分项<ref group="注" name="nolist">无<code>list</code>位置的记分项时不显示。</ref>、玩家的延迟状态（用延迟图标表示）。

玩家列表仅有一列，从左到右分别显示玩家头像、玩家名称和玩家记分项<ref group="注" name="nolist"/>或玩家权限等级图示<ref group="注">在存在<code>list</code>位置的记分项且具有其数值时会被记分项覆盖。</ref>。

# = 玩家头像 =
当服务器启用正版验证时，每列玩家列表的左侧会显示该玩家的头像，当该名玩家的实体被客户端渲染时会显示双层皮肤头像，没有被客户端渲染时会显示单层皮肤头像。可以利用这一特性判断该玩家与自己的距离。

每名玩家的名称左侧会显示该玩家的Minecraft账户头像。未登录的玩家没有头像。

# = 记分项 =

[缩略图|250px|中将记分项位置设置为<code>list</code>的效果，渲染类型为<code>integer</code>](File:Scoreboard Display List Integer.png.md)
[缩略图|250px|中将记分项位置设置为<code>list</code>的效果，渲染类型为<code>heart</code>](File:Scoreboard Display List Hearts.gif.md)

当记分项位置设置为<code>list</code>时，记分项会显示在玩家列表中。

记分项在玩家列表中以黄色文字在玩家名称后显示分数信息（默认为键），而不会显示其名称。

在暂停页面的玩家列表显示分数信息。

# = 玩家延迟 =

[thumb|延迟图标](File:Ping.png.md)

玩家列表的最右侧会用类似信号大小的图标显示玩家当前的延迟，从1格信号到5格信号的延迟区间分别是1000/600/300/150/0毫秒，如果该玩家延迟未知则会在没有信号的图标上加一个红×来表示。
