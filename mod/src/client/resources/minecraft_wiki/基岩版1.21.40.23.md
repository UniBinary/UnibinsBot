# 基岩版1.21.40.23

*页面ID: 126525* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.40.23**（ChromeOS/Android）、**Preview 1.21.40.23**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.40](基岩版1.21.40.md)的第4个测试版，发布于2024年9月25日<ref></ref>，将[收纳袋](收纳袋.md)从[实验性玩法](实验性玩法.md)中移出，并修复了一些漏洞。

# 更改
# = 物品 =
* *[收纳袋](收纳袋.md)**
* 更改了未染色的收纳袋的纹理，以匹配。（）
* 空的收纳袋在被选中时不再会显示其容量条。（）
* 现在染色收纳袋的合成配方会在获得[染料](染料.md)时解锁，而不是在获得未染色的收纳袋时解锁。
* 不再属于[实验性玩法](实验性玩法.md)。
* * 收纳袋所使用的物品组件也不再属于[实验性玩法](实验性玩法.md)。

# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 移除了“”子选项。

* *编辑世界屏幕**
* 加入在新的[Ore UI](Ore UI.md)编辑世界屏幕中编辑世界缩略图的能力。

# = 技术性 =
* *[附加包](附加包.md)和脚本引擎**
* 实体组件中的新的测试性选项现在会正确要求在根JSON对象中指定。

* *API**
* 修复了在内对无效实体调用时可能发生的崩溃。

* *组件**
* 组件的字段现在支持以下3个值：
* * ：接收到的伤害应用于实体。
* * ：接收到的伤害不应用于实体。
* * ：接收到的伤害不应用于实体，但攻击的附带效果应用于实体。
* ** 这意味着攻击者的武器会损失耐久度，魔咒附带效果会被应用等。
* * 之前已存在的内容会自动进行更新，以保持其原先的行为。

* *[基岩版编辑器](基岩版编辑器.md)**
* 加入了新的空气方块图像，以在编辑器中选中空气方块时进行可视化操作。
* 更新了方块选取器模态框，以更好地传达当前选中的方块和替换它的方块。
* 修复了导航面板操作栏图标不正确以及缺失本地化文本的问题。
* 修复了部分图标主题颜色不会正确应用的漏洞。

* *实体**
* 现在使用最小引擎版本为1.17.0或更低版本的资源包时，马身上的马铠会正确渲染。（）

* *性能与稳定性**
* 现在自定义生物群系ID从30,000开始分配，并且存储在世界数据中的中，因此它们的ID分配会在世界的持续时间内-{}-存留。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“自定义生物群系”、“”和“”子选项后才可使用。

# = 技术性 =
* *性能与稳定性**
* 现在在洞穴与山崖更新前使用自定义生物群系创建的世界的区块中的自定义生物群系会被替换为默认生物群系（主世界中的海洋）。

* *[附加包](附加包.md)和脚本引擎**
* 为物品组件加入了字段。
* * 此字段允许指定该物品应该替换其所放置的数据驱动方块所创建的默认物品。
* * 为了能够使用此字段，物品的标识符必须与其所放置的方块的标识符相匹配。
* * 此字段是可选的，默认为false。

* *相机视角**
* 加入了水平和垂直旋转限制，需要开启聚焦目标相机实验性选项。
* 加入了布尔值，用于追踪超出预设旋转限制的实体，需要开启聚焦目标相机实验性选项。

* *图形**
* 修复了点光源阴影会导致附近的表面出现圆圈的问题。
* * 因此，点光源阴影的边缘现在是锯齿状的。这将会在后续更新中解决。
* 在延迟渲染预览功能中加入了数据驱动环境光照的能力。
* * 当SSR和IBL不可用，或在昏暗条件下不足以照亮金属物体时，环境光照可用作间接镜面反射贡献。
* * 环境光照还可用作环境贡献可拥有的最小值，以此避免场景在没有光源的情况下完全变黑。
* 对延迟渲染预览功能相关的JSON文件作出了破坏性的模式更改，以将字段提高至根级别。下列文件会受到影响：
* *
* *
* *
* *
* *
* *
* * 例如：
  :* 之前的模式为：
  :: <syntaxhighlight lang="json">
{
    "minecraft:lighting_settings": {
        "format_version": "1.21.40",
        ...
    }
}
</syntaxhighlight>
  :* 但现在应该写为：
  :: <syntaxhighlight lang="json">
{
    "format_version": "1.21.40",
    "minecraft:lighting_settings": {
        ...
    }
}
</syntaxhighlight>

# 修复
* *辅助功能**
* 为Marketplace Pass内容选项卡和Realms内容选项卡加入了文本转语音配音。

* *方块**
* 修复了方块放置在宝库上后会导致奇怪的方块行为的漏洞。（）
* 更新了行为包文件中遗留的对旧方块名称的引用。

* *命令**
* 修复了某些命令无法识别部分方块或物品名称的问题。

* *图形**
* 数据驱动物品不再会在截图中错位。（）

* *交易**
* 修复了尝试只使用第二个槽位进行交易时发生的崩溃。（）

* *用户界面**
* 为新的游玩屏幕加入了对Realms故事未读标记通知的支持（仅测试版本）。
* 现在收纳袋内的非空的收纳袋会有一个容量条。（）</onlyinclude>
