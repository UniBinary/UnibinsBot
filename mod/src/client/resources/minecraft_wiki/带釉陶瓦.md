* *带釉陶瓦（Glazed Terracotta）**是一种色泽亮丽的[固体方块](固体方块.md)，有16种颜色。

# 生成
品红色带釉陶瓦、粉红色带釉陶瓦、蓝色带釉陶瓦和绿色带釉陶瓦不会生成在世界中。

# = 自然生成 =
紫色带釉陶瓦会在[海底废墟](海底废墟.md)里生成。

黄色带釉陶瓦会在热带草原[村庄](村庄.md)里的石匠小屋生成。

橙色带釉陶瓦会在[热带草原](热带草原.md)村庄里的盔甲匠小屋生成。

白色带釉陶瓦会在[沙漠](沙漠.md)村庄里生成。

黄绿色带釉陶瓦会在沙漠村庄里的教堂生成。

淡蓝色带釉陶瓦会在沙漠村庄里的工具匠小屋生成。

黑色、灰色、淡灰色、白色、棕色、橙色、黄色、青色和淡蓝色带釉陶瓦会在[古迹废墟](古迹废墟.md)里生成。

红色带釉陶瓦会在[试炼密室](试炼密室.md)里生成。

# 破坏
挖掘带釉陶瓦的合适工具是镐。带釉陶瓦需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

带釉陶瓦被破坏后会掉落自身。

# 用途
带釉陶瓦主要用作装饰。

带釉陶瓦能被[活塞](活塞.md)推动，但不能被活塞拉动。这使得带釉陶瓦在一些红石装置中具有特别的作用。

# = 放置 =
[250px|thumb|品红色带釉陶瓦的透视图](File:Magenta Glazed Terracotta Xray.png.md)
在放置时，带釉陶瓦的纹理会根据玩家面对的方向作出旋转。如果相同颜色、方向正确的带釉陶瓦呈2×2或更大面积地摆放，这些纹理会构成一幅完整的图案，如右图所示。

品红色带釉陶瓦包含了箭头（↑）纹理，可用于指引玩家方向。下表是指南，用于正确放置箭头方向（基于测试结果）。“朝向”指的是玩家相对于放置的方块的前方，例如“下”指的是玩家在方块下方。

# = 纹理 =
[thumb|350px|一些2&times;2图案](File:More 2x2 tile options.png.md)
[缩略图|右|150px|青色带釉陶瓦上的苦力怕脸](File:cyanterracottaface.png.md)
按照正确的方向摆放时，多块带釉陶瓦的纹理能够拼接起来，形成更大的图案。带釉陶瓦的纹理大多沿对角线对称，尽管相对应位置上的像素颜色可能稍有差异。

带釉陶瓦上的图案大多没有特殊含义，但部分颜色的带釉陶瓦上有特殊的图案：

* 品红色带釉陶瓦上的箭头。
* 青色带釉陶瓦上的[苦力怕](苦力怕.md)的脸。
* 紫色带釉陶瓦上的[剑](剑.md)柄和[镐](镐.md)头。
