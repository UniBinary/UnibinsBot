# Java版16w21a

*页面ID: 21546* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w21a**是[Java版1.10](Java版1.10.md)的第2个快照，发布于2016年5月25日<ref></ref>，加入了新的NBT标签，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* *NBT标签**
* <code>FallFlying</code>
* * 允许怪物使用鞘翅飞行。
* ** 怪物会在接触地面后失去飞行能力。

# 更改
# = 方块 =
* *[结构方块](结构方块.md)**
* 向加载模式加入了“结构完整性和种子”选项。

* *[骨块](骨块.md)**
* 不再透明。

* *[紫颂果](紫颂果.md)**
* 现在可以正常传送骑着动物的玩家（被骑乘的动物不会被传送）。

* *[发射器](发射器.md)**
* 现在可以给实体装备盾牌。

* *[铁轨](铁轨.md) （任何种类）**
* 上坡铁轨的碰撞箱现在为1个方块。（以前只有格高）。

# = 物品 =
* *[末影珍珠](末影珍珠.md)**
* 现在可以正常传送骑着动物的玩家（被骑乘的动物不会被传送）。

* *[末地传送门](末地传送门.md)**
* 在激活时会替换任何被末地传送门框架围着的方块。

* *[钓鱼竿](钓鱼竿.md)**
* 现在可以将物品拉向玩家。

* *[矿车](矿车.md)**
* 碰撞到实体时会再次乘载实体了。

# = 生物 =
* *[狼](狼.md)**
* 不再消失。

# = 世界生成 =
* *[村庄](村庄.md)**
* 生成在热带草原的村庄铁匠铺会生成圆石以避免被熔岩烧毁。

# = 命令格式 =
* *NBT标签**
* <code>IsVillager</code>和<code>VillagerProfession</code>标签被完全移除，它们被在[16w20a](16w20a.md)中首次加入的<code>ZombieType</code>代替。

# = 游戏内容 =
* *[粒子](粒子.md)**
* <code>fallingdust</code>现在可以被生成了，利用像<code>blockcrack</code>等一些粒子类型的<code>params</code>参数。
* * 使用命令会生成熔岩颜色的粒子。
