# Java版1.2.4

*页面ID: 29987* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.2.4**是的一次次要更新，发布于2012年3月22日<ref></ref>，加入了[木板](木板.md)和[砂岩](砂岩.md)的新变种，优化了聊天框，并修复了一些漏洞。此版本不兼容1.2.1到1.2.3的服务端。

# 新内容
# = 方块 =
* *[木板](木板.md)**
* 现在[木板](木板.md)的类型会随着用于合成的[木头](原木.md)而变化了。
* 现在有总共4种[木板](木板.md)：
* * 橡木木板
* * 白桦木木板
* * 云杉木木板
* * 丛林木木板

* *[砂岩](砂岩.md)**
* 加入了新变种，使用了[Java版1.2.1](Java版1.2.1.md)中加入的未使用的纹理。
* 与普通[砂岩](砂岩.md)的名字是相同的。

# 更改
# = 常规更改 =
* *[聊天](聊天.md)**
* 添加了聊天记录，且编辑聊天文本更加方便。
* 现在聊天框中的链接可以点击。
* * 当点击了这个链接，会有警告屏幕提醒玩家是否要继续打开这个链接。
* 玩家现在可以在聊天框中复制和粘贴链接。
* 鼠标滚轮可用于向上/向下滚动历史记录。
* * 也可以使用和。
* 上/下键可用于浏览最近发送的消息。
* 如果你想输入其他用户的用户名，现在你可以使用来自动补全用户名。
* 在聊天框中复制/粘贴。
* 类似地，聊天中的显示随机字符，，，和分别显示粗体，划线，下划线和斜体，而重置任何设置状态。
* * 上述功能不可以在原版客户端中使用。
* 按可以立即打开聊天框，此时聊天框内会出现一个“/”。
* 按住或可以以相应的方向移动文本光标，所以当你发现前面打了错字时，不必清除前面的字就可以将光标移动到那个字后面了。

* *内存溢出屏幕**
* 加入了“返回”和“退出”按钮。

* *[调试屏幕](调试屏幕.md)**
* 加入了“小型”调试屏幕。
* * 和按下显示的调试屏幕不同，不会显示分析图表和分析器。
* * 可按下+打开。

* *[物品栏](物品栏.md)**
* 重新添加了盔甲栏的轮廓。

# = 方块 =
* *[羊毛](羊毛.md)**
* 轻微降低了各种颜色的饱和度。

# = 生物 =
* *[猫](猫.md)**
* 现在在站着的时候会坐到附近的[箱子](箱子.md)、正在烧炼的[熔炉](熔炉.md)和[床](床.md)的上方。
* * 这会导致[玩家](玩家.md)不可以使用它们。

# 修复
* *修复了25个漏洞**
* 现在在已有台阶上放置另一个台阶（放置出一个完整方块）更容易了。
* 菜单屏幕上的帧率受限，CPU使用率不再是100%。
* 修复了当旧存档最高处有方块时转换位Anvil文件格式时造成崩溃的致命漏洞。
* 修复了在多人游戏中，告示牌被编辑时内容被清空的漏洞。
* 修复了在出生点最高建筑高度位置上有方块导致崩溃的漏洞。
* 修复了多人游戏中存在TNT幽灵方块的漏洞。
* 修复了运输矿车掉落附魔物品的漏洞。
* 修复了使用无效服务器地址加入游戏时的崩溃漏洞。
* 修复了在多人游戏中，玩家不能与在登录时就已存在的实体进行交互的漏洞。
* 修复了画的复制漏洞。
* 修复了熔炉和发射器掉落附魔物品的漏洞。
* 修复了聊天从屏幕消失时的“闪烁”现象。
* 修复了在容器屏幕中的物品文字渲染在物品上方的现象。
* 修复了丛林树苗的问题（将其他树苗变为丛林树苗）。
* 修复了当路径中包含空格时，启动器打开文件夹的问题。
* 修复了一个一对一的照明错误。<!--原文：Fixed an off-by-one lighting bug.-->
* 修复了可以使用活塞将一个方块变成另一个方块的问题。
* 修复了在蘑菇不可存活的阳光下放置它们的问题。
* 修复了亮着的红石灯被破坏时掉落处于充能状态的方块物品的漏洞。
* 现在命令即使在命令已使用过的时候也会正常工作了。
* 修复了玩家站在台阶上会使得台阶变成完整方块的问题。
* 修复了多人游戏中种子未知时，调试屏幕上种子的显示问题。
* 修复了不同职业的村民在客户端侧更改纹理的问题。
* 修复了按住时会从墙角的边缘掉落的问题。
* 玻璃块现在可以再次通过附有精准采集的工具破坏时掉落了。</onlyinclude>
