# 启动器2.2.1169x

*页面ID: 94583* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.2.11698**（）、**2.2.11696**（，版）、**2.2.11699**（）或**2.2.11697**（）是一次[启动器](启动器.md)更新，发布于2022年3月22日。

# 更改
* 为登录过程加入了改进后的超时判定，以防止登录失败时进度条一直处于旋转状态。
* 一些启动器内的FAQ字符串已被推送至Crowdin。
* 各种额外的稳定性和可靠性改进。

# 修复
* 修复了启动器关闭后进程仍在运行的问题，此问题会导致启动器无法重启。
* 修复了安装对话框的问题。
* 修复了一些离线模式的问题。在离线状态尝试登录的过程中加入了更新过后的错误或失败状态提示。
*  - 更新说明页面中的“快照”选项被禁用。
*  - 新启动器字符串中有几处提及“Minecraft: Java Edition”的地方的拼写不统一。
*  - 西里尔字母“Ө”和“Ү”不被像素化字体支持。
*  - 一页中，“Patch notes”的“n”是小写的。
*  - 启动器不支持用双引号括住的Java路径。
*  - “Third-party licenses”中连字符的用法不一致。</onlyinclude>
