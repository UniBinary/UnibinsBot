# 基岩版1.21.81

*页面ID: 151563* | *来源: Minecraft Wiki*

* *1.21.81**是的一次热修复更新，在除iOS/iPadOS和Nintendo Switch外的平台上发布于2025年5月14日<ref></ref>，在iOS/iPadOS平台上发布于2025年5月15日，在Nintendo Switch平台上发布于2025年5月16日，修复了一些漏洞。此版本与[1.21.80](基岩版1.21.80.md)相兼容。

# 修复
* *图形**
* 修复了（实验性功能）有时会应用于目前不支持此功能的世界的问题。
* 修复了特定iOS设备上可能会出现像素化失真的问题。（）

* *游戏内容**
* 修复了玩家在游泳时接触到方块会导致速度下降过快的漏洞。（）

* *性能与稳定性**
* 修复了加载带有被拴住的实体的世界时可能发生的崩溃。
* 修复了激活“SplashPotChange”和“LingeringPotChange”资源包后可能发生的崩溃。（）

* *API**
* 修复了方块自定义组件事件不会使用只读权限的漏洞。由于V1.X.X的脚本在发布时没有附带只读权限，此修复仅会应用于V2.X.X及更高版本的脚本。

* *组件**
* 组件的值现在再次可以在运行时通过组件组来更新。
* 的预设现在会在每一刻重新计算，而不是仅在实体被拴住时重新计算。
