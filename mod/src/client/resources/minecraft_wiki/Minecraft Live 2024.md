# Minecraft Live 2024

*页面ID: 126229* | *来源: Minecraft Wiki*

* *Minecraft Live 2024**是一场线上直播活动，于2024年9月28日17:00（UTC）举行。不同于往届，该场活动不再举行生物投票，也不再公布大型更新内容，取而代之是两个小更新（Drops）内容演示。直播中还展示了[A Minecraft Movie](A Minecraft Movie.md)的幕后制作和线下活动Minecraft Experience: Villager Rescue的体验预览。<ref name="minecraft-live-2024-announcement"></ref><ref name="minecraft-live-2024-recap"></ref>

# 预告
# = Minecraft Live 2024：预告片 =
官方于2024年9月18日发布预告视频，正式宣布此次活动。

# = Minecraft Monthly =
官方于2024年9月25日发布[Minecraft Monthly](Minecraft Monthly.md)，包含部分更新内容的线索。

# 活动
# = 社区预热 =
在主要活动开始前有15分钟的社区预热活动，分享了世界各地YouTuber的Minecraft视频。

# = 版本公告 =
本次直播公布了Minecraft下一次小更新的正式名称[勇气之袋](勇气之袋.md)和更新范围，包括[收纳袋](收纳袋.md)和即将正式加入的[极限模式](极限模式.md)。除此之外，还公布了[之后小更新](苍园觉醒.md)的部分更新内容，展示了敌对生物[嘎枝](嘎枝.md)、生物群系[苍白之园](苍白之园.md)、新的树种[苍白橡树](苍白橡树.md)及其一系列装饰性方块，但并未公布其正式名称。

# = 开发者演示 =
主要活动结束后，主持人[Lydia](Lydia Winters.md)及[Jens](Jens Bergensten.md)、Anna和Marco等开发者演示了玩家与嘎枝的交互，[嘎枝之心](嘎枝之心.md)生成嘎枝的方式，以及由苍白之园衍生方块构成的玩家建筑。

# 你知道吗
* 在活动开始前的9月24日，该活动的官网页面曾短暂切换到直播结束后应该显示的版本，导致部分内容提前泄露。<ref>https://web.archive.org/web/20240924180401/https://www.minecraft.net/en-us/live</ref>
