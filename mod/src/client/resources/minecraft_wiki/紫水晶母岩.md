# 紫水晶母岩

*页面ID: 71723* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *紫水晶母岩（Budding Amethyst）**是一种可以长出[紫晶芽](紫晶芽.md)的方块。

# 生成
# = 自然生成 =
紫水晶母岩会自然生成在[紫晶洞](紫晶洞.md)结构中的内壁，取代一小部分的[紫水晶块](紫水晶块.md)。

# 获取

紫水晶母岩无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，紫水晶母岩可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
挖掘紫水晶母岩的合适工具是镐。紫水晶母岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

紫水晶母岩被破坏后不会掉落。

# 用途
紫水晶母岩接收到[随机刻](刻#随机刻.md)时，它的某个表面会有20%概率长出[紫晶芽](紫晶芽.md)，若已有紫晶芽连接至该紫水晶母岩，则会有20%的概率生长到下一阶段。只有接触到水或空气的表面才有可能长出紫晶芽。调整[游戏规则](游戏规则.md)会改变紫晶芽的生长速度。
