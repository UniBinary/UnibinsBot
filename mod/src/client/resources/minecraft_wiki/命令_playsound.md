# 命令/playsound

*页面ID: 39801* | *来源: Minecraft Wiki*

以特定的音量和音高，在指定位置向玩家播放[声音事件](声音事件.md)实例。

# 语法
; Java版
   <code>-{}-playsound <sound> [<*类别*>] [<targets>] [<pos>] [<volume>] [<pitch>] [<minVolume>]</code>

; 基岩版
   <code>playsound <sound: string> [player: target] [position: x y z] [volume: float] [pitch: float] [minimumVolume: float]</code>

# 参数

   指定要播放的[声音事件](声音事件.md)。
   一个声音事件可被多个不同的声音关联，而实际产生的声音为从中随机挑选的结果，被选中的概率由其权重决定，与正常游戏中相同。例如，声音事件<code>entity.pig.ambient</code>会随机播放多种猪音效之一，因为有多个声音关联于该事件。
   [资源包](资源包.md)可能会向声音事件定义文件中添加额外的声音项目；此命令可以正常播放这些项目。该命令使用的声音名称**不是**音频文件名；而是严格使用文件内定义的声音事件（声音事件名称可能与实际音频文件的文件名和目录完全不同），因此如果要使用该命令播放资源包中新添加的音频文件，必须事先在文件内定义相应的声音事件（这只是为了让该命令能成功解析新添加的声音，如果是使用资源包替换原来已定义的声音事件，则不必为其重新定义）。

：{{cd|-{}-<*类别*>}}
   指定播放声音所属的类别，对应于游戏选项中“音乐和声音”设置的分类，玩家在该类别设定的音量决定了其听到此播放声音的音量。必须为以下之一：<code>master</code>、<code>music</code>、<code>record</code>、<code>weather</code>、<code>block</code>、<code>hostile</code>、<code>neutral</code>、<code>player</code>、<code>ambient</code>、<code>voice</code>或<code>ui</code>。若未指定，默认为<code>master</code>。

   指定播放声音的目标。


   指定声音发出的方位。


   指定声音能被听见的距离。必须至少为0.0。对小于1.0的值，声音会相对减轻，球状可闻范围会相对小。对大于1.0的值，声音不会实际上增大，但其可闻范围（1.0时半径为16米）会与*音量*相乘。声音总会基于与球体中心的距离逐渐衰减至无声。默认为1.0。


   指定声音的音高。若未指定，默认为1.0。
   该数值必须在0.0至2.0间（含），而小于0.5的值与0.5等价。小于1.0的值降低音高而提升持续时间；大于1.0的值提升音高而降低持续时间。音高值是乘在声音-{}-频率上的一个倍率，因此若将0.5-1.0（含）区间内的音高值乘以2，所得的新音高便会高一个八度。
  * 对于[音符盒](音符盒.md)的声音，如果你希望将其他音符转换为音高数值，请参阅[相关内容](音符盒#用途.md)。但请注意1.0的音高值对于每种声音并不一定都是F♯。
   该数字没有特别限制，但是必须要在0.0至256.0之间才有对应效果。高于256.0的值与默认值的效果相同。小于等于0.0的值会导致听不到该声音。
   此参数在调整音高时会相应地调整声音的播放速度，且播放速度相对于原音频采样速度的倍率即为此参数的值。

   指定在声音可闻范围外的目标能听到的音量。若目标在可闻范围外，作为补偿，声源会被放置在距离目标较近的位置（距离小于4格），而<code>-{}-*最小音量*</code>会决定补偿声源的音量。
   如果此数值等于0，则正常可闻范围外的目标听不到声音。如果未指定，则默认为0.0。
