# Java版22w17a

*页面ID: 95427* | *来源: Minecraft Wiki*

<onlyinclude>

* *22w17a**是[Java版1.19](Java版1.19.md)的第8个快照，发布于2022年4月27日<ref></ref>，从中加入了[山羊角](山羊角.md)，对[悦灵](悦灵.md)和[监守者](监守者.md)做出了一些更改，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[山羊角](山羊角.md)**
* 自加入。
* 会在[山羊](山羊.md)冲撞[煤矿石](煤矿石.md)、[绿宝石矿石](绿宝石矿石.md)、[铁矿石](铁矿石.md)、[原木](原木.md)、[浮冰](浮冰.md)或[石头](石头.md)时掉落。
* 可以发出可在远处听到的响亮的声音，有大约7秒的使用冷却时间。
* 共有8种山羊角，不同山羊角可发出的声音不同。
* * “沉思”“”“寻觅”和“”会在普通山羊冲撞方块时掉落，或者出现在[掠夺者前哨站](掠夺者前哨站.md)的[箱子](箱子.md)中。
* * “仰慕”“呼唤”“”和“”仅会在尖叫山羊冲撞方块时掉落。
* * 冲撞方块时掉落山羊角的种类是完全随机的。

# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 加入了关于监守者的远程攻击的死亡消息。

# = 常规 =
* *[聊天](聊天.md)**
* 玩家间的聊天信息现在会附带[RSA](wzh:RSA加密演算法.md)。
* 玩家会在启动游戏时获得由Mojang提供的密钥对。
* 聊天样式现在经由具有<code>chat.type.text</code>翻译键的服务器[资源包](资源包.md)处理。

* *[实体数据格式](实体数据格式.md)**
* 向山羊的实体数据格式中加入<code>HasLeftHorn</code>和<code>HasRightHorn</code>字段。
* * 均为布尔值，山羊头上山羊角的可见性和可掉落性由这2个字段控制。

* *[物品修饰器](物品修饰器.md)**
* 加入了物品函数<code>set_goat_horn_sound</code>。

* *<samp>[server.properties](server.properties.md)</samp>**
* 加入了<code>enforce-secure-profile</code>服务器选项。此选项设为<code>true</code>时，玩家必须具有由Mojang签署的公钥才能进入服务器。默认值为<code>false</code>。

# 更改
# = 方块 =
* *[酿造台](酿造台.md)**
* 更改了酿造台底座的UV和纹理，以与先前在上作出的修复保持一致，在视觉效果上没有影响。

* *[红树根](红树根.md)**
* 更改了方块模型，使内部面与外部面大小一致。

* *[活塞](活塞.md)和[黏性活塞](黏性活塞.md)**
* 更改了活塞头木板部分的纹理，以使该部分颜色与[橡木木板](橡木木板.md)一致。

* *[幽匿块](幽匿块.md)**
* 降低了[爆炸抗性](爆炸抗性.md)。

* *[幽匿催发体](幽匿催发体.md)**
* 现在扩散出的[幽匿](幽匿.md)类方块斑簇可以替换[泥巴](泥巴.md)和[灵魂沙](灵魂沙.md)。

* *[TNT](TNT.md)**
* 现在[矿石](矿石.md)、幽匿类方块和[刷怪笼](刷怪笼.md)被玩家手动点燃的TNT爆炸摧毁时会掉落[经验](经验.md)。

# = 物品 =
* *[栅栏](栅栏.md)**
* 更改了放置在物品栏中的栅栏模型，使其横向两栏杆粗细与方块形式的保持一致。

* *[皮革帽子](皮革帽子.md)**
* 将后部的叠加层纹理下移了两个像素，以使该部分的条形纹理延伸至最下方。

# = 生物 =
* *[悦灵](悦灵.md)**
* 现在在悦灵附近奏响[音符盒](音符盒.md)时会向其发送振动波粒子。
* 现在可通过[羊毛](羊毛.md)阻挡音符盒向悦灵发送信号，以阻止悦灵识别到此音符盒。
* 更改了音效。

* *[唤魔者](唤魔者.md)、[幻术师](幻术师.md)和[女巫](女巫.md)**
* 更改了模型，现在可以渲染出袍子纹理的最下方两行像素。

* *[山羊](山羊.md)**
* 现在每只会掉落最多2个山羊角。剩余数量取决于其头上角的数量。

* *[羊驼](羊驼.md)**
* 更改了所有变种的箱子纹理，现在使用[纹理更新](纹理更新.md)后的箱子纹理。

* *[掠夺者](掠夺者.md)**
* 更改了模型，略微缩短了外衣的长度以与实际纹理相符。

* *[村民](村民.md)**
* 更改了模型，现在可以渲染出袍子纹理的最下方两行像素。
* 更改了所有[生物群系](生物群系.md)服装的纹理。
* * 现在其腿部顶面和底面的颜色与侧面正确匹配了。
* * 移除了[热带草原](热带草原.md)村民皮肤中与村民基本纹理相同的部分。
* * 略微更改了[丛林](丛林.md)村民鞋子的纹理。

* *[卫道士](卫道士.md)**
* 更改了模型，略微缩短了外衣的长度以与实际纹理相符。
* 更改了手臂盘起时的纹理。
* * 现在其双手间的“缝隙”会正确连接起来。
* * 更改了上臂与下臂之间接缝面的颜色，默认情况下不可见。

* *[监守者](监守者.md)**
* 调整了监守者的远程攻击：
* * 现在无视[盾牌](盾牌.md)和[护甲值](护甲值.md)。
* * 造成的伤害由之前的（简单）、（普通）、（困难）减为。
* * 发动攻击的冷却时间由5秒减至2秒。
* * 现在玩家由此死亡时会显示特有的死亡消息。
* 现在死亡时会掉落1个幽匿催发体。

* *[狼](狼.md)**
* 撤销了[22w11a](22w11a.md)中对其耳部和腿部所做的镜像处理。<ref></ref>

* *[僵尸村民](僵尸村民.md)**
* 更改了模型，现在可以渲染出袍子纹理的最下方两行像素。
* 更改了除沙漠和沼泽外所有生物群系服装的纹理。
* * 现在其腿部顶面和底面的颜色与侧面正确匹配了。
* * 在热带草原僵尸村民的服装中加入了“衬衫”部分以与其他僵尸村民相匹配。
* * 略微更改了丛林僵尸村民鞋子的纹理。
* * 移除了武器匠僵尸村民手臂前端的多余纹理。

# = 常规 =
* *[HUD](HUD.md)**
* 将半护甲值图标中的高亮像素点移至图标左侧。

* *[Realms](Realms.md)**
* 将被选中世界的高亮由此前不明显的样式改为清晰的绿色复选标记。

* *[闪烁标语](闪烁标语.md)**
* 移除了“Привет Россия!”。

* *[标签](Java版标签.md)**
* 向方块标签中加入了磨制深板岩。
* 移除了游戏事件标签。
