# Johan Aronsson

*页面ID: 26551* | *来源: Minecraft Wiki*

* *约翰·阿伦森（Johan Aronsson）**在[Mojang Studios](Mojang Studios.md)担任创意主管。

# 关于
2016年10月，Johan加入Mojang，担任像素艺术家主管，负责[Java版](Java版.md)及授权DLC。2017年9月，同时兼任[Minecraft Dungeons](Minecraft Dungeons.md)艺术总监。

2018年9月，开始担任工作室艺术总监。负责Mojang旗下游戏的美术指导工作，包括[Minecraft](Minecraft.md)、[Minecraft Dungeons](Minecraft Dungeons.md)和[Minecraft Legends](Minecraft Legends.md)。同时管理工作室的游戏美术团队。

2021年3月，开始担任品牌艺术总监。负责IP、产品和项目的宣传、活动、沟通和营销素材的创意策划和领导工作。2023年4月，晋升为品牌创意主管。
