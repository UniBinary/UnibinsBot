# Java版19w13a

*页面ID: 41870* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w13a**是[Java版1.14](Java版1.14.md)的第29个快照，发布于2019年3月27日<ref></ref>，加入了效果，辅助设置按钮和新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[状态效果](状态效果.md)**
*
* * 在战胜[袭击](袭击.md)后获得。
* ** 此效果的等级和[不祥之兆](不祥之兆.md)的等级相同。
* * 持续三个游戏日，使[村民](村民.md)的[交易](交易.md)有大幅度的折扣。

# = 常规 =
* *[菜单屏幕](菜单屏幕.md)**
* 在主菜单中加入辅助功能设置按钮。

* *[闪烁标语](闪烁标语.md)**
* 加入了以下闪烁标语:
* * “Rainbow turtle”
* * “Something funny!”
* * “I need more context.”
* * “AAAAAAAA”
* * “Don't worry, be happy”
* * “Water bottle!”
* * “What's the question?”
* * “Plant a tree!”
* * “Go to the dentist.”
* * “What do you expect?”
* * “Look, mom. I'm in a splash!”

# 更改
# = 方块 =
[缩略图|右|在此快照中的一些可放置的方块](File:19w13a transparency.png.md)
* *透明方块**
* 更多的[方块](方块.md)可以放置在[玻璃](玻璃.md)、所有类型的[冰](冰.md)、[荧石](荧石.md)、激活的[红石灯](红石灯.md)、所有颜色的[染色玻璃](染色玻璃.md)、[海晶灯](海晶灯.md)、[信标](信标.md)、[南瓜灯](南瓜灯.md)、高画质下的[树叶](树叶.md)、开启的[活板门](活板门.md)等透明方块上面和侧面了。<ref>https://www.reddit.com/r/Minecraft/comments/b67lvy/19w13a_allows_you_to_place_these_blocks_on_glass/</ref>
* * 活板门可用于[复制绊线钩](Tutorial:方块和物品复制#绊线钩及绊线复制.md)。

# = 生物 =
* *[唤魔者](唤魔者.md)**
* 现在会在[袭击](袭击.md)的第5-7波生成，而不是最后一波。

* *[灾厄村民](灾厄村民.md)**
* 现在能打开门。
* 如果在袭击中杀死所有村民，会“庆祝”。

* *[村民](村民.md)**
* 现在能敲[钟](钟.md)了。
* * 在钟响时会跑进附近的房子。
* 现在再次可以在袭击中交易了。
* 现在会在袭击时产生“冒汗”的粒子效果。
* 现在会在战胜袭击后发射[烟花火箭](烟花火箭.md)来“庆祝”。
* 幼年村民现在有属于特定生物群系的皮肤了。
* 战胜袭击后，村民会根据自己的职业赠送玩家随机物品：
  :

# = 游戏内容 =
* *[不祥之兆](不祥之兆.md)**
* 现在效果等级可到达5。
* * 通过击杀多个[袭击队长](袭击队长.md)提升等级。
* * 击杀一个袭击队长时仅获得等级1的不祥之兆。
* 每一名带有不祥之兆的玩家进入都会导致袭击波数的增加。

* *[袭击](袭击.md)**
* 现在重新平衡了所有的波数，特定的一波注重于生成特定的生物，并且前期的几波袭击变得更难了。
* 游戏[难度](难度.md)决定了波数（简单难度为3波，普通难度为5波，困难难度为7波。第3波会出现劫掠兽，第4波会出现女巫，第5波会出现唤魔者）。
* 额外的不祥之兆进入村庄会导致增加额外的几波，相当于结尾的基础袭击。
* 更高等级的不祥之兆生成的敌人拥有附魔武器的概率更高。
* 现在有胜利或失败的信息代表袭击结束。

# = 声音 =
* *[灾厄村民](灾厄村民.md)、[女巫](女巫.md)和[村民](村民.md)**
* 加入“庆祝”音效。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 移除所有有关于[Markus "Notch" Persson](Markus Persson.md)的闪烁标语。
* * “Made by Notch!”
* * “The Work of Notch!”
* * “110813!”
