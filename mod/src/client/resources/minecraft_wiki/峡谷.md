# 峡谷

*页面ID: 9335* | *来源: Minecraft Wiki*

[thumb|地面上的峡谷](File:Over Ravine.png.md)

* *峡谷（Canyon<ref name="21w06a"></ref>或Ravine）**是一种长且深的地面裂缝，它也是[主世界洞穴](洞穴#主世界.md)系统的一部分。

# 生成
峡谷自然生成于主世界Y=10至Y=67的高度上，每个区块有1%的概率生成。这个高度是峡谷的生成高度，峡谷自身会占据约40格的高度。

峡谷的起始生成点在峡谷的一侧，并不是峡谷的几何中心。每一段峡谷在生成时也会随机上下偏移若干格或进行宽度或高度的缩放。

# 结构
峡谷的长度约为85-127格，宽度通常不多于15格，深度约为27-62格。峡谷的内壁崎岖不平，提供了多层的小平台。峡谷的整体形状呈现越接近中心高度更深、宽度更厚，且向两端递减的趋势。

作为主世界[洞穴](洞穴.md)系统的一部分，峡谷也拥有洞穴的相关特征。如与[含水层](含水层.md)相交时峡谷内会被[水](水.md)或[熔岩](熔岩.md)填充；高耸的内壁更易生成[涌泉](涌泉.md)以形成小瀑布；多种矿石[团簇](团簇.md)以及[矿脉](矿脉.md)会暴露于峡谷内壁；可以与洞穴、[地牢](地牢.md)、[废弃矿井](废弃矿井.md)和其他一些自然生成的结构相连。

若位于史莱姆区块，延伸至Y=40以下的峡谷内有可能生成[史莱姆](史莱姆.md)。

# 已移除的峡谷
# = 水下峡谷 =

[thumb|一道包含涡流气泡柱的水下峡谷](File:Underwater Ravine.png.md)
* *水下峡谷（Underwater Canyon<ref name="21w06a"/>或Underwater Ravines）**是生成在海洋中的峡谷，生成于Y=10至Y=67的高度上，且更倾向于生成于世界底部，每个区块有2%的概率生成。

水下峡谷与普通的峡谷在整体形状上无异。区别在于，水下峡谷内部由水而不是空气填充，其在世界底部生成的熔岩层的表面一层均被替换为[黑曜石](黑曜石.md)和[岩浆块](岩浆块.md)，会产生涡流[气泡柱](气泡柱.md)。[海草](海草.md)和[海带](海带.md)也会生成在黑曜石上。

[洞穴与山崖](洞穴与山崖.md)后，含水层取代了专门的水下峡谷。

# = 裂隙 =

[缩略图|300px|裂隙的透视图](File:Xray view of crack carvers.png.md)
* *裂隙（Crack<ref></ref>或Crevice<ref name="crevice"></ref>）**是一种从地表向下延伸的地形，比峡谷更窄更直。其生成于Y=40至Y=80的高度上，每个区块有0.125%的概率生成。

裂隙最多可以深达90个方块，直通[深板岩](深板岩.md)层。与峡谷类似，裂隙的整体形状也呈现中心深度最深，向两端递减的趋势，且递减的速度明显快于常规的峡谷。
