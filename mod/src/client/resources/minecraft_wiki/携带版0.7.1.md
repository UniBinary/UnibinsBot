# 携带版0.7.1

*页面ID: 21255* | *来源: Minecraft Wiki*

* *v0.7.1 alpha**是[携带版](携带版.md)的一次次要更新，发布于2013年6月7日，更改了标题界面的Logo，修复了[v0.7.0 alpha](携带版Alpha 0.7.0.md)中的一些漏洞与崩溃。

# 更改
# = 常规 =
* 更新了标题界面的Logo。

# 修复

* *其他**
* 修复了牛可以在创造模式中挤奶，但不需要手持空桶的漏洞。
* 修复了合成蛋糕时不返还铁桶的漏洞。
* 修复了在使用分离控制时无法用铁桶取水的漏洞。
* 修复了在创建新世界时滚动会打开另一个可用世界的漏洞。
