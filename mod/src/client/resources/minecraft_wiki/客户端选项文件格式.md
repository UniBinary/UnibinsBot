# 客户端选项文件格式

*页面ID: 9950* | *来源: Minecraft Wiki*

* *客户端选项文件**（****）是一个用来存储所有可以在游戏[选项](选项.md)中改变的设定的文件，同时也会存储游戏退出后需要保存的信息。它在[Java版](Java版.md)中位于文件夹中，在[基岩版](基岩版.md)中位于文件夹中。你可以使用任何文本编辑工具来编辑它，以达到改变设定的效果。值得注意的是，大部分设定你都可以直接在游戏中更改，但仍有少数设定只能通过编辑该文件来修改。

# 选项
# = Java版 =
