# 用途
尽管栅栏看起来只有1格高，但它的[碰撞箱](碰撞箱.md)却有1.5格高。这意味着玩家和大多数生物在没有[跳跃提升](跳跃提升.md)效果时不能越过栅栏。不过由于其轮廓箱仍为1格高，因此通过其上方空间攻击或选中后面的方块不受影响。

所有栅栏的水平长度为0.25格，占据一个方块最中间的位置，多个栅栏连接时中间会被占据从而连成一个整体。

栅栏占据着方块的中心位置，碰撞箱宽度小于1格，因此处于水中的玩家或生物可以通过紧靠未[含水](含水.md)的栅栏呼吸。

# = 连接 =
与栅栏相邻的方块与栅栏相邻的面如果是完整的面，那么栅栏会自动与之连接，但不会连接[屏障](屏障.md)、[南瓜](南瓜.md)、[雕刻南瓜](雕刻南瓜.md)、[南瓜灯](南瓜灯.md)、[西瓜](西瓜.md)、任何类型的[树叶](树叶.md)和[潜影盒](潜影盒.md)。

所有木栅栏会互相连接，下界砖栅栏会互相连接，但木栅栏和下界砖栅栏不会互相连接。栅栏会连接侧面与之相邻的[栅栏门](栅栏门.md)。

# = 拴绳 =
使用[拴绳](拴绳.md)拴着实体时对着栅栏按下可将它们拴在栅栏上，并在栅栏上生成一个[拴绳结](拴绳结.md)。

# 你知道吗
* 如果把[地毯](地毯.md)放在栅栏顶部，玩家可以跳上地毯进而越过栅栏，而除了[兔子](兔子.md)和史莱姆外的生物都不可以。
* 如果在半空中被攻击，造成的击退可以使玩家跨越其原本跳不上的栅栏。
* 玩家可以用台阶放在栅栏旁边跳过栅栏，而大多数一格高的生物不能跳过。
* 与其他栅栏不同，竹栅栏的模型使用单独的[纹理](纹理.md)，而不是使用对应的木板纹理。
* 下界砖栅栏和木栅栏可以通过在两种栅栏之间放置[栅栏门](栅栏门.md)的方式来间接连接。（见）
