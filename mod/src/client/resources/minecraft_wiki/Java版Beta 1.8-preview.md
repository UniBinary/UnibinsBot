# Java版Beta 1.8-preview

*页面ID: 150925* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.8-preview**是[Java版Beta 1.8](Java版Beta 1.8.md)的特别预发布版，该版本被私下赠送给[*Hat Films*](https://youtube.com/c/hatfilms)，并用来制作Beta 1.8的宣传片<ref></ref>。

# 与Beta 1.8-pre1的不同
* *[经验](经验.md)**
* 使用“Skill points”系统。
* * 每提升1等级，会提升3个Skill points。

* *[HUD](HUD.md)**
* 在经验条上方会显示Skill points。
* * 在创造模式下也会出现。
* 不显示版本号。

* *[风袭丘陵](风袭丘陵.md)**
* 不会生成[高草丛](高草丛.md)。

* *[村庄](村庄.md)**
* 可以在任何生物群系中生成。

* *[玫瑰](虞美人.md)**
* 会在世界中生成。

* *[圆盘](圆盘.md)**
* 不会生成。</onlyinclude>
