# 命令/codebuilder

*页面ID: 176233* | *来源: Minecraft Wiki*

控制指定玩家的[代码构建器](代码构建器.md)。

# 语法
   <code>codebuilder code check code_status <status: CodeBuilderCodeStatus> <player: target></code>
  : 检查代码构建器运行结果是否匹配。
   <code>codebuilder navigate <player: target> <openCodeBuilderWindow: Boolean> <URL: text></code>
  : 将代码构建器导向指定链接（仅限已支持平台）。
   <code>codebuilder reset <player: target></code>
  : 重置代码构建器。
   <code>codebuilder runtime <action: CodeBuilderRuntime> <player: target></code>
  : 控制代码构建器运行状态。
   <code>codebuilder subscribe scoreboard <player: target> <objective: string></code>
  : 将代码构建器关联记分项。
   <code>codebuilder unsubscribe scoreboard <player: target> <objective: string></code>
  : 将代码构建器取消关联记分项。

# 参数

   指定运行结果，必须为以下其中之一：
  *  — 错误运行
  *  — 运行中
  *  — 未运行
  *  — 已暂停
  *  — 成功运行

   指定要控制的玩家。


   指定是否打开窗口。


   指定链接文本。


   指定运行状态，必须为以下其中之一：
  *  — 暂停
  *  — 开始
  *  — 终止
