# 音乐唱片far

*页面ID: 156536* | *来源: Minecraft Wiki*

* *far**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的同名曲目。

# 获取
# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片far。

# 用途
# = 音乐 =

[noicon](File:far.ogg.md)

Far是一首平静、轻松的自然风格旋律，游戏内时长为2分54秒。

# = 红石 =

音乐唱片far放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为5的信号。
