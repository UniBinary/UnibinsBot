* *NPC（非玩家控制角色，Non-Player Character）**是一种外观与[村民](村民.md)相似的可交互友好生物，属于[教育版](教育版.md)和[基岩版](基岩版.md)的独有生物<ref>https://education.minecraft.net/support/knowledge-base/using-npcs/</ref>。

# 生成
NPC不会自然生成，仅能通过使用NPC[刷怪蛋](刷怪蛋.md)（输入或获取）或用[命令](命令.md)来生成。若要通过[刷怪蛋](刷怪蛋.md)来生成NPC，玩家必须拥有世界建造者能力，，也可使用命令来手动获取。

NPC生成时头顶会自带一个[格式化代码](格式化代码.md)为黄色（）的名称“NPC”，该名称不能用[命名牌](命名牌.md)更改。

# 掉落物
NPC死亡时不会掉落任何[物品](物品.md)和[经验](经验.md)。

# 行为
NPC没有AI。它们既不能走动也不能被其他实体推动（[船](船.md)除外），大多数实体都可以直接穿过NPC。

NPC免疫几乎所有伤害，也不受[状态效果](状态效果.md)影响。

与大多数[生物](生物.md)相同的是，当玩家距离足够近时，NPC会慢慢转向并看着玩家。NPC能被[活塞](活塞.md)和[水流](水流.md)推动，它们站在[黏液块](黏液块.md)和[蜂蜜块](蜂蜜块.md)上时激活黏性活塞也能被拖动。NPC会受到[风爆](风爆.md)击退。

NPC会受到[僵尸疣猪兽](僵尸疣猪兽.md)、[凋灵](凋灵.md)、[监守者](监守者.md)和“Johnny”[卫道士](卫道士.md)的攻击，也会受到[山羊](山羊.md)的冲撞，尽管NPC不会受到任何伤害，[箭](箭.md)也会穿过NPC。

NPC可以被拥有世界管理员权限的[玩家](玩家.md)立即杀死或被命令杀死。它们在掉入[虚空](虚空.md)后也会立即死亡。

# 界面
[缩略图|当没有世界管理员权限时的NPC界面](File:Npcpet.png.md)
[缩略图|当拥有世界管理员权限时的NPC界面](File:NPCs Talk page in pe.png.md)

右键NPC将显示其界面，它们只能被拥有世界管理员权限的玩家编辑。玩家可在该界面编辑NPC的对话框、名称和外观。当玩家没有世界管理员权限时，它将只显示对话框和按钮。

# = 定制 =
; 名字
   NPC的名字会在其头顶显示。默认的名字为“NPC”，在外观上显示的默认文字颜色为黄色（）。在界面的“名字”一栏可以编辑NPC名字。名字最长32字，文字颜色可以使用[格式化代码](格式化代码.md)来改变。
   注意，该名字（NameTag）与[实体名字](命名牌#用途.md)（CustomName）是不同的，对NameTag的修改不会影响CustomName。

; 对话
   对话框位于“名称”的正下方，通常用作向导工具。对话框的文本字数限制为256，尽管在某些情况下它为337。

; 外观
   NPC的外观是可选择的，只需左键单击你想要的皮肤即可改变皮肤。
   目前NPC拥有60个皮肤。

; 高级设置
   高级NPC设置由命令组成。它们用于创建交互式按钮。目前可以添加的最大高级设置为6个。
  ; 命令
  : 命令功能允许[玩家](玩家.md)在NPC中添加[命令](命令.md)。命令可以在标题下面的第一个输入框中输入， 它不像[命令方块](命令方块.md)，因为它可以同时执行多个命令，目前命令最多能输入1024个字符。
  : 该命令可以作为按钮或直接命令来呈现。作为一个按钮，按钮名称或标签可以通过填写“按钮名称”来改变，标签的文本限制是16个字。只有当玩家的世界管理员权限被禁用时才能执行。
  : 当不作为按钮添加时，右击NPC将执行该命令。相反地，按钮将被显示并且具有默认为浅灰色的标签颜色，并且可以使用格式化代码来改变颜色。
  : 对于NPC内置的命令界面，有一个特有的选择器变量为，它可以选择当前与该NPC进行交互（例如打开NPC对话框、使用NPC按钮和关闭NPC对话框）的玩家。如果该选择器用于外置命令，则不会报错，但不会选择到任何玩家。
