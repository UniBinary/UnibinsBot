# 基岩版1.18.0.21

*页面ID: 90176* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.0.21**是[基岩版1.18.0](基岩版1.18.0.md)的第2个测试版，发布于2021年10月14日<ref></ref>，调整了一些特性，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 用于加载战利品表。

# 更改
# = 方块 =
* *[铜矿石](铜矿石.md)**
* 正常开采掉落[粗铜](粗铜.md)的最大数量由3改为5。

* *[切石机](切石机.md)**
* 现在可将1个[铜块](铜块.md)（含变种）加工成对应变种的4个切制铜块、4个切制铜楼梯或8个切制铜台阶。

# = 生物 =
* *[美西螈](美西螈.md)**
* 现在仅生成于[繁茂洞穴](繁茂洞穴.md)里[黏土](黏土.md)上方的水中。

* *[溺尸](溺尸.md)**
* 现在会生成在[溶洞](溶洞.md)中。

* *[山羊](山羊.md)**
* 不再生成于[裸岩山峰](裸岩山峰.md)。

* *[鳕鱼](鳕鱼.md)、[鲑鱼](鲑鱼.md)、[河豚](河豚.md)、[热带鱼](热带鱼.md)和[海豚](海豚.md)**
* 现在仅生成于Y=50至64之间的水中。
* 另外，热带鱼现在也会生成于任意高度的繁茂洞穴中。

* *[发光鱿鱼](发光鱿鱼.md)**
* 现在仅生成于Y=30以下的水中。

# = 世界生成 =
* *[紫晶洞](紫晶洞.md)**
* 现在仅生成于主世界Y=30以下处。
* 调整了生成频率，以接近[1.17.0](基岩版1.17.0.md)的情况。

* *[生物群系](生物群系.md)**
* 非洞穴生物群系（例如[热带草原](热带草原.md)）不再随[高度](高度.md)变化。
* 调整了一些生物群系的相对大小，以接近1.17.0的情况。
* 提高了大多数生物群系的平均大小。
* 调整了寒冷生物群系生成的位置，以降低与温度较高的生物群系相接的概率。

* *[峡谷](峡谷.md)**
* 调整了生成高度和位置，以匹配1.18.0之前的情况。

* *[地牢](地牢.md)**
* 提高了生成数量，尤其是Y=0以下的数量。

* *[沙砾](沙砾.md)**
* 提高了沙砾团簇的生成数量。

* *[湖泊](湖泊.md)**
* 移除了水湖地物，其功能由[含水层](含水层.md)替代。

[450px|thumb|1.18.0.21的矿石分布](File:21w40a approximate ore distribution.jpg.md)
* *[矿石](矿石.md)分布**
* 再次调整了矿石分布以匹配。

* *[村庄](村庄.md)**
* 现在外形略加分散。

# = 常规 =
* *[菜单屏幕](菜单屏幕.md)**
* [全景图](全景图.md)更改为新地形生成机制下的主世界地表。
* * 由于测试版默认使用beta独有全景图，新全景图在一般情况下并不可见。

# = 技术性 =
* *GameTest框架（实验性）**
* 为加入了只读属性。
* * 以秒为单位，表示最后一存储刻之间的时间。

* *Android**
* 将Android平台使用的API等级升级至Android API 30。
* * 因此游戏数据的外部存储目录由修改为。

# 修复
* *洞穴与山崖特性**
* 修复了一些关于含水层的问题（这使得含水层会在与上个版本不同的位置上生成）。
* 修复了开启过“洞穴及悬崖”选项的超平坦世界中的部分区块会消失的问题。（）
* 陶瓦岩柱现在又会在风蚀恶地中生成了。（）
* 风蚀恶地的地下洞穴中不再会异常生成石柱。（）
* 现在水和熔岩涌泉会以正确的频率生成了。
* 修复了生成于峡谷中的铜矿石会浮空的问题。（）

* *活动对象**
* 闪电不再会出现阴影。（）

* *方块**
* 现在覆雪的草方块上的雪与其他雪类方块的颜色更加相似。（）

* *骨粉**
* 现在对着诡异菌岩使用骨粉又有概率生成下界苗了。（）

* *游戏内容**
* 重新进入开启过“洞穴及悬崖”选项、玩家生成点在Y轴为负数的危险区域的世界时，玩家不再会传送至Y轴为正数的区域。（）
* 铜矿石现在会掉落2-5（而不是2-3）个粗铜。（）
* 现在1个铜块可以在切石机中制成4个切制铜块。（）

* *玩家**
* 修复了玩家在使用鞘翅飞行时受到伤害碰撞箱不会正确更新的问题。（）
* 修复了玩家在使用鞘翅飞行时受到伤害不会停止飞行的问题。（）

* *物品**
* 末影珍珠在林地府邸的战利品箱中不再会被荧光棒代替生成。（）

* *生物**
* 修复了热带鱼无法在繁茂洞穴中生成的问题。（）

* *粒子**
* 水滴粒子现在可以触发溅落效果。

* *用户界面**
* 将一些用户界面出现上的“存档”重命名为更为准确的“世界”。
* 现在滑块的步长值与实际步骤不对应时，其会显示在最近的步骤上。
* 重新加入了世界设置中消失的“终为白日”选项。（）

* *原版趋同**
* 盾牌格挡动画现在能够流畅播放。（）

* *技术性**
* 修复了子区块有时会不使用缓存的请求无法被支持的缓存问题。
* 修复了在动画控制器版本为1.8.0的市场世界中会使用错误模式的动画控制器版本错误。</onlyinclude>
