# 铁砧

*页面ID: 9609* | *来源: Minecraft Wiki*

* *铁（Anvil）**是一种可以[附魔](附魔（物品修饰）.md)、[修复](物品修复#铁砧修复.md)和重命名物品的[方块](方块.md)。铁砧在使用过程中会逐渐受损，变为**开裂的铁砧（Chipped Anvil）**、**损坏的铁砧（Damaged Anvil）**，最终完全消失。

# 生成
普通的铁砧和开裂的铁砧不会生成在世界中。

# = 自然生成 =
[林地府邸](林地府邸.md)的[铁匠屋](林地府邸/结构#铁匠屋.md)中会生成一个损坏的铁砧。

[古迹废墟](古迹废墟.md)的一个厅堂中也会生成一个损坏的铁砧。

# 破坏
挖掘铁砧的合适工具是镐。铁砧需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉-{}-落。

铁砧被破坏后会掉-{}-落自身。

# 用途
# = 改造物品 =

铁砧的主要功能是改造物品，修复其耐久度或添加[魔咒](魔咒.md)。铁砧即可打开其交互界面。

通过访问铁砧的交互界面，铁砧具有以下基本功能：
* 重命名任何物品，包括方块的物品形式。注意，方块数据中不存储方块名称的方块被放置后会失去其名称，而箱子等拥有[方块实体](方块实体.md)的方块（除[结构方块](结构方块.md)）名字会替换掉界面原本的名字。
* 使用修复材料来修复受损的物品。例如，可以使用[铁锭](铁锭.md)修复铁质[工具](工具.md)和[盔甲](盔甲.md)。可修复物品的默认名称通常与修复材料有一致的前缀，但例外情况有[木板](木板.md)修复[盾牌](盾牌.md)、[铁锭](铁锭.md)修复[链甲](链甲.md)、[幻翼膜](幻翼膜.md)修复[鞘翅](鞘翅.md)、[犰狳鳞甲](犰狳鳞甲.md)修复[狼铠](狼铠.md)和[旋风棒](旋风棒.md)修复[重锤](重锤.md)。
* 合并两个相同类型和品质、且都有[耐久度](耐久度.md)机制的物品，例如[镐](镐.md)、[弓](弓.md)、[剪刀](剪刀.md)等。[耐久度](耐久度.md)的合并与使用工作台合并相似，物品上的魔咒遵循的结合规律参见[铁砧机制](铁砧机制.md)。
* 将[工具](工具.md)与[附魔书](附魔书.md)结合，将魔咒转移到工具上。相比于合并两个相似物品上的魔咒，使用[附魔书](附魔书.md)花费更少，且能让物品获得在[附魔台](附魔台.md)上无法得到的魔咒。
重命名物品可在修理或合并物品的同一步骤进行，只要经验花费不太高。

在[生存模式](生存模式.md)和[冒险模式](冒险模式.md)中，铁砧单次只能进行耗费最高39级经验等级的操作。如果要消耗40级或更多经验等级时，铁砧将提示“”并拒绝进行操作（[创造模式](创造模式.md)中没有这个限制）。当消耗的经验等级超过2,147,483,647时，消耗的经验等级将不再显示且物品不能被取出。

[创造模式](创造模式.md)的玩家可以使用铁砧和附魔书为任意物品附上任意魔咒<ref></ref>，不受魔咒之间冲突的影响且不花费经验。

# = 下落的方块 =

铁砧在下方没有不可替代的方块时会变为[下落的方块](下落的方块.md)。

铁砧落地时，会对当前位置的实体造成<math>\min\{2(h-1),40\}</math>的伤害，其中<math>h</math>为下落的高度。装备任意[头盔](头盔.md)可以减少的伤害，但头盔的耐久度会严重损失。令原始伤害为<math>m</math>，则头盔减少的耐久度为{{only|je|for=<math>\lfloor \max\{1, \frac{m}{4}\}\rfloor</math>}}或{{only|be|for=<math>\lfloor \max\{1, \frac{m}{4}\}\rfloor + \lfloor \mathrm{rand}(4,6)\times m \rfloor</math>}}。

铁砧在没有得到支撑时，不会在方块下方产生[粒子](粒子.md)。

# = 地图 =

铁砧可以代替工作台来缩放地图、复制地图或在地图上放置玩家位置指示器，且不会消耗经验。

# = 受损程度 =
铁砧共有3个受损程度：铁砧、开裂的铁砧、损坏的铁砧。受损的铁砧仍然可以正常使用。不同受损程度的铁砧不能相互堆叠。

在非[创造模式](创造模式.md)下，每次使用铁砧都有12%的概率使之受损程度恶化，使其受损程度进入下一个阶段；损坏的铁砧（即最后一个受损程度）发生受损程度恶化时，会直接消失。

下落的铁砧可能会受损或被摧毁。如果铁砧下落的高度高于1格，受损程度恶化的概率为<code>5%×*下落的高度*</code>。

平均每个铁砧能用25次（即铁砧可使用次数的数学期望），相当于平均每用一次铁砧就消耗了1.24个用于合成铁砧的铁锭。

如果玩家因为使用损坏的铁砧，导致该铁砧方块被破坏，则会播放一个特殊、带有破碎的打铁声。

# 你知道吗
* 铁砧的下落参考了[常见的卡通比喻](http://tvtropes.org/pmwiki/pmwiki.php/Main/AnvilOnHead)。
* 铁砧下落所能造成的最大伤害是，能够杀死同一位置上绝大多数具有满生命值的生物。因此可利用铁砧制作陷阱。
* * 虽然游戏设定上头盔能减免掉落铁砧造成的伤害，但实际上铁砧是在落地变为方块的瞬间命中生物的脚部碰撞箱而产生伤害。不过装备靴子并不能减免被铁砧砸中造成的伤害。
* 不同于[箭](箭.md)、[雪球](雪球.md)、[鸡蛋](鸡蛋.md)投射物一次只能对同一位置的一个生物碰撞箱造成单体伤害，铁砧的落下伤害属于多体伤害，对于命中位置上的所有生物碰撞箱造成全体伤害，原理类似[穿透](穿透.md)魔咒，但没有伤害数量上限。
* 铁砧的爆炸抗性与[黑曜石](黑曜石.md)和[附魔台](附魔台.md)同为1200点，仅次于游戏内爆炸抗性第二高的[基岩](基岩.md)，然而其合成材料[铁块](铁块.md)的爆炸抗性只有6点。
* * 因为高防爆抗性的关系，铁砧无法用于[水下TNT爆破](Tutorial:在水下利用TNT破坏方块.md)技巧。
* 重命名后的物品不能与未命名的或不同名称的同类物品重叠。
* * 可利用这个特性低成本获得[物品分类器](Tutorial:通用物品分类器.md)的填充物。
* 对于未附魔物品，建议合成一个新物品或[合并损坏的物品](物品修复.md)，因为“零件修复”普遍花费更多的材料。但盔甲例外，你可以在花费一定的等级来使用更少的材料进行修复。
* 若将下落的铁砧用活塞推入一整片[蜂蜜块](蜂蜜块.md)墙壁，那么铁砧也会因蜂蜜块的特性缓缓滑下。
* * 缓慢下滑的铁砧无论从多高坠落，落地时都不会砸伤坠落点的生物，铁砧本身也不会受损。这可能是因为铁砧实体本体有一部分因陷入蜂蜜块中，而使部分偏移到一格之外，导致无法有效变回方块。
