# 压缩空气

*页面ID: 143859* | *来源: Minecraft Wiki*

* *压缩空气（Packed Air）**是一种类似[空气](空气.md)的方块，位于其中的玩家不会消耗氧气值。

# 生成
压缩空气不会生成在世界中。

# 获取
# = 合成 =

# 用途
放置在[月球](月球.md)上的压缩空气可以使位于其中的玩家不会消耗氧气值。

压缩空气可以放置，但在接触常规的空气方块时会散失。
