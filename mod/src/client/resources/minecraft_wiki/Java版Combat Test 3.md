# Java版Combat Test 3

*页面ID: 49024* | *来源: Minecraft Wiki*

}}<onlyinclude>

* *Combat Test 3**是未来的战斗改版的第3个公开的实验性版本，发布于2019年10月31日<ref></ref>，虽然它是未来版本的测试版，但这个战斗实验版是[Java版1.14.4](Java版1.14.4.md)的分支。此版本只发布在[Reddit](wzh:Reddit.md)上，因此其并不出现在[启动器](启动器.md)版本列表或[Minecraft.net](Minecraft.net.md)的文章中。

# 新内容
# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 为斧加入了[劈裂](劈裂.md)魔咒。
* * 每级魔咒增加伤害和令盾牌失效的时间。
* * 最高等级为III。
* * 与[锋利](锋利.md)魔咒互斥。

* *[盾牌](盾牌.md)**
* 加入了“盾牌指示器”选项，决定“盾牌指示器”是否在使用盾牌时显示，与攻击指示器相似。
* * 可在视频设置下找到，可选状态有“关”、“十字准星”和“热键”。
* 加入了在使用盾牌时对其进行隐藏的选项。
* * 可在视频设置下的“盾牌动画”中找到。

# 更改
# = 物品 =
* *[斧](斧.md)**
* 现在总会令盾牌失效，而不再只有25%的概率令盾牌失效。
* 现在进行攻击只会消耗1点耐久值，而非2点。

* *[剑](剑.md)**
* 将攻击速度从2.5改回3.0。
* 现在又可以一直按住键以在每次指示器填满时都自动进行一次攻击了。
* * 每次自动攻击都需要等待武器冷却达到120%，稍慢于手动连续攻击。

# = 非生物实体 =
* *弹射物**
* 现在不再会激活生物的“无敌时间计时器”，这意味着带有[多重射击](多重射击.md)魔咒的[弩](弩.md)现在可以令其同时发射的3支箭矢全部对同一生物造成有效伤害。

# = 游戏内容 =
* *[击退](击退.md)**
* 击退抗性现在<!--on a scale?-->不再是随机的。

* *[盾牌](盾牌.md)**
* 有效保护范围（扇形区域）的圆心角从180°减至了100°。</onlyinclude>
