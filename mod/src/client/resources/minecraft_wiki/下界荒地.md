* *下界荒地（Nether Wastes）**是一种生成于下界维度的[生物群系](生物群系.md)。

# 描述
下界荒地是一种荒芜的生物群系，主要由[下界岩](下界岩.md)组成。该群系分布着大面积的[熔岩海](熔岩海.md)和少量的[荧石堆](荧石堆.md)，以及[远古残骸](远古残骸.md)、[下界石英矿石](下界石英矿石.md)、[下界金矿石](下界金矿石.md)和[黑石](黑石.md)团簇。熔岩海沿岸还分布着一些[沙砾](沙砾.md)、[灵魂沙](灵魂沙.md)和[岩浆块](岩浆块.md)。

# = 声音 =
当玩家处于下界荒地时，就会开始播放此生物群系的[环境音效](环境音效.md)，还会播放几种通用的[下界音乐](下界音乐.md)，以及“[Rubedo](Minecraft: Nether Update (Original Game Soundtrack)#曲目单.md)”曲目。

# 你知道吗
* 如果主世界生成时使用了下界生物群系，则Y坐标128处会生成基岩层。如果有河流生成在了下界生物群系，则基岩层不会在河流生物群系的上方生成，这使得基岩层存在能够透过阳光的缝隙。下界生物群系的地表完全由石头组成，不会出现任何下界岩或下界矿石。虽然如此，石头层中也不会生成任何矿物或[泥土](泥土.md)、[沙砾](沙砾.md)和[安山岩](安山岩.md)等方块。但洞穴和湖泊（水体呈红色）仍会正常生成。玩家可以正常在主世界当中的下界生物群系里用[水桶](水桶.md)倒水。但尝试在[床](床.md)上睡觉仍会导致爆炸，因为床爆炸的检测判定是生物群系而非维度。
