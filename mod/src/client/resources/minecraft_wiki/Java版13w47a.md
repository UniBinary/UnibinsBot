# Java版13w47a

*页面ID: 33599* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w47a**是[Java版1.7.4](Java版1.7.4.md)的首个快照，发布于2013年11月21日<ref></ref>，在主界面中加入了“广播”选项，加入了一个新的游戏选项，此外，此次更新使用了新的[Mojang](Mojang.md)标志，并修复了一些漏洞。

# 新内容
# = 常规 =
* *广播<ref name="twitch_blog"></ref>**
* 一键在<span class="plainlinks">[Twitch.tv](http://www.twitch.tv/)</span>转播。<ref name="twitch_blog" />
* * 麦克风也可以录制。
* * 在游戏内引进聊天平台。<ref>http://www.youtube.com/watch?v=wPSVJHVL6TA&feature=share&t=6h29m50s (Private video)</ref>
* 多项新的设置。<ref>http://dinnerbone.com/media/uploads/2013-11/screenshots/19_09-34-28_ZU1viVlnmy.png</ref>
* * Twitch广播设置：
* ** 清晰度、帧率、带宽、发送元数据、麦克风音量、系统音量、压缩和（聊天）用户过滤。

* *[选项](选项.md)**
* 在超级秘密设置中加入了“Notch”着色器。

# 更改
# = 常规 =
* *启动界面**
* 游戏启动时将显示新的[Mojang](Mojang.md)标志。

* *[选项](选项.md)**
* 改进了全屏模式（仅限macOS）。

# 修复
</onlyinclude>

# 你知道吗
* 此版本曾经在[启动器](启动器.md)中移除，但在2018年9月重新加入。
* 此版本在发布前一天提供给部分实况主测试新的Twitch直播功能。<ref></ref>
* 该版本的宣传截图中出现了[Grum](Grum.md)的Minecraft皮肤。
