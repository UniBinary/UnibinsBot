# 甜菜根

*页面ID: 11311* | *来源: Minecraft Wiki*

* *甜菜根（Beetroot）**是一种[食物](食物.md)类物品。

# 获取
甜菜根能通过收成完全成熟的甜菜植株来获取，每次掉落/甜菜根，然后系统会尝试进行3次掉落，每次有约）}}或）}}的概率掉落1份甜菜种子（平均掉落份种子），挖掘工具的[时运](时运.md)魔咒每增加1级，尝试次数增加1。甜菜植株可以在[村庄](村庄.md)的农田中发现，或由甜菜种子种植得到。

# 用途
# = 食物 =

手持甜菜根按住键即可食用，每个甜菜根可以回复。

# = 繁殖 =
甜菜根能用来吸引及繁殖[猪](猪.md)。

[村民](村民.md)可以通过拾起至少12个甜菜根来产生繁殖意愿。

# = 合成材料 =

# = 堆肥 =
将甜菜根放入[堆肥桶](堆肥桶.md)中，会有65%的概率增加一层堆肥层。
