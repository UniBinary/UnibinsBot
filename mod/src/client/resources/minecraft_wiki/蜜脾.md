# 蜜脾

*页面ID: 46823* | *来源: Minecraft Wiki*

}}

* *蜜脾（Honeycomb）**是可以从[蜂巢](蜂巢（方块）.md)或[蜂箱](蜂箱.md)中获得的[物品](物品.md)。

# 获取
当蜂巢或蜂箱的<code>honey_level</code>达到5而呈现出蜂蜜纹理时，对其[剪刀](剪刀.md)或触发装有剪刀的[发射器](发射器.md)可以获得3个蜜脾。

# = 箱子战利品 =

# 用途
# = 涂蜡 =
手持蜜脾对着[铜块](铜块.md)、[切制铜块](切制铜块.md)、[切制铜楼梯](切制铜楼梯.md)、[切制铜台阶](切制铜台阶.md)、[雕纹铜块](雕纹铜块.md)、[铜格栅](铜格栅.md)、[铜灯](铜灯.md)、[铜门](铜门.md)、[铜活板门](铜活板门.md)、[避雷针](避雷针.md)、[铜傀儡像](铜傀儡像.md)、[铜灯笼](铜灯笼.md)、[铜链](铜链.md)或[铜栏杆](铜栏杆.md)、[铜箱子](铜箱子.md)或[铜傀儡](铜傀儡.md)按下可消耗一个蜜脾并将其涂蜡，上述方块和生物涂蜡后不再会改变[氧化](氧化.md)状态。朝向以上方块的装有蜜脾的[发射器](发射器.md)被激活时也可将其涂蜡。

手持蜜脾对着[告示牌](告示牌.md)或[悬挂式告示牌](悬挂式告示牌.md)按下可将其涂蜡，并消耗一个蜜脾，涂蜡后的告示牌不再能被编辑文字、染色或改变发亮效果。
