# 锹

*页面ID: 5771* | *来源: Minecraft Wiki*

* *锹（Shovel）**是一种可提高泥土等软质方块采集效率的工具。

# = 锻造 =
下界合金锹可通过在[锻造台](锻造台.md)中升级钻石锹来获得。

# === 合并物品 ===

叠加两把锹的剩余耐久度，再额外获得12%的耐久度，按照铁砧机制保留魔咒。

# = 箱子战利品 =

# = 远古城市 =
[远古城市](远古城市.md)中心的一种地下室房间内会生成一个[熔炉](熔炉.md)，其燃料槽中有一把木锹。

# = 掉落物 =
# == 装备 ==

[僵尸](僵尸.md)和[尸壳](尸壳.md)有0.67%（在困难[难度](难度.md)下是3.33%）的概率在生成时持有铁锹。如果被玩家杀死，它们有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落此铁锹。掉落的铁锹通常是严重损坏的，并且可能附有[魔咒](魔咒.md)：普通难度是0-25%，困难难度是3.125%-25%，根据[区域难度](区域难度.md)变化，魔咒和5-22级的附魔台魔咒相同。

# == 袭击 ==
袭击中生成的[卫道士](卫道士.md)和[掠夺者](掠夺者.md)有4.1%（困难难度下是5.12%）的概率掉落一个严重损坏的铁锹，有时附有随机的魔咒。

# = 交易 =

# = 礼物 =

[工具匠](工具匠.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷石锹。

# 用途
[物品实体](物品实体.md)形式的下界合金锹会漂浮在[熔岩](熔岩.md)上，且不会被[火](火.md)和熔岩摧毁。

# = 挖掘工具 =

锹是一种挖掘工具，每次成功挖掘了任何硬度不为0的方块会消耗1耐久度。

以下方块的合适挖掘工具包含锹：

# = 近战攻击 =
锹每成功进行一次[近战攻击](近战攻击.md)会减少2点耐久度。

# == Java版 ==
锹的攻击速度是1，需要1秒来[恢复](近战攻击#攻击冷却.md)。

# == 基岩版 ==
锹没有攻击冷却。

# = 转化方块 =
对着上方为空气的[草方块](草方块.md)、[泥土](泥土.md)、[砂土](砂土.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)或[缠根泥土](缠根泥土.md)的侧面或顶部锹可使其变为[土径](土径.md)，并消耗1点耐久度。

对点燃的[营火](营火.md)锹可使其熄灭。
