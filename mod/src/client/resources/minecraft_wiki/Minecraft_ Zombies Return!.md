# 概要
波比正担负着重任。混蛋洛根袭击了她的村子，还把她弟弟变成了僵尸。她在与洛根的交战中活了下来，并且会不遗余力地阻止他率领僵尸大军征服主世界的阴谋。但她越是接近这一目标，她就离治好僵尸弟弟的初心越远。

本正担负着……照顾小孩的职责。波比离开后，本就要负责看护她的弟弟约翰尼，并跟上他的训僵尸课程。进展很顺利，约翰尼已经不需要用拴绳拴住，也不怎么想咬人了——除非有谁活该被咬。洛根遗留的藏身之所也开始有点家的感觉了。

然而在大扫除的时候，本发现了洛根的私密日记，里面写满了他所有的极恶阴谋，包括他的下一目标：传奇英雄Pigstep Peggy。他们必须争分夺秒。本能否追寻到波比、阻止洛根的僵尸们再次大快朵颐？Peggy会不会与他们并肩作战？约翰尼能从此戒掉啃食人脑吗？<ref name=MCZombiesR/>
