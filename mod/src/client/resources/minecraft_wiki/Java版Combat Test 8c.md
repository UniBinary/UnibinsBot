# Java版Combat Test 8c

*页面ID: 68330* | *来源: Minecraft Wiki*

}}<onlyinclude>

* *Combat Test 8c**是未来的战斗改版的第9个公开的实验性版本，发布于2020年8月26日<ref></ref>。虽然它是未来版本的测试版，但这个战斗实验版是[Java版1.16.2](Java版1.16.2.md)的分支。此版本只发布在[Reddit](wzh:Reddit.md)上，因此其并不出现在[启动器](启动器.md)版本列表或[Minecraft.net](Minecraft.net.md)的文章中。

# 更改
# = 游戏内容 =
* *[盾牌](盾牌.md)**
* 修复了盾牌的击退计算。
* 现在跳跃时会潜行举盾。
* 带有旗帜的盾牌现在能够抵挡最多近战攻击伤害而非普通盾牌的，且有着更佳的击退抗性，比普通的盾牌更强。
* * 这只是在不加入新物品的情况下测试不同类型盾牌的便捷方式，并不会真正应用于游戏中。</onlyinclude>

# 你知道吗
* 此版本有着与[Combat Test 8](Java版Combat Test 8.md)和[Combat Test 8b](Java版Combat Test 8b.md)相同的协议版本，这意味着它们的客户端和服务器版本彼此兼容。拥有同样协议版本的开发版十分罕见。
