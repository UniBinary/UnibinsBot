# Java版13w41a

*页面ID: 33629* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w41a**是[Java版1.7.2](Java版1.7.2.md)的第10个快照，发布于2013年10月10日<ref></ref>，加入了[染色玻璃](染色玻璃.md)、[染色玻璃板](染色玻璃板.md)以及一条新的[闪烁标语](闪烁标语.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[染色玻璃](染色玻璃.md)**
* [合成](合成.md)方式与[染色陶瓦](染色陶瓦.md)相似，但使用[玻璃](玻璃.md)。

* *[染色玻璃板](染色玻璃板.md)**
* 合成方式与[染色玻璃](染色玻璃.md)相同，但使用[玻璃板](玻璃板.md)。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了“Now contains 32 random daily cats!”，参考自Random_Guy_32的[Twitter](https://twitter.com/Random_Guy_32)。

# 更改
# = 方块 =
* *[铁栏杆](铁栏杆.md)和[玻璃板](玻璃板.md)**
* 现在会互相连接或与[玻璃](玻璃.md)相连接。
* * 现在使用不同的渲染方式，都是2像素厚度。

* *[冰](冰.md)**
* 修复了方块的透明度。
* * 透过冰现在能看见彼此。

* *[上锁的箱子](上锁的箱子.md)**
* 被完全移除，方块数字ID被染色玻璃使用。

* *[水](水.md)**
* 修复了方块的透明度。
* * 透过水现在能看见彼此。

# = 游戏内容 =
* *[下界传送门](下界传送门.md)**
* 修复了透明度。
* * 透过下界传送门现在能看见彼此。

# = 常规 =
* *网络代码**
* 重写了网络代码。<ref></ref>
* * 现在使用[Netty](http://netty.io/)。
* * 大多数数据包不会改变，handshake和ping过程被重做。
* * 拥有一个数据包长度前缀。
* * 协议版本号重置。

* *[服务器列表](服务器列表.md)**
* 重置了[服务器列表](服务器列表.md)。
* * 加入了[服务器](服务器.md)图标。
* * 在鼠标悬浮在玩家数量时会列出目前在线的玩家们。
* * 加入了对多行MOTD（介绍消息）的支持。
* * 移除了MOTD能延伸至屏幕外的支持。

* *[选项](选项.md)**
* 改进了视频[设置](设置.md)界面。
