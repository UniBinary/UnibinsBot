# 海龟鳞甲

*页面ID: 33690* | *来源: Minecraft Wiki*

* *海龟鳞甲（Turtle Scute）**是幼年海龟在成长时掉落的物品，可以用来制作[海龟壳](海龟壳.md)。

# 获取
# = 幼年海龟 =
幼年[海龟](海龟.md)成长为成年海龟时，会掉落一个海龟鳞甲。这是获取该物品的唯一途径。

# 用途
# = 合成材料 =

# = 修复 =
海龟鳞甲可以用来在[铁砧](铁砧.md)上修复[海龟壳](海龟壳.md)。

# 你知道吗
* 鳞甲意指鳞片状的生物板甲，现实中有许多生物都有自己的鳞甲结构，例如鳄鱼表皮上的突起物。对海龟而言便是构成龟壳的大板块。
* 虽然游戏中海龟鳞甲可以合成海龟壳，但在现实中，龟壳本质上是特殊的肋骨结构，且水生龟类脱落的鳞甲并非厚实的板块，而是薄如蛇皮的鳞片薄膜。换言之现实中的[海龟鳞甲](wzh:龟甲.md)薄膜是无法制作海龟壳的。
