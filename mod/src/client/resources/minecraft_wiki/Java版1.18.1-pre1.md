# Java版1.18.1-pre1

*页面ID: 91290* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.18.1-pre1**是[Java版1.18.1](Java版1.18.1.md)的唯一一个预发布版，发布于2021年12月3日<ref name="article_1.18.1-pre1"></ref>，更改了迷雾的表现形式，并修复了一些漏洞。

# 更改
# = 常规 =
* *迷雾**
* 世界迷雾会从离玩家更远的位置上开始显示，以提高远处地形的可见度。
* 现在迷雾以圆柱形范围显示，而不是以前的球形。
