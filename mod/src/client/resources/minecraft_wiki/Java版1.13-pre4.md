# Java版1.13-pre4

*页面ID: 35202* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.13-pre4**是[Java版1.13](Java版1.13.md)的第4个预发布版，发布于2018年6月26日<ref></ref>，修复了一些漏洞。

# 更改
# = 游戏内容 =
* *[生物群系](生物群系.md)**
* 生物群系名称现在按字母顺序罗列在菜单中。

# = 常规 =
* *LWJGL**
* 将[LWJGL](Tutorial:升级LWJGL.md)从版本3.1.2更新到了3.1.6。
