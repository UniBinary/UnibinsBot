# 石头压力板

*页面ID: 164531* | *来源: Minecraft Wiki*

* *石头压力板（Stone Pressure Plate）**是一种可以用来探测[生物](生物.md)的[方块](方块.md)。

# 生成
# = 自然生成 =
石头压力板生成于[沙漠神殿](沙漠神殿.md)和[远古城市](远古城市.md)中。

# = 合成 =

# 破坏
挖掘石头压力板的合适工具是镐。

石头压力板被破坏后会掉落自身。

# 用途
石头压力板必须于[方块支撑形状](方块支撑形状.md)上表面中心完整或边缘完整的方块上方（包括[漏斗](漏斗.md)、[栅栏](栅栏.md)、[侦测器](侦测器.md)等），不能放置于任何方块的侧面与底部。

尝试在无效的表面放置石头压力板会使其“滑入”这块空间内最近的有效附着表面。如尝试在地面上的栅栏侧面放置石头压力板会使其附着到栅栏周围地面方块的顶部。

当石头压力板附着的方块变动（移动、破坏、替代等），不再允许附着时或有[活塞](活塞.md)试图推动它或将方块推入其位置时，石头压力板会掉落为方块物品。

[沙子](沙子.md)或[沙砾](沙砾.md)这类受重力影响的方块正下方为石头压力板时不会开始下落。下落到石头压力板的位置时，它会掉落为方块物品。

# = 红石元件 =

# == 开启 ==
石头压力板只能被[生物](生物.md)开启，不受非生物实体的影响。

石头压力板上方（具体为在石头压力板所在方块的（0.125,0,0.125）到（0.875,0.25,0.875）这个长方体区域内）有[生物](生物.md)时（即使生物的碰撞箱只有一小部分在其中），石头压力板会被**开启**。

石头压力板开启时输出的[信号强度](红石电路#信号强度.md)固定为15。

石头压力板开启后每20游戏刻更新一次状态。

# == 行为 ==
当开启时石头压力板会：
* 激活毗邻的[红石粉](红石粉.md)，四周背对石头压力板的[红石比较器](红石比较器.md)或[红石中继器](红石中继器.md)。
* 强充能石头压力板下方任何[红石导体](红石导体.md)至相应等级。
* 激活毗邻的[机械元件](红石电路#机械元件.md)。

石头压力板没有碰撞箱，不会阻碍实体移动。石头压力板附着的方块能在它下面提供一个固体阻碍（让生物走过，让物体落在上面等等），但石头压力板放置在碰撞箱较小（如栅栏）的方块上时，实体可能在开启石头压力板时穿过石头压力板。因此石头压力板可以用来探测实体而不阻碍它们的运动。

石头压力板关闭时高0.0625个方块（方块的），开启时高0.03125个方块（方块的），但它没有碰撞箱，所以不会影响它上方的实体（如石头压力板上的玩家其实是站在它下面的方块上）。
