# 凋灵玫瑰

*页面ID: 41249* | *来源: Minecraft Wiki*

* *凋灵玫瑰（Wither Rose）**是一种能给予生物[凋零](凋零.md)状态效果的[小型花](小型花.md)。

# 生成
# = 凋灵 =
被[凋灵](凋灵.md)杀死的生物会在其死亡位置放置1株凋灵玫瑰。

# 获取
当任何[生物](生物.md)被[凋灵](凋灵.md)杀死时，如果生成凋灵玫瑰的方块表面不能种植花，或[游戏规则](游戏规则.md)设置为<code>false</code>，那么生成的凋灵玫瑰会变成掉落物。

# 破坏
凋灵玫瑰被挖掘时会立刻被破坏。

凋灵玫瑰被破坏后会掉落自身。

# 用途

与其他花一样，凋灵玫瑰能种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上；除此之外凋灵玫瑰还能种植在[下界岩](下界岩.md)、[灵魂沙](灵魂沙.md)和上。

在非和平难度下，凋灵玫瑰会向所有触碰到它的生物施加[凋零](凋零.md)效果，但凋灵玫瑰[盆栽](盆栽.md)和不会施加凋零效果。在不拥有更长持续时间的凋零效果的情况下，生物每秒会受到两次伤害。

只有[凋灵骷髅](凋灵骷髅.md)可以自然生成在凋灵玫瑰中。只有凋灵骷髅和[僵尸猪灵](僵尸猪灵.md)能在不含雪的凋灵玫瑰中生成。<ref></ref>

# = 蜜蜂 =

蜜蜂对凋灵玫瑰采粉时会获得[凋零](凋零.md)效果。

对蜜蜂凋灵玫瑰会使其获得[凋零](凋零.md)效果，而非繁殖或加速生长。

# = 合成材料 =

# = 谜之炖菜 =

使用凋灵玫瑰合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家7秒的[凋零](凋零.md)效果。

# = 堆肥 =
将凋灵玫瑰放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。

# 你知道吗
* 凋灵玫瑰的英文“Wither Rose”意为凋灵的玫瑰（rose of the Wither）而非凋零的玫瑰（withered rose）。
