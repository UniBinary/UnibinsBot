# 物品耐久

*页面ID: 176* | *来源: Minecraft Wiki*

* *物品耐久（Item durability）**是一部分物品的一项属性，限制了物品的使用次数。

# 监测
[thumb|right|不同耐久度的铁镐](File:Durability bars.png.md)
监测耐久度的基本方式是一个显示在物品栏中叠加在物品图标上的“耐久度条”。满耐久度的物品不会显示耐久度条。

随着物品的使用，耐久度条的有色部分会从右向左逐渐缩短。耐久度条的颜色会从绿逐渐过渡为黄色，然后过渡为红色。最终，耐久度条会变空，表示物品剩下的使用次数已经接近耗尽。

耐久条的颜色为[HSV](wzh:HSL和HSV色彩空间.md)<math>\left( 120^\circ\times\frac{\text{剩余耐久度}}{\text{总耐久度}},~1,~1 \right)</math>。耐久条的总长度为13格，其中有色部分的长度为<math>\text{round}\left( \frac{\text{剩余耐久度}}{\text{总耐久度}}\times13 \right)</math>。

按下[调试组合键](调试屏幕#调试组合键.md)+后，[物品提示框](提示框#物品提示框.md)中会显示准确的剩余耐久度和最大耐久度。

# 机制
适用物品耐久机制的物品具有一项基本属性**最大耐久度（Max durability）**，该基本属性是物品的**剩余耐久度（Durability）**的初始值和最大值。

品质相同的工具具有相同的最大耐久度，盔甲的最大耐久度为槽位基础耐久与**耐久倍率（Durability multiplier）**的乘积。除[马铠](马铠.md)以外，盔甲材料相同的盔甲具有相同的耐久倍率。

多种效果会降低物品的剩余耐久度。通过使用物品将其剩余耐久度彻底耗尽后（剩余耐久度被试图降低到比或低的值时），物品就会损坏，发出响亮的碎裂声，，并从物品栏中消失。
* [鞘翅](鞘翅.md)在耐久度为1时失去其[滑翔](滑翔.md)功能，因此不能通过滑翔将鞘翅的耐久度消耗到1以下。但消耗物品耐久度的[魔咒](魔咒.md)在生效时仍然可以耗尽鞘翅耐久度并将其摧毁。<ref></ref>

在物品的物品数据中，记录的实际上是物品损失的剩余耐久度，即物品的**损坏值（Damage value）**。三者之间的关系为**剩余耐久度=最大耐久度-损坏值**。最大耐久度在一些情况下也被称为**最大损坏值（Max damage）**以表示其实现的行为：损坏值达到或就会摧毁该物品。

物品的最大耐久度和损坏值分别由<code>max_damage</code>和<code>damage</code>[物品堆叠组件](物品堆叠组件.md)定义，但不允许物品既有最大耐久度又有不为1的最大堆叠数量。

生物的天然装备在生成时均是满耐久度，但在掉落时会大幅降低耐久度，甚至可能降至0。

通过[箱子战利品](箱子战利品.md)和[钓鱼](钓鱼.md)，玩家能获取到剩余耐久度不满的物品，其剩余耐久度甚至可能为0。

# 修复耐久度
剩余耐久度的消耗是可逆的，这允许玩家延长它们的带有贵重魔咒的物品的使用寿命，而非在这些物品被损坏后再次制造它们。

# = 物品修复 =

通过[合成](合成.md)或在[砂轮](砂轮.md)中放入两个同种物品，物品可以被合并，其剩余耐久度也会合并，并额外提供5%的剩余耐久度，但物品的所有非诅咒魔咒也会丢失。

通过在[铁砧](铁砧.md)中放入两个同种物品，物品可以被合并，其剩余耐久度也会合并，并额外提供12%的剩余耐久度，但物品的操作数会增加。

通过在[铁砧](铁砧.md)中放入一个物品和其对应的材料，物品可以被修复，每个材料提供25%的剩余耐久度，但物品的操作数会增加。

# = 经验修补 =

物品可以被添加[经验修补](经验修补.md)魔咒。当持有剩余耐久度未满的具有经验修补魔咒的物品时，玩家拾取的[经验球](经验球.md)会被用于修复这些物品而不是提供[经验值](经验值.md)。经验修补提供了可靠且没有副作用的耐久度修复方式，无需承受合并物品或原材料修复的负面效果。

生物被击败后在掉落装备（[武器](武器.md)，[工具](工具.md)或[盔甲](盔甲.md)）时，游戏会重新设置装备的耐久度<!-- 这意味着物品原有的耐久度会被覆盖 -->：先生成一个<math>1</math>至<math>m-3</math>的随机整数<math>k</math>（<math>m</math>为装备的最大耐久），再生成<math>0</math>至<math>k-1</math>的随机整数作为物品的耐久度。其满足以下公式：耐久度不超过<math>x</math>的概率<math>P(x)=\frac{x+\sum_{n=x+1}^{m-3}\frac{x+1}{n}}{m-3} \approx
\frac{x+1}{m-3}\left(1 + \ln\frac{m-3}{x+1}\right) </math><!-- 这意味着物品的耐久度不会是满的 -->，平均耐久为<math>E(x)=\frac{m}{4}-1</math>。以三叉戟和铁质武器为例<!-- 最大耐久=250 -->，<math>P(x)</math>的近似函数<math>\frac{x+1}{m-3}\left(1 + \ln\frac{m-3}{x+1}\right)</math>的图像如右图所示，或者参考[此图表](https://www.desmos.com/calculator/zazlpdrnza)。

生物被击败后在掉落装备（武器，工具或盔甲）时，游戏会重新设置装备的耐久度：最低为25（金质为26），越低的耐久度出现的可能性越高。

# 耐久度消耗
物品的剩余耐久度的消耗会受到[耐久](耐久.md)魔咒的影响：

* 在没有[耐久](耐久.md)魔咒的情况下，每产生1耐久度消耗，都会导致物品的耐久度下降1。
* 对于盔甲以外的物品，如果物品有等级为<math>l</math>的耐久魔咒，每1耐久度消耗导致物品耐久度下降1的概率为<math>\left( \frac{100}{l+1} \right)%</math>。物品的预期寿命延长为原来的<math>\left( l+1\right)</math>倍；对于盔甲物品，如果物品有等级为<math>l</math>的耐久魔咒，则每次消耗1耐久度，导致物品耐久度下降1的概率为<math>\left( 60+\frac{40}{l+1} \right)%</math><!-- ，物品的预期寿命延长为原来的1.25倍/约1.3636倍/约1.4286倍 -->。
* 对于盔甲以外的物品，如果物品有等级为<math>l</math>的耐久魔咒，每一次消耗耐久度时，耐久度被消耗的概率为<math>\left( \frac{100}{l+1} \right)%</math>；对于盔甲物品，如果物品有耐久魔咒，则每次消耗1耐久度，导致耐久度下降1的概率为<math>\left( 60+\frac{40}{l+1} \right)%</math>。

非[玩家](玩家.md)生物拥有的物品的耐久度通常不会下降，但有以下例外：
* 生物在受到[伤害](伤害.md)时盔甲的耐久会正常消耗。
* 亡灵生物在阳光下时，头盔的耐久度会持续下降。
* [弩](弩.md)被生物使用时会损失耐久度，并可以损毁。<ref></ref>
* [荆棘](荆棘.md)魔咒造成的额外耐久消耗仍会生效。

# = 盔甲耐久度 =
[盔甲](盔甲.md)的耐久度消耗取决于盔甲的部位类型（靴子、胸甲、头盔、护腿及动物盔甲）和盔甲材料（皮革、金、铜、锁链、铁、海龟鳞甲、钻石及下界合金）。

在[玩家](玩家.md)承受任何可被盔甲防护的伤害时，玩家穿戴中的盔甲会消耗耐久度，每减免前伤害会消耗每盔甲部件1耐久度（向下取整，但不会低于1）；如果该[伤害类型](伤害#伤害类型.md)穿透护甲值的防护效果，那么盔甲的耐久度不会下降。穿在非[玩家](玩家.md)生物上的盔甲不会因受到[伤害](伤害.md)而失去耐久度。

玩家受到致命伤害时，若未触发[不死图腾](不死图腾.md)，其穿戴的盔甲不会消耗耐久度，无论该伤害是否能被盔甲减免；反之，则盔甲的耐久度按以下机制消耗：若该伤害不能被盔甲减免，则每个盔甲部件都会消耗1耐久度；反之，每个部件都会正常根据减免前伤害大小消耗耐久度。上述情况盔甲都会正常减少耐久度。

如果盔甲有[荆棘](荆棘.md)魔咒，成功通过荆棘魔咒造成伤害还会额外消耗2耐久度。

如果盔甲有[灵魂疾行](灵魂疾行.md)魔咒，每走过1个[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)，都有4%的概率消耗1耐久度。

如果被有伤害的[下落的方块](下落的方块.md)砸中，且受伤害的生物有装备头盔，则伤害减少25%，但每减免伤害会消耗头盔8-13点耐久度，最高可以损失160-260点耐久度，足以瞬间摧毁铁头盔。减少的耐久度为{{only|je|for=-{}-<math>\left\lfloor\max\left\{1,~\frac{\text{原始伤害}}{4}\right\}\right\rfloor</math>}}或{{only|be|for=-{}-<math>\left\lfloor\max\left\{1,~\frac{\text{原始伤害}}{4}\right\}\right\rfloor+\left\lfloor\left(4\sim6\right)\times\text{原始伤害}\right\rfloor</math>}}。

会在阳光下[着火](着火.md)的[亡灵生物](生物#亡灵生物.md)在装备头盔时不会着火，但暴露在阳光下且未与细雪接触时头盔每刻有<math>\frac{11x-8}{-450x+600}</math>概率消耗1耐久度，其中<math>x</math>为[内部天空光照](内部天空光照.md)，且<math>x\in [12,15]</math>。

下界合金盔甲不会在生物受到火焰伤害时产生耐久度消耗。

;
* 成功抵挡伤害时，消耗<span style="color:red">**抵挡的伤害（向上取整）**</span>耐久度。

# = 工具耐久度 =
如果一个物品是一种[挖掘](挖掘.md)工具，在使用该物品成功挖掘了方块后会产生耐久度消耗；对于[镐](镐.md)、[斧](斧.md)、[锹](锹.md)、[锄](锄.md)每次成功挖掘了任何硬度不为0的方块会消耗1耐久度，对于[剑](剑.md)、[三叉戟](三叉戟.md)和[重锤](重锤.md)每次成功挖掘了任何硬度不为0的方块会消耗2耐久度，对于[剪刀](剪刀.md)每次成功挖掘了任何方块会消耗1耐久度。其他物品被用于挖掘时不会消耗耐久度。

如果一个物品是一种能对[近战攻击](近战攻击.md)有影响的物品，在使用该物品进行近战攻击会产生耐久度消耗，对于[剑](剑.md)、[三叉戟](三叉戟.md)和[重锤](重锤.md)会每次消耗1耐久度，对于[镐](镐.md)、[斧](斧.md)、[锹](锹.md)、[锄](锄.md)会每次消耗2耐久度。其他物品被用于近战攻击时不会消耗耐久度。

# = 组件对耐久度的影响 =

部分[物品堆叠组件](物品堆叠组件.md)会影响物品消耗耐久度的行为。
* 具有<code>unbreakable</code>组件、没有<code>max_damage</code>组件或没有<code>damage</code>组件的物品不会消耗耐久。
* 具有组件的装备物品：实体受到指定的[伤害类型](伤害类型.md)时不会消耗耐久。
* 具有<code>glider</code>组件的装备物品：滑翔时每1秒消耗<span style="color:blue">**1**</span>耐久度。
