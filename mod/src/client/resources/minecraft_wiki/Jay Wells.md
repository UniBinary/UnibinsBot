# Jay Wells

*页面ID: 32584* | *来源: Minecraft Wiki*

* *杰伊·韦尔斯（Jay Wells）**是[Mojang Studios](Mojang Studios.md)的社区经理。

# 关于
Jay于2017年9月加入Mojang，担任[Mojira](Mojira.md)社区协调员。负责Mojira漏洞追踪器的管理和内部漏洞报告、撰写开发版本日志，以及其他社区协调工作。

2019年3月，开始担任社区经理。

# 你知道吗
* 在[24w14potato](24w14potato.md)中，马铃薯维度的Boss生物“Mega Spud”名称源自Jay的漏洞追踪器账户名，由其生成的[巨人](巨人.md)形象源自Jay的Minecraft皮肤。
