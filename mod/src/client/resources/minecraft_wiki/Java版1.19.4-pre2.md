# Java版1.19.4-pre2

*页面ID: 102650* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.19.4-pre2**是[Java版1.19.4](Java版1.19.4.md)的第2个预发布版，发布于2023年2月27日<ref></ref>，更新了一些物品的模型并修复了一些漏洞。

# 新内容
# = 常规 =
* *[标签](Java版标签.md)**
* 加入了以下实体标签：
* * ：。
* ** 此处定义的生物会在进入水中时强制其乘客离开。

# 更改
# = 命令格式 =
* ***
* 现在[炽足兽](炽足兽.md)和[烈焰人](烈焰人.md)在通过命令应用冰冻伤害时会有虚弱效果。

* ***
* 现在鸡骑士和蜘蛛骑士可以被子命令视为控制者。

# = 常规 =
* *[创建新的世界](创建新的世界.md)**
* 现在将鼠标指针放在世界名称上时会显示存档文件夹名称。

* *[选项](选项.md)**
* 现在遥测屏幕可以使用箭头按键来滚动。

# 更改（实验性）
# = 方块 =
* *[樱花木门](樱花木门.md)**
* 更改了方块和物品纹理。

* *[樱花树苗](樱花树苗.md)和[粉红色花簇](粉红色花簇.md)**
* 更改了纹理。

* *[饰纹陶罐](饰纹陶罐.md)**
* 更改了颈部的模型。
* * 颈部的模型现在可以切入方块。
* * 现在使用新的更加复杂的模型。

# = 非生物实体 =
* *[樱花木运输船](樱花木运输船.md)**
* 更改了物品纹理。
