# 烟火之星

*页面ID: 9392* | *来源: Minecraft Wiki*

* *烟火之星（Firework Star）**是用来决定[烟花火箭](烟花火箭.md)的色彩与效果的[物品](物品.md)。

# 获取
[创造模式物品栏](创造模式物品栏.md)只提供无颜色、无效果的烟火之星；有16种基础颜色、默认效果的烟火之星。

# 用途
# = 合成材料 =
用烟火之星合成烟花火箭可使其具有绽放效果，并且能造成[爆炸伤害](爆炸伤害.md)。

# 效果
# = 形状效果 =
每个合成[烟花火箭](烟花火箭.md)使用的烟火之星只能有1种形状效果。

# 你知道吗
* 根据描述，可以有2.9×10种不同的烟火之星（如果算上在创造模式的空白烟火则再加1种）和1.9×10种不同的[烟花火箭](烟花火箭.md)（若算上空白的效果则再加3种），但是如果根据视觉效果，只有2.1×10种不同的烟火之星和3.9×10种不同的烟花火箭。
* 使用[钻石](钻石.md)合成的烟火之星必须通过[宝库](宝库.md)战利品才能实现可再生。这是因为[钻石](钻石.md)同样依赖宝库战利品实现可再生，而宝库可以被每个玩家打开无限次数<ref></ref>，且[试炼钥匙](试炼钥匙.md)和[不祥试炼钥匙](不祥试炼钥匙.md)是[可再生资源](可再生资源.md)。
