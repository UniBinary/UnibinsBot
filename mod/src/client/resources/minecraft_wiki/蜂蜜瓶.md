# 蜂蜜瓶

*页面ID: 46828* | *来源: Minecraft Wiki*

* *蜂蜜瓶（Honey Bottle）**是可从蜂巢或蜂箱获得的[食物](食物.md)。

# 获取
对装满蜂蜜（为5）的[蜂巢](蜂巢（方块）.md)或[蜂箱](蜂箱.md)[玻璃瓶](玻璃瓶.md)或触发装有玻璃瓶的[发射器](发射器.md)可以获得1个蜂蜜瓶。

# = 箱子战利品 =

# 用途
# = 食物 =

手持蜂蜜瓶按住键即可食用，每个蜂蜜瓶可以恢复。食用后，该玩家身上的[中毒](中毒.md)效果会被消除。每个蜂蜜瓶被食用后会返还一个[玻璃瓶](玻璃瓶.md)。

玩家在[饥饿值](饥饿值.md)满时也可以食用蜂蜜瓶。

玩家食用一个蜂蜜瓶的时长为，长于其他多数食物的，且还会发出独特的吞咽音效。
