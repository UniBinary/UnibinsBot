# 命令/spawn armor trims

*页面ID: 159468* | *来源: Minecraft Wiki*

]]
}}
生成整齐排列的[盔甲架](盔甲架.md)，用于展示各种[盔甲](盔甲.md)不同锻造原材料时的[盔甲纹饰](盔甲纹饰.md)。

# 语法
   <code>spawn_armor_trims *_lag_my_game</code>
  : 展示所有盔甲纹饰图案。
   <code>spawn_armor_trims <pattern></code>
  : 展示一种盔甲纹饰图案。

# 参数

   指定[盔甲纹饰图案](盔甲纹饰定义格式.md)。
