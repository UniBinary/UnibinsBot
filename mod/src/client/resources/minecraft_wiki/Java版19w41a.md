# Java版19w41a

*页面ID: 48755* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w41a**是[Java版1.15](Java版1.15.md)的第9个快照，发布于2019年10月9日<ref name="article_19w41a"></ref>，加入了新的菜单背景图、两种新的方块、切换[潜行](潜行.md)和[疾跑](疾跑.md)的功能和进行[旁观](旁观.md)的[命令](命令.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[蜂蜜块](蜂蜜块.md)**
* 可使用4个[蜂蜜瓶](蜂蜜瓶.md)合成。
* * 此合成配方不会消耗[玻璃瓶](玻璃瓶.md)（与合成蛋糕时不消耗[铁桶](铁桶.md)相似）。
* 会减慢实体的移动速度，也会降低跳跃高度。
* * 此特性在其上方放置有不完整的方块（如地毯和台阶）时依然有效。
* 站在蜂蜜块上的实体会在该方块被活塞推动时随之一同移动。
* 若玩家撞在由蜂蜜块筑成的竖直墙壁上，则该玩家会在墙面上缓慢下滑。
* 掉落到蜂蜜块上会减少跌落伤害。
* * 跌落伤害会减少至约正常值的：准确值为<code>⌈(跌落高度 - 3) / 5⌉</code>，即在开始的3格后每掉落1格的高度，造成伤害，向上取整。
* 当蜂蜜块被活塞推拉时，与之相邻的方块都将尝试随之往相同方向移动。
* * 与[黏液块](黏液块.md)被活塞推动时的表现相同。
* [生物](生物.md)常常会避免在蜂蜜块上行走。
* 不能被红石信号充能。
* 放置在蜂巢或蜂箱附近时，[蜜蜂](蜜蜂.md)有时会贴在蜂蜜块上以“进食”蜂蜜。
* 碰撞体积略小于正常方块。

* *[蜜脾块](蜜脾块.md)**
* 仅用于装饰。
* 可使用四个[蜜脾](蜜脾.md)合成。

# = 命令格式 =
* ***
* 语法为。
* * <code>target</code> - 将要令玩家进入的旁观视角所属的目标。
* ** 如果省略，使玩家停止旁观。
* * <code>player</code> - 将要旁观的玩家。
* ** 此玩家必须处于旁观模式。
* ** 如果省略，则使用<code>@s</code>。

* *[文本组件](文本组件.md)**
* 加入了<code>copy_to_clipboard</code>动作。

# = 游戏内容 =
* *[控制](控制.md)**
* 和现在可以在设置界面切换“按住”和“锁定”。
* * 允许玩家在切换到其他界面时保持潜行
* * 同样影响在创造模式向下飞行的玩家。锁定后，玩家会保持向下飞行直到解除锁定。

# 更改
# = 方块 =
* *[蜂箱](蜂箱.md)**
* 将蜂箱的英文名Bee hive重命名为Beehive。
* 命名空间ID相应地从更改为。

* *[去皮木头](去皮木头.md)**
* 现在可以使用去皮原木合成。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 更改了蜜蜂刷怪蛋的颜色，从变为。

# = 生物 =
* *常规**
* 生物现在能够更好地躲避[熔岩](熔岩.md)。

* *[末影龙](末影龙.md)**
* 移除了翅膀纹理透明部分中的一个黑点。
* 移除了[爆炸](爆炸.md)时的末影龙翅膀底部的部分纹理。

* *[铁傀儡](铁傀儡.md)**
* 现在会在受到伤害时开裂。
* * 每达到一个受损阶段都会发出受损的音效。
* * 在铁傀儡死亡前会经历从未开裂到完全开裂共4个阶段。
* 现在可以使用[铁锭](铁锭.md)恢复生命值。
* * 每恢复一次都会发出治疗的音效。
* * 每个铁锭恢复。
* ** 4个铁锭可将生命值为的铁傀儡治疗至满生命值。

* *[村民](村民.md)**
* 变成僵尸村民再被治疗恢复后的村民现在不会消失了。

# = 命令格式 =
* ***
* 命令现在会在未给定作用对象时默认作用于<code>@s</code>。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
* [瞬间伤害](瞬间伤害.md)
* *  加入了效果图标。
* [瞬间治疗](瞬间治疗.md)
* *  加入了效果图标。
* [饱和](饱和.md)
* *  加入了效果图标。

# = 常规 =
* *[菜单屏幕](菜单屏幕.md)**
* 对标题界面的背景进行了更改，以展示蜜蜂和蜂巢及其相关物品。
* 在创建世界页面中，按钮下方的描述可以被叙述了。

* *[标签](Java版标签.md)**
* 移除了<code>dirt_like</code>方块标签。
