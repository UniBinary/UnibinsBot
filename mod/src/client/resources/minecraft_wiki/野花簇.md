# 野花簇

*页面ID: 138859* | *来源: Minecraft Wiki*

* *野花簇（Wildflowers）**是一种生成于[桦木森林](桦木森林.md)、[原始桦木森林](原始桦木森林.md)和[草甸](草甸.md)生物群系的装饰性方块。

# 生成
# = 自然生成 =
野花簇会在[桦木森林](桦木森林.md)、[原始桦木森林](原始桦木森林.md)和[草甸](草甸.md)生物群系中自然生成。

# = 人工生成 =
在上述生物群系中对着[草方块](草方块.md)[骨粉](骨粉.md)，有小概率生成野花簇。

# 获取
对着不满4簇花的野花簇骨粉会增加1簇花；对着含有4簇花的野花簇骨粉会掉落1个新的野花簇。

# = 交易 =

# 破坏
野花簇被挖掘时会立刻被破坏。

野花簇被破坏后会掉落自身，掉落个数等于方块内野花簇数。

# 用途
野花簇可以种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。

多个野花簇可以放置在同一格内，这与[海泡菜](海泡菜.md)和[蜡烛](蜡烛.md)类似。最多可以在一个方块空间内放置4簇。

野花簇有4个朝向，其取决于玩家放置时的方向。若一个位置上已有野花簇后，改变方向放置更多野花簇并不会改变其朝向。

野花簇高0.1875（）格，但没有碰撞箱。

# = 合成材料 =

# = 堆肥 =
将野花簇放入[堆肥桶](堆肥桶.md)中有30%的概率增加一层堆肥层。

# = 蜜蜂 =
野花簇可用于吸引、繁殖[蜜蜂](蜜蜂.md)以及加速幼年蜜蜂的成长。蜜蜂也会采集它的花粉。
