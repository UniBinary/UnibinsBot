# Java版13w42b

*页面ID: 33633* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w42b**是[Java版1.7.2](Java版1.7.2.md)的第13个快照，发布于2013年10月18日<ref></ref>，加入了一个新的选项，并修复了[13w42a](13w42a.md)里的漏洞和崩溃。

# 新内容
# = 常规 =
* *[选项](选项.md)**
* “强制使用Unicode字体”按钮被加入到语言选项中。
* * 允许改变Unicode字体是否被强制用于文本上。

# 更改
* *[选项](选项.md)**
* 代码页437字体的前32个字符被替换以支持更多的语言而不需要更换字体。

# 修复
。
