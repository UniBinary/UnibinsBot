# 携带版0.8.0.b2

*页面ID: 31504* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.8.0 alpha build 2**是[v0.8.0 alpha](携带版0.8.0.md)的第2个测试版，也是第一个公开发布的测试版，发布于2013年11月22日，加入了[甜菜根](甜菜根.md)、[甜菜种子](甜菜种子.md)、[甜菜汤](甜菜汤.md)和[矿车](矿车.md)，更改了上个测试版的部分特性，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[甜菜根](甜菜根.md)**
* 一种食物，可回复。
* 不可被食用。
* 用于合成甜菜汤或烧炼成[红色染料](红色染料.md)。
* 无法在[创造模式物品栏](创造模式物品栏.md)中找到。

* *[甜菜种子](甜菜种子.md)**
* 一种种子，用于种植甜菜。
* 在破坏[甜菜根](甜菜根.md)时会掉落1~2个甜菜种子。

* *[甜菜汤](甜菜汤.md)**
* 一种食物，可回复。
* 由4个甜菜根和1个碗合成。
* 无法在[创造模式物品栏](创造模式物品栏.md)中找到。

# = 非生物实体 =
* *[矿车](矿车.md)**
* 一种在[铁轨](铁轨.md)上运行的类似于火车的载具[实体](实体.md)。
* 由5个铁锭合成。

# 更改
# =方块=
* *[煤炭块](煤炭块.md)**
* 移除了使用[下界砖](下界砖.md)的合成配方。

* *[地毯](地毯.md)**
* 为红色地毯添加了合成配方，可由2个红色羊毛合成。

* *[动力铁轨](动力铁轨.md)**
* 为动力铁轨添加了合成配方，可由6个[金锭](金锭.md)、1个[红石粉](红石粉.md)和1个[木棍](木棍.md)合成。

* *[数据更新方块](数据更新方块.md)**
* 更改了纹理，第二个数据更新方块（ate!upd）的纹理被移除，现在使用的是第一个数据更新方块（update!）的纹理。

# = 非生物实体 =
* *[画](画.md)**
* 更改了“Earth”“Water”“Fire”“Wind”四幅画作的纹理。

# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 重新设计了[创造模式物品栏](创造模式物品栏.md)，加入了创造分类（包括建筑方块、装饰性方块、战斗和杂项）。

* *[纹理](纹理.md)**
* 从[Java版](Java版.md)同步了部分纹理。

# = 常规 =
* *图形**
* 远距离时水不透明（仅iOS）。
* Mipmaps（仅iOS）。
* 新的纹理集以及纹理生成脚本。

* *[设置](设置.md)**
* 领域按钮再次被移动到了设置里。
* 移除了平滑光照按钮，现在游戏强制启用平滑光照。
* 移除了可用配方优先按钮，现在合成界面中可用配方强制在最上面。
