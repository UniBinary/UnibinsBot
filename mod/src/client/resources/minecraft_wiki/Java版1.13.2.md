# Java版1.13.2

*页面ID: 36774* | *来源: Minecraft Wiki*

* *1.13.2**是的一次次要更新，发布于2018年10月22日<ref></ref>，优化了多项性能，并修复了一些漏洞。

# 更改
# = 常规 =
* 提升世界加载性能。
* 提升游戏启动性能。
* 提升海龟寻路性能。
* 提升生物生成性能。
* 提升其他各种性能。

# 修复
右击潜影盒时，游戏崩溃。
