# 降雪

*页面ID: 7405* | *来源: Minecraft Wiki*

[缩略图|300px|一幅暴风雪时的山坡景象](File:Snowing.png.md)
* *降雪（Snowfall）**是[Minecraft](Minecraft.md)中偶尔出现的一种[天气](天气.md)。

# 行为
降雪会在[主世界](主世界.md)中[寒冷生物群系](生物群系#温度.md)和部分生物群系的特定[高度](高度.md)替代[降雨](降雨.md)生成。炎热或干燥的生物群系、[虚空](虚空（生物群系）.md)生物群系和其他维度中永远不会下雪。

尽管中NoiseRouter行的T表示当前位置的温度，但用于计算降雪的[温度](温度.md)仅与该位置所在生物群系和高度有关。当Y≤80时，一个位置的温度就是其所在生物群系的基础温度。在Y=81处，温度会通过一个噪声函数在基础温度上随机浮动-0.00875（-）至0.01125（）；然后以此作为基础，任何位于Y≥81区域内的位置每相对于Y=80升高1格，温度就下降0.00125（）。当一个位置的温度小于0.15时，该位置的降雨就会被降雪替代。

和内部分随机区域的基础温度会受另一个噪声函数的影响而被视为0.2，从而改变雪线高度。

平均每场降雪持续0.5-1个[游戏日](昼夜更替#时间换算.md)，两场降雪间隔0.5-7.5个游戏日。降雪有较小的概率变为[雷暴](雷暴.md)。

玩家可以在晚上睡觉来跳过降雪。雷暴发生时，也能在白天睡觉进行跳过。

# 效果
[缩略图|250px|针叶林里的一场降雪](File:Snowfalltundra.png.md)
[thumb|250x250px|基岩版中结霜的针叶林](File:Frostontheleaves.jpg.md)

降雪会使整个世界变暗，导致来自[太阳](太阳.md)的[光照](光照.md)等级降低3，即在白天的亮度等级降为12。但在夜晚亮度等级并没有降低，亮度等级仍然为4。天空会变黑以至看不见天体（即使在不下雪的生物群系里）。<ref></ref>云从白色变为灰色。虽然太阳在雪中不可见，但黎明和黄昏时地平线上的曙光和暮光仍然可见。

在下雪且图像品质为高时，部分生物群系的[树叶](树叶.md)会逐渐结霜。

降雪时，雪会尝试在所有露天的、方块亮度小于10的、上表面完整的[固体方块](固体方块.md)上方积雪。雪可以互相堆积，直至达到或雪。雪的最高堆积高度可由[游戏规则](游戏规则.md)控制。

放置在降雪范围内的[炼药锅](炼药锅.md)会逐渐装满[细雪](细雪.md)。

[快乐恶魂](快乐恶魂.md)在降雪时可以加快恢复[生命值](生命值.md)的速度。

# = 雪花粒子 =
在所有可降雪区域的露天空气中都能够看见下落的雪花[粒子](粒子.md)。不像雨那样，任何[着火](着火.md)的实体与雪接触不会扑灭它们身上的火。由于雪花只掉在一个方块的两条中线上，因此不会看见雪花掉在[玩家](玩家.md)头上。

雪花会穿过非[阻止运动方块](阻止运动方块.md)，如[梯子](梯子.md)、[藤蔓](藤蔓.md)、[地毯](地毯.md)、[红石中继器](红石中继器.md)、[雪](雪.md)、[生物头颅](生物头颅.md)、[花盆](花盆.md)和[蜘蛛网](蜘蛛网.md)。雪花不会穿过阻止运动方块，如[告示牌](告示牌.md)、[旗帜](旗帜.md)、[门](门.md)、[栅栏门](栅栏门.md)、[活板门](活板门.md)、[压力板](压力板.md)、[玻璃板](玻璃板.md)和[铁栏杆](铁栏杆.md)。
