* *切制铜台阶（Cut Copper Slab）**是[切制铜块](切制铜块.md)制作的[台阶](台阶.md)。

# 生成
切制铜台阶、斑驳的切制铜台阶、锈蚀的切制铜台阶、氧化的切制铜台阶、涂蜡的斑驳切制铜台阶、涂蜡的锈蚀切制铜台阶不会生成在世界中，只能通过[氧化](氧化.md)机制生成。

# = 自然生成 =
涂蜡的切制铜台阶会作为[试炼密室](试炼密室.md)决斗室、[宝库](宝库.md)结构的一部分生成。

涂蜡的氧化切制铜台阶会作为试炼密室决斗室的一部分生成。

# 破坏
挖掘切制铜台阶的合适工具是镐。切制铜台阶需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

切制铜台阶被破坏后会掉落自身，双台阶被破坏后会掉落两个组成自身的台阶。

# 用途

# = 氧化 =

切制铜台阶受氧化机制影响，能够在不同变种之间转化。
