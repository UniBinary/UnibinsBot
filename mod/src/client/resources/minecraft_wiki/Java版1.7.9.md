# Java版1.7.9

*页面ID: 31608* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.7.9**是的一次次要更新，发布于2014年4月14日<ref></ref>，修复了更多[Java版1.7.8](Java版1.7.8.md)中有关[皮肤](皮肤.md)的漏洞，此次更新也加快了修改用户名的速度<ref></ref>。此版本不兼容1.7.2到1.7.5的服务端，兼容1.7.6到1.7.8的服务端。

# 更改
# = 常规 =
* *用户名**
* 加快了用户名修改后的转换速度。

* *[皮肤](皮肤.md)**
* 加入对新皮肤系统的支持。
* 放宽了限制条件，所以NPC之类仍然可行。
* [服务器](服务器.md)仍然需要发送具有签名的blob包到[Mojang](Mojang.md)服务器来显示皮肤，但不会再超时，也不会检查“皮肤是否属于该玩家”。
