* *牛（Cow）**是[主世界](主世界.md)中一种常见的友好生物。它们是[皮革](皮革.md)、[生牛肉](生牛肉.md)、[牛排](牛排.md)和[奶桶](奶桶.md)的主要来源。

# 生成
# = 自然生成 =
牛会在[草方块](草方块.md)上至少有2格空间、亮度等级≥7的空间上生成。每只自然生成的牛有5%的概率生成为幼年个体。它们中的大多数都是在第一次生成世界时生成的，但如果已加载[区块](区块.md)里没有友好生物，它们可以在世界生成后的正常生成周期内生成。

尽管在所有生物群系中生成的牛都有对应变种，但它们只会在[平原](平原.md)、[向日葵平原](向日葵平原.md)、[沼泽](沼泽.md)、[风袭丘陵](风袭丘陵.md)、[风袭森林](风袭森林.md)、[风袭沙砾丘陵](风袭沙砾丘陵.md)以及[苍白之园](苍白之园.md)以外的[森林类生物群系](森林类生物群系.md)、[沙漠](沙漠.md)以外的[干旱类生物群系](干旱类生物群系.md)中自然生成。

牛也能生成在[村庄](村庄.md)的牛圈里。

# = 哞菇 =

用[剪刀](剪刀.md)为[哞菇](哞菇.md)剪除蘑菇会使其变成牛。

# 行为
牛会漫无目的地游荡、哞叫，也会躲开足以造成坠落伤害的悬崖、[熔岩](熔岩.md)和[火](火.md)以避免受到伤害。就像其他友好生物一样，牛在受到攻击后会短暂进入受惊状态，四处跑动。

对成年牛铁桶可以挤奶，获得[奶桶](奶桶.md)。

# = 繁殖 =

牛会跟随/手持[小麦](小麦.md)的玩家。

给两只间隔不超过7格的牛喂食小麦会使之进入求爱模式，产下一头[幼年牛](繁殖#幼年生物.md)，并给予玩家。繁殖/后才能再次繁殖。幼年牛需要20分钟长大。使用小麦可以加快幼年牛的生长速度，每次喂食都将会减少幼年牛原来10%的剩余生长时间。繁殖出的幼年牛的变种从双亲的变种中随机选择。

对幼年牛[金蒲公英](金蒲公英.md)可以阻止其成长为成年牛，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年牛无法被喂食除金蒲公英外的其他物品。

# 你知道吗
* 游戏中的温带牛与现实中的[挪威红牛](wikipedia:Norwegian Red.md)相像。
* 寒带牛是基于现实中的[高地牛](wikipedia:Highland cattle.md)制作的。
* 在[PC Gamer演示版](PC Gamer演示版.md)中，牛的身体侧面有“PCG”的标志。
* Notch在Twitter中表示，所有“可繁殖”的友好型动物都表现出两性的特征，并可以在同类之间繁殖。这适用于牛，因为它们有角并且产奶（虽然现实中某些物种的母牛也有牛角）。
* 牛没有立体的乳房。
