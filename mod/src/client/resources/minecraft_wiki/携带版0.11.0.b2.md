# 携带版0.11.0.b2

*页面ID: 28059* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 2**是[v0.11.0 alpha](携带版0.11.0.md)的第2个测试版，发布于2015年4月10日，在菜单中加入了滚动栏，并修复了一些漏洞。

# 新内容
# = 常规 =
* *菜单屏幕**
* 在菜单中加入了滚动栏。

# 修复

* *其他漏洞**
* 打开旧存档时游戏崩溃。
* 狼在杀死目标时仍会保持愤怒状态。
* 被驯服的生物有时候会忘记主人。
* 部分方块的碰撞箱错误。
* 退出游戏后，浮漂不会立即消失。
* 射箭使得游戏崩溃。
* 半空中的箭可以被玩家捡起。</onlyinclude>
