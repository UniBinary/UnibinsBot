# Java版Classic

*页面ID: 6444* | *来源: Minecraft Wiki*

* *Classic**是Minecraft的第二个[开发阶段](版本记录.md)，承接[pre-Classic](Java版pre-Classic.md)，后被[Indev](Java版Indev.md)取代，这也是游戏开发阶段中首个公开部分版本的阶段。该阶段在当时的博客中被统称为“alpha”阶段，直至2010年6月28日的一篇博客才确定其名称。<ref></ref>[创造模式](创造模式.md)和[生存模式](生存模式.md)均在该阶段被引入游戏。

Classic中生存模式的引入是通过一系列名为[生存测试](生存测试.md)的版本完成的，这是该游戏模式非常早期的版本。此测试采用基于点数的系统，玩家可通过杀死游戏中最初的一些[生物](生物.md)来获取点数。即便在Classic被淘汰后，生存测试仍可游玩，直至2010年12月16日，在官方网站的维护中被悄然移除。

Classic不支持当前版本中的诸多主要特性，例如[合成](合成.md)和[物品栏](物品栏.md)。由于从[Indev](Java版Indev.md)到[Beta 1.8](Java版Beta 1.8.md)期间没有“创造”模式，许多玩家继续使用Classic版本来建造在新版本中会耗费大量时间的内容。直到[Beta 1.8](Java版Beta 1.8.md)重新加入创造模式后，Classic版本才成为历史。

# 网站访问
Classic创造模式游戏的最新版本可通过Minecraft官网游玩。在[Infdev](Java版Infdev.md)发布后，该版本不再更新，仅作为历史见证存在。据Notch所言，他计划“缓慢地将其淘汰”，“我不会移除它，而只是隐藏它”。<ref>http://web.archive.org/web/20100702141801/http://www.minecraft.net/</ref>此前，它可在单人模式或多人游戏中游玩。

2011年12月14日，随着[Beta 1.8](Java版Beta 1.8.md)的发布，Mojang移除了Classic的资源路径及保存地址，这可能是移除工作的一部分。结果导致声音无法正常生效，也无法将世界保存在服务器上。没有本地备份的世界均已丢失。

2012年8月8日，Classic版本的网站链接被移除，但在众多玩家的不满声中又重新添加回来。2013年6月1日，由于新启动器已能运行Classic版本，指向Classic的链接再次被移除。尽管此时页面仍可访问，但该页面上的Classic游戏在一段时间内处于停止支持状态。同时，一些主流浏览器增强了默认Java安全设置，导致游戏完全无法游玩，直至2015年9月10日<ref>https://web.archive.org/web/20150910183326/https://minecraft.net/classic/play</ref>至12日<ref>https://web.archive.org/web/20150912132237/https://minecraft.net/classic/play/</ref>期间的某个时间，包含Classic游戏的页面才被彻底移除。

2019年5月7日，为庆祝游戏十周年，基于[Java版Classic 0.0.23a_01](Java版Classic 0.0.23a_01.md)重制的JavaScript版本发布，可通过[classic.minecraft.net](https://classic.minecraft.net)游玩。

# 你知道吗
* 在Classic的文件中，可发现几种生物的信息，这些生物是Classic的生存测试中保留下来的。
* 完整版所使用的玩家皮肤与Classic版本同步，因此付费玩家可在单人游戏和多人游戏中自定义[皮肤](皮肤.md)。
* 在Classic中，玩家运动时手臂会一直前后剧烈摆动。这一特性在Indev中被修改，并在Alpha v1.0.9中被移除，原因是前后不停摆动的手臂及手中的方块会严重阻挡视线。
* Classic版本采用极为老旧的流体物理机制，仅用一个流体方块就可让整个地图被水或熔岩淹没。
* 当生物被加入、首个生存测试版本发布时，玩家可复制部分文件到本地或网页客户端，在Classic多人测试中体验生存内容，或在生存测试中于自定义地图与其他玩家一同游玩。但生物在各客户端的出现位置会有所不同。
* Classic的地图并非无限，而是一个由正常生成的方块构成的立方体，被两层水和基岩（可见31层）包围，且水会从边境流入世界。
* 可通过第三方内存调试器（如Cheat Engine）获取水、熔岩和草方块。
* 环绕地图的海洋会在某个定点停止（正常游戏时无法看见），具体位置取决于渲染距离。
* 0.30版本的文件在未使用区域中间有四种随机的砖块纹理，左下角还包含一个未正确居中的金块纹理。
* 多数情况下，[恶意破坏](Tutorial:防止恶意破坏.md)者会使用无限水源方块来破坏建筑或服务器。
