* *铁门（Iron Door）**是仅可被[红石信号](红石信号.md)开关的[门](门.md)。

# 生成
# = 自然生成 =
铁门会自然生成于[林地府邸](林地府邸.md)的三种监狱房间和。

# 获取
# = 合成 =

# 破坏
挖掘铁门的合适工具是镐。

铁门被破坏后会掉落自身。

# 用途

不同于木门和铜门，铁门只能使用红石信号开启，也不会被僵尸破坏。
