# Java版Beta 1.7

*页面ID: 32728* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.7**是的一次主要更新，发布于2011年6月30日，<ref>https://mcupdate.tumblr.com/post/7080876374/minecraft-beta-17</ref>加入了[活塞](活塞.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[活塞](活塞.md)**
* 加入了活塞和黏性活塞。

# = 物品 =
* *[剪刀](剪刀.md)**
* 一种新工具，可用于获得树叶或从羊身上获取[羊毛](羊毛.md)。

# = 生物 =
* *[蠹虫](蠹虫.md)**
* 加入了纹理（为[Beta 1.8](Java版Beta 1.8.md)做准备）。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 加入了“f”值，范围0-3，用于指明方向。

# 更改
# = 方块 =
* *[圆石](圆石.md)和[红砖块](红砖块.md)**
* 更改了纹理。

* *[蜘蛛网](蜘蛛网.md)**
* 现在需要剪刀或[剑](剑.md)破坏，被破坏时掉落1个[线](线.md)。

* *[栅栏](栅栏.md)**
* 现在能够堆叠至64个。

* *[红石](红石.md)**
* 红石线现在会连接到[红石中继器](红石中继器.md)。

* *[台阶](台阶.md)**
* 现在使用完整方块的下半部分纹理。

* *[TNT](TNT.md)**
* 现在需要[打火石](打火石.md)或[红石](红石.md)激活。

# = 生物 =
* *[羊](羊.md)**
* 现在被玩家攻击不再直接掉落羊毛，死亡时仍会掉落。

* *[鱿鱼](鱿鱼.md)**
* 现在可以消失。

# = 常规 =
* *[纹理包](纹理包.md)**
* 破坏方块动画的灰色的碎裂纹理已被不透明度替代。
* 床和蛋糕的侧面纹理被移到新的纹理包文件。

# 修复
* *修复了2个漏洞**
* 修复了黏土生成的问题。
* 鱿鱼现在会消失了。</onlyinclude>
