# Java版1.16-pre5

*页面ID: 64232* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.16-pre5**是[Java版1.16](Java版1.16.md)的第5个预发布版，发布于2020年6月12日<ref></ref>，为“极佳！”画质加入了警告消息，并修复了一些漏洞。

# 新内容
# = 常规 =

[thumb|“*极佳！*”画质的警告消息](File:Fabulous setting warning for OpenGL 2.1 on macOS.png.md)
* *[选项](选项.md)**
* 为“*极佳！*”画质加入了警告消息。
* * 该消息会在检测到玩家的图形设备将在此画质下产生渲染问题时，或在检测到其设备本身存在问题时出现。
* * 受影响的设备列表可通过使用[资源包](资源包.md)修改。

# 更改
# = 方块 =
* *[水](水.md)**
* 稍微调暗了水面纹理。

# = 常规 =
* *[选项](选项.md)**
* 移除了“流畅”和“高品质”图形选项描述中的引号。
* 图形选项描述中的“极佳！”现在显示为斜体文字“*极佳！*”。

* *创建世界**
* 将[游戏规则](游戏规则.md)和的描述由“控制是否掉落资源，包括经验球”改为“控制<生物死亡/破坏方块>后是否掉落资源，包括经验球”。
