# 空气

*页面ID: 458* | *来源: Minecraft Wiki*

}}
* *空气（Air）**是用来表示其所在的空间未被占用的方块和物品。

* *洞穴空气（Cave air）**是[结构](结构.md)内的地下的空气，生成于[洞穴](洞穴.md)中。

* *虚空空气（Void air）**是内部用于建造区域外的方块位置的空气。

# 生成
空气存在于任何未被[方块](方块.md)占用的空间里。

虚空空气存在于任何不属于可建造区域的空间里，包括未加载的区块、高于或低于建造高度的区域，例如[虚空](虚空.md)中。受限于存档保存，游戏并不会真正在这些区域生成虚空空气，仅仅是当游戏需要使用这些区域的方块时认为这些方块是虚空空气。

# = 自然生成 =
许多[结构](结构.md)都包含空气，在生成时将其他方块替换为空气。

地上结构生成普通空气（除了暴露在[恶地](恶地.md)里的[废弃矿井](废弃矿井.md)和地表的[湖泊](湖泊.md)，它们会生成洞穴空气<ref></ref><ref></ref>），地下结构生成洞穴空气。

# 获取
空气物品存在于任何未被[物品](物品.md)占用的物品槽位里。

一些[战利品表](战利品表.md)中包含空气，使其在一次生成尝试中生成空气，即不生成任何物品。

# 破坏
空气没有[轮廓箱](轮廓箱.md)，因此不能挖掘空气。

[虚空](虚空.md)中的空气不能被破坏，尝试破坏只会使这些方块留在原处而不被改变。

空气被破坏后不会掉落。

# 用途
# = 空气方块 =
空气（左一）以及游戏中的其他隐形方块被渲染出的立方体框外观}}

空气被用于表示没有方块存在的位置。通过或来放置空气，可以移除其他的方块。

空气和非固体方块享有着一些类似的属性，包括在玩家或生物移动中不会受到[窒息](伤害#窒息.md)伤害。玩家或生物在受[溺水](伤害#溺水.md)伤害时也在水中有空气的地方得到呼吸。

空气是一种“隐形方块”，处于开启了“显示隐形方块”的存储模式[结构方块](结构方块.md)的存储区域范围内的空气会显示出一个淡蓝色的立方体框，空气的种类不会影响渲染外观。

# = 空气物品 =
[缩略图|250px|在[[代码连接](File:Air Item on MakeCode.png.md)和[基岩版编辑器](基岩版编辑器.md)展现的空气的图标，然而在游戏内不能以此纹理显示，即使已在代码连接中编写了有关代码]]

空气物品用于表示没有物品存在的位置。玩家并不能像对其他物品那样对空气物品进行操作，如对其在[物品栏](物品栏.md)进行转移或放置它。空气物品被选中时不会在[HUD](HUD.md)显示其名称。

使用命令可以替换某个物品槽位的物品为空气，這將移除该位置的其他物品。

尝试通过读取一个没有物品的物品槽位会读取到一个空气物品。

可以利用命令“给予”玩家一个空气物品，但除了显示一条成功的返回信息以外不会有任何效果。<ref>命令中可用|WAI}}</ref>
