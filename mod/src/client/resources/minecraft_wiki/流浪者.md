* *|流浪者}}（Stray）**是生成在有雪的[生物群系](生物群系.md)的[骷髅](骷髅.md)变种。

# 生成
# = 自然生成 =
流浪者会在[雪原](雪原.md)和[冰刺之地](冰刺之地.md)中以80%的概率取代露天的骷髅生成。

流浪者会在[雪原](雪原.md)、[冰刺之地](冰刺之地.md)、[冻河](冻河.md)、[冻洋](冻洋.md)、[冰冻深海](冰冻深海.md)、[冰封山峰](冰封山峰.md)、[尖峭山峰](尖峭山峰.md)、[积雪山坡](积雪山坡.md)中生成，上述生物群系不会生成骷髅。在[冻洋](冻洋.md)中流浪者可在高度为60-66之间的地面上生成。

[蜘蛛](蜘蛛.md)和[洞穴蜘蛛](洞穴蜘蛛.md)在上述生物群系生成时有0.8%的概率生成为[流浪者蜘蛛骑士](蜘蛛骑士.md)。

流浪者不会由[刷怪笼](刷怪笼.md)自然生成。

# = 试炼刷怪笼 =
[试炼密室](试炼密室.md)中的远程型[试炼刷怪笼](试炼刷怪笼.md)包含流浪者试炼刷怪笼。

# = 转化 =
[thumb|180px|right|一只陷入细雪的骷髅转化为流浪者](File:Skeleton become Stray.gif.md)

[骷髅](骷髅.md)处于[细雪](细雪.md)中后会开始转化为流浪者，再经转化完成。转化成流浪者后，其生命值会回满，且其原本携带的装备和武器不会消失。

[凋灵骷髅](凋灵骷髅.md)、[沼骸](沼骸.md)和[焦骸](焦骸.md)不会转化为流浪者。

# = 万圣节 =

在[万圣夜](wzh:万圣夜.md)（10月31日）当天，流浪者在生成时有22.5%的概率戴着[雕刻南瓜](雕刻南瓜.md)，2.5%的概率戴着[南瓜灯](南瓜灯.md)，但雕刻南瓜或南瓜灯不会掉落。<ref></ref>

# 行为

流浪者的行为与[骷髅](骷髅.md)大致相同，不同的是，流浪者会发射延长版迟缓之箭或带缓慢效果的箭，会对其击中的目标造成30秒[缓慢](缓慢.md)I。流浪者在水下进行攻击时不会射箭，但其使用的近战攻击仍会对目标施加10秒的缓慢效果。

不同于绝大多数生物，流浪者免疫[细雪](细雪.md)的冰冻伤害。

与大多数亡灵生物一样，流浪者在[游戏规则](游戏规则.md)设置为时能够拾起物品，并且拾起物品后的流浪者不再会自然消失。

被流浪者杀死的[苦力怕](苦力怕.md)会额外掉落一张*[13](13.md)*、*[cat](音乐唱片cat.md)*、*[blocks](blocks.md)*、*[chirp](chirp.md)*、*[far](far.md)*、*[mall](mall.md)*、*[mellohi](mellohi.md)*、*[stal](stal.md)*、*[strad](strad.md)*、*[ward](ward.md)*、*[11](11.md)*或*[wait](wait.md)*[音乐唱片](音乐唱片.md)。

# = 生物族群 =

流浪者是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉到水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

流浪者会在阳光下[着火](着火.md)，未戴头盔或生物头颅的流浪者会寻找阴凉处、水域以及来避免着火。与[僵尸](僵尸.md)不同，流浪者不会为了攻击玩家而离开阴影区域，而非像僵尸那样在看见玩家后会不顾一切地追逐。但流浪者有时会因为自己盘旋目标的攻击方式而移动到阳光下。

# 你知道吗
* 根据Jeb所说的话，流浪者的概念源于Bellevue团队举行的一场Game jam。[Jason Major](Jason Major.md)制作出了一堆很酷的[生物](生物.md)，他认为流浪者非常适合他们正在计划加入的新生物。<ref name="minecraft.net-meet-stray" />
* 流浪者的纹理上显示其戴有一条冰项链，但是流浪者并不会掉落与[冰](冰.md)相关的物品。
* 流浪者只会用弓不会用弩，这一点与[骷髅](骷髅.md)和[凋灵骷髅](凋灵骷髅.md)一样。
* 流浪者可以射出时长30秒的迟缓之箭，但其掉落物却是时长11秒的迟缓之箭。
