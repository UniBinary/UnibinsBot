# Java版13w02a

*页面ID: 33406* | *来源: Minecraft Wiki*

</ref>
* 挖掘空的唱片机会在原位置掉落一个不可见的[物品实体](物品实体.md)，拾取该物品实体将导致游戏崩溃，并可能删除唱片机所在的区块。<ref></ref>}}

* *13w02a**是[Java版1.5](Java版1.5.md)的第3个快照，发布于2013年1月10日<ref></ref>，加入了动力铁轨和一些由下界石英合成的建筑方块，以及TNT矿车，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[激活铁轨](激活铁轨.md)**
* 用于触发[TNT矿车](TNT矿车.md)。
* 需要[红石粉](红石粉.md)充能激活。
* 激活后最多能传递8格红石信号。

* *[石英块](石英块.md)、[雕纹石英块](雕纹石英块.md)、[石英柱](石英柱.md)、[石英楼梯](石英楼梯.md)和[石英台阶](石英台阶.md)**
* 新的建筑方块。

# = 非生物实体 =
* *[TNT矿车](TNT矿车.md)**
* 可用[激活铁轨](激活铁轨.md)触发。
* 制作配方是一个[矿车](矿车.md)并在顶部放置[TNT](TNT.md)（允许2×2的合成方式）。
* 它脱轨时会忽略平时的爆炸延时，立即爆炸。
* 其速度越快，爆炸得越猛烈。
* 在创造模式下，TNT矿车在移动中被左键单击会爆炸。

# = 游戏内容 =
* *死亡消息**
* 改进死亡消息——现在包括死亡原因，死亡的玩家在战斗时被物品杀死的物品名称：
* * *玩家*从梯子上摔了下来
* * *玩家*从藤蔓上摔了下来
* * *玩家*从水面跌出
* * *玩家*从高处摔了下来
* * *玩家*浴火焚身
* * *玩家*被仙人掌戳死了
* * *玩家*被*玩家/生物*使用*武器*结束了性命
* * *玩家*在与*玩家/生物*战斗时浴火焚身
* * *玩家*在与*玩家/生物*战斗时被烤焦了
* * *玩家*逃离*玩家/生物*时尝试在熔岩里游泳
* * *玩家*逃离*玩家/生物*时被仙人掌戳死了
* * *玩家*被*玩家/生物*使用*武器*杀害
* * *玩家*尝试伤害*玩家/生物*时被杀
* 由摔落伤害产生的死亡消息现在会通过一个能够产生352种（在en_US.lang中为416种）不同死亡消息的系统来显示。

# 更改
# = 方块 =
* *[铁砧](铁砧.md)**
* 改进了铁砧对容器和[刷怪蛋](刷怪蛋.md)的重命名机制。
* * 重命名的箱子、陷阱箱、发射器、熔炉、酿造台和附魔台会在GUI左上角显示它们的新名称。

* *[漏斗](漏斗.md)**
* 改进了[漏斗](漏斗.md)。
* * 漏斗在接收到红石信号时停止泄漏。
* * 加入了一个正确的图标。
* * 不再认为是木质方块（例如不能作为熔炉燃料使用）。
* * 合成配方从石头改为铁锭。
* * 当一个红石比较器直接放置并连接红石时，状态改变后红石会发出信号。
* ** 1个物品会给予1个信号强度，个堆叠物品（最大堆叠数为64时为21）交给予2个信号强度。
* ** 完全堆叠×3 = 信号强度。
* ** 例如：2个完全堆叠物品/方块会给予6个信号强度，而2个药水也会给予同样的信号强度（因为药水不可堆叠）。

* *[熔岩](熔岩.md)**
* 更改了纹理。

* *[红石比较器](红石比较器.md)**
* 更改了纹理。
* 当用容器连接时，只要容器中有1个物品，它们就会立即发出信号，从而允许空容器检测。

* *[台阶](台阶.md)**
* 以前未使用的台阶（被许多人称为“平滑石台阶”）从游戏中移除。
* 它的数据值被下界砖台阶和石英台阶使用。

* *[陷阱箱](陷阱箱.md)**
* 现在位于创造模式的装饰分类中。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 改进了重命名。
* * 从重命名的蛋中生成的生物会拥有蛋的名称并在[死亡消息](死亡消息.md)中出现。
* * 通过[NBT标签](NBT标签.md)，生物能以名片的形式显示它们的名字。

# = 生物 =
* *[骷髅](骷髅.md)**
* 射击距离从10米增加至了15米。
* 精准度取决于[难度](难度.md)。

# = 世界生成 =
* *[废弃矿井](废弃矿井.md)**
* 原有的[箱子](箱子.md)现在被[运输矿车](运输矿车.md)代替。

# = 游戏内容 =
* *[语言](语言.md)文件**
* 更新语言文件。
* * 语言文件现在可以通过后台下载器进行更新（不需要新的Minecraft版本）。

* *[纹理包](纹理包.md)**
* 改进了[纹理包](纹理包.md)。
* * 纹理现在每个方块/物品共同使用一个文件，在运行时合在一起 - 纹理大小不需要一致。
* * 任何方块和物品纹理都可以通过在正确的图片的每一帧的下面放置另外一帧做成动态纹理——使用可选的.txt指定帧顺序和持续时间。
* * 水、熔岩、指南针和时钟有特殊的规定。
* * 已存在的纹理包将**自动**被转换。
* * 如果纹理文件有缺失的话游戏将使用原版的纹理。
* * 查看[纹理包](纹理包.md)来获得更多信息。
