# 火矢

*页面ID: 36315* | *来源: Minecraft Wiki*

* *火矢（Flame）**是一种用于[弓](弓.md)的[魔咒](魔咒.md)，可以使射出的箭着火。

# 获取

# 用途

此魔咒被附魔在弓上时，可以其使射出的箭着火。着火的箭击中生物后，会使该生物着火100游戏刻（5秒），可被附有[火焰保护](火焰保护.md)魔咒的盔甲降低对着火时间最低值的设置。同时，着火的箭可使其撞击到的TNT被点燃，摧毁其穿过的细雪，还可使被熄灭的[营火](营火.md)被点燃。
