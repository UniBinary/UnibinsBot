# 涡流盔甲纹饰

*页面ID: 157529* | *来源: Minecraft Wiki*

* *涡流盔甲纹饰（Flow Armor Trim）**是一种[盔甲纹饰锻造模板](盔甲纹饰锻造模板.md)，可使用[旋风棒](旋风棒.md)复制自身。

# 获取
# = 箱子战利品 =

# = 合成 =
尽管锻造模板本身不能合成获得，但可以利用特定的合成配方来复制自身。

# 用途
涡流盔甲纹饰可在锻造台上与[盔甲](盔甲.md)和锻造原材料相结合，给盔甲添加纹饰。
