* *Minecraft：携带版（*Minecraft: Pocket Edition*）**是由[Mojang Studios](Mojang Studios.md)开发的[Minecraft](Minecraft.md)移动版。该版本最初于2011年8月16日以6.99美元的价格登陆Google Play，为[Xperia PLAY](wzh:Sony Ericsson Xperia Play.md)独占版本<ref>https://play.google.com/details?id=com.mojang.minecraftpe</ref>，后于2011年11月17日扩展至其他[Android](wzh:Android.md)设备<ref></ref>。适用于[iOS](wzh:iOS.md)的携带版同样在2011年11月17日于Apple App Store发布。<ref>http://appleinformer.org/2011/11/minecraft-pocket-edition-for-ios-now-available-for-download/</ref>

2012年9月13日，携带版登陆亚马逊Appstore；2014年4月2日，支持Fire TV控制器的携带版Amazon Fire TV版发布<ref>http://mashable.com/2014/04/02/amazon-fire-tv-2/</ref>。2013年10月21日之前，无法保存地图且版本锁定在v0.2.1 alpha的演示版本可供下载。2014年12月10日，携带版[Windows Phone](wzh:Windows Phone.md)版在Windows Store上线<ref>http://www.windowscentral.com/minecraft-pocket-edition-comes-windows-phone?utm_source=wpc&utm_medium=twitter</ref>，其中[携带版1.0](携带版1.0.md)及后续版本仅支持Windows 10 Mobile及以上设备。

此后，携带版陆续推出4个移植版本，分别对应[Windows 10](wikipedia:Windows 10.md)（即[Windows 10版](Windows 10版.md)）、[Samsung Gear VR](wikipedia:Samsung Gear VR.md)（即[Gear VR版](Gear VR版.md)）、[Apple TV](wikipedia:Apple TV.md)（即[Apple TV版](Apple TV版.md)）和[Amazon Fire TV](wikipedia:Amazon Fire TV.md)（即[Fire TV版](Fire TV版.md)）。<ref>https://mojang.com/2015/07/announcing-minecraft-windows-10-edition-beta/</ref><ref>https://www3.oculus.com/en-us/blog/minecraft-now-available-on-oculus-for-gear-vr/</ref><ref>https://minecraft.net/en/article/apple-tv-edition-released</ref><ref>https://www.amazon.com/gp/product/B01NCJDPER/</ref>

# 游戏内容
携带版的游戏目标与发展较快的[Java版](Java版.md)、[原主机版](原主机版.md)一致，玩家均可在沙盒式环境中构建虚拟世界。和其他版本一样，携带版也包含在其他版本中出现的[生存](生存.md)内容，例如[酿造](酿造.md)、[饥饿](饥饿.md)机制，以及[下界](下界.md)和[末地](末地.md)维度。多人游戏支持跨平台进行，玩家可在任何能运行携带版的触摸设备上游玩。<ref>http://mojang.com/2011/11/minecraft-pocket-edition-on-ios/</ref>

[HUD](HUD.md)及其他元素均适配移动设备的标准游戏内容。玩家可通过触屏进行交互（iOS和Android版本的携带版游戏内容相同<ref></ref>）。由于触屏操作的局限性，部分特性进行了调整：例如，[合成](合成.md)系统采用[MATTIS](MATTIS.md)系统，丢弃物品需长按物品栏中的物品图标；为提升移动设备屏幕的可见性，被对准的方块会整体高亮，而非仅高亮轮廓。与移动设备的合成菜单不同，Windows 10版的合成菜单与Java版及主机版类似。

携带版发布初期的画面与Minecraft [Alpha](Java版Alpha.md)版相近（如鲜绿色草方块、旧纹理圆石等），但在v0.8.0 alpha版本中，画面质量与Java版持平甚至更优，还会根据[太阳](太阳.md)位置调整亮度和底纹。

携带版与Java版的差异如下：
* 许多[生物](生物.md)的特性与Java版不同，详见下文“生物”段落。
* 支持4种多人游戏方式：
* * 通过无线局域网，最多支持5人共同游玩。
* * 通过[Pocket Realms](Realms.md)，该功能在[v0.7.6 alpha](携带版0.7.6.md)关闭，于[v0.15.0 alpha](携带版0.15.0.md)重新启用。
* * 通过玩家创建的远程服务器，服务器软件列表可参考[此处](携带版服务器软件.md)。
* * 通过Xbox Live。

# = 差异 =

携带版与Java版在诸多方面存在差异，例如拥有更多震动效果、经过修改的地形及独有物品。开发团队已证实，一旦携带版追上Java版的进度，便会开启差异化开发。<ref>http://www.twitch.tv/jbernhardsson/b/519822083</ref>

# = 发布 =
Twitter上曾发布过一段早期游戏蓝本在Xperia PLAY上运行的视频。2011年10月7日，Alpha版本正式发布，且不再为Xperia PLAY独占。该非独占版本原计划于9月29日在Android平台上线<ref></ref>，但因需修复部分严重漏洞，发布日期推迟至10月7日。

在Mojang的一次采访中，iOS版本曾被确认将于2012年之前发布<ref>http://www.unboundgamer.com/_/minecraft-pocket-edition-interview-with-mojang-r393</ref>，随后该版本于2011年11月17日正式推出。

# = Alpha =

[200px|右|缩略图|v0.7.1 alpha前一直沿用的logo](File:Pocket Edition art logo 1.png.md)

在iOS和Android平台上，携带版的各项特性保持一致。Alpha阶段，该版本持续新增多种特性，包括[合成](合成.md)、[冶炼](冶炼.md)、更多[方块](方块.md)、[物品](物品.md)、[生物](生物.md)及游戏模式等，逐步向[Java版](Java版.md)靠拢。由于携带版与Java版的开发团队协作紧密，Java版新增的方块往往会同步在携带版中推出。

# = 正式版本 =
2016年11月11日，[携带版1.0](携带版1.0.md)（即[末影更新](末影更新.md)）的首个开发版发布；2016年12月19日，该正式版正式推出。

# = 快照 =
自2013年11月22日起<ref>https://mojang.com/2013/11/android-beta-program-for-minecraft-pe/</ref>，[Mojang](Mojang.md)开始向加入测试组的用户公开发布测试版及所有更新。发布预览版的目的是收集反馈（尤其是漏洞报告），以提升正式版的稳定性。

在v0.8.0 alpha至v0.12.1 alpha期间，用户需加入[Google+小组](https://play.google.com/apps/testing/com.mojang.minecraftpe)获取开发版，之后可像接收普通更新一样在应用商店中查看开发版更新。2015年7月17日，该Google+小组因垃圾信息和广告问题被移除。<ref></ref><ref></ref><ref></ref>

2015年11月3日，PE Beta团队推出了[专用博客](http://pocketbeta.minecraft.net)<ref></ref>，该博客随后专门用于帮助用户加入0.13.0测试组，并展示开发版的更新日志。

# 销量
2013年12月，携带版的销量达到1650万份，同期Java版销量为1300万份。这些数据是在v0.8.0 alpha发布后统计得出的。<ref>http://www.theguardian.com/technology/2013/dec/17/mojang-minecraft-pocket-edition-apple</ref>

2016年12月2日，[Marsh Davies](Marsh Davies.md)称携带版的销量已突破4000万份（当时Java版的销量超过2400万份）。<ref>https://minecraft.net/en/article/pocket-edition-5-years-old</ref>

该版本常年位居App Store和Google Play付费榜前十，有时还会攀升至榜首。<ref>http://www.apple.com/itunes/charts/paid-apps/</ref><ref>https://play.google.com/store/apps/collection/topselling_paid?hl=en</ref>

# 游戏控制

# = iOS和其他 =
向前移动时，屏幕上会出现两个按钮。跳跃按钮位于右下角，潜行按钮在D-pad中央，双击该按钮可进入潜行状态。跳跃按钮和潜行按钮的位置可在选项菜单的控制部分互换。移动时若面前有1格高的方块，玩家会自动跳上去，此功能也可在选项菜单的控制部分禁用。

点击屏幕可放置方块；破坏方块的操作与Java版类似，需点击并按住方块而非点击鼠标。分离控制模式同样可用，开启后屏幕中央会出现十字准星，便于像Java版那样放置和破坏方块。

切换第三人称视角的操作：进入选项>游戏，移动对应滑块即可。点击省略号可打开物品栏；长按物品栏中的物品或方块会将其丢弃，若快捷栏中是一组物品，长按会丢弃全部。除在容器（如箱子、熔炉等）中操作外，无法将一组物品拆分。

# = 平板选项 =
平板设备可开启分离触控选项，以适配大屏幕操作。开启后，屏幕会显示十字线，右半部分屏幕可用于移动视角。

除屏幕尺寸不同（允许显示更多物品栏）外，平板版本与其他版本无实质区别，且支持与其他设备跨平台联机游玩。

# = Windows 10版本 =
Windows 10版本包含3个控制区域：

* **键盘**：操作方式与Java版类似，但并非所有按键功能都具备，且按键功能不可更改。
* **触摸屏**：可使用Windows 10电脑的触摸屏进行操作，控制方式与携带版类似。
* **控制器**：支持与设备兼容的控制器，按钮布局与[主机版控制](控制#原主机版.md)相近，且控制器按键可自定义。

# 系统要求

部分设备经认定可正常运行游戏，无论是否有定制ROM、内核或可[超频](wikipedia:Overclocking.md)的CPU。但CPU“[MSM7227](wikipedia:MSM7000#MSM7x27.md)”因浮点运算能力较弱，无法运行该游戏。<ref>[wikipedia:MSM7000#MSM7227](wikipedia:MSM7000#MSM7227.md)</ref>

# 你知道吗
* 游戏发布前的演示视频中已出现平滑光照功能，但因在多种设备上出现错误而被移除。v0.7.0 alpha中，平滑光照默认开启；从v0.8.0 alpha开始，该功能无法关闭。
* 应用程序文件系统中的terrain.png文件与Java版几乎完全一致，包含携带版尚未加入的内容（如[命令方块](命令方块.md)）。但在v0.8.0 alpha中，该文件被简化版的terrain-atlas.tga替代。
* Java版平均放置/破坏方块的范围为4-6，而iOS/Android版本为6-9。
* 由于自动跳跃功能，打开暂停菜单时若同时打开背包，玩家会像跳跃或游泳一样进入“自动行驶”状态，可在不使用任何命令的情况下跳跃、行走和/或游泳，关闭暂停菜单或背包后该状态结束。
* 携带版中，[凋灵](凋灵.md)比[末影龙](末影龙.md)更早加入（前者于[v0.16.0 alpha](携带版0.16.0.md)加入，后者于[1.0.0](携带版1.0.0.md)加入）。
