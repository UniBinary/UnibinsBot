# 定义行为
对话框定义数据仅在服务端启动时被加载一次，使用命令不可以使对话框定义被重新加载，而必须重启服务端。

对话框是一种简单的为玩家提供交互界面的方法。它可以向玩家展示固定信息，也允许玩家触发相应事件，或输入并提交数据以触发服务端行为。

# = 调用 =
对话框可以通过命令直接调用，也可以通过文本组件、服务端信息或其他对话框等间接调用。游戏也允许通过[暂停屏幕](暂停屏幕.md)或[快捷键](快捷键.md)直接进入对话框，分别由<code>minecraft</code>命名空间下的两个特殊的对话框标签控制：<code>#pause_screen_additions</code>和<code>#quick_actions</code>。

在暂停屏幕中，游戏会检查当前的对话框数据和服务端链接数据，确认是否需要替换“”和“”按钮。如果需要替换，则“”按钮将被替换为“”按钮，“”按钮将被替换为“”按钮，此时点击“”按钮会打开“”屏幕并显示按钮和按钮。以下是具体的替换行为：
* 如果<code>#pause_screen_additions</code>标签内有且仅有一个注册项，此对话框的显示名称将替换“”按钮文本，此时点击这个按钮将直接打开此对话框。
* 如果<code>#pause_screen_additions</code>标签内有多个注册项，点击按钮将打开<code>custom_options</code>对话框，这个对话框将为所有具有<code>#pause_screen_additions</code>标签的对话框分别显示一个跳转按钮。
* 如果<code>#pause_screen_additions</code>标签内没有注册项，但服务端具有服务端链接数据（由<code>server_links</code>网络数据包发送），游戏将使用<code>server_links</code>对话框数据替换按钮。
* 如果上述条件均不满足，则不替换按钮。
此外，<code>#quick_actions</code>标签内的注册项可以通过快捷键（“”，默认为）打开。如果存在多个注册项，按下快捷键将打开对话框<code>quick_actions</code>，这个对话框将为所有具有<code>#quick_actions</code>标签的对话框分别显示一个跳转按钮。

# = 元素 =
对话框分为**框头（Header）**、**内容（Content）**和**框尾（Footer）**三部分，元素全部居中对齐。

框头高33像素，具有标题文本和警告按钮两个元素，两者间隔10像素。如果窗口宽度不足以显示警告按钮，游戏会自动调整警告按钮位置以确保此按钮可见。

内容高度为窗口高度减去框头和框尾的高度。如果内容部分元素总高度大于内容区域高度，则会创建滚动条以滚动显示。内容分为主体元素和输入面板两部分。

框尾默认情况至少高33像素，具体内容由对话框类型决定，高度可随内部元素数量变化。

所有对话框都可配置框头标题、内容元素和框尾元素。框头的警告按钮用于提示玩家此UI并非游戏的暂停屏幕等内置UI，同时提供了强制退出存档或与服务器断开连接的选项，不可修改。内容元素自上而下依次为**主体元素**、**输入控件**、依对话框类型不同而有不同作用的**操作按钮**。

# = 操作后行为 =
对话框的操作后行为描述了一个对话框执行操作后的行为，共有如下类型：
* **<code>none</code>**：操作后无任何行为，玩家仍在原对话框。需要为<code>false</code>以避免单人模式中的玩家无法退出对话框。
* **<code>close</code>**：关闭当前对话框，通过退出对话框时始终为此行为。
* **<code>wait_for_response</code>**：关闭当前对话框，并进入“”屏幕。此屏幕不会暂停单人游戏，并固定于5秒后弹出返回按钮以允许玩家离开此屏幕。

操作后行为可由专门的操作按钮触发，也可由主体元素文本中的点击事件触发。对话框内有效并能产生对应效果的点击事件只有，其中<code>run_command</code>在网络阶段为配置阶段的对话框内不可用。

<code>number_range</code>即数字输入控件，游戏将渲染一个滑条代表此输入，滑条高度为20像素。

# 操作
* *操作（Action）**描述了玩家与对话框交互时的触发行为。在渲染对话框时，其操作定义了按钮所带的自定义触发行为。根据行为分类可以分为**静态操作（Static Action）**和**动态操作（Dynamic Action）**。

所有操作都有下列结构：

<div class="treeview">

* * ：（文本组件）按钮渲染文本。
* * ：（文本组件）按钮悬浮提示。
* * ：（，默认为150）按钮的宽度，以像素为单位。
* * ：一个具体的操作。
* ** ：对话框操作类型。
* ** 其他标签与操作类型相关。
</div>

# = 动态操作 =
动态操作使用输入控件提供的值，即它们的行为会随着对话框的输入而改变。

# == dynamic/custom ==
根据输入值构建<code>custom</code>点击事件，发送自定义负载。目前自定义负载只接受复合标签。

<div class="treeview">
*  对话框操作
* *
* ** ：<code>dynamic/custom</code>
* ** ：网络负载的命名空间ID。
* ** ：要添加到网络负载的静态负载。
</div>

游戏优先检查是否提供了静态负载，若有则优先读取；然后根据输入值构建若干个输入控件指定的名称为标签名、输入内容为标签内容的键值对并依次进行拼接，整理为最终发送的复合标签，并和命名空间ID一起使用<code>custom_click_action</code>网络数据包发送到服务端。

整理后的复合标签嵌套不允许超过16层，且序列化后长度不能超过32768字节。如果超过此限制，服务端会因为<code>custom_click_action</code>网络数据包无法反序列化而报错并断开与客户端的连接，单人游戏中会直接退出世界。

# == dynamic/run_command ==
根据输入值构建<code>run_command</code>点击事件，发送命令并使服务端执行。

<div class="treeview">
*  对话框操作
* *
* ** ：<code>dynamic/run_command</code>
* ** ：命令模板。
</div>

* *命令模板**

命令模板为一个带有<code>-{}-$(*名称*)</code>的字符串。其中<code>-{}-$(*名称*)</code>部分可视作模板参数，其在提交时将被替换为对应的输入内容。
* 若某参数名称无对应的输入内容，则使用空字符串替换。
* 参数名称所包含的字符必须为字母、数字或下划线。
* 命令模板中必须至少包含一个模板参数。

例如，若当前对话框中包含一个输入控件，其中为<code>input</code>，输入值为<code>test</code>，且命令模板为<code>tellraw @s "$(missing)$(input)"</code>，则将按如下方法替换为<code>tellraw @s "test"</code>：

* <code>tellraw @s "</code>和<code>"</code>为非模板参数段，按原样给出。
* <code>$(missing)</code>无对应值，被视为空字符串。

* *命令行为**

命令模板中的命令无需指定<code>/</code>或<code>$</code>前缀，强制指定游戏会解析失败。命令上下文执行者实体默认为提交该命令模板的玩家。

游戏会将命令模板替换后的结果作为命令解析，并进行解析检查：
* 如果当前网络阶段为配置（Configuration）阶段，游戏不会发送命令，只会在日志中警告命令不可执行。
* 如果命令不能被解析，弹出警告命令错误的对话框，确认是否发送命令。
* 如果命令中包含需要签名的数据（即任何聊天信息参数，例如中的消息参数），则显示屏幕，允许玩家退出此屏幕后在聊天栏执行命令或复制到剪切板中。
* 如果命令所需的权限等级大于0，弹出警告命令需要权限的对话框，确认是否发送命令。
* 如果命令没有上述问题则客户端直接发送命令到服务端。
