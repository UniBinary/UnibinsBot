# 铁活板门

*页面ID: 162854* | *来源: Minecraft Wiki*

* *铁活板门（Iron Trapdoor）**是由[铁锭](铁锭.md)制成的仅可被红石信号开关的[活板门](活板门.md)。

# 生成
# = 自然生成 =
铁活板门可以生成在[远古城市](远古城市.md)的冰窖入口。

# = 合成 =

# 破坏
挖掘铁活板门的合适工具是镐。铁活板门需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

铁活板门被破坏后会掉落自身。

# 用途

不同于木活板门和铜活板门，铁活板门只能被红石信号控制。
