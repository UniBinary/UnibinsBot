# 云

*页面ID: 6333* | *来源: Minecraft Wiki*

[缩略图|300px|最佳图形设定下的云](File:Fancy clouds.png.md)

* *云（Cloud）**是出现在天空中的画面效果，用于丰富游戏画面，对世界没有实际影响。

# 外观
[缩略图|300px|高品质（左）和流畅（右）中云的对比](File:Fancy vs fast clouds.png.md)
[缩略图|300px|不同天气状况中的同一片云](File:CloudsComparison.png.md)

云的渲染可以通过]]”选项|je}}或”选项|be}}调整。
* **关**：云不会显示。
* **流畅**：云透明度较低且呈平面状，在白天和夜晚云的样子不会改变。云在水平方向上最小宽8×8格。云仍然是立体的。这些云的样子类似于现实中的。
* **高品质**：云呈立体透明棱镜状，高约5格，宽12×12格。在夜晚，云逐渐变得暗蓝且更为透明。云的样子与现实中[层积云](wzh:层积云.md)类似。

在云上面或在云中时，无论图像品质是如何设定的，云都会呈现半透明状。[太阳](太阳.md)和[月亮](月亮.md)总能在云下方看见。

云的形状、立体或平面可以通过修改中的而变更。文件的尺寸可更改为任何大小。

# 行为
云会在Y=192至196处向西飘浮。云不可交互，飘浮时它们会穿过方块和实体。与现实中不同，云不会产生[雨或雪](天气.md)，这意味着即使在云的上方也会出现降雨或降雪。

云的运动对于同一服务器上的所有玩家相同。

即使重启游戏，云还会在原来那个位置。在不同世界中云的位置是相同的，如果玩家退出当前世界并生成一个新世界，当他们到达与之前的世界相同的坐标时，云会出现在相同的坐标。
