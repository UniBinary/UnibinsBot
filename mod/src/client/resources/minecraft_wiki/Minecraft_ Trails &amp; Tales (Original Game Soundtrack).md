# Minecraft: Trails &amp; Tales (Original Game Soundtrack)

*页面ID: 104059* | *来源: Minecraft Wiki*

* **Minecraft: Trails & Tales (Original Game Soundtrack)*（《Minecraft：足迹与故事（游戏原声带）》）**是[Aaron Cherof](Aaron Cherof.md)为[Minecraft](Minecraft.md)创作的首张专辑。本专辑在2023年4月26日于Spotify发布。

本专辑包含5首乐曲，时长总计21分钟56秒，包括1首在[菜单屏幕](菜单屏幕.md)播放的曲目及3首在[主世界](主世界.md)生存模式播放的曲目，以及一首[音乐唱片](音乐唱片.md)*Relic*的曲目。
