# Java版标签/猫变种

*页面ID: 161630* | *来源: Minecraft Wiki*

* *猫变种标签（Cat Variant Tags）**是[猫变种](猫#外观.md)的组合。

# 使用
猫变种标签不可被主动调用，它们被游戏用来控制猫的变种选择。

# 已移除的标签
# = default_spawns =
* 在村庄中生成时，每天都可以生成的猫变种。该行为被替代。

添加于：[22w13a](22w13a.md)。移除于：[25w04a](25w04a.md)。

# = full_moon_spawns =
* 在村庄中生成时，只在满月时可以生成的猫变种。该行为被替代。

添加于：[22w13a](22w13a.md)。移除于：[25w04a](25w04a.md)。
