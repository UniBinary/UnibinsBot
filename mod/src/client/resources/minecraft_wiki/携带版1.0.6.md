# 携带版1.0.6

*页面ID: 28614* | *来源: Minecraft Wiki*

* *1.0.6**是[携带版](携带版.md)的一次次要更新，发布于2017月4月11日<ref></ref>，加入了商店中的世界选项和中国神话混搭包，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[设置](设置.md)**
* 在商店中加入了世界选项。

* *[混搭包](混搭包.md)**
* 加入了中国神话混搭包。

# 更改
# = 生物 =
* *[史莱姆](史莱姆.md)**
* [史莱姆](史莱姆.md)的跳跃范围现在正确了。

# = 常规 =
* *信息**
* 游戏中的消息/更新日志不再和最新更新绑定了。

# 修复
* *修复了19个漏洞**
* 由骷髅马陷阱生成的骷髅马不能被驯服或骑乘。
* 在部分安卓设备里的游戏无法正常启动。
* 幼年生物没有空闲音效。
* 被凋灵摧毁的方块不会掉落。
* 由发射器发射的箭现在会直接使得前方一格的生物受伤。
* 在附加包里的雪傀儡的头部比例不正确。
* 在使用移动数据时，在商店里下载内容不能取消。
* 更改已经导入并设置为全局的资源包的存储位置时游戏崩溃。
* 2016年节日混搭包里的皮肤出现错误。
* Realms世界里攻击烈焰人导致游戏崩溃。
* 替换Realms世界现在会应用其中的行为包。
* 物品现在能穿过台阶下方的空隙。
* 放置了下半部分的台阶使得生物生成在其底部的概率下降。
* 可以使用带有精准采集的工具来获得燃烧的熔炉。
* 熔炉界面里的部分物品名称出现错误。
* 如果玩家缺少合成末地烛的原料时，末地烛在合成界面里的图标不会变灰。
* 末地传送门方块被视作固体方块，且粒子错误。
* 试图加入已满人的多人游戏时崩溃。
* 玩家在加入Xbox Live多人游戏时没有音效。
