# 高度图

*页面ID: 108392* | *来源: Minecraft Wiki*

* *高度图（Heightmaps）**是游戏于每个X/Z位置所记录的该位置最高方块Y坐标信息。其数据被储存在[区块](区块存储格式#高度图存储格式.md)中，并在许多游戏计算中被使用。

# 列表
为了适应不同的运算用途，游戏中有不止一个高度图，它们对最高方块的定义方式不尽相同。

若没有符合条件的方块，高度图的值将为<code>-{}-最低建筑高度-1</code>。

# = 客户端 =
这两个高度图会被发送给客户端使用，并同时显示在[调试屏幕](调试屏幕.md)的<code>CH</code>与<code>SH</code>栏。

# == world_surface ==
储存最高非[空气](空气.md)方块的Y坐标。此处的空气包含所有种类。

# == motion_blocking ==
储存最高的阻止运动方块或[流体](流体.md)的Y坐标。

# = 服务器端 =
这两个高度图只在服务器端使用，并显示在调试屏幕的<code>SH</code>栏。

# == ocean_floor ==
储存最高的阻止运动方块的Y坐标。

# == motion_blocking_no_leaves ==
与<code>motion_blocking</code>基本相同，但[树叶](树叶.md)被排除在外（不论是否含水）。

# = 世界生成用 =
这两个高度图仅在游戏内部[世界生成](世界生成.md)时使用，并于结束后即删除，无法在调试屏幕查看，亦无法于命令中使用。

# == world_surface_wg ==
效果与<code>world_surface</code>相同。

# == ocean_floor_wg ==
效果与<code>ocean_floor</code>相同。

# 用途
# = 调试屏幕 =

[250px|缩略图|调试屏幕中的CH和SH](File:Debug screen heightmaps.png.md)
调试屏幕中会显示目前所在X/Z位置的高度图数值，分为<code>CH</code>（**C**lient Side **H**eightmaps，客户端高度图）与<code>SH</code>（**S**erver Side **H**eightmaps，服务器端高度图）两。其中：
* <code>S</code>代表<code>world_**s**urface</code>
* <code>O</code>代表<code>**o**cean_floor</code>，只在<code>SH</code>显示
* <code>M</code>代表<code>**m**otion_blocking</code>
* <code>ML</code>代表<code>**m**otion_blocking_no_**l**eaves</code>，只在<code>SH</code>显示
若非内建服务器端，即在架设的服务器上游玩，<code>SH</code>各高度图的值将显示为<code>??</code>。

# = 命令 =

[命令](命令.md)可以将命令执行位置的Y轴高度移至指定高度图于原位置处的值。

# = 世界生成 =

世界生成的过程中，常会用到各种高度图来对地表进行定位。

# = 游戏机制 =
高度图在许多游戏机制中被使用，下列出其中几种。若无注明，高度图皆指<code>world_surface</code>。
* [避雷针](避雷针.md)使用高度图来确定其上方没有其他方块，以决定是否能吸引[闪电](闪电.md)。
* 计算[世界出生点](世界出生点.md)时通过<code>world_surface</code>、<code>motion_blocking</code>与<code>ocean_floor</code>之间进行比较来决定是否开始检查该位置，并从高度图的最高方块一路往下检查位置合法性。
* 生物自然[生成](生成#可生成位置.md)随机选择位置时将从最低建筑高度至高度图高度之间随机选择高度。
* * 这意味着越低的高度图值将可带来越高的生成效率，因为选到有效位置的几率将变高。
* 多数[伴随区块生成](生成#初始动物生成.md)的生物使用<code>motion_blocking_no_leaves</code>来决定自身生成位置。
* * 例外为[豹猫](豹猫.md)与[鹦鹉](鹦鹉.md)，使用<code>motion_blocking</code>。
* 各种[生物](生物.md)的AI会使用各高度图来协助寻路。
* [信标](信标.md)将从自身位置一路检查到高度图的最高方块来决定自身的颜色及是否启动。
* * 这意味着若信标距离最高方块越远，更新速度将越慢。
* [流浪商人](流浪商人.md)与[袭击](袭击.md)的生成位置高度都是取高度图的值。
* 游戏欲创建[下界传送门](下界传送门.md)时，有效位置时会从<code>motion_blocking</code>的高度开始往下搜寻。
* [地图](地图.md)使用高度图来检查世界上的表层方块并进行绘制。
* [雨](雨.md)和[雪](降雪.md)落到<code>motion_blocking</code>的高度后才会停止。
