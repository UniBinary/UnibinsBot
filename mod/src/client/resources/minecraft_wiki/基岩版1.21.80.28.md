# 基岩版1.21.80.28

*页面ID: 149988* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.80.28**（ChromeOS/Android）、**Preview 1.21.80.28**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.80](基岩版1.21.80.md)的第6个测试版，发布于2025年4月15日<ref></ref>，加入了[Realms](Realms.md)服务器托管区域的偏好选择功能，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 重新加入了“”（Data-Driven Jigsaw Structures）子选项。

* *[Realms](Realms.md)**
* 加入了Realms服务器托管区域的偏好选择功能：
* * 在Realms设置屏幕中加入了新的“高级”选项卡。
* ** Realm拥有者可以在高级选项卡中选择想要的数据中心区域来托管他们的Realm。
* ** 选项包括区域列表，或允许Realms服务自动为Realm拥有者或在指定中首个加入Realms的玩家选择最佳区域。
* * 注意：选择仅供参考；受限于服务器容量，Realms托管区域可能与所选区域不同。
* ** 此情况下会选择最接近偏好的区域。
* * 加入了一条在加入Realm期间显示的消息，用于指示Realm被分配到该的哪个服务器区域。

# 更改
# = 技术性 =
* *性能与稳定性**
* 修复了将多个值写入覆盖层颜色时数据驱动渲染器中的缓冲区溢出导致的崩溃。
* 修复了区块渲染中的空指针取消引用崩溃。

* *结构**
* 数据驱动拼图结构现在再次需要开启实验性选项。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“”子选项后才可使用。

# = 技术性 =
* *图形**
* 更新了的格式，以支持在中控制末地闪光。
* * 部分现在拥有两个组：包含太阳和月亮周围的光照信息的，以及包含末地闪光信息的。
* ** 部分支持用于控制末地闪光的照明度的字段，以及用于控制闪光颜色的字段。使用新格式的JSON示例如下：
  :: <syntaxhighlight lang="json">
{
  "format_version": "1.21.80",
  "minecraft:lighting_settings": {
    "description": {
      "identifier": "minecraft:default_lighting"
    },
    "directional_lights": {
      "orbital": {
        "sun": {
          "illuminance": {
            "0.0": 1.0,
          },
          "color": {
            "0.0": [ 255, 255, 0 ]
          }
        },
        "moon": {
          "illuminance": {
            "0.0": 1.0,
          },
          "color": {
            "0.0": [ 0, 0, 255 ]
          }
        },
        "orbital_offset_degrees": 5.0
      },
      "flash": {
        "illuminance": 1.0,
        "color": [ 255, 0, 255 ]
      }

# 修复
* *方块**
* 失水恶魂不再会在未开启“”[实验性玩法](实验性玩法.md)的情况下生成。（）

* *收纳袋**
* 现在使用触摸控制点击收纳袋时，空的打开的收纳袋图标会正确渲染。

* *性能与稳定性**
* 修复了市场附加包内容有时无法在世界中加载的漏洞。</onlyinclude>
