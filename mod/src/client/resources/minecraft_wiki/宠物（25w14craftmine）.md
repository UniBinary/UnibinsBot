# 生成
玩家在解锁并激活宠物标签页中的可解锁项目后进入新的矿境，或在矿境中解锁并激活其中的新项目时会生成一只对应的宠物（宠物狼无法控制是否激活，解锁后无法取消生成），并且通过此方式生成的宠物总是设置为（免疫一切不是创造模式玩家、虚空或造成的伤害）。

# 掉落物
宠物被杀死时不会掉落物品和经验。
