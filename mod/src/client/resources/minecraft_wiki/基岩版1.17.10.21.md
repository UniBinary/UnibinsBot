# 基岩版1.17.10.21

*页面ID: 83583* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.17.10.21**是[基岩版1.17.10](基岩版1.17.10.md)的第2个测试版，发布于2021年6月3日<ref></ref>，同步了一些的特性，并修复了一些漏洞。由于提交至应用商店时出现问题，此版本没有发布到Android平台上，但其仍然与[1.17.10.20](基岩版1.17.10.20.md)相兼容。

# 新内容
# = 方块 =
* *[杜鹃花丛盆栽](杜鹃花丛盆栽.md)和[盛开的杜鹃花丛盆栽](盛开的杜鹃花丛盆栽.md)**
* 通过将[杜鹃花丛](杜鹃花丛.md)或[盛开的杜鹃花丛](盛开的杜鹃花丛.md)放入[花盆](花盆.md)获得。

# 更改
# = 方块 =
* *[蓝冰](蓝冰.md)**
* 现在不再发光。<ref></ref>

* *[告示牌](告示牌.md)**
* 告示牌上的发光文字现在拥有发光外边框。

# = 生物 =
* *[山羊](山羊.md)**
* 调整了被小麦吸引的山羊的移动速度以匹配。
* 山羊现在只能免疫点摔落伤害，以同步。

* *[流浪者](流浪者.md)**
* 被[闪电苦力怕](闪电苦力怕.md)炸死后不再掉落[凋灵骷髅头颅](凋灵骷髅头颅.md)，以同步。

# = 世界生成 =
* *[堡垒遗迹](堡垒遗迹.md)**
* 调整了箱子战利品，以同步。
* * 增加了多种稀有战利品的出现权重和堆叠数。
* * 移除了所有“无”战利品项。
* * 提高了战利品箱中武器的平均耐久值。
* * 为战利品表加入了[附魔金苹果](附魔金苹果.md)、[金胡萝卜](金胡萝卜.md)、附魔金[斧](斧.md)和[铁块](铁块.md)。
* * 从藏宝室的箱子中移除了[铁粒](铁粒.md)。
* * 藏宝室的箱子中未附魔的钻石[盔甲](盔甲.md)不再是损坏的。

# = 技术性 =
* *区块**
* 现在除在必要时候之外，其他时间会限制[区块](区块.md)的加载。以旧方式生成的区块在加载时不会自动保存，但当区块的生成方式被修改时（例如放置允许方块或被操作员修改），它们将会被标记为保存。

* *数据驱动生物**
* 现在[马](马.md)及其变种的渲染和动画完全由数据驱动。

* ** 第3版（引擎版本[1.17.10](基岩版1.17.10.md)及以后），在第2版模型的基础上优化了骨骼动画

# 修复
* *稳定性**
* 修复了开启[实验性玩法](实验性玩法.md)（洞穴及悬崖子选项）后破坏方块时发生的崩溃。（）

* *钻石矿石**
* 钻石矿石现在又可以正确生成了。（）

* *发光地衣**
* 发光地衣现在仅能在使用剪刀破坏时掉落。

* *命令**
* 现在如和等关于方块的命令可以使用霜冰作为参数。（）

* *由数据驱动的物品**
* 更新了DisplayNameItemComponent文档。

* *游戏内容**
* 现在使用砂轮为附魔物品祛魔又会正确清除累积惩罚了。（）

* *发光告示牌**
* 告示牌上的发光字体现在拥有边框。（）
* 告示牌上的黑色字体现在可以使用荧光墨囊为其增亮。（）
* 控制器玩家现在手持墨囊或荧光墨囊时会出现提示文字。
* 玩家不再可以在冒险模式下对着告示牌无限使用墨囊和荧光墨囊。
* 玩家不再可以在冒险模式下使用染料为告示牌文字染色。（）

* *图形**
* 水下的迷雾又会根据生物群系而调整了。（）

* *物品**
* 玩家现在又可以使用南瓜与农民交易了。（）

* *唱片机**
* 唱片机现在只会把唱片弹到非固体方块上。（）

* *生物**
* 幼年马及其变种现在变得更高了，且腿部纹理不再会出现深度冲突。（）
* 两栖生物不再会卡在台阶或阳光传感器中。
* 在多人游戏中，被攻击发光鱿鱼不再只会对攻击者表现变暗。
* 1.11版本之后创建的市场世界中的旧村民现在会正确转化为村民v2。

* *山羊**
* 山羊现在可以在黏液块和蜜蜂块上继续冲撞生物。

* *流浪者**
* 流浪者被闪电苦力怕炸死后不再会掉落凋灵骷髅头颅。（）

* *堡垒遗迹**
* 更新了堡垒遗迹的箱子战利品以同步。（）

* *玩家**
* 玩家不再可以在空气中游泳。（）

* *海龟**
* 从海龟蛋中孵化的幼年海龟不再会消失。（）

* *用户界面**
* 辅助功能设置中的“恢复到默认值”按钮现在会重置文字不透明度。
* 修复了游戏指南中的“织布机”部分的一个错别字。（）
* 界面上方的空白标签中的数字现在会显示为0，而不是显示为灰色方框。（）</onlyinclude>
