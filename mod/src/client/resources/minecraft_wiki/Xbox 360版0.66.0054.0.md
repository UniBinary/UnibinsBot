# Xbox 360版0.66.0054.0

*页面ID: 94736* | *来源: Minecraft Wiki*

* *Build 0054**是[Xbox 360版](Xbox 360版.md)的一个开发版本。这个版本是在[Java版Beta 1.6.6](Java版Beta 1.6.6.md)的基础上更新的。

# 新内容
* 加入了新的全景图和教程世界。
* 添加了无需手动保存即可退出的功能。
* 添加了游戏载入后的保存指示器。

# 更改
* 菜单屏幕现在会播放[音乐](音乐.md)和音效。
* 重新设计了所有选项菜单。
* 现在[闪烁标语](闪烁标语.md)跳动得更快了。
* 更改了创建和加载世界的界面。
* 全景图现在会无限循环滚动，而非只是从左滚动到右。
* 将主菜单屏幕的徽标由[100px](File:Xbox 360 Edition logo 1.png.md)更改为[100px](File:Xbox 360 Edition logo 2.png.md)。
* 更改了合成界面。
* 现在会在保存和加载世界时显示[加载提示](加载提示.md)了。
* 更新了调试屏幕。
* 游戏运行更加流畅了。
* 将元数据标题由“Minecraft”改为“Minecraft XDK Edition”。
* 将零售版的元数据描述从“Minecraft is a game about placing blocks to build anything you can imagine.”改为“Minecraft from Partnernet v1.0”。
* 更改了[门](门.md)的音效。
* 从合成菜单中移除了[金苹果](金苹果.md)。
* 将武器部分从合成菜单中移除。
* 武器被重新调整到合成菜单的工具部分。
