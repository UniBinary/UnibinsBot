# 基岩版1.16.0.58

*页面ID: 60677* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.0.58**是[基岩版1.16.0](基岩版1.16.0.md)的第10个测试版，发布于2020年4月22日<ref></ref>，修复了一些漏洞。

# 修复
* *修复了7个漏洞**<br>
* *崩溃**
* 修复了检查市场内容更新时可能出现的崩溃。
* 当打开市场时，安卓平台将不再崩溃。（）

* *游戏内容**
* 炼药锅中的药水现在可以正确地取出了。
* 当按住使用键时，鱼竿现在可以不断的扔出并收回。（）

* *用户界面**
* 现在在触屏设备上双击物品时可以正确堆叠物品了。（）
* 现在能够在控制器中正确地使用"全部合成"功能了。（）
* 现在在创造模式物品栏中搜索时将实时更新搜索结果。（）

* *脚本和行为包**
* 当带有属性的实体消失时，不再会运行。</onlyinclude>
