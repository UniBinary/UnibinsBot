# 启动器3.0.13

*页面ID: 125773* | *来源: Minecraft Wiki*

<onlyinclude>

* *3.0.13**是一次[启动器](启动器.md)更新，发布于2024年9月9日。</onlyinclude>

# 更改
* 对的称呼由“Minecraft for Windows”改为“Minecraft: Bedrock Edition”。

# 修复
* 修复了几个漏洞，以确保启动器关键更新流程顺畅无误。

# 你知道吗
* 由于对基岩版称呼的更改，该版本启动器的名称在Windows 10/11平台上被误写作“Launcher Bedrock Edition”。<ref></ref>
