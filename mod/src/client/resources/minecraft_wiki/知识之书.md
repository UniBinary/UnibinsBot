# 知识之书

*页面ID: 28946* | *来源: Minecraft Wiki*

* *知识之书（Knowledge Book）**是一种后可以让玩家获得指定[合成](合成.md)配方的实用[物品](物品.md)。

# 获取

知识之书无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，知识之书可以通过[命令](命令.md)等方式获得。知识之书不存在于[创造模式物品栏](创造模式物品栏.md)中，除非玩家在“”中存储了知识之书。

例如，以下命令会给予一个可以解锁[铁桶](铁桶.md)和[花盆](花盆.md)的合成配方的知识之书:
["minecraft:bucket", "minecraft:flower_pot"]]}}

# 用途
知识之书用于为使用该物品的玩家解锁指定的合成配方，将其加入到玩家的[配方书](配方书.md)里。知识之书在使用后会被消耗，从玩家的物品栏中消失。

知识之书可搭配[游戏规则](游戏规则.md)设置为<code>true</code>，用于制作自定义地图，因为在为<code>true</code>时，玩家只能使用他们已经拥有的配方。

# = 雕纹书架 =
手持知识之书对[雕纹书架](雕纹书架.md)按键可将书放入其中。
