# 危机纹样陶片

*页面ID: 156721* | *来源: Minecraft Wiki*

* *危机纹样陶片（Danger Pottery Sherd）**是图案形似[苦力怕](苦力怕.md)的[陶片](陶片.md)。

# 获取
# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落危机纹样陶片。

# = 饰纹陶罐 =
被不具有[精准采集](精准采集.md)的工具挖掘破坏或被[弹射物](弹射物.md)击毁时，附有危机纹样陶片的[饰纹陶罐](饰纹陶罐.md)会掉落危机纹样陶片。
