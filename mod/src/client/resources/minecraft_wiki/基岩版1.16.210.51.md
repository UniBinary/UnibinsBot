# 基岩版1.16.210.51

*页面ID: 73216* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.210.51**是[基岩版1.16.210](基岩版1.16.210.md)的第2个测试版，发布于2020年12月9日<ref></ref>，更改了[山羊](山羊.md)和[细雪](细雪.md)的行为，以及修复漏洞。

# 更改
# = 方块 =
* *[细雪](细雪.md)**
* 现在被挖掘时会显示方块破坏动画。
* 穿过云层观看时不再显得透明。

# = 物品 =
* *[盾牌](盾牌.md)**
* 被[山羊](山羊.md)冲撞时，现在会给予玩家部分击退保护。

* *[刷怪蛋](刷怪蛋.md)**
* 更新了山羊刷怪蛋的纹理。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 被山羊冲撞后不再反击。

* *[山羊](山羊.md)**
* 现在死亡时会掉落1-2个[生羊肉](生羊肉.md)。
* 更新了模型，现在有着正确的头部旋转了。
* 现在每次繁殖时只会产生一只幼年山羊。
* 不再选择障碍物后不可到达的位置作为冲撞目标。
* 现在可以跳上一些非全体积[方块](方块.md)，如[台阶](台阶.md)和[楼梯](楼梯.md)。
* 不再从[蜂蜜块](蜂蜜块.md)上起跳。
* 不再跳上[岩浆块](岩浆块.md)。
* 不再攻击[盔甲架](盔甲架.md)。
* 现在每只山羊最多只会掉落2个[山羊角](山羊角.md)。
* * 剩余的山羊角数量会表现在模型上。
* 不再会跳得过高或过低。
* 现在会对攻击目标造成更高的竖向击退。
* 现在能够在冲撞时穿过花、草等非固体方块。
* 现在会对其撞到的第一个目标造成击退。
* 缩短了幼年山羊的击退距离。
* 将幼年山羊的跳跃能力削弱至成年个体的水平之下。

# 修复
* *原版趋同**
* 雪层被水冲掉时不再会产生雪球。
* 现在在暖水海洋生物群系中使用骨粉只会生成海草、珊瑚和珊瑚扇。（）

* *常规**
* 更新了过时的加载界面提示。（、）

* *游戏内容**
* 现在用精准采集附魔工具破坏绯红菌核会掉落可放置的方块。

* *生物**
* 修复了鹦鹉能够无限向上飞行的漏洞。
* 在从市场下载的、1.11版本后创建的世界中，由刷怪笼生成的僵尸村民现在会正确地生成为V2僵尸村民，其被治愈后现在也能够正确地转化为V2村民。
* 现在马、驴、骡、骷髅马和僵尸马可被正确赋予自定义名称，且可使用其对应的“runtime_identifier”识别。

* *图形**
* 修复了RTX世界中装有地图的物品展示框附着在透明方块上时产生的渲染问题。
* 减少了开启DLSS时透过水看鱼产生的重影。</onlyinclude>
