# 游泳

*页面ID: 34095* | *来源: Minecraft Wiki*

<div style='float:right'></div>**游泳（Swimming）**是一种让玩家在水中穿行的[移动方式](运输.md)。

# 控制
[thumb](File:Enter swimming.gif.md)
[thumb|玩家进入和离开游泳状态](File:Exit swimming.gif.md)
玩家可以通过在[水](水.md)中按键游泳。

速泳（疾跑游泳）可通过在水中按住键的同时按住键，或者双击键来激活。玩家在饥饿值小于或等于时无法速泳。

游泳时潜行会让玩家下沉得更快。

# 用途
当在静止的水面上游泳时，玩家以2.20m/s的速度移动。如果玩家部分浸入水中，玩家的速度是1.97m/s。当玩家完全在水下并向下游时，移动速度为1.81m/s，而玩家完全在水下并向上游时，移动速度较慢，为0.39m/s。

# = 速泳 =
[玩家速泳的动画|thumb|350px](File:Swim.gif.md)
速泳允许玩家以大约3.92m/s的速度移动，比行走时的大约4.317m/s的速度略慢。玩家可以在速泳时转身，此时玩家的游泳速度也会降低。速泳也会增加创造模式中[飞行](飞行.md)和游泳的速度。像[疾跑](疾跑.md)一样，虽然“速泳”的同时也会增加视野，但却不会增加实体的移动速度。玩家可以通过按加速键增加游泳速度。

在速泳时按潜行键可以让玩家下降得更快。

在速泳时，玩家可以水平移动<ref></ref> ，而不是像平常那样站立，即使速泳不会导致玩家游得更高。

速泳会减少玩家的饱和度，当饱和度为零时，每游行40米或7秒时会减少的饥饿值。

当玩家在速泳时攻击任何[生物](生物.md)（不包括[鱿鱼](鱿鱼.md)、[鱼](鱼.md)和[海龟](海龟.md)）会导致它们获得比平时更大的击退效果。

速泳在玩家撞到固体方块、潜行、格挡或攻击生物时会结束。另外，速泳也在饥饿值低于或更低时结束。
