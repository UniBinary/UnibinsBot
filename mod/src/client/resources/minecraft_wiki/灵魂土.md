# 灵魂土

*页面ID: 52392* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *灵魂土（Soul Soil）**是一种仅在[灵魂沙峡谷](灵魂沙峡谷.md)生物群系中生成的[方块](方块.md)，可用于生成[灵魂火](灵魂火.md)。

# 生成
# = 自然生成 =
灵魂土在[下界](下界.md)的[灵魂沙峡谷](灵魂沙峡谷.md)生物群系中自然生成。

# 获取
# = 灵魂营火 =
没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[灵魂营火](灵魂营火.md)被破坏后会掉落1个灵魂土。

# 破坏
挖掘灵魂土的合适工具是锹。

灵魂土被破坏后会掉落自身。

# 用途
与[灵魂沙](灵魂沙.md)不同，灵魂土不会降低[实体](实体.md)的移动速度。

# = 合成材料 =

# = 火 =
在灵魂土上点燃的火是[灵魂火](灵魂火.md)，在不被干涉的情况下能够永久燃烧。

# = 凋灵 =

|生成凋灵的一种结构示意图}}
灵魂土可用于搭建生成[凋灵](凋灵.md)的结构。

# = 加速 =
穿着带有[灵魂疾行](灵魂疾行.md)魔咒的[靴子](靴子.md)在灵魂土上或}}行走时，速度为普通行走的{{cd|-{}-1.3 + 魔咒等级 &times; 0.105}}倍。

# = 玄武岩 =
[缩略图|一个简单的玄武岩生成器](File:Basalt generator.gif.md)
位于灵魂土上方且与[蓝冰](蓝冰.md)毗邻的[熔岩](熔岩.md)源或熔岩流会转变成[玄武岩](玄武岩.md)。

# 你知道吗
* 无论是使用灵魂沙还是灵魂土合成的灵魂营火，灵魂营火破坏后都会掉落1个灵魂土。由于灵魂沙及其他灵魂营火的合成材料是可再生的，因此灵魂土也是可再生的。
