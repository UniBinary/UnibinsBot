* *14w04b**是[Java版1.8](Java版1.8.md)的第7个快照，发布于2014年1月24日<ref></ref>，修复了[14w04a](14w04a.md)的漏洞和崩溃。

# 修复
命令复制的命令方块导致游戏崩溃。
|;previous
|45482|杀死生物总是可以得到稀有掉落（100%概率）。
|45496|玩家受到生物伤害时被服务器断开连接。
|45516|熔炉在游戏重启或在切换维度后停止熔炼。
|45528|被雪覆盖的草方块上不显示雪的纹理。
|45552|世界加载或重加载导致物品展示框被复制。
|45605|物品展示框放置在雪上时不输出信号。
|45628|不生成地牢。
|45689|时钟在物品展示框中不显示。
|;hotfix
|45747|物品展示框不能被放置，原先放置的也会掉落。
}}

# 重新上传
该版本于15:54（UTC）被重新上传，以修复无法放置物品展示框与物品实体不会旋转的问题。<ref>: </ref></onlyinclude>
