# Java版1.16.2-pre1

*页面ID: 67482* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.16.2-pre1**是[Java版1.16.2](Java版1.16.2.md)的首个预发布版，发布于2020年7月29日<ref></ref>，该版本添加了“”和“”选项，允许[锁链](锁链.md)沿各坐标轴方向放置，并修复了一些漏洞。

# 新内容
# = 常规 =
* *字体**
* 加入了11种分数字形：

[thumb|本次加入的emoji与其对应的游戏中的物品](File:Emoji Added in JE 1.16.2 Pre1 and Relative Items.png.md)
* 加入了8种与游戏物品相关的emoji：

* 加入了3种其他字形：


* *[选项](选项.md)**
* 添加了“”选项，可影响诸如[反胃](反胃.md)效果和[下界传送门](下界传送门.md)产生的视觉扭曲。
* * 强度范围为关闭（0%）到100%。
* * 当强度较低时，反胃效果将会在屏幕边缘增加绿色的视觉效果。
* * 强度设置得越低，屏幕上的绿色视觉效果越明显。
* ** 虽然选项菜单称该选项会取代低等级的反胃状态效果造成的视觉扭曲，但实际效果与该描述相反。反胃状态效果造成的视觉扭曲只会在强度设置为“关闭”时才会被真正禁用。
* 加入了“”选项。
* * 影响玩家在[疾跑](疾跑.md)、拉弓以及受到[迅捷](迅捷.md)和[](缓慢.md)状态效果影响等情况下的视场角变化幅度。

# 更改
# = 方块 =
* *[气泡柱](气泡柱.md)**
* 现在会正常影响[弹射物](弹射物.md)的运动。

* *[锁链](锁链.md)**
* 现在可沿任意坐标轴方向放置。

* *[菌索](菌索.md)**
* 现在需使用[剪刀](剪刀.md)采集。

* *非固体方块**
* [甘蔗](甘蔗.md)、[高草丛](高草丛.md)等许多非固体方块现在不再会阻挡弹射物。

# = 生物 =
* *[末影人](末影人.md)**
* 不再会将搬起的方块放在[基岩](基岩.md)上。

* *[猪灵](猪灵.md)**
* 现在会在[玩家](玩家.md)在附近破坏或打开[运输矿车](运输矿车.md)时被激怒。

* *[炽足兽](炽足兽.md)**
* 现在会尝试寻路到[熔岩](熔岩.md)上，并且会避免走出熔岩。

* *[僵尸猪灵](僵尸猪灵.md)**
* 现在骑乘炽足兽的僵尸猪灵在生成时会手持[诡异菌钓竿](诡异菌钓竿.md)。

* *[村民](村民.md)**
* 现在会在传送到其他[维度](维度.md)后失去工作站点。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 现在在[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)上跳跃或放置不完整方块不会使[灵魂疾行](灵魂疾行.md)的加速效果中断。

# = 常规 =
* *[自定义维度](自定义维度.md)和[自定义世界生成](自定义世界生成.md)**
* 自定义世界生成和维度设置现在在数据包中使用相同的文件夹模式（<code>-{}-namespace/<类型>/resource.json</code>），与其他资源保持一致。

* *[菜单屏幕](菜单屏幕.md)**
* 将聊天延迟加入到了聊天设置界面。

* *字体**
* 细微更改了部分字形。
