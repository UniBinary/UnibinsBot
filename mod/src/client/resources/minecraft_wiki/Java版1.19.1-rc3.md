# Java版1.19.1-rc3

*页面ID: 97415* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.19.1-rc3**是[Java版1.19.1](Java版1.19.1.md)的第三个，也是最后一个发布候选版本，发布于2022年7月26日<ref></ref>，进行了一项微调，并修复了一个漏洞。

# 更改
# = 常规 =
* *[聊天](聊天.md)**
* 聊天框中不再支持应用步进宽度（Advances，设为正值时可以理解为空白宽度）为负或大于32的字体字形。
