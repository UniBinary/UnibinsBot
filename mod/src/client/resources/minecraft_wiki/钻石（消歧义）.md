# Minecraft
# = 方块和物品 =
*  - 一种通过开采钻石矿石获得的物品，用于合成Minecraft中的高级工具、武器和盔甲。
*  - 一种稀有的矿石，可在主世界的地下发现。
*  - 钻石矿石的深层变种，于[深板岩](深板岩.md)层内替换钻石矿石生成。
*  - 由9颗钻石合成的方块，可用于贮存钻石或装饰。
