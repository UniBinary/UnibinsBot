# 启动器2.1.367x

*页面ID: 45054* | *来源: Minecraft Wiki*

* *2.1.3674**（[Windows](wzh:Microsoft Windows.md)）、**2.1.3676**（[Linux](wzh:Linux.md)）或**2.1.3677**（[macOS](wzh:MacOS.md)）是在2019年4月23日发布的[启动器](启动器.md)版本。

# 新内容
* *语言**
* 支持了哈萨克语。
* *启动**
* 现在可以在任何包含“开始游戏”按钮的界面按来启动游戏。

# 更改
* *无障碍**
* 用户名和密码字段现在支持键盘导航。
* 现在可以通过在设置页面中启用切换或在启动器中的任意位置按，为登录状态和结果启用声音提示。
* *Java参数**
* 默认启动选项已从更改为。

# 修复
*  - 下载1.5.2以下版本的游戏资源会出现403错误。
