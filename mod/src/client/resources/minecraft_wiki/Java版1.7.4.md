* *1.7.4**是的一次次要更新，发布于2013年12月10日<ref name="blogpost_1.7.4"></ref>。虽然它不是1.7的最终版本，却是1.8首个快照发布前的最后一个正式版。此版本兼容1.7.2的服务端。

# 新内容
# = 生物 =
* *[鸡骑士](鸡骑士.md)**
* 幼年[僵尸](僵尸.md)骑着[鸡](鸡.md)的组合体。
* * 因为骑着鸡，幼年僵尸不会受到坠落伤害。
* * 幼年僵尸不会在日光中燃烧。
* 非常稀有——有极小概率生成。
* 僵尸猪人鸡骑士可以生成在下界。

# = 游戏内容 =
* *[着色器](着色器.md)**
* 新的“Notch”着色器。

# = 常规 =
* *原生支持<span class="plainlinks">[Twitch.tv](http://www.twitch.tv/)</span><ref>http://blog.twitch.tv/2013/11/twitch-minecraft-integration-announced-at-minecon</ref>**
* 可以录制音频。
* 游戏内Twitch聊天。<ref>http://www.youtube.com/watch?v=wPSVJHVL6TA&feature=share&t=6h29m50s</ref>
* *加入了Twitch有关的[设置选项](选项#历史.md)<ref>http://dinnerbone.com/media/uploads/2013-11/screenshots/19_09-34-28_ZU1viVlnmy.png</ref>**
* 广播设置：
* * 质量、帧率、带宽、元信息发送、麦克风音量、系统音量、压缩、启用聊天、玩家过滤（聊天）。

# 更改
# = 生物 =
* *绵羊**
* 被命名为“jeb_”的绵羊现在会变换16种颜色。<ref>http://www.reddit.com/r/Minecraft/comments/1seluj/rainbow_sheep_anyone_know_how_long_this_has_been/</ref>
* * 颜色仅仅是视觉效果，不影响掉落物羊毛颜色。

# = 游戏内容 =
* *[属性](属性.md)**
* [锋利](锋利.md)魔咒现在影响“攻击伤害”属性。
* *可骑乘实体**
* 玩家离开实体后不再移动很远的距离。
* *Tab键**
* 如果所有可自动补全选项的开头部分相同，Tab补全会补全开头部分。例如：变为。
* *视频设置**
* 高级OpenGL选项被移除。

# = 常规 =
* *启动画面**
* Mojang徽标从红色变为了橙色，有了2个方角，圆角更圆滑。文本现在是黑色的，并且变细，字体似乎是Insignia和Code pro的混合版。
* 不再能通过[资源包](资源包.md)更改。
* *[Realms](Realms.md)**
* 服务器的图标现在是拥有者的皮肤的头像。
* 配置界面的轮廓被修改了。
