# 铜火把

*页面ID: 161843* | *来源: Minecraft Wiki*

* *铜火把（Copper Torch）**是一种由[铜粒](铜粒.md)合成的可以提供亮光的非固体方块。

# 生成
铜火把不会生成在世界中。

# 获取
# = 合成 =

# 破坏
铜火把被挖掘时会立刻被破坏。

铜火把被破坏后会掉落自身。

# 用途
# = 放置 =

铜火把必须于[方块支撑形状](方块支撑形状.md)上表面中心完整的方块上方或侧面完整的方块侧面，不能放置于任何方块的底部，有个别情况需要放置。详见。

尝试在无效的表面放置铜火把会使其“滑入”这块空间内最近的有效表面。例如，尝试在地面上的栅栏侧面放置铜火把会使其附着到栅栏周围地面方块的顶部。

当铜火把附着的方块变动（移动、破坏、替代等），不再允许附着时，或有[水](水.md)流过和有[活塞](活塞.md)试图推动它或将方块推入其位置时，铜火把会掉落为方块物品。若[熔岩](熔岩.md)流过其位置，铜火把不会掉落。
