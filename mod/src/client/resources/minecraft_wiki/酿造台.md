# 酿造台

*页面ID: 7863* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *酿造台（Brewing Stand）**是一种用于[酿造](酿造.md)[药水](药水.md)、[喷溅药水](喷溅药水.md)和[滞留药水](滞留药水.md)的方块。

# 生成
# = 自然生成 =
空的酿造台会生成在[村庄](村庄.md)的教堂内。

酿造台会生成在[雪屋](雪屋.md)的地下室内，内含一瓶[喷溅型虚弱药水](喷溅型虚弱药水.md)。

酿造台也会自然生成在[末地船](末地船.md)中，内含两瓶[治疗药水](治疗药水.md)II。

# 破坏
挖掘酿造台的合适工具是镐。

酿造台被破坏后会掉落自身和内容物。

# 用途

酿造台不能被[活塞](活塞.md)推动。

酿造台界面的标题为“酿造台”，可在放置前使用[铁砧](铁砧.md)重命名来进行更改，也可以通过使用命令修改酿造台的<code>CustomName</code>标签进行更改。

# = 酿造 =

酿造台最主要的功能是[酿造](酿造.md)。对酿造台按下可以打开酿造台的界面。

酿造台使用[烈焰粉](烈焰粉.md)作为能量，每份烈焰粉可进行20次酿造。与[熔炉](熔炉.md)不同，酿造台的能量影响的是可以执行配方的次数而非运行时间。

若被放置在酿造台中的物品与任意酿造配方匹配，且酿造台有能量，酿造过程就会开始。每次酿造需用时20秒。酿造需要消耗1点能量才能开始，只有酿造过程结束之后才会消耗能量。

酿造台能与[漏斗](漏斗.md)进行如下交互：

* 酿造台上方指向酿造台的漏斗能输入酿造材料；
* 任何有效的药水配方均可预先加入，可用于复杂配方的自动酿造，其中[下界疣](下界疣.md)通常会在第一步进入；
* 药水与用作燃料的烈焰粉能从侧面指向酿造台的漏斗进入；
* 药水可通过下方的漏斗取出。

酿造台没有“输出”槽位，放置在其中的药水会在酿造过程中被直接转换，多个酿造材料可以如此连续地改变药水。放置在酿造台下的漏斗不会检测酿造台是否在工作，在未激活时总是会取走药水。

当酿造台的药水槽位有或任意[药水](药水.md)时，酿造台方块模型上的对应位置会显示红色药水纹理。

# = 红石比较器 =
[红石比较器](红石比较器.md)能够检测酿造台的五个槽位存储物品的数量。

# = 光源 =
酿造台会发出[亮度](亮度.md)为1的光。

# = 更改村民职业 =

失业的[村民](村民.md)在靠近未被认领的酿造台后有机会转变职业为[牧师](牧师.md)。

# 你知道吗
* 即使酿造台没被使用，也会有烟从顶部冒出。
* 无论是否装有药水，酿造台被破坏时产生的粒子总是/红色药水纹理。
* 无论玩家朝向什么方向放置，酿造台总是面向东方。
* 开发者之所以补充酿造台的燃料消耗机制，是因为[Searge](Searge.md)想在[雪屋](雪屋.md)地下室留一个酿造台，同时确保获取[下界](下界.md)独有资源的游戏进程不受影响；并且开发者认为每种合成过程都应消耗资源。<ref></ref>
