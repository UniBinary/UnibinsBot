# 命令/perf

*页面ID: 83035* | *来源: Minecraft Wiki*

记录并保存性能分析数据，如游戏刻执行时长、占用的堆内存大小等指标。

此命令只能在专用服务器上执行，若非专用服务器，则客户端使用进行性能分析。

# 用法
性能分析结束后，将会在{{filepath|-{}-<*游戏根目录*>/debug/profiling}}下创建一个[性能分析报告文件](性能分析报告文件.md)以存储当前游戏的性能数据。

# 语法
<code>perf start</code>
   开始长为10秒的性能测试记录。

<code>perf stop</code>
   在10秒结束前提前停止记录。
