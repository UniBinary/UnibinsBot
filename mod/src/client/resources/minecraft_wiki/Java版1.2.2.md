# Java版1.2.2

*页面ID: 29970* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.2.2**是的一次次要更新，发布于2012年3月1日<ref></ref>，修复了一些世界生成问题。此版本兼容1.2.1的服务端。

# 修复
* *修复了3个漏洞**
* 修复了白桦、云杉、高橡树和沼泽树的生成问题。
* 修复了巨型蘑菇的生成问题。
* 雪现在又一次会出现在地图上了。 </onlyinclude>
