* *Alpha v1.2.3**是的一次次要更新，发布于2010年11月23日，进行了一些更改和修复。

# 新内容
* *常规**
* 玩家[坐标](坐标.md)现在显示在[调试屏幕](调试屏幕.md)中。

# 更改
# = 方块 =
* *[树叶](树叶.md)**
* 现在又会腐烂了。

# = 游戏内容 =
* *[调试屏幕](调试屏幕.md)**
* 不再作为一个选项而永久显示，现在需要按住才能显示。

* *[多人游戏](多人游戏.md)**
* 新的多人游戏特性：
* * 加入了攻击其他[实体](实体.md)的能力：玩家可以伤害[动物](动物.md)、[攻击型生物](攻击型生物.md)、[船](船.md)、[矿车](矿车.md)或者其他[玩家](玩家.md)。
* * 坠落、溺水和着火现在会对玩家造成伤害。
* * 在多人游戏中吃东西会回复[生命](生命.md)。
* * 玩家死亡后会重生。
* * 加入玩家和生物受伤时的动画。
* * 玩家和生物着火时身上出现火。

# 修复
* *修复了2个漏洞**
* 修复了一个与光照有关并导致崩溃的漏洞。
* 玩家在船和矿车中时，地形可以正常更新。</onlyinclude>
