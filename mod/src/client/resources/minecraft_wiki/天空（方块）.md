* *天空（Sky）**是一种用于[大厅](大厅.md)结构的[方块](方块.md)。

# 生成
# = 自然生成 =
天空会在[大厅](大厅.md)结构中生成。

# 获取
天空不能在生存模式中正常获得，但可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)获得。

# 破坏
天空不能被挖掘破坏。

天空被破坏后不会掉落。

# 用途
天空始终被渲染成与其方块所在维度的天空效果相同的视觉效果。

# = 光源 =
天空可以发出等级为15的光照。
