# 灾厄巡逻队

*页面ID: 37138* | *来源: Minecraft Wiki*

[thumb|right|灾厄巡逻队](File:Illager patrol.png.md)
* *灾厄巡逻队（Pillager Patrol）**是由一群自然生成的[掠夺者](掠夺者.md)组成的队伍。

# 生成
灾厄巡逻队是自然生成的[掠夺者](掠夺者.md)队伍，其中一个掠夺者将成为[袭击队长](袭击队长.md)。袭击队长会在头上顶着一面[不祥旗帜](不祥旗帜.md)。其他灾厄村民会跟随队长。

掠夺者的尝试生成次数为<math>\lceil d \rceil + 1</math>，其中<math>d</math>表示[区域难度](区域难度.md)。

灾厄巡逻队含有2-5个掠夺者。

灾厄巡逻队只会在游戏时间达到100分钟（5个游戏日）后自然生成。若此条件满足，系统每隔10-11分钟会有20％概率尝试生成一支巡逻队。

灾厄巡逻队在关闭[游戏规则](游戏规则.md)或关闭[生成事件](生成事件.md)<code>minecraft:pillager_patrols_event</code>时不会自然生成。

# == Java版 ==
如果生成时[主世界](主世界.md)不是白天，则生成失败。先在主世界内选择一名随机玩家，若这名玩家处于[旁观模式](旁观模式.md)，或者以该玩家所在[子区块](子区块.md)为中心的5×5×5子区块范围内[存在村庄](兴趣点#村庄.md)，则生成失败。

接下来将玩家所在位置在X轴与Z轴上分别偏移24-47格作为生成位置。如果生成位置[方块光照](亮度#方块光照.md)大于8、以生成位置为中心21×21×21的区域未完全加载，或者生成位置位于[蘑菇岛](蘑菇岛.md)，则生成失败。

接下来按照上文给出的尝试生成次数开始生成掠夺者。每次生成时，实际生成位置将垂直偏移到最高的除[树叶](树叶.md)外的阻止运动方块或[流体](流体.md)的位置，并且每次生成后都会在X轴与Z轴上分别偏移0-5格。如果首次生成掠夺者时生成失败则整个生成过程中止并失败。

# == 基岩版 ==
灾厄巡逻队会在玩家周围24-48方块远的地方生成。当玩家位于村庄内时，它们则会在离玩家48方块以外的地方生成。它们会在主世界除蘑菇岛和深暗之域外的生物群系中生成。

灾厄巡逻队只在固体方块表面上生成。在简单难度下，它们只能在亮度小于等于7的地表生成。在普通和困难难度下，它们可以在任何亮度下生成。

# 行为
[thumb|right|一支灾厄巡逻队警戒地注视着一个村民](File:Patrol looking villager.png.md)
灾厄巡逻队会四处徘徊着寻找村民，并攻击附近的[玩家](玩家.md)、成年[村民](村民.md)、[铁傀儡](铁傀儡.md)和[流浪商人](流浪商人.md)。巡逻队成员会警戒地注视一名正盯着它们或吸引了它们注意的玩家。若一个玩家距离巡逻队小于10个方块，它们将装填弩并攻击该玩家。如果玩家逃跑，它们会继续追击，直到该玩家死亡或逃到离它们大于等于10方块的地方。

任何不随巡逻队生成的[灾厄村民](灾厄村民.md)、[劫掠兽](劫掠兽.md)或[女巫](女巫.md)都可以在离队长足够近时加入巡逻队。加入了巡逻队的唤魔者、幻术师和女巫会四处徘徊，但不会像其他巡逻队成员一样寻找目标。然而，唤魔者和幻术师仍会施展魔法来攻击生物。

如果一个带有<code>[Johnny](卫道士#“Johnny”卫道士.md)</code>标签的卫道士加入巡逻队队伍，并且对一个生物产生敌意，会使队伍里所有成员攻击该生物。

若队内的其中一个掠夺者受到其他生物的攻击，则该掠夺者10格距离内的所有掠夺者都会对此生物展开攻击。该现象可以在巡逻队与发起攻击的生物之间的距离不超过64格时发生。

袭击队长在死亡时总会掉落一个[不祥旗帜](不祥旗帜.md)。
