# 基岩版独有特性

*页面ID: 14271* | *来源: Minecraft Wiki*

此页面是独有特性列表。

# 常规
; [附加包](附加包.md)
* 用于改变游戏方块、物品以及实体的外观。
* * 行为包，类似于Java版的数据包。可以添加或更改实体、物品、方块、脚本、生物生成规则等内容。
* * [资源包](资源包.md)，拥有与Java版相近的用途。可以更改方块纹理；更改粒子纹理与配置；更改实体纹理、模型、动画；更改音效与音乐；更改语言文件。但暂时无法为原版方块添加自定义方块模型。
* * 世界模板可以用于从外部导入一个世界。

; [RenderDragon](RenderDragon.md)
* 基岩版独有的图形渲染引擎。
* 可以启用延迟渲染功能。
* 兼容Windows绝大多数的现代设备以及Android 9及更高版本的GLES 3.1设备。<ref>https://learn.microsoft.com/en-us/minecraft/creator/documents/deferredlighting?view=minecraft-bedrock-stable</ref>

; 光线追踪和PBR
* 仅在Windows版可用。
* 点击键可以开启/关闭光线追踪。
* 允许内容创作者使用光线追踪和PBR功能创作。
* 兼容性：
# 显卡：支持DirectX以及实时光线追踪渲染的任何显卡，例如NVIDIA GeForce® RTX 20系列或更高，以及AMD Radeon™ RX 6000系列或更高。
# 操作系统：64位Windows 10操作系统，以及最新的硬件驱动。
# 硬件：仅PC平台可用，不支持VR和混合现实设备。
# CPU：Intel Core® i5或更高。
# 内存：8GB或更高。
# Minecraft版本：1.16.200或更高。

; UI
* 具有两个UI框架：Json UI与[Ore UI](Ore UI.md)。
* * Json UI由数据驱动，并且可由资源包自定义；Ore UI暂不支持由资源包定义。
* 两种UI布局：携带版（Pocket）和经典（Classic）。

; 方块选择
* 有两种选择：方块高亮和显示方块轮廓。

; 教育版特性
* 来自[化学更新](化学更新.md)的特性。

; [市场](市场.md)
* 支付货币[16px|link=](File:MCoin.png.md)Minecoin以购买社区作品。

# 游戏机制
; 方块摆放机制
* 如果玩家距离地面一定高度，玩家面朝斜下方向时，可直接在脚下的方块前面摆放方块，而无需对准脚下方块的侧面再摆放。该特性是为了方便触屏操作的玩家而设计的。
* 如果玩家长按鼠标右键或手柄左扳机，可以朝玩家对应的一个方向连续摆放方块，不会因为视角转向而朝其他方向摆放方块。

; [魔咒](魔咒.md)
* [穿刺](穿刺.md)
* * 位于雨中或水中的生物都受此影响，而不仅是水生生物。
* [穿透](穿透.md)
* * 穿透V或更高的等级仍会使射出的箭穿过实体。
* [激流](激流.md)
* * 会造成喷溅伤害（可以多次进行）。
* [锋利](锋利.md)
* * 每等级给予1.25的伤害。

; [灾厄巡逻队](灾厄巡逻队.md)
*
* 在简单难度下，巡逻队只会生成亮度等级低于或等于7的地方；而在普通和困难难度下，会无视亮度生成。

; [袭击](袭击.md)
* 相比Java版，每波的生物数量有所不同。
* 袭击队长不会生成。
* 村庄里的[钟](钟.md)会自动响起。

; [状态效果](状态效果.md)
* [袭击之兆](袭击之兆.md)
* * 获得袭击之兆时会播放动画。
* * 更高级别的效果不会影响袭击事件的生物生成。
* [中毒（致命）](中毒（致命）.md)
* * [鹦鹉](鹦鹉.md)食用[曲奇](曲奇.md)后会获得。
* * 能够伤害并杀死亡灵或非亡灵生物。
* [村庄英雄](村庄英雄.md)
* * 获得时会有动画效果。
* * 正常获得时等级总为1。
* * 村民不会给予玩家礼物。

# 图像
* 与[Java版](Java版.md)相比，[基岩版](基岩版.md)的游戏画质更生动、更流畅。
* [燃烧](燃烧.md)的生物带有的火焰动画根据玩家视角而变换角度且燃烧较慢。
* 物理阴影的方向取决于太阳的位置。
* 日出、日落时分，云层会呈现橘红色。
* [水](水.md)带有平滑光照。
* 发光方块，例如正在工作的熔炉，发光的红石矿石，荧石和熔岩，在它们的四周没有光影。
* 窒息的动画不同。
* 下界传送门的进入动画不同。
* 玩家的燃烧动画不同。
* 熔岩的动画不同。
* 玩家睡眠动画不同。
* TNT爆炸的粒子效果更加有像素感，因为原有纹理被压缩成一个普通粒子效果的大小。

# 世界生成
; [恶地](恶地.md)
* 友好生物可以生成在风蚀恶地里。

; [埋藏的宝藏](埋藏的宝藏.md)
* 可以生成在高海拔的[石岸](石岸.md)里。

; [珊瑚礁](珊瑚礁.md)
* 包含了安山岩、花岗岩、闪长岩、失活的珊瑚扇和失活的珊瑚块。
* 使用NBT结构生成。

; [沙漠神殿](沙漠神殿.md)
* 如果在一个峡谷或河流生成，神殿的地板会被峡谷或河流的底部替换，而不是TNT。
* 如果生成在[条纹之地](条纹之地.md)上，它的地基会高于基岩层，不像在沙漠中那样生成在空气中时不会有一个很高的地基。

; [冻洋（旧版）](冻洋（旧版）.md)
* 未使用的生物群系，和冻洋相似但不会生成冰山和兔子。

; [丛林](丛林.md)
* 会生成更少的高大丛林树。

; [雪原](雪原.md)
* 除[流浪者](流浪者.md)以外的敌对生物不会自然生成。
* * [刷怪笼](刷怪笼.md)会照常运作。

; [巨型蘑菇](巨型蘑菇.md)
* 在沼泽自然生成。

; [雪屋](雪屋.md)
* 携带着[浮冰](浮冰.md)生成而不是冰。
* 如果在条纹之地上生成，它将在水下的海底的基岩层生成，替代了一些基岩，并用石砖替代Y=-64的基岩层。

; [要塞](要塞.md)
* 图书馆的吊灯使用橡木栅栏而不是桦木栅栏。
* 个人房间不生成[铁门](铁门.md)和石质[按钮](按钮.md)。
* 拥有更大的概率生成于村庄的水井下方，[末影之眼](末影之眼.md)追随终点在村庄时更容易发现要塞位置。
* 每个世界能够产生的要塞数量是随机的，而不是每个世界只有128个。
* * 3个要塞生成于以0,0为中心的一环，其他地方要塞随机生成在世界各地。

; [超平坦世界](超平坦世界.md)
* 名为****，在[创建新的世界](创建新的世界.md)屏幕的“”设置中开启该选项后可以选择超平坦世界预设，默认是“”。
* 无法在游戏中自定义世界生成（但仍然可以通过使用外部编辑器在存档的文件里更改<code>FlatWorldLayers</code>以实现自定义）。
* 主世界没有结构和地物生成。

; [树](树.md)
* 一棵树的树干上可能产生[藤蔓](藤蔓.md)，使它看起来好像垂死一般。
* * 这包括由[树苗](树苗.md)长出的树。

# = 方块 =
; [床](床.md)
* 物品栏中显示2D物品模型。

; [仙人掌](仙人掌.md)
* 当一个告示牌放置在它旁边时会被破坏。

; [炼药锅](炼药锅.md)
* 共有六级水位，每级水位相当于Java版的一半。
* 水的颜色可以通过添加染料来改变。
* * 颜色可混合。
* 可用于皮革套装的染色。
* 可用水瓶加水。
* 可储存药水。
* * 将两种不同流体混合（如水和熔岩，不同属性的药水）会发出爆炸声，并且流体会消失。
* * 炼药锅里的药水会发出其粒子效果。
* * 炼药锅里的药水可用于制作药水箭。

; [箱子](箱子.md)

* 对着除火把花和凋灵玫瑰之外的小型花使用骨粉会使其本身生长在其周围。

* 只有袭击中的卫道士可以破坏门，其他情况下不会破坏门。

* 持有三叉戟的溺尸在目标过近时会近战攻击。
* 会主动攻击[雪傀儡](雪傀儡.md)。
* 溺尸游泳动画与玩家相同。
* 皮肤中的头部纹理比Java版更厚。
* 在不完整方块上有寻路问题，会跳着移动，且不会攻击。

; [潜影贝](潜影贝.md)
* 可以使用任意染料对壳进行染色。

; [骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)和[焦骸](焦骸.md)
* 在水下不会射箭，而是改为近战。

; [凋灵骷髅](凋灵骷髅.md)
* 当用命令强制取代其武器成为[弓](弓.md)，其手上的弓会立刻消失。

* 拥有更多变种
* * 骷髅蜘蛛骑士（骷髅骑乘蜘蛛或洞穴蜘蛛）
* ** 除了积雪的生物群系、[下界](下界.md)、[沙漠](沙漠.md)、[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)以外的所有生物群系中生成的蜘蛛和洞穴蜘蛛有1%的概率生成骷髅蜘蛛骑士。
* * 流浪者蜘蛛骑士（流浪者骑乘蜘蛛或洞穴蜘蛛）
* ** 在积雪的生物群系中生成的蜘蛛或洞穴蜘蛛有0.8%的概率生成流浪者蜘蛛骑士。
* * 凋灵骷髅蜘蛛骑士（凋灵骷髅骑乘蜘蛛或洞穴蜘蛛）
* ** 在下界中使用命令、[刷怪蛋](刷怪蛋.md)和[刷怪笼](刷怪笼.md)生成的蜘蛛和洞穴蜘蛛有0.8%的概率生成凋灵骷髅蜘蛛骑士。
* * 沼骸蜘蛛骑士（沼骸骑乘蜘蛛或洞穴蜘蛛）
* ** 在沼泽和红树林沼泽中生成的蜘蛛和洞穴蜘蛛有0.8%的概率生成沼骸蜘蛛骑士。
* * 焦骸蜘蛛骑士（焦骸骑乘蜘蛛或洞穴蜘蛛）
* ** 在沙漠中生成的蜘蛛和洞穴蜘蛛有0.8%的概率生成焦骸蜘蛛骑士。

* 旧版本的村民依然存在，但尝试生成时会立即死亡并原地生成一个平原村民。

* 铁傀儡的生成条件为计算村民和床的数量，因此村民的交流，以及村民被僵尸恐吓并不会提升铁傀儡的生成的频率。
* 若成功入睡，则会在黎明醒来时回满生命值。

* 主动攻击[铁傀儡](铁傀儡.md)和[雪傀儡](雪傀儡.md)。
* 被其他女巫、[劫掠兽](劫掠兽.md)和[灾厄村民](灾厄村民.md)攻击后会还击。

; [凋灵](凋灵.md)
* 在普通或困难难度下，当生命值降到50%时，会生成3-4只[凋灵骷髅](凋灵骷髅.md)。
* 当生成、生命值降到50%或被杀死时有新的动画。
* 拥有新的音效。
* 在不同难度中血量不同。
* 更多的攻击方式。

; [僵尸](僵尸.md)和[尸壳](尸壳.md)
* 没有概率自然生成鸡骑士，因为在基岩版幼年僵尸或幼年尸壳有不同的行为。
* 会主动攻击[雪傀儡](雪傀儡.md)。
* 带有天然装备的僵尸在水中转化为溺尸以及尸壳转化为僵尸时，身上的装备均会掉落，且是无损的，除非它们使用过它。

; [僵尸村民](僵尸村民.md)
* 没有概率自然生成鸡骑士，因为在基岩版幼年僵尸村民有不同的行为。
* 僵尸村民生成时不会携带装备。<ref></ref>
* 生成于雪屋地下室内的僵尸村民的职业是农民而不是牧师。
* 会主动攻击[雪傀儡](雪傀儡.md)。
* 旧版本的僵尸村民依然存在，但尝试生成时会立即死亡并原地生成一个新版本平原僵尸村民。

; [僵尸猪灵](僵尸猪灵.md)
* 存在骑士变种，但无法按预期生成。
* 杀死[村民](村民.md)后不会将其感染为[僵尸村民](僵尸村民.md)。

; [狐狸](狐狸.md)
* 自然生成时叼着的部分物品的概率与Java版不同。
* 狐狸有概率生成在[针叶林](针叶林.md)中。

; [鳕鱼](鳕鱼.md)
* 可以自然生成于[冻洋](冻洋.md)及其变种。

; [熊猫](熊猫.md)

* 成年熊猫偶尔会坐着。
