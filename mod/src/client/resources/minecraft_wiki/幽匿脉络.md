# 幽匿脉络

*页面ID: 90364* | *来源: Minecraft Wiki*

}}

* *幽匿脉络（Sculk Vein）**是一种会由[幽匿催发体](幽匿催发体.md)产生的薄层方块。

# 生成
# = 自然生成 =
幽匿脉络自然生成于[深暗之域](深暗之域.md)生物群系。

# = 幽匿催发体 =

死后会掉落[经验](经验.md)的[生物](生物.md)在距[幽匿催发体](幽匿催发体.md)半径/内的位置死亡时，该生物死亡位置周围会生成幽匿脉络（若满足放置条件）。

# 获取
幽匿脉络的物品形式只能通过使用具有[精准采集](精准采集.md)的工具挖掘破坏幽匿脉络获得。

# 破坏
挖掘幽匿脉络的合适工具是锄。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，幽匿脉络被破坏后不会掉落。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，幽匿脉络被破坏后会掉落自身。

# 用途
幽匿脉络目前仅用于装饰。
