# 力量（魔咒）

*页面ID: 42218* | *来源: Minecraft Wiki*

力-{}-量}}

* *力量（Power）**是一种用于[弓](弓.md)的[魔咒](魔咒.md)，能增加射出的[箭](箭.md)造成的伤害。

# 获取

力量V对于其所有可附魔物品，附魔需要的[附魔等级](附魔等级.md)超过了30级，因此无法从[附魔台](附魔台.md)获取。

力量V可以通过在[铁砧](铁砧.md)合并2个具有力量IV的物品来获得。具有力量V的附魔书可以与[图书管理员](图书管理员.md)交易获得。

# 用途

具有力量魔咒的弓发射的箭，基础伤害增加<math>0.5+0.5p</math>，其中<math>p</math>为力量魔咒等级。

具有力量魔咒的弓发射的箭，最终伤害变为<math>1.25d+0.25pd</math>，其中<math>d</math>为修正前伤害，<math>p</math>为力量魔咒等级。
