# 玻璃瓶

*页面ID: 7513* | *来源: Minecraft Wiki*

* *玻璃瓶（Glass Bottle）**是一种装取[水](水.md)、[药水](药水.md)、[龙息](龙息.md)和[蜂蜜](蜂蜜.md)的物品。

# = 返还 =
饮用[药水](药水.md)或[蜂蜜瓶](蜂蜜瓶.md)会返还空玻璃瓶。投掷[喷溅药水](喷溅药水.md)或者[滞留药水](滞留药水.md)则不会返还玻璃瓶，<ref></ref>。

对着[炼药锅](炼药锅.md)使用水瓶、会将盛有的液体倒进炼药锅里，并返还空玻璃瓶。

对[泥土](泥土.md)、[缠根泥土](缠根泥土.md)或[砂土](砂土.md)水瓶、喷溅型水瓶或滞留型水瓶可使其转变为[泥巴](泥巴.md)，并返还空玻璃瓶。使用[发射器](发射器.md)发射水瓶也能生效，但发射喷溅型水瓶和滞留型水瓶不能。

使用蜂蜜瓶合成[糖](糖.md)或[蜂蜜块](蜂蜜块.md)会留下空玻璃瓶。

# 用途
# = 收集液体 =
# == 水 ==
手持玻璃瓶对着装有水的炼药锅、水源<ref></ref>会获得一个水瓶。

通过将玻璃瓶放入[发射器](发射器.md)，并将发射器的发射口对准水源激活可以取得水瓶，但炼药锅无法做到。<ref></ref>

如果对着水源装水，水不会有变化；如果对着炼药锅装水，那么炼药锅会减少的水量。

# == 药水 ==

手持玻璃瓶对着装有药水的炼药锅会得到对应的药水，完成该动作后炼药锅里的药水会减少。

# == 龙息 ==
手持玻璃瓶对着[末影龙火球](末影龙火球.md)或[末影龙栖息](末影龙#栖息.md)生成的紫色“药水云”玻璃瓶会以[龙息](龙息.md)填满玻璃瓶。

# == 蜂蜜 ==
如果[蜂巢](蜂巢（方块）.md)或[蜂箱](蜂箱.md)已经充满了蜂蜜，手持玻璃瓶对其或使用装有玻璃瓶的发射器的发射口对准蜂巢/蜂箱可以取得蜂蜜瓶，蜂巢/蜂箱的蜂蜜会清零。
