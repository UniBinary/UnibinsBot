* *杜鹃树（Azalea Tree）**是一种通常生成于[繁茂洞穴](繁茂洞穴.md)上方地表的植被[地物](地物.md)。

# 描述
杜鹃树高5-8格。树干由[橡木原木](橡木原木.md)组成，树干高处会朝一个方向歪斜。树冠由[杜鹃树叶](杜鹃树叶.md)和[盛开的杜鹃树叶](盛开的杜鹃树叶.md)组成，呈不规则的团状，且朝着树干偏移的方向延伸。

# 生成
# = 自然生成 =
[缩略图|右|自然生成的杜鹃树|200px](File:Azalea Tree with Roots.png.md)
杜鹃树自然生成于[繁茂洞穴](繁茂洞穴.md)生物群系上方的地表，或是繁茂洞穴中空间充足的地方。自然生成的杜鹃树下方会出现大量团簇状的[缠根泥土](缠根泥土.md)和一些[垂根](垂根.md)。生成在地表的杜鹃树下面的缠根泥土会一直延伸到下面的繁茂洞穴顶部，并且可能会被洞穴或含水层替换。

# = 人为生成 =
对[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)[骨粉](骨粉.md)可以使其生长为杜鹃树，并将其下方1格的方块转变为缠根泥土。
