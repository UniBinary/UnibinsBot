# 携带版0.9.0.b12

*页面ID: 28518* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.9.0 alpha build 12 (RC4)**是[v0.9.0 alpha](携带版0.9.0.md)的第12个测试版，也是第4个发布候选，发布于2014年6月30日，修复了一些漏洞。

# 更改
# = 常规 =
* *性能**
* 更改为批量处理SetEntityMotion、EntityPos和HeadRotation包（从以前的每秒处理3000个包到150个）。

# 修复
* *修复了13个漏洞**
* 删除区块时的崩溃。
* 内存损坏问题。
* Android平台上不会重新使用图像缓冲区，导致异常出现三角形和空洞的问题。
* 加载玩家正在骑乘的世界时的崩溃。
* 骑乘时退出世界的崩溃。
* 多人游戏玩家的同步问题。
* 实体被错误添加至客户端。
* 客户端上出现的一些关于方块实体的漏洞。
* 客户端上的生成位置问题。
* 重置重生点会使玩家生成位置变高。
* 无法在多人游戏中使用交互按钮。
* 客户端上放置的铁轨会被破坏（错误朝向）。
* 客户端上关于箱子的问题。</onlyinclude>
