# PlayStation 4版1.91

*页面ID: 59650* | *来源: Minecraft Wiki*

* *1.91**是[PlayStation 4版](PlayStation 4版.md)的一个更新，发布于2019年6月3日，加入了过去三个版本中没有加入的[村庄与掠夺](村庄与掠夺.md)特性的其余部分。<ref></ref>

# 新内容
# = 方块 =
* *[木桶](木桶.md)**
* 可以作为类似[箱子](箱子.md)的储存方块。
* 出现在[村庄](村庄.md)的渔夫小屋。
* 和箱子不同，在上方有方块时也可以打开。

* *[钟](钟.md)**
* 具有[音效](音效.md)的装饰性方块。
* 当右击使用时，出现被敲击的声音和动画。它同样可以用弹射物和红石信号来触发。
* 自然生成于村庄的会合点。

* *[高炉](高炉.md)**
* 用于烧炼[矿石](矿石.md)，[烧炼](烧炼.md)速度为普通[熔炉](熔炉.md)的两倍。
* 自然生成于村庄的[盔甲匠](盔甲匠.md)小屋。

* *[营火](营火.md)**
* 一个不会传播火的装饰性[方块](方块.md)。
* 可同时烹饪四种食物而无需燃料，但需要30秒时间。
* 可被点燃或熄灭。
* 当被放置到[干草捆](干草捆.md)的顶部时，出现烟雾粒子效果。

* *[制图台](制图台.md)**
* 可在村庄中，尤其是[制图师](制图师.md)的房屋中找到。
* 用于复制，升级，锁定[地图](地图.md)的方块。
* 被锁定的地图无法修改。

* *[堆肥桶](堆肥桶.md)**
* 可用于生产[骨粉](骨粉.md)。
* * 在堆肥桶上使用物品有机会添加1级堆肥，共7级。堆肥机达到7级后，将转为8级，即收获阶段，使用时产出1[骨粉](骨粉.md)。
* * 有时物品将被消耗而不增加一个等级。提升级别的概率取决于项目的质量：较大（可能指营养）或精心制作的项目在使用时提升等级的概率较高（例如[海带](海带.md)有10%的概率，[南瓜派](南瓜派.md)则有100%的概率）。

* *[制箭台](制箭台.md)**
* 可在[制箭师](制箭师.md)的房屋中找到。
* 使用功能将会在之后的更新中添加。

* *[砂轮](砂轮.md)**
* 一个可以移除物品[附魔](附魔.md)的方块。
* 可以通过把物品组合在一起来[修复](修复.md)。
* 自然生成于[武器匠](武器匠.md)的房屋。

* *[灾厄旗帜](灾厄旗帜.md)**
*  一种独特的[旗帜](旗帜.md)，在[掠夺者前哨站](掠夺者前哨站.md)能够找到，它会在[袭击队长](袭击队长.md)的头上顶着。

* *[锻造台](锻造台.md)**
* 可在[工具匠](工具匠.md)的房屋中找到。
* 玩家功能将在以后的更新中添加。

* *[烟熏炉](烟熏炉.md)**
* 在村庄中可被找到，尤其是屠夫的房屋中。
* 一种用于烧制食物，比普通熔炉速度更快的方块。

* *[切石机](切石机.md)**
* 可在[石匠](石匠.md)的房屋中找到。
* 用于制作与各种石头相关的物品和方块。

* *[甜浆果丛](甜浆果丛.md)**
* 可发现于云杉树生物群系及其变种。
* 可用[甜浆果](甜浆果.md)来种植。
* 有四种生长阶段：“幼苗”“无果实”“少量果实”和“成熟”。
* 在生长时掉落1-2个甜浆果，成熟后掉落2-3个。
* 它们在成长的各个阶段都能减缓所有实体的行动（除[狐狸](狐狸.md)外）。
* 任何实体都可以站在里面，但如果实体没有站住，只要甜浆果丛生长过幼苗期，它们就会造成类似于[仙人掌](仙人掌.md)的伤害（除[狐狸](狐狸.md)外）。

# = 物品 =
* *[甜浆果](甜浆果.md)**
* 新的[食物](食物.md)。
* 能在[甜浆果丛](甜浆果丛.md)中获取。

# = 生物 =
* *[袭击队长](袭击队长.md)**
* 在[灾厄巡逻队](灾厄巡逻队.md)和[掠夺者前哨站](掠夺者前哨站.md)附近生成。
* 是一个头顶着特殊旗帜的[掠夺者](掠夺者.md)或[卫道士](卫道士.md)。
* 当被杀死时，给予玩家[不祥之兆](不祥之兆.md)效果。

* *[劫掠兽](劫掠兽.md)**
* 有盔甲和[鞍](鞍.md)的大型、敌对的公牛状生物。
* 非常难以对付。
* 能破坏掉[农作物](农作物.md)和[树叶](树叶.md)。
* 在[袭击](袭击.md)中生成。

* *[流浪商人](流浪商人.md)**
* 一种定期出现在村庄集合点的村民，在游戏中停留2-3天（40-60分钟的现实时间）。这个商人提供从不同[生物群系](生物群系.md)带来的多种多样的物品，随机的[染料](染料.md)，和其他稀有的材料。
* 有两只[行商羊驼](行商羊驼.md)作伴。

# = 世界生成 =
* *[竹林](竹林.md)**
* 新的丛林[生物群系](生物群系.md)的变种。
* 含有竹笋，[丛林神庙](丛林神庙.md)和[熊猫](熊猫.md)。

* *[掠夺者前哨站](掠夺者前哨站.md)**
* [掠夺者前哨站](掠夺者前哨站.md)会在与[村庄](村庄.md)同样的群系中生成，掠夺者会在前哨站附近生成。

# = 游戏内容 =
* *[袭击](袭击.md)**
* 于玩家拥有[不祥之兆](不祥之兆.md)效果进入[村庄](村庄.md)时触发。
* 一大组来袭击村庄和屠杀村民的[灾厄村民](灾厄村民.md)。
* 袭击以波次出现——袭击的波次和时长分别是：简单难度3次，普通难度5次，困难难度7次。
* 一个类似boss血量条会告知玩家剩余的敌人数量。
* 一种类似战斗号角的声音将在以灾厄村民为中心，每波袭击开始时播放。

* *[灾厄巡逻队](灾厄巡逻队.md)**
* 一组自然生成在主世界，包括2-5只[灾厄村民](灾厄村民.md)的队伍。
* 其中一个灾厄村民会成为[袭击队长](袭击队长.md)。

* *[状态效果](状态效果.md)**
* 加入了和效果。

* *[音效](音效.md)**
* 加入了一些[灯笼](灯笼.md)的音效。

* *[交易](交易.md)**
* 改进了交易系统和界面，增加了村民补货的功能。

# = 常规 =
* *奖杯**
* 加入了扩展包10，其中包含6个新奖杯：
* * 杀死劫掠兽！——击杀一只劫掠兽。
* * 低买高卖——以最好的价格交易。
* * 解除附魔——使用砂轮从一个附魔物品中获得经验。
* * 我们被攻击了！——触发一次掠夺者袭击。
* * 拉响警报！——当村庄里有一名敌人时敲响钟。
* * 感觉不太妙——击杀一名掠夺者队长。

# 更改
# = 方块 =
* *[熔炉](熔炉.md)**
* 现在储存由漏斗清空时的熔炼物品的经验。

* *[漏斗](漏斗.md)**
* 现在可以用来填充和清空堆肥桶。

* *[讲台](讲台.md)**
* 在翻页时发出红石信号。

* *[脚手架](脚手架.md)**
* 将脚手架可向外延伸的数量从最初的4个增加到6个。

# = 物品 =
* *[喷溅水瓶](喷溅药水#喷溅型水瓶.md)**
* 现在能熄灭[营火](营火.md)。

# = 生物 =
* *[掠夺者](掠夺者.md)**
* 现在不再攻击幼年村民。
* 现在在袭击中生成的掠夺者具有特殊的掉落物。

* *[卫道士](卫道士.md)**
* 现在不再攻击幼年村民。
* 现在在袭击中生成的卫道士具有特殊的掉落物。
* 袭击中生成的卫道士可以破门。

* *[唤魔者](唤魔者.md)和[恼鬼](恼鬼.md)**
* 现在不再攻击幼年村民。

* *[铁傀儡](铁傀儡.md)**
* 现在在[掠夺者前哨站](掠夺者前哨站.md)的笼子内生成。
* 现在在每个[村庄](村庄.md)都会生成一个铁傀儡。
* 改进寻路机制。

* *[猫](猫.md)**
* 现在根据村庄床的数量生成。
* * 村庄中每四张床生成一只猫。
* * 每个村庄最多生成10只猫。

* *[雪傀儡](雪傀儡.md)**
* 它们现在在营火上行走时会受到伤害。

* *[村民](村民.md)**
* 新村民的行为：
* * 实现了一些新村民的日程。
* * 实现了新村民的睡眠行为。
* * 村民现在会在村庄边缘漫游。
* * 村民在白天下雨时会试图寻找一扇门，但在晚上会找到它们的床。
* * 更新并改进寻路。
* * 村民现在有了一个可视化的交易系统，它们将持有它们想要交易的物品。
* * 村民有了新外观来显示它们的等级、职业和生物群系。
* * 村民现在将在村庄里的集合点周围聚集在一起。
* * 图书管理员将检查书架。
* * 村民会根据村庄里现有的工作点转换职业。
* ** 村民们现在与床和相应的工作点互动。
* 加入了石匠、绿色外观（傻子），无业游民的职业。
* 旧村民会变成新村民。
* 现在可以通过在床上睡觉来恢复生命。

* *[僵尸村民](僵尸村民.md)**
* 现在有了新外观来显示它们的生物群系和职业。
* 旧僵尸村民会变成新僵尸村民。
* 加入了新的音效。

* *[凋灵骷髅](凋灵骷髅.md)**
* 加入了新的音效。

# = 世界生成 =
* *[村庄](村庄.md)**
* 不同的生物群系的村庄有了新外观。
* 增加了村庄工作点和聚集点。
* 房屋的数量取决于床。
* 针叶林村庄现在更为常见。
* 由于新村庄的变化，僵尸村庄被移除。

# = 常规 =
* *[选项](选项.md)**
* 游戏指南现在已经更新了有用的村庄与掠夺知识。
* 更新了游戏指南中的脚手架部分，更改从脚手架上可以延伸多少脚手架的图片。

* *[纹理更新](纹理更新.md)**
* 为方块与物品加入了更多新纹理，包括状态效果的图标。
