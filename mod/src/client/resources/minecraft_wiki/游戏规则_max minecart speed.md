# 游戏规则/max minecart speed

*页面ID: 139318* | *来源: Minecraft Wiki*

* *max_minecart_speed**是控制[矿车](矿车.md)在[铁轨](铁轨.md)上可抵达的最大速度的[游戏规则](游戏规则.md)。

# 行为
此游戏规则可以更改矿车沿轨道移动的最大速度，单位为格/秒。

在陆地铁轨上运动时，矿车最大速度约为<code>-{}-0.06+*此游戏规则的值*&divide;20</code>格/刻。

水中的矿车沿轨道移动的最大速度受此游戏规则的影响只有一半：<code>-{}-0.06+*此游戏规则的值*&divide;40</code>格/刻。

此速度表示沿轨道移动的矿车**每刻**位移前后位置间的[欧几里得距离](欧几里得距离.md)。

受限于加速条件、空气阻力（或水阻力）等因素，矿车不一定能达到最大速度。

max_minecart_speed的值不能低于1，不能高于1000。
