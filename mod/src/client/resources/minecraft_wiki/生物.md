# 生物

*页面ID: 41* | *来源: Minecraft Wiki*

[250px|right](File:Minecraft mobs preview.png.md)
[thumb|right|会在主世界生成的一些敌对生物。从左到右依次为：[[僵尸](File:OverWorld Monsters.png.md)、[蜘蛛](蜘蛛.md)、[末影人](末影人.md)、[苦力怕](苦力怕.md)、[骷髅](骷髅.md)、[溺尸](溺尸.md)、[女巫](女巫.md)和[史莱姆](史莱姆.md)]]
* *生物（Mob）**是指游戏世界中有生命的、可自主移动的一类[实体](实体.md)。术语“Mob”是Mobile或Mobile Entity的简写，表示可移动的实体。

# 生成

[不同的生物会依据自身对[[光照](File:Mob Habitat Collage.png.md)等级或[生物群系](生物群系.md)的需求，生成在不同的栖息地或[结构](结构.md)中|thumb]]
生物的生成有多种原因。许多生物能自然生成，但会受到[光照](光照.md)等级、[生物群系](生物群系.md)及环境的影响。生物通常会以同一种类成群生成，且总会在区块初次创建时出现。大部分成年友好生物以及[疣猪兽](疣猪兽.md)可以进行[繁殖](繁殖.md)。

一般来说，生物不会自然生成在上表面不完整的[方块](方块.md)、[基岩](基岩.md)、[水](水.md)或[熔岩](熔岩.md)上，不过水生生物能在水下生成，[炽足兽](炽足兽.md)可生成在熔岩表面，部分生物如[幻翼](幻翼.md)可以直接在空中生成。[刷怪笼](刷怪笼.md)是个例外，它能让生物在任何地方（包括[空气](空气.md)中）生成。

[雪傀儡](雪傀儡.md)、[铜傀儡](铜傀儡.md)和[凋灵](凋灵.md)需要玩家通过“构建”来生成。[铁傀儡](铁傀儡.md)既可以自然生成，也能由玩家构建生成。在少数情况下末影人也可能在放置方块时意外地构建生物。

[玩家](玩家.md)还可以使用[刷怪蛋](刷怪蛋.md)生成生物，在允许使用[命令](命令.md)的情况下，也能通过命令召唤。

# 行为

[右|缩略图|一只死亡时产生烟雾粒子的猪](File:Pig smoke death.png.md)

生物具备许多非生物实体所没有的游戏机制，像[受击后伤害免疫](受击后伤害免疫.md)、[状态效果](状态效果.md)、[属性](属性.md)、[着火时间](着火.md)、[呼吸](呼吸.md)等。生物死亡时，还会呈现出倒下并冒出烟雾的动画效果。

在Minecraft中，大多数生物都有特定的AI系统，因而拥有不同的行为和机制。当生物附近有玩家时，它们通常会随机游荡，并且一般会避免走到较高的方块上以防[摔落](摔落.md)。不少生物拥有先进的寻路系统，能让它们通过复杂路径到达目的地。

大多数生物能察觉到半径16格[方块](方块.md)内的其他生物，不过有些生物的感知范围更远。大多数生物可以被16个方块以外的玩家听到。

绝大多数生物的视线无法穿透大多数[固体方块](固体方块.md)，包括半透明方块，例如[冰](冰.md)、[玻璃](玻璃.md)或[玻璃板](玻璃板.md)。除了[玩家](玩家.md)和[监守者](监守者.md)，其他所有生物都不会主动在[铁轨](铁轨.md)上行走，除非被其他生物推挤。

# 生物列表
以下是依照生物性质分类的列表，其中“友好生物”和“敌对生物”类别是根据[Java版](Java版.md)中生物对攻击目标的选择方式划分的，生物能够造成伤害的方式不考虑其装备的物品具有的[荆棘](荆棘.md)魔咒。

# = 玩家 =
[玩家](玩家.md)是可被控制的生物，能影响生物的多种状态和效果同样也能作用于玩家。

# = 友好生物 =
友好生物不会主动攻击玩家，且绝大多数都不会因[难度](难度.md)设置而被清除。

; 无攻击行为，无伤害能力
以下生物没有任何造成伤害的能力。

; 无攻击行为，有伤害能力
以下生物的行为会对包括玩家在内的生物造成伤害，但不存在攻击行为。

; 有攻击行为，不攻击玩家
以下生物具备攻击能力，会主动攻击其他生物，但不会反击攻击它们的生物，且不会主动攻击或反击玩家。

; 条件敌对
以下生物具有攻击能力和敌对条件，在受到侵害时会反击加害者，包括玩家。由玩家建造的[铁傀儡](铁傀儡.md)永远不会攻击玩家。

# = 敌对生物 =

敌对生物是危险且具侵略性的生物，部分会阻止玩家入睡，在某些情况下还会攻击其他生物或相互攻击。

这些生物通常拥有不可忽视的杀伤能力，部分生物还具备受[难度](难度.md)影响的额外攻击方式。玩家杀死敌对生物获得的经验值奖励通常高于杀死友好生物。

[铁傀儡](铁傀儡.md)、[雪傀儡](雪傀儡.md)会主动攻击多数敌对生物。完整启动框架的激活的[潮涌核心](潮涌核心.md)会攻击所有敌对生物。拥有[队伍](队伍.md)的[潜影贝](潜影贝.md)会主动攻击除[恶魂](恶魂.md)外的任何非同队敌对生物。

除[潜影贝](潜影贝.md)、[猪灵](猪灵.md)、[疣猪兽](疣猪兽.md)和[末影龙](末影龙.md)外，敌对生物在[难度](难度.md)设为和平时会被移除。

除[史莱姆](史莱姆.md)、[岩浆怪](岩浆怪.md)、[幻翼](幻翼.md)、[守卫者](守卫者.md)、[远古守卫者](远古守卫者.md)、、、[嘎枝](嘎枝.md)和[末影龙](末影龙.md)外，敌对生物被攻击后会进行反击。

杀死任意一个除[监守者](监守者.md)外的敌对生物可以完成[进度](进度.md)“”，杀死每种除[监守者](监守者.md)外的敌对生物至少一次是完成[进度](进度.md)“”的条件之一。

Boss生物是拥有多种攻击手段、坚韧且极具破坏性、始终敌对的敌对生物，为玩家提供更长期、更危险和更大规模的战斗，并有相关[Boss栏](Boss栏.md)显示其生命值。其中只有[凋灵](凋灵.md)会阻止玩家入睡。

# 你知道吗
* Mojang曾表示，将[北极熊](北极熊.md)、[海龟](海龟.md)、[熊猫](熊猫.md)、[蜜蜂](蜜蜂.md)和[美西螈](美西螈.md)加入Minecraft的主要原因是它们在现实中濒临灭绝，希望通过这种方式引起玩家的关注。
* 被命名为“Dinnerbone”或“Grumm”的生物会上下颠倒、四脚朝天。
* 给一只[绵羊](绵羊.md)命名为“jeb_”，其羊毛会不停变色，但剪下的羊毛仍是原本的颜色。
* 给一个[卫道士](卫道士.md)命名为“Johnny”，它会攻击附近的所有生物，不过其他灾厄村民、恶魂、、与除外。这一特性致敬了电影《》。
* 尽管[牛](牛.md)、[鸡](鸡.md)、[村民](村民.md)有着较为明显的性别特征，但根据Jeb在访谈中的说法，Minecraft中只有玩家有性别，其他生物均设定为无性别。<ref>https://youtu.be/pDBf_IKEq3s</ref>
* [幻翼](幻翼.md)、[发光鱿鱼](发光鱿鱼.md)、[悦灵](悦灵.md)、[嗅探兽](嗅探兽.md)和[犰狳](犰狳.md)是通过公众投票加入游戏的生物，这几次投票分别在[MINECON Earth 2017](MINECON Earth 2017.md)、[Minecraft Live 2020](Minecraft Live 2020.md)、[Minecraft Live 2021](Minecraft Live 2021.md)、[Minecraft Live 2022](Minecraft Live 2022.md)和[Minecraft Live 2023](Minecraft Live 2023.md)举行。
* [铜傀儡](铜傀儡.md)是在Minecraft Live 2021生物投票中落选的生物，后在[铜器时代](铜器时代.md)中加入游戏，但其功能与初次提及时不同。
* 在[Meet the Nitwit](https://www.minecraft.net/article/meet-nitwit)文章中提到，[傻子村民](村民#傻子.md)和[蝙蝠](蝙蝠.md)是Minecraft中最“没用”的生物。
* 大部分生物在空闲状态下偶尔会看向附近非旁观模式的玩家，部分生物还会看向其他非玩家生物。
