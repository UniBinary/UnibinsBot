* *13w36b**是[Java版1.7.2](Java版1.7.2.md)的第2个快照，发布于2013年9月6日<ref></ref>，加入了统计信息，并修复了[13w36a](13w36a.md)里的漏洞和崩溃。

# 新内容
# = 常规 =
* *[统计](统计.md)**
* 加入了生物统计信息。

# 更改
# = 物品 =
* *[盔甲](盔甲.md)、[弓](弓.md)、[剑](剑.md)**
* 现在可以从[附魔台](附魔台.md)里得到[耐久](耐久.md)魔咒。

# = 常规 =
* *[设置](设置.md)**
* 稍微改进了超级秘密设置。
* * 按下时会发出一个随机的、音量很低的声音。
