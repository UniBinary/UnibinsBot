# Java版15w38a

*页面ID: 18352* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w38a**是[Java版1.9](Java版1.9.md)的第24个快照，发布于2015年9月16日<ref></ref>，加入了骷髅陷阱马和新的统计信息，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[马](马.md)**
* 加入了骷髅陷阱马。当玩家位于其10格以内时会发生以下事件：
* * <code>SkeletonTrap</code>NBT标签被清除。
* * 如果马不是骷髅马则变为骷髅马。
* * 马变为被驯服状态。
* * 如果是幼年马将会完全成长，且重置喂食冷却。
* * 马会被雷击。
* * 生成一个骑着马的骷髅。
* ** 骷髅拥有3秒的[受击后伤害免疫](受击后伤害免疫.md)时间。
* ** 骷髅不会自然消失。（设置了<code>PersistenceRequired</code>）。
* ** 骷髅会穿着铁质盔甲，除非是随机戴上了其他品质的头盔。
* ** 骷髅的盔甲与弓会有5-22级的[附魔](附魔机制.md)。等级决定于[区域难度](难度#区域难度.md)；简单难度只会是5级附魔。
* * 三个额外的被骑乘着的骷髅马会生成在附近。

# = 常规 =
* *[统计](统计.md)**
* 加入了上床睡觉次数的统计。

# 更改
# = 方块 =
* *[农作物](农作物.md)**
* 略微上升了[小麦种子](小麦种子.md)的掉落概率（平均每作物，取代原来的）。
* 略微上升了胡萝卜与马铃薯的掉落概率（平均每作物，取代原来的）。
* 大大提升[甜菜种子](甜菜种子.md)的掉落概率（平均每作物2 ，取代原来的）。

* *[末地烛](末地烛.md)**
* 侧面放置的末地烛高度从0.5625格改为0.625格，所以不再能像台阶一样行走于其上了。

* *[火](火.md)**
* 火在雨天比之前熄灭得更少了。
* * 每刻的熄灭概率被减少：原本是100%，现在为0−45%，由当前的“age”决定。

# = 生物 =
* *常规**
* 生物普通AI的大改进。

* *[骷髅](骷髅.md)**
* 现在骷髅可以同时行走、瞄准与射击。
* * 骷髅在太过靠近玩家时会退后而在太过遥远时接近。实在太远时也会向玩家冲刺。
* 骷髅有了新的空闲时音效。
* 现在可以经由骷髅陷阱马生成。

* *驯服的[豹猫](豹猫.md)和[狼](狼.md)**
* 死亡时会通知主人，甚至在没有命名时也一样。

* *[村民](村民.md)**
* 将会拾起与种下[甜菜种子](甜菜种子.md)。
* 将会收获[甜菜](甜菜.md)并像胡萝卜与马铃薯那样使用。

# = 非生物实体 =
* *[闪电](闪电.md)**
* 自然雷击可能会生成骷髅陷阱马。
* * 概率决定于[区域难度](难度#区域难度.md)：简单为3.75–7.5%，普通为7.5–20%，困难为11.25–33.75%。<!-- 5% * raw regional difficulty score -->

# = 命令格式 =
* *[NBT](NBT.md)标签**
* 新的NBT标签：
* * <code>SkeletonTrap</code>（字节），决定马属不属于诱骗骷髅。
* * <code>SkeletonTrapTime</code>（整形），在<code>SkeletonTrap</code>设置后每刻都会增加。达到18000（15分钟）后生物刷新消失。
