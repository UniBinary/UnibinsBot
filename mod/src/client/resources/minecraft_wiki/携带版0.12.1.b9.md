# 携带版0.12.1.b9

*页面ID: 27831* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.12.1 alpha build 9**是[v0.12.1 alpha](携带版0.12.1.md)的第9个测试版，发布于2015年8月14日，修复了一些漏洞。

# 更改
* [粒子](粒子.md)位于方块内部时不再变暗。
* 现在[雪傀儡](雪傀儡.md)在草原时，会在走过的路上留下[雪](雪.md)的痕迹。
* [仙人掌](仙人掌.md)现在拥有正确的粒子。
* 现在[熔炉](熔炉.md)将[烧炼](烧炼.md)后的物品名称居中显示。
* 创建随机世界时，[种子](种子（世界生成）.md)的随机性更强。
* “方向键的大小”现在被称为“按钮大小”。
* 附有[冲击](冲击.md)魔咒的[弓](弓.md)不再弹飞生物。<!--Punch enchantment no longer launches monsters.-->
* [凋灵骷髅](凋灵骷髅.md)变得更大。
* 现在[村庄](村庄.md)农田会生成[小麦](小麦.md)和别的作物。
* 现在自定义服务器IP必须是唯一的。
* 现在可以从[水](水.md)下看见[雨](雨.md)。
* 现在下雨和[下雪](下雪.md)的延迟更低。
* 现在用重命名的[刷怪蛋](刷怪蛋.md)生成的生物具有与刷怪蛋相同的名字，且名字会出现在[死亡消息](死亡消息.md)中。

# 修复

* *其他**
* 处理DNS服务器连接问题时游戏崩溃。
* 区块加载时游戏崩溃。
* 按下附魔按钮后游戏崩溃。
* 死亡后的玩家仍然可以通过下界传送门进行传送。
* 使用控制器打开设置选项时游戏崩溃。
* 需要重启游戏才能重新映射手柄。
* 无法使用快捷键选择存档。
* 无法使用键盘打开自定义皮肤界面。
* 玩家死亡后仍然可以使用物品。
* 僵尸村民不会追逐村民。
* 按下会关闭铁砧GUI。
* 无法使用方向键选择存档。
* 控制器按钮标签没有本地化。
* “按钮尺寸”选项对部分UI无效。
* 盔甲物品栏图标下面出现品红色的横线。
* 末影人的传送声音不正确。
* 瞄准箱子后可以射箭。
* 菜单里玩家用户名有黑色底。
* 雪傀儡不会保存头部状态。</onlyinclude>
