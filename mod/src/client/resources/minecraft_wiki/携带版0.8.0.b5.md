# 携带版0.8.0.b5

*页面ID: 31523* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.8.0 alpha build 5**是[v0.8.0 alpha](携带版0.8.0.md)的第5个测试版，发布于2013年11月29日，修复了一些漏洞。

# 更改
# = 方块 =
* *[草方块](草方块.md)**
* 现在对[草方块](草方块.md)使用[骨粉](骨粉.md)时会长成草丛了。

* *[南瓜](南瓜.md)和[西瓜](西瓜.md)**
* [南瓜](南瓜.md)与[西瓜](西瓜.md)苗的成长需要更多的骨粉了。

* *[花](花.md)**
* 对[花](花.md)使用骨粉时会长出其他的花了。
* 花的朝向现在是随机的了。

* *[甘蔗](甘蔗.md)**
* 骨粉现在可以使[甘蔗](甘蔗.md)长到最高了。

# = 物品 =
* *[矿车](矿车.md)**
* [矿车](矿车.md)的行驶更加稳定了。

# 修复

* *其他漏洞**
* 修复了丛林树叶、白色羊毛的纹理。
* 修复了TNT爆炸使告示牌与箱子全变黑的问题。
* 修复了当玩家坐在矿车中时会错误显示许多条腿的问题（当玩家穿着盔甲时）。
* 修复了打火石在创造模式下具有耐久限制的问题。
* 修复了玩家在进食时食物粒子和食物本身不对应的问题。
* 修复了创造模式的玩家在进入世界时获得错误物品的问题（仅客户端）。
* 现在能够正确发生窒息事件。
* 改进了进食动画。
* 修复了日光能照到室内实体的问题。
* 修复了方块在菜单中有高亮显示的问题。
* 修复羊的腿上有黑色的阴影的问题。
* 修复了熔岩接触静水却不产生石头的问题。
* 修复了云的颜色变化速度过慢的问题。
* 修复了破裂方块的裂痕过亮的问题。
* 修复了苦力怕过小的问题。
* 修复了一些额外内存占用问题。
* 修复了GUI的问题。</onlyinclude>
