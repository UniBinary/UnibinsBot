# 火焰弹

*页面ID: 7538* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}
* *火焰弹（Fire Charge）**是一种可以在方块上以生成[火](火.md)、或发射为[小火球](小火球.md)的物品。

# 获取
# = 合成 =

# = 箱子战利品 =

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家1个火焰弹。

# 用途
火焰弹可以作为[打火石](打火石.md)的代替品，在时会生成[火](火.md)，并消耗一个火焰弹。它也可以像打火石一样激活[TNT](TNT.md)、[下界传送门](下界传送门.md)，点燃熄灭的[营火](营火.md)、[蜡烛](蜡烛.md)。

[发射器](发射器.md)在使用火焰弹时会向其面向的方向发射[小火球](小火球.md)。

# 你知道吗
* 火焰弹、[小火球](小火球.md)、[火球](火球.md)共用相同的纹理。
* 当装有火焰弹的发射器前方有某些方块时，火焰会在该方块另一侧出现。
