# Java版12w21b

*页面ID: 32379* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w21b**是[Java版1.3.1](Java版1.3.1.md)的第7个快照，发布于2012年5月25日<ref></ref>，更新了一些方块的纹理，重写了创造模式的物品栏，并修复了[12w21a](12w21a.md)里出现的一些漏洞和崩溃。

# 更改
# = 方块 =
* *[绿宝石矿石](绿宝石矿石.md)**
* 将绿宝石矿石的纹理从 [32px](File:Emerald Ore JE1.png.md) 更改为 [32px](File:Emerald Ore JE2 BE1.png.md)。

* *[上锁的箱子](上锁的箱子.md)**
* [32px](File:Locked Chest JE3.png.md) 更改了纹理。

# = 物品 =
* *[盔甲](盔甲.md)**
* 锁链盔甲现在可以通过[交易](交易.md)获得。

# = 游戏内容 =
* *[区块](区块.md)**
* 稍微加快了存档和读取的速度。

* *[创造模式](创造模式.md)**
* 新的[物品栏](物品栏.md)界面。
* * [方块](方块.md)和[物品](物品.md)被按照类别去分类，每一种类别有自己的标签，这些类别是：建筑方块、装饰方块、红石、交通运输、杂项、食物、工具、战斗、酿造和材料。
* * 物品栏可以搜索指定的物品，只需在物品栏屏幕中输入文字。搜索结果会在搜索物品标签中显示。
* * 玩家的生存模式物品栏可通过[箱子](箱子.md)图标的标签访问。
* * 已经酿造的[药水](药水.md)不包含于它们自己的类别内。
* * 必须按下来关闭新的物品栏窗口。
* * 在创造模式物品栏中加入了[怪物蛋](怪物蛋.md)。
