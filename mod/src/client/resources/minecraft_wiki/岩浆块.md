* *岩浆块（Magma Block）**是一种可以在下界和主世界自然生成的发光方块，[生物](生物.md)踩上去会受到火焰伤害。

# 生成
# = 自然生成 =
[300px|缩略图|右|在下界自然生成的岩浆块](File:Nether Magma Block.png.md)

* [主世界](主世界.md)：
* * 以[水下岩浆块](水下岩浆块.md)的形式生成；
* * 作为[海底废墟](海底废墟.md)和[废弃传送门](废弃传送门.md)的一部分生成；
* * 在[试炼密室](试炼密室.md)结构的地面生成。
* 下界：
* * 在高度Y=27到Y=36之间以1-33方块大小的[团簇](团簇.md)形式自然生成，平均每个[区块](区块.md)尝试生成4个团簇；
* * 在[玄武岩三角洲](玄武岩三角洲.md)的[三角洲](三角洲.md)地形生成；
* * 作为[废弃传送门](废弃传送门.md)的一部分生成。

# 破坏
挖掘岩浆块的合适工具是镐。岩浆块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

岩浆块被破坏后会掉落自身。

# 用途
# = 伤害 =
岩浆块会对站在其上面生物造成每游戏刻的伤害（然而[受击后伤害免疫](受击后伤害免疫.md)会将其减至每半秒受到一次伤害），即使是在水下。岩浆块不会摧毁[物品（实体）](物品（实体）.md)。岩浆块造成的伤害属于火焰伤害，可以被[盔甲](盔甲.md)、[抗性提升](抗性提升.md)效果、[保护](保护.md)和[火焰保护](火焰保护.md)魔咒减免，玩家也可以通过[潜行](潜行.md)、[抗火](抗火.md)效果或者穿上带有[冰霜行者](冰霜行者.md)魔咒的靴子来完全免疫伤害。

在岩浆块上放置[碰撞箱](碰撞箱.md)高度小于等于[活板门](活板门.md)（0.1875格）的方块（如[地毯](地毯.md)、1-4层[雪](雪.md)、[红石中继器](红石中继器.md)等）后，岩浆块仍会对玩家和生物造成伤害。

# = 光源 =
岩浆块会发出亮度等级为3的光。

# = 行为 =
与[熔岩](熔岩.md)类似，岩浆块暴露雨中的时候会产生类似于烟的粒子效果。

[蜘蛛](蜘蛛.md)和[洞穴蜘蛛](洞穴蜘蛛.md)无法爬上岩浆块。

生物会避免走上岩浆块，且其上方不会生成生物（[岩浆怪](岩浆怪.md)、[恶魂](恶魂.md)、[僵尸猪灵](僵尸猪灵.md)和[鱿鱼](鱿鱼.md)<!-- 发光鱿鱼呢？ -->除外）。

与下界岩类似，当岩浆块顶部被点燃时，[火](火.md)将不会熄灭。

# = 气泡柱 =

在[水源](水源.md)下放置岩浆块会产生[向下的气泡柱](氣泡柱#涡流.md)，該氣泡柱會讓[物品](物品（实体）.md)、[玩家](玩家.md)、[船](船.md)和生物等[实体](实体.md)被向下拖動。

玩家可以通过进入岩浆块产生的气泡柱来恢复氧气值。

# = 融冰 =

[冰](冰.md)的下方一格是岩浆块时会使之融化而变成水源。<ref></ref>
