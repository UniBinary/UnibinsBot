# 发光（消歧义）

*页面ID: 125169* | *来源: Minecraft Wiki*

* *发光**或**荧光（Glow**或**Glowing）**可以指：

# Minecraft
# = 方块 =
*  - 生成于[主世界](主世界.md)地下的非固体发光方块。
*  - 一种未使用的方块。
*  - 一种生成于[下界](下界.md)的发光方块。

# = 物品 =
*  - 一种可从洞穴藤蔓上采集获得的食物。
*  - [物品展示框](物品展示框.md)的增亮变种。
*  - 发光鱿鱼掉落的物品。
*  - 破坏荧石后掉落的物品。
*  - 与化学相关的物品，可以在玩家的手中被点亮一段时间。

# = 生物 =
*  - [鱿鱼](鱿鱼.md)的变种，有着发光的纹理。

# = 状态效果 =
*  - 一种状态效果，让实体拥有发光轮廓线，从而使其可以被玩家透过任何遮挡物看见。

# = 地物 =
*  - 由荧石组成的地物。

# = 其他 =
* [发光方块](发光方块.md)
