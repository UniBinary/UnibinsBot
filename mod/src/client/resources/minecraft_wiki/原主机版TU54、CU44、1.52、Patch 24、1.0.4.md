# 原主机版TU54、CU44、1.52、Patch 24、1.0.4

*页面ID: 65798* | *来源: Minecraft Wiki*

* *TU54/CU44/1.52/Patch 24/1.0.4**是[原主机版](原主机版.md)的一次更新，发布于2017年6月27日，加入了许多[探索更新](探索更新.md)与[独乐不如众乐更新](独乐不如众乐更新.md)的特性。<ref></ref><ref></ref>此次更新等价于[携带版1.1.0](携带版1.1.0.md)～[基岩版1.2.0](基岩版1.2.0.md)。

# 新内容
# = 常规 =
* *皮肤包**
* 加入了小游戏英雄皮肤包。

* *选项**
* 加入了生物群系规模滑块、平衡种子、自动跳跃选项。

* *GUI**
* 新的染色合成图标。

# = 游戏内容 =
* *[成就](成就.md)**
* 加入了7个新成就。

* *[附魔](附魔.md)**
* [绑定诅咒](绑定诅咒.md)
* [消失诅咒](消失诅咒.md)

* *[状态效果](状态效果.md)**
* 会在HUD里显示。

# = 世界生成 =
* *[林地府邸](林地府邸.md)**
* 仅生成于[黑森林](黑森林.md)和黑森林丘陵生物群系。

# = 方块 =
* *[侦测器](侦测器.md)**
* 当一个面对的方块传来方块更新时会发出红石信号。

* *[床](床.md)**
* 加入了染色床。

# = 物品 =
* *[不死图腾](不死图腾.md)**
* 手持它的玩家从濒死状态下“复活”。

* *[探险家地图](探险家地图.md)**
* 分为海洋探险家地图和林地探险家地图。

* *[刷怪蛋](刷怪蛋.md)**
* 在创造模式菜单中加入[骷髅马](骷髅马.md)、[僵尸马](僵尸马.md)、[远古守卫者](远古守卫者.md)、[流浪者](流浪者.md)、[凋灵骷髅](凋灵骷髅.md)、[尸壳](尸壳.md)、[唤魔者](唤魔者.md)、[卫道士](卫道士.md)、[恼鬼](恼鬼.md)、[羊驼](羊驼.md)、[鹦鹉](鹦鹉.md)和[僵尸村民](僵尸村民.md)的刷怪蛋。

# 更改
# = 游戏内容 =
* *[饥饿值](饥饿值.md)**
* 减少了饥饿值的损耗。

* *[生命值](生命值.md)**
* 提升了生命值的恢复。

# = 世界生成 =
* *[海底神殿](海底神殿.md)**
* 提高了生成概率。

# = 方块 =
* *[铁栏杆](铁栏杆.md)、[玻璃板](玻璃板.md)和[栅栏](栅栏.md)**
* 在靠近楼梯的背面时会连接到楼梯。

* *[火把](火把.md)**
* 现在可以在楼梯的背面放置。

* *[地毯](地毯.md)和[雪](雪.md)**
* 可以放在倒放的楼梯顶部。

* *[床](床.md)**
* 现在可以减少跌落伤害。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 更改了驴刷怪蛋的纹理。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 带有状态效果的苦力怕在爆炸后会留下滞留药水效果。

# 修复

* *修复了26个漏洞**
