# 平滑砂岩

*页面ID: 28805* | *来源: Minecraft Wiki*

* *平滑砂岩（Smooth Sandstone）**是[砂岩](砂岩.md)制作的装饰性方块。

# 生成
# = 自然生成 =
平滑砂岩会在沙漠[村庄](村庄.md)中生成。

# 破坏
挖掘平滑砂岩的合适工具是镐。平滑砂岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

平滑砂岩被破坏后会掉落自身。
