# 启动器0.9

*页面ID: 49318* | *来源: Minecraft Wiki*

* *0.9**是一个2013年6月10日发布的[启动器](启动器.md)版本。

# 新内容
* 加入了“配置文件编辑器”选项卡。
* * 玩家只能双击其个人资料并在下拉列表中更改或选择游戏的版本。

# 更改
* 修改了选择版本的位置。

# 修复
*  - 修复了启动器无法记住游玩时选择的版本的漏洞。
