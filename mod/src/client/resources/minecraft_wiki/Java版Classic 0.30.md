* *0.30**是2009年11月10日发布的两个[Classic](Java版Classic.md)版本，也是[后期创造](后期创造.md)和Classic开发阶段的最后两个版本。<ref></ref>两个版本间的唯一差异游戏模式的不同：一个仅有[创造模式](创造模式.md)，另一个仅有[生存模式](生存模式.md)。

# 更改
# = 方块 =
* *[TNT](TNT.md)**
* 击打激活的TNT会使其停止引爆并允许[玩家](玩家.md)将其捡起。
* 爆炸后不再产生颗粒。

# = 常规 =
* *其他**
* 极大的改善了世界生成用时。
* * 在先前的版本中，生成世界可能需要2分钟的时间。但自该版本之后仅需要几秒。
* 加入了本地文件存储功能。
* 移除了免费账户的在线存储功能。
* * 现在当免费账户玩家尝试保存时，会提示玩家需要付费。

# 修复
* *修复了4个漏洞**
* 方块现在会再次掉落它们自身了。
* 修复了绵羊碰撞箱上有区域可以使得玩家可以穿过碰撞箱打到后面的问题。
* TNT被打中时不再会消失。
* 降低了多人游戏的延迟。</onlyinclude>
