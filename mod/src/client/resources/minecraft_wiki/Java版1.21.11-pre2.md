* *1.21.11-pre2**是[Java版1.21.11](Java版1.21.11.md)的第2个预发布版，发布于2025年11月21日<ref></ref>，修复了一些漏洞。

此版本也额外发布了未经混淆的版本，称为**1.21.11 Pre-Release 2 Unobfuscated**（启动器内称**1.21.11-pre2_unobfuscated**），旨在过渡至后续小更新时移除混淆。<ref></ref>

# 更改
# = 方块 =
* *[树叶](树叶.md)**
* 更改了“”选项为关时树叶透明部分的视觉效果。

# = 常规 =
* *性能**
* 现在关闭“”选项时会比之前提升更多性能。
