# 命令/swing

*页面ID: 178499* | *来源: Minecraft Wiki*

控制[实体](实体.md)的手臂挥动。

# 语法
   <code>swing [<targets>] [mainhand|offhand]</code>

# 参数

   指定挥臂的实体，默认为命令的执行者。
   只有[生物](生物.md)才具有挥臂这一行为，且客户端只会在特定的生物上渲染挥臂动作。

<code>mainhand|offhand</code>
   指定挥动的手臂，默认为。
   为主手，为副手。
