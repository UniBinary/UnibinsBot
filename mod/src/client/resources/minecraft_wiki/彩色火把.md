# 彩色火把

*页面ID: 34699* | *来源: Minecraft Wiki*

* *彩色火把（Colored torch）**是被[氯化物](氯化物.md)染色的[火把](火把.md)，目前有蓝色、红色、紫色和绿色。

# 生成
彩色火把不会生成在世界中。

# 破坏
彩色火把被挖掘时会立刻被破坏。

彩色火把被破坏后会掉落自身。

# 用途
彩色火把可以被放置于大多数固体方块的顶端或侧面，不过有个别的需要（例外情况见[放置](#放置.md)）。彩色火把为非固体方块，没有碰撞箱。

如果在[沙子](沙子.md)或[沙砾](沙砾.md)这种受重力影响的方块正下方有一个彩色火把，它将不会下落。如果它下落到彩色火把的位置，它将被破坏。

# = 光源 =
彩色火把发出亮度为14的[光](光.md)。彩色火把能融化曼哈顿距离2格内的[雪](雪.md)和[冰](冰.md)。

# 放置
彩色火把只能被放置于方块[中心完整](方块支撑形状.md)的上表面上方或方块完整的侧面。
