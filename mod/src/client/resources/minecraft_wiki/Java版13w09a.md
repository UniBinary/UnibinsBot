# Java版13w09a

*页面ID: 33496* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w09a**是[Java版1.5](Java版1.5.md)的第11个快照，发布于2013年2月26日<ref></ref>，加入了新的生物AI，并修复了一些漏洞。

# 新内容
# = 生物 =
* *常规**
* [生物](生物.md)现在能骑在（骑在其他生物上的）其他生物/载具的生物之上。
* 重新加载后它们不再取消骑乘。
* 生物现在能够骑乘其他生物时生成。
* 允许大量自定义。

# 更改
# = 实体 =
* *常规**
* 玩家在登出后仍会保持骑着载具/生物。

# = 常规 =
* *字体**
* 字体现在能够更改。
* 加入了高清字体的支持。

* *[语言](语言.md)文件**
* 更新了语言文件。

* *[光照](光照.md)**
* 更改了平滑光照，现在拥有“最大”、“最小”和“关”选项。
* * “最小”使用旧的平滑光照，“最大”修复了楼梯的光照漏洞。

* *[纹理包](纹理包.md)**
* 纹理包内的动画化的方块和物品必须包含动画指标（之前为可选项）。
