* *烟熏炉（Smoker）**是专门用于烹制熟食的[熔炉](熔炉.md)变种。

# 生成
# = 自然生成 =
烟熏炉自然生成在[村庄](村庄.md)内的屠夫小屋里。

# 破坏
挖掘烟熏炉的合适工具是镐。烟熏炉需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

烟熏炉被破坏后会掉落自身、内容物和储存的经验值。

# 用途
烟熏炉不能被[活塞](活塞.md)推动。

# = 烧炼 =

烟熏炉只能[烧炼](烧炼.md)食物。速度为每烧炼一个物品，即每分钟烧炼12个物品，是[熔炉](熔炉.md)的2倍。

烟熏炉可以打开它的界面。下方的槽位为“燃料槽”，用于放置燃料（最多1组）；上方的槽位为“烧炼槽”，用于放置烧炼物（最多1组）；右侧的槽位为“成品槽”，烧炼成品会存放于此（最多1组）。

连接到烟熏炉上面的[漏斗](漏斗.md)会向烧炼槽中添加烧炼物，连接到烟熏炉侧面的[漏斗](漏斗.md)会向燃料槽中添加燃料，烟熏炉下面的[漏斗](漏斗.md)会取走成品槽位中的成品和燃料槽中的[铁桶](铁桶.md)，如果铁桶与成品槽的成品同时存在会优先吸取或。烧炼产生的经验会存储在烟熏炉中，当玩家取出成品槽中的成品或烟熏炉被破坏时一并给予玩家。

燃烧中的烟熏炉会生成火焰[粒子](粒子.md)。

烟熏炉燃烧时还会生成烟雾。

# = 红石比较器 =
[红石比较器](红石比较器.md)可检测烟熏炉的内容物占空比，烧炼槽、燃料槽和成品槽都会被统计。

# = 光源 =
燃烧中的烟熏炉会发出13级的光。

# = 自定义名称 =
烟熏炉界面的标题默认为“烟熏炉”，可以在未放置之前使用[铁砧](铁砧.md)重命名来进行更改，也可以通过使用命令修改烟熏炉的<code>CustomName</code>标签进行更改。

# = 更改村民职业 =

如果村庄内有一个未被认领的烟熏炉，则附近任何失业的村民都有机会改变其职业为[屠夫](屠夫.md)。

# = 锁定 =

烟熏炉可以被<code>lock</code>标签上锁。如果烟熏炉的该标签不是空白的，那么这个烟熏炉必须使用符合该标签表示的物品谓词的物品打开。
