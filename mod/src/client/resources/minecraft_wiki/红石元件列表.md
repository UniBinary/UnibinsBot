# 红石元件列表

*页面ID: 10987* | *来源: Minecraft Wiki*

* *红石元件**指用于建造红石电路的[方块](方块.md)。红石元件包括电源（如[红石火把](红石火把.md)、[按钮](按钮.md)等）、传输元件（如[红石粉](红石粉.md)和[红石中继器](红石中继器.md)）与机械元件（如[活塞](活塞.md)、[门](门.md)、[红石灯](红石灯.md)等）。

本条目意在普及红石结构的基础知识。关于相关术语与概念的详情，参见[红石电路](红石电路.md)条目。本文所介绍的方块或物品仅限它们在红石电路中的应用，这些方块与物品的其他用途或特性详见其各自的主条目。

# 性质
这个表格包含了红石元件的部分性质。

# 电源
电源能够产生红石信号。红石信号可能是永久的，也可能受外部条件的触发（例如玩家与生物的活动，环境改变等）。

# = 红石块 =

红石块为永久红石电源，通常使用活塞进行操作。

; 工作
永久输出信号。

; 输出
红石块相当于15级强充能方块，会激活毗邻的朝向正确（如果需要）的元件。不影响毗邻的红石导体。

# = 按钮 =

按钮用于为电路提供脉冲信号。按钮有两种类型：木质与石质。

; 放置
按钮可以附着在[完整](方块支撑形状.md)的方块表面，若其附着的方块被移除或移动，那么按钮就会被破坏并掉落为物品。

; 工作
玩家木质或石质按钮可以按下它。石质按钮被按下后会保持激活10红石刻（1秒）；木质则为15红石刻（1.5秒）。但若是由发射的[箭](箭.md)或[三叉戟](三叉戟.md)激活，木质按钮会保持激活直到箭或三叉戟被捡起或在1分钟之后自然消失。

; 输出
激活时，按钮会**强充能**其附着的红石导体，激活毗邻的朝向正确（如果需要）的元件。

# = 拉杆 =

[缩略图|作为电源的拉杆（按钮特性类似）](File:Lever as power source (v1.4.2).png.md)

拉杆用于为电路提供可开关的持续信号。

; 放置
拉杆能够附着在完整的方块表面上。如果其附着的方块被移除或移动，那么拉杆就会被破坏并掉落为物品。

; 工作
玩家可以拉杆以切换激活和关闭状态。

; 输出
激活时，拉杆会**强充能**其附着的红石导体，激活毗邻的朝向正确（如果需要）的元件。

# = 压力板 =

[缩略图|作为电源的压力板](File:Pressure plate as power source.png.md)

压力板可以探测生物、物品与其他[实体](实体.md)。压力板有三种类型：木质、石质与测重。

; 放置
压力板能够附着在上表面边缘完整或中心完整的方块顶部。若其附着的方块被移除或移动，那么压力板就会被破坏并掉落为物品。

; 工作
当[实体](实体.md)经过或落在压力板上，压力板会激活。实体离开或被移除，压力板经过一定延时后关闭。石质压力板只会被生物（包括玩家）激活，而木质和测重压力板还会被掉落的物品、发射的[箭](箭.md)或[浮漂](浮漂.md)等实体激活。

; 输出
激活时，压力板会**强充能**其下方的红石导体，激活毗邻的朝向正确（如果需要）的元件。测重压力板发出的红石信号的强度随实体数量的增加而增强。

# == 测重压力板 ==

测重压力板用于测量落在其上的物品数量。测重压力板有两种：轻质（金）与重质（铁）。

; 放置
测重压力板能够附着在上表面边缘完整或中心完整的方块顶部。若其附着的方块被移除或移动，那么测重压力板就会被破坏并掉落为物品。

; 工作
当有至少一个实体落在其上时，测重压力板将保持激活。

; 输出
激活时，测重压力板会强充能其附着的方块，激活毗邻的朝向正确（如果需要）的元件。其输出的信号强度与在其上的实体数量成正比。

# = 阳光探测器 =

阳光探测器可用于探测Minecraft的世界亮度。

; 工作
检测自身坐标的世界亮度，普通模式下输出自身位置的世界亮度，反向模式下则相反（输出15-正向模式输出）。

; 输出
阳光探测器会激活毗邻的朝向正确（如果需要）的元件。不影响毗邻的红石导体。

; 版本特性
* 阳光探测器每1s更新一次；侦测器可以直接侦测阳光探测器输出的变化（而无需额外连接红石粉）。

# = 探测铁轨 =

[缩略图|作为电源的探测铁轨](File:Detector rail as power source (v1.4.2).png.md)
探测铁轨能够感知经过的[矿车](矿车.md)。

; 放置
探测铁轨能够附着任何上表面[中心完整](方块支撑形状.md)的方块上。

放置后，探测铁轨会自动连接<u>毗邻</u>或<u>与其落差为1格的</u>其他铁轨、探测铁轨、激活铁轨与动力铁轨。

若其附着的方块被移除或移动，那么探测铁轨就会被破坏并掉落为物品。

; 工作
矿车经过探测铁轨时会激活它，探测铁轨激活后，每隔20[游戏刻](游戏刻.md)检查一次。检查时若发现上方没有矿车，探测铁轨会关闭。

; 输出
激活时，探测铁轨会**强充能**下方的红石导体，激活毗邻的朝向正确（如果需要）的元件。

; 检测
红石比较器可检测探测铁轨上方的运输矿车（或[漏斗矿车](漏斗矿车.md)）内的物品占空比。

# = 陷阱箱 =

陷阱箱用于测得正在查看自身物品栏的玩家数量。

; 工作
有玩家查看陷阱箱时，陷阱箱就会激活。信号强度与当前查看该陷阱箱的玩家数量相等（最多15）。

; 输出
激活时，陷阱箱会强充能周围的红石导体，会激活毗邻的朝向正确（如果需要）的元件。

; 检测
红石比较器可检测陷阱箱内物品的占空比（和箱子一样）。

# = 绊线钩 =

[缩略图|作为电源的绊线钩](File:Tripwire hook as power source (v1.4.2).png.md)

绊线钩可以在绊线线路区域里探测生物与其他[实体](实体.md)。

; 放置
绊线钩需要附着侧面完整的方块侧面。若其附着的方块被移除或移动，那么绊线钩就会被破坏并掉落为物品。

绊线钩工作必须将其与[绊线](绊线.md)组合，组成绊线线路：2个绊线钩附着在方块上，必须面对面放置在同一条直线上（X/Z方向），中间放上“绊线”（至少1格、至多40格的[绊线](绊线.md)）。

多个绊线线路可以相邻放置或交叉放置，不会互相串扰。

; 工作
当绊线接触[实体](实体.md)（无论实体是否移动），该绊线会激活对应的绊线线路中的绊线钩。若实体离开或被移除，对应绊线钩延时后关闭。绊线被破坏时，绊线钩也会被激活5rt（0.5秒），除非是用[剪刀](剪刀.md)破坏绊线。

; 输出
激活时，绊线钩会强充能其附着的方块，激活毗邻的朝向正确（如果需要）的元件。输出的信号强度为15。
* 绊线本身不产生红石信号。

# = 唱片机 =

唱片机可以播放唱片。

; 工作
当内含唱片，且唱片未播放完毕时，唱片机会激活，播放完毕后自动关闭。

; 输出
激活时，唱片机会激活毗邻的朝向正确（如果需要）的元件。输出的信号强度为15。

; 检测
红石比较器可检测唱片机内播放的唱片并输出对应强度信号，详见[唱片机](唱片机.md)页面。唱片播放完毕后红石比较器仍会输出信号，因其只检测内含的唱片，不检测播放状态。

; 版本特性
唱片机不阻断红石线上下连接。

# = 侦测器 =

侦测器用于探测方块变化。

; 放置
侦测器可放置在任何位置，可朝向包括上方和下方在内的任何方向。放置侦测器时，侦测端（它的“脸部”）即探测方块变化的那一面会远离玩家，输出端（输出脉冲的那一面）会朝向玩家。

; 工作
侦测器“面前”的方块状态更改时会导致侦测器**激活**（例如，放置或破坏了一个方块，水变成冰，玩家更改了红石中继器的延迟等）。侦测器保持激活1[红石刻](红石刻.md)，随后自动**关闭**。
* 侦测器被[活塞](#活塞.md)推动时也会激活。

; 输出
激活时，侦测器会强充能输出端正对的红石导体，激活毗邻的朝向正确（如果需要）的元件。
* 基岩版侦测器延迟稍有不同，详见[侦测器](侦测器.md)页面。

# = 讲台 =

; 放置
讲台可以朝东西南北，放置时面向玩家。

; 工作
翻书时，讲台会保持激活1[rt](刻#红石刻.md)。

; 输出
激活时，讲台会强充能下方的红石导体，激活毗邻的朝向正确（如果需要）的元件。

; 检测
红石比较器可检测讲台上书本的翻页进度（第一页为1，翻到最后一页为15），翻页脉冲不影响该信号的强度。

# = 标靶 =

标靶被绝大多数弹射物（包括[箭](箭.md)、[三叉戟](三叉戟.md)、[掷出的鸡蛋](掷出的鸡蛋.md)、[雪球](雪球.md)、[喷溅药水](喷溅药水.md)、由发射器射出的[火焰弹](火焰弹.md)、[滞留药水](滞留药水.md)、[掷出的末影珍珠](掷出的末影珍珠.md)以及[掷出的附魔之瓶](掷出的附魔之瓶.md)）击中时会发出一定强度的红石信号。但被[末影之眼](末影之眼.md)击中时无效。

还可改变红石粉指向（即“引线”）。

; 工作
被箭和三叉戟击中时会保持激活10rt，而其他弹射物击中时则为4rt。命中位置越靠近方块中心，信号强度越高，从1（在边缘）到15（在中心）。

; 输出
激活时，标靶会激活毗邻的朝向正确（如果需要）的元件。不影响毗邻的红石导体。

; 版本特性
标靶是一种能改变红石粉方向且不会同时充能红石粉的红石导体。

标靶改变红石线指向的行为实际是直接在图搜索走向中**将自身作为分支加入**而非**直接改变搜索走向**，因此行为与Java版有差异。

但由自身出发的链接搜索则与常规电源元件搜索方式相当（如唱片机）。

# = 避雷针 =

避雷针可以吸引闪电，引导闪电击中点。

; 工作
避雷针被任意来源的[闪电](闪电.md)击中时会被激活，发出15级的红石信号，持续8游戏刻。

; 输出
激活时，避雷针会**强充能**其杆部指向的[红石导体](红石导体.md)，激活毗邻的朝向正确（如果需要）的元件。

; 版本特性
避雷针可以向指向的红石比较器边侧输入。

# = 幽匿感测体 =

幽匿感测体用来检测声音或声音的频率。

; 工作
幽匿感测体检测到距离它8格内的振动（变种则为16格）后会激活，持续一定时间后关闭。距离越远，振动强度越低，信号强度越低。

; 输出
激活时，幽匿感测体会激活毗邻的朝向正确（如果需要）的元件，不影响毗邻的红石导体。

; 检测
红石比较器可检测幽匿感测体接收到的振动的频率，**不受振动的强度影响**。

# 传输元件
传输元件能够将信号传输到其他元件。

在上一红石刻存在，但在该红石刻的图更新阶段被阻断的信号无法进入这一红石刻的电容器更新阶段，因此无法激活**所有**电容器元件。

# = 红石中继器 =

[缩略图|作为电路元件的红石中继器](File:Redstone repeater as circuit component.png.md)
红石中继器用来传输信号，重新加强因距离而减弱的红石信号，延迟信号，和给予红石信号单向的传输方向。

; 放置
红石中继器可附着在上表面边缘完整的方块顶部。若其附着的方块被移除或移动，那么红石中继器就会被破坏并掉落为物品。

红石中继器共有三种端口：后侧的主输入端I，两侧的锁定输入端L，前侧的输出端O。红石中继器顶部纹理的箭头指向输出端。它的延迟是可调节的，通过右键它可将延迟设置成1至4红石刻（默认为1红石刻）。

; 工作
红石中继器会被任何位于它输入端的[充能方块](红石电路/充能与激活.md)或朝向正确（若需要）的元件激活。

在它的侧面用另一个红石中继器或红石比较器输入可以“锁存”当前状态。一个锁定的中继器会保持状态直到解锁。

; 输出
激活时，红石中继器会激活在它输出端指向的其他朝向正确（若需要）的元件或强充能红石导体。不影响其他位置的方块。

; 注意
红石中继器不仅会“中继”一个信号（为了传输重新加强），它也会产生1至4红石刻的延迟。红石中继器也会把任何持续时间短于它的延迟的脉冲增长到与它的延迟相符。

; 版本特性
红石中继器不依赖计划刻，会将周期2rt的信号串“放大”为其<code>-{}-延迟×2</code>周期的信号串。

# = 红石火把 =

[缩略图|作为电源使用的红石火把](File:Redstone torch as power source.png.md)
红石火把可为电路提供初始信号，或用于反相信号和纵向传输红石信号。

; 放置
红石火把需附着在上表面中心完整的方块顶部和侧面完整的方块的侧面。若其附着的方块被移除或移动，那么红石火把就会被破坏并掉落为物品。

; 工作
红石火把会保持激活，充能它附着的方块时关闭。
* 若其附着的方块是活塞或黏性活塞，则红石火把的开启和关闭受活塞的激活状态（无论是否推出）影响。

; 输出
激活时，红石火把会够**强充能**其**上方**的红石导体，激活毗邻的朝向正确（如果需要）的元件。不影响其附着的方块。

; 版本特性
* 若是红石火把亮灭交替过快（60[gt](刻#游戏刻.md)内熄灭8次），红石火把会“**烧毁**”。<br>烧毁后，当红石火把得到一次[更新](方块更新.md)（需要NC更新），其会解除烧毁。

* 红石火把不依赖计划刻，仅在红石火把输入包含自身时，红石火把会以2rt为周期高频闪烁并每rt增加1时钟值。此时输出的信号为特殊的“半脉冲”信号，只有部分元件响应半脉冲信号，例如[投掷器](投掷器.md)、[发射器](发射器.md)（其余元件将输出视为持续信号）。时钟值到达16后红石火把**烧毁**，到达32后不再增长且允许“复燃”（若红石火把受到图更新，时钟值会重置为0并解除烧毁）。任意外部信号输入可在任意时刻重置时钟值。

# = 红石比较器 =

红石比较器用于比较或相减两个信号，或用于检测容器的装载量以及某些方块的状态。

; 放置
红石比较器可附着在上表面边缘完整的方块顶部。若其附着的方块被移除或移动，那么红石比较器就会被破坏并掉落为物品。

红石比较器共有三种端口：后侧的主输入端I，两侧的副输入端C，前侧的输出端O。红石比较器顶部纹理的箭头由主输入端指向输出端。

红石比较器有两种**模式**。右键比较器可以在比较模式（前端红石火把熄灭）和减法模式（前端红石火把点亮）之间切换。

; 激活
红石比较器会被任何位于它输入端的[充能方块](红石电路/充能与激活.md)或朝向正确（若需要）的元件激活。红石比较器亦可检测后面的方块，包括后方非空的容器或特定的方块时（与比较器相隔1个红石导体时也可以）。其输出不会受到上方或下方的方块影响，但侧向输入会影响到输出信号强度（详见下）。

; 输出
激活时，红石比较器会激活前方的朝向正确（如果需要）的元件、强充能前方的红石导体。不影响其他位置的方块。

红石比较器输出的信号强度会被侧向输入的信号影响，只包括红石粉、红石中继器、另一个比较器的输入：

* **比较模式**
  * 仅在主输入大于等于副输入的情况下输出主输入的信号强度，否则无输出。
   逻辑：
 if(I<C){return 0;}<!--负逻辑,先排除输出为0的情况-->
 else{return I;}<!--剩余情况输出必为输入-->
* **减法模式**
  * 红石比较器只会在输入信号强于侧面信号时输出两者的强度之差，否则无输出。
  * 逻辑：<code>Max(I-C, 0)</code>

被容器激活的红石比较器会输出反应容器占空比的信号，以及反映其他方块的状态。

; 版本特性
* 由于红石比较器的计划刻优先级，常见的小于等于1红石刻长度的信号（如未指向红石中继器或另一个红石比较器的后侧或边侧的红石比较器可以过滤单个侦测器输出脉冲、讲台翻页脉冲）均会被过滤。
* 比较器隔方块检测方块状态、方块实体和实体（如箱子、熔炉、讲台）时若中间所隔的方块被充能至15信号强度，那么比较器会直接输出15信号强度（称为容器屏蔽）。
* 红石比较器不依赖计划刻。

# = 红石粉 =

[缩略图|作为电路元件的红石粉](File:Redstone wire as circuit component.png.md)
红石粉用于传输信号。

; 放置
手持[红石粉](红石粉.md)（红石粉是[物品](物品.md)，放置后的红石粉则为[方块](方块.md)）右键点击即可放置成为红石粉。红石粉能够附着在任何上表面完整的方块顶部。若其附着的方块被移除或移动，那么红石粉就会被破坏并掉落为物品。

红石粉的指向会决定其如何影响毗邻的红石导体与红石元件。

右击单个的红石粉可改变它的形状，有十字状和点状，放置时它默认是十字状。

; 激活
红石粉可以被相连的其他红石粉、相连的元件的输出端（若有）或毗邻的被**强充能**的红石导体激活。信号在红石粉上不断传输时强度会逐格递减。

; 输出
激活时，红石粉会激活它指向的其他元件，弱充能所指向的（包括它下方的）红石导体。
* 当红石粉呈点状时，则它不能弱充能侧面毗邻的方块，但能弱充能其附着方块（如果是红石导体）。

# 机械元件
机械元件能够响应红石信号，执行相应行为。

由于在系统中它们只接受红石信号，因此也被称为**消费者**。

[缩略图|激活机械元件（以红石灯为例）](File:Activating a powered mechanism.png.md)

; 激活
所有机械元件在下列情况下都会激活：
* 毗邻的开启的**电源**（例外：红石火把不会激活其所附着的机械元件，侦测器只激活指向的机械元件）。
* 毗邻的**[充能方块](红石电路/充能与激活.md)**。
* 毗邻的指向机械元件且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)（包括机械元件上方的红石粉）；毗邻但未指向机械元件的红石粉不会激活该机械元件。

在同一红石刻内，电容器更新阶段前存在，但在电容器更新阶段被取消的信号无法进入消费者更新阶段，因此这类信号无法激活**所有**消费者元件。

部分机械元件可能有特例，将在对应栏目列出。

;

[缩略图|**用半连接方式激活活塞**–注意在左边的活塞并**没有**被激活，因为红石**没有**指向它](File:Activation by piston connectivity.png.md)
除了常规激活方式，**发射器**、**投掷器**与**活塞**三种机械元件，当其上方的方块*能被*激活时也会被激活，即使这个“上方的方块”并不存在也没问题。

; [充能与激活](红石电路/充能与激活.md)

[缩略图|upright|红石灯都被激活了，但是充能的方式不同，依次为：
<ol><li>强充能，输出端中继器和红石粉均被激活；
<li>弱充能，输出端中继器激活而红石粉不激活；
<li>不充能，输出端中继器和红石粉均不激活</ol>](File:Powered blocks.png.md)

部分机械元件也是红石导体（如命令方块、发射器、投掷器、音符盒、红石灯），区分它们是被**激活了**还是被**充能了**很重要。被充能意味着**必然**被激活，但被激活不一定被充能。

# = 活塞 =

活塞用于移动方块或实体。分为两种：只能推动方块的**普通活塞**与既可以推动又可以拉动方块的**黏性活塞**。

; 放置
活塞可朝向任何方向，放置时活塞头所处面会朝向放置者。

; 激活
* 详见[半连接性](#半连接.md)，不接受来自活塞头方向的激活（半连接性可以绕过）。
* 不接受来自活塞头方向的连接。

; 工作
* 激活时，活塞会向前方推动最多12个方块。
* 关闭时，普通活塞的活塞头缩回（原本活塞头的位置被空气占据）；黏性活塞还会拉回其前方的方块或方块结构（那个方块或方块结构的位置被空气占据）。

活塞也能推动[实体](实体.md)，例如生物与物品。

某些方块（如基岩、黑曜石、磁石等）不能被活塞推动。还有一些方块（花、草丛、火把、潜影盒等）会在被活塞推动时破坏（即为玩家破坏）。
* [带釉陶瓦](带釉陶瓦.md)允许被推动，但不会被[黏液块](黏液块.md)或[蜂蜜块](蜂蜜块.md)黏连。

; 版本特性
* 若黏性活塞在推出时失去信号，由于正被推动的方块结构尚未被转换为方块，黏性活塞无法拉回该方块结构（该方块结构会正常到达推动后的位置）。

* ：
* * 活塞和标靶一样会主动引线，但同时不会改变红石粉原有的指向（被称为“半引线”）。
* * 活塞运行时，将其作为附着方块的方块不会掉落。
* * 活塞底座不阻断红石粉连接。
* * 红石火把附着在活塞或黏性活塞上时，其会根据活塞或黏性活塞**是否被激活**而熄灭或亮起（无论是否推出或收回），提供了一种别样的布线方法。

# = 铁轨 =

[缩略图|作为电动机械的铁轨与动力铁轨](File:Rails as powered mechanisms.png.md)
铁轨供矿车通行。受红石控制的铁轨可用于切换[矿车](矿车.md)轨道。

; 放置
铁轨需放置在上表面边缘完整的方块顶部。若其附着的方块被移除或移动，那么铁轨就会被破坏并掉落为物品。

放置后，铁轨会自动连接四周（及高一格和低一格）的铁轨、动力铁轨、探测铁轨与激活铁轨。

; 工作
激活后，T型道岔的弯曲铁轨会连接另一个方向。
* 十字道岔的弯曲铁轨被激活后会连接另外两个方向。

# = 动力铁轨 =

动力铁轨用于加速或刹停[矿车](矿车.md)。

; 放置
动力铁轨需放置在上表面边缘完整的方块顶部。若其附着的方块被移除或移动，那么动力铁轨就会被破坏并掉落为物品。

放置后，动力铁轨会自动连接四周（及高一格或低一格）的铁轨、动力铁轨、探测铁轨与激活铁轨。

; 激活
除了上述激活方法外，动力铁轨还能被相邻的激活的动力铁轨激活，除非已距离信号源头9格开外。

; 工作
关闭时，动力铁轨会减速经过的矿车，至多三个未被激活的动力铁轨就可以刹停任意速度的矿车。

激活时，动力铁轨会加速经过的矿车，或启动满足启动条件的矿车。

# = 激活铁轨 =

激活铁轨用于激活[矿车](矿车.md)。

; 放置
激活铁轨需放置在上表面边缘完整的方块顶部。若其附着的方块被移除或移动，那么激活铁轨就会被破坏并掉落为物品。

放置后，激活铁轨会自动连接四周（及高一格或低一格）的铁轨、动力铁轨、探测铁轨与激活铁轨。

; 激活
除了上述激活方法外，激活铁轨还能被相邻的激活的激活铁轨激活，除非已距离信号源头9格开外。

; 工作
激活时，激活铁轨能够影响经过的矿车。因矿车类型而异：
* [命令方块矿车](命令方块矿车.md)会每4个游戏刻（5次/秒）运行一次命令。
* [TNT矿车](TNT矿车.md)会被激活铁轨点燃。
* [漏斗矿车](漏斗矿车.md)会被激活铁轨禁用（即激活铁轨会停止漏斗矿车从其上方的容器吸取物品）。
* 若有实体骑乘普通矿车，那么矿车在经过激活的激活铁轨时会把实体弹出矿车。
* 其他矿车不受激活铁轨影响。

# = 命令方块 =

命令方块用于运行命令。命令方块的物品形式只能通过、[创造模式](创造模式.md)中使用或[命令](命令.md)获得，也可用等命令放置。

; 放置
放置后，命令方块朝向玩家，创造模式玩家可以命令方块来设置其命令。

; 工作
激活时，脉冲型命令方块会执行预设的命令**一次**，连锁型命令方块会**在指向其的命令方块执行命令后**执行命令，而循环型命令方块则会**持续**执行命令。

; 注意
命令方块为红石导体，因此可以充能。

# = 钟 =

激活时发出一次钟声，可被侦测器检测。
* 侦测器可检测被手动或弹射物敲击的钟。

村庄受到袭击时，钟会自动发出一次钟声。

若钟被敲响（无论是手动敲响或是自动敲响），一定范围内的村民会尝试回到它们的“家”。

# = 发射器 =

发射器利用物品与环境互动。

; 放置
发射器可朝向任何方向，放置时输出面会朝向放置者。

; 激活
常规激活方式，外加[半连接性](#半连接.md)。

; 工作
激活时，发射器会随机使用物品槽中的一个物品。
* 若目标物品无法被使用，若没有特别定义，该物品将被掷出，类似投掷器掷出物品。

; 注意
* 发射器为红石导体，因此可以充能。
* 和投掷器不同，发射器无法与容器交互。

# = 投掷器 =

将物品掷出或注入另一个容器（包括其他投掷器）。

; 放置
投掷器可朝向任何方向，放置时输出面会朝向放置者。

; 激活
常规激活方式，外加[半连接性](#半连接.md)。

; 工作
激活时，投掷器会随机投掷物品槽中的一个物品：
* 若投掷器朝向容器且容器可以容纳输出物，则该物品会被输入容器。否则，将会向朝向的方向扔出物品，就像玩家丢弃物品一样。

; 注意
* 投掷器为红石导体，因此可以充能。
* 和发射器不同，投掷器无法使用物品。

# = 门 =

门用于控制生物、物品、船等实体的通过。门有3种：木门、铜门与铁门。所有门均可由红石信号控制，木门和铜门能够被手动开关与被[僵尸](僵尸.md)破坏。

; 放置
门能够放置在上表面完整的方块顶部。若其附着的方块被移除或移动，那么门就会被破坏并掉落为物品。

; 工作
激活时，门会沿转轴打开，反之亦然。
* 门开关时实际没有“移动”（像活塞头或推动方块移动时），它只是简单地在一边消失，在另一边重新出现，因此在“开门”或“关门”时不会推动实体。

# = 活板门 =

活板门用于控制生物、物品、船等实体的通过。活板门有3种：木活板门、铜活板门和铁活板门。所有活板门都允许红石信号控制，木活板门与铜活板门允许手动开关

; 放置
活板门可放置在任何位置。

; 工作
激活时，活板门会沿合页打开，反之亦然。
* 活板门开关时实际没有移动（像活塞头或一个被推动的方块移动那样），它只是简单地从一侧消失，然后在另一侧出现，因此在“开启”或“关闭”时并不会推动实体。

# = 栅栏门 =

栅栏门用于控制生物、物品、船等实体的通过。

; 工作
激活时，栅栏门会打开，允许一切实体通过。

栅栏门开关时实际没有“移动”（像活塞头或推动方块移动时），它只是简单地在一边消失，在另一边重新出现，因此在“开门”或“关门”时不会推动实体。

栅栏门打开后碰撞体积会完全消失，不像门或活板门那样只是更换位置。

# = 漏斗 =

漏斗能向其他容器注入或从其他容器（包括其他漏斗）抽取物品。

; 放置
漏斗被放置时，其尖嘴可朝向除了上方之外的任何方向（朝向与放置方式有关），代表物品输出方向。

; 工作
未激活时，漏斗会自动地：
* 从其上方容器抽取物品（或上方的物品实体）到漏斗自己的物品栏中；
* 向其尖嘴朝向的容器注入物品；
* 并吸取上方的物品实体。
通常，这三个过程均为8游戏刻（0.4秒）一次。

被激活时，漏斗会被“锁定”，停止这三个主动进程，但不会阻止其他容器对自身物品栏内物品的操作。

# = 音符盒 =

音符盒可播放预设的声音。

; 工作
常规激活规则。激活时根据下方的方块或上方的生物头颅发出一次对应类别的声音，并可被调整为不同变种。

音符盒上方必须是空气或生物头颅才能成功发音。

; 注意
音符盒为红石导体，因此可以充能。

# = 红石灯 =

可控地产生[光](光.md)。

; 激活
常规激活规则，但从激活到关闭（即下降沿）有2红石刻（0.2秒）延迟。

; 工作
激活时产生亮度为15的光。

; 注意
红石灯是红石导体，因此可以充能。

# = TNT =

TNT用于产生[爆炸](爆炸.md)。

; 激活
TNT除了能被红石激活外，也能被[火](火.md)、[打火石](打火石.md)与其他爆炸点燃，还可以其他带有火焰的弹射物点燃。

; 工作
激活时，TNT会变为点燃的TNT，此时原有TNT方块变为实体，受重力影响，也能被推动，水也可以移动TNT。TNT被其他激活的TNT激活后40红石刻（4秒）爆炸。若是被其他爆炸引燃的话，则10-30红石刻（1-3秒）后爆炸。

# = 大型垂滴叶 =

大型垂滴叶可以支撑叶片上方的实体一定时间。实体站在叶片上或后叶片倾斜，使该实体摔落。一段时间后叶片会复原。

激活大型垂滴叶的叶片可以使其强制保持水平状态（若已倾斜会复原）。激活叶茎无效。

# = 合成器 =

合成器合成并投掷物品。

; 放置
合成器可朝向任何方向，放置时输出面会朝向放置者。

; 工作
激活时识别9个槽位中的物品，若符合某项合成配方，消耗材料合成1个物品并输出（同时会输出合成返回物）。

若合成器朝向容器且该容器可以容纳输出物，其会直接进入该容器，无法满足该条件的输出物以掉落物的形式掷出（与投掷器相同）。

; 注意
* 合成器为红石导体，因此可以充能。
* 合成器与常规容器不同，在被如漏斗，投掷器输入材料时会自动按：优先同类物品中最少，其次顺序靠前的优先级进入对应槽位（自动均分）。被漏斗或漏斗矿车吸取时则与常规容器相同。

# = 铜灯 =

可控地产生[光](光.md)，亮度等级会随着氧化程度增加而衰减。

; 工作
激活时或切换点亮和熄灭状态。

铜灯激活时，其纹理中心会出现一个红点，无论铜灯是否点亮。

# 交通工具
# = 船 =

船用于在[水](水.md)上进行运输，最多可以承载2个实体（包括玩家）。

;行为

  当在船里时，玩家可以使用移动控制键控制船的移动。船可以被水流推动，当船逆水流行驶时，船会沉到水下。它也会受到气泡柱的影响。

# = 矿车 =

矿车用于在[铁轨](#铁轨.md)上运输生物或玩家。

;行为

  玩家可以从外面推动矿车来移动这个矿车（即使这个矿车不在铁轨上），或者在矿车里按下前进控制键（只有矿车在铁轨上时才有效）。行驶在已激活的动力铁轨上的矿车会加速矿车。如果矿车正在一条已激活的动力铁轨上面行驶时，而且这条铁轨末端连接着一个红石导体，那么矿车在撞上这个方块时会被反弹。

# = 运输矿车 =

运输矿车用于在[铁轨](#铁轨.md)上储存和运输物品。

;行为

  运输矿车将会接收来自漏斗的物品，并允许运输矿车下面的漏斗拉取运输矿车里面的物品。

# = 命令方块矿车 =

命令方块矿车用于执行命令。

;行为

  在[激活铁轨](#激活铁轨.md)上时，命令方块矿车会每隔2个红石刻执行1次命令。

# =  动力矿车 =

动力矿车用于在[铁轨](#铁轨.md)上推动其他矿车。

;行为

  动力矿车会推动或拉动它自身以及其他矿车，而不需要动力铁轨。

# = 漏斗矿车 =

漏斗矿车用于收集、运输以及分配在[铁轨](#铁轨.md)上面的物品。

;行为

  漏斗矿车将会拉取其上方容器的物品，并且把物品推送到其下面的*漏斗*（被运输的物品的数量取决于其允许存储在容器里所持续的速率）。它也会捡起掉在上面的物品。如果漏斗矿车经过激活的激活铁轨，那么它将会立即停止运输物品，除非它再次经过未激活的激活铁轨。

# = TNT矿车 =

TNT矿车用于创造[爆炸](爆炸.md)。

; 行为
   TNT矿车在经过激活的激活铁轨后会被启动，延时后爆炸。

来自TNT矿车的爆炸不会摧毁铁轨以及铁轨的支撑方块。

# 杂项
# = 红石导体 =

红石导体可以用来传输信号。
;充能
  红石导体会被打开的电源或输出信号的[红石中继器](#红石中继器.md)或[红石比较器](#红石比较器.md)强充能。
  红石导体会被指向它（包括在它上方）的激活的[红石粉](#红石粉.md)弱充能。
;效果
  充能的红石导体会激活附着的[红石火把](#红石火把.md)使其熄灭，激活毗邻的背对它的[红石中继器](#红石中继器.md)或[红石比较器](#红石比较器.md)，激活毗邻的机械元件。
  只有强充能的红石导体会激活毗邻的红石粉。
