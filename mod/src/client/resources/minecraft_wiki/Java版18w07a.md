# Java版18w07a

*页面ID: 33639* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w07a**是[Java版1.13](Java版1.13.md)的第18个快照，发布于2018年2月14日<ref></ref>，也是首个加入了[水域更新](水域更新.md)内容的快照，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[去皮原木](去皮原木.md)**
* 可对着[木头](木头.md)[斧](斧.md)来制造。
* 表现与普通的木头一样，也可以用来合成[木板](木板.md)。

* *[气泡柱](气泡柱.md)**
* 由水下至少两格深的[岩浆块](岩浆块.md)或[灵魂沙](灵魂沙.md)创造。
* 岩浆块气泡柱会将实体向下推送，也会阻止物品浮起并使[船](船.md)下沉。
* 灵魂沙气泡柱会将实体向上推送。

* *[海草](海草.md)和[海带](海带.md)**
* 只能在水下放置，且上方至少需要一格水。
* * 也可以通过命令放置在干燥的陆地上。
* 生成于[海洋](海洋.md)中。
* 可长至数个方块高。
* 拥有动画纹理。
* 海草同样有高草变种。
* 海带可以被烧制为干海带。

* *[干海带块](干海带块.md)**
* 在熔炉中作为燃料使用时，可烧炼20个物品。

* *[楼梯](楼梯.md)与[台阶](台阶.md)**
* 加入了海晶石变种。

* *[海龟蛋](海龟蛋.md)**
* 踩在海龟蛋上方会将其破坏。
* * 僵尸和僵尸猪人会刻意地踩在海龟蛋上。

# = 物品 =
* *[三叉戟](三叉戟.md)**
* 可通过将其掷出，也可以通过作为近战武器使用，伤害为。
* 当前在生存模式无法获得。

* *[海带](海带.md)和[干海带](干海带.md)**
* 海带可用于在水下放置海带植株。
* 海带可在熔炉中烘干，成为干海带。
* 干海带可以食用，回复饥饿值。

* *[鳞甲](鳞甲.md)**
* 当幼年海龟长大时掉落。
* 可用于合成[海龟壳](海龟壳.md)。

* *[海龟壳](海龟壳.md)**
* 可作为头盔使用。
* * 装备和出水时会给予玩家10秒的[水下呼吸](状态效果.md)状态效果，本质上是给予玩家额外的10秒水下呼吸时间。
* 可将[粗制的药水](粗制的药水.md)酿造为[神龟药水](药水#神龟药水.md)。

* *[神龟药水](神龟药水.md)**
* 会给予1分钟的[](缓慢.md)IV和[抗性提升](抗性提升.md)IV效果。
* 用[红石粉](红石粉.md)酿造可将效果持续时间延长至3分钟。
* 用[荧石粉](荧石粉.md)酿造可将效果等级从IV升至VI。
* 用[火药](火药.md)或[龙息](龙息.md)酿造会分别得到[喷溅药水](喷溅药水.md)和[滞留药水](滞留药水.md)。

* *[药箭](药箭.md)**
* 加入了神龟之箭。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了海龟刷怪蛋。
* 加入了幻翼刷怪蛋。

# = 生物 =
* *[幻翼](幻翼.md)**
* 生成于[主世界](主世界.md)和[末地](末地.md)。
* 会攻击一段时间没有睡觉的[玩家](玩家.md)。
* 掉落[皮革](皮革.md)。

* *[海龟](海龟.md)**
* 生成于温暖生物群系的[海滩](海滩.md)，但这是暂时的
* 会在出生地海滩上下[蛋](海龟蛋.md)。
* 死亡时掉落0-2条[海草](海草.md)。
* 可以用它们旧壳的[碎片](鳞甲.md)来合成[海龟壳](海龟壳.md)。

# = 命令格式 =
* *[NBT](NBT.md)标签**
* 为[海龟](海龟.md)加入了[NBT标签](NBT标签.md)。
* 为[幻翼](幻翼.md)加入了[NBT标签](NBT标签.md)。

* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 标签中的方块在[水](水.md)中会渲染成模型空白部分为水的样子。
* 加入了方块和物品标签。

# = 游戏内容 =
* *[游泳](游泳.md)**
* 加入了新的游泳能力。
* * 在水中冲刺时激活。按下潜行键会使玩家下潜。

* *[魔咒](魔咒.md)**
* 加入了[忠诚](忠诚.md)魔咒。
* * 最高等级为III。
* * 用于三叉戟上，使三叉戟在投掷后返回。
* 加入了[穿刺](穿刺.md)魔咒。
* * 最高等级为V。
* * 用于三叉戟上，增加对海洋生物的伤害。
* 加入了[激流](激流.md)魔咒。
* * 最高等级为III。
* * 用于三叉戟上，在水中或下雨时投掷后会使玩家突进。
* 加入了[引雷](引雷.md)魔咒。
* * 仅有1级。
* * 用于三叉戟上，在[雷暴](雷暴.md)天气中召唤一道[闪电](闪电.md)击中生物。
* ** 需要目标生物直接在开阔地带，且所处的生物群系正在下雨。

# = 常规 =
* *[粒子](粒子.md)**
* 加入了[粒子](粒子.md)。

* *[统计](统计.md)**
* 加入了[统计数据](统计.md)<code>time_since_sleep</code>。
* * 由幻翼所使用。
* * 当[玩家](玩家.md)离开[床](床.md)时会重置。

# 更改
# = 实体 =
* *[鱿鱼](鱿鱼.md)**
* 鱿鱼现在会喷射墨汁以自卫。

* *[物品实体](物品实体.md)**
* 落入水中的物品实体现在会浮至水面。

* *[僵尸](僵尸.md)、[骷髅](骷髅.md)、[狼](狼.md)和[豹猫](豹猫.md)**
* 僵尸、骷髅、豹猫和狼会主动攻击幼年海龟。

# = 世界生成 =
* *[下界](下界.md)**
* [下界](下界.md)生成的垂直空洞——从基岩层延伸至y=35，y=10以下填满[熔岩](熔岩.md)。在下界底部呈链状生成，常形成宽阔的峡谷。
