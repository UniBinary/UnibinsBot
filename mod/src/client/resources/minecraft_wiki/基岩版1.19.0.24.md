# 基岩版1.19.0.24

*页面ID: 94886* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.0.24**（Xbox/Windows/Android）、**Preview 1.19.0.25**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.0](基岩版1.19.0.md)的第2个测试版，发布于2022年4月14日<ref></ref>，加入了[回响碎片](回响碎片.md)、[追溯指针](追溯指针.md)物品和[迅捷潜行](迅捷潜行.md)魔咒，移除了[铜制号角](铜制号角.md)，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[回响碎片](回响碎片.md)**
* 目前仅能通过[创造模式物品栏](创造模式物品栏.md)或[命令](命令.md)获得。
* 可用于合成追溯指针。

* *[追溯指针](追溯指针.md)**
* 指南针的新变种，会指向玩家上次死亡的位置。
* 指针会在玩家没有死亡位置或者位置在其他维度中时无规则旋转。
* 可使用指南针和8个回响碎片合成。

# = 游戏内容 =
* *[附魔](附魔.md)**
* 加入了新魔咒[迅捷潜行](迅捷潜行.md)。
* * 属于[宝藏型魔咒](宝藏型魔咒.md)，只能从[远古城市](远古城市.md)中的战利品箱获得带有该魔咒的物品。
* * 最高等级为III。
* * 只能应用于[护腿](护腿.md)。
* * 能够提高玩家潜行时的移动速度。
* ** III级提供的潜行速度为正常行走的75%。

# 更改
# = 方块 =
* *[蛙明灯](蛙明灯.md)**
* 加入了新音效。

* *[青蛙卵](青蛙卵.md)**
* 加入了新音效。
* 英文名称由“Frog Spawn”重命名为“Frogspawn”。

* *[红树胎生苗](红树胎生苗.md)**
* 更改了模型以匹配。

* *[泥巴](泥巴.md)**
* 现在将泥巴放在下方挂有[滴水石锥](滴水石锥.md)的方块上一段时间后，其会转化为[黏土](黏土.md)。

* *[泥砖](泥砖.md)**
* 现在被合成时会给予4个，而不是1个。

* *[强化深板岩](强化深板岩.md)**
* 不再能被[活塞](活塞.md)或[黏性活塞](黏性活塞.md)移动。

* *[幽匿感测体](幽匿感测体.md)**
* 现在仅能使用[精准采集](精准采集.md)附魔工具开采，否则只会掉落[经验](经验.md)。

* *[幽匿尖啸体](幽匿尖啸体.md)**
* 不再会被[红石信号](红石信号.md)激活。
* 加入了方块状态，用于决定其是否可以生成[监守者](监守者.md)。
* * 世界生成过程中放置的默认为。
* * [幽匿催发体](幽匿催发体.md)蔓延出的以及玩家放置的默认为。
* 更改了粒子的渲染方式以匹配。
* 现在使用精准采集附魔工具挖掘时又会掉落其自身了。

# = 生物 =
* *[悦灵](悦灵.md)**
* 现在生命值为，而不是。
* 现在每秒会恢复生命值。

* *[流浪商人](流浪商人.md)**
* 现在有概率以5个[绿宝石](绿宝石.md)的价格出售1个[红树胎生苗](红树胎生苗.md)。

* *[监守者](监守者.md)**
* 现在会优先攻击玩家，而不是其他生物。
* 改进了跟随可疑目标的行为。
* 提高了靠嗅觉侦测目标的范围，由16格更改为24格。
* 不再会对[创造模式](创造模式.md)玩家施加[黑暗](黑暗.md)效果。
* 现在被玩家或驯服的狼杀死后会掉，而不是。

# = 世界生成 =
* *[红树林沼泽](红树林沼泽.md)**
* 调整了生物群系大小和地物分布以匹配。
* 增加了红树林沼泽的泥巴层厚度，现在[石头](石头.md)层的上方皆为泥巴。
* 现在红树林沼泽里高红树的生成频率远高于普通红树。
* 现在[热带鱼](热带鱼.md)会在水中生成。
* 现在热带[青蛙](青蛙.md)和史莱姆会在此生成。
* 水下迷雾的颜色由与普通沼泽一致的黄色更改为青色。
* 水体颜色由与普通沼泽一致的灰色更改为青色。

* *[红树](红树.md)**
* 现在树干由[红树原木](红树原木.md)组成，而不是[橡木原木](橡木原木.md)。
* 现在会有[覆地苔藓](覆地苔藓.md)生成在红树根的上方。

# = 常规 =
* *旧世界升级**
* 进行了多项对[区块](区块.md)过渡的改进。

* *[菜单屏幕](菜单屏幕.md)**
* 背景更改为[红树林沼泽](红树林沼泽.md)。
* * 由于测试版默认使用独有背景图，新背景图在一般情况下并不可见。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“香草实验”子选项后才可使用。

# = 物品 =
* *[铜制号角](铜制号角.md)**
* 已被移除。

* *[山羊角](山羊角.md)**
* 现在吹奏音效是瞬间播放的。
* 更改了“Sing”、“Seek”、“Admire”、“Call”、“Yearn”和“Resist”变种使用的音效以匹配。
* * “Sing”、“Seek”和“Admire”变种现在分别使用原有的“Seek”、“Admire”和“Yearn”音效。
* * “Call”、“Yearn”和“Resist”变种现在分别使用原有的“Resist”、“Fly”和“Dream”音效，“Fly”和“Dream”变种现已被移除。
* 现在[掠夺者前哨站](掠夺者前哨站.md)的战利品箱中会生成更多音效种类的山羊角。

# 修复
* *幽匿尖啸体**
* 调整了幽匿尖啸体的尖啸粒子。（）
* 为幽匿尖啸体加入了方块状态，用于决定其是否可以生成监守者，只有世界生成期间放置在深暗之域和远古城市的幽匿尖啸体默认为。（）
* 玩家远离被激活的幽匿尖啸体时不再会阻止生成监守者。
* 幽匿尖啸体不再会试图在和平难度下生成监守者。
* 幽匿尖啸体现在会对附近所有玩家增加生成阶段等级，而不只是对最近的玩家增加等级。

* *监守者**
* 现在监守者受到伤害时会出现受伤动画。（）
* 修复了监守者的胸骨UV与右侧卷须UV相重叠的漏洞。（）
* 监守者不再会对创造模式玩家施加黑暗效果。（）

* *强化深板岩**
* 强化深板岩不再能被活塞或黏性活塞移动。（）

* *青蛙**
* 蛙明灯和青蛙卵现在拥有新的音效。（、）
* 青蛙卵的英文名称由“Frog Spawn”重命名为“Frogspawn”。（）

* *触摸控制**
* 玩家现在可以在船上切换快捷栏的物品槽位。（）

* *悦灵**
* 修复了非悦灵主人玩家拿走正在跟随主人的悦灵的手持物品时可能发生的崩溃。

* *运输船**
* 现在运输船的物品组在创造模式物品栏中会被正确翻译。（）
* 红树木运输船现在拥有合成配方。（）

* *泥砖**
* 现在合成一次泥砖后会正确给予4个泥砖。

* *游戏内容**
* 将酿造台的药水槽的堆叠数量限制为1，以防止材料槽的物品在酿造完毕时被覆盖。
* 修复了组件的方块参数为未知方块时发生的崩溃。
* 受重力影响的方块现在能够正确下落在可替换方块上。（）
* 玩家现在可以不断放置台阶。（）

* *常规**
* 修复了在新的创建新世界UI中点击按钮顶部像素时不会触发操作的问题。（）

* *图形**
* 修复了创造模式玩家站在装有熔岩的炼药锅中时，其身上的着火动画会变闪烁的漏洞。（）

* *物品**
* 修复了白色染料、黑色染料、棕色染料和蓝色染料会显示错误名称的问题。（）

* *性能与稳定性**
* 修复了Pocket UI下的附魔选项不会正确显示的问题。

* *命令方块**
* 现在当命令方块执行命令来复制自己两次时，复制出的命令方块会在接收到红石信号的第一时间尝试激活。（）

* *技术性**
* 现在命令选择器会正确地以名称识别玩家，而不是以名称标签识别。
* 在客户端完成加入前触发的标题命令现在会正确显示，而不是被忽略。
* 现在过滤器会在活动对象移动时返回正确的值。
* 减少了在部分设备上使用大量或运算符来解析Molang表达式时的崩溃。
* 将食用动画与食用持续时间相绑定。</onlyinclude>
