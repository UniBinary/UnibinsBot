# 命令/drop（基岩版）

*页面ID: 113513* | *来源: Minecraft Wiki*

让[智能体](智能体.md)在指定的方向上丢出指定槽位编号上指定数量的物品。

# 语法
   <code>drop <slotNum: int> <quantity: int> <direction: string></code>

# 参数
<code>slotNum: int</code>
  指定要放置的方块的槽位号，槽位号是1到27之间的整数。

<code>quantity: int</code>
  指定掉落物的数量。必须为1到64之间的整数。

<code>direction: string</code>
  指定智能体丢出物品的方向。
  必须为以下之一：
  * <code>forward</code>
  * <code>back</code>
  * <code>left</code>
  * <code>right</code>
