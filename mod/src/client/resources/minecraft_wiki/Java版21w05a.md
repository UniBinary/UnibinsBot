# Java版21w05a

*页面ID: 77689* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w05a**是[Java版1.17](Java版1.17.md)的第7个快照，发布于2021年2月3日<ref></ref>，加入了[繁茂洞穴](繁茂洞穴.md)相关的一些方块和物品、以及新的方块与物品[标签](Java版标签.md)，同时修复了一些漏洞。

# 新内容
# = 方块 =
* *[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)**
* 植物方块。

* *[杜鹃树叶](杜鹃树叶.md)和[盛开的杜鹃树叶](盛开的杜鹃树叶.md)**
* 新的[树叶](树叶.md)种类。

* *[洞穴藤蔓](洞穴藤蔓.md)**
* 光源和食物源，会长出[发光浆果](发光浆果.md)。
* 通过使用发光浆果种植在方块底部获得。

* *[小型垂滴叶](小型垂滴叶.md)**
* 一种植物方块。
* 可通过和[流浪商人](流浪商人.md)进行[交易](交易.md)获得。
* 对其使用骨粉可使之成长为大型垂滴叶。

* *[大型垂滴叶](大型垂滴叶.md)**
* 一种植物方块。
* 实体可在叶片上停留，时间过后继续停留则会摔落。

* *[垂根](垂根.md)**
* 装饰性方块，可放置在方块底部。

* *[缠根泥土](缠根泥土.md)**
* 装饰性方块。

* *[苔藓块](苔藓块.md)**
* 一种不透明的植物方块。

* *[覆地苔藓](覆地苔藓.md)**
* 一种纹理和苔藓块相同但高度只有1像素的方块。

* *[孢子花](孢子花.md)**
* 一种植物方块。
* 可放置在方块的底部。
* 滴落绿色的“孢子”粒子。

# = 物品 =
* *[发光浆果](发光浆果.md)**
* 新的[食物](食物.md)。
* 可从长出果实的洞穴藤蔓上采集获得。
* 可种植在方块底部。

* *[标签](Java版标签.md)**

* 加入了方块标签。
* * 包含了洞穴藤蔓主体和尖端方块。
* 加入了方块标签。
* * 包含了方块标签、方块标签、泥土、沙砾、沙子、苔藓块、方块标签、草丛、高草丛、覆地苔藓、小型垂滴叶、大型垂滴叶、大型垂滴叶茎和藤蔓。
* 加入了物品标签。
* * 包含了甜浆果和发光浆果。

* *纹理**
* 加入了新的纹理。
* * 该纹理目前在游戏中尚未被应用。

# 更改
# = 方块 =
* *[切石机](切石机.md)**
* 现在可用于加工[铜块](铜块.md)以获得其变种。

* *[铜块](铜块.md)、[切制铜块](切制铜块.md)及其变种**
* 重命名了铜块的各个锈蚀变种以同步[基岩版](基岩版.md)。
* 铜块的锈蚀现在受游戏规则影响。

* *[堆肥桶](堆肥桶.md)**
* 下列物品现在可以用来堆肥：
* * 30%概率：杜鹃树叶、发光浆果、覆地苔藓、小型垂滴叶、垂根。
* * 50%概率：盛开的杜鹃树叶。
* * 65%概率：孢子花、杜鹃花丛、苔藓块、大型垂滴叶。
* * 85%概率：盛开的杜鹃花丛。

* *[细雪](细雪.md)**
* 现在可被[活塞](活塞.md)移动。
* 现在可熄灭[箭](箭.md)上的火焰。

* *[幽匿感测体](幽匿感测体.md)**
* 加入了下列可检测的游戏事件：

* *[藤蔓](藤蔓.md)**
* 现在可用[剪刀](剪刀.md)加速破坏。

# = 物品 =
* *[收纳袋](收纳袋.md)**
* 现在当收纳袋第一次出现在玩家的物品栏里时，玩家会收到收纳袋的[教学提示](教学提示.md)。

# = 生物 =
* *[溺尸](溺尸.md)**
* 现在有概率掉落[铜锭](铜锭.md)，而不再掉落[金锭](金锭.md)，与[基岩版](基岩版.md)同步。

* *[骷髅](骷髅.md)**
* 现在陷入[细雪](细雪.md)后开始转化为[流浪者](流浪者.md)的进程，且另需才会转化为[流浪者](流浪者.md)。
* * 后，转化过程不可逆。
* * 也就是说，骷髅转化为流浪者总共需要。

* *[狐狸](狐狸.md)**
* 现在会主动寻找并吃下发光浆果。
* 现在可使用发光浆果繁殖。
* 现在可在[细雪](细雪.md)上行走而不会陷入其中。

* *[流浪商人](流浪商人.md)**
* 现在会出售小型垂滴叶。

# = 游戏内容 =
* *[进度](进度.md)**
* 将发光浆果加入到进度“”的达成要求当中。

* *NBT数据**
* 为所有弹射物实体数据加入了字段。
* * 若该字段的值为，则弹射物会在下一游戏刻触发弹射物发射的游戏事件，然后被周围的幽匿感测体检测到。

# = 常规 =
* *[游戏事件](游戏事件.md)**
* 移除了武装盔甲架、结束进食、攻击实体和使用打火石事件。
* 加入了方块变化、饮用完毕、进食、实体受伤、杀死实体、放置实体、装备物品、生物互动、矿车移动、引爆 、劫掠兽咆哮、鸣钟、剪切、潜影贝关闭和潜影贝打开事件。

* *[资源包](资源包.md)**
* 提升了物品模型的多层覆盖性能。
* 为的GUI纹理加入了收纳袋教程图标。

* *[标签](Java版标签.md)**
* 将杜鹃树叶和盛开的杜鹃树叶添加进方块和物品标签。
* 将狐狸添加进实体类型标签。
* 更改了游戏事件标签。
* * 重命名为。
* * 加入了游泳事件。
* 更新了游戏事件标签以符合所有的游戏事件（详见上述）。

* *[自定义世界](自定义世界.md)**
* 由于光照计算代码的原因，现在世界的建筑高度范围被缩小到最大可以修改为Y=-2032到2031（上一个版本是Y=-2048到2031）。<ref></ref>
