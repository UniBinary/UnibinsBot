* *14w27b**是[Java版1.8](Java版1.8.md)的第33个快照，发布于2014年7月2日<ref></ref>，修复了快照[14w27a](14w27a.md)中的一些漏洞和崩溃。

# 更改
# = 常规 =
* *[方块模型](方块模型.md)**
* 方块模型文件现在允许随机的模型数组。
* * 因此，[草方块](草方块.md)、[泥土](泥土.md)、[沙子](沙子.md)、[红沙](红沙.md)、[石头](石头.md)、[下界岩](下界岩.md)、[基岩](基岩.md)和[TNT](TNT.md)的顶部纹理都是随机旋转的。
