# Java版标签/时间线

*页面ID: 170771* | *来源: Minecraft Wiki*

* *时间线标签（Timeline Tags）**是一组[时间线](时间线.md)ID。

# 使用
在[维度类型](维度类型.md)定义文件中，时间线标签被用于指定当前维度类型中所包含的多个时间线。示例文件参见。

# 当前版本

# = in_end =
* 在[末地](末地.md)活动的时间线。

# = in_nether =
* 在[下界](下界.md)活动的时间线。

# = in_overworld =
* 在[主世界](主世界.md)活动的时间线。

# = universal =
* 在所有维度活动的时间线。
