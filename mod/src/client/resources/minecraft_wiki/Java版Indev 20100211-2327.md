# Java版Indev 20100211-2327

*页面ID: 173022* | *来源: Minecraft Wiki*

<onlyinclude>

* *Minecraft Indev**的一个版本发布于2010年2月11日23:27（UTC），加入了[昼夜更替](昼夜更替.md)。<ref>[Adura的IRC记录](#logs.md): "(18:27:56) <Miclee> Day/night is in indev."..."(18:28:32) <Notch> oh, yeah, it's updated"</ref>

# 新内容
# = 游戏内容 =
* *[昼夜更替](昼夜更替.md)**
* 每个昼夜更替的周期为15分钟。<ref></ref>
* * 每个周期包括7.5分钟的白天和7.5分钟的黑夜。
* 决定生物的生成时间。

# 更改
# = 生物 =
* *[绵羊](绵羊.md)**
* 现在被击中时会掉落1-3个羊毛，羊毛的颜色可能是白色、浅灰色或灰色。<ref></ref>

# = 游戏内容 =
* *[音效](音效.md)**
* 加入了[被动型生物](被动型生物.md)的音效。<ref>[Adura的IRC记录](#logs.md): "(18:32:10) <rcfighter> And now I can hear the sheep outside my farm"</ref>
* * 在此版本之前，它们均使用[玩家](玩家.md)的音效。</onlyinclude>
