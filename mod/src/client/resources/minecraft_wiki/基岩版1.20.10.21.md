# 基岩版1.20.10.21

*页面ID: 104393* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.10.21**（ChromeOS/Android）、**Preview 1.20.10.21**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.10](基岩版1.20.10.md)的第2个测试版，发布于2023年6月1日<ref></ref>，在[实验性玩法](实验性玩法.md)中加入了[配方](配方.md)解锁机制和命令，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“配方解锁”子选项。
* * 用于启用[配方](配方.md)解锁机制。

* *[闪烁标语](闪烁标语.md)**
* 加入了以下闪烁标语：
* * Joule is neat too!

# 更改
# = 非生物实体 =
* *[竹筏](竹筏.md)**
* 移除了合成配方中的[木锹](木锹.md)，以匹配。

# = 技术性 =
* *常规**
* 将自定义方块的更改为。
* 修复了运行意向时会出现的崩溃。
* 修复了当实体与方块发生碰撞时尝试修改实体的尺寸会发生的崩溃。（）

* *物品**
* 现在拥有的物品能在放置方块时正确设置朝向。
* 现在拥有的自定义物品不再会将方块放置在错误的位置。
* 开放了1.20.10及以上版本的实验性JSON格式中的物品组件。
* 开放了1.20.10及以上版本的实验性JSON格式中的物品组件。
* 开放了1.20.10及以上版本的实验性JSON格式中的物品组件。

# 修复
* *潜行和爬行**
* 玩家通过活板门以在炼药锅或堆肥桶内爬行时不再会被困其中。（）
* 纸娃娃现在会在爬行时正确显示。
* 修复了玩家使用鞘翅滑翔或游泳时偶尔会拥有不正确的碰撞箱的问题。（）

* *游戏内容**
* 现在可疑的沙砾和可疑的沙子会在地图上正确显示。
* 修复了在末地中放置末地水晶时可能发生的崩溃。（）
* 盾牌不再会在处于回刺反击姿势的盔甲架的模型内错位。
* 修复了冰上的船会在客户端区块生成启用时消失的问题。（）

* *图形**
* 水下和迷雾效果现在相对于相机视角位置，而不是玩家位置。
* 修复了视场角会影响第一人称视角下的手臂和望远镜边框的外观的问题。（）
* “花俏的树叶”选项现在会立即生效，且不再会导致光线渲染问题。（）

* *生物**
* 将生物在夜间消失的概率恢复正常。（）
* 现在站立不动的骆驼受到伤害时会播放行走动画。（）
* 嗅探兽不再能在空中刨挖种子。

* *用户界面**
* 重新排列了UI屏幕的游戏手柄提示框，以使按钮在控制器的同一侧对齐。

* *原版趋同**
* 更新了竹筏的合成配方，现在不包含木锹。（）</onlyinclude>
