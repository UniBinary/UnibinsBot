# 格挡

*页面ID: 6765* | *来源: Minecraft Wiki*

<div style='float:right'></div>
* *格挡（Blocking）**是一种允许玩家对攻击作出抵挡的游戏机制。

# 用法
# = Java版 =
对攻击作出格挡需要使用[盾牌](盾牌.md)。盾牌会将玩家的移动速度降慢至[潜行](潜行.md)速度，并在5刻（0.25秒）后使来自玩家前方的可格挡攻击和击退效果失效。攻击的所有附加效果（如凋零[效果](效果.md)或[着火](着火.md)）都不会对格挡者起作用。一次成功的格挡会发出响声并消耗盾牌的耐久度。

可格挡的攻击包括生物的近战攻击、所有无特殊效果的弹射物、[箭](箭.md)、[荆棘](荆棘.md)魔咒的反伤以及[爆炸](爆炸.md)。

# = 基岩版 =
对攻击作出格挡需要使用盾牌。蹲下（潜行、向下飞行或在水中向下移动）会触发盾牌功能。骑乘时也会自动触发，并且不会阻止盾牌效果触发。

# 你知道吗
* 格挡姿态是达到最小移动速度的要素之一。要达到最小移动速度，玩家需同时[潜行](潜行.md)并格挡，获得[](缓慢.md)效果，倒退走过放在[冰](冰.md)上的[灵魂沙](灵魂沙.md)，穿过[水](水.md)和[蜘蛛网](蜘蛛网.md)。此时玩家的移动速度约为方块每秒，或16x16纹理下的 - 像素每秒。在没有效果的情况下，玩家移动速度约为0.023854961832格每秒（1格41.92秒）。
