# 物品格式/Java版1.20.5前

*页面ID: 112518* | *来源: Minecraft Wiki*

物品存在于游戏的多个存储文件中，它们都使用统一的格式进行存储。

# 物品存储格式
物品数据可以用于[玩家](玩家.md)的物品栏和[末影箱](末影箱.md)物品栏、[箱子](箱子.md)中的物品、[物品实体](物品实体.md)、[熔炉](熔炉.md)方块实体、[酿造台](酿造台.md)方块实体和[村民](村民.md)交易内容中。

物品存储有两种方式：
* 带槽位存储：带有标签指定物品所在的槽位，比如在箱子中。
* 不带槽位存储：物品不在槽位中，而是作为某个属性类的数据或配置项，例如物品实体。

物品不仅会存储它的[命名空间ID](命名空间ID.md)和数量，也会存储物品内部的附加信息，即。绝大多数物品并没有这些信息，所以这项为空或不存在。在内部定义的标签**都是可选的**，但物品没有这些信息它的行为可能会变得异常。

物品存储格式如下：
<div class="treeview">
*  根标签
* * ：物品的[命名空间ID](命名空间ID.md)。若未指定，游戏会在加载区块或者生成物品时将其变更为空气。
* * ：（大于0）堆叠的[物品](物品.md)数量，此数字不受到对应物品的最大堆叠数量限制。当此值不大于0时在游戏系统中将此物品视为空气。
* * ：（可选）关于当前物品的额外信息，详细内容见下。此标签对于多数物品来说都是非必需项。
</div>
