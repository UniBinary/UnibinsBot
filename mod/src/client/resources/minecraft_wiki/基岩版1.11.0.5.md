# 基岩版1.11.0.5

*页面ID: 41481* | *来源: Minecraft Wiki*

<onlyinclude>
* *beta 1.11.0.5**是[1.11.0](基岩版1.11.0.md)的第4个测试版，发布于2019年3月14日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[高炉](高炉.md)和[烟熏炉](烟熏炉.md)**
* 现在能够储存产生的经验值。

# = 生物 =
* *[马](马.md)**
* 更改了UI中的鞍槽的纹理，以匹配新的鞍纹理。

* *[劫掠兽](劫掠兽.md)**
* 改进了寻路AI。

* *[村民](村民.md)**
* 现在会在工作后短暂休息。
* 现在认领工作方块时，该方块上方会出现高兴的村民粒子效果；若无法触及该方块，则显示愤怒粒子效果。

# = 常规 =
* *[纹理更新](纹理更新.md)**
* 加入了更多方块和物品的新纹理，包括[染色玻璃](染色玻璃.md)。

* *[设置](设置.md)**
* 文本转语音现在会读出所有对话框和游戏内提示。

* *[袭击](袭击.md)**
* 如果在袭击中所有[村民](村民.md)被杀死或所有的[床](床.md)被摧毁，在村庄中的所有玩家现在会受到[不祥之兆](不祥之兆.md)的影响。
* 现在在袭击时会播放具有方向性的号角音效，帮助定位剩余掠夺者的位置。
* 袭击者现在可以穿过水域来进入村庄。
* 现在在袭击时会生成骑乘劫掠兽的唤魔者。
* 现在女巫在袭击时进入村庄具有更高的优先级。

* *用户界面**
* 用户界面背景色从灰色改成了黑色透明。

# 修复
* *修复了42个漏洞**<br>
* *崩溃**
* 修复了游戏进行时的崩溃现象。
* 导入1.10测试版世界时，禁用[实验性玩法](实验性玩法.md)选项会导致游戏崩溃。
* 村民死亡后游戏崩溃。

* *袭击事件**
* 移除了袭击结束后的爆炸占位符音效。
* 号角声现在可用于辨别袭击者的位置。
* 袭击结束后，空的进度条仍然存在。
* 安卓设备里无法发起袭击事件。
* 袭击不再在将模式设置为和平然后切换回生存时被消除。
* 袭击者现在会回击攻击它们的玩家。
* 袭击者现在可以穿过水域来进入村庄。
* 袭击者不再生成于树叶里。
* 现在可以生成骑乘劫掠兽的唤魔者。
* 女巫现在会积极尝试进入村庄。
* 移除了玩家获得村庄英雄后的多余粒子效果。
* 改进了生成袭击队伍的区域选择。

* *常规**
* TTS文本转语音不再覆盖叙述。
* TTS文本转语音现在可以阅读控制器的绑定按键。

* *世界生成**
* 村庄里生成在水中的栅栏现在会被水包围着。
* 村庄的动物圈里不再生成浮空的树。

* *生物**
* 修复了部分村民的梦游行为。
* 生物的寻路AI现在可以使得它们通过含水的方块。（）
* 凋灵骷髅和守卫者现在会正常生成。（）
* 更改了部分村民交易选项的补给数据。
* 在重新进入世界后，流浪商人不再更改其交易选项。
* 自然生成的铁傀儡现在会回击玩家。
* 改进了劫掠兽的寻路AI。
* 村民工作后现在会短暂休息。
* 杀死有掠夺者骑乘的劫掠兽不再使得掠夺者悬空。

* *方块**
* 高炉和烟熏炉产生的经验值现在可以储存。
* TNT爆炸时不会被弹开。（）
* 制箭师村民工作时没有工作音效。
* 村民在找到可用的职业站点方块时现在会发出高兴的粒子效果，在无法触及该方块时会发出愤怒的粒子效果。

* *物品**
* 地图现在会显示水下地形的差异。（）

* *用户界面**
* 在安卓设备下使用携带版UI时，制图台的输出槽位不再覆盖文本框。
* 使用控制器在交易界面里选择左侧的交易选项时现在可以完成交易。
* 马的UI里的鞍槽位的轮廓现在会与新的鞍纹理相匹配。
* 和讲台互动时，部分控制器的按键提示丢失。
* 使用高分辨率的资源包时，织布机的UI里现在会显示正确的旗帜图案。
* 部分触摸屏设备里的Boss条显示错误。
* 选择交易选项时，不再使得交易物品被自动放置。
* 在村民升级前，以锁定的交易选项不再出现。</onlyinclude>
