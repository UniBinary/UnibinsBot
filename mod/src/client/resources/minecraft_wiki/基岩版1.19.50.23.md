# 基岩版1.19.50.23

*页面ID: 99869* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.50.23**（Android）、**Preview 1.19.50.23**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.50](基岩版1.19.50.md)的第4个测试版，发布于2022年11月3日<ref></ref>，修复了一些漏洞。

# 更改
# = 命令格式 =
* ***
* 所有新的子命令不再属于[实验性玩法](实验性玩法.md)。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”、“即将推出的创作者功能”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[告示牌](告示牌.md)和[悬挂式告示牌](悬挂式告示牌.md)**
* 现在使用控制器时，告示牌和悬挂式告示牌的所有变种都会显示“放置”提示。
* 生物现在可以在附着在方块侧面的悬挂式告示牌上正确寻路。

# = 生物 =
* *[骆驼](骆驼.md)**
* 玩家不再能够骑着骆驼在水面上行走或进入水中。（）
* 坐着的骆驼不再会在加载时播放坐下的动画，而是在加载完毕时坐下。
* 骆驼现在可以在不跳跃的情况下越过1.5格高的方块。（）

# = 非生物实体 =
* *[竹筏](竹筏.md)和[运输竹筏](运输竹筏.md)**
* 运输竹筏的英文名称现在会显示为“Raft with Chest”，而不是“Bamboo Raft with Chest”。（）
* 现在竹筏或运输竹筏上的玩家下船时会显示正确的工具提示。（）

# = 常规 =
* *游戏内容**
* 修复了悬挂式告示牌可以替换掉孢子花和大型垂滴叶的问题。
* 修复了悬挂式告示牌可以附着在竹笋上的问题。
* 修复了对着双层竹马赛克台阶使用选取方块或将其破坏时会获得竹台阶的问题。（）
* 修复了竹笋被活塞推动时不会被破坏的问题。

* *常规**
* 修复了延迟时间大于0时不会激活连锁型命令方块的漏洞。

* *音效**
* 修复了悬挂式告示牌不受方块音量影响的问题。

# = 技术性 =
* *命令**
* 命令方块执行的命令不再会保留实体的旋转方向。（）

* *API**
* 修复了组件在部分情况下会返回错误值的问题。（）
* 加入了函数。
* * 用于返回在指定位置放置指定类型的方块或方块排列的有效性。
* 加入了函数。
* * 用于尝试在指定位置放置指定方块排列并根据函数给出其结果。

# 修复
* *游戏内容**
* 船和运输船被活塞推动时不再会传送到处。（）

* *常规**
* 修复了升级1.18前的世界时存档区块会不正确混合的问题。（）

* *图形**
* 为兼容的驱动程序加入了对英特尔集成或独立显卡的D3D12支持。

* *物品**
* 修复了书与笔无法署名并关闭的问题。（）

* *Realms**
* 缩小了上传世界和附加包时的文本以适应对话框。
* 玩家加入已经空了若干分钟的Realms时不再会收到错误消息。

* *性能与稳定性**
* 玩家物品栏中存在包含生物的物品时，打开配方书不再会导致游戏性能显著下降。（）
* 减轻了物品进出漏斗时的服务器卡顿。（）
* 修复了Xbox控制器的摇杆盲区和灵敏度问题。（）

* *触摸控制**
* 修复了新的触摸控制方案下的取消骑乘按钮看起来很模糊的问题。（）

* *用户界面**
* 修复了在携带版UI下的物品栏界面中，物品不能被丢入创造模式物品栏的问题。
* 修复了在携带版UI下的物品栏界面中，“可合成/所有”选项只能在搜索选项卡中更改，而不能在其他选项卡中更改的问题。
* 在Xbox上重新打开菜单屏幕时，使用鼠标进行的镜头移动不再会改变鼠标位置。（）
* 现在选中物品的堆叠计数的文本颜色是白色而不是黄色。

* *原版趋同**
* 被手持重命名后的武器的生物杀死时，英文死亡消息的末尾不再会产生多余的“s”。（）

* *旁观模式**
* 现在输入告示牌的玩家进入旁观模式时，告示牌文本界面会被关闭。
* 现在站在压力板上的玩家进入旁观模式时，压力板会被取消激活。（）</onlyinclude>
