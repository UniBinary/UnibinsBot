# Java版12w15a

*页面ID: 32357* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w15a**是[Java版1.3.1](Java版1.3.1.md)的首个快照，发布于2012年4月12日<ref></ref>。

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 现在可在水中放置[船](船.md)，在铁轨上放置[矿车](矿车.md)、[动力矿车](动力矿车.md)和[运输矿车](运输矿车.md)。

# = 物品 =
* *常规**
* 同一种可堆叠的物品现在分别单独扔到物品栏外会自动堆叠。

# = 生物 =
* *[史莱姆](史莱姆.md)**
* 减少了史莱姆在超平坦世界里的生成率。

# = 非生物实体 =
* *[动力矿车](动力矿车.md)**
* 在[创造模式](创造模式.md)下右键点击一个动力矿车会给予其一个[煤炭](煤炭.md)。

# = 常规 =
* *[控制](控制.md)**
* “选取方块”按钮使用时给予正确的方块；对着[生物](生物.md)点击时，会给予对应的[刷怪蛋](刷怪蛋.md)。
*  + 点击可以用于佩戴[盔甲](盔甲.md)。
*  + 点击可以把物品放进[酿造台](酿造台.md)和[附魔台](附魔台.md)里。</onlyinclude>
