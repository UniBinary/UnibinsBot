* *掉落物（Drops）**是大多数[方块](方块.md)被破坏、[生物](生物.md)或其他[实体](实体.md)死亡后出现的[物品实体](物品实体.md)。

# 掉落物种类
# = 常见掉落物 =
* *常见掉落物（Common drops）**会在生物受到[致死伤害](生命#死亡.md)时出现在其所在的地点。多数生物在被杀死时所能掉落的物品是固定的。某些常见掉落物，譬如[皮革](皮革.md)，并不总是掉落，但掉落概率很高（至少为50%，取决于掉落范围）。如果生物不是由玩家杀死（包括驯服的狼）的话，某些常见掉落物，如[烈焰棒](烈焰棒.md)，就不会掉落。

对以上每一种物品，其掉落数量都会随机（[均匀](wzh:离散型均匀分布.md)）的分布；这种分布使用“掉落范围”来描述。举个例子，一头[牛](牛.md)会掉落0-2份[皮革](皮革.md)物品与1-3份[生牛肉](生牛肉.md)物品。由于上述皮革的掉落范围包括0，因此有的概率不会掉落。

幼年[友好生物](友好生物.md)死亡后不会掉落常见掉落物。

# == 抢夺魔咒 ==
当生物被[抢夺](抢夺.md)魔咒击杀时，某些常见掉落物与少见掉落物的掉落数量会随着魔咒等级的增加而增加。就机制上来说，游戏会随机在0到魔咒等级的区间中随机产生一个分数，并将其四舍五入为最接近的整数，这就是额外掉落的物品数量。

下表是不同魔咒等级对应不同上限增加量的概率：

[流浪者](流浪者.md)和[沼骸](沼骸.md)的药箭是特殊情况：抢夺魔咒会尝试增加药箭的掉落数量，但最终掉落量上限为1。因此，抢夺魔咒增加的是箭掉落的概率，最多达抢夺III的，而不是箭掉落的数量。

# = 稀有掉落物 =
* *稀有掉落物（Rare drops）**只会在怪物被玩家或驯服的狼击杀时出现，但某些稀有掉落物也可以通过其他方式获得。稀有掉落物最多只会掉落1个，且可能会跟普通掉落物一起掉落。是否为稀有掉落物由生物的[战利品表](战利品表.md)中的<code>random_chance_with_looting</code>属性决定。

典型的稀有掉落物掉落概率为2.5%，且武器上的[抢夺](抢夺.md)魔咒每1级会额外增加1%（上限为抢夺III的5.5%）。唯一的例外情况是[兔子](兔子.md)的[兔子脚](兔子脚.md)掉落概率为10%，每1级抢夺魔咒额外增加3%（上限为抢夺III时的19%）。

[凋灵骷髅](凋灵骷髅.md)的[凋灵骷髅头颅](凋灵骷髅头颅.md)掉落概率是2.5%，每1级抢夺魔咒额外增加2%（上限为抢夺III时的8.5%）；而[溺尸](溺尸.md)的[铜锭](铜锭.md)掉落概率是11%，每1级抢夺魔咒额外增加2%（上限为抢夺III时的17%）。

请注意，某些生物有多个稀有掉落物（[守卫者](守卫者.md)和[僵尸](僵尸.md)类生物），则2.5%会平均分配给每个稀有掉落物，而不是独立计算。

[潜影贝](潜影贝.md)掉落的[潜影壳](潜影壳.md)技术上来说也是稀有掉落物，它每次仅掉落1个，但它并不需要玩家杀死才掉落，也有着不是很稀有的50%掉落概率。每1级抢夺魔咒额外增加6.25%（上限为抢夺III时的68.75%）。

# ==掉落概率==
当生物被玩家或驯服的[狼](狼.md)击杀时，会有一定概率掉落其生成时附带的装备（武器，工具或盔甲）。怪物生成时附带的每一件装备有/的概率掉落。掉落概率由生物的<code>drop_chances</code>标签决定。[抢夺](抢夺.md)魔咒每1级增加1%概率（最高为抢夺III时的11.5%，最高为抢夺III时的28%）。每件装备的掉落概率都是独立计算的，这意味着怪物死亡时有可能掉落多件装备。

某些装备物一定不会掉落：

* [万圣节](万圣节.md)时怪物自然装备的[雕刻南瓜](雕刻南瓜.md)、[南瓜灯](南瓜灯.md)不会掉落。<ref></ref>
* [恼鬼](恼鬼.md)手上的[铁剑](铁剑.md)不会掉落。
* [村民](村民.md)手持的物品不会掉落。
* 由不祥试炼额外生成的装备不会掉落。

某些装备物一定会掉落：

* 生物生成后捡起的所有物品都一定会掉落，就算不是被玩家击杀也一样，对幼年[僵尸](僵尸.md)亦成立。
* * 只对敌对生物成立。命令添加的物品不会掉落。
* [不祥旗帜](不祥旗帜.md)总会在[袭击队长](袭击队长.md)死亡时掉落。
* 玩家为[马](马.md)、[驴](驴.md)、[骡](骡.md)、、[殭屍馬](殭屍馬.md)、[羊驼](羊驼.md)、[猪](猪.md)、[炽足兽](炽足兽.md)、[骆驼](骆驼.md)、[駱駝屍殼](駱駝屍殼.md)、[快乐恶魂](快乐恶魂.md)、[鸚鵡螺](鸚鵡螺.md)和[殭屍鸚鵡螺](殭屍鸚鵡螺.md)装备的物品都会掉落，如[鞍](鞍.md)、[箱子](箱子.md)、[地毯](地毯.md)、[挽具](挽具.md)、[馬鎧](馬鎧.md)和[鸚鵡螺鎧](鸚鵡螺鎧.md)。
* [狐狸](狐狸.md)叼着（主手中）的物品必定掉落。
* [尸壳](尸壳.md)在水下转化为[僵尸](僵尸.md)，僵尸在水下转化成[溺尸](溺尸.md)的过程中会掉落所有装备。
* 溺尸副手持着的任何物品都必定掉落，包括用命令添加的物品。
* [铜傀儡](铜傀儡.md)死亡时必定掉落其手持的物品。

# ==掉落物耐久==

生物掉落的物品、工具和盔甲会有0至最大耐久的随机耐久，且越低的耐久度出现的可能性越高。这也是耐久为0的物品唯一的出现方式。

生物掉落的物品、工具和盔甲会至少有25耐久度（金质为26），且越低的耐久度出现的可能性越高。

# = 经验球 =

* *经验球（Experience Orb）**只有在生物受到玩家或驯服的[狼](狼.md)的攻击（近战、弓、雪球、蛋、以及造成瞬间伤害的药水、荆棘魔咒、玩家点燃的TNT爆炸和玩家反弹的弹射物）之后5秒内死亡时才会掉落。同一种生物掉落的所有经验球的价值总和也总是与杀死该生物所应得的经验总值相等。

经验球的掉落与其他掉落物如[物品](物品（实体）.md)不同，生物尸体化为烟雾消失之时经验球才出现在其尸体所在的位置。

# = 方块掉落物 =
大多数方块被摧毁后掉落其本身。以下列出方块的所有特殊掉落。“精准采集”一列表示方块自身是否可以通过[精准采集](精准采集.md)魔咒收集；“时运”一列表示是否受[时运](时运.md)魔咒影响。

<span id="notes">注：</span>

* 有“T”标志的物品需要使用指定的工具破坏才会掉落物品（包括[经验值](经验值.md)）。[精准采集](精准采集.md)魔咒也不能绕过此限制。
* 如上表所述，[时运](时运.md)魔咒可以提高掉落数量，或倍增掉落数量。提高数量只会简单地额外给予0-魔咒等级的物品。倍增具有以下可能性：
* * 时运I：有33%的概率掉落数量×2（平均增加33%）
* * 时运II：25%的概率×2，25%的概率×3（平均增加75%）
* * 时运III：20%的概率×2，20%的概率×3，20%的概率×4（平均增加120%）
* 容器方块（[酿造台](酿造台.md)、[箱子](箱子.md)、[发射器](发射器.md)、[投掷器](投掷器.md)、[花盆](花盆.md)、[熔炉](熔炉.md)、[漏斗](漏斗.md)、[唱片机](唱片机.md)、[陷阱箱](陷阱箱.md)和[合成器](合成器.md)等）被破坏时掉落自身及其内容物。
* 所有未在表格中列出的方块被破坏时均掉落自身。时运魔咒不影响掉落数量。
