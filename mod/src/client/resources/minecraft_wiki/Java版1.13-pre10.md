# Java版1.13-pre10

*页面ID: 35520* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.13-pre10**是[Java版1.13](Java版1.13.md)的第10个，也是最后一个预发布版，发布于2018年7月17日<ref></ref>，加入了“优化世界”按钮，并修复了一些漏洞。

# 新内容
# = 常规 =
[缩略图|世界转换过程](File:World Converter.jpg.md)
* *存档**
* 在编辑现有的Minecraft世界时，现在有一个新的“优化世界”按钮，从而允许玩家将旧世界更新为更新的格式。

# 更改
# = 方块 =
* *[珊瑚](珊瑚.md)**
* 现在需要[精准采集](精准采集.md)魔咒来获取。

* *[珊瑚扇](珊瑚扇.md)和[失活的珊瑚扇](失活的珊瑚扇.md)**
* 使用[精准采集](精准采集.md)魔咒开采时会掉落。

# = 命令格式 =
* ***
* 选项<code>friendlyfire</code>更改为<code>friendlyFire</code>。

# = 常规 =
* *[设置](设置.md)**
* 选项 <code>Fullscreen resolution</code>更改为<code>Fullscreen Resolution</code>。
