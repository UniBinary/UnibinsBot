* *灯笼（Lantern）**是一种能够提供照明的固体[方块](方块.md)。

# 生成
# = 自然生成 =
在雪原[村庄](村庄.md)中，灯笼会悬挂在灯柱和一些房屋的屋檐上。

灯笼也会悬挂在[堡垒遗迹](堡垒遗迹.md)的一些房间里。

# 破坏
挖掘灯笼的合适工具是镐。

灯笼被破坏后会掉落自身。

# 用途
# = 放置 =
灯笼必须放在方块[中心完整](方块支撑形状.md)上表面的上方或中心完整下表面的下方，但有些情况需要通过来放置。依附的方块发生变化且不再能够依附时，灯笼会被破坏并掉落。

垂直的[铁链](铁链.md)和[铜链](铜链.md)能在视觉上和依附在其下方的灯笼相互连接。

灯笼的高度是0.5625格，宽度是0.375格。

# = 光源 =
灯笼会发出光照等级为15级的[光](光.md)，比[火把](火把.md)的光照等级高1级。它也可以融化3格内的[冰](冰.md)和[雪](雪.md)。
