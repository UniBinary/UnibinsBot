# 僵尸马披风

*页面ID: 187163* | *来源: Minecraft Wiki*

* *僵尸马披风（Zombie Horse Cape）**是一件披风。

# 外观
这件披风的设计来自[僵尸马](僵尸马.md)的皮毛。它类似于僵尸马的侧面，带有部分暴露的骨头。

# 描述
此披风是[群骑纷争](群骑纷争.md)版本的纪念披风，2025年12月12日至2025年12月15日期间在基岩版的生存模式下使用[矛](矛.md)击杀5个生物之后，在12月16日后的30天内即可获得。<ref></ref>这五个敌对生物可以分开击杀，任何中立或敌对生物均可。挑战允许从创造模式切换到生存模式。

披风的分发于2025年12月18日开始。所有符合条件的玩家应在活动结束后约30天（2026年1月14日之前）内收到披风。
