# 基岩版未使用特性

*页面ID: 19979* | *来源: Minecraft Wiki*

自从Minecraft开始开发以来，有许多加入了游戏但没什么实际作用的特性。这些特性一些是被移除特性的残留物，或者只是作为新特性的占位符。

# 游戏机制
# = 游戏模式 =
# == 世界游戏模式 ==
可以通过修改<code>GameType</code>使世界游戏模式处于“未知”或[旁观者模式](旁观者模式.md)，这会在世界选择菜单使世界显示为“未知”。

# == 未知模式 ==
当中的<code>GameType</code>为<code>4</code>或<code>5</code>时，玩家会进入一种半[创造模式](创造模式.md)、半[生存模式](生存模式.md)的[游戏模式](游戏模式.md)，游戏中显示为“未知”（<code>GameType</code>为<code>5</code>时默认模式处显示为“默认”。）

该模式特性如下：
* [平视显示器](平视显示器.md)以生存模式方式显示。
* [物品栏](物品栏.md)中配方部分以[创造模式物品栏](创造模式物品栏.md)的方式排列，但仍会在合成原料不足时显示为红色，点击它们只会调出配方，而非拿取物品。
* 玩家可以飞行，不受以外的所有伤害，不会引起任何生物的敌对，可以无限使用物品（存在桶类物品等例外，和正常创造模式不同），但玩家不能瞬间挖掘方块，破坏方块后正常产生掉落物。
# = 附魔 =
这里列出了和[附魔](附魔.md)相关的未使用特性。

# == 附魔任意物品 ==
基岩版中，玩家不能给[方块](方块.md)和[物品](物品.md)附魔（除工具、武器、盔甲、生物头颅和雕刻南瓜），即使玩家处于[创造模式](创造模式.md)。

但使用NBT编辑器可为不能附魔的物品和方块附魔（如为[打火石](打火石.md)附魔[火焰附加](火焰附加.md)），也可以给同一物品添加不相容的附魔（如给[剑](剑.md)同时附魔[亡灵杀手](亡灵杀手.md)和[节肢杀手](节肢杀手.md)）。

尽管基岩版中的[命令](命令.md)附魔受最大等级限制，但NBT编辑器可绕过等级限制为物品附魔高于等级限制的魔咒。

# 方块
# = 旧版切石机 =

[125px|right](File:Stonecutter BE.png.md)
[基岩版1.10.0](基岩版1.10.0.md)引入了新的[切石机](切石机.md)，其纹理和功能于[Java版](Java版.md)中的切石机完全相同。但旧的切石机并未被删除，仅在创造模式物品栏和命令中被移除。仍可通过旧版本世界或物品栏修改器获得。

# = 发光的黑曜石 =

[125px|right](File:Glowing_Obsidian.png.md)
发光的黑曜石是现已弃用的下界反应堆的一部分。它会发出12等级亮度，用钻石镐破坏后掉落其本身。仅可通过旧版本世界或物品栏修改器获得。自[0.12.1](携带版0.12.1.md)起，此方块不再生成，可通过旧版本世界或物品栏修改器获得，在[0.16.0.b1](携带版0.16.0.b1.md)里可以通过放置。

# = reserved6 =
[125px|右](File:Info update BE3.png.md)

reserved6是[携带版](携带版.md)中的未使用技术性方块，曾经被[快捷栏](快捷栏.md)用于引用玩家的[物品栏](物品栏.md)槽位。目前仅可通过物品栏修改器获得，也可以在0.16.0.b1用放置。

在物品栏中，它只会显示其本地化键名<code>tile.reserved6.name</code>。

# = 下界反应核 =

[125px|right](File:Nether Reactor Core.png.md)
下界反应核的功能已于[0.12.1](携带版0.12.1.md)移除。但方块未移除，仍可通过旧版本世界或物品栏修改器获得。现在破坏则掉落合成配方中的物品（除非使用精准采集）来补偿玩家。在0.12.1前，此方块用于激活[下界反应器](下界反应器.md)，正确建造下界反应器后点击反应核会激活反应器，激活后的金块和圆石会被替换成[发光的黑曜石](发光的黑曜石.md)。

# = 隐形基岩 =

[125px|right|class=pixel-image](File:Stone (texture) JE5 BE3.png.md)
隐形基岩曾生成于[旧世界类型](旧世界类型.md)的世界边界，但旧世界类型已于[1.18.0.22](基岩版1.18.0.22.md)移除。目前仅可通过旧版本世界或物品栏修改器获得。其为一种隐形且只能用命令破坏的固体方块，类似于基岩但形似空气。

# = 画 =
有四幅2×2方块大小的画没有明确的目的或用途。通过使用IDA和Android中的libminecraftpe.so文件，发现游戏代码通过<code>Motive::getAllMotivesAsList(void)</code>方法获取所有的画，但<code>Painting::setRandomMotive(int)</code>方法将这四幅画从随机选择的画中排除了。这些画的作者未知。据[Helen Zbihlyj](Helen Zbihlyj.md)透露<ref>https://old.reddit.com/r/Minecraft/comments/u8hpnx/thoughts_on_the_new_paintings/i5olue6/?context=3</ref>，这些画作原本打算用在[MINECON 2012](MINECON 2012.md)或[2013](MINECON 2013.md)的[携带版](携带版.md)宣传世界中。

# = 数据更新方块 =

[125px|右](File:Info update.png.md)
数据更新方块是[基岩版](基岩版.md)中两种相似的占位方块。它们仅可通过物品栏修改器或附加包获得。此方块在旧版本中用于替换数字ID无效的方块，因此已不能在新版世界中生成。如果出现无效ID的方块，它们会被替换为[未知方块](未知方块.md)；若方块ID有效但纹理缺失，则游戏会为对应方块使用品红色和黑色交替的[无效纹理](无效纹理.md)，而非替换为此方块。但是，数据更新方块仍会在超平坦世界的无效自定义层中生成。

在物品栏中，它们只会显示其本地化键名<code>tile.info_update.name</code>、
<code>tile.info_update2.name</code>。

# = 石化橡木台阶 =

在对应不同种类的木头的木台阶被添加之前，橡木台阶和其他石质台阶的性质相同：需要镐破坏，爆炸抗性与石头相同，且具有石头的声音。它们的显示名为*木台阶*，反映了当时橡木是仅有的木板种类。在[携带版0.11.0](携带版0.11.0.md)之前，它们的显示名为*伪木台阶*，破坏时掉落普通的木台阶。现在仍可通过命令、旧版本世界或物品栏修改器获得。它的方块种类为wood_old，物品数据值为2。它在物品栏中缺失了纹理。这个方块并非基岩版独有，因为它们本质上是与中的同一方块平行开发的，不同的是名字和方块掉落，因此从[TU1](Xbox_360版TU1.md)到[TU12](Xbox_360版TU12.md)的原主机版也有相同的特性。

# = 紫珀块 =

[紫珀块](紫珀块.md)具有两个未使用变种，扁平化前的方块数据值为<code>1</code>和<code>3</code>，扁平化后未被删除而是获得了独立ID，分别为：<code>deprecated_purpur_block_1</code>和<code>deprecated_purpur_block_2</code>。它们对应的纹理与常规的紫珀块相同，且可通过命令或物品栏修改器获得。它们是：
* 雕纹紫珀块
* 平滑紫珀块，游戏内显示为<code>tile.deprecated_purpur_block_2.name</code>

# = 破碎的铁砧 =

[125px|右](File:Deprecated_Anvil.png.md)

# 物品
# = 更多的探险家地图 =
除海洋探险家地图、林地探险家地图、试炼探险家地图、叢林探險家地圖、沼澤探險家地圖、村莊地圖和藏宝图可从游戏中获得外，其他的探险家地图也存在于游戏文件中，但仅可通过物品栏修改器获得。这些地图包括：
* 矿井探险家地图：显示最近的废弃矿井。
* 神庙探险家地图：显示这些结构中最近的一个：
* * [沙漠神殿](沙漠神殿.md)
* * [雪屋](雪屋.md)
* 要塞探险家地图：显示最近的[要塞](要塞.md)。这张探险家地图通常会将玩家引导到一个村庄。因为基岩版中的要塞有很高的概率生成在村庄水井或聚集点下方，所以这可以作为除了用末影之眼之外寻找要塞的另一种方法。
* 遗迹探险家地图：显示最近的[海底废墟](海底废墟.md)。
* 沉船探险家地图：显示最近的[沉船](沉船.md)。
* 掠夺者前哨站探险家地图：显示最近的[掠夺者前哨站](掠夺者前哨站.md)。
* 下界要塞探险家地图：显示最近的[下界要塞](下界要塞.md)。不像其他的探险家地图，它使用下界的布局，而非探险家地图的布局。它是静态的灰色，目的地指针保持在正确的位置，但会像玩家的指针一样随机旋转。
* 末地城探险家地图：显示最近的[末地城](末地城.md)。不像其他的探险家地图，它使用末地的布局，而非探险家地图的布局。

这些探险家地图被命名为“未知地图”，其缩放等级与海洋、林地府邸探险家地图相同。当拿在手里时，地图的名称会变成“地图 0”，它们使用一个绿色的三角形来标记目标结构。

这些探险家地图有着正常地图的纹理，但布局和海洋、林地府邸探险家地图一样，用棕色条纹表示水域，棕褐色表示陆地主体。

若[玩家](玩家.md)在不正确的维度获得了这些未使用的探险家地图，如在主世界获得下界要塞探险家地图，会导致游戏崩溃。

# = 药水 =
一些药水在正常的游戏内容中不可获得。它们以3种形式出现：可以饮用的[药水](药水.md)、[喷溅药水](喷溅药水.md)和[滞留药水](滞留药水.md)。它们也有未使用的[药箭](药箭.md)形式。这些药水包括：
* [急迫](急迫.md)药水
* [挖掘疲劳](挖掘疲劳.md)药水
* [失明](失明.md)药水
* [抗性提升](抗性提升.md)药水
* [伤害吸收](伤害吸收.md)药水
* [生命提升](生命提升.md)药水
* [反胃](反胃.md)药水
* [飘浮](飘浮.md)药水

# = 药箭 =
除了用未使用的药水制造的药箭外，还有一些未使用的药箭。这些药箭射中实体时不会产生任何状态效果。这些药箭包括：
* 长久平凡之箭，游戏内显示为<code>tipped_arrow.effect.mundane.extended</code>
* 有4种药箭的显示名称为“药箭”：
* * 喷溅之箭
* * 平凡之箭
* * 浓稠之箭
* * 粗制之箭

# == 来自教育版 ==
在开发[携带版0.16.0](携带版0.16.0.md)时加入到游戏中的物品，除了相片簿被删除，其余物品均存在于目前版本，并具有一定功能。

# === 相片簿 ===

用来存放摄像机拍摄的照片，目前仅存在纹理。

# === 黑板 ===


三个变种：小黑板、告示板和大黑板，可以像告示牌一样写字。

# === 摄像机 ===

摄像机的物品形式在携带版和基岩版中曾多次加入和移除，但其纹理一直存在于默认资源包内。目前，它可以被用于拍照或放置摄像机实体，但不同于教育版，拍摄的照片保存在本地。

# === 生成智能体 ===

* 可以使用命令来获得使用该纹理且名为“[代理机器人](代理机器人.md)刷怪蛋”的[刷怪蛋](刷怪蛋.md)，但使用后无效果。

# 状态效果

一些状态效果在基岩版中只能通过命令获得。

# =  生命提升 =
[生命提升](生命提升.md)加入于[携带版0.12.0](携带版0.12.0.md)。提供可回复的额外生命，但药水效果结束后会消失。

# 世界生成
# = 旧世界类型中的下界 =
下界传送门在[旧世界类型](旧世界类型.md)中无法激活，除非此世界转换为无限类型。

自[携带版0.16.0 build 5](携带版0.16.0.b5.md)起，命令或使玩家无需转换世界类型就可以在旧世界类型中进入下界。

旧世界类型中的下界与正常的下界类似，除了有限的大小。它和主世界的大小相同，均为256×256，高度128方块。但在下界中移动1方块仍然相当于在主世界移动8方块，这可能会导致游戏卡死或崩溃，因此正常情况下旧世界类型里不能进入下界。当玩家从下界返回主世界时在主世界会生成下界传送门，因为单个传送门方块不被认为是有效的传送门。而且玩家还有可能会因为传送到世界边境（[隐形基岩](隐形基岩.md)墙）之外的地方而动弹不得。

# = 旧世界类型中的末地 =
旧世界类型中的末地无法正常到达，因为旧世界类型中不会生成要塞，搭建的末地传送门也不会工作。进入末地的唯一方法是使用命令和放置末地传送门。

不像旧世界类型中的下界那样生成所有结构，旧世界类型中的末地只生成主岛，不会生成外围岛屿。这是由有限的256×256的世界大小导致的。

有时，旧世界类型中的末地不会正常生成地形，导致主岛也不会生成。如果是这种情况，[末影龙](末影龙.md)会被困在世界边界处的半空中，返回传送门会被截断，甚至根本不生成。[末地折跃门](末地折跃门.md)也因为大小限制而不工作。

这也是旧世界类型中的末地无法正常到达的原因，因为返回主世界的仅有的方法是作弊或死亡。

# = 生物群系 =

# == 1.18前 ==

在[基岩版1.18.0](基岩版1.18.0.md)中，主世界的地形生成机制被重写，变得更加多样化并且独立于生物群系。所以有一些相对于其常规版本而言仅地形生成有区别的生物群系的变种就显得有些多余。故这些生物群系最后都被从生成器当中移除。这些生物群系依然存在于代码中，但并未被使用。

# = 自定义超平坦 =
每个[level.dat](基岩版存档格式#level.dat.md)文件都具有一个名为的[NBT](NBT.md)字符串，正确编辑它会生成自定义的Y轴层数。这是[原主机版](原主机版.md)迁移到基岩版时留下的特性。

# = 世界选项 =

# = NPC =
[78px|right](File:NPC5pre.png.md)

* 与[携带版0.16.0](携带版0.16.0.md)不同，这时的NPC只能通过命令生成，在头顶上没有黄色的“NPC”字样，而且没有交谈按钮。
* 在[基岩版1.10.0.3](基岩版1.10.0.3.md)，玩家不能用命令生成NPC，但可通过NBT编辑器生成。这时的NPC对Member权限的玩家有对话屏幕，对有操作员权限和有world builder权限的玩家有编辑屏幕。<!-- /ability命令只能在教育版中启用 -->

# = 摄像机 =
[75px|right](File:Camera.png.md)

摄像机首次出现在[携带版0.1.0](携带版0.1.0.md)的.apk文件中，此时摄像机有功能。

在[0.9.0](携带版0.9.0.md)中，摄像机实体被移除。Tommaso说：“这不意味着摄像机已经消失了。实际上，我对它还有很多想法！我觉得摄像机在拥有了着色器、分享和红石功能后将回归游戏。”

摄像机在[0.14.0](携带版0.14.0.md)被重新加入，但只能通过编辑物品栏获得，后在[0.16.0](携带版0.16.0.md)以后的版本中被移除。

摄像机在[1.8.0.8](基岩版1.8.0.8.md)再次被重新加入，但需要使用NBT编辑器才能获得对应的刷怪蛋。在[1.12.0.2](基岩版1.12.0.2.md)中可使用获得摄像机的物品形式。

在[1.13.0.1](基岩版1.13.0.1.md)中摄像机拥有了功能，拍照后的照片可以在Windows 10版的文件夹以及安卓版的文件夹内找到。

# = 旧版村民 =

旧版村民依然存在于游戏当中，其刷怪蛋只能通过命令来获取。然而，通过刷怪蛋生成的旧版村民会立即死亡并由一个<code>villager_v2</code>（即新版村民）取而代之。

但是在包含旧版村民的模板世界中，村民本身的行为及其纹理仍然会以未被转换的旧版形式存在，纹理也维持在旧版。

旧版村民交易表的内容与界面均保持了旧版样式。

# = 旧版僵尸村民 =
与旧版村民类似，旧版僵尸村民依然存在于游戏当中，其刷怪蛋只能通过命令来获取。然而，通过刷怪蛋生成的旧版僵尸村民会立即死亡并由一个<code>zombie_villager_v2</code>（即新版僵尸村民）取而代之。

# = 远古守卫者幽灵 =

远古守卫者幽灵是[1.13.0.4](基岩版1.13.0.4.md)加入的一个新的未使用的生物。它的文件并不包含在[行为包](行为包.md)里，并且仅能通过命令生成。远古守卫者幽灵有着与[远古守卫者](远古守卫者.md)相同的模型与纹理，但使用玩家受伤的音效，有20点生命值且缺少后尾模型。当它在水面外生成时，会不断上浮直到消失，类似于一个绑着气球的生物，或者说是一个有着高等级[飘浮](飘浮.md)状态效果的生物。但它会穿过其上方的方块。远古守卫者幽灵本身仍然会受到窒息伤害。它的行为很像行为包中AI损坏的生物，会不断上浮并当被击中时穿过方块。

若一个远古守卫者幽灵生成于水下，它会缓慢下沉，穿过所有方块（包括基岩）直到掉落至虚空并死亡。在水下时远古守卫者幽灵会转动它的身体，面向玩家，并在下沉时不断游动。

从实际效果来看，它可能用于远古守卫者在诅咒玩家时的鬼影效果。

# = 卫道士袭击队长 =

[灾厄巡逻队](灾厄巡逻队.md)加入于[1.11.0.1](基岩版1.11.0.1.md)，此时卫道士可以在其中作为袭击队长或者其他队员生成。

由于在[1.18.0.20](基岩版1.18.0.20.md)中从灾厄巡逻队中移除了卫道士，卫道士袭击队长不再自然生成，但仍可用[命令](命令.md)生成。
