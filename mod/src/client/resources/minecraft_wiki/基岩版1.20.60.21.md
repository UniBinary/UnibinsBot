# 基岩版1.20.60.21

*页面ID: 109163* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.60.21**（ChromeOS/Android）、**Preview 1.20.60.21**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.60](基岩版1.20.60.md)的第2个测试版，发布于2023年11月29日至30日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[蜂巢](蜂巢（方块）.md)和[蜂箱](蜂箱.md)**
* 带有[精准采集](精准采集.md)魔咒的[附魔书](附魔书.md)不再能对其产生精准采集魔咒的效果。

* *[营火](营火.md)**
* 将普通营火被破坏后掉落的[木炭](木炭.md)数量由4个减少至2个。

* *[青金石矿石](青金石矿石.md)**
* 现在使用不带有[时运](时运.md)魔咒的[镐](镐.md)挖掘后会最多掉落9个[青金石](青金石.md)（此前为8个），带有时运III的镐则最多会掉落36个（此前为32个）。

* *[下界金矿石](下界金矿石.md)**
* 现在使用不带有时运魔咒的镐挖掘后会最多掉落6个[金粒](金粒.md)（此前为5个），带有时运III的镐则最多会掉落24个（此前为20个）。

* *[铁砧](铁砧.md)**
* 现在在携带版UI下的铁砧UI中的耗费文本拥有了深灰色的背景，以匹配经典UI。

# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* 现在在[快捷栏](快捷栏.md)中拥有蓝色的名称文本颜色。

# 修复
* *方块**
* 使用带有精准采集魔咒的工具挖掘霜冰后不再会在世界中产生水。
* 挖掘海龟蛋、青蛙卵、珊瑚和珊瑚扇时不再会产生双倍数量的粒子效果。
* 带有精准采集魔咒的附魔书不再能对蜂箱和蜂巢产生精准采集魔咒的效果。
* 现在通过破坏床下方的方块来破坏床时会清除出生点。
* 现在挖掘冰、浮冰、霜冰和雪层时会产生振动。
* 现在营火被玩家破坏时会正确掉落2个木炭，而不是4个。（）

* *自定义触摸控制**
* 修复了使用非触摸控制的控制方式退出自定义触摸控制界面时，快捷栏会消失不见的问题。

* *游戏内容**
* 连续放置方块时，台阶和楼梯不再会随机在下半部分开始放置。（）
* 现在除游戏基版本低于1.20.60的世界外，被骑乘的马、驴、骡及其骑乘者可以受到摔落伤害。（）

* *原版趋同**
* 现在使用不带有时运魔咒的镐挖掘下界金矿石后会最多掉落6个金粒（此前为5个），带有时运III的镐则最多会掉落24个（此前为20个）。
* 现在使用不带有时运魔咒的镐挖掘青金石矿石后会最多掉落9个青金石（此前为8个），带有时运III的镐则最多会掉落36个（此前为32个）。

* *图形**
* 修复了在开启“”选项的情况下，从水中离开后会出现不正确的方块光照的问题。（）

* *输入**
* 修复了在移动设备上只使用键盘时无法操控物品栏的问题。
* 修复了在触控模式下使用键盘时无法拆分物品堆叠的问题。

* *用户界面**
* 修复了资源包上的“”按钮无法跳转至界面的问题。
* 修复了低分辨率下的信标UI按钮会超出窗口的问题。（）
* 调整了物品栏中的物品的耐久度条，以使其与快捷栏中的物品的耐久度条相匹配。（）
* 调整了携带版UI下的铁砧UI中的耗费文本，以匹配经典UI。（）
* 音乐唱片现在拥有与附魔物品相同的名称文本颜色。（）

* *加载屏幕**
* 加载屏幕现在会根据玩家的游戏进度显示3种类别的提示。</onlyinclude>
