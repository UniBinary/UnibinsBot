# 基岩版1.20.50.24

*页面ID: 106877* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.50.24**（ChromeOS/Android）、**Preview 1.20.50.24**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.50](基岩版1.20.50.md)的第5个测试版，发布于2023年11月8日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *[Realms](Realms Plus.md)**
* 现在即使未运行游戏，玩家也可以通过使用链接来直接进入Realm。
* * 示例链接：<code>-{}-minecraft://connectToRealm?realmId=<*Realm ID号*></code>。

# 修复
* *图形**
* 修复了盔甲纹饰不会正确渲染的问题。（）

* *物品**
* 修复了有时会在加载带有自定义物品时发生的崩溃。</onlyinclude>
