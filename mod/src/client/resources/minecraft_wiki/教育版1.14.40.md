# 教育版1.14.40

*页面ID: 71311* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14.40**是[教育版1.14.50](教育版1.14.50.md)的一个开发版本，加入了新的Learn to Code特性。<ref></ref>

# 新内容
# = 常规 =
* *代码界面**
* 新的Python代码界面（IDE）使用笔记本样式，并可以在教学指导和写代码的尝试机会中切换。

# 更改
# = 常规 =
* *[代码构建器](代码构建器.md)**
* 重新构建菜单，为编码提供更多空间，菜单选项更容易理解。
* “Home”和“Reset Editor”按钮已添加到“Code Builder”菜单中。

* *图书馆更新**
* Mac和iPad用户现在可以通过谷歌教室或电子邮件分享或分配图书馆课程。

* *允许URL列表**
* 所有身份验证目前都使用*.minecrafteduservices.com完成。

# 修复
* 修复了部分已知漏洞。
