获取可用命令列表或单个命令的帮助信息。

# 用法
命令执行者无法使用的命令（因为权限等级不足或其他限制）不会被显示。

对一些复杂命令可能只会显示基本的语法，可以通过添加更具体的参数来获取附加信息。

# 语法
* **Java版**
   <code>help</code>
  : 列出所有可用命令。
   <code>help <command></code>
  : 显示指定命令的语法帮助。

* **基岩版**
   <code>help <command: CommandName></code>
   <code>? <command: CommandName></code>
  : 显示指定命令的语法帮助。
   <code>help [page: int]</code>
   <code>? [page: int]</code>
  : 列出所有可用命令。

# 参数

   必须为一个英文单词（不含空格）。
   指定要提供帮助的命令名称。还可以进一步提供该命令更精确的参数来获取更精确的信息。

：

   指定要展示的命令列表的页码。小于1的数字会被视为1，大于总页数会被默认为展示最后一页。

# 示例
* 显示命令列表（）：<code>/help</code>
* 显示命令的语法帮助：<code>/help give</code>
* 显示命令中子命令的语法帮助：<code>/help scoreboard add</code>
