* *僵尸马（Zombie Horse）**是[马](马.md)的[亡灵](亡灵.md)变种，拥有僵尸般的绿色外观。

# 生成
[thumb|200px|一只持有铁矛的僵尸骑在僵尸马上](File:Zombie Horseman.png.md)

僵尸马可以自然生成于[热带草原](热带草原.md)、[热带高原](热带高原.md)、[风袭热带草原](风袭热带草原.md)、[平原](平原.md)、[向日葵平原](向日葵平原.md)、[雪原](雪原.md)和生物群系中。但其自然生成时总是会同步生成一个持[铁矛](铁矛.md)的[僵尸](僵尸.md)作为自己的乘客，不会独自生成。这只僵尸仍然会遵循普通僵尸的生成规则，如生成为幼年僵尸、拥有其他天然装备。幼年僵尸马不会自然生成。

不对着僵尸马使用的刷怪蛋生成的僵尸马总是成年的<ref></ref>；对着僵尸马使用的刷怪蛋生成的僵尸马总是幼年的；使用刷怪蛋生成的幼年僵尸马的概率为20%。

# 掉落物
在死亡时，僵尸马会掉落：

}}
* ，如果是[玩家](玩家.md)杀死或者驯服的[狼](狼.md)杀死的。
* 所装备的[鞍](鞍.md)。
* 所装备的[马铠](马铠.md)。

杀死幼年僵尸马不会掉落任何物品和经验。

# 行为
僵尸马会漫无目的地四处游荡、时而嘶叫、摇尾巴以及低头做出吃草的动作。如果玩家靠近，僵尸马有时会转身看着玩家。僵尸马能直接走上1格高的方块。

被驯服和上[鞍](鞍.md)的僵尸马可以用作运输工具，虽然它们不能穿过一格宽的缝隙。僵尸马不可在水下骑乘。

与其他大多数生物类似，僵尸马可以坐在[矿车](矿车.md)里，幼年僵尸马还可以坐在[船](船.md)上。幼年僵尸马成年后会脱离船。与其他大多数生物不同的是，僵尸马每游戏刻有的概率恢复生命值，其恢复速度和普通马一样。

与[马](马.md)不同，僵尸马无法繁殖，幼年僵尸马也无法成长为成年个体。

刷怪蛋生成的幼年僵尸马需20分钟才能成长为成年个体。

僵尸马属于友好生物，但会占用怪物的[生物上限](生成#生物上限.md)。

# = 喂食 =
僵尸马会跟随/内手持[红色蘑菇](红色蘑菇.md)的玩家，给僵尸马喂食红色蘑菇可以增加僵尸马的好感度并治疗僵尸马点生命值。

# = 驯服 =
对着未驯服的僵尸马按下键可以骑上僵尸马来进行驯服。玩家需空手对僵尸马按键，否则僵尸马会拒绝搭载玩家，立刻前腿腾空并嘶叫；玩家可手持着物品按键，但僵尸马也会拒绝手持鞍和马铠的玩家。

即使玩家骑上僵尸马，僵尸马也有很大概率把玩家甩下、前腿腾空并嘶叫。当僵尸马不再试图甩下玩家并产生红心粒子时则驯服成功。

驯服成功率取决于值（好感度）。僵尸马的初始好感度为0（最高值为100）。当玩家骑上僵尸马时，每[游戏刻](游戏刻.md)有2%的概率触发一次驯服检测，会从0-99中随机取一个数字，如果僵尸马的好感度高于该数字，则僵尸马会被驯服，否则将玩家甩下来，并增加5点好感度。好感度也可以通过给僵尸马喂食[红色蘑菇](红色蘑菇.md)来增加，每次喂食增加3点。

即使好感度达到上限，也能正常喂食未驯服的僵尸马。

与其他可驯服生物一样，驯服的僵尸马死亡时会给世界中的所有玩家显示一条[死亡消息](死亡消息.md)。

# = 装备 =
成年僵尸马有两个物品栏：
* 鞍槽：用以装备[鞍](鞍.md)。
* 马铠槽：用以装备[马铠](马铠.md)。

玩家可以使用[剪刀](剪刀.md)移除鞍槽和马铠槽中的物品。二者同时被装备时，剪刀会优先移除马铠。

幼年僵尸马没有这两种物品栏。

手持物品对着僵尸马按下键可以给僵尸马装上物品。骑上僵尸马后打开物品栏或在按住键时对着僵尸马按下键可以打开僵尸马的物品栏。

# = 骑乘 =

给驯服的僵尸马装上鞍后，玩家可以通过键来骑在僵尸马身上并通过方向键来控制僵尸马的行动。玩家可以通过按下来下马。

玩家骑乘僵尸马时会显示僵尸马的生命条，其纹理与玩家的生命条不同。玩家的饥饿条会被僵尸马的生命条代替，经验条也会被僵尸马的跳跃蓄力条代替。玩家的饥饿条和经验条会正常显示，只有在蓄力时，经验条才会被跳跃蓄力条取代，且上方经验等级的数值不会消失。

玩家可以在骑乘僵尸马时使用物品、与方块或其他生物交互。

玩家可以骑着僵尸马安全地通过最低2.75方块的空间，若障碍低于2.75方块，则会造成[窒息](窒息.md)。它们最低能通过1.625方块高的空间，但低于1.75方块高的空间可能会对它们造成伤害。

玩家骑乘僵尸马时不能使用[下界传送门](下界传送门.md)。

# = 生物族群 =

僵尸马是亡灵生物，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，不被[凋灵](凋灵.md)攻击。

僵尸马会在阳光下着火，如果僵尸马装备了[马铠](马铠.md)则不会着火。未装备马铠的僵尸马会寻找阴凉处，水域以及来避免着火。與多數不死生物不同，殭屍馬能夠游泳，在任何情況下都不會沉入水底。

# 统计
僵尸马的[生命值](生命值.md)固定为，移动速度为0.2。它们的跳跃力量在0.4-1.0之间，趋于平均值0.7。
