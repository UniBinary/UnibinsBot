# 荧石粉

*页面ID: 7384* | *来源: Minecraft Wiki*

* *荧石粉（Glowstone Dust）**是一种可用于合成[荧石](荧石.md)和[酿造](酿造.md)的物品。

# 获取
# = 荧石 =
没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[荧石](荧石.md)被破坏后会掉落2-4个荧石粉，挖掘工具的[时运](时运.md)魔咒会使荧石额外等概率掉落0-<魔咒等级>个荧石粉，但掉落总数不会超过4个。

# = 合成材料 =

# = 酿造材料 =
荧石粉可用于增强药效强度并减少持续时间。
