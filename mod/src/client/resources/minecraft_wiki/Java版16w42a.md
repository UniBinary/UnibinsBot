# Java版16w42a

*页面ID: 25760* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w42a**是[Java版1.11](Java版1.11.md)的第12个快照，发布于2016年10月19日<ref></ref>，修复了一些漏洞。

# 更改
# = 物品 =
* *[箭](箭.md)**
* <code>crit</code>标签：现在能确定箭是否会造成[暴击](暴击箭.md)。

# = 生物 =
* *[恼鬼](恼鬼.md)**
* 攻击伤害提高：
* * 简单难度由提高至 。
* * 普通难度由提高至。
* * 困难难度由提高至。
