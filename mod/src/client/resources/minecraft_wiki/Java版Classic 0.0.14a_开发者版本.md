# Java版Classic 0.0.14a/开发者版本

*页面ID: 83859* | *来源: Minecraft Wiki*

该条目记录了[Java版Classic 0.0.14a](Java版Classic 0.0.14a.md)的所有开发者版本。

# 0.0.14a（2009年5月23日）

该版本初步测试了[沙子](沙子.md)、[沙砾](沙砾.md)、[矿石](矿石.md)和[树木](树木.md)。<ref></ref>

# = 新内容 =
* *[沙子](沙子.md)和[沙砾](沙砾.md)**
* 会自然生成在一格厚的海滩上。
* 都会受到重力影响，如果它们被悬空放置，那么它们会瞬间下落到底。<ref>IRC logs: "(00:03:06) <@notch> you can't make roofs out of sand and gravel [...] (00:03:14) <@notch> they fall down when there's air beneath them"(May 24, 2009, 22:03 UTC)</ref>
* *[金矿石](金矿石.md)**
* 在高海拔的水平山脉表面生成。

* *[铁矿石](铁矿石.md)**
* 以巨大的[矿团](矿团.md)生成，有时大到同时在3个洞穴，可以多达167个矿石。

* *[煤矿石](煤矿石.md)**
* 开采后会掉落自身。

* *[原木](原木.md)**
* 作为树木的一部分生成。

* *[树叶](树叶.md)**
* 作为树木的一部分生成。

* *[云](云.md)**
* 加入了云。

# = 更改 =
* *[木板](木板.md)**
* 更改了纹理。

* *[圆石](圆石.md)**
* 更改了纹理。

# 0.0.14a（2009年5月25日）

该版本初步测试了世界大小和[迷雾](迷雾.md)，并更改了[水](水.md)的流动。<ref></ref><ref></ref>

# = 新内容 =
* *[世界大小](Indev世界选项#世界大小.md)**
* 加入了世界大小，共有普通型（Normal）、大型（Huge）和小型（Small）三种世界大小，可由[创建新的世界](创建新的世界.md)屏幕控制。

# = 更改 =
* *[创建新的世界](创建新的世界.md)**
* 现在可以选择要创建世界的[世界大小](Indev世界选项#世界大小.md)。

* *[水](水.md)**
* 流动得更快了。
* 会从世界外流入。
* 测试了放置并破坏水的功能<ref>IRC logs: "(15:45:28) <taodih> notch will we be able to use water as block? [...] (15:45:35) <taodih> in build mode? [...] (15:46:45) <@Notch> taodih: I already can in 0.0.14, but it's DANGEROUS" (May 26, 2009, 13:45 UTC)</ref>。此改动并未加入至正式版本中。

* *[迷雾](迷雾.md)**
* 加入了迷雾。

* *常规**
* 暂时禁用了在线存档。

# 0.0.14a（2009年5月25日）

该版本进行了方块的顶点和颜色偏移测试。<ref></ref><ref></ref>

# = 更改 =
* *[方块](方块.md)**
* 顶点和颜色偏移测试。
* * 顶点偏移让方块变得扭曲，使世界看起来更加“真实”。
* * 颜色偏移使得每个方块的颜色都略有不同。
* * 此改动并未应用到正式版本。

* *常规**
* 重新启用了在线存档。
