# 实体

*页面ID: 7233* | *来源: Minecraft Wiki*

[缩略图|右|一个玩家正站在一些实体前](File:MiscEntities.png.md)
[缩略图|右|中一些实体的[[判定箱](File:EntitiesHitboxes.png.md)，请注意蓝线为实体的朝向]]
* *实体（Entity）**包括在Minecraft中所有动态的、移动中的对象。

# 一般行为
大部分实体拥有以下性质：
* 占有特定的空间大小。此空间是一个固定长宽高的三维长方体（实体不偏斜时，俯视图为矩形）。
* 当着[火](火.md)时，会受到[伤害](伤害.md)或消失，实体显示出被火焰包围的样子。
* 可以拥有[状态效果](状态效果.md)，主要由[药水](药水.md)产生。

部分实体能够[命名牌](命名牌.md)将其重命名。

实体会根据所在位置的[亮度](亮度.md)等级被照亮。例如，如果[矿车](矿车.md)斜着撞进一个固体方块中，就会变成黑色（固体方块的亮度永远是0）；射出的[箭](箭.md)有时候也会呈现黑色（尤其是几乎水平地卡在了天花板上时）。

# = 详细说明 =
、[画](画.md)和[拴绳结](拴绳结.md)是实体，但与其他实体不同，它们和方块网格对齐，而且不能移动。

射出的[弹射物](弹射物.md)、被激活的[TNT](TNT.md)、[下落的方块](下落的方块.md)都拥有无限的生命，因此它们不能被爆炸或燃烧所销毁。但这些实体能通过命令杀死，也会被[虚空](虚空.md)清除。

# == 船和矿车 ==

船和矿车会随着时间推移恢复生命值。比如，船和矿车只能在受到快速的攻击后毁坏，而不会在空手攻击且攻击时间与停止时间间隔相同时被毁坏。船和矿车晃动的幅度标明了其当前的生命值。

# == 下落的方块 ==

[缩略图|右|一个被掉落后的沙子覆盖的[[地牢](File:Sandy Dungeon.png.md)]]

受重力影响的方块包括[沙子](沙子.md)、[沙砾](沙砾.md)、[可疑的沙子](可疑的沙子.md)、[可疑的沙砾](可疑的沙砾.md)、[红沙](红沙.md)、[滴水石锥](滴水石锥.md)、[脚手架](脚手架.md)、[铁砧](铁砧.md)、[龙蛋](龙蛋.md)、[混凝土粉末](混凝土粉末.md)和。

正常情况下以方块形态存在。当一个方块的支持物消失后，方块会变成实体并掉落，直到撞击在另外一个支持物上方。此时实体会在最近的方块网格中转换成原始方块；如果此方块网格已被非固体方块占用（例如[火把](火把.md)或[台阶](台阶.md)），则实体会转换成物品掉落。

虽然这些方块通常竖直向下落，但是它们的轨迹可以被[爆炸](爆炸.md)和带有[黏液块](黏液块.md)的[活塞](活塞.md)、水中的[气泡柱](气泡柱.md)以及改变，也可以通过使用[命令](命令.md)或第三方程序修改掉落的方块的速度和方向。重力的影响会使它们变成掉落物，如果下落的方块自生成后存在了至少也没有变成方块，或在建造高度外且自生成后存在了至少，就会直接消失，一般情况下会掉落为对应的方块物品。

当世界生成时，洞穴生成在沙子底下时，游戏不会更新方块状态，而沙子会悬空，直到周围的方块发生变化。这时一个轻微的变化就会触发整个沙子区域的坍塌。任何在洞穴、在地牢天花板或悬崖下产生的受重力影响的方块（例如沙子、沙砾和红沙）都将保持浮空状态，直到受到了方块更新为止。

# == 交互 ==
有些实体在被时（例如幼年村民、驯服的狼、僵尸、矿车和船），手上物品的交互动作不会被阻止。例如，当玩家手持[水桶](水桶.md)对着驯服的狼，狼会坐下，而桶中的水也会倒出。

# == 骑行 ==

[缩略图|右|一个蜘蛛骑士](File:Skeleton-spider-desert.png.md)

实体可以被骑行或与其他实体组合起来。在这种情况，只有组合体中较低/靠外的那个实体会与其他对象相碰撞，并且有权控制组合体的移动。但是也有例外：乘坐着[矿车](矿车.md)或[船](船.md)或骑着上[鞍](鞍.md)的马的玩家、骑着[鸡](鸡.md)的幼年[僵尸](僵尸.md)和骑着马或乘船的[骷髅](骷髅.md)。目前游戏中的常见实体组合体如：
* 载着[玩家](玩家.md)或[生物](生物.md)的[船](船.md)、[矿车](矿车.md)或[运输船](运输船.md)。
* 戴上[鞍](鞍.md)被玩家骑行的[猪](猪.md)、[马](马.md)、[驴](驴.md)、[骡](骡.md)、[僵尸马](僵尸马.md)、[骷髅马](骷髅马.md)或[骆驼](骆驼.md)。
* 戴上鞍被玩家或[僵尸猪灵](僵尸猪灵.md)骑乘的[炽足兽](炽足兽.md)。
* 戴上鞍被玩家或[尸壳](尸壳.md)和[焦骸](焦骸.md)骑乘的[骆驼尸壳](骆驼尸壳.md)。
* 被玩家骑行的[羊驼](羊驼.md)或[鹦鹉螺](鹦鹉螺.md)。
* 被玩家或溺尸骑行的[僵尸鹦鹉螺](僵尸鹦鹉螺.md)。
* 所有骑着[蜘蛛](蜘蛛.md)或的[骷髅](骷髅.md)（[蜘蛛骑士](蜘蛛骑士.md)）。
* 在玩家肩膀上的[鹦鹉](鹦鹉.md)。
* 骑着[鸡](鸡.md)（[鸡骑士](鸡骑士.md)）或的[幼年僵尸](幼年僵尸.md)或。
* [骷髅陷阱马](骷髅陷阱马.md)和骑着[骷髅马](骷髅马.md)的[骷髅](骷髅.md)。
* [卫道士](卫道士.md)、[掠夺者](掠夺者.md)或[唤魔者](唤魔者.md)骑着的[劫掠兽](劫掠兽.md)。

更高级别的组合体是存在的，如在[矿车](矿车.md)里骑着[猪](猪.md)的[玩家](玩家.md)。

通过命令可以使实体骑乘其他实体，或生成骑着其他实体的实体。

通过命令生成可以在任何实体上面再骑乘一个实体，例如使用{{cmd|summon spider ~ ~ ~ {Passengers:[{id:"skeleton", equipment:{mainhand: {id:bow} } }]} }}会生成一个[蜘蛛骑士](蜘蛛骑士.md)。

如果一个实体正在骑行另一个实体，那么最上层的实体不能传送，因为一旦传送成功，这个实体就会被传送回它骑乘的一个实体。由于游戏通过在新旧位置之间的位置显示实体来平滑移动，因此可能导致在骑乘另一个实体和它们的瞬移位置之间的多个位置处看到该实体。

# 所有实体

以下是目前Minecraft中的实体。

大小既是以格长度为单位（以米计算，注意1格是1m<sup>3</sup>），也是在水平维度（X轴和Z轴）中特定宽度和Y轴中特定高度的[最小边界框](wikipedia:Axis-aligned bounding box#Axis-aligned minimum bounding box.md)的大小。这个边界框不会随实体视觉上的旋转而旋转。

如果仅要获取实体的ID表，请前往[数据值](数据值.md)。

# 运动

一般地，所有实体都具有速度、位置和[朝向](朝向.md)（以[](wzh:经典力学.md)为依据）。一部分实体能被[水](水.md)流推动。包括玩家、生物、船、运输船、物品、被激活的TNT、经验球等。

除[恼鬼](恼鬼.md)、[末影龙](末影龙.md)和旁观模式的玩家外的大部分非弹射物实体的判定箱不能穿过固体方块，弹射物的坐标的移动轨迹不会穿过固体方块，但是其判定箱在自身移动时可以部分地卡在固体方块中。大多数实体会占用所在的空间，阻止方块的放置，除了掉落物和经验球会自动让出占用的空间。若实体确实与固体方块处在同一位置，如被掉落的[沙子](沙子.md)掩埋或被活动的[门](门.md)卡在一起，则可以自由走出方块所在的位置而不能重新进入。（例如，如果玩家和关闭的门卡在一起，头顶无阻碍时，玩家可以向上跳，站在门的下半格上。）

一般地，实体有以下3个数据，完全决定了实体的运动：
* **加速度**<math>a</math>（米/[刻](刻.md)<sup>2</sup>）：描述实体下一刻速度的变化量。此处的加速度是重力加速度，因为其他加速度的计算非常复杂，而且其相关的公式大多是不固定的。<ref group="注" name="爆炸类型不受重力">特别地，爆炸类物品和风弹不受重力影响，而是通过受损获得加速度。</ref>
* **阻力**<math>f</math>：描述实体速度要乘的一个速度，以模拟阻力。竖直方向上的“阻力”和水平方向上的可能不同。“阻力”不应有单位，不然无论如何套公式都会在单位上出错，所以利用公式计算时也需要抛开单位不谈。
* **位置**<math>s</math>：描述实体此时的位置。

进而可以导出以下数据：
* **终端速度**<math>v_\infty</math>（米/刻）：Minecraft通过“阻力”使得实体运动的速度不能无限快，而正常情况下，实体运动能达到的最大速度被称为“终端速度”。<br>计算公式：如果“阻力”的计算比加速度优先，那么<math>v_{\infty}=\frac{a}{1-f}</math>；否则<math>v_\infty=\frac{af}{1-f}</math>。
* **水平最大位移乘数**<math>k_{\infty}</math>（米（米/秒））：此物理量给出了当物体在某一根轴上以某一速度失去加速度后，仅在“阻力”的影响下能到达的最远距离的乘数，其乘以初速度后即得最大位移，即最大位移<math>s'=k_{\infty}v_0</math>。<br>计算公式：如果位置的计算比“阻力”优先，那么<math>k_{\infty}=\frac{1}{1-f}</math>；否则<math>k_{\infty}=\frac{f}{1-f}</math>。

下表就列出了不同实体对3个计算处理的顺序（详见下文）、各数据的值、浮点精度类型、终端速度和最大水平移动距离：

实体在每个刻度会利用3个主要数据分别进行3个程序的计算，计算顺序不尽相同：

* **被给予的加速度：** 将加速度加到当前速度中（大部分實體只会受到重力加速度一个加速度）；
* **被给予的“阻力”：** 将当前速度乘以一个“阻力”系数（这一系数对于水平分量和竖直分量可能不同）；
* **更新位置：** 将当前速度加到当前位置中。

* 各个实体的重力加速度不尽相同
* 所有实体在运动中受到“阻力”的大小不尽相同，计算公式也完全不同，所以添加了引号。-->

Github上有关于这一内容更深入的解析，在[这里](https://github.com/OrHy3/MinecraftMotionTools)。

不同的实体在不同的情况下在每刻中对这些计算的顺序可能是不同的，使得它们的计算方法不尽相同。例如，空中的生物在每刻的计算由以下代码计算：
<syntaxhighlight lang="java">
// 更新位置
position.x += velocity.x;
position.y += velocity.y;
position.z += velocity.z;

// 更新加速度
velocity.y -= 0.08D;

// 更新“阻力”
velocity.x *= 0.91F;
velocity.y *= 0.98F;
velocity.z *= 0.91F;
</syntaxhighlight>

可以得知这个实体的计算顺序为“位置，加速度，‘阻力’”，且加速度为-0.08，水平方向上的“阻力”是0.91<ref group="注">事实上，源代码中<math>f=0.09</math>，计算公式中则改为<math>1-f</math>。但<math>f=0.91</math>可以在很多时候简化计算，表达式也更加简洁，故下文采用这种记法。</ref>，竖直方向上的阻力为0.98。

只需要正确将公式的变量字母替换成加速度和“阻力”的值，并正确排序三个计算的顺序，就可以准确地模拟出任何实体的运动。需要注意的是，不同的实体会使用不同的浮点精度：要么是单精度（float），要么是双精度（double）。由于每次计算时误差都会累计，所以精度对模拟的准确性的影响是相当大的，尤其是在实体高速移动的时候。

# = 公式 =
我们可以计算推得一些公式，去计算实体的各项数据，以模拟实体的运动。

下列公式中的速度和位置都是一个方向上的数据，也就是说，如果想要完整地计算一个实体的位置和速度，需要将速度和距离正交分解成X、Y和Z轴三个方向，然后分别套入公式计算，最后再整合。

所给出的公式中，第一条是递推公式，依据源代码给出；第二条是通项公式，由数学计算得到，详见最后的证明。

# == 速度 ==
我们用<math>v_{t}</math>表示这一游戏刻的速度，<math>v_{t-1}</math>表示上一游戏刻的速度，<math>v_{0}</math>表示初速度，<math>f</math>为“阻力”，<math>a</math>为加速度，于是根据“阻力”和加速度的计算程序的顺序不同，速度的公式有如下几种。每种情况里，第一种是递推公式，满足所有情况；第二种是通项公式，只有整个运动过程中的加速度<math>a</math>和“阻力”<math>f</math>都不变才可以使用：

  “阻力”，加速度：
  *<math>v_{t}=v_{t-1}f+a</math> 或 <math>v_{t}=\left( v_{0}-\frac{a}{1-f} \right)f^{t}+\frac{a}{1-f}</math>；<ref group="注" name="量纲">此处直接把速度和加速度相加，这在量纲上是不可行的，这里可以这么做是因为加速度<math>a</math>乘以了一个时间1[刻](刻.md)，因为数值大小为1，所以直接省去了，故实际计算时需要不考虑量纲。</ref>

  加速度，“阻力”：
  *<math>v_{t}=\left( v_{t-1}+a \right)f</math> 或 <math>v_{t}=\left( v_{0}-\frac{af}{1-f} \right)f^{t}+\frac{af}{1-f}</math>。<ref group="注" name="量纲"/>

# == 位置 ==
我们用<math>s_{t}</math>表示这一游戏刻的位置，<math>s_{t-1}</math>表示上一游戏刻的位置，<math>s_{0}</math>表示初位置，<math>f</math>为“阻力”，<math>a</math>为加速度，于是根据3个程序运算的顺序不同，位置的公式有如下几种。每种情况里，第一种是递推公式，满足所有情况；第二种是通项公式，只有整个运动过程中的加速度<math>a</math>和“阻力”<math>f</math>都不变才可以使用：
  位置，“阻力”，加速度：
  *<math>s_{t}=s_{t-1}+\left( v_{0}-\frac{a}{1-f} \right)f^{t-1}+\frac{a}{1-f}</math> 或 <math>s_{t}=s_{0}+\left( v_{0}-\frac{a}{1-f} \right)\frac{1-f^{t}}{1-f}+\frac{at}{1-f}</math>；

  “阻力”，加速度，位置：
  *<math>s_{t}=s_{t-1}+\left( v_{0}-\frac{a}{1-f} \right)f^{t}+\frac{a}{1-f}</math> 或 <math>s_{t}=s_{0}+\left( v_{0}-\frac{a}{1-f} \right)\frac{\left( 1-f^{t} \right)f}{1-f}+\frac{at}{1-f}</math>；

  位置，加速度，“阻力”：
  *<math>s_{t}=s_{t-1}+\left( v_{0}-\frac{af}{1-f} \right)f^{t-1}+\frac{af}{1-f}</math> 或 <math>s_{t}=s_{0}+\left( v_{0}-\frac{af}{1-f} \right)\frac{1-f^{t}}{1-f}+\frac{aft}{1-f}</math>；

  加速度，“阻力”，位置：
  *<math>s_{t}=s_{t-1}+\left( v_{0}-\frac{af}{1-f} \right)f^{t}+\frac{af}{1-f}</math> 或 <math>s_{t}=s_{0}+\left( v_{0}-\frac{af}{1-f} \right)\frac{\left( 1-f^{t} \right)f}{1-f}+\frac{aft}{1-f}</math>；

  “阻力”，位置，加速度：
  *<math>s_{t}=s_{t-1}+\left( v_{0}-\frac{a}{1-f} \right)f^{t}+\frac{af}{1-f}</math> 或 <math>s_{t}=s_{0}+\left( v_{0}-\frac{a}{1-f} \right)\frac{\left( 1-f^{t} \right)f}{1-f}+\frac{aft}{1-f}</math>；

  加速度，位置，“阻力”：
  *<math>s_{t}=s_{t-1}+\left( v_{0}-\frac{af}{1-f} \right)f^{t-1}+\frac{a}{1-f}</math> 或 <math>s_{t}=s_{0}+\left( v_{0}-\frac{af}{1-f} \right)\frac{1-f^{t}}{1-f}+\frac{at}{1-f}</math>。

<strong>速度公式的证明</strong>
<div class="collapsible-content">
对于递推公式，即每种情况的第一条公式，这是程序所规定的，也就是说，这是Minecraft的物理公设；

对于通项公式，以第一种情况为例：

对<math>v_{t}=v_{t-1}f+a</math>，

两遍同时除以<math>f^{t}</math>，

得到<math>\frac{v_{t}}{f^{t}}=\frac{v_{t-1}}{f^{t-1}}+\frac{a}{f^t}</math>，

令<math>b_{t}=\frac{v_{t}}{f^{t}}</math>，

于是

<math>\begin{align} b_{t}
&=b_{t-1}+\frac{a}{f^t}\\
&=b_{0}+\sum_{k=1}^{t}\frac{a}{f^k}\\
&=b_{0}+a\sum_{k=1}^{t}\left( \frac{1}{f} \right)^{k}\\
&=b_{0}+\underbrace{\frac{a}{f}\dfrac{1-\left( \frac{1}{f} \right)^{t}}{1-\frac{1}{f}}}_{\text{等比数列求和}}\\
&=b_{0}+a\frac{1-\left( \frac{1}{f} \right) ^{t}}{f-1}\\
&=b_{0}+a\frac{1-\frac{1}{f^t}}{f-1}.\end{align}</math>

将<math>b_{t}</math>还原后化简即得。

另外一种情况则只需将<math>v_{t}=\left( v_{t-1}+a \right)f</math>化成<math>v_{t}=v_{t-1}f+af</math>就同理可得。

<strong>距离公式的证明</strong>
<div class="collapsible-content">
以“位置，‘阻力’，加速度”（第1种情况）为例，首先“阻力”比加速度先计算，所以速度公式采用

<math>v_{t}=\left( v_{0}-\frac{a}{1-f} \right)f^{t}+\frac{a}{1-f}</math>

递推公式由<math>s_{t}=s_{t-1}+v_{t-1}</math>代入速度公式即得；

“‘阻力’，加速度，位置”（第2种情况）的递推公式是<math>s_{t}=s_{t-1}+v_{t}</math>，同样代入速度公式即得；接下来2种情况（第3、4种情况）的递推公式同理，只是代入的速度公式不同；

对于“‘阻力’，位置，加速度”（第5种情况），<math>v_{1}=v_{0}f</math>，对于其他正整数<math>t</math>，<math>v_{t}=\left( v_{t-1}+a \right)f</math>，求得其通项公式<math>v_{t}=v_{0}f^{t}+af\frac{1-f^{t-1}}{1-f}</math>代入即可;

对于“加速度，位置，‘阻力’”（第6种情况），<math>v_{1}=v_{0}+a</math>，对于其他正整数<math>t</math>，<math>v_{t}=v_{t-1}f+a</math>，同样求出递推公式即可。

对于通项公式，以“位置，‘阻力’，加速度”（第1种情况）为例，

可见速度公式<math>v_{t}=\left( v_{0}-\frac{a}{1-f} \right)f^{t}+\frac{a}{1-f}</math>是等比数列，对其前<math>\left( t-1 \right)</math>项求和的结果便是<math>x_{t}-x_{0}</math>的结果，套等比数列公式即得。

对这一式子<math>\left( -v_{0}+v_{t} \right)</math>即得“‘阻力’，加速度，位置”（第2种情况）的通项公式；接下来4种情况（第3、4、5、6种情况）的递推公式同理，只是代入的速度公式不同，其中第5、6种情况的通项公式上文已说明。
</div>
</div>

<div class="collapsible collapsed" style="border: thin solid #aaa;margin: 1em 2em;padding: 0.5em 1em 0.4em;">
<strong>水平最大位移乘数的证明</strong>
<div class="collapsible-content">
对于“位置，‘阻力’”的情况，由于<math>v_{t}=v_{t-1}f</math>，故<math>v_{t-1}=v_{0}f^{t-1}</math>。由于<math>s_{t}=s_{t-1}+v_{t-1}</math>，故<math>s_{t}=s_{0}+\sum_{i=0}^{t-1}v_{0}f^{i}</math>，当<math>t\to\infty</math>时，得<math>s_{\infty}=\sum_{i=0}^{\infty}v_{0}f^{i}=v_{0}\left(\frac{1}{1-f}\right)=\frac{v_{0}}{1-f}</math>，其中得到乘数<math>k_{\infty}=\frac{1}{1-f}</math>；

对于“‘阻力’，位置”的情况，由于<math>v_{t}=v_{t-1}f</math>，故<math>v_{t}=v_{0}f^{t}</math>。由于<math>s_{t}=s_{t-1}+v_{t-1}</math>，故<math>s_{t}=s_{0}+\sum_{i=1}^{t}v_{0}f^{i}</math>，当<math>t\to\infty</math>时，得<math>s_{\infty}=\sum_{i=1}^{\infty}v_{0}f^{i}=v_{0}\sum_{i=0}^{\infty}v_{0}f^{i}=v_{0}f\left(\frac{1}{1-f}\right)=\frac{v_{0}f}{1-f}</math>，其中得到乘数<math>k_{\infty}=\frac{f}{1-f}</math>。
