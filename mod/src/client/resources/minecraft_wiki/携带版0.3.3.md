# 携带版0.3.3

*页面ID: 21251* | *来源: Minecraft Wiki*

* *v0.3.3 alpha**是[携带版](携带版.md)的一次次要更新，发布于2012年8月9日<ref name="mojang"></ref>，加入了骷髅、蜘蛛、苦力怕、弓和燧石，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[弓](弓.md)**
* 一种发射[箭](箭.md)的远程武器。
* 可以用[木棍](木棍.md)和[线](线.md)制作。

* *[燧石](燧石.md)**
* 有概率会从[沙砾](沙砾.md)掉落。
* 可用于制作[箭](箭.md)。

# = 生物 =
* *[骷髅](骷髅.md)**
* 亡灵敌对型[生物](生物.md)，持有[弓](弓.md)。
* 死亡时会掉落0－2根[骨头](骨头.md)和0－2支[箭](箭.md)。

* *[蜘蛛](蜘蛛.md)**
* 条件敌对[生物](生物.md)，能够攀爬竖直墙面。
* 死亡时会掉落0－2根[线](线.md)。

* *[苦力怕](苦力怕.md)**
* 目前不会自然生成。
* 敌对型生物，会悄悄接近[玩家](玩家.md)并[爆炸](爆炸.md)。
* 死亡时会掉落0－2份[火药](火药.md)。

# 更改
# = 物品 =
* *[箭](箭.md)**
* 现在能够被[弓](弓.md)发射。
* 现在能够用[燧石](燧石.md)、[木棍](木棍.md)和[羽毛](羽毛.md)合成。

* *[骨头](骨头.md)**
* 现在能够合成骨粉。

* *[骨粉](骨粉.md)**
* 现在可用于在草方块上种植花。
* 现在可用于使树苗立即长成各自对应种类的树。

* *[线](线.md)**
* 现在可用于合成弓。

* *[羽毛](羽毛.md)**
* 现在可用于合成箭。

* *木质[工具](工具.md)**
* 耐久度从使用11次增加到60次。

# = 生物 =
* *[鸡](鸡.md)**
* 现在死亡时会掉落0－2根羽毛。

# = 非生物实体 =
* *[掉落物](掉落物.md)**
* 刷新时间延长至5分钟。

# = 游戏玩法 =
[thumb|此次更新前后亮度的差异](File:Brightness comparison - 0.3.2-0.3.3.gif.md)
* *[光照](光照.md)**
* 增加了整体的亮度。

* *[摔落伤害](摔落伤害.md)**
* 当玩家从一定高度掉下来时会播放骨头碎裂的音效。

* *[快捷栏](快捷栏.md)**
* 所有设备的最少槽位数都增加至6个。

* *[耐久度](耐久度.md)**
* 对生物造成伤害现在计为使用剑1次或使用斧、镐和锹2次。

* *[创造模式物品栏](创造模式物品栏.md)**
* 新增：
* * [弓](弓.md)
* * [黏土](黏土.md)
* * [雪块](雪块.md)
* * [橡树树苗](橡树树苗.md)
* * [云杉树苗](云杉树苗.md)
* * [白桦树苗](白桦树苗.md)

# 修复
* *修复了19个漏洞**
* 火的蔓延机制被关闭以暂时修复熔岩点燃某个方块后，火会蔓延到整个世界的漏洞。
* 修复了使用熔炉时会崩溃的漏洞。
* 修复了树苗及树叶的漏洞。
* 合成门现在需要使用工作台。
* 火把现在可以被放置在栅栏上。
* 蒲公英黄在MATTIS或快捷栏中不再显示为鸡蛋。
* 修复了仙人掌和门放在一起会移除门的下半部分（如果是仙人掌有2格高则为上半部）的漏洞。
* 玩家尝试破坏隐形基岩时不再会产生粒子效果。
* 楼梯现在能够阻挡光照。
* 修复了原先缺失的音效（牛受伤的音效和破坏玻璃或冰时的音效）。
* 修复了栅栏门在玩家手中不显示的漏洞。
* 修复了当玩家站在台阶上放置另一块台阶会导致玩家从这两块台阶上摔下的漏洞。
* 剑和其他工具现在会因为攻击怪物而失去耐久。
* 金质工具不再比木质工具耐久更高。
* 修复了某些生物尾部纹理颠倒的漏洞。
* iPad上的方向键不再与物品栏重叠。
* 甘蔗不再能够在水中放置。
* 放置在雪地上的方块现在在多人游戏中不会被重复放置。
