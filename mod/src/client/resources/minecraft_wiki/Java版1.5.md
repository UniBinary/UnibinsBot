# Java版1.5

*页面ID: 31687* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.5**是**[红石更新](红石更新.md)**的首个正式版，也是的一次主要更新，发布于2013年3月13日<ref></ref>。加入了数种红石有关方块和一种新装饰性方块[石英块](石英块.md)，新的[记分板](记分板.md)系统，新[纹理包](纹理包.md)格式，并进行了[光照](光照.md)引擎优化。

# 新内容
# = 方块 =
* *[激活铁轨](激活铁轨.md)**
* 合成原料包括2个[木棍](木棍.md)，6个[铁锭](铁锭.md)与1个[红石火把](红石火把.md)。
* 可用于触发[TNT矿车](TNT矿车.md)。
* 可用于停止[漏斗矿车](漏斗矿车.md)的工作。
* 可用[红石](红石.md)激活。
* 可以激活连接着的最远8格的激活铁轨。

* *[红石块](红石块.md)**
* 由9个[红石粉](红石粉.md)合成。
* 可用于贮存9个红石粉。
* 发出等同于红石火把的红石信号。
* 持续性电源，可用作可推拉的电源方块。

* *[阳光传感器](阳光传感器.md)**
* 合成原料包括3块木质[台阶](台阶.md)、3个[下界石英](下界石英.md)与3块[玻璃](玻璃.md)。
* 输出信号强度与[阳](太阳.md)光强度相关。
* 仅对日光有效（人造光无法感应，例如火把）。
* 受到降水的干扰。

* *[投掷器](投掷器.md)**
* 合成原料包括7个[圆石](圆石.md)与1个[红石粉](红石粉.md)。
* 将物品放在其前面的容器中，如果没有容器，它将发射物品而不使用它。
* 一个发射器会向玩家“发射”物品，而一个投掷器会向玩家“投掷”物品。<ref></ref>
* 能够朝向6个方向。朝上或朝下时纹理不同。
* 接收到红石信号会投掷。
* 每次信号只投掷一次。
* 当一个红石比较器被直接放在它的对面时，会发出信号——信号长度取决于它的丰度。

* *[漏斗](漏斗.md)**
* 合成原料包括5个[铁锭](铁锭.md)与1个[箱子](箱子.md)。
* 会放置和取出[漏斗](漏斗.md)、[箱子](箱子.md)、[熔炉](熔炉.md)、[运输矿车](运输矿车.md)、[漏斗矿车](漏斗矿车.md)、[发射器](发射器.md)、[投掷器](投掷器.md)、[酿造台](酿造台.md)里的物品。
* 允许众多自动化物品收集、处理系统的实现。
* 激活[漏斗](漏斗.md)会阻止它放入和释放物品的行为。
* 当一个红石比较器被直接放在它的对面时，会发出信号——信号长度取决于它的丰度。
* * 1个物品会给予1格信号长度，三分之一的堆叠数（堆叠数是64的物品为21）给予2个信号长度。
* * 完全堆叠数 × 3 = 信号长度

* *[陷阱箱](陷阱箱.md)**
* 合成原料包括1个[箱子](箱子.md)与1个[绊线钩](绊线钩.md)。
* 输出的信号强度与正在查看箱子物品栏的玩家数量相关。
* 陷阱箱与普通箱子之间可以相邻。
* 陷阱箱可以激活下方相隔一个方块的红石，但横向不可以。<ref></ref>
* 纹理与普通箱子略有差异：锁头旁有淡淡的红色。

* *[测重压力板](测重压力板.md)**
* 用于探测掉落的[物品](物品.md)数量。
* 轻质（金质）达到完全输出需要60个物品。
* 重质（铁质）达到完全输出需要600个物品。
* 信号强度随物品数量线性增长。

* *[红石比较器](红石比较器.md)**
* 基于Minecon 2012上的电容器的设想。
* 合成原料包括3个[红石火把](红石火把.md)，1个[下界石英](下界石英.md)以及3个[石头](石头.md)。
* 外观与中继器类似，但有2个输入端。
* * 如果输入A的强度大于或等于B，输出有两种可能：与A相等，或是A与B强度之差。
* ** 两种输出可用右键切换。
* * 如果输入A的强度小于B，无输出。
* 当其后端与一个容器（[末影箱](末影箱.md)除外）接触时，比较器会发出与容器里物品栏填满程度百分比成正比的强度的信号，对于[唱片机](唱片机.md)则为里面播放的唱片的编号。
* * 这也对陷阱箱有效，所以它可以同时提供两种不同来源的信号。

* *[石英块](石英块.md)**
* 由4个[下界石英](下界石英.md)合成而得。
* 装饰性方块。

* *[石英台阶](石英台阶.md)**
* 由3个[石英块](石英块.md)合成而得。
* 可以颠倒放置。
* 装饰性方块。

* *[石英楼梯](石英楼梯.md)**
* 由6个[石英块](石英块.md)以同样的楼梯合成配方合成而得。
* 可以颠倒放置。
* 装饰性方块。

* *[雕纹石英块](雕纹石英块.md)**
* 由2个石英台阶合成而得。
* 装饰性方块。

* *[石英柱](石英柱.md)**
* 由2个[石英块](石英块.md)合成而得。
* 装饰性方块。
* 与[木头](木头.md)方块类似，可以侧倒放置。

* *多层的[雪](雪.md)**
* 完善，以前可以通过地图编辑器获得多层雪。
* 每一层雪掉落1个[雪球](雪球.md)。
* 每一层雪都有自己的碰撞箱。
* * 除了最上面那一层。所以玩家看上去总是陷进雪地里一点。
* * 在视觉上，4层雪与台阶等高，但5层雪才与台阶的碰撞箱等高。
* 3个雪块可合成6个雪层。
* * 每合成一层雪，玩家都会损失一半的雪球。

* *[双层砂岩台阶](台阶.md)**
* 方块ID为<code>43:9</code>。

* *[下界石英矿石](下界石英矿石.md)**
* 开采后掉落1个[下界石英](下界石英.md)。
* 可熔炼为[下界石英](下界石英.md)。
* 只能通过[精准采集](精准采集.md)魔咒而得。
* [时运](时运.md)魔咒可以提高[下界石英](下界石英.md)的掉落率。

# = 物品 =
* *[下界砖](下界砖.md)**
* 熔炼[下界岩](下界岩.md)而得。
* 用于合成[下界砖块](下界砖块.md)。

* *[下界石英](下界石英.md)**
* 在开采下界石英矿石后掉落。
* 是[阳光传感器](阳光传感器.md)和[红石比较器](红石比较器.md)的合成材料之一。
* 能够用于合成装饰性方块。

# = 非生物实体 =
* *[漏斗矿车](漏斗矿车.md)**
* 合成原料包括1个[漏斗](漏斗.md)与1个[矿车](矿车.md)。
* 只会在经过漏斗上时才能被倒空。
* 可以在经过容器下时吸取物品。

* *[刷怪笼矿车](刷怪笼矿车.md)**
* 只能通过地图编辑器获取。
* 只有实体，没有对应物品形式。
* 与[刷怪笼](刷怪笼.md)的[NBT](NBT.md)结构相同。

* *[TNT矿车](TNT矿车.md)**
* 合成原料包括1个[TNT](TNT.md)与1个[矿车](矿车.md)。
* 由[激活铁轨](激活铁轨.md)触发。
* 爆炸烈度与其速度相关。
* 不会破坏铁轨与支撑铁轨的方块。
* 会破坏红石材料。

# 更改
# = 方块 =
* *[信标](信标.md)**
* 作用范围扩大。
* * 1层：20格（曾为16格）
* * 2层：30格（曾为24格）
* * 3层：40格（曾为32格）
* * 4层：50格（曾为40格）

* *[酿造台](酿造台.md)**
* 当一个[红石比较器](红石比较器.md)被直接放在它的对面时，会发出信号——信号长度取决于它的丰度。

* *[箱子](箱子.md)**
* 当一个红石比较器被直接放在它的对面时，会发出信号——信号长度取决于它的丰度。

* *[探测铁轨](探测铁轨.md)**
* 当一个红石比较器被直接放在它的对面时，会发出信号——信号长度取决于铁轨上方容器的丰度。
* 加入了激活后的纹理。

* *[发射器](发射器.md)**
* 可以为1格内的玩家装备[盔甲](盔甲.md)。
* 可以放置同时激活TNT。
* 可以使用骨粉催熟前方的作物或树苗。
* 可以使用打火石在前方点火，但会消耗耐久。
* 能够朝向6个方向。朝上或朝下时纹理不同。
* 更新时不再发射，而是当它们的输入被激活时触发。
* 当一个红石比较器被直接放在它的对面时，会发出信号——信号长度取决于它的丰度。

* *[唱片机](唱片机.md)**
* 当一个红石比较器被直接放在它的对面时，会发出信号——信号长度取决于使用了哪个音乐唱片。

* *[熔岩](熔岩.md)**
* 更新了纹理。
* 在下界流动更快。
* 在下界中能够以单个隐藏的方块被发现。

* *[上锁的箱子](上锁的箱子.md)**
* 纹理被放在单个文件中，没有任何东西被上锁的箱子使用。
* 现在使用[无效纹理](无效纹理.md)。

* *[下界砖块](下界砖块.md)**
* 现在由四个[下界砖](下界砖.md)合成而得。

* *[楼梯](楼梯.md)**
* 改进了光照。
* 楼梯不再阻止玩家冲刺。

* *[石头双台阶](台阶.md)**
* 双石台阶现在有一个<code>43:8</code>的方块ID。

* *[水](水.md)**
* 创造一个无限水源时不再需要一个方块在下方，但必须有一个水源方块。
* * 这意味着在使用[铁桶](铁桶.md)装水时不再会破坏河流或海洋。

# = 物品 =
* *[骨粉](骨粉.md)**
* 被略微削弱。
* 每次使用只能随机性地催熟若干个生长阶段。
* 对于树苗则需要2-4个才能长成树。
* 使用时会发出绿色粒子。

# = 生物 =
* *常规**
* 如果不是在追赶玩家，所有生物都不会自行跨越铁轨。

* *[骷髅](骷髅.md)**
* 现在射程为15格，以前为10格。
* 目标越接近，攻击速度越快。
* 对只间隔1方块的玩家也射击。

* *[史莱姆](史莱姆.md)**
* 在沼泽[生物群系](生物群系.md)的生成率与月相相关。

* *[僵尸](僵尸.md)**
* 会共同攻击目标。
* 着火时也会波及接触的玩家。
* 血量越少越强大。
* 提升玩家探测距离。

# = 世界生成 =
* *[废弃矿井](废弃矿井.md)**
* 生成的物品改为储存在[运输矿车](运输矿车.md)中，而不是[箱子](箱子.md)。

# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 双击物品会尽可能地堆叠该物品。
* 拖拽堆叠的物品可以进行分离。
* 在该格未被占用时，使用鼠标右键拖拽物品可以在该格内放置一个该物品。
* 在物品合成区域+双击物品可以将所有物品移至物品栏。
* +双击可堆叠物品可以将所有该物品的其他堆叠移至物品栏该区域。
* 当鼠标悬停至[物品栏](物品栏.md)或某一容器内的某一物品上时按可以丢弃该物品。
* 手持盔甲可以通过右键装备。

* *死亡消息**
* 现包括*死因*，*[玩家](玩家.md)杀死了另一[玩家](玩家.md)*以及*所持武器的名称*。
* * *玩家* 从梯子上摔了下来
* * *玩家* 从藤蔓上摔了下来
* * *玩家* 溺死了
* * *玩家* 从高处摔了下来
* * *玩家* 注定要摔死
* * *玩家* 因为*玩家/怪物*注定要摔死
* * *玩家* 浴火焚身
* * *玩家* 被戳死了
* * *玩家* 被*玩家/怪物*用*武器名*结束了生命
* * *玩家* 在与*玩家/怪物*战斗中不慎走入了火中
* * *玩家* 在与*玩家/怪物*战斗时被烤得酥脆
* * *玩家* 在逃离*玩家/怪物*时试图在熔岩里游泳
* * *玩家* 在试图逃离*玩家/怪物*时撞入了仙人掌中
* * *玩家* 被*玩家/怪物*用*武器名*射杀
* * *玩家* 被*玩家/怪物*用*武器名*杀死了
* * *玩家* 试图伤害*玩家/怪物*时被杀死

* *[重命名](重命名.md)、[命名牌](命名牌.md)**
* 当查看已经重命名的物品容器时，现在会在顶部展示名称。
* 已经重命名的命令方块现在会使用它们的名称而不是使用聊天栏里的<code>@</code>符号。
* 已经重命名的刷怪蛋现在会生成带有该名称的生物，并且会出现在[死亡消息](死亡消息.md)中。
* 已经重命名的Boss生物现在会在血量条上方展示名称。
* 看着一个已经重命名的实体时，将显示名称标签。

* *[创造模式](创造模式.md)**
* 所有药水都被分类。
* 在[创造模式](创造模式.md)中，在距离玩家或生物五方格远时即可攻击对方。

* *[魔咒](魔咒.md)**
* 时运现在影响[苹果](苹果.md)与[马铃薯](马铃薯.md)。

# = 常规 =
* *[光照](光照.md)**
* 引擎优化。
* 支持更多真实光照。<ref></ref><ref></ref>
* 台阶和楼梯的正确光照交互。<ref></ref>
* 注意：燃烧的熔炉仍然只从前表面发光（就像以前一样），并且黑点漏洞并未修复。

* *[纹理包](纹理包.md)**
* 纹理包会对每一个方块和物品使用独立的文件，并在运行时将其拼在一起，纹理包的尺寸不需要一致。
* 可以为任何方块和物品通过在右侧对应的文件内下方添加关键帧的方式添加动画，需要在文本文件中自定义每帧的顺序和持续时间。
* [水](水.md)、[熔岩](熔岩.md)、[指南针](指南针.md)、[时钟](时钟.md)有着独特的规则。
* 如果纹理包文件缺少图片会自动使用原版纹理补齐。
* 可以更改字体，甚至是高清的。
* 支持高清纹理。<ref></ref>

* *服务器列表**
* 直接连接IP现在会保存，即使关闭游戏。

* *[语言](语言.md)文件**
* 可以通过后台下载器上传[语言](语言.md)文件。
* * 不需要新版[Minecraft](Minecraft.md)发布即可获得。

* *[选项](选项.md)**
* 将[纹理包](纹理包.md)按钮自开始页面移入选项菜单中。
* 全新的聊天设置以及多人游戏设置。
* * 可以自定义尺寸、聊天窗口高度、显示高度以及宽度。
* 平滑光照能够切换成“最小”、“最大”和“关”。
* * 调至“最小”时使用了旧的平滑光照；“最大”时修复了与楼梯有关的漏洞。
