# 携带版0.7.4

*页面ID: 21263* | *来源: Minecraft Wiki*

* *v0.7.4 alpha**是[携带版](携带版.md)的一次次要更新，修复了[v0.7.3 alpha](携带版0.7.3.md)中的一些漏洞与崩溃。

# 新内容
# = 游戏内容 =
* 在创建世界菜单的编辑部分加入了“External”按钮，用于通过IP连接至服务器。
* 工具损坏时会发出非常微弱的声音，和[打火石](打火石.md)被使用时的声音相同。
* 对着[苦力怕](苦力怕.md)按住打火石可以引爆苦力怕了。
* 加入了对[命令](命令.md)的支持，但尝试使用任何命令时都会显示“Error: Command not found”。
* 在生存模式加入了雕纹石英块。
* 月亮现在有不同的月相了。

# 更改
# = 常规 =
* 云现在变得更暗一些，以匹配。
* 增加了太阳和月亮绕着玩家的轨道大小，修复了太阳和月亮的尺寸以及太阳在云前面出现的问题。
* 在食用[食物](食物.md)后可以听到打嗝声。
* 在生存和创造模式中，若玩家持续按住屏幕，[鸡蛋](鸡蛋.md)可以被不断扔出。
* 每条服务器显示的信息都有标签了（如“Disconnected from server”现在变为“<error> Disconnected from server”）。

# = 方块和物品 =
* [火](火.md)在玩家靠近时会有停顿的声音。
* 现在[打火石](打火石.md)被使用时会发出声音。
