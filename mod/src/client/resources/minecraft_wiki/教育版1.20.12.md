# 教育版1.20.12

*页面ID: 104753* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.20.12**是**[足迹与故事](足迹与故事.md)**的首个正式版，也是的一次主要更新，发布于2023年8月8日<ref></ref>。此次更新加入了对应版本的特性。

# 新内容

* 加入了[足迹与故事](足迹与故事.md)的特性。

# 更改
# = 生物 =
* *[智能体](智能体.md)**
* 不再有范围距离限制，现在可以在远离玩家的位置进行移动和建造。
* 现在拥有操作失败的动画。
* 现在可以在代码指定的方向上的“视线”内检测物品或与物品交互，最远距离为1格。

# = 常规 =
* *[多人游戏](多人游戏.md)**
* 优化了多人游戏的体验，以提高多人游戏的可靠性，减少多人游戏期间断开连接的次数。

* *应用程序**
* 更改了图标。

* *用户界面**
* 现在世界搜索栏旁的按钮会在“我的世界”和“我的模板”之间切换。
