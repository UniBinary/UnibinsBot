# Java版17w16a

*页面ID: 29256* | *来源: Minecraft Wiki*

<onlyinclude>

* *17w16a**是[Java版1.12](Java版1.12.md)的第6个快照，发布于2017年4月20日<ref></ref>，为音符盒加入了新的音效，加入了幻术师和教学提示，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[音符盒](音符盒.md)**
* 当被放置在[骨块](骨块.md)、[羊毛](羊毛.md)、[黏土](黏土.md)或[浮冰](浮冰.md)上时，敲打或激活音符盒不会发出声音。（这是为了以后要添加的音符盒新音效做准备）
* * 添加了以下新的声音事件（当使用时）：
* ** <code>minecraft:block.note.bell</code>
* ** <code>minecraft:block.note.chime</code>
* ** <code>minecraft:block.note.flute</code>
* ** <code>minecraft:block.note.guitar</code>
* ** <code>minecraft:block.note.xylophone</code>

# = 生物 =
* *[幻术师](幻术师.md)**
* 新的[灾厄村民](灾厄村民.md)。
* 会给予玩家20秒的效果，然后向玩家射箭。
* 会召唤幻影。
* * 所有幻影将会显示射击动画，但只有本体才能攻击和被攻击。
* 没有对应的[刷怪蛋](刷怪蛋.md)，只可以使用命令生成。
* 攻击玩家和村民。

# = 常规 =
* *教学提示**
* 只会在[生存模式](生存模式.md)显示，并只在第一次创建新世界时显示。
* * 按玩家账号保存，保存在中。
* ** 名字：<code>tutorialStep</code>。
* ** 标准列表：。

* *[控制](控制.md)**
* 为[创造模式](创造模式.md)下的物品栏保存添加了快捷键选项。

* *JSON格式**
* 添加了'group'到配方格式文件中，用于使相似的配方集合起来。
* 添加了新的'keybind'文本组件，用于参考玩家的按键绑定。

# = 命令 =
* *选择器**
* 。
* 表示执行实体。例：<code>/execute @e[type=Villager] ~ ~ ~ say @s</code>。

# 更改
# = 方块 =
* *[硬化黏土](硬化黏土.md)**
* 重命名为陶瓦。

* *[带釉陶瓦](带釉陶瓦.md)**
* 附在[黏液块](黏液块.md)的侧面、顶部和底部时不再被粘住，但如果附在前面和后面则会被粘住。

* *[潜影盒](潜影盒.md)**
* 更改了颜色，以和其他彩色方块的颜色配套。

* *[命令方块](命令方块.md)**
* 现在会在安排命令链中的所有命令在下一刻之前执行它们。
* * 现在能够通过命令和立即得到结果（而不是让它们在一刻的延迟后）来停止/修改命令链的操作。

# = 物品 =
* *[钓鱼竿](钓鱼竿.md)**
* 增加了钓鱼竿收线的音效。

# = 生物 =
[缩略图|右|250px|潜影贝以前的颜色与现在的颜色的比较](File:NewShulkerColors.png.md)

* *[潜影贝](潜影贝.md)**
* 更改了颜色，以和其他彩色方块的颜色配套。
* * 这导致了“默认”（紫色）的潜影贝和潜影盒拥有更鲜艳的紫色和使其他紫色的方块和物品与之不匹配。

# = 常规 =
* *复述功能**
* 当复述功能不可用时会显示一条消息。

* *[控制](控制.md)**
* 按下会隐藏所有弹出通知。

* *NBT格式**
* 改进了NBT在命令中的解析度。
* * 键现在可以写作被引号括住的形式了（可选），例子：<code>"Motion":[0.0,0.0,0.0]</code>。
* * 未被引用的字符串值现在会变的更加严格，它们不再包含空格或特殊符号，例子：<code>CustomName:Test Test</code>。
* * 以前在列表中可选的指数现在不再被允许使用，例子：<code>Motion:[0:7.3,1:1.0,2:3.1]</code>。
* * 空值不再被允许使用。
* 改进错误消息的提示，现在会指出错误之处。
