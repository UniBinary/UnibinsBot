* *鹦鹉螺（Nautilus）**是一种可驯服的[水生生物](水生生物.md)，驯服后可以被玩家[骑乘](骑乘.md)。

# 生成
鹦鹉螺会在[海洋](海洋.md)、[冻洋](冻洋.md)、[冷水海洋](冷水海洋.md)、[温水海洋](温水海洋.md)和它们的深海变种、[暖水海洋](暖水海洋.md)中生成。鹦鹉螺在冻洋、冷水海洋和[冰冻深海](冰冻深海.md)中的生成频率低于其他生物群系。

鹦鹉螺会生成于Y=38至Y=58的水体中，它们可以单独生成或以每群2-3个生成。

* 所裝備的[鹦鹉螺铠](鹦鹉螺铠.md)。

杀死幼年鹦鹉螺不会掉落任何物品或经验。

# 行为
带鞍的鹦鹉螺会在16格方块范围内随机游动，不带鞍的则在32格方块范围内随机游动。

鹦鹉螺免疫[中毒](中毒.md)效果。

# = 攻击 =
未驯服的成年鹦鹉螺会攻击对其造成伤害的任意生物，后退一段距离后猛地向该生物冲刺，造成伤害和显著击退（如果沿途碰撞到其他生物也会造成伤害），并在约20秒后自动解除敌对状态。未驯服的鹦鹉螺偶尔会主动攻击附近的[河豚](河豚.md)。鹦鹉螺与玩家敌对时，如果玩家手持[鱼](鱼.md)或者[鱼桶](鱼桶.md)，鹦鹉螺将不再攻击玩家。驯服的鹦鹉螺不会与玩家敌对。

鹦鹉螺无法在陆地上攻击目标。

幼年鹦鹉螺不会进行任何攻击行为。

# = 脱水 =
鹦鹉螺完全脱离水时无法自主移动，但仍可被骑乘及控制。

脱离水的鹦鹉螺会在后开始受到|short=1}}/|short=1}}的脱水伤害，直至死亡。

# = 驯服 =
玩家可以对成年的鹦鹉螺[河豚](河豚（物品）.md)或[河豚桶](河豚桶.md)来尝试驯服。喂食后河豚桶会变为[水桶](水桶.md)。

与其他可驯服生物一样，驯服的鹦鹉螺死亡时会给或显示一条[死亡消息](死亡消息.md)。

# = 装备 =

驯服的成年鹦鹉螺有以下两格可用的物品栏：
*  鹦鹉螺铠槽：用以装备[鹦鹉螺铠](鹦鹉螺铠.md)，专用于鹦鹉螺。
*  鞍槽：用以装备[鞍](鞍.md)。

以上两种物品均可被玩家使用[剪刀](剪刀.md)移除。二者同时被装备时，剪刀会优先移除鹦鹉螺铠，再移除鞍。

幼年鹦鹉螺无法装备鹦鹉螺铠和鞍。

# = 骑乘 =

骑乘装备鞍的鹦鹉螺时能用方向键和键来控制它。玩家可以通过按键来脱离鹦鹉螺。玩家可以在骑乘鹦鹉螺时使用物品、与方块或其他生物交互，且不再会在水中缓慢下沉。鹦鹉螺在水中的移动速度为6.50m/s，快于装备附有[深海探索者](深海探索者.md)III靴子的玩家的[速泳](速泳.md)速度。

骑乘鹦鹉螺时，经验条会被鹦鹉螺的冲刺蓄力条替代，该冲刺蓄力条的外观与[马](马.md)等生物的跳跃蓄力条相同。骑乘鹦鹉螺时长按可以进行冲刺蓄力，蓄力时松开可使骑乘的鹦鹉螺高速向前冲刺。随着蓄力时间的增加，蓄力条先快速向右填充，冲刺的速度逐渐增加；在蓄力时蓄力条达到最右端橙色区域，此时蓄力的程度最大，冲刺的速度最大，为24.00m/s，冲刺距离约为13格；之后蓄力条先快后慢地缩回，冲刺速度逐渐衰减。冲刺速度受[迅捷](迅捷.md)、[緩速](緩速.md)等[状态效果](状态效果.md)影响。冲刺后，鹦鹉螺进入持续的冷却时间，冷却期间不能进行冲刺。

玩家骑乘鹦鹉螺时会显示鹦鹉螺的[生命](生命.md)条，其纹理与玩家的生命条不同。

玩家骑乘鹦鹉螺时，为玩家提供持续|je}}或<ref></ref>|be}}的[鹦鹉螺之息](鹦鹉螺之息.md)状态效果，會凍結氧氣條，使其不再消耗。

鹦鹉螺在陆地上也能控制，但是速度比在水中慢得多。

# = 喂食 =
给生命值未满的已驯服的成年鹦鹉螺喂食任意鱼或鱼桶可以使其恢复生命值。

给生命值已满的已驯服的成年鹦鹉螺喂食任意鱼或鱼桶可以让它们繁殖，详见[下文](#繁殖.md)。

鱼桶在喂食后会变为[水桶](水桶.md)。

# = 繁殖 =

鹦鹉螺会跟随/手持任意鱼或鱼桶的玩家。

当对两只生命值已满的已驯服的鹦鹉螺使用任意鱼或鱼桶时，它们就会进入求爱模式。繁殖后会生成一只幼年鹦鹉螺，并掉落，且在5分钟内无法再次繁殖。繁殖生成的幼年鹦鹉螺会直接被驯服。

玩家可以给已驯服的幼年鹦鹉螺喂任意鱼或鱼桶来加快其生长，而未驯服的幼年鹦鹉螺只能用河豚或河豚桶喂食。每次喂食可以减少约剩余成长时间的10%。

对幼年鹦鹉螺[金蒲公英](金蒲公英.md)可以阻止其成长为成年鹦鹉螺，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年鹦鹉螺无法被喂食除金蒲公英外的其他物品。

# = 生物族群 =

鹦鹉螺是水生生物，被具有[穿刺](穿刺.md)魔咒的武器近战攻击，或被具有穿刺魔咒的[三叉戟](三叉戟.md)弹射物命中时会受到额外的伤害。

# 你知道嗎
* 虽然鹦鹉螺是現存的，但开发者破例将其设定为“幻想生物”，借此添加坐骑功能。<ref>https://bsky.app/profile/jebox.bsky.social/post/3lzxfawssqc2s</ref>
* 鹦鹉螺的外观参考了现实中已经灭绝的，以贴合玩家熟悉的[鹦鹉螺壳](鹦鹉螺壳.md)纹理。<ref>https://bsky.app/profile/sarahboev.bsky.social/post/3lztk26noh22w</ref>
* 由於[河豚](河豚（物品）.md)也是釀造[水下呼吸藥水](水下呼吸藥水.md)的原材料，開發者認為就像是河豚解鎖了遊戲的水下呼吸功能一樣，符合某種Minecraft邏輯。因此設計以餵食河豚作為鸚鵡螺的馴服方式。<ref>https://youtu.be/7Xib58aLHUU?si=JutsUGjiNjRmZw_k&t=4m12s</ref>
