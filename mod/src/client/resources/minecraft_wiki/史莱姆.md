* *史莱姆（Slime）**是一种[生成](生成.md)在部分区块地下和[沼泽](沼泽.md)生物群系及其变种的敌对生物。

# 生成
史莱姆生成在40[层](海拔高度.md)以下的特定的“史莱姆区块”里（不限亮度）的[可生成方块](生成#可生成位置.md)上，它们也可以生成在沼泽和红树林沼泽生物群系51-69层且[亮度](亮度.md)等级小于等于7的可生成方块上。

只有1、2和4尺寸<ref group="注">为了方便表述，定义**尺寸**的值为<code>Size</code>+1。</ref>的史莱姆会自然生成。通过可以生成1-127（实体数据<code>Size</code>0-126）尺寸的史莱姆。

生成一个史莱姆需要2.08×2.08×2.08的空间，它们生成的区域必须没有任何液体和方块碰撞。史莱姆生成时统一以大型史莱姆的尺寸判断空间是否充足，因此任何尺寸的史莱姆都无法在小于2.08×2.08×2.08的空间生成。

史莱姆在生成时的尺寸受[副区域难度](副区域难度.md)影响，三种尺寸的概率分别为小型16.5%-33%，中型34%，大型33%-49.5%。

# = 沼泽 =
在[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)中，史莱姆可能会在Y=51到Y=69且亮度等级小于等于7的地方生成。在[满月](满月.md)时，它们的生成概率最大，而在[新月](新月.md)时从不生成。

更准确来说，游戏会检查两个因素：

# 亮度等级是否小于等于一个随机整数（0-7）
# 月亮的明亮部分所占比例是否大于一个随机小数（0-1）

如果这些条件都符合且高度合适，那么就有50%的概率生成史莱姆。

# = 试炼刷怪笼 =
[试炼密室](试炼密室.md)中的小型近战型[试炼刷怪笼](试炼刷怪笼.md)包含史莱姆试炼刷怪笼。

# = 史莱姆区块 =

史莱姆会在整个主世界（除[蘑菇岛](蘑菇岛.md)、[深暗之域](深暗之域.md)和<ref></ref>）的特定[区块](区块.md)Y=40以下生成，忽略亮度等级。大约每十个区块中会有一个是这种特定的“史莱姆区块”。

# == Java版 ==
“史莱姆区块”的决定是由[世界种子](世界种子.md)和区块坐标结合起来的伪随机而成的：
<syntaxhighlight lang="java">
import java.util.Random;

public class CheckSlimeChunk {

    public static boolean isSlimeChunk(long worldSeed,     // 世界种子，一个64位整数，可以通过/seed获取
                                       int  chunkX,        // 区块X轴坐标，32位整数
                                       int  chunkZ) {      // 区块Z轴坐标，32位整数
        Random rng = new Random(
                        worldSeed +
                        (long)(chunkX * chunkX * 4987142) +
                        (long)(chunkX * 5947611) +
                        (long)(chunkZ * chunkZ) * 4392871L +
                        (long)(chunkZ * 389711) ^ 987234911L
        );
        return rng.nextInt(10) == 0;
    }
}
</syntaxhighlight>
也就是说，使用区块坐标来帮助生成一个种子，进而生成一个0-9之间的伪随机数，如果生成的数字是0，那么那个区块就能生成史莱姆。要转换世界坐标到区块坐标，将坐标除以16并向下取整。

# == 基岩版 ==
史莱姆区块的算法与[Java版](Java版.md)不同。算法并不依赖于生成世界的种子，因此史莱姆区块对于每个世界的生成是一样的。<ref>基岩版史莱姆区块算法已由@protolambda和@jocopa3逆向工程得出，并可在GitHub上找到：[https://github.com/depressed-pho/slime-finder-pe][https://gist.github.com/protolambda/00b85bf34a75fd8176342b1ad28bfccc]</ref>

# = 状态效果 =
拥有[渗浆](渗浆.md)状态效果的生物在死亡时会产生2只中型史莱姆。

# 行为

[thumb|right|upright|跳跃的史莱姆](File:Slime.gif.md)
史莱姆通过跳跃移动，每过一段时间跳跃一下。不像其他生物，史莱姆在附近没有玩家时不会停止移动。

史莱姆的生命值等于它们尺寸的平方，它的每个方向的大小是它尺寸的0.52倍，近战攻击伤害等于它的尺寸（除了没有攻击能力的1尺寸史莱姆）。

史莱姆跳跃的距离取决于它们的尺寸，4尺寸的史莱姆可以跳约5.5格远距离，2尺寸的史莱姆可以跳约3.5格远的距离，1尺寸的史莱姆可以跳约2格远的距离。史莱姆跳跃的高度不受尺寸影响，1次只能跳到1个方块的高度。它们会在跳跃以及着陆时发出明显的声音，但空闲时不会发出声音。着陆时，会出现一定量的[黏液球](黏液球.md)粒子，其尺寸为外表尺寸的。

史莱姆会在16格半径（球形）、高度以自身碰撞箱上下扩展4格的范围内搜索玩家、[铁傀儡](铁傀儡.md)，且史莱姆更倾向于搜索玩家。如果找不到目标，它们会等待10-30刻（0.5-1.5秒）。它们会随机转左或转右，改变方向的角度最大为57.26°（1弧度），跳跃，然后重复这个过程。如果找到目标，那么等待的时间将会变为未找到目标的（3-10刻），然后就会在跳跃前将方向对准最近的目标。

不像其他生物，史莱姆完全没有路径搜索能力，只会尝试向目标方向跳跃着前进。这意味着它们在追逐目标时，会掉下悬崖且不能绕过墙壁。

与其他生物不同，史莱姆的近战攻击没有频率限制，会持续进行攻击，且会同时对攻击距离内的所有目标进行攻击。[受击后伤害免疫](受击后伤害免疫.md)使史莱姆对目标生物每秒只能造成两次伤害，但使用[盾牌](盾牌.md)阻挡伤害时将不会触发受击后伤害免疫，因此大型史莱姆会极快速地耗尽盾牌的耐久度。

史莱姆也会持续执行攻击，同时对攻击距离内的所有目标进行攻击，但每次攻击有0.5秒的冷却时间。

尺寸大于1的史莱姆死亡时，会分裂出2-4只新的史莱姆。它们的尺寸会除以2，并向下取整。由史莱姆死亡后分裂而产生的新史莱姆会继承原史莱姆的状态效果、通过下界传送门的冷却时间和。

小型史莱姆没有攻击能力，即使修改其[属性](属性.md)<code>attack_damage</code>。

史莱姆不会阻止玩家[睡觉](睡觉.md)，但玩家仍会因受到尺寸大于1的史莱姆的攻击而惊醒。<ref></ref>

史莱姆免疫[渗浆](渗浆.md)状态效果。

# 你知道吗
* 玩家可以从大型史莱姆和它分裂的所有史莱姆最高获得28经验：最大的能获得4经验；分裂的最多获得8经验；再次分裂的最多获得16经验（每次分裂为4只）。
* 当一个已被命名的大史莱姆分裂成小史莱姆时，所有分裂出的小史莱姆的名字将会与大史莱姆的名字相同。
* 通过命令生成的尺寸为127的史莱姆是游戏中体型最大的生物。
* 小型史莱姆是最弱的敌对生物，其生命值只有，且不具有造成伤害的能力。
* 因为史莱姆的移动速度和它的大小有关，在平地上，8尺寸的史莱姆甚至比没有[状态效果](状态效果.md)影响的玩家还要快。
* 在史莱姆搜寻附近的玩家进行攻击或决定它们是否消失时，史莱姆不会从碰撞箱外侧边缘开始检查，而是从碰撞箱X轴和Z轴中间的那一点以及Y轴的底部开始检查。这意味着生成的自定义尺寸的巨大史莱姆可能会在玩家右前方，并且完全是被动型生物。如果足够大，这种史莱姆甚至会在其外边缘小于1格时消失。
* 史莱姆能够自然生成在[发光的黑曜石](发光的黑曜石.md)上，尽管发光的黑曜石已无法通过常规方法放置在世界中。
