# Java版Infdev 20100325-1545

*页面ID: 173144* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年3月25日15:45（UTC），重新加入了一些特性。<ref></ref><ref>[Adura的IRC记录](#logs.md): "(11:45:44) <Notch> I updated infdev."</ref>

# 新内容
# = 方块 =
* *常规**
* 现在方块再次可以自动更新。

# = 世界生成 =
* *[洞穴](洞穴.md)**
* 被重新加入游戏。
* 可以在[红砖块金字塔](红砖块金字塔.md)内部生成。

* *[矿团](矿团.md)**
* 被重新加入游戏。
* [矿石](矿石.md)现在会以矿团的形式生成。

# 更改
# = 方块 =
* *[台阶](台阶.md)**
* 现在在条件允许的情况下会生成双台阶。

* *[熔炉](熔炉.md)**
* 现在能够正常工作。

* *[花](花.md)**
* 没有暴露在阳光下时会变为[掉落物](掉落物.md)。

* *[火](火.md)**
* 现在不再能够在不可燃方块的侧面点火。

# 修复
* *修复了1个漏洞**
* 由于删除了重复登录的检测，游戏不再随机地出现“冲突”屏幕并崩溃。</onlyinclude>
