# 携带版0.13.0.b1

*页面ID: 18892* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.13.0 alpha build 1**是[v0.13.0 alpha](携带版0.13.0.md)的首个测试版，发布于2015年11月3日，加入了新的红石方块、[兔子](兔子.md)和[沙漠神殿](沙漠神殿.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[红石灯](红石灯.md)**
* 激活后发出等级为15的光照。

* *[红石火把](红石火把.md)**
* 新的红石元件。
* 用于激活或关闭红石电路。

* *[拉杆](拉杆.md)**
* 新的红石元件。
* 用于激活或关闭红石电路。

* *[绊线钩](绊线钩.md)和[绊线](绊线.md)**
* 新的红石元件。
* 相互连接会构成红石开关。

* *[阳光探测器](阳光探测器.md)**
* 用于侦测光照等级，并输出相对应的红石信号强度。

* *[压力板](压力板.md)**
* 加入了木质和石质压力板。

* *[测重压力板](测重压力板.md)**
* 加入了轻质和重质测重压力板。

* *[按钮](按钮.md)**
* 加入了木质和石质按钮。

* *[探测铁轨](探测铁轨.md)**
* 矿车处于其上方会发出红石信号。

* *[激活铁轨](激活铁轨.md)**
* 矿车处于其上方会导致乘客下车。

* *[陷阱箱](陷阱箱.md)**
* 打开后会发出红石信号。
* 纹理和箱子基本相同，但锁的周围有一圈红色的纹理。

* *[门](门.md)**
* 加入了云杉、白桦、丛林、金合欢和深色橡木木门。

* *[铁活板门](铁活板门.md)**
* 和木质活板门功能相同，但只能被红石信号开关。

* *[音符盒](音符盒.md)**
* 会根据其底下的方块类型发出不同的音色。
* 点击可以调音，使用红石激活会发出不变的音调。

# = 物品 =
* *[兔子皮](兔子皮.md)**
* 由[兔子](兔子.md)掉落。
* 可用于合成[皮革](皮革.md)。

* *[食物](食物.md)**
* [生兔肉](生兔肉.md)
* [熟兔肉](熟兔肉.md)
* [兔肉煲](兔肉煲.md)

# = 生物 =
* *[兔子](兔子.md)**
* 新的被动型生物。
* 会远离玩家。
* 可使用胡萝卜进行[繁殖](繁殖.md)。
* 会破坏庄稼。

# = 世界生成 =
* *[沙漠神殿](沙漠神殿.md)**
* 自然生成于[沙漠](沙漠.md)生物群系里。
* 包含了4个宝藏箱，以及由9个[TNT](TNT.md)和1个石质[压力板](压力板.md)组成的陷阱。

# 更改
# = 方块 =
* *[切石机](切石机（MATTIS）.md)**
* 现在无法合成，亦没有具体功能，但仍存在于创造模式物品栏。

* *[线](线.md)和[红石线](红石线.md)**
* 现在可以被放置。

* *[动力铁轨](动力铁轨.md)**
* 现在需要被激活。

# = 非生物实体 =
* *[船](船.md)**
* 缩小了船的体积。
* 移速现在比疾跑略微快一些。
* 行船时不再消耗饥饿值。
* 现在可在停止划桨后立即使用物品和作出攻击。

# 修复
* *修复了39个漏洞**
*  - 玩家可以在空中游泳。
*  - 水下的方块开裂纹理不可见。
*  - 使用骨粉催熟任何花只会给予蒲公英或虞美人。
*  - 动力铁轨与普通铁轨不会连接。
*  - 睡眠时与方块实体互动会出现错误信息。
*  - 告示牌上的文本溢出。
*  - 鸡骑士不会攻击玩家。
*  - 熔炉烧炼时没有发出粒子。
*  - 鸡只被小麦种子吸引。
*  - 手持生物头颅时显示错误。
*  - 在藤蔓上攀爬会发出楼梯的音效。
*  - 第二或第三人称视角下的船显示错误。
*  - 站在红石矿石上不会使其激活。
*  - 搭乘矿车时显示多余的方向键。
*  - 生物可以推开玩家。
*  - “总是白天”按钮覆盖了“制作无限！”按钮。
*  - 手持活板门、地毯和台阶时几乎看不见。
*  - 部分生物在地毯内窒息。
*  - 蜘蛛没有步行音效。
*  - 破坏高草丛时的粒子显示错误。
*  - 使用精准采集破坏部分方块时给予错误的物品。
*  - 烈焰人会被创造模式下的玩家激怒。
*  - 切换应用后，船的方向键丢失。
*  - 菜单里的花屏现象。
*  - 矿车会主动向上行进。
*  - 在没有使用控制器游玩时，主菜单的“游戏”按钮里出现一条白边。
*  - 烧炼进度显示错误。
*  - 村民无法打开除了橡木门以外的所有门。
*  - 村民村民和铁傀儡在切换应用后隐形。
*  - 花盆不能放置在颠倒的楼梯上。
*  - 在“与门”上放置火把会使得游戏崩溃。
*  - 豹猫的头部丢失。
*  - 狼的尾部丢失。
*  - 砂岩台阶的纹理错误。
*  - 骷髅不在阳光下燃烧。
*  - 放置红石火把使得游戏崩溃。
*  - 铁傀儡会在压力板上窒息。
*  - 骷髅在加载或离开存档后不在阳光下燃烧。</onlyinclude>
