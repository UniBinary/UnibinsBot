# Java版1.20-pre2

*页面ID: 104243* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.20-pre2**是[Java版1.20](Java版1.20.md)的第2个预发布版，发布于2023年5月16日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[红石线](红石线.md)**
* 现在红石线会连接四周开启的[活板门](活板门.md)上的红石线。

# = 游戏内容 =
* *[创造模式物品栏](创造模式物品栏.md)**
* [鱼桶](鱼桶.md)改为与鱼物品一致的排序方式。
* [失活的珊瑚块](失活的珊瑚块.md)改为与珊瑚块一致的排序方式。
* [凋灵玫瑰](凋灵玫瑰.md)现在与其他小型花排在一起。
* [红树根](红树根.md)和[沾泥的红树根](沾泥的红树根.md)现在与[原木](原木.md)而不是[树叶](树叶.md)排在一起。

# = 常规 =
* *[菜单屏幕](菜单屏幕.md)**
* 启动游戏时，现在会在用户开启复述功能但功能不可用的时候显示提示框。

* *[配方](配方.md)**
* 现在可用于表示会与空槽位匹配上的合成材料，但下列配方类型不允许空合成材料出现：
