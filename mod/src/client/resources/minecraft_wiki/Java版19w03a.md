# Java版19w03a

*页面ID: 39318* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w03a**是[Java版1.14](Java版1.14.md)的第14个快照，发布于2019年1月16日<ref></ref>，加入了堆肥桶及其合成配方，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[堆肥桶](堆肥桶.md)**
* 生产[骨粉](骨粉.md)。
* * 下面列出的物品之一将向堆肥桶添加1级堆肥，最多7级。堆肥桶达到7级后，进入8级，即收获期，使用时可产出1骨粉。
* * 一些堆肥物品被消耗后不会增加堆肥桶等级。增加等级的概率取决于物品的种类。（例如，[干海带](干海带.md)的概率为10%，而[南瓜派](南瓜派.md)的概率为100%。）
* ** 可堆肥的物品包括：[苹果](苹果.md)、[面包](面包.md)、[蛋糕](蛋糕.md)、[曲奇](曲奇.md)、[西瓜](西瓜.md)和[西瓜片](西瓜片.md)、[干海带](干海带.md)、[胡萝卜](胡萝卜.md)、烤[马铃薯](马铃薯.md)、[南瓜派](南瓜派.md)、[甜菜根](甜菜根.md)、[甜浆果](甜浆果.md)、所有类型的种子（除了[下界疣](下界疣.md)）、[小麦](小麦.md)、[甘蔗](甘蔗.md)、[可可豆](可可豆.md)、所有树苗、所有树叶、所有[蕨](蕨.md)类和[草](草.md)、[海泡菜](海泡菜.md)、所有2格高的花、所有[蘑菇](蘑菇.md)、[仙人掌](仙人掌.md)、[藤蔓](藤蔓.md)和[睡莲](睡莲.md)。
* 用3块木板和4道栅栏制作。

# 更改
# = 方块 =
* *[木桶](木桶.md)、[砂轮](砂轮.md)、[甜浆果丛](甜浆果丛.md)、[烟熏炉](烟熏炉.md)、[高炉](高炉.md)**
* 为方块/物品加入了声音。
* *[农作物](农作物.md)和[下界疣](下界疣.md)**
* 加入了放置和破坏声音。
* *[营火](营火.md)**
* 更改了模型和纹理。
* 现在发出15级的光。

# = 生物 =
* *[巨人](巨人.md)**
* 不再使用僵尸的AI和NBT数据。

# = 游戏内容 =
* *放置方块**
* 现在玩家如果把头埋在方块内放置方块，会放到面向的[互动箱](判定箱#互动箱.md)表面的对面。
