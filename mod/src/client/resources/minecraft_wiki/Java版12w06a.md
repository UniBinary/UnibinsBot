# Java版12w06a

*页面ID: 32322* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w06a**是[Java版1.2.1](Java版1.2.1.md)的第5个快照，发布于2012年2月9日<ref></ref>，加入了新的[音效](音效.md)，改进了[门](门.md)的特性和生物AI，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[音效](音效.md)**
* 为[猫](猫.md)加入了各种声音。
* [僵尸](僵尸.md)敲打[门](门.md)时现在会发出响声。

# 更改
# = 方块 =
* *[门](门.md)**
* 改进门以正确检测是否打开或关闭，现有地图中的双门需要更新。
* * 在门的前面放置2个[压力板](压力板.md)并且踩在上面现在会正确打开门。
* * 踩在单个压力板上面现在会打开对应的门。
* * 踩在2个压力板上门会全部打开。

* *[红石](红石.md)**
* 现在可以放在[荧石](荧石.md)上面。

# = 生物 =
* *常规**
* 加入了稀有掉落物。
* 生物在水中有更好的移动。
* 大部分生物会移动得更慢。
* 当一个玩家被敌对型生物盯上时，它会继续跟踪玩家，即使被其他怪物攻击。

* *[洞穴蜘蛛](洞穴蜘蛛.md)**
* 洞穴蜘蛛顺着水流游向玩家时会非常快，但是逆着水流时只会原地不动。

* *[骷髅](骷髅.md)**
* 现在有概率掉落弓，弓可以是附魔的。

* *[雪傀儡](雪傀儡.md)**
* 下雨时会进入水中会受伤。

* *[村民](村民.md)**
* 改进了AI。
* * 会与同类或被动型生物互动。
* * 下雨时会进入住所以躲避雨。
* * 会跑离僵尸。

* *[僵尸](僵尸.md)**
* 改进了AI。
* * 在困难[难度](难度.md)或[极限模式](极限模式.md)中，僵尸会敲打并破坏木[门](门.md)。
* * 在普通或简单难度中，僵尸仍会敲打木门，但不会将其破坏。
* * 僵尸会攻击[村民](村民.md)。
* * 僵尸在日光中燃烧时会尝试打破木门。
* * 有概率掉落[铁锭](铁锭.md)、[铁盔甲](铁盔甲.md)、[铁锹](铁锹.md)和[铁剑](铁剑.md)。

* *[僵尸猪人](僵尸猪人.md)**
* 增加在水中游泳时的速度。
* 现在有概率掉落[金盔甲](金盔甲.md)、[金锭](金锭.md)、[金剑](金剑.md)和附魔的金剑。

# = 常规 =
* *[调试](调试屏幕.md)按键**
* 按下隐藏HUD的同时还可以禁用碰撞箱的轮廓和方块被打破时的动画。

# 修复
* *修复了5个漏洞**
* 苦力怕不再会在死亡后爆炸了。
* 村民不再会打开铁门了。
* 豹猫、僵尸、狼和骷髅不再会在非全高方块上旋转了。
* 蜘蛛网现在会消除玩家的摔落伤害了。
* 多人游戏中的刷怪笼现在会显示正确的生物了。</onlyinclude>
