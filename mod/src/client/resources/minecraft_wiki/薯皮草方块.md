* *薯皮草方块（Peelgrass Block）**是在[马铃薯维度](马铃薯维度.md)生成的类似于[草方块](草方块.md)的方块。

# 生成
# = 自然生成 =
薯皮草方块自然生成在[植物园](植物园.md)、[田野](田野.md)和[废土](废土.md)生物群系。

# = 转化 =
薯皮草方块可以蔓延至附近的[马铃薯泥土](马铃薯泥土.md)和[泥土](泥土.md)上，类似于草方块的蔓延。

对马铃薯泥土使用黄绿色[马铃薯皮](马铃薯皮.md)可以将其转变为薯皮草方块。

# 获取
薯皮草方块只能通过带有[精准采集](精准采集.md)的工具破坏自身获得。

# 破坏
挖掘薯皮草方块的合适工具是锹。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，薯皮草方块被破坏后会掉落1个[马铃薯泥土](马铃薯泥土.md)。

被具有精准采集的工具挖掘破坏时，薯皮草方块被破坏后会掉落自身。

# 用途
# = 方块转化 =
对薯皮草方块使用[锄](锄.md)可以将其转变成[剧毒耕地](剧毒耕地.md)。

马铃薯可以直接在薯皮草方块上种植。

对薯皮草方块使用[锹](锹.md)可以将其转变成[剧毒土径](剧毒土径.md)。

# = 削皮 =
对薯皮草方块使用[马铃薯削皮刀](马铃薯削皮刀.md)会将其转化为[马铃薯泥土](马铃薯泥土.md)，并掉落黄绿色[马铃薯皮](马铃薯皮.md)。

# = 生物转化 =
当[绵羊](绵羊.md)食用薯皮草方块后，被食用方块会转化成[马铃薯泥土](马铃薯泥土.md)，被剪毛的成年绵羊只会在食用后重新长出羊毛，幼年绵羊每次食用可以使成长用时减少1分钟。
