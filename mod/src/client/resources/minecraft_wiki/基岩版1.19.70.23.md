# 基岩版1.19.70.23

*页面ID: 102072* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.70.23**（Android）、**Preview 1.19.70.23**（Xbox/Windows/iOS/iPadOS）是[基岩版1.19.70](基岩版1.19.70.md)的第4个测试版，发布于2023年2月15日至17日<ref></ref><ref></ref>，在[实验性玩法](实验性玩法.md)中加入了[嗅探兽](嗅探兽.md)和考古学相关内容，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“嗅探器”子选项。
* * 用于启用[嗅探兽](嗅探兽.md)相关特性。

# 更改
# = 生物 =
* *[马](马.md)及其变种**
* 繁殖马及其变种产下的新个体的速度、跳跃高度和生命值不再会趋近双亲对应属性的平均值。
* * 这意味着繁殖马产生的新个体的属性有可能会超越双亲。

# = 命令格式 =
* ***
* 重新加入了旋转参数。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”、“嗅探器”、“即将推出的创作者功能”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[饰纹陶罐](饰纹陶罐.md)**
* 在合成表中使用4个[陶片](陶片.md)或[红砖](红砖.md)摆成菱形以合成。
* * 陶片的种类决定了输出陶罐的对应面出现何种图案，使用红砖则没有图案。
* 非常容易被破坏。
* * 使用[剑](剑.md)、[镐](镐.md)、[锹](锹.md)、[锄](锄.md)、[斧](斧.md)或[三叉戟](三叉戟.md)进行破坏，会碎裂成其原先的合成材料。
* * 徒手破坏、被活塞推动和使用附有[精准采集](精准采集.md)魔咒的工具破坏时掉落自身。

* *[可疑的沙子](可疑的沙子.md)**
* 与[沙子](沙子.md)相似，但纹理看起来更粗糙。
* 受重力影响，会在落地时消失。
* 被挖掘或被活塞推动时不掉落任何物品，用附有精准采集的工具挖掘也不会掉落。
* 会在[沙漠神殿](沙漠神殿.md)和[沙漠水井](沙漠水井.md)中自然生成，两处生成的可疑的沙子带有的战利品表不同。
* 用[刷子](刷子.md)刷可疑的沙子可以刷出物品。
* * 清刷时，可疑的沙子会经历4个阶段，若中途停止，会逐渐恢复原状。
* * 清刷完成后，可疑的沙子会消失。
* * 带有有效战利品表的可疑的沙子才能刷出物品。

* *[火把花植株](火把花植株.md)**
* 可用火把花种子在[耕地](耕地.md)上种出。
* 共有3个生长阶段，完全成熟时变为火把花。
* 若完全成熟，破坏时掉落火把花；若未完全成熟，破坏时掉落火把花种子。

* *[火把花](火把花.md)**
* 一种新的植物。
* 可用于合成[橙色染料](橙色染料.md)。
* 可以放置在[花盆](花盆.md)中。

# = 物品 =
* *[刷子](刷子.md)**
* 用于清刷方块的物品。
* 使用3根[线](线.md)和2个[木棍](木棍.md)合成，摆放方式类似于[镐](镐.md)。
* 成功刷出物品时消耗1点耐久。
* 对可疑的沙子外的其他方块没有实际效果。

* *[陶片](陶片.md)**
* 共有四种，分别为弓箭纹样、举臂纹样、珍宝纹样和头颅纹样。
* 无法合成，只能通过刷可疑的沙子来获得。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了嗅探兽刷怪蛋。

* *[火把花种子](火把花种子.md)**
* 一种新的种子，可以种植在[耕地](耕地.md)上。
* 可通过嗅探兽挖掘获得。

# = 生物 =
* *[嗅探兽](嗅探兽.md)**
* [Minecraft Live 2022](Minecraft Live 2022.md)生物投票的获胜生物，属于友好生物，体型很大。
* 有点生命值。
* 目前不会自然生成。
* 不会被食物吸引，不能被驯服。
* 时常嗅探空气，有时能挖掘出火把花种子。
* * 有8分钟冷却时间。
* * 最近被挖掘过的20个方块会被记录，并且不再寻求挖掘这些方块。
* 可以使用火把花种子喂养和繁殖。

# = 世界生成 =
* *[沙漠神殿](沙漠神殿.md)**
* 更改了结构，现在会有一个填满沙子和可疑的沙子的新空间。
* * 一些沙子会暴露在外，可以在与[蓝色陶瓦](蓝色陶瓦.md)等高的位置上找到。

* *[沙漠水井](沙漠水井.md)**
* 现在可疑的沙子会生成在其水下。

# 修复
* *游戏内容**
* 修复了玩家除非手持一组拴绳，否则无法拴住手持拴绳的悦灵的漏洞。

* *音频**
* 所有种类的按钮和拉杆的音效现在由音频设置中的“方块”滑块控制。（）

* *原版趋同**
* 修复了漏斗断开红石信号连接后不会吸取物品的问题。（）
* 恶魂音效的音量现在会因远离玩家而逐渐衰减。（）

* *常规**
* 现在在快捷栏中切换耐久度相同的同种物品时会播放切换物品动画。

* *图形**
* 在沉浸式VR模式下进入下界时加载屏幕不再会闪烁。

* *物品**
* 修复了已装填的弩在发射后仍会保持已装填状态的问题。（）

* *生物**
* 现在村庄外的村民被玩家攻击时会发出愤怒粒子。
* 马被推动时不再能越过上方覆盖着地毯的栅栏。（）

* *用户界面**
* 修复了在打开UI文本转语音的情况下，使用控制器来控制玩家移动或相机视角移动会导致旁白说出“X of Y”的漏洞。
* 修复了世界目录中包含空格时无法打开对应世界的编辑世界屏幕的漏洞。（）</onlyinclude>
