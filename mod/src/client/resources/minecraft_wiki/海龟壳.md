* *海龟壳（Turtle Shell）**是一种[酿造](酿造.md)原材料，也是一种[头盔](头盔.md)，戴上它的生物会获得[水下呼吸](水下呼吸（状态效果）.md)状态效果。

# == 铁砧 ==
* *材料修复**

每个材料可以恢复海龟壳25%的耐久（向下取整）。

* *合并物品**

叠加两个海龟壳的剩余耐久度，再额外获得12%的耐久度，按照[铁砧机制](铁砧机制.md)保留魔咒。

# 用途

海龟壳作为一种[头盔](头盔.md)，玩家可以在[物品栏](物品栏.md)将海龟壳放入最顶端的盔甲槽当中。

# = 装备 =
<div style='float:right'></div>
戴着海龟壳的生物会在其头部处于[空气](空气.md)中时获得10秒的[水下呼吸](水下呼吸（状态效果）.md)状态效果。此效果仅当生物处于水下时才会开始倒计时，相当于额外给予生物10秒的水中呼吸时长，使得生物可以在水下总共停留25秒而不受[溺水](溺水.md)伤害。如果配合[](水下呼吸（魔咒）.md)魔咒，该时间可延长至约70秒。

生物装备海龟壳后会增加护甲值，与金头盔、锁-{}-链头盔和铁头盔所给予的护甲值相同，仅次于钻石头盔和下界合金头盔。

海龟壳拥有275点耐久度，在同类型的装备中耐久仅次于钻石头盔和下界合金头盔。
