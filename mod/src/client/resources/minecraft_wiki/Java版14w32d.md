# Java版14w32d

*页面ID: 32432* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w32d**是[Java版1.8](Java版1.8.md)的第45个快照，发布于2014年8月8日<ref></ref>，为各种木头加入了对应的门，并修复了[14w32c](14w32c.md)中加入特定服务器时，客户端崩溃/玩家被踢出的漏洞<ref></ref>。

# 新内容
# = 方块 =
* *[门](门.md)**
* 为所有类型的木头加入了对应的门。
* * 不同类型的门有不同的纹理，有些类型的门没有窗户。
* * 现在门的合成配方要求所有6个木板都是相同的类型。
