# Java版1.20-pre6

*页面ID: 104303* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.20-pre6**是[Java版1.20](Java版1.20.md)的第6个预发布版，发布于2023年5月25日<ref></ref>，修复了一些漏洞。

# 更改
# = 游戏内容 =
* *[进度](进度.md)**
* 进度“”由普通进度改为挑战进度。

# = 常规 =
* *[战利品表](战利品表.md)**
* 现在随机序列的ID为可选项，当未指定时序列将会通过无指定性的随机种子生成。

* *[配方](配方.md)**
* 不再能在数据包配方中使用。
* 类型的配方，其字段现在支持以数组形式列出多种原材料。
* * 这些字段允许空数组，意为将此槽位留空。

# 修复
选项中将潜行设为按键切换状态的玩家被杀死后重生时，其他玩家不能观察到其处于潜行状态。
