深色橡树是一种生成于[黑森林](黑森林.md)的植被[地物](地物.md)，分为**普通深色橡树（Dark Oak）**和。

# 种类
# = 普通深色橡树 =
深色橡树有7-11格高，树干横截面最小为2×2格，树干上部有向旁侧突起的原木分杈，托着上方大片的伞状树冠。树干西北角的原木顶端总是比其他3列原木高出1格。

# = 覆藤深色橡树 =

覆藤深色橡树又称濒死的深色橡树。它与普通深色橡树的区别在于，其原木的每个暴露面都有的概率附着[藤蔓](藤蔓.md)。

# 生成
深色橡树生成时会将下方1格的方块转变为[泥土](泥土.md)。

# = 自然生成 =
[黑森林](黑森林.md)生成树木地物时，深色橡树有61.8%的概率生成。

覆藤深色橡树有一定概率会取代普通深色橡树生成。

# = 人为生成 =
[亮度](亮度.md)等级至少为9且有一定的空间时，2×2摆放的[深色橡树树苗](深色橡树树苗.md)可长成普通深色橡树或。
