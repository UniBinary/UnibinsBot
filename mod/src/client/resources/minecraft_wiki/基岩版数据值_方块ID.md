# 基岩版数据值/方块ID

*页面ID: 90997* | *来源: Minecraft Wiki*

在基岩版1.16.100后，方块的数字ID用于存档升级时方块的转化和在游戏运行时使用。

通过[附加包](附加包.md)自定义的方块会占据及之后的数字ID。

<ref group="注">摄像机（方块）在一些[服务器软件](基岩版服务器软件.md)中可以通过[命令](命令.md)获得。</ref>

<ref group="注">物品栏中空槽位对应的ID。</ref>

<ref group="注">任何无效ID的默认方块。</ref>
