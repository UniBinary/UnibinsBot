# 早期创造

*页面ID: 35258* | *来源: Minecraft Wiki*

* *早期创造（Early Creative）**指的是发布于2009年5月16日至5月28日的一系列[Classic](Java版Classic.md)版本，接替了[pre-Classic](Java版pre-Classic.md)并被[多人测试](多人测试.md)代替。

# 新内容
# = 方块 =
; [基岩](基岩.md)
* 自然生成在世界底部。
* 无法被破坏、放置或选择。

; [水](水.md)
* 一种[液体](液体.md)，会自然生成在世界中。
* 可以无限传播，并会蔓延以填补下方和旁边的所有可用空间。
* 水不会在世界外工作。

; [熔岩](熔岩.md)
* 一种[液体](液体.md)，有概率生成在世界中。
* 可以无限传播。
* 靠近水时会生成石头。

; [沙子](沙子.md)和[沙砾](沙砾.md)
* 会自然生成在一格厚的海滩上。
* 会受到重力影响。
* * 如果被悬空放置，那么其会立即下落到底。

; [金矿石](金矿石.md)
* 在高海拔的水平山脉表面生成。

; [铁矿石](铁矿石.md)
* 以巨大的[矿团](矿团.md)生成，有时大到同时在3个洞穴，可以多达167个矿石。

; [煤矿石](煤矿石.md)
* 开采后会掉落自身。

; [原木](原木.md)
* 作为树木的一部分生成。

; [树叶](树叶.md)
* 作为树木的一部分生成。
* 被破坏时，[粒子](粒子.md)以普通速度下落。

# = 生物 =
; [生物](生物（已移除实体）.md)
* 在重新生成世界时不再重置。

# = 游戏内容 =
; [平视显示器](平视显示器.md)
* 在左上角加入了版本号。
* 加入了帧率和区块更新计数器，位于左上角。

; 常规
* 加入了颜色较淡的黑色轮廓箱。
* 现在可以为有账号的玩家保存世界。<ref></ref>
* * 为已注册并登录的玩家提供的功能。
* * 共有5个槽位。
* * 存储于链接 {{cd|-{}-<nowiki>http://www.minecraft.net/play.jsp?name=<用户名>&id=<所在槽位，从0开始计数></nowiki>}} 中。

# = 世界生成 =
; [洞穴](洞穴.md)
* 在地表下随机生成。

; [熔岩湖](熔岩湖.md)
* 会偶尔在地表生成。

; [湖泊](湖泊.md)
* 会偶尔在地表生成。

; [树木](树木.md)
* 由树叶和原木组成。

; [世界大小](Indev世界选项#世界大小.md)
* 加入了世界大小，共有普通型（Normal）、大型（Huge）和小型（Small）三种世界大小，可由[创建新的世界](创建新的世界.md)屏幕控制。
* * 普通型世界面积为256×256。
* * 大型世界世界面积为512×512。
* * 小型世界面积为128×128。

; [云](云.md)
* 加入了云。

; [迷雾](迷雾.md)
* 现在由雾而不是空白区域来控制渲染距离。
* * 雾只会应用于明亮面上。阴影中的方块会以正常样式显示。

# = 常规 =
; [控制](控制.md)
* 单击右键会在放置和破坏模式之间切换。
* 按解除鼠标锁定并暂停游戏。
* 按在四个渲染距离间循环。
* 按会打开暂停菜单。
* 支持滚轮选取[方块](方块.md)。
* 按住鼠标可以每0.25秒连续放置或破坏方块了。
* * 只能选择可以通过数字键选择的方块。
* 按键可以保存出生点。

# 更改
# = 方块 =
; [木板](木板.md)
* 更改了纹理。

; [圆石](圆石.md)
* 更改了纹理。

; [树苗](树苗.md)
* 更改了纹理。
* 现在在阴影处时的外观是高亮的，而在选择时变为隐形。

# = 生物 =
; [生物](生物（已移除实体）.md)
* 现在不再在世界中自然生成。

# = 游戏内容 =
; [世界加载屏幕](世界加载屏幕.md)
* 世界生成界面现在会展示较暗的[泥土](泥土.md)。

; 常规
* 现在选中方块会显示其轮廓。
* 现在创建新世界时会重置生物。
* 按住跳跃键无法再自动跳跃。

# = 世界生成 =
; [世界界限](世界界限.md)
* 现在世界外会生成一片以基岩为海床的海洋。
* 玩家不再能够移动到世界外。

; [虚空](虚空.md)
* 现在世界底部是无尽的熔岩。

; 常规
* 地形变得更加凌乱，地表可见更多凸起。现在也会生成岛屿了。
* 地形总在海平面上方1格处生成。
* 低于海平面的所有可以接触阳光的泥土在生成世界时都不会变为草方块。

# = 常规 =
; [控制](控制.md)
* 按住不再导致玩家在不同位置之间循环重生，按住与单击的效果现在是相同的。
* 玩家在按重生时总是出现在同一地点，除非重生点在水下。

; 存档格式
* 改进了存档格式，现在生物可以被储存在世界数据中。
* * 一个世界中最多可以存在256个[生物](生物.md)。

; 其他
* 加载[pre-Classic](Java版pre-Classic.md)版本的世界会导致世界重新生成。
* 游戏窗口的分辨率现在是854&times;480。
* 改进了性能。
* 提高了帧率。
