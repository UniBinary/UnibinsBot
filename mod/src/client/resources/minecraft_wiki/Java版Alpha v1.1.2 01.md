# Java版Alpha v1.1.2 01

*页面ID: 32526* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.1.2_01**是的一次更新，发布于2010年9月23日，修复了一些漏洞。

# 更改
# = 常规 =
* *资源**
* Minecraft现在从云端下载资源。</onlyinclude>

# 你知道吗
* 这是[启动器](启动器.md)中最旧的拥有正常工作的音效系统的版本。
* * 因为在这个版本中，资源是从Amazon S3云端存储服务下载的，而不是从minecraft.net。不久之后，未使用的声音资源已从minecraft.net中删除，因此导致Alpha v1.1.2_01之前的所有版本都缺少声音。
