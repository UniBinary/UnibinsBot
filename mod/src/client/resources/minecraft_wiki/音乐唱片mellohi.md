# 音乐唱片mellohi

*页面ID: 156538* | *来源: Minecraft Wiki*

* *mellohi**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的同名曲目。

# 获取
# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片mellohi。

# 用途
# = 音乐 =

[noicon](File:mellohi.ogg.md)

Mellohi是一首缓慢、略微抑郁的华尔兹舞曲，背景来自[Mellotron](wikipedia:mellotron.md)乐器的磁带采样，游戏内时长为1分36秒。

# = 红石 =

音乐唱片mellohi放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为7的信号。
