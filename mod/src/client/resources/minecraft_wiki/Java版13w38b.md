# Java版13w38b

*页面ID: 33624* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w38b**是[Java版1.7.2](Java版1.7.2.md)的第6个快照，发布于2013年9月20日<ref></ref>，加入了一个新的选项，将空气定义为方块，并修复了[13w38a](13w38a.md)里的漏洞和崩溃。

# 新内容
# = 常规 =
* *[选项](选项.md)**
* 超级秘密设置
* * 加入了bumpy[着色器](着色器.md)。

# 更改
# = 方块 =
* *[空气](空气.md)**
* 将空气定义为方块，而不再是未被方块占据的空间。<ref></ref><ref></ref>
* 现在可以存放在物品栏内。
* * 空气在物品栏中、作为掉落物和在物品展示框中使用[无效纹理](无效纹理.md)，但手持时与其他方块相似，而且是透明的。

# = 世界生成 =
* *[沼泽](沼泽.md)**
* 移除了沼泽[生物群系](生物群系.md)中的部分地形，但在重新加入。<ref>http://i.imgur.com/wE7PK24.png</ref>
