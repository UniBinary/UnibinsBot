# 携带版1.0.6.0

*页面ID: 28611* | *来源: Minecraft Wiki*

<onlyinclude>

* *alpha 1.0.6.0**是[1.0.6](携带版1.0.6.md)的首个测试版，发布于2017年3月24日<ref>http://pocketbeta.minecraft.net/2017/03/changelog-for-106-beta-build-1.html</ref><ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *选项**
* 在商店中加入了世界选项，以红石大厦为特色。

# 更改
# = 常规 =
* *消息和更新日志**
* 游戏中的消息和更新日志不再和最新更新绑定了。

# = 生物 =
* *史莱姆**
* [史莱姆](史莱姆.md)的跳跃范围现在正确了。

# 修复
* *修复了8个漏洞**
* 由骷髅马陷阱生成的骷髅马不能被驯服或骑乘。
* 幼年生物没有空闲音效。
* 被凋灵摧毁的方块不会掉落。
* 由发射器发射的箭现在会直接使得前方一格的生物受伤。
* 在附加包里的雪傀儡的头部比例不正确。
* 在使用移动数据时，在商店里下载内容不能取消。
* 更改已经导入并设置为全局的资源包的存储位置时游戏崩溃。</onlyinclude>
