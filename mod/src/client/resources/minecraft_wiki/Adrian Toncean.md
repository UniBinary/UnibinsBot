# Adrian Toncean

*页面ID: 57248* | *来源: Minecraft Wiki*

* *Adrian Toncean**是[Mojang Studios](Mojang Studios.md)的一位游戏开发者，担任[Minecraft Dungeons](Minecraft Dungeons.md)的开发工作。<ref></ref>

# 生活与职业
# = 早年生活 =
2009年，Adrian Toncean就读[布加勒斯特大学](wzh:布加勒斯特大学.md)，后来于2012年毕业，获得计算机科学理学士学位。同年，他就读于[查尔摩斯工学院](wzh:查尔摩斯工学院.md)，最终获得计算机系统与网络领域的理学硕士学位。<ref name=StackOverflow></ref>

Adrian自2010年代起就开始用[JavaScript](wzh:JavaScript.md)和[C++](wzh:C++.md)两种语言编写程序。2013年6月，他参与了[Goo Engine](https://github.com/GooTechnologies/goojs/graphs/contributors)的开发。2016年初起，他在Campanja担任了1年的开发者。在此期间，他协助为公司的前端应用引入新的功能。后来，他还担任了[Projectplace International](http://www.projectplace.com/)的开发者。<ref name=StackOverflow/>

# = Mojang =
2017年7月，Adrian入职[Mojang](Mojang.md)，参加C++游戏开发的工作。<ref name=StackOverflow/>他目前担任动作冒险游戏Minecraft Dungeons的开发工作。<ref></ref><ref></ref>
