* *1.18-exp6（1.18 experimental snapshot 6）**是[Java版1.18](Java版1.18.md)的第6个实验性快照，发布于2021年9月1日<ref></ref><ref></ref>，对少数[地形特征](地形特征.md)、[生物群系](生物群系.md)进行了微调。此版本单独发布，故不出现在[启动器](启动器.md)版本列表中。

# 更改
# = 生物 =
* *[马](马.md)、[驴](驴.md)和[骡](骡.md)**
* 现在会跟随手持[金胡萝卜](金胡萝卜.md)、[金苹果](金苹果.md)或[附魔金苹果](附魔金苹果.md)的玩家。

* *[羊驼](羊驼.md)**
* 现在会跟随手持[干草捆](干草捆.md)的玩家。

# = 世界生成 =
[缩略图|500px|此版本前后的海底含水层生成方式对比图](File:1.18-exp6 Cavier Ocean Floors Simplified.jpg.md)
* *[含水层](含水层.md)**
* 现在[海洋](海洋.md)或[河流](河流.md)下方的含水层更易与它们的底部相连。
* * 其下方[洞穴](洞穴.md)更易形成通向水底的洞口，被截断的可能性降低了。
* * 在海洋下方Y=0到Y=40之间的洞穴大概率会被淹没。

* *[巨型针叶林](巨型针叶林.md)和[巨型云杉针叶林](巨型云杉针叶林.md)**
* 不再被视为寒冷类型。
* * 降低了其与积雪生物群系邻接的可能性。

* *[雪林](雪林.md)和[积雪山坡](积雪山坡.md)**
* 降低了在[尖峭山峰](尖峭山峰.md)和[冰封山峰](冰封山峰.md)上生成的可能性。
* 现在处于温和或炎热气候中时，其山麓会从更高处开始生成。
* 现在处于寒冷气候中时，其山麓会从更低处开始生成。

* *[涌泉](涌泉.md)**
* 略微降低了水泉的数量。

* *[沼泽](沼泽.md)**
* 会在干燥地带生成。
* 不再过于分散。

* *水下[峡谷](峡谷.md)**
* 被重新加入。
* * 不再在水下峡谷上使用特定雕刻器。对于海底，则使用普通的噪声洞穴和雕刻器。
* * 变化更丰富、更自然。

* *[洞穴](洞穴.md)**
* 现在雕刻器洞穴可以覆盖海床上的[沙子](沙子.md)和[沙砾](沙砾.md)生成。

* *常规**
* 降低了生成寒冷的微型生物群系的可能性。
* 略微提高了水下[岩浆块](岩浆块.md)的数量。

# 修复
* 修复了1.18-exp5中使繁茂洞穴更小、更分散的意外更改。</onlyinclude>
