# Java版1.8.2-pre1

*页面ID: 14581* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.8.2-pre1**是[Java版1.8.2](Java版1.8.2.md)的首个预发布版，发布于2014年12月18日<ref></ref>。

# 新内容
# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 加入了新的帧率时间图表。
* * 按下在屏幕左下方显示帧时间条形图。

* *[统计信息](统计信息.md)**
* 吃掉蛋糕的片数
* 填充炼药锅
* 从炼药锅取水
* 清洗过的染色盔甲的数量
* 清洗过的旗帜的数量
* 与炼药台的互动
* 与信标的互动
* 查看投掷器
* 查看漏斗
* 查看发射器
* 音符盒点击次数
* 音符盒换音次数
* 将植物放进花盆里
* 触发陷阱箱
* 打开末影箱
* 附魔物品
* 唱片播放次数
* 与熔炉互动
* 与工作台互动
* 打开箱子

# 更改
# = 方块 =
* *[TNT](TNT.md)**
* 把爆炸的物理效果回滚到[14w31a](14w31a.md)之前。
* 爆炸力不再错误偏转。

# = 游戏内容 =
* *[旁观模式](旁观模式.md)**
* 生物不再跟着/追踪旁观模式下的玩家。
