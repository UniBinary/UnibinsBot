# 基岩版1.20.50.20

*页面ID: 106263* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.50.20**（ChromeOS/Android）、**Preview 1.20.50.20**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.50](基岩版1.20.50.md)的首个测试版，发布于2023年10月11日<ref></ref>，为所有版本加入了[Realms](Realms Plus.md)支持，加入了[饰纹陶罐](饰纹陶罐.md)的新功能，改造了游戏指南界面，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* *[游戏规则](游戏规则.md)**
* 加入了游戏规则。
* * 用于控制是否显示配方解锁消息。
* * 默认值为。

# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 加入了被[床](床.md)或[重生锚](重生锚.md)炸死时的死亡消息：
* * “|<死者> 被 [蓄意遊戲設計] 殺死}}”

# = 常规 =
* *[粒子](粒子.md)**
* 加入了粒子。

# 更改
# = 方块 =
* *[安山岩](安山岩.md)、[闪长岩](闪长岩.md)、[花岗岩](花岗岩.md)、[磨制安山岩](磨制安山岩.md)、[磨制闪长岩](磨制闪长岩.md)、[磨制花岗岩](磨制花岗岩.md)和[石头](石头.md)**
* ID现在被拆分为：。
* * 的数据值仍然可用。

* *[饰纹陶罐](饰纹陶罐.md)**
* 现在可在其中放置最多一组的同类物品。
* * 现在[漏斗](漏斗.md)、[漏斗矿车](漏斗矿车.md)和[投掷器](投掷器.md)可以向饰纹陶罐中放置物品，和/或从其中去除物品。
* * [红石比较器](红石比较器.md)现在可检测其中放置的物品数量。
* * [玩家](玩家.md)现在可以与之交互，并可以在其中放置物品。
* ** 玩家的交互动作会使它们晃动，并且发出频率为11的振动。
* * 没有对应界面，其中的物品需要玩家将其破坏后才能取出。
* 现在饰纹陶罐可被弹射物击毁，使其碎裂并掉落其所有内容物。
* 现在可以堆叠至64个。

* *[木板](木板.md)**
* ID现在被拆分为：。
* * 及其数据值仍然可用，但不会在命令提示中显示。

# = 生物 =
* *[卫道士](卫道士.md)和[唤魔者](唤魔者.md)**
* 现在会在和平难度下消失。

# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 将被[岩浆块](岩浆块.md)杀死时的死亡消息由“”更改为“”。

* *[袭击](袭击.md)**
* [灾厄村民](灾厄村民.md)和[女巫](女巫.md)现在可以加入袭击。

# = 常规 =
* *[设置](设置.md)**
* 移除了“垂直同步”选项。
* * 玩家现在需要在视频设置中使用改善输入延迟的模式以获得更加灵敏的输入体验。
* * 仍可以通过先前已有的方法禁用垂直同步功能（例如修改）。

* *[Realms](Realms Plus.md)**
* 现在在所有版本（包括所有非正式版）中可用。
* * 只要有处于活动状态的Realms订阅，任何玩家都可以创建一个免费的预览版Realm。
* * 预览版Realm与普通Realm分开，以避免出现任何问题，从而影响普通Realm。

* *游戏指南**
* 完全改造了游戏指南界面，为其加入了“百科全书”界面。
* 纠正了游戏指南界面中的各种拼写错误。
* 移除了游戏指南界面中“旧世界”相关的过时引用。
* 在游戏指南中加入了下界合金相关物品的描述。

# = 技术性 =
* *[基岩版编辑器](基岩版编辑器.md)**
* 加入了对API的事件支持。
* * 加入了新的触发后事件和信号。
* 修复了切换至十字准星中间画笔进行绘画时不会清除立方体画笔的漏洞。

* *[附加包](附加包.md)和脚本引擎**
* 改进了一些常见脚本错误消息以提供更好的上下文和信息。

* *动画**
* 修复了服务器上相关的不安全性问题。

* *方块**
* 现在带有作为或方块特征的一部分的方块状态的方块会被结构方块正确旋转或镜像。

* *相机视角**

* *AI意向组件**

* *API**

* * 用于将组件ID映射到它们的类型。
* 更改了以返回正确的派生类型。

* *组件**

* *物品**

* *生物**

本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“”、“测试版 API”和“”子选项后才可使用。

# = 游戏内容 =
* *[交易](交易.md)**
* 修复了图书管理员不会出售最高等级的普通附魔书的问题。（）

# = 技术性 =
* *API**
* 加入了，并移除了中的。

* *图形**
* 将延迟渲染图形的视频设置中的光华选项的形式更改为强度滑块。
* * 玩家现在可以根据个人偏好来配置光华强度，仍然可以将滑块设置为0以禁用光华。
* 修复了在启用延迟渲染预览功能的情况下陷入在熔岩或细雪中时不会显示全屏覆盖层的问题。
* 修复了延迟渲染预览功能中的漏斗矿车内缺失漏斗的问题。
* 修复了延迟渲染预览功能中的部分发光方块（如海晶灯、荧石和熔岩等）无法转换为点光源的问题。
* 修复了延迟渲染预览功能中雨、雪和其他天气效果相关的问题。
* 提升了延迟渲染预览功能中远距离光源的质量。
* 平衡了延迟渲染预览功能中仅自发光方块发出的光的亮度。

* *性能与稳定性**
* 优化了Android和Xbox平台上的延迟渲染预览功能中定向光照和阴影的性能。

# 修复
* *游戏内容**
* 盔甲纹饰现在可以应用于自定义盔甲。
* 幻翼不再会错过对使用鞘翅滑翔的玩家进行跟踪的机会。
* 降低了玩家生成在树叶上的概率。

* *袭击**
* 现在通过刷怪蛋生成的女巫能够加入袭击并向袭击者投掷药水。

* *常规**
* 玩家现在可以在Xbox平台上的Realms中下载大于1GB的世界。

* *触摸控制**
* 用于下船的触摸控制按钮不再会持续表现为被按下。（）

* *用户界面**
* 解锁大量物品时配方解锁弹窗不再会加快弹出速度。
* 现在物品栏内的搜索栏会与UI的其余部分对齐。（）
* 将菜单退出加入至可重新映射的操作，其默认值被设置为鼠标后退键。
* 修复了使用含摇杆的触摸控制时，市场包中的自定义载具会显示错误提示的问题。
* 现在Xbox屏幕键盘位于用户所输入文本前方时会移动至不同的位置上。（）
* 移除了测试版HUD中的“Discovery”关键字的本地化。（）
* 修复了岩浆块相关的英文死亡消息中的语法错误。（）
* 更新了在下界中被床炸死时的死亡消息。（）

* *原版趋同**
* 唤魔者和卫道士不再会生成在和平难度下的世界中。（）

* *世界生成**
* 可疑的沙子不再会生成于寒带海底废墟。（）</onlyinclude>
