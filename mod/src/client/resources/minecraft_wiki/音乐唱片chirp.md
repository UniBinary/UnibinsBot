# 音乐唱片chirp

*页面ID: 156535* | *来源: Minecraft Wiki*

* *chirp**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的同名曲目。

# 获取
# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片chirp。

# 用途
# = 音乐 =

[noicon](File:chirp.ogg.md)

Chirp是一首具有复古的曲调的原因，游戏内时长为3分05秒。

# = 红石 =

音乐唱片chirp放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为4的信号。

# 你知道吗
* 此唱片使用来自[Optigan](Wikipedia:Optigan.md)弹奏的唱片“Bossa Nova Style”的样品。<ref>https://optigan.com/info/optigan/merchandise-catalog/discs/entertainment-folio-1six-pack/</ref> 它听起来也非常像来自游戏系列*[LittleBigPlanet](Wikipedia:LittleBigPlanet.md)*的歌曲“The Orb Of Dreamers”，它也使用了该样品。可以[在此](https://www.gamerevolution.com/news/1354-new-minecraft-song-may-have-plagiarized-little-big-planet)对比两首歌曲。
