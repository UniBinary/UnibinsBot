# Java版14w32a

*页面ID: 32459* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w32a**是[Java版1.8](Java版1.8.md)的第42个快照，发布于2014年8月6日<ref></ref>，加入了红砂岩、盔甲架、新的NBT标签和新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[红砂岩](红砂岩.md)**
* 可以用4个排列成正方形的[红沙](红沙.md)合成。
* 有雕纹红砂岩、平滑红砂岩、红砂岩楼梯和红砂岩台阶的形式。
* * 雕纹红砂岩的纹理上是一个凋灵的图案而不是苦力怕。
* * 红砂岩台阶（就像石台阶和砂岩台阶一样）有一个平滑变种。
* * 由平滑双台阶组成——<code>minecraft:double_stone_slab2:8</code>。
* 只生成在恶地生物群系的洞穴入口。

# = 生物 =
* *[盔甲架](盔甲架.md)**
* 可以装饰性地展示盔甲（包括[南瓜](南瓜.md)、[生物头颅](生物头颅.md)和玩家的头）。
* * 盔甲架可以通过右键点击或者用[发射器](发射器.md)发射装上盔甲。
* * 发射器无论瞄准盔甲架什么部位都可以装上盔甲。
* * 右键点击盔甲架上的装备可以移它。
* * 可以展示盔甲的[光效](光效.md)和染色。
* 可以使用任意一种类型的[台阶](台阶.md)和6个[木棍](木棍.md)合成。
* 可以堆叠至16个。
* 盔甲架实际上是实体而不是方块，所以它们可以使用命令生成并且可以放进[矿车](矿车.md)里。
* NBT标签可以创造小的（<code>Small</code>）、隐形的（<code>Invisible</code>）、带胳膊的（<code>ShowArms</code>）、不可摆放盔甲的（<code>DisabledSlots</code>）、不受重力影响的（<code>NoGravity</code>）和有预设姿势的（<code>Pose</code>）盔甲架。

# = 命令格式 =
* *[NBT标签](NBT标签.md)**
* <code>NoAI</code>可以使实体失去它们的AI。
* * 没有AI的实体不会攻击玩家、移动和转身，它们对重力和其他生物的推撞没有反应，但仍会受伤、死亡和骑乘其他实体。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* “This is good for realms.”

# 更改
# = 方块 =
* *[信标](信标.md)**
* 信标发出的光柱会在穿过[染色玻璃](染色玻璃.md)和[染色玻璃板](染色玻璃板.md)后改变颜色。
* * 让光柱穿过多个染色玻璃或染色玻璃板后颜色会混合。

* *[砂土](砂土.md)**
* 用[锄](锄.md)右键点击砂土会使其变成普通的[泥土](泥土.md)。

# = 游戏内容 =
* *[生命条](生命条.md)**
* 现在受伤时生命条有了新的动画，可以显示玩家失去了多少生命值。
