# Java版15w34c

*页面ID: 17798* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w34c**是[Java版1.9](Java版1.9.md)的第12个快照，发布于2015年8月21日<ref></ref>，加入了新的粒子，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[粒子](粒子.md)**
* 新的<code>sweepAttack</code>粒子。
* * 应用在新的防御性横扫攻击。

# 更改
# = 物品 =
* *[剑](剑.md)**
* 新的站立／潜行状态下挥剑时出现的防御性“横扫攻击”
* * 接近一击的生物（边界框水平拓宽1方块，垂直拓宽0.25方块），在攻击者3方块以内会被击退但是不会受到伤害
* * 造成的击退相当于击退I魔咒的80%。
* ** 使用击退魔咒只会影响受到攻击的玩家/生物。
* * 产生<code>sweepAttack</code>粒子效果。

* *[斧](斧.md)**
* 斧的新攻击机制：
* * 用斧攻击使用盾牌格挡的玩家有概率使玩家的盾牌失效5秒钟。
* ** 基础概率为25%，斧的效率魔咒每升一级，会增加5%，疾跑状态会增加75%。
* ** 能通过物品图标的“滚动帘”动画看到。
* *[末影珍珠](末影珍珠.md)和[紫颂果](紫颂果.md)**
* 每次使用后都有冷却时间。
* * 和盾牌有相同的“滚动帘”动画。
* 紫颂果不再能把玩家传送到[下界](下界.md)顶部。

# = 游戏内容 =
* *战斗**
* 若[盾牌](盾牌.md)成功抵挡了一次攻击，攻击者会被击退。
* 在物品气泡中显示攻击速度。
* 不同的工具有不同的攻击速度和伤害。[锄](锄.md)最快，但相比于之前版本伤害仅有小提升；[斧](斧.md)的伤害大幅提升，但攻速最慢。其他工具请参照下表。
