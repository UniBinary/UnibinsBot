# 基岩版1.19.30.20

*页面ID: 97618* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.30.20**（Android）、**Preview 1.19.30.20**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.30](基岩版1.19.30.md)的首个测试版，发布于2022年8月4日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[专用服务器](基岩版专用服务器.md)**
* 加入了服务器属性，用于在服务器范围内禁用指定皮肤。

# 更改
# = 方块 =
* *[附魔台](附魔台.md)**
* 现在会在[附魔](附魔.md)物品时发出音效。

# = 非生物实体 =
* *[火球](火球.md)**
* 更改了碰撞箱以匹配。

# = 技术性 =
* *活动对象属性**
* 整型和浮点型活动对象属性现在会将值限定在指定范围内。

* *附加包与脚本引擎**
* 不再会影响玩家。

* *命令**
* 目标选择器现在会获取与命令来源玩家所获取位置相同的玩家的位置。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“旁观模式”、“假日创造者功能”、“即将推出的创作者功能”和“应用测试框架”子选项后才可使用。

# = 常规 =
* *[旁观模式](旁观模式.md)**
* [末影人](末影人.md)不再会被旁观模式玩家激怒。（）
* [幽匿感测体](幽匿感测体.md)不再会检测到旁观模式玩家在[水](水.md)或[熔岩](熔岩.md)中游泳的动作。（）
* 现在玩家切换到旁观模式后会断开身上的[浮漂](浮漂.md)。
* 旁观模式玩家不再会被爆炸推动。（）
* [细雪](细雪.md)被旁观模式玩家穿过时不再会产生粒子。（）
* [大型垂滴叶](大型垂滴叶.md)被旁观模式玩家触碰到后，其叶面不再会倾斜。（）
* 现在旁观模式玩家在死亡后会保留物品栏中的物品和装备的盔甲。（）
* 旁观模式玩家不再能够通过手持食物来吸引生物。（）
* 命令现在可以定位旁观模式玩家。（）
* 旁观模式不再能通过命令进入，现在仅能够使用命令进入。
* 使用触控的旁观模式玩家不再可以破坏[船](船.md)和[矿车](矿车.md)。（）
* [河豚](河豚.md)不再会对附近的旁观模式玩家做出反应。

# 修复
* *常规**
* 更改了恶魂火球的碰撞箱以匹配。
* 附魔台现在在附魔物品时会发出音效。
* 降落在紫水晶块上不再会发出音效。

* *深暗之域**
* 增加了幽匿尖啸体和幽匿感测体在深暗之域和远古城市中的生成概率以匹配。 （）

* *方块**
* 更改了西瓜方块的底部纹理，使其与顶部纹理相统一。（）
* 泥砖台阶现在可以通过命令放置在方块的上部分。（）
* 边界方块现在会阻挡处于任何高度的玩家。

* *生物**
* 末影人不再会被创造模式玩家激怒。（）
* 更改了猫坐下时的头部方向以匹配。（）
* 修复了导致拴住悦灵的拴绳在改变位置后会断开的问题。（）
* 更改了山羊的冲撞动画，现在在准备冲撞时头会缓慢低下。（）
* 修复了一个可能导致村民在睡觉时碰撞箱脱离服务器的漏洞。

* *用户界面**
* 物品堆叠的弹出动画现在只会在加入新物品时播放。（）
* 拥有自定义名称的村民会现在将名称与交易等级一并显示。（）
* 修复了附魔皮革物品不会有闪光动画的UI问题。（）
* 加入了新的连接错误信息，以更好显示连接错误的区域。

* *游戏内容**
* 活塞的伸缩动画现在更流畅了。（）

* *物品**
* 红树木板、绯红木板和诡异木板现在可以用来修复盾牌。（）

* *市场**
* “无法连接到市场”错误信息不再会被文本朗读器错误朗读。
* 修复了导致文本朗读器朗读“我的内容”页面上的非高亮部分的问题。

* *性能与稳定性**
* 修复了一个可能导致加载床上玩家时出现崩溃的问题。

* *村庄机制**
* 通过摧毁床来结束袭击后袭击栏不再会卡住。（）</onlyinclude>
