# 引雷

*页面ID: 35033* | *来源: Minecraft Wiki*

* *引雷（Channeling）**是用于[三叉戟](三叉戟.md)的[魔咒](魔咒.md)，能在[雷暴](雷暴.md)天气下击中目标时产生[闪电](闪电.md)。

# 获取

# 用途
当生物投掷出的具有引雷魔咒的[三叉戟](三叉戟.md)击中[生物](生物.md)或[避雷针](避雷针.md)时，会在击中的位置生成一道闪电。若具有引雷魔咒的三叉戟是由发射器投掷的，则击中生物时不会生成闪电，击中避雷针时会生成闪电。

如果具有引雷魔咒的三叉戟击中的是生物，则要求被击中的生物必须在露天位置，且当前的天气为[雷暴](雷暴.md)。具有引雷魔咒的三叉戟击中非生物实体也会产生闪电。

如果具有引雷魔咒的三叉戟击中的是避雷针，则要求被击中的避雷针必须在露天位置，且当前的天气为雷暴或。还要求避雷针所处的空间有降雨，即避雷针处于无降水生物群系、降雪的生物群系或上方有方块遮挡的位置时不会生成闪电。

引雷魔咒使用[天空光照](天空光照.md)强度是否为15来判断是否为露天位置，这意味着除击中避雷针外，即使击中位置上方被[玻璃](玻璃.md)等光照透明方块物理阻挡，引雷魔咒仍可以生效。判定实体是否在露天位置是从实体所在的位置（脚部位置）进行判定的，故若被击中的实体在[水](水.md)中、[熔岩](熔岩.md)中、[细雪](细雪.md)中、[蜘蛛网](蜘蛛网.md)中、[灵魂沙](灵魂沙.md)上、[蜂蜜块](蜂蜜块.md)上、8层的[雪](雪.md)上，或具有坐姿的生物坐在靠近地面的实体上等，使实体所在方块不是光照透明方块，则引雷魔咒无法生效。<ref></ref>

由于引雷可以受控地生成闪电，故也可以受控地将[苦力怕](苦力怕.md)、[村民](村民.md)、[猪](猪.md)、[红色哞菇](红色哞菇.md)和[棕色哞菇](棕色哞菇.md)分别转化为[闪电苦力怕](闪电苦力怕.md)、[女巫](女巫.md)、[僵尸猪灵](僵尸猪灵.md)、棕色哞菇和红色哞菇。

当三叉戟同时具有引雷和[激流](激流.md)魔咒时，由于激流禁用了三叉戟的投掷行为，玩家无法通过常规方式生成可触发引雷的三叉戟投掷物，因此在正常游戏过程中引雷魔咒无法生效。

然而，若通过命令等方式直接生成具有引雷魔咒的三叉戟投掷物实体，即使该三叉戟同时具有激流魔咒，引雷效果仍可正常触发。
