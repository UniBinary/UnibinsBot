# 兔子脚

*页面ID: 12761* | *来源: Minecraft Wiki*

* *兔子脚（Rabbit's Foot）**是由[兔子](兔子.md)掉落的一种[酿造](酿造.md)原材料。

# 获取
# = 掉落物 =

成年[狐狸](狐狸.md)自然生成时有2%的概率在嘴里叼着兔子脚，且其死亡时叼着的兔子脚总是会掉落。

# = 礼物 =

已驯服的[猫](猫.md)赠予玩家礼物时，礼物有16.129%的概率是1个兔子脚。

# = 酿造材料 =

# = 交易 =

# = 喂食 =
[骆驼尸壳](骆驼尸壳.md)会跟随/手持兔子脚的玩家，给骆驼尸壳喂食兔子脚可使其恢复点生命值。
