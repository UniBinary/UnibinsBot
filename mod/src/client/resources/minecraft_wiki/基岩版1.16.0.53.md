# 基岩版1.16.0.53

*页面ID: 56774* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.0.53**是[基岩版1.16.0](基岩版1.16.0.md)第7个测试版，发布于2020年3月26日<ref></ref>，加入了加载世界前的法律免责声明，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[世界](世界.md)**
* 加入了加载世界前的法律免责声明：屏幕中的新信息框会告知玩家“在线游戏未分级”。

# 修复
* *崩溃**
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了主机版在分屏模式下退出游戏时可能发生的崩溃。
* 修复了使用角色创建器上的部分自定义角色时的稳定性问题。

* *性能**
* 提升了展示地图的物品展示框的性能。（）

* *常规**
* 修正了专有服务器文档。（、、、和）
* 修复了Gear VR上导入世界模板（.mctemplate）时无法显示的问题。
* 修复了Realms中导致区块无法正确加载的问题。（）
* 修复了“Alex”角色皮肤上的纹理问题。

* *游戏内容**
* 修复了村民无法到达其工作站点方块而导致无法工作的问题。
* 为其他语言加入了Java词汇表的翻译。
* 新创建的地图现在拥有正确的缩放比例。 （）
* 修复了转换为新版本的世界中的地图比例不正确的问题。（）
* 修复了给绵羊剪毛后其纹理不会变为已剪毛纹理的问题。（）
* 修复了部分魔咒不能生效的问题。（）
* 修复了音乐唱片的名称未被翻译为对应语言的问题。

* *图形**
* 修复了透过不透明方块（如玻璃）来看告示牌文字的渲染问题。（）
* 修复了物品展示框中的地图会闪烁为紫色或黑色图案的问题。
* 现在动画比例在关键帧之间使用线性插值。

* *附加包和脚本**
* 现在使用渲染控制器切换其他几何图形即可立即在游戏中更改几何图形。
* 修复了使用带有空格的标签作为参数时选择器@e[tag=]和@e[tag=!]会出现异常的问题。</onlyinclude>
