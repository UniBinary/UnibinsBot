# 水
水的物理特征也在此版本当中受到了改动，玩家在水中的行为也随之发生了变化。

# = 游泳 =
玩家有了真正的游泳动作，可在水下尝试疾跑时激活。这也使得玩家能够直接在水下向任意方向移动，包括正下方。如果玩家因饥饿值过低而无法疾跑，则该玩家此时也无法游泳。在水下还可以加速下沉。

游泳时，玩家可以穿过1格大小的缝隙，与使用[鞘翅](鞘翅.md)飞行相似。

# = 物品与经验 =
物品和经验现在会浮上水面，而不再沉入水底。这使得掉落物在玩家死于水中后更易找回，而垂直运输物品也变得相对简单。

# = 气泡柱 =

[thumb|水下气泡柱，左侧为[[岩浆块](File:Underwaterbubbles.png.md)产生的，右侧为[灵魂沙](灵魂沙.md)产生的]]

[岩浆块](岩浆块.md)和[灵魂沙](灵魂沙.md)现在会在水下产生气泡柱。岩浆块会自然生成在[水下废墟](水下废墟.md)当中，以及水下峡谷中水与熔岩相接之处，而灵魂沙不会在海里自然生成。玩家可以在气泡柱当中呼吸并恢复氧气条。

岩浆块产生的气泡柱会向下牵引实体，而灵魂沙产生的气泡柱会向上推动实体。

# = 呼吸 =
玩家出水后，氧气值每刻恢复4[游戏刻](游戏刻.md)（0.2秒），而不是立即恢复到最大值。

# = 视觉效果 =
水现在在不同的生物群系中拥有不同的颜色和能见度。

水下视觉现在更加清晰了，且玩家在水下停留的时间越久，视觉就会越清晰，但深水处更暗了。[水下呼吸](水下呼吸（状态效果）.md)状态效果和[](水下呼吸（魔咒）.md)魔咒不再会增强水下视野。
