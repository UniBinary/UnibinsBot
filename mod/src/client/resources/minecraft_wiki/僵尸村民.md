* *僵尸村民（Zombie Villager）**是一种[僵尸](僵尸.md)变种，在其带有[虚弱](虚弱.md)效果时使用[金苹果](金苹果.md)可将其治愈成[村民](村民.md)。

# 生成

[缩略图|带有一把[[附魔](File:Zombie Villager with Encharted Wep.png.md)铁剑的僵尸村民]]

自然生成的僵尸有5%的概率生成为僵尸村民。

当[僵尸](僵尸.md)、僵尸村民、[尸壳](尸壳.md)、[溺尸](溺尸.md)或</ref><ref group="注释">僵尸猪灵在自然条件下不会攻击村民，但若[袭击](袭击.md)胜利后村民发射的[烟花火箭](烟花火箭.md)伤害到了它们，它们会进行反击。</ref>}}杀死村民时，村民会有概率变成僵尸村民。以这种方式生成的僵尸村民只会在区块卸载时消失。

在基岩版中，被上述僵尸及其变种攻击后但未死亡的村民，如果在3秒内因为其他无来源伤害死亡，则依然会被感染生成僵尸村民。

[雪屋](雪屋.md)的地下室中会自然生成一个牧师僵尸村民。

僵尸村民也会在[僵尸村庄](村庄#僵尸村庄.md)生成。在僵尸村庄生成的僵尸村民会有意躲避阳光，且不会自然消失。

# = 增援 =

在困难[难度](难度.md)下，僵尸村民受到攻击时可能会生成增援僵尸村民。

# 变种
# = 幼年僵尸村民 =
[thumb|基岩版中幼年僵尸村民可骑乘的所有生物](File:Baby Zombie Villager Jockeys.png.md)
僵尸村民有5%的概率会生成为幼年僵尸村民。幼年僵尸村民的特性与成年僵尸村民略有不同：
* 移动速度比普通僵尸村民快50%，但生命值与之相同，使其更加难以对付。
* 叫声的音调比成年僵尸村民高。
* 被治愈后会变成幼年村民。
* 穿戴的[盔甲](盔甲.md)会缩小以适应身体尺寸。
* 碰撞箱缩小，可以穿过1×1格的空间。
* 被[玩家](玩家.md)或驯服的[狼](狼.md)杀死时会掉落，而不是。
* 永远不会成长为成年僵尸村民。
幼年僵尸村民有5%的概率会在附近的[鸡](鸡.md)上生成成为[鸡骑士](鸡骑士.md)（如果附近没有鸡则生成失败），还有4.75%的概率附带一只[鸡](鸡.md)生成成为[鸡骑士](鸡骑士.md)。

僵尸村民的盔甲不受到多数伤害来源造成的伤害，即玩家正常损害盔甲的途径在僵尸村民的盔甲上无效。另外，僵尸村民自身拥有护甲值，为其提供对[大部分伤害来源](盔甲机制.md)的1.6%-8%减免。

# == 万圣节 ==

在[万圣夜](wzh:万圣夜.md)（10月31日）当天，僵尸村民生成时有22.5%的概率戴着[雕刻南瓜](雕刻南瓜.md)，有2.5%的概率戴着[南瓜灯](南瓜灯.md)，但雕刻南瓜或南瓜灯不会掉落。<ref></ref>

# = 经验值 =
成年僵尸村民被玩家或驯服的狼杀死时会掉落，幼年僵尸村民为。如果这只僵尸村民自然生成时就穿戴着盔甲，每件盔甲还会额外掉落。

# 行为

僵尸村民的多数行为与僵尸相同，会尝试近战攻击[玩家](玩家.md)、幼年[海龟](海龟.md)、[村民](村民.md)、[流浪商人](流浪商人.md)、[铁傀儡](铁傀儡.md)和，会站在[海龟蛋](海龟蛋.md)上来踩碎它们。不同于僵尸的是，即使僵尸村民长时间待在水下，也不会变成[溺尸](溺尸.md)；僵尸村民被[闪电苦力怕](闪电苦力怕.md)炸死后也不会掉落[僵尸的头](僵尸的头.md)；僵尸村民会反击[旋风人](旋风人.md)；僵尸村民会优先踩踏海龟蛋；僵尸村民无法透过方块看见村民和流浪商人。

僵尸村民不能像村民那样打开或关闭门，但与僵尸类似，在困难难度下，部分僵尸村民仍具备破门的能力。

如果一个僵尸或僵尸村民被其他生物所攻击，附近的僵尸村民会向该生物产生敌意。

# = 村民行为 =
僵尸村民通常不会表现出任何村民行为，不能[交易](交易.md)或改变自己的职业。

僵尸村民具有村民拥有的部分数据，包括村民的生物群系服装、职业、职业等级、所有的交易信息。在僵尸村民被治愈前，和村民有关的数据不会改变。

以敌对生物生成方式生成的僵尸村民会有随机的职业。幼年僵尸村民只会是失业。

从未进行过交易的僵尸村民在治愈后若找不到需要的工作站点方块，则在治愈后就会失业。

# = 生物族群 =

僵尸村民是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉直到接触水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

僵尸村民会在阳光下[着火](着火.md)，生成在僵尸村庄中的僵尸村民在未戴头盔或生物头颅时会寻找阴凉处、水域以及来避免着火，但它们会为了追逐攻击目标而离开这些安全区域。

# = 治愈 =
玩家可对拥有效果的僵尸村民[金苹果](金苹果.md)（[附魔金苹果](附魔金苹果.md)不起作用<ref></ref>）将其治愈为[村民](村民.md)。通过以下方式可使僵尸村民获得虚弱效果：
* [喷溅型虚弱药水](喷溅型虚弱药水.md)，可由玩家、[女巫](女巫.md)或[发射器](发射器.md)掷出
* 带有虚弱状态效果的[区域效果云](区域效果云.md)，可由玩家或发射器掷出的[滞留型虚弱药水](滞留型虚弱药水.md)产生
* [虚弱之箭](虚弱之箭.md)，可由玩家、发射器或[焦骸](焦骸.md)射出
* * 使用附有[穿透](穿透.md)的[弩](弩.md)射出的虚弱之箭会穿透僵尸村民，此后仍可以被捡起。由此可以无限使用该药箭。

金苹果喂食成功时，僵尸村民会发出嘶嘶声并开始颤抖，同时它会获得I（简单、普通或）或II（困难）}}效果，时长与初始治愈时间相同。治愈过程需要3-5分钟，在此阶段僵尸村民仍会有和[僵尸](僵尸.md)一样的行为。

初始的治愈时间为一个在3600与6000之间的随机整数，每[游戏刻](游戏刻.md)治愈时间都会减少1，且每刻有1%的概率在以此僵尸村民为中心的9×9×9的空间内搜索[铁栏杆](铁栏杆.md)和[床](床.md)（床的各半分别计算）。每搜索到一个，都有30%的概率使治愈时间额外减少1，最多搜索14个。故在放满14个的情况下可以使治疗速度提升4.2%。治疗时间减至0时，僵尸村民就会被治愈。重新加载可以使僵尸村民立即治愈。<ref></ref>

治愈后，僵尸村民会效果}}或。僵尸村民生成时自带的盔甲和手持物品会消失，捡起的盔甲和物品则会掉落。

自然生成的有职业僵尸村民被治愈后会失去职业。

被治愈的村民在治愈它的玩家与之交易时，交易会有较高的永久折扣。被治愈的村民周围的其他村民也会提供较小幅度的少量折扣。以该村民为中心33×33×33大小范围内的其他村民会根据被治愈村民的数量提供成比例的折扣。被治愈且未进行过交易的村民也有可能变成傻子，这意味着该村民无法提供打折的交易。同时傻子僵尸村民也有可能被治愈为失业村民。被治愈的村民及其附近会获得并传播[言论](言论.md)。

把游戏难度从其他难度调成和平难度不会使僵尸村民变成村民，僵尸村民会像其他敌对生物一样消失。

一次治愈会带来相当于100至125倍价格乘数的折扣。以图书管理员为例，第一次治愈结束后附魔书的价格减少25[绿宝石](绿宝石.md)（最少为1绿宝石），为125×0.2（0.2为附魔书对应价格乘数），但随时间推移折扣会逐渐减少至20绿宝石。上文只考虑了治愈僵尸村民产生的折扣，不考虑交易本身产生的言论、供需关系变化带来的价格变化。

生成为[鸡骑士](鸡骑士.md)的僵尸村民被治愈后仍会骑在鸡身上，即使成年后也无法主动从鸡身上脱离。<ref></ref>

如果骑乘者是幼年僵尸村民，将其治愈成幼年村民时会将它与鸡分离开来。
