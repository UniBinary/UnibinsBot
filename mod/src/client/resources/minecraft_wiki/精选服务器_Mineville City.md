# 精选服务器/Mineville City

*页面ID: 33920* | *来源: Minecraft Wiki*

* *InPVP**是[Minecraft](Minecraft.md)[基岩版](基岩版.md)的[精选服务器](精选服务器.md)。它是第一个与[独乐不如众乐更新](独乐不如众乐更新.md)到来的独有服务器。

# 游戏
# = 空岛战争（Sky Wars） =
你生成在一个空岛，岛上有3个装满[方块](方块.md)、[物品](物品.md)、[武器](武器.md)和[盔甲](盔甲.md)的[箱子](箱子.md)。你必须用[方块](方块.md)搭到其他岛上并杀死岛上的人。最后的生存者获得胜利！

# = TNT跑酷（TNT Run） =
[TNT](方块.md)会在你走过的[TNT](TNT.md)路径掉下来，如果你掉进虚空你就被淘汰了。

# = 起床战争（Money Wars） =
拥有生成器和商店的“空岛战争”，你可以在[床](床.md)上重生，如果你的[床](床.md)被破坏了你就无法重生，被击杀后淘汰。

# = 方块猎人（Block Hunt） =
你生成为一个方块或猎人，方块变成隐形的并被一个方块跟随。方块躲避猎人来获得胜利。猎人要在时间用尽之前找到方块。

# = 太空竞赛（Space Race） =
“太空竞赛”是跑酷游戏，如果你跑进前十名，你将获得称号“Space”。

# = 高塔战争（Tower Wars） =
收集资源以升级装备来夺取对方队伍的旗帜。官方原本是想用黑暗的“末地天空”来作为地图的天空，但是现在改成了两张昼夜不同的地图。

# 大厅
大厅名称为**Nova空间站**。

# 网络
InPvP有一个Xbox网络。你的年龄必须为6+。
