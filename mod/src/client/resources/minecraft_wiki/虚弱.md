# 虚弱

*页面ID: 28816* | *来源: Minecraft Wiki*

* *虚弱（Weakness）**是一种降低[近战攻击](近战攻击.md)伤害的[状态效果](状态效果.md)。

# 效果
对着带有虚弱效果的[僵尸村民](僵尸村民.md)使用[金苹果](金苹果.md)可将其治愈。

饮用[灵药](灵药.md)能消除虚弱。

# = Java版 =
受影响生物的基础近战攻击伤害降低×效果等级，其结算在[暴击](近战攻击#暴击.md)和[魔咒](魔咒.md)之前。

# = 基岩版 =
受虚弱影响生物的近战攻击伤害结算在魔咒之后，暴击之前。

伤害大小可以由递推公式<math>d_n=0.8d_{n-1}-0.5</math>或通项公式<math>d_n=0.8^nd_0+\frac{0.8^n-1}{0.4}</math>计算，其中<math>d_0</math>是输入的攻击力，<math>d_n</math>是输出的攻击力，<math>n</math>为虚弱状态效果的等级。如果得出的值为负数，则不受到伤害。<ref>https://docs.google.com/document/d/1GtZ9ceTfVGbEkKkbZAfzpKKGk2FQ0FwmeUyw5ja14B8/edit?usp=sharing</ref>

当[力量](力量（状态效果）.md)效果和虚弱效果同时存在时，会先使用力量的计算公式，得出的值会作为<math>d_0</math>的值使用。

[铁傀儡](铁傀儡.md)的近战攻击伤害不会被虚弱效果降低。<ref></ref>
