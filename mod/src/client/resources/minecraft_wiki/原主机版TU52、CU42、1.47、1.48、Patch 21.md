# 原主机版TU52、CU42、1.47、1.48、Patch 21

*页面ID: 66373* | *来源: Minecraft Wiki*

* *TU52/CU42/1.47/1.48/Patch 21**是[原主机版](原主机版.md)的一次更新，发布于2017年4月25日。<ref></ref><ref></ref>

# 新内容
# = 常规 =
* *混搭包**
* 加入Glide Beasts Track组合包（Dragon, Kraken 和 Yeti Glide 道路）。

* *小游戏**
* 玩家在到达终点前需要通过所有关口。
* 在退回到主菜单之前，玩家可以在Glide单人模式玩更长时间。
* 减少Glide的重生延迟。
* 在冲过终点显示有颜色的粒子。
* 在Glide里面的Showdown现在显示“Hurry Up”。

# = 游戏内容 =
* *[音乐](音乐.md)**
* 加入新的Glide Tracks音乐。

# 修复
* *修复了7个漏洞**
