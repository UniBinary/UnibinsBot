# 荒野更新

*页面ID: 90245* | *来源: Minecraft Wiki*

[alt=|thumb|荒野更新的官方Logo](File:Minecraft 1.19 Wild Update Logo.png.md)
[thumb|300x300px|荒野更新的官方艺术作品](File:Wild Update Artwork.jpg.md)
* *荒野更新（The Wild Update）**是一次主要更新，于2022年6月7日发布于[Java版1.19](Java版1.19.md)和[基岩版1.19.0](基岩版1.19.0.md)<ref></ref><ref></ref>，其主要内容是加入[深暗之域](深暗之域.md)、[红树林沼泽](红树林沼泽.md)及其相关内容。该次更新由官方宣布于[Minecraft Live 2021](Minecraft Live 2021.md)。<ref></ref>

在[Java版](Java版.md)上，此次更新的开发始于[1.19-exp1](Java版1.19-exp1.md)，其发布于2022年2月17日。1.19的[首个预发布版](Java版1.19-pre1.md)发布于2022年5月18日，[最后一个预发布版](Java版1.19-pre5.md)发布于6月1日，[第一个](Java版1.19-rc1.md)和[第二个](Java版1.19-rc2.md)发布候选版本分别发布于6月2日和6月3日。

在[基岩版](基岩版.md)上，此次更新开发始于[基岩版1.18.0.22](基岩版1.18.0.22.md)，其发布于2021年10月21日。

# = Java版 =
* [1.19.1](Java版1.19.1.md)发布以加入[聊天](聊天.md)功能和[悦灵](悦灵.md)复制，并修复一些漏洞。
* [1.19.2](Java版1.19.2.md)发布以修复一些严重漏洞。
* [1.19.3](Java版1.19.3.md)发布以加入部分[1.20](Java版1.20.md)的特性和重新加入[收纳袋](收纳袋.md)（须启用内置[数据包](数据包.md)），重制[创造模式物品栏](创造模式物品栏.md)，加入聊天举报草稿，以及末影龙、铁傀儡、雪傀儡和凋灵的刷怪蛋，并修复一些漏洞。
