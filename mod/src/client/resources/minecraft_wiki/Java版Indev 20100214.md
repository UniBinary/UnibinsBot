# Java版Indev 20100214

*页面ID: 35410* | *来源: Minecraft Wiki*

<onlyinclude>

* *Minecraft Indev**的一个版本发布于2010年2月14日，加入了新的世界主题。<ref></ref>

# 新内容
# = 世界生成 =
* *[世界主题](Indev世界选项#世界主题.md)**
* 加入了天堂（Paradise）和森林（Woods）两种世界主题。
* * 天堂：世界会有着更大的沙滩，不同种类的花也会在地表大量生成，作物生长较快，时间也会维持在正午。
* * 树林：世界中树木会大量生成，蘑菇也较常见。

# 更改
# = 方块 =
* *[泥土](泥土.md)**
* 任何处于海平面或海平面之下的[泥土](泥土.md)，暴露在足够的光照下都会变成[草方块](草方块.md)。

# = 常规 =
* *[HUD](HUD.md)**
* [玩家](玩家.md)的手现在会正常显示了。</onlyinclude>
