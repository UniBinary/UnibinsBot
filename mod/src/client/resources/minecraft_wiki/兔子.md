* *兔子（Rabbit）**是一种罕见的友好生物。它们是[兔子皮](兔子皮.md)、[兔子脚](兔子脚.md)和[兔肉](兔肉.md)的来源。

# 生成
兔子会在[雪原](雪原.md)、[冰刺之地](冰刺之地.md)、[针叶林](针叶林.md)、[积雪针叶林](积雪针叶林.md)、[沙漠](沙漠.md)、[繁花森林](繁花森林.md)、[草甸](草甸.md)、[樱花树林](樱花树林.md)、[积雪山坡](积雪山坡.md)和[雪林](雪林.md)生物群系生成。兔子还会在[原始云杉针叶林](原始云杉针叶林.md)和[原始松木针叶林](原始松木针叶林.md)中生成；兔子还会在[尖峭山峰](尖峭山峰.md)、[积雪沙滩](积雪沙滩.md)、[冰封山峰](冰封山峰.md)、[冻河](冻河.md)、[冻洋](冻洋.md)和[冰冻深海](冰冻深海.md)中生成。

兔子生成的方块需要满足光照等级不低于7的条件。兔子生成的方块类型与狼相似，不同的生物群系之间有所差异。

在一次成群生成的兔子中，有1-2只为幼年兔子。它们的毛色因生物群系而异。

针叶林生物群系及其变种会生成[狼](狼.md)和[狐狸](狐狸.md)，兔子通常会在生成后被它们杀死，所以兔子在沙漠与其他的生物群系中显得数量更多。

只能使用命令生成。

# 外观
[缩略图|右|自然生成的兔子的6种毛色](File:Six Rabbit Types.png.md) 自然生成的兔子会带有棕色、白色、黑色、黑白斑点、金黄色和棕白色中的一种毛色。

兔子生成时的毛色由其所在的生物群系决定：
* 在寒冷生物群系中，白色占80%，黑白斑点占20%。
* 在沙漠生物群系中，全为金黄色。
* 在其他生物群系中，棕色占50%，棕白色占40%，黑色占10%。

此外，还有或特殊的兔子。

# = 杀手兔 =

</ref>||Marsh Davies Mojang avatar.png}}
[缩略图|150px|右|杀手兔当前的纹理](File:Killer Bunny.png.md)
* *杀手兔（Killer Bunny）**是[Java版](Java版.md)独有的兔子变种。其毛色纯白，有横向的血红色眼睛，而普通兔子的眼睛为纵向。杀手兔可使用命令{{cmd|summon rabbit ~ ~ ~ {RabbitType:99<nowiki>}</nowiki>}}生成。若杀手兔没有自定义名称，游戏会将其自定义名称设置为“杀手兔”（<code>{translate: "entity.minecraft.killer_bunny"}</code>）。

在非和平难度下杀手兔（包括幼年个体）会迅速跳向16格半径内的玩家和[狼](狼.md)，速度远超普通的兔子。一旦它到达近处就会冲向玩家并扑到玩家身上，如果此时玩家未手持胡萝卜、金胡萝卜或蒲公英，则会在简单、普通、困难难度中分别每次受到点伤害。如果玩家攻击杀手兔，它会暂时四处逃窜，不久后又会再次冲向玩家并发起攻击。

未驯服的狼、未驯服的猫和狐狸会主动攻击杀手兔。如果有生物攻击杀手兔，附近的所有杀手兔会一起对该生物发起攻击。

尽管杀手兔具有攻击性，但它不会在和平难度下消失，此时其对玩家的行为与正常兔子相同，但不会主动逃跑，并且仍会攻击狼。

# = Toast兔 =
[缩略图|右|150px|一只被命名为“Toast”的兔子](File:Toast Rabbit.png.md)
将兔子命名为“Toast”（使用[命名牌](命名牌.md)或一个已重命名的[刷怪蛋](刷怪蛋.md)）会使它的纹理发生变化。相比自然生成的黑白斑点兔，其毛发上的黑白斑块更加规则。Toast的行为在命名前后并无差异。无论Toast之间进行繁殖，还是其与其他毛色的兔子繁殖，它们的后代都不会自带Toast的毛色，而是会按照其双亲原本的毛色正常遗传。如果将杀手兔重命名为Toast，它仍然会攻击玩家和狼。与杀手兔相同，Toast不会自然生成。

Toast的皮肤来源于reddit中一位用户[xyzen420](http://www.reddit.com/user/xyzen420)的女朋友[丢失的兔子](http://www.reddit.com/r/minecraftsuggestions/comments/27hjog/to_themogminer_my_bunny_is_missing_please_help_me/)。[Ryan Holtz](Ryan Holtz.md)将其加入游戏也是为了给她留个纪念。<ref></ref>

# 行为
兔子会漫无目的地四处蹦跳。它们在受到攻击时会四处逃窜。除杀手兔外，所有兔子都会躲避8格内的生存或冒险模式玩家，也会躲避4格内的敌对生物（除了、[史莱姆](史莱姆.md)、[岩浆怪](岩浆怪.md)与[恶魂](恶魂.md)），还会躲避10格内的[狼](狼.md)。

未驯服的[狼](狼.md)、未驯服的[猫](猫.md)和[狐狸](狐狸.md)会主动攻击兔子。

# = 啃食作物 =
[缩略图|右|150px|一只兔子正在啃食胡萝卜作物](File:Rabbit eating carrots.gif.md)
当[游戏规则](游戏规则.md)设为时：
* 兔子会寻找并吃掉成熟的[胡萝卜](胡萝卜.md)植株，使其生长阶段减少1级，如果生长阶段为0则胡萝卜会被替换为空气；
* 兔子会寻找并吃掉生长阶段大于1的胡萝卜植株，使其生长阶段减少1级，直到该作物的生长阶段降为1为止。

兔子只能搜寻自身周围[欧几里得距离](欧几里得距离.md)16格内的胡萝卜植株，且行进速度较慢一些。

# = 繁殖 =

兔子会跟随或内手持[胡萝卜](胡萝卜.md)、[金胡萝卜](金胡萝卜.md)或[蒲公英](蒲公英.md)的玩家。

兔子可以用胡萝卜、金胡萝卜或蒲公英[繁殖](繁殖.md)，繁殖成功时给予玩家。繁殖后双亲有/的冷却时间。繁殖出的幼年个体需20分钟才能成长为成年个体。可使用上述物品加速成长，每次减少约10%剩余成长时间。

对幼年兔子[金蒲公英](金蒲公英.md)可以阻止其成长为成年兔子，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年兔子无法被喂食除金蒲公英外的其他物品。

幼年兔子通常会遗传其双亲之一的毛色（各有47.5%概率），但还有5%的概率会根据所处的生物群系生成对应的毛色。

虽然杀手兔具有攻击性，但仍可以与其他兔子或与其他杀手兔繁殖，其后代的毛色生成也符合上述规律。

无法通过繁殖获得幼年的Toast兔子。
