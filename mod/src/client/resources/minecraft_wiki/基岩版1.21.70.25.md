# 基岩版1.21.70.25

*页面ID: 145787* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.70.25**（ChromeOS/Android）、**Preview 1.21.70.25**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.70](基岩版1.21.70.md)的第5个测试版，发布于2025年2月26日<ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[设置](设置.md)**
* 在移动平台上的设置中加入了“”选项。
* * 用于启用过滤不雅用语功能。
* 在设置中加入了“”选项。
* * 用于启用视角切换按钮。

* *[触摸控制](触摸控制.md)**
* 加入了视角切换按钮 [30px|class=pixel-image](File:Perspective BE1.png.md) 。
* * 仅开启“”选项后可用。
* * 在[旁观模式](旁观模式.md)下不可用。<ref></ref>

# 更改
# = 生物 =
* *[哞菇](哞菇.md)**
* 更改了所有变种的鼻子边缘纹理，并去除了腿部的粗糙边框。

* *[牛](牛.md)**
* 回退了1.21.70.23中对温带牛和寒带牛的鼻子边缘纹理的更改，并去除了它们腿部的粗糙边框。

* *[绵羊](绵羊.md)**
* 蓝色、淡蓝色、青色、黄色、橙色和红色绵羊不再自然生成。
* 现在热带生物群系中的少见毛色仅包括灰色、淡灰色、白色和黑色。
* 现在寒带生物群系中的少见毛色仅包括灰色、淡灰色、白色和棕色。
* 调整了羊毛纹理，以移除背部的明显线条。

* *[流浪商人](流浪商人.md)**
* 将用[水瓶](水瓶.md)、[水桶](水桶.md)、[奶桶](奶桶.md)、[发酵蛛眼](发酵蛛眼.md)、[烤马铃薯](烤马铃薯.md)和[干草捆](干草捆.md)与其交易以换取[绿宝石](绿宝石.md)的最大[交易](交易.md)次数由1提升至2。

# = 游戏内容 =
* *[成就](成就.md)**
* 现在可以在启用来自[市场](市场.md)的[附加包](附加包.md)的世界中获取成就。
* * 若要在启用非市场附加包的世界中获取成就，该附加包的文件中必须包含：
  :<syntaxhighlight lang="json">
  "metadata": {
    "product_type": "addon"
  }
</syntaxhighlight>

# = 常规 =
* *[聊天](聊天.md)**
* 更新了不雅用语过滤列表。

* *生物群系**
* 加入了组件，用于覆盖色调方法的颜色。

* *方块**
* 空的钟被黏性活塞移动时不再会导致游戏崩溃。（）

* 将方块组件公开为一个JSON对象。此组件用于表示方块被破坏时使用的粒子。

* 将API函数更新为。

* 修复了导致农场放置在未加载区域附近的漏洞。
* 修复了无法为API函数可视化更新滑块的漏洞。

* 命令方块悬浮名称现在会在命令生成的GUI消息中显示。（）

* *图形**
* 将延迟渲染预览功能中的发光强度降低了10倍，创作者可能需要发光纹理值。
* 为体积散射调整了延迟渲染预览功能中的空气和迷雾密度，以提供更多可见光线。
* 进行了多项对延迟渲染预览功能中的自动曝光和眼部适应的细微调整。

# 修复
* *方块**
* 修复了仙人掌花的碰撞箱与仙人掌的碰撞箱不一致的问题。（）
* 花盆中的植物不再会过度拉伸。（）
* 植物盆栽不再会与花盆穿模。
* 为枯叶堆加入了基于生物群系的着色。
* 修复了野花簇在物品展示框中渲染时会出现流散的像素的问题。（）
* 修复了野花簇物品纹理与Java版相比略有偏移的问题。

* *生物**
* 温带牛的腿部不再会有粗糙的边框。
* 红色和棕色哞菇的腿部不再会有粗糙的边框。
* 修复了哞菇上的蘑菇会在一定距离外产生深度冲突的问题。（）
* 修复了铁傀儡不会在适当的受伤程度下出现开裂纹理的问题。
* 修复了寒带牛的头部侧面纹理不会被正确地镜像的问题。

* *游戏内容**
* 修复了使用具有使用持续时间的物品（钓鱼竿、食物、药水等）并切换槽位时会强制将玩家的槽位变回原先的槽位的漏洞。
* 修复了在疾跑时跳跃时攻击生物会移除玩家所有动量的问题。（）
* 修复了有延迟的玩家在战斗时无法击中对方的问题。（）
* 修复了使用床后玩家的碰撞箱有时会变得不正确的问题。（）

* *用户界面**
* 现在移动光标并按住按钮以拆分物品堆叠时会正确地跨槽位拆分。
* 修复了在创造模式物品栏中拆分物品堆叠时可能发生的潜在崩溃。
* 百科全书现在会使用正确的术语“Enchanting Table”而非“Enchantment Table”。（）
* 现在在手持装有收纳袋的收纳袋的情况下尝试合成收纳袋时会正确合成出收纳袋，而不只是消耗合成材料。（）
* 修复了无法在iOS预览版和PlayStation预览版中访问创建新的世界屏幕的问题。</onlyinclude>
