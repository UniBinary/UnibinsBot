# Java版1.9.3-pre2

*页面ID: 21045* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.9.3-pre2**是[Java版1.9.3](Java版1.9.3.md)的第2个预发布版，发布于2016年4月27日<ref></ref>。

# 新内容
# = 命令格式 =
* ***
* 用法：<code>-{}-/stopsound <nowiki><玩家></nowiki> [来源] [声音]</code>。

# 更改
# = 常规 =
* *[服务器](服务器.md)**
* 在该版本，当连接到一个服务器时，游戏会查询[https://sessionserver.mojang.com/blockedservers](https://sessionserver.mojang.com/blockedservers)，如果该服务器在黑名单中，将会提示服务器不可用。
* * 这种行为在[Java版1.9.3-pre3](Java版1.9.3-pre3.md)中被移除。
