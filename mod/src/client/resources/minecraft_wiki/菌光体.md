* *菌光体（Shroomlight）**是一种外观和[荧石](荧石.md)类似的发光方块，生成在[巨型下界菌](巨型下界菌.md)的菌盖中。

# 生成
# = 自然生成 =
菌光体会自然生成在[绯红森林](绯红森林.md)的[巨型绯红菌](巨型绯红菌.md)和[诡异森林](诡异森林.md)的[巨型诡异菌](巨型诡异菌.md)上。

# = 人为生成 =
在[菌岩](菌岩.md)上用[骨粉](骨粉.md)催熟[下界菌](下界菌.md)得到的巨型绯红菌或巨型诡异菌中也可能会生成菌光体。

# 获取
菌光体的物品形式只能通过破坏菌光体获得。

# 破坏
挖掘菌光体的合适工具是锄。

菌光体被破坏后会掉落自身。

# 用途
# = 光源 =
和[荧石](荧石.md)、[灯笼](灯笼.md)等[方块](方块.md)相似，菌光体会发出[亮度等级](亮度等级.md)为15的光。

# = 堆肥 =
对[堆肥桶](堆肥桶.md)使用菌光体会有65%的概率增加一层堆肥层数。

# = 生物 =
和[南瓜灯](南瓜灯.md)不同，生物无法生成在菌光体上。<ref></ref>
