* *剧毒土径（Poison Path）**是一种装饰性[方块](方块.md)。

# 生成
# = 自然生成 =
剧毒土径会自然生成于[马铃薯维度](马铃薯维度.md)的[植物园](植物园.md)、[田野](田野.md)生物群系和[马铃薯村庄](马铃薯村庄.md)中。

# = 转化 =
对着[马铃薯泥土](马铃薯泥土.md)、[薯皮草方块](薯皮草方块.md)或[腐败的薯皮草方块](腐败的薯皮草方块.md)[锹](锹.md)可将其变成剧毒土径。

# 获取
剧毒土径的物品形式不能在生存模式中正常获得，但可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)获得。

# 破坏
挖掘剧毒土径的合适工具是锹。

剧毒土径被破坏后会掉落1个[马铃薯泥土](马铃薯泥土.md)。

# 用途

剧毒土径主要用于装饰，生物无法在其上生成。剧毒土径的高度只有完整方块的，因此[火把](火把.md)和[按钮](按钮.md)等方块不能依附在该方块上。

剧毒土径方块上方如果紧邻[固体方块](固体方块.md)方块，将变成泥土，但所有[栅栏门](栅栏门.md)除外。
