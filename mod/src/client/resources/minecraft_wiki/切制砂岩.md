# 切制砂岩

*页面ID: 40917* | *来源: Minecraft Wiki*

* *切制砂岩（Cut Sandstone）**是[砂岩](砂岩.md)制作的装饰性方块。

# 生成
# = 自然生成 =
切制砂岩会在沙漠村庄、沙漠神殿和温带海底废墟中生成。

# 破坏
挖掘切制砂岩的合适工具是镐。切制砂岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

切制砂岩被破坏后会掉落自身。
