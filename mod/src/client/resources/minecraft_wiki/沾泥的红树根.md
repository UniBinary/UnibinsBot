# 沾泥的红树根

*页面ID: 94000* | *来源: Minecraft Wiki*

* *沾泥的红树根（Muddy Mangrove Roots）**是[红树根](红树根.md)和[泥巴](泥巴.md)合成的装饰性方块。

# 生成
# = 自然生成 =
[红树](红树.md)生成时，周围若有[泥巴](泥巴.md)与生成的[红树根](红树根.md)重叠，会形成沾泥的红树根。

沾泥的红树根也可能会在[试炼密室](试炼密室.md)的“入口”结构中作为植物造景的一部分生成。

# 破坏
挖掘沾泥的红树根的合适工具是锹。

沾泥的红树根被破坏后会掉落自身。

# 用途
# = 末影人 =
[末影人](末影人.md)可以搬起及放下沾泥的红树根。关闭[游戏规则](游戏规则.md)将阻止该行为。

# = 种植 =
沾泥的红树根上方可以种植[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)、[蕨](蕨.md)、[大型蕨](大型蕨.md)、[花](花.md)、[粉红色花簇](粉红色花簇.md)、[野花簇](野花簇.md)、[灌木丛](灌木丛.md)、[枯萎的灌木](枯萎的灌木.md)、[大型垂滴叶](大型垂滴叶.md)、[下界菌](下界菌.md)、[菌索](菌索.md)、[下界苗](下界苗.md)、[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)，[树苗](树苗.md)、[竹子](竹子.md)和[甜浆果丛](甜浆果丛.md)能在沾泥的红树根上生长。[甘蔗](甘蔗.md)和[蘑菇](蘑菇.md)也会在符合条件的情况下在沾泥的红树根上生长。

# = 转变 =
对上方为空气的[苔藓块](苔藓块.md)或[苍白苔藓块](苍白苔藓块.md)[骨粉](骨粉.md)，会使周围7×11×7范围内最上方的沾泥的红树根转变为苔藓块或苍白苔藓块。

[杜鹃树](杜鹃树.md)长成后会将其下方的沾泥的红树根转变为[缠根泥土](缠根泥土.md)。

[大型云杉](大型云杉.md)长成后会将其下方及周围的沾泥的红树根转变为[灰化土](灰化土.md)。

除大型云杉、杜鹃树、[红树](红树.md)及[珍异橡树](珍异橡树.md)外的[树木](树木.md)长成后，下方的沾泥的红树根会被转变为[泥土](泥土.md)。
