# Java版21w40a

*页面ID: 90056* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w40a**是[Java版1.18](Java版1.18.md)的第4个快照，发布于2021年10月7日<ref></ref>，移除和重命名了一些[生物群系](生物群系.md)，同时调整了地形和一些[生物](生物.md)的生成。

# 更改
# = 方块 =
* *[铜矿石](铜矿石.md)**
* 正常开采掉落[粗铜](粗铜.md)的最大数量由3改为5。

* *[切石机](切石机.md)**
* 现在可将1个[铜块](铜块.md)（含变种）加工成对应变种的4个切制铜块、4个切制铜楼梯或8个切制铜台阶。

* *[熔岩](熔岩.md)**
* 被调整为从Y=-54处开始生成，并会替换该高度以下的空气方块，用于填充深板岩层的洞穴空间。

# = 生物 =
* *[美西螈](美西螈.md)**
* 现在仅生成于[繁茂洞穴](繁茂洞穴.md)里[黏土](黏土.md)上方的水中。

* *[鳕鱼](鳕鱼.md)、[鲑鱼](鲑鱼.md)、[河豚](河豚.md)、[热带鱼](热带鱼.md)、[鱿鱼](鱿鱼.md)和[海豚](海豚.md)**
* 现在仅生成于Y=50至64高度之间的水中。
* 另外，热带鱼现在也生成于任意高度的繁茂洞穴中。

* *[发光鱿鱼](发光鱿鱼.md)**
* 现在仅生成于Y=30高度以下的水中。

* *[山羊](山羊.md)**
* 不再生成于[裸岩山峰](裸岩山峰.md)。

* *[僵尸](僵尸.md)**
* 现在又能在[溶洞](溶洞.md)里生成了。

* *常规**
* 优化了美西螈、山羊、[疣猪兽](疣猪兽.md)、[僵尸疣猪兽](僵尸疣猪兽.md)、[猪灵](猪灵.md)、[猪灵蛮兵](猪灵蛮兵.md)和[村民](村民.md)的AI。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 对于相同的X、Z坐标，非洞穴生物群系（例如[热带草原](热带草原.md)）不再随高度变化。
* 调整了一些生物群系的相对大小，以接近1.17的情况。
* 提高了大多数生物群系的平均大小。

[缩略图|450px|矿石分布变化](File:21w40a approximate ore distribution.jpg.md)
* *[矿石](矿石.md)分布**
* 更新了矿石分布，如图所示。
* * [铜矿石](铜矿石.md)现在会在Y=-16和Y=112之间生成，Y=48处最多，并增加了其[团簇](团簇.md)的生成量。
* * 提高了非暴露的[钻石矿石](钻石矿石.md)的生成量。
* * 将[绿宝石矿石](绿宝石矿石.md)的最低生成高度由Y=32降低到Y=-16，并增加了其团簇的生成量。
* * 提高了[金矿石](金矿石.md)在Y=-48以下的生成量。
* * 将高海拔处[铁矿石](铁矿石.md)的最低生成高度由Y=112降低到Y=80，并增加了其团簇的生成量。

* *[地牢](地牢.md)**
* 提高了生成数量，尤其是Y=0以下的数量。

* *[沙砾](沙砾.md)**
* 现在能生成于Y=0以下，并增加了其团簇的生成量。

* *[湖泊](湖泊.md)**
* 移除了水湖，其功能由[含水层](含水层.md)取代。

* *[岩浆块](岩浆块.md)**
* 略微提高了水下岩浆块的生成频率。
* 熔岩被调整为从 Y=-54 开始生成，并会替换该高度以下的空气方块，用于填充深板岩层的洞穴空间。

* *[村庄](村庄.md)**
* 现在外形略加分散。

* *常规**
* [基岩](基岩.md)层现在会根据[种子](种子（世界生成）.md)来生成。
