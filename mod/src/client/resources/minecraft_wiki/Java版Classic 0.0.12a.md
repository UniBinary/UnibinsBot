# Java版Classic 0.0.12a

*页面ID: 34854* | *来源: Minecraft Wiki*

/开发者版本}}
<onlyinclude>

* *0.0.12a**是的一次更新，发布于2009年5月19日<ref></ref><ref></ref><ref group="注">虽然某些来源说明该版本于5月20日发布，其实际上发布于5月19日22：36（UTC），此时是瑞典时间5月20日00：36。</ref>，加入了[基岩](基岩.md)、[水](水.md)、[熔岩](熔岩.md)和新的地形生成器。

# 新内容
# = 方块 =
* *[基岩](基岩.md)**
* 自然生成在世界底部。
* 无法被破坏、放置或选择。

* *[水](水.md)**
* 一种[液体](液体.md)，会自然生成在世界中。
* 可以无限传播。
* * 会蔓延以填补下方和旁边的所有可用空间。<ref></ref>
* ** 这意味着只需要一个水源就可以淹没整个世界。<ref></ref>
* 水不会在世界外工作（在世界生成后不会从世界外流入世界内）。<ref></ref>

* *[熔岩](熔岩.md)**
* 一种[液体](液体.md)，有概率生成在世界中。
* 可以无限传播。
* 靠近水时会生成石头。

# = 生物 =
* *[生物](生物（已移除实体）.md)**
* 在重新生成世界时不再重置。<ref></ref>

# = 世界生成 =
* *[熔岩湖](熔岩湖.md)**
* 现在会偶尔在地表生成。

* *[湖泊](湖泊.md)**
* 现在会偶尔在地表生成。

# = 游戏内容 =
* *常规**
* 在水中移动会比在空气中更慢。
* * 这只应用于在水中的玩家，生物仍可以在水中以全速移动。
* 玩家跳跃的高度提升了0.5格。<ref></ref>

# = 世界生成 =
* *[虚空](虚空.md)**
* 现在世界底部是无尽的熔岩。

* *[世界界限](世界界限.md)**
* 现在世界外会生成一片以基岩为海床的海洋。
* 玩家不再能够移动到世界外。

* *常规**
* 地形变得更加凌乱，地表可见更多凸起。现在也会生成岛屿了。
* 地形总在海平面上方1格处生成。
* 低于海平面的所有可以接触阳光的泥土在生成世界时都不会变为草方块。

# = 常规 =
* *[控制](控制.md)**
* 按下在四个渲染距离间循环。<ref name="TigSource"></ref>
* 按下将生成新的世界。<ref name="TigSource"/></onlyinclude>

# 你知道吗
* Notch于5月18日发布的展示0.0.12a的视频实际上是其从未向公众发布的[开发版本](/开发.md)。
* 为了使水和熔岩看起来矮于其他方块，其纹理在中被削减了一点。这也使得纹理会在某些角度上与方块重叠。
* 启动器提供的[0.0.13a](Java版Classic 0.0.13a.md)的文件中包含了地形生成文件，其也是0.0.12a的公开发布版本（包括[0.0.12a_01](Java版Classic 0.0.12a 01.md)-[03](Java版Classic 0.0.12a 03.md)）中的地形生成文件。其中有选项可以控制水是否能从世界外传播到世界内，生成均匀的泥土层和允许方块生成在海平面等。这在公开发布的0.0.12a中被禁用（至少在[0.0.12a_03](Java版Classic 0.0.12a 03.md)中确定不可使用）。
