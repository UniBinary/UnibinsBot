# 启动器2.3.200

*页面ID: 96310* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.3.200**是一次[启动器](启动器.md)更新，发布于2022年5月24日。

# 更改
* 做了一些幕后的稳定性改进。

# 修复
* 在修复用户权利和离线模式/超时的问题上做了更多工作。
* 修复了各种其他漏洞、访问和用户与数据方面的问题。
*  - 加载图标的背景大小与加载图标本身大小一致，而不是覆盖整个窗口。
*  - 无网络连接时，“有什么新内容”页面为空白页。
*  - 启动22w19a及以上版本会出现报错信息。
