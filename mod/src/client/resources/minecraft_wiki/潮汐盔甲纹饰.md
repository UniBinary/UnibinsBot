# 潮汐盔甲纹饰

*页面ID: 157467* | *来源: Minecraft Wiki*

* *潮汐盔甲纹饰（Tide Armor Trim）**是一种[盔甲纹饰锻造模板](盔甲纹饰锻造模板.md)，可使用[海晶石](海晶石.md)、复制自身。

# 获取
# = 生物掉落物 =
[远古守卫者](远古守卫者.md)死亡时有20%的概率掉落1个潮汐盔甲纹饰，不受[抢夺](抢夺.md)魔咒影响。

# = 合成 =
尽管潮汐盔甲纹饰本身不能合成获得，但可以利用特定的合成配方来复制自身。

|foot=1
}}

# 用途
潮汐盔甲纹饰可在锻造台上与[盔甲](盔甲.md)和锻造原材料相结合，给盔甲添加纹饰。
