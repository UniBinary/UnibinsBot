# 情人节披风

*页面ID: 186281* | *来源: Minecraft Wiki*

* *情人节披风（Valentine Cape）**是赠送给两名玩家的个人披风。

# 描述
这件披风是由Mojang员工Ekkelangelo赠送给LolFoxy2的，Ekkelangelo帮助LolFoxy2解决了备用账户的迁移问题。<ref></ref><ref>https://i.imgur.com/ZgROuy8.png</ref>但二十分钟后被迅速移除。

它也被赠送给了玩家JoinGrave，可能是出于意外，随后在两天后被移除。<ref></ref>
