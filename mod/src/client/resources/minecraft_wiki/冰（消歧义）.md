# 冰（消歧义）

*页面ID: 28976* | *来源: Minecraft Wiki*

* *冰（Ice）**可以指：

# 方块
*  - 在[冻河](冻河.md)等生物群系自然生成的半透明方块，融化后变成[水](水.md)源。
*  - 冰的变种之一，它不会融化，自然生成在[冰刺之地](冰刺之地.md)等生物群系。
*  - 冰的变种之一，与浮冰相似，同样不会融化，会自然生成在[冻洋](冻洋.md)生物群系。
*  - 冰的变种之一，由玩家穿上具有[冰霜行者](冰霜行者.md)魔咒的[靴子](靴子.md)并在水上行走时生成的方块。

# 物品
*  - 一种掷出后会使落点附近的水结冰的物品。

# 地物
*  - 由浮冰和蓝冰组成的地物，生成于冻洋和冰冻深海的海面上。
*  - 由浮冰构成的高大的尖-{}-刺状地物，生成于冰刺之地。
*  - 生成于冰刺之地的类似圆盘图案的方块聚合体地物。
*  - 由浮冰和蓝冰堆叠而成的地物，生成于雪原村庄。
*  - 由蓝冰组成的地物，只会生成在冰山地形特征的水下部分，依附在构成冰山的浮冰上。
*  - 由雪和冰组成的地物。

# 地形特征
*  - 由浮冰组成的地形特征，生成于冻洋和冰冻深海的海面上，不会生成蓝冰。

# 标签
*  - 一个方块标签。
