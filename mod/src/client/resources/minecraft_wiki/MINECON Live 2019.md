# 生物群系投票
[缩略图|生物群系投票中的三个选项：沼泽、恶地和山地](File:Minecon 2019 biome vote image.png.md)
[缩略图|生物群系投票投票的logo](File:Biome vote logo.png.md)

直播期间，观众可以为三个待更新的[生物群系](生物群系.md)之一进行投票。得票最多的生物群系将在下次大型更新中获得全新的特性，如地形的更改和加入新的[生物](生物.md)。根据投票结果，山地生物群系将最早进行更新<ref name="final_poll"></ref>，包括改进地形生成机制，加入山羊和“更像雪的雪”<ref></ref>。其余两个生物群系则也会获得新特性，但会在之后的更新中到来。<ref></ref>

# = 恶地 =
计划加入风滚草、秃鹫和一种新的仙人掌。恶地在投票第一回合中被淘汰，将成为三个选项中最后一个被更新的生物群系。和热带草原与沙漠一样，目前没有更多关于该群系更新的消息。<ref name="first"></ref>

# = 沼泽 =
计划加入[运输船](运输船.md)、[青蛙](青蛙.md)和[红树](红树.md)。<ref></ref>沼泽在投票最终回合当中被淘汰，将成为三个选项当中第二个被更新的生物群系。<ref name="final_poll"/>之后的[Minecraft Live 2021](Minecraft Live 2021.md)宣布，沼泽将在[荒野更新](荒野更新.md)中更新。

# = 山地 =
计划加入[山羊](山羊.md)和[可陷入的雪](细雪.md)，并改进[山地](山地.md)的地形生成。山地在投票最终回合当中胜出，已率先在[洞穴与山崖](洞穴与山崖.md)中更新。<ref name="final_poll"/>
