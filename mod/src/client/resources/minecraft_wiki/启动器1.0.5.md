# 启动器1.0.5

*页面ID: 49336* | *来源: Minecraft Wiki*

* *1.0.5**是一个2013年7月1日发布的[启动器](启动器.md)版本。

# 新内容
* 在配置文件编辑中添加了“快照”设置，以启用/禁用快照。

# 修复
*  - 启动器软件属性中的发行商一栏缺少数字签名。
