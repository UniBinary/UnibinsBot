# 教育版1.19.50.0

*页面ID: 100336* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.19.50.0**是[教育版1.19.52](教育版1.19.52.md)的首个开发版本，发布于2022年12月1日<ref></ref>，基于[基岩版1.19.50](基岩版1.19.50.md)，加入了[荒野更新](荒野更新.md)的特性。

# 新内容

* 加入了[荒野更新](荒野更新.md)的特性。

# = 常规 =
* *游戏库**
* 加入了“Computer Science”文件夹。

# 更改
# = 常规 =
* *验证库**
* 用于微软账户登录的验证库由Azure Active Directory Authentication Library（ADAL）切换至Microsoft Authentication Library（MSAL）。

* *游戏库**
* 优化了按功能标签搜索的功能以及更好的非英语搜索功能等。<!-- Improved Search featuring tag search, better non-English searching, and more! -->

* *用户体验**
* 提升了在游玩过程中使用提示框和控制提示的体验，使其用起来更方便。

* *最低配置**
* 更改了最低配置，新的如下：
* * macOS Big Sur（11.0）
* * Windows 8.1
* * iOS 11</onlyinclude>
