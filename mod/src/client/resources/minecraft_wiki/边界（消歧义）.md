# Minecraft
# = 方块 =
*  - 基岩版在[旧世界类型](旧世界类型.md)世界周围生成的方块。
*  - 教育版和基岩版独有方块。

# = 命令 =
* [命令/worldborder](命令/worldborder.md) - 调整Java版世界边界的命令。

# = 其他 =
* [世界界限](世界界限.md) - 可游玩世界的硬性界限。
* [世界边界](世界边界.md) - 可以改变的世界的边界。
* [边境之地](边境之地.md) - Java版Beta 1.8之前和基岩版1.17.20.20之前中离出生点很远的地方生成的，会发生严重卡顿和地形极度扭曲的地方。
