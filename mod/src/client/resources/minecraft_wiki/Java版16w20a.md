# Java版16w20a

*页面ID: 21416* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w20a**是[Java版1.10](Java版1.10.md)的首个快照，发布于2016年5月18日<ref name="blogpost_16w20a"></ref>，加入了首批[霜炙更新](霜炙更新.md)的内容，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[结构空位](结构空位.md)**
* 在结构方块将方块留在原地而不被空气替代时使用。
* * 用来替代[屏障](屏障.md)的功能（在早期版本中曾使用），意味着现在可以在结构中使用屏障。
* 不可见，碰撞箱很小。
* * 仅在使用保存型[结构方块](结构方块.md)且选项“Show invisible blocks”（显示隐形方块）为开时可见。
* 允许在结构中预留空位。
* * 与空气不同，它不会在加载时覆盖原有的方块。
* * 示例：如果玩家保存一个两格高的空气结构，并在下面那格放置一个结构空位，之后把这个结构加载到一个两格高的石头中，底部的石头将会保持不变，而顶部的石头会被替换成空气。

* *[岩浆块](岩浆块.md)**
* 在下界生成。
* 会自然发出2级的亮度。
* 用4个[岩浆膏](岩浆膏.md)合成。
* 与仙人掌类似，站在上方的生物会持续受到的伤害。
* 潜行的、装备冰霜行者魔咒的盔甲或拥有抗火效果的生物不受伤害。
* 接收到[随机刻](随机刻.md)时会移除顶部水源。
* 传递方块光源的亮度。<ref></ref>

* *[下界疣块](下界疣块.md)**
* 使用3×3的下界疣合成。

* *[红色下界砖块](红色下界砖块.md)**
* 使用2个[下界砖](下界砖.md)和2个[下界疣](下界疣.md)相互交叉摆放合成。

* *[骨块](骨块.md)**
* 使用3×3的[骨粉](骨粉.md)合成。
* 可以分解成9个骨粉。
* 可在沙漠和沼泽生物群系的地下找到。

# = 生物 =
* *[北极熊](北极熊.md)**
* 成年北极熊和幼崽会随机生成于寒冷生物群系。
* 被攻击后，成年北极熊会反击，幼崽则会逃走。
* * 此外，成年北极熊在幼崽周围时会攻击玩家。
* * 成年北极熊在水中可以比玩家游得更快。
* 鱼和鲑鱼的掉落概率比为3比1。

* *[流浪者](流浪者.md)**
* 行为与普通骷髅相似。
* 掉落物与骷髅相同，但有的概率掉落0–1支[迟缓](迟缓.md)之箭。
* 即为NBT标签设为2的骷髅。
* 在寒冷生物群系中生成（例如冰刺之地）。
* * 在寒冷生物群系中的蜘蛛也有概率被流浪者骑乘。
* 向攻击目标射击迟缓之箭（0:30）。
* * 可以弹回这些箭，使流浪者被自己的效果影响。

* *[尸壳](尸壳.md)**
* 行为与普通僵尸相似。
* 不会在太阳下燃烧。
* 即为NBT标签设为6的僵尸。
* 在温暖生物群系中生成（例如沙漠）。
* 可能会以幼年僵尸或鸡骑士生成。
* 在攻击时会赋予饥饿效果，简单难度为6秒，普通为13秒，困难为20秒。
* 比僵尸高2像素。

# = 世界生成 =
* *[化石](化石.md)**
* 在沙漠、沙漠山丘、沙漠M、沼泽与沼泽M生物群系中，每个区块有的概率生成包含15–24个方块的化石。
* 由煤矿石与骨块组成。
* 文件可以在中的文件夹中找到，在将这些文件放进世界文件夹时只能通过结构方块加载。
* * 最简单的方法是用特殊名称保存新结构，并在设备中搜索这个名称。再将结构放进同一个文件夹并加载。
* 头颅有4种变种，脊椎骨的片段也有4种。

# 更改
# = 方块 =
* *[结构方块](结构方块.md)**
* 现在不同的模式有了各自新的纹理。
* 现在拥有物品形式了，可以被给予或者生成。（只能在创造模式下使用）
* 现在有了可用且易用的GUI。这对地图制作中大有所益。
* 结构可以在每个世界中被附带、存储以及读取在文件夹中。
* 结构在每个方向上有32格的大小限制。使用相对坐标。
* 是命令方块放置结构的一种形式。
* 4种模式：
* * D，数据 — 用于给予箱子或者其他需要数据的方块以数据（默认）
* * S，存储 — 在世界中建造结构后，在方块中选定好结构的位置并将其存储为文件形式。
* * L，读取 — 读取已经存储的结构文件，替换除了屏障方块以外的所有方块。
* * C，角落 — 用于自动计算结构大小。
* 会在结构的外部用白线框出其相应的位置。
* 可以旋转以及镜像方块。
* 存储和读取模式的结构方块可以被红石激活。
* 只有拥有管理员权限的创造模式玩家可以直接放置、破坏以及使用结构方块。
* 放置结构多数情况下比命令要快捷。
* 可以保存任意数量的数据到磁盘的保护之下。
* 存储实体的工作尚未完工。
* 在选择区域内是可以显示红蓝两种小型的方块的。
* * 蓝色代表空气方块，红色代表结构空间方块。
* 在结构方块上会有一个包含模式以及结构名字的姓名标签显示。

* *[末地石砖](末地石砖.md)**
* 不再能被合成。

# = 物品 =

* *[末影人](末影人.md)**
* 在下界中偶尔生成，生成率是（相比岩浆怪为；僵尸猪人是；恶魂为）。

* *[岩浆怪](岩浆怪.md)**

# = 世界生成 =
* *[平原](平原.md)和[向日葵草原](向日葵草原.md)**
* 现在会生成一些树木（5%的区块），为大型橡木，为普通橡木。

* *[冰原](冰原.md)、[雪山](雪山.md)和[冰刺之地](冰刺之地.md)**
* 被动生物在世界生成时生成概率减少（10%降至7%）。

* *[恶地](生物群系#恶地.md)及其全部变种**
* 如果恶地海拔高度超过15，则[硬化黏土](硬化黏土.md)和[染色黏土](染色黏土.md)的生成深度不再超过15格。
* 在Y=32下方生成2处[金矿石](金矿石.md)矿脉外，还会尝试在Y=32与Y=79之间生成20处。
* 在地面上生成[废弃矿井](废弃矿井.md)。
* * 与深色橡木一起生成。

* *[村庄](村庄.md)**
* 现在会在更多的生物群系中生成并会使用相对应的木头种类生成（例如针叶林中生成云杉木，热带草原中生成金合欢木）。
* 草径会代替沙砾生成。
* 现会在水面上生成木板来形成桥梁。
* 热带草原的村庄几乎皆为木质结构，并可能因为铁匠铺内的熔岩而全被烧毁。
* 有2%的概率以废弃村庄生成。

* *[巨型蘑菇](巨型蘑菇.md)**
* 在黑森林中生成的巨型蘑菇可以长到与基岩版相同的更高的高度。

* *[区块](区块.md)**
* 现在可以按下来显示区块的边界。
