* *小火球（Small Fireball）**是由[烈焰人](烈焰人.md)发射或由[发射器](发射器.md)使用[火焰弹](火焰弹.md)发射的[弹射物](弹射物.md)。

# 生成
[烈焰人](烈焰人.md)会向其攻击目标发射小火球。

[发射器](发射器.md)使用[火焰弹](火焰弹.md)时会向其面向的方向发射小火球。

# 行为
小火球拥有不受重力影响的无限远的直线弹道，但会在1分钟后消失。

与[火球](火球.md)不同，小火球的弹道不能被偏转。

[盾牌](盾牌.md)可以阻挡其有效角度内来袭的小火球。

由[烈焰人](烈焰人.md)或[发射器](发射器.md)发射的小火球具有加速度。

# = 造成伤害 =
小火球在直接击中实体时，会对其造成伤害，并设置实体的剩余着火时间为。

小火球命中实体造成的伤害同时属于弹射物伤害和火焰伤害，并同时受到[弹射物保护](弹射物保护.md)和[火焰保护](火焰保护.md)的减免，也会被[抗火](抗火.md)效果无效化。

# = 着火 =
小火球默认是着火的。小火球始终是[着火](着火.md)的，穿过[雨](雨.md)或[水](水.md)时会保持着火，即使修改其实体数据<code>Fire</code>也不能将其熄灭。

小火球会不受阻碍地穿过并点燃[TNT](TNT.md)，可以点燃熄灭的[营火](营火.md)，可以破坏其穿过的[细雪](细雪.md)，会在击中的位置生成[火](火.md)。

# = 与方块交互 =
小火球可以触发其击中的[标靶](标靶.md)，可以敲响[钟](钟.md)。

小火球可以激活[木质压力板](木质压力板.md)。小火球可以触发[绊线](绊线.md)和[探测铁轨](探测铁轨.md)（探测铁轨需要使用[比较器更新感应器](Tutorial:比较器更新感应器.md)检测）。当小火球穿过这些方块时，这些开关会保持开启状态。其他开关则不受小火球的影响。由于小火球不能像[箭](箭.md)或[三叉戟](三叉戟.md)一样插在方块上，通常很难令其保持一个开关的长时间开启。通过命令生成的静止不动的小火球会一直保持其位置的开关开启。
