# 木炭

* *木炭（Charcoal）**是一种燃料[物品](物品.md)，有时可作为[煤炭](煤炭.md)的替代品。

# 获取
# = 烧炼 =

# = 营火 =
未使用附有[精准采集](精准采集.md)的工具破坏[营火](营火.md)会掉落2个木炭。

# = 化合 =

木炭可以由它的基本[元素](元素.md)通过[化合物创建器](化合物创建器.md)合成。

# 用途
# = 合成材料 =

# = 燃料 =
木炭能作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)使用，一个木炭可烧炼80秒（8个物品）。

# = 实验台 =

木炭是在[实验台](实验台.md)上合成[加热块](加热块.md)的原料之一。

# = 动力矿车 =

对[动力矿车](动力矿车.md)木炭可为其增加的行进时间，如果增加后会达到则不再增加。
