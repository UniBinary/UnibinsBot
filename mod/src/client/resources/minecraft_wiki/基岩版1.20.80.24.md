# 基岩版1.20.80.24

*页面ID: 115083* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.80.24**（ChromeOS/Android）、**Preview 1.20.80.24**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.20.80](基岩版1.20.80.md)的第5个测试版，发布于2024年3月27日<ref></ref>，修复了一些漏洞。

# 更改
# = 技术性 =
* *方块**
* 修复了拥有不正确的纹理UV的问题。

* *实体组件**
* 执行的实体传送至其主人所在位置时不再会出现互相卡住的情况。

# 修复
* *性能与稳定性**
* 修复了在创建新的世界和编辑世界屏幕中激活资源包时发生的崩溃。</onlyinclude>
