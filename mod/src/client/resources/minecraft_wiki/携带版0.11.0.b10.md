# 携带版0.11.0.b10

*页面ID: 27888* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 10**是[v0.11.0 alpha](携带版0.11.0.md)的第10个测试版，发布于2015年5月11日，修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[皮肤包](皮肤包.md)**
* 城市人皮肤包。
* 城镇居民皮肤包。

# 更改
# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 增加了创造模式交互距离。

# = 常规 =
* *[控制](控制.md)**
* 现在第三人称模式启用时只能与玩家前方的物体交互。

# 修复

* *其他漏洞**
* 客户端连接至多人游戏时使得OP被传送。
* 快捷栏向左偏移。
* 服务器内的玩家会受到击退影响。
* 玩家会被钓鱼竿拉动。
* 聊天，药水效果和类似的按钮只会在点击时打开（而不是拖拽）。
* 增加了在峭壁变种生物群系内容的沙砾数量。
* 世界打开错误现在会被写入日志文件里（以供日后修复漏洞）。</onlyinclude>
