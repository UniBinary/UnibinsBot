* *双持（Dual Wield）**是一个能让玩家的两只手同时持有[物品](物品.md)或[方块](方块.md)的游戏机制。

# 使用
[缩略图|在物品栏中高亮的为副手栏](File:OffhandSlotHighlighted.png.md)

玩家可以如同装备[盔甲](盔甲.md)那样在[物品栏](物品栏.md)中将物品装备到 副手栏上。玩家同时也可以在选择物品后按下键来自动装备。副手栏将出现在[HUD](HUD.md)的副手侧。如果玩家处于第一人称视角，那么副手会握着所持物品出现在屏幕中。哪只手为主手可以在选项中的[](选项#skinCustomisation.md)中调整。

<!--副手可以在以下情况下其所持的物品：主手没有持有物品，主手不能使用所持物品（如[剑](剑.md)），或是主手此时不能放置其所持方块（在未对着平面时拿着方块）。任何在主手的物品都比副手的拥有更高的优先级，因此只要主手的物品是可使用的（如钓鱼竿），那么不管副手有什么右击都将把钓鱼线甩出去。玩家也无法使用副手来或方块，即使主手没有持有物品。-->
当主手不能使用/放置所持物品（如[剑](剑.md)、[镐](镐.md)或空手，没有对准[草方块](草方块.md)时的[锹](锹.md)或[锄](锄.md)；试图对着空气放方块，在已播种的[耕地](耕地.md)里放置[种子](种子.md)等），键可以使用副手其所持的物品。除当主手持[斧](斧.md)副手持盾时优先使用盾牌而不是斧。其他情况下，任何在主手的物品都比副手的拥有更高的优先级。玩家也无法使用副手来方块，即使主手没有持有物品。

# = 战斗 =
放置于副手中的[箭](箭.md)会比快捷栏或物品栏中的箭更优先被使用。玩家可以将特定的箭装备在副手中并使用[弓](弓.md)来将其发射出去。如果弓处于副手位置，那么在快捷栏中被选中（即被主手持有）的箭将会被优先使用。[盾牌](盾牌.md)被放置在副手中时可以被，使用时可起到防御的功效。若持弩时副手持有烟花火箭，则在装填弩时会装填上烟花火箭。

无论玩家以何种方式击杀[生物](生物.md)，只要伤害发生时[主手](主手.md)持有带[抢夺](抢夺.md)魔咒的[武器](武器.md)，掉落物都受抢夺魔咒影响。利用此特性，你可以将带有抢夺的武器放在主手并用副手的[弓](弓.md)、[弩](弩.md)或[三叉戟](三叉戟.md)进行攻击，或在用主手使用上述三种远程武器后迅速切换到带有抢夺的武器，来增加掉落物获取。

# = 使用工具 =
当玩家使用键将工具放在副手上并且在快捷栏上也选择了工具或武器，对一个方块按下时，副手中的工具可以在该方块上使用，则会使用副手中的工具，除非在快捷栏中的工具或武器也能在该方块上使用。如果是后面的那种情况，则会使用快捷栏中的工具或武器。

当烟花火箭在副手上且正被弩使用时，按下键进行装填，并且在准备完成时再次按下键发射烟花火箭。烟花火箭只有在副手上时才能被弩发射出去。

# = 基岩版 =
玩家只能将少数特定物品放入副手栏进行双持。其中一些为战斗用品，如[箭](箭.md)、[药箭](药箭.md)、[烟花火箭](烟花火箭.md)、[盾牌](盾牌.md)和[不死图腾](不死图腾.md)；另一些是探险道具，如[地图](地图.md)和[探险家地图](探险家地图.md)；还有一些为特殊物品，如[烟花棒](烟花棒.md)和[鹦鹉螺壳](鹦鹉螺壳.md)。然而副手栏的[烟花火箭](烟花火箭.md)并不能加速[鞘翅](鞘翅.md)飞行。玩家可以使用命令来设定副手栏物品，所有物品都可以通过命令放入副手栏，且部分物品可以进行交互，通过按下键实现。但在第一人称下，左手持有的部分方块的模型尚未匹配右手持有方块的模型。
