* *苹果（Apple）**是一种[食物](食物.md)类[物品](物品.md)。

# 获取
# = 树叶 =
没有被[剪刀](剪刀.md)或具有[精准采集](精准采集.md)的工具挖掘破坏，或者自然枯萎时，[橡树树叶](橡树树叶.md)和[深色橡树树叶](深色橡树树叶.md)有0.5%（）的概率掉落一个苹果。使用带有[时运](时运.md)魔咒的工具破坏树叶会增加掉落苹果的概率：时运I是0.556%（），时运II是0.625%（），时运III是0.833%（）。

# 用途
# = 食物 =

手持苹果按住键即可食用，每个苹果可以恢复。

玩家在[饥饿值](饥饿值.md)为满的状态下也可以食用苹果。<ref></ref>

# = 马、驴、骡 =
苹果能治疗[马](马.md)、[驴](驴.md)、[骡](骡.md)生命值、提高3%驯服概率和加速60秒幼年马、幼年驴、幼年骡的成长速度。

# = 合成材料 =

# = 堆肥 =
将苹果放入[堆肥桶](堆肥桶.md)中有65%的概率增加一层堆肥层。
