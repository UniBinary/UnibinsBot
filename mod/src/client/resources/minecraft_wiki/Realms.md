# Realms

*页面ID: 9897* | *来源: Minecraft Wiki*

}}

* *Minecraft Realms**是官方的订阅式[服务器](服务器.md)托管服务。玩家可以创建并管理自己的Minecraft私人服务器。[Mojang](Mojang.md)运营的Realms是简单快捷创建服务器的方式，还可以提供在游戏内管理服务器的方式，也无需服务器主人预先了解互联网运营的知识。Realms还提供玩家暂时将服务器转为小游戏服务器的服务，转换的目标也可以是预制世界模板、冒险地图、游玩地图、灵感地图等。地图由Mojang大约每两周更新一次。Realms并非为大型公共服务器准备，主要受众为家庭或朋友的小团体。<ref></ref>

# 要求
Realms的服务只向符合下列条件的玩家开放<ref></ref>：

* 有Microsoft账号并已购买[Java版](Java版.md)。
* 有稳定的网络连接。
* 年龄在13岁以上。

# 订阅
[300px|缩略图|游戏内的订阅界面，在配置菜单中](File:Realms Subscriptions.png.md)
玩家可在[官网](https://www.minecraft.net/profile/realms/select-plan)管理Realms订阅。

Realms是订阅制服务。上方的链接指向Minecraft账号页面，可以在此续订当前的Realms或购买新的Realms。<ref name=RealmsComputer>https://www.minecraft.net/realms-for-java/plans</ref>

定价方面，Java版Realms单价为每月USD$7.99或HKD$62。若在付款时选择中国大陆地区，则会提示“无法购买”。

Realms订阅仅提供自动续费方案。自订阅开始日起算，每30天自动从已选择的付款方式扣款，无需手动操作。<ref name="RealmsComputer" />

所有玩家都有30日的免费Realms试用，只要之前在Minecraft账号上没有使用过此机会。<ref name="RealmsComputer" />

# 用法

# 地图
Java版的Realms服务中，玩家可以选择暂时用小游戏或者下列类型的地图替换现有地图：世界模板、冒险、体验或示例地图。运行小游戏时，大多数的命令或选项仍然可用。这些地图都由Realms团队从社区中选出。有些地图可能在Realms上已不可选，原因可能是过期或不适合现有版本。这些地图仅适用于Java版。

# = 小游戏 =
小游戏用于游玩并可以重置。

# = 灵感地图 =
灵感地图的出现是为了鼓励人们在Minecraft中建立新的事物。这些地图旨在鼓励玩家尝试令人兴奋的新事物。

# 局限
虽然Realms由Mojang运营保证了安全性，但也有局限之处。下列限制可以由其他普通的服务器运行软件或第三方托管网站解决：

* 强制白名单，同时游玩的最高玩家数为10名，且不能扩充；
* 玩家不能在游戏内被进行邀请、请出或更改权限的操作——必须退出游戏才能完成；
* 小游戏激活时，所有玩家（包括主人）都没有管理权限；
* 旧版本的游戏中不能使用Realms；
* 玩家会因为不活动被踢出服务器；
* 服务器会在午夜重置；
* 16岁以下的用户需要经家长的同意才可以在Realms上游玩。
