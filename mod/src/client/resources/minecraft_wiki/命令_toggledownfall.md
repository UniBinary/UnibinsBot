# 命令/toggledownfall

*页面ID: 39832* | *来源: Minecraft Wiki*

切换[天气](天气.md)。若当前天气为晴天，则切换为降雨；若当前天气为降雨或雷暴，则切换为晴天。

# 语法
   <code>toggledownfall</code>

# 结果
永远执行成功。
