# 耕地

*页面ID: 7818* | *来源: Minecraft Wiki*

* *耕地（Farmland）**是一种可以用来种植与生长[农作物](农作物.md)的[方块](方块.md)。

# 生成
# = 自然生成 =
耕地自然生成在[村庄](村庄.md)的[农田](农田.md)里，其上方种着[小麦植株](小麦植株.md)、[马铃薯](马铃薯.md)、[胡萝卜](胡萝卜.md)、[甜菜植株](甜菜植株.md)、[南瓜茎](南瓜茎.md)或[西瓜茎](西瓜茎.md)。

耕地也自然生成在[林地府邸](林地府邸.md)的“[小麦农场](林地府邸/结构/农场#小麦农场.md)”和“[瓜房](林地府邸/结构/农场#瓜房.md)”两种房间里。

# = 锄 =
对着[泥土](泥土.md)、[草方块](草方块.md)或[土径](土径.md)[锄](锄.md)可将其犁成耕地。

# 获取

耕地无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，耕地可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
挖掘耕地的合适工具是锹。

耕地被破坏后会掉落1个[泥土](泥土.md)。

# 用途
耕地是游戏中一些[农作物](农作物.md)生长所必需的方块，这些农作物有[小麦植株](小麦植株.md)、[马铃薯](马铃薯.md)、[胡萝卜](胡萝卜.md)、[甜菜植株](甜菜植株.md)、[南瓜茎](南瓜茎.md)、[西瓜茎](西瓜茎.md)、[火把花植株](火把花植株.md)和[瓶子草植株](瓶子草植株.md)。

除此以外，一些植物也能种植在耕地上面，包括[树苗](树苗.md)、[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)、[蕨](蕨.md)、[大型蕨](大型蕨.md)、[花](花.md)、[甜浆果](甜浆果.md)、[大型垂滴叶](大型垂滴叶.md)、[杜鹃花丛](杜鹃花丛.md)、[盛开的杜鹃花丛](盛开的杜鹃花丛.md)、、[灌木丛](灌木丛.md)、[萤火虫灌木丛](萤火虫灌木丛.md)、[粉红色花簇](粉红色花簇.md)和[野花簇](野花簇.md)。

[小型垂滴叶](小型垂滴叶.md)只有在至少1格深的[水源](水源.md)中才可种植在耕地上。

在2×2的树苗中，若西北方的一棵被种在耕地里，则所有树苗都不会生长。

2×2的云杉和丛林树苗若西北方的一棵被种在耕地里，则所有树苗都不会生长。

# = 湿润耕地 =
[250px|thumb|湿润耕地的所需条件](File:Farmland Hydration.png.md)
用锄转化或玩家放置的耕地方块开始都是干燥的，没有湿润且上方没有种植作物时，耕地方块会在一段时间后重新退化成泥土。

耕地的湿润程度由范围是0-7的“湿润值”（对应方块状态|je}}或|be}}）决定。“湿润值”达到最大值7时，耕地会进入湿润状态；为最小值0且仍可以降低，并且上方没有种植作物时，耕地将会退化成泥土。

要让耕地湿润，必须满足且保持以下条件之一：
* 自身或高一格平面内、以自身为中心的9×9范围内需要存在至少一个[水](水.md)（水源或水流）或[含水](含水.md)方块。
* 当前生物群系正在[降雨](降雨.md)，[降雪](降雪.md)无法使耕地湿润。

满足上述条件的耕地将在接受到随机刻后，使自身“湿润值”直接变为7，即进入湿润状态；否则会逐渐减少。耕地湿润的过程不受其他因素影响。耕地和水之间即使有方块阻挡也不会影响湿润过程。单个水方块最多能湿润周围9×9范围的耕地。

不同类型的[种子](种子.md)在湿润的耕地的生长速度更快。湿润的耕地能使[小麦植株](小麦植株.md)在比一个[昼夜更替](昼夜更替.md)多一点点的时间内完全成熟。

# = 退化 =
满足以下条件之一时，耕地会退化成泥土：
* 耕地方块完全干涸（“湿润值”为0），且接收到下一个随机刻时上方没有种植[作物](作物.md)。
* 碰撞箱体积大于0.512的生物（如[玩家](玩家.md)）[摔落](摔落.md)到耕地上时，耕地有<math>f-0.5</math>的概率退化，其中<math>f</math>为下落高度，如果摔落高度小于等于0.5格则不会退化，大于1.5格则必定退化。
* * 碰撞箱体积小于或等于0.512，因此即使摔落也不会导致耕地退化的生物有[美西螈](美西螈.md)、[烈焰人](烈焰人.md)、[猫](猫.md)、[洞穴蜘蛛](洞穴蜘蛛.md)、[鸡](鸡.md)、[鳕鱼](鳕鱼.md)、[海豚](海豚.md)、[末影螨](末影螨.md)、[狐狸](狐狸.md)、[青蛙](青蛙.md)、[发光鱿鱼](发光鱿鱼.md)、小型[岩浆怪](岩浆怪.md)、[豹猫](豹猫.md)、[鹦鹉](鹦鹉.md)、[河豚](河豚.md)、[兔子](兔子.md)、[鲑鱼](鲑鱼.md)、[蠹虫](蠹虫.md)、小型[史莱姆](史莱姆.md)、[雪傀儡](雪傀儡.md)、[蝌蚪](蝌蚪.md)、[鱿鱼](鱿鱼.md)、[热带鱼](热带鱼.md)、[狼](狼.md)以及各类幼年生物等。
* [固体方块](固体方块.md)覆盖在耕地方块的上方，比如南瓜或西瓜在上方长出，或。

当耕地退化时，在其上的作物会掉落为物品。

[劫掠兽](劫掠兽.md)在耕地上行走时不会破坏耕地，但会破坏其上的作物或任何植物。

# = 转变 =
[杜鹃树](杜鹃树.md)长成后会将其下方的耕地转变为[缠根泥土](缠根泥土.md)。

[大型云杉](大型云杉.md)长成后会将其下方的耕地转变为[灰化土](灰化土.md)。

# 你知道吗
* 一个水源方块最多可以向水平各个方向流淌7个方块。从水源方块中流出来的水湿润耕地的行为与水源方块湿润耕地的行为相同。正因如此，如果高效利用水源方块，存在利用一个水源方块湿润23×23甚至更大面积耕地的可能性。水也可以往下流，如果在最大建筑高度，仅竖直往下流就可以湿润384÷2×（9×9-1）格，也就是15360格耕地。
