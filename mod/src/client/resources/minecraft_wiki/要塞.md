# 要塞

*页面ID: 7825* | *来源: Minecraft Wiki*

* *要塞（Stronghold）**是一种可以用[末影之眼](末影之眼.md)定位的地下结构，其中一个房间含有[末地传送门](末地传送门.md)。

# 生成
[缩略图|200px|右|设有[[末地传送门框架](File:EndPortalRoom.png.md)和[蠹虫](蠹虫.md)刷怪笼的要塞]]
要塞主要生成在主世界地下，并且通常会尽量避开[海洋](海洋.md)及其变种、[沙滩](沙滩.md)及其变种、[沼泽](沼泽.md)及其变种和[深暗之域](深暗之域.md)生物群系生成，因此生成在水下是很少见的情况。要塞可能生成在基岩层，覆盖掉一些[基岩](基岩.md)。

要塞的很多部分都可能被洞穴、废弃矿井、化石或地牢所覆盖，但末地传送门很少被其他方块替换。峡谷不会覆盖要塞。

# = 基岩版 =
要塞会在距离世界原点至少160格的区域随机生成。与不同，中要塞的生成数量没有限制。此外还有3个额外的要塞会在距离世界原点至少453格的区域生成，它们的位置倾向于接近世界原点，且必然生成在[村庄](村庄.md)的会合点下方。

# = Java版 =
要塞在世界的分布图}}
每个世界里要塞有且只有128个，它们分布于一些指定圆环上的随机位置。每个环都具有一定的半径，其环心都位于这个世界的原点（即X=0，Z=0处），而不是世界出生点（出生点可能偏离原点数百格）。要塞的生成从入口的螺旋楼梯开始，所以要塞的入口一定位于环内；但要塞的其他部分可能会超出环的范围。每个环上的要塞大致上都是以均等角度分散的（例如，第一个环上的3个要塞与中心的连线大致两两间隔120度）。

要塞不会在地表生成，即使有一部分露出地面，那一部分也会被空气取代；而如果要塞罕见地生成在水下，它通常会生成一间“悬浮”的传送门房间。

要塞从中间的第一个环开始生成，然后在第二个环生成，然后在第三个环生成，以此类推，直到总数达到128。
* 第1圈包含3个要塞，位于距离原点1280-2816格处
* 第2圈包含6个要塞，位于距离原点4352-5888格处
* 第3圈包含10个要塞，位于距离原点7424-8960格处
* 第4圈包含15个要塞，位于距离原点10496-12032格处
* 第5圈包含21个要塞，位于距离原点13568-15104格处
* 第6圈包含28个要塞，位于距离原点16640-18176格处
* 第7圈包含36个要塞，位于距离原点19712-21248格处
* 第8圈包含9个要塞，位于距离原点22784-24320格处

# 结构

要塞大小不一，主要由[石砖](石砖.md)（45%）、[苔石砖](苔石砖.md)（30%）、[裂纹石砖](裂纹石砖.md)（20%）以及[虫蚀石砖](虫蚀石砖.md)（5%）构成的房间与门组成。要塞在生成时，没有虫蚀裂纹石砖和虫蚀苔石砖<ref></ref>。要塞里大部分区域有[火把](火把.md)提供照明，但火把的数量不足以防止敌对生物的生成。要塞内的楼梯由石砖、石砖楼梯、石砖台阶组成，没有苔石砖和苔石砖台阶<ref></ref>。

在要塞内的走廊与储藏室里可以找到分散的、拥有各种[战利品](箱子战利品.md)的箱子。

# = 房间 =
[200px|thumb|right|要塞内的一个图书馆](File:Stronghold Library.png.md)
要塞里有多种房间。每个房间都有一个入口，这个入口可能是一个简单的3×3开口，一个木门，或有[铁栏杆](铁栏杆.md)做成的“拱”装饰的1×2开口。房间也可能有通向其他房间的出口，或被石头堵塞的“死胡同”出口。如果生成的房间之间有空位或要塞被[洞穴](洞穴.md)、[废弃矿井](废弃矿井.md)、[地牢](地牢.md)或其他结构截断，这些房间可能会出现另外的“通道”。有时这些入口可能被石块封住，形成“秘密入口”。此种情况一般在5条通道交叉时发生。<ref>https://www.youtube.com/watch?v=E6xqXPpphb8?t=12m37s</ref>

要塞的生成始于一个螺旋楼梯，螺旋楼梯向下通往一个由5条通道交叉而成的路口，从该路口开始随机地向外延伸其他房间，最多可扩展至50个房间，水平跨度可达112格。如果传送门房间没有生成，整个要塞将重新生成。

* 传送门房间：包含[末地传送门](末地传送门.md)及一个生成[蠹虫](蠹虫.md)的[刷怪笼](刷怪笼.md)。房间入口处有两处3格大小的熔岩池，传送门下方还有一座更大的9格熔岩池。房间内有16扇窗户，均由2个[铁栏杆](铁栏杆.md)组成。一般而言，这个房间不能被周围生成的其他结构所覆盖。每个要塞只有一个传送门房间。每个末地传送门框架都有10%的概率已放有一颗末影之眼，这些框架的平均数量为1.2。所有框架均已事先填充好末影之眼的概率为万亿分之一（10<sup>-12</sup>）。
* 图书馆：木质结构的单层或双层大厅，里面有大量书架、木栅栏、梯子、吊灯和蜘蛛网。图书馆有分大小规模。小的图书馆通常包含[书架](书架.md)、[木](木板.md)地板和一个[箱子](箱子.md)，并且只有一层。大的图书馆则含有大量整齐排列的书架、木[栅栏](栅栏.md)、木板地板和[火把](火把.md)，而且在图书馆的下层之上生成一个有天台的二层。两层之间用[梯子](梯子.md)相连，梯子在与入口相对的墙面上，而且蜘蛛网不会在梯子处生成。二层包含由[橡木栅栏](橡木栅栏.md)包围的环形露台，以及天花板中央的由栅栏与[火把](火把.md)构成的枝形吊灯，与下层一样也有一个箱子。虽然图书馆的人工结构是整齐有序的，[蜘蛛网](蜘蛛网.md)却是散乱地出现的。每个要塞最多有两个图书馆，并且图书馆与要塞入口相距至少4个房间。
* 大房间：有3个出口（算上入口是4个）的房间，房间中央有各式的装饰。每个要塞最多生成6个大房间。
* * <!-- Type 3 or 4 -->空房间：没有装饰。
* * <!-- Type 0 --> 石柱房间：房间中央有一个石柱，柱上插有火把。
* * <!-- Type 1 --> 喷泉房间：房间中央有一个石砖搭建的池子，池子中间的石砖柱上有一个水源方块，组成一个喷泉。
* * <!-- Type 2 -->储藏室：双层房间，每层2格高，房间中央有一个[圆石](圆石.md)柱连接上下两层，旁边的墙上有通往二层的梯子。第二层的地板（也是第一层的天花板）由橡木木板组成，第二层有一个箱子和一个火把。
* <!-- SH5C -->五通道路口：有5个出口（算上入口是6个）：一条通道从入口通往下方至由石头台阶和石砖组成的短楼梯，一条通道通往左侧或右侧的入口，一条通道通往左上方由石头台阶和石砖组成的短楼梯，一条通道通往右上方的短楼梯。桥的一侧有一个火把。每个要塞最多有5条<!-- 4 random + the one generated from SHStart -->通道。一般有1至4条通道是被封住的。
* 空牢房：由全是铁栏杆的墙组成的走廊。牢房似乎总是成对出现在走廊中，而且它们具有特征——由铁栏杆做成的笼子和不具有[按钮](按钮.md)的铁门，不过它们里面是空的，没有囚犯。空牢房中不会生成铁门。
* <!-- SHSD, SHStart --> 螺旋楼梯：3×3的竖井，里面有石砖和石台阶做成的螺旋楼梯，底部有一个出口。每个要塞最多6个<!-- 5 random + SHStart -->螺旋楼梯。
* <!-- SHSSD --> 直楼梯：3格宽的楼梯，由圆石楼梯组成，下面有一个出口。楼梯最下面一级有个凹处。每个要塞最多5个直楼梯。
* <!-- SHS --> 走廊：空走廊，最多有3个出口：入口对面有1个出口，左右两侧可能有额外生成的出口。
* <!-- SHCC --> 箱子走廊：内含一个石台阶做成的祭坛，祭坛上放着一个箱子。入口对面有1个出口。每个要塞最多生成4个箱子走廊。
* <!-- SHLT, SHRT --> 拐角走廊：空走廊，有1个出口，或左或右。在入口和下一个房间入口均为橡木门时，拐角走廊看上去可能与小房间相似。
* <!-- SHFC --> 死胡同走廊：空走廊，没有出口（不过可能穿到别的房间形成出口）。这个结构的入口处不会有任何门或拱。

# 你知道吗
* 虽然要塞在生成时不会暴露于地表，但是顶部与地表相通的峡谷可能会使其暴露出来。
* 在要塞中，只有一般的石头方块可以自然生成虫蚀变种，苔石与裂石类的虫蚀方块不会生成。
* 要塞在[自选世界类型](自选世界类型.md)中，除了传送门房间外，其他房间的外墙会缺失，导致要塞外观变得破碎。
* 要塞初始生成的螺旋楼梯中轴总位于区块内的(4,4)处。
* 要塞中生成的门的朝向总是向着初始生成的螺旋楼梯。这可以用于判断玩家是在向内还是向外走。
* 已有项目找出了1.16版本下所有位于第一环内、拥有已激活末地传送门的要塞的种子。<ref>https://github.com/hube12/SSGOutput/releases/tag/1.1</ref>
* 由于要塞的加入时间早于[按钮](按钮.md)，因此基岩版中要塞的所有[门](门.md)都为木门，即使在按钮加入后也并未更改。
