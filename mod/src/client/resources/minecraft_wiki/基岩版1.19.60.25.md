# 基岩版1.19.60.25

*页面ID: 101046* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.60.25**（Android）、**Preview 1.19.60.25**（Xbox/Windows/iOS/iPadOS）是[基岩版1.19.60](基岩版1.19.60.md)的第5个测试版，发布于2023年1月5日<ref></ref>，修复了一些漏洞。

# 更改
# = 物品 =
* *末影龙和凋灵[刷怪蛋](刷怪蛋.md)**
* 从创造模式物品栏中移除，但仍然可通过命令获得。

# = 生物 =
* *[驴](驴.md)和[骡](骡.md)**
* 略微更改了鞍的纹理。

* *[猪灵](猪灵.md)**
* 现在再次能够在[下界](下界.md)亮度为0-10的区域生成。

* *[骷髅马](骷髅马.md)**
* 更改了鞍的纹理，以与其他马匹保持一致。

* *[僵尸马](僵尸马.md)**
* 更改了箱子的纹理，以与[骷髅马](骷髅马.md)保持一致。

# = 常规 =
* *[表情](表情.md)**
* 更新了UI。
* * 仅部分玩家可用。
* * 现在使用表情时聊天栏会出现一条消息。

* *[声音](声音.md)**
* 下列新音效不再属于[实验性玩法](实验性玩法.md)：
* * 下界木质方块的独特音效
* * 木质[按钮](按钮.md)的激活和取消激活音效
* * [门](门.md)、[拉杆](拉杆.md)、[活板门](活板门.md)和[栅栏门](栅栏门.md)的开关音效
* * [压力板](压力板.md)的激活音效和取消激活音效

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”、“即将推出的创作者功能”和“测试版 API”子选项后才可使用。
# = 方块 =
* *[音符盒](音符盒.md)**

# 修复
* *方块**
* 现在下界木质方块拥有其独特音效。

* *命令**
* 修复了使用命令将玩家传送至其他维度时可能出现的崩溃。（）
* 现在对没有分数的玩家执行unless) score|link=none}}时会返回。（）
* unless) score|link=none}}现在不再接受会返回多个实体的实体选择器（即、）。

* *常规**
* 现在在地上放置红石粉时会播放其正确音效。（）
* 现在使用时玩家会对速度改变作出正确反应。

* *物品**
* 从创造模式物品栏中移除了凋灵和末影龙刷怪蛋。

* *生物**
* 现在玩家可以通过选取方块键选择铁傀儡、雪傀儡、凋灵或末影龙来获得对应刷怪蛋。（）
* 现在猪灵可以重新在下界亮度大于7的区域生成。（）
* 现在当唤魔者骑乘在实体上时会播放其“坐下”动画。（）

* *粒子效果**
* 更改了文档，加入了有关新加入材质的信息，同时在示例资源包中加入了示例粒子。

* *性能与稳定性**
* 修复了使用组件时可能出现的崩溃。
* 修复了加载活动对象时可能出现的崩溃。
* 现在客户端的生成需要通过服务器授权，以防客户端生成非必要的区块。

* *触摸控制**
* 修复了在部分设备上按下打开物品栏按键时会错误地与世界交互的问题。
* 修复了当有一行信息处于屏幕之外时无法滚动页面的问题。
* 为重复合成加入了若干冷却间隔。
* 移除了玩家在十字准星模式下滑动攻击和建造按钮时所产生的相机位移延迟。
* 现在触控焦圈可以在非十字准星模式下的新版触摸控制中出现。

* *用户界面**
* 现在触摸设备上的弹窗提示可以在游戏中直接被划走。
* 现在触摸控制设置不再会在Xbox端显示。

* *原版趋同**
* 更改了部分方块的地图标识颜色以匹配。（）
* 更改了青蛙卵的地图标识颜色以匹配。（）
* 更改了床的地图标识颜色以匹配。（）
* 更改木门、铁门、木质活板门和铁活板门的开关音效以匹配。
* 更改了压力板的音效音高以匹配。
* 为木质按钮增加了独特的按下音效以匹配。</onlyinclude>
