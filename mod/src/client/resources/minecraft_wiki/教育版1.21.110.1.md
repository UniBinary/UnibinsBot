# 教育版1.21.110.1

*页面ID: 167631* | *来源: Minecraft Wiki*

<onlyinclude>

* *Preview 1.21.110.1**（Android/ChromeOS/Windows）、**beta 1.21.110.1**（macOS/Windows）、**beta 1.21.112.1**（iOS/iPadOS）是[教育版1.21.132](教育版1.21.132.md)的首个开发版本，在除iOS/iPadOS外的平台上发布于2025年10月1日<ref></ref>，在iOS/iPadOS平台上发布于2025年11月20日，加入了[铜器时代](铜器时代.md)的特性和专用服务器。

# 新内容

* 加入了[铜器时代](铜器时代.md)的特性。
* 加入了[音乐唱片Lava Chicken](音乐唱片Lava Chicken.md)。

# = 常规 =
* *专用服务器**
* 为加入了专用服务器。

# 更改
# = 常规 =
* *[代码构建器](代码构建器.md)**
* Python Notebooks不再是受支持的IDE。

# 修复
* 进一步优化了性能与游戏稳定性。</onlyinclude>
