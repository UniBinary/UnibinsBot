# Java版13w38a

*页面ID: 33622* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w38a**是[Java版1.7.2](Java版1.7.2.md)的第5个快照，发布于2013年9月19日<ref></ref>，加入了和新的成就，修改了地平线附近天空的亮度，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* *[命令](命令.md)**
* 加入了命令以自动踢出一定时间过后仍处于空闲状态的玩家。
* * 仅限多人游戏，只能由管理员使用。

* *[NBT](NBT.md)标签**
* 在数据文件夹里加入了<code><structure>.dat</code>文件以存储结构数据。
* * 包括的<code>.dat</code>文件有、（下界要塞）、（沙漠神殿、丛林神殿和女巫小屋）、等。
* * NBT结构由每个结构的各个部分组成，标有“children”，它起源于的区块，称为BB的标签，以及它是什么类型的结构的ID。
* ** 子标签有结构的每个部分的信息和部件的类型。

# = 游戏内容 =
* *[成就](成就/Java版.md)**
* 加入了成就“给你钻石！”，可以通过把钻石扔给其他玩家获得。

# = 常规 =
* *[亮度](亮度.md)**
* 当玩家在他们和天空之间有方块挡住时，地平线附近的天空现在变暗。
* * 玩家与天空之间的距离越大，天空越黑暗。

# 更改
# = 物品 =
* *[地图](地图.md)**
* 改进了[地图](地图.md)在[物品展示框](物品展示框.md)内的展示。

# = 生物 =
* *[僵尸](僵尸.md)**
* 减少了僵尸产生的延迟。

# = 常规 =
* *[成就](成就/Java版.md)**
* 改进了成就。
* * 当一个玩家获得一个成就时将会在聊天窗口内显示，此功能可以在中关闭。

* *[选项](选项.md)**
* 改进了视频设置。
* * 渲染距离现在是个范围为2至16个区块的滑动条。
* ** 现在在渲染距离为低（4个区块）时就能看见天空了。
* ** 区块能在设置为12外渲染了。
* * 最大帧数现在是个范围为10至250fps以及无限制的滑动条。
* * 加入了Mipmap技术、各向异性过滤技术和全屏抗锯齿技术（作为着色器）。
* ** Mipmap可以设置成关闭和1至4。
* ** 各向异性过滤可以设置成关闭和2、4、8、16。
* ** 全屏抗锯齿（着色器）可以被切换。
* * 它们现在在整个方块上显示。
* 改进了超级秘密选项。
* * 此按钮现在会应用各种不同的实验性[着色器](着色器.md)。
* * 目前可使用的着色器列表：反锯齿、去会聚、剪影、美术、饱和、铅笔、位元、翻转、荧光粉、斑点、快速近似抗锯齿、枕状扫描、斑点2、绿、边缘检测、模糊、倒置、摇晃、盘旋色、彩色电视。
