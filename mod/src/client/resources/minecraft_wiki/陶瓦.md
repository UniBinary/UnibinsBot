# 陶瓦

*页面ID: 10056* | *来源: Minecraft Wiki*

* *陶瓦（Terracotta）**是一种自然生成于恶地，可以通过烧炼[黏土](黏土.md)获得的方块。

# 生成
# = 自然生成 =
; 恶地
陶瓦会生成在[恶地](恶地.md)、[疏林恶地](疏林恶地.md)和[风蚀恶地](风蚀恶地.md)生物群系中。

; [村庄](村庄.md)
陶瓦生成于[平原](平原.md)村庄的石匠房屋，以及[热带草原](热带草原.md)与[沙漠](沙漠.md)村庄的某些房屋。

; 古迹废墟
陶瓦可以在[古迹废墟](古迹废墟.md)生成。

# 破坏
挖掘陶瓦的合适工具是镐。陶瓦需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

陶瓦被破坏后会掉落自身。

# 用途
# = 种植 =
[枯萎的灌木](枯萎的灌木.md)、[矮枯草丛](矮枯草丛.md)和[高枯草丛](高枯草丛.md)可以在陶瓦上面种植。
