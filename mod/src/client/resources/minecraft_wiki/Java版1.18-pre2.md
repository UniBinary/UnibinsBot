# Java版1.18-pre2

*页面ID: 90823* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.18-pre2**是[Java版1.18](Java版1.18.md)的第2个预发布版，发布于2021年11月16日<ref></ref>，把启动游戏所需Java版本从16提升至17，并修复了一些漏洞。

# 更改
# = 非生物实体 =
* *[矿车](矿车.md)**
* 移除了底部多余的棕色纹理。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 将“Now Java 16!”闪烁标语改为“Java 16 + 1 = 17!”。

* *Java版本**
* 现在启动游戏要求的最低Java版本为17。
