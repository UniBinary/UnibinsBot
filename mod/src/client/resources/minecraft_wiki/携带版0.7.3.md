# 携带版0.7.3

*页面ID: 21261* | *来源: Minecraft Wiki*

* *v0.7.3 alpha**是[携带版](携带版.md)的一次次要更新，发布于2013年8月15日<ref>http://web.archive.org/web/20130821065119/https://play.google.com/store/apps/details?id=com.mojang.minecraftpe</ref>，加入了[昼夜更替](昼夜更替.md)，并修复了[v0.7.2 alpha](携带版0.7.2.md)中的一些漏洞与崩溃。

# 新内容
# = 游戏内容 =
* *天空**
* 加入了[太阳](太阳.md)、[月亮](月亮.md)、[星星](星星.md)以及[日出和日落](昼夜更替.md)。

* *[标题界面](标题界面.md)**
* 改进了标题界面。

* *[闪烁标语](闪烁标语.md)**
* 加入了308条闪烁标语。

* *[全景图](全景图.md)**
* 加入了动态的全景图。
* * 菜单全景图使用了[Java版Beta 1.7.3](Java版Beta 1.7.3.md)中的种子，坐标为(61, 75, -68)。<ref></ref>

* *[Pocket Realms](Realms.md)**
* Realms可以重置了。

# = 方块和物品 =
* *[箱子](箱子.md)**
* 加入了大型箱子。
* * 当两个箱子合并时，原先在左侧箱子的物品会出现在下方，右边箱子的物品出现在上方。这可能导致物品损失。
* 现在箱子拥有开关动画。
* 玩家可以在创造模式中打开箱子，但不能看到其内部；它们会立即关上。

* *[台阶](台阶.md)**
* 加入了石英台阶。

# 更改
# = 常规 =
* 在[创造模式](创造模式.md)飞行时加入更多阻力（仅iOS）。
* 当typeinfo启用时停止加载游戏（仅iOS）。
* 木质台阶材料从石头变为木头。在0.7.3之前储存的木质台阶被命名为[伪木台阶](伪木台阶.md)，被挖掘时会掉落普通的木台阶。
* 当新建世界时，默认名称为“My World”。

# = 生物 =
* [亡灵生物](亡灵生物.md)会在阳光下燃烧了。
