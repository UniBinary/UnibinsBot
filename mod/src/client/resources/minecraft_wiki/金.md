# Minecraft
# = 物品 =
*  - 一种通过挖掘金矿石或深层金矿石获得的物品，可冶炼为金锭。
*  - 一种通过冶炼粗金或金矿石或用金粒合成来获取的物品，可用于[合成](合成.md)或[以物易物](以物易物.md)。
*  - 一种可以合成金锭的物品，可以由[僵尸猪灵](僵尸猪灵.md)掉落，也可以通过在[熔炉](熔炉.md)里烧炼金质物品，亦或者通过开采下界金矿石、挖掘镶金黑石获得。
*  - 一种由金锭和[苹果](苹果.md)合成的物品，可以给予玩家各种正面[状态效果](状态效果.md)。
* *  - 金苹果的变种，能给予更佳的状态效果，但不能合成，只能从[生成结构](生成结构.md)中获取。
*  - 一种由金粒和[胡萝卜](胡萝卜.md)合成的物品，可提供较高的饥饿值和饱和度，也可用于[酿造](药水酿造.md)。
*  - 一种由金粒和[西瓜片](西瓜片.md)合成的物品，主要用于酿造。
*  -一种由金锭和[红石粉](红石粉.md)合成的物品，用于查看时间。

# = 方块 =
*  - 一种能在地下深处发现的罕见[矿石](矿石.md)，可以通过挖掘获得粗金，并通过烧炼获得金锭。
*  - 在主世界[深板岩](深板岩.md)层取代普通金矿石生成的变种金矿石。
*  - 金矿石的[下界](下界.md)变种，使用无[精准采集](精准采集.md)魔咒的工具挖掘时只会掉落金粒。
*  - 有着金纹理的[黑石](黑石.md)变种，挖掘后通常掉落自身，但有小概率掉落金粒。
*  - 一种用粗金合成的装饰性方块。
*  - 一种用金锭合成的装饰性方块。
*  - 一种由金粒和[蒲公英](蒲公英.md)合成的[小型花](小型花.md)，可用于停止或恢复幼年生物成长。
*  - 一种化学[元素](元素.md)。
