# 基岩版1.16.230.54

*页面ID: 81207* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.230.54**是[基岩版1.17.0](基岩版1.17.0.md)的第3个测试版，发布于2021年4月8日<ref></ref>，调整了一些[洞穴与山崖](洞穴与山崖.md)的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)**
* 现在对其[骨粉](骨粉.md)可使其长成[杜鹃树](杜鹃树.md)。
* * 需种植在[草方块](草方块.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[灰化土](灰化土.md)或[耕地](耕地.md)上才能被催熟。
* * 长成后该草方块、泥土、砂土、灰化土或耕地会转化为缠根泥土。

* *[煤矿石](煤矿石.md)、[钻石矿石](钻石矿石.md)、[金矿石](金矿石.md)、[铁矿石](铁矿石.md)和[青金石矿石](青金石矿石.md)**
* 再次更改了纹理。
* * 铁矿石的矿粒纹理不再拥有条纹，使之与其他矿石相匹配。
* * 钻石矿石的纹理现在更加接近于深层钻石矿石。

* *[大型垂滴叶](大型垂滴叶.md)**
* 现在破坏其叶茎会掉落其自身，以同步。

* *[小型垂滴叶](小型垂滴叶.md)**
* 现在可用于[堆肥](堆肥.md)。

* *[滴水石锥](滴水石锥.md)**
* 提高了钟乳石滴落[水](水.md)或[熔岩](熔岩.md)的频率。

* *[发光地衣](发光地衣.md)**
* 现在可以自然生成于地下湖泊的壁上。

* *[苔藓块](苔藓块.md)**
* 现在可以垂直蔓延。
* 现在对其骨粉可使其上方长出植物。

* *[细雪](细雪.md)**
* 现在陷入其中的[实体](实体.md)受到冰冻伤害的所需时间为7秒，而不是15秒。
* 冰冻状态下的实体现在每隔2秒会受到一次冰冻伤害，以往这个频率是3秒。
* 提高了实体在细雪中垂直移动的速度。
* 现在破坏细雪需要更长的时间（硬度由0.1改为0.25）。
* 穿着[皮革靴子](皮革靴子.md)的实体现在从大于2.5格的高度摔落到细雪上会陷入其中。
* 着火的实体现在碰到细雪会将其融化。
* 现在冰冻状态下的实体会颤抖。
* 现在贴近细雪会出现迷雾效果。

* *[结构方块](结构方块.md)**
* 为加载模式的结构方块加入了加载动画选项，其与命令的加载动画功能类似。
* * 共拥有3种动画模式选项：“无”、“按层数放置”和“按方块放置”。
* * 可调整动画的加载秒数。

# = 物品 =
* *[皮革马铠](皮革马铠.md)**
* 现在可以使[马](马.md)不受细雪冰冻状态的影响。

# = 生物 =
* *[流浪者](流浪者.md)、[北极熊](北极熊.md)和[雪傀儡](雪傀儡.md)**
* 现在免疫细雪的冰冻伤害。

* *[烈焰人](烈焰人.md)、[岩浆怪](岩浆怪.md)和[炽足兽](炽足兽.md)**
* 现在会受到每次点的冰冻伤害。

* *[流浪商人](流浪商人.md)**
* 加入了以下交易选项：
* * 以1个[绿宝石](绿宝石.md)的价格出售2个[滴水石锥](滴水石锥.md)。
* * 以1个绿宝石的价格出售2个[缠根泥土](缠根泥土.md)。
* * 以1个绿宝石的价格出售2个[苔藓块](苔藓块.md)。
* * 以1个绿宝石的价格出售2个[小型垂滴叶](小型垂滴叶.md)。

* *[村民](村民.md)**
* 石匠村民现在会以1个绿宝石的价格出售4个[滴水石块](滴水石块.md)。

# = 世界生成 =
* *[洞穴](洞穴.md)**
* [滴水石簇](滴水石簇.md)现在会生成于Y=59以下的常规洞穴中。

* *[废弃矿井](废弃矿井.md)**
* [发光浆果](发光浆果.md)现在会生成于矿井的[运输矿车](运输矿车.md)中。

* *[沉船](沉船.md)**
* [苔藓块](苔藓块.md)现在会生成于补给箱中。

# = 游戏内容 =
* *[聊天](聊天.md)**
* 加入了尝试在低于最小建筑高度的区域放置方块时显示的提示：
* * “建筑最低高度是 -64 个方块”
* ** 开启[实验性玩法](实验性玩法.md)（Caves & Cliffs子选项）后显示。
* * “建筑最低高度是 0 个方块”

# 修复
* *洞穴与山崖特性**
* 拴绳现在会正确连接到美西螈的模型上。
* 创造模式物品栏中不再会出现未知无名物品。（）
* 在创造模式物品栏中，现在深板岩圆石位于圆石之后，磨制深板岩位于深板岩之后。
* 在创造模式物品栏中，现在美西螈桶位于细雪桶之后。
* 深板岩砖现在拥有正确的破坏时间。
* 修正了滴水石锥的纹理。
* 一个方块的空间中存在6个发光地衣不再会导致崩溃。
* 现在用附有精准采集魔咒的工具破坏垂根会正确掉落自身。
* 现在破坏大型垂滴叶的叶片部分时其他部分也会一同被破坏。（）
* 对苔藓块使用骨粉不再会生成蕨。（）

* *炽足兽**
* 炽足兽离开熔岩时会正常地颤抖了。（）

* *常规**
* 修复了关闭“视角摇晃”选项时玩家的手仍会摇晃的漏洞。（）
* 僵尸村民在被治愈为村民的过程中会正常地颤抖了。
* 修复了玩家初次进入一个随机的世界时可能会生成在不安全的位置的漏洞。（）

* *命令**
* 修复了命令会显示错误的输出消息的漏洞。（）

* *图形**
* 闪电苦力怕的蓝色电弧现在在大多数情况下都能正常地渲染。（）
* 修复了画无法渲染的漏洞。
* 打开/关闭“光线追踪”选项后，现在会正确加载/卸载光线追踪的特定纹理。

* *物品**
* 现在在主手上切换一些物品（如弓、弩、盾牌、三叉戟）时不再会跳过动画。（）

* *游戏内容**
* 改进了水下的能见度。
* 调整了水下的色调，现在变得更蓝了，以同步。</onlyinclude>
