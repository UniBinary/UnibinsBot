# 暗海晶石

*页面ID: 12720* | *来源: Minecraft Wiki*

* *暗海晶石（Dark Prismarine）**是自然生成于[海底神殿](海底神殿.md)的一种[岩石](岩石.md)方块。

# 生成
# = 自然生成 =
暗海晶石会在[海底神殿](海底神殿.md)中生成。暗海晶石数量较少，在神殿的藏宝室内包围着8个[金块](金块.md)出现，也较少地作为装饰出现。

# 破坏
挖掘暗海晶石的合适工具是镐。暗海晶石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

暗海晶石被破坏后会掉落自身。

# 用途
海晶石的一种用途是作为一个有一定爆炸抗性的建筑或装饰性方块。

# = 潮涌核心 =

暗海晶石可以用于组成[潮涌核心](潮涌核心.md)需要的启动框架。
