# 无效纹理与模型

*页面ID: 122575* | *来源: Minecraft Wiki*

Minecraft使用**无效纹理**与**无效模型**以应对存在于游戏资源与[资源包](资源包.md)的潜在错误。

# 无效纹理
[right|150px|class=pixel-image](File:Missing Texture.png.md)
* *无效纹理**，或**丢失的纹理（Missing Texture）**是一种特殊的[纹理](纹理.md)，它由游戏自动生成，自动添加到所有纹理图集中，并使用<code>minecraft:missingno</code>作为映射命名空间ID。同时，无效纹理也可以作为一个独立纹理，也使用<code>minecraft:missingno</code>作为此纹理的命名空间ID。

无效纹理的尺寸固定为16×16，不随纹理图集大小而改变。其纹理呈棋盘状，由黑色（）与品红色（}}或}}）组成，以在大多数情况下尽可能地显眼。类似的纹理也被其他游戏工作室使用。<ref>如[Valve](https://developer.valvesoftware.com/wiki/Missing_content)。</ref>

当游戏找不到指定的纹理时，游戏会自动将请求的命名空间ID引用到无效纹理，替代缺失的纹理。若指定的纹理的元数据加载产生错误，游戏也会使用无效纹理替代发生错误的纹理。

游戏使用了无效纹理后，会在游戏的输出日志中生成报告：
* 找不到纹理图集内的指定纹理时生成<code>|Using missing texture, unable to load [NAMESPACE]:textures/[TEXTURE].png : java.io.FileNotFoundException: [NAMESPACE]:textures/[TEXTURE].png</code>
* 模型元素缺少对应的纹理时生成<code>Unable to resolve texture reference: #texture in [NAMESPACE]:block/[MODEL]</code>

原版游戏也可以出现无效纹理，然而需要使用命令，游戏加载这些无效纹理时也不一定会在输出日志产生警告：<!--more are added in 1.21.9, see en: page-->

* * 将[空气](空气.md)、[洞穴空气](洞穴空气.md)或[虚空空气](虚空空气.md)应用于<code>minecraft:block_marker</code>粒子：<ref></ref>

# 无效模型
[right|150px](File:Missing Model.png.md)
* *无效模型**，或**丢失的模型（Missing Model）**是一类特殊的[模型](模型.md)。如果游戏没有找到模型，或在模型加载中产生了错误，游戏会自动将异常的模型替换为无效模型。

无效模型的命名空间ID是<code>builtin/missing</code>，它的外观是一个6面纹理都是无效纹理的方块。其硬编码模型可以导出为：

<syntaxhighlight lang="json">
{
  "textures": {
    "particle":  "missingno",
    "missingno": "missingno"
  },
  "elements": [
    {
      "from": [ 0,  0,  0],
      "to":   [16, 16, 16],
      "faces": {
        "down":  { "texture": "#missingno", "uv": [0, 0, 16, 16], "cullface": "down"  },
        "up":    { "texture": "#missingno", "uv": [0, 0, 16, 16], "cullface": "up"    },
        "north": { "texture": "#missingno", "uv": [0, 0, 16, 16], "cullface": "north" },
        "south": { "texture": "#missingno", "uv": [0, 0, 16, 16], "cullface": "south" },
        "west":  { "texture": "#missingno", "uv": [0, 0, 16, 16], "cullface": "west"  },
        "east":  { "texture": "#missingno", "uv": [0, 0, 16, 16], "cullface": "east"  }
      }
    }
  ]
}
</syntaxhighlight>
