# 携带版1.1.0.3

*页面ID: 29106* | *来源: Minecraft Wiki*

<onlyinclude>

* *alpha 1.1.0.3**是[1.1.0](携带版1.1.0.md)的第3个测试版，发布于2017年4月13日<ref></ref>，加入了[商城](商城.md)、[制图师](制图师.md)和[探险家地图](探险家地图.md)，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[商城](商城.md)**
* 加入了Minecraft[商城](商城.md)。

# = 生物 =
* *[村民](村民.md)**
* 加入了制图师村民。
* * 出售常规[地图](地图.md)和[探险家地图](探险家地图.md)。

# 更改
# = 方块 =
* *[西瓜](西瓜.md)**
* 使用[剪刀](剪刀.md)破坏西瓜会掉落9片[西瓜片](西瓜片.md)。

* *[蜘蛛网](蜘蛛网.md)**
* 蜘蛛网可以拆解为9根[线](线.md)。

* *[带釉陶瓦](带釉陶瓦.md)**
* 更改了白色、橙色、品红色和青色带釉陶瓦的纹理。

# = 物品 =
* *[探险家地图](探险家地图.md)**
* 现在可以通过与制图师村民交易获得。

# = 游戏内容 =
* *[资源包](资源包.md)**
* 加入了丢失纹理列表文件时的警告。

# = 常规 =
* *UI**
* 调整了UI以适应商城。

# 修复
* *修复了63个漏洞**
*  - 在床上或酿造台上的生物会被困住和不停旋转。
*  - 玩家无法获得关于凋灵的画。
*  - 被带有火矢的弓杀死的动物不会掉落熟肉。
*  - 治疗之箭不会给亡灵生物造成更多伤害，且箭会弹开。
*  - 女巫会免疫中毒伤害。
*  - 使用资源包时，生命条和饥饿条显示出错。
*  - 村民不能捡起多于一组的物品。
*  - 使用命令清除范围效果时，进入下界传送门时的扭曲效果会短暂显示。
*  - 所有颜色的潜影盒在物品栏或快捷栏里显示为白色。
*  - 为潜影盒染色会失去其所有的内容物。
*  - 在重新进入世界后，物品栏内默认的创造模式物品不再重新显示。
*  - 岩浆怪的跳跃动画丢失。
*  - 村庄生成时不完整。
*  - 将物品快速放入副手槽时游戏崩溃。
*  - 玩家无法破坏画。
* 为唤魔者的咒语重新加入了数据驱动功能。
* 村民在交易时会跑开，导致交易界面自动关闭。
* 加载旧存档时游戏崩溃。
* 原版行为包里的蘑菇岛现在会使用正确的名称和战利品表。
* 玩家重新加入此前取消加入的Realms世界时游戏崩溃。
* 给近战攻击应用不存在的生物效果时游戏崩溃。
* Realms的拥有者不能进入人数已满的世界。
* 大型陷阱箱无法正确高亮两个部分的方块。
* 在打开和关闭酿造台的UI后，药水瓶隐形。
* 玩家会生成在下界的基岩天花板里。
* 玩家在飞行状态下，重新进入Realms世界后不会保持飞行状态。
* 染色方块在创造模式物品栏里的显示顺序不正确。
* 在已经启用了行为包时，仍会弹出询问界面。
* 从下界里首次回到主世界时游戏崩溃。（仅移动端）
* 修复了多个来源的伤害<!-- damage -->（因此玩家不再能看见相互矛盾的界面）。
* 打开存储管理器后，玩家不能正确滚动滑条。
* 当依赖链被破坏时，附加包现在会在子级和父级同时被标记。
* 无法保存语言选项。
* 告示牌上的文本显示不正确。
* 使用“...”按钮关闭物品栏后不再导致快捷栏消失。
* 马在步行时不再前后摇头。
* 雪傀儡不会攻击恼鬼。
* 唤魔者尖牙会留下阴影。
* 重新进入Realms世界后，玩家的隐身效果会消失。
* 不能给多个床染色。
* 冒险模式下，现在只会对玩家可以互动的方块进行高亮处理。
* 在应用了反胃效果后，游戏画面不再猛烈摇晃。
* 成就的描述文本出现多种颜色。
* 修复了各种崩溃。
* 在部分安卓旧设备里退出存档后，保存截图会使得游戏崩溃。
* 存储管理器的确认界面里的文本在一些语言里不会滚动。
* 使用附加包加载世界时内存溢出。（仅iOS版）
* 玩家会在被活塞连接上的黏液块上受到坠落伤害。
* 快捷栏里的数字闪烁。
* 物品栏内的物品不再改变其内容。
* 使用铁桶或玻璃瓶从炼药锅里取水时不再使得快捷栏显示出错。
* 游戏内的难度设定无法更改。
* 命令的参数失效。
* 更改游戏模式后没有反馈信息。
* 卫道士和恼鬼手持武器时的模型不正确。
* 生成末地城后减少渲染距离会使得潜影贝消失。
* 玩家死亡后不会出现烟雾粒子。
* 多人游戏下的命令自动补全功能失效。
* 冒险模式里的和参数无法正常运作。
* 节日混搭包里的皮肤出现错误。
* Realms世界里加入了资源包时，该资源包不会显示。
* 在世界编辑界面里应用了资源包或行为包后按下“游戏”按钮，会使得该界面关闭然后返回到选择世界界面，而不是启动游戏。
* “红石大厦”世界里的描述文本在一些小屏幕设备里断片。</onlyinclude>
