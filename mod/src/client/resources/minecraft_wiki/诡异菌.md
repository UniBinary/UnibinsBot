* *诡异菌（Warped Fungus）**是一种形似蘑菇且自然生成于[下界](下界.md)的方块。

# 生成
# = 自然生成 =
诡异菌自然生成于[绯红森林](绯红森林.md)和[诡异森林](诡异森林.md)生物群系，在诡异森林当中生成频率更高。

下界菌仅生成在Y=25至128间。

# = 骨粉 =
对[诡异菌岩](诡异菌岩.md)或[绯红菌岩](绯红菌岩.md)[骨粉](骨粉.md)有概率使其上方和附近的两种菌岩上出现诡异菌，对诡异菌岩使用骨粉时出现概率更高。

# 破坏
诡异菌被挖掘时会立刻被破坏。

诡异菌被破坏后会掉落自身。

# 用途
诡异菌可以种植在菌岩、[灵魂土](灵魂土.md)、草方块、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。诡异菌需要其下方有固体方块，如果没有支撑方块将掉落为物品。

# = 生长 =
对种植在诡异菌岩上诡异菌骨粉有40%的概率可使之生长为[巨型诡异菌](巨型诡异菌.md)。若不为诡异菌岩则无法生长。

# = 繁殖 =
诡异菌可用于吸引及繁殖[炽足兽](炽足兽.md)，也可喂食给幼年个体，每次喂食减少其10%的剩余成长时间。

# = 堆肥 =
对[堆肥桶](堆肥桶.md)使用诡异菌会有65%的概率增加一层堆肥层数。

# = 疣猪兽 =
疣猪兽会远离17×9×17范围内的诡异菌<ref></ref>。
