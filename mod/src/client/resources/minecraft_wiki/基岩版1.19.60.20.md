# 基岩版1.19.60.20

*页面ID: 100154* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.60.20**（Android）、**Preview 1.19.60.20**（Xbox/Windows）是[基岩版1.19.60](基岩版1.19.60.md)的首个测试版，发布于2022年11月23日<ref></ref>，同步了一些的特性，在[实验性玩法](实验性玩法.md)中加入了一些[1.20.0](基岩版1.20.0.md)的特性，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了[末影龙](末影龙.md)、[铁傀儡](铁傀儡.md)、[雪傀儡](雪傀儡.md)和[凋灵](凋灵.md)刷怪蛋。
* * 末影龙和凋灵刷怪蛋暂时单独位于创造模式物品栏的“物品”分类中，在未来版本将不再可以通过创造模式物品栏获取。

# 更改
# = 方块 =
* *[信标](信标.md)和[潮涌核心](潮涌核心.md)**
* 现在所给予的状态效果产生的粒子效果是半透明的。

# = 生物 =
* *[尸壳](尸壳.md)**
* 更改了碰撞箱大小以近似匹配。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 更改了北极熊刷怪蛋的颜色，以与恶魂的做区分。

# = 游戏内容 =
* *[村庄英雄](村庄英雄.md)**
* 现在会在玩家与[流浪商人](流浪商人.md)交易时提供折扣。<ref></ref>

# = 常规 =
* *[粒子](粒子.md)**
* 加入了对粒子效果色彩混合的支持。

# = 技术性 =
* *活动对象过滤器**
* 创建了新的活动对象过滤器、、和。

* *命令**
* 现在使用新的语法执行命令时会显示产生消息的实体名称。

* *[Molang](Molang.md)**
* 加入了新的Molang，用于检测当前玩家。

* *AI意向**
* AI行为现在会在发射烟花火箭前检查目标上方最高的可被雨水穿过的方块。
* AI行为现在会在寻找露天地点前会检查目标上方最高的可被雨水穿过的方块。
* 为AI行为公开了新的数据参数，以指定开始交易前需要满足的条件，以及退出交易时目标与玩家的最大距离。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”、“即将推出的创作者功能”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[音符盒](音符盒.md)**
* 现在可在其上方放置[生物头颅](生物头颅.md)，在对其按下使用键或被红石信号激活时会发出对应生物空闲时的音效。

* *[生物头颅](生物头颅.md)**
* 现在可放置在音符盒上。

* *[猪灵的头](猪灵的头.md)**
* 可由[猪灵](猪灵.md)被[闪电苦力怕](闪电苦力怕.md)炸死时获得。
* 被红石充能或玩家佩戴走路时耳朵会扇动。

* *[竹块](竹块.md)**
* 可由9个竹子合成。

* *[去皮竹块](去皮竹块.md)**
* 可由竹块去皮得到。

* *[悬挂式告示牌](悬挂式告示牌.md)**
* 更改了墙上的悬挂式丛林木告示牌的方块纹理，加入了顶部铁链以与其他墙上的悬挂式告示牌保持一致。
* 将悬挂式竹告示牌合成配方中的竹板改为去皮竹块，并将产物由2个改为6个。

* *[竹板](竹板.md)**
* 合成配方改为由1个竹块合成2个竹板。
* 将纹理逆时针旋转90度，以与其他种类木板的平铺纹理相匹配。
* * 此更改使[竹按钮](竹按钮.md)、[竹压力板](竹压力板.md)、[竹台阶](竹台阶.md)和[竹楼梯](竹楼梯.md)的纹理也发生了变化。

* *[竹栅栏](竹栅栏.md)**
* 现在在地图上可以显示正确的颜色。

* *[脚手架](脚手架.md)**
* 更改了纹理以匹配其他竹制方块的颜色。

* *[雕纹书架](雕纹书架.md)**
* 加入了其独特的音效。
* 现在可以与[漏斗](漏斗.md)交互。（）

# = 生物 =
* *[骆驼](骆驼.md)**
* 更改了纹理以匹配。（）
* 现在坐下的骆驼在被玩家拴住并移动后会站起。
* 现在在骑乘骆驼的玩家在饥饿值较低时也能控制骆驼冲刺。
* 现在在骆驼站起时骑乘在其上的玩家不会再陷入模型。
* 现在骑乘在骆驼上的玩家会坐在正确的位置。
* 现在骆驼坐下时会减小碰撞箱。
* 减小了幼年骆驼的尺寸。
* 更改了冲刺冷却栏的颜色以匹配。
* 现在[幽匿感测体](幽匿感测体.md)可以检测到骆驼的站起与坐下。

# = 非生物实体 =
* *[竹筏](竹筏.md)和[运输竹筏](运输竹筏.md)**
* 更改了物品纹理以匹配。

# 修复
* *Android**
* 现在Android客户端加载世界时不再会熄屏。
* 现在加载屏幕中的Mojang Studios徽标会在所有版本的Android操作系统中保持一致。（）
* 修复了断连控制器后控制器输入有时会卡死的问题。

* *方块**
* 实体不再会被用红石信号激活的门推动。
* 现在使用选取方块功能选取草和蕨时会返回正确的物品。
* 现在使用选取方块功能选取金合欢树叶和深色橡树树叶时会返回正确的物品。
* 现在南瓜和西瓜可以生长在菌丝体和苔藓块上。（）

* *游戏内容**
* 更改了竹子的放置方式以匹配Java版。在持有竹子物品时点击竹子不再会使竹子生长。（）
* 现在所有生物都可以穿过凋灵玫瑰。（）
* 现在石墙在被连续放置时不会断开。
* 现在当使用命令传送被拴住的生物至较远距离时所有的生物都会被正确释放。（）

* *图形**
* 更改了纹理集中的反射率颜色数组。（）
* 信标效果粒子现在是半透明的。（）
* 潮涌核心效果粒子现在是半透明的。（）

* *生物**
* 现在美西螈处于未加载区块时不会减少其湿润时间。（）
* 热带鱼在地下生成时不再使用地表生成机制的密度极限。（）
* 现在成年尸壳能够进入两格高的空间，幼年尸壳能够进入一格高的空间。（）
* 现在村民在和平难度下可以受到闪电伤害。
* 现在村民在袭击胜利后庆祝时会确保其上方的方块能被雨水穿过，然后再发射烟花火箭。（）

* *粒子效果**
* 修复了拥有碰撞箱和的粒子在受到碰撞后不会消失的漏洞。

* *玩家**
* 修复了玩家在多人游戏中死亡、退出并重新加入后会失去连接的漏洞。

* *性能与稳定性**
* 修复了玩家被凋零效果杀死后产生的崩溃问题。
* 修复了在Xbox上快速连续选中选择世界界面上的编辑世界按钮时出现的崩溃。

* *文本栏**
* 文本栏在被选择后双击不再会取消选择。

* *触摸控制**
* 现在当按下放置键时其图标也会被按下。
* 修复了经典档案UI下玩家无法通过点击物品栏中的物品图标来移除对应物品的问题。
* 现在不处于十字准星模式时，新触控系统的触控焦圈会重新显示。

* *用户界面**
* 为创建世界时磁盘空间不足的情况加入了错误界面。
* 修复了Xbox加载界面上的Mojang Studios图标的分辨率。（）
* 移除了进入世界时的“打开聊天栏”消息周围的多余空格。（）
* 修复了流浪商人交易屏幕会显示交易等级的问题。（）</onlyinclude>
