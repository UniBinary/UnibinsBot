* *豹猫（Ocelot）**是一种[丛林](丛林.md)中罕见的友好生物。

# 生成
豹猫会在[丛林](丛林.md)和[竹林](竹林.md)生物群系中海平面（默认为Y=63）以上的[草方块](草方块.md)或[树叶](树叶.md)方块上自然[生成](生成.md)。生成的豹猫大多数是成年的，有时候也会生成幼年豹猫。每只成年豹猫生成时有的概率会有两只幼年豹猫伴随其生成。任何生成方式都有这个概率，包括[刷怪笼](刷怪笼.md)、自然[生成](生成.md)和[刷怪蛋](刷怪蛋.md)。
<!--如果一个玩家在[创造模式](创造模式.md)里用[刷怪蛋](刷怪蛋.md)在距离自己10格内生成豹猫，那么玩家必须离开这个范围然后重新靠近才能驯服豹猫。-->

豹猫在丛林有的概率生成失败，在竹林100%会生成失败。虽然豹猫是友好生物，但它们的自然生成需要怪物的[生物上限](生成#生物上限.md)，这使得豹猫不能在和平难度下自然生成。<ref></ref>

豹猫也可在[稀疏丛林](稀疏丛林.md)生成。

# 掉落物
成年豹猫被驯服的[狼](狼.md)或[玩家](玩家.md)杀死时会掉落。

和其他幼年动物相同，杀死幼年豹猫不会掉落经验。

# 行为
[thumb](File:Ocelot1.png.md)

豹猫会主动攻击16格内的[鸡](鸡.md)和幼年[海龟](海龟.md)。在发动攻击之前，它们会先以[潜行](潜行.md)姿态接近猎物。豹猫甚至能隔着栅栏或门杀死猎物。一只被命名的豹猫潜行时，其名字不会被显示。

豹猫可以透过[方块](方块.md)定位目标。

[苦力怕](苦力怕.md)会与豹猫保持6格的距离。不过开始爆炸的苦力怕只会在玩家离开其触发爆炸半径外才会逃离豹猫。

[幻翼](幻翼.md)会与豹猫保持16格距离。

豹猫免疫[摔落伤害](伤害#摔落伤害.md)，但仍会像多数生物那样避免掉下悬崖。

豹猫能看到[隐身](隐身.md)的玩家。

除了移动速度较快外，幼年豹猫的行为与成年豹猫没有差别。

# = 信任玩家 =
豹猫是极少数会[疾跑](疾跑.md)的生物之一，如果一个处于生存模式或冒险模式的玩家离它太近，它就会以疾跑的方式逃开。<!--如果此时豹猫处于封闭的空间中，它会原地呆着不动（但仍存在疾跑时才会出现的粒子效果）。一旦出口出现，它就会迅速跑出去。-->

豹猫会接近或内拿着[生鳕鱼](生鳕鱼.md)或[生鲑鱼](生鲑鱼.md)的玩家。若玩家移动或者转动视角幅度过大，或距离豹猫6格内不再拿着前述物品，豹猫会逃离玩家，在几秒内都不会再次接近玩家。

玩家可以通过喂食生鲑鱼或生鳕鱼以获得它们的信任。一旦豹猫信任玩家，它们就不会再逃离玩家。每次喂食有的概率获得豹猫的信任。

信任玩家的豹猫不会消失。与敌对生物类似，不信任玩家的豹猫距离玩家太远时会消失。

# = 繁殖 =

给信任玩家的豹猫喂食生鲑鱼或生鳕鱼可以使它们[繁殖](繁殖.md)，在其后的或内它们则不能再次繁殖。繁殖生出的幼年豹猫也是信任玩家的。

豹猫成功繁殖后会掉落。

使用生鱼能使幼年豹猫的成长速度加快，每条生鱼可减少其约10%的剩余成长时间。

对幼年豹猫[金蒲公英](金蒲公英.md)可以阻止其成长为成年豹猫，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年豹猫无法被喂食除金蒲公英外的其他物品。

# 你知道吗
* 豹猫是[Jon Kågström](Jon Kågström.md)创造的第一种生物。Jon Kågström是一名曾与[Jeb](Jeb.md)合作开发Minecraft的AI专家。<ref></ref>Jeb帮助制作了豹猫的纹理，因为Jon在制作时遇到了困难。<ref></ref>
* 现实生活中，猫的[高空坠落时自动调整姿态的能力](Wikipedia:Cat righting reflex.md)十分著名（虽然它们还是有可能摔伤）。这一点也反映到了Minecraft中：[猫](猫.md)与豹猫对跌落伤害完全免疫。
