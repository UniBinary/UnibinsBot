* *强力马铃薯（Powerful Potato）**是一种会生长出[强壮根茎](强壮根茎.md)的方块。

# 生成
# = 自然生成 =
强力马铃薯会在[马铃薯维度](马铃薯维度.md)的[废土](废土.md)生物群系自然生成。

# 获取
强力马铃薯只能通过破坏强力马铃薯获得。

# 破坏
没有工具可以加速对强力马铃薯的挖掘。

强力马铃薯被破坏后会掉落自身。

# 用途
# = 生长 =
[缩略图|300px|强力马铃薯的生长过程。为了使生长效果明显，已将随机刻速率改为300](File:Powerful_Potato_Growing.gif.md)
强力马铃薯会在被随机刻选中时向侧面和下方生长出相连的[强壮根茎](强壮根茎.md)。

强壮根茎可以替换该位置原有的方块（[基岩](基岩.md)和其他强力马铃薯除外）生成，并在其相连的强力马铃薯周围产生被替换方块的掉落物。

自然生成的方块状态为3的强力马铃薯不会长出强壮根茎，但如果为3的强力马铃薯周围存在强壮根茎，强壮根茎会继续生长。
