* *14w11b**是[Java版1.8](Java版1.8.md)的第18个快照，发布于2014年3月13日<ref></ref>，发布以修复[14w11a](14w11a.md)里的漏洞和崩溃。

# 更改
# = 方块 =
* *方块[模型](模型.md)**
* 常规方块现会加载模型，并且不会预定义方块形状。

# = 生物 =
* *[末影螨](末影螨.md)**
* 被命名的末影螨现在不会消失了，虽然<code>PersistenceRequired</code>仍被忽略。

# 修复
