# 启动器2.3.377

*页面ID: 98191* | *来源: Minecraft Wiki*

* *2.3.377**是一次[启动器](启动器.md)更新，发布于2022年8月23日。

# 更改
* 现在可以在启动器中启动[Minecraft Preview](Minecraft Preview.md)。
* 改进了登录流程。
* 进行了一些修改以确保启动器中的视频可以刷新。
* 改进了启动器安装器的功能。
* 改进了游戏和Game Pass的安装流程、逻辑和访问过程。
* 加入了单击复制错误信息的功能。
* 加入了部分字符串的翻译。

# 修复
* 修复了1.19以上版本无法打开的漏洞。
*  - 在macOS版启动器的版权信息中，“Mojang Studio”被错写为“Mojang”。
*  - 启动器无法启动。
*  - 下载《Minecraft Dungeons》后会出现“无法删除文件”的提示。
*  - 进入Java版游戏并切换到《Minecraft for Windows》标签页并下拉后，右上角的“开始游戏”按钮不会显示“等待安装中”。
