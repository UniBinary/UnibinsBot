# 音乐唱片mall

*页面ID: 156537* | *来源: Minecraft Wiki*

* *mall**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的同名曲目。

# 获取
# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片mall。

# 用途
# = 音乐 =

[noicon](File:mall.ogg.md)

Mall是一首宁静的音乐，由卡林巴琴与其他乐器演奏，游戏内时长为3分17秒。

# = 红石 =

音乐唱片mall放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为6的信号。
