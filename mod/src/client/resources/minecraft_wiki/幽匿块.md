# 幽匿块

*页面ID: 90408* | *来源: Minecraft Wiki*

}}

* *幽匿块（Sculk）**是一种生成于[深暗之域](深暗之域.md)生物群系或由[幽匿催发体](幽匿催发体.md)产生的装饰性方块。

# 生成
# = 自然生成 =
幽匿块自然生成于[深暗之域](深暗之域.md)生物群系。

# = 幽匿催发体 =

死后会掉落[经验](经验.md)的[生物](生物.md)在距[幽匿催发体](幽匿催发体.md)半径/内的位置死亡时，该位置周围接触[空气](空气.md)或[水](水.md)且带标签的方块会转化成幽匿块，每次转化消耗1点经验。

连续的幽匿块之间可以传递幽匿催发体所发出的信号，从而将信号传递出去。

# 获取
# = 箱子战利品 =

# 破坏
挖掘幽匿块的合适工具是锄。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，幽匿块被破坏后会掉落。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，幽匿块被破坏后会掉落自身。

# 用途
幽匿块可用于获取经验。
