# 南瓜

*页面ID: 10060* | *来源: Minecraft Wiki*

* *南瓜（Pumpkin）**是由[南瓜种子](南瓜种子.md)种植出的[农作物](农作物.md)方块，会在[主世界](主世界.md)大多数[生物群系](生物群系.md)地表的[草方块](草方块.md)上自然生成。

# 生成
# = 自然生成 =
南瓜可以自然生成在[主世界](主世界.md)大多数[生物群系](生物群系.md)的地表，但需要一个上方为空气且没有任何如[花](花.md)或[草丛](草丛.md)等植物的[草方块](草方块.md)。因此，多石、多沙或者多草丛的生物群系中很少会生成南瓜。被雪覆盖的草方块上依然可以生成南瓜。

南瓜也会生成在[林地府邸](林地府邸.md)的“[瓜房](林地府邸/结构/农场#瓜房.md)”、[掠夺者前哨站](掠夺者前哨站.md)的羊毛帐篷、[针叶林村庄](针叶林村庄.md)的[农田](农田.md)和[南瓜堆](南瓜堆.md)中。

# = 种植 =

[南瓜茎](南瓜茎.md)生长至成熟后会尝试在它毗邻的4个位置生成一个南瓜，并且要求是该方块为空气并且下方是[泥土](泥土.md)、[草方块](草方块.md)、[耕地](耕地.md)、[砂土](砂土.md)、[灰化土](灰化土.md)、[菌丝体](菌丝体.md)、[缠根泥土](缠根泥土.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[泥巴](泥巴.md)或[沾泥的红树根](沾泥的红树根.md)。如果收割了南瓜但没有破坏南瓜茎，南瓜茎则会尝试生成另外一个南瓜，而不用重新种植或等待南瓜茎再次成熟。

# 破坏
挖掘南瓜的合适工具是斧和剑。

南瓜被破坏后会掉落自身。

# 用途
# = 雕刻 =
对一个南瓜[剪刀](剪刀.md)，可以使其变成一个[雕刻南瓜](雕刻南瓜.md)，并掉落或[南瓜种子](南瓜种子.md)。同时，这会使南瓜的顶部纹理旋转方向。<ref></ref>

由剪刀雕刻产生的雕刻南瓜如果满足[生成生物](雕刻南瓜#生成生物.md)的结构要求，也可以像放置的雕刻南瓜一样生成生物。
