* *避雷针（Lightning Rod）**是一种用于吸引[闪电](闪电.md)的[方块](方块.md)。

# 生成
避雷针不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘避雷针的合适工具是镐。避雷针需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

避雷针被破坏后会掉落自身。

# 用途
避雷针可以将或以内的[闪电](闪电.md)吸引到自身顶部，避雷针被闪电击中时会变白；未涂蜡的避雷针被闪电击中时会变白。

避雷针在[雷暴](雷暴.md)天气中或时会发出白色星形粒子。要使避雷针可以吸引闪电，必须使避雷针在雷暴天气中和雨接触。

当避雷针或时，被带有[引雷](引雷.md)魔咒的[三叉戟](三叉戟.md)击中，闪电会在且总会在避雷针处产生，无需其他实体参与。

避雷针不会吸引由带有引雷魔咒的三叉戟命中实体产生的闪电。

避雷针下方3格内的[实体](实体.md)会被其吸引的闪电击中。

击中避雷针的闪电无法生成[骷髅陷阱马](骷髅陷阱马.md)。

避雷针可以附着于任意方块。

# = 红石元件 =

避雷针被任意来源的闪电击中时会发出15级的红石信号，持续约8个游戏刻，能够充能其附着的[红石导体](红石导体.md)，激活毗邻的红石粉、四周背向的[红石中继器](红石中继器.md)与[红石比较器](红石比较器.md)、附着避雷针的[红石火把](红石火把.md)以及毗邻的机械元件，。

# = 除锈 =

当避雷针附着于铜质方块时，其吸引的闪电会将该铜质方块直接清理为未氧化变种，并减轻邻近其他铜质方块的氧化程度。

类似于其他铜质方块，避雷针被闪电击中时会清除所有锈蚀。

# = 氧化 =

避雷针受氧化机制影响，能够在不同变种之间转化。
