* *河豚（Pufferfish）**是在温水海洋、暖水海洋中生成的友好生物。

# 生成
河豚会在[温水海洋](温水海洋.md)、[温水深海](温水深海.md)及[暖水海洋](暖水海洋.md)生物群系中生成。河豚只在高度Y=50至Y=64之间的水中生成。生成位置以玩家63格球形范围内生成，生成的位置上方必须有水。此生成判定高度只取决于当前维度的海平面，即海平面下13格至海平面的高度区间内都可生成河豚。

河豚会在[暖水海洋](暖水海洋.md)、[温水海洋](温水海洋.md)和[温水深海](温水深海.md)生物群系中生成。河豚自然生成在露天的水中，要求水底高度位于Y=0~64之间，空间检测范围为2×2×2，无亮度限制，不能生成在流动的水中，生成位置需距离玩家12-32格。

# 行为
玩家可以对河豚[水桶](水桶.md)来捕捞河豚以获得一个[河豚桶](河豚桶.md)。当手持河豚桶在一个方块上时，河豚将会和水一起被倒出来。

若带有自定义名称的河豚被水桶装起，则河豚桶也会带有同样的名称。

与其他鱼不同，河豚不会成群地四处游动。

# = 防御 =
当不处于或[旁观模式](旁观模式.md)的玩家、[盔甲架](盔甲架.md)<ref></ref>、[美西螈](美西螈.md)或任何其他非水生的生物在河豚周围5×5×5区域时，河豚会膨胀起来，从未膨胀到半膨胀，再到完全膨胀。河豚在受到任何伤害后也会立即完全膨胀。

河豚不会尝试近战攻击或进行追逐，而是在或后对美西螈和所有非水生生物无差别杀伤，并给予/的效果。这种攻击不能被[力量](力量（状态效果）.md)状态效果影响，[荆棘](荆棘.md)附魔也无法对河豚造成反伤。

河豚造成的伤害会导致拥有反击能力的生物反击并杀死河豚。

# = 弱点 =
河豚离开水后无法存活。如果离开了水，它们会像[守卫者](守卫者.md)一样扑腾一段时间，最后像[鱿鱼](鱿鱼.md)一样窒息而死。它们在翻转的同时还会转动。河豚在装有水的炼药锅中仍会窒息。<ref></ref>

# = 生物族群 =

河豚是水生生物。被具有[穿刺](穿刺.md)魔咒的武器近战攻击，或被具有穿刺魔咒的[三叉戟](三叉戟.md)弹射物命中时会受到额外的伤害。
