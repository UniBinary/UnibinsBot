# 生成结构

*页面ID: 6768* | *来源: Minecraft Wiki*

此页面列出了Minecraft中各种**生成结构（Generated Structure）**。生成结构被定义为：在世界创建界面的“”选项关闭时会被禁用的任何结构。

生成结构既可以被自然生成，也可以通过指令生成

# 主世界
主世界包含多种生成结构，其大小也各不相同。

# = 地下结构 =
这些结构只能生成在默认世界的地下。这些结构也可生成在[超平坦世界](超平坦世界.md)的地表，[废弃矿井](废弃矿井.md)也可生成在[虚空](虚空.md)[自定义世界](自定义世界.md)的地表。

# = 地表结构 =
这些结构只能生成在默认世界的地表（[雪屋](雪屋.md)有地下部分）。

# = 水下结构 =
这些结构能生成在默认世界的水下。[海底废墟](海底废墟.md)和[沉船](沉船.md)有时会生成在岸边，从而生成在水面上。

# 下界
下界包含的结构比主世界更少。

# 末地
末地主岛上不会生成结构。在这个维度中只有一种结构。
