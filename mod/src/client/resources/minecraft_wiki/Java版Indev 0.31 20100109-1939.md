# Java版Indev 0.31 20100109-1939

*页面ID: 172121* | *来源: Minecraft Wiki*

<onlyinclude>
* *0.31**的一个版本发布于2010年1月9日19:39（UTC）<ref>[Adura的IRC记录](#logs.md): "(14:39:20) <Notch> indev's been updated"..."(14:39:06) <Notch> with fiiiire"</ref>，加入了[火](火.md)。<ref></ref>

# 新内容
# = 方块 =
* *[火](火.md)**
* 可以在特定类型的[方块](方块.md)上燃烧。
* 玩家出生时会被给予99个火（在快捷栏第六格）。<ref>[Minecraft Forest Fire Timelapse](https://youtube.com/watch?v=rprfKDp5lHA)</ref>
* 由于它拥有动态纹理，因此在物品栏中不会被渲染。

# = 游戏内容 =
* *[世界类型](Indev世界选项#世界类型.md)**
* 加入了内陆（Inland）世界类型，替代了原始（Original）世界类型。<ref></ref>
* * 与原始世界类型类似，但世界外围为草方块而非水。

# 更改
# = 方块 =
* *[火把](火把.md)**
* 现在稍微变暗了。

# = 游戏内容 =
* *[亮度](亮度.md)**
* 现在有16个等级，之前是9个。
* 光现在能照得更远。

# = 世界生成 =
* *[世界主题](Indev世界选项#世界主题.md)**
* 地狱世界主题中的草方块被[泥土](泥土.md)替代。</onlyinclude>
