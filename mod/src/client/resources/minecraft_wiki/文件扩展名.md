# 文件扩展名

*页面ID: 180091* | *来源: Minecraft Wiki*

Minecraft自定义了多个文件扩展名，用于存储各类数据。

# 通用
* ：NBT的二进制形式。

# Java版
* ：GZip压缩的[NBT格式](NBT格式.md)。
* * 遊戲有時為其备份時使用。
* ：曾在[1.0](Java版1.0.md)至[18w02a](Java版18w02a.md)版本期间用作游戏内语言文件，格式为“[翻译键]=[译文]”，后被取代。
* ：用于保证一个存档仅能被一个游戏实例读写。
* ：用于保存区块数据。
* ：用于额外存储的区块数据。
* ：用于识别原版[资源包](资源包.md)和[数据包](数据包.md)，仅在核心文件中使用。
* ：为数据包提供函数。
* ：用于[资源包](资源包.md)、[数据包](数据包.md)以及[纹理](纹理.md)的元数据。
* ：曾在[Beta 1.3](Java版Beta 1.3.md)至[1.1](Java版1.1.md)版本期间用于保存区块数据。
* ：[数据生成器](数据生成器.md)将NBT文件转换为SNBT格式的文件。

# 基岩版
* ：游戏用于为原版[行为包](行为包.md)及[资源包](附加包.md)目录创建的备份，其中列出了目录内文件及内容。
* ：脚本的分析器捕获，由产生。
* ：可能是[NBT格式](NBT格式.md)。
* * 游戏有时为其备份时使用。
* ：FMOD音频格式，用于游戏内的音效文件，亦可用于资源包。
* ：用作游戏内语言文件，格式为“[翻译键]=[译文]”。
* ：用作游戏材质，亦可用于资源包。
* ：会在[截图](截图.md)后与文件一并保存。
* ：为行为包提供函数。
* ：已移除的格式。
* ：脚本的诊断数据，由产生。
* ：本质是NBT格式，用于[结构方块](结构方块.md)的保存模式和加载模式，亦可用于行为包。
* ：为过滤不雅用语功能提供词语列表，现以[Base64](wzh:Base64.md)格式存储，每行一词。

# = 本体接受的扩展名 =
这些扩展名（除了）本质上都是文件，并且可以在Windows、Android、ChromeOS、iOS以及iPadOS平台上通过Minecraft或Minecraft Preview打开，以导入相关文件。
* ：用于导入[附加包](附加包.md)。
* <ref group="注" name="win">仅Windows平台支持此扩展名。</ref>：用于导入编辑器附加包到[基岩版编辑器](基岩版编辑器.md)中。
* ：用于导入[资源包](附加包.md)、[行为包](行为包.md)以及[皮肤包](皮肤包.md)。
* <ref group="注" name="win" />：用于导入项目到基岩版编辑器中。
* <ref group="注" name="win" />：用于[快速进入游戏](快速进入游戏.md)。
* ：用于导入或导出世界模板。
* ：用于导入或导出[世界](世界.md)。
