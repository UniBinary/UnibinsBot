# 音乐唱片cat

*页面ID: 156532* | *来源: Minecraft Wiki*

* *cat**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的同名曲目。

# 获取
# = 箱子战利品 =

# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片cat。

# 用途
# = 音乐 =

[noicon](File:cat.ogg.md)

Cat是一首由软件合成器演奏的轻快的循环旋律，时长3分05秒。

旋律中伴有合成打击乐，锯齿波合成器自始至终演奏着低音旋律和一些和声。

# = 红石 =

音乐唱片cat放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为2的信号。
