* *13w38c**是[Java版1.7.2](Java版1.7.2.md)的第7个快照，发布于2013年9月20日<ref></ref>，移除了空气的物品形式，并修复了[13w38a](13w38a.md)和[13w38b](13w38b.md)里的漏洞和崩溃。

# 更改
# = 方块 =
* *[空气](空气.md)**
* 移除了空气的物品形式，就像[13w37a](13w37a.md)里大多数的技术性方块那样。
* 不再可通过命令获得。

# 修复
