# 携带版Demo

*页面ID: 21068* | *来源: Minecraft Wiki*

<onlyinclude>

[thumb|[[Notch](File:E32011.jpg.md)在E3 2011上游玩携带版Demo]]

* *携带版Demo（Minecraft - Pocket Edition Demo）**<ref name=":0"></ref>是首个已知的有关[携带版](携带版.md)的测试版本。此版本从未公开发布，但其中的一个版本可以在2011年的E3电子娱乐展上游玩到，其被用于提供给许多个体进行私人的测试和展示。

# = 世界生成 =
* *[树木](树木.md)**

# = 常规 =
* *[物品栏](物品栏.md)**
* 外观更小，并且有8个快捷栏与1个用于打开物品栏的按键。
* 方块在物品形式下显示为它们自身的单面纹理。如果方块有多个纹理，会使用侧面的纹理。

# 早期版本
YouTube视频中出现了一个更早期的Demo版本<ref name=":0"/>，其与E3 2011上展示的版本有些许差异：
* 此版本没有打开物品栏的按键，取而代之的是[铁块](铁块.md)。此外，[梯子](梯子.md)在快捷栏的第9个槽位上，而E3上展示的版本在第8个槽位。
* 当玩家将十字准星对准方块时，方块不会显示白色边框。
* [水](水.md)的纹理似乎与E3上展示的版本不同，然而这可能只是由于硬件问题。

# 你知道吗
* 第一个内部版本只有ASCII渲染器。<ref></ref></onlyinclude>
