# 灵魂沙

*页面ID: 6474* | *来源: Minecraft Wiki*

</ref>||Marsh Davies Mojang avatar.png}}

* *灵魂沙（Soul Sand）**是自然生成在[下界](下界.md)、能够减慢[实体](实体.md)移动速度的方块。

# 生成
# = 自然生成 =
灵魂沙在[灵魂沙峡谷](灵魂沙峡谷.md)中作为地表层与[灵魂土](灵魂土.md)大量混合生成；在灵魂沙峡谷以外的[下界生物群系](生物群系#下界.md)，灵魂沙则以1-12个方块大小的[团簇](团簇.md)生成于Y=31高度以下，每[区块](区块.md)尝试生成12次团簇。

灵魂沙也会在[下界要塞](下界要塞.md)的下界疣房间、[堡垒遗迹](堡垒遗迹.md)的藏宝室和疣猪兽棚、[远古城市](远古城市.md)的营房和中心自然生成。

# 获取
# = 箱子战利品 =

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家2-8个灵魂沙。

# 破坏
挖掘灵魂沙的合适工具是锹。

灵魂沙被破坏后会掉落自身。

# 用途
灵魂沙有不完整的[碰撞箱](判定箱#碰撞箱.md)，其高度为0.875格（14像素）。然而，灵魂沙的方块支撑形状是完整的。

灵魂沙的[速度乘数](速度乘数.md)为0.4，会使位于其上或}}的实体减速。

# = 合成材料 =

# = 种植下界疣 =
[下界疣](下界疣.md)可种植在灵魂沙上（类似于[小麦种子](小麦种子.md)能在[耕地](耕地.md)上种植），破坏完全成熟的下界疣会掉落多个下界疣。

# = 气泡柱 =

在[水源](水源.md)下放置靈魂沙会产生[上涌的气泡柱](气泡柱#涌流.md)，该气泡柱会让[物品](物品（實體）.md)、[玩家](玩家.md)、[船](船.md)和生物等[實體](實體.md)快速升起。

# = 火 =
在灵魂沙上点燃的火是[灵魂火](灵魂火.md)，能够永久燃烧（除非被人为熄灭），并且不会像普通火焰那样向周围的可燃方块蔓延。

# = 凋灵 =
|一种能够生成凋灵的结构示意图}}

灵魂沙可用于搭建生成[凋灵](凋灵.md)的结构。

# = 加速 =
使用带有[灵魂疾行](灵魂疾行.md)魔咒的[靴子](靴子.md)在灵魂沙上或}}行走时，速度为普通行走的{{cd|-{}-1.3 + 魔咒等级 &times; 0.105}}倍。

# 你知道吗
* 在灵魂沙上的[雪](雪.md)或[地毯](地毯.md)不会减速，因为实际踩上的是被覆盖的方块，而不是灵魂沙。
* 如果水流把玩家堆到一堵墙的对角，且在水流末尾处玩家的-{}-头紧贴着灵魂沙，玩家会跳起来。
* 在主世界里，走在灵魂沙上会导致天空明显变暗。该效果在夜晚时并不显著。
* * 这其实是[不完整方块](不完整方块.md)的特性造成的。天空的颜色能反映出玩家所站方块的亮度。由于灵魂沙是不完整方块，所以玩家站在其上方时会被游戏认为卡在了方块之中并处于绝对黑暗的位置。当玩家站在其他被游戏认为的不完整方块上也会出现此现象。
* 灵魂沙在顶部一半的位置有2个小圆形，这一半总是指向西边，这可以在不看[坐标](坐标.md)的情况下容易地辨认出下界的方向。
* [生物头颅](生物头颅.md)和灵魂沙使用了相同的破碎[粒子](粒子.md)。
