* *21w19a**是[Java版1.17](Java版1.17.md)的第21个快照，发布于2021年5月12日<ref></ref>，将启动游戏所需的最低Java版本提高到了[Java 16](https://www.oracle.com/java/technologies/javase-jdk16-downloads.html)，从创造模式物品栏移除了未完成物品（[蜡烛](蜡烛.md)、[收纳袋](收纳袋.md)和[幽匿感测体](幽匿感测体.md)）并移除了相关合成配方，同时修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 加入了以下语法：
* *
* ** 与旧的命令一致。
* *
* ** 将物品从来源复制到目标（可以是多个），有物品修饰器可选。
* *
* ** 修改物品，但不复制。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了、、和方块标签。
* * 拥有此标签的方块可以被相应的工具更快地挖掘。
* 加入了、和方块标签。
* * 这些标签用于决定需要使用特定工具挖掘才有掉落物的方块要用何种级别的工具才能产生掉落物。

# 更改
# = 方块 =
* *[铁砧](铁砧.md)**
* 铁砧UI的物品名称字符长度上限由35增加到50。

* *[蛋糕](蛋糕.md)**
* 插上染色蜡烛的蛋糕的英文名称由“[颜色] Candle Cake”改为“Cake with [颜色] Candle”。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 现在能够为[洞穴藤蔓](洞穴藤蔓.md)授粉。

* *[鱿鱼](鱿鱼.md)和[发光鱿鱼](发光鱿鱼.md)**
* 现在能被[拴绳](拴绳.md)拴住了。

# = 常规 =
* *[创造模式物品栏](创造模式物品栏.md)**
* 移除了一些未完成的物品，包括[幽匿感测体](幽匿感测体.md)、[收纳袋](收纳袋.md)和[蜡烛](蜡烛.md)。
* * 上述物品目前仍可通过、等命令获得。

* *[配方](配方.md)**
* 移除了一些未完成的物品的合成配方，包括收纳袋和蜡烛。
* * 这些配方现在需要使用[洞穴与山崖预览数据包](洞穴与山崖预览数据包.md)才能启用。

* *[闪烁标语](闪烁标语.md)**
* 将“Now Java 8!”闪烁标语更换为“Now Java 16!”。

* *[标签](Java版标签.md)**
* 将洞穴藤蔓加入到方块标签中。
* 将[苔藓块](苔藓块.md)从方块标签中移除。
* 将[杜鹃花丛](杜鹃花丛.md)与[盛开的杜鹃花丛](盛开的杜鹃花丛.md)加入到方块及物品标签中。

* *Java版本**
* 启动游戏所需的最低Java版本现在提高到Java 16。
