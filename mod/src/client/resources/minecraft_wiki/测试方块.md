# 测试方块

*页面ID: 139227* | *来源: Minecraft Wiki*

* *测试方块（Test Block）**是一种用于实现基于方块的测试的技术性方块。

# 生成
测试方块不会生成在世界中。

# 获取
测试方块无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，测试方块可以通过[创造模式物品栏](创造模式物品栏.md)（需要启用“”，或“”中有测试方块）、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
测试方块不能被挖掘破坏。

[权限等级](权限等级.md)不足<code>2</code>的玩家，即使处于创造模式也不能破坏测试方块。

测试方块被破坏后不会掉落。

# 用途

模式测试方块的界面}}

玩家无法在生存模式和冒险模式下放置测试方块、打开测试方块的交互界面并修改其内容或更改其模式。

测试方块不能在[生存模式](生存模式.md)中或以非管理员身份破坏，也不能被[凋灵](凋灵.md)和[末影龙](末影龙.md)破坏。

测试方块不能被点燃，不能被[活塞](活塞.md)推动，还有和[基岩](基岩.md)一样的[爆炸抗性](爆炸抗性.md)。

测试方块可以被[红石信号](红石信号.md)所[激活](#激活.md)，也可以发出红石信号。

除模式测试方块外，测试方块都必须在测试结构中才能发挥其作用。

# = 设置 =
处于[创造模式](创造模式.md)且拥有相关权限的玩家对测试方块点击键能打开其界面。

在[单人游戏](单人游戏.md)中打开测试方块界面时会暂停游戏。

; 方块模式
左下角，即在“完成”上方的按钮用于切换测试方块的模式。

点击“启动模式/模式/失败模式/接受模式”按钮可以改变测试方块的模式。“启动模式”为测试方块的默认模式。模式改变时，测试方块的纹理也会随之改变。

加载方块实体数据时，若<code>mode</code>字段为无效值，则测试方块会变为失败模式。
* 启动模式测试方块：顾名思义，这种方块表示测试的起点。处于启动模式的测试方块不受[NC更新](NC更新.md)影响。当测试启动时，它会激活并产生一次[信号强度](红石电路#信号强度.md)为15的红石脉冲。方块被重置时，它会取消激活。
* 模式测试方块：在运行基于方块的测试实例期间，测试方块被触发时，将所储存的消息输出为一条“Test <*模式名称*> (at <*方块位置*>{{fn|方块位置格式如<code>-{}-BlockPos(x<*方块的X坐标*>, y<*方块的Y坐标*>, z<*方块的Z坐标*>)</code>，其中<code>BlockPos</code>类会被混淆。但对于[25w45a](25w45a.md)起发布的未混淆的游戏而言会原样显示。|name=BlockPos}}): <*消息*>”日志。
* 失败模式测试方块：在运行基于方块的测试实例期间，测试方块被触发时，这条测试实例分支失败。
* 接受模式测试方块：在运行基于方块的测试实例期间，触发时，这条测试实例分支成功。只要在触发此方块前测试未超时，测试实例就不会停止。

; 消息
处于“模式/失败模式/接受模式”模式的测试方块能编辑其被触发后输出到日志中的消息。

虽然启动模式不会显示消息文本框，但原有的消息文本不会因切换模式而丢失。

; 完成
点击“完成”按钮或按会保存消息、模式和方块状态并退出界面。

; 取消
点击“取消”按钮或按会在不保存任何修改的情况下退出界面。

# = 激活 =
当处于“模式/失败模式/接受模式”模式下，测试方块属于[机械元件](红石元件#机械元件.md)，可被下列形式激活：
* 毗邻的开启的**[电源](红石元件#电源.md)**（例外：[红石火把](红石火把.md)不会激活其所附着的测试方块，[侦测器](侦测器.md)只会激活指向的测试方块）。
* 毗邻的**[充能方块](红石电路/充能与激活.md)**。
* 毗邻的指向测试方块且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)（包括测试方块上方的红石粉）；毗邻但未指向测试方块的红石粉不会激活测试方块。

被激活的测试方块会添加“已被激活”的标签，且模式下的测试方块还会输出“Test <*模式名称*> (at <*方块位置*>): <*消息*>”日志信息。
