# 生羊肉

*页面ID: 12660* | *来源: Minecraft Wiki*

* *生羊肉（Raw Mutton）**是一种[食物](食物.md)，可被烹饪成[熟羊肉](熟羊肉.md)。

# 获取
# = 生物掉落物 =

# = 箱子战利品 =

# 用途
# = 食物 =

手持生羊肉按住键即可食用，每个生羊肉可以回复。

# = 烹饪 =
将生羊肉放入[营火](营火.md)、[烟熏炉](烟熏炉.md)或[熔炉](熔炉.md)中烹饪，可以获得熟羊肉。

# = 狼 =
生羊肉能用来吸引、[繁殖](繁殖.md)或治疗驯服的[狼](狼.md)，也可以使已驯服的幼年狼的剩余生长时间加快10%。
