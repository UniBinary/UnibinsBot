* *熊猫（Panda）**是一种生成在[丛林](丛林.md)类生物群系的友好生物。

# 生成
熊猫较为罕见地生成于[丛林](丛林.md)和[竹林](竹林.md)生物群系中，其中在竹林的生成频率最高。熊猫也可在[稀疏丛林](稀疏丛林.md)生成。类似于一些友好生物，熊猫会生成在上方至少有两格方块空间、光照等级不低于9的[草方块](草方块.md)上，但是比其他的丛林生物更稀有。熊猫不会生成在[灰化土](灰化土.md)上。<ref></ref>熊猫在自然生成时会带有随机的“[变种](#变种.md)”，其中普通变种最为常见，棕色的最为罕见。

每只熊猫有5%的概率生成为幼年个体。

# 行为
熊猫会漫无目的地闲逛，也会躲避[水](水.md)、[熔岩](熔岩.md)和足以造成跌落伤害的悬崖，但它们在翻跟头时仍有可能不慎跌入其中。和[北极熊](北极熊.md)相似，熊猫在水中的移动速度快于其他陆地生物。它们会跟随/手持[竹子](竹子.md)的玩家。[雷暴](雷暴.md)天气期间，它们会发出呜咽声。成年熊猫有时会坐着。

成年熊猫会寻找并拾起[物品实体](物品实体.md)形式的[竹子](竹子.md)和[蛋糕](蛋糕.md)。玩家也可通过手持竹子对其按键来给予食物。它们会用双手捧着食物慢慢食用大约五秒。

在每个[游戏刻](游戏刻.md)中，幼年熊猫有（约0.017%）的概率打喷嚏，产生墨绿色的[粒子](粒子.md)，并让周围10格内在地上或水中的成年熊猫吃惊地跳起来。幼年熊猫打喷嚏时有（约0.143%）的概率掉落1个[黏液球](黏液球.md)。

熊猫在被生物攻击后会尝试反击该生物一次，类似于[羊驼](羊驼.md)。但好斗型熊猫会一直反击，直到目标死亡或消失。熊猫被攻击后会先惊慌数秒，随后尝试反击，但好斗的熊猫不会惊慌。幼年熊猫不会反击。

熊猫不能被[拴绳](拴绳.md)拴住。<ref></ref>

类似于[水生生物](水生生物.md)，熊猫不会受到[河豚](河豚.md)的伤害，但好斗的熊猫仍会受到其伤害。

# = 变种 =
熊猫有不同的变种。它们可以是普通的、懒惰的、忧郁的、顽皮的、好斗的、体弱的和棕色的。

[thumb|懒惰的熊猫躺在地上|200px](File:Panda Lying.png.md)
; 懒惰的熊猫
* 会躺在地上。
* 动作比普通熊猫迟缓。
* 是游戏中速度最慢的地面生物。
* 躺在地上时不会跟随手持[竹子](竹子.md)的玩家。
* 玩家可以对它按下键使它站起来。
* 会更频繁地躺在地上。

[thumb|中忧郁的熊猫在[[雷暴](File:WorriedPandaOnRainScreen.jpg.md)中颤抖着并把脸藏起来|200px]]
; 忧郁的熊猫
* 会躲避玩家和大多数的敌对生物（除了[史莱姆](史莱姆.md)、[岩浆怪](岩浆怪.md)、[恶魂](恶魂.md)、[尸壳](尸壳.md)、[潜影贝](潜影贝.md)、[幻翼](幻翼.md)和[末影龙](末影龙.md)）；会躲避除了其他熊猫以外的任何生物。
* 在[雷暴](雷暴.md)中会坐着，并且或。
* 不会主动吃竹子或[蛋糕](蛋糕.md)，无论是否有生物在附近。

[right|thumb|顽皮的熊猫在翻滚|200px](File:Panda Rolling.gif.md)
; 顽皮的熊猫
* 即使成年也会四处翻滚跳跃。有时会因此受伤。<ref></ref>

; 好斗的熊猫
* 自己或附近的熊猫被攻击后会对攻击者敌对。
* 被攻击时不会惊慌逃窜。
* 会持续攻击，而不是只攻击一次。
* 好斗的熊猫移动速度一般，但其被激怒时攻击范围与玩家相当。

; 体弱的熊猫
* 幼年时相比其他幼年熊猫更容易打喷嚏（打喷嚏的概率为0.2%，约为普通幼年熊猫的12倍）。
* 拥有点[生命](生命.md)而不是正常熊猫的点。

; 棕色熊猫
* 没有独特的行为，但其体色为棕白而不是黑白，生成概率也更低。

; 普通熊猫
* 没有独特的行为。

# == 外观 ==
[缩略图|熊猫的不同变种 - 从左至右： 棕色、懒惰、忧郁、顽皮、体弱、好斗和普通](File:NewPandaVariants.jpg.md)

熊猫的外观取决于它们的变种：
*  好斗的熊猫有生气的眉毛。
*  体弱的熊猫有眼泪和鼻涕。
*  顽皮的熊猫会伸出舌头。
*  懒惰的熊猫有一张微笑着的脸。
*  忧郁的熊猫眼睛有两个白点（类似于驯服的[狼](狼.md)）。
*  普通的熊猫有一张忧郁的、嘴角朝下的脸。
*  棕色的熊猫有棕白相间的皮毛和一张忧郁的脸。

# = 遗传 =
类似生物学，每只熊猫都有一对隐藏值互为“[等位基因](wzh:等位基因.md)”，每个位置可能出现七种基因，共同控制熊猫的变种（相对[性状](wzh:性状.md)的不同形态）。七种基因各自与其控制的性状的七种形态对应，其中普通、懒惰、忧郁、顽皮和好斗为显性基因，其余的体弱和棕色为隐性基因。

但与生物学不同的是，“等位基因”地位是不平等的，分为主要与隐藏。若主要基因为显性，则优先表达主要基因；若主要基因为隐性，但隐藏基因与之不同，则表现为普通变种；只有当二者都为同种隐性基因时这种基因控制的形态才会出现。

熊猫变种的遗传遵循[分离定律](wzh:分离定律.md)。当两只熊猫繁殖时，每只熊猫的“等位基因”会发生分离，其中一个基因将遗传给子代，两个基因在幼年熊猫处地位为主要或隐藏是随机的。

幼年熊猫获得的两个基因有的概率发生突变，突变后的概率如下表，适用于所有方式生成的熊猫。

# = 繁殖 =

[thumb|中熊猫的摇头动画|200px](File:Panda Unhappy.gif.md)
熊猫需要额外繁殖条件才能进入[繁殖模式](繁殖#求爱模式.md)，繁殖成功后会掉落。

需要熊猫的7×7×3范围内至少有一格[竹子](竹子.md)，之后喂食竹子使它们繁殖，并且在5分钟后才能再次繁殖。若在不满足条件时喂食，熊猫身上仍会出现爱心粒子，但在喂食另一只熊猫后两只熊猫会一起做出摇头的动作，此时如果再进行喂食，熊猫会坐下并吃掉竹子。若只有一只熊猫满足条件，虽然另一只熊猫会摇头，但仍可成功繁殖。

需要每只熊猫的5格半径范围内都至少有8格竹子，之后喂食竹子使它们繁殖，并且在1分钟后才能再次繁殖。若在不满足条件时喂食，熊猫不会进入“求爱模式”，而是会坐下并吃掉竹子。

给幼年熊猫喂食竹子可以加快其成长，每次喂食可以减少其约10%的剩余生长时间。

对幼年熊猫[金蒲公英](金蒲公英.md)可以阻止其成长为成年熊猫，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年熊猫无法被喂食除金蒲公英外的其他物品。

# 你知道吗
* 为了给熊猫创造游戏中的音效，[Mojang](Mojang.md)的首席声音设计师[Samuel Åberg](Samuel Åberg.md)亲自到录制了大熊猫的声音。<ref></ref>
* 游戏中幼年熊猫的喷嚏声混合了现实中熊猫宝宝和猫的声音，以及鹦鹉模仿打喷嚏的声音。<ref></ref>
* 成年熊猫因幼年熊猫打喷嚏而惊起的行为很可能参考自一个现实中熊猫宝宝在母熊猫吃东西时打喷嚏的[视频](https://www.youtube.com/watch?v=93hq0YU3Gqk)。
* 棕色熊猫是大熊猫的真实亚种，被称为。
* 熊猫进食时手持的竹子和蛋糕实际上位于主手槽。如果用命令|short=1}}或|short=1}}将其替换成其他物品，熊猫也会尝试啃食它。熊猫会在片刻过后丢弃该物品；熊猫只会在受到伤害后停止啃食并丢弃该物品。
* 在触控设备上，拿着蛋糕靠近熊猫时不会出现“喂养”按钮。<ref></ref>
