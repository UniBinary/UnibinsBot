# 成书

*页面ID: 8107* | *来源: Minecraft Wiki*

* *成书（Written Book）**是[书与笔](书与笔.md)经过署名之后的物品。

# 获取
# = 署名 =
成书可以通过为[书与笔](书与笔.md)署名的方式获得。书与笔一旦被署名成为成书，它就不能再编辑。成书的标签并非为“成书”，而是玩家在署名时所定义的标题。它会在标签的顶行里显示其标题，底行标注“”。<*玩家*>指定的是给书与笔署名的玩家。

# = 复制 =
成书可以使用[工作台](工作台.md)复制，分四种复制程度：
* 由[书与笔](书与笔.md)署名而来的成书为“”，复制产物为“”。
* “”的复制产物为“”。
* “”不可复制。
* “”的成书不可复制。游戏中未使用。

# 用途
成书可以通过按键打开，并显示一个可供玩家阅读的界面。

# = 讲台 =
玩家可以将成书放到[讲台](讲台.md)上面。

其与[红石比较器](红石比较器.md)连接时会根据书中页面发出红石信号。最后一页时会发出最大15级红石信号。

关于红石信号等级的计算公式如下：
* [Java版](Java版.md)：<math>1+\frac{\text{页码}-1}{\text{页数}-1}\times14</math>
* [基岩版](基岩版.md)：<math>1+\frac{\text{页面中有内容的大页码数}-2}{\text{总页数}-2}\times14</math>

# = 雕纹书架 =
手持成书对[雕纹书架](雕纹书架.md)按键可将成书放入其中。
