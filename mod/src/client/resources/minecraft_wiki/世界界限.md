# 世界界限

*页面ID: 12847* | *来源: Minecraft Wiki*

* *世界界限（World boundary）**是指Minecraft世界的边缘的区域。

# 定义
# = 水平方向上的世界界限 =
水平方向上的世界界限有多个层级。

* *第一层级**
[缩略图|X/Z ±29,999,984处的世界边界](File:1.21.6World boundary4.png.md)

第一层级是[世界边界](世界边界.md)，默认位于X/Z=±29,999,984。世界边界会阻止玩家再向前行走，下界传送门不会在此之外生成，但依然可以通过几种方法（命令、末影珍珠传送、旁观模式）越过这一边界。

* *第二层级**
[缩略图|X/Z=±30,000,000以外的区块](File:1.11.2World boundary1.png.md)

第二层级位于X/Z=±30,000,000，距离默认世界边界刚好一[区块](区块.md)远。这里有一道不可见的“墙”阻挡玩家，通过设置玩家位置阻止前进，即使旁观模式也无法越过。等命令在此处也无法使用，因游戏不接受超出±29,999,999的值，该值是硬编码到游戏源代码中的。降雨的粒子不再会在此限制之外Y=65以上的位置出现，此限制外的生物的位置也可能会显示不正确。<ref name="MC-267636"></ref>但方块间的相互作用（如水流或熔岩）仍会影响超出此限制的方块。

[缩略图|玩家利用船移动至X/Z=±30,000,000以外，然而地图上显示玩家仍然在X/Z=±30,000,000处](File:1.21.5World boundary1.png.md)

使用[矿车](矿车.md)（在超平坦世界的[预设](超平坦世界#自定义.md)中用[铁轨](铁轨.md)作为世界顶层）或[船](船.md)可突破第二层级限制：矿车尝试越过X/Z=±30,000,096时会卡在该处，玩家无法移动或下矿车，只能用回到正常世界；船虽能到达更远区域，但最远不超过可见区块范围。进入不可见区块边界时，玩家会被固定原地、镜头失控晃动，使用返回正常世界时，船会回到X/Z=±29,999,999。这是因服务器认为玩家加载中心仍在X/Z=±30,000,000处，区块加载范围未变，导致第二层级外部分区块无法完全加载。通过更改渲染距离，玩家最远可到X/Z=±30,000,544，这是原版不修改可达到的最远距离。

* *第三层级**
[缩略图|X/Z=±30,000,544处，这是在原版可达到的最远距离](File:1.21.6World boundary1.png.md)

第三层级位于X/Z=±30,001,056，可视为Minecraft世界的绝对边缘，超过此位置的[区块](区块.md)不会生成。

# = 垂直方向上的世界界限 =
[缩略图|主世界的最大建筑高度处](File:Maximum Height.png.md)

每个维度均存在建筑高度限制，即玩家能够放置和破坏方块的最小与最大高度。该限制由[维度类型](维度类型.md)控制：
* 建筑高度下限由定义，其取值需在-2032至2031之间，且为16的倍数。在原版游戏中，主世界的建筑高度下限为Y=-64，下界和末地则为Y=0。
* 建筑总高度由决定，指玩家可放置和破坏方块的总高度范围，取值为16~4064，且是16的整数倍。原版游戏里，主世界的建筑高度上限为Y=320，下界和末地为Y=256。

无论与如何设置，建筑高度下限不得低于Y=-2032，上限不得超过Y=2031。

上述限制不适用于[实体](实体.md)，实体可移动至远高于建筑高度上限或远低于建筑高度下限的区域。不过，若玩家处于Y=±20,000,000以外，其Y坐标不会被游戏保存，无论超出该位置多远，退出重进后都只会回到Y=±20,000,000处。<ref name="MC-221890"/>

[缩略图|主世界中的虚空](File:The Void beneath Bedrock.png.md)

超出建筑高度限制的区域通常被称为[虚空](虚空.md)。除[末影龙](末影龙.md)外，任何处于建筑高度下限64格及以下的生物，每10游戏刻（0.5秒）会受到的伤害。

# 假区块

[缩略图|正常世界与假区块的交界处，注意植被不会在假区块内生成](File:Mc cutoff.png.md)

假区块是旧版本世界边缘生成的特殊区块，最显著的特点是不具备方块碰撞箱，任何实体进入后都会穿过方块坠入虚空。

# = 特性 =
正常世界[区块](区块.md)的诸多机制在假区块中不再生效，具体包括：
* 实体进入假区块后会穿透方块落入虚空。
* 玩家无法在假区块内放置方块，区块内的方块既不能破坏也无法互动。
* * 实际上假区块内的方块均为[空气](空气.md)。
* ** 因此，假区块中不会自然生成任何生物。
* * 水和熔岩无法流入假区块，会在X/Z=29,999,999处停滞。
* * 若用活塞将方块推入假区块，该方块会永久消失，即便用黏性活塞尝试收回也无法拉回。
* 除[昼夜更替](昼夜更替.md)外，假区块不存在光照更新。
* 默认情况下，假区块仅生成草方块、泥土、石头、沙子、沙石、菌丝、水、熔岩和基岩。
* 假区块内不会自然生成植被、矿石、结构，甚至[顶层雪](顶层雪.md)、[冰](冰.md)、[沙子](沙子.md)、[沙砾](沙砾.md)等方块也不会出现。
* * 这使得X/Z=±30,000,000处形成明显的边界。
* * 通过[降级存档](教程:降级存档.md)，可让X/Z=±30,000,000以外生成的方块或结构在假区块中稳定存在，但仍不具备固态特性。

# 你知道吗
* 游戏实际上还存在被硬编码的“第四层级界限”，即“理论边界”。在不修改客户端的情况下，通过某些手段（如利用漏洞<ref></ref>）试图在X/Z=±33,552,992（由游戏源代码中“ChunkPos.MAX_COORDINATE”变量的数值决定）以外生成区块会导致游戏因“Trying to create chunk out of reasonable bounds: <越界距离>（尝试在理论边界外<越界距离>处生成区块）”而崩溃，这很明显是人为定义的崩溃。虽然在正常游玩的过程中不可能触发，但其确实存在于源代码中。具体Java版源代码片段如下：<syntaxhighlight lang="java">
public AbstractChunkHolder(ChunkPos pos) {
		this.pos = pos;
		if (pos.getChebyshevDistance(ChunkPos.ORIGIN) > ChunkPos.MAX_COORDINATE) {
			throw new IllegalStateException("Trying to create chunk out of reasonable bounds: " + pos);
		}
	}
</syntaxhighlight>
