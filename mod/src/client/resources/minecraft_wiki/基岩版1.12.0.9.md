# 基岩版1.12.0.9

*页面ID: 43969* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.12.0.9**是[1.12.0](基岩版1.12.0.md)的第5个测试版，发布于2019年6月3日<ref></ref>，修复了一些漏洞。

# 更改
# = 游戏内容 =
* *[稀有度](稀有度.md)**
* [金苹果](金苹果.md)和[附魔金苹果](附魔金苹果.md)有了稀有度提示文本。

# = 常规 =
* *[附加包](附加包.md)**
* 移除计时组件后再添加新的不会再使新计时组件继承旧组件的时间值了。
* 参考了以为前缀的方块的JSON内容现在可以被查阅了。

# 修复
* *修复了34个漏洞**<br>
* *崩溃**
* 修复了游戏进行时的崩溃现象。
* 修复了Nintendo Switch版在保存或加载世界时的游戏崩溃。（）
* 修复了加载市场内容时游戏卡住或崩溃。
* 修复了登录Xbox Live时的游戏崩溃。
* 破坏钟时不再导致游戏崩溃。（）
* 修复了导致游戏画面冻结或无响应的问题。（）
* 更改皮肤时不再导致游戏崩溃。
* 加载漫游皮肤时不再导致游戏崩溃。
* 修复了Nintendo Switch版下的部分崩溃现象。

* *性能**
* 改进了打开物品栏时的游戏性能。（）
* 改进了村庄和工作站点方块的性能。
* 改进了诸如生物寻路AI在内的性能。

* *常规**
* 市场搜索界面现在会显示正确的资源包图标。
* 市场里的促销内容现在会正确显示价格减少百分比。
* 在指针指向市场促销内容时图标现在会正确缩放。
* 浏览过相关内容后，“新！”标签现在会正确去除。
* 修复了部分市场内容的截图丢失漏洞。
* 改进了补丁说明以显示正确的更新内容。
* 重启游戏后，皮肤现在可以正常加载了。
* 与邀请游戏有关的部分修复：
* * 在进入已邀请世界失败后，创建或加载世界不再使得游戏崩溃。
* * 修复了玩家收到邀请后无法进入世界或服务器的问题。
* * 玩家在无法进入Realms世界或通过好友栏里试图加入世界失败后，不再显示“无法连接至世界”信息。
* 分屏下的玩家不再会由于加载界面出现问题而无法进入世界。

* *游戏内容**
* 修复了玩家无法使用干草捆来喂食生物的问题。
* 玩家死后的重生位置现在又正确了。
* 现在玩家死后不需要通过重新进入世界来重生。

* *生物**
* 铁傀儡在步行时又会摇晃身体了。

* *图形**
* 修复了此前已驯服的猫的坐下模型。（）
* 附魔盔甲或附魔弓现在会再次显示附魔光效。（）

* *用户界面**
* 修复了使用控制器导航市场内容时出现的问题。
* 触摸屏光标在移动到非配方书槽位时不再使得合成方格被清空。

* *附加包和脚本引擎**
* 修复了无法正常注册自定义方块的问题。
* 自定义物品和方块现在需要在命令里输入前缀。</onlyinclude>
