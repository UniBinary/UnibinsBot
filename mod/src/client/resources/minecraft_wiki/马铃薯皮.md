* *马铃薯皮（Potato Peels）**是一种具有多种用途的、可染色的[物品](物品.md)。

# 获取
# = 削皮 =
以下生物的毒马铃薯变种被[马铃薯削皮刀](马铃薯削皮刀.md)杀死时会额外掉落：

对马铃薯[绵羊](绵羊.md)马铃薯削皮刀可以削下1-3个对应的马铃薯皮，未被削皮的马铃薯绵羊死亡时总会掉落1个对应的马铃薯皮。

对装备[毒马铃薯胸甲](毒马铃薯胸甲.md)的生物马铃薯削皮刀会去除该胸甲，同时削下8个马铃薯皮。

对[薯皮草方块](薯皮草方块.md)的顶部马铃薯削皮刀会将其变为马铃薯泥土，同时削下1个黄绿色马铃薯皮。

对[马铃薯皮方块](马铃薯皮方块.md)马铃薯削皮刀会将其移除，同时削下9个对应的马铃薯皮。

# = 烹饪 =
马铃薯皮可以在[煎炸台](煎炸台.md)或[营火](营火.md)上煎炸制成[薯饼](薯饼.md)。

# = 转化 =
对[马铃薯泥土](马铃薯泥土.md)顶部使用黄绿色马铃薯皮会使其转化为薯皮草方块。
