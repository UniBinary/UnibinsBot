# Java版Classic 0.0.13a 03

*页面ID: 34910* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.13a_03**是的一次更新，发布于2009年5月23日。

目前没有证据能证明0.0.13a_01和0.0.13a_02的存在。

# 更改
# = 生物 =
* *[生物](生物（已移除实体）.md)**
* 现在不再在世界中自然生成。

# = 世界生成 =
* *[熔岩湖](熔岩湖.md)**
* 现在不再在海平面以上生成。

# = 常规 =
* *[控制](控制.md)**
* 在菜单中按将会退出菜单。

# 修复
; 修复了1个漏洞
   通过更新LWJGL版本修复了保存地图的问题。<ref></ref></onlyinclude>
