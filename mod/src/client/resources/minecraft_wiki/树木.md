# 描述

<div style="text-align:center">[500px](File:Arrangement of all tree types.png.md)<br>Minecraft中的一些树木</div>
树木的高度各不相同，最矮仅有1格高（倒下的树木），最高能达到32格（大型丛林树）。

树木的顶部由[树叶](树叶.md)组成，树冠最低可以在碰到地面上。树冠上的树叶大致是聚集在一个直径为5-7格，以树干部分为中心的球形中。树叶的旁边必须有树干或者其他树叶相邻着，否则它将会枯萎并消失。原木和树叶被破坏后不会重新生长回来。

深色橡树、苍白橡树、金合欢树、大型珍异橡树、大型丛林树和红树会长出树枝分杈（以斜向、横向或纵向连接树干或其他树枝的原木）。

自然生成或特定条件下由树苗长成的[橡树](橡树.md)、[白桦](白桦.md)、[红树](红树.md)或[樱花树](樱花树.md)有概率携带[蜂窩](蜂窩.md)。

# 生成

树木在[区块](区块.md)生成时一并产生。树木也可由对应的[树苗](树苗.md)或[杜鹃花丛](杜鹃花丛.md)长成。

# 树叶颜色

根据所在的生物群系不同，橡树、深色橡树、丛林、金合欢以及红树树叶的颜色会有所变化。

# 你知道吗
* 露天[湖泊](湖泊.md)的上方有很小的概率生成悬空树。这是因为在区块生成时，树木的生成顺序先于湖，当湖泊出现在已生成树木的区域时，树木就悬空了。
* 靠近露天[熔岩湖](熔岩湖.md)的树木有可能会被火点燃烧毁，甚至引发一场林火。
* Minecraft中的橡树基于现实中的[白橡](wzh:北美白橡.md)，云杉基于[白云杉](wzh:白云杉.md)，深色橡树基于[黑橡](wzh:北美黑橡.md)，金合欢树基于[伞刺金合欢](wikipedia:Vachellia tortilis.md)，丛林树很可能基于[玫瑰木](wikipedia:Aniba rosaeodora.md)。
