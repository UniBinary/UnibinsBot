* *生物奖杯（Mob Trophy）**是一种装饰性方块，游戏内显示为奖杯（Trophy）。

# 生成
# = 事件生成 =
[微光之门](微光之门.md)解锁的<code>hub/room/stairs</code>房间内部有一个下界合金等级、装有带光效的[羊驼唾沫](羊驼唾沫.md)的生物奖杯。

# 获取
# = 掉落物 =
除盔甲架外的任意[生物](生物.md)被玩家杀死后都有10%的概率额外掉落一个内部装有其生物模型的生物奖杯，此模型有1%的概率具有[光效](光效.md)，同时物品[提示框](提示框.md)中会显示一行“（Oooh, shiny!）”。

生物奖杯的等级随机抽取：
* 草丛（ ≈ %概率）
* 石头（ ≈ %概率）
* 金（ ≈ %概率）
* 钻石（ ≈ %概率）
* 下界合金（ ≈ %概率）

# = 箱子战利品 =
微光之门解锁的<code>hub/room/labyrinth</code>房间的尽头有一个[箱子](箱子.md)，里面有18个钻石等级、装有[闪电束](闪电束.md)的生物奖杯。

# 破坏
生物奖杯被挖掘时会立刻被破坏。

生物奖杯被破坏后会掉落自身，并附带等级和生物模型信息。

# 用途
玩家从矿境返回[主世界](主世界.md)时，物品栏中的生物奖杯不会被清除。

生物奖杯内部装有生物模型，此模型的大小会根据实体类型的不同进行缩放。由于此模型渲染无生物附加数据，因此模型动作固定，具有变种的生物始终展示固定的变种。

玩家与生物奖杯方块时，游戏会根据其内部的实体，从所有ID符合<code>-{}-entity.<*实体ID*>.<*任意值*></code>的[声音事件](Java版声音事件.md)中随机选择一个声音播放。对于大多数生物而言，相当于从其所有可能的音效中随机播放。

生物奖杯的等级会在物品提示框中提示“Grade: <*等级*>（等级：<*等级*>）”，游戏会自动给<*等级*>添加颜色样式。等级同时还决定了生物奖杯外观上两条“条带”的颜色。这两种颜色完全一致，每个等级对应的颜色如下：
* 草丛 -
* 石头 -
* 金 -
* 钻石 -
* 下界合金 -

# = 方块实体 =

生物奖杯拥有一个与其相关的方块实体，以保存生物奖杯的附加数据。

生物奖杯使用<code>mob_trophy/type</code>组件保存生物渲染数据。
