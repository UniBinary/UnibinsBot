# 平滑玄武岩

*页面ID: 79273* | *来源: Minecraft Wiki*

* *平滑玄武岩（Smooth Basalt）**是[玄武岩](玄武岩.md)制作的装饰性方块。

# 生成
# = 自然生成 =

平滑玄武岩会作为[远古城市](远古城市.md)的一部分和[紫晶洞](紫晶洞.md)的外层生成。

# 获取
# = 烧炼 =

# 破坏
挖掘平滑玄武岩的合适工具是镐。平滑玄武岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

平滑玄武岩被破坏后会掉落自身。

# 用途
平滑玄武岩目前仅用于装饰。
