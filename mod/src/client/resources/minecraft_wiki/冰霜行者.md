# 冰霜行者

*页面ID: 42219* | *来源: Minecraft Wiki*

* *冰霜行者（Frost Walker）**是一种用于[靴子](靴子.md)的[魔咒](魔咒.md)，使用后在[水](水.md)上行走能够产生[霜冰](霜冰.md)。

# 获取

冰霜行者是[宝藏型魔咒](宝藏型魔咒.md)，[附魔台](附魔台.md)、非宝藏的战利品、生物天然装备的[附魔](附魔（物品修饰）.md)过程不能提供该魔咒。提供冰霜行者的宝藏型魔咒来源包括：
* [交易](交易.md)以获取具有冰霜行者的工具或附魔书。图书管理员提供的具有冰霜行者的附魔书，价格会增加一倍。
* [钓鱼](钓鱼.md)时获得的物品或附魔书有可能具有冰霜行者。
* 一部分[箱子战利品](箱子战利品.md)会包含有概率出现冰霜行者的物品或附魔书。
* [袭击](袭击.md)中生成的[掠夺者](掠夺者.md)和[卫道士](卫道士.md)有可能会额外掉落具有冰霜行者的附魔书。

# 用途
[thumb](File:FrostWalker.gif.md)
在地上行走（不处于掉落、跳跃、飞行或状态）时，以当前方块位置为圆心，*等级*+2为半径的区域内的所有暴露在空气下，且与玩家站着的方块高度相同的水源方块都会结成[霜冰](霜冰.md)。等级达到14时覆盖范围达到最大，更高的等级将不会提升其覆盖范围。如果将要替换的静水方块中有[生物](生物.md)、[船](船.md)或[玩家](玩家.md)等实体，则该方块不会变成霜冰。

若要使冰在满足融化所需亮度的条件时不融化，则[玩家](玩家.md)需要持续在冰上移动。

此魔咒同时能消除[岩浆块](岩浆块.md)、[营火](营火.md)和[灵魂营火](灵魂营火.md)造成的伤害。

[盔甲架](盔甲架.md)上的靴子拥有此魔咒时，会对盔甲架附近的区域起作用。

[狐狸](狐狸.md)在持有带有此魔咒的靴子时也能够对其附近的区域产生作用。

冰霜行者与[深海探索者](深海探索者.md)被应用在同一个物品上时，每个魔咒都会互不干扰地产生效果。
