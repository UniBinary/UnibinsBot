# Java版Alpha v1.0.12

*页面ID: 32633* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.12**是的一次更新，发布于2010年7月26日<ref></ref>，加入了[史莱姆](史莱姆.md)的音效，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[史莱姆](史莱姆.md)**
* 为其加入了[音效](音效.md)。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入新的特殊标语“missingno”。

# 更改
# = 生物 =
* *[史莱姆](史莱姆.md)**
* 大型史莱姆不再在和平难度中生成了。

# = 常规 =
* *[暂停菜单](暂停菜单.md)**
* 移除了退出游戏按钮文本“Save and quit to title..”中末尾的两个点。

* *[多人游戏](多人游戏.md)**
* 为服务端加入了渲染距离选项。
* 添加了最大玩家数量选项。
* [聊天](聊天.md)界面的文字会自动换行了。

* *[闪烁标语](闪烁标语.md)**
* 移除了文件。
* * 因此，在游戏中闪烁标语总会显示为“missingno”（特殊标语除外）。

# 修复
* *修复了5个漏洞**
* 修复了大型史莱姆会在和平模式中生成的问题。
* 修复了史莱姆定位目标以及攻击的问题。
* 修复了文字颜色损坏的问题。
* 修复了多人游戏中内存泄露的问题。
* 修复了一个关于光照的问题。</onlyinclude>
