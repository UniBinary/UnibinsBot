# 命令/gametips

*页面ID: 124642* | *来源: Minecraft Wiki*

启用或禁用此设备上的[游戏提示](游戏提示.md)。

# 语法
   <code>gametips <status: Status></code>

# 参数

   必须为以下其中之一：
  * <code>disable</code>（可简写为<code>d</code>）代表禁用
  * <code>enable</code>（可简写为<code>e</code>）代表启用

# 结果

# 示例
* 禁用此设备上的[游戏提示](游戏提示.md)：<code>/gametips disable</code>或<code>/gametips d</code>
