# Java版12w30c

*页面ID: 31690* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w30c**是[Java版1.3.1](Java版1.3.1.md)的第17个快照，发布于2012年7月24日<ref></ref>，修复了快照[12w30a](12w30a.md)和[12w30b](12w30b.md)的一些漏洞和崩溃。

# 修复
* *修复了5个漏洞**
* 修复了活塞动画的问题。
* 修复了在特定生物群系中，雨的粒子的问题。
* 修复了将刷怪笼设置为生成<code>FallingSand</code>实体会导致崩溃的问题。
* 修复了一个小的文字问题。
* 修复了传送门放置的问题。</onlyinclude>
