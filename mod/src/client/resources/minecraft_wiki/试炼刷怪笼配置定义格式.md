# 试炼刷怪笼配置定义格式

*页面ID: 143979* | *来源: Minecraft Wiki*

* *试炼刷怪笼配置定义文件**是用于定义[试炼刷怪笼](试炼刷怪笼.md)的试炼行为的数据驱动定义文件。

# 定义格式
试炼刷怪笼配置数据在游戏内使用注册表，数据包路径为，即所有试炼刷怪笼配置定义文件都需要在{{filepath|-{}-data/<*命名空间*>/trial_spawner}}目录内定义。

试炼刷怪笼配置定义文件使用JSON格式，并具有下列结构：

# 定义行为

试炼刷怪笼配置定义数据仅在服务端启动时被加载一次，使用命令不可以使试炼刷怪笼配置定义被重新加载，而必须重启服务端。

试炼刷怪笼配置数据控制了实体生成数据，也控制了试炼结束后产生的战利品。

配置数据需要在试炼刷怪笼的下述[方块实体数据](试炼刷怪笼#方块实体.md)中使用。试炼开启后会使用与方块状态<code>ominous</code>对应的配置数据，任何未填写的字段均被视为默认值。

# = 抽取物品 =
试炼刷怪笼有两种抽取行为：不祥试炼刷怪笼生成的不祥之物生成器和试炼结束后的奖励。

决定了随机生成的[不祥之物生成器](不祥之物生成器.md)内存储的物品。游戏会使用战利品上下文参数集<code>empty</code>从战利品表内生成一项物品，并将获得的物品的数量设为1作为结果。因此生成的战利品表不能使用任何战利品上下文参数。

决定了试炼结束后喷出的奖励。游戏会从中选取一项战利品表，并使用战利品上下文参数集<code>empty</code>从其中生成并一次性弹出奖励物品，每有一个玩家参与试炼就会弹出一次奖励。因此生成试炼刷怪笼奖励的战利品表不能使用任何战利品上下文参数。
