# 基岩版1.21.60.25

*页面ID: 138809* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.60.25**（ChromeOS/Android）、**Preview 1.21.60.25**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.60](基岩版1.21.60.md)的第4个测试版，发布于2025年1月8日<ref></ref>，在[实验性玩法](实验性玩法.md)中加入了[猪](猪.md)的新变种和新的[树叶](树叶.md)粒子、对[磁石](磁石.md)作出了调整，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“”子选项。
* * 用于启用将于2025年首个[小更新](小更新.md)加入的特性。

* *[设置](设置.md)**
* 在设置中加入了“”选项。
* * 用于切换是否启用Websocket功能。
* 在设置中加入了“”按钮。
* * 用于删除所有诊断（）和分析器（）的捕获。

# 更改
# = 方块 =
* *[大型垂滴叶](大型垂滴叶.md)**
* 不再能放置于[苍白苔藓块](苍白苔藓块.md)上。

* *[嘎枝之心](嘎枝之心.md)**
* 为在合理结构中但由于白天而处于休眠状态的嘎枝之心加入了新纹理。
* * 休眠状态的嘎枝之心不能生成嘎枝，也不能生成[树脂团](树脂团.md)。
* 现在激活与休眠状态的转换取决于固定的时间，而不再受天气和维度亮度影响。
* 方块状态<code>active</code>现在被<code>creaking_heart_state</code>取代。
* * 可能的值为。

* *[眼眸花](眼眸花.md)**
* 现在状态的转换取决于固定的时间，而不再受天气和维度亮度影响。

* *[铁栏杆](铁栏杆.md)、[铁块](铁块.md)、[铁活板门](铁活板门.md)、[铁门](铁门.md)和[重质测重压力板](重质测重压力板.md)**
* 加入了独有音效，不再使用金属类方块的通用音效。

* *[下界传送门](下界传送门（方块）.md)**
* 由于对[末地](末地.md)传送至[主世界](主世界.md)相关问题的修复，现在位于末地的下界传送门会将生物传送至[世界出生点](世界出生点.md)的Y=-64处，此前为Y=32767处。

* *[幽匿感测体](幽匿感测体.md)和[校频幽匿感测体](校频幽匿感测体.md)**
* 现在能够检测嘎枝被攻击时晃动身体的动作。

* *[缠怨藤](缠怨藤.md)和[垂泪藤](垂泪藤.md)**
* 现在使用[菌索](菌索.md)的音效，而不是[藤蔓](藤蔓.md)的音效。

# = 物品 =
* *[骨粉](骨粉.md)**

# 修复
* *方块**
* 不带有数据的合成器不再会导致崩溃。（）
* 骨粉不再可以对单个深色橡树苗或苍白橡树树苗使用。（）
* 更新了苍白橡树树叶和苍白橡树树苗的地图颜色，以匹配它们在游戏中的实际颜色。
* 修复了破坏嘎枝之心时可能发生的崩溃。
* 修复了刷怪笼下方的草方块的渲染问题。（）
* 现在玩家无需潜行即可在铁门和铁活板门上放置方块。（）

* *游戏内容**
* 修复了生物从末地前往主世界时会传送至32767高度处的问题。（）

* *常规**
* 现在合成活塞、黏性活塞、投掷器和发射器时，配方书中再次会出现这些方块。

* *图形**
* 在JSON文件中加入了对组件的支持，以控制树叶和草地的颜色或主色调选择。

* *战利品表**
* 带有忽略活动对象ID的刷怪蛋的实体战利品表通过组件而被破坏时，不再会掉落一个无效的刷怪蛋。

* *生物**
* 现在嘎枝被攻击后摇摆时会发出振动。
* 现在嘎枝能够在雪层上生成。（）

* *Realms**
* 修复了旧的Realms的产品描述页面上的按钮可以在“立即订阅...”和“开始免费试用”之间切换的问题。
* 现在即使在账户的隐私设置中禁用访问多人游戏，用户仍可以访问他们归属的Realms的Realms故事。

* *配方**
* 加入了在没有任何键位可以映射为图案字符的情况下解析有序配方时出现的内容日志错误，这修复了带着此类畸形配方打开合成屏幕时发生的崩溃。（）

* *音效**
* 现在玩家挖掘、破坏和放置铁栏杆、铁块、铁活板门、铁门和重质测重压力板，以及在这些方块上行走时会产生铁质感的音效。

* *用户界面**
* 修复了选择在Realm上游玩按钮并取消登录进程时，用户无法从退出编辑世界界面退出的问题。
* 现在可以在启用文本转语音且禁用跨平台游戏的情况下滚动浏览好友选项卡。

* *原版趋同**
* 更改了玩家在岩浆块上行走时的受伤音效，现在使用火焰伤害的受伤音效而非默认音效。（）
* 现在末影人会在玩家注视它时正确地延时进入敌对状态。（）
* 为藤蔓、洞穴藤蔓、垂泪藤和缠怨藤加入了独特音效。（）
* 僵尸村民不再能由僵尸刷怪笼随机生成，以匹配Java版。（）</onlyinclude>
