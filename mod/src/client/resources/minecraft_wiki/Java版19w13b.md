* *19w13b**是[Java版1.14](Java版1.14.md)的第30个快照，发布于2019年3月29日<ref name="article_19w13b"></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[钟](钟.md)**
* 玩家敲钟后半径32方块内参与[袭击](袭击.md)的生物会拥有[发光](发光.md)效果。

* *[石英块](石英块.md)**
* 更改了纹理。

* *[切石机](切石机.md)**
* 加入了[雕纹石砖](雕纹石砖.md)的配方。

# = 生物 =
* *[村民](村民.md)**
* 更新了交易UI。
* * 可用的交易选项会列在左侧栏中，类似于[基岩版](基岩版.md)。
* * 当玩家有对应的物品时，点击交易选项会自动将物品放入交易槽位中。

# = 常规 =
* *[音效](音效.md)**
* 加入了在袭击期间敲响钟时给予[发光](发光.md)效果的新音效。
