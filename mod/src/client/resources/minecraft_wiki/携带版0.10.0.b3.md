# 携带版0.10.0.b3

*页面ID: 28515* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.10.0 alpha build 3**是[v0.10.0 alpha](携带版0.10.0.md)的第3个测试版，发布于2014年10月27日，修复了一些漏洞。

# 修复
* *修复了5个漏洞**

* 游戏不再在设备发生黑屏的时候停止响应。
* 玩家不会再在空中或基岩下方(Y<0)生成。
* 修复了在关闭并重新打开精美图像时发生的游戏图形损坏/崩溃。
* 修复了一些设备上远处地形和水的闪烁。
* 玩家睡觉时游戏不再停止响应。</onlyinclude>
