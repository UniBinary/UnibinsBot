# Java版17w31a

*页面ID: 31930* | *来源: Minecraft Wiki*

<onlyinclude>

* *17w31a**是[Java版1.12.1](Java版1.12.1.md)的唯一一个快照，发布于2017年8月1日<ref name="article_17w31a"></ref>，更新了制作人员名单，并修复了一个漏洞。

# 更改
# = 常规 =
* *[胜利屏幕](胜利屏幕.md)和[鸣谢与著作权说明屏幕](鸣谢与著作权说明屏幕.md)**
* 更新了制作人员名单，现在包含更多[Mojang](Mojang.md)职员。
* [鸣谢与著作权说明屏幕](鸣谢与著作权说明屏幕.md)的滚动速度比[胜利屏幕](胜利屏幕.md)快50%。
