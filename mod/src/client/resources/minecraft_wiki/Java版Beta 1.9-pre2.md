# Java版Beta 1.9-pre2

*页面ID: 32280* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.9-pre2**是[Java版1.0.0](Java版1.0.0.md)的第2个预发布版，发布于2011年9月29日，加入了[炼药锅](炼药锅.md)、[岩浆膏](岩浆膏.md)、九张[音乐唱片](音乐唱片.md)、生物[繁殖](繁殖.md)机制和[极限模式](极限模式.md)，并修复了一个漏洞。

# 新内容
# = 方块 =
* *[炼药锅](炼药锅.md)**
* 编码完成，但仍未分配方块ID。

# = 物品 =
* *[药水](药水.md)**
* 不能正常获得。

* *[玻璃瓶](玻璃瓶.md)**
* 不能正常获得。

* *[岩浆膏](岩浆膏.md)**
* 由[岩浆怪](岩浆怪.md)掉落。

* *[烈焰粉](烈焰粉.md)**
* 由[烈焰棒](烈焰棒.md)合成。
* [酿造](酿造.md)材料。

* *[蜘蛛眼](蜘蛛眼.md)**
* 由[蜘蛛](蜘蛛.md)掉落。
* 酿造材料。

* *[发酵蛛眼](发酵蛛眼.md)**
* 酿造材料。

* *[音乐唱片](音乐唱片.md)**
* 加入了九张新的音乐唱片。

* * [32px](File:Music Disc Blocks JE1 BE1.png.md) Blocks

* * [32px](File:Music Disc Ward JE1 BE1.png.md) Ward

# = 生物 =
* *[繁殖](繁殖.md)**
* 加入了繁殖机制。
* * 动物的繁殖过程为瞬间完成，没有任何冷却机制。由于还未加入幼年生物，所有生物生来就是成年状态。
* * 繁殖出的绵羊的羊毛都是白色的，与其双亲无关。
* * 所有可繁殖的生物（[鸡](鸡.md)、[牛](牛.md)、[哞菇](哞菇.md)、[猪](猪.md)和[绵羊](绵羊.md)）均通过小麦繁殖。
* * 由于漏洞，此时[雪傀儡](雪傀儡.md)可以进入求爱模式，但是不能够繁殖。

# = 常规 =
* *[极限模式](极限模式.md)**
* [难度](难度.md)将被锁定在“困难”，并且迫使玩家在死亡后删除世界。
* 生命条将变更外观以表示当前正处于极限模式下。

# 更改
# = 物品 =
* *[金苹果](金苹果.md)**
* 现在物品栏中的金苹果会产生附魔光效。

* *[牛奶](牛奶.md)**
* 现在能够饮用[牛奶](牛奶.md)了，它能够移除玩家身上的所有状态效果。

# = 生物 =
* *[村民](村民.md)**
* 村民头上的“TESTIFICATE”名称被移除。

* *[僵尸猪灵](僵尸猪灵.md)**
* 僵尸猪人现在拥有，可抵挡8%的伤害。

# = 常规 =
* *[提示框](提示框.md)**
* 物品提示框现在有了一个粉红色的轮廓。

* *[主菜单](主菜单.md)**
* 加入了[Minceraft](Minceraft.md)彩蛋。

* *调试**
* 移除了上个版本里[跳跃](跳跃.md)可以获得[经验](经验.md)的特性。

# 修复
* *修复了1个漏洞**
* 修复了多人游戏中客户端侧双哞菇的漏洞。</onlyinclude>
