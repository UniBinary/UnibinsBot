# 饥饿

*页面ID: 6707* | *来源: Minecraft Wiki*

[缩略图|饥饿条处于屏幕右下方，正对于生命值](File:Hungerscreen.png.md)
* *饥饿（Hunger）**是一种代表[玩家](玩家.md)进食需求的指标，是[生存模式](生存模式.md)中随玩家活动而消耗的重要资源。

# 监测
|饥饿条}}
|不健康的饥饿条}}
玩家的饥饿指标由饥饿条——一排鸡腿图标显示。饥饿条位于[平视显示器](平视显示器.md)（HUD）之上、[生命](生命.md)条的右边，其包含10个鸡腿图标，代表饥饿值，从左到右扣除。每只鸡腿代表饥饿值，不完整的半只鸡腿代表饥饿值。

饥饿条不会直接显示玩家的剩余[饱和度](#机制.md)，但当玩家的饱和度降至0时，饥饿条会周期性地颤抖，表示饥饿值将会在后续活动中下降。

饥饿条不会显示玩家的[消耗度](#机制.md)。

当玩家具有[饥饿](饥饿（状态效果）.md)状态效果时，饥饿条会转变为不健康的黄绿色。

# 机制
玩家的饥饿状态由以下3个变量组成：
* **饥饿值（Hunger Value）**：由玩家的实体数据<code>foodLevel</code>控制，取值范围是从0到20。初始值为。
* **饱和度（Saturation）**：由玩家的实体数据<code>foodSaturationLevel</code>控制，在饥饿值被消耗前会首先被消耗，其值不能超过目前的饥饿值，最低值为0。初始值为5。
* **消耗度（Exhaustion）**：由玩家的实体数据<code>foodExhaustionLevel</code>控制，在玩家从事特定活动时会增加（见）。消耗度的初始数值为0，当消耗度到达4时，就会重置为0并扣除1点饥饿值或饱和度。
* * 如果饱和度大于0，当消耗度到达4时便会减去4并扣除1点饱和度。若剩余饱和度不足1，不会额外扣除饥饿值。
* * 如果饱和度耗尽，当消耗度到达4时便会减去4并扣除1点饥饿值。
* * 如果在同一刻内获得了超出4的消耗度（例如高等级的突进），则造成的消耗度最大值为40，减去4的判定每游戏刻只执行一次。

食用食物来恢复饥饿值是玩家恢复生命值的主要手段，在紧急情况下持续进食也能快速恢复大量生命值。

疾跑、跳跃、破坏方块等多种动作会增加消耗度，间接消耗饥饿值。遭到[尸壳](尸壳.md)的攻击，以及食用[河豚](河豚（物品）.md)、[生鸡肉](生鸡肉.md)（30%的概率）、[腐肉](腐肉.md)（80%的概率）会使玩家受到[饥饿](饥饿（状态效果）.md)状态效果，持续增加玩家的消耗度。

[难度](难度.md)为和平且[游戏规则](游戏规则.md)为<code>true</code>时，玩家每增加饥饿值，且每增加1点饱和度。

难度为和平时，玩家每增加饥饿值。

# = 食物 =

[食物](食物.md)是专门用于恢复饥饿值和饱和度的物品，也是大多数情况下的唯一方式。

食用食物会同时补充饥饿值和饱和度，而先补充的是饥饿值，饥饿值的提高也允许了饱和度上限的提高。例如，玩家吃下一个[金胡萝卜](金胡萝卜.md)（补充），吃之前饥饿值为，饱和度为0，则食用后饥饿值会升至，金胡萝卜提供的饱和度也会被充分利用（从0升到14.4）；然而，如果吃之前饥饿值为，则食用后饥饿值会升至，此时饱和度只能升到14，有0.4的饱和度被浪费掉了。

# = 蛋糕 =

[蛋糕](蛋糕.md)是后会为玩家补充饥饿值和饱和度的方块。与食物不同，使用蛋糕会立刻为玩家补充饥饿值和饱和度；使用蛋糕不会计入物品使用的[统计](统计.md)，但是会计入“”统计。

每个蛋糕共有7片，每次使用会减少1片，每片可以恢复，消耗一个蛋糕的全部7片可以恢复。

# = 饥饿影响 =
玩家的饥饿值控制着生命值的恢复或损失，以及能否疾跑。

[游戏规则](游戏规则.md)为<code>true</code>时，玩家才能通过饥饿值来恢复生命值。

* 当饥饿值在且仍有富余饱和度时，生命值每最多恢复。
* 当饥饿值在时，绝大多数种类的[食物](食物.md)（除了[金苹果](金苹果.md)、[附魔金苹果](附魔金苹果.md)、[紫颂果](紫颂果.md)、、[谜之炖菜](谜之炖菜.md)和[蜂蜜瓶](蜂蜜瓶.md)）都将无法被食用。
* * [和平](和平.md)难度下所有食物都可以食用，即使饥饿值已满。
* 当饥饿值在或更高时，生命值每4秒恢复。
* * 当玩家的生命值未满且饥饿值在或更高，生命值会额外恢复一次。
* 当饥饿值在或更低时，玩家的生命值不会自行恢复。
* 当饥饿值在或更低时，玩家将不能进行疾跑。
* 当饥饿值在或更低时，[矛](矛.md)具有的[突进](突进.md)魔咒不会发挥作用。
* 当饥饿值在时，玩家的生命值将会以每4秒的速度持续减少，并导致玩家不能睡觉，直到玩家进食完毕。饥饿伤害无视玩家的一切防御效果（[盔甲](盔甲.md)、[保护](保护.md)、[抗性提升](抗性提升.md)）。
* * 在简单难度下，玩家的生命值最终会减少到。
* * 在普通难度下，玩家的生命值最终会减少到。
* * 在困难难度下，玩家的生命值最终会减少到并导致死亡。 <ref></ref>

由于饥饿值是玩家独有的，非玩家生物一般情况下不会受到饥饿伤害，但仍可使用对它们造成饥饿伤害。

# = 食物计刻器 =
食物计刻器是饥饿直接影响玩家生命值的方式，由玩家的实体数据<code>foodTickTimer</code>记录了该系统控制玩家生命值升降的间隔时间。
* 当饥饿值是时，食物计刻器每刻增加1，达到10（0.5秒）就会重置为0，并为玩家恢复<code>-{}-*饱和度*÷6</code>点生命值，最多恢复。
* 当饥饿值为及更高时，食物计刻器每刻增加1，达到80（4秒）时就会重置为0，并为玩家恢复点生命值。
* 当饥饿值为，食物计刻器每刻增加1，达到80（4秒）时就会重置为0，并对玩家造成点伤害。
* 其他情况下，食物计刻器为0。
