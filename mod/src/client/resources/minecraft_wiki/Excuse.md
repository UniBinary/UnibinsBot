# Excuse

*页面ID: 169576* | *来源: Minecraft Wiki*

* *Excuse**是一首由[C418](C418.md)创作的音乐，该音乐未被游戏使用。

# 描述
Excuse是一首旋律稀疏、略显诡异的曲目，由钢琴演奏一段悲伤的乐曲组成，带有略微不和谐的和弦，回响宛如在洞穴中，有时还会加入颤音效果。

# 你知道吗
* 此曲目原本为[下界](下界.md)而作，但C418希望此专辑“不仅仅是游戏内容的复制品”，因此没有将本曲加入游戏。<ref>https://c418.org/albums/minecraft-volume-alpha/</ref>
