# Java版20w27a

*页面ID: 65917* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w27a**是[Java版1.16.2](Java版1.16.2.md)的首个快照，发布于2020年7月1日<ref name="20w27a"></ref>，加入了[猪灵蛮兵](猪灵蛮兵.md)及刷怪蛋和新的方块标签，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了[猪灵蛮兵](猪灵蛮兵.md)刷怪蛋。

# = 生物 =
* *[猪灵蛮兵](猪灵蛮兵.md)**
* [猪灵](猪灵.md)的强化变种，携带着[金斧](金斧.md)。
* 总是对玩家敌对。
* 拥有生命值。
* 只在世界生成时生成在[堡垒遗迹](堡垒遗迹.md)里。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 应用于[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[绯红菌岩](绯红菌岩.md)和[诡异菌岩](诡异菌岩.md)。
* * 决定方块即使在光照条件较强的环境下也能种植蘑菇和使巨型蘑菇生长。

# 更改
# = 方块 =
* *[下界菌](下界菌.md)**
* 现在可以种植在[菌丝体](菌丝体.md)上。

# = 生物 =
* *[僵尸疣猪兽](僵尸疣猪兽.md)**
* 现在可被[拴绳](拴绳.md)牵引。

# = 世界生成 =
* *[堡垒遗迹](堡垒遗迹.md)**
* 现在会在世界生成期间生成[猪灵蛮兵](猪灵蛮兵.md)。
* * 普通猪灵仍会正常生成。

# = 游戏内容 =
* *[进度](进度.md)**
* 将[猪灵蛮兵](猪灵蛮兵.md)加入到了进度“”和“”的达成要求当中。

# = 常规 =
* *菜单**
* 现在将[资源包](资源包.md)拖入菜单会使资源包列表直接更新，不再需要重新加载来刷新。
* 现在[数据包](数据包.md)的根文件夹中会有<samp>pack.png</samp>，且会展示在数据包菜单中。
