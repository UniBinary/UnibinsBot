# Java版1.18.1-rc3

*页面ID: 91663* | *来源: Minecraft Wiki*

<onlyinclude><!--漏洞表示安全漏洞时都使用漏洞-->

* *1.18.1-rc3**是[Java版1.18.1](Java版1.18.1.md)的第3个，也是最后一个发布候选版本，发布于2021年12月10日<ref name="article_1.18.1-rc3"></ref>，修复了1个严重安全漏洞。

# 修复

* *其他漏洞**
* 修复了由于上游库log4j2的安全漏洞，攻击者可以通过游戏内聊天或其他方法，使游戏在日志中记录如<code>$<nowiki/>{jndi:ldap://<url>}</code>等的可被利用的字符串时在其他设备上远程执行代码（RCE）的安全漏洞。<ref name="article_1.18.1-rc3"/><ref></ref><ref>https://help.aliyun.com/noticelist/articleid/1060971232.html</ref></onlyinclude>
