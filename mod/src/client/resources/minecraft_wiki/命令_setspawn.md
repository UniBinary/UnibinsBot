# 命令/setspawn

*页面ID: 39866* | *来源: Minecraft Wiki*

将当前位置设置为新玩家的默认[出生点](出生点.md)，与现有的命令效果相同。

# 语法
   <code>setspawn</code>

# 结果
永远执行成功。
