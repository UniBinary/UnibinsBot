# Java版13w04a

*页面ID: 33488* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w04a**是[Java版1.5](Java版1.5.md)的第6个快照，发布于2013年1月24日<ref></ref>，加入了尚未完成的记分板，并修复了一些漏洞。

# 新内容
# = 生物 =
* *常规**
* 生物在被重命名后（通过[铁砧](铁砧.md)或[刷怪蛋](刷怪蛋.md)）会在6格半径距离内在头上显示它们的名字。

# = 命令格式 =
* *[记分板](记分板.md)**
* 加入了[记分板](记分板.md)功能。
* * 尚未100%完成。
* * 记分板可用于记录死亡次数，杀害玩家次数，杀害生物次数，或玩家触发命令的次数。
* * 这个复杂的系统使用名字，显示名，和准则的组合，并给玩家记录分数，分数均为整数。

# 更改
# = 方块 =
* *[命令方块](命令方块.md)**
* 重命名的命令方块在聊天栏中会使用它们的名字来代替<code>@</code>。

* *[发射器](发射器.md)**
* 现在能朝向任何方向放置。
* 现在会将盔甲装备到1方格内的玩家身上。
* 它们现在能激活[TNT](TNT.md)。
* 它们现在能使用骨粉。
* 它们现在能使用打火器，使用时会降低工具的耐久。

* *[投掷器](投掷器.md)**
* 现在能朝向任何方向放置。

* *[红石比较器](红石比较器.md)**
* 现在能用到[唱片机](唱片机.md)上。
* * 根据唱片号码来输出信号。

* *[台阶](台阶.md)**
* 改进了双[台阶](台阶.md)。
* * 43:8将会成为“平滑台阶方块”并保持如此。
* * 简单地说：如果最高的位元被置位的话，顶部的纹理会用在每一个面上，这也可以用来做出平滑砂岩方块（43：9）。

# = 物品 =
* *[盔甲](盔甲.md)**
* 手持盔甲右键现在会穿戴。
* * 在这个快照中，这个功能是非常错误的，容易发生崩溃和不正确的槽位使用。
* * 漏洞在下一个快照中被修复。

* *[骨粉](骨粉.md)**
* 不再给予瞬间生长——取而代之的是进入下一个成长阶段：
* * 农作物将需要7个骨粉。
* * [树苗](树苗.md)和[可可豆](可可豆.md)需要2个。
* * 蘑菇仍会瞬间长成[巨型蘑菇](巨型蘑菇.md)。
* 使用时会发出绿色粒子。
* Dinnerbone表示他仍然需要平衡这个新的骨粉催熟系统<ref></ref>。

# = 生物 =
* *常规**
* 生物现在不会主动走过铁轨。

# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 在[创造模式](创造模式.md)中，玩家现在可以在5米外击中生物或玩家。
* * [生存模式](生存模式.md)和[冒险模式](冒险模式.md)保持原来的距离。
