* *基岩版编辑器（Bedrock Editor）**，亦称**Minecraft编辑器**或者**编辑器**，是可通过创建项目编辑世界的游戏内工具。它可以通过使用脚本进行自定义。

# 启动

[thumb|299x299px|Minecraft启动器中的基岩版编辑器](File:Bedrock Editor in Minecraft Launcher.png.md)
基岩版编辑器可以在[启动器](启动器.md)中启动，位于基岩版分区的“创作者工具”栏目下。分为基于正式版和[测试版](基岩版版本记录/开发版本.md)的两个版本。

除此之外，基岩版编辑器也可以通过快捷方式、、快捷方式或浏览器启动：
# 新建一个快捷方式、按下或打开浏览器输入网址。
# 根据你需要的版本输入以下内容。注意区分大小写。
# * 正式版：<code>minecraft://creator/?Editor=true</code>
# ** 1.21.120之前：<code>minecraft:?Editor=true</code>
# * 预览版：<code>minecraft-preview://creator/?Editor=true</code>
# ** 1.21.120.21之前：<code>minecraft-preview:?Editor=true</code>
# （如果是快捷方式）单击“下一步”并输入快捷方式的文件名，例如“基岩版编辑器”。
# 打开新创建的快捷方式以启动基岩版编辑器。

# 用法

# = 移动 =
使用键在水平方向上移动，使用与键在竖直方向上移动。使用鼠标滚轮向前或向后移动，也可以按住鼠标中键并移动鼠标来平移画面。

将鼠标指针对着任意方块，按移动到所指方块前面，按Ctrl+Shift+F移动到所选区域前面。

按Z以围绕所指方块顺时针旋转，按C以围绕所指方块逆时针旋转。

# = 选择 =
左键单击世界中的任何方块位置可以将其单项选择；按住键可以进行多项选择。

要移动选区，可以使用小控件，也可以在按住的同时使用方向键在水平方向移动，使用/键在竖直方向移动。

# = 工具 =
工具可以从左侧的工具栏中选择。

上述工具均可以自定义键位映射。

是编辑器专有的命令。
