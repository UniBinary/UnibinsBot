# 基岩版1.19.70.22

*页面ID: 101686* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.70.22**（Android）、**Preview 1.19.70.22**（Xbox/Windows/iOS/iPadOS）是[基岩版1.19.70](基岩版1.19.70.md)的第3个测试版，发布于2023年2月8日至11日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[藤蔓](藤蔓.md)**
* 现在使用除[剪刀](剪刀.md)外的[精准采集](精准采集.md)附魔工具破坏藤蔓时不会掉落任何物品。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 将闪烁标语“Almost C++11!”改为“Almost C++17!”。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[竹栅栏](竹栅栏.md)和[竹栅栏门](竹栅栏门.md)**
* 移除了边缘的黑线。（）

* *[悬挂式告示牌](悬挂式告示牌.md)**
* 现在在创造模式物品栏中，悬挂式红树木告示牌和悬挂式竹告示牌位于的前面。（）

* *[结构方块](结构方块.md)**
* 现在使用结构方块将实验性方块导入非实验性世界时，实验性方块会被正确替换为不可交互的[未知方块](未知方块.md)。

# = 生物 =
* *[骆驼](骆驼.md)**
* 现在再次可以走上碰撞箱为1.5格高的方块。（）

# 修复
* *原版趋同**
* 现在弹射物击中紫水晶块或紫水晶母岩时会发出音效。
* 现在使用除剪刀外的任意工具破坏枯萎的灌木时会掉落木棍，即使该工具带有精准采集魔咒也是如此。藤蔓在前述情况下则不会掉落任何物品。（）
* 在钟的下方或上方放置方块时不再会破坏钟。（）

* *旁观模式**
* 玩家在第三人称视角下逐步穿过方块时，相机视角不再会朝向玩家头部进行放大和缩小。（）
* 末地折跃门不再能在旁观模式中使用。（）

* *游戏内容**
* 红石信号源现在能够从不同的侧面来充能单个方块。（）
* 玩家不再可以在空间不足以站立的情况下开始飞行。（）
* 玩家现在可以在不按住潜行键的潜行状态下从方块边缘掉下来。

* *方块**
* 现在堆肥桶被堆满时总会消耗一个物品。（）

* *生物**
* 现在女巫站在营火上时会喝下抗火药水。

* *物品**
* 现在给弩填装箭时会晃动。（）
* 战利品表条件用于内部函数时不再会被游戏忽略。（）
* 雪傀儡、凋灵和行商羊驼刷怪蛋现在会正确出现在物品栏和快捷栏中。

* *市场**
* 在市场界面的侧边栏中加入了新的市场图标。

* *用户界面**
* 现在对胡萝卜使用和物品组件时，胡萝卜会在物品工具提示中显示正确名称。（）
* 调整了Android设备上文本输入栏的键盘交互。

* *命令**
* 命令不再会导致部分实体以某个角度生成。

* *实体属性**
* 修复了当实体属性值被因其他事件触发的移除活动行为的事件修改后更改会丢失的漏洞。</onlyinclude>
