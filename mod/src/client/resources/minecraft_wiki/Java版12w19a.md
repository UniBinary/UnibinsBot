# Java版12w19a

*页面ID: 32370* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w19a**是[Java版1.3.1](Java版1.3.1.md)的第5个快照，发布于2012年5月10日<ref></ref>。

# 新内容
# = 方块 =
* *[可可果](可可果.md)**
* 在丛林中加入了[可可果](可可果.md)。
* * 生成于丛林木。
* * 拥有3个生长阶段，掉落[可可豆](可可豆.md)的数量取决于生长阶段。

* *[砂岩](砂岩.md)和[石砖](石砖.md)**
* [砂岩](砂岩.md)和[石砖](石砖.md)有了正确的名字（例子：平滑砂岩、裂纹石砖）。

# = 世界生成 =
* *[巨型生物群系](巨型生物群系.md)**
* 加入了巨型生物群系[世界类型](世界类型.md)。

# 更改
# = 物品 =
* *[可可豆](可可豆.md)**
* 更改了纹理。
* 破坏丛林木[树叶](树叶.md)不再掉落可可豆。

* *[曲奇](曲奇.md)**
* 现在回复饥饿值而不是。

# = 常规 =
* *[奖励箱](奖励箱.md)**
* 如果附近有一样高度的方块，[火把](火把.md)会生成于奖励箱周围。

# 修复
* *修复了6个漏洞**
* 附魔弓和剑现在再次能正常工作了（其他工具现在有提示框了）。
* 末地和下界现在再次能正常生成了。
* 物品修复现在再次能正常工作了。
* 从创造模式开始的游戏不会再从生存模式开始了。
* 奖励箱现在再次能正常工作了。
* 粒子不能再激活上面有箭矢的木质压力板了。</onlyinclude>

# 你知道吗
* 在此版本中，加载单人游戏世界时，需先将中的（服务端）手动放置到下才能继续加载世界。
