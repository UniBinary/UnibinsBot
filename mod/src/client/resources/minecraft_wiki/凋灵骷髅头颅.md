# 凋灵骷髅头颅

*页面ID: 164563* | *来源: Minecraft Wiki*

* *凋灵骷髅头颅（Wither Skeleton Skull）**是一种[生物头颅](生物头颅.md)。

# 生成
凋灵骷髅头颅不会生成在世界中。

# 获取
# = 掉落 =
只有每只[闪电苦力怕](闪电苦力怕.md)杀死的第一个凋灵骷髅会掉落凋灵骷髅头颅。

# 破坏
没有工具可以加速对凋灵骷髅头颅的挖掘。

凋灵骷髅头颅被破坏后会掉落自身。

被爆炸破坏的凋灵骷髅头颅总是会掉落。

# 用途
凋灵骷髅头颅会被液体破坏。

# = 装饰 =
凋灵骷髅头颅被放置在方块顶面时可以呈16种不同的方向，而放置在方块侧面时可以呈4种不同的方向。凋灵骷髅头颅不需要方块支撑，且可以放置在其他头颅的上方或侧边。

# = 穿戴 =
<div style='float:right'></div>

玩家能将凋灵骷髅头颅装备在头盔槽位。[发射器](发射器.md)也可以将凋灵骷髅头颅装备给没有头戴物品的玩家、[盔甲架](盔甲架.md)和一些人-{}-形生物，且其必须恰好位于发射器前的方块内。

当凋灵骷髅头颅戴在玩家头上时，凋灵骷髅头颅的纹理将会覆盖玩家头部的第二层纹理。

# = 伪装 =
[多人游戏](多人游戏.md)中，穿戴凋灵骷髅头颅的玩家不会在[定位栏](定位栏.md)上显示。

穿戴凋灵骷髅头颅的玩家不会出现在其他玩家的定位器[地图](地图.md)上。

# = 凋灵 =

|召唤凋灵的结构图示}}
将4个[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)呈T字形排列，并在其顶端放置3个凋灵骷髅头颅（也可以使用[发射器](发射器.md)放置头颅，头颅的朝向取决于发射器的朝向），即可召唤凋灵。灵魂沙和灵魂土可以混用。结构可任意旋转。

最后放置的方块必须是凋灵骷髅头颅。T形的两个角落必须是空气方块。
