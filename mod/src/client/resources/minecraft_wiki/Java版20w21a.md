# Java版20w21a

*页面ID: 62447* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w21a**是[Java版1.16](Java版1.16.md)的第18个快照，发布于2020年5月20日<ref name="20w21a"></ref>，加入了[自定义世界](自定义世界.md)、新的音效事件和新的字幕，更新了[client.json](client.json.md)和[设置](设置.md)，并修复了一些漏洞。

# 新内容
[333px|缩略图|使用新生成器在主世界生成的诡异森林生物群系](File:Warped Forest Overworld.png.md)

# = 常规 =
* *[自定义世界](自定义世界.md)**
* 加入了新的实验性功能：自定义世界。
* “编辑世界”菜单中现在有了一个用于导出JSON文件的选项。
* * 之前导出的世界配置可以在创建世界时导入。
* 有许多新的实验性参数可供调整，但是它们之后可能会被移除。

* *<samp>[client.json](client.json.md)</samp>参数**
*
* * 禁用在线聊天的接收和发送。
*
* * 禁用[多人游戏](多人游戏.md)和[Minecraft Realms](Minecraft Realms.md)按钮。

* *[设置](设置.md)**
* 加入了导入/导出世界设置的功能。

* *音效事件**
* 加入了[狐狸](狐狸.md)传送时的新音效事件。

* *[字幕](字幕.md)**
* 为进入[下界传送门](下界传送门.md)的音效加入了字幕“”。
* 为激活[下界传送门](下界传送门.md)的音效加入了字幕“”。
* 为[猫](猫.md)睡觉的音效加入了字幕“”。
* 为[驴](驴.md)进食的音效加入了字幕“”。
* 为[狐狸](狐狸.md)传送的音效加入了字幕“”。
* 为[骡](骡.md)嘶鸣和进食的音效分别加入了字幕“”和“”。
* 为[鹦鹉](鹦鹉.md)模仿[疣猪兽](疣猪兽.md)、[猪灵](猪灵.md)和[僵尸疣猪兽](僵尸疣猪兽.md)的叫声的音效分别加入了字幕“”“”和“”。
* 为[僵尸](僵尸.md)敲打和破坏木[门](门.md)的音效分别加入了字幕“”和“”。
* 为使用[制图台](制图台.md)、[织布机](织布机.md)和[切石机](切石机.md)的音效分别加入了字幕“”“”和“”。
* 上述部分字幕在游戏中不显示，但在[声音事件定义文件](Java版声音事件.md)中被指定。

# 更改
# = 方块 =
* *[红石粉](红石粉.md)**
* 现在可以在十字形红石粉和点状红石粉之间用键切换了。
* * 点状红石粉不会充能周围的方块，但十字形会。
* * 与任何[红石元件](红石元件.md)相连接的红石粉无法切换形状。

* *[菌柄](菌柄.md)**
* 现在硬度为1。

# = 物品 =
* *[下界苗](下界苗.md)**
* 现在物品纹理会位于物品栏槽的中心，而不是底部。

# = 生物 =
* *[猪灵](猪灵.md)**
* 端详金质物品时不会再走动了。
* 如果猪灵在端详金锭时受到伤害，它手中的金锭就会消失且不会进行以物易物。

* *[末影龙](末影龙.md)**
* 现在不会受到创造模式玩家的[荆棘](荆棘.md)伤害了。

# = 世界生成 =
* *[矿石](矿石.md)分布**
* 提高了[玄武岩三角洲](玄武岩三角洲.md)中的矿石生成频率，以解决该生物群系中因[下界岩](下界岩.md)数量较少而矿石稀缺的问题。

* *世界类型**
* [自选世界类型](自选世界类型.md)的世界不再能通过<samp>server.properties</samp>创建。
* 三种世界生成器类型现在变成了独立的世界类型，而不是之前自选世界类型的选项。
* “地表”生成器被重命名为“单一生物群系”（Single Biome）。

# = 命令格式 =
* ***
* 结构名称现在全部是小写字母。

* ***
* 添加了控制传送到的高度的功能。
* * 语法：
* ** 指定可作为结果位置的最大高度。

# = 游戏内容 =
* *[钓鱼](钓鱼.md)**
* [睡莲](睡莲.md)现在属于“垃圾”钓鱼战利品而不是宝藏战利品。

# = 常规 =
* *[超平坦](超平坦.md)**
* 暂时移除了超平坦预设中的结构选项。

[缩略图|加载屏幕上新的Mojang Studios徽标](File:Splash2020.png.md)
* *[菜单屏幕](菜单屏幕.md)**
* 更新了[Mojang Studios](Mojang Studios.md)和[Minecraft](Minecraft.md)的徽标。

* *[NBT标签](NBT标签.md)**
* NBT标签现在是一个用于[玩家数据格式](玩家数据格式.md)的命名空间ID字符串，而不再是数字。

* *[黑曜石平台](黑曜石平台.md)**
* 现在会在非玩家实体从[末地传送门](末地传送门.md)进入末地时重新生成。

* *[字幕](字幕.md)**
* 将僵尸村民转化音效的字幕由“僵尸：转化”改为“僵尸村民：转化”。
* 将僵尸村民治愈音效的字幕由“僵尸：治愈”改为“僵尸村民：治愈”。
* 将字幕“Blast furnace crackles”的大小写更正为“Blast Furnace crackles”。
* 将字幕“Enchanting table used”的大小写更正为“Enchanting Table used”。
* 将字幕“Respawn anchor is charged”的大小写更正为“Respawn Anchor is charged”。
* 将字幕“Respawn anchor depletes”的大小写更正为“Respawn Anchor depletes”。
* 将字幕“Respawn anchor sets spawn”的大小写更正为“Respawn Anchor sets spawn”。
* 将字幕“Turtle egg breaks”的大小写更正为“Turtle Egg breaks”。
* 将字幕“Turtle egg cracks”的大小写更正为“Turtle Egg cracks”。
* 将字幕“Turtle egg hatches”的大小写更正为“Turtle Egg hatches”。
* 移除了字幕“Horse lands”。

* *[标签](Java版标签.md)**
* 移除凋灵玫瑰的方块标签。

* *[世界](世界.md)**
* 旧的自定义世界类型（[Java版1.13](Java版1.13.md)前）现在在世界选择屏幕上显示为“旧版自定义”。
