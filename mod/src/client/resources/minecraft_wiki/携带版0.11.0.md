# 携带版0.11.0

*页面ID: 17031* | *来源: Minecraft Wiki*

* *v0.11.0 alpha**是[携带版](携带版.md)的一次主要更新，发布于2015年6月4日。此更新加入了很多新特性，如[皮肤](皮肤.md)、[船](船.md)、[钓鱼](钓鱼.md)和[状态效果](状态效果.md)，以及新生物如[鱿鱼](鱿鱼.md)和[洞穴蜘蛛](洞穴蜘蛛.md)等。<ref name="0.11.0"></ref><ref></ref>其他值得注意的变化包括提高了性能，并加入了格式化代码。

在此版本之前，玩家必须手动修改游戏文件才能更改皮肤，但在多人游戏中仍会使用一样的默认皮肤。此版本更新后，皮肤可以轻易更改了，也弥补了[Java版](Java版.md)的一个重要特性。

* 可用锹点击草方块创建。
* 会替换村庄里的沙砾铺成的道路。

# = 生物 =
* *[僵尸](僵尸.md)**
* 生成的僵尸有5%的概率为幼年僵尸。
* 生成的幼年僵尸有5%概率为[鸡骑士](鸡骑士.md)（反过来，僵尸也有0.2％的机会成为鸡骑士）。

* *[蝙蝠](蝙蝠.md)**
* 自然生成于昏暗的洞穴里。

* *[洞穴蜘蛛](洞穴蜘蛛.md)**
* 自然生成于废弃矿井里。

* *[恶魂](恶魂.md)**
* 目前不会自然生成。
* 只能使用刷怪蛋生成。

* *[岩浆怪](岩浆怪.md)**
* 死亡时掉落[岩浆膏](岩浆膏.md)。
* 只能使用刷怪蛋生成。

* *[蜘蛛骑士](蜘蛛骑士.md)**
* 也可以生成为一只[骷髅](骷髅.md)骑着一只洞穴蜘蛛。

* *[鱿鱼](鱿鱼.md)**
* 幼年鱿鱼
* 在受到攻击时会喷出“墨汁”。
* 仅在海洋生物群系生成。

# = 非生物实体 =
* *[船](船.md)**
* 被破坏时会冒烟。
* 合成配方为5块[木板](木板.md)和1把[木锹](木锹.md)。
* 尺寸略大于Java版。
* 颜色取决于所使用的木板。
* 图标的颜色总是一样。不会根据实际上船的颜色而改变。
* 具有更强的抗损坏能力：与其他方块碰撞时，船不会被破坏。
* 可搭载2名乘客，包括所有生物。
* 被动和敌对型生物可以在没有玩家的情况下乘船。

* *[恶魂火球](恶魂火球.md)**
* 当[恶魂](恶魂.md)攻击时发射。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
* 对应的药水在下界加入之后才加入游戏。
* [中毒](中毒.md)
* * 通过食用[腐肉](腐肉.md)、[生鸡肉](生鸡肉.md)和[河豚](河豚.md)可以获得。
*  [反胃](反胃.md)
* * 仅可通过食用河豚获得。
*  [饥饿](饥饿（状态效果）.md)
* * 仅可通过食用生鸡肉获得。
* * 对[玩家](玩家.md)没有效果。
* 通过物品栏编辑，可以影响玩家的所有状态效果，例如[生命提升](生命提升.md)和[伤害吸收](伤害吸收.md)，并可以正常发挥作用。但是饥饿和饱和效果不起作用，这是由于缺乏饥饿值所导致的。

* *[死亡消息](死亡消息.md)**
* 移植自Java版。

* *[钓鱼](钓鱼.md)**
* 通过使用[钓鱼竿](钓鱼竿.md)进行。

# = 常规 =
* *[皮肤](皮肤.md)**
* 玩家可以选择“Steve”和“Alex”模型来应用自己的自定义皮肤。
* * 自定义外观使用与Java版相同的格式，可通过从相册中选择一张照片应用。
* 可以通过[皮肤包](皮肤包.md)来应用（每个售价$0.99/£0.79）。

* *[设置](设置.md)**
* 新增针对每个世界的设置，可从选择世界的界面进入。
* * 类似于[命令](命令.md)。
* * 重命名世界。
* * 更改游戏模式。
* * 锁定/取消锁定昼夜更替（仅当世界处于创造模式时才有的选项）。
* * 将旧世界转变为无限。
* ** 会用原始的地图（限制在256×256地图中）的所有保存数据（物品、地形等）创建一个新的世界，并将世界类型设置为无限，保留世界名称。
* ** 被扩展前的原始世界会被重命名为<世界名称>-old。
* 加入了视角摇晃选项。

* *[语言](语言.md)**
* 支持更多语言。

* *[服务器](服务器.md)**
* 自定义被踢出和被封禁的信息。
* 在服务器页面屏幕上显示服务器状态以及当天的消息。

* *[闪烁标语](闪烁标语.md)**
* “Now with skins!”
* “Blame shoghicps!”

# 更改
# = 方块 =
* *[石砖](石砖.md)**
* 雕纹石砖、苔石砖可以在[切石机](切石机（MATTIS）.md)内合成而得。
* 裂纹石砖可以通过烧炼石砖得到。

* *[草](草.md)**
* 将草的像素改为方形，双层草则为随机高度。

* *[木头](木头.md)**
* 现在称为木头，而不是[原木](原木.md)。

# = 物品 =
* *[牛奶](牛奶.md)**
* 喝牛奶以消除各种状态效果。

* *[盔甲](盔甲.md)**
* 不再减少玩家跌落时和着火时受到的伤害。

# = 生物 =
* *常规**
* 玩家在与正在燃烧的生物接触时会着火。

* *[狼](狼.md)**
* 项圈可以被染色了。
* 玩家可以用[腐肉](腐肉.md)喂狼。

* *[僵尸](僵尸.md)**
* 死亡时掉落腐肉。

* *[骷髅](骷髅.md)**
* 射箭变得更加精准。

* *[僵尸猪人](僵尸猪人.md)**
* 为僵尸猪人加入了帽子层，以匹配Java版。

# = 世界生成 =
* *[废弃矿井](废弃矿井.md)**
* 废弃矿井现在会生成洞穴蜘蛛的[刷怪笼](刷怪笼.md)了。

# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 提升创造模式互动距离。
* 从创造模式中彻底移除玩家燃烧动画。

# = 常规 =
* *图标**
* 更改了游戏Logo。

* *用户名**
* 限制玩家的用户名为Java版允许的用户名。

* *[设置](设置.md)**
* 在聊天页面加入了隐藏按钮。
* 世界选择菜单中的*编辑* 按钮从右上角移动到了每一个世界选项的一侧，并且有了新的图标。
* *外部* 按钮现在会出现在*新的*的选项中而非*编辑* 选项中。
* 改善了世界/IP列表

* *[性能](帧率.md)**
* 游戏会试图修复损坏的世界。
* 提升了屏幕旋转时的设备性能。
* 优化了多人游戏的带宽占用。
* 优化了客户端-服务端通信。
* 改进断开连接的消息。
* * 现在包括了被踢出和被封禁的原因。<ref></ref>
* 改进文本渲染。
* 优化世界加载。
* 多人游戏中的[生物](生物.md)生成。
* 更快的[火把](火把.md)放置（减少卡顿）。
* 加入了服务端游戏校对。
* 非精美画质模式现在会正常工作。

* *[格式化代码](格式化代码.md)**
* 0-9和a-f为彩色，“l”为粗体，“o”为斜体，“r”为清除。
* 第三人称模式启用时只能与玩家前方的物体互动。

* *图像**
* 加入了粒子效果。加入破坏方块时的动画，现在其他人的声音会显示在多人游戏中。
* 把物品栏图标从原先的[砖块](砖块.md)改为[箱子](箱子.md)。
