# Java版15w47c

*页面ID: 19001* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w47c**是[Java版1.9](Java版1.9.md)的第43个快照，发布于2015年11月20日<ref></ref>，修复了[15w47b](15w47b.md)中的问题。

# 更改
# = 方块 =
* *[蜘蛛网](蜘蛛网.md)**
* 现在可以被任何一把[剪刀](剪刀.md)采集，不再需要精准采集了。
