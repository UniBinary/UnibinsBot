# 无限

*页面ID: 36314* | *来源: Minecraft Wiki*

* *无限（Infinity）**是一种用于[弓](弓.md)的[魔咒](魔咒.md)，使用后射击时不会消耗普通种类的[箭](箭.md)。

# 获取

# 用途
带有无限魔咒的弓在使用[箭](箭.md)时不会将其消耗掉，且以此方式射出的箭只能在创造模式中捡起。只要使用-{}-者物品栏内存在至少1支箭，就可以发射出无限数量的箭矢。使用指令或在创造模式下通过[铁砧](铁砧.md)附魔無限的[弩](弩.md)亦能生效。

无限只能对箭生效；[药箭](药箭.md)、和[烟花火箭](烟花火箭.md)会被正常消耗。

无限与[经验修补](经验修补.md)被应用在同一个物品上时，每个魔咒都会互不干扰地产生效果。
