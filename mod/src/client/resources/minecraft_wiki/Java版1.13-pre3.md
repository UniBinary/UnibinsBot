# Java版1.13-pre3

*页面ID: 35056* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.13-pre3**是[Java版1.13](Java版1.13.md)的第3个预发布版，发布于2018年6月21日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *存档**
* 优化内存使用。
* 资源包文件夹<code>textures/blocks</code>重命名为<code>textures/block</code>。
* 资源包文件夹<code>textures/items</code>重命名为<code>textures/item</code>。

* *方块状态文件**
* 无方块状态的方块的<code>"normal"</code>改为空字符串（<code>""</code>）。
* 模型引用不再起始于<code>models/block/</code>文件夹，而是在<code>models/</code>。
