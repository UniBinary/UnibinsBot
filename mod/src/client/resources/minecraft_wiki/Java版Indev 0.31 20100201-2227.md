# Java版Indev 0.31 20100201-2227

*页面ID: 35367* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2010年2月1日。<ref></ref>

# 更改
# = 方块 =
* *[石头](石头.md)和[矿石](矿石.md)**
* 现在需要用[镐](镐.md)来破坏。
* * 现在需要使用正确品质的镐来开采与石头相关的[方块](方块.md)。
* * 开采或冶炼矿石只会得到1个对应矿物。

* *[原木](原木.md)**
* 现在其破坏速度快于石头。

* *[海绵](海绵.md)**
* 现在会吸收[无限水源](无限水源.md)和[无限熔岩源](无限熔岩源.md)。

* *常规**
* 硬度越大的方块需要越好的工具来挖掘。

# = 物品 =
* *[镐](镐.md)**
* 降低了镐的开采速度。

# = 生物 =
* *常规**
* 现在会掉落[打火石](打火石.md)。</onlyinclude>
