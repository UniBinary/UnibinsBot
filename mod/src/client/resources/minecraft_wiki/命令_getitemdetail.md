# 命令/getitemdetail

*页面ID: 56768* | *来源: Minecraft Wiki*

返回指定槽位的物品的名称。

# 语法
   <code>-{}-getitemdetail <*slotNum：整数*></code>

# 参数
<code>-{}-*slotNum：整数*</code>
   指定需要获得信息的物品所在的槽位。
