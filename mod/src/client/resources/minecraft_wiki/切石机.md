# 切石机

*页面ID: 9741* | *来源: Minecraft Wiki*

* *切石机（Stonecutter）**是一种用于制造多种建筑[方块](方块.md)的效用型方块，提供比普通的[合成](合成.md)途径更加高效、灵活的切石[配方](配方.md)。

# 生成
# = 自然生成 =
切石机会生成在[古迹废墟](古迹废墟.md)的匠铺以及[村庄](村庄.md)的石匠小屋中。

# 破坏
挖掘切石机的合适工具是镐。切石机需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

切石机被破坏后会掉落自身。

# 用途
# = 切石 =
切石机可以代替[工作台](工作台.md)来制造石质方块，所有切石配方都只需要一个原料就能产出成品，且对于需要在工作台上多步合成的物品可以一步制成。因此通过切石机制作部分方块相比直接合成消耗的原材料更少，所需的步骤也更少，例如切石制作[楼梯](楼梯.md)的原料利用率比直接合成高。
