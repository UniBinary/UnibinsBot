# Java版18w47a

*页面ID: 37359* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w47a**是[Java版1.14](Java版1.14.md)的第7个快照，发布于2018年11月21日<ref></ref>，加入了掠夺者前哨站、袭击和不祥之兆，更改了大量物品的纹理，改进了生物AI，并修复了一些漏洞。

# 新内容
# = 世界生成 =
* *[掠夺者前哨站](掠夺者前哨站.md)**
* 一个与掠夺者相关，但与[灾厄巡逻队](灾厄巡逻队.md)无关的结构。
* 会生成[掠夺者](掠夺者.md)。
* 塔顶有战利品箱，在主塔周围有小型建筑。
* 可以在任何能生成[村庄](村庄.md)的[生物群系](生物群系.md)中生成。
* 使用[拼图方块](拼图方块.md)生成。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
*
* * 杀死灾厄巡逻队队长时获得。

* *[袭击](袭击.md)**
* 在带有效果的玩家进入[村庄](村庄.md)时触发。
* [掠夺者](掠夺者.md)、[卫道士](卫道士.md)、[唤魔者](唤魔者.md)、[女巫](女巫.md)和[](灾厄之兽.md)可以是袭击的一部分。
* * 在进入村庄时，袭击的进度条会像末影龙生命条一样显示，并会在每次杀死掠夺者时减少。
* ** 在接近结束时显示剩余的生物数量。
* * 在效果为高等级时生物会一波一波地出现。
* ** 后期会出现女巫和唤魔者。

# 更改
# = 方块 =
* *[纹理](纹理更新.md)**
* 更改了所有[原木](原木.md)、[木板](木板.md)<ref></ref>、[金块](金块.md)、[钻石块](钻石块.md)、[荧石](荧石.md)、[下界砖块](下界砖块.md)、[砂岩](砂岩.md)、[红砂岩](红砂岩.md)和其他方块的纹理。<ref name="comparison"></ref>
* 更改了[石砖](石砖.md)、[苔石砖](苔石砖.md)、[裂纹石砖](裂纹石砖.md)、[雕纹石砖](雕纹石砖.md)和[小麦植株](小麦植株.md)的纹理。<ref name="comparison" />

# = 生物 =
* *[卫道士](卫道士.md)**
* 现在会破坏门。

* *[](灾厄之兽.md)**
* 现在会在[袭击](袭击.md)中生成。

# = 世界生成 =
* *[灾厄巡逻队](灾厄巡逻队.md)**
* 降低了生成概率。
