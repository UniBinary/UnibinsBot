* *洞穴蜘蛛（Cave Spider）**是一种能够使玩家-{[中毒](中毒.md)}-的敌对生物。

# 生成
洞穴蜘蛛生成在亮度等级小于等于7的[可刷怪方块](生成.md)上。没有生物群系或结构会生成洞穴蜘蛛，因此洞穴蜘蛛不会与多数敌对生物一同生成。

每只洞穴蜘蛛在生成时都有1%的概率再生成一个骷髅[骑乘](骑乘.md)在自身上，形成[蜘蛛骑士](蜘蛛骑士.md)，在部分积雪的生物群系中这只骷髅有80%的概率会是[流浪者](流浪者.md)，在下界中这只骷髅有80%的概率会是[凋灵骷髅](凋灵骷髅.md)，在[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)中这只骷髅有80%的概率会是[沼骸](沼骸.md)，在[沙漠](沙漠.md)中这只骷髅有80%概率会是[焦骸](焦骸.md)，其余情况则会是骷髅。

# = 刷怪笼 =
[废弃矿井](废弃矿井.md)中可能生成包含洞穴蜘蛛[刷怪笼](刷怪笼.md)的结构。

# = 试炼刷怪笼 =
[试炼密室](试炼密室.md)中的小型近战型[试炼刷怪笼](试炼刷怪笼.md)包含洞穴蜘蛛试炼刷怪笼。

# 行为
洞穴蜘蛛沿袭了普通[蜘蛛](蜘蛛.md)的大多数特性：
* 当亮度等级小于等于11时主动攻击[玩家](玩家.md)、[铁傀儡](铁傀儡.md)和，亮度等级大于等于12时则不主动攻击。
* 拥有发亮的纹理，在暗处也清楚可见，但不会影响周围方块的实际[亮度](亮度.md)。
* 需要时会攀爬侧面碰撞箱完整的方块。它们还会攀爬[世界边界](世界边界.md)。它无法攀爬[岩浆块](岩浆块.md)，但当它与其他生物相互挤压时，则可能导致其爬上岩浆块。
* 通过猛扑进行近战攻击。
* 不受[蜘蛛网](蜘蛛网.md)和[中毒](中毒.md)效果的影响。
*
* 属于[节肢动物](节肢动物.md)，受[节肢杀手](节肢杀手.md)魔咒所影响。
* <ref></ref>
*
* 会主动远离或内未蜷缩的[犰狳](犰狳.md)。

但是，与普通蜘蛛相比，洞穴蜘蛛也有不同之处：
* 可穿过1格宽0.5格高的空间。
* 能够穿过下界砖[栅栏](栅栏.md)和普通栅栏之间的空隙。
* 生成时不会自带[状态效果](状态效果.md)。

洞穴蜘蛛的攻击在普通难度下会施加7秒[中毒](中毒.md)I，在困难难度下会施加15秒中毒I。<ref></ref>

# = 生物族群 =

洞穴蜘蛛是[节肢生物](节肢生物.md)，被具有[节肢杀手](节肢杀手.md)魔咒的武器近战攻击时会受到额外的伤害并被施加数秒的[緩速](緩速.md)IV效果。

# 你知道吗
* 洞穴蜘蛛的纹理分辨率比普通蜘蛛高——这是因为它的纹理所占的面积比较小。
* 洞穴蜘蛛的碰撞箱体积只有普通蜘蛛碰撞箱体积的13.9%，但它的模型体积却占普通蜘蛛的34.3%。洞穴蜘蛛的阴影更大，覆盖了49%的区域。
