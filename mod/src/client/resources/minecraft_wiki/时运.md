# 时运

*页面ID: 19754* | *来源: Minecraft Wiki*

* *时运（Fortune）**是一种用于[挖掘工具](工具.md)的[魔咒](魔咒.md)，能够使破坏方块后[掉落物](掉落物.md)数量的期望值增加。

# 获取

# 用途
时运与[精准采集](精准采集.md)被应用在同一个物品上时，对于同时受二者影响的方块，精准采集优先生效。

# = 矿石 =
对于[煤矿石](煤矿石.md)、[铁矿石](铁矿石.md)、[铜矿石](铜矿石.md)、[金矿石](金矿石.md)、[钻石矿石](钻石矿石.md)、[绿宝石矿石](绿宝石矿石.md)、[青金石矿石](青金石矿石.md)、[下界金矿石](下界金矿石.md)和[下界石英矿石](下界石英矿石.md)和[紫水晶簇](紫水晶簇.md)，I级有33%的概率将掉落物数量乘以2（平均掉落增加33%），II级有概率将掉落物数量乘以2或3（各25%概率，平均掉落增加75%），III级有概率将掉落物数量乘以2、3或4（各20%概率，平均掉落增加120%）。对每个等级，掉落一个物品的权重是2，掉落其他数量物品的权重是1。掉落倍率期望公式为<math>\frac{X+1}{2}+\frac{1}{X+2}</math>，式中<math>X</math>为时运的等级。

# = 离散随机 =
[荧石](荧石.md)、[西瓜](西瓜.md)、[下界疣](下界疣.md)、[红石矿石](红石矿石.md)、[甜浆果丛](甜浆果丛.md)、</ref>}}、[嘎枝之心](嘎枝之心.md)的掉落数量服从，这意味着每个掉落数量都是等可能出现的。时运将会以离散型均匀分布额外掉落0至<魔咒等级>个物品，但是总掉落数量不会超过物品自身掉落数量的上限：荧石最多掉落4个[荧石粉](荧石粉.md)，海晶灯最多5个[海晶砂粒](海晶砂粒.md)，西瓜最多9个[西瓜片](西瓜片.md)，嘎枝之心最多掉落9个[树脂团](树脂团.md)。超出上限的掉落尝试将被缩减至上限。

# = 草丛 =
[矮草丛](矮草丛.md)和[蕨](蕨.md)有着固定的概率掉落[小麦种子](小麦种子.md)，不受时运影响。如果会掉落物品，时运会使其以离散型均匀分布随机掉落1至1+2×<魔咒等级>个物品。

# = 农作物 =

# = 预设概率掉落 =
时运会提高[沙砾](沙砾.md)中掉落[燧石](燧石.md)、[树叶](树叶.md)中掉落[树苗](树苗.md)和[木棍](木棍.md)、橡树和深色橡树树叶中掉落[苹果](苹果.md)、[镶金黑石](镶金黑石.md)中掉落[金粒](金粒.md)以及[垂泪藤](垂泪藤.md)和[缠怨藤](缠怨藤.md)掉落自身的概率。

这些概率是预设的固定值而非算法计算得出的，更高等级时运魔咒只会使用已定义概率的最高等级。
