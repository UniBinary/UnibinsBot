# 雪块

*页面ID: 6381* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}
* *雪块（Snow Block）**是用[雪](雪.md)做成的完整方块。

# 生成
# = 自然生成 =
雪块自然生成在[冰刺之地](冰刺之地.md)、[冻洋](冻洋.md)、[雪林](雪林.md)、[积雪山坡](积雪山坡.md)、[尖峭山峰](尖峭山峰.md)、[冰封山峰](冰封山峰.md)生物群系中，也会作为[雪屋](雪屋.md)的墙壁和雪原[村庄](村庄.md)中一些房屋的墙壁生成。

# 获取
被具有[精准采集](精准采集.md)的锹挖掘破坏时，8层的[雪](雪.md)被破坏后会掉落1个雪块。<ref></ref>

# 破坏
挖掘雪块的合适工具是锹。雪块需要木锹或品质更好的锹来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，雪块被破坏后会掉落4个[雪球](雪球.md)。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，雪块被破坏后会掉落自身。

# 用途
与[雪](雪.md)不同，雪块既不会在高亮度等级的光源下融化，也不会被水摧毁。

# = 雪傀儡 =
|雪傀儡构建方法。}}
雪块能用来制造[雪傀儡](雪傀儡.md)。放2个雪块，可以竖放或横放，然后在雪块一端再放1个[雕刻南瓜](雕刻南瓜.md)或[南瓜灯](南瓜灯.md)就能生成雪傀儡，注意雕刻南瓜或南瓜灯必须要最后放置。
