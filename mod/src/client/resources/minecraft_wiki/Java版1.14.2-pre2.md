# Java版1.14.2-pre2

*页面ID: 43240* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14.2-pre2**是[Java版1.14.2](Java版1.14.2.md)的第2个预发布版，发布于2019年5月17日<ref></ref>，加入了新的字体，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[字体](字体.md)**
* 加入了默认的越南文字体。
* 更改了默认亚美尼亚文字体中的一个字符。
* 加入了默认的希伯来语和亚美尼亚语字体中缺少的字形。
