* *毒马铃薯植物（Poisonous Potato Plant）**，简称**P.P.P.**，是会通过任务引导[玩家](玩家.md)的[物品](物品.md)。

# 获取
# = 挖掘 =
破坏完全成熟的[马铃薯](马铃薯.md)作物时，有1%的概率掉落1个毒马铃薯植物。

当使用石镐或更好的镐开采[毒马铃薯矿石](毒马铃薯矿石.md)时，有5%的概率掉落1个毒马铃薯植物。使用附有[精准采集](精准采集.md)魔咒的镐开采毒马铃薯矿石不会掉落毒马铃薯植物。

任意方块被附有[薯化](薯化.md)魔咒的工具破坏时均有5%的概率掉落1个毒马铃薯植物。

# 用途
毒马铃薯植物使用普通的[毒马铃薯](毒马铃薯.md)的纹理。当玩家在物品栏中将鼠标指针悬停在毒马铃薯植物上时，其会出现的纹理层。虽然名叫植物，但并不能用于种植。

在物品栏中点击4次之后，毒马铃薯植物的提示框中会出现一条信息：“On closer inspection this  is a plant”（仔细端详，毒马铃薯是一名植“务”）

毒马铃薯植物可以放在玩家的-{}-头盔栏中，此时其会开始独白，内容显示在屏幕左上角。

玩家或完成特定任务后会触发毒马铃薯植物的下一句独白，或跳过其部分独白。如果玩家从头盔栏中取出毒马铃薯植物并放回，其会重复最后一句独白。

玩家死亡或掉入[马铃薯维度](马铃薯维度.md)的[虚空](虚空.md)后，独白的进度会被重置。
