# 命令/packstack

*页面ID: 175298* | *来源: Minecraft Wiki*

显示[资源包](附加包.md)和[行为包](行为包.md)数据。

# 语法
   <code>packstack <stackType: stackType> [verbose: verbose] [exclude-vanilla: exclude-vanilla]</code>

# 参数

   指定包的类型，必须为（资源包）或（行为包）。

   指定是否显示未启用的包和包的详细信息，必须为。

   指定是否排除原版包，必须为。
