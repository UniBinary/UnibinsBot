# 启动器2.3.645

*页面ID: 102805* | *来源: Minecraft Wiki*

* *2.3.645**是一次[启动器](启动器.md)更新，发布于2023年3月8日。

# 更改
* 改进了启动器中动画的显示方式。
* 更改了在启动器中选择用户名的过程。

# 修复
* 修复了一些与登录和启动器加载过程有关的漏洞。
*  - 滚动页面时“游玩”按钮会在屏幕顶部被切断。
*  - 输出日志会在游戏启动时关闭。
*  - 在低端设备上，加载界面的悦灵动画无法加载或运行缓慢。
