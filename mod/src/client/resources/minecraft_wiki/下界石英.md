# 下界石英

*页面ID: 9521* | *来源: Minecraft Wiki*

* *下界石英（Nether Quartz）**或简称**石英（Quartz）**，是开采[下界石英矿石](下界石英矿石.md)获得的矿物[物品](物品.md)。

# 获取
# = 挖掘 =
[下界石英矿石](下界石英矿石.md)被[镐](镐.md)挖掘会掉落1个下界石英。使用带有[时运](时运.md)魔咒的[镐](镐.md)挖掘会每等级增加1可能的下界石英数量，时运III最多会掉落4个下界石英。如果使用带有[精准采集](精准采集.md)魔咒的镐采集[下界石英矿石](下界石英矿石.md)，会掉落下界石英矿石而不是下界石英。

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家5-12个下界石英。
