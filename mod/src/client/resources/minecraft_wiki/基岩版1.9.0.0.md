# 基岩版1.9.0.0

*页面ID: 37199* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.9.0.0**是[1.9.0](基岩版1.9.0.md)的首个测试版，发布于2018年11月15日<ref></ref>，加入了第二批[村庄与掠夺](村庄与掠夺.md)的部分特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[花](花.md)**
* 加入了[矢车菊](矢车菊.md)。
* * 能合成[蓝色染料](蓝色染料.md)。
* * 出现在[平原](平原.md)生物群系。
* 加入了[铃兰](铃兰.md)。
* * 能合成[白色染料](白色染料.md)。
* * 出现在[森林](森林.md)生物群系。

* *平滑方块**
* 加入了平滑石头、平滑砂岩、平滑红砂岩、平滑石英块。
* *[告示牌](告示牌.md)**
* 加入了云杉木告示牌、白桦木告示牌、金合欢告示牌、丛林木告示牌、深色橡木告示牌。

* *[台阶](台阶.md)**
* 加入了石头台阶、安山岩台阶、磨制安山岩台阶、闪长岩台阶、磨制闪长岩台阶、花岗岩台阶、磨制花岗岩台阶、苔石砖台阶、苔石台阶、平滑砂岩台阶、平滑红砂岩台阶、平滑石英台阶、红色下界砖台阶、末地石砖台阶。
* 加入了切制砂岩台阶和切制红砂岩台阶。

* *[楼梯](楼梯.md)**
* 加入了石头楼梯、安山岩楼梯、磨制安山岩楼梯、闪长岩楼梯、磨制闪长岩楼梯、花岗岩楼梯、磨制花岗岩楼梯、苔石砖楼梯、苔石楼梯、平滑砂岩楼梯、平滑红砂岩楼梯、平滑石英楼梯、红色下界砖楼梯、末地石砖楼梯。

* *[墙](墙.md)**
* 加入了红砖墙、安山岩墙、闪长岩墙、花岗岩墙、海晶石墙、石砖墙、苔石砖墙、砂岩墙、红砂岩墙、下界砖墙、红色下界砖墙、末地石砖墙。

# = 生物 =
* *[掠夺者](掠夺者.md)**
* 敌对生物，被认为是[灾厄村民](灾厄村民.md)的一种。
* 有生命值。
* 手持[弩](弩.md)。
* 被杀死时掉落0–2 ，受[抢夺](抢夺.md)魔咒的影响，最多掉落5根。其手持的有8.5%的概率掉落（抢夺I时为9.5%，抢夺II时为10.5%，抢夺III时为11.5%），拥有随机耐久度并且可以被附魔。
* 会袭击或占领[村庄](村庄.md)，并杀死[村民](村民.md)。
* 不能穿戴任何种类的盔甲。
* 在生存模式下暂时无法生成。

# = 世界生成 =
* *竹林**
* [丛林](丛林.md)的新变种。
* 包含[竹子](竹子.md)，[灰化土](灰化土.md)和[熊猫](熊猫.md)。

# 更改
# = 方块 =
* *[苔石](苔石.md)**
* 英文名被重命名为“Mossy Cobblestone”。

* *[下界砖栅栏](下界砖栅栏.md)**
* 合成配方被改为4个下界砖块和2个下界砖。
* 原来的配方现在用于合成下界砖墙。

* *[砂岩](砂岩.md)**
* 平滑砂岩和平滑红砂岩现在被分别重命名为切制砂岩和切制红砂岩。

* *[告示牌](告示牌.md)**
* 普通的告示牌现在被重命名为橡木告示牌。
* 文本默认颜色被改为白色。
* 橡木告示牌现在需要橡木木板合成，而不是任意木板。

* *[石台阶](平滑石头台阶.md)**
* 普通的石台阶被重命名为平滑石头台阶。
* 现在需要平滑石头合成，而不是普通的石头。

* *[砂岩楼梯](砂岩楼梯.md)和[砂岩台阶](砂岩台阶.md)**
* 现在需要普通的砂岩合成，不再能使用变种合成。

* *[绊线钩](绊线钩.md)**
* 被破坏时会激活，除非使用剪刀。

* *[竹子](竹子.md)**
* 单条竹子现在能稀有地生成在丛林中。

* *[羊毛](羊毛.md)**
* 重命名为“白色羊毛”。

# = 世界生成 =
* *[要塞](要塞.md)、[丛林神庙](丛林神庙.md)和[村庄](村庄.md)**
* 将[圆石楼梯](圆石楼梯.md)替换为[石头楼梯](石头楼梯.md)。

# = 常规 =
* 增加了一些新的由社区建议的屏幕[加载提示](加载提示.md)。
* 当驯服的动物死亡时，现在会在聊天中通知。
* 提高了使用函数命令时的性能，它们现在在世界加载时预编译。

# 修复
* *修复了29个漏洞**
* 修复了游戏过程中出现的崩溃现象。
* 用铁门替代木门放置时游戏崩溃。（）
* 对着装有成书的箱子使用“选取方块”键时游戏崩溃。
* 更新了存储可用空间太低的信息。
* 资源包里的手持物品的纹理现在会正确显示。（）
* 使用触摸屏时，在水下的玩家会保持潜行姿势。（）
* 熊猫的喂食动画出错。
* 使用触摸屏时，手持弩与方块进行互动时会意外射箭。（）
* 手持弩时无法使用近战攻击。(）
* 三叉戟的投掷动画与弩的发射动画重叠。（）
* 使用触摸屏时，试图发射弩会导致玩家挖掘方块。（）
* 为缺失模板的世界加入了提示信息，便于玩家可以在市场重新下载这些模板。
* 改进了部分文本显示，文本框现在能够使用键盘来高亮选择。
* 角色创建器界面现在会显示加载动画。
* Nintendo Switch版的手持模式下，“保存到微软账户”信息丢失。
* 多人游戏下，玩家不再能自定义玩家权限。
* 修复了部分命令的相对坐标低于y3值的错误。（）
* 潜影盒在打开时不能推动实体。（）
* 试图加入不可用的世界时，弹出的错误信息现在更加详细。
* 使用触摸屏时，玩家的朝向会意外选择。（）
* 无法使用命令清除下落的方块。(）
* 在转换后的世界里，杀死末影龙不会掉落正确数量的经验值和生成龙蛋。（）
* 由精准采集工具采集而来的藤蔓现在可以用于旗帜合成配方。（）
* 末地折跃门在已经生成的区域里现在可以正常运作。（）
* 掉落物会卡在台阶和玻璃里。（）
* 改进了在市场界面里使用控制器或键盘时的导航操作。
* 修复了在加勒比海盗混搭包里的“Syrena”皮肤的动画效果损坏问题。
* 在复制循环型命令方块时，“保持激活”选项会重置。（）
* 加入世界后，时钟和指南针无法正常运作。（）</onlyinclude>
