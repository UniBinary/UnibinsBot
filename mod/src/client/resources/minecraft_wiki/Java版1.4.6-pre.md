* *1.4.6（预发布版）**是[Java版1.4.6](Java版1.4.6.md)的唯一一个预发布版，发布于2012年12月17日。<ref></ref>

# 更改
# = 物品 =
* *[弓](弓.md)**
* 当玩家从远处用弓击中另一玩家时，会发出尖鸣声。

# = 常规 =
* *[选项](选项.md)**
* 加入了切换触屏模式的选项。
