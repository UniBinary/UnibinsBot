* *南瓜灯（Jack o'Lantern）**是一种可用于[照明](照明.md)的[固体方块](固体方块.md)。

# 生成
# = 自然生成 =
南瓜灯生成在针叶林[村庄](村庄.md)的[南瓜堆](南瓜堆.md)中。

# 破坏
挖掘南瓜灯的合适工具是斧和剑。

南瓜灯被破坏后会掉落自身。

# 用途
玩家直接放置的南瓜灯会朝向玩家。南瓜灯没有上下朝向。

南瓜灯只在渲染时表现为透明的，其他情况下拥有固体方块共有的属性。例如，南瓜灯可以[窒息](窒息.md)生物，其上可以生成生物，其上面或侧面也可以放置必须附着于其他方块上的方块（如[火把](火把.md)、[红石粉](红石粉.md)）。

南瓜灯不能被[活塞](活塞.md)拉动，被推动时会被破坏并掉落。

# = 光源 =
[缩略图|南瓜灯可用作水下照明](File:Underwater Jack o'lanterns.png.md)
南瓜灯会发出亮度等级为15的光。如同大部分[光](光.md)源一样，它会融化一定范围内的[雪](雪.md)和[冰](冰.md)。

# = 建造生物 =

南瓜灯可摆放在下图所示的结构来建造[铁傀儡](铁傀儡.md)、[雪傀儡](雪傀儡.md)和[铜傀儡](铜傀儡.md)，结构可任意旋转。铁傀儡、雪傀儡和铜傀儡分别需要[铁块](铁块.md)、[雪块](雪块.md)和[铜块](铜块.md)（所有氧化与涂蜡变种）作为身体。

建造时南瓜灯必须在最后放置，否则生物不会生成。建造铁傀儡时，图中的4个空位置（即“双臂”的上方和下方）必须是空气方块，否则铁傀儡不会生成。

南瓜灯可以由[玩家](玩家.md)或放置。
