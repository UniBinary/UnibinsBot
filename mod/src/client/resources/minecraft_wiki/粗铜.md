# 粗铜

*页面ID: 81152* | *来源: Minecraft Wiki*

* *粗铜（Raw Copper）**是一种从[铜矿石](铜矿石.md)中获得的粗金属资源。

# 获取
# = 挖掘 =
当使用未带有[精准采集](精准采集.md)魔咒的[石镐](石镐.md)或更好的镐挖掘[铜矿石](铜矿石.md)、[深层铜矿石](深层铜矿石.md)时，会掉落2-5个粗铜。每1级[时运](时运.md)魔咒使得掉落数量上限增加5个，使用时运III最多可掉落20个。
