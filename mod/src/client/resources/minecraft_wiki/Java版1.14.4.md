# Java版1.14.4

*页面ID: 44799* | *来源: Minecraft Wiki*

* *1.14.4**是的一次次要更新，发布于2019年7月19日<ref></ref>，略微修改了村民和服务器权限，为命令加入了一个新的参数，此外还加入了新的闪烁标语，并修复了一些漏洞。此版本不兼容1.14到1.14.3的服务端。

# 新内容
# = 命令格式 =
* ***
* 加入了
* * 用于在调试性能时获取更详细的信息，例如每个维度中[区块](区块.md)和[方块实体](方块实体.md)的列表。
* ** 将信息以一个<samp>.zip</samp>文件保存在<samp>[.minecraft](.minecraft.md)/debug</samp>文件夹下。

* *<samp>[server.properties](server.properties.md)</samp>**
* 在<samp>server.properties</samp>中加入了，用于控制[函数](Java版函数.md)拥有的权限等级。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了“Ping the human!”。

# 更改
# = 物品 =
* *[谜之炖菜](谜之炖菜.md)**
* 由[虞美人](虞美人.md)合成的谜之炖菜现在会给予玩家[夜视](夜视.md)效果而不是[迅捷](迅捷.md)。

# = 生物 =
* *[村民](村民.md)**
* 现在会自愿拾起物品。
* 现在交易被锁定前可以进行更多次。
* 现在转变成[僵尸村民](僵尸村民.md)后仍能记住其言论。
* * 关于玩家转变[僵尸村民](僵尸村民.md)的言论现在会持续更长时间。
* 现在即使无法补货也可以进行工作了。
* * 除播放工作的音效外，这不会有任何表现。
* 提升了寻路能力。

* *[掠夺者](掠夺者.md)**
* 更改了手臂纹理。

# = 命令格式 =
* *权限**
* 权限等级2现在可以使用和了。

# = 常规 =
* *视角**
* 在第一人称视图中删除了视角中心偏移。

* *<samp>[client.jar](client.jar.md)</samp>**
* 将[Realms](Realms.md)代码重新整合到客户端中，存于<samp>com.mojang.realmsclient.dto</samp>包<!--package-->内。
* 将Realms资源重新加入客户端。

* *性能**
* 性能优化。
* 优化了[树叶](树叶.md)渲染性能。
* 优化了高速移动时的[区块](区块.md)加载性能。

* *[Realms](Realms.md)**
* 移除了Realms界面上的“Player Activity”活动按钮。
