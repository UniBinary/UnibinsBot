# 社交屏幕

*页面ID: 80875* | *来源: Minecraft Wiki*

* *社交屏幕（Social Interactions screen）**是用于屏蔽特定[玩家](玩家.md)发言及举报玩家的界面。

# 用途
在多人游戏中，按下指定键（默认为）可以打开社交屏幕。“”栏目展示所有玩家，“”栏目显示了聊天记录被隐藏的玩家，“”栏目显示了根据微软账户屏蔽的玩家。

社交屏幕只能在[多人游戏](多人游戏.md)世界里打开，在单人游戏中尝试进入社交屏幕会消息“”。

在社交屏幕中还可以举报其他玩家聊天中的不当发言、玩家皮肤和玩家名称。其中可供举报的聊天类型有：

可附加评论以提供与举报相关的更多的细节和信息。

[Realms](Realms.md)上的聊天在未被举报的情况下也会被自动监控。

举报可能的处理结果有：
* 不采取任何措施。
* 临时或永久禁止多人游戏。
* 禁止使用被举报的皮肤。
* 禁止使用被举报的玩家名称。
被封禁的玩家进入游戏后会收到封禁通知，告知该玩家被封禁的原因和封禁时长。如果皮肤被封禁，被举报玩家以及其他所有使用相同皮肤的玩家将会被重置为默认皮肤。如果玩家名称被封禁，被举报玩家会被禁止进行多人游戏，直到其更改名称。

只有使用Mojang分发给Minecraft账户的密钥签名过的消息可被举报。这意味着玩家可以使用[Mod](Mod.md)发送未签名的消息来避免被举报。然而，这类未签名的消息会被客户端标记为“未经验证”，并可以通过在[选项](选项.md)中的聊天设置中启用“”隐藏这类消息；如果服务器在[server.properties](server.properties.md)中启用了<code>enforce-secure-profile</code>，玩家无法发送未经验证的消息。此外，由于[第三方服务器](定制服务器.md)所用软件的技术原因（如更改聊天样式的[Mod](Mod.md)会将玩家消息转化为服务器消息），或者服务器管理员主动安装禁用举报的Mod等，大部分第三方服务器并未启用举报功能。这意味着这类服务器上所有玩家的消息都不能被举报，且“”无法隐藏任何消息，因其并不能隐藏服务器消息。
