# Java版1.12.1

*页面ID: 31903* | *来源: Minecraft Wiki*

* *1.12.1**是的一次次要更新，发布于2017年8月3日<ref name="article_1.12.1"></ref>，修复了一些漏洞。此版本不兼容1.12的服务端。

# 更改
# = 常规 =
* *[胜利屏幕](胜利屏幕.md)和[鸣谢与著作权说明屏幕](鸣谢与著作权说明屏幕.md)**
* 更新了制作人员名单，现在包含更多[Mojang](Mojang.md)职员。
* [鸣谢与著作权说明屏幕](鸣谢与著作权说明屏幕.md)的滚动速度比[胜利屏幕](胜利屏幕.md)快50%。

* *[闪烁标语](闪烁标语.md)**
* 移除了“Better than Prey!”。
