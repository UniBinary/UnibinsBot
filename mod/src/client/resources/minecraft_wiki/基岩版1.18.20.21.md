# 基岩版1.18.20.21

*页面ID: 92539* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.20.21**是[基岩版1.18.30](基岩版1.18.30.md)的首个测试版<ref></ref>，发布于2022年1月27日<ref></ref>，更新了[创建新世界](创建新世界.md)UI，在[实验性玩法](实验性玩法.md)中调整了[青蛙](青蛙.md)相关特性，并修复了一些漏洞。

此版本于2022年1月31日在iOS/iPadOS平台上以**Preview 1.18.20.22**发布。

# 更改
# = 生物 =
* *[狼](狼.md)**
* 未驯服的狼现在可以被[拴绳](拴绳.md)拴住。

# = 游戏内容 =
* *[交易](交易.md)**
* 更改了[盔甲匠](交易#盔甲匠.md)、[牧师](交易#牧师.md)、[渔夫](交易#渔夫.md)、[牧羊人](交易#牧羊人.md)、[工具匠](交易#工具匠.md)和[武器匠](交易#武器匠.md)的交易选项以匹配。
* * 渔夫村民现在会根据其生物群系服饰而出售不同种类的[船](船.md)。
* * 牧师村民现在会出售[荧石](荧石.md)而不是[荧石粉](荧石粉.md)。
* * 武器匠出售附魔[铁剑](铁剑.md)所需的级别更改为新手级别。
* * 盔甲匠收购[钻石](钻石.md)所需的级别更改为老手级别。

# = 命令格式 =
* *[目标选择器](目标选择器.md)**
* 加入了过滤器。
* * 用于根据物品栏中的物品或穿戴的物品来定位实体。

# = 常规 =
* *[创建新世界](创建新世界.md)**
* 重新设计了新的创建新世界UI。
* * 仅部分玩家可用。
* * 可切换回旧UI。

* *[实验性玩法](实验性玩法.md)**
* 移除了“其他修改功能”子选项。

* *[RenderDragon](RenderDragon.md)**
* 重新在Android平台上启用。

* *[种子](种子（世界生成）.md)**
* 现在支持使用64位种子。

# = 技术性 =
* *常规**
* 为或更低的世界现在会提升至，并且世界的的范围由仅使用64位种子的后32位更改为使用完整64位种子，但仍然表示着之前相同的数字。
* * 该更改仅和正负号位需要扩展的负数32位种子相关。

* *命令**
* 加入了命令的重载。
* 实体现在必须加载在一个区域中才能被视为已完全加载并滴答。

* *Molang**
* 在活动对象资源定义的动画（）中的包含大写字母的Molang表达式现在可以使用1.18.20或更高版本的format_version以正确计算。

* *用户界面**
* 现在加载进度屏幕会在加载被标记为的常加载区域时显示。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“荒野更新”、“即将推出的创作者功能”和“应用测试框架”子选项后才可使用。

# = 方块 =
* *[青蛙卵](青蛙卵.md)**
* 英文名由“Frog Egg”更改为“Frog Spawn”。
* 略微更改了纹理。
* 增加了孵化出[蝌蚪](蝌蚪.md)的所需时间。

# = 生物 =
* *[青蛙](青蛙.md)**
* 提高了跳跃频率。
* 现在生成于[草甸](草甸.md)的青蛙为温带（橙色）变种。
* 调整了跳跃和吐舌头时的动画。

* *[蝌蚪](蝌蚪.md)**
* 增大了碰撞箱。

# = 游戏内容 =
* *动画**
* 清理了青蛙的动画、实体和控制器文件。
* 青蛙的水中和游泳动画由线性动画更改为平滑动画。

# 修复
* *原版趋同**
* 现在可以使用64位种子（-9223372036854775808至9223372036854775807）来创建世界，会生成与Java版相同的世界。（、）
* 现在非数字种子会转化为与Java版相同的种子。
* 玩家拉弓并蓄力完成时手臂不再会摆动。（）
* 现在下落的方块又具有完整方块的碰撞箱了。
* 修复了老手级别的牧师村民会出售荧石粉而不是荧石的漏洞。（）
* 未驯服的狼现在可以被拴绳拴住。（）

* *方块**
* 现在点燃的TNT可以正确地随机向X/Z方向移动。
* 修复了快速破坏并放置方块后掉落的物品有时会保持变黑的问题。
* 雪下落时不再会卡在下方方块的边缘。

* *游戏内容**
* 修复了唤魔者召唤的唤魔者尖牙无法在无边界框的方块中生成的问题。
* 现在可以对着如光源方块、大型垂滴叶等可含水的方块使用水桶或熔岩桶。（）
* 访客权限的玩家不再可以破坏画和矿车。（）
* 现在垂直传送至渲染距离之外的高度时会正确加载地形。（）
* 提高了伤害计算的准确性。
* 修复了手持可蓄力物品与钟交互时无法连续敲钟的问题。（）
* 修复了穿戴鞘翅的玩家在某些情况下骑行会切换至滑翔状态的漏洞。（）

* *生物**
* 生物现在能够越过杜鹃花丛。（）
* 生物现在能够越过未完全倾斜的大型垂滴叶，并在其上正确寻路。
* 生物现在能够越过石笋，并在其尖端正确寻路。（）
* 生物现在能够在如钟、酿造台和附魔台等不完整固体方块上移动。
* 生物现在能够在不完整固体方块跳跃到更高位置的完整方块上。
* 生物现在能够在台阶或其他足够高的不完整固体方块跳跃到毗邻的栅栏上。
* 现在即使上方已有方块的空间与生物高度一致，生物也可以穿过不到半格的雪。（）
* 生物现在能够越过珊瑚和珊瑚扇，因为生物不再将其视作固体障碍物。（）
* 修复了玩家手持刷怪蛋时无法打开村民的交易界面的问题。（）
* 修复了袭击期间生成的女巫可能会在袭击期间消失的问题。（）
* 鳕鱼、鲑鱼、河豚、热带鱼和海豚现在又会正确生成于其对应海洋生物群系的深海变种。（）

* *性能与稳定性**
* 修复了在更衣室中离开缩小菜单时可能发生的崩溃。

* *用户界面**
* 将Pocket UI下的物品栏中的默认标签更改为左侧的“可合成”和右侧的“合成中”标签。
* 移除了Pocket UI下的物品栏中的问号按钮。
* 不使用工作台合成时配方表中不再会显示3×3方格的合成配方。
* 玩家现在能够在Pocket UI下的工作台界面使用自由移动来脱下和装备盔甲。（）
* 更新了移动设备上的常规控制器面板图标。
* 现在按下会删除输入光标前方的整个单词。
* 现在按下会删除输入光标后方的整个单词。
* 现在按下会将输入光标移动到光标之前的单词的开头。
* 现在按下会将输入光标移动到光标之后的下一个单词的开头。

* *村民**
* 修复了玩家手持绿宝石时村民不会手持交易物品的问题。（）
* 村民不再会远离僵尸猪灵。（）
* 村民不再会分享小麦种子和甜菜种子。</onlyinclude>
