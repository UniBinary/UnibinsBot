# 用途

使用命名牌前需要将其在[铁砧](铁砧.md)进行命名，并始终消耗1个[经验](经验.md)等级（无论一次命名几个命名牌），拥有相同名称的命名牌是可以堆叠的。没有重命名过的命名牌无法使用。

之后玩家可以通过键将命名牌上的名字命名给生物。除[末影龙](末影龙.md)和[玩家](玩家.md)以外的所有生物都能被命名牌命名。一旦生物被命名，这个名字将会被保留并消耗掉1个命名牌。生物和命名牌都可以无限次重命名。即使某一生物已拥有与命名牌相同的名字，该命名牌仍能对其消耗。

被命名的幼年动物和村民在成年时仍会保留名字。被命名的村民变成僵尸村民时会保留名字，被治愈的僵尸村民也会保留名字。然而，被命名的[蠹虫](蠹虫.md)在侵入方块后名字会消失，因为破坏该方块后它会被一只新生成的蠹虫取代。

# = 效果 =
当玩家屏幕准星指向被命名的生物，且距离足以触及该生物时，生物上方会出现悬浮的名字。

盔甲架的名字不会显示，除非设置了<code>CustomNameVisible:1b</code>；[盔甲架](盔甲架.md)可以像其他生物一样正常显示名字。

被命名的生物不会在这个世界中自然消失，但[流浪商人](流浪商人.md)是例外。

被命名的生物不会被算入生物容量里。

如果一个被命名的生物杀死了玩家或驯服的生物，这个名字将会在死亡消息中代替击杀者的生物类型显示。

被重命名的[凋灵](凋灵.md)会在Boss栏上显示重命名后的名称。

# = 彩蛋 =

* 名称为“jeb_”的[绵羊](绵羊.md)的毛色会随时间不断变化。但它掉落的羊毛是被命名之前的原始颜色。该绵羊被剪毛后身上残留的羊毛仍会保持变色。
* 名称为“Toast”的[兔子](兔子.md)的纹理会变成黑白斑块，纪念一位玩家丢失的兔子。
* 名称为“Johnny”的[卫道士](卫道士.md)会主动攻击除[灾厄村民](灾厄村民.md)、[恶魂](恶魂.md)、</ref>、幼年[村民](村民.md)<ref></ref><ref></ref>}}、以外的任何生物。
* 名称为“Dinnerbone”或“Grumm”的</ref>}}生物的模型会上下颠倒。

# 你知道吗
* 命名牌的加入源于[Paul Soares Jr.](https://www.youtube.com/user/paulsoaresjr/)的请求。<ref></ref><ref></ref>
* 要用命名牌把一个生物命名为“命名牌”，玩家可先把这个命名牌改成其他名字，再重命名回“命名牌”；也可将游戏语言改为其他语言后再重命名。
* 如果一个被命名的生物发生了变化，那么该生物的名称会保留下来，包括：
* * [猪](猪.md)被闪电劈中后变成[僵尸猪灵](僵尸猪灵.md)，[苦力怕](苦力怕.md)被闪电劈中后变成[闪电苦力怕](闪电苦力怕.md)，[村民](村民.md)被闪电劈中后变成[女巫](女巫.md)，红色[哞菇](哞菇.md)与棕色哞菇在闪电之间互相转化。
* * [史莱姆](史莱姆.md)和[岩浆怪](岩浆怪.md)如果发生了分裂，那么在分裂后，每个史莱姆或岩浆怪都会带有相同的名称。
* * 村民被感染为[僵尸村民](僵尸村民.md)，僵尸村民被治愈成村民。
* * [僵尸](僵尸.md)在水中变成[溺尸](溺尸.md)，[尸壳](尸壳.md)在水中变成僵尸。
* * [猪灵](猪灵.md)和[猪灵蛮兵](猪灵蛮兵.md)在下界以外的维度变成僵尸猪灵，[疣猪兽](疣猪兽.md)在下界以外的维度变成[僵尸疣猪兽](僵尸疣猪兽.md)。
* * [骷髅](骷髅.md)在[细雪](细雪.md)中变成[流浪者](流浪者.md)。
