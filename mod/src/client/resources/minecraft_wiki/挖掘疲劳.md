# 挖掘疲劳

*页面ID: 37928* | *来源: Minecraft Wiki*

* *挖掘疲劳（Mining Fatigue）**是一种降低挖掘速度的[状态效果](状态效果.md)。

# 效果
受影响玩家的挖掘速度在1级降低至30%,在2级降低至9%，在3级降低至0.27%，在4级时达到最大限度0.081%。受影响玩家的近战攻击速度降低10%×效果等级。

受影响玩家的挖掘速度降低至0.21的效果等级次方，没有最大限度。

玩家杀死[美西螈](美西螈.md)的攻击目标时，会解除自身的挖掘疲劳效果。

# 来源
[远古守卫者](远古守卫者.md)或</ref>}}会搜寻一次半径50格内没有被1分钟或更长的挖掘疲劳III影响的玩家。被发现的玩家将会获得5分钟的挖掘疲劳III效果，同时一幅吓人的远古守卫者“鬼影”会出现在游戏屏幕，还带有可怕的音效。
