# Java版1.21.1

*页面ID: 124712* | *来源: Minecraft Wiki*

* *1.21.1**是的一次热修复更新，发布于2024年8月8日<ref></ref>，修复了2个严重漏洞。此版本兼容1.21的服务端。

# 新内容
# = 常规 =
* *[语言](语言.md)**
* 加入了对索西语和白俄罗斯语（拉丁字母）的支持。

# 修复

* *未公开漏洞**
* 基于方块实体替换，使得方块实体无法正常获取数据而产生类型转换异常或非法参数异常造成的更新抑制及服务端崩溃。
* 权限不足的玩家能借助修改过的客户端，滥用目标选择器的命令建议，导致服务器溢出而崩溃。
