# Java版Classic服务器1.3

*页面ID: 45305* | *来源: Minecraft Wiki*

* *1.3**是[Classic](Java版Classic.md)服务器的一次更新，发布于2009年6月10日。<ref></ref>

# 新内容
# = 游戏内容 =

* *[聊天](聊天.md)**
* 聊天栏现在会显示最近消息的完整日志了。

# = 命令格式 =
* ***
* 管理员命令。
* 用于将当前位置设置为新玩家的默认出生点。

# = 常规 =
* *[控制](控制.md)**
* 按现在会显示所有登录到服务器的玩家。

* *其他**
* 名称安全性。
* 服务器侧的客户端验证。
* 增加了服务器文件。

# 更改
# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 在多人游戏中不再显示“level generation”和“loading”了。

# = 命令格式 =
* ***
* 效果更直观。

# = 常规 =
* *其他**
* 修改了私有服务器地址的处理行为。

# 修复
* *修复了5个漏洞**
* 修复了服务器心跳包导致游戏暂停的问题。
* 修复了在玩家登录时，他们的出生点会改为默认位置的问题。
* 修复了游戏不能在Mac OS上启动的问题。
* 客户端不再能滥发ping请求了。
* 修复了可被用于批量放置方块的服务器漏洞，玩家不再能利用这些漏洞制造熔岩泛滥等破坏性效果。
