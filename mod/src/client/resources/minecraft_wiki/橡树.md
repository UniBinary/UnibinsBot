橡树是一种常见的植被[地物](地物.md)，分为**普通橡树（Oak）**、**珍异橡树（Fancy Oak）**、**沼泽橡树（Swamp Oak）**、和**倒下的橡树（Fallen Oak）**。

# 种类
[缩略图|右|普通橡树、小型珍异橡树、大型珍异橡树和沼泽橡树](File:OakTrees.png.md)

# = 普通橡树 =
普通橡树有着4格高的树冠。其整体高度为5-7格；高度为5-8格。

# = 珍异橡树 =
这类橡树比较罕见，有着更繁茂的团状树冠。

小型珍异橡树的高度与普通橡树相似。其树干没有分杈，树冠呈较为规整的球形。

在生长空间足够时，珍异橡树能长出多条横向的原木分杈，主干及分杈都托着5格厚的团状叶簇，使得树冠旁侧明显突出，成为较巨大的珍异橡树。大型珍异橡树的高度可以达到18格。

# = 沼泽橡树 =
沼泽橡树的树冠为4格高，但比普通橡树更宽更平坦，且树叶上附有[藤蔓](藤蔓.md)。其整体高度为6-9格；高度为6-10格。

# = 覆藤橡树 =

覆藤橡树也叫做濒死的橡树。除了其暴露的原木爬满藤蔓外，覆藤橡树与普通橡树在外观上并无差别。

# = 倒下的橡树 =
倒下的橡树包含一个单独的纵向原木作为树桩，距其一两格远的地方另有0-5块平躺的原木。树桩的每个侧面有75%的概率附着藤蔓，有时这些原木上会出现[蘑菇](蘑菇.md)。

# 生成
橡树生成时会将下方1格的方块转变为[泥土](泥土.md)。

# = 自然生成 =
生物群系放置树木地物时，每种树木的生成概率如下表所示：

[缩略图|右|带有蜂巢的普通橡树](File:Oak Tree with Bee nest.png.md)
在[平原](平原.md)、[向日葵平原](向日葵平原.md)、[森林](森林.md)和[繁花森林](繁花森林.md)自然生成的橡树有很小的概率带有[蜂巢](蜂巢（方块）.md)，而在[草甸](草甸.md)自然生成的珍异橡树总会带有蜂巢。每个由此方式生成的蜂巢都会容纳3只[蜜蜂](蜜蜂.md)。

[平原村庄](村庄.md)自然生成时，其道路旁和一些牲畜栏中会放置普通橡树。

# = 人为生成 =
[亮度](亮度.md)等级至少为9且有一定的空间时，[橡树树苗](橡树树苗.md)可长成普通橡树、珍异橡树或。沼泽橡树和倒下的橡树无法由树苗长成。<ref></ref>

若橡树树苗的水平2格范围内存在[花](花.md)、[红树胎生苗](红树胎生苗.md)、[盛开的杜鹃花丛](盛开的杜鹃花丛.md)、[盛开的杜鹃树叶](盛开的杜鹃树叶.md)、[樱花树叶](樱花树叶.md)、[粉红色花簇](粉红色花簇.md)、[野花簇](野花簇.md)、[紫颂花](紫颂花.md)、[孢子花](孢子花.md)或[仙人掌花](仙人掌花.md)，则长成的橡树会有5%的概率悬挂着蜂巢；橡树树苗长成的橡树总会有5%的概率悬挂着蜂巢<ref></ref>。每个由此方式生成的蜂巢都会容纳1-3只蜜蜂。

# 你知道吗
* Minecraft中的橡树基于现实中的[白橡](wzh:北美白橡.md)。
* 平原[村庄](村庄.md)的会合点3（）和[试炼密室](试炼密室.md)的入口1（）结构都自带一棵橡树，但它们属于结构的一部分而非真正的橡树地物，且后者的外形异于真正的橡树地物。
