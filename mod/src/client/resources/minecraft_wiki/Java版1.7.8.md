# Java版1.7.8

*页面ID: 31610* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.7.8**是的一次次要更新，发布于2014年4月11日<ref></ref>，是修复[Java版1.7.7](Java版1.7.7.md)中一些崩溃与有关[皮肤](皮肤.md)的漏洞更新<ref></ref>。此版本不兼容1.7.2到1.7.5的服务端，兼容1.7.6和1.7.7的服务端。

# 更改
# = 常规 =
* *Twitch直播**
* 现在会在开始直播前询问，以免产生意外。

* *[服务器](服务器.md)**
* 客户端会自动在23小时59分钟后踢出玩家。<ref></ref>
