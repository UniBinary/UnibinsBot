* *Minecraft Dungeons**，又名Minecraft：地下城，是一款动作/冒险角色扮演类电子游戏，由[Mojang Studios](Mojang Studios.md)、和[Double Eleven](Double Eleven.md)共同开发。它于2020年5月26日发布在PC、Nintendo Switch、PS4和Xbox One平台，并在2020年11月10日向后支持发布在Xbox Series X&#124;S平台，之后于2021年9月22日发布在Steam平台。Windows 10，Windows 11和Xbox版本同样可以通过Xbox Game Pass进行游戏，也可以通过Xbox云游戏在手机端进行游戏。<ref name="Website"/>基础游戏价格为19.99（144，Microsoft Store为69，154，19.99，16.74，29.95)，英雄版（已停售）价格为29.99（214，Microsoft Store为106，234，29.99，24.99，39.95)，并包含额外的[披风](MCD:披风.md)，[宠物](MCD:宠物.md)，以及[觉醒丛林](MCD:觉醒丛林.md)和[悚伏寒冬](MCD:悚伏寒冬.md)两个DLC，普通版可通过购买[英雄通行证](MCD:英雄通行证.md)（已停售）和购买带有四个DLC的第二个扩展包[季票](MCD:季票.md)进行补齐（已停售）或者直接购买[终极版DLC捆绑包](MCD:终极版DLC捆绑包.md)，价格为144（19.99）。[终极版](MCD:终极版.md)包括游戏本体和全部六个DLC，价格为284（39.99）。[1.12.0.0](MCD:1.12.0.0.md)中增加了[冒险通行证](MCD:冒险通行证.md)，共推出三个赛季，价格均为28（3.99）。

目前游戏可在[官网](https://minecraftdungeons.net/)、[Microsoft Store](https://microsoft.com/p/minecraft-dungeons/9P8MK4NC0LJB)和[Steam](https://store.steampowered.com/app/1672970/Minecraft_Dungeons/)进行购买<ref name=get-dungeons>[minecraft.net/get-dungeons](https://minecraft.net/get-dungeons)</ref>。

2023年9月28日，官方宣布游戏不再更新，[1.17](MCD:1.17.md)成为游戏的最后一个版本。<ref></ref>

# 官方游戏介绍
这款全新的动作冒险游戏以经典的地下城迷宫探索为灵感，背景设置在Minecraft世界，在这款游戏中进行战斗！独自勇闯地下城，或与朋友组队！最多可以四名玩家在动感十足、充满宝藏、各不相同的关卡中一起战斗 — 参与史诗中的这一切都是为了拯救村民，打倒恶魔奇厄教主！

发现一大堆强大的新武器和物品，助你击败残酷无情的大群新的可恶怪物。战斗或逃出峡谷、沼泽——当然——还有矿山！足够勇敢或足够愚蠢的人才能够探索这个美丽的方块世界，任何一位冒险家都需要做好准备！那么赶紧的，准备好！

# 游戏内容

[314px|thumb|left|由Mojang发布的Minecraft Dungeons宣传图片](File:Minecraft Dungeons horizontal key art.jpg.md)
游戏支持多达四名玩家参与，具有各种新的武器、物品和生物，以及各种环境的探索和全面的任务，玩家最终将面对一个被称为“奇厄教主”的敌人。

游戏会有特定的任务和地点，以及由程序生成的元素。<ref name = "IGNDungeons">[Minecraft: Dungeons announced for PC](https://au.ign.com/articles/2018/09/29/minecraft-dungeons-announced-for-pc) - IGN, 2018年9月29日</ref>游戏并无职业区分，而是使用各种武器与盔甲进行搭配并使用它们。玩家不会建造或挖矿，因为游戏专注于动作和冒险。游戏在地上和地下都会进行。玩家可以重新游玩他们以前曾经打过的关卡。有“*类似于枢纽世界的东西（Something similar to a hub world）*”。世界是程序生成的，Mojang使用了[世界种子](世界种子.md)来决定地图的生成方式。

原版游戏中的皮肤和角色创建器的皮肤不能用于游戏中。但玩家可以随时为角色选择并更改由官方提供的几十个皮肤。其中一些皮肤需要购买DLC后才可使用。

# = 地点 =

创建角色后，游戏将自动进入一个叫做[鱿鱼海岸](MCD:鱿鱼海岸.md)的地点，同时这也是新手教学关卡。成功通过此关卡可以解锁其他的地点，比如[苦力怕森林](MCD:苦力怕森林.md)，不同地点的解锁方式分别不同。有些地点需要找到特殊的卷轴后才可开启，比如[苦力怕地穴](MCD:苦力怕地穴.md)或[灾厄港口](MCD:灾厄港口.md)。其中一些地点只有购买DLC或扩展包后方可游玩，比如[觉醒丛林](MCD:觉醒丛林.md)、[嚎风山巅](MCD:嚎风山巅.md)中的关卡等；还有些地点需要连接至游戏服务器才能游玩，比如[高塔](MCD:高塔.md)。

# = 物品 =

游戏中的物品大致可以分为六类：
* **[近战武器](MCD:近战武器.md)**——近战武器可以是剑，斧，甚至是[钻石镐](MCD:钻石镐.md)等等。
* **[远程武器](MCD:远程武器.md)**——远程武器大致分为弓和弩两种。不同的武器自带的加成属性也不同。
* **[盔甲](MCD:盔甲.md)**——用于提高玩家的防御力，并给予生命值加成。
* **[法器](MCD:法器.md)**——给玩家带来各种效果的道具，比如群体治疗，召唤攻击，群体伤害等。
* **[消耗品](MCD:消耗品.md)**——是一类增益掉落物，包括食物、药水和诸如箭捆和TNT等的其他物品。
* **[装饰](MCD:装饰.md)**——提供类似时装的效果，会给予玩家额外的穿着，但不会带来任何加成。

# = 附魔 =

游戏中出现了许多原版游戏没有的魔咒，不同的魔咒可用于不同的物品。给物品附魔需要消耗[附魔点数](Minecraft Dungeons:附魔点数.md)，升级魔咒则需要更多的附魔点数。

# = 生物 =

游戏中的生物大多数都为敌对和中立形态。不会对玩家生成敌意的有[猪](MCD:猪.md)、[羊](MCD:羊.md)、[牛](MCD:牛.md)、[豹猫](MCD:豹猫.md)、[熊猫](MCD:熊猫.md)、[羊毛牛](Minecraft Dungeons:羊毛牛.md)、[钥匙傀儡](MCD:钥匙傀儡.md)和[训练假人](MCD:训练假人.md)等。

游戏中的敌人大致可分为三种：[一般敌人](MCD:敌对生物.md)、[小Boss](MCD:小Boss.md)和[主要Boss](MCD:主要Boss.md)。

击杀生物会掉落[绿宝石](MCD:绿宝石.md)、[消耗品](MCD:消耗品.md)，或各式各样的物品。

# 开发

这个游戏在[MINECON Earth 2018](MINECON Earth 2018.md)中被宣布。<ref name = "IGNDungeons"/>这是一款基于[Minecraft](Minecraft.md)游戏的视觉增强版，但与原来的游戏有着不同的游戏风格。<ref>[Mojang announces Minecraft: Dungeons](https://www.polygon.com/2018/9/29/17916066/minecraft-dungeons-mojang-minecon) - Polygon，2018年9月29日</ref>游戏的灵感来源于经典迷宫探索。<ref name="Website"/>2019年9月17日，[Double Eleven](Double Eleven.md)宣布他们正在协助Mojang和Xbox Game Studio进行开发，尤其是在多人游戏和主机版本方面的开发。<ref></ref>

2019年11月宣布Minecraft Dungeons定于2020年4月发布。<ref></ref>但由于2019冠状病毒病疫情的影响，游戏被推迟至2020年5月26日正式发布。<ref name=delayed></ref>游戏的封闭测试从2020年3月25日持续到4月24日。<ref></ref><ref></ref>Minecraft Dungeons在PC和Xbox One平台开启预售，包含20美元的游戏本体/普通版和30美元的英雄版（包含后续DLC）。<ref name=delayed/><ref name=get-dungeons/>

2023年9月28日，官方宣布游戏不再更新，[1.17.0.0](MCD:1.17.0.0.md)成为游戏的最后一个版本。开发团队投入了Minecraft宇宙其他游戏项目的工作中。游戏共更新了17个大版本、39个小版本，发布了6个DLC、3个赛季通行证。
