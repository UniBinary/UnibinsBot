* *镐（Pickaxe）**是游戏中最常使用的挖掘[工具](工具.md)，是挖掘绝大多数[矿石](矿石.md)、[岩石](岩石.md)和金属质[方块](方块.md)的必需品。它们让[玩家](玩家.md)以更快的速度挖掘方块，速度增益取决于制作的材料。

# 用途
[物品实体](物品实体.md)形式的下界合金镐会漂浮在[熔岩](熔岩.md)上，且不会被[火](火.md)和熔岩摧毁。

# = 挖掘工具 =

镐是一种挖掘工具，每次成功挖掘了任何硬度不为0的方块会消耗1耐久度。

# = 近战攻击 =

镐每成功进行一次近战攻击会减少2点耐久度。

# == Java版 ==
镐的攻击速度是1.2，需要来[恢复](近战攻击#攻击冷却.md)。

# == 基岩版 ==
镐没有攻击冷却。

# 你知道吗
# = 宣传 =
* 泡沫橡胶石镐是官方[Minecraft](Minecraft.md)商品。<ref>http://www.jinx.com/p/minecraft_foam_pick_axe.html?catid=&s=minecraft</ref>
* 在游戏《顽皮熊：恐慌天堂》里，你能购买一个钻石镐，根据游戏，它是由Kick it up a Notch Pickaxes制作的，提到Notch。
* 在手机游戏《网红之路》这个增量游戏里，购买了小雕像架后，会有一个钻石镐的模型贴在[草方块](草方块.md)上。
* 在游戏《章鱼奶爸：致命捕捉》的杂货店中，有一个名为“MINTCRAFT”的柜台，柜台上方挂着两把铁镐，柜台上放着许多类似草方块的东西和一个苦力怕的头，拿起它会有爆炸音效。
* 在游戏《》里，你能找到一个镐，叫做“Notched Pickaxe”，明显地是一个[彩蛋](彩蛋.md)。
* 在游戏《枪战世界》里，一个名字是“The Notch Carver”的石镐能被用作近战武器。
* 在游戏《以撒的结合》里，有一个名字叫做"Notch之斧"的可获得物品，有以8位元绘制的样子，能被用于破坏岩石，Notch之斧也在游戏的重作《以撒的结合：重生》回归。
* 在游戏《2》里，你能发现一个以类似Minecraft泥土的方块隐藏的秘密区域，在里面你能打苦力怕和苦力怕妈妈来获得稀有的与Minecraft相关的武器。
