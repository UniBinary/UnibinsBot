# 基岩版1.19.50.21

*页面ID: 98994* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.50.21**（Android）、**Preview 1.19.50.21**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.50](基岩版1.19.50.md)的第2个测试版，发布于2022年10月19日<ref></ref><ref></ref>，通过[实验性玩法](实验性玩法.md)加入了部分[1.20.0](基岩版1.20.0.md)的特性，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[玩家](玩家.md)**
* 加入了7种新的默认皮肤：Makena、Efe、Noor、Kai、Ari、Sunny和Zuri。

# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“下一个主要更新”子选项。
* * 用于启用下一次主要更新的特性。

# 更改
# = 生物 =
* *[玩家](玩家.md)**
* 更改了Steve和Alex的默认皮肤。

# = 常规 =
* *[触摸控制](触摸控制.md)**
* 移除了攻击和交互的操作延时。
* 将摇杆未被锁定时的可拖动范围更改为与摇杆被锁定时相同的可拖动范围。
* * 若已开启“自动冲刺”选项，将摇杆略微拖动到摇杆背景区域上方时会开始疾跑；将摇杆拖动回摇杆背景区域时则会停止疾跑。

# = 技术性 =
* *活动对象属性**
* 活动对象属性（包括Molang查询和属性过滤器，不包括置换）不再是实验性内容。

* *AI意向**
* 为AI行为公开了新的数据参数， 以指定生物献花的时间、开启意向的时间，以及用于搜寻被献花的生物的的维度。
* AI行为现在能够被任何生物使用，而非只能被铁傀儡使用。
* AI行为现在会搜寻指定范围内的所有生物，而不只是最近的生物，这意味着该意向可能会比以前更加始终使用。
* 为AI行为公开了新的数据参数，以指定开启意向所需满足的条件、拿走花前的最小和最大等待时间，以及用于搜寻被拿走花的生物的的维度。
* AI行为现在能够被任何生物使用，而非只能被幼年村民使用。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”、“即将推出的创作者功能”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[竹板](竹板.md)**
* 可由2×2的[竹子](竹子.md)合成。
* 功能与木板一致。
* 可用于合成对应的[楼梯](楼梯.md)、[台阶](台阶.md)、[按钮](按钮.md)、[门](门.md)、[栅栏](栅栏.md)、[栅栏门](栅栏门.md)、[压力板](压力板.md)、[告示牌](告示牌.md)和[活板门](活板门.md)变种。

* *[竹马赛克](竹马赛克.md)**
* 可由纵向排列的1×2竹台阶合成。
* 可用于合成对应的[楼梯](楼梯.md)和[台阶](台阶.md)变种。

* *[雕纹书架](雕纹书架.md)**
* 最多可以存储6本书，可以是[书](书.md)、[书与笔](书与笔.md)、[成书](成书.md)或[附魔书](附魔书.md)。
* 可由6个木板和3个木台阶合成。
* 可以与[红石比较器](红石比较器.md)交互，输出的红石信号强度为最后一次存取书的槽位位置。

* *[悬挂式告示牌](悬挂式告示牌.md)**
* 告示牌的变种，合成所需的材料更多。
* * 可由2个[锁链](锁链.md)和6个[去皮原木](去皮原木.md)合成出6个相應的悬挂式告示牌，或由2个锁链和6个[竹板](竹板.md)合成出2个悬挂式竹告示牌。
* 不能附在方块顶面，但可由以下方式悬挂起来：
* * 附着在可在中心处提供支撑点的方块底面，例如完整方块或栅栏。
* * 附着在方块的固体侧面，模型上会展现出一根横杆。
* ** 放置后可不依赖于该固体侧面而独立存在。
* * 附着在其他悬挂式告示牌的侧面或底面。
* 可作为[熔炉](熔炉.md)燃料，每个能烧炼4个物品。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了[骆驼](骆驼.md)刷怪蛋。

# = 生物 =
* *[骆驼](骆驼.md)**
* 每个[沙漠村庄](村庄.md)中会自然生成一只。
* 有时会原地坐下。
* 可以通过[仙人掌](仙人掌.md)繁殖。
* 可以装备[鞍](鞍.md)，供2名玩家骑乘。
* * 被骑乘时可以慢走和疾跑。也可以冲刺，但耐力会被消耗一段时间。
* * 在玩家骑乘时，身体高度不高于玩家身体高度的敌对生物无法近战攻击到玩家。

# = 非生物实体 =
* *[船](船.md)和[运输船](运输船.md)**
* 加入了竹筏和运输竹筏。
* * 合成时用竹板替代。
* * 与其他的木质变种功能一致，仅外观上有区别。

# = 常规 =
* *[声音](声音.md)**
* 现在，各木种会在其被放置、破坏或在其上行走时有独特的音效。
* * 目前分为主世界木质、下界木质和竹质。
* 更改了下列音效以匹配：
* * 木质按钮的激活和取消激活音效
* * 门、活板门和栅栏门的开关音效
* * 木质压力板的激活音效和取消激活音效
* 更改了测重压力板的激活和取消激活音效。
* 更改了[拉杆](拉杆.md)的开关音效。

# 修复
* *旁观模式**
* 悦灵不再会向旁观模式玩家投掷物品。（）

* *方块**
* 现在木门、铁门、木活板门、铁活板门和栅栏门使用与Java版一致的开关音效。
* 更新了会根据行为发出不同音调的压力板以匹配Java版。
* 为木质按钮加入了独有的激活音效以匹配Java版。
* 现在绯红类和诡异类方块拥有独有的音效组。

* *村民**
* 现在幼年村民在玩耍时会以与Java版相匹配的速度更快地移动。

* *触摸控制**
* 轻击手势现在会使已装填的弩发射。之前版本必须在发射前保持该手势400ms。
* 修复了玩家不能在铁砧界面拖拽或丢弃物品的问题。

* *用户界面**
* 玩家现在可以在全键盘玩法开启时绑定复制坐标的按键。（）

* *世界与维度**
* 修复了切换维度时可能会使玩家卡在“生成地形中”界面，强制重启游戏后会将玩家传送到错误坐标的漏洞。（）

* *游戏内容**
* 暂时回退了对繁殖生物会继承状态效果的修复。（）

* *附加包与脚本引擎**
* 修复了更改拥有子包的资源包的子包在重启游戏前不会应用更改的问题。（）

* *性能与稳定性**
* 修复了在没有开启教育版选项的情况下渲染教育版物品时发生的崩溃。（）</onlyinclude>
