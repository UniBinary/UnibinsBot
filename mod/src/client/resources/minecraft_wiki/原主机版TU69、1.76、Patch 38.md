# 原主机版TU69、1.76、Patch 38

*页面ID: 62645* | *来源: Minecraft Wiki*

* *TU69/1.76/Patch 38**是[原主机版](原主机版.md)的一次更新，发布于2018年9月11日，加入了许多[水域更新](水域更新.md)的特性。<ref></ref>此次更新等价于[基岩版1.4](基岩版1.4.md)、[1.5](基岩版1.5.md)、[1.6](基岩版1.6.md)与[Java版1.13](Java版1.13.md)。

# 新内容
# =[方块](方块.md)=
* 加入了除橡木外5种木头对应的[活板门](活板门.md)、[压力板](压力板.md)和[按钮](按钮.md)。
* 加入了10种[珊瑚块](珊瑚块.md)、5种[珊瑚](珊瑚.md)和5种[珊瑚扇](珊瑚.md)。
* 加入了5种[失活的珊瑚扇](失活的珊瑚扇.md)。
* 加入了[海带](海带.md)。
* 加入了[干海带块](干海带块.md)。
* 加入了[海草](海草.md)。
* 加入了[海泡菜](海泡菜.md)。
* 加入了[海龟蛋](海龟蛋.md)。
* 加入了[蓝冰](蓝冰.md)。
* 加入了[潮涌核心](潮涌核心.md)，可以为在水里的玩家提供潮涌能量状态效果。
* 加入了[木头](木头.md)和[去皮木头](去皮木头.md)。
* 加入了[气泡柱](气泡柱.md)，通过水下的[岩浆块](岩浆块.md)或[灵魂沙](灵魂沙.md)生成，可以使实体沉下或浮起。
* 加入了[海晶石](海晶石.md)楼梯和台阶。

# 更改
# =方块=
* *[南瓜](南瓜.md)**
* 更改了南瓜的纹理，并将旧的纹理命名为“雕刻南瓜”，可通过使用剪刀右键点击南瓜获得。
* *[水](水.md)**
* 水源方块现在能够放置在半透明的方块的里面，例如楼梯和台阶，称之为[含水](含水.md)。
* 修改了纹理。
* *[潜影盒](潜影盒.md)**
* 潜影盒现在能通过使用[炼药锅](炼药锅.md)洗去颜色。

# = 生物 =
* *[马](马.md)**
* 更改了[模型](模型.md)。

# = 非生物实体 =
* *[掉落物](掉落物.md)**
* 掉落物现在会在水面浮动。

# = 游戏内容 =
* *[呼吸](呼吸.md)**
* 生物在可以呼吸时，氧气值每刻恢复，而不是立即恢复到最大值。
* *水下**
* 更改了在水下时的视野。

# = 常规 =
* *[潜行](潜行.md)**
* 当玩家潜行时，画面过渡更流畅了。
