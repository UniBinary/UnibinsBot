# 游戏规则/mob explosion drop decay

*页面ID: 128309* | *来源: Minecraft Wiki*

* *mob_explosion_drop_decay**是控制部分[爆炸](爆炸.md)中一些方块是否不会掉落战利品的[游戏规则](游戏规则.md)。

# 行为
当mob_explosion_drop_decay为<samp>false</samp>时，在[苦力怕](苦力怕.md)、[凋灵](凋灵.md)、[凋灵之首](凋灵之首.md)和[火球](火球.md)引起的爆炸中，所有被破坏方块的掉落物都不会被炸毁。

当mob_explosion_drop_decay为<samp>true</samp>时，在上述爆炸中，部分被破坏方块的掉落物会被炸毁。
