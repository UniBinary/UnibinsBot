# Java版13w24b

*页面ID: 33558* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w24b**是[Java版1.6.1](Java版1.6.1.md)的第14个快照，发布于2013年6月14日<ref></ref>，加入了伤害吸收效果，修复了[13w24a](13w24a.md)里的漏洞和崩溃。

# 新内容
# = 游戏内容 =
* *[状态效果](状态效果.md)**
* 加入了[伤害吸收](伤害吸收.md)状态效果。
* * 取代了普通金苹果的[生命提升](生命提升.md)效果。
* * 也为[附魔金苹果](附魔金苹果.md)加入了同样的效果。

# 更改
# = 方块 =
* *[地毯](地毯.md)**
* 现在能够放置在任何方块的上方。
* * 这些方块包括[水](水.md)源方块、[树苗](树苗.md)、[火把](火把.md)、[箱子](箱子.md)和其他地毯等。
* * 用于修复无法在[铁栏杆](铁栏杆.md)上放置地毯的漏洞，使它们在哪里都能被放置。
