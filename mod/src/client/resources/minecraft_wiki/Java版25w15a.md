# Java版25w15a

*页面ID: 149306* | *来源: Minecraft Wiki*

<onlyinclude>

* *25w15a**是[Java版1.21.6](Java版1.21.6.md)的首个快照，发布于2025年4月8日<ref></ref>，加入了[追逐天空](追逐天空.md)的部分内容，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[失水恶魂](失水恶魂.md)**
* 在[下界](下界.md)中作为[下界化石](下界化石.md)的一部分自然生成。
* 可使用1个[骨块](骨块.md)和8个[恶魂之泪](恶魂之泪.md)合成。
* 被放置时默认处于“干燥”状态，[含水](含水.md)时经过3个阶段，持续一段时间后会生成一只[小恶魂](小恶魂.md)。
* 不再含水时，失水恶魂会逐渐恢复到“干燥”状态。
* 状态变化时会发出声音并产生粒子。
* 被挖掘时，其方块状态不会保留。
* 物品[稀有度](稀有度.md)为“少见”。

# = 物品 =
* *[挽具](挽具.md)**
* 一种能够装备在[快乐恶魂](快乐恶魂.md)上的物品，允许玩家骑乘快乐恶魂。
* 可使用3个[皮革](皮革.md)、2个[玻璃](玻璃.md)和1个[羊毛](羊毛.md)合成。
* 可通过与[染料](染料.md)合成以重新染色。
* 对未被骑乘的快乐恶魂[剪刀](剪刀.md)可卸下其装备的挽具。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了快乐恶魂刷怪蛋。

# = 生物 =
* *[快乐恶魂](快乐恶魂.md)**
* 一种生命值为的飞行可骑乘生物。
* 幼年形态快乐恶魂被称为小恶魂，有着不同的行为：
* * 由持续含水20分钟的失水恶魂生成。
* * 生成后会尝试跟随以下生物：
* ** 半径16格内的玩家
* ** 半径16格内的非水生成年友好生物
* * 若附近没有合适的可跟随生物，小恶魂会在其原点位置（生成位置或最后与之交互的位置）32格内游荡。
* * 会在20分钟后成长。
* * 可被喂食[雪球](雪球.md)以加速成长，也会被雪球吸引。
* 可装备[挽具](挽具.md)，最多允许4名玩家骑乘。
* * 被骑乘时护目镜会下降并遮住眼睛，表示能够被控制。
* ** 未被骑乘时护目镜会升起，并且快乐恶魂会开始在原点位置附近游荡。
* * 第一个骑乘快乐恶魂的玩家会坐在最前方，能够控制它。
* * 后来骑乘的玩家会坐在两侧的槽位上，以第一个骑乘的玩家开始顺时针排序。
* * 玩家按下会脱离快乐恶魂。
* 玩家位于其上方时会停止移动。
* 会被雪球和挽具吸引。
* * 已装备挽具时不会被挽具吸引。
* 无法[繁殖](繁殖.md)和乘[船](船.md)。
* 会缓慢地自然恢复生命值，[降雨](降雨.md)、[降雪](降雪.md)或飞行高度与[云](云.md)的高度相同（即主世界的Y=）时会加快恢复速度。
* 游荡时会保持位于原点位置（生成位置或最后与之交互的位置）64格内。
* * 已装备挽具时会更靠近原点位置，保持位于32格内。
* * 单独游荡时会尝试靠近方块。

* * 此距离会与<code>scale</code>属性相乘以得出最终摄像机距离。

# 更改
# = 方块 =
* *所有[陶瓦](陶瓦.md)**
* 不再发出环境音效。

* *[矮枯草丛](矮枯草丛.md)和[高枯草丛](高枯草丛.md)**
* 现在当下方两格均为沙子、红沙或任何陶瓦时会发出特殊的环境音效。

* *[沙子](沙子.md)和[红沙](红沙.md)**
* 现在会发出的环境音效不再包括“风声”。
* 略微降低了播放环境音效的概率。
* 修改了判断是否播放环境音效的逻辑，现在不需要方块本身露天，只需要上方一格为空气。

* *[枯萎的灌木](枯萎的灌木.md)**
* 略微提升了播放环境音效的概率。

# = 生物 =
* *[恶魂](恶魂.md)**
* 更新了纹理。

* *[玩家](玩家.md)**

* 现在会在旁观模式下随所旁观的实体传送到其他维度，但也会在到达其他维度时停止旁观。

* *[狼](狼.md)、[绵羊](绵羊.md)和[猪](猪.md)**

# 新内容（实验性）
本段落的内容需要开启[实验性内容](实验性内容.md)“定位栏”后才可使用。

# = 游戏内容 =
* *[定位栏](定位栏.md)**
* 一种在多人游戏中允许玩家定位其他玩家的界面元素。
* 定位栏的定位依赖于路径点。
* * 玩家相机视野夹角120°内的路径点会在定位栏上显示不同颜色的指示器。
* * 路径点在相机视域（即屏幕）上/下方时，则会显示指向它的箭头。
* * 队伍中的玩家或生物的路径点的颜色由其所处的队伍颜色决定。
* 默认情况下，所有玩家都会传输出一个路径点，所有玩家也会接收所有路径点。
* * [潜行](潜行.md)、在头盔槽戴有[雕刻南瓜](雕刻南瓜.md)或[生物头颅](生物头颅.md)、[隐身](隐身.md)状态效果会使玩家不在定位栏中显示。
* * 旁观模式玩家只会在其他旁观模式玩家的定位栏中显示。
* * 会在普通情况下占用经验条的位置。

* *[游戏规则](游戏规则.md)**
* 加入了<code>useLocatorBar</code>，默认启用。
* * 启用时，服务器会运行定位栏实验性内容相关特性。
* * 将其关闭时，所有玩家的路径点会被移除。
