* *13w16a**是[Java版1.6.1](Java版1.6.1.md)的首个快照，发布于2013年4月18日<ref></ref>，加入了首批[马匹更新](马匹更新.md)的内容，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[地毯](地毯.md)**
* 地毯可以通过两个同样颜色的[羊毛](羊毛.md)横放来合成。

* *[干草捆](干草捆.md)**
* 能够像[木-{}-头](原木.md)一样以各种方向放置。

# = 物品 =
* *[马铠](马铠.md)**
* 拥有铁质、金质和钻石质变种。
* 合成配方为6个[铁锭](铁锭.md)/[金锭](金锭.md)/[钻石](钻石.md)和一个羊毛。

* *[马鞍](马鞍.md)**
* 可堆叠至32。
* 通过使用5个[皮革](皮革.md)和3个铁锭合成。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了马刷怪蛋。
* * 使用后可获得不同的马品种。
* * 行为与其他刷怪蛋一致。

* *[拴绳](拴绳.md)**
* 可用于将动物拴在[栅栏](栅栏.md)上或牵着走。
* 先右击动物，然后右击栅栏来拴住，可通过再次右击动物来取回拴绳。

# = 生物 =
* *[马](马.md)**
* 可通过按下键骑乘，键下马，用通常的键控制前进方向。最大速度与弹跳高度与马的品种相关。
* 最大生命值各不相同，可以用[小麦](小麦.md)和[胡萝卜](胡萝卜.md)来恢复生命。
* 死后掉落皮革。
* 可用小麦喂养。幼年马可以用[苹果](苹果.md)、[金苹果](金苹果.md)与小麦使其成长。
* 长按键蓄力，放开后可跳跃。
* 它们会自然走过1格高的地方，从而允许玩家步行上山而不需要不停跳跃。
* 它们也可以爬梯，当驾驶它们时。
* 在更多生物mod作者Dr.Zhark（John Olarte）的协助下完成。
* 代码内包含[僵尸马](僵尸马.md)和[骷髅马](骷髅马.md)，但是需要编辑NBT来生成。

* *[驴](驴.md)**
* 行为与马相似，但可以在背上放置[箱子](箱子.md)，虽然这时没有物品栏可用。

* *[骡](骡.md)**
* 可以通过马和驴繁殖获得。

# 更改
# = 生物 =
* *常规**
* 更改了生物难度的概念。<ref></ref>
* * 区域难度：在一个地方待得越久，难度越高。
* * 随难度调整：物品，附魔与AI会随着难度提高而增强。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 改进了[](水下呼吸（魔咒）.md)魔咒。
* * 现在能够帮助玩家在水下看得更清楚（取决于附魔等级，1-3）。

* *骑乘**
* 改进了骑乘机制。
* * 加入了生物的生命条到[HUD](HUD.md)中，在骑乘[猪](猪.md)和[马](马.md)时出现。
* * 当乘坐载具或生物时现在只能通过潜行键来脱离。

# = 常规 =
* *制作人员名单**
* 更多生物mod开发者加入到了。

* *目录结构**
* 更改了[.minecraft](.minecraft.md)的目录结构。
* * 文件夹：存储语言包和声音等资源。
* ** 所有的[音乐唱片](音乐唱片.md)现在使用<code>.ogg</code>格式而不是<code>.mus</code>。
* * 文件夹：存储诸如LWJGL和之类的Java库。
* * 文件夹：每个版本有（元数据）和存储的文件夹（名称与版本号相同，例如13w16a为）。
