# 校频幽匿感测体

*页面ID: 157257* | *来源: Minecraft Wiki*

* *幽匿感测体（Calibrated Sculk Sensor）**是[幽匿感测体](幽匿感测体.md)的变种，可以根据输入信号来接收特定振动频率的振动。

# 生成
校频幽匿感测体不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘校频幽匿感测体的合适工具是锄。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，校频幽匿感测体被破坏后会掉落。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，校频幽匿感测体被破坏后会掉落自身。

# 用途
校频幽匿感测体有朝向，其信号输入面朝向的方向使用紫水晶的纹理标出，该面可接收[红石信号](红石信号.md)。它被玩家放置时会朝向玩家。

# = 振动检测 =
校频幽匿感测体可以检测半径16格范围内由物体的动作产生的振动，但它们不会检测[潜行](潜行.md)的生物发出的部分振动（如行走、摔落或掷出弹射物时发出的振动；潜行时踩踏该校频幽匿感测体的振动除外）、[监守者](监守者.md)发出的所有振动和其他校频幽匿感测体发出的振动。

当校频幽匿感测体检测到振动时，振动源会以每游戏刻1格，即每秒20格的速度向其发出信号粒子；信号到达时，校频幽匿感测体会激活0.5秒，并在周围产生渐变色粒子；激活时间过后，校频幽匿感测体还会有0.5秒的冷却时间。从信号开始发出到冷却时间结束，校频幽匿感测体都不会再检测其他振动，因此不可能出现多个信号同时传向同一个校频幽匿感测体的情况，也不会发生校频幽匿感测体被自身取消激活的振动反复激活的情况。冷却时间结束后，校频幽匿感测体才能继续检测振动。

[羊毛](羊毛.md)会吸收经过的信号，被吸收的信号不会被校频幽匿感测体接收。羊毛或[地毯](地毯.md)的[物品实体](物品实体.md)掉在地上、在羊毛或地毯上行走以及放置羊毛或地毯发出的振动不会被检测。

校频幽匿感测体可[含水](含水.md)。含水的校频幽匿感测体不会发出任何声音，但仍可检测周围的振动。

当[实体](实体.md)位于校频幽匿感测体上时，校频幽匿感测体会持续地周期性激活。

# == 过滤振动 ==
校频幽匿感测体的信号输入面接收到红石信号时，它将只能检测到振动频率与该红石信号强度相等数值的振动。例如紫水晶侧输入强度为5的红石信号，则此校频幽匿感测体将只能接收振动频率为5的振动。

一些游戏行为会同时产生多个振动。例如食用物品会产生两个振动，振动频率分别为3（结束使用物品）和8（进食）；击杀生物会产生两个振动，振动频率分别为7（实体受伤）和15（实体死亡）。校频幽匿感测体通常会检测振动频率最大的振动，而通过输入信号限制则可以过滤非指定频率的振动。

# = 红石元件 =
校频幽匿感测体被激活时会：
* 激活毗邻（除了校频幽匿感测体的信号输入面方向）的红石线，并改变水平方向上毗邻的红石线的指向。信号强度取决于校频幽匿感测体到振动源的距离。
* 激活任何四周（除了校频幽匿感测体的信号输入面方向）背对的[红石中继器](红石中继器.md)和[红石比较器](红石比较器.md)。信号强度取决于校频幽匿感测体到振动源的距离。
* 激活任何毗邻（除了校频幽匿感测体的信号输入面方向）的[机械元件](红石元件.md)（如[门](门.md)、[红石灯](红石灯.md)等），包括校频幽匿感测体上面的和下面的机械元件（但不能激活一些拒绝该方向输入的机械元件，如面朝该校频幽匿感测体的[活塞](活塞.md)）。

校频幽匿感测体发出的红石信号强度与校频幽匿感测体到振动源的距离呈负相关性质，即振动传播距离越短，校频幽匿感测体发出的红石信号越强。
   具体公式为：<code>-{}-max{1, 15 - floor(*距离* * 0.9375)}</code>

当振动源位于校频幽匿感测体正上方（距离为0）时，校频幽匿感测体会输出最大的红石信号强度15。

当校频幽匿感测体探测到它上面的实体时，输出的红石信号强度始终为15。

# == 振动频率 ==
游戏内每种振动都有不同的频率，校频幽匿感测体收到的振动的频率可以被[红石比较器](红石比较器.md)检测并作为主输入端输入。红石比较器检测校频幽匿感测体得到的信号仅与振动频率相关，与振动的远近无关。玩家可以借此探知校频幽匿感测体周围发生的事件类型。

当校频幽匿感测体探测到它上面的实体时，其振动频率为1。

校频幽匿感测体检测到振动时，与之相邻的[紫水晶块](紫水晶块.md)会发生**共振**，即发送一个频率相同的振动。

# = 幽匿尖啸体 =
校频幽匿感测体被玩家的行为激活时会发送信号给半径8格内的[幽匿尖啸体](幽匿尖啸体.md)，将其激活。

# = 光源 =
无论是否被激活，校频幽匿感测体都会发出[亮度](亮度.md)为1的光，但激活时发出的光在视觉上更亮而偏黄。
