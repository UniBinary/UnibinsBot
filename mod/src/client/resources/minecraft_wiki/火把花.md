# 火把花

*页面ID: 102327* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *火把花（Torchflower）**是一种[小型花](小型花.md)。

# 生成
# = 作物 =
[火把花植株](火把花植株.md)完全成熟时会变为火把花。

# 获取
火把花只能通过破坏火把花获得。

# 破坏
火把花被挖掘时会立刻被破坏。

火把花被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 谜之炖菜 =

使用火把花合成或喂食棕色[哞菇](哞菇.md)得到合成的谜之炖菜会给予玩家5s的[夜视](夜视.md)效果。

# = 堆肥 =
将火把花放入[堆肥桶](堆肥桶.md)有85%的概率使堆肥层数增加1。
