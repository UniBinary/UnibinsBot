# Java版12w50b

*页面ID: 33301* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w50b**是[Java版1.4.6](Java版1.4.6.md)的第3个，也是最后一个快照，发布于2012年12月14日<ref></ref>，发布以修复快照[12w50a](12w50a.md)里的漏洞和崩溃。

# 更改
# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 荆棘魔咒的伤害现可自定义。
* 火焰保护魔咒现在会更快地熄灭玩家身上的[火](火.md)。
* 爆炸保护现在减少爆炸反冲。

# 修复
不能在玩家的经验等级为0~1之间时移除经验条。
|;dev
|4191|合成烟花火箭时，如果在合成栏内放入其他合成所不需要的物品，合成依然能进行，但多余的物品会被消耗。
|;previous
|4534|物品（堆）在快捷栏上方的名称提示在其发生改变（比如数量或耐久度）时会再次出现。
|4537|在玩家手中没有任何东西的时候，按下会导致<code>NullPointerException</code>。
|4553|僵尸有时会停止攻击。
|4580|耐久魔咒对盔甲不起作用。
|4584|打开一个GUI会导致快捷栏上方再次显示物品的名称。
|4612|有附魔光效的物品堆在掉落时存在渲染漏洞。
