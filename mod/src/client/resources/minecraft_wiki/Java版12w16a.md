# Java版12w16a

*页面ID: 32360* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w16a**是[Java版1.3.1](Java版1.3.1.md)的第2个快照，发布于2012年4月19日<ref></ref>，加入了奖励箱和新的命令。

# 新内容
# = 游戏内容 =
* *[奖励箱](奖励箱.md)**
* 在创造世界屏幕中加入奖励箱选项。
* * 开启时，玩家出生地旁会有一个被[火把](火把.md)包围的箱子，内有帮助玩家开始游玩生存模式的工具、物品和方块。里面可能含有：
* ** [原木](原木.md)
* ** [木板](木板.md)
* ** [木棍](木棍.md)
* ** 石[镐](镐.md)和/或木镐
* ** 石[斧](斧.md)和/或木斧
* ** [面包](面包.md)
* ** [苹果](苹果.md)

# = 命令格式 =
* *[命令](命令.md)**
* 在创造世界屏幕中加入单人命令选项。
* * 加入了一些新的命令：、、、、和。
* * 输入<code>/</code>然后按下会展示可用命令的列表。
* * 这些命令在创造模式世界中默认开启。
* * 使用命令时，玩家周围的世界是静止的，不像多人游戏那样。

# = 常规 =
* *[演示模式](演示模式.md)**
* 加入了给未购买游戏的玩家免费游玩的演示模式（在正式版本发布前不可用）。
* * 根据语言文件，演示模式会持续6个游戏日（大约1小时40分钟）。
* * 教会玩家如何开始游戏和[控制](控制.md)。

# 更改
# = 常规 =
* *[控制](控制.md)**
* 在创造模式的物品选择屏幕中，热键栏内的物品可以按下删除。

* *[语言](语言.md)文件**
* 升级了语言文件。</onlyinclude>
