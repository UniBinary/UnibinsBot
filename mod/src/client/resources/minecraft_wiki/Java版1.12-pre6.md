# Java版1.12-pre6

*页面ID: 30184* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.12-pre6**是[Java版1.12](Java版1.12.md)的第6个预发布版，发布于2017年5月29日<ref></ref>，更新了主菜单，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[鸣谢与著作权说明屏幕](鸣谢与著作权说明屏幕.md)**
* 可以在[主菜单](主菜单.md)中点击版权文本来查看。

# 更改
# = 方块 =
* *[命令方块](命令方块.md)**
* 命令方块中使用Tab来自动补全的命令名称不再添加<code>/</code>前缀。

* *[旗帜](旗帜.md)**
* 。

# = 常规 =
* *[函数](Java版函数.md)**
* 跳过的函数（当不满足条件时）现在被认为是失败。（比如在命令方块中）

* *[语言](语言.md)**
* 许多之前锁定为英语的文本现在可以翻译了。
* * 完整的更改列表可以在[这里](https://gist.github.com/Dinnerbone/3700d226481934f1eeffe5cd0c22b7d2)找到。

* *性能**
* 改进了[配方书](配方书.md)和[创造模式物品栏](创造模式#创造模式物品栏.md)的搜索，特别是在使用[mod](mod.md)时尤为明显。
* * [命名空间](命名空间.md)（比如*minecraft*:stone）不能再用于搜索。
* 改进了[区块加载](区块加载.md)，因为上一个预发布版将其变得慢了。
