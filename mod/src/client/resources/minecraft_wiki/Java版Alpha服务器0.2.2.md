# Java版Alpha服务器0.2.2

*页面ID: 45482* | *来源: Minecraft Wiki*

* *0.2.2**是一个[Alpha](Java版Alpha.md)服务器版本，与[客户端1.2.0](Java版Alpha v1.2.0.md)在2010年10月30日一起发布，修复了一些漏洞。

# 修复
* 更新了红石的性能。
* 修复了门的动画。
* 修复了一些性能问题。
* 铁轨不再导致崩溃。
