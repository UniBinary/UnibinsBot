* *MINECON披风（MINECON Cape）**是发放给[MINECON](MINECON.md)参与者的披风。

# 描述
# = 2011 =
MINECON 2011参与者披风主体为红色，其上有一个[苦力怕](苦力怕.md)脸部图案。该披风被自动添加到所有参加了[MINECON 2011](MINECON 2011.md)的已注册参与者的账户中。<ref name="help capes">https://help.mojang.com/customer/portal/articles/872983-minecon-capes</ref>

# = 2012 =
MINECON 2012参与者披风主体为蓝色，其上有一个黄色的[镐](镐.md)形状图案。

一封含此披风礼品页面链接的邮件发送给了[MINECON 2012](MINECON 2012.md)的所有注册过的参与者。<ref name="help capes"/>

# = 2013 =
MINECON 2013参与者披风主体为绿色，其上有一个[活塞](活塞.md)侧面纹理的图案，而鞘翅上则显示的是活塞顶部的纹理图案。

在2013年10月30日，Mojang团队的Tobias Mollstam发布了MINECON 2013披风的图像。这套披风显示的是绿色背景上的伸展活塞。<ref></ref>
一封含此披风礼品页面链接的邮件发送给了[MINECON 2013](MINECON 2013.md)的所有注册过的参与者。<ref name="help capes"/>

# = 2015 =
MINECON 2015参与者披风主体为深绿色，其上有一个[铁傀儡](铁傀儡.md)脸部图案。一封含此披风礼品页面链接的邮件发送给了在入口扫描了门票的所有[MINECON 2015](MINECON 2015.md)参与者。<ref name="help capes"/><br>不像之前那样，这套披风8月1-15日在[原主机版](原主机版.md)是可用的。

# = 2016 =
MINECON 2016参与者披风主体为黑色，其上有一个[末影人](末影人.md)脸部图案。 每一位参加了[MINECON 2016](MINECON 2016.md)的玩家都得到了这个披风。一封含此披风礼品页面链接的邮件发送给了于2016年9月24日在入口扫描了门票的所有MINECON 2016参与者。

# 未使用的披风设计
[thumb|200px|MINECON 2011候选披风](File:Cloakvote.png.md)
MINECON 2011候选披风投票展示了5个披风。红色苦力怕披风（设计#2）在MINECON 2011中以42%的选票胜出，蓝镐披风（设计#1）则获得33%的选票，后来用在了MINECON 2012上。<ref>https://www.mojang.com/2011/09/minecon-swag-cloaks</ref>
