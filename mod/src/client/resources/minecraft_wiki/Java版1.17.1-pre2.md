* *1.17.1-pre2**是[Java版1.17.1](Java版1.17.1.md)的第2个预发布版，发布于2021年6月29日<ref></ref>，加入了文言文，移除了马恩岛语、西西里语和士瓦本德语，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[语言](语言.md)**
* 加入了文言文。<!-- 在“语言”页面外不应记载某语言在游戏内显示的语言名称原文 -->

# 更改
# = 常规 =
* *语言**
* 移除了马恩岛语、西西里语和士瓦本德语，因为这些语言的翻译尚未完善。

* *日志**
* 现在当被命名过的生物死亡时，其死亡消息会被记录到日志中。

# 修复
命令清除。
