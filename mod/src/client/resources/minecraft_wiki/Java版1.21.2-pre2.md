# Java版1.21.2-pre2

*页面ID: 127196* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21.2-pre2**是[Java版1.21.2](Java版1.21.2.md)的第2个预发布版，发布于2024年10月10日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[黏液块](黏液块.md)**
* 现在玩家在潜行状态下摔落在其上时不会受到摔落伤害，并能以此阻止继续弹跳。<ref></ref>

# = 生物 =
* *[旋风人](旋风人.md)**
* 不再能在[蜂蜜块](蜂蜜块.md)上起跳。
* 其跳跃高度现在会受到[跳跃提升](跳跃提升.md)状态效果的影响。
* 修改了其在空闲状态下的动画，以匹配。

# = 常规 =
* *[配方](配方.md)**
* 物品转变配方的输出物品不再可以是[空气](空气.md)。

# 更改（实验性）
# = 方块 =
* *[苍白垂须](苍白垂须.md)**
* 现在只会在被[剪刀](剪刀.md)或附有[精准采集](精准采集.md)的工具破坏时掉落。

* *[苍白苔藓块](苍白苔藓块.md)**
* [锄](锄.md)现在能加速破坏苍白苔藓块。

* *[苍白覆地苔藓](苍白覆地苔藓.md)**
* [剑](剑.md)和锄现在能加速破坏苍白覆地苔藓。
* 现在会播放正确的脚步声。

# = 世界生成 =
* *[试炼密室](试炼密室.md)**
* 现在会在[苍白之园](苍白之园.md)生物群系中自然生成。

# = 常规 =
* *[标签](Java版标签.md)**
* 物品标签现在包含而不是。
* 向方块标签中加入了。
* 方块标签现在包含而不是。
