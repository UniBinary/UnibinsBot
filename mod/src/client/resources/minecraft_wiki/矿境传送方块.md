* *矿境传送方块（Mine Travelling Block）**是一种由[矿境合成台](矿境合成台.md)、[矿境回访器](矿境回访器.md)生成，或出现在[矿境](矿境.md)结构中的[方块](方块.md)，能够传送玩家进出矿境。

# 生成
# = 矿境合成台 =
使用[矿境合成台](矿境合成台.md)合成矿境时，矿境传送方块会在其上方一格处生成。若生成位置已有方块，该方块会被破坏。

# = 矿境回访器 =
对着[矿境回访器](矿境回访器.md)矿境物品后，矿境传送方块会在其上方一格处生成，并消耗[矿境物品](矿境（物品）.md)。若生成位置已有方块，该方块会被破坏。

# = 矿境出口 =
矿境传送方块是[矿境出口](矿境出口.md)结构中的一部分。

# 破坏
矿境传送方块不能被挖掘破坏。

|-1
}}

矿境传送方块被破坏后不会掉落。

# 用途
玩家与矿境传送方块后，会被传送到[矿境](矿境.md)或[主世界](主世界.md)中。
* 对于通过矿境合成台生成的矿境传送方块，玩家后，一个10秒的倒计时会出现在快捷栏上方，文字大小和抖动幅度会不断变大。倒计时结束后，玩家将会被传送至新生成的矿境中，并被设为[生存模式](生存模式.md)。
* 对于通过矿境回访器生成的矿境传送方块，玩家后会被立刻传送至对应的矿境中，并被设为[冒险模式](冒险模式.md)，同时获得一个[出口之眼](出口之眼.md)。
* 对于矿境出口中的矿境传送方块，玩家后，一个10秒的倒计时会出现在快捷栏上方。倒计时结束后，玩家将会被传送至主世界中。玩家将恢复其原先在主世界内的游戏模式和物品，其在矿境中获得的[矿境原料](矿境原料.md)和[生物奖杯](生物奖杯.md)将会被保留，剩余的物品将会转化为对应的[经验值](经验值.md)。
若在倒计时期间再次交互，则会停止倒计时并取消传送。

# = 光柱 =
矿境传送方块会持续发出蓝色光柱。与[末地折跃门方块](末地折跃门（方块）.md)的光柱类似，在光柱上面放置染色玻璃并不会改变光柱的颜色，光柱不会被[完全固体渲染方块](遮挡形状.md)阻挡。

# = 光源 =
矿境传送方块会发出亮度等级为15的光。
