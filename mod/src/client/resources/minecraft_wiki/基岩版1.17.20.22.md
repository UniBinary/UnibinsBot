# 基岩版1.17.20.22

*页面ID: 85754* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.17.20.22**是[基岩版1.17.30](基岩版1.17.30.md)的第3个测试版，发布于2021年7月14日<ref></ref><ref></ref>，在[实验性玩法](实验性玩法.md)中更改了敌对生物的生成机制，并修复了一些漏洞。

# 更改
# = 方块 =
* *[光源方块](光源方块.md)**
* 现在当玩家手持光源方块时，放置出的光源方块会显示其物品纹理。

# = 生物 =
* *[美西螈](美西螈.md)**
* 现在仅会在其上方10格内有石头且不存在气泡柱时生成。

# = 常规 =
[thumb|150px|加载界面的旧徽标和新徽标的差异](File:Beta 1.17.20.22 Logo Difference.jpg.md)
* *用户界面**
* 略微更改了加载界面和主菜单（Beta背景显示前）的Minecraft徽标。

# = 技术性 =
* *命令**
* 目标选择器参数和现在支持旋转至北面。

* *生成**
* 现在与类似，仅会指定一个方块列表和距离。
* * 生物仅在其期望生成点下方指定距离内的最近方块存在于列表中（不包括水和空气）时生成。

本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“洞穴及悬崖”和“启用游戏测试框架”子选项后才可使用。

# 修复
* *性能与稳定性**
* 修复了一些游戏过程中可能发生的崩溃。

* *方块**
* 紫水晶簇不再能够放置在土径上。
* 将深层青金石矿石的英文名由“Deepslate Lapis Ore”修正为“Deepslate Lapis Lazuli Ore”。（）
* 现在发射器在收回水时同时会移除水中的气泡柱。（）
* 海泡菜现在会根据其是否含水而更改自身亮度等级。（）
* 雪现在会被火把等光源发出的光融化。（）
* 原版趋同：下落的方块下落在部分方块上不再会被破坏。（）

* *游戏内容**
* 原版趋同：现在对苔藓块使用骨粉也会蔓延至凝灰岩。（）
* 原版趋同：修复了手持光源方块时已放置的光源方块不会显示的问题。（）
* 修复了开启保留物品栏游戏规则后，玩家死亡后持有的物品不会在其他玩家的视角中消失的问题。（）
* 建造于多个区块之间的下界传送门不再会在玩家离开下界时被破坏。（）
* 剪刀现在可以更快并正确地破坏藤蔓和发光地衣。（）
* 现在垂泪藤和缠怨藤会在被玩家破坏后正确生长。（）

* *图形**
* 调整了纹理图集中1级mipmaps中高清纹理的填充以修复纹理渗漏问题。
* 附魔台上的书的一半不再会变黑暗。（）
* 被活塞移动的方块在移动时不再会变白。（）

* *生物**
* 美西螈现在仅在其上方10格内有石头且不存在气泡柱时生成。
* 现在装备下界合金盔甲的盔甲架在被火或熔岩摧毁时会掉落无损的盔甲。（）
* 调整了幻翼的最大生成数量限制。（）
* 山羊现在会发出“impact 3”音效。（）

* *用户界面**
* 配方书的合成结果不再与实际不符。
* 加载测试版的实验性玩法世界前不再显示不一致的警告。
* 光标物品不再属于配方书中的合成配方。
* 现在当玩家合成材料耗尽时会取消选定的合成配方。
* 在配方书搜索合成配方时不再会显示无法合成的配方。
* 若任意合成材料不可用，则下界岩现在会显示在合成网格中。
* 修复了玩家连接有线网络时会出现无线网络连接错误消息的问题。
* 修复了角色创建器中的各种拼写错误。
* 现在悬停的小装饰按钮会在完全加载之前显示为已损坏。
* 修复了一些日语字符的易读性问题。
* 现在非触摸控制玩家在骑马时会正确显示提示。

* *技术性**
* 杀死具有未知战利品表类型的自定义生物不再会导致游戏崩溃，且现在会抛出一个内容错误。（）
* 指定了初始事件的兔子现在可以调整至正常成年兔子的大小。（）</onlyinclude>
