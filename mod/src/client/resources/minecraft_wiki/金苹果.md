# 金苹果

*页面ID: 6996* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *金苹果（Golden Apple）**是一种特殊的[食物](食物.md)，能给予增益状态效果。

# 获取
# = 合成 =

# = 箱子战利品 =

# == 远古城市 ==
在[远古城市](远古城市.md)的结构的雕像下会生成一个[箱子](箱子.md)，其中有1个金苹果。

# 用途
# = 食物 =

手持金苹果按住键即可食用，每个金苹果可以恢复，并获得2分钟的[吸收](吸收.md)I效果（提供[伤害吸收值](伤害吸收值.md)）与5秒的[回復](回復.md)II效果（每25刻，每秒×0.4，共恢复）。

玩家在饥饿值满时也能吃金苹果。

# = 治愈僵尸村民 =

对带有[虚弱](虚弱.md)状态效果的[僵尸村民](僵尸村民.md)金苹果可使其转变为普通[村民](村民.md)。

# = 马、驴、骡 =
金苹果能将驯服[马](马.md)、[驴](驴.md)、[骡](骡.md)的概率增加10%，使其恢复点生命值，同时使马和驴进入[繁殖](繁殖.md)模式。给幼年马、幼年驴、幼年骡喂食金苹果可使其成长加速4分钟。
