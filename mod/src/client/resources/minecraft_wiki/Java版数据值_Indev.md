# Java版数据值/Indev

*页面ID: 22686* | *来源: Minecraft Wiki*

这些数据值适用于Indev版本中的方块和物品。自从Indev版本以来，方块和物品的数量在急剧增加，并且一些ID被移除或重新使用，Indev版本有了自己的数据值列表。带有<span style='color:#00BFFF'>亮蓝色</span>ID的物品无法以正常方式在游戏中在玩家的物品栏中得到。
