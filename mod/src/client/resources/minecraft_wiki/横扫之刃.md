# 横扫之刃

*页面ID: 42224* | *来源: Minecraft Wiki*

* *横扫之刃（Sweeping Edge）**是一种用于[剑](剑.md)的[魔咒](魔咒.md)，能增加横扫攻击的伤害。

# 获取

# 用途

I、II、III级分别为每一次[横扫攻击](近战攻击#横扫攻击.md)对每个实体造成的伤害附加50%、67%、75%的武器基础伤害。

以被命中的实体为中心，1×0.25×1范围内的实体都会受到伤害。

使用附有亡灵杀手或节肢杀手的剑攻击对应的生物可以造成额外的横扫攻击伤害。

横扫攻击最终带来的伤害的计算公式为：<math>1 + (\text{基础近战攻击力} + \text{额外攻击力}) \times \frac{\text{等级} }{\text{等级} + 1} + \text{魔咒攻击力}</math>。

比如：
* 一把附有横扫之刃I的铁剑每次横扫攻击可以对每个生物造成<math>1 + 6 \times \frac{1}{1+1} = </math>伤害。
* 一把附有锋利V和横扫之刃III的下界合金剑每次横扫攻击可以对每个生物造成<math>1 + 8 \times \frac{3}{3+1} + 3 = </math>伤害。
* 任何没有横扫之刃的剑每次横扫攻击可以对每个生物造成<math>1 + \text{基础伤害} \times \frac{0}{0+1} = </math>伤害。

高于III级的横扫之刃造成的伤害按照上方公式来计算，但附加伤害限制在基础伤害的100%以下。
