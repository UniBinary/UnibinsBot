# Amos Roddy

*页面ID: 151485* | *来源: Minecraft Wiki*

* *埃莫斯·罗迪（Amos Roddy）**是一名音乐制作人，他为Minecraft的[追逐天空](追逐天空.md)小更新创作了专辑*[Minecraft: Chase the Skies (Original Game Soundtrack)](Minecraft: Chase the Skies (Original Game Soundtrack).md)*。

# 生平
Amos Roddy在青少年时期受Boards of Canada和Brian Eno的音乐启发，领略到音乐的无限可能。在离开新墨西哥州前往太平洋西北地区后的首个冬天开始自学音乐，并于2014年创作出首张迷你专辑*Pigeon*。此后，他相继为包括Minecraft在内的多款电子游戏作曲。<ref>https://www.amosroddy.com/about</ref>
