# 启动器2.0.100x

*页面ID: 64982* | *来源: Minecraft Wiki*

* *2.0.1003**（[Windows](wzh:Microsoft Windows.md)）、**2.0.1004**（[macOS](wzh:macOS.md)）或 **2.0.1005**（[Linux](wzh:Linux.md)）是一次[启动器](启动器.md)更新，发布于2017年10月25日，修复了一些漏洞。

# 修复
* 修复了一些启动Mod版本时的问题。
*  - 丢失会导致<code>java.io.FileNotFoundException</code>崩溃。
*  - Java 9无法识别虚拟机选项。
