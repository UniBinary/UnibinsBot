# Java版标签/村民交易

*页面ID: 178574* | *来源: Minecraft Wiki*

* *村民交易标签（Villager Trade Tags）**是[村民交易](村民交易定义格式.md)的组合。

# 使用
村民交易标签可以被[交易集](交易集.md)调用，作为当此可抽取的所有可能的交易。
