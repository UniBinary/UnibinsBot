# 基岩版1.17.40.21

*页面ID: 89853* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.17.40.21**是[基岩版1.17.40](基岩版1.17.40.md)的第2个测试版，发布于2021年9月22日<ref></ref><ref></ref>，加入了旧世界开启[实验性玩法](实验性玩法.md)后升级至新世界的支持，并修复了一些漏洞。

# 更改
# = 常规 =
* *[RenderDragon](RenderDragon.md)**
* 移除了对Android ARMv7设备的支持。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“洞穴及悬崖”和“启用游戏测试框架”子选项后才可使用。

# = 世界生成 =
* *[溶洞](溶洞.md)**
* 现在洞穴中的[草方块](草方块.md)会在世界生成时替换为[石头](石头.md)。

* *[山地](山地.md)**
* 山顶的地形现在会更陡峭、崎岖。
* 略微提升了山地和山顶生物群系的海拔高度。

* *[石岸](石岸.md)**
* 现在地表上有概率生成条带状的[沙砾](沙砾.md)地层。

* *[裸岩山峰](裸岩山峰.md)**
* 现在地表上有概率生成条带状的[方解石](方解石.md)地层。

* *常规**
* 现在开启“洞穴及悬崖”选项后，旧区块的Y=0以下处会使用新的世界生成和洞穴生成。<ref></ref>
* * 之前版本升级过的区块的基岩层下方不会出现此更改。
* * 旧区块的基岩层会被替换为[深板岩](深板岩.md)。
* 现在开启“洞穴及悬崖”选项后，旧的[超平坦世界](超平坦世界.md)会升级至新的世界建筑[高度](高度.md)。
* 现在开启“洞穴及悬崖”选项的新超平坦世界会从Y=-64开始生成。

# 修复
* *实验性**
* 修复了beta版中无法飞行至世界高度限制之上的问题（开启洞穴及悬崖实验性玩法子选项前为Y=255，开启后为Y=319）。（）
* 现在铜矿石的最多生成高度是Y=96，而不是Y=64。（）

* *常规**
* 鼠标悬停在草方块时手持雪层不再导致行为异常。（、）
* 蜂巢现在会在世界中以正确的数量生成。（、）
* 非免疫火焰伤害的生物现在会避免进入火中。（）

* *游戏内容**
* 原版趋同：现在玩家可以在向上移动时使用鞘翅滑翔。（）
* 现在对着带有格式化代码的告示牌彩色文本使用染料染色会覆盖掉之前的格式化代码。

* *世界生成**
* 现在化石在其他结构上生成并将其破坏的概率更小了。
* 要塞在开启[实验性玩法](实验性玩法.md)（洞穴及悬崖子选项）后不再会生成于错误位置或消失不见。（）

* *生物**
* 铁傀儡现在仅会生成在固体方块上。（）
* 掠夺者和卫道士现在会正确渲染其使用的武器。（）

* *用户界面**
* 现在非触摸控制玩家骑乘动物时会显示正确的按钮提示。

* *角色创建器**
* 背景皮肤不再会遮挡更衣室界面的左右箭头了。
* 修复了点击更衣室界面的特色项目时不会打开角色创建器的特色项目界面的问题。
* 修复了修改另一物件的颜色时默认衣服也会改变颜色的问题。
* 现在可使用控制器来从之前选择的侧边栏选项导航回扩展视图中，以选择侧边栏选项。
* 打开角色创建器的经典皮肤包时，侧边栏不再会被打开。
* 改进了角色创建器的导航路径，以使其始终切换至选定的角色创建器角色。（）
* 现在可以在游戏中为角色装备市场中的皮肤。

* *技术性**
* 修复了修改渲染控制器时动画会重新启动的漏洞。
* 修复在告示牌文本编辑界面上换行时会丢失文本格式的问题。现在文本会一直显示其拥有的格式，直到输入重置文本代码或其他格式化代码为止。之前放置的告示牌不会因此更改。
* 现在包含大写字母的Molang表达式会被正确评估了。
* 查询现在会正确识别海晶灯。（）
* 为等在之前被忽略的表达式加入了新的编译错误（引擎版本1.17.40更改）。</onlyinclude>
