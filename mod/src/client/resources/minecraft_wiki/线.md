# 线

*页面ID: 6995* | *来源: Minecraft Wiki*

* *线（String）**是一种可用于合成的[物品](物品.md)。线可以被放置为**绊线（Tripwire）**，可与[绊线钩](绊线钩.md)结合而构成绊线线路。

# 生成
# = 自然生成 =
[丛林神庙](丛林神庙.md)内会自然生成5个绊线。

[试炼密室](试炼密室.md)的柱廊结构及<code>encounter_4</code>结构中会自然生成绊线。

# 获取
# = 蜘蛛网 =
没有被具有[精准采集](精准采集.md)的工具或剪刀挖掘破坏时，[蜘蛛网](蜘蛛网.md)被破坏后会掉落1个线。

# = 生物掉落物 =

# = 钓鱼 =
使用未带有[魔咒](魔咒.md)的[钓鱼竿](钓鱼竿.md)钓鱼时有0.6%的概率作为[垃圾](钓鱼#垃圾与宝藏.md)钓到线。使用附有[海之眷顾](海之眷顾.md)I、II或III魔咒的钓鱼竿[钓鱼](钓鱼.md)时该概率则是0.5%、0.4%或0.3%。

# = 礼物 =

已驯服的[猫](猫.md)赠予玩家礼物时，礼物有16.129%的概率是1个线。

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家3-9个线。

# = 箱子战利品 =

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落线。

# 破坏
绊线被挖掘时会立刻被破坏。

绊线被破坏后会掉落1个线。破坏有效绊线线路中的绊线时，如果不是被剪刀挖掘破坏的，会导致与其相连的绊线钩输出一次的红石信号。

# 用途
线可以作为合成材料，绊线可应用于红石电路。

绊线在以下情况会被破坏并掉落线：
* [水](水.md)流过绊线所处位置时
* [活塞](活塞.md)尝试推动绊线或推动方块占据绊线所处位置时

[熔岩](熔岩.md)流过绊线时，绊线会被直接破坏，不掉落线。

# = 红石电路 =

绊线构成能够由实体触发的绊线线路。

;放置
  要放置绊线，对着需要放置绊线的平面上线。

  要使绊线能够被激活并从[绊线钩](绊线钩.md)处产生红石信号，其必须构成“绊线线路”：在一条直线上，两端为附着在方块上的绊线钩，中间用1-40个[绊线](绊线.md)连接。在有效的绊线线路内的绊线有一个矮碰撞箱（顶部0.09375或格，底部悬空0.0625或格），而不在有效的绊线线路内的绊线有一个更高的碰撞箱（0.5格高，不悬空）。

;触发

  几乎所有[实体](实体.md)（玩家、生物、矿车、船、掉落的物品、箭矢等等）在进入绊线的碰撞区域时会将其激活。绊线在碰撞区域内所有实体都离开后才会取消其激活状态。某些箭、被扔出去的[喷溅药水](喷溅药水.md)、[末影珍珠](末影珍珠.md)和[末影之眼](末影之眼.md)等不会激活绊线。

  触发后，绊线每隔10游戏刻更新一次信号。更新信号时如果发现绊线上已经没有实体，会变为非触发状态。实体发生变化或离开时，绊线和绊线钩不会立即被更新。

;行为
  构成有效绊线线路的绊线在被触发时会同时触发线路中的绊线钩（输出红石信号）。被触发的绊线本身**不会**产生红石信号。
  构成有效绊线线路的绊线在被破坏时（包括被水冲毁）时会触发线路中的绊线钩，持续5红石刻（10[游戏刻](游戏刻.md)，0.5秒）。使用[剪刀](剪刀.md)挖掘绊线不会触发绊线钩。
  不构成有效绊线线路的绊线也可以进入触发状态，但其触发和取消触发只能用[方块更新感应器](方块更新感应器.md)或[侦测器](侦测器.md)检测到。
