# 矿境效果

*页面ID: 148604* | *来源: Minecraft Wiki*

* *矿境效果（Mine Effects）**，也称为**世界效果**，是控制[矿境](矿境.md)生成的机制，主要影响矿境内地形、出口位置、生物群系、生物生成等方面。

# 监测
在矿境内，当前生效的矿境效果会在屏幕左上角标记出来。

# 机制
每个矿境均会有自己的矿境效果。矿境将会遵循这些矿境效果生成地形、生物、替代石头生成的方块、生物群系，以及矿境出口结构。时间更替、天气效果、世界行为等亦会受部分矿境效果影响。

通过[矿境合成台](矿境合成台.md)创建矿境时，游戏会为该矿境随机赋予多个矿境效果，玩家亦可通过矿境合成台的界面选择自己所需要的矿境效果。

# = 解锁矿境效果 =
玩家可通过以下途径解锁矿境效果：
* 一小部分矿境效果默认解锁；
* 通过完成特定事件获得包含矿境效果的矿境原料。将这些矿境原料带到矿境出口并离开矿境，或者对着矿境合成台即可解锁；
* * 如果玩家已经解锁了矿境效果，或已在物品栏中获得对应的矿境原料，再次完成事件将不会获得矿境原料。
* 完成包含特定矿境效果、或满足矿境效果解锁条件的矿境可直接解锁。
* 部分矿境效果可以通过完成启用此效果的矿境来解锁。
只有解锁的矿境效果才能在矿境合成台内使用。尚未解锁的矿境效果会显示在矿境合成台界面右侧，会提示相应矿境效果的解锁方法。

游戏随机赋予的初始矿境效果不受解锁进度影响。此外，部分矿境效果即便解锁也不会在矿境合成台内显示，玩家无法手动选择这些矿境效果。

# = 矿境效果分类 =
矿境效果可被分为4类：常规、友好生物、敌对生物、特殊。

在提示框中，常规矿境效果是蓝色的，友好生物矿境效果是绿色的，敌对生物矿境效果是红色的，特殊矿境效果是紫色的。

此外，有少部分矿境效果不遵循上述的颜色规则。

# = 相互作用 =
部分影响同一机制的矿境效果不可共存，一个矿境内只会存在一系列矿境效果中的一个。玩家在矿境合成台内仍可选中与现有矿境效果不可共存的矿境效果，但是后选择的矿境效果将覆盖先前的不可共存矿境效果。

部分矿境效果之间互不兼容，玩家无法在矿境合成台内选中与现有矿境效果不兼容的矿境效果。

# = 经验加成 =
部分矿境效果具有经验加成，这类矿境效果生效时，玩家成功离开矿境时所获得的经验将会乘上对应的倍率。多个矿境效果的经验加成倍率可以叠加。

# 矿境效果列表
# = 世界类型 =

这些矿境效果控制了矿境内的世界基础地形如何生成。矿境必须包含其中一个效果，这些矿境效果**不可共存**。这些矿境效果无额外经验倍率，名称颜色均为蓝色。

# = 出口类型 =
这些矿境效果控制了[矿境出口](矿境出口.md)如何生成。矿境必须包含其中一个效果，这些矿境效果**不可共存**。这些矿境效果无额外经验倍率，名称颜色均为蓝色。

# = 生物群系 =
这些矿境效果主要控制了矿境内可以生成何种生物群系。矿境必须至少包含其中一个效果，这些矿境效果**可以共存**。这些矿境效果无额外经验倍率，名称颜色均为蓝色。

# = 生物生成 =
以下矿境效果控制矿境中可自然生成的生物。这些矿境效果**可以共存**。

# == 友好生物 ==
这些矿境效果负责友好生物生成，名称颜色均为绿色。

# == 敌对生物 ==
这些矿境效果负责敌对生物生成，名称颜色通常为红色，例外是矿境效果“蜜蜂”的名称颜色为浅绿色。

# = 基础岩石类型 =
这些矿境效果主要控制了矿境内世界生成使用的基础岩石。矿境必须至少包含其中一个效果，这些矿境效果**不可共存**。矿境效果的名称颜色均为蓝色。

# = 其他 =
以下矿境效果影响矿境中各方各面的机制，包括方块表面效果、玩家属性、生物行为、时间与天气更替等。

# == 特殊事件 ==
以下矿境效果通常只用于特殊矿境且不可解锁。这些矿境效果无额外经验倍率，名称颜色均为蓝色。实际效果见下文。

# 不共存效果
除了部分同类型矿境效果之间的不兼容性以外，部分矿境效果额外与某些矿境效果不兼容：
* 世界类型“洞穴世界”和“黑暗洞穴世界”与出口类型“地表出口”和“稀有的地表出口”不兼容。
* 世界类型“洞穴世界”和“黑暗洞穴世界”与需要露天才有实际影响的“永恒之夜”“永恒之雨”“永恒雷暴”以及“末影龙Boss战”不兼容。
* “旱地”与“美西螈”“如鱼失水”和“水世界”不兼容。
