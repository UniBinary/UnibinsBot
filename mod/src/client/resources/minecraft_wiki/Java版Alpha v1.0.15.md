# Java版Alpha v1.0.15

*页面ID: 32647* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.15**是的一次更新，发布于2010年8月3日<ref></ref>，重新加入了[多人游戏](多人游戏.md)。

# 新内容
# = 游戏内容 =
* *动画**
* 加入了[游泳](游泳.md)时手臂挥动的动作，可以在多人生存模式中的第三人称模式中看到。

# = 命令格式 =
* ***
* 掉落4个[树苗](树苗.md)。

* ***
* 掉落4块[铁锭](铁锭.md)。

# 更改
# = 方块 =
* *[火](火.md)**
* 现在拥有新的行为。

* *[熔岩](熔岩.md)**
* 现在可以点燃方块了。

* *[书架](书架.md)**
* 更改了合成配方，现在可用6块木板和3本书来合成。

# = 物品 =
* *[第三人称视角](第三人称视角.md)**
* 更改了手持物品的外观。

# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 现在可以输入[Mojang](Mojang.md)服务器以外的[服务器](服务器.md)的IP地址。

# = 常规 =
* *[徽标](徽标.md)**
* 更改了徽标，修复了徽标中的字母“M”。

# 修复
* *修复了2个漏洞**
* 玩家不再能在打开背包界面时移动。
* 玩家不再能在覆盖了雪的实体位置上放置方块。</onlyinclude>

# 你知道吗
* 该版本对应的发布博文被标注为“Minecraft Alpha v1.0.14”，与四天前于7月30日发布的[先前版本](Java版Alpha v1.0.14.md)重复。<ref></ref>不过jar文件的日期和博文的时间戳清晰地体现出其实际为Alpha v1.0.15。
