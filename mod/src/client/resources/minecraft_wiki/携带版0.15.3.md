# 携带版0.15.3

*页面ID: 23294* | *来源: Minecraft Wiki*

* *v0.15.3 alpha**是携带版的一次次要更新，发布于2016年7月19日<ref></ref>，此次更新仅在Android发布，修复了一些漏洞。

# 更改
# = 方块 =
* *[侦测器](侦测器.md)**
* 修复了[侦测器](侦测器.md)方块的放置。

* *[活塞](活塞.md)**
* 对移动中的方块进行调整使其之间行为更加协调和统一。

# = 物品 =
* *[地图](地图.md)**
* 对地图绘制进行调整。

# = 生物 =
* *[马](马.md)**
* 更改了马的繁殖系统以使其与其他版本相协调。

# = 常规 =
* *[多人游戏](多人游戏.md)**
* 多人邀请屏幕文本对齐方式固定。

* *[Realms](Realms.md)**
* 调整[Realms](Realms.md)中的一些购买功能。

* *[控制](控制.md)**
* 针对鼠标控制功能进行微调。

* *[市场](市场.md)**
* 市场页面布局尺寸现在变得更合适。

# 修复

* *其他**
* 使用控制器时，玩家不能在加入Realm界面里滚动好友列表。
* 玩家骑乘猪、马、驴或骡时无法打开物品栏。
* 沙漠里生成的僵尸猪人纹理错误。
* 下界砖栅栏会和单个圆石墙连接起来。
* 登出时，好友列表被清空。
* 马的坠落伤害计算错误。
* 在启动界面按下X按钮使得玩家登出。
* 切换阳光探测器状态时，手持的方块纹理显示错误。
* 可以利用栅栏来复制物品。
* 侦测器放置时出现朝向问题。
* 紧挨放置在地毯、压力板、积雪旁边的玻璃和树叶隐形。
* 成熟的作物不再亮度为0的地方掉落。
* 鸡骑士的模型渲染出错。
* 朝着TNT矿车使用发射器射箭使得游戏崩溃。
* 修复了各种使得游戏崩溃的漏洞。
