* *泥巴（Mud）**是一种大量生成于[红树林沼泽](红树林沼泽.md)的方块，也可通过对[泥土](泥土.md)及其变种[水瓶](水瓶.md)、[喷溅型水瓶](喷溅型水瓶.md)或[滞留型水瓶](滞留型水瓶.md)产生。

# 生成
# = 自然生成 =
泥巴会在[红树林沼泽](红树林沼泽.md)生物群系自然生成。

泥巴也会在[古迹废墟](古迹废墟.md)中自然生成。

泥巴也可能会在[试炼密室](试炼密室.md)的“入口”结构中作为植物造景的一部分生成。

# = 转化 =
对有方块标签的方块（[泥土](泥土.md)、[砂土](砂土.md)或[缠根泥土](缠根泥土.md)）[水瓶](水瓶.md)、[喷溅型水瓶](喷溅型水瓶.md)或[滞留型水瓶](滞留型水瓶.md)，或触发装有水瓶的[发射器](发射器.md)，可以使其转变为泥巴，并返还一个[玻璃瓶](玻璃瓶.md)。

# 获取
泥巴的物品形式只能通过破坏泥巴或击杀手中搬着泥巴的[末影人](末影人.md)来获得。

# 破坏
挖掘泥巴的合适工具是锹。

泥巴被破坏后会掉落自身。

# 用途
[末影人](末影人.md)可以搬起及放下泥巴。关闭[游戏规则](游戏规则.md)将阻止该行为。

# = 方块高度 =
泥巴的[方块高度](方块高度.md)为0.875格，与[灵魂沙](灵魂沙.md)相同（但泥巴不会造成减速），会使上方的[实体](实体.md)下陷2个像素，因此[漏斗](漏斗.md)可以吸取到掉落在泥巴上的掉落物。

# = 种植 =
泥巴的上表面可以种植[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)、[蕨](蕨.md)、[大型蕨](大型蕨.md)、[花](花.md)、[粉红色花簇](粉红色花簇.md)、[野花簇](野花簇.md)、[灌木丛](灌木丛.md)、[枯萎的灌木](枯萎的灌木.md)、[大型垂滴叶](大型垂滴叶.md)、[下界菌](下界菌.md)、[菌索](菌索.md)、[下界苗](下界苗.md)、[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)，[树苗](树苗.md)、[竹子](竹子.md)和[甜浆果丛](甜浆果丛.md)能在泥巴上生长。[甘蔗](甘蔗.md)和[蘑菇](蘑菇.md)也会在符合条件的情况下在泥巴上生长。

# = 合成材料 =

# = 转化 =
将泥巴放置在下方挂有[滴水石锥](滴水石锥.md)的方块上方会使其每随机刻有（约17.6%）的概率转化为[黏土](黏土.md)，平均转化时间为388.4秒。泥巴在[下界](下界.md)由[环境属性](环境属性.md)<code>gameplay/water_evaporates</code>控制。}}中不会转化。<ref></ref>

对上方为空气的[苔藓块](苔藓块.md)或[苍白苔藓块](苍白苔藓块.md)[骨粉](骨粉.md)，会使周围7×11×7范围内最上方的泥巴转变为苔藓块或苍白苔藓块。

[杜鹃树](杜鹃树.md)长成后会将其下方的泥巴转变为[缠根泥土](缠根泥土.md)。

[大型云杉](大型云杉.md)长成后会将其下方及周围的泥巴转变为[灰化土](灰化土.md)。

除大型云杉、杜鹃树、[红树](红树.md)及[珍异橡树](珍异橡树.md)外的[树木](树木.md)长成后，下方的泥巴会被转变为[泥土](泥土.md)。

# 你知道吗
* 泥巴最初设计为类似流体的方块，可以使穿着[靴子](靴子.md)的玩家陷入其中六个像素深，在玩家脱离泥巴的过程中靴子会脱落。但开发者考虑到泥巴将作为建筑材料使用所以弃用了此特性。<ref></ref>
* 泥巴可以转变成[苔藓块](苔藓块.md)，由于泥巴的高度为0.875格而苔藓块的高度为1格，转变时站在上面的实体会陷进苔藓块中<ref></ref>。
