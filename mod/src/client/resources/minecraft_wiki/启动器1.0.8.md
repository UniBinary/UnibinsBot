# 启动器1.0.8

*页面ID: 49341* | *来源: Minecraft Wiki*

* *1.0.8**是2013年7月2日，7月8日和7月9日发布的[启动器](启动器.md)版本。第一个版本导致[Java版1.6.2](Java版1.6.2.md)在Mac OS X上无法启动的问题。第二个版本试图解决此问题，但未成功。 第三版成功解决了该问题。

# 修复
*  - 使用新启动器无法在Mac OS X 10.5.8上启动1.6（无效内存位置的访问）。
*  - 在启动器中点击play并快速关闭它会使Java进程挂起并引发异常。
*  - 文字可能会在调整启动器大小中重叠。
*  - 1.0.4破坏了认证系统。
*  - 新启动器不能在macOS上启动早期的版本（1.5.2）（最新版本可以正常运行）。
