# 启动器2.0.28x-stage

*页面ID: 64842* | *来源: Minecraft Wiki*

<onlyinclude>
* *2.0.282-stage**（[Windows](wzh:Microsoft Windows.md)）或**2.0.283-stage**（[macOS](wzh:macOS.md)）是一个[Minecraft启动器](Minecraft启动器.md)的版本，发布于2016年11月2日。

# 新增
* *常规**
* 现在支持同时运行多个Minecraft实例了。
* 现在启动器可以在游戏打开的情况下不自动关闭，这使得玩家可以帮助页面等。
* 现在，在将设置迁移到新的启动器之前，会自动备份<code>launcher_profiles.json</code>（含有配置文件、登录名等）。
* 将“启动游戏”设置项略微缩小了一点，使得同一空间内可以容下更多设置项。
* “添加新启动选项”的按钮现在位于列表顶部了。
* “保持启动器打开”和“显示游戏日志”现在是单独的选项了。

* *Windows**
* 现在可以不从C盘的路径中运行启动器了。
* * 对于一部分玩家来说，运行启动器仍存在一些问题。
* 现在，游戏打开后再次单击启动器的<code>.exe</code>文件只会返回启动器窗口，而不会执行任何其他操作。

* *Linux**
* Linux支持仍在进行中。这项工作已经很接近成功了——启动器可以正常工作，但是我们还没有发行。

# 修复
* *常规**
* 修复了带有Mod的版本无法启动的问题。
* 分辨率设置现在可以正常工作了。
* 修正了即使打开游戏目录仍会显示错误消息的问题。
* 在输入框中按将不再删除该行的其余部分。
* 在新闻页面上按不再与新闻轮播混淆。
* 修复了游戏关闭时有时会发生崩溃的问题。
* 现在，使用鼠标选择输入并在键盘上按退格键即可正确地删除输入内容。
* 版本信息页面被单击时不再会选择所有文本。

* *Windows**
* 修复了自动更新的漏洞。
* * 这意味着玩家可能需要重新下载启动器才能获取更新。</onlyinclude>
