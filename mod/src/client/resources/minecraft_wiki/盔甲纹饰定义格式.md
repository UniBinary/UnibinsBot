# 盔甲纹饰定义格式

*页面ID: 138777* | *来源: Minecraft Wiki*

* *纹饰图案定义文件**和**纹饰材料定义文件**分别是**纹饰图案（Trim Patterns）**和**纹饰材料（Trim Materials）**在[数据包](数据包.md)中的数据驱动定义文件。纹饰图案和纹饰材料共同组成了**[盔甲纹饰](盔甲纹饰.md)（Armor Trim）**。

# 定义格式
# = 目录结构 =
纹饰图案需要在{{filepath|-{}-data/<*命名空间*>/trim_pattern}}目录内定义，纹饰材料需要在{{filepath|-{}-data/<*命名空间*>/trim_material}}目录内定义。

# = 盔甲纹饰图案 =
纹饰图案定义文件使用JSON格式，并具有下列结构：
<div class="treeview">
*  JSON文件根对象<section begin="codec_trim_pattern"/>
* * ：（[文本组件](文本组件.md)）物品提示框内盔甲纹饰图案的名称。
* * ：（命名空间ID）影响盔甲纹饰使用的纹理。
* * ：（默认为<code>false</code>）渲染盔甲纹饰时是否只在原盔甲纹理的位置上渲染。为<code>true</code>时盔甲纹饰不会在原盔甲的透明像素区域渲染。

纹饰材料定义文件使用JSON格式，并具有下列结构：

# 定义行为
纹饰图案或材料定义数据仅在服务端启动时被加载一次，使用命令不可以使盔甲纹饰定义被重新加载，而必须重启服务端。<ref></ref>

在[盔甲纹饰配方](配方#盔甲纹饰配方.md)中，纹饰材料被内联定义与锻造原材料的<code>provides_trim_material</code>组件内，纹饰图案被配方直接指定。此配方就可以为基础物品添加具有对应纹饰图案和材料的<code>trim</code>组件，用于外观的渲染。

# = 物品提示框 =
具有物品堆叠组件的物品会在物品提示框内显示定义的文本，第一行是盔甲纹饰图案，第二行是盔甲纹饰材料。

只要盔甲纹饰材料名称定义了某项[文本组件样式](文本组件#组件样式.md)，此样式就会覆盖盔甲纹饰图案名称定义的此项文本组件样式。

# = 纹理 =
当生物装备了具有<code>trim</code>物品堆叠组件的物品时，游戏会获取盔甲纹饰数据，并尝试获取应该使用的装备模型预设层类型，在盔甲模型之上进行渲染。

盔甲纹饰纹理由[纹理图集](纹理图集.md)<code>minecraft:armor_trims</code>生成，游戏在渲染时将纹理解析为{{filepath|-{}-assets/<*命名空间*>/textures/trims/entity/<*装备模型预设层类型*>/<*图案路径*>_<*材料字符串*>.png}}。

* <code>-{}-<*装备模型预设层类型*></code>参见[装备模型](装备模型.md)。
* <code>-{}-<*命名空间*></code>和<code>-{}-<*图案路径*></code>即纹饰图案定义的命名空间ID。
* <code>-{}-<*材料字符串*></code>即纹饰材料和定义的字符串。

盔甲纹饰的纹理映射与其盔甲的装备模型的纹理映射相同，也即任何物品都具有渲染纹饰的能力。原版游戏并未直接定义实际纹理，而是定义了若干基本图案和调色板，使用<code>paletted_permutations</code>图集源类型枚举混合自动生成。因此在不修改此纹理图集的前提下所有的非原版盔甲纹饰纹理不会被主动加载。
