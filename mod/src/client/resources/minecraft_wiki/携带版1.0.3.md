# 携带版1.0.3

*页面ID: 27291* | *来源: Minecraft Wiki*

* *1.0.3**是携带版的一次次要更新，发布于2017年2月9日<ref></ref><ref>["Changelog for 1.0.3 beta build"](http://pocketbeta.minecraft.net/2017/02/changelog-for-103-beta-build.html) – Minecraft: Beta Changelogs</ref>，加入了糖果纹理包、荷兰语<ref></ref><ref></ref>和[服务器](服务器.md)移动包，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[纹理包](纹理包.md)**
* 加入了糖果纹理包。

* *[语言](语言.md)**
* 现在支持荷兰语。

* *[服务器](服务器.md)**
* 为服务器加入了移动包（TransferPacket），允许将玩家移动到另一个服务器<ref></ref><ref></ref>。
* 服务器现在可以检测到客户端的许多有用数据<ref></ref>。

# 修复
* *修复了16个漏洞**
*  - 侦测器的顶部纹理总是朝着北。
*  - 不会显示外部服务器的活动状态。
* 服务器的活动状态总是会在离线和在线之间切换。
* 玩家离开导致Realms世界崩溃。
* 使用相同的物品时游戏崩溃。
* 玩家进入生物群系变种时使得服务器崩溃。
* 压力板、按钮和其他红石元件无法更新。
* 漏斗的方块刻不会运作。
* 破坏门时出现问题。
* 可以复制物品。
* 玩家可以获得末地传送门方块。
* 侦测器的箭头不会指示正确的方块。
* 侦测器可以颠倒放置。
* Realms世界里不会显示非好友玩家。
* 蝙蝠不会经常生成。
* 移动端里的末地折跃门方块渲染出错。
