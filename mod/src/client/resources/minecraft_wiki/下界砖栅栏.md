# 下界砖栅栏

*页面ID: 163610* | *来源: Minecraft Wiki*

* *下界砖栅栏（Nether Brick Fence）**是一种正常情况下无法跳过的障碍方块，由[下界砖块](下界砖块.md)和[下界砖](下界砖.md)合成。

# 生成
# = 自然生成 =
下界砖栅栏生成于[下界要塞](下界要塞.md)的窗户栏杆、阳台围栏和门类结构中。

# 破坏
挖掘下界砖栅栏的合适工具是镐。下界砖栅栏需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

下界砖栅栏被破坏后会掉落自身。

# 用途
尽管下界砖栅栏看起来只有1格高，但它的[碰撞箱](碰撞箱.md)却有1.5格高。这意味着玩家和大多数生物在没有[跳跃提升](跳跃提升.md)效果时不能越过下界砖栅栏。不过由于其轮廓箱仍为1格高，因此通过其上方空间攻击或选中后面的方块不受影响。

下界砖栅栏的水平长度为0.25格，占据一个方块最中间的位置，多个下界砖栅栏连接时中间会被占据从而连成一个整体。

下界砖栅栏占据着方块的中心位置，碰撞箱宽度小于1格，因此处于水中的玩家或生物可以通过紧靠未[含水](含水.md)的下界砖栅栏呼吸。

# = 连接 =
与下界砖栅栏相邻的方块与下界砖栅栏相邻的面如果是完整的面，那么下界砖栅栏会自动与之连接，但不会连接[屏障](屏障.md)、[南瓜](南瓜.md)、[雕刻南瓜](雕刻南瓜.md)、[南瓜灯](南瓜灯.md)、[西瓜](西瓜.md)、任何类型的[树叶](树叶.md)和[潜影盒](潜影盒.md)。

下界砖栅栏会互相连接，但不会连接[木栅栏](木栅栏.md)。下界砖栅栏会连接侧面与之相邻的[栅栏门](栅栏门.md)。

# = 拴绳 =
使用[拴绳](拴绳.md)拴着实体时对着下界砖栅栏按下可将它们拴在下界砖栅栏上，并在下界砖栅栏上生成一个[拴绳结](拴绳结.md)。
