# Java版12w32a

*页面ID: 32472* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w32a**是[Java版1.4.2](Java版1.4.2.md)的首个快照，发布于2012年8月9日<ref></ref>。

# 新内容
# = 方块 =
* *[信标](信标.md)**
* 此时名称为“Work in Progress”（开发中）。
* 通过建造一个像[绿宝石块](绿宝石块.md)或[钻石块](钻石块.md)一样的储存性方块组成的金字塔然后将其放在顶端，玩家就可以获得一些[状态效果](状态效果.md)。
* * 一个完整的金字塔可以提供等级II效果，除非玩家在主能力上选择等级I效果。
* 不能被合成，虽然合成配方在计划中。
* * 可以创造模式物品栏中的通过“杂项”标签获得，或者通过命令获得。
* 最低范围是16格。
* 会发出等级15的光。
* 在方块范围内玩家每4秒会获得所选择的效果。
* 最好的方块构造需要164个方块。

* *[命令方块](命令方块.md)**
* 针对冒险地图设计。
* 被红石信号激活后会执行[服务器命令](服务器命令.md)。
* * 可以使用<code>@player</code>或者<code>@p</code>来代替最近的玩家。
* 这个方块不能够被合成，也不能在创造模式物品栏中获得，但是能够通过命令获得。

# = 物品 =
* *夜视[药水](药水.md)**
* 暂时只能在创造模式物品栏中获得。

# = 生物 =
* *[僵尸村民](僵尸村民.md)**
* 在困难难度下，村民被僵尸杀死后有概率变成僵尸村民。
* 僵尸刷怪蛋有概率生成僵尸村民。
* 僵尸村民可以自然生成。
* 僵尸村民可以被[治愈](僵尸村民#治愈.md)，变成普通的村民。
* * 对着拥有状态效果的僵尸村民[金苹果](金苹果.md)可使其开始治愈过程。<ref></ref>

# = 命令格式 =
* *[命令](命令.md)**
*
* ，值可以是<code>true</code>或<code>false</code>。所有的游戏规则除了<code>keepInventory</code>以外都默认为<code>true</code>。以下规则是可用的：
* * <code>doFireTick</code>（<code>false</code>=[火](火.md)不会传播）
* * <code>mobGriefing</code>（<code>false</code>=[苦力怕](苦力怕.md)爆炸后不会破坏方块）
* * <code>keepInventory</code>（<code>true</code>=死亡后物品栏里的物品不会丢失）
* * <code>doMobSpawning</code>（<code>false</code>=不生成生物）
* * <code>doMobLoot</code>（<code>false</code>=生物没有掉落物）
* * <code>doTileDrops</code>（<code>false</code>=方块被打破后没有掉落物）
*
*

# = 常规 =
* *数据文件夹**
* 数据文件夹和地图存档里有了新的文件。

# 更改
# = 生物 =
* *常规**
* [僵尸](僵尸.md)，[骷髅](骷髅.md)和[僵尸猪人](僵尸猪人.md)将根据难度有时携带着附魔武器和穿着任何种类的盔甲生成。

* *[铁傀儡](铁傀儡.md)**
* 现在会攻击[史莱姆](史莱姆.md)和[岩浆怪](岩浆怪.md)。

* *[绵羊](绵羊.md)**
* 刷怪蛋现在可以生成自然颜色的绵羊（白色、灰色、棕色和粉红色等等）。

* *[村民](村民.md)**
* 它们会对新的交易作出积极反应，在玩家伤害它们的时候会作出消极反应。
* * 这个效果只有在村民识别到周围的房子才会发生，通常都会在自然生成的村民上发生。
* 加入了一个未使用的粒子效果，用于表示生气的村民[10px](File:Angry Villager Particle.png.md)。
* 村民不再移除交易，但交易新的物品可能需要更新旧的。

* *[僵尸](僵尸.md)**
* 僵尸的攻击动画会在它们拿着武器时显示。

# = 常规 =
* *制作人员名单**
* 结束后出现的语录的作者由“马克·吐温”变为“未知”，因为该语录没有足够的证据证明出自马克·吐温。

# 修复
* *修复了2个漏洞**
* 修复了命令只能被OP使用的问题。
* 修复了命令不工作的问题。</onlyinclude>
