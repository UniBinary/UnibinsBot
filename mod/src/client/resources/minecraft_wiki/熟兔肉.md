# 熟兔肉

*页面ID: 12776* | *来源: Minecraft Wiki*

* *熟兔肉（Cooked Rabbit）**是一种能被[玩家](玩家.md)食用的[食物](食物.md)类[物品](物品.md)。

# 获取
# = 生物掉落物 =

# = 烹饪 =
生兔肉可以在[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或[营火](营火.md)中烹饪制成熟兔肉。

# = 礼物 =

[屠夫](屠夫.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷熟兔肉。

# 用途
# = 食物 =

手持熟兔肉按住键即可食用，每个熟兔肉可以回复。

# = 合成材料 =

# = 狼 =
熟兔肉能用来吸引、治疗或繁殖驯服的[狼](狼.md)，也可以使已驯服的幼年狼的剩余生长时间加快10%。
