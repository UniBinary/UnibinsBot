# Java版Infdev 20100415

*页面ID: 35947* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年4月15日，修复了一些漏洞。<ref></ref>

# 更改
# = 生物 =
* *常规**
* [生物](生物.md)现在正常生成。
* 大多数生物都会被保存了。

# = 非生物实体 =
* *常规**
* 大多数[实体](实体.md)都会被保存了。
* * 射出的[箭](箭.md)仍不会被保存。

# = 游戏内容 =
* *[皮肤](皮肤.md)**
* 现在可以正常使用自定义皮肤了。
* * 在离线情况下玩家的皮肤会显示为黑色。

# 修复
* *修复了3个漏洞**
* 修复一些损坏的光照代码。
* * 光照现在正确更新了。
* * 内存占用量降低。
* * 生成时未暴露在天空下的方块不再是完全黑色的。</onlyinclude>
