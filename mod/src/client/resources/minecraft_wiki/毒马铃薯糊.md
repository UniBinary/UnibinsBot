* *毒马铃薯糊（Poisonous Mashed Potato）**是一种类似[雪](雪.md)的[方块](方块.md)。

# 生成
# = 毒马铃薯鞋 =

当装备[毒马铃薯鞋](毒马铃薯鞋.md)的[生物](生物.md)摔落时，若摔落高度大于生物的[安全摔落高度](属性/安全摔落高度.md)，生物周围会被放置毒马铃薯糊。毒马铃薯糊的生成数量与半径和生物摔落高度呈正相关。

# 获取
毒马铃薯糊只能通过破坏毒马铃薯糊获得。

# 破坏
挖掘毒马铃薯糊的合适工具是锹。

毒马铃薯糊破坏后会掉落自身，且无视层数只掉落一个毒马铃薯糊。

# 用途
毒马铃薯糊会随着其下方方块的破坏而破坏。玩家可以跳上一个方块加上3层毒马铃薯糊的位置。

毒马铃薯糊会被流过的[水](水.md)或[熔岩](熔岩.md)破坏。

# = 影响实体移动 =

大部分实体会陷入毒马铃薯糊，在其中的移动速度会较为缓慢。生物陷入毒马铃薯糊不会窒息。

[摔落](摔落.md)到毒马铃薯糊上时没有摔落伤害。

# = 胶着 =
进入毒马铃薯糊的生物会获得[胶着](胶着.md)效果。

胶着效果的持续时间与生物脚部位置的毒马铃薯糊层数有关，默认给予5秒，每一层增加1秒。即站在一层毒马铃薯糊中可获得6秒胶着效果，一次性最多（8层）可获得13秒胶着效果。

# = 食用 =
玩家对毒马铃薯糊按下键可使其减少一层，同时恢复饥饿值。
