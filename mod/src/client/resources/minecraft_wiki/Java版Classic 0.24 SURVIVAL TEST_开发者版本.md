# Java版Classic 0.24 SURVIVAL TEST/开发者版本

*页面ID: 35655* | *来源: Minecraft Wiki*

该条目记录了[Java版Classic 0.24 SURVIVAL TEST](Java版Classic 0.24 SURVIVAL TEST.md)的所有开发者版本。

# 0.24（2009年8月4日）

该版本测试了挖掘方块产生的掉落物。<ref></ref>

# = 新内容 =
* *常规**
* 玩家可以通过破坏方块将其捡起并重新放置，其[掉落物](掉落物.md)捡起后会进入玩家的物品栏。
* * 物品栏中有无限的最大堆叠数。

; [控制](控制.md)
* 可以通过按住鼠标来挖掘方块，方块表面会出现裂痕直到被破坏产生掉落物。

# = 更改 =
* *[玩家](玩家.md)和[人类](生物（已移除实体）.md)**
* 面部纹理不再有一个山羊胡子。

# 0.24（2009年8月13日）

该版本初步测试了[盔甲](盔甲.md)和3D图像模式。<ref></ref>

# = 新内容 =
* *[盔甲](盔甲.md)**
* 加入了盔甲。

* *[选项](选项.md)**
* 加入了3D图像模式。

# 0.24（2009年8月14日）

该版本初步测试了[僵尸](僵尸.md)和[骷髅](骷髅.md)。<ref></ref>

# = 新内容 =
* *[僵尸](僵尸.md)和[骷髅](骷髅.md)**
* 没有碰撞箱。
* 不会攻击。
* 会带着随机盔甲自然生成在世界中。

# 0.24（2009年8月18日）

该版本初步测试了生命值。<ref></ref>

# = 新内容 =
* *[生命值](生命值.md)**
* 从高处坠落后会减少。

# 0.24（2009年8月20日）

该版本初步测试了[告示牌](告示牌.md)。<ref></ref>

# = 新内容 =
* *[告示牌](告示牌.md)**
* 按下时会出现预设文字：“This is the test of the signs. Each line can be 15 chars!”（"这是告示牌测试，每行可最多输入15字节！"）
* 属于[实体](实体.md)。

# 0.24（2009年8月22日）

该版本初步测试了[猪](猪.md)。<ref></ref>

# = 新内容 =
* *[猪](猪.md)**
* 会自然生成在世界中。
* 纹理与正式版本中的不同。

# 0.24（2009年8月25日）

该版本加入了一些方块，并完善了[生存模式](生存模式.md)。<ref></ref>

# = 新内容 =
* *[花](花.md)**
* 会自然生成在世界中。

* *[红色蘑菇](红色蘑菇.md)和[棕色蘑菇](棕色蘑菇.md)**
* 会自然生成在世界中。

* *常规**
* 加入了视觉摇晃。

# = 更改 =
* *[橡木原木](橡木原木.md)**
* 破坏原木现在会掉落3-5个木板。

* *[树叶](树叶.md)**
* 树叶现在会掉落树苗。

* *[树苗](树苗.md)**
* 树苗现在会长成[树](树.md)。

* *[熔岩](熔岩.md)**
* 现在会对玩家造成伤害。

* *[平视显示器](平视显示器.md)**
* 当前选定的方块显示在视图中。

* *[生物](生物.md)**
* 生物现在成群生成。
* 玩家和生物现在能互相碰撞。

* *[玩家](玩家.md)**
* 玩家现在能在水下呼吸15秒。

* *[生命值](生命值.md)**
* 受到伤害后，生命条现在会闪烁。
* 如果玩家生命值低，生命条会晃动。

# 0.24（2009年8月28日）

该版本加入了玩家的手臂。<ref></ref>

# = 新内容 =
* *[平视显示器](平视显示器.md)**
* 玩家的手臂现在是可见的。
* * 在没有手持物品时出现，并会在鼠标被按住时摆动。

# = 更改 =
* *[生物](生物.md)**
* 加入了[受击后伤害免疫](受击后伤害免疫.md)。
* 生物现在能受伤，但死亡后没有动画效果。
* 生物现在可以攻击玩家。
* 生物会在从高处坠落后会受到伤害。
