# Java版12w41b

*页面ID: 33156* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w41b**是[Java版1.4.2](Java版1.4.2.md)的第13个快照，发布于2012年10月12日<ref></ref>，发布以修复[12w41a](12w41a.md)里的漏洞和崩溃。

# 更改
# = 方块 =
* *[铁砧](铁砧.md)**
* 现在会根据掉落的高度受损。

# 修复
* *修复了3个漏洞**
* 修复了铁砧掉落时会自行修复的问题。
* 修复了在多人游戏中重命名物品时会发生的一些崩溃。
* 修复了命令不生效和不显示截屏信息的问题。</onlyinclude>
