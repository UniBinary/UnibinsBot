# Minecraft: Nether Update (Original Game Soundtrack)

*页面ID: 65489* | *来源: Minecraft Wiki*

* **Minecraft: Nether Update (Original Game Soundtrack)*（《Minecraft：下界更新（游戏原声带）》）**是[Lena Raine](Lena Raine.md)为[Minecraft](Minecraft.md)创作的首单专辑。本专辑在2020年6月14日在Spotify与Youtube音乐上发布。

本专辑包含5首乐曲，时长总计约20分钟，囊括了所有为[Java版1.16](Java版1.16.md)和[基岩版1.16.0](基岩版1.16.0.md)下界生物群系创作的曲目，以及*Pigstep*[音乐唱片](音乐唱片.md)物品的两个版本。

本专辑现已在[Spotify](https://open.spotify.com/album/0Q4LP9lkODPwHGCXZJJ3Rz?si=N4kam4imRMCz6Bl2QDbSkw)、[Google Play音乐](https://play.google.com/store/music/album/Lena_Raine_Minecraft_Nether_Update_Original_Game_S?id=Bffwildxatumby5b73jlkrq6zse)和[YouTube音乐](https://music.youtube.com/playlist?list=OLAK5uy_luAYVTWsWTSov-rb5Y_Q-5LZDCTPaNKfs)发售。
