# Java版16w39b

*页面ID: 25014* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w39b**是[Java版1.11](Java版1.11.md)的第8个快照，发布于2016年9月29日<ref></ref>，修复了[16w39a](16w39a.md)中的一些漏洞与崩溃。

# 更改
# = 方块 =
* *[花盆](花盆.md)**
* 现在可以按下键来移除已栽种的植物。

# = 生物 =
* *[羊驼](羊驼.md)**
* 掉落物现在受[抢夺](抢夺.md)影响。
