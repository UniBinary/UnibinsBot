# Java版18w22b

*页面ID: 34823* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w22b**是[Java版1.13](Java版1.13.md)的第41个快照，发布于2018年5月30日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[木头](木头.md)**
* 现在可以沿各坐标轴方向放置。

# = 命令格式 =
* *常规**
* 所有的命令反馈消息现在都被翻译了。

# = 常规 =
* *纹理**
* 改进了动画纹理的性能。

* *[聊天](多人游戏.md)**
* 用户名补全在聊天中可以使用了。
