# 基岩版1.16.0.63

*页面ID: 62454* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.0.63**是[基岩版1.16.0](基岩版1.16.0.md)的第14个测试版，发布于2020年5月20日<ref></ref>，加入了文本背景不透明度选项，并修复了一些漏洞。

# 新内容
# = 常规 =
* *辅助功能**
* 加入了“文本背景不透明度”选项，用于更改以物品的工具提示背景。

# 更改
# = 方块 =
* *[下界砖块](下界砖块.md)、[雕纹下界砖块](雕纹下界砖块.md)、[石英砖](石英砖.md)**
* 更改了纹理以匹配Java版。

* *[绯红木门](绯红木门.md)**
* 稍微更改了纹理。
* 绯红木活板门的英文名由“Crimson Trap Door”改为“Crimson Trapdoor”。

* *[诡异木门](诡异木门.md)**
* 稍微更改了纹理。

* *[锁链](锁链.md)**
* 现在被[活塞](活塞.md)推动时不会被破坏。
* 加入了音效。

* *[重生锚](重生锚.md)**
* 加入了音效。
* 现在只有使用钻石[镐](镐.md)和下界合金镐破坏才会掉落自身。
* 现在使用带有[精准采集](精准采集.md)的镐挖掘重生锚会保存其破坏前的能量。
* 现在重生时若重生锚被阻挡，则会在主世界重生。
* 在水中爆炸时不再能破坏方块。
* 现在在所有情况下都显示“重生点设置”消息。
* 现在可以在不设置重生点且不会在除[下界](下界.md)外的维度爆炸的情况下被充能。

* *[磁石](磁石.md)**
* 加入了音效。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[锻造台](锻造台.md)**
* 加入了使用时的声音。
* 改进了使用界面。
* * 向第二个输入槽加入下界合金锭轮廓。
* * 在输入槽上方加入了一个锤子图标，类似于铁砧的用户界面。

* *[墙](墙.md)**
* 现在会与[玻璃板](玻璃板.md)和[铁栏杆](铁栏杆.md)的底部和侧面连接。

* *[缠怨藤](缠怨藤.md)**
* 英文名从“Twisting Vines Block”更改为“Twisting Vines”。
* 现在触碰到水后会被破坏，并有一定概率会掉落其自身。

* *[绯红菌柄](绯红菌柄.md)和[诡异菌柄](诡异菌柄.md)**
* 现在挖掘的时间与挖掘普通[原木](原木.md)的时间相同。
* 现在可以合成其对应的木板。

* *[绯红菌核](绯红菌核.md)和[诡异菌核](诡异菌核.md)**
* 现在可以合成其对应的木板。

* *[发射器](发射器.md)**
* 现在可以用[骨粉](骨粉.md)催熟[垂泪藤](垂泪藤.md)和缠怨藤。
* 现在对重生锚每充能一次只消耗1[荧石](荧石.md)。

* *[垂泪藤](垂泪藤.md)**
* 现在碰到水后会被破坏，并有一定概率掉落其自身。

* *[灵魂土](灵魂土.md)**
* 现在合适挖掘工具是[锹](锹.md)。

* *[灵魂火把](灵魂火把.md)**
* 现在可以用[木炭](木炭.md)合成。

# = 物品 =
* *[磁石指针](磁石指针.md)**
* 加入了使用时的音效。

* *[诡异菌钓竿](诡异菌钓竿.md)**
* 现在可以在[铁砧](铁砧.md)上附魔。

* *[下界合金锹](下界合金锹.md)**
* 现在可以熄灭[营火](营火.md)。

# = 生物 =
* *常规**
* 现在能够装备盔甲的生物可以装备[海龟壳](海龟壳.md)。
* 现在生物可以在[灵魂沙](灵魂沙.md)上寻路了。
* 生物不再消耗自己所捡到的物品。

* *[蜜蜂](蜜蜂.md)**
* 降低了被激怒的蜜蜂的速度。

* *[炽足兽](炽足兽.md)**
* 调整炽足兽在熔岩上的移动速度以匹配Java版。
* 现在会受到摔落伤害。

* *[疣猪兽](疣猪兽.md)**
* 现在具有击退抗性。
* 不再会淹死于熔岩中。
* 更改了逃跑时的行为。
* 现在会对装备[弩](弩.md)的猪灵进行较少的反击。

* *[猪灵](猪灵.md)**
* 现在猪灵在离开[灵魂火](灵魂火.md)、[灵魂灯笼](灵魂灯笼.md)或[灵魂营火](灵魂营火.md)时会发出一种声音。
* 更改了逃跑时的行为。
* 现在跑得比疣猪兽快。
* 现在[陷阱箱](陷阱箱.md)被玩家破坏时猪灵会被激怒。

* *[僵尸疣猪兽](僵尸疣猪兽.md)**
* 现在具有击退抗性。
* 不再会淹死于熔岩中。
* 更改了纹理。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 调整下界生物群系的分布以匹配Java版。
* 现在[诡异森林](诡异森林.md)相比其他下界生物群系更少见了。
* 玩家进入诡异森林时，之前播放的音乐目曲将播放至结束。

# = 命令格式 =

* 现在可以清除[磁石指针](磁石指针.md)。

# = 常规 =
* *闪烁标语和[菜单屏幕](菜单屏幕.md)**
* 更新了[Mojang Studios](Mojang Studios.md)的Logo。

* *其他**
* 更新了Mojang Studios的加载屏幕。
* 更新了基岩版鸣谢名单。

# 修复
* *崩溃**
* 修复了几个游戏中可能发生的崩溃。
* 修复了在生存模式中合成64个蜂蜜块时发生的崩溃。（）
* 修复了一个由下界合金盔甲引起的崩溃。
* 修复了生物更改状态时可能发生的崩溃。
* 修复了以解决飞行实体落地时的卡顿。

* *常规**
* 修复了Xbox One玩家访问市场可能出现的错误问题。
* 提高了加载玩家角色时的稳定性。（）
* 修复了离线时玩家角色可能会丢失的问题。
* 修复了离线状态下重新登录账户后无法取得成就的问题。
* 修复了玩家在第三人称视角中使用钓鱼竿时手部动画不正确的问题。（）
* 修复了Xbox无法同步用户数据的问题。（）
* 修复了分屏游戏时其他玩家的动作渲染问题。
* 现在长时间暂停游戏后继续游戏，玩家的模型不再会消失。（）
* 修复了分屏游戏中当一名玩家看向其他玩家时，其他玩家的手会消失的问题。（）
* 修复了当服务器启用实验性玩法后客户端未启用的问题。
* 优化了声音的加载， 语句现在已经从sound_definitions.json中移除，这使得所有的音效都可以在低内存的设备上播放。
* 修复了一个转换世界时的问题，该问题导致了一些区块中的物品被错误地转换为基岩。

* *游戏**
* 现在染色潜影盒不会导致其包含的物品消失。（）
* 修复了站在压力板上退出游戏所引起的玩家生成位置错误的问题。（）
* 修复了将箭、烟花火箭或鹦鹉螺壳放入副手时会导致副手物品栏UI显示不正常的问题。（）
* 修复了被熔岩烧死的动物会掉落生肉的问题。（）
* 现在“你的床已遗失或被阻挡”信息能够正常显示了。
* 现在重生锚在所有情况下都显示“重生点设置”消息。（）
* 重生锚可以在不设置重生点且不会在除下界外的维度爆炸的情况下被充能。（）
* 重生锚可以在未充能的情况下使用（但不会被激活）。
* 现在农民村民不论其物品栏有多少农作物，都会收割农作物。（）
* 现在经验球生成后会四散开来而不是原地不动。（）
* 现在如果没有足够的空间让玩家在起床后站在床上或床边，那么玩家无法使用床。（）
* 现在无法与端详金锭的猪灵互动。（）
* 现在重生锚能量耗尽时会播放特定音效。（）
* 现在命令支持清除磁石指针。（）
* 屏障不再生成于堡垒遗迹。（）
* 现在堡垒堡垒中的箱子总会生成战利品。（）
* 现在持有剑的生物死亡后不会再掉落两把相同材料的剑。
* 修复了使用锻造台后无法播放相应音效的问题。（）
* 现在重生锚充能声音不会在玄武岩三角洲生物群系中频繁播放。（）
* 现在发射器可以用骨粉催熟缠怨藤。（）
* 下界苗被活塞推动时不再会掉落无法使用的无用物品。（）
* 现在移动中的方块拥有正确的碰撞箱。（）
* 现在关闭火焰蔓延选项后，在灵魂沙或灵魂土上点火会正确地产生灵魂火。（）
* 营火现在可以使用木炭合成。（）
* 在切石机中使用石英块可以制成石英台阶而不是平滑石英台阶。（）
* 现在发射器对重生锚充能时只消耗1荧石。（）
* 精准采集魔咒和命令现在支持绯红木按钮、诡异木按钮、绯红菌核、去皮绯红菌核、诡异菌核、去皮诡异菌核、垂泪藤、缠怨藤、磨制黑石压力板和磨制黑石按钮。
* 现在灵魂火把可以使用木炭合成了。（）
* 现在诡异菌钓竿可以像胡萝卜钓竿一样在铁砧上附魔。（）
* 现在炽足兽会受到摔落伤害。（）
* 现在骑在成年炽足兽上的幼年炽足兽在成年炽足兽离开熔岩时会变紫。（）
* 现在下界合金质物品不会着火了，因为它是无法被烧毁的。
* 现在大型玄武岩柱的高度不能超过10个方块。
* 现在玄武岩三角洲生物群系会正确地生成方块。
* 现在黑石按钮、压力板、台阶和墙会在地图上正确显示。
* 现在重生锚只能使用钻石或下界合金镐采集。（）
* 现在除猪灵外的生物更倾向于捡起石剑而不是金剑。
* 现在垂泪藤和缠怨藤在破坏时会播放正确的音效。
* 现在锁链放置或破坏时会播放音效了。
* 现在重生锚需要使用镐采集。
* 部分物品的配方不再默认使用绯红木板或诡异木板。
* 玩家在掉落时重启世界不再生成于方块上。
* 修复了一个可能让玩家在水中重生的问题。
* 现在下界合金锹能够熄灭营火。（）
* 现在锹可以更快地挖掘灵魂土。（）
* 现在绯红菌柄和诡异菌柄可以合成其对应的木板。（）
* 现在发射器可以用骨粉催熟垂泪藤。（）

* *生物**
* 修复了在台阶上的鸡不会受到熔岩伤害的问题。（）
* 现在疣猪兽远离诡异菌后会恢复平静。
* 村民不再丢弃自己捡到的物品。
* 现在对着僵尸疣猪兽按下选取键会获得僵尸疣猪兽刷怪蛋。
* 下界合金头盔在猪灵头上会正确地渲染了。
* 部分生物在熔岩中淹死会改变行为。
* 在以物易物时，金锭会正确地在猪灵手上渲染。
* 疣猪兽不再远离僵尸疣猪兽。
* 修复了宠物瞬移到下界或从下界瞬移后可能会消失的问题。
* 被激怒的蜜蜂的速度变得更慢了。（）

* *方块**
* 锁链现在可以连接铁栏杆和玻璃板的底部和侧面。（）
* 菌核现在可以合成对应的木板了。（）
* 现在移动中的方块拥有正确的碰撞箱。（）

* *图形**
* 修复了亮度较低的发光方块在放置后的亮度不正确的问题。
* 修复了刷怪笼中的生物不可见的问题。（）
* 物品展示框中的地图的边缘不再会多出几条白线。（）
* 修复了加载后的地图纹理丢失的问题。（）
* 修复了从下界传送门返回主世界时光照亮度未刷新的问题。（）
* 修复了播放手臂的动画时手臂会不断摇动的问题。（）
* 生物举起物品会正确渲染了。
* 磁石指针现在会在物品栏中正确渲染。

* *用户界面**
* 调整了服务器列表。
* 合成配方再一次可以分组显示。
* 为文字加入了可调整不透明度的背景，可前往“辅助功能”设置中调整其不透明度。
* 为命令执行的屏幕标题加入了背景，该背景也应用在物品名称的文字。
* 更新了锻造台的UI界面。

* *命令**
* 修复了命令无法生成ID不带有前缀的蜜蜂及其他新生物的漏洞。（）
* 为加入了新的选项，会替换（旧版方式）或保持旧选项（若某个物品已经位于该槽位，则返回错误）。
* 修复了无法清除损坏的工具的问题。
* 若使用命令在新方块上使用非默认方块状态，则无法执行命令。（）
* 命令现在可以执行更多的方块状态。

* *附加包和脚本**
* 修复了市场上的“Rescue Mission Lava Town”地图中的箱子被击退后无法移动的问题。
* 加入了新的循环模式动画：现无需设置以在完成后结束播放，或将设置为true以在完成后循环播放。现只需在输入即可保持动画的最后一帧。
* 若范围内的json节点的数组只设置了单个值，则现在会显示错误。
* 若使用多个移动控制组件、跳跃控制组件和导-{}-航组件，则现在会显示错误。
* 包含有效和无效命令的函数，现只会执行其中版本为1.15的有效命令，该函数的名称不会出现在自动补全建议列表中，但直接输入仍可执行。
* 从1.16开始，若函数中带有任何无效命令（比如错误的选择器），则其不再可以注册和使用。
* 在设置json变量和的数值时，若最小值大于最大值，则组件现在会正确报错。（）
* 修复了播放音效时会应用错误设置的问题，该问题导致2d音效被视为3d音效而播放，反之亦然。
* 修复了错误地阻断音效播放的问题，尽管该问题依然容易发生，但加载音效时不再会占用大量内存。
* JSON数组中的注释不再会引发错误。（）</onlyinclude>
