# Java版21w14a

*页面ID: 81123* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w14a**是[Java版1.17](Java版1.17.md)的第16个快照，发布于2021年4月7日<ref></ref>，加入了粗金属，添加了为完全锈蚀的铜块涂蜡的特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[铜块](铜块.md)及其变种**
* 加入了完全锈蚀的铜质方块的涂蜡变种。
* * 涂蜡的氧化铜块
* * 涂蜡的氧化切制铜块
* * 涂蜡的氧化切制铜台阶
* * 涂蜡的氧化切制铜楼梯

# = 物品 =
* *[粗金属](粗金属.md)**
* 加入了[粗铁](粗铁.md)、[粗铜](粗铜.md)和[粗金](粗金.md)。
* * 可以熔炼成锭。
* * 现在不使用带有[精准采集](精准采集.md)魔咒的镐开采[铁矿石](铁矿石.md)、[铜矿石](铜矿石.md)和[金矿石](金矿石.md)不再掉落矿石本身，而将掉落其相应的粗金属。
* ** [铁矿石](铁矿石.md)、[铜矿石](铜矿石.md)、[金矿石](金矿石.md)仍然可以被熔炼成锭。
* * 与其他矿物类似，[时运](时运.md)魔咒会影响这些矿物的掉落量。
* * [猪灵](猪灵.md)会尝试捡起粗金。

# 更改
# = 方块 =
* *铜块及其变种**
* 现在铜块、[切制铜块](切制铜块.md)、[切制铜台阶](切制铜台阶.md)、[切制铜楼梯](切制铜楼梯.md)的[氧化](氧化.md)变种可以使用[蜜脾](蜜脾.md)涂蜡。

* *[标签](Java版标签.md)**
* 涂蜡的氧化切制铜楼梯和涂蜡的氧化切制铜台阶分别被添加进方块和物品标签中。
* 粗金被添加进物品标签中。
