# Java版25w17a

*页面ID: 150246* | *来源: Minecraft Wiki*

<onlyinclude>

* *25w17a**是[Java版1.21.6](Java版1.21.6.md)的第3个快照，发布于2025年4月22日<ref></ref>，将[定位栏](定位栏.md)正式加入到游戏中，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[选项](选项.md)**
* 加入了“云层距离”视频设置选项以调整云层渲染范围，默认为128个区块。

# = 命令格式 =
* ***
* 加入了如下新语法：
* * <code>waypoint modify <entity-selector> color reset</code>
* ** 重置路径点颜色效果。
* * <code>waypoint modify <entity-selector> style set <waypoint_style/resource></code><ref>官网更新日志称为<code>waypoint modify <entity-selector> style <waypoint_style/resource></code></ref>
* ** 更改路径点样式。
* * <code>waypoint modify <entity-selector> style reset</code>
* ** 重置路径点样式。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了下列方块标签：
* * ：。
* ** [快乐恶魂](快乐恶魂.md)不会主动靠近的方块。
* * ：。
* ** 控制上方的[失水恶魂](失水恶魂.md)产生环境音效的方块。

* *[资源包](资源包.md)**
* 现在可在目录下定义路径点图标样式。

* *[Realms](Realms.md)**
* 新增了“地区偏好”设置，允许更精细地控制启动的Realms服务器所在的区域。
* * 可以指定一个可选地区，也可以选择根据Realms所有者或者首个加入会话的玩家的延迟自动决定地区。

# 更改
# = 方块 =
* *[失水恶魂](失水恶魂.md)**
* 现在物品[稀有度](稀有度.md)为“常见”。
* 现在不含水时需要下方为[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)才能播放环境音效。

# = 游戏内容 =
* *[定位栏](定位栏.md)**
* 不再属于[实验性内容](实验性内容.md)。

* *[游戏规则](游戏规则.md)**
* 游戏规则<code>useLocatorBar</code>现已重命名为<code>locatorBar</code>，且不再属于[实验性内容](实验性内容.md)。

# = 命令格式 =
* ***
* 移除了<code>modify <entity-selector> fade</code>子命令。
* 不再属于[实验性内容](实验性内容.md)。

* *[实体数据格式](实体数据格式.md)**
* 字段因路径点不再使用透明度区分因而不再需要，现由新加入的控制的路径点样式区分。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[数据组件](数据组件.md)**
* 物品堆叠组件<code>attribute_modifiers</code>的字段现在是可选的。

* *[实验性内容](实验性内容.md)**
* 移除了实验性数据包“”和功能开关<code>locator_bar</code>。

* *[资源包](资源包.md)**
* 将资源包版本号更改为。

* *[Realms](Realms.md)**
* 更改了Realms配置屏幕的外观，现在分为4个标签页——世界、玩家、订阅和设置。

* *[着色器](着色器.md)和后处理效果**
* <code>Fog</code>Uniform块
* * 移除了<code>FOG_IS_SKY</code>以拆分天空着色器。
