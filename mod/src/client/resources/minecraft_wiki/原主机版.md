* *原主机版（Legacy Console Edition）**指可在游戏主机上游玩的[Minecraft](Minecraft.md)，均由[4J Studios](4J Studios.md)开发。其适配：
* [Xbox 360](Xbox 360版.md)
* [Xbox One](Xbox One版.md)（被[基岩版](基岩版.md)取代）
* [PlayStation 3](PlayStation 3版.md)
* [PlayStation 4](PlayStation 4版.md)（被[基岩版](基岩版.md)取代）
* [PlayStation Vita](PlayStation Vita版.md)
* [Wii U](Wii U版.md)
* [Nintendo Switch](Nintendo Switch版.md)（被[基岩版](基岩版.md)取代）

原主机版引入了新的特性，比如更简单的[合成](合成.md)系统、游戏内的[教程](原主机版教程.md)、同屏幕内的[多人游戏](多人游戏.md)（除了[PlayStation Vita](PlayStation Vita版.md)），也有通过PlayStation Network（仅在PS4上需要PlayStation Plus会员）、Xbox Live（需要Xbox Live金会员）、Nintendo Network（仅Wii U）或Nintendo Switch Online（需要订阅）实现的最多8人同时在线的多人游戏。就像其他的游戏一样，后续游戏更新是免费提供的。

先前，“主机版”这个词在本wiki上被用来指代上述版本，但随着基岩版[独乐不如众乐更新](独乐不如众乐更新.md)的发布，Xbox One、Nintendo Switch和PlayStation 4平台被移植到[基岩版](基岩版.md)。另外，[New Nintendo 3DS版](New Nintendo 3DS版.md)在此更新前几天发布，它也是一个运行在主机平台上的版本，但并非基于原主机版的源码。由于“主机版”不再包含所有主机的各种版本，这一词就被修改成了“原主机版”。

2017年9月20日，Xbox One版从Microsoft Store中下架，随之而来的是基岩版的独乐不如众乐更新。拥有之前版本的人有资格免费下载新的基岩版的Minecraft，原来的世界存档和大多数DLC会转移至新版本中。同时，他们仍然能够玩原主机版。Nintendo Switch版于2018年6月21日、PlayStation 4版于2019年12月10日也像上文一样更新了基岩版。<ref></ref><ref name=PS4Bedrock></ref>要把世界存档从Xbox 360版转移到基岩版，仍然必须先转移到Xbox One版上，因为并没有直接转移世界存档的功能。

最初，Xbox One版计划不再更新。由于它少了相当于[TU58](Xbox 360版TU58.md)的更新内容，随后收到了[CU50](Xbox One版CU50.md)，它添加了Minecon Earth皮肤包。更新随后恢复，[CU51](Xbox One版CU51.md)的更新内容相当于[TU60](Xbox 360版TU60.md)，且一并添加了TU58中所有新特性。

2018年5月3日，Mojang宣布大多数原主机版将收到[水域更新](水域更新.md)，但之后将不会再收到更新。Xbox One和Nintendo Switch不在其计划中，因为水域更新将以基岩版的形式提供给Xbox One和Nintendo Switch主机。PS4版仍然收到了后续更新，直到2019年12月10日被基岩版取代为止。<ref></ref><ref name=PS4Bedrock/>

2024年4月9日，Xbox One版的最终更新[CU59](Xbox One版CU59.md)发布<ref>https://youtube.com/shorts/iiSNEAxEYu0</ref>，这意味着所有原主机版均已不再更新且不可用。

# 游戏内容
[缩略图|250px|Xbox 360版的一张游戏截图](File:Minecraft-Xbox360.png.md)
游戏的目的同原本的Java版和基岩版一样，即玩家可以在沙盒的虚拟环境之下建造。因为没有预设的目标，所以玩家可以自己制定自己想要达到的目标。

在很多地方原主机版和Java版除了几个微小的差别之外几乎相同，<ref></ref>不过在Xbox 360版发布时其游戏内容相当于Java版的Beta 1.6.6，而不是当时Java版的1.2.5。Wii U版发布时其游戏内容相当于Java版的1.6.4，而不是当时Java版的1.8.9。

# 与Java版和基岩版的区别

与[Java版1.13](Java版1.13.md)、[基岩版1.8.0](基岩版1.8.0.md)的区别包括：

* 游戏特有的[分屏](分屏.md)功能，<ref></ref>需要带色差线或HDMI线的高清电视以进行分屏游戏。分屏功能同样能在用VGA线或HDMI转DVI线连接显示器时使用。最多4名玩家可以在分屏模式游玩或在线多人模式下8人游玩。Nintendo Switch版也支持在设备上分屏游玩或同WLAN网络内游玩。PlayStation Vita版只支持2-4人的在线游戏和点对点模式。
* 游戏内有自动的[合成](合成.md)系统。这使得可以不需要将物品放置在工作台的格子中也能合成。不过，也有使用Java版合成系统的选项。
* 主机版包含Java版和基岩版没有的教学模式。这种模式引导玩家学习[挖掘](挖掘.md)、放置[方块](方块.md)、[合成](合成.md)、[建造他们的房子](Tutorial:新手手册.md)来度过[夜晚](夜晚.md)、[钓鱼](钓鱼.md)、[附魔](附魔.md)、[药水酿造](药水酿造.md)等等。<ref></ref>
* 在创建一个新世界时，[玩家](玩家.md)便会拿到一张空的[地图](地图.md)。而在基岩版，玩家可以通过开启“初始地图”的选项，使得玩家在第一次进入世界的时候就能得到一张地图。
* Xbox 360、PlayStation 3、PlayStation Vita和Wii U版本的世界的大小被局限于864×864方块内。由于地图边界外的方块是不可交互的， 实际上的地图大小只有862×862方块。但是Nintendo Switch版的世界大小可以达到3072×3072，Xbox One版和PlayStation 4版的世界大小可以达到5120×5120。<ref>http://news.xbox.com/2014/09/03/games-minecraft-launch-on-xbox-one/</ref>
* [下界](下界.md)的地图尺寸也是有限的。对于PS3，PS4，Xbox 360和Wii U版本来说，由于下界与主世界在主机版中的距离比是1:3而非Java版的1:8，所以下界的地图尺寸被限制为288×288方块。Nintendo Switch版的距离比为1:6，下界尺寸大约为512×512方块。[末地](末地.md)也使用上述尺寸。
* 在创建世界时，玩家可以选择三个不同的生物群系选项之一来生成世界。
* 皮肤只能使用默认皮肤和从[皮肤包](皮肤包.md)获取的皮肤。
* 动物的[繁殖](繁殖.md)和效用型生物的生成与Java版相同，除了[狼](狼.md)和[雪傀儡](雪傀儡.md)的数量被限制为16。如果玩家想要繁殖或驯服第17只狼，它将被其他狼杀死。如果玩家想要生成第17个雪傀儡，放下最顶上的南瓜后，生成雪傀儡的三个方块会被破坏并掉落一个[南瓜](南瓜.md)和8个[雪球](雪球.md)。另外，狼会繁殖出满生命的狼幼崽并在玩家不干预的情况下长大。
* 世界的边界不能被破坏，它是无限的海洋。地图的边缘被一圈海水环绕，而且有不可见的屏障阻止所有玩家通过其中。这使得地图边缘生成的[废弃矿井](废弃矿井.md)中的[箱子](箱子.md)出现问题，使玩家无法获取其中的物品。要试图解决该问题，玩家需要在那个箱子旁边放上另一个箱子使其变成一个大箱子才有可能取得物品。
* [创造模式](创造模式.md)的飞行没有惯性——如果你在飞行中停止按前进，你不会向前滑动而是立刻停止。
* 在飞行时，玩家的移动有数字指明其方向，这意味着他们不能够完成一整圈漂移。 这样做是为了在使用控制器时提高精度。
* 当创建一个[超平坦世界](超平坦世界.md)，下界也会是平坦的。
* [下界疣](下界疣.md)随机在下界中的[灵魂沙](灵魂沙.md)上生成，而在Java版中，它只在[下界要塞](下界要塞.md)生成。
* 下界的边缘是[基岩](基岩.md)。
* PlayStation Vita版和Nintendo Switch版本支持Ad-Hoc（点对点）。可选择打开或关闭（在线模式或Ad-Hoc模式）。Ad-Hoc类似于局域网多人游戏服务器但不需要网络连接。
* 除了Wii U版和Nintendo Switch版，统计数据由排行榜代替。

# = 游戏模式 =
游戏模式的设定和其他平台上的版本有些许不同。

; 创造模式
* 使用创造模式会在此世界永久禁用成就/奖杯和排行榜更新，即便随后更改回生存模式也不可获取成就。

; 冒险模式
* 可以通过[适合的工具（取决于方块和工具的材料）](挖掘#合适挖掘工具.md)来拆除。示例：使用[剪刀](剪刀.md)可以破坏[羊毛](羊毛.md)方块；只有[铁镐](铁镐.md)及更高级的工具可以挖掘并收集[金矿石](金矿石.md)。
* 没有公共的服务器。玩家的世界被限制到最多8个在线玩家。通过启用设置选项**Allow Friends of Friends to join**可以起到类似于公共服务器的作用。

; 生存模式
* 所有方块都可破坏，除了[基岩](基岩.md)和[屏障](屏障.md)。

# 你知道吗
* 开发原主机版的公司[4J Studios](4J Studios.md)也移植了其他几款电子游戏，如为Xbox Live Arcade制作的《》和《}}》及其[续作](wikipedia:Banjo Tooie.md)，以及为PS3制作的《》。
* Notch起初说[Xbox 360](wzh:Xbox 360.md)是Minecraft原主机版唯一的提供商。<ref></ref>然而，[索尼](wzh:索尼.md)后来宣布会有[PS3](wzh:PlayStation 3.md)，[PS4](wzh:PlayStation 4.md)，和[Vita](wzh:PlayStation Vita.md)的版本发布。<ref></ref><ref></ref>后来，Mojang又发布了Xbox One、Wii U、Nintendo Switch版本，以及单独开发的[New Nintendo 3DS版](New Nintendo 3DS版.md)。
* 原主机版无法合法地安装[Mod](Mod.md)，只可以通过破解来安装，但玩家可能会因此被封禁。
* 玩家可以用黏性活塞拉走地图边缘的方块，但是不能将方块推入边缘。
* 蜘蛛可以爬上世界的边缘，因为游戏将其认定为方块。
* [玩家](玩家.md)无法飞到世界顶端，虽然它有2,147,483,647方块高，但是世界高度被限制为只有511方块高。
* 在夜間保存游戏存档时，菜单背景会被替换为夜晚版本。
