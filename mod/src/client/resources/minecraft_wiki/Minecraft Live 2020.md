# Minecraft Live 2020

*页面ID: 60928* | *来源: Minecraft Wiki*

* *Minecraft Live 2020**是一次于2020年10月3日16:00（UTC）开始的线上直播活动。<ref>，回复</ref><ref></ref>该活动在[YouTube](https://www.youtube.com/watch?v=DWZIfsaIgtE)、[Twitch](https://twitch.tv/videos/759493665)、[Facebook](https://facebook.com/watch/?v=3511783658865822)和[Minecraft.net](https://minecraft.net/live)上进行了直播。该场活动公布了下一次主要更新的主题“[洞穴与山崖](洞穴与山崖.md)”及其相关特性；同时举行了新一轮生物投票，最终[发光鱿鱼](发光鱿鱼.md)胜出。

该次直播活动在官方最初的计划当中是[Minecraft Festival](Minecraft Festival.md)的一部分，但受[COVID-19疫情](wzh:2019冠状病毒病疫情.md)影响，Minecraft Festival的举办被一再推迟。<ref></ref><ref></ref><ref></ref>

# 活动
# = 社区预热活动 =
在主要活动开始前有约20分钟的社区预热活动。多名YouTuber在此期间分享了他们对此次直播活动的想法。

# = 更新预告 =
与[MINECON Live 2019](MINECON Live 2019.md)相似，直播中公布了下一次主要更新的主题“[洞穴与山崖](洞穴与山崖.md)”及其相关特性，如洞穴生成的优化和新生物[山羊](山羊.md)。与以往不同的是，此次直播在开头部分就宣布了下一次主要更新的主题。

# = 生物投票 =
[thumb|生物投票的3个选项](File:Mclive mobvote header.png.md)
[thumb|生物投票的logo](File:Mob vote logo.png.md)

观众将在直播中投票选出一个生物加入到游戏，该次投票是继[MINECON Earth 2017](MINECON Earth 2017.md)之后的第2次生物投票活动。

投票活动的三个候选生物分别是[Minecraft Dungeons](Minecraft Dungeons.md)中的、[Minecraft Earth](Minecraft Earth.md)中的和<ref></ref>：

; [32px](File:MoobloomPixel.png.md) 哞花（Moobloom）
* 生成于。
* 会以某种方式与[蜜蜂](蜜蜂.md)进行互动。
* 尚不清楚是否会添加，或是以[蒲公英](蒲公英.md)代替。

; [32px](File:IceologerPixel.png.md) 冰术师（Iceologer）
* 生成于。
* 遇见玩家时，会在玩家的-{}-头上生成一团冰块进行攻击。

; [32px](File:GlowSquidPixel.png.md) [发光鱿鱼](发光鱿鱼.md)（Glow Squid）
* 生成于底部的黑暗区域。
* 可以在暗处发光。

未能在投票当中胜出的生物在未来的更新当中加入的可能性较小，但并不一定会像上一次生物投票那样永远不会加入游戏。<ref></ref>

# == 结果 ==
[thumb|发光鱿鱼最终在生物投票中胜出](File:Winner of Mob Vote 2020.gif.md)
投票分为两轮，[哞花](哞花.md)和[冰术师](冰术师.md)分别在第一轮和第二轮投票当中被淘汰，而[发光鱿鱼](发光鱿鱼.md)最终胜出并将加入游戏。

# = Minecraft Earth和Minecraft Dungeons更新 =
预热活动当中介绍了一些[Minecraft Earth](Minecraft Earth.md)和[Minecraft Dungeons](Minecraft Dungeons.md)的更新事项，其中Minecraft Earth将加入[活塞](活塞.md)和[黏性活塞](黏性活塞.md)，而Minecraft Dungeons将更新4款DLC。

# = 开发者讨论 =
和往年一样，[Mojang Studios](Mojang Studios.md)的开发人员将组成一个小组，讨论一些“内部独家新闻”，[Jeb](Jeb.md)将成为特色人员。
