# 虞美人

*页面ID: 29898* | *来源: Minecraft Wiki*

* *虞美人（Poppy）**是一种[小型花](小型花.md)。

# 生成

# = 自然生成 =
虞美人会在[主世界](主世界.md)中除[沼泽](沼泽.md)、[红树林沼泽](红树林沼泽.md)、[苍白之园](苍白之园.md)、[蘑菇岛](蘑菇岛.md)、[繁茂洞穴](繁茂洞穴.md)、[樱花树林](樱花树林.md)、、[恶地](恶地.md)、[疏林恶地](疏林恶地.md)和[风蚀恶地](风蚀恶地.md)之外的所有[生物群系](生物群系.md)自然生成。

虞美人也会在平原、热带草原、针叶林和[村庄](村庄.md)以及[林地府邸](林地府邸.md)中生成。

# = 骨粉 =
在可自然生成虞美人的生物群系中对[草方块](草方块.md)[骨粉](骨粉.md)后，虞美人有概率代替[矮草丛](矮草丛.md)生成。

对着不[含雪](含雪.md)的虞美人使用骨粉会出现更多的虞美人，也有小概率出现[蒲公英](蒲公英.md)，而不会出现草丛。

# = 礼物 =

[幼年村民](幼年村民.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷虞美人。

# = 铜傀儡 =
[铁傀儡](铁傀儡.md)有概率将虞美人赠予[铜傀儡](铜傀儡.md)。铜傀儡会将铁傀儡赠予的虞美人戴在头上，对其[剪刀](剪刀.md)会掉落1个虞美人。

虞美人也会在铜傀儡转变为铜傀儡像或死亡时掉落。

# 破坏
虞美人被挖掘时会立刻被破坏。

虞美人被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 谜之炖菜 =

使用虞美人合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家5s的[夜视](夜视.md)效果。

# = 堆肥 =
将虞美人放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
