# 铁

*页面ID: 6605* | *来源: Minecraft Wiki*

[右|400px](File:AllIron.png.md)
* *铁（Iron）**是一种金属材料，可用于制作多种资源。

# Minecraft
# = 方块和物品 =
*  - 一种通过挖掘铁矿石或深层铁矿石获得的物品，可冶炼为铁锭。
*  - 一种通过冶炼粗铁或铁矿石或用铁粒合成获得的物品，通常被用作合成材料。
*  - 一种可以合成铁锭的物品，可通过熔炼铁质物品或[以物易物](以物易物.md)获得。
*  - 一种能在地下或山地上找到的[矿石](矿石.md)，可以通过开采获得粗铁，并通过烧炼获得铁锭。
*  - 在主世界的[深板岩](深板岩.md)层取代普通铁矿石生成的变种铁矿石。
*  - 一种用粗铁合成的装饰性方块。
*  - 一种可以存储铁资源、创造铁傀儡、搭建[信标](信标.md)底座的方块。
*  - 一种允许玩家修复物品、重命名物品及组合[魔咒](魔咒.md)的方块。
*  - 一类用于提供[矿车](矿车.md)行进路线的非固体方块。
*  - 一种与[玻璃板](玻璃板.md)类似，但[爆炸抗性](爆炸抗性.md)更强的方块。
*  - 一种金属装饰性方块。
*  - 一种只能通过被[红石信号](红石信号.md)激活来打开的[门](门.md)。
*  - 一种只能通过被红石信号激活来打开的[活板门](活板门.md)。
*  -  一种增加信号强度需要的实体数量更多的压力板。
*  - 可以装起[水](水.md)、[熔岩](熔岩.md)、[奶](奶.md)或某些水生[生物](生物.md)的物品。
*  - 一种化学[元素](元素.md)。

# = 生物 =
*  - 一种[友好生物](友好生物.md)，会主动攻击某些[敌对生物](敌对生物.md)来保护[村民](村民.md)和创造它们的[玩家](玩家.md)。
