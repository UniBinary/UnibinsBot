# Java版18w33a

*页面ID: 36112* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w33a**是[Java版1.13.1](Java版1.13.1.md)的第5个，也是最后一个快照，发布于2018年8月15日<ref></ref>，加入了[热带鱼桶](热带鱼桶.md)的提示文本，改进了液体的性能，并修复了许多漏洞。

# 新内容
# = 物品 =
* *[热带鱼桶](热带鱼桶.md)**
* 加入了提示文本。

# 更改
# = 常规 =
* *性能**
* 改进了[液体](液体.md)的性能。
