# 知识之薯

*页面ID: 138330* | *来源: Minecraft Wiki*

* *知识之薯（Potato of Knowledge）**是一种可存储[经验](经验.md)的物品。

# 获取
在[创造模式物品栏](创造模式物品栏.md)中可以获取经验容量为10、50、100的知识之薯。

# = 大脑 =
[大脑](大脑.md)被破坏后会掉落自身和一个与其吸收经验值等同经验的知识之薯。

如果大脑已吸收的经验值达到1000，储存的经验值会清空，且立即掉落一个包含1000经验的知识之薯。

# 用途
知识之薯具有[光效](光效.md)。

# = 储存经验 =
[thumb|一个储存了100点经验的知识之薯](File:Potato of Knowledge Tooltip.png.md)
知识之薯可以存储经验，储存的经验数量会以“Amount: <*XP*>”（容量：<*经验数*>）的格式显示在其[提示框](提示框.md)中。

长按键可以食用知识之薯，食用的动作与其他食物略有不同，时长为。食用后，玩家会获得指定数量的经验，但不会回复[饥饿值](饥饿值.md)与[饱和度](饱和度.md)。
