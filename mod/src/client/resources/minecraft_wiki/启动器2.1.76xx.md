# 启动器2.1.76xx

*页面ID: 48300* | *来源: Minecraft Wiki*

<onlyinclude>
* *2.1.7658**（[Linux](wzh:Linux.md)）、**2.1.7659**（[macOS](wzh:MacOS.md)）或**2.1.7660**（[Windows](wzh:Microsoft Windows.md)）是[启动器](启动器.md)的一次更新，发布于2019年9月23日。<ref>https://piston-meta.mojang.com/mc/launcher_beta_changelog.md</ref>

# 新内容
* 加入了对Linux上屏幕阅读器的支持。

# 更改
* 启动器现在可以在不用登录的情况下游玩Java版[演示模式](演示模式.md)了。
* 改进了无障碍和屏幕阅读器的可用性。
* 在所有平台上重修了启动器的窗口拉伸和位置。
* 启动器日志优化：启动器组件会附加到后面，而不是覆写日志。
* 启动器现在可以断点续传了。
* 优化了Windows上对显示缩放的支持。
* 启动器在Linux上有更好的桌面集成，并可以使用系统对话框（文件浏览一类）。
* Linux包不再依赖于Java 8，而是需要任何合适的Java运行环境。
* * 加入了GTK 3的依赖。
* 优化了UI性能。

# 修复
*  - 在编辑配置界面的版本下拉菜单中，较长的版本名称会被截断。
*  - 不能编辑或删除由Mod安装器写入的启动器配置。
*  - “报告启动器漏洞”按钮的右边缘不在窗口范围内。
*  - 新建配置对话框中的版本选择菜单是空白的。
*  - 新建配置对话框中无法更改版本。
*  - 启动器游戏目录不能正确地处理Linux文件格式。
*  - 最新测试版启动器无法启动游戏。</onlyinclude>
