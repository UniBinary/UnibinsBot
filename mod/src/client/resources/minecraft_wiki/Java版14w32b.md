# Java版14w32b

*页面ID: 32437* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w32b**是[Java版1.8](Java版1.8.md)的第43个快照，发布于2014年8月7日<ref></ref>，加入了非橡木-{}-材料的栅栏、栅栏门和一条新的命令，并修复了一些[14w32a](14w32a.md)的漏洞和崩溃问题。

# 新内容
# = 方块 =
* *[栅栏](栅栏.md)**
* 为所有类型的木材加入了对应的栅栏。
* * 不同种类可以互相连接。
* * 普通栅栏重命名为橡木栅栏。
* 新的合成配方：2根[木棍](木棍.md)和4块[木板](木板.md)（可制作3根栅栏）。

* *[栅栏门](栅栏门.md)**
* 为所有类型的木头添加对应的栅栏门。
* * 不同种类可以互相连接。
* * 普通栅栏门重命名为橡木栅栏门。
* 现在可以被火点燃。

# 更改
# = 方块 =
* *[信标](信标.md)**
* 信标光柱可立即变色。
* 光柱可以穿过所有半透明方块，如[冰](冰.md)、[水](水.md)和[树叶](树叶.md)。

# = 非生物实体 =
* *[盔甲架](盔甲架.md)**
* 现在可以在盔甲架上使用捡起的方块（不会给盔甲架盔甲装备）。
* 现在只能用石[台阶](台阶.md)合成而不能用其他变种的石台阶合成。
