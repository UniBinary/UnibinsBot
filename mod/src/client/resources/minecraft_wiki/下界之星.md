# 下界之星

*页面ID: 8908* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *下界之星（Nether Star）**是一种由[凋灵](凋灵.md)掉落的稀有物品，能够用于合成[信标](信标.md)。

# 获取
# = 凋灵 =

# 用途
下界之星具有[光效](光效.md)。

下界之星不会被爆炸破坏，但它仍能被[仙人掌](仙人掌.md)、[火](火.md)和[熔岩](熔岩.md)摧毁。

由[凋灵](凋灵.md)掉落的下界之星会在而非后被清除；而掉落物形式的下界之星永远不会被清除。
