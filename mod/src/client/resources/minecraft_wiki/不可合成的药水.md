# 不可合成的药水

*页面ID: 179478* | *来源: Minecraft Wiki*

* *不可合成的药水**是在[药水效果](药水效果.md)不存在或无效时作为占位符的药水效果。

该药水效果可以制成[药水](药水.md)**不可合成的药水（Uncraftable Potion）**、[喷溅药水](喷溅药水.md)**不可合成的喷溅型药水（Splash Uncraftable Potion）**、[滞留药水](滞留药水.md)**不可合成的滞留型药水（Lingering Uncraftable Potion）**和[药箭](药箭.md)**不可合成的药箭（Uncraftable Tipped Arrow）**。

# 获取
任何药水效果数据若未指定药水效果，或指定了游戏无法识别的药水效果ID，那么就会使用不可合成的药水这一药水效果。因而不可合成的药水无法在不开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。

# 行为
不可合成的药水不会给予生物任何[状态效果](状态效果.md)。
