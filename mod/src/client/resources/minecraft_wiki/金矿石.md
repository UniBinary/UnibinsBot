# 金矿石

*页面ID: 6352* | *来源: Minecraft Wiki*

* *金矿石（Gold Ore）**是一种可在地下找到的稀有的[矿石](矿石.md)方块。

* *深层金矿石（Deepslate Gold Ore）**是以[深板岩](深板岩.md)作为容矿岩的金矿石变种。

# 生成
# = 自然生成 =
金矿石会以[矿团](矿团.md)的形式生成于[主世界](主世界.md)高度为Y=-64至32的石头之间，其中Y=-16处分布最多并向两端递减，矿团大小为1-9个方块，每[区块](区块.md)会尝试生成4次。

金矿团还会生成在[恶地](恶地.md)、[疏林恶地](疏林恶地.md)和[风蚀恶地](风蚀恶地.md)的Y=28至256高度处，依高度平均分布，矿团大小为1-9个方块，每区块尝试生成50次。

生成于[深板岩](深板岩.md)或[凝灰岩](凝灰岩.md)间的金矿石会被替换为深层金矿石。

# 获取
金矿石和深层金矿石只能通过破坏对应方块获得。

# 破坏
挖掘金矿石和深层金矿石的合适工具是镐。金矿石和深层金矿石需要铁镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，金矿石和深层金矿石被破坏后会掉落1个[粗金](粗金.md)，挖掘工具的[时运](时运.md)魔咒会增加粗金的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，金矿石和深层金矿石被破坏后会掉落自身。

# 用途
# = 猪灵 =
在非和平难度下，无论玩家是否装备了[金质盔甲](盔甲.md)，成年[猪灵](猪灵.md)看见或听见玩家破坏金矿石或深层金矿石后会与之敌对。
