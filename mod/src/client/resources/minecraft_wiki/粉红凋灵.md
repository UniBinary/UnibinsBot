* *粉红凋灵（Pink Wither）**，或**友好凋灵（Friendly Wither）**，是一个同时在[Java版2.0](Java版2.0.md)和[15w14a](15w14a.md)里出现的愚人节生物。

# 生成
# = 2.0 =
}}

在2.0版本中，粉红凋灵可以通过在粉色[羊毛](羊毛.md)上面放置一个装有玫瑰的[花盆](花盆.md)来召唤。新生成的粉红凋灵只有一个头。

# = 15w14a =
在15w14a中，粉红凋灵取代了[凋灵](凋灵.md)，其发射的[粉红凋灵之首](粉红凋灵之首.md)有类似[骨粉](骨粉.md)的效果而非[凋零](凋零.md)效果。

# 掉落物

}}

粉红凋灵被[玩家](玩家.md)或被驯服的[狼](狼.md)杀死时，会掉落。

# 行为

}}
# = 2.0 =
粉红凋灵是一种敌对的[亡灵生物](亡灵生物.md)，会跟随拿着[糖](糖.md)的玩家，给它喂糖会使它长出更多的头，最多三个。与普通的凋灵不同，粉红凋灵不能飞行，且当粉红凋灵之首触碰到方块时，会在半径为15×4×15范围的草方块上长出植物。

# = 15w14a =
粉红凋灵像凋灵一样有三个头。它在生成后也会产生爆炸效果。粉红凋灵发射的粉红凋灵之首可以治疗实体，但也可能对亡灵生物造成伤害。
