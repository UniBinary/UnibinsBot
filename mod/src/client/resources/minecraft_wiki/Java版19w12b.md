# Java版19w12b

*页面ID: 41812* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w12b**是[Java版1.14](Java版1.14.md)的第28个快照，发布于2019年3月21日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[玻璃](玻璃.md)**
* 生物不再在玻璃中受到窒息[伤害](伤害.md)。

* *[告示牌](告示牌.md)**
* 在[生存模式](生存模式.md)中可为文字染色。

* *[活板门](活板门.md)**
* 关闭的顶部活板门有了上表面完整的[方块支撑形状](方块支撑形状.md)，暂时不能锁定[探测铁轨](探测铁轨.md)。

# = 生物 =
* *[铁傀儡](铁傀儡.md)**
* 生成概率稍有提高。
* * 现在需要有5个[村民](村民.md)交谈，而不是10个。
* * 被[僵尸](僵尸.md)攻击的[村民](村民.md)现在有更高的概率生成铁傀儡。

* *[村民](村民.md)**
* 村民不再看旁观模式的玩家。
