# 方块物品

*页面ID: 119141* | *来源: Minecraft Wiki*

* *方块物品（Block Item）**是用于表示[方块](方块.md)的一类[物品](物品.md)，可以为世界中的方块。

# 描述
# = Java版 =
游戏会在物品和方块之间建立映射关系。一般地，在[创造模式](创造模式.md)中对方块使用获得的物品就是其方块物品（例外）。通常情况下，一个方块物品只与一个方块对应，而多个方块可以对应同一个方块物品。但在特定条件下，方块物品可以放置出方块变体而并非原本的方块。例如，物品在准星对准方块侧面时，可以放置出，而非原本的告示牌方块。

方块与方块物品的对应关系概括如下：
* 对于大多数方块，它们与对应的方块物品会使用同一个名字。例如方块与物品。
* 对于拥有变体的方块，它们对应的方块物品可以是同一个。例如各种炼药锅对应的方块物品都是。
* 大多数[作物方块](农作物.md)对应种植时所需的物品。例如和分别对应和；未成熟的和分别对应和。但与对应的方块是而非。
* 特别地，方块对应物品，而其他桶类物品没有对应的方块。
* 、、、、、、、、等没有对应的方块物品。
方块物品除表示方块外，可以拥有其他功能。例如可以用于种植，可以食用，可以[合成](合成.md)为。

# = 基岩版 =
与不同，物品不直接与方块对应。尽管所有方块都与其方块物品一一对应，但方块物品只能用来表示对应的方块，而不具备其他功能。方块物品和方块主要依靠数字ID联系，对于数字ID小于256的方块，其方块物品具有相同的数字ID；对于大于256的方块，用255减去其ID后的数字作为其方块物品的数字ID。游戏会先注册其他物品，再注册方块物品，方块物品的命名空间ID一般和方块相同，除非和既有物品存在冲突。

# == 技术性方块物品 ==
部分方块对应的物品只能通过外部的物品栏编辑器获得。一般有以下两种情况：

# 为实现物品的额外功能而额外注册的物品。以为例，它直接对应的方块物品（<code>minecraft:sweet_berry_bush</code>）不能直接获取，除可以摆放外再无其他功能。此时为实现额外的食用功能，必须另外注册（<code>minecraft:sweet_berries</code>）物品，这样注册的物品不属于方块物品。再如，方块（<code>minecraft:acacia_standing_sign</code>和<code>minecraft:acacia_wall_sign</code>）的方块物品依旧存在，且只能通过外部的物品栏编辑器获得，而对应物品（<code>minecraft:acacia_sign</code>）虽然能通过获得，并能摆放为同名方块，但仍然不是直接对应的方块物品。
# 有时，为了方便地实现物品和方块的不同模型，游戏也会注册额外的物品，这些物品也不属于方块物品的范畴。例如，为实现二维的蛋糕物品模型。游戏在方块以外又注册了物品。虽然两者的命名空间ID都是<code>minecraft:cake</code>，但彼此间并不是方块和方块物品的对应关系，蛋糕方块另有对应的方块物品。因为游戏会先注册其他物品，再注册方块物品，为解决命名空间ID冲突的问题，游戏会在蛋糕方块物品的命名空间ID前加上<code>item.</code>。这样蛋糕方块物品的命名空间ID即为<code>minecraft:item.cake</code>，尽管它只能通过外部的物品栏编辑器获得。这样的方块物品会在重新进入世界时变为覆盖它的物品。

# 获取
方块不能直接存在于物品栏中成为可供玩家利用的资源，而是需要用方块物品来表示方块，。故通常所说的获取某种方块，实际上是获取其所对应的方块物品。通常所说的某种方块资源[可再生](可再生.md)，实际上指的是其方块物品可再生。如说蛋糕可再生，在Java版中指的是蛋糕方块物品可再生，在基岩版中指的是蛋糕物品可再生，而不是蛋糕方块物品。

方块物品可以通过常规的物品获取途径来获取。如方块和实体的[掉落物](掉落物.md)、[交易](交易.md)、[箱子战利品](箱子战利品.md)等等各种方式。

在[创造模式](创造模式.md)下，创造模式物品栏中可获取大部分方块物品。另外，通过也可以获取大部分方块物品，但要注意，该物品不一定是该方块对应的方块物品，例如，[竹笋](竹笋.md)/，但当选取竹笋时却可以得到[竹子](竹子.md)物品。若方块有方块实体，且玩家按下了+组合键，获得的方块物品会存储方块的方块实体数据。

# 用途
# = 放置 =
方块物品往往可以被为方块。方块物品的放置不会计入物品使用次数的[统计](统计.md)。在[生存模式](生存模式.md)下放置会消耗一个物品，但存在一个特殊情况：[细雪桶](细雪桶.md)放置后会返回空桶。

要将一个方块物品放置为方块，玩家需要瞄准一个方块的轮廓箱，然后按下键。若瞄准的方块是[可替代方块](可替代方块.md)，并且其方块物品不是手持的方块物品，则方块会被放置在该可替代方块的位置，直接替代掉该可替代方块；否则，，方块会被放置在瞄准的轮廓箱表面对面的相邻位置，若此位置是可替代方块，并且其方块物品不是手持的方块物品，则可以放置；其他情况下，方块物品都不能被放置出。如果要放置的位置被实体碰撞箱阻挡，则无法放置。

对于绝大多数有朝向的完整方块，方块被放出后会朝向玩家；对于大多数有中心轴的方块，方块被放置后，中心轴会垂直于放置的表面；对于大多数其他有朝向的方块，方块被放置后会附着在指定的表面上。

一些方块有特殊的放置规则：
* 只能放置在水上的方块，包括[睡莲](睡莲.md)和[青蛙卵](青蛙卵.md)，放置时要瞄准水而不是瞄准一个方块的轮廓箱。则必须从上方瞄准水的上表面。
* [蜡烛](蜡烛.md)、[台阶](台阶.md)、[海龟蛋](海龟蛋.md)等方块物品，可以在已有相同方块的位置放置。
* [火把](火把.md)、[旗帜](旗帜.md)、[头颅](头颅.md)、[告示牌](告示牌.md)可以放置为方块的墙上变种。
* 命令方块、拼图方块和结构方块要求玩家必须处于创造模式且或，才能进行放置。
* 不少方块要求放置位置必须满足特定条件才能放置。
* * 部分方块基于其能够附着的方块、[固体方块](固体方块.md)或[方块支撑形状](方块支撑形状.md)的判断，需要相邻的方块支撑才能放置，且在不合适的表面上放置时会方块“滑入”一个合适的表面。
* * 不同的方块还可能会有其他要求，例如仙人掌还要求四周没有固体方块，两格高的植物要求上方方块可替代，竹子要求该位置处没有液体。
* [脚手架](脚手架.md)有独特的放置规则。

方块物品被放置为方块后，会产生[方块更新](方块更新.md)。

方块物品可以使用物品堆叠组件<code>minecraft:block_state</code>和<code>minecraft:block_entity_data</code>储存方块状态和方块实体数据，并在放置时应用。方块物品也可以储存并应用方块状态，但不能储存方块实体数据。

注意，除了方块物品，还有如[打火石](打火石.md)、[水桶](水桶.md)和[熔岩桶](熔岩桶.md)等物品可以放置方块，它们并不是方块物品。除了方块物品，还有很多物品可以放置方块，如[旗帜](旗帜.md)物品、[告示牌](告示牌.md)物品和[小麦种子](小麦种子.md)等，它们也并不是方块物品。

# = 其他 =
方块物品还可能有类似普通物品的其他用途。如，[雕刻南瓜](雕刻南瓜.md)可以像头盔一样戴在头部。
