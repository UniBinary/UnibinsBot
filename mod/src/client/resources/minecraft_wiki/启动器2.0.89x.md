# 启动器2.0.89x

*页面ID: 63564* | *来源: Minecraft Wiki*

* *2.0.895**（[Windows](wzh:Microsoft Windows.md)）或**2.0.897**（[macOS](wzh:macOS.md)）是一次[启动器](启动器.md)更新，发布于2017年5月30日，修复了一些漏洞。

# 修复
*  - Windows上的启动器在启动游戏时显示“Minecraft launcher has stopped working”。
*  - 点击“开始游戏”时游戏无法加载。
*  - 点击“Play Download 1.11.2 - Latest release”后2.0.847版本的启动器一直停留在“Preparing”。
