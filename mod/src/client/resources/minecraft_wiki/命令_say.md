# 命令/say

*页面ID: 39807* | *来源: Minecraft Wiki*

通过聊天框向多个玩家发送消息。

# 语法
* **Java版**
  <code>say <message></code>

* **基岩版**
  <code>say <message: message></code>

# 参数

   要发送的聊天消息。

   使用了聊天类型。

# 输出

# 示例
* 发送“hello!”：<code>say hello!</code>
