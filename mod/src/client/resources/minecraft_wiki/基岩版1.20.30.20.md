# 基岩版1.20.30.20

*页面ID: 105151* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.30.20**（ChromeOS/Android）、**Preview 1.20.30.20**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.30](基岩版1.20.30.md)的第5个测试版，发布于2023年8月3日<ref></ref><ref></ref>，在[实验性玩法](实验性玩法.md)中对[交易](交易.md)做出了平衡性调整、为[RenderDragon](RenderDragon.md)加入了新功能，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* *[游戏规则](游戏规则.md)**
* 加入了游戏规则。
* * 用于控制是否禁止玩家合成未解锁配方的物品。
* * 仅在配方解锁机制开启时生效。
* * 默认值为。

# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“村民贸易再平衡”子选项。
* * 用于启用对[交易](交易.md)做出的平衡性调整。
* 加入了“为创建者提供的渲染龙功能”子选项。
* * 用于启用与[RenderDragon](RenderDragon.md)相关的创作者功能。
* * 目前仅测试版本可用。

* *[设置](设置.md)**
* 在Windows平台上的视频设置中加入了“垂直同步”选项。
* * 用于启用垂直同步功能。

# = 方块 =

# = 物品 =
* *[镐](镐.md)**

# = 世界生成 =
* *[矿石](矿石.md)分布**
* [钻石矿石](钻石矿石.md)会在主世界的[深板岩](深板岩.md)层更加频繁地生成。
* * 加入了中型钻石矿团，其他现有的钻石矿团放置保持不变。
* ** 中型钻石矿团的大小为1-8个钻石矿石，每个区块尝试生成2次，在Y=-64到-4之间均匀分布。暴露在空气中的钻石矿石有50%的概率跳过生成。

# 修复
* *音频**
* 现在流浪者拉弓射箭时会播放正确的音效。（）
* 现在在盔甲槽中切换附魔、纹饰不同但其他相同的盔甲部件时会播放穿戴装备的音效。（）
* 现在足迹与故事音乐曲目会在游戏菜单中播放。（）
* 现在将盾牌装备到副手槽中时会播放音效。（）

* *方块**
* 第三人称相机视角不再能够穿过雪、泥巴和灵魂沙。
* 使用错误工具挖掘切石机时，切石机不再会掉落为物品。（）
* 镐现在可以加快挖掘活塞和黏性活塞的速度。（）
* 激活或取消激活红石中继器和红石比较器时不再会中断水流。（）
* 第三人称相机视角现在能够穿过玻璃、玻璃板和铁栏杆。（）

* *樱花树林**
* 现在樱花树林中的水下迷雾使用会在一段时间后增加能见度的过渡效果。（）

* *游戏内容**
* 将长按合成输出槽的触摸控制功能恢复为在输出槽中快速合成单个物品。（）
* 将长按合成输出槽时的物品合成速度减缓至每秒4个物品，启用快速合成功能前的长按所需时间减少至700ms。
* 更新了睡觉时的文本以适应游戏规则。（）
* 将游戏规则设置为0时不再会跳过睡觉动画。（）
* 现在没有入睡的玩家在其他所有玩家均在睡觉的情况下离开时，夜晚会正确被跳过。
* 玩家在末地传送门正下方睡觉时不再会立即进入末地传送门。（）

* *图形**
* 在视频菜单中加入了垂直同步选项。（）

* *生物**
* 生物现在只能用主手持有和举起灾厄旗帜。（）
* 修复了玩家在船上时其肩上的鹦鹉会面朝与玩家不同的位置的问题。

* *性能与稳定性**
* 修复了在Realms设置中反复按键时可能会删除UI或黑屏的漏洞。
* 修复了玩家被卡在熔岩柱中的恶魂包围时服务器会无响应的问题。（）
* 将物品堆叠中的一个物品放入已满且相同的物品堆叠时不再会导致游戏崩溃。

* *触摸控制**
* 修复了飞行时的潜行操作无法对可交互物品正常生效的问题。（）

* *用户界面**
* 修复了在Android设备上按住返回键时文本框文本有时不会更新的问题。（）
* 修复了iOS和Android平台上对全键盘玩法的支持的相关问题。
* 启用立即重生后不再会出现新的死亡屏幕。
* 修复了带有括号的物品名称不会显示在物品栏或合成菜单上的标题中的问题。（）
* 现在使用游戏手柄在书与笔中切换页面时会播放音效。（）
* 在Xbox平台上按下虚拟键盘上的键时不再会删除光标。（）
* 现在在携带版UI下打开锻造台UI时会使背景变暗。

* *原版趋同**
* 现在村民睡觉时不会获得职业。（）
* 调整了潜影盒的红石信号以匹配Java版。
* 现在冰和雪的形成由随机刻控制。
* 修复了村庄被袭击击败时会使袭击栏自动变为空白的漏洞。（）

* *振动**
