# 胡萝卜钓竿

*页面ID: 8890* | *来源: Minecraft Wiki*

* *胡萝卜钓竿（Carrot on a Stick）**是一种可以用来控制装有[鞍](鞍.md)的[猪](猪.md)的物品。

# = 铁砧 =

叠加两把胡萝卜钓竿的剩余耐久度，再额外获得12%的耐久度，按照铁砧机制保留魔咒。

# 用途
胡萝卜钓竿能用来吸引猪。

# = 骑猪 =

骑在猪上时，如果玩家手持胡萝卜钓竿，则猪会朝玩家面向的方向前进；胡萝卜钓竿还可以加快猪的行进速度，同时使胡萝卜钓竿降低或耐久度。

胡萝卜钓竿的耐久度耗尽后会变成[钓鱼竿](钓鱼竿.md)并保留魔咒。
