# 苍园觉醒

*页面ID: 127195* | *来源: Minecraft Wiki*

[thumb|苍园觉醒官方艺术作品](File:The Garden Awakens Key Art.png.md)
[thumb|苍园觉醒预告版海报](File:The Garden Awakens Pre-Release Key Art.jpg.md)
* *苍园觉醒（The Garden Awakens）**是一次[小更新](小更新.md)，发布于2024年12月3日<ref name="name"></ref><ref></ref>。其宣布于[Minecraft Live 2024](Minecraft Live 2024.md)，主要内容为加入[苍白之园](苍白之园.md)、[嘎枝](嘎枝.md)及一系列相关[方块](方块.md)。

此更新在官方一个关于Minecraft Live的问卷调查中被称作“Vanilla Holiday Update”。<ref></ref><ref></ref>而后以[实验性内容](实验性内容.md)形式加入游戏时使用名称“冬季小更新（Winter Drop）”，其正式名称于2024年11月27日在Minecraft官网上公布。<ref name="name"/>

# = 物品 =

* 用以生成[嘎枝](嘎枝.md)

* 新的[盔甲纹饰](盔甲纹饰.md)材料。
* 可合成[树脂砖块](树脂砖块.md)，并进一步制作成各种建筑方块。
# = 生物 =
* *[x32px](File:Creaking JE1 BE1.png.md) [嘎枝](嘎枝.md)**
* 由嘎枝之心在[夜晚](夜晚.md)或[雷暴](雷暴.md)天气时生成。
* 被玩家注视时无法移动。
* 由嘎枝之心生成的嘎枝[无懈可击](无懈可击.md)，只有在嘎枝之心被摧毁时才会死亡。

# = 世界生成 =
* ***
* [黑森林](黑森林.md)的新变种。
* 会自然生成悬有苍白垂须的苍白橡树，地表覆盖着苍白苔藓块或苍白覆地苔藓，会生成眼眸花。
* 拥有独特的、由此生物群系中的方块产生的环境音效。

* *[32px](File:Pale Oak.png.md) [苍白橡树](苍白橡树.md)**
* 自然生成于[苍白之园](苍白之园.md)生物群系中的树类地物。
* 自然生成时，树干内可能藏有嘎枝之心。
* 一些树叶下方悬挂着苍白垂须。
