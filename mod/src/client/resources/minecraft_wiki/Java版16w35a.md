# Java版16w35a

*页面ID: 24506* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w35a**是[Java版1.11](Java版1.11.md)的第4个快照，发布于2016年9月1日<ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[国际化](国际化.md)**
* 游戏内更多字符串可供国际化：
* * 命令的输出。

# 更改
# = 方块 =
* *常规**
* 诸如[旗帜](旗帜.md)、[漏斗](漏斗.md)、[箱子](箱子.md)、[熔炉](熔炉.md)、[附魔台](附魔台.md)、[发射器](发射器.md)、[投掷器](投掷器.md)、[酿造台](酿造台.md)和[信标](信标.md)的带有自定义名称的方块，在以物品形式掉落并重新放置时都会保留名称。
* * 利用<code>CustomName</code>标签。

* *[地毯](地毯.md)**
* 1张地毯烧炼量从0.33物品增加到0.335物品。
* * 3张地毯可以完整烧炼1个物品。

* *[梯子](梯子.md)**
* 1把梯子烧炼量从1.165物品增加到1.5物品。
* * 2把梯子可以完整烧炼3个物品。

* *[活板门](活板门.md)**
* 在红石源旁放置活板门会立即更新至开启状态。

# = 物品 =
* *[盾牌](盾牌.md)**
* 在近战中，盾牌防御100%而不是66%的伤害。
* * 无[武器](武器.md)的[僵尸](僵尸.md)既不会伤害玩家也不会减少盾牌的耐久值。
* * [苦力怕](苦力怕.md)爆炸将不会对玩家造成伤害。
* * [凋灵骷髅](凋灵骷髅.md)将不会施加凋零效果。
* * 燃烧的[僵尸](僵尸.md)将不会点燃玩家。
* * [尸壳](尸壳.md)将不会施加饥饿效果。
* * [流浪者](流浪者.md)将不会施加效果。

# = 生物 =
* *[烈焰人](烈焰人.md)**
* 被[喷溅型水瓶](喷溅药水#喷溅型水瓶.md)击中时受到伤害。

* *[末影人](末影人.md)**
* 被[喷溅型水瓶](喷溅药水#喷溅型水瓶.md)击中时受到伤害。

* *带鞍的[猪](猪.md)**
* 可使用[命名牌](命名牌.md)重命名。

* *[末影龙](末影龙.md)**
* 使用的组合键可以显示它能被箭击中的碰撞箱。

# = 世界生成 =
* *沙漠[村庄](村庄.md)水井**
* 井底以[砂岩](砂岩.md)而不是[圆石](圆石.md)构成。

# = 常规 =
* *[选项](选项.md)**
* “匿名信息反馈设置”的标题与描述改变
* * 将新的隐私权政策纳入内容。<ref name="new_privacy_policy">http://mojang.com/2016/09/weve-just-updated-our-privacy-policy/</ref>
* * “硬件信息收集”标题现在改为“向我们提供信息！”。
* * 描述信息改为“我们始终希望优化Minecraft，为此我们想收集一些数据。这些数据可以让我们了解到应该支持的硬件与疑难问题的症结所在。我们收集的数据也使我们大致了解活跃用户的基数，以获知我们的工作是否有效。你可以在下面查看所有我们收集的信息。若你不愿意被收集信息随时可以在下面关闭！”
