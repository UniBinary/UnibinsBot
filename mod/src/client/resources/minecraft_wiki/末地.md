# 末地

*页面ID: 6094* | *来源: Minecraft Wiki*

* *末地（The End）**，全称**末路之地**，是类似于外太空的黑暗[维度](维度.md)，飘浮在[虚空](虚空.md)之中。

# 进入
[缩略图|240px|一个在要塞中已经激活的末地传送门](File:Active End Portal.png.md)

要在生存模式下进入末地，[玩家](玩家.md)必须在[要塞](要塞.md)里找到并激活[末地传送门](末地传送门.md)。一旦进入末地，仅可以通过跨维度激活[掷出的末影珍珠](掷出的末影珍珠.md)（可使用[涌流](涌流气泡柱.md)储存），[死亡](死亡.md)或进入[返回传送门](返回传送门.md)（需要杀死[末影龙](末影龙.md)）的方式离开。

末地传送门房间有一正方形形状的[末地传送门框架](末地传送门框架.md)，[玩家](玩家.md)需要把12个[末影之眼](末影之眼.md)分别嵌入12个末地传送门框架中。所有末地传送门框架都被嵌入末影之眼后，末地传送门便被激活。玩家在进入激活的末地传送门时会被立刻传送到末地。

# 环境
末地由一个大岛屿和远处的许多小外岛构成，它们主要由[末地石](末地石.md)组成。中央岛屿和外岛之间的缺口是一个宽度约1000格的环形[虚空](虚空.md)区域。

未处于[末影龙战斗](末影龙战斗.md)时，末地的天空和虚空都是没有图案的静止黑暗，否则会呈现类似噪声图像的背景图案。开启时与天空偶尔会闪烁并出现[末地闪光](末地闪光.md)（可以主动关闭），伴以特殊音效。

与[下界](下界.md)相似，末地没有[天气](天气.md)与[昼夜更替](昼夜更替.md)现象。因特殊的环境效果，不受其他条件影响下，方块稍亮于完全不受光照的状态，且不受游戏时间的影响。

大多数的物品和方块在末地的功能与在主世界一样，除了以下例外：

* 无法[床](床.md)或[重生锚](重生锚.md)设置重生点，尝试使用时会[爆炸](爆炸.md)，其爆炸威力为5，比[TNT](TNT.md)大25%，且爆炸范围里会生成[火](火.md)。
* [时钟](时钟.md)与[指南针](指南针.md)失效，表现为随机转动。但[磁石指针](磁石指针.md)仍会正常工作，可以指向同一维度里绑定的[磁石](磁石.md)。
* [水](水.md)在末地会呈现深紫色（）。
* [下界传送门](下界传送门.md)不能在末地激活。若使用命令放置[下界传送门方块](下界传送门方块.md)并进入，玩家可被正常传送至[下界](下界.md)；而玩家会被传送至[主世界](主世界.md)，但主世界的方块不会产生状态更新。
* [基岩](基岩.md)上的火不会自然熄灭，但也不会自然传播到毗邻的方块上。

# = 中央岛屿 =
[缩略图|240px|末地的中央岛屿。可以看见[[末影龙](File:The End.png.md)在[黑曜石柱](黑曜石柱.md)旁飞翔]]
中央岛屿是玩家进入末地后最先接触的地形，与主世界和下界的地形都不同，其表现为一个悬浮在虚空上的大型实心岛屿。主岛内陆的地面较为平整，但在边缘处可能会出现一些空洞。中央岛屿初始只有三种结构：玩家进入时生成的[黑曜石平台](黑曜石平台.md)、固定出现在x,z=0处地表的[返回传送门](返回传送门.md)，还有环绕返回传送门生成的若干[黑曜石柱](黑曜石柱.md)。任意实体第一次进入中央岛屿时，游戏还会生成一个[末影龙](末影龙.md)，玩家只有击杀末影龙后，才可能返回主世界，或通过生成的[末地折跃门](末地折跃门.md)更方便地前往外岛。

除[Boss](Boss.md)外任意实体在接触[末地传送门方块](末地传送门方块.md)后，会被立即传送到末地中央岛屿的[黑曜石平台](黑曜石平台.md)上，而不用像[下界传送门](下界传送门.md)那样需等待一定时间。所有被传送的实体会生成在以(100,48,0)为中心的黑曜石平台上。黑曜石平台由上方5×3×5的空气和下方5×1×5的黑曜石组成，每一次由实体进入都会重新生成并替换范围内所有方块。

中央岛屿只会在初次加载与玩家复活时生成末影龙，以及自然生成末影人，此外不再自然生成其他任何生物。

特定的[种子](种子（世界生成）.md)会使中央岛屿的地形生成器失效，只留下黑曜石平台和黑曜石柱。<ref></ref>

特定的种子会使中央岛屿中心的末地石缺失。<ref></ref>

# = 外岛 =
[缩略图|240px|中央岛屿和外岛的关系图](File:EnderIslandsRender.jpg.md)
外岛会从距离中心岛屿1000格以外的地方无限向外生成，而中间是大片的虚空。

外岛有大小两种。最小的岛屿可能只会有几个方块，而大型岛屿可以连成一片，规模也会比主岛大很多。与中央岛屿相同，外岛的地面上也只能看到末影人四处活动。不同之处在于，外岛的地面上还会生长着大片[紫颂树](紫颂树.md)，玩家可通过它们收集食用后随机传送的[紫颂果](紫颂果.md)，或者收集用于种植紫颂树的[紫颂花](紫颂花.md)。外岛上会少见地生成[末地城](末地城.md)，其附近还可能会生成[末地船](末地船.md)，[潜影贝](潜影贝.md)会在这些结构当中栖居，各类高价值的战利品也会在此生成，其中[鞘翅](鞘翅.md)和[龙首](龙首.md)是末地船独有的两种战利品。
[thumb|右|240px|末地的外岛之一。可以看到一座[[末地城](File:End Highlands.png.md)和一艘[末地船](末地船.md)]]

到达末地外岛的途径很多，例如建造一个飞行机器（参见[教程:飞行器](教程:飞行器.md)）、直接建造一条长约1000格的桥或在已前往末地城并获得[鞘翅](鞘翅.md)的情况下使用足量的[烟花火箭](烟花火箭.md)飞行。但这三种方式都会占用过多的时间，或消耗大量的游戏资源，并且很不安全。因此更建议通过将[末影珍珠](末影珍珠.md)丢入[末地折跃门](末地折跃门.md)的方式前往外岛，这么做会被传送到距离主岛1000格~1280格附近的某个外岛上。

由于整数溢出，末地的地形会在以世界原点为中心的若干个环形区域中缺失。<ref></ref>该现象从X/Z=±370,720至524,287开始出现，直到X和Z都为±30,000,317时在[世界界限](世界界限.md)范围内发生最后一次，共发生6,549次。

在Windows平台上的基岩版中，末地的地形生成会在超过X/Z=±9,991,500左右（具体的起始位置随种子有微小变化）时出现故障，外岛将会被填充为几乎实心。

# = 生物 =
末地只会自然出现3种[生物](生物.md)：[末影人](末影人.md)自然生成在整个末地的几乎任何地方；[末影龙](末影龙.md)只能在主岛上自然生成一次，但是可以通过在[返回传送门](返回传送门.md)四周放置4个[末地水晶](末地水晶.md)无限重生末影龙；[潜影贝](潜影贝.md)伴随着外部岛屿的[末地城](末地城.md)和[末地船](末地船.md)结构初始生成，或被其他潜影贝的导弹击中时有概率生成一只新的潜影贝，随结构生成的潜影贝被杀死后不会再次自然生成。在此之外，除了[Boss](Boss.md)以外的其他生物可通过末地传送门进入末地。

下列生物与末地相关，但如果没有玩家进行互动，它们将不会生成。

# == 末影龙 ==

末影龙会在实体首次到达末地后生成。

末影龙的生命值降低到后，它会先移动到返回传送门上方（除非距离太远），然后缓慢升起，身体支离破碎，并迸出多条光束，同时会播放特殊音效。上升一定距离后，末影龙会爆炸，在当前位置生成大量[经验球](经验球.md)。末影龙每次死亡后，返回传送门会生成，并在特定位置生成一个[末地折跃门](末地折跃门.md)（最多20个），为玩家提供回到主世界以及到达外岛的方式。

末影龙首次死亡时，过程中会掉落11波[经验球](经验球.md)，总计12000经验值，足够让玩家从0级升到68级。同时返回传送门上还会出现一个[龙蛋](龙蛋.md)。

杀死末影龙后，玩家可以通过在返回传送门的边侧按一定的排列方式放置四个末地水晶来[重生末影龙](末影龙#重生.md)。杀死重新生成的末影龙时，掉落的经验球总量会只有500点经验值。且不再生成新的龙蛋。

玩家第一次进入返回传送门时，游戏会出现[胜利屏幕](胜利屏幕.md)，展示[终末之诗](终末之诗.md)和鸣谢名单等内容，这也代表玩家“完成”了Minecraft，期间玩家可选择跳过。随后会返回[个人出生点](个人出生点.md)。在这之后玩家仍可通过末地传送门返回末地。

# 你知道吗
* 末地的音轨并不是一般的音轨，而是部分主世界音轨带噪音和扭曲效果的另一版本。
* 在一些罕见情况下，末地主岛并不足够大，以至于部分黑曜石柱没有穿过主岛而是直接悬浮在虚空上方。
