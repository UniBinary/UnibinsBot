# 基岩版1.16.220.50

*页面ID: 79816* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.220.50**是[基岩版1.16.220](基岩版1.16.220.md)的首个测试版，发布于2021年3月4日<ref></ref>，加入了[溶洞](溶洞.md)、新的[山地](山地.md)生物群系<ref></ref>和[发光鱿鱼](发光鱿鱼.md)相关特性，并修复了一些漏洞。

以下更新内容基于上一测试版[1.16.210.61](基岩版1.16.210.61.md)，包含了其中已加入的[洞穴与山崖](洞穴与山崖.md)特性。

# 新内容
# = 方块 =
* *[荧光物品展示框](荧光物品展示框.md)**
* 重新加入。

* *[滴水石块](滴水石块.md)**
* 一种装饰性方块。
* 可用4个[滴水石锥](滴水石锥.md)合成。

# = 物品 =
* *[荧光墨囊](荧光墨囊.md)**
* 重新加入。

* *[刷怪蛋](刷怪蛋.md)**
* 重新加入了发光鱿鱼刷怪蛋。

# = 生物 =
* *[发光鱿鱼](发光鱿鱼.md)**
* 重新加入。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* [草甸](草甸.md)
* * 巨型山地的山麓区域。
* * 唯一没有被雪覆盖的区域，长有[蒲公英](蒲公英.md)、[矢车菊](矢车菊.md)和[甜浆果丛](甜浆果丛.md)。
* [雪林](雪林.md)
* * 巨型山地的繁茂山麓区域，[兔子](兔子.md)会生成于此。
* * 被[雪](雪.md)、[雪块](雪块.md)和[细雪](细雪.md)所覆盖，且长有大片的[云杉](云杉.md)。
* [积雪山坡](积雪山坡.md)
* * 巨型山地的陡峭山腰区域，[山羊](山羊.md)会生成于此。
* * 被雪、雪块和细雪所覆盖。
* [尖峭山峰](尖峭山峰.md)
* * 巨型山地的山顶区域之一。
* * 被雪和雪块所覆盖。
* * 仅在达到一定高度的山上才会生成。
* [冰封山峰](冰封山峰.md)
* * 巨型山地的山顶区域之一。
* * 被冰、浮冰、雪和雪块所覆盖。
* * 仅在达到一定高度的山上才会生成。

* *[溶洞](溶洞.md)**
* 主要由滴水石锥和滴水石块构成，顶部和地面上会分别生成钟乳石和石笋，也会生成大量的水池以及[滴水石簇](滴水石簇.md)。
* 目前仅加入了代码文件，无法在现有世界中生成，只能通过[附加包](附加包.md)来生成。

# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 加入了关于[滴水石锥](滴水石锥.md)的死亡消息：
* * “<玩家> 被坠落的钟乳石刺穿了”
* * “<玩家> 被钉在了石笋上”

# 更改
# = 方块 =
* *[告示牌](告示牌.md)**
* 现在可用[荧光墨囊](荧光墨囊.md)对其文本添加增亮效果。
* * 可用[墨囊](墨囊.md)移除增亮效果。
* 现在可用[染料](染料.md)对其文本染色。

* *[滴水石锥](滴水石锥.md)**
* 现在可以[含水](含水.md)了。
* 钟乳石开始下落时其位置会正确偏移。
* 更改了滴水石锥的物品纹理以匹配[Java版](Java版.md)。
* 现在潜行时放置滴水石锥不会形成石柱。
* 生物现在在石笋上方跳跃会受到的摔落伤害。
* 现在拥有正确的碰撞箱。
* 石笋不再会被流动的[熔岩](熔岩.md)破坏。
* 石笋现在会造成正确的摔落伤害。
* 钟乳石在下界里现在只会滴落熔岩。（）
* 现在使用正确的音效。（）
* 现在滴落水或熔岩的滴水石锥会将其下方的[炼药锅](炼药锅.md)填充水或熔岩。（）
* 现在向滴水石锥投掷[三叉戟](三叉戟.md)可以将其破坏。（）

* *[矿石](矿石.md)**
* 更改了所有主世界矿石的纹理以匹配Java版。
* 现在[煤矿石](煤矿石.md)、[铁矿石](铁矿石.md)和[绿宝石矿石](绿宝石矿石.md)可在山地的任何高度生成。
* 现在绿宝石矿石[团簇](团簇.md)的大小为4-9个方块。

# = 世界生成 =
* *[高度](高度.md)**
* 最大高度限制由256格提升至320格。
* * 最低高度仍为Y0。

# = 技术性 =
* *GameTest框架**
* 将快捷帮助中的部分英文单词更新为骆驼拼写法。
* 更新了仅包含原版方块的快捷命令。
* 加入了用于获取方块的函数，不存在方块时会返回到null。
* 加入了，用于枚举所有的方块状态。
* 加入了，用于设置方块状态。
* 加入了类型。
* 为模块加入了类型。
* 加入了，用于枚举内置标签。
* 更新了所有使用x，y，z坐标来执行的函数。
* 现在注册GameTest时会公开填充。
* 修复了新世界中仍会出现曾经执行失败的GameTest的问题。

# 修复
* *性能与稳定性**
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了玩家在第二个物品栏被占用时使用铁砧重命名地图发生的崩溃。（）

* *常规**
* 细雪不再能与非完整方块共同处于一个方块位置。
* 在DX11和手机平台中的告示牌现在会拥有文本增亮效果。（）
* 在关闭作弊后不再可以使用目标选择器选择自己。（）
* 弹射物现在能穿过结构空位。（）
* 僵尸、僵尸村民、尸壳、掠夺者和卫道士现在会正确地手持盾牌。（）
* 现在一些人-{}-形怪物捡起盾牌后会将其持在副手上。
* 现在具有访客权限的玩家死亡后会正确掉落物品。（）
* 改进了向楼梯、台阶及雪的侧面放置方块时的规则。
* 控制器现在可以在侏罗纪世界包中的NPC高级设置界面切换“按钮模式”选项。（）

* *命令**
* 在同一串连锁型命令方块链中，添加了常加载区域后，再列出常加载区域会列出正确数量的常加载区域。
* 命令执行的屏幕标题不再会重复“%”。（）
* 现在和命令配合使用时，会使用命令执行者所在的维度。（）

* *市场**
* 现在市场上的“搜索结果”会在屏幕内不同部分之间正确刷新搜索内容。

* *辅助功能**
* 现在在成就界面可以通过触摸输入来启用屏幕阅读器。
* 修复了使用VR时文本转语音会读取错误文本的漏洞。

* *村庄**
* 村民在接近床时不会穿过方块上床睡觉。</onlyinclude>
