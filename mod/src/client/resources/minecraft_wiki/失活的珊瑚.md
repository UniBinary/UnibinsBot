# 失活的珊瑚

*页面ID: 163054* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *失活的珊瑚（Dead Coral）**是一种由[珊瑚](珊瑚.md)转变的装饰性方块。

# 生成
# = 珊瑚 =
如果[珊瑚](珊瑚.md)保持存活没有接触[水](水.md)或[含水方块](含水方块.md)且未含水，则其会在或后变成对应失活的珊瑚。

# 获取
失活的珊瑚只能通过破坏失活的珊瑚获得。

# 破坏
失活的珊瑚被挖掘时会立刻被破坏。

失活的珊瑚需要木镐或品质更好的镐来挖掘，否则不会掉落。<ref></ref>

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，失活的珊瑚被破坏后不会掉落。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，失活的珊瑚被破坏后会掉落自身。

# 用途
失活的珊瑚目前仅用于装饰。
