* *铜门（Copper Door）**是由[铜锭](铜锭.md)制成的可开关的[门](门.md)。

# 生成
铜门、斑驳的铜门、锈蚀的铜门、氧化的铜门、涂蜡的斑驳铜门和涂蜡的锈蚀铜门不会生成在世界中，只能通过[氧化](氧化.md)机制生成。

# = 自然生成 =
涂蜡的铜门和涂蜡的氧化铜门会生成于[试炼密室](试炼密室.md)的柱廊和交叉口。

# 破坏
挖掘铜门的合适工具是镐。

铜门被破坏后会掉落自身。

# 用途

玩家、[村民](村民.md)、[铜傀儡](铜傀儡.md)、、[猪灵](猪灵.md)和[猪灵蛮兵](猪灵蛮兵.md)可以开关铜门。

对着铜门按下键即可将其打开或关闭，处于[风爆](爆炸#风爆.md)影响范围中时也会改变其开关状态。

在困难[难度](难度.md)下，[僵尸](僵尸.md)及其变种有或的概率具有打破铜门的能力，但只有在尝试接近目标生物时才会那么做。作为袭击的一部分生成的卫道士在普通和困难难度中也会破坏铜门，但只会在锁定一个目标后才会这样做。有时候卫道士也会直接打开铜门而不是破坏它。僵尸和卫道士会尝试冲破处于“关闭”状态的门，门处于“开启”状态时即使阻挡通过也不会尝试打破（例如，靠在门道右侧面对左侧放门，门处于关闭状态时允许通过，开启状态时则不允许通过）。

# = 红石元件 =

被激活的铜门仍然可以被玩家或村民手动关闭，但在接收到新的上升沿或之前，门不会再次自动打开（即需要将红石信号关闭再开启才能重新控制门）。使门的上下部分之中的一部分激活或撤销激活，而另一部分保持激活，门也会重新自动打开（该行为会主要信号源，并使门立刻自身开关状态）。

# = 氧化 =

铜门受氧化机制影响，能够在不同变种之间转化。
