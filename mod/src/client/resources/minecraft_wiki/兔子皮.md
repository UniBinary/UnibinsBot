# 兔子皮

*页面ID: 12748* | *来源: Minecraft Wiki*

* *兔子皮（Rabbit Hide）**是[兔子](兔子.md)的一种掉落物。

# 获取
# = 掉落物 =

成年[狐狸](狐狸.md)自然生成时有2%的概率在嘴里叼着兔子皮，且其死亡时叼着的兔子皮总是会掉落。

# = 礼物 =

已驯服的[猫](猫.md)赠予玩家礼物时，礼物有16.129%的概率是1个兔子皮。
