# 照片

*页面ID: 90128* | *来源: Minecraft Wiki*

* *照片（Photo）**是一种记录[摄像机](摄像机.md)拍摄内容的物品。<ref></ref><ref></ref><ref></ref>

# 获取
当拍摄的照片保存到[相片簿](相片簿.md)时，可将照片导出成物品。

# 用途
类似于[地图](地图.md)，手持照片或将其放置在[物品展示框](物品展示框.md)中时会在上面显示图像。照片可以通过在[铁砧](铁砧.md)中重命名来添加标题，也可以在[相片簿](相片簿.md)中添加标题。通过[书与笔](书与笔.md)或相片簿中的“添加照片”按钮可以添加照片到其中。
