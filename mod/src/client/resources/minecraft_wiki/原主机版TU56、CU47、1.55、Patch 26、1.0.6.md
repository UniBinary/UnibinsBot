# 原主机版TU56、CU47、1.55、Patch 26、1.0.6

*页面ID: 65503* | *来源: Minecraft Wiki*

* *TU56/CU48/1.55/Patch 26/1.0.6**是[原主机版](原主机版.md)的一次更新，发布于2017年7月25日，修复了一些漏洞。<ref></ref><ref></ref>

# 新内容
# = 常规 =
* [NS](Nintendo Switch版.md)：当放置在Nintendo Switch Dock中时，启用1080P显示。

* *皮肤包**
* 加入生物群系定居者2皮肤包。

* *小游戏**
* 在Tumble里加入陶瓦和带釉陶瓦。
* 在Glide里加入免费峡谷赛道。
* 改进了Solo Glide重新启动关卡时的性能。（尤其是使用分屏时）

# 更改
# = 物品 =
* *[不死图腾](不死图腾.md)**
* 现在给予玩家。

# 修复
* *修复了24个漏洞**
* 修复了一些有可能从Battle地图或Glide赛道中逃离的区域。
* 修复了玩家无法在创造模式下对牛挤奶的漏洞。
* 修复了玩家到达另一个维度后很快就被传送回了下界传送门的漏洞。
* 修复了损坏的旗帜不能与人造旗帜堆叠在一起的漏洞。
* 修复了小麦、梯子和旗帜不能在林地府邸正确生成的漏洞。
* 修复了林地府邸里的刷怪笼是猪而不是蜘蛛的漏洞。
* 修复了拿着地图时物品展示框的图标的漏洞。
* 修复了玩家被僵尸村民杀死时显示的错误死亡消息。
* 修复了死亡消息中未显示生物自定义名字的漏洞。
* 修复了无法解锁成就“狙击手的对决”的漏洞。
* 修复了无法解锁成就“伪装”的漏洞。
*  - 玩家可以在PvP被禁用的情况下杀死已被驯服的鹦鹉。
*  - 农民村民在田里收获种子后，只种下一粒种子。
*  - 在暂停菜单上的花费的潜水时间计入“自由潜水员”奖杯。
*  - 村民们扔食物时把食物扔错了方向。
*  - 两种类型的骨块具有不同的图片。
*  - 僵尸村民刷怪蛋的颜色不对。
*  - 花的判定箱被替换。
*  - 当禁用“TNT爆炸”时，床会爆炸。
*  - 生物无法移动其上方的障碍物。
*  - 用某些方法建造末地传送门可能导致在末地传送门框架旁边再建造一个末地传送门。
*  - 只有普通骷髅在下界生成。
*  &  - 物品展示框不显示其物品的自定义名称。
