# 粗铁

*页面ID: 81134* | *来源: Minecraft Wiki*

* *粗铁（Raw Iron）**是一种从[铁矿石](铁矿石.md)中获得的粗金属资源。

# 获取
# = 挖掘 =
当使用未带有[精准采集](精准采集.md)魔咒的[石镐](石镐.md)或更好的镐挖掘[铁矿石](铁矿石.md)、[深层铁矿石](深层铁矿石.md)时，会掉落1个粗铁。每1级[时运](时运.md)魔咒使得掉落量上限增加1个，使用时运III最多可掉落4个。
