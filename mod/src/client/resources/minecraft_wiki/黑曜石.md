* *黑曜石（Obsidian）**是一种[爆炸抗性](爆炸抗性.md)和[硬度](硬度.md)极高的深紫色[方块](方块.md)，可用于构建[下界传送门](下界传送门.md)框架和合成[附魔台](附魔台.md)。

# 生成
# = 自然生成 =
黑曜石可在各个[维度](维度.md)自然生成：
* [主世界](主世界.md)：
* * 作为[海底废墟](海底废墟.md)和[废弃传送门](废弃传送门.md)的一部分生成。
* * 在部分[林地府邸](林地府邸.md)的隐藏房间“黑曜石房间”和“熔岩房”中生成。
* ** “[黑曜石房间](林地府邸/结构/战利品房间#黑曜石房间.md)”的中央有一个由19块黑曜石组成的树状结构，中间藏有一个[钻石块](钻石块.md)。
* ** “[熔岩房](林地府邸/结构/战利品房间#熔岩房.md)”的中央有一个上下底面为黑曜石（共110块）、四面为[玻璃](玻璃.md)的封闭结构，熔岩包围着一个钻石块在其内生成。
* [下界](下界.md)：作为[废弃传送门](废弃传送门.md)的一部分生成。
* [末地](末地.md)：
* * 作为[末地主岛](末地主岛.md)上[黑曜石柱](黑曜石柱.md)的一部分生成。
* * 在[末地船](末地船.md)宝藏室的地板中生成。

# = 水与熔岩接触 =
[thumb|300px|自然生成的黑曜石](File:Natural Obsidian.png.md)
[thumb|200px|水倾倒在熔岩源上，形成黑曜石](File:Obsidian Creation.png.md)

当[水](水.md)遇到[熔岩](熔岩.md)源方块时，黑曜石会取代熔岩源生成。

在主世界中，许多液体在自然生成完毕后会开始更新和迅速蔓延，并产生“自然”的黑曜石。这种现象常见于地下[洞穴](洞穴.md)的[熔岩湖](地形特征#湖泊.md)被附近的[涌泉](涌泉.md)中流出的水淹没。

# = 事件生成 =
当[下界传送门](下界传送门.md)在[下界](下界.md)或[主世界](主世界.md)生成时，黑曜石作为框架生成。

当任意[实体](实体.md)通过[末地传送门](末地传送门.md)进入[末地](末地.md)时，在实体生成的地方会生成由25块黑曜石构成的/，且该平台可以重复生成。

复活[末影龙](末影龙.md)时，由黑曜石构成的[黑曜石柱](黑曜石柱.md)会重新生成。

# 获取

# = 箱子战利品 =

# = 末影箱 =
没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[末影箱](末影箱.md)被破坏后会掉落8个黑曜石。

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家1个黑曜石。

# 破坏
挖掘黑曜石的合适工具是镐。黑曜石需要钻石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

黑曜石被破坏后会掉落自身。

# 用途
黑曜石的爆炸抗性为1200（与[铁砧](铁砧.md)、[下界合金块](下界合金块.md)等方块相同），可以用来构筑高度耐爆炸的结构。它是[生存模式](生存模式.md)里能获得的最高爆炸抗性的方块之一，也不能被[末影龙](末影龙.md)破坏（但能够被[蓝色凋灵之首](蓝色凋灵之首.md)破坏）。这些特性使黑曜石成为极为有效的防御方块，它在多人游戏服务器的许多基地中通常被用作防御破坏者的手段。

[活塞](活塞.md)和[黏性活塞](黏性活塞.md)不能移动黑曜石。

[末地水晶](末地水晶.md)可以放置在黑曜石的顶部。

# = 下界传送门 =
黑曜石可以用来建造[下界传送门](下界传送门.md)框架，该框架需要[火](火.md)来激活。框架的形状是竖直的矩形，其尺寸可以是4×5到23×23之间的任意尺寸。

# 你知道吗
* 尽管在游戏中黑曜石属于较难被破坏的方块，但在现实中，[黑曜石](wzh:黑曜石.md)为玻璃状结构，易碎。
* 在现实中，黑曜石是一种像[安山岩](安山岩.md)那样的突出火成岩，这意味着它们都是由熔岩冷却时形成的。
* 即使黑曜石被TNT完全包围也不能被其爆炸破坏，无论再增加多少TNT也是如此。可以通过命令生成一场爆炸力大到足以摧毁黑曜石的爆炸。
* * [蓝色凋灵之首](蓝色凋灵之首.md)可摧毁黑曜石是一个特殊的特性，它的爆炸并不强于[恶魂火球](恶魂火球.md)。
