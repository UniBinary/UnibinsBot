# 原主机版TU19、CU7、1.12

*页面ID: 82859* | *来源: Minecraft Wiki*

* *TU19/CU7/1.12**是[原主机版](原主机版.md)的一次更新，发布于2014年12月18日和20日。<ref></ref><ref></ref>

# 新内容
# = 常规 =
* *UI**
* 加入[信标](信标.md)、[马](马.md)、[漏斗](漏斗.md)、[烟花火箭](烟花火箭.md)和[烟火之星](烟火之星.md)的界面。
* *[原主机版教程](原主机版教程.md)**
* 更新了教程世界。
* *[声音](声音.md)**
* 加入许多声音。
* *[选项](选项.md)**
* 加入了昼夜更替、保留物品栏、物品掉落等选项。
* *[语言](语言.md)**
* XBONE：加入了语言选择器，并加入了希腊语。

# 更改
# = 方块 =
* *[下界传送门](下界传送门（方块）.md)和[末地传送门方块](末地传送门方块.md)**
* 生物、物品和弹射物可以穿过传送门。
* *[红石中继器](红石中继器.md)**
* 可以被另一个指向其边侧的中继器锁定。
* *[发射器](发射器.md)**
* 可以面向任何方向。

# = 物品 =
* *[骨粉](骨粉.md)**
* 不再使农作物瞬间成熟。
* *[金苹果](金苹果.md)**
* 食用后会有短暂的[伤害吸收](伤害吸收.md)效果。

# = 生物 =
* *[僵尸](僵尸.md)**
* 可以以不同的盔甲生成。
* *[骷髅](骷髅.md)**
* 可以以不同的盔甲生成。

# = 游戏内容 =
* *[红石电路](红石电路.md)**
* [箱子](箱子.md)、[酿造台](酿造台.md)、[发射器](发射器.md)和[唱片机](唱片机.md)可以通过红石比较器发出红石信号。
* *[生成](生成.md)**
* 玩家在一个地方停留的时间越长，该地攻击型生物就越难生成。
