# Java版Combat Test 7c

*页面ID: 68044* | *来源: Minecraft Wiki*

}}<onlyinclude>

* *Combat Test 7c**是未来的战斗改版的第7个公开的实验性版本，发布于2020年8月14日<ref name="reddit_combat_test_7c"></ref>。虽然它是未来版本的测试版，但这个战斗实验版是[Java版1.16.2](Java版1.16.2.md)的分支。此版本只发布在[Reddit](wzh:Reddit.md)上，因此其并不出现在[启动器](启动器.md)版本列表或[Minecraft.net](Minecraft.net.md)的文章中。

# 更改
# = 物品 =
* *[斧](斧.md)**
* 现在可以在铁砧上用附魔书给斧头附上其他武器魔咒。

* *[弓](弓.md)**
* 移除了拉弓时间过长会使精准度逐渐降低的特性。

* *[药水](药水.md)**
* 现在一组可以堆叠到16瓶。
* * 这并不适用于[喷溅药水](喷溅药水.md)和[滞留药水](滞留药水.md)。

* *[盾牌](盾牌.md)**
* 盾牌在使用时现在会增加50%的击退抗性。
* 现在总是可以立即举起盾牌。
* 盾牌现在可以抵御100%的爆炸伤害。

# = 游戏内容 =
* *[战斗](Tutorial:战斗.md)**
* 再次加入了“200%冷却时间”攻击（下称“蓄力攻击”）这一设定及其+1额外攻击距离的特性。
* * 空挥不算作蓄力攻击，其仍有较短的攻击冷却。
* * 玩家潜行时将失去这一额外攻击距离。
* 为自动攻击加入了一个硬编码的1刻来调整攻击频率，而不是之前版本的变慢20%。
* 再次加入了只有在拥有横扫之刃魔咒且进行蓄力攻击的情况下才会产生横扫攻击的特性。
* 将基础攻击距离改回2.5格。

* *[饥饿](饥饿.md)**
* 移除了玩家在进食时受到攻击会使进食中断这一特性。

* *[HUD](HUD.md)**
* 再次加入了攻击指示器。

# 修复
* *上个开发版本的漏洞**
* 更新了下界合金武器的统计数据。
* 潜行时举盾并攻击空气不再会导致失去同步。
* 旁观模式的玩家不再能在空中横扫。
* 击退抗性属性不再能随机地完全抵御击退。
* 修复了潜行举盾攻击时玩家速度的漏洞。<!--Fixed player speed bug for crouching vs using shield--></onlyinclude>

# 你知道吗
* Combat Test 7和7b是秘密的开发版本，由一些选定的社区成员测试（根据[Jeb](Jeb.md)在Reddit上所说，是“@CodingCookey和他的朋友们”）。由于没有发布关于Combat Test 7和7b的官方博文，这两个秘密的开发版本的信息量非常少。<ref name="reddit_combat_test_7c"/><ref></ref>
