# Java版1.16-pre7

*页面ID: 65143* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.16-pre7**是[Java版1.16](Java版1.16.md)的第7个预发布版，发布于2020年6月16日<ref></ref>，加入了大量新字母，并修复了一些漏洞。

# 更改
# = 生物 =
* *[炽足兽](炽足兽.md)**
* 现在每条腿都可分别使用独立的纹理。

# = 世界生成 =
* *[灵魂沙峡谷](灵魂沙峡谷.md)**
* 将骷髅的生成权重由10提升至20。
* 将此生物群系的生成密度由1.0降至0.7。

# = 常规 =
* *[字体](字体.md)**
* 加入了大量新字母。
* * 其中包括此前尚未加入的一些拉丁文、亚美尼亚文连字和格鲁吉亚字母。

# 修复
+鼠标中键无法复制讲台上的成书。
|169319|字母已包含在默认字体中，但单独的变音/分音符（<code>¨</code>）并没有。
|;dev
|176447|炽足兽的两条腿使用了相同的纹理。
|180283|字体json文件结构不一致。
|180467|世界边界不再完全像固体方块一样不可穿过。
|183673|骷髅在灵魂沙峡谷中生成得不够频繁。
|185126|无法在level不高于3的熔岩中跳跃1格高。
|186228|僵尸猪灵手臂纹理的盔甲层无法随其手臂一同举起。
|188552|僵尸猪灵掉落的经验比以前要少。
|188838|墙上的头颅存在深度冲突现象。
|189824|在创造模式下，主世界或常规背景音乐在下界中也会播放。
|189846|海龟蛋孵化时检测的沙子过深，导致孵化机制被破坏。
|;previous
|189856|无法使用命令或放置下界传送门方块。
|189867|无法通过命令或将方块放置在其通常无法存在的位置。

|189895|丛林神庙里的红石粉没有与方块和其他红石元件正确连接。
|189903|海龟寻找其出生的沙滩时检测的方块过深。
|189905|玩家会卡在世界边界当中。
|189968|生物触碰到世界边界时窒息。
|189971|点击“带我返回”按钮会导致半透明方块停止渲染。
