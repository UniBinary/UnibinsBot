# 末影更新

*页面ID: 26310* | *来源: Minecraft Wiki*

[缩略图|300px|由Mojang发布的末影更新图片](File:EnderUpdate.jpg.md)

* *末影更新（Ender Update）**是[携带版](携带版.md)的一次主要更新，发布于2016年12月19日。<ref></ref><ref></ref>此次更新的官方名称主世界更新于2016年11月11日发布在Xbox网站的一篇博文里。<ref name="ms-news">https://news.xbox.com/2016/11/11/end-2016-ender-update-minecraft-windows-10-pocket-edition/</ref>

此次更新的开发始于[0.17.0.1](携带版0.17.0.1.md)，其发布于2016年11月11日。

[Apple TV版](Apple TV版.md)与[Fire TV版](Fire TV版.md)随此版本一同发布。<ref></ref><ref></ref>

# 重要特性

# = 新内容 =
* [末地](末地.md)。
* * 包含[战斗更新](战斗更新.md)中的所有特性，除了在末地城墙上的[旗帜](旗帜.md)。
* 4种新的生物：
* * [末影龙](末影龙.md)、[潜影贝](潜影贝.md)、[末影螨](末影螨.md)和[北极熊](北极熊.md)。
* 14种新的方块：
* * [末影箱](末影箱.md)、[龙首](龙首.md)、[紫颂花](紫颂花.md)、[紫颂植株](紫颂植株.md)、[末地折跃门方块](末地折跃门方块.md)、[末地传送门方块](末地传送门方块.md)、[末地烛](末地烛.md)、[末地石砖](末地石砖.md)、[紫珀块](紫珀块.md)、[紫珀台阶](紫珀台阶.md)、[紫珀楼梯](紫珀楼梯.md)、[紫珀柱](紫珀柱.md)。
* 7种新的物品：
* * [龙息](龙息.md)、[紫颂果](紫颂果.md)、[爆裂紫颂果](爆裂紫颂果.md)、[末地水晶](末地水晶.md)、[潜影壳](潜影壳.md)、[末影之眼](末影之眼.md)、[末影珍珠](末影珍珠.md)和[滞留药水](滞留药水.md)。
* [雪屋](雪屋.md)。
* 7个新的成就。
* 2个新的命令：和。但命令只能定位要塞。

# = 更改 =
* 主世界的建筑[高度](高度.md)限制改为256格。
* [末影人](末影人.md)现在掉落[末影珍珠](末影珍珠.md)。
