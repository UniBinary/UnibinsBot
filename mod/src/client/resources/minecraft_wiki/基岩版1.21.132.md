# 基岩版1.21.132

*页面ID: 181282* | *来源: Minecraft Wiki*

* *1.21.132**是的一次热修复更新，发布于2026年1月8日<ref></ref>，修复了一些漏洞。此版本与[1.21.130](基岩版1.21.130.md)和[1.21.131](基岩版1.21.131.md)相互兼容。

# 更改
# = 技术性 =
* *图形**
* 修复了附着物在游戏暂停时或在NPC UI窗口中渲染时不会正确渲染的问题。

# 修复
* *账户**
* 修复了Xbox平台玩家的玩家数据会在分屏模式下与账户断开连接的问题。（）

* *图形**
* 修复了在主菜单中切换图形模式时不会重载纹理的问题。
* 修复了附加包资源会在第二个玩家加入分屏游戏后消失的问题。（）

* *常规**
* 修复了对过多实体使用命令时可能导致玩家断开连接的漏洞。（）

* *物品**
* 修复了指南针精灵图偶尔会不可见的问题。（）

* *Realms**
* 修复了在Nintendo Switch平台上购买Realm时可能发生的卡死问题。
