# 携带版0.8.0

*页面ID: 21012* | *来源: Minecraft Wiki*

* *v0.8.0 alpha**是[携带版](携带版.md)的一次主要更新，发布于2013年12月12日，加入了新的方块、物品、农作物和一些其他的特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[木板](木板.md)、[台阶](台阶.md)和[楼梯](楼梯.md)**
* 加入了白桦、云杉和丛林变种。
* 只能用其相应的原木类型合成。
* 在生存模式下无法获得丛林变种。

* *[煤炭块](煤炭块.md)**
* 由9个[煤炭](煤炭.md)合成。
* 可在熔炉中作为燃料使用，可以烧炼80个物品。

* *[地毯](地毯.md)**
* 可用于装饰的方块。
* 由2个羊毛对应颜色的羊毛合成。
* 在生存模式中只有红色可用，其余15种颜色仅在创造模式可用。

* *[圆石墙](圆石墙.md)**
* 用于创建边界的装饰方块。
* 由6个[圆石](圆石.md)合成。
* 生物无法从上方跳过。
* 苔石墙在生存模式无法获得。

* *[干草捆](干草捆.md)**
* 可燃的装饰方块，可用于存储[小麦](小麦.md)。
* 由9个[小麦](小麦.md)合成。

* *[铁栏杆](铁栏杆.md)**
* 与[玻璃板](玻璃板.md)有相似的用途。
* 由6个[铁锭](铁锭.md)合成。

* *[南瓜](南瓜.md)**
* 从成熟的南瓜茎长出的方块。
* 可以合成南瓜灯、南瓜派或南瓜籽。

* *[南瓜灯](南瓜灯.md)**
* 新的光源。
* 由1个南瓜和1个火把合成。

* *[铁轨](铁轨.md)**
* 可让矿车在其上行驶的非固体方块。
* 由铁锭和木棍合成。

* *[动力铁轨](动力铁轨.md)**
* 可以提高移动矿车速度的铁轨。
* 由金锭、木棍和红石粉合成。

* *作物**
* [甜菜根](甜菜根.md)
* [胡萝卜](胡萝卜.md)
* [马铃薯](马铃薯.md)
* [南瓜茎](南瓜茎.md)

* *[丛林原木](丛林原木.md)**
* 装饰方块。
* 在生存模式下无法获得。

* *[丛林树叶](丛林树叶.md)**
* 装饰方块。
* 在生存模式下无法获得。

* *[蕨](蕨.md)**
* 与[草](草.md)类似的植物。
* 在生存模式下无法获得。

* *[枯萎的灌木](枯萎的灌木.md)**
* 只能放在沙子上的植物。
* 在生存模式下无法获得。

* *[海绵](海绵.md)**
* 暂无用途。
* 在生存模式下无法获得。

* *[树皮](树皮.md)**
* 暂无用途。
* 在生存模式下无法获得。

# = 游戏内容 =
* *[繁殖](繁殖.md)**
* 当生物吃下其对应的食物后，便会进入“求爱模式”，准备与另外一只同物种的生物共同进行繁殖。
* * 进入求爱模式的生物会持续散发红心[粒子](粒子.md)。
* 当有2只生物进入求爱模式后，便会寻路到彼此身边，在双亲中间生成一只相同物种的幼年动物，并结束求爱模式。

# = 常规 =
* *[Mipmap](wzh:Mipmap.md)（仅iOS）**
* 使远离玩家的方块具有较低分辨率的纹理以提高设备性能。
* *[设置](设置.md)**
* 加入了“远”（Far，8个[区块](区块.md)）和“最远”（The farthest，12.5个区块）渲染距离。

# = 生物 =
* *常规**
* 改进了[AI](AI.md)系统（[生物](生物.md)会游过深[水](水.md)，敌对生物变得更聪明）。
* 动物幼崽会跟着同种成年动物。
* 动物会跟着拿着[小麦](小麦.md)（[牛](牛.md)和[绵羊](绵羊.md)）、[种子](种子.md)（[鸡](鸡.md)）或[马铃薯](马铃薯.md)、[甜菜根](甜菜根.md)、[胡萝卜](胡萝卜.md)（[猪](猪.md)）的玩家。
* 正在燃烧的生物有新的视觉效果。

* *[绵羊](绵羊.md)**
* 绵羊在脸上和被剪毛后有羊毛上层的颜色（仅iOS）。

* *[蜘蛛](蜘蛛.md)**
* 增加了蜘蛛的移动速度。

# = 游戏内容 =
* *[粒子](粒子.md)**
* 进食的[粒子效果](粒子效果.md)使得食物看起来正在被吃，而不再是食物的随机像素。

* *[创造模式](创造模式.md)**
* 在创造模式中，玩家在离开[火](火.md)/[熔岩](熔岩.md)时会立即停止燃烧。
* 创造模式中的挖掘速度在挖掘距离限制附近增加（每秒8个方块）。
* 新的[创造模式物品栏](创造模式物品栏.md)，有四个物品分类。
* 创造模式中，快捷栏在退出世界时现在会被保存。
* 在创造模式物品栏中，灰色羊毛被移到了正确位置。

* *[物品栏](物品栏.md)**
* 被认为不可获得的物品不再在[快捷栏](快捷栏.md)/物品栏中有红色背景。
* 移入/移出箱子的物品现在被正确渲染。
* 在合成界面中，当前可合成的配方被置顶。
* 物品栏中堆叠数目显示为99+的物品在合成界面中会显示实际数目。
* 从物品栏中选取物品时，所选的物品会替代快捷栏中所选格子上的物品，而不再是到达第一格并让快捷栏中所有物品右移一格。
* 更改盔甲/合成的物品栏使得返回按钮能够返回物品栏。

* *[快捷栏](平视显示器#快捷栏.md)**
* 现在是半透明的。
* 当物品栏开着时，按下快捷栏中的<code>[...]</code>可以关闭物品栏。
* 在快捷栏中，冰不再是透明的。

# = 常规 =
* *图像**
* 3D的[云](云.md)有了新的离散算法。
* 手持的物品现在是3D的，轻微上下摆动，转向时旋转摇摆到一边。
* [水](水.md)、天空、[草](草.md)的颜色更淡了。
* * 远距离的水褪色至不透明（仅iOS）。
* 贴图（仅iOS）。
* 用索引缓冲区顶点对象（VBO）扩展重构大多数渲染。
* * 重制了箭的模型。
* * [物品栏](物品栏.md)现在使用缓存的缓冲区顶点对象扩展渲染。
* * 使用三角形扇的新天空渲染。
* 因为性能原因，区块分为靠近的和远离的两列。
* * 只在远的区块有雾。
* * 只在近的区块透明。
* * 在远的区块有测试中的云层。

* *光照**
* 所有实体现在在下方方块上产生圆形的阴影。
* 实体有了像Java版的动态光照。
* 实体有了环境光照。
* 实体的光照与太阳的位置有关。这不影响它们的阴影。

* *性能**
* 新的应用图标。

* *纹理**
* 从Java版移植了大多数纹理。
* 新的纹理图谱和纹理生成器脚本。

* *[设置](设置.md)**
* 现在精美的图像选项默认为开启。
* 移除了平滑光照选项。现在其始终开启。

# 修复

* *测试版本的漏洞**
* — 玩家卡在固体方块中时会产生透视效果，类似于旁观模式。
* — 矿车会显示一种奇怪的形状且角度不对。
* — 矿车在从地下驶出并接触到露天环境时会停止。
* — 第三人称视角无法破坏矿车。
* — 乘坐矿车上坡时会感觉是在攀爬方块而非平滑移动。

* *其他**
* 聊天屏幕上的文字不再中断。
