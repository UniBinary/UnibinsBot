# 基岩版1.14.0.12

*页面ID: 50621* | *来源: Minecraft Wiki*

* *1.14.0.12**是的一次热修复更新，仅在PlayStation 4上发布于2019年12月13日<ref></ref>，修复了一些漏洞。

# 修复
* *崩溃/性能**
* 修复了若干可能发生在游戏过程中的崩溃。
* 修复了若干可能发生在PlayStation 4版游戏存档转换过程中的崩溃（）。
* 修复了登录微软账户时可能发生的崩溃。
* 修复了在试玩版本中解锁奖杯时出现的崩溃。
* 游玩其他版本的存档时不再拖长加载时间。
* *常规**
* 修复了在试玩版本中按下“解锁完整游戏”出现的错误。
* 修复了主菜单和商店中账户出现“错误代码0”的漏洞。
* *游戏内容**
* 当玩家朝向南或北时，视觉摇晃会正确运作。（）。
* 转换PlayStation 4版的存档不再导致潜影盒储存的物品消失（）。
* 修复了转换PlayStation 4版的存档会导致作弊开启的漏洞（）。
* 修复了多人游戏下一些奖杯会为全体玩家解锁的漏洞。
* *生物**
* 蜜蜂现在会在进行攻击后死亡（）。
* *图像**
* 修复了资源包停用后出现损坏纹理的问题。
* 修复了部分角色创建器物品显示不正确的问题。
* *UI**
* 修复了玩家无法在商城中退出物品栏页面的问题。
* 修复了角色创建器页面右侧的下滑栏。
* 修复了出现在资源包和行为包页面中的占位符文本。
