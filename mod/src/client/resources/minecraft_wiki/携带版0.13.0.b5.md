# 携带版0.13.0.b5

*页面ID: 18951* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.13.0 alpha build 5**是[v0.13.0 alpha](携带版0.13.0.md)的第5个测试版，发布于2015年11月11日<ref>http://pocketbeta.minecraft.net/2015/11/changelog-for-013-build-5.html?m=0</ref>，修复了一些漏洞。

# 修复
* *修复了5个漏洞**
* 使用“非门”激活的红石钟现在会稍微变慢运行以保持同步。
* 垂直放置的红石线现在会正确对齐。
* 红石火把现在会正确亮起或熄灭。
* 更改新皮肤包内的部分纹理。
* Fire TV版玩家现在可以正确使用控制器来进行画面移动。</onlyinclude>
