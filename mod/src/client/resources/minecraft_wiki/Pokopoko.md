# 描述

[File:pokopoko.ogg](File:pokopoko.ogg.md)

* Pokopoko*是一首以弦乐器和木管乐器和声为基础，结合手鼓和颤音琴演奏的歌曲。手鼓负责演奏主旋律，而颤音琴则增添了闪闪发光般装饰的音效。
