* *马铃薯树（Potato Tree）**是外观与[金合欢树](金合欢树.md)相似的植被[地物](地物.md)。

# 描述
马铃薯树的高度为6-11格，偶尔也会生成高耸的马铃薯树，长有2-4格高的扁平树冠。

马铃薯树的主干可能会弯折，也有可能长出弯曲的分杈，每条分支带有独立的叶簇。组成弯折枝干的[马铃薯茎柄](马铃薯茎柄.md)在对角线上分布。每簇叶簇下都有概率生成[马铃薯果实](马铃薯果实.md)，马铃薯果实与[马铃薯树叶](马铃薯树叶.md)以[马铃薯果柄](马铃薯果柄.md)连接。

# 生成
马铃薯树生成时会将下方1格的方块转变为[马铃薯泥土](马铃薯泥土.md)。

# = 自然生成 =
马铃薯树会在[植物园](植物园.md)和[腐败区](腐败区.md)中生成。

马铃薯树生成时有很小的概率带有[蜂巢](蜂巢（方块）.md)，每个生成的蜂巢都会容纳3只[蜜蜂](蜜蜂.md)。

# = 人为生成 =
[亮度](亮度.md)等级至少为9且有一定的空间时，对[马铃薯苗](马铃薯苗.md)[骨粉](骨粉.md)可使其长成马铃薯树。
