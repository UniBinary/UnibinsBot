# Java版24w39a

*页面ID: 126516* | *来源: Minecraft Wiki*

<onlyinclude>

* *24w39a**是[Java版1.21.2](Java版1.21.2.md)的第7个快照，发布于2024年9月25日<ref></ref>，将“”[实验性内容](实验性内容.md)正式加入到游戏内，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[标签](Java版标签.md)**
* 加入了物品标签<code>#map_invisibility_equipment</code>：<code>carved_pumpkin</code>。
* * 能被装备以隐藏在其他玩家地图上的玩家标记的物品。
* 加入了实体类型标签<code>#boat</code>：。
* * 用于进度文件。

# 更改
# = 方块 =
* *[容器](容器.md)**
* 方块实体数据<code>Lock</code>现在被重命名为<code>lock</code>，其内容现在是一个[物品谓词](物品谓词.md)。
* * 任意匹配此谓词的物品都能打开此容器。

# = 物品 =
* *[收纳袋](收纳袋.md)**
* 不再属于[实验性内容](实验性内容.md)。

* *[地图](地图.md)**
* 在头部装备[雕刻南瓜](雕刻南瓜.md)的玩家不再会在其他玩家的地图上显示玩家标记。
* * 具体物品可通过新加入的物品标签修改。

# = 生物 =
* *[溺尸](溺尸.md)**
* 现在增援溺尸只能在有足够空间的液体中生成。

* *[生物转化](生物转化.md)**
* 发生僵尸变种与僵尸变种之间的生物转化时，<code>CanBreakDoors</code>标签也会被继承。

# = 非生物实体 =
* *[船](船.md)和[运输船](运输船.md)**
* 拆分了每种船和运输船的实体类型ID，因此移除了<code>Type</code>字段。
* * 移除了。
* * 加入了。

# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 更新了GUI槽位高亮，以提高物品纹理的可见度。
* * 旧版本纹理已添加到Programmer Art[资源包](资源包.md)中。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。
* 移除了<code>bundle</code>实验性数据包和功能开关。

* *[物品堆叠组件](物品堆叠组件.md)**
* <code>lock</code>组件现在是一个物品谓词。

* *[实体子谓词](实体子谓词.md)**
* 移除了<code>boat</code>实体子谓词。
