* *A Minecraft Movie直播活动（A Minecraft Movie Live Event）**，是[基岩版](基岩版.md)中官方与Spark Universe合作开展的限时开放的[活动服务器](活动服务器.md)，属于[A Minecraft Movie](A Minecraft Movie.md)的预热活动。

该服务器由4个场景组成，包括|中港村}}、荒野、外墙和矿井。

服务器设置了6项[任务](#任务与奖励.md)，每隔一天开启一项新的任务，每完成一项任务能获得[角色创建器](角色创建器.md)奖励。当全部完成后，即可获得[渴望披风](渴望披风.md)。<ref></ref>

# 场景

玩家首次进入服务器时会自动装备皮革外套、皮革裤子和皮革靴子，快捷栏的第1-3格分别是石剑、弓和石镐，第7-9格分别是地图、任务列表和空的装扮品槽。这些物品都无法移动和丢弃。玩家的所有装备也不会消耗耐久，即使是在商店中升级后也是如此。

玩家首次进入各场景时，会播放一段动画，向玩家展示这个场景。

玩家可以在各个场景中收集绿宝石和经验值，当前持有的绿宝石数量会在右上角显示。绿宝石可以用于在升级装备和购买装饰品，而经验值没有任何用途，且玩家到达100级后经验等级会固定显示在100级。

地图可以将玩家传送到其他场景。使用地图传送到自己所在的场景，会将玩家传送到场景的起始位置。在矿井中使用地图传送到矿井会使得玩家身上的矿物和宝物丢失。

玩家可以通过任务列表查看所有任务和它们的完成情况。

服务器的各个场景会在一些固定的地点生成50-500不等的绿宝石和其他。

玩家在米德波特村庄以外的场景挂机超过10分钟后会强制回到米德波特村庄中。

玩家在米德波特村庄以外的场景都会正常受到伤害，而饥饿值会保持为满。

服务器中的猪灵存在从电影中取材而原版中不存在的变种。

# = 米德波特村庄 =
[200px|thumb|right|米德波特村庄世界的地图](File:AMCM village world map.png.md)
每次玩家进入服务器时都位于米德波特村庄的中心，面朝西方。

米德波特村庄的建筑和电影中的相似。村庄中有电影中的5名主要角色，玩家可以按下键与他们互动。

村庄中心是史蒂夫，每隔一段时间会播放电影中的部分台词。道恩和娜塔莉在中心的西南方向，玩家可以通过与他们互动进入。加雷特在中心的正北方向，通过互动可以进入。亨利在中心的东南方向，通过互动可以进入。这些角色的分布方位和地图上三个场景的方位一致。

村庄中心有两个商店，靠南边的可以升级装备，北边的可以购买装饰品。

# = 荒野 =
[150px|thumb|right|护送的马车](File:AMCM live event payload cart.png.md)

在荒野中有三个据点，玩家需要护送马车在A据点和B据点，或是B据点和C据点之间安全地往返。

在路上的固定地点会出现一群[掠夺者](掠夺者.md)或[猪灵](猪灵.md)，B据点和C据点之间还会出现[唤魔者](唤魔者.md)，数量视玩家数量而定。它们会攻击玩家和马车，玩家需要将它们消灭才能让马车继续前行。场景中还会少量随机生成[鸡骑士](鸡骑士.md)和[蜘蛛](蜘蛛.md)。马车到达任意据点后，对任意生物造成过伤害的玩家会获得一定数量的经验值和绿宝石，同时马车的血量会回满并出发前往下一个据点。

在A据点的中心旁边是道恩和娜塔莉，玩家可以与她们互动。除此之外还有布告牌，显示玩家成功护送马车的次数。

玩家进入荒野时可能会位于任意据点的中心，或是位于荒野中的某个地点。

马车上方有一道光柱，以便离得较远的玩家发现。玩家在马车附近时，屏幕上面会显示马车的生命值。马车的前进速度和玩家的步行速度相同。马车附近没有玩家或存在敌人时会停下，直到有玩家靠近且附近的敌人全部消失才会继续前行。

# = 外墙 =
[175px|thumb|right|城门](File:AMCM live event gate.png.md)
在外墙中，玩家需要登上城墙，攻击从下界传送门中涌出的猪灵大军，阻止它们破坏城门。玩家在城门附近时，屏幕上面会显示城门的生命值。

在活动的第1-2天，城墙外有7个下界传送门，而在活动的第2天之后，城墙外有13个下界传送门。在每一轮攻势中都会生成数量一定的猪灵，猪灵的-{}-头上会显示生命值。在城墙外还有5个固定位置的铁傀儡帮助玩家抵御进攻，能对猪灵造成伤害。猪灵会优先攻击铁傀儡，然后攻击城门。

在活动的第2天之后，下界传送门还会生成恶魂，会优先向铁傀儡发射火球，铁傀儡被火球伤害后会燃烧。

城墙中间正对的下界传送门顶上会生成“火球”，投向站在城墙上的任意玩家并造成范围伤害。即将被“火球”击中的位置会出现一个准星，玩家位于“火球”的作用范围内时屏幕上会出现一个红色感叹号。

一轮攻势以城门未损坏而恶魂和猪灵全部被击败而告终时，在城墙附近的、使用弓对任意生物造成过伤害的玩家会获得一定数量的经验值和绿宝石，数秒后会开始下一轮攻势，城墙外的5个铁傀儡也会被重置。

在外墙的入口旁边是加雷特，玩家可以与他互动。除此之外还有一块布告牌显示玩家成功抵御的进攻波数。

城墙边缘存在障碍，因此通常情况下玩家无法跳下城墙。

在外墙中，玩家不会受到火焰、熔岩和窒息伤害。恶魂和猪灵也不会以玩家作为攻击目标。

# = 矿井 =
在矿井中，玩家需要采集矿物和收集宝物，并回到中心进行结算，获得经验值和绿宝石。

在矿井表层入口旁边是亨利，玩家可以与他互动。除此之外还有一块布告牌显示玩家成功结算的矿物和宝物总数。

玩家进入矿井时位于表层，可以通过电梯进入1、2层，也可以直接跳下深处到达1层。

在1层矿井中，玩家可以挖掘随处生成的煤矿石、铁矿石、红石矿石；2层矿井中，有深层青金石矿石、深层金矿石和深层钻石矿石。这些矿石的掉落物及[合适挖掘工具](合适挖掘工具.md)和原版游戏一致。矿石破坏后产生的掉落物会自动进入玩家的物品栏，如果玩家的物品栏已满则会丢失。如果没有使用合适挖掘工具破坏，矿石被破坏后只会产生红叉粒子，玩家也不会获得掉落物。

在矿井中会随机生成僵尸、苦力怕或蜘蛛，在2层矿井中还会生成骷髅或末影人，击败它们会获得经验值。这些怪物生成时不会携带[天然装备](掉落物#装备物.md)，也不受亮度限制。矿井中的一些地点还会随机生成[猪灵王](Legends:不败盾山.md)，其被击败时，周围的所有玩家都会获得一定数量的钻石，无论是否对猪灵王造成过伤害。

在矿井中还存在刷怪笼房间，1层有5处，2层有3处，里面有刷怪笼和宝箱，玩家可以在宝箱中获得宝物。刷怪笼会随机生成僵尸、骷髅、蜘蛛或苦力怕，被破坏后不会掉落经验。玩家打开宝箱时，宝箱有一定概率会变成一个激活的TNT，或是消失并在周围生成较多怪物攻击玩家。

在1层矿井的矿道中还有2处刷怪笼和宝箱，类似于废弃矿井中的洞穴蜘蛛刷怪笼，不过并不会生成洞穴蜘蛛。

玩家在回到矿井中心时，身上的矿物和宝物会自动结算为经验值和绿宝石：

玩家在矿井中死亡或使用地图传送至矿井时会掉落身上的所有矿物和宝物，同时被传送回表层。

1层矿井中设计了3处存在较多红石矿石的地点，2层设计了3处存在较多深层钻石矿石的地点。

矿井中的刷怪笼房间会在周围50格内没有玩家时立即刷新，被挖掉的方块刷新所需的时间和周围玩家的距离更大。

玩家可以在手持镐时选中并挖掘矿井中的石头类方块，但无法破坏。

# 商店
米德波特村庄中有两个商店，它们都有两个出入口。其中南边的商店门前挂着一个锤子和锯子交叉构成的装饰，对应电影中的“史蒂夫的秘密藏身处”，可以升级玩家身上的装备；北边的商店门前悬挂着一个钻石靴子雕塑，可以购买装饰品。

# = 装备升级 =
[150px|thumb|right|“史蒂夫的秘密藏身处”门前的标志](File:AMCM live event upgrade sign.png.md)
玩家可以在“史蒂夫的秘密藏身处”中用绿宝石升级装备。建筑里有四个物品展示框，分别展示玩家当前的[盔甲](盔甲.md)、[剑](剑.md)、[镐](镐.md)、[弓](弓.md)，表示此处可以升级的装备。

在每个物品下，玩家可以类似于锻造台的方块，对装备进行常规升级，但只能按照下表中的顺序进行；也可以类似于附魔台的方块，为装备附上额外的魔咒，其不受常规升级顺序的约束。

# = 购买装饰品 =
[150px|thumb|right|装饰商店门前的标志](File:AMCM live event fishing rod.png.md)
玩家可以在装饰商店中用绿宝石购买装饰品。

当玩家在商店购买了任意装饰品后，可以在商店中陈列的这些装饰品处切换是否在头盔槽或快捷栏第9格中持有对应的装饰品。

# 每日变更
活动期间，服务器在每天的特定时间都会发生变更。每当玩家进入服务器时，[聊天栏](聊天栏.md)中都会出现有关当天变更内容的公告。

# = 增益 =
在特定的天数中，玩家或敌人会获得**增益（Buff）**。

当天生效的增益图标会出现在屏幕的右上角，绿宝石数量的左侧。其中敌人的增益图标表现为带有橙色火焰效果的猪灵头像，玩家的增益图标表现为带有绿火焰效果的村民头像。

当各自的增益生效时，敌人会获得II效果，玩家则会获得II和II效果，同时身旁都会产生金色的闪光粒子。

# 隐藏物品
服务器中的各个场景中都有隐藏物品，聊天栏中会随机出现相关的提示。

每处隐藏物品在拾取后不会消失（绿宝石除外），但不能重复拾取。拾取后可以在物品栏中自由移动，但无法用于[合成](合成.md)和。

# 你知道吗
* 与以往的[活动服务器](活动服务器.md)不同，本次服务器的[资源文件](附加包.md)经过加密，类似于来自[市场](市场.md)的包。
* 服务器的音乐使用了[Minecraft Dungeons](Minecraft Dungeons.md)、[Minecraft Legends](Minecraft Legends.md)和[A Minecraft Movie](A Minecraft Movie.md)中部分音乐剪辑后的版本。
* 服务器自4月1日起开放了[聊天](聊天.md)。目前暂不清楚这是否是意外。
* 在4月5日前，尽管第6个任务没有开放，但是仍然可以完成并获得[披风](披风.md)。
* 在4月5日前，尽管矿井2层没有开放，但是仍然可以通过修改服务器附加包的方式进入。
* 尽管服务器的每日公告表明敌人与玩家的增益本应交替进行，但最终只在第2天和第3天对敌人进行了增益，自第4天起增益方一直是玩家。
* 1层矿井中有一处只能通过水下洞穴进入的空气室。
* 发射出的马铃薯可以对荒野中的马车造成伤害，但马车的生命值不会因此减少。
* 由于仙人掌球可以在物品栏中分开，且仙人掌球数量少于3个时能补充到3个，因此可以通过在物品栏中将多个仙人掌球放在不同的格子来刷取仙人掌球。通过此种方法刷取的仙人掌球会在使用地图后消失。
* 服务器的大部分[下界传送门](下界传送门.md)都是假的，但是外墙中有一个是真的。
* 尽管在外墙中玩家无法直接跳下城墙，但是玩家可以通过使用冲出城墙边缘时[潜行](潜行.md)以冲下城墙。
* 玩家可以在给剑附魔火焰附加后对外墙中的城门造成伤害。
* 在外墙中，有时敌人全部被击败后也不会结算，此时玩家可以自行摧毁城门并开始下一波次。
