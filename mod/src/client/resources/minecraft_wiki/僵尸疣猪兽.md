* *僵尸疣猪兽（Zoglin）**是疣猪兽进入[下界](下界.md)以外的维度后转化成的[亡灵](亡灵.md)敌对生物。

# 生成
[疣猪兽](疣猪兽.md)在下界以外的维度停留超过后转化为僵尸疣猪兽。它们转化之后会受到10秒的[反胃](反胃.md)效果，但反胃效果并不会影响其行为。

# 行为
僵尸疣猪兽会主动攻击除[苦力怕](苦力怕.md)、[恶魂](恶魂.md)、和其他僵尸疣猪兽以外的所有生物（包括和[盔甲架](盔甲架.md)<ref></ref><!--Aggressive to any entity that extends the "LivingEntity" class, which includes armor stands. This does not include things like minecarts or item frames.-->）。

成年僵尸疣猪兽会把攻击目标抛向空中，使用[盾牌](盾牌.md)格挡也会稍微被抛起。幼年僵尸疣猪兽也会攻击，但不会将实体抛向空中且攻击速度更快。幼年僵尸疣猪兽被其他生物攻击后不会进行反击。

与[疣猪兽](疣猪兽.md)不同，僵尸疣猪兽不能繁殖，幼年个体不会成长为成年个体。它们也不会远离疣猪兽所排斥的方块。僵尸疣猪兽的攻击比疣猪兽更加频繁。

类似于[僵尸猪灵](僵尸猪灵.md)，僵尸疣猪兽会导致附近的[猪灵](猪灵.md)逃跑，它们也不会[着火](着火.md)，且免疫[火焰伤害](火焰伤害.md)。

# = 生物族群 =

僵尸疣猪兽是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉直到接触水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

僵尸疣猪兽不会在阳光下着火。
