# 破坏
挖掘烤马铃薯砖墙的合适工具是锄和镐。烤马铃薯砖墙需要木质或品质更好的锄或镐来挖掘，否则挖掘时间将延长且不会掉落。

烤马铃薯砖墙被破坏后会掉落自身。

# 用途

烤马铃薯砖墙可用于装饰，并有与其他墙相似的特性。
