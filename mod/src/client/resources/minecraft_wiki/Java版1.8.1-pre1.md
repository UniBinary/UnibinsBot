# Java版1.8.1-pre1

*页面ID: 14108* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.8.1-pre1**是[Java版1.8.1](Java版1.8.1.md)的首个预发布版，发布于2014年10月15日<ref></ref>。

# 新内容
# = 命令格式 =
* *[游戏规则](命令.md)**
* <code>doEntityDrops</code>
* * 类似于<code>doTileDrops</code>，但目标是实体。<ref></ref>

# 更改
# = 方块 =
* *[南瓜灯](南瓜灯.md)**
* 再次能够用来生成[铁傀儡](铁傀儡.md)和[雪傀儡](雪傀儡.md)。

# = 物品 =
* *[地图](地图.md)**
* 改变一些颜色，显然会随着生物群系而改变。

* *[跳跃药水](跳跃药水.md)**
* 现在能够被延长。

# = 生物 =
* *常规**
* 不再逃避即将爆炸的苦力怕。

# = 世界生成 =
* *[沼泽小屋](沼泽小屋.md)**
* 新的生成范围是在Y轴上的64到71。
* 这将使女巫陷阱的刷怪层增加到3。

# = 命令格式 =
* *[游戏规则](命令.md)**
* <code>doTileDrops</code>不再影响实体。

# = 游戏内容 =
* *[制作人员名单](制作人员名单.md)**
* [Ryan Holtz](Ryan Holtz.md)（TheMogMiner）和[Michael Stoyke](Michael Stoyke.md)（Searge）现在在创作中列表中被提到。

# = 常规 =
* *[选项](选项.md)**
* 将“多人游戏设置”更名为“聊天设置”。

* *性能**
* 各处的性能提升。
