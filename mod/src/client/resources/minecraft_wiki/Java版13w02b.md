* *13w02b**是[Java版1.5](Java版1.5.md)的第4个快照，发布于2013年1月11日<ref></ref>，修复了[13w02a](13w02a.md)里的漏洞和崩溃。

# 更改
# = 方块 =
* *[激活铁轨](激活铁轨.md)**
* 更改了[激活铁轨](激活铁轨.md)的合成配方——包含两根[木棍](木棍.md)和一个[红石火把](红石火把.md)，再加上原有的6个[铁锭](铁锭.md)。[Dinnerbone](Dinnerbone.md)指出之前的合成配方为一个漏洞。

* *[箱子](箱子.md)**
* 当连接至一个[红石比较器](红石比较器.md)时，大型[箱子](箱子.md)现在会根据有多少组的物品在内来传输红石信号。
* 在此之前，大型箱子只会根据单个箱子有多满来输出信号。<ref>http://www.reddit.com/r/Minecraft/comments/16dmm1/minecraft_snapshot_13w03a_released/c7v1rki</ref>

* *[漏斗](漏斗.md)**
* 当被充能时，[漏斗](漏斗.md)不会接收任何物品。<ref>http://imgur.com/qogQW,xo2gL#0/</ref>

* *[陷阱箱](陷阱箱.md)**
* 现在会透过一个方块向下传输信号。但不会传输过横向的墙。<ref></ref>
