* *芝士（Cheese）**是一种放置后能为玩家恢复饥饿值的类似[食物](食物.md)的方块。

# 生成
# = 自然生成 =
芝士会自然生成于月球，是月球的主要组成方块。

# = 挤奶 =

对着芝士奶桶可以放置一块新的芝士，且奶桶会变为空[铁桶](铁桶.md)。

# 破坏
没有工具可以加速对芝士的挖掘。

没有被食用的芝士被破坏后会掉落自身，被食用的芝士被破坏后不会掉落。

# 用途
# = 食用 =
与[蛋糕](蛋糕.md)类似，玩家可对芝士按下键吃掉该方块的一角（棱长0.5格的正方体，个方块）。玩家可以选择8个角中的任意一个食用，食用后恢复和1点氧气值。
