# 紫水晶簇

*页面ID: 71918* | *来源: Minecraft Wiki*

* *紫晶芽（Amethyst Bud）**是从[紫水晶母岩](紫水晶母岩.md)上长出的水晶，有**小型紫晶芽（Small Amethyst Bud）**、**中型紫晶芽（Medium Amethyst Bud）**和**大型紫晶芽（Large Amethyst Bud）**三个阶段。

* *紫水晶簇（Amethyst Cluster）**是紫晶芽的最终生长形态。

# 生成
# = 自然生成 =
紫晶芽和紫水晶簇可以在[紫晶洞](紫晶洞.md)中的[紫水晶母岩](紫水晶母岩.md)上自然生成。当紫水晶母岩接收到一个[随机刻](刻#随机刻.md)时，只要毗邻的方块是空气方块或水源方块，该方块就会有20%的概率生成一个小型紫晶芽。

# 获取
紫晶芽和紫水晶簇的物品形式只能通过使用具有[精准采集](精准采集.md)的工具挖掘破坏对应方块获得。

# 破坏
挖掘紫晶芽和紫水晶簇的合适工具是镐。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，紫水晶簇被破坏后会掉落4个[紫水晶碎片](紫水晶碎片.md)，没有使用镐时则是2个，挖掘工具是镐且附有[时运](时运.md)魔咒会增加紫水晶碎片的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，紫晶芽被破坏后不会掉落。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，紫晶芽和紫水晶簇被破坏后会掉落自身。

# 用途
紫水晶簇可用于获得[紫水晶碎片](紫水晶碎片.md)。

紫晶芽和紫水晶簇可以含水。

# = 生长 =
紫晶芽在长成紫水晶簇前有三种生长阶段：小型、中型和大型。当紫水晶母岩接收到一个随机刻时，连接到它的某个紫晶芽有20%的概率生长到下个阶段。

紫晶芽必须放在紫水晶母岩上才能生长。

# = 光源 =
小型、中型、大型紫晶芽会分别发出[亮度](亮度.md)为1、2、4的光，而紫水晶簇则会发出亮度为5的光。
