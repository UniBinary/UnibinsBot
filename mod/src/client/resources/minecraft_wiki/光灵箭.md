# 光灵箭

*页面ID: 159182* | *来源: Minecraft Wiki*

* *光灵箭（Spectral Arrow）**是一种可以对[生物](生物.md)施加[发光](发光.md)效果的[箭矢](箭矢.md)变种。

# 生成
[发射器](发射器.md)在使用光灵箭时会将其发射。

[玩家](玩家.md)使用弓或弩可以发射光灵箭。

# 获取
射出的光灵箭在一些情况下可以被[回收](箭#回收.md)进玩家的[物品栏](物品栏.md)里。

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予6-12支光灵箭。

# = 箱子战利品 =

# 用途

具有[无限](无限.md)魔咒的弓在使用光灵箭射击时，光灵箭会被正常消耗。

# 行为

光灵箭具有与箭相同的行为。

# = 造成状态效果 =
光灵箭在命中生物时会施加10秒的[发光](发光.md)效果。
