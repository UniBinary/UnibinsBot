# 红沙

*页面ID: 162948* | *来源: Minecraft Wiki*

* *红沙（Red Sand）**是一种在[恶地](恶地.md)自然生成的[方块](方块.md)。

# 生成
# = 自然生成 =
红沙自然生成在[恶地](恶地.md)、[疏林恶地](疏林恶地.md)和[风蚀恶地](风蚀恶地.md)生物群系的地表，通常形成由[橙色陶瓦](橙色陶瓦.md)支撑的1格厚的地层。

红沙可以自然生成在空中。当周围接收到方块更新时（在周围有方块被放置或破坏）（需要[PP更新](方块更新#PP更新.md)），相邻的下方没有支撑方块的红沙会全部掉落。

# 破坏
挖掘红沙的合适工具是锹。

红沙被破坏后会掉落自身。

# 用途
# = 下落的方块 =

红沙在下方没有不可替代的方块时会变为[下落的方块](下落的方块.md)。

红沙在没有得到支撑时，会在方块下方产生[粒子](粒子.md)。

# = 种植 =
[仙人掌](仙人掌.md)、[甘蔗](甘蔗.md)、[竹子](竹子.md)、[枯萎的灌木](枯萎的灌木.md)、[矮枯草丛](矮枯草丛.md)和[高枯草丛](高枯草丛.md)可以在红沙上面种植。

# = 环境音效 =
若红沙的上方一格为空气，且其四个水平轴向上八格外处，有至少三处在上下五格内存在上方一格为空气的红沙，该红沙有概率发出特殊的环境音效。

满足上述条件时，红沙总是小概率播放<code>block.sand.idle</code>音效。
