# 珊瑚

* *珊瑚（Coral）**是一类非固体方块，有**管珊瑚（Tube Coral）**、**脑纹珊瑚（Brain Coral）**、**气泡珊瑚（Bubble Coral）**、**火珊瑚（Fire Coral）**和**鹿角珊瑚（Horn Coral）**五个变种。

# 生成
# = 自然生成 =
珊瑚会自然生成在[暖水海洋](暖水海洋.md)群系的[珊瑚礁](珊瑚礁.md)结构中。

# = 骨粉 =
对水下的[泥土](泥土.md)、[砂土](砂土.md)、[沙子](沙子.md)、[红沙](红沙.md)或[沙砾](沙砾.md)使用骨粉有概率生成珊瑚，必须在[暖水海洋](暖水海洋.md)生物群系中进行，而则无须在特定生物群系。

# 获取
珊瑚只能通过破坏珊瑚获得。

# 破坏
珊瑚被挖掘时会立刻被破坏。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，珊瑚被破坏后不会掉落。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，珊瑚被破坏后会掉落自身。

# 用途
在以下情况时，珊瑚会被破坏且不会掉落：
* 珊瑚的附着方块移动、消失或被摧毁；
* [活塞](活塞.md)尝试推动珊瑚或把方块推到珊瑚所在的方块。

# = 失活的珊瑚 =
若要使珊瑚保持存活，要使其至少一面接触[水](水.md)或[含水方块](含水方块.md)，或使其含水，否则会在或后变成对应[失活的珊瑚](失活的珊瑚.md)。

# 你知道吗
* 在现实中，珊瑚是一种[固着动物](wikipedia:Sessility_(motility).md)的群体，不是植物。
* 珊瑚不是[固体方块](固体方块.md)，但失活的珊瑚属于固体方块。
