# 金蒲公英

*页面ID: 184364* | *来源: Minecraft Wiki*

* *金蒲公英（Golden Dandelion）**是一种[小型花](小型花.md)，可以用于阻止部分幼年生物成长。

# 生成
金蒲公英不会生成在世界中。

# 破坏
金蒲公英被挖掘时会立刻被破坏。

金蒲公英被破坏后会掉落自身。

# 用途

金蒲公英可被种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。

金蒲公英也可被放置在[花盆](花盆.md)中。

与其他花不同，蜜蜂不会被金蒲公英方块吸引，也不会跟随手持金蒲公英的玩家。无法喂食成年蜜蜂金蒲公英。<ref></ref>

与其他花不同，金蒲公英不能用于堆肥。<ref></ref>

与[蒲公英](蒲公英.md)不同，兔子不会跟随手持金蒲公英的玩家，无法喂食成年兔子金蒲公英。

对这些种类的幼年生物金蒲公英，将使其<code>Age</code>值锁定（蝌蚪为0，其他生物为-24000）且不会在这个世界中自然消失；对已被阻止成长的幼年生物金蒲公英，将使其从该值开始成长。每次使用将消耗1个金蒲公英，使用后的生物具有2秒的冷却期，期间不能再对其金蒲公英。

被阻止成长的幼年生物无法被喂食除金蒲公英外的其他物品。

# = 谜之炖菜 =

使用金蒲公英合成或得到的谜之炖菜会给予玩家0.35s的[饱和](饱和.md)效果。

# = 猪灵 =
[猪灵](猪灵.md)能够被掉落的金蒲公英吸引，会主动捡起并端详6-8秒，随后放入自己的物品栏，但破坏金蒲公英不会激怒它们。
