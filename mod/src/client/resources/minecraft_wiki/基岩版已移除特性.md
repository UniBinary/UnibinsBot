# 基岩版已移除特性

*页面ID: 20918* | *来源: Minecraft Wiki*

在及其前身的开发历程中，有一些特性被移除了。这些特性可能被替代，或者开发者在晚些时候决定不制作这个特性而被移除。

注意，本页面只记录已被从游戏中移除的特性；被移除的特性在该特性对应条目的历史一段中有描述。

在Xperia PLAY上的携带版视频预览中，可以看到一朵青色玫瑰。其有着独特的青色纹理，通常被称为**青花**。<ref></ref>[Jeb](Jeb.md)称为了尝试修复一些硬件问题，它们被作为玫瑰的替代品。

# = 自定义刷怪蛋 =
[125px|right](File:Spawn Null.png.md)
在[基岩版1.16.100.56](基岩版1.16.100.56.md)前，除了创造模式物品栏内提供的[刷怪蛋](刷怪蛋.md)外，由于决定刷怪蛋生成何种实体的数据值与[实体的数字ID](基岩版数据值#实体ID.md)相同，因此可以通过编辑物品栏获得能够生成特殊实体的刷怪蛋，并且在使用后可以正常生成对应的实体（例如数据值为383:92的刷怪蛋可以生成一道[闪电](闪电.md)）。这些刷怪蛋均使用了空刷怪蛋的纹理，但能通过显示的物品名称加以区分（例如生成盔甲架的刷怪蛋名称为）。

生成某些实体的刷怪蛋会在使用后导致游戏崩溃（例如[浮漂](浮漂.md)和[画](画.md)），另一些则不会生成对应实体（例如[掉落物](掉落物.md)）。

这些自定义刷怪蛋也可以放入[刷怪笼](刷怪笼.md)中，但是刷怪笼不会正常生成对应的实体。

然而，在基岩版1.16.100.56中，由于刷怪蛋的不同实体ID被拆分为各自独立的ID，自定义刷怪蛋的能力也被一同移除，原有的自定义刷怪蛋会变成空刷怪蛋而无法再生成任何实体。

# = 铜制号角 =
[125px|right](File:Copper Horn.png.md)

铜制号角于[1.18.30.26](基岩版1.18.30.26.md)加入游戏，是山羊角的镀铜变种，会根据吹奏者不同的吹奏姿势而发出不同的音色。

在[1.19.0.24](基岩版1.19.0.24.md)中，铜制号角被移除。

# 结构
# = 下界反应器的功能 =
[125px|right](File:Nether Reactor.png.md)

在[0.12.1](携带版0.12.1.md)之前，点击下界反应器核心能激活反应堆，游戏会发送客户端消息"Active!"。在激活后，一个巨大的有35×17×17格的[下界岩](下界岩.md)的多房间结构会在反应器附近生成，非正式名称叫做"下界塔"<ref name="johan 0.5.0 vid2">https://www.twitch.tv/jbernhardsson/b/337680976</ref>。通过将[金块](金块.md)，[圆石](圆石.md)和[下界反应核](下界反应核.md)摆成图中所示的3×3×3排列来构建反应器。 第二层和第三层需要空气占位没有方块的地方。如果结构不正确，尝试激活反应器会导致客户端提示消息"不正确的组合！"。包含反应器的底层空间除了反应器本身的整个房间都会变成空气，而上层中的方块则保持完整。

物品会开始随机地生成在反应器房间，它们有[荧石粉](荧石粉.md)、[下界石英](下界石英.md)、[仙人掌](仙人掌.md)、[甘蔗](甘蔗.md)、两种[蘑菇](蘑菇.md)、[碗](碗.md)、[南瓜种子](南瓜种子.md)和[西瓜种子](西瓜种子.md)，[僵尸猪人](僵尸猪人.md)也会生成（以此法生成的僵尸猪人是敌对生物，而非中立）。在此阶段，组成反应器的方块会变成[发光的黑曜石](发光的黑曜石.md)，而且下界反应核纹理会变为红色。如果玩家开采激活的反应核，反应器的外观会被保持。

下界反应核的运行时间为45秒，之后下界反应器会被破坏，游戏时间会被设为夜晚。

此时含有下界反应核的3×3×3[黑曜石](黑曜石.md)会替代下界反应器，其采用较深的蓝黑色纹理以表明反应已经结束。如果玩家在烧毁的核心周围建造了一个新的下界反应器，那么下界塔会再次生成，尽管不会掉落任何东西。

# = 下界塔 =

[下界塔|thumb|right|150px](File:Nether Spire BE2.png.md)
下界塔是[下界反应核](下界反应核.md)被激活后生产的一种结构，在0.5.0中是由[黑曜石](黑曜石.md)组成的，在0.6.0及以后是由[下界岩](下界岩.md)组成的。

要激活[下界反应核](下界反应核.md)，需要满足以下条件：
* 所有玩家都在激活反应堆的效果范围内。
* 反应堆建在有效范围 （Y4–Y96） 内。
* 激活反应堆的玩家与结构齐平。
* 世界的游戏模式设置为生存模式。
若满足以上条件，点击核心将激活[下界反应核](下界反应核.md)，并向游戏客户端发送消息 “Active！”。在激活后，反应堆周围会立即产生一个具有多个房间的巨大结构，即下界塔。包含下界反应堆的底部房间会用空气替换除反应堆以外的所有阻挡的方块，而上层的块则保持完整。

激活反应堆后，组成反应堆的方块会逐渐被转化为[发光的黑曜石](发光的黑曜石.md)，塔内也会生成一些稀有的物品以及敌对的[僵尸猪人](僵尸猪人.md)（难度为和平时除外）。生成的物品包括[荧石粉](荧石粉.md)、[下界石英](下界石英.md)、[仙人掌](仙人掌.md)、[甘蔗](甘蔗.md)、两种[蘑菇](蘑菇.md)、[弓](弓.md)、[碗](碗.md)、[书](书.md)、[门](门.md)、[床](床.md)、[南瓜种子](南瓜种子.md)和[西瓜种子](西瓜种子.md)。

在下界反应核停止运作时，[发光的黑曜石](发光的黑曜石.md)会变成普通的黑曜石，下界塔的墙壁会出现许多洞，时间也会被迅速设定为晚上。下界塔包含了许多层。如果下界塔生成在高处且突破了高度限制（当时为128）时，上面的部分会被切去。

# 游戏内容
# = 闪烁标语 =

# = 水中疾跑 =
在[基岩版1.2.13.8](基岩版1.2.13.8.md)之前，[玩家](玩家.md)可以在[水](水.md)中疾跑；然而，由于加入了新的[游泳](游泳.md)动画，这个特性被移除了。

# = UI =
部分方块的UI曾被修改，比如[工作台](工作台.md)。工作台的UI从[基岩版1.2.0](基岩版1.2.0.md)开始修改，此前其已经被修改了数次。工作台的早期UI有文本显示能制作的物品信息并显示可以制作的物品，这和[切石机](切石机（MATTIS）.md)的UI很像，后来在0.9.0中被修改。在0.13.0中，由于工作台的UI已完善，切石机的UI被完全移除了，随后被定义为装饰性方块。同样，熔炉界面中输出物品及其信息文本变得可用。

随着旧的UI被移除，相关的文本信息显示也被移除。

# = 提高水下能见度 =
在[基岩版1.4.0](基岩版1.4.0.md)之前，佩戴附有[](水下呼吸（魔咒）.md)魔咒的[头盔](头盔.md)会提高水下能见度。魔咒级别越高，[玩家](玩家.md)的能见度也就越高。此效果也可以从[水下呼吸](水下呼吸（状态效果）.md)状态效果或结合魔咒与状态效果获得。

由于[水](水.md)的纹理被修改，且因玩家现在可以清楚地看到水下而无需效果或附魔，该功能已被移除。不过，[夜视](夜视.md)效果仍然可以提高能见度。另外仍可通过其他方法提升水下能见度，例如[基岩版1.5.0](基岩版1.5.0.md)中添加的[潮涌核心](潮涌核心.md)中的[潮涌能量](潮涌能量.md)状态效果。

# = Minecraft商店 =
Minecraft商店被加入于[0.15.0](携带版0.15.0.md)，其下载的[皮肤包](皮肤包.md)支持离线使用，且需要现金购买。所有内容都是由Minecraft创建的，且更新后会添加更多内容。

其被[携带版1.1.0](携带版1.1.0.md)中的[商城](商城.md)所取代，该商店的内容由社区创建，所需的货币称为“Minecoins”，并且皮肤包不再可以离线使用。

# = 填满物品的快捷栏 =
在[独乐不如众乐更新](独乐不如众乐更新.md)之前，创建一个[创造模式](创造模式.md)的世界后，玩家的[快捷栏](快捷栏.md)默认被填满。其中包括[橡树树苗](橡树树苗.md)、[红砖块](红砖块.md)、[橡木木板](橡木木板.md)、[云杉木板](云杉木板.md)、[圆石墙](圆石墙.md)、[泥土](泥土.md)等物品（取决于显示的快捷栏槽位数量，在6-9个之间）。

# = 耕种草方块 =
在[携带版0.12.1.b8](携带版0.12.1.b8.md)之前，用[锄](锄.md)耕种[草方块](草方块.md)有很小的概率掉落[小麦种子](小麦种子.md)、[南瓜种子](南瓜种子.md)、[西瓜种子](西瓜种子.md)或[甜菜根种子](甜菜根种子.md)。

# = 直接充能的铁轨 =
在[携带版0.13.0.b1](携带版0.13.0.b1.md)之前，[动力铁轨](动力铁轨.md)放下后会持续激活。这是因为[红石系统](红石电路#红石系统.md)在当时尚未加入游戏。

# = 旧的切石机功能 =
在[携带版0.13.0.b1](携带版0.13.0.b1.md)之前，[切石机](切石机（MATTIS）.md)与[工作台](工作台.md)有着同样的用途，但只能用于石头的合成。任何用于合成石头相关的方块的2×2或3×3配方只能在切石机或使用2×2的物品栏合成。然而，在此版本之后，任何关于石头的合成都可以在工作台上制作，因此切石机功能被去除，此后仅用于装饰目的。

# = 附魔书的魔咒直接生效 =
自[基岩版1.19.40.22](基岩版1.19.40.22.md)开始，使用带有时运的附魔书挖掘马铃薯、胡萝卜、西瓜、下界疣、向日葵、丁香、玫瑰丛、牡丹、荧石和沙砾时会增加物品的掉落概率。至[基岩版1.20.60.23](基岩版1.20.60.23.md)，使用带有时运的附魔书挖掘向日葵、丁香、玫瑰丛和牡丹时不再会增加物品的掉落概率；至[基岩版1.20.60.24](基岩版1.20.60.24.md)，使用带有时运的附魔书挖掘马铃薯、胡萝卜、西瓜、甜浆果丛、下界疣、荧石和沙砾时不再会增加物品的掉落概率。

在[基岩版1.21.100.22](基岩版1.21.100.22.md)以前，火焰附加附魔书能用于点燃蜡烛、营火和TNT。

# 实体
# = 生成鸡骑士 =
在0.14.0 build 1之前，[鸡骑士](鸡骑士.md)有机会由[僵尸](僵尸.md)和[僵尸猪人](僵尸猪人.md)群以及它们的[刷怪蛋](刷怪蛋.md)生成。那时，幼年僵尸和幼年僵尸猪人有5％的概率作为鸡骑士生成。然而，从[携带版0.14.0.b1](携带版0.14.0.b1.md)开始，鸡骑士被部分移除，并不再自然生成，但幼年僵尸、幼年僵尸村民和幼年[尸壳](尸壳.md)有15％的概率在试图攻击[玩家](玩家.md)、[村民](村民.md)、[铁傀儡](铁傀儡.md)、[雪傀儡](雪傀儡.md)时作为骑士生成，幼年[僵尸](僵尸.md)、幼年[僵尸村民](僵尸村民.md)和幼年[尸壳](尸壳.md)将检查附近可以骑行的[实体](实体.md)，如[牛](牛.md)、[僵尸村民](僵尸村民.md)、[蜘蛛](蜘蛛.md)和[马](马.md)。然而，幼年僵尸猪人没有能力骑乘附近的怪物，导致僵尸猪人鸡骑士完全不会生成。同时，[鸡](鸡.md)也不再能够在[下界](下界.md)中自然生成。

# = 有关僵尸猪人 =
在0.11.0之前，[僵尸猪人](僵尸猪人.md)的常见掉落物为[羽毛](羽毛.md)，稀有掉落物为[马铃薯](马铃薯.md)或[胡萝卜](胡萝卜.md)。不过这在0.11.0 build 1中被更改，在这次更新中，僵尸猪人的常见掉落物变为[腐肉](腐肉.md)，稀有的掉落物变为[金锭](金锭.md)。在0.12.1 build 1中，[金粒](金粒.md)也作为常见掉落物添加。在0.12.1 build 1之前，僵尸猪人是在阳光下燃烧但也对火免疫的敌对生物。在这段时间，即使僵尸猪人本身没有受到任何伤害，它们周围仍然会出现火焰粒子。在此期间，它们的皮肤还缺少帽子层，且移动速度缓慢，它们的双手也都没有举出来。在0.11.0 build 1中，它们有了[鸡骑士](鸡骑士.md)变种，但是在0.14.0 build 1中，它们的鸡骑士变种被移除，在0.12.1 build 1之前，僵尸猪人始终与玩家敌对且生成的办法只有通过激活[下界反应核](下界反应核.md)。在0.14.0 build 1中, 幼年僵尸猪人可以长大。然而，在某次更新后，幼年僵尸猪人不再长大。在0.12.0中, 僵尸猪人有很小的概率带盔甲生成，然而该设定于不久后被移除。

# = 驯服的豹猫 =
通过喂食生鳕鱼或生鲑鱼，可以使豹猫被驯服为猫。在1.8.0.8中，豹猫和猫分别变成了独立的生物，给它们任何的鱼只会繁殖它们并获得玩家的信任并将小豹猫的生长速度提高10％而不是驯服它们。

# = 萤火虫 =

[150px|右](File:Firefly.gif.md)
在最初，萤火虫被设计为在沼泽生物群系里成群生成。由于游戏里尚未加入其正常生成的能力，也不能通过命令生成，因此它只能在特定版本里使用附加包来手动生成，这是因为在编译零售版（常规版本）时移除了萤火虫的相关代码。

# 实体行为
# = 岩浆怪在受潮时受到伤害 =
[岩浆怪](岩浆怪.md)以前在潮湿的地方时会受到伤害， 因为默认行为包具有岩浆怪的行为<code>magma_cube_hurt_when_wet</code>设置为。如果在雨中和在水中暴露在阳光或月光下，岩浆怪也会受到伤害。在[1.1](携带版1.1.md)的某个测试版本中，此特性被视为一个错误并被移除。

# = 马 =
基岩版加入[马](马.md)时使用了较旧的模型，并在[基岩版1.2.0](基岩版1.2.0.md)中用新模型替换。

在[0.15.0](携带版0.15.0.md)的早期版本中，可以通过喂食食物来驯服马，但是这个特性已经被移除了，现在[玩家](玩家.md)需要骑马来驯服它。

# = 可以繁殖的海豚 =
在[1.2.20.1](基岩版1.2.20.1.md)加入[海豚](海豚.md)时，它可以通过喂养[生鳕鱼](生鳕鱼.md)或[生鲑鱼](生鲑鱼.md)来繁殖。在[1.5.0.0](基岩版1.5.0.0.md)中，用生鱼喂养海豚将使它游向最近的[水下遗迹](水下遗迹.md)或[沉船](沉船.md)，且海豚只能在海洋中自然生成，而不是通过繁殖。

# = 村民总是逃离怪物 =
[村民](村民.md)在刚加入时它们会尽量远离所有怪物，包括条件敌对型怪物，如末影人和蜘蛛。在[携带版0.12.0](携带版0.12.0.md)中，此特性被移除，因为只有僵尸及其变种以及[携带版1.1.0](携带版1.1.0.md)中添加的[灾厄村民](灾厄村民.md)与村民敌对。

# = 幼年实体拥有成年实体的声音 =
在[携带版Alpha](携带版Alpha.md)的早期版本中，所有幼年实体都使用与其成年实体相同的声音，而不是它们现在使用的高音版本。

# = 旧的火焰转移攻击 =
在[携带版Alpha](携带版Alpha.md)中，如果一个身上带火的实体攻击另一个实体，总会将其燃烧效果转移到它攻击的实体身上。对于可以发射物体的怪物，例如[雪傀儡](雪傀儡.md)，它的雪球总会被点燃。

但是后来在未知更新中，火焰转移攻击被更改为取决于区域难度。

# = 实体总会掉落它们的盔甲而不是其掉落物 =
在[携带版0.12.1](携带版0.12.1.md)中，带着盔甲生成的实体总是会在死亡时掉落其盔甲。然而，它们永远不会丢弃它们手中的物品（一个例外是[女巫](女巫.md)，它总是会掉落它死前喝的任何药水）。

从[1.2](基岩版1.2.md)开始此特性被移除，现在装备武器和/或盔甲的实体只有在被玩家杀死时才会丢弃其中一个装备物品，且只有8.5％的概率（这包括[女巫](女巫.md)掉落的药水）。

# = 所有实体都可以在熔岩中呼吸 =
以前，任何具有抗火效果的实体都可以在没有窒息的情况下浸没在熔岩之下。至未知更新时，此特性已被移除，只有一些怪物，如[烈焰人](烈焰人.md)和[恶魂](恶魂.md)能够在熔岩中呼吸。现在，玩家和大多数其他怪物需要水下呼吸或潮涌能量状态效果才能在熔岩里呼吸。

# = 守卫者攻击鱼 =
在[1.2.14.2](基岩版1.2.14.2.md)中，守卫者对[鳕鱼](鳕鱼.md)、[鲑鱼](鲑鱼.md)、[河豚](河豚.md)和[热带鱼](热带鱼.md)抱有敌意。但是，在[1.6.0.5](基岩版1.6.0.5.md)中，由于持低端设备的玩家在[海底神殿](海底神殿.md)附近时可能存在的性能问题，此特性被移除。

# = 僵尸村民不显示职业 =
在[基岩版1.20.20.20](基岩版1.20.20.20.md)以前，僵尸村民在外观上不显示职业。

# = 部分敌对生物在和平难度下不消失 =
在[基岩版1.20.50.20](基岩版1.20.50.20.md)以前，[卫道士](卫道士.md)和[唤魔者](唤魔者.md)在和平难度下不会消失。

在[基岩版1.21.90.20](基岩版1.21.90.20.md)以前及[1.21.90.25](基岩版1.21.90.25.md)至[1.21.100.20](基岩版1.21.100.20.md)之间，[猪灵蛮兵](猪灵蛮兵.md)在和平难度下不会消失。

# = 末影人可以瞬移出船和矿车 =
在[基岩版1.21.60.27](基岩版1.21.60.27.md)以前，末影人可以瞬移出船和矿车。由于[Java版](Java版.md)中末影人并不能瞬移出船和矿车，在此版本中，此特性被视为一个错误而被移除。

# 粒子
出于测试目的，一些不会在世界中自然生成的粒子被加入到一些版本中。<ref></ref>然而它们已经在更新的版本中被移除了。

# 食物
# = 食物直接回复生命 =
在0.12.1 build 1前，食物可以直接为玩家回复生命值。然而，此特性在[饥饿值](饥饿值.md)加入后被移除了。

# = 河豚 =
在0.12.1 build 1前，吃[河豚](河豚（物品）.md)不会获得饥饿状态效果。

# 世界生成
# = 生物群系 =
; 0.9.0前的生物群系

在0.9.0前存在许多生物群系，它们大部分在后来被移除。0.9.0前的生物群系和Java版中从[万圣节更新](万圣节更新.md)到[冒险更新](冒险更新.md)的生物群系以及在[TU5](Xbox 360版TU5.md)之前的[原主机版](原主机版.md)生物群系完全相同。

0.9.0中移除的生物群系：
* [雨林](雨林.md)
* [季节性森林](季节性森林.md)
* [灌木丛地](灌木丛地.md)
* 沼泽地（旧版本）
* 热带草原（旧版本）
* [冻原](冻原.md)（旧版本，与现在的[雪原](雪原.md)不同）
* 沙滩（沙子和沙砾，在[冒险更新](冒险更新.md)之前的旧版本）

; 不积雪的山地
在基岩版1.2前，[山地](山地.md)及其变种在Y=90以上不产生[雪](雪.md)。

; 海平面完全结冰的冻洋及其变种
在[基岩版1.21.100.20](基岩版1.21.100.20.md)前，[冻洋](冻洋.md)及[冰冻深海](冰冻深海.md)的海平面是完全结冰的。

# = 村庄 =
; 沙砾路
在[0.11.0 build 1](携带版0.11.0.b1.md)之前，村庄使用沙砾作为道路，之后使用[土径](土径.md)作为道路。

; 平原村庄在热带草原生成
在[0.15.0 build 1](携带版0.15.0.b1.md)前，生成在热带草原的村庄会使用橡木、橡木木板、橡木栅栏和橡木楼梯生成。但在此之后，这些生成物会被金合欢木变种取代。

# = 树 =
; 冷橡树
冷橡树是[携带版](携带版.md)在0.9.0前因漏洞而生成的极其稀有的树。这个漏洞导致橡树会在森林和积雪生物群系的边缘生成时带上云杉树叶和云杉原木，或者是常规的橡木。

; 旧的橡树
在冷橡树存在的同时，还存在着一种树冠层中只有2个原木的树，而不是常规的3个原木。

# = 损坏的要塞生成 =
在[0.15.0 build 1](携带版0.15.0.b1.md)中，[要塞](要塞.md)只生成1个部分，即螺旋楼梯。其他的部分不会生成，包括[末地传送门](末地传送门.md)房间。这会导致要塞没有战利品可以获得。有两种情况：

* 村庄里的要塞
* * 如果要塞本应该生成在村庄水井下方，要塞会取代村庄水井而生成，而不是生成在水井下方。如果螺旋楼梯的底部被凿穿，下面的水井就会暴露。
* 不在村庄里的要塞
* * 如果要塞本应该生成在除村庄水井下方以外的任何位置，它会生成在很深的地方，大概是在基岩层且会用石砖替代部分基岩。这会导致在生存模式中玩家可以不使用作弊掉进虚空。这种要塞存在的版本较短，只有0.15.0 build 1到0.15.10之间的版本有。最终在[0.16.0 build 1](携带版0.16.0.b1.md)这种生成方式被认为是漏洞而移除。

# = 废弃矿井 =
; 蜘蛛刷怪笼
在废弃矿井在[0.9.0 build 1](携带版0.9.0.b1.md)中加入时，里面的刷怪笼是蜘蛛刷怪笼，而不是现在版本的洞穴蜘蛛，这是因为当时洞穴蜘蛛尚未加入到基岩版中。

# = 边境之地 =

[thumb|X=+12,550,821处的边境之地](File:FarLandsEdge PocketEdition.jpg.md)

[thumb|X与Z坐标+12,550,821处的边境之角，形成天空网格](File:Cornerfarlands pe.png.md)

[thumb|X=-12,550,821处的边境之地，形成无尽的海洋](File:Negative Far Lands2.jpg.md)

边境之地指的是出现在“无限”地图的“边缘”地带的一种奇怪地形。它从X/Z:12,550,821处开始生成。其也有三个变种：边境之墙、天空网格、虚无。

边境之墙与天空网格处均会产生极为怪异的地形。边境之墙高至Y=127，墙面有许多长而大的孔洞，垂直于边缘，一直生成到世界底部。随着坐标增大，其逐渐变得零散，在X或Z为+12,758,545处完全变为虚无。天空网格处的方块会形成网格图案，从Y=127延伸至世界底部。在边境之地被移除前的晚些版本中，天空网格仅在下界与末地生成，而主世界的对应区域变为虚无。

在虚无处，地形完全停止生成，仅剩海洋与基岩层。结构可以在此处生成，且会产生许多有趣的特性。寒带群系中的海洋表面会被冰冻。

自[基岩版1.17.20.20](基岩版1.17.20.20.md)起，边境之地的生成坐标被推到32位整数极限之外，使得这些特性在原版游戏中被移除了。

# 音效
在基岩版中，许多音效被移除了，例如旧的脚步声、破坏方块声、玻璃破碎声、金属块响声、牛叫声、僵尸村民叫声、尸壳叫声、流浪者叫声、爆炸声、水声和流体声，等等。

# 其他
# = 意外加入的教育版特性 =
[黑板](黑板.md)和[相片簿](相片簿.md)原本都是仅存于教育版的特性，被意外加入到[携带版0.16.0.b1](携带版0.16.0.b1.md)。不久它们被移除，因为其本来只是一个教育版所独有的特性。<ref>http://pocketbeta.minecraft.net/2016/08/notes-for-016-beta-build-1-aka-015901.html</ref>

# = 哭泣的黑曜石的旧纹理 =

[right|alt=|旧哭泣的黑曜石纹理](File:Crying Obsidian (texture) JE0 BE0.png.md)
哭泣的黑曜石的旧纹理在[携带版0.1.0](携带版0.1.0.md)中添加于[terrain.png](terrain.png.md)中，为了与[Java版Beta 1.3](Java版Beta 1.3.md)相匹配。它在[v0.2.0](携带版0.2.0.md)中被移除了，由于terrain.png后来已经被修改为与[Java版1.1](Java版1.1.md)相匹配。

哭泣的黑曜石最终在[基岩版1.16.0](基岩版1.16.0.md)加入游戏，不过其纹理发生改变。在Java版[20w10a](20w10a.md)中，这个旧纹理被重新添加到Programmer Art纹理包中。

# = 命令 =
[携带版v0.16.0 alpha](携带版0.16.0.md)中，该命令可以生成[火球](火球.md)、[小火球](小火球.md)、[凋灵之首](凋灵之首.md)及其变种。这些特性在1.0版本中被移除。
