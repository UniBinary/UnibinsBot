# 基岩版1.20.0.20

*页面ID: 103795* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.0.20**（ChromeOS/Android）、**Preview 1.20.0.20**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.0](基岩版1.20.0.md)的首个测试版，发布于2023年4月12日<ref></ref><ref></ref>，加入了[瓶子草](瓶子草.md)和[嗅探兽蛋](嗅探兽蛋.md)相关特性，将[嗅探兽](嗅探兽.md)相关特性从[实验性玩法](实验性玩法.md)中移出，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[瓶子草植株](瓶子草植株.md)**
* 可用瓶子草荚果在[耕地](耕地.md)上种出。
* 共有5个生长阶段。
* * 若完全成熟，破坏时掉落瓶子草；若未完全成熟，破坏时掉落瓶子草荚果。

* *[瓶子草](瓶子草.md)**
* 一种新的大型花。
* 可用于合成[青色染料](青色染料.md)。

* *[嗅探兽蛋](嗅探兽蛋.md)**
* 两只[嗅探兽](嗅探兽.md)繁殖后会产下嗅探兽蛋。
* 放置于[苔藓块](苔藓块.md)上时会在大约10分钟后孵化。放置于其余方块上时的孵化时长约为20分钟。

# = 物品 =
* *[瓶子草荚果](瓶子草荚果.md)**
* 一种新的种子，可以种植在[耕地](耕地.md)上。
* 可通过[嗅探兽](嗅探兽.md)挖掘获得。
* 可用于喂食[鸡](鸡.md)和[鹦鹉](鹦鹉.md)。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了“Enter the Render Dragon!”，用以庆祝[RenderDragon](RenderDragon.md)在全平台上可用。
