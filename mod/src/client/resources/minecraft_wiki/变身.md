# 变身

*页面ID: 147810* | *来源: Minecraft Wiki*

* *变身（Transform）**是一系列改变[实体](实体.md)形态、尺寸的机制。

# 变身
* *变身**，即改变实体形态。

玩家变身后将继承实体的部分行为和属性。

# = 实体之瓶 =
玩家可通过饮用某种非玩家实体的[实体之瓶](实体之瓶.md)变身为对应实体。

投掷喷溅型实体之瓶可将其作用范围内的生物变身为对应的非玩家实体。

# = 投票规则 =
启用规则后，会将所有[玩家](玩家.md)变身。

# = 命令 =
命令可将实体变身，亦可切换玩家的[皮肤](皮肤.md)。

# 变形
* *变形**，即改变实体尺寸。

实体变形后，其掉落物数量会受到影响。（掉落物不受[战利品表](战利品表.md)控制的除外，如[凋灵](凋灵.md)总会掉落一个[下界之星](下界之星.md)。<ref></ref>）

# = 状态效果 =
拥有[变大](变大.md)效果的生物会变形至原来的<math>\text{等级}+1</math>倍。

拥有[变小](变小.md)效果的生物会变形至原来的<math>\frac1{\text{等级}\times2}</math>。

# = 投票规则 =
启用规则后，会将所有[玩家](玩家.md)变形。

# = 命令 =
命令可将实体变形。

# 脱离
* *脱离**，即从变身实体中脱离。

已变身的实体（[盔甲架](盔甲架.md)除外）在其生命值被清零后不会死亡，而是会脱离并回满生命值。

# 还原
* *还原**，即恢复实体形态或尺寸。

# = 虚空之瓶 =
已变身的玩家[虚空之瓶](虚空之瓶.md)后，当不满足以下所有条件时，其形态会被还原：
* 拥有[状态效果](状态效果.md)；
* 此前变身实体为非生物实体；
* 因该虚空伤害脱离。

# = 命令 =
命令可将实体还原。
