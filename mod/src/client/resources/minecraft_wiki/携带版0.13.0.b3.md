# 携带版0.13.0.b3

*页面ID: 18906* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.13.0 alpha build 3**是[v0.13.0 alpha](携带版0.13.0.md)的第3个测试版，发布于2015年11月6日<ref>http://pocketbeta.minecraft.net/2015/11/0130-build-3.html?m=0</ref>，修复了一些漏洞。

# 更改
* 现在[船](船.md)可以在物品栏中堆叠。
* 现在[甜菜汤](甜菜汤.md)不可以在物品栏中堆叠。
* 优化了铁轨拐弯与红石的行为。
* 优化了[史莱姆](史莱姆.md)的生成。
* 红石刻频率更高了。
* 村民现在会正常跟随或停留。

# 修复
* *修复了11个漏洞**
* 覆盖“异或门”时游戏崩溃。
* 蘑菇煲会给予玩家中毒效果。
* 烧炼的进度条显示不正确。
* 黏土会覆盖沙砾生成。
* 砂岩台阶的纹理显示错误。
* 玩家切换为创造模式后，敌对生物仍对玩家保持敌对状态。
* 聊天信息内的颜色显示错误。
* 特定情况下的村民、铁傀儡、豹猫和狼渲染错误。
* 音符盒不能被红石激活。
* 瀑布后面的船渲染错误。
* 水在渲染时部分面的纹理丢失。</onlyinclude>
