# Java版25w08a

*页面ID: 144998* | *来源: Minecraft Wiki*

<onlyinclude>

* *25w08a**是[Java版1.21.5](Java版1.21.5.md)的第7个快照，发布于2025年2月19日<ref></ref>，加入了狼的新音效，更改了所有[刷怪蛋](刷怪蛋.md)的纹理，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[狼](狼.md)**
* 加入了6种音效变种，每种都有独特的空闲、受伤、死亡、嚎叫、呜咽和喘息音效。
* * 新的6种变种包括大型犬（big）、可爱（cute）、小巴哥犬（puglin）、愤怒（angry）、不爽（grumpy）和悲伤（sad），而原来的音效现在称为普通（classic）变种。
* * 每只狼都会从上述7种音效变种中随机选取一种使用，而与其纹理变种无关。

# = 常规 =
* *[数据包](数据包.md)**
* 加入了子文件夹，以定义狼的音效变种。

* *[注册表](注册表.md)**
* 加入了<code>WOLF_SOUND_VARIANT</code>可写注册表。

* *[生物群系数据格式](生物群系数据格式.md)**
* 在生物群系的环境效果中加入了新字段，以定义为枯叶堆着色时所使用的颜色。

* *[狼音效变种定义格式](狼音效变种定义格式.md)**
* 可以通过添加{{filepath|-{}-data/<*命名空间*>/wolf_sound_variant/<*id*>.json}}以配置狼的音效变种。
* 格式：
<div class="treeview">
  *  父标签
  ** ：狼空闲音效的命名空间ID，或直接定义一个[声音事件](Java版声音事件.md)。
  ** ：狼死亡音效的命名空间ID，或直接定义一个声音事件。
  ** ：狼嚎叫音效的命名空间ID，或直接定义一个声音事件。
  ** ：狼受伤音效的命名空间ID，或直接定义一个声音事件。
  ** ：狼喘息音效的命名空间ID，或直接定义一个声音事件。
  ** ：狼呜咽音效的命名空间ID，或直接定义一个声音事件。
</div>

* *[物品堆叠组件](物品堆叠组件.md)**
* 加入了<code>wolf/sound_variant</code>物品堆叠组件。

* *[颜色图](纹理#颜色图.md)**
* 加入了，用于枯叶堆类可着色方块的着色。

* *[资源包](资源包.md)**
* 为绵羊羊毛加入了底层纹理，以在游戏中动态着色。

# 更改
# = 方块 =
* *[枯叶堆](枯叶堆.md)**
* 现在会随所处的生物群系着色。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 更新了纹理。
* * 现在刷怪蛋的大小与所生成生物的大小相匹配。
* * 现在刷怪蛋的外观会凸显出所生成生物的外观。

# = 生物 =
* *[绵羊](绵羊.md)**
* 蓝色、淡蓝色、青色、黄色、橙色和红色绵羊不再自然生成。
* 现在热带生物群系中的少见毛色仅包括灰色、淡灰色、白色和黑色。
* 现在寒带生物群系中的少见毛色仅包括灰色、淡灰色、白色和棕色。
* 现在绵羊身上的毛斑块会保留剪毛前染的颜色，以匹配。
* 现在可以食用[蕨](蕨.md)，以匹配。

* *[流浪商人](流浪商人.md)**
* 将用[水瓶](水瓶.md)、[水桶](水桶.md)、[奶桶](奶桶.md)、[发酵蛛眼](发酵蛛眼.md)、[烤马铃薯](烤马铃薯.md)和[干草捆](干草捆.md)与其交易以换取[绿宝石](绿宝石.md)的最大[交易](交易.md)次数由1提升至2。

# = 游戏内容 =
* *[创造模式物品栏](创造模式物品栏.md)**
* 刷怪蛋一栏的图标现在由[猪刷怪蛋](猪刷怪蛋.md)改为[苦力怕刷怪蛋](苦力怕刷怪蛋.md)。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[物品堆叠组件](物品堆叠组件.md)**
* <code>blocks_attacks</code>组件抵挡没有位置来源的伤害时，现在会假定用于比较的角度为的字段的最大值180。

* *[资源包](资源包.md)**
* 将资源包版本号更改为。
* 现在被重命名为。
* 移除了和。
* 狼原来的音效文件现在移入文件夹。
* 移除了狼未使用的音效。

* *[装备模型](装备模型.md)**
* 配置了的装备模型层的显示不再要求物品处于<code>#dyeable</code>物品标签中。

* *[截图](截图.md)**
* 移除了未使用的巨型屏幕截图功能。

* *[标签](Java版标签.md)**
* 向方块标签中加入了。
* 向伤害类型标签中加入了。
