# 基岩版1.16.230.50

*页面ID: 80809* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.230.50**是[基岩版1.17.0](基岩版1.17.0.md)的首个测试版<ref></ref>，发布于2021年3月25日<ref></ref>，加入了[发光地衣](发光地衣.md)，并修复了一些漏洞。

以下更新内容基于上一测试版[1.16.220.52](基岩版1.16.220.52.md)，包含了其中已加入的[洞穴与山崖](洞穴与山崖.md)特性。

# 新内容
# = 方块 =
* *[发光地衣](发光地衣.md)**
* 一种新的洞穴光源。
* 属于可[含水](含水.md)方块。
* 使用[剪刀](剪刀.md)采集获取。
* 对其使用[骨粉](骨粉.md)可使之蔓延到其他方块表面。
* 可用于堆肥。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# 更改
# = 方块 =
* *[垂根](垂根.md)**
* 现在可用于堆肥。

* *[缠根泥土](缠根泥土.md)**
* 现在可以对其使用锹来转变为[土径](土径.md)。

# = 生物 =

# 修复
* *Android平台**
* 为支持鼠标和键盘的Android设备（8.0 Oreo及更新的版本）加入了使用支持。
* 部分Android设备不再会无法执行多语言输入功能。
* 部分Android设备的十字准星不再会偏移。
* 部分Android设备现在能够正常退出游戏。
* 修复了部分Android设备上的分辨率问题。
* 修复了部分Android设备上的网络问题。
* 在部分Android设备中，玩家进入水中不再会导致黑屏。

* *常规**
* 细雪被爆炸破坏后不再会掉落物品。（）
* 修复了部分燃料的燃烧时间不正确的问题。（）
* 现在第一人称视角的进食动画会正确位于帧的中央了。（）
* 现在第一人称视角的放置方块动画会正确显示了。（）
* 现在第一人称视角的主副手格挡动画是对称的了。（）
* 现在织布机GUI中旗帜的图案具有与原版不同的分辨率时也能正确显示了。
* 现在用切石机制作锈蚀的切制铜台阶（及涂蜡变种）时会正确获得2个而不是1个。（）
* 拴绳现在会与山羊的模型正确连接。（）

* *繁茂洞穴植物**
* 现在使用剪刀采集杜鹃树叶和盛开的杜鹃树叶会正确掉落物品。
* 发射器现在可以对苔藓块使用骨粉。
* 垂根现在可以正确堆叠了。
* 现在使用剪刀采集小型垂滴叶会正确掉落物品。
* 现在对着大型垂滴叶的顶部放置另一大型垂滴叶会提升其高度。
* 现在对缠根泥土使用锹会将其转变为草径。
* 蜜蜂现在会把盛开的杜鹃花丛和盛开的杜鹃树叶视为花。
* 现在对洞穴藤蔓按下方块选取键或使用带有精准采集魔咒的工具破坏洞穴藤蔓会获得发光浆果。

* *用户界面**
* 修复了生成世界时取消加入会导致用户卡死在加载界面的问题。（）

* *技术性**
* 移除了ActorDataIDs中一些错误添加的杖举项。
* 如果关键帧的时间和值相匹配，Catmull-Rom动画不再会出现故障。
* 现在使用命令执行的函数应从执行原点执行，而不是从服务端执行。
* 将语言更改为。专用服务端命令由更改为。将文件更改为文件。JSON格式则仍然不变。
* 修复了，以便使由数据驱动的生物在UI中渲染时可用（例如在物品窗口中，在生物渲染于UI时会返回到true）。 </onlyinclude>
