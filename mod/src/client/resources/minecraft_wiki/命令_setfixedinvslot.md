# 命令/setfixedinvslot

*页面ID: 39926* | *来源: Minecraft Wiki*

用特定物品设置固定物品栏。

# 语法
   <code>-{}-setfixedinvslot <*固定物品栏编号：整数*> <*物品名称：字符串*> [*数据值：整数*]</code>

# 参数
<code>-{}-*固定物品栏编号：整数*</code>
   指定固定物品栏的编号。

<code>-{}-*物品名称：字符串*</code>
   指定物品栏中要放入的物品。必须是有效[物品ID](物品ID.md)（如<code>iron_shovel</code>），或有物品形式的[方块ID](方块ID.md)。

<code>-{}-*数据值：整数*</code>（可选）
   指定物品的数据值。必须是-2,147,483,648和2,147,483,647间的整数（含，无需分隔符），但是对于指定物品无效的会被设为0。若未指定，默认为0。
