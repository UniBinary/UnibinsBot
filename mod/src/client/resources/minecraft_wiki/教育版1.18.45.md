# 教育版1.18.45

*页面ID: 101167* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.18.45**是的一次次要更新，发布于2023年1月17日<ref></ref>，更改了游戏名称和徽标，并修复了一些漏洞。

# 更改
# = 常规 =
* *[徽标](徽标.md)**
* 更新了徽标。

* *应用程序**
* 应用名称由“Minecraft: Education Edition”更改为“Minecraft Education”。
* 更新了应用图标。

# 修复
* 修复了Chromebook上的屏幕挂起/进入Mojang加载屏幕时游戏崩溃的问题。
