# 冲击

*页面ID: 42230* | *来源: Minecraft Wiki*

* *冲击（Punch）**是一种用于[弓](弓.md)的[魔咒](魔咒.md)，能增加[箭](箭.md)的击退距离。

# 获取

# 用途
魔咒每提高一级，水平方向的[击退距离](伤害#击退.md)就会增加3格，而垂直方向的击退距离无论魔咒等级如何都由0.825格增加到1.25格。

冲击会对[创造模式](创造模式.md)下的玩家产生[击退](伤害#击退.md)效果。<ref></ref>
