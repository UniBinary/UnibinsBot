# 基岩版1.19.81

*页面ID: 104067* | *来源: Minecraft Wiki*

* *1.19.81**是的一次热修复更新，发布于2023年4月27日至28日<ref></ref>，修复了一些漏洞。此版本与[1.19.80](基岩版1.19.80.md)相兼容。

# 修复
* 修复了在Realms上使用和其他命令时可能发生的崩溃。
* 修复了精选服务器上的购买按钮会无限加载的问题。
* 修复了精选服务器列表不会显示“显示更多”按钮的问题。
