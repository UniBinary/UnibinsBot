# 犰甲狼兵

*页面ID: 119854* | *来源: Minecraft Wiki*

[thumb|犰甲狼兵的主视觉图](File:Armored Paws Key Art.png.md)
[alt=|thumb|犰甲狼兵的[[Java版](File:1.20.5.png.md)发行说明配图]]
[alt=|thumb|犰甲狼兵的[[基岩版](File:Bedrock 1.20.80 PatchNotes.png.md)发行说明配图]]
* *犰甲狼兵（Armored Paws）**是一次[小更新](小更新.md)，发布于2024年4月23日<ref></ref>。其主要内容是加入[Minecraft Live 2023生物投票](Minecraft Live 2023#生物投票.md)中胜出的[犰狳](犰狳.md)和[狼铠](狼铠.md)，以及[狼](狼.md)的8个新变种。犰狳自然生成于[恶地](恶地.md)、[热带草原](热带草原.md)及其变种生物群系，使用[刷子](刷子.md)刷扫犰狳可以获得[犰狳鳞甲](犰狳鳞甲.md)来合成[狼铠](狼铠.md)。随着狼的新变种的加入，狼现在还会在[热带草原](热带草原.md)、[稀疏丛林](稀疏丛林.md)及[疏林恶地](疏林恶地.md)生成。
