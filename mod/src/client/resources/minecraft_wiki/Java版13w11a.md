# Java版13w11a

*页面ID: 33503* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w11a**是[Java版1.5.1](Java版1.5.1.md)的首个快照，发布于2013年3月14日<ref></ref>，加入了附魔书合并机制，并修复了一些漏洞。

# 更改
# = 物品 =
* *[附魔书](附魔书.md)**
* 可以被合并以提升[附魔](附魔.md)等级，或者在同一本上合并多个魔咒。
* * 当合并提高等级时，两本书的等级必须相同。
* * 仍然需要遵守常规附魔等级限制。

# = 常规 =
* *[Minecraft Realms](Minecraft Realms.md)**
* 进行了优化和改进。

# 修复
为，末影龙仍然能够破坏方块。
|4577|无法通过合并附魔书来获得更高等级的魔咒。
|6705|如果玩家使用第三方工具（如MCEdit）获取拥有多个魔咒的附魔书，然后将该附魔书应用在任意工具上，则只有其魔咒列表中的第一个魔咒会生效。
|;1.5的漏洞
|6391|漏斗上的火不可见。
|8193|如果容器物品栏的第一槽位中无法放置物品，则漏斗会停止向其他槽位输送物品。
|8943|为8的雪上和漏斗上的火不可见。
|11089|若记分板记分项的标题过长，则会显示在游戏屏幕外。
|11109|使用固体方块将容器和红石比较器分隔开会导致红石比较器的方块状态无法更新。
|11217|下坠的方块会从比原位高一格的位置开始下坠。
|11236|画无法被放置。
