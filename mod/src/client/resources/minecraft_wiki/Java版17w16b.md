# Java版17w16b

*页面ID: 29334* | *来源: Minecraft Wiki*

<onlyinclude>

* *17w16b**是[Java版1.12](Java版1.12.md)的第7个快照，发布于2017年4月21日<ref></ref>，加入了新的进度触发器以及1条新的游戏规则，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[进度](进度.md)**
* 新的触发器：<code>minecraft:item_durability_changed</code>。
* * 当玩家物品栏里一个物品受损时触发，例如一把剑攻击生物后耐久值下降。
* * 三个条件能够用于这个触发器：
* ** <code>item</code>: 检查此物品耐久下降前的信息。
* ** <code>durability</code>: 检查此物品耐久下降后的耐久值。
* ** <code>delta</code>: 检查下降了多少耐久值。
