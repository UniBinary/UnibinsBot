# 烤马铃薯

*页面ID: 8821* | *来源: Minecraft Wiki*

* *烤马铃薯（Baked Potato）**是一种能被[玩家](玩家.md)食用的[食物](食物.md)类[物品](物品.md)。

# 获取
# = 烹饪 =
在[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或是[营火](营火.md)中烹饪[马铃薯](马铃薯.md)可以获得烤马铃薯。

# = 生物掉落物 =

# = 箱子战利品 =

# 用途
# = 食物 =

手持烤马铃薯按住键即可食用，每个烤马铃薯可以回复。

# = 合成材料 =

# = 堆肥 =
将烤马铃薯放入[堆肥桶](堆肥桶.md)中有85%的概率使堆肥层数增加1。
