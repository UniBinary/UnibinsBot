# Minecraft Experience: Villager Rescue

[thumb|主视觉图](File:Minecraft Experience Key Art.jpg.md)

* *Minecraft Experience: Villager Rescue**（中国大陆称为**“我的世界·实境探险：拯救村民大行动”**）是一场Minecraft主题的线下沉浸式互动活动。

该活动目前已在或计划在美国达拉斯、英国伦敦、加拿大多伦多、沙特阿拉伯利雅得、墨西哥墨西哥城与丹麦海宁举办。未来计划在美洲、欧洲、亚太地区与中国大陆地区举办。<ref name="minecraftexperience.com">https://www.minecraftexperience.com</ref><ref>https://www.minecraftexperience.com/faq/</ref>

# 活动详情
# = 活动流程 =
活动为线下沉浸式互动冒险玩法，时长为一小时，25名玩家为一组。玩家需要在多个Minecraft[生物群系](生物群系.md)和维度中探索，挖掘矿物，收集各种材料，与[骷髅](骷髅.md)和[苦力怕](苦力怕.md)等生物战斗，完成指定任务，最终拯救[村民](村民.md)。

玩家必须利用在7个房间中收集到的材料尽可能多的治愈村民。游戏场景由投影墙和地板构成，玩家可以通过互动之球和动作感应器与场景内容进行互动。

# = 互动之球 =
互动之球（orb of interaction）是玩家在游戏开始时会获得的一个游戏道具，玩家可以使用互动之球与场景和玩法互动，它会根据玩家的操作振动、发光或改变颜色。

# = 披风 =
[thumb|披风宣传图](File:Minecraft Experience Cape Promotional Image.jpg.md)
完成活动流程的玩家会在电子邮件中收到[Minecraft Experience披风](Minecraft Experience披风.md)的兑换码。

# 活动场次
# = 美国达拉斯 =
首场活动于2024年10月18日至2025年1月20日在美国达拉斯举办。<ref></ref>

工作日门票价格为32美元，周末与节假日门票价格为42美元，VIP门票价格为65美元。另有亲友与组团折扣可用。

# = 英国伦敦 =
第二场活动于2025年4月4日至2026年2月1日在英国伦敦举办。<ref></ref><ref></ref>

3至15岁儿童门票价格为20英镑，16岁及以上成人门票价格为24英镑。另有“黑曜石套餐”门票价格为54英镑。2岁及以下儿童可免费入场，15岁及以下儿童须由成人陪同。

# = 加拿大多伦多 =
第三场活动于2025年6月20日至9月14日在加拿大多伦多举办。<ref></ref><ref></ref>

周一至周四门票价格为32加元，周五门票价格为40加元，周末及节假日门票价格为45加元。2岁及以下儿童可免费入场，15岁及以下儿童须由成人陪同。

# = 沙特阿拉伯利雅得 =
第四场活动于2025年11月1日至2026年2月12日在沙特阿拉伯利雅得举办。<ref>https://webook.com/en/experiences/minecraft-blvd-city-rs25-tickets/</ref>

门票价格为50沙特里亚尔，快速通道门票价格为100沙特里亚尔。仅限8岁及以上儿童及成人入场。

# = 丹麦海宁 =
第五场活动于2026年4月1日至8月23日在丹麦海宁举办。<ref name="Herning"></ref>

3至15岁儿童门票价格为225丹麦克朗，16岁及以上成人门票价格为245丹麦克朗。另有“黑曜石套餐”门票，价格为435丹麦克朗。2岁及以下儿童可免费入场，15岁及以下儿童须由成人陪同。 <ref></ref>

# = 墨西哥墨西哥城 =
第六场活动于2026年3月27日至6月14日墨西哥墨西哥城举办。<ref></ref>

门票价格为549墨西哥比索。<ref>https://tickets.oneboxtds.com/funticket/events/50070?sessionView=CALENDAR</ref>
