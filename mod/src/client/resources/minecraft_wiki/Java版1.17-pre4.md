* *1.17-pre4**是[Java版1.17](Java版1.17.md)的第4个预发布版，发布于2021年6月2日<ref></ref>，修复了以制作人员名单相关问题为主的一些漏洞。

# 更改
# = 方块 =
* *[插上蜡烛的蛋糕](插上蜡烛的蛋糕.md)**
* 插上未染色的蜡烛的蛋糕的英文名称由“Candle Cake”改为“Cake with Candle”。

# = 常规 =
* *制作人员名单**
* 现在在按住空格键的同时若按住键会让滚动速度变得更快。
* * 若同时按住两个键，滚动速度会达到最高。
