* *苍白橡树（Pale Oak）**是一种生成于[苍白之园](苍白之园.md)的植被[地物](地物.md)，分为**普通苍白橡树**、**新生苍白橡树**和**嘎枝苍白橡树**。

# 种类
# = 普通苍白橡树=
普通苍白橡树整体外形与[深色橡树](深色橡树.md)相似，其树叶和树干还有概率附有[苍白垂须](苍白垂须.md)。

# = 新生苍白橡树 =
新生苍白橡树与普通苍白橡树相比，其树叶和树干不会附有[苍白垂须](苍白垂须.md)。

# = 嘎枝苍白橡树 =
嘎枝苍白橡树与普通苍白橡树相比，其树干中会尝试生成一个[嘎枝之心](嘎枝之心.md)方块。由于需要生成位置6个方向被标签为的原木包围，所以嘎枝之心有较大概率生成失败。<ref name="MC-277207"></ref>

# 生成
苍白橡树生成时会将下方1格的方块转变为[泥土](泥土.md)。

普通苍白橡树和嘎枝苍白橡树生成时，每个悬空的树叶和树干方块分别有15%和40%的概率在下方生成[苍白垂须](苍白垂须.md)，每个苍白垂须各有50%概率向下多蔓延一格；还有80%的概率将根部附近水平格、竖直5格内的具有标签的表层方块替换为可能覆有[苍白覆地苔藓](苍白覆地苔藓.md)、[矮草丛](矮草丛.md)或[高草丛](高草丛.md)的[苍白苔藓块](苍白苔藓块.md)。

# = 自然生成 =
在[苍白之园](苍白之园.md)生成树木地物时，普通苍白橡树有90%的概率生成，嘎枝苍白橡树有10%的概率生成。

# = 人为生成 =
[亮度](亮度.md)等级至少为9且有一定的空间时，2×2摆放的[苍白橡树树苗](苍白橡树树苗.md)可长成新生苍白橡树。其他两种苍白橡树无法由树苗长成。<ref></ref>
