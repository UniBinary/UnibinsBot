# Java版1.7.6

*页面ID: 31613* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.7.6**是的一次次要更新，发布于2014年4月9日<ref></ref>，修复了一些漏洞，完善了玩家[皮肤](皮肤.md)系统并支持改名。此版本不兼容1.7.2到1.7.5的服务端。

此版本仅发布了1周就被[1.7.7](Java版1.7.7.md)取代以修复一个重大漏洞，在下周内又发布了[1.7.8](Java版1.7.8.md)与[1.7.9](Java版1.7.9.md)，并最终稳定下来。

# 更改
# = 常规 =
* *[服务器](服务器.md)<!-- 这段内容在ops.json和usercache.json页面写好之后需要添加链接 -->**
* 将[封禁列表](封禁列表存储格式.md)和[白名单](白名单存储格式.md)改用JSON文件格式存储，并更改了存储格式。
* 将改用JSON文件格式存储，并更改了存储格式。
* 在根目录下加入了。

* *[皮肤](皮肤.md)**
* 皮肤与[披风](披风.md)现在通过服务器来分配。
* * 皮肤服务器宕机将会减少，影响也更小。<ref></ref><ref></ref>
* * 皮肤更改不再需要客户端重启，最麻烦的时候也只需要重新加入游戏就可以更新所有皮肤。
* * 服务器可以更改皮肤与披风——只有签名的URL存放在服务器。
* * 重复的皮肤不需要重复下载。
* * 服务器带宽消耗基本不变。

* *用户名**
* 支持用户名修改。
* * 仅是支持，实际上要等到[Java版1.8](Java版1.8.md)正式版才能改名。<ref>https://mojang.com/2014/03/minecraft-snapshot-14w10a/</ref>

* *[选项](选项.md)**
* 服务器[资源包](资源包.md)选项现在会在服务器间分隔，有三个选项：询问、启用、禁用。
* 视场的最小设定从70改为30。

* *[Realms](Realms.md)**
* 改进了配置界面。
* * 可以在配置界面将玩家改为管理员。<ref></ref>
* * 使邀请、回绝玩家更方便。
* * 加入关闭/激活Realms的按钮。
