# 雕刻南瓜

*页面ID: 81953* | *来源: Minecraft Wiki*

* *雕刻南瓜（Carved Pumpkin）**是对[南瓜](南瓜.md)方块[剪刀](剪刀.md)得到的方块。

# 生成
# = 自然生成 =
雕刻南瓜可以自然生成在[林地府邸](林地府邸.md)的“[铁轨与梯子房间](林地府邸/结构/装饰品房间.md)”和[掠夺者前哨站](掠夺者前哨站.md)的稻草人标靶中。

# = 雕刻 =
对一个[南瓜](南瓜.md)[剪刀](剪刀.md)，可以使其变成一个雕刻南瓜，并掉落或南瓜种子。

# 获取
# = 雪傀儡 =
[剪刀](剪刀.md)剪去[雪傀儡](雪傀儡.md)的南瓜头时会掉落1个雕刻南瓜。

# 破坏
挖掘雕刻南瓜的合适工具是斧和剑。

雕刻南瓜被破坏后会掉落自身。

# 用途

# = 头盔 =
雕刻南瓜可作为无防护数值的头盔穿戴，当穿戴雕刻南瓜时，玩家的视野与雕刻南瓜的雕刻轮廓类似。

此外，其作为一个面具，允许玩家望向[末影人](末影人.md)而不会激怒它，同时也能使[嘎枝](嘎枝.md)不受玩家视线的影响，其他玩家的地图上不会显示穿戴雕刻南瓜的玩家的地图图标控制}}。

多人游戏中，穿戴雕刻南瓜的玩家不会在[定位栏](定位栏.md)上显示。

# = 发射器 =
[发射器](发射器.md)会将发射器朝向且在射程内的玩家、生物或盔甲架的头盔栏装备一个雕刻南瓜。

# = 建造生物 =

雕刻南瓜可摆放在下图所示的结构来建造[铁傀儡](铁傀儡.md)、[雪傀儡](雪傀儡.md)和[铜傀儡](铜傀儡.md)，结构可任意旋转。铁傀儡、雪傀儡和铜傀儡分别需要[铁块](铁块.md)、[雪块](雪块.md)和[铜块](铜块.md)（所有氧化与涂蜡变种）作为身体。

建造时雕刻南瓜必须在最后放置，否则生物不会生成。建造铁傀儡时，图中的4个空位置（即“双臂”的上方和下方）必须是空气方块，否则铁傀儡不会生成。

雕刻南瓜可以由[玩家](玩家.md)、[末影人](末影人.md)或[发射器](发射器.md)放置，由剪刀雕刻产生的雕刻南瓜如果满足结构要求也可以生成生物。

# 你知道吗
* [僵尸](僵尸.md)、[僵尸村民](僵尸村民.md)、[溺尸](溺尸.md)、[尸壳](尸壳.md)、[僵尸猪灵](僵尸猪灵.md)、[骷髅](骷髅.md)、[凋灵骷髅](凋灵骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)和[焦骸](焦骸.md)在[万圣夜](wzh:万圣夜.md)（10月31日）时生成有22.5%的概率戴上雕刻南瓜，但是杀死它们后雕刻南瓜并不会掉落。<ref></ref>
* 雕刻南瓜的底部纹理与顶部纹理相同，南瓜也是如此。
* 雪地和南瓜斑块可能会生成在一起。在1.13之前，这可能会导致有极低概率自然生成雪傀儡。
