# 黏土球

*页面ID: 6981* | *来源: Minecraft Wiki*

* *黏土球（Clay Ball）**是一种通过开采[黏土](黏土.md)获得的[物品](物品.md)，可用于制作[红砖](红砖.md)。

# 获取
使用无[精准采集](精准采集.md)魔咒的工具或徒手开采[黏土](黏土.md)可以获得黏土球，因此黏土球可再生。1个黏土会掉落4个黏土球，不受[时运](时运.md)魔咒影响。

# = 箱子战利品 =

# 用途
黏土球可用于重新合成黏土，也可以在[熔炉](熔炉.md)中烧制成[红砖](红砖.md)。
