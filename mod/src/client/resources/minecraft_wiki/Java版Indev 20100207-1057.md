# Java版Indev 20100207-1057

*页面ID: 173009* | *来源: Minecraft Wiki*

<onlyinclude>

* *Minecraft Indev**的一个版本发布于2010年2月7日10:57（UTC）。<ref></ref>

# 更改
# = 方块 =
* *[玻璃](玻璃.md)**
* 现在会阻止光线和雨通过。<ref>[Adura的IRC记录](#logs.md): "(06:12:26) <betasword> Notch: Newest update killed glass. Glass no longer lets light through. D:"</ref>

* *[耕地](耕地.md)**
* 现在非完整方块放在其上时也会变成[泥土](泥土.md)。

* *[水](水.md)**
* 现在会破坏非固体方块了，尽管这样不会掉落任何物品。

# = 常规 =
* *其他**
* 将音效系统修改为使用[OpenAL](wikipedia:OpenAL.md)。</onlyinclude>
