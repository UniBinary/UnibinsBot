# Scrolls披风

*页面ID: 187366* | *来源: Minecraft Wiki*

* *Scrolls披风（Scrolls Champion Cape）**是向在*[Caller's Bane](Caller's Bane.md)*（前称*Scrolls*）游戏中获得高名次的玩家发放的披风。

# 描述
从2014年11月7日开始，这件披风被授予那些在Scrolls每周排行榜上5次获得第一名的玩家。<ref name="Scrolls cape announcement">https://web.archive.org/web/20160320011410/https://scrolls.com/2014/11/up-up-and-away</ref>发放于2015年9月30日截止<ref name="Scrolls cape ended">https://web.archive.org/web/20160308073845/https://scrolls.com/2015/09/greeting-fellow-citizens-of-the-internet</ref>这是因为玩家数量已经变得太少，竞争性太弱。<ref name="Scrolls cape ending">https://web.archive.org/web/20150718025116/http://scrollsdev.tumblr.com:80/post/124058513081/scrolls-faq</ref>

在[MINECON 2015](MINECON 2015.md)期间，Scrolls MINECON开放赛举行，比赛内容包括Scrolls游戏内物品和其他奖品，表现最好的四名玩家还将获得披风。<ref name="Scrolls MINECON Open">https://web.archive.org/web/20160314103615/https://scrolls.com/2015/06/announcing-the-minecon-open</ref>

2014年12月11日至12日，为了庆祝Scrolls的发售，所有玩家都会暂时佩戴这件披风。<ref name="Scrolls temporary cape"></ref>
