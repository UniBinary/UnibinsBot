# 佳酿纹样陶片

*页面ID: 156719* | *来源: Minecraft Wiki*

* *佳酿纹样陶片（Brewer Pottery Sherd）**是图案形似[水瓶](水瓶.md)的[陶片](陶片.md)。

# 获取
# = 考古战利品 =
用[刷子](刷子.md)刷扫[沙漠水井](沙漠水井.md)里的[可疑的沙子](可疑的沙子.md)有概率掉落佳酿纹样陶片。

# = 饰纹陶罐 =
被不具有[精准采集](精准采集.md)的工具挖掘破坏或被[弹射物](弹射物.md)击毁时，附有佳酿纹样陶片的[饰纹陶罐](饰纹陶罐.md)会掉落佳酿纹样陶片。
