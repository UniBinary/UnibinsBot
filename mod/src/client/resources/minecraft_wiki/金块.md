# 金块

*页面ID: 7165* | *来源: Minecraft Wiki*

* *金块（Block of Gold）**是一种用[金锭](金锭.md)合成而来的装饰性矿产[方块](方块.md)。

# 生成
# = 自然生成 =
[海底神殿](海底神殿.md)有一个被[暗海晶石](暗海晶石.md)包住8个金块的中心房间。

金块也会作为[堡垒遗迹](堡垒遗迹.md)和[废弃传送门](废弃传送门.md)的一部分生成。

# 破坏
挖掘金块的合适工具是镐。金块需要铁镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

金块被破坏后会掉落自身。

# 用途
金块可用于存储[金锭](金锭.md)，以此来节约空间。

# = 信标 =

金块可作为激活[信标](信标.md)的底座方块。

# = 合成材料 =

# = 猪灵 =
在非和平难度下，无论玩家是否装备了[金质盔甲](盔甲.md)，成年[猪灵](猪灵.md)看见或听见玩家破坏金块后会与之敌对。

# 你知道吗
[无框|右|32px](File:Tower of Pimps.png.md)
* 在Xbox 360版中的TU19前，在教程世界的沙漠金字塔里可以找到4个堆在1个黑曜石上面的金块。这引用了[Achievement Hunter](wikipedia:Achievement Hunter.md)的*Let's Play Minecraft*系列，这个组合在此系列中用来创建“Tower of Pimps”（如右图），该结构由[Gavin Free](wikipedia:Gavin Free.md)首先创建，现在在许多篇章中用作一座奖杯。
* 金块与[钻石块](钻石块.md)的纹理只有颜色不同，[纹理更新](纹理更新.md)前也是如此。
