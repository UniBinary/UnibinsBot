# 启动器2.3.462

*页面ID: 99111* | *来源: Minecraft Wiki*

* *2.3.462**是一次[启动器](启动器.md)更新，发布于2022年10月20日。

# 新内容
* 加入了7个新的Java版默认皮肤，名称分别为Noor、Sunny、Ari、Zuri、Makena、Kai和Efe。

# 更改
* 现在[Minecraft Live](Minecraft Live.md)页面会显示生物投票的获胜者。
* 更新了[Minecraft Legends](Minecraft Legends.md)页面中的预告片，并重新加入了页面右上角的两只悦灵。
