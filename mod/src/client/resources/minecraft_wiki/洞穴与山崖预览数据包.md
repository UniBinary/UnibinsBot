# 洞穴与山崖预览数据包

*页面ID: 81605* | *来源: Minecraft Wiki*

* *洞穴与山崖预览数据包（Caves & Cliffs Prototype Data Pack）**是由[Mojang Studios](Mojang Studios.md)发布的一款[数据包](数据包.md)，类似于中的[实验性玩法](实验性玩法.md)。该数据包最初随[1.17](Java版1.17.md)的快照版本[21w15a](21w15a.md)一同发布<ref name="article_21w15a"></ref>。

此数据包用于在开始[洞穴与山崖](洞穴与山崖.md)第二部分（[Java版1.18](Java版1.18.md)）开发前，使玩家能体验到快照[21w06a](21w06a.md)和[21w14a](21w14a.md)之间的世界生成方面的修改，并帮助开发者提早完善相关机制。

此处记录了此数据包的更新情况，以及相应的变更。

# 第一版
第一版（）与[21w15a](21w15a.md)一同发布，发布于2021年4月14日。<ref name="article_21w15a"/>

# = 新内容 =
; [洞穴](洞穴.md)
* 加入了[噪声洞穴](噪声洞穴.md)（Noise Caves），有“意面洞穴（Spaghetti Cave）”和“芝士洞穴（Cheese Cave）”两种。
* * 意面洞穴形状像意面一样长而弯曲，有时像宽意面（Tagliatelle）一样宽。
* * 芝士洞穴形状像瑞士奶酪上的孔，且大小不一。
* 生成时使用了[噪声生成器](自定义世界生成.md)。
* 与地面相交时，会在地面生成洞穴入口。

; [含水层](含水层.md)
* 取代了旧的水下雕刻器洞穴和水下峡谷。
* 用于生成噪声洞穴中的水体，仅在Y=31以下产生。
* [岩浆块](岩浆块.md)可以在噪声洞穴水体的底部生成，产生涡流气泡柱。
* [鱼](鱼.md)会在[海洋](海洋.md)或[河流](河流.md)下的含水层中生成。

; [裂隙](裂隙.md)
* 一种从地表向下延伸的裂缝，类似于[峡谷](峡谷.md)，但比峡谷更窄更直。其最多可以深达90个方块，直通深板岩层。

# = 更改 =
; 世界高度
* 将[主世界](主世界.md)可建筑范围的总高度提升至384格。
* * 主世界可建筑范围的Y[坐标](坐标.md)现在是-64到319。

; [矿石](矿石.md)
* 通过为大多数矿石设置一个类似于之前[青金石矿石](青金石矿石.md)的蔓延（spread）值，更改了它们的生成机制。
* * 一些矿石既有了新的蔓延式生成机制，同时又保留着之前的线性生成机制。
* * [煤矿石](煤矿石.md)会尝试生成两次：
* ** 使用蔓延机制在Y=0至Y=192之间生成，在Y=96处生成最多。
* ** 使用线性生成机制在Y=136至Y=319之间均匀生成。
* * [铜矿石](铜矿石.md)会尝试生成一次：
* ** 使用线性生成机制在Y=0至Y=63之间生成。
* * [钻石矿石](钻石矿石.md)会尝试生成两次：
* ** 使用蔓延机制在Y=-144（尽管常规世界生成无法达到如此低的高度）至Y=16之间生成，且在Y=-64处生成最多。
* ** 大型钻石矿团簇会独立生成，生成方法与范围与普通钻石矿团簇相同。
* * [绿宝石矿石](绿宝石矿石.md)会尝试生成一次：
* ** 使用蔓延机制在Y=32至Y=480（尽管常规世界生成无法达到此高度）之间生成，在Y=256处生成最多。
* * [金矿石](金矿石.md)会尝试生成一次：
* ** 使用蔓延机制在Y=-64至Y=32之间生成，在Y=-16处生成最多。
* ** [恶地](恶地.md)的金矿生成机制未改变。
* * [铁矿石](铁矿石.md)会尝试生成三次：
* ** 使用线性生成机制在Y=-64至Y=-32之间生成。
* ** 使用蔓延机制在Y=-24至Y=56之间生成，在Y=16处生成最多。
* ** 使用蔓延机制在Y=128至Y=384（尽管常规世界生成无法达到此高度）之间生成，在Y=256处生成最多。
* * [青金石矿石](青金石矿石.md)会尝试生成两次：
* ** 使用“蔓延”机制在Y=-32至Y=32之间生成，在Y=0处生成最多。
* ** 使用线性生成机制在Y=-64至Y=64之间均匀生成。
* *** 这种方式生成的青金石矿石会像[远古残骸](远古残骸.md)一样埋藏在方块之中。
* * [红石矿石](红石矿石.md)会尝试生成两次：
* ** 使用蔓延机制在Y=-96（尽管常规世界生成无法达到如此低的高度）至Y=-32之间生成，在Y=-64处生成最多。
* ** 使用线性生成机制在Y=-64至Y=15之间均匀生成。
* 更改了各种矿石的生成频率。
* * 减少了裸露煤矿石的生成。
* * 降低了铜矿石的生成频率。
* * 缩小了普通钻石矿团簇的规模，略微提高了生成频率（导致总生成量略微下降），且有50%的概率不会暴露在空气中。
* * 提高了绿宝石矿石生成频率。
* * 提高了金矿石的生成频率，且有50%的概率不会暴露在空气中。
* * 降低了铁矿石的生成频率。
* * 提高了青金石矿石的掩埋频率和生成频率。
* * 降低了红石矿石的生成频率。
* 如果矿石在生成时替代的是深板岩或凝灰岩，则会生成其深层变种。
* * 煤矿石、铜矿石和绿宝石矿石不会在Y=0以下生成，因此其深层变种不会自然生成。

; [深板岩](深板岩.md)
* 在Y=0以下，深板岩会作为主要岩石生成。
* * 从Y=-1至Y=-8处，[石头](石头.md)逐渐会向深板岩过渡。
* * 从Y=-8处开始会完全替换掉石头。
* * 凝灰岩在此高度下会随机替换深板岩生成。
* 仍会在Y=0至Y=16处以团簇形式生成。

; [闪长岩](闪长岩.md)、[安山岩](安山岩.md)和[花岗岩](花岗岩.md)
* 调整了生成团簇的大小以及生成位置。
* * 每次生成的闪长岩、花岗岩和安山岩会更多且更像一个球型，但它们的生成频率会更低。
* 不会在Y=0以下生成。

; [泥土](泥土.md)
* 不会在Y=0以下生成。

; [凝灰岩](凝灰岩.md)
* 会在Y=0以下以[团簇](团簇.md)的形式生成。

; [熔岩](熔岩.md)
* 会从Y=-54处开始生成。

; [要塞](要塞.md)
* 现在根据深度也会被深板岩完全包裹住了。

# 第二版
第二版（）与[21w16a](21w16a.md)一同发布，发布于2021年4月21日。<ref name="article_21w16a"></ref>

# = 新内容 =
; 矿石分布
* 加入了罕见的蛇形[矿脉](矿脉.md)。
* * 在主世界Y=0以上的区域，大型铜矿脉伴随[花岗岩](花岗岩.md)生成。
* * 在主世界Y=0以下的区域，大型铁矿脉伴随[凝灰岩](凝灰岩.md)生成。

# = 更改 =
; [含水层](含水层.md)
* 在主世界Y=0以下区域生成的含水层现在有概率完全由[熔岩](熔岩.md)组成。

# 第三版
第三版（）与[21w17a](21w17a.md)一同发布，发布于2021年4月28日。<ref name="article_21w17a"></ref>

# = 新内容 =
; 面条洞穴
* 一种新的[洞穴](洞穴.md)类型，比[意面洞穴](意面洞穴.md)更加狭窄、弯曲而密闭。

# = 更改 =
; [矿脉](矿脉.md)
* 现在更加罕见且规模更小。
* 现在其中的矿石分布更不均匀，且有更高的概率呈团簇状生成。
* 现在有概率包含[粗铁块](粗铁块.md)或[粗铜块](粗铜块.md)。

; [矿石](矿石.md)生成
* 由于[21w17a](21w17a.md)的更改，[绿宝石矿石](绿宝石矿石.md)现在能够取代[花岗岩](花岗岩.md)、[闪长岩](闪长岩.md)、[安山岩](安山岩.md)、[凝灰岩](凝灰岩.md)和[深板岩](深板岩.md)生成了。
* [煤矿石](煤矿石.md)和[铜矿石](铜矿石.md)现在能够在Y=0至Y=16处取代深板岩或凝灰岩并生成其深层变种了。

# 第四版
第四版（）与[21w18a](21w18a.md)一同发布，发布于2021年5月5日。<ref name="article_21w18a"></ref>

# = 更改 =
; [矿石](矿石.md)分布
* 略微降低了[铜矿石](铜矿石.md)的生成频率。
* 略微降低了中型[铁矿石](铁矿石.md)团簇的生成频率。
* 将小型铁矿石团簇的最大生成高度由-32提高至64。

; [矿脉](矿脉.md)
* 再次缩减了平均规模和生成频率。
* 提高了[粗金属块](粗金属块.md)在矿脉中的生成频率。

; [洞穴](洞穴.md)
* [雕刻器洞穴](雕刻器洞穴.md)现在能生成于[海洋](海洋.md)生物群系下方低于Y=0的区域。
* [面条洞穴](面条洞穴.md)不再生成于主世界Y=30以上的区域。
* 扩大了雕刻器洞穴和面条洞穴的最小规模。

; [深板岩](深板岩.md)
* 现在不再能够在主世界Y=0以上的区域以团簇的形式生成。
* * 这也使得[深层煤矿石](深层煤矿石.md)和[深层铜矿石](深层铜矿石.md)再次无法自然生成。

# 你知道吗
* 该数据包并未向游戏加入任何新的地物生成机制或是噪声洞穴生成机制，而是直接调用/开启了它们。
* * 这意味着各种新的世界生成机制实际上存在于[21w15a](21w15a.md)及之后版本的中，但在原版游戏中并未被启用。
