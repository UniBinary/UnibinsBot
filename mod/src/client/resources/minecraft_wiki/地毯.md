# 地毯

*页面ID: 9967* | *来源: Minecraft Wiki*

* *地毯（Carpet）**是一种主要用来装饰的[方块](方块.md)。

# 生成
# = 自然生成 =
; 雪屋
白色、淡灰色和红色地毯在[雪屋](雪屋.md)里自然生成。
; 林地府邸
除橙色和地毯外，其他颜色的地毯都会在[林地府邸](林地府邸.md)里生成。
; 远古城市
灰色、蓝色、淡蓝色和青色地毯会在[远古城市](远古城市.md)里生成。
; 村庄
不同生物群系的[村庄](村庄.md)里会自然生成不同颜色的地毯。

# 破坏
没有工具可以加速对地毯的挖掘。

地毯被破坏后会掉落自身。

# 用途
地毯的厚度与[压力板](压力板.md)相同。地毯的碰撞箱为格，不像压力板那样，地毯覆盖了它所在方块的整个表面。

地毯可以放在任何非[空气](空气.md)方块上，包括[结构空位](结构空位.md)和[光源方块](光源方块.md)。

地毯可以放在[栅栏](栅栏.md)和[墙](墙.md)的顶部，使玩家能够在上面跳跃。

地毯可被[活塞](活塞.md)推动，但当它被推进一个没有方块支撑的空气方块或被向下拉的时候会掉落为物品。地毯也可以破坏下落的[沙子](沙子.md)和[沙砾](沙砾.md)。

地毯是[光照透明方块](亮度#光照透明方块.md)。

地毯可以放在水方块上，若要放置，必须瞄准有一个可视的碰撞箱的方块放置地毯。

# = 燃料 =

地毯能用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个地毯可以烧炼0.335个物品。

# = 羊驼 =
地毯可以作为一种造型独特的装饰装备在[羊驼](羊驼.md)的身上，但其不具备鞍的功能。

在无骑乘物时，对装备地毯的羊驼[剪刀](剪刀.md)可以剪下所装备的地毯。

# = 幽匿感测体 =
地毯[物品实体](物品实体.md)掉在地上、在地毯上行走/跳跃、放置地毯发出的声音不会被[幽匿感测体](幽匿感测体.md)和[监守者](监守者.md)检测到。

# 你知道吗
* 如果玩家冲过地毯，地毯的粒子效果正好在地毯下面。
* 地毯不会阻止雪的形成。
* 地毯可被安全地放在耕地的上面，尽管它不会保护耕地免遭跳跃的实体的破坏。
* 如果把地毯放在[栅栏](栅栏.md)顶部，玩家将可跳上地毯，而除了兔子和史莱姆外的生物都不可以。
