# Java版12w40b

*页面ID: 33135* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w40b**是[Java版1.4.2](Java版1.4.2.md)的第11个快照，发布于2012年10月5日<ref></ref>，发布以修复[12w34a](12w34a.md)里的漏洞和崩溃。

# 新内容
# = 命令格式 =
* ***
* 加入了一个使玩家相对现有位置传送的方法。
* * 使用<code>~</code>来表示现在的位置，<code>+</code>和<code>-</code>来表明传送的距离。
* * 举例：<code>/tp Steve ~+5 ~-5 5.55</code>可将叫“Steve”的玩家移动到其X+5，Y-5，Z为5.55的位置。

# 修复
* *修复了3个漏洞**
* 修复了玩家挖掘完前面的方块会导致后面的方块也被破坏的问题。
* 修复了信标渲染的问题。
* 修复了一个关于在要塞中的地图导致崩溃的问题。</onlyinclude>
