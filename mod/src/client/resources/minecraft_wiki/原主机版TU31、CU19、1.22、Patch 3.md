# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 可以通过放置[南瓜](南瓜.md)或凋灵骷髅头颅以生成[铁傀儡](铁傀儡.md)、[雪傀儡](雪傀儡.md)或[凋灵](凋灵.md)。
* 只有在铁傀儡、雪傀儡或凋灵的其他部分已经搭建时放置，才能有效地生成。

* *[铁砧](铁砧.md)**
* 铁砧重新平衡。

* *[红石比较器](红石比较器.md)**
* 可以检测物品展示框里的物品的旋转并输出相应的红石信号。

* *[按钮](按钮.md)**
* 现在可以放置在方块的顶部或底部。

* *[激活铁轨](激活铁轨.md)**
* 激活的激活铁轨会卸下矿车里的实体。

* *[炼药锅](炼药锅.md)**
* 容纳着水的炼药锅可使用其中三分之一的水以扑灭燃烧的实体身上的火。

* *[蘑菇方块](蘑菇方块.md)**
* 当使用带有精准采集魔咒的工具采集时，会掉落六面皆为蘑菇纹理而非气孔纹理的方块。

* *[海绵](海绵.md)**
* 重新引入至生存模式，且有了新的行为与纹理。
* 海绵吸水后会变为[湿海绵](湿海绵.md)。
* 海绵周围会出现水粒子。
* 会吸收5格方块以内的水。
* 只有当海绵接触水时才会吸水。

* *[甘蔗](甘蔗.md)**
* 颜色受生物群系的影响。

# = 生物 =
* *[村民](村民.md)**
* 村民有额外的职业和交易体系。
* 村民会收割农作物。
* 村民只在愿意繁殖时繁殖（可以给予它们3个[面包](面包.md)、12个[胡萝卜](胡萝卜.md)或12个[马铃薯](马铃薯.md)以使其愿意）。
* 村民被闪电击中后会变成女巫。

* *[僵尸](僵尸.md)**
* 幼年僵尸会掉落经验球了。
* 会在被闪电苦力怕炸死时掉落[僵尸的头](僵尸的头.md)。

* *[苦力怕](苦力怕.md)**
* 可以被[打火石](打火石.md)点燃了。
* 会在被闪电苦力怕炸死时掉落[苦力怕的头](苦力怕的头.md)。

* *[僵尸猪人](僵尸猪人.md)**
* 成年僵尸猪人会瞬时原谅玩家，并失去速度提升，但会继续攻击，直到玩家离开其视野。

* *[女巫](女巫.md)**
* 当其困在水下时，会饮用[水肺药水](水肺药水.md)。
* 会在死亡后罕见地掉落水肺药水。

* *[绵羊](绵羊.md)**
* 死亡时将掉落羊肉。

* *[骷髅](骷髅.md)**
* 现在会逃离狼。
* 会在被闪电苦力怕炸死时掉落[骷髅头颅](骷髅头颅.md)。

* *[凋灵骷髅](凋灵骷髅.md)**
* 会在被闪电苦力怕炸死时掉落[凋灵骷髅头颅](凋灵骷髅头颅.md)。

* *[蜘蛛](蜘蛛.md)**
* 其视线不再能透过固体方块而发现玩家。

* *[牛](牛.md)**
* 更新了音效。

* *[哞菇](哞菇.md)**
* 更新了音效。

* *幼年生物**
* 幼年动物的成长可通过喂食以加速。

# = 非生物实体 =
* *[物品展示框](物品展示框.md)**
* 物品展示框里的物品可以旋转8个方向，并会发出相应的红石信号。

* *[箭](箭.md)**
* 在水下会更快地减速，且火焰会被浇灭。

* *[矿车](矿车.md)**
* 更新了音效。

# = 游戏内容 =
* *[下界传送门](下界传送门.md)**
* 下界传送门可以由4×5至23×23的任何矩形构成。
* 只要下界传送门足够大，恶魂就可以穿过。
* 框架内任何位置的火都可以激活传送门，不再只有底部。

* *[钓鱼](钓鱼.md)**
* 钓鱼现在有粒子效果。
* * 玩家收杆之前，气泡会向浮漂移动，像鱼游来的样子。

* *[附魔](附魔.md)**
* 附魔现在消耗[青金石](青金石.md)。
* 附魔重新平衡。
* 附魔书可以同时获得多个魔咒。

* *[烧炼](烧炼.md)**
* 当燃料耗尽时，烧炼箭头会以二倍速倒退。
* 空熔炉只能放入燃料或空桶。

* *[游泳](游泳.md)**
* 更多生物会游泳。

* *[声音](声音.md)**
* 添加点燃方块时的打火石声和电荷声。

* *[原主机版教程](原主机版教程.md)**
* 创建了一个新的教程世界。
