# 基岩版1.14.0.51

*页面ID: 49465* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.14.0.51**是[1.14.1](基岩版1.14.1.md)的第2个测试版，发布于2019年11月20日，<ref></ref>修复了一些漏洞。

# 更改
# = 常规 =
* *地图制作与[附加包](附加包.md)**
* 物品标签现在可以通过使用命令来在UI中隐藏。

# 修复
* *修复了6个漏洞**<br>
* *崩溃**
* 修复了若干可能在游戏过程中发生的崩溃。
* 修复了一个在长时间游玩中探索了许多新区块后可能会发生的崩溃。
* 修复了在Android上登录Xbox Live时可能发生的崩溃。

* *常规**
* 修复了市场中销售的某些内容在商店页面内占用太多空间的问题。

* *物品**
* 修复了一个导致金合欢树叶卡在玩家物品栏热键的漏洞。（）

* *UI**
* 修复了一个在新的世界内游玩时不显示保存图标的漏洞。</onlyinclude>
