# 一个极妙之物

*页面ID: 139173* | *来源: Minecraft Wiki*

* *一个极妙之物（A Very Fine Item）**是一种仅能在“isolation”维度中[床](床.md)旁边的[物品展示框](物品展示框.md)内找到的物品。

# 获取
[thumb|“isolation”维度中的床旁边的物品展示框内的“一个极妙之物”](File:Isolation - a very fine item.png.md)

“一个极妙之物”只能从“isolation”维度中[Bob的房子](20w14∞#结构.md)中的物品展示框内获取。

每个世界中仅存在1个“一个极妙之物”。

# 用途
“一个极妙之物”没有实际用途。
