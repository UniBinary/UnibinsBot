* *潜影贝（Shulker）**是生成在[末地城](末地城.md)和[末地船](末地船.md)中伪装成方块的敌对生物。它们会将自己隐藏在贝壳里，和末地城的[紫珀块](紫珀块.md)混在一起。

# 生成
# = 自然生成 =
潜影贝会随着[末地](末地.md)外岛的[末地城](末地城.md)和[末地船](末地船.md)一同生成，它们经常会出现在末地城的墙壁上。潜影贝不会自然消失，即使是在和平难度下。潜影贝随着末地城和末地船一同生成后不会再次自然生成。

# = 人为生成 =
一只**打开壳**的潜影贝被其他潜影贝（或自己）发射的子弹击中时，有概率在原地生成一只潜影贝，并且将自己传送走。

* 被击中的潜影贝会检查以该潜影贝为中心17&times;17&times;17范围内的方块是否满足[传送条件](#行为.md)，会尝试5次。若尝试成功，一只新的潜影贝将会生成在被击中的潜影贝原先附着的地方，否则不会有新的潜影贝生成。
* 若潜影贝被击中时生命值少于一半，则会有25%的概率不生成新的潜影贝。
* 在被击中的潜影贝为中心的8格方块之内，每有一只其他潜影贝，则生成新的潜影贝概率将会降低20%。若该范围内有着5只及以上的潜影贝，则不会有新的潜影贝生成。
* 当被击中的潜影贝因这次攻击死亡时，会在原位置重新生成一只潜影贝。在被击中的潜影贝为中心的9&times;9&times;9范围内若有超过一只其他潜影贝，则重新生成的概率会降低。

# 行为
[thumb|250px|潜影贝射击](File:Shulker shooting.gif.md)
潜影贝一般保持静止，附着在附近方块的碰撞箱完整表面上。若没有方块发生变化且不被攻击，潜影贝会一直停留在自身的位置。

潜影贝的传送需满足以下的其中一个条件：
* 潜影贝所附着的方块已经消失
* 潜影贝检测不到所附着方块的碰撞箱
* 当前占用的方块已不是空气方块
* 无法打开壳
* 生命值低于一半时受到伤害（25%概率）
当条件满足时，潜影贝会尝试传送（每1游戏刻尝试5次）到距离该潜影贝[切比雪夫距离](切比雪夫距离.md)内8格的范围内随机一个**[碰撞箱](碰撞箱.md)完整的表面**上，并根据其依靠的方块表面调整自身朝向。如果没有发现可供传送的合适表面（例如处于虚空中），则不会传送。

另外对于和潜影贝同一高度的脚手架，会主动传送到脚手架下表面，但是传送以后检测不到脚手架的碰撞箱就会往其他合适的地方传送。

如果脚手架有下表面则会阻挡潜影贝从侧面打开外壳，脚手架没有下表面的时候不会阻挡潜影贝从侧面打开外壳。

潜影贝不会阻止附近的玩家使用[床](床.md)入睡，免疫[摔落伤害](伤害#摔落伤害.md)，可被[钓鱼竿](钓鱼竿.md)勾住，但不能被拖动，免疫熔岩和火造成的燃烧伤害，，碰到水时也会传送。

尽管潜影贝与方块有相似之处，但它们与方块有很多差异。例如，生物会试图通过潜影贝寻找路径，而不是绕开<ref></ref>或跳过它们，<ref> </ref>从高处落到它们上时不会产生粒子效果。<ref></ref>它们的[刷怪蛋](刷怪蛋.md)也不会破坏[草丛](草丛.md)等方块。<ref></ref>

具有[隐身](隐身.md)效果的潜影贝全身都不会隐形。<ref></ref>

难度不为和平时，潜影贝主动攻击16格内的玩家，被攻击时会进行反击，且当一只潜影贝受到攻击时，附近的所有潜影贝将对攻击者进行反击。在和平难度下，潜影贝不会进行攻击。<ref></ref>它们永远不会因误伤而互相攻击。

潜影贝会偶尔将外壳微微打开1~3秒，偷看外面的环境。当攻击目标在16格内时，潜影贝便完全打开外壳，每隔1~5.5秒便会发射出一颗沿XYZ轴移动的、追踪目标的[潜影弹](潜影弹.md)。

当潜影贝关闭外壳时，会获得护甲值并可以弹开[箭](箭.md)（包括由具有[穿透](穿透.md)魔咒的弩射出的箭）。打开外壳时，潜影贝就会丧失这一天然盔甲并且正常地受到伤害。

与多数敌对生物不同，潜影贝永远不会自然消失，在不死亡的情况下会永远保留在世界中。在和平难度下，潜影贝不会消失。

# = 染色 =
潜影贝可以获得不同的颜色，就像[潜影盒](潜影盒.md)一样。生成的潜影贝为默认颜色。

潜影贝只能通过命令来染色；[创造模式](创造模式.md)的玩家可以对潜影贝任意一种[染料](染料.md)，使其染上对应的颜色。

# = 队伍 =

当潜影贝位于一个[队伍](队伍.md)中时，会主动攻击不在同一队伍中的除[恶魂](恶魂.md)外的所有敌对生物。

拥有队伍的潜影贝是游戏中极少数会主动攻击[苦力怕](苦力怕.md)的生物。潜影贝不会主动攻击[铁傀儡](铁傀儡.md)和[雪傀儡](雪傀儡.md)，但这些生物会主动攻击潜影贝，潜影贝在受伤后仍然会反击。

在多人游戏或冒险类存档设计中，玩家可以利用潜影贝的这一特性建造一个以潜影贝为守卫的炮台，固守一个特定位置。

# = 水平旋转 =
潜影贝除了在自然生成时具有随机的水平旋转角度属性（即水平朝向，尽管其模型实际上看上去并无旋转），不能够主动改变自身的水平旋转方向。

而由于当潜影贝在乘坐[船](船#行为.md)时，其水平朝向会被约束在相对于船的水平朝向的 [-105°, +105°] 范围内。在水平朝向被改变之后，由于潜影贝依然不会改动自身的水平朝向，这个被改变的值能一直保留到下船时。而又因为船的下客位置由乘客的水平朝向决定，故潜影贝的下船方向也随之改变。<ref>https://github.com/Youmiel/ArticlesAndDevNotes/blob/main/articles/2025-09__shulker_rotation/2025-09__shulker_rotation.md</ref>

# = 运输 =
[缩略图|150px|在[[Java版](File:Shulkerinboat.png.md)中被陆路运输的潜影贝。利用活塞推船上坡]]

潜影贝可以被[船](船.md)或[矿车](矿车.md)运输。它们会进入推进它们所在位置的船和矿车。在船上，潜影贝将默认朝上，无视其登船前的朝向。船的边沿会阻挡部分射出的潜影弹。除非被其他矿车推动，搭载潜影贝的矿车只有底部未被潜影贝覆盖的部分可以被其他实体推动。

当一只潜影贝被推入[返回传送门](返回传送门.md)时，它会被传送到主世界出生点。由于潜影贝会在其附近没有固体方块时传送自己，它们可以沿着返回传送门柱被[活塞](活塞.md)向下推至传送门中，或使用铁轨与矿车将潜影贝推下传送门。

# 你知道吗
* 潜影贝的英文名称“Shulker”是“Shell Lurker（贝壳潜伏者）”的简称。<ref></ref>
* 如果用[命名牌](命名牌.md)将一只潜影贝命名为“[Dinnerbone](Dinnerbone.md)”或“[Grumm](Grumm.md)”，潜影贝会上下颠倒过来，露出底部的螺旋花纹。倒过来的潜影贝离地约个方块的高度。
* * 潜影贝的尺寸为一个全体积方块，但从其模型来看比一个全体积方块略微小了一点。
* 当玩家把受重力影响的方块如[沙砾](沙砾.md)和[铁砧](铁砧.md)放在潜影贝上方时，方块会掉落成物品。
* 在游戏的纹理文件中，潜影贝的导弹被命名为<samp>spark.png</samp>。
* *潜影贝的纹理文件在版本[1.9.4](1.9.4.md)中被命名为<code>endergolem.png</code>，并且潜影贝在当前游戏文件中仍然继承<code>AbstractGolem</code>。
* 当玩家站在潜影贝的壳上时，可以潜行并且不会掉下来，就像站在方块上一样。如果外壳往侧向打开，则相当于一级垂直的[台阶](台阶.md)，玩家仍然可以站在上面并且不会掉落下来，除非壳关闭了。
* 在潜影贝关闭的壳上射[箭](箭.md)，箭将从外壳反弹，这类似于对[创造](创造.md)模式下或拿着[盾牌](盾牌.md)的玩家射箭。但[药箭](药箭.md)效果仍然会生效。
* 如果潜影贝的顶面和侧面存在方块时，会附着到其侧面方块上。
