# Java版1.8.1

*页面ID: 14069* | *来源: Minecraft Wiki*

* *1.8.1**是的一次次要更新，发布于2014年11月24日<!--<ref></ref>--><ref></ref>，加入了1条新的游戏规则，补全了制作人员名单，并修复了一些漏洞。此版本兼容1.8的服务端。

# 新内容
# = 命令格式 =
* ***
* <code>doEntityDrops</code>：与<code>doTileDrops</code>和<code>doMobDrops</code>效果类似，但只适用于非生物[实体](实体.md)。<ref></ref>

# = 游戏内容 =
* *制作人员名单**
* [Ryan Holtz](Ryan Holtz.md)（TheMogMiner）和[Michael Stoyke](Michael Stoyke.md)（Searge）的名字现在出现在制作人员名单中了。

# 更改
# = 方块 =
* *[南瓜灯](南瓜灯.md)**
* 再次能够用来生成[铁傀儡](铁傀儡.md)和[雪傀儡](雪傀儡.md)。

# = 物品 =
* *[地图](地图.md)**
* 现在会正确地显示新加入方块的颜色了。

* *[跳跃药水](跳跃药水.md)**
* 现在能够使用[红石粉](红石粉.md)增强了。

# = 生物 =
* *常规**
* 生物不再逃离即将爆炸的[苦力怕](苦力怕.md)。

# = 非生物实体 =
* *[盔甲架](盔甲架.md)**
* 引入了<code>Marker</code>标签。

* *[掉落物](掉落物.md)**
* 在“快速”图像品质设置下，掉落物也会旋转了。

# = 世界生成 =
* *[沼泽小屋](沼泽小屋.md)**
* 现在可以在Y轴64到71层生成[女巫](女巫.md)。

# = 命令格式 =
* ***
* <code>doTileDrops</code>不再影响实体。

# = 常规 =
* *[选项](选项.md)**
* 将“多人游戏设置”更名为“聊天设置”。
* 云可被设为关/高品质/流畅。
* 实体阴影可被设为开/关。
* 图像品质设置的流畅/高品质现在只影响树叶透明和雨落地的粒子效果。

* *[服务器](服务器.md)**
* 移除了由[纳格算法](wzh:纳格算法.md)导致的客户端[TCP](wzh:传输控制协议.md)数据包延迟。

* *性能**
* 各种性能提升。
* 多处性能优化。
