# 携带版1.0.5.11

*页面ID: 28502* | *来源: Minecraft Wiki*

<onlyinclude>

* *alpha 1.0.5 build 3**（也称为**Alpha 1.0.5.11**或**Alpha 1.0.5.13 re-release**）是[1.0.5](携带版1.0.5.md)的第3个测试版，发布于2017年3月17日<ref></ref>，修复了一些漏洞。

# 更改
# = 命令格式 =
* ***
* 现在使用命令不再让[实体](实体.md)生成在[熔岩](熔岩.md)里了。

# 修复
* *修复了4个漏洞**
*  - 紫颂植株的音效不正确。
*  - 使用铁砧来放大地图时，不对所有玩家产生效果。
* 使用命令时，试图将任何无关物品放入马铠槽时使得游戏崩溃。
* 使用命令时出现错误。</onlyinclude>

# 你知道吗
* 此测试版在无意中允许测试用户进入他们所拥有的[Realms](Realms.md)中，进入之后，Realms会升级到1.0.5，这使得直到其他用户升级到1.0.5正式版前除了该Realms的所有者和其他测试版用户都无法进入该Realms。</onlyinclude>
