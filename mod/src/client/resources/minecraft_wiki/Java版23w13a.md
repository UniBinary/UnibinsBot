# Java版23w13a

*页面ID: 103412* | *来源: Minecraft Wiki*

<onlyinclude>

* *23w13a**是[Java版1.20](Java版1.20.md)的第2个快照，发布于2023年3月29日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[瓶子草](瓶子草.md)**
* 现在被视为大型[花](花.md)。
* * 可用于吸引及繁殖[蜜蜂](蜜蜂.md)。
* * 蜜蜂会采集它的花粉。

* *[瓶子草植株](瓶子草植株.md)**
* 现在蜜蜂可为其授粉，使其生长一个阶段。

# = 物品 =
* *[瓶子草荚果](瓶子草荚果.md)**
* 现在可用于吸引及喂食[鸡](鸡.md)和[鹦鹉](鹦鹉.md)。

# = 生物 =
* *[嗅探兽](嗅探兽.md)**
* 更改了幼年嗅探兽的模型，以匹配。
* 现在成年嗅探兽死亡时不再掉落[苔藓块](苔藓块.md)。

# = 常规 =
* *[选项](选项.md)**
* 现在可以在视频设置屏幕上按下并滚动鼠标滚轮调整界面尺寸。

* *[标签](Java版标签.md)**
* 向方块标签中加入了。
* 向方块标签中加入了。
* 向方块和物品标签中加入了。

* *[进度](进度.md)**
* 现在种植[瓶子草荚果](瓶子草荚果.md)可以达成“”进度。
