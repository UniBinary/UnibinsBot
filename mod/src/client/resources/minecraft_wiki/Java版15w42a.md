# Java版15w42a

*页面ID: 18605* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w42a**是[Java版1.9](Java版1.9.md)的第33个快照，发布于2015年10月14日<ref></ref>，加入了霜冰、宝藏型魔咒以及新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[霜冰](霜冰.md)**
* 由冰霜行者魔咒产生。
* 不能收集到物品栏，也不能通过精准采集或命令获得（只能用放置）
* 在几秒后融化。
* * 融化过程有4个破坏状态（方块状态: <code>age:0，age:1，age:2，age:3</code>）。规则设为0时也会衰减，但较高的数字会让衰减变得很快。
* * 光亮等级越高融化越快（夜晚时不会融化）。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 宝藏型魔咒
* * 带有这类魔咒的物品只能通过战利品箱和[钓鱼](钓鱼.md)直接获得，而对应[附魔书](附魔书.md)需通过[交易](交易.md)获得。
* [冰霜行者](冰霜行者.md)
* * 属于宝藏型魔咒。
* * 在水上行走会创造出[霜冰](霜冰.md)。
* * 不同的等级:
* ** 等级I围绕玩家创造半径为2格霜冰圆。
* ** 每一等级增加一格半径。
* * 总共有两层等级。
* * 玩家需要站在地面以开启冰冻效果，当没入水中或处于空气，水不会变成[霜冰](霜冰.md)。
* * 如果水方块有实体，比如[船](船.md)或是生物浸没则不会生成霜冰。
* * 流动的水也会变成霜冰，使一桶的水也足够制作无限水源了。
* * 与深海探索者互斥。
* [经验修补](经验修补.md)
* * 属于宝藏型魔咒。
* * 持着物品时所有获得的经验会被收集用以修理而不会保存到经验条。
* ** 装备于主手，副手，与盔甲位置都能会认作是“持着”。
* ** 如果多个持着的物品拥有此魔咒，会随机分配收集到的[经验球](经验球.md)。
* ** 每一经验修理2耐久值。
* ** 如果修理所需要的经验比经验球的少，额外的经验会保留到经验条。
* ** 盾牌暂时不能通过使用命令或在生存模式下使用[铁砧](铁砧.md)获得此魔咒。

# 更改
# = 方块 =
* *[铁砧](铁砧.md)**
* 对物品重命名不再增加未来修复/重命名的花费。

* *[酿造台](酿造台.md)**
* 需要[烈焰粉](烈焰粉.md)以使其工作。
* * 一份烈焰粉支持30个材料的酿造 （标签: <code>Fuel:30b</code>）。
* ** 准确地说，每当你放入一份材料就会消耗一份燃料（一份烈焰粉=30份燃料） 。（如果你把酿造材料拿出又放入的话会消耗另一份燃料）
* * 可以通过侧贴的漏斗自动补充。

# = 物品 =
* *[鞘翅](鞘翅.md)**
* 飞行时撞墙会受到伤害。
* 如果你撞墙死了，会有如下死亡消息： “*玩家名字* 承受了过大的动能”。
* 潜行时有了新的动画。

# = 生物 =
* *[玩家](玩家.md)**
* 潜行时玩家的高度为1.65格（一般情况是1.8格）。
* 通过鞘翅飞行时玩家高度仅为0.6格。

# = 非生物实体 =
* *[船](船.md)**
* 提升了速度与操控性。
* 所有种类的船都能合成了。
* * 由于，深色橡木船还不能合成。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 只有一级的魔咒不再显示等级，例如“无限”不再显示为“无限 I”。
* 当穿着了多个带有荆棘效果的盔甲时，会随机选择一个而不是总是使用最底下的那个。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 将“0% sugar”改为“1% sugar”。
* 移除了“SOPA means LOSER in Swedish!”。
