# 基岩版1.9.0.3

*页面ID: 37566* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.9.0.3**是[1.9.0](基岩版1.9.0.md)的第3个测试版，发布于2018年12月5日<ref></ref>，加入了Minecraft脚本引擎（JavaScript），并修复了一些漏洞。

# 更改
# = 物品 =
* *[弩](弩.md)**
* 现在在[掠夺者](掠夺者.md)的手中会显得更大。
* *[盔甲架](盔甲架.md)**
* 给其装备[鞘翅](鞘翅.md)会出现白色的[皮革](皮革.md)。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)后才可使用。

# = 常规 =
* *Minecraft脚本引擎**
* 使用。
* 脚本可以被编写并与[行为包](行为包.md)绑定，以便监听和响应游戏事件、获取和修改实体组件、影响游戏行为。
* * 目前仅[Windows 10版](Windows 10版.md)开启[实验性玩法](实验性玩法.md)后可用。

# 修复
* *修复了10个漏洞**
* 修复了游戏过程中出现的崩溃现象。
* 已驯服的羊驼在打开它们身上的物品栏时不再发光。
* 手持的物品有时会变成白色。
* 罕见情况下，玩家在水附近走动时被传送到船中。
* Minecraft徽标不会出现在暂停或继续游戏后的加载界面中。
* 如果在床上被杀死，玩家不再能在半死状态中重生。（）
* 加载世界时，玩家不再生成在高空中。（）
* 信标光束会再次使用合适的纹理。（）
* 物品栏中的方块现在再次使用中的纹理。
* 优化了客户端和服务端的区块同步流程。</onlyinclude>
