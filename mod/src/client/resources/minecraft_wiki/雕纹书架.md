* *雕纹书架（Chiseled Bookshelf）**是一种可以容纳[书](书.md)、[书与笔](书与笔.md)、[成书](成书.md)、[附魔书](附魔书.md)和的[方块](方块.md)。

# 生成
雕纹书架不会生成在世界中。

# = 合成 =

# 破坏
挖掘雕纹书架的合适工具是斧。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，雕纹书架被破坏后只会掉落内容物，不会掉落自身。

被具有精准采集的工具挖掘破坏时，雕纹书架被破坏后会掉落自身和内容物。

# 用途
# = 容纳书本 =
雕纹书架可以容纳最多6本[书](书.md)、[书与笔](书与笔.md)、[成书](成书.md)、[附魔书](附魔书.md)或[知识之书](知识之书.md)。玩家手持任意书对某个空槽位可以在该槽位放入书本；对非空槽位可以取出对应槽位上的书本。

# = 红石信号 =
[thumb|100px|雕纹书架的槽位与其对应输出的红石信号](File:chiseled_bookshelf_power.png.md)
当把[红石比较器](红石比较器.md)输入端对准雕纹书架放置时，红石比较器会按照最后一次互动的槽位号输出强度为1-6的红石信号，若所有槽位皆未使用过则无信号。注意这与雕纹书架内的书本数量不同，因为取出一本书将记录该次互动时相应的槽位。

# = 容器交互 =
[漏斗](漏斗.md)可以放入或取出书本，[投掷器](投掷器.md)可以放入书本，[漏斗矿车](漏斗矿车.md)可以取出书本。它们总是会与符合条件的第一个槽位交互，即：搜索到第一个空闲槽位后向此处放入书本，搜索到第一个非空槽位后从此取出书本。

全满的漏斗或漏斗矿车不会尝试与其交互，红石信号强度不变；容器不满时，会按上述顺序与每个槽位交互，直至成功取出书本或遍历完所有非空槽位，输出的红石信号强度以最后一次交互为准。

# = 燃料 =
雕纹书架可以作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个雕纹书架可以烧炼1.5个物品。
