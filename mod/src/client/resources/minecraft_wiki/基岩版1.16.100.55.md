# 基岩版1.16.100.55

*页面ID: 69318* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.100.55**是[基岩版1.16.100](基岩版1.16.100.md)的第6个测试版，发布于2020年9月10日<ref></ref>，同步了更多Java版的特性，以及修复漏洞。

# 更改
# = 方块 =
* *[侦测器](侦测器.md)**
* 被活塞移动时不再停留在被激活的状态。

* *[菌光体](菌光体.md)**
* 现在可以堆肥。

# = 物品 =
* *[摄像机](摄像机.md)**
* 不再能通过命令获取。

* *[旗帜图案](旗帜图案.md)**
* “Mojang徽标”旗帜图案现在可以在织布机里合成。

# = 生物 =
* *[猪灵蛮兵](猪灵蛮兵.md)**
* 僵尸化时会保留金斧。

* *[僵尸疣猪兽](僵尸疣猪兽.md)**
* 更改了幼年僵尸疣猪兽的模型以匹配Java版。

# = 常规 =
* *[附加包](附加包.md)和脚本引擎**
* 带宽优化以确保存档数据包只会在本地广播。
* 公开释出 组件，可以进行一定程度的带宽优化。
* 每个角色默认使用  组件进行带宽优化。
* 在原始文本中添加了selector的组件，可以在命令中输出实体的名称。例如和命令。
* 当使用命令时将不会再切断结构了。

* *[实验性玩法](实验性玩法.md)**
* 改进了选项布局。
* * 加入了“Custom Biome Add-Ons”“Experimental Scripting Add-Ons”“Experimental Molang Features”“Next Gameplay Update”选项。<ref></ref>

* *[菜单屏幕](菜单屏幕.md)**
* 为安卓设备添加了带有[Mojang Studios](Mojang Studios.md)图标的启动界面。

# 修复
* *性能与稳定性**
* 玩家重新加入多人游戏后，将其脚下的潜影盒打开不再会导致游戏崩溃。
* 修复了使用命令放置大量传送门方块会导致崩溃的问题。

* *原版趋同**
* 增大了幼年疣猪兽的头部模型。（）
* 菌光体现在能用于堆肥。（）
* 绯红菌和诡异菌现在能被放置在菌丝体上。（）
* 侦测器被活塞推动时不再会保持在激活状态下。（）
* “Mojang徽标”旗帜图案现在可以在织布机里合成。（）
* 可堆肥的方块和物品现在又能够正常用于堆肥了。（）

* *常规**
* 若用和放置的传送门方块不在有效的传送门框架中，则这些方块存在1秒后就会消失。
* 狐狸坠入甜浆果丛时不再会受到伤害。（）
* 调整和分离了命令（<code>title</code>、<code>subtitle</code>与<code>actionbar</code>）的文本和背景。
* 角色创造器的试衣间会在离线时显示已缓存的内容。
* 没有alpha通道的24位PNG图片不能再被当作自定义皮肤了。（）

* *游戏内容**
* 附有灵魂疾行的靴子耐久耗尽后会正常消失，而不再会卡在玩家的装备槽中。（）
* 猪灵蛮兵转化为僵尸猪灵后会保留身上的装备。（）

* *用户界面**
* 当选用“Pocket”选项时，锻造台会正确地显示锤子图标和UI部分。（）

* *新成就界面**
* 将列表中的奖励边框更改至与物品展示框相同。
* 优化了可按击元素的反馈效果。
* 缩减安全区域的大小。
* 修复了使用键盘时无法将聚焦指示从反馈按钮移开的问题。
* 修复了新成就界面有时无法在窗口边界或分屏下沿分界线正常应用安全区域的问题。</onlyinclude>
