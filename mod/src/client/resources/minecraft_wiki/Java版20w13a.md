# Java版20w13a

*页面ID: 56701* | *来源: Minecraft Wiki*

</ref>}}
<onlyinclude>

* *20w13a**是[Java版1.16](Java版1.16.md)的第8个快照，发布于2020年3月25日<ref name="20w13a"></ref>，加入了[炽足兽](炽足兽.md)及刷怪蛋、[磁石](磁石.md)、[诡异菌钓竿](诡异菌钓竿.md)与新的方块和物品标签，并修复了一些漏洞。

# 新内容
# =方块=
* *[磁石](磁石.md)**
* 可由[雕纹石砖](雕纹石砖.md)和[下界合金锭](下界合金锭.md)合成获得。
* 对磁石[指南针](指南针.md)可将其转化为[磁石指针](磁石指针.md)，其指针将始终指向该磁石。
* 可在所有[维度](维度.md)当中使用。

# = 物品 =
* *[诡异菌钓竿](诡异菌钓竿.md)**
* 可由[钓鱼竿](钓鱼竿.md)和[诡异菌](诡异菌.md)合成。
* 可用于控制[炽足兽](炽足兽.md)，使用方式与[胡萝卜钓竿](胡萝卜钓竿.md)相似。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了[炽足兽](炽足兽.md)刷怪蛋。

# = 生物 =
* *[炽足兽](炽足兽.md)**
* 新的被动型生物，生成于[下界](下界.md)的熔岩海中。
* 可装备[鞍](鞍.md)，且能够使用[诡异菌钓竿](诡异菌钓竿.md)控制。
* 接触[水](水.md)或[雨](雨.md)时会受到伤害。
* 具有幼年变种。
* 可通过喂食[诡异菌](诡异菌.md)繁殖。
* 幼年炽足兽或[僵尸猪灵](僵尸猪灵.md)有时会随之生成并骑在其身上。
* * 如果被僵尸猪灵骑在其身上，则它还会装备鞍。

# = 游戏内容 =
* *[标签](Java版标签.md)**
* 加入了方块和物品标签。
* * 分别包含方块和物品标签。
* 加入了方块和物品标签。
* * 应用于[菌柄](菌柄.md)、[去皮菌柄](去皮菌柄.md)、[菌核](菌核.md)、[去皮菌核](去皮菌核.md)和[木板](木板.md)的绯红与诡异变种。
* 加入了方块标签。
* * 应用于[熔岩](熔岩.md)。
* * 如果[炽足兽](炽足兽.md)不在应用该标签的方块当中，它就会打寒颤。

# 更改
# =方块=
* *[玄武岩](玄武岩.md)**
* 现在会在[灵魂土](灵魂土.md)上的熔岩接触[蓝冰](蓝冰.md)时形成。

* *[蜂巢](蜂巢（方块）.md)**
* 现在在地图上呈现黄色。

* *[营火](营火.md)**
* 现在可以使用[菌柄](菌柄.md)和[菌核](菌核.md)合成。

* *[栅栏](栅栏.md)**
* 下界木栅栏现在会和其他木栅栏相连接。

* *[菌核](菌核.md)和[菌柄](菌柄.md)**
* 现在使用下界木质[材料](材料.md)。
* * 不再会被[熔岩](熔岩.md)点燃。

* *[拼图方块](拼图方块.md)**
* 现在有12种朝向。
* 加入了新属性用于描述连接的部件是否可以被选择（和）。
* NBT字段被重命名为。
* 被拆分为（父方块）（子方块）。

* *[下界金矿石](下界金矿石.md)**
* 更改了纹理。
* 现在挖掘下界金矿石会获得[经验](经验.md)。

* *下界[木板](木板.md)、[台阶](台阶.md)和[楼梯](楼梯.md)**
* 不再能作为[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)和[高炉](高炉.md)的燃料使用。

* *[音符盒](音符盒.md)**
* 现在在下方放置下界木质[材料](材料.md)方块时会发出贝斯声。

* *[磨制玄武岩](磨制玄武岩.md)**
* 与其他磨制岩石相似，现在可以在2&times;2合成格中合成。
* 不再能通过[烧炼](烧炼.md)制得。
* 现在可通过使用[切石机](切石机.md)加工玄武岩获得。

* *[重生锚](重生锚.md)**
* 现在可通过[发射器](发射器.md)使用[荧石](荧石.md)来为其补充能量。
* 不再能被[末影龙](末影龙.md)破坏。

* *[烟熏炉](烟熏炉.md)**
* 现在可以使用[菌柄](菌柄.md)和[菌核](菌核.md)合成。

# = 物品 =
* *[木炭](木炭.md)**
* 现在只能通过烧制应用了方块标签的物品获得。
* * 此更改不会影响游戏内容，因为该标签仅应用于可以烧炼为木炭的物品。

# = 生物 =
* *[村民](村民.md)**
* 农民现在能够使用[骨粉](骨粉.md)来促进作物生长。
* 农民现在会把多余的种子放入[堆肥桶](堆肥桶.md)。
* 农民现在会把多余的[小麦](小麦.md)分给其他农民，以使之能够制作[面包](面包.md)。

* *[僵尸猪灵](僵尸猪灵.md)**
* 细微改动了纹理。

# = 游戏内容 =
* *[进度](进度.md)**
* 现在可以通过繁殖[炽足兽](炽足兽.md)来完成“”进度。

* *[以物易物](以物易物.md)**
* 轻微上调了[灵魂疾行](灵魂疾行.md)附魔物品的获得概率。

* *[创造模式物品栏](创造模式物品栏.md)**
* 将[竹子](竹子.md)、[海带](海带.md)和[甘蔗](甘蔗.md)移动到了装饰性方块标签下。

* *[钓鱼](钓鱼.md)**
* 更改了开阔水域的判断方式：
* * [浮漂](浮漂.md)周围5×4×5区域中的每一层都必须满足以下条件之一：
* ** 这一层全部是水（必须是[水源方块](水源方块.md)、无[碰撞箱](碰撞箱.md)的[含水](含水.md)方块，可以是[气泡柱](气泡柱.md)）。
* ** 这一层全部是[空气](空气.md)或[睡莲](睡莲.md)。

* *[配方书](配方书.md)**
* [木炭](木炭.md)的[烧炼](烧炼.md)配方现在需使用物品标签解锁。

* *[标签](Java版标签.md)**
* 将方块标签应用于[重生锚](重生锚.md)。
* 更改了方块和物品标签，使之分别使用方块和物品标签。
