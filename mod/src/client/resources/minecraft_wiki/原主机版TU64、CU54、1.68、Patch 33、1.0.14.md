# 原主机版TU64、CU54、1.68、Patch 33、1.0.14

*页面ID: 62653* | *来源: Minecraft Wiki*

* *TU64/CU54/1.68/Patch 33/1.0.14**是[原主机版](原主机版.md)的一次更新，发布于2018年4月24日，修复了一些漏洞。<ref></ref><ref></ref>

# 新内容
# = 常规 =
* *混搭包**
* 加入了最终幻想 XV（Final Fantasy XV）皮肤包。

# 修复
* *修复了3个漏洞**
* 修复当玩家在手持由钓鱼得来的水瓶看着炼药锅会导致游戏崩溃的漏洞。
* XB360和XBONE： - 水和熔岩桶不能在末地和末地城倾倒。
* PS3：修复游戏在加载带有床的区块而导致游戏崩溃的漏洞。
