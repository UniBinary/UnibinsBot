# 嘎枝之心

*页面ID: 126740* | *来源: Minecraft Wiki*

* *嘎枝之心（Creaking Heart）**是一种激活后可以生成[嘎枝](嘎枝.md)的方块。

# 生成
# = 自然生成 =
嘎枝之心罕见地生成于[苍白之园](苍白之园.md)生物群系中[嘎枝苍白橡树](嘎枝苍白橡树.md)的树干顶端。由树苗生成的苍白橡树中不会出现嘎枝之心。

# 破坏
挖掘嘎枝之心的合适工具是斧。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，嘎枝之心被破坏后会掉落1-3个[树脂团](树脂团.md)。挖掘工具的[时运](时运.md)魔咒会使树脂团额外等概率掉落0-<魔咒等级>个树脂团，但掉落总数不超过9个。

被具有精准采集的工具挖掘破坏时，嘎枝之心被破坏后会掉落自身。

* *自然生成**的嘎枝之心在直接或间接被玩家破坏后，还会掉落。

嘎枝之心被破坏时，将清除绑定的嘎枝。如果是被玩家挖掘直接或间接破坏的，则还会触发玩家的[击杀触发器](进度定义格式#player_killed_entity.md)。

# 用途

|可以使嘎枝之心激活的两种结构示意图}}
嘎枝之心可以放置在不同的方向，类似于[原木](原木.md)。它具有失活、休眠和激活状态，其中初始处于休眠状态。当嘎枝之心两端的方块都是[苍白橡木原木](苍白橡木原木.md)、[](苍白橡木.md)或它们的去皮变种，且朝向与嘎枝之心一致时，嘎枝之心就会脱离失活状态。

# = 周期检查 =
嘎枝之心每游戏刻检查其所处环境，以及绑定的嘎枝的状态。

每次检查中，嘎枝之心会先更新自身状态。如其不处于有效结构中，且没有绑定嘎枝，其将进入失活状态；否则，嘎枝之心在[主世界](主世界.md)的夜晚。}}进入激活状态，其他情况进入休眠状态。如该步中嘎枝之心从其他状态转变到失活状态，则其不会执行后续检查。

随后，嘎枝之心会根据是否绑定嘎枝，执行以下检查：

; 已绑定嘎枝时

如果以下条件有至少一条满足，则将清除绑定的嘎枝：
* 当前时间不为夜晚，且嘎枝没有因为被命名等原因被标记为不能自然删除标签设置为<code>true</code>。}}。
* 嘎枝到嘎枝之心底面中心的[欧几里得距离](欧几里得距离.md)超过34格。
* 在连续5次检查中，嘎枝的边界箱都与某位玩家的视平线相交。

; 未绑定嘎枝时
如满足以下所有条件，嘎枝之心将在周围33×17×33的范围内寻找随机位置生成[嘎枝](嘎枝.md)并与之绑定。
* 嘎枝之心处于激活状态。
* 游戏难度不为和平，且游戏规则不为<code>false</code>。
*

能够生成嘎枝的合适位置需同时满足以下所有条件：
* 下方的方块顶面是完整的，且不能为[树叶](树叶.md)。
* 待生成的位置不能被不完整方块的[碰撞箱](碰撞箱.md)占据，例如[地毯](地毯.md)可以阻止嘎枝生成，但[按钮](按钮.md)不会。
*
* 待生成的位置不能被其他实体的碰撞箱占据。

# = 生成树脂团 =
[thumb|被玩家攻击的嘎枝与其绑定的嘎枝之心之间产生粒子效果并生成树脂团](File:Creaking linked to a creaking heart.jpg.md)
当绑定的嘎枝受到来自玩家或驯服的[狼](狼.md)的伤害时，处于激活状态的嘎枝之心会尝试在周围的、苍白橡木原木、去皮苍白橡木和去皮苍白橡木原木上生成个[树脂团](树脂团.md)。每次生成后有的冷却期，期间不再能生成树脂团。

; 生成细节
该过程中，嘎枝之心将会进行次生成尝试；每次尝试时，以自身为中心、沿相邻的具有标签的方块执行广度优先搜索，最大深度为2；对搜索过程中非自身的方块，将会按随机顺序依次选取一个方向尝试生成树脂团，如生成成功则结束本次生成尝试。

# = 红石比较器 =
嘎枝之心可被[红石比较器](红石比较器.md)检测，输出取决于该嘎枝之心与其绑定的[嘎枝](嘎枝.md)的距离。

若不存在绑定的嘎枝，红石信号强度为零；否则，红石信号强度为<math>15 - \left\lfloor\frac{\min\{d,32\}}{32}\times 15\right\rfloor</math>，其中<math>\lfloor x \rfloor</math>表示向下取整，<math>d</math>为嘎枝之心底面中心至相应嘎枝的[欧几里得距离](欧几里得距离.md)。

# = 闲置音效 =
在夜晚，嘎枝之心处于激活或休眠状态，且六面均被苍白橡木原木、或它们的去皮变种包围时，会播放[闲置音效](#音效.md)。
