* *丛林神庙（Jungle Pyramid）<ref group="注">被称为“Jungle Pyramid”，被称为“Jungle Temple”。</ref>**是一种在[丛林](丛林.md)生物群系自然生成的[结构](结构.md)。

# 生成
丛林神庙生成于[丛林](丛林.md)中，每个丛林有的概率生成丛林神庙。丛林神庙也可能在[竹林](竹林.md)中生成。

丛林神庙可通过[丛林探险家地图](丛林探险家地图.md)定位。与制图师[村民](村民.md)进行交易可获得丛林探险家地图，详见。

# 结构

丛林神庙分为三层，整体由[圆石](圆石.md)、[苔石](苔石.md)和[雕纹石砖](雕纹石砖.md)组成，其墙面还可能覆盖着[藤蔓](藤蔓.md)。

# = 谜题 =

丛林神庙的下层有一个机关室，由3个放置在雕纹石砖上的[拉杆](拉杆.md)组成，它们连接到一个隐藏而狭小的[活塞](活塞.md)门机械房间。隐藏房间里面有一个装有宝物的[箱子](箱子.md)。

# = 陷阱 =
从上述谜题处走下楼有一条通往箱子的走廊。陷阱包含两条[绊线](绊线.md)，它们分别连接着隐藏在藤蔓后面的载有2-14根[箭](箭.md)的[发射器](发射器.md)。第一根绊线在走廊的起点，第二根在箱子前面。触碰绊线或是用[剪刀](剪刀.md)以外的工具破坏绊线，均会触发与其相连的发射器。

# 你知道吗
* 丛林神庙生成时可能会与地形重叠，导致其内部出现不属于神庙组成部分的方块，比如[树叶](树叶.md)。这些方块甚至能覆盖神庙的箱子和发射器或截断红石线路。
* 丛林神庙的地基是一个15×12的长方形。
