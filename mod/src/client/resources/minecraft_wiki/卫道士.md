* *卫道士（Vindicator）**是一种使用[铁斧](铁斧.md)进行攻击的[灾厄村民](灾厄村民.md)。

# 生成
卫道士生成时总携带一把铁斧。铁斧在普通和困难难度中有一定概率（0至25%，具体数值取决于[区域难度](区域难度.md)）附有随机魔咒。

# = 林地府邸 =
卫道士在[林地府邸](林地府邸.md)中的一些特定的房间里生成。有些房间有1个，有些房间有3个，有些房间有2个（并伴有1个[唤魔者](唤魔者.md)）。卫道士还会偶尔生成在走廊里。

在林地府邸里生成的卫道士死亡之后就不会再重新生成，但它们也不会在非和平难度下自然消失。

# = 袭击 =

卫道士可以作为袭击事件的一部分生成。它们在较前的波次中出现的概率较低，但在较后的波次中和困难难度中出现的概率较高。卫道士在袭击中生成时有时会骑着[劫掠兽](劫掠兽.md)。

# 行为
[缩略图|右|200px|一个卫道士正在追逐村民](File:Vindication.png.md)

卫道士与玩家、成年[村民](村民.md)、[铁傀儡](铁傀儡.md)、[流浪商人](流浪商人.md)和敌对。卫道士在攻击目标位于12格范围内时才会对其进行追逐。卫道士不会反击[灾厄村民](灾厄村民.md)、。

卫道士攻击时会伸出主手，将斧举起，并将另一只手前后摆动。卫道士追逐攻击对象时，速度与玩家或相当。卫道士的近战攻击伤害非常高。

卫道士空闲时会像[村民](村民.md)那样把胳膊盘起来，此时它们手中的斧不会显示出来。主手未持有物品的卫道士会像僵尸一样举起双臂。

卫道士用斧攻击玩家时，玩家的[盾牌](盾牌.md)会暂时失效，即使它正在骑乘其他生物也是如此。

卫道士会主动远离[嘎枝](嘎枝.md)。

# = Java版 =
如果卫道士被其他生物所攻击，附近的卫道士会对该生物产生敌意。

在所有难度下，不处于袭击且正在巡逻中受到伤害的卫道士会召唤半径8格内的所有[灾厄村民](灾厄村民.md)、[女巫](女巫.md)和[劫掠兽](劫掠兽.md)攻击伤害它的生物。

敲[钟](钟.md)会给予半径48格内的卫道士的[发光](发光.md)效果。

# = 基岩版 =
卫道士在空闲时仍使用奔跑的速度移动。

[发射器](发射器.md)可以给卫道士装备[盔甲](盔甲.md)，但盔甲不会显示，且卫道士死亡后不会掉落盔甲。

# = 生物族群 =

卫道士是[灾厄村民](生物#灾厄村民.md)，不会被[唤魔者](唤魔者.md)的尖牙伤害，不会被[劫掠兽](劫掠兽.md)的咆哮伤害，不会被[“Johnny”卫道士](#“Johnny”卫道士.md)攻击。卫道士可以加入正在发生的袭击，即使不是在袭击事件中被生成的。卫道士与其他灾厄村民之间即使发生了误伤也不会相互攻击。

# = 袭击 =
在普通和困难难度下，袭击期间生成的卫道士能够破坏周围的[木门](木门.md)和[铜门](铜门.md)。<ref></ref> 袭击期间卫道士也可以像[村民](村民.md)那样把木门或铜门打开。

如果在袭击事件期间所有的村民死亡，或者所有村民的[床](床.md)被破坏，那么它们会欢呼并举起手臂跳动以庆祝胜利。

卫道士在袭击中未到达村民方块附近时不会主动攻击或追击与其敌对的生物，即使与卫道士敌对的生物伤害了卫道士。

# = “Johnny”卫道士 =
如果一个卫道士被命名为“Johnny”（使用[命名牌](命名牌.md)、已被命名的[刷怪蛋](刷怪蛋.md)等），或者卫道士的实体数据<code>Johnny</code>被设为<code>1b</code>，它会攻击除了[灾厄村民](灾厄村民.md)、[恶魂](恶魂.md)、</ref>、幼年[村民](村民.md)<ref></ref><ref></ref>|JE}}和以外的所有生物。[劫掠兽](劫掠兽.md)、、被“Johnny”卫道士攻击后不会反击，除此之外其他具有反击能力的生物都会尝试反击。

实体数据覆盖了卫道士的名字，因此[玩家](玩家.md)可以给一个卫道士设置一个其他的名字并把实体数据<code>Johnny</code>设置为<code>1b</code>，它依然会有上述行为。反之，你可以把一个卫道士命名为“Johnny”并设置实体数据<code>Johnny</code>为<code>0b</code>，此时它不会有上述行为。

另外，如果实体数据<code>Johnny</code>为<code>1b</code>的卫道士在一个[队伍](命令/team.md)中，那么它会无差别攻击其他队伍和没有队伍的生物（包括灾厄村民）。同时，实体数据<code>Johnny</code>为<code>1b</code>的卫道士永远不会攻击同一队伍的生物。

* 根据《[我的世界生物图鉴](Minecraft丛书#指南书.md)》书中的描述，卫道士的智力与僵尸无异，只是比僵尸生命值更高一点罢了，[Cory Scheviak](Cory Scheviak.md)曾说过卫道士的AI可能会有点傻（derpy）。<ref></ref>
