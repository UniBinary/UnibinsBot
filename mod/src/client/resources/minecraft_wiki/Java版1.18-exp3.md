* *1.18-exp3（1.18 experimental snapshot 3）**是[Java版1.18](Java版1.18.md)的第3个实验性快照，发布于2021年8月10日<ref></ref><ref></ref>，对[生物群系](生物群系.md)的分布和地形的生成方式进行了一些调整。此版本单独发布，故不出现在[启动器](启动器.md)版本列表中。

# 新内容
# = 世界生成 =
* *[山地](山地.md)**
* 加入了新的山地变种生物群系：[裸岩山峰](裸岩山峰.md)。
* * [尖峭山峰](尖峭山峰.md)和[冰封山峰](冰封山峰.md)的未覆雪变种，裸露出[石头](石头.md)和条带状的[沙砾](沙砾.md)地层。
* * 用于避免前两种生物群系紧靠[温度](温度.md)较高的生物群系生成。

# 更改
# = 生物 =
* *常规**
* [生物](生物.md)的生成速度不再在低处增加或在高处减少。新生成速度类似于[1.17](Java版1.17.md)中高度为64处的速度。
* * 此更改旨在使更新后的主世界中的生物生成更加一致。

# = 世界生成 =
* *[含水层](含水层.md)**
* 现在能延伸到更深的区域，且更有可能与更低处的洞穴系统相连接。
* 含水层的规模现在更富于变化，以降低充满水的巨型洞穴出现的频率。
* * 地下的湖泊和积水区域现在更加分散，而不是聚集在一起。

* *[恶地](恶地.md)**
* 调整了恶地的生成，使其有时会出现在高原附近的平坦区域，并使红沙生成得更高。
* [风蚀恶地](风蚀恶地.md)生物群系中不再出现浮在水面上方的岩柱。

* *[沙滩](沙滩.md)**
* 略微调整了沙滩的生成方式，现在其更倾向于出现在平坦的海岸边，而不是起伏较大的区域。
* 降低了[石岸](石岸.md)的生成概率。

* *[沙漠神殿](沙漠神殿.md)**
* 为了适应地形的变化，现在总会在地表生成，而不是在固定高度生成。

* *[山地](山地.md)**
* 降低了尖峭山峰、冰封山峰和[草甸](草甸.md)生物群系在低海拔地区的生成概率。
* [积雪山坡](积雪山坡.md)和冰封山峰生物群系不再在[雪](雪.md)下方生成[泥土](泥土.md)。

* *[掠夺者前哨站](掠夺者前哨站.md)**
* 现在会在所有新的山地生物群系生成。

* *[沼泽](沼泽.md)**
* 不再与寒冷的或干燥的生物群系重叠，也不再生成悬浮的水。

* *[村庄](村庄.md)**
* 现在会在草甸生物群系中生成。

* *[生物群系](生物群系.md)**
* 调整了生物群系的分布，降低了[温度](温度.md)相差很大的生物群系相邻的可能性。
* 回-{}-调了[1.18-exp2](Java版1.18-exp2.md)中对生物群系生成的一些更改，重新使其分布和规模更富有变化。
* * 这意味着小片的生物群系又变得更常见了，但现在相邻的生物群系一般会有相近的温度（如[平原](平原.md)里出现一小片[森林](森林.md)）。

* *常规**
* 将碎地形里的悬崖调整得稍微更平滑，使它们看起来不像是区块错误。
* 降低了海岸与河流的地形生成被[含水层](含水层.md)干扰的概率。
* * 不与河流或海洋相邻区域的水体高度主要由局部水面高度（独立于海平面高度）决定。
* * 与海洋或河流相交的洞口和[峡谷](峡谷.md)将主要使用海平面决定水面高度。
* 降低了在内陆低海拔地区充水洞穴的生成概率。
* [草](草.md)不再会生成在水底。
* 降低了在错误位置上放置地物的概率，如沙漠中生成草丛。
* 减少了在干涸峡谷中生成河流的概率。

# 修复
* 修复了山羊不在新的山地生物群系正常生成的问题。
* 修复了多人游戏中（尤其是在其他玩家正在飞行时）玩家所遇到敌对生物数量过多或过少的问题。现在，每个玩家所遇到敌对生物的数量都是均衡的。</onlyinclude>
