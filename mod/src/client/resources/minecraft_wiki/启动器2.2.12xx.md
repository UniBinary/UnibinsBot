# 启动器2.2.12xx

*页面ID: 75434* | *来源: Minecraft Wiki*

* *2.2.1259**（[Windows](wzh:Microsoft Windows.md)与[Dungeons](MCD:启动器.md)）、**2.2.1260**（[macOS](wzh:MacOS.md)）或**2.2.1262**（[Linux](wzh:Linux.md)）是一次[启动器](启动器.md)更新，发布于2021年1月14日。

# 更改
* 将图例上的Steve缩放至3个方块高。

# 修复
* 对账户创建功能进行了更改，有望修复灰屏的问题。
* 修复了使用从右至左的语言时钥匙傀儡的间距问题。
* 为更新说明中的链接加入了外部打开图标。
*  - 在登录Microsoft账户的情况下登录又注销Mojang账户会使启动器暂时处于离线状态。
*  - Minecraft打开两次。
