# 睡莲

*页面ID: 7589* | *来源: Minecraft Wiki*

* *睡莲（Lily Pad）**是一种生长在[沼泽](沼泽.md)水上的[非固体方块](方块基本属性#固体方块.md)。

# 生成
# = 自然生成 =
睡莲自然生成在沼泽和[红树林沼泽](红树林沼泽.md)生物群系内的[水](水.md)上。

睡莲也会在[林地府邸](林地府邸.md)的[小麦农场房间](林地府邸/结构/农场#小麦农场.md)中生成。

# 获取
# = 钓鱼 =
在[钓鱼](钓鱼.md)时，睡莲会作为“[垃圾](钓鱼#垃圾与宝藏.md)”（不包括[丛林](丛林.md)、[竹林](竹林.md)和[稀疏丛林](稀疏丛林.md)生物群系）物品被钓上来。

# = 交易 =

# 破坏
睡莲被挖掘时会立刻被破坏。

睡莲被[船](船.md)或[运输船](运输船.md)穿过时也会被破坏。

睡莲被破坏后会掉落自身。

# 用途
睡莲的碰撞箱为格。

睡莲的一种主要用途是在水上创造可行走的路径，而不需要建造桥梁或使用完整的[方块](方块.md)。当水流到睡莲上时，睡莲会被破坏并掉落为物品。

生物不能在睡莲上生成。

# = 放置 =
睡莲能够放在[水](水.md)、[冰](冰.md)、[霜冰](霜冰.md)或[含水方块](含水方块.md)（例如[台阶](台阶.md)、[楼梯](楼梯.md)、[栅栏](栅栏.md)）的上方。睡莲占据水上方的方块，而不是水方块的一部分。

睡莲会在其附着的方块被替换为除[水](水.md)、[冰](冰.md)、[霜冰](霜冰.md)和[含水方块](含水方块.md)以外的方块的情况下被破坏并掉落自身。

睡莲朝向一个固定的方向，这个方向取决于它们所在的位置，且不被玩家放置睡莲时的朝向影响。替换睡莲不会改变睡莲的方向。

不像大多数方块，睡莲在放置时不会检查实体碰撞。<ref></ref><ref></ref>

# = 堆肥 =
对着[堆肥桶](堆肥桶.md)睡莲有65%的概率增加一层堆肥层。

# 你知道吗
* 当睡莲叶放置在未占据整个方块空间的水源方块上（特别是水流向相邻方块时），睡莲会显示为悬浮在水源方块上方的样子。
* 如果玩家在睡莲上疾跑或摔落，睡莲会产生水粒子。这是因为技术上游戏认为玩家处于睡莲下方的水上。
* 普通的方块可以从下方放置到睡莲底部。这样做会使睡莲被破坏，但先前放置的方块会留在原位。该特性使得玩家可以在水面凭空放置方块。
