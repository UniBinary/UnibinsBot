* *孢子花（Spore Blossom）**是一种会散发“孢子”[粒子](粒子.md)的植物[方块](方块.md)。

# 生成
# = 自然生成 =
孢子花会在[繁茂洞穴](繁茂洞穴.md)的洞顶自然生成。

# 获取
孢子花只能通过破坏孢子花获得。

# 破坏
孢子花被挖掘时会立刻被破坏。

孢子花被破坏后会掉落自身。

# 用途
孢子花会滴落绿色的“孢子”[粒子](粒子.md)，还会向周围散发这种粒子，使其在一定范围内的空气中飘飞弥漫。

不同于其他的[花](花.md)，孢子花能够被放置在任何底面[中心完整](方块支撑形状.md)的方块底部。

# = 蜜蜂 =

孢子花可用于吸引、繁殖[蜜蜂](蜜蜂.md)以及加速幼年蜜蜂的成长。蜜蜂也会采集它的花粉。

# = 堆肥 =
将孢子花放进[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数加1。

# 你知道吗
* 现实中，花是[种子植物](wzh:种子植物.md)特有的器官，而藻类、苔藓和蕨类等则是典型的[孢子植物](wzh:孢子植物.md)。从现实的角度来看，孢子花散发的“孢子”或许是似孢子的花粉（配子体）。
