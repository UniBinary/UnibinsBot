# 地图存储格式

*页面ID: 9292* | *来源: Minecraft Wiki*

* *地图计数存储文件**和**地图数据存储文件**是存档中存储[地图](地图.md)数据的文件。

# 地图计数存储格式
游戏在使用地图时，会给每张独立的地图分配一个**地图编号**（Map ID）。游戏使用地图计数存储文件用于存储最后一个已用的地图编号。

地图计数存储文件位于{{filepath|-{}-<*存档根目录*>/data/idcounts.dat}}，地图计数存储文件位于{{filepath|-{}-<*存档根目录*>/data/minecraft/maps/last_id.dat}}，使用GZip压缩的[NBT](NBT.md)文件格式保存，其内部有下列NBT结构：

<div class="treeview">
*  根标签
* * ：地图计数数据。
* ** ：最后一个已用的地图编号。
* * ：保存此地图计数存储文件的游戏的[数据版本](数据版本.md)。如果此项不存在则游戏认为此项是1343（[Java版1.12.2](Java版1.12.2.md)）。
</div>

# 地图数据存储格式
游戏不会将地图数据存入地图物品中，而是在存档内单独存储地图数据。地图数据存储文件也被官方称为**地图索引文件（Map index files）**<ref></ref>。

地图数据存储文件位于{{filepath|-{}-<*存档根目录*>/data/map_<*地图编号*>.dat}}，地图计数存储文件位于{{filepath|-{}-<*存档根目录*>/data/minecraft/maps/<*地图编号*>.dat}}，使用GZip压缩的NBT文件格式保存，其内部有下列NBT结构：

<div class="treeview">
*  根标签
* * ：地图数据。
* ** ：[旗帜](旗帜.md)标记数据。
* *** ：一个旗帜标记。
* **** ：（旗帜的颜色，见[颜色](颜色.md)。如果不存在则为<code>white</code>（白色）。
* **** ：（[文本组件](文本组件.md)）旗帜标记的名称，使用对应旗帜的名称。
* **** ：旗帜在世界中的位置。
* ** ：地图内部的渲染颜色阵列，总长度16384。如果此数组长度不是16384，游戏将不读取此数组，而是使用全部为0的数组替换。格式见下文。
* ** ：（命名空间ID）地图所记录的维度。
* ** ：[物品展示框](物品展示框.md)显示数据。
* *** ：一个物品展示框的数据。
* **** ：此物品展示框的实体ID。
* **** ：物品展示框在世界中的位置。
* **** ：物品展示框的旋转角度，以角度计。此值对应水平平面内的旋转，如果物品展示框是向上或向下，则为-90。
* ** ：地图是否已被锁定。锁定后的地图无法更新内部的显示数据，也不会更新旗帜标记。
* ** ：（）地图的缩放等级。
* ** ：地图是否追踪并显示在地图显示范围内的手持此地图的[玩家](玩家.md)和物品展示框的位置。当此值不存在时游戏默认为<code>true</code>。
* ** ：地图是否显示距离地图显示范围[切比雪夫距离](切比雪夫距离.md)大于320格的正在手持此地图的玩家，这些玩家会以更小的点渲染（地图图标<code>player_off_limits</code>）。
* ** ：地图中心的世界X坐标。
* ** ：地图中心的世界Z坐标。
* * ：保存此地图数据存储文件的游戏的数据版本。如果此项不存在则游戏认为此项是1343（[Java版1.12.2](Java版1.12.2.md)）。
</div>

记录了地图上每一个点的颜色。地图边长为128，内部有16384个点。假设地图内像素点*P*，按照地图左上角为原点，其横坐标为*x*，纵坐标为*z*，那么这个点在数组内的下标是<math>x+128z</math>。每个字节都表示一个颜色，这个颜色并不是真正的RGB或灰度值，而是**地图色***C*。

地图色*C*按照二进制位分为两个部分：高6位代表**地图基色***B*，低2位代表**颜色修饰***M*。下列代码演示了如何计算地图色：

<syntaxhighlight lang="java">
public static byte getMapColor(int baseColor, int modifier) {
	return (byte) (baseColor << 2 | modifier & 3);
}

public static int getBaseColor(byte mapColor) {
	return (((int) mapColor) & 0xFF) >> 2;
}

public static int getModifier(byte mapColor) {
	return mapColor & 3;
}
</syntaxhighlight>

地图基色*B*是由游戏硬编码的颜色，是一个枚举，共有62种地图基色。颜色修饰*M*有4种，对地图基色提供的RGB颜色进行进一步修改。下表为颜色修饰*M*的取值和对地图基色的影响：

# 存储行为
如果存档内没有创建过任何一张地图，那么地图计数存储文件和地图数据存储文件都不存在。当有玩家创建第一张地图时，这两个文件才会被创建和写入。

如果地图计数存储文件内的地图编号是一个已经存在的地图编号，当游戏创建新的地图时，新的地图会覆盖使用同地图编号的地图。

# 地图更新行为
地图并不是时刻都在更新，也不是所有数据都会同步到地图数据内，部分数据由地图物品保存而不是地图数据保存。

在满足下列条件下，地图内的渲染颜色阵列数据会被更新：
* 地图未被锁定。（为<samp>false</samp>）
* 玩家由主手或副手拿着对应地图编号的地图。
* 地图所记录维度与玩家所在维度一致。

更新地图的范围为玩家为中心、水平半径128格的世界范围。如果维度类型为<samp>true</samp>，即维度具有天花板（例如[下界](下界.md)），那么距离减半，变为64格。如果更新范围内的某个区块未被加载，则这个区块内的地图数据不被更新。

地图颜色按照下列算法计算：
# 定义缩放范围<math>r=2^s</math>，其中*s*是的值。
# 对于每个地图内的像素点，定义平均高度<math>\bar{h}</math>，计算地图基色*B*和平均流体深度<math>\bar{d}</math>：
# * 如果维度有天花板，定义平均高度<math>\bar{h}</math>固定为100，平均流体深度<math>\bar{d}</math>固定为0。根据转换后的世界坐标，填充[泥土](泥土.md)的地图基色（DIRT）或[石头](石头.md)的地图基色（STONE）：
# ** 定义世界坐标为<math>(x, ?, z)</math>，计算<math>31287121(x+231871z)^2+11(x+231871z)</math>，转换为二进制后取第21位。如果是0则为泥土，1为石头。
# * 如果维度没有天花板，则取像素点转换到世界坐标后*r*&times;*r*大小的范围：
# *# 计算这个范围内[高度图](高度图.md)<code>WORLD_SURFACE</code>（最高非空气方块高度）的平均高度作为<math>\bar{h}</math>。
# *# 对于范围内的每个水平坐标：
# *## 如果此水平坐标只有空气，则认为控制地图基色的方块是[基岩](基岩.md)，不进行后续流程。
# *## 从最高非空气方块开始遍历，直到找到一个地图基色不为NONE的方块。如果此水平坐标没有任何地图基色不为NONE的方块，则取最低的方块。
# *## 如果找到的方块含有流体（[水](水.md)、[熔岩](熔岩.md)或任意[含水](含水.md)方块），继续向下查找直到找到第一个不含流体的方块，此方块与之前找到的方块的距离即为流体深度*d*。
# *## 如果找到的方块不含有流体，那么取这个方块作为控制地图基色的方块；如果含有流体，计算方块上表面是否完整，如果完整则仍然取这个方块作为控制地图基色的方块，否则认为流体方块是控制地图基色的方块。计算控制地图基色的方块的地图基色，并记录。
# *# 计算范围内所有流体深度的平均值作为平均流体深度<math>\bar{d}</math>，取出现次数最多的地图基色作为此像素点的地图基色*B*。
# 计算颜色修饰*M*：
# * 如果像素点的地图基色*B*是WATER：
# ** 设像素点位置为<math>(u,v)</math>，计算<math>m=0.1\bar{d}+0.2(u+v \mod 2)</math>。
# *** 如果*m*大于0.9，则颜色修饰为LOW；如果*m*小于0.5，则颜色修饰为HIGH；其他情况下为NORMAL。
# *** 这代表了平均流体深度小于3格时颜色修饰为HIGH，不小于3格且小于5格时为HIGH和NORMAL渐变，不小于5格且小于7格时为NORMAL，不小于7格且小于9格时为NORMAL和LOW渐变，不小于9格时为LOW。
# * 如果像素点地图基色*B*不是WATER：
# ** 获取上方像素点的平均高度<math>\bar{h'}</math>（如果没有上方像素点则假设上方有一个像素点并进行上一步操作计算数据），设像素点位置为<math>(u,v)</math>，计算<math>m=\frac{4(\bar{h}-\bar{h'})}{r+4}+0.4((u+v \mod 2) - 0.5)</math>。
# *** 如果*m*大于0.6，则颜色修饰为HIGH；如果*m*小于-0.6，则颜色修饰为LOW；其他情况下为NORMAL。
# *** 如果缩放等级为0，此公式退化为：如果北方方块高于此方块，则颜色修饰为LOW；如果北方方块与此方块同等高度，则颜色修饰为NORMAL；如果北方方块低于此方块，则颜色修饰为HIGH。
# 按照计算得出的地图基色*B*、颜色修饰*M*，计算地图色*C*写入地图渲染颜色阵列数据。

[350px|thumb|right|使用了带有起伏的方块结构制作一幅像素画](File:Map Pixel Art Train.jpg.md)

当所有方块都处于一个高度时，使用缩放等级为0的地图只会使用62种颜色；但如果方块按照南北方向起伏，则可以使地图拥有186种颜色。这种方式可以扩展地图的颜色，以丰富地图上的色彩呈现。

对于[探险家地图](探险家地图.md)，地图颜色在物品生成时就被决定，只有在玩家后续更新后才会变成真正和世界同步的地图颜色。探险家地图的地图颜色计算如下：
# 获取所有像素点对应世界坐标的[生物群系](生物群系.md)，标记带有<code>#water_on_map_outlines</code>标签（默认为河流类、海洋类、沼泽类生物群系）的生物群系为水系像素点，其他群系则为陆地像素点。
# 遍历所有像素点：
# * 获取周围8个像素点是水系像素点的数量*w*。
# * 如果此像素点不是水系像素点，且*w*为0，则地图基色为NONE，颜色修饰为LOWEST。
# * 如果此像素点不是水系像素点，但*w*大于0，则地图基色为BROWN。当*w*大于3时颜色修饰为NORMAL，否则为LOWEST。
# * 如果此像素点是水系像素点，则地图基色为COLOR_ORANGE，设像素点坐标为<math>(u,v)</math>：
# ** 如果*w*为8，且*v*为偶数，计算<math>m=u+7\sin v</math>，对*m*按位右移3位后对5取余。如果*m*本身为负数，则颜色修饰为LOWEST；如果结果为0或4，则为LOW；如果为1和3，则为NORMAL;如果为2，则为HIGH。
# ** 如果*w*为8，且*v*为奇数，则地图基色为NONE，颜色修饰为LOWEST。
# ** 如果*w*为6或7，则颜色修饰为NORMAL。
# ** 如果*w*为2、3、4、5，则颜色修饰为LOW。
# ** 如果*w*为0或1，则颜色修饰为LOWEST。

地图的旗帜数据和物品展示框数据由地图数据保存。当玩家使用地图物品加入或删除旗帜标记时，数据会立刻同步到地图数据内。当地图物品放入物品展示框或被移出物品展示框时，地图数据也会立刻被更新。但是除了旗帜标记和物品展示框标记外，其他标记数据都由物品数据保存，例如探险家地图上的标记。换言之，地图的渲染颜色阵列、旗帜标记、物品展示框标记、缩放、锁定是全世界同步的，只要保证地图编号一致，数据就会立刻被全局同步；但是，额外的标记不会被全局同步，因为它们在地图物品数据中而不是全局的地图数据内。
