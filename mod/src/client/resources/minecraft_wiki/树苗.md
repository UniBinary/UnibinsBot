# 树苗

*页面ID: 10250* | *来源: Minecraft Wiki*

* *树苗（Sapling）**是一类能够生长为[树](树.md)的[植物](植物.md)，包括**橡树树苗**、**白桦树苗**、**云杉树苗**、**丛林树苗**、**金合欢树苗**、**深色橡树树苗**、**樱花树苗**、**苍白橡树树苗**。

# 生成
# = 自然生成 =
; 云杉树苗
云杉树苗盆栽自然生成在[针叶林](针叶林.md)和[村庄](村庄.md)的石匠房子里。

; 白桦树苗
白桦树苗盆栽自然生成于[林地府邸](林地府邸.md)的一些房间里。

; 深色橡树树苗
林地府邸的[树苗房](林地府邸/结构/装饰品房间#树苗房.md)里会生成58个深色橡树树苗。

; 金合欢树苗
金合欢树苗自然生成在[热带草原](热带草原.md)村庄的图书馆里。

# 获取
# = 树叶 =
当[树叶](树叶.md)自然枯萎消失或被破坏（不使用[精准采集](精准采集.md)附魔工具或[剪刀](剪刀.md)）时，它们有5%的概率掉落1个相应种类的树苗（杜鹃树叶掉落杜鹃花丛；盛开的杜鹃树叶掉落盛开的杜鹃花丛）；丛林树叶为例外，它有2.5%的概率掉落1个丛林树苗。

[时运](时运.md)魔咒会增加树苗的掉落概率，等级I为6.25%（丛林树叶为2.78%），等级II为8.33%（丛林树叶为3.1255%），等级III为10%（丛林树叶为4.17%）。

# = 箱子战利品 =

# == 林地府邸 ==
[林地府邸](林地府邸.md)的[树苗房](林地府邸/结构/装饰品房间#树苗房.md)内总是会生成1个[箱子](箱子.md)，当中有28个深色橡树树苗。

# 破坏
树苗被挖掘时会立刻被破坏。

树苗被破坏后会掉落自身。

# 用途
# = 生长 =
[thumb|一棵种在光照和空间充足的洞穴中的橡树](File:UndergroundTree.png.md)

树苗可被种植在[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[草方块](草方块.md)、[灰化土](灰化土.md)、[砂土](砂土.md)、[菌丝体](菌丝体.md)、[耕地](耕地.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[泥巴](泥巴.md)和[沾泥的红树根](沾泥的红树根.md)上。允许被种植到的方块由标签控制。

树苗的生长由[随机刻](随机刻.md)控制。在长成树木之前，树苗有2个生长阶段（在视觉上没有差异）。处于第2个生长阶段的树苗尝试生长时，游戏会指定树的高度，然后检查生长条件。若不符合条件，则取消这次生长。树苗上方1格的[亮度](亮度.md)等级（在方块光照和天空光照中取较大值）至少为9时，树苗才能生长成[树木](树木.md)。

树苗上方的[树叶](树叶.md)、标签的方块}}、通常不会阻止其生长，但有一些例外。长出的树木会穿过这些方块，有时还能将它们替换掉。

若树叶没有生成，则判定生长失败，但仍然生成原木，且保留树苗（会显示成原木）。

[缩略图|250px|右|大型云杉/松树使土类方块转变为灰化土的最大范围（上方是北）](File:PodzolPattern.png.md)

树苗生长时，若树苗下方1格的方块为草方块、菌丝体、，则它会被替换成泥土，若方块为耕地则会因其上为固体方块而退化；2×2空间摆放的4个云杉树苗生长时则会将下方4个方块替换为[灰化土](灰化土.md)，同时将周围的草方块、泥土、缠根泥土、[砂土](砂土.md)、菌丝体、苔藓块、[苍白苔藓块](苍白苔藓块.md)、泥巴、沾泥的红树根和转变为灰化土。

树苗生长所需的空间依其种类不同而有不同。如无特殊说明，下文中的“空间”指的是一个仅包含**不阻止树苗生长**的方块的区域。

# == Java版 ==
* 橡树树苗需要上方至少有3×5×3的空间；若这一空间里（不包含正上方一格）存在阻止该树苗生长的方块，其只会长成为[珍异橡树](橡树#珍异橡树.md)；若树苗上方存在3×4×3的空间，其会长成5格高的球形珍异橡树。
* 白桦树苗需要上方至少有3×6×3的空间。
* 单个云杉树苗需要上方至少有5×6×5的空间。
* * 在2×2空间内摆放的4个云杉树苗，以西北角树苗为基准，需要上方至少有5×14×5的空间，并且树苗周围至少有3×1×3的空间。
* 单个丛林树苗需要上方至少有3×5×3的空间。
* * 在2×2空间内摆放的4个丛林树苗，以西北角树苗为基准，需要上方至少有5×11×5的空间，并且树苗周围至少有3×1×3的空间。
* 金合欢树苗需要上方至少有5×6×5的空间。
* 单个深色橡树树苗和苍白橡树树苗无法生长。
* * 在2×2空间内摆放的4个深色橡树树苗和苍白橡树树苗，以西北角树苗为基准，需要上方至少有3×7×3的空间。
* 樱花树苗需要上方至少有5×8×5的空间。

# = 生成蜂巢 =
若、白桦或樱花树苗水平2格范围内存在[花](花.md)、，则该树苗长成的树会有5%的概率悬挂着[蜂巢](蜂巢（方块）.md)；即使周围不存在花，橡树树苗长成的树也有5%的概率悬挂着蜂巢<ref></ref>。每个由此生成的蜂巢都会容纳1-3只[蜜蜂](蜜蜂.md)。

# = 装饰 =
任何类型的树苗都可以被放在[花盆](花盆.md)里。

# = 燃料 =
树苗可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个树苗可[烧炼](烧炼.md)0.5个物品。

# = 堆肥 =
将树苗放进[堆肥桶](堆肥桶.md)里有30%概率增加1个堆肥层。

# 你知道吗
* 如果[玩家](玩家.md)站在树苗的位置，此时[树](树.md)仍然能长大，除了[红树](红树.md)以外的树木种类在此时长大可能会使玩家[窒息](窒息.md)。
* 树苗生长的过程本质上是放置了[地物](地物.md)，因此如果使用命令将树苗放置在不具有<code>#dirt</code>标签的方块（如[圆石](圆石.md)）上，则树苗生长时也会将其替换成[泥土](泥土.md)或[灰化土](灰化土.md)（若为大型云杉）。
* 尽管樱花树苗在纹理上表现为长有樱花，但并不能被[蜜蜂](蜜蜂.md)采集花粉或用于繁殖蜜蜂。
