# Java版Classic 0.0.20a 01

*页面ID: 35436* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.20a_01**是的一次更新，发布于2009年6月20日。<ref name="blog"> – 这篇博客提到了在[IRC记录](#logs.md)中也提到的关于玩家可以放置不可破坏方块的漏洞： "*P4:09:25 <Notch> new minecraft-server.zip that doesn't allow that block*" (21:09:25 UTC)，因此这篇博客*确实*与该版本有关。</ref><ref>[IRC记录](#logs.md): "*P4:11:32 <Awol10> wingboy: tried downloading again. the jar file should have an 11:09pm timestamp*" (21:11:32 UTC)</ref>

# 更改
# = 游戏内容 =
* *[快捷栏](快捷栏.md)**
* [泥土](泥土.md)和[圆石](圆石.md)分别被移动到快捷栏的第三和第二格。<ref>[IRC记录](#logs.md): "*P5:05:09 <mezo> notch, in the last version dirt was 2 and cobble was 3, now it's the other way around*" [...] "*P5:05:23 <Notch> ah! that's intentional, mezo*" (22:05 UTC)</ref>

# 修复
* *修复了3个漏洞**
* 修复了一个导致客户端可以放置不可破坏方块的漏洞。<ref name="blog"/>
* 修复了一个协议错误。<ref name="blog"/>
* 修复了FPS的问题。<ref name="FPS and water">[IRC记录](#logs.md):  "*P4:13:25 <Notch> does it work better now?*" [...] "*P4:13:36 <LKA> Notch: FPS is fine now but water transparency is broken now*" (21:13 UTC)</ref></onlyinclude>
