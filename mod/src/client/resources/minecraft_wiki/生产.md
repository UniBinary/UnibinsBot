# 生产

*页面ID: 6749* | *来源: Minecraft Wiki*

[350px|thumb|right|一个小型的[[胡萝卜](File:Small farm.png.md)与[马铃薯](马铃薯.md)田]]
* *生产（Farming）**指有目的、系统性地获取[可再生资源](可再生资源.md)的活动。生产的目标产物通常为[食物](食物.md)、方块、[经验](经验.md)等。一些具体的形式介绍如下：

# 关于生物
;
  用[小麦](小麦.md)、种子、[胡萝卜](胡萝卜.md)来繁殖动物，以收集[鸡蛋](鸡蛋.md)、[奶](奶.md)、[羊毛](羊毛.md)等物品。
;
  建造刷怪的空间，以获得它们的掉落物。
;
  通过建造屋子和床，或是治疗僵尸村民来生成更多村民。

# 获得经验
;
  通过在留在刷怪笼附近来激活它进行刷怪。

# 耕种食物
;
  种植[小麦](小麦.md)、[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)、[甜菜根](甜菜根.md)这四种主食作物。
;
  种植[西瓜](西瓜.md)来获得[西瓜片](西瓜片.md)，种植[南瓜](南瓜.md)。

# 获得方块
;
  获得[圆石](圆石.md)用于基本的建造。
;
  建造坚实的建筑。
;
  制作一个能稳定地自然生成冰的场地。
;
  种植[树木](树木.md)以得到[木头](木头.md)、[树苗](树苗.md)和[苹果](苹果.md)。
;
  种植[仙人掌](仙人掌.md)以获得[绿色染料](绿色染料.md)或制作[陷阱](Tutorial:陷阱.md)。
;
  种植[南瓜](南瓜.md)以获得[雕刻南瓜](雕刻南瓜.md)及[南瓜灯](南瓜灯.md)。
;
  种植[藤蔓](藤蔓.md)以制作梯子或是合成[苔石](苔石.md)和[苔石砖](苔石砖.md)。

# 获得物品
;
  种植[下界疣](下界疣.md)以[酿造](酿造.md)。
;
  种植[蘑菇](蘑菇.md)以制作[蘑菇煲](蘑菇煲.md)或生成[巨型蘑菇](巨型蘑菇.md)。
;
  种植[可可豆](可可豆.md)以制作[曲奇](曲奇.md)或为[羊毛](羊毛.md)染色。
;
  种植[甘蔗](甘蔗.md)以获得[糖](糖.md)，制作[蛋糕](蛋糕.md)的原料。
;
  刷[鸡蛋](鸡蛋.md)来制作[蛋糕](蛋糕.md)或生成[鸡](鸡.md)。
;
  通过困住一个[雪傀儡](雪傀儡.md)来获得在它脚下产生的[雪](雪.md)。
;
  将在[村庄](村庄.md)中自然生成的[铁傀儡](铁傀儡.md)成体系地杀死来获得[铁锭](铁锭.md)。
;
  种植[紫颂果](紫颂果.md)以食用，或用来制作[爆裂紫颂果](爆裂紫颂果.md)以合成[紫珀块](紫珀块.md)。
;
  通过在[下界](下界.md)和[主世界](主世界.md)的[下界传送门](下界传送门.md)杀[僵尸猪灵](僵尸猪灵.md)获取[金粒](金粒.md)。
;
  你可以通过[钓鱼竿](钓鱼竿.md)钓鱼以获取[鱼](鱼.md)、[经验](经验.md)和一些其他的物品。
