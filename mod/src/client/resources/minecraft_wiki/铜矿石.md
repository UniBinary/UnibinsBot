# 铜矿石

*页面ID: 70613* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *铜矿石（Copper Ore）**是一种生成于地下的[矿石](矿石.md)方块。

* *深层铜矿石（Deepslate Copper Ore）**是以[深板岩](深板岩.md)作为容矿岩的铜矿石变种。

# 生成
# = 自然生成 =
# == 矿团 ==
铜矿石会以[矿团](矿团.md)的形式在[主世界](主世界.md)Y=-16至112的区域生成，其中Y=47至48处分布得最多，向两端递减。矿团大小为0-10个方块，每[区块](区块.md)尝试生成16次。但[溶洞](溶洞.md)生物群系中铜矿团的规模约为其他生物群系中的2倍。

生成于[深板岩](深板岩.md)或[凝灰岩](凝灰岩.md)间的铜矿石会被替换为深层铜矿石。

# == 矿脉 ==
在Y=0至50的高度范围间，铜矿石还会在罕见的[铜矿脉](铜矿脉.md)中伴随[花岗岩](花岗岩.md)生成。

# 获取
铜矿石和深层铜矿石只能通过破坏对应方块获得。

# 破坏
挖掘铜矿石和深层铜矿石的合适工具是镐。铜矿石和深层铜矿石需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，铜矿石和深层铜矿石被破坏后会掉落2-5个[粗铜](粗铜.md)，挖掘工具的[时运](时运.md)魔咒会增加粗铜的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，铜矿石和深层铜矿石被破坏后会掉落自身。

# = 烧炼材料 =

# = 山羊冲撞 =
[山羊](山羊.md)在冲撞铜矿石时会掉落[山羊角](山羊角.md)。
