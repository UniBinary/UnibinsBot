# 控制

*页面ID: 7606* | *来源: Minecraft Wiki*

不同的平台上使用不同的**控制（Control）**方式。使用键盘和鼠标控制。会根据平台提供不同的控制方式。在[选项](选项.md)或[设置](设置.md)中可以找到游戏的控制菜单。

# Java版
# = 无法设置的键位 =
Minecraft Java版结合使用键盘和鼠标进行控制。默认配置下单独只用鼠标或键盘都不能控制游戏。之前的许多游戏（例如DOOM、Quake和其他FPS游戏）用过类似的控制系统。没有玩过这些游戏的玩家可能需要一段时间的练习才能熟练地操作，建议这些玩家在掌握这些技术之前先玩[创造模式](创造模式.md)或是将[难度](难度.md)设置为和平。

# 基岩版
# = 键盘与鼠标 =
键盘与鼠标控制类似于[Java版](Java版.md)，但有些不同。这些键位可以在设置中更改。键盘控制在Nintendo Switch和iOS上不可用。鼠标控制仅在Xbox、PlayStation、Windows、Android和iOS/iPadOS上可用；但是，可以在其他支持外置键盘的诸如Android的平台上连接外置键盘，将控制设置为键盘。

游戏在收到鼠标事件后，会自动将控制模式切换为键盘与鼠标，但键盘事件不会。

在Android版本中，游戏不能使用鼠标侧键，但可以使用鼠标侧键的返回键充当返回键。

# == 可设置的键位 ==

如果开启了**全键盘操作（Full Keyboard Gameplay）**，即可使用以下设置。

# = 手柄 =
手柄是Xbox、PlayStaion和Nintendo Switch平台上的默认控制模式。使用蓝牙或有线等方式连接后，也可以在所有其他平台上使用。操控方式与对应平台的[原主机版](原主机版.md)类似，且不同平台之间并无显著差异。在Nintendo Switch上，单个Joy-Con不能玩游戏。使用摇杆时，左摇杆可用于移动，右摇杆可用于移动视角。下方列出的所有键位均可由玩家自定义。空白区域代表该键位默认未被分配键位，玩家可以为其分配一个按钮。

在Xbox、PlayStaion和Nintendo Switch平台，如果连接了多个手柄（单个Joy-Con除外），则在世界中按下其他手柄上的    即可开始[分屏游戏](分屏.md)。

游戏在收到手柄事件后，会自动将控制模式切换为手柄。

# = 触控 =
|三种不同的触控模式}}

通过触摸屏幕来控制显示在屏幕上的东西。可以在[设置](选项#基岩版.md)中（设置 →  → 控制模式）选择控制模式，并且初次使用触控进入游戏时会自动弹出。有三种控制模式：摇杆并点击进行互动、方向键并进行互动、摇杆并瞄准十字线。触摸控制在所有支持触控的设备上都可用。

控制模式为方向键并进行互动时，在设置中（设置 →  → 分离控制）可启用十字准星。

触摸控制在支持触摸的设备上可用，但Nintendo Switch除外，其中触摸屏只能用于与快捷栏、物品栏和菜单进行交互。

除Nintendo Switch外，游戏在收到触控事件后，会自动将控制模式切换为触摸。

如果在设置中启用了，或者是Nintendo Switch版本，则触控无法用于控制游戏，但仍能控制GUI。

在设置中（设置 →  → 自定义控制）可自定义按键的位置、透明度和大小。

# 过时版本
这些版本的游戏已经被移除；然而，游戏控制会在此作为历史档案。

# = [树莓派版](树莓派版.md) =
所有树莓派版的控制均不可被更改。

# = [携带版](携带版.md)：Xperia PLAY =

注意：对于使用游戏手柄的Xperia Play用户，在创造模式下，屏幕下方最下面的两行项目，并且无法向下滚动以查看它们。它们仍然可以，但它需要记住按下方向按钮以它们的次数，或者试错。这有望很快修复，但在4.0更新中最为突出，因为项目数量增加了，现在隐藏了16个项目。 查看它们的唯一方法是打开选项是在选项菜单中使用触摸控件。

# = [原主机版](原主机版.md) =
# == 注意 ==
* 在[PlayStation Vita版](PlayStation Vita版.md)（在PlayStation Vita上游玩时）、[Wii U版](Wii U版.md)（在Wii U GamePad上游玩时）和[Nintendo Switch版](Nintendo Switch版.md)（在桌面或手持模式下游玩时），触摸屏可以用于控制底部的提示框（如可用），以及菜单和物品栏。
* * 同样，在[PlayStation 4版](PlayStation 4版.md)上，触摸板可用于移动物品栏光标以及通过滑动控制菜单。
* [Wii U版](Wii U版.md)可以使用Wii U GamePad、Wii U Pro Controller、Classic Controller或Classic Controller Pro进行游戏。它不能用Wii Remote、Wii Remote Plus或Nunchuk游玩。
* * 注意：虽然[Wii U版](Wii U版.md)不能用Wii Remote或Wii Remote Plus游玩，但需要Wii Remote或Wii Remote Plus才能使用Classic Controller或Classic Controller Pro进行游戏。
* [Nintendo Switch版](Nintendo Switch版.md)可以使用一对Joy-Con、Nintendo Switch Pro Controller或Nintendo Switch Lite游玩。但不能用单个Joy-Con游玩，因为它没有足够的按钮或摇杆。
