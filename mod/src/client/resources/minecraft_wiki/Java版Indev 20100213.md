# Java版Indev 20100213

*页面ID: 35409* | *来源: Minecraft Wiki*

<onlyinclude>

* *Minecraft Indev**的一个版本发布于2010年2月13日。<ref></ref>

# 更改
# = 生物 =
* *[骷髅](骷髅.md)和[僵尸](僵尸.md)**
* 现在会在阳光下燃烧。

* *[蜘蛛](蜘蛛.md)**
* 现在在白天不会攻击[玩家](玩家.md)，除非它被玩家攻击。
* 眼睛现在会发光。

# = 世界生成 =
* *[Indev房子](Indev房子.md)**
* 现在由[石头](石头.md)和[木板](木板.md)组成。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 仅显示FPS开启时，才会显示已分配内存和可用内存。
* * 内存指示器现在使用§7（灰色）[颜色代码](颜色代码.md)来显示。

# 修复
* *修复了2个漏洞**
* 台阶不再导致光照问题。
* 地狱主题世界不再一开始完全明亮，之后逐渐变暗。</onlyinclude>
