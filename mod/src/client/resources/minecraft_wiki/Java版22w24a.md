# Java版22w24a

*页面ID: 96877* | *来源: Minecraft Wiki*

<onlyinclude>

* *22w24a**是[Java版1.19.1](Java版1.19.1.md)的唯一一个快照，发布于2022年6月15日<ref></ref>，加入了[悦灵](悦灵.md)的复制方式以及未完成的聊天举报功能，并修复了一些漏洞。

# 新内容
=== 生物 ===
* *[悦灵](悦灵.md)**
* 现在在唱片机播放音乐时会跳舞。
* 在悦灵跳舞时给予其[紫水晶碎片](紫水晶碎片.md)会使其“复制”并产生另一个悦灵。
* * 每次复制有2.5分钟的冷却时间。
* * 复制出的悦灵不会继承原来的悦灵的信息（如自定义名称）。
* * 可以通过<code>CanDuplicate</code>NBT标签控制（默认值为<code>true</code>）。

# = 常规 =
* *[社交屏幕](社交屏幕.md)**
* 现在可以在社交屏幕中举报玩家在聊天区中的不当发言。

# 更改
# = 方块 =
* *[幽匿感测体](幽匿感测体.md)**
* 加入了可感测的<code>jukebox_play</code>和<code>jukebox_stop_play</code>游戏事件，振动频率为0。

# = 常规 =
* *[聊天](聊天.md)样式**
* 定义聊天类型的JSON文件中不再出现<code>style</code>字段的默认值。
* <samp>game_info.json</samp>现在默认会包含一个复述功能设置项。

* *[暂停菜单](暂停菜单.md)**
* 社交屏幕现在可以通过多人游戏暂停菜单进入。

* *[资源包](资源包.md)**
* 在<samp>social_interactions.png</samp>中加入了3个与聊天举报功能有关的图标。

* *[标签](Java版标签.md)**
* 向游戏事件标签中加入了。
