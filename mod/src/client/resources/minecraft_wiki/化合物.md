* *化合物（Compounds）**是一种在[化学](化学.md)中由许多种[元素](元素.md)组合制造的[物品](物品.md)。

# 获取
化合物可以通过[化合物创建器](化合物创建器.md)来制取。这是通过放入与化合物的化学式相对应数量的元素来完成的。

# = 天然化合物 =
天然化合物是指可以直接从Minecraft的自然界中获取的化合物。

# = 废物 =
废物被归为“化合物”，但唯一制作它的方法是在实验台上使用无效的配方。使用过氧化氢、碘化钾和肥皂制作废物时会产生“[大象牙膏](wzh:大象牙膏.md)”粒子效果。废物没有任何用途。

# 用途
某些化合物被用作[合成](合成.md)或[实验台](实验台.md)实验中的材料。天然化合物还有除化学以外的用途，这在其各自的文章中可找到详述。

# 你知道吗
* 硫酸亚铁实际上是淡蓝绿色的晶体，在现实世界中用其制作墨水需要将其与鞣酸和蓝色染料混合。
* Minecraft中许多化合物的颜色与现实世界不同，例如现实中硝酸镁溶液、苯和氧化铝固体通常都是无色的；但是Minecraft中前两种物质是黄色，而氧化铝是褐色。
