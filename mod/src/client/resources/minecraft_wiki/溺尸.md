* *溺尸（Drowned）**是生成于[海洋](海洋.md)与[河流](河流.md)生物群系的[僵尸](僵尸.md)水下变种，也能在僵尸溺水后生成。

# 生成
# = 自然生成 =
溺尸会在[海洋](海洋.md)、[冷水海洋](冷水海洋.md)、[温水海洋](温水海洋.md)、[冻洋](冻洋.md)和它们的深海变种、[暖水海洋](暖水海洋.md)、[溶洞](溶洞.md)中的[含水层](含水层.md)以及[河流](河流.md)亮度为0的地方生成。其在河流以及溶洞中的生成率比在海洋类生物群系中的更高。

溺尸会在2格或更高的[水源方块](水源方块.md)或流动水中生成（包括[含水](含水.md)方块）。海洋类[生物群系](生物群系.md)中，溺尸会在Y<58（即至少低于海平面6格）的位置生成。

溺尸会在上方至少有1格水源方块或流动水的方块表面上生成，生成高度没有限制，且只会生成在可生成位置（X、Z轴固定）的最高处的表面。其生成量由敌对生物生成上限限制，在海洋类生物群系和溶洞中的密度上限为5，在河流中的密度上限为2。

溺尸在生成时主手有概率携带三叉戟或钓鱼竿，副手也有概率持有鹦鹉螺壳。它们也会有很小的概率生成为溺尸[鸡骑士](鸡骑士.md)。与[僵尸](僵尸.md)不同，它们自然生成时不会携带任何[盔甲](盔甲.md)。

# == 海底废墟 ==
溺尸也会随所有海洋生物群系中的[海底废墟](海底废墟.md)部分子结构一同生成。由此生成的溺尸不会自然消失。

# == 僵尸鹦鹉螺 ==
[缩略图|溺尸骑乘僵尸鹦鹉螺](File:Zombie Nautilus Jockey.png.md)
当溺尸因自然生成或结构生成（例如[海底废墟](海底废墟.md)）而生成时，如果所处的[生物群系](生物群系.md)不是[河流](河流.md)或[冻河](冻河.md)，生成的溺尸不是幼年溺尸且主手持有三叉戟，则有50%的概率生成[僵尸鹦鹉螺](僵尸鹦鹉螺.md)作为溺尸的坐骑。

海洋类生物群系中有小概率额外生成2-4只溺尸，其中会有一只成年溺尸主手持有三叉戟且骑着僵尸鹦鹉螺。

# = 转化 =
[缩略图|一只僵尸正在转化成溺尸](File:Zombie becoming Drowned.gif.md)
如果僵尸头部连续在水中浸泡超过，将开始转化成溺尸。一旦开始转化，它会像僵尸村民被治愈时一样颤抖，此时不需要浸泡在水中也会颤抖并继续转化，后它就会变为溺尸，转化形成的溺尸生命值会回满，且不会携带[三叉戟](三叉戟.md)。

僵尸转化成溺尸后将保留身上穿着的盔甲和手持的物品；僵尸手持或穿戴着的所有物品都会掉落，部分转化成的溺尸能将掉落的物品重新捡起。<ref></ref>

对于僵尸的其他变种，[僵尸村民](僵尸村民.md)和[僵尸猪灵](僵尸猪灵.md)不会转化成溺尸，[尸壳](尸壳.md)则会先转化为僵尸再进一步转化为溺尸。

# = 增援 =

在困难难度下，溺尸受到攻击时可能会生成增援溺尸，详见[僵尸增援](僵尸增援.md)。

# = 万圣节 =

在[万圣夜](wzh:万圣夜.md)（10月31日）当天，溺尸在生成时有22.5%的概率戴着[雕刻南瓜](雕刻南瓜.md)，2.5%的概率戴着[南瓜灯](南瓜灯.md)，但不会掉落。<ref></ref>

# 变种
# = 幼年溺尸 =
溺尸有5%的概率以幼年形态生成，幼年溺尸的行为与成年溺尸略有不同：
* 移动速度比普通溺尸快50%，但生命值与之相同。
* 叫声的音调比普通溺尸高。
* 穿戴的盔甲会缩小以适应身体尺寸。
* 有缩小的碰撞箱，可以穿过1×1格的空间。
* 永远不会成长为成年溺尸。

幼年溺尸有5%的概率会在附近的[鸡](鸡.md)上生成成为[鸡骑士](鸡骑士.md)（如果附近没有鸡则生成失败），还有4.75%的概率附带一只[鸡](鸡.md)生成成为[鸡骑士](鸡骑士.md)。

备注：
* 骑士的速度为幼年溺尸的速度，而不是[坐骑](生物.md)本身的速度。
* 如果幼年溺尸骑乘的是玩家可骑乘的生物，该生物将不可再被玩家骑乘。
* 除了上述生物以外，作为骑士生成的幼年溺尸还会主动接近并骑乘未驯服的僵尸鹦鹉螺。

# 行为
[缩略图|一个正在用三叉戟瞄准的溺尸](File:A drowned.png.md)
一般溺尸使用近战攻击，而生成时携带[三叉戟](三叉戟.md)的溺尸会使用远程攻击。如果携带三叉戟的溺尸离目标不超过3格，则会使用近战攻击。三叉戟可以是附魔的，[忠诚](忠诚.md)和[穿刺](穿刺.md)魔咒可以正常生效，但手持[激流](激流.md)附魔三叉戟的溺尸仍会掷出三叉戟而不触发魔咒。<ref></ref>溺尸能够无限投掷三叉戟，它们每1.5秒朝35格或10格内的目标投掷一次。投掷三叉戟时溺尸会尝试使自身与目标的距离小于等于10格并举起手臂，投掷后仍会继续维持相同的姿势，直到结束攻击。

溺尸可能会在生成时携带[钓鱼竿](钓鱼竿.md)，但不会使用。

溺尸会主动追逐和攻击或<ref></ref>格内的玩家、[村民](村民.md)、[流浪商人](流浪商人.md)、[铁傀儡](铁傀儡.md)、、幼年[海龟](海龟.md)和[美西螈](美西螈.md)，并且会靠近以及尝试踩碎[海龟蛋](海龟蛋.md)。

即使溺尸拥有[隐身](隐身.md)效果，其他生物仍然能够察觉到溺尸。<ref></ref>

溺尸能游泳，速度与玩家相同。溺尸追逐目标时的游泳姿势类似于玩家[速泳](速泳.md)时的姿势。

溺尸可以走上1格高的方块而无需跳跃。

白天未携带三叉戟的溺尸对于不接触水的生物处于被动状态，携带三叉戟的溺尸对于不接触水的生物处于中立状态。溺尸会攻击在水中的玩家、村民、流浪商人、铁傀儡、幼年海龟和美西螈。当生物攻击溺尸时，周围携带三叉戟的溺尸都会进行反击。

白天溺尸对于不接触水的生物处于中立状态。溺尸会攻击在水中的玩家、村民、流浪商人、铁傀儡、雪傀儡、幼年海龟和美西螈。当生物攻击溺尸时，溺尸会进行反击。

白天不在水中的溺尸会寻找附近的水源。如果水面上没有玩家，溺尸会留在它们所在的水面上，并忽略陆地或船上的玩家。不会为了追逐玩家而离开水面。到了晚上，溺尸会在水中游泳，追赶玩家和幼年海龟，会像普通的[僵尸](僵尸.md)一样在岸上行动。

被溺尸直接或用三叉戟杀死的村民有概率变成[僵尸村民](僵尸村民.md)（简单、普通、困难[难度](难度.md)下概率分别为0%、50%、100%）。

如果一个僵尸或溺尸被攻击，附近没有目标的溺尸会向攻击者产生敌意，但溺尸不会因为被其他溺尸的三叉戟误伤而互相攻击。

溺尸总是能够骑上靠近它们且未被驯服的[僵尸鹦鹉螺](僵尸鹦鹉螺.md)，但它们不会主动寻找僵尸鹦鹉螺。

与僵尸类似，部分溺尸在[游戏规则](游戏规则.md)设置为<code>true</code>时具有捡起掉落物、穿戴装备的能力，装备上的魔咒会正常生效。它们也偏好品质更好的装备和武器，但比起剑和斧，它们更愿意捡起三叉戟。

溺尸在不完整方块上时有寻路问题，会跳着移动，且不会攻击。<ref></ref>

# = 生物族群 =

溺尸是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时会受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，不被[凋灵](凋灵.md)攻击。

与多数亡灵生物不同，溺尸能够游泳，不会不受控地沉入水底。

溺尸会在阳光下[着火](着火.md)，未戴[头盔](头盔.md)或[生物头颅](生物头颅.md)的溺尸会寻找阴凉处、水域以及来避免着火。溺尸不属于[水生生物](生物#水生生物.md)。<ref></ref>

# 你知道吗
* 溺尸的声是音效师[Samuel Åberg](Samuel Åberg.md)用牛奶漱喉的声音。<ref></ref>
* 幼年溺尸的官方英文名称是“**Gurgle**”，<ref>https://www.youtube.com/post/Ugkx_RkwCZB7YEPMZFTnMU7NwoOr8cxpK3Kf</ref>即溺尸声的拟声词。
* 在白天，溺尸需要浸在水中才能主动攻击目标。即使是手持三叉戟的溺尸，不在水中时哪怕在阴影处也不会对射程内的攻击目标投掷三叉戟，直到自己或者被攻击才会进行反击。
* 虽然溺尸不会因为被其他溺尸的三叉戟误伤而互相攻击，但如果僵尸被溺尸的三叉戟误伤，附近没有目标的溺尸会因为支-{}-援僵尸而对该溺尸发动攻击。
* 成年溺尸的头部可以旋转360&deg;。
* 手持[鹦鹉螺壳](鹦鹉螺壳.md)的溺尸会使用像玩家一样的手势，而不是将双手平举。
* 当溺尸戴上头盔时，头盔显示在溺尸的贴图下，看起来就像是戴在头皮下面一样，这是因为基岩版溺尸头部模型的第二层比[Java版](Java版.md)更大。
* 能投掷三叉戟的溺尸是特殊的溺尸变种，它们就算失去手中的三叉戟也能够通过投掷三叉戟进行远程攻击，普通溺尸就算获得三叉戟也无法远程攻击，但也会作出投掷三叉戟的动作。
