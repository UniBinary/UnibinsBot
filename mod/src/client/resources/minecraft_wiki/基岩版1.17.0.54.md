# 基岩版1.17.0.54

*页面ID: 82087* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.17.0.54**是[基岩版1.17.0](基岩版1.17.0.md)的第7个测试版，发布于2021年5月6日<ref></ref>，加入了[虫蚀深板岩](虫蚀深板岩.md)，调整了一些特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[虫蚀深板岩](虫蚀深板岩.md)**
* 深板岩的虫蚀变种。
* 被玩家破坏后会生成[蠹虫](蠹虫.md)。
* 自然生成于[峭壁](峭壁.md)及其变种[生物群系](生物群系.md)。

# = 常规 =
* *[设置](设置.md)**
* 加入了“创建者”设置。
* * 目前仅包含内容日志设置。

# 更改
# = 方块 =
* *[杜鹃树叶](杜鹃树叶.md)和[盛开的杜鹃树叶](盛开的杜鹃树叶.md)**
* 现在可使用附有[精准采集](精准采集.md)的工具开采获得。

* *[铜块](铜块.md)**
* 现在需要用9个[铜锭](铜锭.md)合成。
* 现在可分解为9个铜锭。

* *[粗金属块](粗金属块.md)**
* 更改了纹理以匹配。

* *[铜矿石](铜矿石.md)和[深层铜矿石](深层铜矿石.md)**
* 现在开采后掉落的[粗铜](粗铜.md)数量为2-3个，而非先前的1个。

* *[深板岩](深板岩.md)**
* 更改了纹理以匹配。

* *[发射器](发射器.md)**
* 现在可以使用[细雪桶](细雪桶.md)来放置细雪。

* *[滴水石锥](滴水石锥.md)**
* 略微提高了[钟乳石](钟乳石.md)滴落水填充[炼药锅](炼药锅.md)的频率。

* *[细雪](细雪.md)**
* 调整了破坏所需时间以匹配。

* *[孢子花](孢子花.md)**
* 不再能放置于水中。

# = 物品 =
* *[时钟](时钟.md)**
* 更改了纹理以匹配[纹理更新](纹理更新.md)后金质物品的纹理。

* *[指南针](指南针.md)**
* 更改了纹理以匹配纹理更新后铁质物品的纹理。

* *[粗金属](粗金属.md)**
* 更改了纹理以匹配。

# = 生物 =
* *[美西螈](美西螈.md)**
* 离开[水](水.md)时不再会装死。

* *[山羊](山羊.md)**
* 死亡后不再会掉落羊肉。
* 加入了新音效。
* 加入了[尖叫山羊](山羊#生成.md)。

* *[猪灵](猪灵.md)**
* 现在会被[粗金](粗金.md)、[深层金矿石](深层金矿石.md)和[粗金块](粗金块.md)吸引。

* *[骷髅](骷髅.md)**
* 现在骷髅陷入[细雪](细雪.md)后会转化为[流浪者](流浪者.md)。

* *[鱿鱼](鱿鱼.md)和[发光鱿鱼](发光鱿鱼.md)**
* 现在拥有独特的喷墨音效。

# = 世界生成 =
* *[废弃矿井](废弃矿井.md)**
* 现在主世界低于Y=0的区域的废弃矿井中会生成[运输矿车](运输矿车.md)。
* * 仅开启[实验性玩法](实验性玩法.md)（Caves & Cliffs子选项）后可用。

* *[要塞](要塞.md)**
* 现在生成在大型[洞穴](洞穴.md)内的要塞有更高的概率被[石头](石头.md)包裹。
* * 仅开启[实验性玩法](实验性玩法.md)（Caves & Cliffs子选项）后可用。

# = 常规 =
* *[设置](设置.md)**
* 将档案设置中的内容日志设置移动至新的“创建者”设置。

* *[菜单屏幕](菜单屏幕.md)**
* 更改背景图为[紫晶洞](紫晶洞.md)。
* * 由于所有测试版都使用beta独有背景图，新背景图暂时不可见。

* * 包含功能域实体的信息（包含其网络ID和NBT，其中NBT包含有关功能域实体的定义和组件信息），这些信息将会添加到客户端的注册表中。
* 加入了RemoveVolumeEntityPackage。
* * 包含功能域实体的网络ID，可将其从客户端注册表中删除。

# 修复
* *洞穴与山崖特性**
* “装死”时的美西螈不再可以移动。（）
* 现在骷髅陷入细雪后会转化为流浪者。（）
* 细雪上的生物现在会正确寻路。（）
* 原版趋同：细雪上不再能放置脚手架。（）
* 玩家不再可以通过在细雪上跳跃来防止陷入其中。（）
* 现在为铜块涂蜡/脱蜡时会正确显示粒子并播放音效。（）
* 现在放置在切制铜台阶上的树叶会正确渲染了。
* 使用染料为之前的告示牌文本染色不再会使其增亮。（）
* 修复了在第一人称下使用望远镜时可以看见副手上的物品的问题。（）
* 对着缠根泥土使用锄不再会将其错误转化为耕地。
* 在创造模式物品栏中，望远镜现在位于“装备”分类栏中。（）
* 修复了潜影贝不会传送到Y=0以下区域的漏洞。（）

* *原版趋同**
* 现在下落中的方块落在潜影贝上时会被破坏。

* *用户界面**
* 修复了控制器上设置鼠标灵敏度却无效的问题。（）
* 修复了在“鼠标和键盘”设置中无法设置键的功能的漏洞。（）

* *命令**
* 修复了命令方块矿车不受游戏规则影响的问题。（）

* *多人游戏**
* 现在可在未开启作弊时执行，并且其不再使用目标选择器。</onlyinclude>
