# Java版1.20.3-pre2

*页面ID: 108406* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.20.3-pre2**是[Java版1.20.3](Java版1.20.3.md)的第2个预发布版，发布于2023年11月22日<ref></ref>，修复了一些漏洞。

# 更改（实验性）
# = 非生物实体 =
* *[风弹](风弹（实体）.md)**
* 现在可以在碰撞时破坏[饰纹陶罐](饰纹陶罐.md)和[紫颂花](紫颂花.md)。
* * 官方发布的更新文章中指出风弹可以破坏[滴水石锥](滴水石锥.md)，但这一特性并未实现。<ref></ref>

# = 常规 =
* *[标签](Java版标签.md)**
* 向实体类型标签中加入了。

# 修复
暂停游戏后，特定输入将在游戏暂停状态结束后进行。

|265788|“开启免费的快照版Realm”在打开其他界面时依然可选中，导致它的提示框错误的显示在上层。
|266075|末影珍珠落地的位置离投掷者太远时，“”字幕不显示。
|266206|重命名的箭在死亡消息中依然被显示为“箭”。
|266439|向试炼密室内带有战利品表的饰纹陶罐内放入无法填充的物品时，物品消耗将不同步。
