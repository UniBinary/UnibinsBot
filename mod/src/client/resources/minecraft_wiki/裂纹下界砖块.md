# 裂纹下界砖块

*页面ID: 58521* | *来源: Minecraft Wiki*

* *裂纹下界砖块（Cracked Nether Bricks）**是[下界砖块](下界砖块.md)制作的装饰性方块。

# 生成
裂纹下界砖块不会生成在世界中。

# 获取
# = 烧炼 =

# 破坏
挖掘裂纹下界砖块的合适工具是镐。裂纹下界砖块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

裂纹下界砖块被破坏后会掉落自身。

# 用途
裂纹下界砖块目前仅用于装饰。
