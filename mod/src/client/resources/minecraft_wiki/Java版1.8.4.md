# Java版1.8.4

*页面ID: 16266* | *来源: Minecraft Wiki*

* *1.8.4**是的一次次要更新，发布于2015年4月17日<ref></ref><ref>https://www.reddit.com/r/Minecraft/comments/32tb8e/hey_rminecraft_i_wanted_to_bring_light_to_an/cqeo2oe</ref>。修复了各种漏洞和重要的安全缺陷<ref>https://www.reddit.com/r/Minecraft/comments/32tb8e/hey_rminecraft_i_wanted_to_bring_light_to_an/</ref><ref>http://blog.ammaraskar.com/minecraft-vulnerability-advisory/</ref><ref></ref>，以及一些次要的问题的一次更新。此版本兼容1.8到1.8.3的服务端<ref></ref>。

# 更改
# = 生物 =
* *[豹猫](豹猫.md)和[狼](狼.md)**
* 不再跟随旁观模式下的玩家。

# = 世界生成 =
* *[下界传送门](下界传送门.md)**
* 越过下界传送门把玩家传送到传送门外。<ref></ref>

# = 常规 =
* *[玩家头颅](玩家头颅.md)**
* 玩家头颅的皮肤不再可以被任意服务器加载。<ref></ref>
* * 现在只能从Mojang官方服务器中加载。
* 玩家头颅皮肤现在需要使用格式文件。
