* *MCC x Minecraft 15 周年庆典派对**，也被称为**MC Championship x Minecraft 15 周年庆典派对**、**MC Championship小游戏活动**或**MCC派对**<ref group="注">还可以指[MCC派对](https://mcchampionship.fandom.com/wiki/MC_Championship_Party)，一个完全不同的活动，仅由Noxcrew于2023年11月11日举办。</ref>，是[基岩版](基岩版.md)中官方与Noxcrew合作开展的限时开放的[活动服务器](活动服务器.md)。

该服务器由5个部分组成，包括中心和4款小游戏，分别是王牌竞速、网格跑者、时之沙和熔毁。

为庆祝15周年，MCC准备了15项独特挑战，玩家可以玩小游戏，或者解谜；兴许还可以到处走走，说不定能发现惊喜。每完成一项挑战都能获得[角色创建器](角色创建器.md)奖励。当全部完成后，即可获得[MCC 15周年披风](MCC 15周年披风.md)。

# 小游戏

灵感来自[MC Championship](MC Championship.md)。玩家可以通过玩小游戏赚取硬币，然后前往服务器内的[商店](#商店.md)消费。

# = 王牌竞速 =
王牌竞速由单圈比赛组成，可以使用、跳跃增强、和装置来帮助你加快速度。捷径散布在赛道各处。

# = 网格跑者 =
网格跑者是一款在[MINECON Earth 2018](MINECON Earth 2018.md)<ref></ref>期间首次公开的小游戏，由益智竞赛组成。在此次活动中，玩家要以四人为一组进入4个房间并完成不同的挑战，分别是击败野兽、、烤蛋糕和冲刺。每个房间持续一分钟，一分钟后，通往下一个房间的门就会打开。

; 击败野兽
[250px|thumb|“击败野兽”房间的俯视图](File:MCC Screenshot Grid Runners 1.png.md)

进入房间内，玩家会自动穿上除头盔外的铁套且会给予一把[铁剑](铁剑.md)，玩家需要使用这把铁剑与敌人作战。敌人的刷新波数是随机的，当玩家杀死一个敌人或击败一波敌人时，就会分别获得若干枚或10枚硬币。每波敌人会挑选其中一组生成：一些小型史莱姆、一个尸壳和一些僵尸、一个流浪者和一些骷髅、一个流浪者和一些沼骸、一个烈焰人和一些小型岩浆怪、一个女巫和一些掠夺者、一个旋风人和一些沼骸。

;
[250px|thumb|“”房间的俯视图](File:MCC Screenshot Grid Runners 2.png.md)

玩家会得到一支画笔。房间两侧各有一幅画布和画作，玩家需要画笔蘸取黑、棕、黄、红、蓝、绿、紫、白颜料桶中的颜料，然后，玩家可以将颜料射到画布上进行画作的，时不需要准确地瞄准。玩家每正确填涂一个色块可获得3枚硬币，每完成一幅画作可获得10枚硬币。颜料球有一定的半径限制。如果颜料球掉到地上，则会留下痕迹。

; 烤蛋糕
[250px|thumb|“烤蛋糕”房间的俯视图](File:MCC Screenshot Grid Runners 3.png.md)

在这个房间内，有着快速生长的小麦和[甘蔗](甘蔗.md)（只会掉落糖），还有四只快速下蛋的[鸡](鸡.md)、三头[牛](牛.md)和一个装满[铁桶](铁桶.md)的[箱子](箱子.md)。玩家需要收集材料（[鸡蛋](鸡蛋.md)、[糖](糖.md)、[小麦](小麦.md)、[奶桶](奶桶.md)），并通过键交给中间的烤蛋糕机。烤蛋糕机一次只能提供48个相同的材料。烤好一个[蛋糕](蛋糕.md)后，玩家可获得10枚硬币。

; 冲刺
玩家需要冲刺、跳跃，最终越过终点线。

# = 时之沙 =
时之沙是一个布满陷阱、障碍和[怪物](怪物.md)的地牢，玩家需要赶在时间耗尽之前收集更多硬币，或者收集沙子来延长剩余时间，最后通过传送门返回。若未在时间耗尽之前返回传送门，则会扣除一些已获得的硬币。

玩家会得到一把[石剑](石剑.md)，初始装备为皮革套装，全部升级之后为铁盔甲。

地牢里共有70份沙子，每收集1份，计时器会延长10秒。

玩家可以通过杀死怪物、收集散落在地上的硬币堆（5/20/30枚硬币）或解锁箱子来收集硬币。

僵尸和蜘蛛死亡后会掉落1枚硬币；尸壳、掠夺者和骷髅会掉落2枚硬币；唤魔者会掉落3枚硬币。

箱子分为5个铁箱、2个金箱、1个钻石箱和1个下界合金箱，每个箱子需要一把对应的钥匙才能打开，并分别提供50、100、200和400枚硬币。

# = 熔毁 =
[250px|thumb|一个正在熔毁的房间](File:MCC Screenshot Meltdown.png.md)

熔毁是一款PVE类型的小游戏，玩家需要在7个房间中存活下来，同时尽量击败更多怪物。

房间内到处都是[刷怪笼](刷怪笼.md)。玩家会得到一把附有[无限](无限.md)的****。玩家可以[弓](弓.md)来射击怪物使其冻结，并杀死冻结的怪物以获得3枚硬币；还可以捡起地上的硬币堆（5/10枚硬币）来收集硬币。在房间中，玩家的血量不会自然恢复，但在进入下一个房间时会立即回满血量。

游戏开始后，玩家要在10秒内进入房间1，否则开始扣减生命值，每两秒会损失。起始屋会在第20秒熔毁。

每个房间持续105秒（房间1为90秒，房间7为110秒）。当剩余30秒时，该房间开始熔毁，此时进入下一个房间的门会打开；当剩余15秒时，玩家开始被扣减生命值，每两秒会损失。该房间会在时间归零时熔毁。

冻结的怪物会在10秒后或碰到烈焰人后解冻，烈焰人也不会发射火焰弹。

# 挑战
玩家可以通过完成挑战来获得独家的[角色创建器](角色创建器.md)奖励。如果完成了所有挑战，就可以获得[MCC 15周年披风](披风.md)。

# = 神秘洞穴挑战 =
在活动的第一周，于每天UTC时间下午5点<ref></ref>，玩具店上方的神秘洞穴内会出现一幅新的壁画，旁边有一个****NPC正在描述这些壁画。从7月29日起，会出现用于帮助玩家破解壁画的提示，玩家可以随时完成已在洞穴中出现的谜题。
