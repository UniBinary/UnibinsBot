# 弓

*页面ID: 6159* | *来源: Minecraft Wiki*

* *弓（Bow）**是一种可以发射[箭](箭.md)的远程[武器](武器.md)。

# 获取
# = 合成 =

# = 生物掉落 =
# == 骷髅变种 ==
[骷髅](骷髅.md)，[流浪者](流浪者.md)、[沼骸](沼骸.md)和[焦骸](焦骸.md)死亡时有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落一把弓。弓是否带有魔咒取决于[难度](难度.md)，在普通和困难难度下，魔咒的等级等价于附魔台上5-22级的魔咒。

由[骷髅陷阱](骷髅陷阱.md)里的骷髅掉落的附魔弓魔咒等级总等价于附魔台上5-22级的魔咒。准确的值取决于[区域难度](区域难度.md)（简单难度下的魔咒总等价于附魔台上5级的魔咒）。

# == 幻术师 ==

[幻术师](幻术师.md)死亡时有8.5%的概率掉落它们的弓，掉落的概率会随着抢夺魔咒等级的增加而增加。每增加1级，概率增加1%，最高掉落概率为11.5%。

# = 交易 =

# = 钓鱼 =
在[钓鱼](钓鱼.md)时，弓有概率作为[宝藏](钓鱼#垃圾与宝藏.md)被钓上来。钓上来的弓会有损坏，并且附带随机魔咒，该魔咒等价于在[附魔台](附魔台.md)上30级的魔咒。

# 用途
# = 武器 =

<div style='float:right'></div>
长按键可以拉弦。要使用弓，玩家应保证物品栏内至少有一支[箭](箭.md)，或者自身处于创造模式。在拉弦时，玩家只能以[潜行](潜行.md)的速度移动，若玩家正骑着[马](马.md)、坐在[矿车](矿车.md)或者[船](船.md)里，则拉弦不会使移动速度下降。拉弓时，在弓上显示的箭外观不随箭的类型改变。<ref></ref>

弓按照以下顺序选择要消耗的箭：
* 副手中的箭
*
* 快捷栏中最靠左的箭
* 物品栏中距离0槽位最近的箭（从最左上角向右逐行搜索）

拉弓时，拉弓程度会随着时间逐渐增加，其值等于<code>-{}-拉弓时间刻数 × ( 拉弓时间刻数 + 40 ) / 1200</code>。拉弓时间达到1秒时，弓拉满，拉弓程度停止增加，弓会开始上下抖动。

松开时，只有至少拉弓了时才会发射箭。弓发射的箭的速度为<code>拉弓程度 × 60</code>格/秒。

箭矢的飞行轨迹受到重力影响，射箭时须稍稍向上提起准星或处于高位，以便命中目标。流体中的箭会受到极大阻力，无法远飞。

当箭射中其他玩家时，会向发射者播放高音调的“叮”声。

箭造成的伤害不受玩家所带的[力量](力量（状态效果）.md)状态效果的影响，而是基于基础伤害与和射箭物品、箭矢速度相关的各种计算得出。

# == 伤害 ==

箭的基础伤害默认为2，基础伤害会因附魔改变，部分敌对生物所射箭的基础伤害还会根据[难度](难度.md)额外随机增加。基础伤害乘以命中时箭自身的速度并向上取整后，将得到最终伤害。

箭的基础伤害默认根据发射生物类型在不同的区间内随机选择，玩家所射箭的基础伤害还会因附魔、难度设置与命中时自身的速度随机增加。上述修正后，将得到最终伤害。

满弦射出的箭与[弩](弩.md)发射的箭为“暴击箭”，径迹会带有星状浅黄色粒子，命中造成的最终伤害进一步增加。

# = 生物使用 =
[骷髅](骷髅.md)、、[流浪者](流浪者.md)、[沼骸](沼骸.md)、[焦骸](焦骸.md)和[幻术师](幻术师.md)在持有弓时可以发射[箭](箭.md)，且骷髅、流浪者、沼骸、焦骸和幻术师在生成时就持有弓。

流浪者使用弓发射延长版的迟缓之箭，沼骸使用弓发射剧毒之箭，焦骸使用弓发射虚弱之箭，凋灵骷髅使用弓发射着火的箭。

# = 合成材料 =

# = 魔咒 =
弓接受7种不同类型的魔咒<!--指施加在弓上时能对弓的使用效果产生变化的魔咒-->，其基础[附魔能力](附魔能力.md)为1。弓的魔咒不会对箭的速度或距离有任何的影响。

弓能够提升对单一目标的打击强度，与同时打击多个目标的[弩](弩.md)相对。

# = 燃料 =
弓能用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料。每把弓可以烧炼1.5个物品；每把弓能烧炼1个物品。
