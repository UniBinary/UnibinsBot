# 力量

*页面ID: 28780* | *来源: Minecraft Wiki*

* *力量（Strength, Power）**可以指：

# Minecraft
*  - 一种提升近身攻击伤害的[状态效果](状态效果.md)。
* }} - 一种[魔咒](魔咒.md)，可以附在[弓](弓.md)上用于提升[箭](箭.md)造成的伤害。
*  - 饮用后可以获得力量状态效果。
*  - 投掷后可以给击中的生物及附近生物施加力量状态效果。
*  - 投掷后可以在投掷点生成力量[区域效果云](区域效果云.md)。

# Minecraft Dungeons
*  - 一种[魔咒](MCD:魔咒.md)，可以附在[远程武器](MCD:远程武器.md)上用于提升伤害。
*  - 一种[消耗品](MCD:消耗品.md)，饮用后可以获得力量状态效果。
