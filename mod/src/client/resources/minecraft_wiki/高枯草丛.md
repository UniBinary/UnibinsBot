# 高枯草丛

*页面ID: 171930* | *来源: Minecraft Wiki*

* *高枯草丛（Tall Dry Grass）**是一种生成在[沙漠](沙漠.md)和[恶地](恶地.md)的非[固体](固体方块.md)植物方块，高度比[矮枯草丛](矮枯草丛.md)高。

# 生成
# = 自然生成 =
高枯草丛会生成在：
* [沙漠](沙漠.md)的[沙子](沙子.md)上；
* [恶地](恶地.md)、[疏林恶地](疏林恶地.md)和[风蚀恶地](风蚀恶地.md)的[红沙](红沙.md)和[陶瓦](陶瓦.md)上。

# = 骨粉 =
对着矮枯草丛[骨粉](骨粉.md)会使其变为高枯草丛。

# 破坏
高枯草丛被挖掘时会立刻被破坏。

没有被[剪刀](剪刀.md)或具有[精准采集](精准采集.md)的工具挖掘破坏时，高枯草丛被破坏后不会掉落。

被剪刀或具有精准采集的工具挖掘破坏时，高枯草丛被破坏后会掉落自身。

# 用途
高枯草丛只能放置在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[耕地](耕地.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[沙子](沙子.md)、[红沙](红沙.md)、[可疑的沙子](可疑的沙子.md)和[陶瓦](陶瓦.md)上。

当游戏规则为<code>true</code>时，[绵羊](绵羊.md)能够将高枯草丛吃掉。被剪毛的绵羊会在吃掉它们后会重新长出羊毛。

# = 堆肥 =
将高枯草丛放入[堆肥桶](堆肥桶.md)里有30%的概率增加1层堆肥层。

# = 燃料 =
高枯草丛能作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个高枯草丛可以烧炼0.5个物品。

# = 环境音效 =
当高枯草丛下方两格均为[沙子](沙子.md)、[红沙](红沙.md)或任意[陶瓦](陶瓦.md)时，高枯草丛有概率发出特殊的环境音效。
