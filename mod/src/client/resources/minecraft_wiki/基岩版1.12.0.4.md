# 基岩版1.12.0.4

*页面ID: 43030* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.12.0.4**是[1.12.0](基岩版1.12.0.md)的第3个测试版，发布于2019年5月8日<ref></ref>，更换了[全景图](全景图.md)，并修复了一些漏洞。

# 更改
# = 方块 =
* *[红砂岩楼梯](红砂岩楼梯.md)**
* 更改了纹理映射。

* *[制图台](制图台.md)**
* 更改了UI中已锁定地图的玻璃纹理。

# = 生物 =
* *[村民](村民.md)**
* 调整了[工具匠](工具匠.md)村民出售[钻石锄](钻石锄.md)的交易项。
* * 交易所需的[绿宝石](绿宝石.md)由9个减少至4个。
* * 出售的钻石锄不再会带有随机魔咒。

* *[流浪商人](流浪商人.md)**
* 现在不再出售[沙子](沙子.md)。

# = 常规 =
* *[附加包](附加包.md)**
* 告示牌被复制到无支撑的区域时不再被破坏。
* 加入了日志函数的API文档。

# = 游戏内容 =
* *[声音](声音.md)**
* 增加了[袭击](袭击.md)过程中周围袭击者发出的声音的频率和音量，使其更容易定位。

* *[全景图](全景图.md)**
* 全景图从[水域更新](水域更新.md)更新到[村庄与掠夺](村庄与掠夺.md)。

# 修复
* *修复了26个漏洞**<br>
* *崩溃**
* 修复了在使用基岩版专用服务器时可能发生的崩溃。
* 修复了试图使用模板世界创建游戏时可能发生的崩溃。
* 修复了Nintendo Switch版在暂停或继续游戏时发生的游戏崩溃。
* 修复了在UI里使用控制器导航时可能发生的游戏崩溃。

* *常规**
* 即将融化的霜冰不再导致巨大延迟。（）
* 被激活的红石比较器在加载、关闭和在一个刻里重新打开时现在会正确在一个刻里停止输出信号。
* 修复了玩家使用超级马里奥混搭包里重生时生成在错误的位置的问题。
* 移除了流浪商人里的出售沙子的交易选项，并调整了工具匠村民出售钻石锄的交易价格。
* 通过全局设置或世界里下载的资源包现在可以被正确启用。
* 修复了设备之间的玩家皮肤无法同步的问题。
* 成就界面里现在会重新显示玩家的成就获得时间。
* “僵尸医生”成就现在可以正常解锁。

* *游戏内容**
* 玩家在水中取消游泳时不再可以透视方块。
* 玩家被困在下落的沙子或沙砾时现在会受伤。（）
* 使用工作台合并两个严重损坏的工具时现在会给予正确的耐久度。

* *生物**
* 村庄被摧毁后，铁傀儡不再会移动至世界的中心。（）
* 蜘蛛在寻路时现在会正确翻越障碍物。
* 轻微调整了北极熊转向时的动画。

* *图形**
* 物品展示框里的刷怪蛋大小现在是正确的。
* 红砂岩楼梯的纹理现在是正确的。（）
* 更新了制图台UI里已锁定地图的玻璃纹理。（）

* *用户界面**
* 在启用文本转语音功能后，回到游戏选项界面里时现在正确选择此前已选的选项栏。
* 修复了Xbox版下登录微软账号后无法使用控制器导航菜单屏幕的问题。
* 使用携带版UI时，附魔台UI里的书本图标不再覆盖魔咒文字。
* “滚轮滚动”按钮现在只会在VR的设置选项里显示。

* *命令**
* 修复了命令方块里的命令有时候无法执行的漏洞。</onlyinclude>
