# 携带版0.12.1.b10

*页面ID: 17759* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.12.1 alpha build 10**是[v0.12.1 alpha](携带版0.12.1.md)的第10个测试版，发布于2015年8月19日，修复了一些漏洞。

# 更改
* [村民](村民.md)在困难难度中总会变成[僵尸村民](僵尸村民.md)。
* [末影人](末影人.md)现在会躲避水了。
* 仅在生物群系颜色改变时使用叶色着色器。
* 仅对非透明像素进行光照贴图的纹理采样。
* 更新了[爆炸](爆炸.md)、[打火石](打火石.md)、[熔岩](熔岩.md)和玩家的部分音效。
* * 玩家受到虚空伤害时也会发出受伤声了。

# 修复

* *其他**
* 不能使用快捷栏扔出物品。
* 在下界死亡的玩家会重生在下界。
* 打开或关闭游戏时崩溃。
* 多人世界下加载区块会使得游戏崩溃。
* 在下界里生成村民使得游戏崩溃。
* 在网络环境较差时进行多人游戏使得游戏崩溃。
* 楼梯下方的雪不会堆积。
* 打开合成界面时游戏崩溃。
* 生物AI将灵魂沙和箱子视为全体积方块。
* 末影人受伤时颤抖。
* 农民村民不会立即收割成熟的作物。
* 藤蔓不能放置在树叶上侧面。
* 多人游戏下的生物头颅都显示为骷髅头颅。
* 金合欢树和深色橡树表现得像梯子。
* 触摸附魔按钮使得游戏崩溃。
* 僵尸猪人不会死于TNT爆炸。
* 末影人的传送音效不在客户端里播放。
* 端口数字字段输入有误。
* 无法在告示板上输入unicode字符。
* 使用向右往左输入时破坏世界名称格式。
* 仙人掌破坏时显示错误的粒子。
* 无法使用铁砧重命名物品。
* 部分粒子闪烁着黑色。</onlyinclude>
