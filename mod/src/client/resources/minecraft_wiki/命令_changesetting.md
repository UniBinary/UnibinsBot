# 命令/changesetting

*页面ID: 80000* | *来源: Minecraft Wiki*

在[基岩版专用服务器](基岩版专用服务器.md)（BDS）上运行时更改服务器设置。

只能在BDS控制台运行。

# 语法
  <code>changesetting allow-cheats <*value: Boolean*></code>
  <code>changesetting difficulty <*value: Difficulty*></code>
  <code>changesetting difficulty <*value: int*></code>

# 参数
或
   指定一个新的难度，必须是下面的一种：
  * <code>peaceful</code>（可替换为<code>p</code>或<code>0</code>）为和平难度
  * <code>easy</code>（可替换为<code>e</code>或<code>1</code>）为简单难度
  * <code>normal</code>（可替换为<code>n</code>或<code>2</code>）为普通难度
  * <code>hard</code>（可替换为<code>h</code>或<code>3</code>）为困难难度

   指定服务器是否允许作弊。


# 结果

# 示例
* 指定一个新的难度为“困难”：<code>/changesetting difficulty h</code>
* 指定服务器允许作弊：<code>/changesetting allow-cheats true</code>
