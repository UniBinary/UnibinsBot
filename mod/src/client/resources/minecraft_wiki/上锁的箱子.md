* *上锁的箱子（Locked Chest）**，亦称**（Steve Co. Supply Crate）**，是一个有着箱子外观的[愚人节玩笑](愚人节玩笑.md)方块。

# 生成
# = 自然生成 =
在[Beta 1.4](Java版Beta 1.4.md)中，如果日期是4月1日，所有的区块在生成时会随机选择一个位置，如果该位置是一个下方有固体方块的空气方块，则生成一个上锁的箱子。<ref></ref>

每有一个上锁的箱子被成功生成，游戏日志中就会输出一次<code>added a chest!!</code>。

# 获取
在[Beta 1.4](Java版Beta 1.4.md)中，上锁的箱子不能在生存模式中正常获得，只能通过物品栏编辑获得。

在[Beta 1.4_01](Java版Beta 1.4_01.md)以及之后的版本中生成的世界，上锁的箱子仍不能在生存模式中正常获得，其亦不存在于[创造模式物品栏](创造模式物品栏.md)中，但可以通过命令获取。但对于Beta 1.4中已生成上锁的箱子的世界，上锁的箱子在世界升级后仍会正常保留，上锁的箱子可以通过破坏对应方块获得。

# 破坏
在[Beta 1.4](Java版Beta 1.4.md)中，上锁的箱子不能被挖掘破坏。

在[Beta 1.4_01](Java版Beta 1.4_01.md)以及之后的版本和中，上锁的箱子被挖掘时会立刻被破坏。

上锁的箱子被破坏后会掉落自身。

# 用途
# = 放置与朝向 =
在Beta 1.4中，两个相邻放置的上锁的箱子会合并为大型上锁的箱子，功能无变化。和当时的[箱子](箱子.md)一样，大型上锁的箱子周围不能放置上锁的箱子。但在Beta 1.4_01及以后版本，上锁的箱子不再合并，也不再阻拦玩家在其周围放置同类方块。

上锁的箱子会根据周围的方块决定它的朝向。一般情况下，它试图使自己的正面朝外，如果有方块挡住了它的正面，那么上锁的箱子会相应地将自己旋转，使得其背面面对着该方块。在Beta 1.8之前，这是诸如箱子、熔炉等方块的正常行为。从Beta 1.8开始，这些方块的朝向取决于玩家所在的位置，而不会根据周围的方块决定其朝向。由于上锁的箱子是一个不受支持的方块，直到它被移除之前，它仍保持着旧的朝向行为。

# = 交互 =
[缩略图|220px|试图打开箱子时显示的消息](File:Locked Chest Message.gif.md)

在[Beta 1.4](Java版Beta 1.4.md)中，世界中的上锁的箱子会弹出一个屏幕，其标题为“”，告知玩家需要一个才能打开箱子，以及该钥匙可以在“Minecraft商店”中买到。窗口的下方有两个按钮，分别是“现在不用”和“前往商店”。

点击“前往商店”会让玩家跳转至[“Minecraft商店”](#“Minecraft商店”.md)。游戏将会使用操作系统的默认浏览器打开<code>https://minecraft.net/store/loot.jsp</code>。

跳转至“Minecraft商店”是上锁的箱子唯一的功能，上锁的箱子实际上并不能打开，玩家也并不能购买到所谓的“”来开箱。

在[Beta 1.4_01](Java版Beta 1.4_01.md)以及之后的版本中，世界中的上锁的箱子不会有任何效果。

# = 自然消失 =
在[Beta 1.4_01](Java版Beta 1.4_01.md)以及之后的版本中，每当上锁的箱子接收到一个[随机刻](随机刻.md)时，就会自动消失，类似于[树叶](树叶.md)。

# = 光源 =
上锁的箱子会发出[亮度](亮度.md)为15级的光。

# = 燃料 =
上锁的箱子可以被当作[燃料](燃料.md)使用，每个上锁的箱子可以烧炼1.5个物品。

# 你知道吗
* “上锁的箱子”的灵感来源于游戏《[http://wiki.teamfortress.com/wiki/Team_Fortress_2 ]》中的“”<ref></ref>；要打开箱子，必须在游戏商店购买价格为2.49美元的“”<ref></ref>。
* 这或许就是Notch在推特中提到的“愚蠢的秘密项目”。<ref></ref>
* 上锁的箱子在加入游戏时与箱子完全一致。不过，箱子的外观在[Java版Beta 1.8-pre1](Java版Beta 1.8-pre1.md)得到了重制，而上锁的箱子作为不受支持的内容，其外观并没有被更新。
* 上锁的箱子可能会在半空中或者在树顶上生成。
* 钥匙5件套的价格比买5把钥匙还要贵$3。
* 上锁的箱子在被破坏时会产生熔岩粒子。
* [基岩版](基岩版.md)、[原主机版](原主机版.md)和[Minecraft网站](Minecraft网站.md)都有它们自己的“Minecraft商店”。但它们都是用于获得可下载内容，购买[Java版](Java版.md)和Minecraft周边的真实商店，与这个愚人节玩笑没有关联。
* 取代上锁的箱子ID的[染色玻璃](染色玻璃.md)恰好诞生于[另一个愚人节玩笑](Java版2.0.md)。
* 虽然并没有加入上锁的箱子，但在语言文件中有一条名为的本地化键名。
