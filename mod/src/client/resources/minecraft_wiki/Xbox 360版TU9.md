# Xbox 360版TU9

*页面ID: 103918* | *来源: Minecraft Wiki*

* *TU9**是[Xbox 360版](Xbox 360版.md)的一次更新，发布于2013年4月4日。<ref></ref>

# 新内容
# = 方块 =
* *[砂岩](砂岩.md)**
* 加入了其磨制和平滑变种，以及楼梯变种。
* * 只能通过修改游戏获得。
* * 放置后，其行为和常规砂岩一致，并且在被破坏时掉落自身。

* *[楼梯](楼梯.md)**
* 加入了云杉木和白桦木变种。

* *[台阶](台阶.md)**
* 加入了云杉木、白桦木和下界变种。

* *[按钮](按钮.md)**
* 加入了云杉木和白桦木变种。

* *[龙蛋](龙蛋.md)**
* 杀死末影龙后生成。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 用于生成对应生物，只能通过创造模式获得。
* 同种可堆叠至16个。

* *[火焰弹](火焰弹.md)**
* 新的弹射物，用于生成[火](火.md)。

* *[下界砖](下界砖.md)**
* 用于合成[下界砖块](下界砖块.md)。

* *[末地传送门方块](末地传送门方块.md)**
* 激活要塞里的末地传送门框架后生成，用于访问末地。

# = 生物 =
* *[末影龙](末影龙.md)**
* 拥有龙息攻击，以及可以发射末影龙火球。

# = 非生物实体 =
* *[物品展示框](物品展示框.md)**
* 用于展示物品。

* *[末地水晶](末地水晶.md)**
* 自然生成在末地，可被任意弹射物或徒手打破。
* 末影龙靠近时，会向其发射治疗光束。

# = 世界生成 =
* *[末地](末地.md)**
* 有限大小，且有建筑高度限制。
* 黑曜石柱会围绕返回传送门而生成，最高的两个黑曜石柱上面的末地水晶会被铁栏杆保护着。
* 玩家进入后会生成一个[返回传送门](返回传送门.md)，但只有在玩家杀死末影龙后才会激活。

* *[生物群系](生物群系.md)**
* 重新加入了[沙滩](沙滩.md)生物群系。

# = 常规 =
* *音效**
* 加入了“end.ogg”、“nether1.ogg”和“nether2.ogg”背景音乐。

* *选项**
* 为分屏和全屏模式加入了[HUD](HUD.md)大小选项，分屏下允许每个玩家选择自己的界面大小。
* 加入了重设下界的选项，用于为旧有世界生成新加入的[下界要塞](下界要塞.md)。
* 加入了是否显示死亡消息的选项。
* 加入了是否在屏幕上显示玩家形象的选项。

# 更改
# = 方块 =
* *[栅栏门](栅栏门.md)**
* 现在可以使用红石控制开关。

* *[音符盒](音符盒.md)**
* 提升了发声距离。

* *[藤蔓](藤蔓.md)**
* 现在允许玩家攀爬。

* *[发射器](发射器.md)**
* 若装有刷怪蛋，那么在激活时会生成对应生物。
* 若装有液体桶，那么在激活时会倒出或吸入液体。

* *[台阶](台阶.md)**
* 配方现在会给予6个成品。
* 此次更新后合成的木台阶是可燃的，且不能和此前的不可燃台阶堆叠。

* *[沙砾](沙砾.md)**
* [30px](File:Gravel JE4 BE3.png.md) 更改了纹理。

* *[下界疣](下界疣.md)**
* 现在可以在主世界里生长。
* 现在会在下界的任意地方自然生成，而不仅仅在下界要塞里。

* *[告示牌](告示牌.md)**
* 现在可堆叠至16。
* 配方现在会给予3个成品。

* *[按钮](按钮.md)**
* 合成石头按钮现在只需要一个石头。
* 木按钮暂时不能被箭激活。

* *[活板门](活板门.md)**
* 现在可放置在楼梯的背面和单个台阶上。

* *[下界砖块](下界砖块.md)**
* 现在可通过4个下界砖合成获得。

# = 物品 =
* *[碗](碗.md)**
* 现在可堆叠至64。

* *[剑](剑.md)**
* 在“允许建造和挖掘”选项在无限制的情况下，现在允许玩家使用剑进行格挡。

* *[地图](地图.md)**
* 在有玩家进入末地后，地图上的末地传送门会以“X”标记。

* *[可可豆](可可豆.md)**
* [30px](File:Cocoa Beans JE3 BE2.png.md) 更改了纹理。

* *[铁桶](铁桶.md)**
* 现在可堆叠至16。

# = 生物 =
* *[绵羊](绵羊.md)**
* 现在可以通过吃草而重新长出羊毛。

* *[恶魂](恶魂.md)**
* 减小了空闲音量。
* 增大了发射火球时的音量。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 群系的边界现在会出现更平滑的颜色渐变。

* *[村庄](村庄.md)**
* 铁匠铺内的战利品箱子现在和要塞内的保持一致。

* *[下界要塞](下界要塞.md)**
* 下界疣种植区域现在会更加常见。

# = 常规 =
* *商店**
* 更改了显示方式，现在会以DLC发布顺序而显示。

* *教程世界**
* 移动了12个音乐唱片任务中的6个。
* 增加了可攀爬的藤蔓和一些新物品，同时增加或移除了酿造、耕作和繁殖相关物品箱子里的内容。

* *教学内容**
* 加入了末地和繁殖的相关内容。

* *[成就](成就/原主机版与New Nintendo 3DS版.md)**
* 移除了创造模式下的成就获得警告。

* *性能**
* 改进了光照性能。
* 提升了加载和保存速度。

# 修复
* 玩家可以以任意皮肤而使用披风。
* 火球穿越下界传送门时冻结。
* 使用末影珍珠后游戏崩溃。
* 洞穴蜘蛛的大小不正确。
* 经验球的捡起音效只以一个音高播放。
* 使用活塞推动荧石时游戏崩溃。
* 世界边界的区块加载导致游戏崩溃。
* 在“更改皮肤”屏幕下，玩家的进食动画不正确。
