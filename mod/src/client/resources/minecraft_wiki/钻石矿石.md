# 钻石矿石

*页面ID: 6110* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *钻石矿石（Diamond Ore）**是一种较为珍贵的[矿石](矿石.md)方块。

* *深层钻石矿石（Deepslate Diamond Ore）**是以[深板岩](深板岩.md)作为容矿岩的钻石矿石变种。

# 生成
# = 自然生成 =
# == 矿团 ==
钻石矿石会以[团簇](团簇.md)的形式生成于[主世界](主世界.md)高度为Y=-64至16的石头之间，越靠近基岩层生成量越多，且不常露天生成。按照团簇的大小和放置数量，钻石团簇可分为4种：
* 普通团簇大小为1-4，每个区块最多尝试生成7次。生成范围高度在Y=-64到16之间，高度越低生成概率越高。暴露在空气中的钻石矿石有50%的概率跳过生成。生成数量服从[三角形分布](wzh:三角形分布.md)。
* 掩埋的团簇大小为1-8，每个区块最多尝试生成4次。生成范围高度在Y=-64到16之间，高度越低生成概率越高。这种团簇不会暴露在空气中。生成数量服从[三角形分布](wzh:三角形分布.md)。
* 大团簇大小为1-12，每个区块最多尝试生成9次，但有的概率失败。生成范围高度在Y=-64到16之间，高度越低生成概率越高。暴露在空气中的钻石矿石有70%的概率跳过生成。生成数量服从[三角形分布](wzh:三角形分布.md)。
* 中团簇大小为1-8，每个区块尝试生成2次，均匀生成在Y=-64到-4之间。暴露在空气中的钻石矿石有50%的概率跳过生成。生成数量服从[离散型均匀分布](wzh:离散型均匀分布.md)。

生成于[深板岩](深板岩.md)或[凝灰岩](凝灰岩.md)间的钻石矿石会被替换为深层钻石矿石。

# == 化石 ==
深层钻石矿石会在Y=0以下的[化石](化石.md)结构中取代部分[骨块](骨块.md)生成。

# 获取
钻石矿石和深层钻石矿石只能通过破坏对应方块获得。

# 破坏
挖掘钻石矿石和深层钻石矿石的合适工具是镐。钻石矿石和深层钻石矿石需要铁镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，钻石矿石和深层钻石矿石被破坏后会掉落1个[钻石](钻石.md)和，挖掘工具的[时运](时运.md)魔咒会增加钻石的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，钻石矿石和深层钻石矿石被破坏后会掉落自身。
