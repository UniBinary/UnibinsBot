* *信标（Beacon）**是一种特殊的功能型[方块](方块.md)，它被激活时可以向天空发射光柱，并持续对周围玩家施加临时的[状态效果](状态效果.md)。

# 生成
信标不会生成在世界中。

# 获取
# = 合成 =

# 破坏
没有工具可以加速对信标的挖掘。

信标被破坏后会掉落自身。

被[爆炸](爆炸.md)破坏的信标总是会掉落。

# 用途
信标无法被活塞移动。

当被“激活”时，信标可提供两种功能：
* 一条直射云端的地标性光柱，可以在很远的距离外看到。
* 增益效果，信标赋予处于特定范围内的玩家正面的状态效果。

信标可以[含水](含水.md)。

# = 激活 =
[缩略图|信标基座可以由不同的矿物方块组成](File:Beacon multitype pyramid.gif.md)
要激活一个信标，信标必须达成以下条件：
* 信标的上方直至建筑高度限制处不能有除[基岩](基岩.md)外的[完全固体渲染方块](遮挡形状.md)，[遮光玻璃](遮光玻璃.md)也被视为遮挡方块。
* 信标要在由[铁块](铁块.md)、[金块](金块.md)、[绿宝石块](绿宝石块.md)、[钻石块](钻石块.md)或[下界合金块](下界合金块.md)组成的金字塔结构的顶部。

# == 金字塔 ==
[缩略图|右|四种有效的金字塔结构，复杂度从右到左逐渐增加](File:Beacon Pyramid.png.md)

金字塔是激活信标的所需建筑。金字塔有4个不同的等级。金字塔层数越多，在信标界面中可选择的效果选项就会越多，作用范围也会更广。使用不同种类的矿物方块建造金字塔只起到装饰作用，实际上没有任何效果，也不会影响信标的功能。若金字塔受损，信标会失效，但信标会保存其增益效果的设置状态，并在金字塔修复后信标重新激活时便会恢复，不需要重新消耗物品。

[缩略图|右|200px|多信标金字塔示例，这个有6个信标的金字塔使用了尽可能少的矿物方块建造的结构提供了所有6种效果](File:Efficient beacon.png.md)
多个信标可以重复利用其底下的矿物方块。合并的金字塔不需要对称。示例图片中展示了一个有6（2×3）个信标的金字塔。建造它需要244个矿物方块，它的基座为10×11。

# = 光柱 =
如果信标满足激活条件，则信标会出现垂直光柱。光柱的垂直高度会渲染至Y=2048。玩家离光柱越远，光柱将渲染得越厚。

光柱的可见距离与客户端设置的渲染距离相同。在渲染距离允许的情况下，光柱最远可在或外看见。

光柱只是一种视觉效果，并不影响周围的实际[亮度](亮度.md)。

通过在信标方块上面放置[染色玻璃](染色玻璃.md)、[染色玻璃板](染色玻璃板.md)、或可改变光柱的颜色。光柱将会根据它上方的玻璃的颜色而改变它自己的颜色：第一个染色玻璃设置光柱的初始颜色，接下来的染色玻璃会把射入的光柱颜色与自身颜色进行等比例混合向下取整并射出，颜色值与它们对应的[染料纹理漫反射颜色](染料#颜色.md)相同。若一个信标光柱的染色玻璃颜色从下到上为<math>\{c_0,c_1,c_2,...,c_k\}</math>，则最终射出的光柱颜色为<math>2^{-k}c_0+\sum_{i=1}^k2^{i-k-1}c_i</math>（此公式可能略有偏差，因为游戏每个步骤中都会进行向下取整，使得最终值小于此公式计算值）。光柱颜色总数为4928458。

信标光柱不能穿过大多数[完整方块](完整方块.md)，但可以穿过[基岩](基岩.md)（以允许在[下界](下界.md)使用信标）、[末地传送门框架](末地传送门框架.md)和其他信标。

# = 增益效果 =

信标发出光柱后，玩家可以按键打开其界面，通过消耗[铁锭](铁锭.md)、[金锭](金锭.md)、[绿宝石](绿宝石.md)、[钻石](钻石.md)或[下界合金锭](下界合金锭.md)来为一定距离内的玩家提供增益效果，每次修改效果都需要消耗1份上述矿物。消耗的物品种类不会对提供的增益效果造成影响。

在界面里，放置耗材到空槽里，然后通过点击显示的选项来选择一个主效果。座落在4级金字塔上的信标会显示辅助效果，点击会提供一个第二个同时存在的加成。当点击“完成”按钮（绿色的✓标志）时，物品会被消耗，然后激活增益效果。切换增益效果也需要使用耗材。

5种主效果分别是：
*  I：增加移动速度。
*  I：增加破坏方块的速度。
*  I：减少外来几乎所有的伤害（需要2级金字塔）。
*  I：增加跳跃距离和高度（需要2级金字塔）。
*  I：增加近战伤害（需要3级金字塔）。

信标金字塔为4级时，还能够从下列两种辅助效果当中额外选择一个激活：
*  I：恢复生命值。
* 增加主效果等级至等级 II。

两种不同的主效果也能相互结合。操作步骤为：
* 在左面板选择一个主效果；
* 在右面板选择II级选项；
* 在左面板选择第二个主效果。

只有其中一个效果被显示为已选，但两者都会被激活。

如果玩家在信标的作用范围内，信标每4秒会将被选定的状态效果按一个固定的时长给予玩家，或者将玩家已有的状态效果的剩余时长重设为此时长，1级信标中此时长为11秒，金字塔每增加一级，此时长增加2秒。

# == 范围 ==
信标的作用范围是以信标自身为中心的一片长方体区域。这个区域向下和向水平各个方向延伸的距离取决于金字塔的大小（见下表），计算公式为：<code>-{}-信标等级 × 10 + 10</code>。{{only|JE|for=向上延伸的距离为<code>-{}-效果半径 + 所在维度世界高度</code>格<ref>在主世界、主世界洞穴为384格，在下界、末地为256格。</ref>}}或。

信标的效果持续时间（秒）同样取决于金字塔的大小，计算公式为：<code>-{}-9 + 信标等级 × 2</code>。

玩家与信标之间的距离不会影响效果的强度。
