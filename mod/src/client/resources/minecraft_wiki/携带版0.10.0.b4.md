# 携带版0.10.0.b4

*页面ID: 28521* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.10.0 alpha build 4**是[v0.10.0 alpha](携带版0.10.0.md)的第4个测试版，发布于2014年10月31日，修复了一些漏洞。

# 更改
# = 方块 =
* *[玻璃](玻璃.md)**
* 现在仅渲染朝向玩家一侧的纹理。

# = 常规 =
* *性能**
* 游戏转到后台后会限制CPU使用量。

# 修复
* *修复了12个漏洞**
* 修复了所有导致黑屏的漏洞。
* 修复了大部分设备里模板化阴影丢失的漏洞。
* 修复了PowerVR设备里火把和花出现黑色线条的漏洞。
* 禁用精美图像选项后的水中不再出现浓雾。
* 坡道上的铁轨有错误的判定箱。
* 花和骨头产生错误数量的染料。
* 生物可以生成在树叶里。
* 切换或重启应用导致游戏崩溃。
* 创建世界时内存溢出。
* 使用Alpha通道渲染的方块（例如玻璃和树叶）不会出现阴影。
* 鸡的头部的底部纹理出现黑色斑块。
* 物品栏内穿着盔甲的玩家模型受环境光照影响。</onlyinclude>
