* *追逐天空（Chase the Skies）<ref></ref>**是一次[小更新](小更新.md)，发布于2025年6月17日<ref></ref>。主要内容为加入[失水恶魂](失水恶魂.md)、[快乐恶魂](快乐恶魂.md)、的、[鞍](鞍.md)的合成配方及[定位栏](定位栏.md)，并改进[拴绳](拴绳.md)。

本次更新也被称为“2025夏季小更新”（Summer Drop 2025），以[实验性玩法](实验性玩法.md)形式加入游戏时使用名称是“”（Drop 2 2025），其正式名称于2025年6月1日在[Minecraft Monthly](Minecraft Monthly.md)上公布。<ref></ref>

# 重要特性

# = 方块 =
* * [失水恶魂](失水恶魂.md)**
* 会作为[下界化石](下界化石.md)的一部分自然生成，也可由1个[灵魂沙](灵魂沙.md)和8个[恶魂之泪](恶魂之泪.md)合成，还可以通过[以物易物](以物易物.md)获得。
* 可[含水](含水.md)，含水期间会逐渐变为白色并逐渐变为笑脸，并在大约20分钟后转变成[小恶魂](小恶魂.md)。
* 脱离水后会逐渐变回最初的状态。

# = 物品 =
* *[32px](File:Happy Ghast Spawn Egg JE1 BE1.png.md) [快乐恶魂刷怪蛋](快乐恶魂刷怪蛋.md)**
* 用于生成[快乐恶魂](快乐恶魂.md)。

* * [挽具](挽具.md)**
* 可由3个[皮革](皮革.md)、2个[玻璃](玻璃.md)和1个任意[羊毛](羊毛.md)合成。
* 有16种颜色，取决于合成时所用羊毛的颜色。
* 用来对[快乐恶魂](快乐恶魂.md)使其可被[骑乘](骑乘.md)。

* *[32px](File:Music Disc Tears JE1 BE1.png.md) [音乐唱片*Tears*](音乐唱片Tears.md)**
* 玩家反弹[火球](火球.md)击杀[恶魂](恶魂.md)时掉落。

# = 生物 =
* *[48px](File:Happy Ghast JE1 BE1.gif.md) [32px](File:Ghastling JE1 BE1.gif.md) [快乐恶魂](快乐恶魂.md)**
* 一种新的友好[生物](生物.md)，幼年形态由[失水恶魂](失水恶魂.md)生成，称作“[小恶魂](小恶魂.md)”。
* * 给其喂食[雪球](雪球.md)可以加速其成长。
* 对其使用[挽具](挽具.md)后可以[骑乘](骑乘.md)，最多可以容纳4名玩家骑乘。
* 会在空中悬停，此时玩家可以在站立在其上表面。
* 未被骑乘时会被手持[雪球](雪球.md)的玩家吸引。
* 快乐恶魂和小恶魂会每自然恢复，在[主世界](主世界.md)中，处于[雨](雨.md)或[雪](降雪.md)中时或飞行高度与[云](云.md)的高度相同时则会每自然恢复。

# = 游戏内容 =
* *[定位栏](定位栏.md)**
* [HUD](HUD.md)的一部分，用于指示其他玩家的方向。
* 启用定位栏时，如果世界中有多个玩家，定位栏会取代经验栏显示，经验等级仍会保留。
* 玩家的摄像机面向某玩家120度以内时，定位栏会显示彩色提示标识。如果某玩家位于视线上方或下方30度以上，会显示箭头以提示。
* 处于以下情况的玩家不会显示在定位栏中：
* * 处于潜行状态。
* * 穿戴[生物头颅](生物头颅.md)或[雕刻南瓜](雕刻南瓜.md)。
* * 带有[隐身](隐身.md)状态效果。
* * 处于旁观模式。
* 地图创作者和服务器管理员可选择禁用定位栏。
