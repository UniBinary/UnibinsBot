# Java版19w06a

*页面ID: 39713* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w06a**是[Java版1.14](Java版1.14.md)的第20个快照，发布于2019年2月6日<ref></ref>，加入了新的可选方块状态和新的启动界面，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[方块状态](方块状态.md)**
* 加入了新的可选[方块](方块.md)[物品](物品.md)标签： <code>BlockStateTag</code>。
* * 格式为<code>{BlockStateTag:{*state*:"*value*",*state2*:"*value2*",*stateN*:"*valueN*"}}</code>。
* 物品模型不受影响。

* *启动界面**
* 在启动界面加入了进度条。
* 加载完成后，启动屏幕将淡入主菜单。

# 更改
# = 生物 =
* *[流浪商人](流浪商人.md)**
* 现在会在晚上喝下隐身[药水](药水.md)。
* * 日出时会喝下[牛奶](牛奶.md)解除效果。
* 现在有一个包含方块位置的NBT标签。设置后，它们将寻找该位置。

# = 世界生成 =
* *[丛林神庙](丛林神庙.md)**
* 现在会生成于。
* *[村庄](村庄.md)**
* 改进了村庄铁匠铺的生成以防止被内部的熔岩引燃。
* * 沙漠铁匠铺建筑被移除。

# = 常规 =
* 稍微改进了启动时间。
* *[LWJGL](Tutorial:升级LWJGL.md)**
* 更新至3.2.1版本。
* *[粒子](粒子.md)**
* 粒子现在被拆分成每帧单独的纹理文件，取代原来的。
* * 不能使用<code>.mcmeta</code>文件来加载粒子动画；它们仍然是硬编码的。
