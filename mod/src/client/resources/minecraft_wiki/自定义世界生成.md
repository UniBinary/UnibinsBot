# 自定义世界生成

*页面ID: 66671* | *来源: Minecraft Wiki*

* *自定义世界生成（Custom world generation）**可以让[数据包](数据包.md)改变世界的生成方式。

# 世界预设和维度

* *世界预设（World Preset）**和**维度（Dimension）**控制世界具有哪些维度。虽然原版游戏全部使用世界预设定义维度，但游戏仍然支持通过维度文件定义维度。

每个维度都定义了维度使用的地形生成器（噪声、调试或超平坦）。如果是噪声生成器，则还定义了使用的噪声设置和可生成的生物群系，以及生物群系的分布。

# 噪声设置

* *噪声设置（Noise settings）**定义了地形和噪声洞穴所生成的形状，以及地形生成时所附带的方块。噪声设置可通过维度中的噪声生成器来使用。

# 密度函数

* *密度函数（Density Function）**能将随坐标变化的值提供给噪声设置的噪声分配器。

# 噪声

* *噪声（Noise）**用于产生随坐标变化的值，可被密度函数或表面规则引用。

# 生物群系

* *生物群系（Biome）**是在维度里划分出的区域，具有独特的地物、雕刻器、气候、生成的生物、环境音效、音乐以及天空、水、草地和树叶的颜色。

# 雕刻器

* *雕刻器（Carver）**用于雕刻出洞穴或峡谷。注意：噪声洞穴由噪声设置生成，而非雕刻器。

# 地物

* *地物（Feature）**是在地形生成后在每个区块生成的装饰性方块结构。

# 结构

* *结构（Structure）**，也被称为**结构地物（Structure Feature）**，是一种用于生成结构的地物，其中拼图结构提供了多种自定义结构的方法。

# 地表生成器

* *地表生成器（Surface builder）**控制了地表的形状和其生成的方块。
