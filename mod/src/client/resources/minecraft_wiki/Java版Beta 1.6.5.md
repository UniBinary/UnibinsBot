# Java版Beta 1.6.5

*页面ID: 32748* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.6.5**是的一次次要更新，发布于2011年5月28日，修复了一些漏洞。

# 更改
* 重新加入了高级OpenGL（仍然存在与[Beta 1.5](Java版Beta 1.5.md)相同的漏洞）。
* 现在可以更改帧率，可以切换至40帧，90帧和200帧。除了40帧外，当出现方块更新时，帧速率将只会被限制。<ref></ref>
* +点击合成窗口里的物品现在只会移动已经[合成](合成.md)的物品到[玩家](玩家.md)的[物品栏](物品栏.md)中。
* 游戏中的版本号不再显示，但在标题屏幕和调试屏幕上仍然可见。
* 骑乘实体和睡觉的玩家现在在离开游戏将会取消骑乘或睡觉。
* 减弱了[潜行](潜行.md)效果，玩家的脚看起来像悬浮在空中。
* 现在可以潜行着走上[楼梯](楼梯.md)和[台阶](台阶.md)。

# 修复
* *修复了14个漏洞**
* 玩家在地图上所显示的方向现在与玩家实际方向一致，而不是像以前一样有稍微偏移。
* 修复了有时手持地图加载区块会导致游戏崩溃的问题。
* 掉落的装备不会在第一次使用时被损坏了（某些情况下仍然会损坏）。
* 现在，如果一个物品在方块内，会被自动弹出来。
* 放置和破坏火把时的光照又表现的正常了。
* 游戏不会再在使用键点击放入和取出物品时崩溃了。
* 修复了多人游戏中的CPU问题。
* 在蹲下时保存游戏不会在加载存档时一直把玩家传送到上面或下面的方块里了。
* 玩家退出矿车或将一个矿车移动到另一个矿车处不再会撞到并使原始矿车移动起来。
* 修复了玩家生命值在进入和离开下界时看起来是满的的问题。
* 修复了在多人游戏中，一些实体看起来反复的落下并穿过地面的问题。
* 修复了服务器在玩家没有走到角落时判定走到了角落的问题。
* 修复了成就窗口会在窗口外渲染一些图形的问题。
* 修复了几个在多人游戏中，床表现的很奇怪的问题。主要是床“已被占用”的漏洞。</onlyinclude>
