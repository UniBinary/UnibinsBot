# Java版12w18a

*页面ID: 32368* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w18a**是[Java版1.3.1](Java版1.3.1.md)的第4个快照，发布于2012年5月3日<ref></ref>，由于进行了客户端和服务端的逻辑分离，导致此版本存在极多的错误。

# 新内容
# = 方块 =
* *[木头](木头.md)和[木板](木板.md)**
* 木头和木板现在有了正确的名字（例子：橡木木板、云杉台阶）

# 更改
# = 物品 =
* *[书与笔](书与笔.md)**
* 编辑时不再暂停游戏。

* *[告示牌](告示牌.md)**
* 编辑时不再暂停游戏。

* *[可可豆](可可豆.md)**
* 可可豆可以通过丛林树的叶子中获得。

* *[工具](工具.md)**
* 木质工具现在可以用作燃料，每个能烧炼1个物品。

# = 生物 =
* *[村民](村民.md)**
* 通过[刷怪蛋](刷怪蛋.md)生成的村民会获得随机的职业。

* *[玩家](玩家.md)**
* 名称为“Notch”的玩家死亡后不再会额外掉落1个[苹果](苹果.md)。

# = 游戏内容 =
* *[极限模式](极限模式.md)**
* [多人游戏](多人游戏.md)中可用。
* 现在在多人游戏死亡的极限模式的玩家会被自动封禁。

* *[单人游戏](单人游戏.md)**
* 分离了服务器逻辑和客户端，因此单人游戏现在在本地服务器中进行。

# = 命令格式 =
* *常规**
* 输入命令、使用书与笔书写和显示暂停菜单时游戏不再暂停。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 坐标现在四舍五入到五位数。
* 加入了、和值（移动速度、飞行速度和玩家接触到地面时值为）。

* *[语言](语言.md)文件**
* 更新了语言文件。

* *[纹理包](纹理包.md)**
* 支持服务器纹理包自动下载。

* *[闪烁标语](闪烁标语.md)**
* 弹出“[Mojang](Mojang.md)”屏幕的时间现在为1秒而不是3秒。

* *[无限世界预览器](无限世界预览器.md)**
* 被彻底移除。

# 修复
* *修复了4个漏洞**
* 修复了玩家不能切换到物品栏中同种类工具的漏洞。
* 修复了从上方破坏非固体方块时会破坏水的问题。
* 修复了手持工具从创造模式物品栏中取出方块时导致玩家丢失它的问题。
* 修复了使用精准采集挖掘双台阶时只掉落一个而不是两个的问题。</onlyinclude>

# 你知道吗
* 在此版本中，加载单人游戏世界时，需先将中的（服务端）手动放置到下才能继续加载世界。
