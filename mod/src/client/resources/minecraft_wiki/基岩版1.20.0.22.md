# 基岩版1.20.0.22

*页面ID: 104042* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.0.22**（ChromeOS/Android）、**Preview 1.20.0.22**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.0](基岩版1.20.0.md)的第3个测试版，发布于2023年4月26日<ref></ref>，加入了[音乐唱片](音乐唱片.md)Relic、新的[音乐](音乐.md)曲目和命令，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* 加入了音乐唱片Relic，作者为[Aaron Cherof](Aaron Cherof.md)。
* * 目前仅能通过[创造模式物品栏](创造模式物品栏.md)或[命令](命令.md)获得。
* * 能通过[红石比较器](红石比较器.md)输出15格红石信号。<ref></ref>

# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“实验相机”子选项。
* * 用于启用命令。

* *[加载提示](加载提示.md)**
* 加入了[足迹与故事](足迹与故事.md)相关的加载提示。

* *[音乐](音乐.md)**
* 加入了4首新的音乐，作者为[Aaron Cherof](Aaron Cherof.md)：
* * “Bromeliad”会在[竹林](竹林.md)、[樱花树林](樱花树林.md)、[繁花森林](繁花森林.md)、[森林](森林.md)、[丛林](丛林.md)和[稀疏的丛林](稀疏的丛林.md)中播放。
* * “Crescent Dunes”会在[沙漠](沙漠.md)和所有种类的[恶地](恶地.md)中播放。
* * “Echo in the Wind”会在樱花树林、繁花森林、[繁茂洞穴](繁茂洞穴.md)和所有种类的恶地中播放。
* * “A Familiar Room”目前不会播放。<ref name="music-issue"></ref>
* * 不同于，这些音乐目前均不会在[菜单屏幕](菜单屏幕.md)中播放。<ref name="music-issue"></ref>

* *[闪烁标语](闪烁标语.md)**
* 加入了以下闪烁标语：
* * This sand is sus
* * Remember to brush your... ...teeth
* * Has working bookshelves!
* * Sniff sniff...
* * Place hanging sign here

# 更改
# = 方块 =
* *[苔藓块](苔藓块.md)**
* 现在可以在上方种植[甘蔗](甘蔗.md)和[竹子](竹子.md)。

* *[瓶子草](瓶子草.md)**
* 现在能合成出2个青色染料，而不是1个。

* *[火把花](火把花.md)**
* 现在可用于喂食[哞菇](哞菇.md)。

* *[嗅探兽蛋](嗅探兽蛋.md)**
* 现在仅当放置于苔藓块上时会发出粒子效果。

* *[可疑的沙砾](可疑的沙砾.md)**
* 现在可以在上方种植竹子。

* *[可疑的沙子](可疑的沙子.md)**
* 现在可以在上方种植甘蔗、[仙人掌](仙人掌.md)和[枯萎的灌木](枯萎的灌木.md)。

* *[幽匿感测体](幽匿感测体.md)**
* 激活状态的持续时长由40游戏刻改为30游戏刻。
* 冷却状态的持续时长由1游戏刻改为10游戏刻。

* *[校频幽匿感测体](校频幽匿感测体.md)**
* 激活状态的持续时长由20游戏刻改为10游戏刻。
* 冷却状态的持续时长由1游戏刻改为10游戏刻。

# = 物品 =
* *[陶片](陶片.md)**
* 英文名称由“Pottery Shard”更改为“Pottery Sherd”。

# = 生物 =
* *[嗅探兽](嗅探兽.md)**
* 现在能被[火把花种子](火把花种子.md)吸引。

# = 世界生成 =
* *[古迹废墟](古迹废墟.md)**
* 新增了34个结构文件。
* 不再生成[沙子](沙子.md)和[可疑的沙子](可疑的沙子.md)。
* 调整了[沙砾](沙砾.md)和[泥土](泥土.md)的数量。
* 调整了[可疑的沙砾](可疑的沙砾.md)的数量。
* 可疑的沙砾中的战利品表现在被拆分。
* * 稀有战利品和普通战利品现在有各自独立的战利品表。

* *[海底废墟](海底废墟.md)**
* 向热带海底废墟的可疑的沙子的战利品表中加入了[嗅探兽蛋](嗅探兽蛋.md)。

# = 常规 =
* *[音乐](音乐.md)**
* 更改了以下音乐可播放的位置：
* * “Aerie”“Firebugs”和“Labyrinthine”现在不再会在所有种类的丛林中播放。

* *[闪烁标语](闪烁标语.md)**

# = 技术性 =
* *附加包和脚本引擎**
* 现在南瓜方块会使用字符串类型状态而不是整型状态。

* *命令**
* 命令选择器现在可以正确检测活动对象的物品栏中是否有已创建的地图或烟火之星。
* 现在会在命令栏的预览中显示命令描述。

* *基岩版编辑器**
* 修复了客户端的默认命令权限与多人游戏的命令权限显示不同的漏洞。
* 工具模式现在会使用原版键盘进行移动控制，而非使用硬编码的/////键。现在可以在设置菜单中自定义移动与键盘的绑定。

* *物品**
* 使用的自定义物品现在在悬浮提示中和在唱片机播放时会显示正确的声音描述。

# 修复
* *可疑的方块**
* 甘蔗、仙人掌和枯萎的灌木现在可以种植在可疑的沙子上。（、）
* 竹子现在可以种植在可疑的沙子和可疑的沙砾上。（、)
* 甘蔗和竹子现在可以种植在苔藓块上。

* *考古**
* 古迹废墟不再会部分裸露地生成。（）
* 古迹废墟的可疑的沙砾战利品表中不再会出现重复的红砖抽出项。（）

* *瓶子草与瓶子草植株**
* 修复了植株纹理显得更暗的问题。
* 现在用瓶子草合成青色染料会给予2个染料，而不是1个。（）

* *火把花**
* 哞菇现在可以被喂食火把花。（）

* *嗅探兽**
* 嗅探兽现在会倾向于繁殖，而不是倾向于搜寻并刨挖物品或被吸引。
* 嗅探兽现在会在刨挖时产生粒子效果。（）
* 嗅探兽不再会在水中搜寻并刨挖物品。
* 调整了嗅探兽的行走循环动画，使之更加流畅。
* 嗅探兽蛋现在只会在放置在苔藓块上时产生粒子效果，以表示加速孵化。

* *游戏内容**
* 楼梯下飞行时不再会禁用飞行。（）
* 蜜蜂进食时不再会发出玩家进食的音效。（）

* *用户界面**
* 启用“显示坐标”选项后，新的死亡屏幕中不再会显示坐标。
* 为缺失感叹号的闪烁标语加入了感叹号以匹配Java版。（）
* 更新了取消骑乘骆驼的提示框以匹配其他可骑乘生物的提示框。

* *物品**
* 将牧民盔甲纹饰锻造模板的图标向右移动了一个像素。（）
* 将向导盔甲纹饰锻造模板的图标向右移动了一个像素。（）
* 修复了物品展示框中的物品在某些情况下显得过小的问题。（）</onlyinclude>
