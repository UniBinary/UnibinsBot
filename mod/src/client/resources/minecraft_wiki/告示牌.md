# 用途
# = 放置 =
[thumb|right|告示牌在两种放置状态下高度的不同对比，图中将两个告示牌放在同一个方块的位置以便于比较，实际游戏中不可能做到](File:Sign scales.png.md)

告示牌必须放置在[固体方块](固体方块.md)（包括[栅栏](栅栏.md)、[玻璃](玻璃.md)、和其他告示牌）的顶端或侧面。要放置一个告示牌，对着要放置的位置一个告示牌物品，接着输入所需文本（可以为空），点击“完成”或者按钮（或者在基岩版中按下×按钮，在Xbox手柄按下，在PlayStation手柄按下）。若要把告示牌附着于可交互的方块（如[音符盒](音符盒.md)），放置时需保持[潜行](潜行.md)状态。

放置在方块顶部的普通告示牌会竖立在一根短标杆上，朝向放置此告示牌的玩家，总共可朝向16个不同的方向。放置在方块侧面的告示牌会附在该方块的侧表面，当该方块侧面不完整时则飘浮在其所在格的侧表面。

告示牌会在其附着的方块移动或被移除的情况下被破坏并掉落自身。

# = 文本 =
告示牌可被用于显示文本，最多可输入4行文本。

放置告示牌时，玩家会自动打开告示牌正面的文本编辑界面。如果放置的告示牌已经有文本了（如通过物品数据添加），那么告示牌被放置后不会出现文本输入界面。

输入时可使用鼠标或方向键移动光标位置。

当编辑窗口关闭后，对着已放置的告示牌按下键可重新打开编辑窗口，以编辑其正面或背面的文本；对告示牌[蜜脾](蜜脾.md)会使玩家不可与之交互，要修改内容则需重新放置告示牌。[Xbox 360版](Xbox 360版.md)和[基岩版](基岩版.md)支持Xbox 360屏幕键盘以及使用USB键盘或控制器键盘直接修改文本。

对有文字的告示牌[染料](染料.md)可以改变文本颜色。

告示牌上显示的文字不受周围亮度影响。对告示牌[荧光墨囊](荧光墨囊.md)可以提高文本亮度，使用[墨囊](墨囊.md)可以移除发亮效果。告示牌文字被增亮后会出现外边框，边框颜色随文字颜色而定：

告示牌文本可以包含[格式化代码](格式化代码.md)。告示牌文本可使用[文本组件](文本组件.md)，文本组件在编辑完成之后会以文本保存。

如果有其他玩家正在编辑告示牌内容，则不能与该告示牌进行任何交互。

# = 交互 =
告示牌没有碰撞箱，因此[实体](实体.md)可以穿过告示牌。其他方块（包括其他告示牌）可以被放在告示牌的任何一角。

告示牌被[活塞](活塞.md)推动时会掉落为物品；活塞无法推动告示牌。告示牌被活塞拉动时不会有反应（除非告示牌附在伸出的活塞头表面）。

[水](水.md)和[熔岩](熔岩.md)会绕开告示牌流动。告示牌不会被[火](火.md)燃尽。

# = 燃料 =
除下界木质之外的告示牌可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料。每个告示牌可烧炼1个物品。

# = 安全保护 =

告示牌属于“仅管理员可设置数据”的方块。

非管理员玩家对告示牌按下+时不会复制方块实体数据，放置物品栏中已有的带有方块实体数据的告示牌也不会将数据实际加载。

管理员玩家的物品栏中如果携带着有方块实体数据的告示牌，物品[提示框](提示框.md)中会显示警告信息。

# 你知道吗
* 对告示牌[荧光墨囊](荧光墨囊.md)后文本的发光描边，其实是在原文本的图层下偏移生成数个发光文本营造出的假象。游戏总共会渲染文本9次，对性能造成严重的负面影响。<ref></ref><ref></ref>
* 可以通过观察告示牌的顶面或底面纹理来区分正反面，颜色较深的一侧与正面共边。
* 木质告示牌背面直接使用了对应[木板](木板.md)的纹理，而正面在此基础上淡化了木板上的“板缝”，玩家也能以此来区分正反面。
