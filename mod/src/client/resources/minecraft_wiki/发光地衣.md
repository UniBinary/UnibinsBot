# 发光地衣

*页面ID: 75069* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *发光地衣（Glow Lichen）**是一种具有[亮度](亮度.md)的非固体[方块](方块.md)。

# 生成
# = 自然生成 =
发光地衣自然生成于[主世界](主世界.md)所有高度[洞穴](洞穴.md)内部暴露于空气或[水](水.md)中的[石头](石头.md)、[深板岩](深板岩.md)、[安山岩](安山岩.md)、[闪长岩](闪长岩.md)、[花岗岩](花岗岩.md)、[方解石](方解石.md)、[凝灰岩](凝灰岩.md)和[滴水石块](滴水石块.md)表面。

发光地衣会在每个区块尝试生成104到157次，每次尝试生成会搜索半径20格内的可生成方块（方块顶部除外）。如果生成处于地表以下两格方块内将生成失败。生成成功的发光地衣有50%概率蔓延。

发光地衣不会在[深暗之域](深暗之域.md)生物群系生成。

# 获取
发光地衣只能通过破坏发光地衣获得。

# 破坏
挖掘发光地衣的合适工具是斧、剑和剪刀。

没有被[剪刀](剪刀.md)挖掘破坏时，发光地衣被破坏后不会掉落。

被[剪刀](剪刀.md)挖掘破坏时，发光地衣被破坏后会掉落自身。

# 用途
发光地衣的厚度为格，可以放置在或。

发光地衣可以[含水](含水.md)。

# = 骨粉 =
对发光地衣[骨粉](骨粉.md)会使其蔓延到其他可生长的方块表面，无法生长时骨粉不会被消耗。对发光地衣使用骨粉时，它会尽可能地覆盖其相邻方块的侧面和顶部，但不会蔓延至背面。

发光地衣不会自然蔓延。

# = 光源 =
发光地衣会发出[亮度](亮度.md)为7级的光。

# = 堆肥 =
将发光地衣放进[堆肥桶](堆肥桶.md)有50%的概率使堆肥层数增加1。

# 你知道吗
* 在现实生活中，是真菌和绿藻门或蓝细菌的共生体。
* 如果使用[调试棒](调试棒.md)移除发光地衣的所有方块状态，发光地衣会表现为方块状态均为时的形态，即附着在一个方块内的6个面上。
