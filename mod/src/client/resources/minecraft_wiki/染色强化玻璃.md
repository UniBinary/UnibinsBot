# 染色强化玻璃

*页面ID: 170165* | *来源: Minecraft Wiki*

* *染色强化玻璃（Hardened Stained Glass）**是一种在[化学](化学.md)成分上增强的[染色玻璃](染色玻璃.md)。

# 生成
染色强化玻璃不会生成在世界中。

# 破坏
没有工具可以加速对染色强化玻璃的挖掘。

染色强化玻璃被破坏后会掉落自身。

# 用途
当透过染色强化玻璃看时，与该染色强化玻璃相邻的其他强化玻璃不可见，但在普通玻璃上能看见。
