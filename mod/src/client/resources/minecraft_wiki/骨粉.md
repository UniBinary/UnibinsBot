# 骨粉

*页面ID: 6655* | *来源: Minecraft Wiki*

* *骨粉（Bone Meal）**是一种能被用作大部分植物的肥料的[物品](物品.md)。

# 获取
# = 合成 =

# = 鱼 =

# = 堆肥桶 =
对着装满的[堆肥桶](堆肥桶.md)按下键会掉落1个骨粉。

# = 箱子战利品 =

# 用途
# = 肥料 =
骨粉可作为肥料在下列方块上。装有骨粉且朝向下列方块的[发射器](发射器.md)被激活后同样会起作用。

在[创造模式](创造模式.md)中对下列有生长阶段的方块使用骨粉会使其直接成熟。无法对[含雪](含雪.md)的植物使用骨粉。

# = 农民村民 =
职业为农民的[村民](村民.md)会从填满的[堆肥桶](堆肥桶.md)中获取骨粉，并使用骨粉以加快农作物的生长。

# = 合成材料 =
骨粉在合成配方（给[旗帜](旗帜.md)添加图案除外）中可被用作白色染料。
