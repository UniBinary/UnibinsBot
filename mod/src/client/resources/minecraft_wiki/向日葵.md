* *向日葵（Sunflower）**是一种[大型花](大型花.md)。

# 生成

# = 自然生成 =
向日葵会在[向日葵平原](向日葵平原.md)生物群系自然生成。

# 获取
# = 骨粉 =
对着向日葵[骨粉](骨粉.md)会掉落1株新的向日葵。

# 破坏
向日葵被挖掘时会立刻被破坏。

向日葵被破坏后会掉落自身。

# 用途

向日葵的花盘永远朝向东方，可以用于指示方向。<ref></ref>

# = 合成材料 =

# = 堆肥 =
将向日葵放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
