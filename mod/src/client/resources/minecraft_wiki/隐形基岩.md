# 隐形基岩

*页面ID: 24144* | *来源: Minecraft Wiki*

* *隐形基岩（Invisible Bedrock）**是一种隐形且只能用[命令](命令.md)破坏的固体方块，类似于基岩但形似空气。

# 生成
隐形基岩不会生成在世界中。

隐形基岩是[New Nintendo 3DS版](New Nintendo 3DS版.md)和[树莓派版](树莓派版.md)的世界及[旧世界类型](旧世界类型.md)的世界的边界。

# 获取

隐形基岩无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取，不存在于[创造模式物品栏](创造模式物品栏.md)中，且是不可通过获取的物品，只能通过存档编辑或[附加包](附加包.md)获得。

# 破坏
隐形基岩没有[轮廓箱](轮廓箱.md)，因此不能挖掘隐形基岩。

位于世界之外的隐形基岩不能被破坏，尝试破坏会导致这些方块仍然留在原处而不被改变。

隐形基岩被破坏后不会掉落。

# 用途
隐形基岩只有在渲染时是透明的，它会作为一个与玩家和生物碰撞以及阻挡光线的固体方块，在此特性上与[屏障](屏障.md)类似。玩家无法与它交互，尝试破坏它会破坏它后面的方块。

技术上，隐形基岩使用[石头](石头.md)的纹理。如果玩家摔落到隐形基岩上，会产生可见的石头粒子。在[物品栏](物品栏.md)中，它显示为石头的纹理，并且会填充整个物品栏格子，而不是渲染成像正常方块一样的立方体纹理（事实上所有非固态的方块形态都会在物品栏中以这种样子呈现）。在树莓派版中，它使用玻璃纹理，因为游戏基于纹理转变为石头之前的基岩版正式版本的旧版本。
