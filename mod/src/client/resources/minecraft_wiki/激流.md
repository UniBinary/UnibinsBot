# 激流

*页面ID: 42226* | *来源: Minecraft Wiki*

* *激流（Riptide）**是一种用于[三叉戟](三叉戟.md)的[魔咒](魔咒.md)，能使玩家在[水](水.md)中和[雨](雨.md)中投掷三叉戟快速移动。

# 获取

# 用途
拥有此魔咒的三叉戟将无法投掷，即使玩家没有接触水或雨。

当玩家在接触水或雨时，尝试投掷三叉戟会使激流魔咒生效，玩家将以投掷三叉戟的姿态蓄力，发射时，三叉戟会带着玩家一起飞出，速度随魔咒等级提升，玩家的速度会变为<math>0.75(a+1)v_a+v_o</math>格/游戏刻，其中<math>a</math>为激流魔咒的等级，<math>v_a</math>为玩家当前视线单位向量，<math>v_o</math>为玩家原有速度向量。
冲刺会使玩家会作出翻滚动作，周身出现螺旋状水波。动作持续时间不随魔咒等级改变。

玩家可以通过竖直向上使用附有激流的三叉戟来到达更高的高度。三叉戟位于副手时，激流魔咒也可生效。

玩家使用三叉戟发起冲刺时会使其消耗1点耐久，命中生物时会再消耗1点并停止冲刺。击杀生物时，由于[战利品表](战利品表.md)只检测主手物品的魔咒，因此主手物品中的[抢夺](抢夺.md)和[火焰附加](火焰附加.md)魔咒会影响生物掉落物。除此以外，只有所使用的三叉戟上的魔咒会生效。发起冲刺不会消耗三叉戟的耐久，玩家命中生物时会自动使用主手中的物品对其近战攻击，可以正常触发暴击，并且可以命中路线上的多个目标。

玩家使用激流三叉戟冲刺途中，碰撞体积会暂时变小，与玩家游泳或爬行时的碰撞体积改变相同，允许玩家穿过1×1格的空间。

若激流与[忠诚](忠诚.md)或[引雷](引雷.md)被强行应用在同一个三叉戟上，忠诚和引雷会因无法投掷而失去作用。

在降雨天气中，使用[鞘翅](鞘翅.md)滑翔并配合带有激流魔咒的三叉戟会使玩家达到很高的速度和高度。经过持续加速之后，最大速度可以达到400格/秒以上，而最大高度甚至能够超过600格，超过建筑高度限制。

激流魔咒只在玩家尝试投掷三叉戟时才有实际作用。如果三叉戟由[溺尸](溺尸.md)尝试投掷，则会无视激流魔咒而正常投掷出三叉戟实体。<ref></ref>
