# 基岩版1.16.0.51

*页面ID: 56405* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.0.51**是[基岩版1.16.0](基岩版1.16.0.md)的第6个测试版，发布于2020年3月16日<ref></ref>，加入了首批[下界更新](下界更新.md)特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[远古残骸](远古残骸.md)**
* 可以在[下界](下界.md)的任何高度生成，而高度较低处的生成率更高。
* 可放入熔炉或高炉中熔炼，获得下界合金碎片。
* 爆炸抗性和黑曜石相同，但能够被活塞推动。
* 物品形式能够在[熔岩](熔岩.md)中漂浮。
* 不会被熔岩或[火](火.md)烧毁。
* 需要钻石质或更好的镐来开采。
* 生成时不会暴露于空气中。

* *[玄武岩](玄武岩.md)**
* 组成[玄武岩柱](玄武岩柱.md)的方块。
* 自然生成于[灵魂沙峡谷](灵魂沙峡谷.md)生物群系。
* 与[原木](原木.md)相似，可沿不同方向摆放。

* *[下界合金块](下界合金块.md)**
* 可由9个下界合金锭合成获得。
* 不会被[熔岩](熔岩.md)和[火](火.md)烧毁。
* 与黑曜石有着相同的爆炸抗性，但可被活塞推动。

* *[绯红菌和诡异菌](下界菌.md)**
* 分别生成于绯红森林和诡异森林生物群系。
* 可放置在[泥土](泥土.md)、[花盆](花盆.md)、[砂土](砂土.md)、[耕地](耕地.md)、[灰化土](灰化土.md)、[草方块](草方块.md)、[菌岩](菌岩.md)、[灵魂土](灵魂土.md)和[草方块](草方块.md)上。
* 对种在对应变种菌岩上的下界菌使用骨粉可使之生长为对应的巨型下界菌。
* 与[蘑菇](蘑菇.md)不同，下界菌不能蔓延。

* *[绯红菌岩和诡异菌岩](菌岩.md)**
* 与[草方块](草方块.md)类似。
* 对与菌岩相邻的[下界岩](下界岩.md)使用骨粉可使其蔓延。

* *[绯红木板和诡异木板](木板.md)**
* 不可燃尽。
* 可由对应的菌柄方块合成获得。
* 可用于合成对应的[台阶](台阶.md)、[楼梯](楼梯.md)、[栅栏](栅栏.md)、[栅栏门](栅栏门.md)、[压力板](压力板.md)、[按钮](按钮.md)、[告示牌](告示牌.md)、[门](门.md)和[活板门](活板门.md)。

* *[绯红菌索和诡异菌索](菌索.md)**
* 装饰性植物，生成于[绯红森林](绯红森林.md)、[灵魂沙峡谷](灵魂沙峡谷.md)和[诡异森林](诡异森林.md)生物群系。
* 可种植在[花盆](花盆.md)中。

* *[绯红菌柄和诡异菌柄](菌柄.md)**
* 一类组成巨型菌枝干的方块。
* 拥有动态的纹理。
* 顶面的纹理和其他原木相似，呈年轮状。
* 与原木相似，可沿不同方向摆放。
* 不可燃尽。
* 具有对应的去皮变种。

* *[下界苗](下界苗.md)**
* 一种生成于诡异森林生物群系的、类似草丛的植物。

* *[磨制玄武岩](磨制玄武岩.md)**
* 新的装饰性方块。
* 可由4个[玄武岩](玄武岩.md)合成获得。

* *[菌光体](菌光体.md)**
* 与荧石相似，会发出亮度等级为15的光。
* 可使用任意工具采集，但锄和斧是最快的。
* 会作为[巨型菌](巨型菌.md)的一部分生成。

* *[灵魂火](灵魂火.md)**
* 火的蓝色变种。
* 在任何维度下，在灵魂土上点燃的火焰都会呈蓝色。
* * 与下界岩上的火焰相似，会永久燃烧，也不会被雨淋熄。
* 自然生成于下界的灵魂沙峡谷生物群系。
* 每秒会造成伤害，而普通火焰每秒只会造成伤害。

* *[灵魂灯笼](灵魂灯笼.md)**
* 会发出亮度等级为10的光。
* 合成配方与普通的灯笼相似，但需使用灵魂火把而非普通火把。
* 拥有动态的纹理。

* *[灵魂火把](灵魂火把.md)**
* 会发出亮度等级为10的光。
* 合成配方与普通的火把相似，但木棍下方还需放置灵魂土。

* *[灵魂土](灵魂土.md)**
* 和[灵魂沙](灵魂沙.md)一同生成于灵魂沙峡谷生物群系。
* 在其上点燃的火焰为灵魂火。
* 玩家在其上行走时既不会“下陷”，也不会受到减速影响。

* *[标靶](标靶.md)**
* 新的红石元件，被[弹射物](弹射物.md)击中后会发出红石信号。
* * 弹射物击中的位置越接近靶心，其发出的红石信号越强，最高强度可达15。
* 可使用4个[红石粉](红石粉.md)和1个[干草捆](干草捆.md)合成。
* 仅在[实验性玩法](实验性玩法.md)下可用。

# = 物品 =
* *[下界合金盔甲](下界合金盔甲.md)**
* 可由下界合金锭和对应钻石盔甲合成获得。
* 不会烧毁，且会在熔岩中漂浮。
* 拥有比钻石盔甲更高的耐久度和更强的附魔能力。

* *下界合金[斧](斧.md)、[锄](锄.md)、[镐](镐.md)、[锹](锹.md)和[剑](剑.md)**
* 可由下界合金锭和对应钻石工具合成获得。
* 不会被熔岩烧毁，且会在熔岩中漂浮。

* *[下界合金锭](下界合金锭.md)**
* 可由4个金锭和4个下界合金碎片合成获得。
* 可用于升级钻石工具和盔甲。
* 不会被熔岩烧毁，且会在熔岩中漂浮。

* *[下界合金碎片](下界合金碎片.md)**
* 可通过在熔炉中烧炼远古残骸获得。
* 可用于合成下界合金锭。
* 不会被熔岩烧毁，且会在熔岩中漂浮。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了[疣猪兽](疣猪兽.md)和[猪灵](猪灵.md)的刷怪蛋。

# = 生物 =
* *[疣猪兽](疣猪兽.md)**
* 生成于绯红森林生物群系。
* 与玩家敌对。
* 死亡后掉落[生猪排](生猪排.md)，偶尔还会掉落[皮革](皮革.md)。
* 有成年和幼年两种变种。
* 可通过喂食[绯红菌](绯红菌.md)来繁殖。
* 会主动远离[诡异菌](诡异菌.md)。

* *[猪灵](猪灵.md)**
* 生成于[绯红森林](绯红森林.md)和[下界荒地](下界荒地.md)生物群系。
* 成年猪灵生成时会随机装备金剑或弩，偶尔还会装备金质盔甲。
* 成年猪灵默认与玩家敌对，幼年猪灵呈被动状态。
* * 成年猪灵不会攻击穿着金质盔甲的玩家。
* * 它们仍会在玩家挖掘[金块](金块.md)或打开[箱子](箱子.md)时被激怒。
* 玩家可以使用金锭右键它们或把金锭扔在地上来和它们进行[以物易物](以物易物.md)。
* * 目前只会提供[打火石](打火石.md)、[黑曜石](黑曜石.md)和[下界疣块](下界疣块.md)。
* 在某些时候会攻击疣猪兽。
* * 幼年猪灵不会攻击疣猪兽，成年猪灵不会攻击幼年疣猪兽。
* 幼年猪灵会骑在幼年疣猪兽的背上。
* 成年猪灵会主动攻击[凋灵骷髅](凋灵骷髅.md)。
* 会远离灵魂火、灵魂火把、灵魂灯笼和[僵尸猪灵](僵尸猪灵.md)。
* 在主世界中滞留一段时间后会转化为[僵尸猪灵](僵尸猪灵.md)。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* [绯红森林](绯红森林.md)
* * 一种茂密的森林生物群系，绯红巨型菌在此成片地生成。地面上有各种植物、下界菌及其他方块，巨型下界菌的树冠上还会生成垂泪藤。迷雾呈红色。
* * 僵尸猪灵、猪灵和疣猪兽会在此生成。
* [灵魂沙峡谷](灵魂沙峡谷.md)
* * 一种空间开阔的洞穴生物群系，由大型玄武岩柱、灵魂沙和灵魂土组成，灵魂火随处燃烧。迷雾呈蓝色。
* * 骷髅、恶魂会在此自然生成。
* [诡异森林](诡异森林.md)
* * 绯红森林的异色变种，植被、粒子和迷雾效果都与之略有不同。迷雾呈紫色。
* * 只有末影人会在此生成。

* *[结构](结构.md)**
* [玄武岩柱](玄武岩柱.md)
* * 一种由玄武岩构成的、生成于灵魂沙峡谷生物群系的石柱结构，延连地面与天花板。

* [绯红巨型菌](绯红巨型菌.md)和[诡异巨型菌](诡异巨型菌.md)
* * 新型树木结构，分别生成于绯红森林和诡异森林生物群系。
* * 枝干由绯红菌柄或诡异菌柄组成，树冠由下界疣块或诡异疣块组成，其上会生成几个菌光体。
* * 可由对应的下界菌长成。

# = 游戏内容 =
* *[附魔](附魔.md)**
* [绑定诅咒](绑定诅咒.md)
* * 属于宝藏型魔咒。
* * 玩家装备带有该魔咒的物品后便无法将其从盔甲槽中取出。
* * 不能被[砂轮](砂轮.md)祛魔。
* [消失诅咒](消失诅咒.md)
* * 玩家死亡后，其物品栏内带有该魔咒的物品会直接消失，而不会出现在掉落物中。
* ** 可通过修改游戏规则避免其消失。
* * 不能被[砂轮](砂轮.md)祛魔。

# 更改
# = 方块 =
* *[珊瑚](珊瑚.md)和[珊瑚扇](珊瑚扇.md)**
* 现在可用附有精准采集的斧或锹采集。

* *[岩浆块](岩浆块.md)**
* 现在会使其上方的雪融化。

* *[蘑菇](蘑菇.md)**
* 棕色与红色变种分别重命名为“棕色蘑菇”与“红色蘑菇”。

* *[蘑菇方块](蘑菇方块.md)**
* 棕色、红色与柄变种分别重命名为“棕色蘑菇方块”、“红色蘑菇方块”与“蘑菇柄”。
* * 气孔变种仍命名为“蘑菇”。

* *[潜影盒](潜影盒.md)**
* 现在可以使用炼药锅褪色。

* *[墙](墙.md)**
* 垂直放置的多个墙不再出现空隙。

# = 生物 =
* *常规**
* 现在生物被玩家投掷的滞留型药水杀死时，该生物会掉落经验和稀有掉落物。

* *[末影人](末影人.md)**
* 不再能搬起下界岩，但能够搬起部分新增的方块。

* *[凋灵](凋灵.md)**
* 现在可使用[灵魂土](灵魂土.md)召唤。

* *[亡灵生物](亡灵生物.md)**
* 现在有一定的概率会生成可以捡起装备和盔甲的亡灵生物。

* *[僵尸猪人](僵尸猪人.md)**
* 更改了纹理和模型。

* *[鱿鱼](鱿鱼.md)**
* 提高了生成频率。
* * 在[海洋](海洋.md)生物群系的上限为4，[河流](河流.md)生物群系的上限为2。

# = 游戏内容 =
* *击退距离**
* 现在会按比例计算击退距离，而不是按概率计算被击退的概率。

# = 常规 =
* *[附加包](附加包.md)和地图制作**
* 现在下界的生物群系生成是数据驱动的。

* *[边境之地](边境之地.md)**
* 主世界不再会生成天空网格。

# 修复
* *崩溃**
* 在重生末影龙的过程中使用命令不再导致游戏崩溃。

* *常规**
* 修正了钓鱼竿浮标的动画。
* 雪不再会大量生成于一个区块中。

* *游戏内容**
* 漏斗矿车现在被弹射物击中后会掉落漏斗 。（）
* 潜行时对着可交互方块放置方块不再会打开其UI界面。
* 漏斗矿车向漏斗传输物品时，现在可以打开该漏斗且不再会阻止打开其他漏斗。
* 修复了游戏规则设置为false时，打掉盔甲架不会掉落其自身的问题。
* 如果飞行中的玩家的出生点处有末地传送门，则可以正确返回主世界。
* 附魔弓不再能用于自动合成发射器。
* 玩家装备海龟壳进入水中后不再会继续给予水下呼吸效果。（）
* TNT爆炸时不再会掉落其自身。（）
* 命令现在可以正确显示附近的结构。（）
* 重新进入世界后，玩家不再会卡在部分不完整方块中。（）
* 工具现在耐久耗尽后会发出音效。（）
* 打开世界设置时，现在仍然会保持玩家的飞行状态。
* 玩家在气泡柱中游泳不再会一直保持“游泳”姿势。（）
* 现在船上有方块阻挡时也可以移动且不会被卡住。（）
* 船不再可以在下半台阶上移动。
* 现在使用火焰弹点燃营火会正确消耗火焰弹。（）
* 玩家重生后被固体方块卡在非固体方块中不再会出现透视。（）
* 海带在较低高度下不再会停止生长。（）
* 附魔台不再会显示无关的附魔选项。

* *图形**
* 现在可以看见台阶上的火了。（）

* *生物**
* 怪物现在可以捡起装备和盔甲。（）
* 已驯服的马不再会被无法繁殖马的食物吸引。
* 部分生物寻找附近的可攻击目标时会出现一定延迟（如狼攻击绵羊）。
* 鱿鱼现在可以更加频繁生成，在海洋提升了4倍的生成概率，在河流提升了2倍。（）
* 铁傀儡攻击目标前现在会确保可以接近目标。 （）
* 跳跃动画不再会对马造成伤害。
* 北极熊行走时不再会播放追逐玩家的动画。
* 绵羊不再会隔着方块吃草。
* 修复了末影人看着玩家却不会攻击的问题。
* 生物乘坐矿车时不再会抖动。
* 鱼不再生成于流动的水中。
* 更改了消失规则以匹配Java版。（）
* * 此更改可以提高生物生成的稳定性，并提高怪物在玩家探索洞穴以及特定区域尝试生成特定生物时的生成频率（如下界要塞中生成凋灵骷髅）。
* * 任何设置为永久存在的生物（如被吸引、重命名、驯服、繁殖等）不会自然消失。
* * 大部分自然生成的生物距离玩家54格之外会自然消失。
* * 鱼距离玩家40格之外也会自然消失。
* * 如果生物距离玩家40-54格之间，且其30秒内未受到任何伤害，则其有的概率自然消失。

* *方块**
* 活板门的碰撞箱现在与视觉上一致。（）
* 画不再能放置于物品展示框的顶部。
* 仙人掌现在会被流过的熔岩破坏。
* 在雪中的花被破坏后现在会正确掉落物品。（）
* 下落的方块掉落在冰或玻璃上时不再会被破坏。
* 下落的方块现在掉落在向上伸出的活塞臂上时会被破坏。
* 菌丝体在亮度不足时不再会转变为泥土。

* *控制**
* 优化了使用控制器时的物品栏控制。控制器的控制现在变得更加友好，并且更类似于鼠标和键盘控制。（）
* 玩家现在可以在游泳时按住潜行键来向下游泳。
* 现在在水中起床会切换至正确的水下控制按键。（）

* *音效**
* 使用鞘翅飞行时不再导致音效变得奇怪。 （）

* *用户界面**
* 玩家不再可以修改书与笔中的可见内容了。
* 调整了聊天栏中悬浮文本位置以兼容输入模式（控制器模式应在当前选定的元素边缘上显示悬浮文本）。
* 现在手持剪刀对着南瓜会出现雕刻提示文字。
* 统一了全平台的下船提示文字。
* 加入了手持骨粉对着可催熟方块时出现的提示文字。
* 触摸控制玩家使用书与笔时不再会意外打开键盘。</onlyinclude>
