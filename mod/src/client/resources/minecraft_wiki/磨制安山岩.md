# 磨制安山岩

*页面ID: 162973* | *来源: Minecraft Wiki*

* *磨制安山岩（Polished Andesite）**是[安山岩](安山岩.md)制作的装饰性方块。

# 生成
# = 自然生成 =
磨制安山岩会在[雪屋](雪屋.md)地下室角落的红色地毯下、[林地府邸](林地府邸.md)里、[试炼密室](试炼密室.md)里的补给箱和的底座处生成。

# 破坏
挖掘磨制安山岩的合适工具是镐。磨制安山岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

磨制安山岩被破坏后会掉落自身。

# 你知道吗
* 在现实中，[安山岩](wzh:安山岩.md)是一种喷出火成岩，意味着它是由岩浆组成的（“火成岩”），其表面有流出的痕迹（“喷出”），这是因为火山熔岩流动冷却而形成的。
* 安山岩的侵入岩是[闪长岩](闪长岩.md)，意味着两者组成材质相同，但安山岩在地球内部形成而不是喷出时形成。
* * 换句话说，安山岩是由冷却的岩浆组成的，而闪长岩是由冷却的火山熔岩组成的。
