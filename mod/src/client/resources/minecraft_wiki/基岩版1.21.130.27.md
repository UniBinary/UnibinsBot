# 基岩版1.21.130.27

*页面ID: 171165* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.130.27**（ChromeOS/Android）、**Preview 1.21.130.27**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.130](基岩版1.21.130.md)的第6个测试版，发布于2025年11月11日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# = 生物 =
* *[骆驼尸壳](骆驼尸壳.md)**
* 被生物控制时不再能进入惊慌状态。
* 现在在掉落个[腐肉](腐肉.md)的基础上，抢夺魔咒每增加1级，掉落数量上限增加1。

* *[尸壳](尸壳.md)**
* 作为[骆驼尸壳](骆驼尸壳.md)的乘客生成的尸壳脱离坐骑后不再具有骑乘骆驼尸壳的能力。
* 现在作为骆驼尸壳的乘客生成的尸壳被杀死时有50%的概率掉落个[兔子脚](兔子脚.md)而非个腐肉。
* * 抢夺魔咒每增加1级，掉落数量上限增加1。

* *[鹦鹉螺](鹦鹉螺.md)**
* 现在会在和平难度下生成。
* 现在只会在Y=38至Y=58处生成，此前可以在所有高度生成。
* 加入了装备鞍的音效。

* *[焦骸](焦骸.md)**
* 近战攻击伤害由降低至，以匹配。
* 现在只有作为骆驼尸壳的乘客生成的焦骸能够骑乘骆驼尸壳，并且这种焦骸会在脱离坐骑后失去骑乘骆驼尸壳的能力。
* 更改了腿部模型UV映射。

* *[猪灵](猪灵.md)**
* 现在可以捡起所有种类的[矛](矛.md)，优先级与相同品质的剑一致。

* *[蜘蛛骑士](蜘蛛骑士.md)**
* 现在有概率在[沙漠](沙漠.md)中生成[焦骸](焦骸.md)蜘蛛骑士。

* *[僵尸马](僵尸马.md)**
* 降低了可以生成的速度范围。
* 更改了鞍纹理，以与其他马的鞍纹理保持一致。

* *[僵尸鹦鹉螺](僵尸鹦鹉螺.md)**
* 加入了装备鞍的音效。

* *[僵尸村民](僵尸村民.md)**
* 现在可以捡起和使用矛。

* *方块**
* 镜像处理了在结构内使用时的方块状态。
* 加入了组件，属于“即将推出的创作者功能”[实验性玩法](实验性玩法.md)。此组件用于描述方块消耗和潜在传递红石信号的行为。
* * 包含可选字段，用于定义传入信号强度的最小值。若信号强度大于或等于此值，则事件会发送给脚本。默认值为0，这意味着始终会发送事件。
* * 包含可选字段，为布尔值，用于控制信号是否可以穿过此方块，默认为false。
* * 此组件目前对方块置换不可用。
* * 示例：
* : <syntaxhighlight lang="json">
{
	"format_version": "1.21.130",
	"minecraft:block": {
		"description": {
			"identifier": "test:custom_consumer_block"
		},
		"components": {
			"minecraft:redstone_consumer": {
				"min_power": 5,
				"propogates_power": true
			}
		}
	}
}
</syntaxhighlight>
* 修改了方块组件。
* * 移除了之前名为的多余实验性字段。
* * 使用现有字段可以实现相同效果，示例如下：
* : <syntaxhighlight lang="json">
"minecraft:material_instances" : {
	"*": {
		"texture": "my_texture",
		"render_method": "opaque",
		"face_dimming": false,
		"ambient_occlusion", false
	}
}
</syntaxhighlight>
* 加入了方块组件，允许方块接受拴绳附着，包含用于更改拴绳结位置的字段。目前仅在启用“即将推出的创作者功能”时可用。

* *图形**
* 修复了包含的市场内容可能会滥发内容日志错误的漏洞。
* 加入了彩色静态方块光照功能，需要开启“”选项。
* * 此功能仅在测试版本中、使用且已开启上述选项的世界中可用。
* ** 由于一些技术性问题，暂时在Android和PlayStation平台上禁用。
* * 静态光照可以在中使用来定义。
* * 为的方块也会接受彩色静态光照。
* * 静态光照会遵循Minecraft光照规则以及方块组件。
* * 静态光照是可叠加/积累的，因此不同颜色的重叠光照会使光照变得更亮。
* ** 相同类型（即相同颜色和）的重叠光照不会使光照变得更亮。
* * 静态光照不受染色玻璃和其他半透明方块影响。

# 修复
* *群骑纷争**
* 鹦鹉螺之息增益效果不再会阻止玩家在离开水后补充氧气值。
* 鹦鹉螺之息增益效果不再会阻止拥有水下呼吸效果的玩家在骑乘鹦鹉螺时补充氧气值。
* 鹦鹉螺之息增益效果不再会阻止实体在熔岩中补充氧气值。
* 被敌对生物骑乘的骆驼尸壳不再能被拴住。
* 现在抢夺魔咒会对骆驼尸壳正确生效。
* 骆驼尸壳不再会在尸壳和焦骸脱离坐骑后将它们带上来作为乘客。（）
* 现在骆驼尸壳拥有正确的生成分类，以匹配Java版。（）
* 现在骆驼尸壳拥有正确的坐下、站立和冲刺音效。（）
* 现在珊瑚僵尸鹦鹉螺会真正地替换暖水海洋中的普通僵尸鹦鹉螺。
* 减少了鹦鹉螺的头部和外壳之间的穿模。
* 鹦鹉螺脱离水时的受伤音效不再由玩家受伤音效替代。
* 现在鹦鹉螺会在和平难度下生成。（）
* 现在鹦鹉螺只会在Y坐标为38至58之间生成。（）
* 现在焦骸在载具中的垂直偏移量与其他生物相同。
* 调整了焦骸的几何结构，以修复一些视觉漏洞。
* 现在焦骸有概率在沙漠中骑着蜘蛛和洞穴蜘蛛生成，而不是生成普通骷髅。（）
* 修复了鹦鹉螺和僵尸鹦鹉螺不会播放卸下鞍的音效的问题。（）
* 修复了僵尸鹦鹉螺不会播放装备鹦鹉螺铠的音效的问题。（）
* 修复了僵尸鹦鹉螺不会播放卸下鹦鹉螺铠的音效的问题。（）
* 现在猪灵会在端详矛时正确地左手持矛。（）
* 修复了耐久魔咒不会对矛生效的问题。（）
* 修复了在铁砧上合并的附魔矛无法正常使用的问题。（）
* 矛的使用音效不再有概率播放两次。（）
* 增加了进行戳刺或后期阶段的冲锋攻击时矛绕轴旋转的角度。（）
* 现在僵尸手持矛时的手臂挥动是镜像的，以匹配Java版。（）
* 现在矛会在对盔甲架发动冲锋攻击时播放命中音效并触发攻击动画。
* 现在魔咒效果再次只会在玩家和目标的速度足以使矛造成伤害时生效。
* 现在使用触摸控制进行戳刺攻击时，矛会正确地对着点击方向攻击。
