# 粉红色花簇

*页面ID: 102300* | *来源: Minecraft Wiki*

* *粉红色花簇（Pink Petals）**是一种生成于[樱花树林](樱花树林.md)生物群系的装饰性方块。

# 生成
# = 自然生成 =
粉红色花簇会在[樱花树林](樱花树林.md)生物群系中自然生成。

# = 人工生成 =
在樱花树林中对着[草方块](草方块.md)[骨粉](骨粉.md)，有小概率生成粉红色花簇。<ref></ref>

# 获取
对着不满4簇花的粉红色花簇骨粉会增加1簇花；对着含有4簇花的粉红色花簇骨粉会掉落1个新的粉红色花簇。

# 破坏
粉红色花簇被挖掘时会立刻被破坏。

粉红色花簇被破坏后会掉落自身，掉落个数等于方块内粉红色花簇数。

# 用途
粉红色花簇可以种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。

多个粉红色花簇可以放置在同一格内，这与[海泡菜](海泡菜.md)和[蜡烛](蜡烛.md)类似。最多可以在一个方块空间内放置4簇。

粉红色花簇有4个朝向，其取决于玩家放置时的方向。若一个位置上已有粉红色花簇后，改变方向放置更多粉红色花簇并不会改变其朝向。

粉红色花簇高0.1875（）格，但没有碰撞箱。

# = 合成材料 =

# = 蜜蜂 =
粉红色花簇可用于吸引、繁殖[蜜蜂](蜜蜂.md)以及加速幼年蜜蜂的成长。蜜蜂也会采集它的花粉。

# = 堆肥 =
将粉红色花簇放入[堆肥桶](堆肥桶.md)中有30%的概率增加一层堆肥层。

# 你知道吗
[100px|右](File:Pink Petals (item) (pre-release).png.md)
* [樱花树林预览视频](https://www.youtube.com/watch?v=0UB682mwFiA)中出现了粉红色花簇的旧版物品栏图标<ref></ref>，看起来是基于[蒲公英](蒲公英.md)的纹理修改的。
* 樱花树林中的粉红色花簇看起来像是落在地上的樱花花瓣，但实际上它们是一种生长在地面上的花朵，判断依据为：
* * 其纹理下方有茎。
* * 只能够种植在泥土、草方块、泥巴等方块上。
* * 可以对其使用骨粉以增加其数量。
* * 可以用于繁殖蜜蜂，蜜蜂也可以采粉。
