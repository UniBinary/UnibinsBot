# Java版1.14.2-pre1

*页面ID: 43224* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14.2-pre1**是[Java版1.14.2](Java版1.14.2.md)的首个预发布版，发布于2019年5月16日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[营火](营火.md)**
* [含水](含水.md)的[营火](营火.md)不再能被着火的[箭](箭.md)点燃。

# = 生物 =
* *[鹦鹉](鹦鹉.md)**
* 不再生成在[草丛](草丛.md)上，而是生成在[草方块](草方块.md)上。

# = 游戏内容 =
* *[袭击](袭击.md)**
* [袭击生物](袭击.md)现在只生成在完全载入的[区块](区块.md)中。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 现在包含服务器端的区块数量。
