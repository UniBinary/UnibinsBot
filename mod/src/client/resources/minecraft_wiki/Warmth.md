# 描述

[File:Warmth.ogg](File:Warmth.ogg.md)

Warmth以响亮、空洞的声音开场，像有什么东西在金属物体上敲打，随后逐渐转为柔和、温暖、泡泡般的合成器音乐，背景中伴有风琴和一些环境点击声。接近结尾时，音乐又变回敲打声，但更响、更清脆。最后有大量水流动的声音。
