* *Alpha v1.2.0**是**[万圣节更新](万圣节更新.md)**的首个版本，也是的一次主要更新，发布于2010年10月30日<ref></ref>。该版本加入了[下界](下界.md)与新的[生物](生物.md)和[方块](方块.md)，还加入了[钓鱼](钓鱼.md)，一个新的地形生成器，并进行了其他更改与修复。

# 新内容
# = 方块 =
* *[下界岩](下界岩.md)**
* 在下界中大量生成。
* 火会在其上方永久燃烧。

* *[灵魂沙](灵魂沙.md)**
* 对在它上方移动的实体起减速作用。

* *[荧石](荧石.md)**
* 可由4个荧石粉合成。
* 会发出[等级](亮度等级.md)为15的光。

* *[南瓜](南瓜.md)**
* 在[主世界](主世界.md)的某些[生物群系](生物群系.md)中可以找到。
* 可以戴在头上，也可以制成南瓜灯。

* *[南瓜灯](南瓜灯.md)**
* 可由1个南瓜和1个[火把](火把.md)合成。
* 会发出等级为15的光。

* *[下界传送门方块](下界传送门方块.md)**
* 当一个下界传送门被创建时会生成。
* 能够传送[玩家](玩家.md)进出下界。

# = 物品 =
* *[时钟](时钟.md)**
* 可以用来显示游戏时间。

* *[荧石粉](荧石粉.md)**
* 挖掘荧石时掉落。
* 可以用来合成荧石。

* *[生鱼](生鱼.md)**
* 通过钓鱼获得。

* *[熟鱼](熟鱼.md)**
* 由生鱼在熔炉中烹饪获得。
* 食用后恢复。

# = 生物 =
* *[恶魂](恶魂.md)**
* 悬浮在下界中的大型白色生物。
* 会对玩家发射[火球](火球.md)。<ref>火球在发射时会使用[雪球](雪球.md)的纹理。</ref>

* *[僵尸猪人](僵尸猪人.md)**
* 当一只僵尸猪人被攻击时，附近所有的僵尸猪人都会被激怒并攻击玩家。
* 持有[金剑](金剑.md)。<ref name="Release change">此特性加入于[Alpha v1.2.0预发布版](Alpha v1.2.0-preview.md)和Alpha v1.2.0正式版之间。</ref>

# = 世界生成 =
* *常规**
* 更新了世界生成器，并实现了[生物群系](生物群系.md)。

* *[下界](下界.md)**
* 类似于[Indev](Java版Indev.md)版本中地狱类型世界的维度，有[熔岩](熔岩.md)、[恶魂](恶魂.md)与[僵尸猪人](僵尸猪人.md)生成，可用来快速旅行。

* *[沙漠](沙漠.md)**
* 有着[仙人掌](仙人掌.md)和[沙子](沙子.md)的生物群系。[冰原沙漠](冰原沙漠.md)也可以在代码中找到，但未被使用。

* *[冻原](冻原.md)**
* 一个充满冰雪的生物群系，树木稀少。

* *[雨林](雨林.md)**

* *[季节性森林](季节性森林.md)**

* *[热带草原](热带草原.md)**

# = 游戏内容 =
* *[钓鱼](钓鱼.md)**

# = 常规 =
* *音效**
* 加入了新的音乐和音效。

* *[闪烁标语](闪烁标语.md)**
* 加入了新的闪烁标语：
* * “Slow acting portals!”。
* * “Try the Nether!”。
* * “Don't look directly at the bugs!”。
* * “Oh, ok, Pigmen!”。
* * “Finally with ladders!”。
* * “Scary!”。

# 更改
# = 方块 =
* *[楼梯](楼梯.md)和[熔炉](熔炉.md)**
* 现在被放置后都会面向玩家。

* *[草方块](草方块.md)和[树叶](树叶.md)**
* 在阴影处会变暗。
* 其颜色现在取决于所属生物群系的温度/湿度值。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 更换了新的音效。

* *[骷髅](骷髅.md)**
* 现在手持[弓](弓.md)。

* *[史莱姆](史莱姆.md)**
* 完全移除了其生成代码。

* *常规**
* 更深的地区需要更高的光照等级才能防止怪物生成。

# = 世界生成 =
* 假区块从X/Z=±32,000,000处开始生成，取代了之前的虚空。
* * 玩家无法与这些方块交互。
* * 它们均为非固体方块，当玩家走过去后会掉入虚空。
* * 光照系统在此处停止工作。
* * 树木、花、草丛和地牢的生成在此处被切断。
* 移除了[冬天模式](Java版已移除特性#冬天模式.md)。
* * 由于它的移除，雪不再在很高的高度出现扭曲。

# = 游戏内容 =
* *[昼夜更替](昼夜更替.md)**
* 现在黎明和黄昏时地平线会泛红光，就像真正的日出和日落那样。

* *[HUD](HUD.md)**
* 按下可以隐藏HUD和玩家的视图模型。在第三人称模式下（按），按下会提供玩家脸后面的视图。

# = 命令格式 =
* 移除了和命令。

# = 常规 =
* *[徽标](徽标.md)**
* 将*Minecraft*徽标从[x20px](File:Java Edition logo 2.png.md)更改为[x20px](File:Java Edition logo 6.png.md)。</onlyinclude>

# 启动器版
Alpha v1.2.0并不存在于启动器中，启动器中的“a1.2.0”实际上是Alpha v1.2.0_02。
