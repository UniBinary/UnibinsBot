# 市场

*页面ID: 29628* | *来源: Minecraft Wiki*

* *市场（Marketplace**，在PlayStation平台上称为**Minecraft Store）**<ref name="marketplace">[Minecraft Marketplace](https://minecraft.net/marketplace/) - Minecraft.net</ref>是用于购买由Minecraft官方或官方合作伙伴创建的内容的游戏内平台。

# 购买内容
市场中的大多数内容都需要使用真实货币或[16px|link=|class=pixel-image](File:MCoin.png.md)Minecoin来购买，也有少量的免费内容。
* Minecoin是在除PlayStation平台上用于在市场内购买内容虚拟货币，使用真实货币购买，在部分平台上也可使用礼品卡或兑换码等方式兑换。购买或兑换成功后，同一微软账户下Minecoin的数量在这些平台上互通。
* 在PlayStation平台上，Minecraft Store使用的虚拟货币为[16px|link=|class=pixel-image](File:Token.png.md)Token而非Minecoin，其购买价格与Minecoin类似，但只能在PlayStation平台上同步。

Minecraft官方和官方合作伙伴有时会在市场推出永久或限时免费内容，通常为有Minecraft活动、节日或市场推销进行时，或游戏新版本发布时等。

除部分平台的独占内容外，在市场购买的内容在登录了相同微软账号的所有平台和设备上都可用。

同一微软账户下，基岩版与[Minecraft Legends](Minecraft Legends.md)中的Minecoin互通。

# 使用需求
市场需要满足以下条件才可使用：
* 玩家已经购买了游戏。
* 玩家拥有稳定的网络连接。
* 玩家使用的游戏版本支持市场。

# 内容
市场共有5种不同的分类可用，包括[皮肤包](皮肤包.md)、世界、[纹理包](附加包.md)、[混搭包](混搭包.md)和[行为包](行为包.md)。除Windows 10/11平台和Xbox系列主机平台之外，玩家若未登录[Microsoft账户](wzh:Microsoft帐户.md)，购买的内容则会保存在本地设备上；玩家登录Xbox档案后，所有购买的内容都会立即同步到Microsoft账户上。

所有内容均由Minecraft官方合作伙伴提交，并得到Minecraft内容团队的批准。<ref>[Minecraft Marketplace Catalog](https://marketplace.minecraft.net/catalog)</ref>

# = 皮肤包 =

皮肤包包含数个可以在单人和多人游戏中使用的皮肤。部分皮肤包可能会提供1-2个免费皮肤，无需购买即可使用。

从市场获取的皮肤属于受信任的皮肤，可以被启用了“”[设置](设置.md)的玩家看见，也能在中的属性为的服务器上显示。

# = 世界 =
世界是预先建造好的地图，可以提供不同的游玩方式。与混搭包不同，世界包含的自定义纹理、方块、物品和生物只能在对应世界中使用。有些世界可能会附带皮肤。

; 冒险地图
   冒险地图专注于一次性游玩体验，玩家可以在世界提供的游戏引导下一步步探索地图和完成任务，玩法从PvP到模拟类型应有尽有。这些世界分为单人游玩、多人游玩或两者皆可。

; 小游戏
   小游戏世界具有特定的主题或目标，并且设计为可重复游玩。这些世界可以提供一系列不同的玩法和变种，有些还可以被重置以便于再次游玩。

; 生存生成
   生存生成是预设好的生存模式世界，玩家可在其中探索、获得战利品和扩展领地。这些世界能让玩家用焕然一新的体验游玩生存模式。

# = 纹理包 =

纹理包可以修改世界的视觉外观。这些包还可以自定义其他游戏内元素，例如音效、音乐、物品、GUI、生物的动作和几何形状以及玩家的动作。纹理包只能改变已有内容的视觉表现方式，不能添加新的生物、方块、物品或改变玩法。

# = 混搭包 =

混搭包是包含了世界、纹理包和皮肤的捆绑包。与世界附带的纹理包不同，混搭包中的纹理包可以单独使用。

# = 行为包 =

附加包可为世界添加新功能，例如新的生物、方块和物品。附加包可以应用于任何世界，在单人世界和自己主持的多人游戏中均可使用。

来自市场的行为包不会影响世界获得[成就](成就.md)。

# 你知道吗
* 在市场加入Minecraft前，游戏内的纹理包和皮肤需要使用真实货币来购买，因此Mojang加入任何内容前都必须经过每个平台的认证。加入市场和Minecoin便是为了避免此事发生。
* * 在Minecoin加入后，玩家仍可使用真实货币支付。
* * 在市场推出之前购买的内容会显示为“已拥有(P)”而非“已拥有”。
* 从市场下载的皮肤、附加包和世界不像其他内容一样储存在下的、、和文件夹里，而是加密储存在文件夹下。
