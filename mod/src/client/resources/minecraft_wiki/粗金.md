# 粗金

*页面ID: 81153* | *来源: Minecraft Wiki*

* *粗金（Raw Gold）**是一种从[金矿石](金矿石.md)中获得的粗金属资源。

# 获取
# = 挖掘 =
当使用未带有[精准采集](精准采集.md)魔咒的[铁镐](铁镐.md)或更好的镐挖掘[金矿石](金矿石.md)、[深层金矿石](深层金矿石.md)时，会掉落1个粗金。每1级[时运](时运.md)魔咒使得掉落量上限增加1个，使用时运III最多可掉落4个。
