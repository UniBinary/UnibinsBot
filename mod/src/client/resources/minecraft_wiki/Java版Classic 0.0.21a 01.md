# 修复
* 尝试通过为裁剪添加最大迭代次数来修复“悬挂漏洞”。<ref name=0.0.21a_01></ref><ref>[IRC记录](#logs.md): "*A11:40:57 <08Notch> the only difference between 0.0.21a and _01 is that I added a max iterations on the clipping*" (16:40:57 UTC)</ref>
* * 然而，游戏还是会在随机时间突然卡死。<ref>[IRC记录](#logs.md): "*A11:24:10 <08Notch> so it still hangs? :-O [...] A11:24:14 <akuryo> yeah notch*"  (16:24 UTC)</ref></onlyinclude>
