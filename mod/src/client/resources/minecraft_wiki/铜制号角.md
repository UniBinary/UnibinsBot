# 铜制号角

*页面ID: 93662* | *来源: Minecraft Wiki*

* *铜制号角（Copper Horn）**是[山羊角](山羊角.md)的镀铜变种，会根据吹奏者不同的吹奏姿势而发出不同的音色。

# 获取
# = 合成 =

# = 箱子战利品 =
铜制号角有25%概率出现在[掠夺者前哨站](掠夺者前哨站.md)的战利品箱中。

# 用途
当拿着铜制号角时，按住键会显示吹奏动画并发出其对应的吹奏音效。铜制号角在吹奏者抬头、[潜行](潜行.md)或做出其他姿势时会发出三种不同的响声。铜制号角吹奏时播放的音效取决于多重条件，其优先级顺序如下：
* 若处于潜行状态，则播放潜行时吹奏的音效。
* 若在非潜行状态下抬头（仰角45度），则播放仰视时吹奏的音效。
* 若上述条件均不满足，则播放平视时吹奏的音效。

铜制号角每次吹奏时长为1秒，在使用后会有4秒的冷却时间，并会在快捷栏中显示白色覆盖层，类似于[末影珍珠](末影珍珠.md)。同时，玩家物品栏中的其他铜制号角与山羊角也会有一段冷却时间。

# 你知道吗
* 同种铜制号角在仰头和平视时吹奏所发出的声音是同一段音频的高音和低音版本。
* 在玩家吹响铜制号角后，会在吹奏完成时的头部中心发出声音，在这之后即使玩家坐标发生变化，声音的来源仍不会改变。
* 铜制号角被移除的原因是其未能满足开发者的设计目标。<ref></ref>
* * 在一篇推文中，[Kingbdogz](Kingbdogz.md)提到铜制号角的设计初衷更多是出于社交目的而非游戏玩法考量。<ref></ref>
* 铜制号角并未像以往那样设置为不可获得，而是被直接移除，这可能是因为它一直没有从[实验性玩法](实验性玩法.md)中被移出至常规玩法里。
