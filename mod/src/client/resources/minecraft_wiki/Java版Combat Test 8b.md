# Java版Combat Test 8b

*页面ID: 68227* | *来源: Minecraft Wiki*

}}<onlyinclude>

* *Combat Test 8b**是未来的战斗改版的第8个公开的实验性版本，发布于2020年8月21日<ref></ref>。虽然它是未来版本的测试版，但这个战斗实验版是[Java版1.16.2](Java版1.16.2.md)的分支。此版本只发布在[Reddit](wzh:Reddit.md)上，因此其并不出现在[启动器](启动器.md)版本列表或[Minecraft.net](Minecraft.net.md)的文章中。此次更新[Mojang](Mojang.md)也提供了[一份伤害值的表格](https://piston-data.mojang.com/experiments/combat/ed4ac6cf06a6828888f24b58416542dacf6e9960/Minecraft%20Damage%20Calculations%20%28v2%29.xlsx)。

# 更改
# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 将[劈裂](劈裂.md)的攻击力加成由+1/+2/+3改为+2/+3/+4。</onlyinclude>

# 你知道吗
* 此版本有着与[Combat Test 8](Java版Combat Test 8.md)和[Combat Test 8c](Java版Combat Test 8c.md)相同的协议版本，这意味着它们的客户端和服务器版本彼此兼容。拥有同样协议版本的开发版十分罕见。
