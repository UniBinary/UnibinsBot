# 环境音效

*页面ID: 8625* | *来源: Minecraft Wiki*

* *环境音效（Ambience）**是可在特定条件下听到的声音，由[C418](C418.md)和[Samuel Åberg](Samuel Åberg.md)制作。目前，共有167种不同的环境音效。

环境音效根据其播放的条件分为多类。目前，有“洞穴（Cave）”“水下（Underwater）”和“下界（Nether）”三类环境音效。

可以在[Java版](Java版.md)[选项](选项.md)菜单的“音乐和声音”界面或[基岩版](基岩版.md)[设置](设置.md)菜单的“音频设置”界面中，调节“环境”滑块来单独设置环境音效的音量。但是，这也会一并影响[烟花火箭](烟花火箭.md)的音效。

所有环境音效均可使用命令来播放。所有环境音效的ID均以**ambient.*<ID>***开头。

# 洞穴环境音效
[300px|右|缩略图|一个黑暗的洞穴。这是最有可能会听到洞穴环境音效的地方之一](File:Dark cave.png.md)
* *洞穴环境音效**（**Cave Ambience**，简称**洞穴音效**，[字幕](字幕.md)中称****）是当玩家位于[洞穴](洞穴.md)等黑暗的空间中时，使用[“氛围算法”](#氛围算法.md)随机播放的一组声音。

洞穴环境音效可以在任何[生物群系](生物群系.md)（下界的生物群系除外）中播放，只要该含有洞穴等足够黑暗的空间。

# 水下环境音效

* *水下环境音效（Underwater Ambience）**会在[玩家](玩家.md)的头部处于[水](水.md)下时播放。这些音效可以在任何规模、任何[维度](维度.md)的水体中听到。

水下环境音效分为2组：“循环（Loop）”和“循环附加（Loop Additions）”。当玩家处于水下时，这两种音效都将彼此独立地播放。此外，“循环附加”又分为3组。

水下环境音效的ID为{{cd|-{}-ambient.underwater.<本组ID>}}。共有22种不同的水下环境音效。

下表“稀有循环附加”和“顶级稀有循环附加”的名称源于游戏中对应的ID，出现概率并没有其名称所描述的那么低。

# 下界环境音效
* *下界环境音效（Nether ambience）**会在[玩家](玩家.md)位于[下界](下界.md)时播放。每个下界生物群系都有自己独特的环境音效。

下界环境音效被分为三组：“循环（Loop）”“循环附加（Loop Additions）”和“氛围（Mood）”。当玩家位于下界时，这些音效都会彼此独立地播放。

下界环境音效的ID为{{cd|-{}-ambient.<生物群系>.<本组ID>}}。总共有95种不同的下界环境音效。

# 氛围算法
“氛围”类环境音效（原版中仅包括[洞穴环境音效](#洞穴环境音效.md)）会基于一个介于0-100之间的“氛围（mood）”百分值产生。当玩家位于洞穴等黑暗<!--亮度等级小于9？-->的空间中时，“氛围”值就会升高，反之不满足上述条件就会降低。当“氛围”值达到100%时，就会随机播放一种氛围类环境音效，同时“氛围”值也会被重设为0%，以此往复循环。[玩家](玩家.md)周围的环境越黑暗、[固体方块](固体方块.md)越多，“氛围”值就升高得越快。游戏中的即时“氛围”值可以在[调试屏幕](调试屏幕.md)中查看。

以下是使用[](wzh:伪代码.md)描述的简化的“氛围”值运算算法：
<syntaxhighlight lang="python">
updateMood(mood):
    tickDelay = 6000
    maxLightLevel = 15
    block = select a random block in a 17×17×17 block cube centered around the player
    skyLight = block.getSkyLightLevel()

    if (skyLight > 0):
        mood = mood - (skyLight / maxLightLevel) * 0.015
    else:
        blockLight = block.getBlockLightLevel()
        mood = mood - (blockLight - 1) / tickDelay

    if (mood ≥ 1.0):
        player.playCaveAmbience()
        mood = 0.0
    else if (mood < 0):
        mood = 0.0
</syntaxhighlight>

游戏每一个[游戏刻](游戏刻.md)都会调用一次此算法。算法会在以玩家眼部位置为中心的17×17×17的区域内随机选取一个方块，并依此修改“氛围”值：
* 若选取的方块具有天空光，则会将“氛围”值降低该方块光照等级的。
* 若选取的方块没有天空光：
* * 若其方块光照等级大于1，则会将“氛围”值降低 (<方块光照等级> - 1) ×。
* * 若其方块光照等级为0，则会将“氛围”值升高。

这也就是说，如果玩家位于完全黑暗的环境中，四周没有任何可供照明的方块，那么则每隔6000刻（5分钟）就会播放一次洞穴音效。

由于光照不透明方块的天空与方块光照等级都被认定为0，故而洞穴中玩家的“氛围”值会升高得尤其快。

# 你知道吗
[236px|右|缩略图|Cave 14的频谱图像](File:Sound14 spectrogram.png.md)

* 在声谱图中查看“Cave 14”音效时，会出现[苦力怕](苦力怕.md)脸部一样的图案。
* 在当初的[Minecraft Dungeons](Minecraft Dungeons.md)宣传片中，在大约53秒时电梯制动的声音很像“Cave 18”。
* [Minecraft Dungeons](Minecraft Dungeons.md)中[复仇末影之心](MCD:复仇末影之心.md)在Boss战前爬行时使用了“Cave 1”“Cave 2”和“Cave 19”洞穴环境音效。
* 可以通过“Cave 21”音效得到一段摩尔斯电码（-••• • •••• •• -• -••），解码后为英语单词“behind”。<ref>https://x.com/MyIQIsNegative/status/1896161753291206977</ref>
* “Cave 22”中有混响处理的[监守者](监守者.md)咆哮音效。
* “Warped Forest Additions 1-5”中有[末影人](末影人.md)及其[Minecraft Dungeons](Minecraft Dungeons.md)变种的音效。
* “Warped Forest Additions 6”中有倒放并减速的末影人尖叫音效。
* 未使用的“Warped Forest Mood 9”中有减速并混响处理的[女巫](女巫.md)空闲音效。
* “Warped Forest Enish 1-3”是倒放处理的“Crimson Forest Shine 1-3”，文件名“enish”由“shine”（闪光）的字母重组而成。
