* *钻石（Diamond）**是通过开采[钻石矿石](钻石矿石.md)或从[战利品箱子](箱子战利品.md)中获得的一种稀有物品，可用于合成高级的[工具](工具.md)和[盔甲](盔甲.md)，以及复制[锻造模板](锻造模板.md)。

# 获取
# = 挖掘 =

使用[铁镐](铁镐.md)或更好的镐挖掘[钻石矿石](钻石矿石.md)或[深层钻石矿石](深层钻石矿石.md)会掉落1个钻石。使用[时运](时运.md)魔咒的镐挖掘会每等级增加1的最大钻石数量，时运III最多会掉落4个钻石。

# = 信标 =
钻石可以用于从[信标](信标.md)中选择并激活[状态效果](状态效果.md)。玩家必须选择一种可用的状态效果，然后在物品槽中放入一个钻石。

钻石可以代替[铁锭](铁锭.md)、[金锭](金锭.md)、[绿宝石](绿宝石.md)或[下界合金锭](下界合金锭.md)为信标选择状态效果。

# 你知道吗
* 现实中的是研磨工具、切割物质的最佳材料之一，且用于此目的的钻石通常不是宝石级的。
* * 钻石在现实中的稀有程度比Minecraft中高得多。游戏中所反映的宝石级钻石在现实中只能由大型矿脉得来，并且需要经过仔细地切割和加工才能达到相应的品质。而现实中以钻石为基础的工具所使用的是工业级钻石，其相对常见，成本更低。
* 钻石必须通过[宝库](宝库.md)战利品才能实现可再生。这是因为可用于制造钻石的[钻石块](钻石块.md)同样依赖宝库战利品实现可再生，而宝库可以被每个玩家打开无限次数<ref></ref>，且[试炼钥匙](试炼钥匙.md)和[不祥试炼钥匙](不祥试炼钥匙.md)是[可再生资源](可再生资源.md)。
