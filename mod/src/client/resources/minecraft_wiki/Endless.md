# 描述

[File:Endless.ogg](File:Endless.ogg.md)

Endless是一首慢节奏的歌曲，开始时的旋律类似于[Infinite Amethyst](Infinite Amethyst.md)，由钢琴演奏，并在整首曲子中重复出现。接近结尾时，音调加入了混响效果，营造了一种氛围。有一个音调反复出现几次，并且逐渐变慢。
