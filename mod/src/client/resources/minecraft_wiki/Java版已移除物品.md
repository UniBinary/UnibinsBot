# Java版已移除物品

*页面ID: 98493* | *来源: Minecraft Wiki*

# 还原药水

在[Java版1.9](Java版1.9.md)的快照[15w31a](15w31a.md)之前，玩家可以在酿造台上“还原”药水。还原版药水与其基础版药水的外观相同，产生的状态效果也相同，唯一的区别在于数据值。

还原版药水有下列两种基础酿造方法：
* 将[荧石粉](荧石粉.md)加入到延长版药水。
* * 这样做通常会获得增强版药水，但若此药水不存在增强版药水，则会获得还原版药水。
* ** 例如，抗火药水存在延长版药水而不存在增强版药水，因此向延长版抗火药水添加荧石粉后会获得还原版抗火药水，其效果与基础的抗火药水相同。
* 将[红石粉](红石粉.md)加入到增强版药水。
* * 这样做通常会获得延长版药水，但若此药水不存在延长版药水，则会获得还原版药水。
* ** 例如，跳跃药水存在增强版药水而不存在延长版药水，因此向增强版跳跃药水添加红石粉后会获得还原版跳跃药水，其效果与基础的跳跃药水相同。

如果要获得还原版的负面药水，则需使用[发酵蛛眼](发酵蛛眼.md)。可以先酿造负面药水以使用上述方法，也可以先酿造正面药水，再根据其是否具有延长版与增强版药水直接添加发酵蛛眼。

例如，欲获得还原版虚弱药水，可以有下列路径：
* 直接酿造：水瓶 -> 平凡的药水 -> 虚弱药水 -> 虚弱药水（延长） -> 虚弱药水（还原）
* 直接腐化力量药水：水瓶 -> 粗制的药水 -> 力量药水 -> 力量药水（增强） -> 虚弱药水（还原）

# 箭袋
[缩略图|100px](File:Quiver.png.md)
[缩略图|经改进的屏幕截图](File:Quiver-decode.png.md)

箭袋加入于[Java版Indev 0.31 20091231-2147](Java版Indev 0.31 20091231-2147.md)，它的纹理来自[Notch](Notch.md)的一个名为[Legend of the Chambered](Legend of the Chambered.md)的未完成的游戏。

2011年4月23日，[Jeb](Jeb.md)声明最初没有加入箭袋的计划。<ref></ref>

在[Java版1.9](Java版1.9.md)的开发阶段，[Dinnerbone](Dinnerbone.md)在推特上发布了一个2×204960的图片<ref></ref>，这是一个854×480的Minecraft截图整合而成的图片，其中包含了箭袋。<ref></ref>在2015年6月30日，Dinnerbone说他又将它们移除了，因为箭在副手上感觉“更自然”。<ref></ref>

在[Java版1.9](Java版1.9.md)中，箭袋的纹理被移除。
