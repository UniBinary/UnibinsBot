# Java版12w23a

*页面ID: 32406* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w23a**是[Java版1.3.1](Java版1.3.1.md)的第9个快照，发布于2012年6月7日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[楼梯](楼梯.md)**
* 现在拥有正确的碰撞箱。

* *[绊线](绊线.md)**
* 绊线现在能够被大多数[实体](实体.md)激活，包括[箭](箭.md)（[末影之眼](末影之眼.md)和[附魔之瓶](附魔之瓶.md)除外）。
* 最大距离增加到40米。

* *木质[压力板](压力板.md)**
* 现在可以被箭激活。

# = 非生物实体 =
* *[船](船.md)**
* 船现在可以加速到比以前更快的速度。
* 船变得更加容易控制。

# = 游戏内容 =
* *[创造模式物品栏](创造模式物品栏.md)**
* 加入了[末地传送门框架](末地传送门框架.md)。

* *[经验](经验.md)**
* 经验等级再次变为呈曲线上升。
* * 需要825[经验](经验.md)来到达30级。
* * 前16级呈线性，从第17级开始每升1级需要更多的经验来到达最大的30级。

* *[纹理包](纹理包.md)**
* 文件夹中不是格式的纹理包文件也会得到认可。
* 纹理包的封面图标现在基于纹理包文件夹。

* *[多人游戏](多人游戏.md)**
* 多人游戏下玩家可以看见其他玩家挖掘方块时的裂痕效果。

# = 常规 =
* *调试特性**
* 按下不再重新加载区块。

# 修复
* *修复了7个漏洞**
* 修复了一个活塞推动绊线时的问题。
* 村民现在可以再次繁殖了。
* 重新加入了天气变化。
* 修复了史莱姆和岩浆怪的跳跃动画。
* 盔甲和工具的附魔效果现在会显示给多人游戏中的其他玩家了。
* 玩家现在再次可以跳过胜利屏幕了。
* 戴在玩家头上的南瓜现在会朝向正确的方向了。</onlyinclude>
