# Java版Indev 20100219

*页面ID: 35443* | *来源: Minecraft Wiki*

<onlyinclude>
* *Minecraft Indev**的一个版本发布于2010年2月19日，加入了[熔炉](熔炉.md)、[燧石](燧石.md)和一些食物。<ref></ref>

# 新内容
# = 方块 =
* *[熔炉](熔炉.md)**
* 一种功能性方块，用于烧炼[方块](方块.md)和[物品](物品.md)。
* 取代了旧的烧炼系统。
* 如果在烧炼物品时被破坏，会掉落燃烧的熔炉。
* 可由8个[圆石](圆石.md)合成。

# = 物品 =
* *[燧石](燧石.md)**
* 挖掘[沙砾](沙砾.md)有概率掉落。
* 用于合成[打火石](打火石.md)。

* *[生猪排](生猪排.md)**
* 一种新的食物。
* 食用后恢复。

* *[熟猪排](熟猪排.md)**
* 一种新的食物。
* 可以通过熔炉烧炼[生猪排](生猪排.md)制成。
* 食用后恢复。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了一些新的闪烁标语：
* * “Loved by millions!”
* * “Ultimate edition!”
* * “Freaky!”
* * “You've got a brand new key!”
* * “Water proof!”
* * “Uninflammable!”
* * “Whoa, dude!”
* * “All inclusive!”
* * “Tell your friends!”
* * “NP is not in P!”
* * “Notch <3 Ez!”
* * “Music by C418!”

# 更改
# = 方块 =
* *[火](火.md)和[熔岩](熔岩.md)**
* 不再能烧炼物品。
* 与[石头](石头.md)相关的方块现在需要用镐开采才会掉落物品。<ref name="Forum2"></ref>

* *[玻璃](玻璃.md)**
* 不再能由烧炼[沙砾](沙砾.md)获得。

# = 物品 =
* *[煤炭](煤炭.md)**
* 更改了纹理。
* 不再能由烧炼[煤矿石](煤矿石.md)获得。

* *[打火石](打火石.md)**
* 更改了纹理。
* 加入了合成配方，可由铁锭和燧石合成。

# = 非生物实体 =
* *[物品（实体）](物品（实体）.md)**
* 现在会被火和熔岩摧毁。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 现在死亡后会掉落[硫磺](火药.md)。

* *[猪](猪.md)**
* 现在死亡后会掉落[生猪排](生猪排.md)。

* *[绵羊](绵羊.md)**
* 现在死亡后无掉落物。

* *[蜘蛛](蜘蛛.md)**
* 现在死亡后会掉落[线](线.md)。

* *[骷髅](骷髅.md)**
* 现在死亡后会掉落[箭](箭.md)。

* *[僵尸](僵尸.md)**
* 现在死亡后会掉落[羽毛](羽毛.md)。

# = 游戏内容 =
* *[烧炼](烧炼.md)**
* 现在所有的烧炼配方都只会产出1个物品。</onlyinclude>
