# Java版Infdev 20100608

*页面ID: 35983* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年6月8日，修复了一些漏洞。<ref></ref>

# 新内容
# = 生物 =
* *常规**
* 再次加入了影子。

# = 非生物实体 =
* *常规**
* 再次加入了影子。

# 更改
# = 方块 =
* *[门](门.md)**
* 其旋转方式得到改进。

* *[告示牌](告示牌.md)**
* 挖掘速度更快了。
* 现在被破坏会掉落自身。

# 修复
* *修复了4个漏洞**
* 修复了将门放在玻璃、台阶、梯子和告示牌上会导致门立即被破坏并掉落两扇门的漏洞。
* 挖掘告示牌时产生的粒子不再是草方块的了。
* 水的纹理上不再显示熔岩的纹理。
* 在不使用代理调试器时，玩家的皮肤不再是完全黑的，而是显示Steve皮肤。</onlyinclude>
