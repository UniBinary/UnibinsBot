# 工具

*页面ID: 10303* | *来源: Minecraft Wiki*

* *工具（Tool）**是一种能提升玩家采集能力和采集速度，帮助获得信息，或是辅助其他活动的[物品](物品.md)。除[时钟](时钟.md)、[指南针](指南针.md)、[拴绳](拴绳.md)和[铁桶](铁桶.md)外的工具无法堆叠。一些工具具有[物品耐久](物品耐久.md)，可被[修复](物品修复.md)。

# 获取
# = 生物 =

一些工具能通过杀死拿着工具的生物获得。

# = 合成 =
大多数工具能通过合成获得。

# = 锻造 =
[下界合金](品质.md)工具能通过[锻造台](锻造台.md)锻造而成。

# 用途
# = 最佳工具 =

特定工具可加速破坏特定方块，且一些方块必须使用特定工具破坏才会掉落。工具的[品质](品质.md)亦影响方块的破坏速度。从破坏速度角度而言，工具的品质从坏到好，依次是：木质、石质、铜质、铁质、钻石质、下界合金质、金质。

# = 物品耐久 =
物品耐久}}

不同工具的耐久度不同。一些操作会消耗比其他操作更多的耐久。工具的品质亦影响其耐久度。从耐久度角度而言，工具的品质从坏到好，依次是：金质、木质、石质、铜质、铁质、钻石质、下界合金质。

有些工具的功能并不是破坏方块：包括[弓](弓.md)、[弩](弩.md)、[钓鱼竿](钓鱼竿.md)、[胡萝卜钓竿](胡萝卜钓竿.md)、[打火石](打火石.md)、[铁桶](铁桶.md)和[诡异菌钓竿](诡异菌钓竿.md)。这样的工具在破坏方块时与空手没有区别，且不会消耗工具的耐久度。这些工具只有被使用于特定的使用方式时才会发挥作用，并降低耐久度。

# = 烧炼材料 =

=== 燃料 ===
木质工具能作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料使用，一个木质工具可以烧炼10秒（1个物品）。

弓、弩或钓鱼竿能作为熔炉、高炉或烟熏炉的燃料使用，一个弓、弩或钓鱼竿可以烧炼15秒（1.5个物品）。
