* *树脂矿石（Resin Ore）**是一种自然生成于[马铃薯维度](马铃薯维度.md)的[矿石](矿石.md)。

# 生成
# = 自然生成 =
树脂矿石会以[团簇](团簇.md)的形式生成于[马铃薯维度](马铃薯维度.md)Y=0至80高度范围的马铃石之间，其中Y=10处分布得最多，向两端递减。矿团大小为1-6个方块，每区块最多尝试生成20次。

# 获取
树脂矿石只能通过破坏对应方块获得。

# 破坏
挖掘树脂矿石的合适工具是锄。树脂矿石需要木锄或品质更好的锄来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，树脂矿石被破坏后会掉落1个杂质为“气泡”，清晰度为“糟糕”（概率）、“暗淡”（概率）或“终极”（概率）的[毒树脂](毒树脂.md)，挖掘工具的[时运](时运.md)魔咒会增加毒树脂的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，树脂矿石被破坏后会掉落自身。

# 用途
树脂矿石是[光照透明方块](光照透明方块.md)，天空光射入树脂矿石后亮度等级会减少2。

# = 光源 =
树脂矿石会发出[光照等级](光照等级.md)为3的光。
