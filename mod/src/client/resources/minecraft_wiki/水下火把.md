# 水下火把

*页面ID: 34278* | *来源: Minecraft Wiki*

* *水下火把（Underwater torches）**是一种可以在水下发[光](光.md)的非固体[方块](方块.md)。

# 生成
水下火把不会生成在世界中。

# 破坏
水下火把被挖掘时会立刻被破坏。

水下火把被破坏后会掉落自身。

# 用途

水下火把必须放置于方块[中心完整](方块支撑形状.md)的上表面上方或方块完整的侧面，不过有个别的需要放置，详情见下文表格。

当水下火把所附着的方块变得不可附着（被移动、破坏、替换等）时，水下火把会立即掉落。

如果在[沙子](沙子.md)或[沙砾](沙砾.md)这种受重力影响的方块正下方有一个水下火把，它将不会下落。如果它下落到水下火把的位置，它将被破坏。

不同于[火把](火把.md)，水下火把可以[含水](含水.md)。

# = 光源 =
水下火把发出亮度为14的[光](光.md)。水下火把能融化[曼哈顿距离](曼哈顿距离.md)2格内的[雪](雪.md)和[冰](冰.md)。
