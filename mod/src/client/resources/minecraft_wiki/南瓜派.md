* *南瓜派（Pumpkin Pie）**是一种能被[玩家](玩家.md)食用的[食物](食物.md)类[物品](物品.md)。

# 获取
# = 合成 =

# = 交易 =

# = 箱子战利品 =

# = 礼物 =

[农民](农民.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷南瓜派。

# 用途
# = 食物 =

手持南瓜派按住键即可食用，每个南瓜派可以回复。

# = 堆肥 =
将南瓜派放进[堆肥桶](堆肥桶.md)里会使其增加1个堆肥层。
