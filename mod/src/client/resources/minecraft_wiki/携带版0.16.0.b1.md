# 携带版0.16.0.b1

*页面ID: 24475* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.16.0 alpha build 1**（也被称为**0.15.90**<ref>http://pocketbeta.minecraft.net/2016/08/notes-for-016-beta-build-1-aka-015901.html</ref>）是[v0.16.0 alpha](携带版0.16.0.md)的首个测试版，发布于2016年8月29日<ref>http://pocketbeta.minecraft.net/2016/08/changelog-what-is-new-in-0160-update.html</ref>，加入了新的[命令](命令.md)、[海底神殿](海底神殿.md)、[守卫者](守卫者.md)、[远古守卫者](远古守卫者.md)以及其他新特性，并修复了一些漏洞。

# 新内容
# = 常规 =
* 自定义键盘控制的键位。
* 为[创造模式物品栏](创造模式物品栏.md)添加搜索栏。（仅Windows 10版）
* 在VR选项下加入鼠标UI敏感度的选项。（仅Oculus Rift的Windows 10版）
* 选项菜单的新UI。
* 更多选项。
* * 切换式潜行
* 添加退出游戏前的提示。

# 更改
# = 常规 =
* 性能优化。
* 皮肤选择器在选择自定义皮肤时不再在皮肤后显示轮廓。
* 调整UI界面下Oculus Rift的传感器的纵向横向运动比例的鼠标敏感度。（仅Oculus Rift的Windows 10版）
* 为有余力的GPU提升视野距离。（仅Windows 10版与教育版）
* 调整时钟的纹理以纠正全部的错误像素。
* [旧世界类型](旧世界类型.md)选项
* * 不再出现。
* * 之前创建的旧世界仍然可以制作成无限世界类型。

* * 使用时有了新音效。

# 修复

* *其他**
* 使用工作台缩放地图时，原地图可以随意放置。
* 修复了安卓设备里的崩溃。
* 使用Gear VR进行游戏时崩溃。
* 帧率会影响鼠标或控制器的灵敏度。
* 使用FireTV进行游戏时崩溃。
* 当玩家访问Realm设置时游戏崩溃。
* 使用Android、Kindle、iOS和Gear VR设备连接到Realms时游戏崩溃。
* 使用Windows 10版Rift设备进行游戏时，骑乘动物时从房间模式切换到沉浸模式后，动物会被透视。
* 船出现阴影。
* 修复了在夜间破坏附近有村民的门后游戏崩溃。
* 玩家进入游戏后出现频繁的通知文本。
* 如果玩家不能多人游戏，现在不再出现邀请好友按钮。
* 修复了Cake Maniac皮肤的纹理错误。
* 在生存模式里攻击船会出现透视现象。
* 当水源方块结冰时，流动的水仍然会流动。
* 玩家在创造模式里不能持续疾跑。
* 按下不能打开聊天框。
* 打开聊天框后迅速输入文本不再出现多余的字符。
* 玩家在方块里或在活板门的位置里关闭活板门时，取消乘坐载具不再使得身体摇晃。
* 修复了船上的敌对生物的攻击范围问题。
* 试图对着幼年哞菇使用剪刀时不再使其无法动弹。
* 在潜行时与马或猪互动不再取消乘坐。
* 选择已填充的地图时游戏崩溃。
* 在创造模式下打开物品栏使得游戏崩溃。
* 某些亡灵生物不会在日光下自燃。
* 乘坐矿车的末影人可能会在拐弯时激活旁边的石头压力板。
* 在矿车里死亡的生物不会离开矿车。
* 烈焰人是否攻击生物会无视服务器或op的游戏模式。
* 骷髅发射箭时不会瞄准。
* 光标在射箭完成后不再隐形。（仅Gear VR版或Windows 10 Rift版）
* 马铠或鞍的灰色槽位图标不能使用纹理包更改。
* 不再生成浮空的火把。
* 下界疣的生长纹理只显示第一阶段。
* “切换成沉浸模式”不再出现在非VR设备里。
* Windows 10版使用Rift进行游戏时，控制器输入现在会正常运作。
* 玩家可以看见猪的血量。
* 修复了部分关于皮肤、纹理包和购买问题。
* 按下Z按钮现在会打开状态效果的按钮。
* 破坏床后不会重置玩家的出生点。
* 骑乘马或猪时，被骑乘的生物在中-{}-毒时显示的生命值不正确。</onlyinclude>
