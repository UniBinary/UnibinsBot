# 边境之地/基岩版

*页面ID: 103288* | *来源: Minecraft Wiki*

[缩略图|天空网格（上）、边境之墙（左、右）和正常世界（下）](File:1.14.60 Farlands1.jpg.md)
下面介绍了[1.17.20.20](基岩版1.17.20.20.md)之前没有打开“”实验性玩法世界中的边境之地。

# 位置
边境之地会在X/Z=+12,550,821和X/Z=-12,550,824开始向外生成。

# 结构
# = 不同平台之间的差异 =
|移动端和Windows端平台同一个种子相同的位置，可以看到虽然种子相同，但Windows端不生成边境之地}}

在Windows、Xbox One和PlayStation 4平台上，传统的边境之地不会生成，在X/Z=±12,550,824外只会生成[虚无](#虚无.md)（详见下文）。[Realms](Realms.md)和[基岩版专用服务器](基岩版专用服务器.md)世界中的边境之地则与之类似。

在Nintendo Switch平台上生成的边境之地与移动端平台表现相同。

基岩版其余平台上边境之地的现象仍不清楚。

由于移动端上的边境之地较复杂，且通常更为人所知，并与Java版Beta 1.8之前的边境之地存在一些共同点，因此该页面主要记录移动端平台上的边境之地。

# = 不同安装包之间的差异 =
不同于ARMv7架构的基岩版，在ARMv8架构的基岩版中，在1.16.0之前在X/Z轴负方向上边境之墙和边境之角上的天空网格会正常生成，而非虚无和天空网格。

# = 边境之地 =
[缩略图|两个边境之墙交汇处，形成了天空网格](File:Desert corner.png.md)

边境之地不会在[超平坦](超平坦.md)世界中生成，因为这种情况下不会使用噪声生成器。

[基岩版](基岩版.md)的边境之地与[Java版的边境之地](边境之地/Java版/Infdev 20100327至Beta 1.7.3的现象.md)稍有不同，如在基岩版边境之地内生成的沙子和沙砾不会掉落。这使得基岩版边境之地的加载相对稳定。虽然最高可建筑高度为255格，但边境之地的地形仍然会在Y=128处被切断，尽管在其顶端的树仍然会正常生成。

[沉船](沉船.md)和[海底废墟](海底废墟.md)会在地表和大于Y=128的地方生成。而埋藏的宝藏和化石会在半空中生成，不接触任何方块。

与Java版不同，靠近边境之角的边境之墙还可能会发生变形。例如在X=+12,550,745，Z=+4,194,304的边境之墙看起来有点被拉伸而且有点厚；而Z=+8,388,608的边境之墙中的洞穴墙壁较薄且天花板和底部较厚。

在边境之角附近的边境之墙地形还可能会变得无比重复，就像陷入了某种“循环”。值得一提的是，Z轴上的边境之墙看起来比X轴上的边境之墙更具有重复性。

# == 天空网格 ==

[缩略图|天空网格](File:Cornerfarlands pe.png.md)

在X/Z轴正方向上的边境之角，草方块将会不同寻常的以网格图形出现，而不是正常的堆叠出现，这种地形被称为天空网格。<ref></ref>在此处的结构生成也会遵循在虚无的规则。

# == 虚无 ==

[缩略图|边境之墙完全消失后，世界只剩下基岩和无海床的海洋](File:1.14.60_Farlands3.jpg.md)

在X=+12,758,545之后，边境之墙完全消失，之后地形会完全停止生成，只会生成无海床的海洋和基岩层。海草和熔岩层仍然会在基岩层生成，而在[冻洋](冻洋.md)中，冰山也仍然会在海平面生成。

一些结构可以仍然在这里生成：[丛林神庙](丛林神庙.md)会悬浮在半空或者浮在水面上；[村庄](村庄.md)通常生成在海平面；[雪屋](雪屋.md)会在水底的基岩层生成，并用石砖替换掉一部分基岩；[海底废墟](海底废墟.md)和[沉船](沉船.md)总是会生成在水底；[埋藏的宝藏](埋藏的宝藏.md)通常会在海平面生成；而[掠夺者前哨站](掠夺者前哨站.md)只会生成瞭望塔，不会生成其他周围的结构。

沙漠水井、地牢、废弃矿井、林地府邸和化石不能在这里生成。

自然生成的熔岩层的部分熔岩可能即使与水接触也不变成黑曜石。

# 其他维度
[下界](下界.md)、[末地](末地.md)的边境之地都与[主世界](主世界.md)的边境之地大同小异。

# = 下界 =
[缩略图|1.16.221中的下界边境之地](File:1.16.221 Farlands1.jpg.md)

下界边境之地与主世界边境之地几乎相同，只是主要由[下界岩](下界岩.md)和少量下界自然方块构成，在Y=31以下都被熔岩海淹没。

# = 末地 =
[缩略图|1.16.221中的末地边境之地](File:1.16.221 Farlands2.jpg.md)

末地边境之地几乎全部都是由[末地石](末地石.md)组成，比主世界有更多的挤压和拉伸。末地小岛在边境之地内仍然会正常生成。

与主世界和下界边境之地不同的是，末地边境之地在X轴和Z轴两侧的边境之墙可能会在不同的位置上生成，这通常会相差三格，这就在X/Z=0两边的边境之墙都造成了不协调的边界。
