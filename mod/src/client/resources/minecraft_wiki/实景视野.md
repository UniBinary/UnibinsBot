# 实景视野

*页面ID: 151714* | *来源: Minecraft Wiki*

* *实景视野（Reality Vision）**是能在戴上后在屏幕中下部显示一个立体的物品。

# 获取
穿戴实景视野生成的人形生物被玩家或驯服的[狼](狼.md)击杀时有8.5%（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落实景视野。

# 用途
当将实景视野戴在[头盔](头盔.md)槽时，会在屏幕中下部显示一个立体（可随[玩家](玩家.md)视角的移动而移动）。
* 会显示当前渲染的[区块](区块.md)。
* 会在地图上以一条绿色[信标光柱](信标#光柱.md)来标记玩家位置。

戴上实景视野会激活[着色器](着色器.md)（），使屏幕看起来像老旧的电视机。
* 在第一人称视角下还会加上眼罩形遮盖层（）。
* 着色器可以通过按关闭。然而切换到[第三人称视角](第三人称视角.md)时，着色器会被再次激活。

戴上实景视野时所见的[告示牌](告示牌.md)会显示文字“OBEY”（服从）。
