# = 铁砧 =

叠加两把刷子的剩余耐久度，再额外获得12%的耐久度，按照铁砧机制保留魔咒。

# 用途
玩家可以用刷子刷扫方块。对任何方块刷子时，刷子会被平放并左右往复移动，并在目标方块上产生或的对应方块破坏粒子。若对[可疑的方块](可疑的方块.md)使用刷子，可疑的方块将会在后变为[沙子](沙子.md)或[沙砾](沙砾.md)，若为自然生成还会掉落一样物品，详见[其战利品表](可疑的方块#自然生成.md)。

可疑的方块被刷扫完毕时，刷子会消耗1点[耐久度](耐久度.md)。

刷子亦可用于刷扫成年[犰狳](犰狳.md)以获取[犰狳鳞甲](犰狳鳞甲.md)，每次消耗16点耐久度。<ref></ref>
