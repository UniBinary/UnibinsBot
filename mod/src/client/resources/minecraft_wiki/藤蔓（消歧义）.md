# 藤蔓（消歧义）

*页面ID: 71184* | *来源: Minecraft Wiki*

* *藤蔓（Vines）**可以指：

# Minecraft
# = 方块 =
*  - 绿色的植物，自然生成于[丛林](丛林.md)和[沼泽](沼泽.md)。
*  - 可生长[发光浆果](发光浆果.md)的绿色植物，自然生成于[繁茂洞穴](繁茂洞穴.md)。
*  - 蓝色的植物，自然生成于[诡异森林](诡异森林.md)。
*  - 红色的植物，自然生成于[绯红森林](绯红森林.md)。

# = 地物 =
*  - 由藤蔓组成的[地物](地物.md)。

# = 实体 =
* [藤蔓](恶毒马铃薯#用途.md) - 愚人节快照[24w14potato](24w14potato.md)中[恶毒马铃薯](恶毒马铃薯.md)发射的弹射物。

# Minecraft Dungeons
# = 实体 =
*  - [觉醒丛林](觉醒丛林.md)DLC中的植物状实体，由[丛林恶物](丛林恶物.md)生成。
*  - 剧毒的植物状敌对生物，生成于觉醒丛林的各个关卡中。
*  - 植物状敌对生物，生成于觉醒丛林的各个关卡中。

# Minecraft Legends
# = 地物 =
*  - 能施加中毒效果的减益地物。
