* *1.6.4**是的一次次要更新，发布于2013年9月19日<ref></ref>，修复了世界文件中结构保存错误的漏洞。此版本不兼容1.6.1和1.6.2的服务端。

# 新内容
# = 常规 =
* *[server.properties](server.properties.md)**
* 加入了玩家挂机超时选项。
* * 未操作时间超过固定值则会从服务器踢出玩家，默认禁用（0）。

# 修复

* *其他漏洞**
* 修复了客户端与服务端的信号交换漏洞。
