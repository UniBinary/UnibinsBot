# 启动器1.0.3

*页面ID: 49334* | *来源: Minecraft Wiki*

* *1.0.3**是2013年6月27日发布的[启动器](启动器.md)版本。

# 修复
*  - 修复了可使用非付费账户玩完整版游戏的问题。
*  - 修复了当使用玩家名而非邮箱登录游戏的时候，启动器会弹出错误信息的问题。
