# Java版Beta

*页面ID: 6005* | *来源: Minecraft Wiki*

* *Beta**是[Minecraft](Minecraft.md)的第六个[开发阶段](版本记录.md)，该版本于2010年12月10日在[Notch](Notch.md)的博客上宣布，并在九天后的12月20日正式发布。<ref></ref>此阶段不仅包含一些次要更新，游戏价格也比Alpha阶段上涨了50%。同时，免责声明有所更改（Notch删除了“所有未来的更新都将免费提供”这一行内容，不过在Beta发布前购买Minecraft的用户仍适用该声明，Alpha与Beta阶段的购买者均可获得完整且免费的游戏），官网上也有次要更新。

# 特色

* 新的[Minecraft](Minecraft.md)标识和启动器。
* 新的主菜单页面。
* 包含[成就](成就/Java版.md)和[统计](统计.md)。
* 新增[创造模式](创造模式.md)。
* 添加[天气](天气.md)效果：[降雨](降雨.md)和[降雪](降雪.md)。
* 重写[生物群系](生物群系.md)代码。
* [树木](树木.md)的种类更加丰富。
* 新的[亮度](亮度.md)机制。
* 新的图形效果：改进的日出/日落、水里的气泡、[爆炸](爆炸.md)过程以及[虚空](虚空.md)中的粒子效果。
* 新增结构：[要塞](要塞.md)、[废弃矿井](废弃矿井.md)和[村庄](村庄.md)。
* 新增生物：[鱿鱼](鱿鱼.md)、[末影人](末影人.md)、[蠹虫](蠹虫.md)、[洞穴蜘蛛](洞穴蜘蛛.md)以及可驯化的[狼](狼.md)。
* 新增[生命](生命.md)机制：[饥饿系统](饥饿.md)和可堆叠的[食物](食物.md)。
* 新增战斗机制：[暴击](暴击.md)、可储力的[弓](弓.md)、[经验球](经验球.md)、[疾跑](疾跑.md)和[防御](防御.md)。
* 新增红石装置：[红石中继器](红石中继器.md)、[音符盒](音符盒.md)、[动力铁轨](动力铁轨.md)、[探测铁轨](探测铁轨.md)、[活板门](活板门.md)、[活塞](活塞.md)和[黏性活塞](黏性活塞.md)。
* 新增[方块](方块.md)，例如[砂岩](砂岩.md)及[青金石块](青金石块.md)。
* 新增农业元素：[西瓜](西瓜.md)和[南瓜](南瓜.md)。
* 新增[地图](地图.md)。<ref></ref>
* 新增[床](床.md)，用于跳过夜晚并设置[出生点](出生点.md)。
* 新增羊毛[染料](染料.md)。
