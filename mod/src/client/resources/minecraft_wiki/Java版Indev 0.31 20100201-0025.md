# Java版Indev 0.31 20100201-0025

*页面ID: 35366* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2010年2月1日00:25（UTC），加入了玻璃的烧炼配方和布料的合成配方。

# 更改
# = 方块 =
* *[玻璃](玻璃.md)**
* 现在可以通过冶炼[沙子](沙子.md)或[沙砾](沙砾.md)获得1-3个。

* *[布料](布料.md)**
* 现在可以用9个[线](线.md)合成。

# = 非生物实体 =
* *[掉落物](掉落物.md)**
* 现在会在摧毁前在[熔岩](熔岩.md)表面弹跳。</onlyinclude>
