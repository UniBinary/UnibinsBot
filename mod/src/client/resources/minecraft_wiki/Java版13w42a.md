# Java版13w42a

*页面ID: 33631* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w42a**是[Java版1.7.2](Java版1.7.2.md)的第12个快照，发布于2013年10月17日<ref></ref>。

# 更改
# = 方块 =
* *[染色玻璃](染色玻璃.md)和[染色玻璃板](染色玻璃板.md)**
* 有了一个更柔和、更透明的纹理。

* *[告示牌](告示牌.md)**
* 现在可以写上不同的符号了。

* *[水](水.md)**
* 稍微更改了透明度。
* * 如果[水](水.md)与[冰](冰.md)相邻，玩家无法透过冰看到水，但能透过水看到冰。
* * 如果水与冰不相邻，则透过冰也能看到水。<ref></ref>
* 在水下不能再看见水面。

# = 物品 =
* *[地图](地图.md)**
* 改进了[地图](地图.md)。
* * 地图现在会显示[羊毛](羊毛.md)和[染色陶瓦](染色陶瓦.md)的颜色，并允许在地图上显示更广泛的颜色。
* * 不同的[方块](方块.md)在地图上现在有不同的阴影。

# = 生物 =
* *[女巫](女巫.md)**
* 现在可以生成在亮度低于7的任何地方，包括任何[生物群系](生物群系.md)和地下。

# = 常规 =
* *[物品栏](物品栏.md)**
* [盔甲](盔甲.md)槽在空闲时或离开光标时变黑。
* 将光标放在盔甲槽上可以显示盔甲在哪里。

* *[资源包](资源包.md)**
* 重写了声音系统。
* * [资源包](资源包.md)能够用于添加新的声音了。
* * 资源包现在可以通过使用JSON来添加、移除、补充、随机化和给声音分组。
* * 声音和音效现在同时储存在文件夹内。
