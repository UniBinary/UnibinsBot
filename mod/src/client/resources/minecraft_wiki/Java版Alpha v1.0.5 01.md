# Java版Alpha v1.0.5 01

*页面ID: 32489* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.5_01**是的一次更新，发布于2010年7月14日<ref></ref>，主要针对Alpha v1.0.5加入的[雪球](雪球.md)和[雪](雪.md)进行了更改。

# 更改
# = 方块 =
* *[水](水.md)**
* 现在会结冰了。

# = 物品 =
* *[雪球](雪球.md)**
* 现在使用[锹](锹.md)破坏[雪块](雪块.md)时才会掉落。
* 最多可堆叠的数目从64个调整为8个。
* 更改了扔[雪球](雪球.md)时的音效。<!--=== 游戏内容 ===
* *[多人游戏](多人游戏.md)**
* 进行了一些改进（尽管多人游戏仍然处于私人测试阶段）。
* * 方块现在可以被破坏。
* * 加入了运动检测。
* * [玩家](玩家.md)现在不可能再挖掘一个不可破坏的方块。
* * 玩家现在不可能以过快的速度破坏方块。
* * 玩家现在不可能穿过固体方块。-->

# 修复
* *修复了2个漏洞**
* 使用镐挖掘方块的最后一刻会掉落物品。
* 在雪层上方的雪块不再使得其顶部消失。</onlyinclude>
