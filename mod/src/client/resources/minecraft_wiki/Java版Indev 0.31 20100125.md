# Java版Indev 0.31 20100125

*页面ID: 35330* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2010年1月25日，加入了一些粒子。

# 新内容
# = 常规 =
* *[粒子](粒子.md)**
* 加入了[火把](火把.md)、[火](火.md)和[熔岩](熔岩.md)的粒子效果。

# 更改
# = 世界生成 =
* *[Indev房子](Indev房子.md)**
* 添加了一个含有每种布料各一组的[箱子](箱子.md)。
* * 布料不再能够在含有主要方块的箱子中找到。

# = 方块 =
* *[熔岩](熔岩.md)**
* 暴露在空气中的熔岩会变成[石头](石头.md)。<ref name="Forum7"></ref>

* *[水](水.md)**
* 现在会蒸发。<ref name="Forum7"/>

* *[TNT](TNT.md)**
* 不再对[实体](实体.md)造成损伤，也不会摧毁[掉落物](掉落物.md)。
* 不再在水中爆炸。<ref name="Forum1"></ref><ref name="Forum"></ref>
* 从点燃到爆炸的时间由2秒改为4秒。
* 现在点燃时会闪烁。

# = 游戏内容 =
* *[伤害](伤害.md)**
* 溺水受到的伤害由2颗心/秒降低到1颗心/秒。
* 现在会在溺水实体周围产生溺水粒子。

# 修复
* *修复了1个漏洞**
* 修复了挖掘某些方块时若切换手中的物品，方块会出现错误并快速循环变换纹理的漏洞。</onlyinclude>
