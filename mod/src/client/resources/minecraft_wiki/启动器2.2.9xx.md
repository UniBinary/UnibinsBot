# 启动器2.2.9xx

*页面ID: 74150* | *来源: Minecraft Wiki*

* *2.2.911**（[Windows](wzh:Microsoft Windows.md)）、**2.2.910**（[macOS](wzh:MacOS.md)）或**2.2.909**（[Linux](wzh:Linux.md)）是一次[启动器](启动器.md)更新，发布于2020年12月8日。

# 新内容
* 加入了账号迁移常见问题解答。
* 向[Minecraft：Java版](Java版.md)的“配置”界面加入了打开游戏目录的按钮。
* 加入了关于账号迁移登录屏幕的免责声明。

# 更改
* 现在“有Mods”复选框默认会打上勾。
* 对于整个启动器中对话框辅助功能的各种修复。

# 修复
* 修复了向启动器中添加新用户时的漏洞。
* 修复了在macOS上打开目录时的漏洞。
*  - 最新游戏版本被替换为了一个带有OptiFine的修改版本。
*  - 在修改配置界面无法滚动页面。
