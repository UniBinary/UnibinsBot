# 命令/move

*页面ID: 56598* | *来源: Minecraft Wiki*

使[智能体](智能体.md)在指定方向上移动。

# 语法
   <code>-{}-move <*方向：字符串*></code>

# 参数
<code>-{}-*方向：字符串*</code>
   必须为以下之一：
  * <code>forward</code>——向前移动。
  * <code>back</code>——向后移动。
  * <code>left</code>——向左移动。
  * <code>right</code>——向右移动。
  * <code>up</code>——向上移动。
  * <code>down</code>——向下移动。
