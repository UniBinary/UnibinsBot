# 基岩版1.17.30.22

*页面ID: 87329* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.17.30.22**是[基岩版1.17.30](基岩版1.17.30.md)的第7个测试版，发布于2021年8月18日<ref></ref>，修复了一些漏洞。

# 更改
# = 物品 =
* *[潜影盒](潜影盒.md)**
* 现在以[物品实体](物品实体.md)的形式被摧毁时，其内容物会被释放。

* *药水**
* 将药水名称字符串资源和{{cd|-{}-potion..*后缀*}}重命名为{{cd|-{}-*药水*..name}}。
* 药水名称字符串资源现已更改，现在拥有单独的和字符串资源。
* 旧版的和仍然受支持。

# = 常规 =
* *用户界面**
* 现在语言文件格式存在问题时会通知用户一则内容警告信息。

* *行为包**
* 行为包中定义的动画和事件现在可通过需要开启作弊的命令运行，并且无需玩家开启作弊（例如使用命令设置部分游戏规则）。

* *[菜单屏幕](菜单屏幕.md)**
* 将通往[角色创建器](角色创建器.md)的“个人资料（Profile）”按钮重命名为“更衣室（Dressing Room）”。

# 修复
* *制图师**
* 制图师村民现在只会出售未探索过的探险家地图。（）

* *附魔**
* 现在在附魔台上附魔会随机进行加权了。（）

* *原版趋同**
* 修复了手上不持有屏障时屏障没有判定箱的问题。（）
* 修复了屏障不能阻挡弹射物的问题。（）
* 修复了屏障不能阻止玩家透过屏障与方块交互的问题。
* 现在掉落物形式的潜影盒被摧毁时会释放出其内容物。（、）
* 修改了手持和使用弓和三叉戟的动画以近似匹配Java版。（、）
* 草方块和水的颜色不再因噪声洞穴而随机变化。
* 降低了僵尸村庄的生成概率以近似匹配Java版。（）

* *图形**
* 修复了通过网络连接使用市场上的皮肤的其他玩家手持的三叉戟、盾牌和弩会错误渲染的漏洞。（）
* 修复了自定义皮肤玩家使用望远镜时望远镜会显示得像被抛出去的漏洞。（）
* 增大了辐照度缓存样本量，以修复光线追踪模式下辐射光的传播问题。（）
* 调节抗锯齿时快捷栏不再会变得过于昏暗。（）
* 多人游戏中的十字准星不再会闪烁。（）

* *市场**
* 加入了新的圆形加载条以替代市场中的条形加载条。

* *用户界面**
* 修复了快捷栏与经验条错位1个像素的问题。（）
* 现在触摸控制玩家可以按住切石机或织布机的输出槽来快速制作。（）
* 修复了试图激活缺少依赖项的包时会错误弹出弹窗的问题。（）
* 修复了一些包含大写字母拼写的按键的翻译问题。

* *生物（实验性）**
* 修复了在高度为负数的区域取消骑乘生物时会站在错误位置的问题。（）</onlyinclude>
