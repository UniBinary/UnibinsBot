# Minecraft Live 2023

*页面ID: 105808* | *来源: Minecraft Wiki*

* *Minecraft Live 2023**是一场线上直播活动，于2023年10月15日17:00（UTC）举行。该场活动公布了将在[Java版1.21](Java版1.21.md)和[基岩版1.21.0](基岩版1.21.0.md)中加入的少部分内容，但并未公布其主题。同时按照往年的惯例举行新一轮生物投票，最终犰狳胜出。直播中也宣布了[Minecraft Legends](Minecraft Legends.md)即将到来的主要更新。<ref name="minecraft-live-2023-announcement"></ref>

# 预告
# = Minecraft Live 2023：预告片 =
官方于2023年9月13日发布预告视频，正式宣布此次活动。

# = 关于Minecraft Live 2023生物投票 =

# = Minecraft Live 2023——倒计时开始！ =

# 活动
# = 社区预热 =
在主要活动开始前有20分钟的社区预热活动，分享了世界各地YouTuber的Minecraft视频。

# = 版本公告 =
本次直播公布了Minecraft下一次主要更新（[Java版1.21](Java版1.21.md)和[基岩版1.21.0](基岩版1.21.0.md)）的部分更新内容，但并未透露其主题名称。展示了[试炼密室](试炼密室.md)、[试炼刷怪笼](试炼刷怪笼.md)、[铜灯](铜灯.md)、[旋风人](旋风人.md)、[合成器](合成器.md)以及由铜和[凝灰岩](凝灰岩.md)制成的装饰性方块。此次直播并未展示全部的1.21计划内容，而是会在之后的快照及测试版中逐渐揭露。除此之外还公布了[Minecraft Legends](Minecraft Legends.md)一次即将到来的主要更新。

# = 生物投票 =
本届生物投票于[启动器](启动器.md)、[minecraft.net](minecraft.net.md)以及一个[专门开设的基岩版服务器](2023年生物投票服务器活动.md)中同时举行。投票自2023年10月13日17:00（UTC）开始，至10月15日17:15（UTC）结束，共持续48小时15分钟<ref name="minecraft-live-2023-announcement"/>。本届投票有3个生物，[Jens Bergensten](Jens Bergensten.md)在2023年9月27日于四川成都举行的[中国版开发者大会](中国版:2023开发者大会.md)上提到参与投票的是“三个可爱的动物”。<ref>|title=Mojang 首席创意官 Jens 开发者大会完整演讲|website=Bilibili|author=我的世界中文论坛|date=2023年9月27日}}</ref>

[中国版](中国版.md)也在北京时间10月14日1时至10月16日1时于手游版启动器内开放投票渠道，每个账号允许投出一票，在活动结束前可随意修改，且中国版玩家的投票也将计入全球总票数。<ref></ref>

以下为3个候选生物的信息：
[thumb|三个生物的投票选项](File:MCLive2023MobVoteAllOptions.png.md)

; [32px](File:CrabPixel.png.md) 螃蟹（Crab）<ref></ref>
* 会在[红树林沼泽](红树林沼泽.md)中生成。
* 可以纵向攀爬。
* 有巨大的蟹钳，会不时挥舞。
* * [x32px](File:Crab Claw.png.md) 玩家可借助蟹钳来增加放置方块的距离。

; [32px](File:ArmadilloPixel.png.md) （Armadillo）<ref></ref>
* 会在诸如[热带草原](热带草原.md)的温暖生物群系中生成。
* 受到惊吓时会蜷缩成方块状。
* [x32px](File:Armadillo Scute (pre-release).png.md) 其[鳞甲](犰狳鳞甲.md)会掉落，可用于制作[狼铠](狼铠.md)，为[狼](狼.md)提供护甲值。

; [x32px](File:PenguinPixel.png.md) 企鹅（Penguin）<ref></ref>
* 会在[石岸](石岸.md)生成。
* 能在水中悠游、在陆地上笨拙地行走。
* 能够提升附近[船只](船.md)的行驶速度。

# == 结果 ==
直播中途公布了得票数最低的生物，而后在直播末尾公布了得票数最高的生物，犰狳在投票中胜出。投票总数以及各生物具体的得票比例在直播结束后公布。<ref></ref>

# **犰狳**（42.3%，约211.5万票）
# 螃蟹（32.5%，约162.5万票）
# 企鹅（25.2%，约126万票）
