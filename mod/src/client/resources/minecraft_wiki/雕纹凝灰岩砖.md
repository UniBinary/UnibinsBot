# 雕纹凝灰岩砖

*页面ID: 106767* | *来源: Minecraft Wiki*

* *雕纹凝灰岩砖（Chiseled Tuff Bricks）**是[凝灰岩砖](凝灰岩砖.md)制作的装饰性方块。

# 生成
# = 自然生成 =
雕纹凝灰岩砖会作为[试炼密室](试炼密室.md)的一部分生成。

# 破坏
挖掘雕纹凝灰岩砖的合适工具是镐。雕纹凝灰岩砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

雕纹凝灰岩砖被破坏后会掉落自身。

# 用途
雕纹凝灰岩砖目前仅用于装饰。
