# 实验性玩法

*页面ID: 82039* | *来源: Minecraft Wiki*

”标签的实验性世界}}

* *实验性玩法（Experimental Gameplay/Experiments）**是独有的游戏[设置](设置.md)，开启后玩家可以在世界中试用未完成开发或正在开发的实验性功能，这些功能最终可能会在未来版本中实现。

# 切换
实验性玩法的子选项可以在[创建新的世界](创建新的世界.md)界面的设置或编辑世界界面的游戏设置中找到，开启后会导致世界无法解锁[成就](成就.md)<ref></ref>，在创建世界后该选项将会无法关闭。若对已创建的世界开启实验性玩法，则会创建一个开启实验性玩法的副本世界。原有的世界仍然可以进行游戏，但这两个世界的进展不会互相同步。实验性世界的游戏模式后面会显示一个“实验”标签。

# 警告

开启实验性玩法后会启用一些尚未完成开发的实验性功能，这些功能可能会不适应未来版本，从而导致该世界在未来版本中崩溃、损坏或无法加载。加载旧版实验性世界之前会出现一则警告。尝试使用外部程序工具强制关闭实验性玩法可能会导致世界崩溃或损坏。

# = 正式版 =
截至，“”包含下列功能：

* *游戏内容**
* 对盔甲匠和图书管理员的[交易](交易.md)的平衡性调整

截至，“”包含下列功能：

* *物品**
* [命名牌](命名牌.md)的合成配方

* *生物**
* 部分[幼年生物](幼年生物.md)的新模型、新纹理和新音效
* * [牛](牛.md)、[哞菇](哞菇.md)、[豹猫](豹猫.md)和[绵羊](绵羊.md)的新模型和新纹理
* * [猪](猪.md)、[猫](猫.md)和[狼](狼.md)的新模型、新纹理和新音效
* [兔子](兔子.md)的新模型和新纹理

# = 测试版 =
测试版内的实验性功能可能会在正式版基础之上有所改动。

在中，“”中包含的功能与正式版一致。

截至，“”子选项已被移除，其所包含的功能不再是实验性功能。
