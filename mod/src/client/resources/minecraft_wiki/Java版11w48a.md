# Java版11w48a

*页面ID: 31714* | *来源: Minecraft Wiki*

<onlyinclude>

* *11w48a**是[Java版1.1](Java版1.1.md)的第2个快照，发布于2011年12月1日<ref></ref>，修复了一个漏洞。

# 更改
# = 方块 =
* *[耕地](耕地.md)**
* 现在耕地只能被玩家跳跃或掉落在耕地上践踏破坏；走上耕地不再造成踩毁的情况。
* 生物同样只能通过跳跃而不是走上耕地的方法来践踏破坏耕地。

# = 物品 =
* *[苹果](苹果.md)**
* 现在[橡树树叶](橡树树叶.md)有的概率掉落一个苹果。

# = 世界生成 =
* *[虚空迷雾](虚空迷雾.md)**
* 在[创造模式](创造模式.md)下被移除。

* *[针叶林](针叶林.md)**
* 现在生成时会带有[雪](雪.md)。

# 修复
* *修复了1个漏洞**
* 针叶林生物群系不生成冰和雪。</onlyinclude>
