# Java版18w47b

*页面ID: 37424* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w47b**是[Java版1.14](Java版1.14.md)的第8个快照，发布于2018年11月23日<ref></ref>，更改了一些纹理，并修复了一些漏洞。

# 新内容
# = 常规 =
* 在[client.jar](client.jar.md)的根目录加入了version.json文件。
* * 该文件列出了[数据版本](数据版本.md)、[协议版本](协议版本.md)、[数据包](数据包.md)版本、父版本、构建日期和时间等信息，以及是否为稳定构建。

# 更改
# = 方块 =
* *[木桶](木桶.md)**
* 更改了south}}[方块状态](方块状态.md)的UV。

* *[脉冲型命令方块](脉冲型命令方块.md)和[循环型命令方块](循环型命令方块.md)**
* 更改了纹理。

* *[原木](原木.md)**
* 更改了原木和去皮原木的顶部纹理。

* *[云杉门](云杉门.md)和[云杉活板门](云杉活板门.md)**
* 更改了纹理。

# = 物品 =
* *生和熟的[鳕鱼](鱼.md)**
* 纹理还原为[Java版1.13](Java版1.13.md)中的版本。

# = 生物 =
* *[猫](猫.md)**
* 更改了西服猫纹理。

* *常规**
* 更改了生成机制，使其更接近[Java版1.13.2](Java版1.13.2.md)。

# = 常规 =
* *性能**
* 许多世界生成器性能提升。
