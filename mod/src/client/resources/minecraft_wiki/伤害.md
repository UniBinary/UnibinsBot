# 伤害

*页面ID: 10290* | *来源: Minecraft Wiki*

[thumb|[[熔岩](File:LavaDamage.png.md)造成的巨大伤害能迅速吞没一个失足的生物]]
* *伤害（Damage）**是导致[实体](实体.md)[生命值](生命值.md)损失，或遭到击退、着火或[状态效果](状态效果.md)等影响的过程。

# 机制
来自各种来源的伤害会影响生物的健康，施加各种效果，通常是有害的。伤害最主要的效果是降低生物的生命值，这会持续到生物失去所有生命值而死亡。除了降低生命值以外，多数伤害也会施加击退效果，使生物向伤害来源的相反方向飞出。伤害也有可能导致生物[着火](着火.md)，或施加[状态效果](状态效果.md)。

除了造成生命值降低以外，一次伤害效果中还会携带更多内容：
* 伤害可能拥有一个来源，不同的伤害来源可能会使生物做出不同的反应。如果生物被击杀，伤害的来源还会影响生物掉落物战利品表的运作。
* 伤害的类别决定了伤害会以什么方式被防御。一些特定种类的伤害会穿透生物的一部分伤害防护能力。
* 伤害在命中目标后，可以使目标着火、被击退或造成[状态效果](状态效果.md)。

攻击造成伤害通常被视为对生物的直接暴力行为，绝大多数生物在受攻击时都具有明显的反应。拥有攻击能力的生物可能会反击对它们造成伤害的生物，而[村民](村民.md)被玩家攻击时会使或降低。

玩家在受伤时，其视角会“抖动”一下，作为受伤的反馈。可以通过选项“辅助功能→受伤抖动效果”调整抖动强度或禁用抖动。

生命值和伤害值均是[单精度浮点数](wzh:单精度浮点数.md)，可以有小数部分。

在下文的表述中，伤害的数值使用与生命值相同的单位，即受到伤害便降低生命值。

在下文的表述中，“持续造成伤害”或“持续受到伤害”指每都会造成一次伤害的场景。由于生物有[受击后伤害免疫](受击后伤害免疫.md)，持续伤害会被限制为每才能对生物造成一次伤害。如果这些伤害是[盾牌](盾牌.md)可阻挡的，尝试使用盾牌阻挡这些伤害会导致盾牌每一刻都受到打击，快速耗尽其耐久度。如果持续伤害的伤害类型持有伤害类型标签<code>minecraft:bypasses_cooldown</code>，持续伤害将不再会受到受击后伤害免疫的限制，并以十倍于通常情况的速度造成伤害。

如果伤害值调整将伤害值降低到了以下，最终的伤害值将会是而非负值。

玩家受到任何可被[护甲值](护甲值.md)阻挡的伤害皆会使其穿戴的盔甲损失耐久度，每原始伤害会减少每盔甲部件1耐久度（向下取整，但不会低于1）。当玩家被[鸡蛋](鸡蛋.md)、[雪球](雪球.md)或[末影珍珠](末影珍珠.md)命中时，其装备的[盔甲](盔甲.md)也将损耗耐久，尽管它们只能造成伤害。

如果生物即将死于[虚空](虚空.md)和以外的因素造成的伤害，生物持有的[不死图腾](不死图腾.md)会被消耗以阻止死亡，生物的生命值设置为，并触发多种效果。

# = 无懈可击 =

* *无懈可击（Invulnerable）**是实体使自身受到的伤害无效化的机制，即实体**免疫（Immune）**该伤害。当伤害被施加时，如果实体免疫该伤害，那么伤害就会被直接取消，所有伤害造成的效果都会被取消，包括击退、引发的状态效果、引发的着火、引发的生物反应（更新最后攻击者，引起生物逃跑、反击或村庄声望降低）、引发的统计更新、受击后伤害免疫以及其他实体定义的受伤后等效果均不生效。近战攻击造成的伤害被免疫时，近战攻击会失败。

玩家免疫伤害值为0的伤害。

如果实体的实体数据<code>Invulnerable</code>为<code>true</code>，实体将会免疫一切不是创造模式玩家、虚空或造成的伤害；如果实体具有<code>invulnerable</code>能力，实体将会免疫一切不是创造模式玩家、虚空或造成的伤害。

# = 难度影响 =
玩家受到的一部分伤害的伤害值会受到游戏[难度](难度.md)机制的影响。难度对伤害值的影响会使改变后的伤害值被视为减免前伤害，早于所有伤害值调整效果。

如果伤害值受到难度影响，那么该伤害在困难难度下变为<math>1.5 Damage_{before}</math>，在简单难度下变为<math>\min \{0.5 Damage_{before} + 1,\;Damage_{before}\}</math>，在和平难度下变为<math>0</math>。由于玩家免疫伤害值为0的伤害，在和平难度下会导致受难度影响的伤害全部被玩家免疫。

难度对伤害值的影响只适用于对玩家造成的伤害，玩家以外的实体受到的伤害不受难度影响，无论处于哪个难度，造成的伤害都等同于普通难度。

每一种伤害类型都可以指定其伤害值如何受到难度影响：
* 无影响（<code>never</code>）：难度不影响该伤害对玩家的伤害值。目前原版数据中没有使用该设置的伤害类型。
* 有非玩家生物来源时影响（<code>when_caused_by_living_non_player</code>）：难度仅在该伤害有玩家以外的生物来源时才会影响该伤害对玩家的伤害值。绝大多数伤害类型都是这个设置。
* 总是影响（<code>always</code>）：难度总是影响该伤害对玩家的伤害值。所有[爆炸](爆炸.md)现象相关的伤害都使用这个设置。

伤害在不同难度的值是分别指定的，但原版数据中指定的值也都遵循上述的规则。

# = 非生物实体 =
由于只有生物总是具有生命值，[非生物实体](实体.md)受到伤害时通常都不会受到多数对生物造成的效果，如被击退或触发伤害免疫。许多实体甚至无法被选中，尝试攻击时只会使攻击穿透它们并打中其后方的物体。

非生物实体不具有[受击后伤害免疫](受击后伤害免疫.md)。对于会计量伤害值的实体，没有受击后伤害免疫意味着这些实体会在持续的伤害源中每一刻都受到伤害并更改其对应的计数，并相当于在这些伤害源中会承受近10倍于生物的伤害。

# 受击后伤害免疫

# 击退

生物受到伤害时会被**击退（Knockback）**，并被抛向伤害来源的相反方向。击退造成的失控不容小觑，生物也许会因此被击落悬崖或是坠入熔岩中。

向除末影龙外的生物投掷[鸡蛋](鸡蛋.md)、[雪球](雪球.md)或[末影珍珠](末影珍珠.md)时，虽然不会降低生命值，但同样会造成伤害并产生击退效果。

疾跑时攻击生物会增加击退效果，还会产生不同的[音效](音效.md)以区别于普通攻击。

[击退](击退.md)和[冲击](冲击.md)魔咒也能大幅增加武器能造成的击退效果。

生物所站立方块的性质会影响所受到的击退效果。生物站在冰面或[黏液块](黏液块.md)上时受到的击退效果会明显增强，而站立在[灵魂沙](灵魂沙.md)（未穿有[灵魂疾行](灵魂疾行.md)附魔靴子时）或[蜂蜜块](蜂蜜块.md)上受到的击退效果则会被大幅削弱。此外，生物在空中（受重力影响但未落地）或在水中也会增强受到的击退效果。

[末影龙](末影龙.md)、[潜影贝](潜影贝.md)和正在骑乘其他实体的生物不会被击退。

# = 击退抗性 =
* *击退抗性（Knockback resistance）**是生物抵抗击退效果的能力，可以被控制。当生物受到击退效果时，实际的击退距离会按照击退抗性被直接减少。

[爆炸](爆炸.md)造成的[爆炸击退](爆炸击退.md)不受击退抗性的影响。

一部分生物具有额外的基础击退抗性。

一部分[盔甲](盔甲.md)在装备时可以增加生物的击退抗性。

# 造成伤害

游戏中有诸多机制都会造成伤害，关于所有可以产生伤害的情况及数值，请见[伤害/伤害来源](伤害/伤害来源.md)。

# 伤害来源
伤害来源用于表示“某种伤害从何处产生”。一个伤害来源可以来自实体或非实体。

若来自实体，则包含：
* **[伤害类型](伤害类型.md)（Damage Type）**
* **源发实体（Causing Entity）**
* **直接实体（Direct Entity）**

若来自非实体，则包含：
* **[伤害类型](伤害类型.md)（Damage Type）**
* **伤害来源位置（Damage Source Position）**

当某实体对某实体进行攻击时，发出攻击的实体会产生一个伤害来源。

例如，僵尸对村民攻击，此时僵尸产生一个[伤害类型](伤害类型.md)的伤害来源，且在该伤害来源中，僵尸既是源发实体也是直接实体。又比如，当一个玩家射箭击中骷髅时，箭可能会产生一个伤害类型的伤害来源，箭本身将作为造成伤害的直接实体，而射出箭的玩家将作为源发实体。

若源发实体与直接实体不同，则表示该伤害来源是**间接（Indirect）**的。例如，雪傀儡向僵尸发射雪球时，雪傀儡为源发实体，雪傀儡所发射的雪球为直接实体，因为雪球将是直接使僵尸受伤的实体——雪傀儡通过其所发射的雪球间接伤害了僵尸。

直接实体不一定存在。以恶魂火球对玩家造成[爆炸伤害](爆炸伤害.md)为例，对爆炸伤害而言，没有直接实体，而恶魂火球既是源发实体也是爆炸来源，即恶魂火球通过发生[爆炸](爆炸.md)间接伤害了玩家。

# = 造成伤害的生物 =
造成伤害时，生物能够识别伤害的来源，并对其做出回应。大多数有攻击能力的生物都具有反击伤害来源的行为，除非，或因其他原因而不敌对。

一部分生物受攻击时会导致附近的同种或其他生物也变得敌对。村民被玩家攻击时会[言论](言论.md)}}或。

生物死亡时，该生物死亡前最后5秒内最后一个对其造成伤害的生物会被视为击杀者，并计入相关的统计。绝大多数生物只在被[玩家](玩家.md)或玩家驯服的[狼](狼.md)击杀时才会掉落[经验球](经验球.md)。如果在这之后生物还受到过其他不来自生物的伤害并导致了死亡，死亡消息也会有所不同。

玩家使用打火石或生物发射的着火的弹射物点燃的[TNT](TNT.md)炸伤生物也会被视为这一生物造成的伤害。因此，[骷髅](骷髅.md)发射带火的箭引爆TNT炸死[苦力怕](苦力怕.md)也会使其掉落[音乐唱片](音乐唱片.md)。[溺尸](溺尸.md)掷出的三叉戟着火后引爆的TNT炸死的[村民](村民.md)也会变成[僵尸村民](僵尸村民.md)，概率与村民被[僵尸](僵尸.md)杀死时相同。

当[恶魂](恶魂.md)火球受到攻击改变移动方向而对其他生物造成伤害时，此伤害的来源为最后一次攻击火球的生物，而非恶魂。

使用命令，或通过命令生成的具有指定生物UUID作为实体数据的弹射物，是人为操纵并引发任意生物攻击任意生物的常用方式。通过这种方式可以使生物反击[绵羊](绵羊.md)之类本应不能造成任何伤害的生物，使[荆棘](荆棘.md)魔咒伤害“造成伤害”的生物，甚至使[铁傀儡](铁傀儡.md)攻击[村民](村民.md)；由[苦力怕](苦力怕.md)“发射”的箭击中[凋灵骷髅](凋灵骷髅.md)后，被凋灵骷髅近战攻击杀死时也会掉落音乐唱片。

以下方式可以造成伤害而不使生物视为[玩家](玩家.md)造成了伤害：
* 使用红石信号（而不是[打火石](打火石.md)）激活TNT使其爆炸。
* 引爆[床](床.md)或[重生锚](重生锚.md)产生的爆炸不视为任何生物造成的伤害。
* 使用[打火石](打火石.md)点燃方块表面，产生的[火](火.md)烧到了生物。
* 使用[熔岩桶](熔岩桶.md)在生物身上倒出[熔岩](熔岩.md)，或使用[水桶](水桶.md)在[末影人](末影人.md)身上倒出[水](水.md)。
* 在不造成伤害的情况下推挤生物使其[跌落](跌落.md)、[着火](着火.md)、[溺水](溺水.md)或[窒息](窒息.md)。
* 使用[发射器](发射器.md)发射[箭](箭.md)、[喷溅药水](喷溅药水.md)、[火焰弹](火焰弹.md)或[TNT](TNT.md)等各种物品。

# = 造成伤害的物品 =
在确认了造成伤害的生物后，该生物主手持有的[物品](物品.md)将被视为造成伤害的物品，无论伤害是通过何种方式造成的。

持有的物品可能会影响伤害的效果：
* 如果这一物品具有[抢夺](抢夺.md)魔咒，那么因这一伤害而死亡的生物就会受到影响并可能掉落额外的物品。
* 如果这一物品具有自定义名称，那么因这一伤害导致的死亡产生的死亡消息将会包含使用的物品名称。

许多造成伤害的方式在使用后到造成伤害通常有可观的间隔时间，足以允许玩家稳定地更换他们持有的物品，或是直接在主手持有物品而使用副手的工具造成伤害。玩家可以先使用弓或弩射出箭、使用打火石点燃[TNT](TNT.md)、或投掷瞬间伤害药水，在目标受到致命伤害前将手持的物品变更为具有[抢夺](抢夺.md)魔咒的剑，此时死亡的生物将会受到抢夺魔咒影响而可能掉落更多物品。任何物品都可以在不用于近战攻击的情况下，仅需要持有就能影响任何方式死亡的生物及其死亡消息，无论是死于TNT、[烟花火箭](烟花火箭.md)、着火、箭、岩浆块或是摔落，只要伤害是由持有物品的生物造成的。

# 伤害类型

[伤害类型](伤害类型.md)是伤害的基本属性之一。伤害类型决定了该伤害能被如何防护和免疫，影响生物受到伤害时的反应，控制伤害是否能造成击退，以及伤害是否受到难度影响。

# 伤害分类
部分伤害具有一致的特征，使其可以被归类至特定的类别。

# = 魔法伤害 =
魔法伤害是常见的能够穿透防护的伤害，生物的[护甲值](护甲值.md)和[盔甲韧性](盔甲韧性.md)面对魔法伤害时将被完全无视，但[保护](保护.md)魔咒会提供对魔法伤害的防护。

[状态效果](状态效果.md)造成的伤害大多数为魔法伤害，包括[瞬间伤害](瞬间伤害.md)对非亡灵生物的伤害，[瞬间治疗](瞬间治疗.md)对亡灵生物的伤害，以及[中毒](中毒.md)、。

[唤魔者尖牙](唤魔者尖牙.md)和[守卫者](守卫者.md)的激光攻击造成魔法伤害。

[潮涌核心](潮涌核心.md)的攻击造成魔法伤害。

[女巫](女巫.md)受到的魔法伤害降低85%。

魔法伤害具有伤害类型<code>magic</code>（有来源）或<code>indirect_magic</code>（无来源）。

# = 火焰伤害 =
火焰伤害是各类以火焰为设计元素的伤害。[火焰保护](火焰保护.md)魔咒提供对火焰伤害的针对性防护。

玩家受到火焰伤害时，会听到带有“滋滋”声音的伤害音效。

[着火](着火.md)、[火](火.md)、[灵魂火](灵魂火.md)、[营火](营火.md)、[灵魂营火](灵魂营火.md)、[熔岩](熔岩.md)、[岩浆块](岩浆块.md)、[火球](火球.md)和[小火球](小火球.md)能够造成火焰伤害。

[雪傀儡](雪傀儡.md)在高温生物群系中会持续受到火焰伤害。

[僵尸猪灵](僵尸猪灵.md)、[恶魂](恶魂.md)、[凋灵骷髅](凋灵骷髅.md)、[烈焰人](烈焰人.md)、[炽足兽](炽足兽.md)、[岩浆怪](岩浆怪.md)、[潜影贝](潜影贝.md)、[僵尸疣猪兽](僵尸疣猪兽.md)、[监守者](监守者.md)、[末影龙](末影龙.md)、[凋灵](凋灵.md)、与[嘎枝之心](嘎枝之心.md)绑定的[嘎枝](嘎枝.md)、[下界合金质物品](下界合金.md)的[物品实体](物品实体.md)、任何具有[抗火](抗火.md)效果的实体免疫火焰伤害。

火焰伤害具有伤害类型标签。

# = 弹射物伤害 =
弹射物伤害是[弹射物](弹射物.md)对直接命中的生物造成的伤害。[弹射物保护](弹射物保护.md)魔咒提供对弹射物伤害的针对性防护。

[箭](箭.md)、[三叉戟](三叉戟.md)、[小火球](小火球.md)、[火球](火球.md)、、、[潜影弹](潜影弹.md)、[鸡蛋](鸡蛋.md)、[末影珍珠](末影珍珠.md)、[雪球](雪球.md)和[风弹](风弹.md)对被命中的生物造成弹射物伤害。

部分弹射物会造成其他类型的伤害，包括[火球](火球.md)或[凋灵之首](凋灵之首.md)在[爆炸](爆炸.md)时造成的爆炸伤害、[烟花火箭](烟花火箭.md)在爆裂时造成的爆炸伤害和[喷溅型伤害药水](喷溅型伤害药水.md)造成的魔法伤害。

弹射物伤害具有伤害类型标签。

# = 爆炸伤害 =

爆炸伤害是[爆炸](爆炸.md)现象和[烟花火箭](烟花火箭.md)爆裂时造成的伤害。[爆炸保护](爆炸保护.md)魔咒提供对爆炸伤害的针对性防护。

[下界之星](下界之星.md)的[物品实体](物品实体.md)不受爆炸伤害，但仍会受到[爆炸击退](爆炸击退.md)。

爆炸伤害具有伤害类型标签。

# = 摔落伤害 =
摔落伤害是生物[摔落](摔落.md)时、玩家被[末影珍珠](末影珍珠.md)传送或[骑乘](骑乘.md)的实体受到摔落伤害而受到的伤害。[摔落缓冲](摔落缓冲.md)魔咒提供对摔落伤害的针对性防护。
