# 缓降

*页面ID: 36566* | *来源: Minecraft Wiki*

* *缓降（Slow Falling）**是一种大幅降低生物下落速度并阻止[摔落](摔落.md)的[状态效果](状态效果.md)。

# 效果
受影响生物在下降时，若[重力](重力.md)高于0.01，则视为0.01；对于重力原本为0.08的生物，其重力加速度由32m/s<sup>2</sup>降低至4m/s<sup>2</sup>，终端速度由78.4m/s降低至9.8m/s。受影响生物在正在向上移动时仍然受到正常重力的影响。

受影响生物的[下落高度](摔落.md)被设置为0，因此不会[摔落](摔落.md)。这也导致了受影响生物摔落在[耕地](耕地.md)上时不会使其退化成[泥土](泥土.md)、受影响玩家的[近战攻击](近战攻击.md)不能造成[暴击](近战攻击#暴击.md)、无法造成[重锤](重锤.md)的猛击效果。

# 你知道吗
* 缓降只能防止[摔落](摔落.md)，不能防止[末影珍珠](末影珍珠.md)引发的摔落伤害。
* 带有缓降效果的[玩家](玩家.md)在疾跑时跳跃，可以一次跳过约6个方块之远；而正常情况下玩家在疾跑时跳跃只能一次跳过4个方块。
* 若带有缓降效果的玩家使用[鞘翅](鞘翅.md)滑翔，未进行烟花火箭推进时，滑翔距离会是正常情况下的2倍，但滑翔速度只有原来的。烟花火箭推进会以正常速度给予加成，但加速效果的持续时间会变短一些。
