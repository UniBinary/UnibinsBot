* *世界预设标签（World Preset Tags）**是[世界预设](世界预设.md)的组合。

# 使用

世界预设标签不可被主动调用，它们被游戏用来控制[创建世界屏幕](创建新的世界.md)上可供选择的世界预设。

# 当前版本
# = extended =
* 按住键时，在“”按钮中展示的世界预设。

# = normal =
* 默认情况下，在“”按钮中展示的世界预设。
