# 命令/op

*页面ID: 39794* | *来源: Minecraft Wiki*

}}

给予玩家管理员身份。

此命令会将玩家添加进<samp>ops.json</samp>文件，权限等级设为[server.properties](server.properties.md)中<code>op-permission-level</code>所设置的权限等级。

此命令将玩家在“玩家权限”屏幕中的权限改为“操作员”。在[专用服务器](BDS.md)中，玩家还会被记录在<samp>permissions.json</samp>文件里。<samp>permissions.json</samp>文件可以由命令重新加载。

# 语法
* **Java版**
  <code>/op <targets></code>
* **基岩版**
  <code>/op <player: target></code>

# 参数

   指定要被授予管理员权限的玩家。
