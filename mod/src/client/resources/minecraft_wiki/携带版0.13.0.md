# 携带版0.13.0

*页面ID: 18919* | *来源: Minecraft Wiki*

* *v0.13.0 alpha**是携带版的一次主要更新，发布于2015年11月19日。此次更新加入了新的红石物品、新的兔子种类以及沙漠神殿，并修复了大量漏洞。

# 新内容
# = 方块 =
* *[红石灯](红石灯.md)**
* 激活后发出等级为15的光照。

* *[红石火把](红石火把.md)**
* 新的红石元件。
* 用于激活或关闭红石电路。

* *[拉杆](拉杆.md)**
* 新的红石元件。
* 用于激活或关闭红石电路。

* *[绊线钩](绊线钩.md)和[绊线](绊线.md)**
* 新的红石元件。
* 相互连接会构成红石开关。

* *[阳光探测器](阳光探测器.md)**
* 用于侦测光照等级，并输出相对应的红石信号强度。

* *[压力板](压力板.md)**
* 加入了木质和石质压力板。

* *[测重压力板](测重压力板.md)**
* 加入了轻质和重质测重压力板。

* *[按钮](按钮.md)**
* 加入了木质和石质按钮。

* *[探测铁轨](探测铁轨.md)**
* 矿车处于其上方会发出红石信号。

* *[激活铁轨](激活铁轨.md)**
* 矿车处于其上方会导致乘客下车。

* *[陷阱箱](陷阱箱.md)**
* 打开后会发出红石信号。
* 纹理和箱子基本相同，但锁的周围有一圈红色的纹理。

* *[门](门.md)**
* 加入了云杉、白桦、丛林、金合欢和深色橡木木门。

* *[铁活板门](铁活板门.md)**
* 和木质活板门功能相同，但只能被红石信号开关。

* *[音符盒](音符盒.md)**
* 会根据其底下的方块类型发出不同的音色。
* 点击可以调音，使用红石激活会发出不变的音调。

# = 物品 =
* *[兔子皮](兔子皮.md)**
* 由[兔子](兔子.md)掉落。
* 可用于合成[皮革](皮革.md)。

* *[食物](食物.md)**
* [生兔肉](生兔肉.md)
* [熟兔肉](熟兔肉.md)
* [兔肉煲](兔肉煲.md)

# = 生物 =
* *[兔子](兔子.md)**
* 新的被动型生物。
* 会远离玩家。
* 可使用胡萝卜进行[繁殖](繁殖.md)。
* 会破坏庄稼。

# = 世界生成 =
* *[沙漠神殿](沙漠神殿.md)**
* 自然生成于[沙漠](沙漠.md)生物群系里。
* 包含了4个宝藏箱，以及由9个[TNT](TNT.md)和1个石质[压力板](压力板.md)组成的陷阱。

# = 游戏内容 =
* *[高度](高度.md)**
* 若尝试在128格以上继续放置方块现在会出现客户端警告。

* *[粒子](粒子.md)**
* <code>happyVillager</code>
* <code>note</code>

# = 常规 =
* *选项**
* 加入了禁用多人游戏的选项。

* *[皮肤包](皮肤.md)**
* 加入了Biome Settlers皮肤包。

# 更改
# = 方块 =
* *[花](花.md)**
* [骨粉](骨粉.md)生成的花现在与生物群系有关。

* *[黑曜石](黑曜石.md)**
* 破坏时间从3秒更改为6.5秒。

* *[切石机](切石机（MATTIS）.md)**
* 移除了它本身合成配方，原有合成配方由[工作台](工作台.md)继承。
* [生存模式](生存模式.md)中不再可用，仅在[创造模式](创造模式.md)中作为装饰方块。

* *[铁门](铁门.md)**
* 加入了实际功能。
* 可在生存模式中合成。
* 修复了纹理。

* *[橡木门](橡木门.md)**
* 更新了纹理。

* *[线](线.md)**
* 现在可放置。

* *[动力铁轨](动力铁轨.md)**
* 现在需要被红石信号充能。

# = 物品 =
* *[红石粉](红石粉.md)**
* 现在可放置。

* *植物**
* 对其使用[骨粉](骨粉.md)时产生粒子效果。

* *[甜菜根](甜菜根.md)**
* 现在可堆叠至64个。

# = 生物 =
* *[恶魂](恶魂.md)**
* 增加了生成概率。

* *[史莱姆](史莱姆.md)**
* 增加了生成概率。

* *[骷髅](骷髅.md)**
* 现在尝试远离[狼](狼.md)。

* *[村民](村民.md)**
* 会跟着玩家或者停下来。

* *[狼](狼.md)**
* 现在会主动攻击[绵羊](绵羊.md)与[兔子](兔子.md)。

# = 非生物[实体](实体.md) =
* *[船](船.md)**
* 速度与疾跑持平。
* 不再影响[饥饿](饥饿.md)。
* 多个船堆叠会堆高，互相挤压时可以重叠。

* *[矿车](矿车.md)**
* 多个矿车堆叠会堆高。

# = 常规 =
* *[设置](设置.md)**
* 对局域网开放选项不能再在游戏中更改。

* *图像**
* [光照](光照.md)在[下界](下界.md)中也会产生了。

* *[物品栏](物品栏.md)**
* 快捷栏上的物品数量被改为在物品下显示，并与Java版有了相同的字体。

* *杂项**
* 移除了无用的<code>Coral</code>（珊瑚）素材<ref>https://www.reddit.com/r/Minecraft/comments/3n8vta/tommaso_checchi_on_twitter_i_just_removed_coral/cvm3hxc</ref>
* 游戏数据现在以json文件表达（详见[此处](https://gist.github.com/Tomcc/c2a3f6b77e9742779920)的示例）<ref></ref>

# 修复
* *修复了55个漏洞**
*  – 创造模式下仍然会发出玩家溺水的气泡粒子。
*  – 生物会被困在栅栏/栅栏门/墙里。
*  – 玩家在破坏后面没有紧靠方块的方块时，挖掘进度暂停。
*  – 实体和透明方块无法透过云层看见。
*  – 生成新地形时，云层不可见。
*  – 怪物不会攻击藏在两格高的植物里的玩家。
*  – 大量亮度更新使得区块出现许多黑洞。
*  – 进入世界时，玩家会在地面上方悬空生成。
*  – 玩家收回钓鱼竿时，钓鱼按钮会使得已驯服生物站立或坐下。
*  – iOS 6下无法自定义皮肤。
*  – 被水冲掉的火把会直接消失。
*  – 深色橡木方块变种翻译错误。
*  – 对着地面点击鼠标中键不会获得对应方块。
*  – 合成原材料缺失后，自动合成不会停止。
*  – 无法合成附魔台和圆石台阶。
*  – 支撑可可果的方块在被破坏时不显示粒子。
*  – 无法使用喷溅型水瓶灭火。
*  – 在服务器里输入聊天文本没有反馈。
*  – 手持草方块时，草方块的纹理错误。
*  – 放置和破坏铁砧的音效不正确。
*  – 骷髅不会惧怕狼。
*  – 狼不会主动攻击羊。
*  – 攀爬楼梯时，音效播放不正确。
*  – 启动游戏时画面冻结。
*  – 按下交互按钮时，仍会伤害实体。
*  – 刷怪笼能将蜘蛛生成在方块里。
*  – 玩家会主动在楼梯上跳跃。
*  – 下界疣方块有时候无法破坏。
*  – 重命名已经附魔的物品会丢失魔咒。
*  – 下界传送门的音效播放不正确。
*  – 玩家在大于128格高度的地方设置重生点会发送错误的客户端信息。
*  – 繁殖染色的羊不会给予后代正确的颜色。
*  – 进入水中后会显示多余的气泡颗粒。
*  – 本地多人游戏下，其他玩家无法看见划船动画。
*  – 下界里出现地形错误。
*  – 万圣节皮肤的繁体中文翻译错误。
*  – 箱子物品栏内没有显示工具提示。
*  – 在打开箱子后，仍然可以打开其他方块的UI。
*  – 使用键鼠操作时，站在下界传送门的玩家在打开箱子后无法移动。
*  – 多人游戏时，烧炼不会给予玩家经验。
*  – 合成界面的物品不会在槽位里居中显示。
*  – 使用熔炉烧炼多个物品时，字体大小显示错误。
*  – 染色的羊不会给予后代正确的颜色。
*  – 村民的模型渲染不正确。
*  – 在创造模式下乘坐矿车会使得玩家破坏临近的方块。
*  – 玩家在重启手机后，游戏的设置选项会重置。
*  – 本地多人游戏下，天气系统无法正常运作。
*  – 告示牌不会阻止流动的水蔓延。
*  – 通过绊线激活的红石信号不会使得动力铁轨激活。
*  – 在Lumia 950 (10586)设备上按下开始游玩键导致游戏崩溃。
*  – 红石块上方或下方的红石粉不会发出红石信号。
*  – 无法编辑IP地址和端口。
*  – “圆石真多”成就无法完成。
*  – 无法通过击打火焰来灭火。
*  – 德语的按钮翻译错误。
