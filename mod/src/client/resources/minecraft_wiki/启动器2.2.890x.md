# 启动器2.2.890x

*页面ID: 92299* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.2.8908**（）、**2.2.8907**（，版）、**2.2.8909**（）或**2.2.8906**（）是一次[启动器](启动器.md)更新，发布于2022年1月18日。

# 更改
* 更改了“配置”选项卡中复选框的行为。
* 更改了Mojang账户已迁入微软账户时退出登录的流程。

# 修复
*  - 启动游戏时出现错误提示，同时部分版本出现缺失。
*  - 启动启动器时出现灰屏。
*  - 设为某些语言的启动器无法启动。
*  - 皮肤预览不显示透明像素。
*  - MacOS版本的启动器在启动时出现崩溃。
*  - 有有效的Xbox Game Pass订阅时，会出现演示模式。
*  - 不能更改游戏版本。
*  - 卸载的警告信息复用了的。</onlyinclude>
