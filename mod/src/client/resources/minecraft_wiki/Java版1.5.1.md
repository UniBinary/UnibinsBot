# Java版1.5.1

*页面ID: 31627* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.5.1**是的一次次要更新，发布于2013年3月21日<ref name="blogpost_1.5.1"></ref>，修复了特定设备上的帧率下降漏洞。虽然它不是1.5的最终版本，却是[1.6.1](Java版1.6.1.md)首个快照发布前的最后一个正式版。此版本兼容1.5的服务端。

# 更改
# = 方块 =
* *[漏斗](漏斗.md)**
* [熔炉](熔炉.md)燃料槽现在会返还[空桶](空桶.md)。

# = 物品 =
* *[附魔书](附魔书.md)**
* 可以被合并以提升[附魔](附魔.md)等级，或者在同一本上合并多个[魔咒](魔咒.md)。
* * 当合并提高等级时，两本书的等级必须相同。
* * 仍然需要遵守常规附魔等级限制。

# = 生物 =
* *[末影龙](末影龙.md)**
* [游戏规则](游戏规则.md)<code>mobGriefing</code>设为<code>false</code>时不再会破坏方块。

# = 常规 =
* *性能**
* 帧率提升，恢复到1.4的水平。

* *[Minecraft Realms](Minecraft Realms.md)**
* 进行了优化和改进。
