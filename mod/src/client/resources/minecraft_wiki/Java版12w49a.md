# Java版12w49a

*页面ID: 33299* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w49a**是[Java版1.4.6](Java版1.4.6.md)的首个快照，发布于2012年12月7日<ref></ref>。

# 新内容
# = 方块 =
* *[下界砖台阶](下界砖台阶.md)**
* 使用3个[](下界砖块.md)合成。
* 提议来自[MINECON 2012](MINECON 2012.md)。<ref></ref>

# = 物品 =
* *[附魔书](附魔书.md)**
* 用于附魔物品。
* * 在此版本中由于漏洞可以使用铁砧给任意物品附上魔咒。

* *[烟火之星](烟火之星.md)**
* 用于合成烟花火箭。

* *[烟花火箭](烟花火箭.md)**
* 新的可发射弹射物。
* 可通过合成来自定义效果。

# 更改
# = 方块 =
* *常规**
* 玩家处于潜行状态时，能够将诸如红石粉、中继器等物品直接放置在会对右键点击产生反应的方块，如工作台、熔炉与发射器上。

# = 生物 =
* *[恶魂](恶魂.md)**
* 火球的爆炸半径可以用编辑器来自定义。

# = 物品 =
* *[下界之星](下界之星.md)**
* 现在不再会被[爆炸](爆炸.md)所摧毁。
