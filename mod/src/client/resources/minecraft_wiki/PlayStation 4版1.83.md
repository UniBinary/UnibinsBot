# PlayStation 4版1.83

*页面ID: 60982* | *来源: Minecraft Wiki*

* *1.83**是[PlayStation 4版](PlayStation 4版.md)的一次更新，发布于2018年12月18日，加入了许多[村庄与掠夺](村庄与掠夺.md)的特性。此次更新等价于[基岩版1.8.0](基岩版1.8.0.md)。

# 新内容
# = 常规 =
* *混搭包**
* 加入了“The Nightmare before Christmas”。
* *奖杯**
* 加入了扩展包8，其中包含6个新奖杯：
* * （银杯）做一个桶滚动作——使用激流给自己加速。
* * （铜杯）海洋生物学家——用一个桶收集一条鱼。
* * （银杯）啊嘿！——找到一处沉船。
* * （铜杯）世界之巅——放置脚手架直到世界的极限。
* * （铜杯）你去哪了？——早晨收到一只被驯服的猫送的礼物。
* * （金杯）动物学家——用竹子喂养两只熊猫。

# = 生物 =
* *[熊猫](熊猫.md)**
* 生成在[丛林](丛林.md)里。
* 食用[竹子](竹子.md)与[蛋糕](蛋糕.md)。
* 有不同的性格——懒惰、顽皮、好斗或发愁。
* 拥有棕色变种

* *[流浪猫](流浪猫.md)**
* 从[豹猫](豹猫.md)加入猫作为单独的生物。
* 生成于村庄。
* 可以用鱼驯服。
* 有可染的项圈，类似于被驯服的[狼](狼.md)。
* 给玩家带来礼物。
* 会吓跑幻翼。

# = 方块 =
* *[竹子](竹子.md)**
* 可用于制作脚手架或喂养熊猫。
* 可以在丛林中[钓鱼](钓鱼.md)获得，并将出现在一些[箱子](箱子.md)。
* 自然生成将在以后更新。
* *[脚手架](脚手架.md)**
* 一种新的可攀爬的方块，可以用竹子来[合成](合成.md)。

# = 物品 =
* *[染料](染料.md)**
* 加入了[白色染料](白色染料.md)、[蓝色染料](蓝色染料.md)、[棕色染料](棕色染料.md)与[黑色染料](黑色染料.md)。
* 以前用作染料的物品（[骨粉](骨粉.md)、[青金石](青金石.md)、[可可豆](可可豆.md)与[墨囊](墨囊.md)）仍然可以使用。

* *[刷怪蛋](刷怪蛋.md)**
* [熊猫](熊猫.md)
* [猫](猫.md)

# 更改
# = 生物 =
* *[豹猫](豹猫.md)**
* 不再变成猫，但仍然可以通过喂鱼获得信任。

# = 物品 =
* *[仙人掌绿](仙人掌绿.md)**
* 重命名为绿色染料。
* *[蒲公英黄](蒲公英黄.md)**
* 重命名为黄色染料。
* *[玫瑰红](玫瑰红.md)**
* 重命名为红色染料。

# = 常规 =
* *游戏聊天**
* 移除了游戏聊天和它的声音设置选项。如果玩家要进行语音聊天，现在必须使用控制台的群聊。

# 修复
* *修复了3个漏洞**
* 修复了在雪地生物群系附近可能发生的崩溃。
* 修复了在教程等级中的屏障方块。
* 修复了当TNT炸毁栅栏与潜影盒时可能发生的崩溃。
