* *马铃薯果实（Potato Fruit）**是可以在[马铃薯树](马铃薯树.md)上自然生成的[食物](食物.md)类[方块](方块.md)。

# 生成
# = 自然生成 =
马铃薯果实会有概率作为马铃薯树的一部分生成，也会在[马铃薯村庄](马铃薯村庄.md)中[成堆生成](方块堆.md)、作为灯柱等结构的一部分生成。

# 获取
# = 箱子战利品 =

# 破坏
挖掘马铃薯果实的合适工具是剑。

马铃薯果实被破坏后会掉落自身。

# 用途
# = 食物 =

手持马铃薯果实按住键即可食用，每个马铃薯果实可以回复，并提供2秒的效果（减少）。

对准方块马铃薯果实会优先放置而不是食用。

# = 堆肥 =
将马铃薯果实放入[堆肥桶](堆肥桶.md)中有30%的概率增加一层堆肥层。
