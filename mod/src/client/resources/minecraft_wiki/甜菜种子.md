# 甜菜种子

*页面ID: 11417* | *来源: Minecraft Wiki*

* *甜菜种子（Beetroot Seeds）**是可以种出[甜菜根](甜菜根.md)的物品。

* *甜菜根（Beetroots）**是甜菜种子种植在[耕地](耕地.md)上形成的方块。

# 生成
# = 自然生成 =
甜菜根会自然生成在[平原](平原.md)和[沙漠](沙漠.md)类型的[村庄](村庄.md)里[农田](农田.md)结构的[耕地](耕地.md)上。

根据村庄所处生物群系不同，每块耕地上生成甜菜根作物的概率如下。

# 破坏

甜菜根被挖掘时会立刻被破坏。

生长阶段没有达到第4阶段的甜菜根被破坏后会掉落1个甜菜种子。

生长阶段达到第4阶段的甜菜根被破坏后会掉落或个[甜菜根](甜菜根.md)，然后系统会尝试进行3次掉落，每次有约）|JE|short=1}}或）|BE|short=1}}的概率掉落1份甜菜种子，挖掘工具的[时运](时运.md)魔咒每增加1级，尝试次数增加1。还会额外掉落1份甜菜种子。

# 用途
# = 种植 =

对[耕地](耕地.md)的顶面甜菜种子即可种植出甜菜根。甜菜根会经历4个生长阶段。[亮度](亮度.md)等级≥9时，甜菜根才能生长到下一个阶段；亮度等级≤7时无法对耕地甜菜种子，已种植的甜菜根也会在接收到[方块更新](方块更新.md)时掉落为[物品实体](物品实体.md)。

甜菜根在湿润的耕地上生长得更快。对甜菜根[骨粉](骨粉.md)有75%的概率会使其增加1个生长阶段，忽视亮度等级。已有巢且采集了花粉的[蜜蜂](蜜蜂.md)飞过甜菜根时，甜菜根也有概率增加1个生长阶段。

甜菜根植株的四周都为甜菜根植株且都种植在湿润的耕地上会比单独种植在湿润的耕地的甜菜根植株生长速度快约16.7%；而按一排间种甜菜根植株，中间没有作物或为其他作物会比单独种植在湿润的耕地的甜菜根植株生长速度快133%。

甜菜根每生长刻有的概率不会生长，但由于生长阶段比其他作物更少，所以甜菜根的生长速度仍比其他作物稍快。然而催熟甜菜根平均需要使用4份骨粉，其他作物平均只需要份。

# = 繁殖 =

与其他种子相同，甜菜种子可用于吸引及繁殖[鸡](鸡.md)，也可喂食给幼年鸡以减少其10%的剩余生长时间。

# = 驯服 =
与其他种子相同，甜菜种子可用于驯服[鹦鹉](鹦鹉.md)。

# = 堆肥 =
将甜菜种子投入[堆肥桶](堆肥桶.md)后有30%的概率使其增加一层堆肥层。
