# Java版11w50a

*页面ID: 31763* | *来源: Minecraft Wiki*

<onlyinclude>

* *11w50a**<ref group="注">在游戏内被误写为**11w49a**。</ref>是[Java版1.1](Java版1.1.md)的第4个快照，发布于2011年12月15日<ref></ref>，加入了新的[闪烁标语](闪烁标语.md)。

# 新内容

* * -{你好中国}-！
* * Γεια σου Ελλάδα!

# 更改
# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* 除了*11*，其他的音乐唱片现在均可通过让[骷髅](骷髅.md)射杀[苦力怕](苦力怕.md)的方式获得，且掉落的概率相同。

# = 生物 =
* *[绵羊](绵羊.md)**
* 幼年绵羊吃草变得更加频繁。

# = 常规 =
* *调试功能**
* 按下不再能更改游戏模式。</onlyinclude>
