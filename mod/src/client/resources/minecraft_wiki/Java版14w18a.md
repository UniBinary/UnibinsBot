# Java版14w18a

*页面ID: 33969* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w18a**是[Java版1.8](Java版1.8.md)的第20个快照，发布于2014年4月30日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[火把](火把.md)**
* 可以放置在[染色玻璃](染色玻璃.md)上。

* *[活塞](活塞.md)和[黏液块](黏液块.md)**
* 与黏性活塞连接的黏液块会推拉附近的方块。
* * 连接到普通的活塞时则只能推动。
* * 代码由[KaboPC](https://www.youtube.com/user/KaboPC)和[Panda4994](https://www.youtube.com/user/Panda4994)<ref>https://www.youtube.com/watch?v=jpXBKXJlybg</ref><ref></ref>贡献。
* * 无论组合方式如何，最多可以有12块连接到活塞的黏液块被移动。此外还有以下条件：没有方块打断连接，无法移动的方块不在途中阻碍或黏液块没有连接到黏液块。
* * 必须遵守活塞所遵守的规则，通常可以被活塞推动的方块就可以被附着的黏液块推动。
* * 会带来更多的机械，如红石时钟、移动机械、农场等。
* 推动上方有黏液块的活塞会将其上的实体弹入空中。<ref></ref>
