# 战斗更新

*页面ID: 17372* | *来源: Minecraft Wiki*

[缩略图|300px|Mojang发布的战斗更新图片](File:Combat Update Artwork.png.md)
* *战斗更新（Combat Update）**是[Java版](Java版.md)的一次主要更新，发布于2016年2月29日。<ref></ref>此次更新的官方名称<ref></ref>是在2015年4月1日被Reddit用户[3dDeters](http://www.reddit.com/user/3dDeters)在愚人节快照[15w14a](15w14a.md)中隐藏的二维码中发现的。此次更新大幅度修改了战斗系统，也进行了其他的一些更改。

开发团队声称在2015年10月末完成了特性添加，并开始了一段漫长的游戏平衡性调整和漏洞修复<ref></ref>。他们不久宣布1.9不会在2015年发布，因为他们“想在发布前修复更多漏洞，并在节日时使游戏保持稳定”。<ref></ref>

此次更新的开发始于[15w31a](15w31a.md)，其发布于2015年7月29日。

# 重要特性

# = 新内容 =
* 复活[末影龙](末影龙.md)的方法
* 末地外部岛屿无限生成，其中有[紫颂植株](紫颂植株.md)、[末地城](末地城.md)、末地船以及[潜影贝](潜影贝.md)生物
* [双持](双持.md)
* 攻击力度机制
* [属性](属性.md)系统
* [盾牌](盾牌.md)、[光灵箭](光灵箭.md)、14种[药箭](药箭.md)和每种药水的[滞留药水](滞留药水.md)
* 用于滑翔的[鞘翅](鞘翅.md)
* [字幕](字幕.md)
* 副手槽和主手槽
* 生成在寒冷生物群系的[雪屋](雪屋.md)结构
* 雷暴时生成的骷髅陷阱马
* 13种新方块：[草径](草径.md)、[霜冰](霜冰.md)、2种[命令方块](命令方块.md)、[紫颂花](紫颂花.md)和[植物](紫颂植株.md)、[末地折跃门方块](末地折跃门方块.md)、[末地烛](末地烛.md)、[末地石砖](末地石砖.md)、[紫珀块](紫珀块.md)、[紫珀柱](紫珀柱.md)、台阶和楼梯
* 新物品：[甜菜根](甜菜根.md)以及相关物品[甜菜种子](甜菜种子.md)与[甜菜汤](甜菜汤.md)、[末地水晶](末地水晶.md)、普通[紫颂果](紫颂果.md)和[爆裂紫颂果](爆裂紫颂果.md)、[幸运药水](幸运药水.md)和[龙息](龙息.md)
* 5个新闪烁标语
* 4种新[粒子](粒子.md)：
* * <code>sweepAttack</code>、<code>dragonBreath</code>、<code>endRod</code>和<code>damageIndicator</code>
* 4种新状态效果：
* * [飘浮](飘浮.md)、[发光](发光.md)、[幸运](幸运.md)和[霉运](霉运.md)
* 2个新魔咒：
* * 冰霜行者和经验修补
* 5个新统计：
* * <code>sleepInBed</code>、<code>sneakTime</code>、<code>pickup</code>、<code>drop</code>和<code>aviateOneCm</code>
* 新的NBT标签
* 3个新[游戏规则](游戏规则.md)
* * <code>disableElytraMovementCheck</code>、<code>spectatorsGenerateChunks</code>和<code>spawnRadius</code>
* 150多个新声音事件
* 支持中文、日文、韩文和可能其他以IME输入的语言

# = 更改 =
* 更改了末地岛黑曜石柱的布局和[末影龙](末影龙.md)的战斗机制
* 增强了骷髅的AI
* 移除了剑的格挡，加入了一些其他武器的技术
* 重新平衡了工具伤害
* 削弱了锋利和保护魔咒
* 状态效果图标在主屏幕可见
* 重新平衡了生命回复
* 重新平衡了钓鱼机制
* 酿造台现在需要烈焰粉
* 附魔金苹果不再能合成
* 更改了地图
* 重新平衡了在世界生成的箱子里的战利品
* 极限模式死亡后允许玩家以旁观模式继续
* 改进了船
* 要塞生成增加至最多128个
* 大橡树可以再次在树林生成
* 增加了下雨时[火](火.md)的蔓延速度
* 玻璃板和铁栏杆未连接时的模型更细了，而不是之前的十字形模型
* 生物和玩家现在可以互相推动
* 死亡消息现在可显示在死亡屏幕上
* 小幅修改了生物和玩家的高度
* 资源包可以基于数据值，物品状态和持有的手定义模型
* 结构现在从<code>/assets/structures</code>中读取
* 生物、钓鱼和箱子中的战利品现在由[战利品表](战利品表.md)定义

# 性能与优化
* 粒子不再是实体
* 方块刻以游戏刻为基础
* 生物寻路采用更节省CPU的方案
* 减少了连接到服务器时的内存用量

# 跟进版本
* [Java版1.9.1](Java版1.9.1.md)加入了[鞘翅](鞘翅.md)的声音效果、<code>generic.armorToughness</code>数据，并使十字准星攻击指示器默认显示，还有一些小的更改和漏洞修复。
* [Java版1.9.2](Java版1.9.2.md)紧随其后，以修复[Java版1.9.1](Java版1.9.1.md)中，在Realms服务器中坐船和坐矿车时的崩溃问题。
* [Java版1.9.3](Java版1.9.3.md)中修复了一些稳定性问题。添加了命令，还将不符合[EULA](EULA.md)的服务器拉进了黑名单。
* [Java版1.9.4](Java版1.9.4.md)也紧随其后，以修复错误的Realms警告。
