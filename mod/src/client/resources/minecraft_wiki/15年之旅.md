* *15年之旅（15 Year Journey）**是[15周年庆](15周年庆.md)发布于[市场](市场.md)的官方地图，由Oreville Studios制作。主题为一个巨型博物馆。

# 区域
15年之旅由七个主要区域构成。

# = 大厅 =
大厅是连接所有区域的中央区域，有1张贴纸。

# = 水族馆 =
该区域有12张贴纸。

# = 洞穴与山崖 =
该区域有11张贴纸。

# = Alpha =
该区域大量致敬了[Java版Classic](Java版Classic.md)，包含两层楼及八个展览，有4张贴纸。

# = 嗡嗡蜂群 =
该区域为一大型温室，其中包含许多的蜜蜂与村民，有6张贴纸。

# = 维度 =
该区域具有一个中央房间，设有Steve和Alex跟末影龙及凋灵间的战斗雕像，一旁则有分别通向下界与末地空间的门扉，内各有一个小游戏。

该区域有6张贴纸。

# = 探险 =
该区域有13张贴纸。
