# 雪

*页面ID: 475* | *来源: Minecraft Wiki*

* *雪（Snow）**是常见的由降雪天气产生的覆盖性方块。

# 生成
# = 自然生成 =
雪会自然生成于以下生物群系的地表：[雪原](雪原.md)、[积雪针叶林](积雪针叶林.md)、[积雪沙滩](积雪沙滩.md)、[冻洋](冻洋.md)、、[冻河](冻河.md)、[冰刺之地](冰刺之地.md)、[雪林](雪林.md)、[积雪山坡](积雪山坡.md)、[尖峭山峰](尖峭山峰.md)、[冰封山峰](冰封山峰.md)。雪也会在[风袭丘陵](风袭丘陵.md)、[风袭森林](风袭森林.md)和[风袭沙砾丘陵](风袭沙砾丘陵.md)中Y坐标大于等于113的区域生成。

雪只会以单层生成，而会以多层生成。

雪会自然生成在直接暴露于天空下的积雪针叶林[村庄](村庄.md)建筑物上。

多层雪可以作为雪原村庄许多建筑物的一部分生成。单层雪会以[雪堆](雪堆.md)的形式生成于雪原村庄中。

雪还会自然生成在[远古城市](远古城市.md)的冰窖中。

# = 降雪 =
在有雪的[生物群系](生物群系.md)或在较冷生物群系雪线高度以上的地方会随机降雪，而不是降雨。当下雪时，雪会随机在方块光照等级小于等于9的有完整上表面的方块上生成（冰和浮冰除外）。每个游戏刻，一个水平位置上的最高方块尝试降雪的概率是，其中*n*为[游戏规则](游戏规则.md)的值。在默认随机刻速度下，一个水平位置每游戏刻有的概率尝试降雪。

在降雪时可以自然生成多层雪；降雪默认只会形成一层积雪。

积雪最大层数可以通过游戏规则来调整。当将游戏规则设为时不会产生雪。

# = 雪傀儡 =

在能够降雪、寒冷或中性温度的一些[生物群系](生物群系.md)中，雪傀儡走过的地方会留下一层雪；而雪傀儡在任何非干燥生物群系中都会如此。

# 破坏
挖掘雪的合适工具是锹。雪需要木锹或品质更好的锹来挖掘，否则挖掘时间将延长且不会掉落。

被具有[精准采集](精准采集.md)的锹挖掘破坏时，雪会掉落自身，掉落的数量与其层数相同，8层的雪被破坏后会掉落1个[雪块](雪块.md)<ref></ref>；被没有精准采集的锹挖掘破坏时，雪每有1层就掉落1个雪球；1~3层掉落1个雪球，4~5层掉落2个雪球，6~7层掉落3个雪球，8层掉落4个雪球。

# 用途
[300px|thumb|right|激活的[[红石灯](File:Redstone Lamp melt pattern.png.md)融化了附近的雪]]
雪只能被放置在固体方块上，雪会随着其下方方块的破坏而破坏。玩家可以跳上一个方块加上3层雪的位置。

除了最顶层的雪没有高度外，其余每层雪有0.125的高度，特别地，当下方为8层雪、上方为1层雪构成的“9层雪”时，其上两层雪都没有高度。

对于物品实体和弹射物实体，每层雪都有0.125的高度。

若使用的物品是雪，对着层数少于8的雪的侧面按下键时，将会增加这个位置雪的高度。而这将使雪放在临近的方块上。

# = 下落的方块 =

雪在下方没有不可替代的方块时会变为[下落的方块](下落的方块.md)。

# = 覆盖 =

如果雪覆盖在[草方块](草方块.md)、<ref></ref>上面，则这些方块的植被层（整个上表面及侧面的上边）会变成白色。雪不能覆盖在耕地上，也因此不会破坏它们。像[沙子](沙子.md)和[沙砾](沙砾.md)这样受重力影响的方块不会在其下方的方块被雪覆盖时掉落，但它们如果掉落在雪上，则会被破坏。<ref></ref><ref></ref>

当层数少于3的雪覆盖在[岩浆块](岩浆块.md)上时，走到上面的实体会受到岩浆块造成的伤害。

当雪覆盖在[绯红菌岩](绯红菌岩.md)或[诡异菌岩](诡异菌岩.md)上时，菌岩会退化为[下界岩](下界岩.md)。<ref></ref>

如果[树叶](树叶.md)上覆有雪，就会出现雪花从树叶间隙中滑落的[粒子](粒子.md)效果。

雪可以与一格高的非固体方块植物存在于同一方块内（但两格高的植物不可以）<ref></ref>，使植物[含雪](含雪.md)，且此时雪仍可以正常采集与堆层。在已有的植物方块上放置雪会让植物看起来长在雪中，但向有雪的方块放置植物则会移除雪。<ref></ref>

# = 融化 =
附近有或者方块亮度不低于12都会导致积雪融化。无论亮度如何，雪都会在干燥的生物群系融化。

除8层雪不会融化外，其他层数的雪会在收到[随机刻](随机刻.md)时若方块亮度不低于12则全部融化。任何层数的雪在收到随机刻时会逐层融化。

雪融化时不生成液相，而是直接消失并转化为[空气](空气.md)。

# = 狐狸 =
如果[狐狸](狐狸.md)扑向猎物而扑空后落入雪中，它会短暂地陷入雪中，并会产生雪的粒子。

# 你知道吗
* 在[仙人掌](仙人掌.md)前面用雪堆叠成一个完整的方块，仙人掌不会被破坏。
* 当雪在[灵魂沙](灵魂沙.md)上面时灵魂沙会变得和普通方块一样。
* 八层雪等同于一个雪块。
* 下落的雪作为实体可以被[火](火.md)和[熔岩](熔岩.md)点燃。
