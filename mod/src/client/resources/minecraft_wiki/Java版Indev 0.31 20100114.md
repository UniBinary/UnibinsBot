# Java版Indev 0.31 20100114

*页面ID: 35320* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2010年1月14日，加入了[无限水源](无限水源.md)，并修复了一个漏洞。<ref></ref><ref>[Minecraft Indev](https://www.youtube.com/watch?v=A6-bszYJEOc) - Youtube</ref>

# 新内容
# = 方块 =
* *[无限水源](无限水源.md)**
* 放置时会产生无限的[水](水.md)，这些水流动速度快，且不会蒸发。
* [玩家](玩家.md)出生时会携带99个。

# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 拾取已具有完整一组的物品会在[物品栏](物品栏.md)中单个堆积。<ref name="Forum"></ref>
* * 如果继续捡起更多物品会导致它们进入到盔甲槽中。<ref name="Forum1"></ref>

# 修复
* *修复了1个漏洞**
* 现在水流动得更快了。</onlyinclude>
