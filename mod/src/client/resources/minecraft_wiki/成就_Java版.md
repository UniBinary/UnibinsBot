# 成就/Java版

*页面ID: 60175* | *来源: Minecraft Wiki*

* *成就（Achievements）**是[Java版](Java版.md)中已移除的挑战系统，由[进度](进度.md)取代。

# 描述

成就系统的界面呈树状结构。要获得部分成就必须获得其前提成就。<!--起初，成就树显示在界面左侧，右侧显示一个成就树的缩略图。小图从最终版中去除了，仅仅显示成就树。【作为历史内容应当移至历史栏目 ，但变更时间没有确定，故暂时注释保留】-->成就树的背景样式类似游戏内的[世界生成](世界生成.md)模式（界面自顶部开始主要分层分布[泥土](泥土.md)、[石头](石头.md)、[基岩](基岩.md)，其中石头层有类似于游戏内的[矿石分布](矿石/旧矿物图表#洞穴与山崖前.md)）。玩家可按住、拖动鼠标与滚轮缩放查看成就树的详细分支。

在此界面中，玩家离达成一个成就的目标越近，显示的悬浮文本内容就越详细：
* 已获得的成就以“名称/描述/已得到！”的形式呈现（例如“//”）。
* 尚未获得、玩家已获得了全部前提成就的成就以“名称/描述”的形式呈现。
* 尚未获得、玩家与其相距一个或两个前提成就的成就以“名称/需要XX”的形式呈现（例如“/”）。
* 尚未获得、玩家与其相距三个前提成就的成就以“???/需要XX”的形式呈现（例如“???/”）。
* 尚未获得、玩家与其相距四个前提成就的成就不会呈现；只会显示一个图标，没有悬浮文本。
* 尚未获得、玩家与其相距四个前提成就以上的成就不会显示（包括图标）。

成就的获取以每个玩家及每个世界为基准：每个新的世界中的每个新玩家均可以在一棵独立的成就树中获取成就。

当玩家获得一项成就时，会在同一世界所有玩家的聊天框内显示“”字样和该成就的名称。

成就可以在任何[游戏模式](游戏模式.md)中获得，因此一些难以获得的成就可以轻松地在[创造模式](创造模式.md)中获得，比如****，****和****等。
* ****例外，因为该成就需要通过[恶魂火球](恶魂火球.md)击败恶魂获得，而恶魂不会在创造模式攻击玩家。

可以通过命令给予或移除成就。当使用此命令给予玩家一项成就时，其前置成就也会一并获取。

可以通过删除文件夹来重置所有成就，但这么做也会重置[统计](统计.md)数据。

# 你知道吗
* “获得成就！（Achievement Get!）”引自一个梗：早期日文版《[](wzh:超級瑪利歐陽光.md)》*（Super Mario Sunshine）*截图显示当获得阳光值时会显示“获得阳光！（Shine Get!）”。因为这些梗与截图引起的广泛关注，“获得XX！（[noun] Get!）”后来成为图片中流行的用语，Notch也经常浏览这些图片。
