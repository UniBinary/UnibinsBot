* *剧毒耕地（Poison Farmland）**是一种可以用来种植与生长[农作物](农作物.md)的[方块](方块.md)。

# 生成
# = 自然生成 =
剧毒耕地会自然生成于[马铃薯维度](马铃薯维度.md)的[田野](田野.md)生物群系和[马铃薯村庄](马铃薯村庄.md)中。

# = 锄 =
对着[马铃薯泥土](马铃薯泥土.md)、[薯皮草方块](薯皮草方块.md)或[腐败的薯皮草方块](腐败的薯皮草方块.md)[锄](锄.md)可将其犁成剧毒耕地。

# 获取
剧毒耕地不能在生存模式中正常获得，但可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)获得。

# 破坏
挖掘剧毒耕地的合适工具是锹。

剧毒耕地被破坏后会掉落1个[马铃薯泥土](马铃薯泥土.md)。

# 用途

剧毒耕地是游戏中一些[农作物](农作物.md)生长所必需的方块，这些农作物有[小麦植株](小麦植株.md)、[马铃薯](马铃薯.md)、[胡萝卜](胡萝卜.md)、[甜菜植株](甜菜植株.md)、[南瓜茎](南瓜茎.md)、[西瓜茎](西瓜茎.md)、[火把花植株](火把花植株.md)和[瓶子草植株](瓶子草植株.md)。

除此以外，一些植物也能种植在剧毒耕地上面，包括[树苗](树苗.md)、[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[蕨](蕨.md)、[大型蕨](大型蕨.md)、[花](花.md)、[甜浆果](甜浆果.md)、[大型垂滴叶](大型垂滴叶.md)、[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)。

[小型垂滴叶](小型垂滴叶.md)只有在至少1格深的[水源](水源.md)中才可种植在剧毒耕地上。

# = 湿润耕地 =
剧毒耕地方块在创造之初是干的。在下列条件都达成时剧毒耕地会变成湿润的：
# 周围水平方向4格之内必须存在[水](水.md)，包括对角线。
# 水必须和剧毒耕地等高或比剧毒耕地高一格。

在剧毒耕地和水之间的方块不会产生任何影响。

玩家的行为（在剧毒耕地上泼水等）、剧毒耕地所处生物群系（允许水方块存在的前提下）均不影响剧毒耕地湿润的概率。一个水源方块最多可以湿润以它为中心的9×9的耕地。

剧毒耕地也会被[雨](雨.md)湿润。

不同类型的[种子](种子.md)在湿润的剧毒耕地的生长要比在干的剧毒耕地的生长要快。湿润的剧毒耕地会用比一个[昼夜更替](昼夜更替.md)多一点点的时间收获一个完全成熟的[小麦植株](小麦植株.md)。

# = 退化 =
在一定的条件下，剧毒耕地在马铃薯维度中会变成马铃薯泥土，而在其他维度中则会变成泥土，无论它的湿润程度如何。下列任何条件达成时都会发生退化：
* 剧毒耕地方块干涸，而且很长时间内没有任何东西种植在上面。
* 玩家或部分生物在没有[缓降](缓降.md)效果的情况下跳到或掉到方块上。退化概率随摔落高度的增加而增加，如果摔落高度小于等于0.5格则不会退化，大于1.5格则必定退化。
* * 不会导致剧毒耕地退化的生物有[美西螈](美西螈.md)、[猫](猫.md)、[洞穴蜘蛛](洞穴蜘蛛.md)、[鸡](鸡.md)、[鳕鱼](鳕鱼.md)、[海豚](海豚.md)、[末影螨](末影螨.md)、[狐狸](狐狸.md)、[青蛙](青蛙.md)、[发光鱿鱼](发光鱿鱼.md)、小型[岩浆怪](岩浆怪.md)、[豹猫](豹猫.md)、[鹦鹉](鹦鹉.md)、[河豚](河豚.md)、[兔子](兔子.md)、[鲑鱼](鲑鱼.md)、[蠹虫](蠹虫.md)、小型[史莱姆](史莱姆.md)、[蝌蚪](蝌蚪.md)、[鱿鱼](鱿鱼.md)、[热带鱼](热带鱼.md)、[狼](狼.md)以及幼年生物。
* [活塞头](活塞头.md)推到剧毒耕地方块上方。
* [固体方块](固体方块.md)覆盖在剧毒耕地方块的上方，比如南瓜或西瓜在上方长出。输出信号时被[活塞](活塞.md)移动的[侦测器](侦测器.md)到位时不会使下面的剧毒耕地退化。
* [劫掠兽](劫掠兽.md)在剧毒耕地上行走时不会破坏耕地，但会破坏其上的农作物。

当剧毒耕地退化时，在其上的农作物会掉落为物品。
