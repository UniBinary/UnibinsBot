# Java版18w19b

*页面ID: 34718* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w19b**是[Java版1.13](Java版1.13.md)的第34个快照，发布于2018年5月9日<ref></ref>，加入了新的声音事件，以及重新加入了对[18w16a](18w16a.md)前世界的支持，并修复了一些漏洞。

# 更改
# = 常规 =
* *声音事件**
* 加入了<code>entity.husk.converted_to_zombie</code>。
* *其他**
* 现可重新进入18w16a前的世界，然而那些在18w16a中创建的世界仍然损坏。<ref></ref>

# 修复
子命令的命名不正确。
|127249|溺尸的盔甲不显示。
|128681|海豚不掉落经验。
|128700|流动水会在台阶上产生水源。
|;previous
|129221|在铁砧界面中放入带NBT的物品时，游戏崩溃。
|129232|包含字符串或数字的命令NBT比较总会失败。
|129233|玩家手持的带有额外NBT的物品不显示或上下“摆动”；损坏的工具部分不再工作。
|129246|鹦鹉模仿幻翼的声音是空的。
|129247|可编程控制器干扰。
|129282|带NBT的物品不能堆叠。
}}
* *其他修复**
* 在18w16a之前打开的世界现在可以再次打开，尽管在18w16a中创建的世界仍然会被清空。</onlyinclude>
