* *镐方块（Pickaxe Block）**是接受红石信号后会破坏其他方块的方块。

# 生成
镐方块不会生成在世界中。

# = 合成 =

# 破坏
挖掘镐方块的合适工具是镐。镐方块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

镐方块被破坏后会掉落自身。

# 用途

镐方块正面的纹理与[侦测器](侦测器.md)的信号输出端相同。

镐方块在接收到[红石信号](红石信号.md)时会延时后破坏其正面毗邻的方块，类似于的行为。镐方块能够破坏一切方块，包括[基岩](基岩.md)等通常不可破坏的方块。
