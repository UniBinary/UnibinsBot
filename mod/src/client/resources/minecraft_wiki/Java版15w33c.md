# Java版15w33c

*页面ID: 17341* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w33c**是[Java版1.9](Java版1.9.md)的第9个快照，发布于2015年8月14日<ref></ref>，加入了盾牌，并修复了[15w33a](15w33a.md)和[15w33b](15w33b.md)中的一些漏洞与崩溃问题。

# 新内容
# = 物品 =
* *[盾牌](盾牌.md)**
* 用来抵抗攻击的新[工具](工具.md)。
* * 受攻击时按住右键格挡能减少伤害且降低盾牌的耐久。
* ** 无论盾牌是在主手还是副手，都可以正常使用。
* *** 玩家可以一次拿着2个盾牌，但不会影响所受的伤害。
* 可以与[旗帜](旗帜.md)合并。
* * 这不会消耗旗帜。
* 格挡时无法。
* 合成：一列[羊毛](羊毛.md)（必须是相同颜色）、一列[木板](木板.md)（任何种类都可以）和一个在右中的[铁锭](铁锭.md)。
* 只能通过[铁砧](铁砧.md)修复。
* * 需要消耗[木板](木板.md)。
* 不能通过[附魔台](附魔台.md)附魔，但是可以通过[附魔书](附魔书.md)附魔。

# 更改
# = 方块 =
* *[酿造台](酿造台.md)**
* [喷溅药水](喷溅药水.md)可以放进较低的物品栏。

# = 物品 =
* *[剑](剑.md)**
* 格挡时不再能够使用。

* *[喷溅药水](喷溅药水.md)**
* 能放在酿造台里面了。

* *[火焰弹](火焰弹.md)**
* 用[发射器](发射器.md)发射出来的火焰弹会变成[末影龙](末影龙.md)火球，它的颜色是紫色的，并且在爆炸后会散发出龙息。
* * 在此之前，用发射器发射出来的火焰弹和[烈焰人](烈焰人.md)的火球一样。
* * 这在[15w44b](15w44b.md)被恢复，再次发射烈焰人火球。

# = 生物 =
* *[末影龙](末影龙.md)**
* 重生的[末影龙](末影龙.md)掉落500[经验](经验.md)。
* 重生末影龙将使[黑曜石](黑曜石.md)柱、[末地水晶](末地水晶.md)与[铁栏杆](铁栏杆.md)一起刷新出来。
* * 柱顶上会有爆炸[粒子](粒子.md)，因为它们是被重新建造的。
* * [末地折跃门](末地折跃门.md)原封不动。

* *[骷髅](骷髅.md)，[苦力怕](苦力怕.md)和[僵尸](僵尸.md)**
* 玩家带着头时对应生物的探测距离调整，为普通距离的37.5%

# = 非生物实体 =
* *[末地水晶](末地水晶.md)**
* 新的<code>BeamTarget</code>NBT标签。
* * 例子：{{cmd|summon EnderCrystal ~ ~1 ~ {BeamTarget:{X:1,Y:2,Z:3}<nowiki/>} }}

# = 世界生成 =
* *[末地船](末地船.md)**
* 不再和[南瓜](南瓜.md)一起生成。
* 位于中间的铁块被一个[漏斗](漏斗.md)代替。
* * 漏斗内一本[成书](成书.md)，作者为[Searge](Searge.md)，书名为“Work in progress（开发中）”，书的页数为1页，复制程度为原作。
* ** 书中的内容是：“We will have something else here soon...（这里将会有一些别的东西……）”

# = 常规 =
* *[选取方块](选取方块.md)**
* 当按下的同时对物品展示框内的物品使用，复制到的物品会保留原有的各种属性和标签。
