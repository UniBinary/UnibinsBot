# Java版25w10a

*页面ID: 147016* | *来源: Minecraft Wiki*

<onlyinclude>

* *25w10a**是[Java版1.21.5](Java版1.21.5.md)的第10个，也是最后一个快照，发布于2025年3月5日<ref></ref>，加入了<code>[tntExplodes](游戏规则/tntExplodes.md)</code>游戏规则，更新了全景图，为所有实体加入了自定义数据字段，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[游戏规则](游戏规则.md)**
* 加入了<code>[tntExplodes](游戏规则/tntExplodes.md)</code>游戏规则，以同步。
* * 为<code>false</code>时，TNT将不能爆炸，也不可被激活。
* * 默认为<code>true</code>。

# = 常规 =
* *[实体数据格式](实体数据格式.md)**
* 向所有实体（除固有此字段的[标记](标记.md)）加入了字段。
* * 由于以<code>custom_data</code>[数据组件](数据组件.md)形式公开，故可由生成类物品设置，也可由谓词匹配。
* * 当前自定义实体数据存储于<code>data</code>中，未来引入更合适的实体组件存储方式后，此字段名称将会更改。
* * 仅在非空时存储。

* *[实体谓词](实体谓词.md)**
* 加入了新可选字段<code>predicates</code>。
* * 除了操作对象是实体组件外，其功能和格式与物品谓词<code>predicates</code>相同。
* * 存在时，将匹配实体组件的部分内容。

* *方块谓词**
* 加入了新可选字段。
* * 除了操作对象是方块实体组件（若有）外，其功能和格式与同名的物品谓词相同。
* * <code>components</code>存在时，其将匹配方块实体组件的精确内容。
* * <code>predicates</code>存在时，其将匹配方块实体组件的部分内容。

* *[标签](Java版标签.md)**
* 加入了物品标签：。
* * 现有的方块标签的对应物品标签。

# 更改
# = 方块 =
* *[活塞](活塞.md)**
* 现在所破坏的方块会播放对应的破坏音效。

* *[仙人掌花](仙人掌花.md)**
* 现在可以放置在[耕地](耕地.md)上。
* 现在可以被[末影人](末影人.md)拿起。

* *[熔岩](熔岩.md)、[水](水.md)和[萤火虫灌木丛](萤火虫灌木丛.md)**
* 现在其播放的环境音效由“方块”分类移动到“”分类。

* *[测试方块](测试方块.md)和[测试实例方块](测试实例方块.md)**
* 更改了纹理。

# = 生物 =
* *[绵羊](绵羊.md)**
* 调整了羊毛纹理，以消除背部的明显线条。

* *[牛](牛.md)**
* 更新了模型。

# = 游戏内容 =
* *[创造模式物品栏](创造模式物品栏.md)**
* 现在[涡流纹样陶片](涡流纹样陶片.md)位于探险纹样陶片之后。

# = 命令格式 =
* *[SNBT格式](SNBT格式.md)**
* 为简化数据输入和使用，SNBT现在接受以下操作：
* * <code>bool(-{}-<*参数*>)</code>：将参数转换为布尔值。
* ** 参数为布尔值时，直接返回值。
* ** 参数为数字时，在非0时返回<code>true</code>，否则返回<code>false</code>。
* * <code>uuid(-{}-<*字符串*>)</code>：将[UUID](UUID.md)的字符串表示转换为整型数组。
* 将溢出至无穷的浮点值（如<code>1e1000</code>）现在会被拒绝。

# = 常规 =
* *[全景图](全景图.md)**
* 更新了主菜单全景图以匹配[春意盎然](春意盎然.md)。

* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[资源包](资源包.md)**
* 将资源包版本号更改为。

* *[着色器](着色器.md)**
* “全局”Uniform现在可以在任何着色器中定义，游戏将尝试填充这类变量。
* * 目前，包含这些Uniform：。
* * Uniform的类型必须与其通常应有的类型匹配，否则将导致未定义的行为。

* *[标签](Java版标签.md)**
* 向方块标签中加入了。
* 从方块标签中移除了可被[瞬间破坏](瞬间破坏.md)的方块。
