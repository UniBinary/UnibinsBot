# Java版1.0.1

*页面ID: 28499* | *来源: Minecraft Wiki*

* *1.0.1**是的一次服务端更新，发布于2011年11月24日<ref></ref>，修复了服务器中的一些漏洞。其客户端版本仍停留在[1.0.0](Java版1.0.0.md)。

目前没有证据能证明其.exe文件存在。

# 修复
* *修复了2个漏洞**
* 修复了试图登入服务器时出现的“Invalid server key”（无效的服务器秘钥）错误。
* 修复了试图登入服务器时出现的“Null pointer exception”错误。
