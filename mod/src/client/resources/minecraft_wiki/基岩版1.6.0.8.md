# 基岩版1.6.0.8

*页面ID: 35658* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.6.0.8**是[1.6.0](基岩版1.6.0.md)的第4个测试版，发布于2018年7月26日<ref></ref>，修复了一些漏洞。

# 修复
* *修复了25个漏洞**
* 修复了几个游戏中会发生的崩溃。
* 可可豆在使用高清资源包时显示不正确。
* 关闭游戏后再次保存选择的皮肤。
* 在原主机版转换世界中酿造台里的烈焰粉不会消失。（）
* 修复了海龟生蛋的问题。
* 修复了溺尸、尸壳、僵尸和僵尸村民不攻击海龟蛋的问题。
* 修正某些方块在生存模式中被破坏时缺少裂痕纹理的问题。
* 村庄不再在要塞上旋转楼梯而产生。 （）
* 玩家死亡后装备物品不再消失。（）
* 船上敌对的生物不再能从各个角度进攻。 ()
* 拉杆现在有一个“使用”控制器提示。
* 玩家在游泳时不再卡方块和窒息。（）
* 当多人游戏有资源包启用时资源包再次应用。（）
* 修复攻击/破坏被应用在鼠标右键时行为不一致。（）
* 在游戏中时拴绳不再闪烁。
* 仙人掌的碰撞箱过小。
* 修复触屏操作时重复点击的问题。
* 修复待机后进入游戏无法操作。（）
* 书现在再次可以堆叠。（）
* 修复了一个文件可以获得水的漏洞。（）
* 跟踪目标实体的实体现在将正确地在板上进行导-{}-航。
* 带有“can_place_on”标签的砖块可以再次在冒险模式中被玩家放置。
* Add-Ons: 'minecraft:behavior.player_ride_tamed'将会覆盖其他任何的AI目标。
* Add-Ons: 'movement.sway'再次可以允许生物准确移动。
* Add-Ons: "minecraft:entity_spawned"中的"is_biome"过滤器现在可以适当添加或移除组件。</onlyinclude>
