# Java版Infdev 20100227-1414

*页面ID: 35914* | *来源: Minecraft Wiki*

/开发者版本}}
<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的首个版本发布于2010年2月27日14:14（UTC），加入了[金苹果](金苹果.md)，并修改了世界生成。<ref></ref><ref name="wordOfNotch"></ref>

# 新内容
# = 物品 =
* *[金苹果](金苹果.md)**
* 一种[食物](食物.md)。
* 食用后可恢复生命值。
* 可由1个[苹果](苹果.md)和8个[金块](金块.md)合成。

# = 世界生成 =
* *[红砖块金字塔](红砖块金字塔.md)**
* 一种由[红砖块](红砖块.md)构成的实心金字塔型结构。
* 无视[种子](种子（世界生成）.md)生成于特定坐标。
* * 在正X，正Z象限中每1024×1024格就会生成一个。
* 高为256，但由于高度限制为128，导致其顶端会被切除。<ref></ref>

* *[黑曜石墙](黑曜石墙.md)**
* 两堵两格高的墙型结构。
* 生成在X和Z轴处。
* 用于标记世界中心。

# 更改
# = 方块 =
* *常规**
* 方块不再自动更新。
* * 这意味着沙子和沙砾不再下落，液体不再流动，作物和[树苗](树苗.md)不再生长，[海绵](海绵.md)不再起作用。

# = 物品 =
* *[苹果](苹果.md)**
* 不再错误地使用[金头盔](金头盔.md)的纹理。

* *[画](画.md)**
* 更改了配方，现在需要8个[木棍](木棍.md)和1个[淡灰色羊毛](淡灰色羊毛.md)来合成。

# = 生物 =
* *常规**
* 实体不再能正常工作，生物也不再能够生成。

* *[玩家](玩家.md)**
* 现在名称为“Notch”的玩家死亡后会额外掉落1个[苹果](苹果.md)。

# = 非生物实体 =
* *常规**
* [实体](实体.md)不再能正常工作。

# = 游戏内容 =
* *[世界类型](Indev世界选项#世界类型.md)、[世界形状](Indev世界选项#世界形状.md)、[世界大小](Indev世界选项#世界大小.md)和[世界主题](Indev世界选项#世界主题.md)**
* 不再起作用。

* *[第三人称视角](第三人称视角.md)**
* 不再显示[玩家](玩家.md)。

* *[昼夜更替](昼夜更替.md)**
* 被移除。

* *[亮度](亮度.md)**
* 不再正常工作。

* *[音乐](音乐.md)**
* 被移除。

* *常规**
* 移除了存档功能，尝试存档只会产生空的文件。
* 玩家现在会携带999个[玻璃](玻璃.md)和990个[木板](木板.md)生成。

# = 世界生成 =
* *[洞穴](洞穴.md)**
* 被移除。

* *[团簇](团簇.md)**
* 被移除。

* *[树木](树木.md)**
* 被移除。

* *[高度](高度.md)**
* 建筑高度限制更改为128。

* *天空**
* 现在为一个大小为1536×1536的天空盒，颜色为。
* * 会在X/Z=+1,024/-512处停止渲染。

* *[云](云.md)**
* 现在会在X/Z=±512处停止渲染。

* *[Indev房子](Indev房子.md)**
* 被移除。

* *常规**
* 移除了所有[世界界限](世界界限.md)，世界现在无限生成。
* 现在的地形类似于[Classic](Java版Classic.md)阶段。
* 现在只会自然生成[草方块](草方块.md)、[泥土](泥土.md)、[石头](石头.md)、[水](水.md)、[蒲公英](蒲公英.md)、[红砖块](红砖块.md)和[黑曜石](黑曜石.md)。</onlyinclude>
