* *马铃红石矿石（Potone Redstone Ore）**是以[马铃石](马铃石.md)作为容矿岩的[红石矿石](红石矿石.md)变种，会自然生成于[马铃薯维度](马铃薯维度.md)。

# 生成
# = 自然生成 =
马铃红石矿石以[团簇](团簇.md)的形式自然生成于[马铃薯维度](马铃薯维度.md)Y=0至32高度范围内的马铃石之间。共有两种团簇：
* 上层团簇大小为1-8，每个区块尝试生成4次，生成范围高度在Y=0到15之间。
* 下层团簇大小为1-8，每个区块最多尝试生成8次，生成范围高度在Y=0到32之间，高度越低生成概率越高。

# 获取
马铃红石矿石只能通过破坏对应方块获得。

# 破坏
挖掘马铃红石矿石的合适工具是锄。马铃红石矿石需要铁锄或品质更好的锄来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，马铃红石矿石被破坏后会掉落4-5个[红石粉](红石粉.md)和。挖掘工具的[时运](时运.md)魔咒会使马铃红石矿石额外等概率掉落0至<魔咒等级>个红石粉。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，马铃红石矿石被破坏后会掉落自身。

# 用途
# = 光源 =
当鼠标单击或被大多数可移动[实体](实体.md)（不包括[潜行](潜行.md)中的玩家和物品弹射物）接触时，马铃红石矿石会产生9级的亮度以及[红石粉粒子](Java版粒子#dust.md)。该效果会一直持续到马铃红石矿石接收到[随机刻](随机刻.md)为止（平均为68.27秒）。该效果实际上不会产生任何的红石信号，但这个改变可被[方块更新感应器](Tutorial:方块更新感应器.md)和[侦测器](侦测器.md)探测到。
