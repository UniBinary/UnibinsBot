# 毒马铃薯鞋

*页面ID: 163955* | *来源: Minecraft Wiki*

* *毒马铃薯鞋（Poisonous Pota-Toes）**是由马铃薯材料制成的[靴子](靴子.md)，可以抵消摔落伤害。

# 获取
# = 合成 =

# = 虚空 =
在[马铃薯维度](马铃薯维度.md)中掉入[虚空](虚空.md)后，玩家会在[主世界](主世界.md)出生点上方高处生成，并装备毒马铃薯鞋。如果玩家已经穿着靴子，则原本的靴子会被销毁，替换为毒马铃薯鞋。

# = 箱子战利品 =

# 用途
毒马铃薯鞋可以像其他靴子一样被装备在第四个盔甲槽中，但不提供任何[护甲值](护甲值.md)。

# = 摔落 =
当装备毒马铃薯鞋的[生物](生物.md)摔落时，若[摔落高度](摔落#下落高度.md)大于生物的[安全摔落高度](属性/安全摔落高度.md)，生物周围会被放置[毒马铃薯糊](毒马铃薯糊.md)，并重置生物的摔落高度，保护生物免受摔落伤害。若生物不是处于[创造模式](创造模式.md)的[玩家](玩家.md)，毒马铃薯鞋会消耗1个。

具体来说，若设生物的摔落高度为与安全摔落高度之差为<math>s</math>，则毒马铃薯糊的生成尝试次数为<math>\text{clamp}(\frac{s}{50},0,1)\times 79+1</math>（向下取整）。生成尝试位置在生物与毒马铃薯糊的水平[切比雪夫距离](切比雪夫距离.md)小于等于<math>\text{clamp}(\frac{s}{50},0,1)\times 4+1</math>（向下取整）格，垂直距离小于等于1格的区域内随机选取，水平均匀分布，垂直三角形分布。对于每次生成尝试，若生物是玩家且生成尝试位置在世界边界外或[出生点保护](出生点保护.md)内会跳过生成，否则根据[方块](方块.md)类型生成。若方块原来就是毒马铃薯糊，只会增加其层数，最高不超过8；而若方块是其他[可替代](可替代.md)的方块，会破坏原来的方块并产生单层毒马铃薯糊，原来的方块掉落物不受[魔咒](魔咒.md)影响。

# = 发射器 =
[发射器](发射器.md)在使用毒马铃薯鞋物品时，会向朝向的1格内有空的适当盔甲槽的[玩家](玩家.md)、[僵尸](僵尸.md)及其变种、[骷髅](骷髅.md)及其变种、[村民](村民.md)、[猪灵](猪灵.md)、[猪灵蛮兵](猪灵蛮兵.md)或[盔甲架](盔甲架.md)装备毒马铃薯鞋，否则毒马铃薯鞋物品会从发射器中被抛出。
