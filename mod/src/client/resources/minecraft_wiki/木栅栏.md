# 木栅栏

*页面ID: 163547* | *来源: Minecraft Wiki*

# 生成
红树木栅栏、樱花木栅栏、苍白橡木栅栏、竹栅栏、绯红木栅栏和诡异木栅栏不会生成在世界中。

# = 自然生成 =
橡木栅栏自然生成于：
* [沼泽小屋](沼泽小屋.md)；
* [废弃矿井](废弃矿井.md)（支撑着橡木木板生成，或者在矿井悬空时在[铁链](铁链.md)下方生成以吊起矿道）；
* [要塞](要塞.md)的图书馆（作为栏杆和吊灯生成，作吊灯时会与许多[火把](火把.md)连接）；
* [平原](平原.md)村庄，以桌子、路灯、围栏等形式存在；
* [林地府邸](林地府邸.md)和[沉船](沉船.md)。
* [试炼密室](试炼密室.md)的休息室中。

云杉木栅栏自然生成于：
* [针叶林](针叶林.md)、[积雪针叶林](积雪针叶林.md)和[雪原](雪原.md)村庄，以桌子、路灯、围栏等形式存在；
* 沉船。

丛林木栅栏自然生成于沉船中，以及[沙漠](沙漠.md)村庄的盔甲匠房屋内。

金合欢木栅栏自然生成于[热带草原](热带草原.md)村庄，作为桌子、路灯、屋顶等结构的组成部分，也生成于沉船。

深色橡木栅栏生成于：
* [恶地](恶地.md)废弃矿井（支撑着深色橡木木板生成，或者在矿井悬空时在铁链下方生成以吊起矿道）；
* [掠夺者前哨站](掠夺者前哨站.md)、林地府邸、沉船和[远古城市](远古城市.md)。

白桦木栅栏生成于林地府邸和沉船中。

# 破坏
挖掘木栅栏的合适工具是斧。

木栅栏被破坏后会掉落自身。

# 用途
尽管木栅栏看起来只有1格高，但它的[碰撞箱](碰撞箱.md)却有1.5格高。这意味着玩家和大多数生物在没有[跳跃提升](跳跃提升.md)效果时不能越过木栅栏。不过由于其轮廓箱仍为1格高，因此通过其上方空间攻击或选中后面的方块不受影响。

所有木栅栏的水平长度为0.25格，占据一个方块最中间的位置，多个木栅栏连接时中间会被占据从而连成一个整体。

木栅栏占据着方块的中心位置，碰撞箱宽度小于1格，因此处于水中的玩家或生物可以通过紧靠未[含水](含水.md)的木栅栏呼吸。

# = 连接 =
与木栅栏相邻的方块与木栅栏相邻的面如果是完整的面，那么木栅栏会自动与之连接，但不会连接[屏障](屏障.md)、[南瓜](南瓜.md)、[雕刻南瓜](雕刻南瓜.md)、[南瓜灯](南瓜灯.md)、[西瓜](西瓜.md)、任何类型的[树叶](树叶.md)和[潜影盒](潜影盒.md)。

所有木栅栏会互相连接，但不会连接[下界砖栅栏](下界砖栅栏.md)。木栅栏会连接侧面与之相邻的[栅栏门](栅栏门.md)。

# = 拴绳 =
使用[拴绳](拴绳.md)拴着实体时对着木栅栏按下可将它们拴在木栅栏上，并在木栅栏上生成一个[拴绳结](拴绳结.md)。

# = 燃料 =
主世界木质栅栏和竹栅栏可以用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个木质栅栏或竹栅栏可以烧炼1.5个物品。
