# 携带版0.9.0

*页面ID: 21009* | *来源: Minecraft Wiki*

* *v0.9.0 alpha**是[携带版](携带版.md)的一次主要更新，发布于2014年7月10日。加入了新的方块、物品、结构和生物群系，更新了生物AI，大幅重写了世界生成器，并修复了一些漏洞。

* 512格方块的[可视距离](调试屏幕#渲染距离.md)（仅部分支持的设备）

* *[设置](设置.md)**
* 增加了选项，可以选择世界类型：
* [旧世界类型](旧世界类型.md)
* [超平坦](超平坦.md)（在创建世界时游戏内显示的是Flat）
* * 所有的超平坦世界和默认生成的经典超平坦世界都是无限的，但可以在options.txt中更改。<ref></ref>
* 无限
* * 不建议使用低配置设备（iOS5.x及更老版本）。
* * 可靠的游戏尺寸是大约40000×40000（+20000到-20000）。
* ** 在±20,000之外，世界逐渐变得显示不正确，游戏逐渐变得难以进行。<ref></ref>崩溃的可能性和越发严重的卡顿会随着远离世界中心的距离的增加而增加。
* ** 最终，存档会变得不可玩，自然现象例如“条纹之地”和[边境之地](边境之地.md)会出现。
* ** 在一些情况下，世界的外部界限会变得不同——网格状。<ref></ref>黑色的条纹视觉（“条纹之地”）<ref></ref>甚至边境之地（和Java版相同）已经可以观察到。<ref></ref>

# 更改
# = 方块 =
* *常规**
* 方块实体以不同的方式保存。

* *[草方块](草方块.md)**
* 更改了纹理。

* *[原木](原木.md)**
* 现在白桦、云杉和丛林原木顶部有不同纹理。

* *[丛林木板](丛林木板.md)**
* 现在可合成。

* *[沙砾](沙砾.md)**
* 不再在放置时掉落。

* *[楼梯](楼梯.md)和[台阶](台阶.md)**
* 现在拥有正确的名字。

* *[床](床.md)**
* 在普通难度中不再回复生命值。
* 加入了平滑光照。

* *[雪层](雪层.md)**
* 现在可合成。

* *[地毯](地毯.md)**
* 所有地毯可在生存模式中获得。

* *[栅栏](栅栏.md)**
* 加入了平滑光照。

* *[树叶](树叶.md)**
* 加入了平滑光照。
* 丛林树叶完全不透明。
* 新的树叶渲染。

* *[蜘蛛网](蜘蛛网.md)**
* 加入了平滑光照。

* *[箱子](箱子.md)**
* 加入了平滑光照。

* *[荧石](荧石.md)**
* 移除了平滑光照。

* *[玻璃](玻璃.md)**
* 移除了平滑光照。

* *[南瓜灯](南瓜灯.md)**
* 移除了平滑光照。

* *点亮的[红石矿石](红石矿石.md)**
* 移除了平滑光照。

* *[TNT](TNT.md)**
* 改进了性能。

# = 物品 =
* *[染料](染料.md)**
* [灰色染料](灰色染料.md)和[淡灰色染料](淡灰色染料.md)可在生存模式获得。

# = 生物 =
* *常规**
* “新的”生物生成算法。
* 生物受伤时颜色更淡。
* 被动型生物现在以小组生成。

* *[僵尸](僵尸.md)**
* 僵尸的AI和机制更改了，使之更倾向于成群。
* 当被攻击时，僵尸有很小概率生成更多僵尸。

* *[蜘蛛](蜘蛛.md)**
* 现在在树叶上生成，使多树生物群系在夜晚有更多蜘蛛。
* 动画现在是原来的两倍速度。
* 改进了AI。

* *[苦力怕](苦力怕.md)**
* 现在走得更快。
* 改进了AI。
* 不再飘浮在地面上方2像素。

# = 非生物实体 =
* *[摄像机](摄像机.md)**
* 完全移除了[摄像机](摄像机.md)实体。

# = 世界生成 =
* *[树木](树木.md)**
* [云杉橡树](树木#云杉橡树.md)不在新世界生成，因为它们的罕见故障已修复。
* [橡树](树木.md)现在生成时有不同高度和结构。
* [云杉树](树木#云杉树.md)现在生成时有不同高度和结构。

* *[地形特征](地形特征.md)**
* 旧的地形生成被移除，现在使用[旧世界类型](旧世界类型.md)。

* *[生物群系](生物群系.md)**
* 加入了生物群系特有颜色的方块。
* 移除了沙砾海滩。
* 冻洋不再自然生成。

# = 游戏内容 =
* *云**
* 改进了云的外观。

* *雾**
* 雾在地底更暗。

# = 常规 =
* *[物品栏](物品栏.md)**
* 重新设计了合成界面。
* 仅显示可合成配方。
* 生存模式物品栏的新布局。
* 新的选取算法。

* *[GUI](GUI.md)**
* 世界列表现在显示每个世界的大小。
* 每个设备有自身的可视距离。

* *[光照](光照.md)**
* 更新光照生成。

* *[设置](设置.md)**
* options.txt文件现在记录渲染距离而不是未生成方块。<ref></ref>
* Android 4.4设备支持VR模式（隐藏屏幕上的导航栏）。
* 新Level.db保存格式。
* 新的实体操控。
* 重写了网络代码（基本相同文件但是是新的系统）。

* *[服务器](服务器.md)**
* 玩家加入时不再有服务器侧边消息。

# 修复
* *修复了5个漏洞**<br>
* *0.9.0以往正式版的漏洞**
* 使用Mip映射的火会渲染为橙色的大斑块。<ref></ref>
* 多人游戏中的矿车问题。<ref></ref>
* 烤马铃薯的名称和描述出错。
* 合成告示牌只能获得一个告示牌。
* 不同种类的木头在熔炉中会转换为同种木头。
