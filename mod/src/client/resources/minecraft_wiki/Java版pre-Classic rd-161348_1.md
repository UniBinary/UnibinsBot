# Java版pre-Classic rd-161348

*页面ID: 34830* | *来源: Minecraft Wiki*

<onlyinclude>

* *rd-161348**是2009年5月16日11:48（UTC）制作完成的[pre-Classic](Java版pre-Classic.md)版本。<ref></ref>

# 新内容
# = 方块 =
* *[树苗](树苗.md)**
* 按可选择。
* 若处于黑暗中或未放置在[泥土](泥土.md)或[草方块](草方块.md)上时会消失。

# 更改
# = 生物 =
* *[人类](生物（已移除实体）.md)**
* 新建世界时现在数量有所增加。

# = 游戏内容 =
* *[平视显示器](平视显示器.md)**
* 十字准星变粗。
* 右上角的方块预览被翻转。

# = 世界生成 =
* *常规**
* 悬崖更常见。
* 远处物体颜色略深。

# = 常规 =
* *[粒子](Java版粒子.md)**
* 现在会跟随玩家位置：玩家面朝上时能看到完整粒子，而非侧面的一小部分。

# 修复
; 修复了1个漏洞
   修复了特定角度下看不见世界的渲染故障。</onlyinclude>

# 启动器版
启动器中的该版本由源代码编译而来，且为符合实际情况修改了日期为2009年，且包含来自[Classic 0.0.13a](Java版Classic 0.0.13a.md)的以及2013年的签名文件。<ref group="注" name="repackage">启动器版的和文件的修改时间分别为21:25:46（UTC+3）和03:03:00（UTC+3）。邻近版本中的这两个文件与rd-161348中的相同，最后修改时间均精确提前一小时（即UTC+2）。由于时区变更不影响jar文件内容，因此启动器中的变种版本是原版的重新打包版本，且时区变更对其中几个文件产生了影响。</ref>
