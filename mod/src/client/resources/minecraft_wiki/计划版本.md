# 计划版本

*页面ID: 20042* | *来源: Minecraft Wiki*

本页面列出了[Minecraft](Minecraft.md)不同游戏版本的**计划版本（Planned versions）**。这些未来的版本都有主要的参考来源证明其存在，或者已经发布了开发版本。

注意只有拥有已知计划更新的版本会在这里列出。如果没有已知的计划更新，该版本会被略去。

# Java版

# = 26.1 =

* *26.1**是即将到来的一次小更新，发布时间待定。<ref></ref>加入了[金蒲公英](金蒲公英.md)，为一些幼年生物加入了新的纹理、模型和音效，加入了[命名牌](命名牌.md)的合成配方，修改了命令，并修复了一些漏洞。

# 基岩版

# = 26.10 =

* *26.10**是即将到来的一次小更新，发布时间待定。此次更新将会加入[命名牌](命名牌.md)的合成配方，为一些[幼年生物](幼年生物.md)加入新的纹理、模型和音效，修改[兔子](兔子.md)的纹理和模型，并修复一些漏洞。<ref></ref>
