# 甜浆果

*页面ID: 37628* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *甜浆果（Sweet Berries）**是从甜浆果丛处采集而得的[食物](食物.md)。

* *甜浆果丛（Sweet Berry Bush）**是一种能用于获取甜浆果的方块。

# 生成
# = 自然生成 =
甜浆果丛自然生成于所有[针叶林](针叶林.md)和[原始针叶林](原始针叶林.md)生物群系变种中。

此外在所有[积雪针叶林](积雪针叶林.md)生物群系变种中，每个区块都有概率生成几簇甜浆果丛。

# 获取
甜浆果可通过对着甜浆果丛按下键或者破坏它获得，在处于第三生长阶段时给予1-2份，在第四生长阶段给予2-3份。

# = 箱子战利品 =

# 破坏
甜浆果丛被挖掘时会立刻被破坏，用于挖掘的工具的耐久度不会下降。

生长阶段为第1阶段或第2阶段的甜浆果丛被破坏后不会掉落。

生长阶段为第3阶段的甜浆果丛被破坏后会掉落1-2个甜浆果。

生长阶段为第4阶段的甜浆果丛被破坏后会掉落2-3个甜浆果。

当甜浆果丛的生长阶段为第3或4阶段时，挖掘工具的时运魔咒会使甜浆果丛额外等概率掉落0-*<魔咒等级>*个甜浆果。

# 用途
# = 种植 =
如果手持甜浆果对着[草方块](草方块.md)、[泥土](泥土.md)、[灰化土](灰化土.md)、[砂土](砂土.md)、[菌丝体](菌丝体.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[缠根泥土](缠根泥土.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)或[耕地](耕地.md)按下键，会种植一个甜浆果丛，并开始生长直到长至它的完整生长阶段。

# = 生长 =

甜浆果丛种植后会经过4个生长阶段。甜浆果丛上方一格的[亮度](亮度.md)等级≥9时，甜浆果丛才能生长到下一个阶段；其第一个生长阶段是一棵没有甜浆果的小苗；第二阶段长成成熟的植株，但没有任何甜浆果；第三个生长阶段会长出甜浆果；第四个也是最后一个生长阶段会长出更多甜浆果。

对甜浆果丛使用[骨粉](骨粉.md)能使其进入下一生长阶段。采集了花粉的[蜜蜂](蜜蜂.md)飞过甜浆果丛时，甜浆果丛也有概率增加1个生长阶段。

对生长阶段为第3阶段的甜浆果丛按下键会使其掉落1-2个甜浆果并变为第2阶段。

对生长阶段为第4阶段的甜浆果丛按下键会使其掉落2-3个甜浆果并变为第2阶段。

# = 食物 =

手持甜浆果按住键即可食用，每个甜浆果可以回复和/饱和度。

# = 堆肥 =
将甜浆果放入[堆肥桶](堆肥桶.md)里有30%的概率增加1个堆肥层。

# = 繁殖 =
甜浆果可用来吸引和繁殖[狐狸](狐狸.md)，也可喂食给幼年个体以减少其10%的剩余成长时间。繁殖出的幼年狐狸会信任玩家，从而不会主动逃离玩家。

# = 交易 =

# = 移动 =
生物在任意生长阶段的甜浆果丛中移动时，移动速度会减速至正常速度的约34.05%，玩家只能在甜浆果丛中跳个方块高。

除狐狸和蜜蜂外的生物在生长阶段至少为2的甜浆果丛中移动时会每受到伤害。

坐在[矿车](矿车.md)内的生物不会因矿车被推进甜浆果丛里而受伤。像[蜘蛛网](蜘蛛网.md)一样，从空中摔落到甜浆果丛中将不会受到[摔落伤害](摔落伤害.md)，但会因为掉落过程中在其中垂直移动而受到甜浆果丛的伤害。

# = 狐狸 =
[狐狸](狐狸.md)会跑向半径16个方块内<code>age</code>为2或3的甜浆果丛，使甜浆果丛上面的甜浆果掉落，并将<code>age</code>回退至1。

# 你知道吗
* 甜浆果丛会对[恼鬼](恼鬼.md)造成伤害，即使它并不能阻碍其行动。
* 虽然甜浆果丛是[不可替代方块](不可替代方块.md)，但是在其上方一格的受重力影响的方块仍然会下落并掉落为物品。
* 使用[骨粉](骨粉.md)将甜浆果变成生长阶段为3的甜浆果会获得尽可能多的甜浆果，因为生长阶段为3的甜浆果只需要在原来生长阶段为2的基础上花费1个骨粉来获得数学期望为1.5的甜浆果而再消耗一个骨粉只会获得数学期望为2.5的甜浆果。
