# 基岩版1.11.0.10

*页面ID: 42207* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.11.0.10**是[1.11.0](基岩版1.11.0.md)的第8个测试版，发布于2019年4月11日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *优化**
* 优化了目标选择器的使用。
* [村庄](村庄.md)各种性能的优化。
* *[种子选取器](种子选取器.md)**
* 删除了7个[种子](种子（世界生成）.md)并增加了11个。

# 修复
* 修复了村民在附近没有村庄时不会四处游荡的漏洞。（）
* Nintendo Switch版下载可在进行正常多人游戏之后进行本地多人游戏。
* 修复了有时打开皮肤选择界面时会导致游戏崩溃的漏洞。</onlyinclude>
