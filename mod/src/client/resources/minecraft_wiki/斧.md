* *斧（Axe）**是一类能够提高木质方块采集效率的工具，同时也是一种近战[武器](武器.md)。

# === 合并物品 ===

叠加两把斧的剩余耐久度，再额外获得12%的耐久度，按照[铁砧机制](铁砧机制.md)保留魔咒。

# = 生物 =

[卫道士](卫道士.md)生成时手持一把铁斧，被玩家杀死后有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落它手上的铁斧。这把掉落的斧通常会有一定程度的损坏，有时是被附魔的。

[猪灵蛮兵](猪灵蛮兵.md)生成时手持一把金斧，被玩家杀死后有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落它手上的金斧。这把掉落的斧通常会有一定程度的损坏。

# = 袭击 =

[袭击](袭击.md)中产生的卫道士和[掠夺者](掠夺者.md)会有4.1％的概率（困难为5.12％）掉落铁斧，这把斧的耐久值很少，有时会被随机附魔。卫道士可能会掉落两把铁斧，其中一把是自然生成时装备的，另一把则是作为袭击中袭击者掉落的斧。

# == 林地府邸 ==
[林地府邸](林地府邸.md)的[伐木房间](林地府邸/结构/农场#伐木房.md)里生成的[箱子](箱子.md)当中一定有一把带有[效率](效率.md)I魔咒的铁斧。

# = 礼物 =

[武器匠](武器匠.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷石斧、铁斧或金斧。

[工具匠](工具匠.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷石斧。

# 用途
[物品实体](物品实体.md)形式的下界合金斧会漂浮在[熔岩](熔岩.md)上，且不会被[火](火.md)和熔岩摧毁。

# = 挖掘工具 =

斧是一种挖掘工具，每次成功挖掘任何硬度不为0的方块时会消耗1耐久度。

# = 近战攻击 =
斧每成功进行一次[近战攻击](近战攻击.md)会减少2点耐久度。

[盾牌](盾牌.md)防御了使用斧进行的近战攻击时将被[停用](物品#行为.md)，并消耗<code>-{}-攻击伤害（向下取整）+1</code>的耐久度。<ref></ref>

# == Java版 ==
不同品质的斧有不同的攻击速度。

# == 基岩版 ==
斧没有攻击冷却。

# = 魔咒 =
斧能被附加以下[魔咒](魔咒.md)：

# = 去皮 =
对[木头](木头.md)、[原木](原木.md)或[竹块](竹块.md)斧可以使其变成去皮变种。每次去皮会消耗斧1点耐久度。

# = 除锈 =
对[铜块](铜块.md)、[切制铜块](切制铜块.md)、[切制铜楼梯](切制铜楼梯.md)、[切制铜台阶](切制铜台阶.md)、[雕纹铜块](雕纹铜块.md)、[铜格栅](铜格栅.md)、[铜灯](铜灯.md)、[铜门](铜门.md)、[铜活板门](铜活板门.md)、[铜箱子](铜箱子.md)、[铜傀儡](铜傀儡.md)或[铜傀儡像](铜傀儡像.md)斧可为其除锈，每次除锈会使其锈蚀程度减轻一级。若是涂蜡变种则先进行脱蜡。每次脱蜡和除锈操作均会消耗斧1点耐久度。

# = 生成铜傀儡 =
对未涂蜡且未氧化的[铜傀儡像](铜傀儡像.md)斧可以使其生成[铜傀儡](铜傀儡.md)。每次使用会消耗斧1点耐久度。

# = 燃料 =
木斧能被用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个木斧可以烧炼1个物品。

# 你知道吗
* 在[Java版1.13](Java版1.13.md)之前的语言文件中，斧被标记为短柄小斧（Hatchet）。<ref name="1.8 lang">*1.8/assets/minecraft/lang/en_US.lang*, line 915: **item.hatchetIron.name= Iron Axe**</ref>目前斧在[海盗语](彩蛋#语言.md)中也被称为“Hatchet”。
* 在[Java版](Java版.md)中，用斧从超出盾牌有效防御范围的位置对正在举盾的玩家发动近战攻击不会消耗盾牌的耐久度，但仍然可以禁用盾牌5秒并对该玩家造成伤害。
