# 基岩版1.8.0

*页面ID: 36726* | *来源: Minecraft Wiki*

* *1.8.0**是**假日更新**<ref group="注">此更新在游戏内部和菜单中被称为“假日更新”，尽管该名称从未在minecraft.net或社交账户上使用过。</ref>的正式版，也是的一次主要更新，发布于2018年12月11日<ref></ref>，加入了首批[村庄与掠夺](村庄与掠夺.md)更新的特性，例如[熊猫](熊猫.md)、[竹子](竹子.md)、[脚手架](脚手架.md)和[猫](猫.md)。<ref></ref>

[缩略图|Mojang发布的更新主视觉图](File:Cats & Pandas.png.md)

# 新内容
# = 方块 =
* *[竹子](竹子.md)**
* 可在丛林里[钓鱼](钓鱼.md)时获得。
* 在未来的更新中，它将可以在世界中自然生成。
* 可在[沉船](沉船.md)和[丛林神庙](丛林神庙.md)内找到。

* *[脚手架](脚手架.md)**
* 一种用[竹子](竹子.md)和[线](线.md)制作的可攀爬方块。

# = 物品 =
* *[弩](弩.md)**
* 新的远程武器。
* 可附魔新加入的三种魔咒。
* 弩的威力和射程与弓相同，但需要更长时间拉弦。给弩附上[快速装填](快速装填.md)III魔咒后，弩的装填速度略快于弓。
* 当主手上拿着弩，副手上拿着烟花火箭时，可以发射[烟花火箭](烟花火箭.md)。
* 可以在设置中启用[实验性玩法](实验性玩法.md)后获得。

* *[染料](染料.md)**
* 加入了白色染料、蓝色染料、棕色染料和黑色染料。
* 其对应染料（[骨粉](骨粉.md)、[青金石](青金石.md)、[可可豆](可可豆.md)和[墨囊](墨囊.md)）依然可用。

* *[刷怪蛋](刷怪蛋.md)**
* 添加了[熊猫](熊猫.md)、 [猫](猫.md)的刷怪蛋。

* *[摄像机](摄像机.md)**
* 重新加入，但只能使用NBT编辑器获得。

# = 生物 =
* *[熊猫](熊猫.md)**
* 自然生成在[丛林](丛林.md)里。
* 可进食[竹子](竹子.md)和[蛋糕](蛋糕.md)。
* 有不同的习性——懒惰、贪玩、敌对和忧愁。
* 拥有棕色变种。

* *[流浪猫](流浪猫.md)**
* 生成在[村庄](村庄.md)里。
* 可以用[鱼](鱼.md)驯服。
* 驯服后，在玩家睡醒后会带给玩家礼物。
* 拥有像被驯服的[狼](狼.md)一样的项圈。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* [快速装填](快速装填.md)
* * 减少弩的填充时间。
* [多重射击](多重射击.md)
* * 使得弩可以一次性发射3个箭。
* [穿透](穿透.md)
* * 使得弩能穿透生物，且不消耗箭。

* *[成就](成就.md)**
* 新增成就如下：
* * 世界之巅 - 把脚手架搭到世界高度上限（20G）
* * 你去哪了？-在早上获得已驯服猫带来的礼物（20G）
* * 动物学家 - 用竹子喂食两只熊猫（40G）

# 更改
# = 方块 =
* *[命令方块](命令方块.md)**
* 默认名称从“@”变为“!”。

* *[浮冰](浮冰.md)**
* 加入了合成配方。

* *[潜影盒](潜影盒.md)**
* 为未染色的潜影盒加入了合成配方。

# = 物品 =
* *[木棍](木棍.md)**
* 现在可由竹子合成。

* *[弓](弓.md)**
* 拉弦时物品栏内有了动画。

* *[染料](染料.md)**
* “蒲公英黄”“玫瑰红”“仙人掌绿”现在分别被重命名为“黄色染料”“红色染料”和“绿色染料”。

* *[烟花火箭](烟花火箭.md)**
* 现在放在副手槽可以被[弩](弩.md)发射。

# = 生物 =
* *[幻翼](幻翼.md)**
* 现在会害怕[猫](猫.md)，且有猫在周围时不会俯冲。

* *[热带鱼](热带鱼.md)**
* 修改了[热带鱼](热带鱼.md)的大小。

* *[骷髅马](骷髅马.md)和[僵尸马](僵尸马.md)**
* 使用[刷怪蛋](刷怪蛋.md)生成时有概率生成幼年形态。

* *[豹猫](豹猫.md)**
* 不再可被驯服。
* 玩家仍然可以喂食它们以获得它们的信任。
* 现在可喂食河豚和热带鱼。

* *[NPC](NPC.md)**
* NPC此时没有功能。
* 现在能通过来生成。

# = 世界生成 =
* *[沼泽小屋](沼泽小屋.md)**
* 现在会生成一只黑色[猫](猫.md)在里面。

# = 游戏内容 =
* *[生成](生成.md)**
* 改进了生成，生成位置的时间和方式现在被移动到安全区域。

* *[钓鱼](钓鱼.md)**
* 更改了在丛林生物群系内的钓鱼收获。
* * 在鱼类中仅能获得生鲑鱼和生鳕鱼。
* * [竹子](竹子.md)可作为垃圾被钓上来。

* *[成就](成就.md)**
* “驯兽师”成就的描述现在被更改为“获得一头豹猫的信任”，因为豹猫不再能被驯服，现在玩家必须喂给豹猫鱼直到冒出爱心粒子为止。

* *[状态效果](状态效果.md)**
* 更改了生命提升和生命吸收图标的纹理。

# = 常规 =
* *[菜单屏幕](菜单屏幕.md)**
* 现在有了动态的加载进度条。

* *[皮肤包](皮肤包.md)**
* 皮肤现在界面现在会展示更多的皮肤包，每个包可以打开并试用。

* *[商城](商城.md)**
* 玩家现在可以使用分享按钮以发送商城内容的链接。
* 内容现在可以通过“可用更新”来排序。
* 内容现在可以通过评分来排序。

* *游戏指南**
* 加入了有关[脚手架](脚手架.md)的信息。

* *[附加包](附加包.md)的更新**
* 玩家现在可以加入自制的生物、粒子和其他内容，而不需要改变原版特性。

* *[全景图](全景图.md)**
* 更新了全景图，与版本新内容匹配。

* *TTS文本转语音**
* 在Nintendo Switch版上启用了功能。

* *[闪烁标语](闪烁标语.md)**
* 移除了“MCPE!”。

# 修复
* *修复了82个漏洞**<br>
* *崩溃/性能**
* 修复了游戏过程中出现的崩溃现象。
* 加载资源包时，断开网络连接导致游戏崩溃。
* Xbox One版里如果玩家登入后又迅速登出会导致游戏崩溃。
* Windows 10 Mobile下在加载界面下游戏会崩溃。
* Gear VR版启动时游戏崩溃。
* Windows 10的新特性导致游戏崩溃。（）
* 修复了鼠标移动到重命名烟花时发生的崩溃。（）
* 发射器发射鱼桶时游戏崩溃。（）
* 试图对着鱼使用熔岩桶时游戏崩溃。
* 海带生长时游戏崩溃。
* 在主菜单里暂停或继续游戏时使得游戏崩溃。
* 包含了定位器地图的世界会使得游戏崩溃。
* 离开Realms选项界面时游戏崩溃。
* 在Nintendo Switch版里下载或保存数据时游戏崩溃。
* 在Nintendo Switch版里的分屏模式下破坏大小箱子导致游戏崩溃。
* 在移除了鲑鱼的寻路组件后，杀死和生成鲑鱼会使得游戏崩溃。
* 改进了低内存设备的游戏性能。
* 试图打开多个UI时游戏崩溃。
* 含有热带鱼桶的潜影盒会导致世界卡顿。（）
* 渲染区块时，游戏性能下降。（）
* 改进了大多数存档的加载时间。
* iOS版屏幕底部出现响应延迟。 ()

* 活塞臂的碰撞箱不正确。（）

* 双木台阶现在可以无视十字准星的位置来放置。（）

* 使用触摸屏设备时，多个物品现在能通过村民交易来收集。（）
