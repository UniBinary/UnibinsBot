# Java版12w42b

*页面ID: 33293* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w42b**是[Java版1.4.2](Java版1.4.2.md)的第15个，也是最后一个快照，发布于2012年10月18日<ref></ref>，发布以修复快照[12w42a](12w42a.md)里的漏洞和崩溃。

# 新内容
# = 生物 =
* *[蝙蝠](蝙蝠.md)**
* 加入了声音。

* *[蠹虫](蠹虫.md)**
* 加入了脚步声。

* *[僵尸](僵尸.md)**
* 加入了3种新音效。

* *[僵尸猪人](僵尸猪人.md)**
* 加入了声音。

# 更改
# = 方块 =
* *[红石中继器](红石中继器.md)**
* 锁定机制稍微变得更加稳定而且可以预测。但目前仍然不是[Mojang](Mojang.md)想要的结果，但完全修复将需要很大的改动，所以计划在[Java版1.5](Java版1.5.md)中改动。

* *[下落的方块](下落的方块.md)**
* 掉落中的方块在掉落到非固体方块（例如[火把](火把.md)）上时会正确地“弹落”。

# = 常规 =
* *[服务器](服务器.md)**
* 服务器的ping值现在会告示服务器和客户端是否有不匹配通信的协议版本。

* *[语言](语言.md)文件**
* 更新了翻译文件。

# 修复
* *修复了1个漏洞**
* 修复了重命名工具栏的宽度。</onlyinclude>
