# 追随者披风

*页面ID: 186697* | *来源: Minecraft Wiki*

* *追随者披风（Follower's Cape）**是一件[15周年庆](15周年庆.md)期间发放的披风。

# 外观
披风主要部分为白色的苦力怕脸图案，带有电子波纹效果，背景为深黑色，类似TikTok的图标。披风的两侧各有一条蓝色和红色的条纹边框。

# 描述
玩家可以通过兑换代码获得这件披风，代码可以通过观看任何在TikTok上的Minecraft直播获得。此活动于2024年5月15日开始，2024年5月31日结束。

根据用户所在的地区，活动还有其他要求，例如观看一定时长的视频，或需要在聊天中发送“minecraft”。

在TikTok或其奖励计划被禁止的地区，此任务无法正常完成。这些地区的玩家可以通过某种方式绕过禁令、前往未被禁止的地区，或从其他玩家处获得代码来获得披风。
