# 基岩版1.8.0.10

*页面ID: 36779* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.8.0.10**是[1.8.0](基岩版1.8.0.md)的第2个测试版，发布于2018年10月18日<ref>https://feedback.minecraft.net/hc/en-us/articles/360018040232-Minecraft-Beta-1-8-0-10-Xbox-One-Windows-10-Android-</ref>，加入了[弩](弩.md)和命令，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[弩](弩.md)**
* 比[弓](弓.md)更强，但装填速度较慢。
* 如果副手持[烟花火箭](烟花火箭.md)，主手持弩可以发射。

* *[染料](染料.md)**
* 添加了白色染料，蓝色染料，棕色染料和黑色染料。
* 原先用于染料的物品（[骨粉](骨粉.md)、[青金石](青金石.md)、[可可豆](可可豆.md)和[墨囊](墨囊.md)）仍然可以使用。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* [多重射击](多重射击.md)
* * 能同时向不同方向射三支箭，且只消耗一支箭。
* [快速装填](快速装填.md)
* * 加快装填速度。
* [穿透](穿透.md)
* * 使发射的箭穿过多个生物并造成伤害。

# = 命令 =
* ***
* 运行指定功能包内的命令。

# 更改
# = 方块 =
* *[浮冰](浮冰.md)**
* 为[浮冰](浮冰.md)加入了合成配方。

* *[脚手架](脚手架.md)**
* 加入了音效。
* 现在会被熔岩点燃。
* 玩家站在脚手架上时，在脚手架悬空状态下可以潜行了。

# = 物品 =
* *[烟花火箭](烟花火箭.md)**
* 现在能放在副手槽中。

* *[弓](弓.md)**
* 拉弦时快捷栏内会出现动画。

# = 生物 =
* *[熊猫](熊猫.md)**
* 现在能被喂食。
* 加入了额外的音效。
* 当给它食物时会坐下来吃，即使它们很生气或害怕。
* 提高了由攻击性的熊猫造成的伤害。
* 当它们的物品栏里有竹子时会掉落额外的竹子。

# = 游戏内容 =
* *[生成](生成.md)**
* 改进了重生点移动到安全位置的时机和过程。

# = 常规 =
* *[市场](市场.md)**
* 商店已购买内容现在可以用“更新可用”排序。
* 商店内容现在可以按评分排序和过滤。

* *游戏指南**
* 现在可以在“游戏指南”菜单中找到关于脚手架的信息。

# 修复
* *修复了21个漏洞**
* 修复了部分游玩时发生的崩溃。
* 修复了对刷怪笼使用部分刷怪蛋发生的崩溃。
* 修复了打开信标界面发生的崩溃。
* 修复了部分语言在加载世界或打开游戏菜单时发生的崩溃。
* 修复了鼠标移动到重命名烟花时发生的崩溃。（）
* 修复了Xbox One游客访问时启用分屏模式导致的崩溃。
* 脚手架的纹理会闪烁。
* 玩家会在潜行时卡进脚手架方块。
* 幼年熊猫现在有了空闲的声音。
* 当玩家刚从一个被封闭的空间里出来时，它们不再能放置没有充能的红石中继器或红石比较器。（）
* 在离开服务器时，附魔的三叉戟会消失。（）
* 可以复制三叉戟。（）
* 生命提升与伤害吸收效果将不再有相同的图标。
* 修复了在第一人称视角骑马跳跃时的动画。
* 修复了不使用剪刀破坏树叶时掉落树叶而不是树苗的漏洞。
* 修复了多人游戏切换中显示“禁用”选项实际上是“启用”的漏洞。
* 命令里的y轴相对坐标现在再次低于3。（）
* 使用来反向循环命令的自动补全功能时现在会正确循环到列表末端。
* 运行标题与副标题命令时现在会覆盖当前的标题。
* 附加包里的可以在组件组中使用，而不会导致游戏崩溃。</onlyinclude>
