# Java版Combat Test 5

*页面ID: 51353* | *来源: Minecraft Wiki*

}}<onlyinclude>

* *Combat Test 5**是未来的战斗改版的第5个公开的实验性版本，发布于2020年1月16日<ref></ref><ref></ref>，虽然它是未来版本的测试版，但这个战斗实验版是[Java版1.15.2-pre2](Java版1.15.2-pre2.md)的分支。此版本发布在[Reddit](wzh:Reddit.md)和[Minecraft.net](Minecraft.net.md)上，但并不出现在[启动器](启动器.md)版本列表中。

# 新内容
# = 游戏内容 =
* *战斗**
* 现在玩家瞄准实体后将激活“容错时间”（Coyote Time），可使玩家在将十字准星移开该实体后的一小段时间内发动攻击仍可对其造成伤害。

# 更改
# = 物品 =
* *[工具](工具.md)和[武器](武器.md)**
* 降低了绝大多数工具和武器的附加伤害，具体变化<ref group="注">相较以往的Combat Test版本。</ref>如下表所示：

* *[三叉戟](三叉戟.md)**
* 附加伤害由降至。

# = 非生物实体 =
* *[掷出的鸡蛋](掷出的鸡蛋.md)**
* 现在有4刻的冷却时间。

* *[雪球](雪球.md)**
* 现在可以击中玩家并对其造成击退效果。

# = 游戏内容 =
* *攻击**
* 更改了攻击动画以优化连续攻击效果。
* 将物品的基础伤害（包括空手攻击的伤害）由升至，以与[基岩版](基岩版.md)统一。

* *[饥饿](饥饿.md)**
* 移除了饱和度加速恢复生命值的特性。
* 将玩家进食的时间从延长至。
* 强化了自然恢复生命值的特性。玩家的生命值会在饥饿值大于时持续恢复（原值为）。
* 将自然恢复生命值的速度从每提升至每。
* 现在自然恢复生命值只会消耗饥饿值。
* * 饱和度不再能恢复生命值，现在只能用于延缓饥饿值的消耗。
* 现在玩家可以在任意饥饿值水平下疾跑。

* *[击退](伤害#击退.md)**
* 重新引入了攻击悬空的实体时产生的向高处击退的效果。
* 实体现在受到伤害小于的攻击（包括不造成伤害的攻击）时也会被击退了。
