# Java版Indev 0.31 20091231-2147

*页面ID: 171784* | *来源: Minecraft Wiki*

<onlyinclude>
* *0.31**的一个版本发布于2009年12月31日21:47（UTC）<ref name="time">[Adura的IRC记录](#logs.md): "*P4:57:30 <�08Notch�> It's up! It's done!*" (22:57 UTC)</ref>，加入了一些物品。<ref></ref><ref name=newyear></ref>

# 新内容
# = 物品 =
* *[盔甲](盔甲.md)**
* 加入了布甲、皮革链甲、锁链盔甲和铁盔甲。
* * 目前没有实际用途。

* *[锹](锹.md)**
* 加入了铁锹。
* * 目前没有实际用途。

* *[剑](剑.md)**
* 加入了铁剑。
* * 用于对生物造成额外伤害。

* *[箭袋](箭袋.md)**
* 目前没有实际用途。

* *[苹果](苹果.md)**
* 目前没有实际用途。

* *常规**
* 加入了没有用途的非[方块](方块.md)物品。
* * 拿在手上时显示为2D模型。<ref name=newyear/><ref></ref>

# = 非生物实体 =
* *[掉落物](掉落物.md)**
* 现在不会旋转也不会闪烁。

* *激活的[TNT](TNT.md)**
* 由TNT生成，期间会闪烁，最后形成[爆炸](爆炸.md)。

# = 常规 =
* *[控制](控制.md)**
* 现在又可以按丢弃物品了。

# 更改
# = 物品 =
* *[蘑菇](蘑菇.md)**
* 现在不能食用了。

# = 游戏内容 =
* *[平视显示器](平视显示器.md)**
* 快捷栏中现在只包含99个[TNT](TNT.md)和99个[书架](书架.md)。

* *常规**
* [玩家](玩家.md)出生时会携带所有物品。</onlyinclude>
