# 基岩版1.19.40

*页面ID: 98455* | *来源: Minecraft Wiki*

* *1.19.40**是的一次次要更新，发布于2022年10月25日<ref></ref>。此次更新同步了一些的特性，更新了触摸控制，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 加入了被重命名后的物品杀死时出现的死亡消息：
* * “<玩家> 被 <玩家/生物> 用 <物品> 杀死了”

# 更改
# = 方块 =
* *[甜浆果丛](甜浆果丛.md)**
* 现在可以种植在[耕地](耕地.md)上。

* *[脚手架](脚手架.md)**
* 现在每个脚手架只能烧炼0.25个物品。

# = 生物 =
* *[劫掠兽](劫掠兽.md)**
* 不再属于[灾厄村民](灾厄村民.md)。
* * 因此现在会受到[唤魔者尖牙](唤魔者尖牙.md)造成的伤害，且[“Johnny”卫道士](卫道士#“Johnny”卫道士.md)现在会主动攻击劫掠兽。
* 增大了碰撞箱以匹配。

* *[凋灵骷髅](凋灵骷髅.md)**
* 现在能够在[凋灵玫瑰](凋灵玫瑰.md)中生成。

* *[村民](村民.md)**
* 图书管理员村民现在能够出售[消失诅咒](消失诅咒.md)和[绑定诅咒](绑定诅咒.md)附魔书。

# = 游戏内容 =
* *[双持](双持.md)**
* 现在可以使用命令将任意物品放进副手槽里，且部分物品可以像在主手时那样正常交互。

* *[配方](配方.md)**
* 现在合成配方中的同类合成材料可以任意混合（如使用[圆石](圆石.md)和[黑石](黑石.md)合成[石剑](石剑.md)）。
