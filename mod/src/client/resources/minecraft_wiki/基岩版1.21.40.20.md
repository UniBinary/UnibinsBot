# 基岩版1.21.40.20

*页面ID: 125836* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.40.20**（ChromeOS/Android）、**Preview 1.21.40.20**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.40](基岩版1.21.40.md)的首个测试版，发布于2024年9月4日<ref></ref>，同步了一些的特性，在[实验性玩法](实验性玩法.md)中对[收纳袋](收纳袋.md)作出了一些调整，并修复了一些漏洞。

# 更改
# = 方块 =
* *[蜂巢](蜂巢（方块）.md)和[蜂箱](蜂箱.md)**
* 不再可以用作燃料。

* *[生物头颅](生物头颅.md)**
* ID现在被拆分为。
* * 及其数据值仍然可用，但不会在命令提示中出现。

* *[蘑菇柄](蘑菇柄.md)**
* 现在是独立的方块，ID为，并且不再是[红色蘑菇方块](红色蘑菇方块.md)和[棕色蘑菇方块](棕色蘑菇方块.md)的变种。
* 使[堆肥](堆肥.md)层数增加一层的概率由85%降低至65%。

# = 物品 =
* *[附魔金苹果](附魔金苹果.md)**
* 食用后给予的[生命恢复](生命恢复.md)效果等级由V降低至II。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 现在被[沼骸](沼骸.md)杀死时会掉落[音乐唱片](音乐唱片.md)。

* *[猪灵](猪灵.md)**
* 不再会捡起和端详[动力铁轨](动力铁轨.md)。

* *[北极熊](北极熊.md)**
* 现在[着火](着火.md)时死亡会掉落[熟鳕鱼](熟鳕鱼.md)和[熟鲑鱼](熟鲑鱼.md)，而非[生鳕鱼](生鳕鱼.md)和[生鲑鱼](生鲑鱼.md)。

* 在末地城附近加载世界时，游戏不再会崩溃。

# 修复
* *常规**
* 在Nintendo Switch平台上作出了更改，这可能在玩家已设置最大帧数时有助于相邻区块更快加载。（）

* *方块**
* 现在使用命令放置的藤蔓是可见的。（）

* *命令**
* 游戏规则不再被视为作弊内容。（）

* *游戏内容**
* 现在风弹被投掷后会短暂地无法被击中和改变方向。
* 现在无论附近是否有敌对生物，与床进行交互时都会设置重生点。（）
* 现在玩家撞到生成世界的边缘时会保持其速度。例如：使用鞘翅滑翔时，玩家会保持浮空状态，而非立即丢失所有速度。

* *图形**
* 解决了在iOS平台上使用超大号缩放时游戏会显示粉红色的问题。（、）

* *生物**
* 现在北极熊被火或熔岩杀死时会掉落熟鱼。（）
* 掠夺者的音效现在会正常播放。（）
* 现在尝试追随主人的狼、猫和鹦鹉会在传送到主人附近时无缝恢复寻路。
* 现在狼、猫和鹦鹉惊慌且距离主人足够远时会传送至主人附近。
* 现在狼会在战斗且距离主人足够远时传送至主人附近，以防止被主人落下。（）
* 猪灵不再会捡起和端详动力铁轨。（）

* *Realms**
* 修复了无法通过市场来激活Realm的附加包的漏洞。

* *用户界面**
* 切换维度并重新进入世界时不再会显示脱离实体相关的提示。（）
* 盔甲HUD现在会在玩家装备的盔甲损坏时正确更新。（）
* 修复了使用控制器时切石机面板中的关闭按钮子面板会显示为空白，而不是被隐藏起来的漏洞。
* 加入了用于市场模板在特定平台上不可用时进行解释的消息。
* 现在在移动设备上使用经典UI时，饥饿条和生命条会与经验条对齐。（）
* 氧气条现在会与饥饿条正确对齐。（）
* 现在携带版和经典UI设置下的UI中的玩家纸娃娃的位置是一致的。（）
* 现在带有基于百分比的效果的药水会在其（在移动设备上的）提示框中正确显示百分比符号。（）
* 现在当玩家被守卫者的尖-{}-刺杀死时，死亡消息会显示为：“”。（）
* 多条聊天消息不再会互相重叠一个像素。（）
* 看向不可交互的实体时，物品文本不再会跳动。（）
* 将锻造台和织布机的关闭和帮助按钮的视觉效果更改为与制图台相匹配的视觉效果。（）
* “隐藏控制器提示”现在会正确隐藏村民交易菜单中的所有控制提示。（）

* *原版趋同**
* 现在苦力怕被沼骸杀死时会掉落音乐唱片。（）
* 现在沼骸被玩家驯服的生物杀死时会掉落剧毒之箭。
* 现在给绵羊以及猫和狼的项圈染色时会播放与Java版相同的染色音效。（）
* 对堆肥桶使用蘑菇柄时的堆肥层数增加概率由85%调整为65%。
* 移除了创造模式物品栏中所有面皆为气孔的蘑菇方块。
* 附魔金苹果现在会给予生命恢复II，而不是生命恢复V，以匹配Java版。（）
* 现在放置可可豆时会播放音效。（）
* 蜂巢和蜂箱不再可以用作熔炉的燃料。（）</onlyinclude>
