* *Combat Test 8**是未来的战斗改版的一个秘密的实验性版本。此版本是[Java版1.16.2](Java版1.16.2.md)的分支。

# 更改
# = 物品 =
* *[箭](箭.md)**
* 药箭上的瞬间状态效果的实际效果现在被缩放到了，与其他效果的时间缩放保持一致。

* *[弓](弓.md)**
* 再次加入了长时间拉弓会导致精准度降低（拉弓疲劳）的特性，但只会在拉弓超过3秒后发动。拉弓疲劳也会抵消掉[箭](箭.md)的“[暴击伤害](弓#武器.md)”这一特性。

* *[药水](药水.md)**
* I/II的攻击力加成由+3/+6更改为+20%/+40%。
* 每等级恢复的生命值由提升至。
* 饮用药水的耗时由32刻缩短至20刻。

# = 游戏内容 =
* *[饥饿](饥饿.md)**
* 再次加入了玩家受到来自[玩家](玩家.md)或[生物](生物.md)的攻击会使进食中断这一特性，这同样适用于饮用（比如药水）。
* 将进食[谜之炖菜](谜之炖菜.md)、[蘑菇煲](蘑菇煲.md)、[兔肉煲](兔肉煲.md)、[甜菜汤](甜菜汤.md)、[蜂蜜](蜂蜜.md)和[奶](奶.md)的耗时由32刻或40刻缩短至20刻。

* *[魔咒](魔咒.md)**
* 现在在计算[状态效果](状态效果.md)和[暴击](暴击.md)造成的伤害时，武器[魔咒](魔咒.md)的加成会包含在基础攻击内了（即在武器的基础攻击力和魔咒的加成的基础上再计算状态效果等的伤害）。

# 修复
* *上个开发版本的漏洞**
* 再次修复了盾牌保护范围的弧线的漏洞。
* 改进了服务端对于攻击范围的计算。</onlyinclude>

# 你知道吗
* 此版本有着与[Combat Test 8b](Java版Combat Test 8b.md)和[Combat Test 8c](Java版Combat Test 8c.md)相同的协议版本，这意味着它们的客户端和服务器版本彼此兼容。拥有同样协议版本的开发版十分罕见。
