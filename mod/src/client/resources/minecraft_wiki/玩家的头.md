# 玩家的头

*页面ID: 163404* | *来源: Minecraft Wiki*

* *玩家的头（Player Head）**是一种[生物头颅](生物头颅.md)。

# 生成
玩家的头不会生成在世界中。

# 获取

玩家的头无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，玩家的头可以通过”，或“”中有玩家的头）|JE}}、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
没有工具可以加速对玩家的头的挖掘。

玩家的头被破坏后会掉落自身。

被爆炸破坏的玩家的头总是会掉落。

# 用途
玩家的头会被液体破坏。

# = 装饰 =
玩家的头被放置在方块顶面时可以呈16种不同的方向，而放置在方块侧面时可以呈4种不同的方向。玩家的头不需要方块支撑，且可以放置在其他头颅的上方或侧边。

# = 穿戴 =
玩家能将玩家的头装备在头盔槽位。[发射器](发射器.md)也可以将玩家的头装备给没有头戴物品的玩家、[盔甲架](盔甲架.md)和一些人-{}-形生物，且其必须恰好位于发射器前的方块内。

当玩家的头戴在玩家头上时，玩家的头的纹理将会覆盖玩家头部的第二层纹理。

# = 伪装 =
[多人游戏](多人游戏.md)中，穿戴玩家的头的玩家不会在[定位栏](定位栏.md)上显示。

穿戴任意种类头颅的玩家不会出现在其他玩家的定位器[地图](地图.md)上。

若[音符盒](音符盒.md)顶面上放置了玩家的头，则会播放中设置的音效（默认为空）。

# 玩家皮肤

玩家的头可以添加特定的[物品堆叠组件](物品堆叠组件.md)让它显示任何Minecraft正版玩家的皮肤。这意味着如果你想要获得某个人的头，你可以通过修改NBT数据获得它。

[缩略图|右|300px|所有由Mojang提供的MHF生物头颅](File:Allmobheads.png.md)

Mojang创建了一些存有特定皮肤的账户，因此地图创建者们可以直接使用公用头颅而无需担心某位玩家会在某一天里更换了他自己的皮肤。<ref></ref>这些账户的玩家名格式均为<code>-{}-MHF_<*名称*></code>，举个例子，<code>MHF_PigZombie</code>对应的是带有[下界更新](下界更新.md)前[僵尸猪人](僵尸猪人.md)皮肤的Minecraft玩家。MHF的意思是“Marc的头颅格式”（"Marc's Head Format"）。为保证多样化，它们还有一些方块和“额外”头颅。
