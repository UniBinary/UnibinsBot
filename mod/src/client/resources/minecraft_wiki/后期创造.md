# 后期创造

*页面ID: 35227* | *来源: Minecraft Wiki*

* *后期创造（Late Creative）**指的是发布于2009年10月27日至11月10日的**[Classic](Java版Classic.md)**的六个版本。这些版本大多数与[生存测试](生存测试.md)重叠，因为此时Notch会同时在创造和生存模式中发布更新。

# 新内容
# = 常规 =
; [控制](控制.md)
* 左键移除方块。
* 右键放置方块。
; 多人游戏
* 当玩家们站在一起时，他们会互相碰撞。
; [选项](选项.md)
* 加入了切换下雨的开关。
; [Server.properties](Server.properties.md)
* 加入了树生长的开关。
; [动态照明](亮度.md)
* 加入了动态照明系统。

# 更改
# = 常规 =
;[多人游戏](多人游戏.md)
* 对玩家给予/撤销权限会立即进行更改，而不必重新加载。
* 被玩家挡着的方块依然可以进行互动。
* 玩家名字不会出现在玩家的头顶除非鼠标在对准他们。

# = 方块 =
;[TNT](TNT.md)
* 此时还不会爆炸。

# = 生物 =
* 移除了所有生物。

# = 物品 =
;[箭](箭.md)
* 移除了箭。
