# Java版14w26c

*页面ID: 33159* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w26c**是[Java版1.8](Java版1.8.md)的第31个快照，发布于2014年6月26日<ref name="blogpost_14w26c"></ref>，修复了快照[14w26a](14w26a.md)和[14w26b](14w26b.md)中的一些漏洞和一个主要的世界保存损坏的问题。

# 更改
# = 方块 =
* *[干草捆](干草捆.md)**
* 重新平衡了它们治疗和加速[马](马.md)的生长的速度。

* *[南瓜灯](南瓜灯.md)**
* 不再能用于制造傀儡。

# = 生物 =
* *[村民](村民.md)**
* 现在有一个可以放置盔甲和方块的头部物品栏，可通过使用命令放置。

# = 常规 =
* *[方块模型](方块模型.md)**
* 物品可以在文件中指定旋转和转译。

# 修复
生成带有自定义非玩家头颅的僵尸会显示为奇怪的灰色纹理。
|59092|半格向日葵。
|59344|下界传送门生成在空中。
