* *铜链（Copper Chain）**是一种金属装饰性方块。

# 生成
铜链不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘铜链的合适工具是镐。铜链需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

铜链被破坏后会掉落自身。

# 用途
铜链不需要任何用于支撑的方块即可放置，即使周围没有方块也可以完全独立存在。铜链能够水平或垂直放置，但不会像[铁栏杆](铁栏杆.md)一样在不同水平方向相交时形成转角。

若下方依附有[铜灯笼](铜灯笼.md)，铜链的纹理会与其无缝连接。

# = 氧化 =

铜链受氧化机制影响，能够在不同变种之间转化。
