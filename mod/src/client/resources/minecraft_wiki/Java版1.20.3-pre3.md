# Java版1.20.3-pre3

*页面ID: 108744* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.20.3-pre3**是[Java版1.20.3](Java版1.20.3.md)的第3个预发布版，发布于2023年11月27日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *[资源包](资源包.md)**
* 现在缓存的服务器资源包最多只保留20个。
* 现在客户端会在下载资源包时向服务器发送额外，包含资源包相关信息。

# 更改（实验性）
# = 方块 =
* *[铜门](铜门.md)及其所有变种**
* 略微更改了下半部分的纹理。
* 现在合适挖掘工具是[镐](镐.md)。

# = 常规 =
* *[标签](Java版标签.md)**
* 向物品标签中加入了。
* 向物品标签中加入了。
* 从中移除了。
