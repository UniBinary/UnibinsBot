* *气泡柱（Bubble Column）**是一种在[水源](水源.md)中由[岩浆块](岩浆块.md)或[灵魂沙](灵魂沙.md)生成的方块，分别能将[实体](实体.md)向下拉或向上推。

# 生成
# = 自然生成 =
当世界生成时，初始没有任何气泡柱。

一些[洞穴](洞穴.md)、[峡谷](峡谷.md)、[海底废墟](海底废墟.md)和[废弃传送门](废弃传送门.md)会生成在水面以下。当[熔岩](熔岩.md)随之生成在这些地方时，一些熔岩会转变成[黑曜石](黑曜石.md)，另一些会转变成产生气泡柱的[岩浆块](岩浆块.md)。随着海床上的废弃传送门一并生成的熔岩总是会转变成岩浆块。

气泡柱也可以随[水下岩浆块](水下岩浆块.md)而生成。

# = 人工制造 =
当在水源下放置[灵魂沙](灵魂沙.md)时，会产生涌流气泡柱。

当在水源下放置[岩浆块](岩浆块.md)时，会产生涡流气泡柱。

气泡柱在向上延伸的过程中会在抵达非[水源](水源.md)方块后停止延伸。因此如果玩家想制造气泡柱，需要在灵魂沙或岩浆块上方的每一格都放置水源（也可在向下水流中种满[海带](海带.md)再移除），直至理想高度。

# 获取
气泡柱没有对应的物品形式。

气泡柱的物品形式只能通过编辑物品栏获得。

# 破坏
气泡柱没有[轮廓箱](轮廓箱.md)，因此不能挖掘气泡柱。

气泡柱被破坏后不会掉落。

# 用途
当被[活塞](活塞.md)推动时，气泡柱会被破坏并消失。<ref></ref>

# = 呼吸 =

在空气中呼吸的生物可以在气泡柱中呼吸。在水中呼吸的生物无法在气泡柱中呼吸，并且会避开气泡柱。

# = 涡流 =
[thumb|水下产生的气泡柱，左侧为涡流，右侧为涌流](File:Underwaterbubbles.png.md)
将[岩浆块](岩浆块.md)放置在水源下方时，会产生垂直下降的气泡，这就是涡流。
* 涡流会将[实体](实体.md)向下推动。
* * 实体在涡流中的平衡运动速度约为每秒或格。
* 乘[船](船.md)通过涡流时，船会开始摇晃，船持续位于涡流上方3秒后会沉没，并令所有乘客下船。

# = 涌流 =
将[灵魂沙](灵魂沙.md)放置在水源下方时，会产生垂直上升的气泡，这就是涌流。
* 涌流会将实体向上推动。实体被推动的时间越长，速度越快，有时能被推出水面上方几格高的地方。
* * 实体在涌流中的平衡运动速度约为每秒或格。
* 玩家在涌流顶部跳跃时会被向上推起大约1格。

# 你知道吗
* 现实中的海洋气泡柱也确实生成于熔岩裂口和深峡谷、海沟中，然而不同的是熔岩裂口几乎都是喷发上升气泡涌流，而海沟则根据板块运动推挤变化涌流或涡流气泡。
* 与其他实体一致，[下落的方块](下落的方块.md)（[雪](雪.md)和[滴水石锥](滴水石锥.md)除外）也能被涌流气泡柱向上推，导致这些方块在水体顶部上下浮动。
* 玩家通过编辑物品栏获得的气泡柱可以放置，但除非放置时四面都有固体方块并且在[灵魂沙](灵魂沙.md)或[岩浆块](岩浆块.md)上，否则放置后会立刻消失。
* 如果把物品形式的气泡柱放进[物品展示框](物品展示框.md)里，气泡柱会变为静态，纹理的尺寸也会微微放大，乃至接触或超出物品展示框的边缘。
* 对着含水气泡柱之中的水使用[细雪桶](细雪桶.md)放置细雪，气泡柱仍会生效，且该细雪在产生气泡柱的方块被移除前无法使用[铁桶](铁桶.md)回收，并可以被方块替换。<ref></ref>
