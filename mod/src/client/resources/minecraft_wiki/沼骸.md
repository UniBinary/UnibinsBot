* *沼骸（Bogged）**是生成于沼泽中的[骷髅](骷髅.md)变种。

# 生成
# = 自然生成 =
沼骸自然生成于[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)生物群系，代替30%的[骷髅](骷髅.md)生成。

[蜘蛛](蜘蛛.md)和[洞穴蜘蛛](洞穴蜘蛛.md)在沼泽和红树林沼泽生成时有0.8%的概率生成为[沼骸蜘蛛骑士](蜘蛛骑士.md)。

# = 试炼刷怪笼 =
[试炼密室](试炼密室.md)中的远程型[试炼刷怪笼](试炼刷怪笼.md)包含沼骸试炼刷怪笼。

# = 万圣节 =

在[万圣夜](wzh:万圣夜.md)（10月31日）当天，沼骸在生成时有22.5%的概率戴着[雕刻南瓜](雕刻南瓜.md)，2.5%的概率戴着[南瓜灯](南瓜灯.md)，但雕刻南瓜或南瓜灯不会掉落。<ref></ref>

# 行为

沼骸的行为与[骷髅](骷髅.md)大致相同，不同的是，沼骸会发射或，会对其击中的目标造成4秒[中毒](中毒.md)I。沼骸在水下进行攻击时不会射箭，且其使用的近战攻击不会对目标施加中毒效果。

沼骸的攻击冷却时间在简单和普通难度中为，在困难难度中为；沼骸射箭时的攻击冷却时间固定为。

被沼骸杀死的[苦力怕](苦力怕.md)会额外掉落一张*[13](音乐唱片13.md)*、*[cat](音乐唱片cat.md)*、*[blocks](音乐唱片blocks.md)*、*[chirp](音乐唱片chirp.md)*、*[far](音乐唱片far.md)*、*[mall](音乐唱片mall.md)*、*[mellohi](音乐唱片mellohi.md)*、*[stal](音乐唱片stal.md)*、*[strad](音乐唱片strad.md)*、*[ward](音乐唱片ward.md)*、*[11](音乐唱片11.md)*或*[wait](音乐唱片wait.md)*[音乐唱片](音乐唱片.md)。

沼骸像[流浪者](流浪者.md)一样免疫[细雪](细雪.md)的冰冻伤害。

# = 生物族群 =

沼骸是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉到水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

沼骸会在阳光下[着火](着火.md)，未戴头盔或生物头颅的沼骸会寻找阴凉处、水域以及来避免着火。
