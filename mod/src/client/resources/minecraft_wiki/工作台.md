# 工作台

*页面ID: 6197* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *工作台（Crafting Table）**是一种用于合成[配方](合成配方.md)更复杂的[物品](物品.md)的方块。

# 生成
# = 自然生成 =
工作台自然生成于下列结构中：
* [沼泽小屋](沼泽小屋.md)
* [雪屋](雪屋.md)
* [村庄](村庄.md)里的
* [掠夺者前哨站](掠夺者前哨站.md)外的[羊毛帐篷](掠夺者前哨站/结构#帐篷1.md)
* [古迹废墟](古迹废墟.md)里的部分结构
* [试炼密室](试炼密室.md)的休息室

# 获取
# = 合成 =
玩家加入游戏时会立刻解锁工作台的合成配方。

# 破坏
挖掘工作台的合适工具是斧。

工作台被破坏后会掉落自身。

# 用途
# = 合成 =

放置在世界中的工作台会打开工作台的3×3的合成方格，比[物品栏](物品栏.md)的2×2的合成方格更大，能让玩家合成更多的物品。

与物品栏里的合成方格一样，在工作台的合成方格的左边，也有存储了可用的[合成配方](合成配方.md)并可进行一键合成的[配方书](配方书.md)（默认折叠）。

# = 合成材料 =

# = 燃料 =

工作台可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个工作台能烧炼1.5个物品。

# 你知道吗

[thumb|100px|right|alt=Java版原始的工作台图标|客户端的旧图标](File:Java Edition icon 1.png.md)
* 从[Java版1.6.1](Java版1.6.1.md)开始，Java版客户端的旧图标一直是工作台。
* * 在此之前，客户端图标是Java的图标。
* * [1.6.2](Java版1.6.2.md)的客户端图标被意外显示为LWJGL 2的缺省图标，类似于RubyDung中的版本。1.6.2后，图标被恢复。
* * 2023年6月7日，随着[1.20](Java版1.20.md)的发布，[15w43a](15w43a.md)及以上所有版本的图标都被更新为风格化的草方块图标。
* 在2010年1月29日前，最早的物品栏界面是工作台的，这意味着那时无法穿上[盔甲](盔甲.md)，且玩家不能看到自己的形象。
* 尽管工作台的原文在早期版本里就已经重命名为“Crafting Table”，仍有不少语言（包括中文在内）将其视为“Workbench”并加以翻译。
