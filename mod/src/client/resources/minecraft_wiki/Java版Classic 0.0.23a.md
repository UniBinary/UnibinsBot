# Java版Classic 0.0.23a

*页面ID: 35514* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.23a**是的一次更新，发布于2009年7月11日<ref></ref><ref>[IRC 记录](#logs.md): "*A9:16:20 * Notch changes topic to 'http://www.minecraft.net | Client 0.0.23a is out with new options and the ability to remap keys*" (14:16:20 UTC)</ref>，加入了自定义[控制](控制.md)。

# 新内容
# = 常规 =
* *[选项](选项.md)**
* 现在可以自定义[控制](控制.md)。<ref name="options">[IRC记录](#logs.md): "*A9:16:30 <Rock_D> huh, options?*", "*A9:16:39 <Adura> Via Esc*" [...] "*A9:28:01 <CheeToS> I like the new esc menu buttons*" (14:16至14:28 UTC)</ref>
* 现在关闭声音和音乐的选项分离。

* *[控制](控制.md)**
* 控制方式可以通过按下键打开的[暂停菜单](暂停菜单.md)来修改。<ref name="options"/><ref>[IRC记录](#logs.md): "*A9:16:47 <PuyoDead> hey, I like the new buttons*" (14:16:47 UTC)</ref>
* [玩家](玩家.md)不再默认能够通过方向键来控制移动。
* 按下键不再切换渲染距离，<ref>[IRC记录](#logs.md): "*A9:21:23 <PuyoDead> wait, does F still do that as well?*" [...] "*A9:21:32 <CheeToS> PuyoDead: no*" [...] "*A9:22:36 <PuyoDead> awwww... I really, REALLY needed that key for render distance.*" (14:20至14:22 UTC)</ref>因为它被设置为一个选项。<ref>[IRC记录](#logs.md): "*A9:20:06 <CheeToS> Notch: aw man, you removed the varying render distances? I found it EXTREMELY useful :\*" [...] "*A9:20:18 <08Notch> no, it's still there!*" [...] "*A9:20:26 <08Notch> under options, though*" (14:20 UTC)</ref>

* *其他**
* FPS计数器被移除，除非选项“Show FPS”（显示FPS）被设置。<ref>[IRC记录](#logs.md): "*A10:37:40 <Quatroking> where's my FPS counter*", "*A10:37:46 <citricsquid> escape > options*" (15:37:40 UTC)</ref>
* 在Tab菜单中点击玩家的名字可以将其粘贴到聊天中。<ref></ref>

# 更改
# = 方块 =
* *[水](水.md)和[熔岩](熔岩.md)**
* [沙子](沙子.md)和[沙砾](沙砾.md)不再会将水和熔岩视作固体方块并下落到其上方。
* * 现在会穿过液体下落，之后液体会替换它们被放置的位置。
* 除了更新时会流动，其他时候保持静止。

# = 游戏内容 =
* *[暂停菜单](暂停菜单.md)**
* 修改了按键纹理。

# = 常规 =
* *[控制](控制.md)**
* 不能再通过按下键跳跃。</onlyinclude>
