# 基岩版1.4.3

*页面ID: 34876* | *来源: Minecraft Wiki*

* *1.4.3**是的一次热修复更新，仅在iOS平台上发布于2018年6月5日<ref></ref>，修复了一个漏洞。此版本与[1.4.2](基岩版1.4.2.md)相互兼容。

# 修复
* *修复了1个漏洞**
* 修复了未成年账户不能通过LAN联机的漏洞。<ref>https://www.reddit.com/r/MCPE/comments/8owtn2/two_new_changelogs_ios_143_and_nintendo_3ds_15/</ref>

# 你知道吗
* 此次更新没有修改任何源代码。据[HelenAngel](HelenAngel.md)称，此版本主要是为了宣传基岩版[商城](商城.md)的新地图“王国生存”在iOS上的限时免费活动。<ref>HelenAngel在英文Minecraft Wiki Discord上的发言：“FYI - The iOS update today had no code changes whatsoever. We just revved the version number so I could publish patch notes to iOS players to tell them about the free map for a month.”</ref>
