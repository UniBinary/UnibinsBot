* *强壮根茎（Strong Roots）**是由[强力马铃薯](强力马铃薯.md)生长出的[方块](方块.md)。

# 生成
# = 自然生成 =
强壮根茎会自然生成于[马铃薯村庄](马铃薯村庄.md)中。

# = 强力马铃薯 =
[强力马铃薯](强力马铃薯.md)会逐渐向侧面和下方生长出相连的强壮根茎，强壮根茎生成时可以替换该位置原有的方块（基岩和其他强力马铃薯除外）生成。

# 获取
强壮根茎不能在生存模式中正常获得，但可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)获得。

# 破坏
没有工具可以加速对强壮根茎的挖掘。

强壮根茎被破坏后不会掉落。

# 用途
# = 破坏方块 =
强壮根茎在生成时会破坏该位置原有的方块（基岩和其他强力马铃薯除外），并在其相连的强力马铃薯周围产生被替换方块的掉落物，相当于玩家使用合适工具破坏方块。
