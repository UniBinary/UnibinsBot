# Samuel Åberg

*页面ID: 48725* | *来源: Minecraft Wiki*

* *萨穆埃尔·奥贝-{里}-（Samuel Åberg）**在[Mojang Studios](Mojang Studios.md)担任工作室音频总监，他于2015年加入Mojang。

# 参与制作的游戏原声集
* *[Minecraft: The Wild Update (Original Game Soundtrack)](Minecraft: The Wild Update (Original Game Soundtrack).md)*（2022年4月20日）

# 你知道吗
* 为了制作游戏中[海豚](海豚.md)<ref name="D"></ref>和[熊猫](熊猫.md)<ref></ref>的音效，他前往了[科尔莫登野生动物园](Wikipedia:Kolmården Wildlife Park.md)（Kolmården Wildlife Park）和[长隆野生动物世界](wzh:長隆野生動物世界.md)。
* Samuel Åberg在[Java版1.9-pre3](Java版1.9-pre3#更改.md)后被列入[鸣谢名单](鸣谢名单.md)的“音乐与音效”下。
