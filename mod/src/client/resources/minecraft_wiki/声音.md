# 声音

*页面ID: 173081* | *来源: Minecraft Wiki*

* *声音（Sound）**主要用于为游戏提供背景氛围，其也可作为信息源指示世界的变化。

# 机制
游戏会在特定场景中播放声音。例如石头被破坏时，游戏会播放石头的破坏音效；玩家在一些生物群系中时，游戏会播放此生物群系独有的[音乐](音乐.md)。

声音播放也可以由命令控制，可以主动播放一条声音，可以主动中止声音播放。

游戏播放声音时并不是简单地播放声音文件，而是构建声音实例播放声音。每个声音实例都包括调用的声音事件、播放位置、音量、音高和声音分类等属性。

绝大多数声音都以声音来源为播放位置，且最多传播16格。以下为常见的例外：
* 游戏背景声音，只给特定的玩家播放，每个玩家接收到的声音不同。
* [音符盒](音符盒.md)激活时的音效，默认传播48格。
* [唱片机](唱片机.md)的音乐，默认传播64格。
* [山羊角](山羊角.md)吹奏的音效，默认传播256格。
* 全局声音事件，这些声音向所有玩家播放。可以通过游戏规则来控制。
* * [末影龙](末影龙.md)死亡声音。
* * [凋灵](凋灵.md)召唤声音。
* * [末地传送门](末地传送门.md)激活声音。

关于声音实例的详细信息，可参见。

每个玩家最多可以接收255条声音，其中常规声音上限247条，流式播放声音上限8条，具体的数据可以在[调试屏幕](调试屏幕.md)的<code>sound_mood</code>选项中查看。每个玩家最多可以接收32条声音。<ref></ref>

# 声音分类
* *声音分类（Sound Source/Sound Category）**控制了声音播放的分类，以归入[选项](选项.md)中的音量控制。

# = 实体依赖分类 =

声音事件定义直接定义了声音分类。声音事件定义不会定义声音分类，游戏会根据播放场景选择声音分类。这使得同一个声音事件在不同的场景下会使用不同的声音分类，此现象经常出现在与实体相关联的声音上。

以方块的踩踏音效为例，它是一个典型的依赖于来源实体的声音。当玩家踩踏石头时，声音分类为；而当僵尸踩踏石头时，声音分类为。而它的声音分类永远是玩家。

# 字幕

部分声音具有字幕，当游戏播放这个声音的时候，屏幕上会显示此声音的字幕以及大致方位。字幕可通过选项“”来启用。
