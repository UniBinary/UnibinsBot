# Minecraft x Higround

*页面ID: 120458* | *来源: Minecraft Wiki*

[thumb|系列所有商品的概览图](File:Higround Merchandise Overview.png.md)
* *Minecraft x Higround**是[Minecraft](Minecraft.md)与Higround合作推出的一系列周边商品。<ref></ref><ref></ref>于[15周年庆](15周年庆.md)期间公布，并于太平洋时间（UTC-8）2024年5月29日中午12时限量发售。

# 键盘
[thumb|所有Minecraft x Higround键盘](File:Higround Keyboards.jpg.md)
系列中包含6种样式的键盘。

# 鼠标垫
[thumb|所有Minecraft x Higround鼠标垫](File:Higround Mousepads.jpg.md)
系列中包含5种样式的鼠标垫。

# 其他商品
