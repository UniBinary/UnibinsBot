# 盛开的杜鹃花丛

*页面ID: 171893* | *来源: Minecraft Wiki*

* *盛开的杜鹃花丛（Flowering Azalea）**是外观遍布花朵的[杜鹃花丛](杜鹃花丛.md)，具有许多[花](花.md)的性质。

# 生成
# = 自然生成 =
盛开的杜鹃花丛会自然生成于[繁茂洞穴](繁茂洞穴.md)中。

# = 骨粉 =
若一个上方为空气的[苔藓块](苔藓块.md)周围的方块是[草方块](草方块.md)、[砂土](砂土.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[沙子](沙子.md)、[沙砾](沙砾.md)、[石头](石头.md)、[花岗岩](花岗岩.md)、[闪长岩](闪长岩.md)、[安山岩](安山岩.md)、[黏土](黏土.md)、[深板岩](深板岩.md)、[苍白苔藓块](苍白苔藓块.md)或其他苔藓块，且这些方块上方为空气，对着该苔藓块骨粉有概率使其7×11×7格的范围内出现一些盛开的杜鹃花丛。

# 获取
# = 杜鹃树叶 =
当[盛开的杜鹃树叶](盛开的杜鹃树叶.md)被破坏或枯萎时，有5%的概率掉落盛开的杜鹃花丛。使用具有[时运](时运.md)I、II、III魔咒的工具破坏时掉落的概率分别为6.25%、8.33%和10%。

# 破坏
盛开的杜鹃花丛被挖掘时会立刻被破坏。

盛开的杜鹃花丛被破坏后会掉落自身。

# 用途
盛开的杜鹃花丛只能放置在草方块、[菌丝体](菌丝体.md)、灰化土、泥土、[缠根泥土](缠根泥土.md)、砂土、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、苔藓块、苍白苔藓块、黏土上或[花盆](花盆.md)里。

若活塞头推入其位置或[活塞](活塞.md)将方块推入其位置，盛开的杜鹃花丛会被破坏并掉落。

盛开的杜鹃花丛可[含水](含水.md)。<ref></ref>

[液体](液体.md)在水平流动时能破坏路径上的盛开的杜鹃花丛，但在竖直流动时无法破坏路径上的盛开的杜鹃花丛。

# = 种植杜鹃树 =
与[树苗](树苗.md)不同，盛开的杜鹃花丛不会自然生长为杜鹃树。

对上方存在至少3×5×3的空间的盛开的杜鹃花丛骨粉可以使其生长为杜鹃树，并将其下方1格的方块转变为[缠根泥土](缠根泥土.md)。

# = 堆肥 =
将盛开的杜鹃花丛放进堆肥桶有85%的概率使堆肥层数加1。

# = 燃料 =
盛开的杜鹃花丛可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个盛开的杜鹃花丛可烧炼0.5个物品。

# = 蜜蜂 =

[蜜蜂](蜜蜂.md)会将盛开的杜鹃花丛视为花。因此盛开的杜鹃花丛可用于吸引、繁殖蜜蜂以及加速幼年蜜蜂的成长，蜜蜂也会采集它的花粉。

# = 生成蜂巢 =

若橡树、白桦和樱花[树苗](树苗.md)水平2格范围内存在盛开的杜鹃花丛，则该树苗长成的树会有5%的概率悬挂着[蜂巢](蜂巢（方块）.md)，每个由此生成的蜂巢都会容纳1-3只蜜蜂。
