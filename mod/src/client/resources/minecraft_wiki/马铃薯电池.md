* *马铃薯电池（Potato Battery）**是能发出红石信号并对上方的生物造成伤害的[方块](方块.md)。

# 生成
马铃薯电池不会生成在世界中。

# 获取
# = 合成 =


# 破坏
没有工具能够加速对马铃薯电池的挖掘。

马铃薯电池被破坏后会掉落自身。

# 用途
# = 红石元件 =

对马铃薯电池按下可以切换开关状态，马铃薯电池被激活后会：
* 激活任何毗邻的红石线并改变其指向，包括它上面的和下面的红石线（但不会更改指向），向其[提供](红石元件#电源.md)15级的信号等级。
* 激活任何四周的背对马铃薯电池的[红石中继器](红石中继器.md)和[红石比较器](红石比较器.md)，向它们[提供](红石元件#电源.md)15级的信号等级。
* 激活任何毗邻的[机械元件](红石元件.md)（如[门](门.md)、[红石灯](红石灯.md)等），包括马铃薯电池上面的和下面的红石元件。但[活塞](活塞.md)不能被任何在它前面的电源常规激活。
* 向红石比较器的边侧输入信号。

马铃薯电池表现的性质和强充能方块类似，与马铃薯电池相邻的红石导体不会被充能，但其实它不是[红石导体](红石导体.md)，例如马铃薯电池处于[箱子](箱子.md)上方时不会阻止箱子被开启。

# = 造成伤害 =
马铃薯电池激活时，会对站在其上方的生物持续造成每次的伤害，并产生[电火花粒子](Java版粒子#简单粒子.md)连接铁极和铜极。

# = 光源 =
激活的马铃薯电池会发出[亮度](亮度.md)为8的光。
