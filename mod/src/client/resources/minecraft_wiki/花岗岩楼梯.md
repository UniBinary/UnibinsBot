# 花岗岩楼梯

*页面ID: 44272* | *来源: Minecraft Wiki*

* *花岗岩楼梯（Granite Stairs）**是[花岗岩](花岗岩.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
花岗岩楼梯会自然生成在沙漠[村庄](村庄.md)中。

# 破坏
挖掘花岗岩楼梯的合适工具是镐。花岗岩楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

花岗岩楼梯被破坏后会掉落自身。
