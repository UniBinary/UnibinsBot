# Java版12w38a

*页面ID: 33079* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w38a**是[Java版1.4.2](Java版1.4.2.md)的第6个快照，发布于2012年9月20日<ref></ref>。

# 新内容
# = 生物 =
* *[蝙蝠](蝙蝠.md)**
* 一种被动型[生物](生物.md)。
* 生成于黑暗的洞穴里。
* 生成于和平[难度](难度.md)。
* 在白天睡觉。
* 空闲时倒挂在天花板，玩家靠近时会飞起来。
* [刷怪蛋](刷怪蛋.md)在创造模式下可用。

* *[女巫](女巫.md)**
* 在非敌对时鼻子会缓慢地上下浮动。
* 会向投掷剧毒、迟缓、虚弱、和伤害喷溅药水。
* 随时间恢复生命。
* 在攻击时会拿着空瓶子并翘起它们的鼻子。
* 在战斗时会饮用治疗药水和抗火药水来保护自己。
* 会罕见地掉落治疗药水和抗火药水。
* 85%免疫魔法伤害，包括中毒、瞬间伤害和荆棘魔咒。
* 暂时不会自然生成，但是刷怪蛋在创造模式下可用。

# 修复
* *修复了4个漏洞**
* 修复了在玩家离开物品展示框超过20格后消失的问题。
* 修复了实体穿过传送门后，其动量丢失的问题。
* 修复了“无底深渊”超平坦预设中有错误方块的问题。
* 修复了胡萝卜钓竿耐久用尽后不会变回钓鱼竿的问题。</onlyinclude>
