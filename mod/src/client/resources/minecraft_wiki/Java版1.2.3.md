# Java版1.2.3

*页面ID: 29972* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.2.3**是的一次次要更新，发布于2012年3月2日<ref></ref>，修复了一些漏洞与崩溃。此版本兼容1.2.1和1.2.2的服务端。

# 修复
* *修复了4个漏洞**
* 修复了在y=255处光照问题导致崩溃的漏洞。
* 修复了僵尸和骷髅在阳光下不会燃烧的漏洞。
* 修复了除了在世界生成时，自然光照等级比应有亮度暗一级的漏洞。
* 修复了白桦和云杉树苗在y=127以上不会长成树的漏洞。</onlyinclude>
