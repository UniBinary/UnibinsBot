# Java版13w25a

*页面ID: 33559* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w25a**是[Java版1.6.1](Java版1.6.1.md)的第15个快照，发布于2013年6月17日<ref></ref>，加入了一条生物命名彩蛋，并修复了一些漏洞。

# 更改
# = 生物 =
* *常规**
* 被命名为“Dinnerbone”或“Grumm”的生物现在会上下颠倒。

# = 物品 =
* *[附魔金苹果](附魔金苹果.md)**
* [伤害吸收](伤害吸收.md)效果持续时长提升至2:00。
