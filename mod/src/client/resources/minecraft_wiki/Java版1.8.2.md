# Java版1.8.2

*页面ID: 15135* | *来源: Minecraft Wiki*

* *1.8.2**是的一次次要更新，发布于2015年2月19日<ref></ref><ref></ref><ref></ref>，加入了更多的统计信息和调试屏幕的帧率时间图，并修复了一些漏洞。此版本兼容1.8和1.8.1的服务端。

# 新内容
# = 常规 =
* *[统计信息](统计信息.md)**
* 吃掉的蛋糕片数
* 填充炼药锅的次数
* 从炼药锅取水次数
* 染色盔甲的清洗次数
* 旗帜的清洗次数
* 与炼药台的互动次数
* 与信标的互动次数
* 查看投掷器的次数
* 查看漏斗的次数
* 查看发射器的次数
* 音符盒播放次数
* 音符盒调音次数
* 盆栽种植次数
* 触发陷阱箱次数
* 打开末影箱次数
* 附魔次数
* 音乐唱片播放次数
* 与熔炉的互动次数
* 与工作台的互动次数
* 打开箱子次数

* *调试屏幕**
* 加入了新的帧率时间图。
* * 通过按下在屏幕的左下方显示帧率时间图。

# 更改
# = 方块 =
* *[TNT](TNT.md)**
* 爆炸的物理效果改回至[14w31a](14w31a.md)之前。
* 爆炸威力不再根据方向产生偏差。

* *[信标](信标.md)**
* 信标在测试其是否暴露在天空下时会忽视基岩。

# = 物品 =
* *[胡萝卜钓竿](胡萝卜钓竿.md)**
* 合成时将会移除钓鱼竿上的所有魔咒。

# = 生物 =
* *[豹猫](豹猫.md)**
* 豹猫现在会在海平面以上的地方生成，而不是在高度63生成。

* *[鱿鱼](鱿鱼.md)**
* 鱿鱼现在会在低于海平面的地方生成，而不是在高度63生成。

# = 世界生成 =
* *[橡树](树木.md)和[深色橡树](树木.md)**
* 生成树枝时不再替换方块。

* *[自定义](自定义.md)**
* 自定义世界类型草地的生成会正确的随海平面变化

# = 游戏内容 =
* *[旁观模式](旁观模式.md)**
* 生物不再跟随/攻击在旁观模式的玩家。

# = 常规 =
* *[多人游戏](多人游戏.md)**
* 现在在登出服务器时会返回服务器列表而非主菜单。
