管理执行者处的[袭击](袭击.md)。

# 语法
   <code>raid check</code>
  : 检查袭击状态。若存在袭击，则输出事件信息。
   <code>raid glow</code>
  : 对袭击者施加1000秒的2级[发光](发光.md)效果。
   <code>raid setomen <level></code>
  : 设定袭击的[袭击之兆等级](袭击#袭击之兆等级.md)。
   <code>raid sound <type></code>
  : 播放袭击音效。
   <code>raid spawnleader</code>
  : 生成[袭击队长](袭击队长.md)。
   <code>raid start <omenlvl></code>
  : [触发](袭击#袭击触发.md)袭击，若存在袭击队长则不经过首轮冷却。
   <code>raid stop</code>
  : [停止](袭击#停战.md)袭击。

# 参数
和
   指定袭击的[袭击之兆等级](袭击#袭击之兆等级.md)。


   仅当值为时才会真正播放音效。
