丛林树是生成于[丛林](丛林.md)的植被[地物](地物.md)，分为**普通丛林树（Jungle Tree）**、**大型丛林树（Mega Jungle Tree）**、**丛林灌木（Jungle Bush）**、和**倒下的丛林树（Fallen Jungle Tree）**。

# 种类
# = 普通丛林树 =
普通丛林树的树冠形状与普通[橡树](橡树.md)、[白桦](白桦.md)相同。其整体高度为5-13格；高度为5-12格。

# = 大型丛林树 =
大型丛林树表面总会长有[藤蔓](藤蔓.md)，还具有树枝分杈以及不同于普通丛林树的大型伞状树冠。

大型丛林树高11-32格，树干横截尺寸为2×2格，且树干西北角的原木顶端总是比其他3列原木高出1格。

# = 丛林灌木 =
小型灌木状的丛林树由1格丛林原木和少量的橡树树叶组成，只有2-3格高。

# = 覆藤丛林树 =

覆藤丛林树也叫做濒死的丛林树。除了其暴露的原木爬满藤蔓外，覆藤丛林树与普通丛林树在外观上并无差别。

# = 倒下的丛林树 =
倒下的丛林树包含一个单独的纵向原木作为树桩，距其一两格远的地方另有0-9块平躺的原木。树桩的每个侧面有75%的概率附着藤蔓，有时这些原木上会出现[蘑菇](蘑菇.md)。

# 生成
丛林树生成时会将下方1格的方块转变为[泥土](泥土.md)。

# = 自然生成 =
生物群系放置树木地物时，每种树木的生成概率如下表所示：

自然生成的普通丛林树的树干每个暴露面都有20%的概率长有[可可果](可可果.md)，并且树体会附着藤蔓。

# = 人为生成 =
[亮度](亮度.md)等级至少为9且有一定的空间时，1个[丛林树苗](丛林树苗.md)可长成普通丛林树；2×2摆放的丛林树苗能长成大型丛林树。
