# 异界传送门（方块）

*页面ID: 143832* | *来源: Minecraft Wiki*

* *异界传送门（Other Portal）**是一种构成[异界传送门](异界传送门.md)的半透明[方块](方块.md)，可将进入的生物传送至Y轴坐标大于500的位置。

# 生成
# = 异界传送门 =
异界传送门方块是激活的异界传送门结构的一部分。

# 获取
异界传送门方块没有对应的物品形式。

# 破坏
异界传送门不能被挖掘破坏。

异界传送门被破坏后不会掉落。

# 用途

异界传送门方块只能够在[异界传送门](异界传送门.md)结构里出现。当此方块被更新（需要平行方向的[PP更新](方块更新#PP更新.md)），同时被检测到不处于异界传送门中时会被移除。

当一个玩家待在[主世界](主世界.md)或者[下界](下界.md)的异界传送门内4秒后，就会被传送至X与Z轴坐标相同，Y轴坐标大于500的位置，但不会超过Y=650。

异界传送门方块会发出独特的呼啸声，并散发类似雪花的紫色粒子（这种粒子也会由下界传送门、[末影人](末影人.md)、[末影螨](末影螨.md)、[末影珍珠](末影珍珠.md)和[末影箱](末影箱.md)生成）。

不像大多数不可挖掘的方块，异界传送门方块的[爆炸抗性](爆炸抗性.md)只有0。因此，任何能够破坏方块的爆炸会能在波及异界传送门方块时将其破坏，并关闭整个异界传送门。

尝试在异界传送门方块的位置放置任意液体会破坏异界传送门。液体流入异界传送门也会将其破坏。

异界传送门方块无法被[活塞](活塞.md)推动。

# = 光源 =
异界传送门方块会发出亮度等级为11的光。
