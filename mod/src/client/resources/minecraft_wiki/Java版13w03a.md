# Java版13w03a

*页面ID: 33487* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w03a**是[Java版1.5](Java版1.5.md)的第5个快照，发布于2013年1月17日<ref></ref>，加入了投掷器、漏斗矿车和命令，更新了命令方块机制和生物AI，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[投掷器](投掷器.md)**
* 将物品置于其前面的容器中，如果没有容器，则不使用该物品。
* [发射器](发射器.md)会朝玩家“发射”物品，而[投掷器](投掷器.md)会朝玩家“投掷”物品。<ref name="DropperInfo"></ref>
* 合成配方是7个[圆石](圆石.md)摆成∩形状，在中间放置一个[漏斗](漏斗.md)并在底部放置一个[红石粉](红石粉.md)。

# = 非生物实体 =
* *[漏斗矿车](漏斗矿车.md)**
* 合成配方为[矿车](矿车.md)上方放置一个漏斗。
* 只能通过一个漏斗倒空。
* 倒空后才能捡起物品。

# = 命令格式 =
* ***
* 检测玩家，用比较器来获得表示玩家数量的红石信号。

# 更改
# = 方块 =
* *[石英柱](石英柱.md)**
* 石英柱现在能以任何方向摆放，方法与木头一样。

* *[命令方块](命令方块.md)**
* 放于隔壁的[红石比较器](红石比较器.md)能指出上一个命令是否运行成功。

* *[探测铁轨](探测铁轨.md)**
* 由它们充能的比较器会根据铁轨上的容器空满度输出信号。

* *[水](水.md)**
* 创造无限水方块不再需要下方有方块，而是只需要有一个水源方块。
* * 这代表使用铁桶和在水上建筑不会把河流和海弄乱。

# = 生物 =
* *[骷髅](骷髅.md)**
* 现在更难地近身攻击。
* * 根据难度变更。
* * 目标越近，攻击速度越快。
* * 会攻击在一格外的玩家。

* *[僵尸](僵尸.md)**
* 现在更难被攻击。
* * 根据难度变更。
* * 会集中攻击单个目标。
* * 着火的僵尸会使玩家着火。
* * 如果在远方被击中，僵尸会向玩家移动。

# = 非生物实体 =
* *[TNT矿车](TNT矿车.md)**
* 当是通过激活铁轨引爆时，它们不再会将铁轨和支撑其的方块炸毁。
* 仍会炸毁红石材料。

# = 常规 =
* *[选项](选项.md)**
* 在多人游戏菜单中添加了新的聊天选项：“聚焦高度”、“淡化高度”和“宽度”。
* 将[主菜单](主菜单.md)的纹理包按钮移至选项中，以便在游戏内更改纹理包。
