# Java版1.8.9

*页面ID: 19100* | *来源: Minecraft Wiki*

* *1.8.9**是的一次次要更新，发布于2015年12月9日<ref></ref>。此版本兼容1.8到1.8.8的服务端。

# 更改
# = 方块 =
* *[陷阱箱](陷阱箱.md)**
* 会在时间设置为12月24至26日时更改纹理以适配圣诞节。

# = 游戏内容 =
* *Realms**
* 更好地植入Realms。
* 新的配置/离开Realms而不用预先选中Realms的按钮。
