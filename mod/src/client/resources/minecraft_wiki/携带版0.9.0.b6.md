# 携带版0.9.0.b6

*页面ID: 31494* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.9.0 alpha build 6**是[v0.9.0 alpha](携带版0.9.0.md)的第6个测试版，发布于2014年6月19日，修复了一些漏洞。

# 更改
# = 方块 =
* *[火把](火把.md)**
* [火把](火把.md)更亮了，并且与[Java版](Java版.md)更加相似。

# 修复
* *修复了13个漏洞**

* 破坏铁轨下方方块会导致游戏崩溃。
* 区块不会在天空光照发生变化时更新。
* 藤蔓不会正常工作。
* 滴水粒子拥有黑色轮廓。
* 点燃的TNT和落下的沙子/沙砾导致游戏不稳定。
* 哞菇无法繁殖。
* 玩家死亡时不会去除获得的状态（例如着火）。
* 箱子UI内的关闭按钮无效。
* 物品会错误地被放在[...]内。
* 草方块不会在其他方块下方时退化为泥土。
* 制作告示牌不能获得3个。
* 门上有许多的错误。
* 手持时无法看到末地传送门框架。</onlyinclude>
