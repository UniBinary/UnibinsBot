# 模板展示实体

*页面ID: 185734* | *来源: Minecraft Wiki*

* *模板展示实体（Stencil Display）**是用于更改模板形状内的所有渲染片段颜色的实体。

# 生成
模板展示实体不会生成在世界中，但可以使用等命令生成。

# 行为
模板展示实体自身没有移动行为（即使指定了字段），不会受到伤害，不会发出声音，不会阻碍方块放置，也不会将玩家或其他实体推离自己所在的位置。

使用[调试组合键](调试屏幕#调试组合键.md)时，模板展示实体不会显示[判定箱](判定箱.md)，但是会显示代表其朝向的蓝色线段。

模板展示实体无法被选中，因此无法通过使用将其实体数据复制到粘贴板。

# = 细节级别 =
模板展示实体具有5种细节级别（0-4），由实体数据控制。

# = 形状 =
模板展示实体具有锥形（1）和球形（0）两种模板形状，由实体数据控制。

# = 形状 =
模板展示实体可以更改颜色，由实体数据控制，且在模板形状内的所有渲染片段都被覆盖为模板展示实体的颜色。
