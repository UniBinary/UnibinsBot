# 试炼刷怪笼

*页面ID: 107307* | *来源: Minecraft Wiki*

* *试炼刷怪笼（Trial Spawner）**是一种只能在[试炼密室](试炼密室.md)中生成的方块，会根据周围[玩家](玩家.md)的数量调整刷怪总数。

# 生成
# = 自然生成 =
试炼刷怪笼自然生成于[试炼密室](试炼密室.md)的柱廊和决斗室结构中。试炼刷怪笼生成的生物种类可由其底座方块的种类判断，详见。

# = 不祥试炼刷怪笼 =
[不祥试炼刷怪笼](不祥试炼刷怪笼.md)冷却时间结束后会变为试炼刷怪笼。

# 获取

试炼刷怪笼无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，试炼刷怪笼可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
没有工具可以加速对试炼刷怪笼的挖掘。

试炼刷怪笼被破坏后不会掉落。

# 用途

与[刷怪笼](刷怪笼.md)和[不祥试炼刷怪笼](不祥试炼刷怪笼.md)一样，自然生成的试炼刷怪笼均已设置好生成的生物种类；由玩家放置出的试炼刷怪笼默认未设置生物种类（内部为空），对其[刷怪蛋](刷怪蛋.md)可以设置生物种类，但不会写入刷怪蛋中生物的附加数据。

若游戏规则为<code>false</code>，试炼刷怪笼无法运作并生成生物。

# = 激活 =
处于[生存模式](生存模式.md)或[冒险模式](冒险模式.md)的玩家距离试炼刷怪笼14格以内，玩家进入其视线，试炼刷怪笼已设置生物种类且不处于[冷却状态](#冷却.md)时，试炼刷怪笼会被激活，开始尝试在周围生成生物。

试炼刷怪笼从等待玩家状态转为激活状态时亮度会增加，产生上升的[火花粒子](粒子#trial_spawner_detection.md)，并且激活状态下其内部的生物模型旋转得更快、火焰粒子更加密集。

试炼刷怪笼在[和平](和平.md)难度下或[游戏规则](游戏规则.md)为<code>false</code>时<ref></ref>始终保持等待玩家状态，即使它要生成的生物能够存在于这些情况下也是如此。

# = 转变 =
当试炼刷怪笼满足以下条件时，它将变成[不祥试炼刷怪笼](不祥试炼刷怪笼.md)：
* 难度不为[和平](和平.md)。
* [游戏规则](游戏规则.md)为<code>true</code>。
* 检测到处于[生存模式](生存模式.md)或[冒险模式](冒险模式.md)且带有[试炼之兆](试炼之兆.md)状态效果的玩家。
* 满足以下条件之一：
* * 它正在等待玩家或正在激活阶段。
* * 它在冷却阶段中，但上一次激活时没有变为不祥试炼刷怪笼。

试炼刷怪笼变成不祥试炼刷怪笼会跳过冷却时间、重置挑战并清除由它生成的所有在场生物。

# = 生成生物 =
[thumb|俯视视角下，试炼刷怪笼生成生物的范围（为白色+红色羊毛区域，为白色羊毛区域）](File:Spawnerrange.png.md)

激活的试炼刷怪笼运作时，会在一个以试炼刷怪笼为中心的空间体积内生成对应实体，实体的底面中心点会在这个区域内，对应实体的碰撞箱大小不影响生成，只需实体底面中心点不被阻挡即可。这个空间体积范围为垂直距离1格、水平[切比雪夫距离](切比雪夫距离.md)4格；这个空间体积范围为垂直距离1格、水平[曼哈顿距离](曼哈顿距离.md)4格<ref></ref>。越靠近试炼刷怪笼，生成在此位置的概率越大。

试炼刷怪笼生成生物不受[亮度](亮度.md)影响，但它也需要满足刷怪笼的[部分生物生成需求](刷怪笼#生成需求.md)；并且试炼刷怪笼中心到刷怪点的视线必须不被[视野阻挡方块](视野阻挡方块.md)遮挡（也就是说，当六个面都被阻挡时，试炼刷怪笼将无法生成生物）。

激活的试炼刷怪笼每隔一段时间生成1个生物，48格内同时存活的生物数量达到规定的上限后会停止生成。一次试炼中目标数量的生物全部生成并退场<ref group="注">生物死亡或位于试炼刷怪笼48格以外时被视为退场；[史莱姆](史莱姆.md)和[岩浆怪](岩浆怪.md)分裂产生的新生物不被计入。</ref>后，试炼刷怪笼结束运作，试炼完成。

# = 奖励 =
玩家完成一次试炼后，试炼刷怪笼顶部的“闸门”会开启，并弹出奖励。试炼刷怪笼会先从下列两个战利品表中选择一个，再随机抽取物品作为奖励弹出，每个战利品表被选中的概率为50%，选中后直到冷却状态前不再更改。抽取次数等于参与试炼的玩家数量。

由刷怪蛋添加或更改过生物种类的试炼刷怪笼使用试炼刷怪笼的战利品表。

# = 冷却 =
试炼刷怪笼生成奖励之后会进入的冷却状态，亮度等级转为0，试炼刷怪笼顶部的橙色边角变灰。冷却结束后才能再次激活。

即使所在区块被卸载，试炼刷怪笼依然会继续计算冷却倒计时。

# = 安全保护 =

试炼刷怪笼属于“仅管理员可设置数据”的方块。

非管理员玩家对试炼刷怪笼按下+时不会复制方块实体数据，放置物品栏中已有的带有方块实体数据的试炼刷怪笼也不会将数据实际加载。

管理员玩家的物品栏中带有方块实体数据的试炼刷怪笼的物品[提示框](提示框.md)中会显示警告信息。
