# 锻造台

*页面ID: 37016* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *锻造台（Smithing Table）**是一种可以用来制作下界合金质[工具](工具.md)、[武器](武器.md)和[盔甲](盔甲.md)，或结合[锻造模板](锻造模板.md)给盔甲添加不同纹饰的方块。

# 生成
# = 自然生成 =
锻造台自然生成在[古迹废墟](古迹废墟.md)的匠铺以及[村庄](村庄.md)的工具匠小屋中。

# 破坏
挖掘锻造台的合适工具是斧。

锻造台被破坏后会掉落自身。

# 用途
中锻造台的界面}}
# = 锻造 =

放置在世界中的锻造台会打开锻造台的锻造界面，允许玩家通过锻造配方来改造物品。

# = 更改村民职业 =

如果一个锻造台尚未被[村民](村民.md)认领，则附近的失业村民有机会认领该锻造台并转变职业为[工具匠](工具匠.md)。

# = 燃料 =
锻造台能用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个锻造台能烧炼1.5个物品。
