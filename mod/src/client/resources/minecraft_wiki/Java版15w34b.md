# Java版15w34b

*页面ID: 17758* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w34b**是[Java版1.9](Java版1.9.md)的第11个快照，发布于2015年8月20日<ref></ref>，修复了[15w34a](15w34a.md)中的一些漏洞和崩溃。

# 更改
# = 方块 =
* *[命令方块](命令方块.md)**
* 增强命令执行失败的提示。
* 新的制约选项。
* * 默认为不受制约。
* * 当切换为条件制约时，命令方块只有接入方块成功触发命令时才触发命令。
* 支持补全了。

# = 物品 =
* *[盔甲](盔甲.md)**
* 护甲值现在由耐久度决定。
* * 耐久达到一半时会护甲值变为。

* *[命令方块矿车](命令方块矿车.md)**
* 有了新的单次方块纹理。

# = 生物 =
* *常规**
* 受伤时出现灰色生命粒子。
* * 造成更多伤害时会有更多粒子。

* *[巨人](巨人.md)**
* 重新渲染其模型。

# = 游戏内容 =
* *损害值显示**
* 显示绝对伤害而不是增加的伤害。

# = 常规 =
* *[属性](属性.md)**
* 新的“攻击速度”属性，标识符<code>generic.attackSpeed</code>，表明攻击力的每秒回复值。基础为4.0，代表回复时间为0.25秒。
* * 剑，镐，锹将调整-2.75，最终总和为1.25（进度条回复时间0.8秒）。
* * 斧将调整-3.2，最终总和为0.8 （回复时间1.25秒）。
* * 急迫效果增加10%攻速，挖掘疲劳则会减少10%。
