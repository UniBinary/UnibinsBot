# 青金石块

*页面ID: 163* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *青金石块（Block of Lapis Lazuli）**是一种用[青金石](青金石.md)合成的装饰性矿物方块。

# 生成
# = 自然生成 =
青金石块在[林地府邸](林地府邸.md)中[灾厄村民雕像房](林地府邸/结构/装饰品房间#灾厄村民雕像房.md)的雕像头部中心处生成。

# 破坏
挖掘青金石块的合适工具是镐。青金石块需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

青金石块被破坏后会掉落自身。

# 用途
青金石块可用作储存[青金石](青金石.md)，以此来节约空间。

# 你知道吗
* 在现实生活中，[青金石](wzh:青金岩.md)是一种稀有的蓝色宝石，可被研磨加工成群青色颜料。青金石颜料在古代常被用于给泥金抄本、玻璃和壁画上色。
