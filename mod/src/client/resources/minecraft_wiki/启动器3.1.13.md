# 启动器3.1.13

*页面ID: 126140* | *来源: Minecraft Wiki*

<onlyinclude>

* *3.1.13**是一次[启动器](启动器.md)更新，发布于2024年9月17日。

# 更改
* *Minecraft Pixel Remixes*[芯片音乐](wzh:芯片音乐.md)视频现在可以通过启动器中Java版和基岩版的版本展示页面上的按钮播放。

# 修复
*  — Minecraft for Windows的卸载警告是从Minecraft Dungeons复用的。
*  — 赠送按钮会在切换页面后错位。
*  — Windows 10/11上的启动器被称为“Launcher Bedrock Edition”。</onlyinclude>
