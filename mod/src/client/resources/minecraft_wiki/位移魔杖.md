# 位移魔杖

*页面ID: 149959* | *来源: Minecraft Wiki*

* *位移魔杖（Displacement Wand）**是一种可以向前方发射[末影珍珠](末影珍珠.md)的[物品](物品.md)。

# 获取
# = 解锁 =
解锁“[Enigma（谜团）](可解锁项目#teleportation_wand.md)”后，挑战矿境时会自动获得1个位移魔杖。

# 用途
位移魔杖具有[光效](光效.md)。

位移魔杖会向前方发射[末影珍珠](末影珍珠.md)，使用后冷却。

位移魔杖射出的末影珍珠不会生成[末影螨](末影螨.md)，也不会在落地时对玩家造成伤害。
