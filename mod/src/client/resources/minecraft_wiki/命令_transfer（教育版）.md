# 命令/transfer（教育版）

*页面ID: 56673* | *来源: Minecraft Wiki*

将[智能体](智能体.md)的指定数量的物品转移到另一个槽位里。

# 语法
   <code>transfer <*srcSlotNum：整型*> <*quantity：整型*> <*dstSlotNum：整型*></code>

# 参数
<code>*srcSlotNum：整型*</code>
   需要进行转移的槽位，数字为1-27。

<code>*quantity：整型*</code>
   被转换物品的数量。

<code>*srcSlotNum：整型*</code>
   转换的目标槽位，数字为1-27。
