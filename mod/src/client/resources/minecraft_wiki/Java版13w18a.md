# Java版13w18a

*页面ID: 33525* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w18a**是[Java版1.6.1](Java版1.6.1.md)的第4个快照，发布于2013年5月2日<ref></ref>，加入了煤炭块、干草捆、下界要塞箱子战利品和新的纹理加载系统，以及为拴绳加入了新的合成配方，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[煤炭块](煤炭块.md)**
* 使用3×3煤炭而不是木炭合成。
* 能作为熔炉燃料使用，一块能烧炼72个物品，相当于9个煤炭。
* 可用于储存大量煤炭。

* *[干草捆](干草捆.md)**
* 加入了合成配方。
* * 干草捆能通过3×3的小麦合成。
* * 干草捆不能还原为小麦。

# = 物品 =
* *[拴绳](拴绳.md)**
* 加入了新的合成配方。

# = 世界生成 =
* *[下界要塞](下界要塞.md)**
* 加入了箱子战利品。
* * 一般出现在内部的角落内。

# = 常规 =
* *[纹理包](纹理包.md)**
* 开始使用新的纹理加载系统。
* 更改了[无效纹理](无效纹理.md)。

# 更改
# = 方块 =
* *[地毯](地毯.md)**
* 现在能放置在透明方块上了。

* *[上锁的箱子](上锁的箱子.md)**
* 更新了[上锁的箱子](上锁的箱子.md)的纹理。

* *[红石比较器](红石比较器.md)**
* 现在能够根据炼药锅和末地传送门框架的状态输出信号。
* * 炼药锅在空着时不会输出信号，在满水时会输出强度为3的信号，每填装一个玻璃瓶信号会减弱一格。
* * 末地传送门框架如果没有放入末影之眼则不会输出信号，如有放入则输出强度为15的信号。

# = 物品 =
* *[可可豆](可可豆.md)**
* 从地牢箱子中被移除。

* *[马铠](马铠.md)**
* 玩家无法合成马铠了。
* 马铠加入到地牢箱子中。

* *[马鞍](马鞍.md)**
* 移除了马鞍。

* *[鞍](鞍.md)**
* 鞍现在能在大多数生成的箱子内找到。

# = 生物 =
* *[马](马.md)**
* 更改了马装备的可获得性。
* 控制马骑行现在需要普通的鞍。
* * 马和猪现在共有一种鞍。
* 调整了与马相关的特性，使得它们在稍后的游戏中更加实用。

* *[僵尸](僵尸.md)**
* 调整了僵尸生成更多的僵尸的机制，并且僵尸不再容易被玩家发现。
* 僵尸现在会生成于玩家远处的黑暗区域或者洞穴里。
