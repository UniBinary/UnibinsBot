# 末地折跃门（方块）

*页面ID: 17573* | *来源: Minecraft Wiki*

* *末地折跃门（End Gateway）**是出现在[末地折跃门结构](末地折跃门.md)的一种方块，用来把玩家传送到[末地](末地.md)的另一个空岛上。

# 生成

# = 末地折跃门 =
末地折跃门方块会作为[末地折跃门](末地折跃门.md)结构的一部分生成。

# 获取
末地折跃门方块没有对应的物品形式。

末地折跃门方块的物品形式只能通过编辑物品栏获得。

# 破坏
末地折跃门不能被挖掘破坏。

末地折跃门被破坏后不会掉落。

# 用途
[thumb|](File:Endgatewaycommand.jpg.md)
末地折跃门可以将进入其中的实体或对其投掷了[末影珍珠](末影珍珠.md)的实体传送到预设的目的地。末地折跃门的目的地由其方块实体数据值定义，自然生成的末地折跃门的目的地取决于其生成方式：
* 主岛末地折跃门会将实体传送至对应的外岛末地折跃门。
* 外岛末地折跃门会将实体传送至对应的主岛末地折跃门。
* 回归折跃门会将实体传送至黑曜石平台。

如果在末地以外的维度不指定方块数据或，它不会传送实体，。

若熔岩流过末地折跃门，末地折跃门会被破坏。

末地折跃门会阻挡实体通过其自身；末地折跃门对实体没有阻挡作用。

放置在末地中且没有设置目的地的末地折跃门会尝试将玩家传送至外岛最靠近主岛的位置上，并在必要时生成[末地浮岛](末地浮岛.md)。具体来说，当末地传送门方块开始传送实体时，若其处在末地中且方块数据<code>exit_portal</code>不存在，则会遵循以下流程确定传送的目的地<math>P</math>并生成指向自身的[末地折跃门结构](末地折跃门.md)：

# 按照以下方法确定目标位置<math>P_0</math>。注意：在此步骤的计算中，忽视高度，只使用x与z两个坐标进行平面计算：
# # 选择坐标原点（x=0, z=0）到末地折跃门所在位置的方向，距离坐标原点1024格远位置，作为起始位置；
# # 从起始位置开始，检查当前位置所在区块是否为空区块（即没有任何方块的区块）。如果是，以当前位置进入下一步；否则，将当前位置向接近坐标原点方向移动16格，并再次执行该检查，直到找到一个空区块，或当前位置距离起始位置达256格，以当前位置进入下一步；
# # 将上一步的位置作为起始位置，从起始位置开始，检查当前位置所在的区块是否非空。如果是，以当前位置进入下一步；否则，将当前位置向远离坐标原点方向移动16格，并再次执行该检查，直到找到一个非空区块，或当前位置距离起始位置达256格，以当前位置进入下一步；
# # 当前位置即为目标位置<math>P_0</math>。
# 在目标位置<math>P_0</math>所在的区块中，找到同时满足以下条件的，且离坐标原点（x=0, y=0, z=0）最近的一个位置<math>P_1</math>：
# # 位置的高度不低于30，或者位置的高度是整个区块中方块高度的最大值；
# # 位置上的方块是[末地石](末地石.md)；
# # 位置上方1～2格的方块不是完整方块。
# 如果<math>P_1</math>不存在，则令位置<math>P_2</math>为水平坐标（x与z）与<math display="inline">P_0</math>相同，且高度（y）为75的位置，并在该位置生成[末地浮岛](末地浮岛.md)；否则令<math>P_2</math>等于<math>P_1</math>；
# 找到位置在水平方向上与<math>P_2</math>的[切比雪夫距离](切比雪夫距离.md)不超过16，且高度最高的完整方块。将该方块的位置作为传送目的地<math>P</math>；
# # 如果这样的完整方块无法找到（例如末地浮岛被禁用导致无法生成），则将<math>P_2</math>作为传送目的地<math>P</math>；
# 在<math>P</math>上方10格的位置生成指向自身的[末地折跃门结构](末地折跃门.md)；
# 如果实体数据<code>ExactTeleport</code>为，则按照[自然生成的末地折跃门的传送逻辑](末地折跃门#行为.md)，修正传送目的地<math>P</math>。

# 你知道吗
* 若玩家的视线与指令放置的末地折跃门处在同一格，则末地折跃门本身将不可见，但玩家仍能看见其发出的光束。
* 末地折跃门并没有具体名称。由于缺失翻译字符串，它在物品栏中的名称为。
* 末地中由玩家放置的末地折跃门会将玩家传送至坐标（0,0,0）。
* 玩家可以站在主世界和下界中的末地折跃门上，且不会被传送到任何地方。
* 虽然末地折跃门具有碰撞箱，但手持末地折跃门物品的玩家可以将末地折跃门放置在与实体碰撞箱相交的位置，并且在非末地维度还会挤开实体。
