# 建造者

*页面ID: 169074* | *来源: Minecraft Wiki*

}}
* *建造者（Builder）**是使用默认[玩家](玩家.md)皮肤的生物。它们仅在开发者版本[Java版Beta 1.2_02 (20110517)](Java版Beta 1.2_02 (20110517).md)中可用。

# 生成
建造者在创建世界时生成。

# 行为
建造者会在世界中随机移动，并尝试建造建筑。它们持有铁镐，并且可以破坏和放置方块。

建造者会在生成后的几分钟内自爆并重生。

# 未使用变种
* 存在两类未使用的与上述建造者不同的“秘密建造者”实体。若不修改源代码修复错误，这两种建造者都会导致游戏崩溃。
* * 第一类建造者持有在游戏中不渲染的[金镐](金镐.md)。它与[敌对生物](敌对生物.md)具有相似行为，它会四处走动并尝试攻击玩家。<ref></ref>
* * 第二类建造者持有[铁镐](铁镐.md)并四处游走，但并不像普通的建造者那样可以搭建建筑或遵循固定路线。<ref></ref>
