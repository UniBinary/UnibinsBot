# 出生点保护

*页面ID: 126505* | *来源: Minecraft Wiki*

* *出生点保护（Spawn protection）**是阻止玩家在[世界出生点](世界出生点.md)周围改变[方块](方块.md)的机制。

# 描述
出生点保护仅存在于专用服务器中，不适用于[单人游戏](单人游戏.md)或局域网游戏中。

出生点保护区域是正方形的区域，忽略Y轴坐标。文件中的<code>spawn-protection</code>字段决定其边长，边长为 <math>2x+1</math>。例如设置为1，会保护以出生点为中心的3×3的区域。设置为0或负值都将禁用出生点保护。

如果服务器设有[管理员](管理员.md)（文件中有玩家），则出生点保护对管理员不生效。如果服务器未设有管理员，则所有玩家皆不受出生点保护影响。

玩家可以间接地改变保护区域内的方块，例如使用[活塞](活塞.md)、[发射器](发射器.md)、[TNT](TNT.md)等。
