# Java版16w43a

*页面ID: 25962* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w43a**是[Java版1.11](Java版1.11.md)的第13个快照，发布于2016年10月27日<ref></ref>。

# 新内容
# = 非生物实体 =
* *[唤魔者尖牙](唤魔者尖牙.md)**
* 加入了标签。

# = 世界生成 =
* *[林地府邸](林地府邸.md)**
* 现在拥有一个新的房间，房间里有被装在[玻璃](玻璃.md)和[黑曜石](黑曜石.md)里的[熔岩](熔岩.md)，中间有一个[钻石块](钻石块.md)。

# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 加入了“<player|mob> was squished too much（<玩家|生物> 因被过度挤压而死）”，当因[游戏规则](游戏规则.md)<code>maxEntityCramming</code>造成窒息时显示。

# 更改
# = 方块 =
* *[侦测器](侦测器.md)**
* 顶部和底部的箭头现在指向它的输出端。
* 仅在指向[红石导体](红石导体.md)时[更新](方块更新.md)指向的[毗邻](红石电路#位置.md)。

* *[红石中继器](红石中继器.md)和[红石比较器](红石比较器.md)**
* 仅在指向红石导体时更新指向的毗邻。

# = 物品 =
* *[钓鱼竿](钓鱼竿.md)**
* 手持钓鱼竿右击[栅栏](栅栏.md)会抛出或收回钓鱼竿。

# = 生物 =
* *[恼鬼](恼鬼.md)**
* 恼鬼现在会穿过下界传送门和末地传送门和在水里移动。

# = 常规 =
* *[战利品表](战利品表.md)**
* [村民](村民.md)、[恼鬼](恼鬼.md)和[末影龙](末影龙.md)现在会从它们各自的战利品表中抽取物品。
