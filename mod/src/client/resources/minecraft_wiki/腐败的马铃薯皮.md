# 腐败的马铃薯皮

*页面ID: 147635* | *来源: Minecraft Wiki*

* *腐败的马铃薯皮（Corrupted Potato Peels）**是[马铃薯皮](马铃薯皮.md)的腐败变种。

# 获取
# = 削皮 =
对[腐败的薯皮草方块](腐败的薯皮草方块.md)的顶部马铃薯削皮刀会将其变为[马铃薯泥土](马铃薯泥土.md)，同时削下1个腐败的马铃薯皮。

# = 超级马铃薯怪 =
[超级马铃薯怪](超级马铃薯怪.md)进入新阶段时会掉落多个腐败的马铃薯皮。

# = 烹饪 =
马铃薯皮可以在[煎炸台](煎炸台.md)或[营火](营火.md)上煎炸制成[薯饼](薯饼.md)。

# = 转化 =
对[马铃薯泥土](马铃薯泥土.md)顶部使用腐败的马铃薯皮会使其转化为腐败的薯皮草方块。
