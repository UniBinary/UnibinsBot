# 海泡菜

*页面ID: 34204* | *来源: Minecraft Wiki*

* *海泡菜（Sea Pickle）**是以小群落生成的、可以在水下发现的静止的仿生物方块。

# 生成
# = 自然生成 =
海泡菜群落可以在[暖水海洋](暖水海洋.md)底部或[珊瑚礁](珊瑚礁.md)中的[珊瑚块](珊瑚块.md)顶部以1-4个为一组生成。每个区块有的概率生成海泡菜群落。

海泡菜也可以在沙漠[村庄](村庄.md)的小型房屋8中作为装饰出现。

# = 骨粉 =
对在[水源](水源.md)中且位于[珊瑚块](珊瑚块.md)上方的海泡菜[骨粉](骨粉.md)时，该格海泡菜的数量会增加到4个，且有概率向以该格为中心X和Z轴偏移格、Y轴偏移格的下方为珊瑚块的水源或流动的水蔓延。当海泡菜生成的地方是流动的水时，它会将其转化为水源。

在数量为4的海泡菜上骨粉且尝试蔓延的位置均不是下方为珊瑚块的水源或流动的水时，仍会消耗骨粉。

# 破坏
海泡菜被挖掘时会立刻被破坏。

海泡菜被破坏后会掉落自身，掉落数等于方块内海泡菜数。

# 用途
海泡菜可以放在大多数固体方块的顶部，每个方块最多可以放4个，类似于[海龟蛋](海龟蛋.md)。

# = 堆肥 =
海泡菜有65%概率将[堆肥桶](堆肥桶.md)堆肥等级增加1。

# = 光源 =
含水的海泡菜会发光，一个海泡菜会产生6光照等级，之后每增加一个会增加3光照等级。海泡菜发光时，其末尾会有一道浅绿色的光。
