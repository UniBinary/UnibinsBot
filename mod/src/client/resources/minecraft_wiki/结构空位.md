* *结构空位（Structure Void）**是用于标记加载结构时不替换某一位置的方块。

# 生成
结构空位不会生成在世界中。

# 获取

结构空位无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，结构空位可以通过”，或“”中有结构空位）|JE}}、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
结构空位被挖掘时会立刻被破坏，用于挖掘的工具的耐久度不会下降。

结构空位被破坏后不会掉落。

结构空位被破坏后会掉落自身。<ref></ref>

# 用途
[生存模式](生存模式.md)下的玩家也可以放置结构空位。

结构空位通常不可见，并且没有碰撞箱。

结构空位不会被[水](水.md)或[熔岩](熔岩.md)冲毁，能够阻止其流动。

结构空位可以作为结构的一部分被存储，表示结构生成时该位置不进行替换：当包含结构空位的结构被生成时，结构空位不会生成（而[空气](空气.md)会生成），因此这一位置原有的方块不会被替换。这使得结构的形状可以不是长方体。

玩家可以通过将结构生成在完全由结构空位构成的空间中，此时剩下的结构空位就是该结构包含的结构空位。

# = Java版 =
结构空位（右二）以及游戏中的其他隐形方块被渲染出的立方体框外观}}

结构空位具有一个小型的判定箱，位于方块的中心。

在结构空位的判定箱上尝试放置不是结构空位的方块时，方块会取代结构空位。

结构空位是一种“隐形方块”，处于开启了“显示隐形方块”的存储模式[结构方块](结构方块.md)的存储区域范围内的结构空位会显示出一个淡红色的立方体框。

# = 基岩版 =
结构空位被视为一个完整的方块，具有完整方块大小的判定箱，并允许一些方块（如[火把](火把.md)）附着于其上。

在结构空位的判定箱上尝试放置方块时，方块会放在结构空位的旁边而不是取代结构空位。

无法通过在结构空位的位置上放置方块来将其取代。

处于[创造模式](创造模式.md)的[玩家](玩家.md)手持结构空位时，世界中的结构空位会渲染出一个红色的虚线框纹理。
