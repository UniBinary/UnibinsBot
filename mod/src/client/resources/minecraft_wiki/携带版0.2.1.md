* *v0.2.1 alpha**是[携带版](携带版.md)的一次次要更新，发布于2012年3月14日<ref></ref>。其加入了新的控制选项，以及其他更改与修复。

# 新内容
# = 方块 =
* *[书架](书架.md)**
* 在[创造模式](创造模式.md)中加入了[书架](书架.md)。

# = 常规 =
* *[控制](控制.md)**
* 新的[控制选项](控制.md)——分离[控制](控制#触控.md)。
* * 此选项可能更适合大屏幕的设备。十字准星在屏幕右半侧。

# 更改
# = 方块 =
* *常规**
* 现在在破坏它们时有了开裂的纹理。
* 破坏方块时显示的圆圈更加清晰。

* *[橡树](橡树.md)**
* 现在会使用云杉原木生成，而非橡木原木。因此，橡木原木在生存模式下无法获得了。

* *[甘蔗](甘蔗.md)**
* 现在可再生了（但仍然无法收集）。

# = 生物 =
* *[猪](猪.md)**
* 现在会自然生成了。

# = 常规 =
* *[控制](控制.md)**
* [飞行](飞行.md)发生变化；从中心按钮向上/下滑动来上升/下降。
* 大屏幕拥有更多物品[快捷栏](快捷栏.md)。

# 修订版本
不包括v0.2.1 alpha2，v0.2.1 alpha有2个内部版本号不同的apk文件。其余不同之处尚未可知。

# = 版本 =
* 0.2.1(2015)，大小2.84MB
* 0.2.1(2017)，大小2.79MB
