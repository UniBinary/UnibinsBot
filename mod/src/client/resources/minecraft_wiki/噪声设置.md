# 噪声设置

*页面ID: 123330* | *来源: Minecraft Wiki*

* *噪声设置定义文件**是**噪声设置（Noise Settings）**在数据包中的数据驱动定义文件。噪声设置也被称为**噪声生成器设置（Noise Generator Settings）**。

# 定义格式

# 定义行为
噪声设置定义数据仅在服务端启动时加载一次，使用命令不可以使密度函数定义被重新加载，而必须重启服务端。

噪声设置可以在噪声生成器中使用，为维度提供更复杂的世界生成。

噪声设置决定了世界的基础地形，包括噪声洞穴、含水层和矿脉放置。

在地形生成阶段，游戏会先使用最终密度函数是否大于0初步判断一个坐标应该放置维度默认方块还是空气。维度默认方块将被矿脉和表面规则依次替换；而Y=-58以上且海平面或地表以下的空气将被含水层替换，低于Y=-58的空气始终被熔岩替换。

在表面规则应用时，每个默认方块只会被一个表面规则处理，如果一个方块同时满足多个表面规则条件，则以第一个应用的表面规则为结果。计算参数的预处理地表高度受噪声设置直接指定，而表层厚度由<code>minecraft:surface</code>[噪声](噪声.md)决定，游戏将{{cd|-{}-（X,0,Z）处的噪声值 × 2.75 + 3.0}}作为表层厚度，最后还受与坐标相关的随机数的影响上下浮动0.25。

# 内置噪声设置
游戏内置了6个噪声设置：
* <code>minecraft:overworld</code>：用于一般的主世界生成。
* <code>minecraft:amplified</code>：用于放大化主世界生成。
* <code>minecraft:nether</code>：用于常规的下界生成。
* <code>minecraft:caves</code>：用于主世界洞穴生成。
* <code>minecraft:end</code>：用于常规的末地生成。
* <code>minecraft:floating_islands</code>：用于浮岛的生成。
