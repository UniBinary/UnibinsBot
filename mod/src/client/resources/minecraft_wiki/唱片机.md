* *唱片机（Jukebox）**是一种用来播放[音乐唱片](音乐唱片.md)的[方块](方块.md)。

唱片机不会生成在世界中。

# 用途
# = 播放唱片 =
手持[音乐唱片](音乐唱片.md)对着空的唱片机，音乐唱片将会插入唱片机，并且会播放与音乐唱片相对应的音乐。对着已经装有音乐唱片的唱片机将会弹出其中的音乐唱片并停止正在播放的音乐。

唱片机在音乐唱片弹出并重新插入之前只会播放一次音乐。唱片机发出的声音可以向各个方向传播大约65格。唱片机支持游戏中所有可用的[音乐唱片](音乐唱片.md)。开始播放音乐唱片时，[动作栏](动作栏.md)会出现或的“”文本消息。

[漏斗](漏斗.md)和[投掷器](投掷器.md)也可用于插入音乐唱片。

正在播放音乐唱片的唱片机会不停发出音符[粒子](粒子.md)，且颜色会不断变化。粒子和[音符盒](音符盒.md)调音时发出的粒子相同。

[悦灵](悦灵.md)和被驯服的[鹦鹉](鹦鹉.md)会在唱片机播放音乐唱片时跳舞。

# = 红石元件 =

[红石比较器](红石比较器.md)可以检测唱片机内的音乐唱片的ID，并根据ID输出不同强度的信号。不同音乐唱片所对应的红石信号强度如下：

唱片机播放音乐唱片时会直接[输出](红石元件列表#电源.md)15级的红石信号。

# = 循环播放 =
正在播放音乐唱片的唱片机会发出红石信号，从而使与其紧邻的[漏斗](漏斗.md)停止工作。由于漏斗在歌曲播放完毕后会重新工作，漏斗可以用于自动插入和移除音乐唱片以实现循环播放。<ref></ref>
但其不适用于使用了[红石比较器](红石比较器.md)的情况，因为红石比较器只会检测唱片机内是否存在音乐唱片，而不会检查音乐唱片是否正在播放。

# = 燃料 =
唱片机可作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)使用，每个唱片机可以烧炼1.5个物品。

# 你知道吗
[100px|右|缩略图|C418的皮肤](File:C418 skin.png.md)
* Minecraft音乐制作者之一[C418](C418.md)的[皮肤](皮肤.md)是有着唱片机头部的Steve。
* 使用[钻石](钻石.md)作为唱片机合成配方的一部分可能是参考了使用的钻石指针。
* 唱片机的侧面和底面的纹理与[音符盒](音符盒.md)相同。
* 唱片机必须通过[宝库](宝库.md)战利品才能实现可再生。这是因为可用于制造唱片机的[钻石](钻石.md)同样依赖宝库战利品实现可再生，而宝库可以被每个玩家打开无限次数<ref></ref>，且[试炼钥匙](试炼钥匙.md)和[不祥试炼钥匙](不祥试炼钥匙.md)是[可再生资源](可再生资源.md)。
