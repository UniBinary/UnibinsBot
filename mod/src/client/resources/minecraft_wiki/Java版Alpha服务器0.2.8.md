# Java版Alpha服务器0.2.8

*页面ID: 45548* | *来源: Minecraft Wiki*

* *0.2.8**是一个非强制更新的[Alpha](Java版Alpha.md)服务器更新，发布于2010年12月3日。<ref></ref>

# 更改
* 玩家在连接到服务器或在服务器重生后3秒内处于无敌状态。
* 加入服务器页现在会记住服务器的端口和IP地址。
* 向多人游戏加入了命令，可以对玩家造成的伤害。

# 修复
* 修复了一个在特定端口加入服务器会导致忘记所有键位设置的漏洞。
