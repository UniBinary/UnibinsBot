# 启动器2.1.13xx

*页面ID: 65475* | *来源: Minecraft Wiki*

* *2.1.1351**（[Windows](wzh:Microsoft Windows.md)）、**2.1.1350**（[macOS](wzh:macOS.md)）或**2.1.1349** （[Linux](wzh:Linux.md)）是一次[启动器](启动器.md)更新，发布于2018年6月26日，修复了一些漏洞。

# 新增
* 现在安装Minecraft版本时，启动器会检查计算机是否符合要求。如果不符合，则会显示一条消息。
* 现在启动器会显示使游戏崩溃的原因。

# 修复
*  - 1.2.5之前版本的服务器下载链接无效。
*  - 查看崩溃日志的链接无效。
*  - 游戏崩溃时，如果已关闭日志窗口，则启动器不会显示打开崩溃日志的链接。
*  - 错误详细信息中有文字编码错误。
*  - 游戏输出日志中的“显示行数”选项总是设置为“全部”，即使更改它也是这样。
*  - 启动器中提供的是错误的快照版服务器链接。
*  - JVM参数为空时，游戏不能启动。
*  - <code>.dll</code>文件不存在。
*  - 在启动选项标签页上删除配置后，在新闻标签页上不会把它取消选择。
*  - "Copy"字符串不能被翻译。
*  - 访问<code><nowiki>http://resources.download.minecraft.net/ad/</nowiki></code>时返回403错误码。但访问其他目录或<code><nowiki>https://resources.download.minecraft.net/ad/</nowiki></code>时则成功。
