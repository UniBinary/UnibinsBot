# Java版15w36d

*页面ID: 18075* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w36d**是[Java版1.9](Java版1.9.md)的第22个快照，发布于2015年9月4日<ref></ref>，发布以修复[15w36a](15w36a.md)、[15w36b](15w36b.md)和[15w36c](15w36c.md)中的一些漏洞，以及作出一些小更改。

# 新内容
# = 常规 =
* *[属性](属性.md)**
* 盔甲的防护现在可以用<code>generic.armor</code>属性编辑，范围从0（无防护）到30。

# 更改
# = 方块 =
* *[命令方块](命令方块.md)**
* 不同类型的命令方块现在在[地图](地图.md)上将显示不同的颜色。

# = 物品 =
* *[盔甲](盔甲.md)**
* 移除盔甲防护随耐久降低。
* * 盔甲的防护会显示在浮动条上。

# = 命令格式 =
* ***
* 玩家现在可以通过来编辑[生物](生物.md)的副手槽位。
* * 物品根据生物的主手显示。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* [锋利](锋利.md)增加的伤害从<code>-{}-等级+0.5*（等级-1）</code>更改为<code>-{}-1+0.5*（等级-1）</code>。
