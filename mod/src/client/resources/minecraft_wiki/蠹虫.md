* *（Silverfish）**是一种小型的似虫的敌对生物。

# 生成
# = 虫蚀方块 =
摧毁[虫蚀方块](虫蚀方块.md)会生成蠹虫。使用附魔[精准采集](精准采集.md)的工具摧毁虫蚀方块不会生成蠹虫，而是会掉落该方块被虫蚀之前的原始方块。

# = 刷怪笼 =
蠹虫刷怪笼自然生成于[要塞](要塞.md)的末地传送门房间里。

从[刷怪笼](刷怪笼.md)生成时，蠹虫只能生成在亮度等级小于等于11的地方；在可被蛀蚀的方块（石头、深板岩等）上生成则不受亮度等级限制。它们不能生成在玩家[直线距离](距离#欧几里得距离.md)5格半径以内的地方。

# = 试炼刷怪笼 =
[试炼密室](试炼密室.md)中的小型近战型[试炼刷怪笼](试炼刷怪笼.md)包含蠹虫试炼刷怪笼。

激活状态的[不祥试炼刷怪笼](试炼刷怪笼#生成不祥之物.md)在投掷滞留药水时，的概率带有[寄生](寄生.md)效果从而使生物受伤后生成蠹虫。这与试炼刷怪笼原本的类型无关。

# = 状态效果 =
拥有[寄生](寄生.md)状态效果的生物每次受到伤害时有10%的概率生成1-2只蠹虫。

# 掉落物
蠹虫在被[玩家](玩家.md)或者驯服的[狼](狼.md)杀死时会掉落。

# 行为
蠹虫会主动攻击[玩家](玩家.md)、。

当蠹虫受到攻击或[魔法伤害](魔法伤害.md)（如[中毒](中毒.md)效果的伤害）时，其他在21×11×21区域内的[虫蚀方块](虫蚀方块.md)会被破坏并生成蠹虫前来增援。这些蠹虫的视线能够穿过墙壁，并一路找到玩家的位置。若蠹虫被一击杀死则不会引来增援。<ref></ref>如果关闭游戏规则，则虫蚀方块被破坏后不会产生蠹虫。

如果一只蠹虫被其他生物所攻击，附近的蠹虫会对该生物产生敌意。

当蠹虫空闲时，它们会跑进周围的[石头](石头.md)、[圆石](圆石.md)、[石砖](石砖.md)、[苔石砖](苔石砖.md)、[裂纹石砖](裂纹石砖.md)、[雕纹石砖](雕纹石砖.md)或[深板岩](深板岩.md)里，并将该方块转化为对应的[虫蚀方块](虫蚀方块.md)。如果蠹虫正在参与试炼，则不会钻入方块。

如果关闭游戏规则，呼-{}-叫增援时虫蚀方块不会被破坏或生成增援的蠹虫，但会转变为对应的未虫蚀方块；且蠹虫不会钻入方块中。

蠹虫免疫[寄生](寄生.md)状态效果。

蠹虫死亡时并不是侧着倒下，而是底朝天翻转，[蜘蛛](蜘蛛.md)、[洞穴蜘蛛](洞穴蜘蛛.md)和[末影螨](末影螨.md)同样如此。

# = 生物族群 =

蠹虫是[节肢生物](节肢生物.md)，被带有[节肢杀手](节肢杀手.md)魔咒的武器近战攻击时会受到额外的伤害，并被施加数秒的[緩速](緩速.md)IV效果。

# 你知道吗
* 在现实中，[蠹虫](wzh:蠹魚.md)是一种可以在建筑物的黑暗地区和海边的木质建筑以及树上找到的无害的外观类似虾的小型无翼昆虫，它们因损害木制品，纸制品和衣物而臭名远扬。在寒冷的温度下它们会在水里冬眠，它们此时的状态就像小石头或沙砾一样，这与它们在游戏中可以钻入石头的行为相似。
* 愚人节玩笑[Java版2.0](Java版2.0.md)加入了“红石虫”，行为与蠹虫相同，会在红石线信号强度快速变化的地方生成。
