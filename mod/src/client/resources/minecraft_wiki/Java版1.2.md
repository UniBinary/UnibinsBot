# Java版1.2

*页面ID: 32335* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.2**是[Java版1.2.1](Java版1.2.1.md)的唯一一个预发布版，发布于2012年2月29日<ref name="blogspot_1.2"></ref>，加入了新的方块，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[雕纹石砖](雕纹石砖.md)**
* 石砖的新的变种。
* 创造模式独有方块。

* *[砂岩](砂岩.md)**
* 加入了2个新的纹理到文件。它们与[砂岩](砂岩.md)相似，但是它们包含了象形文字，并且没有加入到游戏里：[32px](File:Chiseled Sandstone (side texture) JE0.png.md) [32px](File:Cut Sandstone (side texture) JE0.png.md)

# = 生物 =
* *[铁傀儡](铁傀儡.md)**
* 现在有了音效。

# 更改
# = 方块 =
* *[红石灯](红石灯.md)**
* 更改了纹理。

* *[台阶](台阶.md)**
* 制作台阶时现在会得到6个台阶而不是3个。
* 放置在方块的底部时可以上下颠倒。

* *[梯子](梯子.md)**
* 制作梯子时现在会得到3个梯子而不是2个。

# = 常规 =
* *[控制](控制.md)**
* 移除了在[12w08a](12w08a.md)加入的镜头控制。

* *[调试屏幕](调试屏幕.md)**
* 现在会显示玩家所在的[生物群系](生物群系.md)。并且全局、天空和方块的亮度数值现在对应称为、和。

# 修复
* *修复了21个漏洞**
* 修改了铁傀儡的生成率。
* 修复了放置红石时，动力铁轨的状态更新问题。
* 修复了在雪上放置楼梯时倒置的问题。
* 修复了不能在倒置楼梯（普通楼梯也有可能）上放置火把的问题。
* 修复了唱片机不能在128层以上播放的问题。
* 修复了蘑菇不能在128层以上长成巨型蘑菇的问题。
* 修复了在128层上使用骨粉催熟树木的问题。
* 修复了在建造铁傀儡过程中崩溃的问题。
* 修复了建造铁傀儡时，在它们上方的方块被破坏的问题。
* 修复了已驯服的狼依然会攻击绵羊的问题。
* 修复了一些语言上的问题。
* 修复了一些关于Anvil文件格式的问题。
* 修复了客户端不能正确处理群系值大于22的群系的问题。
* 修复了由于新世界高度而导致的代码检查在无效的生成位置中发生的问题，此问题导致生物的生成速度要快一倍。
* 修复了在基岩上方生成了熔岩湖的问题。
* 修复了铁傀儡的纹理是白色或不可见的问题。
* 修复了铁傀儡模型的问题。
* 修复了村民在晚上感到不安的问题。
* 修复了从灵魂沙上掉落下界疣的问题。
* 修复了铁傀儡造成的卡顿问题。
* 修复了铁傀儡会溺水的问题。</onlyinclude>
