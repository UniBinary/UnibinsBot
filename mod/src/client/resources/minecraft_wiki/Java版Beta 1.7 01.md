# Java版Beta 1.7 01

*页面ID: 32731* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.7_01**是Java版的一次次要更新，发布于2011年6月30日<ref></ref>。修复了[Beta 1.7](Java版Beta 1.7.md)中的一些漏洞和崩溃。

# 修复
* *修复了2个漏洞**
* 修复了一个关于活塞的漏洞。
* 修复了空手时右键点击绵羊会使游戏崩溃的漏洞。</onlyinclude>

# 你知道吗
* 这个版本的补丁程序编号与其他的Beta 1.7更新不一致。这个版本的补丁编号为“_01”，而其他的则为“.n”。版本“Beta 1.7.1”不存在。
* 此版本后游戏不再由[Notch](Notch.md)独立完成。
