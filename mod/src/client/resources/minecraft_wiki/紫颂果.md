# 紫颂果

*页面ID: 17501* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *紫颂果（Chorus Fruit）**是一种[食物](食物.md)类物品，可以被食用或烧炼成[爆裂紫颂果](爆裂紫颂果.md)。

# 获取

[紫颂植株](紫颂植株.md)被破坏时会有50％的概率掉落1个紫颂果，该概率不受[时运](时运.md)魔咒影响。

# 用途
# = 食物 =

手持紫颂果按住键即可食用，每个紫颂果可以回复。

食用紫颂果会引发的紫颂果物品冷却时间，期间受影响玩家不可食用紫颂果。

与大部分食物不同，玩家在满饥饿值的情况下依旧可以食用紫颂果。

# = 传送 =
当[生物](生物.md)食用紫颂果后，该生物将会以[末影人](末影人.md)传送的相似方式传送，在8格[切比雪夫距离](切比雪夫距离.md)内尝试随机选择目标位置，最多尝试16次。不同之处在于，玩家可传送至仅2格高的空间（若玩家处于爬行状态则为1格高）。玩家不会精确落在方块的中心点，而是可能出现在8格范围内的任意位置。若此范围内无有效位置，则传送失败，玩家保持原地。若玩家距离有效目标过远，则无论当前高度如何，都将被垂直传送至地面。

与末影珍珠不同，紫颂果可使玩家穿透固体方块传送。算法会尽量避免流体，玩家无法传送至被水或熔岩占据的空间。但玩家可能被传送到[火](火.md)、[仙人掌](仙人掌.md)或[岩浆块](岩浆块.md)等危险方块上。

当该生物是乘客时，不论传送是否成功，该生物都会停止骑乘。当传送成功时，与末影人瞬移相似的音效会在该生物传送前的位置播放，并重置下落高度。该机制使玩家可以借此穿墙或避免摔落伤害。

紫颂果的传送能力在下界基岩层上方完全不起作用，且不能用来穿越基岩层。

[狐狸](狐狸.md)也可以通过食用紫颂果进行传送，机制与玩家相同。
