# 携带版0.16.2

*页面ID: 26395* | *来源: Minecraft Wiki*

* *v0.16.2 alpha**是携带版的一次次要更新，在Android上发布于2016年11月17日，其余版本发布于11月18日<ref></ref>，加入了卡通纹理包，并修复了[v0.16.1 alpha](携带版0.16.1.md)中的一些漏洞与崩溃。

# 新内容
# = 世界生成 =
* *[村庄](村庄.md)**
* 一个包含农作物的[箱子](箱子.md)会生成于积雪针叶林和雪原村庄的大型住宅里面。

# = 常规 =
* *[资源包](资源包.md)**
* 卡通[纹理包](纹理包.md)。

* 使用打火石激活的苦力怕可以取消爆炸状态。
* 射箭时，箭会从错误的方向飞出。
