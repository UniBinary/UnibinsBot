* *光源方块（Light）**是一种隐形的方块，可以产生0到15级的亮度，主要用于地图制作。

# 生成
光源方块不会生成在世界中。

# 获取

光源方块无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，光源方块可以通过”，或“”中有光源方块）|JE}}、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

使用命令{level:"<int>"<nowiki/>}]}}可获得指定亮度与物品模型的光源方块。若亮度小于0，则物品会使用亮度为0的纹理，大于15则使用亮度为15的纹理。若亮度未指定或不在0-15范围内，其会发出亮度为15的光。

使用命令可获得指定亮度与物品模型的光源方块，数据值未指定则默认为0级。

# 破坏
光源方块不能被挖掘破坏。

光源方块被破坏后不会掉落。

# 用途
光源方块（右一）以及游戏中的其他隐形方块被渲染出的立方体框外观}}
作为一种被设计为隐藏自身存在的方块，光源方块有许多与[结构空位](结构空位.md)相似的性质。

光源方块通常是不可见的，并且没有碰撞箱。

光源方块不会被[水](水.md)或冲毁，

光源方块会阻碍植物生长。

光源方块具有一个完整方块大小的判定箱，但只在玩家手持光源方块时才可以选中，否则玩家只能选中其后方的物体。

在光源方块的判定箱上尝试放置不是光源方块的方块时，方块会取代光源方块。<ref></ref>

光源方块可以含水。含水的光源方块可以通过在光源方块中放置水来获得，允许玩家创造发光且不会结冰或被[熔岩](熔岩.md)破坏的水体。

[缩略图|200px|[[结构方块](file:Light (shown) JE1.png.md)启用的渲染]]

光源方块是一种“隐形方块”，位于开启了“显示隐形方块”的储存模式[结构方块](结构方块.md)的存储区域范围内的光源方块会显示出一个淡黄色的立方体框。

光源方块不可被[活塞](活塞.md)推动和拉动<ref></ref>；而光源方块可被[活塞](活塞.md)推动和拉动<ref></ref>。

# = 等级 =
每个光源方块（无论为[方块](方块.md)还是[物品](物品.md)形式）都有一定的等级，可以是0-15中的任何整数值。物品形式的光源方块纹理为“灯泡”图案，且在等级不为0时，“灯泡”看上去是发光的。纹理左上角还标有显示亮度等级的数字。光源方块的等级决定了其方块形式的亮度等级。

光源方块的等级由其方块状态控制，光源方块的物品形式的等级则由物品数据控制。

光源方块的不同等级具有不同ID。

在创造模式中，对放置的光源方块按键可以顺次更改亮度等级，每次交互会增加1级亮度等级，等级为15时交互则会降回0。

光源方块的判定箱只有在玩家手持光源方块物品时才能选中，因此玩家需要持有光源方块才能与其交互。

除了发出光以外，光源方块还有许多独特的特性，因此玩家可以使用等级为0的光源方块来利用这些特性而不产生光。

# = 粒子 =
类似于[屏障](屏障.md)，在[创造模式](创造模式.md)下，当玩家手持物品形式的光源方块时，所有已经放置的光源方块会以[粒子效果](粒子效果.md)的方式显示其物品图标。图标将在玩家手持光源方块后随机显示，每个粒子显示。距离越近显示概率越大，最终在32格（[切比雪夫距离](切比雪夫距离.md)）外完全不显示；它们将在玩家手持光源方块后立即全部显示。这个效果是客户端处理的，而且在生存模式中拿着光源方块不会出现此粒子效果。当[](视频设置.md)设置为“最少”时，光源方块粒子将不会被显示。

# = 光源 =
光源方块发出亮度等级等同于其方块状态level存储的等级的光。对应ID的光源方块发出对应的亮度等级的光。

等级为0的光源方块不会发光。
