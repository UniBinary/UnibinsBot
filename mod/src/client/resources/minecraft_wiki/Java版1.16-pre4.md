# Java版1.16-pre4

*页面ID: 63904* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.16-pre4**是[Java版1.16](Java版1.16.md)的第4个预发布版，发布于2020年6月11日<ref></ref>，更改了骷髅在灵魂沙峡谷的生成权重和诡异森林与灵魂沙峡谷的生物生成速率，并修复了一些漏洞。

# 更改
# = 世界生成 =
* *[灵魂沙峡谷](灵魂沙峡谷.md)**
* 将骷髅的生成权重由2提升至10。

# = 命令格式 =
* ***
* 将启用/禁用数据包时的聊天输出从“已启用/已禁用数据包 <数据包>”更改为“正在启用/正在禁用数据包 <数据包>”。

# = 游戏内容 =
* *[生成](生成.md)**
* 调整了[诡异森林](诡异森林.md)和[灵魂沙峡谷](灵魂沙峡谷.md)的生物生成速率。
