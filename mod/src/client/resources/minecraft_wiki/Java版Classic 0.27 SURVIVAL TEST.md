# Java版Classic 0.27 SURVIVAL TEST

*页面ID: 35603* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.27 SURVIVAL TEST**是[Java版Classic](Java版Classic.md)的一次更新，发布于2009年10月24日。<ref></ref><ref></ref>

# 更改
# = 方块 =
* *[水](水.md)**
* 现在水贴图顶部的一侧有一个粉红色的条。

* *[熔岩](熔岩.md)**
* 现在熔岩纹理的一侧有一部分水的纹理。

# = 游戏内容 =
* *分数**
* 杀死[僵尸](僵尸.md)现在可以获得80分。
* 杀死[骷髅](骷髅.md)现在可以获得120分。
* 杀死[苦力怕](苦力怕.md)现在可以获得200分。
* 杀死[蜘蛛](蜘蛛.md)现在可以获得105分。

* *常规**
* [玩家](玩家.md)现在手持[物品](物品.md)时，手挥动的速度由原来每秒四次降低为每秒一次。
* * 这是一个强制性的限制，如果玩家点击得更快，手臂将不再摆动得更快。

# 修复
* *修复了1个漏洞**
* 在雨中杀死蜘蛛不再会使游戏崩溃。</onlyinclude>
