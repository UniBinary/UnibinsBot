# Java版15w36a

*页面ID: 18056* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w36a**是[Java版1.9](Java版1.9.md)的第19个快照，发布于2015年9月2日<ref></ref>，加入了一个新的记分板参数，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* *[记分板](记分板.md)**
* 加入了<code>collisionRule</code>参数。
* * 它决定了实体是否能够互相推撞，以及其是否依赖队伍。
* * 次级选项：<code>always</code>、<code>never</code>、<code>pushOtherTeam</code>、<code>pushOwnTeam</code>。

# 更改
# = 方块 =
* *常规**
* 不能使用[命令](命令.md)（例如）的玩家不再能放置[命令方块](命令方块.md)。

# = 物品 =
* *[盔甲](盔甲.md)**
* 盔甲防御计算的改变：
* * 满护甲值（20）减伤从80%削弱到66%（在[16w02a](16w02a.md)改回）。
* * 攻击力度更大时盔甲减伤效果更低：每点攻击减少点有效防御。

# = 生物 =
* *常规**
* 生物被攻击后AI不再重置。
* 所有攻击型生物能在视野中透过固体方块寻找并追逐玩家。

* *[骷髅](骷髅.md)、[苦力怕](苦力怕.md)与[僵尸](僵尸.md)**
* 对戴着[生物头颅](生物头颅.md)的玩家探测距离再次调整回正常距离的50%。

# = 非生物实体 =
* *常规**
* 绝大多数实体（[掉落物](掉落物.md)与[经验球](经验球.md)除外）可被其他实体推动。
* * 这不包括物品、[画](画.md)、[末地水晶](末地水晶.md)、区域效果云、[物品展示框](物品展示框.md)和经验球。
* * 这能通过队伍规则被[生物](生物.md)和玩家覆盖。
* * 相同类别的实体现在能被[钓鱼竿](钓鱼竿.md)的鱼钩“吸住”，如果是生物或者玩家将不再遭受击退或伪损伤。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 锋利与保护被削弱。
* * 第一级锋利为基础伤害增加点伤害并每增加一级随之增加0.5（×0.25），削弱自每级。
* * 保护提供的减伤从抛物线增长改为直线增长。

# = 常规 =
* *性能**
* 优化了连接至服务器时的内存分配。<ref></ref>
