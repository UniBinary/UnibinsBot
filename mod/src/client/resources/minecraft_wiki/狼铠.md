* *狼铠（Wolf Armor）**是一种可以为[狼](狼.md)装备的盔甲物品。

# == 材料修复 ==

每个[犰狳鳞甲](犰狳鳞甲.md)可以恢复狼铠25%的耐久（向下取整）。

# == 合并物品 ==

叠加2个狼铠的剩余耐久度，再额外获得12%的耐久度。

# = 生物掉落物 =
装备了狼铠的狼在死亡时会掉落一个狼铠。

# 用途
[right|160px|framless](File:Wolf wearing Wolf Armor.png.md)

玩家可以对自己驯服的狼以下物品：
* 狼铠：为其装备狼铠
* [剪刀](剪刀.md)：卸下其装备的狼铠
* [犰狳鳞甲](犰狳鳞甲.md)：为其装备的狼铠恢复8点[耐久度](耐久度.md)

# = 提供护甲值 =

装备狼铠的狼会获得[护甲值](护甲值.md)。

# = 提供受伤害行为 =

狼装备的狼铠通过消耗耐久度为狼抵消大多数非魔法[伤害](伤害.md)。

# = 染色 =

狼铠可以被染成12,326,391种颜色。

手持染色的狼铠对着装有水的[炼药锅](炼药锅.md)可以洗掉颜色。

# = 附魔 =
狼铠虽具有耐久度且可穿戴，但其不适用任何[魔咒](魔咒.md)。不过，通过命令及其他方法为狼铠添加的魔咒仍然可以正常生效。
