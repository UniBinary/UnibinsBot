# Java版22w12a

*页面ID: 94286* | *来源: Minecraft Wiki*

<onlyinclude>

* *22w12a**是[Java版1.19](Java版1.19.md)的第2个快照，发布于2022年3月24日<ref></ref>，加入了[运输船](运输船.md)，从[实验性快照](Java版1.19-exp1.md)中加入了生物[监守者](监守者.md)、[黑暗](黑暗.md)状态效果、[迅捷潜行](迅捷潜行.md)魔咒，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了监守者刷怪蛋。

# = 生物 =
* *[监守者](监守者.md)**
* 自[实验性快照](Java版1.19-exp1.md)加入。
* 不再是[亡灵生物](亡灵生物.md)。
* 现在可以攻击到4格高。
* 现在免疫火焰伤害，并且会在[水](水.md)和[熔岩](熔岩.md)中上浮。
* 修改了攻击动画。

# = 非生物实体 =
* *[运输船](运输船.md)**
* 一种携带着[箱子](箱子.md)、类似于[运输矿车](运输矿车.md)的载具，拥有多个木质变种。
* * 与不同的是，此快照中还有红树木变种。
* 可用[船](船.md)和箱子合成。
* 将其物品栏打开或将其破坏会使附近的成年[猪灵](猪灵.md)与玩家敌对。
* 破坏时掉落自身，其中的物品也会掉落出来。
* 只可再乘坐1个实体。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 自[实验性快照](Java版1.19-exp1.md)加入了[迅捷潜行](迅捷潜行.md)魔咒。
* * 现在其用于[护腿](护腿.md)，而非之前的[靴子](靴子.md)。
* * 暂时无法在生存模式下获得。

* *[状态效果](状态效果.md)**
* 自[实验性快照](Java版1.19-exp1.md)加入了[黑暗](黑暗.md)状态效果。
* * 玩家在触发监守者生成阶段或位于监守者附近时会被给予该效果。
* * 此效果会降低玩家的视野亮度，削弱其视觉能力。

# = 常规 =
* *[选项](选项.md)**
* 加入了新的辅助功能选项“”。
* * 用于控制玩家受黑暗效果影响时视野亮度降低的程度。

* *[粒子](粒子.md)**
* 加入了<code>shriek</code>粒子。

* *[标签](Java版标签.md)**
* 加入了物品标签。
* * 包含所有运输船。
* 加入了游戏事件标签。
* * 包含标签下的全部项目（除<code>flap</code>）、。

# 更改
# = 方块 =
* *[树叶](树叶.md)**
* 现在可以[含水](含水.md)，以同步。
* 红树树叶现在可用于[堆肥](堆肥.md)。

* *[幽匿催发体](幽匿催发体.md)**
* 不再生成[幽匿尖啸体](幽匿尖啸体.md)。<ref></ref>

* *[幽匿感测体](幽匿感测体.md)**
* 现在被[潜行](潜行.md)的玩家踩踏时也会激活。

* *[幽匿尖啸体](幽匿尖啸体.md)**
* 自[实验性快照](Java版1.19-exp1.md)加入了功能。
* * 激活后会发出尖啸声，同时顶部产生环状信号[粒子](粒子.md)。
* * 可由[幽匿感测体](幽匿感测体.md)或[红石信号](红石信号.md)激活，也会在被玩家踩踏时激活。
* ** 仅当周围48格内无监守者且周围16格内有非旁观者玩家时才能被激活。
* * 每次呼啸过后会给予玩家13秒（260游戏刻）的[黑暗](黑暗.md)状态效果。
* * 当生成阶段达到“”（即激活3次）并且游戏难度非和平时会生成监守者。
* ** 当生成一次后，再次生成只需触发一次。
* * 目前使用附有[精准采集](精准采集.md)魔咒的工具挖掘时不会掉落其对应的物品。

* *[活板门](活板门.md)**
* 现在[含水](含水.md)活板门改变状态时先[计划](刻#计划刻.md)流动，再发出[PP更新](方块更新#PP更新.md)。

* *[水](水.md)**
* 流动水不再接收四周水源或含水方块上下方[红石线](红石线.md)的间接[PP更新](方块更新#PP更新.md)。

# = 物品 =
* *[船](船.md)**
* 更改了除红树木船外所有船的物品纹理，以使船桨与船身颜色相匹配并同步。
* * 与间的橡木船物品纹理仍有差异。

# = 生物 =
* *[鹦鹉](鹦鹉.md)**
* 现在可以模仿监守者的声音。

# = 世界生成 =
* *[深暗之域](深暗之域.md)**
* 现在与周围区域相比更少含水了。

# = 命令格式 =
* ***
* 现在会返回目标位置的X、Y、Z三个坐标。
* 改进了对3D生物群系的定位，因此现在[洞穴类生物群系](洞穴类生物群系.md)能够正确定位。

# = 常规 =
* *[调试组合键](调试屏幕#调试组合键.md)**
* 移除了循环调整渲染距离的调试组合键（和）。

* *[粒子](粒子.md)**
* 修改了<code>vibration</code>粒子的参数。现在不再将起始位置指定为额外的参数，而是使用该粒子的常规产生位置。

* *[着色器](着色器.md)**
* 现在有新的用于渲染半透明实体的着色器文件。

* *[标签](Java版标签.md)**
* 向物品标签加入了红树木船和。
* 向方块标签加入了红树树叶。
