# Java版Beta 1.8.1

*页面ID: 32300* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.8.1**是的一次次要更新，发布于2011年9月15日<ref></ref>，修复了[Beta 1.8](Java版Beta 1.8.md)里的漏洞和崩溃。此版本兼容Beta 1.8的服务端。

# 更改
# = 世界生成 =
* *[废弃矿井](废弃矿井.md)**
* 柱子现在变成了[栅栏](栅栏.md)而不是[木板](木板.md)。

# 修复
* *修复了2个漏洞**
* 修复了键点击进入一个装满了的箱子或背包时游戏崩溃的漏洞。
* 修复了使用键点击将物品从发射器取出或放入时游戏崩溃的漏洞。</onlyinclude>
