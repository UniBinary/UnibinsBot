# Java版25w06a

*页面ID: 144370* | *来源: Minecraft Wiki*

<onlyinclude>

* *25w06a**是[Java版1.21.5](Java版1.21.5.md)的第5个快照，发布于2025年2月5日<ref></ref>，加入了[鸡](鸡.md)和[鸡蛋](鸡蛋.md)的新变种、[高枯草丛](高枯草丛.md)、[矮枯草丛](矮枯草丛.md)和[仙人掌花](仙人掌花.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[矮枯草丛](矮枯草丛.md)和[高枯草丛](高枯草丛.md)**
* 自然生成于[沙漠](沙漠.md)和[恶地](恶地.md)及其变种生物群系。
* 都只有一格高。
* 与[枯萎的灌木](枯萎的灌木.md)一样能放置于[沙子](沙子.md)、[陶瓦](陶瓦.md)和[泥土](泥土.md)类方块上。
* 对其骨粉：
* * 矮枯草丛会生长为高枯草丛。
* * 高枯草丛在其周围的有效位置生成矮枯草丛。
* 可用于[堆肥](堆肥.md)，有30%的几率增加一层堆肥层。
* 可用作[燃料](燃料.md)，每个[矮枯草丛](矮枯草丛.md)和[高枯草丛](高枯草丛.md)烧炼5秒（0.5个物品）。
* [绵羊](绵羊.md)可以食用它们以长出[羊毛](羊毛.md)。
* 仅在被[剪刀](剪刀.md)或附有[精准采集](精准采集.md)魔咒的工具破坏时掉落。

* *[仙人掌花](仙人掌花.md)**
* 一种花。
* 有一定概率在[沙漠](沙漠.md)和[恶地](恶地.md)及其变种生物群系的仙人掌柱上生成。
* 可放置于[仙人掌](仙人掌.md)或任何顶部可支撑其中心的方块上。
* 有概率由仙人掌长出：
* * 格高的仙人掌柱有10%概率长出仙人掌花而不长高。
* * 3格及更高的仙人掌柱有25%概率长出仙人掌花。
* * 和仙人掌一样，只有其四面均有空间时，仙人掌花才会生成。
* 可用于[堆肥](堆肥.md)，有30%的几率增加一层堆肥层。
* 可用于引诱、喂食[蜜蜂](蜜蜂.md)。
* 可用于合成1个[粉红色染料](粉红色染料.md)。
* 不同于其他一格高的[花](花.md)，仙人掌花不能放进[花盆](花盆.md)。<ref></ref>

# = 物品 =
* *[蓝色鸡蛋](蓝色鸡蛋.md)**
* 由寒带鸡产下的鸡蛋。
* 能生成幼年寒带鸡。
* 合成用途与普通鸡蛋相同。

* *[棕色鸡蛋](棕色鸡蛋.md)**
* 由热带鸡产下的鸡蛋。
* 能生成幼年热带鸡。
* 合成用途与普通鸡蛋相同。

# = 生物 =
* *[鸡](鸡.md)**
* 加入了鸡的变种：热带鸡和寒带鸡。
* * 原本的鸡即为温带鸡变种。

# = 游戏内容 =
* *[游戏规则](游戏规则.md)**
* 加入了新规则<code>allowFireTicksAwayFromPlayer</code>，默认值为<code>false</code>。
* * 为<code>true</code>时，距离玩家8个区块外的[火](火.md)和[熔岩](熔岩.md)仍可执行[游戏刻](游戏刻.md)。

# = 常规 =
* *[数据包](数据包.md)**
* 加入了子文件夹，以按[鸡变种定义格式](鸡变种定义格式.md)添加鸡变种。

* *[注册表](注册表.md)**
* 加入了<code>CHICKEN_VARIANT</code>可写注册表。

* *[物品堆叠组件](物品堆叠组件.md)**
* 加入了<code>chicken/variant</code>组件。

* *[标签](Java版标签.md)**
* 加入了物品标签：。
* * 所有[鸡蛋](鸡蛋.md)，用于[配方](配方.md)。
* * 此标签内的物品不会被[鸡骑士](鸡骑士.md)捡起。
* 加入了方块标签：。
* * 可被[绵羊](绵羊.md)食用而使其羊毛生长的方块。

# 更改
# = 方块 =
* *[萤火虫灌木丛](萤火虫灌木丛.md)**
* 满足以下条件时，每刻有概率会发出特殊的环境音效：
* * 在[主世界](主世界.md)中。
* * 在一天的第12600至23400刻间。
* * 上方没有除[树叶](树叶.md)外的[阻止运动方块](阻止运动方块.md)。

* *[火](火.md)**
* 周围8个区块内不含玩家时，火不再燃烧或蔓延。

* *[枯叶堆](枯叶堆.md)**
* 地图颜色由更改为。

# = 物品 =
* *[烟花火箭](烟花火箭.md)和[弩](弩.md)**
* 现在会合并提示框中的多个相同烟火之星或弹射物的提示文本。

# = 生物 =
* *[猪](猪.md)和[牛](牛.md)**
* 寒热带变种的生成生物群系条件现在与鸡变种一致。

* *[玩家](玩家.md)**
* 装备于盔甲槽位（包括副手）的物品现在也会在中储存。
* * 这些物品在中的字段会被移除，并转换为中[槽位](槽位.md)名称的对应字段（包括）。

# = 游戏内容 =
* *[进度](进度.md)**
* 进度“”现在移动到冒险根进度后。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[资源包](资源包.md)**
* 将资源包版本号更改为。
* 将温带鸡纹理重命名为，并从移动到。

* *[区块刻](区块刻.md)**
* 现在更改了部分区块刻的执行条件。
* * 雨雪相关逻辑、子区块内的[随机刻](随机刻.md)不再只在玩家128格内的区块中执行。
* * [雷暴](雷暴.md)相关逻辑、[周期生成](周期生成.md)仍需在玩家128格内的区块执行。

* *[标签](Java版标签.md)**
* 将方块标签重命名为了。
* 更新了生物群系标签。
