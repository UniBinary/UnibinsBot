# 基岩版1.21.90.28

*页面ID: 152639* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.90.28**（ChromeOS/Android）、**Preview 1.21.90.28**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.90](基岩版1.21.90.md)的第7个测试版，发布于2025年6月2日<ref></ref>，修复了一些漏洞。

# 更改
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 更改了烈焰人和旋风人刷怪蛋的纹理，以匹配对应生物的大小。

# = 常规 =
* *[全景图](全景图.md)**
* 再次更改了未启用时的全景图。
* * 由于测试版本默认使用独有全景图，新全景图在一般情况下并不可见。

# = 技术性 =
* *实体过滤器**
* 加入了实体过滤器，会在主实体骑乘指定族的坐骑时返回true。

# 修复
* *Android**
* 修复了Android设备在最新测试版中登录账户速度过慢，并且在登录前无法打开世界或设置的漏洞。（）

* *生物**
* 骑乘快乐恶魂的玩家不再会导致附近的快乐恶魂停止移动。
* * 这会在玩家飞得离快乐恶魂过近时防止互相阻挡。
* 恶魂的模型现在再次以其碰撞箱为中心。（）
* 现在即使在被骑乘时，快乐恶魂也可以被其他生物推动，除非有玩家站在其上方将其固定。
* 调整了烈焰人和旋风人刷怪蛋的大小，以匹配游戏内对应生物的大小。（）

* *图形**
* 在启用的情况下离开末地时，屏幕不再会变为亮白色。（）
* 在启用的情况下，GPU型号为Mali-G76的设备不再会黑屏。（）
* 在启用的情况下，拴绳不再会在某些角度不可见。（）
* 在启用的情况下，PlayStation 5设备上的水面纹理现在会正常反射天空。（）
* 在启用的情况下，细雪不再看起来与普通的雪块有明显区别。（）
* 现在部分主机（Xbox One、Xbox One S、PlayStation 4）会默认关闭。

* *用户界面**
* 修复了访问好友抽屉式菜单时可能发生的崩溃。</onlyinclude>
