# Java版23w07a

*页面ID: 102065* | *来源: Minecraft Wiki*

<onlyinclude>

* *23w07a**是[Java版1.19.4](Java版1.19.4.md)的第5个，也是最后一个快照，发布于2023年2月15日<ref></ref>，在内置实验性数据包中加入了[嗅探兽](嗅探兽.md)、[樱花树林](樱花树林.md)和考古学相关内容，并修复了一些漏洞。

# 新内容
# = 非生物实体 =
* *[交互实体](交互实体.md)**
* 一种新的实体，会记录所有的和动作。交互实体（）是不可见的，并且有自定义的尺寸，有以下字段：
* * ：实体边界箱的宽度（默认为）。
* * ：实体边界箱的高度（默认为）。
* * ：一个action对象，记录了实体的上一个攻击动作。
* * ：一个action对象，记录了实体的上一个交互动作。
* * ：布尔值，表示交互是否应该触发响应（如手臂挥动、声音效果等，默认为）。
* 相应地，加入了action对象。存储行为时，这个对象有两个字段：
* * ：执行此行为的玩家的UUID（标准整数数组形式）。
* * ：事件发生时，游戏刻的时间戳（存储为长整型）。
* 这使得现在可以使用命令达到以下目的：
* * 将命令执行者设置为最后攻击该实体的玩家：。
* * 将命令执行者设置为最后与该实体交互的玩家：。
* 下列进度触发器也可以检测到相应事件：
* * 可检测到与此实体交互的事件。
* * 可检测到攻击此实体的事件。

# 更改
# = 方块 =
* *[唱片机](唱片机.md)**
* 现在播放[音乐唱片](音乐唱片.md)时会直接发出强度为15的红石信号。
* 现在可以与[投掷器](投掷器.md)和[漏斗](漏斗.md)交互。

# = 生物 =
* *[马](马.md)及其变种**
* 繁殖马及其变种产下的新个体的速度、跳跃高度和生命值不再会趋近双亲对应属性的平均值。
* * 这意味着繁殖马产生的新个体的属性有可能会超越双亲。

# = 常规 =
* *[Realms](Realms.md)**
* 更新了Realms界面，使之更符合单人和多人游戏的界面。

* *[配方](配方.md)**
* 现在[工作台](工作台.md)的合成配方在创建世界后会自动解锁。
* [弩](弩.md)和[灵魂营火](灵魂营火.md)的合成配方不再在得到木棍后解锁。

* *[资源包](资源包.md)**
* 现在原版资源包的语言文件以字符串键名的字母顺序排列。

# 新内容（实验性）
# = 方块 =
* *[樱花树叶](樱花树叶.md)**
* 一种新的树叶，长满粉红色的花朵，其下方会出现粉红色的下落粒子。
* [蜜蜂](蜜蜂.md)会采集它的花粉。

* *[樱花原木](樱花原木.md)**
* 一种紫褐色外皮、粉红色内干的原木，有对应的去皮变种。
* * 去皮变种可以合成对应种类的[悬挂式告示牌](悬挂式告示牌.md)。
* 可用于合成对应种类的[木板](木板.md)。

* *[樱花木板](樱花木板.md)**
* 一种新的木板。
* 可以合成对应种类的[按钮](按钮.md)、[门](门.md)、[栅栏](栅栏.md)、[栅栏门](栅栏门.md)、[压力板](压力板.md)、[告示牌](告示牌.md)、[台阶](台阶.md)、[楼梯](楼梯.md)和[活板门](活板门.md)。

* *[樱花树苗](樱花树苗.md)**
* 一种新的树苗。
* 可以放置在[花盆](花盆.md)中。

* *[櫻花木塊](櫻花木塊.md)**
* 樱花原木的木头变种，有对应的去皮变种。
* 可用于合成对应种类的木板。

* *[饰纹陶罐](饰纹陶罐.md)**
* 在合成表中使用4个[陶片](陶片.md)或[红砖](红砖.md)摆成菱形以合成。
* * 陶片的种类决定了输出陶罐的对应面出现何种图案，使用红砖则没有图案。
* 非常容易被破坏。
* * 使用[剑](剑.md)、[镐](镐.md)、[锹](锹.md)、[锄](锄.md)、[斧](斧.md)或[三叉戟](三叉戟.md)进行破坏，会碎裂成其原先的合成材料。
* * 徒手破坏、被活塞推动和使用附有[精准采集](精准采集.md)魔咒的工具破坏时掉落自身。

* *[粉红色花簇](粉红色花簇.md)**
* 一种新的方块，在樱花树林中自然生成。
* 可通过对已有的粉红色花簇或樱花树林的地面使用[骨粉](骨粉.md)再生。
* 类似于[海泡菜](海泡菜.md)，一个方块内可以放置4个。
* 可以以特定方向放置。
* 可以用来合成[粉红色染料](粉红色染料.md)。
* 蜜蜂会采集它的花粉。

* *[可疑的沙子](可疑的沙子.md)**
* 与[沙子](沙子.md)相似，但纹理看起来更粗糙。
* 受重力影响，会在落地时消失。
* 被挖掘或被活塞推动时不掉落任何物品，用附有精准采集的工具挖掘也不会掉落。
* 会在[沙漠神殿](沙漠神殿.md)和[沙漠水井](沙漠水井.md)中自然生成，两处生成的可疑的沙子带有的战利品表不同。
* 用[刷子](刷子.md)刷可疑的沙子可以刷出物品。
* * 清刷时，可疑的沙子会经历4个阶段，若中途停止，会逐渐恢复原状。
* * 清刷完成后，可疑的沙子转变为普通沙子。
* * 带有有效战利品表的可疑的沙子才能刷出物品。

* *[火把花植株](火把花植株.md)**
* 可用火把花种子在[耕地](耕地.md)上种出。
* 共有3个生长阶段，完全成熟时变为火把花。
* 若完全成熟，破坏时掉落火把花；若未完全成熟，破坏时掉落火把花种子。

* *[火把花](火把花.md)**
* 一种新的植物。
* 可用于合成[橙色染料](橙色染料.md)。
* 可以放置在[花盆](花盆.md)中。

# = 物品 =
* *[刷子](刷子.md)**
* 用于清刷方块的物品。
* 使用3根[线](线.md)和2个[木棍](木棍.md)合成，摆放方式类似于[镐](镐.md)。
* 成功刷出物品时消耗1点耐久。
* 对可疑的沙子外的其他方块没有实际效果。

* *[陶片](陶片.md)**
* 共有四种，分别为弓箭纹样、举臂纹样、珍宝纹样和头颅纹样。
* 无法合成，只能通过刷可疑的沙子来获得。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了嗅探兽刷怪蛋。

* *[火把花种子](火把花种子.md)**
* 一种新的种子，可以种植在[耕地](耕地.md)上。
* 可通过嗅探兽挖掘获得。

# = 生物 =
* *[嗅探兽](嗅探兽.md)**
* [Minecraft Live 2022](Minecraft Live 2022.md)生物投票的获胜生物，属于友好生物，体型很大。
* 有点生命值。
* 目前不会自然生成。
* 不会被食物吸引，不能被驯服。
* 时常嗅探空气，有时能挖掘出火把花种子。
* * 有8分钟冷却时间。
* * 最近被挖掘过的20个方块会被记录，并且不再寻求挖掘这些方块。
* 可以使用火把花种子喂养和繁殖。
* 死亡时掉落[苔藓块](苔藓块.md)。

# = 非生物实体 =
* *[樱花木船](樱花木船.md)**
* 一种新的船，使用樱花木板合成。

* *[樱花木运输船](樱花木运输船.md)**
* 一种新的运输船，使用樱花木船和[箱子](箱子.md)合成。

# = 世界生成 =
* *[樱花树林](樱花树林.md)**
* 一种新的[山地](山地.md)生物群系变种，类似于[草甸](草甸.md)。
* 含有[樱花树](樱花树.md)，一种新的[树木](树木.md)。
* * 可由樱花树苗长成。
* * 有5%的概率带有[蜂巢](蜂巢（方块）.md)。
* 可以自然生成[兔子](兔子.md)、[驴](驴.md)、[绵羊](绵羊.md)、[蜜蜂](蜜蜂.md)。
