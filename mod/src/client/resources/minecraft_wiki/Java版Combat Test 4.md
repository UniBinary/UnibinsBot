# Java版Combat Test 4

*页面ID: 49825* | *来源: Minecraft Wiki*

}}<onlyinclude>

* *Combat Test 4**是未来的战斗改版的第4个公开的实验性版本，发布于2019年11月29日<ref></ref>，虽然它是未来版本的测试版，但这个战斗实验版是[Java版1.15-pre3](Java版1.15-pre3.md)的分支<ref group="注">Combat Test 4于1.15-pre3发布的次日被编译。</ref>。此版本只发布在[Reddit](wzh:Reddit.md)上，因此其并不出现在[启动器](启动器.md)版本列表或[Minecraft.net](Minecraft.net.md)的文章中。

# 新内容
# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 剑原本独有的所有伤害加成型魔咒现在可以通过[附魔台](附魔台.md)直接附魔给[斧](斧.md)。

* *[盾牌](盾牌.md)**
* 加入了禁用在潜行时自动使用盾牌防御的选项。
* * 该选项位于辅助功能菜单当中。

# 更改
# = 物品 =
* *[盾牌](盾牌.md)**
* 移除了隐藏盾牌的选项。

* *[雪球](雪球.md)**
* 现在可堆叠至64。

* *[三叉戟](三叉戟.md)**
* 现在可以由[发射器](发射器.md)发射。
* 带有[忠诚](忠诚.md)魔咒的三叉戟落入虚空也会飞回玩家的手上。
* 带有[穿刺](穿刺.md)魔咒的三叉戟现在会对所有在水中或雨中的生物造成额外伤害。

# = 非生物实体 =
* *[箭](箭.md)**
* 提高了箭的射击精度（“误差范围”从1.0降至了0.25）。

* *扔出的[雪球](雪球.md)**
* 现在有4刻的冷却时间。
* 掷出后的2刻内不会被渲染（以防遮挡玩家视角）。

# = 游戏内容 =
* *[战斗](Tutorial:战斗.md)**
* 攻击指示器现在只会在发动攻击时重置（切换手中的物品现在不会重置攻击指示器）。
* 暴击现在会在攻击冷却达到100%时触发。
* 击退攻击现在会在攻击冷却达到100%时触发。
* 普通攻击的距离减少了0.5格，现在为2.5格。
* 当攻击冷却达到200%时，攻击距离会额外增加1.0格（原为增加0.5格）。
