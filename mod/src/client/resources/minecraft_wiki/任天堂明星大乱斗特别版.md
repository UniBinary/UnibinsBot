《**任天堂明星大乱斗　特别版**》（日文：<span lang="ja">**-{大乱闘スマッシュブラザーズ}- SPECIAL**</span>，英文：**Super Smash Bros. Ultimate**）是一款发表于上的动作类游戏，于2018年12月7日发售。属于任天堂的明星合集类游戏。

Minecraft相关内容在2020年10月13日作为DLC加入。

# Minecraft相关
# = 史蒂夫/艾莉克斯 =

# = 取胜乱斗：寻找世界的终点 =

史蒂夫和艾莉克斯取胜乱斗中的所有斗士都是来自Minecraft中的各种敌对生物。前六回合除第二轮为队伍乱斗外，其他回合都是军团战。结尾制作人员名单的音乐是《Earth》。

# = 场地 =
* *《我的世界》的世界**是《任天堂明星大乱斗　特别版》中的一块场地。根据纹理不同，世界还可以使用不同的[生物群系](生物群系.md)，因此布局也相异。场地同时也会根据音乐不同进行[昼夜更替](昼夜更替.md)。根据地形区别判断，本场地的背景似乎是基于[Java版](Java版.md)的，因为平原场的草更加饱满，雪在冻原场没有和植物占据同一个方块。

各个生物群系可以通过在场地选择界面输入来强制加载。详细如下：
* [平原](平原.md) - 默认的生物群系。背景中有一座村庄，其中有一座钟和农场，还有几间小屋和一堆干草。这一生物群系也同样可以战场化和终点化。可以按住加载。
* [](桦木森林.md)|}} - 平台被两棵桦树掩盖着。可以按住 + 加载。
* [](热带草原.md) - 有着双重树冠的金合欢树，隐藏了一块平台。可以按住 + 上加载。
* [](针叶林.md)}} - 背景中有一间针叶林村庄的村庄小屋。平台上有一堆圆石堆和一棵云杉木。可以按住 + 右加载。
* [](雪原.md) - 背景中有一间雪原的村庄小屋，还有一块羊圈和一座灯柱。此场地有两块平台，中间有一间雪屋。可以按住 + 下加载。
* [石岸](石岸.md) - 有一块平台，有像洞穴一样的石头结构。背景中的群山和场地中隔着海洋。可以按住 + 左加载。

# 你知道吗
* 在游戏文件中，史蒂夫的代号是“pickel”。日语中“pikkeru”一词指的是冰镐，源自德语“Eispickel”。
* 据前Minecraft开发者[Daniel Kaplan](Daniel Kaplan.md)称，任天堂和[Mojang Studios](Mojang Studios.md)至少花了5年时间谈判，才让史蒂夫出现在《任天堂明星大乱斗》中。<ref></ref>
* 2020年10月1日，史蒂夫的首次揭露引发了Twitter上的大量访问，导致该网站一度无法访问。Twitter上一次服务中断是在2009年6月25日，当时著名歌手迈克尔·杰克逊的去世也引发了类似的访问量激增。<ref>https://www.eventhubs.com/news/2020/oct/06/smash-steve-broke-twitter/</ref>
* 史蒂夫的每套可选皮肤都来自[Minecraft中的单一纹理](https://www.ssbwiki.com/File:SteveTextures.png)并略微修改以适应《任天堂明星大乱斗　特别版》的光照。这使得通过替换文件来修改皮肤变得十分简单。
* 由于发布时[下界更新](下界更新.md)是最新版本，任何后续版本的纹理更改都不会同步到《任天堂明星大乱斗　特别版》中。
* 虽然大多数史蒂夫招式和《我的世界》的世界场地的Minecraft纹理使用[纹理更新](纹理更新.md)的纹理，但一些物品（例如掉落的鞘翅、掉落的矿车、掉落的[橡木原木](橡木原木.md)、掉落的[圆石](圆石.md)、掉落的[铁锭](铁锭.md)、掉落的[金锭](金锭.md)以及掉落的[钻石](钻石.md)）使用Programmer Art纹理。
* * 僵尸也使用Programmer Art的僵尸纹理。
* * 有趣的是，尽管掉落的橡木原木使用Programmer Art纹理，《我的世界》的世界场地中的橡木原木却正确的使用了纹理更新的纹理。
* 在史蒂夫的官方预告片中，在介绍艾莉克斯的服装时，艾莉克斯出现的村庄有许多纹理错误，一些原木方向错误，一扇窗户使用[橡木门](橡木门.md)的上半部分而不是[玻璃板](玻璃板.md), 还有一部分墙由Programmer Art纹理的[深色橡木原木](深色橡木原木.md)构成。此外在介绍僵尸的服装时，僵尸所破的门上下纹理错位了。
* 取胜乱斗中的史蒂夫路线名为“寻找世界的终点”，这个名字源于一个世界生成漏洞，当玩家从世界中心向外移动1250万格时，地形就会开始出现故障，社区将其为“[边境之地](边境之地.md)”。
* 史蒂夫和艾莉克斯的其他可选皮肤来自[原主机版](原主机版.md)的[默认皮肤包](皮肤包#默认皮肤包（Default Skin pack）.md)。
