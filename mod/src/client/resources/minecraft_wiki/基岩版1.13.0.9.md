* *beta 1.13.0.9**是[1.13.0](基岩版1.13.0.md)的第6个测试版，在Android上发布于2019年9月2日，而在Xbox One和Windows 10上发布于8月27日<ref></ref>，加入了凋灵玫瑰、光源方块、失活的珊瑚、谜之炖菜、棕色哞菇和新的音符盒音效，对村庄进行了一些更改，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[凋灵玫瑰](凋灵玫瑰.md)**
* 可用于合成[黑色染料](黑色染料.md)。
* 在非和平[难度](难度.md)下对周围的玩家和生物造成1秒的[凋零](凋零.md)效果。
* 由[凋灵](凋灵.md)杀死的非[亡灵生物](亡灵生物.md)掉落或种植。

* *[光源方块](光源方块.md)**
* 有0-15级光照的变种。
* 可以通过获得，和放置。
* 隐形的[末地烛](末地烛.md)（变种6）会自动更新为光源方块。

* *[失活的珊瑚](失活的珊瑚.md)**
* 珊瑚的失活变种。
* * 可以放置在方块顶部。

# = 物品 =
* *[谜之炖菜](谜之炖菜.md)**
* 可以用[红色蘑菇](红色蘑菇.md)和[棕色蘑菇](棕色蘑菇.md)加上[碗](碗.md)和任何一朵[花](花.md)来合成。

# = 生物 =
* *[哞菇](哞菇.md)**
* 加入了棕色哞菇。
* * 不会自然生成。
* * 由红色哞菇被[闪电](闪电.md)击中后转化而来。

# = 世界生成 =
* *[村庄](村庄.md)**
* 在一些[生物群系](生物群系.md)中加入了废弃村庄。
* * 重新加入了[僵尸村庄](僵尸村庄.md)，但使用了新村庄的结构。

# = 常规 =
* *[格式化代码](格式化代码.md)**
* 加入了Minecoin金的格式化代码：<code>§g</code>。

* *[胜利屏幕](胜利屏幕.md)**
* 加入了游戏制作人员名单。
* * 可以在击败[末影龙](末影龙.md)后查看，也可以通过设置菜单下的新按钮查看。

* *[音符盒](音符盒.md)的音效**
* 加入了11种新的音效：
* *  = 木琴
* *  = 铃铛（钟琴）
* *  = 长笛
* *  = 管钟
* *  = 吉他
* *  = 铁片琴（颤音琴）
* *  = 牛铃
* *  = 迪吉里杜管
* *  = “芯片”（方波）
* *  = 班卓琴
* *  = “扣弦”（电钢琴）

# 更改
# = 方块 =
* *[音符盒](音符盒.md)**
* 更新了音符盒的音效。

* *[物品展示框](物品展示框.md)**
* 现在可以放置在方块的顶部和底部。

* *[草径](草径.md)**
* 现可在创造模式物品栏中找到。

# = 生物 =
* *[鱿鱼](鱿鱼.md)**
* 现在会生成在河流中。

* *[玩家](玩家.md)**
* 现在有1.8格高。（）

* *[村民](村民.md)**
* 如果村民的物品栏中有[面包](面包.md)，它们会恢复[生命值](生命值.md)。

# = 常规 =
* *[袭击](袭击.md)**
* 战胜袭击后，[村民](村民.md)会欢呼。
* 袭击摧毁村庄后，[灾厄村民](灾厄村民.md)会欢呼。

* *地图制作及[附加包](附加包.md)**
* 新的数据驱动项目：
* * [海龟](海龟.md)被雷劈时的交互现在是数据驱动了。
* * [河豚](河豚.md)的胀气状态现在是数据驱动了。
* * [酿造台](酿造台.md)的[药水](药水.md)配方现在是数据驱动了。
* * 更改了Breathable、RideTick和Transformation系统，让它们使用ViewedEntityContext。
* * 为ScriptAPI加入了预编译的头部对象。
* 大幅增加了的距离上限。

* *菜单**
* 在“游戏指南”当中加入了[结构方块](结构方块.md)的相关章节。

# 修复
* *修复了132个漏洞**<br>
* *崩溃**
* 修复了游戏过程中可能发生的若干次崩溃。
* 打开世界时，不再出现画面冻结现象。
* 修复了过时活动对象与组件或定义不匹配时的崩溃问题。
* 酿造药水时游戏崩溃。
* 使用低端安卓设备进行游戏时游戏崩溃。
* 组件定义丢失导致游戏崩溃。
* 接受邀请的访客在进入游戏时游戏崩溃。
* 分屏玩家捡起原木时游戏崩溃。
* 修复了在世界接近生成时可能发生的崩溃。（）
* 更改存储位置时游戏崩溃。
* 允许命令方块矿车里的命令时游戏崩溃。
* 在信标UI里双击物品时游戏崩溃。
* 使用发射器对着一格高的花使用骨粉时游戏崩溃。（）
* 使用低内存的安卓或iOS设备进行游戏时崩溃。

* *性能**
* 改进了世界加载世界。
* 优化了地形光线计算。
* 改进了Xbox One版里帧率波动问题。
* 改进了生物的生成时间。

* *常规**
* “我们被攻击了！”和“感觉不太妙”成就可以再次被解锁。（）
* 当使用红石充能时使用放置的动力铁轨能够正常工作。
* 购买某些市场内容时会循环下载过程。
* 在活塞上使用不再留下不可见的活塞臂。
* 删除全局资源包后，它将立即从活跃资源包列表里中删除。
* 设置中的全局资源包现在将更新为新选择的语言。
* 克隆激活的刷怪笼放置后会有动画。（）
* 修复了“多人游戏限制的皮肤！”在尝试加载皮肤之前进入世界时错误弹出。（）
* 在试图拓展已有的村庄时会生成大量小型或空村庄。
* 打开皮肤选择器时无限加载。
* “Tiny Footprints”资源包的盔甲层丢失。

* *游戏内容**
* 火焰附加剑现在不再使创造玩家着火。（）
* 玩家现在可以在吃紫颂果时在不完整或透明的方块上传送。
* 持有红沙的末影人被杀死后不再掉落沙子。（）
* 修正了一个使玩家无法在潜影贝和船上潜行的问题。（）
* 划船动画现在与Java版匹配，并且在划船停止时重新同步船桨。
* 闪电落下的频率降低了。（）
* LT按钮再次可用于快速装备或更换装备。（）
* 玩家现在可以在瞄准附近生物时使用钓鱼竿等物品。
* 来自三叉戟的闪电现在在一个小范围内影响的不仅仅是单个生物。（）
* 在乘船过程中打开物品栏时玩家不再继续划船。（）
* 箭现在可以正常摧毁盔甲架。（）
* 花不再在花盆中变得不可见。（）
* 在红石矿石上潜行不再触发其发光效果。
* 在创造模式下打断活塞头不再会使活塞掉落为物品。（）
* 现在可以正确播放牛奶和药水的饮用声音。（）
* 生物再次掉落盔甲和装备作为战利品。（）
* 下界疣现在有机会在被时运工具破坏时掉落更多物品。（）
* 重新载入世界后，动物繁殖的冷却时间不再重置。
* 除了水中的TNT爆炸以外的爆炸现在能伤害实体。
* 现在能够使用在创造模式下使用拾取方块键获取鹦鹉。
* 发射器能够正常放置船了。
* 铁砧现在能够在使用后消耗耐久度。
* 生物现在能够正确地进入船和矿车。（(）
* 按钮现在可以通过配方书合成。
* 修复了玩家离开水时的冲刺/游泳状态。
* 如果将世界设置为“终为白日”，则“滞留药水”之类的效果云现在可以正常工作。（）
* 从发射器发射的水不再能破坏末地传送门框架及传送方块。
* 信标方块现在可以像其他不透明方块一样窒息玩家和生物。
* 玩家的重生位置现在会倾向于选择浅水区域而不是深水区域。
* 玩家死亡后离开末地后不再生成多条末影龙。（）
* 漏斗现在可以正确地从其上方拾取物品。（）
* “可再生能源”成就可再次被解锁了。（）
* 掠夺者现在会更频繁地在掠夺者哨所周围生成。（）
* 玩家从方块里踏入潜影盒时不再减速。
* “你去哪了？”成就现在能够正确地在Android设备中解锁。
* 现在可以在船上放置或挖掘方块。
* 生物不再将完全修复的武器当作战利品。（）
* 末地主岛里的黑曜石平台上不再能生成末地折跃门。
* 玩家乘船时，定位器地图现在会指示正确的方向。（）
* 降雪不再破坏红石部件。（）
* 玩家现在会正确获取熔炉储存的经验值。（）
* 现在可以在探索时更快地绘制地图，意味着“地图之屋”成就现在可以解锁得更连贯。（）
