# Java版1.4.5-pre

*页面ID: 33109* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.4.5-pre**是[Java版1.4.5](Java版1.4.5.md)的唯一一个预发布版，发布于2012年11月16日<ref name=pre></ref>，修复了一些漏洞。

# 修复
命令最后一页的内容缺失。
|2590|多人游戏中，所有可见实体都会不断地在坐标0，0，0处和原位置之间传送。
}}

* *其他漏洞**
* 修复了编辑告示牌时UI缺失本地化的漏洞。
* 修复了生物头颅戴在头上会穿过皮肤外层纹理的漏洞。
* 修复了发射器向一侧发射的漏洞。
* 修复了狼在干燥时仍会抖动身体的漏洞。
* 修复了局域网服务器无法正确连接的问题。</onlyinclude>
