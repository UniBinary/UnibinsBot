# 末地石

*页面ID: 8003* | *来源: Minecraft Wiki*

</ref>||Marsh Davies Mojang avatar.png}}

* *末地石（End Stone）**是一种淡黄色岩石[方块](方块.md)，也是[末地](末地.md)维度的主要组成方块。

# 生成
# = 自然生成 =
[300px|缩略图|右|完全由末地石组成的一个大型岛屿](File:TheEnd.png.md)

末地石只能在[末地](末地.md)找到，是末地所有地形的基本方块。

# = 事件生成 =
[返回传送门](返回传送门.md)状态更新时会重新生成，包括构成返回传送门结构的16个末地石。由于[末地水晶](末地水晶.md)是[可再生资源](可再生资源.md)，这使末地石成为了可再生资源。

[末地折跃门](末地折跃门.md)第一次被使用并生成新的末地折跃门时，如果目标位置所处区块没有任何末地石，则在y=75处生成一个由末地石构成的[末地浮岛](末地浮岛.md)。

# 获取
末地石只能通过破坏末地石获得。

# 破坏
挖掘末地石的合适工具是镐。末地石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

末地石被破坏后会掉落自身。

# 用途
末地石的[爆炸抗性](爆炸抗性.md)是9，是[石头](石头.md)爆炸抗性的1.5倍。它既不能被[末影人](末影人.md)捡起来，也不能被[末影龙](末影龙.md)摧毁。另外，[紫颂花](紫颂花.md)只能生长在末地石上。
