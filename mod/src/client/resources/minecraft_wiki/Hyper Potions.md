# Hyper Potions

*页面ID: 155743* | *来源: Minecraft Wiki*

* *Hyper Potions**是来自美国加利福尼亚州的一支电子舞曲乐队，Ian Tsuchiura是乐队唯一的成员，该乐队为Minecraft的一张[音乐唱片](音乐唱片.md)创作了专辑*[Minecraft: Lava Chicken (Original Game Soundtrack)](Minecraft: Lava Chicken (Original Game Soundtrack).md)*。其还为宣传Minecraft创作了混音专辑*[Minecraft: Pixel Genesis](Minecraft: Pixel Genesis.md)*、*[Minecraft: Triple Bundle](Minecraft: Triple Bundle.md)*和*[Minecraft: Pixel Drift](Minecraft: Pixel Drift.md)*。
