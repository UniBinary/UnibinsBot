* *薯饼（Hash Browns）**是一种能被[玩家](玩家.md)食用的[食物](食物.md)类[物品](物品.md)。

# 获取
# = 烹饪 =
薯饼可由[马铃薯皮](马铃薯皮.md)在[营火](营火.md)或[煎炸台](煎炸台.md)上煎炸制成。

# 用途
# = 食物 =

手持薯饼按住键即可食用，每个薯饼可以回复。
