* *And Action!**是一张[音乐唱片](音乐唱片.md)，可用于播放由Tone Deaf Rebellion创作的同名曲目。

# 获取
# = 大厅 =
在[大厅](大厅.md)结构的结构中生成的[木桶](木桶.md)中包含一个音乐唱片And Action!。

# = 矿境 =
在[矿境效果](矿境效果.md)“监守者Boss战”生效的[矿境](矿境.md)中，舞台后台的[箱子](箱子.md)中包含两个音乐唱片And Action!。

And Action!是一首复古电子游戏风格的音乐。

该音乐使用Microsoft GS Wavetable Synth合成。

# = 获取经验 =

音乐唱片And Action!所具有的物品基础价值为1。

# = 红石 =

音乐唱片And Action!放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为15的信号。
