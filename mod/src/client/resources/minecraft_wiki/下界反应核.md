# 下界反应核

*页面ID: 9237* | *来源: Minecraft Wiki*

* *下界反应核（Nether Reactor Core）**是一种曾用于建造[下界反应器](下界反应器.md)的方块。

# 生成
下界反应核不会生成在世界中。

# 获取

下界反应核只能通过从[携带版0.12.1.b1](携带版0.12.1.b1.md)前包含下界反应核并升级了的世界中获得，无法在其他未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取，不存在于[创造模式物品栏](创造模式物品栏.md)中，且是不可通过获取的物品。在[创造模式](创造模式.md)中对已有的下界反应核使用可以获得下界反应核；否则，下界反应核只能通过存档编辑或[附加包](附加包.md)获得。

# 破坏
挖掘下界反应核的合适工具是[镐](镐.md)。下界反应核需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

下界反应核被破坏后会掉落6个[铁锭](铁锭.md)和3个[钻石](钻石.md)，即携带版0.12.1.b1前用于合成下界反应核的材料。

即使在被具有精准采集的工具挖掘破坏时，下界反应核被破坏后也不会掉落自身。

# 用途
目前下界反应核只有装饰作用。

# = 下界反应器 =

在[下界](下界.md)维度加入携带版以前，下界反应核可以用来激活[下界反应器](下界反应器.md)（由金块和圆石摆放成的结构）。激活后，反应器周围将生成一个“下界塔”，可以视作下界的代替品。激活45秒后，下界反应核会停止工作，在被破坏并重新放置后才能再次使用。这个功能随着真正的下界的加入而移除。
