# 仙人掌花

*页面ID: 144404* | *来源: Minecraft Wiki*

* *仙人掌花（Cactus Flower）**是一种生长于仙人掌顶部的植物[方块](方块.md)。

# 生成

[仙人掌](仙人掌.md)能够生成仙人掌花。
* 格高的仙人掌柱有10%概率尝试在上方生成仙人掌花。
* 3格及更高的仙人掌柱有25%概率尝试在上方生成仙人掌花。

只有生成位置四面均无固体方块时，仙人掌花才会生成。

# = 自然生成 =
仙人掌花会有25%的概率生成在[仙人掌](仙人掌.md)的顶部。

# 获取
仙人掌花只能通过破坏仙人掌花获得。

# 破坏
仙人掌花被挖掘时会立刻被破坏。

仙人掌花被破坏后会掉落自身。

# 用途
仙人掌花能够被放置在任何顶面[中心完整](判定箱.md)的方块（例如仙人掌）顶部。

不同于其他一格高的[花](花.md)，仙人掌花不能放进[花盆](花盆.md)。<ref></ref>

# = 合成材料 =

# = 蜜蜂 =
仙人掌花可用于吸引、繁殖[蜜蜂](蜜蜂.md)以及加速幼年蜜蜂的成长。蜜蜂也会采集它的花粉。

# = 堆肥 =
将仙人掌花放进[堆肥桶](堆肥桶.md)有30%的概率使堆肥层数加1层。
