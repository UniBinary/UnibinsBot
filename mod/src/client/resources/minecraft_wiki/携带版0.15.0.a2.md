# 携带版0.15.0.a2

*页面ID: 20865* | *来源: Minecraft Wiki*

<onlyinclude>

* *Realms alpha build 1**是[v0.15.0 alpha](携带版0.15.0.md) Realms部分的首个测试版，发布于2016年4月13日<ref></ref><ref>http://mojang.com/2016/04/were-working-on-minecraft-realms-for-pocket-and-win-10/</ref>，重新加入了[Realms](Realms.md)。

# 新内容
* *[Realms](Realms.md)<ref name="realms"></ref><ref></ref>**
* 在[0.15.0](携带版Alpha 0.15.0.md)正式发布前供免费试用。<ref name="realms"/>

* *[主菜单](主菜单.md)**
* **Realms**按钮。
* * 取代原先的**选项**按钮。
* 新增"抗锯齿选项"。

# 更改
* *[主菜单](主菜单.md)**
* 选项按钮现改为一个图标。
* * 移动到屏幕右下方**语言**按钮的旁边。</onlyinclude>
