# 下界岩

* *下界岩（Netherrack）**是在[下界](下界.md)大量生成的岩石状[方块](方块.md)。

# 生成
# = 自然生成 =
下界岩是大多数[下界](下界.md)地形的组成部分，在所有[下界生物群系](生物群系#下界.md)内都可生成。

下界岩还会作为以下[结构](结构.md)的一部分生成：
* [主世界](主世界.md)和下界中的[废弃传送门](废弃传送门.md)；
* [堡垒遗迹](堡垒遗迹.md)的桥和藏宝室。

# = 菌岩 =
类似于[草方块](草方块.md)的死亡，当[绯红菌岩](绯红菌岩.md)或[诡异菌岩](诡异菌岩.md)上方放有不透明的[固体方块](固体方块.md)时，就会退化成下界岩。

# = 事件生成 =

[下界传送门](下界传送门.md)浮空时，下界岩会生成于下界传送门底部，这使得下界岩变得可再生。

# 获取
# = 菌岩 =
没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[菌岩](菌岩.md)被破坏后会掉落1个下界岩。

# 破坏
挖掘下界岩的合适工具是镐。下界岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

下界岩被破坏后会掉落自身。

# 用途
在下界岩顶部点燃的[火](火.md)能够永久燃烧，且不会被降雨淋熄。

在绯红菌岩或诡异菌岩旁边的下界岩上[骨粉](骨粉.md)会将下界岩转为新的[菌岩](菌岩.md)。如果目标下界岩同时和绯红菌岩和诡异菌岩相邻，则使用骨粉后下界岩优先变成X轴正方向，其次是Z轴正方向的菌岩。
