# Realms地图制作者披风

*页面ID: 187434* | *来源: Minecraft Wiki*

* *Reams地图制作者披风（Realms MapMaker Cape）**是授予部分[Java版Realms内容创作者计划](Java版Realms内容创作者计划.md)贡献者的披风。

# 描述
该披风被授予了符合[这个页面](https://atlas.minecraft.net/guidelines#capes)上所列的准则的地图制作者。
