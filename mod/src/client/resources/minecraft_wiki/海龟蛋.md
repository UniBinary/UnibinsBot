# 海龟蛋

*页面ID: 33676* | *来源: Minecraft Wiki*

* *海龟蛋（Turtle Egg）**是一种能够孵化出幼年[海龟](海龟.md)的方块。

# 生成
# = 繁殖海龟 =
给两只[海龟](海龟.md)喂食[海草](海草.md)时，其中一只海龟会回到其出生点，并在附近的[沙子](沙子.md)或[红沙](红沙.md)上“挖洞”，然后产下含有1-4个蛋的海龟蛋方块。

# 获取
海龟蛋只能通过破坏海龟蛋获得。

# 破坏
没有工具可以加速对海龟蛋的挖掘。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，海龟蛋被破坏后不会掉落，方块内海龟蛋数量大于1时变为数量减少1个的海龟蛋。

被具有精准采集的工具挖掘破坏时，海龟蛋被破坏后会掉落1个海龟蛋，方块内海龟蛋数量大于1时变为数量减少1个的海龟蛋。

其他情况下，海龟蛋被破坏后不会掉落。

如果由[创造模式](创造模式.md)的玩家来挖掘，则方块内的所有海龟蛋都会被破坏。<ref></ref>

# 用途
海龟蛋可以像普通固体方块一样放置，一个方块空间中最多可放置4个海龟蛋。它们被放置后无需依附在其他方块面上，因此可以悬在空中。

海龟蛋无法被[黏性活塞](黏性活塞.md)拉动，且会被伸出的活塞头破坏。

[下落的方块](下落的方块.md)落在海龟蛋上会掉落为物品，但不会破坏海龟蛋。

[游戏规则](游戏规则.md)设置为<code>true</code>时，足够大的[生物](生物.md)（海龟除外）可以使海龟蛋破碎；落在和站立在海龟蛋上时每[游戏刻](游戏刻.md)分别有、的概率将其破坏。它们将逐个破碎，直到一个方块空间中的所有海龟蛋都破碎。

设置为<code>true</code>时，[劫掠兽](劫掠兽.md)可以撞碎前方的海龟蛋。

设置为<code>true</code>时，[僵尸](僵尸.md)、[尸壳](尸壳.md)、[溺尸](溺尸.md)、[僵尸村民](僵尸村民.md)和[僵尸猪灵](僵尸猪灵.md)会主动寻找并踩碎海龟蛋。它们会在垂直距离3格、水平[切比雪夫距离](切比雪夫距离.md)24格范围内寻找海龟蛋；而该范围为水平[欧几里得距离](欧几里得距离.md)10格、竖直2格。

# = 孵化 =
海龟蛋需要放置在[沙子](沙子.md)、[红沙](红沙.md)或[可疑的沙子](可疑的沙子.md)上才能孵化出幼年海龟。孵化成功前，海龟蛋会经历3个孵化阶段，每经历一个阶段，海龟蛋上都会多出一些裂纹。一个方块空间内的所有海龟蛋会同时孵出海龟。

孵化海龟蛋需要的时间各不相同（平均需要4.5个游戏日，即现实时间1.5小时左右）。海龟蛋在每游戏日的第21061刻至21904刻（约游戏日中的凌晨03:00~04:00）中，接收到[随机刻](随机刻.md)时，会直接进入下一阶段；在其他时间接收到随机刻有0.2%的概率进入下一阶段。即使是在同一天、同一个海滩上被产下的海龟蛋也是如此。

# 你知道吗
* 海龟蛋在夜晚孵化速度较快的机制是基于现实设计的。现实中的小海龟在白天容易引来掠食者侵害，因此演化出在较低温度时加速孵化的特性，这样能确保小海龟有更高的概率于夜晚孵化。
* [亡灵生物](亡灵生物.md)喜欢踩碎海龟蛋的特性也参考于现实。现实中的海龟蛋营养价值很高，容易引来食蛋生物的捕食，然而这些食蛋生物在Minecraft中没有合适的对应物种，因此改以亡灵生物代替。
* 现实中的母海龟每次能产下1~9窝卵，而每窝卵有至少100颗海龟蛋。游戏中的海龟蛋约4.5个游戏日即可完成孵化，而现实中的海龟蛋需要50天左右才会完成孵化。
