# Java版Beta 1.8

*页面ID: 32283* | *来源: Minecraft Wiki*

键点击进入部分物品欄時可能崩潰。}}

<onlyinclude>

* *Beta 1.8**是**[冒险更新](冒险更新.md)**第一部分的首个正式版，也是的一次主要更新，发布于2011年9月14日<ref></ref>。加入了有关战斗、探索和冒险的内容与新的主菜单屏幕以及其他方面的新特性。

# 新内容
# = 方块 =
* *[石砖](石砖.md)**
* 自然生成于[要塞](要塞.md)中。

* *[台阶](台阶.md)**
* 加入了[石砖台阶](石砖台阶.md)和[红砖台阶](红砖台阶.md)。

* *[楼梯](楼梯.md)**
* 加入了[石砖楼梯](石砖楼梯.md)和[红砖楼梯](红砖楼梯.md)。

* *[栅栏门](栅栏门.md)**
* 一种类似[门](门.md)的可开关的障碍方块，可以用来出入[栅栏](栅栏.md)。

* *[玻璃板](玻璃板.md)**
* 一种可以更经济地替代[玻璃](玻璃.md)方块的装饰性透明[方块](方块.md)。

* *[铁栏杆](铁栏杆.md)**
* 一种与[玻璃板](玻璃板.md)性质类似的装饰性[方块](方块.md)。

* *[西瓜](西瓜.md)**
* 一种从完全生长的西瓜茎中长出来的方块。

# = 物品 =
* *[西瓜片](西瓜片.md)**
* 一种食物，可以回复。
* 可用于合成[西瓜种子](西瓜种子.md)。

* *[生鸡肉](生鸡肉.md)**
* 一种食物，可以回复，同时有概率获得30秒的[中毒](饥饿（状态效果）.md)效果。
* 可被烹饪成[熟鸡肉](熟鸡肉.md)。

* *[生牛肉](生牛肉.md)**
* 一种食物，可以回复。
* 可被烹饪成[牛排](牛排.md)。

* *[熟鸡肉](熟鸡肉.md)**
* 一种食物，可以回复。

* *[牛排](牛排.md)**
* 一种食物，可以回复。
* 有着[熟猪排](熟猪排.md)的旧纹理。

* *[末影珍珠](末影珍珠.md)**
* [末影人](末影人.md)死亡后有概率掉落。
* 目前没有任何用途。

* *[南瓜种子](南瓜种子.md)和[西瓜种子](西瓜种子.md)**
* 可以种植在[耕地](耕地.md)里。
* 完全成熟后可在邻近的[耕地](耕地.md)上生成[南瓜](雕刻南瓜.md)和[西瓜](西瓜.md)。

* *[食物](食物.md)**
* 食物不再直接回复生命值，而是回复饥饿值：如果饥饿值达到90%，会每4秒回复。
* 所有食物现在可堆叠（蘑菇煲除外）。
* 食物现在需要1.6秒来完全消耗，并且有了动画。

# = 生物 =
* *[末影人](末影人.md)**
* 一种敌对生物，能够搬起大多数方块。
* 空闲时，末影人会随机尝试瞬移。
* 玩家在注视末影人的头部时会被激怒变得敌对。
* 作为占位符，末影人使用僵尸的音效。
* 死亡后会掉落[末影珍珠](末影珍珠.md)和。

* *[蠹虫](蠹虫.md)**
* 一种小型的似虫的敌对生物。
* 会在摧毁[虫蚀方块](虫蚀方块.md)时生成。
* 被杀死时会掉落。

* *[洞穴蜘蛛](洞穴蜘蛛.md)**
* 一种能够使玩家[中毒](饥饿（状态效果）.md)的敌对生物，体型比[蜘蛛](蜘蛛.md)略小。
* 可能会在[废弃矿井](废弃矿井.md)中的洞穴蜘蛛[刷怪笼](刷怪笼.md)中生成。
* 被杀死时会掉落。

# = 非生物实体 =
* *[经验球](经验球.md)**
* 在生物被杀死时生成。
* 可以与其他经验球合并。
* 可以被玩家拾取以提升其[经验值](经验值.md)。

# = 游戏内容 =
* *[成就](成就/Java版.md)**
* 加入了“狙击手的对决”。

* *[游戏模式](游戏模式.md)**
* 重新加入了[创造模式](创造模式.md)。
* * 与之前不同的是，现在创造模式支持玩家[飞行](飞行.md)。

* *[粒子](粒子.md)**
* 加入了<code>crit</code>、<code>hugeexplosion</code>、<code>townaura</code>和<code>depthsuspend</code>粒子。

* *[迷雾](迷雾.md)**
* 加入了[虚空迷雾](虚空迷雾.md)。

* *常规**
* 加入了饥饿条。
* 加入了[疾跑](疾跑.md)。

# = 世界生成 =
* *[村庄](村庄.md)**
* 一种结构，包含一些房屋和水井。

* *[要塞](要塞.md)**
* 一种多房间的地下结构。
* 一个世界中只有128个要塞。

* *[废弃矿井](废弃矿井.md)**
* 一种大型地下结构，包含很多矿道。

* *[峡谷](峡谷.md)**
* 一种长且深的地面裂缝。

* *[生物群系](生物群系.md)**
* 加入了[河流](河流.md)、[沼泽](沼泽.md)和[山地](山地.md)生物群系。

# = 常规 =
* *[服务器列表](服务器列表.md)**
* 加入了服务器列表。

* *[控制](控制.md)**
* 攻击、使用物品及选择方块键可以被重新设置。
* 现在可以按来查看在线玩家。
* +点击合成方格里的输出物品会一次合成所有的物品，并且会自动放进物品栏中。

# 更改
# = 方块 =
* *[压力板](压力板.md)**
* 现在能够放置在[栅栏](栅栏.md)上面。

* *[苔石](苔石.md)**
* 更改了纹理。

* *[箱子](箱子.md)**
* 改进了模型。

* *[火把](火把.md)**
* 改进了[火把](火把.md)放置在墙上的模型。

* *[树叶](树叶.md)**
* 玩家放置的树叶不再枯萎。

# = 物品 =
* *[剪刀](剪刀.md)**
* 现在能收集[高草](高草.md)和[藤蔓](藤蔓.md)。

* *[食物](食物.md)**
* 食物不再直接回复生命值，而是回复饥饿值：如果饥饿值达到90%，会每4秒回复。
* 除了蘑菇煲外，所有食物现在可堆叠。
* 食物现在需要1.6秒来完全消耗，并且有了动画。
* 吃下生的食物或[腐肉](腐肉.md)有概率导致玩家[中毒](饥饿（状态效果）.md)，饥饿值会下降比正常快三倍。

# = 生物 =
* *[僵尸](僵尸.md)**
* 现在被杀死时现在掉落[腐肉](腐肉.md)而不是[羽毛](羽毛.md)。

* *[猪](猪.md)**
* 现在其嘴部更加突出。

* *[骷髅](骷髅.md)**
* 其手持的弓现在有了正确的大小。

* *[玩家](玩家.md)**
* 玩家对生物的伤害降至。

* *[怪物](怪物（已移除实体）.md)**
* 移除了实体，但其AI仍然存在于代码中。

* *常规**
* 动物不再自然消失。
* 玩家或[狼](狼.md)攻击被动型的生物时它们会随机向一个方向逃离。

# = 非生物实体 =
* *[箭](箭.md)**
* [箭](箭.md)击中生物将附着于它们身上而不是消失。
* 骷髅的箭将从眼前的弓射出，而不再是头顶。

# = 游戏内容 =
* *[战斗](战斗.md)**
* 现在拉[弓](弓.md)需要蓄力。
* 加入了暴击。
* 持剑时能够按住右键进行[防御](防御.md)。
* 敌对型生物会播放攻击时的动画。
* 手持武器按住鼠标左键现在只能摆动一次。

* *[平视显示器](平视显示器.md)**
* 版本号再次在左上角出现。
* 由于加入了饥饿值，护甲值现在被移到生命值之上。

* *[亮度](亮度.md)**
* 现在[昼夜更替](昼夜更替.md)的光照是预先保存于方块内的，这使黎明和黄昏看起来更顺畅。

* *[昼夜更替](昼夜更替.md)**
* 改进了日出和日落。
* * 在日出和日落时，云会改变颜色，以配合天空的颜色。
* * 地平线，特别是雾霾，在日落和日出时变得更加生动。

* *[云](云.md)**
* 云高度升高到地图的顶部，因此云层不能再穿过方块。
* 云的移动现在与游戏的时间同步。

* *[天气](天气.md)**
* 雨和雪现在渲染速度变得更快。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 移除了一些生物群系。
* 生物群系现在比以往更加巨大。
* 海洋生物群系现在比以往更广且更深。
* 由于技术原因，[雪](雪.md)现在不会自然生成在针叶林和苔原生物群系里。
* 现在[沙子](沙子.md)、[泥土](泥土.md)和[黏土](黏土.md)会随机混合形成海床。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 生物不再被明显地标有实体ID。
* 世界的数字种子显示在玩家位置之下的一个字段中。
* 现在需要在调试屏幕中按下以更改雾。

* *[全景图](全景图.md)**
* 现在是一个动画场景。

* *[主菜单](主菜单.md)**
* 版本号现在显示在左下角而不是左上角。

* *[选项](选项.md)**
* 加入了“亮度”选项，可以调节玩家的视觉亮度。

* *[控制](控制.md)**
* 按住鼠标右键放置方块比以前略慢。

* *常规**
* 游戏代码现在允许[Mod](Mod.md)更容易地改变地图高度。
* 在服务器上OP玩家可以在生存和创造模式之间来回切换<ref></ref>。
* 更改了启动界面的Mojang徽标。

# 修复
; 修复了9个漏洞
   修复了Beta 1.8-pre2中的键点击使游戏崩溃的漏洞。
   修复了在多人游戏中使用命令后，红石电路不工作的问题。
   现在破坏船和矿车会产生粒子了。
   修复了多人游戏中的恶魂攻击音效的问题。
   移除了边境之地。
   修复了台阶、仙人掌、耕地、压力板、栅栏、蛋糕、雪层、按钮以及活板门掉落物太大的问题。
   修复了“智能农场”故障。该故障使栅栏的碰撞箱超出已种植作物的耕地的碰撞箱，并阻止其在被踩踏时变为泥土。
   修复了有关活塞的崩溃漏洞。
   将z-buffer从8位提高到24位，以修复使用AMD显卡而出现的问题。</onlyinclude>
