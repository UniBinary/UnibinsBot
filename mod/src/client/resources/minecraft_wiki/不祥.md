# 不祥

*页面ID: 115215* | *来源: Minecraft Wiki*

* *不祥（Ominous）**可以指：

# Minecraft
# = 方块和物品 =
*  - 具有特殊数据的旗帜，会在[掠夺者前哨站](掠夺者前哨站.md)中生成或由[袭击队长](袭击队长.md)携带。
*  - 试炼刷怪笼的方块状态变种。
*  - 宝库的方块状态变种。
*  - 用于获得不祥之兆效果的物品。
*  - 试炼钥匙的变种。

# = 实体 =
* [不祥之物生成器](不祥之物生成器.md) - 用于展示并发射物品或弹射物的实体，由激活的不祥试炼刷怪笼周期性生成于玩家头顶。

# = 状态效果 =
*  - 使用不祥之瓶获得，进入村庄时此效果会转变为并触发袭击，在试炼刷怪笼附近时此效果会则转变为并触发不祥试炼。

# = 事件 =
* [不祥事件](不祥事件.md) - 一类游戏内事件。
* * [袭击](袭击.md) - 由袭击之兆状态效果触发的不祥事件。
* * [不祥试炼](不祥试炼.md) - 由试炼之兆状态效果触发的不祥事件。
