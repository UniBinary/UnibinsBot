# 基岩版1.14.0.6

*页面ID: 49123* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.14.0.6**是[1.14.0](基岩版1.14.0.md)的第5个测试版，发布于2019年11月6日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[蜂蜜块](蜂蜜块.md)**
* 再次更改了蜂蜜块的纹理以匹配。

# 修复
* *修复了10个漏洞**

* *崩溃**
* 修复了若干可能在游戏过程中发生的崩溃。
* 修复了投掷滞留药水时可能发生的崩溃。

* *常规**
* 修复了披风在某些皮肤包当中不能进行渲染的问题。（）
* 进一步修复，以防止皮肤加载时间过长。（）
* 修复了存在拼写错误的闪烁标语文本。
* 在可供玩家购买的部分地图中，使用命令清空玩家物品栏的操作现在更加顺畅。

* *游戏内容**
* 修复了导致红石信号无法通过区块边界的漏洞。
* 玩家骑马且手持地图时，手臂不再会旋转到“屏幕外”。
* 现在又能通过使用发射器发射雕刻南瓜来召唤铁傀儡了。

* *生物**
* 蜜蜂现在可以穿过打开的门。</onlyinclude>
