# 火把花种子

*页面ID: 102272* | *来源: Minecraft Wiki*

* *火把花种子（Torchflower Seeds）**是能够种出火把花植株的物品。

* *火把花植株（Torchflower Crop）**是种植在[耕地](耕地.md)上的[作物](作物.md)方块，成熟时变为[火把花](火把花.md)。

== 生成 ==
火把花植株不会生成在世界中。

# 获取
# = 嗅探兽 =
火把花种子可通过[嗅探兽](嗅探兽.md)挖掘获得。

# 破坏
火把花植株被挖掘时会立刻被破坏。

火把花植株被破坏后会掉落1个火把花种子。

# 用途
# = 种植 =

对[耕地](耕地.md)的顶面火把花种子可种植出火把花植株。[亮度](亮度.md)等级≥9时，火把花植株才能生长到下一个阶段；亮度等级≤7时无法对耕地火把花种子，已种植的火把花植株也会在接收到[方块更新](方块更新.md)时掉落为[物品实体](物品实体.md)。

火把花植株有3个生长阶段。火把花植株生长时，如果之前的方块状态<code>age</code>已为<code>1</code>或方块状态<code>growth</code>即将变为<code>7</code>，则改为将自身替换为火把花。

火把花植株在湿润的耕地上生长得更快。对火把花植株[骨粉](骨粉.md)有75%的概率使其增加1个生长阶段，忽视亮度等级。已有巢且采集了花粉的[蜜蜂](蜜蜂.md)飞过火把花植株时，植株也有概率增加1个生长阶段。

# = 繁殖 =
火把花种子可用于吸引及[繁殖](繁殖.md)嗅探兽和[鸡](鸡.md)，也可喂食给幼年个体以减少其10%的剩余生长时间。

# = 驯服 =
与其他种子相同，火把花种子可用于吸引及驯服[鹦鹉](鹦鹉.md)。

# = 堆肥 =
将火把花种子放入[堆肥桶](堆肥桶.md)中有30%的概率增加一层堆肥层。

# = 治疗 =

给生命值不满的成年嗅探兽喂食火把花种子可使其恢复点生命值。
