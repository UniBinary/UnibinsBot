# 瓶子草荚果

*页面ID: 103240* | *来源: Minecraft Wiki*

* *瓶子草荚果（Pitcher Pod）**是能够种出瓶子草植株的物品。

* *瓶子草植株（Pitcher Crop）**是种植在[耕地](耕地.md)上的[作物](作物.md)方块，成熟时能掉落[瓶子草](瓶子草.md)。

# 生成
瓶子草植株不会生成在世界中。

# 获取
# = 嗅探兽 =
瓶子草荚果可通过[嗅探兽](嗅探兽.md)挖掘获得。

# 破坏
瓶子草植株被挖掘时会立刻被破坏。

生长阶段没有达到第5阶段的瓶子草植株被破坏后会掉落1个瓶子草荚果。

生长阶段达到了第5阶段的瓶子草植株被破坏后会掉落1个[瓶子草](瓶子草.md)。

# 用途
# = 种植 =

对[耕地](耕地.md)的顶面瓶子草荚果可种植出瓶子草植株。瓶子草植株会经历5个生长阶段。[亮度](亮度.md)等级≥7时，瓶子草植株才能生长到下一个阶段；亮度等级≤7时无法对耕地瓶子草荚果，已种植的瓶子草植株也会在接收到[方块更新](方块更新.md)时掉落为[物品实体](物品实体.md)。

瓶子草植株在湿润的耕地上生长得更快。对瓶子草植株[骨粉](骨粉.md)会使其增加2-5个生长阶段，忽视亮度等级。已有巢且采集了花粉的[蜜蜂](蜜蜂.md)飞过瓶子草植株时，植株也有概率增加1个生长阶段。

# = 繁殖 =
瓶子草荚果可用于吸引及繁殖[鸡](鸡.md)，也可喂食给幼年个体以减少其10%的剩余生长时间。

# = 驯服 =
与其他种子相同，瓶子草荚果可用于吸引及驯服[鹦鹉](鹦鹉.md)。

# = 堆肥 =
将瓶子草荚果放入[堆肥桶](堆肥桶.md)中有30%的概率增加一层堆肥层。
