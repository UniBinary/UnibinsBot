# 基岩版1.13.0.2

*页面ID: 45028* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.13.0.2**是[1.13.0](基岩版1.13.0.md)的第2个测试版，发布于2019年7月10日<ref></ref>，加入了禁用聊天提示的功能，并修复了一些漏洞。

# 新内容
# = 常规 =
* *辅助功能**
* 加入了进入世界后禁用聊天提示的功能。

# 更改
# = 方块 =
* *[TNT](TNT.md)**
* 现在可以使用[红沙](红沙.md)合成：

# = 生物 =
* *[狐狸](狐狸.md)**
* 现在不再会跟随手持[甜浆果](甜浆果.md)的玩家。
* 更改了移动速度，以匹配。

* *[凋灵](凋灵.md)**
* 现在在防御时会出现与闪电苦力怕类似的蓝色效果。

# 修复
* *修复了50个漏洞**<br>
* *崩溃**
* 修复了几个在游戏过程中的崩溃。
* 修复了在iOS设备上从市场同时下载多个包时的崩溃。
* 修复了当村民试图寻找路径时可能发生的崩溃。
* 修复了在后退出游戏时可能发生的崩溃。
* 修复了在加入服务器时的崩溃。
* 修复了在刷怪笼中放入幻翼刷怪蛋时的崩溃。
* 修复了在加载海底神殿时的崩溃。

* *性能**
* 修复了用在末地中鞘翅飞行时的性能问题。

* *常规**
* 修复了各种文本到语音阅读器问题。
* 玩家通过传送门时，屏幕上不再显示聊天说明。（）
* 修复了一些菜单按钮的间距问题。
* 修复了睡觉时潜行的问题。
* 修复了几个持有物品的定位。
* 修复了持有物品时各种市场皮肤的手部位置。
* 结构方块线框切换现在可以正确隐藏并显示线框。
* 修复了僵尸猪人的剑的位置
* 修复了玩家睡觉时视角位置。
* 修复了市场皮肤使用鞘翅时无法切换使用到标准人性模型的问题。
* 结构方块的加载模式现在可以包含实体，以及移除了方块选项。
* 当玩家拖动物品到制图台并卡住的情况下，物品不再丢失。
* 修复了一些重音音节文本字符的问题。（）
* 修复了在第一人称时将物品切换到空手时手的位置不正确的问题。
* 调整玩家拿着地图时手臂的位置，同时处理好了某些市场皮肤短臂和长臂的问题。
* 修复了在一个世界中使用教育版模式会自动更改菜单和选项的问题。（）

* *游戏内容**
* 修复了可能出现在Realms世界和本地世界出现的区块卸载崩溃问题。（）
* 修复了玩家在加入世界或者使用下界传送门时卡在加载界面的问题。（）
* 用精准采集收集的叶子现在会与其他同类叶子正确堆叠。（）
* 鹦鹉现在会正确地落在玩家的肩膀上。
* 唱片机被破坏后现在会停止播放音乐。
* 玩家离凋灵太远时，凋灵的血量条不再消失。（）
* 修复了床的默认制作方式。
* 通过“可加入的好友”列表加入Realm时，现在会使用Realms的UI而不是普通的多人游戏UI。（）
* 使用下界传送门并同时进食不再导致玩家进行随机传送。（）

* *生物**
* 狐狸不再会在玩家潜行时逃跑。
* 狐狸在受到引诱时不会再逃跑。
* 狐狸现在在Java版和基岩版中拥有同样的移动速度。
* 将闪电苦力怕的蓝色效果同时应用到凋灵防御时的效果。
* 狐狸不会再受到拿着食物的玩家的诱惑。
* 在积雪的生物群系里使两只成年红色狐狸繁殖现在会生成一只红色幼年狐狸。
* 修复了狐狸睡觉的冷却时间。
* 狐狸在尝试捕鱼和吃鱼时不会再淹死自己。
* 村民现在会正确地到达它们的工作站点方块。（）
* 受信任的狐狸现在在复仇成功后会失去仇恨值。

* *方块**
* 水平放置的木头方块现在会掉落正确的方块变种。
* TNT现在可以用红沙合成。

* *用户界面**
* 修复了重叠在一起的“登录”信息。
* 移除了多余的下载进度条。

* *附加包和脚本引擎**
* 当脚本使用函数时，方块在下降时不再会卡住。
* 计时区域现在有一个属性以显示它们是否已经到时。
* 自定义可骑乘实体在添加时会正确的显示操作提示信息。</onlyinclude>
