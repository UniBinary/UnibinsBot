# 基岩版1.20.40.22

*页面ID: 105944* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.40.22**（ChromeOS/Android）、**Preview 1.20.40.22**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.40](基岩版1.20.40.md)的第3个测试版，发布于2023年9月20日<ref></ref>，加入了触摸控制的自定义按键功能，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[触摸控制](触摸控制.md)**
* 加入了自定义按键功能。
* * 目前仅在世界中可用，且需要开启“”选项。

* *[设置](设置.md)**
* 在设置中加入了“”选项。
* * 用于启用触摸控制的自定义按键功能。

# 更改
# = 生物 =
* *[女巫](女巫.md)**
* 看向玩家的距离范围由半径4格内增加至半径8格内。

# = 游戏内容 =
* *[声音](声音.md)**
* [山羊角](山羊角.md)吹奏音效的衰减距离由16格增加至256格。

# = 常规 =
* *[触摸控制](触摸控制.md)**
* 略微更改了十字键控制下的按钮样式。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“测试版 API”和“”子选项后才可使用。

# = 技术性 =
* *API**
* 加入了函数。

* *性能与稳定性**
* 修复了在部分Android设备（如Mali GPU）上启用延迟渲染预览功能的情况下加载世界时发生的崩溃。（）
* 禁用了不支持当前计算着色器需求（ 256}}）的部分Android设备上的延迟渲染预览功能。

# 修复
* *方块**
* 修复了编辑告示牌时偶尔会编辑到错误的一侧的问题。（）
* 修复了物品展示框被击中或破坏时可能不会掉落其中的物品的漏洞，该漏洞极其罕见，约有0.000003%的概率出现。

* *教育版选项**
* 修复了在打开相片簿的情况下关闭游戏时会导致游戏崩溃的漏洞。

* *游戏规则**
* 将重生半径游戏规则的默认值更改为10。

* *游戏内容**
* 现在山羊角的吹奏声能够在256格距离之外听见。（）

* *生物**
* 骆驼行走时不再看起来像是滑行。（）
* 骆驼站立不动时不再会移动四肢。（）
* 骆驼不再能够在熔岩中无限冲刺。（）

* *用户界面**
* 自动补全文本现在会将插入符移动至行末。

* *原版趋同**
* 现在创建铁傀儡和雪傀儡时会产生类似于方块被破坏的粒子效果。
* 现在使用与Java版相匹配的流动的水和熔岩的混合机制。（）
* 女巫现在会看向16格距离内的玩家。</onlyinclude>
