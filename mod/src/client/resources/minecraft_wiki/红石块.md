# 红石块

*页面ID: 9537* | *来源: Minecraft Wiki*

* *红石块（Block of Redstone）**是用9个[红石粉](红石粉.md)合成的矿物方块，相当于一个可被活塞推动的不能关闭的[红石电源](红石元件#电源.md)。

# 生成
# = 自然生成 =
红石块会自然生成于[远古城市](远古城市.md)中心的地下室中。

# 破坏
挖掘红石块的合适工具是镐。红石块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

红石块被破坏后会掉落自身。

# 用途
# = 合成材料 =
红石块可用于存储[红石粉](红石粉.md)，以此来节约空间。

# = 红石元件 =
[缩略图|一个红石块会激活红石线和红石中继器，关闭附着其上的红石火把，它还会激活红石元件（左），但不会充能毗邻的红石导体（右）](File:Block of redstone behavior.png.md)

红石块保持输出信号，它不能被关闭，红石块会：
* 激活任何毗邻的红石线并改变水平方向上毗邻的红石线的指向，向其[提供](红石元件#电源.md)15级的信号强度。
* 激活任何四周毗邻的背对红石块的[红石中继器](红石中继器.md)和[红石比较器](红石比较器.md)，向它们[提供](红石元件#电源.md)15级的信号强度。
* 激活附着其上的[红石火把](红石火把.md)使其熄灭。
* 激活任何毗邻的[机械元件](红石元件.md)（如[门](门.md)、[红石灯](红石灯.md)等），包括红石块上面的和下面的红石元件。（但不能激活一些拒绝该方向输入的机械元件，如面朝该红石块的[活塞](活塞.md)）
* 向红石比较器的边侧输入信号。

红石块表现的性质和强充能方块类似，与红石块相邻的红石导体不会被充能，但其实它不是[红石导体](红石导体.md)，例如红石块处于[箱子](箱子.md)上方时不会阻止箱子被开启。

被放置而附着在红石块上的[红石火把](红石火把.md)会在刚被放置时亮起一段时间，随后因红石块保持输出而保持熄灭。
* 时间为2游戏刻。
* 时间为放置时间到下次红石刻时，红石火把在该红石刻的有向图更新阶段加入有向图，在电容器阶段被红石块的信号熄灭，会发出一个长度为1红石刻的只能被电容器元件接收的信号。

# 你知道吗
* 红石块和对应矿石对工具[品质](品质.md)的掉落判定不一致：挖掘[红石矿石](红石矿石.md)用铁及以上品质的镐才有掉落物，挖掘红石块用任何镐均可掉落。这与其他矿物块不同。
