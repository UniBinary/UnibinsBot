# 命令/defaultgamemode

*页面ID: 39689* | *来源: Minecraft Wiki*

设置新玩家加入多人游戏时默认的[游戏模式](游戏模式.md)（生存、创造等）。若在[server.properties](server.properties.md)中<code>force-gamemode</code>字段为<code>true</code>的服务器中，或在任意局域网世界中，执行此命令还会把所有在线玩家的游戏模式改为指定模式。

# 语法
  <code>defaultgamemode <gamemode></code>

# 参数

   指定默认游戏模式。


# 结果

# 输出

# 示例
* 将默认游戏模式设为生存模式：<code>/defaultgamemode survival</code>。
