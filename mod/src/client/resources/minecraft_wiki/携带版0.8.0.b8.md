# 携带版0.8.0.b8

*页面ID: 31530* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.8.0 alpha build 8**是[v0.8.0 alpha](携带版0.8.0.md)的第8个测试版，发布于2013年12月6日，修复了一些漏洞。

# 更改
# = 方块 =
* *[沙子](沙子.md)和[沙砾](沙砾.md)**
* 掉落在[台阶](台阶.md)、[火把](火把.md)等半透明的东西上就会变成可收集的掉落物。

# 修复

* *其他**
* 修复了大箱子无法连接形成的问题。
* 添加了生物的背部伤害与火焰伤害的颜色叠加。
* 现在当两个玩家同时更改箱子中物品的内容时，箱子也会同步刷新。</onlyinclude>
