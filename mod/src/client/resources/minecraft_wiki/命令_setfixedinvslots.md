# 命令/setfixedinvslots

*页面ID: 57668* | *来源: Minecraft Wiki*

固定一个槽位中最多可存放多少数量的物品。

# 语法
   <code>-{}-setfixedinvslots <*fixedinvslotnum：整数*></code>

# 参数
<code>-{}-*fixedinvslotnum：整数*</code>
   设置最大存放数量，可最多选择3个槽位。
