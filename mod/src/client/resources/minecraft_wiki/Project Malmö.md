# Project Malmö

*页面ID: 54754* | *来源: Minecraft Wiki*

* *Project Malmö**是Mojang首个且唯一支持的Mod。<ref>https://web.archive.org/web/20180218210705/https://mojang.com/2016/07/project-malmo-uses-minecraft-to-make-ai-smarter/</ref>其功能包括允许用户查看和编辑Minecraft代码，且定位为基于Minecraft的人工智能研究平台。

# 新内容
Project Malmö包含查看和编辑Minecraft代码的功能，支持在Minecraft环境中进行人工智能实验。该Mod可实现生物合成、建造及其他各类操作，用于辅助人工智能相关研究。

# 下载和运行
# = 下载 =
# 访问[Project Malmö官方GitHub仓库](https://github.com/Microsoft/malmo)，或前往[版本发布页面](https://github.com/Microsoft/malmo/releases)选择所需版本。
# 执行下载操作。

# = 运行 =
# == Windows系统 ==
# 在Project Malmö解压文件夹中打开命令提示符。
# 输入命令<code>cd minecraft && launchClient</code>。
# 启动智能体（相关操作详情可参考[官方说明文档](https://github.com/Microsoft/malmo#launch-an-agent)）。

# == Mac与Linux系统 ==
# 在Project Malmö解压文件夹中打开终端。
# 输入命令<code>cd minecraft && ./launchClient.sh</code>。
# 启动智能体（相关操作详情可参考[官方说明文档](https://github.com/Microsoft/malmo#launch-an-agent)）。
