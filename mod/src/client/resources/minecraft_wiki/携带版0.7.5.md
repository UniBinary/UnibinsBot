# 携带版0.7.5

*页面ID: 21264* | *来源: Minecraft Wiki*

* *v0.7.5 alpha**是[携带版](携带版.md)的一次次要更新，修复了[v0.7.4 alpha](携带版0.7.4.md)中的一些漏洞与崩溃。

# 修复
键可能导致游戏崩溃。
|5201|放置蛋糕或甘蔗可能导致游戏崩溃。
|5202|垂直放置两个箱子会变成大型箱子。
|5210|点击菜单按钮无响应。
|5211|关于床的崩溃。
|5224|创造模式下的铁桶不能用于装盛水或熔岩。
|5232|羊毛不能被火点燃。
|5233|苦力怕不会终止引爆。
|5234|在服务器上高亮选择一个方块时，工具显示错误的图形。
|5237|合成蛋糕后返还的双倍数量的铁桶。
|5435|物品栏漏洞。
}}
