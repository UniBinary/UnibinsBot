# 基岩版1.5.0.1

*页面ID: 34519* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.5.0.1**是[1.5.0](基岩版1.5.0.md)的第2个测试版，发布于2018年5月2日<ref></ref>，加入了[潮涌核心](潮涌核心.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[潮涌核心](潮涌核心.md)**
* 可以在水下建造，并给予玩家潮涌能量的状态效果。
* * 当被完整的框架激活时，里面的纹理再次会发生改变，类似于。
* * 可以像[生物头颅](生物头颅.md)一样以16个不同的方向放置在方块顶部。

# 更改
# = 方块 =
* *[蓝冰](蓝冰.md)**
* 略微减少了摩擦力。

# 修复
* *修复了25个漏洞**
* 修复了部分在游戏进行时的崩溃。
* 骨粉会被快速消耗。
* 创造模式下，玩家在水下飞行时不再能将方块悬浮放置（除非有高亮提示）。
* 玩家不再能透过冰块在水下呼吸。
* 玩家的视野离开水下时，仍会消耗氧气值。
* 重新进入世界后，氧气值会瞬间回满。
* 海豚可以瞬间被喂食。
* 不能在如树叶之类的透明方块上放置栅栏。
* 贴近方块顶部游泳时，该方块不会被渲染。
* 通过命令获得的海草不能堆叠且没有功能。
* 对通过模板创建的世界进行重命名后不能正确保存。
* 所有按钮变种现在会在物品栏内或物品展示框内正常显示。
* 游泳时，拴绳的连接点不再出现在玩家的前方。
* 物品会被卡在流动的水里。
* 由尸壳转化成的僵尸在陆地上的移速太快。
* 创造模式下，疾跑并飞行的速度不会保持不变。
* 向下飞的飞行速度不会保持不变。
* 生物可以生成在地毯上。
* 船里的幼年生物不再持续受伤。
* 在其他玩家退出并重新进入世界后，藏宝图上面的标记消失。
* 爆炸可以摧毁三叉戟实体。
* 插进灵魂沙里的三叉戟不会正常着陆，以及不会使得忠诚魔咒生效。
* 水下的三叉戟实体会不停冒泡。
* 在登录完成后，“登录”按钮不会消失。
* 使用命令不再能将实体或玩家设置在y255处生成。</onlyinclude>
