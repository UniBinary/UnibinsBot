# 启动器2.2.176x

*页面ID: 78162* | *来源: Minecraft Wiki*

* *2.2.1768**（）、**2.2.1769**（）或**2.2.1767**（）是一次[启动器](启动器.md)更新，发布于2021年2月11日。

# 更改
* 为启动器加入了动画。游戏Logo现在有弹跳效果了。下拉“开始游戏”界面后的“开始游戏”按钮现在被放在右上角了。
* 为的更新说明页面引入了新的设计。
* 加入了对俄语（革命前）的支持。
* 为加入了更新说明页面。
* 更改了全屏对话框动画的方向。
* 现在新闻页面中的“No matching results”字符串可以翻译了。
* 现在只会为需要启动的玩家安装JRE了。

# 你知道吗
* 在此启动器版本的官方更新日志中，提及了“从[Java版Alpha 1.0.16_02](Java版Alpha v1.0.16_02.md)中移除了[Herobrine](Herobrine.md)”作为彩蛋。

# 修复
* 移除了指针悬浮在下拉菜单上时的动画。
*  - 打开并挂载<samp>minecraft.dmg</samp>后，其背景无法显示。
*  - 无法启动启动器。
*  - “开始游戏”按钮被禁用时仍然可以按下。
