# 携带版1.0.4.1

*页面ID: 27807* | *来源: Minecraft Wiki*

<onlyinclude>

* *alpha 1.0.4.1**是[1.0.4](携带版1.0.4.md)的第2个，也是最后一个测试版本，发布于2017年2月25日<ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *选项**
* 音乐和音效现在可以用资源包更改了。
* 在设置中添加了新的存储界面以用于管理世界存档、[资源包](资源包.md)和行为包。

# 更改
# = 常规 =
* *性能**
* 添加了CDN以减少文件大小。
* 为旧版本设备添加低渲染距离选项。

* *GUI**
* GUI不再能通过资源包更改了。
* 交易GUI现在会将交易物品结果变成灰色。

# 修复
* *修复了29个漏洞**
*  - 重新进入世界时，雷暴天气被下雨天气替代。
*  - “钻石！”和“保镖”成就无法达成。
*  - HUD里显示的生命条和盔甲条不正确。
*  - 恶魂会在狭窄的空间里生成。
*  - 角视场设置为最大时，玩家疾跑使得角视场变化出错。
*  - 使用地图时，游戏性能骤降。
*  - 对着树叶点击鼠标中键不会给予正确的树叶。
*  - 村民在交易状态时仍会走开。
*  - 非农民村民也会收割和播种作物。
*  - 治愈后的僵尸村民没有职业。
*  - 村民在交易时没有播放交易询问音效。
*  - 交易界面里的附魔书纹理错误。
* 启用行为包时，仍然可以解锁成就。
* 紫色植株在破坏时不会完全被摧毁。
* 启用渲染器时，需要重启以生效。
* 行为包在导入时，清单里的错误不会正常显示。
* 其余玩家在接受资源包并进入游戏时，游戏房主的客户端会崩溃。
* 在导入行为包附属的资源包后，导入该行为包会使得资源包被复制。
* 使用铁砧、酿造台或熔炉时游戏崩溃。
* Gear VR世界和Android世界不会彼此互相展示。
* 使用鞘翅飞行时崩溃。
* 村民会立即捡起向其投掷的掉落物。
* 村民不会互相投掷食物。
* 导入重复的资源包或行为包时游戏崩溃。
* 物品展示框被摧毁时，展示的物品不会掉落。
* 在村民交易界面里的附魔书不能显示包含的魔咒。
* 修复了一些纹理错误。
* 修复了行为包里的HUD图像显示错误。
* 在卸载资源包时，盔甲的纹理不会还原。</onlyinclude>
