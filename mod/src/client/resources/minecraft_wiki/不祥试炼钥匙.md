# 不祥试炼钥匙

*页面ID: 169571* | *来源: Minecraft Wiki*

* *不祥试炼钥匙（Ominous Trial Key）**是[试炼钥匙](试炼钥匙.md)的不祥变种，可用于解锁[不祥宝库](不祥宝库.md)。

# 获取
# = 箱子战利品 =
[不祥试炼刷怪笼](不祥试炼刷怪笼.md)提供战利品时有30%的概率选中包含不祥试炼钥匙的战利品表。

# 用途
不祥试炼钥匙可用于解锁[不祥宝库](不祥宝库.md)，每次解锁消耗1个不祥试炼钥匙。
