# 染色陶瓦

*页面ID: 170167* | *来源: Minecraft Wiki*

* *染色陶瓦（Stained Terracotta）**是一种自然生成于恶地，可以由[陶瓦](陶瓦.md)合成的方块。

# 生成
品红色陶瓦和粉红色陶瓦不会生成在世界中。

# = 自然生成 =
; 恶地
红色、橙色、黄色、棕色、白色和淡灰色陶瓦会生成在[恶地](恶地.md)、[疏林恶地](疏林恶地.md)和[风蚀恶地](风蚀恶地.md)生物群系中。

; [村庄](村庄.md)
白色陶瓦生成于平原村庄的某些房屋。红色、橙色和黄色陶瓦生成于热带草原村庄的某些房屋。黄绿色陶瓦生成于沙漠村庄的石匠房屋。

; 沙漠神殿
蓝色和橙色陶瓦是[沙漠神殿](沙漠神殿.md)结构的一部分。

; 海底废墟
淡蓝色陶瓦可以在[海底废墟](海底废墟.md)生成。

; 古迹废墟
黑色、灰色、淡灰色、棕色、红色、橙色、黄色、青色和蓝色陶瓦可以在[古迹废墟](古迹废墟.md)生成。

# 破坏
挖掘染色陶瓦的合适工具是镐。染色陶瓦需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

染色陶瓦被破坏后会掉落自身。
