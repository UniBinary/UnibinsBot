# 启动器2.2.280x

*页面ID: 82925* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.2.2806**（）、**2.2.2804**（）或**2.2.2803**（）是一次[启动器](启动器.md)更新，发布于2021年5月25日。

# 更改
* 修复了在类Unix系统上构建中断的问题。
* 修复了在Windows系统上无法在日志中记录“看起来正常”的路径的问题。
* 在macOS版本上做了一些修复，以提高可靠性。
* 更新了Bootstrap，以去除对<code><samp>vcruntime140.dll</samp></code>的依赖。
* 增加了额外的日志记录，用以捕获有关CDN问题的信息。

# 修复
*  - 启动器无法加载。
*  - 启动器输出的日志只在窗口的上半部分显示。
*  - 启动器日志前三列的内容显示的比以前要暗。
*  - 点击搜索图标时，启动器中的一些搜索框不会被选中。</onlyinclude>

# 你知道吗
* 此版本的更新日志内容与2.2.27*xx*的相同，只是比它多修复了一个漏洞。
* 此版本发布后，2.2.27*xx*的更新日志消失了。
