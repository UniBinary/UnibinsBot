# 基岩版1.21.10.20

*页面ID: 120364* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.10.20**（ChromeOS/Android）、**Preview 1.21.10.20**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.20](基岩版1.21.20.md)的首个测试版<ref></ref>，发布于2024年5月22日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“”子选项。
* * 用于启用相机预设，可通过命令使用，并且可以拥有视角偏移量。

# = 物品 =
* *[重锤](重锤.md)**
* 现在不再是[蜘蛛网](蜘蛛网.md)和[竹子](竹子.md)的合适挖掘工具，也不再能加速挖掘其他方块。
* 现在不会击退被自己驯服的生物。

# = 生物 =
* *[女巫](女巫.md)**
* 为了增加[沼泽小屋](沼泽小屋.md)农场的产量，现在女巫死亡时总会掉落4-8个[红石粉](红石粉.md)。
* * [抢夺](抢夺.md)魔咒会影响掉落数量。每级可使掉落数量上限增加1，使用抢夺III最多掉落11个。

# = 世界生成 =
* *[试炼密室](试炼密室.md)**
* 现在更少地生成于[深暗之域](深暗之域.md)中。

# = 常规 =
* *[创建新的世界](创建新的世界.md)和新的编辑世界屏幕**
* 现在极限模式选项的开关样式为极限模式红心。
* 现在开启极限模式选项后，世界图标会显示红色边框和极限模式红心。
* 加入了打开和关闭极限模式选项的音效。

* *[教学提示](教学提示.md)**
* 为触控设备加入了游泳提示。
* 现在会指导使用方向键控制方案的触控设备玩家如何进行移动。
* 现在只会在玩家处于水中时显示游泳提示。
* 现在玩家在[细雪](细雪.md)中被冰冻时会优先显示破坏方块提示。
* 现在玩家周围存在敌对生物时只会指导玩家如何逃跑（显示移动、跳跃和转动视角提示），而不会显示其他提示。

# 修复
* *试炼刷怪笼**
* 修复了试炼刷怪笼的纹理存在一些不一致处的问题。（）

* *音乐**
* 音乐不再能被命令停止播放。

* *游戏内容**
* 连续放置台阶和楼梯时不再会随机开始在底部放置方块。（）
* 修复了距离出生点数千格远时，区块内的环境会发生显著变化的漏洞。（）
* 现在破坏树叶时产生的粒子的颜色与所破坏树叶的颜色相匹配。（）
* 定位器地图现在仅会显示头部以及头部附着物。（）
* 现在玩家在沉重核心上行走时发出的音效由音频设置中的正确滑块控制。

* *物品**
* 旋风棒现在会在第三人称视角下正确渲染。（）
* 重锤不再能像剑和其他锋利的物品一样快速破坏蜘蛛网和竹子。（）
* 钓鱼竿浮漂不再能钩住带有弹射物反射组件的活动对象。（）
* 重锤猛击不再会击退由使用重锤的玩家驯服的生物。（）
* 使用带有风爆魔咒的重锤攻击实体时不再会抵消摔落伤害。（）

* *市场**
* 修复了与下载内容卡住相关的大量漏洞，相关错误包括：“下载全部卡在0%”和损坏的内容更新。（）

* *生物**
* 沼骸在水下的近战攻击不再会对被攻击者施加缓慢效果。（）
* 鹦鹉现在会正确模仿附近的沼骸的声音。

* *石化橡木台阶**
* 的橡木外观变种（值为）现在被扁平化为新的方块。（）

* *弹射物**
* 现在可以通过命令生成风弹弹射物。（）
* *Realms**
* 现在Realms购买屏幕上所有的物品均可以被选中，并且可以使用游戏手柄控制进行选择。
* 移除了Minecraft百科全书的Realms部分中多余的“the”。

* *用户界面**
* 拥有生命恢复效果时，HUD中的红心不再会抖动得过快。（）
* 按住单击物品栏物品时不再会导致物品堆叠计数器短暂出现在物品堆叠上方。
* 与玩家交互范围外的方块交互时不再会短暂出现方块界面。
* 物品被快速移动时不再会在物品堆叠大小的数字前方渲染。（）
* 一叠物品上的数字不再会与村民交易菜单中的悬停文本相重叠。（）
* 物品被快速移动到铁砧时不再会在槽位中略微移动。（）
* 在创造模式物品栏中切换选项卡时，物品在触控设备上不再会保持被选中。（）
* 现在可以在移动设备上通过点击创造模式物品栏中的其他物品来移除副手槽和合成方格中的物品。（）

* *宝库**
* 现在试炼密室的宝库喷出的战利品取决于玩家的等级、位置和种子。</onlyinclude>
