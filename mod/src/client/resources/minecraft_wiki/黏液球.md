* *黏液球（Slimeball）**是主要由[史莱姆](史莱姆.md)掉落的[物品](物品.md)。

# 获取
# = 史莱姆 =

# = 熊猫 =
幼年[熊猫](熊猫.md)打喷嚏时有（约0.143%）的概率掉落1个黏液球。

# 用途
# = 繁殖 =
黏液球可用来繁殖[青蛙](青蛙.md)，给[蝌蚪](蝌蚪.md)喂食黏液球会使其加速成长。
