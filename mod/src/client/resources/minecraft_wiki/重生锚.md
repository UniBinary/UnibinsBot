# 重生锚

*页面ID: 56488* | *来源: Minecraft Wiki*

* *重生锚（Respawn Anchor）**是一种允许[玩家](玩家.md)在[下界](下界.md)设置[重生点](重生点.md)的[方块](方块.md)。

# 生成
重生锚不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘重生锚的合适工具是[镐](镐.md)。重生锚需要钻石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

重生锚被破坏后会掉落自身。

# 用途
和[黑曜石](黑曜石.md)以及[哭泣的黑曜石](哭泣的黑曜石.md)一样，重生锚不能被活塞移动，也不能被[末影龙](末影龙.md)破坏。

# = 重生 =
[alt=|thumb|228x228px|玩家重生位置的优先度（1为最高）。所需的最小空间为1×2×1（即在上方重生）](File:Respawn_anchor_logic2.png.md)
重生锚用于在[下界](下界.md)设置重生点。

对重生锚[荧石](荧石.md)可以为其补充能量，同时其纹理将发生改变，其顶部纹理出现类似下界传送门方块的动态效果及其粒子效果，并发出亮度等级为3的光。4块荧石即可将能量补满，能量等级会显示在侧面刻度盘上：每增加一级，可填充刻度盘纹理的四分之一（按顺时针填充）。在使用第一块荧石后，每多使用一次荧石，重生锚的亮度等级都会再增加4。

在玩家使用荧石激活一个重生锚时有一个特定的音效，在玩家对其按键时和使用重生锚重生时有另外一个类似机械的音效。

有能量的重生锚可以重置玩家重生点（这会覆盖掉玩家用床设置的重生点）。玩家死亡后将重生在重生锚附近，同时其能量等级会减少一级。但如果重生锚被破坏，或者能量耗尽，又或是周围的环境无安全位置，玩家死亡后就会重生在世界出生点，并提示“”。

# = 光源 =
能量等级为1、2、3、4的重生锚依次发出[亮度](亮度.md)为3、7、11、15的光。未充能的重生锚不会发光。
[thumb|270px|重生锚根据其能量等级而发出不同等级的光](File:Respawn Anchor Light.gif.md)

# = 红石元件 =
当其有能量时，[红石比较器](红石比较器.md)会根据其能量等级输出不同强度的红石信号：1级能量对应3级信号，2级对应7级信号，3级对应11级信号，4级对应15级信号。

重生锚也可用[发射器](发射器.md)发射荧石补充能量。

# = 生物 =
[疣猪兽](疣猪兽.md)会主动远离17×9×17范围内的重生锚。

生物无法[生成](生成.md)在4级能量的重生锚上，但其他能量等级可以。

# 你知道吗
* 重生锚的光照等级与比较器给出的红石信号强度一致。
* 重生锚的两个环境音效截取自倒放后的[下界传送门方块](下界传送门方块.md)环境音效。<ref></ref>并且相对于下界传送门方块，激活的重生锚的粒子及其顶面的传送门纹理动画都是逆向运动的。
* * 这些细节暗示重生锚是一个不同于下界传送门的单向出口，玩家“只出不进”。<ref></ref>
