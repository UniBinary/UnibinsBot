# 生存测试

*页面ID: 6526* | *来源: Minecraft Wiki*

* *生存测试（Survival Test）**是[Minecraft](Minecraft.md)向优秀会员发布的有关[生存模式](生存模式.md)的测试版本。<ref>https://web.archive.org/web/20090904213840/http://www.minecraft.net/survivaltest</ref>在[Classic](Java版Classic.md)开发阶段中，可以通过访问官网来游玩该版本。<ref>https://web.archive.org/web/20091003232941/http://minecraft.net/survivaltest/</ref>

2009年10月24日<ref>[英语Wiki上的编辑差异](:en:Special:Diff/2864.md)</ref><ref>https://web.archive.org/web/20100125161411/http://www.minecraft.net/survivaltest/</ref>，生存测试向所有人开放，无论是否为高级会员。

在[Alpha](Java版Alpha.md)阶段时，官方页面进行改造升级，生存测试的链接在2010年12月26日被移除。生存测试版本不能在[启动器](启动器.md)中被找到。

# 新内容
# = 生物 =
; [僵尸](僵尸.md)
* 随机生成于新的生存模式地图中，在玩家接近时跟随玩家。
* 可以跑的跟玩家一样快。
* 偶尔会身着盔甲，但是不能对其提供保护。
* 造成到的伤害，攻击时有挥臂的动作。

; [骷髅](骷髅.md)
* 随机生成于新的生存模式地图中，在玩家接近时跟随玩家。
* 偶尔会身着盔甲，但是不能对其提供保护。
* 会射箭来攻击玩家，造成到的伤害。
* * 射出的箭是紫色的。
* * 濒死时它们会随机向周围短距离内射出4-9支箭。这些箭可以被玩家捡起并使用。
* 被杀死时会掉落5支箭。

; [苦力怕](苦力怕.md)
* 近战攻击，造成到的伤害。被玩家击杀后会爆炸。

; [猪](猪.md)
* 被击杀后会掉落棕色蘑菇。

; [蜘蛛](蜘蛛.md)
* 被杀死时掉落棕色蘑菇。

; [绵羊](绵羊.md)
* 被击杀后会掉落棕色蘑菇。
* 被玩家使用左键时会掉落[羊毛](羊毛.md)，可以通过吃[草](草.md)来重新长毛。

; [巨人](巨人.md)
* 因为太过强大而被废弃。

# = 游戏内容 =
; [生存模式](生存模式.md)

; [生命值](生命值.md)
* 共有，由10颗心组成，低于时生命栏会颤动。
* 玩家会在以下情况受到伤害：从高处坠落、溺水、陷入[熔岩](熔岩.md)和被其他生物攻击。

; 分数系统
* 可以通过击杀生物获得分数。
* * 杀死绵羊和猪可以获得10分。
* * 杀死僵尸可以获得80分。
* * 杀死蜘蛛可以获得105分。
* * 杀死骷髅可以获得120分。
* * 杀死苦力怕可以获得200分。
* 不能通过间接杀害获得分数。
* * 例如玩家利用苦力怕炸死了僵尸，玩家不会得到任何分数。

# 更改
# = 方块 =
; [金块](金块.md)
* 现在可以通过挖掘[金矿石](金矿石.md)来获得。

; [铁块](铁块.md)
* 现在可以通过挖掘[铁矿石](铁矿石.md)来获得。

; [石台阶](石台阶.md)
* 现在可以通过挖掘[煤矿石](煤矿石.md)来获得。

; [橡木木板](橡木木板.md)
* 现在可以通过挖掘[橡木原木](橡木原木.md)来获得。

; [羊毛](羊毛.md)
* 现在可以通过对[绵羊](绵羊.md)使用左键来获得。

; [圆石](圆石.md)
* 现在可以通过挖掘[石头](石头.md)来获得。

; [树苗](树苗.md)
* 现在可以通过挖掘[橡树树叶](橡树树叶.md)来获得。

; [泥土](泥土.md)
* 现在可以通过挖掘[草方块](草方块.md)来获得。

; [TNT](TNT.md)
* 现在可以通过使用键来引爆。
* * 最大可以对玩家造成6颗心的伤害，这主要取决于玩家距离TNT有多近。
* * 可以破坏周围的地形，具有约四个方块的爆炸半径。

; [蘑菇](蘑菇.md)
* 现在可以作为食物食用。
* * 食用棕色蘑菇会回复点生命值。
* * 食用红色蘑菇会受到点伤害。
* 棕色蘑菇可由猪和绵羊掉落。

# = 游戏内容 =
; [玩家](玩家.md)
* 玩家走动时会摇晃，以及更逼真的3D立体效果。
* 现在玩家可以看到自己的手。

; [控制](控制.md)
* 按可以发射[箭](箭.md)。

; 常规
* 玩家死亡后不会重生，而是需要重新加载或生成新的世界。
* 玩家出生时，快捷栏的第九个槽位有10个[TNT](TNT.md)。
* 玩家可以通过按下左键来攻击其他生物。
* * 玩家徒手可以对生物造成的伤害。

# 你知道吗
* [Indev 0.31](Indev 0.31.md)在第一次更新中被称为生存测试。
* [苦力怕](苦力怕.md)是由失败的[猪](猪.md)模型制作出来的。
* 在[0.26 SURVIVAL TEST](Java版Classic 0.26 SURVIVAL TEST.md)中，蜘蛛本来的外观是黑眼珠和棕色身体。
