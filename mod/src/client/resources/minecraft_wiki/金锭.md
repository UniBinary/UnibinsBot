# 金锭

*页面ID: 7159* | *来源: Minecraft Wiki*

* *金锭（Gold Ingot）**是一种用于制作多种物品的金属锭，同时也是用于[以物易物](以物易物.md)的物品。

# 用途
金质装备的[耐久度](耐久度.md)和作为[武器](武器.md)时的[攻击伤害](属性/攻击伤害.md)均相对较低，但其[工具](工具.md)的[挖掘](挖掘.md)速度是所有工具中最快的，同时金质装备也有着所有装备中最高的[附魔能力](附魔能力.md)。

# = 修复 =
[金头盔](金头盔.md)、[金胸甲](金胸甲.md)、[金护腿](金护腿.md)、[金靴子](金靴子.md)、[金剑](金剑.md)、[金镐](金镐.md)、[金斧](金斧.md)、[金锄](金锄.md)、[金锹](金锹.md)和[金矛](金矛.md)能在[铁砧](铁砧.md)用金锭来[修复](修复.md)。

# = 以物易物 =
玩家可通过对[猪灵](猪灵.md)或扔出金锭来与之进行[以物易物](以物易物.md)。猪灵收到金锭后会给予玩家特定物品。

# = 信标 =
金锭可用于从[信标](信标.md)中选择并激活[状态效果](状态效果.md)。玩家必须选择一种可用的状态效果，然后在物品槽中放入一个金锭。

金锭可以代替[铁锭](铁锭.md)、[绿宝石](绿宝石.md)、[钻石](钻石.md)或[下界合金锭](下界合金锭.md)为信标选择状态效果。
