# Java版18w22c

*页面ID: 34824* | *来源: Minecraft Wiki*

* *18w22c**是[Java版1.13](Java版1.13.md)的第42个，也是最后一个快照，发布于2018年5月31日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 调试屏幕现在在方块信息下面增加了玩家看向的方块中的流体信息。

* *[控制](控制.md)**
* 补齐坐标的时候会分开补齐每个部分了。
