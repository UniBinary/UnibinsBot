# 远古

*页面ID: 111285* | *来源: Minecraft Wiki*

* *远古（Ancient）**可以指：
# Minecraft
*  - 一种大型的地下[结构](结构.md)，主体由[深板岩](深板岩.md)及其变种方块构成。
*  - 一种出现于[下界](下界.md)的罕见金属[矿石](矿石.md)。
*  - 一种生成于[海底神殿](海底神殿.md)的[敌对生物](敌对生物.md)。
* [远古植物](远古植物.md) - 可通过[嗅探兽](嗅探兽.md)挖掘获得其种子然后种植得到的方块。
*  - 一种被掩埋的陶瓦建筑群结构，主体由构成。
*  - 一种与远古守卫者相似的未使用生物。

# Minecraft Dungeons
* [远古狩猎](远古狩猎.md) - 一种需要献祭武器开启的关卡。
* [远古生物](Dungeons:远古生物.md) - 远古狩猎中作为Boss的普通生物变种。
*  - 中的小Boss。
*  - 隐秘深渊中的主要Boss。
*  - [赛季二：辉光暗夜](Dungeons:赛季.md)的生物击杀特效。
*  - 一种远程武器。
