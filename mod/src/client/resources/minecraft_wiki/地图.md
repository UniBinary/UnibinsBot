# 用途
# = 绘制地图 =
手持空地图按下键即可绘制地图，地图上显示的是[玩家](玩家.md)周围环境的俯视图。地图的上方是北，下方是南，左方是西，右方是东。

地图**不会**以玩家创建地图时所处位置为中心点，而是将世界按一定的比例划分成一个个方格区域后，显示地图首次绘制时所处的区域。<ref></ref>例如，玩家在某个区域内绘制新地图，然后按照地图移动一段距离后再绘制另一张新地图，这两张地图都是一样的，除非玩家走出第一张地图显示的区域，进入另一个方格区域后再创建新地图。

为了在地图上记录各地的地形，玩家在世界移动时必须手持该地图。地图记录玩家在主世界或末地64格为半径，或下界32格为半径范围内的地形。即使玩家在地下，地图也只记录地面。地图只记录各地在玩家探索时的现状，如果世界发生了变化，玩家必须拿着地图重游该区域来更新地图。

地图只在主手拿着地图而副手没有拿着东西时才会显示正常大小。当玩家副手拿着地图，或副手槽拿着其他东西而在主手拿着地图时，会显示一个缩小版的地图。

玩家在地图的位置由一个椭圆形的指针指示，玩家穿过地图地形时会跟着移动。

若玩家离开一个地图显示的区域，该玩家在地图上的指针会变为一个圆点。圆点只会沿着地图边缘移动来显示玩家的相对位置，并且玩家每远离地图中心半径320格，圆点就会缩小一次，直到它在地图上消失。只有其他玩家的物品栏里有一张当前地图的拷贝时，他们才能共同显示在这份地图上。

所有玩家都可以共同显示在地图上。当把地图放进[物品展示框](物品展示框.md)时，地图会显示一个代表展示框所在位置的绿色指针。

在[下界](下界.md)绘制出的地图只会显示棕灰相间的图案，并且玩家指针在下界会迅速旋转。下界的物品展示框指针也会迅速旋转。[末地](末地.md)的方向指示器能正常地运作。

当玩家在一个维度使用地图后离开该维度，地图会显示玩家位于该维度最后一刻的位置和方向。

玩家在主世界时，在下界创建的地图中玩家标记为白色，玩家标记方向会以顺时针以各个方向转动，且在玩家移动时轨迹会与在主世界的保持一致，坐标遵循8:1的比例同步改变；在末地创建的地图不会显示玩家标记。玩家在下界时，在主世界创建的地图中玩家标记为红色，玩家标记方向与玩家在下界的方向对应一致，且在玩家移动时轨迹会与在下界的保持一致，坐标遵循1:8的比例同步改变；在末地创建的地图不会显示玩家标记。玩家在末地时，在主世界创建的地图中玩家标记为一个紫色的点，位置在玩家的出生点；在下界创建的地图不会显示玩家标记。<ref name=multiverse></ref>

玩家可以在地面上建造俯视的大型像素画并绘制地图，将地图放进[物品展示框](物品展示框.md)作为自定义图画。一般建议锁定地图，防止像素画被破坏后地图图案会随之更新。参见。

# = 地图显示 =

地图的每一像素对应世界里能改变大小的区域，它总是对准是8的倍数的X和Z[坐标](坐标.md)。

地图会以较浅的蓝色显示水下大约15格的地面，所以玩家会看见哪里的地势是升高的。当有陆地在水面上时上述不成立。世界的海拔愈高，地图上的颜色愈浅。即使玩家在地表下移动，地图仍会记录地表上的东西。

地图的大小是128×128像素，给予128×128至2048×2048方块（8×8至128×128[区块](区块.md)）的覆盖面，覆盖面取决于缩放等级。缩放等级越大，地图覆盖的范围就越大，但其局部特征会变得不明显。

一些相关的距离：128方块（8区块）是主世界玩家的更新半径。然而，在末地和下界是它的一半（64方块）。而且，1024方块是从[下界传送门](下界传送门.md)的最少主世界距离，你能在这里建造另一个下界传送门并预期能到达下界的一个新地方。这是穿过一个1:8地图的距离，也是1:16地图从中心到边界的距离。

# = 玩家标记和位置指针 =
指示玩家的位置和方向的指针本身就会出现在任何地图里。但当玩家从末地通过命令以外的方式返回主世界后，或者当重载游戏后，其他维度的位置指针会暂时不可见，直至玩家携带地图返回所在的维度。

地图在合成时可以选择是否有标记。当地图在合成时没有使用指南针，就会合成出一个没有标记的“空地图”，否则会合成出一个带有标记的“空定位地图”。玩家进入下界后，标记会变成红色，且在玩家移动时轨迹会与在主世界的保持一致；进入末地后则会变成紫色。如果在末地使用在主世界创建的地图，那么一个紫色的点会出现在玩家的出生点。

只使用纸合成的地图不会带有玩家标记；想要加入标记则要使用指南针。

# == 缩小细节 ==
不同缩放等级的地图：从初始绘制的地图（缩放等级0）到最大的缩放比例（缩放等级4）。

地图在全部缩放等级总是对准一个网格，这表示不管地图原本的中心在哪里，缩小一个特定范围的任何地图都会有同样的中心点。确切而言，地图角点的X和Z坐标值均总会是地图的宽度（等级3是1024格）的整数倍减64，在出生点创造的等级3地图会覆盖从-64到960的X和Z坐标。所有在这范围的地图会缩小到同样的坐标，保证多张相邻的地图在地图墙上总是严丝合缝。

在无缩放的地图中，在X和Z坐标（0,0）上创建地图，标记会出现在地图正中央；而在缩放后的地图上，坐标（0,0）会出现在左上角的方格里。

对于[原主机版](原主机版.md)而言，地图不能被缩放，但可以使用[制图台](制图台.md)以扩展大小。缩放等级为3的地图可以覆盖坐标从-512到+512的范围。这样做是为了能在经典或小型世界里只需使用1个地图，在中型世界里使用9个地图（X和Z坐标范围在±512到±1536）以及在大型世界里使用25个地图（X和Z坐标范围在±1536到±2560）就够了。

缩放等级可以在打开高级工具提示（）后得知。工具提示会展示地图的缩放等级和比例。

# = 复制 =
需要用到空地图和空定位地图。复制后的地图是否有标记取决于用的是哪一种地图。

可使用[制图台](制图台.md)和工作台复制地图。

已探索与绘制的区域会被复制，新探索的区域也会在两个地图都出现。在创造模式，通过对[物品展示框](物品展示框.md)里的地图按选择方块能获得复制的地图（确保在选择方块时该地图不在物品栏里，否则该地图只会被移动到可用的快捷栏）。

# = 旗帜标记 =

[地图上的所有颜色的旗帜标记，以及一个带名称的标记|thumb](File:Banner marked map.png.md)
玩家可以在地图上创建旗帜标记。通过手持地图对着一个[旗帜](旗帜.md)按下键，地图便会留下一个旗帜标记，且标记的颜色与旗帜的颜色一致。如果旗帜有自定义名称，那么地图上的标记也会带有名称。如果旗帜被破坏，那么在区块更新后，地图上的旗帜标记会消失。

# = 锁定地图 =
在制图台上使用[玻璃板](玻璃板.md)可以锁定地图。锁定后的地图内容不再有任何变化，复制该地图后获得的新地图也会被自动锁定。

# 你知道吗
* 使用键能使玩家在手持地图时视线不被阻挡。
* 使用创造的地图如果没有提供有效的地图编号，地图会变成“未知地图”，直到对应地图编号的地图被创建。
* 一些程序能被用于制作有图像和文字的自定义地图而不是真实的地图，很多人在冒险地图中使用这些来展示图像或讲述故事。
* 由于一张地图的所有复制品都链接到同一个文件，复制未完成的地图会使复制品在原本地图绘制时与它同步。因此，储存在箱子的复制品能作为远距离备份。
