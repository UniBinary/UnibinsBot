* *1.21.11-rc1**是[Java版1.21.11](Java版1.21.11.md)的首个发布候选版本，发布于2025年12月4日<ref></ref>，更改了矛冲锋攻击可造成击退的时间和攻击动画。

此版本也额外发布了未经混淆的版本，称为**1.21.11 Release Candidate 1 Unobfuscated**（启动器内称**1.21.11-rc1_unobfuscated**），旨在过渡至后续小更新时移除混淆。<ref></ref>

# 更改
# = 物品 =
* *[矛](矛.md)**
* 增加了矛在冲锋攻击时可以造成击退的持续时间。
* * 冲锋攻击的动画现在更好地对应矛的不同阶段。</onlyinclude>
