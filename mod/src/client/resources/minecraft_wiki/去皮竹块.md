# 去皮竹块

*页面ID: 163638* | *来源: Minecraft Wiki*

* *去皮竹块（Block of Stripped Bamboo）**是一种对[竹块](竹块.md)[斧](斧.md)后得到的[方块](方块.md)。

# 生成
去皮竹块不会生成在世界中，只能通过对[竹块](竹块.md)[斧](斧.md)来产生。

# 获取
去皮竹块只能通过破坏去皮竹块获得。

# 破坏
挖掘去皮竹块的合适工具是斧。

去皮竹块被破坏后会掉落自身。

# 用途
# = 合成材料 =

# = 燃料 =
去皮竹块可以作为[熔炉](熔炉.md)、[高炉](高炉.md)和[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个去皮竹块可以烧炼1.5个单位的物品。
