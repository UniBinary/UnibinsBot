# Java版粒子

*页面ID: 150045* | *来源: Minecraft Wiki*

[缩略图|右|300px|水下粒子效果，包括气泡柱](File:Coral reef at night.png.md)
* *粒子（Particle）**，也称**粒子效果（Particle Effect）**，是[Minecraft](Minecraft.md)中一种特殊的图形效果，在特定事件发生（比如[爆炸](爆炸.md)、[降雨](降雨.md)、用[熔炉](熔炉.md)进行[烧炼](烧炼.md)）时出现。

# 定义
单个粒子由粒子类型（见下表）、此类型所需的选项（见[粒子数据格式](粒子数据格式.md)）、额外参数（见[命令/particle](命令/particle.md)）三者完全定义。在命令中可以指定这三者以生成特定的粒子。绝大多数粒子类型使用的粒子纹理可以通过[资源包](资源包#粒子.md)修改。此外还有三种特殊的粒子类型：<code>explosion_emitter</code>、<code>gust_emitter_large</code>和<code>gust_emitter_small</code>，它们本身不渲染，也不会移动，而是不断在周围随机产生其他粒子，这种粒子类型被称为粒子发射器（Particle Emitter）。

# 行为
单个粒子总会以2D的图像显示，并且大多数粒子会以正前方朝向玩家。它们在一段时间后消失，在这段时间内，它们可能静止不动，也可能发生移动，它们可能在多个纹理间循环，也可能随时间发生尺寸缩放、颜色改变、或透明度改变。

每种粒子类型都有其寿命（Lifetime），从粒子生成开始计时，到达寿命后粒子被移除。有的粒子类型的寿命是在某个范围内的随机数，有的粒子类型的寿命则是固定值。在未到达寿命前，有的粒子也会在特定的条件下消失，如熔岩粒子落入熔岩中会立即消失。

粒子生成时往往会带有初速度，取决于粒子类型。运动速度可能会受到阻力而逐渐减小，不同粒子类型的阻力大小不同，有的粒子类型不受阻力。一些粒子类型还具有重力，使得Y轴方向的速度随时间不断改变。有的粒子类型具有负的重力，使得粒子向上加速。一些粒子类型具有类似[实体](实体.md)的运动碰撞检测，其运动会被方块碰撞箱阻碍。

# 你知道吗
* 大多数粒子的颜色都可以通过资源包来改变，然而红石、传送门和末影人的粒子颜色只能使用MOD更改。
* * <code>dust</code>粒子具有用于颜色的独特语法，用三个RGB值表示为十进制百分比。
* 在游戏内部有一个用来显示捡起物品动画的粒子<code>take</code>，但它不能通过命令生成。它的名称在[Java版1.13](Java版1.13.md)被移除。
