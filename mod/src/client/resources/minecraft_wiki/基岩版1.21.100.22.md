# 基岩版1.21.100.22

*页面ID: 155663* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.100.22**（ChromeOS/Android）、**Preview 1.21.100.22**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.100](基岩版1.21.100.md)的第3个测试版，发布于2025年6月25日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 物品 =
* *[附魔书](附魔书.md)**
* 具有火焰附加的附魔书不再可用于点燃[蜡烛](蜡烛.md)、[营火](营火.md)和[TNT](TNT.md)。

# = 生物 =
* *[快乐恶魂](快乐恶魂.md)**
* 现在被玩家或驯服的[狼](狼.md)杀死时会掉落。

# = 技术性 =
* *生物群系**
* 更新了组件，以包含变量，若为true，则其会为草地添加着色效果，如同顶部有遮挡。

* *方块**
* 将方块格式版本为1.21.100或更高版本的组件从[实验性玩法](实验性玩法.md)中移出。
* 修复了基础方块JSON定义中没有组件的方块会出现不正确的破坏粒子的问题，其现在会像以前一样回退到组件的定义。
* 修复了与读取动画化方块的错误或损坏的JSON数据相关的崩溃。现在会触发错误并阻止方块播放动画。

* *[基岩版编辑器](基岩版编辑器.md)**
* 为模态框工具和属性窗格的提示框加入了一个可选的图像字段。
* 在编辑器窗格设置中加入了“静音音乐”和“静音游戏音效”选项。
* 加入了将结构项目从结构面板拖拽到视口的能力。这会更新剪贴板并激活粘贴预览。
* 更新了编辑器项目中的命令，以使其使用编辑器的结构存储库而非存档的结构存储库。
* 修复了进入测试世界并从测试世界返回后，方块成像会出现不对齐的图标和图像缺陷的问题。

* *图形**
* 钓鱼线：增大了模式下钓鱼线的厚度，以使其不会在启用TAAU时消失。
* 将实体的受伤颜色覆盖层的透明度值由65%降低至25%，以提高可访问性。
* 带有不正确尺寸的焦散纹理不再会加载；现在会发出内容日志错误并改用默认焦散纹理。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“测试版 API”和“”子选项后才可使用。

# = 技术性 =
* *API**
* 为加入了类，用于与交互以更改它们的内容以及为它们署名。
* 为加入了类和类。

* *生物群系**
* 加入了新的服务端生物群系组件，这将合并为一个组件。
* * 每个生物群系只能使用一种构建器类型。
* * 此组件可用于世界生成设置，例如地基材质和海底深度。
* 加入了带有的组件，能够强制生物群系一直湿润或永不湿润。湿度会影响火在生物群系中的蔓延概率和蔓延速率。
* 加入了组件。此组件会影响封冻的生物群系，致使部分区域不会冻结。例如：零散的冰雪。

* *拼图**
* 将结构定义文件夹由更改为。

# 修复
* *方块**
* 修复了具有火焰附加的附魔书可用于点燃蜡烛、营火以及激活TNT的漏洞。（）

* *物品**
* 现在使用拴绳将实体拴在另一实体时的“Attach”提示会被翻译。（）

* *拴绳**
* 现在拴绳的断裂音效会在拴绳持有者所在位置发出，而不是在被拴绳拴住的活动对象所在位置发出。

* *生物**
* 快乐恶魂现在会在被玩家杀死时掉落。
* 自1.21.100起，逐步启用对生物死亡行为的引擎更改。此重构应不会影响游戏内容。

* *弹射物**
* 弹射物的目标差幅现在会根据世界中的活动总时长而递增。（）
* * 此前，弹射物的目标差幅会在每一飞行刻增大一次。
* * 现在，弹射物的目标差幅会在每一活动刻增大一次，无论弹射物的飞行状态如何。

* *音效**
* 提高了骑乘快乐恶魂升空音效的音量。</onlyinclude>
