# 基岩版1.7.0.3

*页面ID: 36357* | *来源: Minecraft Wiki*

<onlyinclude>
* *beta 1.7.0.3**是[1.7.0](基岩版1.7.0.md)的第2个测试版，发布于2018年8月29日<ref>https://feedback.minecraft.net/hc/en-us/articles/360015150092-Minecraft-Beta-1-7-0-3-Xbox-One-Windows-10-Android-</ref>，修复了一些漏洞。

# 修复

* 修复了游戏期间可能出现的崩溃问题。
* 修复了记分板上当没有目标被分配时清除“belowname”显示槽出现的崩溃。
* 修复了上一个Beta版本更新后的出现损坏的皮肤纹理。
* 梯子不再出现在村庄教堂结构的半空中。
* 高海草现在渲染正确。
* 当铁傀儡站在不完全的方块上时又一次能攻击怪物。
* 修复了HUD显示格式化后的文本被截断的问题。
* 当记分项目绑定时，记分板项目将会按字母排序。
* 修复了记分板用户界面的布局问题和更新问题。
* 移除没有加入记分板的实体的分数时，不再会导致给对应的实体加上对应的分数。
* 记分板现在限制侧边栏上显示的被测实体的数量。</onlyinclude>
