# 携带版0.15.6

*页面ID: 23850* | *来源: Minecraft Wiki*

* *v0.15.6 alpha**是携带版的一次次要更新，在iOS、Android和FireOS上发布于2016年8月10日，在Windows Phone和Windows 10中发布于8月11日，修复了[Alpha 0.15.4](携带版Alpha 0.15.4.md)中的一些漏洞与崩溃<ref></ref>。

# 新内容
# = 常规 =
* *[控制](控制.md)**
* Windows 10 Beta版现在支持Oculus Rift。

# 更改
# = 常规 =
* *[控制](控制.md)**
* 启用Oculus Rift时提供更好的键盘和鼠标支持。

* *UI**
* 调整了Oculus Rift模式下的Windows 10 UI以提高可用性。

# 修复

* *其他**
* 更新了Oculus平台启动器的本地化翻译，以及修复了Virtual Studio的可分发的数据包。
* 音频现在会根据玩家选择的扬声器来播放。
* 按钮现在能用于切换电视模式和沉浸模式。
* 修复了一些字符显示问题。
* 修复了Gear VR版的一些崩溃现象。
