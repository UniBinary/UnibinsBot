* *金毒马铃薯（Golden Poisonous Potato）**是一种能被玩家食用的特殊[食物](食物.md)类物品，能给予多种状态效果。

# 获取
# = 合成 =

# 用途
# = 食物 =

手持金毒马铃薯按住键即可食用，每个金毒马铃薯可以回复，并获得多种[状态效果](状态效果.md)。在玩家饥饿值满时也能吃金毒马铃薯。

金毒马铃薯提供2分钟的[伤害吸收](伤害吸收.md)I效果（提供[伤害吸收值](伤害吸收值.md)）与5秒的[中毒](中毒.md)II效果（每12刻，每秒，共扣除）。
