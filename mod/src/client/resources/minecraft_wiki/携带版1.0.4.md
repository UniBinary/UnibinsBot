# 携带版1.0.4

*页面ID: 27588* | *来源: Minecraft Wiki*

* *1.0.4**是一次[携带版](携带版.md)的次要更新，发布于2017年3月9日<ref></ref>，加入了村民交易、新的皮肤包、新的成就、新的附加包格式和新的选项，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[村民](村民.md)**
* 加入了傻子村民（只能使用第三方软件生成）。

# = 游戏内容 =
* *[交易](交易.md)**
* 加入了[交易](交易.md)<ref></ref>。
* * 与村民交易时，村民的头上会出现一个[绿宝石](绿宝石.md)图案。

* *[成就](成就.md)**
* 加入了“斤斤计较”[成就](成就.md)。

# = 常规 =
* *[资源包](资源包.md)**
* 加入了[陌生人皮肤包](皮肤包#SPStrangers.md)。

* *[附加包](附加包.md)**
* 新的附加包格式。所有的附加包都会自动更新，可能会在这些附加包看到警告，但附加包的所有功能都不会受到影响。

* *[设置](设置.md)**
* 在选项中添加了“存储”界面来管理世界、资源包和行为包。
* 现在音乐和音效可通过资源包更改了。

# 更改
# = 生物 =
* *[村民](村民.md)**
* 现在会与其他村民分享食物。
* 现在可以向其投掷3个面包、12个胡萝卜、12个甜菜根或12个马铃薯以增加繁殖意愿。
* 现在只有有意愿时才能繁殖。
* 现在幼年村民拥有和成年村民一样大的头。

* *[潜影贝](潜影贝.md)和[末影龙](末影龙.md)**
* 在附加包的模型现在可以用附加包编辑了。

* *[尸壳](尸壳.md)**
* 现在略高于[僵尸](僵尸.md)了。

# = 常规 =
* *性能**
* 加入了CDN来减少游戏文件大小。
* 为性能较差的旧设备添加了低渲染距离选项。

# 修复
* *修复了63个漏洞**
*  - 重新进入世界后，生物可以穿过栅栏。
*  - 铁匠铺里的熔岩会溢出。
*  - 爆炸会摧毁下界之星。
*  - 重新进入世界时，雷暴天气被下雨天气替代。
*  - 生物生成在双层台阶上时会一直原地转圈。
*  - 村民在里村庄太远的地方游荡。
*  - “钻石！”和“保镖”成就无法达成。
*  - 雕纹砂岩和平滑砂岩的底部纹理错误。
* 和 - 村民无法繁殖。
*  - HUD里显示的生命条和盔甲条不正确。
*  - 恶魂会在狭窄的空间里生成。
*  - 角视场设置为最大时，玩家疾跑使得角视场变化出错。
*  - 使用鞘翅飞行然后撞墙时显示的信息错误。
*  - 装备了鞘翅时仍会显示披风。
*  - 射进方块里的箭会变成黑色。
*  - 使用地图时，游戏性能骤降。
*  - 中型、大型的史莱姆和岩浆怪没有跳跃和着陆声音。
*  - 驴不在平原生物群系里生成。
*  - 如果有玩家在其他维度逗留时，主世界里的玩家不能睡觉。
*  - 末地折跃门方块生成速度太快。
*  - 摧毁画会使得背后的方块也一并摧毁。
*  - 铁砧在掉落后会转向。
*  - 对着树叶点击鼠标中键不会给予正确的树叶。
*  - 客户端在加载新区块时，旧区块不能全部刷新。
*  - 村民在交易状态时仍会走开。
*  - 非农民村民也会收割和播种作物。
*  - 村民在交易时没有播放交易询问音效。
*  - 治愈后的僵尸村民没有职业。
*  - 交易界面里的附魔书纹理错误。
* 使用命令生成村民时，只会生成农民村民。
* 导入0.15.9或更早的世界时，僵尸村民的职业被重置为农民。
* 被攻击时，村民的逃离速度太快。
* 需要有方块在底部支撑的方块（例如火把和铁轨）不能放置在上半部分台阶上面。
* 受到两个来源的伤害时，玩家会死亡两次。
* 骑乘在其他生物身上的生物的位置不正确。
* 存在特殊条件允许时，仍然只能生成常规骷髅变种的蜘蛛骑士。
* 骑乘型生物（例如蜘蛛骑士）不能进入矿车里。
* “又是……末地……”成就无法达成。
* 生成海底神殿或下界要塞时游戏崩溃。
* 无限火会频繁传播或者减缓燃烧。
* 玩家在附近有其他玩家的情况下切换维度时游戏崩溃。
* 使用给予多于一组的物品时，不会在输出信息里显示正确的物品数量。
* 糖果纹理包里的纹理出现错误。
* 导入资源时游戏崩溃。（仅iOS版）
* 退出时崩溃。
* 加载清单里有错误的行为包或资源包时游戏崩溃。
* 启用行为包时，仍然可以解锁成就。
* 紫色植株在破坏时不会完全被摧毁。
* 启用渲染器时，需要重启以生效。
* 行为包在导入时，清单里的错误不会正常显示。
* 其余玩家在接受资源包并进入游戏时，游戏房主的客户端会崩溃。
* 在导入行为包附属的资源包后，导入该行为包会使得资源包被复制。
* 使用铁砧、酿造台或熔炉时游戏崩溃。
* Gear VR世界和Android世界不会彼此互相展示。
* 使用鞘翅飞行时崩溃。
* 村民会立即捡起向其投掷的掉落物。
* 村民不会互相投掷食物。
* 导入重复的资源包或行为包时游戏崩溃。
* 物品展示框被摧毁时，展示的物品不会掉落。
* 在村民交易界面里的附魔书不能显示包含的魔咒。
* 修复了一些纹理错误。
* 修复了行为包里的HUD图像显示错误。
* 在卸载资源包时，盔甲的纹理不会还原。
