# Java版材料

*页面ID: 19113* | *来源: Minecraft Wiki*

* *材料（Material）**将[方块](方块.md)分成了许多不同的种类，并赋予方块各种属性与行为。

# 材料列表
以下是在Minecraft中存在的材料。每一种材料都会赋予方块特定的属性，不过这些行为都能被方块自己的定义的属性覆盖。
; 材料列表（于[1.20](Java版1.20.md)失效）
* 内部名称：材料在游戏源代码中定义的名称。
* 名称：材料的名称。
* 地图颜色：该材料的默认[地图基色](地图基色.md)。
* 是否为液体：。
* 是否为固体：如果是，一些附着性方块可以放在其上。此项也会影响液体的传播。
* 是否固体阻挡：如果是，则铁傀儡可能在其上生成。此项也影响红石导体的判断。
* 是否阻止运动：。
* 是否可以被替换：如果是，可以直接在该方块的位置放置其他方块。
* 熔岩可燃性：只用来指定熔岩是否能在该方块上生成火，与火的传播无关。
* 活塞推动行为：如果是“推动”，该方块会被活塞推动；如果是“阻挡”，该方块会阻止活塞运动；如果是“破坏”，该方块会被活塞破坏；如果是“替换”，该方块会被活塞头替换。

; 材料列表（[23w16a](23w16a.md)）
* 内部名称：材料在游戏源代码中定义的名称。
* 地图颜色：该材料的默认[地图基色](地图基色.md)。
* 是否固体阻挡：如果是，则铁傀儡可能在其上生成。此项也影响红石导体的判断。

# = 窒息生物 =

绝大多数[碰撞箱](碰撞箱.md)完整且由阻止运动材料组成的方块会使头部在其中的生物窒息，下列方块是例外：

* 、、、会使生物窒息。
* 在关闭时会使生物窒息，在开启时不会。
* 和在未伸出时会使生物窒息，在伸出时不会。

# = 遮挡视野 =
类似于窒息方块，有些方块当玩家头部在其中时视野会被完全遮挡，屏幕变暗，并且暗色的方块纹理会遮挡整个屏幕。

所有窒息方块都是遮挡视野方块，8层也是遮挡视野方块。

# = 红石导体 =
[非红石导体（荧石）和红石导体（草方块）|thumb](File:Redstone Solid Block.png.md)

红石导体拥有可被充能、允许[红石比较器](红石比较器.md)检测后方方块、阻止箱子开启、“压断”红石线等属性。绝大多数碰撞箱完整且由固体阻挡材料组成的方块都是红石导体，但下列方块是例外：
* 、、、、、、、和不是红石导体。
* 和是红石导体。

# = 可替换方块 =
[几种可替换方块：空气、结构空位、熔岩、水、雪、藤蔓、蕨、枯萎的灌木、草丛和火|thumb](File:Replacable Block.png.md)
所有由可替换材料组成的方块都是可替换方块。当玩家按键放置方块时会直接覆盖该方块而不是放置在其毗邻，就如空气方块那样。

如果[受重力影响的方块](下落的方块.md)下方是一个可替换的方块，那么它可以在接受[PP更新](方块更新#PP更新.md)后掉落。如果[下落的方块](下落的方块.md)落地时，落地的位置是可替换方块，那么该方块变为下落的方块对应的方块，否则下落的方块会掉落为对应的物品。

# = 其他作用 =
* [末影人](末影人.md)会根据材料是否阻止运动来瞬移。它在瞬移时会随机选择X和Z坐标，然后从上到下依次寻找阻止运动的材料，并尝试传送至其上。
* * 类似地，一些生成或传送到“地表”的生物依靠材料是否阻止运动来寻找表面。
* 玩家[重生](重生.md)的阻挡检查依靠材料是否为固体或流体，但玩家可以重生在旗帜、压力板或告示牌里。
* 仙人掌的破坏取决于四周方块是否为熔岩以及材料是否为固体，上方方块的材料是否为液体。
* 使用[铁桶](铁桶.md)倒液体时，目标位置的材料可替代或者材料不是固体，并且不是末地传送门方块或末地折跃门方块，才会尝试倒出液体。
* 村民召唤[铁傀儡](铁傀儡.md)时，铁傀儡可以在空气材料或液体材料中生成，下面的方块必须是固体阻挡的材料且上表面碰撞箱完整。
* 命令会尝试避免将玩家传送到液体材料或火材料中。
* 当冰被破坏时，如果下方方块的材料阻止运动或是液体，它会变成水。
* 熔岩会检查周围是否有可燃材料并生成火。但火有单独的可燃列表，所以熔岩附近的方块旁边常常会有火，但可能不会烧毁方块。
* [睡莲](睡莲.md)只能被放置在下面材料有冰材料或水的空气材料方块中。
* 雨和雪穿过非流体且不阻止运动的材料。
* [音符盒](音符盒.md)检测下方方块或其材料来决定发出的声音。它检查石头、沙子、玻璃和木头材料，对应的乐器分别是大鼓、小军鼓、击鼓沿和低音提琴。
* 具有不同材料变体的各种方块会检查材料以确定要播放的声音。
* 游戏通常根据木头或金属材料来区分木质或铁质的门和活板门。
