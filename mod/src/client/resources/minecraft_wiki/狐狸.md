* *狐狸（Fox）**是一种通常生成在[针叶林](针叶林.md)、[原始针叶林](原始针叶林.md)和[积雪针叶林](积雪针叶林.md)生物群系的、夜行性的友好生物。

# 生成
狐狸在[针叶林](针叶林.md)、[原始松木针叶林](原始松木针叶林.md)、[原始云杉针叶林](原始云杉针叶林.md)、[积雪针叶林](积雪针叶林.md)和[雪林](雪林.md)生物群系生成。在积雪针叶林和雪林中生成的狐狸是白色的。狐狸可以生成在[草方块](草方块.md)、[砂土](砂土.md)、[灰化土](灰化土.md)、[雪块](雪块.md)或[雪](雪.md)上；狐狸可以生成在任意可生成方块上。

狐狸生成时有5%的概率生成为幼年狐狸。

# 掉落物
成年狐狸被[玩家](玩家.md)或驯服的[狼](狼.md)杀死后会掉落|java|short=1}}或|be|short=1}}。

像其他幼年动物一样，杀死幼年狐狸不会掉落经验。

狐狸总会掉落它们正在持有的物品（已被吃掉的食物不会掉落），自然生成时持有的物品会100%掉落。

# 行为
[thumb|狐狸在云杉树下睡觉](File:Foxes2.png.md)
狐狸的速度很快，和[豹猫](豹猫.md)的速度相近。狐狸会逃离附近的狼、[北极熊](北极熊.md)或不信任的且不是[潜行](潜行.md)状态的玩家。

狐狸在[甜浆果丛](甜浆果丛.md)中移动时不会受到伤害，狐狸处在[细雪](细雪.md)上时也不会陷入其中。

狐狸在雷暴时，且上方没有固体方块时，狐狸会寻找一处上方有固体方块的地点以躲避闪电，此时它们不会攻击任何生物。

# = 信任玩家 =
繁殖2只成年狐狸产生的狐狸会信任（不主动逃离）玩家。但由于幼年狐狸也会像其他幼年动物一样紧随周围的成年个体，信任玩家的幼年狐狸仍有可能会因周围成年狐狸的逃跑而随之远离玩家。

信任玩家的狐狸仍然会逃离野生的狼、<ref></ref>和北极熊，驯服的狼可以但不主动攻击信任玩家的狐狸。当狐狸信任的玩家被狼或北极熊攻击时会反击该目标而不是逃离。

自然生成的狐狸不会信任玩家。然而狐狸会主动靠近16格内手持[甜浆果](甜浆果.md)或[发光浆果](发光浆果.md)的玩家，但会在玩家移动或者转动视角幅度过大时逃窜，类似于[豹猫](豹猫.md)。

# = 攻击 =
[350px|thumb|中狐狸攻击一只[[鸡](File:Fox jump.gif.md)时的动作]]
狐狸会主动攻击[鸡](鸡.md)、[兔子](兔子.md)、[鳕鱼](鳕鱼.md)、[鲑鱼](鲑鱼.md)、[热带鱼](热带鱼.md)和陆地上的幼年[海龟](海龟.md)。繁殖出的狐狸不会主动攻击这些生物，直到它被重新加载后才会主动攻击这些生物。<ref></ref>已信任玩家的狐狸永远不会主动攻击这些生物。

攻击时，狐狸会直接跑向目标并攻击，或是扑向目标。扑向目标前，狐狸会进行蹲伏，把头和身体贴近地面，然后跳跃2-5格的高度（不受效果影响），扑向目标并攻击。狐狸可以由此跳过[栅栏](栅栏.md)和[墙](墙.md)，并攻击至多四格高处的目标。狐狸跳跃前会左右扭动，且跳跃到半空时狐狸的脚会挥舞。狐狸的跳跃动作类似于海豚跳出水面。

红色狐狸会优先攻击在陆地上的鸡、兔子和幼年海龟；而白色狐狸会优先攻击鱼，而不是陆地生物。

扑向雪层的狐狸会暂时“陷进”雪层中，面朝下并发出粒子效果，不久后恢复正常。

即使被拴在[拴绳](拴绳.md)上，狐狸也会尝试奔向最近的可攻击生物。

狐狸可以透过[方块](方块.md)定位目标。

信任玩家的狐狸会攻击25格内伤害到其信任玩家的生物。狐狸会攻击除[山羊](山羊.md)外的任何生物；狐狸仅在玩家受到以下的其中一种伤害时攻击伤害来源：<ref></ref><ref></ref>
* [铁傀儡](铁傀儡.md)、[狼](狼.md)、[蜜蜂](蜜蜂.md)、[北极熊](北极熊.md)、[疣猪兽](疣猪兽.md)、[僵尸疣猪兽](僵尸疣猪兽.md)以外生物的[近战攻击](近战攻击.md)伤害
* [箭](箭.md)、[小火球](小火球.md)和[风弹](风弹（实体）.md)的弹射物伤害

狐狸不会因为试图攻击[幻翼](幻翼.md)而跳跃。

# = 睡觉 =
在白天，如果不是[雷暴](雷暴.md)天气，狐狸会尝试寻找一个天空光照等级≤14且光照等级≥12的位置睡觉，即狐狸不会在缺乏光照的黑暗环境或阳光直射的位置睡觉。如果附近12格内存在满足以下所有条件的生物，狐狸就不会睡觉：
* 不是其他狐狸
* 不受狐狸信任
* 不是[创造模式](创造模式.md)或[旁观模式](旁观模式.md)玩家
* 不在[潜行](潜行.md)状态
*

这些实体不需要被狐狸直接看到也能阻止狐狸睡觉。

狐狸在睡觉时头部会缓缓起伏。狐狸，但不会在睡觉时吃下捡起的物品。

狐狸被拴绳拴住也能够睡觉。

如果狐狸睡觉的条件不符合要求，狐狸会立即醒来。

# = 坐下 =
狐狸偶尔会在不睡觉的时候随机地坐下，最多会坐下。狐狸坐在[船](船.md)上或被[拴绳](拴绳.md)拴住时仍能够坐下。

# = 叼起物品 =
如果狐狸附近的地面上有[物品](物品（实体）.md)，狐狸就会将其捡起来并叼在嘴里。尽管狐狸可以捡起[玩家](玩家.md)能够捡起的任何物品，但狐狸更倾向于捡起食物类的物品（不包含[蛋糕](蛋糕.md)<ref></ref>），其次是未染色的[收纳袋](收纳袋.md)。若已拾起的物品不是食物，并且附近存在食物类物品时，狐狸会吐出原物品，叼起食物。

如果狐狸捡起的物品是食物，则会在后产生食物粒子形成吃食物的视觉效果，再经过后吃掉食物。吃掉食物所产生的其他作用（如[中毒](中毒.md)或传送）会在狐狸身上正常生效。狐狸吃掉装在容器内的食物（如[蘑菇煲](蘑菇煲.md)、[谜之炖菜](谜之炖菜.md)和[蜂蜜瓶](蜂蜜瓶.md)）后会把空容器留在嘴里。

如果以狐狸为半径16个方块范围内有生长阶段为3或4级的[甜浆果丛](甜浆果丛.md)，狐狸会扔掉嘴里的物品并采摘和吃掉其上的甜浆果。狐狸也会从长出果实的[洞穴藤蔓](洞穴藤蔓.md)上采下[发光浆果](发光浆果.md)并吃掉。

狐狸捡起附魔武器或物品并攻击时，武器的增伤值和魔咒会正常发挥作用，捡起[斧](斧.md)能正常停用目标的[盾牌](盾牌.md)，捡起[重锤](重锤.md)在扑向目标时能正常触发[猛击](重锤#下落攻击.md)，但物品的耐久度不会减少。如果狐狸叼着[不死图腾](不死图腾.md)时遭遇致命伤害，不死图腾也能够为狐狸施加相关效果并消失。

# = 村庄 =
狐狸有时会在夜间前往[村庄](村庄.md)。白色狐狸只会前往雪地村庄，而红色狐狸会前往除开雪地以外的村庄。

# = 繁殖 =

给一对狐狸喂食[甜浆果](甜浆果.md)或[发光浆果](发光浆果.md)可以使之[繁殖](繁殖.md)，生出一只幼年狐狸，并掉落。繁殖或后才能再次繁殖。

红色狐狸和白色狐狸繁殖，产生一只白色或红色幼年狐狸的概率各占50%。

繁殖出的幼年狐狸会信任玩家，且不会主动逃离玩家，信任关系在幼年狐狸成年后也会保持下去。不过，由于幼年狐狸仍会跟随附近的成年狐狸，成年狐狸逃离玩家后，幼年狐狸也会跟着逃跑。

可以给幼年狐狸喂食甜浆果或发光浆果加速其成长。

对幼年狐狸[金蒲公英](金蒲公英.md)可以阻止其成长为成年狐狸，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年狐狸无法被喂食除金蒲公英外的其他物品。

# = 天敌 =
未驯服的[狼](狼.md)会主动攻击或格内的狐狸。

成年[北极熊](北极熊.md)会主动攻击16格内的狐狸。

# 你知道吗
[thumb|right|损坏的狐狸模型](File:Foxerror.jpg.md)
* 在狐狸加入游戏之前，一个模型错误导致狐狸看起来像个盒状物体。<ref></ref>
* 尽管狐狸看起来是用嘴叼着物品，实际上它们是用[主手](主手.md)拿着物品。这意味着可以使用或来改变狐狸嘴里叼着的物品。
* 在现实世界中，一些种类的狐狸出其不意地跳得很高以捕捉它们的猎物，这一行为也反映在Minecraft的狐狸上。
* * 狐狸跳起后陷入雪中的行为参考于现实。现实中的赤狐和北极狐会为了猎捕雪层下的猎物（如旅鼠或老鼠之类的啮齿动物）而刻意高跳，利用重力使头部埋入雪层中完成狩猎。<ref>https://youtu.be/D2SoGHFM18I</ref>
* [闪烁标语](闪烁标语.md)“In case it isn't obvious, foxes aren't players”（“以防有人不明白，狐狸不是玩家”）是由于而添加的。
* 游戏中狐狸的音效是由现实中猫和狗的声音混合制成的，而非使用真狐狸的声音。<ref></ref>
* 游戏中红色狐狸的原型基于现实中的赤狐，而白色狐狸则是基于现实中的北极狐，在现实中，这是两种分类完全不同的物种。
