# 石砖

*页面ID: 6022* | *来源: Minecraft Wiki*

* *石砖（Stone Bricks）**是一种由[石头](石头.md)制作的装饰性方块。

# 生成
# = 自然生成 =
石砖会生成在[要塞](要塞.md)、[雪屋](雪屋.md)地下室，[海底废墟](海底废墟.md)、[雪原](雪原.md)村庄、[主世界](主世界.md)的部分[废弃传送门](废弃传送门.md)、[古迹废墟](古迹废墟.md)中，以及[试炼密室](试炼密室.md)中生成[蠹虫](蠹虫.md)的[试炼刷怪笼](试炼刷怪笼.md)旁。

# = 虫蚀石砖 =
被具有[精准采集](精准采集.md)的工具挖掘破坏时，[虫蚀石砖](虫蚀石砖.md)被破坏后会掉落石砖，不会生成蠹虫。

# 破坏
挖掘石砖的合适工具是镐。石砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

石砖被破坏后会掉落自身。

# 你知道吗
* 当烧炼[圆石](圆石.md)来修复[石头](石头.md)的裂纹时，裂开的石头会变成平滑的。但当[烧炼](烧炼.md)没有裂缝的普通石砖时，它们会变成[裂纹石砖](裂纹石砖.md)。这可能参考了2个不同的过程：当[岩石](wzh:岩石.md)受热膨胀时，会导致[裂纹](wikipedia:Fracture (geology).md)的产生，而这会让石砖裂开；而另一种只是简单地烧炼圆石，因此它变回[火成岩](wzh:岩浆岩.md)。
