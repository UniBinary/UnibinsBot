# 携带版0.12.1.b1

*页面ID: 28456* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.12.1 alpha build 1**是[v0.12.1 alpha](携带版0.12.1.md)的首个测试版，发布于2015年7月29日<ref>https://plus.google.com/105412738026646967654/posts/L5PZTjngyf8</ref>，加入了[下界](下界.md)、[酿造](酿造.md)、[附魔](附魔.md)、[饥饿值](饥饿值.md)、[天气](天气.md)等许多新内容。

# 新内容
# = 方块 =
* *[铁砧](铁砧.md)**
* 所有3种受损形式。
* 将[熔炉](熔炉.md)和[酿造台](酿造台.md)重命名后，这些方块在GUI中不显示自定义名称。

* *[酿造台](酿造台.md)**
* 在GUI中不显示自定义名称。

* *[生物头颅](生物头颅.md)**
* 使用了Java版快照[14w30a](14w30a.md)前的物品纹理。
* 不能创造[凋灵](凋灵.md)。
* 不能佩戴。

* *[花盆](花盆.md)**
* 可以将花、仙人掌和枯萎的灌木放进花盆里作为装饰。

* *[灵魂沙](灵魂沙.md)**
* 自然生成于下界。

* *[下界砖栅栏](下界砖栅栏.md)**
* 通过使用[下界砖](下界砖.md)合成。

* *[下界砖台阶](下界砖台阶.md)**
* 通过使用[下界砖](下界砖.md)合成。

* *[下界石英矿石](下界石英矿石.md)**
* 自然生成于下界。

# = 物品 =
* *[玻璃瓶](玻璃瓶.md)**
* 通过使用玻璃合成。
* 可以装水，变成水瓶。

* *[药水](药水.md)**
* 加入了所有类型的药水。

* *[喷溅药水](喷溅药水.md)**
* 加入了所有类型的状态效果。

* *[金胡萝卜](金胡萝卜.md)**
* 用于酿造夜视药水。

* *[下界疣](下界疣.md)**
* 用于酿造粗制药水。

* *[闪烁的西瓜片](闪烁的西瓜片.md)**
* 用于酿造治疗药水。

* *[金苹果](金苹果.md)**
* 通过使用金锭和苹果合成。
* 自然生成于战利品箱子里。
* 食用后获得正面[状态效果](状态效果.md)。

* *[附魔金苹果](附魔金苹果.md)**
* 自然生成于战利品箱子里。
* 食用后获得正面[状态效果](状态效果.md)。

* *[兔子脚](兔子脚.md)**
* 仅在创造模式下可用。
* 用于酿造跳跃药水。

* *[烈焰棒](烈焰棒.md)**
* 由[烈焰人](烈焰人.md)掉落。
* 可以作为燃料烧炼12个物品。

* *[烈焰粉](烈焰粉.md)**
* 通过使用[烈焰棒](烈焰棒.md)合成。
* 用于酿造力量药水。

* *[恶魂之泪](恶魂之泪.md)**
* 由[恶魂](恶魂.md)掉落。
* 用于酿造再生药水。

* *[蜘蛛眼](蜘蛛眼.md)**
* 由[蜘蛛](蜘蛛.md)掉落。
* 用于酿造剧毒药水。

* *[发酵蛛眼](发酵蛛眼.md)**
* 通过使用蜘蛛眼合成。
* 用于酿造隐身、伤害、迟缓和虚弱药水。

* *[毒马铃薯](毒马铃薯.md)**
* 收割成熟的马铃薯后有概率掉落。

# = 生物 =
* *[铁傀儡](铁傀儡.md)**
* 自然生成于村庄。
* 可以通过建造生成。

* *[雪傀儡](雪傀儡.md)**
* 可以通过建造生成。

* *[豹猫](豹猫.md)**
* 自然生成于[丛林](丛林.md)里。
* 可使用生鱼驯服。

* *[僵尸村民](僵尸村民.md)**
* 村民被僵尸感染后仍然保留它们的所属的衣服和职业。
* 加入了幼年僵尸村民。

* *[烈焰人](烈焰人.md)**
* 自然生成于下界要塞里。
* 死后有概率掉落[烈焰棒](烈焰棒.md)。

* *[凋灵骷髅](凋灵骷髅.md)**
* 自然生成于下界要塞里。

* *[闪电苦力怕](闪电苦力怕.md)**
* 雷暴时闪电击中苦力怕生成。

# = 世界生成 =
* *[下界](下界.md)**
* 和Java版一样，是无限大小的。

* *[下界传送门](下界传送门.md)**
* 用于进入或离开下界。
* 最大尺寸23×23格。
* 原来通过[下界反应器](下界反应器.md)可以获得的所有物品现在都能通过各自正常途径获取了。

* *[下界要塞](下界要塞.md)**
* 自然生成于下界。

# = 游戏内容 =
* *[粒子](粒子.md)**
* <code>angryVillager</code>
* <code>largeexplode</code>
* <code>hugeexplode</code>
* <code>blockdust</code>
* <code>slime</code>
* <code>enchantementtable</code>
* <code>droplet</code>
* <code>snowshovel</code>

* *[饥饿](饥饿.md)**
* 进食不再直接回复[生命](生命.md)值。

* *[天气](天气.md)**
* 加入了下雨、下雪和雷暴天气。

* *[疾跑](疾跑.md)**
* 通过双击方向键激活。

* *[酿造](酿造.md)**
* 加入了完整的酿造系统。

* *[难度](难度.md)**
* 包括和平、简单、普通、困难。

* *[物品修复](物品修复.md)**
* 使用[铁砧](铁砧.md)进行。

* *动画**
* 加入了切换快捷栏中的物品时的动画。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* “So fresh, so clean!”

* *[控制](控制.md)**
* 支持手柄和键盘。
* * 可在选项中更改控制。
* 在携带版和Windows 10版中最多五个玩家的跨平台游戏。
* 加入了新的交互按钮“喂养”。
* * 在繁殖动物时使用。

* *[设置](设置.md)**
* 加入了禁用自动跳跃的选项。
* 交换潜行和跳跃按钮的选项。
* 跳跃按钮被移到屏幕右侧。
* 在原跳跃按钮的位置加入了潜行按钮，并变成默认设置。
* 加入了视角模式滑条的选项（第一人称，第三人称，第三人称正面）。

# 更改
# = 常规 =
* 更改游戏的标志
* 图像
* * 更改了水的颜色，处于远处的水看起来会呈现出深蓝色。
* 移动生存模式下暂停键和聊天键的位置
* 在覆雪针叶林中，树叶会结霜
* 滚动条
* * 一直可见
* * 有了新的纹理
* 玩家可以在熔岩中游泳
* 音效
* * 当玩家爬梯子时，会发出新的声效。
* * 水和熔岩会发出新的音效。

# = 生物 =
* 燃烧的生物在灭掉身上的火时会发出“嘶嘶”的声响。
* 生物死后会掉落[经验](经验.md)。
* [僵尸](僵尸.md)
* * 僵尸可以穿上盔甲或拿起物品。
* * 僵尸很少掉落盔甲或武器。
* [骷髅](骷髅.md)
* * 骷髅可以穿上盔甲或拿起物品。
* * 提高射箭的精准度。
* * 骷髅很少掉落其盔甲或武器。
* * 在下界生成的骷髅有很大概率为凋灵骷髅。
* [史莱姆](史莱姆.md)
* * 现在有跳跃时的粒子。
* * 现在掉落[黏液球](黏液球.md)。
* [岩浆怪](岩浆怪.md)
* * 岩浆怪和恶魂会在下界正常地生成。
* * 岩浆怪死后会分裂。
* [僵尸猪人](僵尸猪人.md)
* * 僵尸猪人成为了条件敌对生物。
* * 僵尸猪人会在下界生成。
* [村民](村民.md)
* * 现在能与门交互。
* * 现在能收获农作物。
* * 现在可以繁殖。
* * 被玩家攻击时，头上会出现愤怒粒子效果。

# = 方块和物品 =
* 为[船](船.md)的物品纹理新设计了一种图标。
* * 现在包含了桨。
* * 不同类型的船有各自的颜色。
* 移除了[下界反应核](下界反应核.md)的功能和合成配方。
* [食物](食物.md)
* * 现在回复的是[饥饿值](饥饿值.md)而不是[生命值](生命值.md)。
* [雪](雪.md)
* * 雪通常在降雪形成多层。
* * 雪受重力影响。
* [浮冰](浮冰.md)
* * 新的纹理：[32px](File:Packed Ice JE1 BE2.png.md)
* [枯萎的灌木](枯萎的灌木.md)
* * 不用[剪刀](剪刀.md)破坏时会掉落0-2个[木棍](木棍.md)。
