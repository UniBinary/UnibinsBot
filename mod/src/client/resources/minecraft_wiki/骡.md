* *骡（Mule）**是一种被驯服后可以骑乘并驮货物的[生物](生物.md)。

# 生成
骡只能通过使[马](马.md)和[驴](驴.md)杂交获得。不对着骡使用的刷怪蛋生成的骡总是成年骡<ref></ref>；而使用刷怪蛋有20%概率生成幼年骡。

# 外观
骡是驴和马杂交产生的后代，而且体型更接近马。它们的耳朵、皮肤和鬃毛与驴相似，但骡的皮肤稍显暗淡且呈红棕色。

# 掉落物
在被杀死后，成年骡会掉落：

}}
* ，若[玩家](玩家.md)或驯服的[狼](狼.md)杀死。
* 已装备的[鞍](鞍.md)或者[箱子](箱子.md)及其内容物。

幼年骡被杀死后不会掉落任何掉落物。

# 行为
骡会漫无目的地四处游荡、时而嘶叫、摇尾巴以及低头吃草。与[绵羊](绵羊.md)不同，骡在吃草时不会破坏[草方块](草方块.md)的草皮。如果玩家靠近，骡有时会转身看着玩家。所有的骡（包括未被驯服的），都可以被拴绳拴住而不反抗。但如果玩家试图骑上一头未驯服的成年骡且驯服失败时，则骡会直立起来，甩下玩家，踢动前蹄以示反抗。与其他大多数生物类似，骡可以坐在[矿车](矿车.md)里，幼年骡还可以坐在[船](船.md)上，不过成年后会脱离船。

骡会发出嘶鸣声，比马的嘶鸣声更加尖锐。

与大多数生物不同的是，骡可以缓慢地恢复损失的生命值。

幼年骡不会跟随双亲，只会跟随成年骡。

幼年骡需要20分钟成长为成年个体。

对幼年骡[金蒲公英](金蒲公英.md)可以阻止其成长为成年骡，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年骡无法被喂食除金蒲公英外的其他物品。

# = 驯服 =
成年的骡可以被驯服。

对着未驯服的骡按下键可骑上骡。玩家需空手对骡按键，否则骡会拒绝搭载玩家，立刻前腿腾空并嘶叫；玩家可手持着物品按键，但骡也会拒绝手持鞍和[马铠](马铠.md)的玩家。

即使玩家骑上骡，骡也有很大概率把玩家甩下、前腿腾空并嘶叫。当骡不再试图甩下玩家并产生红心粒子时则驯服成功。

驯服成功率取决于值（好感度）。骡的初始好感度为0（最高值为100）。当玩家骑上骡时，会从0-99中随机取一个数字，如果骡的好感度高于该数字，则骡会被驯服，否则将玩家甩下来，并增加5点好感度。好感度也可以通过给骡喂食来增加，详见[下文](#喂食.md)。

即使好感度达到上限，也能正常喂食未驯服的骡（[干草捆](干草捆.md)除外）。

与其他可驯服生物一样，驯服的骡死亡时会给世界中的所有玩家显示一条[死亡消息](死亡消息.md)，而不会<ref></ref>。

# = 装备 =
骡被驯服后，玩家可以通过骑着骡打开物品栏来打开骡的物品栏，或者在时对着骡按键来打开。

驯服的骡有以下槽位可用：
* 鞍槽，用于装备[鞍](鞍.md)。
* * 鞍槽中的鞍可被玩家使用[剪刀](剪刀.md)移除。
* 15格空的物品栏，手持箱子对骡按键后出现。

骡不能装备[马铠](马铠.md)。

骡身上的箱子不可卸下，除非骡死亡。

# = 骑乘 =

骑乘装备了鞍的骡时能用方向键和键等来控制它。玩家可以通过按键来下骡。玩家可以在骑骡时使用物品、与方块或其他生物交互。玩家无法在骑骡时使用[下界传送门](下界传送门.md)。

玩家骑骡时会显示骡的生命条，其纹理与玩家的生命条不同。玩家的饥饿条被骡的生命条代替，经验条也会被骡的跳跃蓄力条代替；玩家的饥饿条和经验条会正常显示，只有在蓄力时，经验条才会被跳跃蓄力条取代，且上方经验等级的数值不会消失。

骑骡可以直接走上1格高的地方而无需跳跃。骡的速度会受到和效果影响，跳跃高度受到效果影响。[信标](信标.md)的增益效果不会施加给骡。与马不同，无状态效果的骡都有相同的速度和跳跃能力。骡的速度通常比马要慢，但仍然可以通过长按键来蓄力。

如果在骡移动或跳跃时玩家的-{}-头部进入固体方块，则玩家仍会受到窒息伤害。骡最低能通过1.625格高的空间，但低于2.75格高的空间会使玩家受到窒息伤害，低于1.75格高的空间会使骡也受到窒息伤害。骡不能通过1格宽的缝隙。

# = 喂食 =
对骡有效的食物可以喂骡。

给生命值未满的骡喂食可以使其恢复生命值。幼年骡无法通过喂食来恢复生命值。

无法喂食生命值已满且驯服的骡。

给幼年骡喂食可以缩短其成长时间。

下表列出了各种食物对骡的影响。

骡会跟随/内手持金苹果、附魔金苹果或金胡萝卜的玩家。

骡无法繁殖。

# 统计

所有的骡都有3种“马匹统计”，每匹骡都有所不同：生命值、（最大）移动速度和跳跃力量。这些数据是在骡出生或生成后固定的，喂食对其没有影响。然而，所有的骡的速度和跳跃力量固定不变。

# = 生成值 =
因为骡不会自然生成，所以骡没有自己的生成值。

# = 生命值 =

骡的生命值范围在到之间，但趋于均值。生命值为奇数的骡不会在生命条中显示出最后半颗心。

# = 移动速度 =
在没有[状态效果](状态效果.md)影响的情况下，骡的移动速度固定为0.175（7.525格/秒）。相比之下，玩家的正常行走速度为0.1（4.3格/秒），冲刺速度为5.6格/秒。

另见[运输](运输#方式.md)来比较多种运输方式的速度。

# = 跳跃力量 =
骡的跳跃力量固定为0.5，可以跳过格。

# 你知道吗
* “骡（mule）”特指公驴（jack）和母马（mare）的后代。母驴（jenny）和公马（stallion）的后代被称为“（hinny）”。然而，由于骡比更常见，“mule”可以通俗地指代任何马和驴的杂交物种。
* 在现实中，由于马和驴存在生殖隔离，二者交配后产生的骡也无法正常生育后代。
