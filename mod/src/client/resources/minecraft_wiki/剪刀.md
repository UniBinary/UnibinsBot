# 剪刀

*页面ID: 6393* | *来源: Minecraft Wiki*

* *剪刀（Shears）**是主要用来修剪[羊毛](羊毛.md)和开采一些方块的工具。

# 用途
# = 与生物交互 =
对有毛的[绵羊](绵羊.md)剪刀会使其掉落1-3个对应颜色的[羊毛](羊毛.md)，并使它失去毛。

对[哞菇](哞菇.md)剪刀会使其掉落5个对应种类的蘑菇，并使它变成[牛](牛.md)。

对[沼骸](沼骸.md)剪刀会使其掉落2个任意种类的[蘑菇](蘑菇.md)。

对戴着[雕刻南瓜](雕刻南瓜.md)的[雪傀儡](雪傀儡.md)剪刀会使其掉落1个雕刻南瓜，并使它失去穿戴着的雕刻南瓜。

对[拴绳结](拴绳结.md)或被拴绳拴住的生物或实体剪刀会使所有连接到它的拴绳断开连接。

对头上戴有[虞美人](虞美人.md)的[铜傀儡](铜傀儡.md)剪刀会使其掉落1个虞美人，并使它失去头上的虞美人。

# == 卸下装备 ==
对穿着装备的生物剪刀可以卸下其装备，如果生物正在被骑乘则不可通过这种方式卸下装备。这些情况包括：
* [狼](狼.md)的[狼铠](狼铠.md)
* [马](马.md)的[马铠](马铠.md)
* [马](马.md)、[骡](骡.md)、[驴](驴.md)、[骆驼](骆驼.md)、[骆驼尸壳](骆驼尸壳.md)、、[僵尸马](僵尸马.md)、[猪](猪.md)、[炽足兽](炽足兽.md)、[鹦鹉螺](鹦鹉螺.md)或[僵尸鹦鹉螺](僵尸鹦鹉螺.md)的[鞍](鞍.md)
* [羊驼](羊驼.md)和[行商羊驼](行商羊驼.md)的[地毯](地毯.md)
* [快乐恶魂](快乐恶魂.md)的[挽具](挽具.md)
* [鹦鹉螺](鹦鹉螺.md)和[僵尸鹦鹉螺](僵尸鹦鹉螺.md)的[鹦鹉螺铠](鹦鹉螺铠.md)

如果生物具有多个装备，则每次只会卸下一个装备。对于马而言，先卸下马铠再卸下鞍；对于鹦鹉螺和僵尸鹦鹉螺而言，先卸下鹦鹉螺铠再卸下鞍。

# = 与方块交互 =
对[南瓜](南瓜.md)剪刀会使其掉落或[南瓜种子](南瓜种子.md)，并使它变为雕刻南瓜。

对方块状态<code>honey_level</code>为<code>5</code>的[蜂巢](蜂巢（方块）.md)或[蜂箱](蜂箱.md)剪刀会使其掉落3个[蜜脾](蜜脾.md)，并将方块状态<code>honey_level</code>设置为<code>0</code>。

对[洞穴藤蔓](洞穴藤蔓.md)、[垂泪藤](垂泪藤.md)、[缠怨藤](缠怨藤.md)和[海带](海带.md)的尖端剪刀可以使它们停止生长。

# = 挖掘工具 =

剪刀是一种挖掘工具，每次成功挖掘了任何[火](火.md)以外的方块会消耗1耐久度。
