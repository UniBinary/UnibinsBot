# Java版14w32c

*页面ID: 32434* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w32c**是[Java版1.8](Java版1.8.md)的第44个快照，发布于2014年8月8日<ref></ref>，修复了一些[14w32a](14w32a.md)和[14w32b](14w32b.md)的漏洞和崩溃问题。

# 更改
# = 方块 =
* *[黏液块](黏液块.md)**
* 更改了放置和破坏的音效。
* * 使用了[史莱姆](史莱姆.md)的受伤音效。

# = 非生物实体 =
* *[盔甲架](盔甲架.md)**
* 加入了<code>NoBasePlate</code>标签——决定底座是否显示。

# 修复
命令对盔甲架设置姿势标签后，如果不重新登录，则不生效。
