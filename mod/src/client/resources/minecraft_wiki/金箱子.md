* *金箱子（Golden Chest）**是会将其中物品转变为金色物品的[箱子](箱子.md)变种。

# 生成

# 获取
金箱子只能通过命令放置。

# = 合成 =

# = 转化 =

玩家[箱子](箱子.md)或[陷阱箱](陷阱箱.md)时会将其变为金箱子。

# 破坏
挖掘金箱子的合适工具是斧。

金箱子被破坏后会掉落自身和内容物。

# 用途

# = 转化 =
金箱子（不包括大型金箱子）在[界面](界面.md)打开时，每[刻](刻.md)有5%的概率随机抽取箱内一个槽位，若非空槽位则将槽位内的物品按以下对应关系转变为金色物品，不论规则是否开启。

上表中不存在的方块会直接转变为金块，不存在的物品转变为金锭。
