# 樱花披风

*页面ID: 186295* | *来源: Minecraft Wiki*

* *樱花披风（Cherry Blossom Cape或Cherry Cape）**是发放给参加[Minecraft Live 2023](Minecraft Live 2023.md)生物投票的玩家的披风。

# 描述
其发放条件是在[Minecraft网站](Minecraft网站.md)或[Minecraft启动器](Minecraft启动器.md)参加[Minecraft Live 2023](Minecraft Live 2023.md)的生物投票。

玩家在进入[2023年生物投票服务器活动](2023年生物投票服务器活动.md)时立刻获得该披风。<ref>https://imgur.com/o3Bdmyt</ref>

出于未知原因，部分在基岩版中获得了樱花披风的玩家没有在Java版获得此披风，相同IP地址可获得披风的玩家数量也可能存在限制。<ref></ref><ref></ref><ref></ref>

Minecraft帮助中心客服称该披风发放给在任何平台上参与[Minecraft Live 2023](Minecraft Live 2023.md)的生物投票的玩家<ref>[:File:Minecraft Help Re Cherry Blossom Questions.png](:File:Minecraft Help Re Cherry Blossom Questions.png.md)</ref>，尽管这并不符合基岩版的樱花披风的实际发放条件。
