# 更改
# = 方块 =
* *[玩家的头](玩家的头.md)**
* 不再只显示一层。

# = 生物 =
* *[铁傀儡](铁傀儡.md)**
* 现在仅在被玩家杀死时掉落铁锭，这可以通过战斗，[药水](药水.md)，或玩家触发的机关（如手动激活的[TNT](TNT.md)）来达成。
* 不受玩家干涉下死亡，则只会掉落虞美人。

* *[村民](村民.md)**
* 被闪电击中的村民将会变成[女巫](女巫.md)。
* 牧师村民不再购买末影珍珠。

* *[僵尸猪人](僵尸猪人.md)**
* 现在仅在被玩家杀死时掉落[金粒](金粒.md)和稀有掉落物，这可以通过战斗，药水，或玩家触发的机关（如手动激活的TNT）来达成。
* 不受玩家干涉下死亡，则只会掉落[腐肉](腐肉.md)。

# = 世界生成 =
* *[沙漠神殿](沙漠神殿.md)**
* 现在会生成染色[陶瓦](陶瓦.md)而不是[羊毛](羊毛.md)。

* *[村庄](村庄.md)**
* 现在会在沙砾路下生成圆石。

# = 命令格式 =
* ***
* 加入了旋转参数。
* * 例子：传送后会将玩家的脸部/视角向右旋转20度并向下旋转40度。

* *目标选择器**
* 现在支持立方区域。
* * 例子：<code>@e[x=0,y=0,z=0,dx=10,dy=10,dz=10]</code>将选择在0,0,0至10,10,10之间的所有实体。
* 半径数值现在是根据方块的中心点扩散的。
* * 半径为0将检测精准的方块位置。

# = 游戏内容 =
* *物品标签**
* 现在会显示用于命令中的内部名称（模式）。

# = 常规 =
* *方块ID**
* 在命令中的NBT数据现在可以使用方块/物品名来代替数字ID了。
* 旧的ID仍可使用，但在被慢慢地淘汰。
* 其他需要方块/物品ID的命令将需要名字ID。
* 常规的ID在命令中不再运作，现在必须是。

* *调试按钮**
*  + ：清除聊天记录（包括之前的使用命令）。

* *[皮肤](皮肤.md)**
* 现使用不同布局和规格的文件。
* * 文件的规格增加至64×64。
* 左右边手脚纹理现在可以被分开编辑。
* 帽子层被延伸至全身，可以设为透明。
* * 手臂，腿部，头部，和身体的覆盖层分别被称为袖子，裤腿，帽子，和外套。
* 对旧的皮肤反向兼容。
* * 旧的皮肤仍可使用，但不会有新功能。
* * 在14w02a之前的版本使用新皮肤会和旧皮肤一样。
* 在选项菜单内新增“自定义皮肤”按钮。
* * 披风的可见度现在在此处切换。
* * 也可以切换覆盖层的可视度，每个身体部位都可分别切换。
