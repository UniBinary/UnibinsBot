# 携带版0.15.0

*页面ID: 20482* | *来源: Minecraft Wiki*

</ref>}}

* *v0.15.0 alpha**是**[友好更新](友好更新.md)**<ref>http://www.mojang.com/2016/06/whats-in-015-the-friendly-update-for-pocket-win-10/</ref>的首个正式版，也是的一次主要更新，在Android上发布于2016年6月10日，在iOS、FireOS、Windows Phone、Windows 10和Gear VR上发布于6月13日。此版本加入了如[活塞](活塞.md)、[马](马.md)、完整的[Realms](Realms.md)、[命名牌](命名牌.md)、[成就](成就.md)、[丛林神庙](丛林神庙.md)、[胡萝卜钓竿](胡萝卜钓竿.md)以及其他一些新特性，并修复了大量漏洞。

在此版本的开发进程中，携带版的[Realms](Realms.md)基本完成开发，但仍处于Beta测试阶段——这三个测试版是公开发布的。这些版本在非官方角度上也属于0.15.0开发的一部分，但它们尚未包含其他新特性。在此之后，常规的测试版被发布，完整的Realms支持也在正式版发布后加入。

# 新内容
# = 方块 =
* *[活塞](活塞.md)和[黏性活塞](黏性活塞.md)**
* 新的红石元件。
* 用于推动或拉动方块。
* 新的动画：[活塞头](活塞头.md)的下端明显更粗。
* 能够推动[方块实体](方块实体.md)，比如[箱子](箱子.md)。
* 能被放置在方块侧面的方块实体（比如[拉杆](拉杆.md)）能在活塞或黏性活塞上放置。

* *[侦测器](侦测器.md)**
* 新的红石元件。
* 用于检测[方块更新](Tutorial:方块更新感应器.md)。

# = 物品 =
* *[食物](食物.md)**
* [生羊肉](生羊肉.md)
* [熟羊肉](熟羊肉.md)

* *[刷怪蛋](刷怪蛋.md)**
* [马](马.md)
* [僵尸马](僵尸马.md)
* [骷髅马](骷髅马.md)
* [驴](驴.md)
* [骡](骡.md)
* [流浪者](流浪者.md)
* [尸壳](尸壳.md)
* [凋灵骷髅](凋灵骷髅.md)

* *[火焰弹](火焰弹.md)**
* 用于点燃火焰。

* *[命名牌](命名牌.md)**
* 用于为生物自定义名称。

* *[拴绳](拴绳.md)**
* 用于拴住生物。

* *[胡萝卜钓竿](胡萝卜钓竿.md)**
* 用于吸引和控制猪。

* *[药箭](药箭.md)**
* 用炼药锅取得。
* 击中生物会使其获得对应[状态效果](状态效果.md)。

* *[马铠](马铠.md)**
* 可以用[炼药锅](炼药锅.md)染色。
* 可以用[皮革](皮革.md)合成。
* 用于为[马](马.md)提供护甲值。

# = 生物 =
* *常规**
* 加入了当[动物](动物.md)被喂食时的动画。

* *[流浪者](流浪者.md)**
* 骷髅的寒冷变种。
* 自然生成于积雪的生物群系里。

* *[尸壳](尸壳.md)**
* 僵尸的干燥变种。
* 自然生成于沙漠生物群系里。

* *[马](马.md)**
* 新的可骑乘生物。
* 包含了[骷髅马](骷髅马.md)陷阱。

* *[骡](骡.md)**
* 通过马和驴繁殖生成。

* *[驴](驴.md)**
* 新的可骑乘生物。
* 可以为其装备箱子。

# = 世界生成 =
* *[村庄](村庄.md)**
* 加入了新的村庄。
* * 针叶林村庄，用[云杉木](原木.md)替代[橡木](原木.md)。
* * 热带草原村庄，用[金合欢木](原木.md)替代橡木。

* *[僵尸村庄](僵尸村庄.md)**
* 会自然生成僵尸村民。
* 村庄内没有光源和门。
* 建筑以[苔石](苔石.md)做地板。
* 屋子里会生成蜘蛛网。

* *[丛林神庙](丛林神庙.md)**
* 自然生成于丛林生物群系里。
* 包含了陷阱和宝藏箱。

# = 游戏内容 =
* *[成就](成就.md)**
* iOS和Android上的成就（需要登录到Xbox Live）。
* * 更多的成就（共56个）。

* *交互按钮**
* 骑乘猪时使用[胡萝卜钓竿](胡萝卜钓竿.md)加速。
* 使用[命名牌](命名牌.md)为[生物](生物.md)命名。
* 使用[拴绳](拴绳.md)。
* 使用[摄像机](摄像机.md)拍照。

* *骑猪**
* 在加速时有新音效。

# = 常规 =
* *[声音](声音.md)**
* 加入了在[方块](方块.md)上跳跃时的[音效](音效.md)。

* *标题画面**
* “皮肤”按钮。
* * 现在为主菜单上的图标。
* 新的“商店”按钮。
* * 用于购买[皮肤包](皮肤包.md)和[资源包](资源包.md)。

* *[资源包](附加包.md)**
* 一些资源包不完整。
* 在游戏和[设置](设置.md)菜单中，它们被称为资源包。
* 在游戏中，当从设置菜单中管理可用的资源包时，会有移动和选择它们的选项，就像在Java版中那样。
* 除此之外，在游戏文件夹中有一个叫做的文件夹用来储存资源包。

* *[多人游戏](多人游戏.md)**
* 现在可以和Xbox Live好友在线多人游戏。

* *UI**
* 与Windows 10版共享的新的主菜单UI。
* 新的皮肤界面UI，有与主机版相似的旋转预览栏。

# 更改
# = 方块 =
* *[活板门](活板门.md)**
* 不再需要支撑它的方块。

* *[画](画.md)**
* 现在被放置时和被破坏时有了音效。

* *[下界反应核](下界反应核.md)**
* 拥有不同的纹理，且仍不可获得。

* *[玫瑰丛](玫瑰丛.md)**
* 新的纹理。

* *[牡丹](牡丹.md)**
* 新的纹理。

* *[音符盒](音符盒.md)**
* 现在更响。

# = 物品 =
* *[剪刀](剪刀.md)**
* 在破坏任何方块时都会损失耐久值。

* *[地图](地图.md)**
* 带玩家标记的地图现在可用8张纸围绕1个指南针合成。使用旧的合成配方会合成没有标记的地图。

* *[蘑菇](蘑菇.md)**
* 红色蘑菇不再能烧炼成玫瑰红。

# = 生物 =
* *常规**
* 将[生物](生物.md)命名为Dinnerbone或Grumm会使它们上下颠倒。

* *[骷髅](骷髅.md)**
* 加入了射[箭](箭.md)和重新装填[弓](弓.md)时的动画。

* *[兔子](兔子.md)**
* 当被命名为Toast时会改变它们的皮肤。

* *[绵羊](绵羊.md)**
* 当被命名为<code>jeb_</code>时羊毛会一直变色，但不影响取得羊毛时的颜色。

* *[末影人](末影人.md)**
* 可非常罕见地在[下界](下界.md)生成。

* *[猪](猪.md)**
* 现在可以骑乘，通过对其使用[鞍](鞍.md)和胡萝卜钓竿进行。
* 新的加速音效。

# = 世界生成 =
* *[沙漠神殿](沙漠神殿.md)**
* 现在能够在[箱子](箱子.md)里找到[附魔书](附魔书.md)。

# = 常规 =
* *选项**
* 加入了新的滚动条。

* *[多人游戏](多人游戏.md)**
* 现在带宽占用更低。

* *[物品栏](物品栏.md)**
* 按钮现在变得更透明。

# 修复
[**修复了21个漏洞**](https://bugs.mojang.com/browse/MCPE/fixforversion/15397)
* 修复了大量游戏崩溃。
* 修复了使得存档损坏的漏洞。
* 修复了大量红石系统的漏洞。
* 修复了大量多人游戏下不同步的漏洞。
* 方块高亮显示时闪烁。
* 玻璃的纹理发绿。
* 地牢和沙漠神庙里的箱子生成错误。
* 远离刷怪笼时，刷怪笼里的生物模型会抽搐。
*  – 不能看见冰下的水。
*  – 被火把破坏的红沙会变成普通的沙子。
*  – 快捷栏内的仙人掌的纹理错误。
*  – 沙漠神庙里的箱子生成时朝向不正确。
*  – 音符盒发出的音量太小。
*  – 栅栏门开启时的朝向不正确。
*  – 飞行时，可以在半空中潜行。
*  – 沙漠神庙会跨越生物群系生成。
*  – 圆石墙会和朝向不匹配的栅栏门连接。
*  – 物品和实体不能掉进炼药锅里。
*  – 漏斗的纹理错误。
*  – 狼的愤怒状态下的纹理丢失。
*  – 下界疣方块在放置时呈“X”型而不是“#”型。
*  – 画不会和墙壁贴紧。
*  – 飞行时不能使用键转移物品。
*  – 熔岩在下界里渲染错误。
*  – 可以将火把、梯子和藤蔓放置在压力板或阳光探测器的侧面。
*  – 被耕地和草径切断的红石线不会正确对齐。
*  – 将栅栏或圆石墙/苔石墙放进物品展示框时隐形。
*  – 已染色的盔甲在没有打开物品栏时的快捷栏里不显示其颜色。
*  – 打开存档时游戏崩溃。
