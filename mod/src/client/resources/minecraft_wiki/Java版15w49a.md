# 更改
# = 方块 =
* *[信标](信标.md)**
* 在关闭界面时会掉落它所包含的物品。
* 不再从漏斗中接受物品。
* 移除了<code>PaymentItem</code>NBT标签。

* *[仙人掌](仙人掌.md)**
* 在与熔岩相邻时会自毁。
* 在沙子上的仙人掌会在水或熔岩在其上方时自毁。

* *[蜘蛛网](蜘蛛网.md)**
* 蜘蛛网现在会捕捉雪球、鸡蛋、掷出的药水、经验瓶、末影珍珠，并把它们变回到它们的物品形式。
* *[作物](作物.md)和[下界疣](下界疣.md)**
* 碰撞箱会随着其生长发生改变。

* *[门](门.md)**
* 放置时根据玩家点击的方块的半边决定门轴的方向，除非旁边的门使其按特定方式放置。

* *[火](火.md)**
* 在雨中熄灭的概率增加了20%（现在每个age阶段熄灭的概率为20% + age * 3%）。

* *[熔炉](熔炉.md)**
* 移除了<code>lit_furnace</code>（点燃的熔炉）的物品形式。

* *[睡莲](睡莲.md)**
* 修改碰撞箱，现其高度为格（原为格），并且从三条边向内缩小了格。

* *[西瓜](西瓜.md)**
* 西瓜和闪烁的西瓜片现在朝向同一个方向。

* *[活塞](活塞.md)**
* 没有伸出的活塞、面向下方的活塞和面向上方的活塞的活塞臂现被定义为固体顶面，与颠倒的[台阶](台阶.md)和[楼梯](楼梯.md)一样。
* * 这意味着生物可以在上面生成。

* *[动力铁轨](动力铁轨.md)和[激活铁轨](激活铁轨.md)**
* 动力铁轨和激活铁轨不再互相充能。

* *[绊线](绊线.md)和[绊线钩](绊线钩.md)**
* 去除了“悬浮的”和“不悬浮”的区别：以前，绊线只会在整条绊线及两边[绊线钩](绊线钩.md)都在固体方块上或都不在固体方块上时才能工作。

* *[陷阱箱](陷阱箱.md)**
* 在创造模式物品选栏中的位置从装饰类移动到了红石类。

# = 物品 =
* *[鞘翅](鞘翅.md)**
* 增加了撞击到墙上时的伤害。
* *[末地水晶](末地水晶.md)**
* 放置时要求在其放置的方块上面的两个方块为空气或是可替换方块。
* 不能再被放置到有其他实体的位置。

# = 生物 =
* *常规**
* 改进了寻路机制。
* 僵尸、僵尸猪人、史莱姆、岩浆怪、凋灵骷髅、蜘蛛、洞穴蜘蛛、蠹虫和末影螨在被其他生物攻击时会反击了。
* 击退效果不会改变飞行/掉落中的生物的Y向速度。

* *[末影龙](末影龙.md)**
* 不会被[下界传送门](下界传送门.md)或[末地传送门](末地传送门.md)传送了。
* 不能骑乘任何东西了。
* 不会获得药水效果了。

* *[末影人](末影人.md)**
* 不再能透过墙拾起方块了。

* *[马](马.md)**
* 现在会随着玩家一起旋转。

* *[潜影贝](潜影贝.md)**
* 不再飘浮在地面上。

* *[骷髅](骷髅.md)**
* 在装备头盔时不再会寻找阴影处躲藏了。

* *[雪傀儡](雪傀儡.md)**
* 对雪傀儡使用[剪刀](剪刀.md)会移除它头上的南瓜（会消耗剪刀1点耐久）且不会有南瓜掉落。

* *[凋灵](凋灵.md)**
* 不会被[下界传送门](下界传送门.md)或[末地传送门](末地传送门.md)传送了。

# = 非生物实体 =
* *[箭](箭.md)**
* 箭的运动会根据发射者的运动而改变。从地面的角度看，方向与发射者的运动方向一致的箭会飞得更快一些，方向相反则变慢，而方向垂直时箭的方向会向发射者的运动方向偏移。
* 被目标（如盾牌或是栖息的龙）弹开的箭如果能被回收，在被弹开后动力接近零时会变成物品形式。

* *[小火球](小火球.md)**
* 不再伤害（或激怒）对火免疫的实体了。

* *弹射物（[雪球](雪球.md)、[鸡蛋](鸡蛋.md)、[末影珍珠](末影珍珠.md)、[附魔之瓶](附魔之瓶.md)和扔出的[药水](药水.md)）**
* 不再与透明方块发生碰撞。
* * 即使是玻璃这种固体的透明方块。
* 会被蜘蛛网捕获并变回物品形式。
* 运动会受投掷者的运动所影响。

* *[闪电](天气.md)**
* 不再会破坏物品展示框、拴绳结、画和盔甲架。

# = 世界生成 =
* *[末地传送门](末地传送门.md)**
* 有0.0000000001%（）的概率所有12个末地传送门框架都伴随末影之眼生成，现在它会直接激活传送门。

# = 命令格式 =
* ***
* 现在能使用自动补全了。

* ***
* 现在拥有一个<code>player</code>参数来指定哪位玩家能看到粒子以及一个<code>params</code>参数来设定（<code>iconcrack_</code>等粒子的）粒子参数。

# = 游戏内容 =
* *[消耗度](消耗度.md)**
* 潜行的消耗量改为行走时的一半。

* *[冰霜行者](冰霜行者.md)魔咒**
* 现在只要玩家站在地面上就会起作用，不管地面是不是固体方块。
* 不再对盔甲架起效。

* *[战斗](Tutorial:战斗.md)**
* 横扫攻击对被击退的生物造成伤害。
* 无限魔咒不再对光灵箭和药水箭产生效果。

* *[状态效果](状态效果.md)**
* 生命提升的图标改成了多个红心。
* 伤害吸收的图标改成了一个有黄色外框的红心。
* 反胃效果在当使用牛奶或命令清除时会立即停止。

# = 常规 =
* *[声音事件](Java版声音事件.md)**
* 将<code>entity.arrow.successful_hit</code>声音事件重命名为<code>entity.arrow.hit_player</code>。
