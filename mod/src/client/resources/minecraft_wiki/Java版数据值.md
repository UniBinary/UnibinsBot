# Java版数据值

*页面ID: 36628* | *来源: Minecraft Wiki*

这些**数据值（Data Values）**决定了[Java版](Java版.md)内不同种类的方块和物品。它们在Minecraft中有很多用处。[方块ID](#方块.md)用于定义放置在世界的方块和其物品形式（包括物品栏、箱子里的和作为掉落物的）；[物品ID](#物品.md)只对物品有效；[实体ID](#实体.md)只对例如生物和弹射物的实体有效。[方块状态](#方块状态.md)则是进一步定义一个方块所需的附加数据值。

# 协议与数据版本

协议版本用于通过网络识别游戏的版本，通常来说只有兼容的版本可以互相连接。数据版本表示的是游戏保存世界的方式，借此可以将世界更新到最新的版本。
