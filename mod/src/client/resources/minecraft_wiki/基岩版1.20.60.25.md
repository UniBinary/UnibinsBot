# 基岩版1.20.60.25

*页面ID: 111348* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.60.25**（ChromeOS/Android）、**Preview 1.20.60.25**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.60](基岩版1.20.60.md)的第6个测试版，发布于2024年1月10日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[大型箱子](大型箱子.md)和[大型陷阱箱](大型陷阱箱.md)**
* 略微更改了纹理。

* *[凋灵玫瑰](凋灵玫瑰.md)**
* 现在会每0.5秒对生物造成一次伤害，而不是每2秒造成一次。

# = 物品 =
* *[谜之炖菜](谜之炖菜.md)**
* 现在玩家在满[饥饿](饥饿.md)值状态下也可以食用谜之炖菜。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 穿过[甜浆果丛](甜浆果丛.md)时不再会受到伤害。

* *[狼](狼.md)**
* 现在会生成于[雪林](雪林.md)。

* *[僵尸疣猪兽](僵尸疣猪兽.md)**
* 现在会在和平[难度](难度.md)下消失。

* *[雪傀儡](雪傀儡.md)**
* 现在会主动攻击僵尸疣猪兽。

# = 游戏内容 =
* *[含雪](含雪.md)**
* 现在自然生成的植物可以含雪。

# = 技术性 =
* *API**
* 将“值不受支持或超出范围。”错误更改为使用错误类型。

* *方块**
* 为数据驱动方块加入了毗邻完整且不透明的方块时移除几何体的面的功能。
* * 为方块几何结构组件加入了新的字段，该字段引用了为镶嵌几何体设置剔除规则的新的剔除文件（位于资源包的目录）。

* *维度API**
* 方法参数的持续时间现在使用错误类型。

* *[基岩版编辑器](基岩版编辑器.md)**
* 修复了刷新编辑器屏幕时子菜单项目会添加至根级的漏洞。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“”、“即将推出的创作者功能”、“测试版 API”和“”子选项后才可使用。

# = 方块 =
* *[试炼刷怪笼](试炼刷怪笼.md)**
* 现在检测到玩家时，若试炼刷怪笼生成生物的剩余时间少于2秒，则生成延时会被设置为2秒。

# = 生物 =
* *[旋风人](旋风人.md)**
* 现在会反射所有[弹射物](弹射物.md)。
* * 命中旋风人的弹射物会以40°度角向发射该弹射物的实体反射回去。
* 现在躯干部分的杆状物底部的像素与周围部分的颜色相匹配。

# 修复
* *方块**
* 现在无论旗帜是否已在世界中以方块形式放置过，颜色相同的旗帜物品都会一致地堆叠起来。（）
* 凋灵玫瑰现在会每0.5秒对生物造成一次伤害，而不是每2秒造成一次。（）
* 被复制的容器不再会保持打开其容器界面，也不再会导致崩溃。

* *大型箱子和大型陷阱箱**
* 修复了大型箱子和大型陷阱箱的箱盖部分会出现像素阴影的问题。（）

* *常规**
* “”成就现在只能通过收集龙息来解锁。（）

* *物品**
* 现在即使处于满饥饿值状态，玩家也可以食用谜之炖菜。（）

* *生物**
* 降低了钓鱼时产生的经验球的分散程度。（）
* 僵尸疣猪兽不再会在和平难度下生成，且会在难度切换至和平难度时消失。（）
* 经验球不再会与生物相碰撞。（）
* 甜浆果丛不再会对穿过其的蜜蜂造成伤害。（）
* 狼现在会在雪林生物群系中的雪块和雪层上生成。（）

* *性能与稳定性**
* 修复了加入Realm时可能会无限加载的问题。

* *世界生成**
* 现在深色橡树和金合欢树的可替换方块限制也会应用于树枝部分，而不只应用于树干部分。
* 现在世界生成时放置的雪层会覆盖在草丛和花上。（）</onlyinclude>
