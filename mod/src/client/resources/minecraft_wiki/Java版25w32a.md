# Java版25w32a

*页面ID: 161762* | *来源: Minecraft Wiki*

<onlyinclude>

* *25w32a**是[Java版1.21.9](Java版1.21.9.md)的第2个快照，发布于2025年8月5日<ref></ref>，加入了多种铜质方块，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[铜火把](铜火把.md)**
* [火把](火把.md)的变种。
* 由[铜粒](铜粒.md)、[煤炭](煤炭.md)和[木棍](木棍.md)合成。

* *[铜栏杆](铜栏杆.md)**
* [铁栏杆](铁栏杆.md)的铜质变种。
* 由6个[铜锭](铜锭.md)合成。
* 能够氧化、被涂蜡、脱蜡或除锈。

* *[铜链](铜链.md)**
* 铁链的铜质变种。
* 由2个铜粒和1个铜锭合成。
* 能够氧化、被涂蜡、除蜡或除锈。
* 与铁链一样，可用于合成[悬挂式告示牌](悬挂式告示牌.md)。

* *[铜灯笼](铜灯笼.md)**
* [灯笼](灯笼.md)的铜质变种。
* 由8个铜粒和1个铜火把合成。
* 能够氧化、被涂蜡、除蜡或除锈。
* * 氧化程度仅会改变外观，不会影响亮度。

# = 游戏内容 =
* *[粒子](Java版粒子.md)**
* 加入了<code>copper_fire_flame</code>。

# = 常规 =
* *[文本组件](文本组件.md)**
* 加入了<code>object</code>文本组件类型。
* * 用于以字符形式显示纹理图集中的一个精灵图。
* * 精灵图总会显示为8&times;8像素的矩形。
* * 格式：
<div class="treeview">
  :*  复合标签格式根标签
  :** ：<code>object</code>。
  :** ：（默认为<code>minecraft:blocks</code>）纹理图集的命名空间ID。
  :** ：图集中精灵图的命名空间ID。示例：<code>item/porkchop</code>。
</div>

* *[战利品表](战利品表.md)**
* 加入了<code>harvest/sweet_berry_bush</code>战利品表，用于生成与[甜浆果丛](甜浆果丛.md)交互收获甜浆果的战利品。

# 更改
# = 方块 =
* *[铜活板门](铜活板门.md)**
* 配方由6个[铜锭](铜锭.md)合成2个更改为4个铜锭合成1个。

* *[铜傀儡像](铜傀儡像.md)**
* 现在被破坏时总会掉落。
* 现在被[活塞](活塞.md)推动时会被破坏并掉落对应物品。

* *[龙蛋](龙蛋.md)**
* 现在不会传送至所在维度的建筑高度限制之外。

* *[铁链](铁链.md)**
* 锁链（Chain）现在被重命名为铁链（Iron Chain）。

* *[展示架](展示架.md)**
* 调整了槽位中物品的位置，由居中改为置于底部隔板上方。

# = 生物 =
* *[铜傀儡](铜傀儡.md)**
* 现在接受字符串ID而非整型ID。
