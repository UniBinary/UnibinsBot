# Java版1.13-pre7

*页面ID: 35348* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.13-pre7**是[Java版1.13](Java版1.13.md)的第7个预发布版，发布于2018年7月10日<ref></ref>，为命令加入了新的参数，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 加入了。

# 更改
# = 方块 =
* *含水的方块**
* 所有含水方块现在都会显示滴水动画。

* *水**
* 在<code>level=1</code>、<code>level=2</code>或<code>level=3</code>的流动的水按键现在会执行正常跳跃而不是向上。

# = 物品 =
* *[地图](地图.md)**
* 地图被稍微修改，有关哪些方块显示，哪些不显示。<ref>https://www.reddit.com/r/Minecraft/comments/8xo1ex/minecraft_113_map_rendering_changes/</ref>

# = 常规 =
* *[进度](进度.md)**
* 进度描述是彩色的了：
* * 普通进度与目标进度描述为绿色。
* * 挑战进度描述为紫色。

* *[调试屏幕](调试屏幕.md)**
* 左侧：
* * 加入了“Looking at liquid”，显示目标流体的坐标。
* * “Looking at”现在被重命名为“Looking at block”并且现在会穿过流体寻找目标。
* 右侧：
* * “Targeted Block”现在会穿过流体寻找目标。
* * “Targeted Block”现在会显示最多16个方块以外的信息。
* * 加入了“Targeted Entity”，用于显示4个方块以外的实体信息。
* 更改了到。现在会阐明它复制的目标方块或实体的客户端数据，仍能被任何人使用。
* 加入了以将目标方块或实体的服务器端数据复制到剪贴板且只能被服务器管理员使用。

* *字体**
* 修复新近优化的字体的明显问题。
