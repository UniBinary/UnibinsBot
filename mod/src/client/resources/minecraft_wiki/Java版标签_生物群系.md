# Java版标签/生物群系

*页面ID: 161620* | *来源: Minecraft Wiki*

* *生物群系标签（Biome Tags）**是[生物群系](生物群系.md)的组合。

# 使用
生物群系标签控制了结构生成、生物生成等许多功能。命令、等也可以调用生物群系标签。

* 当玩家在此标签中的生物群系中时，[水下迷雾](迷雾#水下迷雾.md)效果距离玩家更近。

添加于：[23w03a](23w03a.md)。移除于：[25w42a](25w42a.md)。

* 在此标签的生物群系中，[火焰](火.md)的燃烧速度会加快。

# = plays_underwater_music =
添加于：[22w11a](22w11a.md)。移除于：[25w42a](25w42a.md)。

* 当玩家在此标签的生物群系中时，游戏会播放[水下音乐](水下音乐.md)。

# = snow_golem_melts =
添加于：[23w03a](23w03a.md)。移除于：[25w42a](25w42a.md)。

* 当[雪傀儡](雪傀儡.md)在此标签的生物群系中时，会开始[融化](雪傀儡#行为.md)。

添加于：[22w11a](22w11a.md)。移除于：[25w45a](25w45a.md)。

* 在此标签的生物群系中，[灾厄巡逻队](灾厄巡逻队.md)不会生成。
