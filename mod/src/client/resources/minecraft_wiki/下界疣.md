# 下界疣

*页面ID: 10500* | *来源: Minecraft Wiki*

* *下界疣（Nether Wart）**是一种生长在[下界](下界.md)的[植物](植物.md)。

# 生成
# = 自然生成 =
; 下界要塞
下界疣小片地生成在[下界要塞](下界要塞.md)的楼梯间中，种植在[灵魂沙](灵魂沙.md)上。

; 堡垒遗迹
下界疣会在部分[堡垒遗迹](堡垒遗迹.md)的居住区中生成，种植在[灵魂沙](灵魂沙.md)上。

# 获取
# = 箱子战利品 =

# 破坏
下界疣被挖掘时会立刻被破坏。

生长阶段没有达到第四阶段的下界疣被破坏后会掉落1个下界疣。

生长阶段达到第四阶段的下界疣被破坏后会掉落2-4个下界疣，挖掘工具的[时运](时运.md)魔咒会使下界疣额外等概率掉落0-<魔咒等级>个下界疣。

# 用途
# = 种植 =

下界疣只能种在[灵魂沙](灵魂沙.md)上，它可以在任何维度中生长。

当在[灵魂沙](灵魂沙.md)上种植时，下界疣会经过三个成长阶段，不过中间的两个阶段看起来几乎完全相同（区别在于第三阶段的选择框高一像素）。下界疣在每个随机刻都有10%的概率生长一个阶段，即在默认的随机刻速度下，每个下界疣平均约每生长一次，即平均约完全长成。下界疣的成长速度不受光照或其他环境因素的影响，[骨粉](骨粉.md)对下界疣没有作用，[蜜蜂](蜜蜂.md)对其授粉同样没有作用。

# = 酿造材料 =
下界疣主要用于[酿造](酿造.md)粗制的药水，是除虚弱药水外所有药水酿造的基础。
