* *海晶灯（Sea Lantern）**是一种在[海底神殿](海底神殿.md)和[海底废墟](海底废墟.md)生成的光源。

# 生成
# = 自然生成 =
海晶灯会在[海底神殿](海底神殿.md)和[海底废墟](海底废墟.md)中自然生成。

# 破坏
没有工具可以加速对海晶灯的挖掘。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，海晶灯被破坏后会掉落2-3个[海晶砂粒](海晶砂粒.md)。挖掘工具的[时运](时运.md)魔咒会使海晶灯额外等概率掉落0-<魔咒等级>个海晶砂粒，但掉落总数不会超过5个。其不受时运魔咒影响。<ref></ref>

被具有[精准采集](精准采集.md)的工具挖掘破坏时，海晶灯被破坏后会掉落自身。

# 用途
# = 光源 =
海晶灯会发出亮度等级为15的[光](光.md)，是游戏中亮度最高的方块之一。

# = 潮涌能量 =

用海晶灯在[潮涌核心](潮涌核心.md)周围构建特殊的结构可以激活潮涌核心，使其在一定的半径内给予生物[潮涌能量](潮涌能量.md)状态效果，半径大小具体取决于使用多少方块为其提供能量。[海晶石](海晶石.md)、[暗海晶石](暗海晶石.md)和[海晶石砖](海晶石砖.md)也可以用于构建此结构。
