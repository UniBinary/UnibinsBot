# 裂纹深板岩瓦

*页面ID: 80316* | *来源: Minecraft Wiki*

* *裂纹深板岩瓦（Cracked Deepslate Tiles）**是[深板岩瓦](深板岩瓦.md)制作的装饰性方块。

# 生成
# = 自然生成 =
裂纹深板岩瓦自然生成于[远古城市](远古城市.md)中。

# 获取
# = 烧炼 =

# 破坏
挖掘裂纹深板岩瓦的合适工具是镐。

裂纹深板岩瓦需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

裂纹深板岩瓦被破坏后会掉落自身。

# 用途
裂纹深板岩瓦目前仅用于装饰。
