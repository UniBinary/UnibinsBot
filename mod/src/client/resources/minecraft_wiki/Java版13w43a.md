# Java版13w43a

*页面ID: 33634* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w43a**是[Java版1.7.2](Java版1.7.2.md)的第14个，也是最后一个快照，发布于2013年10月21日<ref></ref>，加入了金合欢和深色橡树对应的原木、树皮、树叶和树苗，以及一个新的命令，并修复了一个漏洞。

# 新内容
# = 方块 =
* *[树皮](树皮.md)**
* 金合欢树皮
* * 具有类似丛林树皮的纹理，但具有较少的绿色。
* 深色橡木树皮
* * 与云杉树皮有相同的纹理。

* *[原木](原木.md)**
* 金合欢原木
* * 暂时不能合成对应的[木板](木板.md)。
* * 具有类似丛林原木的纹理，但具有较少的绿色。
* * 暂时只能通过外部程序或命令放置。
* 深色橡木原木
* * 暂时不能合成对应的[木板](木板.md)。
* * 与云杉原木有相同的纹理。
* * 暂时只能通过外部程序或命令放置。

* *[树叶](树叶.md)**
* 金合欢树叶
* * 视觉上与橡树树叶相同。
* 深色橡树树叶
* * 视觉上与橡树树叶相同。

* *[树苗](树苗.md)**
* 金合欢树苗
* 深色橡树树苗
* * 必须将树苗摆成2×2方块才能种出深色橡树。

# = 命令格式 =
* *[命令](命令.md)**
* 加入了或命令
* * 用于设置所有玩家的出生点（即使是从未进入[服务器](服务器.md)的玩家或是不在线的玩家，但不会覆盖使用[床](床.md)设置的出生点）

# 更改
# = 方块 =
* *[炼药锅](炼药锅.md)**
* 带有[水](水.md)的[炼药锅](炼药锅.md)现在可以熄灭燃烧的实体，但会消耗一些水。

* *[唱片机](唱片机.md)**
* 由[唱片机](唱片机.md)发出的声音现在会循环播放。

# = 物品 =
* *[地图](地图.md)**
* 被放置[物品展示框](物品展示框.md)的[地图](地图.md)现在会重新显示物品展示框的边框，但是大小仍是整个方块。

* *[河豚](河豚（物品）.md)**
* 更改了纹理。

* *[苹果](苹果.md)**
* 现在深色橡树[树叶](树叶.md)被破坏时有的概率掉落一个苹果。

# = 非生物实体 =
* *[船](船.md)**
* [船](船.md)的控制被还原到了之前的WASD控制法
* * 仅在按下时，和才能被使用。

# = 常规 =
* *[Realms](Realms.md)**
* 改进了对[Realms](Realms.md)的支持。
