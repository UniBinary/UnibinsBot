# Java版15w32a

*页面ID: 17273* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w32a**是[Java版1.9](Java版1.9.md)的第4个快照，发布于2015年8月5日<ref></ref>，加入了新的统计信息和切换创造/旁观模式的快捷键，更新了苦力怕、骷髅和僵尸的生物AI以及世界选择界面，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[苦力怕](苦力怕.md)、[骷髅](骷髅.md)和[僵尸](僵尸.md)**
* 现在必须离得更近才能发现戴着对应生物的头的玩家。
* * 特别是，检测范围减半了。这一缩减与潜行和[隐身效果](状态效果.md)产生的范围缩减可叠加。

# = 常规 =
* *世界选择界面**
* 世界现在会显示它们最后一次进入时的游戏版本，或者当最后的版本比快照15w32a老时显示“未知”。
* * 如果世界没有在任意1.9的快照中打开过，将会有一个叹号（！）在世界名称的最右边；它表示：“不要忘记在此快照中打开这个世界前备份它。”
* * 如果世界在未来的版本打开过，将会有一个叹号（！），版本名称是红色；打开会发出警告。

* *[统计](统计.md)**
* <code>sneakTime</code>
* * 记录玩家按下键多少刻。

* *[快捷键](快捷键.md)**
* 现在可以让游戏模式在[创造模式](创造模式.md)和[旁观模式](旁观模式.md)切换
* * 前提是玩家必须允许使用命令。

# 更改
# = 生物 =
* *[末影龙](末影龙.md)**
* 冲击将会一直刷新来把玩家撞下黑曜石平台。
* 完成末影酸攻击后会立刻冲向玩家。
* 现在在离玩家足够远时会取消末影酸攻击。
* 末影酸的影响范围增加了很多；现在会在龙的360°范围对玩家造成伤害而不是仅仅在龙嘴前。
* 死亡前会飞回传送门。
