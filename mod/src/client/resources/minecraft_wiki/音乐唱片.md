# 音乐唱片

*页面ID: 155* | *来源: Minecraft Wiki*

* *音乐唱片（Music Disc）**是能够放入[唱片机](唱片机.md)播放的物品。可播放由[C418](C418.md)、[Lena Raine](Lena Raine.md)、[Samuel Åberg](Samuel Åberg.md)、[Aaron Cherof](Aaron Cherof.md)、[Amos Roddy](Amos Roddy.md)和[Hyper Potions](Hyper Potions.md)制作的音乐。

# = 箱子战利品 =

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落Relic音乐唱片。

# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后会额外随机掉落一张由C418作曲的音乐唱片（包括13、cat、blocks、chirp、far、mall、mellohi、stal、strad、ward、11以及wait）。<ref>同属黑胶唱片的otherside不在此列，见</ref>

# = 恶魂 =
[恶魂](恶魂.md)被玩家反弹的[火球](火球.md)杀死后会额外掉落一张Tears音乐唱片。

# = 僵尸 =
骑乘在[鸡](鸡.md)上的幼年[僵尸](僵尸.md)、被玩家或驯服的[狼](狼.md)杀死后会额外掉落一张Lava Chicken音乐唱片。
