# Java版Indev 20100207-1101

*页面ID: 35405* | *来源: Minecraft Wiki*

<onlyinclude>

* *Minecraft Indev**的一个版本发布于2010年2月7日。<ref></ref>

# 更改
# = 方块 =
* *[玻璃](玻璃.md)**
* 现在会阻止光线和雨通过。

* *[耕地](耕地.md)**
* 现在非完整方块放在其上时也会变成[泥土](泥土.md)。

* *[水](水.md)**
* 现在会破坏非固体方块了，尽管这样不会掉落任何物品。

# = 常规 =
* *其他**
* 将音效系统修改为使用[OpenAL](wikipedia:OpenAL.md)。</onlyinclude>
