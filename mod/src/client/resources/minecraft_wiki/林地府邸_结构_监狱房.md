# 林地府邸/结构/监狱房

*页面ID: 98242* | *来源: Minecraft Wiki*

<noinclude></noinclude>
每个监狱房间的门口都有一个[卫道士](卫道士.md)生成。

; 大型监狱
在此结构中，两个圆石楼梯是面对面、倒过来放置的。

此结构的技术性名称为“2x2_a1”。

; 红石监狱
在此结构中，所有圆石楼梯都是倒置的。

此结构的技术性名称为“1x2_b1”。

; 小型监狱
第1层第10行的橡木楼梯是倒置的；第4层的圆石楼梯是倒置的，且面向结构内部。

此结构的技术性名称为“1x2_b2”。
