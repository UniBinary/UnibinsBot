# Java版14w25b

*页面ID: 33974* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w25b**是[Java版1.8](Java版1.8.md)的第28个快照，发布于2014年6月19日<ref></ref>，修复了[14w25a](14w25a.md)中的一些漏洞和崩溃问题。

# 新内容
# = 命令格式 =
* ***
* 加入了<code>filtered</code>模式。
* * 过滤无用的方块。
* 加入了<code>normal</code>模式。

# 更改
# = 方块 =
* *[湿海绵](湿海绵.md)**
* 烧炼湿海绵时会在可能时向燃料栏的空桶注水。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 移除了右手边显示玩家注视的方块的方块模型的线条。

# 你知道吗
* 在[14w21b](14w21b.md)与14w25b间共计有2651个文件被修改，41995处新增，43425处删改，总计变动的有285408行代码。<ref></ref>
* [14w25a](14w25a.md)发生漏洞的概率很高，[Michael Stoyke](Michael Stoyke.md)（@SeargeDP）将其归为各个开发者在贡献的大量工作尚未融入一份快照。<ref></ref><ref></ref>
* 此版本曾经在[启动器](启动器.md)中移除，但在2018年9月重新加入。
