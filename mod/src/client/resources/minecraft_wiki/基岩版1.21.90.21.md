# 基岩版1.21.90.21

*页面ID: 150689* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.90.21**（ChromeOS/Android）、**Preview 1.21.90.21**（Xbox/Windows/PlayStation）、**Preview 1.21.90.22**（iOS/iPadOS）是[基岩版1.21.90](基岩版1.21.90.md)的第2个测试版，发布于2025年4月29日至30日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[信标](信标.md)**
* 现在光柱的最大渲染高度为2048格。

* *[枯萎的灌木](枯萎的灌木.md)**
* 略微提升了播放环境音效的概率。

* *[发射器](发射器.md)**
* 现在可以为[快乐恶魂](快乐恶魂.md)装备上[挽具](挽具.md)。

* *[失水恶魂](失水恶魂.md)**
* 现在配方中的[骨块](骨块.md)被替换为[灵魂沙](灵魂沙.md)。
* 现在可以通过[猪灵](猪灵.md)的[以物易物](以物易物.md)获得。

* *[沙子](沙子.md)和[红沙](红沙.md)**
* 现在会发出的环境音效不再包括“风声”。
* 略微降低了播放环境音效的概率。
* 修改了判断是否播放环境音效的逻辑，现在不需要方块本身露天，只需要上方一格为空气。
* 现在会在所有生物群系中发出环境音效。

* *[矮枯草丛](矮枯草丛.md)和[高枯草丛](高枯草丛.md)**
* 现在当下方两格均为沙子、红沙或任何陶瓦时会发出特殊的环境音效。

* *所有[陶瓦](陶瓦.md)**
* 不再发出环境音效。

# = 物品 =
* *[拴绳](拴绳.md)**
* 现在配方中的[黏液球](黏液球.md)被替换为[线](线.md)。

# = 生物 =
* *[烈焰人](烈焰人.md)**
* 将攻击范围由16格增加至48格，以匹配其目标检测范围以及。

* *[快乐恶魂](快乐恶魂.md)**
* 略微缩小了碰撞箱。
* 增大了小恶魂的体型。
* 小恶魂现在会跟随快乐恶魂。
* 降低了小恶魂的移动速度。

* *[僵尸疣猪兽](僵尸疣猪兽.md)**
* 降低了追逐攻击目标的移动速度，现在追逐目标时只会拥有略快（1.15倍）的速度。

* *[僵尸猪灵](僵尸猪灵.md)**
* 幼年僵尸猪灵不再会装备[金剑](金剑.md)。
* 降低了追逐攻击目标的移动速度，现在追逐目标时只会拥有略快（1.05倍）的速度。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 增强了[风爆](风爆.md)造成的击退效果以匹配。

* *[声音](声音.md)**
* 更改了[烈焰人](烈焰人.md)的（发射火球）音效以匹配。
* * 将音量由3.0更改为2.0。
* * 将衰减距离由16格增加至32格。

# = 命令格式 =
* ***
* 为子命令加入了参数。
* * 用于控制处理液体的方式。

# = 技术性 =
* *API**
* 的版本

* * 将枚举由测试版移动至稳定版。

* *方块组件**
* 修复了方块几何结构标识符对于一些行为来说会被忽略的组件漏洞，受影响的行为包括：
* * 生物生成（带有自定义生成规则的生物现在可以生成在使用完整方块几何结构的方块上）
* * 箱子阻碍（使用完整方块几何结构的方块现在会阻碍箱子）
* * 草方块和耕地存活（若上方有使用完整方块几何结构的方块，草方块和耕地会变为泥土）
* * 菌岩存活（若上方有使用完整方块几何结构的方块，菌岩会变为下界岩）
* * 藤蔓生长（藤蔓现在会蔓延至使用完整方块几何结构的方块）
* * 可呼吸性（生物和活动对象不再可以在使用完整方块几何结构的方块中呼吸）

* *方块**
* 将和中的替换为。
* * 这与中的粒子数量字段一致。
* * 仍然会在之前版本的这些文件中使用。

* *组件**
* 修复了在组件中使用带有事件标识符的有效实体时会出现错误的内容日志警告的问题。
* 组件不再需要。

* *[基岩版编辑器](基岩版编辑器.md)**
* 加入了方块选取器模式，用于按名称或颜色筛选方块。
* 更新了编辑器日志记录，以使其在发生全局错误时不会闪烁屏幕。
* 更新了移动阶段的教程步骤确认。
* 更新了农场工具，以使其拥有预览边界框。
* 将方块图像缩略图尺寸由128×128更新为64x64，致使地形方块仅需的纹理内存。
* 修复了多个玩家同时尝试导出时会导致崩溃的漏洞。
* 修复了在编辑器世界中更改视频模式后不会正确显示方块缩略图的漏洞。
* 修复了使用整平画笔工具对准空气时发生的崩溃。
* 修复了点击颜色框不能关闭打开的颜色选取器弹窗的漏洞。

* *[Molang](Molang.md)**
* 修复了无法反映自凋灵死亡以来经过的刻数的问题。

# 修复
* *辅助功能**
* 现在在Android、iOS和Win10平台上更改游戏内语言时，文本转语音功能会选择适当的语音。

* *方块**
* 对含水的失水恶魂使用熔岩桶时不再会复制失水恶魂。
* 对着含水方块使用熔岩桶时不再会清空铁桶而不放置熔岩。（）

* *游戏内容**
* 修复了在攻击生物期间交换物品栏槽位时会重新选择进行攻击时使用的原始物品槽位，而不是停留在新的物品栏槽位的物品上的问题。
* 修复了在双击前进键以疾跑而进入水中时不再会进入游泳状态的问题。（）
* 修复了末地外岛的末地折跃门会将玩家传送至地图边界外，然后立即杀死玩家，导致玩家丢失物品栏中的所有物品的问题。（）

* *常规**
* 现在所有平台上的玩家名称均会用于识别跨平台游戏中的玩家。

* *图形**
* 现在无论模型相对于渲染边界箱的方向是什么，本地玩家的载具都会始终符合渲染条件。
* 修复了在非原生分辨率下使用中的TAAU时，末地传送门有时会出现黑框的问题。（）
* 修复了中带有某些属性的材质会渲染为黑色的漏洞。

* *物品**
* 现在带有风爆魔咒的重锤会将玩家弹射到与Java版相同的高度。（）

* *生物**
* 从远处观察自动走上方块的生物时，生物不再会有时穿过方块。
* 骑乘载具的实体不再会渲染阴影，除非载具是隐形的。（）
* 手动装备鞍的猪被杀死时不再会掉落重复的鞍。（1.21.70至此版本之间手动装备鞍的猪在死亡时仍会掉落重复的鞍。）（）
* 将烈焰人的攻击范围由16格增加至48格，以匹配其目标检测范围。（）
* 将烈焰人的攻击音效范围增加至32格，以匹配Java版。
* 小恶魂现在会跟随快乐恶魂。

* *原版趋同**
* 修复了海绵能够吸掉含水的屏障中的水的漏洞。（）
* 幼年僵尸猪灵不再会装备金剑。
* 基岩版中的僵尸疣猪兽和僵尸猪灵不再会在追逐玩家时拥有过快的移动速度。
* 现在堡垒遗迹中自然生成的猪灵、猪灵蛮兵和疣猪兽在被杀死时会掉落经验值。（）
* 修复了冰封山峰的生成问题，以使其顶层下方的水域不会生成冰块，类似于Java版。（）
* 修复了玩家潜行并看向可交互方块时无法使用可使用物品的漏洞。（）</onlyinclude>
