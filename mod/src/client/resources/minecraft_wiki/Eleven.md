# Eleven

*页面ID: 170093* | *来源: Minecraft Wiki*

* *Eleven**是一首由[C418](C418.md)创作的音乐，该音乐未被游戏使用。

# 描述
Eleven的开头与[音乐唱片11](音乐唱片11.md)一样有静电声，但突然被唱片刮擦声打断，歌曲转为一段新的、缓慢的、平静的钢琴曲，而不是11中令人不安的声音。
