* *去皮木头（Stripped Wood）**和**去皮菌核（Stripped Hyphae）**是[木头](木头.md)和菌核的变种，可通过对木头或菌核任意斧来产生。

# 生成
去皮白桦木、去皮丛林木、去皮深色橡木、去皮金合欢木、去皮红树木、去皮樱花木、去皮苍白橡木和去皮菌核不会生成在世界中，只能通过对其未去皮变种斧来产生。

# = 自然生成 =
去皮橡木会作为[平原](平原.md)[村庄](村庄.md)中的灯柱生成。

去皮云杉木会生成在[雪原](雪原.md)村庄中。

# 破坏
挖掘去皮木头和去皮菌核的合适工具是斧。

去皮木头和去皮菌核被破坏后会掉落自身。

# = 燃料 =
去皮木头可以作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个去皮木头可烧炼1.5个物品。

去皮菌核不可以作为燃料。
