# Java版16w02a

*页面ID: 19296* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w02a**是[Java版1.9](Java版1.9.md)的第49个快照，发布于2016年1月13日<ref></ref>，加入了一个新的声音选项，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[选项](选项.md)**
* 在“音乐和声音...”下加入了“Voice/Speech”（说话声）的音量滑条。
* * 计划用于自定义地图的配音。<ref></ref>

# 更改
# = 命令格式 =
* *常规**
* 加入了[目标选择器参数](目标选择器参数.md)<code>m</code>。
* * 支持反选和英文字数值，例如：<code>@p[m=!1]</code>、<code>@p[m=c]</code>和<code>@p[m=!spectator]</code>。

* ***
* 接受一个声音<code>-{}-<来源></code>作为第二个参数。

# = 方块 =
* *[基岩](基岩.md)**
* 不再能使自身掉落成物品。

* *[空气](空气.md)**
* 能被翻译成其他语言，这是为了在自定义超平坦世界时使用。

* *[信标](信标.md)**
* 放在有效的金字塔结构上会被立刻激活。

* *[石质按钮](石质按钮.md)**
* 用[镐](镐.md)破坏会更快些。

* *[木质按钮](木质按钮.md)**
* 用[斧](斧.md)破坏会更快些。

# = 物品 =
* *[盔甲](盔甲.md)**
* 再次更改了[护甲值](护甲值.md)以使玩家抵御偷袭的[苦力怕](苦力怕.md)。
* * 因攻击力度而降低的有效防御值不再在护甲值低于25%时生效。
* * 最大护甲值的减伤率再次变为80%（[15w36a](15w36a.md)里为66%）。

# = 生物 =
* *常规**
* 生物会因为非实体伤害（例如[仙人掌](仙人掌.md)）而被击退。

* *[末影龙](末影龙.md)**
* 用生成的末影龙会停留在原地。
* * 和以<code>{NoAI:1b}</code>生成的末影龙不同，它仍会挥动它的翼。
* * 这些末影龙不会显示它们的[生命值](生命值.md)，也不会受到以外的伤害。

# = 非生物实体 =
* *[盔甲架](盔甲架.md)**
* 被标记的<code>ArmorStand</code>受[发光](发光.md)效果影响时只会有装备的轮廓。
