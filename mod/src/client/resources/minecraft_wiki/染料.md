# = 基本染料 =
这些基本染料都是通过能在世界自然生成的单个材料制成的，并且无法由其他染料合成。

# = 准基本染料 =
这些染料可以由世界上自然产生的单一材料或通过与其他染料合成。

# = 二级染料 =
二级染料只能通过合成基本染料或与流浪商人交易获得。

# 获取
大部分染料能通过使用各种[花](花.md)、其他物品或其他染料合成获得。[青金石](青金石.md)、[骨粉](骨粉.md)、[墨囊](墨囊.md)和[可可豆](可可豆.md)在合成配方中分别可以直接当作蓝色、白色、黑色和棕色染料使用。

# 用途
# = 染色 =
# == 羊毛和生物 ==
染料可以将任意颜色的羊毛重新染色。

染料能在[绵羊](绵羊.md)身上来改变羊毛的颜色。对染色的绵羊使用剪刀后，它们会掉落相应颜色的羊毛，也会在羊毛重新长出时保留羊毛的颜色。[繁殖](繁殖.md)染色的绵羊会使小绵羊的羊毛保留其中一个双亲的颜色或变成双亲颜色的结合。颜色结合使用与染料一样的规则，例如红色和黄色的绵羊会生出橙色的小绵羊。因为染色的绵羊会剪出无限的羊毛，所以染色和剪羊毛比直接染羊毛效率高。

染料也能在驯服的[狼](狼.md)或者[猫](猫.md)身上使用。对着驯服的狼或者猫染料会改变狼或者猫颈圈的颜色（默认为红色）。

染料还可以在创造模式中将[潜影贝](潜影贝.md)的壳染色。

# == 陶瓦 ==
在工作台把8个陶瓦围着1个染料能给陶瓦染色。

# == 玻璃与玻璃板 ==
在工作台把8个玻璃围着1个染料能给玻璃染色。就像普通玻璃，[染色玻璃](染色玻璃.md)也能被用来合成[染色玻璃板](染色玻璃板.md)，合成方式与普通玻璃板一样。

# == 盔甲 ==
[200px|缩略图|在皮革胸甲显示两个染料的所有组合](File:dyegraph.png.md)

皮革[材质](盔甲材料.md)的[盔甲](盔甲.md)和[马铠](马铠.md)可以通过以下方法染色：
* 直接在工作台上用染料给皮革盔甲染色。
* 将皮革盔甲或皮革马铠浸入已加入染料的[炼药锅](炼药锅.md)中。

皮革盔甲能通过和染料合成来给它们染色。皮革盔甲的颜色有12,326,391种组合，因为可以把多于一个染料放在工作台里和皮革盔甲合成。盔甲能被染色几次，过去的颜色会影响最后的结果。对炼药锅染色的盔甲能恢复它们原本的颜色。

游戏中有特定计算染色盔甲的公式：在RGB颜色模型的每种颜色有红色数值、绿色数值和蓝色数值。合成界面的每个染料和盔甲本身（如果曾被染色）的红色数值、绿色数值和蓝色数值会加到累积总和。此外，最高数值（红色、绿色或蓝色）的累积总和也会保留。在此之后，每个总和会除以用于测试的颜色数量，这会快捷地产生平均的红色、绿色、蓝色和最大值。平均RGB数值的最大值也会被计算。最后，每个平均RGB数值会乘上平均最多数值，再除以平均RGB数值的最大值。被改变的平均RGB数值就会被用作最后的颜色。此过程能用下列公式概括：
<pre>
for each color (all "total" variables start at 0 before counting):
 totalRed = totalRed + redValue
 totalGreen = totalGreen + greenValue
 totalBlue = totalBlue + blueValue
 totalMaximum = totalMaximum + max(red, green, blue)
 numberOfColors = numberOfColors + 1

averageRed = totalRed / numberOfColors
averageGreen = totalGreen / numberOfColors
averageBlue = totalBlue / numberOfColors
averageMaximum = totalMaximum / numberOfColors

maximumOfAverage = max(averageRed, averageGreen, averageBlue)
gainFactor = averageMaximum / maximumOfAverage

resultRed = averageRed * gainFactor
resultGreen = averageGreen * gainFactor
resultBlue = averageBlue * gainFactor
</pre>

由于此公式的运作方式，最后的颜色不会比输入的颜色的平均深，通常比较浅。当然，最后的颜色不会比最浅色的输入颜色更浅。此公式也不会产生高于255的RGB数值（在8 bit RGB颜色模型无效）。

在[铁砧](铁砧.md)上经过了重命名的皮革盔甲被染色或洗净后仍会保留其自定义名称。

# == 烟火之星 ==
[烟火之星](烟火之星.md)与染料合成时能有1种颜色或最多8种颜色的组合。对合成的烟火之星加入一个或多个染料会加入“渐变色”效果。

# == 潜影盒 ==
[潜影盒](潜影盒.md)默认为浅紫色（类似[紫珀块](紫珀块.md)），可以使用其他染料染色。

# == 收纳袋 ==
[收纳袋](收纳袋.md)默认为深棕色（类似[皮革](皮革.md)），可以使用其他染料染色。

# == 床 ==
染料可以将任意颜色的床重新染色。

# == 挽具 ==
染料可以将任意颜色的[挽具](挽具.md)重新染色。

# == 炼药锅的水 ==

[水](水.md)可以在[炼药锅](炼药锅.md)中进行染色。玩家需要将任意染料拿在手中，并对一个装满[水](水.md)的[炼药锅](炼药锅.md)按键。

# == 蜡烛 ==
玩家可以在工作台中为未染色的[蜡烛](蜡烛.md)染色。

# == 告示牌 ==
玩家可以使用染料对[告示牌](告示牌.md)上的文字进行染色。

# = 旗帜图案 =

染料在大多数旗帜图案被用来分辨使用的图案和颜色。

# = 合成材料 =
# == 混凝土粉末 ==
染料可以用于合成[混凝土粉末](混凝土粉末.md)，混凝土粉末遇到水可以变成[混凝土](混凝土.md)方块（混凝土方块无法被直接染色）。

# == 气球 ==

染料可以用来合成[气球](气球.md)。

# == 荧光棒 ==

染料还可以用来合成[荧光棒](荧光棒.md)。

使用黑色或淡灰色染料无法合成荧光棒。

# == 暗海晶石 ==
黑色染料可以用于合成暗海晶石。

# = 其他用途 =
以下物品有其他的用途：
* [墨囊](墨囊.md)可用于合成[书与笔](书与笔.md)，出售给图书管理员[村民](村民.md)换取[绿宝石](绿宝石.md)，以及去除[告示牌](告示牌.md)文字的发光效果。
* [可可豆](可可豆.md)可用于合成[曲奇](曲奇.md)，以及种植在[丛林木](丛林木.md)上来获取更多可可豆。
* [青金石](青金石.md)可用于合成[青金石块](青金石块.md)，以及用作在[附魔台](附魔台.md)上附魔的材料。
* [骨粉](骨粉.md)可用于合成[骨块](骨块.md)，以及催熟各种植物、动物方块和下界菌。

这些物品能用于合成染料。这些物品不能直接用作染料；这些物品仅在合成配方（给[旗帜](旗帜.md)添加图案除外）中可以被视为染料，进而直接作为原材料使用。

# 颜色

每种染料都对应了某种颜色，染色方块或物品上会使用这些颜色进行着色。

; 纹理漫反射颜色
[旗帜](旗帜.md)、皮革盔甲、[信标](信标.md)光柱、[猫](猫.md)和[狼](狼.md)的项圈、[绵羊](绵羊.md)羊毛和[热带鱼](热带鱼.md)花纹的颜色。

; 烟火之星颜色
烟花火箭爆炸时内部[烟火之星](烟火之星.md)包含的颜色。

; 文字颜色
使用染料对[告示牌](告示牌.md)着色后，告示牌文字的渲染颜色。告示牌文字边框的颜色为此颜色各颜色分量减少60%的颜色。

;
两种染料颜色的**有效混色**指的是这两种染料[合成](#合成.md)出的另一种染料的颜色，如果两种染料不能合成出新的染料则不存在有效混色。有效混色只会检测合成配方，因此会受[数据包](数据包.md)自定义的配方影响。

[繁殖](繁殖.md)出的幼年[绵羊](绵羊.md)的羊毛颜色以及幼年[猫](猫.md)和幼年[狼](狼.md)的项圈颜色为其双亲羊毛或项圈颜色的有效混色，如果有效混色不存在，则随机遗传双亲中一方的羊毛或项圈颜色。

# 你知道吗
* 玩家能以1个棕色染料、2个黄色染料、2个黑色染料、3个绿色染料、4个蓝色染料、4个红色染料和6个白色染料通过合成获得每种颜色的染料各1个。
* 染色绵羊繁殖的机制反映了[用进废退说](wzh:拉马克主义#用进废退说.md)：生物进化时继承上一代的外在改变，传到后代。
* 除了棕色（仅染色）、青色和黄色（仅颜色代码）之外，染料的颜色与[格式化代码](格式化代码.md)中的聊天字体颜色相匹配。
