# Java版14w31a

*页面ID: 32651* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w31a**是[Java版1.8](Java版1.8.md)的第41个快照，发布于2014年7月30日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[旗帜](旗帜.md)**
* 加入了缺失的上半和右半图案，上下对角线半边部分、下半部分、上半部分的图案。
* 将现有图案的名称根据[旗帜学](wzh:旗帜学.md)更改。
* 能作为[熔炉](熔炉.md)的燃料。

* *[砂土](砂土.md)和[灰化土](灰化土.md)**
* 当树苗在其上方生长为树木时不再会变为泥土。<ref></ref>

* *[阳光传感器](阳光传感器.md)**
* 能被右键点击倒转。
* * 在与正常相反的时间可以达到最高的能量。
* * 这可以在夜晚而不是白天直接激活红石，不需要一个非门。

* *[圆石楼梯](圆石楼梯.md)**
* 从“石楼梯”重命名为“圆石楼梯”。

* *[西瓜](西瓜.md)**
* 用[斧](斧.md)现在挖掘得更快。

* *[梯子](梯子.md)**
* 用[斧](斧.md)现在挖掘得更快。

# = 物品 =
* *[地图](地图.md)**
* 放大的地图现在对齐于特定的网格，而不是以原始地图为中心。

# = 生物 =
* *[兔子](兔子.md)**
* 现在可以受到坠落伤害。
* 加入了音效。
* * 有“受伤”、“死亡”、“跳跃”和“空闲”的音效。
* ** “跳跃”和“空闲”的音效几乎无法听见。
* 更改了模型。
* * 加入了尾巴。

# = 命令格式 =
* ***
* 现在可以在单人游戏中运行。
* 新的调试参数：<code>-{}-/debug <开始|结束|区块> [<x> <y> <z>]</code>。
* <code>x/y/z</code>只对区块模式有效。
* 也许会删除，因为该命令只是用于测试。<ref>http://www.reddit.com/r/Minecraft/comments/2c5f35/minecraft_snapshot_14w31a_has_been_released/cjct3k1</ref>

# = 游戏内容 =
* *[交易](交易.md)**
* 牧师现在出售以3~11每个的价格出售[附魔之瓶](附魔之瓶.md)。

# = 常规 =
* *[世界边界](世界边界.md)**
* 世界边界尺寸变化的时间参数现在可以更大。
* 只有玩家可以在世界边界之外受伤。

* *优化**
* 多线程生物寻路。
* 更多其他优化。
