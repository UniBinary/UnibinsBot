# 基岩版1.20.0.24

*页面ID: 104226* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.0.24**（ChromeOS/Android）、**Preview 1.20.0.24**（Windows/iOS/iPadOS）是[基岩版1.20.0](基岩版1.20.0.md)的第5个测试版，发布于2023年5月11日<ref></ref>，加入了一个新成就，更新了[种子模板](种子模板.md)的种子列表，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[成就](成就.md)**
* 加入了1个新成就，自2023年6月7日起会在成就屏幕中显示。
* * “风格别致的锻造”——至少应用一次这些锻造模板：尖塔、猪鼻、肋骨、结界、幽静、猥傀、潮汐、向导（30G）

# 更改
# = 常规 =
* *[鸣谢名单](鸣谢名单.md)**
* 更新了鸣谢名单。

* *[种子模板](种子模板.md)**
* 现在包含[樱花树林](樱花树林.md)的种子，2023年5月18日起会在种子列表中显示。<ref></ref>

# 修复
* *游戏内容**
* 玩家传送至尚未加载的区块时不再会停止飞行。（）

* *图形**
* 现在使用高分辨率纹理包时，带有纹饰的盔甲的图标会正确渲染。（）
* 现在嗅探兽蛋和瓶子草荚果能够正确使用高分辨率纹理。（）

* *嗅探兽**
* 现在嗅探兽繁殖后产下嗅探兽蛋时会产生音效。（）

* *生物**
* 猪现在再次可以生成于大多数生物群系，而不是只会生成于樱花树林和草甸。（）

* *性能与稳定性**
* 开始或停止使用不可用的物品时不再会使游戏崩溃。
* 钓鱼竿损坏时不再会使游戏崩溃。（）

* *用户界面**
* 现在所有平台上的主菜单背景都会向下倾斜。

* *附加包**
* 修复了自定义实体的刷怪蛋在交易列表中不受支持的问题。（）</onlyinclude>
