# 原主机版TU62、CU52、1.66、Patch 31、1.0.12

*页面ID: 62785* | *来源: Minecraft Wiki*

* *TU62/CU52/1.67/Patch 31/1.0.12**是[原主机版](原主机版.md)的一次更新，发布于2018年1月30日，修复了一些漏洞。<ref></ref><ref></ref>

# 新内容
# =常规=
* *混搭包**
* 加入了Moana Character Pack。
* [WIIU](Wii U版.md)和[NS](Nintendo Switch版.md)：加入了Skin Pack 1。

# 更改
# =[方块](方块.md)=
* *[活塞](活塞.md)**
* 现在可以推动小箱子，但仅能推进玩家能合法放置箱子的位置。
* *[TNT](TNT.md)**
* 爆炸修改，以使混搭包里的TNT大炮可以如同其以往一般工作。

# = 游戏内容 =
* *[附魔](附魔.md)**
* 创造模式中附魔经验的消耗现在与基岩版相同。

# 修复
* *修复了15个漏洞**
* 修复了：活塞不能移动炼药锅。
* XBONE、PS、WIIU和NS：修复了：把床放在仙人掌附近会导致游戏崩溃。
* 修复了：侦测器不会侦测到一些改变，例如另外一个激活的侦测器。
* 修复了：在火把下方不能放置藤蔓。
* 修复了和平难度中的动物在被击打后不会逃跑的漏洞。
* 修复了没有装备的被驯服的马会在玩家离开这片区域时消失的漏洞。
* 修复了跳跃的马的水平移动距离缩短的漏洞。
* 修复了当告示牌放在一个方块一侧时，那个方块不能被移动的漏洞。
* 修复了当旗帜放在一个方块一侧时，那个方块不能被移动的漏洞。
* 修复了在活塞侧面的绊线钩会在活塞臂伸缩时掉落的漏洞。
* 修复了红石比较器不能处理箱子和陷阱箱大小变化的漏洞。
* 修复了铁轨和火把不能放置在荧石、海晶灯、草丛、或者冰上的漏洞。
* 修复了花盆、门、和南瓜不能放置在草丛上的漏洞。
* 修复了红石，拉杆，按钮不能放置在活塞上的漏洞。
* 修复了当“信任玩家”和“可以打开容器”选项被关闭时，玩家仍可以打开潜影箱的漏洞。
