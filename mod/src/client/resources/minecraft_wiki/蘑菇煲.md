* *蘑菇煲（Mushroom Stew）**是一种[食物](食物.md)类物品。

# 获取
# = 哞菇 =
蘑菇煲能通过拿着[碗](碗.md)对[哞菇](哞菇.md)获得。

如果拿着多于1个碗对哞菇，只有1个碗会被消耗，而蘑菇煲会被放在空的物品栏槽。如果玩家的物品栏已满，则会变为掉落物。

# = 合成 =

# 用途
# = 食物 =

手持蘑菇煲按住键即可食用，每个蘑菇煲可以回复。

蘑菇煲被玩家食用后会返还一个碗，能再次被用来合成。
