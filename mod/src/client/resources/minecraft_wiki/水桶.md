# 水桶

*页面ID: 8422* | *来源: Minecraft Wiki*

* *水桶（Water Bucket）**是装着[水](水.md)的[铁桶](铁桶.md)。

# 获取
手持[铁桶](铁桶.md)对着[水](水.md)源方块、[含水](含水.md)方块或者装满水的[炼药锅](炼药锅.md)按下键可得到水桶，水就会被舀入桶中。若为炼药锅则被清空。流动的水无法填充桶。

# = 箱子战利品 =

# = 熔炉 =
在[熔炉](熔炉.md)中烘烤[湿海绵](湿海绵.md)时，若熔炉的燃料槽中有铁桶，烤干后会得到水桶。

# = 鱼桶 =
玩家使用[热带鱼桶](热带鱼桶.md)喂食[美西螈](美西螈.md)后，物品栏中的热带鱼桶会变为水桶。

玩家使用任意[鱼桶](鱼桶.md)喂食[鹦鹉螺](鹦鹉螺.md)或[僵尸鹦鹉螺](僵尸鹦鹉螺.md)后，物品栏中的鱼桶会变为水桶。

# 用途
手持水桶对着可[含水](含水.md)的方块按键时，水源就会与其共处一格空间内；对着不可含水的方块使用会将水源方块置于其旁边。水桶被使用后会变为[铁桶](铁桶.md)。在[下界](下界.md)中时，使用水桶无法倒出水源，对[可替代方块](可替代方块.md)使用时也不会将其破坏，而是产生烟雾[粒子](粒子.md)效果并直接变为铁桶。对着与[下界传送门方块](下界传送门方块.md)相邻的方块轮廓箱表面放出水源会将传送门破坏。

对着水位未满的[炼药锅](炼药锅.md)水桶会将其填满。对着装有其他物质的炼药锅使用水桶会替换该物质；这样做会导致炼药锅和水桶都被清空，炼药锅还会产生烟雾粒子。

[发射器](发射器.md)发射水桶时若满足放置条件，其会在朝向的方块放置出水源方块并清空水桶。

手持水桶对着[鱼](鱼.md)、[美西螈](美西螈.md)或[蝌蚪](蝌蚪.md)会将其装入桶中，获得对应的[生物桶](生物桶.md)。
