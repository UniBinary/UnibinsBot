# Java版23w16a

*页面ID: 103914* | *来源: Minecraft Wiki*

<onlyinclude>

* *23w16a**是[Java版1.20](Java版1.20.md)的第4个快照，发布于2023年4月20日<ref></ref>，丰富了[古迹废墟](古迹废墟.md)的结构，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[进度](进度.md)**
* 加入了进度触发器，会在合成一个配方时触发。
* * 触发条件：
* ** ：合成出的配方的命名空间ID。
* ** ：由配方中的物品堆叠的谓词组成的数组。
* *** 一个物品堆叠只能满足一个谓词的条件。
* *** 只有在所有谓词的条件被满足时进度才会触发，以区分使用相同标识符但不同合成材料的配方。
* *** 该字段为可选项，当字段未指定或字段为空时，对应的进度只会通过触发。

=== 命令格式 ===
* ***
* 可用于控制函数内部执行流程并更改函数返回值的新命令，可达成以下效果：
* * 跳过当前执行函数中尚未执行的单独顶层命令。
* * 将命令返回值由命令执行次数改为指定值。
* * 此命令本身的返回值即为其参数的值。
* 语法：
* * ：需要指定的返回值。

# 更改
# = 方块 =
* *[按钮](按钮.md)**
* 磨制黑石按钮的破坏时间现在与其他按钮一致。

* *[校频幽匿感测体](校频幽匿感测体.md)**
* 更改了模型，使紫水晶部分与[紫水晶簇](紫水晶簇.md)一致。

* *[饰纹陶罐](饰纹陶罐.md)**
* 将方块实体中字段重命名为。

* *[瓶子草植株](瓶子草植株.md)**
* 更改了每个生长阶段的判定箱形状。

* *[瓶子草](瓶子草.md)**
* 现在是可燃的。

* *[幽匿感测体](幽匿感测体.md)和[幽匿尖啸体](幽匿尖啸体.md)**
* 若有振动计划被幽匿感测体和幽匿尖啸体接收，此振动会在临近全部区块均被加载和计算前留在等待队列中。
* * 此改动用于防止共振机制在远处被卸载的区块中出现问题。

* *[火把花](火把花.md)**
* 现在不再会使[耕地](耕地.md)转变为[泥土](泥土.md)。
* 现在是可燃的。

# = 物品 =
* *[陶片](陶片.md)**
* 英文名称由“Pottery Shard”更改为“Pottery Sherd”。

# = 生物 =
* *[嗅探兽](嗅探兽.md)**
* 躲避过程中不再尝试嗅探。
* 在拥有[飘浮](飘浮.md)效果时不再尝试刨挖。
* 现在可以进入[矿车](矿车.md)。

* *[村民](村民.md)**
* 现在农民可以种植[火把花种子](火把花种子.md)和[瓶子草荚果](瓶子草荚果.md)。

# = 非生物实体 =
* *[展示实体](展示实体.md)**
* 将展示的物品沿Y轴旋转了180度，以与应用于渲染盔甲架头部及展示框上的物品的渲染变换相匹配。

# = 世界生成 =
* *[古迹废墟](古迹废墟.md)**
* 新增了34个结构文件。
* 不再生成[沙子](沙子.md)和[可疑的沙子](可疑的沙子.md)。
* 调整了[沙砾](沙砾.md)和[泥土](泥土.md)的数量。
* 调整了[可疑的沙砾](可疑的沙砾.md)的数量。
* 可疑的沙砾中的战利品表现在被拆分。
* * 稀有战利品和普通战利品现在有各自独立的战利品表。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[世界加载屏幕](世界加载屏幕.md)**
* 略微更改了区块颜色图的颜色。

* *[标签](Java版标签.md)**
* 从方块和物品标签中移除了，并改为新加入的标签。
* 从方块标签中移除了，并改为新加入的标签。
* 从方块标签中移除了。
* 将物品标签重命名为，并将其内部成员做了相应更改。

* *常规**
* 游戏的应用图标由[工作台](工作台.md)改为[草方块](草方块.md)，若是快照则为泥土。
* 加入了对ARM64架构Windows的原生。
* * 目前需要手动在启动器中指定原生Java可执行文件。
