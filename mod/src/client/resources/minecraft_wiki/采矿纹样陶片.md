# 采矿纹样陶片

*页面ID: 156729* | *来源: Minecraft Wiki*

* *采矿纹样陶片（Miner Pottery Sherd）**是图案形似[镐](镐.md)的[陶片](陶片.md)。

# 获取
# = 考古战利品 =
用[刷子](刷子.md)刷扫[沙漠神殿](沙漠神殿.md)里的[可疑的沙子](可疑的沙子.md)有概率掉落采矿纹样陶片。

# = 饰纹陶罐 =
被不具有[精准采集](精准采集.md)的工具挖掘破坏或被[弹射物](弹射物.md)击毁时，附有采矿纹样陶片的[饰纹陶罐](饰纹陶罐.md)会掉落采矿纹样陶片。
