# Java版1.21-pre4

*页面ID: 121378* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21-pre4**是[Java版1.21](Java版1.21.md)的第4个，也是最后一个预发布版，发布于2024年6月7日<ref></ref>，更改了[爆炸保护](爆炸保护.md)和[火焰保护](火焰保护.md)魔咒的效果，并修复了一些漏洞。

# 更改
# = 物品 =
* *[重锤](重锤.md)**
* 不再是[锋利](锋利.md)魔咒的适用物品。

# = 非生物实体 =
* *[被激活的TNT](被激活的TNT.md)**
* 被激活的TNT穿过传送门后不再破坏[下界传送门方块](下界传送门方块.md)。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 因为[爆炸保护](爆炸保护.md)和[火焰保护](火焰保护.md)的属性效果可以在穿戴多个具有此魔咒的装备时叠加，所以只穿单件附魔[盔甲](盔甲.md)的效果现在降低至原来的四分之一。
* * 现在爆炸保护在每件盔甲上会将生物所受爆炸击退效果减少<code>-{}-*等级*×3.75%</code>。
* * 现在火焰保护在每件盔甲上会将生物被施加的着火时间减少<code>-{}-*等级*×3.75%</code>。
