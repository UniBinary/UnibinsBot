# 激活铁轨

*页面ID: 9583* | *来源: Minecraft Wiki*

* *激活铁轨（Activator Rail）**是一种可以引发[矿车](矿车.md)特殊功能的铁轨。

# 生成
激活铁轨不会生成在世界中。

# 破坏
挖掘激活铁轨的合适工具是镐。

激活铁轨被破坏后会掉落自身。

# 用途

激活铁轨是铁轨和[红石元件](红石元件.md)。一系列相连的铁轨（包括普通[铁轨](铁轨.md)、[动力铁轨](动力铁轨.md)、[探测铁轨](探测铁轨.md)和激活铁轨）被称作**轨道**。

激活铁轨会在没有合适方块（见）支撑或时[掉落](掉落.md)为[物品](物品.md)。

如果熔岩流过激活铁轨，激活铁轨将会被摧毁且不会掉落物品。

# = 生物 =
除了玩家和[监守者](监守者.md)以外的所有生物在寻路时不会将激活铁轨视为可以走上或跨越的方块，除非它们正站在任意类型的铁轨上。

# = 放置 =

[thumb|铁轨可能连接到的所有位置，图中以普通铁轨为基准](File:All linked rails.png.md)

激活铁轨只能放置在上表面[边缘完整](方块支撑形状.md)的方块上。

激活铁轨可以和水平方向上相邻一格的铁轨相连，也可以和这些相邻铁轨上方或下方一格的铁轨相连。激活铁轨可以和其他种类的[铁轨](铁轨（消歧义）.md)相连。

# = 铁轨 =

激活铁轨（和其他铁轨）用作供[矿车](矿车.md)通行的铁路。从激活铁轨两头进入的矿车会继续移动，只会失去一点速度（可由[动力铁轨](动力铁轨.md)再次提升速度）。从侧面进入激活铁轨的矿车会转向东边或南边（取决于激活铁轨的朝向），而进入倾斜的激活铁轨的矿车会向下移动。

# = 红石元件 =

激活铁轨可影响途经激活铁轨的矿车。

; 激活
激活铁轨是[机械元件](红石元件#机械元件.md)，它可被下列方式激活：
* 毗邻的开启的**[电源](红石元件#电源.md)**（例外：[侦测器](侦测器.md)只会激活指向的激活铁轨）。
* 毗邻的**[充能方块](红石电路/充能与激活.md)**。
* 毗邻的指向激活铁轨且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)；毗邻但未指向激活铁轨的红石粉不会让激活铁轨激活。

[thumb|中89个被激活的激活铁轨](File:Activator rail signal bifurcation.png.md)
激活的激活铁轨亦可激活邻近并与其连接的其他激活铁轨，从原始激活源开始至多能传递8格。激活的激活铁轨不会激活邻近的不与其连接的激活铁轨，但能激活自己不连接的、逆信号传递方向与其单向连接的激活铁轨，使信号分叉。因此单个激活源可激活至多或个激活铁轨（中间1个和两边各或个）。

; 行为
激活铁轨会视矿车类型以不同效果影响矿车。矿车或</ref>}}时激活铁轨生效。

* *激活**的激活铁轨会：
* 摇晃普通矿车：令其中的生物（含玩家）离开，犹如玩家按下了键离开矿车那样（默认为移动中的矿车的右边一格，至多为上方两格，除非被阻挡）。
* 重复激活[命令方块矿车](命令方块矿车.md)：每隔或使命令方块矿车执行其包含的命令。
* 锁定[漏斗矿车](漏斗矿车.md)——被锁定的漏斗矿车不再在矿车运行时捡起物品，直到该漏斗矿车被**未激活的**激活铁轨解锁（或直到它被破坏或被重新放置）。
* 激活[TNT矿车](TNT矿车.md)——激活的TNT矿车在经过激活铁轨的1秒后爆炸，爆炸威力与速度成正比。

* *未激活**的激活铁轨会：
* 解锁[漏斗矿车](漏斗矿车.md)：被解锁的漏斗矿车会在矿车运行时捡起物品，直到该漏斗矿车被**激活的**激活铁轨锁定。
