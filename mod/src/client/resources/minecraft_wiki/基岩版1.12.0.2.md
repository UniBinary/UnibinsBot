# 基岩版1.12.0.2

*页面ID: 42298* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.12.0.2**是[1.12.0](基岩版1.12.0.md)的首个测试版，发布于2019年4月17日。<ref></ref>

# 新内容
# = 物品 =
* *[摄像机](摄像机.md)**
* 重新加入游戏。
* * 只能通过命令给予物品获取。
* 其物品形式并没有功能。

# = 命令格式 =
* *[游戏规则](游戏规则.md)**
* 加入了规则。
* * 允许指定玩家的生成半径。
* * 在世界设置中加入了新的“Respawn Radius”选项。
* 加入了一些和附加包、地图制作相关的命令。

# = 常规 =
* *精选服务器**
* 允许基岩版服务器上的内容登录。

* *物品ID**
* 物品ID现在可以在客户端和服务端同步。

* *种子选择器**
* 加入了一些新的种子。

# 更改
# = 方块 =
* *[海草](海草.md)**
* 和Java版同步纹理。

* *[命令方块](命令方块.md)**
* 加入了自动完成。
* 加入了延迟功能。
* * 使用这个新的字段可以添加延迟。延迟的刻数是按[红石刻](刻#红石刻.md)计算的。

* *[木桶](木桶.md)**
* 现在在创造模式物品栏中有自己的位置，而不是位于[箱子](箱子.md)分类中。

* *[钟](钟.md)**
* 现在可以使用喷溅药水或滞留药水敲击钟。

* *[制图台](制图台.md)和[讲台](讲台.md)**
* 调整并加入了界面提示。

* *[耕地](耕地.md)**
* 干燥状态的耕地的侧面和底面纹理现在使用[泥土](泥土.md)的纹理，而不是[砂土](砂土.md)的。

* *[冰](冰.md)**
* 现在使用附有效率的镐能更快地挖掘。

* *[浮冰](浮冰.md)和[蓝冰](蓝冰.md)**
* 现在使用镐能更快地挖掘。
* * 镐附有的效率魔咒能够进一步加快挖掘速度。

* *[结构方块](结构方块.md)**
* 现在放置时有轮廓了。

# = 生物 =
* *[流浪商人](流浪商人.md)**
* 加入了新的音效。
* 现在能打开门。

* *[僵尸村民](僵尸村民.md)**
* 加入了新的音效。

* *[村民](村民.md)**
* 村民的交易UI在玩家站得离村民太远时不会打开或关闭了。
* 村民现在会正确的寻找到自己的工作点了。
* 和玩家交易中的村民不会在听到袭击铃声时逃跑或躲藏了。
* 增加了一个拒绝交易音效，用来指示村民不想交易（比如袭击时）。
* 被治愈后的村民会保留在变成僵尸村民前的职业。

* *[灾厄队长](灾厄队长.md)**
* 现在用命令将普通掠夺者转换为灾厄队长时，灾厄旗帜会正确显示。
* 灾厄队长现在会正确掉落灾厄队长旗帜，即使世界被重新加载。
* 不祥之兆效果现在只会在击杀灾厄队长时给予，使用弓箭或者药水造成非致命伤或不是最后一击时不会获得不祥之兆效果。

* *[NPC](NPC.md)**
* 对话和可更换皮肤被移除。

# = 常规 =
* *[附加包](附加包.md)**
* 附加包能用来添加新物品了。
* 生物事件可以在世界选项中启用/禁用了。
* 动画和粒子无需链接实体即可添加。
* 可以通过脚本修改物品栏、手持物品和装备栏了。
* 现在音效可以被动画事件触发了。
* 在脚本API中加入了新的executeCommand。
* 为与物品交互加入新的脚本事件，比如：
* * 捡起物品
* * 掉落物品
* * 持有的物品发生变动
* 增加了一次性动画支持，允许在实体上执行单个动画。
* 粒子发射器现在可以触发脚本事件。
* 更新actor事件的文档，以记录资源包中actor事件的客户端使用情况。
* “Add block”组件现在使用JSON模式。
* 添加了一个屏幕来查看内容日志错误。
* 日志屏幕可以使用打开，或者进入设置→配置文件。
* 添加代码以允许在本地运行静态验证脚本。
* 现在可以通过脚本添加自定义方块。
* * 目前这仍是一个待完善的功能，更多的特性将会在未来的版本中添加。
* 现在只能通过额外的json脚本添加自定义方块。
* * 自定义方块只能使用/+命令放置。
* 增加了新的数据驱动粒子：

* * 潜影弹

* *音乐**
* 现在在键盘显示在屏幕上或打开聊天栏时也会播放。

# 修复
* *修复了74个漏洞**<br>
* *崩溃**
* 修复了游戏进行时出现的崩溃现象。
* 在Xbox上切换用户时游戏崩溃。
* Windows 10版下启动游戏时游戏崩溃。
* 加入Realms世界时，使用实体方块时游戏崩溃。
* 在海底神殿里与远古守卫者战斗时游戏崩溃。
* 使用带有忠诚魔咒的三叉戟时游戏崩溃。
* 按下退出游戏按钮时游戏崩溃。

* *性能**
* 提升了多人游戏下的区块加载性能。
* 改进了使用命令的目标选择器。
* 缓存里的资源包不再导致Nintendo Switch版运行卡顿。（）

* *常规**
* 当多个op在调整玩家权限时，现在会正确同步保存的选项。
* 重新加载世界时，射进方块的箭的位置会被保存。
* 区域效果云不再在时间被更改时生成大量药水粒子。（）
* 在世界编辑界面里，下载的资源包不再被立刻启用。（）
* “总是白天”选项在启用时显示错误。（）
* 穿过绊线的流水不再使得出现积水现象。（）
* 使用命令清除浮漂实体后，玩家不再需要右键点击两次才能抛出新的浮漂。
* Nintendo Switch版里玩家调整网络设置后不再出现多次提示。
* 移除了多余的Xbox Live登录提示。

* *游戏内容**
* 市场下载内容现在能显示最多25个对象。
* 在交易界面里被拆分的一组物品现在仍会算进总交易数量里。
* 方块不能放置在红石矿石上面。（）
* 不同的Xbox设备里现在会正确同步选项。
* 在Realms世界里，现在只有参与抵御袭击的玩家才能获得村庄英雄效果。
* 现在可以使用喷溅药水或滞留药水敲击钟。
* 刷怪笼现在只会在亮度低于7的地方生成敌对生物。（）
* 被活塞推动的可可果没有掉落物。（）
* 修复了部分与末地折跃门有关的漏洞，现在它可以正确将玩家传送到安全的位置。（、和）
* 附有效率的镐现在能更快挖掘冰。（）
* 被治愈的玩家现在会受到TNT的冲击。
* 治愈后，村民丢失职业。（）
* 砂轮现在能正确修复或合并损坏的物品。
* 使用触摸屏时，现在可以手持已经装填的弩来和方块交互。
* 部分方块只有在重启游戏后才能放置。

* *世界生成**
* 基岩版专用服务器或Realms世界里的部分方块生成错误。
* 调整了村庄里的工作站点方块数量。

* *生物**
* 袭击里的卫道士现在能正确寻路。
* 重新进入存档后，凋灵会重复播放生成动画。（）
* 生物不再试图穿过酿造台。
* 生物现在可以生成在双层台阶上。（）
* 生物在穿过梯子时不再被困在梯子上。（）
* 袭击里的唤魔者在寻找村庄时移速太快。

* *方块**
* 脚手架不再能放置在潮涌核心上面。
* 钟的摆动方向不正确。（）

* *物品**
* 铁轨上的掉落物会阻止玩家放置矿车。
* 从酿造台取出的玻璃瓶不能正确堆叠。（）
* 物品展示框内的盾牌发亮。（）

* *图形**
* 村民皮肤出现纹理深度冲突。
* 狼身上的拴绳位置不正确。
* 音符盒发出的音符粒子与音高不符。
* 部分僵尸村民的纹理丢失。
* 耕地的侧面和底部纹理不正确。（）
* 门和活板门的纹理不正确。（）
* 染色的皮革马铠不再能影响其他的马铠。（）

* *用户界面**
* 调整了在安卓设备里使用经典UI时的制图台的UI大小。

* *附加包和脚本引擎**
* 修复了脚本导致玩家悬空的漏洞。
* 现在可以对非原版实体使用“拾取方块”按键。（）
* 和现在会正确获取修改日期。
* 在游戏里循环运行的函数现在需要Game Master权限，而不是玩家权限。
* 为加入了新的构造参数以便管理者可以创建更新权限的实例。</onlyinclude>
