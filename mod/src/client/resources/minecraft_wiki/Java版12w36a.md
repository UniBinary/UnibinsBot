# Java版12w36a

*页面ID: 33048* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w36a**是[Java版1.4.2](Java版1.4.2.md)的第4个快照，发布于2012年9月6日<ref></ref>。

# 新内容
# = 方块 =
* *[生物头颅](生物头颅.md)**
* 一共有5种：
* * 骷髅头颅
* * 凋灵骷髅头颅
* * 僵尸头颅
* * 苦力怕头颅
* * 玩家头颅
* 杀死凋灵骷髅有极小概率掉落凋灵骷髅头颅。
* 其他头颅只能在创造模式物品栏中获得。
* 可以戴在头上。

# = 物品 =
* *[胡萝卜钓竿](胡萝卜钓竿.md)**
* 用于移动[猪](猪.md)。
* 也可以吸引猪。
* 骑乘猪时可以用于控制方向。

* *[画](画.md)**
* 加入了如何制作凋灵的画。

* *[下界之星](下界之星.md)**
* 用于制作[信标](信标.md)。

* *[胡萝卜](胡萝卜.md)和[马铃薯](马铃薯.md)**
* 可以在村庄内找到。
* 胡萝卜可以用于繁殖猪。

# = 生物 =
* *[凋灵骷髅](凋灵骷髅.md)**
* 只生成于[下界](下界.md)。
* 攻击玩家时给予他们凋零[状态效果](状态效果.md)。
* 携带着石剑，被玩家杀死时有概率掉落。
* 掉落[骨头](骨头.md)和[煤炭](煤炭.md)。
* 玩家在下界使用骷髅[刷怪蛋](刷怪蛋.md)时有极高的概率生成它们。
* 可以成为凋灵[蜘蛛骑士](蜘蛛骑士.md)。
* * 通过在下界使用凋灵骷髅刷怪蛋生成。

# 更改
# = 方块 =
* *[信标](信标.md)**
* 有了新的模型和纹理。
* 现在可以通过在中间摆放1个[下界之星](下界之星.md)并在其底部放置3个黑曜石和在顶部5个玻璃制作。

# = 物品 =
* *[金胡萝卜](金胡萝卜.md)**
* 更改了纹理。

* *[胡萝卜](胡萝卜.md)**
* 现在会生成在村庄的农田里。
* 现在可用于繁殖猪。

* *[皮革盔甲](皮革盔甲.md)**
* 现在使用双层纹理，上面一层是颜色。
* 盔甲染色的小更改——颜色将尝试保持饱和度，而不会稀释。

* *[刷怪蛋](刷怪蛋.md)**
* 现在在[下界要塞](下界要塞.md)使用蜘蛛刷怪蛋有概率生成凋灵骷髅蜘蛛骑士。

# = 生物 =
* *[凋灵](凋灵.md)**
* 放置4个[灵魂沙](灵魂沙.md)摆成T字形并在上面放置3个凋灵骷髅头颅可以生成它。
* 死亡后掉落[下界之星](下界之星.md)。
* 生成于[主世界](主世界.md)时，天空会变暗。
* 攻击玩家时给予他们凋零II[状态效果](状态效果.md)。
* 它们的名字在血量条上得以正常显示。

* *[鸡](鸡.md)**
* 现在使用[种子](小麦种子.md)繁殖而不是[小麦](小麦.md)。
* 玩家手持种子是会跟随。

* *[猪](猪.md)**
* 可以通过[胡萝卜](胡萝卜.md)繁殖。
* 装上鞍时被杀死现在会总是掉落鞍。

* *[骷髅](骷髅.md)**
* 死亡后现在会总是掉落捡起的物品。

* *[僵尸](僵尸.md)**
* 更改了模型和纹理。
* * 没有视觉差异，除了它打破了旧的纹理包。
* 死亡后现在会总是掉落捡起的物品。

* *[僵尸猪人](僵尸猪人.md)**
* 更少生成于[下界要塞](下界要塞.md)（概率从43.5%下降至17.9%）。
* 更改了模型和纹理。
* * 没有视觉差异，除了它打破了旧的纹理包。

* *[岩浆怪](岩浆怪.md)**
* 更少生成于下界要塞（概率从13%下降至10.7%）。

* *[烈焰人](烈焰人.md)**
* 更少生成于下界要塞（概率从43.5%下降至35.7%）。</onlyinclude>
