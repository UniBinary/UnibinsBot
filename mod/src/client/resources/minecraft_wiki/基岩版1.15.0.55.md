# 基岩版1.15.0.55

*页面ID: 55877* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.15.0.55**是[基岩版1.16.0](基岩版1.16.0.md)的第4个测试版，发布于2020年3月4日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[活塞](活塞.md)**
* 现在推动[含水](含水.md)方块将使其失去含水状态。

# = 生物 =
* *[村民](村民.md)**
* 由[僵尸村民](僵尸村民.md)治愈而成的村民现在能够提供打折交易。（）
* 现在有概率提供[三叉戟](三叉戟.md)的[附魔书](附魔书.md)作为交易。（）

* *[苦力怕](苦力怕.md)**
* 现在在船上会伤害周围的玩家。

# = 非生物实体 =
* *[蓝色凋灵之首](凋灵之首.md)**
* 现在可以破坏[黑曜石](黑曜石.md)。（）

# 修复
* *修复了18个漏洞**<br>
* *崩溃**
* 修复了若干可能在游戏过程中发生的崩溃。
* 修复了给钓鱼竿附魔可能导致崩溃的问题。

* *常规**
* 滚动时，市场评级现在正确显示。（）

* *游戏内容**
* 海带在被活塞部分折断后会继续生长，下面这片海带将获得最大为24的随机年龄。（）
* 末影龙火球攻击不再造成过度伤害。（）
* 被远程武器摧毁的漏斗矿车现在会掉落漏斗和矿车。（）
* 多个蜂蜜块能够使用2×2合成网格合成。（）
* 制作多个蜂蜜块现在会退回正确数量的玻璃瓶。（和）

* *生物**
* 敌对生物现在能够正确地找到海龟蛋并在海龟蛋上跳。（）
* 被治愈的僵尸村民不再保留其经验值，从而不再阻止其寻找新的职业。（）
* 村民不再专注于赠送胡萝卜。（）
* 生成于林地府邸里的卫道士现在会使用生成事件，并且会在受伤前变成敌对状态。（）
* 给狼喂肉会治愈狼。（）</onlyinclude>
