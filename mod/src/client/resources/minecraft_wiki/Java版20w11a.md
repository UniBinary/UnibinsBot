# Java版20w11a

*页面ID: 56242* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w11a**是[Java版1.16](Java版1.16.md)的第6个快照，发布于2020年3月11日<ref name="20w11a"></ref>，加入了下界金矿石、缠怨藤和灵魂疾行魔咒以及新的粒子、方块标签和物品标签，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[下界金矿石](下界金矿石.md)**
* 可生成于[下界](下界.md)的任何高度。
* 与普通的[金矿石](金矿石.md)性质相同。

* *[缠怨藤](缠怨藤.md)**
* 一种生成于[诡异森林](诡异森林.md)生物群系的[藤蔓](藤蔓.md)变种。
* 与[垂泪藤](垂泪藤.md)不同，它会自下而上生长。
* 可供攀爬。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 加入了[灵魂疾行](灵魂疾行.md)魔咒。
* * 属于[宝藏型魔咒](宝藏型魔咒.md)，只能通过和[猪灵](猪灵.md)进行[以物易物](以物易物.md)获得，不能从[附魔台](附魔台.md)、[箱子战利品](箱子战利品.md)或[交易](交易.md)中获得。
* * 只能附魔在[靴子](靴子.md)上。
* * 可提高使用-{}-者在[灵魂沙](灵魂沙.md)和[灵魂土](灵魂土.md)上的行走速度。
* ** 但玩家每走过一个灵魂沙或灵魂土，其靴子的耐久度都会有4%的概率受消耗。

# = 常规 =
* *[粒子](粒子.md)**
* 加入了新的粒子类型。

* *[标签](Java版标签.md)**
* 加入了方块和物品标签。
* * 应用于[金矿石](金矿石.md)和[下界金矿石](下界金矿石.md)。
* * 应用此标签的方块需要使用[铁镐](铁镐.md)或更高级的镐采集。
* * 许多合成配方使用此标签。
* 加入了物品标签。
* * 在之前的快照中，该标签已作为方块标签加入游戏，现在它同时也是物品标签了。
* * 应用于[灵魂火把](灵魂火把.md)和[灵魂灯笼](灵魂灯笼.md)。
* * [猪灵](猪灵.md)不会尝试捡起应用该标签的方块。
* 加入了方块标签。
* * 应用于灵魂沙和灵魂土。
* * [灵魂疾行](灵魂疾行.md)魔咒会利用该标签检测玩家在何种方块上的行走速度会得到提高。

# 更改
# = 方块 =
* *[钟](钟.md)**
* 现在被任意弹射物击中时都会被敲响。

* *[营火](营火.md)**
* 现在被任意着火的弹射物击中时都会被点燃。

* *[哭泣的黑曜石](哭泣的黑曜石.md)**
* 不再能被[活塞](活塞.md)移动。
* 不再能被[末影龙](末影龙.md)破坏。
* 现在只能使用[钻石镐](钻石镐.md)或[下界合金镐](下界合金镐.md)采集。

* *[火和灵魂火](火.md)**
* 不再拥有破坏动画。
* 被破坏的音效不再和[羊毛](羊毛.md)相似。
* 现在拥有[战利品表](战利品表.md)。

* *[竹子盆栽](竹子盆栽.md)**
* 更改了[模型](模型.md)，移除了其底部多余的面以防止深度冲突。<ref></ref>
* 更改前：[32px](File:Potted Bamboo (facing NWU).png.md)
* 更改后：[32px](File:Potted Bamboo new (facing NWU).png.md)

* *[锻造台](锻造台.md)**
* 现在拥有使用音效。

* *[雪](雪.md)**
* [门](门.md)、[铁轨](铁轨.md)、[按钮](按钮.md)、[火把](火把.md)、[压力板](压力板.md)和[红石粉](红石粉.md)现在可以放置在完整方块大小的雪层上。

* *[灵魂沙](灵魂沙.md)**
* 灵魂沙上方置有[铁轨](铁轨.md)时不再会降低[矿车](矿车.md)的行驶速度。
* [门](门.md)、[铁轨](铁轨.md)、[按钮](按钮.md)、[火把](火把.md)、[压力板](压力板.md)和[红石粉](红石粉.md)现在可以放置在灵魂沙上。

* *[TNT](TNT.md)**
* 现在被任意着火的弹射物击中时都会被激活。

* *[藤蔓](藤蔓.md)**
* 现在拥有攀爬[音效](音效.md)。

* *[垂泪藤](垂泪藤.md)**
* 现在被破坏时只有的概率掉落，但可以使用[时运](时运.md)附魔工具提高掉落率。
* 现在拥有攀爬音效。

# = 物品 =
* *[骨粉](骨粉.md)**
* 现在可以促进[海带](海带.md)、[垂泪藤](垂泪藤.md)和[缠怨藤](缠怨藤.md)的生长。

* *[锄](锄.md)**
* 现在可以提高[标靶](标靶.md)、[干海带块](干海带块.md)和[菌光体](菌光体.md)的采集效率。
* * 由于一个漏洞，用[斧](斧.md)采集菌光体仍然效率更高。<ref></ref>

# = 游戏内容 =
* *[以物易物](以物易物.md)**
* [猪灵](猪灵.md)现在会提供带有灵魂疾行魔咒的[铁靴子](铁靴子.md)和[附魔书](附魔书.md)。

* *[命令](命令.md)**
* 现在可以用于定位[下界化石](下界化石.md)了。

# = 常规 =
* *[标签](Java版标签.md)**
* 将方块标签应用于[缠怨藤](缠怨藤.md)。
* 将方块标签应用于[哭泣的黑曜石](哭泣的黑曜石.md)。
* 将方块标签应用于[诡异菌盆栽](诡异菌盆栽.md)。
