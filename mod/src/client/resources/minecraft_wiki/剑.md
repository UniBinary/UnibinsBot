# = 生物 =

一些生物在生成的时候会带剑，在它们被玩家杀死的情况下有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落剑。手持铁剑的[僵尸](僵尸.md)可以掉落铁剑，[僵尸猪灵](僵尸猪灵.md)和手持金剑的[猪灵](猪灵.md)可以掉落金剑，[凋灵骷髅](凋灵骷髅.md)可以掉落石剑。这些剑大部分损坏严重，有时会附有[魔咒](魔咒.md)（凋灵骷髅的石剑除外）。

一个手持铁剑的[恼鬼](恼鬼.md)被玩家杀死时始终不会掉落一把铁剑，这是因为它们主手手持物品掉落的概率为0。<ref></ref>

袭击时生成的[掠夺者](掠夺者.md)和[卫道士](卫道士.md)有4.1%（困难难度为5.12%）的概率掉落一把铁剑，尽管它会带有随机魔咒，但它受损严重。

# 用途
[物品实体](物品实体.md)形式的下界合金剑会漂浮在[熔岩](熔岩.md)上，且不会被[火](火.md)和熔岩摧毁。

# = 近战攻击 =
剑每成功进行一次[近战攻击](近战攻击.md)会减少1点耐久度。

用剑攻击[船](船.md)和[矿车](矿车.md)会或，还可以触发横扫攻击。

用剑攻击非生物实体不会消耗耐久度。

# == Java版 ==
剑的攻击速度是1.6，需要来[恢复](近战攻击#攻击冷却.md)。

# == 基岩版 ==
剑没有攻击冷却。

# == 横扫攻击 ==

如果[攻击冷却](攻击冷却.md)完成度在90%及以上，且此时[玩家](玩家.md)在地面、不处于[疾跑](疾跑.md)状态，且玩家这一[游戏刻](游戏刻.md)和上一游戏刻移动距离之差不超过属性<code>-{}-[movement_speed](属性/速度.md)</code>的值（默认为0.1米每游戏刻，即2米每秒），使用剑进行[近战攻击](近战攻击.md)就会使出横扫攻击，产生[“剑气”粒子](粒子#sweep_attack.md)，同时击中附近的敌人并导致其被[击退](伤害#击退.md)并受到的伤害。[横扫之刃](横扫之刃.md)魔咒可以为<code>-{}-[sweeping_damage_ratio](属性/横扫伤害比率.md)</code>属性添加修饰符，使横扫伤害在基础上提高一定比例的[攻击伤害](属性/攻击伤害.md)，I级提高50%，II级提高约67%，III级提高75%。横扫攻击的击退效果是[击退](击退.md)I所造成击退的80%，且不受击退魔咒的加成。

要使未被直接攻击的敌人受到横扫攻击，其[碰撞箱](碰撞箱.md)应与以被直接攻击的生物的碰撞箱的边界向外，水平方向各拓展1格，垂直方向各拓展0.25格的长方体相重合，并且被横扫的敌人的脚<!-- 即碰撞箱底面的对角线交点，也就是实体的执行坐标。 -->与使出横扫的玩家的脚的距离小于3格。例如，玩家攻击一只[苦力怕](苦力怕.md)（其碰撞箱宽度为0.6格，高度为1.7格）时，碰撞箱与以该苦力怕的碰撞箱中心为中心，底面边长为2.6格，高度为2.2格的长方体相重合，且脚距离与玩家的脚距离小于3格的其他苦力怕会受到横扫攻击。

# = 挖掘工具 =

剑是一种挖掘工具，每次成功挖掘了任何硬度不为0的方块会消耗2耐久度。剑的品质对挖掘速度没有影响。

# 你知道吗
* 剑的纹理来自Notch遗弃的RPG游戏《[Legend of the Chambered](Legend of the Chambered.md)》。铁剑的纹理首先被制作出来，其他的剑是根据铁剑制作的。
* 如果在[创造模式](创造模式.md)或使用[命令](命令.md)为剑附魔[效率](效率.md)，用它破坏[蜘蛛网](蜘蛛网.md)的时间将会相应缩短。这是因为剑被归类为采集蜘蛛网的合适工具。
* 在[20w06a](20w06a.md)中，下界合金剑剑格两端有透明纹理，使其与其他材料的剑相比外观独特。这一问题在[20w10a](20w10a.md)中被修复。<ref></ref>
