# 基岩版1.21.120.24

*页面ID: 167605* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.120.24**（ChromeOS/Android）、**Preview 1.21.120.24**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.120](基岩版1.21.120.md)的第5个测试版，发布于2025年10月1日<ref></ref>，同步了一些的特性，更新了设置，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[环境音效](环境音效.md)**
* 加入了水下环境音效，以同步。

# 更改
# = 方块 =
* *[水](水.md)**
* 现在每格水只会减少1等级光照亮度，而非2等级光照亮度，以匹配。
* * 此更改仅影响测试版本。

# = 物品 =
* *[盾牌](盾牌.md)**
* 不再是挖掘工具，因此现在使用盾牌挖掘方块时不会消耗盾牌的耐久度。

# = 生物 =
* *[驴](驴.md)和[骡](骡.md)**
* 更改了箱子的纹理。
* 略微更改了鞍的纹理。

* *[羊驼](羊驼.md)**
* 更改了箱子的纹理以匹配。

* *[骷髅马](骷髅马.md)**
* 更改了箱子的纹理，以与[驴](驴.md)和[骡](骡.md)保持一致。
* 更改了鞍的纹理。

* *[僵尸马](僵尸马.md)**
* 更改了箱子的纹理，以与驴和骡保持一致。

# = 游戏内容 =

# 修复
* *方块**
* 现在大型铜箱子的对角线闪光方向与单个铜箱子的对应方向相匹配。
* 现在单个铜箱子和大型铜箱子的箱闩会以相同的方向进行着色。
* 现在大型铜箱子和单个铜箱子拥有一致的着色效果。
* 现在锈蚀的大型铜箱子的底部纹理与其他大型铜箱子一致。

* *游戏内容**
* 修复了使用盾牌挖掘方块时会消耗盾牌的耐久度的问题。（）
* 修复了即使使用盾牌进行格挡，弹射物仍然会施加击退效果的问题。（）

* *市场**
* 市场内容现在可以使用RTX和的过滤器来搜索。

* *图形**
* 修复了溺尸的身体纹理上缺失一些像素的问题。（）
* 修复了驴耳部的顶部包含错误颜色的问题。（）
* 修复了铜马铠、铁马铠、金马铠和钻石马铠的纹理上缺失一些像素的问题。
* 现在物品栏的胸甲盔甲槽和酿造台的空玻璃瓶槽的背景与对应物品纹理相匹配。（）
* 修复了中的颜色分级会导致白色平衡模式变颠倒的问题。（）
* 更新了灰色染料、淡蓝色染料、淡灰色染料和绿色染料的MERS。（）

* *生物**
* 现在伤害吸收效果会在所有金色生命值均因伤害而消失时立即清除。（）
* 溺尸的右臂和覆盖层不再会与胸部相交。（）

* *性能与稳定性**
* 修复了可能生成过多暴击粒子的问题。

* *结构方块**
* 修复了结构方块预览GUI会错误放置自定义方块的问题。

* *用户界面**
* 修复了Windows平台上的测试版本会阻止用户在游玩屏幕中通过模板创建新世界的问题。（）
* 现在可以使用快捷键将物品从对应的快捷栏槽位转移至鼠标悬停在的槽位。（）
* 修复了在游戏窗口在加载世界的情况下未获得焦点时，键盘输入会无法注册的问题。（、）

* *原版趋同**
* 现在羊驼、驴、骡、骷髅马和僵尸马的箱子和鞍纹理在Java版和基岩版中相匹配。（、）
* 现在水下环境音效会在玩家处于水下时播放。（）</onlyinclude>
