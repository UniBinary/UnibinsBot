# 基岩版1.21.60.27

*页面ID: 139222* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.60.27**（ChromeOS/Android）、**Preview 1.21.60.27**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.60](基岩版1.21.60.md)的第5个测试版，发布于2025年1月15日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[发射器](发射器.md)、[投掷器](投掷器.md)和[合成器](合成器.md)**
* 不再能同时拥有多个计划刻。<ref></ref><ref name="bilibiliref">https://www.bilibili.com/opus/1022758384684761090</ref>

* *[水](水.md)和[熔岩](熔岩.md)**
* 流动不再受随机刻影响。<ref name="bilibiliref"/>

# = 生物 =
* *[末影人](末影人.md)**
* 现在无法在[船](船.md)或[矿车](矿车.md)里瞬移。

# = 世界生成 =
* *[化石](化石.md)**
* 现在会生成于[红树林沼泽](红树林沼泽.md)。

* *[丛林灌木](丛林灌木.md)**
* 现在包含[橡树树叶](橡树树叶.md)而非[丛林树叶](丛林树叶.md)，以匹配。

# = 技术性 =
* *组件**
* 将物品组件从[实验性玩法](实验性玩法.md)移动至正式版。同时将相关脚本由测试版移动至正式版。

* *[基岩版编辑器](基岩版编辑器.md)**
* 加入了工作台工具，允许快速修改带有可修改属性的方块（门、栅栏等）的方块状态。
* 将加入至受支持的按键绑定操作，能够以设定的刻间隔模拟按键重复点击。
* 为操作栏加入了“测试世界”、“导出”和“设置”。
* 为操作栏中的“导航面板”加入了缺失的图像。
* 将旋转角度滑块更新为整数。
* 修复了固定距离模式的最大值不正确的问题。
* 修复了悬停在另一UI元素上时，文本框会失去焦点的漏洞。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“测试版 API”子选项后才可使用。

# = 技术性 =
* *API**
* 将模块中的接口重命名为。
* 修复了来自的迭代器被首先删除时可能发生的崩溃。

* *实验性内容**
* 聚焦目标相机视角现在默认拥有值为的 ，以反映世界空间变化。
* 现在使用命令的语法时，或目标距离相机视角超过64区块时，聚焦目标相机视角会停止聚焦。

* *性能与稳定性**
* 加入了在内存不足的情况下应用服务端驱动的纹理内存预算的实验性支持。
* * 启用时，游戏会在内存使用量接近预算限制时通过逐步降低部分纹理的分辨率来节省内存。

# 修复
* *音频**
* 现在在苍白之园生物群系中退出游戏时，音乐的音量会恢复正常。（）

* *方块**
* 张开的眼眸花和闭合的眼眸花不再会出现在尚未更新至1.21.50的世界的创造模式物品栏中。（）

* *游戏内容**
* 修复了玩家爬行着进入世界时有时会受到窒息伤害的问题。（）

* *生物**
* 修复了鱿鱼在旋转时不会匹配其身体运动的问题。
* 修复了一个问题，以阻止末影人在乘坐船和矿车时瞬移。（）

* *原版趋同**
* 现在地图上的小麦颜色是黄色，而不是绿色。（）
* 现在在潜行的情况下修剪长有发光浆果的洞穴藤蔓时会剪断洞穴藤蔓，而不是掉落发光浆果。（）
* 现在海草会更频繁地生成，而高海草的数量因生物群系而异。（）
* 现在海草会在任何深度生成，进而增加总体生成量。（）
* 现在红树林沼泽的降雨量与普通沼泽相匹配。（）
* 现在红树林沼泽的水下迷雾会在进入水中后逐渐变淡，如同其他生物群系一样。（）
* 化石现在会生成在红树林沼泽的地下，类似于普通沼泽。（）
* 丛林灌木现在使用橡树树叶作为树叶部分，以与预期的游戏美感保持一致，尽管树干部分是丛林原木。（）
* 现在为原木去皮时会播放去皮音效，而不是在原木上行走的音效。（）
* 现在转变出土径时会播放锹压地的音效，而不是在草类方块上行走的音效。（）

* *世界生成**
* 修复了新的地形生成会与部分生物群系中的已保存区块不匹配的问题。（）</onlyinclude>
