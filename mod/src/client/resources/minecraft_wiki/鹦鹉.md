* *鹦鹉（Parrot）**是一种生成于[丛林](丛林.md)的、色彩鲜艳的[友好生物](友好生物.md)，可以模仿附近[敌对生物](敌对生物.md)的[音效](音效.md)，驯服之后可以站在[玩家](玩家.md)的肩上。

# 生成
鹦鹉会在[丛林](丛林.md)、[竹林](竹林.md)和生物群系中自然生成。它们可以在Y=70或以上的地方生成，且只会生成在[草方块](草方块.md)、上。

# = 外形 =
[600px|alt=5种不同颜色的鹦鹉](File:ParrotColors.png.md)

鹦鹉有5种不同的颜色：红色、绿色、蓝色、青色和灰色。

# 行为
[缩略图|右|鹦鹉在丛林中飞行](File:ParrotsInJungle.gif.md)

# = 运动 =
鹦鹉不会攻击任何生物，受到伤害时会逃跑。它们可以飞行，当受到攻击后通常会向上飞走。在正常情况下，它们都可以飞，但它们也会“疲惫”<ref></ref>并回到地面。

鹦鹉会聚集并落在附近的[生物](生物.md)旁，包括敌对生物。

如果鹦鹉落到[水](水.md)中，它们会拍打翅膀来[游泳](游泳.md)。

# = 驯服 =
玩家可以通过给鹦鹉吃[小麦种子](小麦种子.md)、[西瓜种子](西瓜种子.md)、[南瓜种子](南瓜种子.md)、[甜菜种子](甜菜种子.md)、[火把花种子](火把花种子.md)或[瓶子草荚果](瓶子草荚果.md)来驯服它们，每次喂食后驯服成功的概率是。一旦被驯服，玩家就可以通过来让鹦鹉坐下。

就像驯服的[狼](狼.md)和[猫](猫.md)一样，驯服的鹦鹉会跟随玩家，除非玩家让它坐下。当玩家离鹦鹉太远时，鹦鹉会传送到玩家身边。

鹦鹉的传送过程不会发出声音。<ref></ref>

与其他可驯服生物一样，驯服的鹦鹉死亡时会给/显示一条[死亡消息](死亡消息.md)。

与其他大多数[动物](动物.md)不同，鹦鹉没有幼年形式，也不能繁殖。

# = 受伤害行为 =
有坐骑的鹦鹉免疫[虚空](虚空.md)和以外的所有伤害，即使坐骑不是玩家。<ref name="MCPE-137310"></ref>

# = 站在肩膀上 =
|width=128px}}
玩家可以通过贴近被驯服的鹦鹉来让鹦鹉站在玩家的肩膀上。被驯服的鹦鹉也会主动向玩家飞行并站在玩家肩上，除非它被命令坐下或被拴绳拴住。一个玩家的肩膀最多可以站2只鹦鹉。鹦鹉会优先站到左肩膀上。鹦鹉也会出现在物品栏界面和中玩家模型的肩膀上。站在肩膀上的鹦鹉总是与玩家的-{}-头看向同一方向。

站在肩膀上的鹦鹉不再是独立的实体，不会受到[伤害](伤害.md)。穿过传送门时，站在玩家肩膀上的鹦鹉会跟随玩家一同到达另一维度。遇到以下情况时，鹦鹉会从玩家肩膀上下来：
* 玩家死亡或受到[伤害](伤害.md)（伤害值为0时仍然触发，但免疫的伤害类型不算）；
* * 此处的免疫不包含[抗火](抗火.md)效果，着火时仍会触发。
* 玩家切换到[旁观模式](旁观模式.md)；
* 玩家下落高度大于0.5，且未在骑乘实体<ref></ref>；
* 玩家睡觉；
* [创造模式](创造模式.md)的玩家进入[飞行](飞行.md)状态；
* 玩家接触到[水](水.md)或[细雪](细雪.md)；
* 玩家触发[激流](激流.md)效果。

鹦鹉作为独立的实体骑乘玩家，骑乘状态的鹦鹉免疫大多数类型伤害<ref name="MCPE-137310"/>。不同于，玩家接触到细雪时鹦鹉不会脱离<ref></ref>。站在玩家肩膀上的鹦鹉会阻止玩家穿过传送门<ref></ref>，也会阻止玩家触发激流效果<ref></ref>。遇到以下情况时，鹦鹉会从玩家肩膀上下来：
* 玩家死亡；
* 玩家切换到[旁观模式](旁观模式.md)；
* 玩家下落高度大于格<ref></ref>；
* 玩家睡觉；
* 鹦鹉接触到水；
* 鹦鹉即将受到火焰或虚空伤害。
* * 抗火可以避免鹦鹉受到火焰伤害；
* * 创造模式玩家肩膀上的鹦鹉免疫火焰伤害。

# = 模仿声音 =
鹦鹉有能力发出敌对生物的声音。鹦鹉发出的声音要比原声高一个音调。

自身20格半径范围内有敌对生物时，鹦鹉会盯着它们模仿声音的目标并发出模仿的声音。

鹦鹉有时会模仿随机敌对生物的声音，即使范围内并不存在这种生物。<ref></ref>

# = 跳舞 =
|跳舞的鹦鹉}}
在[唱片机](唱片机.md)播放唱片的时候，附近的鹦鹉都会跳舞。鹦鹉会在音乐播放完毕后会停止跳舞；鹦鹉会在音乐播放完毕后继续跳舞。

鹦鹉站在玩家肩膀上时不会跳舞。

# = 曲奇 =
向鹦鹉喂食[曲奇](曲奇.md)会使其获得的[中毒](中毒.md)效果并受到来源于玩家的3.40282×10<sup>38</sup>（ × 1.70141×10<sup>38</sup>）伤害。

向鹦鹉喂食曲奇会使其获得的[中毒（致命）](中毒（致命）.md)效果。

# 你知道吗
* 5种鹦鹉纹理中的4种是基于现实生活中的[金刚鹦鹉](wzh:金刚鹦鹉.md)绘制的：红色——五彩金刚鹦鹉；蓝色——紫蓝金刚鹦鹉；绿色——大绿金刚鹦鹉；青色——蓝黄金刚鹦鹉。灰色鹦鹉的原型是现实生活中的[玄凤鹦鹉](wzh:雞尾鸚鵡.md)，眼睛下方的腮红（一团橘色的羽毛，位置是其耳孔部位）是它的特征之一。<ref></ref>
* 鹦鹉跳舞的行为引用自“派对鹦鹉（Party Parrot）”表情包。<ref></ref>Minecraft团队的成员在交流时经常使用不同的派对鹦鹉表情。<ref>["Really. We have over 20 different party parrot emojis. :D"](:en:Special:Diff/1080413.md) – HelenAngel 2017年4月5日</ref>
* 有两条[闪烁标语](闪烁标语.md)警告玩家不要给鹦鹉喂食巧克力和鳄梨。在现实中巧克力对鹦鹉有较强的毒性，这是游戏中该特性的来源。
* 由于[苦力怕](苦力怕.md)没有空闲音效也没有脚步声，当鹦鹉检测到附近的苦力怕时只能模仿它引爆时的音效。
* 鹦鹉的空闲音效念的是英文单词"hello"。<ref></ref>
