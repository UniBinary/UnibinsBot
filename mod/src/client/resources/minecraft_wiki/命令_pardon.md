# 命令/pardon

*页面ID: 39798* | *来源: Minecraft Wiki*

从封禁列表上移除对象。

封禁列表存储在文件。

# pardon

从玩家档案封禁列表上移除指定对象。

# = 语法 =
   <code>pardon <targets></code>

# = 参数 =

   指定要从封禁列表移除的玩家档案。


# = 结果 =

# = 输出 =

# = 示例 =
* <code>/pardon Steve</code>：从封禁列表中移除Steve的玩家档案

# pardon-ip

从IP地址封禁列表移除指定对象。

# = 语法 =
   <code>pardon-ip <target></code>

# = 参数 =

   指定自封禁列表移除的IP地址。应为一个有效的IP地址。


# = 结果 =

# = 输出 =

# = 示例 =
* <code>/pardon-ip 127.0.0.1</code>：从封禁列表中移除本地回环
