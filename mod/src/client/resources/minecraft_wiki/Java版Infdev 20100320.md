# Java版Infdev 20100320

*页面ID: 36001* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年3月20日，重新加入了[树木](树木.md)，并修复了一些漏洞。<ref name="update"></ref>

# 新内容
# = 世界生成 =
* *[树木](树木.md)**
* 被重新加入游戏。

* *[团簇](团簇.md)**
* 被重新加入游戏。
* 矿石无视高度生成。
* * [煤矿石](煤矿石.md)现在非常普遍，[铁矿石](铁矿石.md)和[金矿石](金矿石.md)较普遍，[钻石矿石](钻石矿石.md)很稀有。

# 更改
# = 方块 =
* *[熔炉](熔炉.md)**
* 现在如果被重新放在同一个位置，其中的物品会复原。

* *[箱子](箱子.md)**
* 现在如果被重新放在同一个位置，其中的物品会复原。

# = 游戏内容 =
* *常规**
* 现在玩家会携带64个[钻石斧](钻石斧.md)、64个[钻石锹](钻石锹.md)、64个[钻石镐](钻石镐.md)、64个[火把](火把.md)、64个[打火石](打火石.md)、64个[TNT](TNT.md)、64个[玻璃](玻璃.md)、64个[弓](弓.md)和64个[箭](箭.md)生成。

# 修复
* *修复了4个漏洞**
* 火现在能被正确扑灭。
* 打开容器（例如箱子和熔炉）不再使游戏崩溃。
* “减少崩溃漏洞”。<ref name="update"/>
* 苦力怕和TNT现在能正常爆炸了。</onlyinclude>
