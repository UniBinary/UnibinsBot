# 书

*页面ID: 499* | *来源: Minecraft Wiki*

* *书（Book）**是一种用于[附魔](附魔（物品修饰）.md)与[合成](合成.md)的[物品](物品.md)。

# 获取
# = 书架 =
当不使用带有[精准采集](精准采集.md)魔咒的工具挖掘破坏[书架](书架.md)或爆炸破坏书架时，会掉落3本书。

# = 附魔书 =
在[砂轮](砂轮.md)上将不带有[诅咒](诅咒.md)魔咒的[附魔书](附魔书.md)祛魔会将其变为书。

# = 合成 =

# = 箱子战利品 =

# = 礼物 =

[图书管理员](图书管理员.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷书。

# 用途
# = 合成材料 =

# = 附魔 =

书能通过放进[附魔台](附魔台.md)附魔变成[附魔书](附魔书.md)。

# = 交易 =

# = 雕纹书架 =
手持书对[雕纹书架](雕纹书架.md)按键可将书放入其中。
