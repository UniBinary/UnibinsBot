# PC Gamer演示版

*页面ID: 7612* | *来源: Minecraft Wiki*

[右|缩略图|200px|第214期“PC Gamer”附带包装的演示版光碟](File:Minecraft-demo-disc.png.md)
* *PC Gamer演示版（PC Gamer Demo）**是基于[Java版Beta 1.3](Java版Beta 1.3.md)制作的[演示](wzh:游戏演示.md)版本，随杂志2011年六月刊（美洲版第214期）捆绑附赠。该版本允许玩家体验100分钟的游戏（相当于游戏内的五[天](昼夜更替.md)），时间结束后会提示玩家需购买游戏才能继续游玩当前世界。

# 特性
演示版可使用完整版的所有功能，但会将玩家限制在演示版的世界中。演示版使用的[种子](种子（世界生成）.md)为，且略有变动，用于指导新手体验Minecraft。演示版玩家的[出生点](出生点.md)位于X=166、Y=65、Z=-57处。

在Windows中，玩家的游戏存档保存于当前用户的<code>%APPDATA%\.minecraft\saves</code>中，且与完整版兼容，购买游戏后可继续使用。有关演示版的下载及相关资讯，可在[此处](http://www.pcgamer.com/2011/04/19/download-the-minecraft-demo/)找到（英文）。

演示版包含一张烙有“PC Gamer”标志的[牛](牛.md)皮肤。

# = 已知问题 =
* 如果在演示版过期后玩家持有[铁桶](铁桶.md)，尽管铁桶无法与其他物品互动，玩家仍可使用铁桶挤[牛奶](牛奶.md)。
* 如果玩家在演示版过期时处于89层以上，仍能在89层及以上高度与世界互动。
* 玩家在玩演示版时，若将窗口最小化后再最大化，所有方块都会停止渲染。
* 若玩家同时打开两个演示版窗口，让一个处于世界中的窗口暂停，另一个窗口进入主菜单重置演示版世界，再点击前一个窗口继续游戏，会出现错误信息；演示版游戏时间会被重置，但世界不会重置；物品栏中的物品会丢失，但[方块实体](方块实体.md)中的物品不会丢失。
* 演示版过期后，玩家仍可与[船](船.md)互动。
* 用镐挖掘方块时打开物品栏（默认为键），挖掘会继续，但镐在停止挖掘前不会摆动。

# 你知道吗
* 完整版的Minecraft包含演示版的代码，这些代码直到[Java版1.3](Java版1.3.md)才被启用。
* 演示版拥有在后来的更新中加入的功能文件，例如[狼](狼.md)、[天气](天气.md)与[活塞](活塞.md)的音效。然而，这些文件并未被使用。
* 从那块提示玩家打开[箱子](箱子.md)的[告示牌](告示牌.md)正下方开始向下挖掘，挖几个方块就能发现一个装有22个[火药](火药.md)的箱子。
* 在玩家出生点向后转180度，往右边一直走，跨过一片湖泊后，会看到一个由[雪块](雪块.md)、红色[羊毛](羊毛.md)及黑色羊毛建造的“PC Gamer”标志，其背景颜色与牛身上的标志颜色一致。
* 玩家抵达“PC Gamer”标志后向左走，会发现一个骷髅[地牢](地牢.md)。该[地牢](地牢.md)露天生成在沙漠地表，两个自然生成的箱子中，一个阻挡了背后的水流，另一个与刷怪笼则被坠落的沙子覆盖。
* 玩家抵达“PC Gamer”标志后向右走，会发现菱形的坑。
* 可以修改演示版的游戏文件，让玩家不受游戏时间限制地进行游戏。
* 演示版中没有[调试屏幕](调试屏幕.md)。原因可能是新玩家可能会对界面中显示的信息感到困惑。
* 演示版的帮助中含有Minecraft Wiki的旧网址（<nowiki>http://www.minecraftwiki.net</nowiki>）。
