# Java版24w14potato/potato quest

*页面ID: 119232* | *来源: Minecraft Wiki*

本页面为[24w14potato](24w14potato.md)中马铃薯事件的流程，仅供参考。

# intro
当玩家在主世界初次将毒马铃薯植物放入头盔栏中时，就会触发该段对话。

# in_village
当玩家进入村庄时，就会触发该段对话。

# took_bed
完成后，当玩家在物品栏中获得[床](床.md)后就会触发该段对话。

随后会引出对话。

# slept_in_bed
完成后，当玩家在床上睡觉后就会触发该段对话。

随后会引出对话。

# leaving_village
完成后，如果玩家没有完成或就离开村庄，就会触发该段对话。

# meta_one

对话结束后，玩家会获得一张带有额外描述的[纸](纸.md)（）。随后会引出对话。

# got_paper

对话结束后，玩家的面前会生成一个[铁砧](铁砧.md)，以[下落的方块](下落的方块.md)形式出现。随后会引出对话。

# anvil_dropped

# wrote_thoughts
当玩家从铁砧的输出栏中取出重命名之后的纸后，就会触发该段对话。使用+左键取出则不能触发。<ref></ref>

# crafted_eyes
当玩家在完成后合成马铃薯之眼时，就会触发该段对话。

# thrown_eye
当玩家在完成之后首次使用马铃薯之眼后，就会触发该段对话。

对话完成后，玩家会获得一本[成书](成书.md)（/]|;|$}}|link=none|mod=v}}|$|;}}）。随后会引出对话。

# got_book

# found_portal
当玩家扔出的马铃薯之眼因靠近废弃马铃薯传送门而向下飞行时，或接近主世界的马铃薯传送门时，就会触发该段对话。

# portal_opened
当玩家使用毒马铃薯激活传送门底座时，就会触发该段对话。

# dimension
当玩家通过马铃薯传送门进入马铃薯维度后，就会触发该段对话。

# potato_village
当玩家在完成后进入马铃薯村庄时，就会触发该段对话。

# thrown_eye_part_two
当玩家在完成后在马铃薯维度扔出马铃薯之眼时，就会触发该段对话。

# found_colosseum
当玩家扔出的马铃薯之眼因指向角斗场而向下移动时，就会触发该段对话。

# inside_colosseum
当玩家完成后进入角斗场时，就会触发该段对话。

对话结束后，玩家会获得一个木[剑](剑.md)，随后会引出对话。

# got_sword

该对话将会循环显示，直到玩家获得“[马铃耶什，农民的传说之杖](马铃耶什，农民的传说之杖.md)”。

# got_staff
当玩家在物品栏中获得“马铃耶什，农民的传说之杖”后，就会触发该段对话。

# composted_staff
当玩家对堆肥桶使用“马铃耶什，农民的传说之杖”后，就会触发该段对话。

对话结束后，屏幕上方会显示玩家完成马铃薯事件所用的时间，该时间亦可在[统计信息](统计信息.md)中的“马铃薯事件时长”查看。
