* *讲台（Lectern）**是一种可以用来放[书](书.md)供[玩家](玩家.md)阅读的方块。

# 生成
# = 自然生成 =
讲台能在[村庄](村庄.md)的[图书馆](村庄/结构/图示#图书馆1.md)中生成。

讲台还会在[远古城市](远古城市.md)中心的红石地下室里生成。

# 破坏
挖掘讲台的合适工具是斧。

讲台被破坏后会掉落自身和内容物。

# 用途
讲台可以存放[书与笔](书与笔.md)或[成书](成书.md)，并使多个玩家可以同时阅读，但无法对书与笔进行编辑。拿着书与笔对空的讲台按下键可以把书与笔或成书放在讲台上。然后，再按键可以打开并阅读这部书。之后点击界面上的“取书”按钮可以将放在上面的书与笔或成书取下。

讲台无法被活塞移动。

# = 红石元件 =

当翻动放在讲台上的书的页面时，讲台会产生一次长度为2[游戏刻](游戏刻.md)(1[红石刻](红石刻.md))的[红石脉冲](红石电路#信号与脉冲.md)。该次脉冲可以：

* 激活毗邻（上下左右前后）的红石元件；
* 激活毗邻的[红石线](红石线.md)，提供15强度的信号；
* **[强充能](红石电路/充能与激活.md)**下方的方块至15强度。

[红石比较器](红石比较器.md)可以检测翻页进度并发出红石信号，红石信号的强度取决于书被打开的页数和总页数。书仅有1页时，红石比较器总发出15强度的信号。当书的页数多于1页时，书翻到第1页时总发出1强度的信号，而翻到最后一页时总发出15强度的信号。对于多于1页的书，红石信号强度的计算方式为：

<math>\left\lfloor 1+\frac{\text{当前打开的页码}-1}{\text{书的总页码}-1}\times14 \right\rfloor</math>，其中<math>\left\lfloor x \right\rfloor</math>表示向下取整。

讲台一次显示两页内容。只有最后一页的右侧上写有内容时，最后一页才会改变页码与红石信号强度的对应关系。因此，红石比较器检测3页的书得到的结果与检测写有内容的1页或2页的书相同，均为15强度的信号，如同红石比较器检测1页书那样。对于4页或更多页的书，红石信号强度的计算方式为：

<math>\left\lfloor 1+\frac{\left\lfloor \frac{\text{当前打开的页面中写有内容的页的最大页码数}}{2} \right\rfloor-1}{\left\lfloor \frac{\text{书的总页码}}{2} \right\rfloor-1}\times14 \right\rfloor</math>，其中<math>\left\lfloor x \right\rfloor</math>表示向下取整。

红石比较器可以隔着红石导体检测讲台。

# = 更改村民职业 =

如果一个讲台没有被[村民](村民.md)认领，则附近的任意一个失业村民有机会转变[职业](职业.md)为[图书管理员](图书管理员.md)。

# = 燃料 =
讲台可以作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，1个讲台可以烧制1.5个物品。

# = 安全保护 =

讲台属于“仅管理员可设置数据”的方块。

非管理员玩家对讲台按下+时不会复制方块实体数据，放置物品栏中已有的带有方块实体数据的讲台也不会将数据实际加载。

管理员玩家的物品栏中带有方块实体数据的讲台的物品[提示框](提示框.md)中会显示警告信息。
