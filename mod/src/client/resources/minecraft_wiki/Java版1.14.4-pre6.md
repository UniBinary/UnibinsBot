# Java版1.14.4-pre6

*页面ID: 45277* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14.4-pre6**是[Java版1.14.4](Java版1.14.4.md)的第6个预发布版，发布于2019年7月15日<ref name="article_1.14.4-pre6"></ref>，改进了性能，移除了视角在第一人称模式下的中心偏移，并修复了一些漏洞。

# 更改
# = 常规 =
* *视角**
* 移除了视角在第一人称模式下的中心偏移。

* *性能**
* 改进了性能。
* 改进了高速移动时区块的加载性能。

# 修复

* *其他漏洞**
* 修复了一个内存泄漏漏洞。<ref name="article_1.14.4-pre6"/></onlyinclude>
