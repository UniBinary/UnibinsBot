# Java版pre-Classic rd-132328

*页面ID: 34811* | *来源: Minecraft Wiki*

<onlyinclude>

* *rd-132328**是2009年5月13日21:28（UTC）制作完成的[pre-Classic](Java版pre-Classic.md)版本。<ref></ref>

# 新内容
# = 生物 =
* *[人类](生物（已移除实体）.md) <ref></ref>**
* 默认会以100只的数量自然生成在世界中。
* 会随意移动，无正式AI。
* 不会保存到文件中。
* * 退出游戏后重新进入，已生成的人类会被立即移除并重新生成新的人类。
* 源自[Notch](Notch.md)此前制作的废弃项目[Zombie Town](Zombie Town.md)。
* 在代码中被称为“僵尸”。</onlyinclude>

# 启动器版
启动器中的该版本由源代码编译而来，且为符合实际情况修改了日期为2009年，因此从技术层面而言并非真正的原版。

# 你知道吗
* 此版本中，若玩家在地下生成，会缓缓上升到地面。但玩家实际上不可能在地下生成，因此该特性无法正常触发。
