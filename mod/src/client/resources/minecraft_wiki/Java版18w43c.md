# Java版18w43c

*页面ID: 36855* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w43c**是[Java版1.14](Java版1.14.md)的第3个快照，发布于2018年10月26日<ref></ref>，更新了[调试屏幕](调试屏幕.md)，改善了游戏性能，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 在单人游戏中按下会显示服务器端每秒刻的图表。
* 将刻度时间加入到图表中以帮助寻找卡顿。

# 更改
# = 常规 =
* *性能**
* 现在生物容量不再能无限增长。
* 改进客户端和服务器的通讯性能。
* 改进了性能。
