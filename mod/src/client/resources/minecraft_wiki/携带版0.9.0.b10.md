# 携带版0.9.0.b10

*页面ID: 28889* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.9.0 alpha build 10 (RC2)**是[v0.9.0 alpha](携带版0.9.0.md)的第10个测试版，也是第2个发布候选，发布于2014年6月26日，修复了一些漏洞。

# 更改
# = 方块 =
* *[西瓜](西瓜.md)**
* 减少[丛林](丛林.md)中[西瓜](西瓜.md)的生成数量。

* *[梯子](梯子.md)**
* [梯子](梯子.md)的碰撞箱略微变薄。

# 修复
* *修复了10个漏洞**
* 现在可以在栅栏和墙的顶部放置方块。
* 现在可以破坏告示牌和火把后方的方块。
* 修复了一些关于树叶的问题。
* 刷怪笼不再无视火把的光照。
* 仙人掌不再能够并排放置。
* 破坏树叶和高草丛时的粒子不再是灰色的。
* 修复了一个随机发生的潜在崩溃。
* 修复了部分液体可能会停止流动的问题。
* 修复了多人游戏中的生成位置问题。
* 创造模式物品栏中的选项卡不再会略微偏移。</onlyinclude>
