# Java版Classic 0.0.16a 02

*页面ID: 35264* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.16a_02**是的一次更新，发布于2009年6月7日<ref></ref><ref>[Testvan的IRC日志](#Testvan logs.md)：“*[12:41] <@Notch> do you get a nice "the server is full" message on the site now?*”（18:41 UTC）</ref>，正式加入了[多人游戏](多人游戏.md)，并修复了一些漏洞。

# 更改
# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 正式发布。<ref></ref>

# 修复
* *修复了4个漏洞**
* 修复了一个连接问题。
* 部分修复了。
* 修复了登录屏幕上的闪烁。<ref>[Testvan的IRC日志](#Testvan logs.md)：“*[12:10] <Empty> Notch when I log in the "Today's message screen" flickers.*”[...]“*[12:11] <@Notch> i shall make fix*”（2009年6月7日，18:10 UTC）</ref>
* 修复能在多人游戏生成生物的问题。<ref>[Testvan的IRC日志](#Testvan logs.md)：“*[12:12] <Empty> I wonder can other people see the mobs I spawn*”[...]“*[12:14] <IDTL> Spawning mobs should probably be disabled on multiplayer*”（2009年6月7日，18:12 UTC）</ref></onlyinclude>

# 重新上传
该版本的客户端于6月8日10:26（UTC）被第一次重新上传，以进行一些测试。<ref>[Rotab's IRC logs](#Rotab logs.md): "*(12:26:10) <@Notch> if anyone is available, I need some more mp testing done. =)*" [...] "** Notch changes topic to: http://www.minecraft.net/ | mp test at http://www.minecraft.net/mptest.jsp*" (2009年6月8日 10:26 UTC)</ref>

该版本的客户端于6月8日10:36（UTC）被第二次重新上传，以修复不可用输入流相关的漏洞，但并未成功。<ref>[Rotab's IRC logs](#Rotab logs.md): "*(12:33:34) <KiT_> failed to connect. mp test over? [...] (12:33:58) <@Notch> hold, fixing a bug.. [...] server's up*" (2009年6月8日 10:33至10:36 UTC)</ref>

该版本的客户端于6月8日10:47（UTC）被第三次重新上传，以修复来自的不可用输入流漏洞。<ref>[Rotab's IRC logs](#Rotab logs.md): "*(12:41:25) <@pyl> still unable to get input stream for minecraft.jar, giving up*" [...] "*(12:47:43) <@Notch> restarting server, I think I got the bug now*" (2009年6月8日 10:41至10:47 UTC)</ref><ref><samp>.jar</samp>文件的编译时间是12:47（UTC+2）。</ref>
