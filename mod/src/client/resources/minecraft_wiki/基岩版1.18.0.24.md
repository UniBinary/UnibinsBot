# 基岩版1.18.0.24

*页面ID: 90450* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.0.24**是[基岩版1.18.0](基岩版1.18.0.md)的第5个测试版，发布于2021年10月27日<ref></ref>，加入了打开旧世界时出现的警告，调整了一些特性，并修复了一些漏洞。

# 更改
# = 生物 =
* *[美西螈](美西螈.md)**
* 提高了生成概率。

* *[鱼](鱼.md)**
* 现在会远离美西螈。

* *[岩浆怪](岩浆怪.md)**
* 现在会主动攻击[铁傀儡](铁傀儡.md)。

* *[史莱姆](史莱姆.md)**
* 不再会攻击[雪傀儡](雪傀儡.md)。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 更改了下列生物群系的英文名称和ID，以匹配：


* *[废弃矿井](废弃矿井.md)**
* 现在使用[原木](原木.md)来生成支柱，而不是[木头](木头.md)。

* *[沙砾](沙砾.md)**
* 现在会在Y=0以下处生成。

* *[种子](种子（世界生成）.md)**
* 再次重写了种子系统，世界生成不再与之前测试版相似。<ref></ref><ref></ref>

# = 常规 =
* *世界**
* 加入了打开或升级旧世界时出现的警告，其上有一个备份世界勾选项。
* * 开启该选项后，会自动创建一个备份世界。

# 修复
* *方块**
* 现在玩家又可以通过按住“放置”键来连续放置并收回水、熔岩或细雪了。（）
* 如床、画等需要支撑的方块或实体不再能够放置在光源方块上。（）

* *废弃矿井**
* 废弃矿井的支柱不再会生成在熔岩上。（）
* Y=0以下的废弃矿井中不再会生成泥土。（）
* 现在废弃矿井会以原木代替木头来生成支柱。（）

* *游戏内容**
* 修复了部分世界的存储大小会不正常骤增，从而导致存储空间占用过多的问题。（）
* 修复了手持小型垂滴叶对着较浅的水源时，该水源会变亮的问题。（）
* 现在大型花的上半部分被水流破坏时，其只会掉落一个物品。（）
* 修复了能够透视地形的问题。
* 教育版特性：NPC不再拥有“空闲”音效。（）
* 现在玩家在Y轴为负数的区域吃下紫颂果会被正确传送。（）

* *物品**
* 调整了点燃的TNT、滞留药水、喷溅药水和附魔之瓶在远离玩家移动时的平滑度。（）
* 部分教育版物品不再会触发提示。（）
* 现在所有地被植物均可放置在菌丝体上。（）

* *生物**
* 提高了美西螈在繁茂洞穴中的生成概率。
* 鱼现在会试图远离美西螈。
* 岩浆怪现在会主动攻击铁傀儡，且史莱姆不再会攻击雪傀儡。（）
* 现在寻路中的幻翼在试图穿过山地而被卡住时，其会正确更改寻路方向。（）

* *世界生成**
* 调整了矿石分布以同步Java版。
* 沙砾现在会在世界生成期间替换深板岩生成。（）
* 恶地生物群系中的金矿石不再会过量生成。
* 冻洋生物群系中不再会生成熔岩。（）
* 深层铜矿石现在会正确自然生成。
* 更新了洞穴与山崖中新加入的山地生物群系变种的英文名称，以匹配Java版。

* *用户界面**
* 修复了文本中图标的渲染问题，以避免图标颜色失真。

* *技术性**
* 修复了不在JSON中指定的生物默认生成能力。
* 提升了中的不可移动生物的性能。</onlyinclude>
