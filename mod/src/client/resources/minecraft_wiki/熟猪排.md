# 熟猪排

*页面ID: 7259* | *来源: Minecraft Wiki*

* *熟猪排（Cooked Porkchop）**是一种通过[猪](猪.md)和[疣猪兽](疣猪兽.md)着火时死亡掉落的[食物](食物.md)类[物品](物品.md)。

# 获取
# = 生物掉落物 =

# = 烹饪 =
生猪排能在[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或[营火](营火.md)中被烹饪，每个在熔炉输出区拿出的熟猪排给予0.35[经验](经验.md)（每组22.4经验）。

# = 交易 =

# = 礼物 =

[屠夫](屠夫.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷熟猪排。

# = 箱子战利品 =

# 用途
# = 食物 =

手持熟猪排按住键即可食用，每个熟猪排可以回复。

# = 狼 =
熟猪排能用来吸引、治疗或繁殖驯服的[狼](狼.md)，也可以使已驯服的幼年狼的剩余生长时间加快10%。

# = 猪灵 =
[猪灵](猪灵.md)会主动捡起[生猪排](生猪排.md)和熟猪排。

猪灵不会主动搜寻生猪排和熟猪排，但会[拾取](物品（实体）#拾取.md)它们，且拾起后10秒内不会再捡起这两种物品。
