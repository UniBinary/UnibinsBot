# 原主机版TU27、CU15、1.18

*页面ID: 77633* | *来源: Minecraft Wiki*

* *TU27/CU15/1.18**是[原主机版](原主机版.md)的一次更新，发布于2015年7月24日。<ref></ref><ref></ref>

# 新内容
* *常规**
* XBONE、PS3、PS4、PSV：加入Greek Mythology[混搭包](混搭包.md)试用内容。
* *方块**
* 仅[创造模式](创造模式.md)：金合欢木与深色橡木[原木](原木.md)、[木板](木板.md)、[栅栏](栅栏.md)、[栅栏门](栅栏门.md)、[门](门.md)、[台阶](台阶.md)、[楼梯](楼梯.md)。

# 修复
* *修复了12个漏洞**
* XBONE、PS3、PS4、PSV：修复了在接近村庄、沙漠神殿和丛林神殿时，加载的保存中只有部分被加载的村庄、神殿的崩溃漏洞。
* 修复了狼无法正确受到伤害的漏洞。
* PS3、PS4：修复了禁用天气周期和保存导致其他主机选项设置错误的漏洞。
*  - 发射器的制作配方接受损坏的弓。
*  - 胡萝卜钓竿的制作配方可以接受损坏的钓鱼竿。
*  - 没有权限的玩家可以让你的宠物站起来。
*  - 当动物被杀死时，拴绳会留在栅栏上。
*  - 进入地图后，游戏崩溃。
*  - 合成橡木门时只给予1个门而不是3个门。
*  - PS4：加载世界后约5分钟游戏关闭。
*  - PS3、PS4：在世界上玩创造模式会使游戏随机关闭。
*  - 新栅栏的拴绳漏洞。
