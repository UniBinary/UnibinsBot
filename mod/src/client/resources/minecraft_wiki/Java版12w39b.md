# Java版12w39b

*页面ID: 33083* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w39b**是[Java版1.4.2](Java版1.4.2.md)的第9个快照，发布于2012年9月28日<ref></ref>，发布以修复[12w39a](12w39a.md)里的漏洞和崩溃。

# 新内容
# = 方块 =
* *[刷怪笼](刷怪笼.md)**
* 加入了一些自定义刷怪笼的设定。
* * 现在距离和最大生成速度都可以自定义了。

# = 物品 =
* *自定义[药水](药水.md)**
* 必须用地图编辑器编辑才有效。
* 可以自定义具有多重功效的药水。

# = 命令格式 =
* ***
* 加入了一个命令变量。
* * 在数字后面使用<code>L</code>代表等级，而不是经验数量。
* ** 例如会给予玩家四级经验。

* *[目标选择器](目标选择器.md)**
* [命令方块](命令方块.md)加入了新参数。
* * <code>l</code>和<code>lm</code>代指相对最高等级和相对最低等级玩家。
* * <code>r</code>和<code>lr</code>代指玩家会受影响的最大和最小范围。

# 修复
* *修复了7个漏洞**
* 修复了方块放置时的光照问题。<ref></ref>
* 游戏性能比以前要好了。
* 修复了关于“无底深渊”的问题。
* 修复了南瓜灯从错误的方向发出更强的光的问题。
* 修复了女巫的纹理很奇怪的问题。
* 部分修复了下界卡顿的问题。解决办法是使服务器执行一些原先由客户端执行的工作，而以前的做法会稍微增加一些区块加载的时间。<ref></ref>
* 修复了一些关于倒置的台阶、楼梯和耕地的光照问题。</onlyinclude>
