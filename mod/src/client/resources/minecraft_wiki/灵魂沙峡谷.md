* *灵魂沙峡谷（Soul Sand Valley）**是一种生成于[下界](下界.md)的大型洞穴状生物群系。

# 描述
灵魂沙峡谷主要由[灵魂沙](灵魂沙.md)和[灵魂土](灵魂土.md)构成，临近熔岩海处还会出现[沙砾](沙砾.md)。整个生物群系中，[灵魂火](灵魂火.md)零星地燃于地表，高大的[玄武岩柱](玄武岩柱.md)贯通上下，[下界化石](下界化石.md)散布于谷地之间，[荧石堆](荧石堆.md)罕见地生成在生物群系顶部偶然裸露的[下界岩](下界岩.md)的下方。这里植被稀疏，只有少量的[绯红菌索](绯红菌索.md)和[蘑菇](蘑菇.md)自然生长在地表。迷雾呈阴暗的青色（拥有时则是亮青色），空气中的粒子呈灰色。[洞穴](洞穴.md)、[下界要塞](下界要塞.md)甚至[堡垒遗迹](堡垒遗迹.md)均可能生成于此。

# = 声音 =
当玩家处于灵魂沙峡谷时，就会开始播放此生物群系的环境音效，还会播放几种通用的[下界音乐](下界音乐.md)，以及“[So Below](Minecraft: Nether Update (Original Game Soundtrack)#音轨列表.md)”曲目。
