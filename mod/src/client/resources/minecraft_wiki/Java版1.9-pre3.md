# Java版1.9-pre3

*页面ID: 20410* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.9-pre3**是[Java版1.9](Java版1.9.md)的第3个预发布版，发布于2016年2月24日<ref></ref>，重新加入了[1.8.9](Java版1.8.9.md)中的声音事件，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[声音事件](Java版声音事件.md)**
* 加入了在快照中不可用的、在1.8.9及以前可用的[声音事件](Java版声音事件.md)：
* * <code>block.note.pling</code>
* * <code>entity.bat.loop</code>
* * <code>entity.cat.hiss</code>
* * <code>entity.ghast.scream</code>
* * <code>entity.small_slime.jump</code>
* * <code>entity.wolf.howl</code>
* 不在游戏中使用的新的声音事件：
* * <code>entity.player.breath</code>

# 更改
# =生物=
* *[马](马.md)**
* 将边界箱宽度由1.4格改为1.3964844格。

# = 常规 =
* *[制作人员名单](制作人员名单.md)**
* [Thomas Guimbretière](Thomas Guimbretière.md)被添加到"Game design, programming and graphics"后。
* Samuel Åberg被添加到"Music and sound"后。
* [Erik Broes](Erik Broes.md)被添加到"Game design, programming and graphics"而不是"Programming"。

* *[字幕](字幕.md)**
* <code>subtitles.entity.magmacube.jump</code>变为<code>subtitles.entity.magmacube.squish</code>。
* <code>subtitles.entity.slime.jump</code>被移除，留下<code>subtitles.entity.slime.squish</code>。
