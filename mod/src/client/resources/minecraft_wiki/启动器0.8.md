# 启动器0.8

*页面ID: 49310* | *来源: Minecraft Wiki*

* *0.8**是一个在2013年5月20日发布的[启动器](启动器.md)版本。

# 修复
*  - 修复了Mac中最小化Minecraft图标较低分辨率的问题。
*  - 修复了版本列表不显示的问题。
*  - 修复了新启动器未将任何Java选项传递给Minecraft的问题。
