# Java版1.12-pre4

*页面ID: 30027* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.12-pre4**是[Java版1.12](Java版1.12.md)的第4个预发布版，发布于2017年5月18日<ref></ref>，为命令加入了新的参数，并修复了一些漏洞。

# 新内容
# = 命令 =
* ***
* 加入了新的参数：
* * <code>-{}-if <选择器></code> - 仅在指定了特定选择器时运行函数。（目前仅支持1）
* * <code>-{}-unless <选择器></code> - 仅在未指定特定选择器时运行函数。（目前仅支持0或2+）

# 更改
# = 物品 =
* *[地图](地图.md)**
* [床](床.md)现在在地图上颜色变得正确了。

# 修复

|117544|在地图上不显示染色床的颜色。

|117564|在没有进度完成的时候点击“进度”按钮会导致游戏崩溃。
|117579|配方书中的工具和武器选项卡的图标没有居中。
|117580|经常出现当合成栏中有一格有足够的物品时，配方书不会更新合成栏中的内容的现象。
