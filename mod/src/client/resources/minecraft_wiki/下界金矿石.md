# 下界金矿石

*页面ID: 56246* | *来源: Minecraft Wiki*

* *下界金矿石（Nether Gold Ore）**是一种生成于[下界](下界.md)的[矿石](矿石.md)，是[金粒](金粒.md)的来源之一。

# 生成
# = 自然生成 =
下界金矿石以[团簇](团簇.md)的形式自然生成于[下界](下界.md)Y=10至117高度范围间的[下界岩](下界岩.md)之间，矿团大小为1-10个方块。矿团在[玄武岩三角洲](玄武岩三角洲.md)生物群系之外每[区块](区块.md)生成10次，在玄武岩三角洲每区块生成20次。

# 获取
下界金矿石只能通过破坏下界金矿石获得。

# 破坏
挖掘下界金矿石的合适工具是镐。下界金矿石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，下界金矿石被破坏后会掉落2-6个[金粒](金粒.md)和，挖掘工具的[时运](时运.md)魔咒会增加金粒的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。使用时运III的镐平均获得8.8个金粒，略低于合成1个金锭所需的9个金粒，因此使用[精准采集](精准采集.md)的镐挖掘并烧炼，获得材料数量的期望值更高。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，下界金矿石被破坏后会掉落自身。

# 用途
# = 烧炼配方 =

# = 猪灵 =
在非和平难度下，无论玩家是否装备了[金质盔甲](盔甲.md)，成年[猪灵](猪灵.md)看见或听见玩家破坏下界金矿石后会与之敌对。

# 你知道吗
* 2017年，[Jeb](Jeb.md)对[Reddit](wikipedia:Reddit.md)上请求加入下界金矿石的建议感兴趣。<ref></ref>
* * 有趣的是，Reddit上的帖子也提及若玩家挖掘下界金矿石，[僵尸猪人](僵尸猪人.md)会被激怒。Jeb对此也感兴趣。
* 在现实中，由于石英会产生[压电效应](wzh:压电效应.md)，金矿常伴生于石英矿，而Minecraft的下界中恰好同时出产这两种矿物。
