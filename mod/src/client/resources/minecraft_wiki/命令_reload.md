# 命令/reload

*页面ID: 39805* | *来源: Minecraft Wiki*

}}

重新加载[数据包](数据包.md)，重新加载[行为包](行为包.md)中的[函数](基岩版函数.md)和脚本。

# 用法
如果数据包或行为包含有无效数据（例如错误的配方格式），更改将不会应用，游戏会使用先前的数据。

数据包的等实验性注册项的数据必须依赖于世界加载。<ref></ref><ref></ref><ref></ref><ref></ref><ref></ref>这些注册项不能使用<code>/reload</code>命令重新加载，只能在重新进入世界时加载。

# 语法
* **Java版**
   <code>reload</code>
* **基岩版**
   <code>reload [all: reload_all]</code>

# 参数
：
   必须为<code>all</code>，使玩家退出并重新加入世界，同时重载所有行为包和[资源包](资源包.md)。仅非[BDS](BDS.md)可用。
