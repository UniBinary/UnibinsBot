# Java版1.10.2

*页面ID: 22574* | *来源: Minecraft Wiki*

* *1.10.2**是的一次次要更新，发布于2016年6月23日<ref></ref>，修复了[1.10.1](Java版1.10.1.md)加载世界时导致[崩溃](崩溃.md)的漏洞。此版本兼容1.10和1.10.1的服务端。
