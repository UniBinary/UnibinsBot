# 末地传送门（方块）

*页面ID: 7799* | *来源: Minecraft Wiki*

* *末地传送门（End Portal）**是当[末地传送门](末地传送门.md)建构成形时会生成出现的方块。接触到它的实体会被传送到[末地](末地.md)或从末地被传送到[主世界](主世界.md)。

# 生成
# = 末地传送门 =
末地传送门方块是激活的[末地传送门](末地传送门.md)结构的一部分。

# = 返回传送门 =
末地传送门方块是激活的[返回传送门](返回传送门.md)结构的一部分。

返回传送门会在状态更新时重新生成。

# 获取
末地传送门方块没有对应的物品形式。

末地传送门方块的物品形式只能通过编辑物品栏获得。

# 破坏
末地传送门不能被挖掘破坏。

末地传送门被破坏后不会掉落。

# 用途
末地传送门方块可以用来传送玩家进出[末地](末地.md)。当实体位于[主世界](主世界.md)、[下界](下界.md)或时，接触到末地传送门方块会立刻被传送到末地。当实体位于[末地](末地.md)时，它将会被传送到主世界。单独的末地传送门方块依然有效。

当实体通过末地传送门方块进入末地时，其会出现在[黑曜石平台](黑曜石平台.md)上，每次传送都会使黑曜石平台重新生成。通过末地传送门方块进入主世界的玩家会被传送到他们的[个人出生点](个人出生点.md)，其他实体会被传送到[世界出生点](世界出生点.md)。

如果一个[自定义](自定义.md)世界没有定义维度，末地传送门仍然可以被激活并创建末地传送门方块，但其不能传送任何实体。

# = 特性 =
* 末地传送门方块可以在创造模式下破坏，且不会影响相邻的末地传送门。
* 类似于[下界传送门](下界传送门.md)，末地传送门方块只能够在末地传送门结构里出现，当此方块被更新，同时被检测到不处于末地传送门中时会被移除。
* 玩家无法从下面看见末地传送门方块的纹理。
* 末地传送门方块不会减少摔落伤害。
* 末地传送门方块的顶部表面为}}/}}格高。
* 末地传送门方块没有常规实体纹理的图片，[末地折跃门方块](末地折跃门方块.md)也是如此。
* [TNT](TNT.md)和其他爆炸物不能炸毁末地传送门方块。
* 被骑乘的实体及其骑乘者接触末地传送门方块时不会被传送。
* [末影龙](末影龙.md)不能被末地传送门传送。
* [凋灵](凋灵.md)不能被末地传送门传送。
* 末地传送门方块可能因为末地传送门框架的位置或方向不同而出现在不同的位置。<ref></ref>
* 末地传送门方块不能被[凋灵](凋灵.md)和[末影龙](末影龙.md)破坏。

# = 光源 =
末地传送门会发出亮度等级为15的光。
