# Minecraft LIVE

*页面ID: 90125* | *来源: Minecraft Wiki*

[200px|缩略图|Minecraft LIVE的logo](File:Minecraft Live September 2025 Logo.png.md)

* *Minecraft LIVE**（前称**MINECON Earth**及**MINECON Live**）是每半年举办一次的线上直播活动，活动通常会公布下一次游戏更新内容，以及其他*[Minecraft](Minecraft.md)*相关资讯。

# MINECON Earth

# = 2017 =

[200px|缩略图|MINECON Earth 2017的logo](File:MINECON Earth logo.png.md)

2017年8月8日，**MINECON Earth**被宣布将在2017年11月18日举行，会在livestream平台上直播。<ref></ref>同时被宣布为官方社区活动，活动特点主要囊括了YouTuber，streamer，游戏联赛，服装竞赛等内容。<ref></ref>门票免费参加活动，与会者可以在线购买MINECON品牌商品，送到你的家里。**MINECON Earth**被宣布为“官方社区活动”，由社区主导的合作伙伴Minefaire，Minevention和Blockfest举办。

最终“夜空之怪”（即[幻翼](幻翼.md)）在生物投票当中胜出。

# = 2018 =

[200px|缩略图|MINECON Earth 2018的logo](File:MINECON Earth 2018 Logo.png.md)

* *MINECON Earth 2018**于9月29日在Minecraft官方网站及网易中国版客户端举行现场直播。

2018年4月10日，宣布**MINECON Earth 2018**于2018年9月29日举行。

在**MINECON Earth 2018**期间，[村庄与掠夺](村庄与掠夺.md)更新拉开序幕，并展示了其中的一些内容。<ref></ref>

最终[针叶林](针叶林.md)在生物群系选举当中胜出。

# MINECON Live
# = 2019 =

[200px|thumb|MINECON Live 2019的logo](File:MINECON Live 2019 Logo.png.md)

* *MINECON Live 2019**于美国东部时间9月28日正午12时开始，于下午2时结束，是一场在Minecraft官方网站、YouTube、Twitch、Mixer及网易中国版支持的直播平台举行的现场直播。

MINECON Live 2019公布了下界更新及其部分特性。

最终[山地](山地.md)在生物群系投票当中胜出。

# Minecraft Live
# = 2020 =

[200px|thumb|Minecraft Live 2020的logo](File:Minecraft Live 2020 Logo.png.md)

* *Minecraft Live 2020**于美国东部时间10月3日正午12时开始，于13:30分结束。2020年的活动原计划为**[Minecraft Festival](Minecraft Festival.md)**，但受[COVID-19疫情](wzh:2019冠状病毒病疫情.md)影响，该活动由Minecraft Live 2020取代，原计划的Minecraft Festival的举办日期待定。

直播公布了[洞穴与山崖](洞穴与山崖.md)更新及其部分特性，包括洞穴生成的优化和新生物山羊等内容。在新一轮生物投票当中，[发光鱿鱼](发光鱿鱼.md)最终胜出并将加入该次更新。<ref></ref>

# = 2021 =

[200px|thumb|Minecraft Live 2021的logo](File:Minecraft Live 2020 Logo.png.md)

* *Minecraft Live 2021**直播活动于2021年10月16日举行。<ref></ref>

直播公布了[荒野更新](荒野更新.md)及其部分特性，同时按照往年的惯例举行新一轮生物投票，[悦灵](悦灵.md)最终胜出并加入该次更新。<ref></ref><ref></ref>

# = 2022 =

[200px|thumb|Minecraft Live 2022的logo](File:Minecraft Live 2022 Logo.png.md)

* *Minecraft Live 2022**直播活动于2022年10月15日举行。<ref></ref>

本次活动按照惯例举行新一轮生物投票，但投票在[启动器](启动器.md)、[Minecraft.net](Minecraft.net.md)以及一个专门开设的基岩版服务器中举行，而不再通过Twitter进行。[嗅探兽](嗅探兽.md)最终胜出并加入1.20的更新。

直播公布了将在[Java版1.20](Java版1.20.md)和[基岩版1.20.0](基岩版1.20.0.md)加入的部分特性，同时公布了7种新的默认皮肤。

# = 2023 =

[200px|thumb|Minecraft Live 2023的logo](File:Minecraft Live 2023 Logo.png.md)

* *Minecraft Live 2023**直播活动于2023年10月15日举行。<ref></ref>

本次活动按照惯例举行新一轮生物投票，投票在[启动器](启动器.md)、[Minecraft.net](Minecraft.net.md)以及一个专门开设的基岩版服务器中举行。[犰狳](犰狳.md)最终胜出并将加入此后的更新。

直播公布了将在[Java版1.21](Java版1.21.md)和[基岩版1.21.0](基岩版1.21.0.md)加入的部分特性。

# = 2024 =

[200px|thumb|Minecraft Live 2024的logo](File:Minecraft Live 2024 Logo.png.md)
* *Minecraft Live 2024**直播活动于2024年9月28日举行。<ref></ref>

不同于往届，本次活动不再举行生物投票，也不再公布大型更新内容，取而代之是小更新内容演示。

直播公布了Minecraft下一次小更新的正式名称[勇气之袋](勇气之袋.md)，还公布了之后小更新的部分更新内容，但并未公布其正式名称。

# = 2025 =

[200px|thumb|Minecraft LIVE - March 2025的logo](File:Minecraft Live March 2025 Logo.png.md)
* *Minecraft LIVE - March 2025**直播活动于2025年3月23日举行。<ref></ref>

直播公布了[春意盎然](春意盎然.md)小更新的正式名称和发布日期，并宣布了[下個小更新](追逐天空.md)的更新内容，并带来了一些关于[A Minecraft Movie](A Minecraft Movie.md)的独家消息。<ref></ref><ref></ref>

[200px|thumb|Minecraft LIVE – September 2025的logo](File:Minecraft Live September 2025 Logo.png.md)
* *Minecraft LIVE – September 2025**直播活动于2025年9月27日举行。<ref></ref>

直播公布了[铜器时代](铜器时代.md)小更新的发布日期，并宣布了之后的小更新[群骑纷争](群骑纷争.md)及其更新内容。<ref></ref>
