# Java版1.14.4-pre3

*页面ID: 45011* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14.4-pre3**是[Java版1.14.4](Java版1.14.4.md)的第3个预发布版，发布于2019年7月8日<ref></ref>，加入了新的闪烁标语，并尝试修复了一个关于区块加载延迟的重大漏洞。

# 新内容
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了“Ping the human!”

# 更改
# = 命令格式 =
* *[命令参数类型](命令参数类型.md)**
* 向内建参数类型加入了 <code>brigadier:long</code>。</onlyinclude>
