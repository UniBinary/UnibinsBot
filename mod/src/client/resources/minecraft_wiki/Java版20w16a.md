# Java版20w16a

*页面ID: 59387* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w16a**是[Java版1.16](Java版1.16.md)的第12个快照，发布于2020年4月15日<ref name="20w16a"></ref>，加入了[堡垒遗迹](堡垒遗迹.md)、[废弃传送门](废弃传送门.md)、[锁链](锁链.md)、新的[音乐唱片](音乐唱片.md)和新的物品标签，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[锁链](锁链.md)**
* 生成于[堡垒遗迹](堡垒遗迹.md)和[下界](下界.md)的[废弃传送门](废弃传送门.md)中。
* 可用两个铁粒和一个铁锭合成。
* 可被活塞或黏性活塞推拉。

# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* 添加了音乐唱片Pigstep。
* * 只能在[堡垒遗迹](堡垒遗迹.md)的箱子中被发现。
* * 唱片颜色为红色而不是黑色。
* * 在[唱片机](唱片机.md)中播放时，与之相连的[红石比较器](红石比较器.md)将输出强度为13的红石信号。
* * 不同于其他的音乐唱片，该唱片是由[Lena Raine](Lena Raine.md)而不是[C418](C418.md)制作的。

# = 世界生成 =
* *[堡垒遗迹](堡垒遗迹.md)**
* 生成在除[玄武岩三角洲](玄武岩三角洲.md)外的所有[下界生物群系](生物群系#下界.md)中。
* 生成四种类型的结构：
* * 桥
* * 疣猪兽棚
* * 居住区
* * 藏宝室
* 这是音乐唱片“Pigstep”和猪灵旗帜图案的唯一来源。
* [猪灵](猪灵.md)和[疣猪兽](疣猪兽.md)会在此生成。
* 部分结构会生成[岩浆怪](岩浆怪.md)的[刷怪笼](刷怪笼.md)。

* *[废弃传送门](废弃传送门.md)**
* [下界传送门](下界传送门.md)的破碎残骸。
* 在[主世界](主世界.md)和下界中生成。
* 可能会被埋在地下或水中。
* 会生成战利品箱、哭泣的黑曜石和金块。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了新的物品标签。
* * 包括了除"Pigstep"外的所有的唱片。
* * 用于决定[苦力怕](苦力怕.md)可掉落的唱片。

# 更改
# = 方块 =
* *[雕纹下界砖块](雕纹下界砖块.md)**
* 更改了纹理，上面的图像现在看起来更像是[骷髅头颅](骷髅头颅.md)或[凋灵骷髅头颅](凋灵骷髅头颅.md)。

* *[哭泣的黑曜石](哭泣的黑曜石.md)**
* 现在会出现在[废弃传送门](废弃传送门.md)和[堡垒遗迹](堡垒遗迹.md)的战利品箱里。

* *[镶金黑石](镶金黑石.md)**
* 现在会出现在[堡垒遗迹](堡垒遗迹.md)里。

* *[拼图方块](拼图方块.md)**
* 在GUI中加入了一个按钮，可以根据给定的生成深度从拼图方块生成一个拼图结构。

* *[石英砖](石英砖.md)**
* 改进了纹理，底部一排砖块向右移动了约块。

* *[结构方块](结构方块.md)**
* 结构的最大可选尺寸从32格增加到了48格。

# = 物品 =
* *[旗帜图案](旗帜图案.md)**
* 猪灵旗帜图案现在会出现在堡垒遗迹里。这使得该物品有了获取途径。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 增加了[玄武岩三角洲](玄武岩三角洲.md)中[熔岩](熔岩.md)池的数量。

# = 常规 =
* *其他**
* 加入了JMX MBean，用于监测服务器的每刻耗时。

* *[标签](Java版标签.md)**
* 物品标签中的内容被同步至物品标签，并把该标签的内容改为移动后的标签加上。
