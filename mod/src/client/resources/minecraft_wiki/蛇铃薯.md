# = 马铃薯植株 =
挖掘[马铃薯植株](马铃薯植株.md)时有2%的概率掉落蛇铃薯，不受[时运](时运.md)魔咒影响。

# 用途
长按键可以食用蛇铃薯，食用时长为。食用后玩家不会回复[饥饿值](饥饿值.md)与[饱和度](饱和度.md)。

首次食用蛇铃薯后，整叠物品变为烈毒马铃薯（仅改变显示名称和纹理，数据值仍为<code>snektato</code>）。

食用烈毒马铃薯会受到魔法伤害，以及获得6秒（普通）或14秒（困难）的效果，同时发出[蜘蛛](蜘蛛.md)的嘶嘶声，但不消耗物品。
