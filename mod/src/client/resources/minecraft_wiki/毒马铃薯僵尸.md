* *毒马铃薯僵尸（Posionous Potato Zombie）**是一种类似于[僵尸](僵尸.md)的[马铃薯生物](马铃薯生物.md)。

# 生成
毒马铃薯僵尸会在[主世界](主世界.md)和[马铃薯维度](马铃薯维度.md)中[内部天空光照](亮度#内部天空光照.md)小于或等于7，且[方块光照](亮度#方块光照.md)为0的[可生成位置](生成#可生成位置.md)上生成。与僵尸和其他僵尸的变种一样，毒马铃薯僵尸也有5%的概率生成为幼年毒马铃薯僵尸。

# = 自然生成 =
# == 主世界 ==
毒马铃薯僵尸会在地表和[洞穴](洞穴.md)里罕见地生成，[蘑菇岛](蘑菇岛.md)和[深暗之域](深暗之域.md)除外。

# == 马铃薯维度 ==
毒马铃薯僵尸会在马铃薯维度的地表或[洞穴](洞穴.md)里更加频繁地生成。

# = 超级马铃薯怪召唤 =
3只毒马铃薯僵尸（可能为[鸡骑士](鸡骑士.md)）会在[超级马铃薯怪](超级马铃薯怪.md)进入第三阶段后被召唤。

# = 增援 =

在困难[难度](难度.md)下，毒马铃薯僵尸受到攻击时可能会生成增援毒马铃薯僵尸。

# = 腐败的马铃薯皮方块 =
当一个上方没有其他[实体](实体.md)的[腐败的马铃薯皮方块](腐败的马铃薯皮方块.md)接收到[随机刻](随机刻.md)时，有5%的概率在方块顶部生成一个随机的指定实体，生成为毒马铃薯僵尸的概率是40%。生成不受光照等级、玩家距离或腐败的马铃薯皮方块上方存在[固体方块](固体方块.md)的限制。

# = 转换 =
僵尸、[溺尸](溺尸.md)、[尸壳](尸壳.md)、[僵尸村民](僵尸村民.md)和[僵尸猪灵](僵尸猪灵.md)被毒马铃薯僵尸击杀后，会被转换为毒马铃薯僵尸。

# 行为

毒马铃薯僵尸会主动攻击[玩家](玩家.md)和其他僵尸类型的生物，包括僵尸、[溺尸](溺尸.md)、[尸壳](尸壳.md)、[僵尸村民](僵尸村民.md)和[僵尸猪灵](僵尸猪灵.md)。这些僵尸类型的生物被毒马铃薯僵尸击杀后，会被转换为毒马铃薯僵尸。

毒马铃薯僵尸不会主动攻击[村民](村民.md)和[流浪商人](流浪商人.md)。村民不会试图逃离毒马铃薯僵尸，但流浪商人仍会试图逃离。

毒马铃薯僵尸不会主动攻击戴着[毒马铃薯头饰](毒马铃薯头饰.md)的玩家，但如果玩家攻击它们，它们仍会进行反击。

毒马铃薯僵尸在[水](水.md)中不会转化，不会主动走上[海龟蛋](海龟蛋.md)。

# = 生物族群 =

毒马铃薯僵尸是[亡灵生物](亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉直到接触水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

毒马铃薯僵尸也是[马铃薯生物](马铃薯生物.md)，被[马铃薯削皮刀](马铃薯削皮刀.md)攻击时会额外受到伤害。
