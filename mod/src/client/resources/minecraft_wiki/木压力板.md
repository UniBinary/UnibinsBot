# 木压力板

*页面ID: 164530* | *来源: Minecraft Wiki*

* *木压力板（Wooden Pressure Plate）**是一种可以用来探测[实体](实体.md)的[方块](方块.md)。

# 生成
白桦木压力板、丛林木压力板、深色橡木压力板、红树木压力板、樱花木压力板、苍白橡木压力板、竹压力板、绯红木压力板、诡异木压力板不会生成在世界中。

# = 自然生成 =
橡木压力板生成于[平原村庄](平原村庄.md)和[试炼密室](试炼密室.md)中。

金合欢木压力板生成于[热带草原](热带草原.md)村庄。

云杉木压力板生成于[雪原](雪原.md)村庄。

# 获取

# 破坏
挖掘木压力板的合适工具是斧。

木压力板被破坏后会掉落自身。

# 用途
木压力板必须于[方块支撑形状](方块支撑形状.md)上表面中心完整或边缘完整的方块上方（包括[漏斗](漏斗.md)、[栅栏](栅栏.md)、[侦测器](侦测器.md)等），不能放置于任何方块的侧面与底部。

尝试在无效的表面放置木压力板会使其“滑入”这块空间内最近的有效附着表面。如尝试在地面上的栅栏侧面放置木压力板会使其附着到栅栏周围地面方块的顶部。

当木压力板附着的方块变动（移动、破坏、替代等），不再允许附着时或有[活塞](活塞.md)试图推动它或将方块推入其位置时，木压力板会掉落为方块物品。

[沙子](沙子.md)或[沙砾](沙砾.md)这类受重力影响的方块正下方为木压力板时不会开始下落。下落到木压力板的位置时，它会掉落为方块物品。

# = 红石元件 =

# == 开启 ==
木压力板可以被除了[投掷物](投掷物.md)及[下落的方块](下落的方块.md)以外的所有的实体（包括玩家、生物、[物品](物品（实体）.md)、[箭](箭.md)、[经验球](经验球.md)、[浮漂](浮漂.md)等）开启。

木压力板上方（具体为在木压力板所在方块的（0.125,0,0.125）到（0.875,0.25,0.875）这个长方体区域内）有符合要求的实体时（即使实体的碰撞箱只有一小部分在其中），木压力板会被**开启**。

木压力板开启时输出的[信号强度](红石电路#信号强度.md)固定为15。

木压力板开启后每20游戏刻更新一次状态。

# == 行为 ==
当开启时木压力板会：
* 激活毗邻的[红石粉](红石粉.md)，四周背对木压力板的[红石比较器](红石比较器.md)或[红石中继器](红石中继器.md)。
* 强充能木压力板下方任何[红石导体](红石导体.md)至相应等级。
* 激活毗邻的[机械元件](红石电路#机械元件.md)。

木压力板没有碰撞箱，不会阻碍实体移动。木压力板附着的方块能在它下面提供一个固体阻碍（让生物走过，让物体落在上面等等），但木压力板放置在碰撞箱较小（如栅栏）的方块上时，实体可能在开启木压力板时穿过木压力板。因此木压力板可以用来探测实体而不阻碍它们的运动。

木压力板关闭时高0.0625个方块（方块的），开启时高0.03125个方块（方块的），但它没有碰撞箱，所以不会影响它上方的实体（如木压力板上的玩家其实是站在它下面的方块上）。

# = 燃料 =
主世界木压力板可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个压力板能烧炼1.5个物品。
