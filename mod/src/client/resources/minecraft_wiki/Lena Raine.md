* *莉娜·雷恩（Lena Raine**，[/ˈleɪ.nə/](wikipedia:Help:IPA.md) [LAY-nah](wikipedia:Help:Respell.md) 或 [/ˈlɛ.nə/](wikipedia:Help:IPA.md) [LEN-ah](wikipedia:Help:Respell.md))<ref></ref>**）**（或称**Lena Chappelle**、**kuraine**）是一名音乐制作人，她为Minecraft的[下界更新](下界更新.md)创作了专辑*[Minecraft: Nether Update (Original Game Soundtrack)](Minecraft: Nether Update (Original Game Soundtrack).md)*<ref></ref>，并参与制作了专辑*[Minecraft: Caves & Cliffs (Original Game Soundtrack)](Minecraft: Caves & Cliffs (Original Game Soundtrack).md)*、*[Minecraft: The Wild Update (Original Game Soundtrack)](Minecraft: The Wild Update (Original Game Soundtrack).md)*和*[Minecraft: Tricky Trials (Original Game Soundtrack)](Minecraft: Tricky Trials (Original Game Soundtrack).md)*。<ref></ref>

# 生平
莉娜·雷恩在年轻时参加了合唱团，并接触到了音乐。她的父亲是个小提琴家<ref></ref>。通过Sonic粉丝社区，她被介绍了MIDI编曲。在那里她开始再创作她已知的歌曲，到最后她开始创作原创音乐<ref></ref> 。她后来就读于康沃尔艺术学院（Cornish College of the Arts），并获得了音乐创作学位。<ref></ref>雷恩以创作《[蔚蓝](wzh:蔚藍_(遊戲).md)》（Celeste）和《[激战2](wzh:激戰2.md)》（Guild Wars 2）游戏的配乐而闻名。在2019年，她获得了英国电影电视艺术学院奖的提名，并获得了[美国作曲家、作家和发行商协会](wzh:美國作曲家、作家和發行商協會.md)（ASCAP）年度电子游戏奖项<ref></ref><ref></ref>。她是跨性别人士<ref>[Interview: A Conversation with Lena Chappelle](https://web.archive.org/web/20200703171934/https://pinkfae.org/2015/09/03/interview-a-conversation-with-lena-chappelle/) - PinkFae Gaming: September 3, 2015</ref>。

在Minecraft的[下界更新](下界更新.md)中，她创作的四首新曲目被包含在内<ref>Winslow, Jeremy (April 15, 2020). ["Minecraft Update Adds New Blocks And More For Older PC Version"](https://www.gamespot.com/articles/minecraft-update-adds-new-blocks-and-more-for-java/1100-6476073/). *[Gamespot](wikipedia:GameSpot.md)*. [Archived](https://web.archive.org/web/20211012163831/https://www.gamespot.com/articles/minecraft-update-adds-new-blocks-and-more-for-java/1100-6476073/) from the original on October 12, 2021. Retrieved April 15, 2020.</ref>。一年后，她又重新返回了Minecraft，并与另一位电子游戏作曲家[谷冈久美](谷冈久美.md)（Kumi Tanioka）一起为[洞穴与山崖](洞穴与山崖.md)更新创作了六首曲目<ref>Leston, Ryan (October 20, 2021). [" 'Minecraft' just added some new music"](https://www.nme.com/news/gaming-news/minecraft-just-added-some-new-music-3075321). [NME](wikipedia:NME.md).
