* *幻术师（Illusioner）**是一种尚未使用的[敌对生物](敌对生物.md)，也是一种[灾厄村民](灾厄村民.md)。它可以[隐身](隐身.md)并召唤无敌的分身。

# 生成
幻术师不会自然生成，游戏中亦不存在幻术师的[刷怪蛋](刷怪蛋.md)，但可以通过命令等方式生成。

# 掉落物
当被玩家杀死时，幻术师会有8.5%的概率掉落它们的[弓](弓.md)。如果使用带有抢夺魔咒的武器杀死幻术师，弓的掉落概率为抢夺I的9.5%、抢夺II的10.5%以及抢夺III的11.5%。它们掉落的弓通常有一定程度的破损。

如果幻术师是一个[袭击队长](袭击队长.md)，那么被杀死后会掉落1个。

被[玩家](玩家.md)或驯服的[狼](狼.md)杀死的幻术师会掉落。

# 行为
[缩略图|右|250px|一个幻术师的四个分身，其本体是隐身的](File:IllusionerDuplicates.png.md)

幻术师会攻击12格内的[玩家](玩家.md)、成年[村民](村民.md)、[流浪商人](流浪商人.md)和[铁傀儡](铁傀儡.md)。它可以使用咒语和弓来攻击。

幻术师能够透过具有碰撞箱的方块发现攻击村民、流浪商人和铁傀儡。

幻术师十分敏捷，总是试图让自己与玩家之间保持一定的距离；若与玩家离得太近，它们便会后退。

幻术师有两种咒语：一种能使攻击对象[失明](失明.md)，另一种能召唤分身并使本体隐身。

尽管幻术师无法自然生成，但由命令生成的幻术师仍能参与正在发生的[袭击](袭击.md)。这意味着袭击中的幻术师有概率捡起袭击队长掉落的不祥旗帜，成为下一个袭击队长。

敲[钟](钟.md)会给予半径48格内的幻术师的[发光](发光.md)效果。

如果幻术师被其他生物所攻击，附近的幻术师会对该生物产生敌意。幻术师不会反击[女巫](女巫.md)、[劫掠兽](劫掠兽.md)和[灾厄村民](灾厄村民.md)。

幻术师会主动远离[嘎枝](嘎枝.md)。

# = 生物族群 =

幻术师是[灾厄村民](灾厄村民.md)，不会被[唤魔者](唤魔者.md)的尖牙伤害，不会被[劫掠兽](劫掠兽.md)的咆哮伤害，不会被[“Johnny”卫道士](卫道士#“Johnny”卫道士.md)攻击。幻术师与其他灾厄村民之间即使发生了误伤也不会相互攻击。幻术师可以加入正在发生的袭击，即使不是在袭击事件中被生成的。

# = 造成失明 =
只有在[区域难度](区域难度.md)大于2时，幻术师才会使用失明咒语。

每当幻术师遇到一个新的攻击对象，它会举起手臂、发出声音并生成黑色烟雾（）施法，使其受到持续20秒的效果。幻术师不会短时间内在同一个攻击对象身上多次施放这个咒语，除非它先将注意力转移到其他攻击对象上，再转移回原来的攻击对象。

这个咒语会重置幻术师的咒语冷却时间到，以及重置失明咒语的冷却时间到。

# = 生成分身 =
在幻术师参与到战斗之中时，它会先举起手臂、发出声音并产生蓝色烟雾（）施法，使自己得到持续60秒的效果，并且每当隐身效果快结束时会刷新效果。

只要幻术师具备隐身的状态效果，它都会召唤4个假的分身。幻术师的隐身咒语能使其完全隐身，无论幻术师此时手中持有或身上装备何种物品，其本体都不会显示，但幻术师的分身仍然可以显示本体所持有或装备的物品。

这些来自隐身本体的分身会轻微摇晃，只有幻术师受到攻击它们才会消失。这些分身面对的方向与其移动的位置与本体相同。每当本体使用弓攻击时，它们会使用射击的动画，虽然只有本体才能射击和造成伤害。有时当幻术师的分身生成时，其四个分身并不会离开本体，而是四个分身会重叠和本体一起，由于分身只是本体位置偏移后渲染的模型，并没有碰撞体积，此时幻术师仍会受到伤害。

当幻术师本体受到伤害时，其分身会迅速返回本体位置，又迅速到达新的位置，发出攻击信号。有时当幻术师没有受到攻击时，其分身也会自行瞬移到新的位置。当幻术师拥有攻击目标且已产生分身时，每隔35秒分身会直接达到新的位置。

如果一个隐身的幻术师得到效果，所有的分身都会发光，而本体仍然处于隐身状态。

所有的分身在技术上都属于本体，并不会生成新的实体。

一旦幻术师的[隐身](隐身.md)效果结束后，分身会消失。

这个咒语会重置幻术师的咒语冷却时间到，以及重置隐身咒语的冷却时间到。

# 你知道吗
* 与[掠夺者](掠夺者.md)相似，通过命令使幻术师手中没有弓时，幻术师将无法进行攻击，但仍然能吟诵咒语。
* 当幻术师在副手持有物品时，物品的方向是错误的。
* 据[Cojomax99](Cory Scheviak.md)说，幻术师拥有在[袭击](袭击.md)中生成的数据，尽管它不会在队伍中自然生成。
* 在[纹理更新](纹理更新.md)中，幻术师的眼睛由蓝色变成了绿色。
* [幻术师](MCD:幻术师.md)在[Minecraft Dungeons](Minecraft Dungeons.md)中的[悚伏寒冬DLC](MCD:悚伏寒冬.md)关卡里作为一种[小Boss](MCD:小Boss.md)出现，尽管其形象设计和技能与原版有所不同。
* 幻术师会在愚人节快照[20w14∞](20w14∞.md)中的随机维度里自然生成。
