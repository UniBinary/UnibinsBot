# 启动器2.1.121x

*页面ID: 65166* | *来源: Minecraft Wiki*

* *2.1.1216**（[Windows](wzh:Microsoft Windows.md)）、 **2.1.1217**（[macOS](wzh:macOS.md)）或**2.1.1218**（[Linux](wzh:Linux.md)）是一个[启动器](启动器.md)更新，发布于2018年6月28日，修复了一些漏洞。

# 添加
* 配置文件现在可以按名称或上次更改日期排序。
* 添加了“复制”按钮，可以将一个配置文件复制到另一个配置文件。

# 修复
*  - 旧版本启动器无法登录。
*  - 启动器无法将传送给1.7.2之前的Minecraft客户端。
*  - 启动器尝试在*/opt/minecraft-launcher*路径中创建logs目录。
*  - 日志的输出未自动滚动。
*  - Linux版启动器在下载1.8及以下的版本时提示<code>Missing key 'natives-linux' on libraries[*].downloads</code>。
*  - Linux启动器在启动时未创建工作目录。
*  - 新启动器会将启动器的所在的目录而不是<code>.minecraft</code>目录作为工作目录启动Minecraft。
