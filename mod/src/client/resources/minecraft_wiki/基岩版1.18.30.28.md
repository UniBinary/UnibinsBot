# 基岩版1.18.30.28

*页面ID: 94264* | *来源: Minecraft Wiki*

0以下的部分方块可能会被替换为空气。<ref></ref>}}
<onlyinclude>

* *beta 1.18.30.28**（Xbox/Windows/Android）、**Preview 1.18.30.29**（iOS/iPadOS/Xbox/Windows）是[基岩版1.18.30](基岩版1.18.30.md)的第9个测试版，发布于2022年3月23日<ref></ref><ref></ref>，在[实验性玩法](实验性玩法.md)中加入了[深暗之域](深暗之域.md)和[运输船](运输船.md)，并修复了一些漏洞。

# 更改
# = 生物 =
* *[疣猪兽](疣猪兽.md)**
* 幼年疣猪兽现在会主动攻击玩家。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“荒野更新”、“香草实验”和“假日创造者功能”子选项后才可使用。

# = 方块 =
* *[幽匿尖啸体](幽匿尖啸体.md)**
* 现在使用[精准采集](精准采集.md)附魔工具挖掘时会掉落经验，而不是掉落其自身。<ref></ref>

# = 物品 =
* *[铜制号角](铜制号角.md)**
* 更改了纹理。

# = 生物 =
* *[悦灵](悦灵.md)**
* 现在每次给予物品后会有一段短暂时间不能捡起物品。
* 现在仅会捡起与其手持物品相同的物品。
* 现在会在周围的[音符盒](音符盒.md)演奏时靠近该音符盒。
* 现在免疫主人对其造成的伤害。

# = 非生物实体 =
* *[运输船](运输船.md)**
* 一种携带着[箱子](箱子.md)、类似于[运输矿车](运输矿车.md)的载具，拥有多个木质变种。
* 可用[船](船.md)和箱子合成。
* 被摧毁时会掉落船和箱子，而不是其自身。
* 只可再乘坐1个[实体](实体.md)。

# = 世界生成 =
* *[深暗之域](深暗之域.md)**
* 一种生成于主世界极深地下的[生物群系](生物群系.md)。
* * 倾向于生成在陆地及高山区域的地下。
* 幽匿系列方块会在此生成。
* 类似于[蘑菇岛](蘑菇岛.md)，其他生物无法在此自然生成，除非借助[刷怪笼](刷怪笼.md)。

# = 技术性 =
* *数据驱动物品**
* 为伤害事件响应加入了可选参数，用于指定被生物使用时造成的固定伤害。

# 修复
* *移动端控制**
* 修复了使用新的触摸控制设计时灵敏度过低的问题。（）
* 修复了选择“触摸”交互时会出现“突出显示始终打开”选项的问题。（）
* 修复了部分设备使用新的触摸控制设计时按钮会变得太大、太亮的问题。

* *游戏内容**
* 修复了水下的熔岩湖不会在世界生成期间转变为黑曜石的问题。（）
* 生命恢复效果不再能使生物免疫伤害。（）
* 修复了刻的检查范围不包括实际加载区域中的区块的问题。
* 破坏与花共同占据同一方块空间的雪时不再会破坏花。（）

* *疣猪兽**
* 幼年疣猪兽现在会主动攻击玩家。（）

* *用户界面**
* 连续按下两次潜行键时不再会切换飞行状态。（）
* 修复了按住键疾跑时撞到障碍物后不会继续保持疾跑的问题。（）

* *技术性**
* 加入了阻止活动对象作为骑乘者而被载具骑乘的检查，以防止无限循环寻找根载具。（）
* 在骑乘具有锁定旋转方向的生物的情况下进行的旋转不再会在该生物旋转时意外截断在一侧。</onlyinclude>
