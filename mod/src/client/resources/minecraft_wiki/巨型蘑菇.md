* *巨型蘑菇（Huge Mushroom）**是一种由[蘑菇方块](蘑菇方块.md)组成的[地物](地物.md)，分为**巨型棕色蘑菇（Huge Brown Mushroom）**与**巨型红色蘑菇（Huge Red Mushroom）**。

# 种类

# = 巨型棕色蘑菇 =
巨型棕色蘑菇由中心的茎和顶部7×7的四角缺失的棕色蘑菇方块组成。

# = 巨型红色蘑菇 =
与巨型棕色蘑菇相似，在巨型红色蘑菇的中央同样有茎，但红色巨型蘑菇拥有不同的顶部。这种顶部是由五个3×3的红色蘑菇方块在顶部和四周构成的“圆顶”。

# 生成
通常情况下，一个巨型蘑菇的高度在5-7格之间，但是有的概率生成两倍高度的高巨型蘑菇，这意味着它们的高度可能达到13格。<ref>http://www.reddit.com/r/MCPE/comments/288c1n/are_there_supposed_to_be_super_tall_mushrooms/</ref>

# = 自然生成 =
巨型蘑菇自然生成于[蘑菇岛](蘑菇岛.md)、和[黑森林](黑森林.md)生物群系。

# = 人为生成 =

要种植巨型棕色蘑菇，茎的最下面四个方块（即生成在小蘑菇上方的三个方块）必须为空气或树叶，并且在这之上的7×7×（高度−3）的区域同样不能有除了空气或树叶外的任何方块。由于空间要求与顶部尺寸相匹配，可以使一个巨型棕色蘑菇在其顶部与旁边的巨型蘑菇直接接触时生长。巨型红色蘑菇仅检查茎及茎上1个蘑菇方块处的方块。“圆顶”的其余部分可以存在其他方块。像[台阶](台阶.md)一类的非完整方块、将会被替换，而其他完整方块将会得到保留。

巨型蘑菇茎下面的方块必须为[泥土](泥土.md)、[砂土](砂土.md)、[草方块](草方块.md)、[灰化土](灰化土.md)或[菌丝体](菌丝体.md)。

玩家或[发射器](发射器.md)对[蘑菇](蘑菇.md)使用[骨粉](骨粉.md)时，若满足上述条件，蘑菇有40%的概率生长成巨型蘑菇。蘑菇有约5%的概率会生长为高巨型蘑菇。

巨型蘑菇的高度不会超过其限制。
