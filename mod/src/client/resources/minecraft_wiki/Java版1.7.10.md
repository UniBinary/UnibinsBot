# Java版1.7.10

*页面ID: 13538* | *来源: Minecraft Wiki*

* *1.7.10**是的一次次要更新，发布于2014年6月26日<ref></ref>。此版本使得未来[Realms](Realms.md)的额外更新将不再需要更新游戏本身。此版本不兼容1.7.2到1.7.5的服务端，兼容1.7.6到1.7.9的服务端。

# 新内容
# = 常规 =
* *[Realms](Realms.md)**
* 玩家行为监视器。
* 支持上传自己的世界。
* 获取更多的服务器设置。
* * PvP：开/关
* * 难度：和平/简单/普通/困难
* * 出生点保护：关/1-16
* * 游戏模式：创造/冒险/生存
* * 生成动物：开/关
* * 生成怪物：开/关
* * 生成NPC：开/关
* * 命令方块：开/关

# 更改
# = 常规 =
* *[Realms](Realms.md)**
* 所有和Realms有关的模块被分离到一个单独的库中。
* * 未来Realms的额外更新将不再需要更新Minecraft版本了。
* 改进了用户界面。
