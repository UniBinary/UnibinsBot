# Java版16w40a

*页面ID: 25509* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w40a**是[Java版1.11](Java版1.11.md)的第10个快照，发布于2016年10月6日<ref></ref>，发布以修复[16w39c](16w39c.md)中的一些漏洞与崩溃。

# 更改
# = 方块 =
* *[末地传送门方块](末地传送门方块.md)**
* 中间的“星光”被改变以匹配末地传送门方块。它不再相对于玩家的视角而改变，而是相对于游戏屏幕保持静态。

# = 生物 =
* *[卫道士](卫道士.md)**
* [“Johnny”卫道士](卫道士#“Johnny”卫道士.md)现在也可以通过设置新的位元标签<code>Johnny</code>为<code>true</code>来生成，而不是重命名卫道士为“Johnny”。标签比名称的优先级更高。所以设置为<code>1b</code>的<code>Johnny</code>标签可允许卫道士在使用任意名称的同时具备“Johnny”特性，而设置为<code>0b</code>的<code>Johnny</code>标签能够让名字为“Johnny”的卫道士不具备“Johnny”特性。
* 它们的[斧](斧.md)现在属于它们的<code>HandItems</code>，不像原来完全只是视觉效果。这意味着其伤害现在能够破[盾](盾.md)。
* 卫道士的强度有了很大的提升 - 它们的攻击伤害在简单[难度](难度.md)从提高到了，普通难度从提高到了，困难难度从提高到了。

# = 命令格式 =
* *[NBT标签](NBT标签.md)**
* [恶魂火球](恶魂火球.md)、[小火球](小火球.md)、[末影龙火球](末影龙火球.md)和[凋灵之首](凋灵之首.md)：
* * <code>xTile</code>、<code>yTile</code>、<code>zTile</code>、<code>inTile</code>和<code>inGround</code>标签被移除。
* * <code>life</code>标签不再被使用于任何弹射物上，但仍能被保存/读取。
