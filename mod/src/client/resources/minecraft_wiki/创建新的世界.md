# 创建新的世界

*页面ID: 92549* | *来源: Minecraft Wiki*

* *创建新的世界（Create New World）**界面是一个允许玩家预先设置[世界](世界.md)选项的[菜单屏幕](菜单屏幕.md)。

# Java版

“创建新的世界”屏幕的主页允许玩家在创建世界之前选择一个世界名称并更改各种选项。界面包含3个标签页，选项多为可单击循环切换的按钮。

# = 游戏 =
; （编辑框）
   允许将世界名称设置为自定义字符串。该名称与中的文件夹名称相关，在该文件夹中可以找到世界存档。默认名称为“”。

;
   允许更改世界的默认的[游戏模式](游戏模式.md)。可选[生存](生存.md)（默认）、[极限](极限.md)和[创造](创造.md)。

;
   允许更改默认的[难度](难度.md)设置。可选和平、简单、普通（默认）和困难。

;
   决定是否可以使用[命令](命令.md)和[游戏模式切换器](游戏模式切换器.md)。选择创造模式后默认为打开，其他模式下默认为关闭。

;
   打开一个界面以供玩家选择需要启用的[实验性内容](实验性内容.md)。
   此处的按钮仅快照版本显示。

# = 世界 =
;
   控制[世界类型](世界预设.md)。可选默认、[超平坦](超平坦.md)、[巨型生物群系](巨型生物群系.md)、[放大化](放大化.md)、[单一生物群系](单一生物群系.md)；当按住时，亦可以选择[调试模式](调试模式.md)。选择超平坦或单一生物群系时，可点击“自定义”按钮，并修改该世界类型的设置。对于超平坦的世界类型，自定义按钮选项会显示“自定义超平坦世界”界面；若使用单一生物群系，单击按钮可进入选择生物群系的界面。

; （编辑框）
   允许更改创建[世界](世界.md)时使用的[](种子（世界生成）.md)。任何字符串都可以放在这里，若留空将随机生成。

;
   控制[结构](结构.md)（例如[村庄](村庄.md)和[沉船](沉船.md)等）是否应该在世界中生成，默认为打开。

;
   决定玩家第一次进入世界时是否应该在玩家附近生成一个装满新手战利品的[奖励箱](奖励箱.md)，默认为关闭。

# = 更多 =
;
   打开一个界面以供玩家设置将默认启用或禁用的[游戏规则](游戏规则.md)，即使允许命令被禁用。

;
   打开一个界面以供玩家选择需要启用的[实验性内容](实验性内容.md)。

;
   打开一个界面以供玩家选择需要启用的[数据包](数据包.md)。
