* *Alpha v1.2.2**是的一次次要更新，发布于2010年11月10日<ref>从该版本的<code>.jar</code>文件可知，两个版本分别发布于15:24和18:38（UTC）。</ref>，增加了更多动画，并做了一些小更改及修复。

# 新内容
* *常规**
* 加入了更多动画设定。
* 加入了对[纹理包](纹理包.md)的支持。

# 更改
* *[熔岩](熔岩.md)**
* 现在在[下界](下界.md)流的更远。

* *主菜单**
* 现在有一个纹理包选择菜单，用于玩家更换纹理包，此按钮替换了原先的“Play tutorial level”（游玩教程关卡）按钮。
* 左上角现在显示版本名称。

* *[服务器](服务器.md)**
* 连接到服务器时，出现“连接超时”的显示界面要等待更长的时间。

# 修复
* *修复了5个漏洞**
* 在火中、熔岩里以及仙人掌旁边的玩家和生物不会一直播放受伤音效。
* 从低血量恢复生命时，会获得更高的伤害（此为特性，不是漏洞：WAI）。
* 修复了更改窗口大小时可以复制按钮的漏洞。
* 僵尸猪人和恶魂不再会受到火焰以及熔岩的伤害。
* 修复了音量滑块不能正确保存的问题。</onlyinclude>

# 重新上传
该版本的客户端于16:24（UTC）被第一次重新上传，以移除玩家初始快捷栏中的熔岩桶。<ref></ref>

该版本的客户端于19:38（UTC）被第二次重新上传，以移除按下会生成一个下界传送门的功能。

# 启动器版
该版本的两个重新上传版本在[启动器](启动器.md)中可用，前者被称为“a1.2.2a”，后者被称为“a1.2.2b”。
