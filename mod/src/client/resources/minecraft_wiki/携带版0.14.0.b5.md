# 携带版0.14.0.b5

*页面ID: 19968* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.14.0 alpha build 5**是[v0.14.0 alpha](携带版0.14.0.md)的第5个测试版，发布于2016年2月5日<ref>http://pocketbeta.minecraft.net/2016/02/changelog-for-014-build-5.html</ref>，修复了一些漏洞。

# 更改
* 巨型蘑菇不再生成在水里了。
* [漏斗](漏斗.md)、[发射器](发射器.md)和[投掷器](投掷器.md)的储物栏与其他储物栏更加连贯。
* 加载速度稍快一些。
* 当用锹破坏雪时会掉落[雪球](雪球.md)。

# 修复
* *修复了16个漏洞**
* 漏斗失去了功能。
* 在生存模式下，除非破坏物品展示框，否则无法移除展示的物品。
* 上船时，会放置物品栏内的船。
* 破坏船时会使得背后的另一个船也被破坏。
* 第三人称正面模式下，部分缩略图无法显示。
* 超平坦世界里出现黑色的点。
* 客户端下玩家的朝向不会保存。
* 铁轨不能在东西朝向上平行铺设。
* 附魔台的功能出错。
* 飞行时，物品栏内的染色盔甲显示错误。
* 熄灭的红石火把仍会给予红石信号。
* 物品栏内的栅栏纹理显示错误。
* 破坏物品展示框使得展示的物品被复制。
* 矿车不会互相碰撞，而是会重叠起来。
* 客户端内的TNT不可见。
* 放置相机时游戏崩溃。</onlyinclude>
