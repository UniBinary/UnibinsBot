# 山羊更新

*页面ID: 151306* | *来源: Minecraft Wiki*

[缩略图|山羊更新官方艺术作品](File:GOAT_Update.png.md)
* *山羊更新（GOAT Update）**是[教育版](教育版.md)的一次主要更新，其正式版[1.17.30](教育版1.17.30.md)发布于2021年11月2日，加入了**[下界更新](下界更新.md)**和**[洞穴与山崖](洞穴与山崖.md)**第一部分的特性，以及Flipgrid和[Microsoft Teams](wzh:Microsoft Teams.md)的集成。<ref></ref><ref></ref><ref></ref>

此次更新的开发始于[1.17.30.2](教育版1.17.30.2.md)，其发布于2021年9月24日。

# 重要特性
# = 物品 =
* *[照片](照片.md)**
* 一种由[摄像机](摄像机.md)拍摄的游戏内图片。
* 可以放入[相片簿](相片簿.md)中，或从相片簿中取出。
* 可以被放置在[物品展示框](物品展示框.md)上。

# = 常规 =
[thumb|“朋友！”皮肤包中的所有皮肤|384px](File:EDUFriendsSkinPack.png.md)
* *特性**

* 加入了[下界更新](下界更新.md)和[洞穴与山崖](洞穴与山崖.md)第一部分的特性。

* *[皮肤包](皮肤包.md)**
* 加入了“朋友！”皮肤包。

* *Flipgrid和Microsoft Teams**
* 集成了Flipgrid和Microsoft Teams。

# 跟进版本
* [1.17.31](教育版1.17.31.md)和[1.17.32](教育版1.17.32.md)发布以修复一些漏洞。
