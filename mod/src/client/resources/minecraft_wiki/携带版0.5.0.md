# 携带版0.5.0

*页面ID: 21019* | *来源: Minecraft Wiki*

* *v0.5.0 alpha**是[携带版](携带版.md)的一次主要更新，在Android和iOS上发布于2012年11月15日<ref>发布于此：  并于同一天在iOS上发布（见视频中方块音效）： https://youtu.be/rYrv_QSo2KU</ref><ref>http://web.archive.org/web/20130128073657/https://play.google.com/store/apps/details?id=com.mojang.minecraftpe</ref>，在Fire OS的发布日期未知<ref>http://web.archive.org/web/20121119021216/http://www.amazon.com:80/Mojang-Minecraft-Pocket-Edition/dp/B00992CF6W</ref>。加入了[西瓜](西瓜.md)、[西瓜种子](西瓜种子.md)、[西瓜片](西瓜片.md)、[僵尸猪人](僵尸猪人.md)、[画](画.md)、[荧石](荧石.md)、[荧石粉](荧石粉.md)和[下界反应核](下界反应核.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[下界反应核](下界反应核.md)**
* 用于搭建[下界反应器](下界反应器.md)。
* 由3个钻石和6个铁锭合成。

* *[发光的黑曜石](发光的黑曜石.md)**
* 发出亮度等级为12的光。
* 下界反应器激活后生成。
* 挖掘后只会掉落普通的黑曜石。

* *[荧石](荧石.md)**
* 由4个荧石粉合成。

* *[西瓜](西瓜.md)**
* 通过种植西瓜种子生成。

* *[蜘蛛网](蜘蛛网.md)**
* 目前无法获得。

* *[告示牌](告示牌.md)**
* 目前无法获得且无法使用。

# = 物品 =
* *[西瓜片](西瓜片.md)**
* 破坏西瓜后掉落。
* 可用于合成西瓜种子。

* *[西瓜种子](西瓜种子.md)**
* 新的农作物。
* 由下界反应器生成。
* 成熟后生成西瓜。

* *[荧石粉](荧石粉.md)**
* 由下界反应器生成。
* 可用于合成荧石。

# = 生物 =
* *[僵尸猪人](僵尸猪人.md)**
* 没有帽子层。
* 总是和玩家敌对。
* 由下界反应器生成。

# = 非生物实体 =
* *[画](画.md)**
* 悬挂在墙上的装饰用实体。

# = 世界生成 =
* *[下界反应器](下界反应器.md)**
* 由玩家手动搭建。
* 通过摆放正确的结构，生存模式下激活后可以生成黑曜石尖塔和战利品。
* * 非和平难度下会生成僵尸猪人。
* *[下界塔](下界塔.md)**
* 由激活的下界反应器生成。
* 激活反应堆后，组成反应堆的方块会逐渐被转化为[发光的黑曜石](发光的黑曜石.md)，塔内也会生成一些稀有的物品以及敌对的[僵尸猪人](僵尸猪人.md)（难度为和平时除外）。

# = 游戏内容 =
* *[潜行](潜行.md)**
* 仅能通过Xperia PLAY设备上的按键来切换潜行状态。

# 更改
# = 方块 =
* *[床](床.md)**
* 缩短了睡觉动画。

* *[耕地](耕地.md)**
* 在耕地上跳跃，耕地会变成泥土。

* *[甘蔗](甘蔗.md)**
* 现在可以在沙子上种植。

* *[蘑菇](蘑菇.md)**
* 现在可以种植。

# = 物品 =
* *[食物](食物.md)**
* 现在可以恢复更多生命。

# = 生物 =
* *[僵尸](僵尸.md)和[骷髅](骷髅.md)**
* 加入了新的动画。

# = 游戏内容 =
* *[生命](生命.md)**
* 睡觉现在可以恢复生命。
* 生命条在屏幕左上方显示，而不是快捷栏上方。

* *[天气](天气.md)**
* 游戏的雾气现在更少了。

* *[物品栏](物品栏.md)**
* 选取的物品或方块的名称会显示在快捷栏上方。

# J版本
