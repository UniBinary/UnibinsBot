# = 写作 =
当玩家手持书与笔时，点击键或，就会打开一个文字编辑界面。

的编辑界面}}
这个界面由一张“书页”作为背景，每页有一个文本框和左右翻页按钮（第一页没有左翻页），“书页”的下方有“署名”和“完成”按钮。玩家最多可以写100页的内容，每页最多1024个字符。若一行中的字符的宽度超过114个像素则会进行自动换行，玩家无法通过该界面输入超过14行的文本（包括手动换行和自动换行）。通过修改物品堆叠组件可以突破14行的上限，溢出的文本会按照正常的渲染方式继续向下渲染并可能超出“书页”的范围。

的编辑界面}}
这个界面由两张“书页”作为背景，每页有一个文本框，左右翻页分别在左右两页上（第一页没有左翻页，最后一页没有右翻页），两张“书页”中间的下方有“署名”按钮。玩家最多可以写50页的内容，每页最多256个字符。若一行中的字符的宽度超过122个像素则会进行自动换行，玩家无法通过该界面输入超过14行的文本（包括手动换行和自动换行）。

UI和下的此界面相同。

玩家能够将复制的文字粘贴到文本框中，但如果本次粘贴的字符的宽度超过当前页所能容纳的宽度，粘贴将不会生效。书与笔支持大部分Unicode字符；也支持[格式化代码](格式化代码.md)，可以通过以符号开头的代码修改文本样式。

玩家可以将来自[相片簿](相片簿.md)或[物品栏](物品栏.md)中的[照片](照片.md)导入进书与笔内，并可以将照片移动至上下页或删除照片。

在的单人游戏中，编辑时游戏会暂停。

# == 署名 ==
的签名界面}}
的签名界面}}
点击文本框下方的“署名”按钮后可输入书名和。作者名是为此书签名的玩家名；作者名可以更改，最长可达14个字符，默认是“未知作者”。

书名最长可达15<ref name="MC-210318"></ref>/16个字符。书名中可以添加特殊字符，但无法输入[格式化代码](格式化代码.md)。

UI和下的此界面相同。

书与笔被署名后会变为带有书名和作者名的[成书](成书.md)，不能再被编辑。

# = 讲台 =
玩家可以将书与笔或成书放置在空的[讲台](讲台.md)上。

讲台会根据书中显示的页面发出红石信号。显示最后一页时，讲台会输出15等级的红石信号。

# = 雕纹书架 =
手持书与笔对[雕纹书架](雕纹书架.md)按键可将书与笔放入其中。

# 你知道吗
* 通过辅助程序和编辑器，书与笔最多可以有2,147,483,639页、每页最多32,767字符，还可以修改作者、在标题中添加格式化代码等。
* 用铁砧给未署名的书与笔重命名，书与笔署名后的标题是在铁砧上重命名的名称而非署名时设定的名称，因为在物品堆叠组件中，[](物品堆叠组件#custom_name.md)的优先级高于[](物品堆叠组件#written_book_content.md)。
* 书与笔的第100页仍旧有右翻页，但是点击以后无法生成新的书页，而成书的最后一页是没有右翻页的。
