# Java版12w39a

*页面ID: 33082* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w39a**是[Java版1.4.2](Java版1.4.2.md)的第8个快照，发布于2012年9月27日<ref></ref>。

# 更改
# = 生物 =
* *[女巫](女巫.md)**
* 更改了女巫的纹理尺寸。

# = 游戏内容 =
* *[光照](光照.md)**
* 新的照明系统。
* 之前一些无法准确显示光照效果的[方块](方块.md)现在可以正确显示了：[楼梯](楼梯.md)、[台阶](台阶.md)和[活塞](活塞.md)等等。

* *[音效](音效.md)**
* 一些音效优化。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 调试屏幕现在可以显示玩家所在的[区块](区块.md)了。

# 修复
* *修复了4个漏洞**
* 声音修复：
* * 放置玻璃、玻璃板、荧石、红石灯和冰时发出的声音不再与破坏它们时发出的声音一样了。
* * 现在不会在箭矢射入水中后持续播放水的飞溅声了。
* 修复了女巫对一些玩家而言是白色的问题。
* 新生成的区块和世界中，不再会出现没有被点亮的区域（黑色补丁<ref></ref>）了。</onlyinclude>
