# Java版1.20-pre3

*页面ID: 104269* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.20-pre3**是[Java版1.20](Java版1.20.md)的第3个预发布版，发布于2023年5月19日<ref></ref>，修复了一些漏洞。

# 修复
NBT标签的盔甲架仍可以激活压力板。
|152258|骑乘具缓降效果的实体不能免除摔落伤害。
|181280|有时会显示一些错误纹理。
|259912|带鞍的马可以永久保留飘浮效果。
|260653|标记、交互实体和展示实体会导致压力板无法解除激活状态。
|260903|在末次攻击前一次造成伤害的攻击者可以被记录为击杀者。
|262684|游戏图标分辨率低。
|;dev
|261202|传送展示实体时，骑在展示物上的玩家会有抖动。
|262324|骑乘生物时，传送此生物时的效果不好。
|262505|铁傀儡会产生未与其发生碰撞的方块的粒子。
|262593|两条Realms英文字符串中，“occurred”一词被错写为“occured”。
|;previous
|262709|发射器不把船发射到正确的高度上。
|262712|在配方书中点击右键不显示替代配方。
