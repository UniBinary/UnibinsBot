# 金粒

*页面ID: 7346* | *来源: Minecraft Wiki*

* *金粒（Gold Nugget）**是一种通过杀死[僵尸猪灵](僵尸猪灵.md)、采矿或者炼制金质工具获得的[物品](物品.md)。

# 获取
# = 生物掉落物 =

# = 挖掘 =
使用未带有[精准采集](精准采集.md)魔咒的镐来开采[下界金矿石](下界金矿石.md)会掉落2-6个金粒。[时运](时运.md)魔咒可增加掉落数量，时运III最多掉落24个金粒。

使用未带有精准采集魔咒的镐来开采[镶金黑石](镶金黑石.md)有10%的概率掉落2-5个金粒。时运I使得掉落金粒的概率提升至14.29%（），时运II提升至25%，时运III则为100%。
