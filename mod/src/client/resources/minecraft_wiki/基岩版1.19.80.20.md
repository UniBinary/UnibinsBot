# 基岩版1.19.80.20

*页面ID: 102791* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.80.20**（Android）、**Preview 1.19.80.20**（Xbox/Windows/iOS/iPadOS）是[基岩版1.19.80](基岩版1.19.80.md)的首个测试版，发布于2023年3月8日至14日<ref></ref><ref></ref>，加入了[基岩版编辑器](基岩版编辑器.md)，更新了[死亡屏幕](死亡.md)，同步了一些的特性，在[实验性玩法](实验性玩法.md)中加入了[樱花树林](樱花树林.md)相关内容和新的[潜行](潜行.md)行为，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“短暂潜行”子选项。
* * 用于启用1.49格高的[潜行](潜行.md)行为。

* *[格式化代码](格式化代码.md)**
* 加入了石英色、铁锭色、下界合金色、红石色、铜锭色、金锭色、绿宝石色、钻石色、青金石色和紫水晶色的格式化代码：。

* *[设置](设置.md)**
* 在视频设置中加入了“”选项。
* * 用于启用新的死亡屏幕，默认为开启状态。
* 在设置中加入了“”滑块。
* * 用于控制附魔光效的闪烁速度，默认为50%。
* 在设置中加入了“”滑块。
* * 用于控制附魔光效的透明度，默认为50%。

# = 技术性 =
* *[基岩版编辑器](基岩版编辑器.md)**
* 一种支持引擎内、多方块编辑的编辑器。
* 目前处于早期开发阶段，仅在Windows平台上的[Minecraft Preview](Minecraft Preview.md)中可用。

# 更改
# = 方块 =
* *[原木](原木.md)**
* ID（）现在被拆分为不同种类原木的ID。

* *[西瓜](西瓜.md)和[南瓜](南瓜.md)**
* 现在能够生长在[泥巴](泥巴.md)、[灰化土](灰化土.md)、[菌丝体](菌丝体.md)、[缠根泥土](缠根泥土.md)、[苔藓块](苔藓块.md)和[沾泥的红树根](沾泥的红树根.md)上。

* *[活塞](活塞.md)**
* 现在被活塞破坏的方块会产生粒子效果。

* *[测重压力板](测重压力板.md)**
* 更改了激活和取消激活音效以匹配。

* *[幽匿感测体](幽匿感测体.md)**
* 将游戏事件的振动频率由14更改为2。
* 不再可以检测游戏事件。
* 现在抛出钓鱼竿浮漂时会触发游戏事件。

# = 物品 =
* *常规**
* 更改了物品和[盔甲](盔甲.md)的附魔光效，现在变得更淡。

# = 生物 =
* *[熊猫](熊猫.md)**
* 略微减小了碰撞箱以匹配。

* *[北极熊](北极熊.md)**
* 略微增大了碰撞箱以匹配。

* *[村民](村民.md)**
* 现在会在[交易](交易.md)成功时发出绿色粒子。

# = 非生物实体 =
* *[船](船.md)和[运输船](运输船.md)**
* 现在只能搭载比船小的生物。
* 现在能够搭载[海龟](海龟.md)。

# = 技术性 =
* *数据驱动组件**
* 为弹射物数据加入了字段。
* * 用于设定实体在弹射物射出后是否取消选择其目标。
* 加入了方块组件。
* * 拥有、和三个字段，分别对应旋转、缩放和平移。
* * 可以添加到方块和方块组合的对应数据中。
* * 变换后的几何体仍然拥有与未变换的几何体相同的限制。

* *附加包与脚本引擎**
* 现在可以作为有效的树干和树叶的树木地物JSON文件中的概率相关值。

* *实体过滤器**
* 加入了实体过滤器。
* * 用于确定实体是否为袭击的一部分。

* *方块**
* 移除了方块组件。
* 为方块组件加入了行为。

* *服务器**
* 现在方块可以通过中的设置来为其网络ID选择一个哈希值，该值与其他方块无关，并会在未来的更新中保持不变。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“短暂潜行”、“下一个主要更新”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[樱花树叶](樱花树叶.md)**
* 一种新的树叶，长满粉红色的花朵，其下方会出现粉红色的下落粒子。
* [蜜蜂](蜜蜂.md)会将其视为花。

* *[樱花原木](樱花原木.md)**
* 一种紫褐色外皮、粉红色内干的原木，有对应的去皮变种。
* * 去皮变种可以合成对应种类的[悬挂式告示牌](悬挂式告示牌.md)。
* 可用于合成对应种类的[木板](木板.md)。

* *[樱花木板](樱花木板.md)**
* 一种新的木板。
* 可以合成对应种类的[按钮](按钮.md)、[门](门.md)、[栅栏](栅栏.md)、[栅栏门](栅栏门.md)、[压力板](压力板.md)、[告示牌](告示牌.md)、[台阶](台阶.md)、[楼梯](楼梯.md)和[活板门](活板门.md)。

* *[樱花树苗](樱花树苗.md)**
* 一种新的树苗。
* 可以放置在[花盆](花盆.md)中。

* *[櫻花木塊](櫻花木塊.md)**
* 樱花原木的木头变种，有对应的去皮变种。
* 可用于合成对应种类的木板。

* *[粉红色花簇](粉红色花簇.md)**
* 一种新的方块，在樱花树林中自然生成。
* 可通过对已有的粉红色花簇使用[骨粉](骨粉.md)再生。
* 类似于[海泡菜](海泡菜.md)，一个方块内可以放置4个。
* 可以以特定方向放置。
* 可以用来合成[粉红色染料](粉红色染料.md)。
* 蜜蜂会将其视为花。

* *[饰纹陶罐](饰纹陶罐.md)**
* 更改了颈部的模型。（）
* * 颈部的模型现在可以切入方块。
* * 现在使用新的更加复杂的模型。
* 不再会为需要附着在侧面的方块提供支撑。（）
* 现在是不可堆叠的。（）
* 饰纹陶罐粒子现在使用基于饰纹陶罐默认侧面的纹理。

* *[可疑的沙子](可疑的沙子.md)**
* 不再可以[含水](含水.md)。（）
* 现在能够与栅栏相连接。
* 现在被[刷子](刷子.md)清刷后会变为普通[沙子](沙子.md)。（）
* 现在被[活塞](活塞.md)破坏时会产生粒子效果。
* 修复了使用刷子清刷可疑的沙子时，其中的物品会闪烁的问题。（）

# = 物品 =
* *[刷子](刷子.md)**
* 更改了合成配方，现在需将[羽毛](羽毛.md)、[铜锭](铜锭.md)和[木棍](木棍.md)依次排成一列来合成。（）
* 现在手持刷子在第三人称视角下破坏方块时会正确播放动画。（）
* 为清刷可疑的沙子产生的粒子效果和音效加入了短暂的冷却时间。

* *[陶片](陶片.md)**
* 更改了弓箭纹样陶片应用于[饰纹陶罐](饰纹陶罐.md)上的纹样纹理，以及其物品纹理。

# = 生物 =
* *[骆驼](骆驼.md)**
* 现在进入可骑乘实体中时会停止冲刺。（）

# = 非生物实体 =
* *[樱花木船](樱花木船.md)**
* 一种新的船，使用樱花木板合成。

* *[樱花木运输船](樱花木运输船.md)**
* 一种新的运输船，使用樱花木船和[箱子](箱子.md)合成。

# = 世界生成 =
* *[樱花树林](樱花树林.md)**
* 一种新的[山地](山地.md)生物群系变种，类似于[草甸](草甸.md)。
* 含有[樱花树](樱花树.md)，一种新的[树木](树木.md)。
* * 可由樱花树苗长成。
* * 有5%的概率带有[蜂巢](蜂巢（方块）.md)。
* 可以自然生成[兔子](兔子.md)、[猪](猪.md)、[绵羊](绵羊.md)、[蜜蜂](蜜蜂.md)。

# = 游戏内容 =
* *[潜行](潜行.md)**
* 现在会将玩家的高度降低到1.49格，使其能够穿过1.5格高的空隙。
* 现在玩家位于小于1.8格的空间时会自动进入潜行状态。
* 现在玩家取消潜行需要足够的空间。
* 现在有足够的空间潜行但不能站立时，玩家会从[游泳](游泳.md)状态切换至潜行状态。

# = 常规 =
* *[粒子](粒子.md)**
* 加入了粒子。

* *[配方书](配方书.md)**
* 现在可以在配方书中找到仅使用红砖合成的[饰纹陶罐](饰纹陶罐.md)。

# 修复
* *辅助功能**
* 选择新的物品时，文本转语音不再会读出之前选中的物品。
* 用户在不同选项卡之间切换时，文本转语音不再会卡在辅助功能选项卡中。

* *方块**
* 红树木按钮、竹按钮和磨制黑石按钮不再会在地图上显示。
* 现在将花放入花盆时，花再次会立即显示。

* *游戏内容**
* 修复了玩家通过游戏手柄来退出容器屏幕后会往错误方向移动的问题。（）
* 玩家飞行时不再能潜行。（）
* 修复了在VR模式下的部分方块周围会出现多余的黑色方框的问题。
* 修复了游泳与行走之间的动画过渡问题。（）
* 修复了命令方块可能会导致存档区块内的活动对象卡住的问题。（）
* 生命提升效果在持续时间结束后不再会回满玩家的生命值。（）

* *常规**
* 修复了玩家进入或加载至末地时会播放洞穴环境音效的问题。（）
* 现在在熔炉中烧炼紫颂果会给予经验。（）
* 下界传送门现在能够在生成时替换方块，包括草和雪层等，而不只是空气。（）
* 玩家不再可以在生存模式或冒险模式中更改光源方块的亮度等级。（）
* 营火音效现在更加响亮、更加清晰。（）

* *图形**
* 修复了在RTX渲染引擎下光源（如火把）会错误发出白光的问题。（）
* 船不再会与玩家产生深度冲突。
* 护腿的“裤腿”和“皮带”部分不再会与玩家产生深度冲突。
* 披风在玩家受到伤害时不再会变成红色。（）
* 移除了漏斗模型中的间隙。（）
* 修复了工作台输出槽位的对齐问题。（）
* 将默认的附魔光效强度减半，使其可以使用辅助功能中的选项调整。（）

* *性能与稳定性**
* 修复了无效旗帜图案会导致渲染距离内的玩家游戏崩溃的漏洞。（）

* *触摸控制**
* 修复了点击移动工作台中的物品时物品会卡住的问题。
* 现在当玩家开启自动跳跃且处于水下时可以自动跳上一格高的方块。

* *用户界面**
* 为携带版UI的物品栏屏幕加入了标题。
* 增加了设置屏幕中标题与内容之间的间隔。
* 现在触摸板的滚动会与系统的滚动方向同步。

* *原版趋同**
* 现在玩家被重命名后的物品或附魔物品杀死时，该物品的名称会在重生屏幕和聊天栏中带有颜色地显示。（）
* 测重压力板现在使用与Java版相同的音效。（）
* 移除了记分项名称和记分项显示名称的字符限制。（）
* 西瓜和南瓜现在能够生长在泥巴、灰化土、缠根泥土和沾泥的红树根上。
* 菌岩现在位于创造模式物品栏中的下界岩物品组中。（）
* 现在使用命令杀死盔甲架时，盔甲架会消失，且不产生音效。（）

* *生物**
* 现在只有比船小的生物才能乘船。
* 现在村民交易成功时会产生绿色粒子效果。
* 生物被喂养繁殖用食物时不再会发出玩家进食的音效。
* 略微减小了熊猫的碰撞箱以匹配Java版。
* 略微增大了北极熊的碰撞箱以匹配Java版。
* 海龟现在能够乘坐船或运输船。（）
* 疣猪兽、北极熊和蜘蛛不再能够乘坐船或运输船。（）

* *命令**
* 现在在第二个及接下来的子命令中的目标选择器出现错误时会正确报错。（）
* 修复了命令方块UI中的粘贴按钮会记住之前的无效粘贴的漏洞。（）

* *市场**
* 现在“WDW 魔法王国冒险”世界中的巨雷山、白雪公主与七个小矮人、太空山三个园区中的车厢会与其连接至的矿车正确对齐。

* *用户界面**
* 暂停菜单上的反馈按钮现在会在重定向到浏览器之前弹出弹窗。</onlyinclude>
