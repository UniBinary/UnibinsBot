# 基岩版1.19.50.24

*页面ID: 99944* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.50.24**（Android）、**Preview 1.19.50.24**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.50](基岩版1.19.50.md)的第5个测试版，发布于2022年11月9日<ref></ref>，更改了[恼鬼](恼鬼.md)的模型和纹理，并修复了一些漏洞。

# 更改
# = 生物 =
* *[恼鬼](恼鬼.md)**
* 更改了模型和纹理。
* * 仍保留了比模型稍大一些的[判定箱](判定箱.md)，以便于其战斗。

# = 技术性 =
* *生物**
* 被玩家控制的不再会增加自动步数。
* * 可改用组件。使用和可与之前版本保持一致。

# 修复
* *游戏内容**
* 修复了玩家靠近缩回的活塞时可能会被推到墙的另一侧的漏洞。
* 修复了蜜蜂离开蜂箱时蜂箱不会增加值的漏洞。（）

* *触摸控制**
* 现在触摸控制玩家飞行时的键盘控制会与其他控制模式一致，双击键会正确取消触控模式下的飞行状态。
* 修复了将物品放在创造模式物品栏中的另一物品上时，该物品不会被丢弃的问题。（）

* *命令**
* 现在执行命令时会产生错误信息，而不是导致崩溃。（）</onlyinclude>
