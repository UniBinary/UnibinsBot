# 基岩版1.18.30.32

*页面ID: 94447* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.30.32**（Xbox/Windows/Android）、**Preview 1.18.30.33**（iOS/iPadOS/Xbox/Windows）是[基岩版1.18.30](基岩版1.18.30.md)的第11个测试版，发布于2022年3月31日<ref></ref><ref></ref>，在[实验性玩法](实验性玩法.md)中加入了[远古城市](远古城市.md)结构、[强化深板岩](强化深板岩.md)和[监守者](监守者.md)，并修复了一些漏洞。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“荒野更新”子选项后才可使用。

# = 方块 =
* *[幽匿尖啸体](幽匿尖啸体.md)**
* 现在会在第四阶段生成[监守者](监守者.md)。

* *[强化深板岩](强化深板岩.md)**
* 一种生成于远古城市结构中心的深板岩变种。
* 具有极高的硬度和爆炸抗性。
* 可被[活塞](活塞.md)推拉。
* 生存模式下可以通过挖掘破坏但不可获得掉落物。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了监守者刷怪蛋。

# = 生物 =
* *[监守者](监守者.md)**
* 生命值为。
* 约有3.5格高。
* 属于敌对生物，免疫火焰伤害，并且会在[水](水.md)和[熔岩](熔岩.md)中上浮。
* 抗击退能力极强。
* 会在生成阶段达到第四阶段时从阴凉处钻出。
* * 60秒内未感知到任何振动会钻回地面；若处于阳光下则会立即钻回地面。
* 设定上没有视力但拥有嗅觉与听觉。
* * 能够感知气味信号并获取附近生物的大体位置。
* ** 会优先通过嗅觉寻找最“可疑”的生物，而非距其最近的生物。
* * 能够感知振动信号并获取振动发出的位置。
* ** 会跟随发出振动的实体。
* ** 头上的“触角”会在感知到振动信号时甩动并发光，其感知方式类似于[幽匿感测体](幽匿感测体.md)。<!--
* * Seems to follow the same rules as the [sculk sensor](sculk sensor.md) when detecting vibrations.-->
* *** 无法感知玩家潜行时发出的振动。
* * 生物的“可疑度”会随着其发出的气味或振动信号被监守者感知而提高。
* * 监守者的心跳频率（胸口核心的闪动频率）会随生物的”可疑度”提高。
* 生物的“可疑度”积累到一定程度时，监守者会确定该生物的准确位置并怒吼，无视干扰直接发动攻击。
* * 普通难度下监守者每次攻击能造成的伤害。
* * 玩家使用[盾牌](盾牌.md)格挡监守者攻击后需要5秒冷却来进行下一次格挡。
* 会不断给予附近玩家[黑暗](黑暗.md)状态效果。
* 被玩家杀死后只会掉落经验。

# = 世界生成 =
* *[远古城市](远古城市.md)**
* 一种生成于[深暗之域](深暗之域.md)生物群系的[结构](结构.md)。
* 大体由[深板岩](深板岩.md)（含变种）、[玄武岩](玄武岩.md)（含变种）和[灰色羊毛](灰色羊毛.md)筑成。
* 包含[灵魂沙](灵魂沙.md)、[灵魂火](灵魂火.md)和[灵魂灯笼](灵魂灯笼.md)、[红石灯](红石灯.md)、[蜡烛](蜡烛.md)和[骷髅头颅](骷髅头颅.md)。
* 结构中心为巨大的强化深板岩框架，紧凑的长廊由此向四周延伸。
* 长廊旁的一些破败建筑会生成独有的战利品箱子。

# = 常规 =
* *[粒子](粒子.md)**
* 加入了粒子。

# 修复
* *游戏内容**
* 修复了在穿戴头盔的情况下被下落的方块砸中时可能发生的崩溃。（）
* 修复了导入转换自原主机版的世界后，该世界中的实体会消失不见的问题。
* 现在具有击退抗性的生物（如劫掠兽、僵尸疣猪兽）被铁傀儡攻击时会减少击退距离。
* 修复了末地城地物在末地的生成问题。

* *用户界面**
* 修复了已下载的资源包不会显示其信息和按钮的问题。（）
* 修复了使用触摸控制时无法退出表情切换界面的问题。</onlyinclude>
