# Java版20w29a

*页面ID: 66676* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w29a**是[Java版1.16.2](Java版1.16.2.md)的第3个快照，发布于2020年7月15日<ref name="20w29a"></ref>，更新了命令和，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* *和**
* 加入了参数，可以设置[玩家](玩家.md)重生时面朝的方向。
* 语法：
* *
* *
* ** ：角度制下的浮点数角度值。标识符，会被转换为执行玩家当前的朝向角度值。

# 更改
# = 生物 =
* *[窒息](窒息.md)**
* 现在生物在头部卡入[灵魂沙](灵魂沙.md)、[耕地](耕地.md)和[草径](草径.md)中时会受到窒息伤害。

* *[掠夺者](掠夺者.md)**
* 更改了非武装掠夺者的攻击动画。

* *[卫道士](卫道士.md)**
* 更改了非武装卫道士的攻击动画。

# = 游戏内容 =
* *[创造模式物品栏](创造模式物品栏.md)**
* [工具](工具.md)现在在创造模式物品栏中按其[材料](品质.md)排序。

# = 常规 =
* *[自定义](自定义.md)世界生成**
* 现在可以包含噪声配置。
