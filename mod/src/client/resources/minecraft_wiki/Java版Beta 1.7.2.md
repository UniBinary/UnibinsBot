# Java版Beta 1.7.2

*页面ID: 32732* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.7.2**是的一次次要更新，发布于2011年7月1日，修复了[Beta 1.7_01](Java版Beta 1.7_01.md)里的漏洞和崩溃。

# 修复
* *修复了3个漏洞**
* 崩溃了的世界现在可以再次使用了。<ref></ref>
* 恢复了消失的活塞。<ref></ref>
* 修复了活塞导致的多人游戏服务器崩溃的问题。</onlyinclude>
