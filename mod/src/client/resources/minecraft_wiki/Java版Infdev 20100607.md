# Java版Infdev 20100607

*页面ID: 35949* | *来源: Minecraft Wiki*

<onlyinclude>
* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年6月7日，加入了一些新方块。<ref></ref><ref></ref>

# 新内容
# = 方块 =
* *[告示牌](告示牌.md)**
* 一种功能性方块，用于显示玩家自定义的文字。
* 有[碰撞箱](碰撞箱.md)，可以放置在固体方块的顶部。
* 挖掘耗费的时间很长。
* 被破坏后掉落1个[橡木木板](橡木木板.md)。

* *[梯子](梯子.md)**
* 一种功能性方块，可用于向上或向下爬行。

* *[门](门.md)**
* 一种功能性方块，可开关。

# 更改
# = 生物 =
* *常规**
* [敌对生物](敌对生物.md)的[生成](生成.md)频率变低，使得它们现在比较罕见。

# = 世界生成 =
* *[树木](树木.md)**
* Infdev大树不再生成。</onlyinclude>
