# 发光的黑曜石

*页面ID: 9241* | *来源: Minecraft Wiki*

* *发光的黑曜石（Glowing Obsidian）**是[基岩版](基岩版.md)、[New Nintendo 3DS版](New Nintendo 3DS版.md)、[树莓派版](树莓派版.md)和[教育版](教育版.md)独有的方块，除了用于装饰外没有任何用处。

# 生成
发光的黑曜石不会生成在世界中。

# 获取

发光的黑曜石只能通过从[携带版0.12.1.b1](携带版0.12.1.b1.md)前包含发光的黑曜石并升级了的世界中获得，无法在其他未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取，不存在于[创造模式物品栏](创造模式物品栏.md)中，且是不可通过获取的物品。在[创造模式](创造模式.md)中对已有的发光的黑曜石使用可以获得发光的黑曜石；否则，发光的黑曜石只能通过存档编辑或[附加包](附加包.md)获得。

# 破坏
挖掘发光的黑曜石的合适工具是镐。发光的黑曜石需要钻石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

发光的黑曜石被破坏后会掉落自身。

# 用途
发光的黑曜石会发出[亮度](亮度.md)为12的光。
