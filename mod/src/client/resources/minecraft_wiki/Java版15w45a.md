# Java版15w45a

*页面ID: 18893* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w45a**是[Java版1.9](Java版1.9.md)的第39个快照，发布于2015年11月5日<ref></ref>。开发团队的目标是要在2015年10月底前使1.9版本具有完备的特性，接着再进行一段时间的错误修复<ref></ref>，该快照是在计划的错误修复时间内的首个快照。

# 新内容
# = 常规 =
* *[Realms](Realms.md)**
* 在[选项](选项.md)中加入了“Realms的通知”开关，可在“开”和“关”之间切换。

# 更改
# = 方块 =
* *[睡莲](睡莲.md)**
* 碰撞箱高度改为1像素，取代了之前的像素。

# = 物品 =
* *[地图](地图.md)**
* 恢复到[15w34a](15w34a.md)之前一样，合成时为1:1的放大等级。
* * 并且无法再被放大。
* 这会把地图回退到1.8的行为。

* *[盾牌](盾牌.md)**
* 在盾牌上附上图案现在会消耗旗帜。

# = 生物 =
* *[远古守卫者](远古守卫者.md)**
* 如同在1.8版本，现在其稀有掉落物只有鱼，并移除了曾在快照中的钓鱼宝藏和钓鱼垃圾。

* *[潜影贝](潜影贝.md)**
* 加入了潜影贝受到伤害时的音效。

# = 非生物实体 =
* *[船](船.md)**
* 深色橡木船现在可以被合成了。

# = 命令格式 =
* *常规**
* 补全坐标时如果没有对准方块将补为空。

* *[NBT格式](NBT格式.md)**
* ThrownPotion（扔出的药水）上的<code>Linger</code>byte型标签被移除。作为取代，药水物品如果包含ID<code>minecraft:lingering_potion</code>就会发生滞留。
* * 以下命令可以创造一个ThrownPotion滞留药水：<code>/summon ThrownPotion ~ ~5 ~ {Potion:{id:"minecraft:lingering_potion",tag:{Potion:"minecraft:swiftness"}}}</code>。

# = 游戏内容 =
* *[成就](成就/Java版.md)**
* 成就“君临天下”的描述由“制造一个[附魔金苹果](附魔金苹果.md)”更改为“吃下一个附魔金苹果”。

# = 常规 =
* *优化**
* 对寻路与怪物AI进行了微调。
* 一些性能优化。
