* *琥珀块（Block of Amber）**是用于存储[琥珀宝石](琥珀宝石.md)的方块。

# 生成
琥珀块不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘琥珀块的合适工具是镐。琥珀块需要铁镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

琥珀块被破坏后会掉落自身。

# 用途
# = 信标 =

琥珀块可作为激活[信标](信标.md)的底座方块。
