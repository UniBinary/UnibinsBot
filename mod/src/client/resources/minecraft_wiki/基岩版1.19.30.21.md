# 基岩版1.19.30.21

*页面ID: 97752* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.30.21**（Android）、**Preview 1.19.30.21**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.30](基岩版1.19.30.md)的第2个测试版，发布于2022年8月10日<ref></ref>，加入了新的快捷键，同步了更多的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[结构方块](结构方块.md)**
* 为加载模式的结构方块加入了“水涝方块”选项。
* * 用于允许被放置于水下的结构正确含水。

# = 生物 =
* *成年[疣猪兽](疣猪兽.md)和[僵尸疣猪兽](僵尸疣猪兽.md)**
* 修改了碰撞箱大小和击中范围以近似匹配。

# = 世界生成 =
* *[结构](结构.md)**
* 为下列结构加入了与相匹配的ID。原ID仍可使用，但不会出现在自动补全列表中。


# = 命令格式 =
* ***
* 加入了参数。
* * 若设置为，则允许被放置于水下的结构正确含水。

# = 常规 =
* *[控制](控制.md)**
* 加入了允许[玩家](玩家.md)复制其当前[坐标](坐标.md)或方块坐标的快捷键。
* *  +  + 默认复制当前坐标。
* *  +  + 默认复制所选中方块的坐标。
* * 需要在创建者设置中开启“启用复制坐标 UI”选项。

# 修复
* *旁观模式（实验性）**
* 现在进入旁观模式后，玩家肩上的鹦鹉会跳离玩家。
* 带有行为的生物不再会跟随旁观模式玩家。
* 带有行为的生物不再会尝试骑乘旁观模式玩家。
* 旁观模式玩家的冰霜行者附魔物品不再会影响水。

* *常规**
* 修复了在光源方块上放置盔甲架后光源方块会消失的漏洞。（）

* *生物**
* 修改了疣猪兽和僵尸疣猪兽的碰撞箱大小和击中范围以匹配。（）

* *命令**
* 修改了命令中的一些结构名称，加入了下划线以匹配。旧版的结构名称仍然可以使用，但不会出现在自动补全列表中。

* *游戏内容**
* 为命令和结构方块的加载选项卡加入了字段，以允许玩家使被放置于水中的结构正确含水。
* 同时按下和键后不再会使键一直处于按下状态。

* *物品**
* 创造模式物品栏中的铁栏杆不再会消失，并且可以重新通过命令获得。（）
* 创造模式物品栏中的白色带釉陶瓦不再会消失，并且可以重新通过命令获得。

* *市场**
* 市场上的角色创建器优惠不再会在退出更衣室时丢失缩略图。

* *用户界面**
* 为Xbox云端同步选项加入了一个“重试”按钮。
* 创造模式物品栏中的海草和海带不再被分类为“珊瑚装饰”。（）
* 玩家着火时，火焰不再会穿过手持物品。（）

* *性能与稳定性**
* 游戏不再会在玩家浏览市场时崩溃。</onlyinclude>
