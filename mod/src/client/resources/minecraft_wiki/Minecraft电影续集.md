《》（A Minecraft Movie）的续集，暂定名为**A Minecraft Movie 2**，或被称为**Another Minecraft Movie**，中国大陆定名为**《我的世界大电影2》**。是一部基于同名游戏[Minecraft](Minecraft.md)改编的冒险喜剧电影。

该片将由[杰瑞德·赫斯](Wikipedia:Jared Hess.md)执导，杰瑞德·赫斯与克里斯·加莱塔编写剧本，定于2027年7月23日在北美上映。

# 制作
# = 开发 =
2025年3月30日，在伦敦莱斯特广场举行[A Minecraft Movie](A Minecraft Movie.md)全球首映礼上，导演杰瑞德·赫斯表示了对制作电影续集的兴趣，并表示有很多未在首部电影中实现的想法，可能会被用于续作当中。<ref></ref>

2025年4月8日，杰瑞德·赫斯表示他们已经开始讨论续集。<ref></ref>4月11日，有多家媒体报道，电影的续作已在运作当中，处于早期开发阶段。<ref></ref>次日，华纳兄弟CEO确认[A Minecraft Movie](A Minecraft Movie.md)会有续集。<ref></ref>

2025年10月9日，华纳兄弟与[Mojang Studios](Mojang Studios.md)宣布，续集将于2027年7月23日在北美上映<ref name="date"/>，并发布首张海报。根据同日媒体报道，传奇影业将继续担任投资方与制片方，杰瑞德·赫斯回归导演，与前作编剧克里斯·加莱塔共同编写剧本。凯尔·波耶特、罗伊·李、杰森·莫玛、托菲·弗兰斯·奥拉夫、玛丽·帕伦将、艾瑞克·麦克勒德和凯琳·沃尔特斯共同担任制片人。

2026年1月17日，杰森·莫玛表示电影续作的剧本已经完成，将于4月底开拍。他还表示续作剧情比首作精彩的多。<ref name="Filmingdate"></ref>

# = 拍摄 =
电影将于2026年4月底至5月初期间开拍。<ref name="Filmingdate"></ref><ref></ref>

# 发行
该片由华纳兄弟影业发行，目前定于2027年7月23日在北美上映。<ref name="date"/>
