# 基岩版1.21.130.22

*页面ID: 169164* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.130.22**（ChromeOS/Android）、**Preview 1.21.130.22**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.130](基岩版1.21.130.md)的第2个测试版，发布于2025年10月22日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 生物 =
* *[鹦鹉螺](鹦鹉螺.md)**
* 现在被喂食[鱼桶](鱼桶.md)后，鱼桶会变为[水桶](水桶.md)。
* 现在已驯服的鹦鹉螺会被所有种类的鱼和鱼桶吸引。
* 现在已驯服的鹦鹉螺可以被喂食所有种类的鱼和鱼桶。

* *[幻翼](幻翼.md)**
* 不再会溺水。

* *[僵尸](僵尸.md)、[尸壳](尸壳.md)、[僵尸猪灵](僵尸猪灵.md)和[猪灵](猪灵.md)**
* 现在持有[矛](矛.md)时会使用冲锋攻击。

* *[僵尸马](僵尸马.md)**
* 装备[马铠](马铠.md)时不再会在阳光下着火。
* 重新加入了幼年僵尸马。
* * 幼年僵尸马的体型不再会随时间逐渐增大。

* *[僵尸鹦鹉螺](僵尸鹦鹉螺.md)**
* 现在未驯服的僵尸鹦鹉螺也会被[河豚](河豚（物品）.md)和[河豚桶](河豚桶.md)吸引。
* 现在被喂食鱼桶后，鱼桶会变为水桶。
* 现在已驯服的僵尸鹦鹉螺会被所有种类的鱼和鱼桶吸引。
* 现在已驯服的僵尸鹦鹉螺可以被喂食所有种类的鱼和鱼桶。
* 不再会因脱离水而受到伤害。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“即将推出的创作者功能”和“测试版 API”子选项后才可使用。

# = 技术性 =
* *API**
* 调试绘制
* * 修复了会导致立即被移除的漏洞。
* * 修复了的箭头在某些朝向看起来不正确的漏洞。

* *API基础设施**
* 现代化了序列。加入了下列限制：
* * 将链式子命令数据/名称的最大大小设置为512个字符。
* * 将命令/名称的最大大小设置为512个字符。
* * 将命令/描述的最大大小设置为1000个字符。
* * 将命令/链式子命令索引的最大大小设置为250个元素。
* * 将命令/重载的最大大小设置为250个元素。
* * 将限制/限制索引的最大大小设置为250个元素。

* *方块**
* 加入了组件，需要开启“即将推出的创作者功能”选项，允许具有连接行为的其他方块，如栅栏、墙、栏杆和玻璃板，可以尝试创建连接。
* 加入了原版方块标签，可用于将自定义方块识别为像栅栏一样创建连接的方块。在自定义和原版栅栏之间创建连接需要此标签。
* 上述组件和标签可与一同使用，以制作像原版栅栏一样创建连接的自定义栅栏。适用于自定义栅栏方块的JSON示例如下：

            "identifier": "test:my_fence",

                "minecraft:connection": {
                    "enabled_states": ["minecraft:cardinal_connections"]
                }
            }
        },
        "components": {
            "tag:minecraft:has_fence_connections": {},
            "minecraft:connection_rule": {
                "accepts_connections_from": "only_fences"

# 修复
* *群骑纷争**
* 尝试骑乘未驯服的僵尸马时的提示框的英文名称由“Ride”更改为“Mount”。
* 僵尸马现在拥有正确的生成分类。（）
* 修复了装备了马铠的僵尸马会在阳光下着火的漏洞。（）
* 修复了持有矛的僵尸不会使用冲锋攻击的漏洞。（）

* *常规**
* 解决了Windows平台上的共享世界（对所有玩家可用的世界）不会加载资源包和行为包的问题。（）
* 修复了地上的物品实体可以被攻击摧毁的漏洞。（）

* *生物**
* 现在骆驼行走或冲刺时会从高于4格的高度开始受到摔落伤害。（）
* 幻翼不再会溺水。（）

* *角色创建器**
* 用户不再会因平台皮肤错误而被阻止加载至世界。

* *Realms**
* 修复了Realms时间轴的选择退出成员列表的顶部按钮的控制器焦点会被切断的问题。

* *用户界面**
* 修复了自定义方块不会渲染为“飞行物品”并带有快速移动动画的问题。（）
* 现在若书与笔等部分输入会将文本推出输入窗口，输入文本时会阻止新行。
* 修复了调整窗口大小时聊天栏中的补全命令会错位的问题。（）</onlyinclude>
