# Java版12w05b

*页面ID: 32320* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w05b**是[Java版1.2.1](Java版1.2.1.md)的第4个快照，发布于2012年2月3日<ref></ref>，稍微改动了生物AI，并修复了一些漏洞。

# 更改
# = 生物 =
* *[苦力怕](苦力怕.md)**
* 稍微改进了AI。
* 现在会逃离[猫](猫.md)和[豹猫](豹猫.md)。
* *[村民](村民.md)**
* 现在有了开关门的能力。

# = 常规 =
* *[死亡消息](死亡消息.md)**
* 按钮变为活动状态之前，死亡屏幕会稍微出现延迟，以免在被杀时意外点击按钮。

# 修复
* *修复了2个漏洞**
* 修复了按住单击会只提供一半物品和消耗所有的剩余材料的结果。
* 修复了猫在空手右击时无法坐下的问题。</onlyinclude>
