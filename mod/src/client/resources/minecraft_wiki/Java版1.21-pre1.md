# Java版1.21-pre1

*页面ID: 120859* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21-pre1**是[Java版1.21](Java版1.21.md)的首个预发布版，发布于2024年5月29日<ref></ref>，加入了通过投掷[末影珍珠](末影珍珠.md)或[骑乘](骑乘.md)实体穿越传送门的功能，允许[船](船.md)被[拴绳](拴绳.md)牵引，并修复了一些漏洞。

# 新内容
# = 常规 =
* *服务器链接**
* 加入了一些没有特殊功能的通用链接名称，包括“”、“”、“”、“”、“”、“”、“”、“”和“”。

* *[等级依赖函数](魔咒数据格式/等级依赖函数.md)**
* 加入了新类型<code>lookup</code>，将数值的列表映射到对应等级。如果等级高于所提供的数值，则应用回落值。
* * 附加字段：
* ** <code>values</code>：（可选）以<code>-{}-等级-1</code>为索引的数值列表。
* ** <code>fallback</code>：在等级大于<code>values</code>的尺寸时所应用的回落等级依赖函数值。

* *[已配置的结构地物](自定义结构#已配置的结构地物.md)**
* 向类型为<code>jigsaw</code>的结构加入了字段，默认值为<code>apply_waterlogging</code>。
* * 可能的值为：
* ** <code>apply_waterlogging</code>：如果可含水方块覆盖了原有的水，此方块将[含水](含水.md)。
* ** <code>ignore_waterlogging</code>：覆盖原有的水时，不会使任何可含水方块含水。

* *[结构池](结构池.md)**
* 向元素类型<code>single_pool_element</code>加入了可选字段，可选值与拼图结构字段相同。
* * 生成此结构池的元素时将会覆盖从父拼图结构继承的液体设置。

# 更改
# = 方块 =
* *[门](门.md)**
* 现在由不同材料制成的门也能构成双开门。

# = 物品 =
* *[重锤](重锤.md)**
* 现在攻击速度由0.5更改为0.6。

# = 生物 =
* *常规**
* 由[试炼刷怪笼](试炼刷怪笼.md)转变为不祥状态而移除的生物将会掉落它们从地上拾起的物品。

# = 非生物实体 =
* *[船](船.md)和[运输船](运输船.md)**
* 现在可以被[拴绳](拴绳.md)拴住。

* *[被激活的TNT](被激活的TNT.md)**
* 现在能穿越下界传送门。

* *[掷出的末影珍珠](掷出的末影珍珠.md)**
* 现在能穿越传送门将玩家传送至对应维度。

# = 世界生成 =
* *[下界传送门](下界传送门.md)、[末地传送门](末地传送门.md)和[返回传送门](返回传送门.md)**
* 现在骑乘实体可以无延迟地穿越传送门。

* *[试炼密室](试炼密室.md)**
* 现在其中的可含水方块替换水时不再含水。

* *[末地平台](末地平台.md)**
* 末地平台生成时被替换的5×4×5的方块现在会按战利品表生成[掉落物](掉落物.md)。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 移除了[火焰附加](火焰附加.md)点燃方块的功能。
* * 此功能计划在未来的正式版中加入。
* 更改了[风爆](风爆.md)的击退倍率。
* * 现在风爆I、II、III的击退倍率分别为1.2、1.75和2.2，而更高等级风爆的击退倍率为<code>-{}-1.5+(*等级*-1)×0.35</code>。

# = 命令格式 =
* *[目标选择器](目标选择器.md)**
* <code>@n</code>不再能选中濒死的实体。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。
* 为拼图结构和<code>single_pool_element</code>类型加入了可配置字段。

* *[游戏规则](游戏规则.md)**
* 移除了<code>entitiesWithPassengersCanUsePortals</code>，现在将与此规则默认启用的行为一致。

* *[崩溃](崩溃.md)**
* 现在游戏会将区块加载失败的报告储存于文件夹内。

* *魔咒效果生效条件**
* 与战利品表不同，所有条件需为内联对象而非调用谓词。

* *[标签](Java版标签.md)**
* 移除了方块标签<code>#fire_aspect_lightable</code>。

* *[战利品表谓词](战利品表谓词.md)**
* <code>random_chance_with_enchanted_bonus</code>
* * 移除了字段。
* * 加入了字段，用于未附魔物品的概率。
* * 加入了字段，用于已附魔物品的概率，为等级依赖函数。
