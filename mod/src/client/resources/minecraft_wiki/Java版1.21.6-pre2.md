# Java版1.21.6-pre2

*页面ID: 152627* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21.6-pre2**是[Java版1.21.6](Java版1.21.6.md)的第2个预发布版，发布于2025年6月2日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *[声音事件](Java版声音事件.md)**
* 更改了以下声音分类的英文名称：
* * Friendly Creatures → Friendly Mobs
* * Hostile Creatures → Hostile Mobs

* *[对话框](对话框.md)**
* <code>text</code>输入控件：
* * 输出值作为模板替换时，所有的特殊字符（包括<code>'</code>和<code>"</code>）都将被转义存储。
* * <code>multiline</code>字段：
* ** 如果省略了<code>height</code>且指定了<code>max_lines</code>，则输入框为适应最大行数后的高度不会超过512。
