* *马铃薯泥土（Terre de Pomme）**是一种可以在[马铃薯维度](马铃薯维度.md)中大量发现的类似[泥土](泥土.md)的方块。

# 生成
# = 自然生成 =
马铃薯泥土会自然生成于马铃薯维度的地表，也会作为[废弃马铃薯传送门](废弃马铃薯传送门.md)和[马铃薯晶洞](马铃薯晶洞.md)的一部分生成。

# = 土类方块 =
马铃薯维度中的[草方块](草方块.md)、[土径](土径.md)和[耕地](耕地.md)等因各种原因而将要变为泥土时会转化为马铃薯泥土。

若[薯皮草方块](薯皮草方块.md)或[腐败的薯皮草方块](腐败的薯皮草方块.md)在马铃薯维度中直接被液体源方块或下表面遮挡形状完整的方块覆盖（一层高的[雪](雪.md)除外），薯皮草方块或腐败的薯皮草方块会在随机时间后变成马铃薯泥土，而在其他维度中则会变成泥土。

对着薯皮草方块或腐败的薯皮草方块的顶部[马铃薯削皮刀](马铃薯削皮刀.md)会将其变为马铃薯泥土，同时削下1个[黄绿色马铃薯皮](黄绿色马铃薯皮.md)或[腐败的马铃薯皮](腐败的马铃薯皮.md)。

# 获取
没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[薯皮草方块](薯皮草方块.md)、[腐败的薯皮草方块](腐败的薯皮草方块.md)、[剧毒耕地](剧毒耕地.md)和[剧毒土径](剧毒土径.md)被破坏后会掉落1个马铃薯泥土。

# 破坏
挖掘马铃薯泥土的合适工具是锹。

马铃薯泥土被破坏后会掉落自身。

# 用途
# = 种植 =

[草](草.md)、[花](花.md)、[粉红色花簇](粉红色花簇.md)、[枯萎的灌木](枯萎的灌木.md)、[大型垂滴叶](大型垂滴叶.md)、[下界菌](下界菌.md)、[菌索](菌索.md)、[下界苗](下界苗.md)和[杜鹃花丛](杜鹃花丛.md)都能被放置在马铃薯泥土上。[树苗](树苗.md)、[竹子](竹子.md)和[甜浆果丛](甜浆果丛.md)能在马铃薯泥土上生长。[甘蔗](甘蔗.md)和[蘑菇](蘑菇.md)也会在符合条件的情况下在马铃薯泥土上生长。

# = 转变 =

对着马铃薯泥土[锄](锄.md)可将其转变为剧毒耕地，并使锄消耗掉1点耐久。

对着马铃薯泥土[锹](锹.md)可将其转变为剧毒土径，并使锹消耗掉1点耐久。

对着[苔藓块](苔藓块.md)[骨粉](骨粉.md)可以使其3×3至7×7格范围内上方为空气的马铃薯泥土转变成苔藓块。

[大型云杉](树木.md)长成后会将其周围的马铃薯泥土转变为[灰化土](灰化土.md)。

对着马铃薯泥土[水瓶](水瓶.md)或发射器发射水瓶会将马铃薯泥土转化为[泥巴](泥巴.md)。

对着马铃薯泥土的顶部黄绿色马铃薯皮或腐败的马铃薯皮会将马铃薯泥土转化为薯皮草方块或腐败的薯皮草方块。
