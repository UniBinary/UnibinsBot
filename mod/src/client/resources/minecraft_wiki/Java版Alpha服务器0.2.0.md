# Java版Alpha服务器0.2.0

*页面ID: 45477* | *来源: Minecraft Wiki*

* *0.2.0**是一个[Alpha](Java版Alpha.md)服务器版本，与[客户端1.1.0](Java版Alpha v1.1.0.md)在2010年9月10日一起发布。<ref>
</ref>

# 新内容
* 加入了服务器侧背包。
* 使服务器可以保存玩家退出服务器时的位置。

# 更改
* 使得[箱子](箱子.md)、[告示牌](告示牌.md)和[熔炉](熔炉.md)能在多人游戏中正常工作。
* 向[server.properties](server.properties.md)中加入了<code>monstersfalse</code>。
* * 此设置可以开启实验性生物，但是它们不能被直接伤害。
