# 基岩版1.19.50.22

*页面ID: 99463* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.50.22**（Android）、**Preview 1.19.50.22**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.50](基岩版1.19.50.md)的第3个测试版，发布于2022年10月26日<ref></ref>，在[实验性玩法](实验性玩法.md)中调整了一些特性，并修复了一些漏洞。

# 更改
# = 生物 =
* *[史莱姆](史莱姆.md)和[岩浆怪](岩浆怪.md)**
* 现在能够攻击多个目标。
* 现在能够对[铁傀儡](铁傀儡.md)和[雪傀儡](雪傀儡.md)造成伤害。
* 现在每攻击一次会有0.5秒的冷却时间。

# = 常规 =
* *[角色创建器](角色创建器.md)**
* 加入了一个介绍新的Minecraft初始角色和使用这些角色作为外观的方式的新流程。

# = 技术性 =
* *Molang**
* 更改了的返回值，现在当组件存在时会返回1，不存在时会返回0。

* *常规**
* 开放了1.19.50及以上版本的实验性JSON格式中的。
* 开放了1.19.50及以上版本的实验性JSON格式中的。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”子选项后才可使用。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 更改了骆驼刷怪蛋的颜色。

# = 生物 =
* *[骆驼](骆驼.md)**
* 现在冲刺距离会受到[迅捷](迅捷.md)和[跳跃提升](跳跃提升.md)效果的影响。
* 现在会持续进行冲刺，直到接触到地面或水。
* 现在会自然恢复生命值。
* 调整了行走的循环动画。
* 现在行走动画会与移动速度相匹配。

# = 常规 =
* *控制器工具提示**
* 加入了“放置书”控制器工具提示。
* * 当手持[书](书.md)、[书与笔](书与笔.md)、[成书](成书.md)或[附魔书](附魔书.md)的玩家看向未装满书本的[雕纹书架](雕纹书架.md)时出现。
* 加入了“移除书”控制器工具提示。
* * 当玩家看向装有书本的雕纹书架时出现。

# 修复
* *实验性**
* 修复了雕纹书架的配方问题，以使其能够由带有标准标签的任意木板和木质台阶合成。

* *游戏内容**
* 修复了玩家卡在方块内时能够穿过某些墙的问题。（）
* 现在当玩家卡在方块内时，其会被推到最近的空旷区域。

* *图形**
* 修复了帧率显示不正确而导致回到游戏后性能不稳定的问题。
* 现在使用ANGLE的Android设备上的生物阴影会正确渲染。（）

* *物品**
* 使用铁砧附魔或修复物品时不再会意外地重命名物品。（）

* *生物**
* 修复了史莱姆和岩浆怪在每一随机刻都能消耗盾牌耐久度的漏洞。（）
* 修复了河豚在每一随机刻都能消耗盾牌耐久度的漏洞。（）
* 被摧毁的盔甲架现在会掉落其副手上的物品。（）
* 修复了在末影龙存活的情况下保存并加载世界时，末影龙会无法加载的漏洞。（）

* *性能与稳定性**
* 修复了低内存设备上加载部分市场世界时可能导致游戏崩溃的问题。（）
* 修复了不被玩家拥有的活动对象进入末地传送门时可能发生的崩溃。

* *触摸控制**
* 修复了移动设备上的游泳问题；手持弓、弩或三叉戟并蓄力时不再会立即发射武器。（）
* 修复了手指触摸到快捷栏时会打断摇杆手势的问题。（）
* 修复了不能使用新的触摸控制与部分资源包下的快捷栏交互的问题。（）
* 现在十字准星模式下的疾跑和向下飞行的按钮拥有与其他按钮相同的颜色。（）
* 修复了在新的触摸控制下快速点击向上飞行和向下飞行按钮会取消飞行状态的问题。现在起，双击向下飞行按钮会取消飞行状态。（）
* 现在状态效果图标会在触控模式下适应安全区域。
* 调整了状态效果图标，现在会在屏幕宽度上排成一行，以在触控模式下适应新的触摸控制。

* *原版趋同**
* 现在睡莲被船撞到时会发出音效和粒子效果。（）
* 现在大多数因为没有支撑而被破坏的方块拥有视觉粒子、音频效果和引发振动的事件。
* 珊瑚扇不再能够放置在台阶的侧面。（）
* 珊瑚扇现在能够在玻璃之类的透明固体方块上存活。（）

* *方块**
* 雕纹和切制红砂岩现在拥有平滑的底面。（）

* *旁观模式**
* 旁观模式玩家不再能够通过幽匿尖啸体来召唤监守者。
* 旁观模式玩家不再能够激活幽匿感测体和压力板。（）
* 旁观模式玩家不再会阻拦普通玩家与其他实体（例如方块、按钮、拉杆）交互。

* *配方**
* 现在拥有相同输入材料和不同输出物品的配方会被标记为内容日志错误（合成配方和切石机配方除外）。

* *用户界面**
* 修复了聊天设置中下拉框箭头、开关和滑条的对比问题。</onlyinclude>
