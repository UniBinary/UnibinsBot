# 基岩版1.13.0.16

*页面ID: 48354* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.13.0.16**是[1.13.0](基岩版1.13.0.md)的第9个测试版，发布于2019年9月26日<ref></ref>，修复了一些漏洞。</onlyinclude>

# 更改
# = 生物 =
* *[狐狸](狐狸.md)**
* 跳跃攻击距离从11格减少至5格，以匹配。

# 修复
* *修复了19个漏洞**<br>
* *崩溃/性能**
* 改进了打开物品栏时的性能。
* 改进了方块渲染。
* 攻击河豚时游戏崩溃。
* 使用角色创建器时游戏崩溃。

* *常规**
* 部分修复了导致全局资源包不能在重新启动游戏后启用的问题。
* 已经装备的皮肤在重新启动游戏后不会保留。

* *游戏内容**
* 含水的方块在同一个区块里出发红石更新时出现问题。
* 对着生物点击骑乘时会消耗手持的物品。（）

* *生物**
* 末地水晶不可见。（）
* 狐狸叼着的物品不可见。（）
* 将狐狸的跳跃攻击距离从11格减少至5格，以匹配Java版。
* 马的模型和纹理被回退到旧版本。

* *物品**
* 手持的物品在第三人称模式下出现位置偏移。

* *角色创建器**
* 改进了使用控制器在角色创建器里导航功能。
* 躯干部分的纹理与角色主体不对齐。
* 删除角色的界面不再出现透明的背景。

* *命令**
* 修复了命令的功能。
* 修复了使用命令的错误信息。

* *附加包和脚本引擎**
* 使用附加包创建自定义的凋灵时不会出现Boss条。
