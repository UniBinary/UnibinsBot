# 携带版0.12.1.b4

*页面ID: 27843* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.12.1 alpha build 4**是[v0.12.1 alpha](携带版0.12.1.md)的第4个测试版，发布于2015年8月4日，修复了一些漏洞。
# 更改
* [石英柱](石英柱.md)现在可以水平放置。
* 现在尝试连接到旧版本的多人游戏将会显示错误消息。
* 加入[附魔金苹果](附魔金苹果.md)的合成配方。
* 向创造模式物品栏加入了[附魔书](附魔书.md)。
* 如果切石机和工作台在使用的情况下被破坏，[切石机](切石机.md)和[工作台](工作台.md)的GUI现在将关闭。
* 改进了控制的效果。

# 修复

* *其他**
* 多人游戏下，践踏耕地不会使其退化成泥土。
* 多人游戏下，打开物品栏的按键没有作用。
* 多人游戏下的合成配方显示错误。
* 多人游戏下，某些方块的行为不正常。
* 迅速进入下界会使得游戏崩溃。
* 控制器断开连接后，玩家会一直保持最后一个操控的动作。
* 创造模式下玩家不能饮用药水。
* 节肢杀手魔咒对蜘蛛失效。
* 熔炉内可以显示玩家物品栏里不存在的物品。
* 超平坦世界中的天空是黑色的。
* 左手模式下出现错误。</onlyinclude>
