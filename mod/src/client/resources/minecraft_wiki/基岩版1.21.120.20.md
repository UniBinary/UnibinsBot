# 基岩版1.21.120.20

*页面ID: 165557* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.120.20**（ChromeOS/Android）、**Preview 1.21.120.20**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.120](基岩版1.21.120.md)的首个测试版，发布于2025年9月3日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了“Music by Hyper Potions!”闪烁标语。

# 更改
# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* 现在骑乘在[鸡](鸡.md)上的幼年[僵尸](僵尸.md)、幼年[僵尸村民](僵尸村民.md)和幼年[尸壳](尸壳.md)被驯服的[狼](狼.md)杀死后也会额外掉落一张[音乐唱片Lava Chicken](音乐唱片Lava Chicken.md)。

* *[谜之炖菜](谜之炖菜.md)**
* 现在可以在[创造模式物品栏](创造模式物品栏.md)中找到。
* 现在[创造模式](创造模式.md)下的谜之炖菜会在其[提示框](提示框.md)中显示食用后给予的[状态效果](状态效果.md)以及效果时长。

# = 游戏内容 =
* ***
* 为天气效果加入了类似于雪的TAA上采样功能。
* 将“调整亮度”[设置](设置.md)重命名为“”。
* 为伽马值校准屏幕加入了“重置为默认值”按钮。
* 现在伽马值校准屏幕中的滑块会显示当前的伽马值，滑块的中间对应默认伽马值。

# = 常规 =
* *[鸣谢名单](鸣谢名单.md)**
* 将Hyper Potions添加到鸣谢名单中。

* *[声音](声音.md)**
* 将的衰减距离由12格更改为1-12格。

* *图形**
* 现在相机视角过于靠近或穿过实体时，实体会略微变得透明。

# 修复
* *方块**
* 蝌蚪现在会在青蛙卵下方的水中生成。（）
* 修复了无法在冒险模式中继续破坏处于水下的有效方块的问题。
* 现在向展示架添加红石信号，或者移除指向或来自展示架的红石信号时会发出振动。
* 调整了铁砧和墙放在展示架和物品展示框中时的位置。（）
* 现在玩家对未激活的展示架放置/移除/交换物品时会发出频率为3的振动。
* 现在玩家对激活的展示架放置/移除物品时会发出频率为3的振动。
* 现在玩家将物品与展示架上的物品进行交换时会发出频率为6的振动。

* *命令**
* 修复了命令对末地水晶施加伤害时会不正确地汇报执行失败的问题。（）
* 修复了命令的问题，以使该命令不再会指引玩家到错误区域。（）

* *游戏内容**
* 修复了非常旧的世界中的告示牌文本的加载问题。

* *常规**
* 现在启动缺失市场模板的世界时会正确地重新下载模板并启动世界。
* 现在第一人称相机视角会在面向并攀爬如梯子和藤蔓等方块时略微向后偏移。

* *图形**
* 恢复了在计算不完整方块的环境光遮蔽方面上的Java版趋同性。（）
* 修复了附魔光效动画在游戏暂停时仍会播放的问题。（）
* 修复了玩家移动期间雪花会闪烁的问题。
* 提高了PC和主机上的伽马值校正质量，并更正了的伽马值校准屏幕中的苦力怕纹理的亮度。

* *物品**
* 谜之炖菜现在存在于创造模式物品栏，并带有效果描述。（）

* *生物**
* 现在玩家在副手持有物品的情况下或在装备有盔甲的情况下与铜傀儡交互时，铜傀儡会掉落其携带的物品。（）
* 坐下姿势的铜傀儡像不再会有切断的像素。（）

* *音效**
* 现在铜箱子打开和关闭音效遵循自然衰减曲线。（）
* 现在铜傀儡行走和旋转音效遵循自然衰减曲线。

* *用户界面**
* 现在即使是滚动的消息框，点击文本框时也会将光标放在正确点位。（）
* 现在聊天屏幕上的键盘按钮仅对触摸控制可见。（）
* 修复了可能导致物品栏中没有纹饰的盔甲出现盔甲纹饰的漏洞。
* 更新了需要更多玩家睡觉才能跳到白天时显示的文本。（）
* 修复了本地数据存在但无效时，Xbox云存储支持的世界会显示默认图块的问题。
* 修复了玩家无法在携带版UI将物品从创造模式物品栏移动到物品栏中的漏洞。（）

* *世界生成**
* 结构不再会在区块边界的地物（如树）上构建。</onlyinclude>
