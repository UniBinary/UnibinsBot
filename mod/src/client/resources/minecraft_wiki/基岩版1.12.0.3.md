# 基岩版1.12.0.3

*页面ID: 42795* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.12.0.3**是[1.12.0](基岩版1.12.0.md)的第2个测试版，发布于2019年5月1日<ref></ref>，加入了新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了以下闪烁标语：<ref></ref>
* *“All blocks covered!”
* *“feedback.minecraft.net”
* *“IT came from space.”
* *“Rainbow turtle?”
* *“Something funny!”
* *“I need more context.”
* *“Ahhhhhh!”
* *“Don't worry, be happy!”
* *“Water bottle!”
* *“What's the question?”
* *“Plant a tree!”
* *“Go to the dentist!”
* *“What do you expect?”
* *“Look mum, I'm in a splash!”

# 更改
# = 方块 =
* *[竹子](竹子.md)**
* 更改了纹理，增加其纹理亮度，以匹配[Java版](Java版.md)。（）

* *[烟熏炉](烟熏炉.md)**
* 现在其底面使用单独的纹理，而非顶面纹理。

# = 生物 =
* *[僵尸](僵尸.md)和[卫道士](卫道士.md)**
* 现在能更快破坏门。

# = 常规 =
* *[菜单屏幕](菜单屏幕.md)**
* 将主菜单中的“商店（Store）”按钮重命名为“市场（Marketplace）”。

* *[附加包](附加包.md)**
* 行为包模板中再次包含文件夹了。
* 在行为包模板中加入了配方和物品JSON文件。

* *[交易](交易.md)**
* 更改了[屠夫](屠夫.md)村民的[熟兔肉](熟兔肉.md)的交易价格，由5个[绿宝石](绿宝石.md)减少至1个。
* 现在[制箭师](制箭师.md)村民一次出售16根[箭](箭.md)，而不是5根。
* 制箭师村民不再会出售[林地探险家地图](林地探险家地图.md)。
* 调整了[石匠](石匠.md)村民的交易项。
* * 学徒级石匠现在会出售[磨制花岗岩](磨制花岗岩.md)、[磨制闪长岩](磨制闪长岩.md)、[磨制安山岩](磨制安山岩.md)或[雕纹石砖](雕纹石砖.md)，而不总是出售雕纹石砖。
* * 老手级石匠不再会出售磨制花岗岩、磨制闪长岩或磨制安山岩。
* * 专家级石匠现在会出售[染色陶瓦](染色陶瓦.md)。
* * 大师级石匠现在会出售[石英块](石英块.md)或[石英柱](石英柱.md)，而不总是出售石英柱。
* 现在[皮匠](皮匠.md)村民出售的[鞍](鞍.md)的价格为6个绿宝石，而不是10个。
* 现在[流浪商人](流浪商人.md)会以3个绿宝石的价格出售1个[珊瑚块](珊瑚块.md)，此前为1个绿宝石的价格出售3个。
* 现在流浪商人一次会出售3个[灰化土](灰化土.md)，而不是1个。

* *[闪烁标语](闪烁标语.md)**
* 移除了所有有关[Notch](Notch.md)的闪烁标语：
* * “Made by Notch!”
* * “The Work of Notch!”
* * “110813!”

# 修复
* *修复了51个漏洞**<br>
* *崩溃**
* 修复了游戏进行时的崩溃现象。
* 修复了加载部分模板世界时发生的崩溃。

* *性能**
* 改进了村庄和工作站点方块的性能。
* 修复了使用脚本引擎时的内存溢出现象。

* *常规**
* 修复了消耗堆叠里最后一个物品时无法解锁相应的成就的问题。

* *游戏内容**
* 玩家模型里的手臂和腿部不再被翻转。（）
* “讨价还价”成就现在可以正确解锁。
* 村民购买物品时现在会正确拿走输入槽的第二个物品。
* 手持盾牌和三叉戟不再使它们隐形。（）
* 离开船后，玩家不再可以通过卡进方块里来透视世界。（）

* *生物**
* 已驯服的西服猫现在使用正确的纹理。（）
* 转换自1.10的世界的村庄里的流浪猫不再能认领村庄里的床。（）
* 模板世界里现在只能生成旧版村民。
* 女巫被攻击时不再主动跳跃。
* 修复了皮肤包里部分皮肤的旋转动画。
* 刷怪笼里的恶魂模型现在有正确的体积。
* 改进了部分体型较大或较小生物的寻路AI。
* 僵尸和卫道士现在能更快破坏门。
* 修复了流浪商人的灰化土和珊瑚交易选项。
* 制箭师村民现在会一次出售16根箭，而不是5根。
* 更改了屠夫村民的熟兔肉交易价格。
* 皮匠村民提供的鞍现在需要花费6个绿宝石购买，而不是10个。

* *方块**
* 流动的熔岩触碰水后再次会生成圆石。（）
* 霜冰现在可以被正常破坏。（）
* 台阶和其他非固体方块现在再次能阻止草方块退化成泥土。（）
* 现在再次能使用斧给原木剥皮。（）
* 铁轨构成三岔口时，现在再次可以使用红石信号来改变铁轨转向。（）
* 修复了烟熏炉的底部纹理。（）
* 盔甲架现在可以被装备上盔甲架物品。

* *物品**
* 配方书里的旗帜合成配方现在会正确显示羊毛的颜色。
* 修复了部分工具在使用时不消耗耐久度的问题。

* *图形**
* 第一人称下的玩家进食时手臂位置不再出现错误。（）
* 堆肥桶发出的粒子位置现在出现在正确的位置。
* 修复了部分资源包里的流动水和熔岩纹理。
* 修正了门和活板门里出现的多余灰色纹理。

* *用户界面**
* 使用触摸屏时，合并同类物品时不再使得它们被交换位置。
* 使用触摸屏时，交换副手槽物品不再使得目标物品消失。 （）
* 游戏指南里的制图台选项现在会指向正确的位置。
* 甜浆果在快捷栏里被选中时不再消失。
* 杀死行商羊驼不再使得它的物品栏被打开。

* *命令**
* 移除了命令里的前缀。（）
* 使用命令时，创造模式物品栏里没有出现的方块或实体刷怪蛋不再需要输入命名空间前缀。
* 命令方块里的命令不再需要输入来实现自动补全功能。（）

* *附加包和脚本引擎**
* 文档现在会正确生成。
* 纠正了方块事件的描述。
* 自定义实体现在会重新评估当前目标的有效性。
* 现在会返回方块对象的三维数组。
* 修正了组件里的错误实体组件名称。
* 和现在在给予活动对象位置（或者任意非整形的位置）时会正确处理获取方块的目标。</onlyinclude>
