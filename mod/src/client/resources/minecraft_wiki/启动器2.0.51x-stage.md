# 启动器2.0.51x-stage

*页面ID: 63556* | *来源: Minecraft Wiki*

<onlyinclude>
* *2.0.510-stage**（[Windows](wzh:Microsoft Windows.md)）或**2.1.511-stage**（[macOS](wzh:macOS.md)）是一个[启动器](启动器.md)版本，发布于2017年1月3日，修复了一些漏洞。

# 修复
* 提高了新字体的可读性。
* 修复分辨率。
* 收集的使用情况数据现在可以在启动器选项中将其关闭。</onlyinclude>
