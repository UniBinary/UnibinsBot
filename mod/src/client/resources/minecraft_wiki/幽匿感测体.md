* *幽匿感测体（Sculk Sensor）**是一种可以检测振动并发出[红石信号](红石信号.md)、激活附近[幽匿尖啸体](幽匿尖啸体.md)的方块。

# 生成
# = 自然生成 =
幽匿感测体可作为[幽匿斑块](幽匿斑块.md)的一部分自然生成于[深暗之域](深暗之域.md)生物群系，也可以作为红石元件自然生成于[远古城市](远古城市.md)中心的灯柱和地下室。

# = 幽匿催发体 =

死后会掉落[经验](经验.md)的[生物](生物.md)在距[幽匿催发体](幽匿催发体.md)半径或内的位置死亡时，周围的[幽匿块](幽匿块.md)上有9%的概率生成幽匿感测体，每次生成消耗1点经验。

# 获取
# = 箱子战利品 =

# 破坏
挖掘幽匿感测体的合适工具是锄。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，幽匿感测体被破坏后会掉落。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，幽匿感测体被破坏后会掉落自身。

# 用途
# = 合成材料 =

# = 振动检测 =
[thumb|幽匿感测体检测振动的粒子效果|class=pixel-image](File:Vibration (texture) JE1 BE1.gif.md)
幽匿感测体可以检测半径8格范围内由物体的动作产生的振动，但它们不会检测[潜行](潜行.md)的生物发出的部分振动（如行走、摔落或掷出弹射物时发出的振动；潜行时踩踏该幽匿感测体的振动除外）、[监守者](监守者.md)发出的所有振动和其他幽匿感测体发出的振动。

当幽匿感测体检测到振动时，振动源会以每游戏刻1格，即每秒20格的速度向其发出信号粒子；信号到达时，幽匿感测体会激活1.5秒，并在周围产生渐变色粒子；激活时间过后，幽匿感测体还会有0.5秒的冷却时间。从信号开始发出到冷却时间结束，幽匿感测体都不会再检测其他振动，因此不可能出现多个信号同时传向同一个幽匿感测体的情况，也不会发生幽匿感测体被自身取消激活的振动反复激活的情况。冷却时间结束后，幽匿感测体才能继续检测振动。

[羊毛](羊毛.md)会吸收经过的信号，被吸收的信号不会被幽匿感测体接收。羊毛或[地毯](地毯.md)的[物品实体](物品实体.md)掉在地上、在羊毛或地毯上行走以及放置羊毛或地毯发出的振动不会被检测。

幽匿感测体可[含水](含水.md)。含水的幽匿感测体不会发出任何声音，但仍可检测周围的振动。

当[实体](实体.md)位于幽匿感测体上时，幽匿感测体会持续地周期性激活。

# = 幽匿尖啸体 =
幽匿感测体被玩家的行为激活时会发送信号给半径8格内的[幽匿尖啸体](幽匿尖啸体.md)，将其激活。

# = 红石元件 =
[thumb|300px|在不同距离触发幽匿感测体时，红石输出的可视化效果<ref></ref>](File:A visualization of the redstone output when triggering Sculk Sensors at difference distances.jpg.md)

幽匿感测体被激活时会：
* 激活毗邻的红石线，并改变水平方向上毗邻的红石线的指向。信号强度取决于幽匿感测体到振动源的距离。
* 激活四周背对幽匿感测体的[红石中继器](红石中继器.md)和[红石比较器](红石比较器.md)。信号强度取决于幽匿感测体到振动源的距离。
* 激活毗邻的[机械元件](红石元件.md)（如[门](门.md)、[红石灯](红石灯.md)等），包括幽匿感测体上面的和下面的机械元件（但不能激活一些拒绝该方向输入的机械元件，如面朝该幽匿感测体的[活塞](活塞.md)）。

幽匿感测体发出的红石信号强度与幽匿感测体到振动源的距离呈负相关性质，即振动传播距离越短，幽匿感测体发出的红石信号越强。
   具体公式为：<code>-{}-max{1, 15 - floor(*距离* * 1.875)}</code>

当振动源位于幽匿感测体正上方（距离为0）时，幽匿感测体会输出最大的红石信号强度15。

当幽匿感测体探测到它上面的实体时，输出的红石信号强度始终为15。

# == 振动频率 ==
游戏内每种振动都有不同的频率，幽匿感测体收到的振动的频率可以被[红石比较器](红石比较器.md)检测并作为主输入端输入。红石比较器检测幽匿感测体得到的信号仅与振动频率相关，与振动的远近无关。玩家可以借此探知幽匿感测体周围发生的事件类型。

当幽匿感测体探测到它上面的实体时，其振动频率为1。

幽匿感测体检测到振动时，与之相邻的[紫水晶块](紫水晶块.md)会发生**共振**，即发送一个频率相同的振动。

# = 光源 =
幽匿感测体无论是否被激活亮度都为1，但激活时在视觉上会发出更亮的偏黄的光。
