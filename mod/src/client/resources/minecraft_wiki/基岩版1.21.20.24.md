# 基岩版1.21.20.24

*页面ID: 124131* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.20.24**（ChromeOS/Android）、**Preview 1.21.20.24**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.20](基岩版1.21.20.md)的第9个测试版，发布于2024年7月25日<ref></ref>，修复了一些漏洞。

# 更改
# = 技术性 =
* *[附加包](附加包.md)和脚本引擎**
* 修复了粒子外观布告板组件的默认UV不正确的问题。（）

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“”子选项后才可使用。

# = 技术性 =
* *图形**
* 延迟渲染预览功能不再支持低于iPhone 8、iPad（第8代）或iPad Mini（第5代）的iOS设备。

# 修复
* *游戏内容**
* 靠近屏幕边缘时大型箱子不再会消失。（）
* 修复了旧版世界中的双层植物会被破坏的问题。（）
* 现在玩家重进世界时会面朝与离开时相同的方向。（）</onlyinclude>
