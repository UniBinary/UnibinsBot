# 黏液块

*页面ID: 11499* | *来源: Minecraft Wiki*

</ref>||Tom Stone Mojavatar.png}}

* *黏液块（Slime Block）**是一种允许玩家在其上进行弹跳的[光照透明方块](光照透明方块.md)。

# 生成
黏液块不会生成在世界中。

# 破坏
黏液块被挖掘时会立刻被破坏。

黏液块被破坏后会掉落自身。

# 用途
玩家落至黏液块上不会受到摔落伤害。

黏液块有一些滑，但程度不及[冰](冰.md)。

黏液块会减缓在其上移动的[实体](实体.md)的速度。

# = 弹跳性 =
黏液块会弹起掉落在其上方的玩家、生物和粒子（[物品实体](物品实体.md)、[下落的方块](下落的方块.md)、[矿车](矿车.md)和[船](船.md)等不受影响），弹起高度与下落高度有关。连续弹跳时，弹跳高度会迅速衰减，最大弹跳高度约为57.625格。
忽略离散化运动，史莱姆方块的反弹高度
  <math>\frac{gf}{1-f}\left(\frac{(1-\alpha)f}{1-f}+\log_f(2-\alpha)\right)</math>
，其中
  <math>\alpha = \frac{1-f}{\ln f}W_0\left(\frac{\ln f}{1-f}f^{\frac{1}{1-f}+\frac{(1-f)h}{gf}}\right)</math>
，<math>h</math> 为下落高度、<math>g</math> 为重力（预设为 0.08）、<math>f</math> 为阻力乘数（预设为 0.98）。
* 例如，从255格的高度落至黏液块上会被弹起约50格；从100格的高度落至黏液块上会被弹起32格；从50格的高度落至黏液块上会被弹起约23格。

如果玩家落在黏液块上面时保持，则不会继续弹跳。若玩家落在黏液块上面时按住，会额外获得向前的动力，因此可以使玩家跳得更远，在疾跑时尤为显著。

除[鸡](鸡.md)、[恶魂](恶魂.md)、[蝙蝠](蝙蝠.md)、[幻翼](幻翼.md)、[蜜蜂](蜜蜂.md)、[鹦鹉](鹦鹉.md)和[恼鬼](恼鬼.md)外，大多数生物均可在黏液块上反复弹跳。当玩家试图在黏液块顶部生成一匹[马](马.md)时，这匹马可能会“陷进”黏液块里。

在黏液块上放置[地毯](地毯.md)、[铁轨](铁轨.md)、[活板门](活板门.md)、[红石中继器](红石中继器.md)或[红石比较器](红石比较器.md)都不会使生物停止弹跳，也不会让其受到摔落伤害。[炼药锅](炼药锅.md)和[堆肥桶](堆肥桶.md)也有相同的效果，但仅限于中心区域。与之类似，在黏液块上放置[压力板](压力板.md)也能得到同样的效果，但会使压力板被激活。[蛋糕](蛋糕.md)、[台阶](台阶.md)和其他半体积方块则会终止弹跳。

# = 物品运输 =
当黏液块表面有水流通过时，其表面上的可捡拾[物品](物品.md)将会快速移动（但速度不及它们在[冰](冰.md)面上的速度）。这一特性对于[资源](物品（实体）.md)运输尤其管用，但须将物品以一定角度抛出，且不受水流位置影响（就算水流并不在黏液块顶部，运输也可以进行）。由于黏液块不会融化，相比于冰来讲，它们的安全性更佳。

# = 通过活塞移动 =

取决于首先激活的侦测器，则取决于两个活塞的随机优先级（可通过牺牲掉双向运行能力解决，将一侧的黏性活塞改为普通活塞，活塞虫将向普通活塞指向的方向移动）。

当黏液块被[活塞](活塞.md)推动时，实体（[末影龙](末影龙.md)、和[画](画.md)除外）会向着被推动的方向弹射出去。当活塞收回时，则不会弹射实体。

当黏液块被活塞推动或拉动时，它会试图带着所有相邻的方块朝自身移动的方向移动。可以被它移动的方块种类与[能被黏性活塞**拉回**](活塞#移动方块结构.md)的方块相同。无法被黏性活塞拉回的方块会留在原位。而被移动的方块则会依次推动其他方块，而不单是在活塞前面的方块。举例来说，一个在地上的黏液块会试图移动它自身下方的地面方块，从而在移动的方向上依次推动附加的地面方块，就像它被活塞直接推动一样。

[蜂蜜块](蜂蜜块.md)是唯一的例外，虽然它能被黏性活塞拉动，但在毗邻的黏液块被移动时，它们**不会**随之移动。[带釉陶瓦](带釉陶瓦.md)不能被黏性活塞拉动，因而也无法随黏液块移动。

当黏液块被相邻的黏液块移动时会发生同样的情况。举例来说，当一个单独的活塞作用于一个2×2×2正方体的黏液块里面的任何一个方块时，它能做为一个单位被整体推动或拉动。

当黏液块和活塞不能移动的方块相邻时，它会忽略不动的方块。但是如果相邻的方块可被移动但被不动的方块挡住，黏液块将不会移动。

黏液块不能被非黏性活塞拉动，当它相邻的非黏液块被活塞移动时它也不会移动。

活塞最大可移动12个方块依然适用。举例来说，12个连在一起的黏液块可以被黏性活塞推动或拉动，如果再继续连接其他可移动方块，活塞就不再能将其移动了。

活塞不能通过黏液块的“挂钩”构造来移动自身，但可用多个活塞建造[自动行走装置](Tutorial:飞行器.md)。

# 你知道吗
* 若速度足够快，一个飞出[铁轨](铁轨.md)并落在黏液块上的[矿车](矿车.md)可以弹到对面的铁轨上。
* [兔子](兔子.md)不会在黏液块上跳跃。
* 被活塞上的黏液块向上弹出的实体将上升略大于6.4个方块，其中包括活塞的上升距离。被横向弹出的实体将在弹射方向上移动3.510个方块。
* 当玩家落到黏液块上时尝试跳跃会导致玩家弹起的高度减少到不到格。
