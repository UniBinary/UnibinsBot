# 启动器1.0.9

*页面ID: 49342* | *来源: Minecraft Wiki*

* *1.0.9**是2013年7月10日发布的[启动器](启动器.md)版本。

# 新增
* 增加了对新漏洞汇报系统[Hopper](https://web.archive.org/web/20191028165359/http://hopper.minecraft.net:80/)的支持。
* * 任何客户端报错都会自动上传错误报告。

# 修复
*  - 客户端令牌冲突会阻止玩家登录服务器。
