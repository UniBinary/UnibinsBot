# Java版22w13a

*页面ID: 94453* | *来源: Minecraft Wiki*

<onlyinclude>

* *22w13a**是[Java版1.19](Java版1.19.md)的第3个快照，发布于2022年3月31日<ref></ref>，加入了新生物[悦灵](悦灵.md)和3个新[进度](进度.md)，从[实验性快照](Java版1.19-exp1.md)中加入了[远古城市](远古城市.md)结构和[强化深板岩](强化深板岩.md)方块，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[强化深板岩](强化深板岩.md)**
* 自[实验性快照](Java版1.19-exp1.md)加入。
* 一种生成于远古城市结构中心的深板岩变种，不可合成。
* 具有极高的硬度和爆炸抗性。
* 与实验性快照不同，强化深板岩不再能被活塞推动。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了[悦灵](悦灵.md)刷怪蛋。

# = 生物 =
* *[悦灵](悦灵.md)**
* 一种小巧可爱的蓝色飞行生物，长有与[恼鬼](恼鬼.md)相似的双翼。
* 自然生成于[林地府邸](林地府邸.md)的3种监狱房内和[掠夺者前哨站](掠夺者前哨站.md)的一部分笼子中。
* * 由于漏洞，此版本在加载生成悦灵的[区块](区块.md)时游戏进程会被挂起。<ref></ref>
* 若玩家对悦灵物品，悦灵会手持该物品、信任并跟随该玩家，并在附近区域寻找与手持物相同的[掉落物](掉落物.md)投掷给玩家。
* * 每次给予物品后会有一段短暂时间不能捡起物品。
* 若周围有[音符盒](音符盒.md)奏响，悦灵会在其周围嬉戏并标记该音符盒为最喜爱的音符盒，保持30秒。
* * 期间，悦灵会改为将物品带到此音符盒处。
* 空手与悦灵可以将悦灵手持的物品取下。
* 手持物品时免疫主人对其造成的伤害。

# = 世界生成 =
* *[远古城市](远古城市.md)**
* 自[实验性快照](Java版1.19-exp1.md)加入。
* 一种生成于[深暗之域](深暗之域.md)的大型城池状结构，大体由[深板岩](深板岩.md)、[玄武岩](玄武岩.md)和[羊毛](羊毛.md)及它们的变种筑成。
* 现在固定在Y=-52处生成。
* 较实验性快照添加并修改了许多组成结构：
* * 现在包含更多种类的方块，如[深色橡木](深色橡木.md)制方块、[梯子](梯子.md)、青色、蓝色和淡蓝色的[羊毛](羊毛.md)和[地毯](地毯.md)，以及某些结构中的特殊方块。
* * 入口现在有<code>entrance_path</code>、<code>entrance_connector</code>等新变种。
* * 城墙现在有<code>bridge</code>、<code>passage</code>、<code>ruined</code>等新变种。
* * 建筑现在有<code>camp</code>、<code>ice_box</code>、<code>small_statue</code>、<code>tall_ruins</code>等新变种。
* * 中心结构现在有3个变种，并且增加了含有多种红石装置的地下室。
* ** 地下室经一道机关暗门与外部相隔，内有[红石线](红石线.md)、[红石火把](红石火把.md)、[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)、[红石块](红石块.md)、[红石灯](红石灯.md)、[黏性活塞](黏性活塞.md)、[幽匿感测体](幽匿感测体.md)、[标靶](标靶.md)、[讲台](讲台.md)等元件和相应的电路。
* ** 变种不同，地下室入口处的电路也不同。
* ** 一种变种的地下室有一个[熔炉](熔炉.md)，产物槽有24个[深板岩](深板岩.md)，燃料槽有1把木[锹](锹.md)；祭坛上有一个[箱子](箱子.md)，当中总是装着一个[金胡萝卜](金胡萝卜.md)。
* 较实验性快照修改了[箱子战利品](箱子战利品.md)：
* * 向战利品表中添加了附魔钻石[盔甲](盔甲.md)、[音乐唱片](音乐唱片.md)、[紫水晶碎片](紫水晶碎片.md)、[附魔金苹果](附魔金苹果.md)、[发光浆果](发光浆果.md)等物品。
* * 为<code>ice_box_1</code>子结构设置了单独的战利品表，包含[浮冰](浮冰.md)、[雪球](雪球.md)、[烤马铃薯](烤马铃薯.md)、[谜之炖菜](谜之炖菜.md)和[金胡萝卜](金胡萝卜.md)。

# 更改
# = 方块 =
* *[音符盒](音符盒.md)**
* 现在仅有[羊毛](羊毛.md)和羊毛[地毯](地毯.md)可以阻止音符盒发出声音。

* *[红石粉](红石粉.md)**
* 现在红石线对斜上斜下的[PP更新](方块更新#PP更新.md)仅发给其他红石线。此前红石线放置、破坏、改变状态时，对它水平指向的任意方块，若它不是另一个红石线，则向它上下侧的方块（侦测器除外）发送PP更新。

* *[幽匿尖啸体](幽匿尖啸体.md)**
* 现在可以使用附有[精准采集](精准采集.md)魔咒的工具采集。
* 现在又能被[幽匿催发体](幽匿催发体.md)催生出了。<ref></ref>
* 加入了<code>can_summon</code>方块状态，用于决定其是否可以生成[监守者](监守者.md)。
* * 世界生成过程中放置的默认为<code>true</code>。
* * [幽匿催发体](幽匿催发体.md)蔓延出的以及玩家放置的默认为<code>false</code>。

# = 非生物实体 =
* *[运输矿车](运输矿车.md)、[动力矿车](动力矿车.md)、[TNT矿车](TNT矿车.md)和[漏斗矿车](漏斗矿车.md)**
* 现在它们的合成配方是无序的。
* 现在它们被破坏时会掉落其自身。
