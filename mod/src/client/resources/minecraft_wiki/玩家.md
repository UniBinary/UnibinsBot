* *玩家（Player）**是Minecraft中可控制的[生物](生物.md)。

# 档案

[档案](档案.md)用于自定义玩家的名称、外观（[皮肤](皮肤.md)、[披风](披风.md)）等内容，也用于在服务器中区分不同的游戏用户。以一个游戏档案加入服务器后，就得到一个对应的玩家实体。

# 生成

玩家会在世界出生点进入世界并开始游戏。

玩家可以通过[床](床.md)、[重生锚](重生锚.md)或使用命令来更改个人出生点。当玩家死亡后，将会在个人出生点复活。如果玩家死亡时个人出生点不可用（被阻挡、被破坏或重生锚能量耗尽等），将会重生在世界出生点。

如果[游戏规则](游戏规则.md)为<code>true</code>，玩家在死亡后会立即复活。在非[极限模式](极限模式.md)的情况下，玩家复活后与复活前的游戏模式始终保持一致。

# 掉落物
玩家仅在游戏规则为<code>false</code>且不处于[旁观模式](旁观模式.md)时才会有掉落物。否则，玩家在死亡时将保留他们的物品栏和经验值，并携带着物品和经验值复活。

如果为<code>false</code>，玩家在死亡时将会失去所有物品，掉落物品栏中所有不具有[消失诅咒](消失诅咒.md)的物品，且不受[抢夺](抢夺.md)魔咒影响。这些掉落物可以被任何玩家、生物捡起或被漏斗吸取，亦或是被环境摧毁。无论玩家因何种原因身亡，玩家始终会掉落等同于自身7×经验等级的经验值，至多能掉落。

# 行为
作为游戏的核心部分，包括[合成](合成.md)在内的多种游戏机制都围绕着玩家进行，绝大多数物品、功能性方块和[生物](生物.md)互动仅能由玩家使用，大部分[状态效果](状态效果.md)也只对玩家有实际作用。玩家也是敌对生物主动攻击的第一目标。

玩家接受设备输入进行直接[控制](控制.md)，从而进行自主移动和交互。

# = 玩家名称标签 =
玩家名称会显示在玩家头上的一个标签上。这个标签有三个可见度级别：明亮、暗淡、不可见。[潜行](潜行.md)或标签被方块阻挡可以使其降低一个可见度级别，被挡住的同时潜行将使其不可见。标签可以只被方块挡住一部分，这使其不同的部分可以有不同的可见度。标签对不同玩家的可见度也可能是不同的。

在视野外的玩家的标签不可见。

如果在视频设置选项卡中将“”设置为“关闭”，那么在多人游戏中就无法看到其他玩家的标签。

如果玩家处于一个不显示名称标签的[队伍](队伍.md)中，其他相应的玩家将始终无法看见其玩家名称；如果玩家所处的队伍被指定了颜色，那么玩家名称也会使用这个颜色。

# = 平视显示器 =

显示在屏幕上的[平视显示器](平视显示器.md)（HUD）是玩家用于监测自身健康和游戏状态的主要方式，其中包括玩家的[生命值](生命值.md)、[饥饿](饥饿.md)、[经验](经验.md)与[快捷栏](物品栏.md)，并显示十字准星和手持的物品（或玩家的手臂）。[盔甲](盔甲.md)条会在玩家穿戴盔甲时显示在生命值上方。玩家在潜水时会显示氧气条。界面的右边栏也会在需要时显示记分板。

# = 物品栏 =

玩家拥有36个物品栏槽位、1个[副手](副手.md)槽以及4个盔甲槽。

每个玩家同时还拥有27个[末影箱](末影箱.md)槽位，存储在其中的物品不会因玩家的死亡而失去，且不能被其他玩家访问。

# = 挖掘 =

玩家可以进行挖掘来破坏方块，默认按键设置下可通过对准方块按住鼠标左键进行，即使不使用任何工具也能采集相当多种类的方块，在没有[镐](镐.md)的情况下也能徒手破坏任何可破坏的方块来清除障碍。

# = 近战攻击 =

默认情况下，玩家的基础近战攻击力为，玩家的近战攻击距离为3。通过在主手上持有工具或武器，玩家能够造成更高的近战伤害。玩家能够进行近战攻击[暴击](伤害#暴击.md)，造成更大的伤害。

玩家能够快速造成伤害，攻击间隔时间短于生物的[受击后伤害免疫](受击后伤害免疫.md)时间，足以使大多数生物被持续击退而无法靠近。玩家和其他大部分生物相比具有压倒性的近战攻击距离优势，使玩家能够在其他生物不能近战攻击的距离对其进行近战攻击，甚至是利用地形来完全阻止自身被近战攻击的同时还能进行近战攻击。

玩家的近战攻击会受到攻击冷却的影响。

玩家使用[剑](剑.md)攻击时可以进行横扫攻击，在对目标生物造成主手所持武器的对应伤害的同时，对周围其他生物造成伤害，但伤害较低。

# = 饥饿 =

饥饿值是玩家日常活动中消耗的主要资源，可以通过食用[食物](食物.md)来恢复。

食用食物来恢复饥饿值是玩家恢复生命值的主要手段。

疾跑、跳跃、攻击、挖掘、生命恢复等动作会逐渐消耗玩家的饥饿值。当难度不为和平且饥饿值不足时，生命值将不会自动恢复。当玩家的饥饿值小于等于时，玩家将无法疾跑。当饥饿值下降到时，玩家将会持续承受来自饥饿的伤害，在简单难度下将玩家的生命值降低至，在普通难度下降低至，在困难难度下降低至。饥饿伤害无视玩家的一切防护效果（[盔甲](盔甲.md)、[保护](保护.md)、[抗性提升](抗性提升.md)）。

# = 经验 =

玩家可以通过经验球来获得经验。经验球可以在下列情况下生成：
* 杀死大部分生物
* 挖掘部分方块
* [繁殖](繁殖.md)动物
* [交易](交易.md)
* [烧炼](烧炼.md)
* [附魔之瓶](附魔之瓶.md)破碎
* [钓鱼](钓鱼.md)钓起物品时
* [砂轮](砂轮.md)洗去魔咒

经验可以用来[附魔台](附魔台.md)或[铁砧](铁砧.md)上消耗来改造物品，为武器、工具、盔甲添加[魔咒](魔咒.md)、重命名、修复[剩余耐久度](物品耐久.md)。

获得足够的经验值后，经验等级会升级。经验是一种消耗性资源，积攒经验不能直接使玩家变强。

# = 游戏模式 =

* 在[生存模式](生存模式.md)中，玩家可以放置与挖掘方块，使用所有可用的工具。敌对生物会主动攻击玩家。玩家受到[生命](生命.md)、[饥饿](饥饿.md)等多种因素的限制，并且挖掘方块会耗费一定的时间。
* 在[创造模式](创造模式.md)中，玩家可以通过双击键飞行，不受任何生存因素的制约，可以任意获取绝大多数物品和方块，并无限地使用这些资源。绝大多数的生物不会攻击玩家。玩家不会受到伤害）|JE}}，可以瞬间挖掘方块，并获得大幅增强的互动范围。
* 在[冒险模式](冒险模式.md)中，玩家的大多数游戏内容与生存模式一致。不同的是，玩家不能挖掘或放置任何方块，除非手上持有的工具拥有对应方块的<code>can_place_on</code>或者<code>can_break</code>组件。处于这个模式下的玩家在生成时将直接被精准地放置到世界出生点上而不是其周围的随机位置。这个模式只有在开启[作弊](作弊.md)后输入[命令](命令.md)、打开游戏模式切换器}}或才能开启。
* 在[旁观模式](旁观模式.md)中，玩家会始终处于飞行状态，可以穿过方块、打开物品栏、，但不能挖掘方块或修改物品栏，无法与世界做出任何互动。旁观模式也是[调试模式](调试模式.md)世界类型下的默认游戏模式。

# = 难度影响 =
[难度](难度.md)为和平且游戏规则为<code>true</code>时，玩家每增加生命值。

难度为和平且为<code>true</code>时，玩家每增加饥饿值，且每增加1点[饱和度](饱和度.md)。

难度为和平时，玩家每增加饥饿值。

# = 移动 =

玩家的步行移动速度为每秒4.317米（格）。这意味着Minecraft中的一天能够走动5181格（5.2千米）。

# == 疾跑 ==

玩家能够疾跑。在疾跑时，玩家的饥饿值将会消耗得比平常要快。玩家的疾跑速度大约是5.612格/秒，比常规速度4.317格/秒要快。玩家在疾跑时可以水平跳过4格远的距离。玩家不能在自身饥饿值小于或等于疾跑。可以通过双击键后按住不放，或按下键进行疾跑。

# == 潜行 ==

可以防止玩家从高于1格的位置跌落，这使得它在架空层上水平向外建造时非常地有用。玩家在方块的边缘上停止潜行时不会从那个方块上掉下来，除非玩家继续移动。此外，当玩家在潜行时仍然可以从方块上跳下。

# == 跳跃 ==

是玩家跨越地形的基本方式。在没有[跳跃提升](跳跃提升.md)状态效果的情况下，玩家最高大约可以跳到1.25219格。

# == 游泳 ==

当玩家处于水中尝试移动将会进行游泳。

# == 速泳 ==

当玩家处于水中尝试将会进行速泳。

# == 爬行 ==

玩家被迫处于1格高缺口或游泳游入无水方块的1格高的隧道时，玩家会开始爬行。爬行时为0.6格高，宽度为0.6格。

# == 滑翔 ==

装备了鞘翅的玩家可以在空中时按下进入滑翔状态。

# == 飞行 ==

在[创造模式](创造模式.md)和[旁观模式](旁观模式.md)下的玩家可以进行飞行。在[创造模式](创造模式.md)中，玩家在任何海拔高度均可以双击切换飞行状态。在[飞行](飞行.md)状态下疾跑会大幅增加移动速度。在旁观模式下，玩家无法关闭飞行状态。

# = 受伤害行为 =

玩家受到的来自非玩家生物或[爆炸](爆炸.md)的伤害值会受到[难度](难度.md)影响。

玩家免疫难度修正后、[受击后伤害免疫](受击后伤害免疫.md)修正前伤害值为的伤害，如[雪球](雪球.md)造成的伤害，以及和平[难度](难度.md)中受难度影响而导致伤害值变为0的伤害。

[游戏规则](游戏规则.md)为<code>false</code>时，玩家免疫溺水伤害。

游戏规则为<code>false</code>时，玩家免疫摔落伤害。

游戏规则为<code>false</code>时，玩家免疫火焰伤害。

游戏规则为<code>false</code>时，玩家免疫冰冻伤害。

# = 着火 =

玩家的剩余着火时间（实体属性<code>Fire</code>）在不着火时会被设置为-20，而不是其他生物的-1。这使玩家能够在与[火](火.md)接触不到1秒时脱离的情况下不会着火。

# = 命中反馈 =

由玩家使用[弓](弓.md)或[弩](弩.md)发射的箭在命中其他玩家时，发射者会听到一个高音调的“叮”的声音。

# = 箭与螫针 =

玩家被没有穿透魔咒标签的[箭](箭.md)击中，或被[蜜蜂](蜜蜂.md)成功攻击后，会增加玩家的“箭数量”和“螫针数量”。

玩家具有“箭数量”或“螫针数量”时，会在模型上渲染指定数量的物体插在玩家身上，位置取决于以玩家实体编号为种子的随机生成结果，与受到攻击的角度无关。

“箭数量”和“螫针数量”各自有一个计时器，在其值高于0时，每隔<code>-{}-(30-当前数量)×20</code>[游戏刻](游戏刻.md)（<code>-{}-30-当前数量</code>秒）会减少1。

* 玩家的脚与躯干并不完美地处于同一直线上，这个特性是用来防止在穿戴盔甲时的[深度冲突](wikipedia:z-fighting.md)。
* 在[Java版1.14](Java版1.14.md)之前，视角被定位在玩家的腿部，因此世界在玩家的视野中应该低于1.8格。<ref></ref>
* * 同样，在玩家睡觉时，世界会根据玩家而旋转，而不是玩家的视野在旋转，从而引发一些视觉上的漏洞。<ref></ref>
* 当玩家的游戏ID为“Grumm”或“Dinnerbone”时，玩家的皮肤模型将会上下颠倒。
* 默认用户名为“Steve”，而大多数时候默认的皮肤却为其他角色。

# = Steve和Alex =
[缩略图|僵尸与Steve十分相似](File:Zombie getting punched.png.md)
* Steve有着与[僵尸](僵尸.md)相似的纹理。
* * 在[Java版1.19.3](Java版1.19.3.md)（[22w45a](22w45a.md)）和[基岩版1.19.50.21](基岩版1.19.50.21.md)前，Steve和僵尸穿着完全一致的服装，并拥有相同的皮肤图案。
* Mojang说Alex“从一些角度看起来有些像[Jeb](Jeb.md)”。<ref>https://mojang.com/2015/04/new-skins-achievements-music/</ref>
* Steve脸部的络腮胡于[生存测试](生存测试.md)中被移除，在2022年8月19日发布的[启动器2.3.376](启动器2.3.376.md)，以及[Java版1.19.3](Java版1.19.3.md)、[基岩版1.19.50](基岩版1.19.50.md)中，Steve的胡子才被重新加入。
* 在LEGO Club杂志的2016年7-8月刊中，提到Steve是Alex的男朋友，以及Steve是一个矿工、建筑师和炼金术士，而Alex则是一个建筑师、探险家和猎人。

# = 外部关联 =
* Steve在LEGO系列[21102 LEGO Minecraft Micro World](乐高Minecraft.md)中与一只[苦力怕](苦力怕.md)被设定为微型生物。

* 在Xbox Arcade游戏中，Steve的头是一个可解锁的头盔。

* 在游戏《恐龙快跑：特别版》（*DinoRun SE*）中，Steve的头是一个可穿戴帽子。
* 在游戏*Transformice*中，Steve的头是一个可穿戴帽子。
* 在游戏《荒野老城》中，Steve是一个可游玩角色。
* 在游戏《黑道圣徒4》中，Steve是一件被命名为“Craft Miner”的制服。
* 在游戏*Alone in the park*里，Steve是一个可解锁角色，并且拥有一个类似于石镐的射弹。
* 在游戏《小猫突击队 2》里，Steve是一套名为“Pitman”的装备，挥舞着一个铁镐并且可以打破障碍。
* 在游戏《创造世界》（*Createrria: craft your games*）里，角色“Mr.Pixel”有着和Steve相似的面部。
* 在游戏*BowMasters*中，Steve是一个可游玩角色。
* 在游戏《火柴人至高对决》（*Supreme Duelist Stickman*）中，Steve的头是一个可穿戴帽子，此外还有可放置圆石，TNT以及活塞等方块的镐。
* 在游戏《[任天堂明星大乱斗特别版](任天堂明星大乱斗特别版.md)》中，Steve作为DLC参战斗士登场，而Alex则以“附加颜色”的方式登场。
