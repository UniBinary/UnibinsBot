# Java版Indev 0.31 20091223-0040

*页面ID: 35289* | *来源: Minecraft Wiki*

/开发者版本}}

* *0.31**的第一个版本发布于2009年12月23日00:40（UTC）<ref>[minecraft.20091222的IRC记录](#logs.md): "P6:40:14 <�08Notch�> http://www.minecraft.net/indev/"</ref>，加入了[拉娜](拉娜.md)和[光照](光照.md)，并移除了部分特性。<ref name=":0"></ref>

# 新内容
# = 生物 =
* *[拉娜](拉娜.md)**
* 一种友好生物。
* 会自然生成在世界中。
* 影子与[玩家](玩家.md)相同。

# = 常规 =
* *[亮度](亮度.md)**
* 加入了动态照明。
* 现在有9个光照等级。
* * 正因如此，洞穴变得更暗了。
* 奇怪的是，[物品栏](物品栏.md)和快捷栏中的方块也会受到光照影响——刚进入世界时它们看起来有些暗，一段时间后它们会恢复正常亮度。
* 加入了玩家和生物的影子。
* 更改了方块两侧的阴影。

# 更改
# = 方块 =
* *[TNT](TNT.md)**
* 被移除。

# = 物品 =
* *[箭](箭.md)**
* 被移除。

# = 生物 =
* *常规**
* 移除了除拉娜以外所有生物。

# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 多人游戏现在不可用（尽管其代码仍然存在，并且可以重新启用）。
* * 尝试连接到多人[服务器](服务器.md)将导致玩家在[基岩](基岩.md)中出生。
* 聊天功能不可用，且无法打开玩家列表。

* *[快捷栏](快捷栏.md)**
* 将[TNT](TNT.md)从快捷栏中移除。

* *[创造模式物品栏](创造模式物品栏.md)**
* [32px](File:Dandelion (item) JE1.png.md)创造模式物品栏中花的两个sprite交叉。<!-- 这一句话如何翻译才合适？ --><ref>[minecraft.20091222的IRC记录](#logs.md): "P6:48:18 <Iguana> Plants and such look very squished in the inventory. :P"</ref>

* *[平视显示器](平视显示器.md)**
* 玩家的手不再显示。

* *[游戏模式](游戏模式.md)**
* 玩家默认是[创造模式](创造模式.md)。
* * 然而[生存模式](生存模式.md)可以通过修改添加回来。

* *[雨](雨.md)**
* 雨现在会穿过玻璃。

* *常规**
* 挖掘方块时不再会掉落物品。
* 玩家会携带99个[石头](石头.md)、99个[石台阶](石台阶.md)、99个水和99个熔岩生成。

# = 世界生成 =
* *[世界大小](Indev世界选项#世界大小.md)**
* 现在世界会默认生成小型世界。<ref>[minecraft.20091222的IRC记录](#logs.md): "P6:57:25 <�08Notch�> oh yeah, I made it default to small while I was developing for quicker map regeneration times. =)" (00:57 UTC)</ref>

# = 常规 =
* *[控制](控制.md)**
* 按不再能发射箭。

* *常规**
* 加入了新的开发中的世界文件格式。
* * 保存和加载世界暂时不可用。</onlyinclude>

# 你知道吗
* 这是Minecraft的首个收费版本（价格为€5.00），因为Notch仅向付费用户发布了此版本以测试新的特性。<ref name=":0"/>
