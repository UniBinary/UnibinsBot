# Java版14w26a

*页面ID: 33688* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w26a**是[Java版1.8](Java版1.8.md)的第29个快照，发布于2014年6月25日<ref name="blogpost_14w26a"></ref>。

# 新内容
# = 世界生成 =
* *[调试模式](调试模式.md)**
* 对于[资源包](资源包.md)作者来说很有用。
* 按住并多次点选“世界类型”直到找到它。
* 建议进入旁观模式以避免游戏崩溃（也可以使用创造模式，但是在某些设备上这种方法会失效）
* 所有可能的方块及它们身上所有可能出现的数据值都会生成。
* * 它们生成于y70处且在y60处有一个[屏障](屏障.md)层。
* 放置的方块会消失，破坏的方块会复原。
* * 有一个特殊的生成设定维持着这个特性。如果在第三方NBT编辑器（如NBTexplorer）中把它改为“超平坦”或“普通”，就可以与世界交互了。尽管如此，建议不要在该类型的世界逗留（玩太长时间），因为大部分机器运行这种世界时，会变得反应缓慢，甚至会导致游戏崩溃（不推荐用这个来玩生存模式）。

# = 命令格式 =
* *block> ...}}**
* 可以重置任何物品栏内的物品，包括生物（例如僵尸）的物品栏。
* 完整的命令语法：
* * <code>-{}-/replaceitem entity <实体名> <物品栏内的位置编号> <物品> [数量] [数据值]</code>
* * <code>-{}-/replaceitem block <x> <y> <z> <slot> <物品> [数量] [数据值]</code>
* 例子：<code>/replaceitem entity @e[type=Zombie] slot.weapon minecraft:iron_sword 1 0 </code> 会给予所有僵尸一把铁剑。
* 例子：<code>/replaceitem entity @p slot.hotbar.0 minecraft:fish 4 2 </code> 会在所有玩家的第一个快捷物品栏方格内放置4个小丑鱼。
* 例子：<code> /replaceitem block ~ ~-1 ~ slot.container.5 minecraft:redstone_block 1 0 </code> 会在玩家下方的箱子第六格内放置一个红石块。

* ***
* 加入了<code>sendCommandFeedback</code>。
* * 当设置为时，玩家运行的命令不会展示运行成功后的信息。

# 更改
# = 方块 =
* *常规**
* 在代码中，方块将仅仅，或在大部分情况下使用方块状态，尽管并非所有方块都有方块状态。

* *[命令方块](命令方块.md)**
* “最后一次输出”按钮旁的X/O按钮可以关闭最后一次输出的信息。

* *[熔炉](熔炉.md)**
* 现在熔炉的燃料槽中只允许放入燃料或空铁桶。

# = 非生物实体 =
* *[物品展示框](物品展示框.md)**
* 框架纹理从桦木木板纹理改为橡木木板纹理。

# = 世界生成 =
* *[自定义](自定义.md)世界类型**
* 加入了[海底神殿](海底神殿.md)选项。

* *[沼泽](沼泽.md)**
* 更改了沼泽地形边缘的生成。<ref>http://i.imgur.com/lQELvLX.jpg</ref>

# = 命令格式 =
* ***
* 增加<code>detect</code>子命令（仅能在命令后使用）。
* * 仅当某个特定位置的方块与目标方块相符时，才执行<code>execute</code>命令。
* * 用法：<code>-{}-/execute <玩家/实体名> <x> <y> <z> detect <方块x坐标> <方块y坐标> <方块z坐标> <方块名> <附加值> <符合条件时所执行的命令></code>

* ***
* 加入了<code>add</code>子命令。
* * 该命令与<code>set</code>子命令类似，但是它能以一定的方块数量扩大（或缩小）世界边缘。
* * 参数为负数时，缩小世界边缘。
* * 例如：<code>/worldborder add -75 </code> 将会使世界边缘宽度减少75个方块的长度。

* ***
* 方块限制数量从4096个增加至32768个。

# = 常规 =
* *[资源包](资源包.md)**
* 重做了3D纹理，加入了允许新方块拥有多种纹理的能力。

* *[方块模型](方块模型.md)**
* 现在可以选择显示方块模型的纹理，而不需要指定uvs。
