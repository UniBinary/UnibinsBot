* *画（Painting）**是可以挂在墙上的装饰性[实体](实体.md)。

# 生成
画不会生成在世界中。

# 获取
通过[创造模式物品栏](创造模式物品栏.md)可以获取指定画作的对应物品，指定画作的提示框中会显示画作名称、作者和尺寸（详见）。

# = 合成 =
画可以使用任何颜色的[羊毛](羊毛.md)合成，羊毛的颜色不影响画放置后显示的内容。

# = 交易 =

# 用途
画可以将其放置在[固体方块](固体方块.md)的侧面。与这幅画相邻的其他方块空间可以是任何方块。

画具有不同的尺寸。放置时，画会检查最大的可摆放空间，然后会根据空间随机选择画的内容。因此，若玩家想要放置特定尺寸的画，可以预先在摆放画的墙面放置方块来限制可摆放空间。

# 行为
作为实体，画可以与例如水和[火把](火把.md)一类的方块位于同一位置。具体来说，它们能与任何碰撞箱不与其冲突的方块共享同一个位置。

玩家和生物可以无阻碍地穿过画，只要支撑画的方块允许。光照能穿过画传播。

画不能[着火](着火.md)。

如果画受到伤害（即使受到的伤害值为，如伤害来自或[雪球](雪球.md)等弹射物）或支持画的方块被移除，画就会被破坏并掉落为物品。被[船](船.md)撞击的画也会被破坏并掉落为物品。画作为实体不可以被下界传送门传送，但可以被[末地折跃门](末地折跃门.md)和有效的[末地传送门](末地传送门.md)传送。

# 画作列表
游戏中一共有47种画。其原始作品大多数都由[Kristoffer Zetterstrand](Kristoffer Zetterstrand.md)创作，而且这些适用于Minecraft的低分辨率版本也出自他之手。

# = 特殊的画 =
这4幅画可从[创造模式物品栏](创造模式物品栏.md)的中获取，其[提示框](提示框.md)中均没有署名信息。

它们存在于<samp>kz.png</samp>中而未被使用，见了解更多信息。

据[Helen Zbihlyj](Helen Zbihlyj.md)透露<ref>https://old.reddit.com/r/Minecraft/comments/u8hpnx/thoughts_on_the_new_paintings/i5olue6/?context=3</ref>，这些画作原本打算用在[MINECON 2012](MINECON 2012.md)或[2013](MINECON 2013.md)的[携带版](携带版.md)宣传世界中。

# 你知道吗
* 画其实不是完全贴在墙上的，画与墙之间有一道缝隙。
* 画背面的纹理修改自[木板](木板.md)的纹理，但其色调与游戏中存在的任何一种木板都不相同。
* * [Java版1.17](Java版1.17.md)和[基岩版1.17.0](基岩版1.17.0.md)之前的背面纹理则是修改自[Java版1.0.0](Java版1.0.0.md)前木板的纹理，其与正式版至[纹理更新](纹理更新.md)前的木板纹理不相对应。
* 在多人游戏中，当玩家站在画的后面时，其他玩家不会看到该玩家的名字。
* 由于画属于[实体](实体.md)，[旁观模式](旁观模式.md)的玩家可以对画按下键进入画的视角。
* “燃烧的头骨”（Skull On Fire）画作的背景是一个能够真正生成的Minecraft世界，其基于作者2010年10月12日13:22:49（UTC+2）于[Java版Alpha v1.1.2_01](Java版Alpha v1.1.2_01.md)（或更早版本）中截取的截图。<ref></ref>
* * 该世界的[种子](种子（世界生成）.md)为或（二者生成的世界相同），坐标为X=-249.65，Y=91，Z=-29.04。<ref>https://pastebin.com/fzAY9ES4</ref><ref></ref>
* Kristoffer Zetterstrand亲笔签名、零售估价为3700美元的“燃烧的头骨”原作被赠予了Webhallen Minecraft纹理包大奖赛的冠军Wojciech Mroczek。<ref>https://web.archive.org/web/20110110003612/http://www.webhallen.com:80/minecraft/</ref><ref>https://www.planetminecraft.com/texture-pack/pixeludi-pack-texture-pack-compo-winner/</ref>
* 愚人节快照[24w14potato](24w14potato.md)加入了7幅[与马铃薯有关的画](24w14potato#非生物实体.md)：**美味的形状（Tasty Shapes）**、**自画像（Self-portrait）**、**马铃薯（Potato）**、**聚光灯下（In The Spotlight）**、**烫手洋芋（Hot Potato）**、**这不是马铃薯（This is not a potato）**、**马铃薯的叛逆（The Treachery Potatoes）**。
