# 粗铁块

*页面ID: 81405* | *来源: Minecraft Wiki*

* *粗铁块（Block of Raw Iron）**是用于储存[粗铁](粗铁.md)的方块。

# 生成
# = 自然生成 =
粗铁块有较小的概率自然生成在高度小于0的[铁矿脉](铁矿脉.md)中。

# 获取
# = 合成 =

# 破坏
挖掘粗铁块的合适工具是镐。粗铁块需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

粗铁块被破坏后会掉落自身。

# 用途
粗铁块主要用于储存粗铁。
