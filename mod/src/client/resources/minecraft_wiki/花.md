# 生成

# = 自然生成 =
大多数花会天然在一些[生物群系](生物群系.md)的[泥土](泥土.md)和[草方块](草方块.md)上生成（详见[下文](#花与生物群系.md)）。即使是在积雪生物群系，花仍会天然生成在覆盖着[雪](雪.md)的泥土和草方块上。

此外，一些花还可以在部分[结构](结构.md)中生成：
* 绒球葱、蒲公英、蓝花美耳草、郁金香、虞美人和兰花能在[林地府邸](林地府邸.md)中找到。
* 虞美人、蒲公英以及滨菊能在平原[村庄](村庄.md)中找到。
* 虞美人可以在[热带草原](热带草原.md)村庄中找到。
* 虞美人可以在[针叶林](针叶林.md)村庄和中找到。

蒲公英、虞美人、兰花、绒球葱、蓝花美耳草、滨菊、红色郁金香以及白色郁金香[盆栽](盆栽.md)会在[林地府邸](林地府邸.md)中生成。

蒲公英和虞美人盆栽也会在[村庄](村庄.md)中生成。

# = 骨粉 =
对[草方块](草方块.md)使用[骨粉](骨粉.md)后，花有的概率代替[矮草丛](矮草丛.md)生成。能生成的花取决于生成位置所在的[生物群系](生物群系.md)。

对着不[含雪](含雪.md)的小型花使用骨粉会在其周围的可种植方块上生成更多同种的花，而不会出现草丛；无法对凋灵玫瑰和火把花使用骨粉。

# == 花与生物群系 ==
以下表格列出了在哪些生物群系中花能够生成，以及在哪些生物群系中它们能通过使用骨粉生成。

标记“是”的表示该花既**能**在世界生成时作为生物群系的一部分自然生成，也**能**通过使用骨粉生成；标记“否”的表示该花既**不能**在世界生成时作为生物群系的一部分自然生成，也**不能**通过使用骨粉生成；标记“自然”的表示该花**仅能**在世界生成时作为生物群系的一部分自然生成，而**不能**通过使用骨粉生成。

# = 骨粉 =
对着大型花（瓶子草除外<ref></ref>）使用[骨粉](骨粉.md)时，它会掉落1株新的对应花种。

# 用途
所有花均可种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。凋灵玫瑰还可以种植在[下界岩](下界岩.md)、[灵魂沙](灵魂沙.md)和上。

所有小型花均可种植在[花盆](花盆.md)中。

若水流过其位置、活塞头推入其位置或活塞将方块推入其位置，则花会被破坏。

# = 蜜蜂 =

[蜜蜂](蜜蜂.md)会被花方块吸引。在花的周围环绕一圈后，蜜蜂会采集花粉，使其纹理的后部充满了点状的花粉。带有花粉的蜜蜂也会从身上滴下花粉的[粒子](粒子.md)效果。采集完花粉后蜜蜂会为作物授粉，然后归巢酿蜜。

蜜蜂对张开的眼眸花采粉时会获得1.25秒的[中毒](中毒.md)效果，对凋灵玫瑰采粉时会获得2秒的[凋零](凋零.md)效果。且蜜蜂不会尝试接触闭合的眼眸花和。

蜜蜂只会对[向日葵](向日葵.md)的上半部（花盘）采粉。

大多数花都可用于吸引蜜蜂、繁殖蜜蜂及加速幼年蜜蜂的生长，除了以下例外：
* 蜜蜂不会被闭合的眼眸花吸引，玩家也无法对其；
* 蜜蜂不会被吸引，玩家也无法对成年蜜蜂；
* 对蜜蜂张开的眼眸花会使其获得[中毒](中毒.md)效果，而非繁殖或加速生长；
* 对蜜蜂凋灵玫瑰会使其获得[凋零](凋零.md)效果，而非繁殖或加速生长。

# = 堆肥 =
将火把花或瓶子草放入[堆肥桶](堆肥桶.md)都有85%的概率使堆肥层数增加1。其余的花放入则为65%的概率。无法放入堆肥桶。

# = 生成蜂巢 =
若橡树、白桦或樱花[树苗](树苗.md)水平2格范围内存在花，则该树苗长成的树会有5%的概率悬挂着[蜂巢](蜂巢（方块）.md)。每个由此生成的蜂巢都会容纳1-3只蜜蜂。

# = 染料 =
所有的花均能直接合成出[染料](染料.md)，染料的颜色一般与花本身的颜色相近。小型花可以合成出1个染料，大型花可以合成出2个染料。

|foot=1
}}

# = 谜之炖菜 =
所有小型花均可用于合成[谜之炖菜](谜之炖菜.md)。若为一头棕色[哞菇](哞菇.md)喂食小型花，则下次对其[碗](碗.md)时可获得一碗谜之炖菜。再次对其使用碗则会正常获得[蘑菇煲](蘑菇煲.md)，除非继续对其喂食花。

食用谜之炖菜所给予的效果取决于合成时使用的花的种类。
