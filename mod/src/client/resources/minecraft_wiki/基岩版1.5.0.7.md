# 基岩版1.5.0.7

*页面ID: 34801* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.5.0.7**是[1.5.0](基岩版1.5.0.md)的第4个测试版，发布于2018年5月24日<ref></ref><ref></ref>，加入了调整气泡柱外观的选项，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[设置](设置.md)**
* 现在可以在视频设置中调整气泡柱的外观。

# 更改
# = 物品 =
* *[三叉戟](三叉戟.md)**
* 现在[三叉戟](三叉戟.md)无法在创造模式下破坏方块（与[剑](剑.md)一样）。

# 修复
* *修复了28个漏洞**
* 修复了部分在游戏中出现的漏洞。
* 生成世界时，暂停游戏使得游戏崩溃。
* 玩家跳入水中时不会显示水花粒子。
* 热带鱼在跳入水中时不会显示水花粒子。
* 弓在蓄力时，不会显示在右手。
* 在一些资源包里，凋灵护甲的纹理显示错误。
* 橡木活板门的纹理旋转不正确。
* 在城市纹理包里，仙人掌的纹理出现错误。
* 放置在水面上的方块会丢失其底部的水的纹理。
* 将全体积的透明方块放置在农作物上时可以使其快速生长。
* 在创造模式里侧向飞行不能快速放置方块。
* 生物可以在红石组件的上方生成。
* 使用冰霜行者魔咒时，霜冰的纹理显示延迟。
* 已附魔的三叉戟在火中时不再闪烁红色。
* 无法使用三叉戟来破坏盔甲架。
* 鲑鱼会被困在有限世界的边界上。
* 当玩家肩膀上站着鹦鹉时，发射弹射物会伤害玩家。
* 海豚可以穿过岩浆块。
* 鱼的碰撞箱太小。
* 大于4级的效果不会在状态效果界面里显示。
* 梯子无法自然变成含水状态。
* 效果会使得玩家视野变窄。
* 放置在物品展示框里的海龟蛋会闪烁。
* 僵尸村民不会踩踏海龟蛋。
* 放置海龟蛋时没有粒子效果。
* 三叉戟在击中生物时会坠落在地。
* 溺尸在游泳时，手臂旋转动画出现错误。
* 创造模式下，无法对溺尸使用“选取方块”功能来获得其刷怪蛋。</onlyinclude>
