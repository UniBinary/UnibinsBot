# Java版1.0.0

*页面ID: 15026* | *来源: Minecraft Wiki*

* *1.0.0**（[启动器](启动器.md)中称**1.0**）是**[冒险更新](冒险更新.md)**第二部分的首个正式版，也是的一次主要更新，发布于2011年11月18日<ref></ref>。加入了[酿造](酿造.md)、[附魔](附魔.md)、[末地](末地.md)、[极限模式](极限模式.md)、[繁殖](繁殖.md)以及更多新内容。

该版本恰好在[MINECON 2011](MINECON 2011.md)期间发布，标志着在历时两年半的开发后终于迎来了其正式版本。

# 新内容
# = 方块 =
* *[菌丝体](菌丝体.md)**

* *[龙蛋](龙蛋.md)**
* 在末影龙被击杀后生成。

# 更改
# = 方块 =
* *纹理**
* 更新了部分方块的纹理：

* *[书架](书架.md)**
* 现在被摧毁时会掉落3本[书](书.md)。

* *[刷怪笼](刷怪笼.md)**
* 英文名称由原来的“Monster Spawner”变为“Spawner”。

* *[栅栏](栅栏.md)**
* 现在会自动连接到毗邻的固体方块上。
* 不再阻止玩家移动到它们旁边。
* * 玩家现在可以站在[栅栏](栅栏.md)旁边（类似于[玻璃板](玻璃板.md)和[铁栏杆](铁栏杆.md)）。

* *[荧石](荧石.md)**
* [材料](材料.md)类型现在由“石头”再次变回“玻璃”。
* 现在需要用[镐](镐.md)挖掘才会掉落物品。
* [火把](火把.md)、[拉杆](拉杆.md)等方块现在可以置于其上了。
* 不再被视作红石信号纵向（向下）[“二极管”](传输电路#二极管.md)。
* * 在此之前，红石信号只能由下至上单向传递。

* *[玻璃板](玻璃板.md)**
* 现在使用无[精准采集](精准采集.md)魔咒的工具破坏时不再掉落任何物品。

* *[火](火.md)**
* 现在会在[末地](末地.md)的[基岩](基岩.md)上永久燃烧。

* *[矿石](矿石.md)**
* 现在无需冶炼即可获得矿物的矿石方块（[煤矿石](煤矿石.md)、[青金石矿石](青金石矿石.md)和[红石矿石](红石矿石.md)）可以被烧炼为其对应的矿物了。

* *[红石](红石.md)**
* 现在单独放置时的形状为点状而非原来的十字状。

* *[水](水.md)**
* 现在如果其下方只有一层方块，就会有水滴[粒子](粒子.md)从该方块底部滴落下来。这可以在离该方块13格远处看到。

* *[熔岩](熔岩.md)**
* 现在会在其下单层方块的底部产生熔岩滴[粒子](粒子.md)，效果与上述水滴粒子类似。
* * 该粒子仅为视觉效果，不会造成任何伤害。
* 当流动的熔岩从上方直接接触水源时，会产生一块[石头](石头.md)。
* * 之前，熔岩会直接流过水。

* *[床](床.md)**
* 现在在周围有怪物存在的情况下尝试使用床会显示信息“你现在不能休息，周围有怪物在游荡”（You may not rest now, there are monsters nearby）。

* *[高草](高草.md)**
* 每种高草现在有不同的名称：
* * 枯萎的灌木变种现在被称为“灌木”（Shrub）。
* * 蕨类变种现在被称为“蕨”（Fern）。
* * 普通的草变种仍保持其原有的名称“高草”（Tall Grass）。

* *[黑曜石](黑曜石.md)**
* [硬度](硬度.md)值由10增加至20。
* * 这是为了平衡镐挖掘石质方块时速度的加强。

* *[门](门.md)**
* 木门和铁门现在可以使用对应的[工具](工具.md)（[斧](斧.md)和[镐](镐.md)）更快地进行破坏了。
* 有了新的音效。

* * 现在会自然生成[睡莲](睡莲.md)。

* *[生成结构](生成结构.md)**
* [要塞](要塞.md)
* * 现在会生成装有随机战利品的[箱子](箱子.md)。

# = 游戏内容 =
* *[盔甲](盔甲.md)系统**
* 新的系统，相比之前有很大改进。
* 提升了盔甲的耐久度。

* *[经验](经验.md)**
* 现在可用于[附魔](附魔.md)。
* 一个经验球相当于一点经验。

* *[状态效果](状态效果.md)**
* 现在拥有状态效果的玩家和生物身边会出现旋涡状[粒子](粒子.md)。
* 玩家所拥有的状态效果现在会显示在自己的[物品栏](物品栏.md)旁。

* *[防御](防御.md)**
* 现在玩家在防御时会播放移动手臂的动画，而不像之前一样剑会飘浮在玩家面前。

* *[跳跃](跳跃.md)**
* 现在从按下键到玩家真正跳起的过程中会略微产生延迟。
* * 这样一来，玩家便不再能在两格高的空间内跳跃。

* *[死亡](死亡.md)**
* 现在玩家死亡时掉落的[经验球](经验球.md)数量有限制了。
* 分数时显示的基于收集多少经验球，一个经验球等于一分。

* *[第三人称视角](第三人称视角.md)**
* 按下两次键现在会切换至第三人称正面视角，此时再按一次即可切换回第一人称视角。<ref group="注">这一更改发生在1.0.0的最后一个开发版本[1.0.0-rc2](Java版1.0.0-rc2.md)与其**正式版**之间。</ref>

# 你知道吗
* 该版本最初被命名为“**Beta 1.9**”，但最终[Mojang AB](Mojang AB.md)决定以“Minecraft 1.0.0”的名称发布这次更新并将发布日期提前至MINECON 2011期间。不过由于这一决定是在被标记为“Beta 1.9”的开发版本全部发布后才做出的，因而在该版本的所有预览版中，其都被称为“Beta 1.9”。
* * 2014年的愚人节玩笑便声称村民是在Beta 1.9版本中实现的。
* 这次更新的主要版本版本号命名格式与后续版本的不同。假使之后的版本都按照与“1.0.0”相同的规范命名，那么[1.1](Java版1.1.md)应该是“1.1.0”，依此类推。
* * 不过，之后的[基岩版](基岩版.md)各版本应用了这种命名规范。
