# Java版Alpha v1.0.4

*页面ID: 32485* | *来源: Minecraft Wiki*

<onlyinclude>
* *Alpha v1.0.4**是的一次[秘密更新](秘密更新.md)，发布于2010年7月9日<ref name="blogpost"></ref>，加入了[冬天模式](Java版已移除特性#冬天模式.md)、[降雪](降雪.md)和两种新的[方块](方块.md)。

# 新内容
# = 方块 =
* *[冰](冰.md)**
* 会在冬天模式的世界里生成。
* *[雪](雪.md)**
* 方块暴露在降雪中时会在其顶部生成。
* 目前无法获得。

# = 游戏内容 =
* *动作**
* 加入了[玩家](玩家.md)坐的动作。

# = 世界生成 =
* *冬天模式**
* 一种新的世界类型，包括以下新特性：
* * 持续降雪。
* * 暴露在雪中的方块会覆盖一层的[雪](雪.md)。
* * 暴露在雪中的[水](水.md)会变成[冰](冰.md)。
* 新生成的世界有25%的概率为冬天模式。<ref group="注">冬天模式世界的文件中标签的值为。</ref>

# 更改
# = 非生物实体 =
* *[矿车](矿车.md)**
* 移除了里面的[箱子](箱子.md)纹理。

# = 常规 =
* *[主菜单](主菜单.md)**
* 更改了游戏徽标，并为其加入了动画。

# 修复
* *修复了3个漏洞**
* 修复了一个生物生成代码中的漏洞。
* 玩家不再会在骑乘矿车时在两格高的空间内窒息了。
* 破坏矿车不再导致游戏卡死。</onlyinclude>
