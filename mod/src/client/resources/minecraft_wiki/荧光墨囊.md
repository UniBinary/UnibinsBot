# 荧光墨囊

*页面ID: 75087* | *来源: Minecraft Wiki*

* *荧光墨囊（Glow Ink Sac）**是[发光鱿鱼](发光鱿鱼.md)的掉落物，可用于合成[荧光物品展示框](荧光物品展示框.md)或增亮[告示牌](告示牌.md)的文本。

# 获取
# = 发光鱿鱼 =

== 用途 ==
# = 告示牌 =
[thumb|涂抹了荧光墨囊的告示牌橙色文本效果](File:Glow Ink Sign with Orange Dye.png.md)
对[告示牌](告示牌.md)使用荧光墨囊可以提高文本亮度，还会使文本带有外边框（边框颜色取决于文本的颜色）。对着带有文本发光效果的告示牌使用[墨囊](墨囊.md)可以移除此效果。
