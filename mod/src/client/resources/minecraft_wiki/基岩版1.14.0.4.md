# 基岩版1.14.0.4

*页面ID: 48961* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.14.0.4**是[1.14.0](基岩版1.14.0.md)的第4个测试版，发布于2019年10月30日<ref></ref>，对[蜂蜜瓶](蜂蜜瓶.md)和[蜜脾](蜜脾.md)进行了微调，并修复了一些漏洞。

# 更改
# = 物品 =
* *[蜂蜜瓶](蜂蜜瓶.md)**
* 现在可堆叠至16个。
* 现在可用1个[蜂蜜块](蜂蜜块.md)和4个[玻璃瓶](玻璃瓶.md)合成。
* 更改了纹理，现在和[Java版](Java版.md)的一致。

* *[蜜脾](蜜脾.md)**
* 更改了纹理，现在和Java版的一致。

# 修复
* *修复了10个漏洞**

* *崩溃/性能**
* 修复了几个可能导致游戏运行中发生的崩溃。
* 修复了在使用自定义皮肤时打开角色创建器导致的崩溃。

* *常规**
* 修复了在重启游戏后玩家皮肤被重置为默认皮肤的漏洞。
* 平台特色皮肤现在可以在角色创建器中出现。
* 分屏玩家现在可以在暂停菜单中看到正确的玩家头像。
* 修复了造成Xbox One平台上无法获得“纵横七海”成就的漏洞。
* 修复了屏幕阅读功能关闭后仍然有效的漏洞。（）
* 修复了玩家皮肤需要很长时间来加载的漏洞。（）

* *游戏内容**
* 成就“保镖”现在再次可以被解锁。

* *附加包和脚本引擎**
* 修复了玩家驯服的实体在攻击时被算作玩家攻击的漏洞。</onlyinclude>
