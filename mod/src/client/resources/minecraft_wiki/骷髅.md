* *骷髅（Skeleton）**是一种装备了[弓](弓.md)并发射[箭](箭.md)的常见的[亡灵](生物#亡灵生物.md)敌对生物。

# 生成
骷髅会在[主世界](主世界.md)中[内部天空光照](亮度#内部天空光照.md)小于等于7，且[方块光照](亮度#方块光照.md)为0的[可生成位置](生成#可生成位置.md)上生成，[蘑菇岛](蘑菇岛.md)和[深暗之域](深暗之域.md)除外。骷髅不会在[河流](河流.md)、[冻河](冻河.md)、[雪原](雪原.md)、[冰刺之地](冰刺之地.md)、[冻洋](冻洋.md)、[冰冻深海](冰冻深海.md)、[冰封山峰](冰封山峰.md)、[积雪山坡](积雪山坡.md)、[尖峭山峰](尖峭山峰.md)和[红树林沼泽](红树林沼泽.md)中生成。<ref></ref><ref></ref>

在[雪原](雪原.md)和[冰刺之地](冰刺之地.md)等寒冷生物群系露天生成的骷髅有80%的概率由[流浪者](流浪者.md)替代其生成，在[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)中生成的骷髅有30%的概率由[沼骸](沼骸.md)替代其生成，在[沙漠](沙漠.md)中露天生成的骷髅有50%的概率由[焦骸](焦骸.md)替代其生成。

它们也会在[下界](下界.md)的[灵魂沙峡谷](灵魂沙峡谷.md)频繁生成。当[凋灵骷髅](凋灵骷髅.md)在[下界要塞](下界要塞.md)中生成时，会有20%的概率生成普通骷髅。骷髅在下界生成时需要方块光照小于等于7。

[蜘蛛](蜘蛛.md)生成时会有1%的概率生成一只骑在其身上的骷髅，组成[蜘蛛骑士](蜘蛛骑士.md)。

当玩家触发[骷髅陷阱](骷髅马#骷髅陷阱.md)时会生成[骷髅骑手](骷髅骑手.md)。这些骷髅骑在骷髅马上，装备附魔的弓和铁头盔。这些骷髅在生成后3秒内拥有[受击后伤害免疫](受击后伤害免疫.md)效果。

骷髅不会生成在下界疣块上。

# 行为
骷髅会追逐在它半径16格内的[玩家](玩家.md)、[铁傀儡](铁傀儡.md)和幼年[海龟](海龟.md)，当玩家头戴[骷髅头颅](骷髅头颅.md)时，骷髅的察觉范围会降低至原来的一半（即8格）。它们会走上[楼梯](楼梯.md)、穿过障碍物，以将目标纳入它们的射程范围。当骷髅距离目标16格以内并拥有对目标的直接视野时，它们会停止靠近并开始朝目标射箭，/</ref>}}。

骷髅会主动逃离[狼](狼.md)，同时狼会主动攻击骷髅。骷髅只有与狼保持一定距离时才会尝试反击。而骷髅在被狼攻击后会马上停止逃跑并进行反击。<ref></ref>

骷髅射箭的精确度取决于游戏难度。骷髅拥有一项“射击误差”数值，在简单难度为10，普通难度为6，困难难度为2，而玩家对应值为1。为了修正重力的影响，每当目标与骷髅的水平距离增加1格，骷髅的准星便多抬高0.2格。

[thumb|right|骷髅间的对决。左侧的骷髅变红是因为它受到了来自另一只骷髅的伤害](File:skeletonduel.png.md)

骷髅是最常见的以弹射物作为攻击方式的生物。在无意中或玩家的有意引导下，骷髅射出的箭可能打中[按钮](按钮.md)、[绊线](绊线.md)、[TNT](TNT.md)、[标靶](标靶.md)或其他物体或生物，<ref></ref>。被骷髅伤害的生物可能会尝试反击骷髅，如果骷髅没被攻击过，被攻击后也会转而攻击那个生物。该生物死亡或远离探测范围后，骷髅就又会将目标转向附近的玩家、铁傀儡或幼年海龟。

如果骷髅不持任何物品（可用}</nowiki>}}生成）或所持物品不是弓，骷髅会双手平举并进行近战攻击。此时它们的行为与[凋灵骷髅](凋灵骷髅.md)相似。

骷髅可以爬[梯子](梯子.md)，但它们只有在迫不得已的时候才会爬，因为骷髅的AI没有将梯子作为特殊的路径处理。

被骷髅杀死的[苦力怕](苦力怕.md)会额外掉落一张*[13](音乐唱片13.md)*、*[cat](音乐唱片cat.md)*、*[blocks](音乐唱片blocks.md)*、*[chirp](音乐唱片chirp.md)*、*[far](音乐唱片far.md)*、*[mall](音乐唱片mall.md)*、*[mellohi](音乐唱片mellohi.md)*、*[stal](音乐唱片stal.md)*、*[strad](音乐唱片strad.md)*、*[ward](音乐唱片ward.md)*、*[11](音乐唱片11.md)*或*[wait](音乐唱片wait.md)*[音乐唱片](音乐唱片.md)。

骷髅在不同版本中的独有特性：
;
* 骷髅在射击目标时会以目标为中心持续侧移绕圈以尝试规避攻击。如果目标离它们太近（小于等于4格），骷髅会主动撤退到安全距离。
* 骷髅在水中攻击目标时仍使用远程射击，尽管水会降低[箭](箭.md)的速度。
* 如果骷髅的副手持有箭或箭的变种，则会一直射出这种箭，且持有的箭不会被消耗。
* 如果骷髅被探测范围之外的玩家用除[风弹](风弹.md)外<ref></ref>的弹射物攻击，骷髅将边拉弦边沿着弹射物袭来的方向前进。发现目标时，骷髅会锁定目标并立即射出一支箭矢。

;
* 骷髅在射击时不会移动。
* 骷髅在水中攻击目标时使用近战攻击。<ref></ref>
* 在陆地上攻击时，目标离骷髅越近，骷髅的射速就越快。

# = 箭伤害 =
# == Java版 ==
骷髅的箭造成的伤害会受到非常多因素的影响，因此最终能造成的伤害是极不稳定且多变的。

除了箭本身基于速度造成伤害的行为外，骷髅本身也会进行随机的箭伤害调整。由骷髅发射的箭会在箭的伤害基数2上，在简单、普通、困难下分别增加0.11，0.22，0.33，然后增加一个中位数为0、上下偏差为0.57425的三角分布随机数，还会再加上骷髅的弓的[](力量（魔咒）.md)魔咒的效果。若击中了玩家，这些伤害会被难度修正。

骷髅发射的箭在受随机散射修正前的速度为32米每秒，然后在XYZ分量上分别增加一个-0.55128米每秒至0.55128米每秒的随机值。这低于玩家射箭能达到的60米每秒，因此也会造成更少的伤害。骷髅不发射暴击箭。

骷髅的箭的伤害还会因为目标与骷髅的相对位置而显著改变：骷髅在攻击低处目标时会造成更多伤害，攻击高处目标时会造成更少伤害。环境也会影响箭的速度：箭被水减速后会造成非常低的伤害，长时间自由落地达到终端速度后能造成非常高的伤害。

# == 基岩版 ==
骷髅的箭在简单和普通难度的基础伤害为，在困难难度的基础伤害为。箭击中实体时造成的伤害为基础伤害区间内的均匀分布随机数，不受速度等任何其他因素影响。

# = 生物族群 =

骷髅是亡灵生物，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉直到接触水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

骷髅会在阳光下[着火](着火.md)，未戴头盔或生物头颅的骷髅会寻找阴凉处、水域以及来避免着火。与[僵尸](僵尸.md)不同，骷髅不会为了攻击玩家而离开阴影区域，而非像僵尸那样在看见玩家后会不顾一切地追逐。但骷髅有时会因为自己盘旋目标的攻击方式而移动到阳光下。

# == 万圣节 ==

在[万圣夜](wzh:万圣夜.md)（10月31日）当天，骷髅生成时有22.5%的概率戴着[雕刻南瓜](雕刻南瓜.md)，有2.5%的概率戴着[南瓜灯](南瓜灯.md)，但雕刻南瓜或南瓜灯不会掉落。<ref></ref>

# = 转化 =
[thumb|180px|right|一只陷入细雪的骷髅转化为流浪者](File:Skeleton become Stray.gif.md)

骷髅处于[细雪](细雪.md)中后会开始转化为[流浪者](流浪者.md)，再经转化完成。转化成流浪者后，其生命值会回满，且其原本携带的装备和武器不会消失。
