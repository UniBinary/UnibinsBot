# 裂纹磨制黑石砖

*页面ID: 58522* | *来源: Minecraft Wiki*

* *裂纹磨制黑石砖（Cracked Polished Blackstone Bricks）**是[磨制黑石砖](磨制黑石砖.md)制作的装饰性方块。

# 生成
# = 自然生成 =
裂纹磨制黑石砖会在[堡垒遗迹](堡垒遗迹.md)和下界的[废弃传送门](废弃传送门.md)中自然生成。

# 获取
# = 烧炼 =

# 破坏
挖掘裂纹磨制黑石砖的合适工具是镐。裂纹磨制黑石砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

裂纹磨制黑石砖被破坏后会掉落自身。

# 用途
裂纹磨制黑石砖目前仅用于装饰。
