* *羽毛（Feather）**是[鸡](鸡.md)和[鹦鹉](鹦鹉.md)在死亡时掉落的一种物品。

# 获取
# = 生物掉落物 =
成年[狐狸](狐狸.md)自然生成时有或的概率在嘴里叼着羽毛，且其死亡时叼着的羽毛总是会掉落。

# = 箱子战利品 =

# = 礼物 =

已驯服的[猫](猫.md)赠予玩家礼物时，礼物有16.129%的概率是1个羽毛。
