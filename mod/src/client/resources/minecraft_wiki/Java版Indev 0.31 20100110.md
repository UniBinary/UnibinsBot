# Java版Indev 0.31 20100110

*页面ID: 35313* | *来源: Minecraft Wiki*

<onlyinclude>
* *0.31**的一个版本发布于2010年1月10日，加入了一些新物品，并修复了一些漏洞。<ref></ref>

# 新内容
# = 物品 =
* *[打火石](打火石.md)**
* 用于生[火](火.md)。

* *[镐](镐.md)**
* 加入了铁镐。
* * 用于采集各种类型的[石头](石头.md)，比徒手采集快四倍。

* *[斧](斧.md)**
* 加入了铁斧。
* * 用于采集[木头](木头.md)，比徒手采集快四倍。

# = 常规 =
* ***
* 加入了[弓](弓.md)的纹理。

# 更改
# = 方块 =
* *[熔岩](熔岩.md)**
* 现在会引燃可燃物。

# = 物品 =
* *[锹](锹.md)**
* 现在可以用于采集[泥土](泥土.md)和[沙子](沙子.md)，比徒手采集快四倍。

* *[苹果](苹果.md)**
* 现在可食用。
* * 恢复。

* *常规**
* 现在所有[掉落物](掉落物.md)均会着火。
* 使用错误的[工具](工具.md)挖掘[方块](方块.md)时，挖掘速度会变慢50%。

# = 生物 =
* *常规**
* 现在均会着火。

# = 游戏内容 =
* *[平视显示器](平视显示器.md)**
* 重新安排了快捷栏中的初始物品，现在有锹、斧、打火石、99个[羊毛](羊毛.md)、99个[玻璃](玻璃.md)、99个[火把](火把.md)、99个[TNT](TNT.md)和99个[书架](书架.md)。
* 之前存在于[物品栏](物品栏.md)中的无用物品被99个苹果所取代。

* *[多人游戏](多人游戏.md)**
* 现在完全不可用了，尝试连接到[服务器](服务器.md)时会导致崩溃，尽管其代码仍然存在于游戏中。

* *[世界界限](世界界限.md)**
* [玩家](玩家.md)现在能够在地图边缘的[基岩](基岩.md)上放置[方块](方块.md)。

# = 世界生成 =
* *[世界类型](Java版已移除特性#Indev世界类型.md)**
* “岛屿”世界类型现在会生成更多沙子。

# 修复
* *修复了2个漏洞**
* 在高度限制以上放置方块时不会再消耗方块了。
* 地图边缘不再是完全黑暗的。</onlyinclude>
