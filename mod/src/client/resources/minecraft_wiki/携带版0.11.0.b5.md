# 携带版0.11.0.b5

*页面ID: 27994* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 5**是[v0.11.0 alpha](携带版0.11.0.md)的第5个测试版，发布于2015年4月17日，加入了新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了新的闪烁标语。

# 修复

* *其他漏洞**
* 聊天文本信息渲染不正确。
* 数据包损坏。
* 浮漂的模型损坏。
* 加载无效的皮肤时游戏崩溃。
* 牛奶的名称不正确。
* 末影人的名称不正确。
* 射箭后重新加载世界会使得箭悬浮在半空中。
* 饮用牛奶不会消除状态效果。
* 创造模式中无法正常使用刷怪蛋。
* 主菜单的背景不会滚动。
* 退出游戏时游戏崩溃。
* 清除后台应用会使游戏黑屏。
* 部分方块实体不会被保存。
* 使用钓鱼竿勾住即将爆炸的苦力怕会使游戏崩溃。</onlyinclude>
