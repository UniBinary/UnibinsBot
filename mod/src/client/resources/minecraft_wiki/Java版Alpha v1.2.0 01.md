# Java版Alpha v1.2.0 01

*页面ID: 32533* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.2.0_01**是的一次次要更新，发布于2010年10月30日，修复了一些漏洞。

# 更改
# = 物品 =
* *[盔甲](盔甲.md)**
* 不再能抵挡攻击伤害。

# = 世界生成 =
* *[下界](下界.md)**
* 不再生成[灵魂沙](灵魂沙.md)。
* 现在会生成[沙砾](沙砾.md)。

# 修复
* *修复了2个漏洞**
* 修复了关于物品栏的崩溃问题。<ref>[IRC记录](#logs.md): "*<Notch> I've updated the client with a fix for the inventory crash as well*", "*<Notch> at least for ONE of them*" (21:54 UTC)</ref>
* 玩家创建新世界时不再会偶尔崩溃。</onlyinclude>

# 参考
*  [IRC记录](https://archive.org/download/MinecraftIRCLogs2010), #minecraft.20101030.log，2010年10月30日，UTC–4
