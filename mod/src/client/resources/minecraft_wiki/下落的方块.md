* *下落的方块（Falling Block）**是部分[方块](方块.md)在失去支撑时生成的[实体](实体.md)。

# 生成
下落的方块会在特定方块失去支撑且收到[PP更新](PP更新.md)后生成。

、、、、及其受损变种、、}}、和在下方为[可替代方块](可替代方块.md)时会变为下落的方块。

在放置时没有得到支撑会变成下落的方块。

破坏作为钟乳石的的上层结构会使未受支撑的滴水石锥变为下落的方块。

# 行为
下落的方块的实体名称为<code></code>。

可下落的方块检测到自身的位置不合理时，就会移除自身并生成一个下落的方块，持续向下下落，直到接触到任意可站立表面。如果上述方块处于[含水](含水.md)状态，则会在原处留下水源。

下落的方块有边界箱但无碰撞体积，无法被攻击，射到上方的箭矢会被弹开，但仍会受部分方块或机制影响而改变运动轨迹，如[活塞](活塞.md)、[黏液块](黏液块.md)、[蜘蛛网](蜘蛛网.md)、[气泡柱](气泡柱.md)和[爆炸](爆炸.md)等。

# = 造成伤害 =
由[铁砧](铁砧.md)和[钟乳石](钟乳石.md)产生的下落的方块落地时会对当前位置的生物造成伤害。下落的方块只有接触到地面后的瞬间才会造成伤害，直接接触下落的方块实体本身，或未接触下落的方块砸中的地面均不会受到伤害。<ref></ref>

对于下落的铁砧，从下落的第2格开始每增加一格高度，伤害增加（例如从4格高处下落的铁砧能造成伤害），最终伤害最多不超过。

对于下落的滴水石锥，由于[受击后伤害免疫](受击后伤害免疫.md)机制，连续砸落在生物身上的多个滴水石锥只能造成一次伤害。以最下方的滴水石锥为基准：
* 从它下落的第3格开始，每下落一格高度，伤害增加量等同于组成原本钟乳石结构的滴水石锥数量，但不会少于；
* 每格高度的伤害增加值固定为，与滴水石锥数量无关<ref></ref>。

不论原先位置离地面有多高，铁砧与钟乳石的最终伤害不会超过。

以上内容使用数学公式表达为：

* 离地面<math>h</math>格高的位置下落的铁砧造成的最终伤害为<math>\min\{2(h-1),40\}</math>。

* 尖端距离地面高度为<math>h</math>格、由<math>a</math>个滴水石锥组成的钟乳石造成的最终伤害为<math>\min\{\max\{a,6\}\times(h-2),40\}</math>。

* 尖端距离地面高度为<math>h</math>格的钟乳石造成的最终伤害为<math>\min\{(h-2),40\}</math>。

装备任意[头盔](头盔.md)可以减少的伤害，但头盔的耐久度会严重损失。令原始伤害为<math>m</math>，则头盔减少的耐久度为{{only|je|for=<math>\lfloor \max\{1, \frac{m}{4}\}\rfloor</math>}}或{{only|be|for=<math>\lfloor \max\{1, \frac{m}{4}\}\rfloor + \lfloor \mathrm{rand}(4,6)\times m \rfloor</math>}}。

# = 混凝土粉末 =

[混凝土粉末](混凝土粉末.md)在接触到[水](水.md)时就会停止下落并变成对应的[混凝土](混凝土.md)。

# = 落地 =
下落的方块落地时，会消失并尝试在自身碰撞箱底面中心的坐标处放置自身对应的方块。使用命令召唤的下落的方块落地时可以保留自身全部方块状态。

只有落点位置方块[可替代](可替代.md)（例如[空气](空气.md)、[水](水.md)、[草丛](草丛.md)等）时才可放置方块，否则改为掉落与它对应的[方块物品](方块物品.md)（如果有），下落的沙砾在这种情况下始终不会掉落燧石。以下情况除外：
* 可疑的沙子和可疑的沙砾总是会直接“摔碎”且不掉落任何物品。
* 下落的滴水石锥总是会消失并掉落一个滴水石锥物品。
*

下落的[铁砧](铁砧.md)在落地时可能会受损或被摧毁。如果铁砧下落的高度高于1格，受损程度恶化的概率为5%×*下落的高度*。

# = 超时 =
如果下落的方块自生成后存在了至少也没有变成方块，或在建造高度外且自生成后存在了至少，它也会消失并尝试掉落自身对应的方块物品。。

# 你知道吗
* 在[Java版1.19](Java版1.19.md)前，受重力影响的方块在接收到[方块更新](方块更新.md)时，是由下落的方块移除的。
* * 因此在下落的方块Time值变为1前用[命令](命令/kill.md)清除，原先受重力影响的方块就不会下落。
* 下落的方块每0.45秒下落一米，生物坠落时往往会穿过下落的方块而非与其一同下降，这有时是致命的。
* 下落的方块属于实体，因此它们能被爆炸或向上的[气泡柱](气泡柱.md)推动。
* 射击下落的方块会使弹射物弹开。
* 下落的方块无法继续下落时会尝试放置自身对应的方块，如果此时所在位置被不完整方块（如火把、放置于方块下半的活板门）占用，就会掉落为物品。
* * 如果下落的方块可以穿过该方块继续掉落，那么其不会被破坏。
