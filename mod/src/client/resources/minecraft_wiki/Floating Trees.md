# Floating Trees

*页面ID: 169919* | *来源: Minecraft Wiki*

* *Floating Trees**是一首由[C418](C418.md)创作的音乐。

# 播放条件
Floating Trees会在[主菜单](主菜单.md)中播放，概率为11%。

# 描述

[File:Floating trees.ogg](File:Floating trees.ogg.md)

Floating Trees是一首温暖、空灵且令人平静的环境音乐，主要由风琴演奏，配以明亮的合成器，并由低音弦乐伴奏，所有乐器都与[Minecraft](Minecraft（音乐）.md)的调性相同。在接近结尾的地方，有一些非常轻柔的叮当声作为背景。结尾部分由远处回响的钢琴轻柔演奏，呼应了[Subwoofer Lullaby](Subwoofer Lullaby.md)的结尾旋律。
