# Minecraft
# = 生物 =
*  - 可以在很多[生物群系](生物群系.md)中找到的一种[友好生物](友好生物.md)。
*  - 一种敌对型的兔子。

# = 物品 =
*  - 食用后恢复饥饿值，击杀兔子获得。
*  - 生兔肉在熔炉内烹煮得到，食用后恢复饥饿值。也可以通过被烧死的兔子获得。
*  - 使用熟兔肉、[胡萝卜](胡萝卜.md)、[烤马铃薯](烤马铃薯.md)和[蘑菇](蘑菇.md)合成得到，食用后恢复饥饿值。
*  - 一种可用于合成[皮革](皮革.md)的物品。
*  - 一种可用于[酿造](酿造.md)的物品。
