# 烈焰纹样陶片

*页面ID: 156720* | *来源: Minecraft Wiki*

* *烈焰纹样陶片（Burn Pottery Sherd）**是图案形似[火](火.md)的[陶片](陶片.md)。

# 获取
# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落烈焰纹样陶片。

# = 饰纹陶罐 =
被不具有[精准采集](精准采集.md)的工具挖掘破坏或被[弹射物](弹射物.md)击毁时，附有烈焰纹样陶片的[饰纹陶罐](饰纹陶罐.md)会掉落烈焰纹样陶片。
