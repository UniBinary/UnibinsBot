# Java版26.1-snapshot-4

*页面ID: 183717* | *来源: Minecraft Wiki*

<onlyinclude>

* *26.1-snapshot-4**是[Java版26.1](Java版26.1.md)的第4个快照，发布于2026年1月20日<ref></ref>，为马、驴和骡的幼年变种加入了新的纹理和模型，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[声音事件](Java版声音事件.md)**
* 加入了幼年马的音效：
* * <code>entity.baby_horse.ambient</code>
* * <code>entity.baby_horse.hurt</code>
* * <code>entity.baby_horse.death</code>
* * <code>entity.baby_horse.angry</code>
* * <code>entity.baby_horse.eat</code>
* * <code>entity.baby_horse.fall</code>
* * <code>entity.baby_horse.land</code>
* * <code>entity.baby_horse.step</code>
* * <code>entity.baby_horse.breathe</code>

# 更改
# = 方块 =
* *[去皮云杉原木](去皮云杉原木.md)**
* 更改了顶面纹理以匹配。

# = 生物 =
* *[马](马.md)、[驴](驴.md)、[骡](骡.md)、[骷髅马](骷髅马.md)**
* 更改了幼年个体的纹理和模型。
* * 调整了幼年马和幼年骷髅马的[边界箱](边界箱.md)以匹配其新模型。

* *[僵尸马](僵尸马.md)**
* 更改了幼年个体的纹理和模型。
* 调整了幼年个体的[边界箱](边界箱.md)以匹配其新模型。
* 现在幼年僵尸马可以通过刷怪蛋或命令生成。

* *[鸡](鸡.md)**
* 现在幼年鸡的翅膀使用双层纹理。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为<code>97.1</code>。
* 猪灵和村民的物品栏可以使用<code>mob.inventory.*</code>访问。
* * 因此，移除了<code>piglin.*</code>和<code>villager.*</code>。

* *[资源包](资源包.md)**
* 将资源包版本号更改为<code>78.1</code>。
