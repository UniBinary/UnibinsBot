# 携带版0.9.0.b4

*页面ID: 31492* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.9.0 alpha build 4**是[v0.9.0 alpha](携带版0.9.0.md)的第4个测试版，发布于2014年6月13日，修复了一些漏洞。

# 更改
# = 生物 =
* *[蜘蛛](蜘蛛.md)**
* [蜘蛛](蜘蛛.md)的动画被加速两倍。

# = 方块 =
* *[末地传送门框架](末地传送门框架.md)**
* 现在有碰撞箱。

# 修复
* *修复了16个漏洞**
* 修复了有关世界保存的漏洞。
* 修复了玩家手持物品时的漏洞。
* 修复了有关实体阴影的漏洞。
* 修复了有关活板门平滑光照的漏洞。
* 修复了睡莲的渲染问题。
* 下落的沙子不再能够穿过蜘蛛网和告示牌。
* 门的顶部现在拥有音效。
* 末地传送门已被加入到创造模式物品栏中。
* 移除了铁锭的重复合成配方。
* 修复了蘑菇煲和南瓜派的错误合成配方。
* 现在草和树叶能够在水下渲染。
* 村庄现在生成得更加稀疏（旧版本中已有的会在创建新世界时消失）。
* 现在可以正确给狼喂食。
* 为方块加入了更好的破坏粒子。
* 巨型蘑菇现在应掉落对应蘑菇而不是蘑菇块。
* 台阶顶部不再会引起渲染问题。</onlyinclude>
