# Java版1.21.7

*页面ID: 155641* | *来源: Minecraft Wiki*

* *1.21.7**是的一次热修复更新，发布于2025年6月30日<ref></ref>，加入了出自[A Minecraft Movie](A Minecraft Movie.md)的[画](画.md)和[音乐唱片](音乐唱片.md)，并修复了一些漏洞。此版本不兼容1.21到1.21.6的服务端。

# 新内容
# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* 加入了1张音乐唱片：
* * Hyper Potions - Lava Chicken
* ** 由玩家或玩家驯服的[狼](狼.md)杀死正在骑乘[鸡](鸡.md)的幼年[僵尸](僵尸.md)掉落。
* ** [稀有度](稀有度.md)为“稀有”。
* ** 通过[红石比较器](红石比较器.md)输出的红石信号强度为9。

# = 非生物实体 =
* *[画](画.md)**
* 加入了1幅由[Sarah Boeving](Sarah Boeving.md)创作的画：
* * Dennis

# = 常规 =
* *[标签](Java版标签.md)**
* 向画变种标签<code>#placeable</code>加入了<code>dennis</code>。
