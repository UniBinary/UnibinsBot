* *远古城市（Ancient City）**是一种大型的地下[结构](结构.md)，主体由[深板岩](深板岩.md)及其变种方块构成。

# 生成
远古城市只会自然生成于[深暗之域](深暗之域.md)生物群系，但可能延伸至其他[洞穴类生物群系](洞穴类生物群系.md)中。

远古城市固定在Y=-52处生成。

# 结构

[远古城市景观|右|缩略图|280px](File:Ancient City Scenery.png.md)
远古城市是一种延伸很广的城池状结构，建筑的主体是[深板岩](深板岩.md)及其砖、瓦、楼梯等变种方块，并杂以深暗之域生物群系本身生成的[幽匿斑块](幽匿斑块.md)。许多铺有[羊毛](羊毛.md)、挂有[灵魂灯笼](灵魂灯笼.md)的墙垣相互交错，其间是形态各异、带有战利品[箱子](箱子.md)的建筑物。各结构在自然生成时有一定程度的残缺。

# = 结构目录 =
远古城市的4类结构（入口、中心、建筑和城墙）均位于文件夹<samp>[client.jar](client.jar.md)/data/minecraft/structure/ancient_city</samp>或<samp>data/behavior_packs/vanilla/structures/ancient_city</samp>中。

# = 入口 =
一条较宽的[深板岩瓦](深板岩瓦.md)拱形长廊从远古城市中心伸出，由多支[蜡烛](蜡烛.md)照明。长廊两侧有破损程度各不相同的大型石柱，其上挂着[灵魂灯笼](灵魂灯笼.md)，其中一根有可能被小型前哨站建筑替代。

# = 中心 =
远古城市的中心部分是一座高大的雕像状结构，四周有围墙。它形似[监守者](监守者.md)，嘴部有一圈[强化深板岩](强化深板岩.md)框架，基座下是[灵魂沙](灵魂沙.md)与燃着的[灵魂火](灵魂火.md)，周围还铺有[蜡烛](蜡烛.md)。雕像的基部有隐藏的几个[红石电路](红石电路.md)房间，其中最大的房间内的电路用于控制[活塞](活塞.md)门，激活其中的[幽匿感测体](幽匿感测体.md)即可打开活塞门。

每种活塞门的激活特点各不相同：
* <code>city_center_1</code>——通过幽匿感测体或[拉杆](拉杆.md)激活后，活塞门开启，15个[红石灯](红石灯.md)亮起，[红石信号](红石信号.md)停止后，前156[游戏刻](游戏刻.md)每12游戏刻熄灭1个红石灯，最后2个在180游戏刻时同时熄灭，随后活塞门关闭。
* <code>city_center_2</code>——与前者类似，但只有[振动频率](幽匿感测体#振动频率.md)等于8的振动（进食、饮用时发出的振动）会使活塞门打开，且没有控制活塞门开关的拉杆。
* <code>city_center_3</code>——幽匿感测体激活后，活塞门会持续打开，直到幽匿感测体再次被激活。

# = 建筑 =
远古城市的建筑物被城墙所包围。房屋大多都无屋顶，并且墙壁坍塌破败，直接露出其中的饰物和[箱子](箱子.md)。部分建筑内由[白色蜡烛](白色蜡烛.md)和[灵魂灯笼](灵魂灯笼.md)提供照明。

# = 城墙 =
城墙自远古城市的中心向四周延伸。每截城墙有两道两格宽的窄走廊，地面铺有灰色[羊毛](羊毛.md)，因此玩家可在其上自由行进而不被[幽匿感测体](幽匿感测体.md)和[监守者](监守者.md)侦测到声音。城墙由[灵魂灯笼](灵魂灯笼.md)提供照明。

# 你知道吗
* 远古城市的灵感来源于和。<ref></ref>
* 开发者希望远古城市给人的感觉是为比玩家更大的生物而建的，因此其中有一些略高的阶梯和房间，以及一个巨大的中心雕像。<ref></ref>
* 有时，结构<code>city_center_3</code>中的活塞门是损坏的，电路中一个红石粉放错了位置，这导致活塞门常开，并在幽匿感测体激活后短暂关闭。<ref></ref>
* 中心雕像的框架形似[监守者](监守者.md)嘴部，但雕像的环形“双耳”有别于监守者的卷须，而更像监守者的旧设计“Hollowed”的双耳。
