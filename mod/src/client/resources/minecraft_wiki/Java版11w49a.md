# Java版11w49a

*页面ID: 31760* | *来源: Minecraft Wiki*

<onlyinclude>

* *11w49a**是[Java版1.1](Java版1.1.md)的第3个快照，发布于2011年12月8日<ref></ref>，加入了刷怪蛋、对多种语言的支持，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 创造模式独有物品，可生成如下生物：
* *  [烈焰人](烈焰人.md)
* *  [洞穴蜘蛛](洞穴蜘蛛.md)
* *  [鸡](鸡.md)
* *  [牛](牛.md)
* *  [苦力怕](苦力怕.md)
* *  [末影人](末影人.md)
* *  [恶魂](恶魂.md)
* *  [岩浆怪](岩浆怪.md)
* *  [哞菇](哞菇.md)
* *  [猪](猪.md)
* *  [绵羊](绵羊.md)
* *  [蠹虫](蠹虫.md)
* *  [骷髅](骷髅.md)
* *  [史莱姆](史莱姆.md)
* *  [蜘蛛](蜘蛛.md)
* *  [鱿鱼](鱿鱼.md)
* *  [村民](村民.md)
* *  [狼](狼.md)
* *  [僵尸](僵尸.md)
* *  [僵尸猪人](僵尸猪人.md)

# = 常规 =
* *[语言](语言.md)文件**
* 加入了多种语言。
* *调试功能**
* 在此快照中，按下可以在创造模式与生存模式之间相互切换。此调试功能在下个快照版本被移除。

# = 游戏内容 =
* *[聊天](聊天.md)**
* [格式化代码](格式化代码.md)<code>§k</code>不再使模糊文本在和两种颜色间变换。

# 更改
# = 生物 =
* *[绵羊](绵羊.md)**
* 现在可通过吃[草方块](草方块.md)和[草丛](草丛.md)的方式来重新长出新的[羊毛](羊毛.md)。
* 为了确保游戏的平衡性，现在修剪羊毛可得到羊毛的数量是1-3个而不是之前的2-4个。

# = 常规 =
* *[暂停菜单](暂停菜单.md)**
* 将“Save and quit to title”重命名为“Save and Quit to Title”。

# 修复
* *修复了4个漏洞**
* 耕地会被物品和粒子破坏。
* 修复了多人游戏中的漏洞。
* 修复了一个动力铁轨的漏洞。
* 修复了一个红石在更新上的漏洞。</onlyinclude>
