* *Etho台阶（Etho Slab）**是用[TNT](TNT.md)材料制作的[台阶](台阶.md)。

# 生成
Etho台阶不会生成在世界中。

# 破坏
没有工具能加速对Etho台阶的挖掘。

Etho台阶被破坏后会掉落自身。

# 用途
玩家尝试破坏Etho台阶时，Etho台阶有概率发出对话气泡。

# = 爆炸 =
Etho台阶有多种方式被激活。一旦Etho台阶被激活，就会消失并在Etho台阶方块的中心（+0.5，+0.5，+0.5）生成一个[被激活的TNT](被激活的TNT.md)实体。

Etho台阶被以下方式激活时，会在后爆炸：
* 玩家对其[打火石](打火石.md)或[火焰弹](火焰弹.md)。
* 被[红石信号](红石信号.md)激活（详见下文）。
* 被发射器中的[打火石](打火石.md)激活。

Etho台阶是[机械元件](红石元件#机械元件.md)，可被下列形式激活：
* 毗邻的开启的[电源](红石元件#电源.md)（例外：[红石火把](红石火把.md)不会激活其所附着的Etho台阶）。
* 毗邻的[充能方块](红石电路/充能与激活.md)。
* 毗邻的指向Etho台阶且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)（包括Etho台阶上方的红石粉）；毗邻但未指向Etho台阶的红石粉不会激活Etho台阶。

Etho台阶被爆炸破坏时，会在到后爆炸。

# = 生成铁砧 =
当Etho台阶爆炸后，它会在爆炸范围内的玩家上方生成一个[铁砧](铁砧.md)。
