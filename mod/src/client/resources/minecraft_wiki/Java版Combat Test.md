# Java版Combat Test

*页面ID: 48783* | *来源: Minecraft Wiki*

[thumb|Combat Test 5的宣传图](File:Combatlogo.png.md)
* *Combat Test**是2019至2020年期間一些关于战斗机制的更改发布的分支快照版本。<ref name="Test1"/><ref name="Test2"/><ref name="Test3"/><ref name="Test4"/><ref name="Test5"/><ref name="Test6"/><ref name="Test7"/><ref name="Test8"/>目前，Reddit上已发布-2}}个关于Combat Test的快照，但它们并不能在[启动器](启动器.md)中下载。虽然这些快照是未来更新的预览版本，但它们目前都是基于1.14.x、1.15.x及1.16.x的快照开发的分支版本，且并没有加入其他新内容。这些更改不会作为一个大型更新的主题而被开发，而是会在全新的战斗系统完整成型后直接被加入游戏。<ref name="Test2"/>目前最新的快照版本为。

2020年時曾表示，彼時的更新仍处于第一阶段。第二阶段将会更注重于数值平衡而不是机制更改，同时也会关注和平衡怪物的数值。<ref name="Test6"/><ref></ref>第二阶段也会在[难度](难度.md)上有所更改。<ref></ref>2025年8月18日，开发者[Ulraf](Nir Vaknin.md)确认Combat Test已被搁置，但团队会继续研究游戏战斗系统的改革和优化。<ref></ref>

# 新内容
# = 游戏内容 =
* *[属性](属性.md)**
* [攻击距离](属性/攻击距离.md)
* * ID为<samp>generic.attackReach</samp>
* * 计算值代表玩家的攻击距离。
* * 只对[玩家](玩家.md)有效。
* * 默认值：<samp>3.0</samp>；最小值：<samp>0.0</samp>；最大值：<samp>6.0</samp>。
* * [剑](剑.md)、[锄](锄.md)和[三叉戟](三叉戟.md)现在会以操作<samp>0</samp>和UUID <samp>26cb07a3-209d-4110-8e10-1010243614c8</samp>修改<samp>generic.attackReach</samp>。

* *[魔咒](魔咒.md)**
* [劈裂](劈裂.md)<ref name="Test3"/>
* * 适用于[斧](斧.md)。
* * 该魔咒第一级增加额外伤害，以后每一级斧的伤害便增加。每一级增加令盾牌失效的时间。
* * 最高等级为III，但使用命令附上更高等级的魔咒会使其效果按预期升级。
* * 与[锋利](锋利.md)、[亡灵杀手](亡灵杀手.md)和[节肢杀手](节肢杀手.md)魔咒互斥。

* *[盾牌](盾牌.md)**
* 增加了“盾牌指示器”选项，决定“盾牌指示器”是否在使用盾牌时显示，与攻击指示器相似。<ref name="Test3"/>
* * 可在视频设置下找到，可选状态有“关”、“十字准星”和“热键”。
* * 默认为关闭。
* 加入了开启或关闭在潜行时自动使用盾牌防御的选项。
* * 该选项位于辅助功能菜单当中。
* * 默认为开启。

# 更改
# = [物品](物品.md) =
* *[剑](剑.md)**
* 所有剑的攻击速度都增至3点（0.33秒）。
* 所有剑的伤害值降低。
* 攻击距离仍为3。

* *[斧](斧.md)**
* 所有斧的[攻击速度](攻击速度.md)都增至2点（0.5秒）。
* 所有斧的伤害值都比同种类的剑高。
* 现在总会令盾牌失效，不再只有25%的概率令盾牌失效。
* 现在进行攻击只会消耗1点耐久值，而非2点。
* 不再能从[附魔台](附魔台.md)附魔锋利、亡灵杀手和节肢杀手等武器类魔咒。现在这类魔咒只能通过[铁砧](铁砧.md)附魔。
* 现在能够附魔[横扫之刃](横扫之刃.md)。
* 攻击距离从3降低至2.5。

* *[锄](锄.md)**
* 更改了大部分锄的攻击速度。
* * 木质：2（0.5秒）
* * 石质：2.5（0.4秒）
* * 铁质：3（0.33秒）
* * 钻石质及金质：3.5（0.28秒）
* 更改了所有锄的附加伤害。
* * 木质、石质及金质：
* * 铁质及钻石质：
* * 下界合金质：
* 攻击距离从3增加至3.5格。

* *[镐](镐.md)**
* 所有镐的攻击速度都增至2.5点（0.4秒）。
* 所有镐的伤害值都增加。
* 攻击距离从3降低至2.5。

* *[锹](锹.md)**
* 所有锹的攻击速度都增至2点（0.5秒）。
* 所有锹的伤害值都降低。
* 攻击距离从3降低至2.5。

* *[三叉戟](三叉戟.md)**
* 攻击速度增至2点（0.5秒）。
* 近战伤害值由减至。
* 攻击距离从3增加至3.5。
* 现在可以由[发射器](发射器.md)发射。
* 带有[忠诚](忠诚.md)魔咒的三叉戟落入虚空也会飞回玩家的手上。
* 带有[穿刺](穿刺.md)魔咒的三叉戟现在会对所有在水中或雨中的生物造成额外伤害。

* *[弓](弓.md)**
* 当拉弓时间超过3秒后，射击的精准度会随着拉弓时间的继续延长而逐渐降低。
* * 这也会使箭无法造成[暴击伤害](弓#武器.md)。

* *[雪球](雪球.md)**
* 现在有4刻的投掷冷却时间。
* 现在可堆叠至64。

* *[鸡蛋](鸡蛋.md)**
* 现在有4刻的投掷冷却时间。

* *[盾牌](盾牌.md)**
* 盾牌现在只能抵挡最多近战攻击伤害，但仍能抵挡100%的弹射物伤害。与旗帜合成后的盾牌可抵挡近战攻击伤害。
* * 这只是在不加入新物品的情况下测试不同类型盾牌的便捷方式，并不会真正应用于游戏中。
* 在放下盾牌时会有0.25秒的转换手持物品的延迟。
* 防御时不能“冲砍”造成额外击退效果。
* 现在受到攻击时只会产生50%的击退抗性。
* * 对于空手或非工具物品的攻击仍然有100%的击退抗性。
* 盾牌不会再把挡下的攻击者击退。
* 有效保护范围（扇形区域）的圆心角从180°减至了100°。
* 现在可以完全格挡非玩家造成的爆炸攻击。

* *[药水](药水.md)**
* 现在可叠加至16。
* * 不包括喷溅和滞留型药水。
* [力量](力量（状态效果）.md)由每级+伤害改为每级+20%伤害。
* [瞬间治疗](瞬间治疗.md)每等级恢复的生命值由提升至。
* 饮用药水的耗时由32刻缩短至20刻。

# = 非生物实体 =
* *[弹射物](弹射物.md)**
* 现在会无视[受击后伤害免疫](受击后伤害免疫.md)的差值计算，总是造成全额伤害。这意味着带有[多重射击](多重射击.md)魔咒的[弩](弩.md)现在可以令其同时发射的3支箭矢全部对同一生物造成有效伤害。
* 弹射物的弹射初速度现在会与玩家的运动速度叠加，但只会在玩家瞄准的方向上叠加。

* *[箭](箭.md)**
* 提高了箭的射击精度（“误差范围”从1.0降至了0.25）。
* 药箭上的瞬间状态效果的实际效果现在被缩放到了，与其他效果保持一致。

* *[雪球](雪球.md)、[鸡蛋](鸡蛋.md)**
* 现在在掷出后的2刻内不会被渲染，以防遮挡玩家视角。

* *[玩家](玩家.md)**
* 移除了对0值伤害的免疫。

# = 游戏内容 =
* *[战斗](Tutorial:战斗.md)**
* 不同的武器和物品现在有不同的近战攻击距离，这些距离与玩家能够触碰方块的距离不同。<!--Weapon reach is always active.-->剑的攻击距离为3格，三叉戟和锄的攻击距离为3.5格，其他物品的攻击距离均为2.5格。
* 攻击冷却现在可以达到200%。
* * 剑的攻击动作完全结束后可以令攻击冷却达到200%。
* * 攻击冷却达到190%<ref name=":190%"></ref>后可以进行横扫攻击。
* * 攻击冷却达到190%<ref name=":190%"/>时攻击距离会增加1.0格（原为增加0.5格）。
* 较短冷却时间的武器会令被攻击者有较短的无敌时间。
* 现在可以通过按住键来自动进行攻击。
* * 此时攻击冷却每达到120%就会自动进行一次攻击。
* 现在可以穿过不完整方块（例如[草](草.md)）来攻击生物。
* 更改了攻击动画以优化连续攻击效果。
* 现在无论使用何种武器，未击中生物时的冷却时间总是为。
* 将基础攻击范围由2.5升至3，并移除了延时攻击的额外攻击范围。

* *[饥饿](饥饿.md)**
* 移除了饱和度加速恢复生命值的特性。
* 强化了自然恢复生命值的特性。玩家的生命值会在饥饿值大于时持续恢复（原值为）。
* 将自然恢复生命值的速度从每提升至每。
* 现在自然恢复生命值只会消耗饥饿值。
* 饱和度不再能恢复生命值，现在只能用于延缓饥饿值的消耗。
* 现在玩家在进食时受到伤害会使进食中断。
* 现在自然恢复生命值消耗饥饿值的速度降低了50%。
* 将进食谜之炖菜、蘑菇煲、兔肉煲、甜菜汤、蜂蜜和奶的耗时由32刻或40刻缩短至20刻。

* *[击退](伤害#击退.md)**
* 击退抗性现在<!--on a scale?-->不再是随机的。
* 重新引入了攻击悬空的实体时产生的向高处击退的效果。

* *[横扫攻击](横扫攻击.md)**
* 只有在冷却时间达到190%时才能够进行横扫攻击。
* 现在即使没有击中实体也可以进行横扫攻击了。
* 现在没有横扫之刃魔咒时无法进行横扫攻击。

* *[附魔](附魔.md)**
* 将[横扫之刃](横扫之刃.md)魔咒每级造成的伤害分别降低到武器基础伤害的25/33/37.5%（原为50/67/75%）。
* 现在在计算状态效果和暴击造成的伤害时，武器魔咒的加成会包含在基础攻击内了（即在武器的基础攻击力和魔咒的加成的基础上再计算状态效果等的伤害）。

# = 常规 =
* *攻击**
* 将物品的基础伤害（包括空手攻击的伤害）由增加至。
