# 效率

*页面ID: 28779* | *来源: Minecraft Wiki*

* *效率（Efficiency）**是一种能够提高玩家[挖掘效率](挖掘#挖掘速度.md)的[魔咒](魔咒.md)。

# 获取

效率V对于[书](书.md)、石工具和钻石工具，附魔需要的[附魔等级](附魔等级.md)超过了30级，因此无法从[附魔台](附魔台.md)获取。

# 用途
# = 提升挖掘速度 =

持有合适的工具时挖掘，若物品具有等级大于0的效率魔咒，则“损坏”的基本速度增加等级的平方再加上1。该修正生效于所有其他挖掘速度修正前。

如果正在挖掘的工具不是正在挖掘的方块的合适挖掘工具，效率魔咒不会生效。
