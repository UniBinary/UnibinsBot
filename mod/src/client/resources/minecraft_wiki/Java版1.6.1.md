# Java版1.6.1

*页面ID: 31649* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.6.1**是**[马匹更新](马匹更新.md)**的首个正式版，也是的一次主要更新，发布于2013年7月1日<ref></ref>。加入了诸如[马](马.md)、[拴绳](拴绳.md)、[煤炭块](煤炭块.md)、[地毯](地毯.md)、[资源包](资源包.md)以及新[启动器](启动器.md)之类的新特性。

# 新内容
# = 方块 =
* *[硬化黏土](硬化黏土.md)**
* 通过将[黏土](黏土.md)放入[熔炉](熔炉.md)内[烧炼](烧炼.md)而成。

* *[染色黏土](染色黏土.md)**
* 拥有16种颜色，对应着16种[染料](染料.md)。
* 与[羊毛](羊毛.md)相似。
* 通过把8块硬化黏土环绕染料来合成，会给予8块染色黏土。

* *[煤炭块](煤炭块.md)**
* 只能使用9个[煤炭](煤炭.md)来[合成](合成.md)。
* 能作为[燃料](燃料.md)使用来烧炼80个物品，多于用于合成的9个煤炭（可烧炼72个物品）。

* *[干草捆](干草捆.md)**
* 可以以任何方向放置。
* 使用9个[小麦](小麦.md)来合成。

* *[地毯](地毯.md)**
* 通过将两个相同颜色的羊毛横向摆放来合成，会给予3块地毯。
* 能放置在任何方块上（包括透明的）。

# = 物品 =
* *[马铠](马铠.md)**
* 存在着钻石、金和铁的变种。
* 不能被合成。但能在大部分世界生成的[箱子](箱子.md)内找到，包括[地牢](地牢.md)、[下界要塞](下界要塞.md)、[沙漠神殿](沙漠神殿.md)和[丛林神庙](丛林神庙.md)。
* *[马刷怪蛋](马刷怪蛋.md)**
* 和自然生成的[马](马.md)一样会有7种基础颜色和5种不同纹路的一种。
* 有概率会生成[驴](驴.md)。

* *[拴绳](拴绳.md)**
* 可以将生物拴在[栅栏](栅栏.md)上或是拴着它们走。
* 通过右击来拴住生物，然后右击栅栏或者再次右击生物来取回拴绳。
* 使用4根[线](线.md)和1个[黏液球](黏液球.md)合成，会给予两条拴绳。

* *[命名牌](命名牌.md)**
* 能在地牢箱子内找到。
* 通过在[铁砧](铁砧.md)内重命名后右击生物来命名。

# = 生物 =
* *[马](马.md)**
* 需要先被驯服。
* 通过右击来骑上它们，未驯服的马会将玩家踢下，驯服时会显示红心。
* 驯服后通过+或骑乘时来安上/取下[鞍](鞍.md)和[马铠](马铠.md)。
* 玩家需要将鞍安上才能控制它们—按住空格来储满它们的跳跃条，松开来跳跃至对应的高度，使用普通的移动键来控制它们。每匹马都有不同的跳跃高度和速度。
* 拥有不同的最大生命值，会天然恢复，但小麦能加快此过程。
* 被杀害时会掉落[皮革](皮革.md)以及穿着的装备。
* 可使用[金苹果](金苹果.md)来繁殖—幼年马能通过喂[小麦](小麦.md)、[糖](糖.md)、[面包](面包.md)、[苹果](苹果.md)或金苹果来成长。
* Mo' Creatures（更多生物Mod）的作者DrZhark帮忙进行了创作。

* *[驴](驴.md)**
* 与马相似，但比马小而且是灰色的，可以安上鞍和[箱子](箱子.md)，物品栏的打开方式与马一样。箱子会给予15个物品槽。

* *[骡](骡.md)**
* 与驴相似，但比驴高而且是棕色的。
* 通过将马和驴交配来生出。
* 和驴一样能安上鞍和箱子。
* 无法与马、驴或其他骡进行交配。

* *[骷髅马](骷髅马.md)与[僵尸马](僵尸马.md)**
* 存在于马的代码中，可以通过第三方程序在游戏中出现。

# 更改
# = 方块 =
* *[红石比较器](红石比较器.md)**
* 现在会根据[炼药锅](炼药锅.md)和[末地传送门框架](末地传送门框架.md)的状态而输出信号。
* * 炼药锅将给予从0（空）到3（满）强度的信号。
* * 末地传送门将给予0（无[末影之眼](末影之眼.md)）或15（有末影之眼）强度的信号。

* *[青金石块](青金石块.md)**
* 稍微地修改了纹理，现在有了边框。

# = 物品 =
* *[木炭](木炭.md)**
* 制作了新的纹理，新的形状和阴影能简单地和煤炭区分开来。

* *[鞍](鞍.md)**
* 鞍也能用在马上了。<ref></ref>

* *[金苹果](金苹果.md)**
* 普通金苹果现在将需要[金锭](金锭.md)而不是[金粒](金粒.md)合成。
* 普通金苹果现在将会给予10秒的[生命恢复](生命恢复.md)II效果，两种金苹果现在也会给予1分30秒的[伤害吸收](伤害吸收.md)效果。

* *[闪烁的西瓜片](闪烁的西瓜片.md)**
* 合成配方从1个金粒增加到8个。

* *[刷怪蛋](刷怪蛋.md)**
* 刷怪蛋现在也能在[水](水.md)上使用。

# = 生物 =
* *常规**
* 名字为“Dinnerbone”或“Grumm”的生物将看上去上下颠倒。

* *[僵尸](僵尸.md)**
* 现在有概率在被攻击或是没被注视时生成更多的僵尸。
* 锁定玩家的距离从16个方块提升到了40个方块。
* 被激怒的僵尸即使在玩家32米外仍能行动。

* *[村民](村民.md)**
* 添加了音效。

* *[蜘蛛](蜘蛛.md)**
* 现有概率带着药水效果生成。

# = 世界生成 =
* *[沙漠](沙漠.md)**
* 不再生成湖泊。

* *[下界](下界.md)**
* [下界要塞](下界要塞.md)内现会生成有宝物的箱子。<ref></ref>

# = 游戏内容 =
* *骑乘坐骑**
* 当骑在[生物](生物.md)上时，其[生命值](生命值.md)会显示在HUD中。
* 当坐在[实体](实体.md)上时，从实体上下来的按键从右击改成了[潜行](潜行.md)键。（默认为）
* [船](船.md)的控制从、、键改为鼠标控制。

* *[](水下呼吸（魔咒）.md)魔咒**
* 现在会改善水下视野。

* *更改了生物难度的概念<ref></ref>**
* 区域难度：待在一个地方的时间越长，难度就越高。
* 随着难度浮动 - 物品，附魔或AI将随着难度更改。

* *标签**
* 在[创造模式物品栏](创造模式物品栏.md)内添加了额外的标签来显示物品是属于哪个分类的。
* [剑](剑.md)、[镐](镐.md)、[锹](锹.md)、[斧](斧.md)和[药水](药水.md)的标签会显示造成的伤害或药水给予的效果。

* *[状态效果](状态效果.md)**
* 为改善体验而作出一些平衡更改。
* * [瞬间治疗](瞬间治疗.md)效果被削弱了33%。（I级只会恢复）
* * [生命恢复](生命恢复.md)效果被削弱了50%。（I级时每2.5秒恢复）
* * [力量](力量（状态效果）.md)效果增加的伤害由每等级变为增加130%每等级。
* * [虚弱](虚弱.md)效果减少的伤害由每等级变为每等级。

* *[饥饿](饥饿.md)**
* 天然生命恢复现在会消耗[饥饿值](饥饿值.md)和[饱和度](饱和度.md)。

* *[创造模式](创造模式.md)**
* 在创造模式内持剑将无法破坏方块。
