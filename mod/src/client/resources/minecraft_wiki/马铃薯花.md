* *马铃薯花（Potato flower）**是一种[小型花](小型花.md)。

# 生成
# = 自然生成 =
马铃薯花会在[马铃薯维度](马铃薯维度.md)（[薯饼](薯饼（生物群系）.md)生物群系除外）自然生成。

# 获取
# = 箱子战利品 =

# 破坏
马铃薯花被挖掘时会立刻被破坏。

马铃薯花被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 谜之炖菜 =

使用马铃薯花合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家12秒[中毒](中毒.md)效果。

# = 堆肥 =
将马铃薯花放入[堆肥桶](堆肥桶.md)有85%的概率使堆肥层数增加1。
