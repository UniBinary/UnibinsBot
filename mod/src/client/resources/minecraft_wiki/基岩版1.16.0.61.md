# 基岩版1.16.0.61

*页面ID: 62140* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.0.61**是[基岩版1.16.0](基岩版1.16.0.md)的第13个测试版，发布于2020年5月14日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[水](水.md)**
* 现在从边缘开始冻结，以匹配[Java版](Java版.md)。

* *[铁砧](铁砧.md)**
* 现在会读取“附魔点数”而不是“XP点数”，以匹配[Java版](Java版.md)。

# = 生物 =
* *常规**
* 现在可以拾取盔甲的生物优先捡起铁盔甲而不是锁链盔甲。

# 修复
* *崩溃**
* 修复了一些游玩时可能发生的崩溃问题。
* 修复了在Samsung Galaxy S Duos 2上启动时发生的崩溃问题。
* 修复了在末地可能发生的崩溃问题。
* 修复了在维度之间穿梭的崩溃问题，包括携带被驯服的生物穿过传送门时。
* 在末影龙重生时使用命令不会再发生崩溃了。
* 在灵魂火上使用命令不会再发生崩溃了。（）

* *常规**
* 修复了重载经典皮肤发生的问题。
* 改善了加载字符的可靠性。（）
* 改善了离线角色的加载支持。
* 现在多人游戏中会在角色创建器之前加载经典皮肤。
* 现在上传和下载的存档过大会进行报错。
* 修复了Windows 10上导入旧世界时可能失败的问题。

* *游戏内容**
* 现在更改了生物数量上限，仅会统计具有生成规则的怪物。（）
* 现在生物消失的范围与模拟距离相绑定。（）
* 修复了多人游戏中村民有时无法与工作点绑定的问题。（）
* 修复了重建和摧毁而导致的村庄重叠生成问题。
* 使用鞘翅飞行过快至未加载区块时不再因“感受到动能”而死亡。（）
* 修复了与旧版本相比，峡谷位置不准确的问题。
* 修复了使用重生菜单的关闭标题来刷物品的问题。
* 现在丢弃具有消失诅咒的物品时不再消失。（）
* 现在玩家只能用铁砧一次附魔一个指南针。
* 修复了重新加载存档后红石火把卡住或掉落的问题。（）
* 修复了海带可能停止生长的问题，现在会检查方块游戏刻决定是否生长。（）
* 摔落缓冲和保护现在可正常工作。（）

* *生物**
* 现在鹦鹉飞行时不再卡住。（）
* 现在生物受惊吓时会执行同样的受伤行为。

* *方块**
* 现在墙可以和大多数方块连接。（）
* 现在受重力影响的方块下落时会被朝上的活塞的活塞臂部分破坏为掉落物。
* 现在蘑菇柄可以用精准采集工具正常采集。（）
* 标靶红石信号的持续时间取决于弹射物种类，三叉戟和箭相较于其他弹射物产生的信号持续时间更长。（）
* 现在重新加载存档后红石火把不再卡住或掉落。（）
* 现在使用结构方块复制方块时会保存命令方块的条件设置。
* 修复了将南瓜灯放置在其他方块旁边时会破坏一些市场内容的问题。
* 现在使用精准采集破坏蘑菇柄不再掉落棕色蘑菇方块。（）

* *图形**
* 修复了改变渲染距离后区块闪烁的问题。
* 修复了地图隐形不可见的问题。（）
* 现在画会正确渲染。（）
* 现在信标光束会正确渲染。（）
* 现在怪物燃烧和火矢箭的火焰动画会正常显示。（）
* 修复了会导致动画纹理停止播放的问题。（）
* 修复了会导致烟火粒子无法正常显示的问题。（）
* 现在工具提示的背景和控制器光标会正确渲染。（和）

* *用户界面**
* 修复了附魔的物品会随着光标移动而闪烁的问题。
* 修复了经典UI下使用触控时偶尔会阻止选择物品的问题。
* 修复了无权限账户尝试进入在线游戏时会出现的无用信息。
* 修复了在Realms更新界面加载资源中点击返回后卡住的问题。
* 修复了使用韩文/中文虚拟键盘时无法输入文本和字符的问题。（）
* 修复了超长文本溢出显示的问题。（）
* 修复了无网络时登录账号时显示 -9 错误的问题。
* 修复了经典UI下使用触控时偶尔会阻止选择物品的问题。

* *命令**
* 修复了远距离传送"tick_world"实体时会消失的问题。
* 现在将盔甲架传送到玩家时会面对玩家。（）

* *附加包**
* 现在鞘翅改为数据驱动。
* 自定义模型的骨骼现会遵循父级的变化。
* 修复了粒子的生命周期小于当前帧的2倍时间下无法绘制的问题。这对Advanced Mining的ghost trail内容，以及其他短生命周期粒子的内容有影响。</onlyinclude>
