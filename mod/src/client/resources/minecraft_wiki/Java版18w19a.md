# Java版18w19a

*页面ID: 34701* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w19a**是[Java版1.13](Java版1.13.md)的第33个快照，发布于2018年5月8日<ref name="article_18w19a"></ref>，加入了新的自选世界生成类型、新的状态效果，分离了方块和液体的一些逻辑，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[水](水.md)和[熔岩](熔岩.md)**
* 分离了方块和液体的一些逻辑<ref></ref>。
* * 目前液体：
* ** <code>minecraft:empty</code>
* ** <code>minecraft:flowing_water</code>
* ** <code>minecraft:water</code>
* ** <code>minecraft:flowing_lava</code>
* ** <code>minecraft:lava</code>
* * 一个位置的液体当前取决于该位置的方块; 目前仍有水方块和熔岩方块。<!-- i.e. this change hasn't happened yet: https://twitter.com/Dinnerbone/status/988712909315493888 -->
* 加入了新的液体[标签](Java版标签.md)：<code>minecraft:lava</code>和<code>minecraft:water</code>。
* 该系统主要是内部的；它不能直接与之交互。

# = 世界生成 =
* *[自选世界类型](自选世界类型.md)**
* 新的自选世界生成类型：洞穴。
* * 与下界的生成相似。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
*
* * 让玩家游得更快。
* * 在[海豚](海豚.md)附近游泳获得。

# 更改
# = 方块 =
* *常规**
* 为数个[方块](方块.md)修改了ID与名称：

* *[海龟蛋](海龟蛋.md)**
* 更改了[海龟蛋](海龟蛋.md)的手持纹理。

* *[海草](海草.md)**
* 现在会在水下洞穴内生成。

# = 物品 =
* *常规**
* 为数个[物品](物品.md)修改了ID与名称：

* *[刷怪蛋](刷怪蛋.md)**
* [幻翼](幻翼.md)的[刷怪蛋](刷怪蛋.md)现在视觉效果更贴近原本生物更新过的纹理。

* *[海洋之心](海洋之心.md)**
* 现在生成于埋藏的宝藏箱中（以一组1个的形式存在）。

# = 生物 =
* *常规**
* 为数个[生物](生物.md)修改了ID与名称：

* *亡灵生物**
* 除了[僵尸马](僵尸马.md)外，亡灵生物现在会沉入水中。

* *[骷髅马](骷髅马.md)**
* [骷髅马](骷髅马.md)现在能够在水中骑乘。

* *[幻翼](幻翼.md)**
* 现在拍动翅膀更加流畅快速。
* 现在会掉落经验。

* *[鹦鹉](鹦鹉.md)**
* 现在会模仿[幻翼](幻翼.md)与[溺尸](溺尸.md)的叫声。

* *[海豚](海豚.md)**
* 当[海豚](海豚.md)溺水时, 它们现在会游回水面。

# = 非生物实体 =
* *[经验球](经验球.md)**
* 现在会浮出水面。

# = 世界生成 =
* *常规**
* 由于新的世界生成机制，之前快照中生成的世界将不再可用。

* *[自选世界类型](自选世界类型.md)**
* 生成器“主世界”和“末地”被重命名为“地表”和“浮岛”。

* *[生物群系](生物群系.md)**
* 为数个[生物群系](生物群系.md)修改了名称：

# = 命令格式 =
* ***
* 输出现在能够被复制。

# = 游戏内容 =
* *[进度](进度.md)**
* “”现在包含潮涌能量的[状态效果](状态效果.md)。

# = 常规 =
* *[音效](音效.md)**
* [信标](信标.md)和[潮涌核心](潮涌核心.md)有新的音效。

* *路径**
* 改进了旧版本的升级路径。

* *制作人员名单**
* 更新了制作人员名单。
