# PlayStation 3版1.07

*页面ID: 83042* | *来源: Minecraft Wiki*

* *1.07**是[PlayStation 3版](PlayStation 3版.md)的一次更新，发布于2014年9月11日。

# 新内容
# = 常规 =
* *存档**
* 加入了存档转移。
* *[音乐](音乐.md)**
* 加入新的音乐。

# 修复
* *修复了6个漏洞**
* 修复了爆炸对不相关区域的破坏的漏洞。
* 修复了乘矿车或骑猪时矿车或猪会闪烁的漏洞。
* 修复了3D声音不正确地衰减的漏洞。
* 修复了火把的判定箱有时不正确的漏洞。
* 修复了附魔物品不能尽可能提高破坏方块的效率的漏洞。
* 修复了工具提示禁用时平视显示器重新定位的漏洞。
