# 命令/transform

*页面ID: 108760* | *来源: Minecraft Wiki*

控制实体进行[变身](变身.md)。

# 语法
   <code>transform clear</code>
  : 恢复原形。
   <code>transform into <entity> [<nbt>]</code>
  : 变身为指定实体。
   <code>transform into player <player></code>
  : 切换至指定玩家的皮肤。
   <code>transform scale <scale></code>
  : 更改尺寸。

# 参数

   指定要变身的实体类型。


   指定该实体的[NBT](实体数据格式.md)。


   指定要切换的玩家。


   指定尺寸。
