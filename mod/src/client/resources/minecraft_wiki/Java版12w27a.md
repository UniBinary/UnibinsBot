# Java版12w27a

*页面ID: 32018* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w27a**是[Java版1.3.1](Java版1.3.1.md)的第14个快照，发布于2012年7月5日<ref></ref>，加入了命令，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* *stop>}}**
* 开始或结束调试分析。

# 更改
# = 方块 =
* *[下界疣](下界疣.md)**
* 下界疣现在能种植在[主世界](主世界.md)和[末地](末地.md)里。

* *[告示牌](告示牌.md)**
* 告示牌可堆叠至16个
* 合成告示牌现在能获得3个而不是1个，配方与之前一样。

* *[活塞](活塞.md)**
* 减少了出错的可能，但它们激活状态的更新变慢了，这也改变了活塞的工作方式，使得玩家不得不改变使用[红石中继器](红石中继器.md)等装置的属性。
* * 关于这个更改，活塞现在需要2红石刻（4游戏刻）来伸展，但它们仍会瞬间收回。

# = 非生物实体 =
* *[船](船.md)**
* 船现在被玩家摧毁时会掉落物品。

# = 游戏内容 =
* *[创造模式物品栏](创造模式物品栏.md)**
* 现在会在创造模式物品栏下显示玩家当前拥有的[状态效果](状态效果.md)。

* *[经验](经验.md)**
* 采矿获得的经验现在不同了（采集[煤矿石](煤矿石.md)获得的经验较少，而采集[钻石矿石](钻石矿石.md)和[绿宝石矿石](绿宝石矿石.md)获得的经验较多）。

# 修复
* *修复了13个漏洞**
* 新加入的木楼梯现在会燃烧了。
* 修复了命令不能工作的问题。
* 修复了给特定的有问题的活塞充能时导致游戏崩溃的问题。
* 修复了导致活塞部分不可见和暂时处于错误位置的视觉问题。
* 修复了在下界放置下界传送门并通过时，其在主世界对应位置的门可以生成在非法位置上的问题。
* 修复了使用特定语言时，向局域网开放单人游戏会导致崩溃的问题。
* 修复了在矿车、船和猪上的玩家以及蜘蛛骑士不被显示在正确位置上的问题。
* 修复了一个关于发射器的问题。
* 修复了命令不接受某些来自控制台的字符串，从而显示帮助文本的问题。
* 修复了可以使用依赖于方向的绊线，将方块原有数据值变为特定数据值的问题。
* 修复了在创造模式中喝药水不消耗药水，但是仍然会给予空玻璃瓶的问题。
* 修复了告示牌有时不会保存放置它们时写入的文本内容的问题。
* 修复了火把不会照亮其本身所附着的1×1垂直轴上的方块的问题。</onlyinclude>
