# 制图台

*页面ID: 37012* | *来源: Minecraft Wiki*

* *制图台（Cartography Table）**是用于复制、缩小和锁定[地图](地图.md)的固体[方块](方块.md)。

# 生成
# = 自然生成 =
制图台会生成在[村庄](村庄.md)的制图师小屋中。

制图台也会生成在[古迹废墟](古迹废墟.md)的一个独栋圆顶屋中。

# 获取
# = 合成 =

# 破坏
挖掘制图台的合适工具是斧。

制图台被破坏后会掉落自身。

# 用途

# = 制图 =
制图台可用于复制、缩小和锁定[地图](地图.md)。

制图台也可用于向地图添加指针、创建空地图以及重命名地图。

以下为在制图台能使用的所有配方：

# = 更改村民职业 =

如果一个制图台没有被[村民](村民.md)认领，则附近的任意一个失业村民有机会转变职业为[制图师](制图师.md)。

# = 燃料 =
制图台可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个制图台可烧炼1.5个物品。
