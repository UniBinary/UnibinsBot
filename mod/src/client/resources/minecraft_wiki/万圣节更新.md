# 万圣节更新

*页面ID: 6435* | *来源: Minecraft Wiki*

[缩略图|[[Notch](File:boo original.png.md)希望能在更新前完成的特性列表|400px]]
[缩略图|[[Notch](File:Boo.png.md)在更新中完成的特性列表|400px]]

* *万圣节更新（Halloween Update）**是[Java版Alpha](Java版Alpha.md)的一次主要更新，首个版本[Alpha v1.2.0](Java版Alpha v1.2.0.md)于2010年10月30日发布。此次更新的主题于2010年10月4日在Notch的博客中被公布。<ref name="name"></ref>新的维度[下界](下界.md)是更新中最重要的特性。

# 重要特性

* *新内容**
* [下界](下界.md)
* [下界传送门](下界传送门.md)
* 6种新方块：[荧石](荧石.md)，[下界岩](下界岩.md)，[灵魂沙](灵魂沙.md)，[南瓜](南瓜.md)，[南瓜灯](南瓜灯.md)，[下界传送门方块](下界传送门方块.md)。
* 2种新生物：[恶魂](恶魂.md)，[僵尸猪人](僵尸猪人.md)。
* 2种新物品：[时钟](时钟.md)，[荧石粉](荧石粉.md)。
* [生物群系](生物群系.md)
* [钓鱼](钓鱼.md)

* *重要更改**
* 现可通过隐藏[平视显示器（Heads-Up Display）](HUD.md)和玩家的视图模型。
* 更深的[草方块](草方块.md)和[树叶](树叶.md)。
* 黎明和黄昏时地平线会泛红光，就像真正的日出和日落那样。
* [苦力怕](苦力怕.md)有了新的受伤音效。

# 历史
2010年10月4日，Notch的博客中公布了这一更新。<ref name="name"/>2010年10月8日，一种新方块被公布。三天后，Notch在Twitter上说：“我刚刚把很不公平的生物做得更不公平。你会恨[恶魂](恶魂.md)的。”<ref></ref>2010年10月10日，Notch在他的博客里第一次发布了[下界](下界.md)的截图。[thumb|400px|right|2010年10月10日于Notch的博客上发布的截图](File:Halloween Update Screenshot.png.md)2010年10月19日，Notch在他的博客里发表了以下内容：“那将会有6种新方块（其中5个有独特的功能），1种新怪物，1个新维度，以及一些漏洞修复。”<ref></ref>

2010年10月22日，[此文章](http://www.pcgamer.com/2010/10/22/minecraft-halloween-update-preview-meet-the-ghasts/)出现在PC Gamer的网站上，给予了关于更新的更多细节。文章里写到恶魂是一种“可以摧毁你附近的方块并让它们着火，还会向你吐火球的方形飞天水母”，以及带你去[下界](下界.md)的传送门将会是由[黑曜石](黑曜石.md)做的。

2010年10月25日，Notch在Twitter上说到：“今天我在第二个生物上下功夫，它比恶魂安全多了，其实说真的，它没什么意义！”<ref></ref>这之后被证实为[僵尸猪人](僵尸猪人.md)。

2010年10月29日，[Indie Games](http://www.indiegames.com/blog/2010/10/handson_with_the_minecraft_hal.html) 和 [PC Gamer](http://www.pcgamer.com/2010/10/29/minecraft-halloween-update-hands-on/)发表了关于万圣节更新的文章，其中包含了新内容的视频和截图。两个网站上传了第二个预告视频。PC Gamer视频的标题为Slipgate Adventures，而Indie Games的第二个视频可以在[这里](http://www.indiegames.com/blog/2010/10/moving_between_worlds_in_the_m.html)看到。

# 你知道吗
* “特性列表”先前存在于 minecraft.net/boo，这个页面的存档可以在[archive.org](http://web.archive.org/web/20101204044906/http://www.minecraft.net/boo/)看到。
* 特性列表上说到“传送进来，走10米，传送回去，你就在几百米以外了。”但其实主世界的水平坐标与下界的水平坐标比例为8：1。因此，在下界移动10米，意味着在主世界移动了80米，而不是几百米。并且如果在小于16米的距离内创建一个新的传送门，新的传送门更有可能会把玩家带回到主世界中第一个传送门的位置（除非第一个传送门已被摧毁），而这会导致玩家实际上没有移动。
* 原本[火把](火把.md)被计划改为有限时长的[光源](亮度.md)，可能会在一段时间后熄灭并且需要[打火石](打火石.md)重新点燃，灯笼将作为火把的代替品被加入。但计划没有及时完成，并且由于社区的负面反应，这个计划最终被取消了。
* * 愚人节版本[Java版2.0](Java版2.0.md)加入了火把的燃尽变种。
* * [Java版1.14](Java版1.14.md)加入了[灯笼](灯笼.md)，但火把仍然是一种永久光源。
