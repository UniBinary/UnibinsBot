# Java版1.14-pre5

*页面ID: 42313* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14-pre5**是[Java版1.14](Java版1.14.md)的第5个，也是最后一个预发布版，发布于2019年4月18日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *方块实体**
* [刻](刻.md)现在会正常运作。

* *制作人员名单**
* 更新了名单，加入了更多的Mojang员工。

* *优化**
* 优化了[下界传送门](下界传送门.md)。
* * 在一个实体进入传送门时，传送门的另一端将加载15秒。
