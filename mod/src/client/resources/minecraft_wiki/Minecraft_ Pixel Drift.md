# Minecraft: Pixel Drift

*页面ID: 167003* | *来源: Minecraft Wiki*

* **Minecraft: Pixel Drift***是由floopy, Synthion, [Hyper Potions](Hyper Potions.md), Turbo, meganeko和EX-LYD创作的混音专辑，于2025年9月3日在多平台发布。此专辑是*[Minecraft: The Wild Update (Original Game Soundtrack)](Minecraft: The Wild Update (Original Game Soundtrack).md)*, *[Minecraft: Caves & Cliffs (Original Game Soundtrack)](Minecraft: Caves & Cliffs (Original Game Soundtrack).md)*, *[Minecraft: Trails & Tales (Original Game Soundtrack)](Minecraft: Trails & Tales (Original Game Soundtrack).md)*和*[Minecraft: Chase the Skies (Original Game Soundtrack)](Minecraft: Chase the Skies (Original Game Soundtrack).md)*中的部分曲目的混音版本。专辑封面与动画版本由Martin Wörister制作。
