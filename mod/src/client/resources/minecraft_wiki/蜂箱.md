# 蜂箱

*页面ID: 158312* | *来源: Minecraft Wiki*

{{for|自然生成的蜜蜂-{}-巢穴|蜂巢（方块）}}

* *蜂箱（Beehive）**是可通过合成获取的可作为蜜蜂-{}-巢穴的方块，功能上与[蜂巢](蜂巢（方块）.md)类似。

# 生成
蜂箱不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘蜂箱的合适工具是[斧](斧.md)。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，蜂箱被破坏后会掉落自身，蜂箱中的蜜蜂会以激怒状态被释放出来，同时还会激怒附近的所有蜜蜂。

被具有精准采集的工具挖掘破坏时，蜂箱被破坏后会掉落自身，并装着其中的蜜蜂。

在[创造模式](创造模式.md)下破坏装有蜜蜂的蜂箱时，该蜂箱会掉落并装着其中的蜜蜂，并保留其<code>honey_level</code>数据。<ref></ref>

# 用途
蜂箱有一项方块状态<code>honey_level</code>，可以取0—5中的一个值。新放置的蜂箱的<code>honey_level</code>为0。

<code>honey_level</code>为5的蜂箱会使用充满了蜂蜜的纹理，表明蜂箱可以收获。若该方块的下表面未被遮挡，还会产生滴落的蜂蜜[粒子](粒子.md)。

# = 容纳蜜蜂 =
蜂箱最多同时容纳3只蜜蜂。蜜蜂可以从蜂箱的任何一面进去，但只能从正面出来。

蜜蜂在工作完成后，会不带花蜜离巢，并使蜂箱的<code>honey_level</code>增加1，至多增加至5。

与蜂箱相邻的任何一个方块是[火](火.md)时，其中所有的蜜蜂都会逃离。

# = 收获 =
对<code>honey_level</code>为5的蜂箱[剪刀](剪刀.md)会使其掉落3个[蜜脾](蜜脾.md)，使用[玻璃瓶](玻璃瓶.md)则会使玻璃瓶变为[蜂蜜瓶](蜂蜜瓶.md)，随后其<code>honey_level</code>会变为0。

若玩家从蜂箱收获时，蜂箱的正下方6格内没有点燃的[营火](营火.md)或[灵魂营火](灵魂营火.md)，或二者之间被其他方块阻挡，则其中所有的蜜蜂都会被释放出来并与该玩家敌对。用[发射器](发射器.md)进行收集不会将蜜蜂释放出来。玩家在创造模式或[和平难度](难度#和平.md)下收获时，蜜蜂仍然会被释放出来，但不会攻击玩家。

# = 红石信号 =
当[红石比较器](红石比较器.md)连接至蜂箱时，会输出与其方块状态<code>honey_level</code>相同数值强度的红石信号。
