# 携带版数据值/Alpha 0.2.0前

*页面ID: 161556* | *来源: Minecraft Wiki*

这些数据值适用于中[Demo](携带版Demo.md)至[0.1.3](携带版0.1.3.md)版本中的方块。
# 方块ID
方块 ID 用于定义放置在世界中的方块和物品栏中的物品。带有<span style='color:red'>红色</span>ID的物品无法以正常方式在游戏中在玩家的物品栏中得到，它们只能通过编辑物品栏获得。

物品ID用于定义物品栏中的物品。[携带版0.2.0](携带版0.2.0.md)之前，只有一个可用的物品。
