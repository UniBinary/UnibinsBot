# Java版18w16a

*页面ID: 34293* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w16a**是[Java版1.13](Java版1.13.md)的第32个快照，发布于2018年4月19日<ref></ref>，加入了自选世界类型，并修复了一些漏洞。

# 新内容
# = 世界生成 =
* *[自选世界类型](自选世界类型.md)**
* 用于创建单一生物群系世界。
* 允许在生成主世界与末地地形间选择。

# 更改
# = 方块 =
* *[水](水.md)**
* 水流动并会转变成水源方块的过程改为立刻在该地放置水源方块。

* *[珊瑚扇](珊瑚扇.md)**
* 现在生成在[珊瑚礁](珊瑚礁.md)中[珊瑚块](珊瑚块.md)的侧边。

* *[蓝冰](蓝冰.md)**
* 稍微降低[蓝冰](蓝冰.md)的滑度。

* *[珊瑚块](珊瑚块.md)**
* 现在需要精准采集魔咒的工具才能在被挖掘时掉落为珊瑚块，否则会掉落失活的珊瑚块。
* 不再在陆地上立即转换为失活的珊瑚块。

* *[珊瑚](珊瑚.md)**
* 加入了珊瑚有关的方块与物品标签。

* *[潮涌核心](潮涌核心.md)**
* 放出的粒子效果改为<code>entity_core</code>纹理。

# = 物品 =
* *[海龟壳](海龟壳.md)**
* 给予的[水下呼吸](水下呼吸（状态效果）.md)不再显示粒子效果。

# = 实体 =
* *[溺尸](溺尸.md)**
* 现在可以生成在[海底废墟](海底废墟.md)里。

# = 常规 =
* *[生物群系](生物群系.md)**
* 更改海洋生物群系的温度计算——优化了在海域间温度的转化。
* 生物群系名称可翻译了。
* 一些生物群系的名称更新：

* *[生成](生成.md)**
* 优化了生成位置寻找的代码。
* 新的<code>valid_spawn</code>方块标签用于控制玩家可生成的位置。

* *[刻](刻.md)**
* “液体刻”与“方块刻”现在有所区别。
