* *竹马赛克台阶（Bamboo Mosaic Slab）**是[竹马赛克](竹马赛克.md)制作的[台阶](台阶.md)。

# 生成
竹马赛克台阶不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘竹马赛克台阶的合适工具是斧。

竹马赛克台阶被破坏后会掉落自身，双台阶被破坏后会掉落两个组成自身的台阶。

# 用途

# = 燃料 =
竹马赛克台阶可以作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)。每个竹马赛克台阶在[Java版](Java版.md)中能烧炼0.75个物品，在[基岩版](基岩版.md)中能烧炼1.5个物品。
