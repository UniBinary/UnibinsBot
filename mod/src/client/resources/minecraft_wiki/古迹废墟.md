* *古迹废墟（Trail Ruins）**是一种被掩埋的陶瓦建筑群[结构](结构.md)。

# 生成
古迹废墟自然生成于[丛林](丛林.md)、[针叶林](针叶林.md)、[积雪针叶林](积雪针叶林.md)、[原始松木针叶林](原始松木针叶林.md)、[原始云杉针叶林](原始云杉针叶林.md)、[原始桦木森林](原始桦木森林.md)，从地表以下15格的高度开始生成，废墟的最高处（塔顶）通常裸露在地表。

# 结构
古迹废墟的建筑物主要由[泥砖](泥砖.md)、各色[陶瓦](陶瓦.md)和[带釉陶瓦](带釉陶瓦.md)构成，内部被大量[沙砾](沙砾.md)、[泥土](泥土.md)和[砂土](砂土.md)掩埋。

与多数结构不同的是，古迹废墟的战利品不在[箱子](箱子.md)里，而是藏在[可疑的沙砾](可疑的沙砾.md)中。玩家需要寻找这种夹杂在沙砾、泥土、砂土中的方块，并用[刷子](刷子.md)从中刷扫出战利品。少数可疑的沙砾是浮空生成的，因此其周围的方块更新会导致它被意外破坏。<ref></ref>

# = 结构目录 =
古迹废墟的4类结构（房屋、摆设、道路、塔楼）均位于文件夹<samp>[client.jar](client.jar.md)/data/minecraft/structure/trail_ruins</samp>或<samp>data/behavior_packs/vanilla/structures/trail_ruins</samp>中。

# = 塔楼 =
塔楼是古迹废墟的起始结构池。它由一座高塔和几个较矮的小房间组成。

# = 道路 =
[圆石](圆石.md)和[石砖](石砖.md)铺成的道路从高塔的正门向远处笔直延伸，两侧连接着各种房屋和摆设。整条道路实际上是由几小段结构模板拼接成的。

# = 房屋 =
道路旁侧的房屋分为组合房、独栋房和大房间。其中组合房的主室为狭长的厅堂，两侧各连接着2个“耳房”。

# = 摆设 =
道路旁侧的摆设都较为小巧，均以圆石为底。

# = 构成方块 =

为了将结构做旧、添入战利品，古迹废墟生成时会随机选择一些方块进行替换：
* 对于每个塔尖结构（<code>tower/tower_top_*x*</code>），将其中2个沙砾替换成可疑的沙砾（普通战利品）。
* 对于每个道路结构（<code>roads</code>文件夹中的结构），将其中10%的泥砖替换成泥坯；先将其中20%的沙砾替换成泥土，再将10%的沙砾替换成砂土，最后将2个沙砾替换成可疑的沙砾（普通战利品）。
* 对于其他每个结构：将其中10%的泥砖替换成泥坯；先将其中20%的沙砾替换成泥土，再将10%的沙砾替换成砂土，接着将6个沙砾替换成可疑的沙砾（普通战利品），最后将3个沙砾替换成可疑的沙砾（稀有战利品）。
* * 由于中包含的沙砾过少，实际生成的可疑的沙砾不足9个。
