# 爆炸保护

*页面ID: 29587* | *来源: Minecraft Wiki*

* *爆炸保护（Blast Protection）**是一种用于[盔甲](盔甲.md)的[魔咒](魔咒.md)，能减少[爆炸](爆炸.md)伤害。

# 获取

# 用途
爆炸保护与其任何不共存魔咒被应用在同一个物品上时，每个魔咒都会互不干扰地产生效果。

# = 减少伤害 =

爆炸保护可以减少爆炸伤害，包括[爆炸](爆炸.md)现象和[烟花火箭](烟花火箭.md)爆裂时造成的伤害。每魔咒等级提供2点魔咒保护系数（EPF），即8%伤害减免。

# = 增加爆炸击退抗性 =

爆炸保护可以使生物的[爆炸击退抗性](属性/爆炸击退抗性.md)增加<code>-{}-等级×15%</code>，使受到的[爆炸击退](爆炸击退.md)强度减少。计算魔咒等级时取所有装备的魔咒等级的总和。达到7级时，生物不受爆炸击退影响。
