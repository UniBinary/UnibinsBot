# Java版18w45a

*页面ID: 37136* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w45a**是[Java版1.14](Java版1.14.md)的第5个快照，发布于2018年11月7日<ref></ref>，加入了脚手架、灾厄巡逻队，重写了命令，在资源包菜单加入了旧版纹理的资源包（“Programmer Art – The classic look of Minecraft”），并修复了一些漏洞。

# 新内容
# = 方块 =
* *[脚手架](脚手架.md)**
* 一种可以攀爬的[方块](方块.md)。
* 可使用[竹子](竹子.md)和[线](线.md)合成。
* [玩家](玩家.md)可以按爬上，爬下。
* 玩家和生物可以步行穿过脚手架。

# = 游戏内容 =
* *[灾厄巡逻队](灾厄巡逻队.md)**
* 在世界中生成的一个由1只[](灾厄之兽.md)和4只[掠夺者](掠夺者.md)或[卫道士](卫道士.md)组成的群体。
* 生成在[平原](平原.md)、[针叶林](针叶林.md)、[沙漠](沙漠.md)、[热带草原](热带草原.md)生物群系的所有变种的[草方块](草方块.md)和[沙子](沙子.md)上。
* 在巡逻队队长的头顶上可以找到一种新的[旗帜](旗帜.md)。

# = 常规 =
* *[资源包](资源包.md)**
* 在资源包菜单加入了“Programmer Art – The classic look of Minecraft”资源包。

# 更改
# = 方块 =
* *[告示牌](告示牌.md)**
* 重写了告示牌编辑，使其更直观。
* * 加入了用于编辑自由文本的新可移动光标。
* * 支持选择、复制和粘贴。
