# 基岩版1.19.60.26

*页面ID: 101104* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.60.26**（Android）、**Preview 1.19.60.26**（Xbox/Windows/iOS/iPadOS）是[基岩版1.19.60](基岩版1.19.60.md)的第6个测试版，发布于2023年1月11日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[拉杆](拉杆.md)**
* 现在使用与石质（此前为木质）按钮激活和取消激活音效相同的开关音效。

# = 技术性 =
* *用户界面**
* 现在在创建世界之前进入另一界面后，资源包会应用到该世界中。
* 修复了下载部分资源包后会收到错误提示的问题。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”、“即将推出的创作者功能”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[悬挂式告示牌](悬挂式告示牌.md)**
* 现在玩家在不潜行的情况下对齐放置悬挂式告示牌时，悬挂式告示牌的两条锁链会呈现为垂线，反之为V字形。

# 修复
* *命令**
* 修复了玩家睡觉时被传送会导致无法起床的漏洞。（）

* *游戏内容**
* 修复了无法解锁“始作俑者”成就的问题。

* *图形**
* 弹出键盘时Android平台上的UI不再会闪烁。（）
* 高亮显示选择不再会将树苗之类的透明对象高亮显示为完整的卡片状物体。
* 垂直同步设置现在会在选项中正确配置（非ARM设备）。（）
* 现在在创建世界之前进入另一界面后，资源包会应用到该世界中。
* 修复了下载部分资源包后用户会收到错误提示的问题。
* 修复了熔炉、高炉和烟熏炉UI中的文本会略微左偏的问题。（）

* *性能与稳定性**
* 修复了使用鞘翅滑翔进入末地传送门时可能发生的崩溃。
* 战利品表中具有无效条件、函数或随机池抽出项的实体被杀死时，游戏不再会崩溃。（）

* *原版趋同**
* 拉杆现在会发出与石质按钮相同的音效。（）

* *触摸控制**
* 修复了非触控模式下的物品堆叠拆分问题。</onlyinclude>
