# Java版13w26a

*页面ID: 33562* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w26a**是[Java版1.6.1](Java版1.6.1.md)的第18个，也是最后一个快照，发布于2013年6月24日<ref></ref>，修复了一些漏洞。

# 修复

|18640|当所使用的语言文件缺失时，游戏会在启动时崩溃。
|;dev
|13737|被骑乘的马、骡、驴会在重新加载游戏时重复生成。
|13774|在水下骑乘实体会导致客户端与服务端数据不同步。
|14944|重质测重压力板的英文名“Weighted Pressure Plate (Heavy)”过长，导致无法在铁砧中为其命名。
|16413|船在水中会像马那样与玩家分离。
|16828|马在奔腾时会同时发出奔腾和先前版本中行走的声音。
|16847|玩家在骑马的同时按下键和键会导致下马后马的跳跃蓄力条不会消失。
|16887|骑乘没有上鞍的马时按下下马键会从马的侧边下马。
|17571|生命提升效果失效后给予的额外生命值仍然显示在屏幕上。
|17667|转换资源包时，游戏错误将石砖的纹理转换为圆石的纹理。
|17938|游戏无法正确转换一些动画纹理。
|17997|装备有马铠的马无法繁殖。
|18505|骑马时玩家的朝向不正确。
|18522|3D图像模式下游戏有时会在选项界面崩溃。
|;previous
|18632|玩家骑乘马跳跃时，马不会受到跳跃提升状态效果的影响。
|18633|局域网世界中会出现卡顿并导致游戏崩溃。
|18941|语言选项界面只有“English (US)”一种语言。
}}</onlyinclude>
