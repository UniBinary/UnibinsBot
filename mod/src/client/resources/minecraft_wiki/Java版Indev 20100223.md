# Java版Indev 20100223

*页面ID: 35444* | *来源: Minecraft Wiki*

* *Minecraft Indev**的最后一个版本发布于2010年2月23日，加入了[画](画.md)。<ref></ref>

# 新内容
# = 非生物实体 =
* *[画](画.md)**
* 一种新的装饰性[实体](实体.md)。
* 具有[物品](物品.md)形式。
* 可由8个[木板](木板.md)和1个[淡灰色羊毛](淡灰色羊毛.md)合成。
* 加入了19幅由[Kristoffer Zetterstrand](Kristoffer Zetterstrand.md)创作的画：
* * Kebab
* * Aztec
* * Alban
* * Aztec2
* * Bomb
* * Plant
* * Wasteland
* * Wanderer
* * Pool
* * Courbet
* * Sunset
* * Sea
* * Match
* * Bust
* * Stage
* * Void
* * SkullAndRoses
* * Fighters
* * Pointer

# 更改
# = 方块 =
* *[水](水.md)**
* 改进了性能。

* *[木-{}-头](原木.md)**
* 被破坏后会掉落其自身而非[木板](木板.md)。

* *[木板](木板.md)**
* 加入了合成配方，现在可由1个木-{}-头合成。

* *[石头](石头.md)**
* 现在可由烧炼[圆石](圆石.md)获得。

# = 生物 =
* *[绵羊](绵羊.md)**
* 现在被攻击时只掉落[浅灰色羊毛](浅灰色羊毛.md)。</onlyinclude>
