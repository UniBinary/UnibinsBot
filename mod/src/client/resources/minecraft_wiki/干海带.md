# 干海带

*页面ID: 33669* | *来源: Minecraft Wiki*

* *干海带（Dried Kelp）**是一种用[海带](海带.md)烹饪而成的[食物](食物.md)。

# 获取
# = 烹饪 =
将海带放入[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或[营火](营火.md)中烹饪，可以获得干海带。

# = 合成 =

# 用途
# = 食物 =

[缩略图|玩家正在食用干海带](File:Eating dried kelp.jpg.md)

手持干海带按住键即可食用，每个干海带可以回复和或饱和度。

玩家食用一个干海带的时长为，短于其他多数食物的。

# = 合成材料 =

# = 堆肥 =
干海带有30%概率将[堆肥桶](堆肥桶.md)堆肥等级增加1。
