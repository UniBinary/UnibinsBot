# Java版13w17a

*页面ID: 33524* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w17a**是[Java版1.6.1](Java版1.6.1.md)的第3个快照，发布于2013年4月25日<ref></ref>，加入了陶瓦，修改了地毯的合成配方和水湖、僵尸的生成机制，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[陶瓦](陶瓦.md)**
* 通过烧炼[黏土](黏土.md)获得。

# 更改
# = 方块 =
* *[地毯](地毯.md)**
* [地毯](地毯.md)的配方现在会给予3个地毯。

# = 生物 =
* *[僵尸](僵尸.md)**
* 现在在受到伤害时有概率生成更多的僵尸。
* * 此为此特性的早期版本。在未来，这将主要发生在视线外的封闭空间内。<ref></ref>

# = 世界生成 =
* *[水湖](水湖.md)**
* 水湖不再会在沙漠中生成，但熔岩湖仍会生成。
* 湖只会在沙漠生物群系的边缘生成。

# = 游戏内容 =
* *工具提示**
* 为创造模式物品栏里的搜索栏加入了额外的工具提示。
* 工具提示会提示方块/物品属于哪个类别。
