# 基岩版1.16.210.60

*页面ID: 78238* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.210.60**是[基岩版1.16.210](基岩版1.16.210.md)的第10个测试版，发布于2021年2月18日<ref></ref>，加入了GameTest自动工具，移除了[发光鱿鱼](发光鱿鱼.md)相关特性，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 用于测试GameTest功能。

# = 技术性 =
* *GameTest框架**
* 一个基于将测试代码与测试结构配对的服务端测试的自动工具。
* 在主机版上不可用。
* 仅开启[实验性玩法](实验性玩法.md)后可用。

# = 常规 =
* *[设置](设置.md)**
* 加入了新的[实验性玩法](实验性玩法.md)选项：“Enable GameTest Framework”。

# 更改
# = 方块 =
* *[荧光物品展示框](荧光物品展示框.md)**
* 由于崩溃而暂时移除。

* *[告示牌](告示牌.md)**
* 移除了告示牌的文本染色和增亮效果，原本有效果的告示牌文本会变回黑色。

# = 物品 =
* *[荧光墨囊](荧光墨囊.md)**
* 由于崩溃而暂时移除。

* *[刷怪蛋](刷怪蛋.md)**
* 暂时移除了发光鱿鱼刷怪蛋。

# = 生物 =
* *[发光鱿鱼](发光鱿鱼.md)**
* 由于崩溃而暂时移除。

# 修复
* *性能与稳定性**
* 修复了结构方块加载幽匿感测体时可能发生的崩溃。（）
* 修复了与告示牌交互时可能发生的崩溃。（）

* *常规**
* 选择是否在链接上下载资源包的时间限制由5秒提升至5分钟。

* *新UI**
* 现在默认使用新成就界面（除了VR、PS4平台或启用旁白功能的触控设备）。

* *多人游戏**
* 现在从添加好友界面返回游戏后邀请界面会正确刷新。

* *角色创建器**
* 修复了应用程序脱离上下文时对角色创建器的更改会丢失的漏洞。
* 修复了从“角色创建器”切换至“经典皮肤”后，会使用经典皮肤而不是自己创建的皮肤的漏洞。
* 如果打开更衣室时没有有效角色，则会创建一个新角色。</onlyinclude>
