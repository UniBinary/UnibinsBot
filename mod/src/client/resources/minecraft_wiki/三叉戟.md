* *三叉戟（Trident）**是一种可投射物品，能够用于近战攻击或投掷来造成多种效果。

# 生成

持有三叉戟的[溺尸](溺尸.md)可以无限地发射三叉戟，且其持有的三叉戟不会被消耗。由溺尸发射的三叉戟不能被回收。

[玩家](玩家.md)可以掷出三叉戟。

# 获取
掷出的三叉戟在一些情况下可以被[回收](#回收.md)进玩家的物品栏。

# = 溺尸 =
溺尸自然生成时有6.25%的概率持有随机[耐久度](物品耐久#掉落物耐久.md)的三叉戟，这些手持三叉戟的溺尸有或的概率掉落三叉戟，每级[抢夺](抢夺.md)魔咒可以增加1%的概率（即抢夺III为或）。

# 用途
三叉戟是一种近战和远战均可使用的武器，与铁质工具有相同的耐久度，每造成一次近战伤害或每投掷一次都会减少1点耐久度。只有或点耐久度的三叉戟无法被投掷。

# = 挖掘工具 =

三叉戟是一种挖掘工具，每次成功挖掘了任何硬度不为0的方块会消耗2耐久度。

类似[剑](剑.md)，在[创造模式](创造模式.md)中，三叉戟虽然能够挖掘方块，但无法破坏方块，挖掘方块时<ref></ref>或。

# = 近战攻击 =
三叉戟每成功进行一次[近战攻击](近战攻击.md)会减少1点耐久度。

# == Java版 ==
三叉戟的攻击速度是1.1，需要0.95秒来[恢复](近战攻击#攻击冷却.md)。

# == 基岩版 ==
三叉戟没有攻击冷却。

# = 溺尸 =

持有三叉戟的溺尸每1.5秒向攻击目标投掷一次三叉戟，对被命中的实体造成伤害。溺尸投掷三叉戟时不会消耗掉持有的三叉戟，可以无限投掷，且其投掷的三叉戟不能被回收。

溺尸持有的三叉戟可能是附魔的，但溺尸投掷的三叉戟是没有魔咒的。<ref></ref>

[村民](村民.md)被溺尸用三叉戟刺死后也可能会变成[僵尸村民](僵尸村民.md)。在简单难度下村民转化为僵尸村民的概率为0%，在普通难度下为50%，在困难难度下为100%。

溺尸可以使用三叉戟近战攻击距离其3格内的目标，每次对目标造成伤害。

# = 魔咒 =
三叉戟能被附加以下[魔咒](魔咒.md)：

# == 穿刺 ==

具有穿刺魔咒的三叉戟会对或造成更多的近战及投掷伤害。

# == 激流 ==

具有激流魔咒的三叉戟不能被玩家投掷出。取而代之的是，若玩家身处[水](水.md)中或[雨](雨.md)中，按住键后会将玩家自身向该方向发射出去，该效果将完全取代并取消三叉戟的默认投掷行为；若不在水中或雨中尝试则不会有任何效果。

具有激流魔咒的三叉戟每投掷一次会损失1点耐久度。

推进中的玩家撞击生物时会自动对其执行一次近战攻击。近战攻击忽略攻击者的[属性](属性.md)和[状态效果](状态效果.md)造成伤害，主手物品中只有与战利品表相关的魔咒会生效，且不消耗主手物品耐久。与玩家主动进行的近战攻击无异：玩家的主手物品决定了近战攻击的伤害，主手物品会因为进行近战攻击而消耗耐久度，主手物品的魔咒会生效，且玩家有机会通过该自动的近战攻击造成[暴击](近战攻击#暴击.md)。

三叉戟投出后还会对玩家旁边的生物造成“溅射伤害”。

使用带有激流魔咒的三叉戟还可以大大推进[鞘翅](鞘翅.md)滑翔的速率，且不会打断滑翔过程。

# == 忠诚 ==

具有忠诚魔咒的三叉戟被投出并插在了方块上后，会在数秒后回到投掷者身边，并可以被回收。忠诚魔咒等级越高，用时越短。

当具有忠诚魔咒的三叉戟被投出并正在返回投掷者身边，如果投掷者失踪，如投掷者死亡、进入旁观模式、进入其他维度或退出世界，三叉戟会成为物品掉落在地上。

在返回状态下的三叉戟将会被投掷该三叉戟的生物吸引，且这个过程中三叉戟会穿透方块。投掷者接触到该三叉戟时即可将其回收。若玩家物品栏已满，那么返回的三叉戟就会在玩家身边盘旋，直到玩家的物品栏有空余位置可供玩家捡起。多个三叉戟可以如此“排队”回到玩家的物品栏。

仅当三叉戟的投掷者仍然存在时，它才能返回。由发射器发射的三叉戟不会返回至任何地方，可以被常规的方式回收。

坠入虚空而没有命中方块表面的三叉戟最终会抵达临界高度并被摧毁，而不是从虚空中返回到投掷者身边；三叉戟在虚空中移动约15格后返回。

# == 引雷 ==

具有引雷魔咒的三叉戟可以引发[闪电](闪电.md)的生成。

# 行为
被掷出时，三叉戟会按照斜抛运动的规律飞行，类似于箭，但强度只有80%。不像多数弹射物，三叉戟不受水的阻力影响，这使三叉戟成为了优秀的水下远程武器。三叉戟会受到[气泡柱](气泡柱.md)的影响。

飞行中的三叉戟会受到爆炸的影响，增加或降低三叉戟的速度。

# = 命中实体 =
三叉戟命中实体会造成伤害和击退。不像箭，三叉戟不会在命中生物后消失，而是被弹回一小段距离并继续向下坠落。

三叉戟在被捡起之前只会伤害一个实体一次。三叉戟只要在伤害下一个实体之前接触了固体方块，就可以伤害多个实体。

[末影人](末影人.md)、外壳关闭的[潜影贝](潜影贝.md)、、生命值低于一半的[凋灵](凋灵.md)、处于创造模式的[玩家](玩家.md)和不能被三叉戟命中，三叉戟会被这些实体弹开并失去速度落到地面上。

三叉戟对实体造成弹射物伤害，可以被[弹射物保护](弹射物保护.md)魔咒防护。三叉戟上提供[魔咒攻击力](近战攻击#魔咒攻击力.md)的魔咒（包括[锋利](锋利.md)、[亡灵杀手](亡灵杀手.md)、[节肢杀手](节肢杀手.md)、[穿刺](穿刺.md)）会增加三叉戟造成的弹射物伤害。

[盾牌](盾牌.md)在被使用时可以阻挡其有效角度内来袭的三叉戟。

# = 击中方块 =
三叉戟在击中方块后会插在方块上，摇晃，接着开始计时后消失<ref></ref>|je}}，再次移动时计时会被重置为0。三叉戟的飞行距离与入射角度决定三叉戟射入物体的深度。当三叉戟射中方块的侧面时，三叉戟的尾部会相比预计轨迹更翘起一些。

三叉戟可以触发其击中的[标靶](标靶.md)，可以敲响[钟](钟.md)。

三叉戟可以激活[木质按钮](木质按钮.md)、[木质压力板](木质压力板.md)、[轻质测重压力板](轻质测重压力板.md)、[重质测重压力板](重质测重压力板.md)以及[绊线](绊线.md)。当三叉戟穿过这些方块时，这些开关会保持开启状态。如果三叉戟因为命中了方块而停止运动，那么被三叉戟钉住的开关一直会保持激活状态，直至三叉戟消失或被回收。其他开关则不受三叉戟的影响。由于这些方块不具有碰撞箱，三叉戟无法插在这些方块上，但可以插在临近的方块上来保持与开关相交，甚至同时激活多个开关。

三叉戟会不受阻碍地穿过并破坏[紫颂花](紫颂花.md)或[滴水石锥](滴水石锥.md)，使其掉落为物品。

若三叉戟所射入的方块的碰撞模型发生了变化（如开启或关闭[门](门.md)，[树叶](树叶.md)枯萎，挖掘其依附的方块），则三叉戟会回到未插入方块的状态并开始垂直掉落。

三叉戟在击中方块后再次击中方块时会播放箭的音效。<ref></ref>

# = 着火 =
三叉戟在穿过[火](火.md)或[熔岩](熔岩.md)会着火，穿过[雨](雨.md)或[水](水.md)时会熄灭。[末影龙](末影龙.md)在栖息时会使其反射的三叉戟着火。

着火的三叉戟会不受阻碍地穿过[TNT](TNT.md)并使其被点燃，可以点燃熄灭的[营火](营火.md)，可以破坏其穿过的[细雪](细雪.md)。着火的三叉戟会点燃其命中的实体。

# = 回收 =
三叉戟的实体数据<code>pickup</code>控制三叉戟会如何被回收。

* 由[溺尸](溺尸.md)投掷的三叉戟无法被回收。
* [创造模式](创造模式.md)玩家投掷的三叉戟不能被生存模式的玩家回收。创造模式的玩家可以回收这些三叉戟，但不会增加物品栏内三叉戟的数量。
* 和由[生存模式](生存模式.md)下的玩家投掷的三叉戟可以被回收。

三叉戟只有在击中方块且停止摇晃后才可以被回收；飞行中的三叉戟接触实体会命中或被弹开，而不能被回收。

可以回收的三叉戟在玩家靠近（且玩家物品栏仍然可以装下对应物品）时，会飞向玩家并进入其物品栏，就像拾取[物品](物品（实体）.md)一样。

玩家投掷出的三叉戟正常情况下只能被投掷的玩家回收。

# 你知道吗
* 三叉戟的音效是音效师[Samuel Åberg](Samuel Åberg.md)用金属尺录制的。<ref></ref>
* 创造模式下[剑](剑.md)的部分魔咒（[锋利](锋利.md)、[亡灵杀手](亡灵杀手.md)和[节肢杀手](节肢杀手.md)）也可以附到三叉戟上。这些魔咒会对相应的生物起作用，包括近战攻击和投掷出去命中[末影龙](末影龙.md)以外的<ref></ref>生物。同样的，拥有[穿刺](穿刺.md)魔咒的任何物品也可以对相应的生物起作用。
* 投掷三叉戟的冷却速度比[弓](弓.md)和未附魔[快速装填](快速装填.md)的[弩](弩.md)要快。
* 在[Java版1.14](Java版1.14.md)前，附有忠诚魔咒的三叉戟通过下界传送门与末地传送门后无法返回，在玩家进入对应维度后会重新回到玩家手中。
