# 灵魂灯笼

*页面ID: 161938* | *来源: Minecraft Wiki*

* *灵魂灯笼（Soul Lantern）**是一种由[灵魂火把](灵魂火把.md)合成的可以提供照明的固体方块。

# 生成
# = 自然生成 =
灵魂灯笼会悬挂在[远古城市](远古城市.md)的入口石柱和城墙上。

# 获取
# = 合成 =

# 破坏
挖掘灵魂灯笼的合适工具是镐。

灵魂灯笼被破坏后会掉落自身。

# 用途
# = 放置 =
灵魂灯笼必须放在方块[中心完整](方块支撑形状.md)上表面的上方或中心完整下表面的下方，但有些情况需要通过来放置。依附的方块发生变化且不再能够依附时，灵魂灯笼会被破坏并掉落。

垂直的[铁链](铁链.md)和[铜链](铜链.md)能在视觉上和依附在其下方的灵魂灯笼相互连接。

# = 光源 =
灵魂灯笼会发出光照等级为10级的[光](光.md)。由于亮度低于12，它不能融化雪和冰。

# = 猪灵 =
灵魂灯笼可以驱离非战斗状态的[猪灵](猪灵.md)。
