# Chromebook更新

*页面ID: 126022* | *来源: Minecraft Wiki*

[缩略图|Chromebook更新的图像](File:BuzzyBeesEdu.png.md)
* *Chromebook更新（Chromebook Release）**是的一次主要更新，其正式版[1.14.31](教育版1.14.31.md)发布于2020年8月7日。<ref></ref><ref name="1.14.31"></ref>此次更新加入了对Chromebook的支持，并引入了基岩版[1.13.0](基岩版1.13.0.md)和[1.14.0](基岩版1.14.0.md)（[嗡嗡蜂群](嗡嗡蜂群.md)）的特性。<ref></ref>

# 重要特性

* 加入了[基岩版1.13.0](基岩版1.13.0.md)和[1.14.0](基岩版1.14.0.md)的特性。

* *生物**
* 为[NPC](NPC.md)新增了5种以蜜蜂为主题的NPC皮肤。
[thumb|400px|所有5种以蜜蜂为主题的NPC皮肤](File:NPCBeeKeepers.png.md)

* *常规**
* 加入了对Chromebook的支持。

# 跟进版本
* [1.14.32](教育版1.14.32.md)发布以修复一些漏洞。
