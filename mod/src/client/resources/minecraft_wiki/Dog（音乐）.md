# Dog（音乐）

*页面ID: 169591* | *来源: Minecraft Wiki*

* *Dog**是一首由[C418](C418.md)创作的音乐。

# 播放条件
Dog会在[音乐唱片cat](音乐唱片cat.md)淡出后播放。

# 描述
Dog与[Cat](音乐唱片cat.md)使用相同的旋律，但与之不同的是Dog更偏向于电子音乐，其从Cat结束的地方继续演奏。
