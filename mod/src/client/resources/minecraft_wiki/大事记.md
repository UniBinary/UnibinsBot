# 大事记

此页面用来追溯所有与[Minecraft](Minecraft.md)、[Mojang Studios](Mojang Studios.md)及其员工有关的大事，以及不同版本上的简略的[版本记录](版本记录.md)。

# 2009年
# = 4月 =
* **29日** — [无尽矿工（Infiniminer）](Infiniminer.md)发布<ref>[“Infiniminer”](http://thesiteformerlyknownas.zachtronicsindustries.com/infiniminer/)</ref>，它是一个由[Zachtronics Industries](http://www.zachtronicsindustries.com/)（2011年最受欢迎的解谜游戏[《太空化学（*SpaceChem*）》](wikipedia:SpaceChem.md)的作者）制作的游戏，这款游戏激发了Notch创造Minecraft的灵感。它进行了常规更新，不到一个月之后就变为开源软件。<ref>[“Apparently I’m now in charge of an open source project.”](http://thesiteformerlyknownas.zachtronicsindustries.com/apparently-im-now-in-charge-of-an-open-source-project/)</ref>

# = 5月 — Minecraft的诞生 =
* **10日** — Notch以放弃的[RubyDung](RubyDung.md)和《无尽矿工》的代码作为基础，开始开发名为“Cave Game”的游戏，
* **13日** — Java版：[第一个关于“Cave Game”的视频](http://www.youtube.com/watch?v=F9t3FREAZ-k)被发布。[方块](方块.md)放置，第一个[生物](生物.md)（[人类](生物（已移除实体）.md)）和物理引擎被创建（[Cave game技术测试](Cave game技术测试.md)）。
* **14日** — Java版：“Cave Game”被重命名为“Minecraft: Order of the Stone”，根据玩家[RinkuHero](http://tig.wikia.com/wiki/RinkuHero)在[独立游戏wiki](http://tig.wikia.com/wiki/The_Independent_Games_Wiki)的IRC与Notch的谈话，“Minecraft”的命名模仿了实时策略游戏《[](wzh:星际争霸.md)》（*StarCraft*）（[Java版pre-Classic](Java版pre-Classic.md)）。<ref></ref>
* **16日** — Java版：在TIGSource成员间进行了早期内测（[Java版Classic 0.0.2a](Java版Classic 0.0.2a.md)-[0.0.9a](Java版Classic 0.0.9a.md)）。<ref></ref>
* **17日** — **游戏第一次发布（[Java版Classic 0.0.11a](Java版Classic 0.0.11a.md)）。**游戏名被缩短为“Minecraft”。<ref></ref>
* **21日** — 开放了账号注册。<ref></ref>
* **24日** — 官方的Minecraft论坛开放。<ref></ref>

# = 6月 =
* **1日** — Java版：首次[多人游戏](多人游戏.md)测试（[Java版Classic 0.0.15a](Java版Classic 0.0.15a.md)）。Notch在Jalbum找了个新工作。<ref></ref>
* **8日** — Java版：多人游戏正式发布（[Java版Classic 0.0.16a](Java版Classic 0.0.16a.md)）。
* **14日** — Java版：自定义[皮肤](皮肤.md)发布（[Java版Classic 0.0.18a](Java版Classic 0.0.18a.md)）。

# = 8月 =
* **4日** — Java版：首次展示[生存模式](生存模式.md)元素。
* **18日** — Java版：展示[生命](生命.md)值系统。

# = 9月 =
* **1日** — **生存测试开始（[Java版Classic 0.24 SURVIVAL TEST](Java版Classic 0.24 SURVIVAL TEST.md)）。**

# = 10月 =
* **9日** — 现在玩家可以修改账户密码。<ref></ref>

# = 12月 =
* **22日** — [Hayden Scott-Baron](Hayden Scott-Baron.md)成为了Minecraft的美工。<ref></ref>
* **23日** — Java版：**进入了[Indev开发阶段](Java版Indev.md)（[Java版Indev 0.31](Java版Indev 0.31.md)）**（需要用€5.00购买付费账号）并加入[火把](火把.md)和[动态光照](光.md)。

# 2010年
# = 1月 =
* **13日** — Java版：加入了有限的[水](水.md)（[Indev 0.31-20100113-2015](Java版Indev 0.31 20100113-2015.md)）。
* **13日** — Minecraft的注册用户超过100,000个。<ref></ref>
* **21日** — Minecraft现在可以被赠予非付费用户。<ref></ref>
* **29日** — Java版：加入了[合成](合成.md)系统（[Indev 0.31-20100129-1447](Java版Indev 0.31 20100129-1447.md)）。

# = 2月 =
* **5日** — [Hayden Scott-Baron](Hayden Scott-Baron.md)离开Minecraft的开发团队。<ref></ref>
* **27日** — **Java版Minecraft进入了[Infdev开发阶段](Java版Infdev.md)，并加入了无限世界。**

# = 6月 =
* **1日** — 在辞去Jalbum的工作的几星期后，Notch开始全身心地开发Minecraft。
* **17日** — Minecraft的销量超过20,000。<ref></ref>
* **18日** — Java版：秘密周五更新1（[Java版Infdev 20100618](Java版Infdev 20100618.md)）发布。加入了[矿车](矿车.md)系统。
* **25日** — Java版：秘密周五更新2（[Java版Infdev 20100625-1917](Java版Infdev 20100625-1917.md)）发布。加入了[地牢](地牢.md)。
* **29日** — Java版：玩家现在可以在[独立客户端](独立客户端.md)上进行游戏。

# = 7月 =
* **2日** — Java版：**进入了[Alpha开发阶段](Java版Alpha.md)（[Java版Alpha v1.0.1](Java版Alpha v1.0.1.md)），价格从€5.00涨至€10.00。**
* **3日** — Java版：秘密周五更新3（[Java版Alpha v1.0.1](Java版Alpha v1.0.1.md)）发布。加入了[红石](红石.md)。
* **9日** — Java版：秘密周五更新4（[Java版Alpha v1.0.4](Java版Alpha v1.0.4.md)）发布。加入了“[冬天模式](冬天模式.md)”。
* **16日** — Java版：秘密周五更新5（[Java版Alpha v1.0.6](Java版Alpha v1.0.6.md)）发布。加入了[船](船.md)和[大树](树.md)。
* **22日** — Java版：第一次在互联网上测试多人的生存模式。<ref></ref>
* **23日** — Java版：秘密周五更新6（[Java版Alpha v1.0.11](Java版Alpha v1.0.11.md)）发布。加入了[砖块](砖块.md)和[史莱姆](史莱姆.md)。
* **30日** — Java版：秘密周五更新7（[Java版Alpha v1.0.14](Java版Alpha v1.0.14.md)）发布。加入了[鸡](鸡.md)和[音乐唱片](音乐唱片.md)。

# = 8月 =
* **4日** — Java版：**第一个版本的多人生存游戏（[Java版Alpha v1.0.15](Java版Alpha v1.0.15.md)）。**
* **19日** – 最初的[Herobrine](Herobrine.md) creepypasta被创建。
* **20日** — Java版：秘密周五更新8（[Java版Alpha v1.0.17](Java版Alpha v1.0.17.md)）发布。加入了[栅栏](栅栏.md)。
* **30日** — Notch、JahKob和Carl Manneh得到了一次由VALVe公司提供的前往华盛顿的就业旅行机会。<ref></ref>
* **30日** — 原版[Herobrine](Herobrine.md)的Creepypasta被创作出来。
* **31日** — [MinecraftCon](MineCon.md)，一次由50名以上自发聚集的爱好者参与的聚会在Notch的号召后于华盛顿州的贝尔维尤市举行。<ref></ref>

# = 9月 =
* **2日** — Notch结束美国之旅。
* **10日** — Java版：秘密周五更新9（[Java版Alpha v1.1.0](Java版Alpha v1.1.0.md)）发布，加入了[指南针](指南针.md)。
* **13日** — [Daniel "Kappische" Kaplan](Daniel Kaplan.md)加入Mojang团队。<ref></ref>
* **18日** — Java版：秘密周五更新10（[Java版Alpha v1.1.1](Java版Alpha v1.1.1.md)）发布。加入了[潜行](潜行.md)。理论上Minecraft在周末可以免费玩，因为登录服务无法正常运行。
* **23日** — [Classic](Java版Classic.md)在[Minecraft.net](http://www.minecraft.net/)上再次变得可玩。<ref></ref>

# = 10月 =
* **16日** — [Mojang AB](Mojang AB.md)创立。<ref></ref>
* **30日** — Java版：[Alpha v1.2.0](Java版Alpha v1.2.0.md)“[万圣节更新](万圣节更新.md)”发布。加入了[下界](下界.md)。

# = 12月 =
* **1日** — [Jens "Jeb" Bergensten](Jens Bergensten.md) 和["Junkboy"](Markus Toivonen.md) 加入了Mojang团队。<ref></ref>
* **10日** – 最初的[Herobrine](Herobrine.md)模组被创建。
* **16日** — 转正系统修改：现在使用[礼品码](礼品码.md)转正。<ref></ref>
* **20日** — **Java版Minecraft进入了[Beta开发阶段](Java版Beta.md)（[Java版Beta 1.0](Java版Beta 1.0.md)），价格从€10.00涨至€15.00。**
* **22日** — Java版：[Beta 1.1](Java版Beta 1.1.md)发布。

# 2011年
2011年一共发布了4个[快照](快照.md)。

# = 1月 =
* **3日** — [Tobias Möllstam](Tobias Möllstam.md)和[Carl Manneh](Carl Manneh.md)加入Mojang团队。<ref></ref>
* **12日** — Minecraft销量超过一百万。<ref></ref>
* **13日** — Java版：[Beta 1.2](Java版Beta 1.2.md)发布。

# = 2月 =
* **21日** — Java版：[客户端](独立客户端.md)/[启动器](启动器.md)现在可下载。需要手动更新。
* **22日** — Java版：[Beta 1.3](Java版Beta 1.3.md)发布。

# = 3月 =
* **2日** — [《卷轴》](http://scrolls.com/)，Mojang的第二款游戏，在“Notch之语”宣布<ref></ref>中被提及。
* **4日** — “Minecraft — Volume Alpha”，由[C418](C418.md)所创作的游戏原声碟发布。
* **31日** — Java版：[Beta 1.4](Java版Beta 1.4.md)发布。

# = 4月 =
* **19日** — Java版：[Beta 1.5](Java版Beta 1.5.md)发布。

# = 5月 =
* **25日** — [Kappische](Kappische.md)在Mojang的官网中曝光[携带版](携带版.md)的消息。<ref>[**Pocket Edition revealed:** http://www.mojang.com/2011/05/minecraft-pocket-edition/](http://www.mojang.com/2011/05/minecraft-pocket-edition/)</ref>
* **26日** — Java版：[Beta 1.6](Java版Beta 1.6.md)发布。

# = 6月 =
* **1日** — [携带版](携带版.md)首次在[一个YouTube视频](http://www.youtube.com/watch?v=AmhZkRBQbig)中出现。
* **6日** — 微软[在E3 conference](http://www.youtube.com/watch?v=59OvZwRdLe0)上披露[Xbox 360版](Xbox 360版.md)的消息。
* **30日** — Java版：[Beta 1.7](Java版Beta 1.7.md)发布。

# = 7月 =
* **1日** — Minecraft的注册用户超过一千万。<ref></ref>
* **30日** — 30-31日，Minecraft T恤衫作为DICE和Mojang“友邻交互推广”的一种形式在[Battlefield Heroes](http://www.battlefieldheroes.com/en/createHeroSignup?)上架。<ref></ref>

# = 8月 =
* **5日** — Notch收到一封来自Bethesda公司的15页的信，信中说如果他不把他下一个游戏的名字“卷轴”（根据Bethesda所言，这个名字和上古卷轴太相近）改掉就要对他提出诉讼。在此之前，Notch已经被Bethesda的律师就此问题警告过，并且提出一个妥协方案，即他绝不会在“卷轴”前加上任何字。<ref></ref>
* **8日** — [Henrik "Carnalizer" Pettersson](Henrik Pettersson.md)加入Mojang团队。<ref></ref>
* **14日** — 在Ez与Notch的婚礼上，Minecraft为所有在8月13日和14日购买Minecraft的用户提供一个额外的副本。<ref></ref>
* **16日** — 携带版：**官方发布[0.1.0](携带版0.1.0.md)（Xperia PLAY独占）。**
* **16日** — *[Cobalt](Mojang Studios#Cobalt.md)*公布。

# = 9月 =
* **5日** — “[Project Rex Kwon Do](Project Rex Kwon Do.md)”公布。
* **14日** — Java版：[Beta 1.8](Java版Beta 1.8.md)“[冒险更新](冒险更新.md)”发布。

# = 11月 =
* **5日** — [MinecraftEdu](MinecraftEdu.md)首次发布。
* **14日** — Java版：[Beta音效更新](Beta音效更新.md)发布。
* **17日** — 携带版：第一款iOS携带版发布（[0.1.2](携带版0.1.2.md)）。
* **18日** — [MINECON 2011](MINECON 2011.md)在内华达州拉斯维加斯市的曼德勒海湾举行。来自24个国家的，超过4500人加入了此活动。就在同一天，**官方发布[Java版1.0.0](Java版1.0.0.md)，价格为€20.00。**
* **24日** — Java版：第一个[快照](快照.md)发布了（[11w47a](11w47a.md)）。这标志着[每周快照](每周快照.md)发布的开始。

# = 12月 =
* **1日** — Jeb成为Minecraft的领头开发者。<ref></ref>
* **6日** — Notch第一次提到使[Minecraft主题乐高套装](乐高Minecraft.md)成为[LEGO CUUSOO 计划](wp:Lego Cuusoo.md)的一部分的可能性。<ref></ref>
* **28日** — [Jon Kågström](Jon Kågström.md)被Mojang雇用。

# 2012年
2012年一共发布了46个快照。

# = 1月 =
* **12日** — Java版：[1.1](Java版1.1.md)发布。
* **18日** — 作为世界范围内对[SOPA](wzh:禁止网络盗版法案.md)的抗议活动的一部分，Mojang将自己的所有网站封锁一整天。<ref></ref>
* **24日** — 乐高声明Minecraft乐高计划已经得到了多于10000个的所需投票。<ref>[**LEGO Minecraft passes LEGO review:** http://legocuusoo.posterous.com/minecraft-lego-cuusoo-project-passes-lego-rev-54968](http://legocuusoo.posterous.com/minecraft-lego-cuusoo-project-passes-lego-rev-54968)</ref>

# = 2月 =
* **11日** — 携带版：[0.2.0](携带版0.2.0.md)在Android发布。
* **15日** — 乐高曝光第一套Minecraft乐高套装的最终设计。<ref>[**LEGO Minecraft design revealed:** http://legocuusoo.posterous.com/announcing-lego-minecraft-micro-world-the-thi](http://legocuusoo.posterous.com/announcing-lego-minecraft-micro-world-the-thi)</ref>
* **17日** — 携带版：[0.2.0](携带版0.2.0.md)在iOS发布。
* **18日** — “[Catacomb Snatch](http://catacombsnatch.net/)”，由Mojang在一个周末内制作的游戏被作为一个慈善计划的一部分释出。
* **28日** — [Bukkit](Bukkit.md)团队（由[Nathan "Dinnerbone" Adams](Nathan Adams.md)、[Warren "EvilSeph" Loo](Warren Loo.md)、[Erik "Grum" Broes](Erik Broes.md)与[Nathan "Tahg" Gilbert](Nathan Gilbert.md)组成）为更进一步地加强Minecraft的服务软件正式加入Mojang，同时也为API的制作提供帮助。

# = 3月 =
* **1日** — Java版：[1.2.1](Java版1.2.1.md)发布（1.2被以实际的目的为由跳过）。
* **12日** — “上古卷轴VS卷轴”的诉讼有了结果：Mojang可以将他们的游戏命名为“卷轴”，但不允许以后对这个名字在其他方面的使用。<ref>[**Outcome of the Scrolls lawsuit:** http://www.joystiq.com/2012/03/12/mojang-cant-use-scrolls-in-any-sequels-to-scrolls-lawsuit/](http://www.joystiq.com/2012/03/12/mojang-cant-use-scrolls-in-any-sequels-to-scrolls-lawsuit/)</ref>

# = 4月 =
* **4日**— Java版：[1.2.5](Java版1.2.5.md)发布。
* **23日** — 携带版：[0.3.0](携带版0.3.0.md)在iOS上发布。
* **24日** — 携带版：[0.3.0](携带版0.3.0.md)在Android上发布。

# = 5月 =
* **9日** — **官方发布[Xbox 360版TU1](Xbox 360版TU1.md)。**

# = 6月 =
* **1日** — “Micro World”，第一款Minecraft乐高套装发布（很巧合地是在Notch的生日），并可在乐高在线商店购买。<ref>[**LEGO Minecraft on LEGO store:** http://shop.lego.com/en-US/Minecraft-21102](http://shop.lego.com/en-US/Minecraft-21102)</ref>

# = 7月 =
* **13日** — 原主机版：[Xbox 360版TU3](Xbox 360版TU3.md)发布。
* **16日** — 原主机版：[皮肤包1](皮肤包#皮肤包 1（Skin Pack 1）.md)发布。包含45款皮肤，“光晕”、“神鬼寓言”、“战争机器”的皮肤包括在内。
* **18日** — 原主机版：[沙尘：幸福的尾巴促销皮肤包](皮肤包#沙尘：幸福的尾巴促销皮肤包（Summer Of Arcade Promotional Skin Pack）.md)于2012年8月22日上架。包括由其他商业游戏如“职业滑板高手”和“死光”提供灵感的皮肤等在内的15款皮肤。

# = 8月 =
* **1日** — Java版：[1.3.1](Java版1.3.1.md)发布（1.3被以实际的目的为由跳过）。
* **2日** — 官方在一个宣传视频中公布[MINECON 2012](MINECON 2012.md)将会于11月24至25日在巴黎迪斯尼乐园举行。
* **15日** — Notch和Ez离婚。<ref></ref><ref></ref>
* **24日** — 原主机版：[皮肤包2](皮肤包#皮肤包 2（Skin Pack 2）.md)发布。加入了45款皮肤，“求生之路”、“完美黑暗”和“战争机器”的皮肤包含在内。

# = 9月 =
* **6日** — 携带版：[0.4.0](携带版0.4.0.md)在iOS和Android上发布。
* **13日** — 携带版：Fire的首个携带版版本[0.4.0](携带版0.4.0.md)发布。

# = 10月 =
* **16日** — 原主机版：发布。
* **17日** — 原主机版：[皮肤包3](皮肤包#皮肤包 3（Skin Pack 3）.md)发布。加入了45款皮肤，“半条命”、“传送门”和“求生之路”的皮肤包含在内。
* **24日** — Mojang启用了[Minecraft漏洞追踪器](https://bugs.mojang.com/browse/)，这是一个在线工具，简化了游戏玩家与开发商之间关于游戏漏洞的沟通。
* **25日** — Java版：[1.4.2](Java版1.4.2.md)“[骇人更新](骇人更新.md)”发布（1.4及1.4.1被以实际的目的为由跳过）。
* **26日** — 原主机版：[万圣节皮肤包](皮肤包#万圣节皮肤包（Halloween Skin Pack）.md)上架。它包括55个万圣节主题皮肤，包括7个披风。

* **15日** — 携带版：[0.5.0](携带版0.5.0.md)在iOS和Android上发布。
* **24日** — [MINECON 2012](MINECON 2012.md)在法国巴黎的迪士尼举行。
* **25日** — MINECON 2012的第二天。MINECON2012披风发布。[Java版1.5](Java版1.5.md)“红石更新”公布。

# = 12月 =
* **19日** — 原主机版：发布。[节日皮肤包](皮肤包#节日皮肤包（Festive Skin Pack）.md)包括24个圣诞主题皮肤。
* **20日** — PI：[树莓派版](树莓派版.md)Alpha 0.1非官方发布。

# 2013年
