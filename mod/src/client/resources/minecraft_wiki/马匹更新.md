# 马匹更新

*页面ID: 10269* | *来源: Minecraft Wiki*

[缩略图|400px|海报（与更新一同发布）<ref>https://mojang.com/2013/07/minecraft-the-horse-update/</ref>](File:Horse Update Artwork.png.md)

[缩略图|400px|完整版的马匹更新主视觉图](File:Horse Update Wallpaper.jpg.md)

* *马匹更新（Horse Update）**是[Java版](Java版.md)的一次主要更新，发布于2013年7月1日。<ref>https://mojang.com/2013/06/minecraft-1-6-pre-release/</ref>该更新的官方名称仅仅在1.6版本发布前一周才在Minecraft更新Tumblr（在启动器里看到的网页）上宣布。此更新添加了许多特性，例如[马](马.md)、[拴绳](拴绳.md)、[煤炭块](煤炭块.md)、[地毯](地毯.md)、[资源包](资源包.md)以及新的[启动器](启动器.md)。

此次更新的开发始于[13w16a](13w16a.md)，其发布于2013年4月18日。

# 重要特性

启用了新的[启动器](启动器.md)，更新改进了LWJGL代码和自动更新的能力。

该更新主要涵盖[马](马.md)、[驴](驴.md)和[骡](骡.md)这三种可驯服的生物，能够被骑和繁殖，马以多种毛色存在。

能够用[干草捆](干草捆.md)和其他食物喂养马，用[鞍](鞍.md)和[马铠](马铠.md)来装备马以骑行并保护它们。驴和骡能用鞍来骑上它们，同时可载有一个[箱子](箱子.md)来储存物品。[拴绳](拴绳.md)能被用来拉动任何生物行走或把任何生物拴在[栅栏](栅栏.md)上。[命名牌](命名牌.md)允许命名除[末影龙](末影龙.md)之外的任何生物，此举可防止任何已被命名的生物消失。[金苹果](金苹果.md)的合成配方由8个[金粒](金粒.md)改为8个[金锭](金锭.md)，同时为玩家带来一种新的状态效果——“[伤害吸收](伤害吸收.md)”。

新增的[地毯](地毯.md)可以放置在任何方块上，并且可以在上面行走。[煤炭块](煤炭块.md)也被添加，能够用来压缩煤的贮存空间并提供比以往单个[煤炭](煤炭.md)更多的燃料。[硬化黏土](硬化黏土.md)也被添加了，能用16种可用的[颜色](颜色.md)装点成[染色黏土](染色黏土.md)方块，这样它们就可以避免像[羊毛](羊毛.md)被烧这样的事情了。

# 你知道吗
* 此版本后第三代启动器不再可用。
* 由于新的启动器，自该版本开始游戏能够自动更新。
* 在更新海报上，可以看见未使用的[普通村民](村民.md)以及一个身穿蓝色长袍的村民在一个[铁傀儡](铁傀儡.md)旁。
* 在海报中，Mojang被错误命名为“Notch Development AB”（Notch开发责任有限公司）。
