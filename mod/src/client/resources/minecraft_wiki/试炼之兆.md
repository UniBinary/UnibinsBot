# 试炼之兆

*页面ID: 115200* | *来源: Minecraft Wiki*

* *试炼之兆（Trial Omen）**是带有[不祥之兆](不祥之兆.md)的玩家接近[试炼刷怪笼](试炼刷怪笼.md)时获得的[状态效果](状态效果.md)，可开启不祥试炼。

# 效果
玩家获得试炼之兆时，会播放特殊的音效。音效是<code>event.mob_effect.trial_omen</code>，其字幕为“”；音效是<code>apply_effect.trial_omen</code>。

获得此状态效果的玩家会持续被<code>trial_omen</code>[粒子](粒子.md)包围。

当处于非和平[难度](难度.md)且拥有此效果的[生存模式](生存模式.md)或[冒险模式](冒险模式.md)玩家进入非未激活（若在冷却中，则需其上一次激活不为不祥状态）、非不祥的[试炼刷怪笼](试炼刷怪笼.md)探测范围内时，它会变为[不祥试炼刷怪笼](不祥试炼刷怪笼.md)。

# 来源
没有试炼之兆的玩家在非不祥的试炼刷怪笼探测范围内时，其身上的不祥之兆效果就会变成试炼之兆，持续时间为15分钟×不祥之兆的效果等级。
