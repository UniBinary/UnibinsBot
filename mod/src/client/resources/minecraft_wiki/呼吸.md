# 呼吸

*页面ID: 104515* | *来源: Minecraft Wiki*

[thumb|在Java版中，一个玩家正在门中呼吸](File:Breath of the Door.png.md)
* *呼吸（Breathing）**以维持**氧气值（Oxygen/Air）**是[生物](生物.md)生存的需求之一，生物若长时间不能呼吸则会**溺水（Drown）**或**脱水（Dryout）**而持续受到[伤害](伤害.md)。

# 监测
[thumb|氧气条](File:Bubbles.gif.md)
氧气值的测量和监控基于一排气泡图标，组成了玩家的氧气条。

氧气条位于[平视显示器](平视显示器.md)之上，显示在饥饿条的上方，，其中包含十个气泡图标，消耗时从左到右减少，恢复时从右到左增加。

每一个气泡表示至多氧气值，气泡的数量数值会向上取整。

氧气条只在氧气值被消耗或当前位置不能呼吸时显示。

随着氧气值的消耗，氧气条中的气泡会“破裂”并消失。气泡破裂时会发出音效并在原处留下深色的背景，当所有气泡全部破裂后氧气条会开始剧烈地抖动。氧气条中的所有气泡都消失即表示玩家的氧气值已经耗尽。

# 机制
所有生物都有一项基本数据**氧气值**（实体数据<code>Air</code>）。生物头部所处的方块决定了氧气值将被消耗还是恢复。

不同的生物需要在不同的方块中呼吸：
* 绝大多数生物在[水](水.md)（除了[气泡柱](气泡柱.md)）以外的方块中呼吸。
* [鳕鱼](鳕鱼.md)、[鲑鱼](鲑鱼.md)、[热带鱼](热带鱼.md)、[河豚](河豚.md)、[鱿鱼](鱿鱼.md)、[蝌蚪](蝌蚪.md)、[发光鱿鱼](发光鱿鱼.md)、[鹦鹉螺](鹦鹉螺.md)只能在水（除了气泡柱）中呼吸。[美西螈](美西螈.md)既可以在水（除了气泡柱）中呼吸，也可以在[雨](雨.md)中呼吸。
* [水下-{}-呼吸](水下呼吸（状态效果）.md)与[潮涌能量](潮涌能量.md)使生物总是可以呼吸。
* 生物在[窒息方块](窒息方块.md)中时不能呼吸。

绝大多数生物的氧气值上限是300，即最多可供其呼吸而不受到溺水或脱水伤害；[海豚](海豚.md)是4800；[美西螈](美西螈.md)是6000；；。

生物不能呼吸时，氧气值每刻减少1，并且受到多种因素影响：
* 生物的装备的[](水下呼吸（魔咒）.md)魔咒使氧气供应值在每刻有<code>-{}-*魔咒等级*/(*魔咒等级*+1)</code>的概率不会减少。
* 处于[创造模式](创造模式.md)或[旁观模式](旁观模式.md)的[玩家](玩家.md)的氧气值不会减少。
* [盔甲架](盔甲架.md)、[小恶魂](小恶魂.md)、[铁傀儡](铁傀儡.md)、[铜傀儡](铜傀儡.md)、[守卫者](守卫者.md)、[远古守卫者](远古守卫者.md)、、[青蛙](青蛙.md)、[海龟](海龟.md)和[亡灵生物](亡灵生物.md)的氧气值不会减少。

生物的氧气值为-20且此时不能呼吸时，在空气中呼吸的生物会溺水并受到溺水伤害，在水中呼吸的生物会脱水并受到脱水伤害，然后氧气值被设置为0。这相当于氧气值耗尽的生物每秒都会受到一次伤害，但第一次伤害会在氧气值耗尽后延迟至少1秒才会出现。除玩家以外的生物每0.5秒就会受到一次溺水伤害。生物的装备的[](水下呼吸（魔咒）.md)魔咒使每次伤害有<code>-{}-*魔咒等级*/(*魔咒等级*+1)</code>的概率被取消。

[美西螈](美西螈.md)、[青蛙](青蛙.md)、[守卫者](守卫者.md)、[远古守卫者](远古守卫者.md)、[海龟](海龟.md)、[发光鱿鱼](发光鱿鱼.md)、[鳕鱼](鳕鱼.md)、[河豚](河豚.md)、[鲑鱼](鲑鱼.md)、[鱿鱼](鱿鱼.md)、[热带鱼](热带鱼.md)、[蝌蚪](蝌蚪.md)、[鹦鹉螺](鹦鹉螺.md)、、[小恶魂](小恶魂.md)、[盔甲架](盔甲架.md)和[亡灵生物](亡灵生物.md)不能溺水。

生物受到溺水伤害时会在脚下生成气泡粒子。

除玩家的生物在消耗氧气值时会持续在全身附近产生大量气泡粒子。

当生物可以呼吸时，大多数生物的氧气值每刻增加4，而[鳕鱼](鳕鱼.md)、[鲑鱼](鲑鱼.md)、[热带鱼](热带鱼.md)、[河豚](河豚.md)、[鱿鱼](鱿鱼.md)、[发光鱿鱼](发光鱿鱼.md)、[海豚](海豚.md)、[美西螈](美西螈.md)、[蝌蚪](蝌蚪.md)、[鹦鹉螺](鹦鹉螺.md)、[僵尸鹦鹉螺](僵尸鹦鹉螺.md)以及的氧气值会立刻恢复到最大值。

[喷溅型水瓶](喷溅型水瓶.md)和[滞留型水瓶](滞留型水瓶.md)可以为[美西螈](美西螈.md)恢复1800氧气值。然而，滞留型水瓶产生的[区域效果云](区域效果云.md)没有此效果。

非生物[实体](实体.md)虽然也有氧气值数据，但氧气值不会减少和恢复，改变氧气值也不会有任何效果。

# = 防止溺水和脱水 =
绝大多数生物在寻路时都会避免自己被置入无法呼吸的环境，在无法呼吸时会主动寻找可以呼吸的位置。大多数生物都会在水中上浮来防止被淹没在水中，而水生生物会躲避气泡柱。[女巫](女巫.md)在水下会饮用[水肺药水](水肺药水.md)。

玩家可以通过寻找[气泡柱](气泡柱.md)或来在水下恢复氧气值。如果玩家装备了[海龟壳](海龟壳.md)，在可以呼吸的瞬间就会获得10秒的[水下呼吸](水下呼吸（状态效果）.md)效果，而提供的短暂空气就能再次提供这个效果。如果玩家正在骑乘鹦鹉螺或僵尸鹦鹉螺，玩家就会持续获得[鹦鹉螺之息](鹦鹉螺之息.md)效果。

[游戏规则](游戏规则.md)为<code>false</code>时，玩家免疫溺水伤害，但氧气值的消耗和恢复不受影响。

# 你知道吗
* 在[Java版1.20.3](Java版1.20.3.md)前，[盔甲架](盔甲架.md)需要呼吸空气并且会溺水，尽管盔甲架免疫溺水的伤害，但仍然会因为发生溺水而生成气泡粒子。<ref name="MC-78314" />
* 要受到溺水或脱水伤害，生物的氧气值必须等于-20。更改生物的实体数据将氧气值设置为比-20更低的值会使其氧气值持续下降，而不会造成伤害或使氧气值变为0。
* 一部分生物在水中氧气值不会下降，但不免疫溺水伤害。更改生物的实体数据将氧气值设置为-20可以使通常不会失去氧气值并因此溺水的生物（如[铁傀儡](铁傀儡.md)）在不能呼吸时受到一次溺水伤害。
