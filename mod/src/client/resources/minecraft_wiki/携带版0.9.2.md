* *v0.9.2 alpha**是的一次次要更新，改进了游戏性能，并修复了[v0.9.1 alpha](携带版Alpha 0.9.1.md)中的一些漏洞与崩溃。在iOS上，此次更新还包括[v0.9.1](携带版0.9.1.md)的更改。

# 新内容
# = 生物 =
* *[村民](村民.md)**
* 为iOS版加入了[村民](村民.md)的声音。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了16条闪烁标语。

# 更改
# = 方块 =
* *[菌丝体](菌丝体.md)**
* [菌丝体](菌丝体.md)现在会正确传播。

* *[刷怪笼](刷怪笼.md)**
* 现在更好地运作，延迟更少。

# = 生物 =
* *常规**
* 所有生物的生命值同步到Java版的数值。
* 游戏现在生成的生物更少，清除了旧的敌对生物。

* *[苦力怕](苦力怕.md)**
* [苦力怕](苦力怕.md)现在有正确的爆炸范围。

* *[蜘蛛](蜘蛛.md)**
* 视线不再穿过固体方块。

# = 世界生成 =
* *[要塞](要塞.md)**
* [要塞](要塞.md)的生成变得更普遍。

# = 常规 =
* *[设置](设置.md)**
* 限制世界大小的选项（仅支持低端设备）。
* 老设备在创建无限世界时会被警告。

* *图标**
* 更新了Mojang的徽标。
* 将应用图标回退为0.7.6的设计（没有较大白色覆盖）（仅iOS可见）。

* *优化**
* 减少滞后和内存消耗。

# 修复
* *修复了6个漏洞**
* 修复了发现要塞时会错误生成区块的问题。
* 修复了热带草原和沙漠中的草的颜色为彩色的问题。
* 修复了苦力怕的爆炸前摇时间不正确的问题。
* 修复了生物纹理不正确的问题。
* 修复了iOS上的触摸光圈大小不正确的问题。
* 修复了渲染区块时发生的崩溃。
