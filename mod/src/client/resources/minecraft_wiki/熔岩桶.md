# 熔岩桶

*页面ID: 21742* | *来源: Minecraft Wiki*

* *熔岩桶（Lava Bucket）**是装着[熔岩](熔岩.md)的[铁桶](铁桶.md)。

# 获取
与装[水](水.md)相同，手持[铁桶](铁桶.md)对着[熔岩](熔岩.md)源方块或装满熔岩的[炼药锅](炼药锅.md)按下键可得到熔岩桶，熔岩随之被舀起。与水不同的是，熔岩源方块被舀起后，其相邻的2格熔岩源不会在该格形成新的熔岩源。

# 用途
手持熔岩桶对方块点按键能够在相邻位置放置出熔岩源方块，同时熔岩桶还原为空铁桶。

对空的[炼药锅](炼药锅.md)熔岩桶会将其填满。对装有其他物质的炼药锅使用时会替换该物质；这样做会导致炼药锅和熔岩桶都被清空，炼药锅还会产生烟雾粒子。

[发射器](发射器.md)发射熔岩桶时若满足放置条件，会在朝向的方块放置出熔岩源方块并清空熔岩桶。

发射器或在下界传送门方块的位置放置熔岩会破坏下界传送门。

# = 燃料 =
熔岩桶能作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)使用，一个熔岩桶可以烧炼100个物品，这是所有燃料中的最高值。相比之下，一个[煤炭块](煤炭块.md)只可以烧炼80个物品。烧炼开始后，熔岩桶会变成空铁桶。
