# 弹射物保护

*页面ID: 42229* | *来源: Minecraft Wiki*

* *弹射物保护（Projectile Protection）**是一种用于[盔甲](盔甲.md)的[魔咒](魔咒.md)，能减少来源于[弹射物](弹射物.md)的伤害。

# 获取

# 用途

弹射物保护可以减少弹射物伤害，包括[箭](箭.md)、[三叉戟](三叉戟.md)、[小火球](小火球.md)、[火球](火球.md)</ref>|BE}}、[潜影弹](潜影弹.md)、[掷出的鸡蛋](掷出的鸡蛋.md)、[掷出的末影珍珠](掷出的末影珍珠.md)、[雪球](雪球.md)和[风弹](风弹.md)。

弹射物保护不能防护火球或[凋灵之首](凋灵之首.md)[爆炸](爆炸.md)时造成的爆炸伤害、[烟花火箭](烟花火箭.md)爆裂时造成的爆炸伤害和[喷溅药水](喷溅药水.md)造成的魔法伤害。

每魔咒等级提供2点魔咒保护系数（EPF），即8%伤害减免。

弹射物保护与其任何不共存魔咒被应用在同一个物品上时，每个魔咒都会互不干扰地产生效果。
