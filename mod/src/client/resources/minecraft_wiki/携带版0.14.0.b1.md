# 携带版0.14.0.b1

*页面ID: 19690* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.14.0 alpha build 1**是[v0.14.0 alpha](携带版0.14.0.md)的首个测试版，发布于2016年1月25日<ref>http://pocketbeta.minecraft.net/2016/01/changelog-whats-new-in-0140.html?m=0</ref>，加入了更多红石方块、[沼泽小屋](沼泽小屋.md)、[黏液块](黏液块.md)以及其他内容，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[红石中继器](红石中继器.md)**
* 新的红石元件。
* 具有锁存功能。

* *[红石比较器](红石比较器.md)**
* 新的红石元件。

* *[发射器](发射器.md)**
* 用于发射物品或者弹射物。

* *[投掷器](投掷器.md)**
* 用于投掷物品。

* *大[陷阱箱](陷阱箱.md)**
* 现在两个并排放置的陷阱箱会变成大陷阱箱。

* *[漏斗](漏斗.md)**
* 用于收集物品。

* *[物品展示框](物品展示框.md)**
* 是方块而非实体。
* 不可在同一个方块中放置。
* 使用新的音效。

* *[炼药锅](炼药锅.md)**
* 能用满的炼药锅装满水桶。
* 加入染料为内部水染色。
* * 颜色可以混合。
* 可为物品染色（如皮革盔甲）。
* 可用[水瓶](水瓶.md)往[炼药锅](炼药锅.md)中添加水。
* 可存放药水。
* * 当药水混合起来时会发出爆炸声，但不会爆炸。
* 炼药锅中的药水会发出气泡。

* *[红砂岩](红砂岩.md)**
* 可以合成[红砂岩楼梯](红砂岩楼梯.md)和[红砂岩台阶](红砂岩台阶.md)。
* 有平滑和雕纹变种。

* *[黏液块](黏液块.md)**
* 由9个[黏液球](黏液球.md)合成。

# = 物品 =
* *[地图](地图.md)**
* 使用9张纸来合成。
* 必须用[铁砧](铁砧.md)来添加一个指南针来显示玩家位置。
* 用铁砧来复制，而不是工作台。
* 用铁砧来放大，而不是工作台。

* *[末影珍珠](末影珍珠.md)**
* 目前只能通过编辑物品栏来获得。

# = 生物 =
* *[女巫](女巫.md)**
* 使用新的声音。
* 当女巫距离目标多于11个方块并缺少迅捷效果时，它就会有50%的概率喝下[迅捷药水](迅捷药水.md)。

# = 非生物实体 =
* *[运输矿车](运输矿车.md)**
* 可移动的容器。
* 破坏时有烟雾效果。

* *[TNT矿车](TNT矿车.md)**
* 破坏时有烟雾效果。

* *[漏斗矿车](漏斗矿车.md)**
* 可移动的容器。
* 破坏时有烟雾效果。

* *[摄像机](摄像机.md)**
* 被重新加入（曾经在[Alpha 0.9.0](携带版Alpha 0.9.0.md)被移除）。
* 新纹理。
* 有交互按钮。
* 只能通过编辑物品栏来获得。

# = 世界生成 =
* *[沼泽小屋](结构.md)**
* 炼药锅包含随机药水。

# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 加入了生存模式选项卡。

# = 常规 =
* *[设置](设置.md)**
* 更改GUI大小的选项。

# 更改
# = 方块 =
* *[陷阱箱](陷阱箱.md)**
* 两个陷阱箱邻近放置时会合并成大陷阱箱。

* *[南瓜](南瓜.md)与[生物头颅](生物头颅.md)**
* 玩家可以戴上了。

* *[大型花](大型花.md)**
* 对其施以骨粉时会掉落对应物品。

# = 物品 =
* *[皮革盔甲](皮革盔甲.md)**
* 现在可以被染色。

* *[甜菜根](甜菜根.md)**
* 加入至创造模式物品栏。

# = 生物 =
* *幼年[僵尸](僵尸.md)**
* 有15%的概率试图骑乘生物。如果触发此事件，则在攻击玩家之前会顺次优先考虑骑乘下列生物：
* * 成年[鸡](鸡.md)
* * 成年[豹猫](豹猫.md)
* * 成年[狼](狼.md)
* * 成年[僵尸](僵尸.md)
* * [牛](牛.md)
* * [猪](猪.md)
* * [绵羊](绵羊.md)
* * [蜘蛛](蜘蛛.md)

* *[烈焰人](烈焰人.md)**
* 可以在暗处发亮了。

* *[恶魂](恶魂.md)**
* 眼睛现在会闪烁了。

* *[岩浆怪](岩浆怪.md)**
* 其核心会在暗处发亮了。

* *[村民](村民.md)**
* 现在被[闪电](闪电.md)击中时会变成女巫了。

# = 世界生成 =
* *[废弃矿井](废弃矿井.md)**
* 现在会生成[运输矿车](运输矿车.md)。

# = 常规 =
* *图像**
* 整理了纹理文件。
* 截图现存储为.png文件。

* *[创造模式](创造模式.md)**
* 现在创造模式玩家可以与[箱子](箱子.md)、[铁砧](铁砧.md)、[熔炉](熔炉.md)、[投掷器](投掷器.md)、[发射器](发射器.md)、[酿造台](酿造台.md)、[附魔台](附魔台.md)和[漏斗](漏斗.md)交互。

# 修复
[**修复了67个漏洞**](https://bugs.mojang.com/browse/MCPE/fixforversion/15475)

* 陷阱箱不会给予红石中继器红石信号。
* 在地图上的黏土材料方块都显示为灰色。
* 双栅栏门不会阻止玩家通过。
* 玩家无法打开运输矿车和漏洞矿车。
* 玩家无法关闭箱子的物品栏UI。
* 服务器踢出不活跃玩家时崩溃。
* 被红石线激活的红石机械不会与红石线对齐。
* 建造巨型建筑时会严重影响性能。
* 农民村民没有种子继续播种时游戏崩溃。
* 可以在酿造界面使用控制器的方向键。
* 在部分亚洲语言里，背景和按钮的大小太小而不能容纳文字。
* 曲折轨道上的TNT矿车不能摧毁轨道。
* 区块数据多次发送。
* 服务器以错误的速度运行。
* 杀死女巫需要的攻击次数不会随着武器变化而出现变化。
* 物品栏的槽位不会绑定。
* 玩家死亡后会保留除了盔甲以外的所有物品。
* 骷髅-{}-的头不能向下看。
* 栅栏门不会更新其开关状态。
* Kindle和一些iPad上的玩家模型的手臂渲染出错。
* 箱子在附近有玩家站着时，玩家不能打开该箱子。
* 大型箱子里的下半部分的物品在重新打开世界后消失。
* 试图对着未驯服的狼喂食肉类时丢失交互按钮。
* 试图对着猪喂食甜菜根和马铃薯时丢失交互按钮。
* 在水下游泳时没有音效。
* 使用控制器打开物品栏时，玩家仍会继续移动。
* 铁砧上的槽位不会联立起来。
* 矿车实体无法堆叠起来。
* 同一时间出现多次区块更新时，地形会不停闪烁。
* 蘑菇煲给予中毒效果。
* 水下迷雾效果在玩家乘船进入瀑布时不会出现。
* 放置在水下的栅栏会闪烁。
* 黏土会替代沙砾生成。
* 甜菜汤可以堆叠。
* 聊天信息不能自定义颜色。
* 切换到创造模式后，敌对生物仍会与玩家保持敌对。
