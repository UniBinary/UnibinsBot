* *海龟（Turtle）**是一种海洋中的友好生物，在水陆上均可移动且不会窒息或脱水。

# 生成
# = 自然生成 =
海龟自然生成于[沙滩](沙滩.md)上，但不会生成在[积雪沙滩](积雪沙滩.md)或[石岸](石岸.md)上。海龟有10%的概率会生成为幼年海龟。

海龟会偶尔生成在亮度等级高于8且高度不高于海平面4格（即Y=66及以下）的[沙子](沙子.md)或[红沙](红沙.md)上。

海龟会生成在亮度等级不低于7且高度为60-67的沙子或红沙上。

# = 海龟蛋 =
[海龟蛋](海龟蛋.md)孵化时会生成一个幼年海龟。

成年海龟被[闪电](闪电.md)击中而死时会掉落1个[碗](碗.md)。<ref></ref><ref></ref>然而闪电会迅速将掉落的碗清除，从而难以获得其物品。<ref></ref>

成年海龟被[玩家](玩家.md)或驯服的[狼](狼.md)杀死时会掉落。

幼年海龟长大后会掉落1个[海龟鳞甲](海龟鳞甲.md)。

杀死幼年海龟不会掉落任何经验和物品。

# 行为
海龟会漫无目的地移动。它们在陆地上的移动速度较缓慢，而在水中的游泳速度很快。海龟是友好生物，会在受到攻击时逃跑。在陆地上时它们通常会试图移动至最近的水源地。当在海龟蛋顶部时，它们会悬浮。<ref></ref>

海龟可以走上1格高的方块而无需跳跃。

海龟不能被[拴绳](拴绳.md)拴住。<ref></ref>

海龟可以被[船](船.md)和[矿车](矿车.md)承载。

# = 受伤害行为 =
海龟被[闪电](闪电.md)击中时会受到3.4×10<sup>38</sup>（ × 1.7×10<sup>38</sup>）伤害。

海龟受到的来自闪电的伤害为2000倍，被闪电击中时会受到伤害。

# = 天敌 =
以下生物会主动寻找并攻击附近的幼年海龟：
* 、和会攻击10格或35格内不在水中的幼年海龟；
* 会攻击10格或20格内不在水中的幼年海龟；
* 未驯服的、、、、和会攻击10格或16格内不在水中的幼年海龟；
* 会攻击10格或12格内不在水中的幼年海龟；
* 和未驯服的会攻击10格或8格内不在水中的幼年海龟。

會主動攻擊大多數生物的[僵尸疣猪兽](僵尸疣猪兽.md)、[凋灵](凋灵.md)與命名為「Johnny」的[衛道士](衛道士.md)也會攻擊幼年與成年海龜。

# = 出生地定位 =
海龟能够“记住”它们首次生成的位置。无论它们距离出生地有多远，它们在繁殖后总是会回到它们的出生地，并在附近的沙子上产卵。

幼年海龟会以它们孵化出来的海龟蛋的位置作为它们的出生地位置，无论该海龟蛋是由海龟生成的还是由玩家放置的。

使用[刷怪蛋](刷怪蛋.md)、命令和[刷怪笼](刷怪笼.md)生成的海龟也会记住自己生成的位置。

# = 繁殖 =

海龟会跟随10格或16格内手持[海草](海草.md)的玩家。

若给两只海龟喂食海草，它们会进入[求爱模式](繁殖#求爱模式.md)，掉落，在繁殖后或内不能再次繁殖。其中一只海龟将准备产卵，它的腹部会突起，看起来比普通海龟略微高一些。海龟产卵需要回到它的出生地，当海龟回到出生地后会移动到附近的沙地上，在上面挖几秒后，它会产下1-4枚海龟蛋。海龟最多可以在同一个沙子方块内产下4枚海龟蛋。

海龟蛋共有3个孵化阶段，每个阶段时长是随机的（经历[随机刻](随机刻.md)），全过程平均约一个半小时。海龟蛋在白天和黑夜都可以孵化，但是在夜间孵化更快。海龟蛋只能在[沙子](沙子.md)、[红沙](红沙.md)和[可疑的沙子](可疑的沙子.md)上孵化。

给幼年海龟喂食海草可略微加快其成长速度，每次使用会减少约10%的成长所需时间。

对幼年海龟[金蒲公英](金蒲公英.md)可以阻止其成长为成年海龟，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年海龟无法被喂食除金蒲公英外的其他物品。

# = 生物族群 =

海龟是水生生物。被具有[穿刺](穿刺.md)魔咒的武器近战攻击，或被具有穿刺魔咒的[三叉戟](三叉戟.md)弹射物命中时会受到额外的伤害。

# 你知道吗
* 幼年海龟在游戏内生物中极其矮小，高度仅有或，这样的设定是为了尽可能贴近现实中幼年与成年海龟的真实比例。但即便如此，这个比例还是比现实的海龟宝宝大上许多倍。
* 幼年海龟是Minecraft中天敌最多的生物，这样的设定取自现实。现实中的幼年海龟孵化时会引起海滩周遭所有肉食和食腐动物的大规模猎捕，导致其存活率极低。
* * 再加上现实中海龟的栖息地遭到破坏和其自身遭到人类的捕杀，海龟现已濒临灭绝。Minecraft制作团队将海龟、[北极熊](北极熊.md)、[熊猫](熊猫.md)、[美西螈](美西螈.md)等受威胁物种加入Minecraft是为了引起玩家对此的关注。
* 虽然Minecraft中成年海龟和在水中的幼年海龟没有设定上的天敌，但如果幼年海龟在被追捕途中成长为成年海龟或下水，原先攻击它的生物仍会进行攻击，除了未驯服的猫、豹猫和狐狸。
* 海龟可在水中不会溺死的设定可能参考现实，现实中的水生龟可以用泄殖腔周围的皮肤在水中短暂呼吸一段时间（待在水下过久还是会溺死）。
* 海龟返回出生点的寻路机制参考于现实。现实中幼年海龟会记忆出生时的路线，并在产卵时沿寻记忆返回。
* 海龟脱落[海龟鳞甲](海龟鳞甲.md)的特性参考于现实。现实中的水生龟在成长过程会经历类似蛇蜕皮的鳞甲脱落过程，而陆生龟没有脱落鳞甲的过程。<ref>[wikipedia:Turtle shell#Scutes](wikipedia:Turtle shell#Scutes.md)</ref>
