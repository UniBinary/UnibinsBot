# 下界更新

*页面ID: 48425* | *来源: Minecraft Wiki*

[thumb|下界更新的官方logo](File:Nether Update.png.md)
[thumb|下界更新官方艺术作品](File:Nether Update Artwork.png.md)
* *下界更新（Nether Update）**是一次主要更新。该更新以改造维度[下界](下界.md)为主题进行，添加了诸如新群系和新生物之类的新特性。该次更新由官方宣布于[MINECON Live 2019](MINECON Live 2019.md)<ref name="MineCon article"></ref>，于2020年6月23日同时发布于[Java版](Java版.md)和[基岩版](基岩版.md)。<ref></ref><ref></ref>其版本分别为[Java版1.16](Java版1.16.md)和[基岩版1.16.0](基岩版1.16.0.md)。

在[Java版](Java版.md)上，此次更新的开发始于[20w06a](20w06a.md)，其发布于2020年2月5日。1.16的[首个预发布版](Java版1.16-pre1.md)发布于2020年6月4日，[最后一个预发布版](Java版1.16-pre8.md)发布于6月17日，[发布候选版本](Java版1.16-rc1.md)发布于6月18日。

在[基岩版](基岩版.md)上，此次更新的开发始于[基岩版1.15.0.51](基岩版1.15.0.51.md)，其发布于2020年2月12日。基岩版1.15.0的内容被合并至1.16.0以实现与Java版的版本号同步。

# 跟进版本
# = Java版 =
* [1.16.1](Java版1.16.1.md)发布以解决[Realms](Realms.md)的稳定性问题。
* [1.16.2](Java版1.16.2.md)加入了[猪灵蛮兵](猪灵蛮兵.md)并修复漏洞。
* [1.16.3](Java版1.16.3.md)发布以修复漏洞。
* [1.16.4](Java版1.16.4.md)加入了[社交屏幕](社交屏幕.md)并修复漏洞。
* [1.16.5](Java版1.16.5.md)修复了两个重要稳定性漏洞。

# = 基岩版 =
* [1.16.1](基岩版1.16.1.md)发布以修复漏洞。
* [1.16.1.03](基岩版1.16.1.03.md)（PS4专有）发布以修复游戏加载时卡顿和崩溃风险的漏洞。
* [1.16.1.04](基岩版1.16.1.04.md)（PS4专有）发布以改进游戏内稳定性。
* [1.16.10](基岩版1.16.10.md)发布以添加对弃用设备的警告并修复了移动设备上的一个漏洞。
* [1.16.20](基岩版1.16.20.md)加入了[猪灵蛮兵](猪灵蛮兵.md)并修复漏洞。
* [1.16.21](基岩版1.16.21.md)（NS专有）发布以修复主界面的稳定性漏洞。
* [1.16.40](基岩版1.16.40.md)发布以修复漏洞。
* [1.16.42](基岩版1.16.42.md)为PS4加入了PlayStation VR支持。
* [1.16.50](基岩版1.16.50.md)仅在iOS上发布，优化了稳定性，修复了崩溃问题。
* [1.16.60](基岩版1.16.60.md)仅在PS4上发布，优化了稳定性，减少了崩溃问题。
* [1.16.61](基岩版1.16.61.md)仅在PS4上发布，修复了重要的漏洞和崩溃问题。
* [1.16.100](基岩版1.16.100.md)加入了新命令，扩大了附加包，优化了脚本引擎机制，更改了一些特定方块的机制和内容，从Java版移植了一些内容，为PlayStation 4和5加入了Realms和特色服务器的支持，重做了成就/奖杯界面，并修复了漏洞。
* [1.16.101](基岩版1.16.101.md)修复了移动设备上的一些漏洞。
* [1.16.200](基岩版1.16.200.md)加入了新的音频设置和光线追踪功能，更改死亡消息并修复了一些漏洞。
* [1.16.201](基岩版1.16.201.md)发布以修复漏洞。
* [1.16.210](基岩版1.16.210.md)为下界加入了新的环境音效并修复漏洞。
* [1.16.220](基岩版1.16.220.md)加入了使用染料给告示牌文本染色的功能并修复漏洞。
* [1.16.221](基岩版1.16.221.md)修复了一些严重漏洞和崩溃问题。
