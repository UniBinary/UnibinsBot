# Java版21w06a

*页面ID: 78016* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w06a**是[Java版1.17](Java版1.17.md)的第9个快照，发布于2021年2月10日<ref></ref>，加入了以[噪声洞穴](噪声洞穴.md)和[含水层](含水层.md)为特征的新洞穴生成机制，更改了建筑高度限制，并修复了一些漏洞。

此快照无法加载在旧版本中创建的世界，因为无法更新旧世界的高度限制。

# 新内容
# = 世界生成 =
* *[洞穴](洞穴.md)**
* 加入了含水层（Aquifer）和[噪声洞穴](噪声洞穴.md)（Noise Caves），其中噪声洞穴包含“意面洞穴（Spaghetti Cave）”和“芝士洞穴（Cheese Cave）”。
* 旧洞穴（雕刻器洞穴）依然会与噪声洞穴一起生成。

* *意面洞穴**
* 形状像意面一样长而弯曲的洞穴，有时像宽意面（Tagliatelle）一样宽。
* 生成时使用了[噪声生成器](自定义世界生成.md)。
* 与地面相交时，会在地面生成洞穴入口。

* *芝士洞穴**
* 形状像瑞士奶酪上的孔一样，且大小不一的洞穴。
* 生成时使用了[噪声生成器](自定义世界生成.md)。
* 与地面相交时，会在地面生成洞穴入口。

* *含水层**
* 用于生成噪声洞穴中的水体。目前它仅在Y=31以下产生，这意味着任何位于此高度与海平面（Y=63）之间的噪声洞穴都会完全被水充满。这个问题会在以后的版本中被修复。
* 岩浆块可以在噪声洞穴水体的底部生成，产生涡流气泡柱。
* 取代了旧的水下雕刻器洞穴和水下峡谷。
* [鱼](鱼.md)会在[海洋](海洋.md)或[河流](河流.md)下的含水层中生成。

# 更改
# = 方块 =
* *[垂根](垂根.md)**
* 更改了纹理。

* *[小型垂滴叶](小型垂滴叶.md)**
* 更改了纹理。

* *[大型垂滴叶](大型垂滴叶.md)**
* 在叶片上潜行、跳跃或从其上跳下不再能使之停止倾斜。
* 将倾斜耗时缩短为。
* 现在会在被弹射物击中时倾斜。
* 现在可使用红石信号控制。
* * 叶片接收红石信号时不会倾斜。
* ** 此时叶片被弹射物击中后仍会倾斜。
* * 倾斜的叶片接收红石信号时会回升。

# = 世界生成 =
* *[废弃矿井](废弃矿井.md)**
* 废弃矿井的一部分不再完全浮空生成。
* 如果有必要的话，会生成用于支撑桥梁的[木头](木头.md)<!--已经过测试确定是四面皆为树皮纹理的木头而非原木，请勿更改-->立柱。
* 现在没有更多飘浮的[蜘蛛网](蜘蛛网.md)了。

# = 常规 =
[thumb|世界选择界面中旧世界旁附加的警告信息“Loading of old worlds is temporarily disabled.”](File:21w06a world selection warning.png.md)
[缩略图|新旧世界生成对比图（汉化版）。<ref></ref>](File:Worldgen changes in 21w06a.png.md)

* *世界**
* 将[主世界](主世界.md)可建筑范围的总高度提升到384格。
* * 主世界可建筑范围的Y[坐标](坐标.md)现在是-64到319。
* * 此项更改使得旧版本中创建的世界无法在该快照当中加载。
* * Y=0以下的矿石生成是临时的，且目前地下熔岩无法正常生成。

* *世界选择界面**
* 暂时禁用了加载旧世界的功能。
