# 数据版本

*页面ID: 44992* | *来源: Minecraft Wiki*

* *数据版本（Data Version）**，又称**世界版本（World Version）**<ref><samp>[server.jar](https://minecraft.net/download/server)</samp>或<samp>[javabridge library source](https://libraries.minecraft.net/com/mojang/javabridge/1.0.22/javabridge-1.0.22-sources.jar)</samp>，位于<samp>com.mojang.bridge.game.GameVersion</samp>类中。</ref><ref>出现在[<samp>version.json</samp>格式](#version.json.md)中。</ref>，是保存世界数据中使用的正整数，用于表示特定版本。

# 用途

在选择和加载单人模式的世界时，若客户端的数据版本新于或旧于世界的数据版本，游戏会弹出“”界面，提醒玩家备份存档：
* 若客户端数据版本比世界版本较新，且客户端是[快照](版本格式#快照（Snapshot）.md)版本，则会显示消息“”
* 反之若客户端数据版本比世界版本更旧，会显示消息“”

# 版本
自[15w32a](15w32a.md)以来的每个[Java版](Java版.md)版本，包括小更新和快照版本，都有自己的数据版本。不像客户端版本那样，数据版本采用不断增加的正整数形式。客户端版本通常不能直接比较，因为它们使用不同的格式（例如，“1.14”和“19w02a”无法比较），所以数据版本是必要的。数据版本可能会在主要版本之间跳过一些数字。

# 储存位置
数据版本存储在多个位置。

# = <samp>options.txt</samp> =

的第一行显示数据版本，名为。

# = <samp>level.dat</samp> =

是一个NBT文件，位于每一个存档的根目录下。该文件存储着该存档所有的宏观信息，可以使用特定的工具进行查看和编辑。

一个世界存档的文件内有两个地方存放了数据版本：复合标签下称为的标签和复合标签下称为的标签。

<div class="treeview">
*  level.dat
* * ：文件<samp>level.dat</samp>的信息
* ** ：显示数据版本的整数。
* ** ：关于上次保存世界的时间的版本信息。
* *** ：显示数据版本的整数。
</div>

# = 区域文件 =

区域文件内的每个区块都包含上次加载时的数据版本信息，保存于。

<div class="treeview">
* ：在指定区域坐标[*x*,*z*]处的区域信息（1区域=32×32区块）
* * ：在相对于区域的坐标[*x<sub>1</sub>*,*y<sub>1</sub>*]处的区块信息，此区块位于世界区块坐标(*x<sub>2</sub>*,*y<sub>2</sub>*)（1区块=16×16方块）
* ** ：显示数据版本的整数。
</div>

# = <samp>.dat</samp>和<samp>.nbt</samp>文件 =

# = <samp>version.json</samp> =

自[18w47b](18w47b.md)以后的每个Minecraft版本都在文件内指定了当前版本的数据版本，其位于[客户端](客户端.md)和[服务端](https://minecraft.net/download/server)jar文件的根目录下。
