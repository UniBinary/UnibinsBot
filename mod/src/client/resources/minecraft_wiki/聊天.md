# 聊天

*页面ID: 24879* | *来源: Minecraft Wiki*

* *聊天（Chat）**是玩家通过**聊天屏幕（Chat screen）**与其他玩家交流和执行[命令](命令.md)的基本方式。

# 机制

[缩略图|多人游戏聊天示例（[[基岩版](File:Chat_BE.png.md)）]]

请注意：下述按键可以进行自定义[设置](控制#可设置的键位.md)（下文中所述为默认设置）。

玩家可以通过按，或按、在触摸屏上按下[25px|class=pixel-image](File:Chat button.png.md)、在手柄上按下来打开聊天。

玩家[睡觉](睡觉.md)时也会显示聊天屏幕。

聊天功能包括：
* 历史记录：使用聊天框的右侧的滚动条可以查看历史聊天消息，也可上下滚动鼠标滚轮、或使用和。聊天框保存最近的100行消息。
* * 在输入聊天文字时使用和可以调出自己的已发送消息。
* 可以点击聊天中出现的链接。
* 在聊天中使用复制（）和粘贴（）功能（部分MacOS设备中使用代替）。使用 + 、、、选择文本。
* 格式化字体：玩家可以使用分节符（<code>§</code>）更改文字样式。详见[格式化代码](格式化代码.md)。
* * *注：*分节符作为非法字符，本身无法在原版[客户端](客户端.md)中输入。若将<code>§</code>复制粘贴到聊天框中发送，玩家会被自动踢出服务器，并提示“Illegal characters in chat（聊天消息出现非法字符）”，服务端则会报错<code>disconnect.endOfStream</code>。
* 提及：<code>@</code>符号可用于在聊天中高亮显示玩家名，<code>@here</code>表示提及所有玩家。其颜色可在聊天设置中更改，默认为黄色。

如果因玩家死亡、传送等各种原因导致聊天栏被强制关闭，或未发送消息就查看历史记录时，游戏会暂时保存聊天草稿。

# = 命令 =

聊天输入的一个重要功能是执行[命令](命令.md)。以斜杠（<code>/</code>）作为开头，玩家可以在聊天输入中输入需要被执行的命令。

玩家可以在聊天框中输入命令。命令由服务器解析。
* 在聊天框外，可作为命令输入键——按下后会出现预先输入<code>/</code>开头的聊天框。
* * 输入<code>/</code>后按下会列出当前可用的命令，与执行命令类似。

在输入命令时，按下会根据已输入内容自动补全第一个可能的命令或用户名。若已输入内容可对应多个命令或用户名，聊天框中会显示所有可能结果的列表；再次按下会在输入栏内枚举这个列表。
* 某些命令的一些额外参数也可能可以通过自动补全。
* * 某些处理方块的命令（、等等）会要求提供目标方块的x、y、z轴[坐标](坐标.md)。此时使用可将玩家准星对准的非空气方块的坐标自动填入。

通过更改[聊天设置](选项#聊天设置.md)，聊天框的尺寸可以缩小，透明度也可以调节，甚至可以完全隐藏。

如果[玩家](玩家.md)键入了不存在、有语法错误或其没有权限执行的命令，则该命令无效，玩家会收到一条错误消息。

返回的错误消息只能被试图这样使用命令的用户自己看见。

# = 复述功能 =
[缩略图|320px|class=pixel-image|右|不同的复述功能设置](File:NarratorToastMessage.gif.md)

按下会切换**复述功能（Narrator）**，这是一个会自动朗读聊天消息（包含玩家名字）的文字转语音引擎，复述功能可以切换为以下状态：

* **关闭**：复述功能关闭。
* ****：复述功能会朗读聊天和系统消息。
* ****：复述功能只朗读玩家发出的消息。
* ****：复述功能只会朗读系统发出的消息（命令输出和系统通知，等等）。

复述功能不会朗读命令和命令输出。

# = 聊天屏蔽和举报 =

玩家可以屏蔽特定玩家的聊天消息。被屏蔽的目标是一个微软账户，因此在使用同一游戏账号时，聊天消息的屏蔽状态会在中同步。

玩家可以在社交屏幕中举报玩家在聊天区中的不当发言，被举报的玩家经过审核并认定存在违规行为后会被封禁。

# 你知道吗
* 聊天框中输入的任何不雅用语都会被审查并替换为数字符号（#）。这可以通过在[设置](设置.md)中关闭“”选项来禁用，但前提是玩家必须使用成人Microsoft帐户登录。否则，该选项将无法禁用。
* 如果一个玩家更改了名称后进入多人游戏，聊天栏中会广播“<现在的名称>（之前被称为<之前的名称>）加入了游戏”。
