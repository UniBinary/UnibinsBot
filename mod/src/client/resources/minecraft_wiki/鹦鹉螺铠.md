# 鹦鹉螺铠

* *鹦鹉螺铠（Nautilus Armor）**是可以为[鹦鹉螺](鹦鹉螺.md)和[僵尸鹦鹉螺](僵尸鹦鹉螺.md)装备的盔甲物品。

# 获取
# = 锻造 =
下界合金鹦鹉螺铠可在[锻造台](锻造台.md)中通过升级钻石鹦鹉螺铠而获得。

# = 箱子战利品 =

# 用途
玩家可以为已驯服的成年[鹦鹉螺](鹦鹉螺.md)和已驯服的[僵尸鹦鹉螺](僵尸鹦鹉螺.md)装备或变更鹦鹉螺铠。对没有装备鹦鹉螺铠的鹦鹉螺或僵尸鹦鹉螺鹦鹉螺铠可为其装备。也可以在鹦鹉螺或僵尸鹦鹉螺的交互界面中的鹦鹉螺铠槽位（）放入或移除鹦鹉螺铠。

在无乘客时，对装备鹦鹉螺铠的鹦鹉螺或僵尸鹦鹉螺[剪刀](剪刀.md)可以剪下所装备的鹦鹉螺铠。[绑定诅咒](绑定诅咒.md)不会影响玩家移除鹦鹉螺铠。

鹦鹉螺铠没有耐久度，因此可以无限地使用，不会因承受伤害而损毁。

[物品实体](物品实体.md)形式的下界合金鹦鹉螺铠会漂浮在[熔岩](熔岩.md)上，且不会被[火](火.md)和熔岩摧毁。

# = 提供护甲值 =

鸚鵡螺鎧在被装备时会提供。

# = 提供盔甲韧性 =

钻石鹦鹉螺铠或下界合金鹦鹉螺铠在被装备时会提供。

# = 提供击退抗性 =

獄髓製鸚鵡螺鎧在被装备时会提供击退抗性，即[属性](属性.md)<code>knockback_resistance</code>。

# = 猪灵 =
[猪灵](猪灵.md)会被金鹦鹉螺铠吸引并前往拾取地上的金鹦鹉螺铠，端详或后收进它们的物品栏。

# = 僵尸鹦鹉螺 =
装备了任意鹦鹉螺铠的僵尸鹦鹉螺不会在阳光下[着火](着火.md)。
