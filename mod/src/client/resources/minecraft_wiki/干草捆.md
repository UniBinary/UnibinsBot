* *干草捆（Hay Bale）**是一种方块。它们可以用来喂食马和羊驼，也可以用来存储[小麦](小麦.md)。

# 生成
# = 自然生成 =
干草捆会在[村庄](村庄.md)某些建筑的内部和针叶林村庄的营火下方生成，也会在村庄中以[干草捆堆](干草捆堆.md)的形式生成。

干草捆也会作为[掠夺者前哨站](掠夺者前哨站.md)的稻草人标靶的一部分生成。

# 破坏
挖掘干草捆的合适工具是锄。

干草捆被破坏后会掉落自身。

# 用途
干草捆可以朝任何方向放置，方式与[原木](原木.md)和[石英柱](石英柱.md)一样。

# = 合成材料 =

# = 储存 =
干草捆可以用来储存[小麦](小麦.md)。

# = 马、驴、骡 =
给[马](马.md)、[驴](驴.md)或[骡](骡.md)喂食干草捆可使其恢复。给幼年马、幼年驴或幼年骡喂食干草捆可缩短其成长时间。

# = 羊驼 =
干草捆可用于吸引[羊驼](羊驼.md)和[行商羊驼](行商羊驼.md)。当玩家在或以内手持干草捆时，羊驼和行商羊驼会跟随玩家。

给羊驼或行商羊驼喂食干草捆可使其恢复、增加6点好感度，同时使已驯服的羊驼或行商羊驼进入繁殖模式。给幼年羊驼或行商羊驼喂食干草捆可缩短其成长时间。

# = 摔落 =
干草捆会减少80%的[摔落](摔落.md)伤害，即掉落到干草捆上仅会受到一般情况下20%的摔落伤害。

一个满生命值且未装备任何[盔甲](盔甲.md)的玩家从100.27格[高度](高度.md)摔落到干草捆上依然具有的生命值。

# = 营火 =
在[营火](营火.md)下方放置干草捆可以让营火作为信号火，使其冒出高度为10个方块到25个方块的浓烟。

# = 堆肥 =
把干草捆放进[堆肥桶](堆肥桶.md)内有85%的概率增加一层堆肥层数。
