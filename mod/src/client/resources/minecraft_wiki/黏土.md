* *黏土（Clay）**是一种开采后掉落[黏土球](黏土球.md)的[方块](方块.md)。

# 生成
# = 自然生成 =
黏土通常生成于[河流](河流.md)、[冻河](冻河.md)、[湖泊](含水层.md)、[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)的底部，以[圆盘](圆盘.md)的形式存在。

黏土也会生成于[平原](平原.md)、[热带草原](热带草原.md)、[沙漠](沙漠.md)和[针叶林](针叶林.md)四种[村庄](村庄.md)中。

黏土也会生成于[繁茂洞穴](繁茂洞穴.md)中，组成[多叶黏土层](多叶黏土层.md)。

黏土还会少量生成于[温水海洋](温水海洋.md)的海床中。

# = 转化 =
将[泥巴](泥巴.md)放置在下方挂有[滴水石锥](滴水石锥.md)的方块上方会使其每随机刻有（约17.6%）的概率转化为黏土，平均转化时间为388.4秒。泥巴在[下界](下界.md)由[环境属性](环境属性.md)<code>gameplay/water_evaporates</code>控制。}}中不会转化。<ref></ref>

# 获取
# = 合成 =

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落黏土。

# = 礼物 =

[石匠](石匠.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷黏土。

# 破坏
挖掘黏土的合适工具是锹。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，黏土被破坏后会掉落4个[黏土球](黏土球.md)。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，黏土被破坏后会掉落自身。

# 用途
# = 烧炼 =

# = 种植 =
黏土的上表面可以直接种植[小型垂滴叶](小型垂滴叶.md)、[大型垂滴叶](大型垂滴叶.md)、[红树胎生苗](红树胎生苗.md)和[杜鹃花丛](杜鹃花丛.md)。

# = 转变 =
杜鹃花丛长成[杜鹃树](杜鹃树.md)后会将其下方的黏土转变为[缠根泥土](缠根泥土.md)。

# 你知道吗
* 在现实中，黏土也可以是鲜红色的，并不仅仅局限于蓝灰色。这种颜色在游戏中出现在[陶瓦](陶瓦.md)、[红砖](红砖.md)和[花盆](花盆.md)的纹理中。
