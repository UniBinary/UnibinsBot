# Java版Classic 0.0.10a

*页面ID: 39605* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.10a**是2009年5月17日制作完成的[Classic](Java版Classic.md)版本<ref name="logs"> "*[13:53:09] <Notch_> 0.0.10a should be up now*" [...] "*[13:53:34] <Notch_> I forgot to take out the normal start() and destroy()..*" [...] "*[13:56:55] <Notch_> ok, it's up. 0.0.11a*"</ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[控制](控制.md)**
* 按解除鼠标锁定并暂停游戏。

# 更改
# = 常规 =
* *其他**
* 增强了性能的稳定性。

# 修复
; 修复了1个漏洞
   修复了游戏在Opera浏览器中崩溃的漏洞。</onlyinclude>

# 你知道吗
* 该版本原本计划向公众发布，但由于Notch忘记替换成正常的启动和关闭函数，游戏无法进行，所以在仅仅四分钟后就被[Classic 0.0.11a](Java版Classic 0.0.11a.md)取代了。<ref name="logs"/>
