# 基岩版1.8.0.8

*页面ID: 36724* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.8.0.8**是[1.8.0](基岩版1.8.0.md)的首个测试版，发布于2018年10月10日<ref>https://feedback.minecraft.net/hc/en-us/articles/360016529492-Minecraft-Beta-1-8-0-8-Xbox-One-Windows-10-Android-</ref>，加入了[村庄与掠夺](村庄与掠夺.md)的一些特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[竹子](竹子.md)**
* 可以在丛林钓鱼时找到，并且会存在于一些丛林神殿里的箱子里。
* 暂时不会自然生成。

* *[脚手架](脚手架.md)**
* 一个用[竹子](竹子.md)做的可攀爬方块。
* 按下向上爬以及按下向下爬。

# = 生物 =
* *[熊猫](熊猫.md)**
* 生成在[丛林](丛林.md)里。
* 找到竹子或蛋糕会吃掉它们。
* 有不同的习性：普通、好斗、懒惰和贪玩。
* 幼年熊猫有时会打喷嚏，这会使附近的熊猫跳起来；打喷嚏时，有概率掉落一个[黏液球](黏液球.md)。
* 有棕色的稀有变种。
* 有时会翻滚或坐在地上。

* *[流浪猫](流浪猫.md)**
* 会生成在[村庄](村庄.md)里。
* 可以用鱼驯化它。
* 有了新的外观。

# 更改
# = 物品 =
* *[木棍](木棍.md)**
* 现在能用[竹子](竹子.md)合成。

* *[摄像机](摄像机.md)**
* 重新加入且只能通过编辑NBT生成。

# = 生物 =
* *[豹猫](豹猫.md)**
* 不再能被驯服。
* 可通过喂养以获得其信任。

* *[幻翼](幻翼.md)**
* 现在怕猫，并且猫在周围时不会落下。

* *[骷髅马](骷髅马.md)和[僵尸马](僵尸马.md)**
* 现在用刷怪蛋生成将变得有概率性。

* *[NPC](NPC.md)**
* 现在能使用命令来生成。

# = 游戏内容 =
* *[钓鱼](钓鱼.md)**
* 钓鱼的战利品表被更改：在[丛林](丛林.md)中钓鱼时，玩家只能获得鳕鱼和鲑鱼。
* [竹子](竹子.md)可作为垃圾被钓上来。

# = 世界生成 =
* *[沼泽小屋](沼泽小屋.md)**
* 黑猫现在会生成在沼泽小屋内。

* *[市场](市场.md)**

# 修复
* *修复了57个漏洞**
* 修复了游戏过程中出现的崩溃现象。
* 加载资源包时，断开网络连接导致游戏崩溃。
* Xbox One版里如果玩家登入后又迅速登出会导致游戏崩溃。
* Windows 10 Mobile下在加载界面下游戏会崩溃。
* Gear VR版启动时游戏崩溃。
* 试图对着鱼使用熔岩桶时游戏崩溃。
* 试图打开多个UI时游戏崩溃。
* Windows 10的新特性导致游戏崩溃。（）
* Realms世界里玩家可以瞬间被烈焰人的火球杀死。（）
* 持续种植作物时，现在不再会跳过方块。（）
* 玩家手持肉类靠近已驯服的狼时，狼不会歪头。（）
* 岩浆怪死亡时不再能攻击玩家。（）
* 骑乘矿车的生物不再能激活相邻的探测铁轨。（）
* 恶魂发射火球时，音效播放两次。（）
* 使用配方书合成多个蛋糕时，现在会返还正确数量的空桶。（）
* 墙上的告示牌在破坏时不再显示不同种类的木头的粒子。（）
* 创造模式下，选项允许时爆炸摧毁方块后会使其变成掉落物。（）
* 树苗盆栽在破坏时现在会掉落正确种类的树苗。（）
* 上船的玩家头现在会朝向前方。（）
* 移除了“MCPE!”闪烁标语。（）
* 围绕着屏障的水的渲染不正确。
* 骑乘时，世界有时候会出现黑色斑点。
* 重新进入世界时，如果玩家站在非全体积方块上，玩家会传送走。（）
* 在部分触摸屏设备里出现不正确的交互按钮。
* 如果没有登录到Xbox Live，暂停菜单里不再显示成就按钮。
* 游泳时，玩家可以透视固体方块。
* 使用Xbox One和Nintendo Switch里的限制内容时，现在可以准确看见多人游戏开关选项。
* 双木台阶现在可以无视十字准星的位置来放置。（）
* 在被推动或拉动时，活塞会变成掉落物。（）
* 大型史莱姆或岩浆怪现在有了正确的碰撞箱。（）
* 海带现在可以正常生长在水源方块里或向下流动的水，而不会创建水源方块。（）
* 可以复制铁轨。（）
* 在寒冷的生物群系里，闪电会在远处出现。（）
* 生物有时候会免疫坠落伤害。（）
* “保镖”成就不能达成。（）
* 部分成就无法在更高高度处达成。
* Nintendo Switch版里右后按键现在可以滚动游戏菜单。
* 活塞臂的碰撞箱不正确。（）
* 玩家坠落时可以穿过打开的潜影盒。（）
* 改进了大多数存档的加载时间。
* 修复了使用Windows混合现实设备里用于启动游戏的按钮出现的问题。
* Windows 10版里无法复制或导入大于1GB的存档。（）
* 在里为参数加入了下划线，从而与其余的原版资源包匹配。（）
* 在船上时，定位器地图的玩家标记朝向错误。
* 多人游戏下，自定义玩家权限无法实现。（）
* 缓降药水不能减少鞘翅的向下飞行动力。（）
* 使用触摸屏设备时，多个物品现在能通过村民交易来收集。（）
* 只能合成白色粒子的烟花火箭。
* 上船然后持弓蓄力时，玩家的-{}-头部朝向不正确。
* 在命令方块的自动完成区域里，熔岩块看起来是绿色的。（）
* 在移除了鲑鱼的寻路组件后，杀死和生成鲑鱼会使得游戏崩溃。
* 选项界面里的Page Up和Page Down按键现在会被正确标记。
* 容器的控制器提示现在会正确显示“打开”和“使用”功能。
* 在使用命令的自动补全功能时，纯数字用户名现在会被引号包起。
* 海带生长时游戏崩溃。
* 包含了定位器地图的世界会使得游戏崩溃。
