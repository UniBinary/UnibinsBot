* *僵尸（Zombie）**可以指：

# Minecraft
# = 生物 =
僵尸及其变种：
*  - 常见的亡灵敌对生物，有时会手持[铁锹](铁锹.md)或[铁剑](铁剑.md)进行攻击。
*  - 当僵尸杀死[村民](村民.md)时产生的僵尸变种，也有小概率自然生成，拥有多种职业。
*  - 在[沙漠](沙漠.md)中产生的僵尸变种，并且在攻击目标时会给予其[饥饿](饥饿（状态效果）.md)状态效果。
*  - 在[水](水.md)中产生的或僵尸在水中一段时间后转化的僵尸变种，有时会装备[三叉戟](三叉戟.md)进行远程攻击。
*  - 在[地獄](地獄.md)生成的殭屍變種，也可由[豬布林](豬布林.md)和[豬布林蠻兵](豬布林蠻兵.md)在地獄以外的維度轉化而來。
*  - 一个[幼年僵尸](幼年僵尸.md)或其变种骑着[鸡](鸡.md)。
*  - 愚人节快照[24w14potato](24w14potato.md)中的僵尸变种。
类似僵尸的生物：
*  - 一种[马](马.md)的亡灵变种。
*  - 未使用的大型“被动”僵尸般的怪物。
*  - [疣猪兽](疣猪兽.md)在主世界或末地停留15秒后转化的亡灵敌对生物，会攻击大部分生物。
*  - [鹦鹉螺](鹦鹉螺.md)的亡灵变种。
*  - [骆驼](骆驼.md)的亡灵变种。

# = 物品和方块 =
* 僵尸、僵尸村民、尸壳、溺尸、僵尸马、僵尸鹦鹉螺、僵尸猪灵、僵尸疣猪兽的[刷怪蛋](刷怪蛋.md)。
*  - 僵尸被[闪电苦力怕](闪电苦力怕.md)炸死后掉落的[生物头颅](生物头颅.md)。

# Minecraft Dungeons
*  - 常见的亡灵攻击型生物。
*  - 普通僵尸的变种，身穿[强化链甲](MCD:强化链甲.md)的头盔和[鳞甲](MCD:鳞甲.md)，或身穿全套[强化链甲](MCD:强化链甲.md)，使用单个[双持匕首](MCD:双持匕首.md)或[剑](MCD:剑.md)进行攻击。
*  - 仅在[仙人掌峡谷](MCD:仙人掌峡谷.md)、[沙漠神殿](MCD:沙漠神殿.md)和[腐化锅釜怪](MCD:腐化锅釜怪.md)的Boss战中生成的亡灵攻击型生物。
*  - 中的尸壳变种。
*  - 仅在[觉醒丛林](MCD:觉醒丛林.md)DLC关卡中生成的僵尸变种，攻击时会附带中毒效果。
*  - 中的丛林僵尸变种，攻击不会附带中毒效果。
*  - 在[悚伏寒冬](MCD:悚伏寒冬.md)和部分[嚎风山巅](MCD:嚎风山巅.md)DLC关卡中生成的僵尸变种，攻击时会附带霜冻效果。
*  - 中的霜冻僵尸变种，攻击不会附带霜冻效果。
*  - 仅在[隐秘深渊](MCD:隐秘深渊.md)DLC关卡中生成的变种，有时会手持三叉戟进行近战或远程攻击。
*  - 更加强大的溺尸变种，使用[灵魂之刃](MCD:灵魂之刃.md)或[永恒之刃](MCD:永恒之刃.md)进行攻击，有时还会使用三叉戟进行近战或远程攻击。
*  - DLC隐秘深渊中的[亡灵生物](MCD:亡灵生物.md)小Boss。

Minecraft Dungeons中类似僵尸的生物：
*  - 仅在[下界之焰](MCD:下界之焰.md)DLC关卡中生成的亡灵攻击型生物，使用金剑或[弩](MCD:弩.md)。
*  - 穿戴盔甲的僵尸猪灵变种，使用金斧或[烙火](MCD:烙火.md)或[弩](MCD:弩.md)。
*  - 一个[幼年僵尸](MCD:幼年僵尸.md)骑着鸡。
*  - 许多个垒在一起的[幼年僵尸](MCD:幼年僵尸.md)骑着鸡。

*  - 一种会发射腐肉弹射物进行远程攻击的僵尸。
