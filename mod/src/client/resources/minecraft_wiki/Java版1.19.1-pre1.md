# Java版1.19.1-pre1

*页面ID: 96941* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.19.1-pre1**是[Java版1.19.1](Java版1.19.1.md)的首个预发布版，发布于2022年6月21日<ref></ref>，完善了举报功能并修复了一些漏洞。

# 更改
# = 方块 =
* *[幽匿感测体](幽匿感测体.md)**
* 回退了上个版本作出的更改，但对应游戏事件仍然保留。

# = 生物 =
* *[悦灵](悦灵.md)**
* 将复制的冷却时间由2.5分钟延长至5分钟。

# = 常规 =
* *[资源包](资源包.md)**
* 将与聊天举报功能有关的3个新图标移至<samp>report_button.png</samp>中。

* *[社交屏幕](社交屏幕.md)**
* 现在被举报的玩家经过审核并认定存在违规行为后会被封禁，从而无法进行[在线游戏](多人游戏.md)和加入[Realms](Realms.md)。
* 现在被封禁的玩家进入游戏后会收到封禁通知，告知该玩家被封禁的原因和封禁时长。

* *[标签](Java版标签.md)**
* 回退了上个版本作出的更改。
