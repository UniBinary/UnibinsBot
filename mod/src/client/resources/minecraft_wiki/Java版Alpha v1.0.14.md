* *Alpha v1.0.14**是的一次秘密更新，发布于2010年7月30日。加入了[鸡](鸡.md)、[鸡蛋](鸡蛋.md)、[唱片机](唱片机.md)、[音乐唱片](音乐唱片.md)、[动力矿车](动力矿车.md)和[运输矿车](运输矿车.md)。

# 新内容
# = 方块 =
* *[唱片机](唱片机.md)**
* 用于播放新加入的音乐唱片。
* 由[木板](木板.md)和[钻石](钻石.md)合成。

# = 物品 =
* *[鸡蛋](鸡蛋.md)**
* 鸡会隔一段时间产下鸡蛋，但鸡蛋不可投掷。

* *[音乐唱片](音乐唱片.md)**
* 加入了唱片13和cat。

* *[动力矿车](动力矿车.md)**
* 装有熔炉的矿车，可以充当火车头，使用[煤炭](煤炭.md)作为燃料。

* *[运输矿车](运输矿车.md)**
* 装有箱子的矿车，作为可移动的容器。

# = 生物 =
* *[鸡](鸡.md)**
* 一种友好生物，会自然生成在世界中。
* 会产出[鸡蛋](鸡蛋.md)。

# = 游戏内容 =
* *[音效](音效.md)**
* 加入了3个新的背景音效。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了下列闪烁标语：
* * Haha, LOL!
* * Hampsterdance!
* * Switches and ores!

# 更改
# = 方块 =
* *[仙人掌](仙人掌.md)**
* 现在可以生长到3格方块高，使得其可以被种植。

# = 物品 =
* *[箭](箭.md)**
* 更改了合成配方，合成配方中的[铁锭](铁锭.md)被更改为[燧石](燧石.md)。

# = 生物 =
* *[牛](牛.md)**
* 更改了纹理。

* *[史莱姆](史莱姆.md)**
* 由于其大量生成，故减少了生成数量。
* * 新限制中的计算错误导致史莱姆只会生成在奇怪的位置，因此史莱姆的自然生成目前不可用。

* *[玩家](玩家.md)**
* 玩家的横向跳跃距离从3格改为2格。

# = 游戏内容 =
* *常规**
* 缩短了跳跃距离，这导致玩家现在只能水平跳过两个方块而不是三个。

# = 常规 =
* *[徽标](徽标.md)**
* 更改了徽标，但M字母中缺少1个方块。</onlyinclude>

# 重新上传
该版本的客户端于16:59（UTC）被重新上传，加入了闪烁标语“Switches and ores!”，并修复了合成唱片机会给予玩家[书架](书架.md)的漏洞。

# 你知道吗
* Alpha v1.0.15的发布博文被错误标注为“Minecraft Alpha v1.0.14”。<ref></ref>不过jar文件的日期和博文的时间戳清晰地体现出其实际为Alpha v1.0.15。
