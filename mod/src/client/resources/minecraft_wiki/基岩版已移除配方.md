# 基岩版已移除配方

*页面ID: 98500* | *来源: Minecraft Wiki*

在及其前身的开发历程中，移除了一些合成和烧炼配方。这些合成和烧炼配方可能被替代，或者开发者在晚些时候决定不制作这个合成和烧炼配方而被移除。

# 合成配方
# = 下界反应核 =

在[携带版0.12.1.b1](携带版0.12.1.b1.md)中，下界反应核的配方被移除。它不再出现在配方列表中，并且会在使用无[精准采集](精准采集.md)魔咒的[镐](镐.md)破坏时掉落其合成原材料作为补偿。

# = 旧的切石机 =

在[携带版0.13.0.b1](携带版0.13.0.b1.md)中，随着[工作台](工作台.md)合成石质方块机制的重新加入，旧的切石机配方被移除，并被重新定义为一种仅限创造模式的装饰性方块。新的[切石机](切石机.md)加入后，之前放置的旧切石机依然会正常存在。

# = 可可豆 =

[携带版0.8.0.b3](携带版0.8.0.b3.md)中加入了[可可豆](可可豆.md)的独有合成配方。[0.9.0.b1](携带版0.9.0.b1.md)之后，可以通过种植可可果来获得可可豆。[0.16.0](携带版0.16.0.md)中可可豆的合成配方被移除，因为此配方没有任何意义，现在可可豆已经可以通过种植来无限获取。<ref></ref>

# = 床 =

[携带版1.1.0.0](携带版1.1.0.0.md)中移除了使用任意[羊毛](羊毛.md)颜色制作红色[床](床.md)的配方，同时添加了彩色床的配方。在1.1.0.0之前，游戏中只有红床，而现在需要用红色的羊毛或其他颜色的床加红色染料来制作一张红色的床。

# = 平滑石头台阶 =

在旧版本中，平滑石头台阶（当时称作“石台阶”）可以使用[石头](石头.md)、[安山岩](安山岩.md)、[花岗岩](花岗岩.md)、[闪长岩](闪长岩.md)及其磨制变体来制作。在[基岩版1.2.0.2](基岩版1.2.0.2.md)中，配方改为只可使用石头。在[1.9.0](基岩版1.9.0.md)中，配方又改为使用平滑石头制作。

# = 石砖 =

在旧版本中，石砖可以使用[安山岩](安山岩.md)、[花岗岩](花岗岩.md)、[闪长岩](闪长岩.md)及其磨制变种来制作。在[基岩版1.2.0.2](基岩版1.2.0.2.md)中，配方改为只可使用石头。

# = 红石中继器 =

在旧版本中，红石中继器可以使用[安山岩](安山岩.md)、[花岗岩](花岗岩.md)、[闪长岩](闪长岩.md)及其磨制变体来制作。在[基岩版1.2.0.2](基岩版1.2.0.2.md)中，配方改为只可使用石头。

# = 红石比较器 =

在旧版本中，红石比较器可以使用[安山岩](安山岩.md)、[花岗岩](花岗岩.md)、[闪长岩](闪长岩.md)及其磨制变体来制作。在[基岩版1.2.0.2](基岩版1.2.0.2.md)中，配方改为只可使用石头。

# = 附魔金苹果 =

在[基岩版1.2.13](基岩版1.2.13.md)中，附魔金苹果的合成配方被移除，这使得其直到[基岩版1.21.0](基岩版1.21.0.md)都是不可再生资源。

# = 砂岩和红砂岩楼梯 =

在旧版本中，砂岩和红砂岩楼梯分别可由任意种类的[砂岩](砂岩.md)和[红砂岩](红砂岩.md)合成。在[基岩版1.9.0](基岩版1.9.0.md)中，由于加入了其对应平滑变体，配方改为只可分别使用普通砂岩和红砂岩。
{{Crafting|ignoreusage=1
|A1={Any Sandstone}; {Any Red Sandstone}
|A2={Any Sandstone}; {Any Red Sandstone}
|B2={Any Sandstone}; {Any Red Sandstone}
|A3={Any Sandstone}; {Any Red Sandstone}
|B3={Any Sandstone}; {Any Red Sandstone}
|C3={Any Sandstone}; {Any Red Sandstone}
|Output=Sandstone Stairs; Red Sandstone Stairs
}}

# = 砂岩和红砂岩台阶 =

在旧版本中，砂岩和红砂岩台阶分别可由任意种类的砂岩和红砂岩制成。在基岩版1.9.0中，由于加入了其对应切制和平滑变体，配方改为只可分别使用普通砂岩或红砂岩。
{{Crafting|ignoreusage=1
|A2={Any Sandstone}; {Any Red Sandstone}
|B2={Any Sandstone}; {Any Red Sandstone}
|C2={Any Sandstone}; {Any Red Sandstone}
|Output=Sandstone Slab; Red Sandstone Slab
}}

# = 蜜脾块 =

蜜脾块曾有一个独特的合成配方，需要使用9个[蜜脾](蜜脾.md)合成。在[基岩版1.14.0.2](基岩版1.14.0.2.md)后使用了和相同的合成配方。

# = 铜制号角 =

在[基岩版1.19.0.24](基岩版1.19.0.24.md)中，实验性物品铜制号角被移除，其配方也连带着被一起移除。

# = 竹板 =

在[基岩版1.19.60.20](基岩版1.19.60.20.md)中，竹板的合成配方改为由1个竹块分解成2个竹板。

# = 刷子 =

在[基岩版1.19.80.20](基岩版1.19.80.20.md)中，刷子的合成配方被1个羽毛、1个铜锭和1个木棍的合成配方取代。

# = 线 =

[携带版1.1.0.3](携带版1.1.0.3.md)中加入了用1个[蜘蛛网](蜘蛛网.md)合成9根线的独有配方。[基岩版1.20.10.20](基岩版1.20.10.20.md)中，为同步而移除了此配方。

# = 木桶 =

在[基岩版1.20.10.20](基岩版1.20.10.20.md)中，为同步而加入了使用木板合成木桶的合成配方，后于[基岩版1.20.10.23](基岩版1.20.10.23.md)移除了使用木棍合成木桶的合成配方。

# = 船 =

在[基岩版1.20.10.20](基岩版1.20.10.20.md)和[基岩版1.20.10.21](基岩版1.20.10.21.md)中，为同步而移除了船的合成配方中的[木锹](木锹.md)。

# = 铜门 =

在[基岩版1.21.0.24](基岩版1.21.0.24.md)中，合成铜门需要铜锭，而非铜块，铜门的氧化变种不再能够合成。

# = 铜活板门 =

在[基岩版1.21.0.24](基岩版1.21.0.24.md)中，合成铜活板门需要铜锭，而非铜块，铜活板门的氧化变种不再能够合成。

在[基岩版1.21.110.23](基岩版1.21.110.23.md)中，为与[铜栏杆](铜栏杆.md)做区分，更改了铜活板门的合成配方。此前，合成2个铜活板门需要6个铜锭。

# = 磁石 =

在[基岩版1.21.60.25](基岩版1.21.60.25.md)中，磁石的配方被包含铁锭的配方取代。

# = 拴绳 =

在[基岩版1.21.90.21](基岩版1.21.90.21.md)中，拴绳的配方不再需要黏液球，被线取代。

# = 失水恶魂 =

在[基岩版1.21.90.21](基岩版1.21.90.21.md)中，更改了失水恶魂的合成配方。此前，失水恶魂使用恶魂之泪与骨块合成。

# 烧炼配方
# = 红色染料 =

[携带版0.4.0](携带版0.4.0.md)加入了将红色[蘑菇](蘑菇.md)烧炼为红色染料的配方，随后这一特性在[0.12.1.b1](携带版0.12.1.b1.md)被移除。

移除此配方的原因尚不明确。可能是由于当时红色染料的名称“玫瑰红”表明其应当来自玫瑰而非蘑菇；也有可能是因为旧版本中的[花](花.md)只有蒲公英和青花两种，这个配方只是暂时加入，以便玩家能够在[生存模式](生存模式.md)中通过合理手段获取玫瑰红。
