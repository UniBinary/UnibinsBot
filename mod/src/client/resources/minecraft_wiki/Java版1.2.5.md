# Java版1.2.5

*页面ID: 29989* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.2.5**是的一次次要更新，发布于2012年4月4日<ref name="blogpost_1.2.5"></ref>，修复了一些漏洞和崩溃。此版本兼容1.2.4的服务端。

1.2.5的预发布版发布于2012年3月30日<ref name=blogpost_1.2.5/>，与正式版更新内容相同。

# 新内容
# = 游戏内容 =
* *选取方块键**
* 现在在[创造模式](创造模式.md)可以用鼠标中键来获得十字准星所对准的方块。

# 更改
# = 常规 =
* *直接连接对话框**
* 现在会记住你使用过的最后一个IP。

* *编码**
* 在的文件夹中，数字签名文件和已分别重命名为和。
* 功能没有改变。

# = 方块 =
* *[熔炉](熔炉.md)**
* 现在支持来更方便地操作。

# = 生物 =
* *[猫](豹猫.md)**
* 现在豹猫坐到东西上的欲望降低了，但变得更加好动。

# 修复
* *修复了14个漏洞**
* 修复了检测聊天中特定链接的问题。
* 修复了野生豹猫的行为像驯服了的豹猫的问题。
* 修复了各种聊天崩溃问题。
* 修复了特定情况下世界生成失败的问题。
* 修复了于在特定情况下关闭声音有关的问题。
* “根据Herobrine大人的指示”<ref name=blogpost_1.2.5/>移除了所有幽灵实体。
* 修复了在聊天中粘贴特定字符导致崩溃的问题。
* 修复了在特定环境中，斜杠表现不正确的问题。
* 修复了不严格匹配命令的问题（例如：输入不再会关闭服务器了）。
* 修复了不能点击有颜色链接的问题。
* 修复了村庄中关于门检测的潜在问题（这个问题会导致太多的村民被生成）。
* 对哞菇使用一叠碗不再会使用整叠碗了。
* 手持打火石对一个TNT方块点左键会破坏并使其掉落（右键会激活TNT）。
* 修复了在macOS上使用快捷键不退出程序的问题。</onlyinclude>
