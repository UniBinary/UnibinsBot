* *腐败的马铃薯皮方块（Block of Corrupted Potato Peels）**是[马铃薯皮方块](马铃薯皮方块.md)的腐败变种。

# 生成
腐败的马铃薯皮方块不会生成在世界中。

# 获取
# = 合成 =

# = 破坏 =
没有工具可以加速对腐败的马铃薯皮方块的挖掘。

腐败的马铃薯皮方块被破坏后会掉落自身。

# 用途
腐败的马铃薯皮方块会发出[女巫](女巫.md)的声音和[符文粒子](Java版粒子#简单粒子.md)。

# = 生成实体 =
当一个腐败的马铃薯皮方块接收到[随机刻](随机刻.md)时，它都有5%的概率在自身顶部生成一个随机的指定[实体](实体.md)。不同实体被生成的概率如下：

要生成实体，该方块上必须没有生物。
