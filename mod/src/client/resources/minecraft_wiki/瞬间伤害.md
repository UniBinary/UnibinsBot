# 瞬间伤害

*页面ID: 28619* | *来源: Minecraft Wiki*

* *瞬间伤害（Instant Damage）**是一种能对非亡灵生物造成[伤害](伤害.md)或恢复亡灵生物的[生命值](生命值.md)的[状态效果](状态效果.md)。

# 效果
瞬间伤害是一种即时生效效果。因此与其他效果有多种不同的特性。

对于饮下[药水](药水.md)、被[喷溅药水](喷溅药水.md)击中或停留在[滞留药水](滞留药水.md)产生的[区域效果云](区域效果云.md)里的生物：

* 生物不是亡灵生物，则在生效时立即受到×2<sup>等级</sup>魔法伤害。
* 生物是亡灵生物，则在生效时立即恢复×2<sup>等级</sup>生命值。
* 受这种方式影响的生物直接结算伤害或治疗，因此即使生物免疫状态效果，也仍会被伤害或治疗。

效果由喷溅药水施加时，随距离增加而减少的是伤害或治疗的量而非持续时间；效果由区域效果云施加时，伤害或治疗量减半。

对于被[药箭](药箭.md)击中，或由赋予瞬间伤害效果的生物：

* 受影响生物不是亡灵生物时，每[刻](刻.md)受到×2<sup>等级</sup>魔法伤害。
* * 因[受击后伤害免疫](受击后伤害免疫.md)机制，实际伤害间隔变为10刻。
* 受影响生物是亡灵生物时，每刻恢复×2<sup>等级</sup>生命值。
* 、[末影龙](末影龙.md)免疫此类来源的瞬间伤害效果。

命令可以使效果有更高的持续时间，使用时持续时间参数为游戏刻而非秒数。

如果被赋予效果倍率值0-31（对应等级1-32）范围以外的值，实际生效的倍率值则取[模除](wikipedia:Modulo_operation.md)32后的值。

等级30-32的瞬间伤害效果不会为亡灵生物恢复生命值。

# 你知道吗
* 使用特定等级（即<code>amplifier</code>值为32n + 29（0 ≤ n ≤ 3））的喷溅型瞬间伤害药水投掷生物会引发非预期行为：
* * 向[亡灵生物](亡灵生物.md)投掷时，会因单次治疗量溢出为负数，导致生物直接死亡且不会掉落任何物品。
* * 连续向非亡灵生物投掷时，可能会造成极大伤害，该伤害甚至可以让带有抗性提升4且满生命值的[监守者](监守者.md)瞬间死亡。这一现象产生的原因是生物第一次[受击后伤害免疫](受击后伤害免疫.md)期间又受到了相似的伤害，因而在承受两次随机伤害间差值时死亡。
