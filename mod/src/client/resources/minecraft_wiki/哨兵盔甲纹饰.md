# 哨兵盔甲纹饰

*页面ID: 156937* | *来源: Minecraft Wiki*

* *哨兵盔甲纹饰（Sentry Armor Trim）**是一种[盔甲纹饰锻造模板](盔甲纹饰锻造模板.md)，可使用[圆石](圆石.md)复制自身。

# 获取
# = 箱子战利品 =

# = 合成 =
尽管哨兵盔甲纹饰本身不能合成获得，但可以利用特定的合成配方来复制自身。

# 用途
哨兵盔甲纹饰可在锻造台上与[盔甲](盔甲.md)和锻造原材料相结合，给盔甲添加纹饰。
