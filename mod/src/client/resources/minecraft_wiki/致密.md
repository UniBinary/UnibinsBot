# 致密

*页面ID: 115157* | *来源: Minecraft Wiki*

* *致密（Density）**是一种用于[重锤](重锤.md)的[魔咒](魔咒.md)，可增加玩家在下落时使用重锤造成的伤害。

# 获取

致密V对于[书](书.md)，附魔需要的[附魔等级](附魔等级.md)超过了30级，因此无法从[附魔台](附魔台.md)获取。

# 用途

生物使用具有此魔咒的重锤发动下落攻击时，每级魔咒为[基础近战攻击力](近战攻击#基础近战攻击力.md)增加每下落格数的伤害。亦即增加<math>0.5ph</math>的伤害，其中<math>h</math>为下落高度格数，<math>p</math>为魔咒等级。

致密与其任何不共存魔咒被应用在同一个物品上时，每个魔咒都会互不干扰地产生效果。
