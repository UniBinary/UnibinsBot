# Java版18w10d

*页面ID: 33995* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w10d**是[Java版1.13](Java版1.13.md)的第27个快照，发布于2018年3月9日<ref></ref>，加入了珊瑚礁，并修复了一些漏洞。

# 新内容
# = 世界生成 =
* *[珊瑚礁](珊瑚礁.md)**
* 生成于热带海洋[生物群系](生物群系.md)中。
* 由[珊瑚](珊瑚.md)和[珊瑚块](珊瑚块.md)组成。
* * 这允许珊瑚块自然生成。

# 更改
# = 方块 =
* *[水](水.md)**
* 水能放置进[末影箱](末影箱.md)、[活板门](活板门.md)、[梯子](梯子.md)和[告示牌](告示牌.md)中。
* 水不再穿过固体表面。

* *[潜影盒](潜影盒.md)**
* [潜影盒](潜影盒.md)现在能用[炼药锅](炼药锅.md)洗去染色了。
* * 对有水的炼药锅潜影盒。
* * 炼药锅中的水减少一层。

* *[珊瑚](珊瑚.md)**
* 现在会在暖水海洋生物群系自然生成了。

# = 实体 =
* *[僵尸](僵尸.md)和[僵尸村民](僵尸村民.md)**
* 幼年[僵尸](僵尸.md)和幼年[僵尸村民](僵尸村民.md)现在会在阳光下燃烧了。

* *[幻翼](幻翼.md)**
* [幻翼](幻翼.md)现在在日光中燃烧。
* * 它们不再会在白天直接消失。

# = 游戏内容 =
* *[云](云.md)**
* 大幅度改进云的渲染方式。
