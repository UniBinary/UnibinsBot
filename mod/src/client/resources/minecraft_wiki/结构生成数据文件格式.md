# 结构生成数据文件格式

*页面ID: 19238* | *来源: Minecraft Wiki*

* *Village.dat**、**Fortress.dat、Temple.dat**、**Mineshaft.dat**、**Stronghold.dat**、**Monument.dat**、**EndCity.dat**与**Mansion.dat**文件皆位于名为data的文件夹内，它们分别储存[村庄](村庄.md)、[下界要塞](下界要塞.md)、[沙漠神殿](沙漠神殿.md)&[丛林神庙](丛林神庙.md)&[沼泽小屋](结构.md)&[雪屋](雪屋.md)、[废弃矿井](废弃矿井.md)、[要塞](要塞.md)、[海底神殿](海底神殿.md)、[末地城](末地城.md)与[林地府邸](林地府邸.md)的结构生成信息。生成的结构存储在区块数据内。

# NBT结构
[Java版1.12](Java版1.12.md)的NBT结构。

请注意，以下列出的许多标签仅适用于特定的结构类型。

<div class="treeview">
* ：根标签。
* *
* **: 作用列表。
* ***：一种结构。标签名包含结构起始点方块的坐标。
* ****：结构类型的标识符。一般与文件名匹配。
* **** ：结构起始点方块的X坐标。
* **** ：结构起始点方块的Z坐标。
* **** ：整个结构的框架，有六个变量：X、Y、Z轴的最小值和最大值。
* **** ：（仅限村庄）该村庄是否生成三条非路，如果为0，该村庄事实上并没有生成。
* **** ：（仅限遗迹）已创建了结构的区块的列表。
* *****
* ****** ：区块的X坐标。
* ****** ：区块的Z坐标。
* **** ：构成该结构的分支结构列表。
* ***** ：分支结构列表。
* ****** ：分支结构的标识符。通常是代码，不是一般的人类能读懂的东西。
* ****** ：出现在某些分支结构中，用于计算这个结构会生成于相对起始点的哪个地方。
* ****** ：分支结构可能的朝向。
* ****** ：分支结构的框架，不包括可悬空在路上的村庄屋顶部分，有六个变量：最小的X、Y和Z坐标，和最大的X、Y和Z坐标。
* ****** ：（神庙和小屋）结构的宽度（X/Z）。
* ****** ：（神庙和小屋）结构的高度（Y）。
* ****** ：（神庙和小屋）结构的深度（X/Z）。
* ****** ：（神庙和小屋）该结构被移动到地形表面时移动的Y轴距离，如果它没被移动，则为-1。
* ****** ：（丛林神庙）是否生成走廊里的发射器陷阱。
* ****** ：（丛林神庙）是否生成箱子前的发射器陷阱。
* ****** ：（丛林神庙）是否生成主箱子。
* ****** ：（丛林神庙）是否生成隐藏箱子。
* ****** ：（沙漠神殿）1号箱子是否生成。
* ****** ：（沙漠神殿）2号箱子是否生成。
* ****** ：（沙漠神殿）3号箱子是否生成。
* ****** ：（沙漠神殿）4号箱子是否生成。
* ****** ：（沼泽小屋）最初的女巫是否已经生成。
* ****** ：（废弃矿井"MSCorridor"）走道内是否有铁轨。
* ****** ：（废弃矿井"MSCorridor"）走道内是否有蜘蛛网。
* ****** ：（废弃矿井"MSCorridor"）走道内是否有洞穴蜘蛛刷怪笼。
* ****** ：（废弃矿井"MSCorridor"）走道的长度。
* ****** ：（废弃矿井"MSCrossing"）交叉的地方是否有2楼。
* ****** ：（Mineshaft "MSCrossing"）指示交叉口东入口。
* ****** ：（Mineshaft "MSRoom"）出口的列表。
* ******* ：出口的包围框架。
* ****** ：（下界要塞"NeSCLT"和"NeSCRT"）这个要塞是否应该包含一个箱子，但还没有生成一个箱子。
* ****** ：（下界要塞"NeMT"）这个堡垒是否应该包含一个烈焰人刷怪笼，但还没有生成。
* ****** : (下界要塞"NeBEF"）桥的末端生成下界砖块的种子（使其看起来像是自然断裂的）。
* ****** ：（要塞）入口的门的类型。
* ****** ：（要塞"SHCC"）要塞里的箱子是否已经生成。
* ****** ：（要塞"SHFC"）走道的长度。
* ****** ：（要塞"SH5C"）五道口是否在下层楼梯向上的一侧有出口。
* ****** ：（要塞"SH5C"）五道口是否在下层楼梯向下的一侧有出口。
* ****** ：（要塞"SH5C"）五道口是否在上层楼梯向上的一侧有出口。
* ****** ：（要塞"SH5C"）五道口是否在上层楼梯向上的一侧有出口。
* ****** ：（要塞"SHLi"）图书馆是否有二楼。
* ****** ：（要塞"SHPR"）蠹虫刷怪笼是否已经在这个结构里生成。
* ****** ：（要塞"SHRC"）目标房间是否会生成一个带火把的柱子、一个喷泉、一个带箱子的二楼，还是就一个空房间。
* ****** ：（要塞"SHSD"）螺旋楼梯是要塞的入口还是随机生成的。
* ****** ：（要塞"SHS"）走道的左边是否有出口。
* ****** : (要塞"SHS"）走道的右边是否有出口。
* ****** ：（村庄）该村庄是否是沙漠村庄变种。
* ****** ：（村庄）随着村庄一起生成的村民的数量。
* ****** ：（村庄）该结构被移动到地形表面时移动的Y轴距离，如果它没被移动，则为-1。
* ****** ：（村庄"ViS"）铁匠铺里的箱子是否已经生成。
* ****** ：（村庄"ViF"和"ViDF"）村庄农田里会长什么庄稼，使用[方块](方块.md)ID决定（59=[小麦](小麦.md)，141=[胡萝卜](胡萝卜.md)，142=[马铃薯](马铃薯.md)）。
* ****** ：（村庄"ViF"和"ViDF"）村庄农田里的庄稼。
* ****** ：（村庄"ViDF"）村庄农田里的庄稼。
* ****** ：（村庄"ViDF"）村庄农田里的庄稼。
* ****** ：（村庄"ViSH"）房子是否有通往屋顶的梯子和栅栏。
* ****** ：（村庄"ViSmH"）桌子：0为没有桌子，1和2生成于屋子的一边和另一边。
* ****** ：（村庄"ViSmH"）屋顶的类型。
* ****** ：（村庄"ViSR"）路的长度。
