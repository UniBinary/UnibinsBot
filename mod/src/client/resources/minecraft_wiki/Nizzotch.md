# Nizzotch

* *Nizzotch**是一个YouTube频道，最初由[马库斯·佩尔松（Notch）](Markus Persson.md)用于分享Minecraft的开发视频。其最初创建于2008年8月11日，在2008年8月11日至2011年8月30日期间，该频道上传了39个视频（38个公开视频和1个未列出视频），其中大部分与Minecraft有关，还有一些与Notch的其他游戏相关。<ref>https://web.archive.org/web/20130925121445/http://www.youtube.com/user/Nizzotch/videos</ref><ref>https://web.archive.org/web/20200415202710/https://www.youtube.com/watch?v=9-fuwsWTL_8</ref>

Notch在[万圣节更新](万圣节更新.md)发布后停止在该频道上发布Minecraft内容，并改将更多Minecraft开发进度视频上传到另一个名为[mojnotch](https://www.youtube.com/@mojnotch)的频道和[Minecraft官方频道](https://www.youtube.com/@minecraft)。他还有一个现已删除的[*0x10<sup>c</sup>*频道](https://web.archive.org/web/20130217231320/http://www.youtube.com/channel/UCielLdGIGuEAMsbVuS-kZAg)，及一个他仍然偶尔发布游戏视频的[额外频道](https://www.youtube.com/@_notch)，这两个频道都名为“Markus Persson”。

Nizzotch频道上的所有视频在Notch离开[Mojang](Mojang.md)后被Notch提出的版权索赔屏蔽，后来被设为，因此无法在原始频道上观看。
