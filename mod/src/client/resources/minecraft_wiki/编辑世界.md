# 编辑世界

*页面ID: 155729* | *来源: Minecraft Wiki*

* *编辑世界（Edit World）**是用于编辑已有世界的菜单。多数选项均为不同的[游戏规则](游戏规则.md)。

# Java版
菜单}}
在菜单选中一个世界后，屏幕下方的按钮可用于编辑该世界。点击“”进入菜单后会提供更多选项。

# 基岩版

”选项卡}}
[thumb|默认世界缩略图](File:World preview default.jpg.md)

“编辑世界”界面允许玩家编辑已有世界的部分世界选项、启用和禁用资源包和行为包，删除、复制或导出世界。

开启作弊或[实验性玩法](实验性玩法.md)、使用任何不来自[市场](市场.md)的[附加包](附加包.md)或选择创造模式会导致该世界无法获取[成就](成就.md)。
