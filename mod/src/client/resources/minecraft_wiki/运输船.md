* *运输船（Boat with Chest）**是一种能在水体上运输实体和物品的[船](船.md)。

* *运输竹筏（Bamboo Raft with Chest）**功能与运输船相同，但有着不同的外观。

# 用途
对着方块的上表面运输船可以将其放在世界中，朝向玩家面向的方向。

不同于大多数可存储物品的方块或实体，运输船物品的名称在使用后会丢失，不会显示在运输船的交互界面中。

# = 燃料 =
运输船能用作[熔炉](熔炉.md)、[高炉](高炉.md)和[烟熏炉](烟熏炉.md)的燃料，每个运输船能烧炼6个物品。

# 行为

运输船与船拥有一些相同的行为，但运输船只能有一个乘客。

# = 物品存储 =

类似于[马](马.md)等生物，运输船有一个物品栏。如果玩家乘坐在运输船中，玩家可以通过打开来打开运输船的物品栏；如果玩家未乘坐在运输船中，则玩家可以对运输船（若运输船中没有实体，则还需处于状态）打开运输船的物品栏，其界面与箱子界面类似。运输船没有打开/关闭动画。

就像[运输矿车](运输矿车.md)一样，运输船也可以与漏斗、投掷器等方块交互。当运输船的箱子处于漏斗的上方，下方或者旁边，运输船即可与漏斗交互，如漏斗中的物品进入运输船的箱子中或箱子中的物品进入漏斗。由于运输船特殊尺寸的碰撞箱，在9个漏斗组成的3×3的区域中，只要将运输船放置于9个漏斗的正中间，运输船即可同时与9个漏斗交互。

# = 猪灵 =
在非和平[难度](难度.md)下，成年[猪灵](猪灵.md)会与附近打开或破坏运输船的玩家敌对。

# 你知道吗
* 当[沙子](沙子.md)、[红沙](红沙.md)、[混凝土粉末](混凝土粉末.md)、[沙砾](沙砾.md)、[铁砧](铁砧.md)和[龙蛋](龙蛋.md)掉落在水中的运输船上时，会变成物品形式，上述物品掉落在陆地上的运输船上的箱子部分时也会变成物品形式。
* 运输船中箱子的纹理尺寸是12×12，而不是箱子方块的14×14。而[运输矿车](运输矿车.md)中则是直接渲染了箱子方块本身。
