# Mojang披风

*页面ID: 185860* | *来源: Minecraft Wiki*

* *Mojang披风（Mojang Cape）**是2021年7月25日之前Mojang员工使用的披风。

# 描述
# = 旧版Mojang披风 =
第一代Mojang披风在2010年12月20日到2015年10月7日期间使用。少数[Mojang Studios](Mojang Studios.md)的员工拥有此披风。<ref>https://namemc.com/cape/298ae017a64261ad</ref>

# = 新版Mojang披风 =
第二代Mojang披风在2015年10月7日到2021年7月25日期间使用。部分Mojang Studios的员工拥有此披风。<ref>https://namemc.com/cape/cb5dd34bee340182</ref>
