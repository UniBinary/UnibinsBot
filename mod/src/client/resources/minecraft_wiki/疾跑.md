# 疾跑

*页面ID: 6858* | *来源: Minecraft Wiki*

* *疾跑（Sprinting）**是一种允许[玩家](玩家.md)通过消耗[饥饿](饥饿.md)来换取更快速度的[移动方式](运输.md)。

<div style="float:right"></div>

# 激活
如果要疾跑，玩家可以在移动时按下键，或者双击键。玩家无法在具有[失明](失明.md)效果或[饥饿值](饥饿值.md)小于等于时进行疾跑。按住键后立即短按一次键，或在按住键时双击键也可以开始疾跑。

玩家在水下将会尝试[速泳](速泳.md)。

[豹猫](豹猫.md)、[猫](猫.md)、[铁傀儡](铁傀儡.md)、[凋灵骷髅](凋灵骷髅.md)、幼年[僵尸](僵尸.md)、幼年[僵尸猪灵](僵尸猪灵.md)、幼年[溺尸](溺尸.md)、幼年[尸壳](尸壳.md)、幼年[僵尸村民](僵尸村民.md)、[末影人](末影人.md)和[村民](村民.md)也能像玩家一样进行疾跑。

# 用途
[125px|thumb|疾跑时地面上出现的粒子](File:Sprinting.png.md)

疾跑允许玩家以5.612米/秒的速度前进，比一般的行走速度4.317米/秒快了约30%。玩家可以在疾跑时进行转弯，但这会稍微减缓他们的速度。疾跑也会增加[飞行](飞行.md)速度，在[游泳](游泳.md)时速度也会稍微变快一点。虽然在骑乘[矿车](矿车.md)、[船](船.md)、[马](马.md)、或[猪](猪.md)时“疾跑”会像真正疾跑或喝了迅捷药水时一样增加视野，但实际速度不会提升。然而玩家在骑猪时可以给其加速。

在疾跑时，玩家的跳跃距离可以从普通的两米增加到四米，但这不会使玩家跳得更高。

疾跑会消耗玩家饥饿饱和度，饱和度将会逐渐降至0，若饱和度为0，以每40米或7秒的速度消耗。

疾跑会让玩家的脚部产生与他们脚下方块所对应的[粒子](粒子.md)。而当玩家在疾跑时攻击任何[生物](生物.md)（[鱿鱼](鱿鱼.md)除外）将会产生比平时更大的击退效果。

疾跑会在玩家停止移动、、与方块发生碰撞或在30秒后<ref group="注">如果键被按下，则疾跑将持续30秒以上。</ref>结束。疾跑也会在玩家的饥饿值降至或以下时结束。自动跳跃也会打断疾跑。

若玩家的侧面以较小的角度与方块相碰，疾跑不会停止。

疾跑时潜行、防御、喝药水或吃食物会减慢玩家的速度，但不会停止疾跑。然而，在做这些动作时按下疾跑键并不会开始疾跑。

# 你知道吗
* 一般情况下，一边疾跑一边跳跃比单纯疾跑更快。但在高级别的[迅捷](迅捷.md)效果下，这会变得更慢一些。
* 在2格高的空间中一边疾跑一边跳跃，会比单纯疾跑快几乎一倍，但这会极快地消耗[饥饿值](饥饿值.md)（每秒消耗）。
* * 在天花板或地板上放置[活板门](活板门.md)来降低通道高度或在[冰](冰.md)上疾跑能进一步提升速度。
