# 幽匿尖啸体

*页面ID: 90417* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}
* *幽匿尖啸体（Sculk Shrieker）**是一种激活后给予玩家[黑暗](黑暗.md)状态效果并最终生成[监守者](监守者.md)的[幽匿](幽匿.md)类方块。

# 生成
# = 自然生成 =
幽匿尖啸体自然生成于[深暗之域](深暗之域.md)生物群系。

# = 幽匿催发体 =

死后会掉落[经验](经验.md)的[生物](生物.md)在距[幽匿催发体](幽匿催发体.md)半径/内的位置死亡时，周围的[幽匿块](幽匿块.md)上有1%的概率生成幽匿尖啸体，每次生成消耗1点经验。

# 获取
幽匿尖啸体的物品形式只能通过使用具有[精准采集](精准采集.md)的工具挖掘破坏幽匿尖啸体获得。

# 破坏
挖掘幽匿尖啸体的合适工具是锄。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，幽匿尖啸体被破坏后会掉落。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，幽匿尖啸体被破坏后会掉落自身。

# 用途
幽匿尖啸体可[含水](含水.md)。

根据[方块状态](方块状态.md)<code>can_summon</code>的不同，幽匿尖啸体具有不同的行为。
* 在世界生成期间自然生成的幽匿尖啸体，其<code>can_summon</code>值为<samp>true</samp>，顶部的旋转纹理更亮，旋转速度更快，且沿顺时针旋转，能够给玩家施加[黑暗](黑暗.md)状态效果并最终生成[监守者](监守者.md)。
* 由玩家手动放置或由[幽匿催发体](幽匿催发体.md)生成的幽匿尖啸体，其<code>can_summon</code>值为<samp>false</samp>，顶部的旋转纹理偏暗，旋转速度较慢，且沿逆时针旋转，不可给予玩家黑暗状态效果及生成监守者。

使用命令true]}}或true]}}可以在玩家脚下放置一个<code>can_summon</code>值为<samp>true</samp>的幽匿尖啸体。

# = 激活 =
幽匿尖啸体必须由玩家直接或间接激活。下列实体在满足条件时可以激活幽匿尖啸体：
* 玩家本身
* 玩家正在[骑乘](骑乘.md)的实体
* 由玩家投掷或发射的[弹射物](弹射物.md)
* 由玩家丢出的[物品实体](物品实体.md)

幽匿尖啸体有2种激活途径：
* 被上述实体直接踩踏时激活。
* [幽匿感测体](幽匿感测体.md)或[校频幽匿感测体](校频幽匿感测体.md)被上述实体（不包括[羊毛](羊毛.md)和[地毯](地毯.md)的物品实体）激活时，会传递信号给半径8格内未被羊毛阻挡的幽匿尖啸体，将其激活。

对于<code>can_summon</code>值为<samp>true</samp>的幽匿尖啸体，其在满足下列任一情况下时不能被激活：
* 幽匿尖啸体周围24格内存在监守者。
* 激活幽匿尖啸体的玩家的监守者计时器处于冷却状态，或幽匿尖啸体周围16格内有非[旁观模式](旁观模式.md)玩家的监守者计时器处于冷却状态。

如果[难度](难度.md)为和平，或游戏规则为<samp>false</samp>，那么<code>can_summon</code>值为<samp>true</samp>的幽匿尖啸体的激活不受上述条件约束，但此时不会给予黑暗效果及生成监守者。

[缩略图|右|幽匿尖啸体产生的粒子|class=pixel-image](File:Shriek.png.md)
幽匿尖啸体激活后会立即发出尖啸声，持续，并在顶部产生环状呼啸粒子。含水的幽匿尖啸体不会发出尖啸音效。

# = 生成监守者 =
如果幽匿尖啸体的<code>can_summon</code>值为<samp>true</samp>，为<samp>true</samp>，且难度不为和平，则其在尖啸时会同时计算玩家的警告等级，即使尖啸过程中该幽匿尖啸体被破坏也不会影响玩家警告等级计算。激活幽匿尖啸体的玩家和幽匿尖啸体周围16格的非旁观模式玩家都被认为是参与了这次激活的玩家，这些玩家的最大警告等级+1就是这次激活的警告等级。警告等级不会大于4，如果原先的警告等级已经到4则不会继续增加。所有参与这次激活的玩家的警告等级会被设置为这次激活的警告等级，并会获得的冷却时间，在此期间内这些玩家不能再次激活幽匿尖啸体。

在尖啸完毕后，系统会播放监守者警告音效或生成监守者，同时对周围40格内不存在黑暗状态效果或黑暗状态效果剩余时间小于的[生存](生存.md)或[冒险](冒险.md)模式玩家施加的黑暗状态效果。如果警告等级为1-3，则会播放警告音效，警告音效在[字幕](字幕.md)中分别表现为“”“”和“”。如果警告等级为4，则尝试在其周围11×13×11空间内下方方块上表面完整的位置生成监守者，如果尝试20次仍然没有找到合适的位置生成监守者，那么只会播放监守者的咆哮声。

当玩家不参与激活幽匿尖啸体时，玩家的警告等级每降低一级直到为0。
