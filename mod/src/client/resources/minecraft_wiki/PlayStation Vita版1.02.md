# PlayStation Vita版1.02

*页面ID: 82893* | *来源: Minecraft Wiki*

* *1.02**是[PlayStation Vita版](PlayStation Vita版.md)的一次更新，发布于2014年10月24日。

# 新内容
# = 常规 =
* *DLC**
* 支持限时附加内容。

# 修复
* *修复了5个漏洞**
* 修复了重置下界后保存游戏的崩溃。
* 修复了保存并退出后存档数据损坏的漏洞。
* 修复了存档转移后重新加载存档后玩家物品丢失的漏洞。
* 修复了下界传送门的图形问题。
* 修复了存档转移后主机选项未保存的漏洞。
