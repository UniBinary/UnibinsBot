# 基岩版1.16.0.60

*页面ID: 61884* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.0.60**是[基岩版1.16.0](基岩版1.16.0.md)的第12个测试版，发布于2020年5月7日<ref></ref>，修复了一些漏洞。

# 更改
# = 命令格式 =
* ***
* 现在可以杀死生成的[NPC](NPC.md)。（）

# 修复
* *崩溃**
* 修复一些与图形有关的崩溃。
* 修复了未登录状态下购买Minecoin的崩溃问题。
* 修复了使用“ZigZag”资源包创建世界时的崩溃问题。

* *图形**
* Windows 10上可以再次应用精美树叶选项了。
* 修复了更换资源包时立方贴图没有正确更新的问题。
* 修复了有时退出主菜单后字体消失的问题。
* 修复了玩家上方的用户名闪烁的问题。
* 修复了调整能见度后区块闪烁的问题。
* 修复了丢失的纹理一直被转换的问题，此问题会往日志中不断发送垃圾信息。
* 翻译了“线上游戏未分级”窗口。

* *常规**
* 将默认的聊天字体设置为“Mojangles”。（）

* *市场**
* 修复了某些平台上缩略图无限加载的问题。
* 修复了下载进度条不会正确显示的问题。</onlyinclude>
