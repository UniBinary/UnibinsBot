# Java版1.15.1-pre1

*页面ID: 50574* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.15.1-pre1**是[Java版1.15.1](Java版1.15.1.md)的唯一一个预发布版，发布于2019年12月12日<ref></ref>，优化了游戏性能，并修复了一些漏洞。

# 更改
# = 生物 =
* *[蠹虫](蠹虫.md)**
* 被[爆炸](爆炸.md)摧毁的虫蚀方块不再生成蠹虫。

# = 常规 =
* *性能**
* 优化了[区块](区块.md)的渲染性能，特别是对于拥有很多不同的[方块](方块.md)状态的区块。
* 改进了无效的[生物群系](生物群系.md)ID的网络处理。

# 修复
空指针异常。
|;1.15的漏洞
|167482|损坏的区块导致强制更新世界失败。
|167530|铁砧导致<code>java.lang.StackOverflowError</code>错误。
}}
* *其他漏洞**
* 修复了一个由自定义刷怪笼生成村民导致的滥发到游戏的日志文件的错误。
* 修复了Realms界面崩溃的问题。</onlyinclude>
