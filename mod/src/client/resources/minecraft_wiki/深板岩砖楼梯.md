# 深板岩砖楼梯

*页面ID: 79567* | *来源: Minecraft Wiki*

* *深板岩砖楼梯（Deepslate Brick Stairs）**是[深板岩砖](深板岩砖.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
深板岩砖楼梯会自然生成在[远古城市](远古城市.md)中。

# 破坏
挖掘深板岩砖楼梯的合适工具是镐。深板岩砖楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

深板岩砖楼梯被破坏后会掉落自身。
