# 动画宣传片

*页面ID: 181856* | *来源: Minecraft Wiki*

* *动画宣传片（cinematics，也被称为“电影艺术”）**是[Mojang Studios](Mojang Studios.md)发布，通常用于宣传游戏版本更新或特定事件的动画视频。

# 更新宣传片
更新宣传片通常在主要更新或[小更新](小更新.md)发布当日同步上线Minecraft社交媒体平台，通过动画展示版本更新内容。

# 更新艺术片
更新艺术片通常在[Minecraft Live](Minecraft Live.md)时发布，通过音乐与剧情等形式回顾上次更新或更新特定内容，或为下次更新预热。

# 事件宣传片
事件宣传片通常为预热特定事件或活动发布，如[Minecraft Live](Minecraft Live.md)与[15周年庆](15周年庆.md)等。

# 年度总结
年度总结通常在年末发布，总结一年中的Minecraft玩家数据。
