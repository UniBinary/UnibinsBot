# Java版Infdev 20100624

*页面ID: 35977* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年6月24日，修复了一些漏洞。<ref></ref>

# 新内容
# = 非生物实体 =
* *[矿车](矿车.md)**
* 可乘坐且无法被开启的矿车。

# = 常规 =
* *[控制](控制.md)**
* 按下会显示性能图表。

# 更改
# = 方块 =
* *[羊毛](羊毛.md)**
* 移除了除了白色羊毛以外的所有羊毛。
* 白色羊毛的ID由36改为35。

* *[无限水源](无限水源.md)和[无限熔岩源](无限熔岩源.md)**
* 被移除。
* * 世界中仍然存在的ID为52或53的方块或物品在被加载时会导致游戏崩溃。

* *[铁轨](铁轨.md)**
* 调整了铁轨铺设代码。

# = 物品 =
* *[矿车](矿车.md)**
* 更改了纹理。

# = 生物 =
* *[羊](羊.md)**
* 现在掉落白色羊毛。

# = 世界生成 =
* *常规**
* 更改了世界生成器，以避免山过高从而被高度限制切断。

# = 常规 =
* *存档功能**
* 新的储存文件格式。
* * 储存得到的世界文件巨大。

* *[崩溃](崩溃.md)**
* 新的崩溃报告画面。

# 修复
* *修复了2个漏洞**
* 更佳FPS。
* 更少崩溃。</onlyinclude>
