# 携带版0.8.0.b3

*页面ID: 31517* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.8.0 alpha build 3**是[v0.8.0 alpha](携带版0.8.0.md)的第3个测试版，发布于2013年11月26日，修复了一些漏洞。

# 更改
# = 方块 =
* *[铁轨](铁轨.md)**
* 其下方的方块被破坏时，铁轨会掉落自身。

# = 物品 =
* *[马铃薯](马铃薯.md)、[胡萝卜](胡萝卜.md)和[甜菜根](甜菜根.md)**
* 现在将草方块转化为耕地时会有的概率掉落上述植物了。

* *[画](画.md)**
* 现在有了新的渲染方式。

* *[鸡蛋](鸡蛋.md)**
* 扔[鸡蛋](鸡蛋.md)会生成幼年[鸡](鸡.md)了。

# = 生物 =
* *[蜘蛛](蜘蛛.md)**
* 减慢了[蜘蛛](蜘蛛.md)移动速度。

# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 更改为“Armor/Crafting”界面以便回到物品栏。

* *[创造模式物品栏](创造模式物品栏.md)**
* 在创造模式物品栏中加入了[基岩](基岩.md)、[剪刀](剪刀.md)和[染料](染料.md)。

# 修复

* *其他**
* 修复了无法喂食或繁殖羊。
* 修复了具有随机旋转纹理的基岩。
* 修复了画的阴影。
* 修复了打火石具有无限耐久。
* 修复了砂岩和红石粉的纹理。</onlyinclude>
