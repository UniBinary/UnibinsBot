# New Nintendo 3DS版1.5.25

*页面ID: 39522* | *来源: Minecraft Wiki*

* *1.5.25**是[New Nintendo 3DS版](New Nintendo 3DS版.md)发布于2018年6月5-6日的一次更新，加入了新的DLC、砂土和染色玻璃。<ref></ref>

# 新内容
# = 方块 =
* [砂土](砂土.md)
* [染色玻璃](染色玻璃.md)

# = 常规 =
* Super Mario混搭包
* Cartoon和Fantasy纹理包
* Campfire Tales、City Folk和Town Folk皮肤包

# 更改
* 改进了稳定性和性能。

# 修复
* 修复了此前版本的一些漏洞。
