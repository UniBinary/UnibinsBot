# PlayStation 4版1.95

*页面ID: 59645* | *来源: Minecraft Wiki*

* *1.95**是[PlayStation 4版](PlayStation 4版.md)的一个更新，发布于2019年9月9日。修复了一些漏洞。<ref></ref>

# 更改
# =方块=
* *[木头](木头.md)**
* 现在可以合成[木板](木板.md)（）。

* *[红石粉](红石粉.md)**
* 现在可以放在[玻璃](玻璃.md)上（）。

# 修复
* *修复了5个漏洞**
* 修复了把按钮放置在门的顶部时发生的崩溃。
* 修复浏览烟花合成界面时发生的崩溃。
* 修复了石匠出售雕纹石砖的价格错误（）。
* 修复了当铁轨下面的方块被破坏时，铁轨不会掉落的漏洞（）。
* 修复了石匠村民购买带釉陶瓦而不是出售的漏洞。
