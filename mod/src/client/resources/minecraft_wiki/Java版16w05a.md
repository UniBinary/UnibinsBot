# Java版16w05a

*页面ID: 19921* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w05a**是[Java版1.9](Java版1.9.md)的第52个快照，发布于2016年2月3日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[陷阱箱](陷阱箱.md)**
* 合成配方现在是无序的。

# = 常规 =
* *[服务端](服务端.md)**
* 从这个版本开始不再提供的服务端了。
