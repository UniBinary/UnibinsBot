# MINECON Earth 2017

*页面ID: 32251* | *来源: Minecraft Wiki*

[thumb|MINECON Earth 2017的动画徽标](File:MINECON_Earth.gif.md)

* *MINECON 2017**是于2017年11月18日，在Livestream平台上以互动形式举行的一次直播，时长为90分钟，标题为**MINECON Earth**。其于2017年8月8日被宣布。<ref></ref>[Lydia Winters](Lydia Winters.md)和[Will Arnett](wikipedia:Will Arnett.md)担任该次直播的主持人。直播流前后各有一个预热活动和展后总结，以YouTubers的参与为特色，如[Logdotzip](https://www.youtube.com/user/Logdotzip)和[TrueTriz](https://www.youtube.com/user/TrueTriz)。

# 社区活动
与此同时，MINECON Earth被宣布为官方社区活动，由社区主导的合作伙伴Minefaire，minevention和blockfest举办。他们（与更多人一同前来）受到了官方的认可，来分享他们的Minecraft亲手经历。参与者遇见他们喜爱的YouTuber和streamer，参加游戏联赛和服装竞赛，并看到一些独特的东西等。<ref></ref>

# 活动
# = 生物投票 =
[缩略图|4个选项中有1个新生物被投票选入游戏](File:MINECON 2017 new mob.jpg.md)
观众会在4个选项（绘画）中投票选出1个会加入游戏的新生物。观众可通过发信息或者在网页上投票，而其他3个没有赢得投票的生物被“永久弃置”。<ref></ref>

# == 生物A ==
[缩略图|左|生物A草图](File:MINECON 2017 Mob A.jpg.md)
* *深海之怪（The Monster of the Ocean Depths）**，亦称**藤壶（The Barnacle<ref></ref>）**一种会用触手-{}-把玩家拉走的海洋生物。该生物生成在深海[生物群系](生物群系.md)中，并有一个大嘴，用于移动。[Jeb](Jeb.md)的推荐理由：目前海洋中没有太多的内容，对于航海的玩家而言，这是一个极好的挑战。第一轮投票后，生物A被淘汰。<ref></ref>

# == 生物B ==
[缩略图|左|生物B草图](File:MINECON 2017 Mob B.jpg.md)

* *夜空之怪（The Monster of the Night Skies）**，一种会寻找并攻击在夜晚很久没有睡觉的玩家的一种飞行生物。该生物生成在高空中，且常常结群攻击，Jeb的推荐理由：目前主世界中还没有一个会飞的怪物。<ref></ref>生物B赢得选票，并最先在[Java版1.13](Java版1.13.md)的快照[18w07a](18w07a.md)中加入游戏，名为幻翼。

# == 生物C ==
[缩略图|左|生物C草图](File:MINECON 2017 Mob C.jpg.md)
* *超级饥渴（The Great Hunger）**，是一种像蜥蜴，会钻入地下的生物，也会伪装自己，甚至还会用自己的大口烧死生物。该生物“对于[魔力](魔咒.md)有着极大的欲望”。Jeb的推荐理由：玩家可以使用生物C的能力来添加或移除玩家的物品魔咒。第三轮投票后，生物C被淘汰，其能力可能应用于[Java版1.14](Java版1.14.md)中加入的[砂轮](砂轮.md)。<ref></ref>

# == 生物D ==
[缩略图|左|生物D草图](File:MINECON 2017 Mob D.jpg.md)
* *盘旋地狱（The Hovering Inferno）**，一种[烈焰人](烈焰人.md)。身体部分看起来像盾牌，用于抵挡伤害。该生物随机生成在[下界](下界.md)中的一群烈焰人之中，会用危险的冲击波攻击玩家。Jeb的推荐理由：这让下界变得“更毛骨悚然，更激动人心”。第二轮投票后，生物D被淘汰。<ref></ref>

生物D最终在 [1.14.1.0](MCD:1.14.1.0.md)中作为小Boss加入，名为[野火](MCD:野火.md)（Wildfire）。

# == 结果 ==
在活动举行了30分钟后，生物A失去选票，被淘汰。30分钟后，生物D也被淘汰。在接下来的20分钟后，淘汰了生物C。生物B赢得投票，并与水域更新一同正式发布。生物B已与Java版和原主机版的[水域更新](水域更新.md)和[基岩版1.6.0](基岩版1.6.0.md)一起发布。
