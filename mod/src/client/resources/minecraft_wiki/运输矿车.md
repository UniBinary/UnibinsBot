# 运输矿车

*页面ID: 6992* | *来源: Minecraft Wiki*

* *运输矿车（Minecart with Chest）**是一种里面装着[箱子](箱子.md)的[矿车](矿车.md)。

# 获取
运输矿车实体可以被回收来获取其物品。

# = 自然生成 =

运输矿车自然生成在[废弃矿井](废弃矿井.md)里。

# 用途
对着[铁轨](铁轨.md)按下就可以放置运输矿车。

可以通过对运输矿车按下来查看矿车存储的内容。与矿车互动时，既不会发出声音，也不会显示打开/关闭箱子的动画。

运输矿车通过[动力铁轨](动力铁轨.md)获得的加速取决于它们所装载内容的数量。例如，从1个动力铁轨加速一个空的运输矿车可以让它运行64格，但是满的运输矿车只会运行16格。（与空的普通矿车运行8格和装载着的普通矿车运行80格相反）

运输矿车的另外一个物理性质是可以堆叠。在同样的区域里，只能存放3个箱子的地方最多可以放上4个运输矿车。

[红石比较器](红石比较器.md)可以检测[探测铁轨](探测铁轨.md)上的运输矿车存储物品的数量。

# = 猪灵 =
在非和平[难度](难度.md)下，成年[猪灵](猪灵.md)会与附近打开或破坏运输矿车的玩家敌对。

# = 圣诞节 =
[right|150px](File:Minecart_with_Xmas_chest_JE.png.md)

每年12月24日至26日，运输矿车的纹理会变为圣诞节礼物包裹纹理。由于游戏会读取电脑数据，玩家可以通过更改游戏文件和时间来看到圣诞节纹理。
