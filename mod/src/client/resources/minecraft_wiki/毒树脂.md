# 毒树脂

*页面ID: 138043* | *来源: Minecraft Wiki*

* *毒树脂（Toxic Resin）**是一种可在[制箭台](制箭台/24w14potato.md)中转换为[琥珀宝石](琥珀宝石.md)的物品。

# 获取
# = 挖掘 =
当使用未带有[精准采集](精准采集.md)魔咒的[锄](锄.md)挖掘[树脂矿石](树脂矿石.md)时会掉落1个杂质为“气泡”，清晰度为“糟糕”（概率）、“暗淡”（概率）或“终极”（概率）的毒树脂。

# = 制箭台 =
毒树脂可在制箭台中升高清晰度、随机更改杂质。

# = 烧炼 =
烧炼[毒马铃薯油](毒马铃薯油.md)可获得杂质随机、清晰度为“糟糕”的毒树脂。

毒树脂的烧炼时间为，比普通物品更快。

# 用途
# = 属性 =
毒树脂拥有2个属性：“清晰度”（Clarity）和“杂质”（Impurities），每个属性都有随机的修饰符。游戏中总共有160种不同的组合。这些修饰符会随机分配给每个毒树脂。

毒树脂有10个清晰度种类，从低到高依次为：
* 糟糕（Abysmal）
* 瑕疵（Blemished）
* 暗淡（Clouded）
* 钝感（Dull）
* 终极（Eventual）
* 模糊（Faint）
* 微光（Glimmering）
* 朦胧（Hazy）
* 冰状（Icy）
* 宝石（Jewel）

毒树脂有16个杂质种类：
* 气泡（Air Bubble）
* 虫子（Bug）
* 药物（Chemical）
* 闪长（Diorite）
* 末影（Ender）
* 鱼腥（Fishy）
* 银河（Galactic）
* 蜂蜜（Honey）
* 昆虫（Insect）
* 神灵（Jinn）
* 海妖（Kraken）
* 月球（Lunar）
* 金属（Metallic）
* 下界（Nether）
* 有机（Organic）
* 色素（Pigment）

通过创造模式物品栏和获得的未指定属性的毒树脂默认为“糟糕”清晰度和“气泡”杂质。

# = 制箭 =
毒树脂可在制箭台中升高一个清晰度等级并随机更改杂质。当毒树脂的清晰度达到“宝石”时，其总是会转换为琥珀宝石。
