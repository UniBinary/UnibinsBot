* *女巫（Witch）**是一种会投掷[喷溅药水](喷溅药水.md)、饮用[药水](药水.md)的敌对生物。

# 生成
# = 自然生成 =
女巫会在[主世界](主世界.md)中[内部天空光照](亮度#内部天空光照.md)小于等于7，且[方块光照](亮度#方块光照.md)为0的[可生成位置](生成#可生成位置.md)上生成，[蘑菇岛](蘑菇岛.md)和[深暗之域](深暗之域.md)除外。

女巫不会在[河流](河流.md)、[冻河](冻河.md)和[雪原](雪原.md)生成。<ref></ref><ref></ref>

# = 沼泽小屋 =
在世界生成时，一个女巫和一只未驯服的[黑猫](黑猫.md)固定生成于[沼泽小屋](沼泽小屋.md)的红色蘑菇盆栽前，它们不会自然消失。且世界生成后若指定区域的[亮度](亮度.md)等级为0，那么-{}-女巫就会不断地生成：

女巫在沼泽小屋7×7×9格的区域内<ref group="注">X×Y×Z。X轴与Z轴为整个屋顶的范围再向门口平台延伸1格，Y轴从小屋地板下方一格开始算起。</ref>周期性生成。

女巫只会在沼泽小屋的某一点上<ref group="注">红色蘑菇盆栽一侧与门口一侧的角落2×2格的中心。</ref>周期性生成。生成范围是屋内地板上下总共3格的区域，女巫在此范围内最高可生成位置的西北角处生成。可生成位置需要至少2×2×2的空间，该空间内任何阻碍其碰撞箱检测的方块都会抑制生成，树叶、玻璃等不阻碍其碰撞箱检测的方块则不会阻碍生成，但生成点上方一格必须满足空气检测。生成的女巫类似自然生成的生物，可能会自然消失。

# = 村民 =
在非和平[难度](难度.md)下，位于[闪电](闪电.md)半径3格内的[村民](村民.md)会变成女巫，无论是否成年。通过这种方式生成的女巫不会自然消失。

# = 袭击 =
女巫可以在普通和困难[难度](难度.md)的[袭击](袭击.md)中生成。

无论是何种方式生成的女巫，参与袭击且袭击失败后，都会因为区块卸载而消失。

# 行为

女巫常使用I级[喷溅药水](喷溅药水.md)进行攻击，饮用普通[药水](药水.md)进行防御。

女巫会主动攻击半径或内的[玩家](玩家.md)、，铁傀儡和雪傀儡会主动攻击女巫。女巫受到攻击时会进行反击，女巫不会反击[恶魂](恶魂.md)、。

无论是否在袭击中，敲[钟](钟.md)都会对钟的位置半径48格内的女巫施加的[发光](发光.md)效果。

女巫可以透过[方块](方块.md)定位目标。

袭击中的女巫在袭击失败后会跳跃并欢呼以庆祝胜利。然而袭击失败后，参与袭击的女巫仍具有袭击行为，这可能导致其无法正确地欢呼。

女巫不属于[灾厄村民](灾厄村民.md)，<ref name="MC-182733"></ref>也不会主动攻击[村民](村民.md)和[流浪商人](流浪商人.md)。<ref name="MC-139947"></ref>

# = 投掷药水 =
每种药水以或的间隔投掷。列表中若多个药水的条件满足，则在列表中靠前的药水会被使用。

女巫在攻击亡灵生物时也会使用和，即使这些药水对亡灵生物毫无伤害。<ref name="quote"></ref>被瞬间伤害效果影响的亡灵生物会正常恢复生命值。

# = 饮用药水 =
每一个AI[刻](刻.md)（0.05秒），若女巫没有在饮用[药水](药水.md)，它们可以选择装备并饮用一瓶药水。女巫饮用一瓶药水需要1.6秒，它们在此期间不会攻击。

# = 受伤害行为 =
女巫受到的[魔法伤害](伤害#魔法伤害.md)、[荆棘](荆棘.md)伤害、[守卫者](守卫者.md)尖-{}-刺伤害、降低85%。

# 你知道吗
* 尽管女巫可以作为[袭击](袭击.md)事件中的成员生成，它们并不属于[灾厄村民](灾厄村民.md)。开发者[Cory Scheviak](Cory Scheviak.md)说它们“只是跟着凑热闹而已”。<ref name="MC-182733"/>
* * 因此它们不会攻击[村民](村民.md)<ref name="MC-139947"/>和[流浪商人](流浪商人.md)，。
* 如果一个女巫投掷的喷溅药水击中了另一个女巫，那么被击中的女巫就会进行反击。然而，两个相互敌对的女巫在没有玩家介入的情况下是极难死亡的，因为它们会不停饮用治疗药水，而且魔法抗性消除了大部分伤害。
* 女巫会在受伤时饮用治疗药水，因此[窒息](窒息.md)和[仙人掌](仙人掌.md)带来的伤害很难杀死女巫。
* 在不使用抢夺魔咒效果杀死女巫时，女巫掉落的物品达到最大数量（6个）的概率是（1.2%）。
* 当女巫在喝药水时，它们的鼻子会向上举起并指向前方。女巫空闲时鼻子会轻微地摆动。
* 当玩家提起女巫会掉落与酿造毫无关系的木棍的疑问时，[Dinnerbone](Dinnerbone.md)开玩笑地回应：这是因为女巫是木头做的<ref></ref>。他后来解释说<ref></ref>这是对电影[《巨蟒与圣杯》](Wikipedia:Monty Python and the Holy Grail.md)一个[场景](https://www.youtube.com/watch?v=dtDUmD9MYNg)的引用。
* 女巫的原型为俄罗斯民间传说的[芭芭雅嘎](wzh:芭芭雅嘎.md)。据传说，她的住处是一间长有鸡脚的小屋，而[沼泽小屋](沼泽小屋.md)就是仿照该风格制作的。<ref></ref>
* 女巫的鼻子上有一个突出的小像素块，被认为是一颗痣。
