# Java版17w06a

*页面ID: 27393* | *来源: Minecraft Wiki*

<onlyinclude>

* *17w06a**是[Java版1.12](Java版1.12.md)的首个快照，发布于2017年2月8日<ref></ref>，加入了首批[多彩世界更新](多彩世界更新.md)的特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[混凝土](混凝土.md)**
* 有16种不同的颜色。
* 混凝土粉末与水接触时会固化成混凝土。

* *[混凝土粉末](混凝土粉末.md)**
* 有16种不同的颜色。
* 受重力的影响（像沙子和沙砾）。
* 当它接触水时会变成混凝土。
* 由4个沙子、4个沙砾以及合成表中间任意一个[染料](染料.md)合成8个混凝土粉末方块，可无序合成。

* *[带釉陶瓦](带釉陶瓦.md)**
* 有16种不同染料的颜色。
* 将任何染色硬化黏土在熔炉里烧制可以获得该颜色的带釉陶瓦。
* 可以以4个方向放置：北，南，西，东。
* * 当以正确的方向放置时，可以创造出一个固定的图案。例如，4个黄色带釉陶瓦正确放置时可创造出一个太阳的图案。

# = 常规 =
* *[创造模式](创造模式.md)**
* 可以使用/ 保存物品栏，则可以加载保存的物品栏。
* * 最多可以保存9个物品栏。
* * 如果尝试保存一个空物品栏，它将清除已保存在工具栏中的物品栏，并在相应的方格中放回“信息纸”。

# 更改
# = 方块 =
[缩略图|右|250px|17w06a之前和之后的旗帜颜色的比较图片由[[Jeb](File:BannersBeforeAndAfter.png.md)发布。<ref></ref>]]

* *[羊毛](羊毛.md)**
* 新的配色纹理。

* *[旗帜](旗帜.md)**
* 新的配色纹理。

* 现在将尝试在可用空间中放置可能最大的大小。

* 火在其上可以持续燃烧，就像在下界岩上一样。

* 当处于非敌对状态的[僵尸猪人](僵尸猪人.md)在附近时可以睡觉。

* 更改了光柱的颜色。

* *[绵羊](绵羊.md)**

* *[狼](狼.md)**
* 项圈有了新的配色纹理。
