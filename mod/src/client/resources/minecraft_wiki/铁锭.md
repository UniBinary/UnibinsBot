# 铁锭

*页面ID: 5772* | *来源: Minecraft Wiki*

* *铁锭（Iron Ingot）**是一种用途广泛的金属合成材料，可以通过冶炼[铁矿石](铁矿石.md)、[深层铁矿石](深层铁矿石.md)或[粗铁](粗铁.md)获得。

# = 治疗铁傀儡 =
对铁傀儡1个铁锭能恢复它的生命值。

# = 信标 =
铁锭可用于从[信标](信标.md)中选择并激活状态效果。玩家必须选择一种可用的状态效果，然后在物品槽中放入一个铁锭。

铁锭可以代替[绿宝石](绿宝石.md)、[金锭](金锭.md)、[钻石](钻石.md)或[下界合金锭](下界合金锭.md)为信标选择状态效果。
