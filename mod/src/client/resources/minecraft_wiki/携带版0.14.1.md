# 携带版0.14.1

*页面ID: 20761* | *来源: Minecraft Wiki*

* *v0.14.1 alpha**是携带版的一次次要更新，在Windows 10和Android上发布于2016年4月5日，在iOS和FireOS上发布于4月6日，而在Windows Phone上发布于4月7日，加入了*[Minecraft: Story Mode](Minecraft: Story Mode.md)*的皮肤，并修复了一些漏洞。

# 新内容
# == [皮肤包](皮肤包.md) ==
* 添加Minecraft: Story Mode皮肤包。

# 更改
* 加载世界时不再显示“Generating World”，只显示“Building Terrain”了。

# 修复

* *其他**
* 修复了所有楼梯的光照问题。
* 使用重命名过的物品合成时会被用完了。

# 你知道吗
* 这是最后一个支持iOS 5的版本。
