* *刷怪笼（Monster Spawner）**是可以生成[实体](实体.md)的[方块](方块.md)，内含一个缩小并旋转着的实体模型。

# 生成
# = 自然生成 =
刷怪笼可在以下结构和地物中自然生成，实体的种类取决于所在的结构或地物：
;[地牢](地牢.md)
  可能是一个[僵尸](僵尸.md)刷怪笼（50%概率）、[骷髅](骷髅.md)刷怪笼（25%概率）或[蜘蛛](蜘蛛.md)刷怪笼（25%概率）。
;[废弃矿井](废弃矿井.md)
  被[蜘蛛网](蜘蛛网.md)环绕的[洞穴蜘蛛](洞穴蜘蛛.md)刷怪笼。
;[林地府邸](林地府邸.md)
  很小概率会生成一座内部具有被[蜘蛛网](蜘蛛网.md)环绕的[蜘蛛](蜘蛛.md)刷怪笼的[小房间](林地府邸/结构/战利品房间#蜘蛛房.md)。
;[要塞](要塞.md)
  [蠹虫](蠹虫.md)刷怪笼，位于[末地传送门](末地传送门.md)房间。每个要塞只有1个。
;[下界要塞](下界要塞.md)
  [烈焰人](烈焰人.md)刷怪笼，位于有楼梯引领上去的瞭望台上。每个下界要塞一般有2个。
;[堡垒遗迹](堡垒遗迹.md)
  [岩浆怪](岩浆怪.md)刷怪笼，被[铁链](铁链.md)挂在藏宝室的天花板上。只会生成在堡垒遗迹的藏宝室，并且只有1个。

# 获取

刷怪笼无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，刷怪笼可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
挖掘刷怪笼的合适工具是镐。刷怪笼需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

刷怪笼被破坏后会掉落15-43点[经验](经验.md)。

# 用途
非自然生成的刷怪笼默认为空，可对着刷怪笼[刷怪蛋](刷怪蛋.md)来设置或改变要生成的生物类型，但不会写入刷怪蛋中生物的附加数据。

和平[难度](难度.md)下，刷怪笼生成的任何敌对生物都会在它们生成后立刻消失，而[僵尸猪灵](僵尸猪灵.md)和[恶魂](恶魂.md)完全不会生成。

若游戏规则为<code>false</code>，刷怪笼无法运作并生成生物。

# = 机制 =
[thumb|俯视视角下，刷怪笼生成生物的范围（为白色+红色羊毛区域，为白色羊毛区域）](File:Spawnerrange.png.md)
玩家距离刷怪笼16个方块内时（含刷怪笼），刷怪笼才会运作。刷怪笼运作时，会在一个以刷怪笼为中心的空间体积内生成对应实体，实体的底面中心点会在这个区域内。这个空间体积范围为垂直距离1格、水平[切比雪夫距离](切比雪夫距离.md)4格；这个空间体积范围为垂直距离1格、水平[曼哈顿距离](曼哈顿距离.md)4格<ref></ref>。

刷怪笼内有一个微缩的实体模型，在激活时会逆时针旋转，旋转速度与下一次将要生成的时间有关，最大速度可以达到16.7RPM。其中旋转的生物可能会穿着[盔甲](盔甲.md)、也可能携带[不祥旗帜](不祥旗帜.md)。

刷怪笼方块会尝试在这个有效区域内随机选择的4个位置（作为实体的脚部坐标）分别尝试生成1个实体，每次生成后会等待200-799游戏刻（10-39.95秒）。在等待时，刷怪笼中的实体模型的旋转速度会加快。除了可生成方块地面这一常规生成要求不需要被满足，生物的其他生成要求必须要满足（见下文[生成需求](#生成需求.md)），因此刷怪笼常常不能生成超过4个实体。当刷怪笼生成了实体时，它会产生烟雾和火焰[粒子](粒子.md)效果。如果刷怪笼在有效区域内找不到任何符合要求的位置生成实体，则每一[刻](刻.md)都会尝试一次。

如果6个或更多刷怪笼类型的实体的碰撞箱或，那么刷怪笼内会产生火焰粒子（表示已经“生成”了新的实体），但实际上生成过程被跳过，进入下一个周期。这在4次尝试生成之前都会检查。

实体更有可能生成在靠近刷怪笼而不是远离刷怪笼的地方。

# == 生成需求 ==
刷怪笼会去除对地面必须为可生成方块的生成需求，但实体的其他生成需求（碰撞箱、亮度）仍需要满足。也就是说，对于一些在生成区域边缘生成的实体来说，必须远离方块的[碰撞箱](碰撞箱.md)以确保可以容纳实体的高度和宽度。

对于表中所有列出的生成区域，其水平面是以刷怪笼方块为中心的。虽然猪的不产生碰撞的需求区域是8.9×2.9×8.9，，导致实际成功生成区域的大小减小到8.9×0.9×8.9。生成不要求脚下方块的生物可以生成在空中，忽略对地面的普通生成规则。

刷怪笼生成生物时无视[生物群系](生物群系.md)指定的自然生成生物，大部分生物的生成需求也不含生物群系，所以刷怪笼可以把生物放置在它们不会正常生成的地方。处于[蘑菇岛](蘑菇岛.md)生物群系的刷怪笼能生成敌对生物，[虚空](虚空（生物群系）.md)生物群系中的刷怪笼也能正常生成任何生物。同时，[哞菇](哞菇.md)刷怪笼在平原生物群系里，只要生成区域有[菌丝体](菌丝体.md)，那么哞菇刷怪笼就会生成哞菇。刷怪笼只有任意一面接触[水源](水源.md)才可以生成[鱼](鱼.md)。

刷怪笼的运作不受[游戏规则](游戏规则.md)的影响，也不受生成上限的影响。

# == 禁用 ==
[thumb|right|用[[荧石](File:Blaze Spawner Blocking Pattern.png.md)禁用烈焰人刷怪笼]]

禁用刷怪笼所需的条件取决于生物的种类。

对于只在黑暗中生成的生物，让生成区域[亮度](亮度.md)等级大于0可防止刷怪。在刷怪笼周围放置[火把](火把.md)即可。

对于[烈焰人](烈焰人.md)和[蠹虫](蠹虫.md)刷怪笼，阻止它刷怪需要至少12的亮度等级。例如：
* 使用至少9个亮度为15的方块围起来。
* 在和刷怪笼同一高度使用7×7格火把紧密围起。
* 由于基岩版的刷怪笼只在菱形区域生成生物，在刷怪笼四边各放一个亮度15的南瓜灯即可禁用。

[岩浆怪](岩浆怪.md)刷怪笼无法通过提高-{}-亮度等级禁用。

将刷怪笼的刷怪范围完全用有碰撞箱的方块填满可以有效将其禁用。

# = 自定义刷怪笼 =
[缩略图|一个蜘蛛刷怪笼](File:Example monster spawner - Spider.png.md)
用[命令](命令.md)可以自定义刷怪笼：
* 用于生成任何种类的实体。
* 可以随机生成多种不同的实体。
* 可以设置生成的实体的属性。
* 可以改变刷怪笼本身的部分运作机制，如生成实体的范围、每隔多久尝试一次生成实体。

关于自定义刷怪笼的详细技术性信息详见。

# = 安全保护 =

刷怪笼属于“仅管理员可设置数据”的方块。

非管理员玩家对刷怪笼按下+时不会复制方块实体数据，放置物品栏中已有的带有方块实体数据的刷怪笼也不会将数据实际加载。

管理员玩家的物品栏中带有方块实体数据的刷怪笼的物品[提示框](提示框.md)中会显示警告信息。
