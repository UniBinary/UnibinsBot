# 破坏
挖掘混凝土粉末的合适工具是锹。

混凝土粉末被破坏后会掉落自身。

# 用途

# = 制造混凝土 =
如果混凝土粉末与[水](水.md)接触的话，它会凝固成[混凝土](混凝土.md)方块。特别的是，方块需要被放置、邻近或落入流动的水或者水源方块。当混凝土粉末接触到含水[树叶](树叶.md)除顶面外的五个面时，它均会凝固成混凝土。而如果它被放置在其他[含水](含水.md)方块（如含水[楼梯](楼梯.md)，含水[红树根](红树根.md)等）旁边，则其必须与水可以流出的面相邻，例如[楼梯](楼梯.md)的三个开口侧面，但不能是[楼梯](楼梯.md)的背面、等水不可以流出的面。如果混凝土粉末在降落时从侧面经过水，它不会凝固，如果落在侧面邻近水的位置，它只会在方块更新之后凝固。[雨](雨.md)、[炼药锅](炼药锅.md)或[喷溅型水瓶](喷溅型水瓶.md)对混凝土粉末也没有影响。混凝土粉末的[物品实体](物品实体.md)同样不会凝固。

# = 下落的方块 =

[有框|普通的[[沙子](File:ConcretePowderUsage.gif.md)会沉到水里，而混凝土粉末在与水接触时会直接凝固]]
混凝土粉末在下方没有不可替代的方块时会变为[下落的方块](下落的方块.md)。

除了具有大多下落的方块的行为，下落的混凝土粉末还会在接触到水的时候变为对应的混凝土。

混凝土粉末在没有得到支撑时，会在方块下方产生[粒子](粒子.md)。
