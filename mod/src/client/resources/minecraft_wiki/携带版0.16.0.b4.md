# 携带版0.16.0.b4

*页面ID: 24809* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.16.0 alpha build 4**<ref>http://pocketbeta.minecraft.net/2016/09/0160-beta-changelog-build-4-aka-015907.html</ref><ref>https://bugs.mojang.com/browse/MCPE/fixforversion/15701</ref>（也被称为**0.15.90.7**）是[v0.16.0 alpha](携带版0.16.0.md)的第4个测试版，发布于2016年9月16日，加入了[凋灵](凋灵.md)及相关方块和物品，并修复了一些漏洞。

# 新内容
# = 生物 =
* [凋灵](凋灵.md)
* * 在普通和困难难度下，当生命值降至50%，会生成3-4只[凋灵骷髅](凋灵骷髅.md)。
* * 当制作、生命值降至50%和被杀死时有新的动画。
* * 新的声音。

# = 物品 =
* [下界之星](下界之星.md)
* 衰变[药水](药水.md)
* * 喷溅型衰变[药水](药水.md)
* 衰变之[箭](箭.md)

# = 方块 =
* [信标](信标.md)
* * 在光柱外部看时不能正确显示。
* ** 在内部看时正确可见。
* ** 由于没有[染色玻璃](染色玻璃.md)，光柱不能被着色

# 更改
* 调整了[远古守卫者](远古守卫者.md)的攻击力。
* 修改了[凋灵骷髅](凋灵骷髅.md)的生成率。
* 修复性能问题（[FPS](FPS.md)严重下降）。
* 给[马](马.md)添加了很多动画。
* 修复了一些UI间距问题。
* 修复箭的几个漏洞。
* 更多的活塞动画。
* 移除了在[build 1](携带版0.16.0.b1.md)中添加的、和命令。
* * 现在只用于[教育版](教育版.md)。
* ** 因为该[命令](命令.md)可以打开文件（commands/education.JSON）。
* 移除了[NPC](NPC.md)[刷怪蛋](刷怪蛋.md)。
* [摄像机](摄像机.md)的物品形态被移除。
* [苦力怕](苦力怕.md)和未被驯服的[豹猫](豹猫.md)现在有闲逛的声音。

* *其他**
* 生物的脚步声丢失。
* 玩家不能在水下给铁桶装水。
* 喷溅型伤害药水不会杀死生物且会使其出现掉落物。
* 修复了一些物品的名称。
* 守卫者和远古守卫者的攻击动画丢失。
* 修复了生物的属性出错的漏洞（例如移速、生命值）。
* 加入本地局域网游戏时游戏崩溃。
* 船会随机被破坏。
* 设置为和平难度时，刷怪笼试图生成生物会使得游戏崩溃。
* 玩家投掷雪球、鸡蛋或喷溅药水时游戏崩溃。
* 僵尸猪人会对任意生物敌对。
* 骑乘猪、马或驴进入水中时下潜。
* 守卫者的激光不会改变颜色。
* 骑乘时，地图上的玩家标记朝向错误。
* 游戏规则无法保存。
* 部分生物没有掉落物。
* 玩家在首次生成时生成在危险的位置。
* 玩家在床睡觉时悬空。
* 生成守卫者或远古守卫者时服务端崩溃。
* 守卫者或远古守卫者的激光没有音效。
* 部分生物的掉落物出错（例如不掉落或掉落错误的物品）。
* 聊天窗口不会更新聊天信息。
* 村民在被感染后生成两个僵尸村民。
* 玩家死后，状态效果不会清空。
* 下界生物丢失抗火效果。
* 弹射物只能瞄准一个方向而发射。
* 生物仍然可以发现并攻击隐身的玩家。
* 苦力怕的音效丢失。
* 铁傀儡的攻击动画丢失。
* 闪电的音效丢失。
* 烈焰人的火球不可见，也不会引燃方块。
* 修复了一些加载或导入旧存档时的漏洞。
* 弹射物在反弹时仍会使得玩家受伤。
* 铁傀儡不会攻击伤害村民的敌对生物。
* 在罕见情况下，生物的头部丢失。
* 史莱姆生成时大小出错。
* 僵尸猪人不会携带金剑生成。
* 远古守卫者不会攻击玩家。
* 暂停游戏时不再断开Realm世界的连接。
* 和平模式下，仍然可以触发骷髅马陷阱。</onlyinclude>
