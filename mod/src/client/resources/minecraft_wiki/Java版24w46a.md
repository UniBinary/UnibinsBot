# Java版24w46a

*页面ID: 128671* | *来源: Minecraft Wiki*

<onlyinclude>

* *24w46a**是[Java版1.21.4](Java版1.21.4.md)的第3个，也是最后一个快照，发布于2024年11月13日<ref></ref>，修复了一些漏洞。

# 新内容
# = 物品 =
* *物品使用动画**
* 加入了[收纳袋](收纳袋.md)使用动画<code>bundle</code>。
* * 这也是<code>consumable</code>物品堆叠组件中的有效值之一。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了物品标签<code>#wither_skeleton_disliked_weapons</code>：。
* * 表示凋灵骷髅不想拾取的物品。

* * <code>head</code>
* ** 加入了可选字段，需为纹理的命名空间ID（无需<code>textures/entity/</code>前缀和<code>.png</code>后缀），存在时将使用此纹理，而<code>profile</code>组件和字段提供的纹理将被忽略。

</div>
  * 加入了<code>hanging_sign</code>硬编码渲染器，用于渲染[悬挂式告示牌](悬挂式告示牌.md)。附加字段如下：

* 对<code>condition</code>物品模型映射下的谓词进行下列更改：
* * 移除了布尔值属性。
* * <code>has_component</code>
* ** 加入了字段（默认为<code>false</code>），为<code>true</code>时，[物品默认组件](物品堆叠数据格式#物品默认组件.md)将被忽略。

* * 加入了<code>holder_type</code>离散属性。存在时，返回物品持有者的实体类型命名空间ID。
* * 加入了<code>local_time</code>离散属性，返回根据给定模式格式化的当前时间。此值每秒都会更新。附加字段如下：

  :** ：（默认为客户端设置的时区）时区。如<code>Europe/Stockholm</code>或<code>GMT+0:45</code>。

# 更改
# = 方块 =
* *[闭合的眼眸花](闭合的眼眸花.md)**
* [蜜蜂](蜜蜂.md)不再因接触闭合的眼眸花及其对应[盆栽](盆栽.md)而中毒。

* *[嘎枝之心](嘎枝之心.md)**
* 现在硬度和爆炸抗性翻倍了。
* 加入了数据字段，储存所绑定嘎枝的UUID。

* *[苍白覆地苔藓](苍白覆地苔藓.md)和[小型花](小型花.md)**
* 现在能被树替换。

* *[树脂团](树脂团.md)**
* 现在能被放置于任何方块的完整表面。
* 现在可以[含水](含水.md)，也可被嘎枝之心直接放置于水下。
* 其物品不再能放置于[锻造台](锻造台.md)材料槽。

* *[树脂团](树脂团.md)和[树脂块](树脂块.md)**
* 现在音效更加柔和。

# = 物品 =
* *[树脂砖](树脂砖.md)**
* 现在能放置于锻造台材料槽。

* *[谜之炖菜](谜之炖菜.md)**
* 由[张开的眼眸花](张开的眼眸花.md)合成的谜之炖菜的失明效果持续时间由更改为。

* *[创造模式物品栏](创造模式物品栏.md)**
* 树脂团物品现在位于[蜜脾](蜜脾.md)之后，而非[紫水晶碎片](紫水晶碎片.md)之后。

# = 生物 =
* *[嘎枝](嘎枝.md)**
* 移除了ID为<code>creaking_transient</code>的实体。
* 不再区分临时嘎枝和持久化嘎枝。
* 加入了字段，储存所绑定嘎枝之心的方块位置。此字段存在时，嘎枝会与对应的嘎枝之心绑定，行为变为与此版本前的临时嘎枝一致。
* * 嘎枝现在不会在世界被卸载时消失。

* *[凋灵骷髅](凋灵骷髅.md)**
* 不再偏向于拾取[弓](弓.md)。

# = 游戏内容 =
* *[进度](进度.md)**
* “”现在可以由击杀嘎枝而非临时嘎枝来获取。
* “”现在需要击杀嘎枝而非临时嘎枝。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[资源包](资源包.md)**
* 将资源包版本号更改为。
* 之前仅渲染方块实体模型的方块（旗帜、头颅、床、箱子、潮涌核心、饰纹陶罐、潜影盒和告示牌）现在也会在此之上渲染普通方块模型。

* *[标签](Java版标签.md)**
* 移除了<code>#trim_templates</code>物品标签。
* <code>#trim_materials</code>物品标签中的<code>resin_clump</code>现已修正为<code>resin_brick</code>。
* 现在分别重命名为。
