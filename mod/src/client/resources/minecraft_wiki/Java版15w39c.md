# Java版15w39c

*页面ID: 18420* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w39c**是[Java版1.9](Java版1.9.md)的第28个快照，发布于2015年9月23日<ref></ref>，修复了一些漏洞并提升了性能。

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 现在能在[玩家](玩家.md)、[生物](生物.md)和[盔甲架](盔甲架.md)的头部装备[南瓜](南瓜.md)。

# = 常规 =
* *性能**
* [红石](红石.md)和[活塞](活塞.md)机关在视觉上更新得快很多。
* 提升了使用旧电脑时的性能。

# 修复

|54120|苦力怕碰撞箱和眼睛高度有错误。

|83746|1.9快照中有帧率下降现象。
|86289|盾牌的统计项显示的是<code>item.shield.name</code>而不是“盾牌”。
|88315|重生后区块会一直更新。
|89302|有方块延迟。
