* *beta 1.14.0.1**是[基岩版1.14.0](基岩版1.14.0.md)的首个测试版，在Android上发布于2019年10月12日，而在Xbox One和Windows 10上发布于10月9日<ref></ref>，加入了首批[嗡嗡蜂群](嗡嗡蜂群.md)的特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[蜂箱](蜂箱.md)**
* 由[木板](木板.md)和蜜脾合成。
* 功能和蜂巢相同，但不需要[精准采集](精准采集.md)魔咒也能掉落。

* *[蜂巢](蜂巢（方块）.md)**
* 自然生成在[繁花森林](繁花森林.md)、[平原](平原.md)和[向日葵平原](向日葵平原.md)生物群系。
* 能容纳最多3只蜜蜂。
* 能充满蜂蜜。
* * 蜂蜜水平最高为5。
* 能用附有精准采集的工具获取。

* *[蜜脾块](蜜脾块.md)**
* 由9个蜜脾合成。
* 目前没有用途，完全是装饰性方块。

* *[蜂蜜块](蜂蜜块.md)**
* 可使用4个[蜂蜜瓶](蜂蜜瓶.md)合成。
* 大幅降低移动速度和跳跃高度。
* 实体可以从该方块的侧面缓慢滑下，且站在其上的实体会在该方块被活塞移动时随之一同移动。

# = 物品 =
* *[蜂蜜瓶](蜂蜜瓶.md)**
* 能被饮用，恢复。
* 能用来合成[糖](糖.md)。
* 通过对蜂巢/蜂箱使用玻璃瓶获得。

* *[蜜脾](蜜脾.md)**
* 通过对满的蜂巢/蜂箱使用剪刀获得。
* 能用来合成蜂箱和蜜脾块。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了蜜蜂刷怪蛋。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 拥有。
* 成群生活在蜂巢和蜂箱附近。
* * 如果蜜蜂没有容身的蜂巢或蜂箱，会四处游荡直到找到一个为止。
* 能用任何[花](花.md)来繁殖。
* 被激怒后会成群地攻击。
* * 攻击时会给目标造成[中毒](中毒.md)效果，而完成攻击动作的蜜蜂会在一段时间后死亡。

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 现在能给[玻璃瓶](玻璃瓶.md)填充[水](水.md)或蜂蜜。
* 现在能修剪蜂巢/蜂箱来获得蜜脾。

# = 物品 =
* *[拴绳](拴绳.md)**
* 现在可以拴住[海豚](海豚.md)、[豹猫](豹猫.md)、[鹦鹉](鹦鹉.md)、[北极熊](北极熊.md)和旧版[村民](村民/村庄与掠夺前.md)了。（）

* *[刷怪蛋](刷怪蛋.md)**
* 现在在创造模式物品栏中按字母顺序排列。

# = 生物 =
* *[狐狸](狐狸.md)**
* 降低了攻击范围，以匹配。

# = 游戏内容 =
* *[游泳](游泳.md)**
* 玩家不再能在仅有一格高的水中开始游泳了。

# = 常规 =
* *[经验](经验.md)**
* 调整了[动物](动物.md)掉落的经验值，以匹配。

* *[菜单屏幕](菜单屏幕.md)**
* 更改了背景图，以展示蜜蜂和蜂巢及其相关物品。

# 修复
* *修复了27个漏洞**<br>
* *崩溃**
* 修复了一些游戏过程中可能发生的崩溃。

* *性能**
* 修复了海带生长导致特定区块卡顿的问题。（）

* *常规**
* 修复了使用某些包后玻璃的动画会出现损坏的问题。
* 披风现在会正确显示在角色创建器中。
* 修复了无法获得“把我传走”成就的问题。（）
* 修复了部分皮肤的披风会变成纯白色披风的问题。（）
* 修复了玩家在旧世界类型世界中的特定位置上注销登录时，该世界有时会无法加载的渲染问题。
* 修复了角色创建器上的部分披风无法正确显示在皮肤上的问题。
* 修复了角色创建器上的部分操作无响应的问题。
* 修复了脚本报错消息会显示在“Alien Worlds”市场世界上的问题。

* *游戏内容**
* 矿车的音效现在会正确地加载与播放。
* 含水方块不再能够与附近的红石电路连接。
* 现在触摸控制玩家又可以在创造模式物品栏中正确装备盔甲了。（）
* 修复了弩在填装完毕之后会立即发射的问题。（）
* 冰霜行者魔咒现在又能够正确冻结水面了。（）
* 修复了飞行中的玩家在骑乘实体后，再次飞行会从天上掉下来的漏洞。（）
* 箭或三叉戟被盾牌反弹后不再会卡在方块里。（）
* 现在玩家在耕地上跳跃又会使其变为泥土了。
* 玩家在创造模式下为盔甲架装备盔甲时不再会将盔甲装备到自己身上。

* *生物**
* 降低了狐狸攻击范围以匹配Java版。
* 狐狸叼住的物品不再会隐形了。（）
* 马现在又使用正确的新模型了。
* 提高了飞行生物的寻路精准度。

* *物品**
* 现在指南针和时钟会在快捷栏中正确运作。（）

* *用户界面**
* 羊驼现在又会在装备栏中显示其装备的地毯了。

* *附加包和脚本引擎**
* 现在创建自定义凋灵实体时，其Boss生命条会正确显示。
* 现在骑乘自定义实体时，其生命值又会正确显示了。</onlyinclude>
