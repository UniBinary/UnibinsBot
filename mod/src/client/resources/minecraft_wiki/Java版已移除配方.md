# Java版已移除配方

*页面ID: 98497* | *来源: Minecraft Wiki*

从[Java版](Java版.md)开始开发至今，有一些合成配方已经从游戏中移除。这些合成配方可能已经被取代，或者开发人员已决定其今后不会加入游戏。

请注意：该页只记录从游戏中移除的合成配方；移除的合成配方在其对应的历史段落中有描述。

# 合成配方
# = 箭 =

[Java版Indev 0.31 20100128-2304](Java版Indev 0.31 20100128-2304.md)加入了用1个[苹果](苹果.md)合成箭的测试配方，这个配方在[Java版Indev 0.31 20100129-1447](Java版Indev 0.31 20100129-1447.md)被移除。

[Java版Indev 0.31 20100130](Java版Indev 0.31 20100130.md)加入了另一个合成配方，可以通过[铁锭](铁锭.md)、[木棍](木棍.md)、[羽毛](羽毛.md)合成箭，后于[Java版Alpha v1.0.14](Java版Alpha v1.0.14.md)被移除。

# = 铁块、金块和钻石块 =

[Java版Indev 0.31 20100129-1447](Java版Indev 0.31 20100129-1447.md)加入了用4个矿物原材料合成矿物块的配方：

这些配方在[Java版Indev 0.31 20100130](Java版Indev 0.31 20100130.md)被需要9个矿物原材料的配方取代。

# = 面包 =

[Java版Indev 20100206-2034](Java版Indev 20100206-2034.md)加入了用6个[小麦](小麦.md)合成面包的配方：

该配方在[Java版Indev 20100223](Java版Indev 20100223.md)被需要3个小麦的配方取代。

# = 锁链盔甲 =

在[14w25a](14w25a.md)之前，锁链盔甲可以使用[火](火.md)合成。在这个快照中，无论是否修改物品栏，火都不再能在物品栏中以物品形式存在，配方本身也从游戏的配方注册表中被移除。

# = 附魔金苹果 =

[附魔金苹果](附魔金苹果.md)的配方在[Java版1.3.1](Java版1.3.1.md)中被加入，在[Java版1.9](Java版1.9.md)的快照[15w44a](15w44a.md)被移除。

# = 马铠 =

在[Java版1.6.1](Java版1.6.1.md)的[13w16a](13w16a.md)快照中，马铠的配方被加入游戏：

该配方于同版本的[13w18a](13w18a.md)快照中被移除。

# = 下界合金工具/装备 =

在[Java版1.16](Java版1.16.md)的[20w06a](20w06a.md)快照中，用下界合金锭升级钻石工具及装备的合成配方被加入游戏，后于[20w10a](20w10a.md)快照被移除：

# = 铜块 =

在[Java版1.17](Java版1.17.md)的[20w46a](20w46a.md)快照中，合成铜块所需的铜锭由9个改为4个，反向分解同理：

随后的[21w11a](21w11a.md)加入了将涂蜡的铜块分解为4个铜锭的配方：

这些配方中的铜锭数量在同版本的快照[21w17a](21w17a.md)再次被更改为9个。

# = 竹材 =

在[Java版1.19.3](Java版1.19.3.md)的[22w42a](22w42a.md)快照中，竹材的合成配方被加入游戏，属于[实验性内容](实验性内容.md)“”：

该配方在同版本的[22w45a](22w45a.md)快照中改為由1個[竹方塊](竹方塊.md)分解成2個竹材。

# = 刷子 =

在[Java版1.19.4](Java版1.19.4.md)的[23w07a](23w07a.md)快照中，刷子的合成配方被加入游戏，属于[实验性内容](实验性内容.md)“”：

该配方在同版本的预发布版[Java版1.19.4-pre1](Java版1.19.4-pre1.md)被1个羽毛、1个铜锭和1个木棍的合成配方取代。

# = 地毯 =

在[Java版1.14](Java版1.14.md)的[18w43a](18w43a.md)快照中，白色地毯的染色配方被加入游戏：

该染色配方在[Java版1.20](Java版1.20.md)的预发布版[Java版1.20-pre1](Java版1.20-pre1.md)被单个任意地毯+单个染料的合成配方取代。

# = 铜门 =

在[Java版1.20.3](Java版1.20.3.md)的[23w43a](23w43a.md)快照中，铜门的合成配方被加入游戏，属于[实验性内容](实验性内容.md)“”：

在[Java版1.21](Java版1.21.md)的[24w18a](24w18a.md)快照中，合成铜门需要铜锭，而非铜块，铜门的氧化变种不再能够合成。

# = 铜活板门 =

在[Java版1.20.3](Java版1.20.3.md)的[23w43a](23w43a.md)快照中，铜活板门的合成配方被加入游戏，属于[实验性内容](实验性内容.md)“”：

在[Java版1.21](Java版1.21.md)的[24w18a](24w18a.md)快照中，合成铜活板门需要铜锭，而非铜块，铜活板门的氧化变种不再能够合成。

在[Java版1.21.9](Java版1.21.9.md)的[25w32a](25w32a.md)快照中，为与[铜栏杆](铜栏杆.md)做区分，更改了铜活板门的合成配方。此前，合成2个铜活板门需要6个铜锭。

# = 收纳袋 =

该配方在[Java版1.21.2](Java版1.21.2.md)的快照[24w33a](24w33a.md)被皮革+线的合成配方取代。

# = 磁石 =

在[Java版1.16](Java版1.16.md)的[20w13a](20w13a.md)快照中，磁石的配方被加入游戏：

在[Java版1.21.5](Java版1.21.5.md)的[25w02a](25w02a.md)快照中，该配方被包含铁锭的配方取代。

# = 拴绳 =

在[Java版1.6.1](Java版1.6.1.md)的[13w18a](13w18a.md)快照中，拴绳的配方被加入游戏：

在[Java版1.21.6](Java版1.21.6.md)的[25w18a](25w18a.md)快照中，该配方不再需要黏液球，被线取代。

# = 失水恶魂 =

在[Java版1.21.6](Java版1.21.6.md)的[25w15a](25w15a.md)快照中，失水恶魂的配方被加入游戏：

在[Java版1.21.6](Java版1.21.6.md)的[25w18a](25w18a.md)快照中，更改了失水恶魂的合成配方，该配方被包含灵魂沙的配方取代。
