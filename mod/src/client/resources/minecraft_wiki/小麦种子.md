* *小麦种子（Wheat Seeds）**是能够种出小麦植株的[物品](物品.md)。

* *小麦植株（Wheat Crops）**是种植在[耕地](耕地.md)上的作物方块，成熟时能掉落[小麦](小麦.md)物品。

# 生成
# = 自然生成 =
小麦植株会自然生成在所有类型[村庄](村庄.md)内[农田](农田.md)结构的[耕地](耕地.md)上。

根据村庄所处生物群系不同，每块耕地上生成小麦植株的概率如下。

小麦植株也会在[林地府邸](林地府邸.md)的“[小麦农场](林地府邸/结构/农场#小麦农场.md)”中生成。

# = 村民 =
[农民](农民.md)村民会将自己物品栏中的小麦种子种在[耕地](耕地.md)上。

# 获取
# = 方块掉落物 =
没有被[剪刀](剪刀.md)挖掘破坏时，[草丛](草丛.md)或[蕨](蕨.md)被破坏后有12.5%的概率会掉落1个小麦种子，挖掘工具的[时运](时运.md)魔咒每有1级，上限增加2。

# = 礼物 =

[傻子](傻子.md)和[失业](失业.md)的村民会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷小麦种子。

# = 交易 =

# = 箱子战利品 =

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落小麦种子。

# 破坏
小麦植株被挖掘时会立刻被破坏。

生长阶段没有达到第8阶段的小麦植株被破坏后会掉落1份小麦种子。

生长阶段达到第8阶段的小麦植株被破坏后会掉落1个[小麦](小麦.md)，不受[时运](时运.md)魔咒影响，然后系统会尝试进行3次掉落，每次有约）|JE|short=1}}或）|BE|short=1}}的概率掉落1份小麦种子，挖掘工具的[时运](时运.md)魔咒每增加1级，尝试次数增加1。还会额外掉落1份小麦种子。

# 用途
# = 种植 =

[缩略图|小麦植株的不同生长阶段](File:Crop states.png.md)

对[耕地](耕地.md)的顶面小麦种子即可种植出小麦植株。小麦植株会经历8个生长阶段。[亮度](亮度.md)等级<ref>与下文均指方块光照与天空光照的较大值。</ref>≥9时，小麦植株才能生长到下一个阶段；亮度等级≤7时无法对耕地小麦种子，已种植的小麦植株也会在接收到[方块更新](方块更新.md)时掉落为[物品实体](物品实体.md)。

小麦植株在湿润的耕地上生长得更快。对小麦植株[骨粉](骨粉.md)会使其增加2-5个生长阶段，忽视亮度等级。已有巢且采集了花粉的[蜜蜂](蜜蜂.md)飞过小麦植株时，植株也有概率增加1个生长阶段。

小麦植株的四周都为小麦植株且都种植在湿润的耕地上会比单独种植在湿润的耕地的小麦植株生长速度快约16.7%；而按一排间种小麦植株，中间没有作物或为其他作物会比单独种植在湿润的耕地的小麦植株生长速度快133%。

# = 繁殖 =

与其他种子相同，小麦种子可用于吸引及繁殖[鸡](鸡.md)，也可喂食给幼年鸡以减少其10%的剩余成长时间。

# = 驯服 =
与其他种子相同，小麦种子可用于驯服[鹦鹉](鹦鹉.md)。

# = 堆肥 =
将小麦种子放入[堆肥桶](堆肥桶.md)中有30%的概率增加一层堆肥层。
