* *烫手洋芋（Hot potato）**是一种用于合成[悬浮马铃薯推进器](悬浮马铃薯推进器.md)的[食物](食物.md)类[物品](物品.md)。

# 获取
# = 熔岩 =
将[马铃薯](马铃薯.md)、[烤马铃薯](烤马铃薯.md)或[毒马铃薯](毒马铃薯.md)丢入[熔岩](熔岩.md)，可使其变为烫手洋芋。

# 用途
[thumb|烫手洋芋在熔岩中跳动](File:Hot potato Jumping in Lava.gif.md)

[物品实体](物品实体.md)形式的烫手洋芋免疫火焰伤害，在[火](火.md)或熔岩中不会被烧毁，且在接触熔岩时会向随机方向弹射。

# = 火焰伤害 =
物品栏中存在烫手洋芋的玩家会受到[火焰伤害](火焰伤害.md)。持有后开始受到每次的伤害，之后每过使每次伤害增加，每次伤害的最大值为。

将烫手洋芋移动到另一个槽位可以使伤害重新开始累积，但扔出后重新拾起则不能。

# = 食物 =
手持烫手洋芋按住键即可食用，每个烫手洋芋可以回复，并使玩家额外着火，这个值超过了类型的支持范围，因此玩家的数据在保存时只会取对后16位对32768取模的值。

玩家在[饥饿值](饥饿值.md)为满的状态下也可以食用烫手洋芋。

# = 堆肥 =
将烫手洋芋放入[堆肥桶](堆肥桶.md)中，会有85%的概率增加一层堆肥层。
