# 河豚（物品）

*页面ID: 35832* | *来源: Minecraft Wiki*

* *河豚（Pufferfish）**是一种剧毒食品和[药水](药水.md)原料。

# 获取
# = 钓鱼 =
河豚可以在[钓鱼](钓鱼.md)时作为[鱼](钓鱼#垃圾与宝藏.md)被钓上来。钓上河豚的概率会随着[海之眷顾](海之眷顾.md)魔咒的等级增加而减少。

# = 生物掉落物 =

# 用途
# = 食物 =

手持河豚按住键即可食用，每个河豚可以回复，并给予玩家15秒 III、1分钟 II和15秒 I。

# = 狼 =
河豚可以用于给[狼](狼.md)喂食，恢复的生命值。然而不同于其他狼可食用的食物，河豚不能用于繁殖狼以及加速幼年狼的生长。

# = 鹦鹉螺和僵尸鹦鹉螺 =
[鹦鹉螺](鹦鹉螺.md)和[僵尸鹦鹉螺](僵尸鹦鹉螺.md)会被手持河豚的玩家吸引。

给成年鹦鹉螺和僵尸鹦鹉螺喂食河豚可使其恢复生命值，同时有概率将其驯服。给幼年鹦鹉螺喂食河豚可缩短其约10%成长时间。

给已驯服且生命值已满的成年鹦鹉螺喂食河豚可使其进入[繁殖](繁殖.md)模式。

# 你知道吗
* 河豚给予玩家的反胃和中毒效果实际上是基于现实生活的，因为现实中河豚的器官内含有极危险的“[河-{}-豚毒素](wzh:河豚毒素.md)”，尤其是它们的肝脏和卵囊，这种毒素含量极高。肌肉组织和血液只含有微量毒素。在东亚地区，河豚因肉质鲜美被认为是一道美味佳肴，因为小部分的河豚实际上是可以食用的。任何厨师做这道菜之前必须得到特殊认证。
