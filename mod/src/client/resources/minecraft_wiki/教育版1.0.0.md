# 教育版1.0.0

*页面ID: 34387* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.0.0**是的首个非开发版本，发布于2016年11月1日，加入了一些的独有特性和所有[Windows 10版](Windows 10版.md)的特性。<ref>https://education.minecraft.net/blog/minecraft-education-edition-available-now/</ref><ref>https://mojang.com/2016/11/minecraft-education-edition-has-launched/</ref>

# 新内容
* 来自[Windows 10版](Windows 10版.md)和[携带版Alpha 0.16.0](携带版Alpha 0.16.0.md)测试版的所有特性。
* * [拴绳](拴绳.md)和[马](马.md)、额外的[玩家](玩家.md)皮肤和剩下的[红石](红石.md)功能和升级后的用户界面。

# = 常规 =
* *[课堂模式](课堂模式.md)**
* 简单，安全登录。
* 个人学生和教师登录有助于识别游戏中的每个玩家，并在游玩教育版时确保数据的私密性和安全性。
* 支持单点登录（SSO）功能，因而不需要额外的密码或账户。

# = 方块 =
* *[黑板](黑板.md)**
* 有3种尺寸。
* 可以像[告示牌](告示牌.md)那样可以书写，但可以显示更多文本信息。
* *[允许和拒绝方块](允许和拒绝方块.md)**
* 用于创建受限建筑物区域。
* 允许方块允许没有世界建造者状态的用户在其上放置方块。
* 只有具有世界建造者状态的用户才能将方块放置在拒绝方块之上。

# = 物品 =
* *[相片簿](相片簿.md)**
* 用于保存摄像机拍摄的照片。

# = 实体 =
* *[摄像机](摄像机.md)**
* 用于拍摄照片的实体。
* 照片可以收集并在[相片簿](相片簿.md)内。
* *[Non-Player Characters](NPC.md) (NPC)**
* 一种与[村民](村民.md)相似的生物。
* 玩家朝向它们时会出现一个“对话”按钮。
