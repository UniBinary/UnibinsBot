# 基岩版1.21.80.20

*页面ID: 147327* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.80.20**（ChromeOS/Android）、**Preview 1.21.80.20**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.80](基岩版1.21.80.md)的首个测试版，发布于2025年3月11日<ref></ref><ref></ref>，在[实验性玩法](实验性玩法.md)中加入了[定位栏](定位栏.md)功能，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“”子选项。
* * 用于启用[定位栏](定位栏.md)功能。

* *[粒子](粒子.md)**
* 加入了粒子。

# 更改
# = 方块 =
* *[切制红砂岩台阶](切制红砂岩台阶.md)**
* 现在可以在[切石机](切石机.md)中用[切制红砂岩](切制红砂岩.md)制成。

* *[切制砂岩台阶](切制砂岩台阶.md)**
* 现在可以在切石机中用[切制砂岩](切制砂岩.md)制成。

* *[红树根](红树根.md)**
* 现在能够用作燃料。

# = 物品 =
* *[不死图腾](不死图腾.md)**
* 现在会给予45秒的[生命恢复](生命恢复.md)II效果，此前仅有40秒，以匹配。

# = 生物 =
* *[兔子](兔子.md)**
* 现在掉落[生兔肉](生兔肉.md)或[熟兔肉](熟兔肉.md)的数量上限受[抢夺](抢夺.md)魔咒影响，魔咒每增加1级，掉落数量上限就会增加1。
* * 未受抢夺魔咒影响时的掉落数量仍然为0-1，而非与相同的1。

* *[史莱姆](史莱姆.md)和[岩浆怪](岩浆怪.md)**
* 现在会在分裂后保留其名称。

* *[悦灵](悦灵.md)**
* 现在每秒恢复生命值，而不是每秒恢复，以匹配。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 现在使用带有[锋利](锋利.md)、[亡灵杀手](亡灵杀手.md)或[节肢杀手](节肢杀手.md)的附魔武器攻击生物时会产生粒子效果，以匹配。

* *[钓鱼](钓鱼.md)**
* [睡莲](睡莲.md)现在属于“垃圾”战利品（不包括丛林生物群系），而不是“宝藏”战利品。

# = 常规 =
* *[主菜单](主菜单.md)、[暂停菜单](暂停菜单.md)、编辑世界屏幕和玩家档案屏幕**
* 移除了好友抽屉式菜单按钮。

* *[设置](设置.md)**
* “”选项现在会控制[全景图](全景图.md)的转动和[闪烁标语](闪烁标语.md)的浮动。

* *[闪烁标语](闪烁标语.md)**
* 将闪烁标语“Almost C++17!”改为“Almost C++20!”。

* *[触摸控制](触摸控制.md)**
* 拆分了取消骑乘按钮，并且不再可以在骑乘时用于跳跃：
* * [30px|class=pixel-image](File:Box_exit_BE1.png.md) 取消骑乘非生物实体
* * [30px|class=pixel-image](File:Horse_exit_BE1.png.md) 取消骑乘生物

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“”、“测试版 API”和“”子选项后才可使用。

# = 游戏内容 =
* *[定位栏](定位栏.md)**
* 新的[HUD](HUD.md)元素，用于显示世界中的其他玩家的方向。
* 世界中存在多个玩家时，定位栏会取代经验条，显示在每个玩家的屏幕上。
* * 玩家的经验等级仍会显示在定位栏上方。
* 相机视角在120度内朝向其他玩家时，定位栏会显示彩色指示器。
* 其他玩家位于相机视口（屏幕）上方或下方30度时会显示向上箭头或向下箭头。
* 下列情况下的玩家不会出现在其他玩家的定位栏上：
* * 处于[潜行](潜行.md)状态
* * 处于[旁观模式](旁观模式.md)
* * 拥有[隐身](隐身.md)效果
* * 穿戴[生物头颅](生物头颅.md)或[雕刻南瓜](雕刻南瓜.md)

# 修复
* *方块**
* 树苗的方块状态不再会在尝试生长失败后退化，以防止侦测器错误激活。（）

* *游戏内容**
* 玩家不再会穿过放置在X或Z坐标为2的幂（如256、512、1024等）附近的方块。（）

* *物品**
* 修复了对准刷怪笼时无法使用大多数可使用物品的漏洞。（）
* 红树根现在可以用作熔炉燃料。（）
* 修复了在箱子被漏斗更新的情况下向其槽位添加物品时会移除物品的问题。（）

* *生物**
* 修复了已被命名的史莱姆和岩浆怪会在分裂时丢失名称的漏洞。（）
* 嘎枝不再会在重载世界时消失。（）
* 鹦鹉现在会模仿幻翼、僵尸疣猪兽、守卫者、劫掠兽、掠夺者和烈焰人。（）
* 凋灵骷髅和僵尸猪灵现在可以行走于熔岩中。（）

* *音效**
* 修复了Windows平台上加载至40-41%后所有声音会停止运作的问题。（）

* *性能与稳定性**
* 修复了在空的槽位上创建Realm时偶尔会导致错误的漏洞。
* 修复了部分树叶纹理加载失败时可能会发生的崩溃。

* *用户界面**
* 修复了取消来自另一个服务器的服务器转移请求后，Minecraft会无法加载主菜单的漏洞。（）
* 创造模式物品栏中的（普通、喷溅型、滞留型）迟缓药水IV不再会与其他迟缓药水分离。（）
* 触摸控制：更新了取消骑乘和（骑乘时的）跳跃按钮的图标，以使其更加明显并与其他触摸控制方案保持一致。（）
* 在禁用屏幕动画的情况下暂停或最小化游戏时不再会重置创建新的世界屏幕中的世界种子。（）
* 触摸控制：旁观模式玩家现在也可以自定义触摸控制。（）
* 触摸控制：修复了在极限模式中的自定义死亡动画期间自定义触摸控制时可能导致一些问题的漏洞。（）
* 加入了用以处理编辑世界屏幕、资源包选项卡中的磁盘空间不足错误的模态框。
* 修复了“下载所有缺失的包”按钮在特定条件下不起作用的问题。
* 修复了在雷暴期间睡觉时睡觉屏幕会显示错误消息的漏洞。（）
* 现在进入新玩家流程时会停止主菜单背景图的旋转。

* *原版趋同**
* 为附魔武器加入了魔法暴击粒子，以匹配Java版。（）
* 切制砂岩台阶现在可以在切石机中用切制砂岩制成。（）
* 切制红砂岩台阶现在可以在切石机中用切制红砂岩制成。（）
* 不死图腾现在会给予45秒的生命恢复，如同Java版。（）
* 现在对达到最大储蜜量的蜂巢和蜂箱使用剪刀时会消耗剪刀的耐久度。（）
* 现在抢夺每增加一级，兔子掉落生兔肉的最大数量就会增加1个。（）
* 现在林地府邸的伐木室内的箱子中总会生成带有效率I的铁斧。（）</onlyinclude>
