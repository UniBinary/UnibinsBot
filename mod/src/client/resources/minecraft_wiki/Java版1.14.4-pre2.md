# Java版1.14.4-pre2

*页面ID: 44958* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14.4-pre2**是[Java版1.14.4](Java版1.14.4.md)的第2个预发布版，发布于2019年7月4日<ref name="article_1.14.4-pre2"></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[村民](村民.md)**
* 现在在锁定交易前可以交易更多的物品。
* 现在转变成僵尸村民后仍能记住其言论。
* * 关于玩家转变僵尸村民的言论现在会持续更长时间。
* 现在工作时可以不同时补货。
* 提升村民寻路能力。

# = 常规 =
* *[Minecraft Realms](Minecraft Realms.md)**
* 移除了Realms界面上的“Player Activity”活动按钮。

# = 选项 =
* 在鼠标设置中添加“原始输入”选项。
