# 教育版1.21.03

*页面ID: 114019* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21.03**是**[云更新](云更新.md)**的首个正式版，也是的一次主要更新，发布于2024年7月23日<ref></ref>。此次更新加入了[蝙蝠与陶罐](蝙蝠与陶罐.md)、[犰甲狼兵](犰甲狼兵.md)和[棘巧试炼](棘巧试炼.md)的特性和云世界备份与上传功能。

# 新内容

* 加入了[蝙蝠与陶罐](蝙蝠与陶罐.md)、[犰甲狼兵](犰甲狼兵.md)和[棘巧试炼](棘巧试炼.md)的特性。

# = 常规 =
* *云世界备份与上传**
* 世界作为备份而关闭时，该世界会自动上传至OneDrive。<ref></ref>

# 更改
# = 游戏内容 =
* *[创造模式物品栏](创造模式物品栏.md)**
* [气球](气球.md)和[荧光棒](荧光棒.md)等[化学](化学.md)相关物品现在会出现在创造模式物品栏中。

# = 常规 =
* *[主菜单](主菜单.md)**
* 将“管理帐户”按钮移动至屏幕右下角。

* *其他**
* 更新了相机API。

# 修复
* 优化了游戏的性能与稳定性。
