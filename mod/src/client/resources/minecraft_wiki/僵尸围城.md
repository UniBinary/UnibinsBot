# 僵尸围城

*页面ID: 7614* | *来源: Minecraft Wiki*

[缩略图|350px|一次僵尸围城正在进行](File:Zombie Siege.png.md)

* *僵尸围城（Zombie Siege）**是游戏内的一种事件，表现为大量[僵尸](僵尸.md)在[村庄](村庄.md)里生成。

# 机制
每晚的午夜（[昼夜更替](昼夜更替.md)中的第18000[刻](刻.md)），系统有10%的概率安排一次僵尸围城。如果围城要发生，系统每一[刻](刻.md)会进行一次“是否开始围城”的判定，直至判定成功或日出。须注意，此种判定将会在[天空亮度级别](亮度#天空光照.md)到达12或以上时被停止；然而，恶劣[天气](天气.md)可以使此种判定在黎明之后仍然继续，因为恶劣天气降低了天空的亮度级别。

# = 围城开始判定 =
<!-- [缩略图|250px|过时的僵尸围城的僵尸生成模型](File:Village_siege.png.md) -->
每一个村庄都有一个中心，而放置在村庄里的[钟](钟.md)不仅被用作集会地点，还被视作一个村庄的核心部分。

如果一个玩家在[村庄](村庄.md)里<ref group="注" name="within-village">“在村庄里”定义为：处在一个包含一定量的[床](床.md)、[钟](钟.md)和[工作站点](工作站点.md)的子区块（subchunk）及其周围3x3x3区域内任意一个子区块中。</ref>，且该玩家不处于[旁观模式](旁观模式.md)下，也不处在带有标签的[生物群系](生物群系.md)（在原版中，此生物群系标签仅包含[蘑菇岛](蘑菇岛.md)），那么此玩家就会被视为围城的**理想对象（candidate）**。

玩家总是被按顺序判定，所以只要有一个玩家正被判定为理想对象，其他玩家就不会被系统校检。

如果以上条件符合，玩家被选定，系统会尝试在以此玩家为圆心，半径为32格的圆周上随机寻找十个围城开始点，并判断这些点是否位于村庄内<ref group="注" name="within-village"/>。如果所有十个被找到的点全部无效，那么此次僵尸围城的判定过程将以失败告终，但是下一个游戏刻仍可能会开始另一个判定过程。

在找到一个有效的围城开始点后，系统将会判断该点是否可以生成[僵尸](僵尸.md)（生成规则如下所述）。如果可以生成，僵尸围城即从此点开始。

# = 僵尸生成 =
围城开始后，系统每尝试生成一只僵尸。系统会在开始点周围16x16的水平区域内找到一个点，尝试让僵尸生成于所在此水平位置的最高点（[高度图](高度图.md)<code>WORLD_SURFACE</code>）上。生成尝试一共进行20次，共持续。

僵尸围城过程中生成的僵尸将无视玩家的距离与其他生物存在地生成。只进行如下的生成基本条件检测：
* 生成点亮度允许僵尸生成。
* 生成点正下方的方块必须是可生成方块。
* 生成点必须在村庄内<ref group="注" name="within-village"/>。

[溺尸](溺尸.md)、[尸壳](尸壳.md)、[僵尸村民](僵尸村民.md)和[僵尸猪灵](僵尸猪灵.md)不会在僵尸围城中生成。

多数情况下，僵尸围城中生成的僵尸的行为模式与正常生成的僵尸无异：它们会攻击视野内的任何[村民](村民.md)，村民与[铁傀儡](铁傀儡.md)也会如常地做出反应（逃走或迎击）。当玩家足够远离这些僵尸时，它们也会正常地被清除。如果一个僵尸刚好游走至被围城的村庄范围以外，若此时它没有在追逐一个目标，将会返回[村庄](村庄.md)。

# 应对策略

# = 恢复 =
如果有至少两名村民在围城中存活，村民们可以通过繁殖来使村庄的人口恢复。然而，在没有玩家介入的情况下，村庄很可能因围城和随机生成的僵尸导致所有村民死亡或被僵尸化而被摧毁。

即使一个村庄中所有的村民在围城中死亡，玩家也可以通过治疗僵尸村民或从其他村庄搬运村民的方式来恢复该村庄的人口。
