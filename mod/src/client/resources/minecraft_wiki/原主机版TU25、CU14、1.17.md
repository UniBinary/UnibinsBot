# 原主机版TU25、CU14、1.17

*页面ID: 81047* | *来源: Minecraft Wiki*

* *TU25/CU14/1.17**是[原主机版](原主机版.md)的一次更新，发布于2015年6月30日，加入了许多[缤纷更新](缤纷更新.md)的特性。<ref></ref><ref></ref>此次更新等价于[Java版1.8](Java版1.8.md)。

# 新内容
# = 方块 =
* *[栅栏](栅栏.md)**
* 有橡木、云杉木、白桦木、丛林木四个种类。

* *[栅栏门](栅栏门.md)**
* 有橡木、云杉木、白桦木、丛林木四个种类。

* *[门](门.md)**
* 有橡木、云杉木、白桦木、丛林木四个种类。

* *铁[活板门](活板门.md)**

* *反向[阳光探测器](阳光探测器.md)**

* *[书与笔](书与笔.md)**

* *[染色玻璃](染色玻璃.md)**
* 16种颜色。

* *[染色玻璃板](染色玻璃板.md)**
* 16种颜色。

# 更改
# = 常规 =
* *[混搭包](混搭包.md)**
* PS3、PS4、PSV：加入了LittleBigPlanet(TM)混搭包试用内容。
* *[超平坦世界](超平坦世界.md)类型**
* 加入了自定义超平坦世界界面，以允许玩家自定义超平坦世界生成。
* *[选项](选项.md)**
* 在游戏内新增更改游戏模式、难度、时间、出生点、音效、天气的选项。
* 加入了经典合成选项。
* *[菜单屏幕](菜单屏幕.md)**
* 将多人游戏菜单中的刷新、加入更改为新建、刷新、加入。
* 将游戏模式选项更改为滑块。
* *设备**
* XB360、XBONE、PS3、PS4：为[书与笔](书与笔.md)启用USB键盘。
* XB360：为书与笔启用Chatpad。

# 修复
* *修复了11个漏洞**
* 修复了使用红石粉时的崩溃。
* 修复了各种错误工具提示。
* 修复了摧毁方块时掉落物会在世界顶端而非原方块处生成的漏洞。
* 修复了披风损坏的漏洞。
* 修复了玩家在“允许打开容器”被关闭时仍可以打开陷阱箱、投掷器、漏斗和信标的漏洞。
* 修复了燃烧的箭从发射器射出击中TNT时的崩溃。
* XB360、PS3、PS4、PSV：修复了长时游玩引发内存泄漏导致崩溃的漏洞。
* XB360、PS3、PS4、PSV：修复了掉落物沉没入地面的漏洞。
* XB360、PS3、PS4、PSV：修复了有关TNT爆炸的漏洞。
* XB360、PS3、PS4、PSV：修复了关于幼年村民碰撞高度的漏洞。
* PS3：修复了蒸汽朋克纹理包中的漏洞。
