# Minecraft: Tricky Trials (Original Game Soundtrack)

*页面ID: 119447* | *来源: Minecraft Wiki*

* **Minecraft: Tricky Trials (Original Game Soundtrack)*（《Minecraft：棘巧试炼（游戏原声带）》）**，在部分平台上也称为***Minecraft: 1.21 Soundtrack***，是[Lena Raine](Lena Raine.md)、[Aaron Cherof](Aaron Cherof.md)与[谷冈久美](谷冈久美.md)合作为[棘巧试炼](棘巧试炼.md)创作的专辑。本专辑于2024年4月26日在多平台发布。

本专辑包含12首乐曲，时长总计56分28秒，包括9首在[主世界](主世界.md)播放的曲目，以及3张[音乐唱片](音乐唱片.md)的曲目。<ref></ref>
