# 启动器2.2.811x

*页面ID: 91565* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.2.8116**（）、**2.2.8117**（，版）、**2.2.8115**（）或**2.2.8114**（）是一次[启动器](启动器.md)更新，发布于2021年12月7日。

# 更改
* 改进了微软账户迁移后的过程。
* 改进了Microsoft Store版启动器管理Mod和保存文件的流程，现在会加载和保存配置到独立启动器所使用的文件中。
* 现在用户不会在点击“添加账户”按钮后快速退出登录窗口时收到错误信息了。
* 现在的新用户进入皮肤选项卡后会被提示创建的玩家代号了。

# 修复
*  - 当启动器更换为Microsoft Store版时所有已下载的文件会丢失。
*  - 进入皮肤选项卡并minecraft.net/profile修改玩家名称时会显示并未购买游戏。</onlyinclude>
