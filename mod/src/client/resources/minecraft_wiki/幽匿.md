# 幽匿

*页面ID: 92681* | *来源: Minecraft Wiki*

* *幽匿（Sculk）**可以指：
# 方块
*  - 一种由幽匿催发体产生的装饰性方块。
*  - 一种由幽匿块和骨质材料组成的方块，会利用经验在周围生成其他4种幽匿类方块。
*  - 一种可以检测振动信号，并发出红石能量的方块。
* *  - 幽匿感测体的变种，接收红石信号时只能检测到与该信号强度对应频率的振动。
*  - 一种可被幽匿感测体或玩家踩踏激活，并给予玩家[黑暗](黑暗.md)状态效果，且激活一定次数后，会尝试生成[监守者](监守者.md)的方块。
*  - 一种会由幽匿催发体产生的薄层方块。
* [幽匿钳口](Java版提及特性#幽匿钳口.md) - 未正式加入游戏的一种陷阱方块。

# 地物
