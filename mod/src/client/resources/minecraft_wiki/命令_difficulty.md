# 命令/difficulty

*页面ID: 39722* | *来源: Minecraft Wiki*

设定[世界难度](世界难度.md)等级。

# 语法
* **Java版**
   <code>difficulty [easy|hard|normal|peaceful]</code>

* **基岩版**
   <code>difficulty <difficulty: Difficulty></code>
   <code>difficulty <difficulty: int></code>

# 参数
：easynormalhard}}<br>
：，或
   新的游戏难度。必须为以下之一：
  * <code>peaceful</code>（可简写为<code>p</code>或<code>0</code>）为[和平](和平.md)难度
  * <code>easy</code>（可简写为<code>e</code>或<code>1</code>）为[简单](简单.md)难度
  * <code>normal</code>（可简写为<code>n</code>或<code>2</code>）为[普通](普通.md)难度
  * <code>hard</code>（可简写为<code>h</code>或<code>3</code>）为[困难](困难.md)难度
若未指定参数，则查询当前游戏难度。

# 结果

# 输出

 0，简单  1，普通  2，困难  3）}}

# 示例
* 难度更改为困难：<code>difficulty hard</code>、<code>difficulty h</code>或<code>difficulty 3</code>
