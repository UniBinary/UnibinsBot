# 鞍

*页面ID: 6987* | *来源: Minecraft Wiki*

* *鞍（Saddle）**是一种能够装备在可[骑乘](骑乘.md)生物身上的[物品](物品.md)。

# == 劫掠兽 ==

# == 炽足兽 ==
当[僵尸猪灵](僵尸猪灵.md)生成在炽足兽身上时，[炽足兽](炽足兽.md)会装备鞍。其死亡后总是会掉落1个鞍，不受抢夺魔咒影响。

# 用途
鞍可用来骑乘、控制部分生物。这些生物包括[马](马.md)、[驴](驴.md)、[骡](骡.md)、、[僵尸马](僵尸马.md)、[猪](猪.md)、[炽足兽](炽足兽.md)、[骆驼](骆驼.md)、[骆驼尸壳](骆驼尸壳.md)、[鹦鹉螺](鹦鹉螺.md)和[僵尸鹦鹉螺](僵尸鹦鹉螺.md)。

猪、炽足兽、驯服的鹦鹉螺和驯服的僵尸鹦鹉螺必须装备鞍才能被玩家骑乘。驯服的马、驯服的驴、驯服的骡、、驯服的僵尸马、骆驼、骆驼尸壳、驯服的鹦鹉螺和驯服的僵尸鹦鹉螺必须装备鞍才能被骑乘它的玩家控制。

对上述生物鞍会为其装备鞍。装备鞍的生物没有被骑乘时，对其[剪刀](剪刀.md)可以剪下所装备的鞍，但带有剪刀的发射器不能。

驯服的马、驯服的驴、驯服的骡、、驯服的僵尸马、骆驼、骆驼尸壳、鹦鹉螺和僵尸鹦鹉螺可以在潜行时对其按键或在骑乘时按键打开其物品栏，并将鞍放入其鞍槽或从其鞍槽取出。

装备鞍的骆驼和骆驼尸壳可以被2个玩家骑乘。
