# 携带版0.15.0.b1

*页面ID: 21637* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.15.0 alpha build 1**<ref>https://web.archive.org/web/0/https://www.mojang.com/2016/06/whats-in-015-the-friendly-update-for-pocket-win-10/</ref>是[v0.15.0 alpha](携带版0.15.0.md)的第一个主要测试版，发布于2016年6月3日，加入了[活塞](活塞.md)、[马](马.md)、[命名牌](命名牌.md)、[成就](成就.md)、[丛林神庙](丛林神庙.md)、[胡萝卜钓竿](胡萝卜钓竿.md)以及其他一些新特性。

# 新内容
# = 方块 =
* *[活塞](活塞.md)和[黏性活塞](黏性活塞.md)**
* 新的红石元件。
* 用于推动或拉动方块。
* 数据值为6或7的活塞六面均为侧面纹理，但数据值为6的活塞无法激活。
* 新的动画：[活塞头](活塞头.md)的下端明显更粗。
* 能够推动[方块实体](方块实体.md)，比如[箱子](箱子.md)。
* 能被放置在方块侧面的方块实体（比如[拉杆](拉杆.md)）能在活塞或黏性活塞上放置。

* *[侦测器](侦测器.md)**
* 新的红石元件。
* 用于检测[方块更新](Tutorial:方块更新感应器.md)。

# = 物品 =
* *[食物](食物.md)**
* [生羊肉](生羊肉.md)
* [熟羊肉](熟羊肉.md)

* *[刷怪蛋](刷怪蛋.md)**
* [马](马.md)
* [僵尸马](僵尸马.md)
* [骷髅马](骷髅马.md)
* [驴](驴.md)
* [骡](骡.md)
* [流浪者](流浪者.md)
* [尸壳](尸壳.md)
* [凋灵骷髅](凋灵骷髅.md)

* *[火焰弹](火焰弹.md)**
* 用于点燃火焰。

* *[命名牌](命名牌.md)**
* 用于为生物自定义名称。

* *[拴绳](拴绳.md)**
* 用于拴住生物。

* *[胡萝卜钓竿](胡萝卜钓竿.md)**
* 用于吸引和控制猪。

* *[药箭](药箭.md)**
* 用炼药锅取得。
* 击中生物会使其获得对应[状态效果](状态效果.md)。

* *[马铠](马铠.md)**
* 可以用[炼药锅](炼药锅.md)染色。
* 可以用[皮革](皮革.md)合成。
* 用于为[马](马.md)提供护甲值。

# = 生物 =
* *常规**
* 加入了当[动物](动物.md)被喂食时的动画。

* *[流浪者](流浪者.md)**
* 骷髅的寒冷变种。
* 自然生成于积雪的生物群系里。

* *[尸壳](尸壳.md)**
* 僵尸的干燥变种。
* 自然生成于沙漠生物群系里。

* *[马](马.md)**
* 新的可骑乘生物。
* 包含了[骷髅马](骷髅马.md)陷阱。

* *[骡](骡.md)**
* 通过马和驴繁殖生成。

* *[驴](驴.md)**
* 新的可骑乘生物。
* 可以为其装备箱子。

# = 世界生成 =
* *[村庄](村庄.md)**
* 加入了新的村庄。
* * 针叶林村庄，用[云杉木](原木.md)替代[橡木](原木.md)。
* * 热带草原村庄，用[金合欢木](原木.md)替代橡木。

* *[僵尸村庄](僵尸村庄.md)**
* 会自然生成僵尸村民。
* 村庄内没有光源和门。
* 建筑以[苔石](苔石.md)做地板。
* 屋子里会生成蜘蛛网。

* *[丛林神庙](丛林神庙.md)**
* 自然生成于丛林生物群系里。
* 包含了陷阱和宝藏箱。

# = 游戏内容 =
* *[成就](成就.md)**
* iOS和Android上的成就（需要登录到Xbox Live）。
* * 更多的成就（共56个）。

* *交互按钮**
* 骑乘猪时使用[胡萝卜钓竿](胡萝卜钓竿.md)加速。
* 使用[命名牌](命名牌.md)为[生物](生物.md)命名。
* 使用[拴绳](拴绳.md)。
* 使用[摄像机](摄像机.md)拍照。

* *骑猪**
* 在加速时有新音效。

# = 常规 =
* *[声音](声音.md)**
* 加入了在[方块](方块.md)上跳跃时的[音效](音效.md)。

* *标题画面**
* “皮肤”按钮。
* * 现在为主菜单上的图标。
* 新的“商店”按钮。
* * 用于购买[皮肤包](皮肤包.md)和[资源包](资源包.md)。

* *[资源包](附加包.md)**
* 一些资源包不完整。
* 在游戏和[设置](设置.md)菜单中，它们被称为资源包。
* 在游戏中，当从设置菜单中管理可用的资源包时，会有移动和选择它们的选项，就像在Java版中那样。
* 除此之外，在游戏文件夹中有一个叫做的文件夹用来储存资源包。

* *[多人游戏](多人游戏.md)**
* 现在可以和Xbox Live好友在线多人游戏。

* *UI**
* 与Windows 10版共享的新的主菜单UI。
* 新的皮肤界面UI，有与主机版相似的旋转预览栏。

# 更改
# = 方块 =
* *[火](火.md)**
* 现在在闪电落下的地方会生成火。

* *[活板门](活板门.md)**
* 放置时不再需要支持方块。

* *[画](画.md)**
* 现在放置和破坏有声音了。

* *[炼药锅](炼药锅.md)和[漏斗](漏斗.md)**
* 玩家及部分生物可以站在中间凹陷的部分。

# = 物品 =
* *[剪刀](剪刀.md)**
* 现在破坏任何方块都会耗费耐久值。

# = 常规 =
* *[经验](经验.md)**
* 经验条在[创造模式](创造模式.md)中可见。

* *[多人游戏](多人游戏.md)**
* 在线游戏现在使用更少的带宽。

* *[声音](声音.md)**
* [音符盒](音符盒.md)现在更大声了。</onlyinclude>
