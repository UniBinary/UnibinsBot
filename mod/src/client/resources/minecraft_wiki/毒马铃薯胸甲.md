# 毒马铃薯胸甲

*页面ID: 167439* | *来源: Minecraft Wiki*

* *毒马铃薯胸甲（Poisonous Potato Chestplate）**是由马铃薯材料制成的[胸甲](胸甲.md)，可以抵抗饥饿值消耗。

# 用途

毒马铃薯胸甲可以像其他胸甲一样被装备在第二个盔甲槽中，但不提供任何[护甲值](护甲值.md)。

# = 食用=
当玩家的[饥饿值](饥饿值.md)即将消耗时，若[<code>neverEatArmor</code>](游戏规则/neverEatArmor.md)游戏规则为<code>false</code>，玩家会食用毒马铃薯胸甲，消耗40点耐久度并播放进食音效，取消这次饥饿消耗。

# = 削皮 =
装备毒马铃薯胸甲的生物被[马铃薯削皮刀](马铃薯削皮刀.md)会去除该胸甲，同时削下8个[马铃薯皮](马铃薯皮.md)。

# = 耐久度 =

在[玩家](玩家.md)承受任何可被盔甲防护的伤害时，玩家穿戴中的毒马铃薯胸甲会消耗耐久度，每减免前伤害会消耗毒马铃薯胸甲1耐久度（向下取整，但不会低于1）；如果该[伤害类型](伤害#伤害类型.md)穿透护甲值的防护效果，那么盔甲的耐久度不会下降。

如果毒马铃薯胸甲有[荆棘](荆棘.md)魔咒，成功通过荆棘魔咒造成伤害还会额外消耗2耐久度。

穿在非玩家生物上的毒马铃薯胸甲不会因受到[伤害](伤害.md)而失去耐久度。

毒马铃薯胸甲的耐久度为240。

# = 发射器 =
[发射器](发射器.md)在使用毒马铃薯胸甲物品时，会向朝向的1格内有空的适当盔甲槽的[玩家](玩家.md)、[僵尸](僵尸.md)及其变种、[骷髅](骷髅.md)及其变种、[村民](村民.md)、[猪灵](猪灵.md)、[猪灵蛮兵](猪灵蛮兵.md)或[盔甲架](盔甲架.md)装备毒马铃薯胸甲，否则毒马铃薯胸甲物品会从发射器中被抛出。
