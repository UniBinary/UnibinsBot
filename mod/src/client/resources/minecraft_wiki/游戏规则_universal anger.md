# 游戏规则/universal anger

*页面ID: 128308* | *来源: Minecraft Wiki*

* *universal_anger**是控制[条件敌对生物](生物#条件敌对.md)被激怒时行为的[游戏规则](游戏规则.md)。

# 行为
当universal_anger为<samp>true</samp>时，[末影人](末影人.md)、[北极熊](北极熊.md)、[猪灵](猪灵.md)、[狼](狼.md)、[蜜蜂](蜜蜂.md)和[铁傀儡](铁傀儡.md)被激怒时会对附近的所有[玩家](玩家.md)敌对，而不再限于激怒它们的玩家。

无论此游戏规则为何值，[蜜蜂](蜜蜂.md)所在[蜂巢](蜂巢（方块）.md)被破坏时仍然会攻击附近所有玩家。<ref></ref>
