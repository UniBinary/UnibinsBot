# 缤纷更新

*页面ID: 13602* | *来源: Minecraft Wiki*

[缩略图|300px|Mojang发布的缤纷更新的图像](File:Bountiful Update.png.md)

* *缤纷更新（Bountiful Update）**是[Java版](Java版.md)的一次主要更新，发布于2014年9月2日。本次更新的名称是Mojang官方博客于2014年8月22日公布的。<ref></ref>本次更新的两个主要内容分别针对地图制作和生存元素。

此次更新的开发始于[14w02a](14w02a.md)，其发布于2014年1月9日。

# 重要特性

# = 地图制作 =
* *新内容**
* 5条新的[游戏规则](游戏规则.md)
* * <code>logAdminCommands</code>、<code>randomTickSpeed</code>、<code>reducedDebugInfo</code>、<code>sendCommandFeedback</code>和<code>showDeathMessages</code>
* 5种新的[统计信息](统计信息.md)
* * <code>crouchOneCm</code>、<code>sprintOneCm</code>、<code>talkedToVillager</code>、<code>timeSinceDeath</code>和<code>tradedWithVillager</code>
* 12种新的[命令](命令.md)
* * 、、、、、、、、、、和
* 13种新的[NBT标签](实体数据格式.md)
* * <code>BlockEntityTag</code>、<code>CanDestroy</code>、<code>CanPlaceOn</code>、<code>CommandStats</code>、<code>generation</code>、<code>HideFlags</code>、<code>Lock</code>、<code>NoAI</code>、<code>PickupDelay</code>、<code>rewardExp</code>、<code>SelectedItem</code>、<code>ShowParticles</code>和<code>Silent</code>
* 新的用于选择[实体](实体.md)的[目标选择器](目标选择器.md)<code>@e</code>

* *修改**
* [冒险模式](冒险模式.md)默认无法与方块互动
* 更改许多现存命令的参数与范围
* [方块模型](方块模型.md)现在可以使用自定的纹理了
* [告示牌](告示牌.md)和[成书](成书.md)可以使用.json格式的文本了
* 手持[刷怪蛋](刷怪蛋.md)点击[刷怪笼](刷怪笼.md)会使得刷怪笼内的[生物](生物.md)变化

# = 生存 =
* *新内容**
* 36种新方块：[花岗岩](花岗岩.md)、[安山岩](安山岩.md)、[闪长岩](闪长岩.md)和各自的磨制变种；3种[海晶石](海晶石.md)；与[红砂岩](红砂岩.md)相关的5种方块；5种材料的[门](门.md)、[栅栏](栅栏.md)及[栅栏门](栅栏门.md)；以及[海晶灯](海晶灯.md)、[湿海绵](湿海绵.md)、[黏液块](黏液块.md)、[砂土](砂土.md)、[屏障](屏障.md)、[铁活板门](铁活板门.md)和[旗帜](旗帜.md)
* 新的水下结构：[海底神殿](海底神殿.md)
* 3种新生物：[末影螨](末影螨.md)，[守卫者](守卫者.md)和[兔子](兔子.md)
* [绵羊](绵羊.md)被杀死时掉落[生羊肉](生羊肉.md)
* [盔甲架](盔甲架.md)
* [跳跃药水](跳跃药水.md)，魔咒[深海探索者](深海探索者.md)和成就[](成就/Java版.md)
* 新的游戏模式[旁观模式](旁观模式.md)和世界类型[自定义](自定义.md)和[调试模式](调试模式.md)
* 添加[双层皮肤](皮肤#双层皮肤.md)
* 添加有更细手臂的默认皮肤[“Alex”](玩家.md)

* *修改**
* 修改了[附魔](附魔.md)系统和修理系统的平衡性
* * 附魔现在需要消耗[青金石](青金石.md)
* 在[信标](信标.md)上方放置[染色玻璃](染色玻璃.md)可以改变信标光柱的颜色
* 可以通过[工作台](工作台.md)制作[苔石](苔石.md)、[苔石砖](苔石砖.md)和[雕纹石砖](雕纹石砖.md)了
* [裂纹石砖](裂纹石砖.md)和[海绵](海绵.md)可通过烧制取得
* 旋转[物品展示框](物品展示框.md)可向一个方向发出红石信号，总共可以输出八种不同等级的红石信号
* [阳光传感器](阳光传感器.md)可变为[月光传感器](阳光传感器#作为夜晚感应器.md)
* [激活铁轨](激活铁轨.md)被充能时会使其上方[矿车](矿车.md)内的实体下车
* [箭](箭.md)在[水](水.md)下减速会更快，而且[着火](着火.md)的箭在水中会被熄灭
* 改进了生物的行为和AI
* * 大多数生物可以[游泳](游泳.md)了，比如[史莱姆](史莱姆.md)
* * 大多数生物能够像[僵尸](僵尸.md)一样寻路，比如被激怒的[僵尸猪人](僵尸猪人.md)
* * [骷髅](骷髅.md)在被[狼](狼.md)攻击时会逃走而不是反击
* * [蜘蛛](蜘蛛.md)不再能透过方块看到玩家
* * [铁傀儡](铁傀儡.md)会攻击[苦力怕](苦力怕.md)
* * 喂食幼崽可以加快它们的成长
* * 多数生物会从即将爆炸的苦力怕身边逃走
* * 苦力怕、骷髅、[凋灵骷髅](凋灵骷髅.md)和僵尸被[闪电苦力怕](闪电苦力怕.md)杀死时会掉落它们的[头](头.md)
* [村民](村民.md)的行为改变
* * 现在村民会收获作物
* * 村民只在有意愿时繁衍
* * 有额外的职业和[交易](交易.md)组合
* * 被[闪电束](闪电束.md)击中时会变成[女巫](女巫.md)
* 被[命名牌](命名牌.md)命名过的宠物死亡时将会显示[死亡消息](死亡消息.md)

# = 性能变化 =
* 缓冲区顶点对象（Vertex Buffer Object）被加入视频设置
* 各向异性过滤（Anisotropic Filtering）被移除
* 高级OpenGL被移除以支持高级洞穴剔除算法<ref>http://tomcc.github.io/2014/08/31/visibility-1.html</ref>
* 使用64位Java和分配2GB内存给游戏时渲染距离最远为32个区块

# 跟进版本
* [Java版1.8.1](Java版1.8.1.md)带来了性能优化和漏洞修复；
* [Java版1.8.2](Java版1.8.2.md)带来了新的[统计](统计.md)和调试屏幕的[渲染图表](调试屏幕#渲染图表.md)，以及性能优化和漏洞修复；
* [Java版1.8.3](Java版1.8.3.md)在[Java版1.8.2](Java版1.8.2.md)后很快发布来修复其中的崩溃；
* 在[Java版1.8.4](Java版1.8.4.md)、[Java版1.8.5](Java版1.8.5.md)、[Java版1.8.6](Java版1.8.6.md)和[Java版1.8.7](Java版1.8.7.md)中，对一些漏洞进行了修复；
* [Java版1.8.8](Java版1.8.8.md)中包含了新的Realms小游戏，在Realms中使用纹理包的功能，以及更多漏洞的修复。
* [Java版1.8.9](Java版1.8.9.md)添加了Realms通知功能，并修复了一些漏洞。

# 你知道吗
* [Java版1.8](Java版1.8.md)到[Java版1.8.9](Java版1.8.9.md)的所有版本[协议版本](协议版本.md)相同，也就是说它们互相兼容。
