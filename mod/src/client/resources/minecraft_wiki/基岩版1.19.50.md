# 基岩版1.19.50

*页面ID: 98839* | *来源: Minecraft Wiki*

* *1.19.50**是的一次次要更新，发布于2022年11月29日<ref></ref>。此次更新进一步完善了触摸控制，通过[实验性玩法](实验性玩法.md)加入了部分[1.20.0](基岩版1.20.0.md)的特性，并修复了一些漏洞。

# 更改
# = 方块 =

* *[末影人](末影人.md)**
* 将跟随范围由32格更改至64格。

* 更改了Steve和Alex的默认皮肤。

* 更改了模型和纹理。

# = 常规 =
* *[角色创建器](角色创建器.md)**
* 加入了一个介绍新的Minecraft初始角色和使用这些角色作为外观的方式的新流程。

* *[实验性玩法](实验性玩法.md)**
* 移除了“旁观模式”子选项。

* 现在触控设备默认启用新的触摸控制。
* 优化了触摸控制下长按一组物品来将物品拆分的体验。
* 将拖拽物品前按住物品的停顿时长由120毫秒增加至180毫秒，以更轻松地滚动物品栏界面。
* 改进了新的触控模式下同时按下按钮并移动视角的方式。
* 移除了攻击和交互的操作延时。
* 将摇杆未被锁定时的可拖动范围更改为与摇杆被锁定时相同的可拖动范围。
* * 若已开启“自动冲刺”选项，将摇杆略微拖动到摇杆背景区域上方时会开始疾跑；将摇杆拖动回摇杆背景区域时则会停止疾跑。

* *键鼠控制**
* 现在点击部分功能型方块（如[铁砧](铁砧.md)）使用界面的输出框时，输出的物品会直接进入玩家的物品栏。

* *用户界面**
* 更改了复制世界的错误处理流程，现在会显示一个错误弹窗而不是弹出警告。
* 更改了“”选项的文字颜色，以提升阅读体验。

* 修复了不能使用新的触摸控制与部分资源包下的快捷栏交互的问题。（）

* 调整了状态效果图标，现在会在屏幕宽度上排成一行，以在触控模式下适应新的触摸控制。
* 移除了攻击和交互的操作延时。（）
* 将摇杆未被锁定时的可拖动范围更改为与摇杆被锁定时相同的可拖动范围。若已开启“自动冲刺”选项，将摇杆略微拖动到摇杆背景区域上方时会开始疾跑；将摇杆拖动回摇杆背景区域时则会停止疾跑。
