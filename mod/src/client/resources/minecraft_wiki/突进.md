# 突进

*页面ID: 168381* | *来源: Minecraft Wiki*

* *突进（Lunge）**是一种使用[矛](矛.md)进行戳刺攻击时将攻击者向前推进的[魔咒](魔咒.md)。

# 获取

# 用途

突进魔咒仅影响矛的戳刺攻击，且需要攻击者不在水中、不处于滑翔状态或骑乘状态。

在使用具有突进的矛进行戳刺攻击时，攻击者会获得一个向正前方的水平速度，每级增加9.16米/秒。此水平速度是理论值，增加的水平速度的方向是当前生物视角方向的在水平面上的投影的方向，也即生物的视角越偏向水平方向，获得的速度就越接近理论值，而生物视角正向上方或下方时无法获得额外速度。

突进魔咒每生效一次，矛就会损失1点耐久度，此损失和矛攻击造成的耐久消耗独立计算，可以被[耐久](耐久.md)魔咒减少。

如果攻击者是玩家，则突进魔咒生效还需要玩家饥饿值大于，且魔咒生效时还会增加玩家的[消耗度](消耗度.md)，每级增加4点消耗度。在饱和度为0的情况下，这相当于每级突进魔咒会额外消耗饥饿值。创造模式的玩家不受饥饿值限制。

由于[僵尸](僵尸.md)、[僵尸村民](僵尸村民.md)、[尸壳](尸壳.md)、[僵尸猪灵](僵尸猪灵.md)和[猪灵](猪灵.md)仅会使用矛进行冲锋攻击，因此它们事实上无法使用突进魔咒。
