# Java版1.19.4-pre3

*页面ID: 102662* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.19.4-pre3**是[Java版1.19.4](Java版1.19.4.md)的第3个预发布版，发布于2023年3月1日<ref></ref>，更改了[药水](药水.md)、[药箭](药箭.md)和对应[粒子](Java版粒子.md)的颜色，加入了转储动态纹理内容的功能，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 现在按可以将动态纹理（如纹理图集、[地图](地图.md)等）转储到下。

# 更改
# = 物品 =
* *[药水](药水.md)和[药箭](药箭.md)**
* 更改了具有以下种类的状态效果的药水（所有形式）和药箭的颜色：
* * [抗火](抗火.md)
* * [瞬间伤害](瞬间伤害.md)
* * [隐身](隐身.md)
* * [跳跃提升](跳跃提升.md)
* * [幸运](幸运.md)
* * [夜视](夜视.md)
* * [中毒](中毒.md)
* * [抗性提升](抗性提升.md)
* * [](缓慢.md)
* * [迅捷](迅捷.md)
* * [力量](力量（状态效果）.md)
* * [水下呼吸](水下呼吸（状态效果）.md)

# 更改（实验性）
# = 物品 =
* *[陶片](陶片.md)**
* 更改了弓箭纹样陶片应用于[饰纹陶罐](饰纹陶罐.md)上的纹样纹理，以及其物品纹理。

# = 常规 =
* *[标签](Java版标签.md)**
* 将方块标签中的改为。
