# Minecraft
# = 方块和物品 =
*  - 生成于[主世界](主世界.md)的非固体植物方块，曾名为“草”（Grass）。
*  - 矮草丛的两格高变种。
*  - 一种类似于矮草丛的植物方块。
*  - 蕨的两格高变种。
*  - 生成在[沙漠](沙漠.md)和[恶地](恶地.md)的非固体植物方块。
*  - 矮枯草丛的变种。
*  - 上表面有草皮纹理的[泥土](泥土.md)，生成于主世界，属于固体方块。
* *  - 对草方块使用[锹](锹.md)生成的方块，曾名为“草径”（Grass Path）。
*  - 可以[含水](含水.md)的植物方块。
* *  - 海草的两格高变种。
* 、和 - 生成于[下界](下界.md)的非固体植物方块。
*  - 一种小型花。
*  - 通过种植瓶子草植株获得的大型花。
* *  - 对[耕地](耕地.md)使用瓶子草荚果生成的方块。
* *  - 能够种出瓶子草的物品，可通过[嗅探兽](嗅探兽.md)挖掘获得。
*  - 由[小麦](小麦.md)合成的方块。
*  - 在沼泽和河流附近自然生成的装饰性方块。
*  - 基岩版已移除的方块，与草方块有相似的纹理。

# = 生物群系 =
*  - 地表由草方块组成的山地类生物群系。
*  - 由草方块组成、地势平坦的生物群系，常被称为“草原”。
*  - 与平原相似的温暖生物群系。
* *  - 稀有且地形混乱的热带草原变种。

# = 地物 =
*  - 由干草捆堆叠而成的地物，生成于平原、沙漠和热带草原村庄。
