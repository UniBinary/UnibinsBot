* *运输（Transportation）**包含了玩家在[世界](主世界.md)或[不同维度之间](:Category:维度.md)（[主世界](主世界.md)、[下界](下界.md)和[末地](末地.md)）移动的方式。

# 方式

* *注意：**在任何一种运输方式中的速度测量，所有速度以国际单位表示。1立方米代表1个方块，所以1米每秒等于每秒一格。下表速度的测量不考虑或等[状态效果](状态效果.md)、[灵魂疾行](灵魂疾行.md)或[迅捷潜行](迅捷潜行.md)等[魔咒](魔咒.md)。某些方式不受状态效果的影响。如果玩家具有缓降状态效果，则仅鞘翅比下面列出的要慢，其他不变。

# = 状态效果 =
使用[药水](药水.md)[效果](状态效果#效果列表.md)（包括[信标](信标.md)效果），行走和疾跑的速度变得可与其他运输方式的速度具有可比性。

每一级允许玩家的行走速度与前一级的疾跑速度几乎相同，带有速度II时疾跑只比矿车全速运行和骑猪时加速稍微慢一点。拥有充足的食物和药水支持的话，疾跑可能比建造高速交通系统更有效果。

# = 命令 =
使用可达到极高或极低的速度。此时，玩家移动可能比区块加载的速度快。

# = 魔咒 =
[深海探索者](深海探索者.md)能减少水中的减速，同时减小流水推动玩家的动力。[灵魂疾行](灵魂疾行.md)能提高玩家在[灵魂沙](灵魂沙.md)和[灵魂土](灵魂土.md)上的移动速度。[迅捷潜行](迅捷潜行.md)能提高玩家[潜行](潜行.md)时的移动速度。

# = 垂直运输 =
以下是纯粹垂直移动的例子：

掉落速度更复杂：每刻（秒），不在飞行状态的玩家和生物的垂直速度会减少（更少向上动力，更多向下动力）0.08格每刻（1.6米每秒），再乘以0.98。这**将会**产生每刻3.92格或每秒78.4米的极限速度。然而，世界的最大建筑高度不够高，无法达到此速度：从第256层掉落到基岩需要5.5秒，落地时速度为每刻3.5格（每秒70米）。但是可以用[鞘翅](鞘翅.md)和[烟花火箭](烟花火箭.md)等方式来达到更高的高度，以获得更大的落地速度。

以下函数可用于计算一个自由落下<math>t</math>刻的玩家的速度<math>v</math>（米/刻）：<math>v = 3.92 \times (0.98^t - 1)</math>。计算结果为负数代表速度方向向下。

结合上方的函数能计算出自由落体t刻下落距离<math>d</math>（米）的公式：<math>d = 3.92 \times (99 - 49.50 \times (0.98^t + 1) - t) </math>。掉落距离为负数代表位移方向向下。<!-- 修复了移位公式，现在适用于256格天空限制内的所有移位。 -->在[此处](https://docs.google.com/document/d/1mMNaxMQM2tojSABmi4D0k2SyLrYyr0-QihPe9-fstDQ/edit)可以找到该距离的粗略推导，以及用于生成精确距离的Java代码。

# = 其他运输方式 =
* 玩家也可以用[活塞](活塞.md)来运输。
* * 用活塞、[红石块](红石块.md)和[黏液块](黏液块.md)制造[复杂的飞行机械](Tutorial:飞行器.md)是有可能的。
* [死亡](生命#死亡.md)是会带玩家到[床](床.md)或[出生](出生.md)点的即时运输方式（除非是极限模式），但代价是所有物品和经验（除非[游戏规则](游戏规则.md)为<code>true</code>）。
* * 如果玩家在激活的[返回传送门](返回传送门.md)附近，玩家可以进入传送门，离开[末地](末地.md)，从而在不死亡的情况下即时传送到他们的床或出生点。
* ** 玩家可以将[末影珍珠](末影珍珠.md)投入返回传送门，末影珍珠会传送玩家到世界出生点附近。
* 身处一场[爆炸](爆炸.md)旁边会基于爆炸的强度，使玩家飞行一段距离。
* * 在和平难度下，爆炸不会对玩家造成伤害。
* * 在水中发生的爆炸不会对生物造成伤害。
* * TNT对水平方向玩家的推力似乎远远低于垂直方向玩家的推力，因此虽然将人炸上百米高空轻而易举，但是其不适合用于远距离水平投送玩家。
* 只要[矿车](矿车.md)和[船](船.md)是在玩家的4-5格内，都可以坐上去。把矿车放在一条直线上允许极快的运输（也就是矿车链瞬移），但在下界修一条冰道并用船行驶可以更快地移动。这也适用于带有鞍的猪，只要它们停留在适当的位置（放在栅栏上）。
* [船](船.md)存在一种运用气泡柱与水流的组合加速到极高速度（理论上限取决于区块加载速度和设备性能，可以达到200米每秒）的特殊交通方式，被称为[光速船](Tutorial:光速船.md)。
* 玩家能被[碰撞箱](碰撞箱.md)完整的方块和实体弹出，实体挤压的伤害可以用[梯子](梯子.md)等方块消除。
