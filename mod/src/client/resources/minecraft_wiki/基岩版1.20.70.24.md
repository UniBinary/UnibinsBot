# 基岩版1.20.70.24

*页面ID: 113576* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.70.24**（ChromeOS/Android）、**Preview 1.20.70.24**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.20.70](基岩版1.20.70.md)的第4个测试版，发布于2024年2月15日<ref name="feedbacksite"></ref><ref></ref>，在[实验性玩法](实验性玩法.md)中加入了物品形式的[风弹](风弹（物品）.md)和敌对生物[沼骸](沼骸.md)，并修复了一些漏洞。在PlayStation平台上，此版本仅对部分玩家开放。

# 新内容
# = 常规 =
* *[加载提示](加载提示.md)**
* 加入了一些[Realms](Realms Plus.md)故事相关的加载提示。
* * Android平台上暂时不可用。<ref name="feedbacksite"/>

* *[设置](设置.md)**
* 在设置中加入了“”滑块。
* * 用于修改[动作栏](动作栏.md)背景的不透明度，默认为60%。

# 更改
# = 方块 =
* *[大型蕨](大型蕨.md)**
* 现在被破坏后有概率掉落[小麦种子](小麦种子.md)。

* *[大型花](大型花.md)**
* 大型花的掉落数量不再受[时运](时运.md)魔咒影响。

# = 常规 =
* *[世界加载屏幕](世界加载屏幕.md)**
* 现在只会显示一个游戏模式文本。

# = 技术性 =
* *[附加包](附加包.md)和脚本引擎**
* 现在使用带有 "alpha_test_single_sided"}}的组件的方块会在玩家手中正确显示。

* *[基岩版编辑器](基岩版编辑器.md)**
* 修复了状态栏中显示的光标增量中会出现不正确的负号的问题。
* 为编辑器远程窗格加入了false}}选项。
* 在开始测试对话框的信息段落中加入了文本组件。
* 为扩展上下文创建了包含的服务。
* * 用于存储将为世界绘制的方块类型。
* * 更新了选择、立方体画笔和线条工具以支持使用该服务。
* 在世界选项中加入了用于修改主世界天气的状态菜单。

* *[市场](市场.md)的服务端驱动布局（SDL）**
* 为SDL屏幕加入了拥有不可滚动的布局的功能。
* 为布局加入了包含垂直填满填充物的功能。
* 修复了垂直填满对象在用户界面内的垂直制造器中无法运作的问题。

* *[角色创建器](角色创建器.md)**
* 加入了包含角色创建器动画逻辑的新模型。
* 更新了动画状态已更新时为触发更新绑定而做的逻辑，以防止每一帧更新的绑定会导致帧率大幅下降的问题。

* *性能与稳定性**
* 修复了将“单方块空岛”地图上传至Realms上时，客户端上会在远处生成超平坦世界的问题。
* * 若满足下列条件之一，则客户端连接至专用服务器或Realms时，客户端上不再会错误生成：
* ** 地图是超平坦世界
* ** 地图是市场地图
* * 该更改会覆盖专用服务器的对的设置。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“”和“测试版 API”子选项后才可使用。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了沼骸刷怪蛋。

* *[风弹](风弹（物品）.md)**
* [旋风人](旋风人.md)被玩家或驯服的狼杀死时掉落4-6个。
* 可由[玩家](玩家.md)和[发射器](发射器.md)发射。
* * 玩家发射的风弹比旋风人发射的多10%击退，但影响范围更小。
* * 玩家被自己发射的风弹击中时会重置摔落伤害，且摔落伤害只会从碰撞点以下开始累积。
* 每次使用后有0.5秒的冷却时间。

# = 生物 =
* *[沼骸](沼骸.md)**
* [骷髅](骷髅.md)的新变种。
* * 拥有生命值，不同于骷髅的。
* * 攻击行为与骷髅和流浪者相同。<ref></ref>
* * 发射[剧毒之箭](剧毒之箭.md)而非普通箭。
* 被玩家或驯服的狼杀死时，有概率掉落剧毒之箭。
* 自然生成于[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)生物群系，也会生成于[试炼密室](试炼密室.md)的部分[试炼刷怪笼](试炼刷怪笼.md)。

* *常规**
* [骷髅](骷髅.md)、[僵尸](僵尸.md)、[尸壳](尸壳.md)、[蜘蛛](蜘蛛.md)、[洞穴蜘蛛](洞穴蜘蛛.md)和[流浪者](流浪者.md)现在再次会在受到生物攻击时反击生物。（）
* * 被旋风人发射的风弹击中时仍不会反击旋风人。

# = 非生物实体 =
* *[风弹](风弹（实体）.md)**
* 旋风人发射的风弹的ID由重命名为。
* 加入了翻译字符串。（）
* 现在击中旋风人时会对其造成伤害。

# = 世界生成 =
* *[试炼密室](试炼密室.md)**
* 调整了生成位置以匹配。

# = 技术性 =
* *API**
* 加入了函数。
* * 用于创建新的空白结构。
* 加入了函数。
* * 用于以世界中的方块创建新的结构。
* 加入了 StructureTemplate): boolean}}函数。
* * 用于删除结构。
* 加入了 undefined}}函数。
* * 用于获取带有指定标识符的结构。
* 加入了 StructureTemplate, dimension: Dimension, location: Vector3, options?: StructurePlaceOptions)}}函数。
* * 用于在世界中放置结构。

# 修复
* *方块**
* 首次放置通过创造模式物品栏获得的无图案旗帜时不再会恢复原状。（）
* 大型花不再受时运魔咒影响。（）
* 大型蕨现在有概率掉落小麦种子。（）
* 调整了西瓜、红石矿石、荧石和下界疣受时运魔咒影响时的掉落物分布以匹配Java版。

* *命令**
* 命令方块界面现在会在成功编译命令后移除最后一条错误消息。（）

* *Realms**
* 修复了由于添加新的故事状态条目和俱乐部动态排序之间的资源竞争，从而触发Realms故事后访问Realms故事时发生的崩溃。
* 更改了Xbox平台上的Realms故事隐私和在线安全模态框，以显示二维码而非链接。

* *性能与稳定性**
* 修复了在部分平台上更改语言时游戏可能会卡死的问题。

* *用户界面**
* 现在资源包应用于世界时会启用新的死亡屏幕（仅测试版本）。
* 修复了显示“”模态框时游戏可能会卡死的问题。</onlyinclude>
