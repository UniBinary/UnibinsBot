# 水下TNT

*页面ID: 34245* | *来源: Minecraft Wiki*

* *水下TNT（Underwater TNT）**是一种[爆炸](爆炸.md)时无视[水](水.md)的[TNT](TNT.md)变种，激活后为**被激活的水下TNT（Primed Underwater TNT）**。

# 生成
水下TNT不会生成在世界中。

# 破坏
水下TNT被挖掘时会立刻被破坏。

水下TNT被破坏后会掉落自身。

# 用途

水下TNT的行为与TNT一致，但生成的是被激活的水下TNT而非被激活的TNT。

# 行为

被激活的水下TNT爆炸时无视范围内的[水](水.md)，其余性质与被激活的TNT一致。
