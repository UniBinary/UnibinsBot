# 启动器0.3

*页面ID: 47736* | *来源: Minecraft Wiki*

* *0.3**是在2013年4月22日发布的一个[启动器](启动器.md)小型版本。

# 更改
* 在启动器选项卡中加入了*Local Version Editor (NYI)*（本地版本编辑器）。
* 加入了检查服务器状态的窗口。

# 修复
*  - 无法更新minecraft：Fatal error occured (4): null。
*  - 启动器上的选项卡按钮不会在密码和用户名框间切换。
