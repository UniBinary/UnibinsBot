# Java版1.4.4

*页面ID: 31630* | *来源: Minecraft Wiki*

</ref>}}
<onlyinclude>

* *1.4.4**是的一次次要更新，发布于2012年11月14日<ref></ref>，加入了音乐唱片wait和命令，更新了生物AI，并修复了一些漏洞。此版本不兼容1.4.2的服务端。

1.4.4的预发布版发布于2012年11月8日<ref></ref>，与正式版更新内容相同。

# 新内容
# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* 加入了唱片wait。

# = 命令格式 =
*
* * 给予特定魔咒。<ref group="注">此内容加入于1.4.4预发布版和1.4.4正式版之间。</ref>

# 更改
* *[苦力怕](苦力怕.md)**
* 现在被[骷髅](骷髅.md)杀死后可以掉落音乐唱片*11*。
* *[鱿鱼](鱿鱼.md)**
* 现在未在水下的时候会死亡。
* *幼年生物**
* 可以通过对应刷怪蛋右键于对应生物生成。
* *[蜘蛛网](蜘蛛网.md)**
* 创造模式下，飞过蜘蛛网不会减速，但走过去仍然会减速。
