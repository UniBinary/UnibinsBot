# 骑乘

*页面ID: 101589* | *来源: Minecraft Wiki*

[thumb|150px|正在騎馬的玩家](File:Sunny Horseback.png.md)
* *骑乘（Ride）**是实体被连接到另一个实体上的现象。

# 机制
骑乘会使一个实体被连接到另一个实体上。骑乘着其他实体的实体被称为**乘客（Passenger）**，被骑乘的实体被称为**坐骑（Mount）**。一个实体可以同时是乘客和坐骑。一个实体只能骑乘至多一个实体。对于支持多个乘客的实体，若该实体支持接受乘客控制，那么只有第一个乘客有对坐骑的控制。

坐骑的移动不受其乘客的碰撞箱的影响，因此对于坐骑来说可以进入的位置可能会将乘客置于危险的位置，如将乘客的头部置入方块的内部而导致其[窒息](窒息.md)。

大多数实体的通常骑乘方式只支持一个乘客，[船](船.md)、[竹筏](竹筏.md)、[骆驼](骆驼.md)和[骆驼尸壳](骆驼尸壳.md)支持两个乘客，[快乐恶魂](快乐恶魂.md)支持4个乘客。不过通过命令修改实体数据，一个实体可能被任意数量的实体骑乘。

玩家与非玩家生物同时骑乘支持多个乘客的坐骑时，玩家总是会取得前排。

[玩家](玩家.md)离开世界会导致与其有骑乘关系的实体全部随玩家从世界中消失，在玩家再次进入世界中时与玩家一同生成，除非受影响的实体有其他的玩家乘客。

[标记](标记.md)不能被其他实体骑乘。

乘客有以下的行为：
* 乘客的位置被锁定在其坐骑上，即乘客不能被任何效果影响位置和动量，包括实体之间的碰撞、实体和方块的碰撞、[击退](伤害#击退.md)、[爆炸](爆炸.md)、[钓鱼竿](钓鱼竿.md)、[末影珍珠](末影珍珠.md)、[紫颂果](紫颂果.md)、具有[激流](激流.md)魔咒的[三叉戟](三叉戟.md)、[末影人](末影人.md)和[潜影贝](潜影贝.md)的传送能力、[末地折跃门](末地折跃门（方块）.md)的传送。
* 乘客不会累积下落高度，且有下落高度时骑乘会重置下落高度。
* * 因此，乘客是玩家时，使用[重锤](重锤.md)攻击无法触发猛击。
*
* 乘客是玩家时，不能选中坐骑，因此也不能对其进行[近战攻击](近战攻击.md)或交互。
* 乘客是玩家时，不能选中坐骑的其他乘客，因此也不能对其进行近战攻击或交互。
* 乘客是玩家且玩家在[水](水.md)或[雨](雨.md)中使用带有[激流](激流.md)附魔的[三叉戟](三叉戟.md)时，玩家不会飞出，而坐骑会受到玩家命中生物的伤害。
* 乘客是玩家且坐骑是一种生物时，坐骑的[生命](生命.md)会以生命条的形式显示在玩家的[平视显示器](平视显示器.md)上玩家生命条的对侧。

* * 如果坐骑免疫摔落伤害，伤害不会被传递给乘客。

# 解除骑乘方式
生物通常不会自行离开坐骑，不过有多种效果会使乘客（包括非自愿地）脱离自己的坐骑：
* 乘客被另一个生物使用[矛](矛.md)的冲锋攻击击中。
* 乘客被[钓鱼竿](钓鱼竿.md)牵引。
* 乘客是玩家时，玩家按下。
* 乘客的坐骑死亡或毁除。
* 乘客骑乘未驯服的马、驴、羊驼时被这些生物赶下。
* 乘客骑乘在[水](水.md)中的羊驼、行商羊驼导致其被水淹没而被这些生物赶下。
* 乘客骑乘驶过激活的[激活铁轨](激活铁轨.md)的矿车时被赶下。
* 乘客被}}或}}指定为目标。
* 乘客的坐骑被指定为目标。
* 乘客被命令传送。

# = 鸡骑士 =

* *鸡骑士（Chicken Jockey）**<ref></ref>是幼年[僵尸](僵尸.md)及其变种骑乘着[鸡](鸡.md)的生物组合。

每一只幼年僵尸、幼年尸壳、幼年僵尸村民、幼年溺尸或幼年僵尸猪灵都有5%的概率在生成时检测以生成地点为中心的10×6×10长方体区域里存在的鸡，如果存在鸡，则幼年僵尸会直接生成在任意一只鸡身上形成鸡骑士。如果没有检测到鸡，则会有额外5%的概率生成为骑着一只新的鸡的幼年僵尸。在一个无鸡的环境里，每只幼年僵尸都有0.25%的概率形成鸡骑士；如果在这个区域引入鸡，那么形成概率就会增加到0.4875%。

幼年僵尸、幼年尸壳、幼年僵尸村民和幼年溺尸有15%的概率骑乘变成一只鸡骑士。

鸡骑士中的鸡会获得乘客的速度和行为，并停止下蛋。

# = 生物骑乘炽足兽 =

# = 灾厄村民骑乘劫掠兽 =

在[袭击](袭击.md)中生成的[劫掠兽](劫掠兽.md)在被生成时可能会同时生成骑乘着自身的[掠夺者](掠夺者.md)、[卫道士](卫道士.md)或[唤魔者](唤魔者.md)。

一次袭击中可生成多达7只劫掠兽。非骑乘状态的劫掠兽生成在第3波，被掠夺者骑乘的生成在第5波和第8波，被卫道士骑乘的生成在第7波和第8波，被唤魔者骑乘的也生成在第7波和第8波。

一次袭击中可生成多达5只劫掠兽。非骑乘状态的劫掠兽生成在第3波和第5波，被掠夺者骑乘的生成在第5波和第7波，被唤魔者骑乘的生成在第7波。
