# 启动器2.3.280

*页面ID: 97155* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.3.280**是一次[启动器](启动器.md)更新，发布于2022年7月6日。

# 新内容
* 在Java版的“开始游戏”标签页上加入了有关[Java版1.19.1](Java版1.19.1.md)中新的举报功能的提示。

# 更改
* 将“开始游戏”标签页上的“”/“启动游戏”按钮更改为橙色。
* 改进了游戏安装流程。
* 更新了配置页的下拉菜单。

# 修复
* 修复了一些本地化问题。
*  - 联网时启动器会处于离线模式。
*  - 按住Windows键的同时点击启动器中的按钮会出现问题。
*  - 在启动器主菜单上显示的“有什么新内容？”按钮英文缺少问号。
