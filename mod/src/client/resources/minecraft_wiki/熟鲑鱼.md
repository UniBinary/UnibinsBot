# 熟鲑鱼

*页面ID: 10518* | *来源: Minecraft Wiki*

* *熟鲑鱼（Cooked salmon）**是一种由[生鲑鱼](生鲑鱼.md)烹饪得到的[食物](食物.md)。

# 获取
# = 生物掉落物 =

# = 交易 =

# = 箱子战利品 =

# = 烹饪 =
熟鲑鱼可以用[生鲑鱼](生鲑鱼.md)在[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或[营火](营火.md)中烹饪得到。

# 用途
# = 食物 =

手持熟鲑鱼按住键即可食用，每个熟鲑鱼可以回复。

# = 狼 =
熟鲑鱼可用于给狼回复的生命值。然而和其他狼可以吃的食物不同的是，熟鲑鱼不能用于加快幼年狼的生长以及繁殖，因此只能在狼未处于满血状态下食用。

# = 鹦鹉螺和殭屍鸚鵡螺 =
熟鲑鱼可用于喂食驯服的[鹦鹉螺](鹦鹉螺.md)和[殭屍鸚鵡螺](殭屍鸚鵡螺.md)，使生命值已满的成年鹦鹉螺进入繁殖模式，治疗生命值未满的成年鹦鹉螺和殭屍鸚鵡螺的生命值，加速幼年鹦鹉螺约10%的成长时间。
