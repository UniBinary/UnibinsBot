# Minecraft LIVE - March 2025

*页面ID: 147106* | *来源: Minecraft Wiki*

* *Minecraft LIVE - March 2025**<ref></ref>是一场线上直播活动，于2025年3月22日17:00（UTC）举行。该场活动公布了[春意盎然](春意盎然.md)小更新的正式名称和发布日期，宣布了下个小更新的更新内容，并带来了一些关于[A Minecraft Movie](A Minecraft Movie.md)的独家消息。<ref></ref><ref></ref>

# 活动
# = 社区预热 =
在主要活动开始前有16分钟的社区预热活动，分享了世界各地YouTuber的Minecraft视频。

# = 版本公告 =
本次直播公布了Minecraft下一次小更新的正式名称[春意盎然](春意盎然.md)和更新内容。除此之外，还公布了[之后小更新](追逐天空.md)的部分更新内容，展示了定位栏功能、、物品[挽具](挽具.md)、方块[失水恶魂](失水恶魂.md)以及生物[小恶魂](小恶魂.md)和[快乐恶魂](快乐恶魂.md)，但并未公布其正式名称。

# =  =
本次直播展示了全新的Minecraft画质模式，为游戏加入了水面倒影、镜面高光、自发光纹理、定向光源和阴影的功能，并在直播中展示了富有Minecraft特色的像素反射与像素阴影。其完全运行在客户端。该功能计划在未来几个月内添加到[基岩版](基岩版.md)中，使用[延迟渲染](延迟渲染.md)运行，并在未来添加到[Java版](Java版.md)。

# = 电影宣传 =
本次直播邀请了在[A Minecraft Movie](A Minecraft Movie.md)中饰演娜塔莉的[爱玛·梅耶斯](wzh:爱玛·梅耶斯.md)讲述了一段自己与Minecraft的经历，并带来了一个电影小片段。主要活动结束后，她也与[Jens Bergensten](Jens Bergensten.md)、Agnes等人一同体验了[A Minecraft Movie直播活动](A Minecraft Movie直播活动.md)。

# = 游戏演示 =
主要活动结束后，主持人Vu及Agnes、Snifferrish与Gustav演示了春意盎然小更新中的主要变化、之后小更新的定位栏功能以及新生物快乐恶魂及其相关特性。

官方于2025年3月19日发布此次活动的环节介绍。
