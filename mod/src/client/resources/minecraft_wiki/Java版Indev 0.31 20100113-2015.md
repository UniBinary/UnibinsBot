# Java版Indev 0.31 20100113-2015

*页面ID: 172438* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2010年1月13日20:15（UTC）<ref>[Adura的IRC记录](#logs.md): "(15:16:42) <Notch> indev's been updated"</ref>，更改了水的流动机制。<ref></ref>

# 更改
# = 方块 =
* *[水](水.md)**<ref>[Adura的IRC记录](#logs.md): "(15:19:04) <Notch> it won't flow around along the same lever"..."(15:19:17) <Notch> it will drain downwards, however"</ref>
* 现在是有限的。
* * [海洋](海洋.md)仍然拥有无限的水。<ref>[Adura的IRC记录](#logs.md): "(15:43:00) <Droqen> Isak, remember the ocean is still infinite"</ref>
* * 有概率蒸发或概率复制。
* 流动的水现在略暗于静止的水。

# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 物品栏中的[玩家](玩家.md)模型现在是空的。

# 创造模式
</onlyinclude><onlyinclude>
该版本拥有一个创造模式版本<ref>[Minecraft Forums](https://www.minecraftforum.net/forums/archive/alpha/alpha-survival-single-player/796501-finite-water-today#c20) - "Notch turned off the health for a little time and i managed to get on the bottom on the floating islands alive."</ref>，由于有关[创造模式](创造模式.md)的代码在该版本发布之前就已被破坏，因此该版本存在一些漏洞，例如方块在物品栏中不是无限的。</onlyinclude>
