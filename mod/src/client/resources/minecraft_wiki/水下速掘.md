# 水下速掘

*页面ID: 35003* | *来源: Minecraft Wiki*

* *水下速掘（Aqua Affinity）**是一种防止水下[挖掘](挖掘.md)速度惩罚的头盔[魔咒](魔咒.md)。

# 获取

# 用途

玩家在头盔栏的物品拥有可生效的水下速掘魔咒时，[水下挖掘速度](属性/水下挖掘速度.md)变为<math>0.2 + 0.8l</math>，其中<math>l</math>为水下速掘魔咒的等级。魔咒生效不需要玩家接触地面，但当玩家未接触地面时仍会在这一步计算结束后受到0.2倍的挖掘速度惩罚。

玩家装备的物品具有水下速掘魔咒时，不会因头部处于水中而导致挖掘时间变为5倍。
