# 棘巧试炼

*页面ID: 119386* | *来源: Minecraft Wiki*

[alt=|thumb|棘巧试炼的官方Logo](File:Tricky Trials logo.png.md)
[thumb|棘巧试炼的官方艺术作品](File:Tricky Trials Key Art.png.md)
* *棘巧试炼（Tricky Trials）**是一次主要更新，发布于2024年6月13日。<ref></ref><ref></ref>此次更新在[Minecraft Live 2023](Minecraft Live 2023.md)期间宣布，更新的名称于2024年4月26日的*[Minecraft Monthly](Minecraft Monthly.md)*上公布。<ref></ref><ref></ref>此次更新主要内容为加入[试炼密室](试炼密室.md)结构，新生物[旋风人](旋风人.md)和[沼骸](沼骸.md)，[不祥事件](不祥事件.md)，以及大量的新方块与新物品。

在[Java版](Java版.md)上，此次更新的开发始于[1.20.3](Java版1.20.3.md)的快照[23w42a](23w42a.md)，其发布于2023年10月18日。

在[基岩版](基岩版.md)上，此次更新开发始于[基岩版1.20.50.21](基岩版1.20.50.21.md)，其发布于2023年10月18日。
