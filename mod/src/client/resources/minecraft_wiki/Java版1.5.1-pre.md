# Java版1.5.1-pre

*页面ID: 33505* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.5.1（预发布版）**是[Java版1.5.1](Java版1.5.1.md)的唯一一个预发布版，发布于2013年3月19日。<ref name="mojang.com">https://web.archive.org/web/201303/http://www.mojang.com/2013/03/minecraft-1-5-1-pre-release/</ref>

该预发布版于2013年3月20日被重新上传，以修复一个空指针崩溃<ref></ref>，该重新上传的版本最后成为了完整的1.5.1正式版版本。
