* *远古残骸（Ancient Debris）**是一种出现于[下界](下界.md)的罕见金属[矿石](矿石.md)。

# 生成
# = 自然生成 =
远古残骸在[下界](下界.md)中以[团簇](团簇.md)的形式生成。每个区块最多会生成或个团簇。

其中一个包含0-3块远古残骸，生成在8-24层之间，生成数量服从[三角形分布](wzh:三角形分布.md)；另一个包含0-2块远古残骸，生成在8-119层间，生成数量服从[离散型均匀分布](wzh:离散型均匀分布.md)。平均而言，远古残骸在Y=16高度的储量最为丰富。

远古残骸会在8-23层之间尝试生成2次，生成位置服从离散型均匀分布，每个团簇可能包含0-3块远古残骸；另一个会在8-119层之间尝试生成3次，生成位置服从离散型均匀分布，每个团簇可能包含0-2块远古残骸。<ref></ref>对于每个团簇，在尝试生成之初依照离散型均匀分布选取生成块数，第一块远古残骸直接生成于生成位置原点，第<math>n</math>块以生成位置原点为起点朝随机方向游走<math>2(n-1)</math>次后生成，每次游走的方向均服从离散型均匀分布；如果由于当前位置不是可以用于替换的方块或毗邻于空气方块导致生成失败，照常浪费一次生成块数。平均而言，受到洞穴以及熔岩湖的影响，远古残骸在Y=12-19之间储量最为丰富。

远古残骸在生成时，只会替换不与[空气](空气.md)相邻的[下界岩](下界岩.md)。然而，在远古残骸生成后生成的地物或结构可能会生成空气替换掉其周围的方块，使远古残骸暴露在空气中。

平均每个区块中会生成1.52个远古残骸<!-- 7.41M区块测试结果-->，正常情况下最多会有5个，但技术上来说，最大值可能达到20个<!-- 英文wiki写11，但根据上文计算，在区块的角落，有可能生成4*5=20个 -->，因为如果团簇生成在两个区块的边界上，该团簇最多可能会有2个远古残骸生成在相邻区块上。

# 破坏
挖掘远古残骸的合适工具是镐。远古残骸需要钻石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

远古残骸被破坏后会掉落自身。

# 用途
远古残骸主要用于通过冶炼获得[下界合金碎片](下界合金碎片.md)。

远古残骸的[爆炸](爆炸.md)抗性为1200，与[黑曜石](黑曜石.md)、[哭泣的黑曜石](哭泣的黑曜石.md)、[下界合金块](下界合金块.md)、[附魔台](附魔台.md)、[铁砧](铁砧.md)和[重生锚](重生锚.md)的爆炸抗性相同，因此远古残骸在正常情况下无法被爆炸摧毁。

与黑曜石不同，远古残骸和下界合金块一样可被[活塞](活塞.md)和[黏性活塞](黏性活塞.md)推拉，因此在[红石电路](红石电路.md)中有特殊用途，如防爆[活塞门](Tutorial:活塞使用#门.md)和活塞盾构机。但远古残骸在被活塞移动时可以被爆炸摧毁。

远古残骸会被[蓝色凋灵之首](蓝色凋灵之首.md)、[凋灵](凋灵.md)的接触和[末影龙](末影龙.md)破坏。[物品实体](物品实体.md)形式的远古残骸会漂浮在[熔岩](熔岩.md)上，不会被[火](火.md)和熔岩摧毁。但和其他物品一样，远古残骸的物品实体形式仍可被[仙人掌](仙人掌.md)摧毁。

# 你知道吗
* 远古残骸是所有可[烧炼](烧炼.md)物中产生[经验](经验.md)最多的。
* 每个[区块](区块.md)最多会生成5个远古残骸，所以有极小的概率能发现同一个角落上聚集了4个相邻区块的5个远古残骸，也就是20个相连的远古残骸。
