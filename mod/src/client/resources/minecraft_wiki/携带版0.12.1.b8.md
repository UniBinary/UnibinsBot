# 携带版0.12.1.b8

*页面ID: 27836* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.12.1 alpha build 8**是[v0.12.1 alpha](携带版0.12.1.md)的第8个测试版，发布于2015年8月11日，修复了一些漏洞。

# 更改
* 修改爆炸。
* 对控制器布局屏幕进行大量修改。
* 命名的标签在远处可以被看见。
* 在跳跃时被击中头部会使跳跃延迟。
* 增大了恶魂的碰撞箱。
* 经验球现在会被熔岩或者火摧毁。
* 甜菜根作物可以在村庄的农田里找到。
* 输入更平滑灵敏，特别是在滚动栏。
* 熔岩现在能免除所有掉落伤害。
* 现在可以使用方向键在游戏菜单中选择玩家列表。
* 现在所有物品的魔咒均显示等级 。

# 修复

* *其他**
* 退出游戏后，物品上的魔咒丢失。
* 将玻璃瓶放进酿造台后消失。
* 药水酿造完成后消失。
* 多人游戏下的附魔台失去功能。
* 已经连接的控制器无法使用。
* 返回至皮肤选择界面时，皮肤会重置。
* 修部分日语和繁体中文的字体使用了简体字型。
* 控制器上的翻转Y轴选项失去作用。
* 多人游戏下游戏随机崩溃。
* 按住前进按钮使得自动跳跃失去作用。
* 坐下的狼会在积雪里窒息而亡。
* 经验条会溢出显示。
* 安卓设备会显示试玩版信息。</onlyinclude>
