* *14w10c**是[Java版1.8](Java版1.8.md)的第16个快照，发布于2014年3月7日<ref></ref>，发布以修复[14w10a](14w10a.md)和[14w10b](14w10b.md)里的漏洞和崩溃。

# 更改
# = 方块 =
* *[铁栏杆](铁栏杆.md)**
* 现在会渲染它们的顶部/底部纹理，即使它的上下方连接着其他的铁栏杆。
