# 不祥试炼刷怪笼

*页面ID: 169632* | *来源: Minecraft Wiki*

* *不祥试炼刷怪笼（Ominous Trial Spawner）**是由[试炼刷怪笼](试炼刷怪笼.md)转化而来的方块，提供了更难的试炼挑战。

# 生成
不祥试炼刷怪笼可由[试炼刷怪笼](试炼刷怪笼.md)生成。当试炼刷怪笼满足以下条件时，它将转化为不祥试炼刷怪笼：
* 难度不为[和平](和平.md)。
* [游戏规则](游戏规则.md)为<code>true</code>。
* 检测到处于[生存模式](生存模式.md)或[冒险模式](冒险模式.md)且带有[试炼之兆](试炼之兆.md)状态效果的玩家。
* 满足以下条件之一：
* * 它正在等待玩家或正在激活阶段。
* * 它在冷却阶段中，但上一次激活时没有变为不祥试炼刷怪笼。

# 获取

不祥试炼刷怪笼的[方块物品](方块物品.md)是[试炼刷怪笼](试炼刷怪笼.md)，无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。

# 破坏
没有工具可以加速对不祥试炼刷怪笼的挖掘。

不祥试炼刷怪笼被破坏后不会掉落。

# 用途

与[刷怪笼](刷怪笼.md)和[试炼刷怪笼](试炼刷怪笼.md)一样，自然生成的不祥试炼刷怪笼均已设置好生成的生物种类；由玩家放置出的不祥试炼刷怪笼默认处于未激活状态（内部为空），对其[刷怪蛋](刷怪蛋.md)可以设置生物类型，但不会写入刷怪蛋中生物的附加数据。

若游戏规则为<code>false</code>，不祥试炼刷怪笼无法运作并生成生物。

# = 激活 =
处于[生存模式](生存模式.md)或[冒险模式](冒险模式.md)的玩家距离不祥试炼刷怪笼14格以内，且玩家进入其视线时，不祥试炼刷怪笼会被激活，开始尝试在周围生成生物。

不祥试炼刷怪笼从等待玩家状态转为激活状态时亮度会增加，产生上升的[火花粒子](粒子#trial_spawner_detection.md)，并且激活状态下其内部的生物模型旋转得更快、火焰粒子更加密集。

不祥试炼刷怪笼在[和平](和平.md)难度下或[游戏规则](游戏规则.md)为<code>false</code>时<ref></ref>始终保持等待玩家状态，即使它要生成的生物能够存在于这些情况下也是如此。

# = 转变 =
当不祥试炼刷怪笼的不祥试炼结束后，其将进入冷却状态，冷却时间结束后会变回试炼刷怪笼。

# = 生成生物 =
不祥试炼刷怪笼生成的生物具有以下特征：
* 若能装备盔甲则可能会装备以下盔甲，[盔甲纹饰](盔甲纹饰.md)是铜-{}-质的，并同时附有[保护](保护.md)IV、<ref></ref>：
* * 镶铆盔甲纹饰的[锁链头盔](锁链头盔.md)、涡流盔甲纹饰的[铁头盔](铁头盔.md)或涡流盔甲纹饰的[钻石头盔](钻石头盔.md)
* * 镶铆盔甲纹饰的[锁链胸甲](锁链胸甲.md)、涡流盔甲纹饰的[铁胸甲](铁胸甲.md)或涡流盔甲纹饰的[钻石胸甲](钻石胸甲.md)
* 武器可能是铁剑（可能附有[锋利](锋利.md)I或[击退](击退.md)I）、钻石剑或弓（可能附有[力量](力量（魔咒）.md)I或[冲击](冲击.md)I）。
* 若该生物不能穿戴装备，则会在试炼过程中以总数的2倍生成。（以仅一名玩家参与试炼计算）
* * 试炼中，这些刷怪笼也会生成一种额外的生物。
* 所生成生物被击杀时，由不祥试炼额外生成的装备不会掉落。

# = 生成 =

激活的不祥试炼刷怪笼每会在欧几里得距离14格内的[生存](生存.md)或[冒险模式](冒险模式.md)的玩家及生物上方格生成[不祥之物生成器](不祥之物生成器.md)，投掷随机的[弹射物](弹射物.md)。

# = 奖励 =
玩家完成一次试炼后，不祥试炼刷怪笼顶部的“闸门”会开启，并弹出奖励。与试炼刷怪笼相比，补给战利品表被选中的概率提高到70%，钥匙战利品表被选中的概率降低到30%。抽取次数依然和参与玩家相同，每次弹出的奖励相同。

# = 安全保护 =

不祥试炼刷怪笼属于“仅管理员可设置数据”的方块。

非管理员玩家对不祥试炼刷怪笼按下+时不会复制方块实体数据，放置物品栏中已有的带有方块实体数据的不祥试炼刷怪笼也不会将数据实际加载。

管理员玩家的物品栏中带有方块实体数据的不祥试炼刷怪笼的物品[提示框](提示框.md)中会显示警告信息。
