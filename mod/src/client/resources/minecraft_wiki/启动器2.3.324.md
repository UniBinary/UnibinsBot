# 启动器2.3.324

*页面ID: 97427* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.3.324**是一次[启动器](启动器.md)更新，发布于2022年7月27日。

# 更改
* 更新了一些错误消息以为用户提供更准确的指导。
* 改进了已安装游戏的更新过程。
* （8月6日）更新了背景图。

# 修复
* 修复了部分用户无法进入基岩版的漏洞。
* 修复了与添加或移除Microsoft账户相关的漏洞。
*  - 点击“在此设备上不可用”按钮的弹出窗口中的“受支持的设备上游玩”后会跳转到一个无效链接。
*  - 在特定语言翻译中，不一致的大写转换映射会导致问题。
*  - Q&A部分中的“Q”和“A”字符没有被翻译。
*  - 启动器会先显示“MINECRAFT JAVA & BEDROCK”，然后再显示“MINECRAFT JAVA EDITION”。
*  - 用于比较游戏功能的一个字符串中的“Wi-Fi”被错误地拼写成了“WiFi”。
