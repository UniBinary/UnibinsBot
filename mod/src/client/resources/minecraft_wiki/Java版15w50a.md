# Java版15w50a

*页面ID: 19102* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w50a**是[Java版1.9](Java版1.9.md)的第46个快照，发布于2015年12月9日<ref></ref>，补全了现有声音事件的音效，并修复了漏洞和崩溃。

# 更改
# = 方块 =
* *[漏斗](漏斗.md)**
* 和[箱子](箱子.md)用的NBT标签一样支持[战利品表](战利品表.md)了。

# = 生物 =
* *常规**
* 生物现在会躲避[仙人掌](仙人掌.md)。
* 生物现在能正常通过可以通过的方块。

* *[骷髅](骷髅.md)**
* 头部装备物品时不再躲避到阴影中。
