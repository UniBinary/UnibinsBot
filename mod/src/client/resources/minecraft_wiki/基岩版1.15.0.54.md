# 基岩版1.15.0.54

*页面ID: 55645* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.15.0.54**是[基岩版1.16.0](基岩版1.16.0.md)的第3个测试版，发布于2020年2月27日<ref></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[铁傀儡](铁傀儡.md)**
* 调整了行走动画。（）

# 修复
* *修复了18个漏洞**<br>
* *崩溃**
* 修复了若干可能在游戏过程中发生的崩溃。
* 修复了沿z坐标轴反方向移动有时会导致游戏崩溃的问题。
* 修复了对行为包中特定JSON字符串进行修改时可能会发生的崩溃问题。
* 修复了在Xbox One平台上返回游戏可能发生的崩溃问题。
* 修复了一个使用角色创建器时可能发生的崩溃问题。
* 修复了史莱姆锁定攻击目标后，攻击目标离开该史莱姆的视野可能会导致游戏崩溃的问题。

* *常规**
* 修复了玩家试图传送到附近的区块，系统却判定该区块距离过远的问题。
* 修复了玩家在不同维度间移动时，区块无法正常加载的问题。（）
* 修复了要塞无法生成图书馆和传送室的问题。（）
* 海底神殿现在又会正确生成内部结构了。（）

* *游戏内容**
* 修复了玩家进入末地折跃门后被传送到主岛下方的问题。（）
* 修复了灾厄巡逻队会生成在异常区域的问题。（）
* 修复了玩家从所骑乘的实体上下来后无法打开物品栏的问题。（）

* *生物**
* 修复了北极熊、鹦鹉、豹猫和海豚无法被拴绳牵引的问题。（）

* *UI**
* 确认对话框“玩家需下载资源包以加入”现在又能正常显示了。
* 修复了商城中的“Take a tour”导航箭头。

* *附加包与脚本编写**
* 删除了包括寻路组件（navigation component）的组件组时，实体不再不动。</onlyinclude>
