# 基岩版1.19.10.20

*页面ID: 96339* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.10.20**（Android）、**Preview 1.19.10.20**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.10](基岩版1.19.10.md)的首个测试版，发布于2022年5月25日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了行商羊驼刷怪蛋。

# = 常规 =
* *[设置](设置.md)**
* 在创建者设置中加入了“启用复制坐标 UI”选项。
* * 用于在聊天界面中启用复制坐标UI。

# 更改
# = 方块 =
* *[刷怪笼](刷怪笼.md)**
* 现在仅在被镐或[TNT](TNT.md)破坏时掉落经验。

# = 物品 =
* *[山羊角](山羊角.md)**
* 现在也会在[山羊](山羊.md)撞击[红树原木](红树原木.md)时掉落。

# = 生物 =
* *[悦灵](悦灵.md)**
* 搜寻物品的范围由64格更改为32格以匹配。

* *[行商羊驼](行商羊驼.md)**
* 现在是一种独立于普通羊驼的生物。

* *[监守者](监守者.md)**
* 现在会在卡在液体中时直接消失，而不是钻入地底。

# = 常规 =
* *[控制](控制.md)**
* 为iOS/iPadOS平台加入了对蓝牙键鼠控制的支持。
* 更新了触摸控制摇杆的视觉样式。

* *[音乐](音乐.md)**
* 现在iOS/iPadOS平台上的游戏应用会自带音乐，而不再需要到[市场](市场.md)中下载DLC。

* *声音**
* 现在从物品栏装备盔甲时会播放声音。
* 现在将非盔甲类物品（如[南瓜](南瓜.md)和[生物头颅](生物头颅.md)）放入头盔槽会播放通用的穿戴装备的声音。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“旁观模式”、“即将推出的创作者功能”和“应用测试框架”子选项后才可使用。

# = 常规 =
* *[旁观模式](旁观模式.md)**
* 现在旁观模式玩家可以在任何地方恢复氧气条。
* 现在旁观模式玩家不能被[活塞](活塞.md)推动。
* 旁观模式下的行动不再会消耗玩家的[饥饿值](饥饿值.md)。
* 旁观模式玩家不再会发出声音，如脚步声、攀爬音效和溅水声等。
* 现在玩家进入旁观模式后，未在[床](床.md)上睡觉的计时会暂时停止。
* 现在旁观模式玩家仅会渲染头部。
* 现在旁观模式玩家会渲染为半透明的样子。
* 现在[箭](箭.md)、[三叉戟](三叉戟.md)和火球等弹射物会直接穿过旁观模式玩家。
* 使用手柄的旁观模式玩家不再会收到无用的工具提示。

# = 技术性 =
* *GameTest框架**
* 为函数加入了参数。
* * 若为true，则在传送时保存速度。

# 修复
* *监守者**
* 监守者现在能够穿过熔岩。（）
* 监守者现在能够穿过水。（）
* 监守者不再能在生成或钻地时被推动。
* 现在若处于流体中的监守者试图钻地，其不会显示掘地动画，而是会不带有任何动画和音效地消失。（）
* 监守者现在总是会在怒吼后追击其目标。
* 监守者现在每被攻击一次会增加100点愤怒值。

* *幽匿感测体**
* 幽匿感测体现在能够正确检测大型垂滴叶更改其倾斜状态时产生的振动。（）
* 幽匿感测体现在能够正确检测使用锄耕耘草方块、土径、泥土、砂土或缠根泥土时产生的振动。（）
* 幽匿感测体不再能够检测玩家装备其手持物品时产生的振动。（）

* *悦灵**
* 现在玩家拿走悦灵手持的可堆叠物品时，该物品会正确被添加至现有的物品堆叠中。（）
* 拿走悦灵手持的可堆叠物品时不再会该复制物品。
* 悦灵搜寻物品的范围由64格更改为32格以匹配Java版。（）

* *幽匿脉络**
* 现在使用精准采集附魔工具开采幽匿脉络时，掉落的幽匿脉络数量与其附着的方块面数量相同。

* *幽匿催发体**
* 幽匿催发体现在能够将幽匿块蔓延至泥巴和沾泥的红树根。（）

* *幽匿尖啸体**
* 幽匿尖啸体现在检测是否有监守者的范围为48格，而不是96格。
* 幽匿尖啸体现在会对触发阶段为3或4的玩家施加黑暗状态效果。
* 幽匿尖啸体现在能够检测骑乘任何实体的玩家。（）
* 现在幽匿尖啸体上方有玩家踩踏时会被不停地激活（50%）。（）
* 幽匿尖啸体现在会对远处激活其的玩家造成影响。

* *红树**
* 红树胎生苗生长时不再会被树叶阻挡。（）

* *红树原木**
* 红树原木现在包含在奖励箱的战利品表中。（）

* *红树林沼泽**
* 现在红树林沼泽中生成的村民会成为沼泽村民。（）
* 黏土斑块现在会正确生成在红树林沼泽中。

* *触摸控制**
* 现在玩家可以按住跳跃键以连续跳跃。（）
* 现在使用新触摸控制的玩家可以在脚手架上向下移动。（）

* *原版趋同**
* 现在生物将物品装备至盔甲槽中时会发出音效。（）
* 营火的底部现在能够为其他方块提供完整面支撑。
* 讲台的底部现在能够为其他方块提供完整方块面支撑。
* 垂泪藤现在能够放置在所有可以提供完整方块面的方块底部。（、）
* 现在玩家破坏运输船或运输矿车时会激怒附近的猪灵。（）
* 结构方块不再可以含水。（）
* 离开下界传送门的实体的相对坐标不再会与方块位置坐标相对齐。（）
* 修复了角落里的流体会根据该角落毗邻的方块而拥有意外高度的视觉漏洞。（）

* *方块**
* 现在对着运输船使用高级选取功能时会一同复制其中的物品。（）
* 下界苗和下界菌现在能够放置在泥巴和沾泥的红树根上。
* 使用剪刀开采红树树叶后不再会将红树树叶放入单独的物品堆叠中。

* *命令**
* 使用、或命令移除带有战利品表的箱子时不再会掉落物品。（）

* *EDU**
* 略微更改了书与笔中的尺寸、按钮分布和删除照片的行为，以使其能够在移动设备上更好运行。

* *青蛙**
* 蝌蚪现在会在草甸或裸岩山峰中长成温带青蛙，在深暗之域中长成寒带青蛙。

* *蛙明灯**
* 蛙明灯上的脚步声的音量现在与其他脚步声的音量更加相似。（）

* *游戏内容**
* 玩家关门时不再会被推动。（）
* 现在当物品栏被占满时，副手槽上能够正确堆叠物品。（）
* 现在将物品从物品栏界面装备至盔甲槽中时会发出音效。（）
* 现在多个玩家之间能够听见彼此将物品装备至盔甲槽时发出的音效。
* 修复了由结构方块加载和命令加载的实体，会导致用于保存结构的原始生物和之前结构加载的生物消失的问题。（）
* 修复了1.18.30后将实体传送至1.18.30前未加载的区块中时会使实体丢失的问题。
* 修复了史莱姆不再会在1.18前创建的超平坦世界中生成的漏洞。（）
* 修复了尝试生成史莱姆会出错的漏洞。

* *常规**
* 修复了骑行中的玩家在跨越区块边界处重载时会终止骑行的漏洞。
* 修复了玩家上船时会重置玩家垂直视角的漏洞。（）
* 修复了即使没有受到摔落伤害，玩家在特定高度上的脚手架行走时可能会受到摔落伤害的漏洞。（）
* 修复了升级旧世界后可能会使水柱低于Y=0的漏洞。

* *山羊**
* 现在山羊撞击红树原木时会掉落山羊角。（）

* *图形**
* 副手上的物品不再渲染为黑色。
* 修复了从内部观察屏障时会显示红色纹理或覆盖物的漏洞。（）

* *生物**
* 现在打开行商羊驼的物品栏时，其会显示正确的名称。（）

* *盾牌**
* 现在被斧或监守者攻击而禁用盾牌时会播放物品损坏音效。（）

* *性能与稳定性**
* 修复了船在世界中被取消拴住时可能发生的崩溃。
* 修复了凋灵加载至世界中时可能发生的崩溃。

* *用户界面**
* “Friendly Fire”游戏规则选项现已移动至新的创建新世界UI中的多人游戏选项卡中。
* 现在移动设备上的经验条位于快捷栏的全长度中央，包含末端被省略部分。
* 在聊天界面中加入了复制坐标的控制面板。

* *技术性**
* 将方块组件重命名为。
* 将组件重命名为，并加入了适当的版本控制。
* 将组件的字段重命名为，并加入了适当的版本控制。
* 将组件的重命名为，并加入了适当的版本控制。
* 更新了相关的文档。
* 修复了组件不能正确触发方块组件的问题。
* 现在面朝的方向会借助由一种活动对象类型变为另一种活动对象类型的转换来保存。
* 自动补全建议现在仅会显示有效参数。
* 修复了对着含水的可交互方块（例如拉杆）使用桶时的交互优先级问题。（）
* 行商羊驼现在是一种独立生物，而不是带有特定组件组的普通羊驼。</onlyinclude>
