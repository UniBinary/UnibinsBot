# 基岩版1.21.50.29

*页面ID: 128681* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.50.29**（ChromeOS/Android）、**Preview 1.21.50.29**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.50](基岩版1.21.50.md)的第7个测试版，发布于2024年11月13日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[嘎枝之心](嘎枝之心.md)**
* 将硬度和爆炸抗性由5更改为10。

* *[下界砖块](下界砖块.md)及其变种和[红色下界砖块](红色下界砖块.md)**
* 现在会在游戏中使用新纹理。

* *[雕纹树脂砖块](雕纹树脂砖块.md)**
* 略微更改了纹理，以修正颜色错误的像素并与[树脂砖块](树脂砖块.md)保持一致。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 现在再次会在接触[张开的眼眸花](张开的眼眸花.md)时获得[中毒](中毒.md)效果。<ref></ref>

# 修复
* *方块**
* 修复了雕纹树脂砖块和普通的树脂砖块的纹理之间有单个像素不一致的问题。
* 现在下界砖块和红色下界砖块的砖纹与红砖块和树脂砖块的砖纹对齐。（）

* *图形**
* 修复了Android设备（仅Adreno图形处理器）在高帧率情况下的卡顿问题。

* *用户界面**
* 现在在激活创造模式物品栏选项卡的情况下将鼠标悬停在放在快捷栏中的收纳袋上时，使用滚轮会选择收纳袋中的物品。

* *原版趋同**
* 修复了发光地衣被踩踏时会播放草丛的音效，而不会像Java版一样播放藤蔓的音效的问题。</onlyinclude>
