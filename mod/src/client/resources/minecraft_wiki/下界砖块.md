# 下界砖块

* *下界砖块（Nether Bricks）**是由[下界砖](下界砖.md)合成的方块，也是[下界要塞](下界要塞.md)的主要构成方块。

# 生成
# = 自然生成 =
下界砖块会在[下界要塞](下界要塞.md)中自然生成。

# 获取
# = 合成 =

# 破坏
挖掘下界砖块的合适工具是镐。下界砖块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

下界砖块被破坏后会掉落自身。

# 用途
下界砖块是不可燃方块，且能够抵抗[火球](火球.md)的[爆炸](爆炸.md)，这使得它可作为合适的下界庇护所材料。

如果一个下界砖块是在下界要塞的整体结构范围内（而非仅限于在下属的子结构范围内），会在下界要塞生成的生物（比如[烈焰人](烈焰人.md)和[凋灵骷髅](凋灵骷髅.md)）可以在其他生成条件都符合时生成在该下界砖块上。
