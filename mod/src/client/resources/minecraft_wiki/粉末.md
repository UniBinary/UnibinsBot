# 粉末

*页面ID: 125089* | *来源: Minecraft Wiki*

* *粉**或**粉末（Dust**、**Powder**或**Meal）**可以指：

# Minecraft
# = 物品 =
*  - 破坏[荧石](荧石.md)后掉落的物品。
*  - 挖掘[红石矿石](红石矿石.md)后掉落的物品。
*  - 由[烈焰棒](烈焰棒.md)分解成的物品。
*  - 由[苦力怕](苦力怕.md)、[女巫](女巫.md)和[恶魂](恶魂.md)等生物掉落的物品。
*  - 一种能被用作大部分植物的肥料的物品。
*  - 一种由[甘蔗](甘蔗.md)或[蜂蜜瓶](蜂蜜瓶.md)合成的食物材料。
# = 方块 =
*  - 由[沙子](沙子.md)、[沙砾](沙砾.md)和各种[染料](染料.md)合成的方块，共有16种颜色。
*  - 一种会使大多数生物陷入其中，并在一段时间后造成冰冻伤害的方块。
* *  - 装着细雪的[铁桶](铁桶.md)。

# Minecraft Dungeons
*  - 一种未实装就被移除的物品。
*  - 一种可以眩晕敌人的[法器](法器.md)。
