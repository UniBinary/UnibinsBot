# Oxeye披风

*页面ID: 186367* | *来源: Minecraft Wiki*

* *Oxeye披风（Oxeye cape）**是一件个人披风。

# 外观
这件披风的设计模仿了Oxeye Game Studio的标志，背景为黑色，中间是一个白色圆圈。

# 描述
[Oxeye Game Studio](http://www.oxeyegames.com)是由[Jeb](Jeb.md)等人创立的游戏开发公司，开发过*[Cobalt](Cobalt.md)*等游戏。

这件披风是随机送给玩家iSxckk的，可能是意外，然后在次日被移除了。
