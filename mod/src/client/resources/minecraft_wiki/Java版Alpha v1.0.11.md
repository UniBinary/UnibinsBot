# Java版Alpha v1.0.11

*页面ID: 32626* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.11**是的一次[秘密更新](秘密更新.md)，发布于2010年7月23日<ref></ref>，加入了[甘蔗](甘蔗.md)和[黏土](黏土.md)，[纸](纸.md)、[书](书.md)、[黏土球](黏土球.md)等物品和[史莱姆](史莱姆.md)。

# 新内容
# = 方块 =
* *[甘蔗](甘蔗.md)**
* 会在[水](水.md)边自然生成。
* 无法放置在[沙子](沙子.md)上。
* 用于合成[纸](纸.md)。

* *[黏土](黏土.md)**
* 会在水底自然生成。
* 被破坏后掉落4个黏土球。

# = 物品 =
* *[纸](纸.md)**
* 在[工作台](工作台.md)中横着摆放3个芦苇来[合成](合成.md)。
* 用于合成[书](书.md)。

* *[书](书.md)**
* 可由3张纸来合成。

* *[黏土球](黏土球.md)**
* 挖掘黏土后可获得4个。
* 用于烧炼成[红砖](红砖.md)。

* *[红砖](红砖.md)**
* 通过[烧炼](烧炼.md)黏土获得。
* 用于合成[红砖](红砖块.md)。

* *[黏液球](黏液球.md)**
* 通过杀死最小的史莱姆获得，暂无用途。

# = 生物 =
* *[史莱姆](史莱姆.md)**
* 一种[攻击型生物](攻击型生物.md)，死亡后会分裂成更小的史莱姆。
* * 只会在被空手杀死时分裂，用[剑](剑.md)击杀则不会分裂。

# 更改
# = 方块 =
* *[书架](书架.md)**
* 加入了合成配方，现在可由[木板](木板.md)和[书](书.md)来合成。

* *[砖块](红砖块.md)**
* 更改了纹理。
* 现在可以用4块[红砖](红砖.md)合成了。

* *[仙人掌](仙人掌.md)**
* 更改了纹理。
* 生物现在只会在接触到仙人掌时受到[伤害](伤害.md)。
* 现在只能放置在沙子上。

# = 物品 =
* *[牛奶](奶桶.md)**
* 现在可通过手持[空桶](空桶.md)对着[牛](牛.md)右键获得。

* *[锹](锹.md)**
* 除了木锹以外的所有锹现在会瞬间破坏[雪](雪.md)。

# = 游戏内容 =
* *[第三人称视角](第三人称视角.md)**
* 现在第三人称视角下手持[物品](物品.md)的显示方式与第一人称视角中的不同。

# = 世界生成 =
* *常规**
* 升级并调整了地形生成器。
* * 更改了[树木](树木.md)和[花](花.md)的生成器。</onlyinclude>
