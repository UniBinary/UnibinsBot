# 更改
# = 常规 =
* *[控制](控制.md)**
* 加入了一个键盘映射来控制渲染距离。<ref>[IRC记录](#logs.md): "*A9:32:05 <08Notch> moving it to an F-key, though [...] well, I could just make it mappable..*" (14:32:05 UTC)</ref>
* * [玩家](玩家.md)再次可以通过按下来切换渲染距离。<ref>[IRC记录](#logs.md): "*A9:39:26 <CheeToS> yay, thank you for putting the f key back*" (14:39:26 UTC)</ref>

# 你知道吗
* [Notch](Notch.md)计划在此版本之后修改命名规则，将第二个0和“a”去掉，即“<主版本>.<发布数>[_<补丁数>]”的格式。例如，由于该版本是那时最新的版本，按照这个规则“0.0.23a_01”会被重命名为“0.23_01”。<ref name=change/>然而，这个版本从未被给予过这个名字。
* * 这个规则也被应用于[Beta](Java版Beta.md)版中。
