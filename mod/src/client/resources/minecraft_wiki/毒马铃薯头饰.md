* *毒马铃薯头饰（Poisonous Potato Headpiece）**是一种装饰性[方块](方块.md)。

# 生成
毒马铃薯头饰不会生成在世界中。

# 破坏
没有工具可以加速对毒马铃薯头饰的挖掘。

毒马铃薯头饰被破坏后会掉落自身。

# 用途
# = 穿戴 =
与[雕刻南瓜](雕刻南瓜.md)和[生物头颅](生物头颅.md)类似，玩家可以像装备头盔一样装备毒马铃薯头饰。当毒马铃薯头饰戴在玩家头上时，毒马铃薯头饰的纹理将会覆盖玩家头部的第二层纹理。[玩家](玩家.md)佩戴毒马铃薯头饰时，毒马铃薯僵尸不会主动攻击玩家。

# = 发射器 =
[发射器](发射器.md)会将发射器朝向且在射程内的玩家、生物或盔甲架的头盔栏装备一个毒马铃薯头饰。
