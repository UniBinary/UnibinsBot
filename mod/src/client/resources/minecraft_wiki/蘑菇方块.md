# 蘑菇方块

*页面ID: 21723* | *来源: Minecraft Wiki*

* *蘑菇方块（Mushroom Blocks）**是一类组成巨型蘑菇的固体[方块](方块.md)，共有3种：**棕色蘑菇方块（Brown Mushroom Block）**、**红色蘑菇方块（Red Mushroom Block）**和**蘑菇柄（Mushroom Stem）**。

# 生成
# = 巨型蘑菇 =

蘑菇方块作为巨型蘑菇结构的一部分生成。

# 获取
蘑菇方块只能通过破坏蘑菇方块获得。

# = 创造模式物品栏 =
所有纹理的蘑菇方块都能在创造模式物品栏中获得。

从创造模式物品栏可以获得棕色蘑菇盖纹理、红色蘑菇盖纹理、蘑菇柄的蘑菇方块。其他种类的蘑菇方块（包括带气孔纹理的）可以通过命令获得。

# 破坏
挖掘蘑菇方块的合适工具是斧。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，蘑菇柄被破坏后不会掉落，棕色蘑菇方块和红色蘑菇方块被破坏后会掉落0-2个对应颜色的[蘑菇](蘑菇.md)，概率为0个蘑菇77.78%、1个蘑菇11.11%、2个蘑菇11.11%。

被具有精准采集的工具挖掘破坏时，蘑菇方块被破坏后会掉落六个面都是蘑菇盖或蘑菇柄纹理的1个对应蘑菇方块。

# 用途
可通过在蘑菇方块的某一面放置同种蘑菇方块，使两个方块的接触面变成气孔纹理。

# = 堆肥 =
将棕色蘑菇方块和红色蘑菇方块放进[堆肥桶](堆肥桶.md)有85%的概率增加一层堆肥层.

将蘑菇柄放进堆肥桶有65%的概率增加一层堆肥层。
