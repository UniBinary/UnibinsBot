# 辅助程序与编辑器/Kubik

*页面ID: 16439* | *来源: Minecraft Wiki*

[右|英文版（禁用透明度）](File:Kubik16.png.md)
* *Kubik**是一款Minecraft百科全书应用程序，由Flex编写，基于Adobe Integrated Runtime（AIR）运行。

* *Kubik**于2010年9月24日发布（版本0.5.0）。

适用于Windows 8的**Kubik**于2012年10月3日发布（版本1.0.0.0）。

# 适用于Windows 8的Kubik
[右|300px|](File:Minecraft_kubik_win8_big.png.md)
该版本仅可在Windows应用商店下载，且为Windows 8界面特别定制。

# 功能
* 涵盖Minecraft的所有方面：方块、合成、烧炼、染色、物品、生物。
* 查看（Minecraft日夜计时器）。
* 复制粘贴界面。
* Kubik Portal权限插件及更多。
* 内置更新机制。
* 内置反馈系统。
* 本地化支持。
* Kubik用户留言板。
* 插件系统。

# Kubik插件
1.7版本已支持插件功能：任何人都能创建包含物品和链接的插件，并将其添加到Kubik中。

从2.0版本开始，Kubik采用了全新的核心与插件系统。

# 配置需求
* 装有Windows、GNU/Linux或Mac OS的电脑。
* Adobe Air 3.0以及更高版本。
* 升级、留言板所需的网络连接（可选）。
