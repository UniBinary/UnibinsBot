# 陷阱箱

*页面ID: 9536* | *来源: Minecraft Wiki*

* *陷阱箱（Trapped Chest）**是[箱子](箱子.md)的变种，在开启时会发出[红石信号](红石信号.md)。

# 生成
# = 自然生成 =
陷阱箱会自然生成在[林地府邸](林地府邸.md)的[伪末地传送门房间](林地府邸/结构/战利品房间#伪末地传送门房.md)里，两侧各有一个[TNT](TNT.md)。

# 破坏
挖掘陷阱箱的合适工具是斧。

陷阱箱被破坏后会掉落自身和内容物。

如果一个大型陷阱箱（由2个相邻的陷阱箱组成）的其中一个陷阱箱破坏，那么将会掉落对应27个储存格的物品。

# 用途
陷阱箱可用作物品容器储存物品或用作[红石元件](红石元件.md)。

陷阱箱的闩的四周相比普通箱子的稍红。

若要放置陷阱箱，应对着方块表面。

把一个陷阱箱放在另一个陷阱箱的旁边，若两者朝向相同，那么它们会合并为一个大型陷阱箱。若要避免这种情况，玩家需要（若潜行放置时对准了陷阱箱，则两个箱子仍然会合并）}}或。普通箱子不会与陷阱箱合并。

[水](水.md)和[熔岩](熔岩.md)会绕过陷阱箱流动，不会对其造成任何影响。熔岩会在陷阱箱周围的空气方块生成火，但陷阱箱不会被烧毁（并且也不会以其他方式燃烧）。陷阱箱可被活塞推动。

# = 容器 =

一个陷阱箱拥有27个物品槽位，大型陷阱箱拥有54个槽位。大型陷阱箱的物品槽位分布如下：
* 前27个（上三行）：
* * 对应其面对锁扣观察时的左侧部分。
* * 对应其先被放置的部分。
* 后27个（下三行）：
* * 对应其面对锁扣观察时的右侧部分。
* * 对应其后被放置的部分。

对陷阱箱按下可以打开陷阱箱的界面。

陷阱箱在上方置有或时，或[猫](猫.md)坐在其上方时，不能开启。但由于陷阱箱不是或，所以可以在陷阱箱的上面放置陷阱箱而不影响开启（无论陷阱箱是否已打开）。

陷阱箱界面的标题默认为“箱子”，可以在放置前使用[铁砧](铁砧.md)重命名来进行更改，也可以通过使用命令修改陷阱箱的<code>CustomName</code>标签进行更改（例如，要把位于(0,64,0)的陷阱箱标记为“陷阱！”，则使用命令{{cmd|data merge block 0 64 0 {CustomName:"陷阱！"} }}）。若大型陷阱箱的一半被重命名，那么整个大型陷阱箱界面上的名字都会改变，但若重命名的那一半被摧毁，剩下的一半会恢复到默认状态。若两个部分的名字不同，陷阱箱根据朝向优先选择北侧或西侧的那一半的名字（即X轴或Z轴上坐标最小的那一半），若均无重命名则会显示“大型箱子”。大型陷阱箱界面上的名字取决于被打开的大型陷阱箱的一半的名称。若打开的大型陷阱箱的一半无名称，则会显示“大箱子”。

陷阱箱可以被<code>lock</code>标签上锁。若陷阱箱的该标签不是空白的，那么这个陷阱箱必须使用符合该标签表示的物品谓词的物品打开。

# = 红石元件 =
[缩略图|箱子（左）和陷阱箱（右）可毗邻放置。[[红石粉](File:Chest-Comparsion.png.md)会指向陷阱箱，但不指向普通的箱子]]

陷阱箱可用于检测玩家何时打开了它的界面。

陷阱箱未被打开时不发出信号，被玩家或[铜傀儡](铜傀儡.md)打开时会发出红石信号。从大型陷阱箱的任一部分打开都会使大型陷阱箱的两边都发出信号。陷阱箱不会因[投掷器](投掷器.md)、[合成器](合成器.md)或[漏斗](漏斗.md)改变其内容物而发出红石信号。

当其被打开时，陷阱箱会：
* 激活毗邻的红石粉。信号强度为正在使用陷阱箱的生物数（最大为15）。
* 激活毗邻的背朝陷阱箱的[红石中继器](红石中继器.md)。
* * 陷阱箱不会激活毗邻且背朝它的[红石比较器](红石比较器.md)。红石比较器只能以检测普通箱子的方式检测陷阱箱存储物品的数量。
* 强充能其下方的[红石导体](红石导体.md)。信号强度为正在使用陷阱箱的生物数（最大为15）。
* 激活任何毗邻的机械元件（除面向它的[活塞](活塞.md)外）。

# = 猪灵 =
在非和平[难度](难度.md)下，成年[猪灵](猪灵.md)会与打开或破坏陷阱箱的玩家敌对。

# = 燃料 =
陷阱箱可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个陷阱箱可烧炼1.5个物品。

# = 圣诞节 =

每年12月24日至26日，陷阱箱、[箱子](箱子.md)和会共用圣诞节礼物包裹纹理，因而无法从外观分辨。由于游戏会读取电脑数据，玩家可以通过更改游戏文件和时间来看到圣诞节纹理。
