# Java版1.21.2-pre3

*页面ID: 127213* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21.2-pre3**是[Java版1.21.2](Java版1.21.2.md)的第3个预发布版，发布于2024年10月11日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *[资源包](资源包.md)**
* 将资源包版本号更改为<code>42</code>。
* 现在可使用纹理指定收纳袋物品选择界面的槽位背景。
* 高对比度内置资源包增添了如下高对比度纹理：
* * 提示框背景和边框
* * 收纳袋物品选择界面的槽位背景和选择高亮
