# Java版Indev 0.31 20100107-1851

*页面ID: 172116* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2010年1月7日18:51（UTC）<ref>[dbn的IRC记录](#logs.md): "(13:51:11) <Notch> indev has been updated"</ref>，加入了世界主题。<ref></ref><ref></ref>

# 新内容
# = 游戏内容 =
* *[世界主题](Indev世界选项#世界主题.md)**
* 加入了世界主题，共有普通（Normal）和地狱（Hell）两种世界主题，可由[创建新的世界](创建新的世界.md)屏幕控制。
* * 普通：默认世界主题。
* * 地狱：世界中的草方块会大量被替代为泥土，蘑菇会大量在地表生成，作物生长缓慢，怪物随处生成。

# 更改
# = 游戏内容 =
* *[迷雾](迷雾.md)**
* 在黑暗的区域，雾也会随之变暗。<ref></ref>

# = 世界生成 =
* *常规**
* 深型浮岛世界现在会生成分层岛屿。

# = 常规 =
* *[创建新的世界](创建新的世界.md)**
* 现在可以选择要创建世界的[世界主题](Indev世界选项#世界主题.md)。

* *其他**
* 现在默认会启用Mipmapping。</onlyinclude>
