# Java版Beta 1.2

*页面ID: 32660* | *来源: Minecraft Wiki*

<onlyinclude>
* *Beta 1.2**是的一次主要更新，发布于2011年1月13日，加入了新的方块和物品，并进行了一些更改和修复。

# 新内容
# = 方块 =
* *[蛋糕](蛋糕.md)**
* 可回复。

* *[发射器](发射器.md)**
* 一种新的红石元件。
* 可用于发射其中的物品。

* *[青金石块](青金石块.md)**
* 可由9个青金石合成。

* *[青金石矿石](青金石矿石.md)**
* 开采后可获得青金石。

* *[音符盒](音符盒.md)**
* 右键调音，并在被[红石](红石.md)信号激活时发出声音。

* *[砂岩](砂岩.md)**
* 可由[沙子](沙子.md)合成。

* *[白桦原木](白桦原木.md)**
* 可以在白桦树上找到。
* 可用于制作[木板](木板.md)。

* *[云杉原木](云杉原木.md)**
* 可以在云杉树上找到。
* 可用于制作木板。

* *[白桦树叶](白桦树叶.md)**
* 可以在白桦树上找到。
* 暂时不会掉落任何物品。

* *[云杉树叶](云杉树叶.md)**
* 可以在云杉树上找到。
* 暂时不会掉落任何物品。

* *[染色羊毛](染色羊毛.md)**
* 可用作建筑方块。

# = 物品 =
* *[骨头](骨头.md)**
* 可用于合成[骨粉](骨粉.md)。

* *[染料](染料.md)**
* 共有16种。
* [墨囊](墨囊.md)此时被称为墨袋（Ink Sack）。
* [可可豆](可可豆.md)只能通过[外部程序](辅助程序与编辑器.md)获得。

* *[木炭](木炭.md)**
* 使用[煤炭](煤炭.md)的纹理。
* 烧炼木头获得。

* *[糖](糖.md)**
* 由[甘蔗](甘蔗.md)合成。

# = 生物 =
* *[绵羊](绵羊.md)**
* 加入了[32px](File:Gray Sheep JE1.png.md) 灰色、[32px](File:Light Gray Sheep JE1.png.md) 淡灰色和[32px](File:Black Sheep JE1.png.md) 黑色的变种。
* 死亡时会掉落对应颜色的[羊毛](羊毛.md)。

* *[鱿鱼](鱿鱼.md)**
* 新的水下生物。
* 死亡时掉落[墨囊](墨囊.md)。

# = 世界生成 =
* *[树](树.md)**
* 增加了两个新种类的树：
* * [白桦树](白桦树.md)
* * [云杉树](云杉树.md)

# 更改
# = 方块 =
* *[熔炉](熔炉.md)**
* 重新设计了纹理。
* * 不是默认状态的熔炉将会保持不变。

* *[芦苇](甘蔗.md)**
* 重命名为[甘蔗](甘蔗.md)。

* *[刷怪笼](刷怪笼.md)**
* 现在在单人模式中于其内部会显示一个其生成的生物的旋转模型。

# = 物品 =
* *工具**
* 由[木板](木板.md)、[圆石](圆石.md)、[铁锭](铁锭.md)和[钻石](钻石.md)制成的[工具](工具.md)提高了耐久度。
* 金质工具挖掘类似[石头](石头.md)、[原木](原木.md)等方块的时候比对应的钻石工具更快。

* *[小麦种子](小麦种子.md)**
* 现在在摧毁[草](草.md)的时候有更高的掉落率。

# = 生物 =
* *[骷髅](骷髅.md)**
* 现在掉落[骨头](骨头.md)。

* *[蜘蛛](蜘蛛.md)**
* 现在可以在墙上爬行。

* *[生物](生物（已移除实体）.md)**
* 已被移除，但AI还在代码中。

# = 世界生成 =
* *[矿石](矿石.md)**
* 现在铁矿石、钻石矿石和煤矿石的[矿团](矿团.md)规模更大。

# = 常规 =
* *[控制](控制.md)**
* 按截图的时候，不需要先按住了。

* *[Mods](Mods.md)**
* 加入了Scaevolus的FastRender Mod。<ref></ref>

# 修复
* *修复了10个漏洞**
* 画现在可以在多人游戏中正常工作了。
* 玩家在骑乘状态时断开连接导致玩家不再能进入世界。
* 在多人游戏中可以正确同步更多状态。
* 修复了Scaevolus所作的PowerPC的颜色和声音漏洞。
* 修复了单人游戏中一个严重的区块重载循环。
* 修复了新生成的多人游戏地图中大部分的光照问题。
* 更好地显示多人游戏中下落的沙子。
* 修复了几个加载存档时游戏崩溃的漏洞。
* 南瓜灯现在有正确的提示框了。
* 多人游戏中，绵羊被击中时不再在视觉上失去它们的羊毛。</onlyinclude>
