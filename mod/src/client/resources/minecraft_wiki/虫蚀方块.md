* *虫蚀方块（Infested Block）**是一类外观上与一种方块完全相同，但破坏后会生成[蠹虫](蠹虫.md)的方块。

# 生成
# = 自然生成 =
; 虫蚀石砖、虫蚀苔石砖、虫蚀裂纹石砖、虫蚀雕纹石砖
   虫蚀石砖可以在[要塞](要塞.md)代替普通石砖生成。要塞在生成时没有虫蚀苔石砖、虫蚀裂纹石砖或虫蚀雕纹石砖。
   虫蚀石砖、虫蚀苔石砖、虫蚀裂纹石砖和虫蚀雕纹石砖会在[雪屋](雪屋.md)地下室里生成。
; 虫蚀石头、虫蚀深板岩
   虫蚀石头会在[风袭丘陵](风袭丘陵.md)、[风袭森林](风袭森林.md)、[风袭沙砾丘陵](风袭沙砾丘陵.md)和所有[山地](山地.md)类生物群系所在的区块中生成。在Y=63以下的区域，每个这样的区块尝试生成14次虫蚀石头的[团簇](团簇.md)，大小为0-9个方块。此类生成还可以覆盖其他已生成的虫蚀方块。
   虫蚀石头能够取代[石头](石头.md)、[花岗岩](花岗岩.md)、[安山岩](安山岩.md)、[闪长岩](闪长岩.md)、[凝灰岩](凝灰岩.md)或[深板岩](深板岩.md)生成。其中，取代凝灰岩和深板岩生成时生成的是虫蚀深板岩。
; 虫蚀圆石
   虫蚀圆石会在[林地府邸](林地府邸.md)的“[伪末地传送门房间](林地府邸/结构/战利品房间#伪末地传送门房.md)”里生成。

# = 蠹虫 =
虫蚀方块会在[蠹虫](蠹虫.md)进入对应的普通方块时生成。

# 获取

虫蚀方块无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，虫蚀方块可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
挖掘虫蚀方块的合适工具是镐。虫蚀方块的挖掘用时是对应非虫蚀方块的一半，且没有对工具品质的需求。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，虫蚀方块被破坏后会生成一只蠹虫。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，虫蚀方块被破坏后会掉落对应的正常方块，不会生成蠹虫。

# 用途

虫蚀方块被破坏后会生成一只蠹虫。蠹虫受到攻击或[中毒](中毒.md)等[魔法伤害](魔法伤害.md)时会使其附近21×11×21的虫蚀方块自动破坏，以生成其他蠹虫。

如果关闭游戏规则，则虫蚀方块被破坏后不会产生蠹虫。如果关闭游戏规则，蠹虫呼-{}-叫增援时虫蚀方块不会被破坏或生成增援的蠹虫，但会转变为对应的未虫蚀方块；且蠹虫不会钻入方块中。

# = 区别 =
虫蚀方块与其对应的石质方块有以下区别，据此可以辨别虫蚀方块。
* 虫蚀方块的挖掘用时是对应非虫蚀方块的一半，且不使用镐挖掘时也不会延长挖掘时间。
* 放置在虫蚀方块上的[音符盒](音符盒.md)将发出或，而放置在普通的石头、圆石或石砖上的音符盒将发出底鼓声。
* [苔藓块](苔藓块.md)不能转化虫蚀方块。
* [幽匿催发体](幽匿催发体.md)无法将虫蚀方块转化为[幽匿块](幽匿块.md)，而只会在其表面生成[幽匿脉络](幽匿脉络.md)。
