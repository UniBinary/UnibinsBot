# 命令/globalpause

*页面ID: 57664* | *来源: Minecraft Wiki*

为全体玩家设置是否全局暂停游戏。

# 语法
   <code>-{}-globalpause [isPaused: Boolean]</code>

# 参数

   指定游戏是否全局暂停。
   若未指定，则查询游戏的全局暂停状态。
