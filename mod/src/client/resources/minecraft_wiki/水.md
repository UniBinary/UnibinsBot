* *水（Water）**是一种生成于主世界的[液体](液体.md)。

# 生成
水能够生成水（见）。

# = 自然生成 =
[thumb|right|低于海平面的河道和坑洞被水填满，但峡谷内没有水](File:Over Ravine.png.md)

[主世界](主世界.md)有大量自然生成的水，构成了[海洋](海洋.md)及其变种生物群系、[湿地类生物群系](湿地类生物群系.md)和部分[含水层](含水层.md)的主体方块。技术上而言，水的生成主要受到2个高度影响：[海平面](海平面.md)（Y=63）和[初步地表高度](世界生成#含水层.md)（随地形高度变化）。所有初步地表高度之上且海平面之下的空气将直接填充水，而初步地表高度之下且Y>-54的空气将由含水层负责是否填充水。部分[生成结构](生成结构.md)可能会占据水形成空腔。

水是下列[地物](地物.md)的构成方块：
* [沙漠水井](沙漠水井.md)
* [涌泉](涌泉.md)
* [滴水石簇](滴水石簇.md)

水还包含于下列[结构](结构.md)中：
* [海底神殿](海底神殿.md)；
* <ref></ref>；
* [村庄](村庄.md)的会合点、农田和渔夫小屋；
* [要塞](要塞.md)的喷泉房间；
* [林地府邸](林地府邸.md)的[小麦农场](林地府邸/结构/农场#小麦农场.md)、[瓜房](林地府邸/结构/农场#瓜房.md)和[生态屋](林地府邸/结构/装饰品房间#生态屋.md)；
* [远古城市](远古城市.md)的浴房；
* [试炼密室](试炼密室.md)的入口、柱廊廊尾和交叉口。

水不会生成在[下界](下界.md)中，且使用水桶放置的水会立即蒸发，但可以使用或命令在[下界](下界.md)生成水；[末地](末地.md)也不会自然生成水，但可以正常放置。

# = 水桶 =
玩家对不可含水方块朝向[可替代方块](可替代方块.md)的表面[水桶](水桶.md)，会在后者处放置水（下界除外；即使前者可替代，也不会替换前者）。使用水桶的[发射器](发射器.md)若面朝可替代方块，会在该方块处放置水（下界除外）。

# 获取

水不能获取其物品形式，但玩家可以对准水源方块[铁桶](铁桶.md)来获得[水桶](水桶.md)，从而受控地收集和转移水。

水没有对应的物品形式。

水源和流动的水均有物品形式，但只能通过编辑物品栏获得。

# 破坏
水没有[轮廓箱](轮廓箱.md)，因此不能挖掘水。

水被破坏后不会掉落。

# 用途
# = 游泳 =

键与跳跃键相同；没有游泳的玩家和生物会在水中缓慢地下沉。按住游泳键会使玩家上浮，当到达水面时，玩家会在那里上下摆动。按钮可以更快下沉。当玩家头部没入水中时可以让玩家进入“游泳模式”，玩家完全没入水中，完全水平且只占0.6格高。在第三人称模式或在其他玩家视角中，游泳的玩家会有用双臂拨水的动画。

在水流中逆着水流游泳比静水中游泳慢得多（见[水流](#水流.md)章节），顺着水流游泳则会快得多。

大部分生物能够任何时候在水面保持静止或游泳，除了[铁傀儡](铁傀儡.md)、[雪傀儡](雪傀儡.md)、、[猪灵](猪灵.md)、[疣猪兽](疣猪兽.md)、[猪灵蛮兵](猪灵蛮兵.md)和[亡灵生物](亡灵生物.md)。如果上面有水流下落，可能会导致[溺水](溺水.md)。

任何[实体](实体.md)（包括[玩家](玩家.md)）进入水中时，无论水有多深，也无论从多高的地方摔下来或用[鞘翅](鞘翅.md)滑翔得有多快，均不会受到[摔落伤害](摔落伤害.md)。

视角没入水中时，会产生[雾](雾.md)的效果，并进行相应着色。

# = 传播 =

[300px|right|水的传播](File:Water spread v1-13.png.md)
水会水平和向下传播到附近的[空气](空气.md)方块里。水可以无限向下传播，直到接触到方块或[世界](世界.md)底部。在水平方向，水会从水源方块传播7方块远。水的传播速度是每5[游戏刻](游戏刻.md)一方块，即每秒4方块。

水在水平传播时，每个可以流的方向都会赋予一个传播权重。每个方向上，这个权重的初始值均为999，然后，对于可以流入的每个相邻方块，都会寻找能在4个以内的方块内到达需要流向的方块的方法。如果找到了，则该方向上的水流权重设为该方法的最短的路径长度。最终，水向最低流动权重的方向传播。

传播的水将会熄灭[火](火.md)以及冲走在其传播路径上的一些特定方块，使它们按照不使用[合适挖掘工具](合适挖掘工具.md)且无[时运](时运.md)魔咒时被破坏的掉落概率掉落为物品，并随水漂到水流边缘。受影响的方块包括[植物](植物.md)（除了[树木](树木.md)、[巨型蘑菇](巨型蘑菇.md)和[巨型下界菌](巨型下界菌.md)）、[雪](雪.md)、[火把](火把.md)、[地毯](地毯.md)、[红石线](红石线.md)及其他一些红石元件、[蜘蛛网](蜘蛛网.md)、[生物头颅](生物头颅.md)和[花盆](花盆.md)。

# = 水源方块 =
若一格流动的水在水平方向上紧挨着2个或更多个水源方块或可以向这个方向流出水的含水方块，且下方有一个[固体方块](固体方块.md)或另一个水源方块为<samp>true</samp>}}，则这格水也会变成一个水源方块。利用此特性可以产生无限的水源。

装有[水桶](水桶.md)的[发射器](发射器.md)发射水桶时会在前方1格的可替换方块放置一个水源方块。装有空桶的发射器发射铁桶时会把前方一格的水源吸进铁桶里。

穿着带有[冰霜行者](冰霜行者.md)魔咒的[靴子](靴子.md)且站在固体表面的[玩家](玩家.md)下方半径为2的高度一格的圆柱内水面的水源方块会变成[霜冰](霜冰.md)，它们在光照下很快就会融化（除非玩家在融化前又一次踩到了这个霜冰）。

位于雪线以上暴露在天空下且[方块光照](方块光照.md)小于10的水源方块在可降雪的[生物群系](生物群系.md)中每游戏刻有min(,1)（其中*n*为游戏规则的值）的概率尝试转变为[冰](冰.md)。冰在至少11的[方块光照](方块光照.md)下，会融化并重新变成水源方块（[下界](下界.md)除外，生成空气）。如果冰下面1格有或，冰被破坏后也会变成水源方块，下界除外。

# = 水流 =
水方块里的水流决定了其出现的纹理的流向，以及决定诸如玩家或[船](船.md)之类的实体将会流向哪个方块的方向。

水流在较高的6个深度等级中会以1.40方块/秒（25方块/18秒）的速度推动[生物](生物.md)，第七个深度等级则为0.310方块/秒，第8个深度等级则为0.154方块/秒。创造模式下飞行的玩家不会被推动。

水方块的水平水流基于流入和流出其相邻4个方块的矢量和。例如，如果一个方块从北边流入水，在西边毗临一个固体方块，向南边和东边流出水，那么这个方块的流向将会变成东南偏南方向，因为2个向南的流向（流入、流出）与1个向东的流向（流出）发生了合并。因此，水平方向有16个可能的流向。如果一个河道分支的入口有2方块宽，则实体会流入分支而非沿着河道直线流动。

水方块会产生向下的水流。水方块中的向下水流是由其下方方块造成的。大多数没有固态的顶部面的方块都会在其上方的水方块中产生向下水流。冰和下流的水方块（由向下传播造成的方块）也会在其上方的水方块中形成向下水流，流动的水默认会有一个向下水流。

# = 光线 =
水不会额外减少亮度，但会散射天空光照，因此随着玩家在水中下降，天空光照逐渐消失。水下的视野取决于玩家所在的生物群系。[夜视](夜视.md)和[潮涌能量](潮涌能量.md)状态效果可以增加水下视野。

# = 颜色 =

水有多种颜色，具体取决于生物群系。

# = 熔岩和水的互动 =

水和[熔岩](熔岩.md)可以生成[石头](石头.md)、[圆石](圆石.md)或者[黑曜石](黑曜石.md)，取决于它们如何互动。如果水接触到熔岩源的侧面或上表面，熔岩就会变成黑曜石。如果或，则会产生圆石并且不会移除任何液体源，如果或，则水源会变成石头。

# = 耕地 =

水能湿润附近的[耕地](耕地.md)。

# = 对生物造成伤害 =
水会对[末影人](末影人.md)、[烈焰人](烈焰人.md)、[雪傀儡](雪傀儡.md)、[蜜蜂](蜜蜂.md)和[炽足兽](炽足兽.md)造成伤害，但[炼药锅](炼药锅.md)里的水除外。炼药锅里的水仍会对末影人造成伤害。

# = 减慢挖掘速度 =
玩家头部在水下时，站在水底的[挖掘](挖掘.md)时间是正常的5倍，若未站在固体表面则效果会叠加为25倍。但通过使用[水下速掘](水下速掘.md)魔咒，挖掘速度会变快，从而令站在水底时与正常挖掘时间一样，但未站在固体表面时挖掘时间还是正常时间的5倍。

# = 溺水 =

多数生物在水中无法呼吸，而[鳕鱼](鳕鱼.md)、[鲑鱼](鲑鱼.md)、[热带鱼](热带鱼.md)、[河豚](河豚.md)、[鱿鱼](鱿鱼.md)、[发光鱿鱼](发光鱿鱼.md)、[青蛙](青蛙.md)、[鹦鹉螺](鹦鹉螺.md)、[僵尸鹦鹉螺](僵尸鹦鹉螺.md)、[海龟](海龟.md)、[蝌蚪](蝌蚪.md)和[美西螈](美西螈.md)可以在水中呼吸。无法呼吸一段时间后，生物的氧气值就会耗尽并开始受到伤害。

# = 生物转化 =
当一个[尸壳](尸壳.md)的头部处于水中30秒后，它会开始摇晃，再经15秒后变成[僵尸](僵尸.md)。

当一个僵尸的头部处于水中30秒后，它会开始摇晃，再经15秒后变成[溺尸](溺尸.md)。

# = 固化混凝土粉末 =
当水与[混凝土粉末](混凝土粉末.md)接触时，粉末会固化成[混凝土](混凝土.md)。

# = 海绵 =
当水与[海绵](海绵.md)接触时，3到5方块内的连接的水方块会被消除，海绵也随之变成湿海绵。原来水中的[海草](海草.md)，[海带](海带.md)，[睡莲](睡莲.md)也会被移除，掉落相对应的物品。水生生物也会因此受到窒息伤害。

吸收面积取决于海绵周围水的布局。一块海绵可以吸收4格长，4格宽，1格深中的所有水，但是同时也可以吸收掉2×11格中的水。当海绵尝试吸收2×12格的水时，一小格水会存在于水流末端。当海绵被放置在4×4×4的水中部甚至上部时，其中所有水都会被移除。大于4×4×4方块的水不会被完全移除；所剩余的水方块的数量取决于水方块的形状和海绵的位置。

# = 滴水 =
当水或含水方块下方的支撑方块不是液体时，如果支撑方块的碰撞箱最高高度<1且水源底面的[方块支撑形状](方块支撑形状.md)完整，那么水滴[粒子](粒子.md)会从水源的底面滴落。如果支撑方块不是[玻璃](玻璃.md)、[遮光玻璃](遮光玻璃.md)或[染色玻璃](染色玻璃.md)且支撑方块的碰撞箱最高高度≥1且支撑方块的碰撞箱最低高度与支撑方块下方方块的碰撞箱的最高高度的和<1时，水滴粒子会在支撑方块的碰撞箱最低处滴落。

当[滴水石锥](滴水石锥.md)正好悬挂在原本的水滴粒子滴落面下，那么水滴粒子会从滴水石柱的底部滴落并可以被下方的[炼药锅](炼药锅.md)缓慢收集。

水在多数时间都是静止的，而不是“流动的”——不管它的级别是多少，或是否包含一个向下或向侧面的水流。当被一个特定的方块更新触发时，水会变成“流动的”，更新它的级别，然后变回静止。水泉以流动的水生成，而海洋、湖泊以及河流是以静止的水生成的。这在多数[结构](结构.md)生成时就出现了，导致水“故障”的主要原因是生成的结构不会触发方块更新来让水流进它们。

# 你知道吗
[thumb|基岩版中使用命令在下界荒地和玄武岩三角洲交界处放置的水](File:Water In Basalt Delta.png.md)
* 使用[命令](命令.md)在[下界荒地](下界荒地.md)、[灵魂沙峡谷](灵魂沙峡谷.md)、[绯红森林](绯红森林.md)和[诡异森林](诡异森林.md)生成的水会呈现红色，而在[玄武岩三角洲](玄武岩三角洲.md)生成的水会呈现蓝色。
* 在水下时，玩家的FOV（视野）减低了10，以模拟光的折射。
* 旧的水纹理现在仍然可以在assets文件中找到。如果玩家在水下，那么游戏就会使用这个纹理。
* 水会阻止爆炸发生。这是由于水的高爆炸抗性使得水能够吸收所有爆炸，但、[床](床.md)或[重生锚](重生锚.md)的爆炸例外。
