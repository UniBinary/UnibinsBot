# 命令/turn

*页面ID: 56674* | *来源: Minecraft Wiki*

以特定方向让[智能体](智能体.md)旋转90°。

# 语法
   <code>-{}-turn <*方向：字符串*></code>

# 参数
   *方向：字符串*
  : 指定需要转身的方向。
  : 必须为以下之一：
  :* <code>left</code>——向左转。
  :* <code>right</code>——向右转。
