# 基岩版1.14.0.52

*页面ID: 49770* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.14.0.52**是[1.14.1](基岩版1.14.1.md)的第3个测试版，发布于2019年11月26日<ref></ref>，修复了漏洞。

# 修复
* 修复了在部分Android设备上登录Xbox Live 账户时发生的崩溃。
* 为Xbox One加入了解决更新游戏后的崩溃以及用户界面损坏问题的潜在修复方案。
* 向南或北走动时视角又会正常晃动了。（）
* 修复了合成多个物品时物品会消失的问题。（）
* 修复了奶桶中的奶有时会消失的问题。（）
* 现在幼年蜜蜂被攻击时蜜蜂也会被激怒。
* 修复了禁用资源包后出现的受损纹理。
* 修复了部分玩家无法退出市场“物品栏”界面的问题。
* 提升了玩家数量较多的地区的性能。
* 修复了部分角色创建器物件显示不正确的问题。</onlyinclude>
