# 闪烁标语

*页面ID: 8445* | *来源: Minecraft Wiki*

体现译名差异。}}

* *闪烁标语（Splash）**是[主菜单](主菜单.md)上的黄色文本。其内容由下表中随机选取，并且通常引自流行文化（如网站、精悍引述和电子游戏等）。闪烁标语会在标题屏幕以2Hz（120）的频率跳动。

闪烁标语不在语言文件中定义，没有相应的本地化键名，因而不会随语言设置更改而改变。下文中给出的中文翻译仅供参考。

闪烁标语在[客户端核心文件](客户端核心文件.md)内以纯文本文件形式存储（位于）；则以JSON文件形式存储（位于）。可以使用[资源包](资源包.md)修改闪烁标语。

可以在辅助功能设置中调整是否隐藏闪烁标语。

较长的闪烁标语文本会分为两行显示。若一个单词被分为两行，第一行末尾会额外显示“-”。

# 历史
闪烁标语自[Indev](Java版Indev.md)和[携带版0.7.3](携带版0.7.3.md)就出现在Minecraft中，且不断有新标语加入，一般会在大型更新的时候添加。在Java版Alpha 1.0.14和携带版0.12.1 build 1之前，闪烁标语存放在源代码的一个字符串数组中。
