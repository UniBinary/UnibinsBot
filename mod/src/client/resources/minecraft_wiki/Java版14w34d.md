# Java版14w34d

*页面ID: 32420* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w34d**是[Java版1.8](Java版1.8.md)的第52个，也是最后一个快照，发布于2014年8月20日<ref></ref>，修复了一些漏洞和[14w34a](14w34a.md)、[14w34b](14w34b.md)和[14w34c](14w34c.md)中的崩溃问题。官方宣布这是在1.8预发布版发布前的最后一个快照<ref></ref>。
