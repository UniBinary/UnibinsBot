# 携带版0.12.1.b6

*页面ID: 27840* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.12.1 alpha build 6**是[v0.12.1 alpha](携带版0.12.1.md)的第6个测试版，发布于2015年8月6日，修复了一些漏洞。

# 更改
* 重新整理创造模式物品栏中石锹和石锄的摆放位置。
* 更改在下界中放置水时的粒子。
* 熔岩现在更明亮了。
* 熔岩现在会在下界中更快地流动。
* 提高恶魂射击玩家时的精准度。
* 在选项中加入了玩家视角（即第一人称视角、背面第三人称视角、正面第三人称视角）的滚动条。

# 修复

* *其他**
* 创造模式下的玩家会死于掉入虚空。
* 使用时运魔咒会复制矿石。
* 下界里的熔岩流动速度太慢。
* 破坏箱子后，箱子里的已经附魔的物品会失去其魔咒。
* 修复了多人游戏下部分物品（例如剑和锹）合成错误的漏洞。
* 手持船时只会显示橡木船的纹理。
* 在灵魂沙上移动的实体变黑。
* 跳跃时出现错误的羊毛粒子。
* 铁砧在多人游戏下出现漏洞。
* 选择皮肤时无法退出更改皮肤界面。</onlyinclude>
