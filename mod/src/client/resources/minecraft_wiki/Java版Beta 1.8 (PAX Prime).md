在上，[Mojang](Mojang Studios.md)展示了早期开发的**[Beta 1.8](Java版Beta 1.8.md)**版本。该版本于2011年8月25日编译<ref></ref>，并在第二天的活动中展示给公众。

# 与Java版Beta 1.8-pre1的不同
# = 方块 =
* *[枯萎的灌木](枯萎的灌木.md)**
* 缺少提示框。

* *[藤蔓](藤蔓.md)**
* 缺少提示框。

* *[箱子](箱子.md)**
* 仍然使用完整方块的模型。

* *[栅栏门](栅栏门.md)**
* 缺少提示框。
* 在物品栏中显示为平面纹理：[32px](File:Oak Planks (texture) JE3 BE1.png.md)。

* *[仙人掌](仙人掌.md)**
* 对玩家造成伤害时会补充其饥饿值。<ref></ref>

# = 生物 =
* *常规**
* 每个生物死亡时都会掉落十个单独的[经验球](经验球.md)。
* 被动生物受到攻击时不会跑来跑去。

* *[猪](猪.md)**
* 使用有扁平鼻子的旧模型。

* *[末影人](末影人.md)**
* 死亡时掉落0-2个[钻石](钻石.md)。

# = 世界生成 =
* *[玫瑰](虞美人.md)**
* 会在世界中生成。

* *[村庄](村庄.md)**
* 会生成在任何生物群系，包括海洋。

* *[沙漠](沙漠.md)**
* 一层沙子会生成在泥土上。

* *[沼泽](沼泽.md)**
* 作为一个占位符生物群系。
* 生物群系颜色与[平原](平原.md)相同。
* 不会生成树和矮草丛。

* *[针叶林](针叶林.md)**
* 作为一个占位符生物群系。
* 生物群系颜色与[平原](平原.md)相同。
* 会有稀疏的树木生成。
* 不会生成矮草丛。

* *[风袭丘陵](风袭丘陵.md)**
* 不会生成矮草丛。

* *[海洋](海洋.md)**
* 不会生成矮草丛。

# = 游戏内容 =
* *[物品栏](物品栏.md)**

* 玩家在[生存模式](生存模式.md)创建世界时会携带以上物品。

* *常规**
* 创建世界时玩家会生成在村庄中。

* *[疾跑](疾跑.md)**
* 一次仅持续五秒，在此期间移动速度和视野都会减小。

* *[平视显示器](平视显示器.md)**
* 当玩家的经验等级至少为1时，在经验条的顶部就会显示玩家的“Skill point”，其的数量是经验等级的三倍。
* 版本号不会在左上角出现。

* *[控制](控制.md)**
* 按键绑定不能绑定到鼠标。<ref></ref>
* 只需要按下键即可调节渲染距离，而无需另外按下键。<ref></ref>

# = 常规 =
* *[主菜单](主菜单.md)**
* 使用了旧的[Mojang](Mojang.md)徽标。

* *[多人游戏](多人游戏.md)**
* 多人游戏屏幕没有“刷新”按钮。

* *[光照](光照.md)**
* 使用旧的更新代码。<ref></ref></onlyinclude>

# 你知道吗
* 该版本是PAX Prime 2011中能在现场游玩两个版本中的一个，另外一个是[携带版Demo](携带版Demo.md)。
