# 平视显示器

*页面ID: 15816* | *来源: Minecraft Wiki*

* *平视显示器（Heads-up display，HUD）**是供玩家查看自身游戏状态的屏幕，叠加在玩家在游戏中的视野上。

# 显示
[class=pixel-image|缩略图|在游戏中存在的所有条。从左下起顺时针依次为生命条、盔甲条、氧气槽和饥饿条，底部为经验条](File:HUD.png.md)

HUD会显示玩家的[生命](生命.md)、[饥饿](饥饿.md)和[经验](经验.md)等信息。若不使用触屏，或使用触屏但开启了分离控制，则屏幕中央会出现**十字准星（Crosshair）**，用以指示对准的实体或方块。如果玩家穿着盔甲，则生命条的上方会显示盔甲条；如果玩家在水下，则饥饿条的上方会显示氧气槽。使用携带版UI时，盔甲条和氧气槽会显示在生命条和饥饿条的下方。

在[创造模式](创造模式.md)中，生命条、饥饿条、经验条、盔甲条和氧气条都将隐藏。

[聊天](聊天.md)也是HUD的一部分，它在或，显示了最近的聊天内容或最近执行的命令。可以通过按下或来展开它。

# = 快捷栏 =
[class=pixel-image|thumb|中的快捷栏](File:Hotbar.png.md)
[class=pixel-image|缩略图|[[基岩版](File:Hotbar (BE).png.md)中触屏模式下的快捷栏]]
[class=pixel-image|缩略图|[[New Nintendo 3DS版](File:3DS_hotbar.png.md)中下屏幕的快捷栏]]
* *快捷栏（Hotbar）**出现在HUD底部，用于存储与选择常用物品。快捷栏是物品栏的一部分，有9格。选择的物品会显示在HUD的主手位置上，如果选择的物品为空，那么会显示玩家的手。当玩家选择物品时，选择物品的对应名称会短时间内显示在经验条的上方，。处于创造模式时不会显示物品栏中物品的数量和耐久度。

若使用[双持](双持.md)，则会在副手位置上展示另一物品，并且快捷栏在相应位置会出现一个额外的槽位，这个槽位和里面的物品仅在该物品存在时显示。其会在快捷栏的左边或右边（取决于惯用手设定）显示副手槽和手持的物品。

在使用触屏操控时，快捷栏最右侧有一个额外的按钮，用于打开物品栏。

在[原主机版](原主机版.md)中，快捷栏的外观与Java版和基岩版类似，但位置稍高且透明度稍有不同。

在[New Nintendo 3DS版](New Nintendo 3DS版.md)中，快捷栏位于下屏幕，支持触控笔操作且外观稍有不同。

# = 纸娃娃 =

纸娃娃是显示在HUD左上角的玩家模型。它在玩家[疾跑](疾跑.md)、[潜行](潜行.md)、冲刺[游泳](游泳.md)、使用[鞘翅](鞘翅.md)飞行、装备[盔甲](盔甲.md)等状态时显示。显示内容包括玩家的皮肤、穿戴的盔甲及玩家的动作姿态。

可以通过按键盘上的或通过设置来开启或关闭纸娃娃。

# = 触屏按键 =

[class=pixel-image|thumb|基岩版中“方向键并进行互动”模式下的按键（旧版）](File:HUD-BE-Directional buttons.png.md)
[class=pixel-image|thumb|基岩版中“摇杆并点击进行互动”和“摇杆并瞄准十字线”模式下的按键](File:HUD-BE-Joystick buttons.png.md)
|三种不同的触控模式}}

这些按钮仅在使用[触控](触控.md)控制模式时出现，作为缺乏实体按键的代替方案，它们可以控制玩家行走、[潜行](潜行.md)、飞行或跳跃等。在[设置](选项#基岩版.md)的|觸控}}选项中，可以更换跳跃和潜行的位置。

可以在设置中（设置 →  → 控制模式）选择控制模式，并且初次游戏时会自动弹出。有三种控制模式：摇杆并点击进行互动、方向键并进行互动、摇杆并瞄准十字线。触摸控制在所有支持触控的设备上都可用。

使用方向键控制时在设置中（设置 →  → 分离控制）可启用十字准星。

触摸控制在支持触摸的设备上可用，但Nintendo Switch除外，其触摸屏只能用于与快捷栏、物品栏和菜单进行交互。其他平台可以在设置 → 中启用|觸控僅會影響快捷列}}来达到相同的效果。

在设置中（设置 →  → 自定义控制）可自定义按键的位置、透明度和大小。

# = 十字准星 =
十字准星是屏幕中间的一个十字光标。它展示了你将会在何处使用手中[工具](工具.md)或[物品](物品.md)。十字准星以反色效果显示，这导致其在灰色区域内时几乎是隐形的。

如果[选项](选项.md)内的[攻击指示器](攻击指示器.md)被设置为“十字准星”，武器的冷却时间会通过十字准星下方出现的剑图标显示，图标代表了冷却进度且在武器冷却时间结束后会消失。在“十字准星”模式下如果手持完全冷却的武器且生物和或玩家在攻击范围内，剑的图标及其带额外的加号（+）会显示在十字准星的下方，表明武器在攻击范围内获得最大伤害。

# = 状态效果 =
玩家当前拥有的所有[状态效果](状态效果.md)都显示在屏幕的右上方。即将消耗殆尽的状态效果显示在左侧，并且会开始闪烁。此外，正面状态影响显示在顶部，其他效果（中性或负面的）显示在底部。信标效果具有蓝色（而非灰色）的轮廓，并且HUD中不会显示隐藏了粒子的状态效果。

玩家当前拥有的所有[状态效果](状态效果.md)都显示在屏幕的右上方，并从上到下排列。所有状态效果（包括信标所给予的）按[状态效果ID](基岩版数据值#状态效果ID.md)排列。玩家需要按键或点击任意一个状态效果来查看所有状态效果的剩余时间。如果玩家启用过设置下的自定义控制，并且使用触摸控制，则玩家当前拥有的所有状态效果会从右到左排列，，使用携带版UI时会显示在饥饿条下方。

# = 经验条 =
经验条是一个进度条外观的黄绿色长条，被或，表示了玩家当前有多少经验。

随着玩家获得经验值，经验条会被逐渐填满。当经验条被填满后，玩家的经验等级会增加1，经验条也会相应清空。

当玩家具有1级或更高的经验等级后，经验等级的数值就会显示在经验条或，以黄绿色的文本呈现。

经验条会被[跳跃蓄力条](#骑乘生物.md)或[定位栏](定位栏.md)取代。

# = 骑乘生物 =

[class=pixel-image|缩略图|满的马跳跃蓄力槽](File:Horse jump bar full.png.md)
玩家骑乘[马](马.md)、[驴](驴.md)、[骡](骡.md)、[骷髅马](骷髅马.md)、[僵尸马](僵尸马.md)、[猪](猪.md)、[炽足兽](炽足兽.md)、[骆驼](骆驼.md)、[骆驼尸壳](骆驼尸壳.md)、[鹦鹉螺](鹦鹉螺.md)或[僵尸鹦鹉螺](僵尸鹦鹉螺.md)时，生物生命条会出现在饥饿条的位置（[生存模式](生存模式.md)或[冒险模式](冒险模式.md)下后者会被代替），其纹理与玩家的生命条略有不同。同时经验栏会被该动物的跳跃蓄力栏暂时替代，但经验等级仍会正常显示。

玩家骑乘上述生物时，生物生命条会显示在饥饿条或氧气槽（如有）所在位置的上方，其纹理与玩家的生命条略有不同。该动物的跳跃蓄力栏仅在玩家按住键时代替经验栏显示，同时经验等级会正常显示。

# = 定位栏 =

[thumb|class=pixel-image|生存模式的定位栏](File:Survival Locator Bar.png.md)
已启用游戏规则时，如果世界中存在非自身且非自身正在骑乘的生物的路径点，玩家的动作栏下方位置会显示定位栏。

# 选项
HUD和[GUI](GUI.md)的大小可以通过中的“”}}或设置中的“”}}选项调整。

按或设置中启用“隐藏 HUD”}}可以隐藏所有HUD和方块的轮廓选择线。
* 此操作还会隐藏“高品质”图像设置下的[晕影](wzh:晕影.md)、以及使用[望远镜](望远镜.md)和戴上[雕刻南瓜](雕刻南瓜.md)后遮挡视野的部分。
* 此操作还会隐藏使用触摸控制时的按钮、纸娃娃、坐标显示和游玩的天数显示。
* * 此操作**不会**隐藏[测试版本](基岩版版本记录/开发版本.md)屏幕顶部的[构建信息](构建信息.md)。

可以使用命令来单独调整每个HUD元素的可见性。

HUD也在[调试屏幕](调试屏幕.md)中存在，调试屏幕可以通过按下隐藏。按下将会显示一个饼状图，这个图会显示当前资源的分配情况。按下会显示FPS的统计图。

玩家可以切换主手为左手或右手，副手和副手槽会被移至主手的另一侧。
