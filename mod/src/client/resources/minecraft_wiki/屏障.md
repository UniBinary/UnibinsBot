* *屏障（Barrier）**是一个拥有混合属性的隐形方块。

# 生成
屏障不会生成在世界中。

# = 自然生成 =

屏障在[调试模式](调试模式.md)世界中自然生成。Y=60处生成的屏障层延伸到世界边界处，覆盖整个世界的Y=60层。

# 获取

屏障无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，屏障可以通过”，或“”中有屏障）|JE}}、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
屏障不能被挖掘破坏。

屏障被破坏后不会掉落。

# 用途
屏障（左二）以及游戏中的其他隐形方块被渲染出的立方体框外观}}
玩家在生存模式下也可以放置屏障。

屏障在物品栏内的纹理为一个红色的禁止标识，但在放置后是完全不可见的。玩家只能通过其不可通过性和选中时的判定箱线框来得知屏障的存在。

尽管屏障是一种碰撞箱完整的窒息方块、固体方块、红石导体，光照传播会无衰减地穿过屏障。屏障不会挡住[信标](信标.md)的光柱，不会与[栅栏](栅栏.md)、[铁栏杆](铁栏杆.md)、[玻璃板](玻璃板.md)等方块连接，但在与方块、生物和[红石信号](红石信号.md)交互时和普通的完整方块没有任何差别。屏障的[方块支撑形状](方块支撑形状.md)每个表面都是完整的，因此火把、红石粉等方块可以放在屏障上。

屏障无法被[活塞](活塞.md)移动，也不能被[末影龙](末影龙.md)和[凋灵](凋灵.md)破坏。

[生物](生物.md)不能在屏障方块上自然生成。

屏障可以[含水](含水.md)。只有处于创造模式的玩家，才可以用桶把水倒入屏障，或从屏障中装水。

处于开启了“显示隐形方块”的储存模式[结构方块](结构方块.md)的存储区域范围内的屏障会显示出一个红色的立方体框。

# = 粒子 =
在[创造模式](创造模式.md)下，当玩家手持物品形式的屏障方块时，所有已经放置的屏障方块会以[粒子效果](粒子#block_marker.md)的方式显示其物品图标。此效果由客户端处理。

图标将在玩家手持屏障后随机显示，每个粒子显示。距离越近显示概率越大，最终在32格（[切比雪夫距离](切比雪夫距离.md)）外完全不显示。含水的屏障不会显示出粒子。当[](视频设置.md)设置为“”时，屏障粒子将不会被显示。

图标将在玩家手持屏障后立即全部显示。
