# Java版标签/旗帜图案

*页面ID: 161615* | *来源: Minecraft Wiki*

* *旗帜图案标签（Banner Pattern Tags）**是旗帜图案的组合。

# 使用
旗帜图案标签用于控制[织布机](织布机.md)可绘制的图案。

对于旗帜图案物品而言，这些标签也是它们<code>provides_banner_patterns</code>组件的默认值。
