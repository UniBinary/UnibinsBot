# Java版21w44a

*页面ID: 90601* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w44a**是[Java版1.18](Java版1.18.md)的第8个，也是最后一个快照，发布于2021年11月3日<ref></ref>，改进了旧世界升级，加入了新选项，做了一些调整，并修复了一些漏洞。

# 新内容
# = 世界生成 =
* *旧世界升级**
* 现在旧世界高度的区块升级到新世界高度时，其Y=0以下会按新世界生成机制生成。
* * 但由于漏洞，[深板岩](深板岩.md)和[基岩](基岩.md)层暂时无法在这里生成。<ref></ref>
* [巨型生物群系](巨型生物群系.md)和[放大化](放大化.md)世界现在可以被升级，升级到新的地形系统时，会被保留更多的特征。

# = 常规 =
* *[选项](选项.md)**
* 加入了单独的“”选项界面，位于原先主菜单上的“Realms的通知”选项以及多人游戏暂停菜单上的“难度”位置上。
* * “Realms的通知”被移入此界面。
* * 加入了“”选项，用于设置是否允许服务器将自己的ID公开展示在在线玩家列表中。
* * 加入了“”，用于显示当前的服务器难度。

* *[server.properties](server.properties.md)**
* 加入了<code>hide-online-players</code>，用于服务端收到客户端的状态请求时是否发送在线玩家列表。

# 更改
# = 世界生成 =
* *[深板岩](深板岩.md)**
* 现在会在Y=1到Y=7之间过渡生成，而非之前的Y=-7到Y=-1。

# = 游戏内容 =
* *[进度](进度.md)**
* 将主世界的所有50种生物群系都列入了进度[](进度#advancements-anchor-adventure.adventuring_time.md)的达成要求中，其中新增的19种生物群系如下表所示：


* *[天气](天气.md)**
* 睡觉现在只会在降雨或雷暴时重置天气变化过程。

# = 常规 =
* *JFR分析**
* 现在当JFR分析从外部来源启动时，网络数据包有关的JFR事件会被合并在一起，而不是一个数据包对应一个事件。

* *模拟距离**
* 现在方块和液体也会受到模拟距离的控制。
* 将模拟距离[选项](选项.md)的最小值从2个区块上调到5个区块。

* *常规**
* 优化了实体碰撞。
