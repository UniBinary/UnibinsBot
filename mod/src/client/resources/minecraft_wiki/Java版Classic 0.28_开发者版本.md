# Java版Classic 0.28/开发者版本

*页面ID: 84922* | *来源: Minecraft Wiki*

该条目记录了[Java版Classic 0.28](Java版Classic 0.28.md)的所有开发者版本。

# 0.27 SURVIVAL TEST（2009年10月25日）

该版本测试了[绵羊](绵羊.md)。<ref> produce cloth.|2009年10月25日}}</ref>

# = 新内容 =
* *[绵羊](绵羊.md)**
* 自然生成于世界中。
* 被杀死后掉落[红色羊毛](红色羊毛.md)。

# 0.27 SURVIVAL TEST（2009年10月25日）

该版本调整了绵羊。<ref></ref>

# = 更改 =
* *[绵羊](绵羊.md)**
* 被杀死后现在会掉落白色羊毛。

# 0.27（2009年10月26日）

该版本重新加入了[创造模式](创造模式.md)。<ref></ref>

# = 新内容 =
* *[游戏模式](游戏模式.md)**
* 在单人游戏中重新加入了创造模式。
* * 由于漏洞，创造模式的帧率比生存模式高。
