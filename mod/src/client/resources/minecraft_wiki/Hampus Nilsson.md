# Hampus Nilsson

*页面ID: 19555* | *来源: Minecraft Wiki*

* *哈帕斯·尼尔森（Hampus Nilsson）**是[Mojang Studios](Mojang Studios.md)的一名客户支持经理。他于2013年1月加入公司，但当[Marc Watson](Marc Watson.md)的工作能力改变时，他承担了带头的责任。<ref name="AdminManager"/>
