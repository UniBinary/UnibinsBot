# 燧石

*页面ID: 6908* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *燧石（Flint）**是用于制作[打火石](打火石.md)和[箭](箭.md)的常见原材料。

# 获取
# = 挖掘 =
[沙砾](沙砾.md)被挖掘时有10%的概率掉落1个燧石，其余情况下掉落其自身。使用带[时运](时运.md)I魔咒的工具挖掘可使掉率提高到14%，时运II的掉率为25%，时运III的掉率为100%。使用带[精准采集](精准采集.md)魔咒的工具挖掘沙砾，或是下落的沙砾掉在非[固体方块](固体方块.md)上时，不会掉落燧石。
