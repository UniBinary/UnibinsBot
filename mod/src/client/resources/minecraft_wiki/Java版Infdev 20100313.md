# Java版Infdev 20100313

*页面ID: 35921* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年3月13日，修复了一些漏洞。<ref name="Word of Notch"></ref>

# 新内容
# = 游戏内容 =
* *[昼夜更替](昼夜更替.md)**
* 被重新加入游戏。
* 周期长度短于Indev，一个周期约8分钟，昼夜各持续4分钟。

* *[亮度](亮度.md)**
* 重新正常运作。
* 重新加入了动态光照。

# = 世界生成 =
* *[世界界限](世界界限.md)**
* 被重新加入游戏。
* * 世界在X/Z=±32,000,000外停止生成，在此以外不会生成任何方块。

# 更改
# = 物品 =
* *[工具](工具.md)**
* 钻石质工具的[耐久度](耐久度.md)从257提升至513。

# = 生物 =
* *常规**
* 现在使用双精度浮点数来记录坐标，而不是单精度浮点数。

# = 非生物实体 =
* *常规**
* 现在使用双精度浮点数来记录坐标，而不是单精度浮点数。

# = 游戏内容 =
* *[亮度](亮度.md)**
* 更快的天空亮度重计算。

* *常规**
* 现在玩家生成时会携带更多的物品：999个[玻璃](玻璃.md)、999个[木板](木板.md)、999个[火把](火把.md)、999个[打火石](打火石.md)、999个[钻石锹](钻石锹.md)、999个[钻石镐](钻石镐.md)、999个[熔岩](熔岩.md)和999个[水](水.md)。

# = 世界生成 =
* *[黑曜石墙](Java版已移除特性#黑曜石墙.md)**
* 被移除。

* *天空**
* 移除了天空盒。

* *[雾](雾.md)**
* 现在离玩家更远了，并且略带蓝色。

# = 常规 =
* *[控制](控制.md)**
* 按会重新加载区块，而不是调整视距。

* *其他**
* 游戏现在只在内存中保留附近的[区块](区块.md)的数据，因此当[玩家](玩家.md)行走较远的距离时，内存不再会耗尽。
* * 然而，游戏并不会保存这些数据到硬盘中，当一个区块被卸载时，它的数据会丢失。<ref name="Word of Notch"/>

# 修复
* *修复了5个漏洞**
* 火、齿轮、火把和作物放置时能正常显示了。
* 火把可以放置在方块的侧面了。
* 恢复了熔炉的正面纹理。
* 破坏方块时产生的裂缝现在会连续显示了。
* 修复了一个明显的漏洞，即在远距离处会使得区块分离且相机视角剧烈抖动。</onlyinclude>
