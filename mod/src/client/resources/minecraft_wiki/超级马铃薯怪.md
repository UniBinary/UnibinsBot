* *超级马铃薯怪（Mega Spud）**是生成于[马铃薯维度](马铃薯维度.md)的Boss[生物](生物.md)。

# 生成
在世界生成[角斗场](角斗场.md)时会有1只超级马铃薯怪随之生成。

# 掉落物

}}

超级马铃薯怪在被[玩家](玩家.md)或被驯服的[狼](狼.md)杀死时还会掉落。

# 行为
超级马铃薯怪通过跳跃移动，每过一段时间跳跃一下。不像其他生物，超级马铃薯怪在附近没有玩家时不会停止移动。

超级马铃薯怪会主动攻击玩家、[村民](村民.md)、[流浪商人](流浪商人.md)和[铁傀儡](铁傀儡.md)。

超级马铃薯怪会向玩家发射实体数据<code>ExplosionPower</code>为2的[火球](火球.md)。

# = 阶段 =
超级马铃薯怪拥有10个阶段，首次受到伤害会进入第一阶段，此后每受到伤害进入下一阶段。其所受的除以外类型的单次伤害上限为。

每当进入一个阶段时，超级马铃薯怪将会：
* 更改[Boss栏](Boss栏.md)名称。
* 掉落多个[腐败的马铃薯皮](腐败的马铃薯皮.md)。
* 体型变小，且移动速度变快。
* 身体上出现一层力场，免疫除以外的伤害。
* 召唤出一波带有[发光](发光.md)效果的生物。当召唤的生物全部死亡时，它会咆哮并解除免疫伤害状态。
* 在免疫伤害状态下被玩家攻击时，会重新赋予召唤的生物[发光](发光.md)效果，同时玩家会受到伤害。



# = 发射火球 =
超级马铃薯怪会向玩家发射[火球](火球.md)，其发射的火球像恶魂火球一样，可以被反弹回去。

# = 生物族群 =

超级马铃薯怪是[马铃薯生物](马铃薯生物.md)，被[马铃薯削皮刀](马铃薯削皮刀.md)攻击时会额外受到伤害。

# 你知道吗
* 超级马铃薯怪的英文名字来源于[Jay Wells](Jay Wells.md)的推特ID“Mega_Spud”。
* 在语言文件中，对于该生物有一个未使用的Boss栏名称：“Mega Spud the Frogspawn Foreman”（）。
* 在[25w14craftmine](25w14craftmine.md)中，吃掉100个[毒马铃薯](毒马铃薯.md)会获得“[权威马铃薯杀手](进度/25w14craftmine#advancements-anchor-feats.eat_your_veggies.md)”进度，奖励一个超级马铃薯怪[奖杯](奖杯（25w14craftmine）.md)。
* * 超级马铃薯怪生物本身没有出现在25w14craftmine中。
