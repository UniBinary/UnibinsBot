# Java版12w04a

*页面ID: 32315* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w04a**是[Java版1.2.1](Java版1.2.1.md)的第2个快照，发布于2012年1月26日<ref></ref>，加入了[豹猫](豹猫.md)、[附魔之瓶](附魔之瓶.md)、[沙漠水井](沙漠水井.md)和[丛林树苗](丛林树苗.md)。

# 新内容
# = 方块 =
* *[丛林树苗](丛林树苗.md)**
* 可以生长成新的丛林树。
* 4×4方格的丛林树苗可以生长成巨大的丛林树。

# = 物品 =
* *[火焰弹](火焰弹.md)**
* 可以通过发射器发射，也可以手持点击以创造火。

* *[附魔之瓶](附魔之瓶.md)**
* 可以像[喷溅药水](喷溅药水.md)一样投掷，破碎后生成经验值。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了豹猫刷怪蛋。

# = 生物 =
* *[豹猫](豹猫.md)**
* 新的丛林生物群系特有的生物，可以用[生鱼](生鱼.md)驯服变成[猫](猫.md)。
* * 猫可以吓跑[苦力怕](苦力怕.md)，可以使其坐下，并且站立时可以像[狼](狼.md)一样传送至玩家身边。

# = 世界生成 =
* *[沙漠水井](沙漠水井.md)**
* 一种独有地生成于沙漠生物群系的小型结构。

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* [32px](File:Dispenser (S) JE2 BE1.png.md) 更改了纹理。

* *[橡树树苗](橡树树苗.md)**
* [32px](File:Oak Sapling JE4 BE1.png.md) 更改了纹理。

* *[藤蔓](藤蔓.md)**
* 玩家穿过藤蔓时会变慢，因为它的本质是没有碰撞箱的梯子。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 设置成任意数据ID的刷怪蛋（例如巨人、末影龙和末地水晶）不再生成对应的实体。
* 只有在创造模式物品栏中可用的刷怪蛋才能正常刷出对应生物。

# = 生物 =
* *常规**
* 生物有了改进它们行为的新的AI。
* * [骷髅](骷髅.md)和[僵尸](僵尸.md)在日光中燃烧时会逃到树底下或者跳进水里。
* * 生物不再尝试跳过[栅栏](栅栏.md)。

# = 常规 =
* *语言文件**
* 更新了[语言](语言.md)文件。</onlyinclude>

# 你知道吗
* 在标题画面中，当语言设置为“Afrikaans(ZA)”时，这个快照会用英语短语称呼用户为种族歧视词，取代了单人游戏按钮的文字。Mojang首席开发者Jens Bergensten承认了这个问题，并解释说这是恶作剧者滥用开放翻译系统的结果。下一个快照中删除了冒犯性内容，负责人被封禁。<ref></ref>
* *当语言设置为“Ingles (Uruguay)”时，“单人游戏”、“多人游戏”和“纹理包”按钮文本会被西班牙语短语“Otra razón para odiarte...”替换，翻译为“又一个讨厌你的理由......”。这很可能也是个恶作剧，因为语言标题和主菜单按钮的内容在之前的快照中都没有被破坏。
