# Java版14w28a

*页面ID: 33039* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w28a**是[Java版1.8](Java版1.8.md)的第34个快照，发布于2014年7月9日<ref></ref>，加入了新的命令，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 用法：
* *
* *
* 使用<code>CommandStats</code>的替代和更有特点的互动方式。
* * 它将根据影响该命令的实体/方块的数量来更新记分板目标以及更新该命令运行中的实体的目标，在命令方块中运行时可以使用假玩家。
* * 在<code>模式</code>之后，目前有4个可能的统计信息可以更新：<code>SuccessCount</code>、<code>AffectedBlocks</code>、<code>AffectedEntities</code>和<code>AffectedItems</code>。
* * 例如：在被执行时，将会更新一个名为“Test”的记分板目标，这个目标将会由受该命令影响的方块的数量来更新，因为统计信息被设置为<code>AffectedBlocks</code>。

# 更改
# = 方块 =
* *常规**
* 区块现在使用方块状态而不是方块元数据。

* *[蛋糕](蛋糕.md)**
* 现在是7片而不是6片。
* 可以被比较器检测并产生红石信号。
* * 每片相当于2红石信号强度，最大值为14。

# = 生物 =
* *[末影螨](末影螨.md)**
* 现在不再由[末影人](末影人.md)生成了。

# = 游戏内容 =
* *[魔咒](魔咒.md)和[状态效果](状态效果.md)**
* 魔咒和状态效果现在可以同时接受名称ID和数字ID。

* *[服务器](服务器.md)**
* 现在可以用自定义网络压缩。

# = 常规 =
* *[选项](选项.md)**
* 视频设置
* * 添加替选方块选项来禁用（或启用）加权的可选方块模型。
* ** 当关闭时，最不复杂的模型将最高优先级用于每个方块。

* *性能**
* 改进了显示的性能。
* 对服务器（包括单人的）和客户端的许多优化。
