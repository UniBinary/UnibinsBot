# 基岩版1.17.30.23

*页面ID: 89037* | *来源: Minecraft Wiki*

0以下的部分方块被替换为空气或区块整体下移。<ref></ref>}}
<onlyinclude>

* *beta 1.17.30.23**是[基岩版1.17.30](基岩版1.17.30.md)的第8个测试版，发布于2021年8月25日<ref></ref>，加入了[矿脉](矿脉.md)、[面条洞穴](面条洞穴.md)和多噪声生物群系生成机制，并修复了一些漏洞。<ref></ref>

# 更改
# = 物品 =
* *[营火](营火.md)和[灵魂营火](灵魂营火.md)**
* 现在可以堆叠至64个，以同步[Java版](Java版.md)。

# = 技术性 =
* *[Molang](Molang.md)**
* 为物品冷却加入新的实验性查询：、和。
* 更新了许多用于指出涉及运算符或查询的Molang内容错误。

* *数据驱动物品**
* 更新了IconItemComponent文档，现在列出了字段中的所有ID列表。

* *数据驱动音效**
* 移除了中的元素，因为其用法不明确且从未被使用。

* *游戏内容**
* 数据驱动方块现可添加至创造模式物品栏。
* 击退吼叫不再比之前版本更强力了。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“洞穴及悬崖”和“启用游戏测试框架”子选项后才可使用。

# = 世界生成 =
* *[主世界](主世界.md)**
* 现在生成时使用多噪声生物群系源类型。

* *[面条洞穴](面条洞穴.md)**
* 较[意面洞穴](意面洞穴.md)更细小且曲折的变种噪声洞穴，可在任意Y坐标处生成。

* *[矿脉](矿脉.md)**
* 一种罕见的巨型蛇形结构，区别于常见的较小矿石[团簇](团簇.md)。
* * [铜矿石](铜矿石.md)矿脉和[粗铜块](粗铜块.md)会与[花岗岩](花岗岩.md)伴生，并在Y=0以上生成。
* * [铁矿石](铁矿石.md)矿脉和[粗铁块](粗铁块.md)会与[凝灰岩](凝灰岩.md)伴生，并在Y=0以下生成。

* *[生物群系](生物群系.md)**
* [繁茂的丘陵](繁茂的丘陵.md)、[桦木森林丘陵](桦木森林丘陵.md)、[高大桦木丘陵](高大桦木丘陵.md)、[针叶林丘陵](针叶林丘陵.md)、[针叶林山地](针叶林山地.md)、[沙砾山地+](沙砾山地+.md)、[沙漠丘陵](沙漠丘陵.md)、[沙漠湖泊](沙漠湖泊.md)、[热带高原](热带高原.md)、[破碎的热带高原](破碎的热带高原.md)、[沼泽丘陵](沼泽丘陵.md)、[黑森林丘陵](黑森林丘陵.md)、[雪山](雪山.md)、[积雪的针叶林丘陵](积雪的针叶林丘陵.md)、[积雪的针叶林山地](积雪的针叶林山地.md)、[丛林变种](丛林变种.md)、[丛林丘陵](丛林丘陵.md)、[竹林丘陵](竹林丘陵.md)、[丛林边缘](丛林边缘.md)、[丛林边缘变种](丛林边缘变种.md)、[巨型针叶林丘陵](巨型针叶林丘陵.md)、[巨型云杉针叶林丘陵](巨型云杉针叶林丘陵.md)、[恶地高原](恶地高原.md)、[恶地高原变种](恶地高原变种.md)、[繁茂的恶地高原变种](繁茂的恶地高原变种.md)、[蘑菇岛岸](蘑菇岛岸.md)、[冰刺之地](冰刺之地.md)和[风蚀恶地](风蚀恶地.md)不再能够自然生成。
* [暖水深海](暖水深海.md)现在可以自然生成。

* *常规**
* 现在地势和[海拔高度](海拔高度.md)可以独立于[生物群系](生物群系.md)而变化，生物群系会适应地势的变化。
* * 例如，现在[森林](森林.md)、[沙漠](沙漠.md)等生物群系都可以过渡成[山脉](山脉.md)，而无需生成变种生物群系。
* * 另外，生物群系现在会在交界处更平滑地过渡。
* 地形现在更加平滑，极差也更大。

# 修复
* *游戏内容**
* 营火和灵魂营火现在可以在物品栏中堆叠。（）
* 现在插上蜡烛的蛋糕被活塞推动时会掉落该蜡烛。（）
* 使用水桶收集鱼或美西螈时不再会立刻将其放出。（）
* 重命名后的结构方块在放置时不再会使用不正确的数据模式。（）
* 摔落过程中掉入脚手架时不再会受到额外的摔落伤害。（）
* 修复了带有的告示牌使用荧光墨囊时，其文本的最右边缺失像素轮廓的问题。（）
* 现在荆棘魔咒的反伤会击退生物了。（）
* 调整了铁傀儡的生成机制以匹配Java版。
* 现在对着诡异菌岩使用骨粉有概率生成绯红菌索。（）

* *命令**
* 命令现在可以对睡觉中的玩家使用，且设置的重生点与玩家现有重生点相同时也会输出成功。（）
* 使用目标选择器时，相机抖动命令不再会导致所有玩家的屏幕抖动了。（）

* *市场**
* 修复了显示部分语言时句末会错误出现的“CR”字符的问题。

* *用户界面**
* 修复了登录按钮有时会出现在“市场”按钮后面的问题。
* 修复了使用日语的Windows和Xbox平台上的Noto Sans Smooth字体的易读性和使用问题。

* *技术性**
* 修复了在更多场景中会使用无效数据进行移动预测插值的问题。（）
* 修复了触发物品转换事件时的崩溃。
* 修复了使用动画控制器时粒子效果不会被发射的问题。
* 第一人称下的可见附着物不再会向后渲染。</onlyinclude>
