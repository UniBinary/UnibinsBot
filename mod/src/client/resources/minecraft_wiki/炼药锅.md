* *炼药锅（Cauldron）**是一种可以容纳[水](水.md)、[熔岩](熔岩.md)和[细雪](细雪.md)的方块。它也可以容纳药水和染色的水。

# 生成
# = 自然生成 =
[[[沼泽小屋](File:Natural Cauldron Table.png.md)里自然生成的炼药锅|缩略图]]

[沼泽小屋](沼泽小屋.md)中会生成1个炼药锅。生成的炼药锅是空的；该炼药锅会装有随机水位的随机药水或喷溅药水（除衰变药水）。

[雪屋](雪屋.md)地下室会生成1个水位为的炼药锅。

[林地府邸](林地府邸.md)的[盆栽房](林地府邸/结构/装饰品房间#盆栽房.md)会生成1个装满水的炼药锅，[小型监狱](林地府邸/结构/监狱房#小型监狱.md)和[红石监狱](林地府邸/结构/监狱房#红石监狱.md)内各生成1个空炼药锅，[大型监狱](林地府邸/结构/监狱房#大型监狱.md)内则有4个空炼药锅。

装满水的炼药锅也会自然生成于[村庄](村庄.md)的[皮匠屋](村庄/结构/图示#皮匠屋.md)内。平原类型的皮匠屋会生成或个，沙漠类型的皮匠屋会生成1个，其他类型的皮匠屋会生成2个。

空炼药锅还会自然生成于[古迹废墟](古迹废墟.md)的部分结构中。

# 破坏
挖掘炼药锅的合适工具是镐。炼药锅需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

炼药锅被破坏后会掉落自身，内容物会丢失。

装有熔岩的炼药锅被破坏后，其中的熔岩会迅速将掉落物烧毁，从而难以获得其物品。<ref></ref>

# 用途
# = 物质储存 =
炼药锅可用于储存[水](水.md)、、[熔岩](熔岩.md)和[细雪](细雪.md)。

若向装有物质的炼药锅加入其他物质，原先的物质会被替换掉。这样做会同时清空炼药锅中的物质和尝试加入的物质，并且炼药锅会产生类似水在下界蒸发的烟雾粒子和音效。

当炼药锅上方存在水时，则玩家不能用[熔岩桶](熔岩桶.md)或[细雪桶](细雪桶.md)与其交互。

即使在[冒险模式](冒险模式.md)下，玩家也能向炼药锅中加入或取出物质。<ref></ref>

# == 储存水和细雪 ==
|装有不同水位的水的炼药锅|style=max-width: 150px;}}
|装有不同积雪量的细雪的炼药锅|style=max-width: 150px;}}
对炼药锅[水桶](水桶.md)或[细雪桶](细雪桶.md)可填充炼药锅，即使是在[下界](下界.md)也是如此。炼药锅被完全填充后，可[空桶](空桶.md)收集炼药锅里的水或细雪，并清空炼药锅。对炼药锅使用[生物桶](生物桶.md)不会将其中的水和生物填充进炼药锅，<ref></ref>。

对炼药锅水瓶可让炼药锅的水位上升或并把水瓶变为[玻璃瓶](玻璃瓶.md)。玻璃瓶装炼药锅的水会减少炼药锅或水位，并把玻璃瓶填充为水瓶。

下雨或下雪时，露天的炼药锅里会缓慢地积攒水或细雪。

炼药锅的积水和积雪受[游戏规则](游戏规则.md)的值<math>n</math>影响。在执行区块刻的区块中，每区块每游戏刻有<math>n</math>次尝试，每次尝试有的概率成功，成功后会在16×16的水平位置中选取一个，在该位置的最高处有5%的概率增加一级水位，或者有10%的概率增加一层细雪。也就是平均每游戏刻每个炼药锅有<math>\frac{n}{245760}</math>的概率增加水的堆积程度，有<math>\frac{n}{122880}</math>的概率增加细雪的堆积程度。

如果该生物群系的降水值小于0.5，则炼药锅在接收到[随机刻](随机刻.md)后有两倍降水值的概率增加一级水位或者一层细雪，否则必然增加一级水位或者一层细雪。如果<code>IsCompatible</code>的值为<code>false</code>时只会增加水位。

空的炼药锅会在其上方为水时变成装有水的炼药锅，且水位是满的。非空的炼药锅不会因上方有水而改变水位。

如果由[滴水石锥](滴水石锥.md)组成的钟乳石所附着的方块上方有水源方块，且钟乳石下方有炼药锅，水就会缓慢填充炼药锅。

虽然装有水的炼药锅中看上去有[水](水.md)，但炼药锅不具有灭火以外任何水的行为，不具有水的爆炸抗性，实体在其中不会接触到水而产生声音或[粒子](粒子.md)，生物无法在其中漂浮和游泳且不产生气泡和水粒子，不会伤害[雪傀儡](雪傀儡.md)、、[炽足兽](炽足兽.md)和[烈焰人](烈焰人.md)，[鱼](鱼.md)和[美西螈](美西螈.md)在其中无法恢复[氧气值](氧气值.md)，其他生物在其中也不会[溺水](溺水.md)。

装有细雪的炼药锅不会冰冻其中的生物。

# == 储存染色水 ==

|装有不同颜色水的炼药锅|style=max-width: 150px;}}
炼药锅可以盛染色的水。对着炼药锅[染料](染料.md)会改变水的颜色并消耗1个染料。可以添加不同的染料以组合出不同颜色的水。对着炼药锅[皮革盔甲](皮革盔甲.md)、[皮革马铠](皮革马铠.md)或[狼铠](狼铠.md)会使其染色，并减少炼药锅内的一级水位。

# == 储存熔岩 ==
[150px|thumb|装有熔岩的炼药锅](File:Cauldron (filled with lava).png.md)
炼药锅能用来储存[熔岩](熔岩.md)。装有熔岩的炼药锅会使掉进其中的[实体](实体.md)受伤并着火，还会摧毁除下界合金质的[物品](物品.md)、[工具](工具.md)和[盔甲](盔甲.md)或[远古残骸](远古残骸.md)之外的所有掉落物。免疫火焰伤害的生物进入装有熔岩的炼药锅时会出现着火动画，与进入熔岩不同。<ref></ref>被射出的[箭](箭.md)如果卡在炼药锅侧面的合适位置，那么其也会着火。当对炼药锅[熔岩桶](熔岩桶.md)时，它会像熔岩那样[喷发粒子](熔岩#喷发粒子.md)。水流在装有熔岩的炼药锅上方不会使炼药锅发生任何变化。鍋釜中的熔岩不會使附近的方塊燃燒。

如果由[滴水石锥](滴水石锥.md)组成的钟乳石所附着的方块上方有熔岩源方块，且钟乳石下方有炼药锅，熔岩就会缓慢填充炼药锅。

# == 储存药水 ==

|装有不同药水的炼药锅|class=nomobile|style=max-width: 150px;}}
炼药锅可储存除[基础药水](药水酿造#基础药水.md)外的所有药水。对着炼药锅[药水](药水.md)、[喷溅药水](喷溅药水.md)或[滞留药水](滞留药水.md)会填充炼药锅1个药水位，并把手持的药水变成玻璃瓶；反之，可以用玻璃瓶装走炼药锅的药水，使其减少1个药水位。

填充同一炼药锅的药水必须是[状态效果](状态效果.md)、效果等级都相同的，否则会导致炼药锅被清空。然而，同种药水的对应喷溅型和滞留型可以混合在同一炼药锅，每个炼药锅都只记录最上方一个药水位（最近一次填充）的原瓶子类型。例如，依次向锅中倒入普通、喷溅型和滞留型的夜视药水，再用玻璃瓶装回来会得到3瓶滞留型夜视药水。

对着装有药水的炼药锅[箭](箭.md)会把箭变成对应状态效果的[药箭](药箭.md)，并清空炼药锅。单个药水位可以使最多16支箭变为对应的药水箭，而装满的炼药锅（3个药水位）可以一次性使最多64支箭变为药水箭。

# = 褪色 =
装有水的炼药锅能够洗去[皮革盔甲](皮革盔甲.md)、[皮革马铠](皮革马铠.md)、[狼铠](狼铠.md)、[潜影盒](潜影盒.md)的颜色以及[旗帜](旗帜.md)最外面一层图案，并减少炼药锅内的一级水位，通过对着炼药锅按下键进行。水在进行褪色后不会变色。

# = 灭火 =
装有水或细雪的炼药锅会为接触其内容物的[着火](着火.md)实体灭火。这些实体包括生物、玩家以及。着火的箭如果卡在炼药锅的侧面的合适位置，它上面的火也会被熄灭。炼药锅熄灭实体上的火时，其内容物高度会减少一级，其中的细雪在高度降低后若有剩余，则会变为水。

# = 红石元件 =
[把炼药锅用在红石电路里的一个例子|缩略图](File:Cauldron transmission over piston.png.md)

炼药锅可充当[红石比较器](红石比较器.md)的电源。在红石比较器后面的炼药锅（直接在红石比较器后面或被一个未被充能到15级的固体方块隔开）会输出一个强度与炼药锅装满程度成正比的红石信号。炼药锅为空时输出的红石信号强度为0，此后每填充的水或细雪，信号强度就会增加1，完全填充时强度为3。

红石比较器检测装有熔岩的炼药锅会发出强度为3的红石信号。

# = 更改村民职业 =

如果一个炼药锅没有被[村民](村民.md)认领，则附近的任意一个失业村民有机会转变职业为[皮匠](皮匠.md)。

# = 光源 =
装有熔岩的炼药锅会发出亮度等级为15的光。

# 你知道吗
* 炼药锅的内部有0.25（）个方块高。
* [箭](箭.md)无法进入炼药锅的内部，只会悬浮在炼药锅内壁的上方。
* 装有水的炼药锅被破坏时产生的粒子颜色与空的、装有熔岩或细雪的炼药锅不同，它们看上去像是炼药锅与[水](水.md)纹理混合的结果。
