# Java版Alpha v1.2.0 02

*页面ID: 32534* | *来源: Minecraft Wiki*

<onlyinclude>
* *Alpha v1.2.0_02**是的一次次要更新，发布于2010年10月31日，修复了一些漏洞。

# 更改
# = 方块 =
* *[灵魂沙](灵魂沙.md)**
* 现在又能在[下界](下界.md)生成了。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 现在有了新的受伤音效。<ref>[October 31, 2010, 17:09:33 UTC](https://web.archive.org/web/20120729205914/s3.amazonaws.com/MinecraftResources/) - timestamp in MinecraftResources.</ref>

# 修复
* *修复了1个漏洞**
* 玩家死亡时物品不再消失。

# 重新上传
Alpha 1.2.0_02于2010年11月4日重新上传，修复了在多人游戏中可以复制[火把](火把.md)和[南瓜灯](南瓜灯.md)的漏洞。</onlyinclude>
