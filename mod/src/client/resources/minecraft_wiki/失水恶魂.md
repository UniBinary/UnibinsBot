# 失水恶魂

*页面ID: 148787* | *来源: Minecraft Wiki*

}}

* *失水恶魂（Dried Ghast）**是一种可用于生成[小恶魂](小恶魂.md)的方块。

# 生成
# = 自然生成 =
生成[下界化石](下界化石.md)时，有50%概率在结构的最低一层随机选取一个方块，如果该方块为[空气](空气.md)则生成一个失水恶魂。

# 获取
# = 合成 =

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有（约2.13%）的概率给予玩家1个失水恶魂。

# 破坏
失水恶魂被挖掘时会立刻被破坏。

失水恶魂被破坏后会掉落自身。

# 用途
失水恶魂可以[含水](含水.md)，[水](水.md)和[熔岩](熔岩.md)会绕开失水恶魂流动。

失水恶魂有4个“湿润”阶段，可以通过其纹理的颜色外观来判断。失水恶魂被放置时处于第1阶段。

# = 转变 =
; Java版
在无计划刻时收到[随机刻](随机刻.md)后，失水恶魂会为自己设置一个的[计划刻](计划刻.md)。在收到计划刻时，如果失水恶魂当前处于含水状态，则会试图进入下一阶段，若已处于第4阶段则生成一个小恶魂并移除自身；否则，失水恶魂将恢复到上一个阶段。

在理想情况下，失水恶魂总共需要至少来生成小恶魂，默认随机刻速率下平均需要{{fn|-{}-<math>\approx(5000+4096\div3)\times4</math>}}。

; 基岩版
在放置后，失水恶魂会为自己设置一个随机计划刻，随机计划刻的时长等于除以随机刻。在收到计划刻时，如果失水恶魂当前处于含水状态，则会试图进入下一阶段，若已处于第4阶段则生成一个小恶魂并移除自身；否则，失水恶魂将恢复到上一个阶段。

# = 环境音效 =
当[含水](含水.md)时，或不含水且下方一格为[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)时，失水恶魂分别有概率发出不同的环境音效。
