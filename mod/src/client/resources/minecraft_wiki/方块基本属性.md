# 方块基本属性

*页面ID: 112644* | *来源: Minecraft Wiki*

[方块](方块.md)拥有众多属性，用于控制它们在各个游戏机制下的行为。如果一个方块或它的方块状态的性质不会因为它们所在的环境而发生改变，这些性质就称为方块的**基本属性**。

# 方块基本属性
# = 合适挖掘工具 =

方块的**合适挖掘工具（Breaking tool）**属性决定了什么物品可以有效地挖掘这个方块。

# = 硬度 =

方块的**硬度（Hardness）**决定了挖掘这个方块需要的挖掘时间。

# = 爆炸抗性 =

方块的**爆炸抗性（Blast resistance）**决定了方块在[爆炸](爆炸.md)中吸收和阻止爆炸破坏方块传播的强度。

# = 阻力系数 =
方块的**阻力系数（Friction）**决定了方块与站在其上方的[生物](生物.md)的“摩擦力”，影响生物的加速度并决定稳定移动速度。

如果一个方块绝对光滑，那么生物就无法自行移动；当方块的阻力系数为时，生物稳定移动速度最小。

绝大多数方块的阻力系数为0.6，[黏液块](黏液块.md)的阻力系数为0.8，[冰](冰.md)、[浮冰](浮冰.md)、[霜冰](霜冰.md)的阻力系数为0.98，[蓝冰](蓝冰.md)的阻力系数为0.989。

# = 速度乘数 =
方块的**速度乘数（Speed factor）**会在其上方的实体计算移动速度时产生影响。

当实体移动时，速度会与速度乘数相乘成为下一刻的速度。如果速度乘数小于1，则实体移动速度会被迅速减小直到等于上述乘积。

绝大多数方块的速度乘数为1.0，[灵魂沙](灵魂沙.md)、[蜂蜜块](蜂蜜块.md)的速度乘数为0.4。

# = 跳跃乘数 =
方块的**跳跃乘数（Jump factor）**会在其上方的生物计算跳跃速度时产生影响。

在没有[跳跃提升](跳跃提升.md)状态效果时，生物跳跃的基础速度为<math>0.42f</math>米每游戏刻，其中*f*就是跳跃乘数。

绝大多数方块的跳跃乘数为1.0，[蜂蜜块](蜂蜜块.md)的跳跃乘数为0.5。

# = 引燃几率 =

方块的**引燃几率（Flame odds）**影响[火](火.md)在其附近时传播到该方块表面上的几率和速率。引燃几率为正数的方块被称为**可燃方块（Flammable block）**。

# = 烧毁几率 =

方块的**烧毁几率（Burn odds）**影响[火](火.md)与其相邻时破坏该方块的几率和速率。方块烧毁几率为正数时，其所有表面均可燃烧，否则只有其完整的上表面可以燃烧。

当前所有引燃几率为正数的方块，其烧毁几率也为正数。

# = 熔岩可燃性 =

方块的**熔岩可燃性（Lava flammable）**决定了[熔岩](熔岩.md)是否可以在该方块上生成[火](火.md)。

# = 窒息方块 =

* *窒息方块（Suffocating block）**是[生物](生物.md)视平线处于其中时会发生[窒息](窒息.md)的方块。

# = 视野阻挡 =
* *视野阻挡方块（View blocking block）**会使视平线处于其中的非[旁观模式](旁观模式.md)玩家渲染阻挡视线的效果。绝大多数窒息方块都是视野阻挡方块。

玩家的屏幕会被窒息方块的纹理挡住而无法看见任何物体；窒息方块的内侧也会渲染其表面纹理，使玩家不能看到方块之外的物体。

# = 红石导体 =

方块的**红石导体（Redstone Conducting）**属性决定了方块是否可被[充能](充能.md)，具有红石导体属性的方块被称为**红石导体（Redstone Conductor）**。

尽管名为红石导体，该属性还控制了许多其他的行为，例如红石导体可以压断[红石线](红石线.md)，[箱子](箱子.md)在上方有红石导体时不能开启。

# = 可替代 =
方块的**可替代（Replaceable）**属性决定了方块是否可以被其他方块通过放置被直接替代掉，影响[方块物品](方块物品.md)放置出方块的方式。根据方块是否可替代，方块可以被分为**可替代方块（Replaceable block）**和**不可替代方块（Non-replaceable block）**。

[空气](空气.md)、[水](水.md)、[火](火.md)、[雪](雪.md)、[矮草丛](矮草丛.md)、[藤蔓](藤蔓.md)是典型的可替代方块。[沙子](沙子.md)、[红沙](红沙.md)、[沙砾](沙砾.md)、[龙蛋](龙蛋.md)、[铁砧](铁砧.md)、[混凝土粉末](混凝土粉末.md)、、[可疑的沙子](可疑的沙子.md)和[可疑的沙砾](可疑的沙砾.md)等在下方为可替代方块时会变为[下落的方块](下落的方块.md)。

# = Java版固体方块 =

方块的**固体（Solid）**属性有非常广泛的影响，常见有支撑物体和支持生物生成。具有固体属性的方块被称为**固体方块（Solid block）**。

[蛋糕](蛋糕.md)、[告示牌](告示牌.md)、[旗帜](旗帜.md)、[物品展示框](物品展示框.md)、[荧光物品展示框](荧光物品展示框.md)、[画](画.md)是典型的需要依附固体方块的物体；[仙人掌](仙人掌.md)的侧面有固体方块时会被破坏；[耕地](耕地.md)或[土径](土径.md)的上方有固体方块时会变为[泥土](泥土.md)（例外之一是耕地上方有[移动的活塞](移动的活塞.md)时不会变为泥土）。

# = 基岩版固体方块 =

方块的**固体（Solid）**属性具有许多影响。

[箱子](箱子.md)上方一格的固体方块（[信标](信标.md)、[客户端请求占位符方块](客户端请求占位符方块.md)、[荧石](荧石.md)、[海晶灯](海晶灯.md)、[TNT](TNT.md)、[水下TNT](水下TNT.md)除外）和下半[台阶](台阶.md)会阻止箱子打开；[耕地](耕地.md)的上方有固体方块时会变为[泥土](泥土.md)。

# = 基岩版材料固体方块 =

方块的[材料](基岩版材料.md)的**固体（Solid）**属性具有许多影响。

[蛋糕](蛋糕.md)、[按钮](按钮.md)等需要依附材料固体方块；[仙人掌](仙人掌.md)的侧面有材料固体方块时会被破坏；[土径](土径.md)的上方有材料固体方块（[门](门.md)、[栅栏门](栅栏门.md)除外）时会变为[泥土](泥土.md)。

# = 活塞推动行为 =

方块的**活塞推动行为（Push reaction）**决定了方块在[活塞](活塞.md)移动结构时的行为。

# = 乐器 =

方块的**乐器（Instrument）**决定了方块被放在[音符盒](音符盒.md)下时，音符盒使用的乐器类型。

# = 地图颜色 =

方块的**地图颜色（Map color）**决定了地图在表示此方块时会使用的颜色的基色。
