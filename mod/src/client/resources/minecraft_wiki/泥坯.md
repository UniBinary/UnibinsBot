# 泥坯

*页面ID: 93874* | *来源: Minecraft Wiki*

* *泥（Packed Mud）**是一种由[泥巴](泥巴.md)和[小麦](小麦.md)合成的方块。

# 生成
泥坯会自然生成在[古迹废墟](古迹废墟.md)中。

# = 合成 =

# 破坏
挖掘泥坯的合适工具是镐。

泥坯被破坏后会掉落自身。
