# Java版1.16.4-rc1

*页面ID: 71365* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.16.4-rc1**是[Java版1.16.4](Java版1.16.4.md)的唯一一个发布候选版本，发布于2020年10月27日<ref></ref>，在聊天中加入了隐藏匹配的名称的选项，并修复了一个漏洞。

# 新内容
# = 常规 =
* *[聊天](聊天.md)**
* 加入了隐藏的名称的选项。
* * 某些服务器会非标准格式的聊天。打开此选项后，游戏会的方式尝试隐藏聊天。
