# Java版1.19.2

*页面ID: 97600* | *来源: Minecraft Wiki*

* *1.19.2**是的一次次要更新，发布于2022年8月5日<ref name="article_1.19.2"></ref>，修复了2个严重漏洞。此版本不兼容1.19的服务端，兼容1.19.1的服务端。

# 修复

* *其他漏洞**
* 修复了玩家使用安全聊天时断开连接的漏洞。<ref name="article_1.19.2"/>
* 修复了社交屏幕中的崩溃漏洞。<ref name="article_1.19.2"/>
