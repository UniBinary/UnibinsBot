* *矿境回访器（Mine Revisitor）**是一种可生成前往现有[矿境](矿境.md)的[矿境传送方块](矿境传送方块.md)的方块。

# 生成
# = 自然生成 =
矿境回访器会自然生成于[大厅](大厅.md)结构中。

# 获取
矿境回访器只能通过破坏矿境回访器获得。

# 破坏
矿境回访器不能被挖掘破坏。

矿境回访器被破坏后会掉落自身。

# 用途
# = 生成矿境传送方块 =
对矿境回访器使用[矿境物品](矿境（物品）.md)后消耗此物品，并在其上方生成一个用于返回对应[矿境](矿境.md)的[矿境传送方块](矿境传送方块.md)，原位置上的方块会被破坏并掉落。

# = 光源 =
矿境回访器会发出亮度等级为15的光。
