# 基岩版1.20.20.20

*页面ID: 104717* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.20.20**（ChromeOS/Android）、**Preview 1.20.20.20**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.30](基岩版1.20.30.md)的首个测试版<ref></ref>，发布于2023年6月28日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[雪](雪.md)**
* 更改了高度以匹配，现在不同层数的雪均拥有不同的高度。

# = 生物 =
* *[马](马.md)、[驴](驴.md)和[骡](骡.md)**
* 现在即使未驯服也会跟随手持[金胡萝卜](金胡萝卜.md)、[金苹果](金苹果.md)或[附魔金苹果](附魔金苹果.md)的玩家。

* *[羊驼](羊驼.md)**
* 现在会跟随手持[干草捆](干草捆.md)的玩家。

* *[村民](村民.md)**
* 现在被杀死时掉落其手中的物品的概率为0%。
* * 类似于[恼鬼](恼鬼.md)，[抢夺](抢夺.md)魔咒仍会增加掉落概率。

* *[流浪商人](流浪商人.md)**
* 现在会出售[樱花树苗](樱花树苗.md)。
* 移除了独立交易选项中的[小麦种子](小麦种子.md)、[甜菜种子](甜菜种子.md)、[南瓜种子](南瓜种子.md)和[西瓜种子](西瓜种子.md)。

* *[僵尸村民](僵尸村民.md)**
* 现在会在外观上显示其职业。

# = 游戏内容 =
* *[声音](声音.md)**

* * [溺尸](溺尸.md)投掷[三叉戟](三叉戟.md)
* * [引雷](引雷.md)附魔三叉戟击中目标
* * 关闭[潮涌核心](潮涌核心.md)

* 现在破坏[铁砧](铁砧.md)、在铁砧上行走和摔落在铁砧上时会播放音效。
* 更改了[大型垂滴叶](大型垂滴叶.md)叶片恢复的音效。

# 修复
* *方块**
* 修复了玩家站在雪层上时无法在台阶下方爬行的漏洞。（）
* 现在雪层拥有与Java版相同的高度，不同层数的雪拥有不同的高度。

* *音频**
* 加入了荆棘造成伤害的音效，会在适当的时候播放。（）
* 铁砧现在会发出正确的音效，例如破坏铁砧、在铁砧上行走、摔落在铁砧上的时候。（）
* 现在骷髅射箭、溺尸投掷三叉戟时会播放音效。（）
* 现在实体被引雷附魔三叉戟击中时会播放音效。（）
* 现在玩家绘制空地图时会发出正确的音效。
* 下界传送门现在会在其黑曜石框架被破坏时发出破坏玻璃的音效。（）
* 现在返回到玩家身边的忠诚附魔三叉戟会在玩家所在位置播放音效。（）
* 现在大型垂滴叶重置倾斜状态时会播放正确的音效。（）
* 潮涌核心现在会在关闭时播放关闭音效。（）
* 重生锚现在会正确播放环境音效。（）

* *趋同**
* 下落的方块现在会在下落在船上时被破坏。
* 流浪商人现在也会出售樱花树苗。（）
* 更新了爬行时的相机视角插值率以匹配Java版。（）

* *命令**
* 实体被传送至玩家渲染距离边缘附近保存的区块时不再会消失。

* *游戏内容**
* 靠近水或熔岩时，第三人称相机视角不再会穿过地形。
* 修复了创造模式玩家站在火中时不会着火的问题。
* 玩家不再会在旁观模式下强制潜行或爬行。（）
* 现在玩家骑行时会强制取消潜行或爬行。（）
* 玩家不再会在激流动画期间强制潜行或爬行。
* 玩家不再会在不应该的情况下错误地触发潜行或爬行。
* 修复了服务器上无法触发爬行的一些问题。（）
* 现在在创造模式下进入飞行状态时会取消鞘翅滑翔状态。（）
* 修复了进入包含受损的已保存区块的世界时发生的崩溃。（）
* 现在对饰纹陶罐使用选取方块功能时，物品栏中会产生正确的悬停提示。（）

* *图形**
* 透过末地传送门观察的透明方块不再会变得可见或闪烁。（）
* 修复了传送门效果的底面的颜色和透明度与其他面不匹配的问题。
