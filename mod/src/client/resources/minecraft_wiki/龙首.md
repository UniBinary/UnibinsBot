# 龙首

*页面ID: 163443* | *来源: Minecraft Wiki*

* *龙首（Dragon Head）**是一种仅能从[末地船](末地船.md)获取的[生物头颅](生物头颅.md)。

# 生成
# = 自然生成 =
[末地船](末地船.md)头会生成一个墙上的龙首。

# 获取
龙首-{}-只能通过破坏龙首获得。

与其他[生物头颅](生物头颅.md)不同，龙首不會由[終界龍](終界龍.md)掉落。

# 破坏
没有工具可以加速对龙首的挖掘。

龙首被破坏后会掉落自身。

被爆炸破坏的龙首总是会掉落。

# 用途
龙首会被液体破坏。

# = 装饰 =
[thumb|right|100px|龙首的动画](File:Dragon Head.gif.md)
龙首被放置在方块顶面时可以呈16种不同的方向，而放置在方块侧面时可以呈4种不同的方向。龙首不需要方块支撑，且可以放置在其他头颅的上方或侧边。

龙首收到红石信号时会像[末影龙](末影龙.md)那样反复开合嘴部。若生物穿戴着龙首，相同的动画也会在该生物水平移动时出现。

# = 穿戴 =
<div style='float:right'></div>

玩家能将龙首装备在头盔槽位。[发射器](发射器.md)也可以将龙首装备给没有头戴物品的玩家、[盔甲架](盔甲架.md)和一些人-{}-形生物，且其必须恰好位于发射器前的方块内。

当龙首戴在玩家头上时，龙首的纹理将会覆盖玩家头部的第二层纹理。

# = 伪装 =
[多人游戏](多人游戏.md)中，穿戴龙首的玩家不会在[定位栏](定位栏.md)上显示。

穿戴龙首的玩家不会出现在其他玩家的定位器[地图](地图.md)上。
