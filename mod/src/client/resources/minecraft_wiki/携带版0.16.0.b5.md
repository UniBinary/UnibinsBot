# 携带版0.16.0.b5

*页面ID: 25561* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.16.0 alpha build 5**<ref>https://bugs.mojang.com/browse/MCPE/fixforversion/15713</ref>（也被称为**0.15.90.8**）是[v0.16.0 alpha](携带版0.16.0.md)的第5个测试版，加入了新的[命令](命令.md)、[纹理包](纹理包.md)和[皮肤包](皮肤包.md)，并修复了一些漏洞。

# 新内容
* 新命令：
* 加入了[流浪者](流浪者.md)，[尸壳](尸壳.md)和[矿车](矿车.md)的声音。
* 加入在[0.15.9](携带版Alpha 0.15.9.md)和[0.15.8](携带版Alpha 0.15.8.md)加入的[纹理包](纹理包.md)。
* 加入在0.15.9加入的MineCon[皮肤包](皮肤包.md)。
* 加入[远古守卫者](远古守卫者.md)的[刷怪蛋](刷怪蛋.md)到[创造模式物品栏](创造模式物品栏.md)。
* * 加入远古守卫者刷怪蛋的[纹理](纹理.md)以替代之前的空刷怪蛋。
* 加入了一个新按钮，当你[潜行](潜行.md)并指向一个[村民](村民.md)时显示。

# 更改
* Add-ons现在被称为“行为包”。
* 为一些设置按钮加入了颜色。
* 重新加入了[build 1](携带版0.16.0.b1.md)里被删去的[旧世界类型](旧世界类型.md)。
