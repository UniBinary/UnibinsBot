# 动作栏

*页面ID: 113716* | *来源: Minecraft Wiki*

[thumb|right|动作栏显示正在播放的曲目，位于物品名称文本的上方](File:JukeboxActionbar.png.md)
* *动作栏（Actionbar）**是玩家屏幕中下方的一个文本区域。

# 机制
当玩家进行某些操作时，一段提示性文字会叠加在玩家的视野上，大约3秒后淡出。此时长无法通过[选项](选项.md)修改，也不会受中的“”选项影响。

游戏界面只能显示1个动作栏消息，当有新的动作栏内容时，原先的消息会被新的内容覆盖。

动作栏文本没有背景；动作栏文本带有黑色背景，设置中的“”滑块允许玩家修改背景的不透明度。

# = 命令 =

玩家可以使用<code>/title <targets> actionbar <title></code>命令使动作栏显示指定文本。
