# Mojira管理者披风

*页面ID: 187481* | *来源: Minecraft Wiki*

* *Mojira管理员披风（Moderator Cape）**是授予[漏洞追踪器](漏洞追踪器.md)（Mojira）管理员的披风。

# 描述
该披风在2014年12月25日被授予了漏洞追踪器的管理员。2016年5月9日起再次颁发。
