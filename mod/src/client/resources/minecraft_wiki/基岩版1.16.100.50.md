# 基岩版1.16.100.50

*页面ID: 67545* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.100.50**是[基岩版1.16.100](基岩版1.16.100.md)的首个测试版<ref></ref>，发布于2020年7月30日<ref></ref>，更改了成就界面，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[成就](成就.md)**
* 加入了一个新的成就详情界面。
* * 该功能在多次试行后已可用。<ref name="achievementrollout1"></ref>

* *[设置](设置.md)**
* 在设置页面上添加了Noto Sans字体许可证按钮和弹出式对话框。

# 更改
# = 物品 =
* *[摄像机](摄像机.md)**
* 再一次可通过命令获得。

* *[下界砖](下界砖.md)**
* 现在可以作为[熔炉](熔炉.md)、[高炉](高炉.md)和[烟熏炉](烟熏炉.md)的燃料。<ref></ref>

# = 常规 =
[thumb|400px|新的成就UI界面](File:AchievementsMenuBE116.png.md)
* *[成就](成就.md)**
* 更改了UI<ref></ref>
* * 该功能在多次试行后已可用。<ref name="achievementrollout1"/>

* *地图制作和[附加包](附加包.md)**
* 目标现在为数据驱动。
* 物理组件的现在可以用于决定生物是否受水流重力影响，即使是相对应的导-{}-航组件不存在。
* 末地水晶不能被推动了。
* 鱿鱼的渲染现在由数据驱动。
* 矿车现在由数据驱动，矿车的可骑乘组件、运输矿车、漏斗矿车、命令方块矿车和TNT矿车亦然。

# 修复
* *常规**
* 自定义名称现在可以修改Boss栏了。（）
* 修复了简体中文和繁体中文的系统语言设置被游戏忽视的漏洞。
* Nintendo Switch已经可以正常向Realms上传世界了。（）
* * 此项修复还处Beta阶段，所以还没有应用到Realms和没有Beta测试的平台。
* 玩家重新加入多人游戏后，游戏不会再因为玩家打开自己脚下的潜影盒而崩溃了。
* 修复了部分墙在世界加载后没有正常连接的问题。
* 钓鱼竿现在可以正常地在其他生物附近抛掷了。（）
* 修复了方块选取框位置高出方块的问题。
* 修复了破坏竹子时动画缺失的问题。
* 在档案的设置界面添加了Noto Sans字体授权协议按钮与对话框。

* *图形**
* 修复了部分Windows 10设备上City Living世界中有关玻璃方块的一项图形漏洞。
* 修复了部分设备上Skybox Background图形渲染异常的问题。</onlyinclude>
