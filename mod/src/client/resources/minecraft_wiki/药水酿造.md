* *药水酿造（Brewing）**是在[酿造台](酿造台.md)中往水瓶里加入各种材料而制作[药水](药水.md)、[喷溅药水](喷溅药水.md)和[滞留药水](滞留药水.md)的过程。

# 酿造药水
|原版酿造台UI}}
|在本Wiki中大部分条目使用以上表示酿造配方。<br>箭头左侧的是输入，右侧是输出。}}

将1-3个水瓶或药水放入酿造台界面底部的药水槽中，将材料放入顶部的材料槽中，再在燃料槽里放置烈焰粉，便可开始酿造。

药水的酿造一般从水瓶开始，水瓶可以用[玻璃瓶](玻璃瓶.md)从[水源](水源.md)或[炼药锅](炼药锅.md)里盛水获得。在酿造台具有能量的前提下，添加基础材料来制作基础药水，这一步的产物大部分不具有效果（一般情况下，需要在这一步使用[下界疣](下界疣.md)制作[粗制的药水](粗制的药水.md)）。在此基础上，继续放入影响材料，可以制作出效果药水。继续向具有效果的药水中添加改性剂，可以使药水效果增强、变得更加持久或是腐化现有的效果。

加入[火药](火药.md)，可以将药水转化成喷溅药水，使药水可以投掷（或被[发射器](发射器.md)发射），造成范围效果。还可以对喷溅药水加入[龙息](龙息.md)，将药水转化成滞留药水，使药水投掷后产生一片[区域效果云](区域效果云.md)。

每次酿造耗时总是20秒，与材料种类无关。

酿造需要能量才能进行，在燃料槽放入[烈焰粉](烈焰粉.md)可以为酿造台增加能量，每份烈焰粉使酿造台增加20点能量，即可以进行20次酿造。酿造需要消耗1点能量才能开始，材料被取出等原因导致酿造终止时，消耗的能量不会返还。只有酿造过程结束之后才会消耗能量，中途取出酿造材料不会损失能量。

# 材料
# = 基础材料与改性剂 =
基础材料是直接加入水瓶的材料，是所有药水的起点。[下界疣](下界疣.md)是此阶段的最基本材料，需要用它来制作绝大多数的药水。

改性剂是用来改变药水属性或是使药水效果相反的材料。发酵蛛眼是唯一可以直接酿造成有效药水的改性剂。

* *腐化效果**：发酵蛛眼会改变药水的基本效果，通常会产生与原效果相反的负面效果。
* 腐化药水通常与原药水效果相反。
* 腐化支持相同改性剂的延长版或增强版的药水会得到带有相同改性效果的药水。
* 腐化延长版的剧毒药水只会让其变成普通版的伤害药水，增强版的跳跃药水和迅捷药水不能腐化。
* 隐身药水是夜视药水的腐化版本。也就是说，它将夜视药水“外界于你的可视度变到最高”的效果反转成“你于外界的可见度变为零”，即：隐身。

* *喷溅**和**滞留**药水：任何药水都可以变为喷溅药水或滞留药水，后者是长时间滞留的药水。
* 喷溅药水和滞留药水都可以像它们的普通药水一样改性。例如，喷溅的水瓶可以加入任何基础材料，得到的依然是喷溅药水。
* 喷溅药水和可饮用版本的持续时间相同。
* 滞留药水的持续时间只有可饮用版本的四分之一。例如，8:00的可饮用药水变为滞留药水后只有2:00。

# = 影响材料 =
影响材料将给予粗制的药水一个特定效果，但不会改变药水强度和时间。
若直接加入到水瓶中，任何这些材料都只会造出无效果的药水（[河豚](河豚.md)、[金胡萝卜](金胡萝卜.md)、[海龟壳](海龟壳.md)、[幻翼膜](幻翼膜.md)除外，它们不能加入到水瓶中来制造药水）。

# = 元素 =

某些[元素](元素.md)可以作为酿造材料制作出能够去除特定负面状态的[药物](药物.md)。

# 酿造配方
# = 基础药水 =
基础药水是没有效果的药水。水瓶以外的所有基础药水都是在水瓶里加入单个材料制作而来的。

长久平凡药水无法制作，只能通过命令或[创造模式物品栏](创造模式物品栏.md)获得，但其能够用于酿造虚弱药水。

# = 效果药水 =
效果药水通过将单个材料加入粗制的药水酿造而来（虚弱药水除外），可以和[火药](火药.md)结合以制造其对应的喷溅药水。然而，某些药水需要使用[发酵蛛眼](发酵蛛眼.md)腐化其他药水来得到。

[药物](药物.md)可由粗制的药水加入不同的[元素](#元素.md)酿造成，使用后可以去除特定的效果。药物不是药水，因此没有喷溅、滞留、增强、延长的版本。

# 你知道吗
* 3个药水槽里只要有1个放有药水瓶，酿造过程就会继续，且可以继续放入药水瓶。然而，若移走酿造材料或清空药水槽，那么酿造过程就会终止。
* 使用红石粉来升级没有持续时间的药水（瞬间治疗，瞬间伤害）没有任何作用。
* 虽然Jeb说过在[Beta 1.9-pre3](Java版Beta 1.9-pre3.md)里有161种药水组合而将来会有2,653种，但实际不使用外部程序的话只有22种不同的药水。这些药水中的其中19种各有8种不同效果。
* 喷溅药水能够用发射器发射并且可以激活木质压力板。
* [亡灵生物](亡灵生物.md)不受剧毒药水和再生药水的影响，但会受治疗药水的伤害，并从伤害药水中获得治疗，同时会受衰变药水的凋零效果影响。
* 衰变药水只有II级形式。
