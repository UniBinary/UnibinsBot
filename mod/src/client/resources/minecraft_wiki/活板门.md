# 用途

# = 性质 =
要放置一个活板门，对选定的位置一个活板门物品。放置后，它依靠的方块可以被移除。

活板门被放置后会占用一个方块的顶部或底部，具体情况取决于玩家放置活板门的位置。若活板门被放置在方块顶部，它会向下开启。若被放置在方块底部，它会向上开启。

活板门可以被[活塞](活塞.md)移动。[水](水.md)和[熔岩](熔岩.md)流动时会绕过活板门。含水活板门中的水如同一个水源一样，向四周和下方流出，不会从活板门阻挡的那一面流出。

若一个开启的活板门下方有一个梯子且与梯子在同一面，这个活板门可以像梯子一样被攀爬。

活板门在关闭时，其[判定箱](判定箱.md)的上（顶部活板门）或下（底部活板门）表面完整，因此某些方块可以放在其上方或下方。活板门打开时，则无法放置。例如，可以将灯笼放在关闭的活板门的顶部和下方。活板门打开时其打开方向的判定箱表面完整。活板门开闭时发出[PP更新](PP更新.md)，使依附原完整表面的绝大多数方块掉落。

与大多数[生物](生物.md)的声音类似，开启和关闭活板门的声音最远可以在16格内听到。

# = 障碍 =
活板门是一种可开关的障碍，能阻挡[实体](实体.md)运动。除了用于阻挡[玩家](玩家.md)和生物移动，活板门也可以用于阻挡[船](船.md)、[物品](物品（实体）.md)和[矿车](矿车.md)等实体的运动。

活板门的厚度为）格}}或）格}}。在其余的空间，活板门不会阻挡实体运动。

活板门能够在生物阻挡的情况下被开启或关闭。<ref></ref>开关活板门不会对方块空间中的任何除玩家以外的实体造成影响。站在地面上同时关闭地面上方的一个活板门，会导致玩家进入[爬行](爬行.md)的状态。

生物的寻路系统会将活板门视为关闭的，不管它是不是真的关闭了。这经常会导致生物从开启的活板门处掉下去。<ref></ref>

生物无法生成在活板门上。

# = 红石元件 =
活板门可使用红石信号控制。

活板门是[机械元件](红石元件#机械元件.md)，可被下列形式激活：
* 毗邻的开启的**[电源](红石元件#电源元件.md)**（例外：[红石火把](红石火把.md)不会激活其所附着的活板门，[侦测器](侦测器.md)只会激活指向的活板门）
* 毗邻的**[充能方块](红石电路/充能与激活.md)**
* 毗邻的指向活板门且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)（包括活板门上方的红石粉）；毗邻但未指向活板门的红石粉不会激活活板门

在同一红石刻内，电容器更新阶段前存在，但在电容器更新阶段被取消的信号无法激活活板门。

活板门被红石信号激活（收到上升沿）后会立刻绕着它的“合叶”“旋转”变为开启状态；取消激活（收到下降沿）后活板门会立即回到关闭状态。
