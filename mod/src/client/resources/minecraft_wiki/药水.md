* *药水（Potion）**为可[酿造](酿造.md)的[物品](物品.md)，使用后会给使用-{}-者一些特殊的、有时间限制的[状态效果](状态效果.md)。

# 获取
# = 酿造 =

几乎所有药水能通过以水瓶作为基础的[酿造](酿造.md)获得。

、无法通过酿造获得，只能通过命令或[创造模式物品栏](创造模式物品栏.md)获得。

# = 女巫 =
若[女巫](女巫.md)在饮用治疗药水、抗火药水、迅捷药水或水肺药水时被杀死，该药水有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率作为装备掉落物掉落。

# = 流浪商人 =
若[流浪商人](流浪商人.md)在饮用隐身药水时被杀死，该药水有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率作为装备掉落物掉落。

流浪商人有概率以5个[绿宝石](绿宝石.md)的价格出售1瓶隐身药水。

# = 钓鱼 =
[钓鱼](钓鱼.md)时水瓶可作为垃圾被钓上来。

# = 装满玻璃瓶 =
手持[玻璃瓶](玻璃瓶.md)对着、水源或者装有水的[炼药锅](炼药锅.md)按键会获得一个水瓶。使用玻璃瓶来装炼药锅内的药水会使它变成对应药水。如果使用炼药锅来装满水瓶，炼药锅的水会减少。

# = 自然生成 =
两瓶瞬间治疗II药水能够在[末地船](末地船.md)舱室中的[酿造台](酿造台.md)里获得。

[沼泽小屋](沼泽小屋.md)内的炼药锅随机装着一种除衰变药水以外的药水。

# = 箱子战利品 =

由于药水的最大堆叠数量为1，数量大于1的堆叠会被展开为对应数量的单个物品堆叠。

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家1个水瓶，有的概率给予玩家1瓶抗火药水。

# 用途
药水像[食物](食物.md)一样，能通过长按键使用。使用后，玩家会获得相应的[状态效果](状态效果.md)，并返还空[玻璃瓶](玻璃瓶.md)。

# = 改性 =

药水酿造配方表（最有效率的配方）}}
改性是改变药水的属性或是使药水效果相反的方式，药水有五种改性方式：

* 加入[荧石粉](荧石粉.md)来增强药水效果（得到对应的二级药水）；
* 加入[红石粉](红石粉.md)来延长效果持续时间；
* 加入[火药](火药.md)来制作[喷溅药水](喷溅药水.md)；
* 向喷溅药水加入[龙息](龙息.md)来制作[滞留药水](滞留药水.md)；
* 加入[发酵蛛眼](发酵蛛眼.md)会产生腐化效果，改变药水的基本性状。

腐化的结果通常是得到原效果的相反效果，如[迅捷](迅捷.md)变成[](缓慢.md)，但也有例外，如[夜视](夜视.md)变为[隐身](隐身.md)而非相反效果[失明](失明.md)。

产生腐化后，除伤害药水外的延长版药水都能保留其原有时间。增强版的药水会保留效果等级，而增强版的跳跃药水和迅捷药水不能被腐化。

# = 基础药水 =
基础药水是在酿造主要药水前首先要制作的药水。所有基础药水在饮用时均无任何效果。

# = 填充炼药锅 =
对[炼药锅](炼药锅.md)水瓶或可使炼药锅提升或药水位，同时把手持的水瓶或药水变为玻璃瓶。如果炼药锅盛有[状态效果](状态效果.md)、效果等级与该药水不同的药水，或是其他物质，进行此操作则会导致炼药锅被清空，并产生爆炸的音效和粒子。

# = 和泥 =
对[泥土](泥土.md)、[缠根泥土](缠根泥土.md)或[砂土](砂土.md)水瓶可使其转变为[泥巴](泥巴.md)，并返还空玻璃瓶，使用[发射器](发射器.md)发射水瓶也能生效。

# 你知道吗
* 如果正在一个药水的作用时间内时再饮用一瓶相同的药水，药水效果持续时间不会叠加，只会重置。
* 在高级效果作用时间内饮用低级效果的药水不会有任何变化。例如，玩家先饮用迅捷II药水，紧接着饮用迅捷I药水，仍会获得迅捷II药水效果，相当于浪费了迅捷I药水。
* 伤害药水III可以造成伤害，足以瞬间杀死玩家。
* 饮用完一瓶药水后马上切换到另一瓶能够让[玩家](玩家.md)迅速饮用这两瓶药水，但是饮用第二瓶药水的动作不会显示出来。
* 药水的效果标签如果缺失或者无效，该药水会变成水瓶。
* 喷溅型药水的持续时长与同类普通药水的持续时长相同。
