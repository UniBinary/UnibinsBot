# 启动器1.3.4

*页面ID: 50775* | *来源: Minecraft Wiki*

* *1.3.4**是一个2013年11月26日发布的一个[启动器](启动器.md)的小更新。

# 更改
* 能够更快地下载某些大文件了。

# 修复
*  - 启动器在离线状态下会尝试在代理连接处于活跃状态时下载文件。
