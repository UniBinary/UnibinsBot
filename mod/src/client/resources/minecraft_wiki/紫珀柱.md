# 紫珀柱

*页面ID: 163388* | *来源: Minecraft Wiki*

* *紫珀柱（Purpur Pillar）**是一种自然生成于[末地城](末地城.md)与[末地船](末地船.md)中的装饰性方块。

# 生成
# = 自然生成 =
紫珀柱可以在[末地](末地.md)的[末地城](末地城.md)与[末地船](末地船.md)结构中被找到。

# 破坏
挖掘紫珀柱的合适工具是镐。紫珀柱需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

紫珀柱被破坏后会掉落自身。
