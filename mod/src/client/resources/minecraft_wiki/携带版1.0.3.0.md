# 携带版1.0.3.0

*页面ID: 27292* | *来源: Minecraft Wiki*

<onlyinclude>

* *alpha 1.0.3.0**是[1.0.3](携带版1.0.3.md)的测试版，发布于2017年2月1日<ref></ref>，加入了荷兰语、多人游戏的服务器移动包，并修复了一些漏洞。<ref></ref>

# 新内容
# = 常规 =
* *[语言](语言.md)**
* 支持荷兰语。<ref></ref><ref></ref>

* *[多人游戏](多人游戏.md)**
* 为[服务器](服务器.md)加入了移动包（TransferPacket），允许将玩家移动到另一个服务器。<ref></ref><ref></ref>
* 服务器现在可以检测到客户端的一些有用数据。<ref></ref>

# 修复
* *修复了16个漏洞**
*  - 侦测器的顶部纹理总是朝着北。
*  - 不会显示外部服务器的活动状态。
* 服务器的活动状态总是会在离线和在线之间切换。
* 玩家离开导致Realms世界崩溃。
* 使用相同的物品时游戏崩溃。
* 玩家进入生物群系变种时使得服务器崩溃。
* 压力板、按钮和其他红石元件无法更新。
* 漏斗的方块刻不会运作。
* 破坏门时出现问题。
* 可以复制物品。
* 玩家可以获得末地传送门方块。
* 侦测器的箭头不会指示正确的方块。
* 侦测器可以颠倒放置。
* Realms世界里不会显示非好友玩家。
* 蝙蝠不会经常生成。
* 移动端里的末地折跃门方块渲染出错。</onlyinclude>
