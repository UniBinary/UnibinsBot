# 蜘蛛网

*页面ID: 6019* | *来源: Minecraft Wiki*

* *蜘蛛网（Cobweb）**是一种可以减慢[实体](实体.md)移动速度的方块。

# 生成
# = 自然生成 =
蜘蛛网会自然生成在[要塞](要塞.md)的图书馆、[雪屋](雪屋.md)地下室、[僵尸村庄](僵尸村庄.md)、[废弃矿井](废弃矿井.md)、[林地府邸](林地府邸.md)的蜘蛛房间中以及[试炼密室](试炼密室.md)中生成[蜘蛛](蜘蛛.md)和[洞穴蜘蛛](洞穴蜘蛛.md)的[试炼刷怪笼](试炼刷怪笼.md)旁。

# = 人为生成 =
拥有[盘丝](盘丝.md)状态效果的生物死亡后会在以自身为中心3×3×3的范围内尝试生成2-3个蜘蛛网，且只能生成在上表面完整的方块上。

# 获取
蜘蛛网只能通过破坏蜘蛛网获得。

# 破坏
挖掘蜘蛛网的合适工具是剪刀和剑。蜘蛛网需要剪刀或剑来挖掘，否则挖掘时间将延长且不会掉落。

没有被剪刀或具有[精准采集](精准采集.md)的工具挖掘破坏时，蜘蛛网被破坏后会掉落1个[线](线.md)。

被剪刀或具有精准采集的工具挖掘破坏时，蜘蛛网被破坏后会掉落自身。

# 用途
生物能生成在蜘蛛网内。

当亡灵生物在蜘蛛网里时，它们不会因阳光而燃烧。

蜘蛛网也会使太阳光扩散。

[方块](方块.md)能放在蜘蛛网上，包括[告示牌](告示牌.md)和[画](画.md)。

蜘蛛网会被液体冲毁。

# = 酿造材料 =

# = 减速 =
蜘蛛网可以使绝大多数实体减速，阻止实体受到摔落伤害。蜘蛛和洞穴蜘蛛不会被蜘蛛网减慢速度，[箭](箭.md)等弹射物会直接穿过蜘蛛网而不会被减慢速度。

进入蜘蛛网后实体的移动能力会受到削弱。当玩家在蜘蛛网里行走或[疾跑](疾跑.md)时，玩家的速度会被降低至0.490格/秒或0.637格/秒，未触及地面时水平移动速度进一步降低至0.098格/秒或0.127格/秒。降落速度约为0.078格/秒并保持不变。[黏液块](黏液块.md)和[冰](冰.md)的减速效果可与蜘蛛网的减速效果叠加生效。

拥有[盘丝](盘丝.md)状态效果且会被蜘蛛网减速的生物会以正常速度的50%而不是25%穿过蜘蛛网。

蜘蛛网会限制玩家[跳跃](跳跃.md)，效果等同于处于2米高的窄小空间中。

处在[旁观模式](旁观模式.md)中或[飞行](飞行.md)状态下的[创造模式](创造模式.md)中的玩家不会受蜘蛛网的影响。

[缩略图|双蜘蛛网延时器，延时大概一分钟](File:Cobweb delay.png.md)
在[红石电路](红石电路.md)中，蜘蛛网可作为延时器，掉落物约24秒才能自上而下穿过一个蜘蛛网。
