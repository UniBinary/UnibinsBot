# 携带版0.2.2

*页面ID: 35250* | *来源: Minecraft Wiki*

* *v0.2.2 alpha**是[携带版](携带版.md)的一次次要更新，发布于2012年3月17日<ref name=:0">http://web.archive.org/web/20120422112628/https://play.google.com/store/apps/details?id=com.mojang.minecraftpe</ref>，修复了一些漏洞。此次更新仅发布于Android平台。

# 修复
* 修复了游戏在某些设备上无法正确打开的漏洞。
* 修复了发生在Acer Iconia A500平板上的一个漏洞。

# 内部版本
v0.2.2 alpha的内部版本号为0.2.2(2025)，大小为2.83MB。
