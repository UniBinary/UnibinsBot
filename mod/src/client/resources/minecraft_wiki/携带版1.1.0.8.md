# 携带版1.1.0.8

*页面ID: 29455* | *来源: Minecraft Wiki*

<onlyinclude>

* *alpha 1.1.0.8**是[1.1.0](携带版1.1.0.md)的第6个测试版，发布于2017年4月21日<ref></ref>，修复了一些漏洞。

# 修复
* *修复了5个漏洞**
* 烟雾和水粒子飞行速度太快。
* 敌对生物不能近战攻击骑乘着生物的玩家。
* 在全局资源包或资源包选项卡里下载资源包时游戏崩溃。
* 访问Xbox Live时游戏崩溃。
* 对着末影人投掷隐身药水时，末影人手持的方块会消失。</onlyinclude>
