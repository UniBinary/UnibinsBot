# 熟羊肉

*页面ID: 12707* | *来源: Minecraft Wiki*

* *熟羊肉（Cooked Mutton）**是一种用[生羊肉](生羊肉.md)烹饪而成的[食物](食物.md)。

# 获取
# = 绵羊 =

# = 烹饪 =
熟羊肉可以通过在[熔炉](熔炉.md)、[营火](营火.md)或[烟熏炉](烟熏炉.md)中烹饪[生羊肉](生羊肉.md)获得。

# = 礼物 =

[屠夫](屠夫.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷熟羊肉。

# 用途
# = 食物 =

手持熟羊肉按住键即可食用，每个熟羊肉可以回复。

# = 狼 =
熟羊肉能用来吸引、繁殖或治疗驯服的[狼](狼.md)，也可以使已驯服的幼年狼的剩余生长时间加快10%。
