# Java版13w06a

*页面ID: 33493* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w06a**是[Java版1.5](Java版1.5.md)的第9个快照，发布于2013年2月7日<ref></ref>，加入了刷怪笼矿车，并修复了一些漏洞。

# 新内容
# = 非生物实体 =
* *[刷怪笼矿车](刷怪笼矿车.md)**
* NBT与普通刷怪笼完全相同。
* 不可正常获得，只能通过外部编辑器作为实体生成。

# 更改
# = 常规 =
* *[光照](光照.md)**
* 光照优化。

# 修复
命令的死亡消息错误。
