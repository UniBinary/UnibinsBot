* *1.18-exp2（1.18 experimental snapshot 2）**是[Java版1.18](Java版1.18.md)的第2个实验性快照，发布于2021年7月20日<ref></ref><ref></ref>，对[主世界](主世界.md)地形和多个[生物群系](生物群系.md)的生成进行了调整，并更改了[刷怪笼](刷怪笼.md)生成生物的亮度限制。此版本单独发布，故不出现在[启动器](启动器.md)版本列表中。

# 新内容
# = 常规 =
* *[方块实体数据格式](方块实体数据格式.md)**
* 为[刷怪笼](刷怪笼.md)加入了标签，允许覆写刷怪笼的常规刷怪规则。
* * 此标签中的值指定刷怪笼能刷怪的最高方块光照等级。

# 更改
# = 生物 =
* *常规**
* 现在[僵尸](僵尸.md)、[骷髅](骷髅.md)、[蜘蛛](蜘蛛.md)和[洞穴蜘蛛](洞穴蜘蛛.md)的[刷怪笼](刷怪笼.md)会在[方块光照](方块光照.md)等级不高于11的区域刷怪。

# = 世界生成 =
* *[沙滩](沙滩.md)及其变种**
* 现在总体上更加宽阔。
* 现在陆地与海洋的交界处有概率不生成沙滩及其变种。

* *[沼泽](沼泽.md)、[风蚀恶地](风蚀恶地.md)、[冰刺之地](冰刺之地.md)和[热带高原](热带高原.md)**
* 现在又能自然生成了。

* *旧山地**
* 将[山地](山地.md)重命名为“峭壁”（Extreme Hills）。
* 将[沙砾山地](沙砾山地.md)重命名为“沙砾丘陵”（Gravelly Hills）。

* *新山地**
* 现在常规敌对生物会在此生成。
* 现在[绿宝石矿石](绿宝石矿石.md)和[虫蚀石头](虫蚀石头.md)会在此生成。

* *[草甸](草甸.md)**
* 现在[绵羊](绵羊.md)会在此生成。
* 提高了[兔子](兔子.md)的生成频率。
* 降低了[驴](驴.md)的生成频率。
* 现在会罕见地生成[橡树](橡树.md)或[桦树](桦树.md)，有时带有[蜂巢](蜂巢（方块）.md)。
* [兰花](兰花.md)不再能在此地生成。

* *[繁茂洞穴](繁茂洞穴.md)**
* 现在会略微罕见地生成，且规模更小。

* *[矿脉](矿脉.md)**
* 现在会略微频繁地生成，且规模更大。

* *常规**
* 现在[生物群系](生物群系.md)生成得更加平滑，并且不再那么复杂而分散。
* 略微提高了大面积的平坦地形生成的可能性。
* 现在地下生物群系不会大幅干涉地表生物群系。
* 现在[尖峭山峰](尖峭山峰.md)和[冰封山峰](冰封山峰.md)生物群系可以罕见地在大约Y=260处到达顶峰。
* 现在[结构](结构.md)会生成在正确的群系中。
* 降低了[噪声洞穴](噪声洞穴.md)从地表延伸至[深板岩](深板岩.md)层的可能性。
* 减小了[芝士洞穴](芝士洞穴.md)的尺寸，并降低了其与地表相交的可能性。
* 降低了[沙子](沙子.md)和[沙砾](沙砾.md)生成时浮空的可能性。
* * 现在部分已被[砂岩](砂岩.md)或[石头](石头.md)替代。

# = 常规 =
* *[云](云.md)**
* 将高度从Y=128提高到Y=192。</onlyinclude>
