# 紫颂植株

*页面ID: 17575* | *来源: Minecraft Wiki*

* *紫颂植株（Chorus Plant）**是一种自然生成于[末地](末地.md)的方块。它们可以用[紫颂花](紫颂花.md)来种植。

# 生成
# = 自然生成 =
紫颂植株在末地外岛上作为[紫颂树](紫颂树.md)的“枝干”生成。

# = 紫颂花 =
[紫颂花](紫颂花.md)生长时会生成紫颂植株。

# 获取

紫颂植株无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，紫颂植株可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
挖掘紫颂植株的合适工具是斧和剑。

紫颂植株被破坏后会掉落0-1个[紫颂果](紫颂果.md)。

# 用途
# = 支撑 =
如果六个相邻的方块不符合以下要求，则紫颂植株方块会自动破坏（有可能会掉落紫颂果）：
* 除非至少有一个垂直相邻的方块是空气，否则如果至少有一个其他紫颂植株水平相邻则会自动破坏。
* 除非下面是紫颂植株或末地石，或者与一个在下方是紫颂植株或[末地石](末地石.md)的紫颂植株水平连接，否则紫颂植株也会被自动破坏。
