# Java版15w44a

*页面ID: 18847* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w44a**是[Java版1.9](Java版1.9.md)的第37个快照，发布于2015年10月28日<ref></ref>，加入了末地水晶，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[末地水晶](末地水晶.md)**
* 当玩家杀死[骷髅马](骷髅马.md)或[僵尸马](僵尸马.md)时掉落。
* 只能在[黑曜石](黑曜石.md)和[基岩](基岩.md)上放置。
* 没有底座。
* 用于在末地传送门处重生[末影龙](末影龙.md)。
* 不会被爆炸摧毁（[凋灵](凋灵.md)除外）。

# 更改
# = 方块 =
* *[炼药锅](炼药锅.md)**
* 现在铁桶能从满的炼药锅取水。

# = 物品 =
* *[金苹果](金苹果.md)**
* 普通金苹果现在提供了生命恢复II（在[15w37a](15w37a.md)中为生命恢复I）。
* [附魔金苹果](附魔金苹果.md)不能再被合成。
* * 成就“”不再可获得。Dinnerbone表示此成就将改为“获取型”而非“合成型”以作为修复。<ref></ref>

# = 生物 =
* *[末影龙](末影龙.md)**
* 更改了重生的机制。
* * 要重新生成末影龙，需要在[返回传送门](返回传送门.md)的每一边上放置一个[末地水晶](末地水晶.md)。
* * 在此版本，末地水晶放在返回传送门每一边上的三个方块中的其中一个都能重新生成末影龙。
* * 在重生的时候，这些水晶会发射出光束，并把所有黑曜石柱重置，重置完毕后水晶会爆炸并且生成末影龙。
* * 不再可以通过使用[黏土](黏土.md)制作[苦力怕](苦力怕.md)形状图案来重新生成末影龙。

# = 世界生成 =
* *[珍异橡树](珍异橡树.md)**
* 现在再次可以在森林生物群系中生成。

* *[雪屋](雪屋.md)**
* 雪屋地下室一角的红地毯隐藏了一个磨制[安山岩](安山岩.md)。
* 告示牌的箭头恢复回原来它们最初的样子。

  * 现在：

# = 命令格式 =
* *NBT标签**
* 末地水晶
* * <code>ShowBottom</code>（布尔值）是否显示末地水晶底座，包括末地水晶所站在的方块。

# = 游戏内容 =
* *[饥饿](饥饿.md)**
* 加入了饱和度，会代替饥饿值被消耗。

* *[魔咒](魔咒.md)**
* [经验修补](经验修补.md)的[修正附魔等级范围](魔咒#魔咒属性.md)从40–90改为25–75。

# = 常规 =
* *[战利品表](战利品表.md)**
* 新的“enchant_randomly”和“set_attributes”功能。
* 废弃矿井、沙漠神殿、地牢中的箱子和奖励箱从多个池子放置战利品，以及物品重新平衡。奖励池里的价值更高的物品将先于价值更低的物品出现。
* * 鞍和铁马铠从[废弃矿井](废弃矿井.md)箱子移除；命名牌、附魔及普通金苹果，火把以及充能、探测、激活铁轨增加。
* * [沙漠神殿](沙漠神殿.md)的箱子里添加了蜘蛛眼、火药、线、沙子和金苹果。
* * [奖励箱](奖励箱.md)里添加了鲑鱼。这个箱子里经常有一把斧，一支镐，一些食物还有木质工具。木棍和木板现在更多了。
* * [地牢](地牢.md)箱子里加入了骨头、腐肉、金锭、煤炭、附魔金苹果、西瓜、南瓜和甜菜种子。

* *效果栏**
* 屏幕顶端的“效果栏”会正确地对待隐藏和环境效果。
