# Java版标签/画变种

*页面ID: 161618* | *来源: Minecraft Wiki*

* *画变种标签（Painting Variant Tags）**是[画变种](画变种定义格式.md)的组合。

# 使用
画变种标签不可被主动调用，它们被游戏用来控制创造模式物品栏中提供的画变种。

# 当前版本

# = placeable =
* 可由未在其物品堆叠组件中指定特定画变种的[画](画.md)物品随机放置出的画变种。
* 已注册且会在[创造模式物品栏](创造模式物品栏.md)的“功能方块”标签页中出现的画变种。
* 已注册但不在创造模式物品栏的“管理员用品”标签页中出现的画变种。
