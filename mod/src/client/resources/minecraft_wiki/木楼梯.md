# 生成
红树木楼梯、樱花木楼梯、苍白橡木楼梯、竹楼梯、绯红木楼梯、诡异木楼梯不会生成在世界中。

# = 自然生成 =
云杉木楼梯会自然生成于[沼泽小屋](沼泽小屋.md)和[雪屋](雪屋.md)中。

橡木、深色橡木和白桦木楼梯会自然生成于[林地府邸](林地府邸.md)中。

橡木、白桦木、云杉木、丛林木、及深色橡木楼梯都能在[沉船](沉船.md)中自然生成。

深色橡木楼梯可以在[掠夺者前哨站](掠夺者前哨站.md)中生成。

橡木楼梯会自然生成于平原[村庄](村庄.md)，金合欢木楼梯会自然生成于热带草原村庄，云杉楼梯会自然生成于雪原、针叶林和积雪针叶林村庄。

# 破坏
挖掘木楼梯的合适工具是斧。

木楼梯被破坏后会掉落自身。

# 用途

# = 燃料 =
主世界木楼梯可被用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个木楼梯可烧炼1.5个物品。
