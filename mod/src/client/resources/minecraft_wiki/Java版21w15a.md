* *21w15a**是[Java版1.17](Java版1.17.md)的第17个快照，发布于2021年4月14日<ref></ref>，加入了粗金属块、[标记](标记.md)和新的音效，更新了命令以及一些特性，修复了一些漏洞，并且将先前快照中关于世界生成的大多数更改（例如高度限制和新洞穴类型）回退并整合到一个[单独的数据包](洞穴与山崖预览数据包.md)中。由于技术问题以及COVID-19疫情对开发者的影响，这些更改被安排到了2021年年底<ref></ref>。

# 新内容
# = 方块 =
* *[粗金属块](粗金属块.md)**
* 加入了[粗铁块](粗铁块.md)、[粗铜块](粗铜块.md)和[粗金块](粗金块.md)。
* * 可由对应的9个[粗金属](粗金属.md)合成获得。
* * 可以被拆解为对应的9个粗金属。
* * 不能被[熔炼](熔炼.md)。<ref></ref>
* * [猪灵](猪灵.md)不会捡起粗金块<ref></ref>，也不会与周围挖掘粗金块的玩家敌对<ref></ref>。

# = 非生物实体 =
* *[标记](标记.md)**
* 加入了标记类实体，用于地图制作或数据包的自定义用例。
* * 只存在于服务端，不会发送至客户端。
* * 不进行任何自我更新。
* * 有一个Compound类型的标签，用于储存任何数据。

# = 命令格式 =
* ***
* 新的debug子命令，与命令使用相同的语法。
* * 每个被执行的命令、消息（包括通常不可见的）、结果或错误都会存储在一个文件内。
* * 函数自身无法运行。

# = 声音 =
* *[骨粉](骨粉.md)**
* 为[骨粉](骨粉.md)加入了新的音效与字幕。
* *[山羊](山羊.md)**
* 为[尖叫山羊](山羊#生成.md)加入了新的音效与字幕。

# = 常规 =
* *<samp>[server.properties](server.properties.md)</samp>参数**
* <code>resource-pack-prompt</code>
* * 加入了一条自定义消息，当启用<code>require-resource-pack</code>时，该消息将显示在资源包提示上。
* * 需要使用[JSON文本](JSON文本.md)，可以包含多行。

# 更改
# = 方块 =
* *[金矿石](金矿石.md)、[青金石矿石](青金石矿石.md)、[深层铜矿石](深层铜矿石.md)和[深层青金石矿石](深层青金石矿石.md)**
* 稍微更改了纹理。

# = 物品 =
* *[粗铁](粗铁.md)、[粗铜](粗铜.md)和[粗金](粗金.md)**
* 更改了纹理。

# = 生物 =
* *[美西螈](美西螈.md)**
* 现在在陆地上被[喷溅型水瓶](喷溅型水瓶.md)击中时会获得的额外湿润时间。

* *[山羊](山羊.md)**
* 现在有概率对任何移动的生物及[盔甲架](盔甲架.md)发起冲撞攻击，将其击退。
* * [苦力怕](苦力怕.md)在被山羊冲撞后不会爆炸。
* 现在会避免在[细雪](细雪.md)上行走。

# = 世界生成 =
* *世界[高度](高度.md)限制**
* 主世界的可建筑高度暂时恢复至1.16版本的水平。
* * 此项更改使得在[21w06a](21w06a.md)之前创建的世界再次能够被加载。
* * 此项更改使得在21w06a和[21w14a](21w14a.md)之间版本创建的世界无法被加载。
* ** 通过修改level.dat，并向datapacks文件夹中添加[洞穴与山崖预览数据包](洞穴与山崖预览数据包.md)可以使这些存档重新加载（详见此[教程](Tutorial:强制打开存档.md)）。

* *[洞穴](洞穴.md)**
* 现在[噪声洞穴](噪声洞穴.md)、[含水层](含水层.md)和[裂隙](裂隙.md)不可用了。
* 现在由地形雕刻器生成的洞穴和峡谷仍遵循21w06a前的生成机制。

* *[矿石](矿石.md)分布**
* 除[铜矿石](铜矿石.md)外的矿石分布暂时恢复至1.16版本的水平。
* 铜矿石现在会在主世界Y=0至192的区域自然生成，在Y=96附近最为常见。

* *[深板岩](深板岩.md)和[凝灰岩](凝灰岩.md)**
* 现在仅在主世界Y=0至16的区域呈团簇状生成。

# = 常规 =
* *[菜单屏幕](菜单屏幕.md)**
* 背景更改为[紫晶洞](紫晶洞.md)。

* *[创造模式物品栏](创造模式物品栏.md)**
* 调整了“建筑方块”类别中部分方块的位置。
