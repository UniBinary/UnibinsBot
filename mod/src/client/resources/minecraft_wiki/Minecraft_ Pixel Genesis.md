# Minecraft: Pixel Genesis

*页面ID: 126954* | *来源: Minecraft Wiki*

* **Minecraft: Pixel Genesis***是由[Hyper Potions](Hyper Potions.md)、Synthion、AIKA、leon chang、Snail's House、Elliot Hsu和Anamanaguchi创作的混音专辑，于2024年9月13日在多平台发布。<ref></ref>此专辑是*[Minecraft: Tricky Trials (Original Game Soundtrack)](Minecraft: Tricky Trials (Original Game Soundtrack).md)*中的曲目与*[Infinite Amethyst](Minecraft: Caves & Cliffs (Original Game Soundtrack).md)*的混音版本。专辑封面与动画版本由Martin Wörister制作。<ref></ref>
