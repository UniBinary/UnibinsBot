# Java版Classic 0.0.14a

*页面ID: 34915* | *来源: Minecraft Wiki*

/开发者版本}}
<onlyinclude>

* *0.0.14a**是的一次更新，发布于2009年5月27日<ref name=":0"></ref><ref>["Holy crap new tiles!"](https://forums.tigsource.com/index.php?topic=6273.msg205284#msg205284) – TigSource, May 27, 2009, 15:31:58, UTC&minus;8</ref><ref>[IRC logs](#logs.md): "*(00:26:45) <TheMystic89> seeing a nice number up to the left too*", "*(00:26:54) <Rotab> 0.0.14? =D*" (May 27, 2009, 22:26 UTC)</ref>，加入了[沙子](沙子.md)、[沙砾](沙砾.md)、[矿石](矿石.md)和[树木](树木.md)。

# 新内容
# = 方块 =
* *[沙子](沙子.md)和[沙砾](沙砾.md)**
* 会自然生成在一格厚的海滩上。
* 会受到重力影响。
* * 如果被悬空放置，那么其会立即下落到底。

* *[金矿石](金矿石.md)**
* 在高海拔的水平山脉表面生成。

* *[铁矿石](铁矿石.md)**
* 以巨大的[矿团](矿团.md)生成，有时大到同时在3个洞穴，可以多达167个矿石。

* *[煤矿石](煤矿石.md)**
* 开采后会掉落自身。

* *[原木](原木.md)**
* 作为树木的一部分生成。

* *[树叶](树叶.md)**
* 作为树木的一部分生成。
* 被破坏时，[粒子](粒子.md)以普通速度下落。

# = 世界生成 =
* *[树木](树木.md)**
* 由树叶和原木组成。

* *[世界大小](Indev世界选项#世界大小.md)**
* 加入了世界大小，共有普通型（Normal）、大型（Huge）和小型（Small）三种世界大小，可由[创建新的世界](创建新的世界.md)屏幕控制。
* * 普通型世界面积为256×256。
* * 大型世界世界面积为512×512。
* * 小型世界面积为128×128。

* *常规**
* 新的地形生成器。

# = 游戏内容 =
* *[云](云.md)**
* 加入了云。

* *[迷雾](迷雾.md)**
* 加入了迷雾。

# = 常规 =
* *[控制](控制.md)**
* 支持滚轮选取[方块](方块.md)。
* 按住鼠标可以每0.25秒连续放置或破坏方块了。
* * 只能选择可以通过数字键选择的方块。

* *存档格式**
* 改进了存档格式，现在生物可以被储存在世界数据中。
* * 一个世界中最多可以存在256个[生物](生物.md)。

# 更改
# = 方块 =
* *[木板](木板.md)**
* 更改了纹理。

* *[圆石](圆石.md)**
* 更改了纹理。

* *[水](水.md)**
* 现在流动的速度更快了。<ref></ref>
* 现在可以从世界外流入世界内。
* 现在显示选择放置时的纹理。

# = 常规 =
* *[创建新的世界](创建新的世界.md)**
* 现在可以选择要创建世界的[世界大小](Indev世界选项#世界大小.md)。

* *[控制](控制.md)**
* 玩家在按重生时总是出现在同一地点，除非重生点在水下。<ref>[IRC logs](#logs.md): "*(00:34:59) <Rotab> so you have a fixed spawn point now?*" (May 27, 2009, 22:24 to 22:36 UTC)</ref></onlyinclude>

# 你知道吗
* 0.0.14a中实现的许多特性常常被错误地引用为0.0.14a_01中实现的特性。<ref></ref>
