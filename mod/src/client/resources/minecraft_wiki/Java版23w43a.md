# Java版23w43a

*页面ID: 106510* | *来源: Minecraft Wiki*

<onlyinclude>

* *23w43a**是[Java版1.20.3](Java版1.20.3.md)的第4个快照，发布于2023年10月25日<ref></ref>，加入了命令，更改了蝙蝠的外观，在内置数据包中加入了多种铜制方块和凝灰岩系列方块，并修复了一些漏洞。

# 新内容（实验性）
# = 方块 =
* *[雕纹铜块](雕纹铜块.md)**
* 加入了雕纹铜块，有着X形花纹。
* * 有斑驳、、氧化和它们对应的涂蜡变种。
* * 可以使用2个相同的切制铜台阶合成1个对应的雕纹铜块。
* * 可以使用1个铜块在切石机中切出4个对应的雕纹铜块。

* *[铜格栅](铜格栅.md)**
* 铜质的网状装饰性方块。
* 有斑驳、、氧化和它们对应的涂蜡变种。
* 可以使用4个相同的铜块在合成方格中排成菱形来合成1个对应的铜格栅。
* 可以使用1个铜块在切石机中切出4个对应的铜格栅。

* *[门](门.md)和[活板门](活板门.md)**
* 加入了铜质变种。
* * 有斑驳、和氧化和它们对应的涂蜡变种。
* * 可通过按键开合。

* *[铜灯](铜灯.md)**
* 铜质照明方块。
* 可以使用3个相同的铜块、1个[烈焰棒](烈焰棒.md)和1个[红石粉](红石粉.md)合成4个铜灯。
* 有斑驳、和氧化和它们对应的涂蜡变种。
* 会随着铜的锈蚀而变得暗淡，用[斧](斧.md)除锈可以使之恢复亮度。

* 放置时默认关闭，可以通过输入红石信号进行开关。
* * 不需要红石信号来维持照明，只会在下一次接收到红石信号时改变开关状态。
* 开启时会对[红石比较器](红石比较器.md)输出强度为15的红石信号。

* *[凝灰岩](凝灰岩.md)**
* 加入了磨制凝灰岩、雕纹凝灰岩、凝灰岩砖和雕纹凝灰岩砖。

* *[墙](墙.md)、[楼梯](楼梯.md)和[台阶](台阶.md)**
* 加入了凝灰岩、磨制凝灰岩和凝灰岩砖变种。
