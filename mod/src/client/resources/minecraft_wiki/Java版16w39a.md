# Java版16w39a

*页面ID: 24961* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w39a**是[Java版1.11](Java版1.11.md)的第7个快照，发布于2016年9月28日<ref></ref>，加入了大量[探险更新](探险更新.md)的内容，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[侦测器](侦测器.md)**
* 移植于[基岩版](基岩版.md)。
* * 由于Java版红石的工作方式与基岩版不同，可能会有一些微小的差别。
* 可以探测方块的更新并且输出红石信号。
* * 普通的[BUD](Tutorial:方块更新感应器.md)照常工作。

* *[潜影盒](潜影盒.md)**
* 可以用两个潜影壳和一个箱子合成，箱子在中间，潜影壳一个在上面，另一个在下面。
* * 此快照存在无法在左右栏中合成潜影盒的漏洞。
* 可以像箱子一样使用，但破坏后会保留物品。
* * 如果潜影盒中有物品，在[创造模式](创造模式.md)破坏时也会掉落本身。
* * 不能放在另一个潜影盒中。
* * 在物品栏中只会显示其中的5个槽位。
* * 被活塞推动时会破坏，掉落变为物品状态。
* 开启和关闭的动画与潜影贝相同。
* 可以在方块的任何平面放置，打开的方向也会随之改变。
* * 打开时，潜影盒的高度会从1个方块变为1.5个方块。
* ** 因此，如果打开方向上与其相邻的半个方块被占用将无法打开。
* 可用染料染色。
* * 底部颜色会比正常颜色略深。
* * 在这个快照中，有不能获得染色版本的漏洞，所以暂时只能通过创造模式或命令获得。
* 发射器会把潜影盒放在地上。
* 可以用任何物品，工具破坏，但用[镐](镐.md)更快。

# = 物品 =
* *[潜影壳](潜影壳.md)**
* [潜影贝](潜影贝.md)死后有50%概率掉落。
* 可以和[箱子](箱子.md)一起合成[潜影盒](潜影盒.md)。

* *[不死图腾](不死图腾.md)**
* 唤魔者死后掉落1个不死图腾。
* 当玩家手持不死图腾，会在受到致命攻击时激活它并拯救玩家。
* * 在激活时会给予玩家伤害吸收和生命恢复的效果。
* * 不能阻止与掉落[虚空](虚空.md)的死亡。
* * 激活时会显示使用其物品纹理与模型的动画。

* *[探险家地图](探险家地图.md)**
* 只可以在制图师处交易获得。
* 用于定位[海底神殿](海底神殿.md)与[林地府邸](林地府邸.md)。
* * 海洋探险家地图的物品栏地图标志为蓝色，林地探险家地图为棕色
* 类似于地图，但只会显示陆地的轮廓和一个结构图标。
* * 会在玩家探索到的时候加载并填充地图。
* 调整大小之后，还会显示结构位置图标，但是轮廓会消失。
* 探险图会显示各自生物群系的轮廓。
* 当玩家处于地图范围之外，会显示玩家的定位点，地图上的定位点越小，玩家的距离就越远。
* * 当距离该结构1024方块外时，定位点会由小变大。

# = 生物 =
* *[羊驼](羊驼.md)**
* 在峭壁自然生成。
* 掉落[皮革](皮革.md)。
* 拥有多种颜色的皮肤。像[豹猫](豹猫.md)和[马](马.md)。
* 使用吐口水攻击。
* * 如果玩家攻击它们，它们会攻击玩家一次。造成伤害。
* * 如果不在羊驼队伍中，会对[狼](狼.md)有攻击性。
* 可以装备地毯作为鞍和装备箱子来储物。
* * 装备不同的地毯时会显示不同的纹理。
* * 可储存槽位数量取决于羊驼的强壮度。
* 当被拴绳拴住的时候，附近的羊驼会被吸引，并且尝试在它后面排成一条羊驼队伍。
* * 当处在队伍中时羊驼会变为被动型生物。

* *[灾厄村民](灾厄村民.md)**
* 一类与[村民](村民.md)外观相似的生物，皮肤为浅灰色且穿着深色的衣服。
* 加入两种灾厄村民: [唤魔者](唤魔者.md)与[卫道士](卫道士.md)。

* *[卫道士](卫道士.md)**
* 被激怒时会张开双臂，在主手里拿着一把[铁斧](铁斧.md)。
* 与[玩家](玩家.md)和[村民](村民.md)敌对。
* 名字为<code>Johnny</code>时会攻击附近的所有生物（其他灾厄村民除外）。
* 在林地府邸生成时生成。不会重新生成。
* 可能掉落[绿宝石](绿宝石.md)与[铁斧](铁斧.md)。

* *[唤魔者](唤魔者.md)**
* 作为一个最终挑战或小型Boss加入。
* 掉落[不死图腾](不死图腾.md)。可能掉落[绿宝石](绿宝石.md)。
* 在战斗中，拥有召唤[恼鬼](恼鬼.md)和尖牙攻击的能力。
* * 举起双手来施魔法。
* * 尖牙会造成伤害，无视盔甲。
* 与[玩家](玩家.md)和[村民](村民.md)敌对。
* 生成在林地府邸的第二和第三层楼。不会重新生成。
* 会将16格半径内所有蓝色[绵羊](绵羊.md)变成红色。

* *[恼鬼](恼鬼.md)**
* 只会由[唤魔者](唤魔者.md)召唤。
* 类似于鬼魂，是小型的灰白色飞行生物，可以穿透方块。
* 纹理变为有红色标记时将攻击玩家。
* 与[玩家](玩家.md)和[村民](村民.md)敌对。
* 主手拿着[铁剑](铁剑.md)。

# = 世界生成 =
* *[回归传送门](末地折跃门.md)**
* 看起来像[末地折跃门](末地折跃门.md)，但会把玩家传送到主岛的生成平台。
* 在[末地](末地.md)中[末地城](末地城.md)附近随机生成。

* *[林地府邸](林地府邸.md)**
* 在黑森林中自然生成。
* [灾厄村民](灾厄村民.md)的家
* 有三层，底部两层大顶层小。
* 使用程序生成和[结构方块](结构方块.md)进行随机布局。
* * 因此有些房间可能完全被墙围着，没有入口。
* 主要包括[木板](木板.md)和[圆石](圆石.md)。
* 可以用[林地探险家地图](林地探险家地图.md)找到。

# = 命令格式 =
* ***
* 用法：
* * 适用于：。
* * 沙漠神殿，丛林神庙，女巫小屋和雪屋等都属于。
* 为执行命令的玩家在聊天框中推送指定类型结构的最近坐标。
* * 回复：“Located [Structure] at [x] [y] [z]”（“在 [x] [y] [z] 处定位 [结构]”）。
* * 某些结构会把Y坐标显示为 (y?) 。
* * 如果结构不在附近（即在另一个维度），会回复“Unable to locate any [StructureType] feature”（“无法定位 [结构类型] 特征”）。

* *NBT标签**
* 新的物品标签显示条目：<code>LocName</code>根据语言环境选择翻译。
* <code>CustomPotionColor</code>对于药水与药箭重新设置颜色的总标签。
* <code>ColorMap</code>对于已填充地图的物品纹理重新设置颜色的总标签。

# = 游戏内容 =
* *诅咒魔咒**
* 拥有负面效果的魔咒
* 加入两种诅咒：消失诅咒（魔咒ID 10）和绑定诅咒（魔咒ID 71）。
* * 绑定诅咒会将物品绑定于玩家。如果被诅咒的物品是盔甲，玩家将无法丢弃或脱下它。但是在死亡时会掉落。绑定诅咒不会影响创造模式的玩家。
* * 消失诅咒会使物品在玩家死亡后消失。游戏规则会阻止这一点。
* 一些自然生成的结构里可能有被诅咒的工具、附魔书和盔甲，作为战利品。

* *[粒子](粒子.md)**
* <code>spit</code>
* * 当[羊驼](羊驼.md)吐口水时使用。
* <code>totem</code>
* * 当[不死图腾](不死图腾.md)激活时使用。

# 更改
# = 方块 =
* *[末地折跃门方块](末地折跃门方块.md)**
* 当传送实体时会发出品红色光柱，而不是黄色。
* * 这个颜色与方块首次生成时发出的光柱颜色匹配。

# = 物品 =
* *[地图](地图.md)**
* 在末地中可以使用地图。
* 物品纹理中的“标志”颜色由<code>ColorMap</code>标签决定。
* * 用于探险家地图。

* *[药水](药水.md)和[药箭](药箭.md)**
* 物品纹理的颜色能以<code>CustomPotionColor</code>标签自定义。

# = 生物 =
* *[潜影贝](潜影贝.md)**
* 现在掉落0-1个[潜影壳](潜影壳.md)。
* 可以通过<code>Color</code>标签来生成不同颜色的潜影贝。
* * 更改了颜色的潜影贝有较深色的底部，使它们和普通潜影贝不同。

* *[村民](村民.md)**
* 图书管理员村民的新职业：制图师。
* * 获得[探险家地图](探险家地图.md)的唯一途径。

* *[凋灵骷髅](凋灵骷髅.md)**
* 现在有自己的声音。

* *[僵尸村民](僵尸村民.md)**
* 现在有自己的声音。

# = 常规 =
* *[按键](选项.md)**
* 补全的结果现在按英文字母顺序排列。
* 调换按键控制界面的“完成”和“重置按键”按钮，保持界面统一。
