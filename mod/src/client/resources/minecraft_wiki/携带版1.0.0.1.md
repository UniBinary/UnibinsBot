# 携带版1.0.0.1

*页面ID: 26625* | *来源: Minecraft Wiki*

<onlyinclude>

* *alpha 1.0.0.1**是[1.0.0](携带版1.0.0.md)的第4个测试版，发布于2016年12月7日<ref></ref>，加入了潜影壳，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[潜影壳](潜影壳.md)**
* 暂时没有用途。<ref></ref>

# 更改
# = 方块 =
* *[红石粉](红石粉.md)**
* 破坏[红石粉](红石粉.md)时会出现红色粒子而不是白色粒子。

* *[玻璃](玻璃.md)**
* [玻璃](玻璃.md)再次正确显示其纹理。

* *[紫颂果](紫颂果.md)和[紫颂植株](紫颂植株.md)**
* 调整了[紫颂果](紫颂果.md)和[紫颂植株](紫颂植株.md)的物品栏纹理。

# = 物品 =
* *常规**
* 为[紫颂果](紫颂果.md)与[末影珍珠](末影珍珠.md)添加冷却动画。

# = 生物 =
* *[潜影贝](潜影贝.md)**
* 调整了[潜影贝](潜影贝.md)使其关闭壳时装备盔甲而不是吸收伤害。
* [潜影贝](潜影贝.md)现在重新掉落[潜影壳](潜影壳.md)。

* *[北极熊](北极熊.md)**
* 不再会陷入[雪](雪.md)中。

* *[蠹虫](蠹虫.md)**
* 调整了生成行为，使其与其他版本一致。

* *[兔子](兔子.md)**
* 不再在积雪的[生物群系](生物群系.md)中以指数形式生成。

# = 世界生成 =
* *雪屋**
* 调整了[雪屋](雪屋.md)，使其使用正确的[冰](冰.md)。

# = 常规 =
* *性能**
* 游戏应该更快地开始和/或不会时常停留在黑屏上（仅限Android测试版）。

# 修复
* *修复了26个漏洞**
* 红石中继器的激活时间过短。
* 熄灭的红石火把仍会使得活塞伸出。
* 幼年村民长大时仍会显示幼年模型。
* 玩家在上下移动过程中卡顿会使得他们受伤。
* 现在流浪者在死后会有50%的概率掉落迟缓之箭。
* 画在放置时游戏崩溃。
* 携带版合成界面里不会显示物品栏信息。
* 加载世界模板时只会看见全景图。
* 玩家会在方块的角落重生，而不是方块的正中央。
* 或命令运作不正常。
* 玩家死后不会从死亡的位置获得经验值。
* 商店会卡在加载界面里。（仅Kindle Fire）
* 漏斗会收集不在其上方的物品。
* 玩家捡起的物品不会和物品栏内的同一个物品合并。
* 玩家的出生点在世界高度上限时游戏崩溃。
* 方块高亮时，高亮只会出现一瞬间。
* 潜影弹在发射或破碎时没有音效。
* 紫颂果和紫颂植株在破坏时音效不正确。
* 附有抢夺的剑会在杀死实体时掉落无效的物品，且捡起时游戏崩溃。
* 无法导入含有文件夹的<code>.zip</code>文件。
* 末影人在死后仍会传送。
* 铁傀儡会溺水而死。
* 从Realms世界里移除玩家白名单后不会使得目标玩家被立即踢出。
* 由树苗长大而成的树会隐形（仅Realms世界）。
* 伤害之箭会从生物身上弹开。
* 导入纹理包时游戏崩溃。</onlyinclude>
