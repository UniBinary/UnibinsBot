* *矢车菊（Cornflower）**是一种[小型花](小型花.md)。

# 生成

# = 自然生成 =
矢车菊会在[平原](平原.md)、[向日葵平原](向日葵平原.md)、[繁花森林](繁花森林.md)、[草甸](草甸.md)、[溶洞](溶洞.md)和[深暗之域](深暗之域.md)生物群系自然生成。

# = 骨粉 =
在可自然生成矢车菊的生物群系中对[草方块](草方块.md)[骨粉](骨粉.md)后，矢车菊有概率代替[矮草丛](矮草丛.md)生成。

对着不[含雪](含雪.md)的矢车菊使用骨粉会出现更多的矢车菊，而不会出现草丛。

# 破坏
矢车菊被挖掘时会立刻被破坏。

矢车菊被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 谜之炖菜 =

使用矢车菊合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家5s的[跳跃提升](跳跃提升.md)效果。

# = 堆肥 =
将矢车菊放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
