# 欢迎屏幕

*页面ID: 155004* | *来源: Minecraft Wiki*

* *欢迎屏幕（Welcome Screen）**是在首次运行Minecraft时进入的界面。

# 说明
欢迎屏幕是否会在游戏启动后显示由[options.txt](options.txt.md)中对应的值控制：
* 为，默认为。该值为时则不会在启动游戏后显示该屏幕。
* 为，默认为。该值为时则不会在启动游戏后显示该屏幕。
* * 当中已存在世界时，该值会在游戏启动时自动更改为。

# Java版

首次进入游戏时，游戏会进入辅助功能引导屏幕。

此屏幕提供一些快捷辅助功能选项，如下：

;
   切换复述功能的复述范围：、、或。

;
   点击后会进入[辅助功能设置](选项#accessibility.md)界面。

;
   点击后会进入[语言](语言.md)选择界面。

;
   点击后会进入[主菜单](主菜单.md)。

点击后，游戏会将设置为以防止在之后显示此屏幕。

# 基岩版

首次进入游戏时，游戏会进入欢迎屏幕，在简单介绍游戏玩法的同时引导玩家创建一个世界。

;
   点击此按钮后，游戏会按顺序依次显示以下-{}-界面，供玩家按喜好选择。
# “游戏模式”界面。用于选择游戏模式。
# “生存难度”界面。用于选择游戏难度。
# * 若选择了创造模式，则不会显示此界面，且游戏难度固定为普通。
# “选择角色”界面。可以从9种[默认皮肤](皮肤#默认皮肤.md)中选择一个。
# “”界面。用于选择[触控模式](控制#触控.md)。
# * 此界面仅在使用触屏操控时显示。
# “”界面。简单介绍即将创建的世界。点击“游玩 Minecraft”即可创建该世界并进入。

; 更多选项
   点击后会进入[主菜单](主菜单.md)。

进入世界或主菜单后，游戏会将设置为以防止在之后显示此界面。

# 你知道吗
* 登录提示会优先于此屏幕出现。
* 部分第三方启动器可能会在启动游戏前将修改为，因此游戏将不会显示该屏幕。
