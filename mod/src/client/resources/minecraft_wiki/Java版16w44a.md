# Java版16w44a

*页面ID: 26048* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w44a**是[Java版1.11](Java版1.11.md)的第14个，也是最后一个快照，发布于2016年11月3日<ref></ref>，修复了一些漏洞。

# 更改
# = 游戏内容 =
* *[潜行](潜行.md)**
* 现在会防止玩家在格或更高的方块中掉落；之前为1格方块或更高。
