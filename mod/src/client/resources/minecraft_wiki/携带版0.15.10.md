# 携带版0.15.10

*页面ID: 25469* | *来源: Minecraft Wiki*

* *v0.15.10**是携带版的一次次要更新，在Android上发布于2016年10月3日，其余版本发布于10月4日<ref></ref><ref>https://mojang.com/2016/10/fearsome-fixes-the-spooky-01510-changelog-for-pocket-win-10/</ref>，加入了篝火传奇皮肤包和一些新成就，对部分设置进行了微调，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[资源包](资源包.md)**
* 加入了篝火传奇皮肤包。

* *[成就](成就.md)**
* 加入了下列成就：*自由潜水员*、*兔子的季节*、*干旱期*、*困境*、*信标工程师*、*开始了？*、*开始了。*、*君临天下*和*超级燃料*。

# 更改
# = 常规 =
* *[披风](披风.md)**
* [披风](披风.md)不再穿过[盔甲](盔甲.md)。

* *[纹理](纹理.md)**
* 修复细小的纹理错误。

* *[控制](控制.md)**
* 自动转向的小修复（仅Gear VR）。

# 修复

* *其他**
* 获取MINECON 2016披风时，玩家现在需要确认是否“购买”免费内容；在安卓设备里可以使用代码获取。
* 在VR模式里渲染拴绳导致游戏崩溃。
* 不能使用B控制器按钮来退出游戏（仅Windows 10版）。
* VR模式里的顶部光标闪烁。
* VR模式下鼠标点击不再导致键盘输入停止。
* Oculus商店里启动其他应用不会使得游戏停止运行（仅Windows 10版）。
* 在发布0.16.0.b1和b3前修复了VR模式下的一些漏洞，包括但不限于：
* * 加载世界时游戏崩溃。
* * 无法连接Realms世界。
* * 骑乘动物时，从房间模式切换到沉浸模式使得该动物被透视。
* * 拉弓并射箭后，指示器光标消失。
* * 控制器输入在VR窗口失去焦点时停止。

# 你知道吗
* 九个来自篝火传奇皮肤包的皮肤：[无头的幽魂](https://twitter.com/Minecraft/status/781977172659478528)、[Ol' Diggy](https://twitter.com/Minecraft/status/782158366529490944)、[强迫被海水吞噬的队长](https://twitter.com/Minecraft/status/782339557941452801)、[腐臭的安妮](https://twitter.com/Minecraft/status/782520753396801536)、[许愿人](https://twitter.com/Minecraft/status/782701948222832640)、[欺骗者](https://twitter.com/Minecraft/status/782883142046740484)、[复仇的伐木杰克](https://twitter.com/Minecraft/status/783064336285704194)、[糖果酥](https://twitter.com/Minecraft/status/783245529606160384)和[复活的玫瑰](https://twitter.com/Minecraft/status/783426724516270080)，根据特定的顺序，在一些推文中以快照的方式展示出来，并在一旁附有背景故事，通过官方Minecraft推特账户发送。
* * 这些推文在0.15.10推送到各个设备上的几天前被发送（除了有关复活的玫瑰的推文），作为“戏弄者”的一种形式，从9月30日到10月4日。
* ** 据说推文都恰好在上午或下午的3:01被发送。
