# 用途
# = 食物 =

手持蜘蛛眼按住键即可食用，每个蜘蛛眼可以回复，并给予玩家4秒的效果，造成伤害。

=== 繁殖 ===
蜘蛛眼可用来吸引和繁殖[犰狳](犰狳.md)，也可喂食给幼年个体以减少其10%的剩余成长时间。
