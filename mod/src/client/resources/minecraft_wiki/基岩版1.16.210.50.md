# 基岩版1.16.210.50

*页面ID: 72812* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.210.50**是[基岩版1.16.210](基岩版1.16.210.md)的首个测试版，发布于2020年12月2日<ref></ref>，为[下界](下界.md)加入了新的环境音效，同时修复了一些漏洞。

以下更新内容基于上一测试版[1.16.200.57](基岩版1.16.200.57.md)，包含了其中已加入的[洞穴与山崖](洞穴与山崖.md)特性。

# 新内容
# = 常规 =
* *[环境音效](环境音效.md)**
* 为[下界](下界.md)加入了新的环境音效。<ref></ref>
* * 不同的下界生物群系会播放不同的环境音效。

# 修复
* *常规**
* 玩家再次能够加入视野距离设置为4或更小的服务器了。（）
* 基于原版活动对象<!-- actor -->的自定义生物动画（如熊猫、北极熊）现在可以正常运行。（）
* 恢复了在暂停和重启服务器时重新加入服务器的功能。

* *辅助功能**
* 修复了屏幕阅读器无法读取权限界面的标题的问题。

* *成就界面**
* 移除了启用复述功能后的成就界面摘要面板的输入图例。
* 修复了滚动条能够隐藏在输入图例之后的问题。
* 修正了成就详细信息界面，其内容隐藏在输入图例之后。
* 更新了成就奖励框的大小。
* 更新了锁定成就的艺术图框。</onlyinclude>
