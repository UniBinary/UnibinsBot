# 携带版1.1.5

*页面ID: 32017* | *来源: Minecraft Wiki*

* *1.1.5**是的一次次要更新，在FireOS上发布于2017年8月1日，在Apple TV上发布于8月7日，其余平台发布于8月3日<ref></ref>，修复了一些漏洞。

此版本是[Apple TV版](Apple TV版.md)的最终更新，也是除了iOS系统外最后一个被称作“携带版”的更新。

# 更改
# = 常规 =
* *[商城](商城.md)**
* 所有和商城有关的模块被移动到一个单独的库。
* * 此后新增商城内容时不再需要更新游戏版本。

# 修复
* *修复了3个漏洞**
* 使用资源包并重连世界后，时钟和指南针的纹理不再出现损坏。
* 修复了绊线的纹理。
* 优化了皮肤选择器，现在所有皮肤均会正常显示。
