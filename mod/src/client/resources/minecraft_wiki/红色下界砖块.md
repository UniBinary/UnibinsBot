# 红色下界砖块

*页面ID: 56721* | *来源: Minecraft Wiki*

* *红色下界砖块（Red Nether Bricks）**是由[下界砖](下界砖.md)和[下界疣](下界疣.md)合成的装饰性方块。

# 生成
红色下界砖块不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘红色下界砖块的合适工具是镐。红色下界砖块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

红色下界砖块被破坏后会掉落自身。
