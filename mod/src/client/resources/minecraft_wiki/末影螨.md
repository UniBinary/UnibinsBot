* *末影螨（Endermite）**是[末影珍珠](末影珍珠.md)落地时生成的[敌对生物](敌对生物.md)。

# 生成
每个末影珍珠落地时，末影螨都有5%的概率在玩家使用该末影珍珠或的位置生成。

# 掉落物
末影螨在被[玩家](玩家.md)或者驯服的[狼](狼.md)杀死时会掉落。

# 行为
末影螨会主动攻击16格内的玩家。

如果某个生物攻击了一个末影螨，并且未一击杀死，那么在该区域内的所有末影螨都会与该生物敌对。末影螨被其他生物攻击后不会尝试反击。<ref></ref>

除非末影螨被[命名牌](命名牌.md)命名，否则其会在生成后的2分钟后消失，无视其他条件。

末影螨会在它们周围生成[紫色粒子](粒子#portal.md)。

末影螨死亡时并不是侧着倒下，而是底朝天翻转，[蜘蛛](蜘蛛.md)、[洞穴蜘蛛](洞穴蜘蛛.md)和[蠹虫](蠹虫.md)同样如此。

# = 末影人 =
[末影人](末影人.md)会主动攻击64格内的末影螨。

# = 生物族群 =

末影螨是[节肢生物](节肢生物.md)，被具有[节肢杀手](节肢杀手.md)魔咒的武器近战攻击时会受到额外的伤害并被施加数秒的[緩速](緩速.md)IV效果。
