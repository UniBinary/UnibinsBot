* *附魔（Enchanting）**是一种为不具有魔咒的物品随机生成[魔咒](魔咒.md)的方式，由[附魔台](附魔台.md)、[生物](生物.md)天然装备、[战利品表](战利品表.md)所使用。

# 附魔等级
附魔操作需要一个基本变量**附魔等级**。附魔等级是一个整数，会影响选取魔咒的种类、等级和数量。通常来说，附魔等级越高，获得的魔咒就越优质，魔咒的等级越高，魔咒的数量也越多。
* [附魔台](附魔台.md)可以进行1–30级附魔。附魔台选择附魔等级的方式见。
* 生物天然装备可以进行5–22级附魔。此由原版数据包中的[魔咒提供器](魔咒提供器.md)<code>mob_spawn_equipment</code>定义。
* [村民](村民.md)的部分[交易](交易.md)选项可以进行5–19级附魔。
* [钓鱼](钓鱼.md)和[要塞](要塞.md)、[丛林神庙](丛林神庙.md)的[箱子战利品](箱子战利品.md)可以进行30级附魔。
* [末地城](末地城.md)和[远古城市](远古城市.md)的箱子战利品可以进行20–39级附魔。
* [试炼密室](试炼密室.md)的箱子战利品和[宝库](宝库.md)战利品可以进行0–20级附魔。
* [远古城市](远古城市.md)的箱子战利品可以进行30–50级附魔。

# 附魔能力
每个物品都有它的**附魔能力**，决定了它选中魔咒的种类和等级。附魔能力越高，魔咒的质量就越好。

如果一个物品的附魔能力为0，则无法附魔。

# 修正附魔等级范围
每个魔咒的每个等级都有其**修正附魔等级范围**，由**最大修正附魔等级**和**最小修正附魔等级**构成。

# 魔咒选取
对于指定的附魔等级和一个特定物品，游戏会以它们二者为参数选取随机的魔咒。

# = 修正附魔等级 =
在选取魔咒之前，游戏会将当前的附魔等级与物品的附魔能力进行计算，得到修正后的附魔等级。如果附魔等级为*c*，物品的附魔能力为*l*，则修正后的附魔等级*c*'使用下列步骤进行计算：
# 为附魔等级添加物品附魔能力修正，增加值符合[三角形分布](wzh:三角分布.md)：<math>c'=c+1+\mathrm{randInt}\left(\left\lfloor\frac{l}{4}\right\rfloor+1\right)+\mathrm{randInt}\left(\left\lfloor\frac{l}{4}\right\rfloor+1\right)</math>，其中<math>\mathrm{randInt}(k)</math>的作用是在闭区间<math>[0,k-1]</math>中产生均匀分布的随机整数。
# 对附魔等级进行波动调节，最多波动15%，服从三角分布：{{only|for=<math>c'=(1+0.15(\mathrm{randFloat}()+\mathrm{randFloat}()-1))c'</math>|je}}/{{only|for=<math>c'=(0.85+0.3\cdot\mathrm{randFloat}())c'+0.5</math>|be}}，其中<math>\mathrm{randFloat}()</math>返回区间<math>[0,1)</math>内的随机浮点数。
# 对附魔等级进行/，并进行约束，使其不小于1且不大于32位有符号整数最大值，最终得到修正附魔等级：{{only|for=<math>c'=\max\{\min\{\mathrm{round}(c'),2147483647\},1\}</math>|je}}/{{only|for=<math>c'=\max\{\min\{\mathrm{int}(c'),2147483647\},1\}</math>|be}}。

以中附魔等级30级，对钻石镐附魔进行举例：

取最好情况，即所有随机数返回最大值，则修正附魔等级计算为：

<pre>-{}-
c' = 30 + 1 + randInt(floor(10 / 4) + 1) + randInt(floor(10 / 4) + 1) （添加物品附魔能力修正）
   = 30 + 1 + 2 + 2
   = 35
c' = (1 + 0.15(randFloat() + randFloat() - 1)) &times; 35 （波动调节）
   = (1 + 0.15) &times; 35
   = 40.25
c' = clamp(round(40.25), 1, 2147483647) （舍入约束）
   = 40
</pre>

取最坏情况，即所有随机数返回最小值，则修正附魔等级计算为：

<pre>-{}-
c' = 30 + 1 + randInt(floor(10 / 4) + 1) + randInt(floor(10 / 4) + 1) （添加物品附魔能力修正）
   = 30 + 1 + 0 + 0
   = 31
c' = (1 + 0.15(randFloat() + randFloat() - 1)) &times; 31 （波动调节）
   = (1 - 0.15) &times; 31
   = 26.35
c' = clamp(round(26.35), 1, 2147483647) （舍入约束）
   = 26
</pre>

# = 生成可选魔咒列表 =
根据修正后的附魔等级*c*'，游戏会对物品计算出可以附魔的魔咒列表。

每个魔咒都有它们的出现条件：
* 不可附魔的魔咒（[灵魂疾行](灵魂疾行.md)、[迅捷潜行](迅捷潜行.md)、[风爆](风爆.md)）不会出现在魔咒列表中。
* 宝藏魔咒（[绑定诅咒](绑定诅咒.md)、[冰霜行者](冰霜行者.md)、[经验修补](经验修补.md)、[消失诅咒](消失诅咒.md)）不会出现在非宝藏的魔咒列表中。宝藏包括：
* * 开放水域的[钓鱼](钓鱼.md)战利品。
* * [要塞](要塞.md)储藏室、图书馆、走廊战利品箱。
* * [末地城](末地城.md)战利品箱。
* * [远古城市](远古城市.md)战利品箱。
* * [丛林神庙](丛林神庙.md)战利品箱。
* * [试炼密室](试炼密室.md)战利品箱。
* * 袭击中卫道士和掠夺者的掉落物。
* 如果魔咒不能附魔到指定物品上，则不会出现在魔咒列表中。[书](书.md)无视此限制，书是任何魔咒的适用物品。
* 对于魔咒的每个等级，都有它的**修正附魔等级范围**，由**最大修正附魔等级**和**最小修正附魔等级**构成。只有当修正附魔等级/时，这个魔咒的这个等级才可以出现在魔咒列表中。
* * 如果一个魔咒的不同等级同时满足当前的修正附魔等级，则取最高魔咒等级加入魔咒列表，较低的等级会被清除。

# = 随机挑选魔咒 =
在得到魔咒列表后，游戏会根据魔咒自身的**挑选权重**（**Weight**）对魔咒列表内的所有魔咒进行加权，以降低稀有附魔的出现概率。

在列表生成后，随机选择魔咒的过程开始。若该附魔是在附魔台上进行的，则随机选择魔咒使用的随机函数将使用进行操作的玩家的附魔种子。

假设魔咒列表中总共有<math>i</math>个魔咒，分别为<math>E_1,E_2,E_3,\dots,E_i</math>，对应稀有度的权重为<math>w_1,w_2,w_3,\dots,w_i</math>，则总权重值<math>W</math>为<math>\sum_{k=1}^iw_k</math>，选择第<math>k</math>个魔咒<math>E_k</math>的概率为<math>\frac{w_k}{W}</math>。

在选中一个魔咒后，游戏会判定是否继续选择魔咒：
# 生成一个<math>\left[0,49\right]</math>区间内的随机整数，如果修正附魔等级<math>c'</math>大于等于此整数，则可能继续选择魔咒，否则循环终止，选择完毕。
# * 如果<math>c'</math>不小于49，则一定可以通过此判定，否则概率为<math>\frac{c'+1}{50}</math>。
# 添加该魔咒。
# 删除魔咒列表内刚才选中的魔咒。
# 检查魔咒列表是否为空，如果是，则选择完毕，终止循环。
# 按照当前魔咒列表的魔咒和它们的权重，挑选出新的魔咒。
# 将修正附魔等级折半，并向下取整，即<math>c'=\left\lfloor\frac{c'}{2}\right\rfloor</math>。将修正附魔等级乘以4/5，并向下取整，再加1，即<math>c'=\left\lfloor\frac{4c'}{5}\right\rfloor+1</math>
# 回到第一步，重新判定是否再次选择新的魔咒。

如果附魔的物品是书，并且在附魔台内进行附魔，如果选择的魔咒数量不止一个，则随机删除一个魔咒。
