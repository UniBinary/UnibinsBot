# 末影箱

*页面ID: 8038* | *来源: Minecraft Wiki*

* *末影箱（Ender Chest）**是为每个[玩家](玩家.md)提供可在任意位置使用的同一物品储存的方块，具有类似[箱子](箱子.md)的模型。

# 生成
# = 自然生成 =
[末地城](末地城.md)的战利品房间里会生成一个末影箱，与一个[箱子](箱子.md)相邻。

# 破坏
挖掘末影箱的合适工具是镐。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，末影箱被破坏后会掉落8个[黑曜石](黑曜石.md)。

被具有精准采集的工具挖掘破坏时，末影箱被破坏后会掉落自身。

# 用途
对着一个上方没有或的末影箱按下键即可打开末影箱。末影箱允许玩家访问自己的末影箱[物品栏](物品栏.md)，该物品栏包含27个槽位，与单个[箱子](箱子.md)一致，其内容存储于玩家的实体数据中。

打开任何维度的任何位置的末影箱，其内容始终是一样的。即使一个世界的所有末影箱均被破坏，玩家也不会失去他们储存在其中的物品。

玩家不能访问其他玩家的末影箱物品栏，死亡时也不会掉落存储在末影箱物品栏中的物品。

末影箱本身不存储任何物品，在没有玩家环境的情况下没有内容物，被破坏时也不会掉落其掉落物以外的任何物品，不能和[漏斗](漏斗.md)、[投掷器](投掷器.md)以及[红石比较器](红石比较器.md)进行互动。

尽管有着类似箱子的外观，但末影箱不能被装备在[驴](驴.md)、[骡](骡.md)或[羊驼](羊驼.md)身上，也不会像箱子那样合并成大型箱子。

末影箱不能被[活塞](活塞.md)推动或拉动。

末影箱会产生向内聚拢的与[下界传送门](下界传送门.md)类似的紫色[粒子](粒子.md)，存在于其周围半径为一个方块的区域内。

# = 光源 =
末影箱会发出[亮度](亮度.md)为7级的光。

# = 猪灵 =
在非[和平](和平.md)难度下，成年[猪灵](猪灵.md)会与附近打开或破坏末影箱的玩家敌对。
