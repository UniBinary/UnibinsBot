# Java版Classic 0.28

*页面ID: 35608* | *来源: Minecraft Wiki*

/开发者版本}}
<onlyinclude>

* *0.28**是[Java版Classic](Java版Classic.md)的一次更新，发布于2009年10月27日<ref></ref>，加入了[绵羊](绵羊.md)和[黑曜石](黑曜石.md)，并重新加入了[创造模式](创造模式.md)。

# 新内容
# = 生物 =
* *[绵羊](绵羊.md)**
* 一种友好生物。
* 会自然生成在[生存模式](生存模式.md)的世界中。
* 被攻击时会掉落1~3个布料。
* 被杀死时掉落0~2个[蘑菇](蘑菇.md)，同时给予[玩家](玩家.md)10分。

# = 方块 =
* *[黑曜石](黑曜石.md)**
* 一种装饰性方块。
* 不会自然生成在世界中。
* 硬度非常大。
* 被破坏后掉落1个[圆石](圆石.md)。

# = 游戏内容 =
* *[游戏模式](游戏模式.md)**
* 重新加入了[创造模式](创造模式.md)。
* 现在，可以通过修改文件来修改游戏模式。

# 更改
# = 方块 =
* *[布料](羊毛.md)**
* 更改了浅灰色布料和深灰色布料的纹理。

* *[TNT](TNT.md)**
* 更改了纹理。

# = 游戏内容 =
* *[生存模式](生存模式.md)**
* 仅能通过修改客户端进入。
* 世界中仅会生成绵羊这一种生物。
* * 其他生物也可以存在并正常行动。
* 尝试点燃TNT会让它直接消失。
* 挖掘方块不会掉落物品。
* * 攻击绵羊仍然可以可以掉落[布料](羊毛.md)。

* *[多人游戏](多人游戏.md)**
* 重新加入了对多人游戏的支持。
* 当你站在其他[玩家](玩家.md)旁边或里面时，会稍微将他推开。
* * 可以穿过玩家，但感觉有些像穿过“固体”。

* *[创造模式物品栏](创造模式物品栏.md)**
* 将[熔岩](熔岩.md)和[水](水.md)加入快捷栏。
* 将[矿石](矿石.md)，[石台阶](石台阶.md)，[铁块](铁块.md)，[金块](金块.md)，[砖块](砖块.md)，[书架](书架.md)，[苔石](苔石.md)和[TNT](TNT.md)加入到创造模式物品栏中。

* *[菜单屏幕](菜单屏幕.md)**
* 重新添加了阴影。

* *常规**
* 更改了存档的保存/加载代码。

# = 常规 =
* *[控制](控制.md)**
* 左键移除方块。
* 右键放置方块。
* 生成新世界时不再保存快捷栏内容。
* 重新加入了中键选取方块的功能，取消了攻击速度限制，并将玩家范围恢复到5格（仅限创造模式）。
* 箭数目计数器在创造模式中被隐藏。

* *常规**
* 提高了帧率。
* 渲染引擎支持渲染两层透明度。

# 修复
* *修复了6个漏洞**
* 修复了使用非法名称登录的人会导致玩家断开连接的漏洞。
* 现在看向玻璃会使其后方的纹理消失。
* 台阶放在另一个台阶下方时，其碰撞箱不会合并成一个完整的方块的形式（仍然不能放在顶部）。
* 台阶顶部纹理在其正上方有方块时不可见。
* 在台阶上放置方块不再会导致它变成一个双台阶了。
* 水和熔岩不再显示其他纹理的一部分了。</onlyinclude>
