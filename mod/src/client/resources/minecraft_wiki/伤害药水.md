# 伤害药水

*页面ID: 181474* | *来源: Minecraft Wiki*

* *伤害药水**是提供[瞬间伤害](瞬间伤害.md)状态效果的[药水效果](药水效果.md)。

該藥水效果可以製成[藥水](藥水.md)**伤害药水（Potion of Harming）**、[飛濺藥水](飛濺藥水.md)**喷溅型伤害药水（Splash Potion of Harming）**、[滯留藥水](滯留藥水.md)**滞留型伤害药水（Lingering Potion of Harming）**和[藥水箭](藥水箭.md)**伤害之箭（Arrow of Harming）**。

此药水效果有对应的增强版。

# 生成
# = 生物 =
[女巫](女巫.md)会投掷喷溅型伤害药水。

# = 礼物 =

[制箭师](制箭师.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷伤害之箭。

# = 自然生成 =

[沼泽小屋](沼泽小屋.md)的[炼药锅](炼药锅.md)内可能装有伤害药水。

# = 炼药锅 =

对装有伤害药水的炼药锅使用[玻璃瓶](玻璃瓶.md)可获得伤害药水、喷溅型伤害药水或滞留型伤害药水，具体形式取决于炼药锅内容物。

对装有伤害药水的炼药锅使用[箭](箭.md)可获取伤害之箭，最大数量随内容物水位增加依次为16、32和64。

# 行为
伤害药水包含[瞬间伤害](瞬间伤害.md)状态效果，由于瞬间伤害是一种即时生效效果，因此生物饮用伤害药水、被喷溅伤害药水击中或位于滞留型伤害药水形成的[区域效果云](区域效果云.md)中时会直接受到瞬间伤害效果造成的效果，而不是先获得对应的状态效果再使其生效。对于增强版伤害药水同理。
