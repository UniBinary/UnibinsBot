# 基岩版1.20.10.23

*页面ID: 104527* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.10.23**（ChromeOS/Android）、**Preview 1.20.10.23**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.10](基岩版1.20.10.md)的第3个测试版，发布于2023年6月14日<ref></ref>，将1.49格高的[潜行](潜行.md)行为从[实验性玩法](实验性玩法.md)中移出，并修复了一些漏洞。

# 更改
# = 方块 =
* *[木桶](木桶.md)**
* 不再能够使用[木棍](木棍.md)合成。

# = 游戏内容 =
* *[潜行](潜行.md)**
* 1.49格高的潜行行为不再属于[实验性玩法](实验性玩法.md)。

# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 将“短暂潜行和爬行”子选项重命名为“爬行”。

* *[设置](设置.md)**
* 将“聊天消息持续时间”选项的默认值更改为10秒。

# = 技术性 =
* *附加包与脚本引擎**
* 现在的朝向使用玩家的身体朝向，以修复玩家向前移动但面向两侧时披风停止拍打的漏洞。（）
* 现在侦测器会使用而不是，且有效值变为、、、、和。

* *实体**
* 现在自定义实体可以覆写1.20.0及以上版本中加入的原版实体。

* *物品**
* 开放了1.20.10及以上版本的实验性JSON格式中的物品组件。
* 开放了1.20.10及以上版本的实验性JSON格式中的物品组件。
* 开放了1.20.10及以上版本的实验性JSON格式中的物品组件。
* 开放了1.20.10及以上版本的实验性JSON格式中的物品组件。
* 开放了1.20.10及以上版本的实验性JSON格式中的物品组件。

* *基岩版编辑器**
* 修复了与初始脚本加载有关的错误信息无法显示在日志面板上的漏洞。
* 现在命令可以直接在编辑器中使用，无需启动实验性API。
* 修复了使用D3D11 GPU的设备无法正常进行视图缩放的漏洞。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“短暂潜行和爬行”和“配方解锁”子选项后才可使用。

# = 游戏内容 =
* *[配方书](配方书.md)**
* 移除了某些情况下解锁配方时出现的[弹窗](弹窗.md)。
* [旁观模式](旁观模式.md)玩家不再能够解锁配方。（）
* 解锁新配方时不再会将物品栏中的可合成选项设置为“全部”。

* *[迅捷潜行](迅捷潜行.md)**
* 现在会提高玩家[爬行](爬行.md)时的移动速度。

# 修复
* *潜行和爬行**
* 修复了玩家在梯子上会自动潜行的问题。（）
* 修复了玩家潜行时会卡在梯子顶部的漏洞。（）
* 爬行时的头部不再会跟随相机视角转动。（）
* 修复了迅捷潜行不会提升爬行时的移动速度的问题。（）
* 修复了旧版的类爬行状态无法在“短暂潜行和爬行”选项未开启的情况下正常生效的问题。
* 修复了生物生成时不会拥有正确的碰撞箱的问题。（）
* 使用鞘翅在方块下方滑翔时不再会触发爬行动画。（）
* 现在玩家飞行时可以强制进入潜行或爬行状态。

* *常规**
* 修复了玩家向前移动并看向侧面时，其披风不会正确摆动的问题。（）
* 降低了玩家因“发现身份验证已过期”错误而触发“无法连接”的情况的可能性。（）
* 修复了鼠标配合控制器使用时会出现输入无响应或延迟的问题。（）

* *鼠标输入**
* 优化了同时点击鼠标时的处理方式，现在每个点击会触发单独的关联动作或响应。

* *辅助功能**
* 现在将鼠标悬停在聊天屏幕中的“/”按钮上时，文本转语音旁白会说出“斜杠按钮”。
* 现在聊天消息的默认停留时间为10秒，而弹窗通知的默认停留时间仍为3秒。
* 现在选中快捷栏中的物品时，文本转语音旁白会读出物品的名称。

* *活动对象**
* 修复了不先取消骑乘就无法切换坐骑的问题。（）

* *方块**
* 现在世界更新期间会接受南瓜、南瓜灯和雕刻南瓜的状态字符串。
* 蘑菇现在可以生成在倒下的树木的树干上。（）
* 现在放置在地面上的潮涌核心拥有正确的光照。（）

* *游戏内容**
* 移除了使用木棍合成木桶的合成配方。（）
* 当西侧和北侧附近存在细雪时，离开细雪的实体不再会继续被冰冻。（）

* *雕纹书架**
* 现在从雕纹书架中取出附魔书会播放正确的音效。（）
* 现在雕纹书架槽位的交互是对称的。（）

* *船**
* 现在更新至足迹与故事后，船会继续拥有运载乘客的能力。（）
* * 受此漏洞影响的船再次可以运载乘客。

* *用户界面**
* 光标不再能够通过控制器来移动至任意物品栏槽位的位置上。（）
* 现在马和驴的跳跃蓄力条、骆驼的冲刺蓄力条的长度与经验条一致。（）

* *命令**
* 命令现在会在绝对时间为负数时正确返回天数和当天的时间。

* *专用服务器**
* 修复了<samp>allowlist.json</samp>中的无效元素会导致崩溃的问题。（）</onlyinclude>
