# Java版1.21-pre2

*页面ID: 120908* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21-pre2**是[Java版1.21](Java版1.21.md)的第2个预发布版，发布于2024年5月31日<ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[自定义地物](自定义地物.md)**
* 加入了新的放置修饰器类型<code>fixed_placement</code>用于放置在一组固定位置上的地物。
* 为[末地黑曜石平台](末地平台.md)加入了新地物类型<code>end_platform</code>。

* *[社交屏幕](社交屏幕.md)**
* 加入了在提交玩家举报时显示的确认复选框。

* *[标签](Java版标签.md)**
* 加入了以下方块标签：
* * ：。
* ** 可被生物交互的门。

# 更改
# = 方块 =
* *[铜门](铜门.md)**
* 铜门及其变种现在需要使用石质工具挖掘。
* 铜门及其变种现在不再能由斧加速挖掘。
* 铜门及其变种现在不再能作为燃料。

* *[试炼刷怪笼](试炼刷怪笼.md)**
* 更改了底部纹理以匹配。

# = 物品 =
* *[沉重核心](沉重核心.md)、[三叉戟](三叉戟.md)和[重锤](重锤.md)**
* 现在[稀有度](稀有度.md)为“史诗”。<ref></ref>

* *[旗帜图案](旗帜图案.md)**
* 现在猪鼻旗帜图案的稀有度为“少见”。
* 现在涡流旗帜图案和旋风旗帜图案的稀有度为“稀有”。

# = 非生物实体 =
* *[末地水晶](末地水晶.md)**
* 现在末地水晶免疫火焰伤害。

# = 世界生成 =
* *[末地平台](末地平台.md)**
* 现在作为已配置的地物固定生成于(100,49,0)。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 风爆魔咒不再能通过弹射物攻击生效。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[标签](Java版标签.md)**
* 从方块及物品标签中移除了铜门及其变种，这使得方块标签也不再包含铜门及其变种。
