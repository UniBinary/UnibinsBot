# Java版12w07a

*页面ID: 32326* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w07a**是[Java版1.2.1](Java版1.2.1.md)的第6个快照，发布于2012年2月15日<ref></ref>，加入了[红石灯](红石灯.md)，更改了区域文件格式，提升了世界的最高建筑高度，更新了生物AI，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[红石灯](红石灯.md)**
* 被红石信号激活时开启。
* 可使用[荧石](荧石.md)和[红石](红石.md)合成。

# = 常规 =
* *区域文件格式**
* 现在使用[Anvil文件格式](Anvil文件格式.md)而不是MCRegion格式。
* * 世界文件现在以而非后缀保存。
* * 世界的最高建筑高度由128格增加到256格。
* * 现在最多可以使用4096个[方块ID](Java版数据值/扁平化前/方块ID.md)。

* *[语言](语言.md)**
* 重新加入了在[12w01a](12w01a.md)中被移除的马耳他语。

* ***
* 新的设置：
* * <code>max-build-height</code>

# 更改
# = 方块 =
* *[玻璃](玻璃.md)**
* 现在可以在其上放置[火把](火把.md)和[红石火把](红石火把.md)。

# = 物品 =
* *[锄](锄.md)**
* 当[泥土](泥土.md)和[草方块](草方块.md)上方有方块时不再能使之转化为[耕地](耕地.md)。

# = 生物 =
* *[掉落物](掉落物.md)**
* 降低了[生物](生物.md)掉落稀有掉落物的概率。

* *被动型[生物](生物.md)**
* 现在使用新的AI系统。
* * 现在它们走路时可以移动头部。
* * 幼年动物现在可以用[小麦](小麦.md)吸引。

# = 世界生成 =
* *[村庄](村庄.md)**
* [村民](村民.md)现在会根据[村庄](村庄.md)内的有效房屋数进行繁殖。
* * 玩家可以增加村庄内的有效房屋，其只要有屋顶和木门即判定为有效。
* 现在会发生[僵尸围城](僵尸围城.md)事件。

# = 常规 =
* *[多人游戏](多人游戏.md)**
* 多人游戏中的亮度计算系统不再会使客户端将某些方块视为透明。相反，现在客户端会自行重新计算亮度。
* * 这意味着区块错误不再能通过方块更新来解决。

# 修复
* *修复了3个漏洞**
* 修复了狼的AI系统：它们不再会在玩家受到攻击时传送非常远的距离了。
* 修复了僵尸会破坏铁门的问题。
* 修复了普通牛可以与哞菇繁殖的问题。</onlyinclude>
