# 基岩版1.2.13.8

*页面ID: 34039* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.2.13.8**是[基岩版1.2.13](基岩版1.2.13.md)的第3个测试版，发布于2018年3月16日<ref></ref>，通过[实验性玩法](实验性玩法.md)加入了首批[水域更新](水域更新.md)的特性，并修复了一些漏洞。

# 更改
# = 常规 =
* *[设置](设置.md)**
* 加入了[实验性玩法](实验性玩法.md)选项。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)后才可使用。

# = 方块 =
* *[楼梯](楼梯.md)和[台阶](台阶.md)**
* 加入了[海晶石](海晶石.md)、[海晶石砖](海晶石砖.md)以及[暗海晶石](暗海晶石.md)变种。

* *[去皮原木](去皮原木.md)**
* 原木的去皮变种。
* 通过对着原木斧获得。

* *[去皮木头](去皮木头.md)**
* 木头的去皮变种。
* 目前只能通过命令放置。

# = 物品 =
* *[三叉戟](三叉戟.md)**
* 通过杀死[溺尸](溺尸.md)获得。
* 可以投掷或作为近战武器。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了溺尸刷怪蛋。

# = 生物 =
* *[溺尸](溺尸.md)**
* 生成于[河流](河流.md)和[海洋](海洋.md)。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* [穿刺](穿刺.md)
* * 最高等级为V。
* * 适用于三叉戟，可以给位于水下或者雨中的生物造成额外伤害。

* [引雷](引雷.md)
* * 只有一级。
* * 适用于三叉戟，击中位于雨中的生物时会生成闪电。

* [激流](激流.md)
* * 最高等级为III。
* * 适用于三叉戟，位于水下或者雨中的玩家投掷时会发射自身。

* [忠诚](忠诚.md)
* * 最高等级为III。
* * 适用于三叉戟，投掷后会自动收回。

* *[游泳](游泳.md)**
* 新的游泳动画。

# 修复
* *修复了24个漏洞**
* 铁傀儡不再会在生物生成被禁用时生成。
* 玩家不再可以透过熔岩看见雨滴、烟雾粒子和实体影子。
* 在一个世界中禁用“对局域网内玩家可见”选项后，其他世界不再会一同禁用该选项。
* 复制处于“按住”状态的按钮时，复制出的按钮不再会一直保持此状态。
* 现在在导出世界时会出现一条警告，以提醒玩家不要退出游戏。
* 在转换Xbox One版的世界后，该世界中的红石中继器不再会丢失输出信号。
* 在其他槽位为空的情况下使用选项方块功能时，所选快捷栏槽位中的物品不再会被替换。
* 提升了稳定性，并修复了一些崩溃问题。
* 废弃矿井不再会生成在地表上。
* 修复了对着巨型蘑菇按下选取方块键时会获得错误的蘑菇方块的问题。
* 现在工具会正常生效，且不再会在手中晃动。
* 黏性活塞被重命名后不再会变回普通活塞。
* 绊线钩现在又会生成在丛林神庙中。
* 玩家现在又可以站在梯子上了。
* 玩家不再可以通过将生物头颅放置在水中来复制生物头颅。
* 现在要塞中又会生成苔石转和裂纹石砖了。
* Xbox One X上的最大渲染距离重新更改为22个区块。
* 现在告示牌上又可以输入三行文本了。
* 在皮肤选择器中不再需要按下两次按钮才能取消选择物品。
* 放置在墙上的生物头颅不再会具有不正确的碰撞箱位置。
* 丛林树上不再会生成隐形的藤蔓。
* 玩家现在又可以将火把放置在玩家所在方块的位置上了。
* 现在玩家在水中会更慢地下沉。
* 修复了有时不会渲染世界更新的问题。</onlyinclude>
