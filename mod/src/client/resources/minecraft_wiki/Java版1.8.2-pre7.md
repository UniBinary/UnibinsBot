# Java版1.8.2-pre7

*页面ID: 15540* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.8.2-pre7**是[Java版1.8.2](Java版1.8.2.md)的第7个，也是最后一个预发布版，发布于2015年2月16日<ref></ref>。

# 更改
# = 物品 =
* *[胡萝卜钓竿](胡萝卜钓竿.md)**
* 合成时将会移除钓鱼竿上的所有附魔。

# = 生物 =
* *[豹猫](豹猫.md)**
* 现在只能在海平面及以上生成，而不是在Y=63处生成。

* *[鱿鱼](鱿鱼.md)**
* 现在只能在海平面以下生成，而不是在Y=63处生成。

# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 离开一个服务器时会回到多人游戏界面而非菜单屏幕。
