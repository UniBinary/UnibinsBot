* *21w18a**是[Java版1.17](Java版1.17.md)的第20个快照，发布于2021年5月5日<ref></ref>，更改了[虫蚀方块](虫蚀方块.md)的破坏用时，略微调整了[预览数据包](预览数据包.md)中[矿石](矿石.md)和[洞穴](洞穴.md)的生成机制，并修复了一些漏洞。

# 更改
# = 方块 =
* *[虫蚀方块](虫蚀方块.md)**
* 不再能被瞬间破坏。<!-- 只能这么写。由于bug（MC-224927、MC-224972），徒手或用镐挖掘的表现不一致。 -->

* *[粗金块](粗金块.md)**
* 现在[猪灵](猪灵.md)会主动捡起掉落物形式的粗金块。
* 现在成年猪灵会与附近破坏粗金块的玩家敌对。

* *[光源方块](光源方块.md)**
* 更改了手持状态下的纹理。

# = 生物 =
* *[山羊](山羊.md)**
* 现在[尖叫山羊](山羊#生成.md)相比普通山羊有更高的概率发起冲撞攻击。
* 提高了幼年山羊的冲撞声的音高。

# = 世界生成 =
[缩略图|450px|矿石分布变化](File:21w18a approximate ore distribution.jpg.md)
本段落介绍的内容需加载[数据包](洞穴与山崖预览数据包.md)启用。

* *[矿石](矿石.md)分布**
* 略微降低了[铜矿石](铜矿石.md)的生成频率。
* 略微降低了中型[铁矿石](铁矿石.md)团簇的生成频率。
* 将小型铁矿石团簇的最大生成高度由-32提高至64。

* *[矿脉](矿脉.md)**
* 再次缩减了平均规模和生成频率。
* 提高了[粗金属块](粗金属块.md)在矿脉中的生成频率。

* *[洞穴](洞穴.md)**
* [雕刻器洞穴](雕刻器洞穴.md)现在能生成于[海洋](海洋.md)生物群系下方低于Y=0的区域。
* [面条洞穴](面条洞穴.md)不再生成于主世界Y=30以上的区域。
* 扩大了雕刻器洞穴和面条洞穴的最小规模。

* *[深板岩](深板岩.md)**
* 不再能够在主世界Y=0以上的区域呈团簇状生成。

# = 常规 =
* *[标签](Java版标签.md)**
* 将粗金块加入到和方块标签中。

* *[纹理](纹理.md)**
* 移除了未使用的[美西螈](美西螈.md)嘴部纹理。
* 正确地镜像处理了[山羊](山羊.md)的耳朵纹理。
