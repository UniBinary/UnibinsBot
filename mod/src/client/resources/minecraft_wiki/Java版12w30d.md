# Java版12w30d

*页面ID: 31689* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w30d**是[Java版1.3.1](Java版1.3.1.md)的第18个快照，发布于2012年7月25日<ref></ref>，主要修复了快照[12w30c](12w30c.md)的漏洞和崩溃，加入了树皮，大幅降低了从熔炉中可获得的经验值，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[树皮](树皮.md)**
* 只能通过命令获得。
* 六个面的纹理都为树皮。

# 更改
# = 方块 =
* *[木头](原木.md)**
* 木头现在可以以不同的朝向放置。

# = 游戏内容 =
* *[经验值](经验值.md)**
* 大幅降低了从熔炉中获得的经验值。

# 修复
* *修复了3个漏洞**
* 修复了非标准方块纹理平铺在<code>FallingSand</code>实体上时的显示问题。
* 修复了龙蛋下落时显示为熔岩的问题。
* 修复了被投出的喷溅药水在重载世界后不保存它们的类型的问题。</onlyinclude>
