* *凝灰岩（Tuff）**是一种纹理上多孔的岩石，生成于[主世界](主世界.md)的深处。

# 生成
# = 自然生成 =
凝灰岩会在主世界Y=0以下的区域呈[团簇](团簇.md)状生成，每[区块](区块.md)尝试生成2次，团簇大小为0-64个[方块](方块.md)。

凝灰岩还会在主世界Y=-60至-8的区域与[铁矿石](铁矿石.md)相伴生成，形成[铁矿脉](铁矿脉.md)。

# 获取
# = 箱子战利品 =

# 破坏
挖掘凝灰岩的合适工具是镐。凝灰岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

凝灰岩被破坏后会掉落自身。
