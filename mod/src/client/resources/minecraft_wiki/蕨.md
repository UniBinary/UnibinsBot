# 蕨

*页面ID: 152432* | *来源: Minecraft Wiki*

* *蕨（Fern）**是一种非[固体](固体方块.md)植物方块，常在[针叶林](针叶林.md)等生物群系生成。

# 生成
# = 自然生成 =
蕨会生成在[丛林](丛林.md)、[竹林](竹林.md)、[稀疏丛林](稀疏丛林.md)、[针叶林](针叶林.md)、[积雪针叶林](积雪针叶林.md)、[原始松木针叶林](原始松木针叶林.md)和[原始云杉针叶林](原始云杉针叶林.md)生物群系的草方块上。蕨在丛林、竹林和稀疏丛林中有25%的概率代替矮草丛生成，在针叶林、积雪针叶林、原始松木针叶林和原始云杉针叶林中有80%的概率代替矮草丛生成。

蕨也会在针叶林村庄和中生成。

# = 骨粉 =

对着一片上方为空气的[草方块](草方块.md)骨粉会使其自身和附近7格内（[切比雪夫距离](切比雪夫距离.md)）随机选取的草方块上方生成蕨。

# 破坏
蕨被挖掘时会立刻被破坏。

没有被[剪刀](剪刀.md)挖掘破坏时，蕨被破坏后有的概率会掉落1个[小麦种子](小麦种子.md)，挖掘工具的[时运](时运.md)魔咒每有1级，上限增加2。

被剪刀挖掘破坏时，蕨被破坏后会掉落自身。

# 用途
蕨可以种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。

蕨还可放在[花盆](花盆.md)里。

# = 绵羊 =

游戏规则为<code>true</code>时，[绵羊](绵羊.md)能够将蕨吃掉。被剪毛的绵羊会在吃掉蕨后重新长出羊毛。

# = 堆肥 =
将蕨放入堆肥桶里有65%的概率增加1个堆肥等级。
