# Java版Indev 20100206-2034

*页面ID: 172759* | *来源: Minecraft Wiki*

<onlyinclude>

* *Minecraft Indev**的第一个版本发布于2010年2月6日20:34（UTC）。<ref>[Adura的IRC记录](#logs.md): "(15:36:01) <Notch> ok, indev's been updated"</ref><ref></ref>加入了耕地、锄、种子、小麦作物和面包。

# 新内容
# = 方块 =
* *[耕地](耕地.md)**
* 通过在[泥土](泥土.md)、[草方块](草方块.md)上锄来生成。
* 会被[水](水.md)、无限水源和无限熔岩源润湿。
* 用于[生产](生产.md)。

* *[小麦作物](小麦种子.md)**
* 有8个生长阶段。
* * 在第8个阶段可以收获小麦。

# = 物品 =
* *[面包](面包.md)**
* 新的可食用物品。
* 可用6个小麦合成。
* 食用后恢复。

* *[锄](锄.md)**
* 用于生成耕地。
* 可由[木棍](木棍.md)和[木板](木板.md)、[圆石](圆石.md)、[铁锭](铁锭.md)、[金锭](金锭.md)或[钻石](钻石.md)来合成对应等级的锄。

* *[种子](小麦种子.md)**
* 用于放置小麦作物。

* *[小麦](小麦.md)**
* 可通过破坏成熟的小麦获得。
* 用于合成面包。

# = 游戏内容 =
* *[生产](生产.md)**
* 一种有目的、系统性地获取可再生资源的活动。

# 更改
# = 方块 =
* *[花](花.md)**
* 现在只能放置在正确的方块之上了。
* 当破坏掉其下方的方块时会被一同移除。

# = 物品 =
* *[蘑菇煲](蘑菇煲.md)**
* 现在恢复生命值。

* *[羽毛](羽毛.md)**
* 更改了纹理。

* *金质工具**
* 略微更改了纹理。

* *[苹果](苹果.md)**
* 现在使用金头盔的纹理。

# = 游戏内容 =
* *[平视显示器](平视显示器.md)**
* 游戏版本不再为0.31，而是被更恰当地重命名为“Minecraft Indev”。

* *常规**
* 更改了放置[方块](方块.md)时的手臂摆动动画。
* 每次右击时游戏都会尝试放置方块。
* * 如果方块在[玩家](玩家.md)可触及范围内，即使方块无法被放置，玩家的手臂仍然会摆动。
* 在挖掘过程中切换工具不再导致方块被瞬间破坏。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 添加了“C”，“F”，“O”，“B”，“I”和“T”六种新参数。<ref></ref>
* * “C”：屏幕上渲染的区块数/总区块数。
* * “F”：玩家视野之外的区块数。
* * “O”：被遮挡剔除的区块数。
* * “B”：位于不可见区块中的实体数。
* * “I”：被单独剔除的实体数。
* * “T”：“地形和光照数据”。

* *[主菜单](主菜单.md)**
* 标题屏幕上的泥土背景不再向上滚动了。

* *[世界加载屏幕](世界加载屏幕.md)**
* 加入了泥土背景。

* *[控制](控制.md)**
* 按下现在能正常暂停游戏了。

* *[迷雾](迷雾.md)**
* 移除了“远”渲染距离中的非常微弱的迷雾效果。

* ***
* 添加了金盔甲的纹理。
* 添加了钻石盔甲的纹理。
* 移除了皮革链甲的纹理。

* 修复了生物倒着走路的漏洞。</onlyinclude>
