# Java版17w17b

*页面ID: 29602* | *来源: Minecraft Wiki*

<onlyinclude>

* *17w17b**是[Java版1.12](Java版1.12.md)的第9个快照，发布于2017年4月27日<ref></ref>，加入了新的NBT标签和新的进度触发器，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[NBT标签](NBT标签.md)**
* 为可繁殖的生物添加，标签。
* * 这两个标签一起记录使动物进入繁殖状态的实体的[UUID](UUID.md)。

* *[进度](进度.md)**
* 现在某些进度在完成前会用数字显示完成进度。
* 加入了触发器。
* * 两种可用条件：和，都允许"overworld"、"the_nether"或"the_end"为参数。
* * 无条件时，你能够检查玩家是否在穿越维度。
* “位置”共享对象现在有了一个名为的新的字符串（和上述内容有相同的值）。

# 更改
# = 常规 =
* *[进度](进度.md)**
* 默认的进度现在从本地化文件中获取标题和简介。

# 修复
命令的使用提示信息没有被翻译。
|115392|在局域网世界中，只有主人才能解锁进度。
|115505|不会在嵌入世界文件夹的资源包中寻找进度的背景。
|115710|在骑乘载具时快速按跳跃键会使玩家看不到肩膀上的鹦鹉。
|116143|不需要进入下界就可以获得“下界”进度。
|116616|在繁殖动物后保存并重新进入世界时，<code>bred_animals</code>触发器不起作用。
|116683|命令方块界面上没有提及@s选择器。
|;previous
|116654|“”进度实际检测的是烈焰棒而不是凋灵骷髅头颅。
|116656|在末影龙重生过程中关闭世界后再打开它会导致崩溃。
|116661|在弹出消息中，长进度标题会被截断。
|116665|命令自动补全出的内容不正确。
|116671|具有<code>durability</code>选项的基于物品的触发器对于具有耐久度的物品不起作用。
|116676|鹦鹉不会模仿幻术师的声音。
|116700|当玩家踏上传送门时就可以获得“末地”进度。
