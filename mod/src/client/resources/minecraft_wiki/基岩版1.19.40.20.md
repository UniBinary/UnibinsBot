# 基岩版1.19.40.20

*页面ID: 98452* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.40.20**（Android）、**Preview 1.19.40.20**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.40](基岩版1.19.40.md)的首个测试版，发布于2022年9月8日<ref></ref>，更新了触摸控制，并修复了一些漏洞。

# 更改
# = 游戏内容 =
* *[双持](双持.md)**
* 现在可以使用命令将任意物品放进副手槽里，且部分物品可以像在主手时那样正常交互。

# = 常规 =
* *[触摸控制](触摸控制.md)**
* 现在当启用自动跳跃时，玩家在水中朝着陆地上的一格方块移动时会自动跳出水面。
* 将创造模式下关闭操作按钮并使用触控操作时破坏第一个方块的延时提高到800ms，以减少方块的误破坏。
* 现在使用触控也可以在物品栏中拖拽来放置物品。
* 优化了使用触摸控制时长按一组物品来将物品分开的体验。
* 现在可以在新触控模式下双击下降按钮以取消飞行状态。
* 优化了UI下[状态效果](状态效果.md)的显示位置。
* 在水中前进时不再自动上浮。
* 现在单击一次槽位时会自动将其中的物品放入物品栏，无需再点击物品栏相应的槽位。

# = 技术性 =
* *数据驱动物品**
* 带有<code>minecraft:digger</code>组件的自定义物品、标签和方块标签现在会正常生效。（）

* *活动对象**
* 实现了新的<code>is_baby</code>活动对象过滤器，当主实体是幼年状态时返回true。

* *AI意向**
* 修复了铁傀儡会阻止带有<code>minecraft:take_flower</code>AI行为的生物使用该意向的漏洞。
* 公开了<code>minecraft:play</code>AI行为的新数据参数，可以指定意向保持活跃的持续时间、开启意向的概率、寻找友方的范围，以及与友方一起玩耍时的跟随距离。

# 修复
* *原版趋同**
* 旁观模式玩家死亡时不再掉落经验球。（）
* 旁观模式玩家死亡时不再重置其经验等级。
* 现在被重命名的武器杀死时会出现带着该武器名称的死亡消息。
* 现在黑森林、风袭热带草原和桦木森林会使用正确的草-{}-地颜色。（）

* *辅助功能**
* 快捷栏物品文本背景现在会受文本背景不透明度滑块影响。（）

* *远古城市**
* 远古城市范围内不再生成生物。（）

* *教育版内容**
* 现在NPC的名称默认只会在玩家看向NPC时显示。

* *游戏内容**
* 下落在双层台阶上的下落的方块不再会变成掉落物。（）
* 现在在使用键盘游玩时，向左前方或右前方移动也可以疾跑。（）
* 修复了巨型下界菌在菌岩上长出时菌柄可能会替换掉不完整方块的漏洞。（）
* 修复了红石会在某些情况下输出错误的信号强度的问题。（）
* 修复了在世界建造高度限制附近使用黏性活塞时出现的一些漏洞。（）

* *常规**
* 修复了用户名可能会超过最大长度限制的漏洞。（）

* *图形**
* 放置在其他方块下的含水方块的水的纹理不再渲染得太亮。（）
* 修复了Android设备的屏幕位置的潜在问题。（）

* *物品**
* 修复了在加载带有未识别数据值的箭时导致游戏崩溃的漏洞。（）

* *生物**
* 幼年村民现在又可以拿走铁傀儡手上的花了。
* 守卫者不再能够悬浮在空中。（）
* 现在已驯服的生物会跟随玩家进入末地传送门。
* 现在雪林生物群系被归为寒冷生物群系，生成在此处的村民会使用雪原皮肤。（）

* *档案**
* 移除了非Switch平台设置菜单中的仅适用于NS的“清除账户登录数据”按钮。（）

* *用户界面**
* 将“档案”设置拆分为“通用”和“帐户”。
* 改进了文本转语音对新死亡屏幕的支持。
* 修复了某些世界模板会禁用成就的漏洞。
* 修复了导致玩家在使用VR Snap相机移动后转向错误方向的漏洞。（）

* *世界与维度**
* 修复了导致船进入传送门后消失的漏洞。（）

* *命令**
* 修复了传送会使目标看起来像飞到新的位置而不是瞬间到达的问题。
* 在命令中加入了<code>replace block</code>重载。
* 为命令加入了用特定的自定义方块属性设置自定义方块的能力。

* *稳定性和性能**
* 修复了当结构方块加载一个动画结构，且玩家进入传送门离开维度时可能发生的崩溃 。（）</onlyinclude>
