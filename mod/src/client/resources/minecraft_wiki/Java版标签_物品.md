# Java版标签/物品

*页面ID: 159644* | *来源: Minecraft Wiki*

* *物品标签（Item Tags）**是[物品](物品.md)的组合。

# 使用
物品标签常用于物品类型的判断。例如物品谓词、[配方](配方.md)原料、命令等。只要物品在此标签内，测试就会成功。

在创造模式物品栏中，可以使用<code>-{}-#<*任意文字*></code>来依靠标签搜索物品。

游戏也使用物品标签控制了一些游戏行为。
