# Java版12w30b

*页面ID: 31697* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w30b**是[Java版1.3.1](Java版1.3.1.md)的第16个快照，发布于2012年7月23日<ref></ref>，修复了快照[12w30a](12w30a.md)的一些漏洞和崩溃。

# 修复
* *修复了3个漏洞**
* 修复了<code>Null Pointer Exception</code>问题。
* 修复了不能在方块上使用右键的问题。
* 修复了放置在其他箱子上的箱子不能打开的问题。</onlyinclude>
