# 命令

*页面ID: 9161* | *来源: Minecraft Wiki*

|[Duncan Geere](Duncan Geere.md)<ref></ref>||Duncan Geere Mojavatar.png}}

* *命令（Command）**，也被称作**控制台命令（Console Command）**或**斜杠命令（Slash Command）**，是通过输入特定文本字符串使用的進階功能。

# 使用
[缩略图|右|选取实体的[[UUID](File:Select UUID.gif.md)]]
在客户端中，命令通过Minecraft的[聊天](聊天.md)窗口输入。按下键、键（默认）、|be}}可以唤出聊天窗口。使用键会同时输入命令**必需**的前缀斜杠（<code>/</code>），因此是个实用的快捷键。和键可浏览之前输入的文本，包含所有之前执行的命令。在输入命令时按下键会循环显示当前可用的命令或参数，也可以快速输入准星当前指向方块的坐标（输入实体参数时，如果准星指向某个实体，则可以直接输入其[UUID](UUID.md)）。当光标在某些参数（比如一个ID）的对应位置时，在文本框上方会展示一个可用值的列表。若该参数已经输入了一半，这个列表则只会展示包含当前输入内容的值。

在[命令方块](命令方块.md)中，命令**可以**以前缀斜杠开头，但不是必须的。

命令也可以在多人[服务器](服务器.md)的控制台中输入，但是**不該**加入前缀<code>/</code>。

命令可通过以下方式执行：
* 玩家直接通过聊天框输入命令。
* 通过[命令方块](命令方块.md)或者[命令方块矿车](命令方块矿车.md)。
* 在专用[服务器](服务器.md)中，通过控制台键入命令。
* 在[函数](函数.md)中，作为或的一部分。
* 在行为包的脚本中。
* 在行为包的动画控制器中。
* 在行为包的方块事件响应中。
* 在行为包的实体事件响应中。
* 点击具有<code>run_command</code>行为的[文本组件](文本组件.md)。
* 由连接到客户端的WebSocket服务器请求执行。
* 通过[NPC](NPC.md)对话框执行。

# = 语法表示 =
每条命令都由若干以空格隔开的片段组成。以下格式用以辅助表示命令语法中各片段的含义。关于某条命令的具体语法，请点击[命令列表](#命令列表及其概述.md)中的链接。

：

例如，<code>[<size>]</code>是可选的参数，而<code>[size]</code>是可选的字面量。

以<code>advancement (grant|revoke) <targets> only <advancement> [<criterion>]</code>为例，其中<code>advancement</code>和<code>only</code>是需要原样输入的字面量，<code>(grant|revoke)</code>是需要从<code>grant</code>和<code>revoke</code>中选择一个输入的字面量，<code><targets></code>和<code><advancement></code>是必需的以合适值替换的参数，<code>[<criterion>]</code>是可选的以合适值替换的参数。

：

其中尖括号修饰符（{{code|-{}-<输入项>}}）一般不修饰，必选的字面量不需添加修饰符。例如，<code>set</code>和<code><set></code>都表示必选的字面量，但后者不会在游戏中出现。而<code><size: int></code>是必选的参数。

在和中，方括号都表示可选。被方括号修饰的输入项只能位于命令末尾，不会出现在命令中间。命令结尾允许并列出现多个方括号，如位于命令结尾的<code>a [b] [c]</code>表示只有<code>a</code>、<code>a b</code>和<code>a b c</code>三者是合法的。

# = 限制条件 =
绝大部分命令要求执行上下文要有足够的[权限等级](权限等级.md)，这就意味着大部分命令在单人游戏中只有在开启作弊的情况下才能被使用，并且在多人游戏服务器中需要玩家是管理员时才能使用。详见[权限等级](权限等级.md)。

一些命令对当前的游戏和世界有限制。
* **无**：无限制条件。
* **启用作弊**：仅适用于基岩版。当由**服务端或脚本**（控制台、[计划执行的函数](命令/schedule.md)、[tick.json中的函数](函数.md)）执行时，无论是否启用作弊均可执行相应命令。当以其他方式执行时，相应命令仅在存档启用作弊时才可用。禁用作弊后，除非由服务端或脚本执行，否则即使执行者具有较高的[权限等级](权限等级.md)也无法使用相应命令。
* * 作弊影响玩家的[权限等级](权限等级.md)。权限等级还受其他因素的影响，只要拥有足够高的权限等级，无论此存档是否开启作弊，玩家都可以使用相应命令。
* **仅专用服务器**：此命令只能在专用服务器中执行。
* **非专用服务器**：此命令不能在专用服务器中执行。

# == 作弊 ==
[创建新的世界](创建新的世界.md)时，可以通过”}}或”}}选项启用作弊。

创建新的世界时的“”选项仅影响离线单人世界的玩家或局域网世界的所有者。时的“”选项会影响局域网世界中的所有玩家。

若当前的离线单人游戏未开启作弊，可在公开目前的游戏至局域网时将“”设为开而暂时开启作弊。若要永久开启作弊，必须修改[level.dat](level.dat.md)文件。

作弊可以随时使用设置菜单中的选项切换。开启作弊会导致玩家在该世界永远无法获得[成就](成就.md)，即使后来再关闭作弊也一样。

# = 解析与执行 =
游戏服务端处理命令的过程分为**解析（Parsing）**和**执行（Execution）**两个阶段。在解析阶段，游戏将字符串识别为某个命令，并检查命令是否完整以及参数被是否正确地指定。在执行阶段，命令发挥其功能。

当玩家在聊天框、[命令方块](命令方块.md)或者[命令方块矿车](命令方块矿车.md)中输入命令时，命令也会先在**客户端**解析，以提供自动补全并帮助玩家提前发现错误。
* 当在聊天栏输入参数时，若一个参数无法**被客户端**解析，则会向玩家发出提示。然而，能被客户端解析，并不能保证此参数能被服务端解析。
* * 若某一个参数无法被客户端解析，该参数及之后的所有部分都将被标记为红色，聊天栏上方会显示语法错误信息。
* * 若某一个参数无法被客户端解析，则语法提示中的下一个参数将从灰色变为白色。若已输入所有参数（包括可选参数），那么整个语法提示都将从白色变为灰色。
* 在[命令方块](命令方块.md)中输入命令也有如上的行为。在[命令方块](命令方块.md)中输入命令只会提供自动补全而无语法提示。
* 在聊天框输入命令时，若某两个参数之间存在多个空格，行为同上，但会在执行时和命令历史中将其修正为单个空格。

当在一个命令方块中输入命令后，在关闭命令方块界面后，命令立即在服务端进行解析。若无法解析，会把一个错误信息输出到命令方块的输出框中。

当尝试执行一个无法解析的命令时，游戏将显示错误信息。
* 提示信息的末尾为“**”。
* 提示信息为“”或“”。

[函数](函数.md)中的命令会在加载函数时全部解析，如有任一行命令无法解析，则此函数将无法被加载到游戏中。宏行则是在函数尝试运行时再根据提供的参数进行解析，详见和。

如果脚本中存在无法解析的命令，则在尝试执行该命令时会抛出错误。

# == 输出 ==
命令在尝试执行时会产生**输出值（Output）**。输出值包括**成功次数（Success Count）**和。

成功次数是指命令在命令方块中执行时传出的值。传给命令方块后，成功次数可以由背对命令方块的红石比较器检测（两者可间隔一个[红石导体](红石导体.md)方块），比较器的输入信号强度等于最后一次执行的命令的成功次数。即便命令方块取消激活，成功次数依旧保留，直到再次执行命令，因此比较器能够持续接收同一信号强度的输入。无法在命令方块中执行的命令没有成功次数。即使该命令无法被命令方块或脚本执行，它依旧存在成功次数，只不过无法获取。命令的成功次数通常是0或1，唯一例外是命令。成功次数为0到2,147,483,647（含）之间的整数，与所执行的命令有关（例如，被命令所影响的玩家数、改变的方块数等）。

储存值有两个：**值**和**值**，是命令在执行其他命令的过程中，其他命令传给命令的值。这两个值可以由命令中的子命令储存到指定位置。值只能为0或1。则是一个整数（若不是，则会被向下取整）。所有命令在执行后都有这两个储存值，除了两个例外：本身在不包含<code>if</code>或<code>unless</code>子命令时没有这两个储存值；命令在特定情况下没有这两个储存值。

# == 结果 ==
尝试执行命令后会产生不同的结果，包括无法解析、执行失败、执行成功、。

; 无法解析
   在服务端解析命令时，当前游戏、世界或执行上下文不满足命令的[限制条件](#限制条件.md)，或输入的命令不完整，或存在无法解析的参数，此命令就无法解析。

; 执行出错
   若一个命令执行出错，则意味着该命令存在明显的漏洞。此时会输出“”，并可能会出现其他的副作用（如[崩溃](崩溃.md)），命令也会被中途打断，导致分支未能全部执行。
   从技术上来说，执行出错即该命令在执行时抛出了除<samp>brigadier.exceptions.CommandSyntaxException</samp>以外的异常。

; Void
   仅存在于命令。命令没有值和值可供命令存储时，称该命令执行结果为Void（无返回值）。

; 执行中断
   仅存在于命令。即在执行一个命令的过程中，[执行分支](命令/execute#执行分支.md)数量变成了0，在执行末尾的子命令前就已经停止，称为执行中断。
   比如在命令方块中执行，由于命令方块不是实体，无法被[目标选择器](目标选择器.md)选中，因此该命令中断于。

; 执行失败和执行成功
   若命令不是无法解析、执行错误、Void或执行中断，则该命令的结果可分为执行失败或执行成功。若此时该命令的成功次数为0，则命令执行失败。否则，命令执行成功。
  * 如果该命令无法被命令方块执行，则当储存<code>0</code>时命令失败，当储存<code>1</code>时命令成功。
  * 即使该命令无法被命令方块或脚本执行，它依旧存在成功次数，只不过无法获取。
   请注意：
  *只有在命令不是无法解析、执行错误、Void或执行中断时，才存在执行失败和执行成功。尽管当无法解析、执行出错、Void或执行中断时，命令的成功次数为0，但它不被视为执行失败，也不是执行成功。
  *并非所有的“执行成功”的命令都会使世界有所改变，“执行失败”的命令也不意味着命令什么也没有做。
