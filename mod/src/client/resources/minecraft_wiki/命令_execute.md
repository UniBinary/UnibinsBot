# 命令/execute

*页面ID: 39774* | *来源: Minecraft Wiki*

是各不同功能的子命令的集合，用于改变[命令执行上下文](命令上下文.md)（[修饰子命令](#修饰子命令.md)），执行逻辑判断（[条件子命令](#条件子命令.md)）和，并在此基础上执行任意其他命令。

# 用法
# = 子命令 =
<code>/execute</code>命令有/条子命令。子命令按功能可分为以下几类：
* [修饰子命令](#修饰子命令.md)：修改命令上下文以改变命令执行时的状态，从而以特定的执行位置、执行基准点、执行者、执行朝向、执行维度执行后续子命令。
* [条件子命令](#条件子命令.md)：检测特定条件是否成立并输出结果，或限制子命令执行的条件。
* [存储子命令](#存储子命令.md)：将命令返回值存储至[方块实体](方块实体.md)、[实体](实体.md)或存储容器的NBT数据中，[记分板](记分板.md)的记分项中，或[Boss栏](Boss栏.md)的当前值或最大值中。
* [子命令](#run子命令.md)：执行其他命令。

子命令可以在后串连在一起使用，可出现在命令的任意位置及重复任意次数。但子命令除外，其只能位于末尾且只能使用一次，同时可用于嵌套执行。

命令的结尾必须为条件子命令或子命令，否则命令不可解析。

各子命令按其在命令中的顺序被依次处理，下列命令中子命令虽然一致，但由于顺序不同，会产生不同效果：
* ：所有实体向各自所朝方向移动一格。
* ：所有实体移动到执行者前方一格。

# = 执行分支 =
有些子命令，可以将命令的执行过程**分叉（Fork）**为多个**分支（Branch）**，也就是使得后续的子命令被多次执行。例如，如果子命令选中了多个实体，那么每个实体都会执行一次后续的子命令。

如果一个命令没有被分叉，我们称它只有一个分支——**主分支**。

有些情况下，一个分支会**执行中断**，并且什么也不做（不执行子命令和）。例如，条件子命令的条件没有达成，或是子命令没有选中实体，等等。一个分支中断时会显示一条红色的消息。如果所有的分支都中断了，我们就说这个命令本身[执行中断](命令#结果.md)。

注意：<code>... run execute ...</code>在任何情况下都不会起任何作用。例如下面的两个命令，效果都是一样的：
* armor_stand] as @e[typearmor_stand] run summon armor_stand}}
* armor_stand] run execute as @e[typearmor_stand] run execute run execute run summon armor_stand}}

然而，和的分叉方式并不一样。<ref></ref><ref></ref>
* 游戏会[广度优先](wzh:广度优先搜索.md)地处理子命令，也就是按顺序逐个处理子命令。所以游戏会在处理<code>run</code>子命令之前处理完其他的子命令，于是，<code>run</code>子命令无法影响到其他的子命令。
* 游戏会[深度优先](wzh:深度优先搜索.md)地处理子命令。也就是说，命令执行分叉以后，后续的所有子命令会作为一个整体，每个分支执行一次。
* 例如，如果世界上有两个盔甲架（A和B），一个玩家执行了<code>execute as @e[type=armor_stand] as @e[type=armor_stand] run summon armor_stand</code>，和的行为如图所示：

可以利用达到深度优先的效果，例如：
* 世界上有两个盔甲架，一个玩家执行了<code>/execute as @e[type=armor_stand] run function test</code>，其中函数<samp>test</samp>的内容是：
* * <code>execute as @e[type=armor_stand] run summon armor_stand</code>
* 这样的效果和中的<code>/execute as @e[type=armor_stand] as @e[type=armor_stand] run summon armor_stand</code>是一样的。
暂时无法做到广度优先地执行子命令。

# = 输出 =

# == 储存值 ==

一条分支在完整执行后（没有发生执行中断）会输出<code>success</code>值和<code>result</code>值（另见[命令#输出](命令#输出.md)）。这两个输出值：
* 是各执行分支的输出值，而非命令本身的；
* 均来自结尾的条件子命令或子命令中的命令；
* 均为整数，遇小数时向下取整，总为0或1；
* 如果结尾的子命令在一个分支中执行失败，则此分支的这两个值均为0；
* 均可由存储子命令存储。

请注意，这两个值来自结尾的条件子命令或子命令中的命令，是每个分支的输出值，而非整条命令的。

若使用子命令执行命令，在某些条件下没有这两个输出值。详细信息参见。

如果在储存子命令之后命令执行被分叉，则储存操作将应用于每个分支。每个分支的输出值都会在此分支执行完后被储存。如果所有分支的存储位置相同，则后执行的分支的输出会直接覆盖先执行分支的输出，而不是累加，所以在执行整个命令后，此存储位置最后的值是最后执行的分支的输出。

# == 成功次数 ==
像大多数命令一样，<code>/execute</code>命令（无论是否执行中断）本身也有一个**[成功次数](命令#输出.md)**。成功次数：
* 是命令本身的输出值，而非各执行分支的；
* 来自结尾的条件子命令或子命令；
* 各分支的值会被累加；
* 为大于等于0的整数；
* 当使用命令方块执行<code>/execute</code>时，成功次数会返回到命令方块中，可用条件制约的命令方块检查，或用[红石比较器](红石比较器.md)读取成功次数。

# 条件子命令

条件子命令包括和两种，用于测试特定类型的条件。两者的语义相反但参数结构一致，表示“如果……就”，表示“除非……否则”。

条件子命令可以单独使用，也可以与其他子命令一起使用，根据其处于整条命令中的位置，其行为也有区别：
* 位于整条命令的末尾时，条件子命令会直接输出测试结果。
* 不位于整条命令的末尾时，条件子命令会根据自身语义与测试结果，决定后续子命令是否执行。
* * 若由多个变量（如执行者、执行位置、执行朝向）执行多次时，可作为变量过滤器使用。

可用条件类型：
* ：检测给定位置上的生物群系是否为特定生物群系。
* ：检测给定位置上的方块是否是特定的方块或方块状态。
* ：检测给定区域内的方块是否匹配另一个同等大小区域内的方块。
* ：检测方块、实体或存储容器是否拥有给定的NBT标签。
* ：检测命令执行时所处的维度是否为特定维度。
* ：检测一个或多个特定实体是否存在。
* ：检测函数是否有非零返回值。
* ：检测方块或实体的给定物品栏槽位或槽位区间内是否拥有指定物品。
* ：检测给定位置是否已被加载。
* ：检测谓词计算结果是否为正。
* ：检测指定目标的记分板中的记分项的分数是否与另一个（或同一个）目标的记分板的记分项的分数是否符合指定的关系，或者是否在给定的范围之内。
* ：检测指定ID的秒表的时间是否在给定的范围之内。

  : 当仅给出一个函数时，如果该函数不是宏函数，也不是 Void函数，并且其[返回值](函数#返回值.md)不为 0：

  :* 如果该函数返回失败结果，或者返回值为0的成功结果，则结束此子命令的执行，同时<code>if</code>会终止当前分支，而<code>unless</code>不会执行任何操作。
  :* 如果该函数返回成功结果且其返回值不为0：则结束此子命令的执行，同时<code>if</code>不会执行任何操作，而<code>unless</code>会终止当前分支。

  ; 输出

  ; 示例
  * ：检测秒表的时间是否在10秒内。

# 存储子命令

存储子命令可以将最后一个子命令执行后产生的或值存储到指定位置。

它与其他子命令一起处理，先行记录存储位置，不影响其他子命令。它能够将最后一个子命令执行后产生的返回值存储到指定位置（可以是[记分板](记分板.md)、NBT数据或[Boss栏](Boss栏.md)）。

可用存入位置：
* ：将或存入指定方块实体的指定NBT标签内。
* ：将或存为Boss栏的当前值或最大值。
* ：将或存入指定实体的指定NBT标签内。
* ：将或存入指定分数持有者的指定记分项上。
* ：将或存入指定存储容器的指定NBT标签内。

   将或存入指定[方块实体](方块实体.md)的指定NBT标签内。

  ; 参数
  : ：
  :: 返回值需要存入的目标方块实体的坐标。
  ::
  : ：
  :: 返回值需要存入的NBT路径。
  ::
  : ：floatshortlongdoublebyte)}}
  :: 返回值及目标NBT的数据类型。
  :: 只能为之一。分别表示整型、单精度浮点型、短整型、长整型、双精度浮点型和字节型。
  : ：
