# Java版18w48a

*页面ID: 37487* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w48a**是[Java版1.14](Java版1.14.md)的第9个快照，发布于2018年11月29日<ref></ref>，先前加入的一些装饰性方块能自然生成在村庄中，更改了一些物品的纹理，并修复了一些漏洞。

# 更改
# = 方块 =
* *[木桶](木桶.md)、[钟](钟.md)、[高炉](高炉.md)、[酿造台](酿造台.md)、[制图台](制图台.md)、[制箭台](制箭台.md)、[讲台](讲台.md)、[织布机](织布机.md)、[烟熏炉](烟熏炉.md)、[锻造台](锻造台.md)、[切石机](切石机.md)**
* 现在会自然生成在[平原](平原.md)村庄中。

* *[草径](草径.md)**
* 更改了顶部纹理。

* *[砂轮](砂轮.md)**
* 现在会自然生成在村庄的铁匠铺中。
* 更改了纹理。
* 现在可用木棍、石台阶和木板合成。
* 其GUI拥有2个输入栏和1个输出栏。
* * 可以将2个损坏物品合并为1个，也可以移除非诅咒魔咒。移除魔咒时会得到一些经验。

* *[藤蔓](藤蔓.md)**
* 现在可以在没有支撑方块的情况下攀爬。

# = 生物 =
* *[村民](村民.md)**
* 略微更改了一些交易。

* 为村庄加入了新的结构文件。

# = 常规 =
* *[合成](合成.md)**
* 移除了合并损坏工具的合成配方，被砂轮取代。

* *[主菜单](主菜单.md)**
* 更改为新的村庄背景。
