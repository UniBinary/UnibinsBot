# 原主机版TU23、CU11、1.15

*页面ID: 81543* | *来源: Minecraft Wiki*

* *TU23/CU11/1.15**是[原主机版](原主机版.md)的一次更新，发布于2015年3月25日，修复了一些漏洞。<ref></ref><ref></ref>

# 新内容
# = 常规 =
* *[纹理包](纹理包.md)**
* XBONE、PS3、PS4、PSV：加入了图案纹理包试用内容。
* *[混搭包](混搭包.md)**
* PS3、PS4、PSV：加入了质量效应混搭包试用内容。

# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* PS3、PS4、PSV：在生存模式中加入了*Where Are We Now*音乐唱片。

# = 游戏内容 =
* *[控制](控制.md)**
* PS3、PS4、PSV：加入马的物品栏的快速移动。

# 更改
# = 方块 =
* *[青金石块](青金石块.md)**
* PS3、PS4、PSV：更新了纹理。

# = 生物 =
* *[僵尸](僵尸.md)**
* PS3、PS4、PSV：修正了幼年僵尸判定箱大小。

# = 游戏内容 =
* *主机权限<!-- en: Host privileges -->**
* PS3、PS4、PSV：修改了玩家权限。

# 修复
* *修复了9个漏洞**
* XB360、XBONE、PS3、PS4：修复了分屏时间歇性的看不见玩家和生物的漏洞。
* XB360、XBONE、PS3、PS4：修复了延长游戏时间后分屏崩溃的漏洞。
* 修复了用户客户端挂起时生成凋灵的漏洞。
* 修复了红石比较器的图形问题。
* XBONE、PS3、PS4、PSV：修复了钓鱼时的崩溃。
* PS3、PS4、PSV：修复了放置活塞、发射器、投掷器的问题。
* PS3、PS4、PSV：修复了箱子被摧毁却未消失的漏洞。
* PS3、PS4、PSV：修复了玩家在船上受到摔落伤害的漏洞。
* PS3、PS4、PSV：修复了狼可以传送到船上的玩家并杀死玩家的漏洞。
