# 命令/locatebiome

*页面ID: 52402* | *来源: Minecraft Wiki*

在聊天框中为命令执行者显示指定[生物群系](生物群系.md)的最近坐标和距离。

# 语法
* **Java版**
  <code>-{}-locatebiome <*生物群系ID*></code>

# 参数
<code>-{}-*生物群系ID*</code>

   指定要定位的生物群系或生物群系标签。参见[生物群系/ID](生物群系/ID.md)以查看所有可用的生物群系ID。
