# Java版14w11a

*页面ID: 33898* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w11a**是[Java版1.8](Java版1.8.md)的第17个快照，发布于2014年3月13日<ref></ref>，加入了末影螨，做了一些调整，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[末影螨](末影螨.md)**
* 外形与蠹虫相似，但身体是紫色的并会发出末影粒子。
* 末影人会攻击末影螨。
* 有概率会在末影人传送时出现。
* 会在2分钟后消失。
* 有概率在[末影珍珠](末影珍珠.md)落地时生成。
* 尚未完成——将来也能和龙蛋互动。<ref></ref>
* * 模型将在下个快照中更改。<ref></ref>

# 更改
# = 方块 =
* *常规**
* 现在在内部使用状态而非元数据。
* 元数据仍会被使用一段时间。
* 方块状态会在调试屏幕中显示。
* 在内部，元数据不再需要通过4位的数据值来被计算出，而某个属性的数值现在能够被简单地获取和设置了。

* *方块[模型](模型.md)**
* 转换了栅栏门和酿造台。
* 亮度现在也和模型兼容了。

* *图像**
* 在图像设置为快速时，掉落物现在会在所有3个方块面向玩家。

* *[栅栏门](栅栏门.md)**
* 在物品图标里会展示两个洞。

# = 生物 =
* *[女巫](女巫.md)、[骷髅](骷髅.md)、[僵尸](僵尸.md)、[僵尸猪人](僵尸猪人.md)和[苦力怕](苦力怕.md)**
* 现在会逃离准备爆炸的苦力怕了。

* *[末影人](末影人.md)**
* 移动速度稍微变快了。

* *[蠹虫](蠹虫.md)**
* 现在会在移动之前短暂停住（与大多数生物相似）。

* *[史莱姆](史莱姆.md)**
* 跳跃变得更随机。

# = 非生物实体 =
* *[矿车](矿车.md)**
* 更改了矿车的物理性质。
* * 矿车现在能移动得更快并走得更远。
* * 改进了碰撞和方位处理。
* * 矿车在高速转弯时会脱轨，或在上坡时反弹。

* *[动力矿车](动力矿车.md)**
* 现在会给其他矿车更强的推力。
* 在启动后，它们能穿过未充能的[动力铁轨](动力铁轨.md)且不会变慢。

* *[TNT矿车](TNT矿车.md)**
* TNT矿车的爆炸不再能堆叠了。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 在看着一个方块时，屏幕的右方会显示额外信息和NBT数据。
* 盯着门和红石时会显示方块的状态。
* * 门：面朝的方向，是否开启，盯着那个部分，是否被充能，合页的位置。
* * 红石：东南西北各个方向的充能位置（上、下、旁、无）和能量等级。
* 尚未100%完成，目前缺失很多方块的数据。
