* *下界传送门（Nether Portal）**方块是一种构成[下界传送门](下界传送门.md)的半透明方块，能够传送玩家进出[下界](下界.md)。

# 生成
# = 下界传送门 =
下界传送门方块是激活的下界传送门结构的一部分。

# 获取
下界传送门方块没有对应的物品形式。

下界传送门方块的物品形式只能通过编辑物品栏获得。

# 破坏
下界传送门不能被挖掘破坏。

下界传送门被破坏后不会掉落。

# 用途

[缩略图|下界传送门方块的动画|class=pixel-image](File:NetherPortal.gif.md)

下界传送门不能被[凋灵](凋灵.md)破坏。

下界传送门方块只能够在下界传送门结构里出现。当此方块被更新（需要平行方向的[PP更新](方块更新#PP更新.md)），同时被检测到不处于下界传送门中时会被移除。

下界传送门方块可以用于进入或离开下界。当玩家在[主世界](主世界.md)或下界时，持续处于一个下界传送门方块的位置4秒钟，玩家就会被传送到另一个维度。玩家能够在传送门播放完毕传送动画之前，离开传送门以取消传送。在[创造模式](创造模式.md)中的玩家在接触下界传送门方块时会被瞬间传送到其他维度。如果在一定范围内（约128个方块）有一个**已激活**的传送门，那么玩家就会被传送到那个传送门。否则，会在相应的坐标处（或其附近）选择一个合适的地点生成一个传送门。由命令生成的单独的下界传送门方块仍可以将实体传送到下界，也可以创建传送门，但是不一定传送至传送门内部。

下界传送门方块会发出独特的呼啸声，并散发类似雪花的紫色粒子（这种粒子也会由[末影人](末影人.md)、[末影螨](末影螨.md)、[末影珍珠](末影珍珠.md)和[末影箱](末影箱.md)生成）。

不同于大多数不可挖掘的方块，下界传送门方块的[爆炸抗性](爆炸抗性.md)只有0。因此，任何能够破坏方块的爆炸会能在波及下界传送门方块时将其破坏，并关闭整个下界传送门。一次[恶魂](恶魂.md)火球的攻击就足以关闭下界传送门。

液体在流动时会避开下界传送门方块。发射器或在下界传送门方块的位置放置任意液体会破坏下界传送门。

下界传送门方块无法被[活塞](活塞.md)推动。

放置在[末地](末地.md)或其他[自定义维度](自定义维度.md)的传送门方块能够像在主世界当中一样运作，坐标的换算比同样为1:8，并连接到下界的一个传送门，若无则生成一个传送门。当玩家进入如此生成的传送门后，又会在主世界正常生成一个传送门。

放置在末地的传送门方块会将玩家传送至主世界出生点的Y=-64处<ref></ref>，玩家此时无法与世界正常交互，渲染也会出现一些错误，但玩家重新进入世界后又会恢复正常。在基岩版服务器内进行测试出现的现象如下：
* 玩家在使用命令回到地面后，虽然玩家可以自由走动，但玩家对世界的交互皆以传送后的坐标为中心，而不是自己所看到的玩家实体所在的坐标为中心。生物攻击时依旧以此坐标为玩家中心，并且生物会与看起来并不存在的玩家实体碰撞箱交互，并且能够攻击玩家，但玩家血量并不会变化。
* 玩家依旧可以离开该范围自由走动，直到那个坐标所能加载到的区块边界，玩家的强加载区域以最后一次传送的坐标进行正常判断。
* 在加载范围内，玩家能与生物互动。此时不能杀死玩家，但依旧可以踢出此玩家。玩家处于此状态时无法进入传送门。
* 与最后一次传送坐标处玩家正常触及范围外的带UI方块的交互。玩家无法开启范围外的容器，但依旧能正常使用砂轮。熔炉作为一个容器依旧可在交互后展示熔炉UI，玩家也可以正常操作其内的燃料和被熔炼的物品。但并不会正常展示熔炉UI内熔炼进度条以及燃料消耗情况，不过熔炉会切换正常的燃烧纹理。

如果一个[自定义](自定义.md)世界没有定义，仍然可以激活下界传送门并生成此方块，但无法传送任何实体。

# = 光源 =
下界传送门方块会发出亮度等级为11的光。

# = 疣猪兽 =
疣猪兽会远离附近的下界传送门。
