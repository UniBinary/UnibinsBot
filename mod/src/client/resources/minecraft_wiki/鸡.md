# = 自然生成 =
鸡会自然生成在上方有2格空间且亮度等级9或以上的[草方块](草方块.md)上。鸡会在亮度为7或以上的方块上生成。

尽管在所有生物群系中生成的鸡都有对应变种，但它们只会在[平原](平原.md)、[向日葵平原](向日葵平原.md)、[沼泽](沼泽.md)、[风袭丘陵](风袭丘陵.md)、[风袭森林](风袭森林.md)、[风袭沙砾丘陵](风袭沙砾丘陵.md)以及[苍白之园](苍白之园.md)以外的[森林类生物群系](森林类生物群系.md)、[沙漠](沙漠.md)以外的[干旱类生物群系](干旱类生物群系.md)中自然生成。

自然生成的鸡有5%概率是幼年鸡。

# == 鸡骑士 ==

幼年僵尸、幼年尸壳、幼年僵尸村民、幼年溺尸或有概率生成为鸡骑士。因此，与普通的鸡不同，作为鸡骑士的一部分生成的鸡，其生成条件与其乘客一致。

# = 人为生成 =
掷出的[鸡蛋](鸡蛋.md)击中物体并破裂后，有的概率生成1只幼年鸡。如果尝试生成1只幼年鸡成功，又将会有的概率生成4只幼年鸡。如果向空中一定角度投掷鸡蛋，幼年鸡可能会[生成](生成.md)在墙内，并造成窒息。

# 掉落物
成年鸡被杀死时会掉落：

* 如被[玩家](玩家.md)或驯服的[狼](狼.md)杀死则会掉落（若作为鸡骑士一部分生成则掉落）。

与其他幼年动物一样，杀死幼年鸡不会掉落任何经验和物品。

# 行为
鸡会漫无目的地游荡，且经常在水里游泳。当鸡从高处掉落时会迅速扇动翅膀来减慢下落速度以避免摔伤。尽管如此，它们仍然会尽力避免从悬崖上掉落。

当在一个已加载的区块里时，成年鸡会每隔5-10分钟（6000-12000[刻](刻.md)）下1个[鸡蛋](鸡蛋.md)。组成[鸡骑士](鸡骑士.md)的鸡不会下蛋，即使其上的幼年僵尸已经死亡或脱离骑乘。鸡濒死时也能下蛋。<ref></ref>幼年鸡不能下蛋。

鸡与“家畜”共享一些行为：
* 当受到伤害时，它们都会盲目而快速地逃跑。
* 它们可以游泳，游泳时能清楚地看到它们的翅膀在快速扇动。
* 它们可以被/手持[小麦种子](小麦种子.md)、[甜菜种子](甜菜种子.md)、[西瓜种子](西瓜种子.md)、[南瓜种子](南瓜种子.md)、[火把花种子](火把花种子.md)或[瓶子草荚果](瓶子草荚果.md)的玩家吸引，也能使用这些种子让它们进行[繁殖](繁殖.md)。
* 幼年鸡会尽可能跟随附近的成年鸡。

鸡会被[豹猫](豹猫.md)和[狐狸](狐狸.md)攻击。

鸡游泳时上方需要有2格空气，否则它们在浮上来时会受到溺水伤害，并很可能因此死亡。

不像其他大多数生物，鸡会试图跳上楼梯而不是走上去。<ref></ref>

# = 繁殖 =

[缩略图|右|幼年鸡与它的双亲](File:Minichicken.png.md)

如果用[小麦种子](小麦种子.md)、[甜菜种子](甜菜种子.md)、[西瓜种子](西瓜种子.md)、[南瓜种子](南瓜种子.md)、[火把花种子](火把花种子.md)或[瓶子草荚果](瓶子草荚果.md)喂两只鸡，它们会交配并生出一只幼年鸡，同时掉落。在繁殖后，鸡在/内不能再次繁殖。繁殖出的幼年鸡的变种从双亲的变种中随机选择，与所在生物群系无关。

幼年鸡会在20分钟内长大，可以使用小麦种子、甜菜种子、西瓜种子、南瓜种子、火把花种子或瓶子草荚果加速成长过程；每次使用种子都会减少约剩余成长时间的10%。

对幼年鸡[金蒲公英](金蒲公英.md)可以阻止其成长为成年鸡，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年鸡无法被喂食除金蒲公英外的其他物品。

# 你知道吗
* 寒带鸡的灵感来自于现实中的[波兰鸡](wikipedia:Polish chicken.md)。
* 玩家无法与坐在[矿车](矿车.md)中的鸡交互，因为矿车的判定箱覆盖了鸡的判定箱。
* 当鸡在空中被杀死时，它的“尸体”会比其他生物下落得慢，并且仍然能看到翅膀扇动的动画。
* 因为鸡的尺寸很小，所以鸡能够“藏”在漏斗或炼药锅里，这可保护它们不受这些方块上面的熔岩或水的影响。
* Notch在Twitter中说他将在Beta版本结束前几个星期把鸡改成鸭子<ref></ref>，这在Twitter上引起了热议。几天后，Jeb仍接受到关于这条消息的反馈，他证实这条消息只是一个玩笑。<ref></ref>
* 当你在[原主机版](原主机版.md)加载/创建/退出一个世界时，会出现一条消息“Is it a Chicken, or a duck?”。同时，生物头像的描述的最后一行写道“... and a chicken... Or is it a duck?”。
* * [携带版0.3.0](携带版0.3.0.md)的更新日志里把鸡当成了鸭。<ref>http://www.mojang.com/2012/04/minecraft-pocket-edition-now-with-crafting/</ref>
* * Notch在后来的[博客](The Word of Notch.md)中把鸡称为“the chicken/duck/whatevers”（鸡或鸭或其他什么），说明了在那个时候鸡还没有官方名称。<ref></ref>
* 在现实中，鸡是卵生动物，但在游戏中鸡可以直接生下幼年鸡。
* 在愚人节版本[Java版2.0](Java版2.0.md)中，加入了下[钻石](钻石.md)和[青金石](青金石.md)的[钻石鸡](钻石鸡.md)。
* 鸡在[稀疏丛林](稀疏丛林.md)的生成频率比在其他生物群系中高。
