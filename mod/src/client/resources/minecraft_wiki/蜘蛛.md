* *蜘蛛（Spider）**是一种常见的拥有爬墙能力的条件敌对生物。

# 生成
[缩略图|蜘蛛生成在一个方块上](File:Spider1x1.png.md)
[缩略图|蜘蛛骑士](File:Offset Spider Jockey.png.md)

蜘蛛会生成在主世界方块光照等级为0且内部天空光照等级小于等于7，并且底部有[可生成方块](生成#可生成位置.md)的3×1×3空间内。蜘蛛生成的空气方块上方不能是[碰撞箱](碰撞箱.md)完整的方块（包括玻璃和树叶）或[液体](液体.md)。蜘蛛不会在[河流](河流.md)、[冻河](冻河.md)和[雪原](雪原.md)生成。<ref></ref><ref></ref>

无论是Java版还是基岩版，该空间顶部的方块必须都是非固体方块。

每只蜘蛛在生成时都有1%的概率再生成一个[骷髅](骷髅.md)[骑乘](骑乘.md)在自身上，形成[蜘蛛骑士](蜘蛛骑士.md)。在部分积雪的生物群系中这只骷髅有80%的概率会是[流浪者](流浪者.md)，在下界中这只骷髅有80%的概率会是[凋灵骷髅](凋灵骷髅.md)，在[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)生物群系中这只骷髅有80%的概率会是[沼骸](沼骸.md)，在[沙漠](沙漠.md)中这只骷髅有80%的概率会是[焦骸](焦骸.md)，其余情况则会是骷髅。<ref name="MC-109415"></ref>

# = 刷怪笼 =
[地牢](地牢.md)中的[刷怪笼](刷怪笼.md)有25%的概率为蜘蛛刷怪笼。

[林地府邸](林地府邸.md)的隐藏房间“[蜘蛛房](林地府邸#蜘蛛房.md)”里也会生成蜘蛛刷怪笼。

# = 试炼刷怪笼 =
[试炼密室](试炼密室.md)中的小型近战型[试炼刷怪笼](试炼刷怪笼.md)包含蜘蛛试炼刷怪笼。

# 行为
蜘蛛的眼睛拥有发亮的纹理，在暗处也清楚可见，但不会影响周围方块的实际[亮度](亮度.md)。受隐身效果影响的蜘蛛身体不可见，但发亮的红眼睛仍然可见。<ref></ref><ref></ref>

在[亮度](亮度.md)等级小于等于11时，蜘蛛会主动攻击玩家、和[铁傀儡](铁傀儡.md)；在亮度等级高于11时它们不会主动攻击，除非其他生物首先攻击它们。正在追逐目标的蜘蛛即使进入到亮度等级大于等于12的地方也会继续追逐。如果敌对状态的蜘蛛受到其他来源的伤害，例如摔落，则会结束对目标的敌对状态并重新寻找目标。

蜘蛛在近战时会猛扑攻击目标。在1格水中游泳的蜘蛛可以在目标靠近水的瞬间扑向目标。

当蜘蛛发现目标时，即使目标获得[隐身](隐身.md)效果，蜘蛛仍然会继续攻击目标并锁定其位置，无论蜘蛛是否受伤。

蜘蛛可以攀爬固体方块（蜘蛛无法爬上[岩浆块](岩浆块.md)，但当它与其他生物相互挤压时，则可能导致其爬上岩浆块）。它们也能攀爬[世界边界](世界边界.md)。如果蜘蛛找不到一条追踪目标的理想路径（当攻击目标位于高处时），它会尽可能地靠近目标并垂直向上攀爬，直到可以触及目标。如果此时蜘蛛结束敌对状态，它仍会继续盲目地向前爬2秒钟。

尽管蜘蛛本身不像[洞穴蜘蛛](洞穴蜘蛛.md)一样具有毒性，但蜘蛛也同样不受[中毒](中毒.md)效果的影响。

与大多数生物不同，蜘蛛穿过[蜘蛛网](蜘蛛网.md)时不会被减慢速度。

与大多数生物不同，蜘蛛死亡时并不是侧着倒下，而是底朝天翻转。[洞穴蜘蛛](洞穴蜘蛛.md)、[蠹虫](蠹虫.md)和[末影螨](末影螨.md)同样如此。

蜘蛛会主动远离或内未蜷缩的[犰狳](犰狳.md)。

# = 生物族群 =

蜘蛛是[节肢生物](节肢生物.md)，被具有[节肢杀手](节肢杀手.md)魔咒的武器近战攻击时会受到额外的伤害并被施加数秒的[緩速](緩速.md)IV效果。

# 你知道吗
[缩略图|右|旁观模式中蜘蛛的视野](File:Spider Vision.png.md)
* 从[旁观模式](旁观模式.md)进入蜘蛛的视角会使屏幕带上偏红的模糊滤镜，并且拥有蜘蛛的六重视觉。
* 蜘蛛其实是浮在地面上的，尽管看起来并不明显。
* 蜘蛛底朝天翻转的死亡动画参考自现实中蜘蛛及部分昆虫的死亡姿态。它们在死亡时身体会不受控制，最终底朝天倒在地上。
