* *13w16b**是[Java版1.6.1](Java版1.6.1.md)的第2个快照，发布于2013年4月23日<ref></ref>，加入了命名牌，并修复了[13w16a](13w16a.md)里的漏洞和崩溃。

# 新内容
# = 物品 =
* *[命名牌](命名牌.md)**
* 可用于生物命名。

# = 常规 =
* *工具提示**
* 加入[干草捆](干草捆.md)和[拴绳](拴绳.md)的工具提示。

# 更改
# = 生物 =
* *[马](马.md)**
* 骑马速度现在变慢，并且减弱滑行。

# = 常规 =
* *崩溃报告**
* 重新启用崩溃报告。
