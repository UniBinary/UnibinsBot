* *蒲公英（Dandelion）**是一种[小型花](小型花.md)。

# 生成

# = 自然生成 =
蒲公英会在[主世界](主世界.md)中除[沼泽](沼泽.md)、[红树林沼泽](红树林沼泽.md)、[苍白之园](苍白之园.md)、[蘑菇岛](蘑菇岛.md)、[繁茂洞穴](繁茂洞穴.md)、[樱花树林](樱花树林.md)、[雪林](雪林.md)、[积雪山坡](积雪山坡.md)、[尖峭山峰](尖峭山峰.md)、[冰封山峰](冰封山峰.md)、[裸岩山峰](裸岩山峰.md)、[恶地](恶地.md)、[疏林恶地](疏林恶地.md)、[风蚀恶地](风蚀恶地.md)、之外的所有[生物群系](生物群系.md)自然生成。

蒲公英也会在平原[村庄](村庄.md)和[林地府邸](林地府邸.md)中生成。

# = 骨粉 =
在可自然生成蒲公英的生物群系中对[草方块](草方块.md)[骨粉](骨粉.md)后，蒲公英有概率代替[矮草丛](矮草丛.md)生成。

对着不[含雪](含雪.md)的蒲公英使用骨粉会出现更多的蒲公英，也有小概率出现[虞美人](虞美人.md)，而不会出现草丛。

# 破坏
蒲公英被挖掘时会立刻被破坏。

蒲公英被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 谜之炖菜 =

使用蒲公英合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家/的[饱和](饱和.md)效果。

# = 繁殖 =

蒲公英可用于吸引及繁殖[兔子](兔子.md)和[蜜蜂](蜜蜂.md)，也可喂食给幼年个体以减少其10%的剩余生长时间。

# = 堆肥 =
将蒲公英放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
