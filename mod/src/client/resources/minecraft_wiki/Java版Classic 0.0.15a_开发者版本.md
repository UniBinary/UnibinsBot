# Java版Classic 0.0.15a/开发者版本

*页面ID: 138994* | *来源: Minecraft Wiki*

该条目记录了[Java版Classic 0.0.15a](Java版Classic 0.0.15a.md)的开发者版本。该版本进行了一些更改，并测试了[迷雾](迷雾.md)。<ref></ref>

# 新内容
# = 世界生成 =
* *[迷雾](迷雾.md)**
* 测试了迷雾。雾会根据玩家正在看着的方块的变化而改变颜色并变暗。
* 由于漏洞并未应用到正式版本。

# 更改
# = 方块 =
* *[橡树原木](橡树原木.md)**
* 更改了纹理。

* *[橡树树叶](橡树树叶.md)**
* 更改了纹理。

# = 世界生成 =
* *[树木](树木.md)**
* 更改了形状，现在其顶端有一个明显的十字形。
