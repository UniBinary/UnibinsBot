# Java版Classic 0.26 SURVIVAL TEST/开发者版本

*页面ID: 35661* | *来源: Minecraft Wiki*

Notch发表的7篇[博文](The Word of Notch.md)展示了[生存测试](生存测试.md)开发中的特性。

# 爆炸更新（2009年10月20日）
* *[ Word of Notch帖子]** **["Minecraft Creeper Smoke" on YouTube](https://www.youtube.com/watch?v=7pUs1zMQiNI&list=PLYvbqe7pJsoP9Z2AisjV8jcRPZzV93j7i&index=16)**

# = 更改 =
; [爆炸](爆炸.md)
* 苦力怕的爆炸不再摧毁石头或石质方块。
* 爆炸会产生烟雾。

; [菜单屏幕](菜单屏幕.md)
* 移除了菜单屏幕的渐变效果。

; 常规
* 优化资源使用，通过使远处实体不可见的方式，可见距离由实体大小决定。

# 泥土台阶测试（2009年10月22日）
* *[ Word of Notch帖子]**

[thumb|该版本的泥土台阶和雨](File:DirtSlab.png.md)

# = 新内容 =
; [泥土台阶](泥土台阶.md)
* 世界生成时会替换所有的泥土。
* * 会使它们附近的方块变黑。

# = 更改 =
; [天气](天气.md)
* 加入了[雨](雨.md)。
* * 动态的，雨滴落到地面上时会四处弹跳。
* * 通过按下键生成。

# 雨修复（2009年10月22日）
* *[ Word of Notch帖子]**

# = 更改 =
; [天气](天气.md)
* 雨变得更小了。
* 雨现在可以被方块阻挡。
