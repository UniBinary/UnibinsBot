# 活动服务器

*页面ID: 104850* | *来源: Minecraft Wiki*

* *活动服务器（Live Event）**是[Mojang Studios](Mojang Studios.md)每逢举办大型活动时，向玩家限时开放的官方[基岩版](基岩版.md)[服务器](服务器.md)。和[精选服务器](精选服务器.md)一样，[玩家](玩家.md)可以通过全平台设备加入活动服务器，但都需要登录[Microsoft账户](wzh:Microsoft帐户.md)<ref name="btfaq"></ref>。

# 历次活动服务器

# 安全性
加入活动服务器的硬性要求是玩家必须登录Microsoft账户<ref name="safety"></ref>。通常情况下，服务器内禁用[聊天](聊天.md)，以防止玩家发送不恰当消息。Windows端和移动端玩家也无法在服务器内使用自定义[皮肤](皮肤.md)及从外部导入的[皮肤包](皮肤包.md)，以防止玩家使用引人不适的皮肤或[披风](披风.md)。
