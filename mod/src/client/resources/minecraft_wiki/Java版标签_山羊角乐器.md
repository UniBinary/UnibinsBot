# Java版标签/山羊角乐器

*页面ID: 161616* | *来源: Minecraft Wiki*

* *山羊角乐器标签（Instrument Tags）**是[山羊角乐器](山羊角乐器.md)的组合。

# 使用
山羊角乐器标签用于控制生成的山羊角的种类。

# 当前版本

# = goat_horns =
* 在创造模式物品栏中显示的所有不同乐器的山羊角。

# = regular_goat_horns =
* 普通山羊掉落的山羊角。
* 可从[掠夺者前哨站](掠夺者前哨站.md)战利品箱子中获取的山羊角。

# = screaming_goat_horns =
* 尖叫山羊掉落的山羊角。
