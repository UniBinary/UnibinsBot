# 雕纹石砖

*页面ID: 99478* | *来源: Minecraft Wiki*

* *雕纹石砖（Chiseled Stone Bricks）**是[石头](石头.md)、[石砖](石砖.md)或[石砖台阶](石砖台阶.md)制作的装饰性方块，花纹如同“回”字。

# 生成
# = 自然生成 =
雕纹石砖会生成在[海底废墟](海底废墟.md)、[雪屋](雪屋.md)地下室和[主世界](主世界.md)的部分[废弃传送门](废弃传送门.md)中。[丛林神庙](丛林神庙.md)中也会生成3个雕纹石砖。

# = 虫蚀的方块 =
被具有[精准采集](精准采集.md)的工具挖掘破坏时，[虫蚀雕纹石砖](虫蚀雕纹石砖.md)及其变种被破坏后会掉落雕纹石砖，不会生成蠹虫。

# 破坏
挖掘雕纹石砖的合适工具是镐。雕纹石砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

雕纹石砖被破坏后会掉落自身。
