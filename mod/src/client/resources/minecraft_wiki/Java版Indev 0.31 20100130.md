# Java版Indev 0.31 20100130

*页面ID: 35351* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2010年1月30日01:09（UTC），加入了一些新特性，并修复了一些漏洞。<ref name="WoN 0130 release"></ref>

# 新内容
# = 物品 =
* *[火药](火药.md)**<ref>[Adura的IRC记录](#log.md): "(20:39:10) <Dreanor_Arch>  kill black guys for gunpowder, it's a sterotypical game"</ref>
* 可由[黑史蒂夫](Indev MD3格式生物.md)掉落。
* 用于合成[TNT](TNT.md)。

* *[线](线.md)**<ref>[Adura的IRC记录](#log.md): "(20:38:49) <DragoonEnRegalia> How do you make a string?"..."(20:38:59) <Droqen> DragoonEnRegalia, kill the not black guy"</ref>
* 可由[史蒂夫](Indev MD3格式生物.md)掉落。
* 用于合成[弓](弓.md)。

* *[羽毛](羽毛.md)**
* 可由生物掉落。
* 用于合成[箭](箭.md)。

# = 生物 =
* *[野兽小子](野兽小子.md)**
* 没有动画。
* 有。
* 死亡时掉落0-2个羽毛。

# 更改
# = 方块 =
* *[石台阶](石台阶.md)**
* 加入了合成配方，现在可由3个[圆石](圆石.md)合成。<ref></ref>

* *[TNT](TNT.md)**
* 加入了合成配方，现在可由4个[沙子](沙子.md)和5个火药合成。<ref name="changes">[Adura的IRC记录](#log.md): "(19:57:14) <Notch> you can craft arrows, tnt, and bows"</ref>

* *[齿轮](齿轮.md)**
* 现在在物品栏中会显示动态纹理。

* *[火](火.md)**
* 现在在物品栏中会显示动态纹理。

* *[花](花.md)**
* 现在显示效果与在物品栏中相似。

# = 物品 =
* *[工具](工具.md)**
* 为金质工具加入了合成配方，现在可由[金锭](金锭.md)和[木棍](木棍.md)合成。

* *[弓](弓.md)**
* 加入了合成配方，现在可由3个[木棍](木棍.md)和3个[线](线.md)来合成。<ref name="changes" />

* *[箭](箭.md)**
* 加入了合成配方，现在可由[羽毛](羽毛.md)、[木棍](木棍.md)和[铁锭](铁锭.md)来合成。<ref name="changes" />

# = 生物 =
* *[黑史蒂夫](黑史蒂夫.md)**
* 现在掉落0-2个火药。

* *[史蒂夫](Indev MD3格式生物.md)**
* 现在掉落0-2个线。

# = 游戏内容 =
* *[分数](分数.md)**
* 移除了右上角的记分板。

* *[统计](统计.md)**
* 玩家统计从[物品栏](物品栏.md)中移除。

# = 世界生成 =
* *[Indev房子](Indev房子.md)**
* 移除了其内的所有[箱子](箱子.md)。<ref>[Adura的IRC记录](#log.md): "(20:02:03) <FakeSky> The chests, they're gone""</ref>

* *[虚空](虚空.md)**
* 重新在世界底部加入了熔岩海。
* * 熔岩海无限深。

# 修复
* *修复了4个漏洞**
* 修复了攻击距离过大的漏洞。
* 修复了使用剑时出现的图形错误。
* 掉落的整组物品现在会熔炼成不同的物品（之前只有1个物品会被熔炼，其他的都会消失）。
* 对合成物点右键会把它们全部取出，而不是一个。</onlyinclude>
* 修复了可以穿墙攻击生物的漏洞。<ref>[Adura的IRC记录](#log.md): "(19:57:44) <Notch> wait, I'll fix the "hitting mobs through walls" bug ;D"</ref>
