# 创造模式

*页面ID: 6392* | *来源: Minecraft Wiki*

[thumb|400px|在创造模式中制作的[[wzh:像素画|像素画](File:Creative.png.md)]]

* *创造（Creative）**模式是[Minecraft](Minecraft.md)中主要的[游戏模式](游戏模式.md)之一。创造模式改变了游戏中的生存模式内容，并且允许玩家自由地飞行、创造和破坏结构。

# 游戏内容

在创造模式中，[玩家](玩家.md)拥有无限的[方块](方块.md)用于创造，没有[生命值](生命值.md)、[饥饿值](饥饿值.md)和[氧气值](氧气值.md)，不必担心有危险阻碍他们的建造，还可以进行[飞行](飞行.md)。创造模式允许玩家在没有拿[剑](剑.md)、[矛](矛.md)、[三叉戟](三叉戟.md)、[重锤](重锤.md)或时瞬间破坏大多数的[方块](方块.md)，包括像[基岩](基岩.md)和[末地传送门](末地传送门.md)这种正常情况下不能破坏的方块，只有极少数例外，如中的[隐形基岩](隐形基岩.md)。一次性的物品或时不会消耗它们，使用武器与工具也不会消耗[耐久度](耐久度.md)。由创造模式玩家发射的[箭](箭.md)只能被同为创造模式的玩家捡起，捡起时不会进入玩家的物品栏。

创造模式会给予玩家额外0.5格方块交互距离和额外2格实体交互距离。

使用触屏操作时创造模式给予玩家额外6格方块和实体交互距离。

[250px|thumb|在创造模式中飞行的玩家](File:Fly.png.md)

创造模式下的玩家无法受到除[虚空](虚空.md)和以外的任何伤害。当玩家的Y坐标在世界建筑下限下方超过64格，就会受到虚空伤害。

创造模式下的玩家不会受到任何伤害，若对其使用命令，则聊天栏会提示“玩家在创造模式下无法被杀死”。

创造模式下的玩家仍会在接触火、熔岩时[着火](着火.md)，但在离开火焰环境后会立即结束着火状态。

[生物](生物.md)仍然会像在其他游戏模式中那样生成（包括从[刷怪笼](刷怪笼.md)中生成），但都永远不会攻击玩家（某些情况会看向玩家），也不会因被玩家攻击或其他在生存模式中可行的激怒方式被激怒。即使玩家在创造模式下，增援的[僵尸](僵尸.md)仍然会试图攻击玩家，不过不会造成任何伤害，并且在几秒后就会停止攻击。<ref></ref>

当一个世界被创建后，如果开启了[作弊](作弊.md)，可以通过命令、命令、命令}}或中的[游戏模式切换器](游戏模式切换器.md)、中的设置来切换到创造模式。在[多人游戏](多人游戏.md)中，[管理员](管理员.md)可以通过命令单独切换每一名玩家的游戏模式。这意味着在一个生存模式的世界中（根据管理员的意愿）玩家也可以使用创造模式，反之亦然。新玩家的默认游戏模式也能通过中的命令或中的设置中默认游戏模式来切换。

操作员和房主玩家在未启用作弊的世界中也可以在设置中将默认游戏模式切换为创造模式。切换为创造模式后，作弊会自动开启。

如果游戏能确定方块是被创造模式的玩家所破坏的，那么不会有任何掉落物出现（装有物品的[潜影盒](潜影盒.md)和含有蜜蜂的[蜂巢](蜂巢（方块）.md)和[蜂箱](蜂箱.md)除外）。如果游戏不能确定，方块的物品形式仍会掉落。<ref></ref>

无论是以创造模式创建新的世界还是进入旧的世界，都将永久关闭该世界的[成就](成就.md)和排行榜的更新，但这并不会对游戏内容造成任何影响。换言之，成就和排行榜只有在一直保持在[生存模式](生存模式.md)或[冒险模式](冒险模式.md)下才有效。

创造模式中会额外随机播放创造模式专属的[音乐](音乐.md)。创造模式的玩家在主世界非水下时只会播放6首创造模式专属的音乐。

# 创造模式物品栏

[250px|thumb|[[基岩版](File:Creative Inventory BE (Classic).png.md)中正在显示“所有”标签页的创造模式物品栏（经典UI）]]
[250px|thumb|[[基岩版](File:Creative Inventory BE (Pocket).png.md)中正在显示“所有”标签页的创造模式物品栏（携带版UI）]]

在创造模式中，普通的物品栏窗口被替换成[物品选择栏](物品栏#创造模式物品栏.md)，这个分为多个标签页的物品选择栏包括了游戏中几乎所有的方块和物品（部分方块除外，详见[下文](#不可用的方块和物品.md)），同时内置了搜索功能。其中一个标签页提供了类似生存模式的[物品栏](物品栏.md)，包括[盔甲](盔甲.md)槽，但缺少合成方格。其他标签页包括食物、建筑方块、装饰型方块等。某些物品正常情况下只能在创造模式中得到，如[刷怪蛋](刷怪蛋.md)。一些方块也只能在创造模式中的[管理員](权限等级.md)和，比如[命令方块](命令方块.md)和[结构方块](结构方块.md)。

由于创造模式不会消耗物品，某些物品在创造模式中的表现与在生存模式中不同——比如[铁桶](铁桶.md)能无限移除[水](水.md)或[熔岩](熔岩.md)，并且不会在已有水桶或熔岩桶的情况下继续给予玩家水桶或熔岩桶，水桶和熔岩桶也可以无限次放置而不会倒空；将物品放在物品展示框里或盔甲架上，不会导致它从玩家手中消失，而会将物品复制一份。对物品按下键可以复制物品。

玩家可以捡起[物品](物品.md)，但如果快捷栏已经占满，则物品会放置到生存模式物品栏。被间接破坏的方块（通过破坏它附着的方块，或当受重力影响的方块落到任何非固体方块上时）仍会掉落成物品并可以被捡起。当生存模式物品栏也被占满时，物品仍会被玩家捡起，但会立刻被删除。

生存模式物品栏的右下角有一个“”按钮，拖入其中的物品会被删除。按下键的同时点击该按钮会清除生存模式物品栏（包括快捷栏、副手槽和盔甲槽）当中的所有物品。

创造模式下可通过按下+来保存快捷栏，最多可保存9个。已保存的快捷栏可通过按下+来加载。保存快捷栏时会保留物品的[物品堆叠组件](物品堆叠组件.md)，已保存的快捷栏可在创造模式物品栏中的“已保存的快捷栏”选项卡下查看，并能从其中选取物品。

# = 选取方块 =

创造模式的玩家可以通过来获得物品，即使物品栏中没有这个物品。按住+可以获得包含方块数据的物品。

# = 不可用的方块和物品 =
有一些方块和物品不显示在创造模式物品栏中。它们中的大多数物品可以通过命令获得，而方块可通过和命令放置。可以参考下表中提供的ID。一些[技术性方块](技术性方块.md)例如传送门和熄灭的红石火把，由于没有其物品形式，因此不能正常获得。

# = <code>level.dat</code>中的表示 =

创造模式在<code>level.dat</code>文件中的<code>GameType</code>中表示为<code>1</code>；要手动修改游戏类型，首先要用[NBT编辑器](辅助程序与编辑器/专业工具.md)打开该文件。单人游戏世界并不使用这个字段来保存玩家当前的游戏模式。
