# 锻造

*页面ID: 103420* | *来源: Minecraft Wiki*

中锻造台的GUI}}

* *锻造（Smithing）**是通过[锻造台](锻造台.md)消耗[锻造模板](锻造模板.md)来进行的[装备](装备.md)改造方式。

# 机制
[锻造台](锻造台.md)可以打开锻造界面。

进行锻造时需要在输入槽位放入3个物品：
# 锻造模板槽位：放入一个[锻造模板](锻造模板.md)，其类型决定了锻造的方式。
# 装备槽位：要进行改造的物品。
# 锻造原材料槽位：在锻造中消耗的材料物品。

锻造目前有两类配方：升级配方和盔甲纹饰配方。

当配方正确时，输出槽位就会出现成品，且此时锻造台界面上的[盔甲架](盔甲架.md)会装备该物品，以供玩家预览。从输出槽位中取出物品后，每个输入槽位都会消耗掉1个物品。

如果槽位中有物品但配方不正确，则输出槽位中不会有物品，且箭头上会出现红叉并提示“”。

# = 升级 =
若放入的锻造模板为[下界合金升级](下界合金升级.md)，则锻造台将按照锻造升级配方对盔甲或工具进行升级。此时若装备槽位为钻石装备，锻造原材料槽位为[下界合金锭](下界合金锭.md)，则锻造台输出的物品将是对该钻石质装备升级后得到的下界合金质装备。

升级配方只改变物品类型，即原有物品的任何物品数据，如[魔咒](魔咒.md)、[累积惩罚](铁砧机制#累积惩罚.md)、已损耗的[耐久度](耐久度.md)等均会保留。

# = 添加盔甲纹饰 =
若放入的锻造模板为任意一种[盔甲纹饰锻造模板](#盔甲纹饰锻造模板.md)，则当前锻造台将按照盔甲纹饰配方对盔甲添加**盔甲纹饰（Armor Trim）**。此时若装备槽位为有效的[盔甲](盔甲.md)，锻造原材料槽位为有效的[锻造原材料](#盔甲纹饰材料.md)，则锻造台输出的物品将对该盔甲添加指定盔甲图案和锻造原材料盔甲纹饰。

盔甲纹饰配方只改变装备的盔甲纹饰数据，其他数据例如物品的自定义名称和魔咒等都将保留。

目前仅有人形生物的盔甲具有盔甲纹饰及对应的盔甲纹饰配方，包括所有的头盔、胸甲、护腿和靴子。

# == 盔甲纹饰 ==
盔甲纹饰是覆盖在盔甲外观上的额外图案。它们是纯粹的装饰，不提升盔甲的防护性能或给予其他功能，如非下界合金质的盔甲即使拥有以[下界合金锭](下界合金锭.md)为原材料的盔甲纹饰也能被[熔岩](熔岩.md)摧毁。

不同的盔甲纹饰锻造模板决定盔甲纹饰种类，不同的锻造原材料决定颜色。这两者会在实体所穿戴的和锻造台界面预览的盔甲上展示出来，锻造后盔甲的[提示框](提示框.md)中也会显示它们的名称，且用对应颜色标记，但物品栏图标不体现纹饰种类的区别。

每个盔甲物品只能添加一个盔甲纹饰。纹饰能通过进行[物品修复](物品修复.md)来移除，也可以在锻造台上被替换，或者[合成](合成.md)两个相同材质的同部位的盔甲物品来移除。盔甲物品一旦被添加盔甲纹饰将不能在[砂轮](砂轮.md)上进行操作。

# == 盔甲纹饰材料 ==
盔甲纹饰配方的有效锻造原材料在游戏内也被称为**锭或晶体（Ingots & Crystals）**。每种锻造原材料都对应了不同的盔甲纹饰颜色。如果锻造原材料与盔甲的[盔甲材料](盔甲材料.md)相同，则会使用加深后的颜色。
