# 青金石矿石

*页面ID: 210* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *青金石矿石（Lapis Lazuli Ore）**是开采后可获得青金石的[矿石](矿石.md)方块。

* *深层青金石矿石（Deepslate Lapis Lazuli Ore）**是以[深板岩](深板岩.md)作为容矿岩的青金石矿石变种。

# 生成
# = 自然生成 =
青金石矿石会以[矿团](矿团.md)的形式生成于[主世界](主世界.md)中Y=-64至64的区域，矿团大小为1-7个方块。生成方式包含两种：一种可以露天生成，分布于Y=-32至32之间，在Y=0处最多并向两侧递减，每[区块](区块.md)尝试生成2次；另一种不能暴露于空气生成，在Y=64以下均匀分布，每区块尝试生成4次。

生成于[深板岩](深板岩.md)或[凝灰岩](凝灰岩.md)间的青金石矿石会被替换为深层青金石矿石。

# 获取
青金石矿石和深层青金石矿石只能通过破坏对应方块获得。

# 破坏
挖掘青金石矿石和深层青金石矿石的合适工具是镐。青金石矿石和深层青金石矿石需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，青金石矿石和深层青金石矿石被破坏后会掉落4-9个[青金石](青金石.md)和，挖掘工具的[时运](时运.md)魔咒会增加青金石的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，青金石矿石和深层青金石矿石被破坏后会掉落自身。
