# 获取
# = 箱子战利品 =

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落锻造模板。

# = 生物掉落物 =
[远古守卫者](远古守卫者.md)死亡时有20%的概率掉落1个潮汐盔甲纹饰，不受[抢夺](抢夺.md)魔咒影响。

# = 合成 =
尽管锻造模板本身不能合成获得，但可以利用特定的合成配方来复制它们自身。

# 用途
# = 下界合金升级 =

下界合金升级锻造模板可在[锻造台](锻造台.md)上与[钻石装备](装备.md)和[下界合金锭](下界合金锭.md)相结合，将其升级为对应的下界合金装备。

# = 盔甲纹饰 =

盔甲纹饰锻造模板可在锻造台上与[盔甲](盔甲.md)和锻造原材料相结合，给盔甲添加不同的纹饰。

# 你知道吗
* 据[LadyAgnes](LadyAgnes.md)所说，锻造模板的原名为“锻造蓝图”（Smithing Blueprints），而“蓝图”一词过于现代，偏离了Minecraft的幻想性世界。<ref></ref>
* 一些盔甲纹饰表现的图案与对应锻造模板的获取地点有关<ref>"Some of the armor trims reflect the place where you found the template, for example bastions contain a piglin-inspired trim."-[Sofia Dankis](Sofia Dankis.md)-</ref>：
* * 胸甲和护腿前部的哨兵盔甲纹饰像是[掠夺者前哨站](掠夺者前哨站.md)的墙面图案。
* * 胸甲前部的眼眸盔甲纹饰看起来像[末影之眼](末影之眼.md)，头盔前部的纹饰像是人-{}-形生物的双眼。
* * 肋骨盔甲纹饰看起来像[凋灵骷髅](凋灵骷髅.md)。
* * 幽静盔甲纹饰看起来像[监守者](监守者.md)。
* * 猪鼻盔甲纹饰看起来像[猪灵](猪灵.md)。
* * 尖塔盔甲纹饰看起来像[潜影贝](潜影贝.md)。
* * 潮汐盔甲纹饰看起来像[海晶石砖](海晶石砖.md)。
* * 胸甲和护腿前部的恼鬼盔甲纹饰看起来像[唤魔者](唤魔者.md)袍子的门襟，头盔前部的纹饰像是[恼鬼](恼鬼.md)的眉毛。
* * 镶铆盔甲纹饰看起来像是纹理上有铆钉的[铜块](铜块.md)。
* * 涡流盔甲纹饰看起来像[雕纹凝灰岩](雕纹凝灰岩.md)侧面的“气旋”图案。
* 锻造模板的物品纹理都反映了合成它们所需的物品种类。
* * 此外，海岸盔甲纹饰锻造模板上的[藤壶](wzh:藤壺.md)、幽静盔甲纹饰锻造模板上的[幽匿](幽匿.md)虽与合成物品无关，但也反映了它们的获取地点。
* 若不考虑其他复制材料的可再生性，锻造模板必须通过[宝库](宝库.md)战利品才能实现可再生。这是因为可用于复制锻造模板的[钻石](钻石.md)同样依赖宝库战利品实现可再生，而宝库可以被每个玩家打开无限次数<ref></ref>，且[试炼钥匙](试炼钥匙.md)和[不祥试炼钥匙](不祥试炼钥匙.md)是[可再生资源](可再生资源.md)。
