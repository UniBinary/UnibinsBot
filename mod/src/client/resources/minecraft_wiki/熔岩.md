* *熔岩（Lava）**是一种可以造成伤害并导致着火的发光[液体](液体.md)方块，通常生成于[主世界](主世界.md)低于Y=-54以及[下界](下界.md)低于Y=32的地方。

# 生成
熔岩能够生成熔岩（见）。

# = 自然生成 =
熔岩自然生成在[主世界](主世界.md)和[下界](下界.md)。

在主世界：
* 熔岩会替换Y=-63至-55的洞穴和峡谷中的[空气](空气.md)生成；
* * 这意味着如果创建一个没有任何[洞穴](洞穴.md)和峡谷的[自定义](自定义.md)世界，熔岩就不会出现。
* * 熔岩不会替换[废弃矿井](废弃矿井.md)、[地牢](地牢.md)或[要塞](要塞.md)里的空气方块。
* 单个熔岩源会以[涌泉](涌泉.md)的形式出现在崖壁和洞穴的岩壁；
* 熔岩也能以湖的形式生成；
* * 熔岩湖可以在任何[海拔高度](海拔高度.md)、任何[生物群系](生物群系.md)找到，有不同的大小和尺寸，在地下生成时还会在其上方创造一个小型空间。湖中有时候会生成很小的岛屿。
* 熔岩也会在Y=0以下的一些[含水层](含水层.md)中生成，将其中的[水](水.md)完全替代，形成熔岩含水层；
* [平原](平原.md)、[雪原](雪原.md)和[沙漠](沙漠.md)3种类型的[村庄](村庄.md)的铁匠铺里会生成2格熔岩，[热带草原](热带草原.md)村庄的铁匠铺里则会生成1格熔岩；
* [要塞](要塞.md)中，传送门房间的入口两侧各有3格熔岩，末地传送门框架下方会生成9格熔岩；
* [废弃传送门](废弃传送门.md)中会自然生成熔岩；
* [林地府邸](林地府邸.md)的“[铁匠屋](林地府邸/结构#铁匠屋.md)”中会生成2格熔岩，而隐藏房间“[熔岩房](林地府邸/结构/战利品房间#熔岩房.md)”中会生成25格熔岩，其中藏着一个[钻石块](钻石块.md)。

在下界：
* 熔岩在熔岩海中大片地生成，非常常见，出现的频率高于[水](水.md)在[主世界](主世界.md)出现的频率；
* * 熔岩海会在Y=32（海平面）以下生成。
* 单个熔岩源会以[涌泉](涌泉.md)的形式出现于岩壁、天花板和掩藏在岩体中；
* 熔岩也会生成在[下界要塞](下界要塞.md)的熔岩井内；
* 熔岩也会作为[废弃传送门](废弃传送门.md)、[堡垒遗迹](堡垒遗迹.md)的一部分自然生成。

# = 熔岩桶 =
玩家对方块表面[熔岩桶](熔岩桶.md)会尝试在这一位置生成熔岩。使用熔岩桶的[发射器](发射器.md)会尝试在其面朝方向放置熔岩。

# = 流动熔岩转化 =
为时，流动熔岩在两面与熔岩源相邻时转化为熔岩源。

# 获取

熔岩不能获取其物品形式，但玩家可以对准熔岩源方块[铁桶](铁桶.md)来获得[熔岩桶](熔岩桶.md)，从而受控地收集和转移熔岩。

熔岩没有对应的物品形式。

熔岩的物品形式只能通过编辑物品栏获得。

# 破坏
熔岩没有[轮廓箱](轮廓箱.md)，因此不能挖掘熔岩。

熔岩被破坏后不会掉落。

# 用途
# = 流动 =

|熔岩在主世界和末地中的4种形态|style=max-width: 150px}}
|熔岩在下界中的8种形态|style=max-width: 150px}}

熔岩会从“源方块”流出来。大多数的熔岩流或“熔岩瀑布”都是从一个熔岩源方块流出来的，但是熔岩湖（包括湖面下的熔岩流）都完全是由熔岩源方块组成的。只有源方块才能被铁桶采集。

在[主世界](主世界.md)和[末地](末地.md)中，熔岩源可以向任何水平方向流动3格。熔岩流动的速度比水慢得多，每流动1格，并且失去源头的熔岩会多滞留一小段时间。在[下界](下界.md)由全局[环境属性](环境属性.md)<code>gameplay/fast_lava</code>控制。}}中，熔岩水平方向可以流动7格远，每流动1格。

熔岩在流动时会摧毁以下方块：[树苗](树苗.md)、[杜鹃花丛](杜鹃花丛.md)、[盛开的杜鹃花丛](盛开的杜鹃花丛.md)、[蜘蛛网](蜘蛛网.md)、[矮草丛](矮草丛.md)、[枯萎的灌木](枯萎的灌木.md)、[小麦](小麦.md)、[花](花.md)、[蘑菇](蘑菇.md)、地上的[雪](雪.md)（但雪块不受影响）、[细雪](细雪.md)、[睡莲](睡莲.md)、[藤蔓](藤蔓.md)、[拉杆](拉杆.md)、[按钮](按钮.md)、[火把](火把.md)、[灵魂火把](灵魂火把.md)、[红石火把](红石火把.md)、[红石线](红石线.md)、[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)、以及[生物头颅](生物头颅.md)。[甘蔗](甘蔗.md)可以挡住熔岩，但会在熔岩摧毁其水源时消失。

一个方块的熔岩在受到NC[更新](方块更新.md)（例如被给予红石信号）、受到PP更新或在可生成火的条件（可生成火的区域内有毗邻可燃方块的空气且[游戏规则](游戏规则.md)不为-1时）下受到[随机刻](随机刻.md)<ref></ref>时会重新计算流向并流向最近的低洼地区，但也不会取消原来的流向。这个过程是不可逆的。

熔岩流过有效线路中的[绊线](绊线.md)时，会将绊线直接破坏而不掉落线，并触发与其相连的绊线钩。

# = 光源 =
熔岩会发出亮度为15级的光。

# = 伤害实体 =
[缩略图|浸没在熔岩里面时的视觉效果](File:Inside Lava.png.md)
接触熔岩的实体会每受到一次、一次和一次共三次的[火焰伤害](伤害#火焰伤害.md)的[火焰伤害](伤害#火焰伤害.md)会生效。}}（然而[受击后伤害免疫](受击后伤害免疫.md)会将其减慢至每0.5秒受到一次伤害）。这是游戏中最致命的环境伤害来源之一，能够在短时间内迅速杀死大多数[生物](生物.md)，并摧毁其[掉落物](掉落物.md)。

# = 使实体着火 =

接触熔岩的实体的剩余着火时间将被设置为至少}}或}}，该效果受到[火焰保护](火焰保护.md)魔咒的影响。

接触熔岩的[弹射物](弹射物.md)会着火。

# = 生成火 =
|（侧视图）橙色区域表示该熔岩可生成火的范围，<br>灰色区域是橙色区域的毗邻方块，<br>如果灰色和橙色区域存在易燃的方块，<br>则空气可能会传递火。图中的木板都在安全的区域。
}}

熔岩可以在其上方第一层3×3的区域和上方第二层5×5的区域内生成[火](火.md)，若这片区域的任一方块为[空气](空气.md)方块，且其任一毗邻的方块可以被熔岩引燃，则该空气方块就可能变成火方块。可以被熔岩引燃的方块不一定是可以[被火引燃](火#传播.md)的方块。

在任何深度，无论是熔岩源还是熔岩流都可以以这种方式生成火。

由于生成火需要空气方块，且熔岩本身不具备像火一样破坏方块的能力，将可燃方块用[绊线](绊线.md)、[火把](火把.md)甚至熔岩本身替换毗邻的空气方块即可阻止其着火和被火破坏。

# = 熔岩和水的互动 =

* 熔岩源水平方向或上方触碰水源或水流，熔岩源变为[黑曜石](黑曜石.md)；
* 熔岩源下方触碰水源或水流，无反应；
* 熔岩流水平方向或上方触碰水源或水流，熔岩流变为[圆石](圆石.md)；
* 熔岩流下方触碰水源或水流，无反应；
* 熔岩流向下流入水源或水流，流入的熔岩流（被流入的水源或水流）变为[石头](石头.md)；

液体互动时有以下几点需要注意：
* 水平方向上熔岩和水只会发生触碰，不会发生流入，因为触碰时即会发生变化；
* 竖直方向上只有熔岩流会流入水源或水流，水并不会流入熔岩，因为触碰时即会发生变化；
* 无论方向和生成物，所有变化均在熔岩一侧发生。

# = 熔岩与蓝冰的互动 =
熔岩源或熔岩流下方触碰[灵魂土](灵魂土.md)，且水平方向或上方触碰[蓝冰](蓝冰.md)，熔岩源或熔岩流变成[玄武岩](玄武岩.md)。

# = 喷发粒子 =
熔岩中会喷出“火苗”或“火星”。这些粒子效果只有装饰作用，不会引燃可燃方块或对实体造成伤害。当雨滴滴到熔岩时，黑色“火苗”粒子出现的概率会明显地提高。

# = 熔岩滴 =
[缩略图|方块底部的熔岩滴](File:Particle dripLava.png.md)
当熔岩下方的支撑方块不是液体时，如果支撑方块的碰撞箱最高高度<1且熔岩源底面的[方块支撑形状](方块支撑形状.md)完整，那么熔岩滴[粒子](粒子.md)会从熔岩源的底面滴落。如果支撑方块不是[玻璃](玻璃.md)、[遮光玻璃](遮光玻璃.md)或[染色玻璃](染色玻璃.md)且支撑方块的碰撞箱最高高度≥1且支撑方块的碰撞箱最低高度与支撑方块下方方块的碰撞箱的最高高度的和<1时，熔岩滴粒子会在支撑方块的碰撞箱最低处滴落。

当构成钟乳石的[滴水石锥](滴水石锥.md)正好悬挂在原本的熔岩滴粒子滴落面下，那么熔岩滴粒子会从滴水石柱的底部滴落，并在接受到[随机刻](随机刻.md)时，会有（约5.9%）的概率将下方11格内的[炼药锅](炼药锅.md)用熔岩填满，这使熔岩桶成为可再生资源。

# 你知道吗
* 下面列出了玩家可以在熔岩里存活的时间，假定饥饿值与生命值是满的：
* * 未穿着[盔甲](盔甲.md)可存活2.5秒。
* * 穿着全套未附魔的皮革盔甲可存活3.5秒。
* * 穿着全套未附魔的金盔甲可存活或。
* * 穿着全套未附魔的锁链盔甲可存活或。
* * 穿着全套未附魔的铁盔甲可存活或。
* * 穿着全套未附魔的钻石盔甲可存活或。
* * 穿着全套未附魔的下界合金盔甲可存活或。
* 在距离熔岩方块对角1格的地方放置1个水源方块（但不经过角落）将会首先流向熔岩，然后再流向远离熔岩的方向。出现这个现象的原因是水的物理机制将熔岩所在处认定为空的，并且尝试流到那个地方。一旦水把熔岩变成黑曜石后，水的物理机制就会更新为流到其他各个方向。熔岩遇水时也会发生类似的现象。
* 尽管熔岩是流体，但生物不会在熔岩里溺死。这对所有生物都有效，。
* 拥有[抗火](抗火.md)效果的水生生物可以在熔岩中呼吸并存活，但不会游泳。
* 躺在[床](床.md)上的[玩家](玩家.md)和[村民](村民.md)不能被熔岩伤害。
* 尽管熔岩不能直接减免摔落伤害，但在熔岩中每刻會減少一半的摔落高度。
