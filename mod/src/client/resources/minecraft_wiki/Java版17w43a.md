# Java版17w43a

*页面ID: 33053* | *来源: Minecraft Wiki*

<onlyinclude>

* *17w43a**是[Java版1.13](Java版1.13.md)的首个快照，发布于2017年10月25日<ref></ref>，加入了数据包和新的选项，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[选项](选项.md)**
* 加入了FS（全屏）分辨率选项。
* * 用于更改分辨率。

* *[数据包](数据包.md)**
* 类似于[资源包](资源包.md)，但是用于自定义[战利品表](战利品表.md)、[进度](进度.md)、[函数](Java版函数.md)等数据。
* * 把它们放入一个世界的文件夹来使用。
* 数据包为<code>.zip</code>格式文件或者是在根目录上带有<code>pack.mcmeta</code>的文件夹。数据包位于。
* 检查数据包前，结构现在会从中加载。
* * 然而，此目录**不**应该用于发布结构，但可通过把这些文件移入数据包实现。
* 可通过重新加载。
* 结构：<code>pack.mcmeta</code>、一个<code>data</code>包含一个确定其内容的命名空间的文件夹。
* * 一个命名空间只能包含以下字符：
* * 在文件夹内，可以有的子文件夹。

# 更改
# = 常规 =
* *[选项](选项.md)**
* 在视频设置选项中删除3D选项。

* *[控制](控制.md)**
* 键盘名称现在描述了实际的键（例如“LBUTTON” - >“左按钮”，“BACKSLASH” - >“\”）。

* *[资源包](资源包.md)**
* 默认资源包现在可以被上下移动，就像其他的资源包一样。

* *其他**
* 游戏库更新。
* * LWJGL升级至3.1.2。
* 现在加载或创建世界显示加载阶段的百分比。
* * <code>Preparing spawn area</code>（准备生成区域）现在显示为加载阶段。
