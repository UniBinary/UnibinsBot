# 菌丝体

*页面ID: 8239* | *来源: Minecraft Wiki*

{{for|繁体中文译名为“-{菌絲體}-”的方块|菌核}}

</ref>||Marsh Davies Mojang avatar.png}}

* *菌丝体（Mycelium）**是在[蘑菇岛](蘑菇岛.md)生物群系自然生成的方块，其表面会不断释放出微小的孢子粒子。

# 生成
# = 自然生成 =
菌丝体只能在[蘑菇岛](蘑菇岛.md)生物群系的地表生成。

# 获取
# = 末影人 =
手中搬着菌丝体的[末影人](末影人.md)会在死亡时掉落菌丝体。

# 破坏
挖掘菌丝体的合适工具是[锹](锹.md)。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，菌丝体被破坏后会掉落1个[泥土](泥土.md)。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，菌丝体被破坏后会掉落自身。

# 用途
[末影人](末影人.md)可以搬起及放下菌丝体。关闭[游戏规则](游戏规则.md)将阻止该行为。

# = 种植 =
[蘑菇](蘑菇.md)可以种植在任何[亮度](亮度.md)等级的菌丝体上，且菌丝体上的蘑菇能够生长为[巨型蘑菇](巨型蘑菇.md)。

与[草方块](草方块.md)或[泥土](泥土.md)类似，[树苗](树苗.md)、[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)、[蕨](蕨.md)、[大型蕨](大型蕨.md)、[灌木丛](灌木丛.md)、[枯萎的灌木](枯萎的灌木.md)、[花](花.md)、[粉红色花簇](粉红色花簇.md)、[野花簇](野花簇.md)、[甘蔗](甘蔗.md)、[甜浆果丛](甜浆果丛.md)、[大型垂滴叶](大型垂滴叶.md)、[下界菌](下界菌.md)、[菌索](菌索.md)、[下界苗](下界苗.md)、[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)能够被放置在菌丝体上。

# = 扩散 =
与草方块相同，菌丝体的扩散取决于[随机刻](刻#随机刻.md)。

要使[泥土](泥土.md)接受附近菌丝体的扩散，必须达到下列要求：
# 以菌丝体下方的方块为扩散中心，被菌丝体扩散的泥土必须在该中心3×5×3的范围内。
# 菌丝体的上方必须至少有9级的[亮度](亮度.md)。
# 泥土上方不能被任何下表面[遮挡形状](遮挡形状.md)完整的方块覆盖，但可以是一层高的[雪](雪.md)。
# 泥土上方不能是[水](水.md)，也不能是任何[含水](含水.md)的方块。

如果泥土上有不能被放置在菌丝体上的植物，则泥土受菌丝体扩散后植物就会被破坏。

# = 转变 =
如果菌丝体直接被液体源方块或任何下表面[遮挡形状](遮挡形状.md)完整的方块覆盖（一层高的[雪](雪.md)除外），菌丝体将会在随机时间后变为[泥土](泥土.md)。

对着菌丝体[锹](锹.md)可将其转变为[土径](土径.md)，但菌丝体无法被[锄](锄.md)犁成[耕地](耕地.md)，与[灰化土](灰化土.md)相同。

若菌丝体被[雪](雪.md)或[雪块](雪块.md)覆盖，其顶部和侧面的菌丝体纹理会变成被雪盖住的样子，将其上方的雪移除后便会立即恢复原样。这一点与草方块相同。

对上方为[空气](空气.md)的[苔藓块](苔藓块.md)或[苍白苔藓块](苍白苔藓块.md)[骨粉](骨粉.md)会使周围7×11×7范围内，最上方的菌丝体转变为苔藓块或苍白苔藓块。

[大型云杉](大型云杉.md)长成后会将它下方及周围的菌丝体转变为[灰化土](灰化土.md)。

[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)长成[杜鹃树](杜鹃树.md)后会将其下方的菌丝体转变为[缠根泥土](缠根泥土.md)。

除大型云杉、杜鹃树、[红树](红树.md)外的[树木](树木.md)长成后，下方的菌丝体会被转变为[泥土](泥土.md)。

# = 哞菇 =

当光照等级不低于/时，红色哞菇会生成在生物群系的菌丝体上。这也是唯一一种可以自然生成红色哞菇的方块。
