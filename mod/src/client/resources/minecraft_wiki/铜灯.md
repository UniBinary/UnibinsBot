# 铜灯

*页面ID: 106609* | *来源: Minecraft Wiki*

* *铜灯（Copper Bulb）**是一种会随着时间缓慢生锈的照明[方块](方块.md)，接收到红石脉冲信号时会切换开关状态。

# 生成
铜灯、斑驳的铜灯、锈蚀的铜灯、氧化的铜灯不会生成在世界中，只能通过[氧化](氧化.md)机制生成。

# = 自然生成 =
涂蜡的铜灯、涂蜡的斑驳铜灯、涂蜡的锈蚀铜灯和涂蜡的氧化铜灯可以生成在[试炼密室](试炼密室.md)中，且均为点亮状态。

# 破坏
挖掘铜灯的合适工具是镐。铜灯需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

铜灯被破坏后会掉落自身。

# 用途
铜灯属于[机械元件](红石元件#机械元件.md)，可被下列形式激活：
* 毗邻的开启的**[电源](红石元件#电源.md)**（例外：[红石火把](红石火把.md)不会激活其所附着的铜灯，[侦测器](侦测器.md)只会激活指向的铜灯）。
* 毗邻的**[充能方块](红石电路/充能与激活.md)**。
* 毗邻的指向铜灯且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)（包括铜灯上方的红石粉）；毗邻但未指向铜灯的红石粉不会激活铜灯。

在同一红石刻内，电容器更新阶段前存在，但在电容器更新阶段被取消的信号无法激活铜灯。

铜灯接收到红石脉冲后，会或切换点亮和熄灭状态。该延迟通过创建一个后的[计划刻](计划刻.md)来实现。

铜灯纹理中心具有一个红点，在其被激活时亮起，而无论铜灯是否点亮。

[红石比较器](红石比较器.md)可以检测铜灯的状态。无论其是否氧化，只要铜灯点亮，比较器会发出15级的红石信号；铜灯熄灭时比较器不会发出红石信号。

铜灯搭配红石比较器可构建又小又快且无需上升沿探测器的[T触发器](记忆电路#T触发器.md)。

; ：
   铜灯相较其他消费者元件额外具有1游戏刻延迟，因此会在红石刻工作。
   铜灯不具有“晋升为信号源”属性，因此铜灯不能被[充能](红石电路/充能与激活.md)，但可以[压线](红石粉#形状.md)。

# = 光源 =
铜灯是一种可控[光](光.md)源，放置时默认为熄灭状态。

点亮的铜灯会发出其氧化程度对应亮度等级的光。

# = 氧化 =

铜灯受氧化机制影响，能够在不同变种之间转化。

铜灯的亮度等级会随氧化程度增加而衰减。
