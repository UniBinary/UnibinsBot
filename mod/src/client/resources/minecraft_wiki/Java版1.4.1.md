# Java版1.4.1

*页面ID: 33295* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.4.1**是[Java版1.4.2](Java版1.4.2.md)的第2个，也是最后一个预发布版，发布于2012年10月23日<ref></ref>。

# 更改
# = 方块 =
* *[铁砧](铁砧.md)**
* 调整了在[铁砧](铁砧.md)上重命名的费用。

# = 生物 =
* *[蝙蝠](蝙蝠.md)**
* 降低了[蝙蝠](蝙蝠.md)生成频率。

# = 非生物实体 =
* *[画](画.md)**
* 启用关于[凋灵](凋灵.md)的[画](画.md)。

# = 游戏内容 =
* *[经验](经验.md)**
* 调整了从[烧炼](烧炼.md)得到的[经验值](经验值.md)。

# 修复

* 修复了生物通过木地板时的错误。
* 修复了玩家走过信标时的错误。
* 修复了红石中继器卡在“开”的状态。
* 修复了一些较小字体的问题。
* 修复了湿的狼的样子太吓人。
* 修复了一个允许任何物品放入盔甲槽的漏洞。
* 修复了刷怪笼刷生物太快。
* 修复了下落的沙子不可见。</onlyinclude>
