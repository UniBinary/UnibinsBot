# 基岩版1.16.210.58

*页面ID: 77693* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.210.58**是[基岩版1.16.210](基岩版1.16.210.md)的第8个测试版，发布于2021年2月3日<ref></ref>，做出了一些技术性更改，并修复了一些漏洞。

# 更改
# = 非生物实体 =
* *[掷出的末影珍珠](掷出的末影珍珠.md)**
* 现在爆炸不再会摧毁掷出的末影珍珠，而是推动掷出的末影珍珠。<!--询问基岩版珍珠炮玩家所得-->

# = 命令格式 =
* ***
* 再次将此命令完全移除。

# = 常规 =
* *[设置](设置.md)**
* 由于Mixer流媒体服务不再可用，游戏将广播选项完全移除。

# = 技术性 =
* *组件变量**
*  - 一个可选对象，用于储存玩家右手的和可选切换数据。
*  - 一个可选对象，用于储存玩家左手的和可选切换数据。
*  - 一个可选对象，用于储存、和3个向量，以构建第一人称矩阵。
*  - 一个可选对象，用于储存、和3个向量，以构建第三人称矩阵。

* *渲染偏移组件**
* 如[剑](剑.md)或[镐](镐.md)等简单物品可以对其应用可选的偏移量以改变其渲染方式。
* * 注意：该组件不应该应用到附加物品中。

# 修复
* *辅助功能**
* 现在屏幕阅读器会正确读取个人资料界面上的“编辑/创建角色“按钮的文字。

* *性能与稳定性**
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了抗锯齿设置设为1时打开成就界面可能发生的崩溃。（）

* *常规**
* 修复了刻无法影响方块更新状态的漏洞，这使得农作物和树苗等植物能够再次正确生长。（）
* 修复了玩家在生存模式中使用工具挖方块后无法与物品栏中的工具交互的问题。（）
* 修改了干海带块的底面纹理，使其纹理上的“捆绳”和其他面对齐。（）
* 修复了下雪时在特定模拟距离的雪形成直线的问题。（）
* 现在水中爆炸的TNT会将生存模式的玩家推开。
* 修复了成就名称和描述未被翻译成所选择语言的问题。（）
* 检测到更改后，邀请屏幕上显示的跨平台好友的在线状态将会立即更新。（）
* 修复了更改语言设置后无法正确显示成就奖励的问题。
* 已拥有的和可购买的皮肤在离线时不再被分为不同的类别。
* 重新进入选项卡后，表情界面不再显示之前预览过的表情。
* 更新了游戏中通向反馈网站和漏洞追踪器的链接。

* *图形**
* 现在山羊及其他有色刷怪蛋在手持时会正确渲染。（）
* 修复了屏幕分辨率在调整窗口大小时可能会闪烁的问题。（）
* 现在使用材质状态“Blending”的实体在透明物体后面时会正确渲染。

* *技术性**
* 在市场的地图“Dragons!”中，重新加载带有穿上鞍的龙的地图不再导致行为动画控制器停止工作。
* 禁用了自定义生物群系功能中的实体加载。
* 修复了数据驱动方块的UV会略微收缩且会导致纹理像素扭曲的问题。
* 修复了数据驱动方块被活塞推动后其无法正常工作的问题。</onlyinclude>
