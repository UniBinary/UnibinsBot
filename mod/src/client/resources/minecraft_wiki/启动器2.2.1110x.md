# 启动器2.2.1110x

*页面ID: 93392* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.2.11103**（）、**2.2.11105**（，版）、**2.2.11104**（）或**2.2.11106**（）是一次[启动器](启动器.md)更新，发布于2022年3月1日。

# 新内容
* 在账户选项卡中“清除已缓存的账户令牌”高级设置按钮上加入了鼠标悬停文本。

# 更改
* 使一些错误信息更易读且更有作用。
* 更新了“编辑配置”界面图标列表中一些已过时的纹理。

# 修复
* 修复了各种内部稳定性和可靠性的问题。
* 修复了与Mojang账户迁移至微软账户有关的问题。
* 修复了批量安装对话框的默认逻辑。
*  - 具有有效的Xbox Game Pass订阅情况下，仍会显示演示模式。
*  - 重启启动器后会退出登录。
*  - 游戏会卡在“Making things awesome”界面上。
*  - 在启动器上设置用户名时有13字符数的限制。
*  - 皮肤选项卡中，玩家模型的腿和躯干相交时会出现深度冲突。
*  - 《Minecraft Dungeons》的FAQ中的问题“如果我拥有《Minecraft Dungeons》，启动器中应该显示哪个版本？”的答案的英文版本出现语法错误。
*  - 账户迁移FAQ页面中的问题“我能把自己的旧版Minecraft账户迁移到Microsoft账户吗？”的答案的英文版本中，“account”一词的单复数有误。
*  - 部分字符串中“Minecraft: Java Edition”的拼写不一致。</onlyinclude>
