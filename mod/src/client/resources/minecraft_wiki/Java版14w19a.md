# Java版14w19a

*页面ID: 33978* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w19a**是[Java版1.8](Java版1.8.md)的第22个快照，发布于2014年5月8日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[活塞](活塞.md)与[黏液块](黏液块.md)**
* 黏液块现在可以横向或向下推动玩家。
* * 在地面上的实体要比在空中的实体受力更小。

# = 世界生成 =
* *[世界边界](世界边界.md)**
* **警示**，一个在世界边界近处时可以看到的红色光晕。
* * 仅在高品质模式中可见。
* * 在边界外时，警示的效果保持在最大。
* * 在边界内时，警示的效果随着玩家接近边界时变大。
* * 如果边界是静态的，警示会在玩家进入警示距离时出现，默认距离为5米。
* * 如果边界正在缩小，警示将在边界在警示时间内抵达时开始出现，默认时间为15秒。
* 新的选项
* * amount>}}
* ** <code>buffer</code>是玩家在越过边界后会开始受伤害前的距离（默认为）。
* ** <code>amount</code>是玩家每越过边界缓冲段一米所受到的伤害（默认为）。
* * distance>}}
* ** <code>time</code>为给玩家的提前提示时间（秒），游戏将会使用红色的边框来提醒边界正在逐渐缩减到他们的位置（默认为）。
* ** <code>distance</code>为红色边框会离边界显示的距离（米）（默认为）。
* 在[下界](下界.md)的边界大小现与和[主世界](主世界.md)的相同。
* 下界传送门
* * 传送到下界时将不会在边界外创造新的传送门。
* * 玩家仍可能传送到在边界外的传送门。

# = 游戏内容 =
* *[旁观模式](旁观模式.md)**
* 旁观者现有一个用于传送到别的玩家的界面。
* * 通过鼠标中键或数字键触发。
* 当可传送的玩家超过8名时，两边会改为箭头。
* 当队伍创建后，队伍可以选择只显示那队的玩家。
* 数字键和“捡起方块”键再加上滚轮可以用来控制界面。
* 可以跨维度传送。
* * “距离完成还有段时间。”
