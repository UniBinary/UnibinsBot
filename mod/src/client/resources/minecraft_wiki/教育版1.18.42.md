# 教育版1.18.42

*页面ID: 99440* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.18.42**是的一次次要更新，发布于2022年10月25日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *[多人游戏](多人游戏.md)**
* 改进了多人游戏对代理的支持。
* 提高了多人游戏会话的连接可靠性。

* *图书馆**
* 现在使用新的图书馆搜索栏来搜索内容时，会比以前更容易搜索到整个游戏内的图书馆中的内容。

* *代码**
* 现在代码窗口在移动设备上默认全屏显示。

# 修复
* 提升了性能与稳定性，并修复了各种漏洞。
