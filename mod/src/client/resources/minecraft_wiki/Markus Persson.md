* *马库斯·阿列克谢·佩尔松（Markus Alexej Persson）**，人称**Notch**，是[Minecraft](Minecraft.md)的缔造者以及[Mojang Studios](Mojang Studios.md)的联合创始人之一，现已离职。

# 人物事迹
# = 早年 =
Persson出生于瑞典[斯德哥尔摩](wzh:斯德哥尔摩.md)<ref></ref>。他7岁前居住在[埃斯宾](wzh:埃斯宾.md)，后移至斯德哥尔摩上学。他初次接触编程是7岁时在他父亲的[康懋达128](wikipedia:Commodore 128.md)上。他8岁时借助即输入即运行（type-in，纸质载体上的程序代码）的编码写出了自己的首个文字冒险游戏，虽然没有画面而只有一些文字组件。13岁时，他有了一台[雅达利ST](wzh:雅達利ST.md)，并随几名朋友编写了几段程序。15岁时，他决意成为一名电子游戏开发员，但是他的老师建议他学习图形设计。Persson因此继续在印刷媒体专业进学3年。<ref>http://guru.bafta.org/markus-persson-interview</ref>他没有受过编程培训，他学习的编程语言（包括C++）都于互联网上自学。

修完印刷媒体专业后，Persson在斯德哥尔摩的一家小型网页设计公司求得一职，但他仅在那里工作了6个月。可当他应聘新工作时，世纪初的[互联网泡沫](wzh:互聯網泡沫.md)破裂，他因此无法找到工作，和他的母亲居住了2年。机缘巧合的是，他渐渐开始做起网页开发。

2002年，Persson在Game Federation谋得一份程序员的工作，但是不是开发游戏。他和同事们以及朋友Rolf Jansson都是游戏的狂热爱好者，他于同年成立名为Mojang Specifications的公司。很快，他们开始开发[Wurm Online](Wurm Online.md)，并以公司名义发布。

# = 开发游戏 =
2005年，Persson跳-{槽}-到[King](King.md)公司，<ref></ref>他终于能在这里编写游戏。他为该公司编写了超过30款Flash小游戏。2007年，Persson抛弃了Wurm Online计划，并请求Jansson让自己保留Mojang Specification的名号。他同意了，并将Wurm Online的公司改名为Onetoofree AB。

2009年5月，将近30岁的Persson开始开发Minecraft，这一开始只是工作之余的小项目，因为他此时在[Jalbum](wikipedia:Jalbum.md)的工作与游戏开发无关而是网页开发，<ref></ref>Minecraft逐渐受到他关照。

然而，Minecraft这一业余项目日渐受欢迎，Minecraft的销量提高后，他在Jalbum的工作从全职改为兼职，并最终在2010年6月辞职来全力开发Minecraft。<ref></ref>许多Mojang AB的雇员（包括CEO [Carl Manneh](Carl Manneh.md)）都是Jalbum的前雇员。除了工作，他经常参加小比赛，例如[Ludum Dare](wzh:Ludum Dare.md)、LD12与Java 4K游戏开发大赛。

Persson与Ez在印度尼西亚度假时订婚，<ref></ref><ref></ref>并于2011年8月13日结婚，之后两人在2012年8月15日分道扬镳。<ref></ref>她的哥哥[Kristoffer](Kristoffer.md)是游戏内[繪畫](繪畫.md)的画师。

# = 离开Mojang =
Persson在2014年9月15日将Mojang及公司资产出售给微软。在一篇长博文中，Notch表示“我热爱游戏，我热爱编程，但我不喜欢为了使游戏红极一时而制作它们，我也不想去改变世界。”他又表示，“我已经成为了一种标志。我不想成为标志，也不想对大到我无法理解、不愿从事的事情负责。”<ref>[File:Notch_Blog_2014-Sep-15.png](Media:Notch_Blog_2014-Sep-15.png.md)</ref>

2014年11月5日，Persson与其他创始人从Mojang离职。他写道：“一旦这场交易完成，我就会离开Mojang回去参加[Dare](http://ludumdare.com/compo/Ludum)比赛，还有做些网页实验。如果我不小心做成一件可能会受欢迎的东西，我可能会马上把东西给抛弃掉。”翌日，交易完成，Persson离开了公司。
