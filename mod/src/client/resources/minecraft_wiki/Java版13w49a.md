# Java版13w49a

*页面ID: 33606* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w49a**是[Java版1.7.4](Java版1.7.4.md)的第8个，也是最后一个快照，发布于2013年12月5日<ref></ref>，加入了鸡骑士，更改了[Mojang](Mojang.md)徽标的尺寸，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[鸡骑士](鸡骑士.md)**
* 为幼年[僵尸](僵尸.md)骑着一只[鸡](鸡.md)的组合。
* * 僵尸能够控制鸡而不是使用鸡的AI。
* * 不会受到掉落伤害。
* * 极其稀有。

# 更改
# = 常规 =
* *Mojang徽标**
* [Mojang](Mojang.md)徽标的大小由512×512变为256×256。

# 修复
</onlyinclude>

# 你知道吗
* 此版本曾经在[启动器](启动器.md)中移除，但在2018年9月重新加入。
