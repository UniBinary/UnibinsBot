# Java版Beta音效更新

*页面ID: 20351* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta音效更新（Beta Sound Update）**是2011年11月14日对游戏音效资源的一次更新<ref></ref>。客户端版本没有升级。声音效果升级了，原来未能实现的声音效果也得到了实现。两天后，增加的声音在[Java版1.0.0](Java版1.0.0.md)的第一个预览版本中更新。

# 更改
# = 常规 =
* *音效**
* [箭](箭.md)发射的声音更改了。
* [箱子](箱子.md)开关的声音现在与门不同了。
* [铁门、木门](门.md)、[活板门](活板门.md)和[栅栏门](栅栏门.md)开关的声音更改了。
* [经验球](经验值.md)被拾取时会发出闪烁声。
* 弹射物品（[雪球](雪球.md)、[鸡蛋](鸡蛋.md)、[钓鱼竿](钓鱼竿.md)和[末影珍珠](末影珍珠.md)）的声音更改了。
* [爆炸](爆炸.md)现在有多种不同的声音。

# 你知道吗
* 音效资源更新后，它被应用到所有Minecraft版本中，包括所有的Alpha和Beta版本。
