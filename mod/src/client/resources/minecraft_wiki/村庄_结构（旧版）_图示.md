# 结构
所有村庄都会生成的唯一结构是一口[水井](/水井.md)。村庄最常生成的是几个农场和房屋，而铁匠铺、肉铺、教堂和图书馆则较为稀有。较小的村庄可能不包含上述稀有结构中的任何一种，而较大的村庄则可能会生成多个或多种。

街道以如下方式生成：以[草径](草径.md)替换[草方块](草方块.md)，对应[木板](木板.md)（沙漠村庄中为[砂岩](砂岩.md)）替换[水](水.md)和[熔岩](熔岩.md)，下方有圆石支撑的[沙砾](沙砾.md)替换其他方块。街道均为3个方块宽，从水井处向四个主方向延伸。所有街道均为直线状，在拐角处呈直角。街道不一定是平坦的。

圆石楼梯可以出现在村庄建筑的门口，并且：
* 当这座建筑的入口与街道高度相同时，楼梯不会生成。
* 当建筑入口高于街道所在平面时，楼梯会生成在门口，方便村民进出屋门。
* * 如果建筑入口高度距离街道超过两格，则会在每一级楼梯下生成圆石作为基底，一直延伸至与街道相同的高度上。

在生成所有不对称的建筑，如肉铺和铁匠铺、图书馆时，均有可能产生镜像反转的结构。

村庄的某些建筑，如铁匠铺、小型房屋，不会自然生成门。

建筑物的屋顶以及一些建筑物内部的“长凳”装饰使用的方块并不是转角楼梯，而是对应的木板。

# = 变种 =
村庄有4个变种：

平原村庄主体使用橡木-{}-材质，针叶林村庄使用云杉木-{}-材质；热带草原村庄使用金合欢木-{}-材质，同时会以[金合欢原木](金合欢原木.md)会替代圆石生成；沙漠村庄会以[砂岩](砂岩.md)替代圆石和原木，替代[木板](木板.md)，而木门和木栅栏仍然使用橡木-{}-材质。此外，构成铁匠铺、教堂和水井的圆石不会被替换为金合欢原木或砂岩。

村庄有概率生成为僵尸村庄。此类村庄中的[门](门.md)和[火把](火把.md)会消失，[僵尸村民](僵尸村民.md)会代替村民生成。苔石还会代替绝大部分圆石生成。
