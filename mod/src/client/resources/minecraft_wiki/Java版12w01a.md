# Java版12w01a

*页面ID: 32120* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w01a**是[Java版1.1](Java版1.1.md)的第5个，也是最后一个快照，发布于2012年1月5日<ref></ref>，加入了[超平坦世界](超平坦世界.md)和[沙滩](沙滩.md)[生物群系](生物群系.md)，并加入和移除了一些[语言](语言.md)。

# 新内容
# = 世界生成 =
* *[沙滩](沙滩.md)**
* 重新加入了自[Beta 1.8](Java版Beta 1.8.md)移除的沙滩。
* 现在是[生物群系](生物群系.md)而非地形特征。

* *[超平坦](超平坦.md)**
* 由[草方块](草方块.md)、[泥土](泥土.md)和[基岩](基岩.md)组成的完全平坦的世界，该世界也会生成[村庄](村庄.md)。

* *[世界类型](世界类型.md)**
* 重新加入了自[Infdev](Java版Infdev.md)移除的世界类型。
* 在选择界面中加入了世界类型选项。
* * 目前只有默认和超平坦两种选项。

# = 常规 =
* *语言文件**
* 加入了18种[语言](语言.md)。
* 移除了4种[语言](语言.md)。

# 更改
# = 方块 =
* *[梯子](梯子.md)**
* 移除了梯子的碰撞箱，这意味着梯子不再是固体且实体无法站立其上。
* *[栅栏门](栅栏门.md)**
* 升级了栅栏门的碰撞箱，使其大小与[栅栏](栅栏.md)一致。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 更改了刷怪蛋的颜色，为的是更好地代表各自刷怪蛋生成的[生物](生物.md)。
* 刷怪蛋在创造模式物品栏中已重新排序：

* *  [岩浆怪](岩浆怪.md)
* *  [哞菇](哞菇.md)

* *[苹果](苹果.md)**

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 生物群系颜色现在可以较平滑地进行过渡。
* 为沼泽生物群系与其他生物群系之间加入了正确的颜色过渡。
* 生物群系变得更多样化，包括了森林和沙漠生物群系中的山丘。

* *[村庄](村庄.md)**
* 铁匠铺里现在会生成一个包含战利品的[箱子](箱子.md)。

# = 常规 =
* *[药水酿造](药水酿造.md)**
* 酿造时间减少，现在为20秒。

* *[附魔](附魔机制.md)**
* 调整了附魔的随机性。现在，很多高级魔咒获得的概率降低了。</onlyinclude>
