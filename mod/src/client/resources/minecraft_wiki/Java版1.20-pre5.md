# Java版1.20-pre5

*页面ID: 104289* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.20-pre5**是[Java版1.20](Java版1.20.md)的第5个预发布版，发布于2023年5月23日<ref></ref>，将Unifont更新为15.0.03，并修复了一些漏洞。

# 更改
# = 常规 =
* *[资源包](资源包.md)**
* 将字体从Unifont 15.0.01更新为Unifont 15.0.03。
* * 向Unifont字体文件内加入了一部分[Unicode第2平面](wzh:Unicode字符平面映射#第二輔助平面.md)的中日韩统一表意文字，以覆盖[《通用规范汉字表》](wzh:通用规范汉字表.md)的所有汉字（如化学元素及部分地名、人名用字等），以及一部分第3平面的中日韩统一表意文字，例如[𰻝𰻝（Biángbiáng）面](wzh:𰻝𰻝面.md)的前两个字。
* * 更新了U+FF00到U+FFEF的全角标点及符号，使得其不再呈现为半角拉伸的形态。
* * 微调了其他的部分字形，其中包括臭鼬表情符号（U+1F9A8）的字形。<ref>[GNU Unifont Glyphs - Unifoundry.com](http://unifoundry.com/unifont/index.html), [Wayback Machine上的存档](http://web.archive.org/web/20230523154307/http://unifoundry.com/unifont/index.html)</ref>
