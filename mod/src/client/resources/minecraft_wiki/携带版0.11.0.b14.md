# 携带版0.11.0.b14

*页面ID: 27877* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 14（RC）**是[v0.11.0 alpha](携带版0.11.0.md)的第14个测试版，发布于2015年5月28日。此版本是[v0.11.0 alpha](携带版0.11.0.md)的唯一一个发布候选的版本<ref></ref>。

# 更改
# = 方块 =
* *[草丛](草丛.md)**
* 高草丛和大型蕨的像素现在是方形的。
* 草和蕨的高度现在是随机的。

# = 物品 =
* *[雪球](雪球.md)**
* 加入到[创造模式物品栏](创造模式物品栏.md)里。

# = 生物 =
* *[玩家](玩家.md)**
* 从创造模式中彻底移除了玩家燃烧动画。
* 更改上[船](船.md)方式，这使得[玩家](玩家.md)上船时可以同时操控交互按钮（D-Pad）与方向键。

* *[骷髅](骷髅.md)**
* 提升了射箭准确度。

# = 游戏内容 =
* *[皮肤](皮肤.md)**
* 将自带皮肤“土匪”改为细模型。

# = 常规 =
* *[控制](控制.md)**
* 优化了按键被文字覆盖的效果。

* *存档**
* 游戏将会尝试修复损坏的世界。

# 修复

* *其他漏洞**
* 从输入槽里移除物品时物品消失。
* 玩家-{中毒}-后游戏崩溃。
* 合成时木头的种类显示错误。
* 岩浆怪刷怪蛋的纹理错误。
* 自然生成的熔岩不受重力影响。
* 创造模式下会显示燃烧纹理。
* 手持物品显示不正确的纹理。
* 破坏高草丛时显示错误的粒子。
* 乘船的玩家不会显示聊天和暂停游戏的按钮。
* 客户端里的玩家不能上船。
* 持有空物品时游戏崩溃。
* 洞穴蜘蛛的眼睛纹理丢失。
* 修复了字符串末尾的[NUL]字符。
* 在船上的已驯服生物不再传送到玩家身边。
* 修复了床和洞穴的重生机制。
* 玩家被杀死后生成在同一个高度。
* 处于创造模式的客户端在切换为生存模式时，拥有无限物品。
* 移除了“iMojang”字符串。
* 玩家会在地里生成。
* 修复了多任务切换时导致游戏崩溃的漏洞。
* 修复了客户端不可见的漏洞。
* 投掷雪球使得游戏崩溃。
* 玩家重生后，仍会受到中-{}-毒伤害。
* 状态效果导致内存溢出。
* 加入世界后玩家生成在错误的位置。
* 玩家会一直播放濒死动画。
* 放置后的告示牌被其他玩家破坏时游戏崩溃。
* 熔岩产生的火偏向于朝向东方和北方。
* 对着高草丛多次使用骨粉使得游戏崩溃。
* 末影人不会躲开弹射物。</onlyinclude>
