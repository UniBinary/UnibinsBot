* *村庄（Village）**是自然生成在[主世界](主世界.md)的建筑物群，生活着[村民](村民.md)、[猫](猫.md)、[铁傀儡](铁傀儡.md)；[流浪商人](流浪商人.md)和[行商羊驼](行商羊驼.md)也偶尔会在此居住。其少见的[僵尸村庄](#僵尸村庄.md)变种则居住着[僵尸村民](僵尸村民.md)。

# 生成
[缩略图|一个平原村庄](File:NewPlainsVillage.png.md)
[缩略图|一个针叶林村庄](File:Taiga Village 1 14 1.png.md)
[缩略图|在水下观察生成于深海上方的村庄，可见其中建筑的底座](File:Village in the Deep.png.md)

下表列举了在默认情况下能生成村庄的[生物群系](生物群系.md)，以及生物群系的对应村庄样式。通过[Mod](Mod.md)、或生成在非下述生物群系的村庄则会统一使用平原样式。

如果村庄的建筑或道路生成在半空中，则其下方会生成由草方块或沙子（方块种类取决于生物群系）组成的圆形或方形平台，这可能会使地表看上去较为怪异。这可以在村庄生成在海上时被明显地观察到。如果农田生成在山上，则其下方往往会产生一片空地。

村庄生成的村民的数量取决于有效[床](床.md)的数量和村庄的类型。村民只会自然生成在有床的房屋里，而在没有床的工作站点建筑中不会生成村民。

村庄有2%的概率生成为僵尸村庄，详见[僵尸村庄](村庄#僵尸村庄.md)。

[超平坦世界](超平坦世界.md)类型可以生成平原村庄。

村庄可通过[村庄地图](村庄地图.md)定位。与制图师[村民](村民.md)进行交易可获得各种村庄地图，详见。

# 事件
# = 袭击 =

如果玩家饮用[不祥之瓶](不祥之瓶.md)，会获得时长100分钟的[不祥之兆](不祥之兆.md)状态效果。如果此玩家进入村庄范围内，不祥之兆效果会转变为时长30秒的[袭击之兆](袭击之兆.md)，袭击之兆倒计时结束后会触发袭击事件并生成许多[灾厄村民](灾厄村民.md)来攻击村民。

# = 僵尸围城 =

当僵尸围城发生时，许多僵尸会在村庄附近无视[亮度](亮度.md)和围墙地生成。僵尸围城有10％的概率在每个游戏日的午夜或雷暴期间发生，且该事件在村庄中有至少20张有效[床](床.md)时才有机会触发。

# 结构

[缩略图|右|平原村庄中一处带阁楼的房屋](File:Lofthouse.png.md)

# = 结构目录 =
村庄的结构文件存储在<samp>[client.jar](client.jar.md)/data/minecraft/structure/village</samp>或<samp>data/behavior_packs/vanilla/structures/village</samp>中。

# = 房屋 =
每一个村庄的建筑物数量都可以是不同的，也不是所有村庄都是由所有建筑物组成。除了唯一的、系统性的会合点，每种建筑物的数量都是随机的，而且在[超平坦](超平坦.md)世界中会生成更多。街灯和其他装饰性建筑（干草捆堆、西瓜堆、南瓜堆、雪块和冰块堆）的数量没有限制，如果一个地方无法放置其他建筑物，就可以生成它们。道路会生成在建筑物之间并通常延伸到村庄外围。

结构是从一个加权的概率表中随机选出的。村庄中建筑类型的权重和村庄的类型有关，例如武器匠店铺在针叶林村庄中比在其他村庄中更为常见。

建筑风格和构成村庄结构的方块，因村庄类型而异。不是所有的建筑都能在同一个村庄里生成，尽管有些方块会出现在所有村庄中（如工作点方块和食物）。

# = 道路 =
村庄道路基于现有地形生成，因此它可能向上攀爬高山或向下进入至峡谷，而不会考虑一个实体是否可以走过。道路不会延伸至海平面下并只会取代[草方块](草方块.md)（上方有空气的）、[水](水.md)、[熔岩](熔岩.md)、[沙子](沙子.md)、[砂岩](砂岩.md)和[红砂岩](红砂岩.md)；所有其他方块会被忽略而下方的方块会被当作替代。

在平原、热带草原、针叶林和雪域村庄中，道路由土径和草方块组成。热带草原村庄也会在道路中生成耕地和农作物。生成在水上方的土径会被村庄风格类型的木板取代。沙漠村庄会生成[平滑砂岩](平滑砂岩.md)道路。

在洞穴[自选世界](自选世界类型.md)中，村庄道路会与建筑物生成在不同的层上。而在浮岛自选世界中，村庄可能不会生成道路。

# = 构成方块 =

# 僵尸村庄
[缩略图|一个僵尸村庄](File:Abandoned Village.png.md)

一个村庄生成时有2%的概率生成为**僵尸村庄**（**Abandoned Village**或**Zombie Village**）。在僵尸村庄中，所有生成的村民都会被[僵尸村民](僵尸村民.md)取代，带有职业的[僵尸村民](僵尸村民.md)会在相应的建筑物中生成。在僵尸村庄生成的僵尸村民会有意躲避阳光，且不会自然消失。僵尸村庄在生成时不会生成[铁傀儡](铁傀儡.md)。在僵尸村庄中，所有的[门](门.md)和光源都会消失（除雪原村庄部分会合点），村庄结构生成的方块将随机地被[蜘蛛网](蜘蛛网.md)取代，绝大部分[圆石](圆石.md)则会被[苔石](苔石.md)取代，所有的[玻璃板](玻璃板.md)也被替换为棕色染色玻璃板。僵尸村庄中也可能出现流浪猫。

# 机制

自然生成的村庄至少由一个有效的床和一个村民组成。在极其罕见的情况下，村庄只生成没有床的建筑物，因此不会被游戏识别为一个村庄。

# = 有效床 =

有效床是指不被其他方块阻碍而村民可以用来睡觉的床，而一张有效床如果没有村民与之绑定则为空闲有效床。

如果两个村民附近有空闲有效床，且具有繁殖意愿，则可以生成新的村民。

# = 村庄与范围 =

当有至少一个[村民](村民.md)认领一张[床](床.md)时，即创建出一个村庄。除非至少一张床与村民之间的关系解除（即床被破坏、玩家在这张床上睡觉、或村民无法成功寻路接近床），否则这个村庄会持续存在。在第一个村民认领了一张床后，就会以此床头下方方块的上表面西北角为中心创建出一个大小为65×25×65的村庄。村庄范围的中心由[兴趣点](基岩版存档格式/其他数据格式#兴趣点.md)方块（可以为[床](床.md)、[工作站点方块](工作站点方块.md)或[钟](钟.md)）确定。随着其他村民认领兴趣点方块或与之解除关系，村庄的边界与中心会相应发生变化。这意味着新的村庄中心不再是第一个村民认领的床。若村庄中的村民认领的兴趣点位于当前村庄范围之外，村庄范围会进行最小代价的扩张，将新的兴趣点纳入村庄范围。

游戏内并不存在村庄的数据结构，游戏仅是将已绑定有效床、工作站点或[钟](钟.md)的3&times;3[子区块](子区块.md)范围内的空间识别为“村庄”；同时，也不存在村庄中心的概念。

任何村民、村庄生成的[铁傀儡](铁傀儡.md)、[僵尸围城](僵尸围城.md)生成的僵尸或[袭击](袭击.md)生成的[灾厄村民](灾厄村民.md)和[女巫](女巫.md)会在发现自己距离村庄的距离大于村庄大小时自动寻找路径返回村庄。

# = 会合点 =
村庄的会合点指村庄边界以内的[钟](钟.md)，是村民偶尔聚集交流的位置。会合点附近会伴随着村庄的生成而生成一只[铁傀儡](铁傀儡.md)，也有概率会生成[流浪商人](流浪商人.md)和[行商羊驼](行商羊驼.md)。

# = 工作站点 =

工作站点方块是指诸如[砂轮](砂轮.md)、[切石机](切石机.md)等村民可以使用的方块。有相应职业的村民会在它们对应的工作站点度过相当长的一段时间，除了幼年村民、傻子和失业村民。认领工作站点方块后，村民和工作站点方块上方会出现绿色粒子效果，而村民会获得此站点对应的职业。交易过后的村民只能认领与其职业相符的站点方块。没有连接到工作站点的已交易村民无法恢复供应商品。村民无法认领已被认领的工作站点。游戏内有13个工作站点，分别对应一个职业。

当玩家对村民有行动时，该村民周围产生的[粒子](粒子.md)将表示玩家的声望变化。玩家的声望不会因死亡而重置，玩家也无法改变其他玩家的声望。声望会被每个村庄独立保存，一个玩家的声望有可能在一个村庄中很高但在另一个村庄中则很低。另外，由于每个村庄都保存了玩家的声望，如果整个村庄被破坏（具体为所有村民全部被杀死或所有床或钟被破坏），任何累积在该村庄的声望都会被消除（无论正面还是反面）。

# 你知道吗
* 据Jeb所述，最初他们想要做出一个能适应玩家扩建的村庄人口扩增系统。但后来他们发现识别房子的结构需要大量计算，会拖慢游戏，所以最终决定采用简化方案，将一个“能够划分内部空间和外部空间”的门视为一个房子。在村庄与掠夺更新后，“房子”的定义被更换为一个有效的床。<ref name="minecraft.net"/>
* 在[村庄与掠夺](村庄与掠夺.md)更新前，村庄的房屋和农场会因避免浮空而分别在其下方用圆石和泥土填补。若村庄在[峡谷](峡谷.md)上生成，可能会导致峡谷内出现大量的圆石或泥土柱。
* * 而在[村庄与掠夺](村庄与掠夺.md)更新后，村庄建筑的下方会生成一个由方块组成的近长方形平台（方块种类取决于附近地形）。这种现象在崎岖的地形中常常使地表变得反常。
* 在罕见的情况下，玩家可以找到只有一栋房屋或甚至只有一个工作站（带有工作站点方块的村庄建筑）的小村庄。
* 新式平原村庄与村庄与掠夺更新前的旧式村庄的相似度最高，尤其是其保留了旧式教堂和铁匠铺的设计。
* 在罕见的情况下，[海底废墟](海底废墟.md)会生成在村庄里，这会导致海底废墟强制生成的[溺尸](溺尸.md)攻击村民。
* 铁匠铺的内部天花板与木质屋顶之间留有一定的空间，这使得其中可以生成敌对生物。
* 雪原村庄包含一种和[雪屋](雪屋.md)非常像的小型房屋，但里面没有地毯、工作台、熔炉和地下室。
* * 不排除雪屋同时生成在村庄中的情况，此时的雪屋极其容易被忽视。当触发[袭击](袭击.md)时，雪屋地下室中幸存的牧师村民可能会阻止袭击以失败告终。
* 村庄不存在[丛林](丛林.md)和[沼泽](沼泽.md)生物群系变种，可能是因为藤蔓和海草会使村民的寻路机制出错。<ref>https://youtu.be/hAQfPq4BMN4</ref>
* * 尽管丛林和沼泽中不会自然生成村庄，但在其他生物群系的村庄生成于与上述生物群系交界处时，丛林或沼泽生物群系外观的村民仍会自然生成。
* 有概率生成位于两个或多个生物群系的边界上却只会为某一生物群系设计房子的村庄。
* 村庄的原住民起初是[猪人](Java版已移除特性#猪人.md)，而猪人后来的设计概念被沿用成为下界的[猪灵](猪灵.md)。<ref></ref>
* 雪原村庄的牧羊人小屋结构（<code>snowy_shepherds_house_1</code>）无法正常生成，原因是拼图方块中的名称拼写错误，应为“building”，实为“buidling”。又因为雪原村庄只有这一种牧羊人小屋结构，因此也会导致雪原村庄的牧羊人无法生成。<ref></ref>
