* *僵尸猪灵（Zombified Piglin）**是[猪灵](猪灵.md)的僵尸化变种。

# 生成
每只僵尸猪灵在自然生成时有5%的概率生成为幼年僵尸猪灵。

大部分僵尸猪灵生成时都手持[金剑](金剑.md)，在普通或困难[难度](难度.md)下金剑有一定概率会被随机附魔。该概率随[区域难度](区域难度.md)的增加而增加（最高为25%），而金剑附魔的等级可能会更高。

僵尸猪灵有5%的概率手持[金矛](金矛.md)。

僵尸猪灵在生成时有概率生成能捡起物品以及[盔甲](盔甲.md)的僵尸猪灵。

[万圣夜](wzh:万圣夜.md)（10月31日）当天生成的僵尸猪灵有22.5%的概率戴着[雕刻南瓜](雕刻南瓜.md)，有2.5%的概率戴着[南瓜灯](南瓜灯.md)，但雕刻南瓜或南瓜灯不会掉落。<ref></ref>

# = 下界 =
僵尸猪灵在[下界荒地](下界荒地.md)和[绯红森林](绯红森林.md)生物群系中亮度等级不高于11的地方生成。它们不能生成在[下界疣块](下界疣块.md)或[菌光体](菌光体.md)上。

僵尸猪灵会以4只为一组生成在下界荒地和下界要塞中，也会以2-4只为一组生成在绯红森林中。

僵尸猪灵会以2-4只为一组生成在下界荒地和绯红森林中，也会在下界要塞上单独生成。

僵尸猪灵有时也会随[炽足兽](炽足兽.md)一起生成，此时它们会坐在炽足兽身上，手持[诡异菌钓竿](诡异菌钓竿.md)。

僵尸猪灵可以像[凋灵骷髅](凋灵骷髅.md)一样在[凋灵玫瑰](凋灵玫瑰.md)中生成。<ref></ref>

# = 下界传送门 =
僵尸猪灵能够在[主世界](主世界.md)由[环境属性](环境属性.md)<code>gameplay/nether_portal_spawns_piglin</code>控制。}}的[下界传送门](下界传送门.md)生成。

每一个下界传送门方块在每个[随机刻](随机刻.md)中，都有一个极小的概率（简单难度下为，普通难度下为<!--为保持分母相同，请不要化简此处分数-->，困难难度下为），在下界传送门的底部框架上生成一只僵尸猪灵，且这一生成无视刷怪上限。

每一个下界传送门方块有一个极小的概率（简单难度下为，普通难度下为<!--为保持分母相同，请不要化简此处分数-->，困难难度下为）生成僵尸猪灵。它们会在传送门的东面或南面生成（取决于传送门朝向哪个方向），并且无法用方块阻碍其生成。点燃下界门瞬间也有概率生成僵尸猪灵，这个概率也和游戏难度有关，通过反复激活和破坏下界传送门可以增加僵尸猪灵的生成速度。

僵尸猪灵不能在低于Y=0的下界传送门中生成。<ref></ref>

由此生成的僵尸猪灵（和僵尸猪灵骑乘的鸡）在一定时间内不能传送到下界，不管是穿过生成它的下界传送门还是附近的其他传送门。

# = 猪 =
僵尸猪灵及其幼年变种会在[闪电](闪电.md)劈中[猪](猪.md)及其幼年形式周围4格范围内时生成。由此生成的僵尸猪灵不会自然消失。

# = 猪灵与猪灵蛮兵 =
[猪灵](猪灵.md)或[猪灵蛮兵](猪灵蛮兵.md)在下界以外的维度停留超过后，就会转化成僵尸猪灵，并保留其原本持有的手持物(包括副手)和装备的盔甲，其物品栏内的物品也会全部掉落。

它们转化之后会获得10秒的[反胃](反胃.md)效果，但反胃效果并不会影响其行为。

即使部分手持物猪灵可以使用，但其僵尸化后它们将无法再被继续正常使用，如[弩](弩.md)。

# = 增援 =

在困难[难度](难度.md)下，僵尸猪灵受到攻击时可能会生成增援僵尸猪灵。

# 变种
# = 幼年僵尸猪灵 =
僵尸猪灵有5%的概率以幼年形态生成，幼年僵尸猪灵的行为与成年僵尸猪灵略有不同：
* 移动速度比普通僵尸猪灵快50%，但生命值与之相同。
* 哼叫声的音调比普通僵尸猪灵高。
* 穿戴的盔甲会缩小以适应身体尺寸。
* 有缩小的碰撞箱，可以穿过1×1格的空间。
* 永远不会成长为成年僵尸猪灵。

幼年僵尸猪灵有5%的概率会在附近的[鸡](鸡.md)上生成成为[鸡骑士](鸡骑士.md)（如果附近没有鸡则生成失败），还有4.75%的概率附带一只[鸡](鸡.md)生成成为[鸡骑士](鸡骑士.md)。

* 骑士的速度为幼年僵尸猪灵的速度，而不是[坐骑](生物.md)本身的速度。
* 如果幼年僵尸猪灵骑乘的是玩家可骑乘的生物，该生物将不可再被玩家骑乘。

# 行为
僵尸猪灵空闲时会漫无目的地游荡，它们的移动速度为2.28米/秒。它们免疫[火](火.md)和[熔岩](熔岩.md)等来源的火焰伤害。当僵尸猪灵被激怒时，它们的速度将会增加到3.38米/秒（僵尸猪灵的速度会更快），幼年僵尸猪灵速度还会更快。在被攻击后，它们也会发出长为0-39刻的具有侵略性的声音。僵尸猪灵会联合在一起并尝试“淹没”玩家。

类似于僵尸，在困难难度下，追逐目标的僵尸猪灵会专注于攻击关闭的[木门](木门.md)或[铜门](铜门.md)，甚至有概率能够破门。<ref></ref>

[猪灵](猪灵.md)会远离自己附近的僵尸猪灵。

由[猪灵](猪灵.md)或[猪灵蛮兵](猪灵蛮兵.md)转化而来的僵尸猪灵/具有拾取盔甲和武器的能力。它们会捡起品质、魔咒更好的装备，同时丢弃原先的装备。若是生成时就持有的，则掉落的物品耐久度是满的，若是后来捡拾的，则与捡拾前一样。

自然生成的僵尸猪灵有概率能捡起物品和盔甲。在普通和困难难度下，僵尸猪灵有或的概率会捡起比它们的金质装备品质更好的盔甲和剑，且它们被杀死时总是会掉落捡起的装备。捡起物品后的僵尸猪灵不再会自然消失。僵尸猪灵可以像[掠夺者](掠夺者.md)一样拾取旁边的[不祥旗帜](不祥旗帜.md)。

僵尸猪灵会主动接近并且试图踩碎在其视野23格内的[海龟蛋](海龟蛋.md)，但不会主动攻击幼年[海龟](海龟.md)。

僵尸猪灵会避免在[岩浆块](岩浆块.md)上行走，且无法跳过一格高的岩浆块。如果僵尸猪灵被包围於周圍皆是一格或更高的岩浆块中，它们将靠近包围它们的岩浆块。然而，僵尸猪灵无论是在岩浆块上生成或者被推上岩浆块，都会在岩浆块上正常寻路。

随[炽足兽](炽足兽.md)一起生成的僵尸猪灵不能被骑乘，即使僵尸猪灵此时并未骑乘炽足兽。

# = 敌对性 =
默认情况下的僵尸猪灵是非敌对状态，但如果玩家或生物攻击了一个僵尸猪灵，那么以这个僵尸猪灵为中心的或内的所有僵尸猪灵都会对攻击它的玩家或生物敌对</ref>|be}}，除非这个僵尸猪灵被玩家或生物一击杀死。这适用于来自玩家和其他生物的任何攻击，包括弹开[恶魂](恶魂.md)的火球、或[骷髅](骷髅.md)的箭。

僵尸猪灵会保持敌对20-40秒，不过即使这个时间已过，僵尸猪灵仍然会追赶被标记的玩家，除非玩家逃离它们35格远的追踪范围。接近一个已经敌对的僵尸猪灵（35格内）会导致它发出一个警告，并激怒40格范围以内的僵尸猪灵，在其追踪范围内会以每4-6秒（80-120游戏刻）会招募原本中立的僵尸猪灵。未加载区块里的僵尸猪灵的宽恕计时器会停止。因此，如果玩家进入了一个[下界传送门](下界传送门.md)并返回，此区域内的所有原本处于敌对状态的僵尸猪灵仍然会保持敌对，除非其他玩家在此附近并保持这些区块的加载状态。玩家攻击僵尸猪灵后切换游戏模式，僵尸猪灵仍然会追逐玩家。<ref></ref><ref></ref>

非敌对状态的僵尸猪灵不会阻止玩家入睡。

# = 增援 =

有些僵尸猪灵在受到攻击时（包括被一击杀死的情况）会生成增援，类似于[僵尸](僵尸.md)。

# = 生物族群 =

僵尸猪灵是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉直到接触水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

僵尸猪灵不会在阳光下[着火](着火.md)。

# 你知道吗
* 纹理更新前的僵尸猪人皮肤文件上有文字“THX XAPHOBIA”写在未使用的部分，作为[Notch](Notch.md)对僵尸猪人皮肤制作者[XaPhobia的感谢](http://twitter.com/XaPhobia)。
* 在[基岩版1.16.0](基岩版1.16.0.md)之前，僵尸猪人在生成时有可能装备盔甲，幼年僵尸猪人还有可能会骑乘成年动物和[僵尸](僵尸.md)。
* 由猪灵转化而成的僵尸猪灵会保留手中的弩，但它们无法用弩射出箭。
* 僵尸猪灵在自然条件下不会攻击[村民](村民.md)，但如果村民被僵尸猪灵杀死，也可以被感染为[僵尸村民](僵尸村民.md)，概率与村民被僵尸杀死时相同。
* * 在不开启作弊的情况下，这一点可以通过村民发射[烟花火箭](烟花火箭.md)伤害到僵尸猪灵而被反击，或者持有金矛的僵尸猪灵误伤村民来实现。
* 不同于[猪灵](猪灵.md)，僵尸猪灵没有右耳。
* 尽管僵尸猪灵以群体行动著称，但当矛的冲锋攻击意外命中同类时，被误伤的僵尸猪灵将会进行反击。<ref></ref><ref></ref>
