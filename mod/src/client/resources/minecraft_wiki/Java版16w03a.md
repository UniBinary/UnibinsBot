# Java版16w03a

*页面ID: 19336* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w03a**是[Java版1.9](Java版1.9.md)的第50个快照，发布于2016年1月20日<ref name="blogpost_16w03a"></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[信标](信标.md)**
* 不再像前一个快照。被放置到有效金字塔结构上不会立即被激活。

# = 非生物实体 =
* *[矿车](矿车.md)**
* 当<code>CustomNameVisible</code>有值，则所有种类的[矿车](矿车.md)会显示<code>CustomName</code>。

# = 命令格式 =
* ***
* 不再影响[统计](统计.md)。

# = 常规 =
* *音效**
* 加入了更多音效，并更新了部分既有音效。

# 修复
命令与统计一起执行时，结果不可靠。

|92266|死亡的生物不会从它的队伍中移出。
