* *蜡烛（Candle）**是形状类似于海泡菜的、可用[染料](染料.md)染色的光源。

# 生成
橙色蜡烛、品红色蜡烛、淡蓝色蜡烛、黄色蜡烛、黄绿色蜡烛、粉红色蜡烛、灰色蜡烛、淡灰色蜡烛、青色蜡烛、紫色蜡烛、蓝色蜡烛、棕色蜡烛、绿色蜡烛、黑色蜡烛不会生成在世界中。

# = 自然生成 =
普通蜡烛会生成在[远古城市](远古城市.md)的入口长廊两侧和中心雕像前，还会生成在[试炼密室](试炼密室.md)中。

白色蜡烛会生成在远古城市的一些建筑中。

红色蜡烛会生成于试炼密室里的[不祥宝库](不祥宝库.md)的框架上。

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落染色蜡烛。

# 破坏
没有工具可以加速对蜡烛的挖掘。

蜡烛被破坏后会掉落自身，掉落数等于方块内蜡烛数。

# 用途
[right|点燃的蜡烛的动画|150px](File:Four Candles (lit).gif.md)
蜡烛须放置于或的上方，若其依附的方块被破坏，则会悬浮于空中。

与[海泡菜](海泡菜.md)相似，单个方块空间内最多能放4个同色蜡烛。

蜡烛在放置时是未点燃的，打火石、[火焰弹](火焰弹.md)、、燃烧的[弹射物](弹射物.md)或是可以将其点燃。

蜡烛点燃后，玩家可以通过与蜡烛来熄灭它。蜡烛也会被[风爆](爆炸#风爆.md)、熄灭。

蜡烛可以含水，且含水时无法点燃。

# = 光源 =
蜡烛可以用作光源。点燃时，每个蜡烛会将亮度等级提高3，单个方块空间的亮度最高可达12级。

# = 蛋糕 =
每个完整的[蛋糕](蛋糕.md)上都能且只能放一个蜡烛。如果蛋糕被食用，蜡烛就会掉下来。
