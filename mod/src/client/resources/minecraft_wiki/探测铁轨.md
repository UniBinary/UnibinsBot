# 探测铁轨

*页面ID: 6794* | *来源: Minecraft Wiki*

* *探测铁轨（Detector Rail）**是一种功能类似于[压力板](压力板.md)的[铁轨](铁轨.md)。

# 生成
探测铁轨不会生成在世界中。

# 破坏
挖掘探测铁轨的合适工具是镐。

探测铁轨被破坏后会掉落自身。

# 用途

探测铁轨是铁轨和[红石元件](红石元件.md)。一系列相连的铁轨（包括普通[铁轨](铁轨.md)、[动力铁轨](动力铁轨.md)、探测铁轨和[激活铁轨](激活铁轨.md)）被称作**轨道**。

探测铁轨会在没有合适方块（见）支撑或时[掉落](掉落.md)为[物品](物品.md)。

如果熔岩流过探测铁轨，探测铁轨将会被摧毁且不会掉落物品。

# = 生物 =
除了玩家和[监守者](监守者.md)以外的所有生物在寻路时不会将探测铁轨视为可以走上或跨越的方块，除非它们正站在任意类型的铁轨上。

# = 放置 =

[thumb|铁轨可能连接到的所有位置，图中以普通铁轨为基准](File:All linked rails.png.md)

探测铁轨只能放置在上表面[边缘完整](方块支撑形状.md)的方块上。

探测铁轨可以和水平方向上相邻一格的铁轨相连，也可以和这些相邻铁轨上方或下方一格的铁轨相连。探测铁轨可以和其他种类的[铁轨](铁轨（消歧义）.md)相连。

# = 铁轨 =

探测铁轨（和其他铁轨）充当供矿车通行的铁路。矿车从两端进入探测铁轨都会继续移动，只会失去一点点速度（速度可由[动力铁轨](动力铁轨.md)再次增加）。从侧面进入探测铁轨的矿车会转向东边或南边（取决于探测铁轨朝向），从侧面进入倾斜的探测铁轨的矿车会向下移动。

# = 红石元件 =
[缩略图|一个满载（27组）的矿车以及一个一半满（14组）的矿车的信号输出强度的示例](File:detector comparator strength.gif.md)

探测铁轨是[红石信号源](红石电路#信号源.md)。开启条件如下：
* 在探测铁轨所在方块的(0.2,0,0.2)到(0.8,0.8,0.8)这个长方体之内有任意矿车时（即使矿车只有一小部分在其中）探测铁轨会开启。
* 當矿车中心x-0.29,y-0.15,z-0.29到x+0.29,y+0.35,z+0.29的长方体在探测铁轨所在的格子内时，探测铁轨会开启。

开启的探测铁轨会：
* 激活毗邻的**[红石粉](红石粉.md)**和毗邻的背对自身的**[红石中继器](红石中继器.md)**，信号强度为15。
* 激活毗邻的背对自身的**[红石比较器](红石比较器.md)**，信号强度为对应[运输矿车](运输矿车.md)或[漏斗矿车](漏斗矿车.md)装载量或[命令方块矿车](命令方块矿车.md)的执行成功次数。与红石比较器相隔一个红石导体时也可激活。
* 强充能自身下方的**红石导体**，信号强度为15。
* 激活任何毗邻的[机械元件](红石元件#机械元件.md)（但活塞不会被它所朝向的探测铁轨激活）。

[缩略图|右|比较器只会在运输矿车或漏斗矿车在探测铁轨上面时输出信号](File:Detector-comparator-diff.png.md)
若在探测铁轨的矿车是[运输矿车](运输矿车.md)、[漏斗矿车](漏斗矿车.md)或[命令方块矿车](命令方块矿车.md)，探测铁轨邻近的背对探测铁轨的红石比较器将会输出信号等级对应矿车装载程度或命令执行成功次数的信号，此等级可以为0，也可以大于15。对于其他类型的矿车（包括有玩家或[村民](村民.md)乘坐的普通矿车），红石比较器的输入是0。

探测铁轨开启后，每隔20[游戏刻](游戏刻.md)更新一次信号。更新信号时如果发现在上方没有矿车，探测铁轨会变为非开启状态。矿车驶离以及[运输矿车](运输矿车.md)、[漏斗矿车](漏斗矿车.md)或[命令方块矿车](命令方块矿车.md)发生变化时，探测铁轨不会立即更新。

[活板门](活板门.md)上的探测铁轨会在活板门打开时锁定信号，直接输出的信号不再变化。
* 锁定在**未开启**状态的探测铁轨**不可以**作为红石比较器的主要输入，会在活板门关闭时恢复。
* 锁定在**开启**状态的探测铁轨**可以**作为红石比较器的主要输入，但上面的矿车变化时不更新红石比较器，被[活塞](活塞.md)移动才能恢复。
