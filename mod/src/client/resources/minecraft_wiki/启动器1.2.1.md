# 启动器1.2.1

*页面ID: 49353* | *来源: Minecraft Wiki*

* *1.2.1**是一个在2013年8月2日、6日、7日多次发布的[启动器](启动器.md)版本。

# 新增
* 新增运行Alpha、Beta和快照时的警告。
* 新增Alpha版本。
* 5个Pre-Classic和Classic版本的Minecraft被添加进了启动器。

# 修复
*  - 意外的异常刷新版本列表/Play按钮为灰色。
*  - 启动器无法记住上次使用的配置文件。
*  - 1.0和1.1版本的游戏不可用。
*  - 1.5版本的游戏不能启动，显示。
*  - 选择Alpha 1.2.0版本时会启动Alpha 1.2.0_02。
