# 迟缓药水

*页面ID: 176606* | *来源: Minecraft Wiki*

* *迟缓药水**是提供[緩速](緩速.md)狀態效果的[药水效果](药水效果.md)。

該藥水效果可以製成[药水](药水.md)**迟缓药水（Potion of Slowness）**、[喷溅药水](喷溅药水.md)**喷溅型迟缓药水（Splash Potion of Slowness）**、[滞留药水](滞留药水.md)**滞留型迟缓药水（Lingering Potion of Slowness）**和[药箭](药箭.md)**迟缓之箭（Arrow of Slowness）**。

此药水效果有对应的延长版和增强版。

# 生成
# = 生物 =
[女巫](女巫.md)會對8格以外没有緩速效果的攻击目标丟擲飛濺緩速藥水。

[流髑](流髑.md)會發射延長版緩速之箭；流髑会直接发射帶有緩速狀態效果的箭，而不是发射迟缓之箭，但造成的状态效果相同。

# = 不祥試煉 =
[不祥試煉生怪磚](不祥試煉生怪磚.md)召喚的[不祥物品生成器](不祥物品生成器.md)會射出或。因而被此弹射物击中后会获得20秒而不是2秒的緩速IV。

# = 礼物 =

[制箭师](制箭师.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷緩速之箭。

# = 自然生成 =

[沼澤小屋](沼澤小屋.md)的[鍋釜](鍋釜.md)內可能裝有緩速藥水。

# = 箱子战利品 =

由于最大堆叠数量为1，数量大于1的堆叠会被展开为对应数量的单个物品堆叠。

# = 掉落物 =
流髑會掉落緩速之箭。

# = 炼药锅 =

对装有迟缓药水的炼药锅使用[玻璃瓶](玻璃瓶.md)可获得迟缓药水、喷溅型迟缓药水或滞留型迟缓药水，具体形式取决于炼药锅内容物。

对装有迟缓药水的炼药锅使用[箭](箭.md)可获取伤害之箭，最大数量随内容物水位增加依次为16、32和64。
