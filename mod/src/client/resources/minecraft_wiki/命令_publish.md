# 命令/publish

*页面ID: 39802* | *来源: Minecraft Wiki*

向局域网开放单人游戏世界。

# 语法
  <code>publish [<allowCommands>] [<gamemode>] [<port>]</code>

# 参数

   是否允许[作弊](作弊.md)。若未指定，默认为<code>false</code>。


   新玩家进入世界后的默认[游戏模式](游戏模式.md)。若未指定，新玩家进入世界后的游戏模式为此单人世界的游戏模式。


   主机所在的[端口](wzh:端口.md)。若未指定，则自动分配端口，一般会自动分配在临时端口范围。

# 示例
* 启用作弊，其他玩家以旁观模式加入游戏，指定端口为65531：<code>publish true spectator 65531</code>
