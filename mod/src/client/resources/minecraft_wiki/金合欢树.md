* *金合欢树（Acacia）**是生成于[热带草原](热带草原.md)的植被[地物](地物.md)。

# 描述
金合欢树的高度为6-11格，长有2格高的扁平树冠。

金合欢树的主干可能会弯折，也有可能长出弯曲的分杈，每条分支带有独立的叶簇。组成弯折枝干的原木在对角线上分布。

# 生成
金合欢树生成时会将下方1格的方块转变为[泥土](泥土.md)。

# = 自然生成 =
[热带草原](热带草原.md)、[热带高原](热带高原.md)和[风袭热带草原](风袭热带草原.md)生成树木地物时，金合欢树都有80%的概率生成。

# = 人为生成 =
[亮度](亮度.md)等级至少为9且有一定的空间时，[金合欢树苗](金合欢树苗.md)可长成金合欢树。
