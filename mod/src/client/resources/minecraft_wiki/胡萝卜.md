# 胡萝卜

*页面ID: 8819* | *来源: Minecraft Wiki*

* *胡萝卜（Carrot）**是一种可种植的[食物](食物.md)。

* *胡萝卜（Carrots）**是物品形式的胡萝卜种植在[耕地](耕地.md)上形成的方块。

# 生成
# = 自然生成 =
胡萝卜植株会自然生成在[平原](平原.md)和[雪原](雪原.md)类型的[村庄](村庄.md)里[农田](农田.md)结构的[耕地](耕地.md)上。

根据村庄所处生物群系不同，每块耕地上生成胡萝卜植株的概率如下。

# = 村民 =
[农民](农民.md)村民会将自己物品栏中的胡萝卜种在[耕地](耕地.md)上。

# 破坏
胡萝卜植株被挖掘时会立刻被破坏。

生长阶段没有达到第8阶段的胡萝卜植株被破坏后会掉落1个胡萝卜。

生长阶段达到第8阶段的胡萝卜植株被破坏后会掉落或胡萝卜。其中<math>X</math>为挖掘工具的[时运](时运.md)等级。然后系统会尝试进行3次掉落，每次有约）|JE|short=1}}或）|BE|short=1}}的概率掉落1个胡萝卜，挖掘工具的时运魔咒每增加1级，尝试次数增加1。

# 用途
# = 食物 =

手持胡萝卜按住键即可食用，每个胡萝卜可以回复。

# = 马、驴、骡 =
胡萝卜能治疗[马](马.md)、[驴](驴.md)、[骡](骡.md)生命、提高3%驯服概率和加速60秒幼年马、幼年驴、幼年骡的成长速度。

# = 种植 =

对[耕地](耕地.md)的顶面胡萝卜即可种植出胡萝卜植株。胡萝卜植株会经历8个生长阶段（有4个可视的阶段）。[亮度](亮度.md)等级≥9时，胡萝卜植株才能生长到下一个阶段；亮度等级≤7时无法对耕地胡萝卜，已种植的胡萝卜植株也会在接收到[方块更新](方块更新.md)时掉落为[物品实体](物品实体.md)。

胡萝卜植株在湿润的耕地上生长得更快。对胡萝卜植株[骨粉](骨粉.md)会使其增加2-5个生长阶段，忽视亮度等级。已有巢且采集了花粉的[蜜蜂](蜜蜂.md)飞过胡萝卜植株时，植株也有概率增加1个生长阶段。

胡萝卜植株的四周都为胡萝卜植株且都种植在湿润的耕地上会比单独种植在湿润的耕地的胡萝卜植株生长速度快约16.7%；而按一排间种胡萝卜植株，中间没有作物或为其他作物会比单独种植在湿润的耕地的胡萝卜植株生长速度快133%。

[兔子](兔子.md)会寻找和吃掉或胡萝卜植株，使其倒退1个生长阶段，且不会掉落胡萝卜。

# = 繁殖 =
胡萝卜可用于吸引及繁殖[猪](猪.md)和[兔子](兔子.md)，也可喂食给幼年个体以减少其10%的剩余成长时间。

[村民](村民.md)可以通过拾起至少12个胡萝卜来产生繁殖意愿。

# = 交易 =

# = 堆肥 =
将胡萝卜放入[堆肥桶](堆肥桶.md)中，会有65%的概率增加一层堆肥层。
