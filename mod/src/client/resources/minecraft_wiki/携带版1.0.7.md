# 携带版1.0.7

*页面ID: 29262* | *来源: Minecraft Wiki*

* *1.0.7**是[携带版](携带版.md)的一次次要更新，发布于2017年4月20日<ref></ref>，加入了混搭包，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[混搭包](混搭包.md)**
* 加入了混搭包。

# 更改
# = 方块 =
* *活塞**
* 数据值为6或7的活塞不再能被激活。
# = 常规 =
* *警告**
* 加入了当资源包丢失纹理列表文件时的警告。

# 修复
* *修复了9个漏洞**
*  - 崩溃导致玩家的游戏进度丢失。
*  - 无法获取关于凋灵的画。
*  - 将资源包上传到Realms里时，该资源包显示错误。
*  - 节日混搭包里的皮肤出现问题。
* 使用行为包时，使用不存在的效果来近战攻击时游戏崩溃。
* “红石大厦”地图的描述在小屏幕设备里出现断片。
* TNT在水下爆炸时不再伤害玩家。
* 糖果纹理包里的石英台阶纹理出现错误。
* 矿车会在黏液块上面跳跃太高。
