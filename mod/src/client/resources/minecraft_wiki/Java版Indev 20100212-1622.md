# Java版Indev 20100212-1622

*页面ID: 35408* | *来源: Minecraft Wiki*

<onlyinclude>

* *Minecraft Indev**的一个版本发布于2010年2月12日16:22（UTC）。<ref></ref>

# 新内容
# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 在右上角添加了“Free memory”和“Allocated memory”信息。
* * 该信息用§8（深灰色）[颜色代码](颜色代码.md)显示而不是通常的§f（白色）。

# 更改
# = 游戏内容 =
* *[皮肤](皮肤.md)**
* 皮肤系统现在会正常工作了。
* * 处于测试目的，该版本的玩家皮肤总会显示为Notch。
* 在没有代理时，玩家会显示为纯黑色。

* *[音乐](音乐.md)**
* 被临时禁用。

* *[声音](声音.md)**
* 被临时禁用。</onlyinclude>
