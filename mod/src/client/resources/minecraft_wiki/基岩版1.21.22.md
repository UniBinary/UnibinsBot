# 基岩版1.21.22

*页面ID: 125678* | *来源: Minecraft Wiki*

* *1.21.22**是的一次热修复更新，在除Fire和iOS/iPadOS外的平台上发布于2024年8月26日<ref></ref>，在Fire和iOS/iPadOS平台上发布于2024年8月27日，修复了一些漏洞。此版本与[1.21.20](基岩版1.21.20.md)和[1.21.21](基岩版1.21.21.md)相互兼容。

# 修复
* 修复了一些游戏过程中可能发生的崩溃。
* 优化了来自市场的附加包的加载过程。
* 修复了UI中所有的自定义方块都会旋转180度的漏洞。
* * 字段的默认值现在为，而不是。
  : <syntaxhighlight lang="json">
     "item_display_transforms": {
          "gui" : {
               "translation": [0, 0, 0],
               "rotation": [30, 45, 0],
               "scale": [0.625, 0.625, 0.625],
                "rotation_pivot": [0, 0, 0],
               "scale_pivot": [0, 0, 0],
               "fit_to_frame": true
          }
     }
</syntaxhighlight>
