# 携带版0.14.3

*页面ID: 21456* | *来源: Minecraft Wiki*

* *v0.14.3 alpha**是携带版的一次次要更新，在Android上发布于2016年5月18日，在iOS、FireOS、Windows Phone和Windows 10上发布于5月19日，加入了新的<!--生物群系定居者II-->皮肤包，并修复了一些漏洞。
