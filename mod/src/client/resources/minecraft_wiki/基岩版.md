* *Minecraft：基岩版**（***Minecraft: Bedrock Edition***，官方常称为无副标题的***Minecraft***）是由[Mojang Studios](Mojang Studios.md)、[Xbox Game Studios](Xbox Game Studios.md)及[SkyBox Labs](SkyBox Labs.md)联合开发的多平台版本[Minecraft](Minecraft.md)，其游戏引擎为[基岩引擎](#基岩代码库.md)，该引擎与[携带版](携带版.md)一脉相承。

# 基岩代码库
“基岩版”这一名称源于基岩代码库（Bedrock codebase），该代码库采用C++语言编写，旨在让游戏能够在不支持的平台上运行。在不同平台中，尽管为适配网络、存储等目标平台的特性而对代码进行了修改，但仍有约90%的代码保持一致。这一共享的功能核心被称为“基岩引擎”（Bedrock engine），不过该引擎并无实际的独立物理形态。<ref></ref>

基岩代码库存储于用于管理代码片段并跟踪其演变的软件系统中。这一特性使其不仅能够托管当前版本，还能容纳所有历史版本、独立的[基岩版专用服务器](基岩版专用服务器.md)版本及多个测试版，同时可避免版本冲突。

各目标平台的程序构建过程相互独立，构建完成后会上传至对应平台的应用商店。多数应用商店均有自身的合规性要求，会在新版本开放玩家下载前进行一系列认证测试。[Xbox游戏工作室](Xbox游戏工作室.md)会尽量协调各平台应用商店同步发布新版本，但认证测试流程不受其控制。这可能导致某个版本在特定平台延迟发布，尤其是当版本未通过认证且需返回开发人员处修复时。

基岩还被应用于，以及已停止更新的[树莓派版](树莓派版.md)、。

# 命名
在2022年6月7日之前，“基岩版”并非任何Minecraft版本的正式名称。自[独乐不如众乐更新](独乐不如众乐更新.md)起，所有采用基岩引擎的Minecraft均统一命名为无副标题的**Minecraft**。在此之前，各平台版本均有专属副标题，包括适用于所有移动平台的（Pocket Edition）、[Windows 10版](Windows 10版.md)、[Gear VR版](Gear VR版.md)及[Fire TV版](Fire TV版.md)。其中，是最早的版本，常被简称为“MCPE”或“PE”。如今，这些旧名称有时仍被用来指代所有基岩版，甚至包括重命名后纳入基岩版的版本（如[Xbox One版](Xbox One版.md)、[PlayStation 4版](PlayStation 4版.md)等）。与之相对，原先无副标题的“PC/Mac版”在[1.12.2](Java版1.12.2.md)版本中被命名为“[Minecraft：Java版](Java版.md)”。

上述重命名在玩家社区中引发了混乱，原因如下：
* 在此之前，若无特别说明，无副标题的“Minecraft”一词通常指代原先的[Java版](Java版.md)，而非基岩版。因此，重命名后的一段时间内，“Minecraft”一词的使用存在歧义。
* 主机平台上由引入的基岩版仍以“Minecraft for Xbox One”“Minecraft for Nintendo Switch”“Minecraft for PlayStation 4”之名销售，<ref name="Xbox" /><ref>[Minecraft for Nintendo Switch | Minecraft](https://minecraft.net/store/minecraft-switch)</ref><ref>[Minecraft for PlayStation 4 | Minecraft](https://minecraft.net/store/minecraft-ps4)</ref>且这些名称与原先的（即“[Minecraft：Xbox One版](Xbox One版.md)”“[Minecraft：Nintendo Switch版](Nintendo Switch版.md)”“[Minecraft：PlayStation 4版](PlayStation 4版.md)”）极为相似，这让许多玩家对两个版本的差异感到困惑。
* “Minecraft”一词一直被用作所有版本游戏的统称。

综上，这些复杂因素导致官方名称“Minecraft”无法仅用于指代采用基岩引擎的版本。无论如何，Minecraft Wiki都需要另一个术语来指代这些版本。如同用“蜀”称呼实际国号为“汉”的，尽管并不存在真正名为“基岩版”的版本，Minecraft Wiki仍选择用其作为这些版本的统称。此后，玩家社区也随之采用了“基岩版”这一称呼。如今，它已成为所有采用基岩引擎版本的标准统称术语，后来[Mojang Studios](Mojang Studios.md)也在文章中使用“基岩版”来指代该版本。2022年6月7日，Java版与基岩版开始捆绑销售，标题为“*Minecraft: Java & Bedrock Edition*”<ref>https://www.youtube.com/watch?v=qNMfF9TYETM</ref>，这标志着“Bedrock Edition”被正式认可为基岩版的副标题并投入使用。

# 游戏内容

该版本的游戏目标与和相同，玩家均可在沙盒式环境中构建虚拟世界。与其他版本一样，基岩版也包含在其他版本中出现的[生存](生存.md)内容，例如[酿造](酿造.md)、[饥饿](饥饿.md)机制，以及[下界](下界.md)和[末地](末地.md)维度。此外，玩家可在任何能运行基岩版的触摸设备和主机上进行跨平台多人游戏。<ref></ref>

基岩版与Java版及原主机版存在诸多差异，例如画面更鲜明、地形经过修改、拥有部分独有物品及官方附加包系统<ref>https://minecraft.net/addons/</ref>等。[HUD](HUD.md)及其他元素与Java版相比有所变动，更便于在移动设备上操作。玩家还可通过触摸屏、键盘、鼠标和手柄与游戏进行交互。

基岩版与Java版的不同之处如下：
* 部分[方块](方块.md)、[生物](生物.md)、[物品](物品.md)的特性与Java版不同。
* 支持4种多人游戏方式：
* * 通过无线局域网，允许8名及以下玩家在同一世界中游玩。
* * 通过[Realms](Realms Plus.md)（主机玩家需额外订阅多人游戏加值服务）。
* * 通过[玩家创建的远程服务器](基岩版专用服务器.md)（不含主机端）。
* * 通过微软账号（主机端可登录PSN账号或Nintendo账号）。
* 提供[精选服务器](精选服务器.md)列表（由Mojang Studios的合作伙伴运营），包含Minecraft中的多人小游戏。

基岩版的部分功能仅适用于特定平台。
* [分屏](分屏.md)功能仅适用于Xbox One、Xbox Series X<nowiki>|</nowiki>S、PlayStation 4、PlayStation 5及Nintendo Switch。
* 主机端不支持通过IP地址加入服务器。

# = 兼容设备 =

已知某些低于这些规格的设备，无论是否使用自定义ROM、内核和，都可以正常工作。但由于缺少浮点运算，CPU [MSM7227](wzh:MSM7000#MSM7x27.md)不受支持；NVIDIA Tegra 2处理器因不支持Neon，同样不受支持。

# = 发布 =
Twitter上曾发布过一段早期游戏蓝本在Xperia PLAY上运行的视频。2011年10月7日，Alpha版本正式发布，且不再为Xperia PLAY独占。该非独占版本原计划于9月29日在Android平台上线<ref></ref>，但因需修复部分严重漏洞，发布日期推迟至10月7日。

在Mojang的一次采访中，iOS版本曾被确认将于2012年之前发布<ref>http://www.unboundgamer.com/_/minecraft-pocket-edition-interview-with-mojang-r393</ref>，随后该版本于2011年11月17日正式推出。

# = Alpha =

最初的版本在iOS和Android平台发布后，更新开始同步推送，相同特性也同步加入这两个平台。在Alpha阶段，携带版不断新增多种特性，包括[合成](合成.md)、[烧炼](烧炼.md)、更多[方块](方块.md)、[物品](物品.md)、[生物](生物.md)及游戏模式等，使其更接近[Java版](Java版.md)。由于携带版与Java版的开发团队协作紧密，Java版新增的方块往往会同步在携带版中推出。部分特性在Java版发布前，会先在携带版进行测试，例如[甜菜根](甜菜根.md)及其相关物品，还有[方块模型](方块模型.md)。

Alpha阶段，基岩版被移植到更多平台：携带版首先于2012年9月13日登陆Kindle Fire，又于2014年12月10日在Windows Phone平台发布。[Windows 10版](Windows 10版.md)的Beta版本于2015年7月29日推出，售价高于携带版。[Gear VR版](Gear VR版.md)则于2016年4月27日发布，价格与携带版一致。

此期间，还发布了另外两个基于基岩代码库的[Minecraft](Minecraft.md)版本，且它们独立于基岩版。[树莓派版](树莓派版.md)是Minecraft的免费版本，基于基岩版的旧Alpha版本开发，现已停止更新。[教育版](教育版.md)于2016年11月1日在Windows 10和macOS平台发布。

# = 正式版 =
2016年11月11日，[1.0.0](携带版1.0.0.md)（即[末影更新](末影更新.md)）正式公布，并于同年12月19日与[Apple TV版](Apple TV版.md)及[Fire TV版](Fire TV版.md)一同发布。自2017年2月22日起，携带版重新开始推送针对Windows 10 Mobile的更新。

从[1.2.0](基岩版1.2.0.md)（即[独乐不如众乐更新](独乐不如众乐更新.md)）开始，基岩版的所有版本均移除“Edition”副标题，统一重命名为Minecraft。Xbox One的基岩版移植版本随此次更新同步发布；Nintendo Switch的移植版本于2018年6月21日以数字版和实体版两种形式推出；PlayStation 4用户则在2019年12月10日收到了包含1.14.0更新的基岩版。对于这些主机平台中原有[原主机版](原主机版.md)的所有者，可免费下载该新版本。

# = 测试与预览版 =

2013年11月22日起<ref></ref>，[Mojang](Mojang.md)开始为加入测试组的用户公开发布包含完整更新内容的测试版，旨在通过收集反馈（尤其是漏洞报告）提升正式版的稳定性。0.8.0至0.12.1版本期间，用户需加入[Google+小组](https://play.google.com/apps/testing/com.mojang.minecraftpe)以获取测试版，之后可像接收常规更新一样在应用商店中查看测试版更新。2015年7月17日，该Google+小组因垃圾信息和广告问题被移除。<ref></ref><ref></ref><ref></ref>2015年11月3日，PE开发团队推出[专用博客](http://pocketbeta.minecraft.net)<ref></ref>，用于协助用户加入0.13.0测试组，并展示测试版的更新日志。目前，Android平台用户可在Google Play的Minecraft界面底部加入开发者测试以获取测试版。在[1.19.10.20](基岩版1.19.10.20.md)前，Windows和Xbox One平台用户可通过Xbox会员中心获取测试版。

2022年1月31日起<ref></ref>，测试版计划以Minecraft Preview的形式扩展至其他平台，最早在iOS/iPadOS平台发布，现支持的平台有Xbox、Windows、iOS/iPadOS和PlayStation。原本通过Xbox Insider Hub开展的测试计划被淘汰，除Android与ChromeOS以外的Beta版最终被Minecraft Preview替代。

# = 开发者版本 =
开发者版本是相对上述公开零售版本而言，面向经微软认证的开发者提供的内部非公开测试版本。它允许开发者调用部分游戏代码以实现各类测试目的，并提供比公开测试版本更多的测试功能（例如[萤火虫](萤火虫.md)、[神秘框架](神秘框架.md)等未公开发布的特性）。由于开发者版本为内部使用版本，任何用户都被禁止将其安装包传播至任何外部平台。

# 价格
尽管所有基岩版版本的内容几乎相同，但价格因平台而异：Android版、iOS/iPadOS版、Fire OS版售价为[US$](wzh:美元.md)6.99（折合约[¥](wzh:人民币.md)49.2、[NT$](wzh:新台币.md)220.4、[HK$](wzh:港元.md)54.4）；ChromeOS版（与Android版捆绑）、PlayStation 4版、Xbox One版为[US$](wzh:美元.md)19.99、[¥](wzh:人民币.md)129、[NT$](wzh:新台币.md)679、[HK$](wzh:港元.md)154；Windows版（Java版与基岩版捆绑）为[US$](wzh:美元.md)29.99/[US$](wzh:美元.md)39.99、[¥](wzh:人民币.md)89/[¥](wzh:人民币.md)119、[NT$](wzh:新台币.md)788/[NT$](wzh:新台币.md)1088、[HK$](wzh:港元.md)209/[HK$](wzh:港元.md)269（标准版/豪华版）。最贵的是Nintendo Switch版，售价为[US$](wzh:美元.md)29.99（折合约¥211.2、[NT$](wzh:新台币.md)945.8）、[HK$](wzh:港元.md)234。

在除PlayStation外的任一平台上，从[市场](市场.md)购买的DLC和Minecoin均可用于其他平台，但游戏需在各平台单独购买。尽管为或[GDK](https://learn.microsoft.com/gaming/gdk/)应用程序，Minecraft在Windows 10/11、Windows 10 Mobile和Xbox One平台上仍作为3个独立应用，以不同价格销售（这意味着各平台间的Xbox Live成就不互通，每个平台都有独立的[成就](成就.md)；若在某个平台上购买游戏，并不能同时获得其他平台的版本）。

Xbox One和Windows上的版本可分别供Xbox Game Pass和PC Game Pass订户游玩，也可同时供Xbox Game Pass Ultimate订户游玩。<ref>[Minecraft for Windows | Minecraft](https://minecraft.net/store/minecraft-windows10)</ref><ref name="Xbox">[Minecraft for Xbox | Minecraft](https://minecraft.net/store/minecraft-xbox-one)</ref>Xbox One和PlayStation 4上的版本可向后兼容，在和上运行。<ref name="Xbox" /><ref>[Minecraft - PS4 Games | PlayStation](https://playstation.com/games/minecraft)</ref>与所有版本的Minecraft一样，基岩版的更新均为免费。在Windows平台上，游戏可通过[启动器](启动器.md)启动。

# 销量
[315px|thumb|Minecraft的销量数据，至2015年12月](File:Minecraft Sales Data.png.md)
2013年12月，的销量已达1650万份，同期的销量为1300万份。这些数据是在0.8.0更新发布后统计得出的。<ref>[As Minecraft tops Apple's apps chart for 2013, Mojang talks Pocket Edition](http://theguardian.com/technology/2013/dec/17/mojang-minecraft-pocket-edition-apple) - The Guardian；2013年12月17日</ref>携带版的销量超过了Java版与原主机版的总和，这一成绩被视为巨大的成功。

2016年12月2日，[Marsh Davies](Marsh Davies.md)宣布携带版的销量已突破4000万份（当时Java版的销量已超过2400万份）。<ref></ref>此项统计数据涵盖了[Windows 10版](Windows 10版.md)和[Gear VR版](Gear VR版.md)。

该版本常年位居App Store和Google Play付费榜前十，有时还会攀升至榜首。<ref>http://www.apple.com/itunes/charts/paid-apps/</ref><ref>https://play.google.com/store/apps/collection/topselling_paid?hl=en</ref>
