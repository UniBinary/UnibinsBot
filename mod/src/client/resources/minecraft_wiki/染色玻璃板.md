# 染色玻璃板

*页面ID: 11083* | *来源: Minecraft Wiki*

* *染色玻璃板（Stained Glass Pane）**是由[玻璃板](玻璃板.md)制作的装饰性方块。

# 生成
品红色染色玻璃板、淡蓝色染色玻璃板、黄绿色染色玻璃板、粉红色染色玻璃板、灰色染色玻璃板、淡灰色染色玻璃板、青色染色玻璃板、紫色染色玻璃板、蓝色染色玻璃板、绿色染色玻璃板、黑色染色玻璃板不会生成在世界中。

# = 自然生成 =
[村庄](村庄.md)中会自然生成不同颜色的玻璃板。

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落染色玻璃板。

# 破坏
没有工具可以加速对染色玻璃板的挖掘。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，染色玻璃板被破坏后不会掉落。

被具有精准采集的工具挖掘破坏时，染色玻璃板被破坏后会掉落自身。

# 用途
染色玻璃板比染色玻璃更经济，它们可以用相同的材料做出相当于玻璃方块面积267％( × 100%)的窗户，因为6个玻璃就能合成16个染色玻璃板。

# = 放置 =
如果染色玻璃板所放位置上的四个侧面都没有支撑面完整的方块表面（[潜影盒](潜影盒.md)、、除外）、[墙](墙.md)、[铁栏杆](铁栏杆.md)、[玻璃板](玻璃板.md)或其他染色玻璃板，它会呈现为一个细的竖直状（▪），大小2×2像素；一旦侧面有上述方块，它会变得扁平，或呈现[text-top](File:Curve.png.md)、[text-top](File:T junction.png.md)或[text-top](File:Cross.png.md)形状，这取决于在它周围的方块。染色玻璃板的碰撞箱与染色玻璃板的形状相对应，因此玩家或[物品](物品（实体）.md)都可以穿过2×2染色玻璃板组成的洞。

染色玻璃板永远不会处于水平状态。
