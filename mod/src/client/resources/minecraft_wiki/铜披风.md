# 铜披风

*页面ID: 186289* | *来源: Minecraft Wiki*

* *铜披风（Copper Cape）**是[铜器时代](铜器时代.md)版本的纪念披风。

# 外观
铜披风的设计结合了[铜箱子](铜箱子.md)和[雕纹铜块](雕纹铜块.md)的纹理，并表现出不同的氧化阶段。

鞘翅的设计则来自[铜格栅](铜格栅.md)的纹理。

# 描述
此披风是[铜器时代](铜器时代.md)版本的纪念披风，2025年10月13日至2025年10月20日期间，可通过以下任一渠道获得：放置一个[铜傀儡像](铜傀儡像.md)；在Twitch或TikTok中完成观看任务获得[兑换码](https://minecraft.net/en-us/redeem)；亲自在2025年10月17日至19日于圣地亚哥举行的TwitchCon上获取兑换码。<ref></ref>

拥有基岩版铜披风的玩家于2025年10月15日后收到Java版铜披风。
