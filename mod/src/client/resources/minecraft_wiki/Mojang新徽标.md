# Mojang新徽标

*页面ID: 150675* | *来源: Minecraft Wiki*

* *Mojang新徽标（New Thing）**是一幅旗帜图案，游戏内物品名称为**旗帜图案**。

# 用途
# = 织布机配方 =

Mojang新徽标旗帜图案可以用于[织布机](织布机.md)中来将图案添加到旗帜上。其必须与一个旗帜和染料结合，使用后不会消耗自身。
