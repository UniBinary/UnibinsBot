* *雪傀儡（Snow Golem）**是一种可以发射[雪球](雪球.md)的[友好生物](友好生物.md)。

# 生成
|雪傀儡结构图示|style=display:inline-block;margin:0;max-width:50px}}
|另一种结构|style=display:inline-block;margin:0;max-width:50px}}
放置2个相邻的[雪块](雪块.md)，然后在其中一端放置一个[雕刻南瓜](雕刻南瓜.md)或[南瓜灯](南瓜灯.md)，即可生成一个雪傀儡。

雕刻南瓜或南瓜灯必须最后放置。雕刻南瓜可以被[末影人](末影人.md)和[发射器](发射器.md)放置。南瓜灯也能被发射器放置。放置[南瓜](南瓜.md)不能生成雪傀儡，但用[剪刀](剪刀.md)修剪后可以生成。将这些方块横放或倒放也能生成出雪傀儡。

以任何方向放置方式生成的雪傀儡都会在脚部（即远离雕刻南瓜或南瓜灯）的雪块的位置上生成。

# == 更新区域 ==
[thumb|雪傀儡结构的更新区域（视角向北）](File:Snow_Golem_creation_update_area.png.md)

当已存在一个完整的雪傀儡结构，但由于放置顺序不正确而没有生成雪傀儡时，玩家能在特定区域再放置一个雕刻南瓜或南瓜灯来“更新”结构生成雪傀儡。

更新区域的具体范围为：以雪傀儡结构（包括两处可能的头部位置）的一行方块为起点，向X轴负方向（西）、Z轴负方向（北）以及向下各扩展2格。

若发射器周围有完整的雪傀儡结构，或是仅缺失头部的雪傀儡结构（头部位置为空气或其他方块，其余位置满足要求），且发射器面对的位置在更新区域内，发射器就能将雕刻南瓜放置在面前，即使这样做可能无法生成雪傀儡。

# 行为
[240px|缩略图|一个被剪掉头盔的雪傀儡](File:ShearedSnowGolem.png.md)

雪傀儡空闲时会漫无目的地游荡，试图避开[仙人掌](仙人掌.md)、[火](火.md)、[熔岩](熔岩.md)和[水](水.md)。虽然雪傀儡不会受到摔落伤害，但是它们依然会避开悬崖。它们不会主动躲避雨，下雨时它们可能会走入雨中并受到伤害。雪傀儡可以被[拴绳](拴绳.md)牵引或被拴在栅栏上。

雪傀儡处于[恶地](恶地.md)、[沙漠](沙漠.md)、[热带草原](热带草原.md)、[下界生物群系](生物群系#下界.md)以及它们的变种等[生物群系](生物群系.md)时会受到伤害。雪傀儡是否受到伤害取决于生物群系的温度，当温度高于1.0时，其会受到伤害；而雪傀儡是否受到伤害取决于生物群系的种类本身，与其温度无关。[抗火](抗火.md)效果可以帮助其免受伤害，但效果持续时间结束后仍会受到伤害。不同于绝大多数生物，雪傀儡免疫[细雪](细雪.md)的冰冻伤害。

雪傀儡接触到[雨](雨.md)、[水](水.md)、[喷溅型水瓶](喷溅型水瓶.md)和[滞留型水瓶](滞留型水瓶.md)时，它也会受到伤害。

雪傀儡将[雕刻南瓜](雕刻南瓜.md)作为头盔，与玩家类似——真正的头在头盔内。玩家可以[剪刀](剪刀.md)或使用装有剪刀的[发射器](发射器.md)剪去雪傀儡的南瓜头，露出它真正的头，同时掉落雕刻南瓜。但雕刻南瓜并不是它实体数据中的头盔装备；雪傀儡不显示它装备的物品。玩家也不可以给予它新的雕刻南瓜头盔。

不同于其他生物，雪傀儡处于[着火](着火.md)状态时没有火粒子，但仍会变为橙色。

# = 攻击 =
[240px|缩略图|一群雪傀儡在向[[蜘蛛](File:SnowGolemBehavior.png.md)扔[雪球](雪球.md)]]

雪傀儡能在16格外看见敌对生物，并向其投掷雪球。如果雪傀儡能够接近敌对生物，它会向敌对生物（[恶魂](恶魂.md)、除外）移动，并在距离它们10格时停下。<ref>http://gaming.stackexchange.com/questions/54362/what-is-a-snow-golems-range</ref>它们投掷的雪球可以击退敌对生物，但只会对[烈焰人](烈焰人.md)造成伤害。

[僵尸](僵尸.md)、[尸壳](尸壳.md)、[溺尸](溺尸.md)、[僵尸村民](僵尸村民.md)、[蜘蛛](蜘蛛.md)、[洞穴蜘蛛](洞穴蜘蛛.md)、[史莱姆](史莱姆.md)、[蠹虫](蠹虫.md)、[女巫](女巫.md)、[唤魔者](唤魔者.md)和[卫道士](卫道士.md)会主动攻击雪傀儡。

雪傀儡可以透过[方块](方块.md)定位目标，但是不会透过方块发射雪球。

雪傀儡不会反击任何攻击它的生物，但雪傀儡的弹射物可能会命中沿途的任何生物，并导致有反击行为的生物反击雪傀儡。

雪傀儡是极少数会主动攻击[苦力怕](苦力怕.md)的生物，这将会使苦力怕对雪傀儡产生敌意并爆炸。<ref></ref>

如果[铁傀儡](铁傀儡.md)被雪傀儡的雪球意外击中，铁傀儡会反击雪傀儡。

如果雪傀儡投掷出的雪球击中玩家，就会造成击退，并使驯服的[狼](狼.md)与信任玩家的[狐狸](狐狸.md)攻击雪傀儡。

雪傀儡投掷出的雪球穿过一格熔岩或火后除了对目标产生击退效果外，还会令目标着火。

# = 产雪 =

雪傀儡走过的方块若能支撑[雪](雪.md)，则上方会出现雪，<ref name=SnowGolemTrail></ref>但雪傀儡无法在蘑菇岛、恶地、沙漠、丛林、热带草原和下界的任何生物群系中生成雪。雪傀儡站在[漏斗](漏斗.md)的凹槽内时不会产生雪。[游戏规则](游戏规则.md)设置为<code>false</code>时，雪傀儡无法产生雪。
