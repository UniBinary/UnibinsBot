# 诡异菌岩

*页面ID: 171568* | *来源: Minecraft Wiki*

* *诡异菌岩（Warped Nylium）**是一种在[下界](下界.md)自然生成的方块。

# 生成
# = 自然生成 =
诡异菌岩在[诡异森林](诡异森林.md)中自然生成。

# = 人工生成 =
对在诡异菌岩旁的[下界岩](下界岩.md)[骨粉](骨粉.md)可以使下界岩变为诡异菌岩。激活朝向下界岩的内有骨粉的[发射器](发射器.md)也能使下界岩转变成诡异菌岩。此过程中下界岩的上方必须是[空气](空气.md)。

# == 传播规则 ==
如果在以下界岩为中心3×3×3的区域内有诡异菌岩，那么对下界岩使用[骨粉](骨粉.md)时就能转变为诡异菌岩。

# 破坏
挖掘诡异菌岩的合适工具是[镐](镐.md)。诡异菌岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，诡异菌岩被破坏后会掉落1个[下界岩](下界岩.md)。

被具有精准采集的工具挖掘破坏时，诡异菌岩被破坏后会掉落自身。

# 用途
类似于[草方块](草方块.md)和[菌丝体](菌丝体.md)，当上方放有固体方块时诡异菌岩会退化（基于[随机刻](随机刻.md)）。但不同的是，当上方有[水](水.md)或[熔岩](熔岩.md)时诡异菌岩不会退化。

当[雪](雪.md)覆盖在诡异菌岩上时，诡异菌岩也会退化。<ref></ref>

类似于草方块，玩家可以对诡异菌岩[骨粉](骨粉.md)。这个诡异菌岩、附近的诡异菌岩和绯红菌岩上方会生成两种[菌索](菌索.md)（有1%的概率生成[绯红菌索](绯红菌索.md)<ref></ref>）、两种[下界菌](下界菌.md)（多数是诡异菌）和[下界苗](下界苗.md)，还有的概率生成1格高的[缠怨藤](缠怨藤.md)。

[诡异菌](诡异菌.md)必须种在诡异菌岩上才能用骨粉使其生长为对应的[巨型诡异菌](巨型诡异菌.md)。

[末影人](末影人.md)可以搬起及放下诡异菌岩。关闭[游戏规则](游戏规则.md)将阻止该行为。
