# 基岩版1.15.0.8

*页面ID: 59640* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.15.0.8**是[基岩版1.16.200](基岩版1.16.200.md)的首个[RenderDragon](RenderDragon.md)测试版，发布于2020年4月16日<ref>[Minecraft NVIDIA RTX FAQ](https://help.minecraft.net/hc/en-us/articles/360041035092-Minecraft-NVIDIA-RTX-FAQ)</ref>，将RenderDragon引入到Windows 10平台。

# 新内容
# = 常规 =
* 加入了高级视频选项。
* 加入了DirectX Ray Tracing切换选项。
* * 用于切换[光线追踪](wzh:光線追蹤.md)效果。
* 加入了Upscaling切换选项。
* * 用于利用NVIDIA DLSS 2.0技术提升GeForce RTX显卡上的帧率。
* 加入了Ray Tracing View Bobbing切换选项。
* * 用于切换光线追踪时视角的摇晃效果。
* 加入了Ray Tracing Render Distance切换选项。
* * 用于控制立刻进行光线追踪渲染的区块渲染距离。

# 更改
# = 常规 =
* 资源包现在支持光线追踪。
* 将高级树叶、高级气泡、高级云彩、高级天空、平滑光照、高级图像和视角摇晃选项移入了高级视频设置。</onlyinclude>
