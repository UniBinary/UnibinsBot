# 基岩版1.8.0.11

*页面ID: 36839* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.8.0.11**是[1.8.0](基岩版1.8.0.md)的第3个测试版，发布于2018年10月24日<ref>https://feedback.minecraft.net/hc/en-us/articles/360018603151-Minecraft-Beta-1-8-0-11-Xbox-One-Windows-10-Android-</ref>，更改了熊猫的生物AI，并修复了一些漏洞。

# 更改
# = 生物 =
* *[熊猫](熊猫.md)**
* 所有性格的[熊猫](熊猫.md)在受到攻击时都会尝试反击一次。
* 好斗的熊猫现在会保护其他熊猫。
* 加入了新的好斗的熊猫皮肤。
* 熊猫现在向好斗的熊猫传播愤怒。
* 好斗的熊猫现在会保护受到攻击的幼年熊猫。

# 修复
* *修复了24个漏洞**
* 修复了游戏过程中出现的崩溃现象。
* 加入多人游戏服务器时游戏崩溃。
* 破坏方块时，玩家的手臂摆动不正确。（）
* 自定义实体现在可以正确使用组件。（）
* 玩家现在可以在水里或者旁边使用脚手架。（）
* 攀爬脚手架时，触摸屏设备的飞行按钮现在可以有效使用。（）
* 在部分设备里，马的纹理会闪烁。（）
* 渲染区块时，游戏性能下降。（）
* 现在只有操作员权限的玩家才能更改游戏规则。
* 下落的方块（例如沙子）不再导致脚手架变成掉落物。（）
* 玩家的出生点被以外更改。
* 在“关闭成就”提示框里按下“返回”不再导致游戏模式被更改。
* 重新进入世界时，熊猫会被困在活塞顶部。（）
* 使用新的玩家皮肤不再导致屏幕左上角的纸娃娃出现问题。
* 末影人的下巴消失。
* 创造模式下，方块在被瞬间破坏时现在会更加快消失。
* 市场里的全局搜索结果现在会更加连贯。
* “获取更多模板”界面现在只会显示模板世界。
* 发射器发射鱼桶时游戏崩溃。（）
* 染色床现在有了正确的合成配方。
* 玩家随机出现朝向错误。（）
* 放置双层台阶时不会生成正确的方块。（）
* 玩家站在下界传送门时，退出世界导致游戏崩溃。
* 设置未拥有的皮肤时，现在会将玩家带向角色创建器界面。</onlyinclude>
