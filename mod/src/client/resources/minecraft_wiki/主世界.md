# 主世界

*页面ID: 7268* | *来源: Minecraft Wiki*

[thumb|320px|主世界中的[[森林](File:Overworld.jpg.md)、[积雪针叶林](积雪针叶林.md)和[冻洋](冻洋.md)生物群系]]
* *主世界（Overworld）**是Minecraft玩家的游戏征途开始时所在的[维度](维度.md)。

# 创建
玩家创建新世界时，主世界是该世界中唯一存在的维度。而[下界](下界.md)和[末地](末地.md)这两个维度都需要进入特定的[传送门](传送门.md)才会产生。

# = 种子 =
}}
在Minecraft中创建新世界需要使用种子。种子是用作世界生成算法起点的整数。玩家在创建世界时可以自定义种子，也可以让游戏随机生成一个种子。如果玩家创建世界时输入了非整数形式的种子，游戏则会将其转换成对应的整数使用。

只要游戏平台、[游戏版本](版本历史.md)和[世界类型](世界类型.md)相同，每次使用相同的种子就都会产生几乎完全相同的世界。除了[出生点](出生点.md)有微小的差异外，所有地形对应的[坐标](坐标.md)都会保持一致。

# 环境
主世界的环境极其复杂，而且拥有非常多样的特性。

# = 生物群系 =
[thumb|200px|河流群系穿过[[恶地](File:River through Mesa.png.md)生物群系]]

主世界可以依环境特征划分出多种[生物群系](生物群系.md)。生物群系的种类可以决定其所处区域所有的基本地理性质，且几乎所有生物群系都有各自的变种，可以进一步调整环境特征，令环境景观更加理想化。生物群系也会影响其自身规模的大小，控制可生成[生物](生物.md)的种类，还可以改变[天气](天气.md)等环境行为。

# = 自然结构 =
[thumb|200px|[[村庄](File:Village-1.14-overworld.png.md)，是主世界生成的众多结构之一]]

主世界由大量形态各异的地形元素组成，这些元素被称为结构。结构在不同世界中的分布因种子的差异而大不相同。特定的结构在特定的世界中是独一无二的，而在特定位置生成的结构的种类由此处的生物群系决定。结构一般可以与现实中的景观相联系，譬如[山脉](山脉.md)、[洞穴](洞穴.md)和[湖泊](湖泊.md)。而像[浮岛](浮岛.md)这样的不可能出现在现实世界当中的结构也会出现在主世界中。

除了这些地形元素以外，自然结构还包括自然生成的建筑物，譬如[村庄](村庄.md)、[地牢](地牢.md)和[废弃矿井](废弃矿井.md)。

# = 昼夜更替 =
[thumb|right|昼夜更替的视图](File:Day Night.gif.md)

主世界是唯一拥有昼夜更替的[维度](维度.md)，也因此是唯一一个能够由环境变化反映时间流逝的维度。相比现实世界的时空，主世界的时间总是均一地流逝的。所有同在该维度下的玩家，无论其间隔多远，其时间流逝的速度总是相同的。

在白天，[太阳](太阳.md)作为强大的光源，能够发出最大亮度等级（15）的光。[阳光](阳光.md)可以促进植物生长、影响[生物](生物.md)的生成等。在夜间，[月亮](月亮.md)是唯一的自然光源。但月光相对较暗，其发光的亮度等级只有4，这使敌对生物能够在夜间生成。夜晚是玩家能够上[床](床.md)睡觉的时段。

昼夜更替的情况可通过[时钟](时钟.md)来观察，玩家可以在主世界的任何地方使用时钟查看大致的[Minecraft时间](昼夜更替#时间换算.md)。时间也可以通过命令获取和修改。

太阳如现实世界一般东升西落，因此玩家可以通过观察日月的运动来简单辨别方向。

# = 生物 =

主世界是多种[生物](生物.md)的家园。生物的习性各不相同，且可能会对玩家造成不同程度的威胁，而根据这些特征，生物可以被分成数个类别。不同种类的生物也拥有不同生成条件，其中包括时间、亮度、生物群系以及其他一些因素。

# 生成
与所有其他维度一样，主世界可以无限生成。然而生成会有所限制，[详情见下](#限制.md)。

主世界拥有[高度限制](高度限制.md)（Y=320），最低通往[虚空](虚空.md)（Y=-64），但往四周可水平延伸29,999,999格。<!--技术上而言，世界的生成是通过建立数个噪声分布来决定地形地貌、区块外观，以及山脉、洞穴系统的状态和分布。-->

# = 区块 =
[thumb|right|75px|区块的示意图](File:Chunk.png.md)

区块是世界生成器划分世界的分块，以便管理。区块有16格宽、16格长、384格高，总体积为98304方块。[首次进入世界](出生点区块.md)时，玩家周围的区块会立即生成；随着玩家的移动，新的区块会根据需要逐渐生成。通过调节[渲染距离](渲染距离.md)，玩家可以决定载入内存的区块数量，范围为25-1089个区块。

只有指定范围内的区块能够发生活动（[生物生成](生成#周期生成.md)、[树木](树木.md)生长、[水](水.md)的流动、掉落[物品](物品.md)的消失、生物移动等等），范围以外的区块不活动，且被保存在硬盘上。这种区块管理机制使玩家的计算机免于同时追踪成千上万的[方块](方块.md)和[实体](实体.md)造成卡顿。在无限世界首次被引入时（Infdev-Beta 1.7版本），超出X轴或Z轴±32,000,000处的区块是“假区块”，超过了这个位置不会有方块生成，尽管仍然有方块显示出来。如果玩家尝试走上这些区块，会直接掉进虚空。

# = 限制 =

世界的大小并非无限的。玩家可以最远传送到X/Z=±29,999,999，在游戏中尝试传送到该坐标之外会总是被传送到X/Z=±29,999,999。

X/Z=±30,000,000上存在着一堵隐形的墙以阻止玩家继续前进，利用船和矿车仍然可以绕过这一界限，其中矿车会卡在X/Z=±30,000,096，而船仍然可以向更远的区域行驶。通过更改渲染距离，玩家最远可到达X/Z=±30,000,544。世界的绝对边缘位于X/Z=±30,001,056，超过这个位置的区块不会生成。

[旧世界](旧世界类型.md)的大小限制为256×256。世界的边缘处被[隐形基岩](隐形基岩.md)所包围。

# 你知道吗
* 在主世界中方块能够存在的最大数量约为921.6千兆（9.216×10<sup>17</sup>），预计可从中心往4个方向外延伸30,000,000米。
* * 主世界总面积大约是地球表面积的7倍，海王星表面积的一半。
* 如果有人创造了与地球尺寸大小比为1:1（1方块=1米）的地图，其约由510.9万亿（5.109×10<sup>14</sup>）个方块构成。
* * 与一个月球一样大的地图约由37.95万亿（3.795×10<sup>13</sup>）个方块构成。
