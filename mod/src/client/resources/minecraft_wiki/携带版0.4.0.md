# 携带版0.4.0

*页面ID: 21022* | *来源: Minecraft Wiki*

* *v0.4.0 alpha**是[携带版](携带版.md)的一次主要更新，发布于2012年9月13日<ref name=":0"></ref>，加入了[箱子](箱子.md)、[床](床.md)、[TNT](TNT.md)、[石砖](石砖.md)、[活板门](活板门.md)、[草](草.md)和一些新的食物，在游戏中加入了和平难度，并修复了一些漏洞。这也是Fire OS上第一个公开的发布版本。

# 新内容
# = 方块 =
* *[床](床.md)**
* 用于跳过[夜晚](夜晚.md)并设置重生点。

* *[活板门](活板门.md)**
* 可作为用手打开的1×1屏障。

* *[石砖](石砖.md)**
* 仅在生存模式下可用。

* *[草](草.md)**
* 目前无法获得。

# = 物品 =
* *[打火石](打火石.md)**
* 用于引爆[TNT](TNT.md)。

* *[锄](锄.md)**
* 用于将泥土和草方块变为耕地。

* *[食物](食物.md)**
* [苹果](苹果.md)
* [面包](面包.md)
* [蘑菇煲](蘑菇煲.md)
* [生牛肉](生牛肉.md)
* [牛排](牛排.md)
* [生鸡肉](生鸡肉.md)
* [熟鸡肉](熟鸡肉.md)
* [生猪排](生猪排.md)
* [熟猪排](熟猪排.md)
* [小麦](小麦.md)
* [小麦种子](小麦种子.md)

* *[鸡蛋](鸡蛋.md)**
* 可投掷实体。
* 目前无法获得。

# = 游戏玩法 =
* *[难度](难度.md)**
* 加入了[生存模式](生存模式.md)下的和平[难度](难度.md)选项，打开后会自动回复生命值，敌对生物不会生成。

# = 常规 =
* 加入了一些方块的合成配方：
* * [TNT](TNT.md)
* * [箱子](箱子.md)
* * [羊毛](羊毛.md)

# 更改
# = 常规 =
* Android版移除了Google Play正版验证。

# = 物品 =
* *[雪球](雪球.md)**
* 现在能够被投掷了。

* *[火药](火药.md)**
* 现在可用于合成TNT。

* *[玫瑰红](玫瑰红.md)**
* 现在可通过烧炼[红色蘑菇](红色蘑菇.md)来获得。
* 现在可用于合成红色[羊毛](羊毛.md)。

* *[橙色染料](橙色染料.md)**
* 现在可以用玫瑰红和[蒲公英黄](蒲公英黄.md)合成了。
* 现在可用于合成橙色羊毛。

* *[黄绿色染料](黄绿色染料.md)**
* 现在可以用仙人掌绿和[骨粉](骨粉.md)合成了。
* 现在可用于合成黄绿色羊毛。

* *[仙人掌绿](仙人掌绿.md)**
* 现在可用于合成绿色羊毛。

* *[青色染料](青色染料.md)**
* 现在可以用仙人掌绿和[青金石](青金石.md)合成了。
* 现在可用于合成青色羊毛。

* *[淡蓝色染料](淡蓝色染料.md)**
* 现在可以用骨粉和青金石合成了。
* 现在可用于合成淡蓝色羊毛。

* *[紫色染料](紫色染料.md)**
* 现在可以用玫瑰红和青金石合成了。
* 现在可用于合成紫色羊毛。

* *[品红色染料](品红色染料.md)**
* 现在可以用玫瑰红、青金石和2份骨粉合成了。
* 现在可用于合成品红色羊毛。

* *[粉红色染料](粉红色染料.md)**
* 现在可以用玫瑰红和骨粉合成了。
* 现在可用于合成粉红色羊毛。

# = 生物 =
* 限定了给定[生物](生物.md)类型的总数。
* 生物生成（未完成）

* *[僵尸](僵尸.md)**
* 现在死亡后掉落[羽毛](羽毛.md)。

* *[苦力怕](苦力怕.md)**
* 现在能够自然生成。

# = 世界生成 =
* *[橡树](橡树.md)**

* 当使用物品时，玩家的移动速度会减缓。

* * [活板门](活板门.md)
* * [床](床.md)
* * [箱子](箱子.md)
* * [TNT](TNT.md)（仅Android）<ref></ref>
* * [小麦种子](小麦种子.md)
* * [骨粉](骨粉.md)
* * [铁锄](铁锄.md)

* * [石锹](石锹.md)

# 修复
* *修复了15个漏洞**
* 怪物现在能在室内生成了。
* 向客户端添加了坠落音效。
* 玩家现在能在很远的距离上互相攻击了。
* 在第三人称下弓的渲染不正确。
* 射出箭后的粒子效果丢失。
* 修复了在摧毁时，楼梯变成了它们的原始方块（变回木板）的漏洞。
* 修复了在弓蓄力时可以摧毁某些方块，或与一些方块交互的漏洞。
* 修复了当玩家在蓄力弓时被杀死，游戏会崩溃的漏洞。
* 修复了连接中的玩家可以在创造模式中死亡的漏洞。
* 修复了云杉叶在掉落成物品或拿在手上时，可能六面都会使用工作台的纹理的漏洞。
* 修复了Xperia Play平台上的工作台GUI大小错误的漏洞。
* 修复了弓在使用时不损失耐久的漏洞。
* 由橡木原木组成的树又会自然生成了。
* 修复了破坏一扇门可能会留下一半的门的漏洞。
* 修复了iOS平台上的蜘蛛死亡音效丢失的漏洞。
