# 渗浆

*页面ID: 115146* | *来源: Minecraft Wiki*

* *渗浆（Oozing）**是一种让生物死亡时产生[史莱姆](史莱姆.md)的[状态效果](状态效果.md)。

# 效果
带有此效果的生物死亡时，会尝试在死亡处生成2只中型[史莱姆](史莱姆.md)。生成后该位置的史莱姆数量不会超过[游戏规则](游戏规则.md)。

除末影龙和凋灵外，免疫此效果的生物受标签控制。

# 来源
激活的[不祥试炼刷怪笼](不祥试炼刷怪笼.md)每在玩家或距离不祥试炼刷怪笼14格内的生物头顶生成不祥之物生成器来随机选取生成带有此状态效果的[滞留药水](滞留药水.md)。
