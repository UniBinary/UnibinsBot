# 维度类型

*页面ID: 63674* | *来源: Minecraft Wiki*

* *维度类型定义文件**是**维度类型（Dimension Type）**在数据包中的数据驱动定义文件。

# 定义格式
维度类型在游戏内使用<code>DIMENSION_TYPE</code>注册表，数据包路径为，即所有维度类型定义文件都需要在目录下定义。

维度类型定义文件使用JSON格式，并具有下列结构：

# 定义行为
维度类型仅在服务端启动时加载一次，使用命令不可以使维度类型定义被重新加载，而必须重启服务端。

尽管游戏支持在数据包和中对维度类型内联定义，但游戏不支持加载内联维度类型的维度。<ref></ref>

维度类型控制了维度内所有与[世界生成](世界生成.md)无关的效果，包括建筑高度限制、环境效果和部分方块或生物的行为等。

# = 维度行为 =
下列为维度类型里较复杂的维度效果，对应的游戏行为均假定已满足其他条件。其余不由维度类型控制的维度行为见。

控制了维度逻辑上是否拥有[昼夜更替](昼夜更替.md)。注意：此值不控制太阳的东升西落、亮度的昼夜变化等视觉上的行为，它仅会使部分生物对昼夜更替的判定失效，例如：
* 玩家在任意游戏时间床时均会尝试入睡。（本质上是影响环境属性<code>gameplay/bed_rule</code>的<code>when_dark</code>条件）
* [溺尸](溺尸.md)始终保持敌对状态。
* [流浪商人](流浪商人.md)不再饮用[隐身药水](隐身药水.md)或[奶桶](奶桶.md)。
* [灾厄巡逻队](灾厄巡逻队.md)始终可以尝试生成。
* [末影人](末影人.md)始终不会增加随机传送的概率。
* [狐狸](狐狸.md)始终不会前往村庄或尝试睡觉。
* [僵尸围城](僵尸围城.md)始终可以尝试生成。
* 僵尸类生物和骷髅类生物不会尝试躲避阳光。

控制了下列行为：
* 是否存在[天空光照](天空光照.md)。
* * 同理影响[阳光探测器](阳光探测器.md)的工作等。
* 是否可以生成[幻翼](幻翼.md)。
* 是否拥有[天气](天气.md)变化。

控制了下列行为：
* 初始动物生成寻找可生成方块时，其不会在对应的高度图选择方块，而是在对应高度图的高度上向下搜寻到首个上方为空气的非空气方块上选择方块。
* 玩家是否倾向于生成在Y=64上，而不是生成在最高的方块上。但如果世界是超平坦世界，依然会生成在最顶层。
* 影响部分[地图更新行为](地图存储格式#地图更新行为.md)。
* 是否不拥有天气变化。

# = 其他行为 =
一些维度行为被游戏硬编码，无法被修改。

为便于描述，规定<code>overworld</code>维度为主世界维度，<code>the_nether</code>维度为下界维度，<code>the_end</code>维度为末地维度。游戏以它们的ID为判断依据。
* 玩家总是生成在主世界。
* [下界传送门](下界传送门（方块）.md)在非下界维度时会尝试将实体按维度缩放传送到下界维度，如果世界不存在下界维度则什么也不做；在下界维度时会将实体按维度缩放传送到主世界维度。
* [末地传送门](末地传送门（方块）.md)在非末地维度时会尝试将实体传送到末地维度，如果世界不存在末地维度则什么也不做；在末地维度时会将实体传送到主世界维度。
* 若末地维度的维度类型为<code>the_end</code>，则启用[末影龙战斗](末影龙战斗.md)系统。
* 在末地维度的[霜冰](霜冰.md)依赖[方块光照](方块光照.md)而非[内部天空光照](内部天空光照.md)融化。
* 末地维度永远不会拥有天气。
* 下界维度的地图的玩家图标会随机旋转。
* 部分存档文件的路径与其他维度不同，见。

# 内置维度类型

游戏本体内置了四种维度类型：
* <code>overworld</code>：[主世界](主世界.md)。
* <code>the_nether</code>：[下界](下界.md)。
* <code>the_end</code>：[末地](末地.md)。
* <code>overworld_caves</code>：主世界洞穴。未被直接使用，只用于先前创建的洞穴世界类型的世界。
