# Java版Alpha v1.0.2 02

*页面ID: 33294* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.2_02**是的一次更新，发布于2010年7月6日。

# 更改
# = 方块 =
* *[水](水.md)**
* 只有当流动的水的下方也是水或是不透明方块时，它才会将其级别设为0。

# = 常规 =
* *其他**
* 加入了一个“加载纹理”的调试字符串，用于玩家的皮肤。
* 更改一些与世界信息有关的代码。</onlyinclude>
