* *玫瑰丛（Rose Bush）**是一种[大型花](大型花.md)。

# 生成

# = 自然生成 =
玫瑰丛会在[森林](森林.md)、[桦木森林](桦木森林.md)、[原始桦木森林](原始桦木森林.md)、[黑森林](黑森林.md)和[繁花森林](繁花森林.md)生物群系自然生成。

# 获取
# = 骨粉 =
对着玫瑰丛[骨粉](骨粉.md)会掉落1株新的玫瑰丛。

# 破坏
玫瑰丛被挖掘时会立刻被破坏。

玫瑰丛被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 堆肥 =
将玫瑰丛放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
