# 游戏模式

*页面ID: 6389* | *来源: Minecraft Wiki*

* *游戏模式（Game Mode）**是控制[玩家](玩家.md)进行游戏的方式的系统。<!--极限模式不是玩家游戏模式，而是世界设置，不应被添加至此条目 -->

# 机制

游戏中总共有四种游戏模式：
* 在[生存模式](生存模式.md)中，玩家可以放置与挖掘方块，使用所有可用的工具。敌对生物会主动攻击玩家。玩家受到[生命](生命.md)、[饥饿](饥饿.md)等多种因素的限制，并且挖掘方块会耗费一定的时间。
* 在[创造模式](创造模式.md)中，玩家不受任何生存因素的制约。玩家可以任意获取绝大多数物品和方块，并无限地使用这些资源。玩家可以瞬间挖掘方块、通过双击[飞行](飞行.md)，并具有大幅增强的互动范围。所有生物不会攻击玩家，玩家也不会受到伤害）|je}}。
* 在[冒险模式](冒险模式.md)中，玩家的大多数游戏内容与生存模式一致。不同的是，玩家不能挖掘或放置任何方块，除非手上持有的工具拥有对应方块的<code>can_destroy</code>[组件](组件.md)，或者拥有对应方块的 <code>can_place_on</code>组件。处于这个模式下的玩家在生成时将直接被精准地放置到世界出生点上而不是其周围的随机位置。
* 在[旁观模式](旁观模式.md)中，玩家会始终处于飞行状态，可以穿过方块、，但不能挖掘方块或修改物品栏，无法与世界做出任何互动。旁观模式也是[调试模式](调试模式.md)世界类型下的默认游戏模式。

# = 世界游戏模式 =

在创建一个世界时，可以选择世界的默认游戏模式。如果创建了一个[极限模式](极限模式.md)的世界，那么游戏模式将会是生存模式。

旁观模式的世界只能通过创建一个[调试模式](调试模式.md)的世界来选择。

每一个世界都有自己默认的游戏模式。这个游戏模式会影响每一个首次进入世界的玩家的游戏模式，但不会影响这些玩家在切换了游戏模式之后的游戏内容。

世界的游戏模式可以通过来更改；世界的游戏模式可以在游戏设置中修改，也可以通过修改存档文件来修改。

在存档屏幕，世界默认的游戏模式也会显示在世界名称的下方。

# = 玩家游戏模式 =
对于每一个玩家，其实体数据<code>playerGameType</code>记录了玩家当前的游戏模式。

变更玩家游戏模式的基本方式是。

[权限等级](权限等级.md)至少为的玩家还可以通过+来快捷切换游戏模式，或使用+来快捷切换到旁观模式或上一个游戏模式（若无则为创造模式）。

在[极限模式](极限模式.md)的世界中死亡后，玩家的游戏模式会被变更为旁观模式。

所有的[进度](进度.md)都可以在任意游戏模式中获得。

玩家可以在自己的游戏设置中变更自己的游戏模式。

所有的[成就](成就.md)都只能在生存模式中获得。

[目标选择器](目标选择器.md)可以筛选处于指定游戏模式的玩家。
