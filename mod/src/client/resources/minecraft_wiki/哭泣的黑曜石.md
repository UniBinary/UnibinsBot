* *哭泣的黑曜石（Crying Obsidian）**是[黑曜石](黑曜石.md)的变种方块。

# 生成
# = 自然生成 =
构成[废弃传送门](废弃传送门.md)的部分[黑曜石](黑曜石.md)会被哭泣的黑曜石替代。

# 获取
# = 箱子战利品 =

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家1-3个哭泣的黑曜石。

# 破坏
挖掘哭泣的黑曜石的合适工具是镐。哭泣的黑曜石需要钻石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

哭泣的黑曜石被破坏后会掉落自身。

# 用途
与黑曜石相似，哭泣的黑曜石是[硬度](硬度.md)非常高的建筑方块，其具有1200的[爆炸抗性](爆炸抗性.md)，且无法被[活塞](活塞.md)推动或被[末影龙](末影龙.md)破坏。它可用于制作[重生锚](重生锚.md)，能让玩家在[下界](下界.md)中重生。

放置时，哭泣的黑曜石偶尔会产生紫色滴状[粒子](粒子.md)，如同在“哭泣”一样。这些滴状粒子仅起装饰作用。

与黑曜石不同，哭泣的黑曜石不能用于构建下界传送门框架。

# = 光源 =
哭泣的黑曜石会发出[亮度](亮度.md)为10的光。
