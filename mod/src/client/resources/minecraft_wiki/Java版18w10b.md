# Java版18w10b

*页面ID: 33958* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w10b**是[Java版1.13](Java版1.13.md)的第25个快照，发布于2018年3月7日<ref></ref>，加入了失活的珊瑚、未染色的潜影盒以及更多的音效，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[失活的珊瑚](珊瑚块.md)**
* 加入了红色、黄色、蓝色、紫色和粉红色失活的珊瑚。
* * 离开水，珊瑚会变成等效色<!-- equivalently-colored -->的失活珊瑚。
* 移除了旧的失活珊瑚。

* *[潜影盒](潜影盒.md)**
* 加入了未染色的潜影盒。
* * 紫色潜影盒现在有了正确的紫色。

# = 常规 =
* *声音**
* 加入了更多的水下环境音效。
* 加入了[热带鱼](热带鱼.md)的声音。

# 更改
# = 方块 =
* *[珊瑚](珊瑚.md)**
* 更改了[珊瑚](珊瑚.md)的纹理。
