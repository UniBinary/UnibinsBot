# 混淆映射表

*页面ID: 47770* | *来源: Minecraft Wiki*

* *混淆映射表（Obfuscation Map）**是[Proguard](https://www.guardsquare.com/en/products/proguard)输出的映射了被混淆的类和类成员在混淆前后的名称的文本文件。<ref></ref>自[19w36a](19w36a.md)以来所有版本的[client.json](client.json.md)中都会导出混淆映射表。在19w36a发布一小段时间后，[Java版1.14.4](Java版1.14.4.md)的client.json也获得更新，导出了混淆映射表。<ref></ref>

2025年10月29日，Mojang宣布从[群骑纷争](群骑纷争.md)的下一个小更新的首个快照（即[26.1-snapshot-1](Java版26.1-snapshot-1.md)）开始，Java版代码将不再被混淆，因此混淆映射表将会被移除。此外，在[25w45a](25w45a.md)至[Java版1.21.11](Java版1.21.11.md)的所有版本中，Mojang同时发布了已混淆和未混淆的核心文件，以帮助模组作者进行过渡。<ref></ref>

# 用途
混淆映射表原意是用来反混淆被混淆后的堆栈记录的（例如[崩溃报告](崩溃.md)中的堆栈记录）。<ref></ref>对应教程[在此](Tutorial:获取崩溃报告#对报告进行反混淆.md)。

[Dinnerbone](Dinnerbone.md)和[Adrian Östergård](Adrian Östergård.md)表示混淆映射表会使编写[Mod](Mod.md)更方便。<ref></ref><ref></ref>[Searge](Searge.md)表示混淆映射表可以替代一些[辅助程序与编辑器](辅助程序与编辑器.md)，例如[Mod Coder Pack](Mod Coder Pack.md)。<ref></ref>

# = 第三方用途 =

混淆映射表中包含的信息足以反混淆Minecraft使之反编译出容易理解的代码。可能有[辅助程序与编辑器](辅助程序与编辑器.md)能够方便地反编译反混淆后的Minecraft。

根据许可证，这类反混淆反编译后的代码只能以修改后的版本发布，或作为更大的项目的一部分。

# 你知道吗
* 到2020年8月16日许可证更新为止，当年发布的版本在其混淆映射表文件的许可证中仍然使用<code># (c) 2019 Microsoft Corporation.</code>。
* 在客户端混淆映射表中，第一个方法是<code>youJustLostTheGame()</code>，这是致敬[The Game](wzh:The Game (游戏).md)的一个彩蛋。
* * 这个方法用于在按住调试按键十秒后触发游戏崩溃。
* * 在[21w13a](21w13a.md)至[1.21.1](Java版1.21.1.md)之间的版本的混淆映射表中，该方法的位置被重排到了第四位。<ref></ref>
