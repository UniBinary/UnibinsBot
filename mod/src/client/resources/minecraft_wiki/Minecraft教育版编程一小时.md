# Minecraft教育版编程一小时

*页面ID: 101165* | *来源: Minecraft Wiki*

* *Minecraft教育版编程一小时（Minecraft Education Hour of Code）**是[教育版](教育版.md)的可游玩地图，每年发布一次，目前共有6个课程。

# 课程
# = 2024年 =
[thumb|2024年课程的缩略图](File:Hour of Code 2024 Thumbnail.jpg.md)
2024年的编程一小时课程主题为“演出必须继续”（The Show Must Go On）。

# = 2023年 =
[thumb|2023年课程的缩略图](File:Hour of Code 2023 Thumbnail.jpg.md)
2023年的编程一小时课程主题为“AI世代”（Generation AI）。

# = 2022年 =
[thumb|2022年课程的缩略图](File:Hour of Code 2022 Thumbnail.jpg.md)
2022年的编程一小时课程主题为“逃离庄园”（Escape Estate）。

# = 2021年 =
[thumb|2021年课程的缩略图](File:Hour of Code 2021 Thumbnail.jpg.md)
2021年的编程一小时课程主题为“时间之旅”（TimeCraft）。

“穿越时空，通过编写代码探索建立美好未来的概念。体验一个由自己选择的冒险游戏，探索人类重要成就的关键时刻。利用代码超能力，解决历史上的神秘事故，收集线索，完成拼图，找出时间罪魁祸首，从而拯救未来。”

# = 2020年 =
[thumb|2020年课程的缩略图](File:Hour of Code 2020 Thumbnail.jpg.md)
2020年的编程一小时课程是有关社交情感技能的。这一课程又名“两个村庄的故事”（A Minecraft Tale of Two Villages）。

“在这次的Minecraft教育版编程一小时免费课程中，运用基本的编程概念，让两个村庄结下友谊。玩家们将会体验对邻居的同理心和同情心，学会合作和包容，并锻炼社交情感技能。”

# = 2019年 =
[thumb|2019年课程的缩略图](File:Hour of Code 2019 Thumbnail.jpg.md)
首个编程一小时课程发布于2019年，主题为森林大火。这一课程又名“AI造福人类”（AI for Good）。

“在这一免费的Minecraft教育版编程一小时课程中，探索基本的编程概念，了解人工智能技术！与Minecraft和MakeCode一起，帮助[智能体](智能体.md)遏制森林大火......”
