# 平滑石头

*页面ID: 43788* | *来源: Minecraft Wiki*

* *平滑石头（Smooth Stone）**是[石头](石头.md)的变种，可以通过[烧炼](烧炼.md)石头获得。

# 生成
# = 自然生成 =
平滑石头会自然生成在[平原](平原.md)、[热带草原](热带草原.md)和[雪原](雪原.md)[村庄](村庄.md)的屠夫房屋中，也会自然生成于平原村庄的盔甲匠房屋和热带草原村庄的铁匠铺中。

平滑石头还会自然生成在[古迹废墟](古迹废墟.md)中。

# 获取
# = 箱子战利品 =

# = 烧炼 =
平滑石头可以由石头烧炼而成。

# 破坏
挖掘平滑石头的合适工具是镐。平滑石头需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

平滑石头被破坏后会掉落自身。
