# Minecraft: Caves &amp; Cliffs (Original Game Soundtrack)

*页面ID: 90342* | *来源: Minecraft Wiki*

* **Minecraft: Caves & Cliffs (Original Game Soundtrack)*（《Minecraft：洞穴与山崖（游戏原声带）》）**是[Lena Raine](Lena Raine.md)与[谷冈久美](谷冈久美.md)合作为[Minecraft](Minecraft.md)的一次主要更新[洞穴与山崖](洞穴与山崖.md)创作的专辑，也是Lena Raine为Minecraft创作的第二张专辑。专辑于2021年10月20日在Spotify上发布。

本专辑包含10首乐曲，时长总计47分钟46秒，包括9首在[主世界](主世界.md)播放的曲目，以及1首*otherside*[音乐唱片](音乐唱片.md)的曲目。

# 曲目单

# 你知道吗
* 有4首乐曲的播放位置从特定生物群系改为了主世界任何位置。<ref></ref>
* * "Left to Bloom"原定于草甸、繁茂洞穴、森林、丛林和原始针叶林中播放。
* * "One More Day"原定于草甸、积雪山坡、繁茂洞穴、森林、丛林和原始针叶林中播放。
* * "Floating Dream"原定于尖峭山峰、繁茂洞穴、森林、丛林和原始针叶林中播放。
* * "Comforting Memories"原定于雪林中播放。
