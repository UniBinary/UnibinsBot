# Java版21w03a

*页面ID: 75041* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w03a**是[Java版1.17](Java版1.17.md)的第6个快照，发布于2021年1月20日<ref></ref>，加入了[发光鱿鱼](发光鱿鱼.md)、[发光鱿鱼刷怪蛋](发光鱿鱼刷怪蛋.md)、[发光地衣](发光地衣.md)、[荧光墨囊](荧光墨囊.md)和[荧光物品展示框](荧光物品展示框.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[发光地衣](发光地衣.md)**
* 新加入的光源，会发出[亮度](亮度.md)为7级的光。
* 自然生成于[洞穴](洞穴.md)中，较为罕见。
* 可附着在方块的任意表面上。
* 可使用[剪刀](剪刀.md)采集。
* 可以[含水](含水.md)。
* 使用[骨粉](骨粉.md)可使之蔓延到其他方块表面。

* *[荧光物品展示框](荧光物品展示框.md)**
* 一种新的发光[实体](实体.md)。
* 放置于其中的物品会发光。
* 亮度仅反映在纹理上，不会影响光照等级。
* 可使用[荧光墨囊](荧光墨囊.md)和[物品展示框](物品展示框.md)合成。

# = 物品 =
* *[荧光墨囊](荧光墨囊.md)**
* 由发光鱿鱼掉落。
* 可用于制作荧光物品展示框。
* 对[告示牌](告示牌.md)上的文本（包括已染色的文本）使用后可提高其亮度，但并不会影响光照等级。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了发光鱿鱼刷怪蛋。

# = 生物 =
* *[发光鱿鱼](发光鱿鱼.md)**
* 新的水生生物，原型为[Minecraft Earth](Minecraft Earth.md)的[发光鱿鱼](MCE:发光鱿鱼.md)。
* 尚不可自然生成。
* 会被[美西螈](美西螈.md)主动攻击。
* 死亡后掉落荧光墨囊。
* 亮度仅反映在纹理上，不会影响光照等级。

# 更改
# = 方块 =
* *[滴水石块](滴水石块.md)**
* 现在由4个[滴水石锥](滴水石锥.md)合成。

* *[告示牌](告示牌.md)**
* 现在可使用荧光墨囊来提高其文本亮度。
* * 亮度仅反映于文本本身，不会影响光照等级。
* 对发光文字使用[墨囊](墨囊.md)将移除发光效果。
* 加入了一个新的[方块状态](方块状态.md)<code>lit</code>，以指示告示牌的文本是否变亮。

# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 为在石笋上摔死添加了独有的死亡消息。
* * “<玩家> 被石笋刺穿了”和“<玩家> 在攻击 <实体>时被石笋刺穿了”。
* * 在此之前在石笋上摔死使用的是常规的摔落死亡消息。

* *[配方书](配方书.md)**
* [雕纹磨制黑石](雕纹磨制黑石.md)配方书的解锁条件由[磨制黑石](磨制黑石.md)改为[磨制黑石台阶](磨制黑石台阶.md)。

* *[字幕](字幕.md)**
* 更改英文中部分字幕的大小写。

# = 常规 =
* *方块模型**
* 简化了[藤蔓](藤蔓.md)的方块模型。

* *[服务器](服务器.md)**
* 更改了无法到认证服务器的错误。现在的描述是“”而不是“

* *[标签](Java版标签.md)**
* 将发光鱿鱼添加进实体类型标签。

* *[混淆映射表](混淆映射表.md)**
* 更改了混淆映射表中的许可证信息。

* *世界选取**
* 添加了数对降级存档的警告。

* *[语言](语言.md)**
* 移除了哥特语、卡拜尔语、毛利语、莫霍克语、努克语、奥杰布瓦语和塔罗萨语，因为这些语言的翻译尚未完善。

* *[自定义世界](自定义世界.md)**
* 世界的建筑高度范围最大可以修改为Y=-2048到2031，山地和洞穴的生成将相应地扩展，类似于放大化世界类型。
