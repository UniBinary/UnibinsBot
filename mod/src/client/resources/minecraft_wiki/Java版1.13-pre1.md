# Java版1.13-pre1

*页面ID: 34863* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.13-pre1**是[Java版1.13](Java版1.13.md)的首个预发布版，发布于2018年6月4日<ref></ref>。

# 新内容
# = 常规 =
* *[音乐](音乐.md)**
* 加入了三首水下背景音乐：
* * *[Shuniji](:File:Shuniji.ogg.md)*、*[Dragon Fish](:File:Dragon Fish.ogg.md)*和*[Axolotl](:File:Axolotl.ogg.md)*。
* * 它们的命令ID是<code>music.under_water</code>。

# 更改
# = 方块 =
* *[木头](木头.md)**
* 更改了6种树皮方块的顶部和底部纹理。

* *[去皮丛林原木](去皮丛林原木.md)**
* 更新了侧边纹理。

* *[命令方块](命令方块.md)**
* 玩家现在可以再次在[命令方块](命令方块.md)中使用补全命令。

# = 生物 =
* *[幻翼](幻翼.md)**
* 加入了新的拍打声。

* *[溺尸](溺尸.md)**
* 现在有了游泳动画。

# = 常规 =
* *[全景图](全景图.md)**
* 更新为水域更新全景图。
