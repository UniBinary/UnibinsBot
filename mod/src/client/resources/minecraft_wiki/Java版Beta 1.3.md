* *Beta 1.3**是的一次主要更新，发布于2011年2月22日<ref></ref>，加入了[红石中继器](红石中继器.md)、[床](床.md)、3种新的[台阶](台阶.md)和新的加载界面，将世界格式从[Alpha世界格式](Alpha世界格式.md)变为了[MCRegion](区域文件格式.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[红石中继器](红石中继器.md)**
* 一种红石元件。
* 用于“加强”“中继”红石信号、阻止信号“倒流”和增加传输“延迟”。

* *[床](床.md)**
* 一种可以用来睡觉并保存重生点的方块。

* *[台阶](台阶.md)**
* 加入了圆石、砂岩和木台阶。
* * 该版本加入的木台阶实际上是[石化橡木台阶](石化橡木台阶.md)。

# = 命令格式 =
* ***
* 为[多人游戏](多人游戏.md)服务器加入了白名单机制。
* * 可以启用或禁用白名单。
* * 可以添加或删除白名单内的[玩家](玩家.md)。
* * 可以列出白名单里的所有玩家。
* 此时[白名单](白名单存储格式.md)文件名为<code>white-list.txt</code>。

# = 常规 =
* *[选项](选项.md)**
* 新的图像设置界面。

* *[主菜单](主菜单.md)**
* 将启动界面从“Loading...”更改为显示Mojang Logo的新界面。

# 更改
# = 方块 =
* *[红石粉](红石粉.md)**
* 离红石能量源越远，红石粉就越暗，红石能量也就越弱。

* *[砂岩](砂岩.md)**
* 现在可以在自然生成的[沙子](沙子.md)下面找到。
* 现在能更快地挖掘[砂岩](砂岩.md)。

* *[台阶](台阶.md)**
* 现在会在挖掉一个由双台阶组成的方块时掉落两个台阶。
* [石台阶](石台阶.md)现在可以由3个对应材料合成。

* *[石质压力板](石质压力板.md)和[木质压力板](木质压力板.md)**
* 现在需要2个对应材料，而不是3个。

# = 物品 =
* *[火药](火药.md)**
* 现在叫做火药（Gunpowder），而不是硫磺（*Sulphur*）。

# = 生物 =
* *常规**
* 在更高的难度下，友好生物会生成得更少。

* *[史莱姆](史莱姆.md)**
* 现在生成概率更高。

# = 世界生成 =
* *[主世界](主世界.md)**
* 玩家现在可以自定义世界名称。

* *[种子](种子（世界生成）.md)**
* 玩家现在可以自定义世界生成的种子。
* 现在可以创建超过5个世界。
* 更改了删除世界时的确认信息。

# = 游戏内容 =
* *[第三人称视角](第三人称视角.md)**
* 当玩家行走时，可以明显地看到视角在摆动（只有在启用视角摇晃时才能看到）。

# = 常规 =
* *[控制](控制.md)**
* 现在在按下和时切换其对应的模式。
* 当模式开启时，生物的头顶会显示它们独一无二的实体ID。
* 按下可以切换平滑移动视角模式。

* *[选项](选项.md)**
* 可以切换传统的光照和平滑的光照。
* 在地图选择界面加入了滚动条。
* 玩家现在在创建新世界的时候，可以选择世界名称。

* *[McRegion](区域文件格式.md)**
* 现在用内置的自动程序将世界区块转换为McRegion存储形式。

* *[纹理包](纹理包.md)**
* 在纹理包列表里添加了滚动条。

# 修复
* *修复了10个漏洞**
* 现在破坏双台阶（一个台阶放在另一个上面）时，会掉落2个台阶而不是1个。
* 木头不再不可燃尽。
* 修复了草地和沙地相关生物群系边界的问题（边界排成一行，而不是明显显示块状边界）。
* 关闭客户端程序时，不再会接收到与<code>minecraft.exe</code>处于同一文件夹中的Java错误日志<code>.txt</code>文件。
* 玩家不能再通过点击-松开的方式快速挖掘方块了（仅在多人游戏中称为“点击挖掘”）。
* 多人游戏中玩家站在栅栏上时不再出现相关漏洞。
* 玩家不再能从鱿鱼身上挤奶。
* 玩家手持弓或钓鱼竿对木门右键时，不再会射出箭矢以及放出鱼钩。
* 现在多人游戏中，敌对生物能被正常攻击。
* 现在在多人游戏中挖掘青金石矿会掉落4-8个青金石。</onlyinclude>
