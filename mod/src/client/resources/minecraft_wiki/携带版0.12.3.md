# 携带版0.12.3

*页面ID: 18910* | *来源: Minecraft Wiki*

* *v0.12.3 alpha**是的一次次要更新，在Android上发布于2015年10月22日，而在其他平台上发布于10月23日<ref>https://bugs.mojang.com/browse/MCPE/fixforversion/15393</ref>。此版本加入了新的万圣节装饰皮肤包，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[皮肤](皮肤.md)**
* 加入了[Halloween Costumes](皮肤包#万圣节装饰皮肤包（Halloween Costumes Skin pack）.md)。

# 更改
# = 常规 =
* *[多人游戏](多人游戏.md)**
* 局域网选项的描述从*Local Server Multiplayer*改为*Broadcast to LAN*。

# 修复

* *其他**
* 物品工具提示的显示位置不正确，且显示时间太短。
* 死亡界面下的控制器无法运作。
* iPhone 6 Plus中显示的Mojang徽标不居中。
* 无法将方块瞬间破坏。
* 快捷栏首个槽位的物品可以被复制。
* 控制器的工具提示（[X]）没有在物品栏内显示在快捷栏的上方。
* 玩家不能使用控制器上的触摸板在物品栏内选择物品。
