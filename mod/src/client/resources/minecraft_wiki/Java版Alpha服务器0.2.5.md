# Java版Alpha服务器0.2.5

*页面ID: 45540* | *来源: Minecraft Wiki*

* *0.2.5**是一个[Alpha](Java版Alpha.md)服务器版本，与[客户端1.2.3](Java版Alpha v1.2.3.md)在2010年11月23日一起发布。

# 添加
* 新的服务器配置选项
* * <code>pvp <true/false></code>（默认为<code>true</code>）。如果被设置为<code>false</code>，[玩家](玩家.md)无法直接攻击其他玩家（即用手或工具攻击或使用[弓](弓.md)射击别人；[熔岩](熔岩.md)等仍会伤害玩家）。
* * <code>spawn-monsters <true/false></code>（默认为<code>true</code>）。如果被设置为<code>false</code>，所有攻击型生物将被移除，无法再度[生成](生成.md)。
* * <code>spawn-animals <true/false></code>（默认为<code>true</code>）。如果被设置为<code>false</code>，所有被动性生物将被移除，无法再度生成。

# 更改
* 多人模式下，玩家和生物着[火](火.md)现在可以以着火的姿态被看见。
* 现在会正确给予摔落，溺水和燃烧的伤害。
* 食用[食物](食物.md)会恢复[生命](生命.md)。
* 玩家现在可以重生。

# 修复
* 修复了多人模式下一个方块重生的问题。
