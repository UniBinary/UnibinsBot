# 音乐唱片Creator

*页面ID: 156619* | *来源: Minecraft Wiki*

* *Creator**是一张[音乐唱片](音乐唱片.md)，可用于播放由[Lena Raine](Lena Raine.md)创作的同名曲目。

# 获取
# = 箱子战利品 =

# 用途
# = 音乐 =

[noicon](File:Creator.ogg.md)

Creator是一首类似于发条发声的音乐。

在音乐的中后部分有发条上条，以及打击乐、重金属的声音。

# = 红石 =

音乐唱片Creator放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为12的信号。
