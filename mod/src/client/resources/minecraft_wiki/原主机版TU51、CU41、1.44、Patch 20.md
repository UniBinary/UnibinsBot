# 原主机版TU51、CU41、1.44、Patch 20

*页面ID: 66389* | *来源: Minecraft Wiki*

* *TU51/CU41/1.44/Patch 20**是[原主机版](原主机版.md)的一次更新，发布于2017年3月27日，加入了Glide小游戏，并修复了一些漏洞。<ref></ref><ref></ref>

# 新内容
# = 常规 =
* *小游戏**
* 加入了Glide小游戏。
* 加入了新的小游戏大厅。
* [XBONE](Xbox One版.md)和[PS4](PS4.md)：添加了Glide的排行榜。
* [XBONE](Xbox One版.md)和[PS4](PS4.md)：Battle和Glide小游戏最多可以支持16个玩家。

# 修复

* *修复了7个漏洞**
