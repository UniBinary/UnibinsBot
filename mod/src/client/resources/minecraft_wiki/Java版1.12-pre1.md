# Java版1.12-pre1

*页面ID: 29908* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.12-pre1**是[Java版1.12](Java版1.12.md)的首个预发布版，发布于2017年5月10日<ref></ref>，加入了新的进度及进度触发器、1条新的游戏规则以及新的函数系统，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[进度](进度.md)**
* 加入了新的进度：
* * 狂乱的鸡尾酒 - 同时拥有所有可酿出的药水的[药水效果](状态效果.md)
* * 超越生死 - 利用[不死图腾](不死图腾.md)逃离死神
* * 四维碎块 - 利用[下界](下界.md)移动对应主世界7千米的距离
* * 脆弱的同盟 - 把一只恶魂从下界救出，将其安全带到主世界……然后干掉它。
* 加入了<code>hidden</code>，隐藏进度介绍的设置，默认为。
* 加入了新的<code>effects_changed</code>、<code>used_totem</code>、<code>nether_travel</code>的进度触发器。
* 加入了<code>function</code>作为进度的奖励。

* *[函数](Java版函数.md)**
* 加入了新的函数系统，这是一个位于的纯文档系统。
* 函数中可填写多条命令，每条命令一行，同时可以使用<code>//</code>或者<code>#</code>注释。

# = 游戏内容 =
* *游戏规则**
* 加入了新的<code>gameLoopFunction</code>游戏规则，用于设置每游戏刻触发的函数。

# = 命令 =
* 加入了新的命令。

# 更改
# = 方块 =
* *[绊线钩](绊线钩.md)**
* [TNT](TNT.md)上的绊线钩不再在收到[方块更新](方块更新.md)时掉落。

# = 常规 =
* *[进度](进度.md)**
* 进度树现在将在UI中居中显示。
* 进度中的物品和实体将拥有一个额外的NBT字段（有如命令中的NBT一样）。
* 进度中的实体将有额外的<code>effects</code>与<code>location</code>字段。
* 移除了进度中的<code>commands</code>奖励。
* 移除了<code>arbitrary_player_tick</code>触发器。

* *[配方书](配方书.md)**
* 优化了配方书。
