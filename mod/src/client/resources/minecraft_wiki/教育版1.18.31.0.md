# 教育版1.18.31.0

*页面ID: 97254* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.18.31.0**是[教育版1.18.32](教育版1.18.32.md)的第3个开发版本，发布于2022年7月14日<ref name=changelog3></ref>，启用了新的渲染引擎[RenderDragon](RenderDragon.md)，并对WebSocket做出了一些技术性更改。

# 新内容
# = 常规 =
* *[RenderDragon](RenderDragon.md)**
* 现在使用新的渲染引擎RenderDragon。

# 更改
# = 技术性 =
* *WebSocket**
* 将Websocket服务器和代码构建器发送的JSON格式更新为分层型JSON格式，以代替平面型格式。
* 移除了用途不大的属性，并将方块和物品ID移动至较新的基于名称的格式，以代替数值型格式。
* 将Websocket中基于智能体的命令移动至新的格式，现在所有命令都排列在其中，并包含关联响应的唯一ID。
* 现在Websocket和代码构建器API相关的重大更改都会使的值增加。</onlyinclude>
