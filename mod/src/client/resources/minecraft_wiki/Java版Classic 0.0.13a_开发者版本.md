# Java版Classic 0.0.13a/开发者版本

*页面ID: 83848* | *来源: Minecraft Wiki*

该条目记录了[Java版Classic 0.0.13a](Java版Classic 0.0.13a.md)的所有开发者版本。

# 0.0.13a（2009年5月21日）

该版本进行了一些更改。

此版本于启动器中可用，即启动器中的“c0.0.13a”。

# = 新内容 =
* *[控制](控制.md)**
* 现在按下键会打开暂停目录，包括回到游戏，新建世界和保存/读取世界的选项。其中最后一个选项没有实际功能。

* *[轮廓箱](轮廓箱.md)**
* 会显示在选择中的方块周围。

# = 更改 =
* *[树苗](树苗.md)**
* 更改了纹理。

* *[熔岩](熔岩.md)**
* 不再是透明的。
* 处于熔岩内部时所见的迷雾由橘黄色改为较浓的红色。

* *[控制](控制.md)**
* 按住不再导致玩家在不同位置之间循环重生，按住与单击的效果现在是相同的。

* *[平视显示器](平视显示器.md)**
* 现在在右上角会显示玩家正在手持的方块。

* *常规**
* 按住跳跃键无法再自动跳跃。
* 玩家的跳跃高度从1.5格降低到1格。
* 在水中游泳和下沉的速度加快。
* 现在在熔岩中游泳的速度慢于在水中的速度。
* 游戏分辨率现在是854×480，而不是640×480。
* 现在生成的世界完全平坦。当在暂停界面生成新世界时，该世界会形成长条形（512×64×32）的平坦世界。
* * 洞穴仍然会生成。

# 0.0.13a（2009年5月21日）

该版本测试了世界大小。

# = 更改 =
* *常规**
* 世界大小现在为1024×64×64而不是512×64×32，并重新加入了地形。<ref>Minecraft IRC logs，2009年5月21日
* "(10:48:56) Notch_: and I just tried making a 1024x64x64 map. It's nuts [...] (10:49:06) Notch_: it's basically a looong gauntlet of hills and lakes"</ref>
* 如果在世界生成时水和熔岩临近生成，石头就会生成。

# 0.0.13a（2009年5月21日）

该版本更改了世界加载屏幕，并测试了大型世界。<ref></ref>

# = 更改 =
* *[世界加载屏幕](世界加载屏幕.md)**
* 更改了世界生成界面，现在泥土背景更昏暗了，并在进度文本下方添加了进度条。

* *常规**
* 测试了[大型世界](Indev世界选项#世界大小.md)。
* 世界大小现在为512×64×512。
* 泥土层现在更均匀了。
