# Java版1.20-pre1

*页面ID: 104220* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.20-pre1**是[Java版1.20](Java版1.20.md)的首个预发布版，发布于2023年5月10日<ref></ref>，同步了一些的特性，加入了新的伤害类型，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[伤害类型](伤害类型.md)**
* 加入了2种新伤害类型。
* *
* ** [玩家](玩家.md)位于[世界边界](世界边界.md)外死亡时使用，替代了之前使用的，边界外死亡的[死亡消息](死亡消息.md)也因此更改。
* *
* ** 使用命令强制清除[实体](实体.md)时使用，替代了之前使用的，命令显示的死亡消息也因此更改。

# 更改
# = 方块 =
* *[床](床.md)、[地毯](地毯.md)和[羊毛](羊毛.md)**
* 现在所有颜色的单个方块物品均可以通过与单个[染料](染料.md)合成而染成其他颜色的单个方块物品，以同步。
* 地毯不再能通过8个白色地毯围绕单个染料的方式染色。

# = 命令格式 =
* ***
* 数据源的参数现在可以以负数表示从字符串末尾起计的位置。

# = 常规 =
* *[战利品表](战利品表.md)**
* 战利品表的随机序列现在是确定性的。
* * 随机序列现在基于世界种子和序列ID而产生，如两者一致，生成的随机序列也一致。
* * 用于战利品表的随机序列ID现在可通过新的字段指定。

* ***
* 文件更改为编码存储。
* 读取文件默认以UTF-8编码读取，若失败则按以前使用的编码（ISO 8859-1/Latin 1）读取。

* *[标签](Java版标签.md)**
* 从方块标签中移除了。
* 向伤害类型标签中加入了。
* 向伤害类型标签中加入了。
