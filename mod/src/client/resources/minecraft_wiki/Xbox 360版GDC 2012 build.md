# Xbox 360版GDC 2012 build

*页面ID: 97390* | *来源: Minecraft Wiki*

* *GDC build**是的一个开发者版本，曾在2012年的游戏开发者大会<ref>https://youtu.be/8lDVYWeUDJQ</ref><ref>https://youtu.be/3e7u9MnzrfU</ref>上展示过。这个版本是基于[Java版Beta 1.6.6](Java版Beta 1.6.6.md)制作的。

# 新内容
* 更改了主菜单上的Minecraft徽标。
* 更新了带有提示的加载页面。
* 主菜单上的全景背景现在无限循环了。
* 新的世界选择菜单。
* 更新了多人分屏游玩模式。
* 增加了更多音乐。
* 提升了音质。
* 修复了非常多的漏洞。
* 更改了合成菜单和工具提示。
* 优化了性能。
* 许多其他变化。
