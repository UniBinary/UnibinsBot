* *13w41b**是[Java版1.7.2](Java版1.7.2.md)的第11个快照，发布于2013年10月11日<ref></ref>，以修复[13w41a](13w41a.md)里的漏洞和崩溃。

# 修复
键补全的参数。
|;previous
|34641|暂停游戏功能失效。
|34642|白色染色玻璃板的英文“White Stained Glass Pane Pane”中有错别字。
|34679|使用染色玻璃只能合成6个对应颜色的染色玻璃板而不是16个。
|34705|登录服务器时会空指针异常。

|34650|某些实体的碰撞会使游戏崩溃：<code>java.lang.NullPointerException</code>。

# 重新上传
* 13w41b于2013年10月11日晚些时候重新上传以修复一个有关服务器图标的漏洞。<ref></ref></onlyinclude>

# 你知道吗
* 此版本与[13w41a](13w41a.md)的协议版本相同，但不相互兼容。
* 此版本曾经在[启动器](启动器.md)中移除，但在2018年9月重新加入。
* 该版本的宣传截图中出现了[Grum](Grum.md)的Minecraft皮肤。
