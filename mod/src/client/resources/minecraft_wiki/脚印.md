# 脚印

*页面ID: 139337* | *来源: Minecraft Wiki*

* *脚印（Footprint）**是一种仅能在“missing”维度的[箱子](箱子.md)中找到的物品。

# 获取

“missing”维度中的箱子中会生成2个脚印。

# 用途
脚印没有实际用途。
