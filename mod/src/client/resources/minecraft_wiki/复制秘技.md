# 复制秘技

*页面ID: 139309* | *来源: Minecraft Wiki*

* *minecraft:dupe_hack**，下文称**复制秘技（Dupe Hack）**，是用于复制任意物品的物品。

# 获取
当玩家击杀带有容器的实体（例如[漏斗矿车](漏斗矿车.md)、带有箱子的[羊驼](羊驼.md)）时，复制秘技会按照规则指定的概率掉落，默认为0。

复制秘技无法在[创造模式物品栏](创造模式物品栏.md)中获取，但可通过[命令](命令.md)获取。

# 用途
# = 合成材料 =
复制秘技可用于在[工作台](工作台.md)中复制少量物品。

如果被复制的物品堆叠上限为1，复制出的物品会超出其堆叠上限。

复制秘技可以复制自身。以从上到下、从左到右为顺序，位于合成格中较为靠后的复制秘技会被复制。
中指定的概率（默认为30%）损毁而消失。
