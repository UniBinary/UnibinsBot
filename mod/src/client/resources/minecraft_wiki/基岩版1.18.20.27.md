# 基岩版1.18.20.27

*页面ID: 93083* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.20.27**（Xbox/Windows/Android）、**Preview 1.18.20.28**（iOS/iPadOS/Xbox/Windows）是[基岩版1.18.30](基岩版1.18.30.md)的第4个测试版，发布于2022年2月17日<ref></ref>，修改了生物的[伤害](伤害.md)机制，并修复了一些漏洞。

# 更改
# = 物品 =
* *[船](船.md)**
* 现在云杉木船和深色橡木船的新物品纹理会在游戏中显示。<ref></ref>

# = 生物 =
* *[牛](牛.md)、[猪](猪.md)、[鸡](鸡.md)和[绵羊](绵羊.md)**
* 不再生成于[积雪针叶林](积雪针叶林.md)。

* *[疣猪兽](疣猪兽.md)**
* 幼年疣猪兽不再攻击玩家。

* *[岩浆怪](岩浆怪.md)**
* 小型岩浆怪在简单和普通难度下的攻击力由更改为。

* *[骷髅](骷髅.md)**
* 简单和普通难度下的近战攻击伤害由更改为。

* *[蜘蛛](蜘蛛.md)**
* 简单难度下的攻击力由更改为。

* *[狼](狼.md)**
* 未驯服的狼在普通难度下的攻击力由更改为。

* *[僵尸疣猪兽](僵尸疣猪兽.md)**
* 幼年僵尸疣猪兽在简单和普通难度下的攻击力由更改为。

* *常规**
* 现在生物对玩家的攻击伤害会受到游戏[难度](难度.md)机制的影响。

# = 游戏内容 =

# 修复
* *游戏内容**
* 修复了物品或方块名称包含“.”时无法识别活动对象的定义标识符的问题。
* 提高了伤害计算的准确性，游戏现在会正确计算和积累伤害，以造成更多的伤害。
* 现在生物造成的伤害会根据不同高低的游戏难度而调整。
* 提高了盔甲和保护的防御计算的准确性。
* 现在龙息攻击会正确造成伤害。（）
* 现在玩家在熔岩中退出游戏后，重新进入世界时的出生位置会保持不变。（）
* 玩家现在可以不断地在梯子和藤蔓等可攀爬方块上向下飞行。（）
* 修复了盾牌防御动画在防御一次攻击后会停止流畅播放动画的漏洞。（）

* *图形**
* 修复了纹理文件名拼写不正确，且该纹理不会在游戏中显示的漏洞。（）

* *生物**
* 使用精准采集附魔工具破坏蜂巢时蜜蜂不再会被激怒。（）
* 现在烈焰人火球、唤魔者尖牙和潜影贝子弹在所有难度下均造成相同的伤害。
* 略微提高了小型岩浆怪造成的伤害，由简单和普通难度下的更改为。
* 略微降低了蜘蛛造成的伤害，由简单难度下的更改为。（）
* 略微降低了幼年僵尸疣猪兽造成的伤害，由简单和普通难度下的更改为。
* 略微降低了骷髅近战攻击造成的伤害，由简单和普通难度下的更改为。
* 略微提高了狼造成的伤害，由普通难度下的更改为。
* 幼年疣猪兽不再攻击玩家。
* 牛、猪、鸡和绵羊不再会生成于积雪针叶林生物群系。

* *用户界面**
* 玩家的触摸移出触控按钮的范围时，该按钮不再会卡在按下状态。（）
* 修复了部分Android设备上使用新UI时，其上的文本会显示不正确的问题。（）
* 修复了使用控制器游玩并将鼠标悬停在合成界面的搜索栏中时可能发生的崩溃。

* *市场**
* 现在Minecoin购买界面中会出现其他平台上购买的“新手硬币同捆包”。
* 点击“查看更多”时游戏不再会停止响应或崩溃。
* 现在市场标签会适应描述段落。
* 下载弹窗在被关闭时不再会闪烁。
* 客户端现在支持市场界面中的多个玩家计算标签。
* 加入了在已装备角色创建器饰品的情况下在市场界面中装备皮肤包的皮肤时出现的弹窗警告。

* *角色创建器**
* 修复了部分表情在动画将近结束时会被意外旋转的问题。（）

* *技术性**
* 修复了在0.0时动画时间线事件有时不会在循环动画中运行的漏洞。
* 修复了命令方块在“Extreme Speed Runner”市场地图中无法正常生成生物的问题。
* 现在武器被生物使用时会正确应用武器事件。（）</onlyinclude>
