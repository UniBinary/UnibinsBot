# 树脂团

*页面ID: 128012* | *来源: Minecraft Wiki*

* *树脂团（Resin Clump）**是一种来源于[嘎枝之心](嘎枝之心.md)的[方块](方块.md)。它主要用于制作[树脂块](树脂块.md)与[树脂砖](树脂砖.md)，进而合成出整个树脂系列方块。

# 生成
树脂团不会生成在世界中。

# = 人为生成 =

当绑定了嘎枝之心的[嘎枝](嘎枝.md)被攻击时，与其绑定的[嘎枝之心](嘎枝之心.md)周围的、苍白橡木原木、去皮苍白橡木和去皮苍白橡木原木上会生成树脂团。

# 获取
# = 合成 =

# = 嘎枝之心 =
没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，嘎枝之心被破坏后会掉落个树脂团。使用附有[时运](时运.md)魔咒的工具破坏会额外等概率掉落个树脂团。

# = 箱子战利品 =
树脂团可以在林地府邸的箱子中找到。

# 破坏
树脂团被挖掘时会立刻被破坏。

树脂团被破坏后会掉落自身。

# 用途
# = 放置 =
在一个方块大小的空间内可以放置多个树脂团，例如角落处的三个面。当其中一个树脂团被破坏时，同一个方块空间内的其他树脂团也会被破坏。

当树脂团所附着的方块被破坏时，树脂团所附着的面也会被破坏，但如果树脂团没有被完全破坏则不会掉落树脂团物品<ref></ref>。

树脂团可以[含水](含水.md)。
