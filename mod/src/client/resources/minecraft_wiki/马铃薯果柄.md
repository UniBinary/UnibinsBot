* *马铃薯果柄（Potato Pedicule）**是一种类似于[锁链](锁链.md)的方块。

# 生成
# = 自然生成 =
马铃薯果柄会与[马铃薯果实](马铃薯果实.md)一同作为[马铃薯树](马铃薯树.md)的一部分生成，也会在[马铃薯废弃矿井](马铃薯废弃矿井.md)和[马铃薯村庄](马铃薯村庄.md)中生成。

# 破坏
没有工具可以加速对马铃薯果柄的挖掘。

马铃薯果柄被破坏后会掉落自身。

# 用途

马铃薯果柄可用于类似于锁链的装饰性用途。与锁链不同的是，其不能被[活塞](活塞.md)推拉，也不能用于[合成](合成.md)。

# = 堆肥 =
马铃薯果柄可以用于堆肥，对[堆肥桶](堆肥桶.md)有30%的概率使堆肥桶层数增加1层。
