# Java版Beta 1.0

*页面ID: 32572* | *来源: Minecraft Wiki*

<onlyinclude>
* *Beta 1.0**是[Beta](Java版Beta.md)开发阶段的首个正式版，也是的一次主要更新，发布于2010年12月20日。

# 新内容
# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 使用服务器端物品栏。
* 背包中的物品提示。
* * [玩家](玩家.md)将光标停留在物品上时会出现对应的名称。

# = 常规 =
* *[皮肤](皮肤.md)**
* 为Mojang职员加入了[披风](披风.md)。
* 加入了deadmau5皮肤，只供玩家deadmau5使用。

* *[闪烁标语](闪烁标语.md)**
* 加入了新的闪烁标语：
* * Finally Beta!
* * Woo, reddit!
* * Twittered about!
* * Jump up, jump up, and get down!
* * Joel is neat!
* * A riddle, wrapped in a mystery!
* * Huge tracts of land!
* * Welcome to your Doom!
* * Stay a while, stay forever!
* * Stay a while and listen!
* * Treatment for your rash!
* * "Noun" is an autonym!
* * Information wants to be free!
* * "Almost never" is an interesting concept!

# 更改
# = 方块 =
* *[箱子](箱子.md)**
* 当玩家离箱子过远或箱子被摧毁时，将会关闭物品栏。

* *[树叶](树叶.md)**
* 再次加入了树叶枯萎机制，与之前的有所不同。

# = 物品 =
* *[鸡蛋](鸡蛋.md)**
* 现在可以被掷出了。
* * 掷出鸡蛋有概率生成一只幼年鸡。

# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 玩家不再能用物品栏中的合成方格存储物品。
* * 在关闭物品栏界面的同时，合成方格会立即被清空。

# = 常规 =
* *[多人游戏](多人游戏.md)**
* 在大多数情况下减少服务器保存区块的频率。
* * 当一个区块在30秒内被保存过，它们将不会被再次保存。

# 修复
* *修复了3个漏洞**
* 作为服务器侧物品栏工作的成果，许多问题都被修复了。
* 修复了命令。
* 掉落在地上的工具不再自动修复。</onlyinclude>
