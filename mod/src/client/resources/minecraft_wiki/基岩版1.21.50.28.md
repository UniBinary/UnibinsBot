# 基岩版1.21.50.28

*页面ID: 128526* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.50.28**（ChromeOS/Android）、**Preview 1.21.50.28**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.50](基岩版1.21.50.md)的第6个测试版，发布于2024年11月7日<ref></ref>，调整了一些特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[红砖块](红砖块.md)及其变种、[下界砖块](下界砖块.md)及其变种、[红色下界砖块](红色下界砖块.md)和[树脂砖块](树脂砖块.md)及其变种**
* 更改了纹理，以与其他砖类方块的砖纹水平对齐。
* * 由于漏洞，下界砖块及其变种和红色下界砖块不会使用新纹理。<ref></ref>

* *[嘎枝之心](嘎枝之心.md)**
* 现在使用带有[时运](时运.md)魔咒的工具破坏时会增加[树脂团](树脂团.md)的掉落数量。

* *[红树树叶](红树树叶.md)**
* 更改了流畅画质下的纹理，以使用单独的不透明纹理。

* *[幽匿感测体](幽匿感测体.md)和[校频幽匿感测体](校频幽匿感测体.md)**
* 现在能检测[眼眸花](眼眸花.md)张开和闭合的动作。

# = 物品 =
* *[树脂砖](树脂砖.md)**
* 现在取代树脂团成为盔甲纹饰材料。

* *[谜之炖菜](谜之炖菜.md)**
* 现在食用由[张开的眼眸花](张开的眼眸花.md)合成的谜之炖菜后给予的[失明](失明.md)效果的持续时间为，而非，以与由[蓝花美耳草](蓝花美耳草.md)合成的谜之炖菜保持一致。
* 现在食用由[闭合的眼眸花](闭合的眼眸花.md)合成的谜之炖菜后给予的[反胃](反胃.md)效果的持续时间为，而非。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 接触眼眸花时不再会获得[中毒](中毒.md)效果。<ref></ref>
* 现在能被喂食张开的眼眸花，被喂食时会获得中毒效果。
* 现在会被张开的眼眸花吸引。
* 不再会尝试采集[闭合的眼眸花](闭合的眼眸花.md)的花粉。
* 现在被喂食[凋灵玫瑰](凋灵玫瑰.md)时会获得[凋零](凋零.md)效果，而非繁殖或加速生长。
* 被一击杀死时不再会激怒附近的同类生物。

* *[岩浆怪](岩浆怪.md)**
* 更新了UV映射。

* *[劫掠兽](劫掠兽.md)**
* 现在能够摧毁[樱花树叶](樱花树叶.md)和[苍白橡树树叶](苍白橡树树叶.md)。

* *[狼](狼.md)、[蠹虫](蠹虫.md)和[僵尸猪灵](僵尸猪灵.md)**
* 被一击杀死时不再会激怒附近的同类生物。

# 修复
* *苍白之园**
* 现在苍白之园生物群系中的地平线上的天空会在下雨时变得更暗。（）

* *方块**
* 由刷怪蛋设置生物的试炼刷怪笼不再会在其冷却时间结束后恢复至初始状态。（）
* 远处的杜鹃花丛、盛开的杜鹃花丛、红树树叶、樱花树叶、苍白橡树树叶不再会显示黑色像素。（）
* 红树树叶现在拥有“花俏的树叶”被禁用时的专用纹理。（）
* 苍白橡树树叶纹理的方向不再是随机的。
* 苔藓块现在拥有更小声的在其上行走和在其上着陆的音效。（）
* 饰纹陶罐不再会在世界加载时触发侦测器。
* 修复了打开版本锁定在1.21.40以下的世界模板时，所有种类的头颅会转变为骷髅头颅的问题。
* * 此修复不会影响已覆盖的区块。
* 更新了红砖块、下界砖块、红色下界砖块、树脂砖块和相关方块的纹理，以与其他砖类方块水平对齐。（）
* 现在由张开的眼眸花施加的中毒效果也会在蜜蜂处于方块内部时对其造成伤害，而不只是在离开方块内部时对其造成伤害。
* 铜格栅覆盖如静止的水和静止的熔岩等液体时，液体不再会不正确地镶嵌。（）
* 现在使用时运工具破坏嘎枝之心时会掉落更多的树脂团。（）
* 现在即使处于含雪状态，眼眸花也会张开和闭合。（）
* 现在苍白覆地苔藓的侧面会正确着色。（）
* 现在挖掘苍白覆地苔藓时侧面会使用正确的裂纹。（）

* *游戏内容**
* 修复了客户端与服务端的降雨或降雪天气状态有时会不匹配的问题。（）

* *物品**
* 除了教育版，小黑板不再会存在于创造模式物品栏。（）
* 现在由张开的眼眸花合成的谜之炖菜会给予与由蓝花美耳草合成的谜之炖菜相同持续时间的失明效果。（）

* *生物**
* 玩家在远处观察嘎枝时，嘎枝不再会偶尔穿过方块。
* 劫掠兽现在能够摧毁所有类型的树叶，而不是有限选择的树叶。（）
* 岩浆怪模型部分的UV不再会相互重叠。

* *Realms**
* 修复了在部分平台的管理成员屏幕上邀请玩家后返回Realms故事时发生的崩溃。

* *音效**
* 为嘎枝之心、树脂砖块和树脂块加入了在其上跳跃和在其上着陆的声音事件。（、）

* *用户界面**
* 现在收纳袋提示框中的物品具有灰色背景。
* 触摸控制：修复了离开船后相机视角有时会卡住的漏洞。（）
* 现在用光标放下收纳袋后会正确显示收纳袋提示框。
* 现在光标带着收纳袋悬停在合成屏幕和工作台屏幕的合成输出上时的游戏手柄提示是正确的。

* *原版趋同**
* 一击杀死狼、蜜蜂或蠹虫时不再会激怒附近的同类生物。
* 一击杀死僵尸猪灵时不再会激怒附近的僵尸猪灵。（）
* 现在即使下方没有方块支撑，头颅也可以放置在方块的侧面。

* *武器**
* 生物在攻击过程中使用损坏的物品进行攻击时，游戏不再会崩溃。</onlyinclude>
