* *1.17.1**是的一次次要更新，发布于2021年7月6日<ref></ref>，加入了文言文和新的死亡消息，调整了部分游戏机制，并修复了一些漏洞。此版本不兼容1.17的服务端。

# 新内容
# = 常规 =
* *[语言](语言.md)**
* 加入了文言文。<!-- 在“语言”页面外不应记载某语言在游戏内显示的语言名称原文 -->

* *[死亡消息](死亡消息.md)**
* 为一些水生生物添加了2条死亡消息<ref></ref>：
* *
* *

# 更改
# = 方块 =
* *[炼药锅](炼药锅.md)**
* 将降雪时填充[细雪](细雪.md)的速度提高为原来的2倍。

# = 物品 =
* *[望远镜](望远镜.md)**
* 调整了手持模型的纹理。
* * 现在其后侧会显示紫水晶镜片的纹理，而不是之前的铜质纹理。

# = 生物 =
* *[美西螈](美西螈.md)**
* 蓝色美西螈现在只能通过繁殖生成。

* *[溺尸](溺尸.md)**
* 将[铜锭](铜锭.md)的掉落概率由5%提升至11%，每级[抢夺](抢夺.md)魔咒提高的掉落概率由1%提升至2%，以同步。

* *[山羊](山羊.md)**
* 现在繁殖普通山羊有2%的概率产下尖叫山羊。
* 山羊身上的[状态效果](状态效果.md)现在也会在其跳跃和冲撞时生效。

* *[僵尸](僵尸.md)、[僵尸村民](僵尸村民.md)、[尸壳](尸壳.md)和[溺尸](溺尸.md)**
* 不再捡起[荧光墨囊](荧光墨囊.md)。

# = 常规 =
* *协议**
* 服务器地址为SRV记录时，握手包中“地址”和“端口”字段的填充方法被回退到了1.17前的方式。
* * 现在，SRV记录实际指向的服务器地址和端口会被填充到这两个字段中，而不是把“服务器地址”所填内容和25565分别填入这两个字段中。

* *[字体](字体.md)**
* 加入了一些新字符，包含一些货币符号和一些新表情。
* * 新字符包括：<span style="word-break:break-all;">✂🍖🪣🔔⏳⚑₠₡₢₣₤₥₦₩₫₭₮₰₱₲₳₵₶₷₸₹₺₻₼₿</span>。

* *语言**
* 移除了马恩岛语、西西里语和士瓦本德语，因为这些语言的翻译尚未完善。

* *日志**
* 现在当被命名过的生物死亡时，其死亡消息会被记录到日志中。
