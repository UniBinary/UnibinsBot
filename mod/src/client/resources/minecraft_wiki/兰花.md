# 兰花

*页面ID: 21027* | *来源: Minecraft Wiki*

* *兰花（Blue Orchid）**是一种[小型花](小型花.md)。

# 生成

# = 自然生成 =
兰花会在[沼泽](沼泽.md)生物群系自然生成。

兰花也会在[林地府邸](林地府邸.md)中生成。

# = 骨粉 =
在[沼泽](沼泽.md)生物群系中对[草方块](草方块.md)[骨粉](骨粉.md)后，兰花有概率代替[矮草丛](矮草丛.md)生成。

对着不[含雪](含雪.md)的兰花使用骨粉会出现更多的兰花，而不会出现草丛。

# 破坏
兰花被挖掘时会立刻被破坏。

兰花被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 谜之炖菜 =

使用兰花合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家/的[饱和](饱和.md)效果。

# = 堆肥 =
将兰花放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
