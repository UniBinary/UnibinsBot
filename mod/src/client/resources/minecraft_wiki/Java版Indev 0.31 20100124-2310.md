# Java版Indev 0.31 20100124-2310

*页面ID: 35329* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2010年1月24日23:10（UTC），更改了弓和TNT的机制。<ref name="Forum"></ref>

# 新内容
# = 常规 =
* *[粒子](粒子.md)**
* 为挖掘[方块](方块.md)加入了粒子效果。

# 更改
# = 物品 =
* *[弓](弓.md)**
* 在射击时会消耗[箭](箭.md)。
* 将箭射入[水](水.md)中会产生气泡粒子。

# = 非生物实体 =
* *常规**
* [物品](物品.md)现在会被[火](火.md)和[熔岩](熔岩.md)摧毁。

# = 游戏内容 =
* *常规**
* [玩家](玩家.md)现在只能一次丢弃一个物品，而不是一组。

# = 世界生成 =
* *[Indev房子](Indev房子.md)**
* Indev房子中加入了一个装满TNT的箱子。<ref name="Forum"/>

* *常规**
* 所有基岩层正上方的空气变为熔岩。

# = 方块 =
* *[火把](火把.md)**
* 减小了火把的碰撞箱。
* 添加了顶部纹理。

* *[TNT](TNT.md)**
* 穿过更坚固的材料时，爆炸的力量会被削弱。
* 现在会产生烟雾粒子。<ref></ref>
* 现在会造成更多伤害。<ref></ref>

* *[箱子](箱子.md)**
* 不再能制作三重箱子了。<ref></ref></onlyinclude>
