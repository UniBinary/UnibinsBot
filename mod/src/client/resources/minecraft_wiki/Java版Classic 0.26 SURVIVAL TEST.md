# Java版Classic 0.26 SURVIVAL TEST

*页面ID: 35600* | *来源: Minecraft Wiki*

/开发者版本}}
<onlyinclude>

* *0.26 SURVIVAL TEST**是[Java版Classic](Java版Classic.md)的一次更新，发布于2009年10月24日<ref></ref>，加入了[蜘蛛](蜘蛛.md)和一些新的方块。

# 新内容
# = 方块 =
* *[石台阶](石台阶.md)<ref></ref>**
* 一种装饰性方块。
* 不会自然生成在世界中。

* *[铁块](铁块.md)**
* 一种装饰性方块。
* 不会自然生成在世界中。

* *[苔石](苔石.md)**
* 一种装饰性方块。
* 不会自然生成在世界中。

* *[TNT](TNT.md)**
* 世界生成时给予玩家10个。
* 其他爆炸不会点燃TNT，而是会像其他方块一样被摧毁。

* *[红砖块](红砖块.md)**
* 一种装饰性方块。
* 不会自然生成在世界中。
* 无法通过常规手段获得。

* *[书架](书架.md)**
* 一种装饰性方块。
* 不会自然生成在世界中。
* 无法通过常规手段获得。
* 被破坏时不掉落任何物品。

# = 生物 =
* *[蜘蛛](蜘蛛.md)**
* 一种敌对生物，通过近战攻击[玩家](玩家.md)。
* 会自然生成在世界中。
* 死后掉落0~2个棕色[蘑菇](蘑菇.md)。
* 死亡时给予[玩家](玩家.md)10点分数。

# = 游戏内容 =
* *[降雨](天气.md)<ref></ref>**
* 按触发。

# = 常规 =
* *[选项](选项.md)**
* 帧率限制。

* ***
* 加入了[蜘蛛网](蜘蛛网.md)的纹理。

# 更改
# = 方块 =
* *[石头](石头.md)**
* 现在被破坏后掉落[圆石](圆石.md)。

* *[煤矿石](煤矿石.md)**
* 被破坏后会掉落1–3个[石台阶](石台阶.md)。

* *[金矿石](金矿石.md)**
* 更改了纹理。

* *[金块](金块.md)**
* 更改了纹理。
* 可以通过挖掘[金矿石](金矿石.md)获得。

* *[铁矿石](铁矿石.md)**
* 被破坏后掉落1-3个[铁块](铁块.md)。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 更改了纹理。
* 现在在死亡时出现爆炸[粒子](粒子.md)。
* 现在只能破坏泥质方块。

# = 游戏内容 =
* *[碰撞箱](碰撞箱.md)**
* 缩小了所有植物的碰撞箱。

* *[菜单屏幕](菜单屏幕.md)**
* 取消了背景的渐变色。
* * 这意味着死亡界面不再是红色，菜单屏幕不再是灰色。

* *[光照](光照.md)**
* 水面上的方块不再在其表面产生阴影。

* *常规**
* 玩家现在可以更快的造成伤害。

# = 常规 =
* *[控制](控制.md)**
* 按键不再会放置[告示牌](告示牌.md)。</onlyinclude>

# 你知道吗
* 很多人都误以为该版本中的蜘蛛为棕色。<ref></ref><ref></ref>然而，[Omniarchive](https://discord.com/invite/h45wxnE)社区于2020年4月8日细致科学地分析了现有证据，几乎可以确认此版本公开发布时的蜘蛛为黑色。<ref>[:en:Special:diff/1546659](:en:Special:diff/1546659.md) – 2020年4月9日 13:54 UTC</ref>
