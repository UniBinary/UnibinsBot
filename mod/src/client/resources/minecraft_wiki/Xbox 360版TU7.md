*页面ID: 98216* | *来源: Minecraft Wiki*

# = 常规 =

* 包含新生物群系的新教程世界。
* * 为新特性设计的新教程。

* 为下载内容菜单添加了头像物品。

# 更改
# = 方块 =
* 栅栏现在会与邻近的方块连接。

# = 物品 =
* [末影珍珠](末影珍珠.md)现在可以在生存及创造模式中用来投掷以传送（落地时会造成伤害）。

# = 生物 =
* 除非被攻击，否则敌对生物不会追赶创造模式的玩家。

# = 常规 =
* [皮肤包](皮肤包.md)的[皮肤](皮肤.md)动画
* * 禁用皮肤动画的选项。
