# 槽位

*页面ID: 122291* | *来源: Minecraft Wiki*

* *槽位（Slot）**是[方块实体](方块实体.md)或[实体](实体.md)的数据中能储存单个物品堆叠的位置。

# Java版
游戏使用**槽位索引**确定一个槽位。

# = 命令参数 =
在命令中槽位使用字符串名称指定，而不是直接指定其索引。当命令执行时，字符串名称会被映射到槽位索引。

槽位的字符串名称包含**槽位类型**和可选的**槽位编号**两部分，格式为<code>-{}-<槽位类型></code>或<code>-{}-<槽位类型>.<槽位编号></code>.

还支持带有通配符的槽位名称：
* <code>container.*</code>：包含<code>container.0</code>到<code>container.53</code>。
* <code>hotbar.*</code>：包含<code>hotbar.0</code>到<code>hotbar.8</code>。
* <code>inventory.*</code>：包含<code>inventory.0</code>到<code>inventory.26</code>。
* <code>enderchest.*</code>：包含<code>enderchest.0</code>到<code>enderchest.26</code>。
* <code>villager.*</code>：包含<code>villager.0</code>到<code>villager.7</code>。
* <code>piglin.*</code>：包含<code>piglin.0</code>到<code>piglin.7</code>。
* <code>horse.*</code>：包含<code>horse.0</code>到<code>horse.14</code>。
* <code>weapon.*</code>：包含。
* <code>armor.*</code>：包含。
* <code>player.crafting.*</code>：包含<code>player.crafting.0</code>到<code>player.crafting.3</code>。

# = 装备槽位 =
装备槽位在实体数据、实体谓词和与生物装备相关的物品堆叠组件（如）等中使用。所有生物都具有这些槽位，但不一定全部使用这些槽位。

通常情况下，装备槽位被所有人-{}-形生物使用；装备槽位被用于动物盔甲，包括狼的狼铠、羊驼的地毯、马的马铠和快乐恶魂的挽具；装备槽位被用于马类生物、骆驼、猪和炽足兽的鞍。

# = 命令参数 =
命令中槽位使用**槽位类型**和**槽位编号**两个参数指定。

对于一个方块实体，其槽位的槽位类型是<code>slot.container</code>。
* [箱子](箱子.md)、[发射器](发射器.md)、[投掷器](投掷器.md)、[漏斗](漏斗.md)、[陷阱箱](陷阱箱.md)、[木桶](木桶.md)、[潜影盒](潜影盒.md)左上角的槽位编号为0，先向右逐槽位增加1，再从下一行开头继续计数。（例如，箱子第二行从左到右的槽位编号是9到17)。大箱子里的物品实际上储存在两个单独的方块实体中。
* [酿造台](酿造台.md)下方的三个槽位从左到右编号依次为0到2，顶部的原料槽位编号为3，燃料槽位为4。
* [熔炉](熔炉.md)的原料槽位的编号为0，燃料槽位为1，输出槽位为2。
