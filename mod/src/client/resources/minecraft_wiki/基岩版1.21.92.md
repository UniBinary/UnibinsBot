# 基岩版1.21.92

*页面ID: 154893* | *来源: Minecraft Wiki*

* *1.21.92**是的一次热修复更新，在ChromeOS/Android、iOS/iPadOS、PlayStation和Windows平台上发布于2025年6月19日<ref></ref>，在Fire和Xbox平台上发布于2025年6月20日，在Nintendo Switch平台上发布于2025年6月24日，修复了一些漏洞。此版本与[1.21.90](基岩版1.21.90.md)和[1.21.91](基岩版1.21.91.md)相互兼容。

# 更改
# = 技术性 =
* *物品**
* 现在宽度或高度小于16像素的物品再次会正确渲染。

* *图形**
* 现在纹理包中的自定义天空盒会在非设置下渲染。（）

* *生物**
* 修复了一个问题，以恢复允许实体定义文件中的空值组件正确解析和加载的原始行为。

# 修复
* *游戏内容**
* 修复了Xbox平台上的分屏玩家会一直显示为访客的问题。（）
* 修复了玩家尝试添加分屏玩家时会与多人游戏世界断开连接的问题。

* *弹射物**
* 弹射物的目标差幅现在会根据世界中的活动总时长而递增。（）
* * 此前，弹射物的目标差幅会在每一飞行刻增大一次。
* * 现在，弹射物的目标差幅会在每一活动刻增大一次，无论弹射物的飞行状态如何。
