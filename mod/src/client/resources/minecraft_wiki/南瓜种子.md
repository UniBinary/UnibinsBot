# 南瓜种子

*页面ID: 7395* | *来源: Minecraft Wiki*

* *南瓜种子（Pumpkin Seeds）**是一种用来种植[南瓜](南瓜.md)的[物品](物品.md)。

* *南瓜茎（Pumpkin Stem）**是南瓜种子种植在[耕地](耕地.md)上形成的方块，成熟后可在相邻且合适的空方块处生成南瓜。

# 生成
# = 自然生成 =
南瓜茎会以30%概率自然生成在[针叶林](针叶林.md)类型的[村庄](村庄.md)里[农田](农田.md)结构的[耕地](耕地.md)上。

此外，[林地府邸](林地府邸.md)的[瓜房](林地府邸/结构/农场#瓜房.md)中会固定地生成16个南瓜茎。

# 破坏
南瓜茎被挖掘时会立刻被破坏。

南瓜茎被破坏后会掉落0–3个南瓜种子，每个值的掉落概率取决于南瓜茎的生长阶段。

# 用途
# = 种植 =
西瓜和南瓜种植}}

对[耕地](耕地.md)的顶面南瓜种子可种植出南瓜茎。[亮度](亮度.md)等级≥9时，南瓜茎才能生长到下一个阶段。

南瓜茎会经历8个生长阶段，成熟后会尝试在相邻的空方块生成[南瓜](南瓜.md)，要求该方块下方是[泥土](泥土.md)、[草方块](草方块.md)、[耕地](耕地.md)、[砂土](砂土.md)、[灰化土](灰化土.md)、[菌丝体](菌丝体.md)、[缠根泥土](缠根泥土.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[泥巴](泥巴.md)或[沾泥的红树根](沾泥的红树根.md)。如果相邻的方块已经有了一个南瓜，该南瓜茎只会在原有的南瓜被移除后结出新的南瓜。

南瓜茎在湿润的耕地上生长得更快。对南瓜茎[骨粉](骨粉.md)会使其增加2-5个生长阶段，忽视亮度等级。已有巢且采集了花粉的[蜜蜂](蜜蜂.md)飞过南瓜茎时，南瓜茎也有概率增加1个生长阶段。上述方式催熟南瓜茎并不会使之直接生长出南瓜。

# = 繁殖 =
与其他种子相同，南瓜种子可用于吸引及繁殖[鸡](鸡.md)，也可喂食给幼年鸡以减少其10%的剩余成长时间。

# = 驯服 =
与其他种子相同，南瓜种子可用于驯服[鹦鹉](鹦鹉.md)。

# = 堆肥 =
将南瓜种子放入[堆肥桶](堆肥桶.md)中有30%的概率增加一层堆肥层。

# 南瓜茎
* *南瓜茎（Pumpkin Stem）**是南瓜种子种植在[耕地](耕地.md)上后产生的方块。它会从地下开始逐渐成长为一条完整的茎。南瓜茎起初是绿色的，成熟时则是棕色的。

南瓜茎结出南瓜后便会弯曲。一条成熟的南瓜茎会连接旁边由该南瓜茎生长出来的南瓜，这意味着成熟的南瓜茎有5种可能的状态。如果南瓜茎旁边有多个可以连接的南瓜，其连接方向的优先顺序将依次为东、西、北和南。如果茎旁边没有任何南瓜，它就会恢复直立的状态。

南瓜茎是一种不可以作为[物品](物品.md)获取的[技术性方块](技术性方块.md)。

可以通过编辑[物品栏](物品栏.md)或者添加[附加包](附加包.md)来获取南瓜茎。
