# Java版1.3.2

*页面ID: 29996* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.3.2**是的一次次要更新，发布于2012年8月16日<ref name="blogpost_1.3.2"></ref>，修复了[Java版1.3.1](Java版1.3.1.md)中的一些漏洞和崩溃。此版本兼容1.3.1的服务端。

1.3.2的预发布版发布于2012年8月14日<ref name="blogpost_1.3.2"/>，但与正式版更新内容相同。

# 更改
# = 世界生成 =
* *[树木](树木.md)**
* 大型橡树现在会生成横向的枝干。

# = 常规 =
* *[服务器列表](服务器列表.md)**
* 现在可以用键切换是否显示服务器IP地址。

# 修复
* *修复了4个漏洞**
* 修复了玩家在中进入以前所去过的下界时，有时会掉出世界的问题。<ref></ref>
* 修复了将水或玩家推入角落时，玩家会受到伤害的问题。
* 修复了各种不常见的崩溃错误。
* 修复了玩家从4格高的地方摔落时不受到伤害的问题。</onlyinclude>
