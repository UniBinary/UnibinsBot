# Minecraft Now Boss投票服务器活动

*页面ID: 184053* | *来源: Minecraft Wiki*

* *Minecraft Now Boss投票服务器活动（2022 Boss Vote Event）**是一个[活动服务器](活动服务器.md)，玩家可以在此为[末影龙](末影龙.md)或[凋灵](凋灵.md)投票。

# 主要活动
# = Boss投票 =
玩家可以在投票区域拉下拉杆来为Boss投票。

# = 末影过山车 =
末影过山车可以带领玩家游览整个地图。

# 小游戏
# = 竞技场 =
进入竞技场后，玩家需要在2分钟内击败尽可能多的敌人。竞技场外的玩家可以向竞技场内的玩家提供[曲奇](曲奇.md)和[附魔金苹果](附魔金苹果.md)。

# == 物品商店 ==
物品商店是一个位于竞技场中心的建筑。玩家可以用通过击败敌对生物获得的点数（Points）在此购买物品。可购买的物品有：

*  - 10点数
*  - 150点数
*  - 400点数
*  - 10点数
*  - 150点数
*  - 400点数
*  - 150点数
*  - 50点数

# = 跑酷 =
以末影龙与凋灵的战斗为主题的跑酷。

# = 传送门速降 =
传送门速降位于生物投票区域的中心，设有多个障碍物以延缓玩家快速下落。玩家需要尽快落入位于挑战底部的泳池中来完成挑战。
