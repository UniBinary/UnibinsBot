# 试炼钥匙

*页面ID: 107356* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *试炼钥匙（Trial Key）**是从[试炼密室](试炼密室.md)中获取的物品，可用于解锁[宝库](宝库.md)。

# 获取
# = 箱子战利品 =
[试炼刷怪笼](试炼刷怪笼.md)提供战利品时有50%的概率选中包含试炼钥匙的战利品表。

# 用途
试炼钥匙可用于解锁[宝库](宝库.md)，每次解锁消耗1个试炼钥匙。
