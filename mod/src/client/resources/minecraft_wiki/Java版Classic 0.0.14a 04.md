# Java版Classic 0.0.14a 04

*页面ID: 34954* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.14a_04**是的一次更新，发布于2009年5月28日<ref>[IRC日志](#logs.md): "*(19:35:52) * notch changes topic to: http://www.minecraft.net/ | http://www.mojang.com/forum/ | 0.0.14a_04 is up. You can now set the spawn point with return.*" (17:35 UTC)</ref><ref></ref>，更改了[树木](树木.md)的形状和[迷雾](迷雾.md)的颜色。

# 新内容
# = 常规 =
* *[控制](控制.md)**
* 按键可以保存出生点。
* * 按键会在出生点处重生。

# 更改
# = 世界生成 =
* *[树木](树木.md)**
* 其顶部现在具有“+”的形状。<ref>[IRC日志](#logs.md): "*[17:06] <justinforasec> notch this is just a style thing, but did u want the trees to be cubes? i found if u take off the corners they look alot more natural*" [...] "*[17:07] <@notch> oooh, that IS nicer, justinforasec* [...] *[17:07] <@notch> I'm definitely making it so for the next version, thank you*"(17:06 UTC)</ref>

# = 游戏内容 =
* *[迷雾](迷雾.md)**
* 现在是白色的而不是蓝色的。<ref>[IRC日志](#logs.md): "*[10:35] <justinforasec> i dont get why the fog is blue* [...] *[10:35] <justinforasec> wouldnt white or greyish be better?*"(17:06 UTC)</ref><ref>[IRC日志](#logs.md): "*[23:07] <justinforasec> hey the fog is white!* [...] *[23:07] <justinforasec> ty notch*"(17:06 UTC)</ref>
* 现在会被应用于阴影面了。</onlyinclude>

# 重新上传
该版本于17:43（UTC）被重新上传，以尝试修复一个有关鼠标控制问题的漏洞，但没有成功。<ref>[IRC日志](#logs.md): "*(19:40:02) <justinforasec> hey notch there might be something wrong with mouse control, mines very... weird*" [...] "*(19:40:22) <mezo> mouse movement seems very bugged*" [...] "*(19:43:35) <@notch> is the mouse look fixed now?*" [...] "*(19:44:02) <mezo> mouse is fixed*" [...] "*(19:44:09) <mezo> nm no it's not*" [...] "*(19:45:13) <mezo> doesnt do it*", "*(19:45:21) <mezo> it's fine for about two seconds then it deteriorates*" [...] "*(19:45:41) <mezo> it's very jittery, as if it's only reading a few dpi*" (17:40 to 17:45 UTC)</ref>
