# Java版1.13.2-pre1

*页面ID: 36770* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.13.2-pre1**是[Java版1.13.2](Java版1.13.2.md)的首个预发布版，发布于2018年10月16日<ref></ref>，修复了[Java版1.13.1](Java版1.13.1.md)遗留的一些漏洞，并做了一些性能改进。

# 更改
# = 常规 =
* *性能**
* 提升了世界加载性能。
* 提升了游戏启动性能。
* 提升了海龟寻路性能。
* 提升了生物生成性能。
* 提升了其他各种性能。
