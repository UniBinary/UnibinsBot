# 时髦的传送门（方块）

*页面ID: 150096* | *来源: Minecraft Wiki*

* *时髦的传送门（Funky Portal）**方块，也被称为**传送门（Neither Portal）**方块，是一种构成[时髦的传送门](时髦的传送门.md)的半透明方块，能够传送玩家进出[自定义维度](20w14∞#世界生成.md)。

# 生成
# = 时髦的传送门 =
时髦的传送门方块是激活的[时髦的传送门](时髦的传送门.md)结构的一部分。

# 获取
时髦的传送门没有对应的物品形式。

# 破坏
时髦的传送门不能被挖掘破坏。

时髦的传送门被破坏后不会掉落。

# 用途

时髦的传送门方块只能够在[时髦的传送门](时髦的传送门.md)结构里出现。当此方块被更新（需要平行方向的[PP更新](方块更新#PP更新.md)），同时被检测到不处于时髦的传送门中时会被移除。

时髦的传送门方块可以用于传送生物进入或离开自定义维度。玩家持续处于一个时髦的传送门方块的位置4秒钟就会被传送到另一个维度。玩家可以在传送门播放完毕传送动画之前，离开传送门以取消传送。[创造模式](创造模式.md)的玩家或其他未骑乘或被骑乘的实体在接触时髦的传送门方块时会被瞬间传送到其他维度。如果在约128格以内有一个**已激活**的传送门，那么玩家就会被传送到那个传送门。否则会在相应的坐标处（或其附近）选择一个合适的地点生成传送门。由命令生成单独的时髦的传送门方块仍可以将实体传送到自定义维度或主世界。

不像大多数不可挖掘的方块，时髦的传送门方块的[爆炸抗性](爆炸抗性.md)只有0。因此，任何能够破坏方块的爆炸会能在波及时髦的传送门方块时将其破坏，并关闭整个时髦的传送门。

液体在流动时会避开时髦的传送门方块。发射器或玩家在时髦的传送门方块的位置放置任意液体会破坏时髦的传送门。

时髦的传送门方块无法被[活塞](活塞.md)推动。

时髦的传送门的颜色和指向的维度取决于玩家丢进去的书与笔或成书里的内容。具体而言，这些书的内容会使当前的传送门获得对应维度的数字ID，此数字会与<code>0xFFFFFF</code>按位与得到RGB颜色，根据维度的不同共有<math>2^{24}</math>种颜色。

# = 光源 =
时髦的传送门方块会发出亮度等级为11的光。
