# Java版Indev 0.31 20100129-1447

*页面ID: 172458* | *来源: Minecraft Wiki*

<onlyinclude>
* *0.31**的一个版本发布于2010年1月29日14:47（UTC），加入了一些新特性。<ref name="WoN 0129 release"></ref>

# 新内容
# = 物品 =
* *[木棍](木棍.md)<ref name="0129 demo"></ref>**
* 用于合成其他物品。
* 可由2个[木板](木板.md)来合成。

# = 生物 =
* *[黑史蒂夫](黑史蒂夫.md)<ref name="0129 demo" />**
* 有点生命值。
* 死亡后没有[掉落物](掉落物.md)。

* *[史蒂夫](Indev MD3格式生物.md)<ref name="0129 demo" />**
* 有点生命值。
* 死亡后没有掉落物。

# = 游戏内容 =
* *[烧炼](烧炼.md)**
* 将物品扔进[火](火.md)或[熔岩](熔岩.md)中即可进行。<ref name="0129 demo" />

# 更改
# = 方块 =
* *[煤矿石](煤矿石.md)**
* 现在可以被烧炼，被烧炼后掉落1-3个[煤炭](煤炭.md)。

* *[铁矿石](铁矿石.md)**
* 现在可以被烧炼，被烧炼后掉落1-3个[铁锭](铁锭.md)。

* *[金矿石](金矿石.md)**
* 现在可以被烧炼，被烧炼后掉落1-3个[金锭](金锭.md)。

* *[钻石矿石](钻石矿石.md)**
* 现在可以被烧炼，被烧炼后掉落1-3个[钻石](钻石.md)。

* *[铁块](铁块.md)**
* 加入了合成配方，现在可由4个铁锭来合成。

* *[金块](金块.md)**
* 加入了合成配方，现在可由4个金锭来合成。

* *[钻石块](钻石块.md)**
* 加入了合成配方，现在可由4个钻石来合成。

* *[火把](火把.md)**
* 加入了合成配方，现在可由1个木棍和1个煤炭来合成。

# = 物品 =
* *[工具](工具.md)**
* 加入了[剑](剑.md)、[镐](镐.md)、[锹](锹.md)和[斧](斧.md)的合成配方，现在可由木棍和木板、圆石、铁锭、金锭或钻石来合成对应等级的工具。

* *[煤炭](煤炭.md)**
* 现在可以通过烧炼煤矿石获得。

* *[铁锭](铁锭.md)**
* 更改了纹理。
* 现在可以通过烧炼铁矿石获得。

* *[金锭](金锭.md)**
* 更改了纹理。
* 现在可以通过烧炼金矿石获得。

* *[钻石](钻石.md)**
* 现在可以通过烧炼钻石矿石获得。

* *常规**
* 物品现在可以堆叠到64个。<ref name="WoN 0129 release" />

# = 非生物实体 =
* *[掉落物](掉落物.md)**
* 现在可以更快地捡起掉落物。
* 不会被火摧毁了。

# = 游戏内容 =
* *[合成](合成.md)**
* 移除了用[苹果](苹果.md)合成[箭](箭.md)的配方。

* *常规**
* 现在玩家出生时会携带[打火石](打火石.md)。

# = 世界生成 =
* *[Indev房子](Indev房子.md)**
* 移除了装有[TNT](TNT.md)和[布料](布料.md)的[箱子](箱子.md)。
* 从箱子中移除了所有物品。</onlyinclude>

# = 常规 =
* *[控制](控制.md)**
* 右键单击可从拿起的一组[物品](物品.md)中放下单个物品。<ref name="WoN 0129 release" />
