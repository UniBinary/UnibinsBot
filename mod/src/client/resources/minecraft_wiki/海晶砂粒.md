# 海晶砂粒

*页面ID: 12510* | *来源: Minecraft Wiki*

* *海晶砂粒（Prismarine Crystals）**是一种通过杀死[守卫者](守卫者.md)和[远古守卫者](远古守卫者.md)获得的[物品](物品.md)。

# 获取
# = 生物掉落物 =

# = 海晶灯 =
没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[海晶灯](海晶灯.md)被破坏后会掉落2-3个海晶砂粒。工具的[时运](时运.md)魔咒会使海晶灯额外等概率掉落0-<魔咒等级>个海晶砂粒，但掉落总数不会超过5个。海晶砂粒的掉落数量不受时运魔咒影响。<ref></ref>
