* *19w45a**是[Java版1.15](Java版1.15.md)的第12个快照，发布于2019年11月7日<ref name="19w45a"></ref>，加入了新的实体标签，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[标签](Java版标签.md)**
* 加入了实体标签。

# 更改
# = 方块 =
* *[堆肥桶](堆肥桶.md)**
* 现在由[台阶](台阶.md)合成（类似于[基岩版](基岩版.md)），而不是[栅栏](栅栏.md)和[木板](木板.md)。

* *[末地石砖](末地石砖.md)**
* 现在的硬度为3。
* 现在的爆炸抗性为45。

# = 物品 =
* *[盾牌](盾牌.md)**
* 图案纹理现在使用透明通道确定颜色，而不是亮度。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 蜜蜂现在会在各方向上搜寻最多10方块距离来寻找可占有的蜂巢/蜂箱。

* *[鹦鹉](鹦鹉.md)**
* 不再模仿[末影人](末影人.md)的声音。

# = 世界生成 =
* *[树木](树木.md)**
* [桦树](桦树.md)现在会生成于[黑森林](黑森林.md)生物群系。

# = 游戏内容 =
* *[进度](进度.md)**
* 现在可以用[光灵箭](光灵箭.md)获得“”进度。

# = 常规 =
* *纹理**
* 将[Java版1.13](Java版1.13.md)的菜单页面背景图的纹理改为1×1像素。
* 移除了[自定义](自定义/Java版1.13前.md)世界类型的除了“空岛”的预设图标。
