# 基岩版1.19.0.26

*页面ID: 95161* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.0.26**（Xbox/Windows/Android）、**Preview 1.19.0.27**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.0](基岩版1.19.0.md)的第3个测试版，发布于2022年4月20日<ref></ref>，加入了[监守者](监守者.md)的远程攻击方式和新的[音乐](音乐.md)曲目，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[音乐](音乐.md)**
* 加入了4首新的音乐，作者为[Lena Raine](Lena Raine.md)：
* * “Ancestry”仅会在[深暗之域](深暗之域.md)中播放。
* * “Aerie”“Firebugs”和“Labyrinthine”会在[繁茂洞穴](繁茂洞穴.md)、所有种类的[沼泽](沼泽.md)、[森林](森林.md)和[丛林](丛林.md)中以及[菜单屏幕](菜单屏幕.md)中播放。

* *[粒子](粒子.md)**
* 加入了粒子。

# 更改
# = 方块 =
* *[红树根](红树根.md)和[红树胎生苗](红树胎生苗.md)**
* 现在可用于[堆肥](堆肥.md)。

* *[泥巴](泥巴.md)**
* 现在[甘蔗](甘蔗.md)、[竹子](竹子.md)和[大型垂滴叶](大型垂滴叶.md)可以被放置在其顶面上。

* *[沾泥的红树根](沾泥的红树根.md)**
* 现在[花](花.md)、[树苗](树苗.md)和[草丛](草丛.md)可以被放置在其顶面上。

* *[音符盒](音符盒.md)**
* 回退了1.18.30.22仅让羊毛和羊毛地毯可以阻止音符盒发出声音的更改。

* *[强化深板岩](强化深板岩.md)**
* 不再能够被[末影龙](末影龙.md)或[凋灵](凋灵.md)破坏。

* *[幽匿尖啸体](幽匿尖啸体.md)**
* 更改了模型以及侧面纹理，现在其上半部分的高度减小了1个像素。

# = 物品 =
* *[船](船.md)和[运输船](运输船.md)**
* 更改了物品纹理以匹配。

* *[回响碎片](回响碎片.md)**
* 现在可以在远古城市的战利品箱中找到。

# = 生物 =
* *[蝌蚪](蝌蚪.md)**
* 现在会跟随手持[黏液球](黏液球.md)的玩家。

* *[监守者](监守者.md)**
* 现在若其目标的位置在近战范围外或有方块阻隔，会尝试蓄力并发起远程攻击。
* * 攻击时，一道形如幽匿尖啸体尖啸粒子的攻击波粒子会自其胸前发出，并有胸口张开的动画。
* * 此远程攻击可击中距离监守者15格内的生物，并造成和该难度下近战攻击相等的伤害。
* * 此远程攻击一次只能击中一个目标，且可以攻击到在墙后的生物。
* 靠嗅觉侦测时垂直方向的敌对范围由6格改为20格。
* 现在所有与监守者发生接触的生物都会将其激怒，不再限于玩家。

# = 世界生成 =
* *[远古城市](远古城市.md)**
* 更新了结构以匹配。
* 更新了战利品表以匹配。

# = 常规 =
* *[音乐](音乐.md)**
* 更改了以下音乐可播放的位置：
* * “Stand Tall”“Wending”和“Infinite Amethyst”现在不再会在菜单屏幕上播放。
* * “Left to Bloom”和“One More Day”现在不再会在菜单屏幕上播放，会在所有种类的森林、丛林和[原始针叶林](原始针叶林.md)中播放。
* * “Floating Dream”和“Comforting Memories”现在会在所有种类的森林、丛林和原始针叶林中播放。

# 修复
* *音效**
* 青蛙现在会使用所有的受伤音效。（）
* 蛙明灯现在拥有正确的破坏音效。（）

* *远古城市**
* 远古城市中的灵魂灯笼不再会悬空生成。（）
* 现在远古城市的中心部分会生成完整的强化深板岩框架。（）

* *监守者**
* 监守者不再会在具有目标时进行嗅探。
* 现在监守者若嗅探到目标，则会停止钻回地面。
* 监守者现在会被其他生物推动。
* 监守者现在会被接触其的其他生物激怒。（）
* 修复了攻击监守者并切换游戏模式时发生的崩溃。
* 监守者现在会掉落正确的经验。（）

* *悦灵**
* 与悦灵交互的提示文本被更改为“给小安粒物品”。（）

* *方块**
* 凋灵不再能够破坏强化深板岩。（）
* 末影龙不再能够破坏强化深板岩。（）
* 在创造模式物品栏中，强化深板岩现已移动至自然选项卡。（）

* *泥砖**
* 现在泥砖楼梯、台阶或墙会正确被分组。（）

* *游戏内容**
* 修复了使用材料分解器时发生的崩溃（教育版特性）。
* 修复了在水下可以从内部来破坏光源方块的问题。（）
* 修复了在熔炉中拿走不正确槽位上的物品时会获得经验的问题。（）
* 现在红树根和红树胎生苗可用于堆肥。（、）
* 现在泥巴和沾泥的红树根上可以放置更多种类的植物，包括所有花、树苗、竹子、甘蔗、大型垂滴叶和甜浆果丛。（）
* 红树现在可以穿过雪层生成。（）

* *触摸控制设置**
* 关闭“移动摇杆可见”选项后，“静态摇杆”选项不再会一同被禁用。（）

* *图形**
* 更新了运输船的物品纹理以匹配Java版。（）

* *袭击**
* 灾厄村民现在可以转移至其他村庄进行袭击。（）

* *技术性**
* 修复了权重不能作用于音乐的问题。</onlyinclude>
