* *Minecraft教育版（*Minecraft Education*）**是Minecraft特别为教室使用而设计的教学版本。它由[Mojang Studios](Mojang Studios.md)和[Xbox Game Studios](wzh:Xbox游戏工作室.md)共同开发，包含了让[Minecraft](Minecraft.md)在课堂里容易使用的特性。完整的游戏已在2016年11月1日发布。<ref name=EducationBlogPost/>Beta版本的测试在2016年6月9日至11月1日间进行。

2018年8月20日，Mojang宣布将于2018年秋季教育版将支持iPad。<ref>https://education.minecraft.net/ipad</ref>微软表示，许可用户可以在9月开始使用。<ref>[What’s New in EDU: Minecraft: Education Edition expands to iPad - August 20. 2018](https://educationblog.microsoft.com/2018/08/minecraft-education-edition-ipad-whats-new-in-edu/)</ref> 它已于2018年9月6日在App Store发布。

2020年6月26日，针对Google Play商店的兼容Chromebook推出了教育版公开测试版。完整游戏已于2020年8月7日发布到Chromebook的Google Play商店。<ref>https://education.minecraft.net/chromebook</ref>

# 特性

* *教育版**基于<ref></ref>制作，包含了可以在课堂里让Minecraft更易理解和更有效果的特性。在编辑世界的“|作弊}}”设置中启用“Education Edition”选项也能带来部分教育版的方块和物品。这些特性有：
* 简单的课堂合作：教育工作者反馈说教育版最大的优点是学生能够合作完成项目以及解决问题。一间最多有30名学生的课室在游玩一个世界而无需设立多个服务器。学生也可以通过加入他们同学的世界从而简单地以一对或一组的形式进行合作。
* NPC：教育工作者可创建一个来充当学生的游戏内向导、下达命令、提供更多信息，同时也允许教育工作者插入一个web链接到外部资源。
*  + : 用Minecraft教学的一个重要方面是能够在游戏内收集学习过程中的信息和追踪学生的进度。摄像机和相片簿功能允许学生拍下他们成果的截图以及上传他们项目进度的文档。
* ：黑板建造者可使用黑板沟通学习的目标，提供附加信息以及在游戏内下达明确的命令。黑板有3种不同的尺寸： (1×1)， (2×1)， 和 (3×2)。
* 教程世界：对于初来乍到Minecraft的教育工作者和学生，可游玩教程世界来引导他们在游戏内导航、合成、放置以及摧毁方块。
* 和方块：这些方块可以让教育工作者（或者拥有 Worldbuilder 的玩家）来规划允许玩家建造和不允许玩家建造的区域。
* 方块：这个方块不允许玩家进入或者离开一个区域。受影响的范围从方块放置的X和Z坐标的平面一直沿着Y坐标延伸，该方块有着和圆石墙相同的外形，不同的是它是平整的而且有着红色的纹理和粒子效果。
* 教室模式：这是教育版中赠送的程序，它让教育工作者能够掌握整张地图（包括里面的全部玩家），与玩家交流（监视着谈话），以及关闭/打开世界的一些设置。
* 附加的物品栏：教育版里有一个有三个物品槽的小物品栏，玩家们的这个物品栏可以被教育工作者开启。这个物品栏在主物品栏的右边，教育工作者可以把物品填入这个物品栏。
* [代码构建器](代码构建器.md)和：一个免费的教育版程序，允许学生在代码编辑器中编写代码，然后智能体执行程序中的代码。这是一个新特性且已在[1.0.1](教育版1.0.1.md)中应用。
* 一个叫做的命令可修改玩家的权限，例如<code>worldbuilder</code>权限；<code>mayfly</code>，允许在所有游戏模式中启用/禁用飞行；以及<code>mute</code>，它允许将玩家禁言。能力类似于游戏规则，除了它们适用于玩家而不是整个世界。
* 一个新的<code>immutableWorld</code>游戏规则，如果它被开启，将阻止任何不是教师（或没有 WorldBuilder 权限）的玩家打破或放置任何方块，除非它们位于方块范围。
* Worldbuilder 是一种可以应用于玩家的权限，可以让他们绕过方块与方块的功能。

# 教案
针对教育版的教案已开放下载，涵盖了各种各样的学科，包括科学、数学、计算机科学、语言艺术、历史与文化、艺术与设计、公民素养、社交情感、平等与包容、气候与<ref>https://education.minecraft.net/resources</ref>。此外，教育工作者可以从网站处上传他们为他人创建的教案。

# 价格
完整游戏的价格为4.99美元/用户/年，新用户在购买前可以免费试用，游客可以体验演示版模式。学校端部署和大规模的学术机构的批量定价也已在计划中。已经拥有[MinecraftEdu](MinecraftEdu.md)的学校和地区将会免费获得教育版。

2017年5月2日宣布，当学校或者教育机构购买了一个新的Windows 10设备便可以免费获得一年的Minecraft教育版。<ref></ref>

# 购买资格
为了获得教育版购买的资格，你必须达成下列要求<ref></ref>：

* 拥有Microsoft 365（原Office 365）教育版账户
* 教育者要取得购买资格，必须是学术机构的全职或兼职教员/职员，并且拥有一个由学校提供的学校电子邮箱，以接受附加电子邮件的用户。
* 区域或学校要取得购买资格，必须是一个素质教育用户，这个用户的定义是专门教育其注册学生为目的的机构组织。
* 公共图书馆要取得购买资格，必须为所有给定的社区、区域或地区免费提供普通图书馆服务。
* 公共博物馆要取得购买资格，必须是一个本质上以永久基础教育或以审美为目的，并利用专业人员定期向公众展示一个有形物体的机构或机构组织。
* 家庭教育项目要取得购买资格，必须提供向学生提供中小学教育或学生出具其属于由国家认可的家庭教育组织或被一个当地学区明确承认此为一种可接受的教育方式或者州立承认/任何的教育组织的书面证明。

# 系统需求
最低系统配置需求（[根据Support Center](https://edusupport.minecraft.net/hc/en-us/articles/360047556591-System-Requirements)）：

# = Windows 10 =
* 1GHz或更高频率的32位或64位处理器。
* 2GB的内存。
* 2GB的可用存储空间。
* 支持DirectX 9和WDDM 1.0或更高的设备。

# = macOS =
* macOS Sonoma (14)或更高版本。
* 2GB内存。
* 2GB可用存储空间。
* [在此处内列出的Mac型号](https://support.apple.com/zh-cn/105113)。

# = iOS/iPadOS =
* iOS/iPadOS 15.0或更高版本，兼容以下设备：
* * iPhone 6S或更新设备
* * iPhone SE或更新设备
* * iPhone Air
* * iPad（第5代）或更新设备
* * iPad Air 2或更新设备
* * iPad mini 4或更新设备
* * iPad Pro（9.7英寸、10.5英寸、11英寸和12.9英寸）或更新设备
* * iPod touch 7

# = Android =
* Android Oreo (8.0)或更高版本。

# = ChromeOS =
* ChromeOS 114或更高版本。
* 支持Play商店应用的设备。
* 在设备上每个账户约500MB的硬盘驱动器空余存储空间（250MB客户端+储存世界的空间）。
