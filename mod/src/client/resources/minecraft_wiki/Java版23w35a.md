# Java版23w35a

*页面ID: 105665* | *来源: Minecraft Wiki*

<onlyinclude>

* *23w35a**是[Java版1.20.2](Java版1.20.2.md)的第4个，也是最后一个快照，发布于2023年8月30日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[红石线](红石线.md)、[红石中继器](红石中继器.md)和[红石比较器](红石比较器.md)**
* 现在收到来自下侧的[PP更新](方块更新#PP更新.md)时检查附着。

# = 常规 =
* *常规**
* 将LWJGL的版本升级到3.3.2。
* 随游戏一同提供的Microsoft OpenJDK版本升级至17.0.8。
