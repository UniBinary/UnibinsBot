# 烈焰

*页面ID: 112275* | *来源: Minecraft Wiki*

* *烈焰（Blaze）**可以指：

# Minecraft
*  - 一种敌对生物，可掉落烈焰棒。
*  - 烈焰人的掉落物，可合成烈焰粉。
*  - 用烈焰棒合成获得的物品，可作为酿造燃料，也可用于酿造力量药水。
*  - 用于制作[饰纹陶罐](饰纹陶罐.md)的物品。

# Minecraft Dungeons
# = 生物 =
*  - 生成于的敌对生物。
*  - 下界之焰中只会刷烈焰人的敌对生物。
*  - 一种远古生物。

# = 魔咒 =
*  - 能提高玩家造成火焰伤害的魔咒。

# = 关卡 =
*  - 主大陆中的关卡。

# = 成就 =
* [烈火试炼](MCD:成就.md)

# Minecraft Legends
# = 生物 =
*  - 一种敌对生物，会投掷手中的烈焰棒进行远程攻击。

# = 建筑 =
*  - 一种猪灵建筑，会发射烈焰棒进行攻击。
