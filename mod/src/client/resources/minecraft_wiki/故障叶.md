# 故障叶

*页面ID: 91831* | *来源: Minecraft Wiki*

* *故障叶（<samp>leaves_carried</samp>）**<ref>https://www.minecraftforum.net/forums/minecraft-pocket-edition/mcpe-discussion/1968560-my-report-on-3-strange-new-blocks?comment=8</ref>是一种渲染存储[树叶](树叶.md)模型的方块。

# 获取
故障叶只能通过编辑物品栏获得。

# 破坏
故障叶的挖掘时间与树叶相同。用[剪刀](剪刀.md)挖掘后会掉落普通的树叶。<!--

-->

# 用途
# = 外观 =
故障叶的基础状态与常规的橡树树叶极其相似，但有一些差异：主要的差异在于故障叶比橡树树叶更暗，因为故障叶在树叶的基础上进行了染色，但树叶的纹理是已经上色过的，而非染色方块通常使用的灰度图像。染色所使用的具体的颜色是。

然而，故障叶元数据更高的版本的行为与上文不一致。最为显眼的是元数据为1的种类，对应云杉树叶，使用[工作台](工作台.md)的侧面纹理。可以通过检查<samp>[terrain.png](terrain.png.md)</samp>解释这一点。

元数据为1（对应云杉树叶）的种类使用着色，元数据为2（对应白桦树叶）的使用着色。元数据为3的在<samp>leaves_carried</samp>被移除的版本中最终会与丛林树叶对应，而其所着颜色暂不清楚。

# = 与树叶的功能差异 =
尽管看起来与树叶非常相似，但故障叶与正常树叶有显著的功能差异，例如它们不会枯萎。
