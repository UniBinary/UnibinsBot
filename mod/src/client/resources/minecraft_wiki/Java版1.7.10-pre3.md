# Java版1.7.10-pre3

*页面ID: 33615* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.7.10-pre3**是[Java版1.7.10](Java版1.7.10.md)的第3个预发布版，发布于2014年6月10日<ref></ref>，以修复[Java版1.7.10-pre2](Java版1.7.10-pre2.md)中有关[服务器](服务器.md)断开连接的漏洞<ref></ref>。

# 修复

* 有关服务器断开连接的漏洞。</onlyinclude>

# 你知道吗
* 此版本曾经在[启动器](启动器.md)中移除，但在2018年9月重新加入。
