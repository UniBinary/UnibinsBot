# 音乐唱片13

*页面ID: 156191* | *来源: Minecraft Wiki*

* *13**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的曲目Thirteen。

# 获取
# = 箱子战利品 =

# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片13。

# 用途
# = 音乐 =

[noicon](File:13.ogg.md)

Thirteen是一首以洞穴为主题，稍稍令人不安的环境音乐曲目。

整曲完全沉浸于混响中，交杂着洞穴音效、共振般的金属敲击声、静谧的风声、低沉射击的弓声、重度混响的嘶嘶声，而后是重度混响的爆炸声与回响的水花声。

# = 红石 =

音乐唱片13放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为1的信号。

# 你知道吗
* 此唱片参考了[环境音效](环境音效.md)。名称13也是对加入唱片时存在的13个环境音效的引用。可以在整个音轨上听到其中的一些环境音效。
* * C418起初希望此唱片在玩家探索至洞穴深处时找到，并由一台设备播放，营造令人毛骨悚然的氛围。<ref name="album">https://c418.org/albums/minecraft-volume-alpha/</ref>
