# Java版1.8.1-pre4

*页面ID: 14256* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.8.1-pre4**是[Java版1.8.1](Java版1.8.1.md)的第4个预发布版，发布于2014年11月6日<ref></ref>。

# 更改
# = 非生物实体 =
* *[物品实体](物品实体.md)**
* 在“快速”图像品质设置下，掉落的物品会旋转。

# = 常规 =
* *[选项](选项.md)**
* 云：关/高品质/流畅。
* 实体阴影：开或关。
* 图像品质设置的流畅/高品质现在只影响树叶透明和雨落地的粒子效果。

* *性能**
* 性能优化。
