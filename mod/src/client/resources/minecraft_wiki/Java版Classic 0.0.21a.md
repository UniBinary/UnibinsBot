# Java版Classic 0.0.21a

*页面ID: 35489* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.21a**是的一次更新，发布于2009年6月22日。<ref>[IRC记录](#logs.md): "*P2:52:16 <Notch> 0.0.21a is up, fixing the long standing picking bug*" (19:52:16 UTC)</ref><ref name="blog"></ref>

# 更改
# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 现在具有灰色背景。
* 现在可以一边行走一边修改物品槽位了。<ref>[IRC记录](#logs.md): "*P2:52:22 <Notch> also, new B-menu*", "*P2:52:28 <Notch> you can walk and change slot with it up now*" (19:52 UTC)</ref>

# = 世界生成 =
* *常规**
* 世界生成的“雕饰”阶段被略微修改，导致需要更长的时间来生成世界。<ref>[IRC记录](#logs.md): "*P2:54:48 <greenslimy> Notch, Im on single player and generating a map is so slow >.>*" [...] "*P2:57:04 <Notch> carving changed a bit*" (19:54:48和19:57:04 UTC)</ref>

# = 常规 =
* *其他**
* 提高了一些电脑的游戏运行帧率。

# 修复
* *修复了3个漏洞**
* 修复了一个使得所有MacBook玩家都不能进行游戏的漏洞。
* <!--选择方块可以正常的工作了。-->修复了一个关于OpenGL的漏洞。<ref>[IRC记录](#logs.md): "*P2:58:28 <peerkoel> Notch: what exactly was the picking bug?*" [...] "*P2:58:40 <Notch> opengl picking wasn't working right on some cards*" (19:58 UTC)</ref>
* * 改为使用光线投射（raycasting）。<ref>[IRC记录](#logs.md): "*P2:58:54 <Notch> so I changed it to a pure software implementation (raycasting)*", "*P2:58:57 <Notch> it's also ten times faster, heh*" (19:58 UTC)</ref>
* 修复了一个不能使方块高亮的漏洞。<ref>[IRC记录](#logs.md): *P4:05:10 <Haruhi2> I fixed the problem*" [...] "*P4:05:17 <Haruhi2> with not being able to highlight*" [...] "*P4:05:41 <Notch> actually, 0.0.21a fixes it at well*" [...] "*P4:05:51 <Notch> all highlighting is done is software now. =)*" (21:05 UTC)</ref>

# 重新上传
该版本的客户端于20:09（UTC）被重新上传<ref>[IRC记录](#logs.md): "*P3:12:15 <peerkoel> hm, client version is still 0.0.21a?*" (20:12:15 UTC)</ref>，重新加入了鼠标自动点击功能<ref>[IRC记录](#logs.md): "*P3:09:13 <Notch> client is updated again*" [...] "*P3:10:20 <Notch> does autoclick work now?*" (20:09:13至20:10:20 UTC)</ref>，同时提高了玩家操作距离<ref>[IRC记录](#logs.md): "*P3:12:45 <AlLnAtuRalX> Notch, thanks for increasing build distance*" (20:12:45 UTC)</ref>，并修复了一些漏洞。</onlyinclude>
