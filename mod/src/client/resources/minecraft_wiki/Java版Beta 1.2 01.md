# Java版Beta 1.2 01

*页面ID: 32663* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.2_01**是的一次次要更新，发布于2011年1月14日。重新添加了[史莱姆](史莱姆.md)，修复了Beta 1.2中的一些漏洞，并优化了性能。

# 新内容
* 加入一个[画](画.md)的代码，但画本身没加入到游戏中。
* [史莱姆](史莱姆.md)被重新加入到游戏中，但是生成概率非常低。

# 更改
* 优化性能。
* 稍微降低了[鱿鱼](鱿鱼.md)的生成率。
* 修正放置时动作不正常的各种方块（[铁轨](铁轨.md)、[火把](火把.md)等）。
* 修正光照问题。
* 减少了晚上怪物生成的数量。
* [闪烁标语](闪烁标语.md)在主菜单上的文字恢复正常（不再是“Finally beta!”）。

# 修复
* *修复了3个漏洞**
* 修复了放置各种方块时表现的很奇怪的问题（铁轨、火把等）。
* 修复了一些光照问题。
* 添加了一个临时性的修复，用以避免区块可见性错误。<ref></ref></onlyinclude>
