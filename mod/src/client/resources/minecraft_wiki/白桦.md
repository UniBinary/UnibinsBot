白桦是一种植被[地物](地物.md)，分为**普通白桦（Birch）**、**高白桦（Super Birch）**、**倒下的白桦（Fallen Birch）**和**倒下的高白桦（Fallen Super Birch）**。

# 种类
# = 普通白桦 =
普通白桦的树冠形状与普通[橡树](橡树.md)、[丛林树](丛林树.md)以及高白桦相同。其整体高度为6-8格；高度为6-9格。

# = 高白桦 =
高白桦的整体高度为6-14格；整体高度为6-16格。

# = 倒下的白桦与倒下的高白桦 =
倒下的白桦包含一个单独的纵向原木作为树桩，距其一两格远的地方平躺着一排原木（普通白桦为0-6格，高白桦为0-13格）。有时这些原木上会出现[蘑菇](蘑菇.md)，但树桩处不会出现[藤蔓](藤蔓.md)。

# 生成
白桦生成时会将下方1格的方块转变为[泥土](泥土.md)。

# = 自然生成 =
生物群系放置树木地物时，每种树木的生成概率如下表所示：

在[桦木森林](桦木森林.md)、[原始桦木森林](原始桦木森林.md)、[森林](森林.md)和[繁花森林](繁花森林.md)自然生成的白桦有很小的概率带有[蜂巢](蜂巢（方块）.md)，而在[草甸](草甸.md)自然生成的高白桦总会带有蜂巢。每个由此方式生成的蜂巢都会容纳3只[蜜蜂](蜜蜂.md)。

# = 人为生成 =
[亮度](亮度.md)等级至少为9且有一定的空间时，[白桦树苗](白桦树苗.md)可长成普通白桦。

若白桦树苗的水平2格范围内存在[花](花.md)、，则长成的白桦会有5%的概率悬挂着[蜂巢](蜂巢（方块）.md)，每个由此方式生成的蜂巢都会容纳1-3只蜜蜂。
