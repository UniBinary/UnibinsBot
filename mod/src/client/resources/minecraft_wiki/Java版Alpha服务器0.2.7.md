# Java版Alpha服务器0.2.7

*页面ID: 45547* | *来源: Minecraft Wiki*

* *0.2.7**是非强制更新的一个[Alpha](Java版Alpha.md)服务器版本，与[客户端1.2.5](Java版Alpha v1.2.5.md)在2010年12月1日一起发布。<ref></ref>

# 更改
* 修复了服务器中的内存泄漏漏洞，该漏洞中实体位置更新累积在孤立的玩家对象中。
* 移除了服务器对命令的支持。
