# 启动器2.1.532x

*页面ID: 45060* | *来源: Minecraft Wiki*

<onlyinclude>
* *2.1.5322**（[Windows](wzh:Microsoft Windows.md)）、**2.1.5321**（[macOS](wzh:MacOS.md)）或**2.1.5320**（[Linux](wzh:Linux.md)）是在2019年6月25日发布的[启动器](启动器.md)测试版本，修复了一些漏洞。<ref name="changelog-2.1.532x">https://piston-meta.mojang.com/mc/launcher_beta_changelog.md</ref>

# 更改
* 添加了更多日志记录以追踪 - 启动器无法建立与互联网的连接。
* 将启动器版本添加到日志文件中。
* 添加了更多图标供配置选择。

# 修复
* 修复了在演示模式下丢失的新闻帖子。
* 修复了默认安装图标错误。
* 修复了第三方软件添加的安装未在启动时显示的选项。
*  - “安装”按钮显示旧版纹理。
*  - 未正确应用JVM参数。
*  - 当系统区域设置不符合预期时，在Linux上崩溃。
*  - 缺少游戏文件。
*  - 在Linux上登录后，启动器为空白。
*  - 无法游玩演示版。</onlyinclude>
