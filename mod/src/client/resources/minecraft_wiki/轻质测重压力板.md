# 轻质测重压力板

*页面ID: 164708* | *来源: Minecraft Wiki*

* *轻质测重压力板（Light Weighted Pressure Plate）**是一种可以用来探测站在上方[实体](实体.md)数量的[方块](方块.md)。

# 生成
轻质测重压力板不会生成在世界中。

# 破坏
挖掘轻质测重压力板的合适工具是镐。

轻质测重压力板被破坏后会掉落自身。

# 用途
轻质测重压力板必须于[方块支撑形状](方块支撑形状.md)上表面中心完整或边缘完整的方块上方（包括[漏斗](漏斗.md)、[栅栏](栅栏.md)、[侦测器](侦测器.md)等），不能放置于任何方块的侧面与底部。

尝试在无效的表面放置轻质测重压力板会使其“滑入”这块空间内最近的有效附着表面。如尝试在地面上的栅栏侧面放置轻质测重压力板会使其附着到栅栏周围地面方块的顶部。

当轻质测重压力板附着的方块变动（移动、破坏、替代等），不再允许附着时或有[活塞](活塞.md)试图推动它或将方块推入其位置时，轻质测重压力板会掉落为方块物品。

[沙子](沙子.md)或[沙砾](沙砾.md)这类受重力影响的方块正下方为轻质测重压力板时不会开始下落。下落到轻质测重压力板的位置时，它会掉落为方块物品。

# == 开启 ==
轻质测重压力板可以被除了[投掷物](投掷物.md)及[下落的方块](下落的方块.md)以外的所有的实体（包括玩家、生物、[物品](物品（实体）.md)、[箭](箭.md)、[经验球](经验球.md)、[浮漂](浮漂.md)等）开启。

轻质测重压力板上方（具体为在轻质测重压力板所在方块的（0.125,0,0.125）到（0.875,0.25,0.875）这个长方体区域内）有符合要求的实体时（即使实体的碰撞箱只有一小部分在其中），轻质测重压力板会被**开启**。

轻质测重压力板开启时输出的信号强度取决于实体数量（见**轻质测重压力板信号强度与所需实体数对照表**），不随实体类型而变化，而只是检测实体数量。堆叠的物品是单个实体，无论堆叠多少物品。当同种多个物品掉在一个轻质测重压力板上时，它们最初可能是单独的实体，轻质测重压力板将单独计数，但当它们堆叠后，信号强度可能会下降。

轻质测重压力板每10游戏刻更新一次状态。

# == 行为 ==
当开启时轻质测重压力板会：
* 激活毗邻的[红石粉](红石粉.md)，四周背对轻质测重压力板的[红石比较器](红石比较器.md)或[红石中继器](红石中继器.md)。
* 强充能轻质测重压力板下方任何[红石导体](红石导体.md)至相应等级。
* 激活毗邻的[机械元件](红石电路#机械元件.md)。

轻质测重压力板没有碰撞箱，不会阻碍实体移动。轻质测重压力板附着的方块能在它下面提供一个固体阻碍（让生物走过，让物体落在上面等等），但轻质测重压力板放置在碰撞箱较小（如栅栏）的方块上时，实体可能在开启轻质测重压力板时穿过轻质测重压力板。因此轻质测重压力板可以用来探测实体而不阻碍它们的运动。

轻质测重压力板关闭时高0.0625个方块（方块的），开启时高0.03125个方块（方块的），但它没有碰撞箱，所以不会影响它上方的实体（如轻质测重压力板上的玩家其实是站在它下面的方块上）。

# = 猪灵 =
[猪灵](猪灵.md)能够被掉落的轻质测重压力板吸引，会主动捡起并端详6-8秒，随后放入自己的物品栏，但破坏轻质测重压力板不会激怒它们。
