# 雕纹下界砖块

*页面ID: 99473* | *来源: Minecraft Wiki*

* *雕纹下界砖块（Chiseled Nether Bricks）**是[下界砖块](下界砖块.md)制作的装饰性方块，每个面都带有[凋灵骷髅](凋灵骷髅.md)面部图案。

# 生成
雕纹下界砖块不会生成在世界中。

# 获取
# = 合成 =

# = 切石 =

# 破坏
挖掘雕纹下界砖块的合适工具是镐。雕纹下界砖块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

雕纹下界砖块被破坏后会掉落自身。

# 用途
雕纹下界砖块目前仅用于装饰。
