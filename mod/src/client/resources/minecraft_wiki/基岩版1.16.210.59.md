# 基岩版1.16.210.59

*页面ID: 78051* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.210.59**是[基岩版1.16.210](基岩版1.16.210.md)的第9个测试版，发布于2021年2月11日<ref></ref>，加入了[发光鱿鱼](发光鱿鱼.md)相关特性<ref></ref>，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[荧光物品展示框](荧光物品展示框.md)**
* 物品展示框的增亮变种。
* 发光亮度仅反映在其纹理上，不会影响光照等级。
* 目前方块形式使用普通物品展示框的纹理。
* 物品放在其中也会增亮。
* 可用[物品展示框](物品展示框.md)和荧光墨囊合成获得。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# = 物品 =
* *[荧光墨囊](荧光墨囊.md)**
* 发光鱿鱼死亡后会掉落。
* 可用于合成荧光物品展示框。
* 可增亮[告示牌](告示牌.md)上的文字。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了发光鱿鱼刷怪蛋。
* * 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# = 生物 =
* *[发光鱿鱼](发光鱿鱼.md)**
* 来源于[Minecraft Earth](Minecraft Earth.md)中的[同名生物](MCE:发光鱿鱼.md)。
* 行为与普通[鱿鱼](鱿鱼.md)大致相同。
* 目前无法自然生成。
* 死亡后会掉落荧光墨囊。
* 发光亮度仅反映在其纹理上，不会影响光照等级。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# 更改
# = 方块 =
* *[告示牌](告示牌.md)**
* 移除了彩色文本自带的增亮效果，以与Java版统一。

# = 物品 =
* *[墨囊](墨囊.md)**
* 现在可用于移除告示牌上的文字的增亮效果。

* *[染料](染料.md)**
* 现在可以对告示牌上的文字染色。

# 修复
* *辅助功能**
* 屏幕阅读器现在可以正确读取A/B或X/Y切换按键的名称。
* 修复了屏幕阅读器有时无法读取部分按键名称的问题。

* *性能与稳定性**
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了离开世界时可能发生的崩溃。
* 修复了附近有村庄的专有服务器上偶尔发生的崩溃。（）
* 修复了有关市场上的世界加载受损生物群系的崩溃问题。

* *常规**
* 命令方块不再会将其命令替换为“###”。（）
* 修复了触摸控制在部分情况下挖掘方块会被打断的问题。（）
* 修复了“换床单啦”成就奖杯可以通过合成床来解锁的问题。
* 现在矿车在玩家乘坐且未被渲染时会正确更新其效果（播放音效、玩家坐标）。（）
* 修正了使用控制器时的皮肤预览导航。
* 修复了高延迟下箭击中玩家后卡在空中的问题。
* 修复了“创建新世界”菜单中的模板选项重叠的问题
* 修复了市场“已拥有的包”界面缺失不兼容按键的问题。
* 修复了游戏内补丁说明多次显示的问题。
* 修复了一些在滚动或清除市场过滤器时的界面问题。

* *图形**
* 下界的迷雾现在能够正常显示。（）

* *云存储（Xbox平台）**
* 解决了部分情况下无法将世界正确同步到云储存的问题。如果在同步世界时出现问题，请打开该世界，保存并退出，等待一段时间使世界重新同步到云储存中。

* *技术性**
* 修复了区块被卸载时动画结构无法继续进行动画的问题。
* 1.16.2以及之前版本创建的附着物都不会为第一人称下持有它的玩家渲染。1.16.2版本之后创建的除盔甲以外的附着物都可在第一人称下被渲染。
* 现在自定义方块被破坏后只会以默认的方块状态掉落了，不管是否使用精准采集。
* 修复了组件物品JSON模式中会以字符串被验证的问题。
* 若命令指定的区域已加载，该命令能够重新以一个实体为起点执行了。</onlyinclude>
