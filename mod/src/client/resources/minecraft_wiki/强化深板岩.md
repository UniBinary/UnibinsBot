# 强化深板岩

*页面ID: 93183* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *强化深板岩（Reinforced Deepslate）**是一种仅生成于[远古城市](远古城市.md)的方块，具有类似[深板岩](深板岩.md)的外观。

# 生成
# = 自然生成 =
强化深板岩自然生成于[远古城市](远古城市.md)的中心，组成一个大型框架。

# 获取

强化深板岩无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，强化深板岩可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
没有工具可以加速对强化深板岩的挖掘。

强化深板岩被破坏后不会掉落。

# 用途
强化深板岩具有极高的爆炸抗性，与[黑曜石](黑曜石.md)、[哭泣的黑曜石](哭泣的黑曜石.md)、[远古残骸](远古残骸.md)、[下界合金块](下界合金块.md)、[铁砧](铁砧.md)、[附魔台](附魔台.md)和[重生锚](重生锚.md)的爆炸抗性相同，在正常情况下无法被爆炸摧毁。

强化深板岩是不会被[凋灵](凋灵.md)和[末影龙](末影龙.md)破坏的少数方块之一，并且不能被[活塞](活塞.md)或[黏性活塞](黏性活塞.md)移动。

尽管具有类似[深板岩](深板岩.md)的名称和纹理，强化深板岩并不是深板岩的变种。

强化深板岩目前仅用于装饰。

# 你知道吗
* [Brandon Pearce](Brandon Pearce.md)曾提及强化深板岩的加入就是为了增添神秘感。<ref></ref>
* 强化深板岩包含了类似于[幽匿尖啸体](幽匿尖啸体.md)和[幽匿催发体](幽匿催发体.md)的白色骨状材料<ref></ref>和蓝色[幽匿](幽匿.md)纹理。
