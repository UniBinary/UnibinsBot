# Java版24w07a

*页面ID: 113519* | *来源: Minecraft Wiki*

<onlyinclude>

* *24w07a**是[Java版1.20.5](Java版1.20.5.md)的第9个快照，发布于2024年2月14日<ref></ref>，在内置实验性数据包中加入了[沼骸](沼骸.md)，并修复了一些漏洞。

# 更改
# = 方块 =
* *[漏斗](漏斗.md)**
* 现在其上方为[蜂巢](蜂巢（方块）.md)或[蜂箱](蜂箱.md)时仍能吸取[物品实体](物品实体.md)。

# = 生物 =
* *[熊猫](熊猫.md)**
* 现在幼年熊猫打喷嚏掉落的[黏液球](黏液球.md)由战利品表控制。

# = 非生物实体 =
* *[漏斗矿车](漏斗矿车.md)**
* 回退了[24w06a](24w06a.md)的更改。

# = 命令格式 =
* ***
* 将参数的最大值由7更改为20。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为<code>32</code>。
* 加入了<code>gameplay/panda_sneeze</code>战利品表，用于控制在[熊猫](熊猫.md)打喷嚏时掉落的物品。

* *[标签](Java版标签.md)**
* 加入了以下方块标签：
* * ：。

# 新内容（实验性）
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了沼骸刷怪蛋。

# = 生物 =
* *[沼骸](沼骸.md)**
* [骷髅](骷髅.md)的新变种。
* * 拥有生命值，不同于骷髅的。
* * 在简单和普通[难度](难度.md)中攻击间隔是，不同于骷髅的；在困难难度中攻击间隔是，不同于骷髅的。
* * 发射[剧毒之箭](剧毒之箭.md)而非普通箭。
* 被玩家或驯服的狼杀死时，有概率掉落剧毒之箭。
* 自然生成于[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)生物群系，也会代替先前的带剧毒之箭的骷髅生成于[试炼密室](试炼密室.md)的部分[试炼刷怪笼](试炼刷怪笼.md)。

# 更改（实验性）
# = 生物 =
* *[旋风人](旋风人.md)**
* 现在会将弹射物向其反方向发射。
* 现在[抢夺](抢夺.md)魔咒对其生效。

# = 非生物实体 =
* *[风弹](风弹（实体）.md)**
* 现在可以穿过[碰撞箱](碰撞箱.md)不完整的方块。

# = 游戏内容 =
* *[进度](进度.md)**
* 现在可通过击杀沼骸达成“”进度。
* 将沼骸加入到“”进度的达成要求中。

# = 常规 =
* *[标签](Java版标签.md)**
* 向实体类型标签加入了。
* 向实体类型标签加入了。
