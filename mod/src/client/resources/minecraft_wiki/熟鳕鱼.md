# 熟鳕鱼

*页面ID: 33830* | *来源: Minecraft Wiki*

* *熟鳕鱼（Cooked Cod）**是一种由[生鳕鱼](生鳕鱼.md)烹饪而成的[食物](食物.md)。

# 获取
# = 生物掉落物 =

# = 自然生成 =

# = 烹饪 =
将[生鳕鱼](生鳕鱼.md)放入[营火](营火.md)、[烟熏炉](烟熏炉.md)或[熔炉](熔炉.md)中烹饪，可以获得熟鳕鱼。

# = 交易 =

# 用途
# = 食物 =

手持熟鳕鱼按住键即可食用，每个熟鳕鱼可以回复。

# = 狼 =
每条熟鳕鱼可给[狼](狼.md)恢复点生命值。然而熟鳕鱼不能用于加快幼年狼的成长以及用于繁殖，因此只能在狼未处于满血状态下食用。

# = 鹦鹉螺和殭屍鸚鵡螺 =
熟鳕鱼可用于喂食驯服的[鹦鹉螺](鹦鹉螺.md)和[殭屍鸚鵡螺](殭屍鸚鵡螺.md)，使生命值已满的成年鹦鹉螺进入繁殖模式，治疗生命值未满的成年鹦鹉螺和殭屍鸚鵡螺的生命值，加速幼年鹦鹉螺约10%的成长时间。
