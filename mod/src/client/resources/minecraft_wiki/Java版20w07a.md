# Java版20w07a

*页面ID: 54647* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w07a**是[Java版1.16](Java版1.16.md)的第2个快照，发布于2020年2月14日<ref name="20w07a"></ref>，加入了猪灵和疣猪兽以及对应的刷怪蛋、新的方块标签，补全了死亡消息，更新了部分生物的AI或纹理，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了猪灵刷怪蛋。

# = 生物 =
* *[猪灵](猪灵.md)**
* 生成于[绯红森林](绯红森林.md)和[下界荒地](下界荒地.md)生物群系。
* 是一种敌对生物，但幼年猪灵无攻击行为。
* * 不会攻击穿着金质盔甲的玩家。
* * 它们会在玩家挖掘[金块](金块.md)或打开[箱子](箱子.md)时被激怒，即使玩家穿着金质盔甲。
* 玩家可以使用金锭右键它们或把金锭扔在地上来和它们以物易物。
* 在某些时候会攻击疣猪兽。
* * 幼年猪灵不会攻击，成年猪灵不会攻击幼年的疣猪兽。
* 攻击[凋灵骷髅](凋灵骷髅.md)。
* 会远离灵魂火和[僵尸猪人](僵尸猪人.md)。
* 喜欢以群组狩猎和争斗。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了<code>beacon_base_blocks</code>方块标签。
* * 包含[铁块](铁块.md)、[金块](金块.md)、[钻石块](钻石块.md)、[绿宝石块](绿宝石块.md)和[下界合金块](下界合金块.md)。
* * 控制可以作为[信标](信标.md)底座的方块。
* 加入了<code>beacon_payment_items</code>物品标签。
* * 包含[铁锭](铁锭.md)、[金锭](金锭.md)、[钻石](钻石.md)、[绿宝石](绿宝石.md)和[下界合金锭](下界合金锭.md)。
* * 控制可以更改信标状态的物品。
* 加入了<code>wall_post_override</code>方块标签。
* * 包含[灯笼](灯笼.md)、[灵魂灯笼](灵魂灯笼.md)、[火把](火把.md)、[灵魂火把](灵魂火把.md)、[红石火把](红石火把.md)和[绊线](绊线.md)。
* * 控制可以把旁边的墙转变为其“柱子”形式的非固体方块。
* 加入了<code>wither_summon_base_blocks</code>方块标签。
* * 包含[灵魂沙](灵魂沙.md)和[灵魂土](灵魂土.md)。
* * 控制可用于搭建生成凋灵的底座的方块。

* *文本**
* 补充了一条缺失的死亡消息文本。<ref></ref>

* *纹理**
* 加入了[僵尸猪灵](僵尸猪灵.md)（zombified piglin）的实体纹理。
* * 如果将其应用于[猪灵](猪灵.md)，会发现少了一只耳朵。
* 加入了为猪灵定制的皮革头盔、锁链头盔、铁头盔、金头盔、钻石头盔和下界合金头盔纹理。

# 更改
# = 方块 =
* *[信标](信标.md)**
* 下界合金块现在可以用于搭建[信标金字塔](信标金字塔.md)，下界合金锭也可以用于更改信标给予玩家的状态效果。

* *[灵魂灯笼](灵魂灯笼.md)**
* 现在有动态纹理了。
* 从纹理中移除了木头的颜色。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 更改了疣猪兽刷怪蛋的颜色。
* 现在用没有幼年形态的生物的刷怪蛋对着对应的生物使用时，会生成出其成年形态的生物。

# = 生物 =
* *[末影人](末影人.md)**
* 现在可以搬起[菌岩](菌岩.md)、[菌索](菌索.md)和[下界菌](下界菌.md)及其变种。
* 不再能搬起[下界岩](下界岩.md)。

* *[疣猪兽](疣猪兽.md)**
* 加入了幼年个体。
* 会攻击视线范围内的玩家。
* 死亡后掉落[生猪排](生猪排.md)，并有概率掉落皮革。
* 玩家可以喂给它们[绯红菌](绯红菌.md)来使之繁殖。
* 成年疣猪兽有时会被成年猪灵猎杀。
* 会远离[诡异菌](诡异菌.md)。
* 有了新的音效。

* *[凋灵](凋灵.md)**
* 现在召唤凋灵时可以用[灵魂土](灵魂土.md)作为底座。

# = 游戏内容 =
* *[进度](进度.md)**
* 现在可以通过杀死猪灵或疣猪兽完成「」进度。
* 现在完成「」进度还需杀死猪灵和疣猪兽。

# = 常规 =
* *[标签](Java版标签.md)**
* 移除了[下界岩](下界岩.md)并增加了[下界菌](下界菌.md)、[菌索](菌索.md)和[菌岩](菌岩.md)及其变种到方块标签。
