# 获取
# = 合成 =
使用3个对应方块即可合成6个半磚。<ref name="article"/>

# = 切石 =
部分台阶也可以使用切石机制作，1个方块可以切出2个对应种类的台阶。另外，若甲方块可以切石为乙方块，则甲方块也可以切石为乙方块对应的台阶。

# 用途
台阶的高度只有对应方块的一半，因此生物可以依靠台阶走上完整方块而无需[跳跃](跳跃.md)。同时，玩家也可以[潜行](潜行.md)着依靠台阶走下完整方块而无需跳跃。

[下落的方块](下落的方块.md)落到下半台阶上会掉落为物品。

台阶不会阻挡光线通过，并会散射天空光照。

台阶可以[含水](含水.md)。

生物可以生成在上半台阶和双层台阶上，但不能生成在下半台阶上。[生物](生物.md)在寻路时会把台阶当作一个完整方块对待。

# = 放置 =
对着方块的顶部或者其侧面的下半部分会放置一个下半部分的台阶；对着方块的底部或者其侧面的上半部分会放置一个上半部分的台阶。

对于两个相同类型的台阶，对着台阶上半部分的底部或者下半部分的顶部会放置一个双层台阶。

# = 破坏 =
双层台阶被破坏时，上半台阶和下半台阶都会被破坏，并掉落2个台阶。

# 你知道吗
* 平面上用台阶构成的1×1的凹陷会正常变暗，但2×1的台阶和2×2的楼梯构成的1×1的凹陷会变暗得更少，因为其周围环绕的固体方块更少。<ref></ref>
* 当[水](水.md)或[熔岩](熔岩.md)在倒置的台阶上时，滴落的粒子效果会出现在台阶下面的半空中，而不是从台阶本身滴落<ref></ref>。
* 玩家不能在不跳跃的情况下从[灵魂沙](灵魂沙.md)直接走上一个下半台阶——这不仅适用于灵魂沙，同时也都适用于任何[高度差](碰撞箱.md)为格的方块，因为玩家不跳跃时最高能走上0.6格高。
