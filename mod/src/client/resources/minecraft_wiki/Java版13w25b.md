# Java版13w25b

*页面ID: 33560* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w25b**是[Java版1.6.1](Java版1.6.1.md)的第16个快照，发布于2013年6月18日<ref></ref>，修复了[13w25a](13w25a.md)里的漏洞和崩溃。

# 更改
# = 物品 =
* *[剑](剑.md)**
* 玩家不再能在[创造模式](创造模式.md)下手持剑破坏方块了。

# 修复
记分项的数值不会随着生命提升状态效果而更新。
|18277|读取含有unicode字符的文件会导致游戏崩溃。
|;previous
|18257|属性并不能够抵消摔落伤害的击退效果。
|18306|游戏会在点击“纹理包”按钮后崩溃。
}}</onlyinclude>

# 你知道吗
* 该版本的宣传截图中出现了[Grum](Grum.md)的Minecraft皮肤。
