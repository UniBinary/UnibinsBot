# 极限模式

*页面ID: 6413* | *来源: Minecraft Wiki*

* *极限（Hardcore）**模式是难度锁定为困难且[玩家](玩家.md)在死亡后以[旁观模式](旁观模式.md)重生的世界设置。

# 机制
处于极限模式的世界或服务器有以下特征：
* 其[level.dat](level.dat.md)或[server.properties](server.properties.md)中的数据为；
* 其[server.properties](server.properties.md)中的属性（只影响由服务器新创建的世界）或其[level.dat](基岩版存档格式#level.dat.md)中的数据为<code>true</code>。

在[选择世界菜单](选择世界菜单.md)中，极限模式的世界会或。这些世界还会显示独特的边框和图标。

极限模式是一个世界设置，会影响世界中的所有玩家，因此无法为特定的玩家单独开启或关闭极限模式。

# = 创建新的世界 =

在创建新的世界时，“极限”是或，选择该选项即可创建一个极限模式世界。

选定“极限”游戏模式时，[创建新的世界](创建新的世界.md)界面中的”}}“允许命令”和“奖励箱”将被锁定为关，世界的游戏模式被锁定为[生存模式](生存模式.md)，[难度](难度.md)被锁定为困难。不过，世界被创建后可以通过编辑level.dat来更改它们，设置世界游戏模式和难度、解锁难度或开启作弊，且不会受到极限模式的影响。

在选择世界菜单、创建新的世界和编辑世界界面中，极限模式世界的世界图标周围会显示红色边框，右上角或底部会显示一个极限模式红心，它会不时在红色和白色之间闪动。

# = 生命监测 =

|极限模式下的生命条}}

在极限模式的世界中，生命条中的红心的外观会有改变，提醒玩家极限模式的启用。

这个效果是纯粹装饰性的，不会对生命的其他方面有影响。

# = 玩家死亡 =
中极限模式的死亡界面}}
中极限模式的死亡界面}}

在极限模式的世界中，[死亡界面](生命#死亡界面.md)相比非极限模式的死亡界面有所不同，其中的标题“你死了！”变为了“游戏结束！”，且其中的按钮“重生”变为了“旁观世界”。

玩家在死亡后重生在他们的个人重生点，但[游戏模式](游戏模式.md)会变为[旁观模式](旁观模式.md)，无法再对世界做出任何影响，无法被其他活着的玩家观测到，在不作弊的情况下无法改变自己的游戏模式，相当于死亡的玩家被永久移除出了世界，即极限模式中的玩家只有一次生命。这是除锁定创建新的世界参数和改变生命条外观以外，极限模式对游戏内容唯一的真正影响。

玩家在任何游戏模式中死亡重生后都会变为[旁观模式](旁观模式.md)。

若玩家已在极限模式的世界中死亡，则玩家会被添加值为<samp>true</samp>的[标签](基岩版存档格式/实体格式#玩家.md)。该世界在[选择世界菜单](选择世界菜单.md)和编辑世界界面中的世界图标周围会显示灰色边框，右上角或底部的极限模式红心也会变为灰色。

# 你知道吗
[thumb|右|200px|玩笑中的“超极限模式”按钮](File:1DNGn.png.md)

* 玩家可以通过暂停菜单中的“对局域网开放”功能启用作弊，从而绕过创建世界时不能开启作弊的效果，并执行任何[命令](命令.md)。
* 将极限模式的世界降级到[Java版Beta 1.9-pre2](Java版Beta 1.9-pre2.md)之前的版本会导致世界数据中的<code>hardcore</code>丢失，并导致该存档再次升级后不再是极限模式。
* Notch曾经在Twitter表示，会发布一种“超极限”模式，付费玩家如果死亡则会撤销账号。当然，最后证实这是一个玩笑。<ref></ref>
