# 启动器2.1.249x-beta

*页面ID: 65403* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.1.2494-beta**（[Windows](wzh:Microsoft Windows.md)）、**2.1.2495-beta**（[macOS](wzh:macOS.md)）或**2.1.2496-beta**（[Linux](wzh:Linux.md)）是一个[启动器](启动器.md)更新，发布于2019年2月21日，修复了一些漏洞。

# 新内容
* 新的下载系统，可以提高下载的可靠性和速度。

# 修复
*  - 如果<code>%APPDATA%\.minecraft</code>是NTFS连接，启动器就无法更新。
*  - 在英国下载<code>Shuniji.ogg</code>时会被损坏。</onlyinclude>
