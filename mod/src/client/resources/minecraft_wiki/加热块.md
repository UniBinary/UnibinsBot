# 加热块

*页面ID: 34787* | *来源: Minecraft Wiki*

* *加热块（Heat block）**是一种可以融化[雪](雪.md)、[冰](冰.md)和[浮冰](浮冰.md)，但不具有[亮度](亮度.md)的方块。

# 生成
加热块不会生成在世界中。

# 破坏
挖掘加热块的合适工具是镐。加热块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

加热块被破坏后会掉落自身。

# 用途
加热块用于融化2格范围内（[曼哈顿距离](曼哈顿距离.md)）的[雪](雪.md)、[冰](冰.md)和[浮冰](浮冰.md)。
