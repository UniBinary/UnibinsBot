# Java版17w13b

*页面ID: 28810* | *来源: Minecraft Wiki*

<onlyinclude>

* *17w13b**是[Java版1.12](Java版1.12.md)的第3个快照，发布于2017年3月31日<ref></ref>，加入了灰色鹦鹉，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[鹦鹉](鹦鹉.md)**
* 加入了灰色鹦鹉，像是鸡尾鹦鹉。
