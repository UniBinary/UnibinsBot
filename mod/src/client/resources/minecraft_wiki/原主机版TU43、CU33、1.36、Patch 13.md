# 原主机版TU43、CU33、1.36、Patch 13

*页面ID: 67711* | *来源: Minecraft Wiki*

* *TU43/CU33/1.36/Patch 13**是[原主机版](原主机版.md)的一次更新，发布于2016年10月4日。<ref></ref><ref></ref>

# 新内容
# = 常规 =
* *[混搭包](混搭包.md)**
* 加入中国神话混搭包（Chinese Mythology Mash-Up）。
* [XBONE](Xbox One版.md)：在Minecraft商城内加入一个捆绑包的物品，里面包含建筑者组合包和星球大战组合包。

# = 游戏内容 =
* *[音效](音效.md)**
* 加入[北极熊](北极熊.md)、[女巫](女巫.md)、[鱿鱼](鱿鱼.md)、[雪傀儡](雪傀儡.md)、[盔甲架](盔甲架.md)、[牛](牛.md)、[马](马.md)、[物品展示框](物品展示框.md)、[拴绳](拴绳.md)结和[画](画.md)的音效。

* *[附魔](附魔.md)**
* 加入了[冰霜行者](冰霜行者.md)和[经验修补](经验修补.md)两种魔咒。

# = 方块 =
* [末地石砖](末地石砖.md)
* [甜菜](甜菜.md)
* [草径](草径.md)
* * 可以在创造模式物品栏被找到。
* [霜冰](霜冰.md)
* * 可以被精准采集附魔工具采集。
* [岩浆块](岩浆块.md)
* [下界疣块](下界疣块.md)
* [红色下界砖块](红色下界砖块.md)
* [骨块](骨块.md)
* [旗帜](旗帜.md)
* * 有一个自动合成的选项（当开启经典合成界面时使用默认值）。

# = 物品 =

# 更改
# = 常规 =
* 更新所有纹理和混搭包的物品和方块。

# = 游戏内容 =
* *[生命](生命.md)**
* 进食可以恢复生命值。
* *[附魔](附魔.md)**
* 削弱了锋利[魔咒](魔咒.md)。
* *[躺](躺.md)**
* 更改了睡觉动画。

# = 方块 =
* *[金矿石](金矿石.md)**
* [金矿石](金矿石.md)可在恶地的Y=32-79直接生成。

# = 物品 =
* *[硬化黏土](硬化黏土.md)**
* “Stained clay”（染色黏土）现在被命名为“Hardened Clay”（硬化黏土）。例如“White Hardened Clay”（白色硬化黏土）。

# = 生物 =
* *[末影人](末影人.md)**
* 现在可以在[下界](下界.md)生成。

# = 世界生成 =
* *[巨型蘑菇](巨型蘑菇.md)**
* 有机会长得比普通的高两倍。

* *[村庄](村庄.md)**
* 现在与草径一同生成。
* 不再受限于生物群系的边界。
* 现在会在水上生成桥梁。
* 现在有很小的概率使村庄生成为僵尸村庄。
* 农田包括甜菜根在内。

* *[废弃矿井](废弃矿井.md)**
* 现在可在恶地生成。

* *[箱子战利品](箱子战利品.md)**
* 更改宝藏箱的物品（地牢、沙漠神殿、废弃矿井等）。

* *[平原](平原.md)及其变种**
* 现在有概率生成树。
