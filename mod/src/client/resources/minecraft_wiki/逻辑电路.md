# 逻辑电路

*页面ID: 9711* | *来源: Minecraft Wiki*

<!--需要补充蕴含非门-->

* *逻辑电路（Logic Circuit）**或**逻辑门（Logic Gate）**是根据当前输入状态与自身类型，返回对应输出的电路组件。

逻辑门的种类繁多，每种逻辑门也有很多千差万别的构型，各有优缺点，详见[Tutorial:基本邏輯門](Tutorial:基本邏輯門.md)。

# 概念

若期望在输入稳定时输出发生改变，请参见[脉冲电路](脉冲电路.md)；若期望保存输入的某个状态（单个逻辑门无法完成此功能），参见[记忆电路](记忆电路.md)。

逻辑门本身具有少量延迟（可以简单地累加）。有些逻辑门构型的上下边沿延迟不同，则需要分开计算上下边沿的延迟。

若逻辑门的多个输入间延迟差异过大（如一个先到，一个后到），会产生**毛刺**。
* 这是因为逻辑门根据先到的输入计算了输出，再根据后到的输入更新了输出。
* 毛刺可用记忆电路消除。
* 毛刺并不完全负面，甚至可以人为设计毛刺来满足需求。

; 交换输入
除蕴含门、蕴含非门外的二输入逻辑门，交换A端与B端不会影响输出结果。

; 扩展输入
或门、与门、异或门与同或门可通过“二叉树形”级联改造为多输入形式。改造后的多输入形式仍可任意交换输入端。

在Minecraft中，可以直接实现多输入或门和多输入与门。

; 逻辑门的选择
若不清楚应该用哪种逻辑门，你可以像这里一样列出真值表（列出所有输入信号的可能组合以及期望对应的输出），然后可以将你列出的表与下面的表进行对比，看看哪一种符合即可选用。列表也给出了每种运算的对应数学符号。

# 逻辑门
* *逻辑门（Logic Gate）**为最基本的逻辑电路。

# = 非门 =

* *[非门](wzh:邏輯非.md)（NOT Gate）**，即“反相器”。逻辑：
* 若输入真，则输出假。
* 若输入假，则输出真。

会将所输入的真值反相，也就是当输入为假时输出为真，反之亦然。

Minecraft的[红石火把](红石火把.md)就是非门。

# = 或门 =

* *[或门](wzh:邏輯或.md)（OR Gate）**，逻辑：
* **任意**输入为真，则输出真。
* 否则输出假。

可通过二叉树型级联二输入或门来改造为多输入或门。多输入或门仍可任意交换输入端。

在Minecraft中可以直接连接红石线实现或门（线或），但需要注意输入间的串扰（如A输入的信号反向传递到B输入导致串扰）。

# = 或非门 =

* *[或非门](wzh:邏輯或非.md)（NOR gate）**，即反相输出的或门。逻辑：
* **任意**输入为真，则输出假。
* 否则输出真。

多输入或非门一般通过在多输入或门的输入连接一个非门翻转输出来实现。

或非门亦可看作非门的多输入形式。

可以只用或非门实现任意逻辑。

# = 与门 =

* *[与门](wzh:邏輯與.md)（AND gate）**，逻辑：
* **所有**输入为真，则输出真。
* 否则输出假。

可通过二叉树型级联二输入与门来改造为多输入与门。多输入与门仍可任意交换输入端。

在Minecraft中可以通过“非或非”结构直接实现任意输入数量的与门。

与门的典型应用是建造一个可以锁住的门，如果要开门，就需要同时按钮按下以及锁（通常是拉杆）打开的情况下激活按钮。

# = 与非门 =

* *[与非门](wzh:谢费尔竖线.md)（NAND gate）**，即反相输出的与门。逻辑：
* **所有**输入为真，则输出假。
* 否则输出真。

多输入与非门一般通过在多输入与门的输入连接一个非门翻转输出来实现。对于“非或非”结构的多输入或门，则是将逻辑简化为“非或”（“非或非非”，两个非门相互抵消后变为“非或”）。

可以只用与非门实现任意逻辑。

# = 异或门 =

* *[异或门](wzh:邏輯異或.md)（XOR gate）**，逻辑：
* 若输入为真的数量为**奇数**，则输出真，否则输出假。
* * 因此若有奇数个输入发生变动，则输出会发生变动。
* 对于二输入版本，逻辑可简述为“输入是否不同？”。

可通过二叉树型级联二输入异或门来改造为多输入异或门。多输入异或门仍可任意交换输入端。

对于任意同或门，为其奇数个输入添加非门可将其转换为异或门。

异或门一般能满足在多地控制同一机械的需要。控制端（通常为拉杆）用异或门组合，切换任意一个控制端都会改变异或门的输出（类似于现实生活中控制同一个灯泡的[两个开关](Wikipedia:Multiway_switching.md)——你可以用任意一个开关控制灯泡的亮暗）。

# = 同或门 =

* *[同或门](wzh:当且仅当.md)（XNOR gate）**，逻辑为：
* 若输入为真的数量为**偶数**，则输出真，否则输出假。
* * 因此若有奇数个输入发生变动，则输出会发生变动。
* 对于二输入版本，逻辑可简述为“输入是否相同？”。

可通过二叉树型级联二输入同或门来改造为多输入同或门。多输入同或门仍可任意交换输入端。

对于任意异或门，为其奇数个输入添加非门可将其转换为同或门。

# = 蕴含门 =

* *[蕴含门](wzh:實質條件.md)（IMPLIES Gate）**在逻辑学里又称为“实质条件”（可简述为“若A则B”）。逻辑：
* 若输入A为真且输入B为假，则输出假。
* 否则输出真。

蕴含门不能随意交换输入A和输入B。

若1代表真，0代表假，蕴含门亦可理解为“A小于等于B”（A<=B）。

# = 蕴含非门 =

* *蕴含非门（NIMPLY Gate）**是蕴含门的输出再取反。逻辑：
* 若输入A为真且输入B为假，则输出真。
* 否则输出假。

蕴含非门不能随意交换输入A和输入B。

若将现实逻辑电路中的“高阻态”视为0，则蕴含非门和[三态门](wzh:三态逻辑.md)等效。

在Minecraft中，红石比较器能直接作为蕴含非门使用。

# 你知道吗
非、或、或非和与非这四种逻辑任选其二都可以实现所有逻辑，还可以仅用其中的或非逻辑和与非逻辑实现所有逻辑。
