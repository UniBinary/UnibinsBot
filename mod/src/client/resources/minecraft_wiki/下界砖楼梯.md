# 下界砖楼梯

*页面ID: 56724* | *来源: Minecraft Wiki*

* *下界砖楼梯（Nether Brick Stairs）**是[下界砖块](下界砖块.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
下界砖楼梯会自然生成于[下界要塞](下界要塞.md)中。

# 破坏
挖掘下界砖楼梯的合适工具是镐。下界砖楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

下界砖楼梯被破坏后会掉落自身。
