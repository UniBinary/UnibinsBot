# Java版1.15.1

*页面ID: 50576* | *来源: Minecraft Wiki*

* *1.15.1**是的一次次要更新，发布于2019年12月17日<ref></ref>，优化了游戏性能，并修复了一些漏洞。此版本不兼容1.15的服务端。

# 更改
# = 常规 =
* *性能**
* 优化了[区块](区块.md)的渲染性能，特别是对于拥有很多不同的[方块](方块.md)状态的区块。
* *网络处理**
* 改进了无效的[生物群系](生物群系.md)ID的网络处理。

# 修复
空指针异常。

* *其他漏洞**
* 修复了一个由自定义刷怪笼生成村民导致的滥发到游戏的日志文件的错误。
* 修复了Realms界面崩溃的问题。
