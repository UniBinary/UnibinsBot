* *行商羊驼（Trader Llama）**是[羊驼](羊驼.md)的独特变种，一般伴随着[流浪商人](流浪商人.md)生成。

# 生成
流浪商人总会与2只被[拴绳](拴绳.md)拴着的行商羊驼同时生成。

不对着行商羊驼使用的刷怪蛋生成的行商羊驼总是成年的<ref></ref>；而使用刷怪蛋生成的幼年行商羊驼概率为10%。

使用[刷怪蛋](刷怪蛋.md)或[命令](命令.md)生成的流浪商人也会自带2只行商羊驼。

行商羊驼生成后有47999刻的存留时间（实体数据），比流浪商人少1刻。时间减少到0时行商羊驼会被强制清除。行商羊驼被玩家拴住或骑乘时，倒计时暂停；若处于已驯服状态便不再会消失。

被流浪商人拴住的行商羊驼会在拴绳断裂后变得能够被自然清除。

# 掉落物
成年行商羊驼死亡后会掉落以下物品：

}}
* 已装备的和。
* [物品栏](物品栏.md)内的任何物品。
* ，若被[玩家](玩家.md)或驯服的[狼](狼.md)杀死。

杀死幼年行商羊驼不会掉落任何物品或经验。

# 行为

行商羊驼可以走上1格高的方块而无需跳跃。

与大多数生物不同的是，行商羊驼可以缓慢地恢复损失的生命值。

# = 吐唾沫 =

如果行商羊驼受到攻击，它会试图逃离攻击者，停止逃跑后朝攻击者吐一口唾沫，造成的伤害（无论是否被驯服，无论是否成年）。与大多数会反击目标至死亡的生物不同，行商羊驼只会吐一次唾沫，无论是否命中都不会再继续攻击，但被吐中的生物有可能反击行商羊驼。当它们向攻击者吐唾沫时，有时会因为误击同类而导致一群行商羊驼互相攻击；它们不会因为误伤而互相攻击。当[难度](难度.md)为和平时，行商羊驼不会攻击玩家。

行商羊驼会主动攻击未驯服的[狼](狼.md)。行商羊驼会基于它们的强度（实体数据）击退狼。遇到强度为4或5的行商羊驼，狼总会逃跑；<ref></ref>对于较弱的行商羊驼，狼则会时不时相应地逃跑。

在没有被激怒的情况下，行商羊驼不会攻击驯服的狼。但如果玩家驯服了正在被行商羊驼攻击的狼，行商羊驼仍会继续攻击。

行商羊驼会主动攻击[僵尸](僵尸.md)、[溺尸](溺尸.md)、[尸壳](尸壳.md)、[僵尸村民](僵尸村民.md)和[灾厄村民](灾厄村民.md)。

当牵住行商羊驼的流浪商人被攻击时，行商羊驼会向攻击者持续吐唾沫，直到目标死亡；如果行商羊驼所在区块卸载，重新加载后行商羊驼只会尝试向原目标吐一次唾沫。行商羊驼只会向攻击者吐两次唾沫。

# = 牵引 =
当一只行商羊驼被[拴绳](拴绳.md)拴住时，附近最多10只[羊驼](羊驼.md)或行商羊驼（无论是否被驯服，无论是否成年）会以一定的顺序跟随该行商羊驼，形成一支驼队。虽然每支驼队可容纳的羊驼或行商羊驼数量有限，但玩家还可以再拴住一只形成另一支驼队。

如果驼队中的一只行商羊驼突然死亡或被传送到范围外，排在其后面的所有羊驼或行商羊驼都会脱节并且不再跟着驼队；这种情况会导致驼队成员的顺序有变动，但不会脱节。

如果被拴绳拴住的行商羊驼与其他实体连接，则不会形成驼队。

# = 驯服 =
成年行商羊驼可以被驯服。骑乘行商羊驼直到心形[粒子](粒子.md)出现即为成功驯服。行商羊驼被驯服后，玩家可以通过骑着行商羊驼打开物品栏来查看它的物品栏UI，或者在时对着行商羊驼来打开。

驯服难度取决于行商羊驼的值（好感度），好感度越高的行商羊驼越容易驯服。行商羊驼好感度的初值为0，最高值为30。当玩家骑上未驯服的行商羊驼时，会随机生成一个范围在0到29内的数。行商羊驼在好感度高于该数值时被驯服，否则玩家会被弹下驼背，并且好感度+5。喂食行商羊驼亦能增加好感度，详见[下文](#喂食.md)。

自然生成的行商羊驼为未驯服的，玩家也无法骑上去，当拴绳断裂后，行商羊驼才可被骑乘并驯服；流浪商人拴着的行商羊驼是已驯服的，但仅当拴绳断裂后才能被骑乘并查看UI。

与其他可驯服生物一样，驯服的行商羊驼死亡时会给世界中的所有玩家显示一条[死亡消息](死亡消息.md)，而不会<ref></ref>。

已驯服的行商羊驼不能被装备[鞍](鞍.md)，因此玩家无法通过骑乘控制它们移动。

# == 装饰 ==
已驯服的行商羊驼拥有用于装备1个[地毯](地毯.md)的槽位，不同颜色的地毯产生的装饰样式不同。

可以通过命令在行商羊驼的<code>armor.body</code>槽位装备地毯。

玩家可使用[剪刀](剪刀.md)将行商羊驼上身的地毯剪下。

行商羊驼的纹理上有一种独特的蓝色装饰样式，这种样式可以通过给行商羊驼装备任意地毯来覆盖掉，但不能将其去除。

状态下的行商羊驼仍会显示其身上的地毯。

# == 储存 ==
手持[箱子](箱子.md)对着已驯服的行商羊驼能装备上箱子，并根据强度（实体数据）给出3、6、9、12或15格的物品栏空间。物品栏空间数量的算法是3*。

玩家无法卸下行商羊驼身上的箱子，除非它们死亡。

# = 喂食 =
手持食物对着行商羊驼可给其喂食。下表罗列出了行商羊驼可食用的食物和其对行商羊驼的效果。

行商羊驼会跟随/手持干草捆的玩家。

# == 繁殖 ==

给生命值已满的两只已驯服的行商羊驼喂食干草捆，可以使它们进入[繁殖](繁殖.md)模式。

两只行商羊驼繁殖时，会产下一只幼年行商羊驼。幼年行商羊驼需要20分钟成长为成年个体，给其喂食小麦或干草捆可以加速其成长。

对幼年行商羊驼[金蒲公英](金蒲公英.md)可以阻止其成长为成年行商羊驼，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年行商羊驼无法被喂食除金蒲公英外的其他物品。

一只羊驼和一只行商羊驼繁殖时，有均等概率产下一只幼年羊驼或幼年行商羊驼。

一只羊驼和一只行商羊驼繁殖时，会产下一只幼年羊驼。

每次繁殖后掉落，双亲进入/的冷却时间，之后才能继续繁殖。

幼年羊驼或行商羊驼的毛色会等概率地遗传自其双亲之一。繁殖出的幼年行商羊驼有着小号的行商羊驼样式。

繁殖出的幼年羊驼的强度则是在1和较强双亲的强度间取一个随机整数，这个数有3%的概率会加1，但最大值仍然是5。查看下表以快速参考具体概率。

以较强双亲的某一行为基准，其对应的列中的数据显示各种子代强度的可能性。
