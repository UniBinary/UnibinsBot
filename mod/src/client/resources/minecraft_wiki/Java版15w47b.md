# Java版15w47b

*页面ID: 18998* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w47b**是[Java版1.9](Java版1.9.md)的第42个快照，发布于2015年11月19日<ref></ref>，加入了新的音效，并修复了[15w47a](15w47a.md)中的问题。

# 新内容
# = 方块 =
* *[酿造台](酿造台.md)**
* 当酿造完成时有新的音效。
* 使用音效事件：<code>block.brewing_stand.brew</code>

# = 生物 =
* *[女巫](女巫.md)**
* 当空闲，死亡，饮用药水，抛出药水和受到伤害时有新的音效。
* 使用<code>entity.witch</code>中的音效：<code>ambient</code>，<code>death</code>，<code>drink</code>，<code>throw</code>和<code>hurt</code>
* *[潜影贝](潜影贝.md)**
* 当空闲，死亡，壳关闭时受到攻击，导弹被击中以及导弹命中时有新的音效。
* 使用<code>entity.shulker</code>中的音效：<code>ambient</code>，<code>death</code>和<code>close</code>以及<code>entity.shulker_bullet</code>中的音效：<code>hurt</code>和<code>hit</code>
* *[兔子](兔子.md)**
* 杀手兔攻击时有新的音效。
* 使用音效事件：<code>entity.rabbit.attack</code>
* *[马](马.md)**
* 被玩家喂食时有新的音效。
* 使用音效事件：<code>entity.horse.eat</code>
* *[守卫者](守卫者.md)**
* 防御荆棘攻击时有新的音效。
* 使用音效事件：<code>entity.guardian.thorns</code>

# = 非生物实体 =
* *[船](船.md)**
* 放置船时有新的音效。
* 使用音效事件：<code>block.boat.place</code>

# = 游戏内容 =
* *[伤害](伤害.md)**
* 当受到暴击，击退，格挡，强攻击, 横扫攻击以及弱攻击时有新的音效。
* 使用<code>entity.player.attack</code>中的音效：<code>crit</code>，<code>knockback</code>，<code>nodamage</code>，<code>strong</code>，<code>sweep</code>和<code>weak</code>

* *[盾牌](盾牌.md)**
* 格挡时有新的音效。
* 使用音效事件：<code>entity.shield.block</code>

# 更改
# = 方块 =
* *[信标](信标.md)**
* 效果持续时间基于信标的等级，为9秒+每级2秒（之前是固定的9秒）。

# = 物品 =
* *[箭](箭.md)**
* 现在会在创造模式玩家身上弹开，而不是之前直接穿过。

* *[剪刀](剪刀.md)**
* 现在破坏任何方块时都会损失耐久（之前只会在破坏[叶子](叶子.md)，[蜘蛛网](蜘蛛网.md)，[草](草.md)，[藤蔓](藤蔓.md)，[绊线](绊线.md)和[羊毛](羊毛.md)时损失耐久）。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 精准采集不再能在生存模式附加到[剪刀](剪刀.md)上。
* * 这使得蜘蛛网变得不可获得。
