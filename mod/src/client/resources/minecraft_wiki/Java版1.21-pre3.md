# Java版1.21-pre3

*页面ID: 121300* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21-pre3**是[Java版1.21](Java版1.21.md)的第3个预发布版，发布于2024年6月5日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[魔咒实体效果类型](魔咒数据格式#实体效果.md)**
* 将<code>replace_disc</code>重命名为<code>replace_disk</code>。
