# Java版1.9.1-pre2

*页面ID: 20520* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.9.1-pre2**是[Java版1.9.1](Java版1.9.1.md)的第2个预发布版，发布于2016年3月10日<ref name="blogpost_1.9.1-pre2"></ref><ref></ref>。

# 更改
# = 物品 =
* *[运输矿车](运输矿车.md)和[漏斗矿车](漏斗矿车.md)**
* 现在物品栏名称和物品对应。

# = 游戏内容 =
* *战斗**
* 当武器攻击冷却时间为75%或更高时，忽略武器攻击冷却时间（之后在正式版中恢复）。
* 护盾在受到较弱攻击（以下伤害）时不会受到损坏。

# 修复

* *其他漏洞**
* 修复了寻路代码导致崩溃的漏洞（并发修改异常）。<ref name="blogpost_1.9.1-pre2"/></onlyinclude>
