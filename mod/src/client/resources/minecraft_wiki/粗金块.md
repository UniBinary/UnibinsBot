# 粗金块

*页面ID: 81411* | *来源: Minecraft Wiki*

* *粗金块（Block of Raw Gold）**是用于储存[粗金](粗金.md)的方块。

# 生成
粗金块不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘粗金块的合适工具是镐。粗金块需要铁镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

粗金块被破坏后会掉落自身。

# 用途
粗金块主要用于储存粗金。

# = 合成材料 =

# = 猪灵 =
在非和平[难度](难度.md)下，无论玩家是否装备了[金质盔甲](盔甲.md)，成年[猪灵](猪灵.md)看见或听见玩家破坏粗金块后会与之敌对。
