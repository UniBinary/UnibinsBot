# 基岩版1.5.0.0

*页面ID: 34331* | *来源: Minecraft Wiki*

<onlyinclude>
* *beta 1.5.0.0**是[1.5.0](基岩版1.5.0.md)的首个测试版，发布于2018年4月25日<ref></ref>，加入了第一人称视角下使用[激流](激流.md)三叉戟的动画，更改了一些[水域更新](水域更新.md)（第一部分）的特性，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[附魔](附魔.md)**
* [激流](激流.md)
* * 加入了第一人称视角下使用激流[三叉戟](三叉戟.md)的动画。

# 更改
# = 物品 =
* *[鹦鹉螺壳](鹦鹉螺壳.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

* *[三叉戟](三叉戟.md)**
* 现在可以附上[经验修补](经验修补.md)和[耐久](耐久.md)魔咒。

# = 生物 =
* *[海豚](海豚.md)**
* 对其喂食[生鳕鱼](生鳕鱼.md)或[生鲑鱼](生鲑鱼.md)现在可以带领玩家到最近的[海底废墟](海底废墟.md)或[沉船](沉船.md)。

* *[溺尸](溺尸.md)**
* 现在可以手持鹦鹉螺壳生成。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[尸壳](尸壳.md)**
* 现在溺水后会变成[僵尸](僵尸.md)。

* *[骷髅马](骷髅马.md)**
* 现在可在水下骑乘。

* *[骷髅](骷髅.md)和[流浪者](流浪者.md)**
* 在水下时现在会使用近战攻击。

* *[亡灵生物](亡灵生物.md)**
* 现在会沉没且能在水下行走。

# = 非生物实体 =
* *[船](船.md)**
* 更改了使用键鼠控制船只的转向方式，按键向前移动，按向后移动。

# = 游戏内容 =
* *[附魔](附魔.md)**
* [激流](激流.md)
* * 更新了玩家旋转纹理。

* *[游泳](游泳.md)**
* 改进了玩家在水面游泳的动作。

# 修复
* *修复了51个漏洞**
* 修复了大部分游戏时经常出现的崩溃。
* 游玩Truffletop Town地图时，使用鞘翅和烟花火箭飞行时游戏崩溃。
* 生存模式下无法使用拾取方块功能。
* 在游泳时，玩家无法使用触摸屏里的“向下飞行”来浮上水面。
* 使用镐破坏珊瑚时，现在会掉落失活的珊瑚；使用精准采集的镐破坏珊瑚时会掉落自身。
* 海豚只会显示空闲动画。
* 生存模式下，配方书里没有显示烟花火箭的合成配方。
* 鱼在离开区块渲染的最大距离后重新回来时消失。
* 现在可以正常清除物品。
* 在对按键重新映射后，首次鼠标点击现在可以正常运作。
* 在没有旧存档可以同步的情况下弹出的信息现在会正确显示。
* 可以对被玩家骑乘的马绑上拴绳或者气球。
* 在携带版UI下，使用键鼠操作无法正常显示附魔台上的魔咒名称。
* 盔甲在被生物破坏后仍会显示。
* 在Realms里恢复备份内容或替换世界时，资源包和行为包不能正常启用或禁用。
* “信任玩家等级”选项更改后无法保存。
* 海带的纹理显示不正确。
* 使用命令时，梯子被视作带有碰撞箱的隐形方块。
* 透过水下的玻璃观察时不能看见水面。
* 潜行或跳跃进入水中后会阻止向上跳跃或游泳的动作。
* 双门的显示不正确。
* 海晶石楼梯的纹理出错。
* 在创造模式下放置旗帜会使其被消耗。
* 拾取方块功能不会给予正确变种的按钮和压力板。
* 在较高渲染范围内的玻璃在特定角度下渲染出现问题。
* 在结构里生成的僵尸村民的移速太快。
* 无法食用生鱼。
* 头部贴紧冰游泳可以恢复氧气值。
* 溺尸腿部的顶层出现灰色线。
* 在VR设备里，三叉戟不会朝着玩家注视的方向扔出。
* 按下“默认设置”按钮现在只会影响已选的输入设备。
* 从生存模式切换为创造模式后，个人游戏模式不会随之切换。
* 玩家距离末影龙太远时会使得末影龙冻结。
* 使用发射器给海带发射骨粉时，现在会消耗骨粉。
* 掉落物不会穿过上半部分台阶的底部空隙。
* 在商店界面搜索时，缩略图、游戏模式和世界模板不会显示。
* 附魔台里的书本纹理会覆盖建议的魔咒名称。
* 高大白桦树不会在高大白桦森林生物群系里生成。
* 船上的生物会360°旋转其头部。
* 贴近水面时，从特定角度观察水面不会使其被渲染。
* 无法使用喷溅水瓶来使得陆地上的海豚保持湿润。
* 在水下放置方块时，控制器没有按键提示。
* 浮岛上面不会生成草或者积雪。
* 无法正常生成风蚀恶地生物群系。
* 从一个矿车跳到另一个矿车时出现问题。
* 玩家在岸上附近游泳并退出世界时，重新进入世界后会使得玩家在陆地上游泳。
* 创造模式下，玩家在水下飞行时不再能将方块悬浮放置。
* 骑乘生物时不再能使用激流魔咒。
* 冰山、海草和海带不再替代海底神殿的组成方块而生成。
* 三叉戟的附魔光效在第一人称模式下不正确。
* 在蓄力时，第一人称下的三叉戟的朝向不正确。</onlyinclude>
