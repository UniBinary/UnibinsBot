# 蓝花美耳草

*页面ID: 81648* | *来源: Minecraft Wiki*

* *蓝花美耳草（Azure Bluet）**是一种[小型花](小型花.md)。

# 生成

# = 自然生成 =
蓝花美耳草会在[平原](平原.md)、[向日葵平原](向日葵平原.md)、[繁花森林](繁花森林.md)、[草甸](草甸.md)、[溶洞](溶洞.md)和[深暗之域](深暗之域.md)生物群系自然生成。

蓝花美耳草也会在[林地府邸](林地府邸.md)中生成。

# = 骨粉 =
在可自然生成蓝花美耳草的生物群系中对[草方块](草方块.md)[骨粉](骨粉.md)后，蓝花美耳草有概率代替[矮草丛](矮草丛.md)生成。

对着不[含雪](含雪.md)的蓝花美耳草使用骨粉会出现更多的蓝花美耳草，而不会出现草丛。

# 破坏
蓝花美耳草被挖掘时会立刻被破坏。

蓝花美耳草被破坏后会掉落自身。

# = 合成材料 =

# = 谜之炖菜 =

使用蓝花美耳草合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家/的[失明](失明.md)效果。

# = 堆肥 =
将蓝花美耳草放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
