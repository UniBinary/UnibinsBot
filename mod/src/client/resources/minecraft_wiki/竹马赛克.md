# 竹马赛克

*页面ID: 99125* | *来源: Minecraft Wiki*

* *竹马赛克（Bamboo Mosaic）**是一种由[竹台阶](竹台阶.md)合成的装饰性方块。

# 生成
竹马赛克不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘竹马赛克的合适工具是斧。

竹马赛克被破坏后会掉落自身。

# 用途
# = 合成材料 =

# = 燃料 =
竹马赛克可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个竹马赛克可以烧炼1.5个物品。
