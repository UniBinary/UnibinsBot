# Java版18w31a

*页面ID: 35706* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w31a**是[Java版1.13.1](Java版1.13.1.md)的第3个快照，发布于2018年8月1日<ref name="18w31a"></ref>，加入了骨粉的一些新特性，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[骨粉](骨粉.md)**
* 在暖水海洋生物群系的水中使用[骨粉](骨粉.md)有概率使[珊瑚](珊瑚.md)生长。

# = 实体 =
* *[鱼](鱼.md)**
* 在被杀死时有5％概率掉落[骨粉](骨粉.md)。

# = 命令格式 =
* *NBT[标签](Java版标签.md)**
* 加入了方块[标签](Java版标签.md)<code>minecraft:underwater_bonemeals</code>。

* ***
* 在游戏中加入了强制加载区块的概念和一个命令（）来开启及关闭强制加载。

# 更改
# = 方块 =
* *潮涌核心**
* [潮涌核心](潮涌核心.md)的充水现在正确了。

# = 实体 =
* *鱿鱼**
* [鱿鱼](鱿鱼.md)现在仅生成于河流和海洋，而非任何水体中。

# = 命令格式 =
* ***
* [记分板](记分板.md)的计算符号<code>%=</code>从Java原本的<code>%</code>被更改为<code>Math.floorMod</code>。这使计算时使用floored [modulo](wikipedia:Modulo_operation.md)，而不是truncated [modulo](wikipedia:Modulo_operation.md)，所以现在<code>-1 % 7</code>会得出6而不会是-1。<ref>https://www.reddit.com/r/Minecraft/comments/93pmai/minecraft_snapshot_18w31a/e3fkwrj</ref>

# = 常规 =
* *性能**
* 对性能进行了优化。

* *[函数](Java版函数.md)**
* 函数解析错误日志中的行号现在以1开头（为0）。
