# 基岩版1.17.0.52

*页面ID: 81704* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.17.0.52**是[基岩版1.17.0](基岩版1.17.0.md)的第6个测试版，发布于2021年4月28日<ref></ref>，将部分特性从[实验性玩法](实验性玩法.md)中移出，并修复了一些漏洞。

# 更改
# = 方块 =
* *常规**
* [紫晶芽](紫晶芽.md)、[紫水晶簇](紫水晶簇.md)、[紫水晶块](紫水晶块.md)、[紫水晶母岩](紫水晶母岩.md)、[杜鹃花丛](杜鹃花丛.md)及其变种、[杜鹃树叶](杜鹃树叶.md)及其变种、[大型垂滴叶](大型垂滴叶.md)、[铜块](铜块.md)及其变种、[方解石](方解石.md)、[铜矿石](铜矿石.md)、[深板岩](深板岩.md)及其变种、[深层矿石](深层矿石.md)、[滴水石块](滴水石块.md)、[缠根泥土](缠根泥土.md)、[垂根](垂根.md)、[避雷针](避雷针.md)、[苔藓块](苔藓块.md)、[覆地苔藓](覆地苔藓.md)、[孢子花](孢子花.md)、[粗金属块](粗金属块.md)、[平滑玄武岩](平滑玄武岩.md)、[遮光玻璃](遮光玻璃.md)和[凝灰岩](凝灰岩.md)不再属于[实验性玩法](实验性玩法.md)。

* *[炼药锅](炼药锅.md)**
* 现在在下雪时会逐渐填充细雪。

* *[圆石](圆石.md)和[深板岩圆石](深板岩圆石.md)**
* 现在可在[铁砧](铁砧.md)上用于修复石质工具。

* *[荧光物品展示框](荧光物品展示框.md)**
* 现在放置在其中的[地图](地图.md)会被增亮。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[滴水石锥](滴水石锥.md)**
* 现在滴水石锥上方方块被破坏后会产生方块更新并一同破坏滴水石锥。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[小型垂滴叶](小型垂滴叶.md)**
* 现在可以种植在[苔藓块](苔藓块.md)上。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[石头](石头.md)、[安山岩](安山岩.md)、[闪长岩](闪长岩.md)和[花岗岩](花岗岩.md)**
* 不再可以在铁砧上用于修复石质工具，以同步。

# = 物品 =
* *常规**
* [紫水晶碎片](紫水晶碎片.md)、[铜锭](铜锭.md)、[荧光墨囊](荧光墨囊.md)、[望远镜](望远镜.md)、[发光浆果](发光浆果.md)、[美西螈刷怪蛋](美西螈刷怪蛋.md)、[发光鱿鱼刷怪蛋](发光鱿鱼刷怪蛋.md)和[山羊刷怪蛋](山羊刷怪蛋.md)不再属于[实验性玩法](实验性玩法.md)。

* *[粗金属](粗金属.md)**
* 现在开采[铁矿石](铁矿石.md)、[金矿石](金矿石.md)或[铜矿石](铜矿石.md)后所掉落的粗金属数量受[时运](时运.md)魔咒影响。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[细雪桶](细雪桶.md)**
* 现在可通过对着装有细雪的炼药锅使用[铁桶](铁桶.md)获得。

# = 生物 =
* *[美西螈](美西螈.md)**
* 现在可以对美西螈投掷[喷溅](喷溅型水瓶.md)或[滞留型水瓶](滞留型水瓶.md)以湿润其身体。
* 更改了生成机制，现在最大生成高度为Y=63而不是Y=30。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[发光鱿鱼](发光鱿鱼.md)**
* 更改了生成机制，现在最大生成高度为Y=63而不是Y=30。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[山羊](山羊.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

* *[雪傀儡](雪傀儡.md)和[炽足兽](炽足兽.md)**
* 现在对其投掷喷溅或滞留型水瓶会对其造成伤害。

# = 世界生成 =
* *[紫晶洞](紫晶洞.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

# = 常规 =
[thumb|新的加载界面](File:Bedrock 1.17 Updated Loading Screen.png.md)
* *用户界面**
* 更新了加载界面的外观。

# = 技术性 =
* *[附加包](附加包.md)和脚本引擎**
* 加入了用于获取默认骨骼动画的MoLang查询。
* 更新了根据指定参数返回标准化物品剩余使用时间的MoLang查询。

# 修复
* *洞穴与山崖特性**
* 美西螈现在会正常播放所有音效。（）
* 美西螈现在会更频繁地游泳。（）
* 现在种植在苔藓块上的树苗可被催熟为树木。（）
* 圆石和深板岩圆石现在可用于修复石质工具。（）
* 现在炼药锅在下雪时会逐渐填充细雪。（）
* 更改了发光地衣的纹理以匹配Java版。（）
* 发光地衣现在在地图上显示为普通方块的颜色。（）
* 现在杜鹃树叶和盛开的杜鹃树叶在地图上显示为正确的颜色。
* 现在放置于荧光物品展示框中的地图会被正确增亮。（）
* 现在涂蜡的氧化切制铜台阶可以正确合并成双台阶了。

* *常规**
* 使用移动数据网络的玩家又可以在多人游戏中邀请好友了。（）

* *图形**
* 在开启Education Edition选项的世界中，暂停并回到游戏不再导致化学物品图标丢失。
* 修复了所有生物群系均使用相同的水下迷雾效果，且随着时间流逝不会提高视野亮度的问题。（和）
* 开启[实验性玩法](实验性玩法.md)（Caves & Cliffs子选项）后，河流和陆地类生物群系中的水下视野将会提升以匹配Java版。

* *方块**
* 告示牌上带有颜色的文本不再会不可见。（）

* *物品**
* 船现在只会在其船身碰到仙人掌才会被破坏。（）
* 更改了拉弓时其在屏幕上的位置以匹配之前版本。（）
* 弩现在会在玩家或生物的主手上正确渲染。（）
* 修复了玩家切换其主手物品时副手上的盾牌会播放装备动画的问题。（）
* 清空过药水的炼药锅现在会正确收集雨水。
* 修复了使用任意一种染料即可合成各种颜色的烟花火箭的问题。（）

* *生物**
* 现在对烈焰人和末影人投掷喷溅型或滞留型水瓶会对其造成伤害。（）
* 修复了开启[实验性玩法](实验性玩法.md)（Caves & Cliffs子选项）后Y=0以下处不会生成生物的问题。（）
* 实体落入水中时又会播放音效了。

* *Android平台**
* Android玩家现在可以看到邀请和成就提示。（）

* *游戏内容**
* 修复了部分方块在加快随机刻后生长速度过快的问题。

* *命令**
* 现在旧世界中不可执行命令，之前执行过该命令的旧世界会将世界出生点更改至初始出生点。（）</onlyinclude>
