# 生存模式

*页面ID: 6404* | *来源: Minecraft Wiki*

[375px|缩略图|Minecraft的生存模式，可以看到[[生命](File:Survival.png.md)条、[饥饿](饥饿.md)条、经验条和快捷栏]]

* *生存（Survival）**模式是[Minecraft](Minecraft.md)中的一种[游戏模式](游戏模式.md)。在该模式中，玩家必须要收集资源、建造建筑、和[怪物](怪物.md)战斗、进行[饥饿](饥饿.md)管理和探索世界来生存和发展。

# 游戏内容
[thumb|200px|[[工作台](File:Crafting Table.png.md)，生存模式中对于任何玩家必备的方块]]

在生存模式中，[玩家](玩家.md)拥有一个[物品栏](物品栏.md)用于收集[物品](物品.md)。物品可以按特定的[配方](配方.md)组合起来，用于制造[工具](工具.md)和其他物品。这就是所谓的[合成](合成.md)。大部分合成需要[工作台](工作台.md)来进行，而一小部分的物品可以用物品栏内2×2的合成方格进行合成。一些物品不能通过普通合成来获取，这就需要[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或[高炉](高炉.md)来[烧炼](烧炼.md)。还有一些方块提供更高级的用途，比如[酿造台](酿造台.md)、[铁砧](铁砧.md)、[锻造台](锻造台.md)、[制图台](制图台.md)、[织布机](织布机.md)、[砂轮](砂轮.md)和[附魔台](附魔台.md)。

[thumb|200px|基本的生存模式物品栏](File:Inventory.png.md)

在生存模式中，玩家会受到环境和[敌对生物](敌对生物.md)的伤害（除非是[和平](和平.md)难度）。如果玩家受到足够的伤害，玩家会[死亡](生命#死亡.md)并回到其世界出生点或重生点（已绑定的[床](床.md)或充能的[重生锚](重生锚.md)旁边）。

当一个世界被创建后，如果开启了“”选项，则可以通过命令、命令、命令}}或中的[游戏模式切换器](游戏模式切换器.md)、中的设置来切换到生存模式。在[多人游戏](多人游戏.md)中，[管理员](管理员.md)可以通过命令单独切换每一名玩家的游戏模式。新玩家的默认游戏模式也能通过中的命令或中的设置中默认游戏模式来切换。

# = 目标 =

[thumb|250px|在生存模式中玩家会在像这样的[[洞穴](File:Big Cave Entrance.png.md)里找到发展用的大部分资源]]

尽管Minecraft是一个没有预定义目标的游戏，但是它有一个基本玩法，就是“寻宝游戏”。在努力建造和扩展他们的庇护所的同时，玩家们收集各种[物品](物品.md)和资源，通过很多物品来获得其他物品从而提升玩家们的能力，攻击和防御。经过一些时间，玩家会来到其他[维度](维度.md)（包括[下界](下界.md)和[末地](末地.md)）从而达到他们的目标。

玩家可以在生存模式内前往[末地](末地.md)击败[末影龙](末影龙.md)后达到“一个恰当的结局”，但这并不意味着游戏结束；末影龙死亡后，玩家会获得一个奖杯物品（即[龙蛋](龙蛋.md)），大量的[经验](经验.md)，之后观看[胜利屏幕](胜利屏幕.md)并阅读[终末之诗](终末之诗.md)，离开末地，开始进一步的发展。玩家还可以挑战另外一个可选的Boss——[凋灵](凋灵.md)，这个Boss可以在生存模式中后期时挑战。玩家还可以自己制定一些其他的目标并尝试达成；此外，有一些玩家有一个共同的目标——获得游戏内的所有或。

在[基岩版](基岩版.md)中，玩家能在[超平坦](超平坦.md)以外的世界且在[作弊](作弊.md)和操作员权限关闭的情况下在生存模式中获得[成就](成就.md)。如果玩家创建一个[创造模式](创造模式.md)世界后切换至生存模式，那么无法获得成就。在[Java版](Java版.md)中，玩家可以在任意模式中完成[进度](进度.md)。

# = 单人生存模式（） =
单人生存模式是Minecraft最早出现的，也是默认的游戏模式。只要玩家已经下载好了[游戏文件](.minecraft.md)，SSP就可以离线或在线游玩。

# = 多人生存模式（） =
[thumb|250px|两个玩家在多人生存模式内一起建造一个庇护所](File:BuildCollaboration.png.md)

多人生存模式允许多个玩家连接到一个Minecraft[服务器](服务器.md)。这使得玩家可以相互交流，共同合作（或[PvP](Tutorial:PvP.md)）以实现他们的生存目标。
