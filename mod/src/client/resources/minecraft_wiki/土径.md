# 土径

*页面ID: 15157* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *土径（Dirt Path）**是一种装饰性方块。

# 生成
# = 自然生成 =
土径会作为[村庄](村庄.md)的道路生成。

# = 转化 =
土径可以通过对上方为空气的[草方块](草方块.md)、[泥土](泥土.md)、[砂土](砂土.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)或[缠根泥土](缠根泥土.md)的侧面或顶部任何类型的[锹](锹.md)来制造。每次制造土径都会使[锹](锹.md)消耗1点耐久。

# 获取

土径的[方块物品](方块物品.md)无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，土径可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

土径被具有[精准采集](精准采集.md)的工具挖掘破坏后会掉落自身。

# 破坏
挖掘土径的合适工具是锹。

土径被破坏后总是会掉落1个[泥土](泥土.md)。

土径被不具有[精准采集](精准采集.md)的工具破坏后会掉落1个泥土，当被具有精准采集的工具挖掘破坏后则会掉落自身。

# 用途
土径主要用于装饰，生物无法在其上生成。土径的颜色和[沙漠](沙漠.md)或[热带草原](热带草原.md)生物群系中的[草方块](草方块.md)相近。土径的高度只有完整方块的，。

土径方块上方如果紧邻或，将变成泥土，但所有[栅栏门](栅栏门.md)和除外。

对着土径[锄](锄.md)可将其犁成[耕地](耕地.md)。
