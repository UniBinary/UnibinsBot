* *3D Shareware v1.34**是一个[愚人节玩笑](愚人节玩笑.md)版本，官方亦称**Minecraft 3D**和**MineCraft 3D: Memory Block Edition**<ref>https://www.instagram.com/p/BvtyNKjn2zR/</ref>，发布于2019年4月1日。<ref name="3d"/>此版本中有许多仿20世纪90年代电子游戏的元素。本次更新是[19w13b](19w13b.md)的分支版本。

# 更改
# = 方块 =
* *[木桶](木桶.md)**
[right|frameless|256x256px|class=pixel-image](File:Barrel 3DShareware.gif.md)
* 类似于[火球](火球.md)，在木桶上有2D[伪三维](wzh:偽三維#看板.md)模型的[火](火.md)，它总是面向玩家。
* 特定情况下会产生爆炸：
* * 关闭一个木桶时，如果木桶为空则会发生爆炸，否则木桶会不停地发出关闭UI的声音。爆炸不会摧毁方块。
* * 向木桶射箭，木桶会爆炸。不像关闭空木桶产生的爆炸，此爆炸会摧毁方块。
* 会在世界中随机生成。通过此方式生成的木桶也被称为“奖励桶”（见下）。
* * 生成时会带有<code>bonus_barrel</code>战利品表，此表可包含名为*BFC9000*的附魔[多重射击](多重射击.md)的弩和1-12支箭以及不同类型的附魔盔甲和武器、随机效果的药水箭以及随机效果的药水（喷溅药水和滞留药水）。

# 你知道吗
* 此版本的数据版本和[19w13b](19w13b.md)的相同，协议版本与[13w42a](13w42a.md)和[13w42b](13w42b.md)的相同，但都不兼容。
* 此版本创建的唯一世界被称为“MoJang Presents”，并保存在shareware目录下（从其他版本可以看见）。
* 按下重载资源时会暂时显示没有滤镜时的游戏画面。更改语言或资源包会移除加载界面的阴影。
* jar文件中<code>assets/minecraft</code>文件夹下面的<code>sound.sys</code>文件是一个Printfox图像，包含Minecraft开发者团队的合照，此照片在吃下“3D”物品后显示。
* 不同颜色的钥匙（如打开*蓝色*的门）有翻译文本。
* 文件<code>loading.png</code>有启动/退出游戏时的文本。在图像的下方，可以看见“Cheeky!”，而此单词不会在正常游戏中显示。
* 如果内部服务器把玩家踢出，游戏仍然会显示多人游戏选择界面，但此界面正常来讲是不能打开的（因为是演示模式）。这可以通过使用手动触发。
* 加载界面中的“Loading MINECRAF.WAD”的文字指的是文件格式（[.wad](wikipedia:.wad.md)），其经常用于《》及其续作《》的数据存储。根据此版本的背景故事，Minecraft 3D很可能在《毁灭战士》首次发布的1年后（即1995年）制作完成的。
* * 为还原当时流行的DOS系统的转换，上述文字中的文件名称<code>MINECRAFT.WAD</code>变为<code>MINECRAF.WAD</code>。
* 红色、黄色和蓝色钥匙参考自《毁灭战士》和《毁灭战士II》，它在整个关卡设计中大量使用了三钥匙系统。IDKFA作弊码也是从《毁灭战士》来的，与其功能类似，此作弊码在游戏中输入后会给予玩家三把钥匙。在木桶内找到的名为BFC9000的弩最有可能是对《毁灭战士》的另一个参考，因为《毁灭战士》中有一个非常强大的武器叫做BFG9000。
* 退出界面的“Thank you for playing MineCraft 3D”（感谢你游玩MineCraft 3D）文本参考了《》中的“Thank you for playing Wing Commander.”（感谢你游玩银河飞将。）实际上它把错误信息隐藏并以感谢信息替代。<ref>https://www.gamasutra.com/view/news/249475/More_dirty_coding_tricks_from_game_developers.php</ref>
* 当Mojang徽标显示时播放的声音名称是<code>awesome_intro</code>，而这个音效文件的名称是<code>bim_bom.ogg</code>。
* “Boss模式”参考自90年代中某些游戏所包含的键盘快捷键“老板键”。当按下“老板键”时，游戏会弹出空白终端或某一生产力程序的虚假屏幕，意在隐藏用户在工作时间玩游戏的事实。
* 如果在正常版本中（[18w44a](18w44a.md)及以后）载入3D Shareware v1.34的存档，原来的物品、生命值、饥饿值等会保留，但一些3D Shareware v1.34独有的物品会被删除，不可撤销。
* * 且原来生成的木桶会被转换成空的木桶（位置与原位置相同）。
* 在游玩时重载资源，如果此时[快捷栏](快捷栏.md)存有[物品](物品.md)，则在重载资源界面会显示这些物品。
