* *荧石（Glowstone）**是出现在[下界](下界.md)的发光[方块](方块.md)。

# 生成
# = 自然生成 =
[缩略图|在[[下界](File:GlowstoneInNether.png.md)自然生成的荧石堆]]

荧石会以[荧石堆](荧石堆.md)的形式自然生成在[下界](下界.md)的[下界岩](下界岩.md)、[黑石](黑石.md)和[玄武岩](玄武岩.md)天花板的底部。

# 破坏
没有工具可以加速对荧石的挖掘。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，荧石被破坏后会掉落2-4个[荧石粉](荧石粉.md)。挖掘工具的时运魔咒会使荧石额外等概率掉落0-<魔咒等级>个荧石粉，但掉落总数不会超过4个。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，荧石被破坏后会掉落自身。

# 用途
生物无法生成在荧石上；只有生成不受光照等级限制的生物才可以生成在荧石上。

# = 光源 =
荧石会发出亮度为15级的光。

# 你知道吗
* 在下界较矮的天花板上生成的荧石可能会与地面接触。
* 当荧石被放置在离地面9格或以上的地方时（超出荧石的照明范围），荧石会投下一个阴影，虽然它是发光方块。
