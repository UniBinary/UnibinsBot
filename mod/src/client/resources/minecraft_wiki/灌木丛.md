# 灌木丛

*页面ID: 43356* | *来源: Minecraft Wiki*

* *灌木丛（Bush）**是一种装饰性方块。

# 生成
# = 自然生成 =
灌木丛会在[平原](平原.md)、[风袭丘陵](风袭丘陵.md)、[风袭沙砾丘陵](风袭沙砾丘陵.md)、[风袭森林](风袭森林.md)、[河流](河流.md)、[冻河](冻河.md)、[森林](森林.md)、[桦木森林](桦木森林.md)和[原始桦木森林](原始桦木森林.md)以斑块形式自然生成。

# = 骨粉 =
对着灌木丛使用骨粉会在[曼哈顿距离](曼哈顿距离.md)为1的随机可种植方块上生成一个新的灌木丛。

# 破坏
灌木丛被挖掘时会立刻被破坏，用于挖掘的工具的耐久度不会下降。

没有被[剪刀](剪刀.md)或具有[精准采集](精准采集.md)的工具挖掘破坏时，灌木丛被破坏后不会掉落。

被剪刀或具有精准采集的工具挖掘破坏时，灌木丛被破坏后会掉落自身。

# 用途
灌木丛可以种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。

# = 堆肥 =
将灌木丛放入[堆肥桶](堆肥桶.md)里有30%的概率增加1个堆肥层。
