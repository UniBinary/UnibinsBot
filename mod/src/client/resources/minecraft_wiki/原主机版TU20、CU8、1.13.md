* *TU20/CU8/1.13**是[原主机版](原主机版.md)的一次更新，发布于2015年1月16日，修复了一些漏洞。<ref></ref><ref></ref>

# 更改
# = 常规 =
* *[纹理包](纹理包.md)**
* 更改了城市纹理包中阳光传感器的纹理，使之更像是一个太阳能电池板了。

# = 方块 =
* *[草方块](草方块.md)**
* 如果“生物破坏”被关闭，羊就不会使草方块变成泥土。

# = 生物 =
* *[女巫](女巫.md)**
* 女巫能罕见地在黑暗的地方生成。

# = 非生物实体 =
* *[矿车](矿车.md)**
* 更改了矿车的行为，使玩家可以在矿车上转弯。

# = 游戏内容 =
* *[生成](生成.md)**
* 更新时马和其他动物消失会考虑[鞍](鞍.md)、[马鞍包](儲物箱#驴、骡、羊驼的物品栏.md)、[拴绳](拴绳.md)、[盔甲](盔甲.md)和。
* *[交易](交易.md)**
* 图书管理员出售命名牌的概率变得很小。

# = 世界生成 =
* *[下界](下界.md)**
* 罕见地生成骷髅和凋灵骷髅。

# 修复
* *修复了26个漏洞**
* 修复各种红石漏洞。
* 修复了破坏上面放有地图的物品展示框时崩溃的漏洞。
* 修复了当发射器被阻塞时发射器正在发射水或熔岩时会崩溃的漏洞。
* 修复了将船放置在不良表面上导致游戏崩溃的漏洞。
* 修复了石砖楼梯的配方。
* 修复了玩家可以在他们的生命条已是零心情况下存活的漏洞。
* 修复了冒险模式下主机选项菜单中导致选项设置错误的漏洞。
* 修复动物被击中后不停止奔跑的漏洞。
* 修复了摧毁种植的南瓜和西瓜梗会掉落不正确数量的种子的漏洞。
* 修复了当难度从和平设置为简单时凋灵骷髅停止在下界生成的漏洞。
* 修复了尽管关闭了“TNT 爆炸”选项，但TNT矿车还是会爆炸的漏洞。
* 修复了音符盒的扩音范围，以便可以在更远的地方听到它们。
* 修复了骑行时玩家的腿没有正确旋转的漏洞。
* 修复了狼的治疗工具提示。
* 修复了当玩家拿着拴绳并瞄准攻击型生物时显示不正确的工具提示。
* 修复了具有不正确命名空間的虚弱药水效果描述。
* 修复了苦力怕离地悬浮的漏洞。
* 修复了命名标签在凋灵、铁傀儡和凋灵骷髅上无法正常工作的漏洞。
* 修复了玩家名称没有被着色的漏洞。
* 修复了骑马时马没有渲染的漏洞。
* XB360：修复了save运输的漏洞。
* XBONE：修复了“还治彼身”成就在满足其要求后未解锁的漏洞。
* XBONE：修复了在完成"本地的酿造厂"的条件时未解锁成就。
* XBONE：修复了在大型丛林生物群系中移动时的性能问题。
* PS3：修复了万圣节纹理包纹理的问题。
* PS4：修复了在大型丛林生物群系中移动时的性能问题。
