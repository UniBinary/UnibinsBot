# 用途

Shazboots!与[锁链靴子](锁链靴子.md)相似，但不可烧炼。

装备Shazboots!后，玩家获得的[](Shazboots!（状态效果）.md)效果，但需要按住或移除该装备才能发挥效果。

装备Shazboots!后，玩家不站在地面上时会立刻失去[跳跃提升](跳跃提升.md)效果。

装备Shazboots!后，在地面上的玩家长按时可以进行蓄力，此时经验条也会被蓄力条取代。当玩家松开跳跃键时将立刻获得时间为的跳跃提升效果，等级为玩家的每刻水平方向位移变化量×7.5+1（向下取整），通过此方式获得的跳跃提升效果不会显示粒子效果，也不会显示图标。玩家松开跳跃键时也会进行跳跃，即蓄力条进度越大，松开跳跃键后跳跃的高度越高。

# = 外观 =
