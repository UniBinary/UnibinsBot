# 西瓜种子

*页面ID: 7361* | *来源: Minecraft Wiki*

* *西瓜种子（Melon Seeds）**是一种用来种植[西瓜](西瓜.md)的[物品](物品.md)。

* *西瓜茎（Melon Stem）**是西瓜种子种植在[耕地](耕地.md)上形成的方块，成熟后可在相邻且合适的空方块处生成西瓜。

# 生成
# = 自然生成 =
西瓜茎会自然生成在[热带草原](热带草原.md)和[沙漠](沙漠.md)类型的[村庄](村庄.md)里[农田](农田.md)结构的[耕地](耕地.md)上。

# 破坏
西瓜茎被挖掘时会立刻被破坏。

西瓜茎被破坏后会掉落0–3个西瓜种子，每个值的掉落概率取决于西瓜茎的生长阶段。

# 用途
# = 种植 =
西瓜和南瓜种植}}

对[耕地](耕地.md)的顶面西瓜种子可种植出西瓜茎。[亮度](亮度.md)等级≥9时，西瓜茎才能生长到下一个阶段。

西瓜茎会经历8个生长阶段，成熟后会尝试在相邻的空方块生成[西瓜](西瓜.md)，要求该方块下方是[泥土](泥土.md)、[草方块](草方块.md)、[耕地](耕地.md)、[砂土](砂土.md)、[灰化土](灰化土.md)、[菌丝体](菌丝体.md)、[缠根泥土](缠根泥土.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[泥巴](泥巴.md)或[沾泥的红树根](沾泥的红树根.md)。如果相邻的方块已经有了一个西瓜，该西瓜茎只会在原有的西瓜被移除后结出新的西瓜。

西瓜茎在湿润的耕地上生长得更快。对西瓜茎[骨粉](骨粉.md)会使其增加2-5个生长阶段，忽视亮度等级。已有巢且采集了花粉的[蜜蜂](蜜蜂.md)飞过西瓜茎时，西瓜茎也有概率增加1个生长阶段。以上述方式催熟西瓜茎并不会使之直接长出西瓜。

# = 繁殖 =
与其他种子相同，西瓜种子可用于吸引及繁殖[鸡](鸡.md)，也可喂食给幼年鸡以减少其10%的剩余成长时间。

# = 驯服 =
与其他种子相同，西瓜种子可用于驯服[鹦鹉](鹦鹉.md)。

# = 堆肥 =
将西瓜种子放入[堆肥桶](堆肥桶.md)中有30%的概率增加一层堆肥层。

# 西瓜茎
* *西瓜茎（Melon Stem）**是西瓜种子种植在耕地上后产生的方块。它会从地下开始逐渐成长为一条完整的茎。西瓜茎起初是绿色的，成熟时则是棕色的。

西瓜茎结出西瓜后便会弯曲。一条成熟的西瓜茎会连接旁边由该西瓜茎生长出来的西瓜，这意味着成熟的西瓜茎有5种可能的状态。如果西瓜茎旁边有多个可以连接的西瓜，其连接方向的优先顺序将依次为东、西、北和南。如果茎旁边没有任何西瓜，它就会恢复直立的状态。

西瓜茎是一种不可以作为[物品](物品.md)获取的[技术性方块](技术性方块.md)。

可以通过编辑[物品栏](物品栏.md)或者添加[附加包](附加包.md)来获取西瓜茎。
