* *鸡蛋（Egg）**是一种由[鸡](鸡.md)产下的[物品](物品.md)。

* *蓝色鸡蛋（Blue Egg）**和**棕色鸡蛋（Brown Egg）**分别是由寒带鸡和热带鸡产下的鸡蛋变种。

* *掷出的鸡蛋（Thrown Egg）**是投掷鸡蛋时产生的[弹射物](弹射物.md)。

# 获取
# = 生物 =
除了属于[鸡骑士](鸡骑士.md)一部分的鸡，成年[鸡](鸡.md)每5-10分钟下一颗鸡蛋。鸡所产下的鸡蛋类型取决于其变种：温带鸡下普通鸡蛋，寒带鸡下蓝色鸡蛋，热带鸡下棕色鸡蛋。

成年[狐狸](狐狸.md)自然生成时有或的概率在嘴里叼着普通鸡蛋，且其死亡时叼着的鸡蛋总是会掉落。

# 用途
# = 投掷 =
鸡蛋可以将其投掷出去，生成弹射物。

[发射器](发射器.md)也可以射出鸡蛋。

# 行为
掷出的鸡蛋是一种[弹射物](弹射物.md)，可以触发[标靶](标靶.md)。

掷出的鸡蛋会受到重力影响和环境阻力的影响。

# = 着火 =
掷出的鸡蛋可以[着火](着火.md)。掷出的鸡蛋在穿过[火](火.md)或[熔岩](熔岩.md)会着火，穿过[雨](雨.md)或[水](水.md)时会熄灭。

着火的掷出的鸡蛋会不受阻碍地穿过[TNT](TNT.md)并使其激活，可以点燃熄灭的[营火](营火.md)，可以破坏其穿过的[细雪](细雪.md)。着火的鸡蛋会点燃其命中的实体。

# = 造成伤害 =
掷出的鸡蛋在直接击中实体时，会对其造成伤害。该伤害可以产生击退。虽然不能对大多数生物的生命值造成影响，生物仍然会将其视为一种攻击行为并做出相应的反应。

和[末影龙](末影龙.md)的受伤害行为使其免疫掷出的鸡蛋造成的伤害。<ref></ref>

# = 生成鸡 =
掷出的鸡蛋击中物体并破裂后，有的概率生成一只幼年鸡（即平均每8个鸡蛋里有1个会生成出幼年鸡）。如果掷出的鸡蛋能够生成幼年鸡，则其又有的概率额外再生成3只幼年鸡（即平均每256个鸡蛋里有1个会生成出4只幼年鸡）。因其他因素消失的掷出的鸡蛋不会生成鸡。

生成的幼年鸡变种取决于鸡蛋的变种，普通鸡蛋、蓝色鸡蛋和棕色鸡蛋分别生成温带鸡、寒带鸡和热带鸡。

# = 与方块交互 =
掷出的鸡蛋可以触发其击中的[标靶](标靶.md)、敲响[钟](钟.md)或击塌[大型垂滴叶](大型垂滴叶.md)。

掷出的鸡蛋可以激活[木质压力板](木质压力板.md)和[绊线](绊线.md)。当掷出的鸡蛋穿过这些方块时，这些开关会保持开启状态。其他开关则不受掷出的鸡蛋的影响。

# 你知道吗
* 鸡蛋会在被其他弹射物撞到时破坏，但生成幼年鸡的概率不会被影响。
* 对着[下界传送门](下界传送门.md)丢鸡蛋会使它在撞到传送门时破坏。
