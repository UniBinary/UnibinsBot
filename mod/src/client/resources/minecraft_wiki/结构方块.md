# 结构方块

*页面ID: 17934* | *来源: Minecraft Wiki*

* *结构方块（Structure Block）**是用于放置和手动操作[结构](结构.md)的方块。

# 生成
结构方块不会生成在世界中。部分结构包含结构方块，但这些结构方块在自然生成时被转换为了其他物体，使结构方块不会生成在世界中。

使用结构方块加载包含结构方块的结构会正常地生成结构方块。

# 获取

结构方块无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，结构方块可以通过”，或“”中有结构方块）|JE}}、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
结构方块不能被挖掘破坏。

结构方块被破坏后不会掉落。

# 用途
结构方块不可被[生存模式](生存模式.md)下的玩家破坏，也不可被[凋灵](凋灵.md)和[末影龙](末影龙.md)破坏，其爆炸抗性和基岩相同。

对结构方块按下键可以打开其界面。只有处于[创造模式](创造模式.md)且拥有适当权限的玩家才能打开结构方块界面。若被命名，结构方块会在突出显示时在其上方显示名字，名字跟在方块模式后面（如“保存：房子”）。

结构方块的物品形式使用一个方块形式不会使用的“空”的纹理。

保存在内存中的结构比保存在磁盘上的同名结构有更高的优先级。只有在内存中的结构卸载后，磁盘上的同名结构才能被加载。

结构方块可以切换模式来改变工作方式，在切换模式时会尽可能保留结构方块的设置。

部分模式下的结构方块允许接收红石信号来触发其工作，此时的结构方块是[机械元件](红石元件#机械元件.md)，可被下列形式激活：
* 毗邻的开启的**[电源](红石元件#电源.md)**（例外：[红石火把](红石火把.md)不会激活其所附着的结构方块，[侦测器](侦测器.md)只会激活指向的结构方块）。
* 毗邻的**[充能方块](红石电路/充能与激活.md)**。
* 毗邻的指向结构方块且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)（包括结构方块上方的红石粉）；毗邻但未指向结构方块的红石粉不会激活结构方块。

在同一红石刻内，电容器更新阶段前存在，但在电容器更新阶段被取消的信号无法激活结构方块。

多数模式具有这些选项：

; 模式
   这个选项被用于更改当前模式。
   点击模式按钮会切换模式。需要按住Alt时点击才能切换成数据模式。
   模式选择是一个下拉菜单，可以选择其中的选项。

; 结构名称
   希望操作的结构的[命名空间ID](命名空间ID.md)。只能使用命名空间ID允许的[合法字符](命名空间ID#合法字符.md)。
   若不指定命名空间，则默认为或。

; 相对位置
   从结构方块本身所处的位置计算，输入X、Y、Z值以设置结构轮廓的起始坐标。
   对于任何方向，结构方块允许的最大尺寸是或。
   默认为X=0，Y=1，Z=0。
   默认为X=0，Y=-1，Z=0。

;
   恢复所有参数回到打开界面时的值。

结构方块的界面会实时渲染结构区域的场景，可以拖动并改变角度，但不能缩放。

# = 加载模式 =

 **加载模式（Load Mode）**的结构方块可以向世界中生成结构。

加载模式的结构方块在被红石激活时，会尝试以其中被配置的内容加载结构，并自动先进行初始化。

结构加载可以指定加载动画，使加载将不再是在一刻内完成的，而是随着时间逐渐生成。
* 一旦开始加载，即使破坏结构方块也不会停止加载过程。
* 这个过程可能会破坏结构中由多个部分构成的方块（如[床](床.md)、[门](门.md)或[高草](高草.md)），破坏结构中需要依附其他方块的方块（如[火把](火把.md)），或导致[水](水.md)、[熔岩](熔岩.md)、[火](火.md)的溢出和蔓延。

加载模式的结构方块包含以下选项：

; 结构名称
   将要加载的结构名称。
   游戏中原本就存在许多结构，这些结构处于<版本号>.jar中<code>-{}-/data/minecraft/structure/*<文件夹名称>*</code>里，只需输入<code>-{}-*<文件夹名称>*/*<结构名称(无后缀名)>*</code>即可被加载模式的结构方块使用。
   存在下列文件夹：
  * <code>-{}-[ancient_city](ancient_city.md)</code>
  * <code>-{}-[bastion](bastion.md)</code>
  * <code>-{}-[end_city](末地城.md)</code>
  * <code>[fossil](fossil.md)</code>
  * <code>[igloo](雪屋.md)</code>
  * <code>-{}-[nether_fossils](下界化石.md)</code>
  * <code>-{}-[pillager_outpost](掠夺者前哨站.md)</code>
  * <code>-{}-[ruined_portal](废弃传送门.md)</code>
  * <code>[shipwreck](沉船.md)</code>
  * <code>-{}-[trail_ruins](trail_ruins.md)</code>
  * <code>-{}-[trial_chambers](试炼密室.md)</code>
  * <code>-{}-[underwater_ruin](海底废墟.md)</code>
  * <code>-{}-[village](village.md)</code>
  * <code>-{}-[woodland_mansion](林地府邸.md)</code>

; 相对位置
   将要加载的结构的起始位置。

; 显示边框
   高亮显示即将加载区域的轮廓。

; 及种子
   根据输入的种子，在生成时只生成部分方块。
   完整性数值越低，生成的方块越少。
   未生成方块的位置，位置上原本的方块会被保留。
   完整性数值仅允许0.0到1.0范围内，默认为1.0。
   完整性数值仅允许0.0到100.0范围内，默认为100.0。

; 包括实体
   加载结构中保存的[实体](实体.md)。
   默认或。

;
   加载结构时，使可含水方块在加载区域的水源方块上可以加载为含水方块。否则，可含水方块会取代水源方块而加载为普通方块。
   但由于一个漏洞，在关闭该选项时会导致部分位置本应加载为普通方块，实际上加载为具有一定含水方块特性，却不真正含水的方块，具体表现为可以像水源一样减速玩家，外观上和普通的含水方块一致，却不像水源方块一样流出水，也不判定为含水方块的特殊方块。
   默认关闭。

   默认关闭。

;
   选择结构加载时的动画。

角落模式的结构方块在被红石激活时会从内存中卸载当前结构。

# = 数据模式 =

 **数据模式（Data Mode）**是一个已经被弃用的模式，其功能现已由[拼图方块](拼图方块.md)代替，但仍在一些原版结构中使用。数据模式的结构方块只能在自然生成的过程中发挥作用，其用作运行特定硬编码函数的位置标记。

数据模式的结构方块在被红石激活时没有效果。

数据模式的结构方块只在自然生成的过程中有实际作用。使用结构方块加载这些结构将会正常生成数据模式的结构方块。

它们通过其元数据所标注的位置来运行，它只能被用于指定相关结构的一个函数。该结构方块之后删除。
* 直接放在要保存的任意方块的周围。
* 当这个结构首次被替换的时候，这个数据是错误的。

数据模式的结构方块包含以下选项：

; 自定义数据标签名称
   方块实体的名称。
   可用的值包括:
  ; **[雪屋](雪屋.md)**
  : "chest" - 将该结构方块下的箱子的[战利品表](战利品表.md)设为"chests/igloo_chest"，此外，该表种子取决于世界种子。
  ; **[末地城](末地城.md)**
  : "Chest" - 将该结构方块下的箱子的战利品表设为"chests/end_city_treasure"，此外，该表种子取决于世界种子。
  : "Sentry" - 在该结构方块的位置生成[潜影贝](潜影贝.md)。
  : "Elytra" - 在该结构方块的位置生成带有[鞘翅](鞘翅.md)的[物品展示框](物品展示框.md)实体。
  ; **[林地府邸](林地府邸.md)**
  : "ChestSouth" - 设置要替代该结构方块的箱子的战利品表为"chests/woodland_mansion"，并将战利品表种子设置为取决于世界种子。
  : "ChestNorth" - 设置要替代该结构方块的箱子的战利品表为"chests/woodland_mansion"，并将战利品表种子设置为取决于世界种子。
  : "ChestEast" - 设置要替代该结构方块的箱子的战利品表为"chests/woodland_mansion"，并将战利品表种子设置为取决于世界种子。
  : "ChestWest" - 设置要替代该结构方块的箱子的战利品表为"chests/woodland_mansion"，并将战利品表种子设置为取决于世界种子。
  : "Mage" - 在该结构方块的位置生成[唤魔者](唤魔者.md)。
  : "Warrior" - 在该结构方块的位置生成[卫道士](卫道士.md)。

# = 3D输出模式 =

 **3D输出模式（3D Export Mode）**的结构方块类似于存储模式，但结构将被输出为<code>.glb</code>文件格式的3D渲染而不是实际的结构。

该模式只能在Windows版本中使用，在其他版本中处于此模式的结构方块会变成默认的保存模式，且无法通过重置恢复。

导出时，会弹出一个Windows文件资源管理器窗口引导用户存储导出的文件。

通过这种方式导出的3D渲染与预览图中的实时渲染是基本一致的——包括所有不正确剔除的方块表面。

尝试导出包含[末地传送门方块](末地传送门方块.md)、[下界传送门方块](下界传送门方块.md)等的结构时只能得到一个静态纹理的方块。

这种方式导出的<code>.glb</code>文件可以用3D Viewer<ref>https://www.microsoft.com/p/3d-viewer/9nblggh42ths</ref>或Paint 3D<ref>https://www.microsoft.com/p/paint-3d/9nblggh5fv99</ref>应用查看，但游戏不能从<code>.glb</code>文件中加载结构。

此模式不支持导出实体。同时，被导出的部分方块在3D Viewer或Paint 3D中无法正常显示，例如活塞臂、箱子、床等。

3D输出模式的结构方块在被红石激活时没有效果。

3D输出模式的结构方块包含以下选项：

; 相对位置
   将要输出为3D渲染的结构的起始位置，与[保存模式](#保存模式.md)中同样的选项的用法一致。

; 结构大小
   输入X、Y、Z坐标来设置与相对位置坐标的距离，与保存模式中同样的选项的用法一致。
   最大为64×384×64。

; 移除方块
   输出3D渲染时，不在其中包含任何[方块](方块.md)。
   默认关闭。

; 显示边框
   高亮显示即将加载区域的轮廓。
   默认开启。

; 导出
   执行导出并输出<code>.glb</code>文件。
