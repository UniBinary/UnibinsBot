# Java版标签/魔咒

*页面ID: 161611* | *来源: Minecraft Wiki*

* *魔咒标签（Enchantment Tags）**是[魔咒](魔咒.md)的组合。

# 使用
魔咒标签用于控制魔咒的出现条件和一些基本功能。

# 当前版本

# = curse =
* 在提示框中以红色文本显示且不可被祛魔的魔咒。

# = double_trade_price =
* 需要花费双倍绿宝石交易的魔咒。

# = exclusive_set/armor =
* 不能在盔甲上共存的魔咒。

# = exclusive_set/boots =
* 不能在靴子上共存的魔咒。

# = exclusive_set/bow =
* 不能在弓上共存的魔咒。

# = exclusive_set/crossbow =
* 不能在弩上共存的魔咒。

# = exclusive_set/damage =
* 不能共存的伤害增幅类魔咒。

# = exclusive_set/mining =
* 不能共存的挖掘类魔咒。

# = exclusive_set/riptide =
* 不能与[激流](激流.md)共存的魔咒。

# = in_enchanting_table =
* 会出现在[附魔台](附魔台.md)里的魔咒。

# = non_treasure =
* 非宝藏类魔咒。

# = on_mob_spawn_equipment =
* 会出现在随机生成生物所穿装备上的魔咒。

# = on_random_loot =
* 会出现在战利品箱子内的战利品上的魔咒。

# = on_traded_equipment =
* 会出现在交易中的附魔装备上的魔咒。

# = prevents_bee_spawns_when_mining =
* 使工具破坏蜂巢和蜂箱后不会释放激怒状态的蜜蜂的魔咒。

# = prevents_decorated_pot_shattering =
* 使工具不会打破[饰纹陶罐](饰纹陶罐.md)的魔咒。

# = prevents_ice_melting =
* 使工具不会将[冰](冰.md)打破成[水](水.md)的魔咒。

# = prevents_infested_spawns =
* 允许工具破坏[虫蚀方块](虫蚀方块.md)而不生成其中生物的魔咒。

# = smelts_loot =
* 使掉落的战利品经过[烧炼](烧炼.md)的魔咒。

# = tooltip_order =
* 影响在物品[提示框](提示框.md)中所显示魔咒的顺序。

# = tradeable =
* 会出现在交易中的附魔书上的魔咒。

# = treasure =
* 宝藏类魔咒。
