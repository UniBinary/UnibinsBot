# 基岩版1.16.20.50

*页面ID: 65605* | *来源: Minecraft Wiki*

<onlyinclude>
* *beta 1.16.20.50**是[基岩版1.16.20](基岩版1.16.20.md)的首个测试版本，发布于2020年6月25日<ref></ref>，加入了[猪灵蛮兵](猪灵蛮兵.md)并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了[猪灵蛮兵](猪灵蛮兵.md)刷怪蛋。

# = 生物 =
* *[猪灵蛮兵](猪灵蛮兵.md)**
* 比[猪灵](猪灵.md)更加强大的变种。
* 生成于[堡垒遗迹](堡垒遗迹.md)。
* 不会被金质物品吸引。
* [玩家](玩家.md)无论是否装备金质[盔甲](盔甲.md)，都会受到其攻击。
* 可在生成时携带[金斧](金斧.md)。
* 生成时不会装备任何盔甲。

# 更改
# = 方块 =
* *[绯红木板](绯红木板.md)和[诡异木板](诡异木板.md)**
* 现在被放置或踩踏时会发出木质方块的音效。

* *[熔炉](熔炉.md)**
* 现在破坏熔炉会掉落其内积累的[烧炼](烧炼.md)经验。

* *[灵魂营火](灵魂营火.md)**
* 将其[亮度等级](亮度等级.md)调整为10。

* *[垂泪藤](垂泪藤.md)和[缠怨藤](缠怨藤.md)**
* 现在攀爬时会发出音效。

* *[墙](墙.md)**
* 现在会与打开的[活板门](活板门.md)连接。
* 现在会与[玻璃](玻璃.md)连接。

# = 物品 =
* *[下界合金](下界合金.md)物品**
* 现在会在[熔岩](熔岩.md)表面漂浮。

* *[下界合金盔甲](下界合金盔甲.md)**
* 现在装备时会发出独特的音效。

* *[骨粉](骨粉.md)**
* 现在对[花](花.md)或[草丛](草丛.md)使用骨粉时，如果不会长出新的植物，就不会消耗骨粉。

# = 生物 =
* *[猪灵](猪灵.md)**
* 不再会自然生成在[菌光体](菌光体.md)上。
* 现在会在和平[难度](难度.md)下生成。

* *[疣猪兽](疣猪兽.md)**
* 不再会在和平难度下攻击距其过近的玩家。

* *[僵尸疣猪兽](僵尸疣猪兽.md)**
* 现在拥有独立的音效。

# 修复
* *修复了42个漏洞**
* 幼年猪现在会正确地消失。
* 海豚、鱼类和鱿鱼现在又能够在气泡柱中生成了。（）
* 生物的生成最大半径现在是44格。（）
* 墙现在会与打开的活板门连接。（）
* 墙现在会与玻璃连接。（）
* 破坏熔炉现在会掉落其内积累的烧炼经验。（）
* 西瓜和南瓜的茎现在又会在其下的方块被移除时被破坏了。（）
* 现在对花或草丛使用骨粉时，如果不会长出新的植物，就不会消耗骨粉。（）
* 凋灵的生命值剩余一半时，其血条不再会异常地显示为空。（）
* 船不再会被无碰撞箱的实体拖慢速度。（）
* 洞穴环境音效不再会在商城页面播放了。
* 由活塞推动的黏液块现在又会正确地将玩家弹射出去了。（）
* 修正了灵魂营火的亮度等级。（）
* 攀爬藤蔓现在有音效了。（）
* 修复了放置下界疣块的音效。
* 修复了绯红、诡异木质系列方块的放置和踩踏音效。（）
* 疣猪兽不再会在和平难度下攻击离其过近的玩家。（）
* 猪灵不再会自然生成在菌光体上。
* 驯服的狼不再会在从下界传送门返回主世界时消失。
* 猪灵现在会在和平难度下生成。
* 下界合金物品不再会在熔岩中弹跳。（）
* 装备下界合金盔甲现在会发出独特的音效。（）
* 僵尸疣猪兽的音效现在不再与猪相同。（）
* 制作人员名单的滚动速度不再受帧率影响。
* 用定位废弃传送门不再会返回占位符文本。（）
* 破坏菌核所需的时间现在与菌柄相同。（）
* 新增的下界生物群系、方块与结构不再是生成于固定版本的世界当中。（）
* 看向猪灵时不再会显示“打开”的工具提示。（）
* 猪灵的双臂动作现在与玩家更相似，而不再与僵尸相似。（）
* 猪灵端详金锭时被一击杀死会掉落该金锭。
* 修复了世界重新加载期间，猪灵端详物品时的重复物品相关问题。
* 熔岩中的下界合金物品不再会在重新加载世界时消失。（）
* 更新了猪灵的图形和模型文件，修复了物品被幼年人-{}-形生物拿起时的显示尺寸问题。
* 石英块不再能通过用熔炉烧炼雕纹石英块和石英柱获得。
* 石英砖现在在切石机上只能通过加工石英块获得。
* 标靶的环对应的红石信号强度不再会因为箭的旧版几何属性而出错。
* 游戏不再不停试图绘制信标UI中的下界合金锭。
* 在下界更新前的锁定的版本内容中在灵魂沙上面点火不再产生充当占位符的灵魂火。<!--Setting Soul Sand on fire no longer produces a placeholder Soul Fire block on Pre Nether version locked content -->
* 在给予猪灵金锭后，在其观察金锭的时候重新进入世界时，猪灵不再掉落整组金锭，而是从战利品表中抽取一项物品掉落。
* 猪灵不再捡起整组的金质物品。（）
* 凋灵的血条现在会在玩家从其他维度返回时正常重新显示。
* 猪灵在生成时不再会装备附魔盔甲。
* 尸壳现在对铁盔甲的喜好程度高于锁链盔甲。
* 玩家不再能与幼年猪灵互动。
* 修复了用绯红或诡异木台阶合成木桶的配方。</onlyinclude>
