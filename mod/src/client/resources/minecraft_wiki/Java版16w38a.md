# Java版16w38a

*页面ID: 24815* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w38a**是[Java版1.11](Java版1.11.md)的第6个快照，发布于2016年9月20日<ref></ref>，加入了2条新的游戏规则。

# 新内容
# = 命令格式 =
* ***
* 加入了<code>doWeatherCycle</code>参数。
* * 这会决定天气是否会变化。
* * 默认为开启。
* 加入了<code>maxEntityCramming</code>参数。
* * 默认为。
* ** 如果一个实体试图推动超过24个实体时，它就会开始窒息。（包括推走矿车，即矿车不会窒息，但推走矿车的怪物或玩家会窒息。）
* ** 死亡消息是：<实体>在墙里窒息而亡。
* * 设置成可以停用这个规则。
* * 只会影响生物和玩家。

# 更改
# = 方块 =
* *[圆石墙](圆石墙.md)和[苔石墙](苔石墙.md)**
* 从[创造模式](创造模式.md)物品栏的“建筑方块”栏移动到了“装饰性方块”栏。

* *[耕地](耕地.md)**
* 使用选取耕地时，耕地不再变为[泥土](泥土.md)，而是直接选取耕地本身。

# = 物品 =
* *[药水](药水.md)**
* 具有丢失或者无效的药水效果的药水现在会被默认为无法合成的药水（Uncraftable Potion），没有附魔[光效](光效.md)并且呈品红色。
* * 这也适用于滞留药水、喷溅药水和药箭。
* * 由于没有标签的水瓶被更名为无法合成的药水，创造物品栏中的酿造图标也相应改变。

* *[鞘翅](鞘翅.md)**
* 装备在[骷髅](骷髅.md)，[僵尸](僵尸.md)和[盔甲架](盔甲架.md)身上时呈可见状态。

# = 生物 =
* *[守卫者](守卫者.md)和[远古守卫者](远古守卫者.md)**
* 如果在着火时死亡，则会掉落[熟鱼](鱼.md)而不是[生鱼](鱼.md)。
* 只有被玩家杀死才能获得的稀有掉落不受影响。

* *[兔子](兔子.md)**
* [生兔肉](生兔肉.md)的掉落现在会被抢夺[魔咒](魔咒.md)影响。

* *骷髅和僵尸[马](马.md)**
* [骨头](骨头.md)和[腐肉](腐肉.md)的掉落现在分别为0-2个，并且会受到抢夺[魔咒](魔咒.md)的影响。

# = 游戏内容 =
* *[钓鱼](钓鱼.md)**
* [墨囊](墨囊.md)现在为10个1点权重，而不是1个10点。

# = 常规 =
* *[聊天](聊天.md)**
* 信息可以有256个字节而不是100个。
