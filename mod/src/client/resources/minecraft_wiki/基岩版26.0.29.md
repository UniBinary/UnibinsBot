# 基岩版26.0.29

*页面ID: 183766* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 26.0.29**（ChromeOS/Android）、**Preview 26.0.29**（Windows/Xbox/iOS/iPadOS/PlayStation）是[基岩版26.0](基岩版26.0.md)的第6个测试版，发布于2026年1月20日<ref></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[北极熊](北极熊.md)**
* 现在成年北极熊再次会攻击靠近幼年北极熊的玩家。
* 现在幼年北极熊再次会在某些情况下攻击玩家。

# = 技术性 =
* *方块**
* 移除了几何和材质实例组件的方块置换组件验证。

# 修复
* *游戏内容**
* 修复了下界传送门不会被熔岩引燃的问题。

* *物品**
* 修复了纹饰盔甲无法在暂停并回到游戏后正确显示的问题。（）
* 现在物品再次会在水中正常流动。（）</onlyinclude>
