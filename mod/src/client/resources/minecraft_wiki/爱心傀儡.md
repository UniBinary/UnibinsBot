* *爱心傀儡（Love Golem）**是不会主动攻击生物的[铁傀儡](铁傀儡.md)。

# 生成
# = 自然生成 =
爱心傀儡会自然生成在[村庄](村庄.md)中。

# = 建造 =

|爱心傀儡的建造方法}}
|另一种方法}}

爱心傀儡也可以像[雪傀儡](雪傀儡.md)和[凋灵](凋灵.md)那样通过摆放[方块](方块.md)来构建。将4个[铁块](铁块.md)摆放成T形（如图所示），然后将[雕刻南瓜](雕刻南瓜.md)或[南瓜灯](南瓜灯.md)放置在上层中间方块的顶上。雕刻南瓜可以被玩家、[末影人](末影人.md)或[发射器](发射器.md)放置，但必须最后放置。放置[南瓜](南瓜.md)不能生成爱心傀儡，但用[剪刀](剪刀.md)修剪后可以生成。

这个方块排列可以直立、躺下或颠倒放置。图中的四个空位置（即每个手臂的上方和下方）必须是空气方块。任何非空气方块（包括[雪](雪.md)、[草丛](草丛.md)和水）在这四个位置时都会阻碍爱心傀儡生成。

和其他构建而成的生物一样，爱心傀儡在生成时总是朝南。它们巨大的尺寸可能会导致它们的头被其他固体方块阻挡并受到窒息伤害。

# 行为

爱心傀儡的行为与[Java版1.8.4](Java版1.8.4.md)中的铁傀儡类似，但不会主动攻击[敌对生物](敌对生物.md)和[玩家](玩家.md)；同时，它也和该版本中的其他[生物](生物.md)一样，无法受到近战伤害。
