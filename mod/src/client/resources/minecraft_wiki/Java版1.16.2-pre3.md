# Java版1.16.2-pre3

*页面ID: 67751* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.16.2-pre3**是[Java版1.16.2](Java版1.16.2.md)的第3个，也是最后一个预发布版，发布于2020年8月6日<ref></ref>，解决了狼在暗处的渲染错误，并修复了一些漏洞。

# 更改
# = 生物 =
* *[狼](狼.md)**
* 现在在暗处会正确渲染了。

# 修复
成黑色。
|167756|狼在没有受到天空光照直接照射时变得很暗。
|;1.16的漏洞
|191388|控制台反复提示“No key position_predicate in MapLike”。
|;1.16.1的漏洞
|197049|重新登录后会保存待处理消息，而不保存普通消息。
|197053|按下会清除“<code>-{}-</code>”的提示，但是不会清除实际上待发送的。
|;dev
|196534|游戏不识别自定义维度类型：<code>java.lang.IllegalStateException: Unregistered dimension type</code>。
|;previous
|197122|游戏在创建或进入调试模式世界后崩溃。
|197152|部分活塞结构会生成幽灵方块。

|197242|自定义多噪声维度导致游戏崩溃：<code>Crash with custom multi-noise dimension: java.lang.IllegalStateException: Unregistered dimension type: cha@90d4173</code>。
