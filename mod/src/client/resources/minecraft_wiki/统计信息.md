# 统计信息

*页面ID: 8621* | *来源: Minecraft Wiki*

* *统计信息（Statistic）**是一项游戏功能，可以计算玩家进行特定动作的次数。

[基岩版](基岩版.md)未将此功能实现在游戏内，但已登录Xbox账号的玩家可以通过Xbox提供的相关服务查看部分统计信息。

# 统计界面
统计界面的统计信息被分为以下三栏：
* ****：通用窗口分门别类地显示了大量数据，详细数据见下文中的表格。
* ****：物品窗口显示了不同物品的方块形式被开采（若有）、物品形式被合成、使用的次数以及被拾起和丢弃的个数。该栏可使用界面顶部的按钮更改各项物品的排列顺序。
* ****：生物窗口显示了各种生物被玩家击杀的次数，以及玩家被这些生物击杀的次数。
物品窗口顶部的按钮可用于对列表进行排序。通用和生物窗口按照字母顺序排序。

# 命名空间ID
统计信息的[命名空间ID](命名空间ID.md)是唯一的。它们是游戏中唯一的组合命名空间ID。

统计信息的命名空间ID也采用<code>NAMESPACE:PATH</code>的形式，其中<code>NAMESPACE</code>由统计类型命名空间ID转换得到，格式为<code>namespace.path</code>；<code>PATH</code>由统计名称命名空间ID转换得到，格式也为<code>namespace.path</code>。

例如，统计玩家繁殖动物次数的统计名称的命名空间ID为<code>minecraft:animals_bred</code>，其所属的统计类型的命名空间ID为<code>minecraft:custom</code>，则组合而成的完整的统计信息命名空间ID为<code>minecraft.custom:minecraft.animals_bred</code>。也即，统计信息的命名空间ID采用<code>A.B:C.D</code>的形式，其中：

* <code>A</code>是统计类型的命名空间。
* <code>B</code>是统计类型的路径。
* <code>C</code>是统计名称的命名空间。
* <code>D</code>是统计名称的路径。

若命名空间为<code>minecraft</code>则可以省略。如以下四个ID的效果相同：
* <code>minecraft.mined:minecraft.stone</code>
* <code>mined:minecraft.stone</code>
* <code>minecraft.mined:stone</code>
* <code>mined:stone</code>

# = 统计类型和名称 =
统计信息分为几种类型。对于通用信息，它们的类型被称为<code>minecraft:custom</code>。对于物品信息，其被称为<code>minecraft:mined</code>、<code>minecraft:broken</code>、<code>minecraft:crafted</code>、<code>minecraft:used</code>、<code>minecraft:picked_up</code>和<code>minecraft:dropped</code>。对于生物信息，其被称为<code>minecraft:killed</code>和<code>minecraft:killed_by</code>。
