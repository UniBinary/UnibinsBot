# Java版Infdev 20100420

*页面ID: 35948* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年4月20日，进行了一些更改和修复。<ref></ref>

# 更改
# = 方块 =
* *[树苗](树苗.md)**
* 现在会生长成Infdev大树。

# = 生物 =
* *常规**
* 修改了生物寻路和行为。
* 生物生成减少。

# = 世界生成 =
* *常规**
* 世界生成器更新。
* * 现在生成得更快了。
* * 地形看起来不再那么崎岖，山地明显减少了。相应的，[丘陵](丘陵.md)生成地更加频繁了。

# = 常规 =
* *世界保存**
* 世界自动保存的频率减少。

* *存档格式**
* 世界存档格式更改。

# 修复
* *修复了2个漏洞**
* 生物寻路不再将生物带到垂直落差较大的地方。
* 敌对生物不再生成在光明的区域。</onlyinclude>
