# 普通披风

*页面ID: 186099* | *来源: Minecraft Wiki*

* *普通披风（Common Cape）**是向2025年5月6日至2026年5月6日登录基岩版账号的玩家的披风。<ref></ref>

# 外观
普通披风的设计灵感来自[草方块](草方块.md)。其顶部呈绿色半圆状，中心颜色渐深，代表草。棕色底部嵌有银白色小点，代表[泥土](泥土.md)。

# 描述
在分发期间，任何平台上使用微软账户登录基岩版的玩家都可以在基岩版和Java版中获得这款披风。即使在无需使用微软账户即可游玩的平台上，获取这件披风也需要拥有微软账户。
