# 命令/tp/Java版17w45a前

*页面ID: 39833* | *来源: Minecraft Wiki*

传送实体（玩家、生物等）到指定位置，并可选地修改其朝向。

此命令与之间的主要差别是：使用基于传送目标当前位置的相对坐标，而使用基于命令执行位置的相对坐标。
并且，大多数命令只能影响已经生成的区块，但是却可以将实体传送到尚未生成的区块中。若被传送的目标是玩家，则传送后玩家所在的区块及附近的区块会自动开始生成。

# 语法
   <code>-{}-tp <*目的地实体*></code>
   <code>-{}-tp <*传送目标*> <*目的地实体*></code>
   <code>-{}-tp <*x*> <*y*> <*z*> [<*Y旋转角度*> <*X旋转角度*>]</code>
   <code>-{}-tp <*传送目标*> <*x*> <*y*> <*z*> [<*Y旋转角度*> <*X旋转角度*>]</code>

# 参数
<code>-{}-*传送目标*</code>
   指定要传送的实体。必须为玩家名称、[目标选择器](目标选择器.md)或[UUID](UUID.md)。
   若被指定的待传送实体之中，存在所处维度与目的地处世界维度不相同的情况，则这一部分实体的传送会失败，其余实体传送成功。

<code>-{}-*目的地实体*</code>
   指定传送的目的地实体。必须为玩家名称、[目标选择器](目标选择器.md)或[UUID](UUID.md)。

<code>*x y z*</code>
   传送目标至指定坐标。指定坐标的<code>*x*</code>和<code>*z*</code>必须位于-30,000,000至30,000,000之间（不含），<code>*y*</code>必须位于-4096至4096（包含）。可以使用波浪号（<code>~</code>）来指定基于传送目标当前位置的[相对坐标](相对坐标.md)——这是一种特殊情况，大多数情况下，波浪号使用基于命令执行位置的相对坐标。如果需要基于命令执行位置的传送，可以使用命令。

<code>-{}-*Y旋转角度*</code>
   指定水平旋转角度（正北方为-180.0，正东为-90.0，正南为0.0，正西为90.0，正北以西为179.9，之后回到-180.0）。可以使用波浪号（<code>~</code>）指定基于当前旋转角度的相对偏移。

<code>*-{}-X旋转角度*</code>
   指定垂直旋转角度（竖直上方为-90.0，至竖直下方90.0）。可以使用波浪号（<code>~</code>）指定基于当前旋转角度的相对偏移。

# 示例
   将执行实体传送到Alice的位置： <code>tp @s Alice</code>
   将所有距执行实体10格内的实体传送到自身上方第5格的位置，且向左旋转25度：<code>tp @e[r=10] ~ ~5 ~ ~-25 ~</code>
   将所有玩家传送到执行实体的位置： <code>tp @a @s</code>
   将执行实体传送到自身上方第200格的位置：<code>tp ~ ~200 ~</code>
   将执行实体传送到x=100、z=100处，高度为传送前位置上方第3格：<code>tp 100 ~3 100</code>
   将距执行实体最近的玩家在其当前位置处向右旋转10度：<code>tp @p ~ ~ ~ ~10 ~</code>
