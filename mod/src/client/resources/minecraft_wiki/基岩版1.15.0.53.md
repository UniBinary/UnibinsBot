# 基岩版1.15.0.53

*页面ID: 54830* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.15.0.53**[基岩版1.16.0](基岩版1.16.0.md)的第2个测试版，发布于2020年2月20日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[侦测器](侦测器.md)**
* 放置时不再发出[红石](红石.md)信号。

# = 常规 =
* *地图制作和[附加包](附加包.md)**
* 被抛出的物品现在是数据驱动的了。
* 溺尸现在是数据驱动的了。

# 修复
* *修复了20个漏洞**<br>
* *崩溃**
* 修复了游戏过程中可能发生的几次崩溃。

* *性能**
* 优化了关键帧的动画播放。
* 优化了破坏许多海带时的性能。

* *辅助功能**
* 文字转语音阅读器现在可以正确读取URL了。

* *常规**
* 在有限的空间中，滞留的和喷溅的药水粒子现在仍保留在其边界内了。
* 修复了阻止循环和连锁型命令方块打开的错误。 （）
* 当蛋糕被食用一部分时，会具有正确的纹理状态了。（）

* *游戏玩法**
* 修复了在海绵上点火后放水会出现“幻像”水块的问题。 （）
* 修复了气泡柱无法收集水的问题。 （）
* 占据相同空间的堆叠的矿车现在会按预期分开了。 （）
* 现在在脚手架上行走会发出正确的声音了。 （）

* *生物**
* 幼年生物在岩浆块上生成时现在会持续受到伤害了。 （）

* *图形**
* 修复了当手持盔甲时，盔甲会意外地出现在生物身上的问题。

* *附加包**
* 使用运行时标识符字段的自定义实体现在使用该自定义实体的名称，而非其原始实体的名称。 （）
* 修复了行为，当附近有方块时，这些行为可能会导致生物卡死。
* 已分配的喷溅药水和滞留药水在其弹射成分中具有药水效果了。
* 修复了冲突框未从脚本更新的问题。
* 组件现在可以在非生物（例如末地水晶）上使用。
* 当动作被选中时，出现在空中的生物将不再认为它在地面上。

* *角色创建器**
* 修复了某些角色创建器的选择不会在之间保存的问题。（）</onlyinclude>
