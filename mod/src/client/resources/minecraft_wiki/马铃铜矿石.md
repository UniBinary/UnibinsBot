* *马铃铜矿石（Potone Copper Ore）**是以[马铃石](马铃石.md)作为容矿岩的[铜矿石](铜矿石.md)变种，会自然生成于[马铃薯维度](马铃薯维度.md)。

# 生成
# = 自然生成 =
马铃铜矿石以[团簇](团簇.md)的形式自然生成于[马铃薯维度](马铃薯维度.md)Y=0至112高度范围内的马铃石之间，其中Y=47至48处分布得最多，向两端递减。矿团大小为0-10个方块，每[区块](区块.md)最多尝试生成4次。

# 获取
马铃铜矿石只能通过破坏对应方块获得。

# 破坏
挖掘马铃铜矿石的合适工具是锄。马铃铜矿石需要石锄或品质更好的锄来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，马铃铜矿石被破坏后会掉落2-5个[粗铜](粗铜.md)和，挖掘工具的[时运](时运.md)魔咒会增加粗铜的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，马铃铜矿石被破坏后会掉落自身。

# 用途
马铃铜矿石目前仅用于装饰。
