* *远古守卫者（Elder Guardian）**是一种生成于[海底神殿](海底神殿.md)的敌对生物。它是[守卫者](守卫者.md)更强大的变种。

# 生成
在每座[海底神殿](海底神殿.md)的生成过程中会有3只远古守卫者随之生成：一只在顶部房间，另两只则分别位于神殿的两个侧翼。

远古守卫者只能在世界生成的过程中被生成，在最初生成之后不会再次生成，因此在每个世界中其数量是有限的。

# 行为
远古守卫者在水中和陆地上的多数行为与[守卫者](守卫者.md)的行为相同。像[守卫者](守卫者.md)一样，远古守卫者也会主动攻击[玩家](玩家.md)、[鱿鱼](鱿鱼.md)、[发光鱿鱼](发光鱿鱼.md)和[美西螈](美西螈.md)。与守卫者不同的是：

* 远古守卫者在空闲时不会四处游动（当被移动到自己的生成点之外时会试图游回自己的生成点）。
* 远古守卫者在被目标玩家接近时不会游开。

远古守卫者的眼睛会跟随并紧盯附近的玩家，而且会直直地盯着正在攻击的目标。它们的眼睛能够跟随拥有效果且没有穿任何[盔甲](盔甲.md)（即完全“看不见”）的玩家。远古守卫者也会攻击具有同样效果的其他目标。它们的眼睛似乎只会单纯地跟踪最近的玩家，即使这个玩家处于[旁观模式](旁观模式.md)。

与多数敌对生物不同，远古守卫者永远不会自然消失，在不死亡的情况下会永远保留在世界中。但在和平难度下，远古守卫者会像多数敌对生物一样被移除。

远古守卫者有两种攻击方法：发射激光和用于防御的尖-{}-刺攻击。它们还能给予玩家[挖掘疲劳](挖掘疲劳.md)状态效果。

# = 生物族群 =

远古守卫者是水生生物，被具有[穿刺](穿刺.md)魔咒的武器近战攻击，或被具有穿刺魔咒的[三叉戟](三叉戟.md)弹射物命中时会受到额外的伤害。

# = 攻击 =
远古守卫者有2种攻击方式：发射激光和伸出防御性的尖-{}-刺（与[荆棘](荆棘.md)魔咒类似）。与多数攻击型生物不同，远古守卫者没有追逐行为，不会尝试靠近或远离目标。若目标跑出它们的视线，它们会一直游荡直至目标再次进入视线，然后开始激光充能进行攻击。

远古守卫者会主动攻击[玩家](玩家.md)、[美西螈](美西螈.md)、[鱿鱼](鱿鱼.md)和[发光鱿鱼](发光鱿鱼.md)。除这些生物以外，远古守卫者并不会使用激光反击攻击它的生物（如铁傀儡），但它的尖-{}-刺仍可对这些攻击者造成伤害。

;激光
激光需要几秒钟的充能时间，在充能期间没有任何伤害。正在蓄能的激光会从紫色逐渐变成亮黄色，能量充满后，激光就会突然消失并对目标造成两次伤害。远古守卫者在再次攻击前会游动3秒。如果在激光充能时接近远古守卫者，充能会被取消，远古守卫者会退到一个合适的距离后再继续进行攻击。激光不能躲避或使用[盾牌](盾牌.md)抵挡。激光的最大射程约为14格。若玩家跑出激光的射程或激光被固体方块（包括透明固体方块，如玻璃）阻挡，远古守卫者会停止充能，不造成任何伤害。

远古守卫者的激光消失时，会按照顺序先后造成两次伤害：
* 在简单、普通、困难难度下分别造成魔法伤害，不会被护甲值降低。
* 在简单、普通、困难难度下分别造成/生物伤害，会被护甲值降低。由于[受击后伤害免疫](受击后伤害免疫.md)，此攻击伤害会被削减到此次伤害和上次伤害的差值，此差值经过[护甲值计算](盔甲机制.md)后才会对生物造成真正的对应伤害。

;尖-{}-刺
每次近战攻击伸出尖-{}-刺的远古守卫者会受到点伤害（/），类似于[荆棘](荆棘.md)魔咒，且会导致与荆棘魔咒一致的[死亡消息](生命#死亡.md)。与荆棘魔咒不同，这一效果只对近战攻击有效。接近远古守卫者时尖-{}-刺总是伸出的，因为它们不会游开。

# 你知道吗
* 远古守卫者的眼睛实际上是生物模型的“头部”。这造成了动态眼睛的错觉。
* 游戏《[](wzh:龙与地下城.md)》中的[眼魔](https://forgottenrealms.fandom.com/wiki/Beholder)是远古守卫者的灵感来源之一。<ref name="story"></ref>
* 远古守卫者被[Jeb](Jeb.md)称作“小型Boss”（Miniboss），<ref name="story"/>在设计之初也被定位为Boss，<ref name="meet-elder-guardian"/>但它不属于真正的[Boss生物](Boss生物.md)。
* 据Jeb所述，远古守卫者的存在是为了鼓励玩家解出海底神殿的迷宫，而不是直接挖穿它。<ref name="minecraft.net"/>
* * 另外，他表示远古守卫者的“鬼影”旨在暗示玩家[挖掘疲劳](挖掘疲劳.md)效果的来源，造成是无意的。<ref name="minecraft.net"/>
* 据Jeb所述，远古守卫者之所以掉落[湿海绵](湿海绵.md)，是为了确保玩家能从不含海绵房的[海底神殿](海底神殿.md)中获取湿海绵。<ref>https://bsky.app/profile/jebox.bsky.social/post/3lrb26wj5fc2w</ref>
* 在Java版的愚人节版本[3D Shareware v1.34](Java版3D Shareware v1.34.md)中，远古守卫者会掉落蓝色钥匙。
