# 紫水晶块

*页面ID: 71722* | *来源: Minecraft Wiki*

* *紫水晶块（Block of Amethyst）**是由[紫水晶碎片](紫水晶碎片.md)合成的方块。

# 生成
# = 自然生成 =
紫水晶块会作为[紫晶洞](紫晶洞.md)的内壁自然生成。

# 获取
# = 合成 =

# 破坏
挖掘紫水晶块的合适工具是镐。紫水晶块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

紫水晶块被破坏后会掉落自身。

# 用途
# = 共振 =
如果紫水晶块相邻[幽匿感测体](幽匿感测体.md)或[校频幽匿感测体](校频幽匿感测体.md)，那么当幽匿感测体或校频幽匿感测体接收到振动时，紫水晶块会在自身的位置发送一个与幽匿感测体或校频幽匿感测体接收到的振动相同振动频率的振动，并产生共振音效。

振动频率越高，共振音效越短促、越尖锐。振动频率从1增大到15时，共振音效的音高依次为0、2、4、6、7、9、10、12、14、15、18、19、21、22和24。

共振允许在不重新创造振动源的情况下远程传递振动。

# 你知道吗
* 紫水晶块的纹理更类似于现实中的（charoite）。
* 与[石英块](石英块.md)类似，紫水晶块无法拆解成[紫水晶碎片](紫水晶碎片.md)，因此不能使用紫水晶块储存紫水晶碎片。
