# 基岩版26.0.28

*页面ID: 182395* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 26.0.28**（ChromeOS/Android）、**Preview 26.0.28**（Windows/Xbox/iOS/iPadOS/PlayStation）是[基岩版26.0](基岩版26.0.md)的第5个测试版，发布于2026年1月13日<ref></ref>，更新了[设置](设置.md)菜单，并修复了一些漏洞。

# 更改
# = 常规 =
* *[设置](设置.md)**
* 更新了设置菜单，以使用[Ore UI](Ore UI.md)。

# = 技术性 =
* *方块**
* 与其他方块相交的自定义方块现在拥有更好的环境光遮蔽。

* *[基岩版编辑器](基岩版编辑器.md)**
* 在世界菜单中加入了区块管理面板，用于重新生成或删除区块。
* 为选区体积加入了1,000,000格的动态限制。这允许非立方体矩形超出100×100×100的立方体限制。较大立方体限制仍然为1024×1024×1024。
* 加入了电影化工具，用于创建相机动画路径：
* * 使用带有样条插值（Catmull-Rom或线性）的控制点来创建路径。
* * 控制点和带有交互式小工具的样条路径在游戏内是可视化的。
* * 播放/停止相机沿样条路径移动的动画预览。
* * 导出有重复时间戳验证的TypeScript代码。
* 为编辑器加入了洪水工具。
* * 用于在大范围内有效地添加或移除水和熔岩的新工具。
* 设置面板现在支持编辑每个生物群系的设置。
* 利用方块特征的方块现在会在编辑器中使用时连接。

* *图形**
* 修复了附着物在游戏暂停时或在NPC UI窗口中渲染时不会正确渲染的问题。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“”子选项后才可使用。

# = 技术性 =
* *图形**
* 修复了使用为创作者提供的[RenderDragon](RenderDragon.md)功能实验性内容的世界中可能由特定方块引发的崩溃。
* 修复了在使用静态彩色光照的情况下移除光源时会短暂闪烁的问题。
* 在测试版本中为Android和Playstation平台加入了对的彩色方块光照功能的支持，世界启用“”实验性玩法时可用。
* 驯服的幼年狼现在拥有MERS绘图。

* *用户界面**
* 现在当玩家与服务器断开连接时，第三方和外部服务器会使用与其他类型服务器相同的屏幕设计。屏幕会更突出显示服务器发送的消息。

# 修复
* *游戏内容**
* 修复了繁殖动物时发生的罕见崩溃。

* *Realms**
* 修复了在Nintendo Switch平台上购买Realm时可能发生的卡死问题。

* *音效**
* 现在玩家可以在16格内听到鹦鹉螺的骑乘音效，并且该音效的音量会更小。

* *用户界面**
* 修复了离开设置屏幕后不会套用全局资源包的问题。（）
* 修复了在社交设置屏幕中选择任意下拉菜单时会导致游戏卡死的漏洞。（）

* *世界**
* 修复了无法复制或导出文件夹中的世界的漏洞。（）</onlyinclude>
