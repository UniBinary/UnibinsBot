# 基岩版1.14.0.50

*页面ID: 49368* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.14.0.50**是[1.14.1](基岩版1.14.1.md)的首个测试版，发布于2019年11月13日<ref></ref>，修复了一些漏洞。

# 修复
* *崩溃**
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了在Xbox One上试图退出Xbox Live账户登录时可能发生的崩溃。
* 修复了在Xbox One上切换Minecraft和 Minecraft Club页面时可能发生的崩溃。
* 修复了加载角色创建器时可能发生的崩溃。

* *常规**
* 修复了Xbox One上的分屏玩家在加入世界时屏幕可能会闪烁的问题。
* 在市场下载免费音乐包DLC时不再显示出错。
* 加载提示现在会在语言设置为日语时正确显示了。

* *角色创建器**
* 市场上装备的皮肤现在会在导向角色创建器时更新装备到玩家模型上。
* 现在在游戏中使用角色创建器为皮肤添加或移除创始人披风会立即在游戏中更新皮肤，而无需重启游戏。
* 修复了重新进入角色创建器后无法添加披风的问题。
* 同步自Minecraft Earth的皮肤在角色创建器中不再显示为“跨设备可用”。
* 优化了角色创建器皮肤的大小，以提升在服务器使用该皮肤时的性能。

* *游戏内容**
* 铁桶又可以用于挤奶了。（）
* 奶桶又可以用于合成蛋糕了。（）
* 手持奶桶并长按“使用”按钮时，不再会不停地播放饮用动画。（）
* 修复了附近的水源变为含水方块时甘蔗会被破坏的问题。（）

* *生物**
* 被激怒的蜜蜂不再可以蜇玩家两次了。（）</onlyinclude>
