# Java版24w20a

* *24w20a**是[Java版1.21](Java版1.21.md)的第4个快照，发布于2024年5月15日<ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[实体谓词](实体谓词.md)**
* 加入了移动谓词的子谓词<code>movement</code>。
* 加入了可选的位置信息谓词<code>movement_affected_by</code>，存在时匹配实体下方最多0.5格可以影响其移动的方块。

# 更改
# = 方块 =
* *[活塞](活塞.md)**
* 更改了音效，同时降低了音效的音量和衰减距离，以解决大型红石机械非常吵闹的问题。

# = 物品 =
* *[重锤](重锤.md)**
* 现在进行普通攻击和暴击时又会正常消耗[耐久](物品耐久.md)。

# = 生物 =
* *[沼骸](沼骸.md)**
* 用[剪刀](剪刀.md)修剪头上的[蘑菇](蘑菇.md)现在不再被游戏规则<code>doMobLoot</code>影响，且蘑菇现在也会从正确的位置掉落。

* *[女巫](女巫.md)**
* 为了增加[沼泽小屋](沼泽小屋.md)农场的产量，现在女巫死亡时总会掉落4-8个[红石粉](红石粉.md)。
* * [抢夺](抢夺.md)魔咒会影响掉落数量。每级可使掉落数量上限增加1，使用抢夺III最多掉落11个。

* *[玩家](玩家.md)**
* 现在玩家重生、改变维度或通关游戏时，自定义属性基值、属性修饰符和状态效果将被保留。

# = 世界生成 =
* *[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)**
* 将[骷髅](骷髅.md)的生成权重由100降低至70，将[沼骸](沼骸.md)的生成权重由50降低至30。
* * 这使得骷髅和沼骸都将更少地生成。

# = 游戏内容 =
* *[鸣谢名单](鸣谢名单.md)**
* 更新了鸣谢名单以匹配人员职位变动。

# = 常规 =
* *[属性](属性.md)**
* 现在生效槽位为的属性修饰符不再在[提示框](提示框.md)中显示每种槽位的详情，而显示为“”、“”和“”。

* *[数据包](数据包.md)**
* 将数据包版本号更改为。
* 现在[魔咒的数据驱动](魔咒数据格式.md)字段<code>weight</code>具有上界，值为1024。
* 现在魔咒的数据驱动字段<code>max_level</code>具有上界，值为255。

* *[字体](字体.md)**
* 将字体从Unifont 15.1.04更新为Unifont 15.1.05。
* * 扩充了中日韩统一表意文字拓展区的字符，包括[Unicode第2平面](wzh:Unicode字符平面映射#第二輔助平面.md)和第3平面中的粤语用字。
* * 更新了谚文字母的字形，以与谚文音节的字形保持一致。
* * 微调了类字母符号（U+2100~U+214F）的字形。
* * 调整了Ľ（U+013D）的字形，以在捷克文/斯洛伐克文中取得更好的显示效果。<ref>[GNU Unifont Glyphs - Unifoundry.com](http://unifoundry.com/unifont/index.html)</ref>
* 现在“”选项不再对假名使用Unifont JP字体。

* *[结构NBT标签](自定义结构.md)**
* 现在还可以为一个复合标签，包括：
* * ：（非负数）距维度底部的垂直填充长度。
* * ：（非负数）距维度顶部的垂直填充长度。
* * 示例：<code>dimension_padding: 10</code>或<code>dimension_padding: { bottom: 10, top: 5 }</code>都是有效的。
