# 铁块

*页面ID: 6193* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *铁块（Block of Iron）**是一种由[铁锭](铁锭.md)合成而来的金属方块。

# 生成
铁块不会生成在世界中。

# 获取
# = 箱子战利品 =

# = 合成 =

# 破坏
挖掘铁块的合适工具是镐。铁块需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

铁块被破坏后会掉落自身。

# 用途
铁块可以用于存储[铁锭](铁锭.md)，以此来节约空间。

# = 信标 =

铁块可作为激活[信标](信标.md)的底座方块。

# = 生成铁傀儡 =

|铁傀儡建造图示}}
铁块和[雕刻南瓜](雕刻南瓜.md)或[南瓜灯](南瓜灯.md)可以用来建造[铁傀儡](铁傀儡.md)。雕刻南瓜或南瓜灯必须最后放置，放置后会立刻生成一只铁傀儡。
