* *生物（Mob）**是使用默认玩家[皮肤](皮肤.md)的友好[生物](生物.md)。

# 生成
# = [0.24_SURVIVAL_TEST](0.24_SURVIVAL_TEST.md)前 =
生物会在世界中随机自然生成，[rd-160052](Java版pre-Classic rd-160052.md)后也可通过按键生成。

# = 0.24_SURVIVAL_TEST后 =
生物不会在世界中自然生成，只能通过使用Mod或地图编辑器来生成。

# 掉落物
在[Indev 0.31 20100131-2157](Java版Indev 0.31 20100131-2157.md)至[20100201-2227](Java版Indev 0.31 20100201-2227.md)中，生物死后会随机掉落[线](线.md)、[羽毛](羽毛.md)或[火药](火药.md)。

在[Indev 0.31 20100201-0038](Java版Indev 0.31 20100201-0038.md)至[20100201-2227](Java版Indev 0.31 20100201-2227.md)中，生物死后会随机掉落[线](线.md)、[羽毛](羽毛.md)、[火药](火药.md)或[打火石](打火石.md)。

其余版本的生物死后没有掉落物。

# 行为
生物会以接近圆形的路径随机行走，有时会跳跃，不会放置或破坏[方块](方块.md)。生物在移动时会被固体方块所阻挡，但不会受到[液体](液体.md)的阻力影响。
