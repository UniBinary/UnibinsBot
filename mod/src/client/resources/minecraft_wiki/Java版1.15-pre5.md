# Java版1.15-pre5

*页面ID: 49945* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.15-pre5**是[Java版1.15](Java版1.15.md)的第5个预发布版，发布于2019年12月5日<ref></ref>，调整了客户端下载资源包的大小上限，并修复了一些漏洞。

# 更改
# = 常规 =
* *[资源包](资源包.md)**
* 将客户端下载资源包的大小上限从50MB增加至100MB。
