# 结构集

*页面ID: 152986* | *来源: Minecraft Wiki*

* *结构集定义文件**是**结构集（Structure Set）**在数据包中的数据驱动定义文件。

# = 结构放置类型 =
结构放置类型决定了结构的放置方式，游戏共有下列放置类型。

# == concentric_rings ==
同心圆环放置，原版游戏用于[要塞](要塞.md)。每个维度只生成固定数量的结构，以世界中心为原点按同心圆环的方式放置结构。

<div class="treeview">
* * ：<code>concentric_rings</code>
* * ：（）每一环的宽度加上每环间的间隙宽度，单位为**6区块**。
* * ：（）该维度尝试生成的总次数。
* * ：（）最中心一环的结构尝试生成次数。第n环中的尝试生成次数为：<code>-{}-第n环的次数 = spread * (n^2 + 3n + 2) / 6</code>，直到次数达到总次数。
* * ：此结构更倾向于生成的生物群系。
</div>

# == random_spread ==
随机扩散放置，原版游戏用于[海底神殿](海底神殿.md)和[沼泽小屋](沼泽小屋.md)等结构。游戏会将维度分割为以个区块为边长的若干分块，每个分块只能尝试生成一次结构。而为了避免两个结构的距离过近，游戏只会在每个分块内以个区块为边长的小分块内生成，多出的XZ正方向的狭长区域永远不会生成结构。

<div class="treeview">
* * ：<code>random_spread</code>
* * ：（默认为<code>linear</code>）扩散类型。可以为<code>linear</code>或<code>triangular</code>。区别在于<code>triangular</code>不容易比<code>linear</code>出现极端值。
* * ：（）两个结构之间的平均距离（单位为区块）。
* * ：（）两个结构之间的最小距离（单位为区块）。两次结构之间的最大距离则为。
</div>

# 定义行为
结构集定义数据仅在服务端启动时加载一次，使用命令不可以重新加载结构集定义，而必须重启服务端。

结构集用于让结构“自然生成”于世界。在世界生成阶段，每个维度都会尝试计算所有可用的结构集，在结构集计算的坐标上挑选可能的结构。如果当前位置的概率不通过，或不符合生物群系要求，或诸如地形限制等其他因素导致计算失败，则此处不会放置结构；否则，游戏会在区块内记录将要生成的结构片段，待区块加载时生成结构。
