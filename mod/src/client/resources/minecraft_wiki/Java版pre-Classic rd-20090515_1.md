* *rd-20090515**是2009年5月15日制作的[pre-Classic](Java版pre-Classic.md)版本。<ref></ref><ref></ref>

# 新内容
# = 方块 =
* *[泥土](泥土.md)**
* 会自然生成在草方块下方，通常会生成几层。
* 在阳光下放置一段时间后会形成[草方块](草方块.md)。

* *[圆石](圆石.md)**
* 不会在世界中自然生成，只能由[玩家](玩家.md)放置。

* *[木板](木板.md)**
* 不会在世界中自然生成，只能由玩家放置。

* *常规**
* 现在支持不同类型的方块和动态方块。

# = 游戏内容 =
* *[平视显示器](平视显示器.md)**
* 加入了十字准星。

# = 常规 =
* *[控制](控制.md)**
* 按下可生成[生物](生物（已移除实体）.md)。
* 按数字键–可选择方块。
* *  当前选定的方块会显示在右上角。

# 更改
# = 方块 =
* *[草方块](草方块.md)**
* 更改了纹理。现在顶部和侧面有了不同纹理，不再是每个面都使用相同的纹理。
* * 顶部纹理稍作增亮。
* 不再能正常放置。
* 若未暴露在阳光下，会恢复为泥土。

* *[石头](石头.md)**
* 更改了纹理。

# = 生物 =
* *[人类](生物（已移除实体）.md)**
* 生成数量从100个减少到10个。
* 在Y<-100时会被移除。
* 在阴影下会显得更暗。

# = 游戏内容 =
* *[亮度](亮度.md)**
* 阴影亮度有所提高。

* *常规**
* 现在较远处的明亮方块表面会出现一层薄雾。
* 降低了处于半空中的移动速度。
* 修改了[玩家](玩家.md)的物理模型，现在能跳得更远，行走和下落速度更快。

# = 世界生成 =
* *常规**
* 现在创建的世界不再是平坦的。
* 加载更旧的pre-Classic版本世界时，所有方块会变为石头。</onlyinclude>

# = 常规 =
* *其他**
* 加入了全屏模式。

# 启动器版
该版本不存在于[启动器](启动器.md)中，启动器中名为“rd-20090515”的版本实际上是[rd-161348](Java版pre-Classic rd-161348.md)。

# 你知道吗
* 与其他pre-Classic版本不同，它的命名格式不是“ddhhmm”（日-小时-分钟），而是“yyyymmdd”（年-月-日）。
* 该版本中将“*Cave Game*”更名为“*Minecraft: Order of the Stone*”。<ref></ref>
