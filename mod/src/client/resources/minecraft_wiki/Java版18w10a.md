# Java版18w10a

*页面ID: 33936* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w10a**是[Java版1.13](Java版1.13.md)的第24个快照，发布于2018年3月6日<ref></ref>，加入了珊瑚、热带鱼桶以及藏宝图，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[珊瑚](珊瑚.md)**
* 有蓝色珊瑚、粉红色珊瑚、紫色珊瑚、红色珊瑚和黄色珊瑚变种。
* 只能在水里放置。

# = 物品 =
* *[地图](地图.md)**
* 现在能够在[地图](地图.md)上放置标记了。
* * 对着[旗帜](旗帜.md)拿着地图使用会在地图上标记。
* * 对同样的旗帜再次使用会取消标记。
* * 地图的标记会显示该旗帜的底色。
* * 如果是有名称的旗帜，标记同样也会显示其名称。
* * 如果旗帜被摧毁了，那么标记会在你拿地图靠近标记位置时消失。
* * 在地图上使用新的<code>banners</code>NBT标签。

* *[热带鱼桶](热带鱼桶.md)**
* 通过使用水桶装起[热带鱼](热带鱼.md)获得。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了热带鱼刷怪蛋。

* *[藏宝图](藏宝图.md)**
* 能在[海底废墟](海底废墟.md)的箱子中发现。
* 能指引玩家发现埋藏的宝藏。

# = 实体 =
* *[热带鱼](热带鱼.md)**
* 拥有3072种不同的形状、颜色与图案组合。
* 一样能用水桶抓住，鱼的类型仍然被保存着。
* 生成于暖水海洋和温水海洋。
* 会掉落自身。

# = 世界生成 =
* *[埋藏的宝藏](埋藏的宝藏.md)**
* 拥有自己的<code>buried_treasure</code>[战利品表](战利品表.md)。
* 可通过[海底废墟](海底废墟.md)宝箱的[藏宝图](藏宝图.md)定位。

# = 常规 =
* *音乐**
* 水下环境
* * 进入水中有了新音效。
* * 离开水中有了新音效。
* * 为水下环境加入循环音效。
* ** 此外也有另外两个额外的循环音效。
* *** 其中一种是罕见的，勉强听到鲸鱼叫声、合上嘴巴和板块张裂的声音。

# 更改
# = 方块 =
* *[海带](海带.md)**
* 更改了纹理。

* *[珊瑚块](珊瑚块.md)**
* 更改了纹理（失活的珊瑚块除外）。
* * 每种颜色都有不同的纹理。

# = 物品 =
* *[三叉戟](三叉戟.md)**
* 更改了三叉戟在[物品栏](物品栏.md)中的模型。

# = 实体 =
* *[幻翼](幻翼.md)**
* 更改了幻翼的模型与纹理。
* 更改了幻翼的行为AI。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 现在水下能见度在每个生物群系都不同。

# = 命令格式 =
* *[标签](Java版标签.md)**
* 加入了方块和物品标签<code>coral_plants</code>。
* 现在<code>waterlogged</code>方块标签现在包含珊瑚丛。
