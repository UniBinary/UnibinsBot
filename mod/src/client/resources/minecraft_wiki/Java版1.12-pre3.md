* *1.12-pre3**是[Java版1.12](Java版1.12.md)的第3个预发布版，发布于2017年5月17日<ref name=1.12-pre3></ref>，加入了新的音效，优化了游戏性能，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[进度](进度.md)**
* 将[抗性提升](抗性提升.md)加入了完成隐藏挑战“为什么会变成这样呢？”需获得的[状态效果](状态效果.md)的列表中。
* * 现在当完成该挑战时，会给予玩家而非之前的。
* 完成“均衡饮食”挑战所需要吃的食物的种类更多了。
* * 现在需要35种而非之前的30种。
* “进度”界面会记住玩家上次打开的标签页。
* 将进度的<code>requirements</code>改变成OR值中的一个AND值。

* *[控制](控制.md)**
* 为打开“进度”界面添加了新的热键。（默认为）

* *音效**
* 为声音事件<code>entity.player.hurt_drown</code>和<code>entity.player.hurt_on_fire</code>加入了新的音效。

# 更改
# = 生物 =
* *[鹦鹉](鹦鹉.md)**
* 现在驯服鹦鹉需要给它们喂[小麦种子](小麦种子.md)而非[曲奇](曲奇.md)。
* * 尝试给鹦鹉喂食曲奇，鹦鹉会立即死亡。
* ** 因吃了曲奇而死亡的鹦鹉会在死亡时发出[中毒](中毒.md)的[粒子](粒子.md)。
* 现在可以在旧版本中已经生成的丛林里生成。

* *[凋灵](凋灵.md)**
* 无法再破坏[末地折跃门方块](末地折跃门方块.md)和[活塞臂](活塞臂.md)。

# = 常规 =
* *[函数](Java版函数.md)**
* 现在使用新的文件拓展名而非之前的。
* 每一栏的命令不再以“/”开头。
* 现在仅能使用“#”来注释，而非之前的“//”。
* 函数会按照预期地进行递归，甚至在混合了和命令时。

* *教学提示**
* 当在决定是否显示时会更智能。

* *性能**
* 对[配方书](配方书.md)和[创造模式物品栏](创造模式#创造模式物品栏.md)的搜索功能进行了巨大优化。
* 对进度进行了一些优化。
