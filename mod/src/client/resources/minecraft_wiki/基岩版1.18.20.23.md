# 基岩版1.18.20.23

*页面ID: 92687* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.20.23**（Xbox/Windows/Android）、**Preview 1.18.20.24**（iOS/iPadOS/Xbox）是[基岩版1.18.30](基岩版1.18.30.md)的第2个测试版，发布于2022年2月2日<ref></ref>，在[实验性玩法](实验性玩法.md)中调整了一些特性，并修复了一些漏洞。

此版本也于2022年2月7日在Xbox平台上以Preview形式发布。

# 更改
# = 常规 =
* *[设置](设置.md)**
* 移除了“切换蹲下”和“摇杆透明度”选项。

# = 技术性 =
* *命令**
* 命令不再能修改包含组件的实体所在的区域。

* *EatMobGoal**
* EatMobGoal现在无法在目标为玩家时应用。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“荒野更新”、“香草实验”和“应用测试框架”子选项后才可使用。

# = 方块 =
* *[青蛙卵](青蛙卵.md)**
* 现在被[活塞](活塞.md)推动时会被破坏。
* 现在会在其下方的水消失时被破坏。
* 现在可放置在[含水](含水.md)方块上。
* 不再可以通过命令来放置在固体方块上或水下。
* 现在会被[下落的方块](下落的方块.md)破坏。

# = 物品 =
* *[山羊角](山羊角.md)**
* 现在每次使用后会有一段冷却时间。

# = 生物 =
* *[青蛙](青蛙.md)**
* 现在可以使用[黏液球](黏液球.md)来繁殖和吸引青蛙，而不是使用[海草](海草.md)。
* 现在会倾向于跳上[睡莲](睡莲.md)和[大型垂滴叶](大型垂滴叶.md)。

* *[蝌蚪](蝌蚪.md)**
* 现在生命值为，而不是。
* 现在可以使用黏液球来加速蝌蚪成长，而不是使用海草。

# 修复
* *自定义皮肤**
* 修复了退出更衣室界面时自定义皮肤不会被保存的问题。

* *游戏内容**
* 修复了经验修补魔咒不会正确吸收经验球来修复物品的问题。（）

* *生物**
* 溺尸不再会在方块亮度大于0时生成。（）

* *用户界面**
* 修复了Pocket UI的物品栏界面在使用部分语言时，其中的2×2合成方格上方的标签会被截断的问题。
* 修复了开启游戏进入新的创建新世界UI时，侧边栏中的Beta功能设置不会持续存在的问题。

* *原版趋同**
* 现在上方为流动的水的钟乳石不会填充其下方的炼药锅。

* *物品**
* 现在可以在已穿戴不同种类盔甲时按下“装备”按钮来装备自定义盔甲。（）
