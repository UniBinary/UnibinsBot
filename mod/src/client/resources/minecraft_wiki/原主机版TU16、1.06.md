# 原主机版TU16、1.06

*页面ID: 83458* | *来源: Minecraft Wiki*

* *TU16/1.06**是[原主机版](原主机版.md)的一次更新，发布于2014年5月19日和28日。<ref></ref>

# 新内容
# = 常规 =
* *[纹理包](纹理包.md)**
* PS3：加入糖果纹理包。
* PS3：加入自然纹理包。
* *[皮肤包](皮肤包.md)**
* PS3：加入皮肤包2。
* PS3：加入战斗与野兽2皮肤包。

# 修复
* *修复了20个漏洞**
* 修复了玩家死亡后重生时隐身的漏洞。
* 修复了两个玩家同时通过下界传送门玩家隐身的漏洞。
* 修复了玩家传送后直到其移动前隐身的漏洞。
* 修复了音符盒音高错误的漏洞——在演奏和弦时更明显。
* 修复了死在墙上的生物（会发生在幼年生物成年后）。
* 修复未在地图中加载的区块 - 通常是特定的种子码。
* 修复了正在播放的CD从唱片机弹出后无法播放音乐的漏洞。
* 修复了玩家可以在箱子上方已经放置一个方块的情况下将告示牌放置到箱子上的漏洞。
* 修复了玩家能够繁殖未驯服豹猫的漏洞。
* 修复了玩家可以用猫繁殖豹猫的漏洞。
* 修复了当被驯服的狼生气时没有玩家靠近它们它们会消失的漏洞。
* 修复了夜视效果玩家掉入末地虚空时游戏用户界面被破坏的漏洞。
* 修复了在游玩本地分屏游戏时，如果玩家在生存模式下彼此离太远，则会崩溃闪烁和/或消失的漏洞。
* 修復了當其他玩家距離主要玩家30格以上時，不會在分屏中顯示傷害貼图的漏洞。
* 修复了熔岩颗粒过暗的漏洞。
* 修复了坐在狼（或静止实体）上如果远程玩家在它们旁边生成或生成很远并快速朝它们时无法立即见看见的漏洞。
* 修复了附魔皮革盔甲不显示附魔光效的问题。
* 修复了手中的附魔物品效果错误。
* 修复了放置在Y=128的方块呈黑色的漏洞。
* PS3：语音聊天修复。
