# 新内容（实验性）
以下内容属于“冬季小更新”。

# = 方块 =
* *[苍白橡树树苗](苍白橡树树苗.md)**
* 一种新的树苗，由苍白橡树树叶掉落，也可通过[交易](交易.md)获取。
* 与[深色橡树树苗](深色橡树树苗.md)一样，单个无法生长，在2×2空间摆放的4个苍白橡树树苗才可生长为苍白橡树。

* *[苍白橡树树叶](苍白橡树树叶.md)**
* 随苍白橡树生成的自然方块。

* *[苍白橡木原木](苍白橡木原木.md)**
* 随苍白橡树生成的自然方块。
* 有对应的去皮变种。
* * 可以合成对应种类的[悬挂式告示牌](悬挂式告示牌.md)。

* *[](苍白橡木.md)**
* 由4个苍白橡木原木合成。
* 有对应的去皮变种。

* *[苍白橡木木板](苍白橡木木板.md)**
* 一种新的木板。
* 可用于合成对应的[按钮](按钮.md)、[门](门.md)、[栅栏](栅栏.md)、[栅栏门](栅栏门.md)、[压力板](压力板.md)、[告示牌](告示牌.md)、[台阶](台阶.md)、[楼梯](楼梯.md)、[活板门](活板门.md)、[船](船.md)和[运输船](运输船.md)。

* *[苍白苔藓块](苍白苔藓块.md)**
* 自然生成于苍白之园生物群系中。
* 类似于[苔藓块](苔藓块.md)，植物类方块能放置在其上。

* *[苍白覆地苔藓](苍白覆地苔藓.md)**
* 自然生成于苍白之园生物群系中。
* 放置时，会尝试依附相邻的方块向上延伸至多两格。
* 对其骨粉时，会向所有相邻方块的对应面延伸。

* *[苍白垂须](苍白垂须.md)**
* 自然生成于苍白之园生物群系中苍白橡树的树叶下方的网状藤蔓。
* 不因随机刻自然生长，但可使用骨粉使其向下生长。
* 在使用[剪刀](剪刀.md)或附有[精准采集](精准采集.md)的工具破坏时掉落对应的[方块物品](方块物品.md)。

* *[嘎枝之心](嘎枝之心.md)**
* 生成于苍白橡树的树干中，四周均被苍白橡木原木覆盖。
* 如果放置在朝向正确的苍白橡木原木之间，它会在夜晚或雷暴时激活，并在水平16格、竖直8格范围内生成嘎枝。
* 所生成的嘎枝被玩家攻击时会发出指向该方块的粒子效果。
* 被破坏时，所生成的嘎枝会一并被移除。
* [斧](斧.md)是破坏此方块的合适工具，但只有附有精准采集的工具能通过破坏使其掉落对应的方块物品。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了嘎枝刷怪蛋，所生成的嘎枝（ID为<code>creaking</code>）不会随着[昼夜更替](昼夜更替.md)或[天气](天气.md)变化而消失，能够受伤、穿越传送门。

# = 生物 =
* *[嘎枝](嘎枝.md)**
* 一种生命值为的敌对生物。
* 在玩家视野内时不会移动，除非看着它的所有玩家都戴着[雕刻南瓜](雕刻南瓜.md)。
* 不会为[船](船.md)所困。
* 由嘎枝之心生成的嘎枝（ID为<code>creaking_transient</code>）[无懈可击](无懈可击.md)，只有在嘎枝之心被摧毁时才会死亡。
* * 这种嘎枝不受光照亮度影响，但会随着昼夜更替和天气变化而消失与生成。
* * 不能穿越传送门。
* * 不会被保存或加载。
* * 不能被刷怪蛋或命令生成。
* ** 由嘎枝刷怪蛋生成的嘎枝（ID为<code>creaking</code>）不具有上述特性，但仍然免疫火焰伤害。
* [灾厄村民](灾厄村民.md)会主动远离嘎枝。

# = 非生物实体 =
* *[苍白橡木船](苍白橡木船.md)**
* 由苍白橡木木板合成的船变种。

* *[苍白橡木运输船](苍白橡木运输船.md)**
* 由苍白橡木木板合成的运输船变种。

# = 世界生成 =
* *[苍白之园](苍白之园.md)**
* [黑森林](黑森林.md)的新变种。
* 会自然生成悬有苍白垂须的苍白橡树，地表覆盖着苍白苔藓块或苍白覆地苔藓。
* [动物](动物.md)类生物不会在这里自然生成。
* 拥有独特的、由此生物群系中的方块产生的环境音效。
* * 这些音效主要由依附于苍白橡树树叶或原木的苍白垂须和夜间激活的嘎枝之心方块产生。

* *[苍白橡树](苍白橡树.md)**
* 自然生成于苍白之园生物群系中的树类地物。
* * 树干内可能藏有嘎枝之心。
* * 一些树叶下方悬挂着苍白垂须。
