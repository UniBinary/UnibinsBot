* *铜活板门（Copper Trapdoor）**是由[铜锭](铜锭.md)制成的可手动开关的[活板门](活板门.md)。

# 生成
铜活板门、斑驳的铜活板门、锈蚀的铜活板门、涂蜡的铜活板门、涂蜡的斑驳铜活板门和涂蜡的锈蚀铜活板门不会生成在世界中，只能通过[氧化](氧化.md)机制生成。

# = 自然生成 =
氧化的铜活板门和涂蜡的氧化铜活板门可以生成在[试炼密室](试炼密室.md)的柱廊和交叉口中。

# 破坏
挖掘铜活板门的合适工具是镐。铜活板门需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

铜活板门被破坏后会掉落自身。

# 用途

对着铜活板门按下键可将其打开或关闭，处于[风爆](爆炸#风爆.md)影响范围中时也会改变其开关状态。

# = 红石元件 =

被激活的铜活板门和仍然可以被玩家或村民手动关闭，但在接收到新的上升沿或之前，活板门不会再次自动打开（即需要将红石信号关闭再开启才能重新控制活板门）。

# = 氧化 =

铜活板门受氧化机制影响，能够在不同变种之间转化。
