* *尸（Husk）**是生成在沙漠中的[僵尸](僵尸.md)变种。

# 生成
尸壳会在[沙漠](沙漠.md)中[内部天空光照](亮度#内部天空光照.md)小于等于7，且[方块光照](亮度#方块光照.md)为0的[可生成位置](生成#可生成位置.md)上生成。

尸壳在沙漠中有80%的概率取代僵尸生成于地表。<ref name="husk-spawn" group="注">当一个位置的[天空光照等级](亮度#天空光照.md)等于15时，尸壳生成系统会将其视为地表。</ref>

尸壳在沙漠中有70%的概率取代僵尸生成。

尸壳自然生成时，有10%的概率再生成一个骆驼尸壳作为坐骑，此时尸壳将手持[铁矛](铁矛.md)。

尸壳会作为骆驼尸壳的乘客自然生成于沙漠。

# = 试炼刷怪笼 =
[试炼密室](试炼密室.md)中的近战型[试炼刷怪笼](试炼刷怪笼.md)包含尸壳试炼刷怪笼。

# = 增援 =

在困难[难度](难度.md)下，尸壳受到攻击时可能会生成增援尸壳，详见[僵尸增援](僵尸增援.md)。

# 变种
# = 幼年尸壳 =
[缩略图|三只成年尸壳和一只幼年尸壳](File:HuskAndBaby.png.md)
[thumb|基岩版中幼年尸壳可骑乘的所有生物](File:Baby Husk Jockeys.png.md)
尸壳有5%的概率会生成为幼年尸壳。幼年尸壳的特性与成年尸壳略有不同：
* 移动速度比普通尸壳快50%，但生命值与之相同，使其更加难以对付。
* 叫声的音调比成年尸壳高。
* 穿戴的[盔甲](盔甲.md)会缩小以适应身体尺寸。
* 有缩小的碰撞箱，可以穿过1×1格的空间。
* 被[玩家](玩家.md)或驯服的[狼](狼.md)杀死时会掉落，而不是。
* 永远不会成长为成年尸壳。
幼年尸壳有5%的概率会在附近的[鸡](鸡.md)上生成成为[鸡骑士](鸡骑士.md)（如果附近没有鸡则生成失败），还有4.75%的概率附带一只[鸡](鸡.md)生成成为[鸡骑士](鸡骑士.md)。

* 骑士的速度为幼年尸壳的速度，而不是坐骑本身的速度。
* 如果幼年尸壳骑乘的是玩家可骑乘的生物，该生物将不可再被玩家骑乘。

# = 经验 =
被玩家或驯服的狼杀死时，成年尸壳会掉落，幼年尸壳会掉落。每个自然生成的或会额外掉落。

# = 万圣节 =

在[万圣夜](wzh:万圣夜.md)（10月31日）当天，尸壳生成时有22.5%的概率戴着[雕刻南瓜](雕刻南瓜.md)，有2.5%的概率戴着[南瓜灯](南瓜灯.md)，但雕刻南瓜或南瓜灯不会掉落。<ref></ref>

# 行为

[thumb|一只溺水的尸壳转变为僵尸](File:Husk becoming Zombie.gif.md)
尸壳会追杀或<ref></ref>格以内的玩家、[铁傀儡](铁傀儡.md)、、[村民](村民.md)、[流浪商人](流浪商人.md)和幼年[海龟](海龟.md)。它们会尝试避开障碍物，包括悬崖、[水](水.md)和[熔岩](熔岩.md)，并且尝试寻找接近玩家最近的路线。

尸壳在攻击时会对目标施加或的[饥饿](饥饿（状态效果）.md)效果。手持或的尸壳在攻击时不会对目标施加饥饿效果。

在困难模式中，尸壳会破坏[木门](木门.md)和[铜门](铜门.md)。

尸壳会寻找周围的[海龟蛋](海龟蛋.md)并尝试踩碎它。

与大多数亡灵生物相同，尸壳在[游戏规则](游戏规则.md)设置为时能够拾起物品，并且拾起物品后的尸壳不再会自然消失。

当尸壳在水里超过时，会开始转化为僵尸，再经转化完成。尸壳装备的盔甲和手持物品会在转化后掉落，但转化而成的僵尸也可能会重新捡起来穿戴上。

如果一个[僵尸](僵尸.md)或尸壳被其他生物所攻击，附近没有目标的尸壳会向该生物产生敌意。

# = 生物族群 =

尸壳是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉直到接触水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

尸壳不会在阳光下[着火](着火.md)。
