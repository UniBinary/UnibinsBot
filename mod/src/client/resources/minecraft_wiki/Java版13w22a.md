* *13w22a**是[Java版1.6.1](Java版1.6.1.md)的第10个快照，发布于2013年5月30日<ref></ref>，为许多生物加入了音效，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[马](马.md)、[驴](驴.md)、[骡](骡.md)、[僵尸马](僵尸马.md)和[骷髅马](骷髅马.md)**
* 加入了音效。

* *[村民](村民.md)**
* 加入了音效。
* * 声音包括多种空闲，接受，拒绝，争论和被攻击的声音，以及单一的死亡声音。

# 更改
# = 物品 =
* *[拴绳](拴绳.md)**
* 有了更高的拉伸度，这使其更难断裂。
