# Java版1.4.3

*页面ID: 32786* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.4.3**是[Java版1.4.4](Java版1.4.4.md)的一个预发布版，发布于2012年11月1日<ref></ref>，加入了一个新的[音乐唱片](音乐唱片.md)并修复了许多漏洞。

# 新内容
# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* 加入了唱片wait。
* * 这个唱片最初是在[Beta 1.9-pre2](Java版Beta 1.9-pre2.md)中加入的，名为“Where are we now”，但由于名称中空格的漏洞而无法使用，因此将其改名为“wait”。

# 更改
# = 方块 =
* *[水](水.md)**
* 现在水能够完全抵消所有的摔落伤害。<ref></ref>
