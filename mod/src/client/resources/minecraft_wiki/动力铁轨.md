# 动力铁轨

*页面ID: 7693* | *来源: Minecraft Wiki*

* *动力铁轨（Powered Rail）**是能够加速或刹停[矿车](矿车.md)的方块。

# 生成
动力铁轨不会生成在世界中。

# = 箱子战利品 =

# 破坏
挖掘动力铁轨的合适工具是镐。

动力铁轨被破坏后会掉落自身。

# 用途

动力铁轨是铁轨和[红石元件](红石元件.md)，能改变[矿车](矿车.md)的速度。一系列相连的铁轨（包括普通[铁轨](铁轨.md)、动力铁轨、[探测铁轨](探测铁轨.md)和[激活铁轨](激活铁轨.md)）被称作**轨道**。

动力铁轨会在没有合适方块（见）支撑或时[掉落](掉落.md)为[物品](物品.md)。

如果熔岩流过动力铁轨，动力铁轨将会被摧毁且不会掉落物品。

# = 生物 =
除了玩家和[监守者](监守者.md)以外的所有生物在寻路时不会将动力铁轨视为可以走上或跨越的方块，除非它们正站在任意类型的铁轨上。

# = 放置 =
[thumb|铁轨可能连接到的所有位置，图中以普通铁轨为基准](File:All linked rails.png.md)
动力铁轨只能放置在上表面[边缘完整](方块支撑形状.md)的方块上。尝试把动力铁轨放置在方块的侧面或底面时，如果这些面邻近的顶面符合条件，动力铁轨会放在邻近的顶面上。

动力铁轨可以和水平方向上相邻一格的铁轨相连，也可以和这些相邻铁轨上方或下方一格的铁轨相连。动力铁轨可以和其他种类的[铁轨](铁轨（消歧义）.md)相连。

放置动力铁轨时，动力铁轨会或。然后，新放置的动力铁轨和临近的铁轨会立即检查自己是否可以与其他铁轨相连并改变方向：
* 如果有1个铁轨可供连接，动力铁轨会呈直线连接已有铁轨，朝南-北方向或东-西方向；
* 如果有2个铁轨可供连接：
* * 如果这两个铁轨都是朝南-北方向或东-西方向的，动力铁轨会直接连接这两个铁轨；
* * 否则，动力铁轨在放下后会或；
* 如果有超过2个的铁轨可供连接，动力铁轨会按照或的顺序检查这些铁轨是否可以连接，如果都无法连接则或。

在这个检查的过程中，已经以南-北或东-西方式连接了其他铁轨的铁轨会被忽略。

# = 铁轨 =

动力铁轨（和其他铁轨）可以被用作矿车行驶的“道路”。从任意一端驶入动力铁轨的矿车会继续向原来的方向运动，但根据动力铁轨的状态，矿车的速度会有所改变（见下）。从动力铁轨的侧面“撞”进来的矿车会转向东方或南方（视动力铁轨的走向而定）；若动力铁轨有斜坡，矿车会转向下方。

# = 红石元件 =

当矿车驶过时，动力铁轨能改变它们的速度。

; 激活
动力铁轨是[机械元件](红石元件#机械元件.md)，它可被下列方式激活：
* 毗邻的开启的**[电源](红石元件#电源.md)**（例外：[侦测器](侦测器.md)只会激活指向的动力铁轨）。
* 毗邻的**[充能方块](红石电路/充能与激活.md)**。
* 毗邻的指向动力铁轨且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)；毗邻但未指向动力铁轨的红石粉不会激活动力铁轨。
[thumb|中89个被激活的动力铁轨](File:Powered rail signal bifurcation.png.md)

激活的动力铁轨亦可激活邻近并与其连接的其他动力铁轨，从原始激活源开始至多能传递8格。激活的动力铁轨不会激活邻近的不与其连接的动力铁轨，但能激活自己不连接的、逆信号传递方向与其单向连接的动力铁轨，使信号分叉。因此单个激活源可激活至多或个动力铁轨（中间1个和两边各或个）。

; 行为
* *激活**的动力铁轨会：
* 加速正在运动的矿车（无论南北方向或东西方向）。
* 使矿车加速离开另一端的或时（当动力铁轨的一端堵着对应方块时，静止的矿车会在动力铁轨激活时朝另一端运动；而从另一端驶来的矿车由于接到反方向的加速度，会被动力铁轨“弹开”）。

* *未激活**的动力铁轨会：
* 降低矿车的移动速度，正常情况下至多2格即可完全刹停矿车（即使矿车正在下坡）。

动力铁轨不会将矿车的速度提升至8格/秒以上。但使用特殊的动力铁轨布局或常规铁轨的穿插可以实现更高的速度，详见[Tutorial:矿车](Tutorial:矿车.md)。可修改速度上限。}}
