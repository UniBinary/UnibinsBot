# Realms Plus

*页面ID: 50507* | *来源: Minecraft Wiki*

}}

* *Minecraft Realms Plus**是官方的订阅式[服务器](服务器.md)托管服务。玩家可以创建并管理自己的Minecraft私人服务器。[Mojang](Mojang.md)运营的Realms Plus是简单快捷创建服务器的方式，还可以提供在游戏内管理服务器的方式，也无需服务器主人预先了解互联网运营的知识。Realms Plus还允许玩家从由Mojang提供的内容列表中自由选择，列表大约每月更新一次。Realms Plus并非为大型公共服务器准备，主要受众为家庭或朋友的小圈子。<ref></ref>

# 要求
Realms Plus只向符合下列条件的玩家开放<ref></ref>：

* 玩家必须拥有一个[Xbox Live账号](https://www.xbox.com/live)，并且已经购买了[基岩版](基岩版.md)。
* 有良好的互联网连接。
* 要加入Realms社区，玩家年龄还需在13岁以上。
* 主机玩家必须在其设备上订阅支持多人游戏的服务：
* * Xbox玩家需订阅[Xbox Game Pass Core或Xbox Game Pass Ultimate](wzh:Xbox Game Pass.md)
* * PlayStation 4玩家需订阅[PlayStation Plus](wzh:PlayStation Plus.md)
* * Nintendo Switch玩家需订阅[Nintendo Switch Online](wzh:Nintendo Switch Online.md)

# 订阅

Realms Plus是基于订阅的服务。上方的链接会将玩家导向游戏内的商城，然后允许玩家续订当前的Realms Plus或购买新的服务，价格为$7.99/月。

所有玩家都有30日的免费Realms Plus试用，只要其Xbox Live账户之前没有使用过此试用。

# 内容
所有内容均由Minecraft内容团队选定。
