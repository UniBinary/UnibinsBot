# Java版12w17a

*页面ID: 32365* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w17a**是[Java版1.3.1](Java版1.3.1.md)的第3个快照，发布于2012年4月26日<ref></ref>，加入了多种台阶、书与笔以及成书，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[台阶](台阶.md)**
* 加入了与四种木板颜色相同的台阶。
* * 双木台阶有了新的方块ID125，单木台阶则为126。
* * 这些新的台阶不再表现得像石头那样。
* * [斧](斧.md)可有效挖掘它们。
* * 不再免疫[火](火.md)和[熔岩](熔岩.md)。
* * 在旧版中制作的木质台阶仍然表现得像石头并且防火，当放置或开采时不会变成新的台阶。

# = 物品 =
* *[书与笔](书与笔.md)**
* 可编辑的书——书与笔，用[书](书.md)、[皮革](皮革.md)和[墨囊](墨囊.md)合成。
* * 制作完成后，手持右键点击会弹出一个界面，从而允许玩家输入文字。
* * 按下“保存”会保存文字并允许玩家再次编辑，而不是“署名”。
* * “署名”时可以输入16字节长的标题并且不再能编辑，书与笔会变成成书，图标和标签一起被改变。

* *[成书](成书.md)**
* 外观和普通的书相似，但带有物品附魔后的效果。
* 由书与笔署名后获得，书中内容不能被编辑。

# = 命令 =
* *常规**
* 加入了。

# = 常规 =
* *[选项](选项.md)**
* 加入了“聊天选项”。
* * 加入了聊天框不透明度，让聊天变得半透明。
* * 加入了聊天开关，用于移除多人游戏下的聊天。
* * 加入了聊天字体颜色选项。
* * 在聊天中加入“仅限命令”模式。

# 更改
# = 方块 =
* *[冰](冰.md)**
* 在[下界](下界.md)中的冰不再变成[水](水.md)。

* *[树苗](树苗.md)**
* 树苗有了正确的名字（例如：云杉树苗）。

# = 物品 =
* *[书](书.md)**
* 现在需要用到[皮革](皮革.md)制作书。

# = 生物 =
* *被动型生物**
* 在非常拥挤的情况下可以“穿过”玩家而不是不停推动。

# = 非生物实体 =
* *[船](船.md)**
* 在创造模式下现在能一击摧毁。

* *[矿车](矿车.md)**
* 在创造模式下现在能一击摧毁。

# = 游戏内容 =
* *[创造模式](创造模式.md)**
* [创造模式](创造模式.md)下的[工具](工具.md)有了无限的[耐久度](耐久度.md)。
* [创造模式](创造模式.md)下的[矿车](矿车.md)和[船](船.md)可以一击即破。
* 飞行着穿过水流不再减速。

* *[魔咒](魔咒.md)**
* 精准采集现在能用于开采[冰](冰.md)和[玻璃板](玻璃板.md)。

* *[极限模式](极限模式.md)**
* 不再能开启[奖励箱](奖励箱.md)和[极限模式](极限模式.md)。

# = 命令格式 =
* *常规**
* 多人游戏中命令被显示成*斜体*。

# 修复
* *修复了3个漏洞**
* 修复了实体的碰撞错误。
* 修复了拾取方块的功能。
* 修复了聊天问题。</onlyinclude>
