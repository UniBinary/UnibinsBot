# 末地传送门框架

*页面ID: 7751* | *来源: Minecraft Wiki*

* *末地传送门框架（End Portal Frame）**是组成[末地传送门](末地传送门.md)的方块，有与[末地石](末地石.md)相似的纹理，顶部与侧面带有蓝绿色花纹。

# 生成
# = 自然生成 =

每个[要塞](要塞.md)都会生成一个末地传送门，包含12个末地传送门框架，每个框架都有10%的概率被插上[末影之眼](末影之眼.md)。

# 获取

末地传送门框架无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，末地传送门框架可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
末地传送门框架不能被挖掘破坏。

末地传送门框架被破坏后不会掉落。

# 用途
|末地传送门摆放方式}}
末地传送门框架用于组成末地传送门，其顶部可被插上[末影之眼](末影之眼.md)。对末地传送门框架末影之眼可将末影之眼放在末地传送门框架的顶端。若将末地传送门框架摆放为末地传送门的样式，并将所有12个方块都放上末影之眼，末地传送门就会激活，玩家可通过末地传送门方块进入[末地](末地.md)。

和[基岩](基岩.md)一样，末地传送门框架不能通过挖掘或者常规的爆炸来破坏，也不能被[凋灵](凋灵.md)和[末影龙](末影龙.md)破坏。其只能在[创造模式](创造模式.md)中被破坏。

# = 放置 =
末地传送门框架有方向，会朝向东南西北四个方向之一。

放置末地传送门框架时，被放置的末地传送门框架会朝向玩家面向方向的相反方向。

玩家可以在任何位置摆出末地传送门的结构并将其激活。所有的构成末地传送门的12个末地传送门框架都必须朝向中间3×3的末地传送门方块区域，否则末地传送门不能被正确地激活<ref></ref>。

# = 红石元件 =
[红石比较器](红石比较器.md)可检测末地传送门框架的顶部是否有[末影之眼](末影之眼.md)。
* 若有，则获得强度为15的红石信号。
* 若无，则信号为0。

# = 光源 =
末地传送门框架会发出亮度为1的光。

# 你知道吗
* 摧毁末地传送门框架不会使传送门本身关闭，而摧毁末地传送门框架会像摧毁[下界传送门](下界传送门.md)的框架那样使传送门关闭。
* 尽管末地传送门框架基部使用的纹理与末地石相似，但其破坏音效使用了和[玻璃](玻璃.md)相同的音效。
