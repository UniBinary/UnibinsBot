# 边境之地/基岩版/1.17.20.20之前“洞穴及悬崖”实验性玩法中的现象

*页面ID: 152967* | *来源: Minecraft Wiki*

[缩略图|边境之角（上）、平顶边境之墙（左）、边境之墙（右）和正常世界（下）](File:1.16.230.56 expFarlands2.jpg.md)

下面介绍了[1.16.230.56](基岩版1.16.230.56.md)至[1.17.20.20](基岩版1.17.20.20.md)之间“”实验性玩法世界中的边境之地。

# 位置
边境之地会在X/Z=+12,550,821和X/Z=-12,550,824开始向外生成。

# 结构
# = 在不同平台上的差异 =
除了移动端上的边境之地以外，其余平台上边境之地的现象仍不清楚。

该页面主要记录移动端平台上的边境之地。

# = 不同安装包之间的差异 =
不同于ARMv7的基岩版，在ARMv8架构的基岩版中，在X/Z轴负方向上边境之墙和边境之角会正常生成，而非平顶边境之墙和边境高墙。

# = 边境之地 =
[缩略图|两个边境之墙交汇处，形成了边境之角](File:1.16.230.56 expFarlands1.jpg.md)

边境之地不会在[超平坦世界](超平坦世界.md)中生成，因为这种情况下不会使用噪声生成器。

[基岩版](基岩版.md)的边境之地与Java版的[Beta 1.8之前的边境之地](边境之地/Java版Beta1.8之前版本的现象.md)稍有不同，如在基岩版边境之地内生成的沙子和沙砾不会掉落。这使得基岩版边境之地的加载相对稳定。虽然最高可建筑高度为255格，但边境之地的地形仍然会在Y=128，Y=134或Y=256处被切断，尽管在其顶端的树仍然会正常生成。

[沉船](沉船.md)和[水下遗迹](水下遗迹.md)会在地表生成。而埋藏的宝藏和化石会在半空中生成，不接触任何方块。

洞穴也可以在边境之地中的任何位置生成，包括平顶边境之墙，边境之角和边境高墙。

# == 边境之墙 ==
[缩略图|边境之墙](File:1.16.230.56 expFarlands3.jpg.md)

# == 边境之角 ==
[缩略图|边境之角](File:1.16.230.56 expFarlands4.jpg.md)

与[Java版的边境之角](边境之地/Java版/Infdev 20100327至Beta 1.7.3的现象#边境之角.md)类似，两个边境之墙的交汇处会生成堆叠型地形的边境之角。但与之不同的是，边境之角会高达Y=134而非Y=128。相较于边境之墙的蜂窝高墙，边境之角的地形要正常一些。边境之角以一个较为正常的地形为基础，一个一个地往上堆叠，中间留下空气夹层，成为一个巨大的“三明治”。每一层地形都像是一个巨大的浮空岛，但除了最顶端的一层，其余各层都是几乎黑暗的。

边境之角的堆叠层数不是固定的，有可能是6层到9层。这些堆叠层可以分为4类：

* 最顶层：这一层在边境之角的最高处，上面可能会生成一些植被。

* 干燥层：这一类层会稍微平坦一些，也会出现树木，但整体是几乎处于黑暗当中的。一些堆叠层有着类似于洞穴的天花板，而另一些则有着完全方正的由石头构成的墙壁。

* 淹没层：跟干燥层相似，这些堆叠层会稍微平坦一些，但主要由石头构成。洞穴会在此处生成，形成粗糙的墙壁，而干燥层完全方正的墙壁在此处仍会生成，从而形成了独特的景观。

* 洞穴层：整体环境与干燥层类似，这一类层会生成空阔的，且拥有方正石头墙壁的洞穴，同时也有可能会大量暴露出基岩层。与淹没层不同，这一层不会被水淹没。

# == 平顶边境之墙 ==

[缩略图|平顶边境之墙](File:1.16.230.56 expFarlands5.jpg.md)

Z=-12,550,821以外会生成平顶边境之墙，与常规边境之墙不同的是，平顶边境之墙高达Y=134而非Y=128，且这类地形通常拥有着厚的“天花板”，除了洞穴以外“天花板”通常不会出现缝隙。

与X轴正方向和Z轴正方向上的边境之墙相同，平顶边境之墙和靠近平顶边境之墙的边境之角也会逐渐变宽，但这有一定限度。在Z=+12,758,545之后，平顶边境之墙从外观看与边境高墙相当相似，但与之不同的是其内部也只会生成充满[空气](空气.md)和[水](水.md)的“长方体”，一直到32位整数限制。

ARMv8架构的基岩版中不会生成该地形。

# == 边境高墙 ==

[缩略图|边境高墙](File:1.16.230.56 expFarlands6.jpg.md)

在X=+12,758,545之后，边境之墙完全消失，之后只会生成一堵完全实心的边境高墙，这与[Java版边境之地的最初形态](边境之地/Java版/Infdev 20100325及之前版本的现象.md)类似，但与之不同的是边境高墙顶端会生成一些植被。

与常规的边境之墙不同，边境高墙可达Y=134而非Y=128。

# = 山地边境之地 =

[缩略图|山地边境之地](File:1.16.230.56 expFarlands7.jpg.md)

山地边境之地会生成在[山地](山地.md)生物群系，其形态与常规边境之地类似，但与后者不同的是前者的高度直达Y=256而非Y=128，其与常规边境之地之间还会生成“丘陵边境之地”以实现地形的过渡，“丘陵边境之地”通常有着比较方正的地形，其上通常也会生成一些森林。

# 其他维度

由于[下界](下界.md)、[末地](末地.md)的地形生成器尚未变动，因此这两个维度的边境之地都与未打开“洞穴及山崖”实验性玩法的世界中一致。
