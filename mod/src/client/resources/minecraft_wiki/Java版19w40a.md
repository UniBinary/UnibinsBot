# Java版19w40a

*页面ID: 48551* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w40a**是[Java版1.15](Java版1.15.md)的第8个快照，发布于2019年10月2日<ref name="19w40a"></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[鹦鹉](鹦鹉.md)**
* 现在玩家骑乘着其他实体时，鹦鹉也能站在该玩家的肩膀上。

# = 常规 =
* *[方块模型](方块模型.md)**
* 将方块在物品栏中的外观恢复到了[19w39a](19w39a.md)前的样子（亮面在左，暗面在右）。但现在物品栏中的模型比之前更亮了。
