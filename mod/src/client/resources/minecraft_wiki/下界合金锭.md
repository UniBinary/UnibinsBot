# 下界合金锭

*页面ID: 52393* | *来源: Minecraft Wiki*

* *下界合金锭（Netherite Ingot）**是用于制作游戏中最高级别的[工具](工具.md)、[武器](武器.md)和[盔甲](盔甲.md)的材料，其[物品实体](物品实体.md)形式不会被[火](火.md)或[熔岩](熔岩.md)烧毁。

# 获取
下界合金锭可由四个[下界合金碎片](下界合金碎片.md)和四个[金锭](金锭.md)合成而来，合成配方是无序的，也可由[下界合金块](下界合金块.md)分解得到。

# 用途
[物品实体](物品实体.md)形式的下界合金锭会漂浮在[熔岩](熔岩.md)上，且不会被[火](火.md)和熔岩摧毁，但仍可被[仙人掌](仙人掌.md)或爆炸等方式摧毁。

# = 锻造 =
在[锻造台](锻造台.md)上，下界合金锭可用于将钻石装备升级为下界合金装备。耐久度、魔咒和自定义名称等[物品堆叠组件](物品堆叠组件.md)数据会被保留。

下界合金锭也可用于给任意盔甲加上纹饰，但不会提升盔甲属性。耐久度、魔咒和自定义名称等物品堆叠组件数据会被保留。
