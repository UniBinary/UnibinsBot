# Herobrine

*页面ID: 7456* | *来源: Minecraft Wiki*

[缩略图|x300px|Herobrine](File:Herobrine.png.md)

* *Herobrine**（）是[Minecraft](Minecraft.md)相关社区创作的[恐怖故事](wzh:Creepypasta.md)主角，也是Minecraft社区内容的重要标志形象之一，且从未在任何官方版本的Minecraft中出现。

首个提及Herobrine的帖子所包含的故事、图片，以及Brocraft的直播视频，通常被视作Herobrine传说的“经典”版本。此后出现的所有相关内容或设定，均被认为是爱好者基于该“经典”版本进行的二次创作或改编。

# Herobrine是否存在
Herobrine**不存在**于原版Minecraft中，且在历史上从未在原版游戏内出现过。

从技术层面看，Minecraft的源代码中无任何关于Herobrine的引用，也不存在允许生成具有类似Herobrine行为的[实体](实体.md)的代码。

在无Mod、未经修改的[客户端](客户端.md)或[服务器](服务器.md)中，不存在任何可使Herobrine出现的方法。游戏内若出现Herobrine相关表现，通常是因玩家安装了特定[Mod](Mod.md)、[数据包](数据包.md)，或其他玩家使用了Herobrine的[皮肤](皮肤.md)所致。

# 起源与流行

[缩略图|流传的Herobrine的故事](File:1283223082465.jpg.md)

在早期流行的恐怖故事中，Herobrine会随机搭建结构，例如海洋中的沙子金字塔、矿洞中的苔石金字塔，以及长长的2×2隧道等。他还会砍掉树上所有的[树叶](树叶.md)。

Herobrine首次出现在一个描述玩家目击Herobrine过程的帖子内的一张的图片中。这个帖子发布在[4chan](wzh:4chan.md)的/v/板块上，它在论坛发表后只有很少人注意到。它叙述了Herobrine是如何出现在自己的单人游戏中，并到处建造小金字塔和隧道的。这是早期社交网络上称它为“Herobrine”的一个例子。

# = 白眼 =
2010年7月31日，[Minecraft Forum](Minecraft Forum.md)用户Flaky发表了一条评论，据说是从4chan的/v/板块上的一个帖子复制的，其中包含玩家听了[音乐唱片](音乐唱片.md)“11”之后遇到一个有着发光的白色眼睛的实体的故事。<ref></ref>评论中留下了关于这双眼睛的猜想，在该评论发表的前一天（也就是唱片加入到游戏中的同一天）上传至YouTube的“13”，展示了一个黑暗的[洞穴](洞穴.md)，左下角有一双白色的眼睛。<ref></ref>这个故事是Minecraft中首个与白眼超自然生物相关的都市传说。

第二天，论坛用户Endorphine发布了一个帖子，讲述了一个关于[Alpha v1.0.3](Java版Alpha v1.0.3.md)中为洞穴加入[环境音效](环境音效.md)的故事，每当这些声音播放时，就会出现“一对白色像素”。<ref></ref>同样的视频作为这些白色像素出现的例子被链接。该实体被称作“白眼”，一种雌性生物，她会从远处跟踪玩家，除了空白的白色眼睛外，没有任何明显的特征。<ref></ref>

# = Copeland的直播 =

[缩略图|Herobrine首次“出现”在Brocraft的视频中](File:1286120683579.png.md)
[缩略图|上图的高清还原版](File:1286120683579-REMASTERED.png.md)
[缩略图|250px|Herobrine的恶作剧直播结束时，Brocraft的所有观众被重定向到的图片](File:HerobrineBrocastCreepyPage.gif.md)

直到后来，当一个叫“Copeland”的Brocraft主播把Herobrine PS进几张截图并展示在聊天里后，Herobrine才获得越来越高的人气。他逐渐迷上了这个故事，并希望自己成为这个故事的一部分。在获得大量良好响应后，他决定筹划一个恶作剧。他在一封邮件里解释了这件事情的详细经过。<ref>[Copeland对Herobrine恶作剧的叙述](Herobrine/直播幕后.md)</ref>

当时，Copeland以一名普通玩家的身份在一个世界中游玩，但故意避开了正在建设的用于恶作剧的房间。Herobrine出现在直播视频的20:45处，其已被确认是一幅被修改过纹理的[画](画.md)。之后，Copeland尖叫着跑出了房间，并迅速结束了直播。

在聊天中，Copeland假装被吓到了，随后又在论坛上发布了一个帖子，其中包含指向该直播视频的链接，希望以此将这个故事广泛散播，并获得与上一次类似的响应。<ref></ref>

不久，Copeland移除了这幅画并把它改回了正常的纹理。他继续进行直播，假装自己很害怕。他宣称自己将会删除世界，以此确保自己永远不会再见到Herobrine。

后来，Patimuss制作了一个视频。在这个视频里，Herobrine出现在玩家自制的[熔岩](熔岩.md)池里。这次的Herobrine是独立存在的<!--即没有依附着其他方块-->。由此看来，它很可能是一扇被修改过纹理的[门](门.md)。在Patimuss跑开并保存游戏后，直播中断。仅仅10分钟后直播便恢复，但Herobrine消失了。<ref>[Patimuss的直播视频](http://www.livestream.com/minecrafterryday/video?clipId=pla_7c528f18-2c03-4cb2-9e14-9ee8e4e7d312&utm_source=lslibrary&utm_medium=ui-thumb)</ref>

后来，在Patimuss的第二次直播中，观众听到了他对自己的妻子说自己是在调戏观众，结果导致直播评论数量直线上升。Patimuss随即放出了一个假的游戏崩溃画面。Copeland对Patimuss将Herobrine是个骗局的事实暴露出来一事很不满意。

Patimuss视频中发生之事的准确时间尚不明确，但Copeland随后在聊天中发布了一条链接，指向[http://ghostinthestream.net/him.html](http://ghostinthestream.net/him.html)（该网址的存档[在此](http://web.archive.org/web/20130710001351/http://ghostinthestream.net/him.html)）。这很可能是Herobrine“HIM”的简写的由来。网页内容是Herobrine（或者说Steve）的脸，但其眼睛被改为全黑，其中还分别有一颗四处转动的眼珠。

在这张脸的下面，有一大串字符。将所有非字母字符去掉后，就有了以下这段文字：

译文：

这段信息不断暗示观看者们自己正处于一个幻想世界中，并且需要“醒来”，而这些文字就是文中的那个“提示”。

上面的文字来自另一个标题为“Wake Up”（醒来）的恐怖故事。<ref>[Wake Up?](https://www.creepypasta.com/wake-up/) – Creepypasta.com，2008年10月21日</ref>

随后，直播继续进行，但Herobrine并没有再次出现。此后约一年的时间里，Copeland依旧坚称Herobrine是真实存在的。英文Minecraft Wiki曾关于此事向Copeland询问过几个问题，它们都记录在[这里](Herobrine/直播FAQ.md)。

自从这次直播后，Herobrine一下火遍了整个Minecraft社区，俨然成为一种流行文化，更是成为了Minecraft社区的标志。Herobrine的爆红也导致了一大批相关Mod、动画、插画和建筑物的涌现。

在2024年7月15日，YouTube用户brutallillfjomp上传了Copeland的原始直播存档，并在留言区说明他当时下载了该直播存档。<ref></ref>

# Herobrine是什么
# = 经典版 =
Herobrine据称是Notch的已故兄弟，他因为某些缘故进入了Minecraft的世界中。尽管这一传言被视为“经典”，但实际上这是与事实完全不符的，因为Notch本人根本没有亲兄弟。<ref name="Notch">https://www.reddit.com/r/Minecraft/comments/qqenq/minceraft_a_post_mortem/c3zmd7n</ref>

先抛下它的幽灵身份不谈，经典版本还提出了两点似是而非的理论。

Herobrine拥有很多某种计算机病毒的特征，比如说更改和操纵游戏世界，删除论坛上的帖子，或者在Minecraft论坛上发消息，甚至还可能拥有黑进Notch的电子邮箱或推特账户来回复以证明自身存在的能力。

然而，Herobrine只是用户想象出来的虚构体。由Herobrine账号发出的“信息”，包括Notch的电子邮件回复，都只是玩家们自己脑补的。这也是Notch非常排斥经典版故事的原因之一，因为它毫无实际依据并且很容易误导他人。

Herobrine的原型极有可能部分来源于[瘦长人](wzh:瘦长人.md)，[末影人](末影人.md)的设计灵感也来源于它。

# = 社区版 =
玩家间流传最广的设定是：Herobrine是一个幽灵。其他的设定还可能使其成为更为高级的存在：恶魔，不祥之兆，或是其他从经典版设定衍生出的解释。

然而，这些设定大部分都是将Minecraft本身当作现实世界来写，而不是以玩家在游戏内操纵的虚拟角色的视角来写的。经典版的Herobrine并没有出现在现实中，并且仍然受限于当今的数字技术范围内。

# 外观
# = 经典版 =
Herobrine是一个[人类](人类.md)实体，有着[Steve](Steve.md)的玩家[皮肤](皮肤.md)。在Copeland的直播中，它长有胡子，这一点与Steve在很长时间内曾经使用的[皮肤](皮肤.md)不同。更为明显和重要的不同点在于他的眼睛：不仅全白，而且还会在黑暗中发出荧光（与[末影人](末影人.md)、[蜘蛛](蜘蛛.md)和[洞穴蜘蛛](洞穴蜘蛛.md)等生物的眼睛类似）。

# = 社区版 =
Herobrine有时会手持工具出现，例如[镐子](镐子.md)。这个设定来源于社区中广为传播的Herobrine的矿工身份。通常情况下，它的双手中没有任何物品。

Herobrine经常被社区描写成一个在玩家来到这个世界前很久就死去的矿工。然而，他的外观似乎与这些身份设定都毫无关联。

不过，由于Minecraft的世界中本身就有许多[废弃矿井](废弃矿井.md)和[要塞](要塞.md)，并且挖矿也是重要的游戏组成部分，玩家会接受这个设定也就不奇怪了。

# 移动能力
# = 经典版 =
根据起原帖的内容，Herobrine应该拥有在游戏中奔跑的能力。Brocraft的直播视频中它则几乎只是直直地站立着，将双手放在身体两侧，注视着玩家。直播中它并没有任何肢体动作，但却能够改变自身位置。

尚不明确Herobrine是否能够[游泳](游泳.md)，使用[矿车](矿车.md)、[船](船.md)或是[下界传送门](下界传送门.md)。像大多数幽灵一样，他很有可能根本不需要上述任何能力来进行移动。

# = 社区版 =
和被激怒的[末影人](末影人.md)类似，玩家广泛相信经典版中Herobrine拥有瞬移的能力。然而，几乎所有的社区都拒绝了这个设定，并将其描述为正在奔跑。

Herobrine不会飞，也没有任何一个改编版本在这点上认同“经典版”。然而，他却好像有滑行的能力。也就是说，能在没有任何物理移动或向上移动的情况下改变自身位置。这通常在退回到雾中时最明显。

Herobrine通常被描述成拥有歪曲或抽搐的头，这很有可能是因为它大部分时候都被看作是Minecraft中的一个病毒或恐怖的实体，而不是幽灵。

# 与Minecraft的互动
# = 经典版 =
Herobrine能够在Minecraft中进行建造或破坏。原帖的图像中展现了玩家发现的2×2的长隧道、海洋中央的金字塔和没有[叶子](叶子.md)的树。

Herobrine的完整建筑能力尚不明确，但从已知的设定来看，它有分辨出不同形状和材料程度的能力。

Herobrine的目标貌似总是人类玩家。它在Brocraft的视频中从来不和其他的生物进行互动，比如[僵尸](僵尸.md)和[蜘蛛](蜘蛛.md)。自其出现以后加入的更多生物也使其经典版本的设定更加迷雾重重。

起源贴的截图没有展现任何有关它与其他生物互动的能力。尽管图中有一只鸡，但是Herobrine貌似对它没有任何兴趣，而仅仅是盯着玩家。

# = 社区版 =
Herobrine偶尔会和其他生物互动。它有时也可以控制动物，并复活或生成亡灵类生物。

Herobrine貌似拥有可以使用环境中没有的资源进行大幅改造的能力。它的能力一般包括放置圆石、建造地牢类建筑、使用红石火把、建造陷阱等。它的行为模式十分符合一个[创造模式](创造模式.md)的游戏玩家。

Herobrine似乎不能进入[下界](下界.md)或[末地](末地.md)。

# 改编
Herobrine的意图在各个版本中都有所不同，但它们大多数都可以被归类到以下两大类。一类纯粹是出自社区中用户的自行解读和创造，另一类则是基于经典传说的。

# = 经典版 =
在“潜行追踪者”的版本中，他会尾随并跟踪玩家，一旦被发现或靠近就会消失。这个设定直接取自经典版本的故事。

# = 社区版 =
在“复仇者”的版本中，他会试图将玩家引诱入他布下的陷阱里，大概是为了偷走他们的物品。他会等待玩家进入他建造的地牢中，之后将出入口封死，或者直接传送到玩家的身后，大概是将玩家杀死。

其他较为罕见的版本则说他会破坏玩家的作品并从箱子里偷东西走。这个版本的灵感可能来源于多人游戏中的[众多小白和恶意破坏者](Tutorial:防止恶意破坏.md)。

# 未来更新中是否会出现
在Herobrine的传说流行之前，[Notch](Notch.md)曾在Twitter上回复过有关Herobrine的问题。Notch在回答Herobrine是否是游戏中一个真正的实体时，他说：“他不是真的。 =) 不过不久就可能是真的了！”<ref></ref>这确认了Herobrine不存在，但暗示了“Notch计划在以后添加Herobrine”。

在[MINECON 2010](MINECON 2010.md)，Notch确认了Herobrine是一个恶作剧，但开玩笑地暗示可能不是。<ref></ref>第二天，Notch在Twitter上回复关于Herobrine是否是游戏中真实的实体的询问：“不是，但将来可能是。”<ref></ref>，这进一步证实了Herobrine不存在于游戏中，但也表明了稍后被添加可能性。

由于围绕Herobrine页面的事件越来越多，英文Wiki的一位管理员在[IRC](wzh:IRC.md)上向Notch询问Herobrine是否会被加入，而Notch对此的回复是：“暂时还没有任何将Herobrine**本身**加入游戏的计划，不过我的确很喜欢那些流言，哈哈。”

这段对话表明Notch并未真的想要加入Herobrine。但是他所用的措辞“本身”则让人不得不联想到类似的东西可能会被加入。因此，这个管理员又问了一次以求澄清事实，他说：“我们的社区已经疲于应对Herobrine有关的垃圾邮件了。”而Notch的回复是“我没有在游戏中加入Herobrine的计划。”<ref></ref>

# = 目前对于Herobrine的立场 =
自从Minecraft由[Notch](Notch.md)转交给了[Jeb](Jeb.md)后，出现在之后更新中的概率尚不明确。

在2012年8月22日，现任联合开发者[Dinnerbone](Dinnerbone.md)在Twitter上发布：“我们没有任何加入Herobrine的计划。我认为这点永远不会改变。”<ref></ref>

这证实了Herobrine将永远不会在Minecraft的正式版本中出现，以及任何声称在原版Minecraft的未来更新中“找到”Herobrine都是完全毫无根据的。

Herobrine亦在Hatfilms所制作的[MINECON官方预告片](http://www.youtube.com/watch?gl=BE&v=-y2NACUlwmE)的3分11秒处出现。但是参与录制的用户都是上传的自己的皮肤，所以这可能不是他们有意为之的。

Herobrine也曾在Minecon的Xbox专区被发现。他的形象出现在广告板上，就在Xbox摊位后面。在MINECON关闭期间，一位名叫Zaralith的用户通过回答“有多少寓言游戏？”的赠送问题赢得了Herobrine雕像。

有些玩家拿这些图片和视频作为Herobrine会在游戏中被加入的证据。但它们其实只是噱头，用于煽动Herobrine“支持者”的。

Herobrine也出现在了Minecraft的Facebook页面，图片为封面照片。此处需要声明此图片是由一位粉丝在一个比赛中制作的，题材为“夏日恐慌”，因此包含的内容不能被认为是完全蓄意的。

# = 更改日志 =
在[Beta 1.6.6](Java版Beta 1.6.6.md)版本的更新日志中首次声称移除了Herobrine。这只是一个玩笑，其实是暗指Notch移除了[人类](人类.md)生物的部分基本代码，使其无法生成。这样做还有一个不可告人的企图，那就是以此愚弄大家——这是因为当时Herobrine在社区内已经获得了很高的人气。从那时起直到[1.16.2](Java版1.16.2.md)，几乎在每一次主要更新中，的更新日志都会至少提及一次“Removed Herobrine”（移除了Herobrine）作为噱头（例外是[1.1](Java版1.1.md)）。1.16.2之后[1.20](Java版1.20.md)之前的版本的更新日志均未提及，在1.20及[1.21](Java版1.21.md)的更新日志中被再次提及。

# == 启动器更改日志 ==

# 你知道吗
* 在被问到在Wiki中植入音频播放器的相关问题时，[C418](C418.md)也顺便提到了[11号唱片](音乐唱片11.md)内容的问题。他称自己虽不能对其发表太多评论，但是它的确和Herobrine没有任何关系。
* 有一个名为“Herobrine”的注册用户。这是一个付费注册用户（即其不仅已经注册，而且已为正版游戏付费），拥有者未知。由于没有[披风](披风.md)，因此基本上可以认定没有人使用过Herobrine用户名参加任何的线下[MINECON](MINECON.md)活动。
* * 前Mojang员工[Andreas Jörgensen](Andreas Jörgensen.md)称这个Herobrine账户是属于她的一个朋友的。<ref></ref>
* 在2013年9月，Mojang的Marc为头颅模型制作了一系列皮肤。这些皮肤是确保几个官方头颅实体拥有固定的皮肤以使其不被其他皮肤改变。Herobrine是这些皮肤的其中之一，可以使用命令MHF_Herobrine] }}获得。该皮肤以前使用的是Herobrine皮肤没有胡须的版本，实际上是直接从名为Herobrine的账户那里得来的，但这与原始恐怖故事、Copeland的直播，以及Mojang Studios经常使用的官方艺术作品中Herobrine的“经典”形象都不符。在2017年12月，这个错误得以修正，将Herobrine的皮肤变为其“经典”外观，其胡须与[生存测试](生存测试.md)发布前[Steve](Steve.md)和[人类](人类.md)生物的胡须相同。
* “Remove Herobrine”（移除Herobrine）是Java版[3D Shareware v1.34](Java版3D Shareware v1.34.md)愚人节版本中的一个章节。
* 原帖中截图所用的世界种子为，位于坐标X=5.06、Y=71、Z=-298.54处。该截图是在[Java版Alpha v1.0.16_02](Java版Alpha v1.0.16_02.md)中拍摄的。<ref>https://minecraftathome.com/herobrine</ref>[15周年庆](15周年庆.md)[纪念地图](15年之旅.md)alpha区回忆Minecraft Alpha玩法地图中使用了与之相似的地形。
* 在Minecraft的早期版本中，可能出现一个串档bug，导致玩家的单人世界中的某些区块被替换为设备里其他世界中的某些区块。<ref>https://youtu.be/xRAAqyfFuHU?si=eCdnYIzdkfOJknyJ</ref>如果这些区块中恰好包含人工建筑或探索的痕迹等，可能会被误以为是Herobrine等超自然力量所为。
