# 书架

* *书架（Bookshelf）**是一种用于增加[附魔台](附魔台.md)的[附魔等级](附魔（物品修饰）#附魔等级.md)的[方块](方块.md)。

# 生成
# = 自然生成 =
[村庄](村庄.md)的图书馆和一些房子里会生成书架。

[要塞](要塞.md)会生成最多2个图书馆，书架在其中以柱形堆积；同时，更多的书架将会替代底层和露台的两面墙，单层的图书馆有161个书架，而双层的图书馆有233个书架。

书架也会自然生成在[林地府邸](林地府邸.md)里。

# 破坏
挖掘书架的合适工具是斧。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，书架被破坏后会掉落3个[书](书.md)。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，书架被破坏后会掉落自身。

# 用途
# = 附魔 =

如果一个[附魔台](附魔台.md)放置在靠近书架的地方，会有字符[粒子](粒子.md)从书架飞向附魔台，表示这个书架正在参与提升该附魔台的附魔等级。

# = 合成材料 =

# = 燃料 =
书架可以作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个书架可以烧炼1.5个物品。

# = 村民 =
图书管理员[村民](村民.md)会与书架互动。

# 你知道吗
* 书架顶部和底部默认使用与[橡木木板](橡木木板.md)相同的纹理。
* 制作15个书架来得到一个30级的附魔台需要花费90块[木板](木板.md)、45个[皮革](皮革.md)和135张[纸](纸.md)。
