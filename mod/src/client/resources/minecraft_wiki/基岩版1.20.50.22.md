# 基岩版1.20.50.22

*页面ID: 106520* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.50.22**（ChromeOS/Android）、**Preview 1.20.50.22**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.50](基岩版1.20.50.md)的第3个测试版，发布于2023年10月25日<ref name="feedbacksite"></ref><ref></ref>，更改了生物攻击距离的计算方式，在[实验性玩法](实验性玩法.md)中加入了多种铜制方块和凝灰岩系列方块，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* *[游戏规则](游戏规则.md)**
* 加入了游戏规则。
* * 用于控制[弹射物](弹射物.md)是否可以破坏[紫颂花](紫颂花.md)和[饰纹陶罐](饰纹陶罐.md)，以及[三叉戟](三叉戟.md)是否可以破坏[滴水石锥](滴水石锥.md)。
* * 默认值为。

# 更改
# = 方块 =
* *[紫颂花](紫颂花.md)**
* 现在可以被任何弹射物破坏。

* *[饰纹陶罐](饰纹陶罐.md)**
* 更改了除放置物品外的所有音效。

# = 生物 =
* *[蝙蝠](蝙蝠.md)**
* 更改了模型、动画和纹理。

* *[近战攻击](近战攻击.md)**
* 更改了生物近战攻击的攻击距离的计算方法。
* * 生物的攻击距离现在由其边界箱在水平方向上向外延伸得到，而非由水平宽度决定。
* ** 受影响的生物包括：[美西螈](美西螈.md)、[蜜蜂](蜜蜂.md)、[烈焰人](烈焰人.md)、[洞穴蜘蛛](洞穴蜘蛛.md)、[海豚](海豚.md)、[溺尸](溺尸.md)、[末影人](末影人.md)、[末影螨](末影螨.md)、[狐狸](狐狸.md)、[疣猪兽](疣猪兽.md)、[尸壳](尸壳.md)、[铁傀儡](铁傀儡.md)、[熊猫](熊猫.md)、[猪灵](猪灵.md)、[猪灵蛮兵](猪灵蛮兵.md)、[掠夺者](掠夺者.md)、[蠹虫](蠹虫.md)、[骷髅](骷髅.md)、[蜘蛛](蜘蛛.md)、[流浪者](流浪者.md)、[卫道士](卫道士.md)、[监守者](监守者.md)、[凋灵骷髅](凋灵骷髅.md)、[狼](狼.md)、[僵尸疣猪兽](僵尸疣猪兽.md)、[僵尸](僵尸.md)、[僵尸猪灵](僵尸猪灵.md)和[僵尸村民](僵尸村民.md)。
* ** 新的攻击距离为生物的边界箱在水平方向上向外延伸0.8格。
* ** 若边界箱延伸后与目标的边界箱重叠，则生物可以攻击到该目标。

# = 方块 =
* *[铜块](铜块.md)**
* 加入了雕纹铜块，有着X形花纹。
* * 有斑驳、、氧化和它们对应的涂蜡变种。
* * 暂时无法通过合成获得。<ref name="feedbacksite/>
* * 可以使用1个铜块在切石机中切出4个对应的雕纹铜块。

* *[铜格栅](铜格栅.md)**
* 铜质的网状装饰性方块。
* 有斑驳、、氧化和它们对应的涂蜡变种。
* 可以使用4个相同的铜块在合成方格中排成菱形来合成1个对应的铜格栅。
* 可以使用1个铜块在切石机中切出4个对应的铜格栅。

* *[门](门.md)和[活板门](活板门.md)**
* 加入了铜质变种。
* * 有斑驳、和氧化和它们对应的涂蜡变种。
* * 可通过按键开合。

* *[铜灯](铜灯.md)**
* 铜质照明方块。
* 可以使用3个相同的铜块、1个[烈焰棒](烈焰棒.md)和1个[红石粉](红石粉.md)合成4个铜灯。
* 有斑驳、和氧化和它们对应的涂蜡变种。
* 会随着铜的锈蚀而变得暗淡，用[斧](斧.md)除锈可以使之恢复亮度。

* 放置时默认关闭，可以通过输入红石信号进行开关。
* * 不需要红石信号来维持照明，只会在下一次接收到红石信号时改变开关状态。
* 开启时会对[红石比较器](红石比较器.md)输出强度为15的红石信号。

* *[凝灰岩](凝灰岩.md)**
* 加入了雕纹凝灰岩、磨制凝灰岩和凝灰岩砖。
* * 暂时无法通过合成获得。<ref name="feedbacksite/>

* *[墙](墙.md)、[楼梯](楼梯.md)和[台阶](台阶.md)**
* 加入了凝灰岩、磨制凝灰岩和凝灰岩砖变种。
* * 暂时无法通过合成获得。<ref name="feedbacksite/>

# 修复
* *方块**
* 黏性活塞拉动正在拉动玩家和另一方块且正在收回的黏性活塞时不再会导致游戏崩溃。（）
* 紫颂花现在可以被任何弹射物破坏，被弹射物击中不会消失。

* *饰纹陶罐**
* 现在破坏饰纹陶罐发出的声音更加具有“破碎感”。

* *游戏内容**
* 修复了玩家松开使用键以使用已离开物品栏的物品后无法使用盾牌进行格挡的问题。（）

* *生物**
* 若重新加载世界时被拴绳拴住的生物和拴绳持有者不处于同一区块中，拴绳不再会断裂。（）
* 主手上持有某物的生物在着火时攻击不再会使攻击目标着火。

* *触摸控制**
* 修复了玩家没有触摸控制也能进入触摸控制自定义界面的问题。（）

* *用户界面**
* 加载屏幕现在会根据玩家的游戏进度显示3种类别的提示。</onlyinclude>
