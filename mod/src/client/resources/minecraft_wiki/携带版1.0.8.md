# 携带版1.0.8

*页面ID: 29687* | *来源: Minecraft Wiki*

* *1.0.8**是[携带版](携带版.md)的一次次要更新，发布于2017年5月4日<ref name=minecraft.net>https://minecraft.net/en-us/article/magic-gathering-comes-minecraft</ref><ref></ref>，加入了万智牌皮肤包，并修复了一个漏洞。

# 新内容
# = 常规 =
* *[资源包](资源包.md)**
* 加入了万智牌皮肤包。

# 修复
* *修复了1个漏洞**
* 使用辐射混搭包进行游戏时游戏崩溃。
