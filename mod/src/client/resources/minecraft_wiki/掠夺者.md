* *掠夺者（Pillager）**是一种装备[弩](弩.md)的[灾厄村民](灾厄村民.md)。

# 生成
# = 灾厄巡逻队 =

掠夺者会自然生成于灾厄巡逻队。

灾厄巡逻队会于5.5个游戏日后在距离任一玩家24至48格的范围内最高的[固体方块](固体方块.md)上生成，并且每个巡逻队成员只在[方块光照](亮度#方块光照.md)等级不大于8的方块上生成。掠夺者生成于[灾厄巡逻队](灾厄巡逻队.md)，生成的数量取决于[区域难度](区域难度.md)，最高为5，且其中的1个作为[袭击队长](袭击队长.md)生成。

灾厄巡逻队会于5.5个游戏日后在距离任一玩家24至48格的范围内亮度不大于7（简单[难度](难度.md)）/亮度不限（普通或困难难度）的区域生成。单个灾厄巡逻队的成员是2至5名掠夺者，每个巡逻队有1名成员作为袭击队长生成。

# = 掠夺者前哨站 =
掠夺者会自然生成并[消失](生成#清除.md)于[掠夺者前哨站](掠夺者前哨站.md)。

掠夺者会自然生成于以掠夺者前哨站内[箱子](箱子.md)所在的楼层为中心的72×55（向上26、向下28）×72区域内。

|基岩版掠夺者硬编码生成点位置示例，金块代表生成点，蓝线代表区块边界}}
除伴随前哨站一同生成的掠夺者外，掠夺者会在1个、2个或4个特殊位置生成。生成点的数量取决于结构生成的方向（也可以通过区块判断），生成位置的数量根据结构的方向而变化：当顶层向上的楼梯朝南时，生成点有1个（25%概率）；当顶层向上的楼梯朝东/朝西时，生成点有2个（50%概率）；当顶层向上的楼梯朝北时，生成点有4个（25%概率）。它们实际的生成点为柱状，第一个生成点位于箱子斜向结构的中心两格处，其他三个生成点位于距离该生成点8格的哨站边缘。从底层入口处地板开始，垂直向上18格方块，掠夺者可以在这条生成柱内生成。掠夺者会在上方生成柱范围内最高可生成位置的西北角处生成。可生成位置需要至少2×2×2的空间，该空间内任何实心固体方块都会抑制生成，树叶、玻璃等透明方块则不会阻碍生成，但至少需要一个空气类方块。

# = 袭击 =

掠夺者可以作为[袭击](袭击.md)事件的一部分生成，且[袭击](袭击.md)生成的生物中大部分都是掠夺者。

# 行为
[为弩上弦的掠夺者（Java版模型）|thumb|right|150px](File:Pillager Charging Crossbow.gif.md)

掠夺者持有一把[弩](弩.md)并且用弩射出[箭](箭.md)来攻击敌对目标：[玩家](玩家.md)、[铁傀儡](铁傀儡.md)、成年[村民](村民.md)和[流浪商人](流浪商人.md)。它们每3秒向最远8格<ref></ref>远处射1次箭，并且会跟随目标至多或。掠夺者不会反击[灾厄村民](灾厄村民.md)、。

如果在一次[袭击](袭击.md)中所有[村民](村民.md)死亡或所有村民的[床](床.md)被摧毁，存活的掠夺者将会跳动并欢呼庆祝胜利，[基岩版](基岩版.md)中的掠夺者还会挥舞手臂。

掠夺者会主动远离[嘎枝](嘎枝.md)。

# = 生物族群 =

掠夺者是[灾厄村民](生物#灾厄村民.md)，不会被[唤魔者](唤魔者.md)的尖牙伤害，不会被[劫掠兽](劫掠兽.md)的咆哮伤害，不会被[“Johnny”卫道士](卫道士#“Johnny”卫道士.md)攻击。掠夺者可以加入正在发生的袭击，即使不是在袭击事件中被生成的。掠夺者与其他灾厄村民之间即使发生了误伤也不会相互攻击。

# = Java版 =
当掠夺者发现攻击目标时，会先奔跑追逐目标，目标进入射程范围内后掠夺者会为弩上膛并停止奔跑。如果掠夺者的弩已装填，那么该掠夺者的射程范围将和该掠夺者的可视距离一致。

如果掠夺者被其他非灾厄村民的生物所攻击，附近的掠夺者会对该生物产生敌意。

在所有难度下，不处于袭击且正在巡逻中受到伤害的掠夺者会召唤半径8格内的所有[灾厄村民](灾厄村民.md)、[女巫](女巫.md)和[劫掠兽](劫掠兽.md)攻击伤害它的生物。

不像多数生物所持有的武器，掠夺者的弩有使用耐久，当消耗完所有的耐久就会损坏。损坏一把无魔咒或只具有穿透/快速装填的弩需要326箭，而掠夺者每3秒射出一箭，故损坏最短需要16分钟3秒。当弩拥有[耐久](耐久.md)魔咒时，损坏这把弩所需射出的箭的预期数量将乘以<code>-{}-*魔咒等级*+1</code>，如耐久I预期需要326&times;2箭。多重射击可以使损坏所需的时间变为原本的（虽然需要的箭数是一样的，但会每次射出3支箭）。掠夺者没有[弩](弩.md)时不会攻击，而会四处走动。尽管如此，村民仍然会躲避它们，铁傀儡和雪傀儡也会攻击它们。<ref></ref>

敲[钟](钟.md)会给予半径48格内的掠夺者的[发光](发光.md)效果。

有概率生成副手拿弩的掠夺者，它们装填弩的时候仍使用了主手装填弩的动画。

掠夺者在袭击中未到达村民职业方块附近时不会主动攻击或追击与其敌对的生物，即使与掠夺者敌对的生物伤害了掠夺者。

# = 基岩版 =
基岩版中的掠夺者使用了1.14开发版本中的旧AI。<ref></ref>

掠夺者的移动只有奔跑，无论它们在空闲还是追逐都是以奔跑的速度移动。

当掠夺者发现攻击目标时，会先为弩上膛，然后冲到目标面前近距离射击。掠夺者为弩上膛时处于被动状态，此时它们可能不会看着目标或跑走。

和[骷髅](骷髅.md)一样，掠夺者完全沉在[水](水.md)中时会使用近战攻击。

[发射器](发射器.md)能为掠夺者装备盔甲提供防御，但其装备的盔甲并不可见，且死亡时不会掉落。

和其他生物一样，掠夺者无法使用副手的弩。

掠夺者无法消耗它们弩的耐久。<ref></ref>

掠夺者会主动捡起并佩戴掉落在附近3格距离内的[不祥旗帜](不祥旗帜.md)。

掠夺者会主动捡起附近的白色[旗帜](旗帜.md)，并丢弃手中的弩。掠夺者捡起旗帜后会保持先前弩所影响的动作，在发现目标时会以更快频率凭空射出箭矢。

# 你知道吗
[缩略图|掠夺者的最初设计图|255x255像素](File:Early concept design of the Pillager.jpg.md)
* 掠夺者和弩来源自[Minecraft Dungeons](Minecraft Dungeons.md)，尽管它们最先被实装进[Minecraft](Minecraft.md)中。<ref></ref>
* 掠夺者的设计参考了欧洲的海盗，其声音带有浓厚的海盗口音和少许英伦腔。
* 掠夺者被添加到村庄和掠夺中是为了给村民一个“真正的”对手，以平衡新的村庄机制。<ref name="pillagers"/>
* 掠夺者比其他的[灾厄村民](灾厄村民.md)和其他村民略高。
* 掠夺者的手臂不会像村民、女巫、唤魔者、卫道士、幻术师那样合并在胸前，没有弩时掠夺者会下垂其手臂。如果一个没有弩的掠夺者加入一个袭击，该掠夺者会呈现出[卫道士](卫道士.md)攻击时的动作。
* * 这一行为类似[猪灵](猪灵.md)，但是没有弩的掠夺者无法攻击。
* 掠夺者可以使用副手槽的药箭或烟花火箭。
* 命令<code>/summon pillager ~ ~ ~ {}</code>会召唤一个不会主动攻击任何实体的“被动的”掠夺者。
* 若使用发射器给掠夺者装备附有[快速装填](快速装填.md)V（通过使用第三方编辑器）或等级更高的弩，则会造成游戏崩溃。原因是附有快速装填V或等级更高的弩无法装填。
* * 但掠夺者不装填附有[快速装填](快速装填.md)VI或等级更高的弩，更不会进行攻击。
* 如果掠夺者使用的弩带有魔咒，则只有快速装填和穿透魔咒会生效。如果掠夺者没有装备弩，射箭速度反而会变得更快（能够凭空射箭）。<ref></ref>
* 如果使用命令生成空手的掠夺者，或者等待掠夺者手中的弩耐久耗尽使其空手，则该掠夺者会拾起任意种类的旗帜，而不限于不祥旗帜，并将其持在手中。<ref></ref>
