# 携带版0.13.0.b2

*页面ID: 18904* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.13.0 alpha build 2**是[v0.13.0 alpha](携带版0.13.0.md)的第2个测试版，发布于2015年11月4日<ref>http://pocketbeta.minecraft.net/2015/11/changelog-for-013-build-2.html?m=0</ref>，修复了一些漏洞。

# 更改
* 将[黑曜石](黑曜石.md)的破坏所需时长从3秒延长至6.5秒。
* 现在[矿车](矿车.md)可以在物品栏中堆叠了。
* 现在[村民](村民.md)能够打开木门的所有变种。

# 修复
* *修复了13个漏洞**
* 加载的区块过多时，地形会闪烁且不可见。
* 手持除橡木门以外的物品进入村庄会导致游戏崩溃。
* 第一人称下的手持物品的动画出现错误。
* 生物在穿过下界传送门时消失。
* 绊线有多余的合成配方。
* 单个红石线不会被下方的红石电源激活。
* 破坏门的下半部分不会掉落任何东西。
* 生物从矿车上脱离后会立即回到矿车里。
* 豹猫的头不可见。
* 红石块的翻译错误。
* 修复了可以使用铁砧复制物品的漏洞。
* 修复了大部分有关红石机制的漏洞。
* 选择语言界面的画面显示错误。</onlyinclude>
