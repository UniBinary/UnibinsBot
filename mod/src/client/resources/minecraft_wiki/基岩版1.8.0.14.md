# 基岩版1.8.0.14

*页面ID: 37146* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.8.0.14**是[基岩版1.8.0](基岩版1.8.0.md)的第5个测试版，发布于2018年11月7日<ref></ref>，修复了一些漏洞。

# 修复
* *修复了17个漏洞**
* 启动游戏时游戏崩溃。
* 多人游戏下，捡起旗帜导致游戏崩溃。（）
* 丢弃物品时游戏崩溃。
* 在部分设备里按下继续游戏时画面冻结。
* 在主菜单里最小化游戏然后重新进入时游戏崩溃。
* 修复了游戏过程中出现的崩溃现象。
* 重新加载世界时，合成网格里的物品会复制。（）
* 被玩家破坏的竹子没有掉落物。（）
* 刷怪笼不能正常运作。（）
* 种子选取器在网络环境良好的情况下仍然不加载。
* 对市场里部分图片进行了优化。
* 骷髅和流浪者的步行动画不正确。（）
* 卫道士手持的铁斧太大。
* 守卫者的侧面纹理不正确。
* 鲑鱼的鱼尾丢失。
* 豹猫追逐鸡时，尾巴位置不正确。
* 鸡的双翅摆动动画不正确。</onlyinclude>
