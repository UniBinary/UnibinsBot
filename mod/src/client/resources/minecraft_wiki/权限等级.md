# 权限等级

*页面ID: 90098* | *来源: Minecraft Wiki*

* *权限等级（Permission level）**主要用于控制[命令](命令.md)执行者可以执行什么命令。比如不能在[命令方块](命令方块.md)中执行，因为这个命令需要<code>3</code>的权限等级，而命令方块的权限等级仅为<code>2</code>。

# 描述
权限等级是递增的，较高的等级继承低等级的权限的同时，拥有更多的权限。

# = Java版 =
权限等级可为<code>0</code>（All），<code>1</code>（Moderator），<code>2</code>（Gamemaster），<code>3</code>（Admin）或<code>4</code>（Owner）。
; 0级和1级
* 无特殊权限。
; 2级
* 更多[命令](命令.md)可用。
* 玩家可以使用[命令方块](命令方块.md)。
* 玩家可以在按下[调试组合键](调试屏幕#调试组合键.md)时复制服务端NBT数据，在按下时复制客户端NBT数据。
* 玩家可以使用（[游戏模式切换器](游戏模式切换器.md)）和[调试组合键](调试屏幕#调试组合键.md)。
* 玩家可以在[选项](选项.md)中更改或锁定[难度](难度.md)。请注意，单人游戏玩家和局域网世界的发起者在任何情况下都可以更改或锁定难度，即使没有2级权限。
* 开启“管理员用品标签页”选项后，玩家的[创造模式物品栏](创造模式物品栏.md)有管理员用品和“管理员用品”选项卡。
* [目标选择器](目标选择器.md)可以在等命令和[文本组件](文本组件.md)中使用。
; 3级
* 更多命令可用，主要为与多人游戏管理相关的命令。
; 4级
* 所有命令都可用，包括与服务器管理相关的命令。

# = 基岩版 =
权限等级可为<code>0</code>（Any / Normal），<code>1</code>（Game Directors / Operator），<code>2</code>（Admin / Host），<code>3</code>（Host / Automation）或<code>4</code>（Owner / Admin）。<ref>括号中的两个名称，前者源于[官方文档](https://learn.microsoft.com/en-us/minecraft/creator/commands/commands)，后者源于[BDS](BDS.md)的调试信息。</ref>

随着等级的提升，有更多命令可用。

# 不同情景下的权限等级
# = Java版 =
* 对于[函数](Java版函数.md)：
* * 当[解析](Java版函数#加载和解析.md)时（包括宏行的解析），权限等级为<code>2</code>（可在[server.properties](server.properties.md)中更改）。
* * 调用函数时的权限等级详见[命令上下文](命令上下文.md)。
* 对于玩家：
* * 如果该玩家是专用服务器中的管理员，那么其权限等级由中的值决定（其默认值可在[server.properties](server.properties.md)中更改）。
* * 如果该存档创建时启用[允许命令](作弊.md)，且该玩家是单人游戏中的玩家或[局域网游戏](多人游戏.md)的发起者，那么其权限等级为<code>4</code>。
* * 在一个允许命令的[局域网游戏](多人游戏.md)中，所有玩家的权限等级都为<code>4</code>。
* * 否则，该玩家的权限等级为<code>0</code>。
* 其他命令执行者的权限等级详见[命令上下文](命令上下文.md)。
* [文本组件](文本组件.md)解析时的权限等级详见[命令上下文](命令上下文.md)。

# = 基岩版 =
* 对于[函数](基岩版函数.md)：
* * 当[解析](基岩版函数#加载和解析.md)时，权限等级为<code>1</code>。
* * 调用函数时的权限等级详见[命令上下文](命令上下文.md)。
* 对于玩家：
* * 如果该玩家在[专用服务器](BDS.md)中，且该玩家在“玩家权限”屏幕中的“操作员命令”开关已打开，那么其权限等级为<code>1</code>（可在中更改）。
* * 如果该玩家在单人游戏或[局域网游戏](多人游戏.md)中，且该玩家在“玩家权限”屏幕中的“操作员命令”开关已打开，那么其权限等级为<code>3</code>。
* * 否则，该玩家的权限等级为<code>0</code>。
* 其他命令执行者的权限等级详见[命令上下文](命令上下文.md)。

注意：命令的权限等级与暂停屏幕和“玩家权限”屏幕中的身份（访客、成员、或自定义）不同。然而，在单人游戏世界中，身份为“”的玩家的权限等级必定为<code>3</code>，因为该身份要求“”开关已打开；同样，身份为访客或成员的玩家的权限等级必定为<code>0</code>，因为这两个身份要求“”开关关闭。

# 玩家权限

玩家权限用于控制多人游戏中玩家能做的事情，如放置和挖掘方块、攻击生物和玩家等。这些选项可在[暂停菜单](暂停菜单.md)中的玩家权限屏幕中修改，不同的玩家可以设置不同的玩家权限，也有预设可用。

玩家权限分为4种。
* **访客**：只能查看世界，不能与任何方块或实体交互。下方所有选项都是关闭的。
* **成员**：可以挖掘和放置方块，可以和实体交互。
* ****：拥有所有权限，包括但不限于使用[命令](命令.md)、修改世界选项，使用传送等。下方所有选项都是开启的。
* ****：由下方选项控制：

无论自己的玩家权限是什么，主持世界的玩家都可以修改所有玩家的玩家权限。其他玩家只有成为才可以修改玩家的玩家权限。所有玩家都可以查看自己和其他玩家的玩家权限，无论自身的玩家权限是什么。

玩家权限与权限等级不同，后者允许和限制执行特定命令，不同的命令需要的等级不同。除此之外，启用会将该玩家的权限等级设为3（单人游戏和本地局域网游戏）或1（[基岩版专用服务器](基岩版专用服务器.md)）。
