# 垂根

*页面ID: 77862* | *来源: Minecraft Wiki*

* *垂根（Hanging Roots）**是一种装饰性方块。

# 生成
# = 自然生成 =
垂根会生成在[杜鹃树](杜鹃树.md)下方所对的[繁茂洞穴](繁茂洞穴.md)洞顶。

# = 骨粉 =
对[缠根泥土](缠根泥土.md)[骨粉](骨粉.md)会使其下方长出垂根。

# 获取
# = 缠根泥土 =
对着缠根泥土使用[锄](锄.md)可使其转变为普通[泥土](泥土.md)，并掉落1个垂根。

# 破坏
垂根被挖掘时会立刻被破坏。

没有被[剪刀](剪刀.md)挖掘破坏时，垂根被破坏后不会掉落。

被[剪刀](剪刀.md)挖掘破坏时，垂根被破坏后会掉落自身。

# 用途
垂根只能被放置在下表面完整的方块底部。

# = 堆肥 =
将垂根放进[堆肥桶](堆肥桶.md)有30%的概率使堆肥层数增加1。
