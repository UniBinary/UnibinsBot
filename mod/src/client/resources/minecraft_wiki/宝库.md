# 宝库

*页面ID: 112571* | *来源: Minecraft Wiki*

* *宝库（Vault）**是一种生成在[试炼密室](试炼密室.md)中的方块，被[试炼钥匙](试炼钥匙.md)解锁后会喷出战利品。

# = 自然生成 =
[thumb|200px|[[试炼密室](File:Vaultrender3.png.md)中未被激活的宝库]]
宝库自然生成于[试炼密室](试炼密室.md)的入口、决斗室、Encounter和柱廊结构中。

# 获取

宝库无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，宝库可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
没有工具可以加速对宝库的挖掘。

宝库被破坏后不会掉落。

# 用途

未激活的宝库的半径4格内存在可以解锁该宝库的玩家时，它会被激活并播放燃起音效；激活的宝库的半径4.5格内不存在可以解锁该宝库的玩家时，宝库又会熄灭。

宝库从未激活状态转为激活状态时，[亮度](亮度.md)会增加，其下端的灰色边角和正面的双眼纹理变为橙色，正面的嘴部纹理向下张开，并且有[微小的橙色粒子](粒子#vault_connection.md)从玩家身上运动到宝库的嘴部。此外，宝库的内部会出现火焰粒子和展示其战利品表的旋转[物品实体](物品实体.md)，每秒随机更换一次物品，此时展示的物品与实际喷出的战利品无关。

# = 光源 =
未激活的宝库会发出亮度等级为6的光。

激活的宝库会发出亮度等级为12的光。

# = 解锁战利品 =
对激活的宝库[试炼钥匙](试炼钥匙.md)可以将其解锁。

宝库会在方块实体数据中存储最后128-{}-位解锁了宝库的玩家，只有不在该记录中的玩家可以解锁宝库。在记录长度达到128时，解锁宝库会在添加新记录时删除最早的记录，使被删除了记录的玩家可以再次解锁这个宝库。<ref name="MC-274049"></ref><ref name="MCPE-226578"></ref>

解锁宝库会消耗一个试炼钥匙，接着宝库张开的嘴会合上，宝库的内部展示的物品实体立刻更新为即将喷出的战利品，随后顶部的闸门开启。闸门开启时，宝库的内部展示的物品实体为下一次即将喷出的战利品，后喷出战利品，并更新宝库内部展示的物品，以此循环，直到战利品投掷完毕，宝库内部不再展示物品，闸门关闭。

每次解锁时，宝库都会从[战利品表](战利品表.md)中随机抽取物品，具体如下：
* 首先，有80%的概率从稀有战利品表抽取1次，20%概率从普通战利品表抽取1次；
* 总是从普通战利品表抽取1-3次；
* 有25%的成功概率从独有战利品表抽取1次。

# 你知道吗
* 宝库可以被每个玩家打开无限次数<ref name="MC-274049"/><ref name="MCPE-226578"/>，这与Mojang声称的“每个宝库只能被每个玩家打开一次”相悖。
* * 由于[试炼钥匙](试炼钥匙.md)和[不祥试炼钥匙](不祥试炼钥匙.md)是[可再生资源](可再生资源.md)，所以通过宝库和[不祥宝库](不祥宝库.md)获取物品是一种可再生的获取方式。这也是[钻石](钻石.md)、[附魔金苹果](附魔金苹果.md)、[沉重核心](沉重核心.md)、[涡流旗帜图案](涡流旗帜图案.md)、[旋风旗帜图案](旋风旗帜图案.md)和[风爆](风爆.md)[附魔书](附魔书.md)唯一的[可再生获取方式](可再生资源#宝库战利品.md)。
* 据开发者透露，宝库的灵感来源于扭蛋机。<ref>https://www.youtube.com/watch?v=bBr8BBrk1v8</ref>
