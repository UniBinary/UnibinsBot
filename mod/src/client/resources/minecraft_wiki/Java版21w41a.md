# Java版21w41a

*页面ID: 90144* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w41a**是[Java版1.18](Java版1.18.md)的第5个快照，发布于2021年10月13日<ref></ref>，更改了部分纹理，并修复了一些漏洞。

# 更改
# = 方块 =
* *[洞穴藤蔓](洞穴藤蔓.md)**
* 略微更改了纹理，去除了一个灰色像素点。

* *[附魔台](附魔台.md)**
* 更改了其UI中[青金石](青金石.md)槽的纹理，以匹配纹理更新后的青金石纹理。

* *[红石比较器](红石比较器.md)**
* 更改了激活状态的基部纹理。

# = 物品 =
* *[营火](营火.md)**
* 更改了两种营火的物品形式纹理，将火焰部分整体调低了1格像素。

* *[门](门.md)**
* 更改了金合欢木门、白桦木门、深色橡木门、铁门、丛林木门、橡木门和云杉木门的物品形式纹理。

* *[物品展示框](物品展示框.md)**
* 更改了两种物品展示框的物品形式纹理，以匹配其实体形式的边框木材纹理。

* *[告示牌](告示牌.md)**
* 更改了各种告示牌的物品形式纹理，以匹配其方块形式的柄部纹理。

# = 生物 =
* *[凋灵](凋灵.md)**
* 更改了凋灵之首的纹理，以匹配纹理更新后的凋灵头部纹理。

* *[僵尸村民](僵尸村民.md)**
* 更改了盔甲匠和武器匠僵尸村民的纹理，去除了从对应普通村民纹理上提取的多余像素点。

# = 世界生成 =
* *[紫晶洞](紫晶洞.md)**
* 现在仅生成于Y=30高度以下。
* 调整了生成频率，使其接近[1.17](Java版1.17.md)的水平。

* *[废弃矿井](废弃矿井.md)**
* 提高了[恶地](恶地.md)废弃矿井的生成高度。

* *常规**
* 世界生成现在使用新的随机数生成器。

# = 常规 =
* *区块渲染管线**
* 更改了优先级顺序。

* *[菜单屏幕](菜单屏幕.md)**
* 背景更改为[1.18](Java版1.18.md)新地形生成机制下的主世界地表。

* *[服务器](服务器.md)**
* 服务端的类文件现在都会被签名。

* *[疾跑](疾跑.md)**
* 上调了玩家不中止疾跑所容许的侧面与方块相碰的最大角度。
