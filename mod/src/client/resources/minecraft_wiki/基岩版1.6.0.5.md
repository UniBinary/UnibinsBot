# 基岩版1.6.0.5

*页面ID: 35224* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.6.0.5**是[1.6.0](基岩版1.6.0.md)的第2个测试版，发布于2018年6月27日<ref></ref>，加入了[幻翼膜](幻翼膜.md)和缓降效果，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[幻翼膜](幻翼膜.md)**
* 由幻翼掉落。
* 可用于酿造[缓降](缓降.md)药水。
* 可用于修复[鞘翅](鞘翅.md)。

* *[缓降药水](缓降药水.md)**
* 可使用幻翼膜酿造。
* 可给予玩家缓降状态效果。
* 可进一步酿造成[喷溅型缓降药水](喷溅型缓降药水.md)和[滞留型缓降药水](滞留型缓降药水.md)。

* *[缓降之箭](缓降之箭.md)**
* 可给予实体缓降状态效果。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
* [缓降](缓降.md)
* * 使生物的下落速度大幅降低，落地时不受伤害。

# 更改
# = 生物 =
* *[幻翼](幻翼.md)**
* 现在会掉落[幻翼膜](幻翼膜.md)。
* 生命值由增加到。
* 现在属于[亡灵生物](亡灵生物.md)，会在阳光下燃烧。
* 现在能够溺水。

# = 物品 =
* *[鞘翅](鞘翅.md)**
* 现在只能通过幻翼膜修补而不是皮革。

# = 常规 =
* 当首次加入存档时，个人游戏模式现在会被设置为默认的游戏模式选项。

# 修复
* *修复了47个漏洞**
* 修复了游戏中发生的几次崩溃
* 修复了当将重命名的物品放入铁砧的输出槽时发生的崩溃
* 修复的实体在之前的Android beta测试中部件消失
* 当潜行在梯子上打开暂停菜单或物品栏屏幕时，会继续潜行
*  - 在使用鞘翅时烟花火箭再次适当地加速
* 屏障现在可以与水共存。
*  - 视场再次调整时，“FOV可以通过游戏调整”选项被禁用
*  - 红石粉现在呈现在玻璃块的侧面
* 在挪威神话主题包中，末影龙脖子上的纹理不会消失
* 修复在船上时，破坏方块裂纹动画不同步
* 将幻翼的生命值从10增加到20
* 在幻翼的纹理上的两个像素不会消失
* 幻翼现在被认为是亡灵生物
* 幻翼现在可以在水中淹死
* 幻翼的眼睛在隐形效果下保持可见
* 幻翼现在在创造模式下生成后飞起来
* 修改幻翼飞行动画
* 在水下爆炸的TNT不再对玩家和其他实体造成伤害
* 溺尸现在更容易攻击那些在它们上面游泳的玩家。
* 玩家种植的海带会随着时间而增长。
* 幼年马、驴和骡不再能被推着穿过实心方块了
* 苦力怕在被杀死时不再显示白色或快速闪光。
* 使用“填充门”现在用门代替空气块来填充选定区域
* 修复了在加入跨平台世界时Windows 10设备上不出现取消按钮
*  - 海带现在像海草一样放置，可以放置在大部分水下
* 修正了当玩家生成时出生点发生的碰撞
* 陆地植物不能再被放置在水下
* 在Android设备上，水瓶不再有红色液体。它不是任何令人害怕的东西
* 守卫者不再攻击鱼类
* 当潜入水中时能见度会随着时间的推移而增加
*  - 使用的箱子现在可以装备骡和羊驼
*  - 游过某些水下的方块不再去除水下雾
*  - 激活末地传送门将取代传送内部的所有方块
*  - 在触屏设备上打开书与笔不再导致摧毁方块
* 远古守卫者被杀死后会掉落湿海绵。
* 在废弃矿井中产生的浮空的铁轨不再生成
* 修正了某些铁轨的错误碰撞箱
* 在转换世界版本时怪物不再消失
* 海豚不再能通过实心方块攻击玩家
*  - 抗性提升效果现在将抵抗凋零效果。
*  - 快速移动的项目从热键栏到背包现在按预期工作
* 复制容器时不再删除它们的自定义名称。
* 在背包中点击回车键不再将光标移入/退出文本字段或选取/删除物品
* 药水箭的粒子效果不再在流动的水中漂流
* 当怪物被生成时，怪物的音效效果不会提高
* 纹理包在Android设备的包验证屏幕上占位符图标不会消失
* 玩家传送现在效果更保持一致
