# Java版1.2.1

*页面ID: 29967* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.2.1**是的一次主要更新，发布于2012年3月1日<ref></ref>，引入了新的[Anvil文件格式](Anvil文件格式.md)，使建筑高度限制上升至256格，加入了[僵尸围城](僵尸围城.md)、丛林[生物群系](生物群系.md)、[沙漠水井](沙漠水井.md)、[红石灯](红石灯.md)、[火焰弹](火焰弹.md)、[铁傀儡](铁傀儡.md)和[豹猫](豹猫.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[雕纹石砖](雕纹石砖.md)**
* 仅能在[创造模式](创造模式.md)中获得。

* *[红石灯](红石灯.md)**
* 外形类似[荧石](荧石.md)。
* 只有被红石信号激活时才可发光。
* 可以发出15级的亮度。

* *[丛林原木](丛林原木.md)**
* 是新加入的丛林原木的组成方块。
* 其纹理是带着一些苔藓的棕色橡木原木。

* *丛林[树苗](树苗.md)**
* 可以生长出[丛林树](丛林树.md)，可以通过破坏丛林树叶获得树苗。

* *[丛林树叶](丛林树叶.md)**
* 作为丛林树的一部分生成。

# = 物品 =
* *[附魔之瓶](附魔之瓶.md)**
* 使用时会生成[经验球](经验球.md)。
* 仅能在[创造模式](创造模式.md)中获得。

* *[火焰弹](火焰弹.md)**
* 使用时会产生火。
* 可以被[发射器](发射器.md)发射。
* 可以当作[打火石](打火石.md)的替代品。

# = 生物 =
* *[铁傀儡](铁傀儡.md)**
* 偶尔在[村庄](村庄.md)中生成。
* 保护[村民](村民.md)，攻击[僵尸](僵尸.md)以及其他敌对生物。
* 可以通过以一定顺序放置4个[铁块](铁块.md)和1个[南瓜](南瓜.md)生成。

* *[豹猫](豹猫.md)**
* 玩家可以通过喂它们[鱼](生鳕鱼.md)吃，以便把它们驯服成[猫](猫.md)。
* * 可以吓跑[苦力怕](苦力怕.md)。

# = 世界生成 =
* *[丛林](丛林.md)**
* 一个十分大，但很少见的生物群系。这里长着很高大的丛林树，最高有31格高，树干有2×2格粗。这里的[橡树](橡树.md)也很常见，所有树的叶子几乎能把地面覆盖。

* *[沙漠水井](沙漠水井.md)**
* 在[沙漠](沙漠.md)中可以稀有地遇到。

* *[废弃矿井](废弃矿井.md)**
* 生成在空中的部分现在会有[木板](木板.md)桥。

# = 游戏内容 =
* *[僵尸围城](僵尸围城.md)**
* 晚上偶尔会发生在[村庄](村庄.md)里。

# = 常规 =
* *警告信息**
* 进入早于1.2版本中创建的世界将被提示“*必须进行转换！*”

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 更改了纹理。

* *[草丛](草丛.md)**
* 现在在草上放置方块，草会消失，方块会放置在原来草生长的位置上。

* *[梯子](梯子.md)**
* 重新加入了碰撞箱。
* 现在合成梯子会得到3个而不是2个。

* *[熔岩](熔岩.md)**
* 熔岩现在会发出微弱的隆隆声，从熔岩中跳出的大粒子会发出一种像泡泡破裂的声音。

* *[橡树树苗](橡树树苗.md)**
* 更改了纹理。

* *[台阶](台阶.md)和[楼梯](楼梯.md)**
* 现在把它们放置在方块下方可以使它们颠倒放置。
* 现在合成台阶，可以得到6个而不是3个。

* *[藤蔓](藤蔓.md)**
* 现在在有[方块](方块.md)支撑的情况下可以像[梯子](梯子.md)一样爬上去。

# = 生物 =
* *[洞穴蜘蛛](洞穴蜘蛛.md)**
* 现在在流向[玩家](玩家.md)的水流中游泳会游得特别快，但如果水流流向洞穴蜘蛛，它们看起来几乎没有在移动。

* *[苦力怕](苦力怕.md)**
* 现在会偷偷接近玩家。

* *[村民](村民.md)**
* 现在在村庄中有足够多的房间的情况下会[繁殖](繁殖.md)。

* *[狼](狼.md)**
* 被驯服的狼可以用骨头繁殖。

* *[僵尸](僵尸.md)**
* 现在在困难[难度](难度.md)下可以破坏木[门](门.md)。
* 现在稀有地掉落[铁锭](铁锭.md)、铁[头盔](头盔.md)、铁[锹](锹.md)或铁[剑](剑.md)。
* 现在在白天被烧着的情况下会跑到[水](水.md)中，或者跑到阴处躲避。
* 追赶和攻击[村民](村民.md)、门（破坏木门需要在困难难度下）。
* 有时候，僵尸更喜欢对村民进行攻击而非攻击玩家，并且总是选择最近的目标，即使有一个门阻挡住了去路。

* *[骷髅](骷髅.md)**
* 现在稀有地掉落[弓](弓.md)（有可能附魔）。
* 现在在白天被烧着的情况下会跑到水中，或者跑到阴处躲避。

* *[雪傀儡](雪傀儡.md)**
* 现在会在[下界](下界.md)中融化死亡。

* *[僵尸猪人](僵尸猪人.md)**
* 现在稀有地掉落金头盔、金剑（有可能附魔）、[金锭](金锭.md)。
* 现在在水中游得更快。

# = 游戏内容 =
* *[调试屏幕](调试屏幕.md)**
* 加入了新的调试信息：
* * lc：最大部分高度
* * b：显示你所在的[生物群系](生物群系.md)
* * bl：玩家所在位置的方块[亮度](亮度.md)
* * sl：玩家所在位置的天空亮度
* * rl：玩家所在位置的原始亮度

* *[多人游戏](多人游戏.md)**
* 由于生物群系数据现在以[区块](区块.md)形式保存，多人生存模式服务器不再向客户端发送其世界种子，而是在客户端上显示“0”。

* *[第三人称视角](第三人称视角.md)**
* 现在[玩家](玩家.md)的头部移动速度略有减慢。
* * 现在玩家可以在第三人称视角下看到玩家头部的两边了。

# = 常规 =
* *[Anvil文件格式](Anvil文件格式.md)**
* 新的地图文件格式
* * 导致世界建筑高度限制从128格提升至256格
* 以MCRegion格式存储的世界会显示在世界选择界面中，但要继续游玩该世界必须先转换。
* 不再显示以Alpha文件格式保存的世界。

# 修复
* *修复了3个漏洞**
* 门被升级了，是为了双门可以与红石信号更好的交互。
* 环境音效现在能在多人游戏中正常工作了。
* 多人游戏中，刷怪笼会显示正确的生物了（而不是像以前只显示猪）。</onlyinclude>
