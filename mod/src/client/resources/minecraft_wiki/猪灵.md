* *猪灵（Piglin）**是一种自然生成于[下界](下界.md)的敌对生物，玩家能使用[金锭](金锭.md)与其交换物品。

# 生成
猪灵会在[绯红森林](绯红森林.md)与[下界荒地](下界荒地.md)（较为少见）生物群系和[堡垒遗迹](堡垒遗迹.md)结构中亮度等级不高于11的地方生成。它们不能生成在[下界疣块](下界疣块.md)、[菌光体](菌光体.md)或[岩浆块](岩浆块.md)上。

每只猪灵都有或的概率生成为幼年个体。幼年猪灵永远不会成长为成年个体。<ref></ref>

成年猪灵在自然生成时会持有[金剑](金剑.md)、[金矛](金矛.md)或[弩](弩.md)，有时会装备金质盔甲。幼年猪灵在生成时不会携带任何装备。

即使在和平[难度](难度.md)中，猪灵也不会消失。

# 行为
# = 敌对性 =
成年猪灵默认与玩家敌对，但若玩家装备了任何1件[金质盔甲](盔甲材料#影响物品.md)，它们将不会主动攻击该玩家。幼年猪灵始终不会攻击任何生物，且被攻击时会逃跑。在和平[难度](难度.md)中，成年猪灵不会与玩家敌对。

成年猪灵在下列情形下对玩家敌对，其中敌对状态又可分为小、中、大范围，或按照猪灵的行为分为轻度、中度和重度（区别详见[下文](#敌对状态的范围.md)）。

* 玩家未装备金质盔甲。
* * 引起小范围的轻度敌对。
* 看到或听到玩家打开或破坏[箱子](箱子.md)、[陷阱箱](陷阱箱.md)、[铜箱子](铜箱子.md)、[木桶](木桶.md)、[潜影盒](潜影盒.md)、[末影箱](末影箱.md)、[运输矿车](运输矿车.md)或[运输船](运输船.md)，无论其中装有何种物品，也无论玩家是否装备金质盔甲。
* * 打开会引起小范围的中度敌对；破坏则会引起中范围的中度敌对。
* * 使用[活塞](活塞.md)或[黏性活塞](黏性活塞.md)推拉木桶、箱子、陷阱箱等方块也会激怒猪灵。
* 看到或听到玩家破坏[金块](金块.md)、[粗金块](粗金块.md)、[金矿石](金矿石.md)、[深层金矿石](深层金矿石.md)、[下界金矿石](下界金矿石.md)或[镶金黑石](镶金黑石.md)，无论玩家是否装备金质盔甲。
* * 引起中范围的中度敌对。
* * 使用[活塞](活塞.md)或[黏性活塞](黏性活塞.md)推拉上述金质方块也会激怒猪灵。
* 玩家攻击了附近的猪灵或[猪灵蛮兵](猪灵蛮兵.md)，无论是否用一击杀死。
* * 引起大范围的重度敌对（对于受伤的猪灵）或中度敌对（对于其他未受伤的猪灵）。

具有[隐身](隐身.md)效果的玩家只有被猪灵发现才会因为上述情形激怒猪灵。具有隐身效果的玩家只有攻击猪灵才会激怒猪灵。

被激怒后，猪灵会保持敌对状态30秒。

# == 敌对状态的范围 ==
* 小范围：玩家15格距离内所有能够看到玩家的成年猪灵与玩家敌对。
* 中范围：玩家16格距离内的所有成年猪灵与玩家敌对。
* 大范围：被玩家攻击的猪灵或猪灵蛮兵16格距离内的所有成年猪灵与玩家敌对。

# == 敌对状态的程度 ==
* 轻度敌对：猪灵在玩家穿上金质盔甲或不再能看到玩家时会解除其敌对状态，且能在玩家丢出金质物品后暂时解除敌对状态（详见[拾取物品](#拾取物品.md)章节）。
* 中度敌对：猪灵仅能在玩家丢出金质物品后暂时解除敌对状态。
* * 轻度敌对**不会**转化为中度敌对。这意味着，若一只猪灵因玩家未装备金质盔甲而追逐玩家，随后又发现玩家打开、破坏容器或破坏金质方块，则此时玩家可通过穿上金质盔甲或逃出该猪灵的视线解除该猪灵的敌对状态。
* 重度敌对：猪灵不会被金质物品解除敌对状态，也不能进行[以物易物](#以物易物.md)。

# = 攻击 =
发现目标时，持有弩的猪灵会以每2秒一次的频率朝8格<ref></ref>内的目标射[箭](箭.md)，并且会随攻击目标的逼近而后退（如果其后方是悬崖或路被堵住，则只会停在原地）。持弩猪灵只会在与目标保持在4格距离外时才会射击，即使它无路可退也是如此。与其他以[弓](弓.md)作为武器的生物不同，猪灵在射箭时不会左右移动。持有金剑的猪灵则会伸出持剑的手（类似[卫道士](卫道士.md)），冲到攻击目标旁边，直接进行砍击。持有金矛的猪灵会使用矛的冲锋攻击向目标冲来，当相对速度不足以造成伤害或冲锋状态结束时则会尝试拉开一段距离，然后再向目标冲锋。它们永远不会因为误伤而互相攻击。

成年猪灵发动攻击时会呼-{}-叫附近16格内的所有成年猪灵和[猪灵蛮兵](猪灵蛮兵.md)一起发动攻击。因此被猪灵攻击时非常容易引起连锁反应。

成年猪灵会立刻主动攻击16格内的[凋灵骷髅](凋灵骷髅.md)和[凋灵](凋灵.md)。

成年猪灵不会立刻攻击附近的成年[疣猪兽](疣猪兽.md)，而是有-的随机冷却时间。当一只猪灵及其附近所有猪灵的冷却时间结束时，这群成年猪灵会一同对附近的疣猪兽敌对。被疣猪兽群反击时，如果猪灵的数量不占优势，它们会放弃攻击，并与疣猪兽保持至少6个方块的距离。此外，猪灵不会攻击幼年疣猪兽。

击杀一只疣猪兽后，猪灵有}}或}}的概率跳“胜利之舞”（见[画廊](#画廊.md)）。

猪灵不会主动攻击[铁傀儡](铁傀儡.md)和[雪傀儡](雪傀儡.md)，但它们会主动攻击猪灵；被攻击后，成年猪灵会群体反击。

# = 拾取物品 =
当设置为<code>true</code>时，猪灵能够捡起和装备[物品](物品.md)，且偏好金质物品。猪灵总是能够捡起绝大部分金质物品，猪灵捡起金质物品后，会将该物品拿在手中端详片刻（[金粒](金粒.md)除外），然后将其持在手中、装备到身上或放入隐藏的物品栏。非金质物品被捡起或装备的过程是瞬间完成的。

猪灵捡起的物品会在其死后或者转化成[僵尸猪灵](僵尸猪灵.md)后掉落（猪排和供以物易物的金锭除外）。

捡起了物品的猪灵不会自然[消失](生成#清除.md)（由于猪灵不会把猪排和供以物易物的金锭放入物品栏，所以捡起这些物品的猪灵仍会自然消失）。

幼年猪灵会尝试捡起地上的任何物品；而幼年猪灵只会尝试捡起地上的弩、剑、矛、工具、盔甲、生物头颅（猪灵的头除外）、雕刻南瓜、鞘翅、盾牌、猪排或金质物品。

一只成年猪灵手上没有任何物品时，它可能捡起地上的任何物品并握在主手上。手上没有任何物品的猪灵只可能捡起地上的[弩](弩.md)、[剑](剑.md)、[矛](矛.md)、工具、[盾牌](盾牌.md)或金质物品。

猪灵被玩家攻击后内不会再尝试捡起物品。

可使用}}或}}命令来将自定义物品放入猪灵的物品栏中。

==== 金质物品和猪排 ====
猪灵能够主动捡起绝大部分金质物品。

处于轻度或中度敌对状态的成年猪灵在攻击时会因捡起和端详（不会端详[金粒](金粒.md)、[生猪排](生猪排.md)和[熟猪排](熟猪排.md)）这些物品而短暂地解除敌对状态。如果玩家给予了它们[金锭](金锭.md)，它们还能进行[以物易物](#以物易物.md)。在猪灵完成对金锭的端详后，若玩家已经装备上了金质盔甲，则猪灵停止与玩家敌对。

猪灵不会主动搜寻生猪排和熟猪排，但仍可[拾取](物品（实体）#拾取.md)这些物品，每次最多拾取一个，且捡起后10秒内不会再捡起这两种物品。捡起的猪排不会被猪灵放入物品栏，这意味猪灵死亡后不会掉落其捡起的猪排。

猪灵不会主动搜寻[金粒](金粒.md)，但仍可同时拾取附近地面上的所有金粒直至物品栏变满。

# == 装备和武器 ==
猪灵不穿盔甲时总是能够捡起地上的[盔甲](盔甲.md)、[雕刻南瓜](雕刻南瓜.md)、[盾牌](盾牌.md)、[生物头颅](生物头颅.md)（）或[鞘翅](鞘翅.md)并装备。猪灵也能捡起武器。使用时，盔甲和武器的攻击力、防御力以及附魔效果会正常生效。

已装备非金质盔甲的猪灵会捡起并装备比自己的盔甲品质更好的盔甲。但相比[品质](品质.md)最好的盔甲，猪灵仍然更偏好金质盔甲（例如，穿有钻石胸甲的猪灵不会捡起或装备铁胸甲，但戴有下界合金头盔的猪灵会捡起、端详、换上金头盔并将下界合金头盔丢出，并且不会再更换其他品质的头盔）。若猪灵原先装备的盔甲附有[绑定诅咒](绑定诅咒.md)，猪灵不会再捡起其他非金质盔甲，即使捡起的是金质盔甲也只会在端详后收入物品栏。

猪灵捡起[盾牌](盾牌.md)后会在副手上装备。但如果之后该猪灵尝试捡起并端详物品，它会将副手上的盾牌丢出。

猪灵不会使用[弓](弓.md)。

幼年猪灵在不持有武器时会主动捡起并手持武器，但它们不会使用武器。

猪灵持有金矛和弩以外的武器时会捡起弩并替换原有的武器。若弩的附魔等级更高，持有金矛的猪灵也会捡起弩。

猪灵捡起更高等级的附魔金剑或金盔甲后会替换其原有的金剑或同种金盔甲；猪灵只会将其收入物品栏<ref></ref>。

持弩猪灵射箭会使弩的耐久度逐渐磨损，弩损坏后猪灵便会使用近战攻击直至它再捡起一把弩。<ref></ref>

# == 物品栏 ==
猪灵拥有8个隐藏的物品栏。当一只猪灵的物品栏已满时，将无法捡起除以下列表内包含的以外的物品：
* 供以物易物的[金锭](金锭.md)（这意味着成年猪灵即使物品栏已满也仍能以物易物）
* 物品栏内未满一组的可堆叠物品
* 未穿上的</ref>}}盔甲
* 副手未装备的盾牌
*

玩家可以通过强制将其他物品放入猪灵的物品栏。

# = 以物易物 =

玩家通过对成年猪灵丢出[金锭](金锭.md)或金锭可与其交换特定的物品。成年猪灵会端详手持的金锭或秒，期间或，接着收起金锭向玩家丢出交换物，被收起的金锭不会进入其物品栏，而是直接消失。在此期间猪灵若受到攻击，它就会收起手中的金锭并且终止以物易物，如果是玩家攻击的还要后才能继续以物易物。[投掷器](投掷器.md)投掷的金锭也可触发以物易物。[发射器](发射器.md)发射的、投掷器被破坏时掉落的和[僵尸猪灵](僵尸猪灵.md)掉落的金锭可触发以物易物。

幼年猪灵也会端详金锭，但不会与玩家进行以物易物，只会将金锭放入其物品栏。

# = 骑乘疣猪兽 =
幼年猪灵会和幼年[疣猪兽](疣猪兽.md)玩耍，四处奔跑并骑乘。并且幼年猪灵在遇到一只骑着幼年疣猪兽的幼年猪灵时，会有一定的概率再次骑上幼年猪灵的头上，最多3个叠在一起。。它们也会在受到攻击后下来。

只有10%的幼年猪灵会骑乘幼年疣猪兽。

# = 僵尸化 =
[thumb|right|一只猪灵转化为僵尸猪灵](File:Piglin being zombified.gif.md)

猪灵在下界以外的维度中停留超过后会转化为[僵尸猪灵](僵尸猪灵.md)（NBT为<code>true</code>的除外），它们会受到10秒的[反胃](反胃.md)效果，但反胃效果并不会影响其行为。转化后猪灵会保留其装备的盔甲和主手、副手持有的物品（但原先手持弩的猪灵转化后无法再使用弩射击），同时它会失去原有的物品栏，并直接掉落原先物品栏内的物品。转化后的僵尸猪灵/具有拾取盔甲和武器的能力。

猪灵对生物的敌对状态会在其僵尸化后被消除。

和平难度下的猪灵在转化成僵尸猪灵的瞬间会被清除，因为僵尸猪灵被视作敌对生物。

# = 其他 =
猪灵在任何情况下都会主动远离附近的[僵尸猪灵](僵尸猪灵.md)和[僵尸疣猪兽](僵尸疣猪兽.md)，在空闲和欢呼状态下则会主动远离水平半径水平曼哈顿距离8格、垂直半径4格范围内的[灵魂火](灵魂火.md)、[灵魂火把](灵魂火把.md)、[灵魂灯笼](灵魂灯笼.md)和[灵魂营火](灵魂营火.md)。幼年猪灵还会主动远离附近的[凋灵骷髅](凋灵骷髅.md)和[凋灵](凋灵.md)。

猪灵能够使用[木门](木门.md)和[铜门](铜门.md)。

与下界大多数的生物不同，猪灵不免疫火焰伤害。

猪灵不会游泳，而是会在[水](水.md)中下沉。<ref></ref>

类似于[水生生物](水生生物.md)，猪灵不会受到[河豚](河豚.md)的伤害。

# 你知道吗
* 在[箱子](箱子.md)下放置[漏斗](漏斗.md)来获取箱子中的物品不会激怒附近的猪灵。
* 与猪灵进行以物易物时，猪灵扔出的[铁靴子](铁靴子.md)有可能会被它重新捡起并穿上。
* 生成时持[弩](弩.md)的猪灵是一个单独的猪灵变种，它们就算没有弩也能射出箭；而生成时持[金剑](金剑.md)或[金矛](金矛.md)的猪灵就算得到弩也无法射箭。
* 猪灵的音效是通过混合瑞典家猪“Linderödssvin”的声音而制成的。
* 如果用指令移除猪灵的AI，其依然会拾取并端详金质物品，不过其会一直端详手中的金质物品而不收起，除非其遭到了来自生物的攻击。
* * 在这种情况下猪灵依然可以拾取并穿戴盔甲，也可以替换品质更高的盔甲。
* 与猪灵以物易物获得的[水瓶](水瓶.md)、铁质物品，以及堡垒遗迹箱子中的铁质物品、钻石质物品等迹象，都暗示了猪灵曾可能到访过[主世界](主世界.md)。
* * [废弃传送门](废弃传送门.md)的[金块](金块.md)和箱子中的金质物品则说明猪灵与废弃传送门有关，它们可能是通过废弃传送门进入主世界的。
* ** 衍生游戏[Minecraft Legends](Minecraft Legends.md)的剧情涉及了猪灵经传送门侵袭主世界。
* 猪灵头部上方两个白色的像素点是它的眼睛，而下方凸起的红色像素点是它的鼻子。
