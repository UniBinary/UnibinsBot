# Java版标签

*页面ID: 159186* | *来源: Minecraft Wiki*

* *标签（Tag）**允许玩家使用JSON文件将游戏资源分组。

# 定义
# = 目录结构 =

# = 命名空间ID =
标签的ID也遵守[命名空间ID](命名空间ID.md)的格式。为了与非标签元素作区分，在游戏中使用标签时，通常会在其ID前加上“<code>#</code>”前缀。例如，对于方块注册表的元素而言，<code>minecraft:air</code>代表了一个方块，而<code>#minecraft:air</code>代表了一个方块标签。

# = 文件格式 =
标签定义文件使用[JSON](JSON.md)格式，并具有下列结构：

<div class="treeview">
*  根标签。
* * ：（默认为<code>false</code>）此标签是否完全覆盖较低优先级数据包同命名空间下的同名标签。为<code>false</code>时则为此标签进行补充。
* * ：一个游戏资源的列表，代表此标签的内容。
* ** ：一项游戏资源，格式应为<code>-{}-<*命名空间*>:<*路径*></code>。
* ** ：一项游戏资源的标签，格式应为<code>-{}-#<*命名空间*>:<*路径*></code>。循环引用会导致标签加载失败。
* ** ：带有附加选项的格式。
* *** ：一个游戏资源的ID或其标签ID，格式同上。
* *** ：（默认为<code>true</code>）指定的游戏资源是否是必须的。为<code>false</code>时，即使所述内容不存在，游戏也只会静默忽略，而不会使标签加载失败。
</div>

# = 加载行为 =
不同数据包可能会对同一标签重复定义。游戏会自下而上加载标签：
* 如果标签的某个必要元素不存在，或标签出现循环引用，则此标签加载无效。
* 如果标签的某个非必要元素（为<code>false</code>）不存在，则游戏静默忽略，否则正常添加到标签列表中。
* 如果上层数据包定义的标签的为<code>true</code>，则此丢弃下层数据包的数据。即使下层数据包定义的标签无效，游戏也会正常加载上层数据包的标签。
* 如果上层数据包定义的标签的为<code>false</code>，则合并上层和下层的数据。但如果下层数据包定义的标签无效，则此标签加载无效。

# 使用
在不同的场合调用标签会有不同的效果。其广泛的使用方式是测试某资源对象是否在某标签内，只要资源对象符合标签内定义的任意一个资源对象，测试就会成功。

每个原版标签都可能在游戏源码中作为某些执行和调用行为的限定条件，故标签可直接影响其所包含对象的行为。例如，原版方块标签可用于控制和判断各种方块的行为（比如方块是否能被攀爬），原版物品标签可用于控制和判断物品的行为（比如物品是否能被染料染色），原版实体类型标签可用于控制和判断各种生物的行为（比如是否被视为节肢生物，继而影响节肢杀手魔咒）。原版的进度和配方等文件也使用标签从而实现某些条件判断。

原版游戏中不存在函数，默认也不存在函数标签，不过数据包定义的函数文件可以被游戏正常读取。

# = 示例 =
* *定义新标签**
{{file display|data/example/tags/block/my_logs.json|json|
{
  "values": [
    "minecraft:oak_log",
    "minecraft:birch_log",
    "minecraft:spruce_log"
  ]
}
}}

在命令中通过<code>#example:my_logs</code>来使用。例如使用将玩家周围5格的这些方块替换为空气。

* *在标签中引用另外的标签**
{{file display|data/example/tags/block/logs_and_tnt.json|json|
{
  "values": [
    "#minecraft:logs",
    "minecraft:tnt"
  ]
}
}}

此标签文件同时包括方块标签和方块。

* *标签中的可选项**
{{file display|data/example/tags/item/my_items.json|json|
{
  "values": [
    { "id": "example:custom_item", "required": false }
  ]
}
}}

这使得不存在时（比如，在不同的模组环境下时），不会出现加载错误。

* *扩展原版标签**
{{file display|data/minecraft/tags/block/sword_efficient.json|json|
{
  "values": [
    "#minecraft:wool"
  ]
}
}}

在的基础上添加了标签中的所有内容，使得[羊毛](羊毛.md)可被[剑](剑.md)更快地破坏。

* *替换原版标签**
{{file display|data/minecraft/tags/block/beacon_base_blocks.json|json|
{
  "replace": true,
  "values": [
    "minecraft:lodestone"
  ]
}
}}

这将完全覆盖低优先级数据包下的同名文件，使得[信标基座](信标#金字塔.md)只能用[磁石](磁石.md)搭建。
