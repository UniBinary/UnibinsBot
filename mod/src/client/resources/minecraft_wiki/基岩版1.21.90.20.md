# 基岩版1.21.90.20

*页面ID: 150257* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.90.20**（ChromeOS/Android）、**Preview 1.21.90.20**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.90](基岩版1.21.90.md)的首个测试版，发布于2025年4月22日<ref></ref>，更改了[拴绳](拴绳.md)的机制，将所有[追逐天空](追逐天空.md)的特性和从[实验性玩法](实验性玩法.md)中移出，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[创建新的世界](创建新的世界.md)**
* 加入了“”选项。
* * 用于控制是否显示[定位栏](定位栏.md)。

# 更改
# = 方块 =
* *[失水恶魂](失水恶魂.md)**
* 不再属于[实验性玩法](实验性玩法.md)。
* 现在物品[稀有度](稀有度.md)为“常见”。
* 现在不含水时需要下方为[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)才能播放环境音效。

# = 物品 =
* *[挽具](挽具.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

* *[拴绳](拴绳.md)**
* 可牵引长度由10格增长到12格，以判定箱中心距离计算。
* 现在可以连接任意两个生物，而非只能将生物连接到玩家。
* * 玩家牵引生物时对另一生物潜行拴绳会试图将拴绳连接转移到被点击的生物，但如果新连接距离太远，会立刻断裂则不会成功。
* * 拴绳不能连接一个生物与其自身。
* * 被拴住的[羊驼](羊驼.md)不再会形成一支驼队。
* * 幼年生物只能被其他实体拴住，而不能拴住其他实体。
* 现在可以对被拴绳拴住的生物[剪刀](剪刀.md)，以剪断拴绳连接。
* * 装有剪刀的[发射器](发射器.md)也会试图剪断面前生物的拴绳连接。
* 被拴绳牵引时，生物会转向被牵引的方向。
* 玩家在牵引其他生物时使用[烟花火箭](烟花火箭.md)推进会破坏拴绳连接。
* 尝试拴上已经被拴住的生物时，除非该生物由其他玩家拴住，否则将会破坏原有连接，并由玩家拴住该生物。
* 玩家与拴绳结的交互变化如下：
* * 时，会先尝试将玩家牵引的生物拴到拴绳结上，如果均不成功，则由玩家牵引其可牵引的所有生物；如拴绳结此后没有拴住任何生物，其将消失。
* * 潜行时，只会试图将玩家牵引的生物拴到拴绳结上。
* * 剪刀或时，所有生物会由玩家牵引。
* 由[快乐恶魂](快乐恶魂.md)牵引的拴绳自由长度为12格，最大牵引长度为14格。
* [船](船.md)、[运输船](运输船.md)、[骆驼](骆驼.md)、[马](马.md)、[骡](骡.md)、[驴](驴.md)和[嗅探兽](嗅探兽.md)在连接到快乐恶魂上时，会用四根绳子连接二者的四角。
* 现在船和运输船被拴住时在空中会像其他实体一样受到摩擦力影响，而不再会绕玩家旋转或过于有弹性。

* *[刷怪蛋](刷怪蛋.md)**
* [快乐恶魂刷怪蛋](快乐恶魂刷怪蛋.md)不再属于[实验性玩法](实验性玩法.md)。
* 现在使用刷怪蛋生成无法在和平难度下存在的生物时，该生物会生成但被立即清除，而不是无法生成。
* 现在使用[发射器](发射器.md)发射无法在和平难度下存在的生物的刷怪蛋时，该刷怪蛋会被消耗，而不是被以物品形式掷出。

# = 生物 =
* *[恶魂](恶魂.md)**
* 回退了1.21.80.25中对碰撞箱的更改。

* *[快乐恶魂](快乐恶魂.md)**
* 不再属于[实验性玩法](实验性玩法.md)。
* 小恶魂成长为快乐恶魂的所需时间由400分更改为20分。
* 提供支撑的检测范围由向上3格、其他方向1.5格更改为向上2格、向下1格。
* 提供支撑时不再能被骑乘它的玩家控制移动。

* *[猪灵蛮兵](猪灵蛮兵.md)**
* 现在会在和平难度下消失。

* *[僵尸村民](僵尸村民.md)**
* 现在不会在和平难度下消失。<ref></ref>
