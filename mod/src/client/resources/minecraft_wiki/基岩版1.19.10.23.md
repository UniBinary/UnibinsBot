# 基岩版1.19.10.23

*页面ID: 96874* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.10.23**（Android）、**Preview 1.19.10.23**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.10](基岩版1.19.10.md)的第4个测试版，发布于2022年6月15日<ref></ref>，为加入了子命令，同步了更多的特性，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 加入了。
* * 用于定位指定[生物群系](生物群系.md)。
* 加入了。
* * 用于定位指定[结构](结构.md)，与旧版语法功能相同。

# 更改
# = 方块 =
* *[红树胎生苗](红树胎生苗.md)**
* 现在在方块里的位置会随机偏移。

# = 物品 =
* *[河豚](河豚（物品）.md)**
* 给予的[中毒](中毒.md)效果等级由IV降低至II。

# = 生物 =
* *[悦灵](悦灵.md)**
* 现在手持的物品会拥有与其自身相同的发亮纹理效果。

* *[鳕鱼](鳕鱼.md)、[河豚](河豚.md)、[鲑鱼](鲑鱼.md)和[热带鱼](热带鱼.md)**
* 生命值由降低至以匹配。

* *[行商羊驼](行商羊驼.md)**
* 现在会与攻击[流浪商人](流浪商人.md)的生物保持敌对。

* *[潜影贝](潜影贝.md)**
* 现在潜影弹会对被其击中的生物施加[飘浮](飘浮.md)I，而不是飘浮II。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“假日创造者功能”子选项后才可使用。

# = 技术性 =
* *活动对象属性**
* 将字段替换为仅支持数组JSON类型的字段。
* 为拥有支持值的活动对象属性加入了必要的JSON字段。
* * 该属性的字段必须与新的字段中的指定值相匹配。

* *常规**
* 组件值为16的方块不再会无法加载。
* 将组件重命名为。
* 将组件的字段重命名为，其现在使用刻进行描述，而不是使用秒进行描述。
* 将方块可燃尽组件的字段重命名为。
* 加入了使用布尔值来设置方块可燃尽组件的默认可燃尽和不可燃尽数值的功能。

# 修复
* *悦灵**
* 现在悦灵手持的物品会在暗处发光。（）

* *方块**
* 红树木告示牌现在使用红树木板纹理作为挖掘粒子效果。（）
* 现在放置红树胎生苗时会随机偏移。（）
* 现在铁栏杆和玻璃板会与红树根相连接。（）

* *黑暗**
* 黑暗效果现在会在下界和末地维度中正常生效。
* 现在熔岩和细雪迷雾会先于黑暗和失明迷雾渲染。（）

* *幽匿尖啸体**
* 幽匿尖啸体现在能够检测到骑乘包括炽足兽、骷髅马、猪和羊驼在内的所有种类实体的玩家。（）

* *游戏内容**
* 钟现在被任何弹射物击中都会发出声响。
* 紫水晶块现在被弹射物击中时会播放音效。（）
* 修复了在水或船上时无法使用玻璃瓶，且在水上无法放置床的问题。（）

* *监守者**
* 调整了监守者的受伤动画以匹配Java版。（）

* *常规**
* 修复了部分超平坦世界中低于Y=0的地形会错误移除Y=0处基岩的漏洞。（、）

* *用户界面**
* 修复了辅助功能设置中的通知持续时间选项卡拼写出错的问题。（）

* *红树林沼泽**
* 现在红树林沼泽中会生成更茂密的树木以近似匹配Java版。（）
* 现在红树林沼泽中的下方会生成泥巴。（）

* *生物**
* 修复了已驯服生物在多人游戏世界中进入下界传送门时，其会错误消失的漏洞。（）
* 将鳕鱼、河豚、鲑鱼和热带鱼的生命值更改为以匹配Java版。
* 修复了破坏史莱姆生成的行为，以及阻止史莱姆在沼泽生物群系中的史莱姆区块生成的漏洞。（）

* *流浪商人**
* 修复了行商羊驼不会对攻击流浪商人的实体敌对的问题。（）

* *稳定性**
* 进入新手硬币包界面时游戏不再会崩溃。

* *原版趋同**
* 现在潜影弹会对被其击中的生物施加飘浮I，而不是飘浮II。
* 现在吃下河豚后会给予中毒II，而不是中毒IV。

* *技术性**
* 修复了组件的拥有者在没有目标时无法向友方生物传达愤怒的漏洞。现在拥有该组件的生物能够在没有目标且该组件的列表为空时被激怒。（）
* 现在碰撞箱超过生物实际边框的生物能够被弹射物击中。</onlyinclude>
