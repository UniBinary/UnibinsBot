* *区域效果云（Area Effect Cloud）**是一种能为范围内生物施加[状态效果](状态效果.md)的[实体](实体.md)。

# 生成

# = 滞留药水 =
[滞留药水](滞留药水.md)在撞击并破裂后，会在破裂位置生成一团具有对应效果的区域效果云。

该区域效果云的半径为3格，在30秒内逐渐缩小到半径为0后消失，每次对生物造成效果后半径会缩小格且剩余持续时间减少5秒。

# = 苦力怕 =

[苦力怕](苦力怕.md)在爆炸时如果具有任意[状态效果](状态效果.md)，会在爆炸位置生成一个包含其所有状态效果的区域效果云，该区域效果云每一次给予效果时给予的效果的等级和时长都等于苦力怕爆炸时的数据。

该区域效果云的半径为3格，在30秒内逐渐缩小到半径为0后消失，每次使用后半径会缩小格且剩余持续时间减少5秒。

# = 末影龙火球 =
[末影龙火球](末影龙火球.md)在撞击并爆炸后，会在该位置生成一团效果为II、颜色为紫色的区域效果云。该区域效果云可以被收集为[龙息](龙息.md)。

末影龙火球接触[方块](方块.md)时会爆炸，0.5秒后产生区域效果云，半径为3，在30秒内逐渐扩展到半径为5后消失。

末影龙火球碰撞到[实体](实体.md)、方块时都会爆炸，立即产生区域效果云，半径为5，在120秒内逐渐减小直至消失。

# 行为
区域效果云本身是一种不可见的实体，玩家只能通过其产生的大量粒子效果来注意到其存在。

每个区域效果云有以下实体数据定义其行为：
* 半径<code>Radius</code>
* 持续时间<code>Duration</code>
* 半径随时间变化的速率<code>RadiusPerTick</code>
* 每次生效后的半径变化<code>RadiusOnUse</code>
* 每次生效后的持续时间变化<code>DurationOnUse</code>

在区域效果云消失之前，任何进入区域效果云且不免疫其效果的生物在一秒后会受到相应的效果，同时区域效果云的半径会立即改变，其剩余持续时间改变。

方块不能阻止区域效果云扩散和产生效果。处于区域效果云中任何一处得到的效果都相同，且均为最大效果。

# = 状态效果 =
如果区域效果云的效果不是即时生效效果，区域效果云每次生效赋予效果的持续时间是对应普通[药水](药水.md)时长的。

如果区域效果云的效果是一种即时生效效果，包括[瞬间治疗](瞬间治疗.md)、[瞬间伤害](瞬间伤害.md)和[饱和](饱和.md)，区域效果云每次生效的效力会减至对应普通药水的。

# = 龙息 =
由末影龙或末影龙火球产生的区域效果云可以对其[玻璃瓶](玻璃瓶.md)来获取[龙息](龙息.md)，同时半径缩小格。
