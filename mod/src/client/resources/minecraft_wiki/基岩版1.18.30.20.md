# 基岩版1.18.30.20

*页面ID: 93449* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.30.20**（Xbox/Windows/Android）、**Preview 1.18.30.21**（iOS/iPadOS/Xbox/Windows）是[基岩版1.18.30](基岩版1.18.30.md)的第6个测试版，发布于2022年3月3日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[旁观模式](旁观模式.md)**
* 现在可以通过命令进入。
* 目前处于早期开发阶段，暂时使用[生存模式](生存模式.md)的[HUD](HUD.md)和[物品栏](物品栏.md)。
* * 生命值不会降低。
* * 氧气条、饥饿值仍然会发生变化，转为空后不会造成任何影响。

# 更改
# = 生物 =
* *[发光鱿鱼](发光鱿鱼.md)**
* 更改了纹理以修复其发光不正确的问题。

* *[山羊](山羊.md)**
* 山羊身上的[状态效果](状态效果.md)现在也会在其跳跃和冲撞时生效。

* *[玩家](玩家.md)**
* 徒手攻击的伤害由降低至以匹配。

* *[劫掠兽](劫掠兽.md)**
* 现在会主动攻击[流浪商人](流浪商人.md)。

* *[村民](村民.md)**
* 农民村民现在会使用[骨粉](骨粉.md)来催熟农作物，且会对着[堆肥桶](堆肥桶.md)使用多余的种子来转化骨粉。

# = 游戏内容 =
* *[盔甲机制](盔甲机制.md)**
* 加入了[盔甲韧性](盔甲#提供盔甲韧性.md)机制。
* * 同时调整了盔甲的耐久度消耗机制以适应盔甲韧性。
* 现在每件钻石盔甲会提供2点盔甲韧性，每件下界合金盔甲会提供3点。
* * 因此下界合金盔甲现在会提供比钻石盔甲更高的伤害减免。
* 更改了[伤害减免](盔甲机制#伤害减免.md)机制以匹配：
* * 降低了所有盔甲提供的伤害减免。
* * 现在盔甲减免伤害的比例会随着伤害的增高而降低，但减免比例不会降低至原先比例的20%以下。
* ** 每点伤害会减少点有效护甲值。
* * 现在每点护甲值会减免0.8%-4%的伤害，而不是总是减免4%。
* 降低了下界合金盔甲提供的[击退抗性](盔甲#提供击退抗性.md)以匹配。
* * 现在每件下界合金盔甲提供的击退抗性为10%，而不是22.5%。
* * 现在全套下界合金盔甲提供的击退抗性为40%，而不是90%。

* *[保护](保护.md)**
* 现在能够减免[魔法伤害](魔法伤害.md)和[窒息](窒息.md)伤害。
* 降低了伤害减免效果以匹配。

# = 常规 =
* *[RenderDragon](RenderDragon.md)**
* 为所有Android和iOS/iPadOS设备启用了RenderDragon。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“荒野更新”、“假日创造者功能”和“应用测试框架”子选项后才可使用。

# = 方块 =
* *[幽匿尖啸体](幽匿尖啸体.md)**
* 现在会被[幽匿感测体](幽匿感测体.md)激活。
* 现在每次呼啸会触发一个阶段。

# 修复
* *性能与稳定性**
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了在Android上暂停或返回应用程序时可能发生的崩溃。

* *游戏内容**
* 水平分屏游戏时的垂直视野不再会被减少一半，以使分屏玩家能够更容易查看书与笔等物品。
* 调整了世界生成期间的村庄等结构附近的地形。（）
* 禁用“TNT爆炸”且开启“火焰蔓延”游戏规则选项时，TNT不再会消失不见。（）
* 现在将受重力影响的方块放置在雪层上方时，该方块会下落，而不是悬浮在雪层上方。（）

* *原版趋同**
* 创造模式下飞行的玩家不再会被流体推动。（）
* 农民村民现在会使用骨粉来催熟农作物，且会对着堆肥桶使用多余的种子来转化骨粉。（）
* 保护魔咒现在会正确对多数伤害类型生效。（）
* 修复了生命值有时会在视觉上显示为已恢复的不同步问题。
* 现在摔落在石笋上的伤害会被正确视作摔落伤害。（）
* 修复了一些导致受击后伤害免疫无法正确应用的问题。
* 修复了保护魔咒会减免过多伤害的问题，以匹配Java版。（）
* 拥有凋零状态效果时，伤害吸收的生命值不再会变黄。（）
* 加入了盔甲韧性。
* 现在钻石盔甲和下界合金盔甲会分别提供2点和3点盔甲韧性。
* 调整了盔甲的耐久度消耗机制以适应盔甲韧性。
* 现在下界合金盔甲会提供比钻石盔甲更高的伤害减免。
* 降低了下界合金盔甲提供的击退抗性。（）
* 降低了玩家徒手攻击的伤害以匹配Java版。（）

* *图形**
* 修复了发光鱿鱼纹理的部分发光区域透明度不正确，进而导致该部分不发光的问题。（）
* 修复了关闭方块轮廓选择时十字准星会消失的问题。
* 现在无论着火玩家的相机视角是什么，其身上的火都会在物品栏界面中正确地在玩家面前渲染。（）
* 修复了纸娃娃上的皮革盔甲会出现高光效果的问题。（）

* *物品**
* 热带鱼桶在玩家钓到鱼后不再会显示错误名称。

* *市场**
* 现在在商品页面装备皮肤时又会出现提醒信息了。

* *生物**
* 劫掠兽现在会追赶并攻击流浪商人。（）
* 现在通过发射器使用刷怪蛋生成的生物是永久存在的。（）
* 潜影贝不再倾向于与其他潜影贝共处于同一个方块的空间内。（）
* 潜影贝现在会在试图传送前优先选择附着在附近的方块上。
* 现在若条件允许，潜影贝会优先选择继续附着在当前所附着的方块上，而不是直立在其上。

* *用户界面**
* 修复了部分语言的文字在新的创建新世界UI中不会正确渲染的问题。（）

* *村民**
* 制图师村民现在总会出售林地探险家地图。（）

* *命令**
* 现在尝试使用命令来传递至未加载区域且存在0个战利品可被丢出时，游戏会显示正确的错误输出消息。
* 为命令加入了语法。
* 现在客户端完成加入前触发的标题命令会显示出来，而不是被忽略。

* *技术性**
* 行为现在会正确受到生物效果的影响。（）
* 修复了实验性组件BlockCollisionComponents不接受部分规范的问题。</onlyinclude>
