# Java版13w21b

*页面ID: 33535* | *来源: Minecraft Wiki*

* *13w21b**是[Java版1.6.1](Java版1.6.1.md)的第9个快照，2013年5月27日<ref></ref>，发布以修复[13w21a](13w21a.md)里的漏洞和崩溃。

# 修复
语法缺失（）。
|11605|一些死亡消息会用作为导致死亡的玩家或生物的名称。
|16554|en_US语言文件在的语法错误。
|;dev
|15388|驴、骡箱子中的物品可被复制。
|15815|储存在驴、骡箱子中的附魔物品会在其死亡时失去魔咒。
|;previous
|16143|疾跑和速度不起作用。
|16144|服务器不翻译字符串。
|16150|声音一段时间后消失。
