# 携带版1.0.4.0

*页面ID: 27591* | *来源: Minecraft Wiki*

<onlyinclude>

* *alpha 1.0.4.0**是[1.0.4](携带版1.0.4.md)的测试版，发布于2017年2月14日<ref></ref><ref></ref>，加入了村民交易系统，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[村民](村民.md)**
* 加入了傻子村民，但必须通过编辑资源包文件实现。

# = 游戏内容 =
* *[交易](交易.md)**
* 加入了[村民](村民.md)的[交易](交易.md)系统。
* * 当和村民交易时，一个[绿宝石](绿宝石.md)的图案会出现在村民的头上。

* *[附加包](附加包.md)**
* 新的[附加包](附加包.md)格式。所有的附加包都会自动更新，可能会在这些附加包中看到警告，但附加包的所有功能都不会受到影响。

# 更改
# = 生物 =
* *[村民](村民.md)**
* 现在会与其他村民分享食物。
* 现在可以向其投掷3个面包、12个胡萝卜、12个甜菜根或12个马铃薯以增加繁殖意愿。
* 现在只有有意愿时才能繁殖。
* 现在幼年村民拥有和成年村民一样大的头。

* *[潜影贝](潜影贝.md)和[末影龙](末影龙.md)**
* 在附加包的模型现在可以用附加包编辑了。

* *[尸壳](尸壳.md)**
* 现在略高于[僵尸](僵尸.md)。

# 修复
* *修复了34个漏洞**
*  - 重新进入世界后，生物可以穿过栅栏。
*  - 铁匠铺里的熔岩会溢出。
*  - 生物生成在双层台阶上时会一直原地转圈。
*  - 村民在离村庄太远的地方游荡。
*  - 雕纹砂岩和平滑砂岩的底部纹理错误。
* 和 - 村民无法繁殖。
*  - 使用鞘翅飞行然后撞墙时显示的信息错误。
*  - 装备了鞘翅时仍会显示披风。
*  - 射进方块里的箭会变成黑色。
*  - 中型、大型的史莱姆和岩浆怪没有跳跃和着陆声音。
*  - 如果有玩家在其他维度逗留时，主世界里的玩家不能睡觉。
*  - 驴不在平原生物群系里生成。
*  - 末地折跃门方块生成速度太快。
*  - 爆炸会摧毁下界之星。
*  - 摧毁画会使得背后的方块也一并摧毁。
*  - 铁砧在掉落后会转向。
*  - 客户端在加载新区块时，旧区块不能全部刷新。
* 使用命令生成村民时，只会生成农民村民。
* 导入0.15.9或更早的世界时，僵尸村民的职业被重置为农民。
* 被攻击时，村民的逃离速度太快。
* 需要有方块在底部支撑的方块（例如火把和铁轨）不能放置在上半部分台阶上面。
* 受到两个来源的伤害时，玩家会死亡两次。
* 骑乘在其他生物身上的生物的位置不正确。
* 存在特殊条件允许时，仍然只能生成常规骷髅变种的蜘蛛骑士。
* 骑乘型生物（例如蜘蛛骑士）不能进入矿车里。
* “又是……末地……”成就无法达成。
* 生成海底神殿或下界要塞时游戏崩溃。
* 无限火会频繁传播或者减缓燃烧。
* 玩家在附近有其他玩家的情况下切换维度时游戏崩溃。
* 使用给予多于一组的物品时，不会在输出信息里显示正确的物品数量。
* 糖果纹理包里的纹理出现错误。
* 导入资源时游戏崩溃。（仅iOS版）
* 退出时崩溃。
* 加载清单里有错误的行为包或资源包时游戏崩溃。</onlyinclude>
