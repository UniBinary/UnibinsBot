# 马铃薯油

*页面ID: 138320* | *来源: Minecraft Wiki*

* *马铃薯油（Potato Oil）**是一种用于润滑其他物品的物品。

# 获取
# = 精炼 =
在[马铃薯精炼炉](马铃薯精炼炉.md)中精炼[马铃薯](马铃薯.md)可以精炼出马铃薯油，可以获得，精炼时间需要。

# = 箱子战利品 =

# 用途
# = 饮用 =
马铃薯油可以像[药水](药水.md)一样，通过长按键饮用。
* 饮用马铃薯油会获得的[非常滑](非常滑.md)效果。
* 饮用后，会返还空玻璃瓶。

# = 润滑 =
在马铃薯精炼炉的左侧输入槽放入马铃薯油，右侧输入槽放入任意物品，可以润滑该物品，并消耗马铃薯油，不会留下玻璃瓶。
* 润滑后的物品的润滑程度（LubricationFactor）不断趋近直到等于1.0。
* 润滑后的物品实体可以在任意方块上滑行得更远。
* 润滑后的靴子类物品可以让将其穿在身上的玩家滑行。

马铃薯油的润滑作用是物品的固有属性，无论组件数据为何都能进行润滑。

# 你知道吗
* 虽然马铃薯油拥有与[药水](药水.md)相似的外观和功能，但马铃薯油的ID与药水不同，其也不存在“喷溅型马铃薯油”和“滞留型马铃薯油”物品。
* * 在[创造模式物品栏](创造模式物品栏.md)中可以找到名为“马铃薯油”的物品以及其喷溅型和滞留型变种。但这些物品的ID为<code>potion</code>，即它们是具有马铃薯油药水效果的药水。因此这些物品也不能被用来润滑其他物品。
* ** 这些药水形式的“马铃薯油”的瓶中液体呈现微微的淡绿色，而非真正的马铃薯油的白色。
