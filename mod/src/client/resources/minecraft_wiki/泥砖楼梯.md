# 泥砖楼梯

*页面ID: 93990* | *来源: Minecraft Wiki*

* *泥砖楼梯（Mud Brick Stairs）**是[泥砖](泥砖.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
泥砖楼梯会自然生成于[古迹废墟](古迹废墟.md)中。

# 破坏
挖掘泥砖楼梯的合适工具是镐。泥砖楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

泥砖楼梯被破坏后会掉落自身。
