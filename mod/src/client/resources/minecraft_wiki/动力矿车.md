# 动力矿车

*页面ID: 6691* | *来源: Minecraft Wiki*

* *动力矿车（Minecart with Furnace）**是载有[熔炉](熔炉.md)的半自动[矿车](矿车.md)，可以用于驱动其他的[矿车](矿车.md)。

# 用途
动力矿车的放置方式与其他矿车一样。尽管动力矿车的外观是一个装着[熔炉](熔炉.md)的矿车，动力矿车并没有[烧炼](烧炼.md)功能，也没有交互界面。

动力矿车可以蓄能，方法就是对着动力矿车按下键填充燃料（[煤炭](煤炭.md)或[木炭](木炭.md)）。填充燃料后，燃料将被立即消耗，动力矿车将会在以和玩家点击时的方向一致的方向铁轨上开始移动。按键总是会使矿车转变为该方向，即使手中没有煤。

每填充一次燃料，动力矿车就会增加的行进时间，如果增加后会达到则不再增加。

蓄能后，动力矿车会以240米/分钟（约4米/秒，略低于行走速度）的速度移动，每份燃料能让其最多移动720米。它们不会被下坡和激活的[动力铁轨](动力铁轨.md)加速，也不会被上坡和未激活的动力铁轨或推拉其他矿车所减速。

如果动力矿车脱轨然后推回到轨道之上，它会开始再次向它脱轨前的方向移动。

只要燃料未耗尽，动力矿车就可以爬上斜坡并同时推动其他矿车。如果一辆动力矿车在拉动另一辆矿车的同时到达斜坡，被拉动的矿车将会调换顺序到动力矿车的前面，这样它就可以沿斜坡推动而不是拉动，但这样会破坏列车组。

当动力矿车撞上另一个矿车时，另一个矿车会以更快的速度被推出去，而动力矿车会以原速度继续行驶。因为速度差，一些矿车可能会最终停留在直轨道上未加载的区块内。

# = 列车机制 =

[thumb|right|一列动力矿车驱动的矿车列车|alt=](File:FurnaceMinecartTrain.png.md)

行驶速度比动力矿车快的矿车遇上同方向行驶的动力矿车就会形成弱牵引，但弱牵引结构非常脆弱，容易断开。有的方法能够形成强牵引，例如将矿车和未蓄能的动力矿车首尾相连，然后为动力矿车蓄能，此时会形成以动力矿车为车头的强牵引列车组。

无论是强牵引还是弱牵引，在转弯的时候列车组总是会断开。<ref></ref>

一辆动力矿车最多可以牵引四辆矿车，被动力矿车牵引的矿车都会以动力矿车的速度匀速行驶。牵引TNT矿车会导致其爆炸。

# = 属性 =
煤并非作为物品存储在实体中，而是存储在燃料属性中的对象数据中作为刻数。 是一个short值，即最多32767个[刻](刻.md)，小于30分钟。然而，{{cmd|summon furnace_minecart ~ ~ ~ {Fuel:32000} }}并不会让动力矿车行驶，因为没有指定方向。可以在铁轨上按键以给予方向，也可以在召唤时设置<code>PushX</code>和<code>PushZ</code>，这些属性负责方向。请注意，每个实体都具有的<code>Motion</code>属性允许玩家移动矿车，但它不会为矿车提供自己移动所需的方向。
