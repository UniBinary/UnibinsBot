# 难度

*页面ID: 7619* | *来源: Minecraft Wiki*

[缩略图|350px|在较高难度下，身披盔甲的怪物更加常见](File:Skeleton_Golden.png.md)
* *难度（Difficulty）**是在Minecraft中直接影响游戏的难易程度的一个[选项](选项.md)。

# 世界难度

目前游戏中有四种难度设置：和平、简单、普通、困难。它们可以在[选项](选项.md)中或通过命令更改，。[极限模式](极限模式.md)下，[玩家](玩家.md)的游戏难度会被锁定为困难。

# = 和平 =
不会生成除[潜影贝](潜影贝.md)、[疣猪兽](疣猪兽.md)、[猪灵](猪灵.md)和[末影龙](末影龙.md)以外的[敌对生物](敌对生物.md)，并且它们不会攻击玩家（末影龙除外）。人为生成时它们会在瞬间从游戏中移除。生物不会攻击玩家，也无法对玩家造成伤害。玩家的[生命值](生命值.md)会随时间恢复，但是受伤速度过快或受到致命伤害时仍可能[死亡](死亡.md)。[饥饿值](饥饿值.md)永远不会消耗，即使低于最大值也会快速恢复。只能食用[金苹果](金苹果.md)、[附魔金苹果](附魔金苹果.md)、[紫颂果](紫颂果.md)、[谜之炖菜](谜之炖菜.md)和[蜂蜜](蜂蜜.md)；所有[食物](食物.md)都可以食用。

尽管[骆驼尸壳](骆驼尸壳.md)、[骷髅马](骷髅马.md)和[僵尸马](僵尸马.md)属于友好生物，但它们不会在和平难度下自然生成，因为它们的生成机制与敌对生物相关。豹猫的自然生成需要怪物的[生物上限](生成#生物上限.md)，这使得[豹猫](豹猫.md)不能在和平难度下自然生成。<ref></ref>

目前，在大多数情况下，和平难度下不可通关Minecraft，除非使用含已开启的[末地传送门](末地传送门.md)的[种子](种子（世界生成）.md)，否则无法进入[末地](末地.md)。在大多数情况下，杀死[烈焰人](烈焰人.md)从而获得[烈焰棒](烈焰棒.md)，合成[烈焰粉](烈焰粉.md)并进一步合成[末影之眼](末影之眼.md)是激活末地传送门的必要条件。不过，自然生成的末地传送门中的每个[框架](末地传送门框架.md)都各有10%的概率是已经嵌入末影之眼的，因此有极其微小的概率（10）会直接生成已激活的末地传送门，从而允许玩家不获得烈焰棒直接进入末地。在和平难度下[进度](进度.md)或[成就](成就.md)不能被全部达成。

难度为和平且为<code>true</code>时，玩家每增加生命值。

难度为和平且为<code>true</code>时，玩家每增加饥饿值，且每增加1点[饱和度](饱和度.md)。

难度为和平时，玩家每增加饥饿值。

# = 简单 =
会生成敌对生物，不过造成的伤害比普通难度低。饥饿值会消耗，并在耗尽时使玩家的生命值逐渐降至。[洞穴蜘蛛](洞穴蜘蛛.md)和[蜜蜂](蜜蜂.md)在简单难度中不会使目标[中-{}-毒](中毒.md)，[凋灵](凋灵.md)也不会给予玩家[凋零](凋零.md)效果，但[凋灵骷髅](凋灵骷髅.md)会给予玩家凋零效果。[闪电](闪电.md)只会让击中的方块起火，而不会直接导致周围的方块着火。[僵尸](僵尸.md)不会将[村民](村民.md)感染为[僵尸村民](僵尸村民.md)。

# = 普通 =
会生成敌对生物，能造成标准量的伤害。饥饿值会消耗，并在耗尽时使玩家的生命值逐渐降至。[僵尸](僵尸.md)有50%概率将[村民](村民.md)感染为[僵尸村民](僵尸村民.md)。

# = 困难 =
会生成敌对生物，能造成的伤害比普通难度更高。饥饿值会消耗并在耗尽时让玩家饿死。[僵尸](僵尸.md)能够破坏[木门](木门.md)及[铜门](铜门.md)，。[僵尸](僵尸.md)杀死[村民](村民.md)时总是会将其感染为[僵尸村民](僵尸村民.md)。[蜘蛛](蜘蛛.md)生成时可能会带有[迅捷](迅捷.md)、[力量](力量（状态效果）.md)、[生命恢复](生命恢复.md)或[隐身](隐身.md)这四种[效果](效果.md)中的一种。

# 区域难度
[缩略图|400px|[[调试屏幕](File:Local Difficulty Debug.png.md)下显示的区域难度值（对应[调试选项](调试选项.md)）]]

* *区域难度（Regional difficulty）**是一个介于0.00和6.75之间的值，基于不同的因素计算得到。这些因素包括当前区块的“占据时间”、在世界里总共游玩的时长、[月相](月相.md)以及当前难度设置。当前区域难度在[调试屏幕](调试屏幕.md)上显示为“Local Difficulty”（本地难度）之后的第一个值。

在本段中：
* 区块的“占据时间”随着玩家在区块所经过的每一刻而增加。多个玩家的时间会累积起来——如果50个玩家在某区块中度过了1个小时，相当于1个玩家在该区块度过了50个小时。
* “占据时间”不存在。
* 世界的“总时间”指获取到的值加上调试屏幕上的天数转换为刻的值，即<math>\text{总时间} = \text{天数} \times 24000 + \text{当日时间}</math>，不等同于世界的实际游玩时间（获取到的值）。

和平难度下，区域难度总为0。下文的“难度”不包含和平难度。

世界的总时间将在第3个游戏日后开始影响区域难度，随后影响逐渐增大，在63个游戏日时不再继续增大影响。游戏将根据该值计算“总时间因子”。总时间大于63个游戏日时，总时间因子为0.25（即与63个游戏日时的总时间因子相同）；小于3个游戏日时，总时间因子为0；不小于3个游戏日但不大于63个游戏日时，<math>\text{总时间因子} = \frac{(\text{总时间刻数} - 72000)}{5760000}</math>。

区块的占据时间对区域难度的影响最多是50个小时。游戏将根据占据时间、月相计算“区块因子”：
# 困难难度下，如果占据时间大于50个小时，则这一步的值为1，否则为<math>\frac{\text{占据时间刻数}}{3600000}</math>；其他难度下的值为困难难度下的值的；
# 将上一步的值加上总时间因子、月亮亮度的中的较小者，两者相等则加上该相等的值；
# 简单难度下，最终的值为上一步的值的一半，其他难度下最终的值即为上一步的值。

最后，计算<math>0.75 + \text{总时间因子} + \text{区块因子}</math>，在简单，普通或困难难度下分别将该值保持不变、乘2或乘3，就得到最终的区域难度。

在简单难度中区域难度的范围是0.75–1.5，在普通难度时为1.5–4.0，在困难难度时为2.25–6.75。

# = 副区域难度 =

* *副区域难度（Clamped<ref group="注">此处“Clamped”指“值被限定在一个区域内”，即其范围在0.00至1.00之间。</ref> regional difficulty）**是一个介于0.00和1.00之间的值，基于区域难度计算得到。当前副区域难度在调试屏幕上显示为“Local Difficulty”之后的第二个值。

设区域难度为<math>R</math>，副区域难度为<math>C</math>，副区域难度与区域难度的关系式为：<math>C = \begin{cases}0.0, & R < 2.0 \\\dfrac{R - 2.0}{2.0}, & 2.0 \leq R \leq 4.0 \\ 1.0, & R > 4.0 \end{cases}</math>

该计算过程的Java代码如下所示，其中<code>RegionalDifficulty</code>代表区域难度的值，<code>value</code>代表副区域难度的值。
<syntaxhighlight lang="java">
 if ( RegionalDifficulty < 2.0 ) {
     value = 0.0;
 } else if ( RegionalDifficulty > 4.0 ) {
     value = 1.0;
 } else {
     value = ( RegionalDifficulty - 2.0 ) / 2.0;
 }
</syntaxhighlight>

因此，在简单难度下，由于区域难度最高为1.5，该值将始终为0；在困难难度下，由于区域难度最低为2.25，该值将至少为0.125；该值始终为1。

在简单难度中区域难度没有影响；普通难度中且满月时在一个区块中游玩21小时将达到最大影响；而困难难度中且满月时在区块中只要游玩小时就能达到最大影响，并且在游玩超过小时时将保持最大影响。

区域难度不单独使用，仅作为副区域难度计算的中间量使用。
