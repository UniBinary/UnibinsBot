# 深板岩砖

*页面ID: 125617* | *来源: Minecraft Wiki*

* *深板岩砖（Deepslate Bricks）**是[深板岩圆石](深板岩圆石.md)制作的装饰性方块。

# 破坏
挖掘深板岩砖的合适工具是镐。

深板岩砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

深板岩砖被破坏后会掉落自身。
