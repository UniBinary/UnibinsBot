# Java版标签/伤害类型

*页面ID: 161612* | *来源: Minecraft Wiki*

* *伤害类型标签（Damage Type Tags）**是[伤害类型](伤害类型.md)的组合。

# 使用
伤害类型标签用于将伤害类型分组，例如所有火焰伤害被归类为标签<code>#is_fire</code>。当游戏使用标签测试伤害类型时，只要伤害类型在此标签内即测试成功。

# 当前版本

# = always_hurts_ender_dragons =
* 持有该标签的伤害类型的伤害总是能对末影龙造成伤害。

# = always_kills_armor_stands =
* 持有该标签的伤害类型的伤害总是会完全杀死[盔甲架](盔甲架.md)。

# = always_most_significant_fall =
* 生物死于持有此标签的伤害类型的伤害时，在计算死亡消息时总是会认为生物下落了超过15格。

# = always_triggers_silverfish =
* 持有该标签的伤害类型的伤害总是触发[蠹虫](蠹虫.md)破坏周围[虫蚀方块](虫蚀方块.md)的效果，即使伤害没有来源。

# = avoids_guardian_thorns =
* 持有该标签的伤害类型的伤害不触发[守卫者](守卫者.md)或[远古守卫者](远古守卫者.md)的尖-{}-刺效果。

# = burn_from_stepping =
* 持有该标签的伤害类型的伤害会被穿着附有[冰霜行者](冰霜行者.md)靴子的玩家免疫。

# = burns_armor_stands =
* 持有该标签的伤害类型的伤害使盔甲架生命值减少。

# = bypasses_armor =
* 持有该标签的伤害类型的伤害无视[护甲值](护甲值.md)的伤害减免效果。

# = bypasses_cooldown =
* 持有该标签的伤害类型的伤害无视[受击后伤害免疫](受击后伤害免疫.md)。
* 原版游戏未包含此檔案。

# = bypasses_effects =
* 持有该标签的伤害类型的伤害无视[抗性提升](抗性提升.md)的伤害减免效果。

# = bypasses_enchantments =
* 持有该标签的伤害类型的伤害无视[保护](保护.md)的伤害减免效果。

# = bypasses_invulnerability =
* 持有该标签的伤害类型的伤害无视伤害免疫效果，包括持有实体数据<code>Invulnerable</code>的生物、处于创造模式或旁观模式的玩家、准备状态的凋灵、正在钻地的监守者的伤害免疫效果。
* 生物死于持有此标签的伤害类型的伤害时，不会触发不死图腾。

# = bypasses_resistance =
* 持有该标签的伤害类型的伤害无视一切伤害减免效果和伤害免疫效果。

# = bypasses_shield =
* 持有该标签的伤害类型的伤害无视[盾牌](盾牌.md)的阻挡。

# = bypasses_wolf_armor =
* 持有该标签的伤害类型的伤害无视[狼铠](狼铠.md)的抵消效果。

# = can_break_armor_stand =
* 持有该标签的伤害类型能一击破坏盔甲架。

# = damages_helmet =
* 持有该标签的伤害类型的伤害对头盔造成大量耐久度消耗。

# = ignites_armor_stands =
* 持有该标签的伤害类型的伤害设置盔甲架的剩余[着火](着火.md)时间为。

# = is_drowning =
* 持有该标签的伤害类型的伤害被[游戏规则](游戏规则.md)为<code>false</code>时的玩家免疫。

# = is_explosion =
* 持有该标签的伤害类型的伤害受到[爆炸保护](爆炸保护.md)的伤害减免效果。

# = is_fall =
* 持有该标签的伤害类型的伤害受到[摔落缓冲](摔落缓冲.md)的伤害减免效果。
* 持有该标签的伤害类型的伤害被[猫](猫.md)、[豹猫](豹猫.md)、[雪傀儡](雪傀儡.md)、[铁傀儡](铁傀儡.md)、[岩浆怪](岩浆怪.md)、[蝙蝠](蝙蝠.md)、[烈焰人](烈焰人.md)、[末影龙](末影龙.md)、[恶魂](恶魂.md)、[鹦鹉](鹦鹉.md)、[恼鬼](恼鬼.md)、[凋灵](凋灵.md)、[鸡](鸡.md)、[潜影贝](潜影贝.md)、[游戏规则](游戏规则.md)为<code>false</code>时的玩家免疫。

# = is_fire =
* 持有该标签的伤害类型的伤害受到[火焰保护](火焰保护.md)的伤害减免效果。
* 持有该标签的伤害类型的伤害被[僵尸猪灵](僵尸猪灵.md)、[恶魂](恶魂.md)、[凋灵骷髅](凋灵骷髅.md)、[烈焰人](烈焰人.md)、[炽足兽](炽足兽.md)、[岩浆怪](岩浆怪.md)、[僵尸疣猪兽](僵尸疣猪兽.md)、[监守者](监守者.md)、[末影龙](末影龙.md)、[凋灵](凋灵.md)、具有[抗火](抗火.md)效果的生物、[游戏规则](游戏规则.md)为<code>false</code>时的玩家免疫。

# = is_freezing =
* 持有该标签的伤害类型的伤害被[游戏规则](游戏规则.md)为<code>false</code>时的玩家免疫。

# = is_lightning =
* 持有该标签的伤害类型的伤害击杀[海龟](海龟.md)后有概率掉落。

# = is_player_attack =
* 由玩家造成的攻击伤害类型。

# = is_projectile =
* 持有该标签的伤害类型的伤害受到[弹射物保护](弹射物保护.md)的伤害减免效果。

# = mace_smash =
* 用于。

# = no_anger =
* 持有该标签的伤害类型的伤害不引发受到伤害的实体对造成伤害的实体的反击。

# = no_impact =
* 持有该标签的伤害类型的伤害不会使实体受伤后服务端发送数据包以同步位置和速度。

# = no_knockback =
* 持有该标签的伤害类型的伤害不造成[击退](伤害#击退.md)。

# = panic_causes =
* 持有该标签的伤害类型会使被动型动物惊慌（尝试逃走）。

# = panic_environmental_causes =
* 持有该标签的伤害类型会使[条件敌对动物](生物#条件敌对.md)惊慌（进行反击）。

# = witch_resistant_to =
* 持有该标签的伤害类型的伤害受到[女巫](女巫.md)的85%伤害减免效果影响。

# = wither_immune_to =
* 持有该标签的伤害类型的伤害被[凋灵](凋灵.md)免疫。
