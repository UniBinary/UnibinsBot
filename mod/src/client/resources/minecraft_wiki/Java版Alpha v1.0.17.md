# Java版Alpha v1.0.17

*页面ID: 32517* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.17**是的一次秘密更新，发布于2010年8月20日<ref></ref>，加入了[栅栏](栅栏.md)和[蜘蛛骑士](蜘蛛骑士.md)。

# 新内容
# = 方块 =
* *[栅栏](栅栏.md)**
* 高1.5格，不能被生物跳过。
* 可由6个[木棍](木棍.md)合成。

# = 生物 =
* *[蜘蛛骑士](蜘蛛骑士.md)<ref></ref>**
* 一种由[蜘蛛](蜘蛛.md)和[骷髅](骷髅.md)组成的生物组合。

# = 游戏内容 =
* *常规**
* 现在[玩家](玩家.md)生成时会携带64个栅栏。

# 更改
# = 物品 =
* *[奶桶](奶桶.md)**
* 现在可以倒空了。

# = 生物 =
* *[鸡](鸡.md)**
* 现在会在下落时拍打翅膀，因此不再承受摔落伤害了。
* 现在在[多人游戏](多人游戏.md)中可用。<ref>http://i38.tinypic.com/svmmab.jpg</ref>

* *[史莱姆](史莱姆.md)**
* 现在在多人游戏中可用。

* *[猪](猪.md)**
* 现在在多人游戏中可用。

# = 游戏内容 =
* *[昼夜更替](昼夜更替.md)**
* 现在在多人游戏中可用。

* *[第三人称视角](第三人称视角.md)**
* 第三人称视角现在再次居中。
* 现在在第三人称视角中，当玩家右击可以使用的方块，玩家可以看到手臂摆动的动画。</onlyinclude>
