# 启动器2.3.173

*页面ID: 96144* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.3.173**是一次[启动器](启动器.md)更新，发布于2022年5月11日。

# 新内容
* 加入了一键复制错误代码信息的功能。

# 更改
* 增强了在确保用户使用与启动器相同的账户登录Microsoft Store的过程中的消息传递。
* 现在，点击高级选项中的“清除账号口令缓存”按钮会有相应的反馈，使用户可知其已被点击。

# 修复
* 修复了用户无法在按照一款游戏时不能启动另一款的漏洞。
* “无网络连接”以及登录尝试失败的提示现在可以被翻译了，并针对一些本地化过程进行了修复。
* 修复了与无法获取用户Minecraft档案有关的漏洞。
* 修复了各种崩溃以及用户问题。
*  - 启动器的新字符串中几处提及“Minecraft: Java Edition”的地方拼写不正确。
*  - 在一条有关迁移通知的启动器字符串中，术语“roll out”（推出）被拼写成了“rollout”。
*  - 在一条用于常规错误消息的启动器字符串中，单词“Sorry”（抱歉）后缺少逗号。
*  - 单击“编辑配置”菜单中的“浏览”按钮时启动器崩溃。
*  - 启动器在重启过后仍然会提示“请重启启动器以获取最新版本”。</onlyinclude>
