* *巨型诡异菌（Huge Warped Fungus）**是一种生成于下界且类似于[树木](树木.md)的[地物](地物.md)。

# 结构
巨型诡异菌的枝干由[诡异菌柄](诡异菌柄.md)组成，不同植株的枝干粗细各有差异：粗者横截面可达3×3格，且周围会长出一些游离的茎；细者横截面则为1×1格，且笔直向上生长；有些枝干为十字形。枝干的高度在4-26格之间不等。其“菌盖”则由[诡异疣块](诡异疣块.md)组成，最大半径可达4格，且菌盖不会下垂到比枝干根部还低的地方。菌盖内部都可能会生成[菌光体](菌光体.md)。

# 生成
# = 自然生成 =
巨型诡异菌会自然生成于[诡异森林](诡异森林.md)生物群系。

# = 人为生成 =
对种在[诡异菌岩](诡异菌岩.md)上的[诡异菌](诡异菌.md)[骨粉](骨粉.md)可使之生长成对应变种的巨型诡异菌。

如果用骨粉催熟出一个巨型诡异菌，它的菌柄横截面总是1×1格。<ref></ref>

下界菌上方即使有方块阻挡，也能够长成巨型诡异菌<ref></ref>，且其上方的除自身组成方块的任何方块均不会被替换掉。巨型诡异菌最多可生长27格高，所占空间最多可达9×27×9格。

与[树木](树木.md)不同，破坏巨型诡异菌的菌柄不会导致其上的“菌盖”逐渐消失，这意味着处理巨型诡异菌会比处理树木更加麻烦。
