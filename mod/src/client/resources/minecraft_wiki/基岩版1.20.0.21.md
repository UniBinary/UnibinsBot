# 基岩版1.20.0.21

*页面ID: 103893* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.0.21**（ChromeOS/Android）、**Preview 1.20.0.21**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.0](基岩版1.20.0.md)的第2个测试版，发布于2023年4月19日<ref></ref>，将所有[足迹与故事](足迹与故事.md)特性从[实验性玩法](实验性玩法.md)中移出，并修复了一些漏洞。

# 新内容
# = 技术性 =
* *实体过滤器**
* 加入了和实体过滤器。
* * 用于搜索指定装备位置的空物品槽。

# 更改
# = 方块 =
* *[瓶子草植株](瓶子草植株.md)**
* 现在判定箱大小会根据生长阶段变化。

* *[幽匿尖啸体](幽匿尖啸体.md)**
* 现在会在[含水](含水.md)时静音。

* *[幽匿感测体](幽匿感测体.md)**
* 更改了许多可感测的游戏事件的振动频率，新的振动种类及其对应的振动频率见下表：

* 现在会强充能下方的方块。
* 上述更改同样适用于[校频幽匿感测体](校频幽匿感测体.md)。

* *[校频幽匿感测体](校频幽匿感测体.md)**
* 不再属于[实验性玩法](实验性玩法.md)。
* 激活冷却时间由2秒调整至1秒。
* 振动感测距离由8格提升至16格。

* *常规**
* [竹块](竹块.md)及其变种、[竹板](竹板.md)及其变种、[竹马赛克](竹马赛克.md)及其变种、[雕纹书架](雕纹书架.md)、[樱花树叶](樱花树叶.md)、[樱花原木](樱花原木.md)及其变种、[樱花木板](樱花木板.md)及其变种、[樱花树苗](樱花树苗.md)、[櫻花木塊](櫻花木塊.md)及其变种、[悬挂式告示牌](悬挂式告示牌.md)、[饰纹陶罐](饰纹陶罐.md)、[粉红色花簇](粉红色花簇.md)、[可疑的沙砾](可疑的沙砾.md)、[可疑的沙子](可疑的沙子.md)和[猪灵的头](猪灵的头.md)不再属于[实验性玩法](实验性玩法.md)。

# = 物品 =
* *常规**
* [刷子](刷子.md)、[骆驼](骆驼.md)刷怪蛋、[陶片](陶片.md)和[锻造模板](锻造模板.md)不再属于[实验性玩法](实验性玩法.md)。

# = 生物 =
* *[骆驼](骆驼.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

* *[监守者](监守者.md)**
* 现在能检测到[紫水晶块](紫水晶块.md)的共振。

# = 非生物实体 =
* *常规**
* [竹筏](竹筏.md)、[运输竹筏](运输竹筏.md)、[樱花木船](樱花木船.md)和[樱花木运输船](樱花木运输船.md)不再属于[实验性玩法](实验性玩法.md)。

# = 世界生成 =
* *常规**
* [樱花树林](樱花树林.md)生物群系和[古迹废墟](古迹废墟.md)结构不再属于[实验性玩法](实验性玩法.md)。

# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 移除了“下一个主要更新”子选项。

# = 技术性 =
* *基岩版编辑器**
* 修复了编辑器可以在正常游戏时访问的漏洞。

* *常规**
* 修复了Molang序列无法返回部分物品扁平化前的ID的问题。

* *图形**
* 修复了关闭光线追踪功能并加载与光线追踪兼容的内容后启用光线追踪功能可能导致的崩溃。（）

* *物品**
* 现在有和的自定义物品可以一并修复而无须自定义物品条目。

* *配方**
* 修复了使用相同方块但不同数据值的配方会报出不正确的内容日志错误的问题。（）

* *组件**
* 现在的组件可以在JSON文件中正确解析。（）

# 修复
* *辅助功能**
* 文本转语音现在会朗读创造模式物品栏中的四个选项卡的名称。

* *方块**
* 现在刷扫可疑的沙子和可疑的沙砾时会播放对应的音效。（）

* *饰纹陶罐**
* 饰纹陶罐的侧面现在拥有顶行像素。（）

* *瓶子草植株**
* 瓶子草植株现在会根据生长阶段调整判定箱大小。（）
* 瓶子草植株现在拥有底部纹理。（）

* *校频幽匿感测体**
* 现在校频幽匿感测体的激活冷却时间为1秒，而不是2秒。（）
* 现在校频幽匿感测体能够感测16格内的振动，而不是8格内的振动。（）

* *游戏内容**
* 修复了玩家在灵魂沙产生的上涌气泡柱上跳跃时会累积摔落伤害的问题。

* *图形**
* 现在手持或掉落物形式的饰纹陶罐会遵循光照渲染规则。（）
* 现在手持或掉落物形式的潮涌核心会遵循光照渲染规则。

* *告示牌**
* 现在尝试与涂蜡的告示牌交互时会播放音效。（）
* 玩家不再能够对带有空白文本的告示牌使用墨囊、荧光墨囊或染料。（）
* 现在手持无法对告示牌使用的物品与未涂蜡的告示牌交互时会打开告示牌并进行编辑。
* 现在手持部分物品与告示牌交互时只会打开告示牌并进行编辑，不再会触发该物品的特定动作。（）
* * 例如：刷子、盔甲、钓鱼竿、书与笔、山羊角和空白地图。
* 现在使用游戏手柄或触摸控制时，若玩家可以与告示牌交互，则会显示正确的提示框。
* 现在编辑告示牌时显示的文本颜色与对该告示牌使用的染料的颜色相匹配。（）
* 现在可以在不潜行的情况下将悬挂式告示牌附着在另一个悬挂式告示牌上。

* *嗅探兽**
* 修复了嗅探兽的头部会与身体产生深度冲突的问题。（）

* *幽匿尖啸体**
* 含水的幽匿尖啸体现在会静音。（）

* *用户界面**
* 现在使用控制器且控制器提示被禁用时，市场和更衣室的循环按钮会显示导航栏V形图案。（）
* 修复了创建新的世界屏幕中的多人游戏选项即使无效也会偶尔不变灰的问题。
* 现在开启“显示坐标”选项时，坐标会在新的死亡屏幕中显示。

* *原版趋同**
* 现在打开和关闭状态下的门的顶部和底部纹理会正确旋转。（）</onlyinclude>
