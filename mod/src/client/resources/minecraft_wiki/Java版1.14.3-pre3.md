# Java版1.14.3-pre3

*页面ID: 44582* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14.3-pre3**是[Java版1.14.3](Java版1.14.3.md)的第3个预发布版，发布于2019年6月14日<ref></ref>，加入了新的游戏规则和新的语言，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 加入了，设置为时禁用[袭击](袭击.md)。
* 如果在袭击发生时设置为，袭击会停止，但已经生成的袭击者不会被清除。

# = 选项 =
* *[语言](语言.md)**
* 加入了巴什基尔语（Башҡортса）。
* 加入了哥特语（Gutrazda）。

# 更改
# = 方块 =
* *[火把](火把.md)、[灯笼](灯笼.md)和[压力板](压力板.md)**
* 现在可以放在[铁栏杆](铁栏杆.md)和[玻璃板](玻璃板.md)上了。

* *[灯笼](灯笼.md)**
* 现在可以悬挂在[铁栏杆](铁栏杆.md)和[玻璃板](玻璃板.md)的底部了。

# = 物品 =
* *常规**
* [物品](物品.md)现在又可以通过将它们合成在一起来修复了，就像1.14之前那样。
