# 探索更新

*页面ID: 28768* | *来源: Minecraft Wiki*

[缩略图|300px|Mojang发布的探索更新图片](File:Pocket Discovery Update Poster.png.md)

* *探索更新（Discovery Update）**是[携带版](携带版.md)的一次主要更新，发布于2017年6月1日。本次更新的官方名称“探索更新”于2017年3月29日在Minecraft网站的一篇博文中发布。<ref></ref>

此次更新的开发始于[1.1.0.0](携带版1.1.0.0.md)，其发布于2017年3月31日。

# 重要特性

# = 新内容 =
* [Minecraft商城](Minecraft商城.md)
* [林地府邸](林地府邸.md)
* * 包括其在[探险更新](探险更新.md)中的所有特性，除了[旗帜](旗帜.md)。
* 5种新的方块：
* * [混凝土](混凝土.md)，[混凝土粉末](混凝土粉末.md)，[带釉陶瓦](带釉陶瓦.md)，[潜影盒](潜影盒.md)和[霜冰](霜冰.md)。
* 7种新的物品：
* * [探险家地图](探险家地图.md)， [不死图腾](不死图腾.md)，[铁粒](铁粒.md)和4种新的[刷怪蛋](刷怪蛋.md)。
* 5种新生物：
* * [羊驼](羊驼.md)、[卫道士](卫道士.md)、[唤魔者](唤魔者.md)、[恼鬼](恼鬼.md)和制图师[村民](村民.md)。
* 经验修补和冰霜行者[附魔](附魔.md)
* 6个新的成就。

# = 更改 =
* [床](床.md)可以被染成16种颜色。

# 跟进版本
* [1.1.1](携带版1.1.1.md)和[1.1.2](携带版1.1.2.md)发布以修复各种漏洞。
* [1.1.3](携带版1.1.3.md)添加了化石，也为下界添加了一些方块。
* [1.1.4](携带版1.1.4.md)和[1.1.5](携带版1.1.5.md)向商城添加了一些皮肤包。1.1.5也收到了商城内容的更新，这使得商城的更新不再需要版本的升级。
* [1.1.7](携带版1.1.7.md)仅发布于iOS，加入了对[IPv6](wzh:IPv6.md)的支持。
