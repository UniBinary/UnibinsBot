# Java版16w04a

*页面ID: 19731* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w04a**是[Java版1.9](Java版1.9.md)的第51个快照，发布于2016年1月28日<ref></ref>，修复了一些漏洞。

# 更改
# = 非生物实体 =
* *[船](船.md)**
* 按下键与键可前进或后退，分别按下键与键来转向。
* 船在航行经过[睡莲](睡莲.md)时会破坏睡莲。
* 同时按下键与键会停留在原地，而桨会持续划动。
* 不同于前期的快照，船速度更快且更稳定。
* 可在陆地上工作，且速度快于疾跑。
* 船上方有水时会沉没。
* 合成配方不再需要[锹](锹.md)。

# = 常规 =
* *[声音](声音.md)**
* 更新了一些声音文件。
* 雨的声音更轻、更融入背景，听起来也更“真实”。
