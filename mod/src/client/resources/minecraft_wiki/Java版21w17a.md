* *21w17a**是[Java版1.17](Java版1.17.md)的第19个快照，发布于2021年4月28日<ref></ref>，更改了开采[铜矿石](铜矿石.md)掉落[粗铜](粗铜.md)的数量，在[单独的数据包](洞穴与山崖预览数据包.md)中对[洞穴](洞穴.md)和[矿脉](矿脉.md)的生成进行了调整，并修复了一些漏洞。

# 新内容
# = 世界生成 =
本段落介绍的内容需加载[数据包](洞穴与山崖预览数据包.md)启用。

* *[面条洞穴](面条洞穴.md)**
* 一种新的[噪声洞穴](噪声洞穴.md)，比[意面洞穴](意面洞穴.md)更加狭窄、弯曲而密闭。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 包含[黏土](黏土.md)和[苔藓块](苔藓块.md)。
* * [小型垂滴叶](小型垂滴叶.md)可以放置在拥有此标签的方块上。

# 更改
# = 方块 =
[缩略图|21w16a和21w17a中粗金属块纹理的比较](File:Snapshot-21w17a-ore-texture-comparison-full.jpg.md)

* *[粗金属块](粗金属块.md)**
* 更改了纹理。

* *[铜矿石](铜矿石.md)和[深层铜矿石](深层铜矿石.md)**
* 现在被开采后会掉落2-3个[粗铜](粗铜.md)，而非先前的1个。
* * [时运](时运.md)魔咒可以增加掉落数量。

* *[铜块](铜块.md)**
* 现在铜块需要用9个[铜锭](铜锭.md)合成。
* 现在铜块和[涂蜡的铜块](涂蜡的铜块.md)可分解为9个铜锭。

* *[小型垂滴叶](小型垂滴叶.md)**
* 现在可以放置在[苔藓块](苔藓块.md)上。

* *[大型垂滴叶](大型垂滴叶.md)**
* 现在大型垂滴叶茎在其上方的茎或叶片被破坏时也会被一同破坏。

* *[垂根](垂根.md)**
* 现在能够[含水](含水.md)了。

# = 生物 =
* *[凋灵](凋灵.md)**
* 现在免疫[冰冻](细雪#冰冻.md)伤害。

# = 世界生成 =
* *[矿脉](矿脉.md)**
* 现在更加罕见且规模更小。
* 现在其中的[矿石](矿石.md)分布更不均匀，且有更高的概率呈团簇状生成。
* 现在有概率包含[粗铁块](粗铁块.md)或[粗铜块](粗铜块.md)。
* * 上述更改需加载[数据包](洞穴与山崖预览数据包.md)启用。

* *[矿石](矿石.md)分布**
* 现在[绿宝石矿石](绿宝石矿石.md)能够取代[花岗岩](花岗岩.md)、[闪长岩](闪长岩.md)、[安山岩](安山岩.md)、[凝灰岩](凝灰岩.md)和[深板岩](深板岩.md)生成。
* 现在[煤矿石](煤矿石.md)、[铜矿石](铜矿石.md)和绿宝石矿石在取代深板岩或凝灰岩生成时会生成为深层变种。

# = 常规 =
* *[标签](Java版标签.md)**
* 将凋灵加入到了实体类型标签中。

* *[格式化代码](格式化代码.md)**
* 现在随机字符（§k）后面的“i”不再会显示为i、!或|，而是和它所占位置大小相同的字符。

# 修复
2999983以外的世界边界会导致游戏崩溃。
