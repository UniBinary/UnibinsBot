# Java版12w05a

*页面ID: 32318* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w05a**是[Java版1.2.1](Java版1.2.1.md)的第3个快照，发布于2012年2月2日<ref></ref>，细微修改了生物AI，并更改了熔岩流动的声音。

# 更改
# = 方块 =
* *[枯萎的灌木](枯萎的灌木.md)**
* 现在能够通过使用[剪刀](剪刀.md)获得。

# = 物品 =
* *[火焰弹](火焰弹.md)**
* 现在能够用[木炭](木炭.md)合成。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 现在会跑离[豹猫](豹猫.md)。
* 苦力怕有了新的AI——它们会跟随玩家。

* *[豹猫](豹猫.md)**
* 变得更容易被驯服，并且驯服后可以坐下。

* *[村民](村民.md)**
* 现在会寻找[村庄](村庄.md)并且居住下来。

* *音效**
* [熔岩](熔岩.md)有了流动时特有的声音。

# = 世界生成 =
* *[废弃矿井](废弃矿井.md)**
* [废弃矿井](废弃矿井.md)如果经过悬空的地方，会生成桥梁。

# = 常规 =
* *[语言](语言.md)文件**
* 更新了语言文件。
* * 移除了一些令人反感的翻译文本。

* *[附魔台](附魔台.md)**
* 在[创造模式](创造模式.md)下，使用附魔台附魔不再需要[经验值](经验值.md)。

* *[音效](音效.md)**
* 熔岩的声音现在会正常播放。

# 修复
* *修复了1个漏洞**
* 修复了一个利用下界传送门复制物品的漏洞。

# 重新上传
该版本于14:42（UTC）被重新上传，以修复空手右键豹猫使其坐下时的崩溃和语言翻译上的漏洞。<ref></ref></onlyinclude>
