# 音乐唱片ward

*页面ID: 156609* | *来源: Minecraft Wiki*

* *ward**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的同名曲目。

# 获取
# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片ward。

# 用途
# = 音乐 =

[noicon](File:ward.ogg.md)

Ward乐曲开头是电子管风琴演奏的肖邦的《葬礼进行曲》片段<ref></ref>，接着被黑胶静电声打断，其后转为欢快的电子乐，并配以忧郁的低音，游戏内时长为4分11秒。

# = 红石 =

音乐唱片ward放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为10的信号。
