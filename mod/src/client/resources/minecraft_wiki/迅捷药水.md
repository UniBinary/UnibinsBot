# 迅捷药水

*页面ID: 181533* | *来源: Minecraft Wiki*

* *迅捷药水**是提供[迅捷](迅捷.md)状态效果的[药水效果](药水效果.md)。

该药水效果可以制成[药水](药水.md)**迅捷药水（Potion of Swiftness）**、[喷溅药水](喷溅药水.md)**喷溅型迅捷药水（Splash Potion of Swiftness）**、[滞留药水](滞留药水.md)**滞留型迅捷药水（Lingering Potion of Swiftness）**和[藥水箭](藥水箭.md)**迅捷之箭（Arrow of Swiftness）**。

此药水效果有对应的延长版和增强版。

# 生成
# = 不祥试炼 =
[不祥试炼刷怪笼](不祥试炼刷怪笼.md)召唤的[不祥之物生成器](不祥之物生成器.md)会投掷滞留型缓降药水，并生成对应的[区域效果云](区域效果云.md)。

# = 礼物 =

[制箭师](制箭师.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷迅捷之箭。

# = 自然生成 =

[沼泽小屋](沼泽小屋.md)的[炼药锅](炼药锅.md)内可能装有迅捷药水。

# = 箱子战利品 =

# = 炼药锅 =

对装有迅捷药水的炼药锅使用[玻璃瓶](玻璃瓶.md)可获得迅捷药水、喷溅型迅捷药水或滞留型迅捷药水，具体形式取决于炼药锅内容物。

对装有迅捷药水的炼药锅使用[箭](箭.md)可获取迅捷之箭，最大数量随内容物水位增加依次为16、32和64。
