# 更改（实验性）
# = 方块 =
* *[铜灯](铜灯.md)**
* 移除了1游戏刻的延迟。

* *[铜格栅](铜格栅.md)**
* 现在可以含水。
* * 和含水的[红树根](红树根.md)一样，水不会从方块的任何一面流出。

* *[合成器](合成器.md)**
* 更改了纹理。
* 现在其输出物品的频率与[发射器](发射器.md)、[投掷器](投掷器.md)相同。

* *[凝灰岩砖](凝灰岩砖.md)及其对应的[台阶](台阶.md)、[楼梯](楼梯.md)和[墙](墙.md)**
* 更改了纹理。

# = 游戏内容 =
* *[进度](进度.md)**
* 现在可通过击杀[旋风人](旋风人.md)获得“”进度。
* 将旋风人加入到“”进度的达成要求中。
