# 音乐唱片blocks

*页面ID: 156534* | *来源: Minecraft Wiki*

* *blocks**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的同名曲目。

# 获取
# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片blocks。

# 用途
# = 音乐 =

[noicon](File:blocks.ogg.md)

Blocks是一首欢快的芯片音乐风格乐曲，伴有舒缓的华尔兹节奏，游戏内时长为5分45秒。

# = 红石 =

音乐唱片blocks放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为3的信号。
