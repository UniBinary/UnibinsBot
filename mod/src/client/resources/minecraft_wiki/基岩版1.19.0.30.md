# 基岩版1.19.0.30

*页面ID: 95937* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.0.30**（Xbox/Windows/Android）、**Preview 1.19.0.31**（iOS/iPadOS/Windows）、**Preview 1.19.0.65**（Xbox）是[基岩版1.19.0](基岩版1.19.0.md)的第5个测试版，发布于2022年5月4日<ref></ref>，加入了一些新[成就](成就.md)，调整了一些特性，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[成就](成就.md)**
* 加入了4个新成就。
* * “蔓延”——杀死催化剂旁的生物（10G）
* * “生日歌”——让小安粒在音符盒上掉落蛋糕（10G）
* * “我们的力量结合起来！”——将所有3只青蛙灯都放在您的物品栏中（30G）
* * “潜行 100”——潜行到潜声传感器旁边，不要触发它（10G）

# 更改
# = 方块 =
* *[幽匿感测体](幽匿感测体.md)**
* 现在能够检测使用[锄](锄.md)耕作和[船](船.md)移动产生的振动。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 现在可以使用[红树胎生苗](红树胎生苗.md)来繁殖。
* 现在会在红树胎生苗中采蜜。

* *[青蛙](青蛙.md)**
* 现在被玩家杀死后会掉落经验。

* *[末影人](末影人.md)、[猪灵](猪灵.md)和[凋灵骷髅](凋灵骷髅.md)**
* 现在在[下界](下界.md)生成时要求的亮度等级范围扩大为0-10。

* *[骷髅](骷髅.md)**
* 现在在[灵魂沙峡谷](灵魂沙峡谷.md)生成时要求的亮度等级范围扩大为0-7。
* 现在在[下界要塞](下界要塞.md)生成时要求的亮度等级范围扩大为0-10。

* *[监守者](监守者.md)**
* 现在会每隔6秒给予玩家一次[黑暗](黑暗.md)效果，而不是不断施加黑暗效果。

# = 非生物实体 =
* *[运输船](运输船.md)、[运输矿车](运输矿车.md)、[TNT矿车](TNT矿车.md)和[漏斗矿车](漏斗矿车.md)**
* 现在它们被破坏时会掉落其自身。

# = 游戏内容 =
* *[粒子](粒子.md)**
* 更新了粒子的纹理。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“旁观模式”和“应用测试框架”子选项后才可使用。

# = 游戏内容 =
* *[旁观模式](旁观模式.md)**
* 为旁观模式加入了自定义按键映射功能。
* 现在旁观模式玩家无法做出以下操作：
* * 攻击
* * 建造
* * 丢弃物品
* * 使用物品
* * 打开[物品栏](物品栏.md)
* * 通过控制与世界交互
* * 与[箱子](箱子.md)或其他容器交互
* 玩家在地面上进入旁观模式时，其飞行不再会变得缓慢。
* 现在玩家在进入旁观模式时会获得穿墙和飞行的能力。
* 现在玩家进入旁观模式时，骑行、物品使用、睡觉和使用[鞘翅](鞘翅.md)滑翔的操作会相应停止。
* 双击跳跃键不再会破坏旁观模式。

# = 技术性 =
* *GameTest框架**
* GameTest模块类别由更改为中的。
* 加入了一个可选特性。
* * 目前仅有一个受支持的值。
* 中新的JavaScript模块的格式如下：
   <syntaxhighlight lang="json">
  "modules": [
    {
      "description": "JavaScript模块代码",
      "language": "javascript",
      "type": "script",
      "uuid": "<UUID>",
      "version": [0, 0, 1],
      "entry": "scripts/main.js"
    }
  ],
</syntaxhighlight>
* 命令
* * 加入了命令，用于创建GameTest脚本性能跟踪。脚本配置文件应被写入Minecraft日志记录文件夹中。
* 移除了的GameTest结构中的最大行程距离限制。

# 修复
* *辅助功能**
* 现在提交反馈按钮会被文本转语音称作一个链接。
* “控制器连接丢失”窗口现在也会在主菜单屏幕显示。

* *悦灵**
* 被拴住的悦灵在试图飞向较远处物品时不再会停止移动。

* *远古城市**
* 远古城市不再会经常被水或熔岩淹没。（）
* 在水中拥有黑暗效果时不再会在光源附近产生彩色的跃动线。（）
* 黑暗效果不再会突然淡入。（）
* 破坏激活中的幽匿尖啸体不再会阻止监守者生成。（）
* 远古城市中不再会生成周围带有幽匿脉络的结构空位。（）
* 现在远古城市的主要结构中央下方的陷阱机制变种可以正常运作。（）
* 幽匿尖啸体现在又可以含水了。

* *监守者**
* 监守者现在会每隔6秒给予一次黑暗效果。
* 监守者现在不会被经验球激怒或将其锁定为目标。（）
* 监守者现在不会攻击非生物实体，如三叉戟。
* 监守者现在能够检测幽匿尖啸体在尖啸时产生的振动。
* 监守者现在倾向于在嗅探后寻找最近生物的位置。
* 监守者现在不会在被攻击后激怒时播放愤怒察觉的音效。
* 现在监守者的心跳会反映监守者对目标的愤怒等级或最高的愤怒等级。
* 修复了监守者从地面钻出时会小幅度跳跃的问题。（）

* *幽匿感测体**
* 幽匿感测体现在能够正确检测将海龟蛋和台阶放置在相应方块上时产生的振动。（）
* 幽匿感测体现在会在其顶部存在实体时反复激活。（）
* 弹射物击中羊毛或羊毛地毯时不再会产生振动。
* 玩家看向已驯服的动物时不再会产生振动。
* 玩家潜行并使用副手槽中的盾牌时不再会产生振动。（）
* 幽匿感测体现在能够检测使用锄耕耘泥土、砂土或缠根泥土时产生的振动。（）
* 幽匿感测体现在能够检测船移动产生的振动。
* 幽匿感测体现在能够检测气泡柱上方的船溅起水花产生的振动。
* 幽匿感测体现在能够检测使用水瓶与泥土、砂土或缠根泥土交互转变泥巴时产生的振动。（）
* 幽匿感测体现在又可以含水了。
* 现在幽匿感测体的下表面能够为其他方块提供支撑。
* 玩家在幽匿感测体上潜行时，其他幽匿感测体不再能够一同被激活。

* *红树**
* 调整了红树胎生苗的生长速度以匹配Java版。（）
* 蜜蜂现在可以对红树胎生苗采集花粉。（）
* 现在可以使用去皮红树原木来合成红树木板。（）
* 红树木类方块现在位于其他主世界木质类方块旁边。（）
* 红树根在创造模式物品栏中不再位于“树木”物品组中。
* 更改了红树木在地图上的颜色以匹配Java版。（）
* 更改了红树原木和去皮原木在地图上的颜色以匹配Java版。（）
* 红树根现在是可被点燃的。（）

* *泥巴**
* 现在受重力影响的方块下落在泥巴上时会被破坏。（）
* 现在将泥土转变为泥巴时会播放溅射音效。（）
* 在创造模式物品栏中，现在泥巴位于泥土旁边。（）
* 现在将两个泥砖台阶叠放成一个完整方块时会播放音效。（）

* *青蛙**
* 青蛙现在会像牛和山羊等动物一样掉落经验。（）
* 青蛙卵不再受随机刻速度影响。
* 提高了蝌蚪受伤音效的音量，且蝌蚪现在拥有长成青蛙的音效。（）

* *游戏内容**
* 提高了末影人、猪灵、骷髅和凋灵骷髅在下界生成所需的光照等级范围（由0提高至10）。
* 火把不再可以放置在钟上。

* *图形**
* 修复了拴绳会渲染在玻璃顶部的漏洞。（）
* 撤销了对狼模型中生物部分的镜像处理。

* *物品**
* 现在运输船被摧毁后会掉落一个物品，而不是两个物品（船和箱子）。（）
* 红树根不再可以用作熔炉燃料。
* 现在各个矿车变种（运输矿车、漏斗矿车或TNT矿车）被摧毁时会掉落其自身一个物品，而不是分解为两个物品（如箱子和矿车）。

* *寻路**
* 生物不再会卡在打开的活板门中。（）

* *性能与稳定性**
* 修复了两个玩家穿戴荆棘附魔盔甲进行战斗时可能发生的崩溃。（）
* 修复了对世界中充满空气的区块进行过渡时可能发生的崩溃。
* 修复了分屏游戏过程中可能发生的崩溃。

* *技术性**
* 更新了特定字符串类别“本地化字符串”、“路径字符串”和“标识符字符串”的文档。
* 为过滤器测试加入了，以阻止生物移动至水下方块。（）
* 修复了尝试访问空实体时发生的崩溃。
* 使用“Cruise Ship Roleplay”世界模板（3P）创建世界时游戏不再会崩溃。</onlyinclude>
