# 基岩版1.17.10.20

*页面ID: 82934* | *来源: Minecraft Wiki*

</ref>}}
<onlyinclude>

* *beta 1.17.10.20**是[基岩版1.17.10](基岩版1.17.10.md)的首个测试版，发布于2021年5月26日<ref></ref>，调整了一些特性，并修复了一些漏洞。

以下更新内容基于上一测试版[1.17.0.58](基岩版1.17.0.58.md)，包含了其中已加入的[洞穴与山崖](洞穴与山崖.md)第二部分的特性。

# 更改
# = 方块 =
* *[石英块](石英块.md)、[石英台阶](石英台阶.md)、[石英楼梯](石英楼梯.md)、[工作台](工作台.md)、[磨制黑石砖](磨制黑石砖.md)、[磨制黑石砖台阶](磨制黑石砖台阶.md)、[磨制黑石砖楼梯](磨制黑石砖楼梯.md)、[磨制黑石砖墙](磨制黑石砖墙.md)、[裂纹磨制黑石砖](裂纹磨制黑石砖.md)和[幽匿感测体](幽匿感测体.md)**
* 更改了纹理以匹配。

* *[垂根](垂根.md)**
* 不再可以[含水](含水.md)。

* *[缠根泥土](缠根泥土.md)**
* 现在纹理会随机旋转，以同步普通[泥土](泥土.md)。

# = 物品 =
* *[干海带](干海带.md)、[下界合金斧](下界合金斧.md)、[下界合金靴子](下界合金靴子.md)、[下界合金锄](下界合金锄.md)、[下界合金锭](下界合金锭.md)、[下界合金镐](下界合金镐.md)和[下界合金剑](下界合金剑.md)**
* 更改了纹理以匹配。

# = 生物 =
* *[美西螈](美西螈.md)**
* 装死时不再会摆动尾巴。
* 缩小了美西螈的碰撞箱以匹配其尺寸。
* 现在给其喂食[热带鱼桶](热带鱼桶.md)后会返还水桶，而不是空桶。

* *[骷髅](骷髅.md)**
* 陷入[细雪](细雪.md)中转化为[流浪者](流浪者.md)所需的时间由45秒缩短至20秒。

# = 非生物实体 =
* *[末地水晶](末地水晶.md)**
* 更改了实体模型以匹配，现在其包含3个正方体框架而不是2个。

# = 常规 =
* *[设置](设置.md)**
* 为辅助功能设置加入了新图标。

# = 技术性 =
* *[Molang](Molang.md)**
* 加入了查询函数，用于确定实体的底部是否被渲染。
* 加入了查询函数，用于确定一个生物自死亡过后经过的时间。
* 加入了数学函数，用于将任意角度值转化至区间[-180, 180)内。

* *游戏内容**
* 若战利品箱放置在相同坐标上且Seed=0，则战利品箱中会随机生成战利品。
* * 注意：在对原版战利品箱使用选取键前，若NBT中的Seed没有设置为0，则每个副本箱子均会生成相同的战利品。

* *数据驱动生物**
* [末影龙](末影龙.md)和[末地水晶](末地水晶.md)的渲染和动画现在是完全由数据驱动的。

* *图形**
* 不再支持最大D3D11功能级别为9_3或以下的图形硬件。

* *性能与稳定性**
* 为JSON解析加入了更好的错误处理，并为物品解析和战利品表加入了若干新的内容错误。

* *活动对象**
* 新传入客户端的类型的同步属性现在会正确注册到客户端的Actor Property Manager组中。

* *GameTest框架**
* 更新了命令，现在可用于清除区域之外的测试。

# 修复
* *原版趋同**
* 调整了雷暴的出现频率以匹配Java版。（）

* *美西螈**
* 美西螈装死时不再会摆动尾巴。（）
* 缩小了美西螈的碰撞箱以匹配其尺寸。
* 现在给美西螈喂食热带鱼桶后会返还水桶，而不是空桶。（）
* 溺尸、守卫者和远古守卫者现在会主动攻击美西螈。

* *杜鹃**
* 现在放置在黏土上时也可以对杜鹃花丛骨粉。
* 现在对着杜鹃树叶或盛开的杜鹃树叶使用选取方块键会正确获得对应方块。（）

* *铜矿石**
* 在创造模式物品栏中，铜矿石现在位于其他主世界矿石之后。（）

* *深板岩**
* 在创造模式物品栏中，深板岩现在位于其他石头之后。（）

* *荧光物品展示框**
* 在创造模式物品栏中，荧光物品展示框现在位于普通物品展示框之后。（）

* *垂根**
* 垂根现在会被水流破坏。（、）

* *避雷针**
* 下落的方块下落到避雷针顶部时不再会被破坏。（）

* *缠根泥土**
* 现在纹理会随机旋转，以同步普通泥土。（）

* *角色创建器**
* 现在可以在角色创建器中预览物件和按下“装备”按钮以装备物件。
* 为角色创建器加入了装备经典皮肤和披风的按钮。

* *命令**
* 命令现在会正确清除HUD上的标题。（）

* *皮肤编辑界面**
* 个人资料界面的重新加载按钮现已本地化。

* *游戏内容**
* 修复了分屏玩家无法在铁砧上重命名物品的问题。（）

* *图形**
* 如鸡蛋和雪球等弹射物在弹射时不再会出现阴影。

* *物品**
* 现在所有掉落物拥有相似的悬浮高度。
* 现在由数据驱动的物品在未指定方块时会使手臂摆动更快。（）
* 现在通过命令获得的烟花火箭拥有飞行时间。（）
* 现在通过命令获得的烟花火箭拥有正确的颜色。（）

* *繁茂洞穴**
* 小型垂滴叶现在只能使用剪刀破坏获得。

* *骷髅**
* 骷髅陷入细雪中转化为流浪者所需的时间由45秒缩短至20秒。

* *细雪**
* 游戏规则被禁用时，着火的实体进入细雪后不再会使其融化。（）

* *用户界面**
* 现在快捷栏工具提示的显示时间会根据工具提示文本的长度而调整。</onlyinclude>
