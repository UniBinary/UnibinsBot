# 马铃薯削皮刀

*页面ID: 143834* | *来源: Minecraft Wiki*

* *马铃薯削皮刀（Potato Peeler）**是一种可以削下[马铃薯皮](马铃薯皮.md)的[工具](工具.md)和[武器](武器.md)。

# 用途
在[创造模式](创造模式.md)中，马铃薯削皮刀虽然能够挖掘方块，但无法破坏方块，挖掘方块时也不会发出声音。

# = 近战攻击 =
马铃薯削皮刀的攻击速度是5，需要来[恢复](近战攻击#攻击冷却.md)。

# == 对马铃薯生物 ==

# = 削皮 =
以下生物的[毒马铃薯变种](马铃薯生物.md)被马铃薯削皮刀杀死时会额外掉落：

对马铃薯绵羊马铃薯削皮刀可以削下1-3个对应颜色的马铃薯皮，未被削皮的马铃薯绵羊死亡时总会掉落1个对应颜色的马铃薯皮。

对除马铃薯绵羊外，装备[毒马铃薯胸甲](毒马铃薯胸甲.md)的生物马铃薯削皮刀可以削下8个马铃薯皮。

对方块马铃薯削皮刀可以对方块削皮。若转化目标方块不是空气，掉落物会掉落在使用的一面。以下方块可以通过马铃薯削皮刀削皮：
* 对[腐败的薯皮草方块](腐败的薯皮草方块.md)的顶面使用可以削下1个[腐败的马铃薯皮](腐败的马铃薯皮.md)，并将其转化为[马铃薯泥土](马铃薯泥土.md)。
* 对[薯皮草方块](薯皮草方块.md)顶面使用可以削下1个[黄绿色马铃薯皮](黄绿色马铃薯皮.md)，并将其转化为马铃薯泥土。
* 对[马铃薯皮方块](马铃薯皮方块.md)使用可以削下9个对应颜色的马铃薯皮，并移除方块。
* 对[毒马铃薯方块](毒马铃薯方块.md)使用可以削下9个[毒马铃薯](毒马铃薯/24w14potato.md)，并将其转化为马铃薯皮方块。
