# 圆石楼梯

*页面ID: 20005* | *来源: Minecraft Wiki*

* *圆石楼梯（Cobblestone Stairs）**是[圆石](圆石.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
圆石楼梯会自然生成于[掠夺者前哨站](掠夺者前哨站.md)、[要塞](要塞.md)、[林地府邸](林地府邸.md)、[丛林神庙](丛林神庙.md)以及平原、针叶林和积雪针叶林[村庄](村庄.md)。

# 破坏
挖掘圆石楼梯的合适工具是镐。圆石楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

圆石楼梯被破坏后会掉落自身。
