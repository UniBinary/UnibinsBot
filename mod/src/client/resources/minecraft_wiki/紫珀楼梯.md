# 紫珀楼梯

*页面ID: 44293* | *来源: Minecraft Wiki*

* *紫珀楼梯（Purpur Stairs）**是[紫珀块](紫珀块.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
紫珀楼梯会自然生成在[末地城](末地城.md)。

# 获取
# = 合成 =
可以混合使用任意紫珀块合成，只能使用单种方块合成。

# 破坏
挖掘紫珀楼梯的合适工具是镐。紫珀楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

紫珀楼梯被破坏后会掉落自身。
