# 红砖块

*页面ID: 5782* | *来源: Minecraft Wiki*

* *红砖块（Bricks）**是一种装饰用的建筑方块。

# 生成
# = 自然生成 =
红砖块会在[海底废墟](海底废墟.md)、[古迹废墟](古迹废墟.md)以及平原[村庄](村庄.md)的[盔甲匠房屋](村庄/结构/图示/平原盔甲匠房屋.md)里生成。

# 破坏
挖掘红砖块的合适工具是镐。红砖块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

红砖块被破坏后会掉落自身。

# 用途
红砖块有着与石类方块相同的爆炸抗性，所以可用作长久的建筑方块。
