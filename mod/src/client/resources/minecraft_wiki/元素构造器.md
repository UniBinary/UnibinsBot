# 元素构造器

*页面ID: 34276* | *来源: Minecraft Wiki*

* *元素构造器（Element Constructor）**是在[化学](化学.md)中使用的[方块](方块.md)。它允许玩家通过调整质子、电子和中子的数量来构造[元素](元素.md)。

# 生成
元素构造器不会生成在世界中。

# 获取
元素构造器不能在生存模式中正常获得，但可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)获得。

# 破坏
挖掘元素构造器的合适工具是镐。

元素构造器被破坏后会掉落自身。

# 用途
# = 信息 =

元素构造器会打开一个界面，带有一个大显示器和三个可调节的质子、中子和电子数量滑块，滑块旁有可选的文本输入框。滑块条上面标着粒子类型和它的带电状态。通过移动滑块或在文本输入框中键入数字，大显示器将显示所选的粒子数。在右面的显示屏里会显示出对应的卢瑟福原子结构模型。

构造完成的元素和同位素可以从元素显示器右侧的输出栏中移出。此外，物品栏中的元素可以插入输出栏，来查看它质子、电子和中子的数量。元素构造器有118种元素和400种同位素可供构造。

元素构造器不能输出未知元素，未知元素也不能放入元素构造器中。

当元素构造器顶部着火时，其将无法使用。

# 你知道吗
* 元素构造器界面右边的原子模型是卢瑟福原子结构模型，这是已经被化学界否认的模型，但其结构直观，不失其意义。
* 在元素构造器界面的原子模型中，部分原子的电子填充的轨道与实际不符。
