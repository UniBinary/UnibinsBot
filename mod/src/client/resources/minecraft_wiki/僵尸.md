* *僵尸（Zombie）**是一种常见的[亡灵](亡灵.md)敌对生物，具有多个变种。

# 生成
# = 自然生成 =
僵尸会在[主世界](主世界.md)中[内部天空光照](亮度#内部天空光照.md)小于或等于7，且[方块光照](亮度#方块光照.md)为0的[可生成位置](生成#可生成位置.md)上生成，[蘑菇岛](蘑菇岛.md)和[深暗之域](深暗之域.md)除外。僵尸不会在[河流](河流.md)、[冻河](冻河.md)和[雪原](雪原.md)单独生成。<ref></ref><ref></ref>

在[沙漠](沙漠.md)生物群系，所有暴露在天空下生成的僵尸都有或的概率生成为[尸壳](尸壳.md)；未暴露在天空下生成的僵尸也会以相同的概率尝试生成为尸壳，但该部分会生成失败，导致既不生成僵尸也不生成尸壳。不是尸壳的僵尸有5%概率生成为[僵尸村民](僵尸村民.md)。而所有的僵尸及变种也有5%的概率生成为其幼年变体。

僵尸会作为[僵尸马](僵尸马.md)的乘客自然生成于[热带草原](热带草原.md)、[热带高原](热带高原.md)、[风袭热带草原](风袭热带草原.md)、[平原](平原.md)和[雪原](雪原.md)生物群系中。

# = 僵尸围城 =

如果玩家夜晚处于一个[村庄](村庄.md)中，村庄周围可能会生成多达20只僵尸。僵尸围城可以发生在所有[生物群系](生物群系.md)中（包括[蘑菇岛](蘑菇岛.md)<ref></ref>）。[溺尸](溺尸.md)、[尸壳](尸壳.md)、[僵尸村民](僵尸村民.md)和[僵尸猪灵](僵尸猪灵.md)不会在僵尸围城中生成。

# = 刷怪笼 =
[地牢](地牢.md)里面的[刷怪笼](刷怪笼.md)有50%的概率为僵尸刷怪笼。

# = 试炼刷怪笼 =
[试炼密室](试炼密室.md)中的近战型[试炼刷怪笼](试炼刷怪笼.md)包含僵尸试炼刷怪笼，小型近战型试炼刷怪笼包含幼年僵尸刷怪笼。

# = 转化 =
[尸壳](尸壳.md)在水里超过时，会开始转化为僵尸，再经转化完成。

# = 增援 =

在困难[难度](难度.md)下，僵尸受到攻击时可能会生成增援僵尸，详见。

# 变种
# = 幼年僵尸 =
[缩略图|一只幼年僵尸](File:Baby zombie.png.md)
[缩略图|一个带有盔甲的[[鸡骑士](File:BabyZombieRidingChicken.png.md)]]

僵尸有5%的概率以幼年形态生成，幼年僵尸的行为与成年僵尸略有不同：

* 移动速度比普通僵尸快50%，但生命值与之相同。
* 叫声的音调比普通僵尸高。
* 穿戴的盔甲会缩小以适应身体尺寸。
* 有缩小的碰撞箱，可以穿过1×1格的空间。
* 永远不会成长为成年僵尸。

幼年僵尸有5%的概率会在附近的[鸡](鸡.md)上生成成为[鸡骑士](鸡骑士.md)（如果附近没有鸡则生成失败），还有4.75%的概率附带一只[鸡](鸡.md)生成成为[鸡骑士](鸡骑士.md)。

# = 僵尸村民 =

僵尸在生成时有5%概率以僵尸村民的形态生成。被僵尸杀死的[村民](村民.md)也会有概率变成僵尸村民（困难难度下为100%，普通难度为50%，简单难度为0%）。可以使用投掷喷溅型虚弱药水并喂食金苹果的方式治愈僵尸村民。僵尸村民在[平原](平原.md)生物群系生成的概率比高（10%）。

# = 尸壳 =

尸壳在[沙漠](沙漠.md)生物群系中有或的概率取代僵尸而生成。它们会像普通僵尸一样攻击，被尸壳攻击的玩家会受到或的[饥饿](饥饿.md)效果，且尸壳在日光下不会燃烧。

# = 溺尸 =

溺尸生成于[海洋](海洋.md)、[河流](河流.md)生物群系中。僵尸头部浸泡在水中后也会转化为溺尸。溺尸可以在水中游泳、呼吸并在水底和陆地上行走。大多数溺尸使用近战攻击，而一些携带三叉戟的溺尸能够手持[三叉戟](三叉戟.md)进行远程攻击。

# = 僵尸猪灵 =

僵尸猪灵可在下界的[下界荒地](下界荒地.md)、[绯红森林](绯红森林.md)或主世界的[下界传送门](下界传送门.md)中自然生成，亦可由[猪](猪.md)被闪电劈中或[猪灵](猪灵.md)和[猪灵蛮兵](猪灵蛮兵.md)在下界以外的维度中转化而生成。

# 行为
# = 攻击 =
[thumb|为了攻击村民，僵尸试图摧毁门而非绕道而行](File:zombie ways.png.md)

僵尸会尝试避开障碍，悬崖以及熔岩，并且会尝试找到到达攻击目标所处位置的最短路径。<ref></ref>僵尸在受到其他生物攻击后会改变一次攻击目标，之后不会再转移目标，唯一能让这个次数的方法是让僵尸重新进入追逐阶段（离开僵尸视线后再次被僵尸追逐）。<ref></ref>

僵尸会主动攻击视线范围或<ref></ref>格内的玩家、[铁傀儡](铁傀儡.md)、、[村民](村民.md)、[流浪商人](流浪商人.md)和幼年[海龟](海龟.md)。优先级从低到高为最近的幼年海龟、最近的村民、流浪商人或铁傀儡、、最近的玩家、攻击它的生物。

玩家头戴[僵尸的头](僵尸的头.md)时，僵尸的追踪范围会缩小至正常距离的一半（17.5格）。

僵尸会主动寻找垂直距离3格、水平[切比雪夫距离](切比雪夫距离.md)24格以内的[海龟蛋](海龟蛋.md)，然后在海龟蛋上跳跃，直到把海龟蛋踩碎。

如果一个僵尸被其他生物攻击，附近没有目标的僵尸会对该生物产生敌意。

着火的僵尸在攻击生物时，可能会使受到攻击的生物着火，概率为（[区域难度](区域难度.md)×30）%，持续时间为（[区域难度](区域难度.md)向下取整×2）秒。如果僵尸的盔甲附有[荆棘](荆棘.md)魔咒，玩家在攻击僵尸时会因受到荆棘伤害而着火。着火的僵尸在普通或困难难度下总会使受到攻击的生物着火，持续时间为2秒。如果僵尸手持物品，受到攻击的生物将不会着火。

# = 生物族群 =

僵尸是亡灵生物，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉直到接触水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

僵尸会在阳光下[着火](着火.md)，除非它们的头盔栏中拥有物品。

# = 破门 =
在困难难度下，追逐目标的僵尸会**专注于**攻击关闭的[木门](木门.md)或[铜门](铜门.md)。僵尸有或的概率可以成功破门。否则，门只会出现裂纹，而不被破坏。僵尸不能破坏[铁门](铁门.md)。被破坏的门会产生掉落物，则不会。

# = 捡起物品 =
当设置为<code>true</code>时，一些僵尸具备捡起掉落物的能力，且捡起物品后的僵尸不再会自然消失。捡起物品的概率与[区域难度](区域难度.md)有关，每只僵尸有（副区域难度×55）%的概率捡起物品。

如果这些物品是[盔甲](盔甲.md)、[雕刻南瓜](雕刻南瓜.md)、[生物头颅](生物头颅.md)、[鞘翅](鞘翅.md)或[盾牌](盾牌.md)，僵尸会直接穿戴在身上。如果这些物品是近战[武器](武器.md)或[工具](工具.md)，僵尸会使用这些物品。

如果僵尸再次遇到这些物品，且符合以下条件其一时，它们会捡起并替换身上的物品：
* 如果新物品是盔甲或工具/近战武器，而旧物品不是（例如，比起[弓](弓.md)和[雕刻南瓜](雕刻南瓜.md)，僵尸更喜欢[剑](剑.md)和[头盔](头盔.md)）；
* 如果新旧物品都是盔甲或工具/近战武器，但新物品的盔甲值或基础攻击伤害加成更高（比起锋利V的钻石剑，僵尸更喜欢石斧，虽然前者的实际攻击伤害加成更高，但是石斧的基础攻击伤害加成高于钻石剑）；
* 如果两件物品都是具有相同盔甲值的盔甲或相同基础攻击伤害加成的工具/近战武器，但新物品具有更高等级的[魔咒](魔咒.md)或更多的[耐久](耐久.md)。

僵尸用捡起的新物品替换生成时携带的原有物品时，丢弃原有物品的概率与使用抢夺I杀死僵尸时掉落原有物品的概率相同，且掉落的物品一定是满耐久度的；若原有物品为后来捡起的物品，则掉落概率为100%。无论是生成时携带的还是后来捡起的物品，在替换时掉落概率均为100%。

被僵尸替换下而掉落的物品在内无法被玩家捡起，但可以被漏斗收集。

僵尸不会捡起[荧光墨囊](荧光墨囊.md)。鸡骑士不会捡起[鸡蛋](鸡蛋.md)。鸡骑士可以捡起蓝色鸡蛋和棕色鸡蛋。

# = 增援 =

在所有难度中，受到伤害的僵尸会召唤其他以它为中心67×21×67到111×21×111区域内的僵尸<ref group="注">范围半径取决于<code>follow_range</code>属性：基本值为35，随机奖励±5%，然后随机加上0-50%的僵尸生成奖励。</ref>攻击玩家，即使被召唤的僵尸没有看见玩家。

在困难难度下且[游戏规则](游戏规则.md)为<code>true</code>时，受到伤害的僵尸会生成一些额外的僵尸前来“增援”，作为“增援”生成的僵尸会具有相同的种类或其幼年变种（例如，[僵尸村民](僵尸村民.md)生成的增援僵尸只能是僵尸村民）。每一只僵尸都有，该属性的取值范围是0-0.1。“领头”僵尸（见下文）会向这个属性加成0.5-0.75。当僵尸被一个实体伤害，或在选定某个实体作为目标后受伤，僵尸最多会尝试随机选择生成增援僵尸的位置50次（三个方向轴上0或±7-40米外），生成位置需要是固体方块的上表面，亮度等级小于等于9，7米内没有玩家，且没有任何可碰撞的实体和方块阻碍增援的生成。呼-{}-叫增援的僵尸和前来增援的僵尸都会在属性中给予约-0.05的惩罚，从而降低无限生成增援僵尸的概率。

“领头”僵尸是一种特殊的僵尸，它有至多5%的概率生成，具体取决于[区域难度](区域难度.md)。“领头”僵尸对属性有0.5-0.75的的加成。“领头”僵尸的最大生命值是之间的均匀分布随机数，<ref name="healthbug"/>|JE 26.1}}。“领头”僵尸在困难难度破门时一定能成功。

“增援”的生成不受[生物上限](生物上限.md)的限制。

# = 转化 =
如果僵尸头部保持浸泡于水中超过，它将开始转化成[溺尸](溺尸.md)。一旦开始转化，它会像[僵尸村民](僵尸村民.md)被治愈时一样颤抖，后它就会变为溺尸，转化形成的溺尸的生命值会回满，生物对僵尸产生的敌意在其转化后会立刻解除。若转化过程被中断则会重新开始计时。

僵尸转化成溺尸后将保留身上穿着的盔甲和手持的物品；僵尸手持或穿戴着的所有物品都会掉落，但转化成的溺尸也能将掉落的物品重新捡起。

只有僵尸会转化为溺尸，僵尸村民和僵尸猪灵无法进行转化。<ref></ref>但待在水下的尸壳会先转化为僵尸，再花费一段时间转化为溺尸。

# 你知道吗
* 僵尸有着与Steve相似的纹理。
* * 在[Java版1.19.3](Java版1.19.3.md)（[22w45a](22w45a.md)）和[基岩版1.19.50.21](基岩版1.19.50.21.md)前，Steve和僵尸穿着完全一致的服装，并拥有相同的皮肤图案。
* 僵尸、[骷髅](骷髅.md)和[苦力怕](苦力怕.md)是游戏中加入时间最早的且未被移除的敌对性生物。
* 成年僵尸试炼刷怪笼中依然可能生成幼年僵尸和僵尸鸡骑士，而幼年僵尸试炼刷怪笼中只能生成幼年僵尸，不会生成鸡骑士，即使在该区域引入了鸡。普通试炼刷怪笼生成的幼年僵尸也不会持有盔甲和武器。
* 僵尸穿上盔甲的顺序是按照“头盔—胸甲—护腿—靴子”的顺序来生成的。比如一个生成时穿着护腿的僵尸就一定穿戴了头盔和胸甲。
