# Java版16w50a

*页面ID: 26726* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w50a**是[Java版1.11.1](Java版1.11.1.md)的唯一一个快照，发布于2016年12月15日<ref name="blogpost_16w50a"></ref>，加入了铁粒以及横扫之刃魔咒，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[铁粒](铁粒.md)**
* 可由[铁锭](铁锭.md)分解而成，也可以通过烧炼铁质工具和铁盔甲获得。
* 可以合成[铁锭](铁锭.md)。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 加入了[横扫之刃](横扫之刃.md)魔咒。
* * 会增加剑类武器的横扫伤害。
* * 3级魔咒会使横扫伤害和普通伤害相同。

# 更改
# = 方块 =
* *[熔炉](熔炉.md)**
* 铁和金质工具和装备可以被熔化成[铁粒](铁粒.md)和金粒。铁[马铠](马铠.md)和金马铠也可以被熔化。
* * 每融化一个物品可以得到1个铁粒或金粒。
* 更改烧炼物品时间。

* *[活塞](活塞.md)**
* 为<code>piston_extension</code>方块加入了新的标签<code>source</code>，设置为时方块体现为活塞头，时体现为推出的方块。

# = 物品 =
* *[箭](箭.md)**
* 为实体加入了新的<code>Color</code>标签，用于为带有<code>CustomPotionColor</code>标签的射出的箭实体显示自定义的药水颜色。

* *[烟花火箭](烟花火箭.md)**
* 当使用[鞘翅](鞘翅.md)飞行时，使用烟花火箭会推进玩家。
* * 追踪玩家直到消失或者爆炸。
* * 延长了烟花火箭的飞行时间，使其持续飞行时间变长。
* * 即使是在空中烟花爆炸也会造成伤害。
* * 在方块上使用烟花火箭的动作优先于空中右击功能。这意味着飞行时，玩家看着一个方块使用烟花火箭将使烟花火箭正常发射，而不是用于推进。
* 烟花的爆炸会对周围的[实体](实体.md)造成伤害。
* * 爆炸伤害的半径约为2-3个方块，并且以任何形状爆炸的伤害都一样（像恶魂火球、苦力怕爆炸等等）。不管爆炸半径是多少，在其内的实体受到的伤害都一样。
* * 没有穿戴任何盔甲时受到的伤害，穿全套钻石[盔甲](盔甲.md)的话，则是颗心。
* * 死亡消息是：<玩家>随着一声巨响消失了。

* *[不死图腾](不死图腾.md)**
* 物品ID由<code>totem</code>改为<code>totem_of_undying</code>。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 在生存模式或使用命令时弓的经验修补不再与无限魔咒兼容。
* * 然而在本快照中，玩家仍然可以把经验修补加到具有无限的[弓](弓.md)上，但是反过来不行。
* * 对已有的拥有两种魔咒的弓，两个魔咒依然同时生效。

# = 常规 =
* *[攻击指示器](攻击指示器.md)**
* 在十字光标模式下，攻击完全冷却后，并且怪物/实体在攻击距离内时，攻击指示器会出现且包括一个感叹号。

* *[统计](统计.md)**
* 移除了“钓垃圾”与“钓宝藏”统计信息。
