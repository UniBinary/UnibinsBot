# Java版1.21.3

*页面ID: 127985* | *来源: Minecraft Wiki*

* *1.21.3**是的一次热修复更新，发布于2024年10月23日<ref></ref>，修复了一些漏洞。此版本不兼容1.21到1.21.1的服务端，兼容1.21.2的服务端。

从旧版本升级到此版本的[鲑鱼](鲑鱼.md)或从1.21.2升级到此版本的小型鲑鱼都将变为中型鲑鱼。
