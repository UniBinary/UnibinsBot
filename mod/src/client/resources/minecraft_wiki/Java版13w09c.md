# Java版13w09c

*页面ID: 33499* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w09c**是[Java版1.5](Java版1.5.md)的第13个快照，发布于2013年3月1日<ref></ref>，加入了1种新的玩家<code>NBT</code>标签，发布以修复[13w09a](13w09a.md)和[13w09b](13w09b.md)里的漏洞和崩溃。

# 新内容
# = 游戏内容 =
* *[NBT标签](NBT标签.md)**
* 为玩家加入了<code>SeeFriendlyInvisibles</code>NBT标签。

# 更改
# = 物品 =
* *[药水](药水.md)**
* 所有药水在创造模式中现在按类型排列。

# = 命令格式 =
* ***
* 倍数值不再有4的上限。
* 可以使用移除效果。
