# 山地

*页面ID: 36444* | *来源: Minecraft Wiki*

[thumb|320px|草甸、雪林、积雪山坡、尖峭山峰与冰封山峰共同组成了一片大型山地](File:1.17 new mountains.png.md)

* *山地（Mountains）**是一类高海拔的[生物群系](生物群系.md)。

# 描述
山地类生物群系包含草甸、樱花树林、雪林、积雪山坡、尖峭山峰、冰封山峰和裸岩山峰，彼此差异较为明显。[掠夺者前哨站](掠夺者前哨站.md)会在所有的山地生物群系中生成，草甸中也会生成[村庄](村庄.md)，积雪山坡也会生成[雪屋](雪屋.md)。[山羊](山羊.md)也会在部分山地生物群系中生成。类似于[风袭丘陵](风袭丘陵.md)，[绿宝石矿石](绿宝石矿石.md)和[虫蚀石头](虫蚀石头.md)会在山地取代一些石头生成，并且[煤矿石](煤矿石.md)和[铁矿石](铁矿石.md)会在海拔较高处的山峰普遍生成。

# 种类
# = 山坡 =
这类生物群系常生成于山坡地带，是非山地类生物群系向山峰地带的过渡生物群系。

# == 草甸 ==

* *草甸（Meadow）**是一种繁花似锦的山地类生物群系，以地表大量生成的花为特征。在这里生成的树总是带有[蜂巢](蜂巢（方块）.md)。

# == 樱花树林 ==

* *樱花树林（Cherry Grove）**是一种花团锦簇的山地类生物群系，[樱花树](樱花树.md)在此大量生成。

# == 雪林 ==

* *雪林（Grove）**是一种繁茂的山地类生物群系，地表被雪覆盖，以[云杉](云杉.md)为主要树木，远看类似于[积雪针叶林](积雪针叶林.md)。

# == 积雪山坡 ==

* *积雪山坡（Snowy Slopes）**是一种覆雪的山地类生物群系，地表会被雪、雪块和细雪覆盖。

# = 山峰 =
这类生物群系常生成于山峰地带，是Minecraft中海拔最高的一族生物群系。

# == 尖峭山峰 ==

* *尖峭山峰（Jagged Peaks）**是组成山地顶峰的山地类生物群系，该生物群系表面被雪和雪块覆盖。

# == 冰封山峰 ==

* *冰封山峰（Frozen Peaks）**是组成山地顶峰的覆雪的山地类生物群系，其山势比尖峭山峰更平缓，山峰顶部会出现[冰](冰.md)和条带状的[浮冰](浮冰.md)。

# == 裸岩山峰 ==

* *裸岩山峰（Stony Peaks）**是组成山地顶峰的温暖的山地类生物群系，其地表未覆雪，还会裸露出[石头](石头.md)和条带状的[方解石](方解石.md)。
