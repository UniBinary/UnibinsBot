# 含水

*页面ID: 36050* | *来源: Minecraft Wiki*

[150px|thumb|含水的[[橡木栅栏](File:Waterlogged Oak Fence.png.md)]]
方块的**含水（Waterlogged）**状态是指[水源](水源.md)方块填充了不完整方块（即未完全充满其方块体积的方块，如门、梯子和植物）未充满体积的部分。

# 机制
特定的方块具有方块状态，该方块状态可以为或，可以通过[调试棒](调试棒.md)调整；少数方块如[海草](海草.md)、[海带](海带.md)、[气泡柱](气泡柱.md)总是含水的。这只是一个临时性解决方案，完全实现方块和液体的区分仍在计划中。<ref></ref>

当可被[活塞](活塞.md)推动的含水方块未能在2[游戏刻](游戏刻.md)内提前到位时，方块的含水状态将被消除，否则方块将可以保留含水状态。

几乎所有不完整方块都能含水。含水由游戏的“图层”系统处理，通过修改，任何方块都能含水。只有流动的水可以被直接替换。

含水的不完整方块和水源方块占据相同体积。破坏含水方块不会对水源方块造成影响。

所有含水方块都具有水源方块的大部分特性，且会覆盖这些方块原有的部分特性（例如，原本可燃烧的方块在含水后变得不可燃烧）。含水方块不会结[冰](冰.md)。含水方块能将[熔岩](熔岩.md)转变为[黑曜石](黑曜石.md)或[圆石](圆石.md)，而熔岩不会将含水方块转变为石头。可以通过含水方块向玻璃瓶中装水。<ref></ref>

若一个未含水的可含水方块在**水平**方向上紧挨着2个或更多个水方块或可以向这个方向流出水的含水方块（液相被该可含水方块的表面完全阻挡的**除外**，例如下半[台阶](台阶.md)的表面完全阻挡水平毗邻的含水上半台阶的液相。流动水一律视为**完整**的水方块），其中**2个或更多个**为**水源**或**含水方块**，且该可含水方块下方有一个[固体方块](固体方块.md)、另一个水源方块或含水非固体方块，并且[游戏规则](游戏规则.md)为<samp>true</samp>，则满足上述要求（即液相未被阻挡）的水（可以是流动水）或含水方块计算流动方向时会将该可含水方块纳入流动范围，若决定向该方块流动，该方块将含水。

# 行为

下表展示了不同方块在不同版本中的含水情况。图例：
* <span class="tc-no">红色</span>背景表示此方块不能放置在水中或被放置在水中后会移除所在格的水，标记“掉落”的还会被流动的水摧毁，其中可以掉落的方块会在被破坏时变成[掉落物](掉落物.md)。
* <span class="tc-partial">黄色</span>背景表示此方块必须放在水中。
* <span class="tc-yes">绿色</span>背景表示此方块可以放在流动的水或水源中。
* <span class="tc-planned">蓝色</span>背景表示此方块可以放在水源中。

可在获取Java版中含水机制的更多信息。
