# Java版1.7.10-pre4

*页面ID: 33616* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.7.10-pre4**是[Java版1.7.10](Java版1.7.10.md)的第4个，也是最后一个预发布版，发布于2014年6月18日<ref></ref>，以提供更多[Realms](Realms.md)的功能。

# 新内容
# = 常规 =
* *[Realms](Realms.md)**
* 允许将存档上传至Realms。
* 加入了允许Realms的拥有者启用[命令方块](命令方块.md)的选项。

# 修复

* *其他漏洞**
* 修复一些关于未来版本兼容性的问题。</onlyinclude>
