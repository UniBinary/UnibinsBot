# Java版17w15a

*页面ID: 29040* | *来源: Minecraft Wiki*

<onlyinclude>

* *17w15a**是[Java版1.12](Java版1.12.md)的第5个快照，发布于2017年4月12日<ref></ref>，加入了彩色床和新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[床](床.md)**
* 加入了可以用染色羊毛合成或用染料染色的彩色床。
* 现在会像[黏液块](黏液块.md)一样，当玩家在上面跳跃时轻轻弹起玩家，但效果比黏液块弱。
* 现在坠落在床上时，受到的摔落伤害会减弱。
* * 玩家可以在离床41格的高度下摔落并活着。
* ** 如果更高，弹起后再落下时造成的伤害会杀死玩家。
* * 玩家可以在床旁边的地面上造一个七格高的平台以防自己死亡，在这种情况下玩家可以摔落45格后仍然存活下来。
* 现在床成为了[方块实体](方块实体.md)，并且床的每一半都可以用NBT标签<code>color</code>染色。
* 由于有了新的颜色，现在它们在物品栏里的纹理由2D模型变成了3D模型。

# = 常规 =
* *[进度](进度.md)**
* 对一些进度加入了描述并更改了一些标题。
* 成就“[](成就/Java版#Adventuring Time.md)”被重制为了一个进度。

* *[复述功能](复述功能.md)**
* 添加了切换复述功能模式时的弹出通知。
* 添加了几种复述功能模式：“关闭”、“阅读聊天文本和系统消息”、“仅阅读聊天文本”和“仅阅读系统消息”。

* *[闪烁标语](闪烁标语.md)**
* 添加了“Don't feed chocolate to parrots!”（意为“不要给鹦鹉喂食巧克力！”）。

# 更改
# = 方块 =
* *[楼梯](楼梯.md)**
* 楼梯的背面和下面现在被认为是“固体”了。
* * 这允许[火把](火把.md)、[栅栏](栅栏.md)、[铁栏杆](铁栏杆.md)、[玻璃板](玻璃板.md)、[圆石墙](圆石墙.md)和[雪](雪.md)能够较好地和它连接。

* *[栅栏](栅栏.md)、[圆石墙](圆石墙.md)、[玻璃板](玻璃板.md)和[铁栏杆](铁栏杆.md)**
* 现在可以和[楼梯](楼梯.md)、[按钮](按钮.md)、[告示牌](告示牌.md)、所有种类的[铁轨](铁轨.md)、[旗帜](旗帜.md)、[线](线.md)、[红石](红石.md)、[压力板](压力板.md)、[拉杆](拉杆.md)、[绊线钩](绊线钩.md)、[黏性活塞](黏性活塞.md)和[结构空位](结构方块.md)连接。

# = 生物 =
* *[鹦鹉](鹦鹉.md)**
* 跳舞时不再变色。

# = 常规 =
* *[配方书](配方书.md)**
* 在提示框中的图标现在会快速循环显示所有已解锁的配方。
