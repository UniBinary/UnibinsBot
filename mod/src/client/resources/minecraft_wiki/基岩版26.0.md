# 基岩版26.0

*页面ID: 175001* | *来源: Minecraft Wiki*

* *26.0**是的一次次要更新，发布于2026年2月10日<ref></ref><ref></ref>。此次更新加入了对命令宏的支持，同步了一些的特性，在[实验性玩法](实验性玩法.md)中加入了一些[2026年第1次小更新](2026年第1次小更新.md)的特性，并修复了一些漏洞。

此次基岩版更新首次采用新[版本格式](版本格式#正式版（基岩版）.md)，该格式宣布于2025年12月2日。<ref></ref>
