# Java版Classic 0.0.14a 03

*页面ID: 34916* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.14a_03**是的一次更新，发布于2009年5月27日<ref name="_03">[IRC日志](#logs.md): "*(01:04:14) <@notch> I'd appreciate it if you could reload so you get 14a_03, then try loading your levels*" (May 27, 2009, 23:04 UTC)</ref><ref name="Facepunch">http://web.archive.org/web/20091214203443/http://www.facepunch.com:80/showthread.php?t=742672&page=11</ref>，修复了一些漏洞。

目前没有证据能证明0.0.14a_02的存在。

# 修复
; 修复了4个漏洞
   修复了0.0.14a的前几个版本中在加载地图时出现的一个由于混淆器与序列化结合不善而导致的漏洞。<ref></ref>
   修复了玩家不能在液体中放置方块的漏洞。<ref>[IRC日志](#logs.md): "*[17:04] <Duke[B12]> Seems you cannot spawn blocks underwater [...] [17:05] <@notch> Duke[B12]: You can in _03*" (May 27, 2009, 23:04 UTC)</ref>
   玩家现在不会在液体中出生了。<ref>[IRC日志](#logs.md): "*(01:02:24) <@notch> the new version shouldn't let you spawn in water any more*" (May 27, 2009, 23:02 UTC)</ref>
   修复了一个可以使玩家具有极快速度的漏洞。<ref>[IRC日志](#logs.md): "*[17:07] <Evil-Ville> Oh by the way the speed bug is fixed*" (May 27, 2009, 23:07 UTC)</ref></onlyinclude>
