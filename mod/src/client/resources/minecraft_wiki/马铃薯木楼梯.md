* *马铃薯木楼梯（Potato Stairs）**是[马铃薯木板](马铃薯木板.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
马铃薯木楼梯会自然生成在[马铃薯村庄](马铃薯村庄.md)中。

# 获取
# = 合成 =

# 破坏
挖掘马铃薯木楼梯的合适工具是斧。

马铃薯木楼梯被破坏后会掉落自身。

# 用途

# = 燃料 =
与[马铃薯茎柄](马铃薯茎柄.md)和其他马铃薯木制品不同，马铃薯木楼梯可被用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个马铃薯木楼梯可烧炼1.5个物品。
