* *毒马铃薯锤（Poisonous Potato Hammer）**是一种可以用于近战攻击，快速造成大量伤害的物品。

# 获取
# = 合成 =

# 用途
毒马铃薯锤默认带有魔咒[击退](击退.md)X。

在[创造模式](创造模式.md)中，毒马铃薯锤虽然能够挖掘方块，但无法破坏方块，挖掘方块时也不会发出声音。

# = 近战攻击 =
毒马铃薯锤的攻击速度是6，需要来[恢复](近战攻击#攻击冷却.md)。

玩家使用毒马铃薯锤攻击时，有30%的概率同时向前投掷[滞留型剧毒药水](滞留型剧毒药水.md)。

# 你知道吗
* 生成剧毒药水前，游戏会尝试消耗毒马铃薯锤的耐久度，但并不会生效。这意味着毒马铃薯锤最初可能被设计为有耐久度的武器。
