# 携带版0.9.4

*页面ID: 21277* | *来源: Minecraft Wiki*

* *v0.9.4 alpha**是携带版的一次次要更新，此次更新在iOS和Android上发布，修复了[v0.9.3 alpha](携带版Alpha 0.9.3.md)中的一些漏洞与崩溃。在iOS版本中，此次更新包括了[0.9.3](携带版Alpha 0.9.3.md)的更改。

# 更改
# = 常规 =
* *[菜单](菜单.md)**
* 当锁定设备、回到主屏幕或切换应用后回到游戏，游戏会打开暂停菜单。

* *其他漏洞**
