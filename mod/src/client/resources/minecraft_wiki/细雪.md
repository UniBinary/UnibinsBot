# 细雪

*页面ID: 71552* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *细雪（Powder Snow）**是一种会使大多数生物陷入其中，并在一段时间后造成冰冻伤害的[方块](方块.md)。

# 生成
# = 自然生成 =
细雪会自然生成于[积雪山坡](积雪山坡.md)和[雪林](雪林.md)生物群系的地表。

细雪也会自然生成在[试炼密室](试炼密室.md)的结构中，铺满地面。

# = 细雪桶 =
玩家对方块表面[细雪桶](细雪桶.md)会尝试在这一位置放置细雪。面朝空气的[发射器](发射器.md)使用细雪桶时会在其面朝方向放置细雪。

# 获取

玩家可以[铁桶](铁桶.md)来获得[细雪桶](细雪桶.md)，从而受控地收集和转移细雪。对着细雪按下键获得的是细雪桶。

细雪的[方块物品](方块物品.md)是[细雪桶](细雪桶.md)。

细雪的方块物品只能通过编辑物品栏获得。

# 破坏
没有工具可以加速对细雪的挖掘。<ref></ref><ref></ref>

细雪被破坏后不会掉落。

# 用途
细雪的[模型](模型.md)、[轮廓箱](轮廓箱.md)和对部分实体的[碰撞箱](碰撞箱.md)是一个完整方块，但玩家能够打开上方有细雪的[箱子](箱子.md)、[陷阱箱](陷阱箱.md)、[末影箱](末影箱.md)和[潜影盒](潜影盒.md)。且[植物](植物.md)、[拉杆](拉杆.md)、[压力板](压力板.md)、[按钮](按钮.md)、[火把](火把.md)、[铁轨](铁轨.md)、[告示牌](告示牌.md)、[脚手架](脚手架.md)、[梯子](梯子.md)、[钟](钟.md)、[灯笼](灯笼.md)、[旗帜](旗帜.md)、[雪](雪.md)和[物品展示框](物品展示框.md)等方块都无法直接放置在细雪上。

细雪会被流过的[水](水.md)或[熔岩](熔岩.md)破坏。

[信标](信标.md)的光束会穿过细雪，且原先的光束颜色不变。玩家在细雪中也能看见光束。

当[草方块](草方块.md)、被细雪覆盖时，其植被层在纹理上会覆雪。

细雪在[下界](下界.md)中同样可以被放置，在用于坠落免伤时可作为[水](水.md)的替代品，在用于灭掉实体的火时可作为[水](水.md)的一次性替代品。

# = 细雪桶 =
对细雪[铁桶](铁桶.md)会移除细雪，并使铁桶变为[细雪桶](细雪桶.md)。使用铁桶的[发射器](发射器.md)会尝试移除其面朝方向的细雪，并获得细雪桶，类似于发射器使用桶与[水](水.md)和[熔岩](熔岩.md)的互动方式。

# = 影响实体移动 =
大部分实体会陷入细雪，在其中的移动速度会较为缓慢。细雪也会阻碍实体的跳跃，未装备皮革靴子的玩家只能在细雪内跳个方块高。生物陷入细雪不会窒息。

细雪对不同实体有不同的碰撞箱：
* 对于下落高度超过2.5格的实体，细雪具有0.9格高的碰撞箱。
* 对于下落高度不超过2.5格的[兔子](兔子.md)、[末影螨](末影螨.md)、[蠹虫](蠹虫.md)、[狐狸](狐狸.md)、、[下落的方块](下落的方块.md)、装备了[皮革靴子](皮革靴子.md)的生物，细雪具有1格高的碰撞箱，因此它们不会陷入细雪。
* 对于下落高度不超过2.5格的其他实体，细雪没有碰撞箱。

因此如果[下落的方块](下落的方块.md)的下落距离低于2.5格，会停留在细雪上而转化为方块。高于2.5时，它们会陷入细雪而被破坏成为[物品实体](物品实体.md)。而无论下落高度为多少，总会在细雪上方转化成方块形式。

装备了皮革靴子的玩家可以像类似于使用[脚手架](脚手架.md)的方式在细雪中移动，按住会陷入细雪中，而按住则会向上移动。

大多数生物在寻路时会将细雪视为正常的固体方块，而[山羊](山羊.md)会避开细雪。

[摔落](摔落.md)到细雪上时没有摔落伤害。穿着皮革靴子摔落到细雪上的实体，如果摔落高度大于2.5格，则会穿过细雪而不被其接住。

# = 与着火实体接触 =
细雪可以消除着火的生物、[箭](箭.md)、[三叉戟](三叉戟.md)的着火状态，并在这个过程中被破坏。

射入细雪的着火的[火球](火球.md)、[小火球](小火球.md)的着火状态不能被细雪消除，且它们会摧毁其穿过的所有细雪。

# = 冰冻 =
[thumb|当玩家进入方块内部时周围渲染的冰霜纹理叠层](File:Frozen effect (texture).png.md)
[thumb|生命值的冰冻动画|class=pixel-image](File:HUD recieving the freeze damage.gif.md)
[thumb|极限模式生命值的冰冻动画|class=pixel-image](File:HUD recieving the freeze damage hardcore.gif.md)

处于细雪中的生物会逐渐被**冰冻（Freezing）**，移动速度降低，并最终持续受到伤害。

随着冰冻的进度累计，生物的移动速度会降低，身体颤抖，并最终在持续接触后开始进入冰冻状态，同时每受到伤害，对于[烈焰人](烈焰人.md)、[岩浆怪](岩浆怪.md)和[炽足兽](炽足兽.md)则是每受到伤害。

被冰冻的玩家会看到环绕着[HUD](HUD.md)边缘的霜花纹理，其不透明度取决于被冰冻的程度。玩家被冰冻了后，HUD边缘的霜花纹理变为不透明，HUD上的生命值会变成蓝青色的冻结纹理。被冰冻的玩家会因移动速度的降低，视场角也会不同程度地降低。

冰冻是由实体数据控制的。生物与细雪相交时，该标签的值每游戏刻增加1，最多增加至140；离开细雪后，该值每游戏刻减少2，该值达到140的生物将会持续受到伤害。使用命令使超过140的生物与细雪相交时会缓慢下降，直至140。

冰冻不是一种[状态效果](状态效果.md)，因而无法通过饮用[奶](奶.md)消除。

[骷髅](骷髅.md)、[流浪者](流浪者.md)、、[北极熊](北极熊.md)、[雪傀儡](雪傀儡.md)、[凋灵](凋灵.md)、[末影龙](末影龙.md)、装备了任意[皮革盔甲](皮革盔甲.md)的[生物](生物.md)、装备了[皮革马铠](皮革马铠.md)的[马](马.md)不会被细雪冰冻。在被冰冻的过程中装备皮革盔甲或皮革马铠后会随着时间从冰冻中恢复。会着火的实体与熔岩或火接触会立即消除冰冻状态。

# = 流浪者 =
[骷髅](骷髅.md)处于细雪中后会开始转化为[流浪者](流浪者.md)，再经转化完成。转化成流浪者后，其生命值会回满，且其原本携带的装备仍会保留。
