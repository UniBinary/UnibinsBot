*页面ID: 34384* | *来源: Minecraft Wiki*

* *1.0.21**是的一次更新，发布于2017年10月9日，等同于[基岩版1.2.2](基岩版1.2.2.md)。<ref></ref>

# 新内容
# = 常规 =
* 新的世界开始选项
* * [初始地图](地图.md)
* * [奖励箱](奖励箱.md)
* * 信任玩家
* 新的游戏规则
* * 显示坐标
* * TNT爆炸
* * 自然生成
* 纸娃娃显示
* 轮廓选择
* 显示玩家标签
* [HUD](HUD.md)不透明度
* 分离控制
* 加载屏幕现在会出现有趣的和有用的提示
* 游戏指南界面
* 在使用控制器进行导航时，向[物品栏](物品栏.md)屏幕加入了一个空闲光标

# 更改
# = 常规 =
* 扩展了世界选项

# = 物品 =
* 扩展了[相片簿](相片簿.md)编辑功能

# 修复
* *修复了7个漏洞**
* 学生现在可以放置自己的黑板，而无需Worldbuild权限
* NPC现在可以运行斜杠命令
* 当加入游戏时所有玩家不能看见修复后的物品栏
* 修复了除非以特定方式瞄准，否则黑板和告示牌不可见
* 修复了第一次到下界或末地时崩溃
* 修复了将世界从0.16更新为0.17时崩溃
* 在帮助页面添加了命令的描述
