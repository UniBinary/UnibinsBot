# 提示框

*页面ID: 102043* | *来源: Minecraft Wiki*

* *提示框（Tooltip）**是某一图标、文本或按钮获得焦点时出现的带有深蓝色描边的方框。

# 类型
# = 物品提示框 =

鼠标指针悬停在[物品栏](物品栏.md)、的某一物品，，指针右侧就会出现物品提示框。若玩家使用触控设备游玩，提示框还会在玩家选中物品栏的物品时出现于快捷栏上方，且在几秒内淡出。[空气](空气.md)及其变种在被选中时不会出现物品提示框。

大多数物品的提示框仅包含物品的名称，名称颜色取决于该物品的[稀有度](稀有度.md)。在[创造模式](创造模式.md)下，和“搜索物品”标签页中的物品还会显示所属分类。

同时按可以启用高级提示框，以显示物品的ID和组件数量。

物品持有的[物品堆叠组件](物品堆叠组件.md)控制了许多物品提示框的行为。许多组件会给提示框添加额外文本；组件控制了物品提示框样式；组件控制了物品提示框的可见性和由其他组件产生的特殊提示框文本的可见性。

# == 特殊物品提示框 ==
[武器](武器.md)和一些[工具](工具.md)的提示框会显示其[魔咒](魔咒.md)、攻击伤害、。[弩](弩.md)会显示其装填的[弹射物](弹射物.md)信息。

[盔甲](盔甲.md)的提示框还会显示[纹饰种类与材质](盔甲纹饰.md)、魔咒、[护甲值](护甲值.md)加成、[盔甲韧性](盔甲韧性.md)加成（若有）和[击退抗性](击退抗性.md)加成。[马铠](马铠.md)和[狼铠](狼铠.md)也会显示其护甲值加成和盔甲韧性加成（若有）。

带有[水下速掘](水下速掘.md)、[爆炸保护](爆炸保护.md)、[深海探索者](深海探索者.md)、[效率](效率.md)、[火焰保护](火焰保护.md)、[](水下呼吸（魔咒）.md)、[横扫之刃](横扫之刃.md)和[迅捷潜行](迅捷潜行.md)魔咒的装备会在其提示框中显示魔咒所应用的[属性修饰符](属性修饰符.md)。

已[染色](染料#盔甲.md)的皮革盔甲、皮革马铠和狼铠会标有“已染色”。开启高级提示框时则显示十六进制颜色码。

开启高级提示框时消耗了耐久度的物品还会显示{{cd|-{}-当前耐久度 / 最大耐久度}}。

[锻造模板](锻造模板.md)会显示用途和所需原材料。

[药水](药水.md)、[喷溅药水](喷溅药水.md)、[滞留药水](滞留药水.md)、[药箭](药箭.md)、或的[谜之炖菜](谜之炖菜.md)会显示其[状态效果](状态效果.md)信息。[不祥之瓶](不祥之瓶.md)会显示不祥之兆信息。

[潜影盒](潜影盒.md)会显示内容物及其数量，最多能显示前5项。

[收纳袋](收纳袋.md)会显示储存槽和容量条。

[烟火之星](烟火之星.md)和[烟花火箭](烟花火箭.md)会显示其颜色、[形状效果](烟火之星#形状效果.md)和[附加效果](烟火之星#附加效果.md)，此外烟花火箭也会显示[飞行时间](烟花火箭#持续时间和方向.md)。

[地图](地图.md)会显示其编号、锁定状况、；开启高级提示框时地图还显示比例尺和等级。

[饰纹陶罐](饰纹陶罐.md)会按前、左、右、后的顺序显示其合成材料。

[热带鱼桶](热带鱼桶.md)的提示框会显示鱼的颜色和体型。

[刷怪笼](刷怪笼.md)和[试炼刷怪笼](试炼刷怪笼.md)还会显示生成的[生物](生物.md)种类，空刷怪笼则会介绍如何设置生物种类；能放置出指定画作的[](画.md)还会显示尺寸、作品名称（若有）和作者（若有）；蜂巢和蜂箱还会显示蜂蜜等级和蜜蜂数量。

[成书](成书.md)还会显示作者和稿件状况；[附魔书](附魔书.md)还会显示其魔咒；[山羊角](山羊角.md)还会显示音效名称；[音乐唱片](音乐唱片.md)还会显示作者和曲目名称。

[刷怪蛋](刷怪蛋.md)、[命令方块](命令方块.md)、[讲台](讲台.md)、[告示牌](告示牌.md)、[悬挂式告示牌](悬挂式告示牌.md)、[刷怪笼](刷怪笼.md)、[试炼刷怪笼](试炼刷怪笼.md)满足特定条件时会显示安全保护提示，见和。

一些[刷怪蛋](刷怪蛋.md)在和平[难度](难度.md)下会显示禁用提示。

# = 状态效果提示框 =
[thumb|紧凑型状态效果。此时如果将光标放在某一个状态效果上，则会出现显示状态效果详细信息的提示框。](File:CreativePackWithEffect.png.md)

游戏界面尺寸较小时，物品栏旁的[状态效果](状态效果.md)栏只会显示图标。若鼠标指针悬停于状态效果图标，指针右侧会出现状态效果提示框，包含效果名称和剩余时长。

# = 实体提示框 =

开启高级提示框后，聊天栏中[死亡消息](死亡消息.md)、[命令](命令.md)返回等信息所提及的[实体](实体.md)和发言的玩家也有提示框，出现在鼠标指针右侧，包含实体名称、类型、[UUID](UUID.md)。

# = 其他提示框 =

鼠标指针悬停于标签页图标和[命名空间ID](命名空间ID.md)时，指针右上角会出现提示框。

鼠标指针悬停于一些需要详细说明的[菜单屏幕](菜单屏幕.md)按钮时会出现提示框。这些按钮用键选中时则会出现与按钮左端对齐的提示框。

鼠标指针悬停于命令执行出错的结果文本时，指针右上角会出现提示框。
