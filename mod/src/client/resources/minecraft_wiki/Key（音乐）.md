# 描述

[File:Key.ogg](File:Key.ogg.md)

Key是一首钢琴曲，伴随着安静、遥远而又稀疏的回声旋律。

专辑中的Key使用更重的回声以与[Door](Door（音乐）.md)相照应，同时使用了[Minecraft](Minecraft（音乐）.md)的部分旋律。
