# 末地水晶

*页面ID: 8307* | *来源: Minecraft Wiki*

* *末地水晶（End Crystal）**是一种能够引发大威力[爆炸](爆炸.md)的[实体](实体.md)和[物品](物品.md)，可以用于治疗和复活[末影龙](末影龙.md)。

# 生成
# = 自然生成 =
末地水晶是[黑曜石柱](黑曜石柱.md)结构的一部分，每一个黑曜石柱在其顶端都有1个基岩，作为末地水晶的基座。

末地共有10个[黑曜石柱](黑曜石柱.md)，其中2个黑曜石柱的末地水晶还被[铁栏杆](铁栏杆.md)围住。

在复活[末影龙](末影龙.md)时，末地水晶会随着整个黑曜石柱的重新生成而一起生成。

# 用途
对[基岩](基岩.md)或[黑曜石](黑曜石.md)末地水晶时，若这个基岩或黑曜石上方1格为[空气](空气.md)，并且上方2格内没有实体，那么一个没有基座的末地水晶会被放置在该方块上方1格的位置。

# 行为
末地水晶没有碰撞行为，其他实体可以穿过它。

末地水晶免疫[火焰伤害](火焰伤害.md)。

末地水晶具有两种外观：有基座和无基座。自然生成的末地水晶具有基岩基座。

处于末地的末地水晶会在其下方1格有满足火的放置条件的方块时持续产生[火](火.md)。

末地水晶可以被[活塞](活塞.md)推动。

# = 治疗末影龙 =
末地水晶每0.5秒为半径32格内的所有[末影龙](末影龙.md)恢复，该效果不会被任何物体阻挡。

# = 爆炸 =
末地水晶受到任何[伤害](伤害.md)时会**立即**[爆炸](爆炸.md)并消失，即使该攻击只造成0伤害值。末地水晶受到爆炸伤害后会消失，但不产生爆炸。

末地水晶的[爆炸威力](爆炸威力.md)为6，比[TNT](TNT.md)的爆炸威力大50%。其爆炸所产生的伤害将继承导致其爆炸的伤害来源。

末地水晶爆炸时会使正在接受其治疗的[末影龙](末影龙.md)受到伤害。

# = 光柱 =
末地水晶可以投射一道光柱到指定位置。

参与复活末影龙的末地水晶会投射光束到各种位置，直到末影龙复活。

末地水晶也会将光柱投射到正在治疗的末影龙上。

该光柱由末地水晶的实体数据<code>BeamTarget</code>控制，可以由或等方式修改。

# = 复活末影龙 =
[right|thumb|一种重生末影龙的摆放末地水晶的方式](File:End Crystals on the Exit portal.png.md)

与末影龙的战斗结束后，当返回传送门的四个边上各放置了至少一个末地水晶时，末影龙会开始重生。

== 你知道吗 ==<!--末地水晶符文的内容尚未得到官方证实，请勿擅自添加-->
[thumb|12w36a-37a中的信标模型](File:Beacon JE2.gif.md)
* [信标](信标.md)中曾有一个类似于缩小版黄色末地水晶的动态实体，末地水晶下方的基岩底座同样呈现在了该信标实体的下方，但这个基座通常会被隐藏在信标下面附着的方块中。
* 实体在移动时才会进行是否被点燃的判定，因此固定不动的末地水晶不会被自己燃起的火焰引爆。
* 使用[末影珍珠](末影珍珠.md)传送到末地水晶时受到的伤害基本相当于玩家在传送前所处位置[攻击](攻击.md)末地水晶时受到的伤害，最低为5点来自于末影珍珠的传送伤害。
