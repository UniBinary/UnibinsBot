* *活塞（Piston）**和**黏性活塞（Sticky Piston）**是一种被[红石信号](红石信号.md)激活时可以推动大多数[方块](方块.md)和[实体](实体.md)的[红石元件](红石元件.md)方块，并在过程中产生[移动方块结构](移动方块结构.md)。其中黏性活塞在收回时会拉动方块，活塞在收回时不会拉动方块。

* *活塞头（Piston Head）**（又称**活塞臂（Piston Arm）**）是活塞保持伸出时存在于其面向方向的方块。

# 生成
普通的活塞不会生成在世界中。

# = 自然生成 =
[丛林神庙](丛林神庙.md)中会自然生成3个黏性活塞。

[远古城市](远古城市.md)中心的红石地下室里会自然生成5个黏性活塞。

# 获取
活塞头没有对应的[方块物品](方块物品.md)。使用和可分别获得活塞头和黏性活塞头的方块物品。

# 破坏
挖掘活塞、黏性活塞和活塞头<ref></ref>的合适工具是镐。

活塞和黏性活塞被破坏后会掉落自身，其前方的活塞头（若有）也会立即被破坏。

活塞头被破坏后不会掉落任何物品，其后方的活塞也会立即被破坏。

# 用途
利用活塞|Tutorial:活塞电路活塞电路}}
活塞在被放置时永远朝向玩家。附着性方块（比如拉杆）可以放在活塞或黏性活塞上。

当活塞被激活时，活塞的木质表面（活塞头）会在[启动延迟](#启动延迟.md)后尝试伸出，并移动在其前方的方块；当活塞被取消激活时，活塞头会被收回。如果是黏性活塞，活塞头被收回时也会尝试将前方的方块拉回。

虽然黏性活塞在收回时会拉动方块，静止的黏性活塞或黏性活塞头上的方块不会被黏住。

在活塞推出和拉回时会发出声音，以活塞为中心31×31×31的区域内都能听到。

# = 活塞头 =
当活塞头的后方接收到或时，它会检查自己的后方是否正确连接到了一个对应的活塞上。若没有连接到一个活塞或是活塞的方向与活塞头不对应，那么活塞头会被立刻破坏。

活塞头没有其他行为，其存在对活塞的收回行为运作不是必须的，如无头黏性活塞可以拉回面向方向2格处的方块。

活塞头有两种模型，完整的活塞头和短活塞头，后者在活塞未完全推出时的[移动的活塞](移动的活塞.md)渲染时使用。活塞头具有方块状态<code>short</code>用于控制是否为短活塞头模型，在正常运作的活塞中、包括移动的活塞中永远为<code>false</code>，只用于在[调试模式](调试模式.md)中展示短活塞头模型。

活塞头使用一个方块状态来定义它是一个普通活塞头还是一个黏性活塞头。两种活塞头使用不同的方块ID定义。

# == 激活 ==
活塞是[机械元件](红石元件#机械元件.md)，可被下列形式激活：
* 除活塞面向的毗邻的开启的**[电源](红石元件#电源.md)**（例外：[红石火把](红石火把.md)不会激活其所附着的活塞，[侦测器](侦测器.md)只会激活指向的活塞）。
* 除活塞面向的毗邻的**[充能方块](红石电路/充能与激活.md)**。
* 除活塞面向的毗邻的指向活塞且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)（包括活塞上方的红石粉）；毗邻但未指向活塞的红石粉或。

活塞还能通过[半连接性](半连接性.md)激活。若以上所述的途径对于活塞正上方的方格（不需要实际存在红石元件，[空气](空气.md)方块或非红石导体均可）成立，则活塞可以被激活。该激活方式可能使活塞进入[BUD](BUD.md)状态，详见[教程/半连接性](教程/半连接性.md)。

在同一红石刻内，电容器更新阶段前存在，但在电容器更新阶段被取消的信号无法激活活塞。

活塞不是红石导体，不可充能。

# == 行为 ==
活塞被激活或取消激活后会在启动延迟后推出或拉回。活塞正在推拉时不响应输入变化。

# = 启动延迟 =
活塞被激活或取消激活后不会立刻推出或拉回，从输入变化到活塞真正开始推拉的时延就是启动延迟。

启动延迟固定为，即活塞输入变化后后开始推出或拉回。

启动延迟取决于活塞输入变化发生在游戏计算的什么阶段：
* 若活塞输入变化在计算[计划刻](计划刻.md)、区块刻、方块事件时产生（**早于或位于方块事件阶段**），那么活塞的方块事件会在这一游戏刻的方块事件阶段被执行。<br>此时启动延迟为，即“同刻启动”。
* 若活塞输入变化在计算实体、方块实体、玩家运算时产生（**晚于方块事件阶段**），活塞的方块事件需要等候下一刻的方块事件阶段再被执行。<br>此时启动延迟为，即“下一刻启动”。

# = 创建移动方块结构 =

工作的活塞会让方块被推动或拉动，从而使这些方块及其关联的方块跟随活塞的推拉而移动，此过程会创建出[移动方块结构](移动方块结构.md)。

# 你知道吗
* Mojang曾经声称活塞只能推动12个方块的限制不会被改动，因为“现有的限制是有意设计的”。<ref>

</ref>
* 当活塞托举着一个受重力影响的方块（例如[沙子](沙子.md)）并不断迅速地伸缩，该方块很有可能最终掉落为[物品](物品.md)。因为该方块所对应的实体要变回对应方块时，活塞臂刚好伸出了。不过，[沙砾](沙砾.md)不会掉落为[燧石](燧石.md)。
* 如果通过短脉冲充能的黏性活塞直接推动含水方块，那么含水方块在被推动到新地点后还会保持含水。
* 生物可以在活塞头方块中生成。
* 地毯可以放在活塞头上，如果用替换活塞头的话，地毯还会留在原位。
* 使用命令放置的活塞头是不可见且是没有碰撞箱的，并且方块也不能覆盖活塞头。
* 活塞头在基岩版中与Java版形状略有不同。
* 如果一个活塞在世界的顶部，并且面向上，或者在底部且面向下，它就不能伸出。
* 一个活塞不能推动另一个被激活的活塞。
* [水](水.md)和[熔岩](熔岩.md)在常规状态下不能被破坏，但是通过活塞推动可以破坏水或熔岩并使其产生方块被破坏的粒子。
