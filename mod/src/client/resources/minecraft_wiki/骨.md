# 骨

*页面ID: 70551* | *来源: Minecraft Wiki*

* *骨（Bone）**可以指：
# Minecraft
# = 方块和物品 =
*  - 一种从[鱼](鱼.md)和[骷髅](骷髅.md)身上掉落或从[钓鱼](钓鱼.md)获得的物品。
*  - 一种用骨头合成的物品，从鱼或[堆肥桶](堆肥桶.md)获得。
*  - 一种用9个骨粉合成的方块，可以从自然生成的[化石](化石.md)中获得。

# = 地物 =
*  - [主世界](主世界.md)的地物。
*  - [下界](下界.md)的结构。

# Minecraft Earth
*  - 一种有着骨头纹理的生物。
*  - 骨蜘蛛攻击时发射的弹射物。

# Minecraft Dungeons
*  - 一种[弓](弓.md)的独特变种。
*  - 一种可消耗道具。
