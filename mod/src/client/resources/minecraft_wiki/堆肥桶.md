* *堆肥桶（Composter）**是一种可用于将部分方块和物品转化成[骨粉](骨粉.md)的方块。

# 生成
# = 自然生成 =
堆肥桶会自然生成在[村庄](村庄.md)的[农田](农田.md)里，也会自然生成在[古迹废墟](古迹废墟.md)的一个厅堂中。

# 破坏
挖掘堆肥桶的合适工具是斧。

堆肥桶被破坏后会掉落自身，如果堆肥桶是满的则还会掉落1个[骨粉](骨粉.md)。

# 用途
将可用于堆肥的物品放入堆肥桶，可生产[骨粉](骨粉.md)。

[红石比较器](红石比较器.md)可检测堆肥桶的堆肥层数，每多一层增加一格信号。

# = 堆肥 =
堆肥桶可堆肥来填充（即向堆肥桶填充可用于堆肥的物品）。当成功添加一个物品时，堆肥桶会出现绿色[粒子](粒子.md)。不同物品有不同的可堆肥性，物品的百分比越高，使用时增加一层堆肥层数的概率就越高。而当堆肥桶为空桶时，任何可堆肥的物品都会使堆肥层数增加一层。<ref></ref>每层堆肥都具有类似[灰化土](灰化土.md)顶部纹理的外观，当堆肥桶里面的堆肥到达第7层的时候，堆肥的外观会改变，表示这时候再或它就会产生骨粉。

下面的表格列出了可以在堆肥桶中的物品、可以增加堆肥层数的概率、填满堆肥桶所需平均物品数和填充一组物品后可得骨粉数量期望值。

# = 漏斗 =

对着堆肥桶上面的[漏斗](漏斗.md)、[投掷器](投掷器.md)或[合成器](合成器.md)会将可用于堆肥的物品放入堆肥桶中，有概率增加堆肥桶的层数。

堆肥桶下方的漏斗可以在其达到第8层时吸取骨粉，重置堆肥桶为0层。

漏斗、投掷器或合成器无法连接堆肥桶的侧面。

# = 更改村民职业 =

若一个堆肥桶没有被[村民](村民.md)认领，则附近的任意一个无业村民有机会转变职业为[农民](农民.md)。

# = 燃料 =
堆肥桶可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个堆肥桶可烧炼1.5个物品。
