* *蛋糕（Cake）**是一種放置后能为[玩家](玩家.md)恢复[饥饿值](饥饿值.md)的类似[食物](食物.md)的方块。

* *插上蜡烛的蛋糕（Cake with Candle）**是顶部带有[蜡烛](蜡烛.md)的蛋糕，可以点燃蜡烛提供亮度。

# 生成
蛋糕不会生成在世界中。

# 破坏
没有工具可以加速对蛋糕的挖掘。

蛋糕被破坏后不会掉落，插上蜡烛的蛋糕被破坏后只会掉落对应颜色的蜡烛。

# 用途
# = 食用=

蛋糕是一种类似[食物](食物.md)的物品，但是此[方块物品](方块物品.md)不能被[玩家](玩家.md)直接食用，而是需要放置为方块才能。

蛋糕方块在被后会为玩家补充[饥饿值](饥饿值.md)和[饱和度](饱和度.md)。蛋糕没有“食用时长”，使用后会立刻为玩家补充饥饿值和饱和度。玩家在饥饿值满时也可以使用蛋糕。多个玩家可以同时吃一个蛋糕。

每个蛋糕共有7片，每次使用会减少1片，每片可以回复，消耗一个蛋糕的全部7片可以回复。蛋糕的营养价值可以视为0.1。

蛋糕不具有食物属性（如食用时长）及其提供的食物的普遍行为（如[狐狸](狐狸.md)对食物的行为），也不会播放食用音效、不能完成[进度](进度.md)“”，进度“”不要求蛋糕，因此在各类游戏场景中不被认为是一种食物；使用蛋糕不会计入物品使用的[统计](统计.md)，但是会计入“”统计。

# = 红石 =
[红石比较器](红石比较器.md)的输入端与蛋糕相邻时，输出端会根据蛋糕片数产生红石信号，一个完整蛋糕可产生强度为14的信号，每食用一片蛋糕就会减少2信号强度。

# = 熊猫 =
[熊猫](熊猫.md)会走向[物品实体](物品实体.md)形式的蛋糕，将其捡起并食用。憂鬱的貓熊不會主動食用蛋糕。

玩家对熊猫蛋糕可以给予它蛋糕。

# = 堆肥 =
把蛋糕放入[堆肥桶](堆肥桶.md)中有100%的概率使堆肥层数加1。

# = 蜡烛 =
完整的蛋糕可以插上一个[蜡烛](蜡烛.md)变成对应颜色的插上蜡烛的蛋糕，食用蛋糕会使蜡烛掉落。

蜡烛在放置时是未点燃的，[打火石](打火石.md)、[火焰弹](火焰弹.md)、、燃烧的[弹射物](弹射物.md)或是可以将其点燃。

蜡烛点燃后，玩家可以通过空手与或来熄灭它，若无法食用蛋糕，玩家也可以手持物品将蜡烛熄灭。蜡烛也会被[风爆](爆炸#风爆.md)、熄灭。

# = 光源 =

插上点燃的蜡烛的蛋糕会发出亮度为3的光。
