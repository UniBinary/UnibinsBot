# 煤炭

*页面ID: 5889* | *来源: Minecraft Wiki*

* *煤炭（Coal）**是一种燃料[物品](物品.md)。

# 获取
# = 煤矿石 =
用未带有[精准采集](精准采集.md)魔咒的镐开采1个[煤矿石](煤矿石.md)或[深层煤矿石](深层煤矿石.md)会掉落1个煤炭，每等级[时运](时运.md)魔咒将掉落数量上限增加1，使用时运III最多会掉落4个煤炭。

# = 生物掉落物 =

# = 箱子战利品 =

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)和[海底废墟](海底废墟.md)里的[可疑的方块](可疑的方块.md)有概率掉落煤炭。

# 用途
# = 合成材料 =

# = 燃料 =
煤炭能作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)使用，一个煤炭可烧炼80秒（8个物品）。

# = 交易 =

# = 动力矿车 =

对[动力矿车](动力矿车.md)煤炭可为其增加的行进时间，如果增加后会达到则不再增加。
