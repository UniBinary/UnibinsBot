# Java版21w05b

*页面ID: 77863* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w05b**是[Java版1.17](Java版1.17.md)的第8个快照，发布于2021年2月4日<ref></ref>，更改了[铜块](铜块.md)及其变种的英文名称，并修复了一些漏洞。

# 更改
* *[铜块](铜块.md)及其变种**
* 铜块的英文名称从“Copper Block”更改为“Block of Copper”。
* 删除了铜块的氧化变种以及涂蜡氧化变种英文名称中的“block”单词。
* * 这些方块的ID同样也作了更改。
* 涂蜡的铜块的英文名称从“Waxed Copper”改为“Waxed Block of Copper”。
* * 它的ID从改为。
