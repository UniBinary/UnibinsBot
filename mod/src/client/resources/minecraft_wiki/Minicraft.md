* **Minicraft***是[Notch](Notch.md)在2011年的48小时游戏开发比赛[Ludum Dare 22](http://ludumdare.com/compo/)中制作的2D俯视角电子游戏。游戏在2011年12月19日发布后从未有任何官方更新。

终止支持后，Notch开放了*Minicraft*的源代码，而其知名度也随更多玩家制作自己的*Minicraft*版本而增加。与之同时，Notch也在开发*Minicraft*的续集*Minitale*，但由于从未发布而鲜有人知。

# 控制
* 使用或键来移动和在物品栏中滚动。
* 使用或来攻击。
* 使用打开物品栏并暂停游戏和在物品栏中使用物品。

# 游戏内容
[thumb|玩家在森林中走过](File:Minicraft Forest.gif.md)
* Minicraft*的部分游戏内容与Minecraft相似，玩家需要收集物资、合成工具来采矿、伐树、生产、挖坑和杀死僵尸与史莱姆，并以打败Boss空气精灵为目标。*Minicraft*在Ludum Dare比赛中的主题为“孤独”，游戏提交时的描述是：“这个游戏的目标是打败世界中除了自己唯一的有感情的存在，来保证你永远孤独下去。”

游戏的地图是有限的，玩家会生成在其中的一系列岛屿中。*Minicraft*有5个地表类生物群系，即森林、平原、沙漠、山地和海洋；3个洞穴类生物群系，即干燥洞穴，水洞穴和熔岩洞穴；以及一个天空生物群系。

玩家有10点生命值和10点能量值。能量值能迅速恢复，但生命值必须通过进食恢复。攻击、进食等行为会消耗能量值。当能量值不足时，玩家的移动速度将会变得缓慢，同时无法使用物品或进行上述的行为。工具对目标的伤害随玩家的能量值增加，而使用时消耗的能量值随工具的等级减少。对大部分地砖使用木质工具消耗5点能量值，而对矿石使用消耗7点能量值。工具每提升一级，每次使用时消耗的能量值减少1点。

# 实体
[thumb|与空气精灵战斗的玩家](File:Air wizard battle.png.md)
实体是世界中可移动的物体。

# = 生物 =
所有其他生物均与玩家敌对，它们会靠近玩家并在接触时对玩家产生伤害。

# = 家具 =
家具是可以放置在世界中的物件。家具会与玩家和生物碰撞，并且玩家可以推动家具，或使用强力手套将家具拿起。游戏中有六种家具，即 [32px|link=](File:Minicraft Workbench.png.md) **工作台**、[32px|link=](File:Minicraft Chest.png.md) **箱子**、[32px|link=](File:Minicraft Oven.png.md) **烤箱**、[32px|link=](File:Minicraft Furnace.png.md) **熔炉**、[32px|link=](File:Minicraft Anvil.png.md) **铁砧**和[32px|link=](File:Minicraft Lantern.png.md) **灯笼**。除了灯笼以外，所有家具可以被交互及用于合成或储存物品。

# = 其他实体 =
其他在游戏中的实体包括**掉落物**，其会在与玩家接触时自动被玩家捡起。掉落物会闪烁并随后消失。此外，**火光**是空气精灵发射的投射物。火光会缓慢远离空气精灵并在与玩家或其他生物接触时对其产生1点伤害。

# 地砖
* *地砖（Tiles）**相当于二维的[方块](方块.md)，是*Minicraft*世界里最基本的组成单位。
* **仙人掌**：生成在沙漠区域中，在接触时对生物和玩家产生1点伤害，共有10点生命值并掉落1-2个仙人掌。
* **云仙人掌**：生成在天空中。类似于矿石，在接触时产生3点伤害，共有10点生命值。
* **云**：组成天空地形的地砖，对其使用锹并不会破坏地砖，而是掉落云物品。
* **泥土**：生成在地表的草、沙和岩石之下，可以用于填补洞和替换液体地砖。
* **耕地**：通过锄耕作草、泥土或石头产生，其上方可以种植作物。如果没有种植作物，耕地最终会变回为泥土或石头，踩过时也有概率令耕地退化。收获作物和对其使用锹时亦会令耕地变化。
* **花**：生成在草的斑块上，每朵花地砖包含两朵代表[滨菊](滨菊.md)的白色和黄色花。破坏地砖时掉落1-2个花，其中每一个都可以重新放置为有两朵花的花地砖，使其容易再生。当草在其上生长时，花可以散布到邻近的泥土地砖。
* **草**：在地表的大部分泥土上生成，并且可以散布到邻近的泥土地砖。花和树可以在其上方种植。对草使用锄或锹时有概率掉落种子而非破坏。
* **硬石**：八个硬石包裹着每个通往天空的楼梯，只能被宝石镐挖掘。具有与岩石相同的掉落物和200点生命值。
* **洞**：对暴露的泥土或石头使用锹可以产生一个洞。液体可以流入洞中，而怪物无法跨越。在洞中放置泥土将其变回泥土或石头地砖。
* **无限坠落**：用于天空中云朵之间的空隙。只有空气精灵可以在无限坠落上行走。
* **熔岩**：在地底最底一层生成，会发出光亮并在接触时产生大量伤害。怪物无法进入熔岩。
* **矿石**：矿石有三种类型，铁、金及宝石。矿石只在能量值满时使用镐才会受到伤害。每使用镐时都有概率掉落矿石，并在破坏时掉落更多。在接触时会产生3点伤害，因此玩家需要在采矿时多加留意。
* **岩石** - 生成在山地生物群系并组成地底的绝大部分，构成玩家必须挖掘才能通过的墙壁，共有50生命值，掉落1-4个石头和0-1个煤炭。
* **沙子** - 生成在沙漠生态群系中泥土上，仙人掌可以在其上方放置。玩家及生物在上方行走时会留下脚印（包括没有脚的史莱姆），在一段随机时间后消失。
* **树苗** - 新种植的树或仙人掌在成熟前的阶段。
* **楼梯** - 不同关卡间的通道，可在世界不同地方找到。一个层级中往下的通道将连接至另一个层级中往上的通道。无法被破坏。
* **石头** - 组成地底层级的地面。功能与泥土相似，在挖掘时掉落泥土，而在地底放置泥土将变成石头。
* **树** - 在地表的草上生成，生物无法穿过，并在每次玩家敲打时有概率掉落苹果。共有20点生命值，掉落1-2个木头和0-2个橡实。当四棵树被放置在一起时，其之间将会出现第五颗树，但第五颗树只在视觉上存在。
* **水** - 在地表和地底的中间层级生成，玩家在水中游泳时会消耗能量值，并在能量值耗尽时受到伤害。怪物无法进入水中。
* **小麦** - 在耕地上种植种子后生长而成，共有六个生长阶段。生长阶段越高，则在破坏时掉落的小麦物品越多。

# 关卡
[thumb|地表关卡的典型视图。](File:Minicraft.png.md)
在*Minicraft*的世界里有五个由楼梯连接的关卡。它们是:
* **地面**——玩家生成的地方。总是被阳光点亮，只有绿色的怪物生成在这里。地面可大致分为五个不同的生物群系：
* * **森林**——一个被草和树木覆盖的地方。
* * **平原**——一个被草覆盖的地方，而没有树木。
* * **沙漠**——一个被沙子和仙人掌覆盖的地方。
* * **山**——一个被岩石和楼梯覆盖的地方。
* * **海洋**——一个被水覆盖的地方。
* **干燥洞穴**——地下的第一个关卡，由被藤蔓和铁矿石填充的蜿蜒的洞穴系统组成。红色和绿色的怪物生成在这里。
* **水洞穴**——地下的第二个关卡，充满了大水湖和金矿脉。白色、红色和绿色的怪物生成在这里。
* **熔岩洞穴**——地下的第三个关卡，充满了大熔岩湖和宝石矿脉。黑色、白色、红色和绿色的怪物生成在这里
* **天空**——使用宝石镐，玩家可以破坏通往天空的楼梯周围的硬石屏障。一个由云平台和无底洞组成的关卡，黑色的怪物和空气精灵居住在这里。

# 你知道吗
* *Minicraft*的网页版托管在[这个网页](https://s3.amazonaws.com/ld48/ld22/index.html)（但由于Java小程序被弃用，它在现代浏览器中已无法游玩）。

* 后来加入Minecraft的很多特性最早出现在*Minicraft*中，例如[树掉落苹果](苹果#获取.md)、[僵尸变种](僵尸（消歧义）.md)、[铁砧](铁砧.md)、白色的[花](花.md)、[捡起时保留存储的存储物品](潜影盒.md)、[用于烹饪食物的特殊熔炉](烟熏炉.md)、[灯笼](灯笼.md)、[地下的大湖](含水层.md)和[以风为主题的敌人](旋风人.md)。
* 天空关卡和未实现的[天域](天域.md)相似。
* *Minitale*曾计划作为*Minicraft*的续作。Notch在完成原版游戏几天后宣布将继续开发这款游戏<ref></ref>，随后确认了续作正在制作中<ref></ref>，不久后宣布了它的名字。<ref></ref>据Notch透露的消息，续作将加入保存和加载、回放功能、一个新的关卡生成器、<ref></ref>改进的灯笼<ref></ref>和宽屏分辨率。<ref></ref>
* 这个游戏的“关于”页面包含对Notch父亲的纪念，他在Notch完成这个游戏的几天前去世了。<ref>https://web.archive.org/web/20121213195317/http://notch.tumblr.com/post/37823268132/i-love-you-dad</ref>
