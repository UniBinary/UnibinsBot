# Java版16w05b

*页面ID: 19935* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w05b**是[Java版1.9](Java版1.9.md)的第53个快照，发布于2016年2月4日<ref></ref>，发布以修复上一个快照中的问题。

# 更改
# = 物品 =
* *[盔甲](盔甲.md)**
* 削弱盔甲在有效防御中的点数，因为攻击力度现在可使得有效防御降低至20%的护甲值（自[16w02a](16w02a.md)原为25%）。

# = 游戏内容 =
* *战斗机制**
* 攻击冷却效果增强：20%到100%之间二次项式变化（[16w02a](16w02a.md)为50%到100%之间线性变化）。

* *[爆炸](爆炸.md)**
* [爆炸](爆炸.md)伤害调高至<code>(impact×impact+impact)×**7**×power+1</code>（[16w02a](16w02a.md)为<code>(impact×impact+impact)×**4.5**×power+1</code>）。

# = 常规 =
* *[聊天](聊天.md)**
* 调高了聊天框。

* *[调试屏幕](调试屏幕.md)**
* 在主菜单的左下角和调试屏幕左上角的版本号后面显示是否为快照。
* * 示例：“16w05b/snapshot”。
