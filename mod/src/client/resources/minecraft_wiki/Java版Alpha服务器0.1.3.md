# Java版Alpha服务器0.1.3

*页面ID: 45475* | *来源: Minecraft Wiki*

* *0.1.3**是一个[Alpha](Java版Alpha.md)服务器版本，对应[客户端1.0.16_02](Java版Alpha v1.0.16 02.md)，发布于2010年8月17日。<ref name="blogpost"></ref>

# 新内容
* 增加了对命令的支持，用于向另一个玩家说悄悄话。
* 增加了对命令的支持，用于向执行此命令的OP玩家显示目前在线的玩家列表。
* 现在服务器会记录管理员所执行的命令，并给所有在线的OP玩家广播命令的执行。

# 更改
* OP现在可以在出生点区域建造。

# 修复
* 修复了命令。
