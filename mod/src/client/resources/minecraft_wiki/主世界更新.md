# 主世界更新

*页面ID: 26693* | *来源: Minecraft Wiki*

[缩略图|300px|博文中主世界更新的内容图](File:Overworld Update banner.png.md)
* *主世界更新（Overworld Update）**是[携带版Alpha](携带版Alpha.md)的一次主要更新，发布于2016年2月18日。此次更新的名称于2016年11月11日发布在Xbox网站的一篇博文里。<ref>http://news.xbox.com/2016/11/11/end-2016-ender-update-minecraft-windows-10-pocket-edition/</ref>

此次更新的开发始于[Alpha 0.14.0 build 1](携带版0.14.0.b1.md)，其发布于2016年1月25日。

# 重要特性

# = 新内容 =
* 加入了各种选项。
* 10种新方块：
* * [红石比较器](红石比较器.md)、[发射器](发射器.md)、[投掷器](投掷器.md)、[漏斗](漏斗.md)、[运输矿车](运输矿车.md)、[TNT矿车](TNT矿车.md)、[漏斗矿车](漏斗矿车.md)、[炼药锅](炼药锅.md)、[红砂岩](红砂岩.md)（及其变种）和[黏液块](黏液块.md)。
* 3种新物品：
* * [物品展示框](物品展示框.md)、[地图](地图.md)和[末影珍珠](末影珍珠.md)。
* [沼泽小屋](沼泽小屋.md)。
* [女巫](女巫.md)。

# = 更改 =
* 生物、方块和物品的各种更改。

# 跟进版本
* [Alpha 0.14.1](携带版Alpha 0.14.1.md)加入了*Minecraft: Story Mode*皮肤包。
* [Alpha 0.14.2](携带版Alpha 0.14.2.md)修复了Alpha 0.14.1中的一些漏洞和崩溃。
* [Alpha 0.14.3](携带版Alpha 0.14.3.md)加入了生物群系定居者2皮肤包。
