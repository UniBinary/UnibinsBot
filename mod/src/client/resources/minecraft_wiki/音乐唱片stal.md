# 音乐唱片stal

*页面ID: 156539* | *来源: Minecraft Wiki*

* *stal**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的同名曲目。

# 获取
# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片stal。

# 用途
# = 音乐 =

[noicon](File:stal.ogg.md)

Stal是一首由钢琴、萨克斯风和低音提琴演奏的缓和的爵士乐曲，并有竖笛间奏，游戏内时长为2分30秒。

# = 红石 =

音乐唱片stal放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为8的信号。

# 你知道吗
* “Stal”是瑞典语，意即英语的“stole”（“偷”的过去式），但也可以是有上圆圈变音符号的“stål”，意思是英语的“steel”（钢；坚韧）。
