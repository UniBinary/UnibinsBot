# Java版Indev

*页面ID: 7602* | *来源: Minecraft Wiki*

[thumb|有[[拉娜](File:Ranagroup.png.md)生物的一个Indev版本]]

* *Indev**（全称**<u>In</u> <u>Dev</u>elopment**，即开发中）是Minecraft的第三个[开发阶段](版本记录.md)，也是较早的Minecraft[生存模式](生存模式.md)测试版本。它继承了[Classic](Java版Classic.md)阶段的[生存测试](生存测试.md)，同时是Minecraft第二个公开发布部分版本的开发阶段。在[Infdev](Java版Infdev.md)引入无限地图后，Indev被其取代。

在[Notch](Notch.md)收到让社区体验新添加特性的请求后，Indev最初于2009年12月23日发布。Indev的0.31版本在minecraft.net/indev上公布，且仅对购买过该游戏的玩家开放<ref></ref>，这也让Indev成为Minecraft的首个付费版本。其新特性包括比[Classic](Java版Classic.md)更复杂、更真实的[光照](光照.md)系统，以及对MD3格式生物模型的支持，[野兽小子](野兽小子.md)、[黑史蒂夫](黑史蒂夫.md)、[史蒂夫](Indev MD3格式生物#史蒂夫.md)和[拉娜](拉娜.md)便是例证。此后，Indev共收到56次更新，为Minecraft增添了诸多重要特性，具体如下所列。在这一开发周期中，更新主要侧重于测试新内容，例如[火把](火把.md)和[火](火.md)。也正因如此，当时的游戏内容虽较今日的Minecraft少得多，但已趋于标准化。

玩家可在有限地图中进行游戏，地图的特点由其形状和大小决定。游戏玩法与[生存测试](生存测试.md)存在显著差异，为未来的游戏模式奠定了基础。如今，玩家需要使用[工具](工具.md)和[武器](武器.md)，收集并准备食物，运用[合成](合成.md)和[烧炼](烧炼.md)系统，谨慎地度过每一天。与生存测试相同，玩家仍需将地图保存到计算机的文件中，若玩家死亡，则需重新加载地图。

针对Indev的有限地图，一个改变游戏的想法很快应运而生。2010年2月23日，Indev迎来最后一次更新，与此同时，[Infdev](Java版Infdev.md)的开发启动，该版本采用无边界、可无限延伸的地图模式。在Infdev期间及进入[Alpha](Java版Alpha.md)阶段后，Indev在minecraft.net上仍可使用。2010年9月，Indev与Infdev一同从网站上被移除，此后便无法继续游玩。Indev的部分功能在如今的Minecraft中已不复存在，例如挑选地图的特性、保存和重新加载地图的需求以及等距地图查看器。这些特性已被[生物群系](生物群系.md)、地图自动保存、死亡后[重生](重生.md)和新的无限地图查看器（现已移除）所替代。

# 与生存测试不同的特性

* [Indev房子](Indev房子.md)。
* [物品栏](物品栏.md)。
* [合成](合成.md)。
* [地图生成界面](Indev世界选项.md)，可配置地图主题、地图类型和地图形状。
* 动态[光照](光照.md)。
* 以[生猪排](生猪排.md)、[熟猪排](熟猪排.md)、[面包](面包.md)及[蘑菇汤](蘑菇汤.md)（后来被重命名为蘑菇煲）代替[蘑菇](蘑菇.md)作为可进食的[食物](食物.md)，用于补充[生命](生命.md)。
* 新的镶嵌器，以加快游戏运行速度。
* 持有多组相同物品的能力。
* 全屏模式。
* 第三人称视角，可通过按F5切换。
* 等距截图，可通过按F7捕获。
* 装饰用的[画](画.md)。
* [工具](工具.md)和装备。
* [耕作](Tutorial:农作物种植.md)。
* [生物](生物.md)更新（更好的寻路算法、不同的[难度](难度.md)选项）。
* [昼夜更替](昼夜更替.md)（包括太阳和月亮）。
* 新的世界格式（.mclevel）。
* 需要[弓](弓.md)来射[箭](箭.md)。
* [熔炉](熔炉.md)和[烧炼](烧炼.md)。
* [火把](火把.md)和[火](火.md)。
* 新的生物音效。
* 新的[主菜单](主菜单.md)。
* 拉娜、野兽小子、黑史蒂夫和史蒂夫（仅存在于[Indev 0.31](Indev 0.31.md)，未在[Minecraft Indev](Minecraft Indev.md)版本中正式加入）。

# 你知道吗
* Indev的包含蜘蛛网的纹理，不过该方块直到[Beta](Java版Beta.md)阶段才正式加入。
* Indev中有椅子的纹理，但在之后的Infdev中被删除。由于当时游戏里并不存在椅子，这表明添加椅子的想法要么被放弃，要么被推迟了很长时间。
* 如今不借助修改或代理游玩Indev，可能会被踢回主菜单或导致游戏崩溃，但仍有几个早期版本可正常运行。
* Indev的[基岩](基岩.md)层没有间隙，Classic也是如此，直到[Infdev](Java版Infdev.md)与[Alpha](Java版Alpha.md)（1.2.0之前）才出现间隙。
* 在Indev和[Infdev](Java版Infdev.md)中，打开[物品栏](物品栏.md)（或[工作台](工作台.md)、[箱子](箱子.md)、[熔炉](熔炉.md)）时，第一人称视角下玩家的手臂会缓慢来回摆动，且此时可随意走动。走动时手臂会像第三人称视角中那样随机翻转，关闭物品栏后，手臂会暂停在翻转时的位置，重新打开物品栏可恢复正常。
* Indev版本的世界外围是不可操作的超平坦世界，其超平坦代码为：<code>31*minecraft:bedrock,1*minecraft:grass_block</code>。玩家在世界边缘之外会被缓慢推回，且距离地图越远，推回速度越快，但这一现象在Indev 0.31中不会出现。
* 现在游玩Indev有声音，而Infdev没有，因为Infdev的资源已从minecraft.net/resources中移除。
* 在Indev的文件中，能找到一张名为的图片，该图片与任天堂NES主机中的图片相同。
* 如今游玩Indev，玩家皮肤会变成黑色，这是由于Mojang移除了对Indev皮肤的支持；但断网后，皮肤会变成史蒂夫而非黑色。
* Indev中，生物受伤的声音与玩家相同。
* 在早期的Indev中，物品栏上的玩家模型是拉娜，但这只是一个占位符。
* 创建世界时选择“Floating”世界主题，有时会导致游戏崩溃。
* 在[Indev 0.31](Java版Indev 0.31.md)的早期版本中，试图创建“巨大”规模的世界，总会导致游戏崩溃或异常卡顿。
* 玩家攻击绵羊时，可能会触发一个罕见漏洞，导致绵羊掉落品红色羊毛而非灰色羊毛。
* 若玩家创建地狱主题的世界，生成点的光照会明显暗于正常世界，这会使生物更容易生成，且世界会被熔岩环绕。
* Indev在启动器中无法找到任何版本。
