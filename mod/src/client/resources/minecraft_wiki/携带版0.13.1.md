# 携带版0.13.1

*页面ID: 19191* | *来源: Minecraft Wiki*

* *v0.13.1 alpha**是携带版的一次次要更新，发布于2015年12月16日，加入了新的皮肤包，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[皮肤包](皮肤包.md)**
* 加入了[2015节假日皮肤包](皮肤包#2015节假日皮肤包（Holiday Skin Pack 2015）.md)。

# 更改
# = 常规 =
* *[主菜单](主菜单.md)**
* 把“皮肤”和“选项”的按钮移至主菜单中部。
* 选项按钮不再是扳手图标。
* * 增加按钮的大小。
* * 选项菜单中的左侧现在有三个选项，而不是四个。
