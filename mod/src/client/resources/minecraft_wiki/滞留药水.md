* *滞留药水（Lingering Potion）**是[药水](药水.md)的可抛掷变种，会在破裂后留下[区域效果云](区域效果云.md)。

# 获取
# = 酿造 =

向喷溅药水加入[龙息](龙息.md)能酿造滞留药水。酿造出的滞留药水显示的时长（若有）与原喷溅药水相同。

、无法通过酿造获得，只能通过命令或[创造模式物品栏](创造模式物品栏.md)获得。

# = 箱子战利品 =

由于滞留药水的最大堆叠数量为1，数量大于1的堆叠会被展开为对应数量的单个物品堆叠。

# 用途
# = 投掷 =
滞留药水可以将其投掷出去，生成弹射物。

[发射器](发射器.md)也可以射出滞留药水。

滞留药水被投掷后会破裂而不会返还空瓶。

# = 合成材料 =

# = 和泥 =
对[泥土](泥土.md)、[缠根泥土](缠根泥土.md)或[砂土](砂土.md)滞留型水瓶可使其转变为[泥巴](泥巴.md)，并返还[玻璃瓶](玻璃瓶.md)。[发射器](发射器.md)对这些方块发射滞留型水瓶仍会生成弹射物，而非将其转变。

# = 填充炼药锅 =

对[炼药锅](炼药锅.md)滞留药水可使炼药锅提升两级药水位，同时把手持的滞留药水变为玻璃瓶。如果炼药锅盛有[状态效果](状态效果.md)、效果等级与该滞留药水不同的药水，或是其他物质，进行此操作则会导致炼药锅被清空，并产生爆炸的音效和粒子。

# = 不可合成的滞留型药水 =

不可合成的滞留型药水是药水效果是无药水效果的滞留药水，它不能在生存模式获取。它也有药水、喷溅药水和药箭的版本。

# 行为
滞留药水是一种[弹射物](弹射物.md)，可以触发[标靶](标靶.md)。

滞留药水会受到重力影响和环境阻力的影响。

滞留药水穿过[火](火.md)或[熔岩](熔岩.md)不会[着火](着火.md)，则会。

# = 生成区域效果云 =

滞留药水在撞击后破裂，创造出一片区域效果云。药水云由对应效果的药水粒子组成。与喷溅药水不同，处于滞留药水的药水云中任何一处得到的效果都相同，且均为最大效果。

由滞留药水生成的区域效果云的初始半径为3格，并在30秒内渐渐缩小到0。

滞留型[基础药水](基础药水.md)破裂时会生成蓝色的区域效果云，这种区域效果云会以稍长的间隔产生下列三种作用：
* 为其中[着火](着火.md)的生物灭火，除非其处于[熔岩](熔岩.md)。
* 对其中的[末影人](末影人.md)、[烈焰人](烈焰人.md)、[雪傀儡](雪傀儡.md)和[炽足兽](炽足兽.md)造成伤害。
* 为其中的[美西螈](美西螈.md)恢复的氧气值。

若这种区域效果云多片重叠，其灭火效果不会良好地叠加，伤害效果则几乎不叠加。

除了具有以上行为外，滞留型水瓶还会在碎裂时扑灭扔中及与其水平相邻的方块上的[火](火.md)、[营火](营火.md)和[灵魂营火](灵魂营火.md)。

滞留型基础药水不会产生区域效果云，表现类似于其对应的喷溅型基础药水，其中滞留型水瓶会扑灭扔中及与其水平相邻的方块上的火、营火和灵魂营火，且会在欧几里得距离4格内产生如下影响：
* 为着火的生物灭火。
* 将点亮的[蜡烛](蜡烛.md)熄灭。
* 对烈焰人、末影人、雪傀儡和炽足兽造成的伤害。
* * 然而，如果滞留型水瓶直接砸向末影人，末影人会瞬移而不被命中。
* 使美西螈的氧气值恢复。

# = 与方块交互 =
滞留药水可以触发其击中的[标靶](标靶.md)、敲响[钟](钟.md)或击塌[大型垂滴叶](大型垂滴叶.md)。

滞留药水可以激活[木质压力板](木质压力板.md)和[绊线](绊线.md)。当滞留药水穿过这些方块时，这些开关会保持开启状态。其他开关则不受滞留药水的影响。
