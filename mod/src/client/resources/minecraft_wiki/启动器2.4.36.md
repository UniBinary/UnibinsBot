# 启动器2.4.36

*页面ID: 103859* | *来源: Minecraft Wiki*

* *2.4.36**是一次[启动器](启动器.md)更新，发布于2023年4月17日。

# 新内容
* [Minecraft Legends](Minecraft Legends.md)现已在启动器中正式发行。

# 更改
* 改进了启动器更新的流程。

# 修复
*  - “开始游戏按钮哪去了！？”消息中的“了解更多”按钮无法完整显示。
*  - 《Minecraft Dungeons》页面的“开始游戏”按钮与其他页面不对齐。
*  - 启动器中的游戏错误消息无法被翻译。
*  - 字符串的游戏名之间中缺少一个分号。
*  - 字符串中缺少变量。
*  - 《Minecraft：Java版》和《Minecraft Dungeons》促销界面的“立即购买！”字符串无法被翻译。
