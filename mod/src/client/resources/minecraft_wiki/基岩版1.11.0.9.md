# 基岩版1.11.0.9

*页面ID: 42040* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.11.0.9**是[1.11.0](基岩版1.11.0.md)的第7个测试版，发布于2019年4月3日，修复了一些漏洞。<ref></ref>

# 更改
# = 方块 =
* *[绊线](绊线.md)**
* 更改了纹理。

# 修复
* *修复了20个漏洞**<br>
* *崩溃**
* 修复了在没有血量的实体（船和拴绳等）上使用血量组件时脚本崩溃的问题。
* 修复了当主用户正在退出，其他用户正在加入当前世界时可能发生的崩溃问题。
* 修复了获得不祥之兆效果时可能发生的崩溃。
* 修复了游戏进行时的崩溃现象。

* *常规**
* 在Nintendo Switch上调整按键时，现在会正确地显示按键工具提示。
* 修复了Switch上会阻止命令按钮在运行命令或打字聊天后工作的漏洞。
* 玩家现在可以在游戏中的扩展皮肤包列表中选择马里奥皮肤。
* 皮肤选择器里的皮肤包不再受限于15个。
* 现在可以在设置中正确地切换Switch上的按键。
* 文本转语音功能现在会在Switch上保持同步。
* 文本转语音功能现在会正确地读取模型弹出窗口上的文字。
* 玩家可以在Switch上离线查看皮肤选择菜单，而无需连接互联网。

* *游戏内容**
* TNT爆炸时会击退正在被治愈的玩家。
* 与砂轮交互时不再“使用”玩家手持的物品。

* *方块**
* 海草生长时不能再破坏它上面的方块。（）

* *生物**
* 怪物会正确地在冰原生物群系中生成。

* *图形**
* 更改了绊线的纹理。
* 音高粒子颜色现在和音符盒的音高一致。
* 回退了音高粒子的颜色渲染系统。

* *命令**
* 使用命令时，即使方块没有任何值也不再报错。</onlyinclude>
