# Java版23w14a

*页面ID: 103589* | *来源: Minecraft Wiki*

<onlyinclude>

* *23w14a**是[Java版1.20](Java版1.20.md)的第3个快照，发布于2023年4月5日<ref></ref>，更换了[全景图](全景图.md)与游戏[徽标](徽标.md)，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[标签](Java版标签.md)**
* 加入了以下方块标签：
* * ：
* ** 此处定义的方块可以增加[附魔台](附魔台.md)的最大附魔等级。
* * ：
* ** 此处定义的方块不会阻断对附魔台的附魔等级增益。
* * ：。
* * ：。
* ** 此处定义的方块能被长成的[树木](树木.md)替换。
* * ：。
* ** 此处定义的方块可以用[剑](剑.md)更快地破坏。

# 更改
# = 方块 =
* *[紫水晶块](紫水晶块.md)**
* 加入到[创造模式物品栏](创造模式物品栏.md)中的“红石方块”标签页。

* *[大型箱子](大型箱子.md)和[大型陷阱箱](大型陷阱箱.md)**
* 略微更改了纹理。

* *[按钮](按钮.md)**
* 更改了模型UV映射。

* *[校频幽匿感测体](校频幽匿感测体.md)**
* 现在被激活时会发光，与幽匿感测体一致。
* 振动感测距离由8格提升至16格。
* 激活冷却时间由2秒调整至1秒。
* 接收红石信号的方式与其他红石元件更加一致，例如信号可以在被1格方块相隔的情况下被接收。
* 调整了红石信号输出方式，使其更适合距离计算。
* 现在会强充能下方的方块。
* 现在可以检测[嗅探兽](嗅探兽.md)刨挖种子的事件。

* *[饰纹陶罐](饰纹陶罐.md)**
* 现在可以通过一般途径含水。

* *[附魔台](附魔台.md)**
* 现在多数非固体方块不会阻断[书架](书架.md)对附魔台的附魔等级增益。

* *[悬挂式告示牌](悬挂式告示牌.md)**
* 每行文本的字符限制由8字符更改为12字符。<ref></ref>

* *[漏斗](漏斗.md)**
* 更改了底面纹理。

* *[瓶子草植株](瓶子草植株.md)**
* 现在可以被[劫掠兽](劫掠兽.md)破坏。
* 现在判定箱大小会根据生长阶段变化。

* *[瓶子草](瓶子草.md)**
* 现在能合成出2个青色染料，而不是1个。
* 现在在创造模式物品栏中与其他大型花列在一起。

* *[紫色带釉陶瓦](紫色带釉陶瓦.md)**
* 略微更改了纹理，使剑的图案契合[纹理更新](纹理更新.md)后的剑纹理。

* *[幽匿感测体](幽匿感测体.md)**
* 调整了红石信号输出方式，使其更适合距离计算。
* 现在会强充能下方的方块。
* 现在可以检测[嗅探兽](嗅探兽.md)刨挖种子的事件。

* *[幽匿尖啸体](幽匿尖啸体.md)**
* 现在能检测到[紫水晶块](紫水晶块.md)的共振。
* 现在会在[含水](含水.md)时静音。
* 加入到创造模式物品栏中的“红石方块”标签页。

* *[告示牌](告示牌.md)**
* 现在内容包含可点击命令的告示牌在未涂蜡的状态下也可交互了。
* 内容包含非的聊天组件的告示牌不再能编辑了。
* 玩家远离告示牌而关闭编辑界面时，已有编辑内容现在会被保存。

* *[可疑的沙砾](可疑的沙砾.md)**
* 分配了[合适挖掘工具](合适挖掘工具.md)，现在为[锹](锹.md)。
* 现在可以在上方种植[竹子](竹子.md)。

* *[可疑的沙子](可疑的沙子.md)**
* 分配了合适挖掘工具，现在为锹。
* 现在可以在上方种植[仙人掌](仙人掌.md)和[甘蔗](甘蔗.md)。
* 幽匿类方块蔓延时，可疑的沙子不再被替换。

* *[火把花](火把花.md)**
* 现在在创造模式物品栏中与其他小型[花](花.md)列在一起。

# = 物品 =
* *[刷子](刷子.md)**
* 刷扫方块的音量大小现在由“方块”音量滑块而非“玩家”音量滑块控制。

# = 生物 =
* *[猫](猫.md)**
* 略微调整了尾巴的位置。
* 略微更改了西服猫的纹理。

* *[嗅探兽](嗅探兽.md)**
* 现在能被[火把花种子](火把花种子.md)吸引。
* 现在其名称会出现在模型上方的正确位置，先前是出现在模型内部。
* 现在能刨挖[泥巴](泥巴.md)。
* 现在产出[嗅探兽蛋](嗅探兽蛋.md)时会发出声音。
* 现在幼年嗅探兽嗅探时的声音会有不一样的音高，与其他幼年生物类似。

* *[村民](村民.md)**
* 现在能捡起火把花种子和瓶子草荚果。
* 略微更改了沙漠村民手臂和草鞋上的纹理。

* *[监守者](监守者.md)**
* 现在能检测到[紫水晶块](紫水晶块.md)的共振。

* *[僵尸村民](僵尸村民.md)**
* 更改了沙漠僵尸村民手臂的纹理。

# = 世界生成 =
* *[沙漠神殿](沙漠神殿.md)**
* 地窖的顶部坍塌程度加大，并且现在最上层一定会露出一个[可疑的沙子](可疑的沙子.md)。
