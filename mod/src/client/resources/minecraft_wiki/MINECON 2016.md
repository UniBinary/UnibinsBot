# MINECON 2016

*页面ID: 36336* | *来源: Minecraft Wiki*

* *MINECON 2016**于2016年9月24至25日期间在美国加利福尼亚州的安纳海姆举行。

# 宣布
2016年3月7日，官方宣布MINECON 2016将于9月24-25日在加利福尼亚洲的安纳海姆举行。<ref>[MineCon 2016 Announcement](https://www.youtube.com/watch?v=1nP328vm5ik)</ref>
</ref>|Mojang logo.svg}}

2016年4月18日，[MINECON主页](https://minecon.minecraft.net)发布，显示售票日的倒计时。[折扣酒店的信息](https://registration.experientevent.com/ShowMCO161/Flow/ATTENDEE#/registrant//Dashboard/)也随之公布。

2016年8月12日，宣布了MINECON 2016上有关于携带版插件API的新闻。<ref></ref><ref></ref><ref></ref>

# 地点
MINECON 2016在美国加利福尼亚洲的安纳海姆会议中心举行。

会议中心地-{}-址：加利福尼亚州安纳海姆市西卡特拉大道800号<ref>http://www.anaheim.net/1117/Anaheim-Convention-Center-Arena</ref>

MINECON 2016在安纳海姆会议中心里的位置是展厅A和D，建议的入口为较低楼层的展厅E。

# 票务
2016年4月18日，Mojang宣布门票将在5月6-7日[销售](https://www.eventbrite.com/e/minecon-2016-tickets-25082871544)。<ref name=2016Tix>http://mojang.com/2016/04/minecon-2016-tickets/</ref><ref>https://www.eventbrite.com/e/minecon-2016-tickets-25082871544</ref>门票分两批发售，每批各6000张，每张160美元，共12000张<ref name=2016Tix/>。参与者同时获得折扣酒店的信息。<ref>https://registration.experientevent.com/ShowMCO161/Flow/ATTENDEE#/registrant//Dashboard/</ref>

; 批次
* 第一批：太平洋标准时间5月6日18点
* 第二批：太平洋标准时间5月7日12点
