# 钟

*页面ID: 37004* | *来源: Minecraft Wiki*

* *钟（Bell）**是在时会发出声响的方块。与大部分功能方块不同，钟无法通过[合成](合成.md)获取。

# 生成
# = 自然生成 =
钟会在[村庄](村庄.md)中生成，通常会生成在村庄中心的[会合点](村庄/结构/图示#会合点1.md)附近。

# 破坏
挖掘钟的合适工具是镐。

钟被破坏后会掉落自身。

# 用途
[缩略图|右|200px|钟被敲响时的动画](File:Bell gongs.gif.md)
钟只能被放置在一个方块[中心完整](方块支撑形状.md)的底面下方或完整的上表面和侧面上。

当钟的侧面被时，钟会摇晃并发出响声。钟只能从侧面敲响。

钟被红石信号激活、处于[风爆](爆炸#风爆.md)影响范围中、被任何[弹射物](弹射物.md)或撞击时会被敲响。

# = 红石元件 =
钟是[机械元件](红石元件#机械元件.md)，可被下列形式激活：
* 毗邻的开启的**[电源](红石元件#电源.md)**（例外：[侦测器](侦测器.md)只会激活指向的钟）。
* 毗邻的**[充能方块](红石电路/充能与激活.md)**。
* 毗邻的指向钟且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)；毗邻但未指向钟的红石粉不会激活钟。

：
* 在同一红石刻内，电容器更新阶段前存在，但在电容器更新阶段被取消的信号无法激活钟。
* 钟可主动引导毗邻的红石粉激活自身，但完全不会改变其指向（亦不会被弱充能，除非红石粉原有指向即可弱充能钟）。

# = 村庄 =
当钟被放置在被[村民](村民.md)认领的[床](床.md)附近时，钟会被认领，此时钟的上方会出现[绿色粒子效果](粒子#happy_villager.md)。被认领的钟定义了一个[村庄](村庄.md)的会合点。

钟被用作村庄的警报系统。当钟响起时，会警告附近的村民使其立即停止工作或睡觉等活动，并立即跑到其认领的床，没有认领床的村民会跑到最近的床。钟被敲响后30秒才能恢复正常的行为。1个钟的有效警告范围是31×31×31矩形区域。钟声的传播范围比有效警告范围小，为29×29×29矩形区域。

在[袭击](袭击.md)准备开始时，至少有一名村民会在距离足够的情况下冲向钟并将其敲响，以向所有村民警告袭击的发生。

在袭击准备开始时，村庄中的钟会自动鸣响，而非由村民敲响。

# = 回响 =

钟被敲响后，以钟为中心半径48格内的[灾厄村民](灾厄村民.md)、[劫掠兽](劫掠兽.md)和[女巫](女巫.md)都会获得的[发光](发光.md)效果，并发出大量的[黄色粒子](粒子#entity_effect.md)，且此时钟会产生回响声。

持续不断地敲击一个钟并不会导致回响重复发生，除非停止敲击。

# = 猪灵 =
[猪灵](猪灵.md)能够被掉落的钟吸引，会主动捡起并端详或，随后放入自己的物品栏，但破坏钟不会激怒它们。

# 你知道吗
* 一些村庄会生成不止一个钟，但村民只需要其中一个来集会和生成[铁傀儡](铁傀儡.md)。
* [滑翔](滑翔.md)的玩家使用[烟花火箭](烟花火箭.md)加速时，撞击钟侧面的边缘会使钟发出响声。
* ：
* * 钟曾有未使用的数据值，只有侧面纹理（钟架）却没有钟，且不能发出响声。
* * 钟会打偏任何撞击时不会消失的弹射物（如[箭](箭.md)和[三叉戟](三叉戟.md)）。
* * 村民在钟附近扔给其他[村民](村民.md)食物时，掉落物有一定概率击中钟，导致所有村民逃跑。
