* *调试选项档案文件**是游戏记录[调试选项](调试屏幕#调试选项屏幕.md)的游戏配置文件。

# 存储格式
调试选项档案文件位于。此文件使用JSON文件格式保存，并具有下列结构：

<div class="treeview">
*  JSON文件根对象
* * ：玩家自定义的调试选项档案。
* ** ：此项调试选项的状态。取值只能为<code>alwaysOn</code>（）、<code>inOverlay</code>（）或<code>never</code>（）。
* * ：游戏内置的调试选项档案。取值只能为<code>default</code>（）或<code>performance</code>（）。

# 存储行为
游戏在游戏启动时会尝试读取调试选项档案文件，以获取调试选项配置。

* 如果调试选项档案文件不存在，则游戏静默处理，并使用默认配置。
* 如果调试选项档案文件存在，则加载此文件：
* * 如果文件无法加载，或文件格式错误，则游戏日志报错<code>-{}-Couldn't read debug profile file <*此文件*>, resetting to default</code>，并重置调试配置为默认配置。
* * 如果存在，则直接使用其指定的调试选项档案配置。
* * 否则，读取的内容加载调试选项，任何未指定的调试选项均被视为<code>never</code>。

只要玩家对调试选项进行了任何更改，此文件就会立刻保存。

* 如果文件无法保存，则游戏日志报错<code>-{}-Failed to save debug profile file <*此文件*></code>，并重置调试配置为默认配置。
