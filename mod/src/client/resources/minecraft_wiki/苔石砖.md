# 苔石砖

*页面ID: 6023* | *来源: Minecraft Wiki*

* *苔石砖（Mossy Stone Bricks）**是[石砖](石砖.md)制作的装饰性方块。

# 生成
# = 自然生成 =
苔石砖会生成在[要塞](要塞.md)、[海底废墟](海底废墟.md)、[雪屋](雪屋.md)地下室和[主世界](主世界.md)的部分[废弃传送门](废弃传送门.md)中。

# 获取
# = 合成 =

# = 虫蚀的方块 =
被具有[精准采集](精准采集.md)的工具挖掘破坏时，[虫蚀苔石砖](虫蚀苔石砖.md)被破坏后会掉落苔石砖，不会生成蠹虫。

# 破坏
挖掘苔石砖的合适工具是镐。苔石砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

苔石砖被破坏后会掉落自身。
