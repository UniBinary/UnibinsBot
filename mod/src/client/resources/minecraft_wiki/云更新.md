# 云更新

*页面ID: 126017* | *来源: Minecraft Wiki*

[缩略图|云更新的更新横幅](File:Cloud Update banner.jpg.md)

* *云更新（Cloud Update）**是的一次主要更新，其正式版[1.21.03](教育版1.21.03.md)发布于2024年7月23日。<ref></ref>此次更新加入了[蝙蝠与陶罐](蝙蝠与陶罐.md)、[犰甲狼兵](犰甲狼兵.md)和[棘巧试炼](棘巧试炼.md)的特性以及云世界备份与上传功能。

# 重要特性

* 加入了[蝙蝠与陶罐](蝙蝠与陶罐.md)、[犰甲狼兵](犰甲狼兵.md)和[棘巧试炼](棘巧试炼.md)的特性。

* *游戏内容**
* [气球](气球.md)和[荧光棒](荧光棒.md)等[化学](化学.md)相关物品现在会出现在创造模式物品栏中。

* *常规**
* 当世界作为备份而关闭时，该世界会自动上传至OneDrive。<ref></ref>

# 跟进版本
* [1.21.05](教育版1.21.05.md)发布以为macOS和iOS/iPadOS平台加入对云世界备份的支持，并修复一些漏洞。
* [1.21.06](教育版1.21.06.md)发布以优化编写代码的性能。
* [1.21.10](教育版1.21.10.md)发布以修复一些漏洞。
