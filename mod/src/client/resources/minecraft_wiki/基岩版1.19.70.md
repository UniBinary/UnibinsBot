# 基岩版1.19.70

*页面ID: 101352* | *来源: Minecraft Wiki*

* *1.19.70**是的一次次要更新，也是ChromeOS平台的首次更新，发布于2023年3月14日至15日<ref></ref>。此次更新同步了一些的特性，在[实验性玩法](实验性玩法.md)中加入了更多[1.20.0](基岩版1.20.0.md)的特性，并修复了一些漏洞。

* *[实验性玩法](实验性玩法.md)**
* 加入了“嗅探器”子选项。
* * 用于启用[嗅探兽](嗅探兽.md)相关特性。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”、“嗅探器”、“即将推出的创作者功能”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[饰纹陶罐](饰纹陶罐.md)**
* 在合成表中使用4个[陶片](陶片.md)或[红砖](红砖.md)摆成菱形以合成。
* * 陶片的种类决定了输出陶罐的对应面出现何种图案，使用红砖则没有图案。
* 非常容易被破坏。
* * 使用[剑](剑.md)、[镐](镐.md)、[锹](锹.md)、[锄](锄.md)、[斧](斧.md)或[三叉戟](三叉戟.md)进行破坏，会碎裂成其原先的合成材料。
* * 徒手破坏、被活塞推动和使用附有[精准采集](精准采集.md)魔咒的工具破坏时掉落自身。

* *[可疑的沙子](可疑的沙子.md)**
* 与[沙子](沙子.md)相似，但纹理看起来更粗糙。
* 受重力影响，会在落地时消失。
* 被挖掘或被活塞推动时不掉落任何物品，用附有精准采集的工具挖掘也不会掉落。
* 会在[沙漠神殿](沙漠神殿.md)和[沙漠水井](沙漠水井.md)中自然生成，两处生成的可疑的沙子带有的战利品表不同。
* 用[刷子](刷子.md)刷可疑的沙子可以刷出物品。
* * 清刷时，可疑的沙子会经历4个阶段，若中途停止，会逐渐恢复原状。
* * 清刷完成后，可疑的沙子会消失。
* * 带有有效战利品表的可疑的沙子才能刷出物品。

* *[火把花植株](火把花植株.md)**
* 可用火把花种子在[耕地](耕地.md)上种出。
* 共有3个生长阶段，完全成熟时变为火把花。
* 若完全成熟，破坏时掉落火把花；若未完全成熟，破坏时掉落火把花种子。

* *[火把花](火把花.md)**
* 一种新的植物。
* 可用于合成[橙色染料](橙色染料.md)。
* 可以放置在[花盆](花盆.md)中。

* *[猪灵的头](猪灵的头.md)和[龙首](龙首.md)**
* 现在物品栏和快捷栏中的猪灵的头会正确渲染耳朵的位置，使其不再覆盖头部。（）
* 不再会在快捷栏或物品栏中显示动画。（、）

* *[竹栅栏](竹栅栏.md)和[竹栅栏门](竹栅栏门.md)**
* 移除了边缘的黑线。（）

* *[悬挂式告示牌](悬挂式告示牌.md)**
* 现在悬挂式红树木告示牌和悬挂式竹告示牌正确位于创造模式物品栏中。（）

* *[结构方块](结构方块.md)**
* 现在使用结构方块将实验性方块导入非实验性世界时，实验性方块会被正确替换为不可交互的[未知方块](未知方块.md)。

# = 物品 =
* *[刷子](刷子.md)**
* 用于清刷方块的物品。
* 使用3根[线](线.md)和2个[木棍](木棍.md)合成，摆放方式类似于[镐](镐.md)。
* 成功刷出物品时消耗1点耐久。
* 对可疑的沙子外的其他方块没有实际效果。

* *[陶片](陶片.md)**
* 共有四种，分别为弓箭纹样、举臂纹样、珍宝纹样和头颅纹样。
* 无法合成，只能通过刷可疑的沙子来获得。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了嗅探兽刷怪蛋。

* *[火把花种子](火把花种子.md)**
* 一种新的种子，可以种植在[耕地](耕地.md)上。
* 可通过嗅探兽挖掘获得。

# = 生物 =
* *[嗅探兽](嗅探兽.md)**
* [Minecraft Live 2022](Minecraft Live 2022.md)生物投票的获胜生物，属于友好生物，体型很大。
* 有点生命值。
* 目前不会自然生成。
* 不会被食物吸引，不能被驯服。
* 时常嗅探空气，有时能挖掘出火把花种子。
* * 有8分钟冷却时间。
* * 最近被挖掘过的20个方块会被记录，并且不再寻求挖掘这些方块。
* 可以使用火把花种子喂养和繁殖。

* *[骆驼](骆驼.md)**
* 现在玩家在骑乘骆驼时能够受到摔落伤害。
* 现在再次可以走上碰撞箱为1.5格高的方块。（）

# = 世界生成 =
* *[沙漠神殿](沙漠神殿.md)**
* 更改了结构，现在会有一个填满沙子和可疑的沙子的新空间。
* * 一些沙子会暴露在外，可以在与[蓝色陶瓦](蓝色陶瓦.md)等高的位置上找到。

* *[沙漠水井](沙漠水井.md)**
* 现在可疑的沙子会生成在其水下。
