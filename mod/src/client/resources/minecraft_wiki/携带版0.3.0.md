# 携带版0.3.0

*页面ID: 21023* | *来源: Minecraft Wiki*

* *v0.3.0 alpha**是[携带版](携带版.md)的一次主要更新，发布于2012年4月23日及2012年4月24日。<ref>https://web.archive.org/web/20120504163040/http://itunes.apple.com/us/app/id479516143?mt=8</ref><ref>http://web.archive.org/web/20120427014353/https://play.google.com/store/apps/details?id=com.mojang.minecraftpe</ref>其加入了一些值得注意的特性，例如[合成](合成.md)、新[生物](生物.md)、[方块](方块.md)、[物品](物品.md)和[工具](工具.md)，以及其他更改和修复。<ref></ref>

v0.3.0 alpha于2012年4月24日重新发布以修复一个启动时崩溃的漏洞，其后又再次重新发布以加入更多的物品栏空间和更小的GUI，同时也修复了一个关于图标的漏洞。

# 新内容
# = 方块 =
* *[工作台](工作台.md)**
* 允许玩家合成更多种类的方块和物品。
* 可以使用[木板](木板.md)合成。

* *[铁矿石](铁矿石.md)**
* 一种可以在地下发现的矿石。
* 需要使用[石镐](石镐.md)进行挖掘。
* 目前没有任何用途。

* *[红砖台阶](红砖台阶.md)**
* [红砖块](红砖块.md)的半格高变种，可用红砖块合成。

* *[红砖楼梯](红砖楼梯.md)**
* 红砖块的楼梯变种，可用红砖块合成。

# = 物品 =
* *[雪球](雪球.md)**
* 由[雪](雪.md)和[雪块](雪块.md)掉落。
* 可用于合成[雪块](雪块.md)。

* *[木棍](木棍.md)**
* 可用于合成很多[工具](工具.md)和[物品](物品.md)。
* 可以使用[木板](木板.md)合成。

* *[蒲公英黄](蒲公英黄.md)**
* 可用于合成[黄色羊毛](黄色羊毛.md)。
* 可以使用[蒲公英](蒲公英.md)合成。

* *[碗](碗.md)**
* 目前没有任何用途。
* 可以使用[木板](木板.md)合成。

* *[糖](糖.md)**
* 目前没有任何用途。
* 可以使用[甘蔗](甘蔗.md)合成。

* *[书](书.md)**
* 可用于合成[书架](书架.md)。
* 可以使用[纸](纸.md)合成。

* *[纸](纸.md)**
* 可用于合成[书](书.md)。
* 可以使用[甘蔗](甘蔗.md)合成。

* *[煤炭](煤炭.md)**
* 可用[镐](镐.md)从[煤矿石](煤矿石.md)中获得。
* 可用于合成[火把](火把.md)。

* *[青金石](青金石.md)**
* 可用[石镐](石镐.md)从[青金石矿石](青金石矿石.md)中获得。
* 可用于合成[蓝色羊毛](蓝色羊毛.md)。

* *木质[工具](工具.md)**
* 与用手相比，可以更快、更有效地执行某些操作，但不如石质工具有效，并且耐久度远低于石质工具。
* [木斧](木斧.md)
* [木锹](木锹.md)
* [木镐](木镐.md)
* [木剑](木剑.md)

* *[木炭](木炭.md)、[线](线.md)、[羽毛](羽毛.md)、[箭](箭.md)、[骨头](骨头.md)、[](黏土球.md)、[红砖](红砖.md)以及除蒲公英黄、青金石外的14种[染料](染料.md)**
* 目前没有任何用途。
* 目前在生存模式下无法获得。

# = 生物 =
* *[牛](牛.md)**
* 一种常见的被动型[生物](生物.md)。
* 死亡时不掉落任何物品。

* *[鸡](鸡.md)**
* 一种常见的被动型生物。
* 死亡时不掉落任何物品。

# = 游戏内容 =
* 新的[音效](音效.md)

* *[物品栏](物品栏.md)**
* 物品栏现在有了背景方格。
* 生存模式物品栏现在有了2×2合成格。

* *[合成](合成.md)**
* 让玩家能够合成方块和物品。
* 使用独有的Minecraft高级触屏技术界面系统（Minecraft Advanced Touch Technology Interface System，MATTIS）合成系统。

# 更改
# = 非生物实体 =
* *[摄像机](摄像机.md)**
* 现在可用物品栏编辑器来获得。

# = 游戏内容 =
* *[生存模式](生存模式.md)**
* 所有物品现在都可以收集（[剪刀](剪刀.md)、[红砖块](红砖块.md)和[玻璃](玻璃.md)除外）。

* *[物品栏](物品栏.md)**
* 玩家不再能够无限堆叠[石锹](石锹.md)、[石镐](石镐.md)、[石斧](石斧.md)、[剪刀](剪刀.md)、[石剑](石剑.md)、[梯子](梯子.md)、[火把](火把.md)、[木门](木门.md)、[栅栏](栅栏.md)、[栅栏门](栅栏门.md)、[木板](木板.md)、[红砖](红砖.md)、[楼梯](楼梯.md)、[台阶](台阶.md)、[玻璃](玻璃.md)、[树叶](树叶.md)和[羊毛](羊毛.md)。

* *[创造模式物品栏](创造模式物品栏.md)**
* 加入了[红砖楼梯](红砖楼梯.md)、[木质台阶](木质台阶.md)、[红砖台阶](红砖台阶.md)、[橙色羊毛](橙色羊毛.md)、[品红色羊毛](品红色羊毛.md)和[工作台](工作台.md)。

# 内部版本
v0.3.0 alpha的内部版本号为0.3.0(3007)，大小为6.06MB。

# 你知道吗
v0.3.1 alpha似乎并不存在，版本号从0.3.0直接跳到了0.3.2。由于0.3.0的第二次重新发布增加了功能，而非像大多数其他重新发布一样只解决了崩溃问题，所以其可能会被追溯为0.3.1。
