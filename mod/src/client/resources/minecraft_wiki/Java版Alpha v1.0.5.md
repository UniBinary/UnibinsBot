# Java版Alpha v1.0.5

*页面ID: 32488* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.5**是的一次更新，发布于2010年7月13日<ref></ref>，加入了[雪球](雪球.md)和[雪块](雪块.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[雪块](雪块.md)**
* 挖掘后掉落6个雪球。
* 需要9个雪球来[合成](合成.md)。

# = 物品 =
* *[雪球](雪球.md)**
* 可以抛出去，但不会造成任何[伤害](伤害.md)。
* 可以堆叠至64个。

# 更改
# = 方块 =
* *[告示牌](告示牌.md)**
* 放置告示牌时上方不需要是空气了。

* *[冰](冰.md)**
* [硬度](硬度.md)由0.1提升到0.5。

* *[雪](雪.md)**
* [挖掘](挖掘.md)后会掉落雪球。

# = 游戏内容 =
* *[第三人称视角](第三人称视角.md)**
* 不再会产生降雨粒子。

# = 常规 =
* *世界保存**
* 游戏不再在崩溃时保存。

# 修复
* *修复了2个漏洞**
* 修复了在雪上建造的漏洞。
* 修复了冰的渲染问题。

# 重新上传
该版本的客户端于21:49（UTC）被重新上传，雪不再能放置在[玻璃](玻璃.md)上了。</onlyinclude>
