* *盔甲（Armor）**是可由生物穿戴的[物品](物品.md)。盔甲在被装备后能给予穿戴者不同等级的保护，减少常见类型的伤害，并呈现在穿戴者的外观上。它能放置在玩家[物品栏](物品栏.md)的指定盔甲栏。

盔甲可按部位分为**头盔（Helmet）**、**胸甲（Chestplate）**、**护腿（Leggings）**和**靴子（Boots）**4种，可按[盔甲材料](盔甲材料.md)分为**皮革盔甲（Leather Armor）**、**铜盔甲（Copper Armor）**、**锁链盔甲（Chainmail Armor）**、**铁盔甲（Iron Armor）**、**钻石盔甲（Diamond Armor）**、**金盔甲（Golden Armor）**、**下界合金盔甲（Netherite Armor）**和**海龟鳞甲盔甲（Turtle Scute Armor）**8种。

# = 合成 =
制作一整套盔甲一般需要24个相应材料。注意：锁链盔甲和下界合金盔甲无法通过合成获得；海龟壳没有对应的胸甲、护腿和靴子。

# = 锻造 =
下界合金盔甲可通过在[锻造台](锻造台.md)中升级钻石盔甲来获得，耐久度、魔咒和自定义名称等物品数据会被保留。

# == 铁砧 ==

* *材料修复**

每个材料可以恢复盔甲25%的耐久（向下取整）。

锁链盔甲的修复原料视为铁锭，而下界合金盔甲的修复原料视为下界合金锭。

* *合并物品**

叠加两件盔甲的剩余耐久度，再额外获得12%的耐久度，按照[铁砧机制](铁砧机制.md)保留魔咒。

# = 掉落物 =
穿着盔甲生成的[僵尸](僵尸.md)、[骷髅](骷髅.md)及它们的变种在被玩家或驯服的狼杀死时有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落其自然生成时携带的盔甲，盔甲的耐久度是随机的，且有可能携带随机魔咒。它们死亡时必定会掉落它们曾拾起并穿上的盔甲。

猪灵被玩家或驯服的狼杀死时有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落其自然生成时携带的金盔甲，盔甲的耐久度是随机的，且有可能携带随机魔咒。猪灵在死亡时必定会掉落它们曾拾起并穿上的盔甲。

在[袭击](袭击.md)中生成的[掠夺者](掠夺者.md)和[卫道士](卫道士.md)死亡后会根据[难度](难度.md)掉落任意一件铁盔甲，掉落概率在简单和普通难度为16.66%，困难难度为20.51%；带有[魔咒](魔咒.md)的概率在简单难度为0%，普通难度为33.33%，困难难度为50%。这些盔甲具有30%到90%的随机耐久。

# 用途
生物装备盔甲后可获得对伤害的额外防护能力。装备的盔甲是所有生物共有的实体数据的一部分，因此所有生物都可被命令装备盔甲。虽然部分生物不会显示它们装备的盔甲，但装备的盔甲仍然会运作。

要使盔甲保护玩家，玩家需先将盔甲装备到相应的盔甲槽当中。头盔、胸甲、护腿和靴子对应的盔甲槽分别是头部、上身、下身和足部，它们位于[物品栏](物品栏.md)中玩家角色形象的旁边。玩家也可在手持盔甲时按下键来将其装备到身上，如果此时对应的盔甲槽中已经放入了一件盔甲，则两件盔甲会在物品栏中互换位置。在创造模式下按键将盔甲装备到空盔甲槽后会在物品栏中留下一件同样的装备。

由于[海龟壳](海龟壳.md)不能像其他盔甲组成完整的一套，因此不能按成套的装备讨论。如果将其单独与其他头盔相比较，可得知其提供的护甲值与金头盔、锁链头盔和铁头盔提供的护甲值相同，且耐久度介于铁头盔和钻石头盔之间。

下界合金盔甲的[物品实体](物品实体.md)免疫[火焰伤害](伤害#火焰伤害.md)。

# = 外观 =
盔甲被装备时会显示在装备着它们的生物身上，一整套盔甲将会覆盖生物的大部分外观，但生物的头部和手臂仍然是可见的。如果盔甲有[魔咒](魔咒.md)，那么适用于物品的附魔外观效果也会出现在生物穿戴的盔甲外观上。

盔甲可通过被玩家改造来改变它们的外观。

# == 染色 ==
[200px|缩略图|在皮革外套显示两种染料的所有组合](File:dyegraph.png.md)

皮革盔甲可以被染色，且颜色可以混合。持有染色过的皮革盔甲时[炼药锅](炼药锅.md)可以清除其颜色。

# == 盔甲纹饰 ==

盔甲上可以添加盔甲纹饰，但不提升盔甲的防护性能或给予其他功能。

# = 提供属性 =

|游戏中的盔甲条}}

盔甲在被装备时会提供[属性](属性.md)：
* 所有盔甲在被装备时都会提供。
* 钻石盔甲和下界合金盔甲在被装备时会提供。
* * 每件钻石增加2盔甲韧性，整套钻石增加8盔甲韧性。
* * 每件下界合金盔甲增加3盔甲韧性，整套下界合金盔甲增加12盔甲韧性。
* 下界合金盔甲在被装备时会提供。
* * 每件下界合金盔甲增加10%击退抗性，整套下界合金盔甲增加40%击退抗性。

胸甲在同盔甲材料其他盔甲当中提供的护甲值总是最高，其次则是护腿。对于皮革、铁、钻石和下界合金盔甲，靴子和头盔提供的护甲值相同；而对于铜、金和锁链盔甲，头盔比靴子提供的护甲值高。

# = 提供水下呼吸 =
[海龟壳](海龟壳.md)会为没有浸没在水中的生物提供10秒的[水下呼吸效果](水下呼吸（状态效果）.md)。

# = 躲避猪灵 =
成年[猪灵](猪灵.md)不会主动攻击装备了任意金盔甲的玩家。

# = 防止冰冻 =
装备任意皮革盔甲可以防止生物受到[细雪](细雪.md)的冰冻影响。

装备皮革靴子能防止生物陷入细雪，也可让生物在细雪内上下自由移动。

# = 魔咒 =

盔甲可以获得魔咒，其中许多魔咒专用于盔甲。魔咒能额外提供的保护，包括一些护甲值不会保护的伤害，例如摔落伤害或火。透过魔咒减少的伤害不会降低盔甲的耐久度。盔甲的魔咒不会显示在盔甲条。

盔甲的附魔能力取决于它的材料。材料的附魔能力愈高，得到多个和高等级魔咒的概率愈高（详情参见[附魔（物品修饰）](附魔（物品修饰）.md)）。

盔甲可以获得以下魔咒：

[保护](保护.md)、[弹射物保护](弹射物保护.md)、[火焰保护](火焰保护.md)和[爆炸保护](爆炸保护.md)为一组不共存魔咒，[冰霜行者](冰霜行者.md)和[深海探索者](深海探索者.md)为一组不共存魔咒。然而[不祥试炼刷怪笼](不祥试炼刷怪笼.md)生成的生物穿戴的盔甲会同时具有保护、弹射物保护、和火焰保护。<ref name="MC-270636"></ref>

# = 耐久度 =

在[玩家](玩家.md)承受任何可被护甲值防护的伤害时，玩家穿戴中的盔甲会消耗耐久度。详见主条目。

下表则是耐久度与耗费材料数的比值，以靴子为100%的比较基准。

这表示对于相同数量的皮革/铁锭/金锭/钻石，靴子能抵抗的伤害是护腿的1.5倍。因此，虽然胸甲和护腿每单位材料的护甲值较高，但每单位材料的耐久度却比较少。

# = 发射器 =
[发射器](发射器.md)在使用盔甲物品时，会向朝向的1格内有空的适当盔甲槽的[玩家](玩家.md)、[僵尸](僵尸.md)及其变种、[骷髅](骷髅.md)及其变种、、、[猪灵](猪灵.md)、[猪灵蛮兵](猪灵蛮兵.md)或[盔甲架](盔甲架.md)装备盔甲，否则盔甲物品会从发射器中被抛出。

# = 减少下落的方块的伤害 =

下落的[滴水石锥](滴水石锥.md)和下落的[铁砧](铁砧.md)会对下落处的生物造成伤害。如果生物装备了头盔，那么生物受到的伤害会减少四分之一，但头盔会受到大量耐久度损耗。

# 你知道吗
* 将盔甲纹理文件调整成半透明后，在游戏中盔甲显示依然是不透明的。
* [猪灵](猪灵.md)和[僵尸村民](僵尸村民.md)有特殊的盔甲纹理。
* 生物穿上盔甲的顺序是按照“头盔—胸甲—护腿—靴子”的顺序来生成的。比如一个生成了护腿的僵尸就一定穿上了头盔和胸甲。
