# 生成
金合欢木活板门、红树木活板门、樱花木活板门、苍白橡木活板门、竹活板门、绯红木活板门和诡异木活板门不会生成在世界中。

# = 自然生成 =
橡木活板门可以生成在平原村庄、[雪屋](雪屋.md)和[沉船](沉船.md)中。

云杉木活板门可以生成在针叶林村庄和沉船中。

丛林木活板门生成在沙漠村庄的堆肥桶四周以及沉船中。

白桦木和深色橡木活板门可以生成在沉船中。

# 破坏
挖掘木活板门的合适工具是斧。

木活板门被破坏后会掉落自身。

# 用途

玩家可以手动开关木活板门，木活板门也会被[风爆](爆炸#风爆.md)所开关。

熔岩能在木活板门旁的空气方块燃起[火](火.md)，使木活板门看起来像是在燃烧，然而实际上活板门不会烧毁（也不能以任何其他形式烧毁）。

对着木活板门按下键即可将其打开或关闭，处于[风爆](爆炸#风爆.md)影响范围中时也会改变其开关状态。

# = 红石元件 =

被激活的木活板门和仍然可以被玩家或村民手动关闭，但在接收到新的上升沿或之前，活板门不会再次自动打开（即需要将红石信号关闭再开启才能重新控制活板门）。

# = 燃料 =
主世界木活板门和竹活板门可以被用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个活板门可以烧炼1.5个物品。
