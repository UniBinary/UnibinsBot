# 概述
下面的教程会教你在[Minecraft](Minecraft.md)中做很多有用或是有趣的事。如果你是一名刚进入游戏且手足无措的新手，你可以参考本页面中列出的教程。

本页面中作了<u>下划线</u>标记的教程为中文原创教程，它们绝大多数都是中文的用户原创的。如果你对Minecraft比较熟悉，你也可以试着撰写一篇新的教程。注意：编写教程时请遵守[格式指导](MCW:格式指导.md)。请善用[草稿](Help:草稿.md)来持续编写页面使之内容充分。

在你的教程底部需要放置模板和<code>-{}-[[[:Category:中文原创教程]([[:Category:中文原创教程.md)]]</code>分类标签，并请在编写完毕后于本页及模板中添加你的教程的链接。你也可以在找到待翻译的教程。
