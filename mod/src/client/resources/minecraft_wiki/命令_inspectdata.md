# 命令/inspectdata

*页面ID: 57666* | *来源: Minecraft Wiki*

返回指定方向上方块的数据值。

# 语法
   <code>-{}-inspectdata <*方向：字符串*></code>

# 参数
<code>-{}-*方向：字符串*</code>
   指定智能体需要确认方块的数据值的方向。
   必须为一下之一：
  * <code>forward</code>——前方。
  * <code>back</code>——后方。
  * <code>left</code>——左侧。
  * <code>right</code>——右侧。
  * <code>up</code>——上方。
  * <code>down</code>——下方。
