# Java版15w43a

*页面ID: 18703* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w43a**是[Java版1.9](Java版1.9.md)的第34个快照，发布于2015年10月21日<ref></ref>，加入了雪屋、新的NBT标签和战利品表，并通过修复漏洞，使得中文、日文和韩文等依赖于输入法的语言可以直接输入到游戏中。

# 新内容
# = 世界生成 =
* *[雪屋](雪屋.md)**
* 自然生成于[冰原](冰原.md)与[冷针叶林](冷针叶林.md)生物群系（不包括变种）中。
* * 与沙漠神殿、丛林神庙和沼泽小屋共享生成参数：先生成结构的位置，随后根据所在生物群系决定生成何种结构。
* 雪屋有50%的概率包含一个由[石砖](石砖.md)及其变种构成的地下室，其入口隐藏在雪屋的地毯下。
* * 地下室中用铁栏杆分别关押着一个[村民](村民.md)和一个[僵尸村民](僵尸村民.md)，其中僵尸村民带有标签以确保它不会消失。
* * 生成的战利品[箱子](箱子.md)中，有时其中央包含一个[金苹果](金苹果.md)，提示玩家治愈僵尸村民。
* * 生成的[酿造台](酿造台.md)中，总会有一瓶[喷溅型虚弱药水](喷溅型虚弱药水.md)提示玩家用它将僵尸村民转变为村民。
* * 一些石砖属于[怪物蛋](怪物蛋.md)变种，可以释放出[蠹虫](蠹虫.md)。
* 由[Searge](Searge.md)制作（从NBT数据中可以找到）。

# = 命令格式 =
* *[NBT标签](NBT标签.md)**
* [箱子](箱子.md)和[运输矿车](运输矿车.md)：
* * <code>LootTable</code>（字符串）：下一次打开箱子时使用的战利品表。如果这是大箱子的一部分，那么只有一半的标签才会起效。
* * <code>LootTableSeed</code>（长整型）：战利品表生成的种子。0或省略则会用随机的种子。
* ** 例如：{{cmd|setblock *x* *y* *z* minecraft:chest 0 replace {LootTable:"chests/simple_dungeon",LootTableSeed:12345} }}
* [生物](生物.md)：
* * <code>DeathLootTable</code>（字符串）：决定当前生物被杀死后掉落物品的战利品表。
* * <code>DeathLootTableSeed</code>（长整型）：生成战利品表的种子。0或未定义则使用随机种子。

# = 常规 =
* *战利品表**
* 所有生物、箱子等的战利品现在都基于[战利品表](战利品表.md)。这不包括方块掉落物。
* * 地图编辑者可以在{{filepath|-{}-<世界>/data/loot_tables}}文件夹里添加一个文件来改变，然而此功能在43a里不能使用。

# 更改
# = 方块 =
* *[木质压力板](木质压力板.md)、[测重压力板](测重压力板.md)、[栅栏门](栅栏门.md)、[木质按钮](木质按钮.md)和[铁门](铁门.md)和[木门](木门.md)**
* 加入了新的音效。

* *[睡莲](睡莲.md)**
* 现在能放置在冰和霜冰上了，但在方块更新后仍会掉落。

* *[甘蔗](甘蔗.md)**
* 当相邻的水转变为[霜冰](霜冰.md)时不再掉落为物品。

* *[箱子](箱子.md)**
* 更改了音效。
* * 末影箱仍然使用旧的音效。<ref></ref>

# = 生物 =
* *[守卫者](守卫者.md)和[远古守卫者](远古守卫者.md)**
* 更改了战利品掉落机制：
* * 之前是33%掉落[生鱼](生鱼.md)，当不掉落生鱼时有33%概率掉落[海晶砂粒](海晶砂粒.md)。
* * 现在是40%掉落生鱼，40%掉落海晶砂粒，20%二者皆不掉落，且二者的掉落均受[抢夺](抢夺.md)魔咒影响。
* * [海晶碎片](海晶碎片.md)的掉落机制没有变化。

* *[鸡](鸡.md)、[兔子](兔子.md)和[蜘蛛](蜘蛛.md)**
* 掉落物现在受抢夺魔咒影响了。

# = 世界生成 =
* *[要塞](要塞.md)**
* 每个世界的要塞数量从3个增加到128个。

* ** 展现所有+组合键的用途。
