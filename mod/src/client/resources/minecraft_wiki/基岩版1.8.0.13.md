# 基岩版1.8.0.13

*页面ID: 37041* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.8.0.13**是[1.8.0](基岩版1.8.0.md)的第4个测试版，发布于2018年11月1日<ref>https://feedback.minecraft.net/hc/en-us/articles/360018908951-Minecraft-Beta-1-8-0-13-Xbox-One-Windows-10-Android-</ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[熊猫](熊猫.md)**
* 当跟随手持竹子的玩家后，熊猫现在会更快回到它们的正常行为。

# = 命令 =
* ***
* 现在只有拥有管理员权限的玩家能够使用命令。

# = 游戏内容 =
* *[记分板](记分板.md)**
* 现在设置记分板中记分项名称的命令能被识别了。
* *[潜影盒](潜影盒.md)**
* 为未染色的[潜影盒](潜影盒.md)加入了合成配方。

# 修复
* *修复了28个漏洞**
* 修复了游戏过程中出现的崩溃现象。
* 在购买DLC时，游戏崩溃。
* 模板的文本颜色会影响UI的文本。
* 加载资源包时，新的方块纹理显示错误。（）
* 世界保存时，会出现损坏且不能在列表里看见。
* 改进了低内存设备的游戏性能。
* 猫在坐下时四肢分离。（）
* 空的刷怪笼不再显示火焰粒子。
* 使用结构方块导出模型时游戏崩溃。
* 改进了市场搜索结果的过滤功能。
* 豹猫的腿部在潜行时不再悬空。
* 绵羊在注视玩家时，头部模型不正确。（）
* 市场里部分内容的图标丢失。
* 使用脚手架攀爬时，屏幕会闪烁。
* 暂停游戏时，图像显示错误。
* 在一些设备里改进了市场的显示图片。
* “精灵岛英雄”资源包里的女巫纹理出现错误。
* “糖果世界”模板世界里的尸壳纹理出现错误。
* 修复了“Papercraft Adventure”模板世界里的持弓姿势不正确问题。
* “冒险者的梦想”模板世界里的哞菇的腿部模型丢失。
* 修复了有自定义模型的豹猫的几何纹理问题。
* “冒险者的梦想”模板世界里的鞍会隐形。
* 修复了在一些模板地图里的羊驼的腿部旋转错误。
* “糖果世界里的噩梦”模板世界里的“噩梦女妖”的头部大小和位置不正确。
* “被困太空”模板世界里骑乘生物时高度不正确。
* “CampCraft”模板世界里的模型不正确。
* “侏罗纪深渊世界”里的唤魔者的手臂不同步。</onlyinclude>
