# Java版19w02a

*页面ID: 39261* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w02a**是[Java版1.14](Java版1.14.md)的第13个快照，发布于2019年1月9日<ref></ref>，加入了营火、命令、新的粒子、自定义营火配方、新的统计信息以及新的加载动画，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[营火](营火.md)**
* 可用于装饰壁炉，火不会蔓延。
* * 不会烧毁掉落物。
* 用原木、一块煤炭或木炭以及木棍合成。
* 最多可以同时烤4个食物，但是用时是熔炉的3倍（30秒）。
* * 拿着食物右键可以把食物放到营火上。
* * 食物烤熟后会掉落。
* 发出一种新的粒子效果，一种可以在比普通粒子效果更远的距离看到烟雾效果的粒子。
* * 粒子有时可以穿过固体方块。
* * 在营火下放置一个[干草捆](干草捆.md)会使烟雾粒子停留的时间更长，上升得更高。
* 发出9级的光。
* 可以用[水桶](水#水桶.md)熄灭。
* * 扑灭会使其上面的任何食物掉落，但是这些食物不能被捡起来。
* * 可以用打火石重新点燃，但是不能用其他的火源，例如火焰弹点燃。
* 站在上面会受到火焰伤害。
* * 在上面潜行可以避免受到伤害。

# = 命令格式 =
* ***
* 一般用法：
* 向与发送命令的玩家同一队伍的所有玩家发送<信息>。对这一个队伍里的所有玩家都生效。
* 又可写作：。
* 点击队伍名称会打开一个新的命令。

# = 常规 =
* *[粒子](粒子.md)**
* 加入了2种新的粒子：。

* *[配方](配方.md)**
* 加入了营火的自定义“营火”合成配方。

* *[统计](统计.md)**
* 加入了四个新的统计项目：
* * “与高炉的交互次数”
* * “与营火的交互次数”
* * “与讲台的交互次数”
* * “与烟熏炉的交互次数”

* *世界生成**
* 加入了在生成世界时的[加载动画](世界加载界面.md)。
* * 生成的区块现在有可视化的渲染了。

# 更改
# = 方块 =
* *[制图台](制图台.md)**
* 现在可以用木板和纸制作。
* UI可视化配方的功能。
* 允许复制、扩展和锁定地图。
* * 可以使用玻璃板进行锁定以防止它们被修改。

* *[讲台](讲台.md)**
* 现在可以用木台阶和书架合成。
* 对空的讲台右键可以放书。
* 对有书的书架右键可以看书。
* * 在多人游戏中玩家不需要拿着书的情况下看书。
* * 当前页面是持久的，并且所有阅读者共享书的同一页。
* 讲台里的书可以被拿走。
* 翻页时发出[红石](红石.md)信号。
* * [红石比较器](红石比较器.md)可用于检测书的阅读进度。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 保护、爆炸保护、弹射物保护、火焰保护不再互相排斥。
