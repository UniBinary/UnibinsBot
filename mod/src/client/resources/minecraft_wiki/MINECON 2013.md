# 宣布
</ref>|LydiaWinters twitter.jpg}}
</ref>|Jeb twitter.jpg}}

Mojang在6月27日宣布MINECON 2013将会在11月2日-3日在美国的佛罗里达州的奥兰多举办。<ref>https://mojang.com/2013/07/where-in-the-world-is-minecon-2013/</ref>Mojang同时宣布门票以及酒店的购买与预订将会在七月开始。

在许多猜测之后，Mojang终于发布官方消息，宣布MINECON 2013将会于[橘子郡会展中心](wikipedia:Orange County Convention Center.md)（OCCC）举行。<ref>https://mojang.com/2013/07/minecon-tickets-are-here/</ref>在一段时间内，MINECON 2013被列在橘子郡会展中心的事件日历上，但是由于过多人橘子郡会展中心的网站，MINECON 2013只得被从事件日历上暂时移除。在全部门票都被售出之后，MINECON又被重新加入了橘子郡会展中心的在线服务日历<ref>http://www.occc.net/iEBMS/coe/coe_p1_all.aspx?oc=10&cc=COEexorder</ref>和BANNER上<ref>http://www.occc.net/iebms/coe/coe_p1_all.aspx?oc=10&cc=COESMBANNER</ref>。还有一个页面，是专门为参展人员提供电子、光照以及其他展位效果而设立的。<ref>http://www.occc.net/iEBMS/wbe/wbe_p1_main.aspx?&oc=10&cc=WBE1034905</ref> 在OCCC的网站上有一个文章叫做“未命名档案”<ref>http://www.occc.net/search_results.asp?q=Minecon</ref>看上去是关于MINECON 2013的，打开它就会重定向到404网页。<ref>http://www.occc.net/calendar2_detail.asp?ID=34905</ref>

# 地点
MINECON 2013在美国橘子郡会展中心举行。<ref>http://minecon.eventbrite.com/</ref>

地-{}-址：美国佛罗里达州奥兰多国际大道9990号OCCC的西楼WA3- WB1展厅。<ref>http://www.occc.net/search_results.asp?q=Minecon</ref>

# 年龄限制
[Mojang](Mojang.md)本来对于独自参观的人（没有陪同成人）的年龄限制为17岁，即16岁以及以下必须有成人陪同。不过后来经过一些调查和考虑，他们把年龄限制下降到14岁，即13岁以及以下必须有成人陪同。因为这次变故，他们对涉及的家长票进行了退款。退款的门票将会重新出售。<ref>https://mojang.com/2013/08/minecon-2013-2/</ref>

# 票务
早在7月31日，Mojang就确认说票会在那天晚些时候开始发售。据说这些票会分三批出售，每批售2500张（共7500张），票价为$150。<ref>https://minecon.mojang.com/</ref>这个系统意在帮助学生或有工作的人获得票。当时Mojang声明票一共只有7500张，没有剩余。他们不会线下售票，也不会免费提供票给媒体。<ref>https://mojang.com/2013/08/minecon-2013-2/</ref>

; 批-{}-次
* 第一批：7月31日，4:00 PM PDT和7:00 EDT。（一分钟内售罄）<ref></ref>
* 第二批：8月2日，7:00 AM PDT和10:00 EDT。
* 第三批：8月3日，12:00 PM PDT和3:00 EDT。

# 披风
在9月5日，Mojang宣布出席MINECON的玩家会得到一件披风。<ref>http://help.mojang.com/customer/portal/articles/1246918-minecon-2013 MINECON 2013 support page</ref>之后的消息显示发放披风的时间“略有推迟”。

在10月29日，Mojang表示，披风将作为一个获取链接发送给购票者留下的电子邮件地址。邮件内容为：“前往MINECON的最激动人心指出在于你能获得一件能向所有在线玩家展示的游戏披风。”“今年的披风为墨绿底色，一个炫酷的活塞位于中央。点击下面的链接登录到minecraft.net后，披风会自动添加到你的角色上。”——Lydia Winters

# 争议
Mojang与其门票代理商[Eventbrite](http://www.eventbrite.com/home/)在当年的门票销售系统上饱受批评。三批-{}-次的门票迅速售罄（第一批三秒售罄），且购买门票时，Eventbrite网站响应速度慢时会提示“Pending”。正因如此，出现了很多抱怨的推文。

# 竞赛
MINECON 2013举办了一场官方服饰竞赛和一场官方建筑竞赛。

# = 建筑竞赛 =
由于离比赛地点很近，比赛以“万圣节”为主题。竞赛其实比盛会提前了几周进行，并在闭幕式上宣布了获胜者。

在MINECON 2013和MINECON 2012的正式建造比赛中，Tewkesape和theo_the_ape是唯一一组进入前三名的参赛者。
