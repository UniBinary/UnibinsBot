# Java版12w41a

*页面ID: 33155* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w41a**是[Java版1.4.2](Java版1.4.2.md)的第12个快照，发布于2012年10月11日<ref></ref>。

# 新内容
# = 方块 =
* *[铁砧](铁砧.md)**
* 加入了新的[铁砧](铁砧.md)方块来进行修复，合并和命名物品。
* * 有3种不同的损害状态：铁砧、轻微损坏的铁砧和严重损坏的铁砧。
* * 铁砧不仅可以重命名工具和盔甲，任何物品都可以。
* ** 重命名的可放置物品将不会在放置后保留名字。
* * 铁砧可以合并魔咒。
* ** 拥有2个不同附魔的物品将都取两个魔咒。
* ** 拥有相同魔咒的物品如果它们为同等级，将提升等级为下一等级，否则取更高等级的那个。
* ** 有些互不兼容魔咒将会在合并只留下一个（如锋利I和亡灵杀手I）。
* *** 第一个物品有优先权（如果不兼容消失的是第二个物品上的魔咒）。
* * 铁砧也可以像沙子、沙砾和龙蛋一样掉落。
* ** 如果它掉落在生物身上，铁砧将会根据掉落的距离造成伤害。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 苦力怕现在可以通过编辑生物生成和NBT标签来自定义爆炸范围和引信时间（）

# 更改
# = 方块 =
* *[信标](信标.md)**
* 减轻了从信标获得的效果在屏幕上产生的干扰。
* * 其他状态效果没有作出更改。

# = 生物 =
* *常规**
* 生物不再在几秒钟后忘记敌对的创造模式玩家。

# = 游戏内容 =
* *[经验](经验.md)**
* 升级时的音效现在只会每5级播放一次并有所调整。
* 繁殖动物现在会给予经验。

* *[调试屏幕](调试屏幕.md)**
* 对调试屏幕作小调整
* * 现在会显示损伤物品的耐久值，在地图上会显示放大等级。
* * 值现在会显示玩家面向的基本方向。
* * 饼图现在会在菜单里显示而不是反过来。

* *[选项](选项.md)界面**
* 将聊天设定重命名为多人游戏设定。
* * 保留了旧的聊天设定菜单。
* * 给拥有披风者添加了隐藏披风的选项。

# 修复
* *修复了5个漏洞**
* 修复了将铁砧侧向放置在特定方向时，它掉落下来也是侧向着地的问题。
* 修复了破坏铁砧下方的方块导致铁砧恢复到普通铁砧的问题。
* 修复了使用命令时出现了错误：手持方块的玩家会得到一个普通的消息但是不会死的问题。
* 修复了在多人游戏服务器中，如果在重命名物品时清空了全部的名字会导致崩溃的问题。
* 修复了对黏土使用大于时运IV的附魔（正常情况下不能获得）时导致游戏崩溃的问题。</onlyinclude>
