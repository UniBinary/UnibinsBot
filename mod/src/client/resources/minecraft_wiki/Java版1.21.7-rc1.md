# Java版1.21.7-rc1

*页面ID: 155637* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21.7-rc1**是[Java版1.21.7](Java版1.21.7.md)的首个发布候选版本，发布于2025年6月25日<ref></ref>，加入了出自[A Minecraft Movie](A Minecraft Movie.md)的[画](画.md)和[音乐唱片](音乐唱片.md)，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* 加入了1张音乐唱片：
* * Hyper Potions - Lava Chicken
* ** 由玩家或玩家驯服的[狼](狼.md)杀死正在骑乘[鸡](鸡.md)的幼年[僵尸](僵尸.md)掉落。
* ** [稀有度](稀有度.md)为“稀有”。
* ** 通过[红石比较器](红石比较器.md)输出的红石信号强度为9。

# = 非生物实体 =
* *[画](画.md)**
* 加入了1幅由[Sarah Boeving](Sarah Boeving.md)创作的画：
* * Dennis

# = 常规 =
* *[标签](Java版标签.md)**
* 向画变种标签<code>#placeable</code>加入了<code>dennis</code>。
