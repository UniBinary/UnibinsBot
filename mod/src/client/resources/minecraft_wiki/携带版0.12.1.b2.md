# 携带版0.12.1.b2

*页面ID: 27847* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.12.1 alpha build 2**是[v0.12.1 alpha](携带版0.12.1.md)的第2个测试版，发布于2015年7月30日，修复了一些漏洞。

# 更改
* 添加了[豹猫](豹猫.md)的驯服按钮。
* 破坏[农作物](农作物.md)现在总掉落[种子](种子.md)。
* 将飞行控制按钮略微缩小。
* [雪傀儡](雪傀儡.md)现在生成时会戴着[南瓜](南瓜.md)。

# 修复

* *其他**
* 修复了打开控制器屏幕<!--controller screen-->时出现的漏洞。
* 修复了在积雪的生物群系中长时间停留后出现的漏洞。
* 修复了许多多人游戏的漏洞。
* 现在在疾跑时左右移动不会中断疾跑。
* 现在可以用钓鱼竿拉动鱿鱼。
* 挂起应用程序后现在天气会正常显示。
* 传送门的效果现在会在进入传送门后显示。
* 雪球现在不会随机改变颜色。
* 岩浆怪现在会在多人游戏中正常跳跃。
* 修复了在菜单屏幕能够移动角色的漏洞。
* 修复了切换到触摸控制后不能使用返回按钮退出选项菜单的漏洞。
* 使用精准采集收集的草现在是正常的。
* 现在可以在铁砧的第二个槽位放置物品。</onlyinclude>
