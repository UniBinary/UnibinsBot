# 命令/warden spawn tracker

*页面ID: 93350* | *来源: Minecraft Wiki*

设置[幽匿尖啸体](幽匿尖啸体.md)生成[监守者](监守者.md)之前应接收到多少次振动。

# 语法
   <code>warden_spawn_tracker clear</code>
  : 清空玩家的监守者计数器，包括警告等级和冷却时间。
   <code>warden_spawn_tracker set <warning_level></code>
  : 将玩家的警告等级设为指定值。

# 参数

   指定警告等级的数值。

# 输出

# 示例
* 将玩家的警告等级设为1：<code>/warden_spawn_tracker set 1</code>
