# 基岩版1.21.100.20

*页面ID: 152952* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.100.20**（ChromeOS/Android）、**Preview 1.21.100.20**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.100](基岩版1.21.100.md)的首个测试版，发布于2025年6月10日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了“Music by C418!”闪烁标语。

# 更改
# = 物品 =
* *[拴绳](拴绳.md)和[气球](气球.md)**
* 不再可以拴在[墙](墙.md)上。

# = 生物 =
* *[悦灵](悦灵.md)**
* 不再可以被给予[拴绳](拴绳.md)。

* *[动物](动物.md)**
* 将空闲音效的间隔调整为6秒，以匹配。

* *[恶魂](恶魂.md)**
* 将空闲音效的间隔调整为4秒，以匹配。

* *[猪灵蛮兵](猪灵蛮兵.md)**
* 现在会在和平难度下消失。

* *[鱿鱼](鱿鱼.md)和[发光鱿鱼](发光鱿鱼.md)**
* 更改了碰撞箱以匹配。

# = 非生物实体 =
* *[拴绳结](拴绳结.md)**
* 现在会在[栅栏](栅栏.md)被移除后立即消失。

# = 世界生成 =
* *[冰冻深海](冰冻深海.md)**
* 现在表面不会被冻结。

* *[冻洋](冻洋.md)**
* 不再是完全冰冻的。
