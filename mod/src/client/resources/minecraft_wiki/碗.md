# 碗

*页面ID: 6191* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}
* *碗（Bowl）**是用来装一些[食物](食物.md)的容器。

# 获取
# = 合成 =

# = 钓鱼 =
[钓鱼](钓鱼.md)时碗可作为垃圾被钓上来。

# = 食物 =
[兔肉煲](兔肉煲.md)、[甜菜汤](甜菜汤.md)、[蘑菇煲](蘑菇煲.md)和[谜之炖菜](谜之炖菜.md)被食用后会返还空碗。

# = 生物掉落物 =
[海龟](海龟.md)被[闪电](闪电.md)击中而死时会掉落1个碗。<ref name=MC-125562></ref><ref></ref>然而闪电会迅速将掉落的碗清除，从而难以获得其物品。<ref></ref>

# 用途
# = 合成材料 =

# = 哞菇 =
对[哞菇](哞菇.md)碗可以获得[蘑菇煲](蘑菇煲.md)。如果之前给棕色哞菇喂食过某些[花](花.md)，那么可以获得对应的[谜之炖菜](谜之炖菜.md)。

# = 燃料 =
碗能用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料。每个碗可以烧炼0.5个物品；每个碗可以烧炼1个物品。
