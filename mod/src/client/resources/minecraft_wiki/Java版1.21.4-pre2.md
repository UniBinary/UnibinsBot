# Java版1.21.4-pre2

*页面ID: 129069* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21.4-pre2**是[Java版1.21.4](Java版1.21.4.md)的第2个预发布版，发布于2024年11月25日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)和[高炉](高炉.md)**
* 对方块实体数据进行下列更改：
* * 将重命名为。
* * 将重命名为。
* * 将重命名为。
* * 加入了字段，表示熔炉应燃烧的总时长。

# = 生物 =
* *[嘎枝](嘎枝.md)**
* 现在未与[嘎枝之心](嘎枝之心.md)绑定的嘎枝受到伤害时会发出通用受伤音效而非晃动音效。<!--原bug存在于1.21.2，但mojira上没有相关报告-->

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* [冰霜行者](冰霜行者.md)魔咒不再在目标实体骑乘其他实体时生效。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。
