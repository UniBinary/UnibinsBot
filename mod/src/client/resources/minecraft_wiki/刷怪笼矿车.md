# 刷怪笼矿车

*页面ID: 9766* | *来源: Minecraft Wiki*

* *刷怪笼矿车（Minecart with Monster Spawner）**是一种装着[刷怪笼](刷怪笼.md)的[矿车](矿车.md)。

# 生成
刷怪笼矿车只能通过命令生成。没有可以放置刷怪笼矿车的物品。

# 行为

刷怪笼矿车的行为与刷怪笼基本一致，其NBT数据也与刷怪笼相同。<ref></ref>

与刷怪笼不同，不能对刷怪笼矿车使用[刷怪蛋](刷怪蛋.md)来改变其生成的生物。

刷怪笼矿车被破坏后会掉落一个矿车。
