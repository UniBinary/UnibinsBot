# 客户端请求占位符方块

*页面ID: 90814* | *来源: Minecraft Wiki*

* *tile.client_request_placeholder_block.name**（下文称**客户端请求占位符方块**）是基岩版客户端独有的占位符方块。

# 生成
客户端请求占位符方块会生成于未加载的区块。

# 获取
客户端请求占位符方块只能通过存档编辑或[附加包](附加包.md)获得。

# 破坏
客户端请求占位符方块没有能用于挖掘且可以被选中的判定框，因此不能挖掘客户端请求占位符方块。

客户端请求占位符方块被破坏后不会掉落。

# 用途
[thumb|250x250px|客户端请求占位符方块会让与它接触的方块不渲染（即透视效果），并且能让弹射物穿过自身](File:Client request placeholder block characteristics.jpg.md)
客户端请求占位符方块具有与[携带版0.13.0.b1](携带版0.13.0.b1.md)之前的[隐形基岩](隐形基岩.md)相似的属性，无法被选中且不渲染与其接触的完整方块表面，但与隐形基岩不同的是，客户端请求占位符方块可以让[弹射物](弹射物.md)穿过自身，这些特性与阻止玩家进入未加载区块的方块相似。
