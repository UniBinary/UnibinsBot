# Java版14w29b

*页面ID: 32712* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w29b**是[Java版1.8](Java版1.8.md)的第37个快照，发布于2014年7月16日<ref></ref>，修复了快照[14w29a](14w29a.md)中的一些漏洞和崩溃，但是该快照主要更新了多线程区块加载。

# 更改
# = 常规 =
* *优化**
* 优化了多线程区块加载。
