# Java版Infdev 20100330-1203

*页面ID: 86168* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年3月30日。<ref></ref>

== 更改 ==
# = 方块 =
* *[熔炉](熔炉.md)**
* 烧炼一个物品的时间由4秒改回了8秒。

# 修复
* *修复了5个漏洞**
* 修复了导致容器内容物（如箱子和熔炉）有时未能保存的漏洞。
* 修复了台阶的光照错误。
* 世界的顶部不再完全被照亮，其不再导致崩溃。
* 修复了世界重新加载时导致树和矿石重新生成的漏洞。
* 小麦作物在被破坏后不再保留其生长阶段，此漏洞曾经导致新种植的作物呈现先前生长在该方块上的作物的生长阶段。</onlyinclude>
