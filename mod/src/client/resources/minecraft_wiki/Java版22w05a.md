# Java版22w05a

*页面ID: 92686* | *来源: Minecraft Wiki*

<onlyinclude>

* *22w05a**是[Java版1.18.2](Java版1.18.2.md)的第2个快照，发布于2022年2月2日<ref></ref>，暂时回退了上个版本对[恶地](恶地.md)生成的更改，并修复了一些漏洞。

# 更改
# = 世界生成 =
* *[恶地](恶地.md)**
* 回退了[22w03a](22w03a.md)对恶地的更改，以避免出现区块硬边界。
* * 此更改以后还会重新加入。

* *[超平坦世界](超平坦世界.md)**
* 将“”预设的顶层方块高度由Y=-9提升至Y=55，以防止[史莱姆](史莱姆.md)生成。

# = 常规 =
* *[标签](Java版标签.md)**
* 移除了[泥土](泥土.md)的<code>#dripstone_replaceable_blocks</code>方块标签。
