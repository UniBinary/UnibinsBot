* *0.0.13a**是的一次更新，发布于2009年5月22日<ref name=":0"></ref><ref></ref>，作出了一些更改和修复。

# 新内容
# = 游戏内容 =
* *常规**
* 加入了颜色较淡的黑色轮廓箱。
* 现在可以为有账号的玩家保存世界。<ref></ref>
* * 为已注册并登录的玩家提供的功能。
* * 共有5个槽位。
* * 存储于链接 {{cd|-{}-<nowiki>http://www.minecraft.net/play.jsp?name=<用户名>&id=<所在槽位，从0开始计数></nowiki>}} 中。

# = 常规 =
* *[控制](控制.md)**
* 按下现在会打开暂停菜单。

# 更改
# = 方块 =
* *[树苗](树苗.md)**
* 更改了纹理。

* *[熔岩](熔岩.md)**
* 不再是透明的。
* 处于熔岩内部时所见的迷雾由橘黄色改为较浓的红色。

# = 世界生成 =
* *常规**
* 地形不再总是生成在水上1格的位置。<ref>[IRC logs](#logs.md): "*(22:12:23) <Notch_> it's fixed in 0.0.13a. =)*" (20:12 UTC)</ref>
* 世界生成时熔岩和水不再总是会生成[石头](石头.md)。<ref>[IRC logs](#logs.md): "*(16:29:51) fartron: Notch_, how can lava float on water without forming stone? [...] Notch_: it can't in 0.0.13a. :D*" (14:29 UTC)</ref>
* 表层泥土现在更均匀了。
* * 现在石头上方几乎总有[草方块](草方块.md)和泥土层。
* * 崖面现在不全部由泥土和草方块组成。

# = 游戏内容 =
* *[平视显示器](平视显示器.md)**
* 在右上角会再次显示玩家正在手持着的方块。

* *[世界加载屏幕](世界加载屏幕.md)**
* 世界生成界面现在会展示较暗的[泥土](泥土.md)。

* *常规**
* 按住跳跃键无法再自动跳跃。
* 玩家的跳跃高度被降低到0.0.11a时的数值。
* 在[水](水.md)中游泳和下沉的速度变得更快。

# = 常规 =
* *[控制](控制.md)**
* 按住不再导致玩家在不同位置之间循环重生，按住与单击的效果现在是相同的。

* *其他**
* 游戏窗口的分辨率现在是854&times;480，而不是640&times;480。

# 修复
; 修复了1个漏洞
   修复了接触世界顶端和底部的方块面不会显示纹理的漏洞。</onlyinclude>

# 启动器版
启动器中的“c0.0.13a”的与2009年发布的原版有着很大不同：原版支持常规地形，而启动器的版本严格使用平坦地形。此外在启动器的版本中，[0.0.12a](Java版Classic 0.0.12a.md)中的许多功能仍然存在。这可能是由于该版本是0.0.13a的[早期开发版本](/开发.md)而非最终正式版。
