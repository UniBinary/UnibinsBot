# 基岩版1.16.210.56

*页面ID: 75046* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.210.56**是[基岩版1.16.210](基岩版1.16.210.md)的第6个测试版，发布于2021年1月20日<ref></ref>，加入了[滴水石锥](滴水石锥.md)和[幽匿感测体](幽匿感测体.md)，并修复了一些漏洞。<ref></ref>

# 新内容
# = 方块 =
* *[滴水石锥](滴水石锥.md)**
* 目前无法自然生成，仅能从[创造模式物品栏](创造模式物品栏.md)中获取。
* 可以放在方块顶部或底部，形成钟乳石或石笋。
* * 可以形成更长的钟乳石或石笋。
* 石笋会在其下方没有方块时被破坏，并会对掉落在其上方的[实体](实体.md)造成伤害。
* * 掉落在石笋上的实体会受到3倍的摔落伤害。
* 钟乳石会在其上方没有方块时掉落，并会对其砸中的实体造成伤害。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

* *[幽匿感测体](幽匿感测体.md)**
* 一种新的红石元件。
* 能够检测声音发出红石信号。
* 连接[红石比较器](红石比较器.md)时能够基于声音的振动频率发出不同的信号强度。
* 目前仅能通过创造模式物品栏或命令获取。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# = 游戏内容 =
* *[粒子](粒子.md)**
* 加入了新的粒子类型：和。

# 更改
# = 常规 =
* *[加载提示](加载提示.md)**
* 加入了一条新的加载提示：
* * “在 iOS、Android 或 FireOS 上游玩？快去市场获取免费的《我的世界》原创音乐包，享受完整的《我的世界》体验吧。”

# 修复
* *常规**
* 修复了“猪排”成就和奖杯可以通过生猪排来解锁的问题。（）
* 修复了狐狸会不停地叼着甜浆果并无法吃甜浆果的漏洞。（）
* 现在可以点击“下载模板”来正确地下载缺少现有世界所需的模板。
* 修复了玩家能够在冒险模式下使用刷怪蛋的漏洞。

* *命令**
* 命令现在可以设置灵魂灯笼的连接状态。（）
* 命令现在可以设置锁链的旋转状态。（）
* 和事件现在支持方块的自定义状态。

* *方块**
* 修复了部分市场上的世界有不正确的方块数据在Realms多人游戏中的移动端和PC端的世界生成的问题。

* *世界生成**
* Mcstructure文件中保存的实体不会在游戏崩溃时加载到该世界。（）

* *技术性**
* 为方块事件响应加入了布尔参数，默认设置为false。因此不再会在创造模式下减少默认物品堆叠。</onlyinclude>
