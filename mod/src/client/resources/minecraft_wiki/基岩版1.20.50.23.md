# 基岩版1.20.50.23

*页面ID: 106812* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.50.23**（ChromeOS/Android）、**Preview 1.20.50.23**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.50](基岩版1.20.50.md)的第4个测试版，发布于2023年11月2日<ref></ref>，在[实验性玩法](实验性玩法.md)中调整了一些特性，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[设置](设置.md)**
* 在帐户设置中加入了“”选项。
* * 用于启用远程登录Microsoft账户功能。

# 更改
# = 常规 =
* *用户界面**
* 优化了[主菜单](主菜单.md)和世界创建的体验。
* * 目前仅对部分玩家推出。

# = 技术性 =
* *API**
* 将由移动至。

* *物品**
* 在1.20.50及更高版本的格式版本中弃用了的事件触发器。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[雕纹铜块](雕纹铜块.md)**
* 现在可通过合成获得。

* *[涂蜡的雕纹铜块](涂蜡的雕纹铜块.md)**
* 现在可通过使用[涂蜡的切制铜台阶](涂蜡的切制铜台阶.md)合成获得。
* 现在所有变种可由对应的[涂蜡的铜块](涂蜡的铜块.md)在[切石机](切石机.md)中制成。

* *[雕纹凝灰岩](雕纹凝灰岩.md)、[雕纹凝灰岩砖](雕纹凝灰岩砖.md)和[磨制凝灰岩](磨制凝灰岩.md)**
* 现在所有变种可通过合成获得。

* *[铜门](铜门.md)和[铜活板门](铜活板门.md)**
* 更改了所有变种的方块和物品纹理。

* *[合成器](合成器.md)**
* 更改了纹理。

* *[凝灰岩砖](凝灰岩砖.md)、[凝灰岩砖台阶](凝灰岩砖台阶.md)、[凝灰岩砖楼梯](凝灰岩砖楼梯.md)和[凝灰岩砖墙](凝灰岩砖墙.md)**
* 更改了方块和物品纹理。
* 现在可通过合成获得。

* *[涂蜡的铜门](涂蜡的铜门.md)和[涂蜡的铜活板门](涂蜡的铜活板门.md)**
* 现在所有变种可通过合成获得。

* *[涂蜡的铜格栅](涂蜡的铜格栅.md)**
* 现在所有变种可由对应的涂蜡的铜块在切石机中制成。

# = 技术性 =
* *API**
*
* * 将属性重命名为，以使其更加清晰易懂。
* 将更改为仅在只读模式下运行。
* 将由类更改为带有属性的接口。
* 现在会正确反映其可以返回 undefined}}，而不只是。

* *Gametest**
* 动态属性
* * NBT更改：动态属性现在使用行为包清单文件UUID而非模块UUID。使用动态属性的现有世界会继续运作，在读取或修改属性时会迁移至新格式。

# 修复
* *方块**
* 紫颂花现在可以被任何弹射物破坏，被弹射物击中不会消失。（）
* 修复了方解石物品无法通过命令或创造模式物品栏获得的问题。（）

* *合成和物品栏界面**
* 现在会保存物品栏选项的状态（如“全部/可合成”切换和所选的物品栏选项卡）。（）

* *游戏内容**
* 修复了飞行的玩家接触到地面后移速会显著减慢的问题。
* 现在使用触摸控制的玩家可以在水中潜行。（）

* *常规**
* 优化了对世界导出期间出现的意外错误的处理方式，且现在会提供更好的错误消息传达。（）

* *图形**
* 降低了快捷栏的透明度。（）
* 为没有背景渐暗的屏幕加入了背景渐暗效果。（）

* *市场**
* 修复了在市场中执行不同操作时可能会卡死的问题。
* 加入了将服务器内的玩家跳转至更衣室优惠的功能。

* *生物**
* 现在在新的体积限制采用前被放置于船中，且被识别为体积过大的生物，将不再会强制从船中脱离。（）

* *Molang**
* 现在再次会检测玩家的垂直运动。

* *角色创建器**
* 现在经典皮肤信息弹窗会将玩家送往正确的设置页面。

* *Realms**
* 修复了做其他事情一段时间后加入Realm时可能发生的崩溃。

* *用户界面**
* 修复了设置中的“创建者”选项卡周围的边框不会高亮显示的问题。（）</onlyinclude>
