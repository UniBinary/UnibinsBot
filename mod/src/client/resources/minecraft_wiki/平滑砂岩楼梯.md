# 平滑砂岩楼梯

*页面ID: 44281* | *来源: Minecraft Wiki*

* *平滑砂岩楼梯（Smooth Sandstone Stairs）**是[平滑砂岩](平滑砂岩.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
平滑砂岩楼梯会自然生成在沙漠[村庄](村庄.md)。

# 破坏
挖掘平滑砂岩楼梯的合适工具是镐。平滑砂岩楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

平滑砂岩楼梯被破坏后会掉落自身。
