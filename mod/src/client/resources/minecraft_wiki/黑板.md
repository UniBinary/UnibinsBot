# 黑板

*页面ID: 22089* | *来源: Minecraft Wiki*

* *黑板（Chalkboard）**是一种功能类似[告示牌](告示牌.md)，但能展示更多文本的方块。<ref>https://education.minecraft.net/support/knowledge-base/using-slates-posters-boards/</ref>黑板共有三种不同尺寸的变种：1×1的**小黑板（Slate）**、2×1的**告示板（Poster）**和3×2的**大黑板（Board）**。

# 生成
黑板不会生成在世界中。

# 获取
黑板的物品形式不能在生存模式中正常获得，但可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或命令获得。

# 破坏
挖掘黑板的合适工具是斧。

黑板被破坏后会掉落自身。

[创造模式](创造模式.md)下的玩家破坏告示板的右半边或大黑板除下部中间外的部分时，告示板或大黑板也会掉落。

# 用途
黑板可用于展示文本。玩家可以选中放置好的黑板，编辑需要展示的文字并按下“OK”按钮来保存。点击黑板UI右上角的“×”可以关闭编辑界面。

黑板可以放置在方块（包括[栅栏](栅栏.md)、[玻璃](玻璃.md)、[铁轨](铁轨.md)及黑板本身等非固体方块）的顶部或侧面。放置在方块顶部的小黑板会有一根立柱支持，且玩家可通过改变摆放时面朝的方向来调整小黑板的朝向。小黑板与告示牌一样，共有16种朝向可供调整，而告示板和大黑板只有4种。

小黑板和告示板可以输入6行文本，而大黑板可以输入15行文本。

与告示牌不同，黑板不能被[活塞](活塞.md)移动。

黑板是非固体方块，没有碰撞箱，因此[实体](实体.md)可以穿过黑板。

只有具有世界建造者权限的玩家可以放置方块形式的黑板。
