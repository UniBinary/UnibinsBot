# = 方块 =
* *[失水恶魂](失水恶魂.md)**
* 在[下界](下界.md)中作为[下界化石](下界化石.md)的一部分自然生成。
* 可使用1个[骨块](骨块.md)和8个[恶魂之泪](恶魂之泪.md)合成。
* [含水](含水.md)时会经历3个状态（不包括初始的“干燥”状态），持续20分钟后会生成一只[小恶魂](小恶魂.md)。
* 被放置时默认处于“干燥”状态。
* 不再含水时，失水恶魂会在与其含水时长相等的时间后转换为“干燥”状态。

# = 物品 =
* *[挽具](挽具.md)**
* 一种能够装备在[快乐恶魂](快乐恶魂.md)上的物品，允许玩家骑乘快乐恶魂。
* 可使用3个[皮革](皮革.md)、2个[玻璃](玻璃.md)和1个[羊毛](羊毛.md)合成。
* 可通过与[染料](染料.md)合成以重新染色。
* 对快乐恶魂[剪刀](剪刀.md)可卸下其装备的挽具。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了快乐恶魂刷怪蛋。

# 修复
* *角色创建器**
* 修复了使用自定义皮肤时玩家模型会以错误大小显示的问题。（）

* *方块**
* 花现在具有与Java版相同的随机偏移范围和值。
* 竹子、垂根和红树胎生苗、下界苗现在具有与Java版相同的随机偏移范围和值。
* 珊瑚和珊瑚扇现在具有与Java版相同的随机偏移范围和值。
* 如向日葵等两格高的植物现在具有与Java版相同的随机偏移范围和值。
* 滴水石锥、高草丛和枯草丛现在具有与Java版相同的随机偏移范围和值。

* *编辑器**
* 现在在结构面板中编辑结构的字段时允许在字段被编辑时保存。

* *游戏内容**
* 修复了玩家在水中疾跑会比游泳速度更快的漏洞。

* *生物**
* 农民村民收集种下的农作物时不再会偶尔卡住。（）

* *音乐**
* 修复了在游戏暂停的情况下从设置菜单进入鸣谢名单时不会播放鸣谢名单的音乐的问题。（）

* *配方**
