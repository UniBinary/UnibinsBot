# 基岩版26.10.24

*页面ID: 187728* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 26.10.24**（ChromeOS/Android）、**Preview 26.10.24**（Windows/Xbox/iOS/iPadOS/PlayStation）是[基岩版26.10](基岩版26.10.md)的第4个测试版，发布于2026年2月17日<ref></ref>，加入了部分生物的音效变种和一些切石机配方，更改了部分幼年生物的模型，在[实验性玩法](实验性玩法.md)中为[熔炉](熔炉.md)、[高炉](高炉.md)和[烟熏炉](烟熏炉.md)加入了[配方书](配方书.md)，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[猫](猫.md)、[猪](猪.md)、[牛](牛.md)和[鸡](鸡.md)**
* 加入了新的成年音效变种：
* * 猫
* **
* * 猪
* **
* **
* * 牛
* **
* * 鸡
* **
* 已有生物的音效变种会是所有变种中的随机一种。

# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“Furnace Recipe Book”子选项。
* * 用于启用[熔炉](熔炉.md)、[高炉](高炉.md)和[烟熏炉](烟熏炉.md)的[配方书](配方书.md)。

# 更改
# = 方块 =
* *[圆石](圆石.md)**
* 现在可以在[切石机](切石机.md)中制成[雕纹石砖](雕纹石砖.md)和[石砖](石砖.md)及对应的[台阶](台阶.md)、[楼梯](楼梯.md)和[墙](墙.md)。

* *[枯萎的灌木](枯萎的灌木.md)**
* 现在可以放置在[耕地](耕地.md)上。

* *[深板岩](深板岩.md)**
* 现在可以在切石机中制成[雕纹深板岩](雕纹深板岩.md)和[深板岩圆石](深板岩圆石.md)、[深板岩砖](深板岩砖.md)、[深板岩瓦](深板岩瓦.md)、[磨制深板岩](磨制深板岩.md)及对应的台阶、楼梯和墙。

* *[金蒲公英](金蒲公英.md)**
* 现在对幼年动物使用金蒲公英时会发出绿色粒子。
* * 粒子向下移动表示已阻止成长。
* * 粒子向上移动表示成长已重新开始。
* 现在使用金蒲公英阻止幼年动物成长或使幼年动物重新开始成长时会播放音效。

* *[石头](石头.md)、[花岗岩](花岗岩.md)、[磨制花岗岩](磨制花岗岩.md)、[闪长岩](闪长岩.md)、[磨制闪长岩](磨制闪长岩.md)、[安山岩](安山岩.md)和[磨制安山岩](磨制安山岩.md)**
* 现在可以在切石机中制成[圆石](圆石.md)及对应的台阶、楼梯和墙。

# = 生物 =
* *[幼年生物](幼年生物.md)**
* 更新了以下幼年生物的纹理和模型：
* * [熊猫](熊猫.md)
* * [炽足兽](炽足兽.md)
* * [疣猪兽](疣猪兽.md)
* * [嗅探兽](嗅探兽.md)
* * [僵尸疣猪兽](僵尸疣猪兽.md)

* *[马](马.md)、[僵尸马](僵尸马.md)和[骷髅马](骷髅马.md)**
* 略微增大了幼年变种的碰撞箱，高度由0.8格更改为1.12格，宽度由0.7格更改为0.98格。

* *[海龟](海龟.md)**
* 调整了幼年海龟的碰撞箱大小，高度由0.2格更改为0.21333328格，宽度由0.6格更改为0.64格。

# = 常规 =
* *[暂停菜单](暂停菜单.md)**
* 加入了游戏指南按钮，显示为一个问号。

* *[服务器列表](服务器列表.md)**
* 现在会显示自定义服务器，即使没有找到Minecraft提供的服务器也会如此。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“Furnace Recipe Book”子选项后才可使用。

# = 常规 =
* *[配方书](配方书.md)**
* 为[熔炉](熔炉.md)、[高炉](高炉.md)和[烟熏炉](烟熏炉.md)加入了配方书。

# 修复
* *输入**
* 修复了Windows平台上的“滚动方向”系统设置没有效果的漏洞。（）

* *物品**
* 开启或关闭高分辨率资源包后，时钟、指南针和追溯指针不再会有损坏的外观。（）
* 修复了捡起已在副手持有的物品时，玩家物品栏有时不会正确更新的问题。（）

* *生物**
* 对着另一只猫或狼使用刷怪蛋生成的幼年猫或幼年狼不再会变得无法驯服。（）
* 对着另一只猫或狼使用刷怪蛋生成的幼年猫或幼年狼不再会带有灰色项圈。（）
* 现在幼年狼被玩家攻击时，附近的成年狼和幼年狼会被激怒。
* 玩家不再能够使未驯服的狼与驯服的狼繁殖。
* 幼年狼现在会攻击绵羊。
* 现在幼年骡和幼年驴的模型是居中的，以使它们的碰撞箱不再错位。
* 幼年僵尸马现在可以被拴住。
* 使用生成事件生成的幼年骷髅马不再能被玩家骑乘。
* 幼年犰狳现在拥有正确的头部位置。
* 幼年犰狳现在会在展开时播放正确的动画。
* 现在狐狸携带的物品会正确显示为叼在嘴里。
* 更新了幼年羊驼的模型，以使腿部不再出现视觉故障。
* 修复了驯服的幼年猫的英国短毛变种的纹理。
* 现在幼年村民的碰撞箱会正确对齐。
* 幼年僵尸、幼年尸壳、幼年猪灵、幼年僵尸猪灵和幼年溺尸骑乘载具或其他生物时，它们的躯干不再会有奇怪的偏移。
* 幼年狼现在会在愤怒时嚎叫。
* 现在成年人形敌对生物再次会在正确位置上副手持有物品。
* 幼年村民现在再次会在床的中央睡觉。
* 改进了具有新的几何形状的被拴住幼年生物的拴绳位置。
* 为驯服的幼年猫加入了MERS纹理。
* 幼年北极熊现在拥有正确的尺寸。
* 修复了使用经典纹理包时，幼年生物会出现错误缩放的情况的问题。
* 修复了炽足兽和猪灵（再次）会过于热情地尖叫的回溯问题。
* 调低了幼年僵尸和幼年溺尸的手臂，以防止它们持有的物品与头部之间产生错位。
* 从成年狼动画中分离了幼年狼动画。
* 修复了幼年犰狳不会在蜷缩时向外窥视的问题。

* *Realms**
* 移除了旗标和旧的Realms备份系统，现在新的备份系统Realms存档会始终启用。

* *性能与稳定性**
* 修复了加载有过多方块计划进行滴答的世界时，服务器会变低速的问题。（）
* 修复了在下界中的熔岩流附近逗留时，游戏会卡死并且存档文件会变大的问题。（）

* *用户界面**
* 修复了滚动条外的元素的旁白。
* 修复了骑乘生物时UI中的角色会不正确旋转的问题。
* 修复了在游戏内修改时无法保存部分Ore UI的键盘与鼠标设置的问题。（）
* 现在可以使用鼠标或触控来移动告示牌内的插入符。（）</onlyinclude>
