* *瘟疫鲸台阶（Plaguewhale Slab）**是一种紫色扁形的[远古守卫者](远古守卫者.md)变种。

# 生成
[thumb|[[角斗场](File:Inside colosseum.png.md)内的[超级马铃薯怪](超级马铃薯怪.md)和瘟疫鲸台阶]]

在每座[角斗场](角斗场.md)的生成过程中会有15只瘟疫鲸台阶随之生成。

进入第九阶段的[超级马铃薯怪](超级马铃薯怪.md)会生成9只瘟疫鲸台阶。

# 行为

瘟疫鲸台阶不会给予玩家[挖掘疲劳](挖掘疲劳.md)效果，不被[潮涌核心](潮涌核心.md)攻击。

[美西螈](美西螈.md)会主动攻击瘟疫鲸台阶。

当瘟疫鲸台阶被攻击时，不会像远古守卫者一样带有尖-{}-刺伤害，而是给予攻击者2秒[凋零](凋零.md)效果。

瘟疫鲸台阶会主动攻击[玩家](玩家.md)。除[玩家](玩家.md)以外，瘟疫鲸台阶并不会使用激光反击攻击它的生物（如铁傀儡），但它被近战攻击时仍会给予攻击者2秒[凋零](凋零.md)效果。

# = 生物族群 =

瘟疫鲸台阶是水生生物。被具有[穿刺](穿刺.md)魔咒的武器近战攻击，或被具有穿刺魔咒的[三叉戟](三叉戟.md)弹射物命中时会受到额外的伤害。

# = 攻击 =

瘟疫鲸台阶的激光不会直接造成伤害，但会在击中目标时对目标持续施加2秒的[中毒](中毒.md)效果。其能量充满后会对目标施加3.5秒（非困难难度）或4.5秒（困难难度）的[凋零](凋零.md)效果。

# = 堆叠 =
[thumb|两只堆叠的瘟疫鲸台阶](File:Plaguewhale stack.png.md)

瘟疫鲸台阶可以骑乘在周围的其他瘟疫鲸台阶上，就像堆叠在一起的台阶一样。至多只会有2只瘟疫鲸台阶相堆叠，其碰撞箱的并恰相当于一个[远古守卫者](远古守卫者.md)的碰撞箱。

当若干只堆叠的瘟疫鲸台阶的其中一只受伤时，其会从堆叠中脱离。
