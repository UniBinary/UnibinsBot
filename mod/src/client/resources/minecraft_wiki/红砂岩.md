# 红砂岩

*页面ID: 28590* | *来源: Minecraft Wiki*

* *红砂岩（Red Sandstone）**是在[恶地](恶地.md)常见的一种[方块](方块.md)，也可由[红沙](红沙.md)合成。

# 生成
# = 自然生成 =
红砂岩会自然生成于[恶地](恶地.md)、[疏林恶地](疏林恶地.md)和[风蚀恶地](风蚀恶地.md)里位于[红沙](红沙.md)层的洞穴入口和峡谷顶端。

# 破坏
挖掘红砂岩的合适工具是镐。红砂岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

红砂岩被破坏后会掉落自身。
