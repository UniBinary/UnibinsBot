# Java版12w34b

*页面ID: 33047* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w34b**是[Java版1.4.2](Java版1.4.2.md)的第3个快照，发布于2012年8月24日<ref></ref>，修复了[12w34a](12w34a.md)里的漏洞和崩溃。

# 新内容
# = 游戏内容 =
* *[Boss生物](Boss生物.md)**
* 在其血量条上加入了名字。

# 更改
# = 方块 =
* *[按钮](按钮.md)**
* 更改了[按钮](按钮.md)的配方，制作按钮现在需要1个[石头](石头.md)或1个[木板](木板.md)。

# = 物品 =
* *[盔甲](盔甲.md)**
* 稍微更改了[皮革](皮革.md)和钻石[盔甲](盔甲.md)的纹理：
* * 皮革盔甲的袖子延伸了一个像素。
* ** 物品纹理被更改以与新纹理相对应。
* * 钻石盔甲的袖子里面有了一个缺口。

* *[地图](地图.md)**
* 移除了[地图](地图.md)左上角的数字“map_#/#”，现在会在提示框中标示“map #”。
* 地图有了缩放等级。在此之前地图固定在1:8，现在开始时是1:1并能通过再合成已有地图来增加到最大1:16。

# = 生物 =
* *[凋灵](凋灵.md)**
* [凋灵](凋灵.md)的生命下降到一半的时候会获得凋灵盔甲，使其对[箭](箭.md)免疫。

* *攻击型生物**
* [僵尸](僵尸.md)、[骷髅](骷髅.md)和[僵尸猪人](僵尸猪人.md)生成时偶尔拥有捡起物品的能力。
* * 捡起的盔甲会自动装备，物品会直接拿在手上而不仅仅只是武器，这意味着它们可以拿起经过的物品，例如[腐肉](腐肉.md)。
* * 这会使僵尸猪人丢弃它们的剑。
* * 这会使骷髅丢弃它们的弓。
* * 这种允许它们捡起物品的属性被称为<code>CanPickUpLoot</code>。

* *[僵尸猪人](僵尸猪人.md)**
* 在主世界，僵尸猪人会渴望回到下界（例如，如果玩家在创造模式中制作了一个下界传送门并生成一个僵尸猪人，它会跑进传送门里）。

# 修复
* *修复了2个漏洞**
* 修复了物品展示框导致崩溃的问题。
* 修复了一些关于下界传送门的问题。</onlyinclude>
