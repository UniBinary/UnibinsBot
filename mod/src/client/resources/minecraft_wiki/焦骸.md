* *焦骸（Parched）**是生成于沙漠中的[骷髅](骷髅.md)变种。

# 生成
# = 自然生成 =
焦骸自然生成于[沙漠](沙漠.md)生物群系，在露天时取代50%的[骷髅](骷髅.md)生成。

焦骸还会作为[骆驼尸壳](骆驼尸壳.md)的乘客生成。

[蜘蛛](蜘蛛.md)和[洞穴蜘蛛](洞穴蜘蛛.md)在沙漠生成时有0.8%的概率生成为[焦骸蜘蛛骑士](蜘蛛骑士.md)。

# = 万圣节 =

在[万圣夜](wzh:万圣夜.md)（10月31日）当天，焦骸在生成时有22.5%的概率戴着[雕刻南瓜](雕刻南瓜.md)，2.5%的概率戴着[南瓜灯](南瓜灯.md)，但雕刻南瓜或南瓜灯不会掉落。<ref></ref>

# 行为

焦骸的行为与[骷髅](骷髅.md)大致相同，不同的是，焦骸会发射或，会对其击中的目标造成/[虚弱](虚弱.md)I。焦骸在水下进行攻击时不会射箭，且其使用的近战攻击不会对目标施加虚弱效果。

焦骸的攻击冷却时间在简单和普通难度中为，在困难难度中为；焦骸射箭时的攻击冷却时间固定为。

被焦骸杀死的[苦力怕](苦力怕.md)会额外掉落一张*[13](音乐唱片13.md)*、*[cat](音乐唱片cat.md)*、*[blocks](音乐唱片blocks.md)*、*[chirp](音乐唱片chirp.md)*、*[far](音乐唱片far.md)*、*[mall](音乐唱片mall.md)*、*[mellohi](音乐唱片mellohi.md)*、*[stal](音乐唱片stal.md)*、*[strad](音乐唱片strad.md)*、*[ward](音乐唱片ward.md)*、*[11](音乐唱片11.md)*或*[wait](音乐唱片wait.md)*[音乐唱片](音乐唱片.md)。

焦骸免疫[虚弱](虚弱.md)效果。

与[尸壳](尸壳.md)不同，焦骸在水里不会转化为骷髅。<ref></ref>

# = 生物族群 =

焦骸是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉到水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

焦骸不会在阳光下[着火](着火.md)。
