# 毒马铃薯油

*页面ID: 138921* | *来源: Minecraft Wiki*

* *毒马铃薯油（Poisonous Potato Oil）**是由[毒马铃薯](毒马铃薯/24w14potato.md)精炼后得到的物品。

# 获取
# = 精炼 =
在[马铃薯精炼炉](马铃薯精炼炉.md)中精炼毒马铃薯可以精炼出毒马铃薯油，可以获得，精炼时间需要。

# = 箱子战利品 =

# 用途
# = 饮用 =
毒马铃薯油可以像[药水](药水.md)一样，通过长按键饮用。
* 饮用毒马铃薯油会获得的[非常滑](非常滑.md)效果和的[中毒](中毒.md)效果。
* 饮用后，会返还空玻璃瓶。

# = 烧炼 =
烧炼毒马铃薯油可获得杂质随机、清晰度为“糟糕”的[毒树脂](毒树脂.md)。烧炼时间为，比普通物品更慢。烧炼后，不会留下玻璃瓶。

# 你知道吗
* 虽然毒马铃薯油拥有与[药水](药水.md)相似的外观和功能，但毒马铃薯油的ID与药水不同，其也不存在“喷溅型毒马铃薯油”和“滞留型毒马铃薯油”物品。
* * 在[创造模式物品栏](创造模式物品栏.md)中可以找到名为“毒马铃薯油”的物品以及其喷溅型和滞留型变种。但这些物品的ID为<code>potion</code>，即它们是具有毒马铃薯油药水效果的药水。因此这些物品也不能被用来烧炼获得毒树脂。
* ** 这些药水形式的“毒马铃薯油”的瓶中液体呈现微微的淡绿色，而非真正的毒马铃薯油的白色。
