# 友好更新

*页面ID: 21628* | *来源: Minecraft Wiki*

[缩略图|300px|Mojang发布的友好更新的内容图](File:Pocket Edition Friendly Update Poster.png.md)

* *友好更新（Friendly Update）**是[携带版Alpha](携带版Alpha.md)的一次主要更新，该版本于2016年6月10日在Android平台发布，并于6月13日在全部平台发布。此次更新的名称于2016年6月3日Mojang网站上的博客帖子中公布。<ref></ref>

此次更新的开发始于[Alpha 0.15.0 build 1](携带版0.15.0.b1.md)，其发布于2016年6月3日。

# 重要特性

# = 新内容 =
* [Realms](Realms.md)，需要使用Xbox Live账户登录
* iOS与Android上的成就系统
* 通过Xbox Live实现的在线多人游戏
* 骑猪
* [活塞](活塞.md)与[黏性活塞](黏性活塞.md)
* [侦测器](侦测器.md)，方块更新检测器
* 羊现在掉落[羊肉](羊肉.md)
* 药箭，使用炼药锅制作
* 皮革马铠，可被染色
* 七种新生物：[马](马.md)、[驴](驴.md)、[骡](骡.md)、[骷髅马](骷髅马.md)、[僵尸马](僵尸马.md)、[流浪者](流浪者.md)、[尸壳](尸壳.md)
* [命名牌](命名牌.md)
* [拴绳](拴绳.md)
* [火焰弹](火焰弹.md)
* [胡萝卜钓竿](胡萝卜钓竿.md)
* 村庄现在可在针叶林和冰原生物群系中生成。

# = 更改 =
* [活板门](活板门.md)不再需要支撑方块。
* [剪刀](剪刀.md)破坏任何方块都会减少耐久值。
* 减少了在线多人游戏使用带宽以优化性能。
* 在热带草原生成的村庄现在使用金合欢木。
