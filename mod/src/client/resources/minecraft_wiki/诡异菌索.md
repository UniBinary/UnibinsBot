# 诡异菌索

*页面ID: 171571* | *来源: Minecraft Wiki*

* *诡异菌索（Warped Roots）**是一种[非固体](非固体方块.md)植物方块。

# 生成
# = 自然生成 =
诡异菌索自然生成于[诡异森林](诡异森林.md)生物群系。

# = 骨粉 =
对[诡异菌岩](诡异菌岩.md)[骨粉](骨粉.md)会使其上方和周围的两种菌岩上长出诡异菌索（有1%概率出现[绯红菌索](绯红菌索.md)<ref></ref>）。

# 破坏
诡异菌索被挖掘时会立刻被破坏。

诡异菌索被破坏后会掉落自身。

# 用途
# = 装饰 =
诡异菌索可被种植在[菌岩](菌岩.md)、[灵魂土](灵魂土.md)、[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。

诡异菌索也可被种在[花盆](花盆.md)中，且纹理与其方块形式不同。

# = 堆肥 =
对[堆肥桶](堆肥桶.md)使用诡异菌索会有65%的概率增加一层堆肥层数。
