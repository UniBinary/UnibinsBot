# New Nintendo 3DS版独有特性

*页面ID: 36076* | *来源: Minecraft Wiki*

下列是[New Nintendo 3DS版](New Nintendo 3DS版.md)的独有特性。

# 菜单屏幕
* 在玩家进入到下界时，下屏幕的地图会显示一个固定的地图，代表玩家的指针会固定在中间并稳定地顺时针旋转。
* 游戏将文件保存在microSD上的额外数据中，而不是内部存储中。
* * 这样做的原因可能是因为Minecraft比许多3DS游戏的占用存储空间大小还要大。
* * 因为New 3DS平台硬件的限制，游戏每20分钟会触发一次自动保存，在自动保存期间游戏会暂停。
* ** 自动保存的提醒时间分别是20分钟、10分钟、5分钟、1分钟和最后10秒中的每一秒。
* 在这个版本中，最大的世界尺寸为2016×2016，相比之下，*Wii U版*的864×864要小得多。
* * 这可能是因为额外的数据不受保存数据的限制。
* * 基岩版比原主机版占用空间更小，从而允许它们拥有更大的世界。
* 这个游戏的内部程序是“Proteus”和“Silverfish”。
* 这个版本没有官方公开的漏洞追踪器。
* 这个版本有20条独有的[闪烁标语](闪烁标语.md)。<ref></ref>
* * 其中10条是Other Ocean engineer设定的，以此“（希望）粉丝去发现它们”。<ref></ref>
* * 剩下的10个分别为：<ref></ref><ref></ref><ref></ref>
* ** “Coffee! Coffee now!”
* ** “Don't be that guy!”
* ** “Go to sleep! Go to sleep! It's time to go to sleep!”
* ** “Generate me a force field with that computer and a microwave!”
* ** “Ah, another visitor!”
* ** “Rise from your grave!”
* ** “What are you selling?”
* ** “Rob is jarig!”
* ** “Don, bear near?”
* ** “Don't awoo!”
* 这也是唯一一个[闪烁标语](闪烁标语.md)不倾斜着悬浮在标题右下角的版本。

# 世界生成
; [生物群系](生物群系.md)
* 生物群系会被缩放。

; [超平坦](超平坦.md)世界类型
* 名称为“平淡的”。
* 无法自定义。
* 没有村庄。

; [村庄](村庄.md)
* 铁匠铺的[箱子](箱子.md)可能含有[墨囊](墨囊.md)和[绿宝石](绿宝石.md)。
* 铁匠铺的箱子不包含[钻石](钻石.md)。
* 桌面是[棕色地毯](棕色地毯.md)而不是[压力板](压力板.md)。
* 独有地生成在[雪原](雪原.md)或[积雪针叶林](积雪针叶林.md)中，使用杉木生成，就像[针叶林](针叶林.md)村庄一样。
* [僵尸村庄](僵尸村庄.md)由[苔石](苔石.md)和[蜘蛛网](蜘蛛网.md)组成。
* [金合欢木](金合欢木.md)不会取代[热带草原](热带草原.md)村庄里的[圆石](圆石.md)。

; [树](树.md)
* 可能会出现垂死的树，树干上覆盖着[藤蔓](藤蔓.md)。

* * 它们上面往往长有藤蔓和[蘑菇](蘑菇.md)，并且木头朝水平方向。树苗也可能长出倒下的树。

; [巨型蘑菇](巨型蘑菇.md)
* 在[沼泽](沼泽.md)自然生成。

; [沼泽小屋](沼泽小屋.md)
* [炼药锅](炼药锅.md)装有随机[药水](药水.md)。
* * 可能是[喷溅药水](喷溅药水.md)。
* * 药水装满了或。

; [沙漠神殿](沙漠神殿.md)
* 宝藏箱不包含[火药](火药.md)、[线](线.md)和[沙子](沙子.md)。
* 如果在一个[峡谷](峡谷.md)或[河流](河流.md)中生成，神殿的地板会被峡谷或河流的底部替换，而不是[TNT](TNT.md)。

; [要塞](要塞.md)
* 图书馆的箱子不包含[指南针](指南针.md)和空[地图](地图.md)。
* 祭坛箱子不包括[末影珍珠](末影珍珠.md)。
* 拥有更大的概率生成于村庄的水井下方，并且轻易地可以不用[末影之眼](末影之眼.md)发现。

# 方块和物品
; [隐形基岩](隐形基岩.md)
* 弹射物可以穿过它。
* 具有阴影。
* 在物品栏中使用石头的一面纹理。

; [丛林树叶](丛林树叶.md)
* 不透明，无视图像设置。

; [切石机](切石机（MATTIS）.md)
* 可以在创造模式物品栏中获得，只有装饰用途。

; [甘蔗](甘蔗.md)
* 可以用[骨粉](骨粉.md)加快成长。

; [花](花.md)
* 在一格高的花上使用骨粉会使蒲公英或虞美人生长在其周围。

; [冰](冰.md)
* 不透明，无视图像设置。

; [雪](雪.md)
* 下雪后会增加层数。
* 受重力影响。
* 物品栏中名为“顶层雪”
* 在无雪生物群系会逐渐融化（峭壁生物群系除外）。
* 可以和部分植物形成[含雪](含雪.md)

; [灰化土](灰化土.md)
* 数据值是243，而不是3:2。

; [树叶](树叶.md)
* 在下雪的生物群系，如[积雪针叶林](积雪针叶林.md)，会出现结霜。

; [刷怪笼](刷怪笼.md)
* 挖掘所需时间比稍长。

; [无草泥土](泥土.md)
* 数据值为[Java版1.7](Java版1.7.md)的1，为砂土的临时替代物，但在1.5.2.3中加入的砂土导致其不可用。

; [水](水.md)
* 受平滑光照影响。
* 沼泽生物群系中的水是深灰色的。

; [船](船.md)
* 合成配方中有[木锹](木锹.md)。
* 摧毁后出现烟雾。

; [红石粉](红石粉.md)
* 单独放置后始终呈“+”型而不可切换为“·”，即使它没有连接到另一个红石元件。
* 没有半连接性。

; [黑曜石](黑曜石.md)
* 挖掘需要6.5秒而不是10秒。

; [下界砖块](下界砖块.md)
* 纹理更明亮。

; [附魔台](附魔台.md)
* 会发出12级亮光。

; [炼药锅](炼药锅.md)
* 水的颜色可以通过添加染料来改变。
* * 颜色可混合。
* 可用于染色（如皮革盔甲）。
* 可用水瓶加水。
* 可储存药水。
* * 将两种不同药水混合会发出爆炸声，并且药水会消失。
* * 炼药锅里的药水会发出其粒子效果。
* * 炼药锅里的药水可用于制作药水箭。

; [物品展示框](物品展示框.md)
* 使用方块实体而不是实体。
* 不能和透明方块共存。
* 不能彼此共存。
* 可以被[黏性活塞](黏性活塞.md)拉动，但是会因此被破坏，即使目标位置已有方块支撑。

; [小丑鱼](小丑鱼.md)和[河豚](河豚（物品）.md)
* 可用于驯服[豹猫](豹猫.md)。

; [钓鱼竿](钓鱼竿.md)
* 浮漂具有立体模型。

; [盔甲](盔甲.md)
* 皮革盔甲需要用[炼药锅](炼药锅.md)来染色，而不是合成格。

; [下界反应核](下界反应核.md)
* 仅用于装饰。
* 只能通过修改物品栏获得。
* 只能被有“精准采集”附魔的镐采集。
* * 如果不用镐破坏，它将不会掉落任何东西。
* * 如果用无“精准采集”附魔的镐破坏，它将会掉落3个钻石和6个铁锭。

; [数据更新方块](数据更新方块.md)
* 可通过编辑物品栏获得。
* 功能与纹理丢失方块相同。
* 可以空手开采（类似于泥土）。

; [活塞](活塞.md)和[黏性活塞](黏性活塞.md)
* 需要1刻才能缩回，而不是立即缩回。
* 有更粗的活塞臂。
* 可以推动箱子和发射器之类的[方块实体](方块实体.md)。

; [侦测器](侦测器.md)
* 用于检测方块更新（BUD）。
* 使用6个圆石，1个石英和2个红石粉合成。
* 有不同的纹理。

; [药箭](药箭.md)
* 通过装满药水的炼药锅制作。

; 皮革[马铠](马铠.md)
* 可以使用炼药锅染色。
* 可以在工作台通过7个[皮革](皮革.md)形成的“H”型以合成。

; [苔石](苔石.md)
* 可以在[僵尸村庄](僵尸村庄.md)内发现。

; [蜘蛛网](蜘蛛网.md)
* 可生成在僵尸村庄建筑顶部。

; [告示牌](告示牌.md)
* 总共可以写入四行文本，但是只有前三行会显示在告示牌上，第四行会出现在错误的位置。
* * 如果仅按十字键下键无法到达第四行，只有在第一行按十字键上键才能在第四行写入文本。
* 每行可以写入15个字符，但是当字符长度超过告示牌显示范围时会有一部分字符变成“...”

; [不死图腾](不死图腾.md)与[探险家地图](探险家地图.md)
* 只要在快捷栏中就能生效，无需玩家手持。可能与缺少双持机制有关。
* 探险家地图在第一人称视角中也会以物品形式拿在手中，其效果变为在下屏幕的地图中显示对应结构位置的图标。

# 生物
; 所有生物
* 如果玩家被着火的生物攻击，那么玩家也会着火。

; 幼年[僵尸](僵尸.md)
* 它们有15%的概率生成鸡骑士，如果触发此事件，则在攻击玩家之前会顺次优先考虑骑乘下列生物：
* * [洞穴蜘蛛](洞穴蜘蛛.md)
* * 成年[鸡](鸡.md)
* * [牛](牛.md)
* * [马](马.md)、[驴](驴.md)和[骡](骡.md)
* ** 变得不可骑乘并且受幼年僵尸或幼年尸壳控制。
* * 成年[尸壳](尸壳.md)
* * [哞菇](哞菇.md)
* ** 仍可以被剪掉蘑菇，但是幼年僵尸或幼年尸壳会下来。
* * 成年[豹猫](豹猫.md)
* ** 几乎不会攻击玩家，由于该豹猫会不断远离玩家，而且速度稍慢，因为豹猫有幼年僵尸的速度，而且还可以被驯服，如果豹猫被驯服，幼年僵尸或幼年尸壳会下来。
* * [猪](猪.md)
* * [绵羊](绵羊.md)
* ** 绵羊仍可以被染色。
* * [骷髅马](骷髅马.md)
* ** 变得不可骑乘，当被闪电击中时，骷髅马不会变成骷髅骑士。如果已经包含一个骑士，骷髅将受幼年僵尸或幼年尸壳控制。
* * [蜘蛛](蜘蛛.md)
* * 成年[狼](狼.md)
* ** 狼变为敌对，但不会惹怒其他的狼。
* * 成年[僵尸](僵尸.md)
* ** 僵尸仍会在日光下燃烧。
* * [僵尸马](僵尸马.md)
* ** 变得不可骑乘并且受幼年僵尸或幼年尸壳控制。
* * 成年[僵尸猪人](僵尸猪人.md)
* ** 僵尸猪人会变得敌对，但不会惹怒其他的僵尸猪人。
* * 成年[僵尸村民](僵尸村民.md)
* ** 僵尸村民仍然可以被治疗，但在被治疗后，幼年僵尸会下来。
* * 如果幼年僵尸骑着的生物死亡或消失，幼年僵尸会尝试使用其他生物再次成为骑士。

; [洞穴蜘蛛](洞穴蜘蛛.md)
* 有1%的概率变成[蜘蛛骑士](蜘蛛骑士.md)。
* * 如果在下界，它们会有1%概率以凋灵骑士形式生成（这将使其变得更危险，因为如果玩家被攻击，玩家会获得洞穴蜘蛛和凋灵骷髅给予的状态效果）。
* * 如果有洞穴蜘蛛[刷怪笼](刷怪笼.md)的[废弃矿井](废弃矿井.md)生成在有雪的[生物群系](生物群系.md)，洞穴蜘蛛有概率和流浪者作为蜘蛛骑士[生成](生成.md)。

; [鸡](鸡.md)和[猪](猪.md)
* 其幼体可以自然生成。

; [绵羊](绵羊.md)
* 绵羊的面孔和剪毛后毛孔的颜色对应毛的颜色。
* 幼体可以自然生成。

; [雪傀儡](雪傀儡.md)
* 生成时可以将南瓜灯作为头。
* * 头仍然会显示为普通的南瓜。

; [鱿鱼](鱿鱼.md)
* 仅在海洋变种和海滩生物群系中生成。
* 拥有独有的生成、潜水或死亡时的音效。
* 是游戏中唯一分类为“水生生物”的生物。

; [狼](狼.md)
* 幼年狼可以自然生成。

; [烈焰人](烈焰人.md)
* 在暗处发亮。

; [恶魂](恶魂.md)
* 有发光的眼睛。

; [岩浆怪](岩浆怪.md)
* 核心在黑暗中发光。

; [蜘蛛骑士](蜘蛛骑士.md)
* 可生成洞穴蜘蛛，取代蜘蛛的位置。
* 能生成幼年僵尸，取代骷髅的位置。

; [洞穴蜘蛛骑士](洞穴蜘蛛骑士.md)
* 能生成洞穴蜘蛛，取代蜘蛛的位置。

; [骷髅](骷髅.md)
* 如果有骷髅手持不是弓的物品，骷髅不会近战，但是如果它以前是持弓的话那么骷髅会用箭攻击玩家。

; [僵尸](僵尸.md)
* 如果手持物品，那么死后有8.5%的概率掉落该物品。

; [凋灵骷髅](凋灵骷髅.md)
* 能和洞穴蜘蛛生成凋灵骷髅骑士。
* 携带弓的凋灵骷髅只能通过物品栏编辑器生成。

# 游戏内容
* [着火](着火.md)实体带有的火焰动画会根据玩家视角而变换角度，且燃烧较慢。
* 物理阴影的方向取决于太阳的位置。
* 日出、日落时分，云层会呈现橘红色。
* [水](水.md)带有平滑光照且透明度相同。
* 发光方块（如正在工作的熔炉、熔岩）的四周没有阴影。
* 窒息的动画不同。
* 下界传送门的进入动画不同。
* 玩家的燃烧动画不同。
* 熔岩的动画不同。
* 有些生物有攻击动画。
* * [僵尸猪人](僵尸猪人.md)和幼年僵尸猪人。

* 未来计划支持New 3DS的立体3D，但由于New Nintendo 3DS版已不再更新，故未实现。<ref>[HelenAngel的讨论页编辑](:en:Special:diff/1147139.md)</ref>
* 目前New Nintendo 3DS版没有[多人游戏](多人游戏.md)。本地ad-hoc联机已在1.4加入。<ref></ref>
* 世界类型为默认和[超平坦](超平坦.md)。世界的大小为[小型](小型（世界类型）.md)（672×672）、[中型](中型（世界类型）.md)（1344×1344）和[大型](大型（世界类型）.md)（2016×2016），世界大小一旦生成不能更改。[下界](下界.md)与[主世界](主世界.md)大小的比值为1：3。
* 世界高度被限制为128，就像在携带版Alpha那样，虽然大小可以比[原主机版](原主机版.md)中的[典型](典型（世界类型）.md)和[小型](小型（世界类型）.md)世界类型大。
* 生物的存在比主机版严格：只能有24个敌对型生物、24个被动型生物、16个水生生物（仅包括[鱿鱼](鱿鱼.md)）和16个[村民](村民.md)同时存在，[末影龙](末影龙.md)和[凋灵](凋灵.md)只能各存在1个，[铁傀儡](铁傀儡.md)和[雪傀儡](雪傀儡.md)总共只能存在2个，但是[经验球](经验球.md)不受此限制。
* * 如果对应生物已满，[刷怪蛋](刷怪蛋.md)会提示“世界中的*生物类型*数已达到上限。”，[发射器](发射器.md)会把刷怪蛋以物品形式掷出，而凋灵、铁傀儡和雪傀儡的组成方块不会被消耗。
* 没有[地图](地图.md)物品，但地图会始终显示在触摸屏上。玩家的[坐标](坐标.md)会显示在快捷栏与地图之间，当玩家选择物品时，选择物品的对应名称及其部分信息（如物品已有魔咒、药水持续时间等）会短时间内覆盖坐标。触摸屏也可用于管理[物品栏](物品栏.md)和[合成](合成.md)。
* [玩家](玩家.md)身上的[状态效果](状态效果.md)没有单独的页面，也不在物品栏中显示，而是直接以图标和效果等级、剩余持续时间的组合形式显示在上屏幕左侧。
* “选项”中只能调整[难度](难度.md)、鼠标灵敏度、自动跳跃、反转Y轴、亮度、视角摇晃、音效和音乐的音量、游戏语言，查看更新补丁日志、玩家名称、世界种子、手册、制作人员名单。
* * 世界创建/编辑屏幕中只有世界名称、游戏模式、难度、世界大小（世界编辑屏幕中不显示）、纹理包、终为白日、世界种子和世界类型（世界编辑屏幕中不可调整）。
