# 用途

[玩家](玩家.md)钓鱼竿时会发射一个**浮漂（Fishing Hook/Fishing Bobber）**，再次就能收竿，使浮漂被拉回到玩家的位置。浮漂与钓竿之间由鱼线连接，鱼线的最大释放长度为32米，这是一个固定机制，没有任何手段可以改变鱼线的最大释放长度。在浮漂被发射后，切换到别的物品会导致浮漂消失，而钓鱼竿的耐久度不会下降。

收竿时，钓鱼竿会产生[耐久度](耐久度.md)消耗：
* 通过[钓鱼](钓鱼.md)成功钓上物品会消耗1点耐久度。
* 浮漂钩在地面上时收回会消耗2点耐久度。
* 浮漂钩在实体上时收回会消耗5点耐久度，无论实体是否能被钩走；浮漂钩在[物品实体](物品实体.md)上时收回会消耗3点耐久度。

浮漂不可通过命令生成。

# = 钓鱼 =

钓鱼竿的主要用途是钓鱼。玩家可以向[水](水.md)中发射浮漂来进行钓鱼，获得多种物品。

# = 钩实体 =
浮漂可以钩住多种[实体](实体.md)。在浮漂钩住实体时，收竿会将它们拉向使用-{}-者，施加一个朝向收竿玩家的猛烈动量，以米每秒为单位的动量值在数值上等于浮漂到收竿玩家的以米为单位的距离值的。

浮漂可以钩住发射该浮漂的玩家。如果玩家此时收杆，玩家会对自己施加动量，但通常会因为浮漂和自己在同一位置而只能提供零强度的动量。

如果被浮漂钩中的实体正在骑乘其他实体，收竿会使其脱离坐骑。

类似于[雪球](雪球.md)等，浮漂是会造成伤害的[弹射物](弹射物.md)。该伤害可以产生击退。虽然不能对大多数生物的生命值造成影响，生物仍然会将其视为一种攻击行为并做出相应的反应。末地水晶或画等实体也将因此爆炸或掉落。

# 你知道吗
* [玩家](玩家.md)最远能把钓鱼竿浮漂抛出33格。
* 玩家能在抛竿后上[床](床.md)睡觉，鱼线和浮漂不会消失。
* 钓鱼竿浮漂具有3D模型。
* 若玩家乘坐[矿车](矿车.md)时一直抛竿钓住该矿车并收竿，矿车就会飞起来。
* [隐藏HUD](平视显示器#选项.md)时，玩家手持的钓鱼竿和会被隐藏，但钓鱼竿的其余部分仍然可见。
* 浮漂抛至[熔岩](熔岩.md)中时，浮漂会在熔岩中下沉，且浮漂会着火，但钓鱼竿的耐久并不会因此减少。浮漂抛至熔岩中时，会自动收竿。
* 使用指令更改物品数据的刷怪笼、试炼刷怪笼、刷怪蛋生成的浮漂在生成后会立即消失。
