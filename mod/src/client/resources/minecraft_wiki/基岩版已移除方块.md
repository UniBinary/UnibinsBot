# 基岩版已移除方块

*页面ID: 98498* | *来源: Minecraft Wiki*

在及其前身的开发历程中，有一些方块被移除了。这些方块可能被替代，或者开发者在晚些时候决定不制作这个方块而被移除。

# 故障草（253号方块）

* *故障草（<samp>grass_carried</samp>）**存在于早期的[携带版](携带版.md)中，该方块的数字ID为253。它有与一般[草方块](草方块.md)相同的顶部纹理，但有特别的底部纹理。

该方块在[携带版0.8.0.b1](携带版0.8.0.b1.md)中被移除，可能是由于该版本中物品渲染的变化。现在其原本对应的数字ID指向[强化玻璃](强化玻璃.md)。

# 故障叶（254号方块）

* *故障叶（<samp>leaves_carried</samp>）**与故障草同样存在于早期的[携带版](携带版.md)中，数字ID为254，对应的数字ID已被[染色强化玻璃](染色强化玻璃.md)替代。其用于存储[树叶](树叶.md)在物品栏中的方块物品的模型形式，与253号方块类似，但是为与普通树叶相似的着色树叶， damage值为0、1和2的故障叶分别着色为, 和。

# 空数字ID槽位的占位符方块
在[基岩版1.2.10.1](基岩版1.2.10.1.md)到[基岩版1.6.0](基岩版1.6.0.md)之间的版本中，空的数字ID槽位的都被一些占位符方块填满，这些占位符方块的纹理都使用着[数据更新方块](数据更新方块.md)的纹理，音效则为石头的音效，在生存模式下可以被瞬间破坏并获得，类似于[未知方块](未知方块.md)。这些方块在物品栏的数字ID与它们的方块数字ID对应，方块数字ID大于255的在物品栏的数字ID则为<code>-{}-255-方块ID</code>。下面是来自基岩版1.2.10.1的例子：

# 残缺的活塞

[150px|右](File:Weird Piston.png.md)
曾经，特殊值为6和7的活塞外观为穿模的活塞，这是在加入正常的活塞时类似[Java版的六面活塞方块](Java版已移除方块#六面共用纹理的方块.md)一样被意外加入的，尽管这有待确认。其在[1.13.0.1](基岩版1.13.0.1.md)中被移除。

在[携带版0.15.0.b1](携带版0.15.0.b1.md)中，活塞首次加入进游戏，如果用其他方式放置特殊值为1-5的活塞，它会变成无头活塞。特殊值为7的活塞会隔一个方块推动方块。特殊值为8-15的活塞，其行为与特殊值为0-7的活塞相同。

在更高的版本中尝试放置该特殊值的方块，将会放置一个正常的活塞，但方向是随机的。

# 花岗岩、磨制花岗岩和闪长岩架的钟

<div style="float:right;">
[150px](File:Granite Bell.png.md)
[150px](File:Polished Granite Bell.png.md)
[150px](File:Diorite Bell.png.md)
</div>
在钟被引入基岩版后，使用[花岗岩](花岗岩.md)、[磨制花岗岩](磨制花岗岩.md)和[闪长岩](闪长岩.md)纹理的钟也被加入了。这些钟只能通过命令来放置。

这有可能是钟的方块状态程序不完整造成的。钟可以面向四个方向，此时有四种不同类型的钟（石架钟与这三种钟并列），这将对应于四个正交的朝向。由于此时花岗岩和闪长岩被储存为[石头](石头.md)的数据值，所以这会从所使用的石头纹理的对应数据值中被提取出来。试图放置一个数据值为4或以上的钟会失败，因为这些钟没有任何对应的方向，因此也没有[磨制闪长岩](磨制闪长岩.md)、[安山岩](安山岩.md)或[磨制安山岩](磨制安山岩.md)的钟。

# 无钟钟架
[150px|右](File:Bellless_Bell_BE1.png.md)
基岩版曾有一个未使用的[钟](钟.md)，由没有钟的支架组成。这个钟不能被敲响，但它在被破坏后会掉落一个正常的钟。

# 不能使用的烟熏炉、高炉、讲台和木桶
基岩版曾有几个未使用的方块处于锁定状态。这些方块不能被玩家打开或使用（它们的GUI不显示，但玩家的手仍然可以执行一个动作）。

在一次未知的更新中，它们被并入了正常版本的方块。

# 无烟营火

从1.10.0测试版更新到1.11.0的营火不会产生烟雾颗粒，因为1.10.0的营火没有实际功能，它在一次未知的更新中被合并到正常版本的方块中。

# 带插槽的神秘框架

[150px|右](File:Mysterious Frame Slot.png.md)
神秘框架是[强化深板岩](强化深板岩.md)的前身，具有相同的ID和纹理。神秘框架曾经具有带插槽的方块变种，两者最初被设计为[远古城市](远古城市.md)的巨大传送门结构的组成方块。

带插槽的神秘框架仅存在于开发者版本中，在[基岩版1.18.30.32](基岩版1.18.30.32.md)，神秘框架被重命名为强化深板岩加入常规版本，而带插槽的神秘框架被移除。

# 平滑石砖

[150px|右](File:Smooth Stone Bricks.png.md)
* *平滑石砖（Smooth Stone Bricks）**是[石砖](石砖.md)的未使用变种，该方块只能通过命令获取，且没有实际用途。

在[基岩版1.21.10.20](基岩版1.21.10.20.md)中，石砖的ID<code>stonebrick</code>被拆分，原有的平滑石砖会转换为石砖。

# 结构空气

* *结构空气（Structure Air）**是方块状态为的结构空位。结构空气在结构保存与加载中与普通方块一致，可以被加载到世界中，而不像普通结构空位一样表现为不替换方块。

在[基岩版1.21.30.21](基岩版1.21.30.21.md)中，移除了方块状态<code>structure_void_type</code>，现有的结构空气会转化为结构空位。
