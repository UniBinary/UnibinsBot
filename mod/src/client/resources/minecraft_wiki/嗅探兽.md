* *嗅探兽（Sniffer）**是一种友好生物，会时常嗅探空气，有时能刨挖出远古植物的种子。

# 生成

嗅探兽不会自然生成，只能从[嗅探兽蛋](嗅探兽蛋.md)中孵出。孵化通常要约20分钟，但若放置在[苔藓块](苔藓块.md)上方则仅需约10分钟。

# 掉落物
嗅探兽在被[玩家](玩家.md)或驯服的[狼](狼.md)杀死时会掉落。

幼年嗅探兽死亡时不会掉落任何物品和经验。

# 行为
[thumb|正在刨挖种子的嗅探兽](File:Sniffer digs.png.md)
嗅探兽会漫无目的地移动，时常嗅探空气，闻嗅时其鼻子会小幅拉长。

有时嗅探兽会用力闻嗅一次，探测以自己为中心的水平半径20格、垂直半径3格内是否存在[泥土](泥土.md)、[草方块](草方块.md)、[灰化土](灰化土.md)、[砂土](砂土.md)、[缠根泥土](缠根泥土.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[泥巴](泥巴.md)或[沾泥的红树根](沾泥的红树根.md)，若有则向其走动，期间会将鼻子贴近地面，规律地左右摆头并连续嗅探。到达目的方块后，嗅探兽会在原地将三对腿分别向左右张开，使身体紧贴地面，然后低头刨挖一段时间，被挖掘方块上方会生成大量方块破坏粒子。刨挖结束后，嗅探兽会扬头抛出一份[火把花种子](火把花种子.md)或[瓶子草荚果](瓶子草荚果.md)，并在接下来的一段时间开心地左右摇晃头部与扇动耳朵，然后恢复正常行为。嗅探兽刨挖出火把花种子或瓶子草荚果的概率相同。

若选定的方块在嗅探兽向其走动的过程中变得无法到达，嗅探兽会抬起头，然后再次用力闻嗅并重复先前行为，重复数次后若仍无法成功则会放弃尝试。每次刨挖后将会进入一段持续的冷却时间，并在接下来20次嗅探中忽略这次刨挖的方块。嗅探兽向选定的方块走动时，只要所处高度发生变化便会立即放弃嗅探。

嗅探兽在刨挖方块时受伤或所处高度发生变化会停止刨挖。

嗅探兽被[拴绳](拴绳.md)拴住时不会刨挖。

幼年嗅探兽不会刨挖。

嗅探兽会跟随/内手持[火把花种子](火把花种子.md)的玩家。

# = 繁殖 =

嗅探兽可通过喂食火把花种子[繁殖](繁殖.md)，同时会掉落1-7经验值和一个[嗅探兽蛋](嗅探兽蛋.md)，繁殖后双亲有/的冷却时间。嗅探兽蛋孵出的幼年个体需40分钟才能成长为成年个体，可使用火把花种子加速成长，每次减少10%剩余成长时间。

对幼年嗅探兽[金蒲公英](金蒲公英.md)可以阻止其成长为成年嗅探兽，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年嗅探兽无法被喂食除金蒲公英外的其他物品。

与其他幼年生物不同，幼年嗅探兽不会跟随成年个体。<ref></ref>

# = 治疗 =

给生命值未满的成年嗅探兽喂食火把花种子可使其恢复点生命值，此时嗅探兽不会进入求爱模式。

* 幼年嗅探兽的官方英文名称为“**Snifflet**”。<ref></ref>
* 嗅探兽的行走动作参考了现实中的蜈蚣，张开腿趴地的姿势参考自现实中柯基犬的“板鸭趴”姿势。<ref></ref>
