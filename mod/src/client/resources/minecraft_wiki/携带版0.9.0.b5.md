# 携带版0.9.0.b5

*页面ID: 31493* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.9.0 build alpha 5**是[v0.9.0 alpha](携带版0.9.0.md)的第5个测试版，发布于2014年6月18日，修复了一些漏洞。

# 更改
# = 方块 =
* *[高草丛](高草丛.md)**
* 不再可燃。

* *[火把](火把.md)**
* 加快了[火把](火把.md)放置速度。

# = 物品 =
* *[绿宝石](绿宝石.md)**
* 为与[绿宝石](绿宝石.md)有关的物品加入了合成配方。

# = 常规 =
* *纹理**
* 纹理改为在后台加载以避免卡顿。

* *优化**
* 优化LevelDB的编译。
* 再次优化破坏方块的粒子效果。
* 优化粒子的渲染。

# 修复
* *修复了9个漏洞**
* 多人游戏中的漏洞。
* 爆炸可能会引起崩溃。
* 游泳以及探索洞穴时，天空会变暗。
* 水在熔岩上方随世界生成时不会制造出黑曜石。
* 光照的错误更新。
* TNT不会重建图形。
* TNT不会引爆其他TNT。
* 云杉树苗无法生长成红杉。
* 各类墙、门和靠近墙的活板门的某一侧会有黑色纹理。</onlyinclude>
