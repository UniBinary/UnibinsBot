# Java版16w33a

*页面ID: 24027* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w33a**是[Java版1.11](Java版1.11.md)的第3个快照，发布于2016年8月17日<ref></ref>，加入了2条新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* “Should not be played while driving”
* “You're going too fast!”

# 更改
# = 方块 =
* *[床](床.md)**
* 现在当玩家与床，但不在床旁边时，会显示一条信息：
* * “You may not rest now, the bed is too far away”（你现在不能休息，床离你太远）。
* * 之前，玩家不会收到信息，也不能睡觉。

* *[旗帜](旗帜.md)**
* 当使用非染料物品，例如[苦力怕头颅](苦力怕头颅.md)或[附魔金苹果](附魔金苹果.md)涂图案时，现在需要[染料](染料.md)。
* * 在此之前，缺少染料会涂黑色图案。

# = 物品 =
* *[盾牌](盾牌.md)**
* 与旗帜合成时会保留魔咒等级和耐久度。

# = 生物 =
* *农民[村民](村民.md)**
* 现在销售5-7个[苹果](苹果.md)，而不是5个。
* 现在销售6-10个[曲奇](曲奇.md)，而不是6个。

* *[远古守卫者](远古守卫者.md)**
* 现在掉落一个湿[海绵](海绵.md)而不是干海绵。

# = 游戏内容 =
* *[烧炼](烧炼.md)**
* 更多物品可以在熔炉中作为燃料：
* * 1个[羊毛](羊毛.md)可以烧0.5个物品。
* * 1个[地毯](地毯.md)可以烧0.33个物品，比少一点。
* * 1个[梯子](梯子.md)可以烧1.165个物品，比少一点。
* * 1个[木质按钮](木质按钮.md)可以烧0.5个物品。
* * 1个[弓](弓.md)可以烧1.5个物品。
* * 1个[钓鱼竿](钓鱼竿.md)可以烧1.5个物品。
* * 1个[告示牌](告示牌.md)可以烧1个物品。
* * 1个[碗](碗.md)可以烧0.5个物品。
* * 1个[木门](木门.md)可以烧1个物品。
* * 1个[船](船.md)可以烧2个物品。

# = 常规 =
* *[字幕](字幕.md)**
* 远古守卫者和僵尸村民现在拥有与守卫者和僵尸不同的字幕。
