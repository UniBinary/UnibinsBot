# Java版13w18c

*页面ID: 33528* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w18c**是[Java版1.6.1](Java版1.6.1.md)的第6个快照，发布于2013年5月2日<ref></ref>，发布以修复[13w18a](13w18a.md)和[13w18b](13w18b.md)里的漏洞和崩溃。

# 更改

* *[煤炭块](煤炭块.md)**
* [煤炭块](煤炭块.md)的烧炼时间从720秒变为800秒。
* * 能烧炼80个[物品](物品.md)，相当于10个[煤炭](煤炭.md)。
