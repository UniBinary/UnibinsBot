# Java版1.20.5-rc1

*页面ID: 119102* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.20.5-rc1**是[Java版1.20.5](Java版1.20.5.md)的首个发布候选版本，发布于2024年4月18日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *协议**
* 更改了游戏客户端由于服务器发送的中的无效数据而断开连接的方法。
* * 为了简化过渡期，经过修改的服务器可以通过在<code>handshake/game_profile</code>中设置合适字段来选择退出。
* * 该选项将在下个正式版中删除。
