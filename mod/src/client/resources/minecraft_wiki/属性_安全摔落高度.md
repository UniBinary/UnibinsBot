# 属性/安全摔落高度

*页面ID: 122718* | *来源: Minecraft Wiki*

* *安全摔落高度（Safe Fall Distance）**是控制生物摔落而不受伤害的最大高度的[属性](属性.md)。

# 行为

当生物摔落触地时，如果下落高度小于此属性计算值，则不产生落地粒子。

当生物摔落触地时，游戏按照下列步骤计算摔落伤害：
# 获取生物的下落高度*f*和此属性计算值*h*。
# 获取生物脚下的方块，修正下落高度，获得方块摔落伤害系数*r*：
# * 如果为[干草捆](干草捆.md)和[蜂蜜块](蜂蜜块.md)，则摔落伤害系数*r*为0.2。
# * 如果为[床](床.md)，则摔落伤害系数*r*为0.5。
# * 如果为方向向上的[滴水石锥](滴水石锥.md)，则下落高度<math>f \leftarrow f+2</math>，摔落伤害系数*r*为2。
# * 其他方块摔落伤害系数*r*为1。
# 获取摔落伤害倍数属性计算值为*a*，则摔落伤害为<math>d=\left\lceil\left(f-h\right)ra\right\rceil</math>。
# 对于部分生物，摔落伤害会被强制减少：
# * [山羊](山羊.md)的摔落伤害固定减少10，即<math>d \leftarrow d-10</math>。
# * [青蛙](青蛙.md)的摔落伤害固定减少5，即<math>d \leftarrow d-5</math>。
