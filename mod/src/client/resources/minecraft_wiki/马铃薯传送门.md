# 马铃薯传送门

*页面ID: 144249* | *来源: Minecraft Wiki*

* *马铃薯传送门（Potato Portal）**是一种由[传送门底座](传送门底座.md)生成的方块，能够传送玩家进出[马铃薯维度](马铃薯维度.md)。

# 生成
# = 传送门底座 =
对着[主世界](主世界.md)或[马铃薯维度](马铃薯维度.md)中的[传送门底座](传送门底座.md)[毒马铃薯](毒马铃薯.md)后，如果传送门底座上方是可替代的方块，则会生成马铃薯传送门，并消耗一个毒马铃薯。

# = 马铃耶什，农民的传说之杖 =
已获得“”（Non Plus Ultra）进度的玩家或创造模式玩家[马铃耶什，农民的传说之杖](马铃耶什，农民的传说之杖.md)会放置一个马铃薯传送门。

# 获取
马铃薯传送门不能在生存模式中正常获得，但可以通过[创造模式物品栏](创造模式物品栏.md)或[命令](命令.md)获得。

# 破坏
马铃薯传送门不能被挖掘破坏。

# 用途
当一个玩家待在[主世界](主世界.md)或者[马铃薯维度](马铃薯维度.md)的马铃薯传送门内4秒后，玩家会传送到对应的维度里。玩家可以在传送动画结束前走出传送门来取消传送。如果玩家处于[创造模式](创造模式.md)，那么玩家会在进入传送门的瞬间被传送。创造模式和非创造模式玩家传送之前需要等待的时间分别由[游戏规则](游戏规则.md)控制。如果玩家骑乘在生物上，玩家及生物均不会被传送门传送。

大多数实体都能通过马铃薯传送门传送，包括各种[生物](生物.md)（除了[凋灵](凋灵.md)和[末影龙](末影龙.md)）、[船](船.md)、[矿车](矿车.md)、[弹射物](弹射物.md)和[物品实体](物品实体.md)。实体组合（例如[蜘蛛骑士](蜘蛛骑士.md)）不能通过传送门。

与[下界传送门](下界传送门.md)不同，马铃薯传送门只会在传送时搜索目标坐标64×64范围内的兴趣点。在坐标上，[马铃薯维度](马铃薯维度.md)和[主世界](主世界.md)的比例为1:1，即玩家在传送后的坐标不会改变。

# = 进入或离开下界 =
当玩家在进行传送时破坏马铃薯传送门，马铃薯传送门会表现出下界传送门的行为。
* 若玩家原本在主世界或末地：传送到下界的下界传送门的位置。
* 若玩家原本在下界：传送到主世界的下界传送门的位置。
* 若玩家原本在马铃薯维度：传送到下界的马铃薯传送门的位置。
若在对应位置附近找不到合适的传送门则生成一个新的。

[TNT](TNT.md)的引信时间刚好是4秒，在生存模式下可以使用[线](线.md)和[侦测器](侦测器.md)在玩家接触传送门时立刻激活TNT稳定实现此操作。

# = 活塞推动行为 =
马铃薯传送门无法被[活塞](活塞.md)推拉，但可被[悬浮马铃薯推进器](悬浮马铃薯推进器.md)推动。

# = 光源 =
马铃薯传送门会发出亮度等级为15的光。
