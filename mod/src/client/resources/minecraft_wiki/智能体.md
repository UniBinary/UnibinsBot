* *智能体（Agent）**一般被认为是一种[教育版](教育版.md)独有[生物](生物.md)，但实际上在[基岩版](基岩版.md)同样可以被召唤。通常情况下它通过让玩家进行编程来控制，来实现帮助玩家学习编程的目的。

# 生成
智能体不会自然生成，但是能通过或[命令](命令.md)生成。

不能直接使用来生成或控制智能体，而是需要利用[NPC](NPC.md)执行，或使用WebSocket执行。

如果智能体被结构方块保存并由另一位玩家加载时，所加载的智能体会变为那位加载结构的玩家所有。但那位玩家无法使用控制。当其由命令方块使用加载时，智能体会被隐藏。

智能体也可以在基岩版中使用[MyAgent](https://github.com/mcpews/MyAgent)等工具创建，详见[Tutorial:WebSocket](Tutorial:WebSocket.md)。

# 掉落物
智能体死亡时不会掉落任何[物品](物品.md)和[经验](经验.md)。

# 行为
智能体是一种生物，但没有生物行为。

智能体不能被任何影响移动的效果移动，不会[下落](摔落.md)，不会被[水流](水流.md)移动，不会被[爆炸](爆炸.md)推动。

智能体未接收到来自WebSocket端的命令时，如果脚下没有方块则会在原地上下飘浮，如果有方块则会站在方块上。

智能体的名称会保持显示并且被随机赋予颜色，名字格式为：<code>-{}-主人名称.Agent</code>，示例：Steve.Agent。

智能体能破坏所有有掉落物形式的方块。

智能体无论是否在未加载的区块中，当玩家作为执行者执行<code>/agent tp</code>时都可将其传送至玩家所在坐标。

智能体免疫[状态效果](状态效果.md)。

智能体在主人传送到另外一个维度时，会被传送到传送门旁边。

# = 隐藏 =
智能体会随着主人退出游戏而在原地隐藏，在主人重新进入游戏时出现。

智能体在隐藏状态时名字会被一起隐藏。

智能体隐藏时没有碰撞箱，但即便如此也不能在智能体所在坐标放置方块。

# = 用法 =
智能体通常与适用于Minecraft的[代码连接](代码连接.md)配合使用，并且可以通过可视化[ScratchX](wzh:Scratch.md)编程。

智能体拥有自己的27个物品的物品栏，可以由玩家编程使用命令来操作，或直接由玩家可以在游戏中访问的GUI进行编辑。

可视化界面允许玩家将命令、结构建筑及其他组件拖放至一个序列中，并将此序列与一个自定义名称的消息命令（ChatCommand）相关联，这个命令可以以发送消息的方式在控制台中执行。

# = 受伤害行为 =
智能体免疫伤害。
