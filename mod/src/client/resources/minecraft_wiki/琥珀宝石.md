# 琥珀宝石

*页面ID: 143736* | *来源: Minecraft Wiki*

* *琥珀宝石（Amber Gem）**是一种可用于[交易](交易.md)的[物品](物品.md)。

# 获取
# = 制箭 =
[毒树脂](毒树脂.md)的清晰度达到“宝石（Jewel）”时会被[制箭台](制箭台/24w14potato.md)转换为琥珀宝石。

# 用途
# = 交易 =

琥珀宝石可用作与[村民](村民.md)和[流浪商人](流浪商人.md)进行出售交易的货币。

# = 信标 =
琥珀宝石可用于从[信标](信标.md)中选择并激活[状态效果](状态效果.md)。玩家必须选择一种可用的状态效果，然后在物品槽中放入一个琥珀宝石。

琥珀宝石可以代替[铁锭](铁锭.md)、[金锭](金锭.md)、[钻石](钻石.md)、[绿宝石](绿宝石.md)或[下界合金锭](下界合金锭.md)为信标选择状态效果。
