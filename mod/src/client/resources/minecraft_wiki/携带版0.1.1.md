# 携带版0.1.1

*页面ID: 21240* | *来源: Minecraft Wiki*

* *v0.1.1 alpha**是[携带版](携带版.md)的一次次要更新，发布于2011年10月7日<ref name=":0"></ref>。该版本是首个面向所有[Android](wzh:Android.md)设备的版本。
# 新内容
# = 常规 =
* 新的物品栏界面。
* 新的方向键纹理。
* * 比原来更加精致且高清。

# 更改
# = 常规 =
* 略微修改了[主菜单](主菜单.md)中按钮的纹理。
* [暂停菜单](暂停菜单.md)的按钮纹理从[Java版](Java版.md)的按钮纹理改为了触摸屏UI的纹理。
* 新建世界按钮的纹理改为了触摸屏UI的纹理。

# 内部版本
* *v0.1.1 alpha**的内部版本号为0.1.1(1015)，大小为1.56MB。

# J版本
[thumb|v0.1.1 alpha的J版本](File:Pocket Edition 0.1.1j.png.md)
* *v0.1.1j alpha**在Google Play上于未知日期发布，发布给较旧的Android设备提供支持。<ref></ref>其内部版本号为0.1.1(1013)，大小为1.99MB。
