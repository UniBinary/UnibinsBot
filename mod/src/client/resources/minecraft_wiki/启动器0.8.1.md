# 启动器0.8.1

*页面ID: 49312* | *来源: Minecraft Wiki*

* *0.8.1**是一个在2013年5月21日发布的一个[启动器](启动器.md)版本。

# 更改
* 客户端将在选中快照后使用工作台作为icon。
* * 启动器仍然使用草方块作为icon。
* * 选择已发布的游戏版本仍然使用Java图标作为icon。
