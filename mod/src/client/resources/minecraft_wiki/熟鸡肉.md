# 熟鸡肉

*页面ID: 7110* | *来源: Minecraft Wiki*

* *熟鸡肉（Cooked Chicken）**是一种用[生鸡肉](生鸡肉.md)烹饪而成的[食物](食物.md)。

# 获取
# = 生物掉落物 =

# = 烹饪 =
将生鸡肉放入[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或[营火](营火.md)中烹饪，可以获得熟鸡肉。

# = 交易 =

# = 礼物 =

[屠夫](屠夫.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷熟鸡肉。

# = 箱子战利品 =

# 用途
# = 食物 =

手持熟鸡肉按住键即可食用，每个熟鸡肉可以回复。

# = 狼 =
熟鸡肉能用来吸引、治疗或繁殖已驯服的[狼](狼.md)，也可以使已驯服的幼年狼的剩余生长时间加快10%。
