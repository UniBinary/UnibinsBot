# Java版13w09b

*页面ID: 33498* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w09b**是[Java版1.5](Java版1.5.md)的第12个快照，发布于2013年2月27日<ref></ref>，加入了新的命令，此版本修复了[13w09a](13w09a.md)里的漏洞和崩溃。这也是第一个包含Minecraft [Realms](Realms.md)的快照。

# 新内容
# = 命令格式 =
* ***
* 语法：。
* 最大时间为1000000秒。
* 倍数将增加效果的等级。
* 倍数的上限为4。

# = 常规 =
* *[Realms](Realms.md)**
* 加入了[Minecraft Realms](Minecraft Realms.md)<ref>http://www.youtube.com/watch?v=MNZFI04cS5c</ref>。
* * 随机选择少量玩家进行测试。
* ** 有100名玩家被选中。<ref>http://www.youtube.com/watch?v=rlBFEl29s8c</ref>
* * 可通过[主菜单](主菜单.md)的对应按钮进入。

# 更改
# = 物品 =
* *[苹果](苹果.md)**
* [时运](时运.md)魔咒现在会增加苹果掉落的概率。

# 修复
命令对已有损坏值的盔甲无效。
