# 携带版1.0.0.2

*页面ID: 26649* | *来源: Minecraft Wiki*

<onlyinclude>

* *alpha 1.0.0.2**是[1.0.0](携带版1.0.0.md)的第5个测试版，发布于2016年12月9日<ref></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[末影龙](末影龙.md)**
* [末影龙](末影龙.md)现在朝着实际上最近的[末地水晶](末地水晶.md)飞去。

# 修复
* *修复了4个漏洞**
* 骑乘马时游戏崩溃。
* 试图喂食动物时游戏崩溃。
* 试图给新的世界加载大体积的资源包时游戏崩溃。
* 错误导致安卓设备里游戏崩溃。</onlyinclude>
