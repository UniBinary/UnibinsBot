# Java版Alpha v1.0.6 01

*页面ID: 32494* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.6_01**是的一次更新，发布于2010年7月17日<ref></ref>，加入了一些[闪烁标语](闪烁标语.md)，并更改了树叶的枯萎机制。

# 新内容
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了以下闪烁标语：
* * "Matt Damon!"
* * "Superfragilisticexpialidocious!"
* * "Consummate V's!"
* * "Cow Tools!"
* * "Double buffered!"
* * "Fan fiction!"
* 新加入了特殊闪烁标语，只在特定日期或在特定日期为特定玩家显示。
* * "Happy birthday! I love you! Alex x" - 在2010年7月26日为玩家"athna"显示。
* * "Happy birthday, ez!" - 在每年的11月9日显示。
* * "Happy birthday, Notch!" - 在每年的6月1日显示。
* * "Merry X-mas!" - 在每年的12月24日显示。
* * "Happy new year!" - 在每年的1月1日显示。

# 更改
# = 方块 =
* *[树叶](树叶.md)**
* 现在又会枯萎了。
* * 游戏会检查其下面是否有固体方块或其他树叶，亦或是与固体方块相邻。如果没有，它必须能够连接到另一个树叶，并且与起支撑作用的方块的距离不超过5格。否则，树叶将会枯萎。

# = 生物 =
* *[生成](生成.md)**
* 改进了[生物](生物.md)的[生成](生成.md)。
* * 生物的生成概率变得更低了，从而使得[玩家](玩家.md)很难获得某些物品。

# = 非生物实体 =
* *[船](船.md)**
* 船现在能够放置在[水](水.md)以外的地方。
* 船现在只会在高速撞击时被破坏。
* 船达到足够被破坏的速度时会生成水喷溅的[粒子](粒子.md)。
* 船现在可以更平滑地转弯。

# 修复
* *修复了1个漏洞**
* 修复了死亡后出现卡顿的漏洞。</onlyinclude>
