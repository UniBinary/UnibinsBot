# 命令/detect

*页面ID: 41301* | *来源: Minecraft Wiki*

检测在指定的方向上是否有可碰撞的方块。

# 语法
   <code>-{}-detect <*方向：字符串*></code>

# 参数
<code>-{}-*方向：字符串*</code>
   指定[智能体](智能体.md)检测可碰撞方块的方向。必须为以下之一：
  * <code>forward</code>检测前面的方块。
  * <code>back</code>检测后面的方块。
  * <code>left</code>检测左侧的方块。
  * <code>right</code>检测右侧的方块。
  * <code>up</code>检测上面的方块。
  * <code>down</code>检测下面的方块。
