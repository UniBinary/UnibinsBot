* *海晶石（Prismarine）**是自然生成于[海底神殿](海底神殿.md)和[海底废墟](海底废墟.md)的一种[岩石](岩石.md)方块。

# 生成
# = 自然生成 =
海晶石会在[海底神殿](海底神殿.md)和[海底废墟](海底废墟.md)中生成。

# 破坏
挖掘海晶石的合适工具是镐。海晶石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

海晶石被破坏后会掉落自身。

# 用途
[125px|缩略图|右|海晶石的颜色变化](File:Prismarine.gif.md)
海晶石的一种用途是作为一个有一定爆炸抗性的建筑或装饰性方块。

海晶石有动态纹理，可以作为独特的装饰。海晶石的裂纹的颜色在水色、绿、紫及靛蓝之间缓慢地循环变化。海晶石有22次不规则的纹理变化，周期长度为5分30秒。

# = 潮涌核心 =

海晶石可以用于组成[潮涌核心](潮涌核心.md)需要的启动框架。
