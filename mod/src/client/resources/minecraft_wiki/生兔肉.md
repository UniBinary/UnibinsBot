# 生兔肉

*页面ID: 12770* | *来源: Minecraft Wiki*

* *生兔肉（Raw Rabbit）**是一种[食物](食物.md)，可以被烹饪成[熟兔肉](熟兔肉.md)。

# 获取
# = 生物掉落物 =

# 用途
# = 食物 =

手持生兔肉按住键即可食用，每个生兔肉可以回复。

# = 烹饪材料 =
将生兔肉放入[营火](营火.md)、[烟熏炉](烟熏炉.md)或[熔炉](熔炉.md)中烹饪，可以获得熟兔肉。

# = 狼 =
生兔肉能用来吸引、治疗或繁殖驯服的[狼](狼.md)，也可以使已驯服的幼年狼的剩余生长时间加快10%。
