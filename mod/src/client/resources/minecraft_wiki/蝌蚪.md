* *蝌蚪（Tadpole）**是一种友好生物，属于[青蛙](青蛙.md)的幼年形态。

# 生成
# = 孵化 =
[青蛙卵](青蛙卵.md)孵化后会生成2-5只蝌蚪。

# 掉落物
与其他幼年动物一样，蝌蚪死亡时不会掉落任何物品或[经验值](经验值.md)。

# 行为
蝌蚪在水中会漫无目的地游动。蝌蚪在陆地上时会像[鱼](鱼.md)一样扑腾，并试图寻找附近的[水](水.md)，停留在陆地上的蝌蚪大约或后便开始受到[脱水](脱水.md)伤害。

[美西螈](美西螈.md)会主动攻击蝌蚪。

对蝌蚪水桶可以获得[蝌蚪桶](蝌蚪桶.md)，从而能够携带蝌蚪。

蝌蚪会在20分钟之后成长为[青蛙](青蛙.md)，青蛙的肤色由蝌蚪所处的[生物群系](生物群系.md)决定，详见。

蝌蚪会跟随/手持[黏液球](黏液球.md)的玩家。给其喂食黏液球可加速成长，每次缩短约10%的剩余成长时间。

对蝌蚪[金蒲公英](金蒲公英.md)可以阻止其成长为青蛙，再次对其金蒲公英将使其重新开始成长。被阻止成长的蝌蚪无法被喂食除金蒲公英外的其他物品。

虽然蝌蚪具有很多幼年生物的行为，但游戏内部将其视为和青蛙不同的两种生物，因而蝌蚪不会像多数幼年动物那样主动跟随青蛙。

# = 生物族群 =

蝌蚪是水生生物。被具有[穿刺](穿刺.md)魔咒的武器近战攻击，或被具有穿刺魔咒的[三叉戟](三叉戟.md)弹射物命中时会受到额外的伤害。
