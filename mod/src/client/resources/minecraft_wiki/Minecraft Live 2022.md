# Minecraft Live 2022

*页面ID: 98230* | *来源: Minecraft Wiki*

* *Minecraft Live 2022**是一场线上直播活动，于2022年10月15日16:00（UTC）举行。该场活动公布了将在[Java版1.20](Java版1.20.md)和[基岩版1.20.0](基岩版1.20.0.md)中加入的少部分内容，但并未公布其主题，新版本的首个快照在10月19日发布<ref name="try-first-minecraft-1-20-feature"></ref>；同时按照往年的惯例举行了新一轮生物投票，最终[嗅探兽](嗅探兽.md)胜出。直播中也宣布了将加入7种新的默认[皮肤](皮肤.md)，于2022年推出；[Minecraft Dungeons](Minecraft Dungeons.md)的新赛季动物狂欢将于10月19日开始；[Minecraft Legends](Minecraft Legends.md)将于2023年春季发布。<ref name="minecraft-live-2022-back"></ref><ref name="minecraft-now-august-2022"></ref>

# 预告
此次直播活动最初由[Agnes Larsson](Agnes Larsson.md)在2022年8月25日的[Minecraft Now](Minecraft Now.md)直播过程中透露，她表示Minecraft Live 2022将于2022年10月15日举行。<ref name="minecraft-now-august-2022"/>

# = Minecraft Live 2022：预告片 =
官方于2022年9月8日发布预告视频，正式宣布此次活动。

# 活动
# = 社区预热 =
在主要活动开始前有30分钟的社区预热活动，分享了世界各地YouTuber的Minecraft视频。

# = 版本公告 =
本次直播公布了Minecraft下一次主要更新（[Java版1.20](Java版1.20.md)和[基岩版1.20.0](基岩版1.20.0.md)）的部分更新内容，但并未透露其主题名称。展示了[骆驼](骆驼.md)、[悬挂式告示牌](悬挂式告示牌.md)、[雕纹书架](雕纹书架.md)以及由[竹板](竹板.md)和[竹马赛克](竹马赛克.md)制成的方块，同时还展示了7个新的默认[皮肤](皮肤.md)。此次直播并未展示全部的1.20计划内容，而是会在之后的快照及测试版中逐渐揭露。除此之外还公布了[Minecraft Legends](Minecraft Legends.md)的开发进度和[Minecraft Dungeons](Minecraft Dungeons.md)的[季节性冒险](MCD:赛季.md)相关内容。

# = 社区相关 =
直播中演示了如何通过[Blockbench](https://blockbench.net/)中的Minecraft Entity Wizard来进行生物模型制作。

# = 生物投票 =
有别于往届生物投票，本届生物投票在[启动器](启动器.md)、[Minecraft.net](Minecraft.net.md)以及一个专门开设的[基岩版服务器](2022年生物投票服务器活动.md)（可以通过主菜单屏幕上的按钮进入）中同时进行，而不再通过Twitter进行。投票自2022年10月14日16:00（UTC）开始，至10月15日16:15（UTC）结束，共持续24小时15分钟。<ref name="minecraft-live-2022-back"/>

[缩略图|右|生物投票的3个选项](File:MCLive2022MobVoteAllOptions.png.md)
以下为当时透露的3个候选生物的信息：
; [32px](File:SnifferPixel.png.md) [嗅探兽](嗅探兽.md)（Sniffer）<ref></ref>
* 一种远古的卵生爬行动物，拥有绿色的皮毛、红色的头和黄色的嘴。
* 可从[海底废墟](海底废墟.md)的[箱子](箱子.md)中找到它的蛋。
* 喜爱植物，会利用嗅觉从土地中挖掘出远古植物的种子。
* * 若该生物在投票中胜出，该植物也会一同加入，但只具有装饰性用途。

; [32px](File:RascalPixel.png.md) 淘气鬼（Rascal）<ref></ref>
* 一种背着篓子的洞穴生物，外观与[流浪者](流浪者.md)相似。
* 罕见地生成于Y=0以下的[废弃矿井](废弃矿井.md)中。
* 喜欢玩捉迷藏游戏。
* * 被找到3次后会从篓子里取出采矿用品（如附魔[镐](镐.md)）送给玩家，随后传送离开。

; [32px](File:TuffGolemPixel.png.md) 凝灰岩傀儡（Tuff Golem）<ref></ref>
* 一种由[凝灰岩](凝灰岩.md)构成的1格高的生物，如果在制造它时放置[羊毛](羊毛.md)则会穿上红色斗篷。
* 制造出后可以进行堆叠。
* 可以托着斗篷展示玩家给予的物品。
* 可以坐在原地休眠，也可以四处走动。
* * 在未持有物品的状态下走动时，可以拾起周围的一种[物品实体](物品实体.md)并托在手中。

# == 结果 ==
直播末尾公布了投票的最终结果。节目中称共收到350万张选票，获胜的嗅探兽获过半数选票，各生物具体的得票比例已在直播结束后披露。<ref></ref>

下面为三者的排名（从高到低）：
# **[嗅探兽](嗅探兽.md)**（55.1%，约192.85万票）
# 淘气鬼（27.7%，约96.95万票）
# 凝灰岩傀儡（17.2%，约60.2万票）
