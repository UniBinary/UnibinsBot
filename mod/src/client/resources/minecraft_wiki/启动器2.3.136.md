# 启动器2.3.136

*页面ID: 94724* | *来源: Minecraft Wiki*

* *2.3.136**是一次[启动器](启动器.md)更新，2022年4月12日以测试版的形式在、和平台上发布，2022年4月20日<ref group=注>检查到其发布的时间，实际发布时间可能更早。</ref>以测试版的形式在（新版启动器）平台上发布，2022年4月22日以正式版的形式在以上所有平台上发布。

# 新内容
* 加入了一个可以使用户在启动器中评价Microsoft Store版启动器的设置。

# 更改
* 更新了一些错误信息，使它们更有作用。
* 对启动器进行了各种漏洞修复和各种稳定性改进，并更新了启动器的分发管道。

# 修复
*  - 输出的游戏日志中，消息会被截断，且不显示相应的滚动条。
*  - 一些选定的按钮和字段不能同时使用和键来交互。
*  - “The Marketplace Spring Sale is Here!”文章的分类错误。
*  - “账户迁移FAQ”页面中的信息过时。
