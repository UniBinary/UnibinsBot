# 基岩版26.10.23

*页面ID: 186055* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 26.10.23**（ChromeOS/Android）、**Preview 26.10.23**（Windows/Xbox/iOS/iPadOS/PlayStation）是[基岩版26.10](基岩版26.10.md)的第3个测试版，发布于2026年2月11日<ref></ref>，加入了[音符盒](音符盒.md)的新音色“小号”，更改了部分幼年生物的模型，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[音符盒](音符盒.md)**
* 加入了新的音色“小号”（Trumpet），对应的乐器方块为[铜块](铜块.md)、[雕纹铜块](雕纹铜块.md)、[切制铜块](切制铜块.md)及其氧化和涂蜡变种。
* * 音色会随着[氧化](氧化.md)程度的不同而改变。

# = 常规 =
* *[控制](控制.md)**
* 加入了新的按键绑定“Describe”。
* * 通过文本和文本转语音功能告知玩家面向的方块或生物。
* * 适用于键盘和控制器控制。

# 更改
# = 方块 =
* *[金蒲公英](金蒲公英.md)**
* [骨粉](骨粉.md)不再可以对金蒲公英生效。
* 现在可用于合成[谜之炖菜](谜之炖菜.md)，给予玩家[饱和](饱和.md)效果。
* 现在可用于合成[黄色染料](黄色染料.md)。
* 现在可以被[末影人](末影人.md)搬起。
* 现在可以被能够捡起物品的非玩家生物捡起。
* 现在[猪灵](猪灵.md)会被金蒲公英吸引。
* 现在可以通过与[流浪商人](流浪商人.md)交易获得。

# = 生物 =
* *[幼年生物](幼年生物.md)**
* 更新了以下幼年生物的纹理和模型：
* * [猪灵](猪灵.md)
* * [村民](村民.md)
* * [僵尸村民](僵尸村民.md)
* * [僵尸猪灵](僵尸猪灵.md)
* * [僵尸](僵尸.md)
* * [尸壳](尸壳.md)
* * [溺尸](溺尸.md)
* 现在人形幼年生物拥有独特的盔甲模型。
* * 不再会渲染[盔甲纹饰](盔甲纹饰.md)。
* 人形幼年生物手持的物品不再会被缩小。

* *[猫](猫.md)**
* 修正了幼年英国短毛猫的后脑勺纹理。

* *[鸡](鸡.md)**
* 修正了幼年热带鸡的侧面纹理。

* *[马](马.md)**
* 更改了成年马的斑点位置，以匹配幼年马。

* *[猪](猪.md)**
* 修正了幼年温带猪的身体纹理，使其色调一致。

* *[兔子](兔子.md)**
* 修正了幼年棕色兔子的腿部纹理。

* *[海龟](海龟.md)**
* 更改了幼年海龟的四肢纹理。

# = 游戏内容 =
* *[极限模式](极限模式.md)**
* 现在游戏规则为的极限模式世界会在[选择世界菜单](选择世界菜单.md)中显示游玩天数。

* ** 因此，若组件部分有<code>"minecraft:selection_box": {"origin": [-8, 0, 5], "size": [16, 16, 3] }</code>，则各个部分都会有16×16×3的AABB，当玩家看向多部分方块时，轮廓AABB（在世界空间中）会是已组合的16×16×9。

# 修复
* *2026年第1次小更新**
* 修复了幼年鸡的热带变种纹理。
* * 更改了纹理的条纹，以使其两侧对称。
* 修复了棕色幼年兔子的纹理。
* * 脚部纹理已被修复。
* 修复了幼年海龟的纹理颜色。
* 修复了幼年海龟的MERS。（）

* *图形**
* 修复了在开启的情况下靠近其他光源方块时，手持的部分光源方块会显得不亮的问题。
* 在中为更多实体和物品加入了对静态局部光照的支持，包括活塞、移动的方块、告示牌、床和箱子。
* 修复了UI图标不会在最小的缩放比例设置下显示的问题。（）

* *生物**
* 修复了村民睡觉时偶尔会出现在地上而不是床上的问题。（）
* 修复了幼年猫的英国短毛变种的纹理。
* 修复了幼年猪的纹理颜色。

* *人物**
* 现在切换至经典皮肤然后切换回人物时，皮肤会正确对其他玩家显示。
* 在多人游戏世界中游玩期间，用户不再会在其他用户实际上没有更改皮肤时接收到有关其他用户更新皮肤的消息。

* *Realms**
* 为服务器区域本地化字符串加入了一个尾随空格。
* Realm存档现在会在信息下拉菜单中显示正确的版本格式。
* 修复了超大UI下的“”屏幕上的文本会变得不可读的问题。
* 修复了旧版UI下会出现不存在的Realms下载按钮的问题。
* 输入图例不再会切断选择退出的成员的时间轴末端。
* 移除了Ore UI的Realms编辑世界中的模拟距离滑块。

* *用户界面**
* 修复了退出好友的个人资料页面后返回按钮不起作用的问题。（）
* 修复了携带版UI下的交易屏幕中两个物品的交易项会出现重叠的问题。（）</onlyinclude>
