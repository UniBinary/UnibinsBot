# 携带版0.8.2

*页面ID: 21271* | *来源: Minecraft Wiki*

* *v0.8.2 alpha**是[携带版](携带版.md)的一次次要更新，发布于2014年4月2日<ref>http://mashable.com/2014/04/02/amazon-fire-tv-2/</ref>，此次更新仅发布于Amazon Fire TV设备。

# 新内容
# = 常规 =
* *[控制](控制.md)**
* 加入了对Amazon Fire TV的控制器支持。
* 加入了控制器特性界面。

# 更改
# = 常规 =
* *[设置](设置.md)**
* 减少了选项数量。

# 你知道吗
* 此版本曾在Kindle Fire可用。
