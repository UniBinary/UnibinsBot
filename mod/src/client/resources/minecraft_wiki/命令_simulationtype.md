# 命令/simulationtype

*页面ID: 125921* | *来源: Minecraft Wiki*

更改模拟类型。可用于阻止或允许实体行为。

主要用于在命令方块或函数中对游戏世界的某些模拟规则进行控制。例如可以设置方块更新的模拟方式等相关模拟行为。不同的模拟类型会影响游戏中物理、方块更新等机制的运行方式。

# 语法
   <code>simulationtype <state: SimulationTypeEnum></code>

# 参数

   指定模拟类型，必须为以下其中之一：
  * <code>editor</code> — 编辑器（阻止实体行为）
  * <code>game</code> — 游戏（允许实体行为）
