# Java版1.13-pre2

*页面ID: 34998* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.13-pre2**是[Java版1.13](Java版1.13.md)的第2个预发布版，发布于2018年6月15日<ref></ref>，加入了6种不同的去皮木头和浮冰的合成配方，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[去皮木头](去皮木头.md)**
* 加入了6种去皮[木头](木头.md)方块。

* *[浮冰](浮冰.md)**
* 现在可以用9个[冰](冰.md)合成[浮冰](浮冰.md)。


# 更改
# = 方块 =
* *[木头](木头.md)**
* 回退了[Java版1.13-pre1](Java版1.13-pre1.md)对树皮纹理的更改。

* *[床](床.md)**
* 更改了使用床失败后的信息：“你只能在夜间或雷暴中入眠”。

# = 生物 =
* *[骷髅马](马.md)**
* 更新模型以修复严重的深度冲突（[Z-fighting](wikipedia:Z-fighting.md)）。

* *[僵尸马](马.md)**
* 现在会沉入水中。

# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 稀有价值的物品会以各自的颜色高亮显示名称，而不仅仅是白色。<ref></ref>

# = 常规 =
* *模型**
* 更新模型以修复严重的深度冲突。

* *启动界面**
* 优化了开始界面。

* *其他**
* 各种性能优化。
