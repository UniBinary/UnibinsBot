# 携带版0.10.0.b5

*页面ID: 28514* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.10.0 alpha build 5**是[v0.10.0 alpha](携带版0.10.0.md)的第5个测试版，发布于2014年11月3日，修复了一些漏洞。

# 修复
* *修复了9个漏洞**
* 修复了玩家在水下时的画面渲染错误。
* 修复了大多数设备在打开游戏时黑屏的漏洞。
* 门的侧面出现黑线。
* OpenGLES 3和Mipmap被意外禁用。
* 修复了图像深度的渲染精度丢失的漏洞。
* 切换游戏时，聊天信息会保留。
* 在没有关闭选项界面时直接退出游戏会导致选项不被保存。
* 灵敏度比预期的要低。
* 破坏门的底部不会掉落门自身。</onlyinclude>
