# 启动器3.21.5

*页面ID: 169126* | *来源: Minecraft Wiki*

<onlyinclude>

* *3.21.5**是一次[启动器](启动器.md)更新，发布于2025年10月14日。

# 新内容
* 在启动器中加入了对手柄和[ROG Xbox Ally](https://www.xbox.com/en-US/handhelds/rog-xbox-ally)的支持。

# 修复
*  — “购买Minecoin”界面底部的Chromebook被错拼为“Chrombook”。
*  — “Minecoins”在一个字符串（“Buy MineCoins”）中被错误地大写。
* 修复了一些其他漏洞，并进行底层改进。</onlyinclude>
