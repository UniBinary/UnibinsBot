# 太阳

*页面ID: 177* | *来源: Minecraft Wiki*

[缩略图|160px|太阳](File:sun.png.md)

* *太阳（Sun）**是[Minecraft](Minecraft.md)主世界中提供光照的一个主要天体。

# 白天

[缩略图|右|250px|太阳从地平线上升起](File:Sunrise.png.md)

太阳和[月亮](月亮.md)从东方升起，西方落下。

当[玩家](玩家.md)新建一个[世界](世界.md)时，时间会被设置为拂晓，太阳开始从地平线上升起。随着时间流逝，太阳渐渐划过天空。当太阳落下后，[月亮](月亮.md)随之升起，白天结束。一个完整的[白天](昼夜更替#白天.md)持续现实时间10分钟。

# 阳光
* *阳光（Sunlight）**是指在没有[恶劣天气](天气.md)时，将直接暴露在[天空](空气.md)下的、不被[光照不透明](亮度#光照透明方块.md)方块遮挡的方块照亮的[光](光.md)。[云](云.md)不会产生阴影，但在下雨、下雪时，天空会变暗，阳光亮度会降低。此时，白天的[最大内部光照](亮度#内部光照.md)会从正常的15降至12。雷雨时最大内部光照下降到10级，生成时的天空光照被削减10级，使得敌对生物得以生成。

随着太阳的升起落下，暴露在阳光下的方块会根据太阳的入射角改变亮度，造成拂晓时亮度逐渐升高、黄昏时亮度逐渐降低的效果。然而，方块的阴影不会随太阳的方位而变化，从而使日晷无法实现。

如果一个位置的上方有散射天空光照的方块，随着玩家越深入地下，来自阳光的天空光照会渐渐降低。在[洞穴](洞穴.md)等上方有光照不透明方块的位置，玩家越深入内部来自阳光的天空光照也会越来越低，直到最终完全无法用阳光看到东西。洞穴中天花板上的裂缝或天井能让阳光从中照射进地底，但阳光无法照亮洞穴的所有位置，只能照亮一小片范围。

# = 对生物的影响 =
[缩略图|200px|僵尸在阳光下灼烧并死亡](File:Zombie Death.png.md)
阳光影响[生物](生物.md)的[生成](生成.md)。大部分友好生物需要天空光照大于等于9的环境下才能生成（[蝙蝠](蝙蝠.md)、[鱿鱼](鱿鱼.md)除外），因此这些生物在日落后不会自然生成。相反，敌对生物会在天空光照小于7的环境下生成。

除此之外，阳光还会影响生物的行为。[僵尸](僵尸.md)、[僵尸村民](僵尸村民.md)、[溺尸](溺尸.md)、[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、[幻翼](幻翼.md)、[殭屍馬](殭屍馬.md)和[僵尸鹦鹉螺](僵尸鹦鹉螺.md)会在阳光完全照亮的区域中[着火](着火.md)，它们会尝试避免与阳光接触。它们在水中、雨中、装备[头盔](头盔.md)、[馬鎧](馬鎧.md)或[鹦鹉螺铠](鹦鹉螺铠.md)时不会自燃。[蜘蛛](蜘蛛.md)在阳光直射下不与玩家敌对，除非被玩家攻击或在被阳光直射前正在追逐玩家。[末影人](末影人.md)在阳光下时会传送以避免阳光照射。除此之外的敌对生物不受阳光影响。

# 你知道吗
* 太阳在日出和日落时看起来更大。
* * 如果玩家在水下或地下看太阳，它在日落时和在空中时一样大。
* * 这是由于游戏在玩家直接暴露在天空下时对太阳有着特殊的渲染方式。
* 太阳绕着玩家转，而不是绕着地图转。
* * 由于天体、[星星](星星.md)之间的相对位置是固定的，Minecraft目前不可能出现日食。
* 若玩家处于距离地表大约1.4倍渲染距离的高度上时，会同时看到太阳和与其相对的月亮，感觉就像步入了太空。
* 太阳轨迹平面垂直于地面，在正午路经天顶。这是因为渲染逻辑没有设置任何Z轴旋转或偏移来模拟轴向倾斜或纬度。因此，太阳轨迹不会像在地球北半球那样向南倾斜。
