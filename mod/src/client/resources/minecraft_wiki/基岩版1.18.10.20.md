# 基岩版1.18.10.20

*页面ID: 90853* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.10.20**是[基岩版1.18.10](基岩版1.18.10.md)的首个测试版，发布于2021年11月18日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[大型垂滴叶](大型垂滴叶.md)**
* 现在只能放置在[黏土](黏土.md)、[砂土](砂土.md)、[泥土](泥土.md)、[耕地](耕地.md)、[草方块](草方块.md)、[苔藓块](苔藓块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)和[缠根泥土](缠根泥土.md)上。

* *[洞穴藤蔓](洞穴藤蔓.md)**
* 略微更改了纹理，去除了一个灰色像素点。

* *[红石比较器](红石比较器.md)**
* 更改了激活状态的基部纹理。

# = 物品 =
* *[营火](营火.md)**
* 更改了两种营火的物品形式纹理，将火焰部分整体调低了1格像素。

* *[门](门.md)**
* 更改了金合欢木门、白桦木门、深色橡木门、铁门、丛林木门、橡木门和云杉木门的物品形式纹理。
* * 橡木门的新纹理暂时不会在游戏中显示。<ref></ref>

* *[物品展示框](物品展示框.md)**
* 更改了两种物品展示框的物品形式纹理，以匹配其方块形式的边框木材纹理。

* *[磁石指针](磁石指针.md)**
* 更改了纹理以匹配。

* *[音乐唱片](音乐唱片.md)**
* 调整了播放音乐唱片Pigstep和otherside并连接红石比较器时输出的[红石信号](红石信号.md)强度，以匹配。

* *[告示牌](告示牌.md)**
* 更改了各种告示牌的物品形式纹理，以匹配其方块形式的柄部纹理。

# = 生物 =
* *[凋灵](凋灵.md)**
* 更改了凋灵之首的纹理，以匹配纹理更新后的凋灵头部纹理。

# = 世界生成 =
* *[深板岩](深板岩.md)**
* 现在会在主世界的Y=1到Y=7之间过渡生成，而非之前的Y=-7到Y=-1。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 将“[this splash text has been delayed until part 2]”闪烁标语改为“[this splash text is now available]”。
* 加入了“Don't feed chocolate to parrots!”闪烁标语。

* 更新了FuelItemComponent文档。
* 将DamageableItemComponent重命名为DurabilityItemComponent。

* 将SaturationModifier使用的数据类型由字符串更改为浮点数。

# 修复
* *游戏内容**
* 修复了HUD上的物品冷却在视觉上并不会半透明的问题。（）
* 海洋和沼泽生物群系中的废弃传送门不再包含水，并且其现在会在无水源时生成。
* 游戏规则选项“爆炸破坏”被关闭时，使用命令生成的TNT不再会爆炸。（）
* 将冰霜行者的影响范围锁定为8格，以避免导致服务器无响应。
* 农民村民现在最多能够捡起数量不超过8组的物品。（）
* 现在手持玩家标记相对偏移的地图时会根据屏幕的长宽之比，从而使标记接近于屏幕边缘并保持总是可见。
* 修复了敌对生物刷怪笼在其所在区块被重新加载时，其有时会停止生成生物的问题。（）
* 现在又可以解锁“强大的胃”成就了。（）
* 修复了结构方块在加载结构时会无限生成相同实体的问题。（）
* 玩家不再会被自己所穿戴的荆棘附魔盔甲反伤。（）
* 现在吃下食物时又会获得相应效果了。

* *方块**
* 现在靠近方块边缘的水会正确流动。
* 火不再能在避雷针上点燃。
* 现在蜡烛会以正确的宽度与下方的墙连接。（）
* 改进了方块实体（如沙子和沙砾）下落时的动画。（）
* 结构方块中的大型垂滴叶、紫晶芽和紫水晶簇不再会被破坏。
* 紫水晶簇现在会在其支撑方块被破坏时正确地被破坏。（）
* 铜块及其变种现在会在下界中氧化。（）
* 大型垂滴叶现在只能放置在黏土、砂土、泥土、耕地、草方块、苔藓块、缠根泥土、菌丝体和灰化土上。（）
* 滴水石锥现在只能放置在方块的完整一面上。
* 发光地衣现在会正确被放置。
* 游戏规则设置为false时，岩浆块不再会对玩家造成伤害。（）
* 玩家现在可以在脚手架中使用表情。（）
* 玩家重生或起床后不再会出现移动问题。

* *生物**
* 现在村民、兔子和狐狸在冰封山峰或尖峭山峰中会以其对应的雪地变种生成。（）
* 山羊现在会正确生成于尖峭山峰和冰冻山峰。（）

* *图形**
* 修复了在使用鞘翅滑翔时睡觉的视角问题。（）
* 修复了从其他维度返回主世界后光源会被移除的光照漏洞。（）
* 更新了一些方块和物品的纹理以修复纹理同步问题。（）

* *市场**
* 修复了购买Minecoin后，直到重启游戏为止才会刷新其数量的问题。

* *用户界面**
* 修复了在暂停界面向上滚动时无法打开成就界面的问题。
* 现在使用自定义分辨率对焦时，暂停界面上的“邀请加入游戏”和成就按钮拥有白色边框。
* 修复了市场侧边栏上内容板块的滚动高度，以使不同分辨率的设备都会显示滚动条。
* 修复了添加玩家为好友时其用户名旁会多出“-”的问题。（）

* *世界生成**
* 修复了Realms中恶地和冻洋生物群系的生成与常规世界不一致的问题。
* 现在升级旧世界后，旧区块中的Y=0至4之间的基岩层会正确被深板岩代替。（）
* 深层铜矿石现在会生成在溶洞中。（）

* *原版趋同**
* 调整了音乐唱片*otherside*输出的红石信号强度以匹配Java版。（）
* 调整了音乐唱片*Pigstep*输出的红石信号强度以匹配Java版。（）
* 现在拉弓时的摇晃动画仅在拉满弓箭时播放。

* *命令**
* 命令不再拥有多余的参数。（）

* *性能与稳定性**
* 加入了新的内容日志消息以协助获取BDS崩溃报告。（）

* *技术性**
* 修复了自定义食物的行为不会复制在访客的客户端上的问题。
* 修复了动画控制器引用其自身作为一种“动画”时可能发生的崩溃。
* 命令被指定高范围参数时游戏不再会自动退出。（）
* 修复了执行命令时游戏性能下降的漏洞。（）
* 修复了左侧无有效实体或物品时，箭头运算符会返回0，但不是整个表达式返回0的问题。
* 修复了生物碰撞箱的宽度和高度设置为负数时可能发生的崩溃。
* 修复了常加载区域有时会跳过一刻的问题。（）
* 现在分屏游戏的第2个玩家可查看内容日志历史面板，而不会导致游戏崩溃。
* 修复了实体文档中的许多条目都缺少“Description”的问题。
* 修复了实体文档中的一些错别字和不一致处。
* 通过添加网络保存或加载标签以修复BlockPartVisibilityComponent在多人游戏中的问题。（）</onlyinclude>
