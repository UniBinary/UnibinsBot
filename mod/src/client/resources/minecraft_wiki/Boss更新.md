# Boss更新

*页面ID: 24477* | *来源: Minecraft Wiki*

[缩略图|300px|Boss更新的图片，由Mojang发布](File:BossUpdatePE.png.md)

* *Boss更新（Boss Update）**是[携带版Alpha](携带版Alpha.md)的一次主要更新，在除iOS外的其他平台发布于2016年10月21日。<ref></ref>iOS版于几天之后的10月25日发布。<ref></ref>此次更新的名称于2016年8月29日Mojang网站上的博客帖子中公布。<ref></ref>

此次更新的开发始于[Alpha 0.16.0 build 1](携带版0.16.0.b1.md)，其发布于2016年8月29日。

# 重要特性

# = 新内容 =
* 更改了许多设置。
* 行为包。
* [命令](命令.md)。
* [海底神殿](海底神殿.md)。
* 4种新方块：
* * [海晶灯](海晶灯.md)、[海晶石](海晶石.md)、[湿海绵](湿海绵.md)和[信标](信标.md)。
* 6种新物品：
* * [海晶砂粒](海晶砂粒.md)、[海晶碎片](海晶碎片.md)、[下界之星](下界之星.md)、衰变[药水](药水.md)/喷溅型衰变药水/衰变之[箭](箭.md)。
* 3种新生物：
* * [守卫者](守卫者.md)、[远古守卫者](远古守卫者.md)和[凋灵](凋灵.md)。

# = 更改 =
* 添加各种物品、方块和生物的声音。

# 跟进版本
* [Alpha 0.16.1](携带版Alpha 0.16.1.md)发布以修复一些漏洞与崩溃。
* [Alpha 0.16.2](携带版Alpha 0.16.2.md)发布以修复一些漏洞与崩溃，并添加了卡通纹理包。
