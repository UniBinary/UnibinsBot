* *Minecraft：树莓派版（*Minecraft: Pi Edition*）**为[Minecraft](Minecraft.md)为[树莓派（Raspberry Pi）](wzh:树莓派.md)而设计的版本。该版本基于[携带版0.6.1](携带版0.6.1.md)开发，但进行了些许删减，同时包含一些改进过的特性以及对多种编程语言提供支持等。树莓派版旨在为编程新手提供一种教学工具。此版本同时于[此处](https://www.minecraft.net/en-us/edition/pi)提供免费下载。树莓派版鼓励使用者通过[API](wikipedia:API.md)修改游戏的源代码。<ref></ref>

树莓派版由携带版的开发者[Aron Nieminen](Aron Nieminen.md)与[Daniel Frisk](Daniel Frisk.md)联手进行开发。<ref>http://pi.minecraft.net/?page_id=14</ref>

树莓派版从未接受过后续更新，也不会进一步更新。

# 发展
# = 发布 =
Minecraft树莓派版于2012年11月24日于Mojang官方网站中公布。<ref></ref>

在树莓派版正式发布前，Mojang数据库中存有标记为0.1的编译版本，但是由于被加密，所以当时没有办法获得。但是在其上传的最初一段时间内由于未加以保护，所以人们可以在未发布前进行下载。2012年12月20日[Mojang](Mojang.md)在官网上宣称树莓派版的发布，实际上游戏并没发行，且很快就删除了树莓派版发布的文章，在公众第二次可以该文章之前均会返回404错误。

2013年2月11日，Minecraft树莓派版正式于[Mojang](Mojang.md)官方网站中发布0.1.1版本。在Minecraft树莓派版的网站中提及在2012年12月20日，之前删除的文章被恢复也证明了之前的推断是正确的。

# = 运行于Raspberry Pi OS（原Raspbian） =
2014年9月15日，Raspberry Pi 基金会宣布新Raspbian操作系统将会自带Minecraft树莓派版。<ref></ref>

现如今该版本已不在Bullseye、Bookworm或更高版本的Raspberry Pi OS软件库中提供，这也代表着玩家无法在这些版本的系统中通过<code>sudo apt install minecraft-pi</code>安装它。该版本的二进制文件也无法按照预期在这些系统正常运行。

# = 停止更新 =
树莓派版从来没有发布任何后续版本，并且它的开发者没有任何进一步的消息，所以不知道他们是否在开发新的版本。直到2016年1月25日，[Tommaso Checchi](Tommaso Checchi.md)在Reddit上表明了：
</ref>}}

2021年8月，Raspberry Pi OS Bullseye发布，树莓派版被正式从游戏文件夹和推荐软件页面中删除，这是因为Bullseye终止了对树莓派版依赖的图形API的支持。<ref>[raspbian - Bullseye: E: Unable to locate package minecraft-pi - Raspberry Pi Stack Exchange](https://raspberrypi.stackexchange.com/questions/133145/bullseye-e-unable-to-locate-package-minecraft-pi)</ref>

# 游戏内容
树莓派版与[携带版](携带版.md)在许多方面十分相像。与早期携带版版本相似，树莓派版也只能生成256&times;256&times;128个方块大小的[旧世界类型](旧世界类型.md)世界。玩家的皮肤永远是默认的“Steve”皮肤。该版本的标题画面与世界选择画面与[携带版0.7.0](携带版0.7.0.md)之前的版本相同。

玩家可以潜行，但不能疾跑。生物不会自然生成，虽然在玩家的热键栏内一开始都会有一把铁剑。弓也是可用的，但是使用弓时玩家会无限地蓄力，直到玩家选择另一物品或登出。

树莓派版包括所有来自携带版0.6.1的方块。游戏模式只有唯一的[创造模式](创造模式.md)，无合成和烧炼机制。

# 与携带版0.6.1的不同
* [生存模式](生存模式.md)被强制禁用。
* * 加载一个处于生存模式的世界会使游戏进入半[生存模式](生存模式.md)/半[创造模式](创造模式.md)的状态，有些游戏规则像是创造，有些则像生存。
* * 不能加入处于生存模式的服务器。
* Xperia Play UI被普通UI取代。
* [告示牌](告示牌.md)不会在放置时打开UI，除非使用外部程序或添加Mod。
* 新建的世界无法更改名称和[种子](种子（世界生成）.md)，世界名称始终为。
* 没有关于局域网服务器的设置，局域网游戏始终启用。
* 当进入[多人游戏](多人游戏.md)世界时，暂停界面没有退出并复制该地图的选项。
* * 与携带版0.6.1一样，地图保存在文件夹中的，除非重命名这些文件，否则不会出现在选择世界的界面。
* 自定义光标显示在系统光标的后面。
* 包含的语言文件与携带版0.6.1的不一样。
* 暂停菜单有静音按钮，但是游戏本身却没有[音效](音效.md)。

# 你知道吗
* 树莓派版从技术上来说是修改版的携带版0.6.1。
* 树莓派版拥有潜行功能，而[携带版](携带版.md)在[0.12.1](携带版Alpha 0.12.1.md)才加入了这个功能。
* 玩家名称总是“StevePi”。
* 虽然没有生存模式，但是玩家可以通过掉入虚空来死亡，这也表明了生命系统仍然存在。
* 在0.6.1里的所有生物依然存在，但只能加载一个携带版地图或通过激活下界反应核的方式的方式才能生成。
* 加载一个支持的携带版地图会加载所有原本已生成的生物、一个仅客户端存在的假日月循环和激活下界反应核以生成僵尸猪人的能力。
* 当玩家退出世界后，其物品栏不会被保存。玩家再次进入游戏时，物品栏会恢复默认状态。
* 为了树莓派的稳定运行，树莓派版的Minecraft的硬件加速被调整得很低，这使得玩家无法正常截图。在SSH联机状态下尝试运行也会出现黑屏的情况。
* 玩家可以通过编辑来修改玩家皮肤。如果从APT安装，则在，玩家还可以通过编辑 <code>image</code>目录下的其他文件来修改其他纹理。
* 尽管此版本需要OpenGL ES 1，但它只能链接到OpenGL ES 2。
* 该版本还有一个衍生版本Minecraft: Pi Edition: Reborn，适用于几乎所有Linux系统。<ref>[Minecraft: Pi Edition Modding Project](https://gitea.thebrokenrail.com/minecraft-pi-reborn/minecraft-pi-reborn)</ref>
