* *凋灵骷髅（Wither Skeleton）**是生成于[下界要塞](下界要塞.md)且能造成[凋零](凋零.md)效果的[骷髅](骷髅.md)变种。

# 生成
凋灵骷髅在[下界要塞](下界要塞.md)中亮度小于等于7的地方自然生成，詳見。

生成于下界的[蜘蛛](蜘蛛.md)和[洞穴蜘蛛](洞穴蜘蛛.md)（通过使用[刷怪蛋](刷怪蛋.md)、命令或[刷怪笼](刷怪笼.md)等）有0.8%概率生成[凋灵骷髅蜘蛛骑士](蜘蛛骑士.md)。

凋灵骷髅可以生成在[凋灵玫瑰](凋灵玫瑰.md)中。凋灵骷髅是唯一一种可以自然生成在凋灵玫瑰中的生物。<ref>僵尸猪灵能在凋灵玫瑰中生成。}}</ref>

# = 万圣节 =

在[万圣夜](wzh:万圣夜.md)（10月31日）当天，凋灵骷髅在生成时有22.5%的概率戴着[雕刻南瓜](雕刻南瓜.md)，2.5%的概率戴着[南瓜灯](南瓜灯.md)，但雕刻南瓜或南瓜灯不会掉落。<ref></ref>

# = 凋灵 =

在普通或困难[难度](难度.md)下，当[凋灵](凋灵.md)生命值降至50%时会生成3-4只凋灵骷髅。

# 行为
凋灵骷髅在空闲时会四处游荡，但在玩家、幼年[海龟](海龟.md)、[铁傀儡](铁傀儡.md)、[猪灵](猪灵.md)或[猪灵蛮兵](猪灵蛮兵.md)距离它们16格以内时，它们会以玩家行走的速度向这些目标冲刺并进行攻击。

凋灵骷髅会主动逃离[狼](狼.md)，并且在被狼攻击后还会尝试反击；而凋灵骷髅不会逃离狼，只会在被狼攻击后尝试反击。<ref></ref>

由[凋灵](凋灵.md)生命值降至50%时生成的凋灵骷髅被该凋灵误伤后不会尝试反击，但被其他凋灵误伤后仍会尝试反击。

凋灵骷髅的近战攻击会造成10秒[凋零](凋零.md)I。

凋灵骷髅有5%的概率以左手作为主手。类似于其他[亡灵生物](亡灵生物.md)，生成的凋灵骷髅可能会有捡起近战武器和盔甲的能力。尽管一些生成的凋灵骷髅能捡起物品，但无论如何它们都不会捡起弓。持有[弓](弓.md)的凋灵骷髅（默认不可生成，只能通过[命令](命令.md)实现）会发射[着火](着火.md)的箭，即使弓没有[火矢](火矢.md)魔咒。凋灵骷髅持弓时的行为与使用弓的普通骷髅行为类似。凋灵骷髅不会使用弓。

凋灵骷髅免疫[凋零](凋零.md)效果，无法[着火](着火.md)，并且免疫[火焰伤害](伤害#火焰伤害.md)。

被凋灵骷髅杀死的[苦力怕](苦力怕.md)会额外掉落一张*[13](音乐唱片13.md)*、*[cat](音乐唱片cat.md)*、*[blocks](音乐唱片blocks.md)*、*[chirp](音乐唱片chirp.md)*、*[far](音乐唱片far.md)*、*[mall](音乐唱片mall.md)*、*[mellohi](音乐唱片mellohi.md)*、*[stal](音乐唱片stal.md)*、*[strad](音乐唱片strad.md)*、*[ward](音乐唱片ward.md)*、*[11](音乐唱片11.md)*或*[wait](音乐唱片wait.md)*[音乐唱片](音乐唱片.md)。

# = 生物族群 =

凋灵骷髅是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉直到接触水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

凋灵骷髅不会在阳光下[着火](着火.md)，，并会像骷髅一样寻找阴凉处。

# 你知道吗
* 类似于其他骷髅变种，凋灵骷髅并不会使用[弩](弩.md)。
* 击杀凋灵骷髅掉落的[石剑](石剑.md)剩余[耐久度](耐久度.md)可以为0，剩余耐久度被试图降低到比1低的值时物品会被摧毁，因此借此可以获得正常使用无法得到的剩余耐久度。
