# Java版Classic 0.0.22a

*页面ID: 40212* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.22a**是的一次更新，发布于2009年6月29日<ref>[IRC记录](#logs.md): "*P5:21:52 <Rroff> before on just plain 22a sound was fine for me*". (22:21:52 UTC)</ref><ref>[IRC记录](#logs.md): "*P4:56:47 <akuryo> notch you did an update?*", "*P4:56:55 <AlLnAtuRalX> Notch, server update?*". (21:56 UTC)</ref>，加入了[音效](音效.md)和[音乐](音乐.md)。

# 新内容
# = 游戏内容 =
* *[音效](音效.md)**
* 加入了基本音效。<ref>[IRC记录](#logs.md): "*P4:58:39 <08Notch> yeah, this is very basic sound*". (21:58:39 UTC)</ref><ref>[IRC记录](#logs.md): "*P4:59:46 <akuryo> SOUND IS HERE*" (21:59:46 UTC)</ref>
* 包括基本的脚步声音，<ref name="footstep">[IRC记录](#logs.md): "*P4:59:07 <C418> I actually really love the destroying sound being footsteps*". (21:59:07 UTC)</ref>在[玻璃](玻璃.md)上脚步的声音<ref>[IRC记录](#logs.md): "*P4:58:59 <AlLnAtuRalX> I love the walk on glass sound*". (21:58:59 UTC)</ref>以及在[布料](布料.md)和[草方块](草方块.md)上脚步的声音。<ref>[IRC记录](#logs.md): "*P5:01:06 <AlLnAtuRalX> the footsteps on cloth / grass one*" (22:01:06 UTC)</ref>
* 破坏[方块](方块.md)会发出脚步声。<ref name="footstep"/>

* *[音乐](音乐.md)**
* 加入了""、""和""三首曲目。<ref>[IRC记录](#logs.md): "*P5:00:04 <AlLnAtuRalX> I hear music?*" [...] "*P5:00:59 <Quatroking> what the hell is this music*" [...] "*P5:03:36 <Lmaoboat> Lol, I heared the music after a a while without it, and I was about to yell at my brother for playing the piano again*" (22:00:04至22:03:36 UTC)</ref><ref>[IRC记录](#logs.md): "*P5:01:51 <C418> I should have made hard techno*" [...] "*P5:46:34 <08Notch> no, C418 did the music*" (22:01:51和22:46:34 UTC)</ref>

# 更改
# = 方块 =
* *[熔岩](熔岩.md)**
* [熔岩](熔岩.md)的纹理变得更亮。<ref>[IRC记录](#logs.md): "*P5:05:14 <Fishlips> thank you so much for making lava look a thousand times better!*" [...] "*P5:08:36 <Evil-Ville> ah you made lava brighter*" [...] "*P5:10:35 <Fishlips> lava has been changed*" [...] "*P5:10:39 <Quatroking> Yep*" [...] "*P5:10:46 <Quatroking> just checked the pic on the wiki and this one is brighter*" [...] "*P5:10:58 <AlLnAtuRalX> New lava owns*" (22:05:14至22:10:58 UTC)</ref>

# = 常规 =
* *其他**
* 用FPS限制器替代了FPS计。<ref name="fps limit">[IRC记录](#logs.md): "*P5:06:14 <08Notch> i took out the fps meter*" [...] *P5:06:18 <08Notch> and added a framerate limiter*". (22:06 UTC)</ref>
* * 限制FPS为200。</onlyinclude>

# 重新上传
该版本的客户端于21:58（UTC）被重新上传，以修复[玩家](玩家.md)无法连接到服务器的漏洞。<ref>[IRC记录](#logs.md): "*P4:58:33 <08Notch> there we go, the client should work again*". (21:58:33 UTC)</ref>
