# 羊毛

* *羊毛（Wool）**是一种从[绵羊](绵羊.md)身上获取的方块，有着16种不同的[颜色](颜色.md)。

# 生成
紫色羊毛、粉红色羊毛、品红色羊毛不会生成在世界中。

# = 自然生成 =
; 林地府邸
除品红色、粉红色、和紫色以外的多种羊毛自然生成于[林地府邸](林地府邸.md)。
; 村庄
白色和黄色羊毛生成于[平原](平原.md)村庄中的牧羊人房子、制箭师房子与会合点；淡灰色羊毛生成于[雪原](雪原.md)村庄中。
; 掠夺者前哨站
白色羊毛在[掠夺者前哨站](掠夺者前哨站.md)中作为羊毛帐篷生成。
; 远古城市
灰色羊毛在[远古城市](远古城市.md)中作为走廊的地板生成。

蓝色、淡蓝色和青色羊毛堆积在远古城市的营地结构中。

# 获取
# = 绵羊 =
在成年[绵羊](绵羊.md)身上[剪刀](剪刀.md)会获得1-3个羊毛；如果绵羊在死亡时没有被剪毛，则会掉落1个羊毛。

掉落的羊毛的颜色与绵羊的颜色相同，羊毛的掉落数量不会受[抢夺](抢夺.md)魔咒的影响。

白色、淡灰色、灰色、黑色、棕色、粉红色羊毛可以在相应的绵羊身上自然地找到。而剩余的颜色则需要对绵羊染色才能得到。

# 破坏
挖掘羊毛的合适工具是剪刀。

羊毛被破坏后会掉落自身。

# 用途
羊毛是易于破坏、易燃且爆炸抗性低的方块。它们的主要用途是装饰以及制作床。

# = 交易 =

# = 合成材料 =
使用任何颜色的羊毛或木头合成[画](画.md)不会对合成出来的物品的外貌造成影响。

# = 燃料 =

羊毛能用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个羊毛可以烧炼0.5个物品。

# = 幽匿感测体 =
羊毛可以阻断[幽匿感测体](幽匿感测体.md)感应振动。

羊毛[物品实体](物品实体.md)掉在地上、在羊毛上行走、放置羊毛-{}-发出的声音不会被幽匿感测体检测。
