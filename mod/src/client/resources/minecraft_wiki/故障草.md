# 故障草

*页面ID: 91802* | *来源: Minecraft Wiki*

* *故障草（<samp>grass_carried</samp>）**是一种渲染存储[草方块](草方块.md)模型的方块。

# 获取
故障草只能通过编辑物品栏获得。

# 破坏
故障草可用任何工具或徒手瞬间破坏，但不会掉落任何物品。

# 用途
# = 外观 =
故障草的外观与草方块较为相似，但有两个明显的差异：
* 故障草的顶部纹理颜色与草方块的明显不同，并且更能适配常规草方块的侧面纹理。
* * 这是因为故障草使用染色前的纹理，而草方块使用进行常规染色的灰度纹理。
* 草方块底部使用[泥土](泥土.md)的纹理，但故障草底部使用草方块侧面的纹理：[32px](File:Grass_Block_(facing_NWU)_BE3.png.md)

# = 与草方块的功能性差异 =
除了在视觉上的差异，故障草与常规的草方块还具有明显的功能性差异：
* 可被瞬间破坏。<ref name=BreakingFootage">https://youtu.be/djvCj4tZdNM?t=9m06s</ref>
* 破坏后不产生掉落物。<ref name=BreakingFootage"/>
* 在物品栏中没有图标。<ref>https://youtu.be/djvCj4tZdNM?t=8m35s</ref>
* 不能被转变为[耕地](耕地.md)。<ref name="MCForums">https://www.minecraftforum.net/forums/minecraft-pocket-edition/mcpe-discussion/1968560-my-report-on-3-strange-new-blocks</ref>
* 需要放置在草方块上的方块，如[花](花.md)和[甘蔗](甘蔗.md)，不能放在故障草上方。<ref name="MCForums"/>
* 在故障草上方放置固体方块不会使其逐渐转变为泥土。
