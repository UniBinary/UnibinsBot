# Java版1.18.1

*页面ID: 91291* | *来源: Minecraft Wiki*

* *1.18.1**是的一次次要更新，发布于2021年12月10日<ref></ref>，对迷雾做了一些调整，并修复了一些漏洞（其中包括一个可能导致服务器执行非法远程代码的[Apache Log4j2重大安全漏洞](Tutorial:修复Apache Log4j2漏洞.md)）。此版本兼容[1.18](Java版1.18.md)的服务端。

# 更改
# = 常规 =
* *迷雾**
* 世界迷雾会从离玩家更远的位置上开始显示，以提高远处地形的可见度。
* 现在迷雾以圆柱形范围显示，而不是以前的球形。
