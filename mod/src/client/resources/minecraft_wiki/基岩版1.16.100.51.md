# 基岩版1.16.100.51

*页面ID: 68008* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.100.51**是[基岩版1.16.100](基岩版1.16.100.md)的第2个测试版<ref></ref>，发布于2020年8月12日<ref></ref>，同步了一些的特性，更改了成就界面，并修复了一些漏洞。

# 更改
# = 方块 =
* *[玄武岩](玄武岩.md)**
* 不再会被恶魂火球摧毁。
* 现在破坏玄武岩需要更多时间。

# = 生物 =
* *[海豚](海豚.md)**
* 更改了海豚窒息的时间为以同步。

* *[雪傀儡](雪傀儡.md)**
* 现在剪下雪傀儡的南瓜头时会掉落[雕刻南瓜](雕刻南瓜.md)。

* *[海龟](海龟.md)**
* 现在会在下蛋时播放音效。

# = 非生物实体 =
* *[经验球](经验球.md)**
* 现在可以在水中漂浮。

# = 游戏内容 =
* *[附魔](附魔.md)**
* [经验修补](经验修补.md)魔咒现在只会修复受损的物品，而不是随机抽取物品进行修复。

# = 常规 =
* *[成就](成就.md)**
* 手柄的扳机现在可以用于在成就界面切换标签页了。
* 修改了标签页默认的页面。
* 在列表下方和输入框中间增加了一个空隙。
* 现在成就详细信息界面会显示“在其他平台上已完成”部分。

* *地图制作和[附加包](附加包.md)**
* 物品命名格式不再需要部分，因此其将被忽略。
* 添加了实体行动预测。

# 修复
* *崩溃与性能**
* 当重新加入多人游戏对话的玩家打开脚下的潜影盒时游戏不再崩溃。（）

* *原版趋同**
* 海龟在下蛋时会播放音效。
* 更改了海豚窒息的时间为120秒以与Java版同步。
* 经验修补魔咒现在只会修复受损的物品，而不是随机抽取物品进行修复。（）
* 现在玄武岩不能被恶魂火球摧毁。（）
* 现在挖掘玄武岩需要更多时间。
* 当红石火把放置于TNT之上时，TNT不再被激活。（）
* 现在经验球可以在水中漂浮。（）
* 调整了下界合金物品在熔岩中的移动行为。（）
* 更改了村民交易的折扣价格以与Java版同步。（）
* 活塞不能再伸出建筑高度限制或虚空。（、）

* *常规**
* 除非砂轮改变了物品属性，否则它现在不会再展示结果。（）
* 气泡柱的水现在按照它应有的方式流动了。（）
* 被命名的船和矿车在放置和摧毁时，其名称将会被保留并在世界中显示。（）
* 熔炼后的物品（1.13之前）不再包含错误的耐久值，可以堆叠。（）
* 现在敌对生物可在雷雨天生成。（）
* 现在剪下雪傀儡的南瓜头时会掉落雕刻南瓜。（）
* 现在在末地和下界的蜜蜂会在分配时间后离开其蜂房/蜂巢。（）
* 水现在会正确地在边缘附近流动。
* 修复了一个可能导致掉落的方块在传送门附近重复出现的问题。（）
* 村民不再会被锁定到错误的职业。（）
* 当重生末影龙时，基座上的龙蛋不再消失。（）
* 在海洋生物群系进入水中时音乐不再被打断。（）
* 树苗在靠近树木和花朵时，其将不再错误地转变为蜂巢。(）
* 若漏斗上方有容器，则此漏斗不再收集掉落的物品。（）
* 当下方的支撑方块被活塞推动时，重力方块不再被摧毁。（）
* 种植大型云杉树时灰化土不会在第一层下方生成了。（）
* 修复了导致铁轨在X轴上不被正确地充能的问题。（）
* 现在陆地上的海龟和海豚会正确地向水中移动。（）
* 现在玩家在船上时指南针能指向正确的方向。（）
* 生物的不活跃计时器将在32格内有玩家时重置。
* 恶魂能再次在所有亮度等级下生成。（）
* 修复了恼鬼在X和Z轴方向的运动。（）
* 烈焰人现在会基于玩家距离切换近距离和远距离攻击。（）
* 下落中的方块消失的时间更长了。（）
* 命名牌现在能再次正确地工作。（）
* 现在能持续地用铁桶收集鱼了。

* *用户界面**
* 修正了在NPC对话框中单击以编辑文本框不会显示插入符号的视觉问题。

* *技术性**
* 修复了ItemDescriptors。
* 物品命名格式“minecraft:item.someitem”不再需要“item”部分，因此其将被忽略。
* 添加了实体行动预测。</onlyinclude>
