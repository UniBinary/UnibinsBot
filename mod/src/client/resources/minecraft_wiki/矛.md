# = 生物 =

[僵尸](僵尸.md)、和[屍殼](屍殼.md)在生成时可能携带铁矛，作为[僵尸马](僵尸马.md)或[骆驼尸壳](骆驼尸壳.md)的乘客生成时必然携带铁矛。[猪灵](猪灵.md)、[僵尸猪灵](僵尸猪灵.md)在生成时可能携带金矛。这些矛可能带有魔咒。这些生物被玩家或玩家驯服的[狼](狼.md)击杀时，其手中的矛有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落。

# 用途
玩家手持矛时不能[挖掘](挖掘.md)方块。

[物品实体](物品实体.md)形式的下界合金矛会漂浮在[熔岩](熔岩.md)上，且不会被[火](火.md)和熔岩摧毁。

# = 近战攻击 =
矛有两种[近战攻击](近战攻击.md)方式，分别为“戳刺”和“冲锋”。

目标的碰撞箱对于矛的或会扩大0.125格以便击中，戳刺攻击会扩大0.25格。

矛的近战攻击有穿透效果。一旦触发攻击，在实体的碰撞箱扩大后能被矛攻击到的所有实体都会被攻击，即无视被攻击实体对攻击的“遮挡”。若攻击者与目标之间满足触发攻击的其他条件，但中间相隔[可替代方块](可替代方块.md)（如[矮草丛](矮草丛.md)、[高草丛](高草丛.md)等），攻击会正常触发。一次攻击中，矛攻击到的每个实体都会独立地进行[消耗度](消耗度.md)、[耐久度](耐久度.md)消耗等的结算，即玩家一次性攻击过多实体会大量消耗饥饿值与矛的耐久度。若矛附有[火焰附加](火焰附加.md)魔咒，则魔咒对所有攻击到的实体正常生效；若矛附有[击退](击退.md)魔咒，则魔咒只对矛直接攻击的实体生效。

即使满足触发[暴击](暴击.md)的条件，矛的近战攻击也不能触发暴击。即使满足触发[击退攻击](击退攻击.md)的条件，矛的近战攻击也不能触发击退攻击。

矛每成功进行一次近战攻击会减少1点[耐久度](耐久度.md)。

# == 戳刺 ==
[玩家](玩家.md)通过按下键可触发戳刺。矛进行戳刺攻击时有把矛向前戳出的动画，发出矛戳刺的音效。[攻击冷却完成度](攻击冷却.md)回满前不可再次使用戳刺攻击；矛进行一次戳刺攻击后进入[物品冷却](物品冷却.md)时间，冷却期间不能再次进行戳刺攻击，冷却时间与Java版中同品质矛的攻击冷却时间相同。

矛的[工具材料](工具材料.md)品质越高，戳刺伤害越高，但冷却时间越长。

矛的戳刺拥有4.5格的攻击范围，大于玩家的一般攻击范围3格，但矛的戳刺攻击需要在攻击者距离目标至少2格时才能触发。

使用有[突进](突进.md)魔咒的矛进行戳刺攻击时会给予攻击者一个水平方向的速度，将攻击者向前推进，这需要攻击者不在水中、不处于滑翔状态或骑乘状态。若攻击者是玩家，这会大量消耗玩家的[饱和度](饱和度.md)和[饥饿值](饥饿值.md)。

矛在攻击指示器未满时无法进行戳刺攻击。

# == 冲锋 ==
玩家通过按下键抬起矛，可进入冲锋状态，此时矛会被放平，矛头朝向前方。冲锋状态下矛无法进行戳刺攻击。

进入冲锋状态需要一小段时间。抬起矛一段时间后，会进入“疲劳”状态，此时矛开始抖动，矛头由水平方向旋转至竖直方向；若持续抬起时间更长，会进入“脱离”状态，此时矛头会下垂；“脱离”状态结束后，矛会恢复到抬起前的状态，不再能触发冲锋攻击，除非再次进入冲锋状态。

在冲锋时，如果攻击者向前移动直到视线正对目标的[碰撞箱](碰撞箱.md)，且攻击者与目标之间的距离大于2格并小于4.5格，则会独立地尝试对目标造成以下三种效果：
* 若攻击者与目标间的相对速度（相应速度矢量在攻击者视线上的分量，下同）大于4.6米/秒，则按下文算法对目标产生伤害。
* * 若冲锋攻击未触发伤害效果，则不会激怒目标。
* 若攻击者速度大于5.1米/秒，且矛尚未进入“脱离”状态，则对目标产生[击退](伤害#击退.md)。否则攻击不造成击退，不会触发[击退](击退.md)魔咒的效果。
* 若攻击者速度大于下表中的“击落所需攻击者速度”，且矛尚未进入“疲劳”状态，而目标正在[骑乘](骑乘.md)另一实体，则将目标从载具上击落。若目标被其他实体骑乘则不会解除其骑乘状态。
只要上述三种效果中的任何一个被触发，则视为产生一次“冲锋攻击”，此时手中矛的模型会向后突进一小段，并发出矛击中的音效。矛的冲锋攻击无冷却，冲锋时可以无间隔地进行攻击，但矛击中时的动画和音效只会在先前的击中动画结束时播放。[攻击冷却](攻击冷却.md)时间内仍可以触发冲锋攻击，且伤害不受影响；矛在[冷却](物品冷却.md)时仍可以触发冲锋攻击。

冲锋攻击的伤害随攻击者与被攻击实体的相对速度提升而增加，随相对速度方向与攻击者视角夹角方向减小而增加，但不受矛是否进入“疲劳”或“脱离”状态的影响。矛的[工具材料](工具材料.md)品质越高，冲锋攻击的伤害越高，将乘客从载具上击落所需的速度越小，进入攻击状态的时间越短，但进入“疲劳”、“脱离”状态、结束攻击的时间也越短。冲锋攻击伤害不受[虚弱](虚弱.md)和[力量](力量（状态效果）.md)状态效果影响。

冲锋攻击造成的伤害为<math>\lceil \vec{v_{at}} \times \alpha \rceil</math>，伤害倍率<math>\alpha</math>取决于矛的品质，相对速度<math>\vec{v_{at}} \equiv  \left | \left ( \vec{v_a} - \vec{v_t} \right ) \cdot \hat{d} \right |</math>，其中<math>\vec{v_a}</math>为攻击者速度，<math>\vec{v_t}</math>为被攻击者速度，单位均为公尺/秒，<math>\hat{d}</math>为攻击者视角方向的单位向量。

# = 生物使用 =
[僵尸](僵尸.md)、[僵尸村民](僵尸村民.md)、[尸壳](尸壳.md)、[僵尸猪灵](僵尸猪灵.md)、[猪灵](猪灵.md)持有矛时，外观与玩家持有矛不同，其空闲时矛会放平，且左手略微抬起。它们仅会以冲锋攻击的方式使用矛。它们举起矛一段时间后会正常触发“疲劳”、“脱离”状态，也会正常结束攻击状态。当与目标的相对速度不足以造成伤害或冲锋状态结束时，它们会尝试拉开一段距离，然后再向目标冲锋。如果骑乘速度较快的载具如[僵尸马](僵尸马.md)、[骆驼尸壳](骆驼尸壳.md)，其冲锋时会额外加速，造成更高的伤害。它们进行冲锋攻击时，游戏进行条件判定的所需速度会乘以0.2，所需距离会乘以0.5，这使得它们能更容易地对玩家造成较高伤害，更容易将玩家从载具上击落。

其他生物在手持矛时并不会冲锋，只会像使用[剑](剑.md)、[斧](斧.md)等武器一样使用矛的戳刺攻击。这反而导致这些不会冲锋的生物使用带有[突进](突进.md)魔咒的矛时突进魔咒会生效。

非玩家使用矛的冲锋攻击只有2.5格的攻击范围。

# 你知道吗
* 在不进行任何附魔的情况下，玩家使用单次伤害最高的下界合金矛从高空垂直下落时，通过冲锋方式能造成的伤害上限为94点。
* 处于[创造模式](创造模式.md)的玩家可以被矛的冲锋攻击击退、击落载具，即使攻击来自处于[生存模式](生存模式.md)的玩家。
* 冲锋攻击时，造成伤害至少需要4.6米/秒的相对速度，而造成击退至少需要5.1米/秒的攻击者速度。因此当目标移动时，攻击者速度不等于相对速度，矛便会有与平时不同的表现。
* * [骷髅](骷髅.md)在玩家靠近时会缓慢后退以远离玩家，因此玩家疾跑时对骷髅的冲锋攻击经常只会将骷髅击退而不造成任何伤害。
* * 玩家A朝向持矛冲锋但不移动的玩家B快速移动时，玩家A会被攻击受到伤害，但不会被击退。这可能导致玩家A与玩家B间的距离缩短到2格内，使得玩家B不再能用矛攻击玩家A。
* 矛的冲锋攻击伤害不仅受相对速度大小影响，还受攻击者视角方向影响。攻击者视线方向与相对速度夹角越小，攻击伤害越大。
* * 攻击者骑[马](马.md)、[骆驼](骆驼.md)等载具攻击地面上的目标时，攻击者需要低头才能攻击到目标，相对速度与视线夹角变大，攻击伤害变小。
* * 攻击者横向移动时，相对速度方向与视线夹角接近直角，因此伤害降低甚至不能触发冲锋攻击。
* 矛进行冲锋攻击判定所需的“视线”与通常意义上的“视线”（即按下组合键时从实体[视平线](视平线.md)处发出的蓝色箭头）有时不重合。
* * 玩家[速泳](速泳.md)时，[判定箱](判定箱.md)高度降低，通常意义上的视线也降低，但矛进行冲锋攻击判定所需的视线不变。因此玩家需要瞄准目标的判定箱下方才能正常进行冲锋攻击。
* * 套有[鞍](鞍.md)的坐下的[骆驼](骆驼.md)被玩家骑乘时，玩家可以按下键使骆驼站起。然而，站起后玩家进行攻击判定所需的视线仍处于站起前的较低位置，使得相对速度方向与视线夹角减小，上文提及的攻击伤害变小的效应被减弱，矛更容易击中目标且可以造成更高伤害。
