# 原主机版TU21、CU9、1.14

*页面ID: 81554* | *来源: Minecraft Wiki*

* *TU21/CU9/1.14**是[原主机版](原主机版.md)的一次更新，发布于2015年2月11日，修复了一些漏洞。<ref></ref><ref></ref>

# 更改
# = 非生物实体 =
* *[矿车](矿车.md)**
* 增加矿车极限。

# = 游戏内容 =
* *[合成](合成.md)**
* 合成地图现在会输出一张空地图。

# 修复
* *修复了8个漏洞**
* 关于红石的修复。
* 被驯服的马在被栅栏围起来的地方停下。
* 修复了音符盒的崩溃。
* 修复了村庄的漏洞。
* 修复了重新加载后女巫小屋将会生成非女巫的生物的漏洞。
* 修复了下界重置后烈焰人刷怪笼和箱子不会出现在下界的漏洞。
* 修复了矿车穿过下界传送门的漏洞。
* PSV：修复了云看起来如二维般的漏洞。
