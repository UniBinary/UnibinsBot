# 基岩版1.16.210.53

*页面ID: 73520* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.210.53**是[基岩版1.16.210](基岩版1.16.210.md)的第3个测试版，发布于2020年12月17日<ref></ref>，加入了[细雪桶](细雪桶.md)和全屏游戏快捷键，同时修复了一些漏洞。

# 新内容
# = 物品 =
* *[细雪桶](细雪桶.md)**
* 通过对[细雪](细雪.md)[铁桶](铁桶.md)获得。
* 可用于放置细雪。

# = 命令格式 =
* *[游戏规则](游戏规则.md)**
* <code>freezeDamage</code>
* * 玩家是否承受冰冻伤害。

# 更改
# = 方块 =
* *[细雪](细雪.md)**
* 现在实体在其内移动或落在其上时会出现[粒子效果](粒子效果.md)。
* 着火的生物受到的冰冻效果现在会被立即移除。
* 陷入细雪的生物现在可在寻路时穿过细雪。
* 生物身上的火现在会在其踏入细雪时熄灭。
* [红石粉](红石粉.md)、[火把](火把.md)和[物品展示框](物品展示框.md)不再能放置在细雪上。
* 受重力影响的方块落在细雪上后不再会被破坏。
* 玩家陷入细雪时，第三人称视角不再会被挤入玩家头部的内侧。
* 生成在细雪内部的生物不再会误生成在地下。
* 从创造模式物品栏中移除了细雪方块。（）
* 细雪不再会阻挡弹射物。（）
* 较轻的生物现在可以在细雪中攀爬和寻路。
* [兔子](兔子.md)、[蠹虫](蠹虫.md)和[末影螨](末影螨.md)不再会陷入细雪。
* 在细雪中行走的生物现在会发出正确的脚步声，而不再发出踩踏其脚下的方块的脚步声。
* 现在装备皮革靴子可以在细雪内向上攀爬。（）
* 细雪现在拥有独立的互动音效。
* 玩家视角处于细雪方块内部时，其上会渲染迷雾和一层覆盖纹理。

# = 物品 =
* *[皮革盔甲](皮革盔甲.md)**
* 现在装备任意一件皮革盔甲即可完全免疫冰冻效果。

# = 生物 =
* *[山羊](山羊.md)**
* 现在会在寻路时避免走上细雪。

# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 加入了“冻死”的死亡消息：
* * “<玩家>被冻死了”

# = 常规 =
* *[控制](控制.md)**
* 现在可以通过按下快捷键切换至全屏显示模式。

* *[设置](设置.md)**
* 由于Mixer流媒体服务不再可用，游戏将广播选项完全移除。

* *[粒子](粒子.md)**
* 加入了新的粒子类型：。

# 修复
* *下界环境音效**
* 手机端玩家现在可以体验下界环境音效。（）

* *常规**
* 用炼药锅为潜影盒洗去染色后，其内容物不再会丢失。（）
* 加入了生物取消骑乘其他实体的新逻辑规则。
* * 这也引入了一套更精确的实体高度检测机制，使得实体能够在不同高度处取消骑乘后落在不同位置。
* 玩家取消骑乘实体（如船）后不再会落入水和熔岩。
* 加入了全屏游戏快捷键。
* 现在登录失败后游戏会提供更加实用的错误信息，同时还会显示错误代码。

* *游戏内容**
* 现在在所有用同一个种子创建的世界中，同一位置的战利品箱中总会以相同顺序生成相同的战利品。（）
* 放置在区块边界的大箱子不再会部分隐形，打开时也不再会引起崩溃。（）
* 金苹果和附魔金苹果现在被选中时会显示彩色的提示文本。（）

* *技术性内容**
* 将中的属性更改为适用于自定义生物的功能。</onlyinclude>
