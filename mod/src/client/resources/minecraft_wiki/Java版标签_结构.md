# Java版标签/结构

*页面ID: 161626* | *来源: Minecraft Wiki*

* *结构标签（Structure Tags）**是[生成结构](生成结构.md)的组合。

# 使用
结构标签通常用于定位结构，如[探险家地图](探险家地图.md)的定位和命令的定位。
