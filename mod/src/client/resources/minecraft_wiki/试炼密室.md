* *试炼密室（Trial Chambers）**是[主世界](主世界.md)中包含[试炼刷怪笼](试炼刷怪笼.md)和[宝库](宝库.md)的地下[结构](结构.md)。

# 生成
试炼密室自然生成于主世界的[深板岩](深板岩.md)层，通常被地形掩埋。其起始结构<code>corridor/end_*x*</code>（廊尾）在Y=-40至-20的高度生成，但结构整体并不局限于该高度。实际上，结构的大多数房间往往在Y=-20至0的高度生成。

试炼密室的生成按照网格状排列。在以世界原点为中心每34×34个[区块](区块.md)的区域中总会有一个试炼密室生成。

试炼密室的生成按照网格状排列。游戏会尝试在每34×34个区块的区域内生成一个试炼密室。试炼密室只会在特定的生物群系中生成。它们通常会在[繁茂洞穴](繁茂洞穴.md)或[溶洞](溶洞.md)的边缘附近生成，而不会在内部生成。

试炼密室可通过[试炼探险家地图](试炼探险家地图.md)定位。与制图师[村民](村民.md)进行交易可获得试炼探险家地图，详见。

# 结构
[thumb|一个试炼密室的平面图，水潭处为起始结构](File:Trial Chambers layout.png.md)

试炼密室由多个大小不一的相通结构组成，主要分为**柱廊（Corridor）**、**过道（Hallway）**、**交叉口（Intersection）**和**决斗室（Chamber）**。

决斗室是供玩家与敌对生物战斗并收获战利品的场地，设有多个[试炼刷怪笼](试炼刷怪笼.md)，分为近战型（[僵尸](僵尸.md)、[尸壳](尸壳.md)、[蜘蛛](蜘蛛.md)择其一）、小型近战型（[洞穴蜘蛛](洞穴蜘蛛.md)、[幼年僵尸](幼年僵尸.md)、[蠹虫](蠹虫.md)、[史莱姆](史莱姆.md)择其一）、远程型（[骷髅](骷髅.md)、[沼骸](沼骸.md)、[流浪者](流浪者.md)择其一）和[旋风人](旋风人.md)刷怪笼。试炼刷怪笼附近地面上的方块指示其激活时会召唤什么生物，详见[下文](#试炼刷怪笼.md)。击杀其生成的所有生物后，每个试炼刷怪笼会喷出一些补给物品**或**1个[试炼钥匙](试炼钥匙.md)，用试炼钥匙解锁决斗室内的[宝库](宝库.md)后即可获取战利品，有概率获得试炼密室独有的[风弹](风弹（物品）.md)、[沉重核心](沉重核心.md)、2种[锻造模板](锻造模板.md)及2种[旗帜图案](旗帜图案.md)。

[试炼探险家地图](试炼探险家地图.md)上的[20px|class=pixel-image|link=](File:Map icons-trial chambers JE1 BE1.png.md)图标定位的是试炼密室的起始结构（柱廊的廊尾），玩家到达此处后可选择以下路径：
# 直接进入一个必定有旋风人试炼刷怪笼的决斗室。
# 沿着柱廊前进。
# # 打开柱廊侧边的[铜门](铜门.md)，经过一条过道，过道尽头是一个试炼刷怪笼类型不定的决斗室、一处死胡同或是一个有箱子的房间。
# # 沿着柱廊直走到尽头，到达一处三岔交叉口；
# ## 选择岔道之一，进入一个试炼刷怪笼类型不定的决斗室。
# ## 选择另一条岔道，通向第二条柱廊，可继续开启铜门。柱廊远端是带有壁画和喷泉的中庭，尽头可能有一个植物造景。

试炼密室是全封闭的结构，且几乎完全由[凝灰岩砖](凝灰岩砖.md)包裹。试炼密室的地板为涂蜡的氧化铜块及其变种，墙面嵌有涂蜡的铜块和不同[氧化](氧化.md)程度的[涂蜡的铜灯](涂蜡的铜灯.md)。铜灯是试炼密室中的主要光源，玩家可用[斧](斧.md)为已氧化的铜灯除锈，增加其亮度等级。

# = 柱廊 =
[thumb|right|250px|柱廊的剖面图](File:Trial Chambers corridor.png.md)
试炼密室交叉口结构的其中一条通道依次连接柱廊1、中庭、“入口”<ref group="注" name="entrance">文件名如此，实际上并非试炼探险家地图定位处。</ref>结构，另一条通道依次连接柱廊2、廊尾、旋风人决斗室。

每条柱廊由4个随机抽取的柱廊片段拼接而成，每个片段都有上中下3层。一些片段的侧边有通往过道结构的[铜门](铜门.md)。在世界中自然生成时，柱廊片段中会放置一些[摆设](#摆设.md)；柱廊中央还会随机添入一些附属结构（Addon），如平台、[绊线钩](绊线钩.md)陷阱、随机[试炼刷怪笼](试炼刷怪笼.md)（不包括旋风人）。

# = 过道 =
[thumb|right|250px|铜门后的一条蜿蜒的过道](File:Trial Chamber hallway.png.md)
过道是将柱廊与决斗室连通，或是通往死胡同的小型楼梯间结构，有直行楼梯和旋转楼梯。一些过道会生成箱子。

# == Encounter ==

作为过道的变种，Encounter在连接柱廊与决斗室的过道中罕见<ref></ref>生成。这些结构中包含一个[试炼刷怪笼](试炼刷怪笼.md)、一个[宝库](宝库.md)，并生成其他障碍物，形成比决斗室更简单的挑战。

# = 交叉口 =
[thumb|right|250px|交叉口样式之一](File:Trial Chamber intersection.png.md)
交叉口与3条通道相接，分别通往柱廊1、柱廊2和决斗室。交叉口设有多张[床](床.md)，供玩家设置出生点。

# = 决斗室 =
[thumb|right|250px|决斗室样式之一](File:Trial Chamber room.jpeg.md)
决斗室共有8种样式，每种决斗室都预留有多个入口，入口处会放置[漏斗](漏斗.md)和[木桶](木桶.md)组成的弃物装置<ref></ref>。决斗室在世界中自然生成时，其中任意一个入口会与廊尾、过道或交叉口相接，其余入口则被封上；[宝库](宝库.md)和多数[试炼刷怪笼](试炼刷怪笼.md)会出现在决斗室内固定的位置；决斗室的空旷处还会随机添入多种附属结构：在高处放置桥或悬吊平台，地面放置障碍墙，中央放置刷怪主平台，角落放置走道，走道上可能带有额外的试炼刷怪笼。

大多数会生成旋风人的决斗室还会出现带[弹射物](弹射物.md)的发射器机关，旋风人的[风弹](风弹（实体）.md)造成的[风爆](爆炸#风爆.md)可以触发这些机关。

# 战利品

# = 试炼刷怪笼 =

[试炼刷怪笼](试炼刷怪笼.md)会掉落下列2个战利品表之一的物品，每个战利品表被选中的概率为50%。参与试炼的玩家数量决定了试炼刷怪笼从同一个战利品表中随机抽取物品的次数。

与[试炼刷怪笼](试炼刷怪笼.md)相比，[不祥试炼刷怪笼](不祥试炼刷怪笼.md)的补给战利品表被选中的概率提高到70%，钥匙战利品表被选中的概率降低到30%。战利品的抽取次数依然与玩家数量相同。

# = 宝库 =

每次解锁时，宝库都会从战利品表中随机抽取物品，具体如下：
* 首先，有80%的概率从稀有战利品表抽取1次，20%概率从普通战利品表抽取1次；
* 总是从普通战利品表抽取1-3次；
* 对于普通的[宝库](宝库.md)，有25%的成功概率从独有战利品表抽取1次；对于[不祥宝库](不祥宝库.md)，则有75%的成功概率从独有战利品表抽取1次。
柱廊密室的战利品箱子也使用试炼密室宝库的普通、稀有和独有战利品表。

# 你知道吗
* 试炼密室的构想始于[David Carlton](David Carlton.md)在会议中提议重制[地牢](地牢.md)。<ref>https://clips.twitch.tv/KawaiiArbitraryNikudonKeyboardCat-BsrnVON_L8vehSz8</ref>
* 试炼密室的设计融合了的建筑风格与未来科技感。<ref></ref>
* [Brandon Pearce](Brandon Pearce.md)曾用“pretty tinkery”（很爱捣鼓）来形容试炼密室的建造者。<ref></ref>
* [Lena Raine](Lena Raine.md)认为她创作的曲目“[Deeper](Deeper.md)”很贴合她对试炼密室的想象：新色彩、新材料以及“在混乱空间中的刻意设计”，同时它展现了“主世界略微黑暗的一面”。<ref></ref>
* * 而在游戏中，该曲目播放于[深暗之域](深暗之域.md)和[溶洞](溶洞.md)。
* 在一期试炼刷怪笼前瞻视频中出现了未曾实装的决斗室样式，包含二楼的活板门陷阱、[红石灯](红石灯.md)机关和立柱包围的旋风人试炼刷怪笼。<ref></ref>
* * 可能为首批实装的决斗室中所缺失的。
* 试炼密室中刻意设计了一些隐藏房间，这些房间通常在最底层有一个异常的[涂蜡的铜格栅](涂蜡的铜格栅.md)作为暗示。
* 决斗室的结构生成相当随机，有可能会出现入口被某些结构堵住导致玩家不能进入的情况。
* 并非所有决斗室都含不祥宝库，决斗室的不祥宝库可能会被楼梯结构取代，决斗室的不祥宝库可能会被发射器取代。
* 由于决斗室空间狭窄，生成的骷髅或变种常会相互误伤并反击，这正是开发者的设计预期。<ref name="chamber-secrets"/>
* 当决斗室的地板发射器装的是[水桶](水桶.md)时，会因为无法放置水而直接掷出水桶。
* 决斗室的外圈地面上用[涂蜡的氧化切制铜块](涂蜡的氧化切制铜块.md)标记出发射器水流扩散的最远位置。
* * 由于水流的距离受一些附属结构影响，它与该标记并不吻合<ref></ref>；在的前身决斗室中，二者是完全吻合的。
* 在试炼密室交叉口中，粉红色床生成的概率低于其他颜色的床，这是开发者有意为之的。<ref></ref>
* 由于试炼密室的生成顺序先于[团簇](团簇.md)取代[石头](石头.md)的生成，标示蜘蛛和洞穴蜘蛛试炼刷怪笼的石头可能会被某些构成团簇的方块取代。
