# 基岩版提及特性

*页面ID: 20912* | *来源: Minecraft Wiki*

有许多特性被提及要加入到基岩版中。

# 计划中
# = 战斗更改 =

更改的战斗系统，并同步到基岩版上。<ref></ref>

# = 扁平化 =

在[Java版1.13](Java版1.13.md)中，许多ID被合并或拆分等，数字ID也被移除了。这个被称为“扁平化”的过程也计划在基岩版上实现。

# = 制箭台的功能 =
[制箭台](制箭台.md)在后续版本中将获得实际功能。[Java版](Java版.md)与[基岩版](基岩版.md)均有更新计划。

# = 投票决定的更新 =
[沙漠](沙漠.md)和[热带草原](热带草原.md)生物群系在[MINECON Earth 2018](MINECON Earth 2018#生物群系选举.md)的“生物群系选举”当中被淘汰。官方承诺这些生物群系的新特性将在未来的某次更新当中加入游戏：<ref></ref><ref></ref>

* 将为沙漠添加-{棕}-榈树、绿洲和狐獴。
* 将为热带草原添加猴面包树、白蚁和鸵鸟。
* 狐獴和鸵鸟出现在了Minecraft Live 2022和Minecraft Live 2023的生物投票基岩版服务器中。

[山地](山地.md)生物群系在[MINECON Live 2019](MINECON Live 2019#生物群系投票.md)的“生物群系投票”当中胜出，其相关特性已于[Java版1.18](Java版1.18.md)和[基岩版1.18.0](基岩版1.18.0.md)加入游戏中。未在投票当中胜出的[沼泽](沼泽.md)相关特性已于[Java版1.19](Java版1.19.md)和[基岩版1.19.0](基岩版1.19.0.md)加入游戏中。未在投票当中胜出的[恶地](恶地.md)将在其后的版本当中更新，将为其添加秃鹫、风滚草和一种新型的仙人掌。<ref></ref>
* 秃鹫出现在了[Minecraft Live 2022](Minecraft Live 2022.md)和[Minecraft Live 2023](Minecraft Live 2023.md)的生物投票基岩版服务器中。

[哞花](Minecraft Earth:哞花.md)和[冰术师](Minecraft Dungeons:冰术师.md)在[Minecraft Live 2020](Minecraft Live 2020.md)的“生物投票”中落选，但有可能会在未来的更新中加入。<ref></ref>
* 哞花和冰术师出现在了Minecraft Live 2022和Minecraft Live 2023的生物投票基岩版服务器中。

怒目怪和[铜傀儡](铜傀儡.md)在[Minecraft Live 2021](Minecraft Live 2021.md)的“生物投票”中落选，铜傀儡已于[基岩版1.21.100](基岩版1.21.100.md)加入游戏中，而怒目怪有可能会在未来的更新中加入。
* 怒目怪和[铜傀儡](铜傀儡.md)出现在了Minecraft Live 2022和Minecraft Live 2023的生物投票基岩版服务器中。

凝灰岩傀儡和淘气鬼在[Minecraft Live 2022](Minecraft Live 2022.md)的“生物投票”中落选，但有可能会在未来的更新中加入。
* 凝灰岩傀儡和淘气鬼出现在了Minecraft Live 2023的生物投票基岩版服务器中。

螃蟹和企鹅在[Minecraft Live 2023](Minecraft Live 2023.md)的“生物投票”中落选，但有可能会在未来的更新中加入。

# 未完全实现的特性
下列特性已被Mojang员工展示，但没有进一步的开发或者之后被取消了。

# = 桨 =
2014年9月19日，[Tommaso](Tommaso Checchi.md)表示当[船](船.md)被加入至携带版时，可能也会加入“桨”物品，用于驾驶船。<ref></ref><ref> </ref>但“桨”物品始终未被加入游戏，仅于[船](船.md)的合成配方中以[木锹](木锹.md)代替。[基岩版1.20.10](基岩版1.20.10.md)移除了船的合成配方中的木锹。

# = 动力矿车 =
[150px|右](File:Minecart with Furnace.png.md)

在2016年1月23日，[Tomasso](Tomas Sommar.md)说他打算加入动力矿车，但不知道如何实现，因此动力矿车仅存在于纹理中。

# 提及特性
下列特性在某一时刻被提及，但后来被放弃或其当前状态未知。注意其中一些特性是被以前的开发者提出的，他们现在已不在[Mojang](Mojang.md)工作。

# = 世界生成 =
开发者曾经提到了许多有关世界生成的更改。Tomasso计划加入遥远的生物群系，在有限世界的边缘能够发现，原本计划在0.9.0加入，却因未知原因被推迟了。<ref name="FarBiome"></ref><ref name="PEPanel"></ref><ref name="Far0.9.1"></ref><ref name=todo></ref>他还提出了一个独特的位于世界下面的地下结构<ref name="exclusive"></ref>和一个梦之维度<ref name="Q&A">https://m.twitch.tv/mojang/v/19541608, October 7, 2015</ref>，然而这些想法都没有实现。

Tommaso表示他想使每个生物群系的难度都不同，让系统可以根据生物群系来生成不同数量的生物和掉落物数量，或者根据天气生成不同的资源。<ref></ref>这会使夜间敌对生物的数量和每个生物群系获得的资源数量出现不同。他还表示，他想要更多的生物群系独有生物以及具有特定难度/生物分布的生物群系。

许多的这些想法在[MINECON 2016](MINECON 2016.md)再次重申，开发者表示他们可以从PC移植世界生成的变化，或者创造一个新的世界生成。他们表示，这个世界生成系统随着时间的推移可以有更好的发展，生物群系越来越多，生成越来越多，地下更多的空间，可能将海平面提高到y=96，使地形变得不可预测。这个构想最终由“洞穴与山崖”更新得以实现。<ref name="Minecon2016"/>

# = 接口/控制 =
在MINECON 2016上，开发人员提到了未来对控件的改进，使其成为基于矢量的，允许在Android上完全支持鼠标，并拥有更好的内置控制器支持。<ref name="Minecon2016"/>目前Android设备已经可以使用鼠标操控。

此外，在上一个面板中，他们还提到了能够将长触重新映射到基于硬度的触摸（3D触摸）的能力的iPhone。<ref name="Q&A"/>

# = 其他的旧世界大小 =
Tomasso说他们可能会为[旧世界类型](旧世界类型.md)提供其他可选的大小，除了原有的256×256之外，还提及了1000×1000和10000×10000这两种大小。<ref></ref>该想法于[MINECON 2016](MINECON 2016.md)被再度提及。

# = 在主机上加载外部文件 =
Roger Carpenter在Xbox One的1.2 Beta中提及。<ref>https://mixer.com/Minecraft?vod=6632210</ref>他们希望主机版可以从外部媒体（如U盘）加载文件。这将像在其他平台上一样，可以使用Add-Ons、自定义世界、皮肤和资源包等。但主机公司担心其“安全问题”。其他游戏从外部媒体加载内容，有时在主机上被黑客利用以运行未经授权的代码。若无法在外部媒体加载Add-Ons，他们将“通过其他方式解决”。

# 来自Java版

开发人员提到了将来会把Java版的特性移植到基岩版上去，包括：
* 在所有基岩版版本之间共享世界。<ref name="BlockTalk"></ref>
* 用Mojang账号登录。<ref name="Q&A"/>
* * 现在和均使用Microsoft账号登录。
* 与Java版独立服务器相似的服务器特性。<ref name="Minecon2016"></ref>
* [Java版1.9](Java版1.9.md)的战斗机制。<ref></ref>
* * 一部分在[基岩版1.10.0](基岩版1.10.0.md)中加入，例如[盾牌](盾牌.md)（使用方式与Java版略有不同）。
* * 一部分在[基岩版1.18.30](基岩版1.18.30.md)中加入，例如[盔甲韧性](盔甲韧性.md)和[斧头](斧头.md)破盾。
* 双持。
* * 一部分在[携带版1.1.0](携带版1.1.0.md)中加入，例如副手槽可以放入[不死图腾](不死图腾.md)和[箭](箭.md)。
* * 一部分在[基岩版1.2.0](基岩版1.2.0.md)中加入，例如副手槽可以放入[地图](地图.md)。
* * 一部分在[基岩版1.8.0](基岩版1.8.0.md)中加入，例如副手槽可以放入[烟花](烟花.md)。
* * 一部分在[基岩版1.19.40](基岩版1.19.40.md)中加入，可以通过命令将任何物品放入到副手槽内，且部分物品可以像在主手时那样正常交互。但是部分物品和方块没有正确的第一人称左手手持模型。
* [进度](进度.md)。<ref></ref>
* 更多[命令](命令.md)。<ref></ref>
* 地图上的[旗帜](旗帜.md)标记。<ref name=banner-item_frame></ref>
* 更多世界类型：[放大化](放大化.md)、[巨型生物群系](巨型生物群系.md)和[调试模式](调试模式.md)。
