* *生毒马铃薯片（Poisonous Potato Slices）**是一种能被[玩家](玩家.md)食用的[食物](食物.md)类[物品](物品.md)。

# 获取
# = 切毒马铃薯 =
切毒马铃薯
|Olink=none
}}

# 用途
# = 食物 =

手持生毒马铃薯片按住键即可食用，每个生毒马铃薯片可以回复。

食用生毒马铃薯片有独特的[音效](#音效.md)。

# = 烧炼材料 =
生毒马铃薯片能在[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或[营火](营火.md)中被烹饪成[炸毒马铃薯片](炸毒马铃薯片.md)。
