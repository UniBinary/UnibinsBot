# 携带版0.11.0.b9

*页面ID: 27933* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 9**是[v0.11.0 alpha](携带版0.11.0.md)的第9个测试版，发布于2015年5月4日，修复了一些漏洞。

# 新内容
# = 生物 =
* *常规**
* 燃烧的生物在接触玩家时会使玩家着火。

# 修复

* *其他漏洞**
* 修复了大多数的语言翻译错误。
* 修复了有关tessellator的漏洞。
* 修复了有关下落的方块的漏洞。
* 打开皮肤选择界面使得游戏崩溃。
* 实体速度不正确。
* 修复了有关传送机制的漏洞。
* 修复了有关驯服狼的漏洞。</onlyinclude>
