# 基岩版1.17.0.56

*页面ID: 82311* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.17.0.56**是[基岩版1.17.0](基岩版1.17.0.md)的第8个测试版，发布于2021年5月13日<ref></ref>，加入了[熔岩含水层](含水层.md)，并修复了一些漏洞。

# 更改
# = 方块 =
* *[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)**
* 现在种植在[苔藓块](苔藓块.md)上也可以被[骨粉](骨粉.md)催熟为[杜鹃树](杜鹃树.md)。

* *[深板岩](深板岩.md)和[虫蚀深板岩](虫蚀深板岩.md)**
* 现在会保持顶部和底部纹理方向一致。
* * 由于镶嵌的限制，深板岩仅有顶部和底部纹理方向保持一致（深板岩是可旋转方块）。

* *[细雪](细雪.md)**
* 纹理不再会随机旋转。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 不再会在[甜浆果丛](甜浆果丛.md)中采蜜。

* *[美西螈](美西螈.md)**
* 不再会攻击[隐身](隐身.md)的生物。
* 更改了纹理以匹配。

* *[凋灵](凋灵.md)**
* 现在免疫细雪的冰冻伤害。

# = 世界生成 =
* *[紫晶洞](紫晶洞.md)**
* 略微降低了生成频率，将每个区块生成紫晶洞的概率由降低到。

* *[含水层](含水层.md)**
* 现在Y=0以下的含水层中的水有概率被[熔岩](熔岩.md)完全替代。
* * 仅开启[实验性玩法](实验性玩法.md)（洞穴及悬崖子选项）后可用。

# = 常规 =
* *控制器提示**
* 加入了以下提示：
* * 手持[望远镜](望远镜.md)
* * 用[铁桶](铁桶.md)收集[炼药锅](炼药锅.md)中的熔岩
* * 用铁桶收集炼药锅中的细雪
* * 用熔岩桶填充炼药锅
* * 用细雪填充炼药锅

* *[实验性玩法](实验性玩法.md)**
* 加入了在旧世界启用[实验性玩法](实验性玩法.md)时出现的警告。
* 加入了显示世界是否有开启[实验性玩法](实验性玩法.md)的标签。
* 在世界创建设置中加入了关于[实验性玩法](实验性玩法.md)的描述。

# 修复
* *洞穴与山崖特性**
* 现在用美西螈桶放置美西螈会保留其被装起前的颜色。（）
* 破坏紫晶芽或紫水晶簇的粒子不再会悬浮在空中。
* 更改了手持紫晶芽时的渲染模型以匹配Java版。（）
* 降低了紫晶洞的生成概率。
* 玩家现在能够对小型垂滴叶按下选取方块键。（）
* 对小型垂滴叶使用骨粉后，长成的大型垂滴叶高度现在至少为2格。（）
* 生物又可以在滴水石锥附近正确寻路了。
* 自然生成的发光鱿鱼现在会被刷新。 （）
* 现在对着发光鱿鱼按下选取键会获得发光鱿鱼刷怪蛋。（）
* 闪电击中避雷针时不再会生成骷髅陷阱。
* 部分方块不再可以放置在细雪上。（）
* 栅栏和墙不再会与附近的细雪连接。（）
* 陷入细雪时的迷雾效果不再会于第三人称视角下显示。（）
* 着火时进入了2个细雪不再会导致未被融化的细雪隐形。（）
* 细雪不再拥有可以与生物碰撞的边角了。

* *生物**
* 现在骷髅在细雪中转化为流浪者时会播放正确音效。
* 凋灵不再会受到细雪的冰冻伤害。（）
* 蜜蜂不再会从甜浆果丛中采蜜了。
* 蜜蜂又可以正确进入蜂箱或蜂巢了。（）

* *游戏内容**
* 受到负值伤害的玩家不再出现伤害吸收值。（）
* 现在触摸控制的玩家按住合成输出格能够快速合成一组物品。（）

* *铁矿石、金矿石**
* 现在在低于1.17版本的旧世界中开采铁矿石或金矿石会正确掉落其自身，而不是不掉落任何物品。

* *物品**
* 捡起部分物品时不再会捡起整组物品并扔掉多余的物品。（）

* *玩家动画**
* 修复了玩家在被其他玩家杀死而重生后会显示持弓动画的问题。（）
* 修复了“视角摇晃”选项开启时某些物品（主手持有的弓、弩、三叉戟、盾牌）不会摇晃的问题。（）

* *翻译**
* 移除了“Lit Deepslate Redstone”的翻译。（）

* *技术性**
* 修复了在“Simburbia”世界中站在窗帘方块旁会使视野变成数据更新方块的问题。
* 修复了使用停止播放音效时发生的崩溃。（）
* 修复了加载原版生物的json定义时的合并漏洞。
* 修复了JSON版本低于1.8.0的被覆写生物的属性的漏洞，这使得蜜蜂可以通过命令生成。（）
* 现在过滤器会正确分类自定义刷怪蛋。
* 若设置为true时且弹射物着火，则只会使被该弹射物击中的生物免疫火焰伤害。

* *图形**
* 修复了Windows 10上由于指针引用过时而在光线追踪模式下发生的崩溃。
* 修复了在多种情况下（切换分辨率、开启画质提升、开启/关闭光线追踪）光线追踪纹理无法加载的问题。
* 修复了附魔弓的纹理过暗的问题。（）

* *专用服务器**
* 专用服务器日志现在会在加载时显示该世界中所启用的实验性玩法选项。</onlyinclude>
