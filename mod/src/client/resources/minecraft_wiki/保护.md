# 保护

*页面ID: 42220* | *来源: Minecraft Wiki*

* *保护（Protection）**是一种用于[盔甲](盔甲.md)的[魔咒](魔咒.md)，能减少生物受到的绝大多数类型的伤害。

# 获取

# 用途

保护魔咒可以减少绝大多数类型的伤害。每魔咒等级提供1点魔咒保护系数（EPF），即4%伤害减免。

保护魔咒不能减少[饥饿](饥饿.md)、[虚空](虚空.md)、[监守者](监守者.md)的远程攻击和造成的伤害。

保护与其任何不共存魔咒被应用在同一个物品上时，每个魔咒都会互不干扰地产生效果。
