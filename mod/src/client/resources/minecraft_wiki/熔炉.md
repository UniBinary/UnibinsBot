* *熔炉（Furnace）**是一种可以[烧炼](烧炼.md)物品的方块。

# 生成
# = 自然生成 =
每个[平原](平原.md)和[沙漠](沙漠.md)[村庄](村庄.md)的铁匠铺里会生成两个熔炉，每个[雪屋](雪屋.md)中会生成一个熔炉。

熔炉也会在[雪原](雪原.md)村庄的某些小屋、[针叶林](针叶林.md)村庄和小屋中生成。

熔炉也会在[古迹废墟](古迹废墟.md)的匠铺中生成。

熔炉还会作为红石电路的一部分在[远古城市](远古城市.md)<code>ancient_city/city_center/city_center_2</code>结构的地下室里生成，其燃料槽有1把木[锹](锹.md)、产物槽有24个[深板岩](深板岩.md)。

# 获取
燃烧的熔炉只能通过命令如{{cmd|give @s <nowiki>minecraft:furnace[minecraft:block_state={lit:"true"}]</nowiki>}}获得，但在物品栏中它不是燃烧着的。可以通过修改物品栏来获得。无论里面有没有物品，它都会一直保持点亮状态。

# 破坏
挖掘熔炉的合适工具是镐。熔炉需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

熔炉被破坏后会掉落自身、内容物和储存的经验值。

# 用途
熔炉不能被[活塞](活塞.md)推动。

# = 烧炼 =

熔炉的主要用途是[烧炼](烧炼.md)，速度为每烧炼一个物品，即每分钟烧炼6个物品。

熔炉可打开它的界面。下方的槽位为“燃料槽”，用于放置燃料（最多1组）；上方的槽位为“烧炼槽”，用于放置烧炼物（最多1组）；右侧的槽位为“成品槽”，烧炼成品会存放于此（最多1组）。

熔炉的烧炼速度是[高炉](高炉.md)和[烟熏炉](烟熏炉.md)的一半，但熔炉可进行全部烧炼配方，包括高炉和烟熏炉的配方及高炉和烟熏炉都不能进行的配方。

连接到熔炉上面的[漏斗](漏斗.md)会向烧炼槽中添加烧炼物，连接到熔炉侧面的[漏斗](漏斗.md)会向燃料槽中添加燃料，熔炉下面的[漏斗](漏斗.md)会取走成品槽的物品和燃料槽的[铁桶](铁桶.md)或[水桶](水桶.md)，如果燃料槽与成品槽同时存在物品会优先吸取或。烧炼产生的经验会存储在熔炉中，当玩家取出成品槽中的成品或熔炉被破坏时一并给予玩家。

燃烧中的熔炉会生成烟雾和火焰[粒子](粒子.md)。

# = 红石比较器 =
[红石比较器](红石比较器.md)可检测熔炉的内容物占空比，烧炼槽、燃料槽和成品槽都会被统计。

# = 光源 =
燃烧中的熔炉会发出13级的光。

# = 自定义名称 =
熔炉界面的标题默认为“熔炉”，可以在未放置之前使用[铁砧](铁砧.md)重命名来进行更改，也可以通过使用命令修改熔炉的<code>CustomName</code>标签进行更改。

# = 上锁 =

熔炉可以被<code>lock</code>标签上锁。如果熔炉的该标签不是空白的，那么这个熔炉必须使用符合该标签表示的物品谓词的物品打开。

# 你知道吗
* 熔炉的功能集多个设备的功能于一个方块：锻铁炉、高炉、熔炼炉、转炉和焙烧炉（用于烧炼矿石），熟食炉（用于烘焙和烹饪），炭坑（用于燃烧木头），窑（用于烤制黏土和玻璃）以及精炼炉（用于精炼[粗铜](粗铜.md)）。
