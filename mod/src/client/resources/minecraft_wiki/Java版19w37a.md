# Java版19w37a

*页面ID: 47484* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w37a**是[Java版1.15](Java版1.15.md)的第4个快照，发布于2019年9月11日<ref name="19w37a"></ref>，同步了一些的[独有特性](基岩版独有特性.md)，并修复了一些漏洞。

# 更改
# = 方块 =
* *[营火](营火.md)**
* 现在能被[锹](锹.md)熄灭了。
* *[耕地](耕地.md)**
* 可以手动在耕地上而不会将其变成[泥土](泥土.md)的[方块](方块.md)现在也可以被活塞推到耕地上，而方块下的耕地不会变成泥土。
* *[草丛](草丛.md)**
* 大型蕨现在会掉落[小麦种子](小麦种子.md)。

# = 物品 =
* *[船](船.md)**
* 作为[熔炉](熔炉.md)、[高炉](高炉.md)、[烟熏炉](烟熏炉.md)的[燃料](燃料.md)时现在能[烧炼](烧炼.md)6个物品，而不是过去的1个物品。

# = 实体 =
* *[生物](生物.md)**
* [可繁殖](繁殖.md)的生物在成群地自然生成时现在有时会生成对应的幼年个体了。
* * [牛](牛.md)、[绵羊](绵羊.md)、[猪](猪.md)和[鸡](鸡.md)生成幼年个体的概率为5%
* * [狼](狼.md)、[羊驼](羊驼.md)和[马](马.md)生成幼年个体的概率为10%

# = 常规 =
* *进度**
* 进度中的物品判定现在会将实际的魔咒和储存的魔咒区分开，例如储存在[附魔书](附魔书.md)里的魔咒
* * 用于匹配存储的附魔。
