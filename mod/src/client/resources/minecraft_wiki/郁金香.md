# 郁金香

*页面ID: 21032* | *来源: Minecraft Wiki*

* *郁金香（Tulip）**是一类[小型花](小型花.md)，有**红色郁金香（Red Tulip）**、**橙色郁金香（Orange Tulip）**、**白色郁金香（White Tulip）**和**粉红色郁金香（Pink Tulip）**共4种。

# 生成

# = 自然生成 =
郁金香会在[平原](平原.md)、[向日葵平原](向日葵平原.md)、[繁花森林](繁花森林.md)、[溶洞](溶洞.md)和[深暗之域](深暗之域.md)生物群系自然生成。

郁金香也会在[林地府邸](林地府邸.md)中生成。

# = 骨粉 =
在可自然生成郁金香的生物群系中对[草方块](草方块.md)[骨粉](骨粉.md)后，郁金香有概率代替[矮草丛](矮草丛.md)生成。

对着不[含雪](含雪.md)的郁金香使用骨粉会出现更多的同种颜色的郁金香，而不会出现草丛。

# 破坏
郁金香被挖掘时会立刻被破坏。

郁金香被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 谜之炖菜 =

使用郁金香合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家7s的[虚弱](虚弱.md)效果。

# = 堆肥 =
将郁金香放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
