# 沙子

* *沙子（Sand）**是一种在[沙滩](沙滩.md)和[沙漠](沙漠.md)自然生成的[方块](方块.md)。

# 生成
# = 自然生成 =
沙子会以[圆盘](圆盘.md)的形式生成于主世界生物群系（[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)除外）的地表水域底部。

沙子会在[沙漠](沙漠.md)、[沙滩](沙滩.md)和[积雪沙滩](积雪沙滩.md)的地表大量生成，通常形成由[砂岩](砂岩.md)支撐的4格厚的地层。沙子也会在[温水海洋](温水海洋.md)、[温水深海](温水深海.md)、[暖水海洋](暖水海洋.md)及[暖水深海](暖水深海.md)的海底生成，通常形成由[石头](石头.md)支撑的1格厚的海床。

沙子也会生成在部分[埋藏的宝藏](埋藏的宝藏.md)的[箱子](箱子.md)上方，将箱子掩埋。

沙子也会作为温带[海底废墟](海底废墟.md)、沙漠[村庄](村庄.md)、[沙漠神殿](沙漠神殿.md)、[沙漠水井](沙漠水井.md)和[试炼密室](试炼密室.md)的一部分生成，温带海底废墟的沙子可能会被替换为[可疑的沙子](可疑的沙子.md)。

沙子可以自然生成在空中。当周围接收到方块更新时（在周围有方块被放置或破坏）（需要[PP更新](方块更新#PP更新.md)），相邻的下方没有支撑方块的沙子会全部掉落。

# = 可疑的沙子 =
[可疑的沙子](可疑的沙子.md)被[刷子](刷子.md)刷扫后会转换为沙子。

挖掘沙子的合适工具是锹。

沙子被破坏后会掉落自身。

# 用途
# = 下落的方块 =

沙子在下方没有不可替代的方块时会变为[下落的方块](下落的方块.md)。

沙子在没有得到支撑时，会在方块下方产生[粒子](粒子.md)。

# = 种植 =
[仙人掌](仙人掌.md)、[甘蔗](甘蔗.md)、[竹子](竹子.md)、[枯萎的灌木](枯萎的灌木.md)、[矮枯草丛](矮枯草丛.md)和[高枯草丛](高枯草丛.md)可以在沙子上面种植。

# = 环境音效 =
若沙子的上方一格为空气，且其四个水平轴向上八格外处，有至少三处在上下五格内存在上方一格为空气的沙子，该沙子有概率发出特殊的环境音效。

满足上述条件时，沙子总是小概率播放<code>block.sand.idle</code>音效。

# 你知道吗
* 如果一块沙子上面有[雪](雪.md)，沙子下落时，雪会被摧毁而不会掉落[雪球](雪球.md)。
* 由于下落的沙子被认为是一个实体，它因此可以被[TNT大炮](Tutorial:TNT大炮.md)发射，这与激活的TNT类似。
* 沙子在变成下落的方块实体时，其纹理会被旋转，类似于激活的TNT。但[沙砾](沙砾.md)并不会这样。
* 在沙漠和有沙子的洞穴出口中，常常会看到浮空而不下落的沙子，这些沙子在收到[方块更新](方块更新.md)后才会下落。
* 因为<code>falling_block</code>是一个实体，浮空的沙子方块会在一瞬间消失并生成一个<code>falling_block</code>实体。沙子落地时则反之，实体消失后，沙子方块将被程序放置在新的位置上。
