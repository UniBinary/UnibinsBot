# 红树根

*页面ID: 93872* | *来源: Minecraft Wiki*

* *红树根（Mangrove Roots）**是一种装饰性方块，会作为红树底部的根须生成。

# 生成
# = 自然生成 =
自然生成的[红树](红树.md)地物有红树根作为其底部的根须生成。

红树根也可能会在试炼密室的“入口”结构中作为植物造景的一部分生成。

# = 红树胎生苗 =
[红树胎生苗](红树胎生苗.md)长成红树时，红树根会作为其底部的根须生成。

# 获取
红树根的物品形式只能通过破坏红树根获得。

# 破坏
挖掘红树根的合适工具是斧。

红树根被破坏后会掉落自身。

# 用途
红树根可以[含水](含水.md)。不像多数可含水的方块，红树根是一个完整方块且没有任何一个表面允许水的流出或流入。

# = 合成材料 =

# = 燃料 =
红树根可以作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个红树根可以烧炼1.5个物品。

# = 堆肥 =
红树根有30%的概率将[堆肥桶](堆肥桶.md)的堆肥层数增加1。
