* *末影龙火球（Dragon Fireball）**是[末影龙](末影龙.md)发射的[弹射物](弹射物.md)。

# 生成
[末影龙](末影龙.md)会向[玩家](玩家.md)发射末影龙火球。

# 行为
末影龙火球是一种弹射物，可以触发[标靶](标靶.md)。

末影龙火球拥有不受[重力](重力.md)影响的无限远的直线弹道，但会在1分钟后消失。

与[火球](火球.md)不同，末影龙火球的弹道不能被偏转。

由末影龙发射的末影龙火球是匀速的，具有加速度的火球只能由[命令](命令.md)生成。

# = 生成区域效果云 =

末影龙火球在撞击并爆炸后，会在该位置生成一团效果为II、颜色为紫色的[区域效果云](区域效果云.md)。该区域效果云可以被收集为[龙息](龙息.md)。

末影龙火球接触[方块](方块.md)时会爆炸，0.5秒后产生区域效果云，半径为3，在30秒内逐渐扩展到半径为5后消失。

末影龙火球碰撞到[实体](实体.md)、方块时都会爆炸，立即产生区域效果云，半径为5，在120秒内逐渐减小直至消失。

# = 着火 =
末影龙火球可以[着火](着火.md)。末影龙火球在穿过[火](火.md)或[熔岩](熔岩.md)会着火，穿过[雨](雨.md)、[水](水.md)或[细雪](细雪.md)时会熄灭。

着火的末影龙火球会不受阻碍地穿过[TNT](TNT.md)并使其激活，可以点燃熄灭的[营火](营火.md)，可以破坏其穿过的[细雪](细雪.md)。着火的末影龙火球会点燃其命中的实体。

# = 与方块交互 =
末影龙火球可以触发其击中的[标靶](标靶.md)，可以敲响[钟](钟.md)。

末影龙火球可以激活[木质压力板](木质压力板.md)。末影龙火球可以触发[绊线](绊线.md)和[探测铁轨](探测铁轨.md)（探测铁轨需要使用[比较器更新感应器](Tutorial:比较器更新感应器.md)检测）。当末影龙火球穿过这些方块时，这些开关会保持开启状态。其他开关则不受末影龙火球的影响。由于末影龙火球不能像[箭](箭.md)或[三叉戟](三叉戟.md)一样插在方块上，通常很难使开关保持长时间开启。通过[命令](命令.md)生成的静止不动的末影龙火球会一直保持其位置的开关开启。

# 你知道吗
* 只有具备动量的末影龙火球才会爆炸。用命令生成的静止的末影龙火球接触到方块也不会爆炸；若用爆炸等方式使末影龙火球产生动量，火球才会在接触方块时爆炸。
* 末影龙火球有一个未使用的纹理文件。
