# 基岩版1.11.0.7

*页面ID: 41807* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.11.0.7**是[1.11.0](基岩版1.11.0.md)的第5个测试版，发布于2019年3月20日<ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *皮肤包**
* 当在皮肤包选择一个皮肤时，所选的皮肤会在同一个账户的基岩版设备上执行。

# 更改
# = 方块 =
* *[制图台](制图台.md)、[锻造台](锻造台.md)和[制箭台](制箭台.md)**
* 更改了合成配方，使[锻造台](锻造台.md)和[制箭台](制箭台.md)与[Java版](Java版.md)匹配，[制图台](制图台.md)与[19w11a](19w11a.md)匹配。

# = 生物 =
* *[卫道士](卫道士.md)**
* 现在能够破坏[木门](木门.md)。

# = 游戏内容 =
* *[交易](交易.md)**
* 在交易上点击右键会自动交易。

* *[袭击](袭击.md)**
* 袭击结束两个游戏日后会显示一条信息。
* 将生成在村庄附近的袭击的最大生成距离从52提升到了1024。

* *[状态效果](状态效果.md)**
* 为不祥之兆和村庄英雄加入新的弹出动画。

# 修复
* *修复了29个漏洞**<br>
* *崩溃**
* 修复了游戏进行时的崩溃现象。
* 进入下界传送门时游戏崩溃。（）
* 没有主人的唤魔者尖牙在试图伤害实体时使得游戏崩溃。（）
* 创建新世界时，下载丢失的资源包使得游戏无响应。

* *性能**
* 改进了村民交易界面的运行性能。

* *常规**
* 修复了大部分与TTS文本转语音功能有关的漏洞。
* 禁用“多人游戏”选项时，现在会对模板世界起作用。

* *游戏内容**
* 玩家会在X和Z轴为65535附近的区域穿过方块掉进虚空里。（）
* 玩家退出存档时，袭击进度停止。
* 敲钟不再使得玩家无法退出交易界面。

* *生物**
* 减少了溺尸的攻击距离。
* 玩家睡觉时，头部可以穿墙。（）
* 部分交易选项的价格不合理。
* 灾厄巡逻队不再卡在同一位置。
* 灾厄巡逻队现在会避免生成在村庄周围，如果玩家在村庄里面时。
* 村民工作时会失去与烟熏炉和高炉的绑定。
* 劫掠兽现在会更快进入村庄。
* 劫掠兽不再能穿墙伤害生物。
* 掠夺者前哨站内现在会正确生成掠夺者。

* *方块**
* 挖掘方块时，有时不会显示粒子。
* 圆石台阶在更新游戏时变成了圆石，而名称仍然是圆石台阶。（）
* 滞留药水会使得钟一直被敲响。
* 被活塞推动的堆肥桶不再能掉落无限数量的骨粉。（）

* *物品**
* 部分物品放进物品展示框时会出现纹理渲染错误。（）
* 受损的工具现在可以被烧炼为金粒或铁粒。（）
* 仙人掌现在可以被烧炼为绿色染料。（）

* *用户界面**
* 更新了游戏指南里的脚手架说明。

* *附加包和脚本引擎**
* 模板世界里的村民和僵尸村民刷怪蛋不同步。
* 修复了附加包里的末影人主节点<!-- pivot point change -->改动。</onlyinclude>
