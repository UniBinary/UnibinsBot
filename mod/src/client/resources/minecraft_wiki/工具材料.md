# 工具材料

*页面ID: 56485* | *来源: Minecraft Wiki*

* *工具材料（Tool Material）**指的是工具和武器不同的等级和材料。

# 材料
工具材料决定了物品的、耐久度、挖掘速度倍率、伤害加成、附魔能力和修复所用的物品。

目前游戏中的材料有木质、石质、铜质、铁质、钻石质、下界合金质和金质。

; Java版标签

# 物品影响
[斧](斧.md)、[锄](锄.md)、[镐](镐.md)、[锹](锹.md)、[剑](剑.md)和[矛](矛.md)都使用了工具材料。

工具材料影响上述物品的[默认组件](物品堆叠数据格式#物品默认组件.md)。
* <code>attribute_modifiers</code>：<code>-{}-[{type: "attack_damage", id: "base_attack_damage", slot: "mainhand", operation: "add_value", amount: <*伤害加成*>},{type: "attack_speed", id: "base_attack_speed", slot: "mainhand", operation: "add_value", amount: <*[攻击速度](属性/攻击速度#已知修饰符.md)*>}]</code>
* <code>enchantable</code>：使用上表中的附魔能力。
* <code>max_damage</code>：使用上表中的耐久度。
* <code>repairable</code>：使用上表中的修复所用物品的标签ID。
* <code>tool</code>：
* * 除剑外：<code>-{}-{rules: [{blocks: "<*不适宜挖掘的方块标签ID*>", correct_for_drops: false}, {blocks: "#mineable/<*工具类型*>", correct_for_drops: true, speed:"<*挖掘速度倍率*>"}]}</code>
* * 剑的组件值不受工具材料影响，固定为<code>{"can_destroy_blocks_in_creative": false, "damage_per_block": 2, "rules": [{"blocks": "minecraft:cobweb", "correct_for_drops": true, "speed": 15.0}, {"blocks": "#minecraft:sword_instantly_mines", "speed": 3.4028235E38}, {"blocks": "#minecraft:sword_efficient","speed": 1.5}]}</code>
