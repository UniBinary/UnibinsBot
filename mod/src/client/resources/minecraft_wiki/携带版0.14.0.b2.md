# 携带版0.14.0.b2

*页面ID: 19703* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.14.0 alpha build 2**是[v0.14.0 alpha](携带版0.14.0.md)的第2个测试版，发布于2016年1月27日<ref>http://pocketbeta.minecraft.net/2016/01/changelog-for-014-build-2_27.html?m=0</ref>，修复了一些漏洞。

# 更改
* 破坏[物品展示框](物品展示框.md)时会发出粒子效果。
* 被[闪电苦力怕](闪电苦力怕.md)炸死的[僵尸](僵尸.md)会掉落[头颅](头颅.md)。
* 移除运作中的[漏斗](漏斗.md)、[发射器](发射器.md)、[投掷器](投掷器.md)UI中的进度条。

# 修复

* *其他**
* 暂停游戏时，物品展示框会消失或者失效。
* 创造模式下使用铁砧会消耗经验值。
* 炼药锅内的药水发出的粒子时黑色的。
* 更改GUI尺寸时，佩戴南瓜时显示的纹理错误。
* 退出游戏时游戏崩溃。
* 将物品投进下界传送门后会复制。
* 铁砧、熔炉和附魔台会复制物品。
* 物品展示框的光照错误。
* 创造模式下，不能移出物品展示框内的物品，除非将其破坏。
* 乘船的生物出现错误。
* 投到台阶上的鸡蛋在半空中破碎。
* 僵尸村民的腿部纹理错误。
* 皮革盔甲的纹理错误。</onlyinclude>
