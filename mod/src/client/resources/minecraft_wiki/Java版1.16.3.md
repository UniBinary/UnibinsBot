# Java版1.16.3

*页面ID: 69001* | *来源: Minecraft Wiki*

* *1.16.3**是的一次次要更新，发布于2020年9月10日<ref></ref>，修复了一些漏洞。此版本不兼容1.16到1.16.2的服务端。

1.16.3的游戏内容与其发布候选版本一致<ref></ref>，两者仅在协议版本和数据版本上有所不同。
