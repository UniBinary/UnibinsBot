# 携带版0.9.3

*页面ID: 21275* | *来源: Minecraft Wiki*

* *v0.9.3 alpha**是携带版的一次次要更新，仅在Android上发布于2014年7月16日。此次更新修复了[v0.9.2 alpha](携带版Alpha 0.9.2.md)中的一些漏洞与崩溃。

# 更改
# = 方块 =
* *[羊毛](羊毛.md)**
* 加入了[羊毛](羊毛.md)的平滑光照。

# = 常规 =
* *渲染**
* 改进雾和[区块](区块.md)的渲染。

* *优化**
* 可视距离不再在Android上限制为3。
* 游戏会尝试覆盖损坏的世界。
* 游戏运行得更快，不再有崩溃。
* 改进了[多人游戏](多人游戏.md)的性能。

# 修复

* *其他**
* 生物在和平模式下不再出现
* 修复了在加入多人游戏世界时画面冻结的漏洞。
* 修复了重生时偶尔画面冻结的漏洞。
* 修复了重生在无效的高度的漏洞。
* 修复了苦力怕声音的漏洞。
* 客户端内的实体消失机制再次正常运作。
