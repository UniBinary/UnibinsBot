# 红石粉

*页面ID: 6721* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *红石粉（Redstone Dust）**是一种有多种用途的原材料物品。红石粉可以被放置为**红石线（Redstone Wire）**，传输[红石信号](红石信号.md)。

# 生成
# = 自然生成 =
[丛林神庙](丛林神庙.md)中自然生成15个红石线。

[林地府邸](林地府邸.md)中的一种监狱房间内可以找到5个红石线。

[远古城市](远古城市.md)中心的地下室内可以找到多个红石线。

[试炼密室](试炼密室.md)的<code>encounter_4</code>结构中可以找到一个红石线。

# 获取
# = 红石矿石 =

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[红石矿石](红石矿石.md)或[深层红石矿石](深层红石矿石.md)被破坏后会掉落4-5个红石粉。挖掘工具的[时运](时运.md)魔咒会使其额外等概率掉落0-<魔咒等级>个红石粉，故时运III时可以掉落4-8个红石粉。

# 破坏
红石线被挖掘时会立刻被破坏。

红石线被破坏后会掉落1个红石粉。

# 用途
红石粉可用于[酿造](酿造.md)和[合成](合成.md)，也可以放置在地上形成红石线，构成红石电路。

红石线的判定箱在方块下部约格高，判定箱形状取决于红石线形状。

红石线在遇到下列情况时会被移除并掉落为物品：
* 移动、移除或摧毁红石线所附着的方块
* [水](水.md)流过
* [活塞](活塞.md)尝试推动它或将方块推入其位置

若[熔岩](熔岩.md)流过其位置，红石线将被熔岩摧毁而不会掉落为物品。

# = 放置 =
[缩略图|红石线的摆放示例。*左上角：*红石线可穿过非红石导体往斜上方连接。*右上角：*红石**不能**穿过红石导体往斜上方连接。*中央：*红石线随信号减弱而变暗，最远可从信号源往外传输15格](File:Redstone wire as circuit component.png.md)

红石粉只能放在上表面[方块支撑形状](方块支撑形状.md)完整的方块或[漏斗](漏斗.md)上。

# == 形状 ==
红石线在放置或接收[方块更新](方块更新.md)（需要来自四周和上方的PP更新）时会自动调整形状。

* 连到四周的红石线。
* 连到红石比较器，或是指向或背向它的红石中继器。
* 连到四周侦测器的输出端。
* 连到四周的其他红石[电源元件](红石元件#电源元件.md)、[传输元件](红石元件#传输元件.md)。
*
* 连到与其高一方格或低一方格的邻近的红石线，除非红石线的较低者的正上方被红石导体阻挡（称为“压线”）。
* * 若红石线的较高者处于方块支撑形状上表面不完整的方块上（漏斗和[活板门](活板门.md)除外），较低者不会向上连接。<ref></ref>
* * 若红石线的较高者处于方块支撑形状不完整的方块上，且连接方向上的面不完整，则较低者看起来不会向上连接，而是连到较高者下方的不完整方块上。
* 若未连到与某一水平方向垂直的两个水平方向，则其会连到这一水平方向及其对面方向。也就是说，如果红石线只连接了一个方向，就会变为一条直线。如果没有连接任何方向，红石线会变成“十”字形。

对于没有连接到任何红石元件的十字形的红石线，可以按键使其变为点状，从而不与任何方向连接，再按一次可以恢复。

# == 指向 ==
红石线激活其他元件或充能其他方块时会有它的指向：

*
* * 在形状上应当连接到哪些水平方向，就指向哪些方向，不论形状是否已更新。
* * 永远指向下方，不指向上方。
*
* * 若四周均不可连接，指向四周。
* * 若某一方向可连接，且另外三面不可连接，指向这一方向及其对面。
* * 指向活塞（除非活塞面朝该红石线）。
* * 若某两个相对的方向可连接，另外与之垂直的两个水平方向不可连接，游戏会判断哪一端有信号源，并使该红石线指向对面方向。
* * 永远指向下方，不指向上方。
* 红石线会在逻辑上（区别于上文[形状上的连接](#形状.md)）连接以下水平方向：
* * 该方向有红石线。
* * 该方向有红石比较器，或是指向或背向它的红石中继器。
* * 该方向为侦测器的输出端。
* * 该方向为其他的红石[电源元件](红石元件#电源元件.md)、[传输元件](红石元件#传输元件.md)。
* * 若正上方没有红石导体，且该方向为上放有红石线的方块。
* * 该方向非红石导体，且下方有红石线。

红石线一般不会自动指向附近[机械元件](红石元件#机械元件.md)。若需要指向它们，必须在附近放置额外的红石元件来调整。

红石线的指向因玩家使用和其他红石粉在它四周、下侧[红石导体](红石导体.md)侧面、上方红石绝缘体侧面被放置或破坏以外的原因而改变时，红石线不会方块更新（狭义）。由此可以产生一种暂稳态，其中的机械元件在不应该激活的情况下保持激活，或相反，直至有什么东西引起了电路更新。红石线的这种“特性”可以用来构建[方块更新感应器](方块更新感应器.md)。

# == 行为 ==
红石线可以传输红石信号，从而控制[机械元件](红石元件#机械元件.md)和红石元器件。

红石线可被以下方式激活：
* 毗邻的朝向正确（如果需要）且输出信号的[电源元件](红石元件#电源元件.md)和红石中继器、红石比较器。信号强度为该红石元件输出的信号强度。
* 毗邻的强充能方块。信号强度为该方块的充能等级。
* 附近的其他红石线。信号强度会递减1。红石线可以高一方格或低一方格，但有以下限制：
* * 红石线可以被低一方格的红石线激活，或被处于红石导体上的高1格的红石线激活。或红石绝缘体上的红石线不能将信号往下传输。
* * 高低红石线连线拐角处的方块必须为红石绝缘体。红石导体会切断高低红石线之间的连接（称为“压线”），

红石线的信号强度范围为0-15。大部分电源元件将红石线激活至15级，但另外一些元件（[阳光探测器](阳光探测器.md)、[陷阱箱](陷阱箱.md)、[测重压力板](测重压力板.md)和[红石比较器](红石比较器.md)）可能会输出较低的信号强度。

信号通过红石线传输时，每经过1格红石线，信号强度降低1。因此，仅用红石线最远可以将信号传输15格。若要继续传输信号，必须增强信号——这是红石中继器的典型应用场景。

激活的红石线可以以下列方式激活其他红石元件：
* 激活毗邻的自身[指向](#指向.md)的元件。
* 弱充能毗邻的自身[指向](#指向.md)的红石导体至自身信号强度。弱充能的方块不能激活毗邻的红石线，但仍能够激活毗邻的红石中继器、红石比较器、红石火把和机械元件。
* 单独的点状红石不会激活与充能四周的红石元件和红石导体。

# = 实验性 =

和未开启“”[实验性内容](实验性内容.md)的世界相比：

红石线的性能影响被降低：
* 红石线的信号强度会在红石线传递NC更新之前计算完成。
* 现在仅会对可能接受到来自自身的红石信号的位置传递NC更新。
* * 具体包括红石线的正上方和其指向的所有方块。

[thumb|以蓝线表示更新方向。<br>左一：非竖直方向传入，以红石信号来源方向的反方向为更新方向<br>左二：竖直方向传入，但存在拉杆提供的水平方向，以拉杆方向为更新方向<br>左三：竖直方向传入，但拉杆为红石导体提供了更新方向，以此更新方向为更新方向<br>左四：竖直方向传入，但不存在水平方向，更新方向随机](File:experimental redstone wire update order.png.md)
红石线的更新行为被更改：
* 现在红石线具有更新方向。
* * 如果红石线从**非竖直方向**接受红石信号，则以此来源方向的反方向为更新方向。
* ** 通常情况下来源方向与红石信号的传递方向相反，即更新方向事实上就是红石信号传递的方向。
* * 如果红石线从**竖直方向**接受红石信号，则需要判断电源的方向性：
* ** 如果电源具有水平方向性，例如被拉杆、按钮等电源激活，则使用此方向。
* ** 如果电源不具有水平方向性，例如被红石火把、侦测器、红石块等电源激活，则四个水平方向随机选取。
* 红石线更新时会向其指向的多个方块传递更新，以更新方向为准，更新顺序为：**左、后、前、右、下、上**。
* * 如果更新传递至红石导体方块，则此方块也会按照此顺序进行更新。
* 红石信号更新现在取决于连接顺序。接通或断开信号源时，靠近信号源的红石元件将优先被更新。
* * 此处的“靠近”判定所用的距离为红石信号传递到红石元件的传递次数，即沿红石线传递的距离，不考虑实际的空间距离或红石线的信号强度。
* * 每充能一次，更新顺序只会随机一次。在一整条红石线上，左右红石元件被更新的顺序总是一致的。
* * 如果距离相等，通常而言左侧的红石元件优先激活。但如果被激活的红石线的激活方向随机，则更新顺序一同随机。
