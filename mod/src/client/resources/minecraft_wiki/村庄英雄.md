# 村庄英雄

*页面ID: 41271* | *来源: Minecraft Wiki*

* *村庄英雄（Hero of the Village）**是在击败一次[袭击](袭击.md)后获得的[状态效果](状态效果.md)，能使[村民](村民.md)和<ref name="MCPE-190255"></ref>提供[交易](交易.md)折扣。

# 效果
[thumb|基岩版中获得村庄英雄时播放的动画](File:Hero of the Village Bedrock Animation.gif.md)
带有此效果的玩家会获得村民赠送的礼物，并且在与村民[交易](交易.md)时获得折扣。

带有此效果的玩家会在与村民和流浪商人<ref name="MCPE-190255"/>交易时获得折扣；且在获得此效果时，屏幕中央会播放一个图标旋转的动画，与获得和发动[不死图腾](不死图腾.md)时类似。

# = 折扣 =
等级为I的村庄英雄效果会把第一等级的交易价格降低30%；每一级可额外降低（6.25%）；当村庄英雄等级为V时，交易价格会减少55%。不管折扣有多大，最终交易物品数量总是至少为1；换句话说，物品不会是免费的。在其他情况下，减量是折扣率乘以原始计数向下取整，遇零进一。

例如：村庄英雄III会减少原价的42.5%。如果交易的第一栏原来需要14个[绿宝石](绿宝石.md)，最终的折扣为5个绿宝石（由5.95向下取整而得），而最终需要9个绿宝石。

村庄英雄可以通过任何通常能移除状态效果的方法移除，包括饮用[奶](奶.md)。

# = 给予物品 =

当玩家在[村庄](村庄.md)获得村庄英雄效果后，村民会根据自己的职业从下方表格中的选项中随机选取物品投掷给予玩家。

村民要将物品给予带有村庄英雄效果的玩家，必须满足下列条件：
* 村民可以看见玩家。
* 村民与玩家的距离不超过5格。
* 村民处于空闲状态、正在工作或在会合点聚集。
* * 在晚上，村民会试图睡觉，而不会给予玩家物品。

每个村民在给予玩家一件物品后会有一段长度为30秒至330秒不等的冷却时间。
