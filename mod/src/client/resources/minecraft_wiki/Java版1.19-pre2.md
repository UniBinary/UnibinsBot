# Java版1.19-pre2

*页面ID: 96291* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.19-pre2**是[Java版1.19](Java版1.19.md)的第2个预发布版，发布于2022年5月23日<ref></ref>，做了一些微调，并修复了以[幽匿感测体](幽匿感测体.md)感测振动相关问题为主的一些漏洞。

# 新内容
# = 常规 =
* *[标签](Java版标签.md)**
* 加入了以下[生物群系标签](Java版标签/生物群系.md)：
* * ：

# 更改
# = 方块 =
* *[幽匿感测体](幽匿感测体.md)**
* 加入了可感测的<code>teleport</code>游戏事件，振动频率为5。

# = 物品 =
* *[山羊角](山羊角.md)**
* 现在也会在[山羊](山羊.md)撞击[铜矿石](铜矿石.md)后掉落。

# = 生物 =
* *[监守者](监守者.md)**
* 现在会在卡在液体中时直接消失，而不是钻入地底。

# = 游戏内容 =
* *[进度](进度.md)**
* 在[幽匿催发体](幽匿催发体.md)附近杀死不再计入进度“[](进度#advancements-anchor-adventure.kill_mob_near_sculk_catalyst.md)”的完成情况中。

# = 常规 =
* *声音**
* 回退了上个版本作出的将非盔甲类物品放入头盔槽会播放通用的穿戴装备的声音的更改。
* * 但它们仍然能被[幽匿感测体](幽匿感测体.md)检测到。

* *[标签](Java版标签.md)**
* 向方块标签中加入了。
* 向游戏事件标签中加入了。
