# 附魔台

*页面ID: 6012* | *来源: Minecraft Wiki*

* *附魔台（Enchanting Table）**是一种能够让玩家花费经验等级来为[工具](工具.md)、[武器](武器.md)、[书](书.md)和[盔甲](盔甲.md)进行[附魔](附魔（物品修饰）.md)的[方块](方块.md)。

# 生成
附魔台不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘附魔台的合适工具是镐。附魔台需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

附魔台被破坏后会掉落自身。

# 用途
附魔台的高度为格。

与[台阶](台阶.md)类似，将附魔台放在[冰](冰.md)上时，附魔台的上表面会变得像冰一样滑，使得玩家能够在其上滑行。

# = 附魔 =

[缩略图|附魔界面](File:enchanting-grid.png.md)
附魔台主要用于给未附魔的物品[附魔](附魔（物品修饰）.md)。附魔台可以为任何有[附魔能力](附魔能力.md)且没有[魔咒](魔咒.md)的物品进行附魔；没有附魔能力不能在附魔台上附魔。附魔台不会提供[宝藏型魔咒](宝藏型魔咒.md)。

要附魔物品，首先需要世界中的附魔台以进入附魔界面，然后将若干[青金石](青金石.md)和接受附魔的物品放入输入槽位中。

放入物品后，附魔台便会生成至多3个附魔选项，显示在附魔台的界面右侧。每个选项都包含了一个可以应用到该物品上的附魔结果，具体取决于该选项的附魔等级。每个选项中间出现的图案对附魔没有任何影响。悬停在一个选项上会显示其中的一个魔咒，但实际上可能包含多个魔咒。

在附魔台上进行附魔时，附魔使用的随机数发生器会使用玩家的“附魔种子”（）进行计算。玩家在附魔台上进行附魔后，会重新生成新的附魔种子。附魔种子的存在使玩家在不进行附魔的情况下，相同的物品在相同的有效方块时总是会得到相同的附魔选项。

满足以下条件的选项才能被选择：
* 玩家当前所持经验等级不低于选项右下角显示的数值，即**附魔等级**。
* 青金石槽位上已放置青金石数量不低于选项左侧显示的数值，即**经验等级消耗值**。

点击选项后，附魔台中的青金石堆叠数和玩家的经验等级都会减少等同于经验等级消耗值的数量，并发出回响的书页声，然后将该附魔结果中的魔咒应用到物品上。

创造模式下使用附魔台仍然消耗经验等级。不过，当玩家没有足够的经验等级时，附魔台只会将其扣至0级，且视为等级足够而继续正常附魔。

# == 生成附魔等级 ==
当把一件可附魔的物品放上附魔台时，附魔台会计算三个选项的随机附魔等级，用于生成附魔结果。

假设有效方块数量为*n*，如果*n*大于15，则设置为15。先计算一个附魔等级基数*b*：

<math>b=\mathrm{randInt}(8)+1+\lfloor\frac{n}{2}\rfloor+\mathrm{randInt}(n+1)</math>

其中，函数<math>\mathrm{randInt}(k)</math>的作用是在闭区间<math>[0,k-1]</math>中产生均匀分布的随机整数。

对于附魔台内的每一个选项，附魔台都会生成一次基数，即每个选项的基数可能是不同的。在一次生成内，三个选项的基数是相同的。再根据选项的位置对基数进行调整，决定选项的附魔等级：
* 第一行：<math>\max\left\{\lfloor\frac{b}{3}\rfloor,1\right\}</math>。
* 第二行：<math>\lfloor\frac{2b}{3}\rfloor+1</math>。
* 第三行：<math>\max\{b,2n\}</math>。

如果第二行生成的附魔等级为1，则第二行会被删除。如果第三行生成的附魔等级小于3，则第三行会被删除。

# = 有效方块 =
附魔台周围的**有效方块**数量会影响其附魔等级的生成。

一个方块需要满足下列条件才可能被计算为有效方块：
* 方块必须包含<code>#enchantment_power_provider</code>标签，默认为书架。方块必须为书架。
* 必须位于附魔台同一高度或比附魔台高一格，且与附魔台的水平[切比雪夫距离](切比雪夫距离.md)为2。

附魔台会生成<code>enchant</code>或<code>enchanting_table_particle</code>[粒子](粒子.md)，从有效方块处飘入附魔台。

在下图中的所有书架都可能被计算为有效方块：

附魔台和这些有效方块位置之间不能被阻挡，否则这个位置就无法被识别为有效方块。带有<code>#enchantment_power_transmitter</code>的方块（[空气](空气.md)等可替代方块）不会阻挡有效方块的识别；只有空气不会阻挡有效方块的识别。

根据阻挡方块相对于附魔台的位置，其阻挡有效方块的位置也不同：
* 与附魔台同高度的阻挡方块不会阻挡高一格的有效方块，比附魔台高一格的阻挡方块也不会阻挡与附魔台同高度的有效方块。
* 位于附魔台侧方的阻挡方块会阻挡它后方的3个有效方块位置。
* 位于附魔台斜角方向上的阻挡方块会阻挡它后方斜角的1个有效位置。

* 位于附魔台侧方的阻挡方块会阻挡它正后方的2个有效方块位置。

# = 控制附魔 =
根据附魔台的机制，玩家可以通过多种方式控制物品附魔。

# == 改变有效方块数量 ==
有效方块的数量影响附魔等级，进而影响生成的魔咒。

如果想要减少有效方块数从而减少附魔等级，可以在附魔台和有效方块之间放置[火把](火把.md)、[线](线.md)等方块使部分有效方块无效。

# == 进行任意附魔 ==
对任意物品进行任意等级的附魔都会改变玩家的附魔种子，从而改变所有物品在所有附魔等级上的附魔选项。因此，如果针对某个工具没有称心如意的附魔选项，可以消耗1块青金石和1级经验等级随便附魔一本书或另一个工具来刷新附魔选项，或者在工具附魔后使用[砂轮](砂轮.md)清除其魔咒。

# == RNG附魔 ==

RNG（Random Number Generator）即[随机数发生器](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/Random.html)。附魔种子的生成使用实体自身的随机数发生器的结果。根据当前的魔咒列表和物品附上的魔咒，可以反推附魔种子，根据附魔种子又可以推得实体随机数发生器种子。通过丢弃物品等方式，可以使得实体随机数发生器更新。利用此项特性，可以使附魔种子“固定”到某一个可以获得指定魔咒的种子上，从而进行精准附魔。

# = 符文 =

[thumb|300px|符号文字从书架流入的动画](File:Enchantment Table animated experience.gif.md)
神秘难解的符号文字从书架上浮现并飘进附魔台，并在附魔台的界面中显示，它们即[标准银河字母](wikipedia:en:Commander Keen#Legacy.md)（Standard Galactic Alphabet，SGA）——在《[指挥官基恩](wzh:指挥官基恩.md)》系列电子游戏中使用的一种简单的字母表替代密码。该效果仅在粒子效果启用时出现。

[center](File:Standard Galactic Alphabet.png.md)

如果将视频[选项](选项.md)中的“”设置为“最少”，则无法看到这些符文字母。附魔名称会在以下的单词列表中随机构建：

<blockquote>**air animal baguette ball beast berata bless cold creature cthulhu cube curse darkness demon destroy dry earth elder elemental embiggen enchant fhtagn fiddle fire free fresh galvanize grow hot humanoid ignite imbue inside klaatu light limited mental mglwnafh niktu of other phnglui physical range rlyeh scrolls self shorten shrink snuff sphere spirit stale stretch the towards twist undead water wet wgahnagl xyzzy**</blockquote>

先从以上列表中选取三到五个词首尾组合生成魔咒名称，然后使用标准银河字母显示出来，以作装饰。这与各选项实际对应的魔咒并无关系。

# = 自定义名称 =
附魔台操作界面中显示的名称是附魔，但该名称可以通过在[铁砧](铁砧.md)上对附魔台进行重命名或使用命令修改其标签来自定义。

# 你知道吗
[200px|缩略图|附魔台将生成的粒子传送至书架内部，粒子纹理变为黑色](File:Black Runes.png.md)

* 书架发出的粒子是由附魔台生成的。粒子先是生成在附魔台内部，然后立即被传送到书架内部。
* 附魔台会发光是为了解决附魔台上的书不能正确控制亮度的渲染缺陷。附魔台的亮度特性因[趋同事项](趋同事项.md)而加入了。
* 附魔台的高度介于整个方块和台阶之间，所以附魔台可以在[TNT大炮](TNT大炮.md)中取代台阶或活板门，用作射程放大器。
* [隐身](隐身.md)的玩家靠近附魔台时，台上的书仍会打开。
* 用以生成附魔界面上用标准银河字母组成的说明文字的单词表中包含了几个玩笑：
* * 一种单词组合“the elder scrolls”可能意在讽刺开发*The Elder Scrolls*（《上古卷轴》）系列的Bethesda及其母公司Zenimax。后者曾起诉Mojang一款名为*Scroll*（《卷轴》）的游戏侵犯其权利。
* * 一种单词组合“klaatu berata niktu”引用了“[Klaatu barada nikto](wikipedia:Klaatu barada nikto.md)”，但有拼写错误。这是一个来源于1951年的电影*The Day the Earth Stood Stil*（《地球停转之日》）的短语。这条短语也经常被其他电影、卡通和游戏引用。
* * “xyzzy”是游戏*Colossal Cave Adventure*（《洞穴深处的冒险》）中的一条咒语。这条咒语也被其他许多游戏用作彩蛋或作弊码。
* * “embiggen”是*Simpsons*（《辛普森的一家》）中的一个虚构的词。原文是“A Noble Spirit Embiggens the Smallest Man”（高贵的心灵使矮小的人变得伟大）。
* 附魔台必须通过[宝库](宝库.md)战利品才能实现可再生。这是因为可用于制造附魔台的[钻石](钻石.md)同样依赖宝库战利品实现可再生，而宝库可以被每个玩家打开无限次数<ref></ref>，且[试炼钥匙](试炼钥匙.md)和[不祥试炼钥匙](不祥试炼钥匙.md)是[可再生资源](可再生资源.md)。
