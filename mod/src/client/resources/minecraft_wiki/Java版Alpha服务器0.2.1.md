# Java版Alpha服务器0.2.1

*页面ID: 45481* | *来源: Minecraft Wiki*

* *0.2.1**是一个[Alpha](Java版Alpha.md)服务器版本，发布于2010年9月19日。<ref></ref>

# 修复
* 钓鱼竿不再能破坏一切。
* 修复了多人模式下关于熔炉的漏洞。
* 玩家执行的错误命令不再使服务器崩溃。
