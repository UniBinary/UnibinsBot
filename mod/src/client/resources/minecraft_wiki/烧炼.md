# 烧炼

*页面ID: 9075* | *来源: Minecraft Wiki*

|熔炉的界面}}
* *烧炼（Smelting）**（依具体语境可能又被称为**烧制**、****、**冶炼**或**烹饪**）是转化物品的一种方式，只要给予适合的材料，就会输出对应的成品。烧炼可以使用[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)进行，一些[食物](食物.md)也能使用[营火](营火.md)烹饪。

# 用途和机制
# = 熔炉 =
当[熔炉](熔炉.md)的燃料槽内有燃料，烧炼槽中有烧炼物，且成品槽没有与烧炼所得成品不同的物品时，烧炼就会开始，即使玩家关闭界面，烧炼也会继续。开始烧炼时会先用掉一份燃料，填满界面上的火焰图示。即使烧炼槽中没有烧炼物，火焰也会随时间逐渐减弱。火焰逐渐减弱直至消失后，若烧炼槽仍有烧炼物，熔炉会使用下一份燃料继续烧炼。

熔炉烧炼一个物品需要，界面中的箭头会显示烧炼的进度。若在火焰消失之前箭头已经填满，则烧炼物转换为成品并进入成品槽；若箭头填满前火焰已经消失且没有燃料补充，则箭头的进度会以两倍速度倒退。

若玩家离烧炼的熔炉太远而导致[区块](区块.md)卸载，熔炉会暂停烧炼直到玩家重新加载熔炉所在区块。玩家进入其他维度或退出游戏后熔炉也会暂停烧炼。玩家睡觉不影响烧炼速度，因为烧炼进度只因玩家实际在游戏内时长而定，而睡觉时游戏会直接将游戏时间设定为早上，烧炼进度不会因跳过晚上而瞬间增加。

玩家取出成品会获得对应数量的[经验值](经验值.md)。即使熔炉烧炼成品被[漏斗](漏斗.md)取出，玩家从熔炉中取出任意成品或破坏熔炉后同样会获得其内积累的经验值。<ref></ref>经验值的小数部分代表额外获得的概率。

# = 高炉和烟熏炉 =
物品也可以用[高炉](高炉.md)和[烟熏炉](烟熏炉.md)烧炼，机制和使用方法与普通的熔炉相同，但烧炼效率是普通熔炉的2倍，即烧一个物品只需要。

但高炉只能冶炼[矿物](矿物.md)，熔炼金属工具、武器和盔甲；烟熏炉只能烹饪[食物](食物.md)。

# = 营火 =

食物也能用[营火](营火.md)烹饪，且无需燃料。玩家需要手持[配方](#配方.md)内列出的食物对着一个点燃的营火并它。只要营火仍在燃烧就能无限制地烧制食物。营火烹饪一个食物需要，是熔炉烧炼时间的3倍，但至多可同时烹饪4个食物。烹饪完成后，成品会弹出并变成掉落物。

# 你知道吗

* 使用单个熔炉烧炼一组（64个）物品需要10分40秒时间，可以通过使用多个熔炉**并行**烧炼来压缩最终用时。
* 使用[木炭](木炭.md)作为燃料比使用[原木](原木.md)或[木头](木头.md)作为燃料效率高4倍（×4.57），比使用木板的效率高倍。
* 使用[木板](木板.md)制作[木质台阶](木质台阶.md)作为燃料比使用木板烧炼原木或木头来获得木炭作为燃料的效率高（×1.875）
* 烧炼木炭时最为理想的燃料是它本身。
* 把[煤炭](煤炭.md)合成为[煤炭块](煤炭块.md)可以增加烧炼效率（×1.11）。9个煤炭能烧炼72个物品，而煤炭块可以烧炼80个。
* 如果使用木质工具作为燃料，最具性价比的做法是把工具用到只剩下1耐久度，然后作为燃料使用。
* 尽管下界木与其制品不能直接作为燃料使用，但通过将其合成为诸如[木棍](木棍.md)等由主世界木板同样能制成的物品间接达成该目的。
* “烧炼”在Minecraft中是一个相当广泛的术语，而在现实世界中，烧炼具有更精确的定义。<ref></ref>
