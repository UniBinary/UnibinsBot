# 生成
# = 自然生成 =
马铃圆石楼梯会生成在[马铃薯村庄](马铃薯村庄.md)、[角斗场](角斗场.md)和所有维度的[废弃马铃薯传送门](废弃马铃薯传送门.md)。

# 破坏
挖掘马铃圆石楼梯的合适工具是锄。马铃圆石楼梯需要木锄或品质更好的锄来挖掘，否则挖掘时间将延长且不会掉落。

马铃圆石楼梯被破坏后会掉落自身。
