# Minecraft LIVE – September 2025

*页面ID: 166534* | *来源: Minecraft Wiki*

* *Minecraft LIVE – September 2025**<ref></ref>是一场线上直播活动，于2025年9月27日17:00（UTC）举办。该场活动展示了[铜器时代](铜器时代.md)小更新的更新内容，并宣布了之后的小更新[群骑纷争](群骑纷争.md)及其更新内容。<ref></ref><ref></ref>

# 活动
# = 社区预热 =
在主要活动开始前有约16分钟的社区预热活动，分享了世界各地YouTuber的Minecraft视频。

# = 版本公告 =
本次直播展示了[铜器时代](铜器时代.md)的更新内容，包括[铜傀儡](铜傀儡.md)及其特性、[铜系列的工具、武器和盔甲](铜#工具、武器和盔甲.md)、[展示架](展示架.md)等内容。除此之外，还公布了之后小更新的名称[群骑纷争](群骑纷争.md)以及将于该次小更新加入的新武器[矛](矛.md)与新生物[鹦鹉螺](鹦鹉螺.md)等内容。

# = 游戏演示 =
主要活动结束后，主持人Vu与Agnes、Snifferrish与Gustav演示了铜器时代中的主要变化，之后与Agnes、Tubbolive和Linda演示了群骑纷争中的新生物鹦鹉螺及其相关特性与矛的战斗方式。
