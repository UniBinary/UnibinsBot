# Crowdin中文翻译者披风

*页面ID: 186384* | *来源: Minecraft Wiki*

* *Crowdin中文翻译者披风（Chinese Translator Cape）**是授予为[Crowdin](Crowdin.md)中文翻译做出巨大贡献的3名翻译员的披风。

# 外观
这件披风几乎与[Crowdin翻译者披风](Crowdin翻译者披风.md)相同，但其底面印有中国国旗。

# 描述
在2015年6月4日，[Powup333](User:Powup333.md)、[Craft_Lawrence](User:Craft Lawrence.md)和[sjjklh](User:Sjjklh.md)因Crowdin翻译计划的中文部分作出的巨大贡献获得此披风<ref>https://www.mcbbs.net/thread-452211-1-1.html</ref>。
