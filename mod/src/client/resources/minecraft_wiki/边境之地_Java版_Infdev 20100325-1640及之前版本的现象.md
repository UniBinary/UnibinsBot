# 边境之地/Java版/Infdev 20100325-1640及之前版本的现象

*页面ID: 152556* | *来源: Minecraft Wiki*

[缩略图|Infdev 20100227-1433中边境之地的石墙结构](File:FarlandsCliffs.jpg.md)

下面介绍了[Infdev 20100325-1640](Java版Infdev 20100325-1640.md)及之前版本的边境之地。

# 位置
边境之地会在X/Z=±33,554,432开始向外生成。

# 结构
在[Infdev 20100313](Java版Infdev 20100313.md)之前[Infdev](Java版Infdev.md)版本的边境之地与后来版本的不同，它只是一个从基岩层延伸到世界顶端的一堵实心[石头](石头.md)墙，并一直延伸到32位整数限制。这是边境之地第一次真正可见的外观，尽管在视觉上与[后来版本](边境之地/Java版/Infdev 20100327至Beta 1.7.3的现象.md)的截然不同。

边境之地可能并不总是从X/Z=33,554,432开始生成，因为其表面还可能会出现粗糙、重复的梳状结构，之间则不会生成除了水以外的任何[方块](方块.md)，这会暴露出[世界底部](虚空.md)的[熔岩](熔岩.md)海，梳状结构上还可能会生成一些[草方块](草方块.md)。有时边境之地也有可能不会生成梳状结构，而是完全光滑的，而至于到底是生成与否，这主要取决于种子。
