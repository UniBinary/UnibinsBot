# 煤炭块

*页面ID: 10067* | *来源: Minecraft Wiki*

* *煤炭块（Block of Coal）**是一种能被用作燃料的矿物方块。

# 生成
# = 自然生成 =
煤炭块会作为[古迹废墟](古迹废墟.md)摆设结构的一部分生成。

# 获取
# = 合成 =
煤炭块只能用煤炭合成，其合成方法和其他[矿物](矿物.md)方块一样。

# 破坏
挖掘煤炭块的合适工具是镐。煤炭块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

煤炭块被破坏后会掉落自身。

# 用途
煤炭块可用于储存[煤炭](煤炭.md)，以此来节约空间。

# = 合成材料 =

# = 燃料 =
煤炭块能用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料。1个煤炭块能烧炼800秒（80物品），是1个煤炭的10倍，比单独使用9个煤炭多出的时间，这使得煤炭块比煤炭更适合烧炼大量物品。

# 你知道吗
* 煤炭块不能使用木炭合成，这是出于合成和还原的逻辑问题。<ref name="dinnertweet"/>
* 煤炭块不能作为[动力矿车](动力矿车.md)的燃料使用。
