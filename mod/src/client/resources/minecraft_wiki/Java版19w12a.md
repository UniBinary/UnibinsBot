# Java版19w12a

*页面ID: 41805* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w12a**是[Java版1.14](Java版1.14.md)的第27个快照，发布于2019年3月20日<ref></ref>，加入了切制砂岩和切制红砂岩台阶，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[台阶](台阶.md)**
* 加入了[切制砂岩](切制砂岩.md)和[切制红砂岩](切制红砂岩.md)台阶。
* * 使用切制砂岩和切制红砂岩合成。
* * 不再能够使用切制砂岩制作普通的砂岩台阶。

# 更改
# = 方块 =
* *[旗帜](旗帜.md)**
* 灾厄旗帜不再可用[织布机](织布机.md)或[工作台](工作台.md)复制。

* *[玻璃](玻璃.md)**
* 现在更像大多数的[固体方块](固体方块.md)。
* * 不能传输红石信号了（例如：通过红石中继器传输）。
* * 红石粉现在能放在玻璃上面。
* * 生物在其中会窒息了。

* *[草径](草径.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)**
* 放置时会随机旋转，和[草方块](草方块.md)一样。

* *[砂岩](砂岩.md)**
* 可以通过[切石机](切石机.md)获得[切制砂岩](切制砂岩.md)和[切制红砂岩](切制红砂岩.md)。

* *[告示牌](告示牌.md)**
* 现在只能在[创造模式](创造模式.md)中给文字染色。

# = 物品 =
* *[不死图腾](不死图腾.md)**
* 使用时的模型和纹理可以通过[资源包](资源包.md)更改。

# = 生物 =
* *[铁傀儡](铁傀儡.md)**
* 调整了在[村庄](村庄.md)的生成。
* * 现在只有当村民在聚集前工作或睡觉过会生成。

* *[村民](村民.md)**
* 改进了AI。
* 幼年村民现在会在村庄里玩耍。
* 更改了积雪的村庄和积雪的僵尸村庄中的傻子村民和失业村民。

* *常规**
* 更新了许多实体的碰撞箱和眼睛位置。
* * 玩家潜行时的高度现在是1.5米。

# = 游戏内容 =
* *[进度](进度.md)**
* [](进度#advancements-anchor-husbandry.breed_all_animals.md)
* * 现在也需要繁殖[狐狸](狐狸.md)。

* *[潜行](潜行.md)**
* 现在会将玩家的高度降低到1.5个方块，使其能够穿过1.5格高的空隙。

* *[交易](交易.md)**
* 综合改进。
* * 交易选项会在交易6-8次后失效，而不是4次。

# = 常规 =
* *[创造模式物品栏](创造模式物品栏.md)**
* 现在能在“装饰性方块”卡槽下找到[墙](墙.md)。

* *[声音](声音.md)**
* 重写了声音系统。
* 减少了播放声音的延迟。

* *[闪烁标语](闪烁标语.md)**
* 移除了“Hobo humping slobo babe!”
* 加入了“<玩家名称> IS YOU”
* *世界创建**
* 创建已经使用了相同名字的世界会在文件夹末尾加上括起来的数字（例如“New World (3)”而不是“New World---”）。
