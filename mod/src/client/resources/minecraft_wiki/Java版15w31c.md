# Java版15w31c

*页面ID: 17247* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w31c**是[Java版1.9](Java版1.9.md)的第3个快照，发布于2015年7月31日<ref></ref>，修复了[15w31a](15w31a.md)及[15w31b](15w31b.md)的漏洞。

# 更改
# = 方块 =
* *[草径](草径.md)**
* 草径的高度现在是方块高。

* *[陷阱箱](陷阱箱.md)**
* 陷阱箱现在与普通的[箱子](箱子.md)的物品模型一模一样了。
* * 以前的更改是为了更好地区分陷阱箱与箱子。

# = 生物 =
* *[末影龙](末影龙.md)**
* 重生的[末影龙](末影龙.md)不会掉落多于一个的龙蛋了。

# = 世界生成 =
* *[下界](下界.md)**
* 重新加入了[下界](下界.md)的雾。

# = 游戏内容 =
* ***
* 不再重置跳跃提升所带来的掉落伤害了。
* *双持**
* 现在副手槽可以在玩家的物品栏装满时捡起东西了。
