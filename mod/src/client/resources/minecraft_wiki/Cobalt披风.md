# Cobalt披风

*页面ID: 187479* | *来源: Minecraft Wiki*

* *Cobalt披风（Cobalt Cape）**是向在*[Cobalt](Cobalt.md)*游戏关卡制作大赛与[Cobalt联盟](http://cobaltleague.net/)锦标赛中的参与者/获胜者提供的披风。

# 描述
该披风只提供给关卡制作大赛与[Cobalt联盟](http://cobaltleague.net/)锦标赛中的参与者/获胜者。<ref></ref>
