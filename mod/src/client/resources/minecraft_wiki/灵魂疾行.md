# 灵魂疾行

*页面ID: 56257* | *来源: Minecraft Wiki*

* *灵魂疾行（Soul Speed）**是一种用于[靴子](靴子.md)的[魔咒](魔咒.md)，能提高玩家在[灵魂沙](灵魂沙.md)和[灵魂土](灵魂土.md)<ref group="注" name="soul_speed_blocks">该特性由[标签](Java版标签.md)控制。</ref>上的移动速度。

# 获取
灵魂疾行是不可[附魔](附魔（物品修饰）.md)的魔咒，且无法通过以下方式以外的任何方式获取，包括通常的宝藏型魔咒来源（如[钓鱼](钓鱼.md)或[交易](交易.md)）。

玩家可以通过和[猪灵](猪灵.md)进行[以物易物](以物易物.md)来获得具有灵魂疾行魔咒的[附魔书](附魔书.md)和[铁靴子](铁靴子.md)。

具有灵魂疾行的附魔书和[金靴子](金靴子.md)可以在[堡垒遗迹](堡垒遗迹.md)中找到。

# 用途
# = 加速 =
灵魂疾行会提高玩家在[灵魂沙](灵魂沙.md)和[灵魂土](灵魂土.md)<ref group="注" name="soul_speed_blocks" />上或}}行走的速度。

该魔咒生效时，玩家的增加{{cd|-{}-0.03 + 魔咒等级 &times; 0.0105}}，并扩大玩家视场角（FOV）。

该魔咒生效时，玩家的增加，这意味着灵魂沙的0.4速度乘数和灵魂土的1.0速度乘数均会被视为1.0速度乘数，即玩家在灵魂沙和灵魂土上行走的速度相同。

在灵魂沙或灵魂土上的[地毯](地毯.md)或上行走也可以获得灵魂疾行的效果。

# = 耐久 =
玩家在装备带有该魔咒的靴子时，每走过1个灵魂沙或灵魂土<ref group="注" name="soul_speed_blocks" />，其靴子都有4%的概率消耗耐久度。

各种靴子在满耐久且无其他耐久消耗因素影响的情况下可走过的灵魂沙及灵魂土数量的期望如下表所示：
