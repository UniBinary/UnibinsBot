* *马铠（Horse Armor）**是可以为[马](马.md)装备的盔甲物品。

# 获取
# = 箱子战利品 =

# = 合成 =

# = 锻造 =
下界合金马铠可通过在[锻造台](锻造台.md)中升级钻石马铠来获得，魔咒和自定义名称等物品数据会被保留。

# = 生物掉落 =
由玩家装备上马铠的马在死亡时总是会掉落一个对应的马铠。

# = 交易 =

# 用途
玩家可以为已驯服的马装备或变更马铠。玩家手持马铠时对没有装备马铠的马可为其装备马铠，也可以在马的交互界面中的马铠槽位（）放入或移除马铠。[绑定诅咒](绑定诅咒.md)魔咒不会影响玩家移除马铠。

马铠没有耐久度，因此可以无限地使用，不会因承受伤害而损毁。

只有马和[僵尸马](僵尸马.md)可以装备马铠。[驴](驴.md)、[骡](骡.md)、[骷髅马](骷髅马.md)和[羊驼](羊驼.md)不能装备马铠。

在无骑乘物时，对装备马铠的马或僵尸马[剪刀](剪刀.md)可以剪下所装备的马铠。

[物品实体](物品实体.md)形式的下界合金马铠会漂浮在[熔岩](熔岩.md)上，且不会被[火](火.md)和熔岩摧毁。

# = 提供护甲值 =

马铠在被装备时会提供。

# = 提供盔甲韧性 =

钻石马铠或下界合金马铠在被装备时会提供。

# = 提供击退抗性 =

下界合金质马铠在被装备时会提供击退抗性，即[属性](属性.md)<code>knockback_resistance</code>。

# = 抵抗细雪 =
装备了皮革马铠的马不会因接触[细雪](细雪.md)而被冰冻。

# = 僵尸马 =
装备了任意马铠的僵尸马不会在阳光下[着火](着火.md)。

# = 染色 =

皮革马铠可以被染成12,326,391种颜色。

手持染色的马铠对着装有水的[炼药锅](炼药锅.md)可以洗掉颜色。

# 你知道吗
* [创造模式](创造模式.md)下的玩家能使用[铁砧](铁砧.md)为马铠添加魔咒，但适用于[盔甲](盔甲.md)的魔咒不在马铠上生效。马铠只能通过物品栏编辑器获取魔咒，适用于盔甲的魔咒（除了[绑定诅咒](绑定诅咒.md)）会在马铠上生效。
