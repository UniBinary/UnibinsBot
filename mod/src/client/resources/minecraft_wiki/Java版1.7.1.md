# Java版1.7.1

*页面ID: 33435* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.7.1**是[Java版1.7.2](Java版1.7.2.md)的第2个，也是最后一个预发布版，发布于2013年10月23日<ref></ref>，此版本添加了先前版本中缺少的金合欢和深色橡木木板。

# 新内容
# = 方块 =
* *[木板](木板.md)**
* 加入了新的金合欢木板和深色橡木木板。

# 更改
# = 方块 =
* *[唱片机](唱片机.md)**
* 不再循环播放音乐。

# = 常规 =
* *[控制](控制.md)**
* 更改了的画面。[实体](实体.md)的[碰撞箱](碰撞箱.md)现在是完全透明并带有白色细轮廓的。

* *常规**
* 方块的碰撞箱现在是完全黑色而不是深灰色。

# 修复
命令召唤物品会引起空指针异常。

|31669|开启着色器后快捷栏中附魔物品会显示其背景。
