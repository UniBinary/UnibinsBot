# 旁观模式

*页面ID: 11655* | *来源: Minecraft Wiki*

[缩略图|使用旁观模式看到的世界](File:Player View.png.md)

[缩略图|使用旁观模式看到的世界](File:Spectator BE.png.md)

* *（Spectator）**模式是一种[游戏模式](游戏模式.md)，允许玩家以[飞行](飞行.md)的方式无障碍穿过方块和[实体](实体.md)并观察世界。

当一个世界被创建后，如果开启了“”选项，则可以通过命令、中的[游戏模式切换器](游戏模式切换器.md)、其他模式中按下切换或中的设置来切换到旁观模式。在[多人游戏](多人游戏.md)中，[管理员](管理员.md)可以通过命令单独切换每一名玩家的游戏模式。新玩家的默认游戏模式也能通过中的命令来切换。在[极限模式](极限模式.md)中死亡后也可以进入旁观模式。

# 用途
# = 飞行 =
旁观模式的玩家总是处于飞行状态，如果尝试降落在地上则会穿过方块。按住键的同时按下键可以让旁观模式的玩家飞行的速度更快，且[迅捷](迅捷.md)和[](缓慢.md)效果对他们无效。

飞行过程中滑动鼠标滚轮可以调整飞行速度。滚轮向上则加速，滚轮向下则减速（减到0为止）。

旁观模式的玩家的飞行速度可以达到每秒43.556方块，按下键后的速度可以达到每秒87.111方块。

# = 隐形 =
[thumb|旁观者视角中的旁观者](File:Translucent skull.png.md)

旁观模式的玩家可以相互看见呈半透明状的头颅，而非旁观模式的玩家不能看见处于旁观模式的玩家。

旁观模式的玩家不会被生物注意，也不会触发生物生成（包括[刷怪笼](刷怪笼.md)）和消失。

# = 穿墙 =
处于旁观模式的玩家可以穿过所有的[方块](方块.md)与[实体](实体.md)。当其头部进入固体方块时，可以对其他方块进行透视。

# = 查看隐形实体 =
旁观模式的玩家能看见隐形的实体（包括<code>Invisible</code>被设置为<code>true</code>的[盔甲架](盔甲架.md)，而[标记](标记.md)以及<code>view_range</code>被设置为<code>0b</code>的[展示实体](展示实体.md)除外）。

这些隐形的实体呈半透明状（就像在非旁观模式中查看设置了而隐形的队友一样）。

# = 高亮玩家 =

旁观模式的玩家在[按键绑定](控制#可设置的键位.md)菜单中“”选项设置好按键后（默认无绑定），按住时将所有[玩家](玩家.md)高亮显示，与[发光](发光.md)效果类似，松开按键时效果会立即消失。若玩家在[队伍](队伍.md)中，则其描边颜色与队伍指定的颜色保持相同。

# = GUI =

旁观模式的玩家打开[物品栏](物品栏.md)时，会显示自己的半透明头颅而不是自己的全身模型，同时也不能改变自己的物品栏（如拿起、移动或丢弃）。

旁观模式的玩家不能改变任何[容器](容器.md)内物品，却可以查看其内容：当玩家视角指向任何容器时，其屏幕中心会出现十字准星，此时可以按下键查看；当某些容器使用[战利品表](战利品表.md)却尚未生成战利品时，该玩家将无法查看此容器内容，其[动作栏](动作栏.md)上会显示一行红色文字：“”

# = 传送 =

旁观模式的玩家可以使用 - 或对应[快捷栏](快捷栏.md)的[键位](键位.md)来查看当前服务器上的非旁观玩家，多次按下即可传送过去。

# = 实体视角 =

旁观模式的玩家实体或使用命令时，该玩家的位置与视角会跟随此实体。在使用实体视角时再会显示此实体而不是玩家。按下回到飞行模式。

当被跟随的实体死亡时，旁观模式的玩家将自动脱离被跟随实体。

某些生物有独特的[着色器](着色器.md)。这些过滤器会改变旁观者的视觉效果。如果按下，它会移除着色器而不会退出实体视角。下表是一些拥有着色器的生物：

# = 其他 =
旁观模式的玩家仅会受到和命令的[伤害](伤害.md)。

玩家在处于骑乘生物或载具的状态下进入旁观模式时会自动从其上脱离。

[多人游戏](多人游戏.md)的[玩家列表](玩家列表.md)中，处于旁观模式的玩家名字会变为斜体并标灰。

当游戏规则禁用时，旁观模式下的玩家不会生成区块。

# 你知道吗
* 旁观模式中“传送到玩家”“传送到队伍成员”的物品栏图标是一个[末影之眼](末影之眼.md)加上一个2D的[Steve](Steve.md)头像，而“关闭菜单”的图标直接复制自[屏障](屏障.md)的图标。
* * 然而，在[纹理更新](纹理更新.md)和默认[皮肤](皮肤.md)的更新后，二者的图标均没有得到相应更新。<ref></ref>
* 如果玩家戴着一个[雕刻南瓜](雕刻南瓜.md)进入旁观模式，玩家会一直保持戴着南瓜的视角。
* 如果一个实体掉出世界，那么任何以其视角观看的旁观者都会因此而死亡，因为它们仍然是独立的实体，并且会受到虚空伤害。
* 在生物视角中死亡会使玩家重生时有着与生物相同的着色器视图。
* 被观察者使用[望远镜](望远镜.md)对旁观者同样有效，但是旁观者的视野中不会出现望远镜的遮罩。
* 尽管[监守者](监守者.md)被设定为没有视觉，但在旁观模式进入其视角可以发现其与普通视角完全相同。<ref></ref>
* 在[下界传送门](下界传送门.md)内切换为旁观模式后，仍会出现进入传送门时的视觉效果。
