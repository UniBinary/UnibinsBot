# Java版Alpha服务器0.1.2

*页面ID: 45473* | *来源: Minecraft Wiki*

* *0.1.2**是一个[Alpha](Java版Alpha.md)服务器版本，与[客户端Alpha v1.0.16_01](Java版Alpha v1.0.16 01.md)在2010年8月12日一起发布。<ref name="blogpost"></ref>

# 新内容
* 加入了对新的命令的支持：
* * 可移动玩家1至玩家2处。
* * 可强制将服务器保存至硬盘。
* * 可禁用自动保存。
* * 可启用自动保存。

# 重新上传
该版本于18:18（UTC）被重新上传，加入了对命令的支持。<ref name="blogpost"/>
