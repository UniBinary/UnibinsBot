# Java版Indev 0.31 20091223-0040/开发者版本

*页面ID: 56195* | *来源: Minecraft Wiki*

* *Java版Indev 0.31 20091223-0040**拥有几个被标记为**0.30**的未发布测试版本，它们由[Notch](Notch.md)展示在[他的博客上](The Word of Notch.md)。

这些版本与[Java版Classic 0.30](Java版Classic 0.30.md)不同，并展示了将在[Indev](Java版Indev.md)中加入的一些纹理。在Classic 0.30之后这些版本才被发布，并包含了Indev 0.31的新特性，因此这些版本实际上属于[Java版Indev 0.31 20091223-0040](Java版Indev 0.31 20091223-0040.md)的开发版本。<!-- 见英语Wiki的介绍 -->

# MD3生物模型测试（2009年12月8日）
[thumb|MD3生物模型测试](File:Indev 0.30 dev 1207.png.md)

# = 新内容 =
; [游戏模式](游戏模式.md)
* 现在游戏模式默认为[生存模式](生存模式.md)。

; 常规
* MD3玩家模型测试。
* 添加了多种生物，使用了来自游戏“Quake”的模型。

# 有限水测试（2009年12月19日）
* *[ Word of Notch博文]**

# = 更改 =
; [水](水.md)
* 现在水是有限的。
* * 只有当它下面一层是一个湖泊时，水才会往四周流动。
* * 后来因为漏洞被移除。
* 水现在拥有一个动态的侧面纹理。

# 光影测试（2009年12月19日）
[thumb|拉娜的一张截图](File:Indev 0.30 dev 1219.png.md)
* *[ Word of Notch博文]**、**[YouTube视频](https://www.youtube.com/watch?v=trIiFA23fOQ)**

# = 新内容 =
; [拉娜](拉娜.md)

# 动态光照测试（2009年12月19日）
* *[ Word of Notch博文]**

[缩略图](File:Indev 0.30 dev 1222.png.md)

# = 新内容 =
; [光照](光照.md)
* 加入了早期的动态光照。
* * 加入了更多的光照等级。
* * [方块](方块.md)还不能发光。
* * 由于漏洞，洞穴中的雾呈现出白色。

# 防穿墙机制测试（2009年12月19日）
* *[ Word of Notch博文]**

# = 新内容 =
; 常规
* 加入了防穿墙机制。
* * [服务器](服务器.md)将检查[玩家](玩家.md)是否能够穿过某个区域。
* * 由于延迟问题，如果一个玩家走过设法在这个玩家面前放置方块的另一个玩家，这个玩家有时会被传送回来。
