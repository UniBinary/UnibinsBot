# Java版25w19a

*页面ID: 151084* | *来源: Minecraft Wiki*

<onlyinclude>

* *25w19a**是[Java版1.21.6](Java版1.21.6.md)的第5个快照，发布于2025年5月6日<ref></ref>，修复了一些漏洞。

# 新内容
# = 生物 =
* *[快乐恶魂](快乐恶魂.md)**
* 加入了可选的字段，此值每刻不断减少，归0前快乐恶魂始终认为自己上方存在[玩家](玩家.md)。

* *[恼鬼](恼鬼.md)**
* 加入了可选的字段，存储生成恼鬼的AI生物的UUID。

# = 非生物实体 =
* *[被激活的TNT](被激活的TNT.md)**
* 加入了可选的字段，存储激活TNT的生物的UUID。

# = 游戏内容 =
* *[迷雾](迷雾.md)**
* 加入了2种迷雾类型：维度或Boss迷雾和大气迷雾。

# 更改
# = 方块 =
* *[失水恶魂](失水恶魂.md)**
* 移除了挖掘音效。

# = 生物 =
* *[快乐恶魂](快乐恶魂.md)**
* 现在其（<code>scale</code>）属性大于1.0时效果与等于1.0相同。
* 未装备[挽具](挽具.md)（可以是任意可装备到此快乐恶魂身体槽位的物品）时，骑乘它的玩家不再能控制其移动。

# = 非生物实体 =
* *[弹射物](弹射物.md)**
* 弹射物的目标差幅不再为固定的0.3格，而是会在弹射物生成后从0起每刻增加0.05格，直到达到原来的0.3格差幅。
* * 这提高了近距离使用弹射物的精准度。

# = 游戏内容 =
* *[迷雾](迷雾.md)**
* 改善了迷雾的氛围。
* 现在[降雨](降雨.md)和[雷暴](雷暴.md)天气会有更多的迷雾。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[配方书](配方书.md)**
* 将[床](床.md)和[地毯](地毯.md)的染色配方的配方种类由<code>building</code>更改为<code>misc</code>。
* 将[挽具](挽具.md)的合成与染色配方的配方种类由<code>misc</code>更改为<code>equipment</code>。

* *[资源包](资源包.md)**
* 将资源包版本号更改为。

* *[声音事件](Java版声音事件.md)**
* 移除了<code>block.dried_ghast.hit</code>声音事件。

* *游戏测试系统**
* 服务器重新启动后，测试框架将不再尝试重新启动此前运行的测试。

* *[客户端核心文件](客户端核心文件.md)**
* <code>--quickPlaySingleplayer</code>命令行参数现在可以不指定标识符，以启动上次游玩的世界。

* *[纹理](纹理.md)**
* [全景图](全景图.md)纹理现在必须为大小相同的正方形。
* 移除了状态效果图集，而文件夹中的精灵图现在移动到了GUI图集中，这意味着状态效果图标纹理现在是GUI纹理。

* *[着色器](着色器.md)与后处理效果**
* 对迷雾着色器进行了如下更改：
* * 迷雾现在分为环境迷雾和基于渲染距离的迷雾。
* ** 此前，这两种概念在同一个Uniform中混用。
* ** 环境迷雾用于形成玩家所处环境（比如水、熔岩、细雪，现在还有大气）的“朦胧感”，由球面距离影响其强度。
* ** 渲染距离迷雾用于模糊可见地形的边界，由圆柱距离影响其强度。
* ** 对于任何给定的顶点，得到的迷雾值是两种迷雾强度的最大值。
* <code>Fog</code>Uniform块
* * <code>FogStart</code>已被重命名为<code>FogRenderDistanceStart</code>，表示渲染距离迷雾的起始。
* * <code>FogEnd</code>已被重命名为<code>FogRenderDistanceEnd</code>，表示渲染距离迷雾的结束。
* * 加入了<code>FogEnvironmentalStart</code>，表示环境迷雾的起始。
* * 加入了<code>FogEnvironmentalEnd</code>，表示环境迷雾的结束。
* * 移除了<code>FogShape</code>。
