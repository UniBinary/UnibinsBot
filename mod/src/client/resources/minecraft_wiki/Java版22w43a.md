# Java版22w43a

*页面ID: 99445* | *来源: Minecraft Wiki*

<onlyinclude>

* *22w43a**是[Java版1.19.3](Java版1.19.3.md)的第2个快照，发布于2022年10月26日<ref></ref>，为聊天举报加入了草稿功能，对[创造模式物品栏](创造模式物品栏.md)做了进一步更改，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[聊天](聊天.md)**
* 加入了聊天举报草稿，可在玩家连接至服务器时临时保存举报内容。
* * 退出聊天举报屏幕时，举报内容可被丢弃，也可被保存为草稿。
* ** 聊天举报屏幕被强行关闭（如玩家死亡）时，举报内容总会被保存为草稿。
* * 会一直保留至玩家退出服务器或世界。
* ** 退出时会提示玩家是否丢弃，或是写完并发送举报内容。

* *[语言](语言.md)**
* 加入了纳瓦特尔语。
* 加入了卢森尼亚语。

# 更改
# = 方块 =
* *[栅栏门](栅栏门.md)**
* 其底面不再提供支撑中心点。
* * 例如，在此版本中悬挂式告示牌无法悬挂在栅栏门下方。

# = 游戏内容 =
* *[创造模式物品栏](创造模式物品栏.md)**
* 更改了创造模式物品栏部分类别的图标，以优化颜色编码，并使图标更具代表性。
* * ：铁斧→钻石镐
* * ：金剑→下界合金剑
* * 消耗品：胡萝卜→金苹果
* * 合成用品：下界合金锭→铁锭
* * 刷怪蛋：潜影贝刷怪蛋→猪刷怪蛋
* 自然方块类别的英文名由“Nature Blocks”改为“Natural Blocks”。
* 将泥土和石头移至自然方块类别的顶部。
* 将水瓶加入消耗品类别中（上个快照时水瓶未出现在任何类别中）。
* 重排了石英类方块，使平滑石英类方块独立出去。
* 自然方块类别中，可攀爬类植物方块现在被放在一起。
* 更改了类铜块的顺序。
* 更改了各种珊瑚块的顺序，以与珊瑚以及珊瑚扇的顺序保持一致。
* 自然方块类别中，下界岩被移到菌岩旁边。
* 重排了装备顺序，以使金质工具和武器按逻辑顺序排序。
* 将普通铁轨移至其他铁轨前面。
* 将染色方块（羊毛、陶瓦、蜡烛、旗帜、染色玻璃等）颜色渐变排序。
* 将告示牌移至功能方块类别中更靠上的位置。
* 建筑方块类别中，玄武岩类方块移至下界砖类方块后面，黑石旁边。
* 重排了自然方块类别中各植物的顺序。
* 向下列分类中加入了下列物品：
* * 红石方块：运输船、钟、大型垂滴叶、白色羊毛（置于幽匿感测体旁边）、线（置于绊线钩旁边）、红石矿石和雕纹书架
* * 消耗品：奶桶
* * 功能方块：灾厄旗帜、龙蛋、讲台、避雷针和音符盒
* * 合成用品：雪球
* * 刷怪蛋：刷怪笼
* * ：TNT和末地水晶
* * ：骨粉

# = 常规 =
* *[聊天](聊天.md)**
* 聊天举报屏幕现在会显示被举报的玩家重新进入服务器的时间。

* *协议**
* 现在会在不重新连接的情况下。
* 收到登录时，客户端现在会重置其聊天。

* *其他**
* 将游戏对线性代数类型的迁移至Java OpenGL Math Library（JOML）。

# 更改（实验性）
以下内容仅在创建世界时启用对应的内置数据包后才会出现。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 更改了骆驼刷怪蛋的颜色。

# = 生物 =
* *[骆驼](骆驼.md)**
* 调整了行走的循环动画。
