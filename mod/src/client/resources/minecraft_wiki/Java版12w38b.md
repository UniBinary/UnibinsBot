# Java版12w38b

*页面ID: 33081* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w38b**是[Java版1.4.2](Java版1.4.2.md)的第7个快照，发布于2012年9月21日<ref></ref>，修复了[12w38a](12w38a.md)里的漏洞和崩溃。

# 更改
# = 生物 =
* *[苦力怕](苦力怕.md)**
* 新的苦力怕爆炸机制。
* * 在一定高度坠落到玩家的位置时会爆炸。

* *[女巫](女巫.md)**
* 不能伤害自己了。
* 稍微更改了纹理。
* 新的[掉落物](掉落物.md)：
* * 药水材料
* * 木棍
* * 有概率掉落死时拿着的物品

# = 非生物实体 =
* *[矿车](矿车.md)**
* 加入了音效。

# = 世界生成 =
* *[洞穴](洞穴.md)**
* 加入了新的[洞穴音效](洞穴音效.md)。

# = 游戏内容 =
* *[伤害](伤害.md)**
* 加入了新的坠落伤害音效。

* *[经验](经验.md)**
* 更改了升级的音效。

* *[音效](音效.md)**
* 更新了音效引擎，并且修复了错误的音效。
* 将[12w38a](12w38a.md)的新的方块放置音效更改回原来的音效。

# 修复
* *修复了1个漏洞**
* 又可以正常工作了。</onlyinclude>
