* *疣猪兽（Hoglin）**是一种生成在[绯红森林](绯红森林.md)的敌对生物。

# 生成
疣猪兽自然生成于[绯红森林](绯红森林.md)生物群系，也生成于[堡垒遗迹](堡垒遗迹.md)的疣猪兽棚和桥中。每只疣猪兽有或的概率生成为幼年个体。

疣猪兽的生成不受亮度影响，且不会生成在[下界疣块](下界疣块.md)、[岩浆块](岩浆块.md)或[菌光体](菌光体.md)上。

即使在和平[难度](难度.md)中，疣猪兽也不会消失。

# 行为
在非和平[难度](难度.md)中，疣猪兽会攻击视线内的玩家。成年疣猪兽会像[铁傀儡](铁傀儡.md)一样将玩家抛向空中，，即便使用[盾牌](盾牌.md)格挡其攻击也依旧会被抛起一小段距离；幼年疣猪兽攻击力更低且无法抛起玩家，但攻击速度更快，被攻击后会在短时间内像多数友好生物一样逃跑。

成年疣猪兽在每次近战攻击后的2秒（40刻）内无法再次发动攻击。

与[劫掠兽](劫掠兽.md)类似，疣猪兽拥有极长的击退距离和很高的击退抗性。但自然生成在堡垒遗迹中的疣猪兽没有击退抗性。<ref></ref>

疣猪兽不会游泳，因此会在水中下沉且会溺水；不同于多数下界生物，疣猪兽不免疫[火焰伤害](伤害#火焰伤害.md)。

疣猪兽会远离水平[曼哈顿距离](曼哈顿距离.md)8格、垂直4格范围内的[诡异菌](诡异菌.md)、<ref></ref>、[下界传送门方块](下界传送门方块.md)和[重生锚](重生锚.md)。如果玩家站在上述方块旁，疣猪兽仍会尝试攻击玩家，但移动到上述范围内时即会掉头逃跑。

幼年疣猪兽会互相追逐嬉戏，也会和幼年猪灵玩耍，幼年猪灵还可能骑在幼年疣猪兽身上。

如果一只疣猪兽被攻击，附近的疣猪兽会对攻击者产生敌意</ref>|je}}。

幼年疣猪兽被攻击后不会进行反击，成年疣猪兽也不会援助幼年疣猪兽。但幼年疣猪兽反而会援助成年疣猪兽。

尽管疣猪兽的碰撞箱高度为1.4格，但疣猪兽无法在低于1.5625格的空间内自由移动。<ref></ref>

# = 繁殖 =

疣猪兽可以通过[绯红菌](绯红菌.md)来[繁殖](繁殖.md)，繁殖成功后会掉落。繁殖/后才能再次繁殖。

幼年疣猪兽需要20分钟成长为成年个体。使用绯红菌可以加快幼年疣猪兽的生长速度，每次喂食都将会减少幼年疣猪兽约10%的剩余生长时间。

对幼年疣猪兽[金蒲公英](金蒲公英.md)可以阻止其成长为成年疣猪兽，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年疣猪兽无法被喂食除金蒲公英外的其他物品。

疣猪兽是唯一一种可以繁殖的敌对生物。

# = 猪灵 =
当成年[猪灵](猪灵.md)攻击成年疣猪兽时，成年疣猪兽会反击。但如果在疣猪兽32格范围内成年猪灵的数量比成年疣猪兽多，它们会尝试避开猪灵。

在[堡垒遗迹](堡垒遗迹.md)疣猪兽棚中生成的疣猪兽不会攻击猪灵，反之亦然。

幼年疣猪兽会和幼年猪灵嬉戏玩耍，后者会骑到前者身上。如果幼年猪灵的数量多于幼年疣猪兽，未能骑上幼年疣猪兽的幼年猪灵会跟随一只已被骑乘的幼年疣猪兽，直到其身上的幼年猪灵停止骑乘，以便其他的幼年猪灵轮流骑上它。

# = 僵尸化 =
[缩略图|右|一头疣猪兽正转化为[[僵尸疣猪兽](File:Hoglin being Zombified.gif.md)]]
疣猪兽在[下界](下界.md)以外的维度中停留超过后会转化为[僵尸疣猪兽](僵尸疣猪兽.md)。转化成的僵尸疣猪兽会受到的效果，但反胃效果并不会影响其行为。

和平[难度](难度.md)下的疣猪兽在转化成僵尸疣猪兽的瞬间会被清除。

# 你知道吗
* 据[Henrik Kniberg](Henrik Kniberg.md)所述，疣猪兽会远离[诡异菌](诡异菌.md)是因为它们厌恶诡异菌的气味。<ref></ref>
* * 与其类似，当被问及疣猪兽是否也讨厌[下界传送门](下界传送门（方块）.md)的气味时，Henrik回复说疣猪兽会远离下界传送门是因为它们认为下界传送门的声音很恼人。<ref></ref>
* “Hoglin”这个名字是由社区选择的，疣猪兽一开始叫做“Piglin Beast”（猪灵兽）。
* * 与之相似的是，[劫掠兽](劫掠兽.md)的英文名称“Ravager”也是由社区选择的，它起初叫做“Illager Beast”（）。
[150px|缩略图|一群疣猪兽在跳舞](File:Hoglin dance.gif.md)
* Henrik Kniberg发布过一段关于疣猪兽玩笑特性的[视频](https://www.youtube.com/watch?v=8UeeF4lMPnk)。视频中一群疣猪兽击杀[猪灵](猪灵.md)之后摇晃着脑袋，随后用后脚站立跳起了舞，类似于猪灵的“胜利之舞”。
* 幼年疣猪兽身上的可能参考了现实中的欧亚野猪幼崽，其也有同样的条纹。
* 存在未使用的“疣猪兽肉”物品纹理<samp>hoglin_meat_raw.png</samp>和<samp>hoglin_meat_cooked.png</samp>，分别使用[生牛肉](生牛肉.md)和[牛排](牛排.md)的纹理作为占位符。
