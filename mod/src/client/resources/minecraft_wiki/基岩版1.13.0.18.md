# 基岩版1.13.0.18

*页面ID: 48553* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.13.0.18**是[基岩版1.13.0](基岩版1.13.0.md)的第11个测试版，发布于2019年10月2日<ref></ref>，修复了一些漏洞。

# 修复
* *修复了37个漏洞**<br>
* *崩溃/性能**
* 修复了安卓设备中获取存储权限时发生的崩溃。
* 修复了一些在游戏中发生的崩溃。
* 修复了在设置中的语言选项中滑动屏幕而导致的崩溃。（）
* 修复了安卓设备里使用角色创建器时的崩溃。（）

* *常规**
* “把我传走”成就无法完成。

* *游戏内容**
* 创造模式下玩家骑行实体后从空中坠落。（）
* 在不同的Xbox One中漫游世界时玩家生成在错误的位置。

* *生物**
* 僵尸不能生成在洞穴里。（）

* *物品**
* 地毯不会出现在羊驼的物品栏界面里。
* 弩会在弹射物装载完毕后立刻发射。（）
* 修复了在创造模式物品栏中丢弃受损物品的能力。（）
* 在快捷栏中的指南针和时钟的动画显示不正确。（）
* 创造模式下无法直接触摸屏幕来装备盔甲。（）
* 附有冰霜行者的靴子不能使水结冰。

* *图形**
* 箱子的破坏动画不能正确显示。
* 玩家潜行时头颅显示错误。（）
* 玩家游泳时手臂动画不正确。（）
* 穿戴生物头颅时现在能匹配玩家的-{}-头部大小。
* 工作台图标在特定的GUI标度修正下不能正常显示其顶部网格。
* 物品栏里的部分纹理丢失或损坏。（）
* 部分皮肤显示时带有白色披风。（）
* 盔甲无法兼容外层皮肤。
* 被破坏的方块留下阴影。

* *用户界面**
* 角色创建器的一些修复和加载时间优化。
* 外部服务器现在再次会显示在服务器界面。
* 修复了诸如漏斗和发射器的方块的状态改变后，首次尝试打开其物品栏界面失败的漏洞。
* 档案界面在分屏游戏再次能打开。
* 在全局资源菜单中，“阅读更多”按钮再次会显示在资源包旁边。

* *命令**
* 命令再次能够正确地命名实体（如果定义了名称）。

* *附加包和脚本引擎**
* 自定义生物的刷怪蛋在创造模式下不会出现。
* 由被缩放的生物所拿着的物品会再次会渲染为（与生物）同样的大小
*  1.2.0不再破坏组件。
* 修复了实体触发自定义动画功能。
* 在上使用资源会再次移除源实体。
* 当实体被骑乘时，组件会再次执行。
* 修复了末影龙在一些附加包中不会正常生成的漏洞。
* 资源包中存在的错误再次会在资源包清单验证界面中显示。</onlyinclude>
