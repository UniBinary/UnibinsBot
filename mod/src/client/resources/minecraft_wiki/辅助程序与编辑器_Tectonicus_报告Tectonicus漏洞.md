# 辅助程序与编辑器/Tectonicus/报告Tectonicus漏洞

*页面ID: 16251* | *来源: Minecraft Wiki*

若你在运行Tectonicus时遇到问题，或发现其漏洞，请阅读本页面，以便正确报告相关情况。

* *未按照本页步骤报告的漏洞或问题将被忽略。**

# 需检查的事项
报告问题前，请确保已完成以下检查：

* 你是否使用的是最新版本？（可查看[社区帖子](http://www.minecraftforum.net/viewtopic.php?f=25&t=95739)获取最新版本）
* 你是否已安装Java？（在命令行输入“java -version”查看安装情况）
* 你是否检查了文件路径？99%的错误都是由拼写错误、路径中存在空格却未用引号包裹路径等原因导致的

# 需报告的信息
提交漏洞报告或问题时，务必**完整**包含以下信息：

* 你的操作系统（如Windows XP）
* 你的Java版本（在命令行输入“java -version”查看）
* 你正在使用的Tectonicus版本
* Tectonicus运行文件夹中生成的完整日志文件TectonicusLog.txt
* 你使用的**准确**命令
* 你使用的**准确**配置文件
* 你尝试映射的Minecraft世界的**准确**位置
* 你执行的完整步骤

# 问题描述要求
描述问题时，需包含以下内容：

* 你想要进行的操作（例如创建洞穴映射器）
* 未按预期运行的情况（例如未生成任何图像、未生成HTML文件，或在浏览器中打开HTML文件时显示白屏等）

# 提交报告途径
请在[Tectonicus漏洞追踪器](https://github.com/tectonicus/tectonicus/issues)中报告漏洞及新功能需求。
