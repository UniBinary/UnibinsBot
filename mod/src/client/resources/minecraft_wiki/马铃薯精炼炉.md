* *马铃薯精炼炉（Potato Refinery）**是一种用于精炼[马铃薯油](马铃薯油.md)和润滑[物品](物品.md)的方块。

# 生成
马铃薯精炼炉不会生成在世界中。

# = 合成 =

# 破坏
没有工具可以加速对马铃薯精炼炉的挖掘。

马铃薯精炼炉被破坏后会掉落自身，但不包括其内容物。

# 用途
[thumb|right|马铃薯精炼炉的界面](file:Potato Refinery GUI.png.md)
马铃薯精炼炉的物品栏拥有4个槽位。左下方的槽位为“燃料槽”，用于放置燃料（最多1组），其余槽位在不同的使用场景下有着不同的用途。

# = 精炼 =

在燃料槽放入燃料，左上方的槽位放入精炼物，右上方的槽位放入[玻璃瓶](玻璃瓶.md)后，就会开始精炼过程。

每种燃料的燃烧时间与其在[烧炼](烧炼.md)过程中的燃烧时间相同。

仅有2种精炼配方：
* [马铃薯](马铃薯.md)可以精炼出[马铃薯油](马铃薯油.md)，获得，需要。
* [毒马铃薯](毒马铃薯.md)可以精炼出[毒马铃薯油](毒马铃薯油.md)，获得，需要。

# = 润滑 =
在燃料槽放入燃料，左上方的槽位放入马铃薯油，右上方的槽位放入任意物品，可以润滑该物品。放入毒马铃薯油不能润滑物品。

每个物品需要进行润滑。润滑后马铃薯油会被消耗，不会留下玻璃瓶。润滑物品不会使玩家获得经验。
* 润滑后的物品的润滑程度（LubricationFactor）不断趋近直到等于1.0。
* 润滑后的[物品实体](物品实体.md)可以在任意方块上滑行得更远。
* 润滑后的[靴子](靴子.md)类物品可以让将其穿在身上的玩家滑行。

# = 红石比较器 =
[红石比较器](红石比较器.md)可检测马铃薯精炼炉的内容物占空比，4个槽位都会被统计。

# = 光源 =
精炼中的马铃薯精炼炉会发出13级的光。

# = 上锁 =
马铃薯精炼炉可以被<code>Lock</code>标签上锁。如果马铃薯精炼炉的该标签不是空白的，那么这个马铃薯精炼炉必须使用名称与其相同的物品打开。
