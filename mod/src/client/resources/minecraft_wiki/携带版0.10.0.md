# 携带版0.10.0

*页面ID: 21065* | *来源: Minecraft Wiki*

* *v0.10.0 alpha**是的一次主要更新，发布于2014年11月18日。其加入了创造模式中的日夜循环、64位设备的支持和新的[栅栏](栅栏.md)种类，以及其他的更改与修复。

# 新内容
# = 方块 =
* *[栅栏](栅栏.md)和[栅栏门](栅栏门.md)**
* 云杉木
* 白桦木
* 丛林木
* 金合欢木
* 深色橡木

# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 加入了昼夜更替。

# = 常规 =
* *[设置](设置.md)**
* 加入了亮度调节选项。

* *性能**
* 适配64位软硬件，以使64位用户获得更流畅的体验。
* 支持iPhone 6和iPhone 6 Plus分辨率。

# 更改
# = 方块 =
* *[沙子](沙子.md)**
* 加入了粉尘粒子效果。

* *[红沙](红沙.md)**
* 加入了粉尘粒子效果。

* *[沙砾](沙砾.md)**
* 加入了粉尘粒子效果。

* *[金矿石](金矿石.md)**
* [金矿石](金矿石.md)可以在恶地生物群系的任意高度生成。

* *[箱子](箱子.md)和[告示牌](告示牌.md)**
* 为箱子和告示牌添加被选中时的层。

# = 生物 =
* *常规**
* 行走动画的速度加快同时针对每种动物做出了微调。
* 敌对生物现在成组地生成。
* 幼年动物现在会游泳了。

* *[史莱姆](史莱姆.md)**
* 史莱姆现在有了弹跳动画。

# = 游戏内容 =
* *[声音](声音.md)**
* 更改了部分音效，如下表所示（不包括旧的箭击中方块、抛掷物品、射箭、受伤、爆炸、挖掘和脚步的音效）：

# = 世界生成 =
* *[废弃矿井](废弃矿井.md)**
* 现在可以在[恶地](生物群系.md)生物群系的地表生成。

* *[巨型蘑菇](巨型蘑菇.md)**
* 巨型蘑菇现在生成于沼泽。

# = 常规 =
* *[设置](设置.md)**
* **图像**
* * 使用了[OpenGL ES](WZH:OpenGL ES.md) 2.0：
* ** 着色器
* ** 圆形的，与Java版色彩一致的雾。
* ** 水的纹理更亮更平滑。
* ** [太阳](太阳.md)现在略微变大。
* ** [云](云.md)和地形会在夜间呈现蓝色色泽。
* ** 水的平滑光照。
* ** 沼泽水颜色现在是深灰色。
* ** 云和地表结构会在日落时呈现红色色泽。
* ** 正在加载的远方区块现在有淡入效果。
* ** 来自Java版的有色光。
* ** 在支持OpenGL ES 3.0的Android设备上启用Mipmaps。

* *[多人游戏](多人游戏.md)**
* 缩小了聊天框。<ref></ref>
* 聊天信息的背景框会在信息末尾处结束，并且不会遮挡整个屏幕。
* 多人游戏中一天的时间现在同步得更精确。

* *[服务器](服务器.md)**
* 当尝试加入多人游戏世界/服务器的用时过久时会显示“Cancel”按钮。

* *[GUI](GUI.md)**
* 交互按钮现在是透明的了。

* *性能**
* 优化区块渲染。
* 改进了性能。

# 修复
* *修复了15个漏洞**<br>**0.10.0以往正式版的漏洞**
* 打开警告信息或不同的UI时游戏画面冻结（仅iOS）。<ref></ref>
* 渲染刷怪笼时游戏崩溃。
* 打开键盘时游戏崩溃或内存溢出（仅iOS）。
* 切换应用时游戏崩溃（仅Android）。
* 生物“生成在半空中”。
* 生成世界时放置熔岩导致游戏崩溃。
* 手持火把时的纹理错误。
* 云出现不寻常的洞。
* 矿车底部的棕色纹理错误。
* 多人游戏下的随机崩溃现象。
* 高亮显示大型箱子时游戏崩溃。
* 水不会推动实体。
* 徒手攻击实体时的错误伤害值。
* 鸡的纹理出现黑色的斑块。
* 牛的移动速度不正确。
