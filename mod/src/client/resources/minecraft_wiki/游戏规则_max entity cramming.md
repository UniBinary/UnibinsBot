# 游戏规则/max entity cramming

*页面ID: 127380* | *来源: Minecraft Wiki*

* *max_entity_cramming**是控制[生物](生物.md)受[挤压](挤压.md)需要推动的[实体](实体.md)数量的[游戏规则](游戏规则.md)。

# 行为
当max_entity_cramming大于0时：
* 如果生物正在推动的实体数量达到max_entity_cramming个，则其会开始受到来自挤压机制的[伤害](伤害.md)。
* 带有[渗浆](渗浆.md)效果的生物死亡时生成的[史莱姆](史莱姆.md)的数量不会使该位置的史莱姆数量达到max_entity_cramming个。

max_entity_cramming的值不能低于0。
