# 基岩版1.16.200.55

*页面ID: 72328* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.200.55**是[基岩版1.16.200](基岩版1.16.200.md)的第4个测试版，发布于2020年11月11日<ref></ref>，加入了过时显卡驱动的启动提示界面，以及修复了漏洞。

# 新内容
# = 常规 =
* *[菜单屏幕](菜单屏幕.md)**
* 加入了一个警告，提醒玩家正在使用过时的显卡驱动。

# 修复
* *常规**
* 修复了一个导致生物（如：掠夺者）试图躲避阳光的漏洞。
* 修复了一些移动设备上暂停并重开之后导致声音丢失的漏洞。（）
* 修复了一个导致垂直击退过于微弱的错误。
* 修复了启用光线追踪后飞行会导致世界卡顿和帧率下降的漏洞。（）

* *技术性**
* 一些使用先前坐标的旧命令版本现在会使用新的坐标。
* 修复了不再在上运作的漏洞。
* 禁用各向异性过滤（Mipmap）时将纹理图集的填充大小从0更改为1。
* 修复了组件里列出的方块不会正常运作的漏洞。

* *MoLang**
* 几何图形、材质和纹理变种名称现在会再一次包含点号。</onlyinclude>
