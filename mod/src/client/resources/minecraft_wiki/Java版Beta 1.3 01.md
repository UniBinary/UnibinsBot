# Java版Beta 1.3 01

*页面ID: 32762* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.3_01**是的一次次要更新，发布于2011年2月23日，修复了[Beta 1.3](Java版Beta 1.3.md)里的漏洞和崩溃。

# 更改
* 取消了对Java 1.6的。

# 修复
* *修复了3个漏洞**
* 修复了macOS平台上，点击“Singleplayer”按钮导致游戏崩溃的漏洞。
* 能够连接到Beta 1.3的服务器。
* 修复了物品重复的漏洞。</onlyinclude>
