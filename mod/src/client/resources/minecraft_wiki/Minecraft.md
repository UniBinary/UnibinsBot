* *Minecraft**是一款，[中国版](中国版.md)官方译为《我的世界》<ref></ref><ref>https://24h.pchome.com.tw/prod/DGBJLN-D900GETAT</ref>，又称《当个创世神》<ref>https://www.swanpanasia.com/products/minecraft-portal-dash</ref>或《麦块》<ref>https://www.youtube.com/watch?v=pAei6ZOk6hE</ref>，开创者为[马库斯·佩尔松](Markus Persson.md)（Notch）。游戏现由[Mojang Studios](Mojang Studios.md)维护，隶属于。

自开创伊始到[延斯·伯根斯坦](Jens Bergensten.md)（Jeb）加入并负责开发前，Minecraft的全部开发工作几乎都由Notch完成。游戏[音乐](音乐.md)由[丹尼尔·罗森费尔德](C418.md)、[莉娜·雷恩](Lena Raine.md)、[谷冈久美](谷冈久美.md)、[Aaron Cherof](Aaron Cherof.md)和[Amos Roddy](Amos Roddy.md)创作；[克里斯托弗·塞特斯特兰德](Kristoffer Zetterstrand.md)和[Sarah Boeving](Sarah Boeving.md)绘制了游戏中的[画](画.md)。游戏最初于2009年5月17日作为[Classic](Java版Classic.md)版本发布，2011年11月18日发布[正式版](正式版.md)。至今，Minecraft的游戏平台已涵盖[移动设备](基岩版.md)和[游戏主机](原主机版.md)。2014年11月6日，Minecraft及Mojang的全部资产被以25亿美元收购。<ref>https://mojang.com/2014/09/yes-were-being-bought-by-microsoft/</ref><ref></ref>Notch从此离开Mojang，不再为Minecraft工作。截至2025年4月，Minecraft的销量已突破3.5亿份。<ref>[Best-selling videogame](https://www.guinnessworldrecords.com/world-records/best-selling-video-game)</ref>

Minecraft着重于让[玩家](玩家.md)探索、交互并改变一个动态生成1[m³](wzh:立方米.md)大小[方块](方块.md)的[世界](世界.md)。除方块外，环境中还包括[动](生物.md)[植物](植物.md)与[物品](物品.md)。游戏内容包括采集[矿石](矿石.md)，与敌对[生物](生物.md)战斗，收集游戏中的各种资源来合成新的[方块](方块.md)与[工具](工具.md)。开放的[游戏模式](游戏模式.md)允许玩家在各类多人服务器或单人地图中创造建筑物与艺术作品。其他内容包括用于逻辑运算与远程控制的[红石电路](红石电路.md)、[矿车](矿车.md)及[铁轨](铁轨.md)，以及称之为“[下界](下界.md)”的神秘维度。最终，玩家可选择前往名为“[末地](末地.md)”的维度旅行，并击败[末影龙](末影龙.md)。

# 游戏内容
[300px|缩略图|Minecraft中的一个新世界](File:Survival.png.md)

# = 方块 =

Minecraft发生在[由立方体构成的三维网格](wzh:立方体堆砌.md)世界中，每个立方体由特定种类的方块占据（有些方块不一定是立方体形的）。方块种类繁多，类似[草](草.md)、[石头](石头.md)及各种[矿石](矿石.md)这样的自然方块在世界中随机生成。玩家也能自行[合成](合成.md)方块，例如[工作台](工作台.md)和[熔炉](熔炉.md)。资源可通过徒手或使用[工具](工具.md)从方块中获取。部分资源是可在玩家[物品栏](物品栏.md)中放置的简单方块，其余则用于合成其他方块或工具，还有些或许仅作装饰用途。有些方块无法通过正常的生存手段破坏，例如[基岩](基岩.md)、[末地传送门](末地传送门方块.md)、[命令方块](命令方块.md)和[屏障](屏障.md)。

# = 玩家 =

[100px|缩略图|[[玩家](File:Steve.png.md)的九种默认形象之一（Steve）]]
玩家是用户在世界中控制的人物。当用户开始新游戏时，玩家会被放入由随机或指定的[种子](种子（世界生成）.md)生成的世界中，[物品栏](物品栏.md)为空。玩家有10颗心的[生命条](生命条.md)，会受到跌落、窒息、溺水、[火](火.md)、[熔岩](熔岩.md)、[闪电](闪电.md)、[仙人掌](仙人掌.md)、掉入[虚空](虚空.md)、掉落的[铁砧](铁砧.md)以及被敌对[生物](生物.md)和其他玩家击中所产生的伤害。对生命的伤害可被[盔甲](盔甲.md)抵消，生命值可通过食用[食物](食物.md)或饮用特定[药水](药水.md)恢复；若将[难度](难度.md)设为和平，生命值会自动恢复。[饥饿值](饥饿值.md)是和平难度以外的一项指标，会随时间逐渐消耗，[疾跑](疾跑.md)时消耗会加剧。[食物](食物.md)可恢复饥饿值，食用部分食物也会对玩家产生额外的效果。饥饿值降到零时会消耗玩家的生命值，具体情况取决于[难度](难度.md)等级，困难难度下会导致[死亡](死亡.md)。

# = 采矿 =

[300px|缩略图|主世界中各种能被采集的矿石（靠近熔岩）](File:MultipleOreBlobs.png.md)

游戏名定为Minecraft，其中的“mine”指的就是采矿——这是游戏中的一项主要活动，即进入地表以下采集[矿石](矿石.md)及其他材料的过程。主世界的矿石包括[煤](煤矿石.md)、[铁](铁矿石.md)、[铜](铜矿石.md)、[金](金矿石.md)、[红石](红石矿石.md)、[青金石](青金石矿石.md)、[绿宝石](绿宝石矿石.md)和[钻石](钻石矿石.md)，开采这些矿石是制作各类物品的关键。采矿的方式可以是从地表[挖掘](挖掘.md)一个洞直通地下，也可以是沿着天然[洞穴](洞穴.md)往下走。游戏还会生成[废弃矿井](废弃矿井.md)等结构，为玩家提供寻找资源的额外区域。

# = 合成与烧炼 =

[缩略图|120px|一个[[工作台](File:Crafting Table.png.md)]]

合成是指玩家在[物品栏](物品栏.md)的2×2网格或[工作台](工作台.md)提供的3×3网格中，将自己[物品栏](物品栏.md)中已有的方块或物品合并、拆解或改造成新的[方块](方块.md)或[物品](物品.md)，以满足生存需求。每种可合成物品的配方各不相同，玩家可通过查阅配方书了解各类配方。随着游戏版本的不断更新，新的合成配方会持续增加。

烧炼是指使用燃料在[熔炉](熔炉.md)中将某些方块或物品加工成其他方块或物品。与合成类似，烧炼也有多种配方，同样可通过查阅配方书了解（例如将[粗铁](粗铁.md)冶炼为[铁锭](铁锭.md)）。此外，不同燃料的燃烧时长不同，[烟熏炉](烟熏炉.md)和[高炉](高炉.md)能提高某些方块或物品的烧炼效率，这就需要玩家选择合适的燃料和熔炉。

# = 酿造与附魔 =
[300px|缩略图|右|一些字符正在飘进一个[[附魔台](File:Enchantment Table animated experience.gif.md)]]

酿造指的是在[酿造台](酿造台.md)中使用各种原料和水制造[药水](药水.md)。酿造系统有着较为复杂的配方，根据原料的不同，酿造完成的药水效果也多种多样。它们储存在[玻璃瓶](玻璃瓶.md)中，玩家可以饮用，也能将其继续酿造成[喷溅](喷溅药水.md)或[滞留](滞留药水.md)形式，丢到其他[生物](生物.md)或玩家身上，产生不同效果。

附魔指的是在[附魔台](附魔台.md)上通过花费[经验](经验.md)和[青金石](青金石.md)，给[盔甲](盔甲.md)、[工具](工具.md)和[武器](武器.md)附上独特的“魔咒”，使其拥有特别的属性。更高级的魔咒可通过在周围放置[书架](书架.md)升级附魔台，或使用[铁砧](铁砧.md)将物品与[附魔书](附魔书.md)合并来获取。

# = 生物 =

[200px|缩略图|右|森林里的苦力怕，它们一旦靠近玩家就会爆炸](File:Creeper in forest.png.md)

生物（Mob，“mobiles”的缩写）是动物或其他居住在世界中的可移动[实体](实体.md)。根据它们对玩家是否有敌意，可分为友好生物和敌对生物。

[主世界](主世界.md)居住着许多动物，常见的包括、、、、、、、、、、、、、、、等，它们对玩家的生存有着不同的辅助作用。

主世界常见的怪物有、、、、、、、、等，它们各有独特的生成需求和攻击方式。

目前，Minecraft中只有两种NPC生物：和。前者生活在[村庄](村庄.md)中，后者会生成在玩家附近，玩家都能与它们[交易](交易.md)获取资源。Minecraft中只有两种Boss生物：和。前者仅生成于[末地](末地.md)的主岛，且可以由玩家复活；后者玩家可在任意[维度](维度.md)召唤。

其他[维度](维度.md)的生物详见下文的和章节。

# = 下界 =

[300px|缩略图|右|下界景观一隅](File:The Nether.png.md)

下界是Minecraft的一个维度，可从[主世界](主世界.md)通过[下界传送门](下界传送门.md)进入。下界有五大[生物群系](生物群系.md)：[下界荒地](下界荒地.md)、[绯红森林](绯红森林.md)、[诡异森林](诡异森林.md)、[灵魂沙峡谷](灵魂沙峡谷.md)和[玄武岩三角洲](玄武岩三角洲.md)，每个生物群系各有不同的景观与生物。

下界充斥着大片[熔岩海](熔岩海.md)，栖息着、、、、、、、等危险怪物，也有这类虽有敌意但可进行[以物易物](以物易物.md)的生物，以及能作为穿越熔岩海载具的友好生物。

下界还可开采到[下界石英矿石](下界石英矿石.md)、[下界金矿石](下界金矿石.md)、[荧石](荧石.md)，以及能用来制成强大[下界合金](下界合金.md)制品的珍贵[远古残骸](远古残骸.md)。

# = 末地 =

[缩略图|300px|末地主岛](File:The End.png.md)

末路之地，通称末地，是Minecraft的“最终维度”，可通过[要塞](要塞.md)中的[末地传送门](末地传送门.md)抵达。它悬浮于虚空中，由[末地石](末地石.md)构成的一座主岛及环绕其外的无数外岛组成。这里的生物有Boss生物、数量众多且随处可见的，以及方块状的。

主岛上矗立着[黑曜石柱](黑曜石柱.md)，柱上有[末地水晶](末地水晶.md)，是与[末影龙](末影龙.md)战斗的场所。战斗胜利后，可通过[末地折跃门](末地折跃门.md)前往外岛。外岛生长着大量[紫颂树](紫颂树.md)，还会罕见生成[末地城](末地城.md)，城内有[潜影贝](潜影贝.md)守卫，藏有丰厚战利品。末地城旁可能出现的[末地船](末地船.md)中，还有极为稀有的战利品——[鞘翅](鞘翅.md)。

# = 多人游戏 =

[300px|缩略图|右|多人游戏服务器中的PvP](File:PlayerVersusPlayer.png.md)
Minecraft本身支持多人游戏。在多人游戏中，不同玩家得以在同一个世界中相互交流互动。玩家可以互相协作进行建设、采矿和战斗（或[互相对抗](PvP.md)）等。

# == Minecraft Realms ==

* *Minecraft Realms**是官方的、基于订阅的[服务器](服务器.md)托管服务，供玩家创建和管理自己的私有Minecraft服务器。由[Mojang Studios](Mojang Studios.md)托管的Realms提供了简单快捷的服务器创建方式，允许所有者（服主）从游戏内直接管理，无需具备互联网服务器搭建知识。不过，Realms并非为大型公开服务器设计，更适合一群玩友或家庭使用。<ref></ref>私有Realms服务器设置简便，且只要服主持续付费，就能全天候提供服务。

# = 基岩版 =

[300px|缩略图|右|[[Notch](File:Pocket.jpg.md)和携带版Minecraft]]
[300px|缩略图|右|Minecraft的销售数据，截至2015年12月](File:Minecraft Sales Data.png.md)

基岩版（亦称作基岩平台、基岩代码库或基岩引擎），是由[Mojang Studios](Mojang Studios.md)、[Xbox Game Studios](Xbox Game Studios.md)、[4J Studios](4J Studios.md)和[SkyBox Labs](SkyBox Labs.md)联合开发的多平台版本的Minecraft。由于其游戏引擎源自携带版，所以在此版本之前，该作品系列在提及时常使用“携带版”“MCPE”或“携带版/Windows 10版”等名称。

所有基岩版的标题均为**Minecraft**，没有副标题。在[独乐不如众乐更新](独乐不如众乐更新.md)之前，每个平台上的版本都有不同副标题，包括[携带版](携带版.md)（所有移动平台）、[Windows 10版](Windows 10版.md)、[Xbox One版](Xbox One版.md)、[Nintendo Switch版](Nintendo Switch版.md)、[Gear VR版](Gear VR版.md)和[Fire TV版](Fire TV版.md)。

基岩版于2011年8月16日在Google Play<ref>https://play.google.com/details?id=com.mojang.minecraftpe</ref>上初始发布，为[Xperia PLAY](wzh:Sony Ericsson Xperia Play.md)独占，售价6.99美元；随后在2011年10月7日向其他[Android](wzh:Android.md)设备发布<ref></ref>，2011年11月17日向[iOS](wzh:iOS.md)设备发布<ref>http://appleinformer.org/2011/11/minecraft-pocket-edition-for-ios-now-available-for-download/</ref>。2012年9月13日，携带版在Amazon Appstore上线销售。[Windows Phone](wzh:Windows Phone.md)版于2014年12月10日以[携带版1.0.0](携带版1.0.0.md)在Windows商店发布<ref>http://www.windowscentral.com/minecraft-pocket-edition-comes-windows-phone</ref>，后续更新版本仅适用于Windows 10 Mobile。之后，携带版又扩展到4个平台：2015年7月29日发布至[Windows 10](Windows 10版.md)，2016年4月27日发布至[三星Gear VR](Gear VR版.md)，2016年12月19日发布至[Apple TV](Apple TV版.md)和[亚马逊Fire TV](Fire TV版.md)。<ref>https://mojang.com/2015/07/announcing-minecraft-windows-10-edition-beta/</ref><ref>https://www3.oculus.com/en-us/blog/minecraft-now-available-on-oculus-for-gear-vr/</ref><ref>https://minecraft.net/article/apple-tv-edition-released</ref><ref>https://www.amazon.com/gp/product/B01NCJDPER/</ref>2018年9月24日，[Apple TV版](Apple TV版.md)终止更新。

# = Java版 =

Minecraft的原始版本，可在Windows、macOS和Linux上运行，必须通过[启动器](启动器.md)启动。游戏最初于2009年5月16日以“早期个人单机alpha”之名发布，之后经历了多个开发阶段（Classic、Indev、Infdev、Alpha、Beta），最终于2011年11月18日发布正式版。自正式版推出后，Java版已进行过多次重大更新。

# = 原主机版 =

原主机版是适用于游戏机的Minecraft，原先由开发者[4J Studios](4J Studios.md)持续更新。

原主机版最初于2012年5月9日在[Xbox 360](Xbox 360版.md)上发布。该版本由Mojang在2011年6月7日的E3游戏展上宣布，发行日期则在次年3月22日由PlayXBLA的推特账户公布。2013年12月17日，其在[PlayStation 3](PlayStation 3版.md)上的版本发布，该版本于2013年8月20日宣布。之后，游戏陆续为[Xbox One](Xbox One版.md)、[PlayStation 4](PlayStation 4版.md)、[PlayStation Vita](PlayStation Vita版.md)、[Wii U](Wii U版.md)以及[Nintendo Switch](Nintendo Switch版.md)推出了适配版本。2019年12月10日，原主机版的所有子版本终止更新。

# = New Nintendo 3DS版 =


New Nintendo 3DS版于2017年9月13日发布，是由[Other Ocean Interactive](Other Ocean Interactive.md)开发的特殊移植版本。该版本可在Nintendo eShop获取，但仅适用于New 3DS和New 2DS设备。其多人游戏模式仅限本地游玩。2019年1月15日，此版本终止更新。

# = 教育版 =

教育版是专为课堂使用设计、具有教育作用的Minecraft版本。它由Mojang Studios和Xbox工作室联合开发，包含便于在教室环境中使用的功能。该版本的完整应用于2016年11月1日正式发布。

# = 其他版本 =
除以上所述之外，Minecraft还有许多其他版本。*[Minecraft 4k](Minecraft 4k.md)*是一个简易版本的Minecraft，由Notch参照其他“4k” Java游戏的样式，为参加竞赛而制作。树莓派版移植自[携带版](携带版.md)的[0.5.0版本](携带版版本记录#0.5.0.md)，适配于平台。<ref>http://www.mojang.com/2012/11/minecraft-is-coming-to-the-raspberry-pi/</ref>其旨在为新手程序员提供教学工具，允许用户修改游戏代码，且支持多种编程语言，2016年1月终止支持。

# 游戏个性化
# = 附加包 =

附加包是为的Minecraft带来自定义内容的首次尝试，且受官方支持。它允许玩家更改世界样式、[生物](生物.md)行为和[生物群系](生物群系.md)等。

# = 数据包 =

数据包适用于，为玩家更深层次自定义Minecraft体验提供官方支持。无需任何代码更改，即可用其覆盖或添加新的[进度](进度.md)、[函数](Java版函数.md)、[战利品表](战利品表.md)、[维度](维度.md)、[世界生成机制](自定义世界生成.md)、[结构](结构.md)、[配方](配方.md)和[标签](Java版标签.md)。

# = 资源包 =

资源包可更改游戏内大多数的[纹理](纹理.md)、[声音](声音.md)、文字和部分[模型](模型.md)，受官方支持。它必须包含特定的文件和文件夹结构，储存在<samp>.zip</samp>压缩文件、或文件夹中，放置在Java版的<code>.minecraft/resourcepacks</code>或基岩版的<code>com.mojang/resource_packs</code>目录下，可在[选项](选项.md)中查看或启用。其对游戏的改变程度主要取决于包含的文件数量。

# = 皮肤 =

皮肤是覆盖在玩家模型上的纹理。

皮肤文件分为多个区域，对应角色表面的不同部位（如头的前部、左脚等）。皮肤仅允许使用纯色；皮肤文件中不允许有透明区域，除非该区域在第二层（默认透明）；离线游戏时，像素若被忽略，会使皮肤出现“洞”。第二层可用于为角色添加眼镜、帽子等配件（甚至更大的头）。

玩家还能通过[角色创建器](角色创建器.md)直接修改游戏中角色的体型、着装等。

# = 非官方Mod =

可通过添加或替换Java类文件修改Java版中的[client.jar](client.jar.md)。这种制作mod的方法不受Mojang Studios支持，可能因mod过期、有缺陷或与其他mod冲突而损坏游戏。部分mod作者给[Notch](Notch.md)、[Jeb](Jeb.md)等主导开发者留下深刻印象，其作品被纳入官方更新：Hippoplatimus制作的[活塞](活塞.md)mod和Dr. Zhark制作的“更多生物”（Mo' Creatures）mod，分别加入[Java版Beta 1.7](Java版Beta 1.7.md)和[Java版1.6.1](Java版1.6.1.md)中。<ref>http://www.peripheralarbor.com/minecraft/minecraftscriptphotojournal.html</ref><ref></ref><ref></ref><ref></ref>

# = 第三方程序 =

有许多专为Minecraft打造的程序，包括3D地图编辑器与浏览器、游戏修改器、各类信息程序、服务器包装程序及其他专业程序。和mod一样，这些程序也不受Mojang Studios支持。

# 衍生游戏
# = Minecraft Dungeons =

Minecraft Dungeons（Minecraft：地下城）是一款动作/冒险角色扮演类电子游戏，由[Mojang Studios](Mojang Studios.md)、[Xbox Game Studios](Xbox Game Studios.md)和[Double Eleven](Double Eleven.md)联合开发，于2020年5月26日正式发售，至今已推出6个DLC。

# = Minecraft Legends =

Minecraft Legends（Minecraft：传奇）是由[Mojang Studios](Mojang Studios.md)、[Xbox Game Studios](Xbox Game Studios.md)与[wikipedia:Blackbird Interactive](wikipedia:Blackbird Interactive.md)合作开发的[即时动作战略游戏](wzh:即时战略游戏.md)。

# = Minecraft: Story Mode =

* Minecraft: Story Mode*（Minecraft：故事模式）是一款基于沙盒游戏Minecraft的点击式叙事冒险。2015年10月多平台发布，同年12月16日推出Windows 10版，2016年1月21日发布[Wii U版](Wii U版.md)。由[Telltale Games](Telltale Games.md)与[Mojang Studios](Mojang Studios.md)联合开发，音乐由美国加利福尼亚州的民间氛围风格乐队Anadel创作。游戏延续Telltale既往作品的章节连载形式，玩家的选择和行动对后续剧情有重要影响。2019年6月25日，因Telltale Games关闭，该游戏停止运营。

# = Minecraft: Story Mode第二季 =

* Minecraft: Story Mode - Season Two*（Minecraft：故事模式第二季）是[Telltale Games](Telltale Games.md)与[Mojang Studios](Mojang Studios.md)合作开发的*Minecraft: Story Mode*续作，2017年7月多平台发布，同前作一样分为5个章节。2019年6月25日，因Telltale Games关闭停止运营。

# = Minecraft Earth =

Minecraft Earth是一款免费增强现实（AR）移动游戏，支持iOS（iOS 13及以上）、iPadOS和Android（8.0及以上）设备，且需支持ARKit和ARCore，同时需要连接Wi-Fi网络。2021年6月30日，该游戏停止运营。<ref>|January 4, 2021}}</ref>
