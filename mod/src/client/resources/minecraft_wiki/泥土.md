# 泥土

*页面ID: 463* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *泥土（Dirt）**是一种在[主世界](主世界.md)中大量生成的软质[方块](方块.md)。

# 生成
# = 自然生成 =
泥土占据了大多数主世界[生物群系](生物群系.md)的地表。此外，泥土也能以[团簇](团簇.md)方式生成在任何生物群系的地下且Y高度为0~160处，每区块尝试生成7次，团簇大小为1-33个方块。

泥土也会生成在[村庄](村庄.md)的一些房屋和[废弃矿井](废弃矿井.md)中。

泥土也会生成在[林地府邸](林地府邸.md)的一些房间中。

泥土也会生成在[远古城市](远古城市.md)中心的隐藏房间。

泥土也会作为[古迹废墟](古迹废墟.md)的一部分生成，随机替换掉结构中原有的[沙砾](沙砾.md)。

泥土可能会在[试炼密室](试炼密室.md)的“入口”结构中作为植物造景的一部分生成。

# = 土类方块 =
当[生物](生物.md)在[耕地](耕地.md)上跳跃，耕地上方有[固体方块](固体方块.md)，或耕地上没有种[农作物](农作物.md)且其水平[切比雪夫距离](切比雪夫距离.md)4格范围内没有[水](水.md)时，耕地会退化成泥土。

[砂土](砂土.md)能被[锄](锄.md)耕成泥土。

[缠根泥土](缠根泥土.md)能被[锄](锄.md)耕成泥土，并掉落一个[垂根](垂根.md)。

若[草方块](草方块.md)或[菌丝体](菌丝体.md)直接被液体源方块或下表面[遮挡形状](遮挡形状.md)完整的方块覆盖（一层高的[雪](雪.md)除外），草方块或菌丝体将会在随机时间后变为泥土。

# = 树木 =
除[大型云杉](大型云杉.md)、[杜鹃树](杜鹃树.md)、[红树](红树.md)外的[树木](树木.md)地物生成时，树木下方的方块会被替换为泥土；[砂土](砂土.md)、[苍白苔藓块](苍白苔藓块.md)、不会被替换。

# 获取
和[耕地](耕地.md)被破坏后总会掉落1个泥土。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)和被破坏后会掉落1个泥土。

# = 末影人 =
手中搬着泥土的[末影人](末影人.md)会在死亡时掉落泥土。

# 破坏
挖掘泥土的合适工具是锹。

泥土被破坏后会掉落自身。

# 用途
[末影人](末影人.md)可以搬起及放下泥土。关闭[游戏规则](游戏规则.md)将阻止该行为。

# = 种植 =
[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)、[蕨](蕨.md)、[大型蕨](大型蕨.md)、[花](花.md)、[粉红色花簇](粉红色花簇.md)、[野花簇](野花簇.md)、[灌木丛](灌木丛.md)、[枯萎的灌木](枯萎的灌木.md)、[大型垂滴叶](大型垂滴叶.md)、[下界菌](下界菌.md)、[绯红菌](绯红菌.md)、[诡异菌](诡异菌.md)、[下界苗](下界苗.md)、[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)都能被放置在泥土上。[树苗](树苗.md)、[竹子](竹子.md)和[甜浆果丛](甜浆果丛.md)能在泥土上生长。[甘蔗](甘蔗.md)和[蘑菇](蘑菇.md)也会在符合条件的情况下在泥土上生长。

# = 转变 =
对着泥土[锄](锄.md)可将其转变为[耕地](耕地.md)，并使锄消耗掉1点耐久。

对着泥土[锹](锹.md)可将其转变为[土径](土径.md)，并使锹消耗掉1点耐久。

对着[苔藓块](苔藓块.md)或[苍白苔藓块](苍白苔藓块.md)[骨粉](骨粉.md)可以使其3×3至7×7格范围内上方为空气的泥土转变成苔藓块或苍白苔藓块。

[大型云杉](大型云杉.md)长成后会将其下方及周围的泥土转变为[灰化土](灰化土.md)。

[杜鹃树](杜鹃树.md)长成后会将其下方的泥土转变为[缠根泥土](缠根泥土.md)。

对着泥土[水瓶](水瓶.md)或发射器发射水瓶会将泥土转化为[泥巴](泥巴.md)。
