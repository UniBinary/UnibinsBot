# Java版25w43a

*页面ID: 169131* | *来源: Minecraft Wiki*

<onlyinclude>

* *25w43a**是[Java版1.21.11](Java版1.21.11.md)的第3个快照，发布于2025年10月21日<ref></ref>，修复了一些漏洞。

# 新内容
# = 生物 =
* *[鹦鹉螺](鹦鹉螺.md)和[僵尸鹦鹉螺](僵尸鹦鹉螺.md)**
* 加入了在水中装备鞍的音效：<code>item.underwater_saddle.equip</code>。

# = 常规 =
* *[物品修饰器](物品修饰器.md)**
* 加入了物品修饰器<code>discard</code>。
* * 将物品堆叠替换为空堆叠，无额外字段。

* *[魔咒定义格式](魔咒定义格式.md)**
* 加入了魔咒效果<code>apply_exhaustion</code>，用于对目标实体赋予额外的[消耗度](消耗度.md)。格式如下：
* * <code>amount</code>：要套用的消耗度的等级依赖函数，仅对玩家有实际作用。

# 更改
# = 物品 =
* *[矛](矛.md)**
* 增加了玩家和生物进行冲锋攻击造成的伤害。
* 略微增大了模型。
* 现在进行冲锋攻击击中目标时会有视觉反馈。
* 现在增加攻击伤害的[属性修饰符](属性修饰符.md)只应用于主手而非双手。

# = 生物 =
* *[鹦鹉螺](鹦鹉螺.md)和[僵尸鹦鹉螺](僵尸鹦鹉螺.md)**
* 现在不再能上船。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 现在[突进](突进.md)魔咒不再额外消耗矛的耐久度，而是像疾跑和跳跃那样消耗玩家的[饱和度](饱和度.md)和饥饿值。
* * I级消耗，II级消耗，III级消耗。
* * 现在只有玩家有大于的饥饿值时，突进魔咒才会发挥作用。

* *[世界边界](世界边界.md)**
* 现在世界边界插值取决于游戏刻而不是现实时间。
* * 因此，游戏暂停时世界边界不再会移动。
* * 这也意味着世界边界插值也会被影响。

# = 命令格式 =
* ***
* <code>time</code>参数现在以刻而不是秒-{}-表示。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[资源包](资源包.md)**
* 将资源包版本号更改为。

* *[物品修饰器](物品修饰器.md)**
* <code>filtered</code>：
* * 将<code>modifier</code>替换下以下两个字段：
* ** <code>on_pass</code>：当<code>item_filter</code>测试成功时应用的战利品表函数或其。
* ** <code>on_fail</code>：当<code>item_filter</code>测试失败时应用的战利品表函数或其。

* *[纹理](纹理.md)**
* 移除了纹理元数据属性，由取代。新字段是一个枚举值，可用值如下：
* * <code>mean</code>：计算当前MipMap等级下颜色和透明度的平均值，每四个像素为一组，以生成下一等级的MipMap像素。这曾经是并将继续是绝大多数固体或半透明完整方块的方法。
* * <code>dark_cutout</code>：与<code>mean</code>相似，但混合颜色的方式会使cutout像素变暗。这曾经是并将继续是红树根和沾泥的红树根的方法，来模拟较黑暗的方块内部。
* * <code>cutout</code>：新方法，基于原始纹理而不是上一MipMap等级的纹理生成MipMap纹理。在此版本中用于绝大多数cutout方块。
* * <code>strict_cutout</code>：<code>cutout</code>的变种，使用更严格的透明通道截止值，会导致使用此值的纹理在高MipMap等级时不可见。它被用于花等方块来避免伪影。
* * <code>auto</code>：默认值，使游戏选择不包含完全透明像素的所有像素的平均值，并对其余像素进行<code>cutout</code>处理。
* 现在方块的动态纹理再次在所有MipMap等级下动态显示。
* 信标和红石粉现在支持透明纹理。

* *[LWJGL](https://www.lwjgl.org/)**
* 将LWJGL从版本3.3.3更新到了3.3.6。
