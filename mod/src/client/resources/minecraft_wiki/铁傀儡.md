* *铁傀儡（Iron Golem）**是一种高大且强壮的友好生物，用于保护[玩家](玩家.md)和[村民](村民.md)。

# 生成
铁傀儡会随村庄一同生成于村庄会合点处。

# = 村民 =

# == Java版 ==
村民生成铁傀儡的过程与其职业和上次工作的时间无关，如果村民在前内睡过觉且在前内没有观察到铁傀儡，则该村民产生生成铁傀儡的意愿。村民每过就会观察一次周围是否存在铁傀儡。如果存在铁傀儡的[边界箱](边界箱.md)与该村民边界箱各个方向膨胀16格形成的包围盒相交，即视为观察到周围存在铁傀儡。

村民每内最多传播一次言论，若该村民有生成铁傀儡的意愿，且还存在另外4个边界箱与该村民边界箱各个方向膨胀10格的包围盒相交的有意愿的村民（合计5名村民为一组单位），在言论传播时铁傀儡就会尝试生成。铁傀儡生成后，该村民及其周围10格内的所有其他村民会进入的冷却时间，在冷却时间内它们也会继续观察周围是否存在铁傀儡。

如果村民受伤或处在惊慌状态下，且在20分钟内有过一次睡觉，也会每尝试生成1次铁傀儡，这种情况下只需要3名有意愿的村民而非5名为一组单位。这种生成方式一样会受到16格范围内的铁傀儡侦测和冷却的限制。

当村民尝试生成1个铁傀儡时，系统最多会尝试10次，在以该村民为中心的17×13×17格范围内（村民所在方块坐标的水平方向±8格，竖直方向±6格范围内）生成1个铁傀儡。每次尝试生成铁傀儡时，系统会在这个范围内随机选择一个高13格的1×1柱状区域，然后从这个柱状区域的最顶部开始向下查找，直到找到一个合适位置，若无法找到合适位置则这次尝试失败。即：若多个合适位置的X坐标和Z坐标相同，铁傀儡只会生成在最高的那个，低处的合适位置无法生成铁傀儡。

铁傀儡的合适位置需符合以下条件：
* 该处需为空气或液体
* 该处下方的方块必须是[固体方块](固体方块.md)或[细雪](细雪.md)
* 该处下方不能是下列方块：
* * [冰](冰.md)
* * [浮冰](浮冰.md)
* * [玻璃](玻璃.md)（含染色与[遮光](遮光玻璃.md)变种）
* * [玻璃板](玻璃板.md)（含染色变种）
* * [树叶](树叶.md)
* * [仙人掌](仙人掌.md)
* * [TNT](TNT.md)
* * [蜘蛛网](蜘蛛网.md)
* * [信标](信标.md)
* * [荧石](荧石.md)
* * [海晶灯](海晶灯.md)
* * [潮涌核心](潮涌核心.md)

选定合适位置后，若该位置下方为[可生成方块](生成#可生成位置.md)，且生成的铁傀儡不会和任何其他实体和方块的碰撞箱碰撞，则铁傀儡会被生成在此处；否则，此次尝试失败。

# == 基岩版 ==
铁傀儡的生成具有以下条件：
* 村庄中至少存在20张床和10个村民。
* 每多10个村民，村庄可存在的铁傀儡上限加1，但不影响铁傀儡生成速度。
* 村庄中75%的村民必须在过去的一天里工作过。
* [村庄](村庄.md)内的所有村民都必须与[床](床.md)绑定，且村民的数量少于或等于床的数量。如果村民数量多于床，则铁傀儡不会生成。

满足条件后每[刻](刻.md)都有的概率尝试生成（平均每35秒1次）。铁傀儡生成在围绕由床、钟或其他工作方块构建的村庄范围的中心的17×13×17范围内的最高可生成位置。生成点上方2×3×2的空间上（即铁傀儡所在生成方块的西北角处水平居中点）需满足碰撞箱检测，当碰撞箱不足以生成铁傀儡时生成失败。

铁傀儡生成点必须为除楼梯以外上表面西北角完整的方块（如炼药锅、堆肥桶），所在生成方块的上方一格必须全部为[真空气方块](生成#空气检测.md)（即空气、流体）才能生成。

# = 建造 =
|一种可生成铁傀儡的结构图示}}
|另一种结构}}

将4个[铁块](铁块.md)摆放成T形（如图所示），然后将[雕刻南瓜](雕刻南瓜.md)或[南瓜灯](南瓜灯.md)放置在T字的正上方，即可生成一个铁傀儡。由玩家建造的铁傀儡永远不会攻击玩家。

雕刻南瓜或南瓜灯必须最后放置。雕刻南瓜可以被[末影人](末影人.md)和[发射器](发射器.md)放置。南瓜灯也能被发射器放置。放置[南瓜](南瓜.md)不能生成铁傀儡，但用[剪刀](剪刀.md)修剪后可以生成。

这个结构可以直立、躺下或颠倒放置。图中的4个空位置（即“双臂”的上方和下方）必须是空气方块。

和其他构建而成的生物一样，铁傀儡在生成时总是朝南。它们较大的尺寸可能会导致头部被其他固体方块阻挡并受到窒息伤害。

# == 更新区域 ==
[thumb|一些铁傀儡结构的更新区域（视角向南）](File:Iron_Golem_creation_update_area.png.md)

当已存在一个完整的铁傀儡结构但没有生成铁傀儡时（由于方块放置顺序或先前有多余方块干扰），玩家能在特定区域再放置一个雕刻南瓜或南瓜灯来“更新”结构生成铁傀儡。

更新区域的具体范围为：以铁傀儡结构的头部一行方块为起点，向X轴负方向（西）、Z轴负方向（北）以及向下各扩展2格。除开结构本身所需的空气方块。

若发射器周围有完整的铁傀儡结构，或是仅缺失头部的铁傀儡结构（头部位置为空气或其他方块，其余位置满足要求），且发射器面对的位置在更新区域内（也包括结构本身空气方块的位置），发射器就能将雕刻南瓜放置在面前，即使这样做可能无法生成铁傀儡。

# 行为
铁傀儡会在[村庄](村庄.md)周围缓慢地徘徊来进行巡逻，会一直贴着建筑物以及其他结构的边缘。与村民类似，无论它们是在何处生成的，它们都不会离开村庄。有时铁傀儡会像在和村民交谈一般面对村民。

如果不在村庄里，铁傀儡就会四处缓慢游荡，它们通常会自行走向附近的村庄。

只有村庄自然生成的铁傀儡不会离开村庄。<ref></ref>

铁傀儡可以直接走上1格高的方块而无需跳跃。它们会尝试避开[水](水.md)、[熔岩](熔岩.md)、[火](火.md)、[仙人掌](仙人掌.md)。铁傀儡免疫溺水伤害和摔落伤害。在水中，铁傀儡会沉入水底，但是它们仍然能够在水下自由移动。

与大部分友好生物类似，铁傀儡可以被[拴绳](拴绳.md)拴住。

铁傀儡移动的速度会快一些。

铁傀儡在行走时会在脚下产生粒子。

# = 攻击 =
铁傀儡会主动追踪并攻击16格内的绝大多数敌对生物，铁傀儡也会追逐飞行敌对生物，但不会追逐[恶魂](恶魂.md)。如果玩家在一个村庄的[声望](声望.md)值在-15及以下，任何在该村庄自然生成的铁傀儡都会与玩家敌对；如果附近有村民对某个玩家的声望小于-100，则该村庄的铁傀儡会与此玩家敌对。铁傀儡被生物攻击时会进行反击。由玩家建造的铁傀儡永远不会攻击玩家。村庄自然生成的铁傀儡不会直接因为生物攻击了村民而攻击该生物，则会。

当铁傀儡被激怒时，它们会快速跑向目标。铁傀儡会抡起双臂对目标进行攻击，并将目标抛向空中。

多个铁傀儡可能会同时击中同一目标，目标被铁傀儡抛向空中的高度与对其进行攻击的铁傀儡的数量有关。

铁傀儡会感知到[袭击](袭击.md)事件中的灾厄村民的位置并且向其移动，即使它们不在铁傀儡的视线范围内或藏在建筑后或地底下时也是如此。

下表列出了生物是否会被铁傀儡主动攻击或者主动攻击铁傀儡。注意：即使一些生物不会主动攻击铁傀儡，也会在被攻击后反击；即使生物不会主动攻击铁傀儡，它们的攻击方式（如弹射物）也可能会误伤铁傀儡并导致铁傀儡反击。

# = 承受伤害 =
[僵尸](僵尸.md)及其变种（[僵尸猪灵](僵尸猪灵.md)除外）、[骷髅](骷髅.md)及其变种、[蜘蛛](蜘蛛.md)、[洞穴蜘蛛](洞穴蜘蛛.md)、[旋风人](旋风人.md)、[史莱姆](史莱姆.md)、[岩浆怪](岩浆怪.md)和[灾厄村民](灾厄村民.md)都会主动攻击铁傀儡，且可能会对其造成严重的伤害，特别是在它们成群攻击的情况下。如果铁傀儡被多个生物攻击，那么它就会按照这些生物攻击它的顺序来对这些生物进行反击。[恼鬼](恼鬼.md)、[蠹虫](蠹虫.md)和[女巫](女巫.md)也会主动攻击铁傀儡。

铁傀儡有100％的击退抗性，但铁傀儡可以被附有[冲击](冲击.md)魔咒的[弓](弓.md)击退，而则不能。

# = 开裂 =
铁傀儡剩余的生命值可通过其身上裂纹的数量反映出来，其或时每损失|be}}，开裂就会变严重一些。铁傀儡受不同程度损伤时对应的纹理共有4种。

# = 治疗 =
玩家可以通过对受伤的铁傀儡[铁锭](铁锭.md)来为其恢复生命值，每个[铁锭](铁锭.md)可以恢复的生命值。

# = 送花 =
[缩略图|一个送出虞美人的铁傀儡](File:Irongolemflower.png.md)

铁傀儡每2个游戏刻有的概率，在自身碰撞箱X轴和Z轴方向两侧各扩展6格、在Y轴方向上下各扩展2格的范围内，尝试寻找幼年村民或[铜傀儡](铜傀儡.md)，并选择其中最近的目标送出[虞美人](虞美人.md)。此过程需要铁傀儡所在处的天空光照等级≥12，则需要其位于主世界。

在找到目标后的400游戏刻内，铁傀儡会抬起右手拿着虞美人并面向目标，尝试送出虞美人。铁傀儡不会采摘虞美人，准备送出的虞美人会直接出现在铁傀儡的右手。

如果铁傀儡送出虞美人的目标是铜傀儡，铜傀儡会靠近并面向铁傀儡。铜傀儡不会理睬铁傀儡。当两者的碰撞箱相交且铜傀儡的头上没有虞美人时，铁傀儡手上的虞美人会消失，而铜傀儡的头上会出现一株虞美人。

如果铁傀儡送出虞美人的目标是幼年村民，在铁傀儡找到目标后80—400游戏刻内的某个时刻，该幼年村民会靠近并面向铁傀儡，随后“接过”虞美人。<ref>幼年村民因无法接受铁傀儡送出的虞美人。</ref>尽管如此，村民的物品栏中并不会出现虞美人。

# 你知道吗
[缩略图|200px|《天空之城》中的机器人](File:Castleintheskyrobot.png.md)
* 铁傀儡给幼年村民送[虞美人](虞美人.md)的机制致敬了日本动画师宫崎骏的电影作品《[天空之城](wzh:天空之城.md)》的古老机器人<ref></ref>。幼年村民注意到铁傀儡手中的虞美人时，会慢慢地接近，并最终接受虞美人。
* 铁傀儡不会主动进入船或矿车里。但将在铁轨上的矿车推到铁傀儡处会使铁傀儡进入矿车。
* 铁傀儡在Xbox 360 Marketplace是一个可购买物品。
