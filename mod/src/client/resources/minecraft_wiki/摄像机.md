* *摄像机（Camera）**是一个可以捕获并存储图像的物品和生物。在[教育版](教育版.md)中，它能配合[相片簿](相片簿.md)使用来创建照片收藏<ref>https://education.minecraft.net/support/knowledge-base/using-cameras-portfolios/</ref> 。

摄像机同时存在为[方块](方块.md)、[物品](物品.md)、[实体](实体.md)，下文分别称**摄像机方块**、**摄像机物品**、**摄像机实体**。

# 生成
摄像机方块不会生成在世界中。

摄像机实体由摄像机物品生成。

# 获取

摄像机无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。

摄像机物品是不可通过获取的物品，不存在于[创造模式物品栏](创造模式物品栏.md)中，只能通过存档编辑或[附加包](附加包.md)获得。

摄像机物品可以通过[创造模式物品栏](创造模式物品栏.md)获得。

# 破坏
摄像机方块被挖掘时会立刻被破坏。

摄像机方块被破坏后不会掉落。

# 掉落物
摄像机实体死亡时不掉落任何[物品](物品.md)或[经验](经验.md)。

# 用途
摄像机方块仅用于为摄像机物品提供物品模型，没有其他用途或行为。

# = 拍摄 =
摄像机物品可以拍摄一张屏幕截图。时摄像机物品会拍摄特写照片。对方块顶部摄像机物品会将其放置为摄像机实体。

开启后，摄像机拍摄的照片无法正确渲染内容。

# = 燃料 =
摄像机物品可以用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个摄像机物品可烧炼1.5个物品。

# 行为
摄像机实体是一种[生物](生物.md)。

玩家对摄像机实体长按会使其拍摄镜头对准的画面。

摄像机实体不能正常拍摄截图。

类似于[盔甲架](盔甲架.md)，许多生物会对环境中存在的摄像机实体有反应。

摄像机不具有结构完整性，会在生命值降低至时死亡。

# = 受伤害行为 =
摄像机只会受到命令、[状态效果](状态效果.md)以及来自玩家的伤害，并免疫其他所有伤害。

摄像机受到玩家的伤害时会立即死亡，不会播放死亡音效和动画。

# 你知道吗
