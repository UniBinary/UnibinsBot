# 档案

*页面ID: 125817* | *来源: Minecraft Wiki*

* *游戏档案（Game Profile）**，也称**玩家档案（Player Profile）**<ref group="注">在[Mojang API](Mojang API.md)中被直接称为档案（Profile）。</ref>用于自定义[玩家](玩家.md)的名称、外观等内容，也用于在服务器中区分游戏用户。一个游戏账户只有一个游戏档案。以一个游戏档案加入服务器后，就得到一个对应的[玩家实体](玩家.md)。

游戏档案用[UUID](UUID.md)作为唯一标识符；游戏档案用XUID（Xbox UID）或PFID（PlayFab ID）作为唯一标识符。

# 玩家名称
玩家在游戏内的名称取决于其**用户名（Username）**。用户名用于在多人游戏中游玩时方便地区分不同玩家。在某些情况下，多个机器人会同时注册账户，然后创建多个具有相同名称的账户。<ref>https://namemc.com/search?q=increased</ref>

用户名必须在3-16个字符之间。只有一些在游戏处于早期开发阶段时购买的玩家拥有1-2个字符的用户名。玩家可以每隔30天更改其用户名。当玩家更改其用户名时，其旧用户名会保留37天，之后其他玩家可以取其旧用户名作为自己的用户名。因为玩家每隔30天可以更改其用户名，这样玩家就可以占有2个用户名而其他玩家不能使用这2个用户名。如果玩家拥有1-2个字符的用户名并更改其用户名，旧的用户名将永远不能被再次获得。<ref>https://namemc.com/name/p6</ref>用户名可以在[minecraft.net](minecraft.net.md)的[档案名称](https://www.minecraft.net/msaprofile/mygames/editprofile)页面修改。

玩家可以选择不登录Xbox而无限次免费地更改他们的用户名，未登录时修改用户名可以使用任何语言。亦可以登录Xbox Live账户付费（首次免费）修改他们的Xbox ID，以此修改基岩版用户名。

# 外观

[thumb|Minecraft的9款预设皮肤：Sunny、Kai、Makena、Steve、Alex、Zuri、Efe、Ari、Noor](File:Friends.png.md)
玩家的外观<ref group="注">在的[角色创建器](角色创建器.md)中亦作角色（Character）</ref>可以进行一定程度的定制。

# = Java版 =
玩家可以自由选择9种预设皮肤中的一个，也可以在[minecraft.net](minecraft.net.md)的[更改皮肤页](https://www.minecraft.net/msaprofile/mygames/editskin)上传一个后缀名为.PNG的图像文件，以此替代默认皮肤。两个玩家模型可以通过下载免费皮肤或使用皮肤编辑软件进行自定义。若玩家未设置过皮肤、加入了离线模式服务器、使用了演示版或离线模式时，游戏会根据玩家的[UUID](UUID.md)，通过一定的算法确定玩家的模型（宽型或纤细）并从游戏内置的皮肤文件中确定皮肤。

在获取了任意披风后，玩家可以在[Minecraft账户页面](https://www.minecraft.net/msaprofile/mygames/editskin)或[启动器](启动器.md)上选择要使用的披风。

# = 基岩版 =
在创建角色时可以选择9种预设皮肤，这些选择都会为自定义皮肤设置皮肤及模型，但玩家可以按下自定义按钮来修改皮肤。然而，基岩版允许使用[皮肤包](皮肤包.md)，每一个皮肤包都包含了可供选择的免费皮肤。一些皮肤需要购买才能获得。玩家可以通过主菜单中的设置里面的皮肤设置修改他们的皮肤。

玩家可以在[角色创建器](角色创建器.md)处选择穿着披风。某些皮肤包或自定义皮肤会自带披风。

# 查询

可通过命令使用玩家名称或[UUID](UUID.md)查询任意已购买游戏玩家的档案，通过输出的消息还可以快捷执行与对应档案相关的命令。
