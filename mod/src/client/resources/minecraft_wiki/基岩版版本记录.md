# 基岩版版本记录

*页面ID: 32765* | *来源: Minecraft Wiki*

基岩版自从2011年8月16日以来仍在持续开发中，在当时被称为携带版。Alpha阶段持续至2016年11月18日，在发布[携带版1.0](携带版1.0.md)之前。在发布[基岩版1.2.0](基岩版1.2.0.md)后，“携带版”被现在的“基岩版”所取代。

访问[https://aka.ms/MinecraftUpdate](https://aka.ms/MinecraftUpdate)会自动跳转到最新版本的更新日志页面。

# 基岩版
自2017年9月20日[独乐不如众乐更新](独乐不如众乐更新.md)发布起，多人游戏开始可以在移动设备、Windows、Xbox One、Nintendo Switch上进行，最后于2024年10月22日扩展到PlayStation 5。基岩版现仍在持续开发中。

# 携带版
[携带版1.0](携带版1.0.md)引入了游戏中的最后一个维度——[末地](末地.md)，也同时迎来了正式版的发布。随后游戏被重命名为[基岩版](基岩版.md)，距离正式版只有一年不到。

# 携带版Alpha

[携带版](携带版.md)的雏形演示版最初在E3 2011上于2011年7月揭露，开发持续了5年多。在[携带版1.0.0](携带版1.0.0.md)发布之前，这个漫长的开发阶段不断地从[Java版](Java版.md)上将各类特性移植到移动平台，直到游戏正式发布。
