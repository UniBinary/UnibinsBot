# 基岩版1.18.31

*页面ID: 95434* | *来源: Minecraft Wiki*

* *1.18.31**是的一次热修复更新，在除Nintendo Switch外的平台上发布于2022年4月27日<ref></ref>，在Nintendo Switch平台上发布于2022年4月29日，加入了一个新的[实验性玩法](实验性玩法.md)子选项，并修复了一些漏洞。此版本与[1.18.30](基岩版1.18.30.md)相兼容。

# 新内容
# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“旁观模式”子选项。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“旁观模式”子选项后才可使用。

# = 游戏内容 =
* *[旁观模式](旁观模式.md)**
* 现在属于[实验性玩法](实验性玩法.md)中的“旁观模式”部分。
* 现在也可以通过命令进入。

# 修复
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了能够通过熔炉不正确获得经验的问题。（）
* 修复了重载RTX世界时屏幕会变黑的问题。（）
* 修复了Android设备上远处方块的纹理会出现颗粒、扭曲和失真的问题。（）
* 修复了iOS设备上的流动的水和熔岩的纹理无法正确渲染的问题。
* 修复了各种帧率问题，尤其是配置较差的移动设备。（）
* 生物不再可以生成在按钮上。（）
* 修复了多次保存和重置区块时会使区块加载出现延迟、性能问题以及游戏性能不稳定的问题。（、）
* 修复了更新至1.18.30后无法打开世界的问题。
* “音乐之声”成就现在会在条件满足时达成。
* 修复了在Nintendo Switch上无法打开市场的问题。（）
* 修复了在市场购买商品时可能会出现无限的加载界面的问题。
