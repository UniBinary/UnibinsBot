# 游戏规则/block explosion drop decay

*页面ID: 127282* | *来源: Minecraft Wiki*

* *block_explosion_drop_decay**是控制部分[爆炸](爆炸.md)中一些方块是否不会掉落战利品的[游戏规则](游戏规则.md)。

# 行为
当block_explosion_drop_decay为<samp>false</samp>时，在[床](床.md)、[重生锚](重生锚.md)和[末地水晶](末地水晶.md)引起的爆炸中，所有被破坏方块的掉落物都不会被炸毁。

当block_explosion_drop_decay为<samp>true</samp>时，在上述爆炸中，部分被破坏方块的掉落物会被炸毁。
