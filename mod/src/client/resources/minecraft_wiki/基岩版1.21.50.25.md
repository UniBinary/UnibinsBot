# 基岩版1.21.50.25

*页面ID: 127992* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.50.25**（ChromeOS/Android）、**Preview 1.21.50.25**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.50](基岩版1.21.50.md)的第4个测试版，发布于2024年10月23日<ref></ref><ref></ref>，加入了[树脂团](树脂团.md)和[眼眸花](眼眸花.md)以及相关方块和物品，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[树脂块](树脂块.md)**
* 可使用9个[树脂团](树脂团.md)合成。
* 可与2个[苍白橡树原木](苍白橡树原木.md)合成为[嘎枝之心](嘎枝之心.md)。

* *[雕纹树脂砖块](雕纹树脂砖块.md)**
* [树脂砖块](树脂砖块.md)的雕纹变种。
* 可使用2个[树脂砖台阶](树脂砖台阶.md)合成，也可在[切石机](切石机.md)中用树脂砖块制成。

* *[眼眸花](眼眸花.md)**
* 一种新的[花](花.md)，自然生成于[苍白之园](苍白之园.md)生物群系。
* * 也可通过在苍白之园生物群系中对[草方块](草方块.md)使用[骨粉](骨粉.md)生成。
* 有2种变种：闭合的眼眸花和张开的眼眸花。
* 会根据当天的时间在不同的变种之间转换。
* * 夜晚时为张开的眼眸花。
* * 白天时为闭合的眼眸花。
* * 在没有[昼夜更替](昼夜更替.md)的维度中会维持原样。
* 种植在地上时会与其他眼眸花产生联系，使之张开或闭合。
* 张开的眼眸花会在夜晚时发光，但不会影响周围的[亮度](亮度.md)。
* [蜜蜂](蜜蜂.md)对其采粉时会获得[中毒](中毒.md)效果。
* 不可用于吸引及繁殖蜜蜂。<ref></ref><ref></ref>
* 由张开的眼眸花合成的[谜之炖菜](谜之炖菜.md)会给予[失明](失明.md)效果，由闭合的眼眸花合成的谜之炖菜会给予[反胃](反胃.md)效果。
* [灰色染料](灰色染料.md)可使用闭合的眼眸花合成，[橙色染料](橙色染料.md)可使用张开的眼眸花合成。

* *[树脂砖块](树脂砖块.md)**
* 可使用4个树脂砖合成。
* 可用于合成对应的[楼梯](楼梯.md)、[墙](墙.md)和[台阶](台阶.md)。
* * 合成时只会给予1个对应的楼梯、墙和台阶。<ref></ref><ref></ref><ref></ref>

* *[树脂团](树脂团.md)**
* 破坏嘎枝之心时掉落1-3个，不受[时运](时运.md)魔咒影响<ref></ref>。
* 嘎枝之心绑定的嘎枝被攻击时，嘎枝之心周围会生成树脂团。
* 有概率在[林地府邸](林地府邸.md)的战利品箱中找到。
* 可用于合成[树脂块](树脂块.md)。
* 可在[熔炉](熔炉.md)中烧炼为[树脂砖](树脂砖.md)。
* 可用作[盔甲纹饰](盔甲纹饰.md)材料。

# = 物品 =
* *[树脂砖](树脂砖.md)**
* 可通过烧炼[树脂团](树脂团.md)获得。
* 有概率在林地府邸的战利品箱中找到。
* 可用于合成[树脂砖块](树脂砖块.md)。

# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“瞄准辅助”子选项。
* * 用于在自定义相机视角时启用瞄准辅助功能。
* ** 目前瞄准辅助仅支持方块。实体会在未来的正式版中启用。

* *[设置](设置.md)**
* 在设置中加入了“”选项。
* * 用于启用内存层覆盖。

# 更改
# = 方块 =
* *[嘎枝之心](嘎枝之心.md)**
* 现在自然生成的嘎枝之心被破坏时会掉落，即使使用[精准采集](精准采集.md)工具也是如此。
* 提高了环境音效的频率。
* 更改了未激活的嘎枝之心的纹理，以与激活状态更加一致。

* *[苍白垂须](苍白垂须.md)**
* 提高了环境音效的频率。

* *[苍白橡树树苗](苍白橡树树苗.md)**
* 现在可用于[堆肥](堆肥.md)。
* 现在会在[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上生长。

* *[苍白橡木告示牌](苍白橡木告示牌.md)**
* 更改了方块形式和UI的纹理，以与其他[告示牌](告示牌.md)保持一致。

* *[红砖块](红砖块.md)及对应的[楼梯](楼梯.md)、[台阶](台阶.md)和[墙](墙.md)**
* 更改了纹理，以与[树脂砖块](树脂砖块.md)的砖纹保持一致。

# = 物品 =
* *[苍白橡木运输船](苍白橡木运输船.md)**
* 再次更改了物品纹理。

* *[苍白橡木告示牌](苍白橡木告示牌.md)和[悬挂式苍白橡木告示牌](悬挂式苍白橡木告示牌.md)**
* 再次更改了物品纹理，以与其他告示牌和悬挂式告示牌保持一致。

# = 生物 =
* *[嘎枝](嘎枝.md)**
* 提高了速度。
* 现在会造成更多伤害。
* * 简单难度下的近战攻击伤害由增加至。
* * 普通难度下的近战攻击伤害由增加至。
* * 困难难度下的近战攻击伤害由增加至。
* 现在当所绑定的嘎枝之心被破坏时，嘎枝会在消失前抽搐2.25秒。
* 现在绑定了嘎枝之心的嘎枝会在与玩家处于同一格方块内超过5秒时消失。
* * 此更改旨在防止出现玩家与绑定了嘎枝之心的嘎枝处于同一格方块内时，因无法攻击嘎枝或挖掘方块而被困于此处，进而需要重进游戏以清除嘎枝的情况。
* 现在绑定了嘎枝之心的嘎枝消失时会激活[幽匿催发体](幽匿催发体.md)。
* * 不会生成[幽匿块](幽匿块.md)，因为嘎枝不会掉落经验。
* 更改了行走动画和攻击动画。
* 绑定了嘎枝之心的嘎枝不再会避开能够造成伤害的方块。
* 未绑定嘎枝之心的嘎枝不再免疫[火焰伤害](火焰伤害.md)。
* 未绑定嘎枝之心的嘎枝现在会避开能够造成伤害的方块。
* 降低了攻击速度以匹配。

* *[恶魂](恶魂.md)**
* 不再会被[女巫](女巫.md)反击。

# = 世界生成 =
* *[苍白之园](苍白之园.md)**
* 进一步调整了地平线上的天空颜色以匹配。
* 迷雾颜色由更改为。

* *[苍白橡树](苍白橡树.md)**
* 由[苍白橡树树苗](苍白橡树树苗.md)长成的苍白橡树不再有概率生成苍白垂须。

# = 常规 =
* *[粒子](粒子.md)**
* 将粒子重命名为。

# = 技术性 =
* *API**
* 为加入了附加可选参数。
* * 有效的通过函数传递时，新创建的主题会继承父主题的所有主题颜色属性。

* *生物群系**
* 修复了1.17.40前创建的区块会表现为海洋生物群系，使用类似于海洋的迷雾、天空颜色和生物生成的问题。（）

* *[基岩版编辑器](基岩版编辑器.md)**
* 加入了新的定位工具以协助查找生物群系。
* 现在启动编辑器时会将时间固定在中午。
* 改进了视口焦点的可见性，现在焦点上会有动画轮廓，并加入了聚焦状态作为切换模式（）的步骤。
* 为加入了函数。
* * 用于尝试设置模态框输入焦点（如工具轨道的视口）。

* *实体组件**
* 移除了组件，并将其替换为新组件。
* * 添加给实体时会阻止其他实体攻击该实体，除非攻击者满足例外过滤器。
* * 在原版中，此组件被添加给恶魂。
* * 创作者可以将实体添加到例外过滤器中，以允许实体攻击恶魂。

* *实体事件响应**
* 实体事件响应现在被标记为测试性内容，并需要在根JSON对象中指定。
* * 当前的实现并不完全符合内部标准，因此在开发出更强大的技术性解决方案之前，此实体事件响应对创作者内容不可用。
* * 这种方式能够在不冒向后兼容的风险的情况下迭代功能。
* 加入了实体事件响应，允许在实体边界框的中心发射粒子。
* * 允许指定要发射的粒子类型。

* *网络协议**
* 移除了存档事件。
* 加入了新的粒子类型：。

# 修复
* *苍白之园**
* 调整了苍白橡木告示牌模型和UI的纹理，以与其他告示牌保持一致。（）
* 苍白橡树树苗现在可用于堆肥。（）
* 苍白垂须现在使用与其他苔藓类和苍白苔藓类方块相同的音效。（）

* *嘎枝之心**
* 更新了未激活的嘎枝之心的纹理，以与激活状态更加一致。（）

* *嘎枝**
* 降低了嘎枝的攻击速度以匹配Java版。（）

* *方块与物品**
* 现在只有使用镐来挖掘高炉、炼药锅、发射器、投掷器、附魔台、熔炉、漏斗和烟熏炉才能使它们掉落。（）
* 现在使用任何工具破坏所有种类的铜门、铁门、重质测重压力板、轻质测重压力板、磨制黑石压力板和石头压力板这类需要支持的方块时均能使它们掉落。
* 现在使用不合适的工具挖掘紫水晶母岩时会减慢挖掘。
* 现在使用不正确的工具挖掘钟、酿造台、合成器、末影箱、灯笼和灵魂灯笼这类总会掉落的方块时也能较快地挖掘。（）
* 修复了潜影盒的颜色不会作为名称的一部分显示的问题。（）
* 处于黏液块、蜂蜜块、漏斗和加热块（教育版方块）下方时，草方块和菌岩不再会退化为泥土和下界岩。（）
* 现在处于侦测器下方时，草方块和菌岩会退化为泥土和下界岩。

* *地物**
* 苍白橡树树苗现在会在苔藓块和苍白苔藓块上生长。（）

* *游戏内容**
* 现在使用命令时，相机视角会以正确的方式绕X轴和Y轴旋转。
* 现在使用空的收纳袋时会使动画在第一人称和第三人称视角下播放。
* 现在船上或骆驼上的第二个乘客进入未加载的区块时也收到警告消息。

* *常规**
* 更改了玩家生成逻辑，因此现在会更少地生成在水中或细雪中。（）

* *图形**
* 移除了海带的非预期的深色着色。（）

* *物品**
* 现在所有着火的弹射物都会激活TNT矿车和TNT。（）

* *生物**
* 现在不处于固体表面上时，旋风人会播放正确的空闲音效。（）

* *Realms**
* 移除了Realms故事设置中的选择退出选项，现在其位于时间轴选项卡中。
* 修复了玩家无法在激活的Realm上创建新世界的问题。

* *音效**
* 湿海绵现在会正确播放方块音效。（）

* *试炼密室**
* 将结构中的箱子的内容更改为引用战利品表。

* *用户界面**
* 在槽位之间移动盾牌物品时不再会改变物品大小。
* 现在移动至玩家光标下的收纳袋会正确更新其提示框。
* 现在可以使用收纳袋收集合成输出，以将合成出的物品放入收纳袋中。
* 触摸控制：修复了自定义控制期间可以与船交互的漏洞。（、）
* 触摸控制：在摇杆模式下，现在可以通过双击“向上飞”按钮以停止飞行。（）
* 触摸控制：快速连续点击向上飞和向下飞按钮时不再会使玩家停止飞行。（）
* 快捷栏中的工具消耗耐久度时不再会播放动画。（）
* 移除了玩家使用游戏手柄时命令方块UI中的“X”关闭按钮。
* 修复了无法在新的服务器选项卡中加入服务器前正确验证输入错误的IP地址的问题（仅测试版本）。
* 现在在触摸屏设备上的收纳袋提示框中选择物品时会出现显示物品名称的弹窗。</onlyinclude>
