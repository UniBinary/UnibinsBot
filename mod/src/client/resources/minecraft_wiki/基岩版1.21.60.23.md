# 基岩版1.21.60.23

*页面ID: 137067* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.60.23**（ChromeOS/Android）、**Preview 1.21.60.23**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.60](基岩版1.21.60.md)的第2个测试版，发布于2024年12月4日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[旗帜](旗帜.md)**
* 现在重命名的旗帜被破坏时或被[炼药锅](炼药锅.md)清洗时会保留自定义名称。

* *[樱花树苗](樱花树苗.md)**
* 现在可以穿过[樱花树叶](樱花树叶.md)而生长。<ref></ref>

* *[栅栏门](栅栏门.md)**
* 现在使用方块状态，而不是，该状态使用字符串值。

* *[缠怨藤](缠怨藤.md)和[垂泪藤](垂泪藤.md)**
* 现在使用带有[时运](时运.md)魔咒的工具挖掘时会增加掉落概率。
* * 时运I会将概率增加至55%，时运II增加至77%，时运III增加至100%。

# = 物品 =
* *[谜之炖菜](谜之炖菜.md)**
* 现在食用由[郁金香](郁金香.md)合成的谜之炖菜后给予的[虚弱](虚弱.md)效果的持续时间为，而非。

# = 生物 =
* *[嘎枝](嘎枝.md)**
* 现在已激活的嘎枝拥有不受[隐身](隐身.md)效果影响的眼眸。

# 修复
* *方块**
* 修复了传送回有方块实体被破坏的区块时可能发生的崩溃。（）
* 从远处观察睡莲时，睡莲不再会闪烁。（）
* 从远处观察向日葵时，向日葵不再会闪烁。（、）

* *图形**
* 现在处于较低的Y坐标时屏幕周围的黑边会逐渐出现，而不是突然出现。（）

* *生物**
* 现在即使处于隐身状态下，只要嘎枝有攻击目标，其眼眸就会渲染。（）
* 新的岩浆怪模型和纹理现在仅会被明确覆盖该模型和纹理的资源包使用，因为该模型和纹理已被重命名，以区别于原始资源。（）
* * 此更改是追溯性的，自1.21.50版本开始生效。

* *性能与稳定性**
* 修复了若在首次进行下载和加入尝试时取消加入多人游戏，则无法下载可选包和必需包的问题。

* *用户界面**
* 触摸控制：现在可以像PC一样在向下飞行时将方块放置在容器上。（）
* 现在内容较长的收件箱消息可以在进入收件箱屏幕后使用游戏手柄立即滚动。
* 修复了在特定情况下下载资源包时会出现“发生未知错误”的问题。

* *原版趋同**
* 眼眸花和覆地苍白苔藓不再会在苍白橡树的树干内生成。
* 矮草丛现在会在平原中更频率地大量生成。（）
* 甜浆果丛现在会生成于原始云杉针叶林。（）
* 甜浆果丛现在会生成于原始松木针叶林。（）
* 修复了草甸的植被分布不正确的问题。（、）
* 现在红树林沼泽中的红树会生成在水上。（）
* 苍白橡树树叶不再会比Java版显得更亮。（）
* 重命名的旗帜被破坏时或被炼药锅清洗时不再会丢失自定义名称。（）
* 现在使用时运附魔工具破坏缠怨藤和垂泪藤时会增加掉落为物品的概率，包括使用时运III时的100%概率。（）
* 发射器现在可以将潜影盒放置在水下。（）
* 现在食用由郁金香合成的谜之炖菜时会获得7秒虚弱效果，以匹配Java版。（）
* 现在食用通过沉船和与村民交易获得的带有虚弱效果的谜之炖菜时会获得7秒虚弱效果。
* 下界砖台阶、红色下界砖台阶、下界砖墙、红色下界砖墙、裂纹下界砖块和雕纹下界砖块现在拥有与下界砖块相同的音效，以匹配Java版。（）</onlyinclude>
