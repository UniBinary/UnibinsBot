# 深板岩圆石楼梯

*页面ID: 79565* | *来源: Minecraft Wiki*

* *深板岩圆石楼梯（Cobbled Deepslate Stairs）**是[深板岩圆石](深板岩圆石.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
深板岩圆石楼梯会自然生成在[远古城市](远古城市.md)中。

# 破坏
挖掘深板岩圆石楼梯的合适工具是镐。深板岩圆石楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

深板岩圆石楼梯被破坏后会掉落自身。
