# 携带版0.10.0.b7

*页面ID: 28512* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.10.0 alpha build 7**是[v0.10.0 alpha](携带版0.10.0.md)的第7个测试版，发布于2014年11月7日，修复了一些漏洞。由于开发过程中出现的漏洞，此版本在提交到应用商店后被紧急制止了分发。<ref></ref>该版本一直存在于Google Play数据库中，但在build 8发布之前并未开放下载权限，因此大部分玩家无法获得该版本。

# 更改
# = 方块 =
* *[水](水.md)**
* 重新加入了水的音效。

# = 常规 =
* *渲染**
* 落日时的云与地形现在变得更红。
* Mod制作者可以用Version 300着色器。
* * 可能使文字渲染（特别是非ASCII文字）更快。

# 修复
* *修复了4个漏洞**

* 修复了一个在服务器上发现的问题。
* 修复了从其他应用程序切换回来后游戏保持静音的漏洞。（Android）
* 在服务器里游玩时又可以睡觉了。
* 现在玩家在睡觉时的朝向正常了。</onlyinclude>
