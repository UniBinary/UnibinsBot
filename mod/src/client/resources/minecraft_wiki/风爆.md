# 风爆

*页面ID: 115159* | *来源: Minecraft Wiki*

* *风爆（Wind Burst）**是一种用于[重锤](重锤.md)的[魔咒](魔咒.md)，可以使攻击后产生[风爆](爆炸#风爆.md)。

# 获取
风爆是不可[附魔](附魔（物品修饰）.md)的魔咒，且无法通过以下方式以外的任何方式获取。

[不祥宝库](不祥宝库.md)可以提供风爆I附魔书。具有风爆II和风爆III的物品只能通过使用铁砧合并获得。

# 用途

生物在[下落高度](摔落#下落高度.md)大于1.5格时使用具有风爆的物品进行[近战攻击](近战攻击.md)会在攻击者的位置产生[风爆](爆炸#风爆.md)，将攻击者和周围的生物向上弹起。生物处于滑翔状态时不能触发。

通过此方式可以实现重锤的连续下落攻击，但是此魔咒产生的风爆会清零重锤原有的摔落伤害保护持续计时，导致生物受到全额摔落伤害<ref></ref>，因此从极高位置进行下落攻击有较大风险。

若使用[命令](命令.md)等方式将风爆应用于重锤以外的物品，或用重锤攻击非生物实体，由于没有下落攻击时所给予的滞空，风爆将攻击者弹起的效果将较小或不稳定。<ref></ref>

每魔咒等级会增加产生风爆的击退威力。
