# Java版Classic 0.29 01

*页面ID: 35647* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.29_01**是[0.29](Java版Classic 0.29.md)的一个漏洞修复版本，发布于2009年10月29日。<ref></ref>

# 更改
# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 名称不会出现在玩家身上，除非十字准星指在他们身上。
* * 名称不再会隐藏在地形中。

* *常规**
* [玩家](玩家.md)现在可以隔着其他玩家来放置方块了。</onlyinclude>

# 你知道吗
* 此版本可以通过修改中的<code>Minecraft.class</code>文件进入[生存模式](生存模式.md)。
* 在有关这一版本的推文中，Notch称“现在可以穿过玩家来放置方块了。”<!--You can now build through players-->然而，这一特性并不能正常运作。
