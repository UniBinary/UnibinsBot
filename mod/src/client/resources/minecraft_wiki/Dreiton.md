# Dreiton

*页面ID: 170091* | *来源: Minecraft Wiki*

* *Dreiton**是一首由[C418](C418.md)创作的音乐。

# 描述

[File:Dreiton.ogg](File:Dreiton.ogg.md)

Dreiton以遥远、芯片风格的合成器演奏简单的节奏开场，并使用泛音鼓作为伴奏。一些部分更侧重于泛音鼓的旋律，听起来与[Aria Math](Aria Math.md)非常相似。这首曲子的节奏缓慢，音量逐渐增大，然后突然安静下来，随后慢慢以响亮的铜管和弦乐达到高潮，最后戏剧性地转入安静的吉他部分。

# 你知道吗
*  “Dreiton”是德语，意为“三音”，可能引用自C418的早期专辑[*zweitonegoismus*](https://c418.bandcamp.com/album/zweitonegoismus)（意为“二音自我主义”），而其本身则又可能引用自他更早的一张专辑[*Sine*](https://c418.bandcamp.com/album/sine)（调换s和e后得到“eins”，在德语中意为“一”）。
* C418专辑“148”中的Vierton是本曲目的混音版。
