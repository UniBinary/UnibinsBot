# New Nintendo 3DS版1.4.23

*页面ID: 39521* | *来源: Minecraft Wiki*

* *1.4.23**是[New Nintendo 3DS版](New Nintendo 3DS版.md)发布于2018年3月21-22日的一次更新，加入了多人游戏，修复了一些漏洞。<ref></ref>

# 新内容
* 在本地游戏加入了2人[多人游戏](多人游戏.md)的支持。

# 更改
* 提升稳定性与优化。

# 修复
* 修复了此前版本的一些漏洞。
