# 存储格式
在存档中，玩家数据存储在两个位置：
* 对于单人游戏存档，玩家数据保存在内的标签内。
* 在{{filepath|-{}-<*存档根目录*>/playerdata/<*玩家UUID*>.dat}}内存储了各个玩家的数据。此文件可能具有副本。

在存档中，玩家数据存储在{{filepath|-{}-<*存档根目录*>/players/data/<*玩家UUID*>.dat}}内，每个玩家都对应一个玩家数据文件。此文件可能具有副本。

对于单独存储玩家数据的玩家数据存储文件，它使用GZip压缩的[NBT](NBT.md)文件格式保存，其NBT结构与玩家数据结构一致。

# 存储行为
对于单人游戏存档，内的标签内的玩家数据优先级高于存档目录内中的玩家数据的优先级。

与类似，玩家数据也很重要，所以也具有备份文件。当玩家数据被保存时，游戏按照下列步骤创建备份：
# 先将新的数据写入到{{filename|-{}-<*玩家UUID*>-<*随机字符串*>.dat}}内。
# 将原先的{{filename|-{}-<*玩家UUID*>.dat}}移动到{{filename|-{}-<*玩家UUID*>.dat_old}}。
# 删除{{filename|-{}-<*玩家UUID*>.dat}}。
# 将刚才写入的{{filename|-{}-<*玩家UUID*>-<*随机字符串*>.dat}}移动到{{filename|-{}-<*玩家UUID*>.dat}}。
# 如果有任何一步出错，都将{{filename|-{}-<*玩家UUID*>.dat_old}}移动回{{filename|-{}-<*玩家UUID*>.dat}}。

加载时如果主文件损坏，那么游戏会尝试使用旧版本自动修复文件：
# 将原先的{{filename|-{}-<*玩家UUID*>.dat}}复制到{{filename|-{}-<*玩家UUID*>_corrupted_<*时间戳*>.dat}}。
# 加载{{filename|-{}-<*玩家UUID*>.dat_old}}。
