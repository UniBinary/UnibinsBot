* *潮涌核心（Conduit）**是一种类似[信标](信标.md)的功能型方块，激活时能给予玩家[潮涌能量](潮涌能量.md)效果，并且会伤害附近的[敌对生物](敌对生物.md)。

# 生成
潮涌核心不会生成在世界中。

# = 合成 =

# 破坏
挖掘潮涌核心的合适工具是镐。

潮涌核心被破坏后会掉落自身。

被[爆炸](爆炸.md)破坏的潮涌核心总是会掉落。

# 用途
# = 潮涌能量 =
潮涌核心启动框架的示意图，可以点击图片右侧的黑色部分查看不同层数。图中的[海晶石](海晶石.md)也可以是[海晶灯](海晶灯.md)、[海晶石砖](海晶石砖.md)或[暗海晶石](暗海晶石.md)：

激活时，潮涌核心会为其影响范围内接触到[水](水.md)或[降雨](降雨.md)（不包括降雪）的玩家提供13秒的状态效果，效果的时长每1秒刷新一次。该效果可避免玩家氧气栏氧气值下降、给予玩家水下夜视效果，并将玩家的水下挖掘速度增加（仍慢于正常的挖掘速度）。

要激活潮涌核心，潮涌核心需要完全被水环绕（可以是水源、水流或[含水](含水.md)方块），而潮涌核心及周边的水需要被启动框架包围。该框架由3个不同方向、以潮涌核心为中心的5×5正方形组成，只有[海晶石](海晶石.md)、[暗海晶石](暗海晶石.md)、[海晶石砖](海晶石砖.md)及[海晶灯](海晶灯.md)会被视为启动框架的部分。海晶石及其变种的台阶和楼梯不能作为启动框架的有效部分。

启动框架至少包含16个方块才会激活潮涌核心，此时影响半径为32格。启动框架每拥有7个方块，影响半径就会增加16格。完整启动框架（42个方块）的影响半径为96格。当潮涌核心被框架激活时，其中间的海洋之心会在鹦鹉螺壳的环绕下显露出来。

框架内的其他方块，或不在启动框架之内的方块对激活潮涌核心没有影响。

# = 攻击 =
用完整版框架激活潮涌核心后，当核心的8格范围内有任意[敌对生物](敌对生物.md)和接触到水或雨时，它们会每2秒受到点伤害。每个潮涌核心只能同时攻击一个目标，与此相对，每个目标最多只能同时被一个潮涌核心攻击。

# = 光源 =
潮涌核心会发出亮度等级为15的光，无论它是否被激活。

# 你知道吗
* 当潮涌核心激活时，其模型中心会显示类似[海洋之心](海洋之心.md)的纹理，对应了潮涌核心的合成材料。
* * 潮涌核心在寻找敌对生物时会出现一个打开的眼睛，否则就会闭上眼睛。
* 潮涌核心被取消激活时会旋转一个角度：每次顺时针旋转1.5°，其旋转方式似乎是无规律的。
* 使用指令或者世界预设放置的潮涌核心总是含水的。
