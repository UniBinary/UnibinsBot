# Java版Beta 1.9-pre4

*页面ID: 32288* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.9-pre4**是[Java版1.0.0](Java版1.0.0.md)的第4个预发布版，发布于2011年10月13日，加入了末地维度，并修复了一些漏洞。

# 新内容
# = 世界生成 =
* *[末地](末地.md)**
* 新的维度。

# = 常规 =
* ***
* 新的设置选项：
* * <code>debug</code>
* * <code>enable-query</code>
* * <code>enable-rcon</code>
* * <code>query.port</code>
* * <code>rcon.password</code>
* * <code>rcon.port</code>

# = 物品 =
* *[闪烁的西瓜片](闪烁的西瓜片.md)**
* 用于代替恶魂之泪制作治疗药水。

* *[喷溅药水](喷溅药水.md)**
* 可以投掷。
* 被投掷时会产生区域效果，可以通过在普通药水的基础上添加火药获得。

# = 生物 =
* *[末影龙](末影龙.md)**
* 不能自然生成，仅存于源代码中。

# 更改
# = 方块 =
* *[末地传送门方块](末地传送门方块.md)**
* 现在有功能了。
* 玩家把鼠标悬停在物品栏中的末地传送门方块上时不会再导致游戏崩溃了，但是不显示末地传送门方块的名称。
* *[花](花.md)**
* 现在会随机朝向，像草和泥土那样。
* *[末地石](末地石.md)**
* 纹理由[30px](File:End Stone before Beta 1.9-pre4.png.md)变为[30px](File:End Stone JE1 BE1.png.md)。

# = 物品 =
* *[水桶](水桶.md)和[熔岩桶](熔岩桶.md)**
* 桶中的流体可以处理其他流体源，就像固体方块，可以将它们放在彼此的顶部，而不需要相邻的墙。

* *[恶魂之泪](恶魂之泪.md)**
* 现在用于制作[再生药水](再生药水.md)。
* 不再能制作治疗药水。

# = 世界生成 =
* *[要塞](要塞.md)**
* 重新设计了[末地传送门框架](末地传送门框架.md)。

# = 游戏内容 =
* *[太阳](太阳.md)和[月亮](月亮.md)**
* 太阳和月亮现在会从东边升起西边落下，基于地图的顶部是北方，是圆的。
* 月亮现在有多个月相，有点类似于真正的月亮。
* *[状态效果](状态效果.md)**
* 在状态效果的作用下加入了漩涡粒子。
* *[附魔](附魔.md)**
* 完全实现了附魔机制。

# = 常规 =
* *[纹理包](纹理包.md)**
* 按下可以重新加载纹理包。

# 修复
* *修复了5个漏洞**
* 附魔操作现在是服务器侧的变化，而不仅仅是客户端侧的变化。
* 修复了在附魔台和酿造台上使用键点击导致崩溃的漏洞。
* 暴击现在可以在多人游戏中出现了。
* 用于标记要塞的玻璃塔不再出现了。
* 修复了除了光照漏洞以外的动力矿车的所有漏洞。</onlyinclude>
