# 煤矿石

*页面ID: 6111* | *来源: Minecraft Wiki*

* *煤矿石（Coal Ore）**是挖掘时会掉落[煤炭](煤炭.md)的[矿石](矿石.md)方块。

* *深层煤矿石（Deepslate Coal Ore）**是以[深板岩](深板岩.md)作为容矿岩的煤矿石变种。

# 生成
# = 自然生成 =
煤矿石会以[团簇](团簇.md)的形式生成于主世界Y=0至320高度的石头之间，矿团大小为1-17个方块。依高度有两种生成机制：其一适用于Y=0至192，在Y=96分布量最多并向两端递减，每区块尝试生成20次且较少露天出现；其二适用于Y=136以上，均匀分布，每区块尝试生成30次。

在高度Y=-24以上，煤矿石也可以作为浅层[化石](化石.md)的一部分生成。

生成于[深板岩](深板岩.md)和[凝灰岩](凝灰岩.md)间的煤矿石会被替换为深层煤矿石。

# 获取
煤矿石和深层煤矿石只能通过破坏对应方块获得。

# 破坏
挖掘煤矿石和深层煤矿石的合适工具是镐。煤矿石和深层煤矿石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，煤矿石和深层煤矿石被破坏后会掉落1个[煤炭](煤炭.md)和，挖掘工具的[时运](时运.md)魔咒会增加煤炭的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，煤矿石和深层煤矿石被破坏后会掉落自身。

# 用途
# = 烧炼配方 =

注：烧炼矿石比开采矿石效率更低，因为它需要燃料以获得煤，而煤是主要从煤矿石直接开采获得的。

# = 山羊冲撞 =
[山羊](山羊.md)在冲撞煤矿石时会掉落[山羊角](山羊角.md)。
