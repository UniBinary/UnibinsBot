# 获取
# = 合成 =
所有楼梯合成配方的摆放方式均相同，使用6个对应方块可合成4个对应楼梯。

# = 切石 =
除去木楼梯和竹马赛克楼梯以外的楼梯也可以使用切石机制作，1个方块可以切出1个对应种类的楼梯。另外，若甲方块可以切石为乙方块，则甲方块也可以切石为乙方块对应的楼梯。

# 用途
楼梯的上表面或下表面、以及楼梯的背面具有完整的[方块支撑形状](方块支撑形状.md)，因此可以放置[火把](火把.md)等方块。

透過[走上方塊](走上方塊.md)機制，在楼梯上走上相同的高度比跳上相同的高度要快，而跳跃会产生[消耗度](消耗度.md)。上楼梯时疾跑能提高爬升速度，但也会产生大量[消耗度](消耗度.md)。

楼梯可以[含水](含水.md)。

# = 放置 =
[缩略图|**楼梯的组合变形** — **左：**单独放置时原来的朝向。**右：**毗邻楼梯时改变了形状。（**上：**内角 **下：** 外角）](File:Stairs reconfiguration.png.md)

楼梯被放置时，它的半格面会朝向玩家。

楼梯可以正面朝上或者上下颠倒地放置：
* 对着[方块](方块.md)的顶部或下半侧面放置的楼梯是正面朝上的。
* 对着方块的底部或上半侧面放置的楼梯是上下颠倒的。

楼梯会更改它们的形状以与毗邻的楼梯（包括不同类型的）连接：
* 当楼梯的半格面与另一个楼梯的面毗邻时，楼梯的整格面会变成“L”形，以连接另一个楼梯的半格面（这形成了一个“内角”）。
* 当楼梯的整格面与另一个楼梯的面毗邻时，楼梯的半格面会变成“L”形，以连接另一个楼梯的整格面（这形成了一个“外角”）。

正面朝上的楼梯与上下颠倒的楼梯不会互相连接。
