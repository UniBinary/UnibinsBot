# 基岩版1.21.130.24

*页面ID: 169618* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.130.24**（ChromeOS/Android）、**Preview 1.21.130.24**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.130](基岩版1.21.130.md)的第3个测试版，发布于2025年10月29日<ref></ref><ref></ref>，加入了新生物[焦骸](焦骸.md)和[骆驼尸壳](骆驼尸壳.md)，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了焦骸刷怪蛋和骆驼尸壳刷怪蛋。

# = 生物 =
* *[焦骸](焦骸.md)**
* 新的骷髅变种。
* 在[沙漠](沙漠.md)生物群系中亮度为0的地方代替部分骷髅生成。
* 不会在阳光下燃烧。
* 会射出[虚弱之箭](虚弱之箭.md)。
* 和[沼骸](沼骸.md)类似，射箭的频率比普通骷髅慢。
* 和[尸壳](尸壳.md)类似，不会生成在洞穴中。

* *[骆驼尸壳](骆驼尸壳.md)**
* 新的亡灵生物。
* 暂时无法自然生成。
* 不会在阳光下燃烧。
* 尸壳和焦骸能够骑乘骆驼尸壳。
* * 焦骸还会主动寻找附近的骆驼尸壳。
* 只有在乘客对玩家敌对时才会对玩家敌对。
* 会和其他敌对生物一样自然消失，但被玩家骑乘时不会。
* 可以用[兔子脚](兔子脚.md)吸引和喂食。
* 无法繁殖。
* 成年骆驼尸壳可装备[鞍](鞍.md)，装备后可以骑乘。
* 骑乘时，行为和普通骆驼一致。

# 更改
# = 物品 =
* *[矛](矛.md)**
* 现在会算上持有者的基础攻击伤害。
* 更改了下界合金矛的纹理以匹配。
* 略微增加了使用矛攻击后的冷却时间，以匹配并能够更容易地触发[突进](突进.md)魔咒。
* * 石矛：0.7秒 → 0.75秒
* * 铜矛：0.75秒 → 0.85秒
* * 金矛和铁矛：0.8秒 → 0.95秒
* * 钻石矛：0.9秒 → 1.05秒
* * 下界合金矛：1秒 → 1.15秒

# = 生物 =
* *[马](马.md)、[骡](骡.md)、[驴](驴.md)和[骆驼](骆驼.md)**
* 现在被玩家在水里骑乘时不再会下沉。

* *[鹦鹉螺](鹦鹉螺.md)**
* 冲撞攻击的冷却时间由2秒增加至4秒。
* 冲撞速度由10格/秒增加至14格/秒。
* 攻击力由-降低至。

* *[僵尸马](僵尸马.md)**
* 现在被玩家在水里骑乘时不再会下沉。
* 现在会生成于[雪原](雪原.md)和[冰刺之地](冰刺之地.md)。
* 现在会避开阳光。

* *[僵尸鹦鹉螺](僵尸鹦鹉螺.md)**
* 冲撞攻击的冷却时间由2秒增加至4秒。
* 冲撞速度由10格/秒增加至14格/秒。
* 将所有音效的音频分类由敌对生物更改为友好生物。
* 现在会主动攻击附近的[河豚](河豚.md)，而不是玩家。
* 现在会在被激怒时攻击激怒它的生物。
* 攻击力由-降低至。
* 装备[鹦鹉螺铠](鹦鹉螺铠.md)时不再会在阳光下着火。

# 修复
* *群骑纷争**
* 现在驯服的鹦鹉螺在陆地上死亡时会有正确的死亡消息。
* 鹦鹉螺被推到干燥的陆地上时不再会发出溅水声。
* 现在离开水的鹦鹉螺会发出受伤和死亡音效。
* 现在当提供食物时，鹦鹉螺会优先考虑繁殖而不是被吸引。
* 现在创造模式物品栏中的矛物品组会被标记为“Spears”而非“Spear”。（）
* 更新了下界合金矛的物品图标，以匹配其游戏内模型的颜色。（）
* 将物品标签重命名为，以匹配类似的标签。（）
* 调整了启用时矛的反射率。
* 修复了取消骑乘僵尸马时缺失提示文本的问题。
* 修复了僵尸马不会生成于雪原的漏洞。
* 修复了僵尸马的喂食音效不受友好生物音频设置影响的漏洞。
* 僵尸马现在使用普通马的喂食音效。
