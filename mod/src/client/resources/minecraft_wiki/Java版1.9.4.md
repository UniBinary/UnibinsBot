# Java版1.9.4

*页面ID: 21228* | *来源: Minecraft Wiki*

* *1.9.4**是的一次次要更新，发布于2016年5月10日<ref></ref>。此版本不兼容1.9到1.9.2的服务端，兼容1.9.3的服务端。

# 更改
# = 常规 =
* *警告**
* 移除了错误的快照版本警告。

# 修复
