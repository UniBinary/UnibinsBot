# 织布机

*页面ID: 36849* | *来源: Minecraft Wiki*

* *织布机（Loom）**是一种可以用来绘制[旗帜](旗帜.md)的[方块](方块.md)。

# 生成
# = 自然生成 =
织布机会自然生成在[村庄](村庄.md)的牧羊人小屋中。

织布机还会自然生成于[古迹废墟](古迹废墟.md)的部分结构中。

# 破坏
挖掘织布机的合适工具是斧。

织布机被破坏后会掉落自身。

# 用途

# = 绘制旗帜 =

按键可以打开织布机的操作界面。它有三个槽位，用于放置[旗帜](旗帜.md)、[染料](染料.md)和非必需的[旗帜图案](旗帜图案.md)。当玩家放入旗帜和染料，一个图案列表会出现在中间。制作以下10种图案必须放入旗帜图案：花朵盾徽、苦力怕盾徽、头颅盾徽、Mojang徽标、猪鼻、地球、砖纹、波纹边、涡流和旋风。放入旗帜图案将使列表仅显示其对应的图案。

鼠标悬浮在图案列表上时，将显示一个提示框，提示内容为将印上的图案名称。

如已放入染料并且在选择列表上已选择图案，右边会显示应用后旗帜的预览。在预览下方的槽中拿出旗帜来完成制作。原始旗帜和染料将从各自的槽中消失，但不会消耗旗帜图案。

# = 更改村民职业 =

如果一个织布机没有被[村民](村民.md)认领，则附近的任意一个失业村民有机会转变职业为[牧羊人](牧羊人.md)。

# = 燃料 =
织布机可以作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个织布机可以烧炼1.5个物品。
