* *实体之瓶（Bottle of Entity）**是饮用时将[玩家](玩家.md)[变身](变身.md)为特定[实体](实体.md)的饮品。

* *喷溅型实体之瓶（Splash Bottle of Entity）**是可投掷的实体之瓶。

* *虚空之瓶（Bottle of Void）**是可将玩家从非玩家实体[还原](变身#还原.md)的物品。

# 获取
非[生物](生物.md)实体的实体之瓶只能通过[命令](命令.md)获取。

# = 转化 =
手持虚空之瓶对着[生物](生物.md)后，其会转化为对应生物的实体之瓶。

启用规则后，[玻璃瓶](玻璃瓶.md)会返还虚空之瓶。

# = 酿造 =

与[药水](药水.md)类似，向实体之瓶中加入[火药](火药.md)能酿造对应的喷溅型实体之瓶。

# 用途
实体之瓶被饮用后会变为1个空玻璃瓶，并且不会返还任何物品。

虚空之瓶被饮用后不会返还任何物品。

# = 变身 =
饮用某种非玩家实体的实体之瓶会[变身](变身.md)为对应实体。

若使用的实体之瓶没有指定其对应的实体，则无法变身。

# = 还原 =
已变身的玩家虚空之瓶后，会受到点[虚空伤害](虚空伤害.md)，同时：
* 若玩家拥有[状态效果](状态效果.md)，会去除其拥有的某一状态效果，并获得带有所去除状态效果的[不可合成的药水](不可合成的药水.md)；
* 若玩家此前变身实体为非生物实体，其虚空之瓶会转化为猪之瓶；
* 若玩家因该虚空伤害从变身中脱离，其虚空之瓶会转化为猪之瓶；
* 否则，玩家形态会被[还原](变身#还原.md)，其虚空之瓶会转化为此前变身实体对应的实体之瓶。

# = 投掷 =
类似于[喷溅药水](喷溅药水.md)，喷溅型实体之瓶可以将其投掷出去，生成弹射物。

[发射器](发射器.md)也可以射出喷溅型实体之瓶。

喷溅型实体之瓶被投掷后会破裂而不会返还空瓶。

# 行为
喷溅型实体之瓶的行为类似于[喷溅药水](喷溅药水.md)，不同的是其不会向生物施加状态效果，而是将其作用范围内的生物[变身](变身.md)为对应的非玩家实体。

若使用的喷溅型实体之瓶没有指定其对应的实体，则无法变身。
