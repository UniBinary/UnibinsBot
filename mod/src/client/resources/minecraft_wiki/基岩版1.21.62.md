# 基岩版1.21.62

*页面ID: 145739* | *来源: Minecraft Wiki*

* *1.21.62**是的一次热修复更新，在除Nintendo Switch外的平台上发布于2025年2月25日<ref></ref>，在Nintendo Switch平台上发布于2025年2月26日，修复了一些漏洞。此版本与[1.21.60](基岩版1.21.60.md)和[1.21.61](基岩版1.21.61.md)相互兼容。

# 更改
# = 技术性 =
* *专用服务器**
* 为处于模式时的专用服务器公开了新参数。此参数会使服务器对实体交互更加严格。
* * 默认为false，可以设置为true。会影响实体交互接收。

* *游戏内容**
* 命令方块悬浮名称现在会在[命令](命令.md)生成的GUI消息中显示。（）

# 修复
* *游戏内容**
* 修复了在疾跑时跳跃时攻击生物会移除玩家所有动量的问题。（）
* 修复了有延迟的玩家在战斗时无法击中对方的问题。（）
* 修复了使用床后玩家的碰撞箱有时会变得不正确的问题。（）

* *用户界面**
* 现在在手持装有收纳袋的收纳袋的情况下尝试合成收纳袋时会正确合成出收纳袋，而不只是消耗合成材料。（）
* 修复了无法通过好友抽屉式菜单来加入Realm的问题。
