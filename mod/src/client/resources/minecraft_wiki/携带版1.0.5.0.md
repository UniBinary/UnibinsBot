# 携带版1.0.5.0

*页面ID: 28398* | *来源: Minecraft Wiki*

<onlyinclude>

* *alpha 1.0.5.0**是[1.0.5](携带版1.0.5.md)的首个测试版，发布于2017年3月10日<ref></ref>，加入了新命令、命令方块等内容，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[命令方块](命令方块.md)**
* 加入了所有种类的命令方块。

# = 物品 =
* *[命令方块矿车](命令方块矿车.md)**
* 显示为[循环型命令方块](循环型命令方块.md)。

# 更改
# = 物品 =
* *[青金石](青金石.md)**
* 现在青金石图标在[附魔台](附魔台.md)中显示正确。

# = 生物 =
* *[恶魂](恶魂.md)**
* 恶魂火球的精确度调整正确。

* *[岩浆怪](岩浆怪.md)**
* 跳跃范围改至正确的值。

# = 常规 =
* *辅助功能**
* 在储存管理器里的已输入文字上不会出现放大镜图标。

# 修复
* *修复了31个漏洞**
*  - 村民和友好生物会随机消失。<ref>
</ref>
*  - 将植物放进花盆里后，物品栏里的花不会立刻消失。
*  - 敌对生物会无视高度生成。
*  - 不死生物的行走音效错误。
*  - 玩家手持的信标朝向错误。
*  - 末影人没有空闲音效。
*  - 地牢或神殿里的附魔书生成不正确。
* 崩溃发生后，在区块边缘的生物会消失。
* 重新进入世界后玩家的位置偏移，使得玩家在方块里窒息。
* 带有实体目标的命令执行后游戏崩溃。
* 在试图分享之前分享过的文件时点击取消会使得游戏崩溃。
* 存储选项里单个项的分享按钮丢失。
* 玩家在存储选项里删除文件时游戏崩溃。
* 修复了一些与存储管理器有关的漏洞。
* 将着色后的植物放置在花盆上时，该植物的颜色出错。
* 聊天信息出现两次。
* 使用放置方块时，瞬间破坏这些方块会使得方块出现鬼影。
* 命令不会显示命令描述。
* 全局资源包在新建并进入游戏后被卸载。（仅Android和Fire TV版）
* 加载部分世界时游戏崩溃。
* 执行命令出错时游戏崩溃。
* 命令不能填充末地传送门方块。
* Xbox Live好友邀请弹窗不会显示。（仅iOS版）
* 在远离主机时，客户端会更改自己的世界选项。
* 如果输入光标在代码行末尾时，命令不会正确执行。
* 使用放置铁轨、床和可可果时会出现鬼影方块。
* Apple TV版里无法使用控制器来滚动屏幕。
* 在按下“选择新皮肤”按钮后游戏崩溃。（仅gear VR版）
* 导入资源包后会使得资源包消失。
* 更改Realms后游戏崩溃。
* 生物死亡后游戏崩溃。</onlyinclude>
