# 原主机版TU73、1.82、Patch 42

*页面ID: 62284* | *来源: Minecraft Wiki*

* *TU73/1.82/Patch 42**是[原主机版](原主机版.md)的一次更新，发布于2018年12月18日，修复了一些漏洞。<ref></ref>

# 新内容
# = 常规 =
* *混搭包**
* 加入了圣诞夜惊魂（The Nightmare before Christmas）混搭包。

# 修复
* *修复了3个漏洞**
* 修复了靠近雪的崩溃。
* 修复了教程关卡的屏障方块。
* 修复了TNT炸坏栅栏和潜影盒的崩溃。
