# 音乐唱片wait

*页面ID: 156612* | *来源: Minecraft Wiki*

* *wait**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的同名曲目。

# 获取
# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片wait。

# 用途
# = 音乐 =

[noicon](File:where are we now.ogg.md)

Wait是一首欢快的[Minecraft](Minecraft（音乐）.md)混音版乐曲，游戏内时长3分51秒。

乐曲始于一些安静的合成拉丁打击乐和软件合成器旋律，然后扩展成一首芯片音乐风格的歌曲。

# = 红石 =

音乐唱片wait放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为12的信号。
