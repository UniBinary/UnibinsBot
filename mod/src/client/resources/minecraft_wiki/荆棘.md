# 荆棘

*页面ID: 42228* | *来源: Minecraft Wiki*

* *荆棘（Thorns）**是一种用于[盔甲](盔甲.md)的[魔咒](魔咒.md)，能对攻击者造成反弹伤害。

# 获取

荆棘III附魔需要的[附魔等级](附魔等级.md)超过了30级，因此无法从[附魔台](附魔台.md)获取。

# 用途
受影响生物被攻击时，有<code>-{}-(*等级*×15)%</code>的概率对攻击者随机造成伤害。荆棘造成的伤害会产生击退，并且会被[护甲值](护甲值.md)和[保护](保护.md)减免，可以被盾牌抵挡。

盔甲耐久度除正常消耗外，在成功造成荆棘伤害时还会额外多消耗2点耐久度。若多个盔甲拥有此魔咒，则每一部位的盔甲会轮流进行荆棘伤害结算。荆棘生效带来的额外耐久度消耗会分别作用于生效荆棘的盔甲。[耐久](耐久.md)魔咒会正常减免这一耐久度消耗。

[监守者](监守者.md)的音波不会触发荆棘魔咒。<ref></ref>

如果[盔甲架](盔甲架.md)上的盔甲拥有荆棘魔咒，则会在玩家攻击盔甲架且未能破坏盔甲架时对玩家造成伤害。

玩家手持附有荆棘魔咒的物品（[附魔书](附魔书.md)除外）时，荆棘魔咒仍能生效。<ref></ref>
