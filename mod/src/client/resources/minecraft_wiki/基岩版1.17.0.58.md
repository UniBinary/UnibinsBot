# 基岩版1.17.0.58

*页面ID: 82830* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.17.0.58**是[基岩版1.17.0](基岩版1.17.0.md)的第9个测试版，发布于2021年5月20日<ref></ref>，修复了一些漏洞。

# 更改
# = 技术性 =
* *生物**
* 为组件加入了字段。
* * 如果该字段写有物品名称，则在调用任意时会返回该物品名称。类似于中的。

# 修复
* *滴水石锥**
* 钟乳石现在仅会从尖端开始滴落液体。
* 提高了钟乳石滴落水填充炼药锅的频率。
* 现在钟乳石在其上方块产生方块更新时会被破坏。

* *用户界面**
* 调整了设置界面的背景颜色。

* *图形**
* 修复了在旧世界中，玩家乘坐矿车向上看时可能会被矿车内部结构遮挡视线的漏洞。
* 放置于荧光物品展示框的地图不再会导致附近的物品一同变得增亮。

* *物品**
* 现在破坏荧光物品展示框或对其按下选取键会获得其自身。（）
* 现在使用高级选取方块功能时会保存选取方块的数据。（）
* 现在熔炉、烟熏炉或高炉在燃料耗尽时不会继续发光。（、）
* 修复了地图会以玩家为中心来创建的漏洞。（）
* 现在给幼年美西螈喂食热带鱼桶会返还一个铁桶。
* 现在放出过美西螈的铁桶可与其他铁桶堆叠。（）

* *游戏内容**
* 修复了存在大量下界传送门方块时传送门会破裂或导致崩溃的问题。（、）
* 修复了水下的岩浆块不会把生物往下拉的问题。（）

* *命令**
* 执行命令时，函数的坐标偏移不再会为函数的每个命令重新单独计算，而现在只会重新计算一次。（）

* *技术性**
* 修复了告示牌在放置时不会显示其保存的文本的问题。
* 过滤器又支持数据值了。</onlyinclude>
