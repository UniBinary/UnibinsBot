# 深板岩圆石

*页面ID: 79281* | *来源: Minecraft Wiki*

* *深板岩圆石（Cobbled Deepslate）**是一种用途类似于[圆石](圆石.md)或[黑石](黑石.md)的方块。

# 生成
# = 自然生成 =
深板岩圆石会大量生成于[远古城市](远古城市.md)中，也会生成于[试炼密室](试炼密室.md)的过道末端。

# 获取
# = 深板岩 =
没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[深板岩](深板岩.md)被破坏后会掉落1个深板岩圆石。

# 破坏
挖掘深板岩圆石的合适工具是镐。深板岩圆石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

深板岩圆石被破坏后会掉落自身。

# 用途
深板岩圆石可用于代替圆石来合成石质工具、酿造台和熔炉，也可以在[铁砧](铁砧.md)中修复石质工具。它还可以用来进一步合成[磨制深板岩](磨制深板岩.md)。
