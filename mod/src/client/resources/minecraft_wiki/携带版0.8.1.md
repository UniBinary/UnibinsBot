# 携带版0.8.1

*页面ID: 21269* | *来源: Minecraft Wiki*

* *v0.8.1 alpha**是[携带版](携带版.md)的一次次要更新，发布于2013年12月19日，修复了[v0.8.0 alpha](携带版0.8.0.md)中的一些漏洞与崩溃。

# 更改
* *[木炭](木炭.md)**
* 更改了木炭的纹理，以同步[Java版1.6.1](Java版1.6.1.md)。

* *[僵尸猪人](僵尸猪人.md)**
* 不再会在白天的阳光下燃烧。
