* *火球（Fireball）**是由[恶魂](恶魂.md)发射的[弹射物](弹射物.md)。

# 生成
[恶魂](恶魂.md)会向其攻击目标发射火球。

# 行为
火球是一种弹射物，可以触发[标靶](标靶.md)。

火球拥有不受重力影响的无限远的直线弹道。

火球可以被[弹射物](弹射物.md)（</ref>}}）或[玩家](玩家.md)使用[近战攻击](近战攻击.md)让它们偏离弹道。当两个火球相撞时，其中一个火球的移动会偏移到一个角度，而另一个会爆炸。

[盾牌](盾牌.md)在被使用时可以阻挡其有效角度内来袭的火球。

由恶魂发射的火球是匀速的，具有加速度的火球只能由[命令](命令.md)生成。

# = 造成伤害 =
火球在直接击中实体时，会对其造成伤害。与[小火球](小火球.md)不同，火球不会设置实体的剩余着火时间。<ref></ref>

火球命中实体造成的伤害同时属于[弹射物伤害](弹射物伤害.md)和[火焰伤害](火焰伤害.md)，并同时受到[弹射物保护](弹射物保护.md)和[火焰保护](火焰保护.md)的减免，也会被[抗火](抗火.md)效果无效化。

恶魂被玩家反弹的火球命中时，会受到的直接命中伤害，此伤害无视上述免疫效果。

# = 造成爆炸 =

火球在击中实体或方块时，会造成[爆炸威力](爆炸威力.md)为其实体数据<code>ExplosionPower</code>的[爆炸](爆炸.md)，默认为1。

火球造成的爆炸可以生成[火](火.md)。

火球仅在[游戏规则](游戏规则.md)为<code>true</code>才能造成可以破坏方块和生成[火](火.md)的爆炸。

承受1威力的火球爆炸的最低[爆炸抗性](爆炸抗性.md)为4.034（等价于1个[蜘蛛网](蜘蛛网.md)）。因此，火球无法摧毁爆炸抗性为6的[石头](石头.md)、[圆石](圆石.md)、[下界砖块](下界砖块.md)等石质方块。

# = 着火 =
火球默认是[着火](着火.md)的。着火的火球始终不会熄灭，穿过[雨](雨.md)或[水](水.md)时会保持着火，即使修改其实体数据<code>Fire</code>也不能将其熄灭。

即使不爆炸破坏方块，火球会点燃[TNT](TNT.md)，可以点燃熄灭的[营火](营火.md)，可以破坏其穿过的[细雪](细雪.md)。

# = 与方块交互 =
火球可以触发其击中的[标靶](标靶.md)，可以敲响[钟](钟.md)，但火球造成的[爆炸](爆炸.md)可能会将这些方块破坏。

火球可以激活[木质压力板](木质压力板.md)。火球可以触发[绊线](绊线.md)和[探测铁轨](探测铁轨.md)（探测铁轨需要使用[比较器更新感应器](Tutorial:比较器更新感应器.md)检测）。当火球穿过这些方块时，这些开关会保持开启状态。其他开关则不受火球的影响。由于火球不能像[箭](箭.md)或[三叉戟](三叉戟.md)一样插在方块上，通常很难开关保持长时间开启，且火球很容易炸毁这些开关。通过[命令](命令.md)生成的静止不动的火球会一直保持其位置的开关开启。
