# Java版Beta 1.5 02

*页面ID: 34283* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.5_02**是的一次服务端更新，发布于2011年4月20日，<ref></ref>修复了Beta 1.5_01的一些漏洞。Beta 1.5_01客户端可以连接到使用Beta 1.5_02服务端的服务器。<ref></ref>

# 修复
* *修复了2个漏洞**
* 游戏不再因为Beta 1.5_01中多人游戏的漏洞造成“internal server error”而崩溃。
* 玩家从工作台上取下物品时不再会显示“保存区块”的页面。</onlyinclude>
