# 基岩版1.2.14.2

*页面ID: 34106* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.2.14.2**是[基岩版1.4.0](基岩版1.4.0.md)的首个测试版，发布于2018年3月28日<ref></ref>，加入了许多[水域更新](水域更新.md)的特性，如新海洋、新的鱼、珊瑚、藏宝图和冰山，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[蓝冰](蓝冰.md)**
* 自然生成于冰山和封冻深海生物群系中。
* 会发出亮度为4的光。

* *[按钮](按钮.md)、[压力板](压力板.md)和[活板门](活板门.md)**
* 现在被拆分为所有木板的6种变种。

* *[珊瑚](珊瑚.md)**
* 自然生成于暖水海洋生物群系中。
* 只能放置于水中。
* 有失活变种，生成方式与功能和常规珊瑚相同。
* 可用附有[精准采集](精准采集.md)魔咒的工具开采获得。

* *[珊瑚块](珊瑚块.md)**
* 自然生成于暖水海洋生物群系中。
* 离开水会失活。
* 可用附有精准采集魔咒的镐开采获得，若是普通的镐则会掉落失活变种。

* *[珊瑚扇](珊瑚扇.md)**
* 自然生成于暖水海洋生物群系中。
* 有失活变种，生成方式与功能和常规珊瑚扇相同。
* 可放置在水下方块的顶部。
* 可用附有精准采集魔咒的工具开采获得。

* *[海带](海带.md)**
* 自然生成于海洋生物群系中。
* 只能放置于水中。
* 会生长至数个方块高。
* 拥有动态纹理。
* 可烧炼成干海带。
* 在物品栏中使用着独有的物品形式纹理。

* *[干海带块](干海带块.md)**
* 通过9个干海带合成。
* 可作为燃料，烧炼20个物品。

* *[海草](海草.md)**
* 自然生成于海洋、[河流](河流.md)和[沼泽](沼泽.md)生物群系中。
* 对着水下方块使用骨粉时会生成海草。
* 具有高海草变种。
* 拥有动态纹理。
* 颜色为深绿色。
* 海草在物品栏中使用着普通的[草](草.md)的纹理。

* *[水](水.md)**
* 新行为：
* * 水源方块可放置在大多数非固体方块内。
* * 流动的水仍不能流过非固体方块。
* * 方块可以放置在水下，而不会在其周围产生空气。

# = 物品 =
* *[鱼桶](鱼桶.md)**
* 用于填充或放置生物鱼。
* 河豚桶中的河豚是旧纹理的。
* [空桶](空桶.md)也可以转化为鱼桶。

* *[干海带](干海带.md)**
* 通过海带烧炼而得。
* 可用于合成干海带块。
* 可食用，回复点饥饿值。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了鳕鱼、鲑鱼、河豚和热带鱼刷怪蛋。
* * 有着像鱼卵一样的独有纹理。

# = 生物 =
* *[溺尸](溺尸.md)**
* 加入了幼年溺尸。

* *[鱼](鱼.md)**
* [鳕鱼](鳕鱼.md)
* * 自然生成于冷水、常规和温水海洋生物群系中。
* [河豚](河豚.md)
* * 仅自然生成于暖水海洋生物群系中。
* * 玩家靠近时会膨胀。
* * 会给予周围玩家中毒效果7秒。
* [鲑鱼](鲑鱼.md)
* * 自然生成于冷水、常规、冻洋和温水海洋及其变种生物群系中。
* [热带鱼](热带鱼.md)
* * 仅自然生成于暖水海洋及其深海变种生物群系中。
* * 有16种颜色和图案。

# = 世界生成 =
* *[海洋](海洋.md)**
* 加入了冷水、温水和暖水海洋及其深海变种。

* *[埋藏的宝藏](埋藏的宝藏.md)**
* 由一个战利品箱组成的结构。
* [藏宝图](藏宝图.md)可帮助玩家定位埋藏的宝藏。

* *[珊瑚礁](珊瑚礁.md)**
* 自然生成于暖水生物群系中。
* 珊瑚扇、失活的珊瑚和失活的珊瑚扇会作为珊瑚礁的一部分自然生成。

* *[冰山](冰山.md)**
* 自然生成于冻洋生物群系中。

* *[沉船](沉船.md)**
* 自然生成于海洋和[沙滩](沙滩.md)生物群系中。
* 包含1-3个战利品箱。
* 生成时可能会直立、侧立或倒立。
* 部分沉船中会生成[去皮木头](原木.md)。

* *[海洋峡谷](峡谷.md)**
* 自然生成于海洋生物群系中。

# 更改
# = 方块 =
* *[南瓜](南瓜.md)**
* 南瓜现在可以被修剪为雕刻南瓜。

# = 物品 =
* *[鱼](鱼.md)**
* 更改了[生鱼](生鱼.md)、[熟鱼](熟鱼.md)、[生鲑鱼](生鲑鱼.md)、[熟鲑鱼](熟鲑鱼.md)、[热带鱼](热带鱼（物品）.md)和[河豚](河豚（物品）.md)的纹理。

* *[拴绳](拴绳.md)**
* 现在可以连接到[船](船.md)上。

* *[铁轨](铁轨.md)**
* 现在可以放置在水下。

# = 生物 =
* *[溺尸](溺尸.md)**
* 现在溺尸的头部会在暗处发出不影响亮度等级的光。

# = 非生物实体 =
* *[物品](物品（实体）.md)**
* 物品实体现在会浮在水面上。

# = 游戏内容 =
* *[控制](控制.md)**
* 微调了游戏指针的定向运动，以获得更可预测的运动。

* *[商城](商城.md)**
* 在商城中加入了“购买内容”部分，以管理玩家已获取的所有内容。

# 修复
* *修复了7个漏洞**
* 优化了进入皮肤选择器以及应用资源包时的加载时间延迟。
* 现在玩家会在烹饪生鳕鱼并吃下熟鲑鱼后解锁“美味的鱼”成就。
* 现在钓鱼时有正确的概率获得1个墨囊。
* 在船上使用附魔击退的武器来攻击生物时，该生物不再总是会被向东击退。
* 被雪覆盖的树叶在禁用平滑光照时不再会渲染为红色。
* 现在连锁型命令方块在执行命令时，其毗邻的其他连锁型命令方块会按顺序执行命令。
* 修复了Gear TV上的“正在与服务器断开连接”提示会显示过大的问题。</onlyinclude>
