# 基岩版1.21.21

*页面ID: 125100* | *来源: Minecraft Wiki*

* *1.21.21**是的一次热修复更新，在除Windows和Nintendo Switch外的平台上发布于2024年8月14日<ref></ref>，在Windows平台上发布于2024年8月15日，在Nintendo Switch平台上发布于2024年8月20日，修复了一个漏洞。此版本与[1.21.20](基岩版1.21.20.md)相兼容。

# 修复
* 提高了连接到Realms的可靠性。
