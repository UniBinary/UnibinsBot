# 用途
# = 食物 =

手持兔肉煲按住键即可食用，每个兔肉煲可以回复。

吃完兔肉煲后会获得空[碗](碗.md)。

# = 狼 =
兔肉煲可以给驯服的[狼](狼.md)食用，回复的生命值，</ref>|be}}。然而和其他可以给狼吃的食物不同，兔肉煲不能加速幼年狼的生长，也不能用于繁殖，因此狼只有在生命值不满时才能食用兔肉煲。

# 你知道吗
* 如果兔肉煲的材料分开来吃，蘑菇用[蘑菇煲](蘑菇煲.md)的一半饥饿值来计算，这些材料共会恢复。如果不计算蘑菇，则会恢复。 因此，合成兔肉煲会导致饱和度的净亏损，不过吃兔肉煲比分开吃兔肉煲的材料要快得多。
