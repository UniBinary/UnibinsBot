# 基岩版1.19.0.28

*页面ID: 95554* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.0.28**（Xbox/Windows/Android）、**Preview 1.19.0.29**（iOS/iPadOS/Windows）、**Preview 1.19.0.64**（Xbox）是[基岩版1.19.0](基岩版1.19.0.md)的第4个测试版，发布于2022年4月28日<ref></ref>，加入了[唱片残片](唱片残片.md)和[音乐唱片](音乐唱片.md)*5*，调整了一些特性，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[唱片残片](唱片残片.md)**
* 一种残片物品，可以罕见地在[远古城市](远古城市.md)的战利品箱子中找到。

* *[音乐唱片](音乐唱片.md)**
* 加入了音乐唱片5，作者为[Samuel Åberg](Samuel Åberg.md)。
* * 只能通过9个唱片残片合成得到。

# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 加入了关于监守者的远程攻击的死亡消息。
* * “<玩家> 被一声尖锐的尖叫声摧毁了”
* * “<玩家> 在试图逃离 <玩家/生物> 时被一声尖锐的尖叫声摧毁了”

# 更改
# = 方块 =
* *[蛙明灯](蛙明灯.md)**
* 现在使用任何工具或徒手挖掘时都会掉落其自身。

* *[青蛙卵](青蛙卵.md)**
* 现在会被流动的水破坏。

* *[红树树叶](红树树叶.md)**
* 现在使用[剪刀](剪刀.md)挖掘时会掉落其自身。

* *[幽匿感测体](幽匿感测体.md)**
* 现在能够检测玩家使用[钓鱼竿](钓鱼竿.md)产生的振动。

* *羊毛[地毯](地毯.md)**
* 现在放置羊毛地毯时，其被放置、被破坏以及以物品形式掉落时所产生的振动会被减弱，与[羊毛](羊毛.md)一样。
* 羊毛地毯现在还可以减弱在其上面跑和跳跃所产生的振动。

# = 物品 =
* *[山羊角](山羊角.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

* *[运输矿车](运输矿车.md)、[TNT矿车](TNT矿车.md)和[漏斗矿车](漏斗矿车.md)**
* 现在它们的合成配方是无序的。

# = 生物 =
* *[悦灵](悦灵.md)**
* 加入了投掷物品的音效。

* *[潜影贝](潜影贝.md)**
* 现在免疫火焰伤害。

* *[行商羊驼](行商羊驼.md)**
* 现在可以使用[干草捆](干草捆.md)来繁殖。

* *[监守者](监守者.md)**
* 调整了监守者的远程攻击：
* * 现在无视[盾牌](盾牌.md)和[护甲值](护甲值.md)。
* * 造成的伤害由之前的（简单）、（普通）、（困难）减为（简单）、（普通）、（困难）。
* * 发动攻击的冷却时间由5秒减至2秒。
* * 现在玩家由此死亡时会显示特有的[死亡消息](死亡消息.md)。
* 现在死亡时会掉落1个[幽匿催发体](幽匿催发体.md)。
* 现在被弹射物分散注意力时，其激怒等级会相应增加。
* * 非频繁投掷会增加10，频繁投掷会增加30。

# = 技术性 =
* *常规**
* 改进了数据驱动方块的内容日志报错，以记录资源包、文件和方块标识符。
* 将BlockGeometryComponent中的字段限制为256字符。

* *图形**
* 恢复后的Xbox设备现在会使用之前初始化使用的值来重新初始化。

* *[Molang](Molang.md)**
* 现在手动渲染过程中会避免清除临时Molang变量。

# 修复
* *监守者**
* 监守者现在会对非箭类弹射物发出的振动做出响应。
* 监守者现在会被非箭类弹射物分散注意力。（）
* 监守者现在会被所有与其接触的生物激怒。（）

* *幽匿**
* 现在幽匿催发体和幽匿尖啸体拥有与Java版一致的爆炸抗性。（）
* 恢复了一些被错误移除的幽匿相关音效。（）
* 现在幽匿尖啸体的尖啸音效被正确划分至“方块”音效分类。（）
* 现在幽匿感测体的激活和取消激活音效被正确划分至“方块”音效分类。（）
* 被持有或放置于物品展示框中的幽匿尖啸体不再会在任何方块面上出现深度冲突。（）
* 活塞现在不能够推动幽匿尖啸体、幽匿感测体和幽匿催发体。（）
* 挖掘幽匿感测体时，其“卷须”部分附近不再会出现破坏动画。（）

* *红树**
* 骨粉不再能够无限催熟红树胎生苗。（）
* 红树胎生苗不再能在上方被阻挡时长成红树。
* 将合并至方块，并更改为使用悬挂方块状态。
* 紅樹林木塊或红树原木现在能够正确阻止树叶枯萎。（）
* 调整了红树的树叶部分以匹配Java版。
* 修复了红树长成后其树干不包含原木的问题。（）
* 修复了大部分红树类方块不会受到火焰影响的问题。
* 现在对着泥巴上除红树胎生苗外的树苗使用骨粉后，该树苗会长成结构完整的树。
* 现在使用剪刀破坏红树树叶后会掉落其自身。（）
* 现在可以使用红树类方块来合成营火和烟熏炉。（）

* *悦灵**
* 现在可以从悦灵手中拿走一个可堆叠物品，并将其添加至现有的物品堆叠。（）

* *青蛙**
* 青蛙不再会在泥巴上出现寻路问题，且泥巴暂时不再会使实体略微下陷。（）
* 修复了青蛙吞下史莱姆或岩浆怪时，其头部与嘴部出现深度冲突的问题。（）

* *蛙明灯**
* 蛙明灯现在在地图上拥有正常的颜色。（）
* 蛙明灯现在拥有正确的破坏时间。

* *游戏内容**
* 生物不再可以生成在按钮上。（）
* 紫水晶簇不再能够放置在幽匿尖啸体和其他顶部没有支撑的方块上，且现在可以按预期放置在底部有支撑的方块底部。（）
* 修复了未损坏的工具，如在铁砧上更改名称的镐，在首次使用时无法正确生效的问题。（）
* 现在运输矿车、漏斗矿车和TNT矿车的合成配方是无序的。
* 修复了在拥有伤害吸收效果的情况下受到巨大致命伤害时会出现卡死的问题。

* *原版趋同**
* 潜影贝现在免疫火焰伤害。（）
* 潜影贝现在会在载具中保存直立。（）
* 相对坐标负Y轴和X轴上存在其他潜影贝时，潜影贝不再会无法生成。

* *触摸控制**
* 玩家现在可以由移动方向滑动到跳跃，且在“经典”触摸控制方案下切换跳跃和潜行时不再会被打断。（）

* *图形**
* 修复了RTX世界中不会更新太阳方向的问题。（）

* *行商羊驼**
* 行商羊驼断开流浪商人的拴绳连接后不再会保持存在。（）

* *性能与稳定性**
* 修复了断开连接的玩家和村民进行最后一项交易时可能发生的崩溃。
* 修复了在iOS设备上位于村庄时可能发生的崩溃。

* *用户界面**
* 修复了熔炉、高炉、烟熏炉、附魔台、砂轮、酿造台、铁砧、信标和锻造台界面中，点击玩家物品栏左侧的深灰色区域时会错误丢弃物品的漏洞。
* 精选服务器的消息文本不再会居中处理。

* *命令**
* 为命令加入了语法。</onlyinclude>
