# Java版12w07b

*页面ID: 32329* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w07b**是[Java版1.2.1](Java版1.2.1.md)的第7个快照，发布于2012年2月15日<ref></ref>，修复了一些漏洞和崩溃。

# 修复
* *修复了3个漏洞**
* 修复了着火的方块时会破坏方块的问题。
* 修复了生物在y=255以上高度生成时发生的崩溃。
* 修复了多人游戏中绵羊的动画。</onlyinclude>
