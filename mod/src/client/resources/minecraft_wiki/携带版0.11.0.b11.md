# 携带版0.11.0.b11

*页面ID: 27885* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 11**是[v0.11.0 alpha](携带版0.11.0.md)的第11个测试版。

# 新内容
# = 物品 =
* *[工具](工具.md)**
* 在创造模式物品栏中加入了木质、石质、铁质、金质和钻石质的工具。

# 更改
# = 物品 =
* *[钓鱼竿](钓鱼竿.md)**
* 现在玩家可以正常在[第三人称视角](第三人称视角.md)抛出[钓鱼竿](钓鱼竿.md)了。

# = 生物 =
* *[狼](狼.md)**
* 现在可以给[狼](狼.md)喂食[腐肉](腐肉.md)。

# = 游戏内容 =
* *[皮肤包](皮肤包.md)**
* 调整了[皮肤包](皮肤包.md)。

* *[GUI](GUI.md)**
* 将连接指示器更改为显示能否可以连接到的点。

* *其他漏洞**
* 关闭服务器时游戏崩溃。
* 加入世界时游戏崩溃。
* 关闭无线网络连接时游戏崩溃。
* 切换世界时游戏崩溃。
* 修复了多人游戏下矿车和船的漏洞。
* 离开船后，钓鱼的按钮优先于上船按钮显示。
* 输出槽位为空时，熔炉仍会运作。
* 选中的语言不会居中展示。
* 创造模式下的玩家会在虚空中死亡。
* 修复了重新连接时搭乘船的漏洞。
* 玩家会生成在透明方块里。
* 修复了带有急迫效果时的挖掘速度。
* 修复了船的判定箱，使得玩家可以破坏船下方的方块和在船上钓鱼。</onlyinclude>
