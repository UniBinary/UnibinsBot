# 音乐唱片11

*页面ID: 156611* | *来源: Minecraft Wiki*

* *11**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的同名曲目。

# 获取
# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片11。

# 用途
# = 音乐 =

[noicon](File:11.ogg.md)

11是一首略微令人不安的唱片。

此张唱片记录了疑似一个人跑过或破坏石头方块的声音，伴随沉重的呼吸声，随后停下并使用打火石点火，咳嗽，翻页，之后随背景噪音的接近以紧促的步伐继续奔跑起来。发出的方块声音听起来像泥土和石头。可以一直听到这个人的挣扎声和诡异的背景音。在临近结尾的突然停止之前可以听到奇怪的吠叫声或风吹声，然后是放置泥土的声音。最后发出类似于坏掉的唱片发出的失真噪音，以安静的哔哔声、黑胶静电声和嘶嘶声结束。

# = 红石 =

音乐唱片11放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为11的信号。

# 你知道吗
* 音乐唱片11在数据值上存在许多巧合：它是游戏的第11张唱片，时长1分11秒，并会让[唱片机](唱片机.md)对[红石比较器](红石比较器.md)输出强度为11的信号。
* 如果将此唱片的ogg格式文件在音频编辑器中转换成频谱图，在结尾的杂音部分会显示疑似为[Steve](Steve.md)的脸和数字12418的图像。
* * 这段数字是一个视觉签名，因为“12”在十六进制中为C，与418相结合即为“C418”。
