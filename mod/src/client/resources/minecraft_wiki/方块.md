# 方块

*页面ID: 10550* | *来源: Minecraft Wiki*

[thumb|Minecraft主世界中最常见的几种方块](File:Blocks preview.png.md)
* *方块（Block）**是[Minecraft](Minecraft.md)世界里最基本的组成单位。

# 行为
[thumb|由多种方块组成的景观，能看到[[草方块](File:Forest beside Plains.png.md)、[树叶](树叶.md)等方块]]
在游戏中，存在由无数单元组成的[网格](wzh:立方体堆砌.md)，每个单元为1立方米，方块就存在于这些单元里。通常，一个单元内只能有一个方块，但[台阶](台阶.md)、[海龟蛋](海龟蛋.md)、[蜡烛](蜡烛.md)等方块是例外。

游戏内的环境由方块构成，玩家能以多种方式对其进行收集和利用。

[空气](空气.md)是一种特殊方块，无法被破坏，不阻挡移动，是没有方块时的替代物。它有两个变种：[洞穴空气](洞穴空气.md)和[虚空空气](虚空空气.md)。

部分方块能发出[光亮](亮度.md)，像[火把](火把.md)和[荧石](荧石.md)，不同方块的亮度有所不同。

大多数方块不受重力影响，例外的有[沙子](沙子.md)、[红沙](红沙.md)、[沙砾](沙砾.md)、[铁砧](铁砧.md)、[龙蛋](龙蛋.md)、[混凝土粉末](混凝土粉末.md)、没有支撑的[脚手架](脚手架.md)、、[可疑的沙子](可疑的沙子.md)和[可疑的沙砾](可疑的沙砾.md)。

方块被破坏后会发出相应的[声音](声音.md)和[粒子](粒子.md)，但以下情况除外：
* 方块受重力影响，且掉落到无效位置<ref></ref>
* 坠落或用到损坏的[铁砧](铁砧.md)（仅无粒子出现）<ref></ref>
* 方块被流体冲掉<ref></ref>
* 方块被其他方块占据其位置<ref></ref>
* [铁轨](铁轨.md)（所有种类）、[火把](火把.md)、[灵魂火把](灵魂火把.md)、[红石线](红石线.md)、[红石中继器](红石中继器.md)和[红石比较器](红石比较器.md)的支持方块被移除<ref></ref>
* [树叶](树叶.md)枯萎<ref></ref>

# 方块物品

* *[方块物品](方块物品.md)（Block Item）**是用于表示方块的一类[物品](物品.md)，可以为世界中的方块。

# 方块高度

大多数方块都是1×1×1格的正方体，但也有一些例外（如[台阶](台阶.md)和[楼梯](楼梯.md)），这类方块被称为不完整方块。

默认情况下，若两个相邻方块之间的高度差小于0.6（）格，生物无需跳跃就能直接[走上这个高度差](走上方块.md)。

# 纹理
绝大部分方块表面的纹理都是16×16像素的。大多数方块默认为一立方米大小，但它们能使用[模型](模型.md)来改变。

大多数方块的纹理是静态的，但[水](水.md)、[熔岩](熔岩.md)、[下界传送门](下界传送门（方块）.md)、[末地传送门](末地传送门（方块）.md)及[末地折跃门](末地折跃门（方块）.md)方块、[火](火.md)、[灵魂火](灵魂火.md)、[海晶灯](海晶灯.md)、[海晶石](海晶石.md)、[岩浆块](岩浆块.md)、[菌柄](菌柄.md)、[菌核](菌核.md)、[海草](海草.md)、[海带](海带.md)、[灯笼](灯笼.md)、[灵魂灯笼](灵魂灯笼.md)、[幽匿块](幽匿块.md)、[幽匿感测体](幽匿感测体.md)、[校频幽匿感测体](校频幽匿感测体.md)、[幽匿尖啸体](幽匿尖啸体.md)、[幽匿脉络](幽匿脉络.md)、点燃的[营火](营火.md)和[灵魂营火](灵魂营火.md)、、已充能的[重生锚](重生锚.md)、燃烧中的[高炉](高炉.md)及[烟熏炉](烟熏炉.md)、[切石机](切石机.md)、[萤火虫灌木丛](萤火虫灌木丛.md)和[命令方块](命令方块.md)的纹理是动态纹理。

通过使用[资源包](资源包.md)，玩家能够改变方块的纹理和分辨率，包括决定纹理是否为动态。资源包也能够使用[模型](模型.md)来改变方块的形状或使方块等比例缩放，不过二次方长度的尺寸通常效果比较好。

# = 技术性方块 =
技术性方块是指在游戏中的事件发生期间可用于各种目的的方块，或使用单独的命名空间ID以避免[方块状态](方块状态.md)的不必要组合。技术性方块通常没有对应的[方块物品](方块物品.md)，它们不能通过正常游戏获得，且大部分都不能通过[命令](命令.md)或者使用编辑器获得。部分技术性方块则可以使用物品栏编辑器或[附加包](附加包.md)来获得。
如果玩家获得技术性方块，它们的纹理通常是[26px](File:Missing Texture Block.png.md) [无效纹理](无效纹理.md)。
