# 基岩版1.13.0.15

*页面ID: 47760* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.13.0.15**是[1.13.0](基岩版1.13.0.md)的第8个测试版，发布于2019年9月19日<ref></ref>，加入了[角色创建器](角色创建器.md)，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[角色创建器](角色创建器.md)**
* 允许玩家以多种方式个性化定制自己的游戏角色，包括身体的大小和形状，及四肢、眼睛、嘴巴、发型发色、面部毛发和肤色的调整。
* * 包含100余种可免费调整的项目，另有一系列自定义饰品可供选购。
* 之前的自定义皮肤仍然可以在Windows 10和移动平台上导入。
* *辅助功能**
* 在辅助功能设置中添加了允许用户不自动启用“聊天文本转语音”的选项。

# 更改
# = 生物 =
* *[村民](村民.md)**
* 农民现在会出售[谜之炖菜](谜之炖菜.md)。（）

# = 常规 =
* *[主菜单](主菜单.md)**
* 将“成就”按钮和皮肤按钮整合并入新的“个人资料”按钮。

# 修复
* *修复了35个漏洞**<br>
* *崩溃/性能**
* 修复了游戏进行时的崩溃现象。
* 修复了食用或饮用单个物品后发生的崩溃。（）
* 修复了与动画相关的崩溃。
* 修复了使用自定义大小的立方体贴图的资源包时发生的崩溃。
* 修复了当远古守卫者攻击时可能发生的崩溃。（）
* 修复了在下载市场内物品时断网时可能发生的崩溃。
* 通过移除未使用的默认纹理来进一步改进优化。
* 刷怪笼和洞穴蜘蛛不再显示错误日志并导致游戏崩溃。（、和）

* *常规**
* 修复了无法应用自定义皮肤的问题。（）
* 在市场地图“旅行商人”里的Jillager角色现在可以正确更改职业。
* 在“辅助功能”设置中加入了新选项，允许用户在其平台启用时不会自动开启“文字转语音”，可以防止每次玩家重新开始游戏时意外开启屏幕阅读器。（）
* 免费的皮肤可以在设备之间正确漫游。

* *游戏内容**
* 在农民村民的交易选项里加入了谜之炖菜。（）
* 修复了配方书中缺少各种工具的问题。
* 现在食用紫颂果可以正常传送了。

* *生物**
* 修复了各种生物的头部动画，使它们在坐着、睡觉或进食时可以面向正确的方向。（和）
* 现在骑着掠夺兽的掠夺者会庆祝袭击的胜利。（）
* 调整了溺尸的生成规则，以防止存档中有大量溺尸存在。（）
* * 如果满足以下条件，溺尸会消失：玩家离开54个方块之外，溺尸在白天30秒内没有执行任何动作。
* 修复了熊猫动画和拴绳的位置。

* *方块**
* 屏障现在可以正常传输红石信号了。（）
* 被爆炸摧毁的树叶不再留下一个隐形方块。

* *物品**
* 损坏的鞘翅现在有正确的纹理。（）
* 鞘翅在使用时现在消耗耐久度。
* 紫颂果现在回到了正确的创造模式物品栏分类中。
* 半透明方块不会再完全不透明。（）

* *用户界面**
* 与图书管理员村民交易时，书现在会正确显示描述。（）
* 复了阻止聊天记录滚动的错误。

* *图形**
* 修复了云的阴影方向。（）
* 站立和游泳之间的动画过渡现在会更平稳。
* 修复了在分屏多人游戏时可能导致的UI闪烁的问题。
* 拴着生物的拴绳不再悬浮在空中。（）

* *命令**
* 使用命令放置的炼药锅现在有了正确的数据。

* *附加包和脚本引擎**
* 恶魂的“注视玩家”行为不再是硬编码了。
* 修复了具有标记的实体可以互相推入并穿过完整方块的问题。
* 自定义弹射物实体现在可以将其物理性质定义在一个数据包中，而不必覆盖其默认的行为。</onlyinclude>
