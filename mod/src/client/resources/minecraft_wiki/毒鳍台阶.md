* *毒鳍台阶（Toxifin Slab）**是一种土黄色扁形的[守卫者](守卫者.md)变种。

# 生成
[thumb|[[废土](File:Wasteland and toxifin.jpg.md)生物群系中的毒鳍台阶]]
毒鳍台阶生成于马铃薯维度的[废土](废土.md)生物群系中（不限亮度）。

[角斗场](角斗场.md)的水池中央会生成隐藏的毒鳍台阶[刷怪笼](刷怪笼.md)。

当被玩家或驯服的狼杀死时，毒鳍台阶会掉落。

# 行为

毒鳍台阶不会被[潮涌核心](潮涌核心.md)攻击。

[美西螈](美西螈.md)会主动攻击毒鳍台阶。

当毒鳍台阶被近战攻击时，不会像守卫者一样带有尖刺伤害，而是给予攻击者2秒[凋零](凋零.md)效果。

毒鳍台阶会主动攻击[玩家](玩家.md)。除[玩家](玩家.md)以外，毒鳍台阶并不会使用激光反击攻击它的生物（如铁傀儡），但它被近战攻击时仍会给予攻击者2秒[凋零](凋零.md)效果。

# = 生物族群 =

毒鳍台阶是水生生物。被具有[穿刺](穿刺.md)魔咒的武器近战攻击，或被具有穿刺魔咒的[三叉戟](三叉戟.md)弹射物命中时会受到额外的伤害。

# = 攻击 =

毒鳍台阶的激光不会直接造成伤害，但会在击中目标时对目标持续施加2秒的[中毒](中毒.md)效果。

# = 堆叠 =
[thumb|[[角斗场](File:toxifin stack.jpg.md)内堆叠的毒鳍台阶]]
毒鳍台阶可以骑乘在周围的其他毒鳍台阶上，就像堆叠在一起的台阶一样。2只堆叠的毒鳍台阶的碰撞箱的并恰相当于一个[守卫者](守卫者.md)的碰撞箱。

当若干只堆叠的毒鳍台阶的其中一只受伤时，其会从堆叠中脱离。
