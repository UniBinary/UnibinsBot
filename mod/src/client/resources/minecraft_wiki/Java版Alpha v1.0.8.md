# Java版Alpha v1.0.8

*页面ID: 32501* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.8**是的一次更新，发布于2010年7月19日<ref></ref>。加入了[牛](牛.md)、[牛奶](牛奶.md)和[皮革](皮革.md)，并更改了皮革[盔甲](盔甲.md)的[合成](合成.md)配方。

# 新内容
# = 物品 =
* *[皮革](皮革.md)**
* 牛[死亡](死亡.md)后掉落。

* *[牛奶](牛奶.md)**
* 目前无法获得。
* 暂时没有功能。

# = 生物 =
* *[牛](牛.md)**
* 死亡后掉落0-2个皮革。

# 更改
# = 物品 =
* *[皮革盔甲](皮革盔甲.md)**
* 皮革盔甲现在需要用皮革合成，而不是[羊毛](羊毛.md)。</onlyinclude>
