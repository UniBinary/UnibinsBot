# Java版Infdev 20100625-1917

*页面ID: 35974* | *来源: Minecraft Wiki*

<onlyinclude>
* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年6月25日，<ref></ref>此版本是一次[秘密更新](秘密更新.md)，加入了地牢、刷怪笼和鞍。此版本也被称作**秘密周五更新2**。

# 新内容
# = 方块 =
* *[刷怪笼](刷怪笼.md)**
* 在地牢中自然生成。
* 在它周围会不断生成[僵尸](僵尸.md)、[骷髅](骷髅.md)或[蜘蛛](蜘蛛.md)。
* 被破坏后不会掉落自身。

# = 物品 =
* *[鞍](鞍.md)**
* 一种功能性物品，自然生成在地牢的箱子中。
* 可以装备于[猪](猪.md)上，用于[骑乘](骑乘.md)猪。

# = 世界生成 =
* *[地牢](地牢.md)**
* 一种小型结构，内含有一个怪物刷怪笼和1/2个箱子。
* * 箱子里可能有[火药](火药.md)、[线](线.md)、[小麦](小麦.md)、[面包](面包.md)、[铁锭](铁锭.md)、[铁桶](铁桶.md)和马鞍，少数情况下还有[金苹果](金苹果.md)。</onlyinclude>
