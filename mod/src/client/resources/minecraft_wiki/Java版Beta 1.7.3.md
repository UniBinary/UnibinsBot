# Java版Beta 1.7.3

*页面ID: 32734* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.7.3**是的一次次要更新，发布于2011年7月8日，修复了上个版本的一些漏洞。<ref></ref>

# 修复
* *修复了8个漏洞**
* 修复了可以使用活塞复制方块的漏洞。
* 修复了在活塞前放置告示牌导致客户端崩溃，然后使得活塞被充能且告示牌被移除的问题。
* 被推动的冰块现在不会再产生水而破坏一切了。
* 动力铁轨现在不会在没有能量源的时候被充能了。
* 通过红石连接到活塞晶体管末端的活塞在能量消失时现在会正常关闭了。
* 门不再产生紫色粒子。
* 多人游戏中，被修改的客户端不能再编辑已放置告示牌上的内容了。
* 被活塞推动的画现在会正常掉落了。</onlyinclude>
