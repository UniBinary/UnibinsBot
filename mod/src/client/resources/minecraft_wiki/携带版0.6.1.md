# 携带版0.6.1

*页面ID: 21254* | *来源: Minecraft Wiki*

* *v0.6.1 alpha**是[携带版](携带版.md)的一次次要更新，在Android和Fire OS设备上于2013年1月31日发布<ref>http://web.archive.org/web/20130306041212/https://play.google.com/store/apps/details?id=com.mojang.minecraftpe</ref>，在iOS设备上于2013年2月2日发布<ref>https://web.archive.org/web/20130304210857/https://itunes.apple.com/us/app/minecraft-pocket-edition/id479516143?mt=8</ref>，修复了[0.6.0 alpha](携带版0.6.0.md)中的一些漏洞与崩溃。[树莓派版](树莓派版.md)基于此版本开发。

# 修复

* *其他**
* 砂岩、下界石英和石砖楼梯不再有随机纹理。
* 为下界石英楼梯加入了语言文件名。
