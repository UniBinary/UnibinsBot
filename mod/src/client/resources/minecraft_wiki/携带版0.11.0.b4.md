# 携带版0.11.0.b4

*页面ID: 28042* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 4**是[v0.11.0 alpha](携带版0.11.0.md)的第4个测试版，发布于2015年4月15日，加入了喝[牛奶](牛奶.md)去除[状态效果](状态效果.md)的机制，并修复了一些漏洞。

# 更改
# = 物品 =
* *[牛奶](牛奶.md)**
* 现在可以被饮用，且饮用后能消除所有状态效果。

# = 常规 =
* *版本号**
* 版本的名字现在包括测试版编号。

# 修复

* *其他漏洞**
* 第一人称模式下玩家的袖子错误显示。
* 药水的持续时间比实际时间长。
* 游戏菜单有关的漏洞。
* 玩家可以生成在高空。
* 玩家的生成朝向和生成速度错误。
* 使用粗体字时，聊天框信息渲染错误。
* 更改了加载和保存皮肤的方式。</onlyinclude>
