# 生物转化

*页面ID: 162166* | *来源: Minecraft Wiki*

* *生物转化（Mob conversion）**是适用于[AI生物](AI生物.md)的转化机制。

# 机制
生物转化允许一个生物转化为另一个生物，且允许转化前后的生物类型不同。

与自然[生成](生成.md)的生物相比，经转化生成的生物会继承原生物的部分实体数据，例如生物转化生成时会继承原生物的自定义名称。

技术上而言，生物转化并不是直接改变生物本体，而是先生成一个新的生物，待新生物继承原生物的部分实体数据后，再直接移除原生物，从而实现生物的“转化”。需要如此做，是因为一个已被实例化的生物的类型是不可被改变的，因此需要重新生成一个新的各方面都相同的生物来间接地实现。

因此尽管诸如[苦力怕](苦力怕.md)转化为闪电苦力怕等行为也发生了转化，但这种转化依赖于直接修改生物本体数据，而非此处的狭义上的生物转化。

下列生物可以进行生物转化：
* [哞菇](哞菇.md)被[剪刀](剪刀.md)修剪后转化为[牛](牛.md)。
* [猪](猪.md)被[闪电](闪电.md)击中后转化为[僵尸猪灵](僵尸猪灵.md)。
* [蝌蚪](蝌蚪.md)成长转化为[青蛙](青蛙.md)。
* [骷髅](骷髅.md)在[细雪](细雪.md)中转化为[流浪者](流浪者.md)。
* [猪灵](猪灵.md)和[猪灵蛮兵](猪灵蛮兵.md)在非[下界](下界.md)维度转化为僵尸猪灵。
* [疣猪兽](疣猪兽.md)在非下界维度转化为[僵尸疣猪兽](僵尸疣猪兽.md)。
* [尸壳](尸壳.md)在[水](水.md)中转化为[僵尸](僵尸.md)。
* 僵尸在水中转化为[溺尸](溺尸.md)。
* [村民](村民.md)被闪电击中后转化为[女巫](女巫.md)。
* 村民被僵尸类生物。}}击杀后转化为[僵尸村民](僵尸村民.md)。
* 僵尸村民被[治愈](僵尸村民#治愈.md)而转化为村民。

[史莱姆](史莱姆.md)与[岩浆怪](岩浆怪.md)死亡后分裂成小史莱姆和小岩浆怪的行为也属于生物转化。游戏会使原生物转化多次以实现分裂效果，如史莱姆分裂就是发生了多次大史莱姆到小史莱姆的转化。

# 属性继承
# = Java版 =
游戏内部将生物转化分为了**单生物（Single）**和**死亡时分裂（Split on death）**两种类型。此外生物转化时还有两个布尔参数**保留装备（Keep equipment）**和**保持可以捡起战利品（Preserve can pick up loot）**，控制着特定属性的继承。

如果转化类型是死亡时分裂转化，则生物转化前会尝试丢弃[乘客](乘客.md)和[拴绳](拴绳.md)数据，乘客将强制脱离骑乘，而拴绳会主动断开。

在转化过程中，新生物会继承原生物的下列实体属性，而其他实体属性会被忽略。

如果是僵尸村民与村民之间的转化，则游戏还会额外继承村民数据。
