# 启动器1.0

*页面ID: 49331* | *来源: Minecraft Wiki*

* *1.0**是一个2013年6月25日与26日分别发布的启动器版本，第一次发布没有记录关于此版本的更改，第二次发布关闭了Yggdrasil来解决登录错误的问题。

# 修复
*  - 在Mac上，即便把Java降级至Java 6，也无法运行演示版。
*  - 迁移后的账户无法登录1.0.1版本启动器。
