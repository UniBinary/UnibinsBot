* *Note Block Studio**（以前称为**Minecraft Note Block Studio**、**Minecraft Song Planner**）是一款Minecraft音乐编辑器。通过它，你可以制作复杂的[音符盒](音符盒.md)音乐，且无需任何红石知识。若无需将制作的音乐导入Minecraft，还能在软件内放置超过音符盒2个八度音域的音符。此外，软件提供自定义乐器和指定对应声音的选项。

该软件允许导入MIDI（Musical Instrument Digital Interface 乐器数字接口）文件和使用MIDI设备；导出[MCEdit](辅助程序与编辑器/地图工具#地图编辑工具.md) Schematic文件和NBT文件，这使得用MIDI语言编写任何歌曲成为可能，且能轻松导入[音符盒](音符盒.md)。

软件还支持将歌曲导出为MP3、WAV等音频文件，以及可供游戏内欣赏的数据包。

该软件可在[此处](https://opennbs.org/)下载。
