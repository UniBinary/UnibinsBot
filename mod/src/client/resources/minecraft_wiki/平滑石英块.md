# 平滑石英块

*页面ID: 156706* | *来源: Minecraft Wiki*

* *平滑石英块（Smooth Quartz Block）**是[石英块](石英块.md)制作的装饰性方块。

# 生成
平滑石英块不会生成在世界中。

# 破坏
挖掘平滑石英块的合适工具是[镐](镐.md)。平滑石英块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

雕纹石英块被破坏后会掉落自身。
