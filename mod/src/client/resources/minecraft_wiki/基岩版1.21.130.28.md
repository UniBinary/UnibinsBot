# 基岩版1.21.130.28

*页面ID: 171852* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.130.28**（ChromeOS/Android）、**Preview 1.21.130.28**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.130](基岩版1.21.130.md)的第7个测试版，发布于2025年11月18日<ref></ref>，修复了一些漏洞。

# 更改
# = 物品 =
* *[下界合金马铠](下界合金马铠.md)和[下界合金鹦鹉螺铠](下界合金鹦鹉螺铠.md)**
* 现在会提供10%的[击退抗性](击退抗性.md)。

# = 生物 =
* *[僵尸马](僵尸马.md)**
* 不再会在和平难度下生成。

# = 技术性 =
* *[基岩版编辑器](基岩版编辑器.md)**
* 修复了尝试将方块移出世界的边界时，编辑器会卡死的问题。

* *图形**
* 更新了iOS和Android平台上支持的设备，包括对Adreno 700系列的额外支持。（）
* 修复了“”选项可能导致启动时发生崩溃的问题。（）

* *世界生成**
* 现在带有组件的方块会在世界生成期间被拼图结构放置时更新。

# 修复
* *群骑纷争**
* 现在下界合金马铠会提供0.1的击退抗性。（）
* 现在下界合金鹦鹉螺铠会提供0.1的击退抗性。（）

* *档案**
* 移除了Windows平台上的用户档案屏幕中非预期的退出登录按钮。玩家应通过Xbox应用程序来退出登录。（）

* *文本输入**
* 修复了输入法的候选词会在显示器上错误显示或相对于文本框错位的问题。</onlyinclude>
