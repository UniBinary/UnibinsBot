# 基岩版1.19.0.32

*页面ID: 96030* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.0.32**（Xbox/Windows/Android）、**Preview 1.19.0.33**（iOS/iPadOS/Windows）、**Preview 1.19.0.66**（Xbox）是[基岩版1.19.0](基岩版1.19.0.md)的第6个测试版，发布于2022年5月12日<ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[设置](设置.md)**
* 在设置中加入了“通知持续时间”选项。
* * 用于修改游戏通知的持续时间，默认为3秒。

# 更改
# = 技术性 =
* *GameTest框架（实验性）**
* 更新了专用服务器以允许服务器在加载脚本时明确列出需要加载的脚本模块。
* * 默认配置文件位于。若缺失该新文件，所有脚本模块在默认情况下都会被禁用。

# 修复
* *悦灵**
* 悦灵现在暂时不会跟随其主人一同传送至下界。（）
* * 这只是一个临时更改，该特性会在悦灵有时会传送至方块内或在切换维度时窒息的问题被修复后恢复。

* *方块**
* 非自然生成的幽匿尖啸体现在具有激活冷却时间，如同自然生成的幽匿尖啸体。（）
* 使用精准采集附魔工具挖掘幽匿尖啸体或幽匿感测体时，其不再会掉落经验。（、）
* 提高了破坏强化深板岩的所需时间，并使其不再受工具影响，以近似匹配Java版。（）
* 幽匿块上不再能蔓延火或灵魂火。

* *红树林沼泽**
* 在Y坐标为负数处的红树现在能够正常生长。（）

* *图形**
* 修复了一些Android平台上的图形损坏问题。（）
* 修复了多次使用表情时可能会出现的严重视觉问题。（）

* *移动**
* 现在使用移动预测的活动对象又能够顺利传送了。

* *性能与稳定性**
* 提升了部分Android设备上的游戏性能。（）
* 修复了尝试渲染依赖于生物群系数据的方块时可能发生的崩溃。

* *用户界面**
* 现在按住键并点击一个物品时，相同物品又会被组合至同个堆叠中。（）

* *技术性**
* 修复了当命令方块将另一个命令方块复制到自身位置上时，复制出的命令方块不会在更换红石信号之前执行命令的行为问题。</onlyinclude>
