# Minecraft Live 2021

*页面ID: 89305* | *来源: Minecraft Wiki*

* *Minecraft Live 2021**是一场线上直播活动，于2021年10月16日16:00（UTC）举行。该场直播公布了[荒野更新](荒野更新.md)，同时按照往年的惯例举行了新一轮生物投票，最终[悦灵](悦灵.md)胜出。<ref></ref><ref></ref>

# 公告
此次直播活动最初透露于Minecraft的官方YouTube频道发布的视频“*Caves & Cliffs Special: Looking Forward*”（洞穴与山崖更新特辑：展望未来）当中。[Agnes Larsson](Agnes Larsson.md)在视频中谈到洞穴与山崖之后的更新内容会在Minecraft Live 2021上公布。

# 预告
# = Minecraft Live 2021: 预告片 =
官方之后在2021年9月2日发布预告视频，正式公布此次活动。

# 活动
# = 社区预热 =
在主要活动开始前有30分钟的社区预热活动，此活动分享了世界各地YouTuber的Minecraft视频。

# = 开发相关 =
直播活动开头分享了[洞穴与山崖](洞穴与山崖.md)更新的开发历程和社区积极参与反馈的重要作用，开发人员承诺此次主要更新的第二部分将会优化世界中新旧区块之间的过渡，并宣布在开发版本中近似匹配了[Java版](Java版.md)和[基岩版](基岩版.md)中相同值的[世界种子](世界种子.md)的地形。

# = 社区相关 =
直播中演示了如何通过[Blockbench](https://blockbench.net/)来进行游戏模型创作，并且介绍了世界各地的学生如何通过Minecraft[教育版](教育版.md)来了解文化。

# = 版本公告 =
本次直播公布了Minecraft下一次主要更新（1.19）的主题“[荒野更新](荒野更新.md)”（The Wild Update），展示了[深暗之域](深暗之域.md)生物群系和[幽匿](幽匿.md)系列方块的开发进展（同时也实质上宣布了这部分内容实装的顺延），并宣布将加入在[MINECON Live 2019](MINECON Live 2019.md)的生物群系投票中淘汰的[沼泽](沼泽.md)生物群系相关特性：[青蛙](青蛙.md)、[红树](红树.md)和[运输船](运输船.md)等。除此之外还公布了[Minecraft Dungeons](Minecraft Dungeons.md)的[季节性冒险](MCD:赛季.md)相关内容。

直播中还宣布[Java版](Java版.md)和[基岩版](基岩版.md)将于2021年11月共同加入到。

# = 生物投票 =
[缩略图|右|生物投票的logo](File:Mob vote logo.png.md)
[缩略图|右|生物投票的3个选项](File:MCLive2021MobVoteAllOptions.png.md)
[缩略图|右|[[悦灵](File:Winner of Mob Vote 2021.gif.md)最终在投票中胜出]]

直播期间，观众可在Minecraft的官方Twitter上投票选出一个生物加入到游戏，该次投票是自[MINECON Earth 2017](MINECON Earth 2017.md)以来的第3次生物投票活动。

以下为3个候选生物的信息：
; [32px](File:GlarePixel.png.md) 怒目怪（Glare）<ref></ref>
* 一种出现于暗处的悬浮生物。
* 身体覆盖着绿色植被，面部只露出双眼。
* 会飞向光照等级可支持怪物生成的区域，并逐渐变得暴躁，以警示玩家。
; [32px](File:AllayPixel.png.md) [悦灵](悦灵.md)（Allay）<ref></ref>
* 一种小巧的蓝色飞行生物。
* 长有与[恼鬼](恼鬼.md)相似的双翼。
* 会被[音符盒](音符盒.md)的乐声吸引，也会随着音乐起舞。
* 若玩家给出某种物品，它会在已加载的区块中寻找其他相同或相似的掉落物，并将其放在玩家或音符盒的附近。
; [32px](File:CopperGolemPixel.png.md) [铜傀儡](铜傀儡.md)（Copper Golem）<ref></ref>
* 一种全身由铜组成的生物。
* 头顶有一根[避雷针](避雷针.md)形的天线，可以吸引[闪电](闪电.md)。
* 类似于[铜块](铜块.md)，其身体会随时间缓慢生锈。
* * 完全氧化时将无法移动。
* * 可对其[斧](斧.md)来除锈。
* 似乎可使用[铜锭](铜锭.md)制作，或是通过按指定方式摆放铜块来召唤。
* 会随机按下附近的铜质[按钮](按钮.md)。
* * 若铜傀儡在投票中胜出，铜质按钮也会与其一同加入到游戏中。
* 尽管没有赢得生物投票，其仍于[铜器时代](铜器时代.md)被加入，不过其功能被更改。
