# 附魔书

*页面ID: 9377* | *来源: Minecraft Wiki*

* *附魔书（Enchanted Book）**是用来给特定物品添加[魔咒](魔咒.md)的[物品](物品.md)。

# 获取
# = 箱子战利品 =

# = 钓鱼 =
附魔书可以作为“宝藏”物品通过[钓鱼](钓鱼.md)获得。附魔概率与附魔台上的30级附魔相同，但包含宝藏魔咒（灵魂疾行、风爆与迅捷潜行除外）且多重附魔的概率没有削减。

# = 交易 =

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家1本随机等级的[灵魂疾行](灵魂疾行.md)附魔书。

# = 掉落 =

# = 附魔 =
[缩略图|一本附有多个高级魔咒的附魔书](File:Enchanted Book 4x.png.md)
[缩略图|一本附有多个高级魔咒的附魔书。所有魔咒可以应用到同一个物品上](File:Similar enchantments.png.md)

玩家可以在[附魔台](附魔台.md)给[书](书.md)附魔来制作附魔书。一本书获得多重附魔的概率较低，因为将要生成多个魔咒时会随机移除其中一个，并且书附到的魔咒的等级比大多数物品低。宝藏魔咒无法从附魔台获得。

# 用途
附魔书拥有[光效](光效.md)。

# = 储存魔咒 =

附魔书的标志性功能是存储魔咒。

附魔书在其[物品堆叠组件](物品堆叠组件.md)<code>stored_enchantments</code>而非<code>enchantments</code>中存储魔咒，在<code>enchantment_glint_override</code>组件中储存光效。这意味着附魔书实际上并不具有魔咒，其存储的魔咒均不会生效。例如，存储了[锋利](锋利.md)的附魔书不会增加[近战攻击](近战攻击.md)的魔咒攻击力，持有存储了[时运](时运.md)的附魔书不能增加[挖掘](挖掘.md)的方块的掉落物。

附魔书以类似其他附魔物品的方式存储魔咒，这意味着附魔书具有魔咒。这导致许多魔咒都会在附魔书上生效：具有[火焰附加](火焰附加.md)的附魔书可用于点燃[TNT矿车](TNT矿车.md)，具有[风爆](风爆.md)的附魔书可用于产生[风爆效果](爆炸#风爆.md)。

# = 铁砧操作 =

附魔书唯一的设计用途是在[铁砧](铁砧.md)上作为牺牲物品使用，从而为另一个物品（可以是附魔书）添加魔咒和升级魔咒。在铁砧上使用后，附魔书会消失。

在生存模式中，在铁砧上消耗附魔书是为不能在[附魔台](附魔台.md)上[附魔](附魔（物品修饰）.md)的物品（如[剪刀](剪刀.md)、[盾牌](盾牌.md)）添加魔咒的唯一方式。

# = 祛魔 =
在[砂轮](砂轮.md)上将附魔书祛魔会移除其上所有非诅咒魔咒，如果魔咒被全部移除，附魔书会变为普通的[书](书.md)。

# = 雕纹书架 =
手持附魔书对[雕纹书架](雕纹书架.md)按键可将附魔书放入其中。
