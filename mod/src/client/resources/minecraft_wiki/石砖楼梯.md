# 石砖楼梯

*页面ID: 44284* | *来源: Minecraft Wiki*

* *石砖楼梯（Stone Brick Stairs）**是[石砖](石砖.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
石砖楼梯会自然生成于主世界的[废弃传送门](废弃传送门.md)、[要塞](要塞.md)和寒带[海底废墟](海底废墟.md)中。

# 破坏
挖掘石砖楼梯的合适工具是镐。石砖楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

石砖楼梯被破坏后会掉落自身。
