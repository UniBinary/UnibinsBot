=== 实体 ===
*  - 由[恶魂](恶魂.md)生成的弹射物实体。
*  - 由[发射器](发射器.md)使用[火焰弹](火焰弹.md)生成或由[烈焰人](烈焰人.md)生成的弹射物实体。
*  - 由[末影龙](末影龙.md)生成的弹射物实体。

# = 物品 =
*  - 用于生成火的物品，可以被[发射器](发射器.md)以小火球形式发射。

# = 魔咒 =
*  - 用于给近战武器造成着火的魔咒。
*  - 用于给弓造成着火的魔咒。
*  - 用于盔甲的魔咒，能减少火焰伤害。

# = 状态效果 =
*  - 用于免疫火焰伤害的效果。

# = 游戏机制 =
*
* [着火](着火.md)

# = 游戏规则 =
* 或 - 用于控制火焰蔓延的游戏规则。
*  - 决定玩家是否免疫火焰伤害的游戏规则。

# Minecraft Dungeons
# = 物品 =
*  - 装备后可以发射燃烧的箭的法器。
*  - 虚空回响中的消耗品，可获得燃烧效果。

# = 魔咒 =
*  - 在自身周围生成一个火环并对在火环范围内的生物造成火焰伤害的魔咒。
*  - 可以点燃被攻击生物的魔咒。
*  - 可提高玩家造成的火焰伤害的魔咒。
*  - 可点燃玩家经过的位置并给踏入其中生物造成伤害的魔咒。
