# Java版Classic服务器1.8.2

*页面ID: 45315* | *来源: Minecraft Wiki*

* *1.8.2**是[1.8](Java版Classic服务器1.8.md)的一个漏洞修复版本，发布于2009年6月20日21:09（UTC）。<ref> – 这篇博文中提到了修复玩家能够破坏不可破坏的方块的问题，在[IRC记录](#logs.md)也同样提及： "*P4:09:25 <Notch> new minecraft-server.zip that doesn't allow that block*" (21:09:25 UTC).</ref>

尽管从[0.24](Java版Classic 0.24 SURVIVAL TEST.md)至[0.27](Java版Classic 0.27 SURVIVAL TEST.md)的版本可以连接到该服务器，但由于服务器上缺乏对生存模式的支持从而无法正常工作。

# 修复
* *修复了1个漏洞**
* 修复玩家能够破坏不可破坏的方块的问题。
