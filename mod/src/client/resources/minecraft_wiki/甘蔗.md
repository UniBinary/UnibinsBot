# 甘蔗

*页面ID: 9091* | *来源: Minecraft Wiki*

* *甘蔗（Sugar Cane）**是一种生成于[主世界](主世界.md)水体附近的植物。

# 生成
甘蔗能够生成甘蔗（见）。

# = 自然生成 =
[缩略图|250px|在岸边自然生成的甘蔗](File:Sugar Canez.png.md)

甘蔗可以在[水](水.md)的附近自然生成，它有2（的概率），3（的概率）或4（的概率）格高。若游戏选择在已生成的甘蔗上生成另一个甘蔗，则会出现稀有的高甘蔗。

甘蔗会尝试在主世界上的所有生物群系生成10次，生成处附近需要有水（寒冷群系则需要有冰）。在沼泽生物群系会追加10次的生成机会，在沙漠生物群系会追加50次的生成机会，不过沙漠群系中除了偶然生成的湖以外水资源十分稀少，因此在沙漠湖岸有时候能够发现较多自然生成的甘蔗。

# 破坏
甘蔗被挖掘时会立刻被破坏。

甘蔗被破坏后会掉落自身。

# 用途
甘蔗不会被水冲走，且能够放置在水中。由于甘蔗不能含水，放置在水中时可为玩家提供氧气。<ref></ref>

甘蔗的颜色取决于它处在的生物群系。

当甘蔗的位置变得不合适时，例如当移除支撑方块时，甘蔗会被破坏并作为物品掉落。当所有相邻的水均被移除时，甘蔗不会立刻破坏，而是在下次接收到[PP更新](PP更新.md)或[随机刻](随机刻.md)时被破坏。

# = 种植 =

[200px|缩略图|一个地下甘蔗农场](File:Underground Sugar Farm.png.md)
甘蔗只能种植在其他甘蔗顶部或满足以下条件的位置：
* 下方方块是[沙子](沙子.md)、[红沙](红沙.md)、[可疑的沙子](可疑的沙子.md)、[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)或[苍白苔藓块](苍白苔藓块.md)
* 下方方块毗邻[水](水.md)、[含水方块](含水方块.md)或[霜冰](霜冰.md)

# = 生长 =

甘蔗只能生长到3格高。顶部甘蔗累计收到16个随机[刻](刻.md)（即平均每18分钟<!--平均68.27秒/刻*16刻/增长=18.2分钟-->，但实际速率可能有较大差异）后会生长一格甘蔗。

[骨粉](骨粉.md)可以加速甘蔗的生长，对Y=0以下的甘蔗骨粉可使其高度超过3格。<ref></ref>

无论[亮度](亮度.md)等级如何，甘蔗都能生长。

# = 堆肥 =
将甘蔗放入[堆肥桶](堆肥桶.md)中有50％的概率将堆肥层数增加1。
