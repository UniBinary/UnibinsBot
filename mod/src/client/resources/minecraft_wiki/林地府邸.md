* *林地府邸（Woodland Mansion）**是一种非常罕见的大型[结构](结构.md)，仅能在[黑森林](黑森林.md)和[苍白之园](苍白之园.md)中生成。

# 生成
林地府邸会非常罕见地在黑森林和苍白之园中生成，通常分布在距离[出生点](出生点.md)上千格甚至更远的位置。

林地府邸可通过[林地探险家地图](林地探险家地图.md)定位。与制图师[村民](村民.md)进行交易可获得林地探险家地图，详见。

# 结构

林地府邸是随机生成的，不同林地府邸的内部结构会有所差异。所有林地府邸都有下列共同之处：它们都有2-3层，每层都包含各式各样的房间，且整个结构都生成于[圆石](圆石.md)地基上。顶层的面积不到下面几层的一半。所有林地府邸中都有一个连接着迷宫走廊的大门厅。

# = 结构目录 =
林地府邸的结构以NBT文件的形式存储在<samp>[client.jar](client.jar.md)/data/minecraft/structure/woodland_mansion</samp>或<samp>data/behavior_packs/vanilla/structures/mansion</samp>中。下表罗列了林地府邸中可能出现的所有房间，还有它们的名称和具体描述。

# = 生物 =
每个林地府邸自然生成时，其一些特定的房间里会生成[唤魔者](唤魔者.md)、[卫道士](卫道士.md)以及[悦灵](悦灵.md)，并且只能生成一次。生成的数量取决于房间种类（数据在下文[房间类型](#房间.md)中列出）。

林地府邸内部的大部分空间非常黑暗，因此常规的[敌对生物](敌对生物.md)（如[僵尸](僵尸.md)、[骷髅](骷髅.md)和[苦力怕](苦力怕.md)）会在这里正常生成。

# = 房间 =
林地府邸有许多不同类型的房间，但其内部布局是随机生成的，所以并不一定所有类型的房间都会出现在同一个林地府邸内。而且并非所有的房间都能自由出入，因为有些房间的入口被封死了，有些则根本没有入口。

# 你知道吗
* 带有林地府邸的[苍白之园](苍白之园.md)生物群系的稀有程度比[蘑菇岛](蘑菇岛.md)生物群系的稀有程度还要高。
* 组成林地府邸的大部分方块是可燃的，所以只要在林地府邸内点[火](火.md)或倒[熔岩](熔岩.md)，火势可能不可避免地蔓延到整个建筑且难以扑灭。
* * 有些林地府邸在生成时临近熔岩湖，这可能导致其自燃。
* 在直楼梯房、弯曲的楼梯间、灾厄村民头画像房、灾厄村民雕像房中所设计的灾厄村民图像的眉毛与所有[灾厄村民生物](灾厄村民.md)斜上分开的眉毛造型不同，反而是像[村民](村民.md)一样的连心眉。
* 根据伪末地传送门房的设计逻辑，熔岩房的内部可能是个仿照[末地水晶](末地水晶.md)或[信标](信标.md)的雕像，底部铺有[黑曜石](黑曜石.md)、底座上方[玻璃](玻璃.md)包裹着内核心是共通点。
