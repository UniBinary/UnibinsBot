# 队伍

*页面ID: 123997* | *来源: Minecraft Wiki*

* *队伍（Team）**是由[记分板](记分板.md)系统管理的一套游戏机制，可将游戏内的[实体](实体.md)进行分组并对其整体添加属性。

# 用途
队伍仅能通过命令进行创建、删除和修改，因此一般被地图创作者和服务器管理员用于让一些玩家或生物形成联合的整体。

一个队伍由若干成员实体组成，一个实体仅能属于一个队伍，多个队伍不能共享成员。

# = 实体行为影响 =
生物处于队伍时，攻击行为的目标选择会有改变：
* 有主动攻击行为的生物不会主动攻击所属队伍内成员；
* [远古守卫者](远古守卫者.md)不会对所属队伍内成员施加[挖掘疲劳](挖掘疲劳.md)效果；
* [监守者](监守者.md)不会对所属队伍内成员施加[黑暗](黑暗.md)效果；
* [重锤](重锤.md)的攻击对攻击者所属队伍内成员不产生击退效果；
* [山羊](山羊.md)不会冲撞所属队伍内成员；
* [嘎枝](嘎枝.md)不会因被队伍成员看到而驻足；
* [潜影贝](潜影贝.md)位于一个队伍中时，会主动攻击任何不在同一队伍中的除[恶魂](恶魂.md)外的所有敌对生物。

玩家仍然可以对同队伍内的其他成员发动攻击。

属性<code>friendlyFire</code>为<code>false</code>的队伍中的实体会免疫来源为队伍内成员的伤害。

# = 命令 =

可以在目标选择器中使用参数“team”检查实体是否属于给定队伍，在名称前加上“!”可检查是否不属于给定队伍，若队伍名称留空则会检查是否属于任意队伍。

同一队伍内的成员可以使用进行队伍内沟通，该命令的权限等级要求为1，因此默认情况下所有玩家都能使用。
