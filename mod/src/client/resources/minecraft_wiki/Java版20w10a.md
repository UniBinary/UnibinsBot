# Java版20w10a

*页面ID: 55875* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w10a**是[Java版1.16](Java版1.16.md)的第5个快照，发布于2020年3月4日<ref name="20w10a"></ref>，为[锻造台](锻造台.md)引入了实际功能，加入了[菌核](菌核.md)、新的方块标签和下界[环境音效](环境音效.md)，更改了一些物品/方块的纹理，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[菌核](菌核.md)**
* [菌柄](菌柄.md)的变种，6面都有菌皮。
* 也有去皮变种。

# = 常规 =
* *[环境音效](环境音效.md)**
* 为[下界](下界.md)加入了95个新环境音效。
* * 每种下界生物群系都会各自播放不同的环境音效。

* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 应用于[诡异菌](诡异菌.md)。
* * 并未应用于诡异菌盆栽。
* * [疣猪兽](疣猪兽.md)会躲避应用该标签的方块。
* 加入了方块标签。
* * 应用于[灵魂火](灵魂火.md)、[灵魂火把](灵魂火把.md)和[灵魂灯笼](灵魂灯笼.md)。
* * [猪灵](猪灵.md)会躲避应用该标签的方块。

# 更改
# = 方块 =
* *[绯红菌索](绯红菌索.md)**
* 修改了其物品栏纹理。

* *[哭泣的黑曜石](哭泣的黑曜石.md)**
* 现在在Programmar Art资源包中使用2011年的旧纹理。

* *[火](火.md)**
* 现在拥有正常的碰撞箱（[方块](方块.md)）。
* 现在拥有被破坏时的动画效果。
* 类似于其他方块，不再能被创造模式下的[剑](剑.md)或[三叉戟](三叉戟.md)熄灭，可以使用[调试棒](调试棒.md)进行调整。

* *[下界苗](下界苗.md)**
* 更改了纹理。

* *[侦测器](侦测器.md)和[红石块](红石块.md)**
* 现在可以在其上放置[梯子](梯子.md)和[绊线钩](绊线钩.md)。

* *[锻造台](锻造台.md)**
* 加入了实际功能：可将钻石质物品升级为下界合金质物品。
* * 由于移除了下界合金质工具和盔甲在[工作台](工作台.md)中的合成配方，其现已成为打造下界合金质装备的唯一途径。
* * 钻石质物品原有的[魔咒](魔咒.md)会在升级到下界合金质后得到保留。

* *[灵魂火](灵魂火.md)**
* 现在拥有正常的碰撞箱（格）。
* 类似于其他方块，不再能被创造模式下的[剑](剑.md)或[三叉戟](三叉戟.md)熄灭。

* *[标靶](标靶.md)**
* 现在可以在其上放置[梯子](梯子.md)和[绊线钩](绊线钩.md)。
* 现在是可燃的了。
* 现在被[活塞](活塞.md)或[黏性活塞](黏性活塞.md)推动后不会保持激活状态了。
* 现在被[末影珍珠](末影珍珠.md)和[附魔之瓶](附魔之瓶.md)击中时也会发出红石信号。

* *[诡异菌](诡异菌.md)**
* 修改了其物品栏纹理。

# = 物品 =
* *[锄](锄.md)**
* 现在可以附上[效率](效率.md)、[时运](时运.md)和[精准采集](精准采集.md)魔咒。
* 现在可以比其他工具更快地挖掘[干草捆](干草捆.md)。
* 不同品质的锄挖掘合适的方块时，其效率也各不相同。

* *下界合金[斧](斧.md)、[锄](锄.md)、[镐](镐.md)、[锹](锹.md)、[剑](剑.md)、[头盔](头盔.md)、[盔甲](盔甲.md)、[护腿](护腿.md)和[靴子](靴子.md)**
* 不再能够通过[工作台](工作台.md)合成。
* 更改了所有下界合金质工具、武器和盔甲的纹理。

* *[下界合金碎片](下界合金碎片.md)**
* 更改了纹理。

# = 生物 =
* *[鱼](鱼.md)**
* 现在会在最近的玩家距其超过64格时消失。
* * 这不适用于由玩家放置的鱼及被命名的鱼。<ref></ref>

# = 非生物实体 =
* *[物品展示框](物品展示框.md)**
* 有了2个新的NBT标签：
* * <code>Invisible</code>：使得物品展示框不可见（其内展示的物品仍然可见）。
* * <code>Fixed</code>：禁止物品展示框被破坏，同时禁止其内的物品被移除（不会妨碍物品的旋转）。

# = 游戏内容 =
* *[以物易物](以物易物.md)**
* 再次调整了以物易物。<ref></ref>
* * 猪灵现可提供[灵魂沙](灵魂沙.md)和[铁粒](铁粒.md)。
* * 猪灵不再提供[菌光体](菌光体.md)、[诡异菌岩](诡异菌岩.md)和[诡异菌](诡异菌.md)。
* * 获得下界合金锄的概率现在更小了。

* *[进度](进度.md)**
* 修改了触发器。
* * 条件：
* ** 将重命名为。
* ** 加入了：用于匹配弹射物[实体](实体.md)。
* ** 加入了：用于匹配抛出或射出弹射物的[玩家](玩家.md)。

# = 常规 =
* *[模型](模型.md)**
* 改进了“方块状态”文件的换行与缩进，现在会在引用模型时确定名称空间。
* 模型文件现在会在引用其他模型文件时指明命名空间。

* *<samp>[client.jar](client.jar.md)</samp>**
* 移除了客户端里的[Realms](Realms.md)代码，但在assets文件夹里仍有其资源文件。

* *[实体](实体.md)UUID**
* 弹射物实体，如[箭](箭.md)和[雪球](雪球.md)的UUID现在会以含有4个整数的数组的形式存储。将来所有的UUID都会以这种格式存储。

* *[Realms](Realms.md)**
* 移除了下列翻译字符串：
* *
* *
* *

* *[标签](Java版标签.md)**
* 向方块和物品标签中加入了绯红菌核和去皮绯红菌核。
* 向方块和物品标签中加入了诡异菌核和去皮诡异菌核。
