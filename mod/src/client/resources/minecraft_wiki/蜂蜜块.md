# 蜂蜜块

*页面ID: 48778* | *来源: Minecraft Wiki*

* *蜂蜜块（Honey Block）**是一种用[蜂蜜瓶](蜂蜜瓶.md)合成的黏性方块。

# 生成
蜂蜜块不会生成在世界中。

# 获取
# = 合成 =
合成蜂蜜块后空[玻璃瓶](玻璃瓶.md)会留在合成方格中。
}}

# 破坏
蜂蜜块被挖掘时会立刻被破坏。

蜂蜜块被破坏后会掉落自身。

# 用途
生物会避免在蜂蜜块上移动。

蜂蜜块不是[碰撞箱](碰撞箱.md)和[方块支撑形状](方块支撑形状.md)完整的方块，虽然它们在视觉上占有像素的体积，但其碰撞体积只有或像素。因此一些只能被放置在表面完整的方块上的方块（如[红石粉](红石粉.md)和[火把](火把.md)）不能附在蜂蜜块上。

# = 活塞 =
蜂蜜块被[活塞](活塞.md)移动时，站在其上表面的实体都会随之一同移动。但与[黏液块](黏液块.md)不同，蜂蜜块被活塞向上推动时，站在其上表面的实体不会被弹飞。
被活塞移动的蜂蜜块不会移动接触到其侧面或底部的实体，这个行为是被刻意设计的，<ref></ref>与其他方块不一致。

蜂蜜块被活塞移动时，它也会尝试移动所有与之相邻的方块。除黏液块外的能被黏性活塞**拉动**的方块都能被蜂蜜块移动。被推动的方块同样可以**推动**在其移动方向上的其他方块。例如，在地上的蜂蜜块向水平方向移动时会试图移动它下面的方块，并且沿着移动的方向推动其他的地表方块。

当被移动的相邻方块也是蜂蜜块时，蜂蜜块也会试图移动所有与之相邻的方块。例如，一个由蜂蜜块组成的2×2×2的正方体会作为一个整体而被单个活塞移动。

与蜂蜜块相邻的不可被活塞移动的方块会被忽略。然而，如果相邻方块能被移动，但其移动方向上有不可移动的方块所阻挡，则蜂蜜块也不会被移动。[液体](液体.md)是例外：它们不会被移动，但也不会阻止活塞移动其他方块以进入它们所在的空间。<ref></ref>

蜂蜜块不能被普通活塞拉动，也不能跟与之相邻的被活塞移动的方块（非蜂蜜块）一起移动。

能一次性被活塞移动最多12个方块的规则在蜂蜜块上仍然适用。例如，只要一个2×2×3的蜂蜜块组成的长方体没有其他可移动的方块与之相邻，就可以被黏性活塞推动或拉动。

# = 减速 =
蜂蜜块会减缓在其上移动的[实体](实体.md)的速度。玩家在蜂蜜块上行走的速度为或}}，比正常行走速度慢大约或。玩家贴着蜂蜜块的侧面行走也会被减速。

蜂蜜块也会阻碍实体的跳跃。玩家只能在蜂蜜块上跳}}或}}个方块高（一般情况下，玩家跳跃高度为个方块），比常规跳跃高度低或。因此站在蜂蜜块上的玩家只能走上半格或高度更低的方块。

# = 下滑 =
实体可稍稍“陷入”蜂蜜块的侧面（即紧贴着蜂蜜块的碰撞箱）缓慢下滑，落地时不受到跌落伤害，类似于爬下[梯子](梯子.md)。且不会减慢玩家水平方向的移动速度。因此玩家在跳跃时通过侧贴蜂蜜块可延长约2格的跳跃距离。

# = 掉落 =
类似于[干草捆](干草捆.md)，摔在蜂蜜块上的生物受到的跌落伤害会减少80%。如当玩家或其他生物从本应造成的伤害的高度摔下时，则只会受到伤害。

# 你知道吗
* 像[箭](箭.md)这样体积较小的实体可以从蜂蜜块之间的缝隙中穿过（箭的宽度小于2像素）。
* 现实中的蜜蜂会在温度较低，且难以找到鲜花时进食蜂蜜。而通常情况下，蜜蜂主要以花粉为食。
* 蜂蜜块的外层的纹理调用数据驱动中定义的顶面纹理，内层的纹理则正常调用数据驱动中定义的各面纹理。
