# 剧毒药水

*页面ID: 180980* | *来源: Minecraft Wiki*

* *剧毒药水**是提供[中毒](中毒.md)状态效果的[药水效果](药水效果.md)。

该药水效果可以制成[药水](药水.md)**剧毒药水（Potion of Poison）**、[喷溅药水](喷溅药水.md)**喷溅型剧毒药水（Splash Potion of Poison）**、[滞留药水](滞留药水.md)**滞留型剧毒药水（Lingering Potion of Poison）**和[藥水箭](藥水箭.md)**剧毒之箭（Arrow of Poison）**。

此药水效果有对应的延长版和增强版。

# 生成
# = 生物 =
[女巫](女巫.md)会对生命值高于且不具有中毒效果的生物投掷喷溅型剧毒药水。

[沼骸](沼骸.md)会发射剧毒之箭。沼骸会直接发射带有中毒状态效果的箭，而不是发射剧毒之箭，但造成的状态效果相同。

# = 不祥试炼 =
[不祥试炼刷怪笼](不祥试炼刷怪笼.md)生成的[不祥之物生成器](不祥之物生成器.md)会发射或。因而被此弹射物击中后会获得45秒而不是5秒的中毒。

# = 礼物 =

[制箭师](制箭师.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷剧毒之箭。

# = 自然生成 =

[沼泽小屋](沼泽小屋.md)的[炼药锅](炼药锅.md)内可能装有剧毒药水。

# = 箱子战利品 =

由于喷溅药水和滞留药水的最大堆叠数量为1，数量大于1的堆叠会被展开为对应数量的单个物品堆叠。

# = 掉落物 =
沼骸会掉落剧毒之箭。

# = 炼药锅 =

对装有剧毒药水的炼药锅使用[玻璃瓶](玻璃瓶.md)可获得剧毒药水、喷溅型剧毒药水或滞留型剧毒药水，具体形式取决于炼药锅内容物。

对装有剧毒药水的炼药锅使用[箭](箭.md)可获取剧毒之箭，最大数量随内容物水位增加依次为16、32和64。

# 你知道吗
* 剧毒药水在某些场景中是药箭默认的药水效果。
* * [统计信息](统计信息.md)屏幕上显示的药箭是剧毒之箭。
* * 若使用药箭合成饰纹陶罐，则饰纹陶罐破碎后会掉落剧毒之箭。
