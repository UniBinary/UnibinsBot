# 腐肉

*页面ID: 7169* | *来源: Minecraft Wiki*

</ref>||Duncan_Geere_Mojavatar.png}}

* *腐肉（Rotten Flesh）**是一种能被[玩家](玩家.md)食用的[食物](食物.md)类[物品](物品.md)，食用后有概率获得[饥饿](饥饿（状态效果）.md)状态效果。

# 获取
# = 生物掉落物 =

# = 钓鱼 =
[钓鱼](钓鱼.md)时，腐肉可作为垃圾被钓上来。

# = 箱子战利品 =

# = 礼物 =

已驯服的[猫](猫.md)赠予玩家礼物时，礼物有（约为16.129%）的概率是1个腐肉。

# 用途
# = 食物 =

手持腐肉按住键即可食用。每个腐肉可以回复，有80%的概率使玩家获得30秒的效果。通过食用腐肉获得的饥饿效果时长不会叠加只会重置。

# = 狼 =
腐肉能用来吸引、治疗或繁殖驯服的[狼](狼.md)，也可以使已驯服的幼年狼的剩余生长时间加快10%。

狼不会因食用腐肉而获得效果。
