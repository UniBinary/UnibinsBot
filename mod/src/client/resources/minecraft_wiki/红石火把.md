* *红石火把（Redstone Torch）**是逻辑类似于非门的[红石电源](红石元件#电源元件.md)，是一种非固体[方块](方块.md)。

# 生成
# = 自然生成 =
红石火把会在[雪屋](雪屋.md)和[远古城市](远古城市.md)中自然生成。

# 获取
# = 合成 =

# 破坏
红石火把被挖掘时会立刻被破坏。

红石火把被破坏后会掉落自身。

# 用途
红石火把可作为合成材料、红石元件或光源。

# = 放置 =

[缩略图|红石火把的放置及其特点示意图](File:Redstone torch as power source.png.md)

红石火把必须于[方块支撑形状](方块支撑形状.md)上表面中心完整的方块上方或侧面完整的方块侧面，不能放置于任何方块的底部，有个别情况需要放置。详见。

尝试在无效的表面放置红石火把会使其“滑入”这块空间内最近的有效表面。例如，尝试在地面上的栅栏侧面放置红石火把会使其附着到栅栏周围地面方块的顶部。

当红石火把附着的方块变动（移动、破坏、替代等），不再允许附着时，或有[水](水.md)流过和有[活塞](活塞.md)试图推动它或将方块推入其位置时，红石火把会掉落为方块物品。若[熔岩](熔岩.md)流过其位置，红石火把不会掉落。

# = 合成材料 =
红石火把可用于合成[激活铁轨](激活铁轨.md)、[红石比较器](红石比较器.md)与[红石中继器](红石中继器.md)。

# = 光源 =
点亮的红石火把会发出[亮度](亮度.md)为7的光，所以红石火把不能融化[雪](雪.md)或[冰](冰.md)。

# = 红石元件 =

红石火把可以用于强充能方块、激活红石元器件（如[红石线](红石线.md)，信号强度为15）与[机械元件](红石元件#机械元件.md)（如[活塞](活塞.md)），或类似[非门](逻辑电路#非门.md)那样反转信号。

# == 点亮与熄灭 ==
红石火把的逻辑类似于[非门](逻辑电路#非门.md)：**未激活**时，红石火把亮起并输出信号（强度为15），**激活**时则熄灭并取消输出信号。
* 红石火把所附着的红石导体被[充能](充能.md)时会被激活，从而熄灭。
* 红石火把附着在[红石块](红石块.md)上时被激活，从而熄灭。
* 附着在活塞基部的红石火把在活塞被激活时熄灭，否则亮起，无论活塞是否成功推出或收回。

红石火把有2游戏刻的延迟，这意味着它需要2游戏刻来改变状态。

在上一红石刻存在，但在该红石刻的图更新阶段被阻断的信号无法激活红石火把。

其附着的充能状态的变更一般情况下至少需要持续1红石刻才能让红石火把改变状态。例如红石火把在自己的附着方块向其输出2游戏刻或更短的脉冲时不会熄灭。
* 例如：红石火把附着的[侦测器](侦测器.md)向其输出信号时，红石火把会创建2[游戏刻](游戏刻.md)后更新状态的[计划刻](计划刻.md)。2游戏刻后由于侦测器已经熄灭，此时红石火把不会被激活而熄灭，也不能再次计划更新状态从而在侦测器再次点亮时熄灭。但若红石火把在2游戏刻内被破坏且在原处放置了相同[命名空间ID](命名空间ID.md)、附着有信号的方块的红石火把，新的红石火把能在旧的红石火把的计划刻执行时熄灭。

; 行为
红石火把不会直接影响其附着的方块，即使附着的是机械元件，如红石火把不会激活其附着的红石灯。

* 激活[毗邻](红石电路#毗邻.md)（除了附着）的[红石粉](红石粉.md)至15[充能等级](充能等级.md)；
* 向毗邻（除了附着）的[红石比较器](红石比较器.md)、[红石中继器](红石中继器.md)朝向红石火把的输入端输入15信号强度；
* 强充能其正上方的[红石导体](红石导体.md)（侧面或下方的红石导体不会被充能）；
* 激活毗邻（除了附着）的[机械元件](红石元件列表#机械元件.md)（除不接受此方向激活的红石元件，如面向它的活塞等）；
* 产生红色粉末[粒子](粒子.md)。

# == 烧毁 ==
红石火把烧毁时会产生“smoke”[粒子](粒子.md)，并发出像火被浇灭时那样的嘶嘶声。红石火把烧毁次数没有上限。

; Java版
当某一位置的红石火把在之内熄灭**8**次时，其会立即**烧毁**。

若最后一次熄灭**直接**导致了红石火把**瞬间**撤销激活，那么它将会保持熄灭，直到收到[NC更新](NC更新.md)；但在最近60游戏刻内熄灭次数小于8次前它会无视所有方块更新。

若最后一次熄灭不会直接导致火把瞬间撤销激活，将会保持熄灭并无视所有方块更新，直到160游戏刻后会检测是否应该亮起并恢复正常。

; 基岩版
红石火把具有两个变量：“燃烧值”和“CanReigniteFromBurnout”。前者默认为0，用于判断烧毁；后者默认为false，用于控制火把烧毁后是否可以复燃，后续将该变量称为“复燃值”。

若燃烧值大于32，复燃值会被设置为<code>true</code>；若复燃值为<code>true</code>，则燃烧值不可增加。

“半脉冲”指红石火把即将烧毁（燃烧值大于0且小于等于16）时输出的高频脉冲信号。只有一部分红石元件能够正常接受半脉冲信号，另一部分红石元件会始终将红石火把视为激活（直到该红石火把烧毁）。
* 红石灯是特例，其会正常接收高频半脉冲信号且内部信号会被正确计算，但会因失去信号时间过短而不会熄灭。

当某个红石火把的输入只有自身时，会使自身燃烧值+1（若可以），反转亮灭，输出“半脉冲”。若燃烧值大于16，火把“烧毁”（不再输出信号，燃烧值等于16时会输出最后一次半脉冲）。
* 若红石火把收到其他元件的输入，燃烧值**归零**，复燃值被设置为<code>false</code>。
* 若红石火把收到方块更新，且复燃值为<code>true</code>，燃烧值**归零**，复燃值被设置为<code>false</code>。
