*页面ID: 35971* | *来源: Minecraft Wiki*

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年6月27日，修复了一些漏洞。

# 更改
# = 方块 =
* *[刷怪笼](刷怪笼.md)**
* 现在拥有一个独立的方块实体ID。
