* *恶魂（Ghast）**是[下界](下界.md)中一种会向[玩家](玩家.md)发射[火球](火球.md)的巨大浮空[敌对生物](敌对生物.md)。

# 生成
恶魂会在[下界荒地](下界荒地.md)、[灵魂沙峡谷](灵魂沙峡谷.md)和[玄武岩三角洲](玄武岩三角洲.md)生物群系中自然生成，且不会在[下界要塞](下界要塞.md)中生成。恶魂只有在其下方是[固体方块](固体方块.md)，并且拥有至少或的空间时才会自然生成。其生成不受到[亮度等级](亮度等级.md)的限制。

# 行为
恶魂常常闭着眼睛和嘴巴在[下界](下界.md)四处飘浮并且定期发出高亢的[猫](猫.md)一般的叫声，在被伤害时还会高声尖叫。当恶魂找到攻击目标时，其红色的眼睛和嘴巴会张开，同时会发出口哨般的噪声，随后发射[火球](火球.md)。恶魂发出的声音随距离衰减的程度减弱，这使得[玩家](玩家.md)能够在它们距离自己还有一定距离时就听到它们的声音。它们的体积是或，触手与玩家的手臂宽度相同，尽管看上去更长更瘦。

# = 攻击 =

恶魂拥有100格的搜索范围<ref>http://gaming.stackexchange.com/questions/17279/how-far-can-mobs-see</ref>、爆炸的攻击力以及可观的移动能力。与其他敌对生物不同，恶魂没有追逐模式：它们不会试着去靠近玩家，也不会试着去远离。玩家首次位于以恶魂为中心，8格高，64格为半径的区域内时，它们会转向玩家并发射火球，一旦锁定玩家，只要距离其64格内，在任意方向上都可以被检测到。当玩家距离其远于64格后或有方块阻挡其视线，恶魂就会停止攻击。距离其远于100格后恶魂就会对该玩家失去兴趣，再次进入8格高的初始范围内时才会被再次攻击；恶魂固定攻击距离其28格内的玩家，并在有方块阻挡其视线时停止攻击，在该玩家距离其远于28格后失去兴趣。在攻击时恶魂会尝试提升[高度](高度.md)。若恶魂没有攻击目标，其受到伤害时会逃跑。

驯服的[狼](狼.md)、[雪傀儡](雪傀儡.md)、[僵尸疣猪兽](僵尸疣猪兽.md)、[“Johnny”卫道士](卫道士#“Johnny”卫道士.md)、[凋灵](凋灵.md)和与该恶魂不在同一队伍的[潜影贝](潜影贝.md)皆不会攻击恶魂，[山羊](山羊.md)也不会冲撞恶魂。[铁傀儡](铁傀儡.md)不会主动寻找恶魂进行攻击，但当二者碰撞箱交叠时，铁傀儡会对恶魂发起攻击。

恶魂只与玩家敌对，且除了[监守者](监守者.md)以外的任何生物皆不会尝试反击恶魂。

恶魂与玩家和任何攻击到它的生物（其他恶魂除外）敌对，且除了监守者和信任玩家的[狐狸](狐狸.md)以外的任何生物皆不会尝试反击恶魂。

恶魂会在目标突然消失或离开攻击范围时保持其当前纹理状态，并面向目标最后出现的位置飘浮。若恶魂因上述原因保持发射火球的纹理，且此时目标又再次出现，则恶魂会瞬间发射火球。

# = 受伤害行为 =
恶魂免疫[火焰伤害](火焰伤害.md)和[摔落伤害](摔落伤害.md)。

恶魂被玩家反弹的[火球](火球.md)命中时，会受到伤害。

# 你知道吗
* 恶魂的英文名称“Ghast”源于“Ghastly”（可怕的）。“Ghast”一词用作怪物名称是由首创的，后广泛出现在各种奇幻故事和游戏中。
* [C418](C418.md)在Reddit上的一个AMA透露恶魂的音效源于他家的猫，猫在睡觉时被打扰就会发出这种声音。<ref>http://www.reddit.com/r/IAmA/comments/nbe2h/i_am_the_composer_and_sound_designer_of_minecraft/c37sjyb</ref>
* 如果恶魂被困在1格厚的立方体里，它们发射的[火球](火球.md)会穿过立方体。这是因为所有生物发出的[弹射物](弹射物.md)都是在它之前一个方块生成的，以防止这个弹射物伤及发出弹射物的生物。
* 尽管恶魂的名字中包含“”，而且不会被[凋灵](凋灵.md)攻击，但恶魂并不是[亡灵生物](亡灵生物.md)。
* 在极少数情况下，生成的恶魂可以看穿方块攻击玩家（这些情况大多数在密闭空间里发生）。
* 在使用有[](力量（魔咒）.md)I魔咒的[弓](弓.md)并且满弦拉弓时，恶魂可以被一箭杀死。
* * 当[弩](弩.md)射出的[箭](箭.md)造成[暴击](箭#箭伤害.md)也能将恶魂一箭杀死。
