# 启动器2.8.2

*页面ID: 105689* | *来源: Minecraft Wiki*

* *2.8.2**是一次[启动器](启动器.md)更新，发布于2023年8月29日。

# 修复
* 修复了一些安装过程中的漏洞。
* 修复了一些快速进入游戏功能中的漏洞。
* 修复了一些皮肤的漏洞。
*  - 语言进度弹窗中的Crowdin链接失效。
*  - 返回到“开始游戏”选项卡时，“舒缓场景”的视频和音频会突然结束。
*  - 用在Realms选项卡中的一条启动器字符串中的“Owned”一词不能被翻译。
*  - 快速进入游戏功能的快速进入游戏功能标签不能被翻译。
*  - “Minecraft: Java Edition”选项卡中的“QUICK PLAY”字符串不能被翻译。
