# Java版12w30e

*页面ID: 30089* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w30e**是[Java版1.3.1](Java版1.3.1.md)的第19个，也是最后一个快照，发布于2012年7月25日<ref></ref>，修复了[12w30d](12w30d.md)中的一些漏洞与崩溃。

# 修复
* *修复了3个漏洞**
* 修复了可可豆不能种在旋转了的木头方块上。
* 修复了创造模式中的复制漏洞。<ref></ref>
* 修复了创造模式中有生存模式物品栏的问题。</onlyinclude>
