* *24w34a**是[Java版1.21.2](Java版1.21.2.md)的第2个快照，发布于2024年8月21日<ref></ref>，加入了3个新的[物品堆叠组件](物品堆叠组件.md)，更改了[矿车](矿车.md)改进、红石电路优化相关的[实验性内容](实验性内容.md)，并修复了一些漏洞。

# 更改
# = 方块 =
* *[炼药锅](炼药锅.md)**
* 现在又能对水下炼药锅水桶了。

* *[火把](火把.md)和[灵魂火把](灵魂火把.md)**
* 更改了模型和UV映射，现在又会渲染其底面了。

# = 物品 =
* *[不祥之瓶](不祥之瓶.md)**
* 现在不再是[食物](食物.md)。

* *常规**
* 在[创造模式](创造模式.md)下使用物品后不再会返还其他物品。
* * 例如：创造模式下玩家饮用[蜂蜜瓶](蜂蜜瓶.md)后不再返还[玻璃瓶](玻璃瓶.md)。

# = 生物 =
* *[烈焰人](烈焰人.md)**
* 更改了烈焰棒部分的底部纹理。

# = 非生物实体 =
* *[箭](箭.md)、[三叉戟](三叉戟.md)和[浮漂](浮漂.md)**
* 现在会在撞击[世界边界](世界边界.md)时反弹。

# = 世界生成 =
* *[试炼密室](试炼密室.md)**
* 在<code>encounter_4</code>结构的发射器机关中添加了一个发射器。
* 移除了结构中的空箱子。

# = 游戏内容 =
* *[配方书](配方书.md)**
* 现在会能通过键重选上次选中的配方。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[资源包](资源包.md)**
* 将资源包版本号更改为。

* *[物品堆叠组件](物品堆叠组件.md)**
* <code>food</code>组件现在只保存食物数据，而不再影响食物是否能被食用。
* * 因此移除了、和字段，其功能被新加入的组件取代。

* *性能**
* 改善了更高渲染距离下的性能，并降低了相机转动对性能的影响。

* *[着色器](着色器.md)和后处理管线**
* 移除了核心着色器<code>rendertype_entity_glint_direct</code>，现以<code>rendertype_entity_glint</code>代替。
* 移除了核心着色器<code>rendertype_entity_translucent_cull</code>，现以<code>rendertype_item_entity_translucent_cull</code>代替。
* 用于后处理效果的程序定义（{{filepath|-{}-assets/<命名空间>/shaders/program/<名称>.json}}）现与核心着色器定义（{{filepath|-{}-assets/<命名空间>/shaders/core/<名称>.json}}）一致化。
* * 移除了没有实际作用的<code>blend</code>字段。
* * 移除了<code>attributes</code>字段，其顶点属性<code>Position</code>将永被绑定。
* * Uniform现与为核心着色器提供的Uniform合并，其中<code>Time</code>被重命名为<code>GameTime</code>。
* 着色器引用现在需为着色器命名空间ID。
* * 顶点着色器<code>-{}-<命名空间>:<路径></code>会被处理为{{filepath|-{}-assets/<命名空间>/shaders/<路径>.vsh}}。
* * 片段着色器<code>-{}-<命名空间>:<路径></code>会被处理为{{filepath|-{}-assets/<命名空间>/shaders/<路径>.fsh}}。
* 着色器源文件不再需放于子目录。
* 着色器导入指令<code>#moj_import</code>现在支持带绝对路径的命名空间包含着色器。
* * 例如<code>#moj_import <minecraft:fog.glsl></code>会导入。
* 现在后处理管线程序由{{filepath|-{}-assets/<命名空间>/shaders/post}}移动到{{filepath|-{}-assets/<命名空间>/post_effect}}。
* 后处理管线使用的顶点和片段着色器现由{{filepath|-{}-assets/<命名空间>/shaders/program}}移动到{{filepath|-{}-assets/<命名空间>/shaders/post}}。
* 后处理渲染过程<code>name</code>现被重命名为<code>program</code>，且需要命名空间ID。
* * 例如<code>-{}-<命名空间>:<路径></code>会被处理为{{filepath|-{}-assets/<命名空间>/shaders/<路径>.json}}。

# 更改（实验性）
# = 方块 =
以下内容属于“”。
* 在传播距离相等时，红石信号会优先更新左侧，再按正常顺序更新。（即更新顺序为左、后、前、右、下、上。）
* * 这导致在多数情况下，传播距离相等时的更新顺序不再具有随机性。
* * 如果中位红石线优先接受到红石信号，且信号由红石线的正上方一格或正下方一格的信号源产生，则仍然会随机交换左侧和右侧的更新顺序。<!--被强充能的红石导体不能产生随机-->
* ** 电路中，可在红石线上方放置红石火把、侦测器或由活塞推动的红石块以进行左右随机。

# = 物品 =
以下内容属于“收纳袋”。

* *[收纳袋](收纳袋.md)**
* 现在收纳袋物品提示框最多显示3行物品而非2行，使得折叠部分物品的收纳袋至少能展示8种物品。

# = 非生物实体 =
以下内容属于“”。

* *[矿车](矿车.md)及其变种**
* 矿车再次可以被[发射器](发射器.md)重叠放置。
* 在短距离下落或垂直下落时，矿车不再会倾斜。
* 放置在铁轨上时，矿车会朝向正确的方向。放置在倾斜铁轨上时，矿车会正常倾斜。
* 在倾斜铁轨上移动时，矿车不再会穿过压在铁轨上的方块，而是会与之碰撞。
* 落至铁轨上时，矿车不再强制与铁轨中心对齐。
* * 在弯铁轨上的矿车将会对齐到偏向转弯内侧的位置。
* * 被活塞推动后，矿车也会正常对齐到铁轨上。
* 放置在一对相向的倾斜铁轨之间的矿车更容易停下了。
