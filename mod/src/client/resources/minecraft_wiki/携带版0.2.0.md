# 携带版0.2.0

*页面ID: 21024* | *来源: Minecraft Wiki*

* *v0.2.0 alpha**是[携带版](携带版.md)的一次主要更新，在Android平台上发布于2012年2月10日，在iOS平台上发布于2012年2月17日<ref>https://web.archive.org/web/20120306173021/http://itunes.apple.com/us/app/id479516143?mt=8</ref>，加入了[生存模式](生存模式.md)，更改了一些特性并修复了一些漏洞。此版本是Android与iOS设备拥有同等特性的开端。

# 新内容
# = 方块 =
* [栅栏](栅栏.md)
* [栅栏门](栅栏门.md)
* [木门](木门.md)

# = 物品 =
* [工具](工具.md)
* * 石[锹](锹.md)
* * 石[镐](镐.md)
* * 石[斧](斧.md)
* * 石[剑](剑.md)
* * [剪刀](剪刀.md)
* ** 给[绵羊](绵羊.md)剪毛时需要按住屏幕，类似于破坏方块。单击绵羊只会对其造成伤害。

# = 生物 =
* [绵羊](绵羊.md)
* [猪](猪.md)
* * 不能自然生成。
* [僵尸](僵尸.md)
* * 只会在夜间生成。
* 幼年[动物](动物.md)
* * 不能自然生成。
* [摄像机](摄像机.md)
* * 由于不会保存到<code>entities.dat</code>，摄像机无法在世界中直接使用，只能通过编辑物品栏才能生成摄像机。
* * 用于拍摄照片。

# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 创建在0.2.0之前的世界都会变成创造模式。
* [飞行](飞行.md)
* * 双击跳跃键开始飞行，双击并按住上下键来分别控制上升和下降。

* *[生存模式](生存模式.md)**
* 有[昼夜交替](昼夜交替.md)。
* 尚未实现[合成](合成.md)。因此，[锹](锹.md)、[镐](镐.md)、[斧](斧.md)、[剑](剑.md)、[剪刀](剪刀.md)、[梯子](梯子.md)、[火把](火把.md)、[木门](木门.md)、[栅栏](栅栏.md)、[栅栏门](栅栏门.md)、[木板](木板.md)、[砖头](砖头.md)、[楼梯](楼梯.md)、[台阶](台阶.md)、[玻璃](玻璃.md)、[树叶](树叶.md)和[羊毛](羊毛.md)（淡灰色、品红色和橙色羊毛除外）都无法在生存模式中获取。
* 当选择了一个数量为0的物品时，会显示玩家的手。
* 加入了生命条（生命值会缓慢恢复，就像Java版中的和平难度）
* 加入了氧气值和氧气条，现在玩家在沉入水中耗尽氧气后持续失去生命值直到死亡。
* 加入了死亡，并在死亡时显示重生和返回主菜单选项。
* 无论用什么工具，破坏方块时都可以掉出相同的物品（基岩除外）。
* * 例如，用手破坏[石头](石头.md)时会掉落[圆石](圆石.md)，但使用[镐](镐.md)会更快一些。

* 现在玩家的视野再次会在着火时被遮挡。

# 修订版本
v0.2.0在2012年12月11日被重新上传，主要修复了有些设备在创建世界时游戏会崩溃的漏洞。2个版本的内部版本号如下：

* 0.2.0(2005)
* 0.2.0(2006)

两个版本的大小都是2.72MB。
