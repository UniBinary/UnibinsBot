# Java版1.14.3-pre2

*页面ID: 44054* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14.3-pre2**是[Java版1.14.3](Java版1.14.3.md)的第2个预发布版，发布于2019年6月7日<ref></ref>，更改了灾厄巡逻队和村民的一些特性，并修复了一些漏洞。

# 更改
# = 常规 =
* *[灾厄巡逻队](灾厄巡逻队.md)**
* [卫道士](卫道士.md)不再是灾厄巡逻队的一部分了。
* 延长了最小生成时间，从5+（最大为1）分钟到10+（最大为1）分钟。
* 如果[光照](光照.md)等级不能满足怪物生成的条件，那么灾厄巡逻队也不会生成。
* 灾厄巡逻队现在会在除[蘑菇岛](蘑菇岛.md)以外的[生物群系](生物群系.md)生成。

* *[进度](进度.md)**
* “”进度不再需要[饱和](饱和.md)。

* *[魔咒](魔咒.md)**
* [保护](保护.md)、[弹射物保护](弹射物保护.md)、[火焰保护](火焰保护.md)和[爆炸保护](爆炸保护.md)不再兼容了，就像1.14之前那样。

# = 生物 =
* *[村民](村民.md)**
* 受惊的村民现在会工作和睡眠，从而不会一直处于恐慌状态。
* 村民的“最后一次睡眠”和“最后一次工作”属性现在会正确保存。
