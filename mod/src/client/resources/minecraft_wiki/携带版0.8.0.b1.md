# 携带版0.8.0.b1

*页面ID: 97814* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.8.0 alpha build 1**（游戏内称呼为**v0.8.0 alpha**，内部称呼为**0.8.0_test1**）是[v0.8.0 alpha](携带版0.8.0.md)的首个测试版。

该版本从未公开发布，但是客户端被两次上传到了Google Play中。这两次上传的区别未知。

# 新内容
# = 方块 =
* *[枯萎的灌木](枯萎的灌木.md)**
* 一种类植物方块。
* 暂时不能自然生成。

* *[原木](原木.md)**
* 加入了丛林木，可在创造模式物品栏内获得。

* *[木头](木头.md)**
* 加入了橡木、云杉木和白桦木。
* 只能使用世界编辑器获得。

* *[楼梯](楼梯.md)**
* 加入了桦木、云杉木和丛林木楼梯。

* *[台阶](台阶.md)**
* 加入了白桦木、云杉木与丛林木台阶。

* *[南瓜](南瓜.md)**
* 一种由南瓜种子种植而来的农作物。
* 暂时不能自然生成。
* 可以合成[南瓜灯](南瓜灯.md)、[南瓜派](南瓜派.md)或[南瓜种子](南瓜种子.md)。

* *[南瓜灯](南瓜灯.md)**
* 一种外表类似南瓜的光源。
* 可用1个火把和1个南瓜进行合成。

* *[墙](墙.md)**
* 加入了[圆石墙](圆石墙.md)和[苔石墙](苔石墙.md)。
* * 苔石墙暂时不能合成。

* *[地毯](地毯.md)**
* 一种装饰方块。
* 暂时不能合成，只能通过创造模式获取。

* *[铁栏杆](铁栏杆.md)**
* 暂时不能自然生成。
* 由6个[铁锭](铁锭.md)合成。

* *[草丛](草丛.md)**
* 加入了[蕨](蕨.md)。

* *[干草捆](干草捆.md)**
* 一种可燃的装饰方块。
* 由9个小麦合成。

* *[煤炭块](煤炭块.md)**
* 一种装饰性方块。
* 除了用9块[煤炭](煤炭.md)合成，还可以用4块[下界砖](下界砖.md)合成。
* 能在熔炉中作为燃料使用，可以烧炼80个物品。

* *[铁轨](铁轨.md)**
* 暂时不能自然生成。
* 由[铁锭](铁锭.md)和[木棍](木棍.md)合成。

* *[动力铁轨](动力铁轨.md)**
* 一种能加速矿车行驶的铁轨。
* 暂时不能合成，只能通过创造模式获取。
* 无论如何，都处于激活状态。

* *[海绵](海绵.md)**
* 没有功能。
* 暂时不能自然生成，仅能在创造模式物品栏找到。

# = 物品 =
* *[马铃薯](马铃薯.md)**
* 一种食物，可恢复。
* 可直接食用，也可在熔炉内烤制成[烤马铃薯](烤马铃薯.md)。
* 可由击杀[僵尸](僵尸.md)获得。

* *[烤马铃薯](烤马铃薯.md)**
* 一种食物，可恢复。
* 由马铃薯烤制而来。

* *[胡萝卜](胡萝卜.md)**
* 一种食物，可恢复。
* 可由击杀[僵尸](僵尸.md)获得。

* *[南瓜种子](南瓜种子.md)**
* 一种用于种植南瓜的种子。
* 可通过激活下界反应器获得。
* 可由南瓜合成。

* *[南瓜派](南瓜派.md)**
* 一种由南瓜合成的食物，恢复。
* 由1个南瓜、1个糖、1个鸡蛋合成。

* *[红石粉](红石粉.md)**
* 一种通过挖掘红石矿石掉落的物品。
* 用于合成指南针和时钟。
* 目前无法放置。
* 暂时不能在创造模式物品栏内找到。

# = 生物 =
* *[繁殖](繁殖.md)**
* 当生物吃下其对应的食物后，便会进入“求爱模式”，准备与另外一只同物种的生物共同进行繁殖。
* * 进入求爱模式的生物会持续散发红心[粒子](粒子.md)。
* 当有2只生物进入求爱模式后，便会寻路到彼此身边，在双亲中间生成一只相同物种的幼年动物，并结束求爱模式。

* *常规**
* 加入了新的生物AI。

# = 游戏内容 =
* *纹理**
* 新的颜色与纹理。
* * 从[Java版](Java版.md)移植了大部分纹理。
* * 新的[草](草.md)颜色。
* * 新的天空颜色。
* * 新的水颜色（在远距离下）。
* 远距离渲染。

* *物品栏**
* 在[创造模式物品栏](创造模式物品栏.md)里加入了[草](草.md)、[打火石](打火石.md)、[雪](雪.md)、[冰](冰.md)和[海绵](海绵.md)。

* *动画**
* 新的火焰特效。
* [弓](弓.md)的动画现在采用新的渲染方式。
* 物品的动画。

# = 常规 =
* 加入了可用配方优先按钮。
* * 启用按钮后，合成界面会优先展示可以合成的物品。

# 更改
# = 方块 =
* *[故障叶](故障叶.md)**
* 由于此版本对方块、物品的渲染和纹理存储等进行了重大重构，移除了故障叶。

* *[故障草](故障草.md)**
* 由于此版本对方块、物品的渲染和纹理存储等进行了重大重构，移除了故障草。

* *[原木](原木.md)**
* 现在所有种类的原木都可以被横向放置了。
* 现在原木在放置时内侧总是朝着玩家。

* *[Reserved6](Reserved6.md)**
* 纹理改为纯灰。

* *[树叶](树叶.md)**
* 在[创造模式](创造模式.md)物品栏中加入了丛林树叶。
* 更改了橡树树叶和白桦树叶的纹理。
* 树叶的物品栏图标现在会渲染其物品模型。

# = 生物 =
* *[猪](猪.md)**
* 现在会跟随手持[马铃薯](马铃薯.md)和[胡萝卜](胡萝卜.md)的玩家。
* 现在不可被喂食。
* 有了新的AI。

* *[牛](牛.md)**
* 现在会跟随手持[小麦](小麦.md)的玩家。
* 现在可被繁殖。
* 改进AI。

* *[绵羊](绵羊.md)**
* 现在所有绵羊身上的羊毛都被渲染为白色。
* 现在可被繁殖。
* 改进AI。

# = 物品 =
* *[指南针](指南针.md)**
* 现在可以指示出生点了。
* 现在可由4个铁锭和1个红石粉合成。

* *[时钟](时钟.md)**
* 更改了纹理。
* 现在可以显示当前的游戏时间了。
* 现在可以用1个金锭和1个红石粉合成。

* *[骨粉](骨粉.md)**
* 更改了纹理。
* 现在需要多次使用才能使作物完全生长。

# = 常规 =
* 更改了[熔炉](熔炉.md)、[砂岩台阶](砂岩台阶.md)和[树叶](树叶.md)的模型。
* 模仿了Java版的[实体](实体.md)动态光照。
* * 背景光照。
* * 光照方向取决于太阳的位置。
* 新的手持物品渲染。
* 透明快捷栏。
* 可以在有物品的物品栏格子中替换物品。
* 重置文本模式（比如在聊天栏）。
* 模板化阴影。
* 物品手持时有呼吸时的震颤了。
* 旋转纹理以隐藏重复图案。
* * 关闭平滑光照后，方块的侧面纹理会被错误地旋转。
* 新的默认设置。
* * 加入了“远”（256格）与“最远”（400格）的渲染距离。
* * 高品质图像默认开启。
* * 默认视距是“远”。
* 加入领域按钮从设置移动到了[菜单屏幕](菜单屏幕.md)。
* 重构渲染以使用缓冲区顶点对象（VBO）。
* * 重置了[箭](箭.md)的模型。
* * [物品栏](物品栏.md)现在使用缓存过的缓冲区顶点对象。
* * 现在使用三角扇法作为新的天空渲染方式。
* 由于表现/性能的原因，远近区块现在使用两个线程处理。
* * 雾现在只出现于远处的区块，且其仅在近处透明。
* * “仅限开发测试”层现在隐藏于远处的区块。
* 火把现在是不透明方块。
* 3D的云拥有了新的算法。
* 重构OpenGL用法以避免功耗过高（如动物不再仅处于开发测试阶段）。
