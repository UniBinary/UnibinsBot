# 末地石砖

*页面ID: 17548* | *来源: Minecraft Wiki*

* *末地石砖（End Stone Bricks）**是[末地石](末地石.md)制作的装饰性方块。

# 生成

# = 自然生成 =
末地石砖可以在[末地城](末地城.md)和[末地船](末地船.md)中自然生成。

# 破坏
挖掘末地石砖的合适工具是镐。末地石砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

末地石砖被破坏后会掉落自身。

# 用途
末地石砖主要用来装饰，与其他砖块类型方块相似。
