# 携带版0.11.0.b7

*页面ID: 27988* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 7**是[v0.11.0 alpha](携带版0.11.0.md)的第7个测试版，发布于2015年4月24日，修复了一些漏洞。

# 修复

* *其他漏洞**
* 修复了关于幼年僵尸的一个错误。<!-- Fixed AABB on baby zombies -->
* 刷怪笼导致游戏崩溃。
* 语言选项的返回按钮丢失。
* 皮肤界面的玩家位置不正确。
* 破坏运作中的下界反应核导致游戏崩溃。
* 渲染物品时出现漏洞。
* 多人游戏下，狼的坐下动作不同步。
* 有时候游戏会黑屏。
* 玩家不受坠落伤害影响。
* 死亡后，物品栏不会自动关闭。</onlyinclude>
