# 降雨

*页面ID: 8465* | *来源: Minecraft Wiki*

[350px|右](File:Rain.png.md)
* *降雨（Rain）**是[Minecraft](Minecraft.md)中偶尔出现的一种[天气](天气.md)。

# 行为
降雨是在[主世界](主世界.md)随机生成的一种暂时的、全局的天气状况<ref></ref>，在部分区域可能变为[降雪](降雪.md)。炎热或干燥的[生物群系](生物群系.md)、[虚空](虚空（生物群系）.md)生物群系和其他维度中永远不会下雨。

平均每场降雨持续0.5-1个[Minecraft日](昼夜更替#时间换算.md)，两场降雨间隔0.5-7.5个游戏日。降雨有一定的概率变为[雷暴](雷暴.md)。

降雨天气发生时，玩家虽然不能在白天睡觉，但可以在晚上睡觉来跳过降雨。

== 现象 ==
在特定[高度](高度.md)以上，降雨会变成降雪，这个高度由[生物群系](生物群系.md)决定。有些生物群系一直都是降雪，有些生物群系永远不会降雪。

降雨天气发生时，会在世界中产生一些效果：
* 降雨会使世界变暗，导致[太阳](太阳.md)给予的[亮度](亮度.md)降低3，在白天亮度只有12。
* * 然而月光给予的亮度却没有降低，亮度仍然为4。
* 天空背景会变为黑色（包括在不下雨的生物群系里）。
* 太阳、[月亮](月亮.md)和[星星](星星.md)消失。<ref></ref>
* * 虽然太阳在雨中不可见，黎明和黄昏时地平线上的曙光和暮光仍然可见。
* 虽然云不会沉积，但会从白色变为灰色。
* [蜜蜂](蜜蜂.md)不会离开[蜂巢](蜂巢（方块）.md)进行工作，离巢的蜜蜂会返回蜂巢。
* [村民](村民.md)始终待在家里并停止日程安排。

上方没有任何遮挡雨水的方块时，视为接触雨水。与雨水接触会有一些效果：
* [火](火.md)会更快熄灭。
* * 火几乎会立即熄灭。
* [着火](着火.md)的生物、[箭](箭.md)和[三叉戟](三叉戟.md)会立刻结束着火。
* [末影人](末影人.md)、[雪傀儡](雪傀儡.md)、[烈焰人](烈焰人.md)和[炽足兽](炽足兽.md)会持续受到伤害，末影人会因被雨水伤害而随机传送。
* [浮漂](浮漂.md)会缩短[钓鱼](钓鱼.md)时上钩等待时间。<ref></ref>
* [狼](狼.md)会被浸湿，停止接触雨水后会甩干。
* 未变湿的[耕地](耕地.md)会变湿。<ref></ref>
* [炼药锅](炼药锅.md)会缓慢地装满[水](水.md)。
* 玩家可以在[潮涌核心](潮涌核心.md)影响范围内获得状态效果。
* [美西螈](美西螈.md)和[海豚](海豚.md)会回满[氧气值](氧气值.md)。
* 玩家可以使用具有[激流](激流.md)魔咒的[三叉戟](三叉戟.md)。
* 生物受到的来自具有[穿刺](穿刺.md)魔咒的物品的伤害增加。
* [快乐恶魂](快乐恶魂.md)恢复[生命值](生命值.md)的速度会提升。

降雨不会扑灭[下界岩](下界岩.md)、[岩浆块](岩浆块.md)、[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)上的火，并且也不会使熔岩变为[黑曜石](黑曜石.md)<ref></ref>。

# = 降雨粒子 =
雨在碰到一个方块时会产生降雨[粒子](粒子.md)并发出声音，这种声音在16格内的任何地方都能够被听见。可在[视频设置](选项#视频设置.md)菜单内将粒子设置为“最小”以关闭这些粒子。虽然降雨粒子只能在10格内被看见，但它的效果却发生在所有已加载的区域里。

降雨会穿过非[阻止运动方块](阻止运动方块.md)，如[梯子](梯子.md)、[藤蔓](藤蔓.md)、[地毯](地毯.md)、[红石中继器](红石中继器.md)、[雪](雪.md)、[生物头颅](生物头颅.md)、[花盆](花盆.md)和[蜘蛛网](蜘蛛网.md)。降雨不会穿过阻止运动方块，如[告示牌](告示牌.md)、[旗帜](旗帜.md)、[门](门.md)、[栅栏门](栅栏门.md)、[活板门](活板门.md)、[压力板](压力板.md)、[玻璃板](玻璃板.md)和[铁栏杆](铁栏杆.md)。

雨会沿对角线下降并随机改变方向，且下得更快。

# 你知道吗
[缩略图|300px|落入虚空的雨](File:Void Rain.png.md)
* 雨降落的速度比玩家自由下落的速度慢。
* 雨在云层上也会存在。Notch的解释是云层之上的灰色区域才是雨真正的来源。<ref></ref>
* 雨最低能落到[虚空](虚空.md)里一格（Y=-65）。由于虚空中没有方块，雨消失时不会产生粒子。
