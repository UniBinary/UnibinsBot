# Java版Classic 0.25 SURVIVAL TEST

*页面ID: 35585* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.25 SURVIVAL TEST**是的一次更新，发布于2009年9月3日<ref></ref>，修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *常规**
* 现在可以保存和加载世界。

# 更改
# = 生物 =
* *[猪](猪.md)**
* 现在会掉落0-2个棕色[蘑菇](蘑菇.md)。

* *[骷髅](骷髅.md)**
* 攻击方式改为远程攻击。
* 现在会发射紫色的[箭](箭.md)[32px](File:Purple Arrow JE1.png.md)。
* 现在死亡时会随机向周围短距离内射出4-9支箭。

* *[怪物](怪物.md)**
* 现在会互相攻击，但这在骷髅之间不会发生。

* *常规**
* 生物现在移动的更快，并且有了更大的跟随半径。
* 生物会在更远的地方观察到[玩家](玩家.md)。
* 生物现在随时间而消失。

# = 非生物实体 =
* *[箭](箭.md)**
* 更改了纹理。
* 现在能飞得更远。

# = 游戏内容 =
* *[平视显示器](平视显示器.md)**
* 在右上角现在会显示分数。

* *常规**
* 玩家现在带着20支箭生成。

# 修复
* *修复了2个漏洞**
* 箭矢飞行时间超过1秒后现在也会造成伤害了。<ref>[IRC记录](#logs.md): "*A11:15:20 <08Notch> Evil-Ville: Actually, there was a bug. They didn't cause damage at all after one second flight time. :D*" (16:15:20 UTC)</ref>
* 修复了可以穿墙攻击怪物的问题。

# 重新上传
该版本于16:15（UTC）被第一次重新上传，将箭的伤害从更改为。<ref>[IRC日志](#logs.md)：“*A11:15:16 <Real> do arrows have increased damage now that they're limited, Notch?*”[...]“*A11:15:29 <08Notch> Real: Yes, in a few seconds. ;)*”</ref>

该版本于16:26（UTC）被第二次重新上传，在死亡界面加入了“加载世界（Load Level）”按钮。<ref>[IRC记录](#logs.md): "*A11:26:38 <08Notch> ok, I fixed the creeper craters*" [...] "*A11:26:43 <08Notch> and added a load button to the death screen*" (16:26 UTC)</ref>

该版本于16:58（UTC）被第三次重新上传<ref>[IRC记录](#logs.md): "*A11:58:33 <08Notch> i didn't bump the number :-O*" [...] "*A11:58:56 <Quatroking> Notch: but we do have a new version?*" [...] "*A11:59:11 <08Notch> yes, Quatroking *" (16:58至16:59 UTC)</ref><ref> | As cited in [IRC logs](#logs.md): "*P12:02:24 <citricsquid> got a video :D*" (17:02:24 UTC)</ref>，现在箭在[方块](方块.md)上会停留更长时间，可以通过URL加载世界<ref>[IRC记录](#logs.md): "*A11:57:05 <08Notch> level loading will work any second now*", "*A11:57:08 <08Notch> just uploaded a new index.jsp*" [...] "*A11:58:06 <08Notch> loading via url works now, yay*", "*A11:58:10 <08Notch> and arrows stay around much longer*" (16:58 UTC)</ref>，以及[玩家](玩家.md)不能再单击右键来造成伤害了。<ref>[IRC记录](#logs.md): "*A11:51:55 <ZomBuster> Ill ask this again, can you stop mobs getting hurt from right-clicking?*" (16:51:55 UTC)</ref></onlyinclude>
