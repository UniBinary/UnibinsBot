# 节肢杀手

*页面ID: 29214* | *来源: Minecraft Wiki*

* *节肢杀手（Bane of Arthropods）**是一种用于武器的魔咒，可对[节肢生物](节肢生物.md)（[蜘蛛](蜘蛛.md)、[洞穴蜘蛛](洞穴蜘蛛.md)、[蠹虫](蠹虫.md)、[末影螨](末影螨.md)和[蜜蜂](蜜蜂.md)）造成额外伤害并施加效果。

# 获取

节肢杀手V对于[书](书.md)、，附魔需要的[附魔等级](附魔等级.md)超过了30级，因此无法从[附魔台](附魔台.md)获取。

# 用途

[魔咒攻击力](近战攻击#魔咒攻击力.md)增加<math>2.5n</math>，，其中<math>n</math>为节肢杀手魔咒等级，仅对节肢生物有效。

对被近战攻击伤害的节肢生物造成IV效果，持续时间为<math>1</math>秒至<math>1+0.5n</math>秒之间的均匀随机数，其中<math>n</math>为节肢杀手魔咒等级。

节肢杀手与其任何不共存魔咒被应用在同一个物品上时，每个魔咒都会互不干扰地产生效果。

# = 攻击伤害 =
下表列出了每个魔咒等级每次攻击所带来的伤害，括号内为[暴击](近战攻击#暴击.md)伤害，基于以下条件：
* 攻击者基础近战攻击力受主手物品影响前的计算值为1
*
* 攻击目标无[受击后伤害免疫](受击后伤害免疫.md)
* 攻击目标不因[盔甲值](盔甲值.md)、[保护](保护.md)、[抗性提升](抗性提升.md)等因素增加或减少所受伤害

由于蜘蛛只有的生命值，使用节肢杀手V可以在攻击冷却结束后一击杀死它们。[斧](斧.md)甚至可以在更低的魔咒等级下实现此效果。

# == Java版 ==
注：暴击不增加魔咒攻击力。

# == 基岩版 ==
注：魔咒攻击力向下取整，暴击增加魔咒攻击力。
