# MINECON

*页面ID: 8742* | *来源: Minecraft Wiki*

[200px|缩略图|MINECON的logo](File:New_MineCon_Logo.png.md)

* *MINECON**是[Mojang Studios](Mojang Studios.md)自2010年至2016年举办的*[Minecraft](Minecraft.md)*线下聚会活动。

# MINECON

# = 2010 =

# == MinecraftCon ==
[200px|右|MinecraftCon 2010 logo](File:MinecraftCon 2010 logo2.png.md)

* *MinecraftCon 2010**于2010年8月31日在华盛顿州贝尔维尤举行，是Minecraft粉丝的自发聚会。它是由Notch在博客文章中构思的。<ref></ref>

# == MINECON 2010 ==
[200px|缩略图|MINECON 2010的logo](File:MINECON 2010 logo.png.md)

* *MINECON 2010**是Minecraft [Classic](Java版Classic.md)服务器上Minecraft粉丝的聚会。<ref>http://www.minecraftforum.net/topic/11896-</ref>[Minecraft Forums](Minecraft Forums.md)上的[这个主题](http://www.minecraftforum.net/topic/11896-)是聚会的非正式组织点。

# = 2011 =

[右|200px|缩略图|MINECON 2011的logo](File:MINECON 2011 logo.png.md)
* *MINECON 2011**于2011年11月18日在内华达州拉斯维加斯曼德勒海湾举行，恰逢游戏（[Java版1.0.0](Java版1.0.0.md)）发布。<ref></ref>它位于美国内华达州曼德勒海湾度假村和赌场。门票于2011年8月11日开始销售。与会者获得了独有的MINECON 2011[披风](披风.md)。

MINECON举办了许多激动人心的活动，包括正式发布的Minecraft、Minecraft社区成员的主题演讲（包括[Notch](Notch.md)）、建筑竞赛、具有不同Minecraft主题的分组课程、服装比赛、展览、会议和全球Minecraft人物和纪念商品。

# = 2012 =

[200px|右|缩略图|MINECON 2012的logo](File:MINECON 2012 Logo.svg.md)
* *MINECON 2012**于当年11月24日至25日在[巴黎迪士尼乐园](wzh:巴黎迪士尼乐园度假区.md)举行。该会议有4500人参加，与去年大致相同。<ref>http://www.bbc.co.uk/news/technology-20492574</ref>与去年一样，MINECON 2012的与会者获得了独有披风。

# = 2013 =

[200px|右|缩略图|MINECON 2013的logo](File:MINECON 2013 Logo.png.md)
* *MINECON 2013**于11月2日-11月3日在佛罗里达州奥兰多举行。

Mojang于6月27日透露，MINECON 2013将于11月2日至3日在佛罗里达州奥兰多举行。<ref>https://mojang.com/2013/07/where-in-the-world-is-minecon-2013/</ref>在经历了许多谜团之后，Mojang正式确认MINECON 2013将在[橘子郡会展中心](wikipedia:Orange County Convention Center.md)举办。<ref>https://mojang.com/2013/07/minecon-tickets-are-here/</ref>7月31日之前，Mojang确认门票将于当天晚些时候开始销售。据说这些门票分三批发售，<ref>http://minecon.eventbrite.com/</ref>每批售出2500张门票，每件150美元（总共7500张门票）。Mojang于9月5日发布消息称，MINECON的与会者将获得2013年的MINECON披风。<ref>[MINECON 2013 support page](http://help.mojang.com/customer/portal/articles/1246918-minecon-2013)</ref>

# = 2015 =

[200px|缩略图|MINECON 2015的logo](File:MINECON 2015 Logo.png.md)

* *MINECON 2015**于7月4日-5日在英国伦敦的ExCeL国际会展中心举办。<ref>http://www.excel-london.co.uk/whats-on/minecon-2015/</ref>2014年3月30日，最初宣布下一届MINECON将在欧洲的某个地方举行。后来证实，MINECON无法在2014年举行，而是必须滞后至2015年春季在伦敦举行。<ref>https://mojang.com/2014/08/minecon-2015/</ref>2015年3月18日，Mojang宣布门票将于3月27日（周五）和3月28日（周六）开售。<ref name="2015Ticket">https://mojang.com/2015/03/minecon-2015-tickets-announcement/</ref>3月28日，门票分两批发布<ref>http://minecon2015.eventbrite.co.uk/</ref>。

# = 2016 =

[200px|右|缩略图|MINECON 2016的logo](File:MINECON 2016 Logo.png.md)

* *MINECON 2016**于9月24-25日在美国加利福尼亚州的安纳海姆举行。此次活动公布于2016年3月7日<ref>[MINECON 2016 Announcement](https://youtu.be/1nP328vm5ik) - YouTube</ref>，门票于5月6日-7日发售。<ref>http://www.mojang.com/2016/04/minecon-2016-tickets</ref>

# MINECON Earth、MINECON Live及Minecraft LIVE

[200px|缩略图|Minecraft LIVE的logo](File:Minecraft Live September 2025 Logo.png.md)

2017年起，MINECON由线下聚会调整为线上直播形式，调整后最初被称为MINECON Earth，2019年更名为MINECON Live，2020年定名为Minecraft LIVE。

# Minecraft Festival
[200px|thumb|Minecraft Festival的logo](File:Minecraft Festival 2020 Logo.png.md)

* *Minecraft Festival**是一次在佛罗里达的奥兰多市举行的聚会活动，原计划于2020年举办，之后由于[COVID-19疫情](wzh:2019冠状病毒病疫情.md)而被一再推迟，具体举办日期待定。<ref></ref><ref>https://minecraftfestival.com/</ref>
