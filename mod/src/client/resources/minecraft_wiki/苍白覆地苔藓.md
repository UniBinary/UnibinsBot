# 苍白覆地苔藓

*页面ID: 126808* | *来源: Minecraft Wiki*

}}

* *苍白覆地苔藓（Pale Moss Carpet）**是一种会在相邻方块的侧面生长出藤蔓般的苍白苔藓的方块。

# 生成
# = 自然生成 =
苍白覆地苔藓会自然生成于[苍白之园](苍白之园.md)生物群系。

# = 骨粉 =
对着上方为空气的[苍白苔藓块](苍白苔藓块.md)[骨粉](骨粉.md)有25%的概率在其水平[切比雪夫距离](切比雪夫距离.md)半径3格，垂直切比雪夫距离半径5格范围内随机生成苍白覆地苔藓。

# 破坏
挖掘苍白覆地苔藓的合适工具是锄。

苍白覆地苔藓被破坏后会掉落自身。

# 用途
苍白覆地苔藓的碰撞箱为格。

苍白覆地苔藓可以放在任何非[空气](空气.md)方块上，包括[结构空位](结构空位.md)和[光源方块](光源方块.md)。

苍白覆地苔藓可以放在[栅栏](栅栏.md)和[墙](墙.md)的顶部，使玩家能够在上面跳跃。

苍白覆地苔藓无法被[活塞](活塞.md)拉动，并且伸出的[活塞头](活塞头.md)或流动的[水](水.md)经过苍白覆地苔藓时会破坏苍白覆地苔藓使其变成掉落物。

苍白覆地苔藓是[光照透明方块](亮度#光照透明方块.md)。

# = 放置 =
|苍白覆地苔藓及其藤蔓纹理}}
当苍白覆地苔藓被放置在一个方块旁边时，藤蔓纹理会出现于该方块与之相邻的表面上。如果该方块上方还有第二个方块，当放置苍白覆地苔藓时，则有50%的概率出现两格高的藤蔓纹理。玩家可以破坏第二个藤蔓纹理，以使其保持在一个方块高；对苍白覆地苔藓或第一格藤蔓纹理[骨粉](骨粉.md)会长出第二格藤蔓纹理。

# = 堆肥 =
将苍白覆地苔藓放进[堆肥桶](堆肥桶.md)有30%的概率使堆肥层数加1。
