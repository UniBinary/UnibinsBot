# Java版19w08a

*页面ID: 40259* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w08a**是[Java版1.14](Java版1.14.md)的第22个快照，发布于2019年2月20日<ref></ref>，加入了皮革马铠和棕色哞菇，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[马铠](马铠.md)**
* 加入了皮革马铠。
* * 由7个皮革制成。
* * 和[皮革盔甲](皮革盔甲.md)相似，共有12,326,391种颜色可[染](染色#盔甲.md)。

# = 生物 =
* *棕色[哞菇](哞菇.md)**
* 不会自然生成。
* * 当普通红色哞菇被[闪电](闪电.md)击中时生成。
* * 当再次被闪电击中时变回红色哞菇。
* 当棕色哞菇被喂食[花](花.md)后，下次对它使用碗时会得到与花对应的[谜之炖菜](谜之炖菜.md)。
* * [谜之炖菜](谜之炖菜.md)在喂食花后仅提供一次。

# 更改
# = 方块 =
* *[绿宝石块](绿宝石块.md)、[钻石矿石](钻石矿石.md)、[闪长岩](闪长岩.md)、[草方块](草方块.md)、[积雪的草方块](草方块.md)和[橡木门](橡木门.md)**
* 更新了纹理。

* *[平滑石英块](平滑石英块.md)**
* 现在使用的是普通石英块的底部纹理，而不是顶部。

* *[染色玻璃](染色玻璃.md)和[染色玻璃板](染色玻璃板.md)**
* 更新了纹理，使其和普通玻璃和玻璃板相对应。

# = 物品 =
* *[金盔甲](金盔甲.md)、[马铠](马铠.md)、[蛋糕](蛋糕.md)、[绿宝石](绿宝石.md)、[幻翼膜](幻翼膜.md)和[雪球](雪球.md)**
* 更新了纹理。

# = 生物 =
* *常规**
* 可以使用命令让生物在床上睡觉。

* *[海豚](海豚.md)**
* 不再能通过[发射器](发射器.md)来为它们装上盔甲。

* *[狐狸](狐狸.md)**
* 更改碰撞箱和眼部的高度（防止狐狸在游泳时溺水）。
* 不再能通过发射器来为它们装上盔甲。
* 狐狸吠叫的声音被重命名为尖叫声。

* *[铁傀儡](铁傀儡.md)**
* 更新了纹理。

* *[熊猫](熊猫.md)**
* 不再能通过发射器来为它们装上盔甲。
* 5%的自然生成的熊猫会是幼年熊猫。

* *[哞菇](哞菇.md)**
* 加入了2种新的音效：转变为普通牛和进食。
* 哞菇现在有了个<code>type</code>数据字段。

* *[骷髅马](骷髅马.md)和[僵尸马](僵尸马.md)**
* 更新了纹理。

# = 世界生成 =
* *[村庄](村庄.md)**
* 所有的村庄现在都会生成一个[铁傀儡](铁傀儡.md)。
* 更新了动物生成结构和村民生成结构。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
* 状态效果的图标文件被拆分，每种状态效果现在是独立的文件。
* 更新了[不祥之兆](不祥之兆.md)、[幸运](幸运.md)和[霉运](霉运.md)的图标。
* 改进了[隐身](隐身.md)状态效果，使其在许多情况下正常工作。
* * 守卫者不再能看见隐身的玩家。
* * 僵尸和灾厄村民不再能看见隐身的村民和流浪商人。

# = 命令格式 =
* 除双引号外，单引号<code>'text'</code>现在可用于命令中的字符串引号。<ref>[Allow single quote in strings by boq · Pull Request #52 · Mojang/brigadier](https://github.com/Mojang/brigadier/pull/52)</ref>
* * 单引号字符串内的双引号作为普通字符处理，不需要转义（反之亦然），这样可以更容易地在NBT中输入文本组件。

# = 常规 =
* 在[上一个快照](19w07a.md)加入的加载界面现在会在切换游戏语言和更改或重新载入[资源包](资源包.md)时显示。
* * 进行这些工作时不会使客户端无响应。
