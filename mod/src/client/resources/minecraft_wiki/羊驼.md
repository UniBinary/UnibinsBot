* *羊驼（Llama）**是一种驯服后可以驮运货物的友好生物。

# 生成
羊驼会在[热带高原](热带高原.md)、、[风袭丘陵](风袭丘陵.md)、[风袭森林](风袭森林.md)和[风袭沙砾丘陵](风袭沙砾丘陵.md)中自然生成，生成的地方亮度等级需大于等于7且位于草方块上。

羊驼有10%的概率生成为幼年个体。

不对着羊驼使用的[刷怪蛋](刷怪蛋.md)生成的羊驼总是成年羊驼<ref></ref>；而使用刷怪蛋生成的幼年羊驼与自然生成概率一致。

# 掉落物
成年羊驼死亡后会掉落以下物品：

}}
* 已装备的和。
* [物品栏](物品栏.md)内的任何物品。
* ，若被[玩家](玩家.md)或驯服的[狼](狼.md)杀死。

杀死幼年羊驼不会掉落任何物品或经验。

# 行为
羊驼可以走上1格高的方块而无需跳跃。

与大多数生物不同的是，羊驼可以缓慢地恢复损失的生命值。

# = 吐唾沫 =

如果羊驼受到攻击，它会试图逃离攻击者，停止逃跑后朝攻击者吐一口唾沫，造成的伤害（无论是否被驯服，无论是否成年）。与大多数会反击目标至死亡的生物不同，羊驼只会吐一次唾沫，无论是否命中都不会再继续攻击，但被吐中的生物有可能反击羊驼。当它们向攻击者吐唾沫时，有时会因为误击同类而导致一群羊驼互相攻击。当[难度](难度.md)为和平时，羊驼不会攻击玩家。

羊驼会主动攻击未驯服的[狼](狼.md)。羊驼会基于它们的强度（实体数据）击退狼。遇到强度为4或5的羊驼，狼总会逃跑；<ref></ref>对于较弱的羊驼，狼则会时不时相应地逃跑。

在没有被激怒的情况下，羊驼不会攻击驯服的狼。但如果玩家驯服了正在被羊驼攻击的狼，羊驼仍会继续攻击。

# = 牵引 =
当一只羊驼被[拴绳](拴绳.md)拴住时，附近最多10只羊驼或[行商羊驼](行商羊驼.md)（无论是否被驯服，无论是否成年）会以一定的顺序跟随该羊驼，形成一支驼队。虽然每支驼队可容纳的羊驼或行商羊驼数量有限，但玩家还可以再拴住一只羊驼形成另一支驼队。

如果驼队中的一只羊驼突然死亡或被传送到范围外，排在其后面的所有羊驼或行商羊驼都会脱节并且不再跟着驼队；这种情况会导致驼队成员的顺序有变动，但不会脱节。

如果被拴绳拴住的羊驼与其他实体连接，则不会形成驼队。

# = 驯服 =
成年羊驼可以被驯服。骑乘羊驼直到心形[粒子](粒子.md)出现即为成功驯服。羊驼被驯服后，玩家可以通过骑着羊驼打开物品栏来查看它的物品栏UI，或者在时对着羊驼来打开。

驯服难度取决于羊驼的值（好感度），好感度越高的羊驼越容易驯服。羊驼好感度的初值为0，最高值为30。当玩家骑上未驯服的羊驼时，会随机生成一个范围在0到29内的数。羊驼在好感度高于该数值时被驯服，否则玩家会被弹下驼背，并且好感度增加5。喂食羊驼亦能增加好感度，详见[下文](#喂食.md)。

与其他可驯服生物一样，驯服的羊驼死亡时会给世界中的所有玩家显示一条[死亡消息](死亡消息.md)，而不会<ref></ref>。

已驯服的羊驼不能被装备[鞍](鞍.md)，因此玩家无法通过骑乘控制它们移动。

# == 装饰 ==
[缩略图|右|250px|羊驼所有的装饰样式](File:All llama swag patterns.png.md)

已驯服的羊驼拥有用于装备1个[地毯](地毯.md)的槽位，不同颜色的地毯产生的装饰样式不同。

可以通过命令在羊驼的<code>armor.body</code>槽位装备地毯。

玩家可使用[剪刀](剪刀.md)将羊驼上身的地毯剪下。

状态下的羊驼仍会显示其身上的地毯。

# == 储存 ==

手持[箱子](箱子.md)对着已驯服的羊驼能装备上箱子，并根据强度（实体数据）给出3、6、9、12或15格的物品栏空间。物品栏空间数量的算法是3*。

玩家无法卸下羊驼身上的箱子，除非它们死亡。

# = 喂食 =
手持食物对着羊驼可给其喂食。下表罗列出了羊驼可食用的食物和其对羊驼的效果。

羊驼会跟随/手持干草捆的玩家。

# == 繁殖 ==

给两只生命值已满的已驯服的羊驼喂食[干草捆](干草捆.md)，可以使它们进入[繁殖](繁殖.md)模式。

两只羊驼繁殖时，会产下一只幼年羊驼。幼年羊驼需要20分钟成长为成年个体，给其喂食小麦或干草捆可以加速其成长。

对幼年羊驼[金蒲公英](金蒲公英.md)可以阻止其成长为成年羊驼，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年羊驼无法被喂食除金蒲公英外的其他物品。

一只羊驼和一只行商羊驼繁殖时，有均等概率产下一只幼年羊驼或幼年行商羊驼。

一只羊驼和一只行商羊驼繁殖时，会产下一只幼年羊驼。

每次繁殖后会掉落，双亲进入/的冷却时间，之后才能继续繁殖。

幼年羊驼的毛色会等概率地遗传自其双亲之一。普通羊驼身上的地毯样式不会遗传。

繁殖出的幼年羊驼的强度则是在1和较强双亲的强度间取一个随机整数，这个数有3%的概率会加1，但最大值仍然是5。查看下表以快速参考具体概率。

以较强双亲的某一行为基准，其对应的列中的数据显示各种子代强度的可能性。

# 统计
所有的羊驼具有2种“马匹统计”，每只羊驼都有所不同：生命值、强度。 这些数据是在羊驼出生或生成后固定的，喂食对其没有影响。

# == 生命值 ==
羊驼的生命值范围在到之间，但趋于均值。生命值为奇数的羊驼不会在生命条中显示出最后半颗心。

# == 强度 ==
羊驼的强度（实体数据）影响羊驼能够携带的物品数量以及使[狼](狼.md)逃离的能力，其范围为1-5，但趋向于1-3。
