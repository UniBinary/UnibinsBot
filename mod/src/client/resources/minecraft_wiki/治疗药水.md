# 治疗药水

*页面ID: 181488* | *来源: Minecraft Wiki*

* *治疗药水**是提供[瞬间治疗](瞬间治疗.md)状态效果的[药水效果](药水效果.md)。

该药水效果可以制成[药水](药水.md)**治疗药水（Potion of Healing）**、[喷溅药水](喷溅药水.md)**喷溅型治疗药水（Splash Potion of Healing）**、[滞留药水](滞留药水.md)**滞留型治疗药水（Lingering Potion of Healing）**和[藥水箭](藥水箭.md)**治疗之箭（Arrow of Healing）**。

此药水效果有对应的增强版。

# 生成
# = 生物 =
[女巫](女巫.md)会对生命值低于的[灾厄村民](灾厄村民.md)或[劫掠兽](劫掠兽.md)投掷喷溅型治疗药水。

# = 礼物 =

[制箭师](制箭师.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷治疗之箭。

# = 女巫 =
[女巫](女巫.md)在生命值未满時會饮用治疗药水。若飲用时被杀死，该药水有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率作为装备掉落物掉落。

# = 自然生成 =

[沼泽小屋](沼泽小屋.md)的[炼药锅](炼药锅.md)内可能装有治疗药水。

# = 箱子战利品 =

# = 炼药锅 =

对装有治疗药水的炼药锅使用[玻璃瓶](玻璃瓶.md)可获得治疗药水、喷溅型治疗药水或滞留型治疗药水，具体形式取决于炼药锅内容物。

对装有治疗药水的炼药锅使用[箭](箭.md)可获取治疗之箭，最大数量随内容物水位增加依次为16、32和64。

# 行为
治疗药水包含[瞬间治疗](瞬间治疗.md)状态效果，由于瞬间治疗是一种即时生效效果，因此生物饮用治疗药水、被喷溅治疗药水击中或位于滞留治疗药水形成的[区域效果云](区域效果云.md)中时会直接受到瞬间治疗效果造成的效果。对于增强版治疗药水同理。
