# = 音乐 =

[noicon](File:Pigstep.ogg.md)

Pigstep是一首节奏强烈、节拍类似嘻哈风格、旋律狂野的曲目。

该曲目始于重复的大号曲调和回响贝斯风格的落点，同时也有一些使人联想到收音机的更柔和的部分。

在专辑中，该曲目有单声道（*Pigstep - Mono Mix*）和双声道（*Pigstep - Stereo Mix*）两个版本，游戏内采用的是单声道版本。

# = 红石 =
