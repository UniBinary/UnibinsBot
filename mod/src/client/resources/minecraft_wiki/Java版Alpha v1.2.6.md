# Java版Alpha v1.2.6

*页面ID: 32568* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.2.6**是的一次次要更新，也是[Alpha](Java版Alpha.md)开发阶段的最后1个版本，发布于2010年12月3日。<ref name="bu5"></ref>

# 新内容
* 在[多人游戏](多人游戏.md)中加入了，能对[玩家](玩家.md)造成伤害。
* 在地表和洞穴中加入了小型[湖泊](地形特征.md)和罕见的小型[熔岩](熔岩.md)池。

# 修复
* *修复了4个漏洞**
* 物品不会在打开箱子时被使用了。
* 使用某种方式破坏船时，会掉落几倍于正常数量的掉落物。
* 对客户端打了补丁，以避免重复实体。
* 修复了破坏玩家下方的载具时游戏崩溃的漏洞。</onlyinclude>
