# 梯子

*页面ID: 6227* | *来源: Minecraft Wiki*

* *梯子（Ladder）**是用于在墙上进行水平或垂直移动的木质[方块](方块.md)。它们只能放在方块的侧面。

# 生成
# = 自然生成 =
梯子可以自然生成在：
* [要塞](要塞.md)的图书馆房间以及有木质天花板的房间交界处；
* [村庄](村庄.md)的部分建筑中，如教堂以及有屋顶和栅栏的房子里；
* [雪屋](雪屋.md)的地下室通道中；
* [末地城](末地城.md)和[末地船](末地船.md)中；
* [林地府邸](林地府邸.md)的部分房间内；
* [远古城市](远古城市.md)的部分结构中；
* [古迹废墟](古迹废墟.md)的部分结构中；
* [试炼密室](试炼密室.md)的部分结构中。

# 破坏
挖掘梯子的合适工具是斧。

梯子被破坏后会掉落自身。

# 用途
梯子只能被放置在一个方块完整的侧面上。如果尝试将其放置在不符合要求的表面上，梯子就会试图“滑入”一个合理的位置。

不能在梯子的正面放置梯子，即使这个面相对的位置有一个可以放置梯子的表面。这允许玩家按住键不断上爬或下降并放置梯子的同时，不会将梯子贴到不期望的位置上。

梯子会阻挡[水](水.md)和[熔岩](熔岩.md)的流动。梯子放入水源后会[含水](含水.md)，放入熔岩或流动的水后则会将其替代。

梯子有一个可以站立的上表面，。生物摔落到梯子的上表面可能会受到摔落伤害。

# = 攀爬 =
当生物的[碰撞箱](碰撞箱.md)底面中心点在梯子所在的方块空间时，梯子会产生作用：

* 当生物朝梯子依附的墙壁推进时，生物会以约每秒2.5格的速度沿着梯子上升至顶端。
* 生物最大下落速度会被降低到爬梯的速度。
* * 如果生物坠落时落到梯子的作用范围中，坠落速度也会被重置为这个速度，并且生物不会受坠落伤害。
* 生物在梯子上的水平移动摩擦力与[冰](冰.md)的相同。（也就是说，使用冰和梯子在狭小的空间里移动时，效果将会相同。）

在梯子上会紧靠住梯子而不下滑，此时由于没有站在地面上，[挖掘](挖掘.md)方块需要的时间会变为5倍。

有外力作用时，[生物](生物.md)可以像玩家一样爬上梯子，但它们不会刻意这么做。

[马](马.md)、[驴](驴.md)、[骡](骡.md)、[羊驼](羊驼.md)、[骷髅马](骷髅马.md)和[僵尸马](僵尸马.md)不能使用梯子，通过梯子时不被影响移动。

含水的梯子不可攀爬。

# = 活板门 =

若一个开启的[活板门](活板门.md)的下方有梯子，则这个活板门可以作为梯子使用。

# = 燃料 =
梯子能用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个梯子可以烧炼1.5个物品。

# 你知道吗
* 通过按住跳跃键，玩家仍然能够使用隔着的梯子制作而成的水梯。
* 尝试在另一个梯子占据的地方放置梯子会把梯子放在附近的某个地方（因为梯子有碰撞箱）。
* 可以在梯子上按着潜行键时移除梯子，但需要较长时间，因为玩家未着地时破坏任何方块的时间都会延长5倍。
* 与步行、冲刺和游泳时不同的是，在爬梯子的时候，吃食物、用盾格挡和拉弓的动作不会使玩家的移动速度减慢。
* 像[藤蔓](藤蔓.md)那样，玩家穿过梯子时速度会变慢。
* 如果玩家站在梯子下面一格的下半[台阶](台阶.md)上，玩家要跳跃才能爬上梯子。
* 利用梯子上方的活板门可作为梯子使用的特性，可以将活板门与梯子交错向上搭建来实现一个在两侧都可攀爬的梯子。
