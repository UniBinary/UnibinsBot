# 携带版0.10.1

*页面ID: 24043* | *来源: Minecraft Wiki*

* *v0.10.1 alpha**是携带版的一次次要更新，发布于2014年11月19日，此次更新仅在Android上发布，修复了[v0.10.0 alpha](携带版0.10.0.md)中的一些漏洞与崩溃。

# 修复
* 修复了一些漏洞与崩溃。
* 修复了一个会导致区块损坏的漏洞。
