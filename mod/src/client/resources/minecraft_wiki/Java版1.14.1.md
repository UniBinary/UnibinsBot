# Java版1.14.1

*页面ID: 42997* | *来源: Minecraft Wiki*

* *1.14.1**是的一次次要更新，发布于2019年5月13日<ref></ref>，加入了新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了以下标语：
* * “Awesome game design right there!”（精彩的游戏设计就在那里！）
* * “Ph1lza had a good run!”（Ph1lza<ref group="注">极限模式玩家，曾保持极限模式生存时间最久记录，于2019年4月24日被幼年僵尸打至残血后被蜘蛛所杀。</ref>已经做得很不错了！）
* * “10 years of Mining and Crafting!”（Minecraft十周年！）

* *[控制](控制.md)**
* 在按住时按下会暂停游戏，并不会打开暂停菜单。

# 更改
# = 方块 =
* *[营火](营火.md)**
* 着火的箭可以点燃[营火](营火.md)。
* *[工作台](工作台.md)**
* 根据[木板](木板.md)纹理更新了纹理。
* *[铁矿石](铁矿石.md)**
* 更改了纹理以修复错误的着色像素。

# = 物品 =
* *[皮革马铠](皮革马铠.md)**
* 根据[纹理更新](纹理更新.md)更新了纹理。
* *[铁马铠](铁马铠.md)**
* 稍微调整了颜色。

# = 世界生成 =
* *[村庄](村庄.md)**
* 许多结构为了改进光照而有所更改。
