* *生猪排（Raw Porkchop）**是一种[食物](食物.md)，可以被烹饪成[熟猪排](熟猪排.md)。

# 获取

# = 生物掉落物 =

# = 箱子战利品 =

# 用途
# = 食物 =

手持生猪排按住键即可食用，每个生猪排可以回复。

# = 烹饪 =
生猪排能在[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或[营火](营火.md)中被烹饪成[熟猪排](熟猪排.md)。

# = 狼 =
生猪排能用来吸引、治疗或繁殖驯服的[狼](狼.md)，也可以使驯服的幼年狼缩短其生长时间的10%。

# = 交易 =

# = 猪灵 =
[猪灵](猪灵.md)会主动捡起生猪排和[熟猪排](熟猪排.md)。

猪灵不会主动搜寻生猪排和熟猪排，但会被猪灵[拾取](物品（实体）#拾取.md)，且捡起后10秒内不会再捡起这两种物品。
