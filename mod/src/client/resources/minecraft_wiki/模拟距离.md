# 模拟距离

*页面ID: 90792* | *来源: Minecraft Wiki*

* *模拟距离（Simulation Distance）**是控制世界计算范围的设置。
# 模拟距离范围

服务器的模拟距离可以在[server.properties](server.properties.md)文件里修改。

# 基岩版
# = 设置 =
创建新世界时，设置中有一个调整模拟距离的滑块。每个世界的模拟距离是独立的，在世界处于加载状态时无法更改。

# = 生成和清除 =

模拟距离限制了生物生成和清除的最大距离。
[right|300px|thumb|基岩版生成与模拟距离的关系](File:Simulation Distance Example.png.md)

在模拟距离内，每个区块、每一游戏刻有的概率在尝试运行生物生成的算法。

在最大生成距离内大于32格超过30秒后，并且在最近30秒内没有受到伤害时，每游戏刻有的概率被随机清除。

鱼只在高度Y=50至Y=64之间的水中自然生成，生成在距离玩家12-32格远。

右图是模拟距离在4-12之间的整数时的范围示意图<ref>https://www.desmos.com/calculator/b4vlwpausw?lang=zh-CN</ref>，其中黑色表示玩家所在位置，红色表示加载的区块，绿色表示生物生成的范围，不在绿色区域内的生物会被立刻清除。

无论模拟距离为多少，有持久性的生物不会被清除。<div style='float:right'></div>

具有持久性NBT标签的生物不会被清除。以下方式会使生物拥有持久性：
* 该生物与玩家互动：
* * 被玩家骑乘
* * 被[命名牌](命名牌.md)命名
* * 受[食物](食物.md)诱惑
* * 是其他生物繁殖的后代（海龟蛋除外）
* * 被玩家驯服
* * 是或是刷怪蛋生成的
* * [是被治愈的僵尸村民](僵尸村民#治愈.md)（生成[村民](村民.md)）
* * 是触发骷髅陷阱生成的（生成[骷髅马](骷髅马.md)和[骷髅](骷髅.md)）
* 该生物是伴随结构生成的：
* * [末地城](末地城.md)中的[潜影贝](潜影贝.md)
* * [沼泽小屋](沼泽小屋.md)中的[女巫](女巫.md)
* * [僵尸村庄](僵尸村庄.md)中的[僵尸村民](僵尸村民.md)
* * [林地府邸](林地府邸.md)中的[卫道士](卫道士.md)

以下实体总是拥有持久性：
* [末影龙](末影龙.md)
* [凋灵](凋灵.md)
* [远古守卫者](远古守卫者.md)
* [守卫者](守卫者.md)
* [铁傀儡](铁傀儡.md)
* [雪傀儡](雪傀儡.md)
* [村民](村民.md)
* [盔甲架](盔甲架.md)
* [智能体](智能体.md)

[鱼](鱼.md)只要距离最近的玩家40格之外就会被立刻清除。

# = 区块加载 =

区块的加载范围也由模拟距离n决定，控制实体、方块更新的最大范围，其最大的加载范围距离玩家曼哈顿距离n+1个区块，且与玩家所在区块的X和Z坐标相同的最外侧4个区块不加载。

卸载的区块的[游戏刻](游戏刻.md)会停止执行，农作物停止生长，液体停止流动等。

命令的作用范围与模拟距离有关。<ref></ref>

# Java版
# = 设置 =
所有本地世界的模拟距离都是一致的，且可以随时更改。

# = 生成和清除 =
模拟距离与生物的生成与清除无关，参见[生成](生成.md)。

# = 区块加载 =

模拟距离决定了区块计算等级。

# 你知道吗

* 模拟距离在理想情况下应当小于渲染距离，因为在模拟距离内更新所有实体比相等的渲染距离对性能的负担更大。
