# 嗅探兽蛋

*页面ID: 103265* | *来源: Minecraft Wiki*

* *嗅探兽蛋（Sniffer Egg）**是一种能够孵化出幼年[嗅探兽](嗅探兽.md)的方块。

# 生成
嗅探兽蛋不会生成在世界中。

# 获取
# = 考古战利品 =
用[刷子](刷子.md)刷扫热带[海底废墟](海底废墟.md)里的[可疑的沙子](可疑的沙子.md)有概率掉落嗅探兽蛋。

# = 嗅探兽 =
给两只成年嗅探兽喂食[火把花种子](火把花种子.md)使之繁殖后，其中一只会掉落一个嗅探兽蛋。

# 破坏
没有工具可以加速对嗅探兽蛋的挖掘。

嗅探兽蛋被破坏后会掉落自身。

# 用途
嗅探兽蛋有3个生长阶段，可以通过其纹理的开裂外观来判断。嗅探兽蛋被放置时处于第1阶段。

在被放置后或进入新的生长阶段后，嗅探兽蛋会为自己设置一个至的[计划刻](计划刻.md)，若下方有[苔藓块](苔藓块.md)则改为至。在收到计划刻后，嗅探兽蛋会试图进入下一阶段，若已经是第3阶段则生成一个幼年嗅探兽并移除自身。

嗅探兽蛋总共需要至来孵化，若下方有苔藓块则需要至来孵化。

不同于[海龟蛋](海龟蛋.md)，嗅探兽蛋在放置后不会被踩坏，[僵尸](僵尸.md)等[亡灵生物](亡灵生物.md)也不会寻找嗅探兽蛋并试图摧毁它。

[活塞](活塞.md)可以推动嗅探兽蛋。<ref></ref>这甚至会加快其孵化速度。<ref></ref>
