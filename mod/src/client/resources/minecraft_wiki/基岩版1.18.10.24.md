# 基岩版1.18.10.24

*页面ID: 91715* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.10.24**是[基岩版1.18.10](基岩版1.18.10.md)的第4个测试版，发布于2021年12月15日<ref></ref><ref></ref>，在[实验性玩法](实验性玩法.md)中加入了[青蛙](青蛙.md)、[蝌蚪](蝌蚪.md)及其相关方块和物品，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[旗帜图案](旗帜图案.md)**
* 加入了地球旗帜图案，以同步。
* * 目前无法在[生存模式](生存模式.md)中正常获得。

# 更改
# = 技术性 =
* *Android**
* 将应用程序所使用的目标API更新至API 30。

* *数据驱动生物**
* 现在自然生成的成年豹猫伴随两只幼年豹猫一同生成的随机概率由实体JSON定义中添加的组件处理。

* *[Molang](Molang.md)**
* 加入了，其作为WearableItemComponent和Molang的槽位参数。

* *RandomStrollGoal**
* 优化了RandomStrollGoal的性能。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“荒野更新”和“应用测试框架”子选项后才可使用。

# = 方块 =
* *[青蛙卵](青蛙卵.md)**
* 一种可放置于水上的非固体方块。
* 青蛙繁殖后产出。
* 可孵化出2-6只蝌蚪。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了青蛙刷怪蛋和蝌蚪刷怪蛋。

* *[蝌蚪桶](蝌蚪桶.md)**
* 通过对蝌蚪[水桶](水桶.md)获得。
* 可用于携带蝌蚪，类似于[鱼桶](鱼桶.md)。

# = 生物 =
* *[青蛙](青蛙.md)**
* 自然生成于[沼泽](沼泽.md)生物群系。
* 时常鼓动鸣囊，在陆地上会跳跃行走，在水中会游泳。
* 生成在温度过低、适中、过高的区域中时分别为绿色、橙色、白色。
* 会跟随手持[海草](海草.md)的玩家，并可以用海草繁殖。
* * 繁殖后产下青蛙卵。
* 蝌蚪会发育成青蛙。
* 会捕食小型[史莱姆](史莱姆.md)。

* *[蝌蚪](蝌蚪.md)**
* 青蛙的幼年形态。
* 在陆地上会像[鱼](鱼.md)一样扑腾，最终会脱水而死。
* 最终会发育成青蛙。
* * 喂食海草可加速成长。
* 可以被装在[水桶](水桶.md)里。

# = 技术性 =
* *GameTest框架**
*
* * 更新了以获取。
*
* * 加入了属性，用于指示哪种方块被破坏。

# 修复
* *游戏内容**
* 玩家通过杀死掠夺者队长获得不祥之兆效果后，不再会出现粒子效果。
* 现在玩家睡觉时其屏幕又会逐渐变黑了。（）
* 现在玩家潜行时镜头又会进行位置插值了。（）

* *村民**
* 现在与缺货的村民交易时其会播放拒绝的音效。（）

* *渲染**
* 修复了末影龙在濒死状态下飞向返回传送门时其会变得隐身的问题。（）

* *性能与稳定性**
* 修复了玩家接近村庄时可能发生的崩溃。
* 修复了使用Pocket UI在工作台界面按住键并单击其中的盔甲时可能发生的崩溃。（）

* *用户界面**
* 为物品文本名称条框加入了适当的填充，其会在玩家在生存模式下装备盔甲并选择快捷栏上的物品时体现。（）
* 修复了文本信息包含按钮图案时会减少文本偏移量的问题。

* *原版趋同**
* 加入了地球旗帜图案。

* *命令**
* 修复了使用命令无法杀死带有伤害吸收效果的实体的漏洞。（）
* 现在对驴和骡身上的箱子使用命令时，物品会被放入正确槽位。

* *教育版特性**
* 现在美西螈、蜜蜂、船、猫、海豚、发光鱿鱼、山羊、疣猪兽、铁傀儡、豹猫、熊猫、鹦鹉、猪、北极熊、鱿鱼、炽足兽、狼和僵尸疣猪兽均可以被气球拴住。

* *技术性**
* 玩家在函数中嵌套调用命令时游戏不再会崩溃。（）
* 现在访问其他实体上所缺失的公共变量时会返回0.0，并且不再会导致出错。
* 修复了加载包含大写字母的公共变量时会导致出错的问题。</onlyinclude>
