# 维度定义格式

*页面ID: 63607* | *来源: Minecraft Wiki*

* *维度定义文件**是**维度（Dimension）**在[数据包](数据包.md)中的数据驱动定义文件。

# 定义格式
维度在游戏内使用<code>LEVEL_STEM</code>注册表，数据包路径为，即所有维度定义文件都需要在目录内定义。

维度定义文件使用JSON格式，并具有下列结构：

<div class="treeview">
*  JSON文件根对象
* * ：[维度类型](维度类型.md)，决定了维度除世界生成外的基础特征。虽然游戏支持内联定义但会因为无法获取维度类型的命名空间ID导致无法验证从而中断游戏连接。
* * ：区块生成器，决定了维度[世界生成](世界生成.md)的基础特征。
* ** ：区块生成器类型。
* ** 依区块生成器类型的额外字段，见。
</div>

# = 区块生成器 =
* *区块生成器（Chunk Generator）**决定了维度应该如何生成地形。

除地形生成本身外，区块生成器还决定了本维度的海平面、允许生成地形的最低高度和总高度。对于噪声型区块生成器而言，这些值从噪声设置中读取；而另外两种区块生成器硬编码允许生成地形的最低高度和总高度分别为0和384，平坦型区块生成器海平面为-64，调试型为63。这些值影响了维度的各种行为。

# == debug ==
调试型区块生成器，生成[调试模式](调试模式.md)世界的网格状方块集合。不会生成任何其他地形，固定使用平原生物群系。

<div class="treeview">
*  区块生成器
* * ：<code>debug</code>
</div>

# == flat ==
平坦型区块生成器，生成[超平坦](超平坦.md)世界。超平坦生成设置决定了本维度的地形生成、固定使用的生物群系、生成结构以及部分地物生成。

<div class="treeview">
*  区块生成器
* * ：<code>flat</code>
* * ：超平坦世界生成设置。
* **
</div>

# == noise ==
噪声型区块生成器，使用[噪声生成器](噪声生成器.md)生成更复杂的地形。

[噪声设置](噪声设置.md)决定了维度的地形生成，生物群系源决定了维度的生物群系分布，区块生成的所有阶段都会进行。玩家在此区块生成器的维度中时[调试屏幕](调试屏幕.md)会显示部分世界生成信息。

<div class="treeview">
*  区块生成器
* * ：<code>noise</code>
* * ：生物群系源，决定生物群系如何分布。
* ** ：（命名空间ID）生物群系源类型。
* ** 依生物群系源类型的额外字段，见。
* * ：噪声设置，决定了本维度的地形生成和生物群系分布等。
* ** 见[噪声设置](噪声设置.md)。
</div>

# = 生物群系源 =

生物群系源决定了世界生成中游戏如何放置生物群系。只有噪声生成器可以设置生物群系源，其余两种区块生成器均使用固定型。

# == checkerboard ==
棋盘型生物群系源，以棋盘样式放置生物群系。

<div class="treeview">
*  生物群系源
* * ：<code>checkerboard</code>
* * ：要生成的生物群系。可以为一个生物群系ID、一个生物群系标签或一个生物群系ID的列表。
* * ：（，默认为2）棋盘格的大小。设定为0表示每个格子都是一个区块宽。每次增加时都会加倍。
</div>

# == fixed ==
固定型生物群系源，固定使用一个特定的生物群系。也被[单一生物群系](单一生物群系.md)所用。

<div class="treeview">
*  生物群系源
* * ：<code>fixed</code>
* * ：（命名空间ID）生物群系。
</div>

# == multi_noise ==
多噪声型生物群系源，将根据生物群系噪声放置生物群系。被主世界和下界所用。

<div class="treeview">
*  生物群系源
* * ：<code>multi_noise</code>
* *
* * ：多噪声参数列表，命名空间ID或内联定义均可。
* *
* * ：（不能为空）生物群系参数特征列表。生物群系可以在多个参数特征中出现。
* ** ：一个参数特征。
* ***：一个生物群系ID。
* ***：代表应该放置生物群系的最理想条件。
* ****
</div>

# == the_end ==
末地型生物群系源。被用于[末地](末地.md)维度。
<div class="treeview">
*  生物群系源
* * ：<code>the_end</code>
</div>

# 多噪声参数列表
多噪声参数列表，全称**多噪声型生物群系源参数列表（Multi Noise Biome Source Parameter List）**，用于引用一个内置的生物群系参数。其以JSON文件的形式存储于数据包的{{filepath|-{}-data/<*命名空间*>/worldgen/multi_noise_biome_source_parameter_list}}目录下。

<div class="treeview">
*  JSON文件根对象
* * ：（命名空间ID）一个生物群系参数。原版默认存在<code>overworld</code>和<code>nether</code>两个生物群系参数。
</div>

多噪声参数列表只能引用硬编码的生物群系参数，被原版游戏用于临时修改主世界生物群系分布的世界。当游戏添加了新的实验性生物群系从而需要修改实验性世界引用的生物群系参数时，只需修改多噪声参数列表引用的生物群系参数以间接修改维度，而无需直接修改维度数据。

# 定义行为
维度定义数据仅在服务端启动时加载一次，使用命令不可以使维度定义被重新加载，而必须重启服务端。

游戏加载存档时，会将所有可用的维度的命名空间ID及其定义存储于中，即使修改了维度的数据包被禁用，游戏也能加载被修改后的维度数据。游戏加载存档时，会将所有可用的维度动态加载到世界中，如果修改了维度的数据包被禁用，则游戏不会加载数据包提供的维度。因此**不推荐**在存档创建后对维度进行添加或删除操作，这可能导致存档损坏或载入无效的区块数据。

原版游戏不存在维度定义文件，而是全部使用[世界预设](世界预设定义格式.md)文件定义的维度集来注册维度。但游戏依旧允许通过维度定义文件修改维度，且维度文件对维度定义的优先级高于世界预设文件。
