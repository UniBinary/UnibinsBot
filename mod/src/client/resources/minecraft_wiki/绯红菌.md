* *绯红菌（Crimson Fungus）**是一种形似蘑菇且自然生成于[下界](下界.md)的方块。

# 生成
# = 自然生成 =
绯红菌自然生成于[绯红森林](绯红森林.md)和[诡异森林](诡异森林.md)生物群系，在绯红森林当中生成频率更高。

绯红菌仅生成在Y=25至128间。

# = 骨粉 =
对[绯红菌岩](绯红菌岩.md)或[诡异菌岩](诡异菌岩.md)[骨粉](骨粉.md)有概率使其上方和附近的两种菌岩上出现绯红菌，对绯红菌岩使用骨粉时出现概率更高。

# 获取
# = 箱子战利品 =

# 破坏
绯红菌被挖掘时会立刻被破坏。

绯红菌被破坏后会掉落自身。

# 用途
绯红菌可以种植在菌岩、[灵魂土](灵魂土.md)、草方块、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。绯红菌需要其下方有固体方块，如果没有支撑方块将掉落为物品。

# = 生长 =
对种植在对应绯红菌岩上绯红菌骨粉有40%的概率可使之生长为[巨型绯红菌](巨型绯红菌.md)。若不为绯红菌岩则无法生长。

# = 繁殖 =
绯红菌可用于繁殖[疣猪兽](疣猪兽.md)和加速幼年疣猪兽成长，但它们不会在躲避诡异菌时繁殖。

# = 堆肥 =
对[堆肥桶](堆肥桶.md)使用绯红菌会有65%的概率增加一层堆肥层数。
