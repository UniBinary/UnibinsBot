* *樱花树（Cherry Blossom Tree）**是一种生成于[樱花树林](樱花树林.md)的植被[地物](地物.md)。

# 描述
樱花树的整体高度为10-11格。其枝干歪斜，树叶纹理布满粉红色的樱花，并且树叶会洒下粉红色的[花瓣粒子](粒子#cherry_leaves.md)。

每棵樱花树长有1-3条均在XY或ZY平面内的枝干，其中分枝长2-4格、高3-5格。

樱花树的树冠高5格，上部呈较为规则的团状。樱花树叶每个底面有大约16.7%的概率下垂。

# 生成
樱花树生成时会将下方1格的方块转变为[泥土](泥土.md)。

# = 自然生成 =
[樱花树林](樱花树林.md)生成树木地物时，樱花树有100%的概率生成。

樱花树自然生成时有5%的概率带有一个容纳3只[蜜蜂](蜜蜂.md)的[蜂巢](蜂巢（方块）.md)。

# = 人为生成 =
[亮度](亮度.md)等级至少为9且有一定的空间时，[樱花树苗](樱花树苗.md)可长成樱花树。

若樱花树苗的水平2格范围内存在[花](花.md)、，则长成的樱花树会有5%的概率悬挂着蜂巢，每个由此方式生成的蜂巢都会容纳1-3只蜜蜂。

# 你知道吗
* 现实生活中的樱花木为红棕色，而非游戏中的粉红色。
* 在樱花树林生物群系的早期开发过程中，开发者使用猪的纹理作为樱花树的树叶的占位符。<ref></ref>
* 2013年，[Patrick Geuder](Patrick Geuder.md)表示自己想在Minecraft中见到樱花树，[Dinnerbone](Dinnerbone.md)回复如果他写好了代码，就会把樱花树加进游戏。<ref></ref>
