# Java版1.5.2

*页面ID: 31625* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.5.2**是的一次次要更新，发布于2013年4月25日<ref name="blogpost_1.5.2"></ref>，修复了[Java版1.5](Java版1.5.md)和[Java版1.5.1](Java版1.5.1.md)中的一些漏洞与崩溃。此版本不兼容1.5和1.5.1的服务端。

这是最后一个可以运行在PowerPC架构Mac上的Minecraft版本，并且无需下载即可游玩。由于此版本加入了一个会使PowerPC Mac的光照出现渲染错误的内容，所以继续在PowerPC Mac上运行Minecraft的玩家可以使用1.5.1。

# 修复

|11984|所有方块的纹理都变为绿色和红色并不断闪烁。
