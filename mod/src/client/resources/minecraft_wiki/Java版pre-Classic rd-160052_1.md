# Java版pre-Classic rd-160052

*页面ID: 34827* | *来源: Minecraft Wiki*

<onlyinclude>

* *rd-160052**是2009年5月15日22:52（UTC）制作完成的[pre-Classic](Java版pre-Classic.md)版本。<ref></ref><ref group="注">虽然部分来源称该版本于5月16日发布，但实际上它发布于5月15日22:52（UTC），对应瑞典时间为5月16日00:52。</ref>

# 新内容
# = 常规 =
* *[粒子](Java版粒子.md)**
* 加入了方块粒子实体。
* * 打破方块时会出现。
* * 掉落到地面后会消失。

# 更改
# = 常规 =
* *其他**
* 游戏现在默认以全屏模式运行。</onlyinclude>

# 你知道吗
* 游戏名称从*Minecraft: Order of the Stone*改为“Minecraft”。

# 启动器版
启动器中的该版本由源代码编译而来，且为符合实际情况修改了日期为2009年，因此从技术层面而言并非真正的原版。
