# Java版pre-Classic rd-132211

*页面ID: 34808* | *来源: Minecraft Wiki*

<onlyinclude>

* *rd-132211**是2009年5月13日20:11（UTC）制作完成的一个[pre-Classic](Java版pre-Classic.md)版本。<ref></ref>

# 新内容
# = 游戏内容 =
* *[轮廓箱](轮廓箱.md)**
* 一个闪烁的白色覆盖层，用于显示玩家鼠标所指的方块。

* *常规**
* 可放置和破坏方块。
* * 左键单击放置方块，右键单击破坏方块。
* 无法在世界外放置方块。

# = 常规 =
* *[控制](控制.md)**
* 按可保存存档。
* * 关闭游戏时存档也会自动保存。

# 更改
# = 方块 =
* *常规**
* 现在放置的方块种类由[高度](高度.md)决定。
* * Y=42总是为草方块，而之外总是为[石头](石头.md)或[空气](空气.md)。

# = 世界生成 =
* *常规**
* 改进了世界生成，现在世界不再像[Cave game技术测试](Cave game技术测试.md)视频中那样杂乱随机，而是变得完全平坦。
* 世界大小为256×256×42，可建筑高度为64格。
* Y=41以下的世界被石头填满，Y=42为草方块，其余部分则无任何方块。</onlyinclude>

# 启动器版
启动器中的该版本由源代码编译而来，且为符合实际情况修改了日期为2009年，因此从技术层面而言并非真正的原版。

# 你知道吗
* 与后续版本存档保存在单独文件夹不同，此版本的存档数据保存在启动器文件夹内的文件中。
