# 基岩版1.16.0.55

*页面ID: 57438* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.0.55**是[基岩版1.16.0](基岩版1.16.0.md)的第8个测试版，发布于2020年4月2日<ref></ref>，修复了一些漏洞。

# 更改
# = 物品 =
* *[胡萝卜钓竿](胡萝卜钓竿.md)、[盾牌](盾牌.md)和[锹](锹.md)**
* 调整了耐久以匹配[Java版](Java版.md)。

# 修复
* *修复了41个漏洞**<br>
* *崩溃**
* 修复了可能会在游戏过程中发生的数次崩溃。
* 修复了在iOS设备上创建世界时可能发生的崩溃
* 修复了在带有粒子效果的情况下退出世界时可能发生的崩溃
* 修复了有关玩家下水的一系列问题。
* 修复了生物状态变化时可能发生的崩溃问题。

* *常规**
* 修复了敌对生物的亮度生成的问题。（）
* 修复了存档大于250MB时区块不会被正确加载的问题。（）
* 修复了放置/移除方块后光照不变化的问题。
* 相同的区域刻创建后不会移除同样存在的区域刻了。（）
* 光照会在区块/子区块之间正确传递了。（）
* 修复了服务器上可能导致区域灯光错误的问题。
* 给命令的destroy（旧行为）和keep参数新增overload选项（倘若某项占用该参数，则会报错）。
* 全键盘玩法下的平滑效果会再次正常工作了。（）
* 在下界或末地死掉后死亡背景界面不会再疯狂抖动了。

* *游戏内容**
* 现在可以再次收集含气泡柱的水源方块了。（）
* 修复了鹦鹉站在玩家肩膀上时，使用鱼竿会令浮漂贴在鹦鹉身上的问题。（）
* 现在可以拿着骨粉采集成熟的甜浆果了。（）
* 点燃TNT后，火焰弹会正常消耗了。（）
* 定位器地图中的玩家图标不会变成全白正方形了。

* *方块**
* 破坏门的下半部分后，告示牌不会凭空悬浮了。（）

* *生物**
* 苦力怕丢失目标后不会立刻丢失仇恨了。（）
* 恶魂的碰撞箱不会偏移了。（）
* 修复了以允许实体往下方攻击其他实体。
* 修复了铁傀儡手臂的摆动幅度不正常的问题。

* *图像与渲染**
* 经验球现在是数据驱动了。
* 烈焰球现在是数据驱动了。
* NPC的几何模型和动画现在是数据驱动了。
* 从熔炉中取出物品后不会再变绿了。
* 修复了玻璃和水挨着时水无法覆盖玻璃的问题。
* 修复了加入指南针时自定义闪烁纹理不正确的问题。

* *脚本与组件**
* 移除从未用过的type类型。
* 更新包括了internal entities object或array属性。
* 更新了行为。
* 为添加了目标行为。
* 修复了已被移除或摧毁的实体在脚本中仍然查询为存在的问题。
* 的字段包含无效物品时现在会报错了。
* 因为会查找指定区域中的所有方块，所以不再使用此内容。
* 修复了以解决飞行中的实体无法使用的问题，让飞行实体在落地时不会卡住了
* 在文档中的生成规则部分加入了缺失的 组件（）。
* 在中给提供了无效的物品名后将会报错。</onlyinclude>
