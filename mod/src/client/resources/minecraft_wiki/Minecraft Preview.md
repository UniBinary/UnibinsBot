* *Minecraft Preview**是一个用于测试的beta特性的独立应用。与原有的将beta特性直接加入游戏本体、用户选择加入测试的测试方式不同，beta特性与基岩版正式版得以共存。<ref name="minecraft-preview-initial-post"></ref>

截至目前，此测试计划仅对Windows用户<ref name= "PreviewWin10"></ref>、Xbox用户<ref name= "PreviewXbox""></ref>、PlayStation用户，以及少数iOS和iPadOS平台上的用户有效。

# 开发
2022年1月31日，[Mojang](Mojang.md)宣布测试版计划以Minecraft Preview的形式扩展到其他平台，最早通过TestFlight在iOS/iPadOS平台上发布与正式版相独立的Minecraft Preview应用。此计划最早在TestFlight上仅有500个名额<ref></ref>，后来又增加了500个名额。<ref></ref>

2022年2月7日，Minecraft Preview通过Xbox Insider Hub发布到Xbox平台上，用于测试将存档迁移到新应用上。此测试分为2个阶段，第一阶段会向所有Xbox Insider玩家发布<ref name="PreviewXbox"/>，第二阶段则仅向购买了的玩家发布。<ref></ref>

2022年2月9日，Minecraft Preview在Windows平台上发布，已购买游戏的玩家才可以下载并进行游戏。<ref></ref>

2024年2月15日，Minecraft Preview在PlayStation平台上发布。

# 参与方法
# = iOS & iPadOS =
需要预先注册TestFlight以[获取测试资格](https://aka.ms/PreviewApple)，目前Minecraft Preview仅对TestFlight上有限数量的用户可用。

# = Windows =
Minecraft Preview在[Microsoft Store](https://xbox.com/games/store/-/9P5X4QVLC2XR)上对所有已购买Windows版游戏的玩家，以及订阅了PC Game Pass或Xbox Game Pass Ultimate的玩家可用。<ref name="minecraft-preview-initial-post"/>

# = Xbox =
Minecraft Preview在上对所有已购买Xbox版游戏的玩家，以及订阅了PC Game Pass或Xbox Game Pass Ultimate的玩家可用。<ref name="minecraft-preview-initial-post"/>

# = PlayStation =
打开设置，选择侧边栏底部的“Preview”，点击“获取PlayStation 4 Preview”或“获取PlayStation 5 Preview”即可下载Minecraft Preview。<ref name="minecraft-preview-initial-post"/>

# = 其他平台 =
FAQ中提到Minecraft Preview将会发布到其他平台上，并且FAQ也会在Minecraft Preview发布到这些平台上时同步更新。<ref name="minecraft-preview-initial-post"/>
