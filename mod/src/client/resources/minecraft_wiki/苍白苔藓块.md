# 苍白苔藓块

*页面ID: 126795* | *来源: Minecraft Wiki*

}}

* *苍白苔藓块（Pale Moss Block）**是一种生成于[苍白之园](苍白之园.md)生物群系的方块。

# 生成
# = 自然生成 =
苍白苔藓块会自然生成于[苍白之园](苍白之园.md)生物群系。

# 获取
# = 交易 =

# 破坏
挖掘苍白苔藓块的合适工具是锄。

苍白苔藓块被破坏后会掉落自身。

# 用途
除[仙人掌](仙人掌.md)、[小型垂滴叶](小型垂滴叶.md)和[大型垂滴叶](大型垂滴叶.md)以外的所有植物都可以直接放置在苍白苔藓块上。小型垂滴叶可以放置在上方一格有[水源](水源.md)的苍白苔藓块上。[绯红菌](绯红菌.md)和[诡异菌](诡异菌.md)也可以放在苍白苔藓块上，但是[蘑菇](蘑菇.md)只能在[亮度等级](亮度等级.md)12或以下才可以放置。

# = 骨粉 =
上方一格为空气的苍白苔藓块被玩家或发射器[骨粉](骨粉.md)后，以苍白苔藓块为中心，水平切比雪夫半径或，垂直切比雪夫半径5格范围内，最上方且上方一格为空气<ref>、</ref>的[草方块](草方块.md)、[泥土](泥土.md)、[砂土](砂土.md)、[灰化土](灰化土.md)、[缠根泥土](缠根泥土.md)、[菌丝体](菌丝体.md)、[石头](石头.md)、[深板岩](深板岩.md)、[凝灰岩](凝灰岩.md)、[花岗岩](花岗岩.md)、[闪长岩](闪长岩.md)、[安山岩](安山岩.md)、<ref></ref>、和[苔藓块](苔藓块.md)有概率转变为苍白苔藓块，转变后的苍白苔藓块上有概率出现[苍白覆地苔藓](苍白覆地苔藓.md)、[矮草丛](矮草丛.md)或[高草丛](高草丛.md)中的一种。

# = 转变 =
部分[树苗](树苗.md)以及[杜鹃花丛](杜鹃花丛.md)长成为[树木](树木.md)后会使其下方的苍白苔藓块转变。
* 以2×2放置的云杉树苗长成[大型云杉](大型云杉.md)后，云杉树苗下方的4个苍白苔藓块以及周围的苍白苔藓块会转变为[灰化土](灰化土.md)。
* 杜鹃花丛长成为[杜鹃树](杜鹃树.md)后会将其下方的苍白苔藓块转变为[缠根泥土](缠根泥土.md)。

# = 合成材料 =

# = 堆肥 =
将苍白苔藓块放入[堆肥桶](堆肥桶.md)会有65%的概率增加一层堆肥层。
