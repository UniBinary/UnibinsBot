* *马（Horse）**是一种可驯服[生物](生物.md)，被驯服后可以骑乘。

# 生成
[thumb|250px|自然生成的马群，其中所有马的毛色相同，但花纹不同](File:HorseHerd.jpg.md)

马会在[平原](平原.md)、[向日葵平原](向日葵平原.md)、[热带草原](热带草原.md)、[热带高原](热带高原.md)和[风袭热带草原](风袭热带草原.md)生物群系自然生成。马有多种不同的毛色与花纹，各种毛色与花纹的组合生成概率相同。生成在同一群当中的所有马匹毛色均相同，但花纹不一定相同。每匹马都有20%的概率会生成为幼年个体。

马可以在[村庄](村庄.md)的马厩和动物围栏中生成。

不对着马使用的刷怪蛋生成的马总是成年马<ref></ref>；而使用刷怪蛋生成的幼年马与自然生成概率一致。

# 外观
[缩略图|250px|全部35匹马的种类：<br>
毛色（从左到右）：白色、淡栗色、深枣红色、褐色、黑色、灰色和深褐色<br>
花纹（从上到下）：无花纹、长袜白斑、雪片白斑、白色斑点和黑色斑点](File:HorseBreeds.png.md)

马匹拥有各自的毛色和花纹。与[狼](狼.md)和[猫](猫.md)不同，马被驯服后外观并不会发生变化，虽然可以通过马是否佩戴装备来辨别其是否已被驯服。

马匹有7种不同的毛色，包括白色、淡栗色、深枣红色、褐色、黑色、灰色、深褐色；同时还有5种不同的花纹样式，包括无花纹、长袜白斑、雪片白斑、白色斑点以及黑色斑点。所有毛色与斑点的组合共有35种。

# 行为
[180px|right](File:Horse eating grass.gif.md)
[180px|right](File:Horse Standing.gif.md)

马会漫无目的地四处游荡，偶尔停下来用后腿站立伸展前腿，甩尾，或低头，像吃草一样。与[绵羊](绵羊.md)不同，马吃草时不会破坏草方块上的草皮。如果玩家靠近，马可能会看着玩家。任何一匹马，即使是野生的马，都可以让玩家使用[拴绳](拴绳.md)牵引且毫不反抗。但如果玩家试图骑上一匹未驯服的野马且驯服失败时，则马会直立起来，甩下玩家，踢动前蹄以示反抗。与其他大多数生物类似，马可以坐在[矿车](矿车.md)里，幼年马还可以坐在[船](船.md)上，不过成年后会脱离船。

马会发出嘶鸣声和嘶哑的声音。

与大多数生物不同的是，马每刻都有的概率恢复。

# = 驯服 =
成年的马可以被驯服。

对着未驯服的马按下键可骑上马。玩家需空手对马按键，否则马会拒绝搭载玩家，立刻前腿腾空并嘶叫；玩家可手持着物品按键，但马也会拒绝手持鞍和马铠的玩家。

即使玩家骑上马，马也有很大概率把玩家甩下、前腿腾空并嘶叫。当马不再试图甩下玩家并产生红心粒子时则驯服成功。

驯服成功率取决于值（好感度）。马的初始好感度为0（最高值为100）。当玩家骑上马时，每[游戏刻](游戏刻.md)有2%的概率触发一次驯服检测，会从0-99中随机取一个数字，如果马的好感度高于该数字，则马会被驯服，否则将玩家甩下来，并增加5点好感度。好感度也可以通过给马喂食来增加，详见[下文](#喂食.md)。

即使好感度达到上限，也能正常喂食未驯服的马（[干草捆](干草捆.md)除外）。

与其他可驯服生物一样，驯服的马死亡时会给世界中的所有玩家显示一条[死亡消息](死亡消息.md)，而不会，即使对于该马的主人<ref></ref>。

# = 装备 =

驯服的马有以下两格可用的物品栏：

* 马铠槽：用以装备[马铠](马铠.md)，专用于马。
* 鞍槽：用以装备[鞍](鞍.md)。

以上两种物品皆可被玩家使用[剪刀](剪刀.md)移除。二者同时被装备时，剪刀会优先移除马铠，再移除鞍。

幼年马没有这两种物品栏。

手持物品然后对着马按下键来给马装上物品。骑上马后打开玩家物品栏或按住键对着马按下键可以打开马的物品栏。

# = 骑乘 =

骑乘装备了鞍的马时能用方向键和键等来控制它。玩家可以通过按键来下马。玩家可以在骑马时使用物品、与方块或其他生物交互。玩家无法在骑马时使用[下界传送门](下界传送门.md)。

玩家骑马时会显示马的[生命](生命.md)条，其纹理与玩家的生命条不同。玩家的[饥饿](饥饿.md)条被马的生命条代替，[经验](经验.md)条会被马的跳跃蓄力条代替，但经验等级仍会正常显示；玩家的饥饿条和经验条会正常显示，只有在蓄力时，经验条才会被跳跃蓄力条取代，且上方经验等级的数值不会消失。

如果在马移动或跳跃时玩家的-{}-头部进入固体方块，则玩家仍会受到窒息伤害。马最低能通过1.625格高的空间，但低于2.75格高的空间会使玩家受到窒息伤害，低于1.75格高的空间会使马也受到窒息伤害。马不能通过1格宽的缝隙。

玩家骑马的速度通常快于玩家[疾跑](疾跑.md)的速度。马在后退时很缓慢，往侧边移动时速度与玩家行走的速度相等（详见[下文](#移动速度.md)）。马的速度与其外表无关。马的速度会受来自非[信标](信标.md)的和效果影响。

骑马时可以使用键以[跳跃](跳跃.md)，长按可以蓄力以便跳得更高，蓄力后跳得最高，更长的蓄力时间会使马跳跃的高度缓慢降低。蓄力条会在蓄力结束后的内持续显示。马跳跃的能力强于玩家，骑马可以直接走上1格高的地方而无需跳跃，跳跃能力良好的马可以跳过碰撞箱为1.5格高的方块（如[栅栏](栅栏.md)），部分个体则最高能跳过5格高的障碍，有时马会跳跃得过高以致受到[摔落](摔落.md)伤害。马的跳跃能力与其外表无关。马受来自非信标的影响。

马的移动速度和跳跃能力参见下文[“马匹统计”](#统计.md)。

# = 喂食 =
对马使用有效的食物可以喂马。

给生命值未满的马喂食可以使其恢复生命值。幼年马无法通过喂食来恢复生命值。

给生命值已满的已驯服的成年马喂食[金胡萝卜](金胡萝卜.md)、[金苹果](金苹果.md)或[附魔金苹果](附魔金苹果.md)可以让它们繁殖，详见[下文](#繁殖.md)。

给幼年马喂食可以缩短其成长时间。

无法喂食已进入“求爱模式”或生命值已满且已驯服的马。

下表列出了各种食物对马的影响。

马会跟随/内手持金苹果、附魔金苹果及金胡萝卜的玩家。

# = 繁殖 =

对生命值已满的驯服的马使用金苹果、附魔金苹果或金胡萝卜会让它们进入求爱模式，使其生下一匹幼年马，并掉落，同时双亲有或的冷却时间。幼年马需要20分钟成长为成年个体，给幼年马喂食可以加速其成长。

对幼年马[金蒲公英](金蒲公英.md)可以阻止其成长为成年马，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年马无法被喂食除金蒲公英外的其他物品。

后代的马匹统计取决于亲本，参见[下文](马#繁殖值.md)。

取决于亲本及小概率的变异，后代的毛色会是亲本其中一种或是其他种类。

* 与马繁殖：繁殖两匹马会生成一匹幼年马。通常幼年马的颜色是父母双方的其中一种。概率会突变为其他颜色（这个颜色仍然可能是父母的颜色，这会轻微减少生成其他颜色的概率），花纹同理，但突变概率为。
* 与[驴](驴.md)繁殖：繁殖马和驴会生成一头幼年[骡](骡.md)。

# 统计

所有的马都有3种“马匹统计”，每匹马匹都有所不同：生命值、最大移动速度和跳跃力量。这些数据是在马生成后固定的，喂食对其没有影响。

# = 生成数据值 =
当除了繁殖以外以任何方式生成时——例如使用命令、自然生成、作为骷髅马陷阱的一部分生成或使用刷怪蛋生成——马会根据其类型在特定范围内分配其属性。

# = 生命值 =
马的生命值范围在到之间，但趋于均值。生命值为奇数的马不会在生命条中显示出最后半颗心。

# = 移动速度 =
马的移动速度为0.1125–0.3375个内部单位，趋于平均值0.225，玩家的正常行走速度为0.1。这里列出的速度均是在没有[状态效果](状态效果.md)影响的情况下。

换算为格每秒：
* 最大速度：14.57格/秒
* 最小速度：4.86格/秒
* 平均速度：9.71格/秒

作为对比，列出玩家步行速度：
* 玩家速度（行走）：4.32格/秒
* 玩家速度（疾跑）：5.61格/秒

另见[运输](运输#方式.md)来比较多种运输方式的速度。

# = 跳跃力量 =
马的跳跃力量在0.4-1.0个内部单位之间，趋于平均值0.7。

跳跃力量0.5可以跳过格，1.0可以跳过格。马最高可跳到格的地方。

下面给出的公式可以根据马的跳跃力量计算跳跃高度（RSS为5.510e-19）。

<math>height = -0.1817584952 x^3 + 3.689713992 x^2 + 2.128599134 x - 0.343930367</math>

其中x为跳跃力量。

# = 繁殖值 =
当繁殖两匹马或一匹马和一头驴时，产生的后代的数据的分布规律类似于[正态分布](wzh:正态分布.md)，其均值为双亲的数据平均值，方差随双亲数据差值的增大而增大。具体概率密度分布可以参照[此图表](https://www.desmos.com/calculator/b3wxipbmjn)。

当繁殖两匹马或一匹马和一头驴时，产生的后代的数据通过将双亲的数据与第三组随机数据共同取平均确定（即将双亲的数据与随机值相加并除以3）。
