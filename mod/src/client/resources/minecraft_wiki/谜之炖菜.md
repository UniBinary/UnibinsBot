# 谜之炖菜

*页面ID: 36872* | *来源: Minecraft Wiki*

* *谜之炖菜（Suspicious Stew）**是一种可以给予玩家[状态效果](状态效果.md)的[食物](食物.md)。

# 获取
能被[合成](合成.md)的谜之炖菜可在[创造模式物品栏](创造模式物品栏.md)中获取，用[命令](命令.md)获取的谜之炖菜如果没有设置物品数据，食用后不会获得状态效果。

所有种类的谜之炖菜均可在创造模式物品栏中获取。

# = 棕色哞菇 =
给[棕色哞菇](棕色哞菇.md)喂食小型[花](花.md)后，再对棕色哞菇[碗](碗.md)可以获得谜之炖菜，其状态效果与使用该花合成得到的效果相同。

# = 交易 =

# = 合成 =

大型花（[向日葵](向日葵.md)、[丁香](丁香.md)、[玫瑰丛](玫瑰丛.md)、[牡丹](牡丹.md)和[瓶子草](瓶子草.md)）不能用于合成谜之炖菜。

# = 箱子战利品 =

由于谜之炖菜的最大堆叠数量为1，数量大于1的堆叠会被展开为对应数量的单个物品堆叠。

# = 考古战利品 =
用[刷子](刷子.md)刷扫[沙漠水井](沙漠水井.md)里的[可疑的沙子](可疑的沙子.md)有概率掉落谜之炖菜。

# 用途
# = 食物 =

手持谜之炖菜按住键即可食用，每个谜之炖菜可以回复，并且给予一小段时间的[状态效果](状态效果.md)；这一数据储存在[物品堆叠组件](物品堆叠组件.md)中。

玩家食用谜之炖菜后会返还一个碗。

玩家在[饥饿](饥饿.md)值为满的状态下也可以食用谜之炖菜。
