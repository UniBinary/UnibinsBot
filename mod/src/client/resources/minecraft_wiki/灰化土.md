# 灰化土

*页面ID: 10355* | *来源: Minecraft Wiki*

{{quote|如果你以为这个词是我们编出来的，那也没关系。Podzol不是指的那个在《[五军之战](wzh:哈比人：五軍之戰.md)》中被杀掉的哥布-{}-林首领之一吗？大概是的吧。但Minecraft里有一种稀有方块也叫这个古怪的名字，而且它在现实的大自然里有着超乎想象的地位！|[Duncan Geere](Duncan Geere.md)<ref></ref>||Duncan Geere Mojavatar.png}}

* *灰化土（Podzol）**是自然生成于[原始松木针叶林](原始松木针叶林.md)、[原始云杉针叶林](原始云杉针叶林.md)和[竹林](竹林.md)的方块。

# = 自然生成 =
灰化土会在[原始松木针叶林](原始松木针叶林.md)、[原始云杉针叶林](原始云杉针叶林.md)和[竹林](竹林.md)生物群系中生成。

灰化土还会生成在[试炼密室](试炼密室.md)中[沼骸](沼骸.md)和[洞穴蜘蛛](洞穴蜘蛛.md)的[试炼刷怪笼](试炼刷怪笼.md)旁。

# = 大型云杉 =
[大型云杉](大型云杉.md)长成后会将其下方的4个方块替换为灰化土，同时将周围的[草方块](草方块.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[菌丝体](菌丝体.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)和转变为灰化土。

# 获取
# = 末影人 =
手中搬着灰化土的[末影人](末影人.md)会在死亡时掉落灰化土。

# = 交易 =

# 破坏
挖掘灰化土的合适工具是锹。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，灰化土被破坏后会掉落1个[泥土](泥土.md)。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，灰化土被破坏后会掉落自身。

# 用途

不同于[草方块](草方块.md)和[菌丝体](菌丝体.md)，灰化土不会向[泥土](泥土.md)扩散，将固体方块放置在其上面时它也永远不会退化成泥土。

# = 生物 =
[末影人](末影人.md)可以搬起及放下灰化土。关闭[游戏规则](游戏规则.md)将阻止该行为。

# = 种植 =
灰化土和[菌丝体](菌丝体.md)一样允许[蘑菇](蘑菇.md)在其上方生长并且不受[亮度](亮度.md)限制，从而允许[巨型蘑菇](巨型蘑菇.md)的生长。

[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)、[蕨](蕨.md)、[大型蕨](大型蕨.md)、[花](花.md)、[粉红色花簇](粉红色花簇.md)、[野花簇](野花簇.md)、[灌木丛](灌木丛.md)、[枯萎的灌木](枯萎的灌木.md)、[大型垂滴叶](大型垂滴叶.md)、[下界菌](下界菌.md)、[绯红菌索](绯红菌索.md)、[诡异菌索](诡异菌索.md)、[下界苗](下界苗.md)、[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)都能被放置在灰化土上。[树苗](树苗.md)、[竹子](竹子.md)和[甜浆果丛](甜浆果丛.md)能在灰化土上生长。[甘蔗](甘蔗.md)也会在符合条件的情况下在灰化土上生长。

# = 转变 =
对着灰化土[锹](锹.md)可将其转变为[土径](土径.md)，并使锹消耗掉1点耐久。但灰化土无法被[锄](锄.md)犁成[耕地](耕地.md)，这一点与[菌丝体](菌丝体.md)相同。

[杜鹃树](杜鹃树.md)长成后会将其下方的灰化土转变为[缠根泥土](缠根泥土.md)。

若灰化土被[雪](雪.md)或[雪块](雪块.md)覆盖，其顶部和侧面的深色土壤纹理会变成被雪盖住的样子，将其上方的雪移除后便会立即恢复原样。

对上方为[空气](空气.md)的[苔藓块](苔藓块.md)或[苍白苔藓块](苍白苔藓块.md)[骨粉](骨粉.md)会使周围7×11×7范围内，最上方的灰化土转变为苔藓块或苍白苔藓块。
