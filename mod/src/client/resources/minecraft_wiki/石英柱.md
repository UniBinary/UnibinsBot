# 石英柱

*页面ID: 156705* | *来源: Minecraft Wiki*

* *石英柱（Quartz Pillar）**是[石英块](石英块.md)制作的装饰性方块。

# 生成
石英柱不会生成在世界中。

# 破坏
挖掘石英柱的合适工具是[镐](镐.md)。石英柱需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

石英柱被破坏后会掉落自身。

# 用途
石英柱可以通过改变放置的位置来改变南/北或东/西纹理，类似于[原木](原木.md)。
