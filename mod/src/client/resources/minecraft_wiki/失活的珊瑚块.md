# 失活的珊瑚块

*页面ID: 162926* | *来源: Minecraft Wiki*

* *失活的珊瑚块（Dead Coral Block）**是一种由[珊瑚块](珊瑚块.md)转变的装饰性方块。

# 生成
# = 自然生成 =
失活的珊瑚块会自然生成在[珊瑚礁](珊瑚礁.md)结构中，它们可以在[暖水海洋](暖水海洋.md)中被找到。

# = 珊瑚块 =
|珊瑚块失活的情况示意图}}

如果珊瑚块没有接触[水](水.md)或[含水](含水.md)方块，其会在或后变成对应失活的珊瑚块。

如果珊瑚块的六面都不为[空气](空气.md)方块，则其不会变成对应失活的珊瑚块。<ref></ref>

# 获取
失活的珊瑚块只能通过破坏失活的珊瑚块获得。

# 破坏
挖掘失活的珊瑚块的合适工具是[镐](镐.md)。失活的珊瑚块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，珊瑚块被破坏后将掉落为对应的失活的珊瑚块。

# 用途
失活的珊瑚块目前仅用于装饰。

失活的珊瑚块只能放置在上表面完整的方块上。<ref></ref>
