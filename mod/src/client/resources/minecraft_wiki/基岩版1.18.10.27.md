# 基岩版1.18.10.27

*页面ID: 92065* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.10.27**是[基岩版1.18.10](基岩版1.18.10.md)的第6个测试版，发布于2022年1月11日<ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[设置](设置.md)**
* 在轻触设置中加入了“切换蹲下”选项和“摇杆透明度”滑块选项。

# 更改
# = 物品 =
* *[船](船.md)**
* 物品纹理由[32px](File:Oak Boat (item) JE4 BE3.png.md) [32px](File:Spruce Boat (item) JE2 BE3.png.md) [32px](File:Birch Boat (item) JE2 BE3.png.md) [32px](File:Jungle Boat (item) JE2 BE3.png.md) [32px](File:Acacia Boat (item) JE2 BE3.png.md) [32px](File:Dark Oak Boat (item) JE2 BE3.png.md)更改为[32px](File:Oak Boat (item) BE4.png.md) [32px](File:Spruce Boat (item) BE4.png.md) [32px](File:Birch Boat (item) JE3 BE4.png.md) [32px](File:Jungle Boat (item) JE3 BE4.png.md) [32px](File:Acacia Boat (item) JE3 BE4.png.md) [32px](File:Dark Oak Boat (item) JE3 BE4.png.md)，使船桨的纹理与船身颜色相匹配（云杉除外），同时加深了船的内部边沿的颜色。
* * 深色橡木船的新物品纹理暂时不会在游戏中显示。<ref></ref>

# = 生物 =
* *[猫](猫.md)**
* 未驯服的猫现在可以被拴绳拴住。

* *[守卫者](守卫者.md)和[远古守卫者](远古守卫者.md)**
* 瞄准目标或玩家时不再下沉。

# = 技术性 =
* *性能与稳定性**
* 降低了常加载区域的内存使用量以及加载时间。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“应用测试框架”和“Molang 功能”子选项后才可使用。

# = 技术性 =
* *GameTest框架**
* 加入了函数<code>setVelocity(velocity: Vector): bool</code>，用于设置实体的速度。
* 加入了属性<code>viewVector: Vector</code>，为向量，表示实体正在面向的方向。
* 加入了属性<code>headLocation: Location</code>，表示实体head骨骼的位置。
* 加入了属性<code>bodyRotation: number</code>，为浮点数，表示实体body骨骼的旋转（角度制）。

* *[Molang](Molang.md)**
* 加入了<code>query.all</code>和<code>query.any</code>以检查一个值是否与后面的所有值或任何值匹配。
* 加入了<code>query.in_range</code>以检查一个值是否在最小值和最大值之间（含区间端点）的范围内。

# 修复
* *实验性**
* 青蛙不再吞食山羊。（）

* *方块**
* 重载世界时，放置在区块边界上的可可果不再会被破坏。（）
* 结构方块的结构现在会正确变换（旋转或镜像）多面方块（例如发光地衣）。

* *游戏内容**
* 修复了破坏正在闪烁的侦测器时，获得的物品在物品栏中保持输出状态的漏洞。（）
* 修复了画可以与荧光物品展示框、告示牌、旗帜和火把相重叠的漏洞。
* 掠夺者前哨站现在会生成正常数量的掠夺者和铁傀儡。（）

* *图形**
* 乘船移动较远距离后下船时，船不再会消失。（）
* 船的物品纹理中桨的纹理现在与船身的颜色一致。（）

* *用户界面**
* 携带UI的“建筑”选项卡的颜色现在是正确的。
* 修复了使用携带UI时缺失物品栏槽位的漏洞。（）
* 修复了一个创造模式物品栏中空槽位的漏洞，此漏洞会导致在世界中的交互问题。（）

* *世界生成**
* 箱子和刷怪笼现在会正确地在结构中生成。（、、）

* *动画**
* 修复了当事件指定的时间等于总的<code>animation_length</code>时，动画、音效以及粒子事件不会被触发的漏洞。
* 修复了在未明确指定<code>animation_length</code>时，动画长度计算过程中未考虑事件时间的漏洞。

* *常规**
* 修复了导致声明为数值型值而不是字符串的<code>format_versions</code>被正确解析的漏洞。
* 使用游戏基版本为洞穴与山崖更新之前版本的世界模板创建超平坦世界时，世界中不再会有多层的64个方块悬空。</onlyinclude>
