# 携带版0.15.8

*页面ID: 24802* | *来源: Minecraft Wiki*

* *v0.15.8 alpha**是携带版的一次次要更新，发布于2016年9月15日，加入了魔幻[纹理包](纹理包.md)<ref></ref>。

# 新内容
# = 常规 =
* *[资源包](资源包.md)**
* 加入了魔幻纹理包。

# 修复
* *修复了2个漏洞**
* 附魔师皮肤背后的书本纹理出现错误。
* 塑料纹理包或城市纹理包里的时钟、指南针和睡莲的纹理出现错误。
