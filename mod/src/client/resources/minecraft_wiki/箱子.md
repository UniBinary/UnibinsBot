# 箱子

*页面ID: 6481* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *箱子（Chest）**是用来储存[物品](物品.md)的[方块](方块.md)。

# 生成
# = 自然生成 =

许多箱子在生成时都会储存着物品，搜索自然生成的箱子是玩家获取资源的重要方式之一。

箱子可在[村庄](村庄.md)、[要塞](要塞.md)、[林地府邸](林地府邸.md)、[远古城市](远古城市.md)、[试炼密室](试炼密室.md)、[沙漠神殿](沙漠神殿.md)、[掠夺者前哨站](掠夺者前哨站.md)、[废弃矿井](废弃矿井.md)、[丛林神庙](丛林神庙.md)、[沉船](沉船.md)、[地牢](地牢.md)、[废弃传送门](废弃传送门.md)、[雪屋](雪屋.md)、[海底废墟](海底废墟.md)、[埋藏的宝藏](埋藏的宝藏.md)、[下界要塞](下界要塞.md)、[堡垒遗迹](堡垒遗迹.md)和[末地城](末地城.md)生成。

这些箱子里生成的战利品取决于战利品表的种子，而战利品表的种子和世界生成的[种子](种子（世界生成）.md)有关，因此相同种子的地图的箱子战利品是一样的。

在生成世界选项中的“奖励箱”选项打开时，箱子还会生成于[奖励箱](奖励箱.md)。

# 破坏
挖掘箱子的合适工具是斧。

箱子被破坏后会掉落自身和内容物。

如果一个大型箱子（由2个相邻的箱子组成）的其中一个箱子破坏，那么将会掉落对应的27个储存格的物品。

# 用途
箱子可用作[容器](容器.md)和[合成](合成.md)材料。

若要放置箱子，应对着方块表面。对着一个小型箱子放置同向箱子时，游戏会优先尝试与之合并成大型箱子。

把一个箱子放在另一个箱子的旁边，若两者朝向相同，那么它们会合并为一个大型箱子。若要避免这种情况，玩家需要（若潜行放置时对准了箱子，则两个箱子仍然会合并）}}或。普通箱子不会与陷阱箱合并。

[水](水.md)和[熔岩](熔岩.md)会绕过箱子流动，不会对其造成任何影响。熔岩会在箱子周围的空气方块生成火，但箱子不会被烧毁（并且也不会以其他方式燃烧）。箱子能够被[活塞](活塞.md)推动。

# = 容器 =

一个箱子拥有27个物品槽位，大型箱子拥有54个槽位。大型箱子的物品槽位分布如下：
* 前27个（上三行）：
* * 对应其面对锁扣观察时的左侧部分。
* * 对应其先被放置的部分。
* 后27个（下三行）：
* * 对应其面对锁扣观察时的右侧部分。
* * 对应其后被放置的部分。

对箱子按下可打开箱子的界面。

箱子在上方置有或时，或[猫](猫.md)坐在其上方时，不能开启。但由于箱子不是或，所以可以在箱子的上面放置箱子而不影响开启（无论箱子是否已打开）。

箱子界面的标题默认为“箱子”，可以在放置前使用[铁砧](铁砧.md)重命名来进行更改，也可以通过使用命令修改箱子的<code>CustomName</code>标签进行更改（例如要把位于(0,64,0)的箱子标记为“宝箱”，则使用命令{{cmd|data merge block 0 64 0 {CustomName:"宝箱"} }}）。若大型箱子的一半被重命名，那么整个大型箱子界面上的名字都会改变，但若重命名的那一半被摧毁，剩下的一半会恢复到默认状态。若两个部分的名字不同，箱子根据朝向优先选择北侧或西侧的那一半的名字（即X轴或Z轴上坐标最小的那一半），若均无重命名则会显示“大型箱子”。大型箱子界面上的名字取决于被打开的大型箱子的一半的名称。若打开的大型箱子的一半无名称，则会显示“大箱子”。

箱子可以被<code>lock</code>标签上锁。若箱子的该标签不是空白的，那么这个箱子必须使用符合该标签表示的物品谓词的物品打开。

箱子的容量会因不同条件而有很大变化，包括它是否为大型箱子、里面的物品是否能堆叠，还有里面是否放有[潜影盒](潜影盒.md)。只在箱子里存放不可堆叠的物品时存贮量最少；只在箱子里存放可以堆叠64件的物品时存贮量最大。潜影盒是不可堆叠的，但它们每个都可以容纳27组最多堆叠至64件的物品，因此用它们来填充箱子的话，可使箱子的最大容量变为原来的27倍。

[红石比较器](红石比较器.md)可检测箱子存储物品的数量。当比较器检测大型箱子时，比较器会检测整个大型箱子（54个槽位），而不只是比较器后方的那半个。

# = 驴、骡、羊驼的物品栏 =
对[驴](驴.md)、[骡](骡.md)或[羊驼](羊驼.md)箱子可为驴、骡或羊驼装备箱子。

驴、骡背上的箱子有15格存储空间，羊驼背上的箱子有3-15格存储空间，由羊驼的“强度（Strength）”决定（详见）。不能通过除杀死带有箱子的驴、骡或羊驼以外的方法来移除箱子。同时按下以及键可打开箱子，或者骑着携带有箱子的驴或骡并按下键。

# = 合成材料 =

# = 燃料 =
箱子可以用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个箱子可烧炼1.5个物品。

# = 猪灵 =
在非和平[难度](难度.md)下，成年[猪灵](猪灵.md)会与附近打开或破坏箱子的玩家敌对。

# = 圣诞节 =

每年12月24日至26日，箱子、[陷阱箱](陷阱箱.md)会共用圣诞节礼物包裹纹理，因而无法从外观分辨。由于游戏会读取电脑数据，玩家可以通过更改游戏文件和时间来看到圣诞节纹理。安装在动物（[骡](骡.md)、[驴](驴.md)等）身上的箱子和[运输船](运输船.md)上的箱子不会改变纹理。
