# 基岩版1.19.40.23

*页面ID: 98711* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.40.23**（Android）、**Preview 1.19.40.23**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.40](基岩版1.19.40.md)的第4个测试版，发布于2022年9月29日<ref></ref>，同步了一些特性，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 加入了被重命名后的物品杀死时出现的死亡消息：
* * “<玩家> 被 <玩家/生物> 用 <物品> 杀死了”

# 更改
# = 生物 =
* *[凋灵骷髅](凋灵骷髅.md)**
* 现在能够在[凋灵玫瑰](凋灵玫瑰.md)中生成。

* *[村民](村民.md)**
* 图书管理员村民现在能够出售[消失诅咒](消失诅咒.md)和[绑定诅咒](绑定诅咒.md)附魔书。

# = 命令格式 =

* 暂时移除了旋转参数。

# 修复
* *原版趋同**
* 现在被重命名的武器杀死时会出现带着该武器名称的死亡消息。（）
* 凋灵骷髅现在能够在凋灵玫瑰中生成。（）
* 降低了游泳时消耗的饥饿值以匹配Java版。（）
* 图书管理员村民现在能够出售消失诅咒和绑定诅咒附魔书。（）

* *旁观模式（实验性）**
* 潜影弹不再会跟随旁观模式玩家。（）
* 现在旁观模式玩家在普通玩家的视角中是隐形的。
* 服务器上不存在其他非旁观模式玩家时，旁观模式玩家不再会影响生物的消失。
* 服务器上只有旁观模式玩家在线时，生物消失会被暂停。

* *用户界面**
* 修复了死亡消息有时会太长以至于无法在屏幕上显示的漏洞。（)
* 触控设备的物品栏按钮现在会在关闭物品栏后重置为默认外观。
* 修复了合成界面的搜索字符串不会正确保存的问题。
* 修复了Xbox上的物品栏界面会缺失耐久度条的问题。（）
* 修复了创建新的世界上的登录按钮无法在部分平台上生效的漏洞。

* *移动端控制**
* 修复了在移动设备上将物品从快捷栏移动到创造模式物品栏中的其他物品上时，该物品不会被删除的问题。
* 修复了触摸控制下的堆叠拆分进度条不对齐的问题。
* 调整了触摸控制下工具栏和状态效果图标的布局。
* 暂时禁用了新的触控拆分堆叠的体验优化。

* *生物**
* 现在坐在船上的生物无法再进入其他维度。（）

* *方块**
* 现在附魔台上的书会面向离它最近的玩家。（）

* *NPC（教育版）**
* NPC现在能够不拥有名称，将名称隐藏在头顶。

* *市场**
* 修复了市场同捆包的价格在购买后不会显示为免费的问题。

* *性能与稳定性**
* 修复了一个可能源自于爆炸的崩溃。
* 修复了退出分屏时可能发生的崩溃。</onlyinclude>
