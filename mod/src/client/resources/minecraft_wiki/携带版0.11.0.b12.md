# 携带版0.11.0.b12

*页面ID: 27883* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 12**是[v0.11.0 alpha](携带版0.11.0.md)的第12个测试版，发布于2015年5月20日，修复了一些漏洞。

# 更改
# = 物品 =
* *常规**
* 从[创造模式物品栏](创造模式物品栏.md)中移除了上个测试版加入的所有[物品](物品.md)，甚至build 1加入的铁锹。

# = 游戏内容 =
* *[皮肤](皮肤.md)**
* 加入了更改选择[皮肤](皮肤.md)时高亮显示的效果。

# = 世界生成 =
* *[废弃矿井](废弃矿井.md)**
* 现在包含[洞穴蜘蛛](洞穴蜘蛛.md)[刷怪笼](刷怪笼.md)，洞穴蜘蛛因此能够自然生成。

# 修复

* *其他漏洞**
* 客户端使用最后一组物品时游戏崩溃。
* 破坏花或蘑菇时游戏崩溃。
* 暂停游戏时断开连接使得游戏崩溃。
* 水下不能使用铁桶。
* 玩家在水下时不能正常上船。
* 创造模式下的玩家仍会着火。
* 最小型的史莱姆不再在和平模式中生成。
* 皮肤包界面的皮肤不会居中显示。
* 修复了一些本地化漏洞。</onlyinclude>
