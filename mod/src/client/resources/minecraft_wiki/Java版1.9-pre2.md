# Java版1.9-pre2

*页面ID: 20388* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.9-pre2**是[Java版1.9](Java版1.9.md)的第2个预发布版，发布于2016年2月18日<ref></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *常规**
* [成群生成](成群生成.md)的生物不会过于密集，也不会过于分散。
* * 之前，生物群体会从中心开始生成三次并且累计四次在±5的范围内调整X、Z坐标，每次尝试生成一个生物，总共12次尝试生成生物（如果生成数量已满，就会提早结束）。现在，所谓的“四次”是1-4的随机次数，这意味着总的生成尝试会更少，生成地点远离生物群体坐标中心的概率也会更小。

# 修复
命令不能与选择器一起工作，不会解析到具体的一个实体。
