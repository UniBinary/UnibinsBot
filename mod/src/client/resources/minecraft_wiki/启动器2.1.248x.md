# 启动器2.1.248x

*页面ID: 65931* | *来源: Minecraft Wiki*

* *2.1.2481**（[Windows](wzh:Microsoft Windows.md))、**2.1.2480**（[macOS](wzh:macOS.md)）或**2.1.2482**（[Linux](wzh:Linux.md)）是[启动器](启动器.md)的一次更新，发布于2019年2月21日，修复了一些漏洞。

# 新内容
* 添加了在macOS上当启动失败时检查文件的功能。
* 更新翻译。

# 修复
*  - 切换Wi-Fi网络时，启动器会忘记登录令牌。
*  - 启动器需要连接到<code>youtube.com</code>才能启动。
*  - 如果将<samp>.minecraft</samp>文件夹移动到其他位置，再在原位置用符号链接链接到新位置时，<code>.exe</code>格式的启动器无法启动。
*  - <code>.deb</code>格式安装包有依赖关系冲突。
