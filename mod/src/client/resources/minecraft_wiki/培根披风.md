# 培根披风

*页面ID: 186123* | *来源: Minecraft Wiki*

* *培根披风（Bacon Cape）**是[Notch](Notch.md)赠送给[Miclee](:en:User:Miclee.md)的披风。

# 描述
[Notch](Notch.md)将该披风赠予给了[Miclee](:en:User:Miclee.md)<ref></ref>，因为他提出了关于[猪人](Java版已移除特性#猪人.md)的主意<ref></ref>。但后来由于许多人要求Notch给予他们个性化披风，Notch收回了培根披风。该披风由Miclee亲自制作。
