# Java版19w46b

*页面ID: 49379* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w46b**是[Java版1.15](Java版1.15.md)的第15个，也是最后一个快照，发布于2019年11月14日<ref name="19w46b"></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *[复述功能](复述功能.md)**
* 若将复述功能模式设置为“系统”或“全部”，则[命令](命令.md)补充建议现在也会被复述。

* *文本**
* 调整了文本颜色的对比度。

# 修复

* *其他漏洞**
* 修复了当蜜蜂遗忘单朵花的坐标时游戏崩溃的漏洞。
* 修复了为超平坦世界设置无效的生物群系会导致游戏崩溃的漏洞。
* 修复了在聊天栏中使用键填充名字导致游戏崩溃的漏洞。</onlyinclude>
