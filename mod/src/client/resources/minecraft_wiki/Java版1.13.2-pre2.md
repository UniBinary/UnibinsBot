# Java版1.13.2-pre2

*页面ID: 36778* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.13.2-pre2**是[Java版1.13.2](Java版1.13.2.md)的第2个，也是最后一个预发布版，发布于2018年10月18日<ref></ref>，修复了一些漏洞，并做了一些性能改进。

# 更改
# = 常规 =
* *性能**
* 提升世界加载性能。
* 提升游戏启动性能。
* 提升海龟寻路性能。
* 提升生物生成性能。
* 提升其他各种性能。

# 修复
