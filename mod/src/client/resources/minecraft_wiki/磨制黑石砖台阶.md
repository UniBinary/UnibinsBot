# 生成
# = 自然生成 =
磨制黑石砖台阶会自然生成在下界的[废弃传送门](废弃传送门.md)中。

# 破坏
挖掘磨制黑石砖台阶的合适工具是镐。磨制黑石砖台阶需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

磨制黑石砖台阶被破坏后会掉落自身，双台阶被破坏后会掉落两个组成自身的台阶。
