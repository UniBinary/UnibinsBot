# 钻石块

*页面ID: 7162* | *来源: Minecraft Wiki*

* *钻石块（Block of Diamond）**是一种珍贵的装饰性矿产[方块](方块.md)。

# 生成
# = 自然生成 =
钻石块会在[林地府邸](林地府邸.md)的“[黑曜石房间](林地府邸/结构/战利品房间#黑曜石房间.md)”和“[熔岩房](林地府邸/结构/战利品房间#熔岩房.md)”的中心生成。

# 破坏
挖掘钻石块的合适工具是镐。钻石块需要铁镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

钻石块被破坏后会掉落自身。

# 用途
钻石块可以用来存储[钻石](钻石.md)，以此来节约空间。

# = 信标 =

钻石块可作为激活[信标](信标.md)的底座方块。

# 你知道吗
* 钻石块与[金块](金块.md)的纹理只有颜色不同，[纹理更新](纹理更新.md)前也是如此。
* 钻石块必须通过[不祥宝库](不祥宝库.md)战利品才能实现可再生。这是因为可用于制造钻石块的[钻石](钻石.md)同样依赖宝库战利品实现可再生，而宝库可以被每个玩家打开无限次数<ref></ref>，且[不祥试炼钥匙](不祥试炼钥匙.md)是[可再生资源](可再生资源.md)。
