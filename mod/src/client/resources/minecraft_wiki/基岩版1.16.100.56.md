# 基岩版1.16.100.56

*页面ID: 70064* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.100.56**是[基岩版1.16.100](基岩版1.16.100.md)的第7个测试版，发布于2020年9月17日<ref></ref>，做出了一些技术性更改，并修复了一些漏洞。

# 更改
# = 常规 =
* *[附加包](附加包.md)和脚本引擎**
* 加入了从而允许玩家设置方块可以放置的条件。
* 为方块描述符加入了序列化。
* 为方块描述符加入了静态的函数来比较两个方块描述符：、和。
* 方块描述符的项目变量被更改为以在设置方块状态时延迟方块解析时设置方块状态，并获得设置完毕的方块。
* 移除了所有现有方块*JSON解析
* 加入了验证解析和方块序列化描述符的单元测试。<!-- unit tests -->
* 加入了验证方块描述符之间的比较的单元测试。
* 加入了验证从方块描述符获得已经设定方块状态的方块的单元测试。

* *[实验性玩法](实验性玩法.md)**

== 修复 ==
* *性能与稳定性**
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了Xbox One上启动游戏时的崩溃。

* *成就界面**
* 游玩时间现在会正确地显示在成就界面上。（）
* 启用复述功能时，现在可以按手柄左键把光标移动到摘要上。
* 更新了成就列表和成就奖励的输入图标。
* 现在打开成就详情界面时显示“界面”二字。
* 修改了计算玩家成就点数的方式。
* 当数据被提取后即使超时也会显示成就。
* 修复了使用非主流鼠标按钮时不播放点击声音的漏洞。
* 修复了即使界面不能滚动也会显示滚动条的漏洞。
* 为手柄光标移动添加了加速功能。
* 修复了从“全部”选项卡切换时光标消失的漏洞。
* 支持使用鼠标“后退按钮”来从成就界面返回。
* 支持使用“退出按钮”来从成就界面返回。
* 修复了当选项卡被选中时输入图标仍然显示“open”的问题。

* *常规**
* 修复了文本转语音无法读取界面上的信息的问题。
* 修复了地图不在命令的物品列表中的问题。
* 修复了关闭登录提示窗口后登录按钮无响应的问题。

* *游戏内容**
* 现在石质工具的合成配方默认显示为圆石。（）
* 更改了灾厄号角音效的线性衰减，比之前略微减弱。（）
* 现在放置和破坏物品展示框的音效能够正确播放。（）</onlyinclude>
