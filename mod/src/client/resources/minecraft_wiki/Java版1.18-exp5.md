* *1.18-exp5（1.18 experimental snapshot 5）**是[Java版1.18](Java版1.18.md)的第5个实验性快照，发布于2021年8月25日<ref></ref><ref></ref>，调整了一些[地形特征](地形特征.md)、[生物群系](生物群系.md)的生成。此版本单独发布，故不出现在[启动器](启动器.md)版本列表中。

# 更改
# = 生物 =
* *常规**
* 撤回了[1.18-exp3](Java版1.18-exp3.md)关于[生物](生物.md)生成的更改，现在生物的生成速度又会像以前那样在低处增大、在高处减小。
* * 生物生成与海拔[高度](高度.md)的关系今后仍可能进一步调整。

# = 世界生成 =
* *[恶地](恶地.md)**
* 略微降低了平均大小。

* *[溶洞](溶洞.md)**
* 现在洞口处的[草方块](草方块.md)由[石头](石头.md)取代。

* *[丛林边缘](丛林边缘.md)**
* 重新加入，但其不再起过渡功能。

* *[繁茂洞穴](繁茂洞穴.md)**
* 现在[涌泉](涌泉.md)会在此生成。

* *[山地](山地.md)<!--Mountains-->**
* 山顶的地形现在会更陡峭、崎岖。
* 略微增加了[山脉](山脉.md)和[尖峭山峰](尖峭山峰.md)、[冰封山峰](冰封山峰.md)、[裸岩山峰](裸岩山峰.md)生物群系的平均大小。
* 提高了整体的海拔高度。

* *[蘑菇岛](蘑菇岛.md)**
* 调整了生成方式，使其与岛屿的形状更加一致。

* *[河流](河流.md)**
* 调整了河流的深度和河岸的坡度，降低了河流过深或过浅（甚至在平坦区域干涸）的可能性。
* 河流会与沼泽更好地融合，而不会直接穿过沼泽（两者间的界限不再过于明显）。

* *[沼泽](沼泽.md)**
* 现在更倾向于在内陆生成，以防止其与[海洋](海洋.md)交界而使[水](水.md)的色差过大。
* 沼泽[橡树](橡树.md)现在能生成在更深的水中。

* *[洞穴](洞穴.md)**
* [雕刻器洞穴](雕刻器洞穴.md)现在可以覆盖[红沙](红沙.md)和[方解石](方解石.md)生成，以避免这两种方块在洞穴中悬空。

* *常规**
* 小型[湖泊](湖泊.md)不再在干燥且炎热的[生物群系](生物群系.md)中生成（[沙漠](沙漠.md)、恶地和[热带草原](热带草原.md)）；减少了其他生物群系中湖泊生成的数量。
* [涌泉](涌泉.md)可以在更多种类的方块中生成（例如[泥土](泥土.md)和[雪块](雪块.md)），增加了小山泉和瀑布的生成概率。
* 减少了碎地形和[破碎的热带草原](破碎的热带草原.md)生物群系的数量，且部分区域由更加平坦的沙滩代替。

# 修复
* 主世界Y=0以上的化石中不再错误生成深层钻石矿石。
* 修复了1.18-exp4中使山地地形更加低缓的意外更改。
* 修复了1.18-exp4中平坦地形的突起（技术名称为“3D噪声”）过少的意外更改。</onlyinclude>
