# 状态效果

*页面ID: 7674* | *来源: Minecraft Wiki*

* *状态效果（Status Effect/Mob Effect）**，或简称**效果（Effect）**，是一种作用于[生物](生物.md)并对其产生正面、负面或中性影响的游戏机制。

# 监测
状态效果以及它们的等级和持续时间会显示在[物品栏](物品栏.md)右侧，如果右侧空间不足（例如分辨率较低时）会显示为小图标，没有被隐藏粒子效果的状态效果会在屏幕右上角标记出来。

状态效果展示在一个单独的窗口里，它可以通过按下键或点击状态效果图标来打开。屏幕右上方会显示所有拥有的状态效果，无论粒子效果是否被隐藏。

当状态效果的持续时间小于10秒时，状态效果图标将以每秒2次的频率闪动。亮度幅值随剩余时间减少逐渐增强。亮度幅值不变。

# 机制
受状态效果影响的生物会在一段时间内受到不同方面的影响。在这段时间内，旋转的粒子会从受影响的生物的位置发出。

状态效果有多种获取途径，包括饮用[药水](药水.md)、食用某些[食物](食物.md)、进入[信标](信标.md)和[潮涌核心](潮涌核心.md)的作用范围、靠近[生物](生物.md)、被特定[生物](生物.md)攻击、接触[区域效果云](区域效果云.md)。命令可以用于为生物添加或移除状态效果。

任何数量的不同状态效果能够同时在一个生物上生效，即使是像力量和虚弱这种拥有反效果的效果。在生物身上应用一个已生效的效果时，新等级将覆盖旧等级，同等级时持续时间长的覆盖时间短的。同种效果不能被应用多次，即使等级不同。

能够直接造成伤害的状态效果会造成[魔法伤害](伤害#魔法伤害.md)。

# = 效果等级 =

状态效果具有等级。对于大多数状态效果，等级越高，效果越强。

在游戏内部、[命令](命令.md)与[药水](药水.md)的修饰NBT标签，游戏保存的是“倍率”（amplifier）值而不是等级。倍率比等级小1，例如力量II的倍率为1。

状态效果的倍率不能为负数。负数状态效果倍率会被视为0倍率（1等级）；倍率使用无符号整数。

当强状态效果覆盖弱状态效果时，弱效果会保留但处于隐藏状态。如果弱效果比强效果有着更长的持续时间，它将在强效果终止后重新出现。这使得通过应用一刻的高等级效果来制作自定义药水解毒剂是不可行的。当强状态效果覆盖弱状态效果时，弱效果会被删除，无法重新出现。<ref></ref>

# = 效果持续时间 =
状态效果有持续时间。在持续时间结束后，状态效果就会从生物上消失。[伤害吸收](伤害吸收.md)会在伤害吸收值被消耗完后立刻消失。

通过可以获得无限持续时间的状态效果。

# = 免疫状态效果 =
少数生物会免疫特定的状态效果，即不能被任何方式添加该状态效果。使用为生物添加其免疫的状态效果会导致命令执行失败。使用为生物添加其免疫的状态效果后清除该效果会导致命令执行失败。

[蜘蛛](蜘蛛.md)、[洞穴蜘蛛](洞穴蜘蛛.md)、[鹦鹉螺](鹦鹉螺.md)和[亡灵生物](亡灵生物.md)免疫[中毒](中毒.md)，亡灵生物免疫[生命恢复](生命恢复.md)，[凋灵骷髅](凋灵骷髅.md)免疫[凋零](凋零.md)，[史莱姆](史莱姆.md)免疫[渗浆](渗浆.md)，[蠹虫](蠹虫.md)免疫[寄生](寄生.md)，[焦骸](焦骸.md)免疫[虚弱](虚弱.md)，[凋灵](凋灵.md)免疫或，[末影龙](末影龙.md)、免疫全部状态效果。

# = 即时生效效果 =
[瞬间治疗](瞬间治疗.md)、[瞬间伤害](瞬间伤害.md)、[饱和](饱和.md)是即时生效效果。

使用为生物添加即时生效效果时，持续时间参数为游戏刻而非秒数。

即时生效效果的[喷溅药水](喷溅药水.md)或[区域效果云](区域效果云.md)不施加状态效果，而是直接应用它们的效果（伤害、治疗、增加饥饿值和饱和度），应用伤害时还会使用自身的来源作为伤害来源。这也导致了末影龙虽然免疫瞬间伤害，却会受到喷溅型伤害药水的魔法伤害。喷溅药水每次施加效果时，会随距离衰减效果强度；区域效果云每次施加效果时，效果强度减半。

# = 状态效果分类 =
状态效果可被分为三类：正面、中性、负面。

在[提示框](提示框.md)中，正面和中性的效果是蓝色的，负面的效果是红色的。

在[平视显示器](平视显示器.md)中，正面的效果显示在第一行，中性和负面的效果显示在第二行。

# = 解除效果 =
以下方式可以解除所有状态效果：
* 饮用[奶](奶.md)。
* 玩家[死亡](死亡.md)后[重生](重生.md)。
* 激活[不死图腾](不死图腾.md)的效果。
* 使用或。

以下方式可以解除特定状态效果；
* [不祥之兆](不祥之兆.md)触发[不祥事件](不祥事件.md)时会解除不祥之兆。
* 杀死[美西螈](美西螈.md)的攻击目标可以解除[挖掘疲劳](挖掘疲劳.md)。
* 饮用[蜂蜜瓶](蜂蜜瓶.md)可以解除[中毒](中毒.md)。
* 饮用[补药](补药.md)可以解除[反胃](反胃.md)。
* 饮用[眼药水](眼药水.md)可以解除[失明](失明.md)。
* 饮用[灵药](灵药.md)可以解除[虚弱](虚弱.md)。
