# 墨囊

*页面ID: 83* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *墨囊（Ink Sac）**是[鱿鱼](鱿鱼.md)的掉落物，可用于合成[黑色染料](黑色染料.md)。

# 获取
# = 鱿鱼 =

# = 钓鱼 =
[钓鱼](钓鱼.md)时墨囊可作为[垃圾](钓鱼#垃圾与宝藏.md)被钓上来，数量固定为10个。[海之眷顾](海之眷顾.md)魔咒会降低得到墨囊的概率。

# = 箱子战利品 =

# = 化合 =

墨囊可以用基本[元素](元素.md)通过[化合物创建器](化合物创建器.md)化合而成。

# 用途
# = 合成材料 =
墨囊在合成配方（给[旗帜](旗帜.md)添加图案除外）中可被用作黑色染料。

# = 交易 =

# = 告示牌 =
对[告示牌](告示牌.md)使用墨囊可以去除[荧光墨囊](荧光墨囊.md)带来的文本增亮效果。
