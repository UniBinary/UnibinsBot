# 原主机版未使用特性

*页面ID: 101529* | *来源: Minecraft Wiki*

* *注意**：此页面中介绍的大多数特性需要通过物品栏编辑器和NBT修改器才能在游戏中展现。

# 技术性内容
# = 无限耐久的工具 =
通过修改NBT数据，可以使[工具](工具.md)，[武器](武器.md)和[盔甲](盔甲.md)获得无限耐久度。

# = 破坏和放置 =
通过NBT修改器，可以设定[物品](物品.md)和[方块](方块.md)只能被放置在特定的方块上或者只能破坏特定的方块。然而，这个设定本身在游戏中似乎并不起作用。

# 方块和物品
# = 命令方块 =

在[Java版](Java版.md)中，命令方块需要通过[命令](命令.md)或[创造模式物品栏](创造模式物品栏.md)才能获得。但是在[原主机版](原主机版.md)中，其只能使用物品栏编辑器和其他外部工具才能在游戏中获得。三种模式的命令方块都可以被修改进游戏中，但其没有任何功能，与之相关的只有与执行命令有关的未使用的NBT标签和“用于执行命令”的一条说明。此外，三种模式的命令方块都拥有未使用的条件制约模式下的纹理。

# = 屏障 =

屏障只能通过物品栏编辑器和其他外部工具获得。在[原主机版](原主机版.md)里，屏障的功能并不完全，它会阻挡光线，这使得其会投射出阴影。和屏障相关的仅有“一个看不见且十分坚硬的方块”的一条说明。有意思的是，屏障在[水域更新](水域更新.md)的教程模式的地图中被使用过，同时在对战模式的DLC地图中也被使用过。

# = <samp>debug_fourj_item</samp> =

<samp>debug_fourj_item</samp>在物品栏中使用和[屏障](屏障.md)一样的纹理，其没有显示名称，没有说明，不能放置，用途未知，它的ID<ref name="youtube"></ref>表明其用于调试和测试。<samp>debug_fourj_item</samp>只能通过物品栏编辑器和其他外部工具获得。

# = 命令方块矿车 =

[命令方块矿车](命令方块矿车.md)仅有物品形式，如果试图放置，则只会放置一个普通的[矿车](矿车.md)。命令方块矿车实体无法用NBT修改器修改出来。除此之外，还有一条关于它的未使用的说明：“可以在轨道上运行的同时执行命令”。

# = 光灵箭 =

在[原主机版](原主机版.md)中，光灵箭可以正常使用。但是当击中生物时，光灵箭并不会给该生物给予[发光](发光.md)效果，这使得其变为了一个[原主机版](原主机版.md)中未使用的特性。关于它的说明是：“可以使被击中生物的轮廓发光，并且能透过方块看到其轮廓”。

# = 石化橡木台阶 =

在对应不同种类的木头的木台阶被添加之前，橡木台阶和其他石质台阶的特性是一致的，这意味着它不会燃烧，而且需要用镐来收集。在[原主机版](原主机版.md)中，石化橡木台阶并没有被删除，而是成为了一个未使用的特性。

# = 盾牌 =

盾牌的代码可以在游戏数据中找到。其只能使用物品栏编辑器才能获得。在游戏中，盾牌没有模型和材质，也不会展示名称和描述。尽管如此，其仍然具有功能，可以吸收绝大部分伤害。

盾牌在[PlayStation 4版1.90](PlayStation 4版1.90.md)中被正式加入，然而对于其他版本而言，盾牌是一个未使用特性。

# 生物
# = 杀手兔 =

杀手兔是毛色纯白，有横向的血红色眼睛且对玩家具有敌意的生物，在[原主机版](原主机版.md)中，杀手兔只能将兔子的**RabbitType**tag改为99才能生成，生成后其上方会出现"entity.KillerBunny.name"的标签。其攻击伤害受难度影响，在简单、普通、困难难度中分别每次造成、、点伤害。

# 区域
# = 洞穴测试区 =
[thumb|测试区域](File:Battlemode Cavern Large testing area.png.md)
在对战模式的巨大洞穴地图中，有一个不使用作弊手段就无法进入的区域。其似乎是用于测试对战模式中各种方面的区域。其包括一个[箱子](箱子.md)，一个[运输矿车](运输矿车.md)，一个[熔炉](熔炉.md)，一个[工作台](工作台.md)，一个[附魔台](附魔台.md)，一个[物品展示框](物品展示框.md)，一个[发射器](发射器.md)和一个[炼药锅](炼药锅.md)组成。同时还有一个写着“11111”的[告示牌](告示牌.md)，[箱子](箱子.md)是空的，但是[熔炉](熔炉.md)里有一组[金锭](金锭.md)。

# = 洞穴地图中不可见的结构 =
[thumb|在竞技场旁的一个村庄](File:Battlemode Cavern Large village.png.md)
[thumb|在竞技场上方由苔石砖组成的结构](File:Battlemode Cavern Large structure.png.md)
同样在对战模式的巨大洞穴地图中，在洞穴穴口的旁边有一个看不见的[村庄](村庄.md)，和一个由[苔石砖](苔石砖.md)组成的结构，其可能是主竞技场中未使用的一部分结构。

# = 海湾地图中不可见的洞穴 =
[thumb](File:Battlemode Cove Large unseen cave.png.md)
[thumb](File:Battlemode Cove Large unseen cave mountains.png.md)
在巨大海湾地图中，有许多未使用以及不可见的区域，这些区域大部分都是洞穴。和洞穴地图中不可见的结构不同，海湾地图中有些区域并不需要通过作弊手段才能看见，比如可以通过瀑布中的间隙游出主竞技场从而到达这些区域。

# 声音
# = 损坏的洞穴音频 =
有两段损坏的洞穴音频，分别是**cave1.binka**和**cave8.binka**，其在之后的更新中移除。有趣的是，在这两段音频移除之前，使用的未损坏的版本被储存在“_fixed”的文件夹中。

# = 未使用的循环音频 =
在游戏文件中，有四段未使用的循环音频，但是其都在后续的更新中被移除了。

# 状态效果
# = 发光 =

在[原主机版](原主机版.md)中，仅能通过NBT修改器才能获得该效果。在[Java版](Java版.md)中，如果被[光灵箭](光灵箭.md)射中后就会获得该效果，但在[原主机版](原主机版.md)中，光灵箭本身并不能给予发光效果，并且该效果本身在[原主机版](原主机版.md)中也不会有任何作用。

# = 饱和 =

饱和效果在[原主机版](原主机版.md)中没有任何作用，其不会回复[饥饿值](饥饿值.md)。即便使用NBT修改器更改效果持续时间，该效果在[原主机版](原主机版.md)也中只会持续几个游戏刻。

# = 失明 =

失明效果会导致[玩家](玩家.md)视角变得阴暗无比，也会阻止玩家[疾跑](疾跑.md)与产生[暴击](近战攻击#暴击.md)。在[原主机版](原主机版.md)中，失明是未使用的效果之一。

# = 生命提升 =

生命提升效果可以提升生物[生命](生命.md)上限。在[原主机版](原主机版.md)中，其使用[伤害吸收](伤害吸收.md)的效果图标，而不是自己的。

# = 霉运 =

与[幸运](幸运.md)的效果相反，其将<code>generic.luck</code>属性减去 1 × 等级，从而减小获得高质量战利品的概率。

# 其他
# = 调试菜单 =
在[原主机版](原主机版.md)中，有一个调试菜单，开发人员可能在开发过程中使用了该菜单。其只能在[Xbox 360版TU1](Xbox 360版TU1.md)及以下的版本中进入并使用。

# = 旧教程世界 =
在游戏文件中，有一个[Xbox 360版TU46](Xbox 360版TU46.md)教程世界的文件，其位于**\Tutorial\Tutorial.mcs**中。

# = DLC =
有一些DLC曾经可以直接购买，但现在只能通过修改获得。大部分无法获得的DLC位于**\CU\DLC\**中。
