# Java版1.3

*页面ID: 30083* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.3**是[Java版1.3.1](Java版1.3.1.md)的唯一一个预发布版，发布于2012年7月26日<ref></ref>，更新了GUI，修复了一些漏洞。

# 更改
# = 方块 =
* *[TNT](TNT.md)**
* TNT在和平难度下不对玩家造成伤害。

# = 游戏内容 =
* *[GUI](平视显示器.md)**
* 破坏方块的动画现在能在GUI隐藏下显示。

* *[超平坦世界](超平坦世界.md)**
* 在超平坦内重生不再是随机的。

# 修复
* *修复了5个漏洞**
* 修复了西瓜茎不对齐的问题。
* 修复了一个崩溃漏洞。
* 修复了在创造模式中，不能与生存模式物品栏中的胸甲槽交互的问题。
* 修复了使用附有精准采集魔咒的工具挖掘旋转了的原木时得到的物品也是旋转了的形式的问题。
* 修复了不能将一个台阶放在另一个台阶与方块间的小空隙里面的问题。</onlyinclude>
