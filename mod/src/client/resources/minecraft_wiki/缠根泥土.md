# 缠根泥土

*页面ID: 77887* | *来源: Minecraft Wiki*

* *缠根泥土（Rooted Dirt）**是一种装饰性的[泥土](泥土.md)变种方块。

# 生成
# = 自然生成 =
[thumb|right|杜鹃树下方自然生成的缠根泥土](File:Azalea Tree with Roots.png.md)
缠根泥土会自然生成在[杜鹃树](杜鹃树.md)的下方。

# = 杜鹃树 =
[杜鹃树](杜鹃树.md)地物生成时会将下方1格的方块替换为缠根泥土。

# 获取
# = 交易 =

# 破坏
挖掘缠根泥土的合适工具是锹。

缠根泥土被破坏后会掉落自身。

# 用途
类似于[砂土](砂土.md)，[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)、[花](花.md)、[粉红色花簇](粉红色花簇.md)、[野花簇](野花簇.md)、[灌木丛](灌木丛.md)、[枯萎的灌木](枯萎的灌木.md)、[大型垂滴叶](大型垂滴叶.md)、[下界菌](下界菌.md)、[菌索](菌索.md)、[下界苗](下界苗.md)、[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)都能直接放置在缠根泥土上。[树苗](树苗.md)、[竹子](竹子.md)和[甜浆果丛](甜浆果丛.md)能在缠根泥土上生长。[甘蔗](甘蔗.md)和[蘑菇](蘑菇.md)也会在符合条件的情况下在缠根泥土上生长。

对缠根泥土[骨粉](骨粉.md)会使其底部长出[垂根](垂根.md)。

[末影人](末影人.md)可以搬起及放下缠根泥土。关闭[游戏规则](游戏规则.md)将阻止该行为。

# = 转化 =
对着缠根泥土[锄](锄.md)可使其转变为普通[泥土](泥土.md)，并掉落一个[垂根](垂根.md)；对着缠根泥土[锹](锹.md)则能使其转变为[土径](土径.md)；缠根泥土上方的树苗生长成树时会将缠根泥土转变为普通泥土。

[大型云杉](大型云杉.md)长成后会将其下方及周围的缠根泥土转变为[灰化土](灰化土.md)。

除大型云杉、杜鹃树、[红树](红树.md)及[珍异橡树](珍异橡树.md)外的[树木](树木.md)长成后，下方的缠根泥土会被转变为[泥土](泥土.md)。

对上方为空气的[苔藓块](苔藓块.md)或[苍白苔藓块](苍白苔藓块.md)[骨粉](骨粉.md)会使周围7×11×7范围内，最上方的缠根泥土转变为苔藓块或苍白苔藓块。

对着缠根泥土[水瓶](水瓶.md)或发射器发射水瓶会将缠根泥土转化为[泥巴](泥巴.md)。

[菌丝体](菌丝体.md)和[草方块](草方块.md)不会蔓延到缠根泥土上。
