* *重锤（Mace）**是一种可以提高下落攻击伤害、提供击退效果和击中[实体](实体.md)后免疫摔落伤害的近战[武器](武器.md)。

# === 材料修复 ===

每个材料可以恢复重锤25%的耐久（向下取整）。

# === 合并物品 ===

叠加两把重锤的剩余耐久度，再额外获得12%的耐久度，按照[铁砧机制](铁砧机制.md)保留魔咒。

# 用途
# = 挖掘工具 =

重锤是一种[挖掘](挖掘.md)工具，每次成功挖掘了任何硬度不为0的方块会消耗2耐久度。

在[创造模式](创造模式.md)中，重锤虽然能够挖掘方块，但无法破坏方块，挖掘方块时也不会发出声音<ref></ref>。

# = 近战攻击 =
重锤每成功进行一次[近战攻击](近战攻击.md)会减少1点耐久度，符合特定条件时会发动[下落攻击](#下落攻击.md)。

# == Java版 ==
重锤的攻击速度是0.6，需要1.65秒来[恢复](近战攻击#攻击冷却.md)。

# == 基岩版 ==
重锤没有攻击冷却。

# = 下落攻击 =
# == 启动 ==

生物在下落高度大于1.5格时使用重锤进行近战攻击会发动**下落攻击**（亦称**猛击**），使这次攻击产生特殊效果。是否仍在攻击冷却并不影响其触发<ref></ref>，且攻击目标可以是如[末地水晶](末地水晶.md)的[实体](实体.md)而不限于生物<ref></ref>。而下落攻击的目标必须是生物（包括[盔甲架](盔甲架.md)），但[风爆](风爆.md)仍能在攻击非生物实体时触发。<ref></ref><ref></ref><ref></ref>

由于下落高度的计算-{}-机制，拥有[缓降](缓降.md)状态时无法触发猛击，详见。此外，虽然快速下降的[鞘翅](鞘翅.md)滑翔也能累积下落高度，但滑翔时无法触发猛击<ref></ref>，不过该限制可通过在攻击的前一瞬间脱下鞘翅来绕开<ref></ref>。而玩家即便处于滑翔状态也可以触发猛击。<ref></ref>

在触发猛击的瞬间，攻击者的下落速度将被设为向上0.01格每游戏刻（0.2米每秒），产生刹时的滞空，并重置玩家的下落高度。此外在攻击后的内，玩家下落原点会视作在击中目标时自身的位置，这意味着玩家的摔落伤害将从该处重新起算。若在攻击时已近地面，此机制能免除或降低玩家所受的摔落伤害。类似地，下落高度的重置也将影响下一次重锤下落攻击的计算。

# == 伤害 ==
重锤在猛击时会使用<code>mace_smash</code>伤害类型，并有着特殊的[死亡消息](死亡消息.md)。

生物进行下落攻击时，将产生随下落高度增加的[额外攻击力](近战攻击#额外攻击力.md)，伤害不具上限。<ref></ref>
* 对于前3格下落高度，每格造成伤害。
* 对于第4-8格下落高度，每格造成伤害。
* 对于其余的下落高度，每格造成伤害。
* 若重锤附有[致密](致密.md)，则每格再额外造成0.5&times;致密等级的伤害。

该伤害可以使用公式<math>\min\left\{6, 2h\right\}+\min\left\{8, h\right\}+\left(1+0.5p\right)\times h</math>计算，其中<math>h</math>为下落高度格数，<math>p</math>为致密魔咒等级。

此伤害加成与[暴击](暴击.md)各自独立，它们通常会同时触发，并进一步应用暴击增加的50%伤害。但在重锤未完全冷却或攻击末影龙等不符合暴击条件的情况，两者可以不同时发生。

重錘還可以附魔[破甲](破甲.md)，令目標[盔甲值](盔甲值.md)的[伤害减免百分比](盔甲机制#伤害减免.md)降低<code>-{}-魔咒等级×15%</code>。

# == 击退 ==
如果被击中的生物站在地面上，则攻击时周围会产生与被击中生物脚下方块的破坏粒子相同的粒子效果。

而被击中的生物3.5格范围内的其他生物<ref></ref>也会被击退，击退速度与生物和被击中生物的距离负相关，如果攻击者下落高度大于5格则击退速度翻倍。击退效果对飞行中的[创造模式](创造模式.md)玩家也有效。

能降低生物受重锤的击退效果。

若附有[风爆](风爆.md)的重锤造成猛击，会产生[风爆效果](爆炸#风爆.md)，将攻击者弹起并弹飞周围的实体。

與猛击本身不同，風爆並不要求目標是生物，但由于没有下落攻击时所给予的滞空，由此產生的风爆将攻击者弹起的效果将较小或不稳定。<ref></ref>。此外由于风爆为爆炸，若穿着附有[爆炸保护](爆炸保护.md)的盔甲，也会削弱风爆的效果。[下界合金盔甲](下界合金盔甲.md)的也会削弱风爆的效果。<ref></ref>

# == 计算器 ==
此计算器可计算玩家使用重锤最终造成的伤害，并可反推指定伤害所需的下落高度。须注意下落高度是开始下落到攻击时的距离，而非到地面的距离。
