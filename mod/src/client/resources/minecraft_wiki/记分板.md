# 记分板

*页面ID: 9658* | *来源: Minecraft Wiki*

[缩略图|350px|一张记分板的截图](File:Scoreboard.png.md)
* *记分板（Scoreboard）**系统是一套通过[命令](命令.md)操纵的复杂游戏机制。主要为地图作者与[服务器](服务器.md)运营者准备，记分板可用多种形式追踪、设置并列出玩家及实体的分数。

# 记分项

* *记分项（Objective）**主要由三部分组成：名称、显示名称、准则。记分项可追踪或监听游戏内的某些物体或事件，并将该物体或事件的部分属性转化为可存储于实体内的分数。在游戏内部，记分板分数为一个32位整型数字，故不能为小数，取值范围为-2,147,483,648至2,147,483,647（闭区间）。

记分项**名称（Name）**：记分项的唯一标识名，用于在命令、目标选择器参数以及某些文件格式内部引用记分项。记分项名称区分大小写，名称可以包含所有的大小写字母、数字、下划线、点、减号和加号。可以是任何字符。

* *显示名称（Display Name）**：用于在不同场合显示记分项。允许不同记分项拥有相同的显示名称。为一个[文本组件](文本组件.md)；只能是一个文本。

* *准则（Criterion，复数为Criteria）**：决定记分项应追踪游戏内的哪些物体或事件，该记分项的分数将根据指定的准则进行更新。下方的表格列举了所有的准则。

* *分数（Score）**：除只读型（参见）的记分项外，所有记分项的分数都可以被命令修改。可以指定增加或减少的值，也可以直接设置为某一特定值。

* *分数持有者（Score Holder）**：已被一个记分项记录的，拥有确定分值的玩家的名称或实体[UUID](UUID.md)。其中，玩家名不一定是一个实际存在的玩家。非玩家实体的分数只能通过命令修改，而不能通过游戏系统修改。和玩家不同，非玩家实体死亡后，其分数会被删除（对应一个记分项从内存中释放）。

命令可以通过[目标选择器](目标选择器.md)的参数来检查实体的记分项分数，语法为{{cd|-{}-scores{<名称><最小值>..<最大值>}<nowiki/>}}。其中，{{cd|-{}-<名称>}}即为记分项的唯一标识名。

比如，在[命令方块](命令方块.md)中输入{{cmd|1=execute if entity @a[scores={deaths=1..5}]}}会让比较器或条件制约的命令方块在有玩家于<code>deaths</code>记分板上拥有1至5分时提供输出。

# === 复合准则 ===
复合准则由多个部分构成，各部分间使用点号来分隔。例如， <code>minecraft.killed_by:minecraft.zombie</code>是一种复合准则，当玩家被僵尸杀死时才会增加分数。

基于复合准则的所有分数都可以通过命令修改。

任何[统计信息的命名空间ID](统计信息#命名空间ID.md)都可用作复合准则。<ref></ref>玩家自身统计数据的存储与记分板分数的存储互相独立。当这些统计数据更新时，跟踪的记分项也会同步更新。

# 队伍

* *队伍（Team）**是记分板系统管理的一套机制，可以将玩家和其他实体进行分组，形成联合的整体。
