# 发光浆果

*页面ID: 70609* | *来源: Minecraft Wiki*

* *发光浆果（Glow Berries）**是一种可从洞穴藤蔓上采集获得的[食物](食物.md)物品。

* *洞穴藤（Cave Vines）**是一种能长出发光浆果，且长出后会发光的可生长植物[方块](方块.md)。

# 生成
洞穴藤蔓能够生成洞穴藤蔓（见）。

# = 自然生成 =
洞穴藤蔓会自然生成于[繁茂洞穴](繁茂洞穴.md)生物群系。

# 获取
# = 箱子战利品 =

# 破坏
洞穴藤蔓被挖掘时会立刻被破坏。

长出发光浆果的洞穴藤蔓被破坏后会掉落1个发光浆果。

没有长出发光浆果的洞穴藤蔓被破坏后不会掉落。

# 用途
持有发光浆果对下表面[方块支撑形状](判定箱#方块支撑形状.md)完整的方块底部按下键可以放置洞穴藤蔓。

破坏洞穴藤蔓会一同摧毁其下方所有连接着的洞穴藤蔓。

# = 攀爬 =
站在洞穴藤蔓内部按住可以爬上它。如果洞穴藤蔓后面有/，按下也可以攀爬。在洞穴藤蔓上按住可以使玩家悬空于所在位置。

# = 生长 =

洞穴藤蔓下方为空气方块时，它会向下生长，生长出的每格洞穴藤蔓有的概率长有发光浆果。已生长出的洞穴藤蔓不会自然长出发光浆果，但对其[骨粉](骨粉.md)也可以使其长出发光浆果。已有巢且采集了花粉的[蜜蜂](蜜蜂.md)飞过洞穴藤蔓时，洞穴藤蔓也有概率长出发光浆果。

自然生成的洞穴藤蔓拥有23~25的值，玩家放置的洞穴藤蔓拥有或的值，使用和放置的洞穴藤蔓为0。洞穴藤蔓生长时，新长出的洞穴藤蔓的age值增加1，洞穴藤蔓age值为25时不再生长。当洞穴藤蔓末端被破坏时，其上方的洞穴藤蔓将重新获得随机值。

洞穴藤蔓在收到随机刻时，有概率增加生长。

对着长出发光浆果的洞穴藤蔓按下会掉落1个发光浆果，并使其变为未长出发光浆果的状态。

洞穴藤蔓分为两种方块，位于最末段端的为（洞穴藤蔓），其他部分则为（洞穴藤蔓植株），只有具值，两者会在需要时互相转换。

# = 阻止生长 =
对洞穴藤蔓的底部[剪刀](剪刀.md)可使洞穴藤蔓的<code>age</code>状态变为25，此后洞穴藤蔓不会再继续生长。

# = 光源 =
长出发光浆果的洞穴藤蔓会发出等级为14的[光](光.md)。

# = 食物 =
发光浆果可作为[食物](食物.md)食用，回复饥饿值以及或点[饱和度](饱和度.md)。

# = 堆肥 =
将发光浆果放进[堆肥桶](堆肥桶.md)有30%的概率使堆肥层数增加1。

# = 狐狸 =
给一对成年[狐狸](狐狸.md)喂食发光浆果可使之繁殖。繁殖出的幼年狐狸会信任玩家，从而不会主动逃离玩家。给幼年狐狸喂食发光浆果可以加速成长，每次减少10%的剩余成长时间。

狐狸会跑向半径16格内能够触及的已结果的洞穴藤蔓，使发光浆果从洞穴藤蔓上掉落，并将其叼走。狐狸嘴里原先叼着的物品会在其拾起发光浆果时转变为掉落物。
