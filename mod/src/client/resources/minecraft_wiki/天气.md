# 天气

*页面ID: 8361* | *来源: Minecraft Wiki*

[thumb](File:Weather preview.png.md)
[缩略图|250px|2个[[生物群系](File:UVNCC.jpg.md)中的天气]]

* *天气（Weather）**是发生在[世界](世界.md)中的全局性状态。<ref></ref>

# 机制
[缩略图|125px|不同天气下天空亮度等级的对比](File:WeatherSkyComparison.png.md)

天气影响所有维度中的所有位置。天气不是局部发生的，因此不会出现不同位置有不同天气的情况。

世界的天气可以是以下三种天气之一：**晴天（Clear）**，**降雨（Rain）**，**雷暴（Thunder）**。在发生降雨或雷暴时，天气在特定位置上的具体表现则受到生物群系和位置的影响，分为三类：**降雨**，**降雪**，**阴天**。

所有的[下界](下界.md)和[末地](末地.md)的生物群系都只能发生阴天，而这些维度没有阳光，因此无法察觉世界天气的变化。不过，如果玩家将能够发生降雨或降雪的生物群系生成在下界或末地，就能观察到天气。

游戏中有两个计时器控制天气：降雨计时器和雷暴计时器。降雨计时器激活时世界会开始下雨，通常每次降雨持续随机持续3~13分钟，而晴天随机持续10-150分钟。若降雨计时器和雷暴计时器同时处于激活状态，则天气变为雷暴。平均有的时间处于晴天天气，有的时间处于降雨天气，有的时间处于雷暴天气。

[玩家](玩家.md)使用[床](床.md)完成一次睡觉并跳过了时间后，天气总是会被设置为晴天。

使用可以改变天气。通过改变天气会导致降雨计时器和雷暴计时器变为相同值，因此晴天结束后必然会进入雷暴天气。命令会使天气在恶劣天气和晴天中相互切换。

[游戏规则](游戏规则.md)控制了天气是否会变化。该游戏规则为<code>false</code>时，天气不能被和|be}}以外的方式改变。

# 世界天气
# = 晴天 =
晴天是没有特殊天气现象的天气。[太阳](太阳.md)、[月亮](月亮.md)和[星星](星星.md)只在晴天时是可见的。晴天的[云](云.md)是白色的。[村民](村民.md)只在晴天时进行工作。<ref></ref>

晴天时，玩家可以使用床睡觉的时间范围为12542-23459刻。

# = 降雨 =

降雨是少见的天气。降雨发生时，太阳、月亮、星星会变得不可见，且云和天空的颜色会变为灰色。降雨也会导致村民停止工作并回到它们的家中。

降雨时，玩家可以使用床睡觉的时间范围为12010-23991刻。

降雨时，受[昼夜更替](昼夜更替.md)影响的[内部天空光照](亮度#内部光照.md)不会超过12。

# = 雷暴 =

[thumb|闪电击中了一棵树](File:LightningStrike.gif.md)

雷暴是十分罕见的恶劣天气，在降雨的效果外追加了更多的效果。

雷暴时，玩家可以在一天中的任何时候使用床睡觉，从而结束雷暴天气。

雷暴时，受昼夜更替影响的[内部天空光照](亮度#内部光照.md)不会超过10。在[敌对生物](敌对生物.md)生成系统中，雷暴时天空光照还会被视为降低了10级，这使得敌对生物可以在一天中的任何时间生成。<ref></ref>

雷暴时，天气表现为降雨的位置会有概率生成[闪电](闪电.md)。

# 天气表现
在天气为降雨和雷暴时，不同位置会出现不同的天气表现。

[生物群系](生物群系.md)有两种降水类型：无降水与有降水。无降水的生物群系只能出现阴天；有降水的生物群系，温度大于0.15时会出现降雨，否则会出现降雪。

由于温度受到高度的影响，在不同高度上也会出现不同的天气表现。

# = 降雨 =

[缩略图|250px|降雨时的山景](File:Rainy Hills.png.md)

降雨发生时，降雨粒子从天空中快速落下，降雨粒子在碰到一个方块时会发出响亮的雨声，这些声音能在远至16格以外的地方听见。这些粒子（及其相关的声音）可以通过[视频设置](视频设置.md)菜单中设置为“”来关闭。

雨水对与其接触的实体或方块有许多效果：
* 与雨水接触会消除实体的[着火](着火.md)状态。
* [火](火.md)暴露在雨水中会显著增加其熄灭速率，但不会影响不会熄灭的火，如[下界岩](下界岩.md)上的火。<ref></ref>
* [熔岩](熔岩.md)与雨水接触时会显著增加其喷发粒子的生成频率，但不会变为[黑曜石](黑曜石.md)。<ref></ref>
* [末影人](末影人.md)、[雪傀儡](雪傀儡.md)、[烈焰人](烈焰人.md)和[炽足兽](炽足兽.md)在接触雨水时会持续受到[伤害](伤害.md)。
* [钓鱼](钓鱼.md)时，[浮漂](浮漂.md)与雨水接触会降低钓鱼需要的等待时间。<ref></ref>
* [狼](狼.md)在雨水会变湿，在静止时甩干。
* 干的[耕地](耕地.md)会变湿。<ref></ref>
* [炼药锅](炼药锅.md)会逐渐被[水](水.md)填充。
* 使用[打火石](打火石.md)点火，火将会立刻熄灭。
* 在雷暴时，闪电会随机生成在有雨水落下的位置。
* 与雨水接触可以使用[三叉戟](三叉戟.md)的[激流](激流.md)效果。
* 在雷暴时，有[引雷](引雷.md)魔咒的三叉戟在击中与雨水接触的实体或[避雷针](避雷针.md)时会生成闪电。

# = 降雪 =

[缩略图|250px|一场降雪](File:Snowing.png.md)

降雪发生时，降雪粒子从天空中缓慢落下。降雪不会产生雨声。

降雪的标志性特征是[雪](雪.md)的生成。除了8层的雪，所有暴露在天空下且上表面完整的方块均会开始出现雪。<ref></ref>降雪还会导致已有的雪增加层数。

暴露在天空下的[炼药锅](炼药锅.md)在降雪时会逐渐被[细雪](细雪.md)填充。

不像降雨，降雪不能消除着火，也不能激活三叉戟的激流效果。

# = 阴天 =
阴天时不会有雨或雪出现。这意味着除了太阳、月亮、星星的可见性、云的颜色、天空的颜色和亮度等级的变化以外，阴天没有和晴天的其他区别。

所有下界和末地的生物群系都只会发生阴天，因此在这些维度中，天气的变化是无法被观测到的。

# 你知道吗
[缩略图|200px|雨滴掉进虚空](File:Void Rain.png.md)
* 雨和雪仍然在云的上方掉下。Notch对此的解释是雷暴时云上面的灰色部分是另一层云，这一层云是降雨的来源。<ref></ref>
* 降雨和降雪实际上会掉进虚空中（-64层）<!-- 经过测试，降雪粒子不会像1.18以前的版本一样穿过基岩层而抵达y=-65处 -->。这可以在创造模式中飞行在虚空中看到。注意雨滴没有发出粒子，因为其下方没有方块。
* 降雨时天空会变暗，但有时仍然能看得见太阳。
