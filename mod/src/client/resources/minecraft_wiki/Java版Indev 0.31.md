# Java版Indev 0.31

*页面ID: 35316* | *来源: Minecraft Wiki*

* *Indev 0.31**指的是[2009年12月23日](Java版Indev 0.31 20091223-0040.md)至[2010年2月6日](Java版Indev 0.31 20100206-1437.md)期间发布的26个不同的**[Indev](Java版Indev.md)**版本。

# 新内容
# = 常规 =
;常规
* [菜单屏幕](菜单屏幕.md)
* 动态光照
* [生存模式](生存模式.md)
* [合成](合成.md)
* [烧炼](烧炼.md)
* * 通过将物品扔进[火](火.md)或[熔岩](熔岩.md)进行。
* [难度](难度.md)设定
* * 和平、简单、普通和困难。

; 设置
* 等距级渲染截图。
* 通过按下进入全屏模式。
* 能够一次扔出一组物品而不是一个物品的能力。
* 右键单击从悬停的堆叠中存放单个物品。
* 玩家现在需要[镐](镐.md)来挖掘石头。

; 粒子
* 在开采方块或从火和熔岩处出现，也在火把上方出现。

; 音效
* 音效引擎。

# = 方块 =
* [火](火.md)
* * 可用于[烧炼](烧炼.md)。
* [火把](火把.md)
* * 有照明周围的作用。
* [箱子](箱子.md)

* [工作台](工作台.md)
* * 按下使用键可以打开3×3的合成网格，取代了键合成。
* [无限水源](无限水源.md)
* * 始终从最高移除位置处排水。
* [无限熔岩源](无限熔岩源.md)

# 更改
# = 常规 =
* 穿过更坚固的材料时，爆炸会失去威力。

# = 方块 =
* 树叶现在会产生阴影。
* 草现在能够在光照下产生。
* 熔岩会使可燃材料着火。
* 水不会在地表流动。
* * 如果它旁边有一个空的空间，它不会扩散到未填充的水面上。
* * 将蒸发（2/3概率）或复制（1/3概率）。

# = 生物 =
* 生物现在会受到坠落和着火等的伤害。
* 被动型生物现在只会生成在亮的地方。
* 敌对型生物现在只会生成在暗的地方。

# = 非生物实体 =
* 所有物品和生物都能着火。

# = 世界生成 =
* 海洋现在拥有无限水。

# = 命令格式 =
* 移除了当前的所有命令。
