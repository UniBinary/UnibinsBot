# 龙息

*页面ID: 17382* | *来源: Minecraft Wiki*

</ref>||Marsh Davies Mojang avatar.png}}

* *龙息（Dragon's Breath）**是收集[末影龙](末影龙.md)吐出的龙息团后获得的物品，可用于酿造[滞留药水](滞留药水.md)。

# 获取
龙息可以通过对着[末影龙](末影龙.md)的龙息攻击或[末影龙火球](末影龙火球.md)产生的[区域效果云](区域效果云.md)[玻璃瓶](玻璃瓶.md)来获取。

# 用途
# = 酿造材料 =

若输入槽中只有一瓶龙息，则酿造完成后不会返还空玻璃瓶；若输入槽中有多于一瓶的龙息，则酿造完成后会返还空玻璃瓶，返还的玻璃瓶会以[物品实体](物品（实体）.md)的形式弹出。<ref></ref>

无论输入槽中有多少瓶龙息，酿造完成后都不会返还空玻璃瓶。
