# 更改
# = 方块 =
* *[无限水源](无限水源.md)**
* 不再比流动的水更亮。

# = 物品 =
* *[盔甲](盔甲.md)**
* 可以正常使用了。
* 现在会损耗耐久。

* *[箭](箭.md)**
* 现在击中处于和平难度的玩家时会反弹，而不是造成伤害。

# = 生物 =
* *[僵尸](僵尸.md)和[骷髅](骷髅.md)**
* 调整了[僵尸](僵尸.md)和[骷髅](骷髅.md)在阳光下着火的条件。

* *常规**
* 如果一个[生物](生物.md)缺少<code>health</code>NBT标签，会默认将其生命值设为。

# = 游戏内容 =
* *[伤害](伤害.md)**
* [玩家](玩家.md)碰到[熔岩](熔岩.md)现在每次仅造成伤害，而不是，因为玩家现在会受到火焰的持续伤害。

* *[生命值](生命值.md)**
* 玩家时生命值现在会被保存。重新加载存档时，玩家不再处于满血状态了。</onlyinclude>
