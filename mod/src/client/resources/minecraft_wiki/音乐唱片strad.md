# 音乐唱片strad

*页面ID: 156608* | *来源: Minecraft Wiki*

* *strad**是一张[音乐唱片](音乐唱片.md)，可用于播放由[C418](C418.md)创作的同名曲目。

# 获取
# = 苦力怕 =
[苦力怕](苦力怕.md)被[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、或[焦骸](焦骸.md)杀死后有概率额外掉落一张音乐唱片strad。

# 用途
# = 音乐 =

[noicon](File:strad.ogg.md)

Strad是一首热带风格的合成音乐，主旋律由钢鼓演奏，弦乐、木管乐和软件合成器的分层混合伴奏。

# = 红石 =

音乐唱片strad放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为9的信号。
