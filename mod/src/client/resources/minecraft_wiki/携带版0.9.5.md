# 携带版0.9.5

*页面ID: 21280* | *来源: Minecraft Wiki*

* *v0.9.5 alpha**是携带版的一次次要更新，修复了[v0.9.4 alpha](携带版Alpha 0.9.4.md)中的一些漏洞与崩溃。在Amazon版本中，此版本包括了[0.9.2](携带版Alpha 0.9.2.md)、[0.9.3](携带版Alpha 0.9.3.md)和[0.9.4](携带版Alpha 0.9.4.md)中的更改。这是Samsung Galaxy Apps上的最后一个游戏版本<ref>https://web.archive.org/web/20190710074207/https://imgur.com/ZlazCI5</ref>。

# 新内容
# = 世界生成 =
* *[生物群系](生物群系.md)**
* 加入了[风蚀恶地](风蚀恶地.md)、[沙砾山地+](沙砾山地+.md)和[丛林丘陵](丛林丘陵.md)。

# 更改
# = 方块 =
* *[苔石](苔石.md)**
* [苔石](苔石.md)可以用[圆石](圆石.md)和[藤蔓](藤蔓.md)合成了。

* *[闪长岩](闪长岩.md)、[安山岩](安山岩.md)和[花岗岩](花岗岩.md)**
* [闪长岩](闪长岩.md)、[安山岩](安山岩.md)和[花岗岩](花岗岩.md)可合成[石砖](石砖.md)

# = 生物 =
* *常规**
* 动物不再消失了。

# = 常规 =
* *[高度](高度.md)**
* 因为重生错误被置于在极高处的玩家现在被放回y=130。

* *[服务器](服务器.md)**
* 当服务器满时，玩家不再在“定位服务器”处卡住了。

* *优化**
* 取消后台渲染以减少电量消耗（Android）。
* 改进性能。
* 为旧设备提升了FPS。

# 修复

* *其他**
* 修复了平顶山岩柱生物群系的生成错误。
* 修复了安卓平台下锁定设备后游戏冻结、崩溃和损坏存档等问题。
* 修复了在切换应用后游戏会出现区块丢失和损坏等问题。
* 修复了在性能较低的客户端下无法加载多人游戏服务器的区块的漏洞。
* 修复了在0.9.0或0.9.2下加载超平坦世界会使游戏崩溃的漏洞。
* 修复了玩家断开多人游戏连接后服务器崩溃的漏洞。
* 修复了客户端里玩家在多人游戏中崩溃的漏洞。
* 要塞内的喷泉现在会正确生成。
* 修复了Amazon Fire TV下部分纹理丢失的漏洞。

# 重新上传
v0.9.5 alpha在2014年7月27日于Andriod平台重新上传以修复一些漏洞。
