* *火（Fire）**是一种能够扩散并破坏方块和伤害生物的方块。

# 生成
火能够生成火（见）。

[打火石](打火石.md)和[火焰弹](火焰弹.md)可以生成火。

以任何方式在一个下方是[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)该特性由方块标签控制。}}的位置放置火时，会改为放置[灵魂火](灵魂火.md)。

# = 自然生成 =
火以[随机斑块](随机斑块.md)的形式在[下界](下界.md)中生成。

# = 爆炸 =
能够产生火的[爆炸](爆炸.md)，爆炸后在爆炸范围内的每一个位置若下方可以容许上方点火，则有的概率在这个位置生成火。

这些爆炸也包括：
* 在[主世界](主世界.md)以外的维度使用[床](床.md)时引发的爆炸。
* 在[下界](下界.md)以外的维度使用[重生锚](重生锚.md)时引发的爆炸。
* [火球](火球.md)引发的爆炸。

# = 熔岩 =

熔岩会在周围的方块上生成火。

# = 末地水晶 =

生成在末地的[末地水晶](末地水晶.md)会在其位置处连续生成火。

# = 小火球 =

小火球会在命中位置生成火。

# = 闪电束 =

闪电会在命中区域内生成火。

# = 发射器 =
正在使用打火石的[发射器](发射器.md)会在其面对的方向生成火。

# = 实验台 =

在[实验台](实验台.md)中合成产品时，如果组合的材料不能合成产品，点击“合成”后实验台的顶部可能会生成火。

# 获取
火没有对应的物品形式。

火的物品形式只能通过编辑物品栏获得。

# 破坏
火被挖掘时会立刻被破坏。[剪刀](剪刀.md)用于挖掘火时，耐久度不会下降。

火被破坏后不会掉落。

# 用途
[thumb|火附近有可燃尽方块时的生成位置](File:Fire position.png.md)

在游戏计算中，火的行为由[计划刻](计划刻.md)控制，不受[随机刻速率](随机刻速率.md)的影响。火从一次更新到下一次更新的间隔为到。

当[游戏规则](游戏规则.md)为时或内不含玩家时，火将停止被更新：
* 火不会被游戏更新状态。
* 火不会破坏方块。
* 火不会传播。
* 火不会熄灭。
* 熔岩不会产生火。

火仍能在不被更新的情况下对实体造成伤害。

[水](水.md)和[熔岩](熔岩.md)在流动时会冲毁沿途的火。在火方块的位置放置方块也能将火取代掉。

正在燃烧的方块的一侧会让那一侧的火被扑灭，并发出嘶嘶声。

[喷溅型水瓶](喷溅型水瓶.md)和[滞留型水瓶](滞留型水瓶.md)会扑灭范围内的火。

当火失去了支撑自身的方块时，火会直接被移除。

# = 光源 =
火发出亮度为15级的光。

# = 伤害实体 =
火会对身处其中的实体持续造成每两次的[火焰伤害](伤害#火焰伤害.md)（然而[受击后伤害免疫](受击后伤害免疫.md)会将其减慢至每0.5秒受到一次伤害）。

[僵尸猪灵](僵尸猪灵.md)、[恶魂](恶魂.md)、[凋灵骷髅](凋灵骷髅.md)、[烈焰人](烈焰人.md)、[炽足兽](炽足兽.md)、[岩浆怪](岩浆怪.md)、[潜影贝](潜影贝.md)、[僵尸疣猪兽](僵尸疣猪兽.md)、[监守者](监守者.md)、[末影龙](末影龙.md)、[凋灵](凋灵.md)、绑定[嘎枝之心](嘎枝之心.md)的[嘎枝](嘎枝.md)、[下界合金](下界合金.md)质[物品实体](物品实体.md)和具有[抗火](抗火.md)效果的生物不会受到火造成的火焰伤害。

# = 使实体着火 =

生物在接触到火时，其**剩余着火时间**会持续增加，无视生物的具有[火焰保护](火焰保护.md)魔咒的盔甲。
* 当生物处于火中时，剩余着火时间不会下降。
* 当生物的剩余着火时间不高于0时，剩余着火时间将会每增加。
* 当生物的剩余着火时间高于0时，剩余着火时间将会每增加。
* 当生物在火中移动时，剩余着火时间将会额外每增加。

一旦生物的剩余着火时间高于0，其剩余着火时间将被设置为至少，该效果受到[火焰保护](火焰保护.md)魔咒的影响。

# = 传播 =
[右|缩略图|火周围的安全建筑区域](File:Fire-safe-building.png.md)
火可以在**引燃几率**大于0的方块表面上传播，这类方块也被称为****。[含水](含水.md)的可燃方块会被视为不可燃方块。

火可以在以自身为中心3×3水平范围的区域内传播，最高可传播至向上4格，最低可传播至向下1格。对于区域内的每个位置，如果位置上的方块不是空气，那么这里无法放置火；如果这个位置毗邻的方块都不是可燃方块，那么火也无法传播至此。火无视阻挡，可以穿越方块传播引燃其他方块。

火传播区域内根据高度有不同的**基础引燃度**。以火方块为中心的3×3×3范围内，基础引燃度为100；距离火两格高的位置基础引燃度为200，距离三格为300，距离四格为400。每个传播位置根据周围方块的不同也有它们的**引燃度**，其公式为<math>\left [ \frac{i+7d+40}{a+30}\right ]</math>。其中：
* *i*为所有毗邻方块的最大引燃几率；
* *d*为[难度](难度.md)，从和平到困难分别对应0-3；
* *a*为火的方块属性<code>age</code>的值。
如果火位于可加速燃烧的生物群系由环境属性控制。}}（[丛林](丛林.md)、[竹林](竹林.md)、[沼泽](沼泽.md)、[红树林沼泽](红树林沼泽.md)、[蘑菇岛](蘑菇岛.md)、[积雪山坡](积雪山坡.md)、[尖峭山峰](尖峭山峰.md)或[冰封山峰](冰封山峰.md)）内，则引燃度减半并向下取整。如果引燃度为0，或是[雨](雨.md)可以直接落到这个位置或其水平毗邻的4个方块，那么这个位置就无法传播火。如果位置满足条件，每个计划刻这个位置可以传播火的概率为，其中*a*为引燃度，*b*为基础引燃度。火燃烧得越久、传播得越远，传播的速度也会变慢。

# = 烧毁方块 =
[缩略图|处于火灾中的村庄和森林，四处蔓延的火破坏了沿途的多数方块](File:BurningVillage.png.md)
火可以烧毁毗邻的方块。每种方块都具有**烧毁几率**，烧毁几率大于0则可以被火烧毁。设某一个方块的烧毁几率为*b*，如果火在这个方块的侧面，则火接受到计划刻时这个方块有的概率被烧毁；如果火在上面或者下面，则为。如果火位于可加速燃烧的生物群系内，在侧面的烧毁概率变为，在上下面的烧毁概率变为。

被火烧毁的方块不会掉落。当[TNT](TNT.md)被火烧毁时，会被直接激活并随后爆炸。如果被烧毁的方块位置上不会接触到雨，在被烧毁之后有（*a*为执行烧毁的火方块属性<code>age</code>的值）的概率在原地生成火，其<code>age</code>方块属性有80%的概率与执行烧毁的火相同，有20%的概率再加1。

# = 熄灭 =
火在燃烧一段时间后会自行熄灭，熄灭行为主要由方块属性<code>age</code>决定。

* 接收到计划刻时，<code>age</code>有的概率增加1。
* 如果[雨](雨.md)直接落到火或其水平毗邻的4个方块，在每一个计划刻，火都有<math>20+3a</math>%的概率熄灭，其中*a*为<code>age</code>的值。
* 如果火没有毗邻任何可燃方块，且下方方块上表面不完整或<code>age</code>值大于3，那么火在接收到计划刻时会立刻熄灭。
* 如果<code>age</code>值为15，且火下方没有可燃方块，那么火在接收到计划刻时会有25%的概率熄灭。
* 在雨中的火几乎会瞬间熄灭。<ref></ref>

# = 永久燃烧 =
[thumb|250px|在下界岩上燃烧的火永远不会熄灭](File:Infinite Fire.png.md)
维度可以指定部分方块上的火永久燃烧，使其不会熄灭，无法被[雨](雨.md)扑灭，但可以人为扑灭。

在所有维度中，[下界岩](下界岩.md)和[岩浆块](岩浆块.md)上的火均可永久燃烧。

在[末地](末地.md)中，[基岩](基岩.md)上的火也可永久燃烧。

该特性由[维度类型](维度类型.md)指定的[方块标签](Java版标签/方块.md)控制，如（主世界）、（下界）、（末地）。

# = 激活下界传送门 =

在合法的下界传送门框架内生成火可以将其激活，即使火没有毗邻一个可用的方块表面，无论火是因什么原因而被生成的。

这只在火被生成时有效：已经生成的火在可以被激活的下界传送门出现后，也不会将其激活。

这允许玩家在不使用打火石的情况下，通过放置可燃物引导火的传播来激活下界传送门。

# = 蜜蜂 =
对[蜂箱](蜂箱.md)或[蜂巢](蜂巢（方块）.md)点火会导致[蜜蜂](蜜蜂.md)逃离该方块。

# = 灵魂火 =
火下方的方块变为[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)时，会转变为[灵魂火](灵魂火.md)。

# = 化学设备 =

当[化合物创建器](化合物创建器.md)、[实验台](实验台.md)、[材料分解器](材料分解器.md)或[元素构造器](元素构造器.md)顶部着火时，其将无法使用。
