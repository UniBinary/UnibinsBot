# 基岩版1.18.0.20

*页面ID: 90038* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.0.20**是[基岩版1.18.0](基岩版1.18.0.md)的首个测试版，发布于2021年10月6日<ref></ref>，将所有[洞穴与山崖](洞穴与山崖.md)第二部分的特性从[实验性玩法](实验性玩法.md)中移出，并修复了一些漏洞。

# 更改
# = 方块 =
* *[深板岩](深板岩.md)**
* 深板岩[团簇](团簇.md)不再会在[主世界](主世界.md)的Y=0以上处生成。

* *[幽匿感测体](幽匿感测体.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

* *[凝灰岩](凝灰岩.md)**
* 凝灰岩团簇现在会在主世界的Y=0以下处生成。

# = 物品 =
* *[山羊角](山羊角.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* [草甸](草甸.md)、[雪林](雪林.md)、[尖峭山峰](尖峭山峰.md)、[积雪山坡](积雪山坡.md)、[冰封山峰](冰封山峰.md)、[裸岩山峰](裸岩山峰.md)、[繁茂洞穴](繁茂洞穴.md)和[溶洞](溶洞.md)不再属于[实验性玩法](实验性玩法.md)。
* 现在尖峭山峰、冰封山峰和裸岩山峰中的小山更近似于锯齿状，以匹配。

* *[洞穴](洞穴.md)**
* [含水层](含水层.md)和[噪声洞穴](噪声洞穴.md)不再属于[实验性玩法](实验性玩法.md)。
* 现在[雕刻器洞穴](雕刻器洞穴.md)会在主世界地表上生成。
* 更改了雕刻器洞穴的生成位置以匹配。

* *[矿脉](矿脉.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

* *[矿石](矿石.md)分布**
* 更改了主世界矿石的生成概率以匹配。
* 更改了[花岗岩](花岗岩.md)、[闪长岩](闪长岩.md)、[安山岩](安山岩.md)、[泥土](泥土.md)、[沙砾](沙砾.md)的生成位置，以匹配。

# = 游戏内容 =
* *[灾厄巡逻队](灾厄巡逻队.md)**
* 不再会自然生成[卫道士](卫道士.md)。

* *[袭击](袭击.md)**
* Boss栏的颜色由紫色更改为红色。

* *[状态效果](状态效果.md)**
* 现在玩家击败袭击后获得的[村庄英雄](村庄英雄.md)效果的时长为40:00，而不是无限次获得该效果。

# = 常规 =
* *[区块](区块.md)**
* 优化了新旧区块之间的过渡。

* *[实验性玩法](实验性玩法.md)**
* 移除了“洞穴及悬崖”子选项。

# 修复
* *洞穴与山崖特性**
* 修复了大型树不能在Y=0以下处生长的问题。（）
* 现在繁茂洞穴中会正确生成小型垂滴叶。
* 洞穴中的水不再会浮空。（）
* 草甸上生成的植物不再会替代村庄等结构的组成方块。
* 紫晶洞现在会在正确的Y轴范围内生成。（）
* 废弃矿井不再能够替换掉基岩。（）

* *性能与稳定性**
* 当服务端和客户端拥有不同运行时间的方块ID时，玩家不再会断开连接。
* 优化了在主世界放置藤蔓所需的时间延迟。

* *辅助功能**
* 为屏幕阅读器加入了其所缺少的“控制器失去连接”提示。

* *游戏内容**
* 修复了移动下界传送门后其位置未更新的问题。（）
* 游戏规则被禁用时，破坏火下方的方块后不再会生成隐形的火。（）

* *常规**
* 配置高于推荐渲染距离的玩家现在会收到更改推荐值的提示。
* 更新了默认渲染距离和最大渲染距离，以提升性能。
* 现在玩家在游戏中登录时，会收到将要返回至主菜单的提示。

* *图形**
* 现在附魔的雕刻南瓜的附魔光效仅会覆盖其自身，而不是覆盖其所在的槽位。（）
* 修复了在旧世界中乘坐矿车时，向上看有时会看到矿车内部从而阻挡视线的漏洞。
* 更新了附魔物品的渲染方式，以使其在下界渲染时不再隐形。（）

* *市场**
* 在无网络连接或会话启动失败时不再会出现市场更新提示。

* *生物**
* 生物现在能够跳过活板门。
* 生物不再会走到营火上。（）
* 美西螈现在会在空中正确显示动画。（）
* 甜浆果丛现在会正确伤害进入其中的生物。（、）
* 生物不再会试图走入甜浆果丛中。

* *用户界面**
* 结构方块现在可以在世界高度限制内正确加载和保存结构。（）
* 修复了在市场中搜索不存在的内容时会错误显示“1项结果”的问题。
* 修复了分辨率比例为4:3的屏幕上会出现文字重叠的问题。
* 修复了在多人游戏中睡觉时的Java版同步问题。现在玩家睡觉时会显示一条有多少人在等待全体玩家睡觉的消息。
* 为不同渲染配置的玩家加入了更好的视觉反馈和提示。

* *原版趋同**
* 现在在袭击结束后，若玩家离袭击地点较远，则袭击者会自然消失。
* 袭击Boss栏的颜色由紫色更改为红色。（）
* 卫道士不再会在灾厄巡逻队中自然生成。

* *村庄英雄**
* 现在在袭击中杀死过袭击者的玩家会在击败袭击后获得村庄英雄效果，并且该效果会保留在玩家身上，即使离开村庄也不会消失。（）

* *技术性**
* 现在通过函数内的命令触发的函数调用顺序是一致的。（）
* 加入了对子区块请求的缓存支持，并修复了地形上会出现空洞的问题。
* 修复了试图渲染在之前版本中通过JSON文件引入的原版生物时可能发生的渲染错误。
* 现在大部分内容日志报错和警告仅会在世界中显示一次。</onlyinclude>
