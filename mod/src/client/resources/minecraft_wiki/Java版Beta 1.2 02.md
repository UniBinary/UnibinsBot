# Java版Beta 1.2 02

*页面ID: 32680* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.2_02**是的一次次要更新，发布于2011年1月21日，主要更改了皮肤下载的位置。

# 新内容
# = 常规 =
[thumb|使用在游戏内截得的截图](File:TGA screenshot example previewable.png.md)
* *[控制](控制.md)**
* 按可以生成一张大小为36450×17700像素，大小1.8G左右的TGA格式截图（不含任何UI）。当该文件生成完毕后，游戏将会暂时卡死并出现图像扭曲。根据Notch的说法<ref></ref>，这是一项没有完成的测试用代码。这项“特性”一直到[Beta 1.5](Java版Beta 1.5.md)才被移除。

# 更改
# = 方块 =
* *[青金石矿石](青金石矿石.md)**
* 单人游戏中每块青金石矿石将会掉落4~8块[青金石](青金石.md)，而不是1个（[多人游戏](多人游戏.md)暂未被更新影响）。
* 现在可以在基岩层找到。

# = 物品 =
* *墨袋**
* 重命名为[墨囊](墨囊.md)。

# = 常规 =
* *[皮肤](皮肤.md)**
* 现在从Amazon S3下载，而不是minecraft.net。</onlyinclude>

# 你知道吗
* 这个版本有一个用于宣传用途的[衍生版本](Java版Beta 1.2_02 (20110517).md)。
