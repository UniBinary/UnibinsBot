# Aaron Cherof

*页面ID: 104062* | *来源: Minecraft Wiki*

* *·谢洛夫（Aaron Cherof）**是一名音乐制作人，他为Minecraft的[足迹与故事](足迹与故事.md)和[棘巧试炼](棘巧试炼.md)更新创作了专辑*[Minecraft: Trails & Tales (Original Game Soundtrack)](Minecraft: Trails & Tales (Original Game Soundtrack).md)*和*[Minecraft: Tricky Trials (Original Game Soundtrack)](Minecraft: Tricky Trials (Original Game Soundtrack).md)*。

# 生平
Aaron Cherof从6岁开始弹钢琴，12岁开始作曲，其编曲深受JRPG游戏的影响。后来，在了解到独立游戏开始流行后，Aaron开始参与西雅图独立游戏开发者社区，并参加了多种[Game Jam](wzh:Game Jam.md)，开始与他人合作。之后，Aaron开始参与游戏Remix，并推出了自己的音乐。<ref></ref>

# 参与制作的游戏原声集
