# 原主机版TU15、1.05

*页面ID: 83462* | *来源: Minecraft Wiki*

* *TU15/1.05**是[原主机版](原主机版.md)的一次更新，发布于2014年4月2日。<ref></ref>

# 更改
# = 生物 =
* *[僵尸](僵尸.md)**
* 将僵尸的稀有掉落物改为[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)与[铁锭](铁锭.md)。

# = 游戏内容 =
* *[合成](合成.md)**
* 物品栏中修复物品不再允许有附有魔咒的工具被修复（因为会丢失魔咒）。

# 修复
* *修复了23个漏洞**
* 修复了方块破坏后重新出现的漏洞。
* 修复了随机摔落伤害的漏洞。
* 修复了区块加载慢的漏洞。
* 修复了游戏开始时地图不正确显示的漏洞。
* 修复了分屏音频的漏洞。
* 修复了分屏中方块不总是显示裂痕的漏洞。
* 修复了末影龙的声音。
* 修复了鸡、狼、哞菇生成的问题。
* 修复了导致快速选择栏中的第一项有时会在打开物品栏时移动到物品栏的漏洞。
* 修复了发射器中的村民刷怪蛋生成的村民不产生随机职业的漏洞。
* 修复了铁傀儡杀死骷髅后不停止攻击的漏洞。
* 修复了玩家骑猪或乘矿车时传送的漏洞。
* 修复了动物攀爬圆石墙的漏洞。
* 修复了栅栏和圆石墙连接的漏洞。
* 修复了隐身药水不能使羊完全隐身的漏洞。
* 修复了玩家有隐身效果时玩家标签仍可见的漏洞。
* 修复了被驯服的狼在水中游泳隐身的漏洞。
* 修复以使奖励箱可生成在TU14、1.04前的世界。
* 修复了导致固定网络玩家在两个略微不同的位置之间摆动的漏洞。
* 修复了不同步音频。
* XB360：铁砧聊天板输入修复。
* PS3：语音聊天修复。
* PS3：修复物品栏、工作台和铁砧的双重退出声音。
