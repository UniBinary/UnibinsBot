# 数据更新方块

*页面ID: 89353* | *来源: Minecraft Wiki*

* *tile.info_update.name**和**tile.info_update2.name**（下文称**数据更新方块**）是[基岩版](基岩版.md)独有的占位符方块。

# 生成
数据更新方块通常不会生成在世界中。

有无效数字ID的方块存在于世界中时，该方块被加载为数据更新方块。

# 获取

数据更新方块只能通过升级[基岩版1.6.0](基岩版1.6.0.md)之前的世界获得，无法在其他未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取，不存在于[创造模式物品栏](创造模式物品栏.md)中，且是不可通过获取的物品。在[创造模式](创造模式.md)中对已有的数据更新方块使用可以获得数据更新方块；否则，数据更新方块只能通过存档编辑或[附加包](附加包.md)获得。

# 破坏
没有工具能够加速对数据更新方块的挖掘。

数据更新方块被破坏后会掉落自身。

# 用途
[thumb|超平坦世界中由无效自定义层加载而来的数据更新方块](File:Tile.info update.name in Superflat.png.md)
数据更新方块是未知数字ID的加载结果。数据更新方块通常来自旧版本的世界被跨越多个主要版本升级到新版本后加载。另外，如果[超平坦世界](超平坦世界.md)存档的文件里的<code>FlatWorldLayers</code>自定义的层中存在ID无效的方块，这些方块也会被加载为数据更新方块。
