* *驴（Donkey）**是一种被驯服后可以骑乘并驮货物的[生物](生物.md)。

# 生成
驴会在[平原](平原.md)、[向日葵平原](向日葵平原.md)、[草甸](草甸.md)、[热带草原](热带草原.md)、[热带高原](热带高原.md)和[风袭热带草原](风袭热带草原.md)中生成。生成的驴中有20%是幼年驴。

不对着驴使用的刷怪蛋生成的驴总是成年驴<ref></ref>；而使用刷怪蛋生成的幼年驴与自然生成概率一致。

# 行为
驴会漫无目的地四处游荡、时不时鸣叫、摇尾巴以及低头吃草。与[绵羊](绵羊.md)不同，驴在吃草时不会破坏[草方块](草方块.md)的草皮。如果玩家靠近，驴可能会看着玩家。任何一头驴，即使是未驯服的驴，都可以让玩家使用[拴绳](拴绳.md)牵引且毫不反抗。但如果玩家试图骑上一头未驯服的成年驴且驯服失败时，则驴会直立起来，甩下玩家，踢动前蹄以示反抗。与其他大多数生物类似，驴可以坐在[矿车](矿车.md)里，幼年驴还可以坐在[船](船.md)上，不过成年后会脱离船。

驴会发出嘶鸣声，比马的嘶鸣声更加尖锐。

与大多数生物不同的是，驴可以缓慢地恢复损失的生命值。

# = 驯服 =
成年的驴可以被驯服。

对着未驯服的驴按下键可骑上驴。玩家需空手对驴按键，否则驴会拒绝搭载玩家，立刻前腿腾空并嘶叫；玩家可手持着物品按键，但驴也会拒绝手持[鞍](鞍.md)和[马铠](马铠.md)的玩家。

即使玩家骑上驴，驴也有很大概率把玩家甩下、前腿腾空并嘶叫。当驴不再试图甩下玩家并产生红心粒子时则驯服成功。

驯服成功率取决于值（好感度）。驴的初始好感度为0（最高值为100）。当玩家骑上驴时，会从0-99中随机取一个数字，如果驴的好感度高于该数字，则驴会被驯服，否则将玩家甩下来，并增加5点好感度。好感度也可以通过给驴喂食来增加，详见。

即使好感度达到上限，也能正常喂食未驯服的驴（[干草捆](干草捆.md)除外）。

与其他可驯服生物一样，驯服的驴死亡时会给世界中的所有玩家显示一条[死亡消息](死亡消息.md)，而不会<ref></ref>。

# = 装备 =

驴被驯服后，玩家可以通过骑着驴打开物品栏来打开驴的物品栏，或者在时对着驴按键来打开。

驯服的驴有以下槽位可用：
* 鞍槽：用于装备[鞍](鞍.md)。
* * 可被玩家使用[剪刀](剪刀.md)移除。
* 15格空的物品栏，手持[箱子](箱子.md)对驴按键后出现。

驴不能装备[马铠](马铠.md)。

驴身上的箱子不可卸下，除非驴死亡。

# = 骑乘 =

骑乘装备了鞍的驴时能用方向键和键等来控制它。玩家可以通过按键来下驴。玩家可以在骑驴时使用物品、与方块或其他生物交互。玩家无法在骑驴时使用[下界传送门](下界传送门.md)。

玩家骑驴时会显示驴的[生命条](生命条.md)，其纹理与玩家的生命条不同。玩家的[饥饿条](饥饿条.md)被驴的生命条代替，[经验条](经验条.md)也会被驴的跳跃蓄力条代替；玩家的饥饿条和经验条会正常显示，只有在蓄力时，经验条才会被跳跃蓄力条取代，且上方经验等级的数值不会消失。

玩家可以在骑驴时使用物品、与方块或其他生物交互。

骑驴可以直接走上1格高的地方而无需跳跃。驴的速度会受到和效果影响，跳跃高度受到效果影响。[信标](信标.md)的增益效果不会施加给驴。与[马](马.md)不同的是，无状态效果的驴都有相同的速度和跳跃能力。驴的速度通常比马要慢，但仍然可以通过长按键来蓄力。

如果在驴移动或跳跃时玩家的-{}-头部进入固体方块，则玩家仍会受到窒息伤害。驴最低能通过1.625格高的空间，但低于2.75格高的空间会使玩家受到窒息伤害，低于1.75格高的空间会使驴也受到窒息伤害。驴不能通过1格宽的缝隙。

# = 喂食 =
对驴有效的食物可以喂驴。

给生命值未满的驴喂食可以使其恢复生命值。幼年驴无法通过喂食来恢复生命值。

给生命值已满的且驯服的成年驴喂食[金胡萝卜](金胡萝卜.md)、[金苹果](金苹果.md)或[附魔金苹果](附魔金苹果.md)可以让它们繁殖，详见。

给幼年驴喂食可以缩短其成长时间。

无法喂食已进入“求爱模式”或生命值已满且已驯服的驴。

下表列出了各种食物对驴的影响。

驴会跟随/内手持金苹果、附魔金苹果及金胡萝卜的玩家。

# = 繁殖 =

对生命值已满的驯服的驴使用金苹果、附魔金苹果或金胡萝卜会让它们进入[繁殖](繁殖.md)模式。当两头驴都进入繁殖模式时，它们会产下一头幼年驴；当一头驴和一匹马都进入繁殖模式时，它们会产下一头幼年[骡](骡.md)。繁殖后会掉落，同时双亲有或的冷却时间。幼年驴需要20分钟成长为成年个体，给幼年驴喂食可以加速其成长。

对幼年驴[金蒲公英](金蒲公英.md)可以阻止其成长为成年驴，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年驴无法被喂食除金蒲公英外的其他物品。

# 统计

驴有3种“马匹统计”，每头驴的统计都有所不同：生命值、（最大）移动速度和跳跃力量。这些数据是在驴出生或生成后固定的，喂食对其没有影响。

# = 生成值 =
除了繁殖以外，例如使用命令、自然生成、或使用刷怪蛋生成，会在特定范围内分配驴的属性。

# == 生命值 ==

驴的生命值范围在到之间，但趋于均值。生命值为奇数的驴不会在生命条中显示出最后半颗心。

# = 移动速度 =
驴的移动速度固定为0.175（7.525格/秒）。相比之下，玩家的正常行走速度为0.1（4.3格/秒），冲刺速度为5.6格/秒。这里列出的速度均是在没有[状态效果](状态效果.md)影响的情况下。

另见[运输](运输#方式.md)来比较多种运输方式的速度。
