# Java版Beta 1.8-pre2

*页面ID: 32465* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.8-pre2**是[Beta 1.8](Java版Beta 1.8.md)的第2个，也是最后一个预发布版，发布于2011年9月12日，<ref></ref>修复了一些漏洞。

# 更改
# = 方块 =
* *[石砖](石砖.md)**
* 裂纹石砖和苔石砖现在掉落自身而不是普通的石砖。

# = 物品 =
* *[剑](剑.md)**
* 格挡效果现在会在多人生存模式游戏下起作用。

* *[骨粉](骨粉.md)**
* 现在能够在南瓜和西瓜种子上使用骨粉。
* 一个种植在草和泥土上面的蘑菇可以长成[巨型蘑菇](巨型蘑菇.md)。

# = 生物 =
* *[鱿鱼](鱿鱼.md)**
* 被杀死时掉落[经验球](经验球.md)。

* *[鸡](鸡.md)**
* 被烧死后现在掉落熟鸡肉。

* *[牛](牛.md)**
* 被烧死后现在掉落牛排。

# = 世界生成 =
* *虚空迷雾**
* 调整了低空迷雾的强度，减弱了极端程度。

* *[废弃矿井](废弃矿井.md)**
* 它们的密度现在减半。

* *[要塞](要塞.md)**
* 增加了要塞数量，每个世界中现在是3个而不是1个。

# = 游戏内容 =
* *创造模式物品栏**
* 一些丢失的方块现在在创造模式的物品选择屏幕中。

* *[创造模式](创造模式.md)**
* 现在不能在创造模式中吃东西。

# = 常规 =
* *[选项](选项.md)**
* “生成结构”现在默认为开。

* *[控制](控制.md)**
* 和的功能由于残留的调试代码现在已被移除。
* 迷雾开关更改为。

# 修复
* *修复了7个漏洞**
* 修复了在多人游戏中，末影人的客户端侧问题。
* 修复了可以通过右键或潜行开始疾跑的问题。
* 修复了熔炉方块实体崩溃。
* 修复了离开工作台时，里面有物品会导致合成网格中出现幽灵方块。
* 修复了单人模式下内存泄露的问题。
* 修复了在下界放置藤蔓和树叶导致崩溃的问题。
* 修复了耕地不能种植西瓜和南瓜种子的问题。
