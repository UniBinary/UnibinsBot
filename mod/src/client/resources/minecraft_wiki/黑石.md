# 黑石

* *黑石（Blackstone）**是一种用途类似于[圆石](圆石.md)或[深板岩圆石](深板岩圆石.md)的深色方块，仅可以在[下界](下界.md)生成。

# 生成
# = 自然生成 =
黑石会在[玄武岩三角洲](玄武岩三角洲.md)生物群系中大量自然生成。

黑石会作为[堡垒遗迹](堡垒遗迹.md)的一部分自然生成。

[团簇](团簇.md)形式的黑石也会尝试生成在[下界](下界.md)除玄武岩三角洲以外所有[生物群系](生物群系.md)的5-28层，每区块尝试生成2次，团簇大小为1-33个方块。

# 获取
# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家8-16个黑石。

# 破坏
挖掘黑石的合适工具是镐。黑石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

黑石被破坏后会掉落自身。

# 用途
黑石可替代[圆石](圆石.md)来合成石质工具、[熔炉](熔炉.md)和[酿造台](酿造台.md)。它也可以制作成[磨制黑石](磨制黑石.md)，用来进一步合成[磨制黑石砖](磨制黑石砖.md)。
