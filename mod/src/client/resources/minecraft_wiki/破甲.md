# 破甲

*页面ID: 115137* | *来源: Minecraft Wiki*

{{redirect|突-{袭}-|中台湾正体译为“突-{襲}-”的游戏事件|袭击}}

* *破甲（Breach）**是一种用于[重锤](重锤.md)的[魔咒](魔咒.md)，可降低目标的护甲效果。

# 获取

破甲IV对于[书](书.md)，附魔需要的[附魔等级](附魔等级.md)超过了30级，因此无法从[附魔台](附魔台.md)获取。

# 用途

生物受到伤害时，若攻击者主手持有具有破甲魔咒的物品，则护甲值和盔甲韧性决定的伤害减免百分比降低<code>-{}-魔咒等级×15%</code>，但最多减少到0%。

破甲与其任何不共存魔咒被附在同一个物品上时，每个魔咒都会互不干扰地产生效果。
