# 朝向

*页面ID: 166959* | *来源: Minecraft Wiki*

[thumb|蓝色的线表示这一只青蛙的视线](File:Temperate Frog (hitbox).png.md)
* *朝向（Rotation）**（也被称为**方向**或**视角方向**）是[实体](实体.md)所面向的方向。在Minecraft中，朝向包括**Y轴旋转角（偏航角）**和**X轴旋转角（俯仰角）**，其中“X轴”和“Y轴”指的是它们旋转所绕的轴。这会影响实体的身体和头部的方向。对于没有头部的实体而言，它们有时可以绕X轴完全旋转。朝向可以限制[生物](生物.md)和[玩家](玩家.md)的视野，其他的实体（例如[船](船.md)和[物品展示框](物品展示框.md)）也有朝向。

# 表示方法
朝向以“度”为单位，用2个浮点值表示。
* **Y轴旋转角（偏航角）**：-180&deg;为正北，-90&deg;为正东，0&deg;为正南，+90&deg;为正西，+180&deg;则回到正北。
* **X轴旋转角（俯仰角）**：水平是0&deg;，向下看是正值，向上看是负值。不会超过正负90&deg;。

# 调试屏幕

[thumb|[[调试屏幕](File:Facing Debug.png.md)下显示的朝向]]
使用，所有[实体](实体.md)的朝向会以蓝色光束的方式显示。

# Y轴旋转角（偏航角）与方位
Y轴旋转角（偏航角）改变会改变面向的方向和运动的方向。<ref>[Wikipedia:Yaw_(rotation)](Wikipedia:Yaw_(rotation).md)</ref>可以在中查看[玩家](玩家.md)此处的Y轴旋转角（偏航角）。

# 有效角度范围
无论是在Minecraft还是现实中，通常朝向角度的有效范围为<math>\left[ -180^\circ, 180^\circ \right)</math>，如果超出了这个角度，就会通过取余的方式回到这一范围。**[模运算](wzh:模运算.md)**是一种不错的取余方法。

例如：当计算的结果是-190&deg;时，根据<math>-190 \equiv 170 \pmod{360}</math>，最终的结果是取余的结构170&deg;。

在编程语言中，常常会用到类似于<code>a % n</code>或<code>mod(a , n)</code>的取模运算符。但当其中有且仅有一个数是负数时，取模运算便会失效，所以各编程语言的处理方法不尽相同。<ref>例如，在Python中，<code>-200 % 360</code>返回的结果是<code>160</code>，而在C/C++/Java/JavaScript中<code>-200 % 360</code>返回的结果却是<code>-200</code>，超出了有效范围。</ref><ref>[Wikipedia:Modulo](Wikipedia:Modulo.md)</ref>此处<math>n=360</math>，所以在取模前需要将被除数<math>a</math>转换为一个正值。

# 实体移动

实体的移动受到朝向的影响，实体移动的方向主要受实体的朝向影响，例如在[玩家](玩家.md)使用[鞘翅](鞘翅.md)时，玩家的朝向很大程度上决定了接下来的运动轨迹和接触方块后所受的伤害。

# 放置方块
视角会影响某些方块的放置方向，例如[玩家](玩家.md)放置的[楼梯](楼梯.md)、[告示牌](告示牌.md)等的朝向取决于玩家的朝向，这些物品的朝向则会影响使用。

# 目标选择
目标选择条件允许根据实体的特定视角来筛选实体：

角度范围通过两个点确定，例如<code>43..47</code>。下面的这个命令可以给Y轴旋转角度数（偏航角）在43&deg;到47&deg;间的所有[玩家](玩家.md)的[动作栏](动作栏.md)中显示“您的Y轴旋转角度数（偏航角）在43度到47度间。”：
 /title @a[y_rotation=43..47] actionbar {"text":"您的Y轴旋转角度数（偏航角）在43度到47度间。"}

下面的这个命令可以给X轴旋转角度数（俯仰角）在43&deg;到47&deg;间的所有[玩家](玩家.md)的[动作栏](动作栏.md)中显示“您的X轴旋转角度数（俯仰角）在43度到47度间。”：
 /title @a[x_rotation=43..47] actionbar {"text":"您的X轴旋转角度数（俯仰角）在43度到47度间。"}

这四条命令可以检测[玩家](玩家.md)所面向的方向，并在[聊天框](聊天框.md)中以的方式输出目前的朝向：
 /execute if entity @p[y_rotation=135..-135] run say North
 /execute if entity @p[y_rotation=-135..-45] run say East
 /execute if entity @p[y_rotation=-45..45] run say South
 /execute if entity @p[y_rotation=45..135] run say West

# 数据值

所有[实体](实体.md)都有名为<code>Rotation</code>的数据，用来储存实体的朝向。

[Java版](Java版.md)实体数据（节选）：
<div class="treeview">
* ：实体数据根标签
* *：两个浮点型数据值定义了实体的朝向角度。
* ** : Y轴旋转角（偏航角），范围是<math>\left[ -180^\circ, 180^\circ \right) </math>。
* ** : X轴旋转角（俯仰角），范围是<math>\left[ -90^\circ, 90^\circ \right] </math>。
</div>

[基岩版](基岩版.md)实体数据（节选）：
<div class="treeview">
* ：根标签。
* *：两个浮点型数据值定义了实体的朝向角度。
* ** : Y轴旋转角（偏航角），范围是<math>\left[ 0^\circ, 360^\circ \right) </math>。
* ** : X轴旋转角（俯仰角），范围是<math>\left[ -90^\circ, 90^\circ \right] </math>。
</div>

# 设置视角
可以使用命令或|je}}设置[实体](实体.md)的视角。拥有[生物AI](生物AI.md)的实体在传送后依然会自由移动，但其移动将从固定视角开始。

除了玩家外的所有实体均可以通过命令修改其<code>Rotation</code>数据来设置视角。

# 视角坐标

插入符号<code>^</code>允许根据实体的旋转角度来确定位置坐标。
