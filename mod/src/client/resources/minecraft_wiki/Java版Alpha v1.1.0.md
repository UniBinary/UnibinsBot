* *Alpha v1.1.0**是的一次秘密更新，发布于2010年9月10日<ref></ref>，加入了[指南针](指南针.md)和服务端[物品栏](物品栏.md)，对其他内容做了一些修改，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[指南针](指南针.md)**
* 指向[玩家](玩家.md)的出生点。

# = 游戏内容 =
* *多人游戏物品栏**
* 现在物品栏在多人游戏可用了。

* *[调试屏幕](调试屏幕.md)**
* 按住查看。

# 更改
* 与[服务器](服务器.md)断开连接时，服务器会保存玩家的位置。
* 当生成世界时，[黏土](黏土.md)变得更常见。
* 1个[熔岩桶](熔岩桶.md)可以用于烧炼100个物品。
* 实验内容更改为在[多人游戏](多人游戏.md)中允许怪物生成。

# 修复
* *修复了2个漏洞**
* 在高画质下，火把不能放置在树叶上。
* 箱子、告示牌以及熔炉现在能在多人游戏中正常工作了。

# 重新上传
该版本的客户端于18:17（UTC）被重新上传，以修复玩家视角可能在墙壁内错误移动的漏洞。</onlyinclude>
