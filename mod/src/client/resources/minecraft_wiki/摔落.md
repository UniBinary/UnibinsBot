# 摔落

*页面ID: 101085* | *来源: Minecraft Wiki*

* *摔落（Falling）**是在[实体](实体.md)从高处下落到可站立表面时发生的事件，会造成摔落[伤害](伤害.md)等多种效果。

# 下落高度
实体受到的摔落伤害取决于**下落高度**而非落地速度。下落高度根据每刻的坐标变化积累，在下降时增加，但升高时不会减少。

部分效果会停止并清除实体的下落高度，但不能防止实体因其他原因而受到摔落伤害。

以下效果将下落高度重置为0格：
* 下落时与[水](水.md)、[蜘蛛网](蜘蛛网.md)、[蜂蜜块](蜂蜜块.md)侧面、[甜浆果丛](甜浆果丛.md)、[细雪](细雪.md)、[气泡柱](气泡柱.md)接触。
* 向上或向下攀爬[梯子](梯子.md)、[藤蔓](藤蔓.md)、[脚手架](脚手架.md)、[垂泪藤](垂泪藤.md)、[缠怨藤](缠怨藤.md)、[洞穴藤蔓](洞穴藤蔓.md)。
* * 直接摔落到这些方块上时依然会受到伤害。
* * 开启状态的[活板门](活板门.md)下方有梯子且与梯子在同一面时，活板门也会像梯子一样可以攀爬。
* * [马](马.md)、[驴](驴.md)、[骡](骡.md)不受上述除[脚手架](脚手架.md)外方块的影响。
* * [蜘蛛](蜘蛛.md)正在攀爬的方块被视为“梯子”考虑。
* 正在骑乘实体。
* [矿车](矿车.md)落到轨道上时。
* [船](船.md)在深度超过1格的水上时。
* 生物使用[末影珍珠](末影珍珠.md)或[紫颂果](紫颂果.md)传送。
* 生物具有[飘浮](飘浮.md)或[缓降](缓降.md)状态效果。
* 玩家向上运动（即实体数据<code>Motion[1]</code>的值大于0）。
* 生物接触到可站立表面并计算完摔落伤害等摔落行为后。

下降速度小于每刻0.5格（10m/s）时，以下效果将下落高度重置为1格：
* 使用[鞘翅](鞘翅.md)滑翔时。
* 当生物被[拴绳](拴绳.md)拴住，拴绳长度大于其弹性距离时。大部分生物的拴绳弹性距离为6格，恶魂和快乐恶魂为10格。

与[熔岩](熔岩.md)接触时，每1刻下落高度减半。

对于下落高度超过2.5格的实体，[细雪](细雪.md)具有0.9格高的碰撞箱。

# 摔落结算
当实体接触到可站立表面时（所有固体阻挡碰撞箱的上表面，包括绝大多数方块、[潜影贝](潜影贝.md)或船的顶面，或[炽足兽](炽足兽.md)摔到熔岩上），便会根据下落高度和摔落位置的方块来计算摔落的效果，包括声音、粒子和伤害。

摔落事件造成的伤害类型为[摔落伤害](伤害#摔落伤害.md)，[护甲值](护甲值.md)不能减免摔落伤害，但[摔落缓冲](摔落缓冲.md)和[保护](保护.md)魔咒可以。

由于计算摔落效果先于更新摔落距离，落地前最后一刻的高度不会被计算。

当生物摔落触地时，若摔落位置的方块不是[黏液块](黏液块.md)或[细雪](细雪.md)，游戏按照下列步骤计算摔落伤害：
# 获取生物的下落高度*f*和安全降落高度*h*。
# * 对于[骆驼](骆驼.md)、[驴](驴.md)、[马](马.md)、[羊驼](羊驼.md)、[骡](骡.md)、[骷髅马](骷髅马.md)、[行商羊驼](行商羊驼.md)、[僵尸马](僵尸马.md)，安全降落高度*h*为6。
# * 对于[狐狸](狐狸.md)，安全降落高度*h*为5。
# * 对于其他生物，安全降落高度*h*为3。
# * 当生物摔落触地时，如果下落高度小于安全下落高度，则不产生落地粒子。
# 获取生物脚下的方块，对特定方块修正下落高度，获得方块摔落伤害系数*r*：
# * 如果为[干草捆](干草捆.md)和[蜂蜜块](蜂蜜块.md)，则摔落伤害系数*r*为0.2。
# * 如果为[床](床.md)，则摔落伤害系数*r*为0.5。
# * 如果为方向向上的[滴水石锥](滴水石锥.md)，则下落高度<math>f \leftarrow f+2</math>，摔落伤害系数*r*为2。
# * 其他方块摔落伤害系数*r*为1。
# 获取生物为*a*，则摔落伤害为<math>d=\lceil\left(f-h\right)ra\rceil</math>。
# 对于部分生物，摔落伤害会被强制减少：
# * [山羊](山羊.md)的摔落伤害固定减少10，即<math>d \leftarrow d-10</math>。
# * [青蛙](青蛙.md)的摔落伤害固定减少5，即<math>d \leftarrow d-5</math>。
* 在没有额外防护的情况下，大多数生物的致命下落高度为<code>生命值 + 3</code>格，对于生命值为的玩家则是23格。

除伤害生物外，摔落位置的方块会提供摔落行为：
; [床](床.md)
   生物的垂直速度变为相反数的66%，非生物实体的垂直速度变为相反数的52.8%。
  * 在落地前上床（如果可以）会暂时避免伤害，但伤害仍会在起床后计算。
; [黏液块](黏液块.md)
   正在的玩家以外的生物的垂直速度变为相反数的100%，非生物实体的垂直速度变为相反数的80%。
; [海龟蛋](海龟蛋.md)
   [海龟](海龟.md)和[蝙蝠](蝙蝠.md)以外的生物摔落时，的概率破坏方块中的一个海龟蛋。
; [耕地](耕地.md)
   碰撞箱体积大于0.512m<sup>3</sup>的生物摔落时，<code>下落高度 - 0.5</code>的概率使耕地变为泥土。

部分实体在摔落时有特殊效果：
* [马](马.md)、[驴](驴.md)、[骡](骡.md)、[僵尸马](僵尸马.md)和[骷髅马](骷髅马.md)等在摔落时，实际下落高度会减少一半再计算摔落伤害，因此摔落伤害的计算结果会更低，其乘客受到的摔落伤害也会被减少。
* [山羊](山羊.md)的摔落伤害固定减少10，[青蛙](青蛙.md)的摔落伤害固定减少5。
* [铁傀儡](铁傀儡.md)、[雪傀儡](雪傀儡.md)、[铜傀儡](铜傀儡.md)、[潜影贝](潜影贝.md)、[悦灵](悦灵.md)、[蝙蝠](蝙蝠.md)、[蜜蜂](蜜蜂.md)、[烈焰人](烈焰人.md)、[猫](猫.md)、[鸡](鸡.md)、[恶魂](恶魂.md)、[幻翼](幻翼.md)、[岩浆怪](岩浆怪.md)、[豹猫](豹猫.md)、[鹦鹉](鹦鹉.md)、[凋灵](凋灵.md)、[旋风人](旋风人.md)等生物免疫摔落伤害。
* 实体被骑乘并摔落时会将摔落伤害传递给乘客，所有骑乘者都会受到其坐骑受到的减免前的摔落伤害。免疫摔落伤害的实体不会传递摔落伤害给其乘客。

# 避免摔落
几乎所有生物在寻路时都会有意避免使自己受到摔落伤害的摔落路径。通常情况下，生物寻路时可接受的下落高度为3格。

当生物有攻击目标时，寻路时可接受的下落高度为<code>-{}-3 + 最高值(0, 剩余生命值 - 最大生命值 × 33% - 难度修正值)</code>格，其中难度修正值在简单难度时为8，普通难度时为4，其余情况下为0。

与其他生物不同，有目标的[苦力怕](苦力怕.md)在寻路时能接受的下落高度为<code>-{}-3 + 剩余生命值 - 1</code>格，这使苦力怕会只要不受到致命摔落伤害就会从高处跳下来。

上述生物寻路时可接受的下落高度计算均不考虑对摔落伤害的增加、减少或免疫效果，仅与生物的生命值有关。

在一些情况下，玩家能避免摔落或在摔落中生还。
* [潜行](潜行.md)状态会防止玩家走下高度差等于或大于格方块的平面边界。
* 在落地前的瞬间放置[水](水.md)、[蜘蛛网](蜘蛛网.md)、[黏液块](黏液块.md)、[干草捆](干草捆.md)、[蜂蜜块](蜂蜜块.md)、[缠怨藤](缠怨藤.md)、[细雪](细雪.md)、[床](床.md)等能够降低或免除摔落伤害的方块。
* 使用末影珍珠或紫颂果传送，使用末影珍珠时玩家将会受到伤害。
* 身着具有[摔落缓冲](摔落缓冲.md)或[保护](保护.md)魔咒的盔甲会减少摔落伤害，减少的量取决于魔咒的等级。
* 使用[缓降药水](药水#缓降药水.md)获得[缓降](缓降.md)效果，从而规避摔落伤害。
* [跳跃提升](跳跃提升.md)效果每一级降低摔落伤害，如处于跳跃提升II时下落5格等同于普通情况下下落3格。
* 使用[神龟药水](药水#神龟药水.md)、附魔金苹果获得[抗性提升](抗性提升.md)效果，从而减少摔落伤害。
* 坐在[船](船.md)中下落将完全免除摔落伤害。
