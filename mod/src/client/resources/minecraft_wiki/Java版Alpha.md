# Java版Alpha

*页面ID: 6644* | *来源: Minecraft Wiki*

* *Alpha**是[Minecraft](Minecraft.md)的第五个[开发阶段](版本记录.md)，该阶段仅支持[生存模式](生存模式.md)。

Alpha阶段的Minecraft更新极为频繁，这主要是因为[Notch](Notch.md)于2010年5月29日辞去工作，全身心投入到游戏开发中，还成立了一家小型公司<ref></ref>。在此后的几周内，诸多错误被不断修复，相关信息也发布到了他的[开发博客](The Word of Notch.md)上。该阶段的新内容和修改包括[秘密周五更新](秘密周五更新.md)，让玩家能更好地在游戏中探索。

2010年12月11日，Notch宣布游戏进入[Beta](Java版Beta.md)开发阶段，同时将于12月20日将游戏售价上调至€14.95。<ref></ref>

# 特点

* 多人生存模式（SMP），可通过IP地址连接服务器。
* [下界](下界.md) - 需通过[下界传送门](下界传送门.md)进入，包含主世界没有的生物（如[恶魂](恶魂.md)和[僵尸猪人](僵尸猪人.md)），且支持快速移动。
* [生物群系](生物群系.md) - 不同环境在位置、[区块](区块.md)、温度上存在差异。
* 加入[红石电路](红石电路.md)系统及I/O逻辑开关。
* [万圣节更新](万圣节更新.md)中新增物品：[下界岩](下界岩.md)、[荧石](荧石.md)、[灵魂沙](灵魂沙.md)、[南瓜](南瓜.md)和[南瓜灯](南瓜灯.md)。
* 改进AI寻路系统和生成系统。
* [洞穴](洞穴.md)和[生物](生物.md)新增音效。
* 加入了[雪](雪.md)和[冰](冰.md)地形，以及[雪块](雪块.md)。
* 加入了[船](船.md)。
* 加入了[牛](牛.md)、[史莱姆](史莱姆.md)和[鸡](鸡.md)三种生物。
* 新的[音乐](音乐.md)。
* 新的[画](画.md)。
* 新的世界高度限制：最顶层为128层。
* 按可隐藏角色信息和手臂显示（HUD）。
* 按截图，图片将保存至。
* 物品栏有40个格子，而非Beta版及之后的36个，因为合成格也可存放物品。

# 你知道吗
* 2010年9月18日，Minecraft官方服务器出现故障，Notch将那个周末设为“免费”，任何人都可免费下载并游玩Minecraft。<ref></ref>此事引发广泛新闻报道，吸引了大量新玩家，其中不少人后来购买了Minecraft。<ref>http://news.bigdownload.com/2010/09/28/minecraft-sees-surge-in-sales-following-unplanned-free-weekend/</ref>
