# Java版19w44a

*页面ID: 48962* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w44a**是[Java版1.15](Java版1.15.md)的第11个快照，发布于2019年10月30日<ref name="19w44a"></ref>，修改了[蜂蜜瓶](蜂蜜瓶.md)的堆叠机制，并且对[铁傀儡](铁傀儡.md)、[区块](区块.md)和[粒子](粒子.md)进行了优化，修复了一些漏洞。

# 新内容
# = 常规 =
* *[标签](Java版标签.md)**
* 加入了方块标签。

# 更改
# = 物品 =
* *[蜂蜜瓶](蜂蜜瓶.md)**
* 将4个[玻璃瓶](玻璃瓶.md)与1个[蜂蜜块](蜂蜜块.md)一同放入[工作台](工作台.md)进行合成，现在可以获得4个蜂蜜瓶。
* 现在是可堆叠的（上限为16）。

# = 生物 =
* *[铁傀儡](铁傀儡.md)**
* 铁傀儡的开裂程度现在由剩余[生命值](生命值.md)与总生命值的比值决定。

* *[鹦鹉](鹦鹉.md)**
* 不再会模仿[狼](狼.md)、[北极熊](北极熊.md)和[僵尸猪人](僵尸猪人.md)的叫声。

# = 常规 =
* *[区块](区块.md)**
* 改进了区块加载。

* *[配方书](配方书.md)**
* 许多方块类物品的配方更改为只需要获得1份原材料即可在配方书中解锁。
* * 这其中包括:
  :
* 当玩家获得9份上列部分方块的原材料时，这些方块分解为其原材料的合成配方不再会解锁。
* * 这其中包括:
  :

* *[粒子](粒子.md)**
* 优化了粒子垂直下落并与方块发生碰撞的动画。
