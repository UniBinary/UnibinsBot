# 物品冷却

*页面ID: 170580* | *来源: Minecraft Wiki*

* *物品冷却** （也被称为**使用冷却**）是在一段时间内限制物品使用的机制。

# 机制
对于大部分拥有冷却的物品，物品冷却在后触发。物品冷却表现为在[快捷栏](快捷栏.md)和[物品栏](物品栏.md)中，物品不断下降的透明白色进度条。当冷却进度条下降到底部时，物品冷却完毕。物品冷却会影响玩家的所有同类物品。当玩家用[盾牌](盾牌.md)格挡[斧](斧.md)或[监守者](监守者.md)的近战攻击后，盾牌会被停用，进入5秒冷却。在[基岩版](基岩版.md)中，使用[矛](矛.md)进行一次戳刺后，矛会进入冷却。

# 数据组件

[数据组件](数据组件.md)<code>[use_cooldown](数据组件#use_cooldown.md)</code>可以控制物品的冷却时间。如{seconds:1}]}}可以给予玩家一个冷却时间为1秒的雪球。如果没有定义，该物品会使用物品的ID作为冷却组ID；否则使用的值。

数据组件<code>[block_attacks](数据组件#block_attacks.md)</code>中，可以控制物品被可停用格挡的攻击击中时，物品冷却时长的乘数。如果该值为<code>0</code>，则物品不能被攻击停用。
