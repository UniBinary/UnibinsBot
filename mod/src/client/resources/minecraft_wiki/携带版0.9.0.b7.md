# 携带版0.9.0.b7

*页面ID: 31497* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.9.0 alpha build 7**是[v0.9.0 alpha](携带版0.9.0.md)的第7个测试版，发布于2014年6月23日，修改了村庄的生成机制，并修复了一些漏洞。

# 更改
# = 世界生成 =
* *[村庄](村庄.md)**
* 让村庄更加常见。

# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 在创造模式物品栏中选择正确的分类打开。
* 在生存模式物品栏中，如果手持合成有关物品，会默认打开合成界面。
* 带有末影之眼的末地传送门框架不再存在于创造模式物品栏。

# = 常规 =
* *优化**
* 刷新了有限世界以消除卡顿。
* 更改网络协议版本（无法兼容Alpha 0.9.0 build 6及以前版本）。

# 修复
* *修复了9个漏洞**
* 熔炉的某一错误会引起崩溃。
* 游戏内怪物生成过多。
* 有限世界范围外的生物存在生成问题。
* 客户端上玩家生成位置有误。
* 若不点击不透明方块则无法破坏透明方块。
* 梯子、火把等无法放置在与玩家位置交叉/靠近的地方。
* 熔炉物品栏无法正常刷新。
* 服务器上的玩家加入信息是重复的。
* 生存中的盔甲栏渲染错误。</onlyinclude>
