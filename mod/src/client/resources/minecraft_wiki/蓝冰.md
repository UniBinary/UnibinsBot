# 蓝冰

*页面ID: 34113* | *来源: Minecraft Wiki*

* *蓝冰（Blue Ice）**是一种自然生成于[冰山](冰山.md)，可以由[浮冰](浮冰.md)合成的方块。

# 生成
# = 自然生成 =
蓝冰会自然生成在[冻洋](冻洋.md)生物群系（作为[冰山](冰山.md)的一部分）、雪原[村庄](村庄.md)的某些房屋和[远古城市](远古城市.md)的冰窖中。

蓝冰还会在雪原村庄中以[冰堆](冰堆.md)的形式生成。

# 破坏
挖掘蓝冰的合适工具是镐。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，蓝冰被破坏后不会掉落。

被具有精准采集的工具挖掘破坏时，蓝冰被破坏后会掉落自身。

# 用途
蓝冰很滑，且比[冰](冰.md)和[浮冰](浮冰.md)更滑，包括物品在内的大多数[实体](实体.md)（[矿车](矿车.md)除外<ref></ref>）可以在蓝冰上面滑动。在水流下放置蓝冰亦可加快物品在水流中的速度，但生物不会在底部有蓝冰的水流上滑的更快。

[船](船.md)在蓝冰上行驶比在普通的冰或浮冰上行驶更快，最快速度可达72.73格/秒（冰和浮冰为40格/秒）。

蓝冰是一个完整的固体方块，并允许任何物体放置在它上面。

不同于普通的冰，将光源放置在蓝冰旁并不会使蓝冰融化，生物也可以在蓝冰上生成。
