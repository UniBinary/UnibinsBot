# Java版1.8.6

*页面ID: 16530* | *来源: Minecraft Wiki*

* *1.8.6**是的一次次要更新，发布于2015年5月25日<ref></ref>。此更新解决了未能在[Java版1.8.5](Java版1.8.5.md)完全修复的问题<ref></ref>。此版本兼容1.8到1.8.5的服务端。
