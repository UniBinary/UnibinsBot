# 苔石

* *苔石（Mossy Cobblestone）**是[圆石](圆石.md)的生苔变种，在某些[结构](结构.md)中伴随圆石生成。

# 生成
# = 自然生成 =
在[地牢](地牢.md)的地板、[丛林神庙](丛林神庙.md)、[掠夺者前哨站](掠夺者前哨站.md)以及平原、针叶林、雪原[村庄](村庄.md)和[僵尸村庄](僵尸村庄.md)中生成的圆石有概率被替换为苔石，该概率取决于所在结构的种类。

苔石还会在[试炼密室](试炼密室.md)中的僵尸和幼年僵尸[试炼刷怪笼](试炼刷怪笼.md)旁生成，也会作为[海底废墟](海底废墟.md)部分结构和[生苔的巨石](生苔的巨石.md)地物的一部分生成。

# 破坏
挖掘苔石的合适工具是镐。苔石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

苔石被破坏后会掉落自身。
