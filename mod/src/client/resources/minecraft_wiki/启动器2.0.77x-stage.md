# 启动器2.0.77x-stage

*页面ID: 63432* | *来源: Minecraft Wiki*

* *2.0.774-stage**（[Windows](wzh:Microsoft Windows.md)）或**2.0.775-stage**（[macOS](wzh:macOS.md)）是一次[启动器](启动器.md)更新，发布于2017年2月8日，修复了一些漏洞。

# 修复
*  - Windows启动器在关闭时不会记住窗口的位置。
*  - 启动器在使用现有账户登录时会强制调整大小。
