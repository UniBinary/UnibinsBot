# Java版1.18-pre5

*页面ID: 90874* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.18-pre5**是[Java版1.18](Java版1.18.md)的第5个预发布版，发布于2021年11月19日<ref></ref>，更改了新地形在旧区块下方的生成条件，并修复了一些以纹理问题为主的漏洞。

# 新内容
# = 常规 =
* *[标签](Java版标签.md)**
* 加入了以下方块标签：
* * <code>azalea_grows_on</code>
* * <code>azalea_root_replaceable</code>
* * <code>replaceable_plants</code>
* * <code>terracotta</code>
* 加入了以下物品标签：
* * <code>dirt</code>
* * <code>terracotta</code>

# 更改
# = 方块 =
* *[铁砧](铁砧.md)**
* 略微更改了GUI上锤子的纹理。

* *[木桶](木桶.md)**
* 更改了底面纹理，以匹配[纹理更新](纹理更新.md)后的木板纹理。

* *[胡萝卜](胡萝卜.md)**
* 更改了其<code>stage3</code>的纹理，去除了一个多余的像素点。

* *[制图台](制图台.md)**
* 更改了纹理，以匹配纹理更新后的木板纹理。

* *[可可果](可可果.md)**
* 更改了其<code>stage0</code>和<code>stage1</code>的纹理文件，去除了多余的像素。

* *[土径](土径.md)**
* 更改了侧面纹理，以匹配其顶面纹理。

* *[门](门.md)**
* 更改了门的模型，以修复云杉木门顶部及底部的纹理问题。
* 更改了橡木门和铁门的纹理，去除了其中部的多余横线。

* *[附魔台](附魔台.md)**
* 更改了其UI中[青金石](青金石.md)槽的纹理。

* *[玻璃板](玻璃板.md)**
* 更改了顶部纹理，以匹配其侧面纹理。

* *[讲台](讲台.md)**
* 更改了底座的纹理，以匹配纹理更新后的木板纹理。

* *[原木](原木.md)**
* 更改了绯红菌柄和诡异菌柄的顶部纹理，以匹配。
* 更改了深色橡木原木的顶部纹理。
* 更改了去皮深色橡木原木的侧面纹理，以匹配其顶面颜色。

* *[云杉木板](云杉木板.md)**
* 更改了纹理上取色错误的一个像素点。

* *[染色玻璃](染色玻璃.md)和[染色玻璃板](染色玻璃板.md)**
* 更改了蓝色、红色染色玻璃及对应玻璃板的纹理，现在其透明度与其他染色玻璃一致。

* *[睡莲](睡莲.md)**
* 更改了纹理UV。

* *[仙人掌盆栽](仙人掌盆栽.md)**
* 更改了模型。

# = 物品 =
* *[甜菜种子](甜菜种子.md)和[西瓜种子](西瓜种子.md)**
* 将纹理整体下调了1个像素。

* *[盔甲](盔甲.md)**
* 更改了金胸甲、钻石胸甲和钻石护腿的模型纹理。

# = 生物 =
* *[美西螈](美西螈.md)**
* 更改了棕色变种的背面纹理，使之水平居中。

* *[唤魔者](唤魔者.md)、[卫道士](卫道士.md)和[女巫](女巫.md)**
* 更改了纹理，移除了多余的兜帽纹理。

* *[幻术师](幻术师.md)**
* 更改了纹理，移除了几个多余的像素点。

* *[鹦鹉](鹦鹉.md)**
* 更改了所有变种的模型，使其翅膀贴图不再颠倒。

# = 非生物实体 =
* *[盔甲架](盔甲架.md)**
* 更新了平滑石头底座的边框纹理。

# = 世界生成 =
* *[随机斑块](随机斑块.md)**
* 现在[西瓜](西瓜.md)斑块的生成量大约是之前的10倍。
* 现在[南瓜](南瓜.md)斑块的生成量大约是之前的6倍。
* 现在[甜浆果丛](甜浆果丛.md)斑块的生成量大约是之前的4倍。

* *旧世界升级**
* 现在，若一个旧区块Y=0高度的任意位置上有基岩，则新地形会在Y=0高度的所有非空气方块的下方生成。
