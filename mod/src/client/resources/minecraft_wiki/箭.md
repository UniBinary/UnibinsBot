* *箭（Arrow）**是一种用于攻击的弹射物。

# 生成
[骷髅](骷髅.md)、可以使用[弓](弓.md)来发射箭，[掠夺者](掠夺者.md)、[猪灵](猪灵.md)可以使用[弩](弩.md)来发射箭。凋灵骷髅会发射着火的箭，[流浪者](流浪者.md)会发射带效果的箭，[沼骸](沼骸.md)会发射带中毒效果的箭，[焦骸](焦骸.md)会发射带虚弱效果的箭。以上生物不需要拥有箭就可以无限发射箭，且使用弓的生物副手持有箭及其变种时也能无限发射对应的箭。由非玩家生物发射的箭不能被回收。

[发射器](发射器.md)在使用箭时会将其发射。

[玩家](玩家.md)使用弓或弩可以发射箭。

# 获取
射出的箭在一些情况下可以被[回收](#回收.md)进玩家的[物品栏](物品栏.md)里。

# = 掉落物 =
掠夺者和猪灵在被玩家或驯服的[狼](狼.md)杀死时可能会掉落其持有的弩，若其中包含已经装填的箭，则可以在发射出来后回收。

# 用途

箭的物品形式不能被直接使用。弓、弩、发射器可以消耗箭，并发射箭实体。

具有[无限](无限.md)魔咒的弓在使用普通的箭射击时，箭不会被消耗。

具有[穿透](穿透.md)魔咒的弩可以使箭射中实体后再射到方块上，具有[多重射击](多重射击.md)魔咒的弩也能够在可回收的箭未命中实体的情况下回收药箭，玩家可以借此将箭回收，使箭的效果在箭不被消耗的情况下被无限使用。

# 行为
箭是一种[弹射物](弹射物.md)，可以触发[标靶](标靶.md)。

被射出时，箭会按照[斜抛运动](wzh:抛物线.md)的规律飞行，且会受到[空气](空气.md)、[水](水.md)和[熔岩](熔岩.md)阻力的影响。

飞行中的箭会受到[爆炸](爆炸.md)的影响，增加或降低箭的速度。高强度爆炸发射的高速箭可以造成极高且没有上限的伤害。

[液体](液体.md)中的箭会受到可观的阻力：箭在射出不到8米时，水平速度就会完全减至0，然后开始垂直下沉，但箭造成的[击退](伤害#击退.md)效果不受影响。水中的箭还会产生气泡粒子效果尾迹。

使用[弓](弓.md)沿水平方向射出至平地上时，未拉弦的箭大约可射3米远，拉至一半可射15米远，拉满弦可射24米远。以合适的角度射出一支拉满弦的箭可使其飞行约120米，而该距离约为240米。竖直向上射出的箭最高可飞约66米。

在箭的轨迹中有一个用于X、Y和Z坐标的随机变量，由<code>this.rand.nextGaussian() * 0.0075 * (double)inaccuracy</code><ref>https://docs.oracle.com/javase/8/docs/api/java/util/Random.html#nextGaussian--</ref>给出。这一不准确值相对较小，但在较长的距离中会变得明显。

[缩略图|嵌入[[树](File:ArrowShotInTree.png.md)中的一支箭]]
箭在击中方块后会插在方块上，摇晃7[刻](刻.md)，并开始1分钟的消失计时。箭的飞行距离与入射角度决定箭射入物体的深度。当箭射中方块的侧面时，箭尾会相比预计轨迹更翘起一些。这可能会导致箭横穿两个方块，并激活位于其上方的开关，或阻挡位于其上方的[铁轨](铁轨.md)。

射到[铁轨](铁轨.md)上的箭会阻止矿车前进，直至箭消失或被回收。

若箭所射入的方块的碰撞模型发生了变化（如开启或关闭[门](门.md)，[树叶](树叶.md)枯萎，挖掘其依附的方块），则箭会回到未插入方块的状态并开始垂直掉落。

插在方块上的箭会开始计时并在后消失，再次移动时计时将被重置为0。

# = 着火 =
箭在穿过[火](火.md)或[熔岩](熔岩.md)会[着火](着火.md)，穿过[雨](雨.md)或[水](水.md)时会熄灭。具有[火矢](火矢.md)魔咒的[弓](弓.md)发射的箭在射出时是着火的。栖息状态的[末影龙](末影龙.md)会使其反弹的箭着火。

着火的箭会激活并不受阻碍地穿过[TNT](TNT.md)，可以点燃熄灭的[营火](营火.md)，可以破坏其穿过的[细雪](细雪.md)。

着火的箭命中实体可以使其着火。

# = 命中实体 =
箭可以命中[实体](实体.md)，造成伤害、击退、着火或状态效果。

[末影人](末影人.md)、外壳关闭的[潜影贝](潜影贝.md)、栖息状态的[末影龙](末影龙.md)、生命值或的[凋灵](凋灵.md)、处于[创造模式](创造模式.md)的[玩家](玩家.md)、不能被箭命中，箭会被这些实体弹开并失去速度落到地面上。

[旋风人](旋风人.md)不能被箭命中，且箭会减速并朝发射者的方向重新射出。

具有[冲击](冲击.md)魔咒的弓射出的箭能造成更强的[击退](伤害#击退.md)。

箭默认仅能命中1个实体，具有[穿透](穿透.md)魔咒的弩或可以使发射的箭可以命中的实体数量增加，可命中实体数量至少为2的箭会穿过命中的实体并使自身此数值-1，此数值为1或不存在时，命中实体的箭会消失。

举[盾牌](盾牌.md)的玩家可以反弹在有效角度内来袭的箭。剩余可命中实体数量至少为2的箭无法被盾牌阻挡。

# == 造成伤害 ==

箭对实体造成[弹射物伤害](弹射物伤害.md)，可以被[弹射物保护](弹射物保护.md)魔咒防护。箭造成的伤害受到诸多因素的影响，其伤害值会在极大的范围内浮动。

被箭射中的[船](船.md)、[矿车](矿车.md)、[物品展示框](物品展示框.md)、[画](画.md)、[末地水晶](末地水晶.md)等实体会被破坏。

# == 造成着火 ==

被着火的箭命中的实体，其剩余着火时间会被设置为100，最终增燃烧时间会正常受[火焰保护](火焰保护.md)魔咒的影响。

# = 玩家 =

[缩略图|身上插着箭的两名玩家](File:WeGotShot.png.md)

玩家被箭射中时，箭会插在玩家身上，外观总是为普通箭的纹理。<ref></ref>被插中的位置与被箭射中的位置无关，而是由实体编号作为种子随机出现的视觉效果。

由玩家使用弓或弩发射的箭在命中其他玩家时，发射者会听到一个高音调的“叮”的声音。

# = 与方块交互 =
箭可以触发其击中的[标靶](标靶.md)，可以敲响[钟](钟.md)。

箭可以激活[木质按钮](木质按钮.md)、[木质压力板](木质压力板.md)以及[绊线](绊线.md)。当箭穿过这些方块时，这些开关会保持开启状态。如果箭因为命中了方块而停止运动，那么被箭钉住的开关一直会保持激活状态，直至箭消失或被回收。其他开关则不受箭的影响。由于这些方块不具有[碰撞箱](碰撞箱.md)，箭无法插在这些方块上，但可以插在临近的方块上来保持与开关相交，甚至同时激活多个开关。

# = 回收 =
箭的实体数据<code>pickup</code>控制箭会如何被回收。

* 由骷髅、凋灵骷髅、流浪者、沼骸、[焦骸](焦骸.md)、、掠夺者、猪灵发射的箭无法被回收。<ref></ref>
* 玩家使用具有无限魔咒的弓射出的普通箭，以及创造模式玩家射出的箭不能被生存模式的玩家回收。创造模式的玩家可以回收这些箭，但不会增加物品栏内箭的数量。
* 由发射器发射的箭，由[生存模式](生存模式.md)下的玩家使用不具有无限魔咒的弓发射的箭，以及玩家使用弩发射的不由多重射击魔咒增加的箭可以被回收。

箭只有在扎进了方块且停止了摇晃之后才可以被回收，飞行中的箭接触实体会命中或被弹开，而不能被回收。

在Java版中，可以回收的箭在玩家靠近后，则会飞向玩家并进入其物品栏，就像拾取[物品](物品（实体）.md)一样。若玩家物品栏装不下对应物品，则该玩家只能在处于创造模式时回收，并且不会增加物品栏内箭的数量。在基岩版中，可回收的箭会在接触玩家碰撞箱后消失并相应在物品栏增加物品形式的箭。

扎在玩家上的箭不能被回收，玩家在死亡时也不会掉落他们身上扎着的箭。

在Java版中，由玩家使用带有多重射击附魔的弩散射的箭无法被生存模式的玩家回收。在基岩版中，玩家靠近由多重射击的弩散射的箭后，箭会播放回收动画，但不会增加物品栏内箭的数量。

# 箭伤害
# = Java版 =
箭的基础伤害为2。

由骷髅、流浪者、沼骸、[焦骸](焦骸.md)、凋灵骷髅发射的箭，基础伤害增加<math>0.11r+m</math>，其中<math>r</math>在简单、普通、困难难度分别为1、2、3，<math>m</math>为中位数为0、上下偏差为0.57425的[三角分布](wzh:三角形分布.md)随机数。

由具有[力量](力量（魔咒）.md)魔咒的弓射出的箭，基础伤害增加<math>0.5+0.5p</math>，其中<math>p</math>为力量魔咒等级。箭在发射时，其基础伤害就已经计算完毕。

箭造成的伤害为<math>\mathrm{ceil}(v d)</math>，其中<math>d</math>为基础伤害，<math>v</math>为击中时的速度（单位为米每游戏刻），<math>\mathrm{ceil}</math>为向上取整函数。

玩家使用弓在满弦时发射的箭和弩发射的箭是“暴击箭”，箭造成的伤害额外增加<math>0</math>至<math>\mathrm{floor}(0.5d)+1</math>之间的均匀分布随机整数，其中<math>d</math>为速度修正前伤害，<math>\mathrm{floor}</math>为向下取整函数。

箭最终造成的伤害不能超过2,147,483,647（ × 1,073,741,823.5）。至此伤害值计算完毕，并对实体产生伤害事件。

# = 基岩版 =
箭击中实体时，取基础伤害区间内的均匀分布随机数作为基础伤害，根据发射者种类，该区间有所不同：
* 玩家发射的箭为1。
* 掠夺者发射的箭为3–6。
* 其他生物在简单和普通难度发射的箭为1–4，在困难难度发射的箭为1–5。

由具有[力量](力量（魔咒）.md)魔咒的弓射出的箭，伤害变为<math>1.25d+0.25pd</math>，其中<math>d</math>为修正前伤害，<math>p</math>为力量魔咒等级。

如果箭是玩家发射的，那么伤害变为<math>d+0.11r+0.25m+0.97v</math>，其中<math>d</math>为基础伤害，<math>r</math>在简单、普通、困难难度分别为1、2、3，<math>m</math>为N(0,1)的[Marsaglia极化高斯](wikipedia:Marsaglia polar method.md)随机数，<math>v</math>为击中时的速度（单位为米每游戏刻）<!--，<math>f</math>对于玩家箭和非玩家箭分别为0.97和2.0-->。

玩家使用弓在满弦时发射的箭和弩发射的箭是“暴击箭”，伤害变为<math>\max\left\{9, \min\left\{10, d+0.5dr+2r\right\}\right\}</math>，其中<math>d</math>为修正前伤害，<math>r</math>为0–1的均匀分布随机数。

箭最终造成的伤害不能超过2,147,483,647（ × 1,073,741,823.5）。至此伤害值计算完毕，并对实体产生伤害事件。

# 你知道吗
* 若箭射入一个有着多种状态的方块，在方块更新时箭会脱离一瞬，导致其稍微移动一点，刷新消失倒计时。
* 在默认情况下，拉弓所射箭矢的生成位置会稍微靠向玩家的主手。若玩家抵住墙壁，在准星不动的时候射箭，会发现箭会集中在准星的右方。但如果玩家在选项中将主手设为左手，那么弓箭产生的位置就会稍微靠左。
* 箭矢实体的实际朝向与模型的旋转角度在数值上为相反数关系。
