# Java版Alpha服务器0.2.6

*页面ID: 45544* | *来源: Minecraft Wiki*

* *0.2.6**是一个[Alpha](Java版Alpha.md)服务器版本。此版本是由于协议更改而进行的一次强制更新，发布于2010年11月30日。<ref></ref>

# 更改
* 添加了正确的生物和玩家受伤的动画和音效。
* 修复了死亡玩家登录时不可见的漏洞。
* 服务器日志现在是向<code>server.log</code>文件末尾追加内容，而不是覆盖它。
* 加入服务器屏幕现在可以记住最后加入的IP。
* 在服务器上增加了区块保存的频率。
* 退出潜行模式不会再触发很多声音。
* 潜行玩家现在是隐形的。
* 潜行玩家的名牌不能透过墙看见，并且名牌的可见距离也缩短了。
