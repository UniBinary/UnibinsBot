# Java版1.7.6-pre1

*页面ID: 33610* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.7.6-pre1**是[Java版1.7.6](Java版1.7.6.md)的首个预发布版，发布于2014年4月3日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *[服务器](服务器.md)<!-- 这段内容在ops.json和usercache.json页面写好之后需要添加链接 -->**
* 将[封禁列表](封禁列表存储格式.md)和[白名单](白名单存储格式.md)改用JSON文件格式存储，并更改了存储格式。
* 将改用JSON文件格式存储，并更改了存储格式。
* 在根目录下加入了。

* *[皮肤](皮肤.md)**
* 皮肤和[披风](披风.md)现在通过服务器分发。
* * 皮肤服务器中断发生频率降低，产生的影响减少。<ref></ref><ref></ref>
* * 更换皮肤不再需要重启客户端。在最坏的情况下，也只需重新登录以更新每个人的皮肤。
* * 服务器无法修改皮肤或披风，因为服务端仅保存签署的URL。
* * 相同的皮肤不需要重复下载。
* * 几乎不影响服务器流量。

* *更改名称**
* 支持更改名称。
* * 仅为更名系统提供支持，实际上更名服务会在[Java版1.8](Java版1.8.md)正式版后开放。<ref>https://mojang.com/2014/03/minecraft-snapshot-14w10a/</ref>

* *[选项](选项.md)**
* 服务器[资源包](资源包.md)选项现在是每个服务器的服务器资源包，并且拥有3个选项：询问、启用和禁用。
* FOV设定最低值更改为30。
