# 火焰魔杖

*页面ID: 149836* | *来源: Minecraft Wiki*

* *火焰魔杖（Fire Wand）**是一种可以向前发射[火球](火球.md)或[末影龙火球](末影龙火球.md)的[物品](物品.md)。

# 获取
# = 解锁 =
解锁“[Leaf（树叶）](可解锁项目#fire_wand.md)”后，挑战矿境时会自动获得1个火焰魔杖。

# 用途
火焰魔杖具有[光效](光效.md)。

火焰魔杖会向前方发射[火球](火球.md)，或在解锁“[Dragon Fire（龙焰）](可解锁项目#dragon_fire.md)”后发射[末影龙火球](末影龙火球.md)。使用后冷却。
