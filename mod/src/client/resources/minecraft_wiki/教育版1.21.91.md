# 教育版1.21.91

*页面ID: 129015* | *来源: Minecraft Wiki*

* *1.21.91**是**[追逐云端](追逐云端.md)**的首个正式版，也是的一次次要更新，发布于2025年7月22日<ref></ref>。此次更新加入了[勇气之袋](勇气之袋.md)、[苍园觉醒](苍园觉醒.md)、[春意盎然](春意盎然.md)和[追逐天空](追逐天空.md)的特性。

# 新内容

* 加入了[勇气之袋](勇气之袋.md)、[苍园觉醒](苍园觉醒.md)、[春意盎然](春意盎然.md)和[追逐天空](追逐天空.md)的特性。
* * 不包括[极限模式](极限模式.md)和。

# = 游戏内容 =
* *[旁观模式](旁观模式.md)**
* 正式加入。

# 更改
# = 常规 =
* *[代码构建器](代码构建器.md)**
* Tynker不再是受支持的IDE。
* 加入了用于发送警示的游戏内弹窗。
* 为Microsoft MakeCode加入了读写文件功能。

* *云存储**
* 现在支持更大的世界大小。
* 降低了出现错误的概率，并提高了上传和下载的性能。

* *[多人游戏](多人游戏.md)和代码编写**
* 更新了多人游戏的登录和连接，以提高可靠性。
* 更新了代码基础架构，以提高性能与稳定性。

* *用户界面**
* 更改了[创建新的世界](创建新的世界.md)和编辑世界菜单的UI。
* * 现在能够更轻松地创建世界和修改世界设置。
* * 拆分了教育者设置，以便于用户理解世界配置。
* * 加入了7个[超平坦世界](超平坦世界.md)预设。

* *[皮肤](皮肤.md)**
* 更改了Steve和Alex的默认皮肤。
* 加入了7种新的默认皮肤：Makena、Efe、Noor、Kai、Ari、Sunny和Zuri。

* *常规**
* 现在Windows的exe版本默认为64位。

# 修复
* 优化了性能和游戏稳定性。
