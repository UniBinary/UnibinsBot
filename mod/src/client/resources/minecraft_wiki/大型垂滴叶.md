* *大型垂滴叶（Big Dripleaf）**是一种生成于[繁茂洞穴](繁茂洞穴.md)、能够使处于其上的[实体](实体.md)摔落的植物方块。

# 生成
# = 自然生成 =
大型垂滴叶会自然生成于[繁茂洞穴](繁茂洞穴.md)生物群系的[多叶黏土层](多叶黏土层.md)上。

# = 小型垂滴叶 =
对[小型垂滴叶](小型垂滴叶.md)[骨粉](骨粉.md)可使之成长为2-5格高的大型垂滴叶。若小型垂滴叶上方3格内有方块阻挡，则催成的大型垂滴叶最高只能长到该方块的下方。

# 获取
大型垂滴叶的物品形式只能通过破坏大型垂滴叶获得。

# 破坏
挖掘大型垂滴叶的合适工具是斧和剑。

大型垂滴叶被破坏后会掉落自身。

# 用途
大型垂滴叶只能放置在[黏土](黏土.md)、[苔藓块](苔藓块.md)、[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)和[沾泥的红树根](沾泥的红树根.md)上。

破坏大型垂滴叶的任意部分会导致整个植株被破坏，且每一格会掉落一个大型垂滴叶物品。

# = 倾斜 =
实体（包括生物和掉落物）可以在大型垂滴叶的叶片上停留片刻。若实体在叶片上停留时间超过|short=1}}/|short=1}}，或者叶片被[弹射物](弹射物.md)击中，则该大型垂滴叶的叶片会倾斜，待在其上方的实体也会随之摔落。倾斜后叶片会重新复原。

若玩家待在1格或2格高的大型垂滴叶的所在格，且该大型垂滴叶的叶片正在倾斜，则叶片复原后玩家分别会在叶片下方激活[爬行](爬行.md)和[潜行](潜行.md)。

叶片被弹射物击中时，大型垂滴叶进入下一状态的计时器不会被重置。因此由于实体停留而开始计时的叶片在被弹射物击中而变为<code>full</code>状态后会继续剩余计时，从而使状态在内复原。<ref></ref>

# = 骨粉 =
对着大型垂滴叶[骨粉](骨粉.md)可使其高度增加1。

# = 堆肥 =
将大型垂滴叶放进[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数加1。

# = 红石元件 =

对着大型垂滴叶的叶片施加[红石信号](红石信号.md)可以防止其倾斜，使得大型垂滴叶的方块状态保持在/，红石信号也可以促使倾斜的叶片回升。但被红石信号激活中的大型垂滴叶叶片被弹射物击中时仍会倾斜。对茎部施加红石信号则无效。
