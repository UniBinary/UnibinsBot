# 昼夜更替

*页面ID: 7327* | *来源: Minecraft Wiki*

[right|400px|一个完整的昼夜更替过程](File:Day Night.gif.md)

* *昼夜更替（Daylight Cycle）**是[主世界](主世界.md)中2个主要[亮度](亮度.md)设置的交替过程，周期20分钟。

# 行为

在昼夜更替中，[太阳](太阳.md)和[月亮](月亮.md)围绕着玩家旋转，分别在正午和午夜出现在玩家的正上方。太阳和月亮相对于星星和彼此总是保持在相同的位置。因此，日食不可能出现，而月亮显示的样式取决于经过的夜晚数量。

在单人游戏中，当游戏暂停或时，昼夜更替会暂停；除此之外，只要未关闭，昼夜更替永远不会暂停。

在多人游戏中，只要服务器正在运行且未关闭，昼夜更替就始终会正常进行。

当玩家处于[下界](下界.md)或[末地](末地.md)时，昼夜更替会一直进行，但这些维度本身不会发生改变，直到[主世界](主世界.md)被再次加载。在另一个维度创建的[村庄](村庄.md)若被加载，其中的[村民](村民.md)仍会遵循正常的村庄时间表。

# 24小时制下的Minecraft日

# = 白天 =
[thumb|right|300px|一天的开始](File:Survival.png.md)

白天是一天周期中最长的一节，持续10分钟。

开始：0刻（早上06:00:00.0）

中午：6000刻（下午12:00:00.0）

结束：12000刻（下午06:00:00.0）

玩家在一个[单人游戏](单人游戏.md)中的新世界首次出生时，时间总会处于白天的开始（0:00）。大多数[多人游戏](多人游戏.md)的[服务器](服务器.md)时间也是从这个时间开始，但昼夜更替会持续进行，不会受玩家加入影响。

白天时，[太阳](太阳.md)会逐渐升到蓝天的中央。天空的具体颜色取决于当前所在的[生物群系](生物群系.md)。例如，[沙漠](沙漠.md)的天空比[草原](草原.md)蓝色更淡。

在将近正午的时候，所有直接暴露于天空下的方块均被内部天空光照为最大值15的阳光照射。阳光提供了[树苗](树苗.md)、[草](草方块.md)和[农作物](农作物.md)生长所需的充足阳光。直接暴露在阳光下的大部分[亡灵生物](亡灵生物.md)（不处于阴凉处、水和[细雪](细雪.md)，且不戴[头盔](头盔.md)）开始自燃。另外，阳光会使尚未追逐玩家的[蜘蛛](蜘蛛.md)进入中立状态，使[末影人](末影人.md)靠近玩家时随机传送并保持对玩家的中立。

在白天持续期间，[阳光探测器](阳光探测器.md)的信号输出强度保持最大。

# = 日落 =
[300px|thumb|在地图的高处看到的日落](File:A sunset.png.md)

日落是介于白天和夜晚之间的时间段，持续1.5分钟。

* 开始：12000刻（下午06:00:00.0）
* 中点：12900刻（下午06:54:00.0）
* 结束：13800刻（下午07:48:00.0）

日落时，[太阳](太阳.md)从西边降落，[月亮](月亮.md)从东边升起。下落的太阳附近的天空会有红晕。日落时的太阳看上去还会渐渐变大。

所有直接暴露在天空之下的、未被其他光源照亮的方块，每10秒钟亮度降低1级。

在日落和日出之间的时间段，玩家可以睡在[床](床.md)上。在[单人游戏](单人游戏.md)中，睡觉会直接将昼夜更替快进到日出，且将[天气](天气.md)转为晴朗。多人游戏中也可以实现，只需要所有的在线玩家都睡在床上，或睡在床上玩家的比例达到所设定的值即可。然而，游戏中许多机制中时间并不会随之流逝：比如，农作物不会生长，[熔炉](熔炉.md)中的物品[烧炼](烧炼.md)进度也不会改变。

# = 夜晚 =
[300px|thumb|[[冻原](File:TundraNight.png.md)的夜晚；可以看到多种生物]]

夜晚持续7分钟。

* 开始：13800刻（下午07:48:00.0）
* 午夜：18000刻（早上12:00:00.0）
* 结束：22200刻（早上04:12:00.0）

晴朗的夜晚时，玩家可以在12542刻（下午06:32:31.2）到23459刻（早上05:27:32.4）时睡觉。在雨天，玩家可以在12010刻（下午06:00:36.0）到23991刻（早上05:59:27.6）时睡觉。

亡灵生物不再在12210（下午06:12:36.0）至23791刻（早上05:47:27.6）燃烧。

夜晚时，[月亮](月亮.md)会逐渐升到天空的中央，黑蓝色的天空布满了微小而白亮的[星星](星星.md)。星星会随着月亮移动，日落即将结束的时候会先于月亮出现。

夜晚期间，整个世界被黑暗掩盖，内部天空光照最低降至4，从而使[敌对生物](敌对生物.md)会在地表生成。允许敌对生物生成的精确时间为9625刻。虽然夜晚的亮度低，但农作物仍会生长，除非玩家睡在[床](床.md)上度过夜晚。

# = 日出/黎明 =
[300px|thumb|太阳从地平线上升起](File:Sunrise.png.md)

日出是介于夜晚和白天之间的时间段，持续1.5分钟。

* 开始：22200刻（早上04:12:00.0）
* 中点：23100刻（早上05:06:00.0）
* 结束：24000（0）刻（早上06:00:00.0）

日出时，月亮往西方地平线方向降落，太阳从东方地平线上升起。升起的太阳附近的天空会有红晕。升起的太阳看上去会渐渐变大，但最后会随着高度增加而慢慢缩小至8×8像素。

所有直接暴露在天空之下的方块每隔10秒亮度增加1。最终，阳光的威力再一次展现，大部分怪物的威胁被驱除。

日出的曙光开始于22009刻（04:00:32）。精确的停止刷怪时间为或，雨天则推迟至23031刻（05:01:08）。<ref group="注" name="redstone-before-spawn">测量值来源于敌对生物生成周期状态变化前最后一次执行的[命令](命令.md)的时间戳。在[雷暴](雷暴.md)的持续时间内，敌对生物可在一天的任何时刻生成。</ref>

# 时钟

[时钟](时钟.md)可使玩家获知Minecraft时间。玩家在地下作业、看不到昼夜更替现象的情况时，时钟会发挥很大作用。它能避免玩家不小心在夜晚返回地面而成为敌对生物的猎物。

[下界](下界.md)和[末地](末地.md)没有昼夜更替，时钟只能随机地旋转，不能发挥其作用。

# 命令

可以使用命令修改时间。要启用或禁用昼夜更替机制，可使用命令调整游戏规则。

# = 设置时间 =
可用命令将时间设置为特定值。

  语法：<code>-{}-**/time** set <*时间值* | day | noon | night | midnight></code>

示例：

   - 将时间设为日出。
   - 将时间设为白日（/）。
   - 将时间设为中午。
   - 将时间设为日落。
   - 将时间设为夜晚（/）。
   - 将时间设为午夜（/）。
   - 将时间设为午夜。

# = 月相 =
游戏中每过一天，时间计数便会增加24000刻。虽然每天的交替是一样的，但[月亮](月亮.md)会经历8种月相。虽然没有命令直接更改月相，但命令可以快进至下一个月相。进一步而言，使用以下命令可以直接指定不同的月相：

  或 - 满月
   - 亏凸月
   - 下弦月
   - 残月
   - 新月
   - 娥眉月
   - 上弦月
    - 盈凸月

# 你知道吗
* [主世界](主世界.md)的昼夜更替在玩家处于[下界](下界.md)或[末地](末地.md)时也会继续，不过产生的变化只会在重新加载主世界后才会发生。下界和末地中[村民](村民.md)的行为也会受时间影响。
* 背景[音乐](音乐.md)会在昼夜更替中特定的时间响起。
[thumb|right|时间溢出后会被重置](File:Time reset after overflowing BE.gif.md)
* 命令能设置的最大时间值为2,147,483,647（2<sup>31</sup> - 1），这也是中时间的极限；使用NBT编辑器可达的最大时间值为9,223,372,036,854,775,807（2<sup>63</sup> - 1）。
* * 时间超过最大值后，因数据溢出，昼夜更替无法正常继续，而会使时间倒退回或。
* ** -2,147,483,648（-2<sup>31</sup>）也是命令能够设置的最小时间值。小于该值时，游戏时间会变回最大值。
* * 在游戏中正常达到这两个时刻需要很长时间：
* ** 上述提到的2,147,483,647值在游戏中相当于：天数 = 89,478；当天刻 = 11,467；相当于现实时间的 [年/月/日（时:分:秒:毫秒）] = 1581/12/25（11:28:58:800）（考虑闰年导致的8天6小时修正），不考虑闰年则为 1582/1/1（17:28:58:800）。要达到此值，现实流逝时间约为1,242天18小时。
* ** 上述提到的9,223,372,036,854,775,807相当于游戏中的384,307,168,202,282天，大约10,522亿年。要达到此值，现实流逝时间约为21亿年。
* 当游戏时间为-2,147,483,648至-24,000，且游戏规则<code>[showDaysPlayed](游戏规则/showDaysPlayed.md)</code>为<code>true</code>时，游玩的天数会显示为“”。
