# 不祥之瓶

</ref>||Duncan Geere Mojavatar.png}}

* *不祥之瓶（Ominous Bottle）**是一种可以给予玩家[不祥之兆](不祥之兆.md)状态效果的物品。

# 获取
# = 生物掉落物 =
不在（包含脫離）[袭击](袭击.md)中的[掠夺者](掠夺者.md)和作为[袭击队长](袭击队长.md)被杀死后会掉落I-V级的不祥之瓶，每种等级概率相同。

# = 箱子战利品 =

# 用途

玩家此物品后会获得1小时40分钟的[不祥之兆](不祥之兆.md)状态效果，从而触发不祥事件。

尽管有类似[玻璃瓶](玻璃瓶.md)的外观，不祥之瓶被消耗后不会留下玻璃瓶。
