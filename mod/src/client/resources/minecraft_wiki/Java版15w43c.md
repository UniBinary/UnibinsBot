# Java版15w43c

*页面ID: 18721* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w43c**是[Java版1.9](Java版1.9.md)的第36个快照，发布于2015年10月23日<ref></ref>，对战利品表系统做出了修改，也修复了一些漏洞和崩溃。

# 更改
# = 生物 =
* *常规**
* 修复了生物不会掉落自身携带物的漏洞。

* *[猪](猪.md)**
* 装备了鞍的[猪](猪.md)会重新掉落鞍了。

* *[末影人](末影人.md)**
* 现在会重新掉落它捡起的方块。

# = 非生物实体 =
* *[船](船.md)**
* 重新绘制了船的纹理。现在船两边的桨都拥有了自己的[纹理](纹理包.md)。

# = 世界生成 =
* *[雪屋](雪屋.md)**
* [酿造台](酿造台.md)里的[玻璃瓶](玻璃瓶.md)被移除了。
* [蜘蛛网](蜘蛛网.md)可以在地下室的角落里被找到。
* [雪屋](雪屋.md)的地下室里的[告示牌](告示牌.md)内容被更改了。<ref>https://www.reddit.com/r/Minecraft/comments/3px30m/snapshot_14w43c/cwa5z2n</ref>

# = 游戏内容 =
* *[钓鱼](钓鱼.md)**
* [饵钓](饵钓.md)魔咒不再影响到钓起的物品，只影响钓鱼等待时间。
* [海之眷顾](海之眷顾.md)魔咒因新的钓鱼战利品表的输入错误而失效。
* 钓上垃圾会损耗得更轻（0%–90%的耐久剩余）而宝藏会损耗得更严重（0%–25%的耐久剩余）。
* [墨囊](墨囊.md)会以10的权重钓起（之前是一组10个，每个权重为1）。

# = 常规 =
* *[战利品表](战利品表.md)**
* 现在更新了，所以取代'items'节点包含'item'入口点，现在是一个'entries'节点包含'type'和'name'入口点。
* * 类型入口点可以是'item'，'loot_table'或'empty'。
* * 名称入口点既可以是物品的标识符也可以是战利品表的位置与名称。
* ** 例子:
  :::<code>"type": "loot_table",</code>
  :::<code>"name": "minecraft:gameplay/fishing/treasure",</code>
  * 这使得嵌套战利品表变得更加容易。
* [钓鱼](钓鱼.md)物品表现在可以使用了, 以及骷髅[马](马.md)，僵尸[马](马.md)和无毛[绵羊](绵羊.md)。
* 增加了 'set_damage', 用来改变[工具](工具.md)的耐久度。
* 调整了一些战利品表。
* * [守卫者](守卫者.md)和[远古守卫者](远古守卫者.md)再次拥有了稀有掉落：[鱼](鱼.md)。
* * [远古守卫者](远古守卫者.md)只有在被[玩家](玩家.md)杀死的时候才掉落[海绵](海绵.md)。
* * [马](马.md)再次掉落[皮革](皮革.md)了。骷髅[马](马.md)和僵尸[马](马.md)分别掉落1个[骨头](骨头.md)和1个[腐肉](腐肉.md)。
* * [鱿鱼](鱿鱼.md)再次掉落1-3个[墨囊](墨囊.md)（在[15w43b](15w43b.md)变成0-2个）。
* * 凋灵[骷髅](骷髅.md)关于[煤](煤.md)的掉落恢复到原有机制:掉落 −1–1（也就是66%的概率是0，33%的概率是1）且数量通过[抢夺](抢夺.md)依旧会提升。
* * [蜘蛛](蜘蛛.md)与[洞穴蜘蛛](洞穴蜘蛛.md)关于[蜘蛛眼](蜘蛛眼.md)的掉落进行了调整，现在掉落 −1–1（66%的概率是0，33%的概率是1）且数量通过[抢夺](抢夺.md)依旧会提升。
* * 穿着装备的[生物](生物.md)会掉落装备。
* * 有[鞍](鞍.md)的[猪](猪.md)会掉落[鞍](鞍.md)。
* * [末影人](末影人.md)会掉落拿着的方块。
