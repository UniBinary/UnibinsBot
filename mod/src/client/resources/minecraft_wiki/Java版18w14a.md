# Java版18w14a

*页面ID: 34137* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w14a**是[Java版1.13](Java版1.13.md)的第29个快照，发布于2018年4月4日<ref></ref>，加入了幻翼膜、缓降效果、缓降药水以及缓降之箭，此外还加入了新的进度，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[幻翼膜](幻翼膜.md)**
* 由[幻翼](幻翼.md)掉落。
* 用于修复[鞘翅](鞘翅.md)。
* 可用于合成缓降药水。

* *[缓降药水](药水#缓降药水.md)**
* 用幻翼膜酿造。
* 给予玩家缓降状态效果，持续1:30。
* 可以通过红石酿造延长至3:30。

* *[缓降之箭](缓降之箭.md)**
* 给予玩家缓降状态效果。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
* 缓降
* * 使玩家坠落速率显著降低，落地时也不承受伤害。
* ** 使玩家可以跳跃地更远。
* ** 若玩家在水下疾跑时有此效果，玩家可以跳过5.5个方块的空隙，而普通疾跑只有4格。

# = 常规 =
* *[进度](进度.md)**
* 加入了4项[进度](进度.md)。
* * 腥味十足的生意：钓到一条鱼。
* * 战术性钓鱼：不用钓鱼竿抓住一条鱼！
* * 抖包袱：往什么东西扔出三叉戟。
* * 魔女审判：雷击一名村民。

# 更改
# = 方块 =
* *[海带](海带.md)**
* 更新了纹理。
* 不再生成于暖水海洋里。

* *[海草](海草.md)**
* 现在可以生成于河流和沼泽里。

# = 物品 =
* *[鞘翅](鞘翅.md)**
* 鞘翅现在需要幻翼膜而不是皮革来修补。

# = 生物 =
* *[幻翼](幻翼.md)**
* 幻翼现在掉落幻翼膜而不是[皮革](皮革.md)。

# = 游戏内容 =
* *云**
* 更多地优化云的渲染。

* *[魔咒](魔咒.md)**
* [激流](激流.md)魔咒
* * 与[忠诚](忠诚.md)或[引雷](引雷.md)排斥。
* * 激流不会使三叉戟扔出，而是会将玩家连同三叉戟向前推进。
