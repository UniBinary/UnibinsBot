# 眼眸花

*页面ID: 128242* | *来源: Minecraft Wiki*

* *眼眸花（Eyeblossom）**是一类[小型花](小型花.md)，有**闭合的眼眸花（Closed Eyeblossom）**和**张开的眼眸花（Open Eyeblossom）**两种。

# 生成

张开的眼眸花与闭合的眼眸花可以互相转化。（见）。

# = 自然生成 =
张开的眼眸花不会生成在世界中。

闭合的眼眸花会在[苍白之园](苍白之园.md)生物群系自然生成。

# = 骨粉 =
在苍白之园生物群系中对[草方块](草方块.md)[骨粉](骨粉.md)后，闭合的眼眸花有概率代替[矮草丛](矮草丛.md)生成。

对着不[含雪](含雪.md)的眼眸花使用骨粉会出现更多的状态相同的眼眸花，而不会出现草丛。

# 破坏
眼眸花被挖掘时会立刻被破坏。

眼眸花被破坏后会掉落自身。

# 用途

张开的眼眸花的橙色花蕊部分有发亮的纹理，在暗处也清楚可见，但不会影响周围方块的实际[亮度](亮度.md)。

# = 蜜蜂 =

蜜蜂对张开的眼眸花采粉时会获得[中毒](中毒.md)效果，且不会尝试接触闭合的眼眸花。

玩家无法对蜜蜂闭合的眼眸花，对蜜蜂张开的眼眸花会使其获得[中毒](中毒.md)效果，而非繁殖或加速生长。

# = 转化 =
接收到[随机刻](随机刻.md)或[计划刻](计划刻.md)时，张开的眼眸花在一天的第23400至次日第12600刻之间时会转化为闭合的眼眸花，闭合的眼眸花在一天的第12600至23400刻之间时会转化为张开的眼眸花。在无[昼夜更替](昼夜更替.md)的维度中，眼眸花不会转化。

眼眸花转化时会产生向上飘动的[粒子](粒子#trail.md)，播放转化[音效](#音效.md)，并向以自身为中心7×5×7格范围内的眼眸花发送<math>\lfloor 5d \rfloor</math>到<math>\lfloor 10d \rfloor</math>后的计划刻，其中<math>d</math>是该方块到正在转化的眼眸花的欧几里得距离。这意味着正在转化的眼眸花可加快其他眼眸花的同向转化。

眼眸花[盆栽](盆栽.md)也会进行同样的转化，但盆栽之间及眼眸花和盆栽之间**不会**发送计划刻加快同向转化。

# = 合成材料 =

# = 谜之炖菜 =

使用闭合的眼眸花合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家7s的[反胃](反胃.md)效果。

使用张开的眼眸花合成或喂食棕色哞菇得到的谜之炖菜会给予玩家/的[失明](失明.md)效果。

# = 堆肥 =
将眼眸花放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。

# = 环境音效 =
张开的眼眸花在放置在[苍白苔藓块](苍白苔藓块.md)上时有概率发出特殊的环境音效。
