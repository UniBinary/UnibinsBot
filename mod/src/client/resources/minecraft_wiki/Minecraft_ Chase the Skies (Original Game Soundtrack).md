# Minecraft: Chase the Skies (Original Game Soundtrack)

*页面ID: 151477* | *来源: Minecraft Wiki*

* **Minecraft: Chase the Skies (Original Game Soundtrack)*（《Minecraft：追逐天空（游戏原声带）》）**是[追逐天空](追逐天空.md)的音乐专辑，也是[Amos Roddy](Amos Roddy.md)为[Minecraft](Minecraft.md)创作的首张专辑。本专辑于2025年5月13日在多平台发布。部分平台上也被称为***Minecraft: Game Drop 2 - 2025 (Original Game Soundtrack)***。

本专辑包含6首乐曲，时长总计21分07秒，包括5首在[主世界](主世界.md)播放的曲目，以及1张[音乐唱片](音乐唱片.md)的曲目。
