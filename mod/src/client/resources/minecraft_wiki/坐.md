# 坐

*页面ID: 45085* | *来源: Minecraft Wiki*

<div style='float:right'></div>
* *坐（Sitting）**是一种在特定情况下由玩家和某些生物使用的游戏机制。

# 机制
# = 人-{}-形生物 =
以下人-{}-形生物在[骑乘](骑乘.md)其他实体时使用坐姿：

# = 狼、鹦鹉和猫 =
[150px|right](File:Sitting Tamed Jellie Cat with Red Collar.png.md)
玩家可以通过对自己驯服的[狼](狼.md)、[鹦鹉](鹦鹉.md)或者[猫](猫.md)按下键来命令其坐下。坐着的狼、鹦鹉或者猫会待在原地，不会主动移动或传送至玩家身边（除非它们受到攻击或它们被迫站起）。

狼、鹦鹉和猫在骑乘时不会使用坐姿。<ref name="MC-93491"></ref>

# = 熊猫 =
[熊猫](熊猫.md)会在捡起[竹子](竹子.md)或[蛋糕](蛋糕.md)的物品形式时坐起来，并开始啃食捡起的物品。

# = 狐狸 =
[150px|right](File:Sitting Fox.png.md)
[狐狸](狐狸.md)找不到可以睡觉的地方时偶尔会主动坐下。然而这只是暂时的，狐狸会在几秒钟内恢复站立。狐狸不会一直坐在矿车内。<ref name="MC-93491"/>

# = 骆驼 =
[骆驼](骆驼.md)和[骆驼尸壳](骆驼尸壳.md)在未被骑乘时有时会坐下，歇息十几秒后再缓慢站起。
