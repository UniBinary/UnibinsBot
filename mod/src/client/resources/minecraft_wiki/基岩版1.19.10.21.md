# 基岩版1.19.10.21

*页面ID: 96555* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.10.21**（Android）、**Preview 1.19.10.21**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.10](基岩版1.19.10.md)的第2个测试版，发布于2022年6月1日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 加入了关于甜浆果丛的死亡消息：
* * “<玩家> 被甜浆果灌木丛刺死了”

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了下列闪烁标语：
* * You are valid!
* * I'm glad you're here!
* * You are welcome here!
* * Your gender is valid!
* * Contains infinite genders!

# 更改
# = 方块 =
* *[幽匿感测体](幽匿感测体.md)**
* 现在能够检测更多种类的振动以同步：
* * 打开或关闭[运输船](运输船.md)；
* * 玩家饮用[奶](奶.md)；
* * 使用[铁桶](铁桶.md)收集[细雪](细雪.md)；
* * 在细雪或[蜘蛛网](蜘蛛网.md)中行走；
* * 给[盔甲架](盔甲架.md)装备物品。

* *[红树根](红树根.md)**
* 现在使用[斧](斧.md)再次可以加速挖掘。

* *[沾泥的红树根](沾泥的红树根.md)**
* 现在合适挖掘工具是[锹](锹.md)。

* *[甜浆果丛](甜浆果丛.md)**
* 现在可以种植在[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)或[缠根泥土](缠根泥土.md)上。

# = 生物 =
* *[村民](村民.md)**
* 现在会远离[僵尸疣猪兽](僵尸疣猪兽.md)。

* *[流浪商人](流浪商人.md)**
* 现在会远离僵尸疣猪兽。
* 现在会在白天饮用奶以消除[隐身](隐身.md)效果。

* *[监守者](监守者.md)**
* 监守者的远程攻击现在会无视可减伤的魔咒（如[保护](保护.md)）。

# = 世界生成 =
* *[远古城市](远古城市.md)**
* 更新了结构以匹配。

# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 现在也会在死亡界面中显示。

# = 常规 =
* *[死亡界面](死亡界面.md)**
* 更改了死亡界面以近似匹配。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“旁观模式”、“即将推出的创作者功能”和“应用测试框架”子选项后才可使用。

# = 常规 =
* *[旁观模式](旁观模式.md)**
* 现在旁观模式玩家无法通过游戏内容来获得状态效果。
* 现在拥有[不祥之兆](不祥之兆.md)效果的旁观模式玩家进入[村庄](村庄.md)时不会触发[袭击](袭击.md)。

# = 技术性 =
* *活动对象属性**
* 现在跨多个客户端与实体的活动对象属性会正确地保存和加载。

* *GameTest框架**
* 命令现在包含原生API对其追踪的调用堆栈进行调用。

# 修复
* *幽匿感测体**
* 现在无论振动从何方传播，幽匿感测体都会以相同的方式被羊毛阻断检测。（）
* 幽匿感测体不再能够检测玩家放置地毯、破坏地毯、在地毯上行走和摔落在地毯上产生的振动。（）
* 幽匿感测体不再能够检测物品形式的羊毛或地毯碰到地面产生的振动。（）
* 幽匿感测体现在会保留其通过保存或加载来做出反应的振动的相关信息。
* 幽匿感测体现在能够检测打开或关闭运输船的箱子产生的振动。（）
* 现在幽匿感测体检测到流体被放置和被收集时，其会分别发出强度为12和13的红石信号。
* 幽匿感测体现在能够检测玩家饮用奶产生的振动。
* 幽匿感测体现在能够检测使用桶收集细雪产生的振动。（）
* 幽匿感测体不再能够检测实体在覆有幽匿脉络的羊毛上跳跃产生的振动。
* 幽匿感测体不再能够检测实体站在脚手架上产生的振动。（）
* 幽匿感测体现在能够检测实体在细雪或蜘蛛网中行走产生的振动。（）
* 幽匿感测体现在能够检测给盔甲架装备物品产生的振动。
* 幽匿感测体不再能够检测生物在生成时装备任何自身物品产生的振动。

* *幽匿尖啸体**
* 幽匿尖啸体现在会保留其通过保存或加载来做出反应的振动的相关信息。
* 幽匿尖啸体不再能够在水下生成监守者。（）

* *监守者**
* 监守者现在可以生成在更多种类的非完整方块上，如上半台阶、红石粉、雪层、按钮和绊线。（）
* * 由于限制，目前无法在特定种类的方块上生成，如树叶和高度较低的台阶。
* 监守者现在会保留其通过保存或加载来做出反应的振动的相关信息。
* 监守者的远程攻击现在会无视如保护魔咒等魔法伤害减免。（）

* *悦灵**
* 悦灵现在会保留其通过保存或加载来做出反应的振动的相关信息。

* *红树胎生苗**
* 红树胎生苗现在使用草的音效。
* 红树胎生苗不再会被流动的水破坏。（）

* *深暗之域**
* 现在远古城市中的营地结构会正确生成。（）
* 现在幽匿脉络地物可以和幽匿斑块地物生成在相同高度的空间范围内。（）

* *方块**
* 使用剪刀开采红树树叶后不再会将红树树叶放入不同的物品堆叠中。（）
* 现在去皮红树原木可以合成为去皮红树木而不是普通紅樹林木塊。（）
* 现在红树胎生苗被放入花盆中时其会正确渲染。（）
* 甜浆果丛现在可以种植在泥巴、沾泥的红树根或缠根泥土上。（）

* *游戏内容**
* 现在将金质或铁质工具熔炼为金粒或铁粒后会获得经验。（）
* 修复了灵魂营火使用错误标签导致特定的营火合成配方无法正常运作的漏洞。（）
* 修复了导入由原主机版游戏转换而来的世界时，其中的实体会消失不见的问题。
* 实体传送至未加载区块时不再会将它们删除。
* 钓鱼竿浮标穿过能够切换维度的传送门时不再会导致游戏崩溃。（）
* 修复了玩家在游泳时死亡后不会重置其碰撞箱的漏洞。（）
* 修复了生命提升提供的额外生命值不会被保留的问题。（）
* 现在可以使用红树木板、绯红木板或诡异木板来修复木质工具。（）

* *角色创建器**
* 进入更衣室时不再会无限加载。
* 修复了表情切换界面中的一些文本，以使文本适应在界面框中。
* 修复了快捷表情列表无法显示重复表情，以及玩家没有事先进入更衣室时快捷表情列表不会正确显示的问题。

* *图形**
* 修复了水下迷雾的传播速度与字段中的指定值不匹配的问题。（）
* 修复了视野适应效果影响时，各个生物群系之间的水下迷雾会过渡不平滑的问题。
* 修复了重载导致DX11发生黑屏现象的RTX世界时设备会损坏的问题。
* 始于负数迷雾的迷雾设置不再会使UI元素被迷雾颜色着色。
* 修复了Nintendo Switch上的地形会在迷雾中闪烁的问题。

* *分屏**
* 修复了分屏模式下的玩家动画系统问题。
* * 修复了其他玩家的弩、三叉戟和盾牌渲染不正确的问题。（）
* * 修复了在床上睡觉时分屏位置渲染不正确的问题。（）
* * 修复了分屏时的鞘翅动画不正确的问题。
* * 修复了第二个玩家使用第一人称视角时附着的拴绳位置不正确的问题。

* *市场**
* 现在Minecoin会被文本转语音读作“Minecoins”。
* 修复了评分的百分比会上增至100%的问题。
* 修复了已下载的皮肤包不会显示信息和按钮的问题。（）

* *村民**
* 村民现在会远离僵尸疣猪兽。（）

* *流浪商人**
* 流浪商人现在会远离僵尸疣猪兽。
* 流浪商人现在会饮用奶以消除其隐身效果。（）

* *凋灵**
* 现在凋灵被玩家攻击时会破坏黑曜石。（）
* 被攻击的凋灵不再会在比预期更短的延迟时间后破坏周围方块。

* *玩家渲染**
* 更改了玩家的实体json文件，以修复手持地图时不会渲染手臂的问题。（）

* *用户界面**
* 在死亡界面中加入了玩家的死亡原因。
* 将Pocket UI下的死亡界面中的主菜单按钮移动至屏幕顶端，以避免在战斗期间错误按下按钮。
* 修复了使用游戏手柄时，“选择”提示会在死亡界面中错误定位的问题。
* 加入了死于甜浆果丛时的正确死亡消息。（）
* 为黄色闪烁标语加入了最小尺寸。
* 修复了经典UI下的物品栏界面中的合成槽上方的“合成”字样不正确的问题。（）
* 现在使用世界模板创建的世界总会禁用成就。
* 修复了玩家点击熔炉、高炉、烟熏炉、附魔台、砂轮、酿造台、铁砧、信标、锻造台、织布机、制图台和切石机界面的深灰色区域时，物品会被错误丢弃的问题。
* 修复了模态框中的部分文本段落没有对齐的问题。（）

* *原版趋同**
* 现在进入下界传送门的活动对象会以相同的相对位置和旋转角度离开传送门。（）
* 现在使用锹挖掘沾泥的红树根最快。（）
* 现在使用斧挖掘红树根最快。（）
* 更新了远古城市的结构以匹配Java版。

* *移动端控制**
* 更新了触摸控制摇杆的视觉样式。

* *性能与稳定性**
* 玩家在多人游戏中切换维度同时离开世界时，游戏不再会崩溃。
* 修复了玩家在凋零效果的影响下死亡时发生的崩溃。

* *技术性**
* 修复了传送命令中的参数会计算得出不正确的垂直朝向的问题。（）
* 加入了行为，允许生物根据指定环境条件来饮用奶。</onlyinclude>
