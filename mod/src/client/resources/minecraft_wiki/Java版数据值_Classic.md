# Java版数据值/Classic

*页面ID: 10175* | *来源: Minecraft Wiki*

[缩略图|右|Classic和Indev中的方块和物品列表](File:DataValuesOld.png.md)以下这些数据值适用于在Minecraft Classic的世界中放下的方块。由于Minecraft Classic之后的版本大量增加了方块的数量，并且移除或重新使用了方块ID，Minecraft Classic拥有自己的列表。带有<span style='color:#00BFFF'>亮蓝色</span>ID的物品无法以正常方式在游戏中在玩家的物品栏中得到。
