# 基岩版1.19.60.22

*页面ID: 100352* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.60.22**（Android）、**Preview 1.19.60.22**（Xbox/Windows）是[基岩版1.19.60](基岩版1.19.60.md)的第2个测试版，发布于2022年12月1日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[设置](设置.md)**
* 重新加入了“”选项。

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 现在发射器可以：
* * 给[猪](猪.md)和已驯服的[马](马.md)、[驴](驴.md)、[骡](骡.md)配鞍；
* * 给已驯服的马配马铠；
* * 给已驯服的[羊驼](羊驼.md)配地毯；
* * 给已驯服的羊驼、驴和骡配箱子；
* * 修剪[哞菇](哞菇.md)；
* * 修剪[雪傀儡](雪傀儡.md)。
* 现在发射器每次只能修剪一只[绵羊](绵羊.md)。

* *[地毯](地毯.md)**
* 现在对已驯服的羊驼按下地毯会直接装备地毯。

# = 物品 =
* *[鞍](鞍.md)**
* 现在对已驯服的马、驴和骡鞍会直接装备鞍。

* *[马铠](马铠.md)**
* 现在对已驯服的马马铠会直接装备马铠。

# = 生物 =
* *[末影人](末影人.md)、[骷髅](骷髅.md)和[凋灵骷髅](凋灵骷髅.md)**
* 现在在[下界](下界.md)中只会生成于亮度为7及以下的位置，以削弱一些基于下界传送门的农场。

* *[猪灵](猪灵.md)**
* 将生成时要求的亮度等级范围重新更改为0-7。

* *[恼鬼](恼鬼.md)**
* 更改了纹理以匹配。

# = 非生物实体 =
* *[经验球](经验球.md)**
* 现在同一方块内的经验球会合并起来，直至到达上限。
* * 不会导致总经验值减少。

# = 技术性 =
* *组件**
* 为过滤器的参数加入了可能值。
* * 用于检查活动对象物品栏中的物品。
* 为组件加入了字段。
* * 设置此字段并完成互动后可以将玩家持有的物品装备到指定的槽位中。
* * 槽位中原有的物品会加入到玩家的物品栏中。
* * 在非创造模式下，被装备的物品会从玩家的物品栏中移除。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”、“即将推出的创作者功能”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[竹块](竹块.md)和[去皮竹块](去皮竹块.md)**
* 更改了纹理，使其光照与其他方块保持一致。
* 现在划分在[创造模式物品栏](创造模式物品栏.md)中的“木头”物品组中，而不是在“原木”物品组中。
* 去皮竹块的英文名称由“Stripped Block of Bamboo”更改为“Block of Stripped Bamboo”。

* *[竹板](竹板.md)和[竹台阶](竹台阶.md)**
* 现在可以在合成配方中代替木板和木质台阶使用。

* *[竹马赛克](竹马赛克.md)和[竹马赛克台阶](竹马赛克台阶.md)**
* 不再可以在合成配方中代替木板和木质台阶使用。

* *[雕纹书架](雕纹书架.md)**
* 现在指向其中的任意槽位时可以向特定槽位中放入书或从特定槽位中取出书。
* 现在可以在手持书的情况下取出书。

* *[发射器](发射器.md)**
* 现在可以给[骆驼](骆驼.md)配鞍。

# = 物品 =
* *[鞍](鞍.md)**
* 现在对骆驼鞍会直接装备鞍。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了嗅探兽刷怪蛋的物品数字ID，为500。

# = 生物 =
* *[嗅探兽](嗅探兽.md)**
* 加入了嗅探兽的实体数字ID，为139。

# = 常规 =
* *[声音](声音.md)**
* “玩家”音效滑块现在可以正确调整玩家在竹质方块、悬挂告示牌、下界木质方块和雕纹书架上的行走音效和掉落音效。
* “方块”音效滑块现在可以正确调整雕纹书架的音效。（）
* 降低了音符盒发出末影龙环境音效时的音量。
* “唱片机/音符盒”音效滑块现在可以正确调整将生物头颅放置在音符盒上方后发出的音效。

# 修复
* *游戏内容**
* 修复了玩家站在被活塞向上推动的方块上时会从中摔落下来的问题。（）
* 修复了最后一名玩家处于下界或末地时会错误地跳过夜晚的问题。
* 现在当所有主世界玩家睡觉时，进入下界或末地的玩家会被无视而直接跳过夜晚。
* 修复了在丢弃物品的同时睡觉会导致服务器被挂起的漏洞。（）
* 现在生成在同一方块内的经验球会合并起来，直至到达上限。（）

* *常规**
* 修复了使用游戏手柄取消选择文本栏后不会重新瞄准的问题。（）
* 修复了成就界面和新的创建新的世界界面上的界面元素不能正确触发音效的问题。（）

* *物品**
* 修复了无法用部分绊线钩与制箭师村民进行交易的问题。（）

* *移动端控制**
* 修复了玩家无法在摇杆和十字准星触摸控制方案下与Toast通知交互的漏洞。

* *生物**
* 修复了恼鬼在黑暗环境下会异常发光的问题。
* 修复了Java版和基岩版的恼鬼纹理不趋同的问题。（）
* 末影人、骷髅和凋灵骷髅现在在下界中只会生成于亮度为7及以下的位置。（）

* *玩家**
* 修复了在玩家死亡并返回菜单后重进游戏导致的碰撞箱与名称不对齐的漏洞。（）

* *触摸控制**
* 现在当玩家使用第二种输入法且悬浮在另一标签页上时，物品栏标签页会重置悬浮状态。

* *原版趋同**
* 现在对已驯服的马、驴和骡按下使用鞍会直接装备鞍。（）
* 现在对已驯服的马、驴和骡按下使用马铠会直接装备马铠。（）
* 现在对已驯服的羊驼按下使用地毯会直接装备地毯。（）
* 现在发射器可以给已驯服的马配鞍和马铠。
* 现在发射器可以给已驯服的驴和骡配鞍和箱子。
* 现在发射器可以给已驯服的羊驼配地毯和箱子。
* 现在发射器可以给猪和炽足兽配鞍。
* 现在发射器每次只能修剪一只绵羊。
* 现在发射器可以修剪哞菇和雪傀儡。

* *流浪商人**
* 流浪商人不再有概率提供重复的种子交易选项。（）

* *用户界面**
* 更改了游玩屏幕、语言设置屏幕、控制设置屏幕的世界列表以及邀请好友屏幕的好友列表项目过多时的文本朗读枚举常量。</onlyinclude>
