# 教育版1.21.50.1

*页面ID: 138203* | *来源: Minecraft Wiki*

<onlyinclude>

* *Preview 1.21.50.1**（Android/ChromeOS/Windows）、**beta 1.21.50.1**（iOS/iPadOS/macOS/Windows）是[教育版1.21.91](教育版1.21.91.md)的第3个开发版本，发布于2024年12月19日<ref></ref>，加入了[苍园觉醒](苍园觉醒.md)的特性。

# 新内容

* 加入了[苍园觉醒](苍园觉醒.md)的特性。

# 更改
# = 常规 =
* *云存储**
* 现在支持更大的世界大小。
* 降低了出现错误的概率，并提高了上传和下载的性能。

* *[多人游戏](多人游戏.md)和代码编写**
* 更新了多人游戏的登录和连接，以提高可靠性。
* 更新了代码基础架构，以提高性能与稳定性。

# 修复
* 优化了性能和游戏稳定性。</onlyinclude>
