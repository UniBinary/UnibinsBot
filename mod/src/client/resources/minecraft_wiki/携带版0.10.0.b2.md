# 携带版0.10.0.b2

*页面ID: 28525* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.10.0 alpha build 2**是[v0.10.0 alpha](携带版0.10.0.md)的第2个测试版，发布于2014年10月23日，修复了一些漏洞。

# 更改
# = 方块 =
* *[树叶](树叶.md)**
* 再次为树叶加入平滑光照。

* *[水](水.md)**
* 使在沼泽水与普通水之间的颜色过渡更平滑。

# = 常规 =
* *渲染**
* “环绕雾”现在变圆了。

# 修复
* *修复了28个漏洞**
* 分屏模式下弓丢失了十字准星。
* 在一些旧型号的GPU（PowerVR SGX535、SGX531、SGX540）上使用精美图像选项导致渲染问题。
* 渲染矿车模型时游戏崩溃。
* 打开存档时游戏崩溃。
* 渲染某些粒子时游戏崩溃。
* 手持某些物品时GUI和生物模型损坏。
* 台阶的某些面的纹理丢失。
* 玩家可以穿过墙看见告示牌的文本。
* 随机光照漏洞。
* TNT被激活时，紧邻的掉落物也会跟着闪烁。
* 掉落物在坠落的过程中会推动玩家。
* 第三人称下摄像机的视线不会无视非固体方块
* 箭会插进非固体方块中。
* 火把会阻止下落的方块继续下落。
* 在夜晚被发现的矿车在底部会出现木质平台。
* 在夜晚，蘑菇会出现在沙漠里。
* 火把出现黑色轮廓。
* 哞菇被挤奶时不消耗碗。
* 坠落到世界底部导致游戏崩溃。
* 床的底部的纹理错误。
* 刷怪笼产生的粒子错误。
* 物品栏内工具的耐久度条渲染错误。
* 暗处的水出现发亮的轮廓。
* 沼泽中睡莲下方的水的透明度错误。
* 紧邻的草方块出现闪烁的纹理。
* 藤蔓的颜色错误。
* 幼年生物不会游泳，且会沉到水底。
* 在水底放置方块会导致水出现错误的颜色。</onlyinclude>
