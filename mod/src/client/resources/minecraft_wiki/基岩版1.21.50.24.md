# 基岩版1.21.50.24

*页面ID: 127421* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.50.24**（ChromeOS/Android）、**Preview 1.21.50.24**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.50](基岩版1.21.50.md)的第3个测试版，发布于2024年10月17日<ref></ref>，调整了一些[苍园觉醒](苍园觉醒.md)的特性，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[粒子](粒子.md)**
* 加入了粒子。

# 更改
# = 方块 =
* *[紫水晶母岩](紫水晶母岩.md)**
* 现在不使用合适工具挖掘时会延长挖掘时间。

* *[钟](钟.md)、[酿造台](酿造台.md)、[合成器](合成器.md)、[末影箱](末影箱.md)、[灯笼](灯笼.md)、[灵魂灯笼](灵魂灯笼.md)、[化合物创建器](化合物创建器.md)、[材料分解器](材料分解器.md)、[元素构造器](元素构造器.md)和[实验台](实验台.md)**
* 不再会在不使用[镐](镐.md)挖掘时延长挖掘时间。

* *[高炉](高炉.md)、[炼药锅](炼药锅.md)、[发射器](发射器.md)、[投掷器](投掷器.md)、[附魔台](附魔台.md)、[熔炉](熔炉.md)、[漏斗](漏斗.md)和[烟熏炉](烟熏炉.md)**
* 现在只会在使用镐挖掘时掉落。

* *[铁门](铁门.md)、[重质测重压力板](重质测重压力板.md)、[轻质测重压力板](轻质测重压力板.md)、[磨制黑石压力板](磨制黑石压力板.md)和[石头压力板](石头压力板.md)**
* 不再需要木镐或品质更好的镐来挖掘，此前若不使用木镐来挖掘则会延长挖掘时间且不会掉落。

* *[嘎枝之心](嘎枝之心.md)**
* 不再可以被[活塞](活塞.md)推拉。
* 不再可以用作[燃料](燃料.md)。

* *[铜门](铜门.md)**
* 不再需要石镐或品质更好的镐来挖掘，此前若不使用石镐来挖掘则会延长挖掘时间且不会掉落。

* *[去皮苍白橡木原木](去皮苍白橡木原木.md)和[去皮苍白橡木](去皮苍白橡木.md)**
* 更改了纹理以匹配。

# = 物品 =
* *[沉重核心](沉重核心.md)**
* 更改了物品纹理。

* *[苍白橡木运输船](苍白橡木运输船.md)和[悬挂式苍白橡木告示牌](悬挂式苍白橡木告示牌.md)**

* 更改了物品纹理，以与其他苍白木质物品保持一致。

# = 世界生成 =
* *[苍白之园](苍白之园.md)**
* 调整了苍白苔藓[斑块](斑块.md)的大小和生成位置。
* * 现在自然生成的苍白苔藓斑块会生成得更大。
* * 现在苍白苔藓斑块有概率在不与[苍白橡树](苍白橡树.md)相邻的情况下自然生成。
* * 现在苍白苔藓斑块上会生成更少的[高草丛](高草丛.md)。
* 增大了苍白橡树的密度以匹配。
* [花](花.md)和[蘑菇](蘑菇.md)不再会生成于此。
* 现在迷雾颜色为。

* *[苍白橡树](苍白橡树.md)**
* 现在由[苍白橡树树苗](苍白橡树树苗.md)长成后，其树干和树叶下方有概率生成苍白垂须。

# 修复
* *苍园觉醒特性**
* 增大了苍白之园中苍白橡树的密度以匹配Java版。（）
* 现在处于苍白之园生物群系时，地平线上的天空会完全是灰色的，而不会有部分蓝色。（）
* 现在去皮苍白橡木原木会显得更亮，以与其他苍白木质方块相匹配。（）
* 现在苍白橡树树苗长成苍白橡树时，苍白橡树上会悬挂苍白垂须，但底部不会生成苍白苔藓斑块。（）
* 苍白橡木告示牌UI的左上角不再会缺失像素。（）
* 调整了苍白橡木告示牌和悬挂式苍白橡木告示牌的物品纹理，以与其他苍白木质物品保持一致。（）
* 调整了苍白橡木运输船的物品纹理，以与其他种类的船保持一致。
* 第三人称视角下的苍白覆地苔藓不再会在玩家手中飘浮。（）
* 现在通过命令清除嘎枝时，绑定嘎枝的嘎枝之心和部分苍白橡树的支持会停止运作。
* 在创造模式下对嘎枝之心使用+时不再会保留其数据。
* 现在嘎枝之心无法被活塞移动。（）
* 现在嘎枝之心生成和清除嘎枝时会在嘎枝所在位置发出振动。

* *辅助功能**
* 修复了iOS平台上与触觉反馈相关的问题。（）

* *方块与物品**
* 现在只有使用镐来挖掘高炉、炼药锅、发射器、投掷器、附魔台、熔炉、漏斗和烟熏炉才能使它们掉落。（）
* 现在使用任何工具破坏所有种类的铜门、铁门、重质测重压力板、轻质测重压力板、磨制黑石压力板和石头压力板这类需要支持的方块时均能使它们掉落。
* 现在使用不合适的工具挖掘紫水晶母岩时会减慢挖掘。
* 现在使用不正确的工具挖掘钟、酿造台、合成器、末影箱、灯笼和灵魂灯笼这类总会掉落的方块时也能较快地挖掘。（）

* *游戏内容**
* 现在当游戏基版本低于1.18.20时，命令和任何大于或等于目标当前生命值的伤害会杀死目标。
* 现在由下界传送门生成的僵尸猪灵会有15秒的使用传送门的冷却时间。

* *图形**
* 具有多种变种的纹理现在会加载PBR纹理数据。（）

* *Realms**
* 加入了一个模态框，会在更改激活的Realms槽位，以防止出现因玩家重按编辑世界按钮而导致推送多个Realms槽位设置屏幕成堆的错误时显示。
* 修复了在Realms槽位中上传或替换世界后不会保留游戏模式和难度的问题。

* *音效**
* 调整了紫水晶类方块的破坏音效、挖掘音效、放置音效、在其上摔落的音效、在其上行走的音效和在其上着陆的音效的音量和音高。

* *用户界面**
* 调整了纸娃娃的位置，以使其不与UI栏相重叠。（）
* 移动设备：进入多窗口或分屏模式时不再会覆盖自定义控制已保存的键位。（）
* 改进了聊天栏和告示牌中泰语字体的渲染。（）
* 为部分方块加入了UI中缺失的快速切换动画。
* 现在移动至玩家光标下的收纳袋会正确更新其提示框。</onlyinclude>
