# 嗅探纹样陶片

*页面ID: 156738* | *来源: Minecraft Wiki*

* *嗅探纹样陶片（Snort Pottery Sherd）**是图案形似[嗅探兽](嗅探兽.md)的[陶片](陶片.md)。

# 获取
# = 考古战利品 =
用[刷子](刷子.md)刷扫[海底废墟](海底废墟.md)里的[可疑的沙子](可疑的沙子.md)有概率掉落嗅探纹样陶片。

# = 饰纹陶罐 =
被不具有[精准采集](精准采集.md)的工具挖掘破坏或被[弹射物](弹射物.md)击毁时，附有嗅探纹样陶片的[饰纹陶罐](饰纹陶罐.md)会掉落嗅探纹样陶片。
