* *月球牛（Moon Cow）**是头戴[玻璃](玻璃.md)的牛，只在[月球](月球.md)维度生成。

# 生成
[thumb|自然生成于[[月球](File:MoonCowGroup.png.md)维度的一群月球牛]]

月球牛会以1-5只为一群自然生成于[月球](月球.md)维度的[芝士](芝士.md)方块表面。

# 行为
月球牛会漫无目的地游荡、哞叫，也会躲开悬崖、[熔岩](熔岩.md)和[火](火.md)以避免受到伤害。与其他友好生物一样，月球牛在受到攻击后会短暂进入受惊状态，四处跑动。

玩家可以直接骑乘月球牛，但无法控制其移动。

# = 繁殖 =
月球牛会跟随10格内手持[小麦](小麦.md)的玩家。

给两只间隔不超过7格的月球牛喂食小麦会使之进入[繁殖](繁殖.md)模式，产下一头[幼年月球牛](繁殖#幼年生物.md)，并给予玩家。繁殖5分钟后才能再次繁殖。幼年月球牛需要20分钟长大。使用小麦可以加快幼年月球牛的生长速度，每次喂食都将会减少幼年月球牛约10%的剩余生长时间。

# = 气球 =
可以给月球牛喂食[空气](空气（23w13a_or_b）.md)，使它们变成气球牛并带着骑乘它们的玩家返回主世界。它们掉落的玻璃瓶允许玩家在用完时制造新的空气。当Y=689时，月球牛会爆炸并给予玩家20秒的[反胃](反胃.md)II和[飘浮](飘浮.md)II。
