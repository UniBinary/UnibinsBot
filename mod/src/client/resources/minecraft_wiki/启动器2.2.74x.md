# 启动器2.2.74x

*页面ID: 74154* | *来源: Minecraft Wiki*

* *2.2.743**（[Windows](wzh:Microsoft Windows.md)与[Dungeons](MCD:启动器.md)）、**2.2.740**（[macOS](wzh:MacOS.md)）或**2.2.741**（[Linux](wzh:Linux.md)）是一次[启动器](启动器.md)更新，发布于2020年11月27日。本次更新加入了对Microsoft账户的支持，以及使用同一启动器游玩[Minecraft：Java版](Java版.md)和[Minecraft Dungeons](Minecraft Dungeons.md)的能力。

# 新内容
* 加入了启动可能不支持最新的游戏内玩家安全功能的Minecraft版本时的警告。
* 将“有Mods”作为过滤器选项加入到了Java版配置页面中。
* 向安全通知弹窗中添加了有关玩家安全功能的网络链接。

# 更改
* 改进了Java版配置页面的搜索区域
* 改进了Minecraft：Java版“开始游戏”页面的布局。
* 更改了Minecraft：Java版“开始游戏”界面的背景图。<!--thanks r/Minecraft for the height fixes discussion that brought this to light-->
* 解决了在“配置”标签页不选择任何配置会导致“开始游戏”页面中所有配置被隐藏的问题。
* 解决了运行游戏时启动器无法打开的问题。
* 解决了默认皮肤在启动器和游戏中不一致的问题。
* 删除了日志窗口中的奇/偶颜色。
* 修复了搜索框中文本重叠的漏洞。
* 修复了帮助区域中与文本长度和屏幕宽度有关的问题。
* 对安装程序中文本的小型更新。

# 修复
*  - useCoreError/index.tsx:84在应该显示“log in”时，使用了术语“login”。
*  - 点击登录页面上的“忘记密码”链接会将用户带到minecraft.net主页。
*  - 若只框选“有Mods”，则装载Mod的版本不会显示。
*  - 关于Mojang账户（电子邮件）的信息在“其他”后缺少一个逗号。
*  - 若不重启启动器，账户列表即使在切换账户后也不会更新。
*  - FAQ/支持中心的链接会将用户定向到help.mojang.com。
*  - 提供反馈：Minecraft Dungeons“帮助”菜单中的链接会将用户带到不存在的页面。
*  - Mojang Support推特账户链接的大小写不正确。
