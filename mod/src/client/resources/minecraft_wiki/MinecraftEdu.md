* *MinecraftEdu**是[Java版](Java版.md)的一个分支，由[TeacherGaming](http://teachergaming.com)开发，[E-Line Media](http://elinemedia.com)发布，并经[Mojang AB](Mojang AB.md)许可。<ref>https://help.mojang.com/customer/en/portal/articles/325947-where-can-i-buy-minecraft-</ref>它是指[Minecraft](Minecraft.md)的教育版本，供课堂使用。

MinecraftEdu最初由TeacherGaming开发。TeacherGaming起初由来自美国和芬兰的3名开发人员和3名老师组成，后来扩展至8人。

MinecraftEdu致力于让[玩家](玩家.md)探索，交互和修改由1立方米大小的[方块](方块.md)组成的动态生成的[地图](主世界.md)。学生应该在老师的帮助下学习各种科目。教师可以更改设置以禁止学生放置/破坏服务器上使所用的[方块](方块.md)和[世界](世界.md)的位置。

2016年1月19日，Mojang宣布将从TeacherGaming收购MinecraftEdu，同时宣布了Minecraft新的教育版本——[教育版](教育版.md)，目前其已在全球范围内投放市场。<ref></ref>

# 购买和可用性
MinecraftEdu需要购买来使用。用户许可证的价格为每位学生18美元（24岁及以下）或14美元（25岁及以上）；服务器许可证41美元，可以一次性购买。购买后，可以通过下载启动器来玩游戏。MinecraftEdu Hosting Beta也可以按每月20美元的价格使用，不需要再次支付服务器软件许可。

# = 硬件需求 =
<ref>http://minecraftedu.com/faq#question_2-13</ref><ref>https://help.mojang.com/customer/portal/articles/325948-minecraft-system-requirements</ref>

最低要求：
* 一台Windows、Mac或Linux电脑（台式机或笔记本）
* 2 GB或更大的RAM
* Intel Pentium D、AMD Athlon或更好的处理器
* 200MB或更多的可用硬盘空间
* Java 6 Release 45或更新（包括Java 7和8）

推荐要求：
* CPU：Intel Core i3或AMD Athlon II (K10) 2.8 GHz
* RAM：4GB
* GPU：GeForce 2xx Series或AMD Radeon HD 5xxx Series（不包括集成芯片组），带有OpenGL 3.3
* HDD：1GB
* 来自java.com的Java 8最新版本

软件要求：
* Minecraft 1.6版或更高版本。较旧的版本需要更新为当前版本
* 请注意，某些用户在使用Minecraft的操作系统（32位或64位）的不匹配版本，使用某些版本的Java 7或安装多个Java版本时会遇到问题。

# = 停止发售 =
从2016年4月5日起，MinecraftEdu将不再销售。但是，已经购买了MinecraftEdu许可证的客户可以继续使用MinecraftEdu。从那时起，MinecraftEdu不再收到TeacherGaming的新更新，并且Mojang将不再支持MinecraftEdu。但是，内置在“MinecraftEdu”中的世界不会移植到[教育版](教育版.md)。<ref></ref>

# 游戏内容
游戏的目标仍然与常规的[Minecraft](Minecraft.md)相同，在那里玩家可以在类似于沙盒的环境中构建虚拟现实。但是，MinecraftEdu的目标还在于教育用途，以教授各种科目。

# = 与常规[Minecraft](Minecraft.md)的不同 =
MinecraftEdu在许多方面与常规版本有所不同，例如教程模式，教师[选项](选项.md)和独占[方块](方块.md)/[物品](物品.md)。

（可以通过按下打开。在较旧的版本中，可以通过按下打开。）

# == 教程世界 ==
* MinecraftEdu附带了一个教程世界，教师可以从服务器菜单中进行选择，它涵盖了控件，放置/破坏[方块](方块.md)，教师选项等的基础知识。

# == [Mods](Mods.md) ==
; [Forge](http://files.minecraftforge.net)
* MinecraftEdu预先打包有[Forge](http://files.minecraftforge.net)，可轻松进行Mod安装。

; [ComputerCraftEdu](http://computercraftedu.com)
* [ComputerCraftEdu](http://computercraftedu.com)与MinecraftEdu预先打包在一起，是TeacherGaming和[Dan200](https://twitter.com/DanTwoHundred)（ComputerCraft的作者）制作的[ComputerCraft](http://www.computercraft.info/)的教育版本，旨在教学生如何在[Minecraft](Minecraft.md)内部进行编码。

# == [皮肤](皮肤.md) ==
* 当没有加入可自定义的[皮肤](皮肤.md)时，学生在首次加入服务器或创建世界时会从MinecraftEdu（除了Steve和Alex）附带的许多默认皮肤中选择其皮肤。
