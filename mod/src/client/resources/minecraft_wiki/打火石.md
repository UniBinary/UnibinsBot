# 用途
# = 点火 =
[thumb|火附近有可燃尽方块时的生成位置](File:Fire position.png.md)

手持打火石对着方块的一面时，[火](火.md)会尝试生成在毗邻该面的方块空间内。若该空间下方的方块顶面完整，火就会生成在这一顶面上。绝大多数完整的上表面都是满足条件的，包括以下方块的上表面：
* 在方块空间上半部分且关闭的[活板门](活板门.md)
* 倒置的[楼梯](楼梯.md)
* 上半[台阶](台阶.md)，包括双台阶
* 8层的[雪](雪.md)

若这一空间与其他[可燃尽的方块](火#烧毁方块.md)（如[木板](木板.md)、[地毯](地毯.md)）相邻，且该空间下方的方块顶面不满足条件，火就会生成在可燃尽方块与这一空间相邻的所有面上。

需要注意的是[蜂蜜块](蜂蜜块.md)上表面不能点燃火，但[黏液块](黏液块.md)可以。

对着[灵魂沙](灵魂沙.md)和[灵魂土](灵魂土.md)的上表面使用打火石则会生成[灵魂火](灵魂火.md)。

在[下界传送门](下界传送门.md)的框架内点着火可以激活下界传送门。

对[TNT](TNT.md)、<ref></ref>或[苦力怕](苦力怕.md)使用打火石会引爆它们。

对熄灭的[营火](营火.md)、[蜡烛](蜡烛.md)或[插上蜡烛的蛋糕](插上蜡烛的蛋糕.md)使用打火石可以点燃它们。

使用打火石成功点火后会消耗1点耐久度，每个无[耐久](耐久.md)魔咒的打火石可使用/。使用打火石后未成功生火仍会消耗打火石耐久度。

# = 挖掘工具 =

打火石是一种挖掘工具，每次成功挖掘了任何硬度不为0的方块会消耗2耐久度。<ref></ref>

# 你知道吗
* [冒险模式](冒险模式.md)的玩家不能用打火石点火，也不能激活[下界传送门](下界传送门.md)（除非使用[物品堆叠组件](物品堆叠组件.md)<code>can_place_on</code>指定其可放置在[黑曜石](黑曜石.md)上），但仍可以引爆[TNT](TNT.md)和[苦力怕](苦力怕.md)。
* 打火石点出的火在下雨时会立即熄灭。<ref></ref>
