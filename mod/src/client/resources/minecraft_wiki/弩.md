# 弩

*页面ID: 36784* | *来源: Minecraft Wiki*

* *弩（Crossbow）**是一种可以装填和发射[箭](箭.md)、[药箭](药箭.md)、[烟花火箭](烟花火箭.md)的远程[武器](武器.md)。

# = 武器 =
长按可以拉弦进行装填。要使用弩，需要[箭](箭.md)或处于副手中的[烟花火箭](烟花火箭.md)，或者自身处于创造模式。在拉弦时，玩家只能以潜行的速度移动，若玩家正骑着[马](马.md)、坐在[矿车](矿车.md)或者[船](船.md)里，则拉弦不会使移动速度下降。玩家必须最终松开才能完成装填。

完成弩的装填需要1.25秒的拉弦，具有[快速装填](快速装填.md)魔咒时每魔咒等级将这一时间减少0.25秒。弩在装填完毕后，纹理上才会显示出一支箭或烟花火箭，且在弩上的非烟花火箭装填物总是显示为普通的箭。<ref></ref>与弓不同，弩只有完成了装填后，在装填物出现在了纹理上之后才能进行射击。完成装填后，玩家持有装填的弩时可以正常速度移动，且弩可以被移动到任何地方而保持装填物的装填状态。

装填完成后，再次按就能无延迟地立即打出攻击，这允许玩家同时持有多把弩时通过频繁切换弩来倾泻出大量的箭或烟花火箭。

使用非烟花火箭填充物时每次消耗1点耐久度，使用烟花火箭时每次消耗3点耐久度。[多重射击](多重射击.md)魔咒会使弩一次被装入3个物品，并产生3倍[耐久度](耐久度.md)消耗，但只会消耗1个物品。弩在发射时会消耗耐久度。

尽管[末影人](末影人.md)不会被箭击中，但烟花火箭造成的范围伤害可以伤害末影人。

弩按照以下顺序选择要装填的物品：
* 快捷栏中被选中的箭或烟花火箭（副手持弩时）
* 副手中的箭或烟花火箭
* 快捷栏中最左侧的箭
* 物品栏中距离0槽位最近的箭（从最左上角向右逐行搜索）

烟花火箭必须放置在副手中或在快捷栏中被选中才可以装填进弩中。

创造模式玩家会填充带有<code>intangible_projectile</code>组件的弹射物，多重射击魔咒会额外在弩的<code>charged_projectiles</code>组件中加入两项带有<code>intangible_projectile</code>组件的相同弹射物，它们被发射后只能被创造模式玩家拾起。

尽管多重射击只能让弩同时装填3个物品，但通过修改<code>charged_projectiles</code>组件可让弩同时装填更多不同类型的物品。除了烟花火箭以外的装填物都会使弩显示箭的纹理且在提示框中显示“弹射物：*<此装填物>*”，若此物品数量大于1还会显示数量。发射装填物后会生成对应数量的带有对应<code>item</code>标签的箭，拾起这些箭会获得其<code>item</code>标签对应的物品。

# = 箭 =

弩可以发射箭以造成伤害。弩发射的箭均为暴击箭。弩发射的箭的速度在随机散射修正前为63m/s。

具有[穿透](穿透.md)魔咒的弩可以使发射的箭可以命中的实体数量增加，可命中实体数量至少为2的箭会穿过命中的实体并使自身此数值减1，此数值为1或不存在时，命中实体的箭会消失。剩余可命中实体数量至少为2的箭无法被盾牌阻挡，而是正常地命中其后的实体。

# = 烟花火箭 =

弩可以装填并发射[烟花火箭](烟花火箭.md)。

弩发射的烟花火箭的速度在随机散射修正前为32m/s，而发射出的烟花火箭飞行时间不变，因此发射出烟花火箭的飞行距离增加。由弩竖直向上发射的飞行时间为1的烟花火箭飞行高度与由玩家或[发射器](发射器.md)燃放的飞行时间为3的烟花火箭高度相近。

[多重射击](多重射击.md)魔咒对烟花火箭也有效，让玩家可以一次发射3个烟花火箭而只消耗一个。[穿透](穿透.md)魔咒对烟花火箭没有效果。

没有烟火之星的烟花火箭在飞行[一段时间](烟花火箭#持续时间和方向.md)或后会消失，碰到方块上会在方块上继续滑行，但在方块上滑行过程中碰到实体不会消失；有烟火之星的烟花在飞行一段时间以及后会爆裂，并根据合成材料的不同产生各种色彩缤纷的爆裂效果。如果合成时使用多个烟火之星，所有效果将会同时出现。

包含一个[烟火之星](烟火之星.md)的烟花火箭爆炸会造成到点伤害，且每增加1个烟火之星会增加到点伤害。

# = 生物使用 =
[掠夺者](掠夺者.md)和[猪灵](猪灵.md)可以使用弩，且不需要拥有箭就可以进行装填。

[掠夺者](掠夺者.md)在被生成时就会装备弩。[猪灵](猪灵.md)在被生成时有可能装备弩。

不像生物会使用的其他物品，弩被生物使用时同样会损失耐久度，并可以损毁。

# = 魔咒 =
弩接受6种不同类型的魔咒<!--指生存模式下能够施加在弩上的魔咒-->，其基础[附魔能力](附魔能力.md)为1。弩的魔咒不会对箭的速度或距离有任何的影响。

弩能够提升对同时打击多个目标的能力，与精于打击单一目标的[弓](弓.md)相对。

[](力量（魔咒）.md)、[冲击](冲击.md)、[火矢](火矢.md)、[无限](无限.md)之类的[弓](弓.md)的魔咒不适用于弩。即使强制为弩添加弓的魔咒，也不会有任何实质性的效果。

# = 燃料 =
弩可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每把弩可烧炼或个物品。
