# Java版18w14b

*页面ID: 34148* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w14b**是[Java版1.13](Java版1.13.md)的第30个快照，发布于2018年4月5日<ref></ref>，加入了海泡菜，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[海泡菜](海泡菜.md)**
* 生成于热带海洋里，围绕着[珊瑚礁](珊瑚礁.md)生成。
* 一格内最多可以放置4个。
* 每个增加3亮度等级，但只能在水下放置时起效。
* 可以烧炼成[黄绿色染料](黄绿色染料.md)。

# 更改
# = 方块 =
* *[珊瑚](珊瑚.md)**
* 现在有了更具体的名称。
* 为珊瑚和它们的变种更改了名称。
* * 珊瑚现在被命名为“珊瑚块”。
* * 失活的珊瑚现被命名为“失活的珊瑚块”。
* * 珊瑚丛现被命名为“珊瑚”。
* * “蓝色”珊瑚现在被命名为“管珊瑚”。
* * “粉红”珊瑚现在被命名为“脑珊瑚”。
* * “紫色”珊瑚现被命名为“气泡珊瑚”。
* * “红色”珊瑚现在被命名为“火珊瑚”。
* * “黄色”珊瑚现在被命名为“鹿角珊瑚”。
* 新的珊瑚扇纹理。
