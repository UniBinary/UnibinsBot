# Java版15w41a

*页面ID: 18543* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w41a**是[Java版1.9](Java版1.9.md)的第31个快照，发布于2015年10月7日<ref></ref>，加入了鞘翅、不同种类的船和新的NBT标签，并修复了一些漏洞。

# 新内容
# = 物品 =
* [鞘翅](鞘翅.md)
* * 功能来源于悬挂式滑翔机。
* ** 当自低高度跳下缓慢降落时不会受到掉落伤害（不能头部朝下俯冲）。
* ** 头部朝下俯冲还是会受到掉落伤害。
* * 必须装备于“胸甲”位置以使其工作。
* * 可以使用431秒且能用皮革在铁砧上修补。
* * 可以使用[铁砧](铁砧.md)或命令给予耐久[魔咒](魔咒.md)。
* * 在空中失速时双腿会有“行走”的动作。
* * 类似于[Super Mario 64](wzh:Super Mario 64.md)的飞行帽。
* * 在[末地船](末地城#末地船.md)的[物品展示框](物品展示框.md)中找到，取代了原本的信标/Searge的书。
* * 不滑翔时翅膀会折起。
* * 披风在穿着时不会显示。
* * 以每秒1点的速度降低耐久。
* 不同种类的[船](船.md)。
* * 目前只有橡木船能被合成。

# = 命令格式 =
* *NBT标签**
* 对于所有实体：
* * <code>Passengers</code>（列表标签）：取代原来的复合标签。不像那样，它可以让多个骑乘者处于同一个深度上。与处于嵌套最深层的实体会在堆叠最顶层不同，处于数据根部的实体会在堆叠最顶层。举个例子，下面命令的盔甲架在堆叠中将会处于同深度的[牛](牛.md)与[猪](猪.md)的上方：
* ** <code>/summon ArmorStand ~ ~1 ~ {Passengers:[{id:"Cow"},{id:"Pig"}]}</code>
* * <code>Riding</code> (复合标签)：标签被移除以支持新的标签。
* 对于玩家：
* * <code>RootVehicle</code>
* ** 随着标签的引入，这个新的复合标签会复制玩家目前骑乘的实体的标签。和是实体的UUIDLeast和UUIDMost数据，而包含的是真正的数据。
* ** <code>/testfor @a {RootVehicle:{AttachLeast:1l,AttachMost:1l,Entity:{id:"Boat",CustomName:"Test"}}}</code>

# 更改
# = 非生物实体 =
* *船**
* 更改了服务端传输、处理玩家移动的方式
* 合成配方现在包括了[木锹](木锹.md)以作为桨。
* 现在需要划桨使船移动，需要用到键和键。
* * 会划左浆，使船转向右边，反之亦然。
* * 同时按下键和键会使玩家同时划动左右桨，将玩家向前驱动。快速交替按动键和键会使玩家前进更快。
* * 移动鼠标玩家可以完整观察左侧与右侧，但不能观测后方。移动鼠标亦不再使船转向。
* * 按下键，键或者键不再有任何效果。
* 船在前进中时玩家不再能使用物品攻击。
* 所有的实体都可以进入船，最多可以搭载两个实体（包括玩家）。

# = 世界生成 =
* *[末地船](末地城#末地船.md)**
* 移除了带书的漏斗。
* 移除了铁块。
* 扩大了地板的[黑曜石](黑曜石.md)图案。
* 添加了带有鞘翅的物品展示框。

# = 游戏内容 =
* *[交易](交易.md)**
* 牧师现在以4-7个[绿宝石](绿宝石.md)销售[末影珍珠](末影珍珠.md)而不是[末影之眼](末影之眼.md)。

# = 常规 =
* *多人游戏**
* 增强了作弊检测。
