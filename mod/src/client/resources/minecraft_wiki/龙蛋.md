# 龙蛋

*页面ID: 7957* | *来源: Minecraft Wiki*

</ref>||Duncan_Geere_Mojavatar.png}}

* *龙蛋（Dragon Egg）**是一种首次击杀[末影龙](末影龙.md)后生成的装饰性[方块](方块.md)。

# 生成
[thumb|首次击杀末影龙后，在返回传送门上生成的龙蛋](File:Dragon egg on portal.png.md)
首次击杀[末影龙](末影龙.md)，且[返回传送门](返回传送门.md)激活后，龙蛋会出现在返回传送门顶端。返回传送门的中心的正上方如果有固体方块，那么龙蛋会生成在(0,0)最高的固体方块上方1格处。如果最高的固体方块触及了世界高度限制，则龙蛋不会生成。

# 获取

龙蛋的物品形式只能通过破坏龙蛋获得。由于龙蛋会导致龙蛋瞬移，玩家通常需要挖掘以外的方式来获取龙蛋。

每个世界只有一个龙蛋，因为只有首次击杀末影龙会生成龙蛋；第二次击败末影龙也有可能生成龙蛋。<ref></ref>

# 破坏
没有工具可以加速对龙蛋的挖掘。

龙蛋被破坏后会掉落自身。

被[爆炸](爆炸.md)破坏的龙蛋总是会掉落。

# 用途
[缩略图|250px|点击龙蛋后瞬移位置的热度图](File:Dragon Egg Heatmap.png.md)

# = 下落的方块 =

龙蛋在下方没有不可替代的方块时会后}}变为[下落的方块](下落的方块.md)。

龙蛋未得到支撑时，不会在其下方产生[粒子](粒子.md)。

# = 光源 =
龙蛋发出[亮度](亮度.md)等级为1级的光。

# = 瞬移 =
空手或在生存模式或冒险模式下龙蛋，龙蛋会尝试1000次瞬移到以其为中心竖直距离7格、水平[切比雪夫距离](切比雪夫距离.md)15格内（总范围为31×15×31）的不在[世界边界](世界边界.md)外的[空气](空气.md)中。龙蛋瞬移会产生128个与[末影人](末影人.md)瞬移时相同的[粒子](粒子.md)，但并不在正确的位置上<ref></ref>。龙蛋常常瞬移至高空中并变为下落的方块。

若这1000次尝试全部失败，龙蛋就不会瞬移，因此直接挖掘龙蛋成为可能。<ref>http://imgur.com/a/vQFMB</ref>

# 你知道吗
* [Mojang](Mojang.md)曾出价请Minecraft漫画《WonderCraft》的作者Samcube设计一些Minecraft的官方海报。在这些作品中的一幅里可以看到：一个有着末影龙的地方，还有一只站在[巨型蘑菇](巨型蘑菇.md)上的[鸡](鸡.md)，在鸡旁边有一个紫色蛋形方块——这就是龙蛋。
