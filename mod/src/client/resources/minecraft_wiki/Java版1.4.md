# Java版1.4

*页面ID: 33296* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.4**是[Java版1.4.2](Java版1.4.2.md)的首个预发布版，发布于2012年10月19日<ref></ref>。

# 新内容
# = 方块 =
* *[铁砧](铁砧.md)**
* 加入了新的音效。

# = 生物 =
* *[蝙蝠](蝙蝠.md)**
* 加入了新的音效。

* *[末影龙](末影龙.md)**
* 加入了新的音效。

* *[凋灵](凋灵.md)**
* 加入了新的音效。

* *[僵尸](僵尸.md)**
* 加入了新的音效（治愈僵尸村民和感染村民）。

# 更改
# = 方块 =
* *[铁砧](铁砧.md)**
* 在[创造模式](创造模式.md)中移除了用于[铁砧](铁砧.md)的等级限制。

# = 常规 =
* *[服务器](服务器.md)**
* 如果服务器不匹配客户端版本，服务器会在多人菜单中显示它们的版本。</onlyinclude>
