# Java版22w11a

*页面ID: 93660* | *来源: Minecraft Wiki*

<onlyinclude>

* *22w11a**是[Java版1.19](Java版1.19.md)的首个快照，发布于2022年3月16日<ref></ref>，加入了[青蛙](青蛙.md)、[蝌蚪](蝌蚪.md)2种生物和红树、泥巴系列方块，从先前的[实验性快照](Java版1.19-exp1.md)中加入了[幽匿](幽匿.md)系列方块和[深暗之域](深暗之域.md)生物群系，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[蛙明灯](蛙明灯.md)**
* 一种[亮度](亮度.md)为15的发光方块，会在[青蛙](青蛙.md)吞食小型[岩浆怪](岩浆怪.md)时掉落。
* 共有赭黄、珠光、青翠3个变种，绿色、橙色和白色品种的青蛙分别掉落青翠、赭黄和珠光变种。

* *[青蛙卵](青蛙卵.md)**
* 一种可放置于[水](水.md)上的非固体方块。
* 对两只[青蛙](青蛙.md)喂食[黏液球](黏液球.md)后，其中一只青蛙会寻找附近的水源或流水，并在上方产下青蛙卵。
* * 一段时间以后，青蛙卵会孵化成蝌蚪。

* *[红树原木](红树原木.md)**
* 一种褐色外皮、朱红色内干的[原木](原木.md)。
* 有对应的去皮变种。

* *[紅樹林木塊](紅樹林木塊.md)**
* 红树原木的[木头](木头.md)变种，可用红树原木合成。
* 有对应的去皮变种。

* *[红树木板](红树木板.md)**
* 一种朱红色木板，可用红树原木或紅樹林木塊合成。
* 可用于合成对应的[按钮](按钮.md)、[门](门.md)、[栅栏](栅栏.md)、[栅栏门](栅栏门.md)、[压力板](压力板.md)、[告示牌](告示牌.md)、[台阶](台阶.md)、[楼梯](楼梯.md)和[活板门](活板门.md)。

* *[红树树叶](红树树叶.md)**
* 一种暗绿色的树叶。
* 对其[骨粉](骨粉.md)，其下表面会开始生长红树胎生苗。

* *[红树根](红树根.md)**
* 一种褐绿色的根须状方块，视觉上是透明的，类似于树叶。
* 可以[含水](含水.md)。
* * 其所含的水目前不会流到其他含水方块上。
* 用[斧](斧.md)的挖掘速度最快。
* 被活塞移动时不会被破坏。若含水，其中的水会消失。
* 可以被充能。

* *[红树胎生苗](红树胎生苗.md)**
* 一种新的树苗。
* 会在对红树树叶骨粉后在其下表面长出。
* * 共有4个生长阶段，使用骨粉可以加速生长。
* 可以种植在[泥土](泥土.md)及其变种、[黏土](黏土.md)和泥巴上，且能够种植在水下。
* 对其骨粉后会长成[橡树](橡树.md)。
* * 由于相关内容尚未完成，此特性当前仅用作占位符。
* 可以放在[花盆](花盆.md)中。
* 可用于吸引和繁殖[蜜蜂](蜜蜂.md)，且蜜蜂会采集它的花粉。

* *[泥巴](泥巴.md)**
* 一种蓝黑色方块。
* 对[泥土](泥土.md)、[砂土](砂土.md)或[缠根泥土](缠根泥土.md)[水瓶](水瓶.md)或通过[发射器](发射器.md)发射水瓶会将其转化为泥巴。
* 方块[高度](碰撞箱.md)与[灵魂沙](灵魂沙.md)相同，会使上方的实体下陷，但不会造成减速。

* *[沾泥的红树根](沾泥的红树根.md)**
* 红树根的变种，可用1块红树根与1块泥巴合成。
* 与红树根不同，其不能含水，视觉上也不透明。
* 用[锹](锹.md)的挖掘速度最快。

* *[泥坯](泥坯.md)**
* 一种土色的方块，可用1个泥巴与1个[小麦](小麦.md)合成。

* *[泥砖](泥砖.md)**
* 泥坯的砖类变种，可用[泥坯](泥坯.md)合成。
* 可用于合成对应的[台阶](台阶.md)、[楼梯](楼梯.md)和[墙](墙.md)。

* *[幽匿块](幽匿块.md)**
* 自[实验性快照](Java版1.19-exp1.md)加入。
* 生成于深暗之域生物群系。
* 拥有动态纹理。
* 只能使用[精准采集](精准采集.md)附魔工具获得，使用其他方式破坏则只会掉落[经验](经验.md)。
* 在幽匿催发体周围死亡的生物下方会长出幽匿块。
* 与上述实验性快照不同的是，将[羊毛](羊毛.md)放置在幽匿块上不会被[幽匿感测体](幽匿感测体.md)检测到。

* *[幽匿催发体](幽匿催发体.md)**
* 自实验性快照加入。
* 生成于深暗之域生物群系。
* 在其周围有生物死亡时会散发灵魂[粒子](粒子.md)，并将生物掉落的经验转换为幽匿块。长出幽匿块的数量取决于生物被玩家杀死时正常掉落的经验数量，经验越多，长出的幽匿块就越多。
* * 长出幽匿块的数量不会因为生物非玩家杀死（不掉落经验）而改变。
* 只能使用精准采集附魔工具获得，使用其他方式破坏则只会掉落经验。
* 会发出6级的光。
* [32px](File:Sculk_Catalyst_Bloom.gif.md) 拥有激活动画。

* *[幽匿尖啸体](幽匿尖啸体.md)**
* 自实验性快照加入。
* 生成于深暗之域生物群系。
* 只能使用精准采集附魔工具获得，使用其他方式破坏则不掉落任何物品。
* 因相关生物[监守者](监守者.md)尚未加入，目前其无法激活也不会呼啸，仅有装饰用途。

* *[幽匿脉络](幽匿脉络.md)**
* 自实验性快照加入。
* 会在深暗之域生物群系当中幽匿块斑块的边缘生成。
* 生成时会依附在其他方块的顶部，而摆放时可依附在其他方块的任意一面上。
* 拥有动态纹理。
* 能够[含水](含水.md)。
* 只能使用精准采集附魔工具获得，使用其他方式破坏则不会掉落任何物品。
* 部分透明，可以让玩家看到其覆盖的方块。

# = 生物 =
* *[青蛙](青蛙.md)**
* 自然生成于[沼泽](沼泽.md)生物群系。
* 时常鼓动鸣囊，在陆地上会跳跃行走，在水中会游泳，且游泳的速度要比行走快。
* 有绿色、橙色、白色3个变种。
* 可以通过喂食[黏液球](黏液球.md)使之繁殖。
* * 繁殖后产下[青蛙卵](青蛙卵.md)。
* 会吞食小型[史莱姆](史莱姆.md)，并掉落1个黏液球。
* 会吞食小型[岩浆怪](岩浆怪.md)，并掉落1块相应种类的[蛙明灯](蛙明灯.md)。
* 蝌蚪会发育成青蛙。

* *蝌蚪**
* 青蛙的幼年形态，会成长并最终发育为青蛙。
* * 喂食[黏液球](黏液球.md)可加速成长。
* * 长成的青蛙种类取决于所在[生物群系](生物群系.md)的[温度](温度.md)。
* 在水中会游泳；在陆地上会像[鱼](鱼.md)一样扑腾，最终会脱水而死。
* 可以被装在[水桶](水桶.md)里。

# = 常规 =
* *[区块存储格式](区块存储格式.md)**
* 加入了，以决定要使用哪部分的数据作为地形过渡的依据。

* *[数据包](数据包.md)和[资源包](资源包.md)**
* 现在可在<samp>pack.mcmeta</samp>中添加<code>filter</code>字段，以支持对包中特定内容的屏蔽。
* * 此字段中有一个必选字段<code>block</code>，是一个包含命名空间（<code>namespace</code>）和路径（<code>path</code>）正则表达式的列表。
* * 若任何一个在此包下方的包中有能与<code>filter</code>中<code>path</code>匹配上的文件，则此文件将被屏蔽。
* * 均为可选项，若此二者均不填时，则表示匹配所有值。
* * 例如，向数据包添加以下内容即可屏蔽原版数据包的配方以及进度：
  ::<syntaxhighlight lang="json">
"filter": {
    "block": [
        {
            "namespace": "minecraft",
            "path": "recipes/.*"
        },
        {
            "namespace": "minecraft",
            "path": "advancements/.*"
        }
    ]
}
</syntaxhighlight>

# 更改
# = 方块 =
* *[酿造台](酿造台.md)**
* 略微更改了纹理，以使其臂与其底座相连。

* *[可可果](可可果.md)**
* 略微更改了<code>stage2</code>的顶面和底面纹理，以使其与侧面的纹理大小保持一致。

* *[末地传送门框架](末地传送门框架.md)**
* 略微更改了纹理，以使其与[末地石](末地石.md)间的过渡更平滑。

* *[末地烛](末地烛.md)**
* 移除了纹理中未使用的像素。

* *[菌丝体](菌丝体.md)**
* 略微更改了其侧面纹理，以与其他泥土基底方块相匹配。

* *[脚手架](脚手架.md)**
* 现在每个脚手架只能烧炼0.25个物品。

* *[幽匿感测体](幽匿感测体.md)**
* 自[实验性快照](Java版1.19-exp1.md)引入了以下更改：
* * 重新加入到[创造模式物品栏](创造模式物品栏.md)。
* * 现在只能使用精准采集附魔工具获得，使用其他方式破坏则只会掉落经验。
* 与上述实验性快照不同的是，[潜行](潜行.md)的玩家踩踏幽匿感测体不会将其激活。

* *[烟熏炉](烟熏炉.md)**
* 旋转了其底部纹理的左下角部分，以使其朝向正确。

# = 世界生成 =
* *[自定义世界生成](自定义世界生成.md)**
* 原版世界生成参考数据包中不再出现<samp>dimension</samp>文件夹，但自定义数据包中维度文件的功能不受影响。
* 在数据生成器报告的<samp>biome_parameters</samp>文件夹中加入了一种新的文件类型，其中包含所有由默认原版维度使用的生物群系参数。
* 自定义维度不再需要单独的<code>seed</code>字段。对于维度来说，现在不存在单独的维度种子，因为所有维度统一使用世界种子。
