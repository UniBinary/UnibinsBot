# 基岩版1.18.0.23

*页面ID: 90400* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.0.23**是[基岩版1.18.0](基岩版1.18.0.md)的第4个测试版，发布于2021年10月22日<ref></ref>，修复了游戏数据保存至外部存储的支持问题。

# 修复
* 修复了保存在外部存储中的存档等游戏数据的支持问题，以使其能够再次出现在部分玩家的游戏中。</onlyinclude>
