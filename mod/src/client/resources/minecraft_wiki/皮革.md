# 皮革

*页面ID: 6985* | *来源: Minecraft Wiki*

* *皮革（Leather）**是一种多用途合成材料。

# 获取
# = 生物掉落物 =
成年[狐狸](狐狸.md)自然生成时有4%的概率在嘴里叼着皮革，且其死亡时叼着的皮革总是会掉落。

# = 钓鱼 =
[钓鱼](钓鱼.md)时皮革可作为垃圾被钓上。

# = 箱子战利品 =

# = 合成 =

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家2-4个皮革。

# = 礼物 =

[皮匠](皮匠.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷皮革。

# = 铁砧修复 =

皮革[帽子](帽子.md)、[外套](外套.md)、[裤子](裤子.md)和[靴子](靴子.md)能在[铁砧](铁砧.md)上用皮革来[修复](修复.md)，每个修复25%耐久度（向下取整）。
