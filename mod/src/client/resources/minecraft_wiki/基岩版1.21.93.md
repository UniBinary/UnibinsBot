# 基岩版1.21.93

*页面ID: 156665* | *来源: Minecraft Wiki*

* *1.21.93**是的一次热修复更新，发布于2025年7月3日<ref></ref>，加入了1张来自[A Minecraft Movie](A Minecraft Movie.md)的[音乐唱片](音乐唱片.md)，并修复了一些漏洞。此版本不兼容[1.21.90](基岩版1.21.90.md)至[1.21.92](基岩版1.21.92.md)。

# 新内容
# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* 加入了音乐唱片“Lava Chicken”，作者为[Hyper Potions](Hyper Potions.md)。
* * 由玩家杀死正在骑乘[鸡](鸡.md)的幼年[僵尸](僵尸.md)、[僵尸村民](僵尸村民.md)和[尸壳](尸壳.md)掉落。
* * [稀有度](稀有度.md)为“少见”。
* * 通过[红石比较器](红石比较器.md)输出的红石信号强度为9。

# 更改
# = 非生物实体 =
* *[画](画.md)**
* 更改了“Dennis”画作的纹理以匹配。

# = 技术性 =
* *API**
* 加入了新的条件，允许检查掉落战利品的受伤实体所骑乘的坐骑实体类型。
* * 类似于，允许指定字段以在决定选择战利品表中哪个抽取项时进行检查。
* 加入了新的条件，允许检查掉落战利品的实体是否为。

# 修复
* *常规**
* 修复了导致世界模板中的包消失的漏洞。（）
* PlayStation和Switch平台上的分屏玩家现在可以访问他们在1.21.80及更早版本中创建的玩家数据（如物品栏）。（）

* *图形**
* 降低了启用时火把、红石火把、灵魂火把和灵魂灯笼的发光强度。（）
* 修复了不会在上下文中正确运行，进而导致部分资源包出现动画问题的漏洞。
* 在启用的情况下直视告示牌上的发光文本时，文本不再会显得过亮。

* *生物**
* 修复了快乐恶魂被拴在地表附近时会导致性能下降的问题。（）
* 空气摩擦力现在仅会应用于被拴住的船。（）
* * 被拴住的船仍然不会绕玩家旋转。
* * 船再次会在离开悬崖时保留动量。

* *用户界面**
* 修复了玩家无法在使用触控设备上的交互按钮时移动相机视角的问题。（）
