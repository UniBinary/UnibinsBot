# Java版Classic 0.0.12a/开发者版本

*页面ID: 21524* | *来源: Minecraft Wiki*

该条目记录了[Java版Classic 0.0.12a](Java版Classic 0.0.12a.md)的所有开发者版本。

# 0.0.11a（2009年5月18日）

该版本进行了初步的服务端开发，并于启动器中可用，即启动器中的“c0.0.11a”。

# = 新内容 =
* *其他**
* 加入了处理基本客户端连接和发送消息的代码。

# 0.0.12a（2009年5月18日）

该版本进行了初步的[基岩](基岩.md)和[水](水.md)的开发，并测试了新的地形生成器。<ref></ref><ref></ref>

# = 新内容 =
* *[基岩](基岩.md)**
* 不能被破坏、放置或选择。
* 在世界外低于海平面两格的位置和世界底部生成，包围[世界](世界.md)。

* *[水](水.md)**
* 不透明，完整方块，会阻挡光照。
* 玩家可在水中[游泳](游泳.md)，但生物会在水下全速移动。
* 会填充其下方或周围的任何可用空间。

* *[世界界限](世界界限.md)**
* 世界外会生成一片以基岩为海床的海洋，这使得玩家不再能掉出世界。

* *[控制](控制.md)**
* 按下键可在四种不同的渲染距离中切换。
* 按下键可在不出现世界生成界面的情况下重新生成世界。[人类](生物（已移除实体）.md)不会因此操作而被重置。

# = 更改 =
* *地形**
* 地形更加凌乱，地面上可见更多凸起。
* 现在可以生成岛屿了。
* 没有方块可以生成在海平面上，地形总是比其高1个方块。
* 生成在海平面以下的[泥土](泥土.md)即使有光照也不会转化为[草方块](草方块.md)。

# 你知道吗
