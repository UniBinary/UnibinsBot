# 砂轮

*页面ID: 37019* | *来源: Minecraft Wiki*

* *砂轮（Grindstone）**是可用于修补损坏的物品并移除魔咒的方块。

# 生成
# = 自然生成 =
[thumb|right|在针叶林村庄的武器匠铺内生成的砂轮](File:Weaponsmith shelter.jpg.md)
砂轮会自然生成于[村庄](村庄.md)的武器匠铺里。

砂轮还会自然生成于[古迹废墟](古迹废墟.md)的独栋圆顶屋中。

# 破坏
挖掘砂轮的合适工具是镐。砂轮需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

砂轮被破坏后会掉落自身。

# 用途
砂轮不能被[活塞](活塞.md)移动。

砂轮会在附着方块移动、移除或被破坏的情况下被破坏并掉落自身。

# = 修复和祛魔 =

按键可打开砂轮的界面，其有三个槽位：两个输入槽和一个产物槽。

砂轮的两个输入物品槽位中，最上方的槽位放置**目标物品**，下方的槽位则放置**牺牲物品**。砂轮操作可以不需要牺牲物品。

砂轮会对目标物品进行以下操作后生成**产物**：
* 所有输入物品的所有非诅咒魔咒会被移除。计算所有被移除的魔咒的[最小修正附魔等级](魔咒#魔咒属性.md)之和，除以2后向上取整得到<code>x</code>，随后砂轮在取出产物时弹出<code>x + random.nextInt(x)</code>经验值。例如，移除火焰保护I将会提供5–9经验值。
* 若提供了牺牲物品：
* * 目标物品会获得牺牲物品的剩余[耐久度](耐久度.md)，然后再额外获得5%剩余耐久度。
* * 目标物品会获得牺牲物品的所有未被移除的魔咒，且无视添加魔咒通常会受到的限制。
* 若目标物品的[累积惩罚操作数](铁砧机制#累积惩罚.md)高于物品上未被移除的魔咒数量，操作数会被降低到魔咒数量。
* 目标物品中的所有其他物品数据都会被保留，如物品名称。
* 若目标物品是[附魔书](附魔书.md)，且所有魔咒都能被砂轮清除，则产物会变为[书](书.md)。

在以下情况时，砂轮不能提供输出：
* 输入单个没有魔咒的物品
* 输入两个不同的物品
* 输入两个物品都是附魔书
*

取出产物会确认砂轮的操作，并移除所有输入物品。

若操作无效，砂轮会像[铁砧](铁砧.md)一样，箭头上会出现一个红叉。

# = 更改村民职业 =
如果一个砂轮没有被[村民](村民.md)认领，则附近的任意一个失业村民有机会转变职业为[武器匠](武器匠.md)。
