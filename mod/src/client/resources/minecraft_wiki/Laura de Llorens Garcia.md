# Laura de Llorens Garcia

*页面ID: 67116* | *来源: Minecraft Wiki*

* *Laura de Llorens Garcia**是[Mojang Studios](Mojang Studios.md)的设计总监。

# 关于
2019年10月，Laura加入Mojang，担任[Minecraft Dungeons](Minecraft Dungeons.md)的高级游戏设计师。2021年10月，晋升至游戏设计主管。

2023年9月起，担任设计总监。
