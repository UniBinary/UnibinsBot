# 携带版1.0.2

*页面ID: 27050* | *来源: Minecraft Wiki*

* *1.0.2**是携带版的一次次要更新，在iOS、Android、FireOS、Windows 10和Fire TV平台上发布于2017年1月19日，而在Gear VR和Apple TV平台发布于1月25日<ref></ref>，修复了一些漏洞。

# 修复
* *修复了25个漏洞**
* 距离8格以外的末影螨不会攻击生物。
* 命令现在可以用于查找要塞。
* 无法将滞留药水倒入炼药锅里或取出。
* 马只能以一个方向来向上跑。
* 使用滞留药水会合成错误的药箭。
* 下载音乐包时游戏崩溃。（Android版）
* 成就界面显示错误。（Fire TV版）
* 打开大型箱子时，方块模型出错。
* 末影人在死后仍会传送。
* 骷髅和流浪者的攻击力会无视世界难度。
* 骷髅和流浪者不会逃离狼。
* 触摸板会使得玩家经常向下看。
* 使用刷怪蛋生成村民或装备盔甲时游戏崩溃。
* 多人游戏下的弹射物行为不正确。
* 物品展示框可以用来复制物品。
* 处于隐身状态下的生物会无敌。
* 使用鞘翅飞行时，重新进入游戏会使得玩家往下坠落。
* Realms世界里死亡的羊使得游戏崩溃。
* 多人游戏下，给牛挤奶会丢失铁桶。
* 凋灵之首不能反弹。
* 凋灵头部不会朝向目标玩家。
* 导入世界后，末地水晶消失。
* 鸡下蛋的冷却时间错误。
* 死亡后的生物不再能受伤。
* 和格式的文件无法被游戏识别。（iOS版）
