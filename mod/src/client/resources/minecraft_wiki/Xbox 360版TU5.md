# 更改
# = 方块 =
* 更改了[TNT](TNT.md)的爆炸音效。
* 为[发射器](发射器.md)加入了快速移动。
* 改进了[箱子](箱子.md)的模型，为其加入了3D的锁以及打开和关闭的动画。
* [压力板](压力板.md)现在可以被放置在[栅栏](栅栏.md)上。
* 玩家放置的树叶不再会枯萎。
* <span style="color:red">1.1的特性</span>：树叶会掉落苹果。
* <span style="color:red">1.2.3的特性</span>：南瓜和西瓜的生长速度变快了，并且不再需要茎旁有耕地方块。
* <span style="color:red">1.2.3的特性</span>：修复了藤蔓的机制以防止其过度蔓延。

# = 物品 =
* 现在除了[蘑菇煲](蘑菇煲.md)和[蛋糕](蛋糕.md)以外的食物都可堆叠。
* 对[弓](弓.md)做出了更改，现在其有拉弓和射箭动画。
* 加入了剑的格挡功能。
* 剪刀现在可以用来采集高草丛和新加入的藤蔓。
* 改变了所有食物的描述，现在会显示它们恢复的饥饿值。
* <span style="color:red">1.2.5的特性</span>：加入了熔炉界面的快速移动。
* <span style="color:red">1.2.3的特性</span>：蘑菇煲的合成配方变得无序。

# = 生物 =
* 友好生物现在会在受伤时逃跑。
* 猪的鼻子现在向前突出。
* 骷髅现在手持完整大小的弓。
* 动物不再自然消失，使得它们能被捕捉到。
* 僵尸现在掉落腐肉而不是羽毛。
* 更新了一些生物的音效。

# = 世界生成 =
* 云层的高度被提升到了地图的顶端，因此云层不再能穿过方块了。
* 云的运动现在会与游戏内时间同步。
* 改进了日出和日落。
* 改进了仰视时雨的效果。
* 移除了[虚空](虚空.md)，使其不再破坏顶层或底层的基岩。
* 移除了下列生物群系：
* * [雨林](雨林.md)
* * [季节性森林](季节性森林.md)
* * [热带草原](热带草原.md)
* * [灌木丛地](灌木丛地.md)
* * [冻原](冻原.md)

# = 游戏内容 =
* 为[物品栏](物品栏.md)界面加入了[盔甲](盔甲.md)的快速装备。

# = 常规 =
* 教程
* * 更改了教程世界以加入新的地形特征。
* * 为教程世界加入了[疾跑](疾跑.md)教程。
* * 为教程世界加入了进食教程。
* * 为教程世界加入了[音乐唱片](音乐唱片.md)任务：玩家可以搜寻世界中的12个[箱子](箱子.md)，每个箱子中各自包含一张可以在[唱片机](唱片机.md)中播放的音乐唱片。
* <span style="color:red">1.2.3的特性</span>：更改了挖掘速度。
* 更新了“如何游玩”HUD界面，加入了饥饿条相关的内容。
* 向“如何游玩”菜单加入了创造模式和疾跑相关的介绍。
* 更新了“下载内容”菜单，加入了可用DLC的图片。
* 教程世界现在使用schematic文件生成。

# 修复
* 修复了复制物品的漏洞。
* 调整了分屏模式中手持物品的宽高比。
* 修复了玩家数据不保存，导致物品栏清空的漏洞。
* 修复了红石块会被烧毁的漏洞。
* 修复了动力矿车无法驱动其他矿车的漏洞。
* 修复了第三人称视角的粒子代码。
