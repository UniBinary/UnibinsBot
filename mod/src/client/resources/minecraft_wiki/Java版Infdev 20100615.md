# Java版Infdev 20100615

*页面ID: 35988* | *来源: Minecraft Wiki*

<onlyinclude>
* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年6月15日，加入了一些新物品。<ref></ref>

# 新内容
# = 物品 =
* *[铁桶](铁桶.md)**
* 可收集[水](水.md)和[熔岩](熔岩.md)。
* *[水桶](水桶.md)**
* 可以放置水。
* 不能放置于已包含[液体](液体.md)的方块上来将其替换；仅可替换非液体方块。
* *[熔岩桶](熔岩桶.md)**
* 可以放置熔岩。
* 不能放置于已包含[液体](液体.md)的方块上来将其替换；仅可替换非液体方块。

# = 常规 =
* *[选项](选项.md)**
* 流畅/高品质图形切换。
* * 此选项仅能切换云的2D和3D。流畅的云与[Infdev 20100608](Java版Infdev 20100608.md)中的云完全相同。默认设置为高品质。

# 更改
# = 方块 =
* *[水](水.md)和[熔岩](熔岩.md)**
* 现在再次可以流动。
* * 处于流动的液体中的[实体](实体.md)会随之移动。
* ** 射出的[箭](箭.md)不受此影响。

* *[树叶](树叶.md)**
* 现在会腐烂了。

* *[门](门.md)**
* 现在被破坏后会掉落自身。

# = 游戏内容 =
* *[昼夜更替](昼夜更替.md)**
* 白天现在比夜晚稍长。</onlyinclude>
