# Java版Beta 1.4 01

*页面ID: 32760* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.4_01**是的一次次要更新，发布于2011年4月5日，移除了[上锁的箱子](上锁的箱子.md)，并修复了有关[床](床.md)标记重生点的漏洞。

# 更改
# = 方块 =
* *[上锁的箱子](上锁的箱子.md)**
* 部分移除了该方块，其仍能通过编辑[物品栏](物品栏.md)获得。
* 上锁的箱子在接受到随机刻时会消失，以避免游戏崩溃。但如果物品栏中有上锁的箱子的方块物品，它们将不会消失。

# 修复
* *修复了1个漏洞**
* 床现在可以正常地标记重生点了。</onlyinclude>
