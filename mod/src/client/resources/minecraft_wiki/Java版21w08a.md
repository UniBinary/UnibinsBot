# Java版21w08a

*页面ID: 79271* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w08a**是[Java版1.17](Java版1.17.md)的第11个快照，发布于2021年2月24日<ref></ref>，加入了[深层矿石](深层矿石.md)、[平滑玄武岩](平滑玄武岩.md)和[裂隙](裂隙.md)，重命名“阴沉石”为“深板岩”，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[平滑玄武岩](平滑玄武岩.md)**
* 在[紫晶洞](紫晶洞.md)结构中生成以取代[凝灰岩](凝灰岩.md)层。
* 可以通过熔炼[玄武岩](玄武岩.md)获得。

* *[深层矿石](深层矿石.md)**
* 加入了深层铁矿石、深层金矿石、深层红石矿石、深层青金石矿石和深层钻石矿石。
* 挖掘耗时是普通矿石的1.5倍。
* 纹理上以[深板岩](深板岩.md)作为容矿岩，而非石头。
* 完全取代了Y=-8以下的主世界矿石。

* *[深板岩圆石](深板岩圆石.md)**
* 通过开采深板岩获得。
* 与[黑石](黑石.md)功能相同，可代替[圆石](圆石.md)合成石质工具、熔炉以及酿造台。
* 与[圆石](圆石.md)一样拥有[墙](墙.md)、[楼梯](楼梯.md)和[台阶](台阶.md)变种。

# = 世界生成 =
* *[裂隙](裂隙.md)**
* 地面上一种深而长的裂缝，比[峡谷](峡谷.md)更窄更直。
* 可以深达90格。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 应用于深板岩。
* 加入了方块和物品标签。
* * 应用于对应矿石的石头纹理及深板岩纹理变种。
* 加入了方块标签。
* * 应用于石头、花岗岩、闪长岩、安山岩和凝灰岩。

# 更改
# = 方块 =
* *阴沉石**
* 重命名为“[深板岩](深板岩.md)（Deepslate）”。
* 略微更改了纹理。
* 不能再用于合成方块或修复物品，该功能已被[深板岩圆石](深板岩圆石.md)取代。
* 现在拥有新的音效。
* 现在只会在使用带[精准采集](精准采集.md)魔咒的镐挖掘时掉落其本身。

* *[黑石](黑石.md)、[磨制深板岩](磨制深板岩.md)、[雕纹深板岩](雕纹深板岩.md)、[深板岩砖](深板岩砖.md)、[深板岩瓦](深板岩瓦.md)及对应[台阶](台阶.md)、[楼梯](楼梯.md)和[墙](墙.md)**
* 略微更改了纹理。

* *[矿石](矿石.md)**
* 更改了除钻石矿石外的所有主世界矿石纹理。
* * 其中[铜矿石](铜矿石.md)具有局部氧化的纹理，[金矿石](金矿石.md)不再使用与下界金矿石相同的矿粒纹理。

* *[孢子花](孢子花.md)**
* 现在会向其周围的空气中散发类似“孢子”的粒子。

* *[凝灰岩](凝灰岩.md)**
* 现在会在Y=0以下以[团簇](团簇.md)的形式生成。

* *[安山岩](安山岩.md)**
* 不再在Y=0以下生成。

* *[熔岩](熔岩.md)**
* 现在会从Y=-54处开始生成。

# = 世界生成 =
[缩略图|450px|矿石分布变化](File:21w08a approximate ore distribution.png.md)
* *[矿石](矿石.md)分布**
* 再一次更改了矿石分布。
* * [铁矿石](铁矿石.md)现在能生成在Y=0以下，但团簇较小且生成频率较低。
* * 提高了[金矿石](金矿石.md)的生成频率，且有50%的概率不会暴露在空气中。
* * [钻石矿石](钻石矿石.md)现在也有50%的概率不会暴露在空气中。
* * 提高了[青金石矿石](青金石矿石.md)的掩埋频率。
* * 降低了[铜矿石](铜矿石.md)的生成频率。

* *[洞穴](洞穴.md)**
* 调整了洞穴的尺寸。
* 现在旧式洞穴能生成在Y=0以下。

# = 常规 =
* *创造模式物品栏**
* [黏液块](黏液块.md)和[蜂蜜块](蜂蜜块.md)现在被移到了红石选项卡中。

* *[标签](Java版标签.md)**
* 将凝灰岩添加进方块标签。
* 将[深层金矿石](深层金矿石.md)添加进方块和物品标签。
