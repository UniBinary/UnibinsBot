# Java版12w08a

*页面ID: 32330* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w08a**是[Java版1.2.1](Java版1.2.1.md)的第8个，也是最后一个快照，发布于2012年2月23日<ref></ref>，加入了[铁傀儡](铁傀儡.md)，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[铁傀儡](铁傀儡.md)**
* 新的效用型生物。
* 有时自然生成在大型[村庄](村庄.md)中充当守卫。
* 也可以通过4个[铁块](铁块.md)和1个[南瓜](南瓜.md)摆放生成。

# = 常规 =
* *[控制](控制.md)**
* 加入了镜头控制（这是意外加入的，Jeb说“deadmau5 camera”镜头控制会在下个快照中被移除）。<ref></ref><ref></ref>
* * 按下会导致玩家“卡屏”，直到再次按下为止，这导致玩家看起来像方块一样。
* * 按下导致视角无法移动，这允许使第三人称模式下玩家模型旋转。
* * 滚动鼠标的滚轮（包括打开物品栏时）会旋转向前，向左，向右和向后的方向。
* * 按下、、、、、、、、和会以各种方式改变视角的位置，同时按下两个功能相同的按键（例如）会恢复至普通的视角（但是无效）。

# 更改
# = 方块 =
* *[楼梯](楼梯.md)**
* 放置在方块的底部时可以上下颠倒。

# = 世界生成 =
* *常规**
* 熔岩池和宽阔的石头区域现在会经常生成在地表。

# = 常规 =
* *[语言](语言.md)**
* 移除了一些加拿大英语的定型语句。

# 修复
* *修复了1个漏洞**
* 修复了末地和洞穴生成出错的漏洞。</onlyinclude>
