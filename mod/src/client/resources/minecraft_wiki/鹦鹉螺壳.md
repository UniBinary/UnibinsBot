# 鹦鹉螺壳

*页面ID: 34248* | *来源: Minecraft Wiki*

</ref>，在[鹦鹉螺](鹦鹉螺.md)于2025年9月举办的[Minecraft LIVE – September 2025](Minecraft LIVE – September 2025.md)被宣布前|image=Duncan Geere Mojavatar.png}}

* *鹦鹉螺壳（Nautilus Shell）**是一种用于合成[潮涌核心](潮涌核心.md)的物品。

# 获取
# = 钓鱼 =
鹦鹉螺壳可以在[钓鱼](钓鱼.md)时作为[宝藏物品](钓鱼#垃圾与宝藏.md)钓上来。[海之眷顾](海之眷顾.md)魔咒可以增加钓到鹦鹉螺壳的概率。

# = 溺尸 =
[溺尸](溺尸.md)生成时有或的概率在[副手](副手.md)持有一个鹦鹉螺壳，被杀死后会掉落，因为溺尸死亡时总是会掉落副手中的物品。
