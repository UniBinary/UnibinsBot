# Java版13w37b

*页面ID: 33621* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w37b**是[Java版1.7.2](Java版1.7.2.md)的第4个快照，发布于2013年9月13日<ref></ref>，以修复[13w37a](13w37a.md)里的漏洞和崩溃。

# 修复
命令执行成功后没有提示输出。

# 你知道吗
* 此版本曾经在[启动器](启动器.md)中移除，但在2018年9月重新加入。
* 该版本的宣传截图中出现了[Grum](Grum.md)的Minecraft皮肤。
