# Java版Beta 1.9-pre6

*页面ID: 32292* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.9-pre6**是[Java版1.0.0](Java版1.0.0.md)的第6个，也是最后一个预发布版，发布于2011年11月11日<ref></ref> ，加入了[龙蛋](龙蛋.md)和[末地水晶](末地水晶.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[龙蛋](龙蛋.md)**
* 仅作装饰用途。

# = 非生物实体 =
* *[末地水晶](末地水晶.md)**
* 一种可以在基岩上方生成的实体。
* 具有类似于菱形的形状，有两立方体在轴线上旋转，末影龙进入一定范围时会有治疗光束射向它，可以用近战攻击或箭射击，导致其爆炸。
* 出现在末地里所有黑曜石柱的顶部。

# = 常规 =
* *游戏文件**
* 加入了以下文本文件至的文件夹：
* *
* *
* *

* *选项**
* 加入了视频设置里的选项。
* * 有三种选择：
* ** “全部”——渲染所有的粒子效果。
* ** “少量”——渲染一半的粒子效果。
* ** “最少”——不渲染粒子效果（除了破坏方块时的粒子）。

* *制作人员名单**
* 加入了结束标题和游戏制作人员名单。

# 更改
# = 方块 =
* *[水](水.md)**
* 向下流动的水现在创造多次的流动的水。

* *[床](床.md)**
* 尝试在敌对性生物附近睡觉时会出现信息“你现在不能休息，附近有怪物在游荡”。

* *[楼梯](楼梯.md)**
* 用任何材料挖掘楼梯会掉落自身而不是合成它的材料的方块形式。

* *[沙子](沙子.md)**
* 更改了纹理。

* *[草方块](草方块.md)**
* 更改了侧面纹理。

# = 生物 =
* *[末影龙](末影龙.md)**
* 与末影龙的战斗更加完善。
* * 与末影龙战斗时“Boss生命值”血条现在出现在屏幕正上方，与末影龙有相同的紫色色调。
* * 通过由基岩组成和顶部带有龙蛋的终末之池离开会把玩家传送到出生点或床边。

# = 游戏内容 =
* *太阳和月亮**
* 将其纹理改回方形。

* *[附魔](附魔.md)**
* 现在拥有[效率](效率.md)魔咒的物品能够对所有方块造成影响。

* *[挖掘](挖掘.md)**
* 不适合挖掘特定方块的工具可以比用手挖掘得更快，例如镐可以比空手更快地挖掘泥土，但不比锹快。
* 一些方块的使用工具挖掘时间被修复，例如[工作台](工作台.md)现在用斧会更快将其破坏，[铁轨](铁轨.md)用镐会更快将其破坏。
* 更改了许多方块的挖掘时间，包括[红石矿石](红石矿石.md)、[石砖](石砖.md)、[下界砖块](下界砖块.md)、[铁栏杆](铁栏杆.md)、[门](门.md)、[刷怪笼](刷怪笼.md)和[黑曜石](黑曜石.md)，使得它们可以以更快速度挖掘。

* *[烧炼](烧炼.md)**
* 现在可以将[煤矿石](煤矿石.md)烧炼成[煤炭](煤炭.md)。

# 修复
* *修复了12个漏洞**
* 修复了实体模型的错误。
* 盔甲的耐久度比Beta 1.8中的耐久更高。
* 创造模式中，使用物品攻击生物不再使物品损失耐久。
* 现在睡莲是一个可以站立的方块。
* 蕨、高草和睡莲现在会出现在创造模式物品栏中。
* 从创造模式物品栏中删除了蛋糕和甘蔗不必要的方块版本。
* 附魔台现在需要时间来挖掘，此前打一下就可以破坏。
* 将“Mods and Texture Packs”改为“Texture Packs”。
* 中继器时钟现在不会在卸载区块时卡住了。
* 在耕地下方放置栅栏不再会阻止耕地变成泥土了。
* 动力矿车可以把空矿车推向任何方向。
* 染色绵羊繁殖的幼年绵羊出生时会有相应的颜色，此前只有白色。</onlyinclude>
