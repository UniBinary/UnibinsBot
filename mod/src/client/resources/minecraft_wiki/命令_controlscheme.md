# 命令/controlscheme

*页面ID: 149703* | *来源: Minecraft Wiki*

修改相机预设的控制方案。

此命令需与命令一同使用。

# 语法
   <code>controlscheme <players: target> clear</code>
  : 清除控制方案。
   <code>controlscheme <players: target> set <control scheme: controlscheme></code>
  : 设定控制方案。

# 参数

   指定要被修改控制方案的[玩家](玩家.md)。


   指定控制方案。
   必须为以下其中之一：
  *  — 相对相机进行移动，视角保持水平并跟随移动方向
  *  — 相对相机进行移动，视角保持水平并跟随朝向
  *  — 相对玩家进行移动，视角跟随朝向
  *  — 相对玩家进行移动，视角保持水平并跟随移动方向
  *  — 相对玩家进行移动，视角保持水平并跟随朝向
