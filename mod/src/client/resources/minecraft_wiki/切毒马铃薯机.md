* *切毒马铃薯机（Poisonous Potato Cutter）**是用于将[毒马铃薯](毒马铃薯.md)加工为[生毒马铃薯片](生毒马铃薯片.md)或[生毒马铃薯条](生毒马铃薯条.md)的方块。

# 生成
切毒马铃薯机不会生成在世界中。

# = 合成 =

# 破坏
挖掘切毒马铃薯机的合适工具是[镐](镐.md)。切毒马铃薯机需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

切毒马铃薯机被破坏后会掉落自身。

# 用途
# = 切毒马铃薯 =
切毒马铃薯机可用于将[毒马铃薯](毒马铃薯.md)加工为[生毒马铃薯片](生毒马铃薯片.md)或[生毒马铃薯条](生毒马铃薯条.md)。
