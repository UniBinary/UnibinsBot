# Java版18w22a

*页面ID: 34821* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w22a**是[Java版1.13](Java版1.13.md)的第40个快照，发布于2018年5月29日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[树叶](树叶.md)**
* 自然生成的树叶最多可在距离原木6格的距离不会消失，而不是4格。
* * 树叶的方块状态中，<code>check_decay</code>和<code>decayable</code>两个布尔型变量变为<code>distance</code>（范围1-7）和一个<code>persistent</code>布尔型变量。

* *[海龟蛋](海龟蛋.md)和[海泡菜](海泡菜.md)**
* 如果在一个堆叠内放置更多数量时，在玩家进入它的碰撞箱内时会导致放置失败。
* 在一个堆叠内增加数量时现在会发出放置的声音。
* 可通过瞄准相邻的方块放置更多的堆叠。
* 右键它们不再使手摆动。
* 海泡菜现在需要方块支撑。

# = 物品 =
* *[热带鱼桶](热带鱼桶.md)**
* 更改了纹理。

# = 生物 =
* *[马](马.md)**
* 更改了奶白色马的纹理。
* 更改了装备了铁马铠的马的纹理。
