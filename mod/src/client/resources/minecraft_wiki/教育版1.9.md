# 教育版1.9

*页面ID: 41813* | *来源: Minecraft Wiki*

* *1.9.0**（Windows）、**1.9.1**（macOS）或**1.9**（iOS）是**[春季更新](春季更新.md)**的首个正式版，也是的一次更新，发布于2019年3月27日。此版本加入了来自[基岩版1.8.0](基岩版1.8.0.md)和[1.9.0](基岩版1.9.0.md)的[村庄与掠夺](村庄与掠夺.md)的特性。<ref name=release></ref>

# 新内容
# = 方块 =
* *[竹子](竹子.md)**
* 可以通过在[丛林](丛林.md)生物群系中钓鱼时获得，并且可在一些[箱子](箱子.md)中找到。

* *[脚手架](脚手架.md)**
* 新的可攀爬的[方块](方块.md)，可通过使用竹子[合成](合成.md)而成。

* *[花](花.md)**
* 加入[矢车菊](矢车菊.md)。
* * 可以合成[蓝色染料](蓝色染料.md)。
* * 在[平原](平原.md)生成。
* 加入[铃兰](铃兰.md)。
* * 可以合成[白色染料](白色染料.md)。
* * 在[森林](森林.md)生成。

* *[告示牌](告示牌.md)**
* 加入了各种木质变种：云杉木、白桦木、金合欢木、丛林木和深色橡木。

* *平滑方块**
* 加入[平滑石头](平滑石头.md)。平滑砂岩、平滑红砂岩和平滑石英块。

* *[台阶](台阶.md)**
* 加入石头、安山岩、磨制安山岩、闪长岩、磨制闪长岩、花岗岩、磨制花岗岩、苔石砖、苔石、平滑砂岩、平滑红砂岩、平滑石英、红下界砖和末地石砖台阶。
* 加入切制砂岩和切制红砂岩台阶。

* *[楼梯](楼梯.md)**
* 加入石头、安山岩、磨制安山岩、闪长岩、磨制闪长岩、花岗岩、磨制花岗岩、苔石砖、苔石、平滑砂岩、平滑红砂岩、平滑石英、红下界砖和末地石砖楼梯。

* *[墙](墙.md)**
* 加入砖、安山岩、闪长岩、花岗岩、海晶石、石砖、苔石砖、砂岩、红砂岩、下界砖、红下界砖和末地石砖墙。

# = 物品 =
* *新的[染料](染料.md)物品**
* 加入[白色染料](白色染料.md)、[蓝色染料](蓝色染料.md)、[棕色染料](棕色染料.md)和[黑色染料](黑色染料.md)。
* 之前能染色的物品（[骨粉](骨粉.md)、[青金石](青金石.md)、[可可豆](可可豆.md)和[墨囊](墨囊.md)）仍可用来染色。

* *[刷怪蛋](刷怪蛋.md)**
* [熊猫](熊猫.md)
* [猫](猫.md)

# = 生物 =
* *[熊猫](熊猫.md)**
* 在丛林中生成。
* 食用[竹子](竹子.md)和[蛋糕](蛋糕.md)物品。
* 有非常不同的性格：懒惰、贪玩、攻击型或焦虑。
* 有一个罕见的棕色变种。

* *[流浪猫](流浪猫.md)**
* 在[村庄](村庄.md)中生成。
* 可使用[鱼](鱼.md)来驯服。
* 会给予玩家“礼物”。
* 有可以被染色的项圈，类似[狼](狼.md)。

* *友好生物**
* 现在会随机进入交配模式。

# 更改
# = 方块 =
* *[苔石](苔石.md)**
* 英文名称被更改为“Mossy Cobblestone”，原作“Moss Stone”

* *[下界砖栅栏](下界砖栅栏.md)**
* 合成配方被改为4个下界砖块和两个下界砖物品。
* * 原先的合成配方现在用于合成[墙](墙.md)。

* *平滑砂岩和平滑红砂岩**
* 现在被分别改名为切制砂岩和切制红砂岩。

* *[告示牌](告示牌.md)**
* 现在名称被改为橡木告示牌。
* * 橡木告示牌需要橡木木板合成，不再接受其他木板。

* *[石质台阶](台阶.md)**
* 现在被改名为平滑石台阶，并且需要用平滑石头合成，而不是普通石头。
* * 原先的合成配方现在用于合成石头台阶。

* *[砂岩](砂岩.md)和[红砂岩](红砂岩.md)楼梯和台阶**
* 合成时不能配用各种砂岩，而需要同一种砂岩。

* *[炼药锅](炼药锅.md)**
* 现在可以用于盛放[熔岩](熔岩.md)。
* * 会燃烧在内的实体；会发光。

* *[绊线钩](绊线钩.md)**
* 在被破坏时发出信号，除非使用[剪刀](剪刀.md)来破坏。

* *[羊毛](羊毛.md)**
* 把白色羊毛的英文名称“white colored wool”改为“white wool”。

* *[命令方块](命令方块.md)**
* 现在默认名称为“!”而不是“@”。

* *[浮冰](浮冰.md)**
* 加入合成配方。

* *[潜影箱](潜影箱.md)**
* 加入未染色的潜影箱的合成配方，

# = 物品 =
* *[木棍](木棍.md)**
* 现在可以使用竹子合成而得。

* *[弓](弓.md)**
* 弓在被拉时，快捷栏会有显示。

* *[染料](染料.md)**
* “蒲公英黄”、“玫瑰红”和“仙人掌绿”被分别重命名为“黄色染料”、“红色染料”和“绿色染料”。

* *[烟花火箭](烟花火箭.md)**
* 现在可以被放在[副手](副手.md)上。

# = 生物 =
* *[幻翼](幻翼.md)**
* 现在会怕猫，不会在有猫的地方突袭。

* *[热带鱼](热带鱼.md)**
* 更改了热带鱼的大小。

* *[骷髅马](骷髅马.md)和[僵尸马](僵尸马.md)**
* 使用[刷怪蛋](刷怪蛋.md)时，有概率生成小马。

* *[豹猫](豹猫.md)**
* 不再能被驯服
* [玩家](玩家.md)仍可通过向它们喂食来获得它们的“信任”。
* 现在可使用河豚和热带鱼来喂食豹猫。

# = 世界生成 =
* 现在生成[沼泽小屋](沼泽小屋.md)会有一只黑猫。
* [竹子](竹子.md)可以在[沉船](沉船.md)和[丛林神庙](丛林神庙.md)的[箱子](箱子.md)里找到。

# = 游戏内容 =
* *[钓鱼](钓鱼.md)**
* 在丛林生物群系的获得物有所改变。
* * 现在在丛林中钓到鱼只会是[生鳕鱼](生鳕鱼.md)和[生鲑鱼](生鲑鱼.md)。
* * [竹子](竹子.md)有概率作为“垃圾”被钓到。

* *[成就](成就.md)**
* 由于豹猫不能被驯服，驯狮者成就的描述从“驯服一只豹猫”变为“增加豹猫的信任”。为了得到这个成就，玩家必须给豹猫喂鱼，直到得到豹猫的信任（发出“爱心”）。

# = 命令格式 =
* *以下[命令](命令.md)可在非作弊情况下执行：**
* <code>/gamerule showcoordinates</code>
* <code>/gamerule dofiretick</code>
* <code>/gamerule tntexplodes</code>
* <code>/gamerule domobloot</code>
* <code>/gamerule naturalregeneration</code>
* <code>/gamerule dotiledrops</code>
* <code>/gamerule pvp</code>
* 现在只有带有调试员许可的玩家可使用游戏规则。
* 用来设置记分板名称的命令现在可被识别。

* *自动填写**
* 玩家提到的自动填写列表现在在斜杠命令中可用。

# = 常规 =
* *可用性**
* 教育版现在可在Windows主机上使用。
* * 使用SCCM或者Intune更新并部署了可用性，与Windows 7、Windows 8.1、和所有Windows 10版兼容。

* *加载界面**
* 现在有加载进度条动画。

* *[皮肤包](皮肤包.md)**
* 在皮肤选择界面中加入更多的皮肤包，并且每个皮肤包有可被打开并查看的界面。

* *[生成](生成.md)**
* 改进了移动生成出生点的方法和时间。

* *[商城](商城.md)**
* 玩家可以使用分享按钮来发送商城的链接。
* 通过商城物品栏的“可用更新”来为内容分类。
* 通过商城评价来为内容分类。

* *游戏指南**
* 加入[脚手架](脚手架.md)的教程。

* *[附加包](附加包.md)**
* 玩家可加入自己的[生物](生物.md)、[粒子](粒子.md)以及更多不需要替代原版特性的内容。

* *[全景图](全景图.md)**
* 更新了全景图。

* *[纹理](纹理.md)**
* [生命提升](生命提升.md)和[伤害吸收](伤害吸收.md)图标现在有不同的外观。

# 修复
* 修复了智能体放置水时使游戏崩溃的漏洞。
* 修复了“对LAN可见”功能的调节。
* 修复了在Windows 10版本1511及以前安装游戏不工作的漏洞。
* 修复了在Windows 10版本1607连接多人游戏失败的漏洞。
* 修复了多种语言在游戏中显示不正确的漏洞。
