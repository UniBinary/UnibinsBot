# 携带版0.15.0.b2

*页面ID: 22032* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.15.0 alpha build 2**是[v0.15.0 alpha](携带版0.15.0.md)的第2个测试版，发布于2016年6月8日<ref></ref>，修复了一些漏洞。

# 更改
* [玩家](玩家.md)不再出生在[树叶](树叶.md)中。
* 恢复了GUI大小的选项。
* 更改了[草径](草径.md)的纹理。
* 更改了[玫瑰](玫瑰.md)和[牡丹](牡丹.md)的纹理。
* 修正[附魔台](附魔台.md)界面的关闭按钮。

# 修复
* *修复了11个漏洞**
* 修复了部分只发生在特定情况下的崩溃。
* 透过按钮移动不再出现窒息现象。
* 使用炼药锅混合颜色时现在会更新水的颜色。
* 被火把或红石火把移除的方块不再使其变成掉落物。
* 修复了可以无限制使用流量数据游玩世界的漏洞。
* 马在空闲状态下会使得骑乘者原地转圈。
* 多人游戏下的蜘蛛骑士保持非敌对状态。
* 触摸设备里的繁殖交互按钮失效。
* 黏性活塞出现漏洞。
* 在床上睡觉时无法打开聊天信息。
* 骑马时图像显示错误。</onlyinclude>
