# 版本类型

*页面ID: 126987* | *来源: Minecraft Wiki*

[Minecraft](Minecraft.md)有多种**版本类型**（或**更新类型**）。在正式版本中，当前更新以小更新为主，并以此为基础发布次要更新与热修复。在发布正式版本前，会发布不同的开发版本测试、更改新功能，或修复漏洞。

# 正式版本
* *正式版本（Release）**是会全量推送给主要发行平台上所有玩家的一类游戏更新。正式版本通常会具有不同数量的[开发版本](#开发版本.md)。

# = 小更新 =
* *小更新（Game Drop**，或简称为**drop）**属主题更新，会包含特定主题的新内容。小更新的内容大小不等，每年会发布3-4次。

小更新的概念初次公布于[犰甲狼兵](犰甲狼兵.md)<ref></ref>，[蝙蝠与陶罐](蝙蝠与陶罐.md)在此概念提出后被追认为小更新。<ref></ref>2024年9月，Mojang宣布调整游戏开发节奏，在此之后使用功能发布更加频繁的小更新替代每年一更的主要更新。<ref></ref>

在旧的版本号系统中，小更新会改变次要版本号，例如[Java版1.21.4](Java版1.21.4.md)更新至[Java版1.21.5](Java版1.21.5.md)，[基岩版1.21.31](基岩版1.21.31.md)更新至[基岩版1.21.40](基岩版1.21.40.md)。

# = 次要更新 =
2024年9月前，**次要更新（minor update）**通常是针对主要更新补充或修改一些少量的游戏内容。例如，[Java版1.16.2](Java版1.16.2.md)与[基岩版1.16.20](基岩版1.16.20.md)是为了将[猪灵蛮兵](猪灵蛮兵.md)补充进[下界更新](下界更新.md)的。

2024年9月后，因小更新的发布更加频繁，一般不会有太多针对小更新游戏内容的补充或修改，而仅会发布修复一些漏洞的热修复。旧版本号系统时，热修复也会更改次要版本号，因此热更新有时也被称为“热修复次要更新（minor hotfix update）”，例如2025年发布的[Java版1.21.7](Java版1.21.7.md)、[Java版1.21.8](Java版1.21.8.md)与[Java版1.21.10](Java版1.21.10.md)。在新版本号系统中，热修复不会再改变Java版的次要版本号，Java版也不再存在次要更新。

次要更新通常会加入Java版趋同特性或在[实验性玩法](实验性玩法.md)中加入下一次小更新的部分特性。例如2025年发布的4次基岩版次要更新：[基岩版1.21.60](基岩版1.21.60.md)、[基岩版1.21.80](基岩版1.21.80.md)、[基岩版1.21.100](基岩版1.21.100.md)与[基岩版1.21.120](基岩版1.21.120.md)。次要更新通常会改变次要版本号，例如[基岩版1.20.30](基岩版1.20.30.md)更新至[基岩版1.20.40](基岩版1.20.40.md)，新版本号系统中则是“26.10”更新至“26.20”。

# = 热修复 =
* *热修复（Hotfix）**是用于正式版本中修复错误或漏洞的更新。有些热修复版本也会加入部分新特性。

在Java版中，旧版本号系统时，热修复也会改变次要版本号，例如[Java版1.21.9](Java版1.21.9.md)更新至[Java版1.21.10](Java版1.21.10.md)。在新版本号系统中，热修复会直接改变热修复序号，例如“26.1”更新至“26.1.1”。

在基岩版中，热修复会改变版本号中的最后一位数字，例如[基岩版1.21.81](基岩版1.21.81.md)更新至[基岩版1.21.82](基岩版1.21.82.md)。

# 开发版本
* *开发版本（Development Version）**是会公开发布，旨在测试新功能、更改或修复漏洞，以便使主要或次要更新发布正式版本的一类游戏版本。开发版本可能会破坏游戏存档。

# = Java版 =
# == 快照 ==
* *快照（Snapshot）**是一个术语，用于描述更新的不稳定开发版本。每次更新或小更新都会发布每周快照，以便让玩家对开发中的功能和更改进行反馈。

第一个快照是2011年[1.1](Java版1.1.md)的[11w47a](11w47a.md)。

# == 预发布版 ==
* *预发布版（Pre-release）**是比快照更稳定的游戏开发版本。一旦开发达到预发布阶段，更新的内容一般就已基本完整。随后的预发布版将专注于漏洞的修复和功能的稳定性。最终的预发布版可能在功能上与正式版本相同（如[1.4.7](Java版1.4.7.md)）。

预发布版最初被用于[Java版Beta 1.8](Java版Beta 1.8.md)的开发，第一个预发布版是[Beta 1.8 Pre-release](Beta 1.8 Pre-release.md)。这时，每周快照还没有启用，所以这个预发布版是[Java版Beta 1.8](Java版Beta 1.8.md)的第一个开发版本。

# == 发布候选 ==
* *发布候选（Release Candidate）**版本是开发版本中的一种，除非发现重大的游戏漏洞，否则它将是正式发布前的最后一个版本<ref></ref>。通常来说，一个版本的正式发布版本与它的最后一个发布候选版本是相同的，不同的只是版本名称字符串。

第一个发布候选版本是2011年[1.0.0](Java版1.0.0.md)的[RC1](RC1.md)。在1.0.0之后，Mojang有很长一段时间没有发布候选版本，直到2020年[Java版1.16-rc1](Java版1.16-rc1.md)发布。

# = 基岩版 =
# == Beta与Preview ==
的开发版本也被称为Beta与Preview。

自[独乐不如众乐更新](独乐不如众乐更新.md)发布以来，的开发版本以Beta的形式发布于Android、Xbox与Windows 10平台。

开发版本在Apple平台上发布时，的开发版本在一些平台被改称为Preview，仅Android和ChromeOS平台上还保留着Beta的名称。

Beta与Preview通常会在周二、周三或周四发布。

# 已过时
# = 主要更新 =
* *主要更新（major update）**是指为游戏添加大量新游戏内容的更新。主要更新通常会以[生物群系](生物群系.md)或[结构](结构.md)等特定内容为更新主题，且更新内的大部分游戏内容都会契合更新主题。例如，[棘巧试炼](棘巧试炼.md)中几乎所有新游戏内容都与[试炼密室](试炼密室.md)直接相关或作为其组成部分。

在旧的版本号系统中，主要更新通常会改变主要版本号，例如[棘巧试炼](棘巧试炼.md)是从[Java版1.20.6](Java版1.20.6.md)更新至[Java版1.21](Java版1.21.md)，[基岩版1.20.81](基岩版1.20.81.md)更新至[基岩版1.21.0](基岩版1.21.0.md)。

继2024年的[棘巧试炼](棘巧试炼.md)后，Mojang没有再继续发布过主要更新。

# = Java预览版 =
Java版的**预览版（Preview）**是一类Mojang提供给[*Hat Films*](https://youtube.com/c/hatfilms)、[*PC Gamer*](https://www.pcgamer.com/minecraft-halloween-update-hands-on/)和[*Indiegames*](http://www.indiegames.com/2010/10/handson_with_the_minecraft_hal.html)用来制作游戏更新宣传片或文章的开发版本。[Alpha v1.2.0](Java版Alpha v1.2.0-preview.md)、[Beta 1.6](Java版Beta 1.6.md)、[Beta 1.7](Java版Beta 1.7.md)与[Beta 1.8](Java版Beta 1.8.md)这四个版本都曾有过预览版。

# = Java版Test Build =
Java版的**Test Build**是开发版本中的一种，目前唯一已知的Test Build版本是[Beta 1.6 Test Build 3](Java版Beta 1.6 Test Build 3.md)。

# = Java版实验性快照 =
Java版的**实验性快照（Experimental Snapshot）**是Mojang在标准快照开发周期之前使用的一种特定的快照类型。这些版本包含比标准快照更多的不稳定性内容更改。

实验性快照首先在[1.18](Java版1.18.md)中使用。而自1.18中使用实验性快照以来，实验性快照只在[1.19](Java版1.19.md)中使用过一次。这种类型的快照已经过时了，因为现在的标准快照中会包含[实验性内容](实验性内容.md)。

# = 携带版Build与alpha =
携带版的**Build**是在Android平台上使用的开发版本。在[携带版Alpha](携带版Alpha.md)阶段结束后，alpha被用作[携带版1.0.0](携带版1.0.0.md)与[1.1.0](携带版1.1.0.md)的开发版本名称。

# 其他
# = 愚人节更新 =
Mojang通常会在愚人节（4月1日）发布的玩笑性质的**[愚人节更新](愚人节玩笑.md)**。该版本通常基于某个特定主题，以Java版快照的形式发布。

# = 秘密更新 =

* *秘密更新（Seecret Update）**是[Notch](Notch.md)在[Minecraft](Minecraft.md)的[Infdev](Java版Infdev.md)和[Alpha](Java版Alpha.md)开发阶段中发布的一系列十个更新，一般不会有通知。它们以发布当天的星期来命名。

# = 开发者版本 =

* *开发者版本（Developer Build）**或**内部版本（Internal version）**，是指开发过程中不打算对外发布的内部测试版本。
