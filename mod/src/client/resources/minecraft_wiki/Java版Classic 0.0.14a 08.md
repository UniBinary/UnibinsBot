# 更改
# = 方块 =
* *[水](水.md)和[熔岩](熔岩.md)**
* 现在受环境光遮蔽。<ref>[IRC日志](#logs.md): "*[14:43] <@notch> a free bonus is that shadows now show up on water surfaces :D*" (20:43 UTC)</ref>

* *[树苗](树苗.md)**
* 现在在阴影处时的外观是高亮的，而在选择时变为隐形。

# = 常规 =
* *其他**
* 加载[pre-Classic](Java版pre-Classic.md)版本的世界会导致世界重新生成。
* 提高了帧率。<ref name="release"/>
