# Java版Classic服务器1.8.3

*页面ID: 45325* | *来源: Minecraft Wiki*

* *1.9**（原**1.8.3**）是[Classic](Java版Classic.md)服务器的一次更新，发布于2009年10月27日。<ref></ref>

此版本的文件将其标记为"**1.8.3**"，但版本1.9.1将其重新标记为"1.9"<ref name="README"/>。

# 新内容
# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 为生存模式下的多人游戏添加了支持。
* * 由于正在开发，故未在网站公开列出。

# = 常规 =
* *[服务器](服务器.md)**
* 为[0.28](Java版Classic 0.28.md)的所有特性添加了服务器支持。

# 修复
* *修复了1个漏洞**
* 修复了有人使用非法名称登录服务器时导致玩家断开连接的漏洞。<ref name="README"/>
