# 服务器列表

*页面ID: 9033* | *来源: Minecraft Wiki*

[400px|缩略图|右|Java版[[多人游戏](File:Server-list.png.md)中的服务器列表]]

在Minecraft[多人游戏](多人游戏.md)中包含了一份**服务器列表（Server list）**，玩家可以在其中保存其玩过的服务器信息。

并没有预置一份服务器列表，在[Minecraft 官方网站](http://www.minecraft.net/)中也找不到类似信息。但是在独立的Java版[启动器](启动器.md)中支持向多人游戏中添加服务器的功能，可以使玩家得以获悉服务器是否在线，服务器最大容量以及服务器与你之间的网络连接程度（ping时间），鼠标悬停至服务器列表中连接状态图标时，会为玩家显示与该服务器之间的连接速度。

服务器列表中包含了[精选服务器](精选服务器.md)部分，它们与[Mojang Studios](Mojang Studios.md)进行合作。

# 寻找非官方服务器
有一些网站允许服务器所有者公开发布服务器，并且列出有关这些服务器的IP地址和其他信息。

# 服务器排序
服务器以可更改的顺序在列表中显示。要更改服务器在列表中的显示顺序，请将鼠标悬停在要移动的服务器上，然后使用箭头在列表中向上或向下移动服务器。或者，你可以按住并使用方向键进行调整。

服务器总是有序排列的。
