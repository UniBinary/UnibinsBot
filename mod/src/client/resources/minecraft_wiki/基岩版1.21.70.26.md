# 基岩版1.21.70.26

*页面ID: 147032* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.70.26**（ChromeOS/Android）、**Preview 1.21.70.26**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.70](基岩版1.21.70.md)的第6个测试版，发布于2025年3月5日<ref></ref>，更新了[全景图](全景图.md)，并修复了一些漏洞。

# 更改
# = 常规 =
* *[聊天](聊天.md)**
* 回退了1.21.70.25中对过滤列表的更新。

* *[全景图](全景图.md)**
* 更新了主菜单全景图以匹配[春意盎然](春意盎然.md)。

# = 技术性 =
* *刷怪蛋**
* 修复了加入新的刷怪蛋纹理后僵尸村民实体文件名的最后部分与之前版本不匹配的问题。（）

# 修复
* *效果**
* 修复了潜影弹会错误施加200秒的飘浮，而非预期的10秒飘浮的问题。（）

* *游戏内容**
* 收纳袋被盔甲架手持后不再会变成空的。（）

* *生物**
* 修复了被某些玩家用来制作无敌“宠物”生物的旧版喷溅药水漏洞。在1.21.70.24或更高版本的世界中，任何已有的无敌生物现在均会正确死亡和消失。（）

* *用户界面**
* 移除了服务器选项卡中的服务器IP地址。（）</onlyinclude>
