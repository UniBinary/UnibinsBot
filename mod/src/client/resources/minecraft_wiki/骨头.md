# 骨头

*页面ID: 484* | *来源: Minecraft Wiki*

* *骨头（Bone）**是一种主要从[骷髅](骷髅.md)掉落的[物品](物品.md)。

# 获取
# = 箱子战利品 =

# = 掉落物 =

# = 钓鱼 =
骨头在[钓鱼](钓鱼.md)时可以作为垃圾钓出。最高概率是在没有海之眷顾和饵钓[魔咒](魔咒.md)时达到，为1.1%。

# 用途
# = 驯服 =
骨头可用于驯服[狼](狼.md)，每使用一次有的概率驯服。骨头无法驯服敌对的狼。

# 你知道吗
<div style='float:right'></div>
* 若使用命令将骨头放入玩家的头盔槽，它会横向出现在玩家嘴部，看起来像是把骨头衔着。可在了解更多此类彩蛋。
* 玩家和一些人-{}-形生物手持长条状物品（骨头、[竹子](竹子.md)、[木棍](木棍.md)、[调试棒](调试棒.md)、[烈焰棒](烈焰棒.md)、[旋风棒](旋风棒.md)）的方式和手持工具类似。
