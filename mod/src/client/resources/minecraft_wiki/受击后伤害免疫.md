# 受击后伤害免疫

* *受击后伤害免疫（Post Hit Damage Immunity**，简称**PHDI）**是一个适用于所有[生物](生物.md)的效果，会降低生物从高频率伤害源中受到的最终伤害。

# 机制
受击后伤害免疫最先对伤害值进行调整，先于所有其他效果，受击后伤害免疫阶段调整时，减去的是被[盔甲](盔甲.md)的护甲值与其[保护](保护.md)魔咒、[抗性提升](抗性提升.md)效果等因素影响之前的伤害值。

受击后伤害免疫最后对伤害值进行调整，晚于其他所有效果，受击后伤害免疫阶段调整时，减去的是被[盔甲](盔甲.md)的护甲值与其[保护](保护.md)魔咒、[抗性提升](抗性提升.md)效果等因素影响之后的伤害值。

在[生物](生物.md)没有处于受击后伤害免疫状态时，受到任何伤害之后，其**无懈可击时间（Invulnerable Time）**会被设置为，其**最后伤害**设置为伤害值。无懈可击时间内，生物的外观呈红色，即处于受击后伤害免疫状态。

在这段时间内，如果生物再次受到了伤害，则计算这次伤害与最后伤害的差值（若低于则视为），然后受到等同于差值的伤害。并且若这次伤害大于最后伤害，最后伤害会被设置为该伤害值。

无懈可击时间结束后，生物的外观恢复，同时清除最后伤害。

# = 常见影响 =
如果一个生物受到了伤害，在无懈可击时间内又受到了伤害（在被降低后为伤害），则生物最终总共会受到伤害。

如果一个生物受到了伤害，在无懈可击时间内又受到了伤害（在被降低后为伤害），则生物最终总共会受到伤害。

如果一个生物每一刻都受到伤害，在获得无懈可击时间后有9刻中的伤害都会被降低至伤害。最终无懈可击时间会回到0，然后再次受到伤害。这使每一刻都造成固定伤害的效果（如危险环境）的伤害频率被限制为才能造成一次伤害。

如果一个生物受到了伤害，然后每一刻都受到比上一刻受到伤害增加的伤害，那么生物将每一刻都受到伤害，直到无懈可击时间结束。

由于和（击中[亡灵生物](亡灵生物.md)时）造成的弹射物伤害和魔法伤害是两次不同的伤害，受击后伤害免疫会使这两次伤害中只有伤害值更大的一个会生效。例如，一支从拥有[](力量（魔咒）.md)V魔咒的[弓](弓.md)射出的伤害之箭II能够对没有盔甲的目标造成伤害，其[瞬间伤害](瞬间伤害.md)II效果造成的伤害会因为受击后伤害免疫而降低至（最终总计仍受到伤害）。

# = 对护甲值伤害调整效果的影响 =
由于受击后伤害免疫最先对伤害值进行调整，先于所有其他效果。并且[护甲值](护甲值.md)的伤害减免比例取决于伤害值，使用被受击后伤害免疫调整过的伤害值，受击后伤害免疫的这一行为会导致非常奇怪的伤害值结果。

继续以上述情况为例，一整套（无附魔的）钻石盔甲给予的护甲值和8点盔甲韧性能够将弹射物伤害降低到只有约伤害。

但药箭效果造成的伤害仍与箭的弹射物伤害进行计算，使得此次效果造成的伤害依然为（最终总计仍受到伤害）；但轻微拉弓则会发射出只有约弹射物伤害的箭，药箭效果造成的伤害就会被减少为约，使得最后造成的伤害大于拉满弦时。而如果将钻石盔甲替换为全套附魔[弹射物保护](弹射物保护.md)的下界合金盔甲，此种现象则会更加明显。

而此时上述事例中拉满弦时，瞬间伤害II效果造成的伤害会在箭伤害修正结束后补齐应有的伤害，使最终总伤害达到。

再以全套附魔[保护](保护.md)IV下界合金盔甲为例：
* 药箭的弹射物伤害和魔法伤害会先进行受击后伤害免疫调整伤害到和，随后弹射物伤害被盔甲和保护魔咒影响降低至。
* 药箭的弹射物伤害和魔法伤害会先分别被盔甲和保护魔咒影响降低至和，随后进行伤害免疫分别调整伤害到和。

另一个例子是的[守卫者](守卫者.md)的激光攻击，该攻击对目标依次造成2个伤害：
# 在简单、普通、困难难度下分别造成魔法伤害，不会被护甲值降低。
# 在简单、普通、困难难度下分别造成生物伤害，会被护甲值降低。

目标先受到，进入受击后伤害免疫状态，然后再受到第二个攻击，被减去最后伤害后变为。此时目标若有护甲值，第二个伤害会变为，最终伤害为。

# 外部影响
一些其他的游戏内容会根据生物的受击后伤害免疫状态决定其行为，这些行为并不是受击后伤害免疫实现的。
* 生物发动[近战攻击](近战攻击.md)时，若最终的近战攻击力不高于被攻击生物的最后伤害，近战攻击会失败。
* [箭类弹射物](弹射物#箭类弹射物.md)不能击中受击后伤害免疫中的生物。
