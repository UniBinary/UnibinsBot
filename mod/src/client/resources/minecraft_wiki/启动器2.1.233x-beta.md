# 启动器2.1.233x-beta

*页面ID: 67051* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.1.2337-beta**（[Windows](wzh:Microsoft Windows.md)）、**2.1.2338-beta**（[macOS](wzh:macOS.md)）或**2.1.2339-beta**（[Linux](wzh:Linux.md)）是一个[启动器](启动器.md)更新，发布于2019年2月6日，修复了一些漏洞。

# 添加
* 在“设置”页面添加了一个接收beta更新的开关。
* 添加了一个改进了性能的游戏日志窗口。

# 修复
* 修复了与链接和UNC文件夹路径相关的漏洞。
* 修复了版本页面上缺失Bootstrap版本信息的漏洞。
*  - 灰色按钮上的长文本不居中，悬停在其上方时移动。
*  - 启动程序在打开后不打开窗口。
*  - 不支持UNC路径游戏目录。
*  - 不会在现有上启动Minecraft。
*  - 如果列表中的条目超过十个，则配置文件的顺序错误。
*  - 启动器未正确排序配置文件。
*  - 如果文件夹在中是符号链接，则无法启动。
*  - 在自定义Java可执行程序路径中不能使用硬链接。
*  - 对于非Mojang托管的JAR，beta启动器在404错误时中断。</onlyinclude>
