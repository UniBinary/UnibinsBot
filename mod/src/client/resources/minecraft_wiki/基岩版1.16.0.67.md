# 基岩版1.16.0.67

*页面ID: 63897* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.0.67**是[基岩版1.16.0](基岩版1.16.0.md)的第17个测试版，发布于2020年6月11日<ref></ref>，移除了一些平台上内嵌的Xbox浏览器，加入了新的添加好友界面UI，并修复了一些漏洞。

# 新内容
* *UI**
* 在Android/iOS上移除了内嵌的Xbox浏览器，加入了以Minecraft UI为元素的添加好友界面。

# 修复
* *修复了4个漏洞**
* 修复了当尝试登入Xbox Live/Microsoft账号可能发生的崩溃 （）（）
* 修复了当尝试离线登录时可能发生的崩溃（）
* 修复了各种任天堂Switch登录和账号链接的问题（）
* 修复了有时会阻止在移动设备上正确发送/接收游戏邀请的问题</onlyinclude>
