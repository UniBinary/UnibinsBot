# 携带版1.1.3

*页面ID: 30607* | *来源: Minecraft Wiki*

* *1.1.3**是携带版的一次次要更新，发布于2017年7月6日<ref></ref>，加入了岩浆块、骨块、下界疣块、红色下界砖块、化石和商城的新内容，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[岩浆块](岩浆块.md)**
* 自然生成于下界。
* 非下界生物站在其上面会受伤。

* *[骨块](骨块.md)**
* 可用于储存[骨粉](骨粉.md)。
* 作为[化石](化石.md)的一部分自然生成。

* *[下界疣块](下界疣块.md)**
* 通过使用9个[下界疣](下界疣.md)合成。
* 不可拆解，因此仅用于装饰。

* *红色[下界砖块](下界砖块.md)**
* 下界砖块的红色变种。
* 通过使用[下界砖](下界砖.md)和下界疣合成。

# = 世界生成 =
* *[化石](化石.md)**
* 自然生成于[沙漠](沙漠.md)和[沼泽](沼泽.md)生物群系的地下。
* 由[骨块](骨块.md)和[煤矿石](煤矿石.md)组成。

# = 常规 =
* *商城**
* 混搭包
* Noxcrew的《Summer Mini-Games Festival》
* Imagiverse的《Wisteria Grove》
* Imagiverse的《The Kingdom of Torchwall》

# 更改
# = 常规 =
* *[附加包](附加包.md)**
* 更新的资源包和行为包已在minecraft.net/addons上可用。
* 所有行为组件和AI目标参数现在出现在文档中。

# 修复
* *修复了2个漏洞**
* 修复了一些崩溃问题，并提升了稳定性。
* 将方块放置在旧世界类型世界的边界处时，游戏崩溃。
