# 镶金黑石

*页面ID: 58514* | *来源: Minecraft Wiki*

* *镶金黑石（Gilded Blackstone）**是[黑石](黑石.md)的变种方块，挖掘后会掉落自身或[金粒](金粒.md)。

# 生成
# = 自然生成 =
镶金黑石会在[堡垒遗迹](堡垒遗迹.md)中自然生成。

# 获取
# = 箱子战利品 =

# 破坏
挖掘镶金黑石的合适工具是镐。镶金黑石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，镶金黑石被破坏后有10%的概率掉落2-5个金粒，若挖掘工具具有[时运](时运.md)I则掉落金粒的概率提升至14.29%（），时运II提升至25%，时运III提升至100%，如果没有掉落金粒则掉落自身。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，镶金黑石被破坏后会掉落自身。

# 用途
# = 猪灵 =
在非和平[难度](难度.md)下，无论玩家是否装备了[金质盔甲](盔甲.md)，成年[猪灵](猪灵.md)看见或听见玩家破坏镶金黑石后会与之敌对。

# 你知道吗
* 镶金黑石结合了[黑石](黑石.md)的纹理和[20w13a](20w13a.md)之前的[下界金矿石](下界金矿石.md)的纹理。
* 镶金黑石不属于[矿石](矿石.md)。<ref>：“WAI as gilded blackstone is not a gold ore and cannot be smelted into gold ingots.” – Cory Scheviak，2020年4月16日</ref>
