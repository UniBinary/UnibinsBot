# 基岩版1.18.10.26

*页面ID: 91990* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.10.26**是[基岩版1.18.10](基岩版1.18.10.md)的第5个测试版，发布于2022年1月5日<ref></ref>，加入了命令，同步了更多的特性，在[实验性玩法](实验性玩法.md)中加入了[蛙明灯](蛙明灯.md)，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 用于对实体造成伤害。

# 更改
# = 方块 =
* *[发光地衣](发光地衣.md)**
* 现在发出的光的[亮度](亮度.md)等级为7，而不是10。

# = 生物 =
* *[铁傀儡](铁傀儡.md)**
* 现在会根据自身的生命值在纹理上表现不同程度的开裂。
* 现在仅会主动攻击在[村庄](村庄.md)中声望过低的玩家。

* *[村民](村民.md)和[流浪商人](流浪商人.md)**
* [交易](交易.md)时其头顶不再会出现绿宝石图标。

# = 物品 =
* *[铁锭](铁锭.md)**
* 现在可用于治疗[铁傀儡](铁傀儡.md)，以同步。

# = 世界生成 =
* *[雪林](雪林.md)**
* 现在[松树](松树.md)会生成于此。

* *[熔岩湖](熔岩湖.md)**
* 现在在地下只能生成于Y=0以上。

# = 游戏内容 =
* *[交易](交易.md)**
* 更改了[屠夫](屠夫.md)、[制图师](制图师.md)、[图书管理员](图书管理员.md)和[流浪商人](流浪商人.md)的交易选项以匹配。
* * 屠夫不再会出售[熟兔肉](熟兔肉.md)、[熟羊肉](熟羊肉.md)和[牛排](牛排.md)。
* * 制图师现在会出售[地球旗帜图案](地球旗帜图案.md)，不再会出售[花朵盾徽旗帜图案](花朵盾徽旗帜图案.md)、[砖纹旗帜图案](砖纹旗帜图案.md)和[波纹边旗帜图案](波纹边旗帜图案.md)。
* * 图书管理员现在会购买2个[书与笔](书与笔.md)，而不是1个。
* * 流浪商人不再会出售[向日葵](向日葵.md)、[丁香](丁香.md)、[玫瑰丛](玫瑰丛.md)和[牡丹](牡丹.md)。

# = 常规 =
* *[RenderDragon](RenderDragon.md)**
* 再次禁用（仅Android平台）。

# 修复
* *实验性**
* 青蛙和蝌蚪现在拥有自己的音效。（）
* 青蛙现在会以正确的速度逃离。
* 发光地衣不再可以放置在青蛙卵上。

* *性能与稳定性**
* 修复了退出世界时区块中的实体无法被保存的问题。（）
* 现在加载出生点周围有恶地生物群系生成的特定种子世界时，游戏不再会崩溃。（）

* *原版趋同**
* 铁傀儡现在会根据自身的生命值在纹理上表现不同程度的开裂，并且铁锭现在可用于治疗铁傀儡。（）
* 发光地衣现在拥有与Java版相匹配的光照等级。
* 狐狸现在会在扑向猎物时向下锁定目标。（）
* 移除了与村民交易时其头顶上的绿宝石图标。
* 更新了屠夫、制图师、图书管理员和流浪商人的交易选项。
* 铁傀儡现在仅会主动攻击在村庄中声望过低且攻击过村民的玩家。

* *辅助功能**
* 现在文本转语音（TTS）能够正确读取实验性玩法选项的名称。

* *命令**
* 使用或命令放置可可豆时不再会导致出错。

* *地物生成**
* 大型滴水石地物的底部不再会在熔岩中悬浮生成。（）
* 滴水石簇中不再会生成仅1格高的石笋。（）

* *熔炉**
* 现在高炉和烟熏炉又会正确给予经验了。（）

* *游戏内容**
* 现在滴水石锥有概率生成在大型钟乳石和大型石笋结构中。（）
* 熔岩湖现在仅在Y坐标为正数的地方生成。（)
* * 接近Y=0处的熔岩湖仍会生成交叉的石头和深板岩外边。
* 珊瑚现在会在暖水海洋的更深处生成。（）
* 现在雪林生物群系中会生成更多种类的树。（）
* 修复了使用VR游玩时无法更改光源方块的亮度等级的问题。
* 修复了按住鼠标右键并移动时无法连续放置光源方块的问题。（）
* 光源方块现在会正确含水。（）
* 修复了附近生物数量过多时破坏方块、打开箱子或进入传送门会出现延迟或无响应的问题。（）
* 现在破坏草和大型花时会出现正确的动画。（）
* 含雪的花现在会正确被爆炸破坏。（）
* 骷髅马骑士现在会正确寻路。（）

* *世界生成**
* 冰山地物不再能够代替雪屋结构的雪块生成。（）
* 露天洞穴中的水不再会不均衡生成。（）
* 含水层在生成时不再会丢失其中的水。（）

* *技术性**
* 重新加入了命令重命名为的更改。（）
* 现在JumpToBlockGoal会在寻找时正确向上和向下搜索相同距离，以允许生物使用相同高度的目标。
* 加入了具有相同名称但命名空间不同的方块的支持。
* 修复了动画控制器递归检查会错误禁止控制器正常反复使用的问题。
* 修复了资源包设置界面中的上下箭头按钮会在高亮显示时变大的问题。（）</onlyinclude>
