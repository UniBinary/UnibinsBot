# 命令/debugdim

*页面ID: 108205* | *来源: Minecraft Wiki*

保存[维度](20w14∞#世界生成.md)数据。

# 用法
执行命令后，会在世界存档的文件夹中生成多个文件，包括：
* 一个，存储此维度的维度类型编号、维度使用的生成器（包括地形生成器和生物群系源）、默认方块、默认流体、迷雾渲染数据、阴影渲染数据和昼夜更替的周期。
* 一个或多个，存储用于生成该维度中的生物群系的数据，每个生物群系对应一个文件。

# 语法
   <code>debugdim</code>

# 结果
永远执行成功。
