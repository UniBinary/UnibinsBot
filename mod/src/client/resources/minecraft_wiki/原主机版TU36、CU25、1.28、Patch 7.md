# 原主机版TU36、CU25、1.28、Patch 7

*页面ID: 68111* | *来源: Minecraft Wiki*

* *TU36/CU25/1.28/Patch 7**是[原主机版](原主机版.md)的一次更新，发布于2016年6月21日，加入了一些特性，并修复了6个漏洞。<ref></ref><ref></ref>

# 新内容
* 加入了对战小游戏。
* 更新了更多皮肤。
* 在控制界面加入Safe Sprint的选项。根据所选的控制布局，此选项可以将“更改视角模式”或“潜行/下马（矿车）”移动远离摇杆按钮，因为很多人在开始跑步时会意外按下摇杆。
* 启用了战斗地图和季节DLC。
* 新增了洞穴、峡谷和超平坦地形。
* 通过切换按钮添加了“分发物品”功能（开始并确认分发）。这允许一组物品通过在物品栏的多个槽中拉动这组物品。

# 修复
* *修复了6个漏洞**
