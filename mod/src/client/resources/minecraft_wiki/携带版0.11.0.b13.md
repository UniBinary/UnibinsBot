# 携带版0.11.0.b13

*页面ID: 27879* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 13**是[v0.11.0 alpha](携带版0.11.0.md)的第13个测试版，发布于2015年5月22日，修复了一些漏洞。

# 更改
# = 游戏内容 =
* *[创造模式物品栏](创造模式物品栏.md)**
* 重新在创造模式物品栏加入了所有工具。

# 修复

* *其他漏洞**
* 加载区块时游戏经常崩溃。
* 创建实体时游戏崩溃。
* 修复了一些本地化漏洞。
* 修复了世界边界外实体的光照漏洞。</onlyinclude>
