# 开发资源

*页面ID: 6669* | *来源: Minecraft Wiki*

Minecraft 是用Java编写的，则是用C++编写的。尽管其源代码经过混淆，但社区已经了解Minecraft的大多数代码是如何运作的。随着官方[混淆映射表](混淆映射表.md)的发布，的绝大多数代码已经可读。从26.1-snapshot-1开始，Java版代码不再被混淆。Notch给出了关于Minecraft所使用的[NBT格式](NBT格式.md)笔记。对此，社区已经得到了使用NBT格式文件的信息。

# NBT格式
[NBT格式](NBT格式.md)几乎用于所有Minecraft中的文件。它是一个由**标签**组成的经过GZip压缩或的树状结构，每个标签具有类型、名称和基于类型的负载。

# 存档格式
每个Minecraft的版本都有自己的存档格式。以下的信息是介绍不同的存档格式，可让软件开发者用来创建[地图编辑器](辅助程序与编辑器.md)、服务器、地图生成器及其他程序。
[方块](方块.md)、[物品](物品.md)和[数据值](数据值.md)是各存档共通的。

* [Classic世界格式](Classic世界格式.md)被旧的[Classic](Java版Classic.md)版Minecraft所使用：[生存模式](生存模式.md)、[创造模式](创造模式.md)以及[多人游戏](多人游戏.md)。
* [Indev世界格式](Indev世界格式.md)用于[Indev](Java版Indev.md)版。
* [Alpha世界格式](Alpha世界格式.md)用于[Alpha](Java版Alpha.md)版（旧称[Minecraft Infdev](Java版Infdev.md)）。
* [Java版存档格式](Java版存档格式.md)用于Minecraft[Java版](Java版.md)。
* * [玩家数据格式](玩家数据格式.md)用于存储玩家的状态。
* * [区域文件格式](区域文件格式.md)用于存储各个区块内的数据。
* ** [区块存储格式](区块存储格式.md)用于包含在区域中的单独的16×384×16区块。
* * [地图存储格式](地图存储格式.md)用于存储可合成的[地图](地图.md)物品的颜色。
* * [Villages.dat格式](Villages.dat格式.md)用于存储地图中村庄的状态。
* * [结构存储格式](结构存储格式.md)用于存储[结构方块](结构方块.md)保存的结构.
* [基岩版存档格式](基岩版存档格式.md)用于Minecraft[基岩版](基岩版.md)。

# 其他格式
* [服务器列表存储格式](服务器列表存储格式.md)用于存储保存的多人服务器列表。
* [Schematic档案](Schematic文件格式.md)是一种基于[NBT](NBT.md)的格式，用于第三方应用程序储存地图的某段区域以便之后使用。

# 程序库
这些是由社区创建的库，用于各类文件与Minecraft进行交互。

# Mod编写工具
* [Minecraft编辑者包](Minecraft Coder Pack.md)即Minecraft Coder Pack，简称MCP，用于编写所有单机或多人Mod的基本程序。
* [MCAnimator](http://www.minecraftforum.net/forums/mapping-and-modding/minecraft-tools/2187221-1-2-1-mcanimator-windows-mac-linux-better) - 一个全新的建模工具：用于创建可以具有纹理和动画的自定义模型。拥有许多工具可以帮助你完成创建过程。你可以导出到所有最新的Minecraft版本。它拥有一个完美的动画控制库。
* [Techne](http://www.minecraftforum.net/viewtopic.php?f=1022&t=217348) - 模型架构器：用于建立能用于游戏的自创模型，并且能使用基本模型的程序。
* [FMCModeler](http://www.minecraftforum.net/viewtopic.php?f=1022&t=269231) 用于建立能用于游戏的自创模型, 亦可从Java程序代码建构出模型（有一些限制）。以Glash写成。此程序似乎已经放弃开发, 但依然可以用于CustomRenderer。
