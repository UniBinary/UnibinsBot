# 穿刺

*页面ID: 35035* | *来源: Minecraft Wiki*

* *穿刺（Impaling）**是一种用于增加[三叉戟](三叉戟.md)造成的伤害的[魔咒](魔咒.md)。

# 获取

# 用途

[魔咒攻击力](近战攻击#魔咒攻击力.md)增加<math>2.5n</math>，其中<math>n</math>为穿刺魔咒等级，仅对或有效，但在基岩版中，接触水对船上的[生物](生物.md)无效。

穿刺与其任何不共存魔咒被应用在同一个物品上时，每个魔咒都会互不干扰地产生效果。

# = 攻击伤害 =
下表列出了每个魔咒等级每次攻击所带来的伤害，括号内为[暴击](近战攻击#暴击.md)伤害，基于以下条件：
* 攻击者基础近战攻击力受主手物品影响前的计算值为1
*
* 攻击目标无[受击后伤害免疫](受击后伤害免疫.md)
* 攻击目标不因[盔甲值](盔甲值.md)、[保护](保护.md)、[抗性提升](抗性提升.md)等因素增加或减少所受伤害

# == Java版 ==
注：暴击不增加魔咒攻击力。

# == 基岩版 ==
注：魔咒攻击力向下取整，暴击增加魔咒攻击力。
