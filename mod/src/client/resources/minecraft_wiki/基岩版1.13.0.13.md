# 基岩版1.13.0.13

*页面ID: 47561* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.13.0.13**是[1.13.0](基岩版1.13.0.md)的第7个测试版，发布于2019年9月12日<ref></ref>，加入了调整屏幕安全区大小的提示以及Xbox One中的新渲染引擎，并修复了一些漏洞。

# 新内容
# = 常规 =
* *屏幕大小**
* 加入了一条新的提示，告知玩家在必要的时候调整屏幕安全区大小。

* *[RenderDragon](RenderDragon.md)**
* Xbox One现在使用新的渲染引擎RenderDragon。

# 修复
* *修复了21个漏洞**<br>
* *崩溃**
* 修复了游戏进行时的崩溃现象。
* 修复了使用命令时游戏崩溃的问题。
* 修复了玩家退出多人游戏时可能发生的崩溃问题。
* 修复了玩家退出多人游戏的同时打开聊天框会发生崩溃的问题。
* 带有无效参数的光源方块不会再导致游戏崩溃。（）

* *性能**
* 优化动画效果以提升性能。
* 针对低内存设备加入新的音符盒音效支持。
* 改善在飞行时区块加载的性能。

* *常规**
* 修复了一些Xbox One的测试版玩家无法正常加载主菜单UI的问题。（）
* 埋藏的宝藏里面的箱子不再生成在村庄结构范围里。
* 修复了一个游玩时会导致一些世界存档损坏的问题。（）

* *生物**
* 农民村民在物品栏有空位时会正常收割作物。（）
* 海龟和热带鱼不再会在海底继续往下钻。
* 袭击中的村民躲藏行动现在更加统一。

* *用户界面**
* 更正了“反馈”与“保存并退出”按钮之间的间隔。

* *图形**
* 修复了鹦鹉坐在玩家肩膀上的位置。

* *命令**
* 目标选择器现在可以正常使用.（）
* 开启了平滑字体显示后可以正常使用混淆文本。

* *附加包和脚本引擎**
* 参数可以正常使用在玩家上。
* 计算方法可以被正确使用。
* 正确的死亡消息可以用在自定义实体上。</onlyinclude>
