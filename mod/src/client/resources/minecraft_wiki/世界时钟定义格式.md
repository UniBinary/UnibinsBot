# 世界时钟定义格式

*页面ID: 182393* | *来源: Minecraft Wiki*

* *世界时钟定义文件**是**世界时钟（World Clock）**在[数据包](数据包.md)中的数据驱动定义文件。

# 定义行为
世界时钟定义数据仅在服务端启动时被加载一次，使用命令不可以使世界时钟定义被重新加载，而必须重启服务端。

世界时钟本身不包含任何数据，游戏使用其ID来区分不同的世界时钟。每个世界时钟都代表了一个内部时间，此时间每[游戏刻](游戏刻.md)都会增加，可以设定是否暂停。世界时钟的时间设定和是否暂停直接受命令管理。

如果游戏规则为<code>false</code>，即使世界时钟没有被暂停也不会随时间增加。

在世界中时，每个[维度](维度.md)都会根据[维度类型](维度类型.md)获取自身的世界时钟，作为命令未显式指定世界时钟的默认值，以及根据使用了此世界时钟的[时间线](时间线.md)来确定使用哪些时间标记。

在世界中时，每个时间线都会根据自身使用的世界时钟来计算环境属性轨道的时间。

存档的运行时间（或称游戏时间，GameTime）不受世界时钟管理。

# = 时间标记 =
* *时间标记（Time Marker）**为世界时钟的特定时间节点赋予了特定名称。时间标记在时间线的内定义，服务端启动时会将其注册到时间线使用的世界时钟上。

时间标记可以在命令中使用。除此之外，游戏定义了下列用于控制游戏行为的时间标记：
* <code>wake_up_from_sleep</code>：玩家睡觉醒来后，游戏将时间快进到的时间。当前维度不存在此时间标记时玩家醒来将不会改变时间。
* <code>roll_village_siege</code>：游戏开始判定[僵尸围城](僵尸围城.md)发生的时间。当前维度不存在此时间标记时不会进行僵尸围城判定。

# 内置世界时钟
游戏中存在2个世界时钟，分别是<code>overworld</code>和<code>the_end</code>。

世界时钟<code>overworld</code>被用于[主世界](主世界.md)维度，且游戏内所有的[内置时间线](时间线定义格式#内置时间线.md)均使用它来计算时间。

世界时钟<code>overworld</code>拥有6个时间标记，这6个时间标记均由时间线<code>day</code>定义：
* <code>day</code>：1000
* <code>noon</code>：6000
* <code>night</code>：13000
* <code>midnight</code>：18000
* <code>wake_up_from_sleep</code>：0，且不在的命令提示中出现
* <code>roll_village_siege</code>：18000，且不在的命令提示中出现

世界时钟<code>overworld</code>也被游戏用于计算[区域难度](区域难度.md)（不存在此世界时钟时始终为0）、固定[调试模式](调试模式.md)世界的时间（不存在此世界时钟时服务端会崩溃，若此世界时钟没有时间标记<code>noon</code>则不会修改时间）。

世界时钟<code>the_end</code>被用于[末地](末地.md)维度，用来计算[末地闪光](末地闪光.md)的出现时间。
