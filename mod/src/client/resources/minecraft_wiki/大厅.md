* *大厅（Hub）**结构是玩家的出生点，也是游戏玩法的核心房间。

# 生成
大厅自然生成于[主世界](主世界.md)中。

# 结构
[thumb|300px|大厅中心房间](File:Hub Center.png.md)
大厅总体上包括主房间和小房间两部分。

主房间包括中心房间和一条回忆长廊，主要由[石头](石头.md)、[天空](天空（方块）.md)和[淡灰色染色玻璃](淡灰色染色玻璃.md)等方块构成，是推进游戏进度的核心场所。

小房间不会主动生成，玩家需要使用[微光钥匙](微光钥匙.md)打开[微光之门](微光之门.md)以解锁小房间。

# = 结构目录 =
大厅的所有结构均位于文件夹<samp>[client.jar](client.jar.md)/data/minecraft/structure/hub</samp>中。

# = 构成 =
# == 主房间 ==
中心房间的长廊部分与回忆长廊存在天空墙，天空墙向上无限延伸，直到世界高度限制下16格（默认为Y=303）。

游戏生成这些结构时，会将所有的基岩替换为天空。

# == 小房间 ==

游戏生成这些结构时，会将所有的基岩替换为天空。
