# 生鲑鱼

*页面ID: 10515* | *来源: Minecraft Wiki*

* *生鲑鱼（Raw salmon）**是一种食物，可以被烹饪成[熟鲑鱼](熟鲑鱼.md)。

# 获取
# = 钓鱼 =
生鲑鱼可以在[钓鱼](钓鱼.md)时作为[鱼](钓鱼#垃圾与宝藏.md)被钓上来。钓上生鲑鱼的概率会随着[海之眷顾](海之眷顾.md)魔咒的等级减少。

# = 生物掉落物 =

# = 箱子战利品 =

# = 礼物 =

[渔夫](渔夫.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷生鲑鱼。

# 用途
# = 食物 =

手持生鲑鱼按住键即可食用，每个生鲑鱼可以回复。

# = 烹饪 =
将生鲑鱼放入[营火](营火.md)、[烟熏炉](烟熏炉.md)或[熔炉](熔炉.md)中烹饪，可以获得熟鲑鱼。

# = 交易 =

# = 豹猫和猫 =
生鲑鱼可以用于驯服流浪[猫](猫.md)，每条有的概率驯服成功。它们也可用于把猫从[箱子](箱子.md)和[床](床.md)等方块上引诱下来、[繁殖](繁殖.md)猫和[豹猫](豹猫.md)、减少幼年猫和豹猫10%的剩余生长时间，以及暂时获得豹猫的信任。另外，每条生鲑鱼可以为猫恢复生命值。

# = 海豚 =
用生鲑鱼喂食[海豚](海豚.md)后，海豚会向距离最近的带[箱子](箱子.md)的[海底废墟](海底废墟.md)或[沉船](沉船.md)游去，给玩家指引方向。喂食生鲑鱼还会提升海豚对玩家的信任，使它们更多地与玩家互动，但不能够使海豚繁殖。

# = 狼 =
生鲑鱼能喂食生命值不满的[狼](狼.md)，一次可以为其治疗。和其他狼可以吃的食物不同的是，生鲑鱼不能用来喂食幼年狼或者加速其生长，因此只能在狼不处于满生命值的状态下食用。

# = 鹦鹉螺和殭屍鸚鵡螺 =
生鲑鱼可用于喂食驯服的[鹦鹉螺](鹦鹉螺.md)和[殭屍鸚鵡螺](殭屍鸚鵡螺.md)，使生命值已满的成年鹦鹉螺进入繁殖模式，治疗生命值未满的成年鹦鹉螺和殭屍鸚鵡螺的生命值，加速幼年鹦鹉螺约10%的成长时间。
