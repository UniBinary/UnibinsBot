# 磨制凝灰岩

*页面ID: 106640* | *来源: Minecraft Wiki*

* *磨制凝灰岩（Polished Tuff）**是[凝灰岩](凝灰岩.md)制作的装饰性方块。

# 生成
# = 自然生成 =
磨制凝灰岩会生成在试炼密室中部分结构的天花板上。

# 破坏
挖掘磨制凝灰岩的合适工具是镐。磨制凝灰岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

磨制凝灰岩被破坏后会掉落自身。
