# Java版1.13-pre9

*页面ID: 35509* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.13-pre9**是[Java版1.13](Java版1.13.md)的第9个预发布版，发布于2018年7月16日<ref></ref>，加入了一些遗漏的字幕，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[字幕](字幕.md)**
* 加入了一些遗漏的[字幕](字幕.md)。<ref>https://pokechu22.github.io/Burger/diff_1.13-pre8_1.13-pre9#language:subtitles</ref>

# 修复
和的<code>&lt;center&gt;</code>变量没有坐标提示。
|122997|树叶靠近原木时消失。
|125977|无头坐标对方块更新无反应。
|131821|Cory Scheviak未出现在制作者名单中。
|131822|用1.13-pre3或更新的客户端尝试加入1.13-pre2或更旧的服务器时会出现未解码的/难懂的错误信息。
|132210|在战利品表中的<code>random_chance</code>里使用小数的漏洞。
|132652|在键补全中，以非空字符起始的用户名字符串会发生偏移。
|132657|当在聊天输入行的中间没有起始字符串的情况下调用时，左侧将显示用户名选项卡。
|132713|在1.13-pre6的服务器上运行1.12.2的世界会停止运行并崩溃。
|133337|打开语言设置时，<code>org.lwjgl.opengl.GL11.glDrawArrays</code>崩溃（由“无法找到字符Ʞ（<code>\ua7b0</code>）的字形”引起）。
|;previous
|133446|在1.13上运行1.12的世界会有卡顿。
|133503|1.12.2的控制设置可能在升级到1.13后完全丢失。
|133630|从小窗口最大化到部分全屏时，开始界面不能正常显示。
