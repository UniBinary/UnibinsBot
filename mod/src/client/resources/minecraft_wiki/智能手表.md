# 智能手表

*页面ID: 151817* | *来源: Minecraft Wiki*

* *智能手表（Smarter Watch）**是用于在[快捷栏](快捷栏.md)的物品提示文字处显示时间的物品。

# 获取
穿戴智能手表生成的人形生物被玩家或驯服的[狼](狼.md)击杀时有8.5%（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落智能手表。

# 用途
# = 显示时间 =
当智能手表戴在主手或副手上时，[快捷栏](快捷栏.md)的物品提示文字处会显示时间，书写格式为“<*分*>:<*秒*>”。显示的时间使用24分钟制，但由于每个游戏日仅有20分钟，通常会错误计时。

# = 推送通知 =
当智能手表戴在主手或副手上时，[聊天框](聊天框.md)会推送通知：

* [统计信息](统计信息.md)中的距离统计每逢10的该数值当前位数-1次方的倍数，[聊天框](聊天框.md)就会推送通知。
* * 如：“Notice! Distance Flown is now 100!”（注意！飞行距离现为100！）
* 玩家受到伤害时聊天框会显示如下消息：
* * “Notice! You recently took <*伤害*> hearts of damage!”（注意！你最近受到了<*伤害*>点生命值的伤害！）
