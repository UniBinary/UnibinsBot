# 2022年生物投票服务器活动

*页面ID: 104911* | *来源: Minecraft Wiki*

* *2022年生物投票服务器活动（Mob Vote 2022 Server Event）**<ref group="注">[主菜单](主菜单.md)上称作**生物投票2022（Mob Vote 2022）**。</ref>是作为[Minecraft Live 2022](Minecraft Live 2022.md)活动一部分的限时开放的官方[活动服务器](活动服务器.md)，玩家可以在服务器中参与一年一度的生物投票。

# 描述
[thumb|250px|无生物的直播列车](File:Live Train Mob Vote 2022 Server.png.md)
服务器的[世界](世界.md)中的方块和NPC外观皆为生物投票视频中的风格。

玩家的[出生点](出生点.md)位于一个类似荧幕的舞台上。

出生点旁边有两个模仿矿车隧道的装饰，其中有一列乘坐着各种生物的直播列车“Live Train”，参考了Minecraft Live 2022宣传片中[Alex和各种生物共同乘坐列车的动画片段](https://www.youtube.com/watch?v=jMe3tdyjouM=100s)。

# 主要活动
[thumb|淘气鬼、凝灰岩傀儡和嗅探兽雕像](File:Minecraft Live 2022 mob vote in-game-map.png.md)

服务器的中心有3个巨大的候选生物雕像，凝灰岩傀儡雕像后有一个浮空的生物投票徽标。

# = 投票广场 =
玩家可在生物雕像中间的投票广场参与[2022年生物投票](Minecraft Live 2022#生物投票.md)。拉下对应拉杆即可确定投票对象，票选对象可以更改。

# = 过山车 =

过山车（Rollercoaster）的起点位于淘气鬼雕像左边的矿道中。过山车围绕着整个地图，玩家可乘坐矿车环绕地图观光。

# = 生物介绍地点 =
3个候选生物的介绍地点皆与其在宣传片中的场景相似，玩家可以前往对应地点观看候选生物的2D形象、与小Agnes和小Jens以获取生物的详细介绍。

用于投票的拉杆也会出现在各个介绍地点处，玩家也可以在此拉下对应拉杆确定该投票对象。

# == 沙滩 ==
沙滩位于嗅探兽雕像的右侧，为[嗅探兽](嗅探兽.md)的介绍地点。

# == 矿井 ==
矿井位于淘气鬼雕像的左侧，为淘气鬼的介绍地点。

# == 房子 ==
房子位于凝灰岩傀儡雕像的右侧的村庄景观中，共有两座，其中一座与[凝灰岩傀儡介绍视频](https://www.youtube.com/watch?v=5EYP3_yRD1k)的房子相似，为凝灰岩傀儡的介绍地点。

另一座为拥有村民画像的房子，玩家可以与小Vu。

# 小游戏
在服务器中有许多在社区流传甚广的小游戏。

# = Jens战斗竞技场 =

“Jens战斗竞技场”（Jens Combat Arena）位于淘气鬼雕像右侧与凝灰岩傀儡雕像左侧之间的区域。玩家可以在2分钟内与多波次的敌人战斗（可以与多名玩家同时参与），时间结束后将会结算获得的总积分与挑战成功的波数。

玩家在进入战斗后将被给予一把[石剑](石剑.md)、一把[弓](弓.md)和32根[箭](箭.md)。在场外未参与的玩家可在竞技场观看处的两个金苹果补给处按下按钮给予场内正在战斗的玩家一个[附魔金苹果](附魔金苹果.md)，每局挑战只能给予一次。

; 物品商店
物品商店（Item Shop）是位于竞技场中的地点。玩家可以通过攻击敌对生物获得积分，用来购买物品商店中的物品。可获得的物品如下：

在一次挑战中，玩家在购买物品商店的剑之后，将会替换掉物品栏中原有的剑。玩家只能购买较已有的剑更高品质的剑（类似于升级装备），若购买较已有的剑品质更低的剑，将会提示“不可以对剑降级”。

# = 漏斗水立方 =

“漏斗水立方”（Hopper Dropper）是位于投票广场上方的计时坠落游戏。玩家需要躲避障碍物（如[黏液块](黏液块.md)和[橡木原木](橡木原木.md)）尽快地从顶端下落到最底端的终点，挑战过程中，玩家能够看到自己已花费的时间。下落至最底端即为完成挑战。挑战结束后，玩家将被告知完成挑战所花费的总时长。

# = 跑酷 =
每个跑酷都有多个记录点和不同的难度。要完成跑酷，玩家必须敲响放置在生物雕像顶部的[钟](钟.md)。

# == 嗅探兽跑酷 ==
“嗅探兽跑酷”（Sniffer Parkour）是一个中等难度的计时跑酷区域，围绕着嗅探兽雕像，途经24个[青翠蛙明灯](青翠蛙明灯.md)记录点。

# == 凝灰岩傀儡跑酷 ==
“凝灰岩傀儡跑酷”（Tuff Golem Parkour）是一个高难度的计时跑酷区域，围绕着城堡和凝灰岩傀儡雕像，途经20个赭黄蛙明灯记录点。

# == 淘气鬼跑酷 ==
“淘气鬼跑酷”（Rascal Parkour）是一个低难度的计时跑酷区域，围绕着雪山和淘气鬼雕像，途经19个珠光蛙明灯记录点。

# 隐藏彩蛋
# = 列车空位 =
出生点旁边的直播列车中有一个空位，玩家乘坐后将会提示“感谢您的乘坐！”。

# = 青蛙雕像 =
嗅探兽雕像内有一个乘坐矿车的溫帶青蛙雕像。

# = 往届投票 =
# == 已加入生物 ==
4只在往届生物投票或生物群系选举/投票中已加入的生物，其游戏内形象隐藏于服务器世界的各个角落。

* [狐狸](狐狸.md)位于矿井旁山坡的一棵橡树下。
* [发光鱿鱼](发光鱿鱼.md)位于沙滩后的河流中。
* [青蛙](青蛙.md)位于出生点桥下的沼泽景观中。
* [悦灵](悦灵.md)位于村庄景观的广场的[音符盒](音符盒.md)旁。

# == 落选生物 ==
7只在往届生物投票或生物群系选举/投票中落选的生物，其2D形象隐藏于服务器世界的各个角落。

部分生物的隐藏地点景观与其在宣传片中的场景相似。
