# 基岩版26.0.23

*页面ID: 174985* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 26.0.23**（ChromeOS/Android）、**Preview 26.0.23**（Xbox/iOS/iPadOS/PlayStation）、**Preview 26.0.24**（Windows）是[基岩版26.0](基岩版26.0.md)的首个测试版，发布于2025年12月3日<ref></ref>，加入了对命令宏的支持，同步了一些的特性，并修复了一些漏洞。

# = 常规 =
* *[控制](控制.md)**
* 加入了对命令宏的支持。
* * 有10个键位映射用于执行命令。
* ** 每个键位映射均有文本输入框，用于指定按下该键位时执行的命令。
* ** 只能在游戏中执行命令。
* ** 所有可映射键位均为 + 所选键位的组合键。
* * 仅开启“Enable Command Macros”选项后可用。

# 更改
# = 方块 =
* *[发光的黑曜石](发光的黑曜石.md)**
* 现在拥有显示名称。

# = 物品 =
* *[马铠](马铠.md)**
* 现在金马铠会提供2点盔甲韧性。<ref></ref>
* 现在下界合金马铠会提供3点盔甲韧性。
* 现在会在[提示框](提示框.md)中显示护甲值加成、盔甲韧性加成和击退抗性加成。

* *[鹦鹉螺铠](鹦鹉螺铠.md)**
* 现在钻石鹦鹉螺铠会提供2点盔甲韧性。
* 现在下界合金鹦鹉螺铠会提供3点盔甲韧性。
* 现在会在提示框中显示护甲值加成、盔甲韧性加成和击退抗性加成。

* *[狼铠](狼铠.md)**
* 现在会在提示框中显示护甲值加成、盔甲韧性加成和击退抗性加成。

# = 生物 =
* *[发光鱿鱼](发光鱿鱼.md)**
* 幼年发光鱿鱼死亡时不再会掉落[荧光墨囊](荧光墨囊.md)。

* *[马](马.md)、[驴](驴.md)、[骡](骡.md)和[骷髅马](骷髅马.md)**
* 幼年变种的体型不再会随时间逐渐增大，以匹配。

* *[溺尸](溺尸.md)**
* 不再会捡起[矛](矛.md)。
* 现在幼年溺尸可以携带[三叉戟](三叉戟.md)生成。
* 调整了溺尸生成时携带物品的概率以近似匹配：
* * 携带三叉戟的概率由15%降低至6.25%。
* * 携带[钓鱼竿](钓鱼竿.md)的概率由0.85%提高至3.515625%。
* * 携带[鹦鹉螺壳](鹦鹉螺壳.md)的概率由8%降低至7%。

* *[鹦鹉螺](鹦鹉螺.md)**
* 加入了独特的游泳音效。
* * 幼年鹦鹉螺拥有不同于成年鹦鹉螺的音效。
* 加入了在陆地上时空闲时、受伤和死亡的音效。
* * 幼年鹦鹉螺拥有不同于成年鹦鹉螺的音效。

* *[北极熊](北极熊.md)**
* 现在幼年北极熊会攻击[狐狸](狐狸.md)。<ref group="注" name="attackbug">实际上为漏洞的作用目标由玩家转移到狐狸。</ref>
* 成年北极熊不再会攻击靠近幼年北极熊的玩家。

* *[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)和[焦骸](焦骸.md)**
* 不再会捡起矛。

* *[鱿鱼](鱿鱼.md)**
* 幼年鱿鱼死亡时不再会掉落[墨囊](墨囊.md)。

* *[僵尸马](僵尸马.md)**
* 幼年僵尸马不再会成长为成年个体。

* *[僵尸鹦鹉螺](僵尸鹦鹉螺.md)**
* 加入了独特的游泳音效。
* 加入了在陆地上时空闲时、受伤和死亡的音效。

# 修复
* *方块**
* 修复了末地折跃门会将玩家传送至虚空区域的问题。（）

* *游戏内容**
* 现在卫道士会在被使用“Johnny”命名牌时正确地攻击所有非灾厄村民生物。

* *常规**
* “”成就不再会在PC上到达少于17个生物群系后解锁。（）
* 修复了Windows平台上即使单个显示器有足够空间，窗口也会在重新打开时重置为较小大小的问题。（）

* *图形**
* 修复了在选择光线追踪图形模式的情况下拍摄的截图不会精确渲染的漏洞。
* 修复了在开启的情况下关闭“”选项时，高亮显示会不可见的漏洞。（）
* 修复了游戏更新后图形模式选项会发生变化的问题。（）
* 修复了在开启的情况下，水的消光会在位于其后的区块丢失时覆盖迷雾绘制的问题。
* 修复了在开启的情况下，部分皮肤中较深的颜色会显得褪色的问题。（）
* 修复了“隐藏天空闪光”选项会导致末地入场环境音效循环播放的漏洞。
* 修复了音符盒上的音符效果不会在黑暗环境中显示正确颜色的问题。
* 修复了资源包将末地传送门在中定义为点光源时，末地传送门上的光照会渲染不正确的问题。
* 现在当玩家靠近时，着火的生物和玩家身上的火焰效果会变透明。
* 修复了雪傀儡的南瓜头不会在“”选项开启时变透明的问题。（）

* 修复了删除物品展示框中的定位器地图时，地图标记会卡住的问题。（）

* *生物**
