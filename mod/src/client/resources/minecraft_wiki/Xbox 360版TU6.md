# Xbox 360版TU6

*页面ID: 98096* | *来源: Minecraft Wiki*

* *TU6**是[Xbox 360版](Xbox 360版.md)的一次更新，发布于2012年11月15日<ref></ref>，此次更新基于[Java版Beta 1.8.1](Java版Beta 1.8.1.md)开发。

# 新内容
# = 常规 =
* *[选项](选项.md)**
* 加入了用于在创造模式下清除物品栏的快速命令，按下访问。
* 加入了用于开关[虚空](虚空.md)迷雾的开关。迷雾默认关闭，开启状态取决于房主的设置。
* 加入了在图形设置中禁用HUD和玩家手部外观的选项。
* 在房主和玩家（Host and Player）选项中加入了“游戏指南”页面。

# 更改
# = 物品 =
* *[蛋糕](蛋糕.md)**
* 现在可以堆叠了。

* *[金苹果](金苹果.md)**
* 将合成配方中的[金粒](金粒.md)改为[金锭](金锭.md)。

# = 方块 =
* *[栅栏](栅栏.md)**
* 碰撞箱减小到与栅栏方块相等的大小。

# 修复
* 修复了重命名保存文件时出错的问题。
* 修复了Beta 1.8.2之前创建的世界因符号而崩溃的问题。
* 修复了金苹果和南瓜籽合成配方丢失的问题。
* 修复了“玩家标记显示”被禁用时地图上出现的重生玩家的问题。
* 修复了创造模式下的水桶和熔岩桶不能无限使用的问题。
* 修复了怪物生成代码在世界上繁殖更多动物的问题。
* 修复了在Beta 1.8.2更新之前创建的世界中，箱子被错误地照亮和放置的问题。
* 修复了在不吃东西的玩家身上显示的吃东西动画的问题。
* 修复了箱子的盖子不正常的问题。
* 修复了玩家空手时游戏声音不播放的问题。
* 修复了生物在没有受到伤害的情况下会受到伤害的问题。
* 修复了铁栏杆和栅栏门的声音。
* 修复了“团队领袖”成就被错误奖励的问题。
* 修复了排行榜的统计数据出错的问题。
* 修复了玻璃板和铁栏杆的边缘连接问题。
* 修复了小字符显示变为绿色的问题。
* 修复了将分屏玩家设置为0时产生的问题。
* 修复了禁用云渲染和在地图边缘渲染块的问题。
* 修复了分屏玩家无法在教程中挖掘的问题。
* 修复了玩家在低饥饿值下保存生存世界后无法在创造模式里冲刺的问题。
* 修复了禁用PvP时箭仍然会造成的PvP伤害的问题。
* 修复了压力板在激活时无法正常工作的问题。
* 修复了创造模式游戏中出现的低食物条提示的问题。
* 启用房主隐形选项时现在将从房主上移除玩家阴影。
* 修复了世界中红色花朵不会蔓延的问题。
* 修复了活塞推动动画出错的问题。
* 修复了由于信任玩家被关闭而无法进食的玩家仍然可以疾跑的问题。
* 修复了使用Facebook共享工具后界面消失的问题。
* 修复了限制生成史莱姆、恶魂和蠹虫的数量出错问题。
* 修复了在创作模式下防止光标离开屏幕的问题。
* 修复了披风的渲染问题：
* * 冲刺飞行时显示不正确。
* * 在虚空中不显示。
* * 玩家重生时不显示。
* 修复了创造模式下的弓会在发射时消耗箭的问题。
* 降低了箱子打开/关闭声音效果的音量。
