# Java版1.18-rc1

*页面ID: 90939* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.18-rc1**是[Java版1.18](Java版1.18.md)的首个发布候选版本，发布于2021年11月25日<ref></ref>，提高了服务器资源包的大小限制，并修复了1个与内存泄露有关的漏洞。

# 更改
# = 常规 =
* *[资源包](资源包.md)**
* 服务器资源包的大小限制由100MB提高到250MB。
