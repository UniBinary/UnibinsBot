* *出口之眼（Eye of Exit）**是一种用于定位及传送的可合成[物品](物品.md)，也是[末影之眼](末影之眼.md)的替代品。

# 获取
# = 合成 =

# = 自动获得 =
玩家进入一个已完成的矿境时，其物品栏会被暂时清空，并获得一个出口之眼。

# 用途

出口之眼可以用于在挑战矿境时定位矿境出口、回访矿境时传送至大厅，也可作为[末影之眼](末影之眼.md)的替代品用来合成[末影箱](末影箱.md)及[末地水晶](末地水晶.md)。

# = 获取经验 =

出口之眼所具有的物品基础价值为1。

# = 定位矿境出口 =
在挑战矿境时使用出口之眼时，会生成一个指向此矿境中最近的[矿境出口](矿境出口.md)的出口之眼实体。

# = 返回大厅 =
在回访矿境时使用出口之眼时，会将玩家传送回大厅，并返还进入前物品栏中的物品。

# = 造成伤害 =
未解锁“[寻路者](可解锁项目.md)”的玩家使用出口之眼时，会受到伤害。

# = 合成材料 =
由于移除了末影之眼，出口之眼会代替末影之眼作为合成材料。
