# 勇气之袋

*页面ID: 127113* | *来源: Minecraft Wiki*

[thumb|勇气之袋的官方艺术作品](File:Bundles of Bravery Key Art.png.md)

* *勇气之袋（Bundles of Bravery）**是一次[小更新](小更新.md)，发布于2024年10月22日<ref></ref><ref></ref><ref></ref>。其主题于2024年9月28日公布于[Minecraft Live 2024](Minecraft Live 2024.md)。其主要内容为加入[收纳袋](收纳袋.md)及为[基岩版](基岩版.md)和[Realms](Realms.md)加入[极限模式](极限模式.md)。<ref></ref>

# 重要特性

# = 物品 =
* * [收纳袋](收纳袋.md)**
* 由[线](线.md)和[皮革](皮革.md)合成。

* 可以容纳一组堆叠的不同物品。
* 有16种染色变种，可以使用染料更改颜色。

# = 世界设置 =
* *[32px](File:Hardcore Heart.svg.md) [极限模式](极限模式.md)**
* 现在可以在Realms和中创建极限模式世界。
* 世界难度锁定为[困难](困难.md)，[玩家](玩家.md)死亡后无法重生，只能以[旁观模式](旁观模式.md)观察世界。
