红树是一种生成于[红树林沼泽](红树林沼泽.md)的植被[地物](地物.md)，分为**普通红树（Mangrove）**和**高红树（Tall Mangrove）**。

# 种类
# = 普通红树 =
普通红树的根须发达，树根方块从原木基部向四周和下方延伸，同一轴方向内两端最远相距13格。每格红树根的顶面都有50%的概率被[覆地苔藓](覆地苔藓.md)覆盖。若生成红树根的方块空间被[泥巴](泥巴.md)占据，该位置会形成[沾泥的红树根](沾泥的红树根.md)。

每格红树树干有50%的概率延伸出一条斜45°的分杈。树叶的每个侧面有/的概率生成[藤蔓](藤蔓.md)。

红树树叶每个底面有14%的概率长着任意生长阶段的[红树胎生苗](红树胎生苗.md)；概率为25%。

普通红树的树干高2-7格。

# = 高红树 =
高红树的特征和普通红树的特征基本一样，但高红树的树干高4-14格。红树树叶每个底面有的概率长着任意生长阶段的红树胎生苗；概率和普通红树一样，为14%。

# 生成
# = 自然生成 =
[红树林沼泽](红树林沼泽.md)生成树木地物时，普通红树有15%的概率生成，高红树有85%的概率生成。

红树自然生成时有1%的概率带有一个容纳3只[蜜蜂](蜜蜂.md)的[蜂巢](蜂巢（方块）.md)。

# = 人为生成 =
空间充足时，[红树胎生苗](红树胎生苗.md)可长成普通红树或高红树，无论[亮度](亮度.md)等级为多少。

由胎生苗长成的红树有1%的概率带有一个容纳1-3只蜜蜂的蜂巢。
