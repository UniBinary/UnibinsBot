# 携带版0.11.0.b1

*页面ID: 30540* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 1**是[v0.11.0 alpha](携带版0.11.0.md)发布的首个测试版，发布于2015年4月9日，加入了新的方块、物品和生物，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[红石块](红石块.md)**
* 新的矿物块。
* 仅用于存储红石粉。

* *[草径](草径.md)**
* 替代村庄的沙砾道路生成。
* 对草方块锹生成。

# = 物品 =
* *[船](船.md)**
* 新的载具。
* 不会被撞毁。
* 可以由两个生物共同乘坐的船。

* *[鱼](鱼.md)**
* 加入了[鳕鱼](生鳕鱼.md)、[鲑鱼](生鲑鱼.md)、[河豚](河豚（物品）.md)和[小丑鱼](小丑鱼.md)。

* *[钓鱼竿](钓鱼竿.md)**
* 新的工具，可用于钓鱼。

* *[腐肉](腐肉.md)**
* 新的食物，由[僵尸](僵尸.md)掉落。
* 食用会获得[中毒](中毒.md)效果。

# = 生物 =
* *[鱿鱼](鱿鱼.md)**
* 新的被动型生物，自然生成于在[海洋](海洋.md)里。
* 幼年鱿鱼。

* *[僵尸](僵尸.md)和[僵尸猪人](僵尸猪人.md)**
* 加入了僵尸和僵尸猪人的幼年变种。

* *[恶魂](恶魂.md)**
* 新的敌对生物。
* 暂时不会自然生成。

* *[洞穴蜘蛛](洞穴蜘蛛.md)**
* 新的敌对生物。
* 暂时不会自然生成。

* *[蝙蝠](蝙蝠.md)**
* 新的被动型生物，自然生成于地下。

* *[蜘蛛骑士](蜘蛛骑士.md)**
* 蜘蛛和骷髅的组合型生物。

* *[鸡骑士](鸡骑士.md)**
* 僵尸或僵尸猪人和鸡的组合型生物。
* 包括成年和幼年变种。

# = 游戏内容 =
* *[钓鱼](钓鱼.md)**
* 新的游戏机制，可以获得不同种类的鱼。

* *[状态效果](状态效果.md)**
* 加入了[生命恢复](生命恢复.md)、[抗性提升](抗性提升.md)、[缓慢](缓慢.md)、[迅捷](迅捷.md)、[跳跃提升](跳跃提升.md)、[伤害吸收](伤害吸收.md)、[水下呼吸](水下呼吸（状态效果）.md)、[凋零](凋零.md)、[力量](力量（状态效果）.md)、[虚弱](虚弱.md)、[饱和](饱和.md)、[生命提升](生命提升.md)、[抗火](抗火.md)、[瞬间治疗](瞬间治疗.md)、[瞬间伤害](瞬间伤害.md)、[急迫](急迫.md)、[挖掘疲劳](挖掘疲劳.md)、[夜视](夜视.md)、[隐身](隐身.md)、[中毒](中毒.md)、[饥饿](饥饿（状态效果）.md)和[反胃](反胃.md)效果。
* * 只有[中毒](中毒.md)、[饥饿](饥饿（状态效果）.md)和[反胃](反胃.md)效果能够以正常途径获得。

* *[皮肤](皮肤.md)**
* 加入了Alex皮肤和皮肤包。

# = 常规 =
* *[语言](语言.md)**
* 加入了多国语言翻译。
* 加入了文本格式代码。

* *[设置](设置.md)**
* 新的世界选项界面：
* * 重命名世界
* * 更改游戏模式
* * 锁定/解锁日夜循环
* * 使旧版生成的世界无限化

* *[GUI](GUI.md)**
* 在服务器进入画面显示服务器状态和MOTD。
* 加入了“隐藏”按钮以隐藏聊天信息。

* *[死亡消息](死亡消息.md)**
* 加入了基本的死亡消息。

# 更改
# = 方块 =
* *[石砖](石砖.md)**
* [裂纹石砖](裂纹石砖.md)、[苔石砖](苔石砖.md)与[雕纹石砖](雕纹石砖.md)能够在生存模式中合理获得。

# = 物品 =
* *[锹](锹.md)**
* 在[创造模式物品栏](创造模式物品栏.md)中加入了铁锹。

# = 常规 =
* *优化**
* 优化多人游戏带宽占用。
* 优化客户端到服务端通信。
* 优化断开连接信息。
* 优化字体渲染。
* 优化世界加载。
* 更快的火把放置（减少卡顿）。
* 加入服务端游戏校对，不会再有损坏的画面。
* 非“精美画质”模式现在正常工作。
* 将物品栏图标从石砖改成箱子。
* 将玩家名限制条件改为Java版上的限制。

# 修复
* *[修复了40个漏洞](https://bugs.mojang.com/browse/MCPE/fixforversion/15310)**
* 破坏方块后圆圈不会立刻消失。
* 保存世界时游戏崩溃。
* 破打开盔甲界面时游戏崩溃。
* 打开熔炉GUI时游戏界面。
* 游戏进度有时不会保存。
* 僵尸猪人会在阳光下自燃。
* 有时候无法创建新世界。
* 死后玩家会被困在虚空里。
* 生存模式下可以利用快捷栏复制物品。
* 交互按钮在远离目标生物时仍然可以使用。
* 栅栏下的草方块和菌丝体不会蔓延，而在水下时却会。
* 水中的墙无法正确相互连接。
* 可可果被破坏时，紧邻的方块不会收到方块更新。
* 生存模式下可以破坏基岩。
* 放置水可以覆盖透明方块。
* 木斧不能用作熔炉的燃料。
* 木斧不能用作熔炉的燃料。
* 紧邻方块会随时收到方块更新，以及出现渲染漏洞。
* 栅栏会使得顶部的下落的沙砾掉落。
* 破坏正在运行的下界反应核使得出现永夜现象。
* 游玩时不能更改用户名。
* 无法使用切石机合成石英楼梯。
* Realms世界里游戏崩溃会复制玩家。
* 放在仙人掌旁的门会被复制。
* 放置在透明方块侧面的水不会变成无限水源。
* 两格高的植物生长时会移除上半部分的方块。
* 骑乘矿车的实体会以两倍速的刻运作。
* 喂食狼可以复制物品。
* 铁栏杆不能和玻璃板连接。
* 纵向的栅栏会试图和横向的栅栏门连接。
* 金合欢木和深色橡木楼梯不可燃。
* 生长失败的树苗底部的草方块会变成泥土。
* 堆叠放置的地毯不会掉落超过一个的量。
* 放置在火把上的沙子或沙砾会悬空。
* 在Y=127处的方块会发光。
* 放置未知的方块时游戏崩溃。
* 树苗有时候不会生长。
* 沙漠水井和部分生物群系变种（例如高大桦木森林）不会生成。
* 连接到局域网世界时游戏崩溃。
