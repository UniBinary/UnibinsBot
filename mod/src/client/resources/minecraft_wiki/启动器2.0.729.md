# 启动器2.0.729

*页面ID: 63438* | *来源: Minecraft Wiki*

* *2.0.729**（[Windows](wzh:Microsoft Windows.md)）是一个[启动器](启动器.md)版本，发布于2017年2月1日，修复了一些漏洞。

# 修复
* 修复了更新过程。
* 修复了Mods的问题。
*  - 启动器更新为2.0.x后会再次降级为1.6.76。
*  - 新启动器导致Curse启动器无法启动Mod。
*  - 自定义日志配置中的“Browse”按钮不起作用。
