# 基岩版1.14.0.3

*页面ID: 48905* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.14.0.3**是[基岩版1.14.0](基岩版1.14.0.md)的第3个测试版，发布于2019年10月23日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[蜂巢](蜂巢（方块）.md)**
* 英文名称由“Bee nest”重命名为“Bee Nest”。

# 修复
* *修复了9个漏洞**<br>
* *常规**
* 修复了“Traveling Trader”市场世界中的活塞红石机制问题。
* 现在使用垂直分屏的玩家可以在角色创建器中选择特色饰件。
* 现在装备新的自定义皮肤后无需重启游戏即可更新玩家模型。
* 玩家现在可以在已拥有的皮肤上装备创始人披风。（）
* 现在可以使用控制器来高亮显示并选择按下“在商店中查看已有的包”按钮。

* *游戏内容**
* 调整了马在蜂蜜块上移动时的行为以匹配Java版。
* 现在拥有跳跃提升II效果的玩家站在蜂蜜块上可以跳跃到一格高。

* *物品**
* 现在蜂巢的英文名称“Bee nest”中的“n”是大写的。（）

* *图形**
* 现在玻璃放置在海带植株附近时，海带中的水会正确渲染。</onlyinclude>
