# Java版20w49a

*页面ID: 72810* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w49a**是[Java版1.17](Java版1.17.md)的第4个快照，发布于2020年12月2日<ref></ref>，加入了[幽匿感测体](幽匿感测体.md)、[溶洞](溶洞.md)生物群系、新的死亡消息、新的粒子和新的方块与游戏事件标签，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[幽匿感测体](幽匿感测体.md)**
* 一种新的红石元件。
* 通过检测振动发出红石信号。
* 将其连接到红石比较器会发出不同的信号强度，信号强度基于振动频率。
* 在其周围放置[羊毛](羊毛.md)可阻止其检测振动。
* 目前仅能通过[创造模式物品栏](创造模式物品栏.md)或命令等获取。

# = 生物群系 =
* *[溶洞](溶洞.md)**
* 一种新的地下生物群系。
* 由[滴水石块](滴水石块.md)、[滴水石锥](滴水石锥.md)和小水池组成。
* 目前不会自然生成在常规的世界中，仅能通过在[自选世界](自选世界类型.md)界面中选择“溶洞”生物群系，或是选用[自定义](自定义.md)世界类型等手段生成。

# = 游戏内容 =

* *[死亡消息](死亡消息.md)**
* 加入了关于钟乳石的死亡消息。
* * “<玩家>被坠落的钟乳石刺穿了”
* * “<玩家>在与<实体>战斗时被坠落的钟乳石刺穿了”

* *[粒子](粒子.md)**
* 加入了新的粒子类型和。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 包含方块标签和[泥土](泥土.md)。
* * 用于滴水石块生成，拥有此标签的方块可以被滴水石块替换、滴水石锥可以在其上生成。
* 加入了方块标签。
* * 包含方块标签。
* * 拥有此标签的方块位于幽匿感测体和振动之间时会阻止振动被检测到。
* 加入了新的标签类型。
* 加入了游戏事件标签。
* * 包含脚步、摔落和射击投射物事件。
* * 当事件来源潜行时，拥有此标签的游戏事件不会被幽匿感测体检测。
* 加入了游戏事件标签。
* * 包含任何游戏事件。
* * 拥有此标签的游戏事件会被幽匿感测体检测。

# 更改
# = 方块 =
* *[滴水石锥](滴水石锥.md)**
* 在为true的维度（原版中为[下界](下界.md)）中，钟乳石会生成熔岩粒子而不是水的粒子。

# = 物品 =
* *[收纳袋](收纳袋.md)**
* 现在无论是否开启，都会以分数显示其容量。

# = 游戏内容 =
* *[伤害吸收](伤害吸收.md)**
* 当玩家有[中毒](中毒.md)或[凋零](凋零.md)效果时，其满的伤害吸收生命条现在将保持为黄色，而不是显示为空。

* *[冰冻](细雪#冰冻.md)**
* [极限模式](极限模式.md)现在也会显示冰冻状态下的生命条。
* * 纹理与普通的生存模式下的冰冻生命条相同。

# = 常规 =
* *[自定义世界](自定义世界.md)**
* 向维度类型加入了和参数。
* * 现在[虚空临界高度](虚空#底层虚空.md)为。
* *服务器**
* 移除了服务器设置。
