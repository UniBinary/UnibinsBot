* *煎炸台（Frying Table）**是一种用于烹饪[马铃薯](马铃薯.md)，以及将[马铃薯皮](马铃薯皮.md)制作成[薯饼](薯饼.md)的方块。

# 生成
煎炸台会作为[马铃薯村庄](马铃薯村庄.md)的一部分生成。

# 获取
# = 合成 =

# 破坏
没有工具可以加速对煎炸台的挖掘。

煎炸台被破坏后会掉落自身。

# 用途

煎炸台的大部分用途与[营火](营火.md)相同。

点燃的煎炸台不会发光。

# = 伤害 =
点燃的煎炸台会对位于其中的生物造成[伤害](伤害.md)。

# = 烹饪 =
对着点燃的煎炸台任意种类的[马铃薯皮](马铃薯皮.md)（腐败变种除外）可将其放到煎炸台上。烹饪结束后，马铃薯皮会掉落为[薯饼](薯饼.md)物品。

[马铃薯](马铃薯.md)也可在该方块上进行烹饪，但此外的其他食物无法在其上进行烹饪。
