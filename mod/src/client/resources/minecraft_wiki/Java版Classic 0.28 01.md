# Java版Classic 0.28 01

*页面ID: 35625* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.28_01**是[0.28](Java版Classic 0.28.md)的一个漏洞修复版本，发布于2009年10月27日<ref></ref>，修复了一个漏洞。

# 修复
* *修复了1个漏洞**
* 修复了一个玩家能在创造模式多人游戏中杀死对方的漏洞。
* * 这也意味着玩家不再能在创造模式中伤害生物了。
* ** 生物也不能被箭伤害，但是玩家仍然可以从绵羊上剪下羊毛。</onlyinclude>

# 你知道吗
* 此版本可以通过修改中的<code>Minecraft.class</code>文件进入[生存模式](生存模式.md)。
