# 剩余物

*页面ID: 144649* | *来源: Minecraft Wiki*

* *剩余物（Leftover）**，也被称为**结界（Zone）**或**结界方块（Zone Block）**，是一种自然生成于“zones”维度中的方块。

# 生成
剩余物会在“zones”维度中自然生成。

# 获取
剩余物只能通过使用或类似的命令来放置，没有物品形式。

# 用途
剩余物是隐形的，只会散发出“Happy Villager”[粒子](粒子.md)效果。

进入剩余物中的实体会获得3秒II和3秒IV。

尽管剩余物是隐形的，但无法将其他方块放置在它所在的位置，[活塞](活塞.md)也不能将其移动或破坏。

将物品扔入其中后，该物品的重力会发生改变。
