# Java版Alpha v1.0.10

*页面ID: 32565* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.10**是的一次更新，发布于2010年7月22日<ref></ref>，加入了早期对[生存模式](生存模式.md)的[多人游戏](多人游戏.md)的支持。

# 新内容
# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 被重新加入游戏。
* 目前只有[Mojang](Mojang.md)的[服务器](服务器.md)。
* 仅能通过私人邀请访问。

# 更改
# = 常规 =
* *[主菜单](主菜单.md)**
* 单人游戏文本从"Single player"改为"Singleplayer"。
* 多人游戏文本从"Multi player"改为"Multiplayer"。</onlyinclude>
