# 携带版0.17.0.1

*页面ID: 26313* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.17.0.1 alpha**是[1.0.0](携带版1.0.0.md)的首个测试版，发布于2016年11月11日<ref>http://pocketbeta.minecraft.net/2016/11/10-beta-changelog-build-1-aka-01701.html</ref>，加入了首批[末影更新](末影更新.md)的特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[龙首](龙首.md)**
* 一种生物头颅。
* 末地船的船头会生成1个龙首。
* 在其收到红石信号时嘴会反复开闭。该动画在装备龙首的玩家、僵尸、骷髅或盔甲架水平移动时也会出现。
* * 若红石信号中断，嘴部会保持红石信号消失时的角度。

* *[末影箱](末影箱.md)**
* 一种可储存物品的方块。
* 末地城的战利品房间里会生成1个末影箱。
* 容量与箱子相同，为27格储存槽位。其内容存储于玩家的实体数据中。
* * 这意味着玩家不能访问其他玩家的末影箱物品栏，末影箱的内容物也不因其被破坏而丢失。
* 打开任何维度的任何位置的末影箱，其内容始终是一样的。
* 由8个[黑曜石](黑曜石.md)与1个[末影之眼](末影之眼.md)合成。

* *[末地烛](末地烛.md)**
* 一种装饰性光源，会产生白色粒子。
* 自然生成于末地城的塔顶或内部侧面上。
* 可以水平或垂直放置。
* 由1个[烈焰棒](烈焰棒.md)和1个[爆裂紫颂果](爆裂紫颂果.md)合成4个末地烛。

* *[龙蛋](龙蛋.md)**
* 一种装饰性方块。
* 首次击杀末影龙，且返回传送门激活后，龙蛋会出现在返回传送门顶端。
* 挖掘会导致其瞬移，可通过产生爆炸或在其为[下落的方块](下落的方块.md)状态时即可摧毁。

* *[紫颂植株](紫颂植株.md)**
* 一种植物。
* 在末地高地上作为紫颂树的“枝干”生成。
* 可以破坏紫颂植株得到紫颂果。

* *[紫颂花](紫颂花.md)**
* 一种植物。
* 自然生成在末地外岛，长在紫颂树的顶部。
* 可用于在末地石上种植紫颂树。

* *[紫珀块](紫珀块.md)**
* 一种装饰性方块。
* 自然生成于末地城与末地船中。
* 可由4个[爆裂紫颂果](爆裂紫颂果.md)合成4个紫珀块。

* *[紫珀柱](紫珀柱.md)**
* 一种装饰性方块。
* 自然生成于末地城与末地船中。
* 可由2个[紫珀台阶](紫珀台阶.md)合成1个紫珀柱。

* *[紫珀台阶](紫珀台阶.md)**
* 一种装饰性方块。
* 自然生成于末地城与末地船中。
* 可由任意3个[紫珀块](紫珀块.md)合成6个紫珀台阶。

* *[紫珀楼梯](紫珀楼梯.md)**
* 一种装饰性方块。
* 自然生成于末地城与末地船中。
* 可由任意6个[紫珀块](紫珀块.md)合成4个紫珀台阶。

* *[末地石砖](末地石砖.md)**
* 一种装饰性方块，是[末地石](末地石.md)的石砖变种。
* 自然生成于末地城与末地船中。
* 可由4个末地石合成4个末地石砖。

* *[染色玻璃](染色玻璃.md)**
* [玻璃](玻璃.md)的染色变种，有16种颜色。
* 由8个玻璃与1个对应颜色的染料可合成8个染色玻璃。
* 品红色变种自然生成于末地城。

* *[染色玻璃板](染色玻璃板.md)**
* [玻璃板](玻璃板.md)的染色变种。
* 使用玻璃板的纹理，没有合成方式。
* 暂时不能自然生成。

* *[结构方块](结构方块.md)**
* 一种用于放置和操作结构的方块。
* 目前有2种模式：储存模式、加载模式。
* 由于没有分配方块ID，完全无法获得。

* *[结构空位](结构空位.md)**
* 一种用于标记加载结构时不替换某一位置的方块。
* 通常不可见，并且没有碰撞箱。
* 由于没有分配方块ID，完全无法获得。

# = 物品 =
* *[龙息](龙息.md)**
* 一种瓶装物品。
* 通过使用玻璃瓶收集末影龙吐出的龙息团获得。
* 用于酿造[滞留药水](滞留药水.md)。

* *[鞘翅](鞘翅.md)**
* 一种装备。装备后可使玩家滑翔。
* 可装备在玩家的胸甲槽上。
* 仅在末地船里的物品展示框内自然生成。
* 若玩家使用了披风，鞘翅会印上披风的图案。

* *[末地水晶](末地水晶.md)**
* 一种能够引发大威力爆炸的物品。
* 生成在末地主岛黑曜石柱的基岩基座上。
* 当其受到任何伤害时会立即爆炸并消失，[爆炸威力](爆炸威力.md)为6。
* 可以用于治疗和复活末影龙。

* *[紫颂果](紫颂果.md)**
* 一种食物，可以回复。
* * 与大部分食物不同，玩家在满饥饿值的情况下依旧可以食用紫颂果。
* 可以直接食用，也可烧炼成爆裂紫颂果。
* 食用后玩家会瞬间传送至可传送的随机地点。
* 破坏每格[紫颂植株](紫颂植株.md)有50%的概率获得1个紫颂果。

* *[爆裂紫颂果](爆裂紫颂果.md)**
* 一种通过烧炼紫颂果获得的物品，不可食用。
* 用于合成紫珀块与末地烛。

* *[末影之眼](末影之眼.md)**
* 一种用于定位、激活末地传送门的物品。
* 使用12个末影之眼即可激活空的末地传送门。
  * 一旦放置在末地传送门框架上就无法卸下。
* 可用1个[烈焰粉](烈焰粉.md)与1个[末影珍珠](末影珍珠.md)合成1个末影之眼。

* *[滞留药水](滞留药水.md)**
* 药水的可抛掷变种，会在破裂后留下能够造成状态效果的区域效果云。
* 可在酿造台内由龙息与对应种类的[喷溅药水](喷溅药水.md)制成。

# 更改
# = 方块 =
* *[床](床.md)**
* “你的床已遗失或被阻挡”会在玩家死亡并且床被破坏时出现。

* *[箱子](箱子.md)**
* 现在在两个容器之间转移物品更快了。

# = 物品 =
* *[地图](地图.md)**
* 现在在[末地](末地.md)可用。

* *[药箭](药箭.md)**
* 现在拥有类似于[Java版1.9](Java版1.9.md)中获取[药箭](药箭.md)的方法，但依然可以用[炼药锅](炼药锅.md)获得。

* *[附魔金苹果](附魔金苹果.md)**
* 现在提供正确的伤害吸收值。

* *[南瓜](南瓜.md)**
* 戴上[南瓜](南瓜.md)可以防止末影人攻击玩家。

* *[蘑菇](蘑菇.md)**
* 现在可以用蘑菇种植出[巨型蘑菇](巨型蘑菇.md)。

* *[牛奶](牛奶.md)**
* 现在可以在创造模式中喝[牛奶](牛奶.md)。

* *[甜菜汤](甜菜汤.md)和[甜菜根](甜菜根.md)**
* 甜菜根和甜菜汤现在会出现在创造模式物品栏。

* *[末影珍珠](末影珍珠.md)**
* [末影珍珠](末影珍珠.md)现在可以正常使用了。

# = 生物 =
* *[僵尸](僵尸.md)**
* 幼年僵尸被杀死时现在会掉落战利品。

* *[末影人](末影人.md)**
* 现在杀死[末影人](末影人.md)会掉落末影珍珠。
* 喷溅药水产生的负面效果不再对末影人起作用（它们会快速传送）。

* *[雪傀儡](雪傀儡.md)**
* [雪傀儡](雪傀儡.md)现在会攻击[蠹虫](蠹虫.md)。

* *[村民](村民.md)**
* [村民](村民.md)被尸壳杀死时会变成僵尸村民。

* *[牛](牛.md)**
* 现在只有成年的[牛](牛.md)可以挤奶。

* *[猪](猪.md)**
* 马铃薯和甜菜根又能用来喂养和繁殖[猪](猪.md)了。

* *[凋灵](凋灵.md)**
* [凋灵](凋灵.md)不再与凋灵骷髅和流浪者敌对。

* *[岩浆怪](岩浆怪.md)**
* [岩浆怪](岩浆怪.md)不再受到水的伤害。

* *[马](马.md)、[驴](驴.md)和[骡](骡.md)**
* 未被驯服的马、驴和骡不会在你手持食物时跟着你了。

* *[绵羊](绵羊.md)**
* 使用触摸控制的情况下要染色[绵羊](绵羊.md)时，会出现一个“染色”按钮。

* *常规**
* 在玩家骑着猪、马、骡和驴的时候，被引诱的生物不再推动玩家。
* 被驯服的生物杀死的生物现在会掉落经验球。

# = 游戏内容 =

# = 常规 =
* *[设置](设置.md)**
* 在音乐设置下方添加是否启用聊天文字转语音选项。
* 在高级视频设置加入一个为“携带版”和“经典”（类似于[Windows 10版](Windows 10版.md)）用户界面设置。
* 调整弹出窗口的透明度，改进阅读效果。

* *[附加包](附加包.md)**
* 有关Add-Ons的各种调整，包括改进加载。
* Add-Ons manifest的更强验证。

* *版本水印**
* 开头由"v"更改为"alpha"。

* *动画**
* 现在有扔出物品的动画。

# 修复
* *修复了35个漏洞**
* 音效的音量不正确。
* 文本在刷新时显示错误。
* 文本的大小和显示空格出错。
* 水和熔岩的流向不正确。
* Windows 10版下不会在用户列表里显示名称含有UTF-8字符的玩家。
* 名称含有UTF-8字符的玩家时，删除世界使得游戏崩溃。
* 视角场滑条显示的值不正确。
* 石头在合成界面里的显示不正确。
* Windows 10版下两个分辨率不同的屏幕连接时使得游戏在启动时崩溃。
* Android设备里玩家在锁屏时软键盘会切换成数字键盘。
* 使用蘑菇煲时游戏崩溃。
* Realm名称会覆盖已连接玩家的数量。
* 网络链接断开时，在Realm上使用替换世界按钮使得游戏崩溃。
* 守卫者、凋灵骷髅和烈焰人在将难度切换为非和平模式时不会生成（但只在新生成的下界要塞里修复）。
* 商店里试图购买产品时卡在“取得产品中”界面。
* 玩家在重新进入世界后，实体坠落过程被重置。
* 骷髅马陷阱无法运作。
* 酿造完成后无法获得成就。
* “本地的酿造厂”、“怪物猎人”和“弓箭手”成就无法完成。
* 循环执行命令以获取字符时不会显示所有的可用值。
* 运输矿车、漏斗矿车和TNT矿车在进入方块时卡在一半位置。
* 生物不会溺水。
* 移动端下在没有连接无线网络时启动游戏导致游戏崩溃。
* 箭的击中音效缺失。
* TTS朗读信息功能在输入新信息时被打断。
* 饥饿值过低时仍然可以疾跑。
* 使用命令时游戏崩溃。
* 画在放置时会重叠。
* 在Realm上使用替换世界按钮或选择世界时游戏崩溃。（iOS版）
* 玩家在骑乘马时重新连接世界后使得挖掘速度变慢。
* 玩家可以通过命令开使得桶放置其他方块。
* 加载在0.16.0之前创建的世界会使得猫转变为豹猫。
* 村庄的人口数量不受门的控制。
* 启动游戏时黑屏。（Fire TV版）
* 玩家在注视末影人的身体时仍会激怒它。</onlyinclude>
