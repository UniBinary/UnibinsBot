# 基岩版1.20.81

*页面ID: 119434* | *来源: Minecraft Wiki*

* *1.20.81**是的一次热修复更新，在Fire平台上发布于2024年4月26日<ref></ref>，在除Fire和Nintendo Switch外的平台上发布于2024年4月29日<ref></ref>，在Nintendo Switch平台上发布于2024年5月3日，修复了一些漏洞。此版本与[1.20.80](基岩版1.20.80.md)相兼容。

# 修复
* 修复了一些游戏过程中可能发生的崩溃。
* 相机视角在传送后不再会延迟一帧。
