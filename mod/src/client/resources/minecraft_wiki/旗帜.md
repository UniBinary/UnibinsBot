# 用途
[thumb|x200px|重叠在旗帜上的方块](File:Standing banner with block.png.md)
[thumb|x200px|重叠在附着于方块侧面上的旗帜上的方块](File:Wall banner with block.png.md)

旗帜有16种底色。一面旗帜最多能印6次不同图案。对装有水的[炼药锅](炼药锅.md)旗帜可以将旗帜的最上层（即最后印上的图案）洗去。

类似[告示牌](告示牌.md)，旗帜可以面对不同方向放置在方块的顶面和侧面。旗帜没有碰撞检测，所以[物品](物品.md)与[生物](生物.md)可以穿过旗帜。

其他方块（包括其他旗帜）可以在旗帜碰撞箱的任何边界放置；这意味着尽管旗帜看起来是两个方块高，但是只填充了底部的方块（对于墙上的旗帜则是顶部）。

旗帜可以被放在[物品展示框](物品展示框.md)内，只显示它们物品形式的样子。

[水](水.md)与[熔岩](熔岩.md)会在旗帜周围流动。熔岩会在旗帜旁的空气方块燃起火焰，使得旗帜看起来可燃，但是旗帜不会烧毁（也不会被其他方式点燃的火焰烧毁）。旗帜可以[含水](含水.md)。

旗帜会在附着方块移动、移除或被破坏的情况下被破坏并掉落自身。旗帜被[活塞](活塞.md)推动时会掉落为物品；活塞无法推动旗帜。旗帜被活塞拉动时不会有反应。

# = 复制 =
通过使用空白旗帜，玩家可以复制几个图案相同的旗帜。

# = 合成材料 =
通过使用旗帜，玩家可以给盾牌印上图案。盾牌的分辨率小于旗帜，所以盾牌上的图案会看起来有些差别或偏移。

# = 燃料 =
旗帜可以作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个旗帜可以燃烧1.5个物品。

# = 重命名 =
旗帜可以被指定一个自定义名称，这个名称在放置和回收时可以保留。玩家可以通过[铁砧](铁砧.md)重命名旗帜，命令更改旗帜的方块数据<code>CustomName</code>|je}}。

# = 地图标记 =

拿着[地图](地图.md)右键点击旗帜可以在地图上旗帜的位置处产生一个标记。标记会与旗帜的基础颜色相同且不会有任何图案。除非地图使用[制图台](制图台.md)锁定，否则破坏旗帜后标记也会跟着被移除。如果重命名旗帜，则会在标记上方显示名称。

# = 图案 =
一面旗帜最多能有6种图案，而且最后添加的图案会覆盖在原有图案的顶部。

任何底色的旗帜都可以被使用，底色会被图案覆盖。可以使用[织布机](织布机.md)为旗帜染上图案；而为旗帜染图案既可以通过使用织布机，也可以通过用[工作台](工作台.md)合成。

# = 穿戴 =
* 使用命令可将头盔槽位的物品替换为旗帜，此时旗帜会出现在玩家的-{}-头部后方。

# 你知道吗
* 旗帜图案的英文名称主要来源于[旗-{}-帜学用语](wikipedia:Glossary_of_vexillology#Basic_patterns.md)，其方向亦以旗帜本身的相对方位为准。部分英文名称因此与命名空间ID中根据观察者视角确定左右的方式是左右相反的。
* 放置出的旗帜具有轻微摆动的视觉效果。
* 考虑到旗帜图案共42种，染料共16种，旗帜共16种，每个旗帜最多可以有6层图案。因此生存模式下可以做出的不重复的旗帜总数理论值为：<div style="text-align: center;"><math>16 \times \sum_{k=0}^6 (16 \times 42)^k = 1475646641940097552 \approx 1.47 \times 10^{18} </math></div>
* * 出于图案覆盖或与基底同色的原因，上述结果中会有相当一部分旗帜在视觉上难以区分。
