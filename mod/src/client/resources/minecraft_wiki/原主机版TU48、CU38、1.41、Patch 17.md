# 原主机版TU48、CU38、1.41、Patch 17

*页面ID: 66432* | *来源: Minecraft Wiki*

* *TU48/CU38/1.41/Patch 17**是[原主机版](原主机版.md)的一次更新，发布于2017年1月27日，修复了一些漏洞。<ref></ref><ref></ref>

# 新内容
# = 游戏内容 =
* *[成就](成就.md)**
* 加入了11个生存成就。
* 加入了7个Tumble成就。

# 更改
# = 常规 =
* *小游戏**
* 封闭了Battle Mini Game地图中不可进入的区域。

# = 游戏内容 =
* *[奖励箱](奖励箱.md)**
* 增加了西瓜种子、南瓜种子、甜菜种子和丛林木树苗在其中生成的概率。

* *[教程](原主机版教程.md)**
在游玩教程世界时重新进入教程区域会重置箱子。

# = 方块 =
* *[刷怪笼](刷怪笼.md)**
* 因受生成限制而生成失败时会出现粒子效果和声音效果。

# = 物品 =
* *[滞留药水](滞留药水.md)**
* 改善了扔出滞留药水时的帧率。

# 修复
* *修复了20个漏洞**
