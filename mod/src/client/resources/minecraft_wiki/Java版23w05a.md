# Java版23w05a

*页面ID: 101511* | *来源: Minecraft Wiki*

<onlyinclude>

* *23w05a**是[Java版1.19.4](Java版1.19.4.md)的第3个快照，发布于2023年2月1日<ref></ref>，重新设计了[创建新的世界](创建新的世界.md)屏幕，使所有盔甲都可加上任意颜色的纹饰，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[选项](选项.md)**
* 加入了“”和“”选项，分别用于调整附魔光效的变化速度和显眼程度。

# 更改
# = 物品 =
* *[盔甲](盔甲.md)和[鞘翅](鞘翅.md)**
* 现在手持的盔甲或鞘翅可以通过按键与对应盔甲槽中的物品交换位置。

# = 命令格式 =
* ***
* 效果持续时长现在可以被指定为。
* * 此时，在物品栏中显示的效果时长会显示为“∞”。

# = 常规 =
* *[创建新的世界](创建新的世界.md)**
* 重新设计了布局，现在被分为3个：
* * “游戏”：用于设置世界名称、[游戏模式](游戏模式.md)、[难度](难度.md)及允许[作弊](作弊.md)。
* * “世界”：用于设置[世界类型](世界类型.md)、[种子](种子（世界生成）.md)及[结构](结构.md)与[奖励箱](奖励箱.md)的生成。
* * “更多”：用于设置[游戏规则](游戏规则.md)及进入[数据包](数据包.md)选择屏幕。
* 移除了“编辑世界”屏幕中的“导入设置”和“导出设置”按钮。

* *[菜单屏幕](菜单屏幕.md)**
* 更改了菜单界面[提示框](提示框.md)确定显示位置的方式。

# 更改（实验性）
# = 物品 =
* *[锻造模板](锻造模板.md)**
* 增加了多种锻造模板的生成概率。
* * 现在沙丘、海岸、荒野和哨兵盔甲纹饰锻造模板在其对应战利品箱中总会生成2个。
* * 下界合金升级锻造模板的生成概率加倍。
* * 现在[要塞](要塞.md)图书馆的战利品箱中总会生成1个眼眸盔甲纹饰锻造模板。
* * 大幅增加了恼鬼盔甲纹饰锻造模板在[林地府邸](林地府邸.md)中的生成概率。
* 更改了沙丘盔甲纹饰的纹理，将[胸甲](胸甲.md)正面的纹饰整体上移了2个像素。

# = 游戏内容 =
* *[盔甲](盔甲.md)**
* 现在皮革盔甲也可以在[锻造台](锻造台.md)中加上纹饰。
* 现在锻造原材料可以与盔甲材料相同。

# = 常规 =
* *[数据包](数据包.md)**
* 在中定义了一个新字段：
* * ：可选，用于要被覆盖调色板的盔甲材料映射表。
* ** 键名为要被此锻造材料覆盖调色板的盔甲材料。
* ** 键值为当锻造材料应用于对应盔甲材料时，需要使用的调色板名称。
* 移除了字段。

* *[标签](Java版标签.md)**
* 向物品标签中加入了。
