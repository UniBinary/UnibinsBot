# 雕纹砂岩

*页面ID: 99477* | *来源: Minecraft Wiki*

* *雕纹砂岩（Chiseled Sandstone）**是[砂岩](砂岩.md)制作的装饰性方块，四个侧面上都有一个[苦力怕](苦力怕.md)的脸。

# 生成
# = 自然生成 =
雕纹砂岩会在沙漠村庄、沙漠神殿和温带海底废墟中生成，还会生成在试炼密室中生成[尸壳](尸壳.md)的[试炼刷怪笼](试炼刷怪笼.md)旁。

# 破坏
挖掘雕纹砂岩的合适工具是镐。雕纹砂岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

雕纹砂岩被破坏后会掉落自身。
