* *腐败的薯皮草方块（Corrupted Peelgrass Block）**是[薯皮草方块](薯皮草方块.md)的腐败变种。

# 生成
# = 自然生成 =
腐败的薯皮草方块自然生成在[腐败区](腐败区.md)和[废土](废土.md)群系。

# = 转化 =
腐败的薯皮草方块可以蔓延至附近的[马铃薯泥土](马铃薯泥土.md)和[泥土](泥土.md)上，类似于草方块的蔓延。

对着马铃薯泥土的顶部腐败的马铃薯皮会将马铃薯泥土转化为腐败的薯皮草方块。

# 获取
腐败的薯皮草方块只能通过带有[精准采集](精准采集.md)的工具破坏自身获得。

# 破坏
挖掘腐败的薯皮草方块的合适工具是锹。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，腐败的薯皮草方块被破坏后会掉落1个[马铃薯泥土](马铃薯泥土.md)。

被具有精准采集的工具挖掘破坏时，腐败的薯皮草方块被破坏后会掉落自身。

# 用途
# = 方块转化 =
对腐败的薯皮草方块使用[锄](锄.md)可以将其转变成[剧毒耕地](剧毒耕地.md)。

马铃薯可以直接在腐败的薯皮草方块上种植。

对腐败的薯皮草方块使用[锹](锹.md)可以将其转变成[剧毒土径](剧毒土径.md)。

# = 削皮 =
对腐败的薯皮草方块使用[马铃薯削皮刀](马铃薯削皮刀.md)会将其转化为[马铃薯泥土](马铃薯泥土.md)，并掉落腐败的[马铃薯皮](马铃薯皮.md)。

# = 生物转化 =
当[绵羊](绵羊.md)食用腐败的薯皮草方块后，被食用方块会转化成[马铃薯泥土](马铃薯泥土.md)，绵羊会获得1秒的[中毒](中毒.md)效果。
