# Java版Indev 0.31 20100104-2154

*页面ID: 172003* | *来源: Minecraft Wiki*

<onlyinclude>
* *0.31**的一个版本发布于2010年1月4日21:54（UTC）<ref>[Adura的IRC记录](#logs.md): "(16:54:47) <Notch> /indev/ has been updated"</ref>，加入了新的音效引擎。<ref></ref>

# 新内容
# = 游戏内容 =
* *[音效](音效.md)**
* 加入了新的音效引擎。

# 更改
# = 游戏内容 =
* *[平视显示器](平视显示器.md)**
* 将[火把](火把.md)添加到了快捷栏中。

* *[创造模式物品栏](创造模式物品栏.md)**
* 不再能被打开，因为与其绑定的键位已被移除，并且无法在选项中为其设置键位。与其相关的类文件也已被删除。
* * 此版本没有发布[创造模式](创造模式.md)，因此这个更改未使用，只能通过修改游戏找到。

* *[亮度](亮度.md)**
* 动态光照不再影响[物品栏](物品栏.md)和快捷栏中的物品。</onlyinclude>
