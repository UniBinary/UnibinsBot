# 基岩版1.21.110.23

*页面ID: 162036* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.110.23**（ChromeOS/Android）、**Preview 1.21.110.23**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.111](基岩版1.21.111.md)的第3个测试版，发布于2025年8月6日<ref></ref>，加入了一些铜质装饰性方块，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[铜火把](铜火把.md)**
* [火把](火把.md)的变种。
* 由[铜粒](铜粒.md)、[煤炭](煤炭.md)和[木棍](木棍.md)合成。

* *[铜栏杆](铜栏杆.md)**
* [铁栏杆](铁栏杆.md)的铜质变种。
* 由6个[铜锭](铜锭.md)合成。
* 能够氧化、被涂蜡、除蜡或除锈。

* *[铜链](铜链.md)**
* 铁链的铜质变种。
* 由2个铜粒和1个铜锭合成。
* 能够氧化、被涂蜡、除蜡或除锈。
* 与铁链一样，可用于合成[悬挂式告示牌](悬挂式告示牌.md)。

* *[铜灯笼](铜灯笼.md)**
* [灯笼](灯笼.md)的铜质变种。
* 由8个铜粒和1个铜火把合成。
* 能够氧化、被涂蜡、除蜡或除锈。
* * 氧化程度仅会改变外观，不会影响亮度。

# = 游戏内容 =
* *[粒子](基岩版粒子.md)**
* 加入了粒子。

# 更改
# = 方块 =
* *[铜箱子](铜箱子.md)**
* 现在可与[蜜脾](蜜脾.md)合成为对应的涂蜡变种。

* *[铜傀儡像](铜傀儡像.md)**
* 现在被[活塞](活塞.md)推动时会被破坏并掉落，并且不再能被[黏性活塞](黏性活塞.md)拉动。
* 现在可以[含水](含水.md)。
* 现在可与蜜脾合成为对应的涂蜡变种。

* *[铜活板门](铜活板门.md)**
* 配方由6个[铜锭](铜锭.md)更改为4个铜锭。

* *[铁链](铁链.md)**
* 锁链（Chain）现在被重命名为铁链（Iron Chain）。
* * ID由更改为。
* ** 仍然可用，但不会在命令提示中显示。

* *[避雷针](避雷针.md)**
* 现在未涂蜡的避雷针会在被闪电击中时完全变白，以匹配。
* 现在可与蜜脾合成为对应的涂蜡变种。

* *[展示架](展示架.md)**
* 现在创造模式玩家手持物品与未激活的展示架交互时，所选槽位中的物品会被替换为玩家手持物品，而不是与之交换。
* 调整了槽位中物品的位置。

# = 物品 =
* *[剪刀](剪刀.md)**
* 现在可用于剪下[铜傀儡](铜傀儡.md)头上的[虞美人](虞美人.md)。
* * 不会掉落虞美人。

# = 生物 =
* *[铜傀儡](铜傀儡.md)**
* 将碰撞箱宽度由0.875格缩小至0.6格。
* 现在可以开关[木门](木门.md)和[铜门](铜门.md)。

* *[铁傀儡](铁傀儡.md)**
* 现在会将虞美人赠予附近的铜傀儡，接受的铜傀儡会将其戴到头上。

* *[狐狸](狐狸.md)**
* 现在会将[蜂蜜瓶](蜂蜜瓶.md)视为食物类食品，并会倾向于将其捡起。
