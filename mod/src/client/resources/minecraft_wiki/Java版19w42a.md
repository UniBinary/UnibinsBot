# Java版19w42a

*页面ID: 48862* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w42a**是[Java版1.15](Java版1.15.md)的第10个快照，发布于2019年10月16日<ref name="19w42a"></ref>，令[黏液块](黏液块.md)和[蜂蜜块](蜂蜜块.md)不再会粘在一起，同时修复了一些漏洞。

# 新内容
# = 常规 =
* *[标签](Java版标签.md)**
* 加入了物品标签。

* *附魔**
* 附魔物品现在可以在黑暗中发光了。

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 现在会在面朝的方块不是[水](水.md)时正确地发射[玻璃瓶](玻璃瓶.md)。
* 由发射器射出的[火焰弹](火焰弹.md)现在可以点燃[营火](营火.md)了。
* 现在可以用于放置[盔甲架](盔甲架.md)了。

* *[蜂蜜块](蜂蜜块.md)和[黏液块](黏液块.md)**
* 不再会粘在一起。

# = 常规 =
* *纹理**
* 移除了未使用的两个纹理（蜂蜡块和结晶蜜）。

# 修复
创建的物品展示框是不可见/遥远的。
