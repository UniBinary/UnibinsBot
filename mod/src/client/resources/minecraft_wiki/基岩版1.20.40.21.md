# 基岩版1.20.40.21

*页面ID: 105801* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.40.21**（ChromeOS/Android）、**Preview 1.20.40.21**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.40](基岩版1.20.40.md)的第2个测试版，发布于2023年9月13日<ref></ref>，修复了一些漏洞。

# 更改
# = 技术性 =
* *[附加包](附加包.md)和脚本引擎**
* 现在会防止方块被变换至超过30×30×30像素的限制，也会防止被平移或缩放。无效方块现在会显示为数据更新方块。（）

* *API**
* 在版本中开放了。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“”、“”和“”子选项后才可使用。

# = 物品 =
* *[探险家地图](探险家地图.md)**
* 现在新加入的7种探险家地图也会指向已探索区块中的结构。

# = 技术性 =
* *图形**
* 修复了延迟渲染预览功能中的粒子效果不会持续发亮的问题。

* *物品**
* 自1.20.40版本起，弃用了组件。
* 自1.20.40版本起，弃用了组件。
* 自1.20.40版本起，弃用了组件。

# 修复
* *性能与稳定性**
* 修复了在“”市场地图中的“Archold”房间中运行时可能发生的崩溃。

* *原版趋同**
* 更改了溅水音效。（）
* * 现在仅会在活动对象被水淹没至眼部高度时播放进入或离开水中的环境音效，以同步Java版。
* * 更新了进入水中时的溅水音效以匹配Java版。
* 现在HUD上的Boss栏使用与Java版相同的颜色。（）
* 骆驼不再能在熔岩或水中冲刺。
* 铁傀儡不再会自然生成于会导致它们窒息的2格高空间内。（）

* *游戏内容**
* 药箭被阻挡时，玩家不再会受到药箭的状态效果的影响。（）
* 下界和末地中创建的村庄不再会保存至主世界。（）

* *物品**
* 现在再次可以使用铁桶取出含水方块中的水，完全被水淹没的含水方块除外。（）

* *触摸控制**
* 加入了关闭“”选项时的骆驼冲刺按钮。（）
* 修复了使用触摸控制时的潜行键会部分挡住向前移动的方向键的问题。（）</onlyinclude>
