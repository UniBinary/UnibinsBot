# 用途
对着方块（包括流体）的上表面船可以将其放在世界中，朝向玩家面向的方向，并和放置方块一样需要放置的位置有足够的空间且不能有其他实体阻挡。玩家浸没在流体中时不能放置船。

# 行为
对着船按下键或上船。

下船可以使用键、键}}。下船时的落点由玩家当前视角的水平朝向决定，若玩家所朝方向没有与船紧邻的固体方块，落点为船的正中心位置。下船时的落点为船的正中心位置，而与视角朝向无关。

使用键鼠或控制时，船的控制使用键、（左转）、（右转）和键。

使用触摸控制时，若控制模式为“”，则船的控制使用两个划桨键：拨动右桨将船左转，拨动左桨将船右转，两键同时按下时船往前行进；若控制模式为“”或“”，则船的控制使用移动摇杆，使用方式与使用键鼠或手柄时类似。

和[床](床.md)不一样，试图登上已经有两个实体搭乘的船不会出现一条已被占用的消息。<ref></ref>

船上方存在水或[含水方块](含水.md)时，玩家不能上船。当船视角线<!-- 船碰撞箱蓝色线 -->未被水或含水方块完全浸没时，玩家不能上船，但生物仍能上船并在1[刻](刻.md)后主动下船；当船视角线被水或含水方块完全浸没时，玩家和生物都不能上船。

# = 掉落 =
船的掉落受到**损坏度（Damage）**的影响，每点伤害会造成10点损坏度。船损坏度的初始值为0，大于40后船会掉落。如果损坏度大于0，则每游戏刻减少1。所以单次攻击伤害大于时可以一击让船变成掉落物。

船的掉落受到**结构完整度（Structural Integrity）**的影响，每点伤害会减少1点结构完整度。船结构完整度的初始值为40，但不会随时间恢复。<ref></ref><ref></ref>与[矿车](矿车.md)不同的是，当玩家重载船所在区块时，船的结构完整度会恢复至初始值。

创造模式下的玩家对船造成伤害时可以将其一击摧毁。

[状态效果](状态效果.md)可以改变玩家对船的或的影响，但暴击与[锋利](锋利.md)魔咒均不会。

# = 控制 =
[缩略图|处于气泡柱上方的摇晃的船](File:Oak Boat shake.gif.md)
船根据玩家的控制进行移动，或由水流带动。在水面上前进时，它与[矿车](矿车.md)单坐标轴的最大速度相同，为8m/s。在岸上时，它也能以2m/s移动。船不会根据鼠标视角的移动而改变运动方向。玩家不能在划桨的同时使用物品。

船可用于快速安全地通过水域，不会因为撞击或下落而损毁。船会不受阻碍地穿过[睡莲](睡莲.md)并将其摧毁。船在[冰](冰.md)、[霜冰](霜冰.md)、[浮冰](浮冰.md)、[蓝冰](蓝冰.md)上移动非常迅速。在冰、霜冰和浮冰上的速度可以达到40m/s，而在蓝冰上可以达到72.73m/s。

在特定方块上移动时，船的速度将比在普通方块上时更低，在[黏液块](黏液块.md)上的速度为0.92m/s，在[蜂蜜块](蜂蜜块.md)或[灵魂沙](灵魂沙.md)上则为1.053m/s。

若船被水浸没（比如进入瀑布）就会沉没。船在被浸没时不会沉没，而会上浮。因此借助阶梯式上坡水流可实现“仅用流水带动船只上坡”。

处于[气泡柱](气泡柱.md)上方的船会晃动。船持续位于[岩浆块](岩浆块.md)产生的涡流气泡柱上方3秒后会沉没，并令所有乘客下船。船在脱离涡流气泡柱后便会恢复上浮，而不会；[灵魂沙](灵魂沙.md)产生的涌流气泡柱可以使沉没的船重新上浮。当涌流和涡流气泡柱同时作用于一艘船，它会在水面上下浮动而不沉没，且乘客会掉出船。

非玩家生物要走上船或者走下船才能上船；非玩家生物与船接触就会上船，玩家驾船驶向生物亦可以使其上船。[鱼](鱼.md)类、[蝌蚪](蝌蚪.md)、[嘎枝](嘎枝.md)和[边界箱](边界箱.md)宽度超过船自身宽度的生物不能上船。

船可以承载两个生物，具有前排和后排两个座位。坐在前排的生物可对船进行驾驶控制，后排的生物在前排的生物驾驶船时可以正常使用自己的物品。当前排的生物退出船后，后排的生物会进入前排。玩家与非玩家生物同时乘船时，玩家总是会取-{}-得前排。船上只有一个生物时，这个生物会坐在船的中间位置。玩家不能进入两个座位均被生物占用的船。

乘船时，乘客的视角被限制在正前方180°角，但非玩家生物还是能向背后进行近战攻击或发射弹射物。[旋风人](旋风人.md)在船上时仍然能随意转动身体。

# 你知道吗
* 在特制的蓝冰做成的轨道上行驶的船是一种十分有效的快速交通的途径，可以达到72.727米/秒的速度。如果在下界，这个速度将超过以主世界为标准的[音速](wzh:音速.md)，达到时速2016公里，接近于一架[协和式客机](wzh:协和式客机.md)的时速。
* [下落的方块](下落的方块.md)掉落到船上时会破坏并掉落为物品。
* 当船上有两名乘客时，船的速度不会因多了一名乘客而减慢，而是与玩家单人乘坐时的速度一样快。
* 玩家第一次进入水中就会解锁船的配方，但进入含水方块中却不能解锁。<ref></ref>
