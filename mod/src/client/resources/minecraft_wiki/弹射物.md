# 弹射物

*页面ID: 55603* | *来源: Minecraft Wiki*

* *弹射物（Projectile）**是一类沿轨迹飞行并可以命中各类物体的[实体](实体.md)，可以造成[伤害](伤害.md)等多种效果。

# 生成
多种生物会生成弹射物作为它们的攻击手段。玩家也可以使用部分物品来生成弹射物。

[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、[焦骸](焦骸.md)、[凋灵骷髅](凋灵骷髅.md)、可以使用[弓](弓.md)来发射[箭](箭.md)，[掠夺者](掠夺者.md)、[猪灵](猪灵.md)可以使用[弩](弩.md)来发射箭或[烟花火箭](烟花火箭.md)，[烈焰人](烈焰人.md)可以发射[小火球](小火球.md)，[恶魂](恶魂.md)可以发射[火球](火球.md)，[雪傀儡](雪傀儡.md)可以发射雪球，[旋风人](旋风人.md)可以发射[风弹](风弹（实体）.md)，[女巫](女巫.md)可以发射[喷溅药水](喷溅药水.md)，[末影龙](末影龙.md)可以发射末影龙火球，[凋灵](凋灵.md)可以发射凋灵之首，[羊驼](羊驼.md)和行商羊驼可以发射羊驼唾沫，[溺尸](溺尸.md)在持有[三叉戟](三叉戟.md)时可以发射三叉戟，[潜影贝](潜影贝.md)可以发射能够锁定并追踪目标的[潜影弹](潜影弹.md)，[村民](村民.md)可以发射烟花火箭。

[玩家](玩家.md)可以使用弓发射箭，可以使用弩发射箭或烟花火箭，可以对任意方块表面使用烟花火箭来在指定位置将其发射，可以[钓鱼竿](钓鱼竿.md)来发射和收回[浮漂](浮漂.md)，可以通过来发射[鸡蛋](鸡蛋.md)、[雪球](雪球.md)、[末影珍珠](末影珍珠.md)、[喷溅药水](喷溅药水.md)、[滞留药水](滞留药水.md)、[附魔之瓶](附魔之瓶.md)、[风弹](风弹（物品）.md)和。

[发射器](发射器.md)可以发射[箭](箭.md)、[火焰弹](火焰弹.md)（发射为[小火球](小火球.md)）、烟花火箭、鸡蛋、雪球、喷溅药水、滞留药水、附魔之瓶、风弹和。

# 行为
弹射物按照一定的速度飞行，最终击中方块、实体或，并产生效果。弹射物还可能会受到多种物理效果，如受重力影响而下坠，受[蜘蛛网](蜘蛛网.md)、[液体](液体.md)等阻力减速，或被[爆炸](爆炸.md)加速。多数弹射物在击中物体后会破裂，从世界中消失。

除浮漂外，所有弹射物的实体数据都具有记录该弹射物的发射者。在弹射物造成伤害时，该伤害被视为由发射者间接造成，并引发相关的伤害效果和[魔咒](魔咒.md)效果。发射器发射的弹射物不具有该实体数据。

被生物发射的弹射物会被发射者的影响其初速度：弹射物在X/Z轴上的速度会与发射者同轴上的速度相加，如果发射者不在地面上，弹射物在Y轴上的速度还会与发射者的竖直速度相加。

# = 与实体碰撞 =
弹射物在离开发射者的碰撞箱前不能命中发射者。在弹射物离开发射者后，弹射物可以击中甚至击杀发射者。

对命中实体造成伤害的弹射物，均对命中的实体造成[弹射物伤害](弹射物伤害.md)和沿其运动方向的[击退](伤害#击退.md)。[弹射物保护](弹射物保护.md)提供针对弹射物伤害的伤害减免。[着火](着火.md)的箭、鸡蛋、雪球、三叉戟、风弹还会点燃命中的实体。和命中实体时造成的伤害同时是弹射物伤害和[火焰伤害](火焰伤害.md)。

[盾牌](盾牌.md)可以抵挡几乎所有弹射物的命中，使其被弹开或破裂而不能造成伤害。仍有剩余穿透数量的箭是唯一一种可以穿透实体并无视盾牌的弹射物。

除[潜影弹](潜影弹.md)外的所有弹射物的直接命中都会被[末影人](末影人.md)通过传送来躲避，使弹射物可以继续飞行下去。

[旋风人](旋风人.md)不会受到除风弹外<ref></ref>任何弹射物的伤害，同时命中旋风人的这些弹射物会被减速<ref>-伤害。|WAI}}</ref>并朝发射者的方向重新射出。

# = 与方块碰撞 =
所有的弹射物都可以触发其击中的[标靶](标靶.md)，击塌其击中的[大型垂滴叶](大型垂滴叶.md)。

所有的弹射物可以激活[木质压力板](木质压力板.md)和[绊线](绊线.md)，和可以激活[木质按钮](木质按钮.md)。当弹射物穿过这些方块时，这些开关会保持开启状态。其他开关则不受弹射物的影响。[箭](箭.md)和[三叉戟](三叉戟.md)可以插在方块上，并保持这些开关的开启。

任何具有伤害的弹射物都可以敲响[钟](钟.md)。任何弹射物都可以敲响[钟](钟.md)。

着火的弹射物可以不受阻碍地穿过并激活[TNT](TNT.md)，可以点燃熄灭的[营火](营火.md)，可以破坏其穿过的[细雪](细雪.md)，其着火状态不能被细雪熄灭。

弹射物能够破坏以下方块：
* [三叉戟](三叉戟.md)会破坏其击中的[滴水石锥](滴水石锥.md)。
* [箭](箭.md)、[三叉戟](三叉戟.md)、[鸡蛋](鸡蛋.md)、[雪球](雪球.md)、[小火球](小火球.md)、[恶魂火球](恶魂火球.md)、[末影龙火球](末影龙火球.md)、[凋灵之首](凋灵之首.md)、[风弹](风弹（实体）.md)、[烟花火箭](烟花火箭.md)和会破坏其击中的[紫颂花](紫颂花.md)或[饰纹陶罐](饰纹陶罐.md)。

# = 与世界边界碰撞 =
箭类弹射物和浮漂会在碰到[世界边界](世界边界.md)时反弹，烟花火箭会沿边界飞行，而其他弹射物则会在边界处破裂或消失。

# 弹射物分类
# = 箭类弹射物 =
箭类弹射物包括、|je}}和。

这些弹射物在击中方块时会插在方块上，并有机会被回收。如果这些弹射物射中的方块被改变或方块的碰撞模型发生了变化，这些弹射物就会再次下坠并有机会命中实体或插在另一个方块上。在停止运动1分钟后，这些弹射物会消失。

被盾牌挡下时，这些弹射物会被弹开而不会破裂。三叉戟在任何情况下都不会破裂。

[末影人](末影人.md)、外壳关闭的[潜影贝](潜影贝.md)、栖息状态的[末影龙](末影龙.md)（）、生命值低于一半的[凋灵](凋灵.md)、处于创造模式的[玩家](玩家.md)、不能被这些弹射物命中，接触到这些生物时会被弹开并失去速度落到地面上。

# = 火球类弹射物 =

这些弹射物不受重力影响，而是按照其实体数据特殊指定的加速度来保持持续的位置变化。风弹以外的火球类弹射物在1分钟后都会消失，不能无限地飞行下去。
