# Java版18w09a

*页面ID: 33859* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w09a**是[Java版1.13](Java版1.13.md)的第23个快照，发布于2018年3月1日<ref></ref>，加入了珊瑚块和海底废墟，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[珊瑚块](珊瑚块.md)**
* 有5种颜色：蓝色、粉红色、紫色、红色与黄色。
* 需要水来维持存活。
* * 若没有水，会变为失活的珊瑚。
* ** 失活的珊瑚无法复活。
* 目前仅可在创造模式物品栏中获得。

# = 世界生成 =
* *结构**
* [海底废墟](海底废墟.md)
* * 拥有多种不同的形状和大小。
* * 冷水废墟生成于冷水海洋和冻洋生物群系，无视深度。
* * 温水废墟生成于暖水海洋、温水海洋和温水深海生物群系。
* * 可单独生成，也可成片生成类似村庄的废墟。
* * 有时也会有部分处于地下或海平面之上。

# 更改
# = 生物 =
* *[幻翼](幻翼.md)**
* 不再生成于[末地](末地.md)。
* 现在会在白天时消失。

# = 命令格式 =
* *[标签](Java版标签.md)**
* 加入了方块标签<code>minecraft:coral</code>。
* <code>minecraft:water_hacked</code>标签现在包含[箱子](箱子.md)。

# = 游戏内容 =
* *[粒子](粒子.md)**
* 稍微优化了粒子渲染。
