* *USB充电块（USB Charger Block）**是能持续发出强度为15的红石信号的方块，类似于[红石块](红石块.md)。

# 生成
USB充电块不会生成在世界中。

# = 合成 =

# 破坏
挖掘USB充电块的合适工具是镐。USB充电块需要木镐或更好品质的镐来挖掘，否则挖掘时间将延长且不会掉落。

USB充电块被破坏后会掉落自身。

# 用途
# = 红石元件 =

USB充电块保持输出信号，它不能被关闭，USB充电块会：
* 激活任何毗邻的红石线并改变其指向，包括它上面的和下面的红石线（但不会更改指向），向其[提供](红石元件#电源.md)15级的信号等级。
* 激活任何四周的背对USB充电块的[红石中继器](红石中继器.md)和[红石比较器](红石比较器.md)，向它们[提供](红石元件#电源.md)等级为15级的红石信号。
* 激活附着其上的[红石火把](红石火把.md)使其熄灭。
* 激活任何毗邻的[机械元件](红石元件.md)（如[门](门.md)、[红石灯](红石灯.md)等），包括USB充电块上面的和下面的红石元件。但[活塞](活塞.md)不能被任何在它前面的电源常规激活。
* 向红石比较器的边侧输入信号。

USB充电块表现的性质和强充能方块类似，与USB充电块相邻的红石导体不会被充能，但其实它不是[红石导体](红石导体.md)，例如USB充电块处于[箱子](箱子.md)上方时不会阻止箱子被开启。

若[红石火把](红石火把.md)附着USB充电块，它会在刚被放置时亮起1红石刻，随后因USB充电块保持输出而保持熄灭。
