# Java版20w19a

*页面ID: 61856* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w19a**是[Java版1.16](Java版1.16.md)的第15个快照，发布于2020年5月6日<ref name="20w19a"></ref>，加入了新的统计信息和新的方块标签，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[统计](统计.md)**
* 加入了[炽足兽](炽足兽.md)骑乘距离的统计信息。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 包含带有标签的方块以及凋灵玫瑰与甜浆果丛。
* * 生物不能生成于带有此标签的方块内。

# 更改
# = 方块 =
* *[黑石](黑石.md)**
* 底部纹理现在与顶部纹理统一了。

* *[绯红木门](绯红木门.md)和[诡异木门](诡异木门.md)**
* 现在纹理包含铰链了。

* *[下界苗](下界苗.md)**
* 现在需使用[剪刀](剪刀.md)采集。
* 现在在方块里的位置会随机偏移，类似于[花](花.md)和[草丛](草丛.md)。

* *[绯红菌索](绯红菌索.md)和[诡异菌索](诡异菌索.md)**
* 现在在方块里的位置会随机偏移，类似于[花](花.md)和[草丛](草丛.md)。

* *[红石粉](红石粉.md)**
* 与高一格的[灵魂沙](灵魂沙.md)和八层[雪](雪.md)上的红石粉连接时，现在视觉上也向上连接。
* 与高一格的[楼梯](楼梯.md)上的红石粉连接时，如果是在楼梯背部，现在视觉上也向上连接。
* 现在，在红石线的整体都产生粒子，以前只在中心产生。
* * 现在，由于精度损失，当距离原点超过百万格时，粒子的位置将不正确<ref></ref>（参见[距离现象/Java版](距离现象/Java版.md)）。

* *[缠怨藤](缠怨藤.md)和[垂泪藤](垂泪藤.md)**
* 降低了对它们使用[骨粉](骨粉.md)时所生长的高度。

# = 生物 =
* *常规**
* 生物现在不能再在[凋灵玫瑰](凋灵玫瑰.md)里生成了。
* 调整了生成方式，使其更趋向于遵循生物生成上限。

* *[鱼](鱼.md)**
* 它们现在有自己的生成类别和生成上限了。

* *[疣猪兽](疣猪兽.md)与[猪灵](猪灵.md)**
* 现在在[末地](末地.md)也会僵尸化了。

* *[铁傀儡](铁傀儡.md)**
* 现在生成铁傀儡的条件与[村民](村民.md)的工作状态与最近工作时间无关。

# = 世界生成 =
* *[下界](下界.md)**
* 略微降低了[堡垒遗迹](堡垒遗迹.md)的生成频率。
* 更改了[生物群系](生物群系.md)的分布。
* 现在小堆的[黑石](黑石.md)和[沙砾](沙砾.md)会生成于任何下界生物群系的熔岩海高度了。
* 现在小堆的[灵魂沙](灵魂沙.md)会生成于[灵魂沙峡谷](灵魂沙峡谷.md)的熔岩海高度了。

# = 游戏内容 =
* *创造模式[物品栏](物品栏.md)**
* 方块分类与标签名称不再使用粗体。

* *[配方书](配方书.md)**
* [指南针](指南针.md)和[时钟](时钟.md)不再能在配方书中运作了。

# = 常规 =
* *[标签](Java版标签.md)**
* 更改了方块与物品标签，以使用其对应的标签。
* * 这实际上使得绯红木楼梯和诡异木楼梯有了该标签。
