# 基岩版1.20.80.20

*页面ID: 113934* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.80.20**（ChromeOS/Android）、**Preview 1.20.80.20**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.20.80](基岩版1.20.80.md)的首个测试版，发布于2024年2月29日<ref></ref><ref></ref>，为[狼铠](狼铠.md)加入了新特性，将[犰狳](犰狳.md)和[狼铠](狼铠.md)相关特性从[实验性玩法](实验性玩法.md)中移出，同步了一些的特性，并修复了一些漏洞。

# = 物品 =
* *[犰狳鳞甲](犰狳鳞甲.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

* *[犰狳刷怪蛋](犰狳刷怪蛋.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

* *[狼铠](狼铠.md)**
* 现在具有64点耐久度，且会根据剩余耐久度呈现不同程度的开裂纹理。
* 现在可以像[皮革盔甲](皮革盔甲.md)一样染色。
* 将物品纹理上移了2个像素，为耐久条腾出空间。
* 添加了用于染色的叠加纹理，并为实体模型添加了半透明的开裂纹理。
* * 开裂纹理与不同。<ref></ref>
* 不再属于[实验性玩法](实验性玩法.md)。

# = 生物 =
* *[犰狳](犰狳.md)**
* 现在能在红色、橙色、黄色、棕色、白色和淡灰色[陶瓦](陶瓦.md)上生成。
* 蜷缩后不再会重置繁殖冷却时间。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[狼](狼.md)**
* 现在在装备狼铠时，受到特定伤害时不减少生命值，改为使其装备的狼铠减少等于向上取整的伤害值的剩余耐久度。
* 现在狼的主人可以对狼使用[犰狳鳞甲](犰狳鳞甲.md)修复其装备的狼铠。
* 更改了狼身上的项圈的纹理以匹配。

# = 游戏内容 =
* *[物品耐久](物品耐久.md)**
* 更改了耐久度条的颜色以匹配。<ref></ref>
* * 现在耐久度条的颜色会从绿逐渐过渡为黄色，再过渡为红色，而非直接从绿逐渐过渡为红色，并且比以前更加明亮。
* * 现在耐久度条的背景是纯黑的，而非透明的。

# 修复
* *狼**
* 现在驯服的狼的项圈会正确显示阴影。（）
* 现在狼坐下时其尾巴会位于正确位置。（）

* *犰狳**
* 犰狳蜷缩后不再会重置繁殖冷却时间。
* 现在即使已开启[实验性玩法](实验性玩法.md)，蜘蛛和洞穴蜘蛛也会远离犰狳。（）

* *方块**
* 现在使用时运III附魔工具挖掘甜浆果丛时最多会掉落6个甜浆果。（）
* 现在完全成熟的可可果总会掉落3个可可豆。
* 现在将两个相同的台阶放置在一起时会变为双层台阶。（）

* *游戏内容**
* 修复了驯服的生物传送至它的主人旁后，该生物的垂直位置在其他玩家视角中不会正确显示的问题。（）
* 马和船在骑乘和取消骑乘时不再会错误移动至先前位置。

* *Realms故事**
* 修复了Realms故事在游玩屏幕中会失去焦点的问题。
* 成员和时间线选项卡现在被限制为最多渲染300个Realm玩家，以避免大型Realm上出现性能问题。
* * 所有玩家仍可在成员选项卡中被搜到。
* 玩家在添加新故事的情况下离开添加新故事界面时，文本框不再会被清除。
* * 玩家本来就可以保存故事的草稿。
* 现在发布Realm故事时，只有当前正在玩由Realm托管的游戏的玩家的-{}-头像会显示在线标记。
* 修复了Realms故事的“决定加入”界面有时候会在视觉上出现损坏的问题。
* 修复了再次选择相同的截图时会取消选择截图，而不是只保留所选截图的漏洞。

* *用户界面**
* 延长了显示标准加载提示的时间间隔。
* 增加了“向前移动”按钮的交互范围，以使玩家无需停止移动即可滑动至附近的按钮。（）
* 现在新的游玩屏幕中导入的世界会在“（导入）”后缀前方出现一个空格（仅测试版本）。
* 现在在触控设备上切换物品时，物品的图标会以正确方向移动。
* 现在自定义饰纹陶罐和染色旗帜会在合成器的输出槽中正确渲染。
* 现在触控设备上的所选物品会在所有屏幕中显示蓝色背景。
* 触摸屏版本的信标、制图台和锻造台界面中不再会缺失移动物品动画。</onlyinclude>
