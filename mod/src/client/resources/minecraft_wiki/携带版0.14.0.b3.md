# 携带版0.14.0.b3

*页面ID: 19749* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.14.0 alpha build 3**是[v0.14.0 alpha](携带版0.14.0.md)的第3个测试版，发布于2016年1月29日<ref>http://pocketbeta.minecraft.net/2016/01/changelog-for-014-build-3.html?m=0</ref>，修复了一些漏洞。

# 更改
* [地图](地图.md)现在会以最大尺寸激活，避免用[铁砧](铁砧.md)放大造成的高花费。
* * 这是在PC合成完整加入之后就会移除的权宜之计。
* 加速[雪](雪.md)、[地毯](地毯.md)和[台阶](台阶.md)的渲染。
* [花](花.md)等类似方块的碰撞箱不再是整个方块。
* 现在可用“创建地图”按钮以激活地图。
* [投掷器](投掷器.md)、[漏斗](漏斗.md)与[发射器](发射器.md)菜单现在有一个滚动式指示器。
* 开放到局域网在游戏中不能改变时会显示成灰色按钮，来表明它不能被更改。
* [女巫](女巫.md)在不攻击玩家的时候会躲避水。
* [运输矿车](运输矿车.md)在创造模式时会掉落物品。
* [红石比较器](红石比较器.md)和[物品展示框](物品展示框.md)的行为更像Java版。
* 增大了[村庄](村庄.md)中[门](门.md)数与[村民](村民.md)数的比值。

# 修复
* *[修复了19个漏洞](https://bugs.mojang.com/browse/MCPE/fixforversion/15500)**
* 从物品展示框移除物品时游戏崩溃。
* 客户端离线时，地图变得不可用。
* 在超平坦世界里破坏漏斗或投掷器使得游戏崩溃。
* 尝试在运输矿车内放入物品使得游戏崩溃。
* 使用合成配方时游戏崩溃。
* 默认的灵敏度偏高。
* 圆石墙的侧面纹理错误。
* 物品展示框内展示的地图没有玩家标记。
* 已附魔的物品的光效变弱。
* 已附魔的盔甲颜色显示错误。
* 附魔光效的动画失效。
* 在服务器重启后，所有玩家都会回到主世界里。
* 漏斗在物品达到最大堆叠数后不再接收物品。
* iOS端下的音效播放错误。
* 阳光下位于水中的亡灵生物不再闪烁着燃烧纹理。
* 无法在多人游戏下聊天。
* 恶地生物群系里自然生成的运输矿车是浮空的。
* 沙子会变成红沙。
* 佩带第二个生物头颅使得前一个被摧毁。</onlyinclude>
