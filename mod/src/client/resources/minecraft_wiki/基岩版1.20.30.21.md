# 基岩版1.20.30.21

*页面ID: 105251* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.30.21**（ChromeOS/Android）、**Preview 1.20.30.21**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.30](基岩版1.20.30.md)的第6个测试版，发布于2023年8月9日至10日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[设置](设置.md)**
* 在Windows平台上的视频设置中加入了“”选项。
* * 用于改善输入延迟，但会增加电池消耗。

# 更改
# = 方块 =
* *[栅栏门](栅栏门.md)**
* 更改了除竹栅栏门外所有栅栏门的物品模型以匹配其方块模型。

* *[幽匿感测体](幽匿感测体.md)和[校频幽匿感测体](校频幽匿感测体.md)**
* 现在能检测以下动作：
* * 使用[命名牌](命名牌.md)
* * [唤魔者](唤魔者.md)召唤[恼鬼](恼鬼.md)或尖牙
* * [鸡](鸡.md)下蛋
* * [海龟](海龟.md)和[青蛙](青蛙.md)产卵
* * 使用[骨粉](骨粉.md)
* * [漏斗](漏斗.md)将[书](书.md)放入[雕纹书架](雕纹书架.md)中
* * 熄灭[火](火.md)
* * 搭乘或取消搭乘载具
* * [兔子](兔子.md)啃食[胡萝卜](胡萝卜.md)作物
* * [狐狸](狐狸.md)吃掉[甜浆果丛](甜浆果丛.md)上的[甜浆果](甜浆果.md)
* * 放置[旗帜](旗帜.md)、[竹笋](竹笋.md)、[生物头颅](生物头颅.md)、[睡莲](睡莲.md)和[青蛙卵](青蛙卵.md)
* * 放置[海泡菜](海泡菜.md)和增加海泡菜的放置数量
* * [海龟蛋](海龟蛋.md)破裂

# = 生物 =
* *[女巫](女巫.md)**
* 现在会在[袭击](袭击.md)时向袭击者投掷喷溅型治疗药水和再生药水。

* *[村民](村民.md)**
* 现在被多次感染并治愈时，所提供的折扣不再翻倍。

# = 世界生成 =
* *[掠夺者前哨站](掠夺者前哨站.md)**
* 现在会生成于[樱花树林](樱花树林.md)。

# = 游戏内容 =
* *[声音](声音.md)**
* 现在以下未使用音效会正常播放：
* * [猪](猪.md)转化为[僵尸猪灵](僵尸猪灵.md)
* * [疣猪兽](疣猪兽.md)转化为[僵尸疣猪兽](僵尸疣猪兽.md)
* 加入了下列音效：
* * 使用[剪刀](剪刀.md)雕刻[南瓜](南瓜.md)
* * [尸壳](尸壳.md)转化为[僵尸](僵尸.md)

# = 常规 =
* *[HUD](HUD.md)**
* 更新了触摸控制下的屏幕上方按钮。

# = 技术性 =
* *[基岩版编辑器](基岩版编辑器.md)**
* 修复了小工具能够无限拖动的问题，以及小工具拖动尺寸相关的漏洞，现在将其限制至100单位。
* * 运作原理：100×100×100的总体积；在总体积100×100×100的范围内创建多个选择的能力。

* *性能与稳定性**
* 游戏尝试放置无效的自定义地物时不再会崩溃。

# 修复
* *音频**
* 现在猪转化为僵尸猪灵时会播放音效。（）
* 现在使用剪刀雕刻南瓜时会播放与Java版相同的雕刻音效。
* 现在疣猪兽转化为僵尸疣猪兽时会播放独特的音效。（）
* 现在物品掉落到熔岩中时会不断播放音效。（）
* 下界合金质物品掉落到熔岩中时不再会偶尔播放音效。（）
* 现在雪傀儡投掷雪球时会播放音效。（）
* 现在尸壳在水下转化为僵尸时会播放音效。

* *市场**
* 修复了Realms上下载的世界无法正确加载包的问题。

* *游戏内容**
* 进入末地传送门返回主世界时，游戏不再会因渲染资源耗尽而崩溃。（）
* 玩家站在方块下方时的地平线不再会改变颜色。（）
* 对准前方并按住放置按钮的情况下在潜行状态跳跃时，方块不再会继续放置在偏离玩家所对准的位置上。
* 村民被多次感染为僵尸村民并被治愈时不再会增加折扣。

* *袭击**
* 女巫现在会在袭击时向袭击者投掷治疗和再生药水。

* *原版趋同**
* 玩家现在可以在创造模式下从爬行或潜行状态切换至飞行状态。
* 现在UI和物品展示框中的栅栏门的图标模型与栅栏门的方块形式相匹配。（）

* *用户界面**
* 更新了触摸控制的菜单HUD图标。

* *结构**
* 掠夺者前哨站现在会生成于樱花树林生物群系。（）

* *振动**
* 现在使用水桶收集鱼、美西螈或蝌蚪时会在正确的位置上产生振动。
* 现在使用命名牌时会产生振动。
* 现在唤魔者召唤恼鬼或尖牙时会产生振动。
* 现在鸡下蛋时会产生振动。
* 现在海龟和青蛙产卵时会产生振动。
* 现在使用骨粉时会产生振动。
* 弹射物卡在幽匿感测体和幽匿尖啸体中时，幽匿感测体和幽匿尖啸体不再会反复激活。（）
* 现在使用漏斗将书放入雕纹书架中时，雕纹书架会产生振动。（）
* 现在熄灭火时会产生振动。
* 现在搭乘或取消搭乘载具时会产生振动。
* 现在兔子啃食胡萝卜作物时会产生振动。
* 现在狐狸吃掉甜浆果丛上的甜浆果时会产生振动。
* 现在卸下盔甲发出的振动频率与装备盔甲发出的振动频率不同。
* 现在放置旗帜时会产生振动。
* 现在放置竹笋时会产生振动。
* 现在放置生物头颅时会产生振动。
* 现在放置睡莲时会产生振动。
* 现在放置青蛙卵时会产生振动。
* 现在放置海泡菜和增加海泡菜的放置数量时会产生振动。
* 现在将海龟蛋添加至放置出的海龟蛋中时会产生与放置方块相同的振动频率。
* 现在无论存在多少个海龟蛋，破坏海龟蛋时会产生与放置方块相同的振动频率。
* 现在海龟蛋破裂时会产生振动。</onlyinclude>
