# Java版Infdev 20100611

*页面ID: 35985* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年6月11日。<ref name="announcement"></ref>

# 新内容
# = 世界生成 =
* *[云](云.md)**
* 现在是立体的，拥有[纹理](纹理.md)，而且半透明。

# 更改
# = 方块 =
* *[门](门.md)**
* 更改了其侧面的纹理。
* * 在先前的版本中其纹理和[木板](木板.md)相同，现在使用了独有的纹理。

# = 世界生成 =
* *[树木](树木.md)**
* 更改了生成数量。

* *常规**
* 地形生成器现在会尝试生成大型岛屿。
* 生成器现在允许生成更高的山脉，甚至会达到高度限制而被切断。</onlyinclude>
