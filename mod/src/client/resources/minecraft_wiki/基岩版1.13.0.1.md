* *beta 1.13.0.1**是[1.13.0](基岩版1.13.0.md)的首个测试版，在Android上发布于2019年7月1日，而在Xbox One和Windows 10上发布于6月27日<ref></ref>，加入了狐狸和命令自动补全，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[结构空位](结构空位.md)**
* 一种透明的方块，用于结构方块显示[空气](空气.md)。
* * 此前开发者使用[屏障](屏障.md)实现其功能。
* 该方块是隐形的，并且拥有一个小碰撞箱。
* * 只有在[结构方块](结构方块.md)中启用"显示隐形方块"时才会显示。
* * 此外，玩家手持结构空位时，所有放置的结构空位都将可见，类似于屏障。
* 用于显示结构中的空位。
* * 不同于空气，不会在加载时覆盖方块。
* * 例如，如果玩家将2格高结构顶部的空气和底部的结构空位加载到一个2格高的石头方块中，则顶部的方块将转变为空气，但底部仍保持为石头。
* 纹理与Java版的不同。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了[狐狸](狐狸.md)刷怪蛋。

# = 生物 =
* *[狐狸](狐狸.md)**
* 是一种夜间生物，在白天睡觉，晚上活动。
* 可以用[甜浆果](甜浆果.md)来使其繁殖。
* * 新生的小狐狸信任并且不会远离玩家。
* 在降雪的[生物群系](生物群系.md)生成白色变种。
* [北极熊](北极熊.md)和[狼](狼.md)会主动攻击它们。
* 信任玩家的狐狸会保护玩家。
* 能够捡起并用嘴携带物品。
* * 会吃掉嘴里的[食物](食物.md)。
* 自然生成的狐狸有概率嘴里叼着东西。
* * 狐狸死亡时，嘴里叼着的物品100%掉落，即使是它生成时叼着的物品。
* * 自然生成时叼着的部分物品的概率与Java版不同。
* 狐狸有概率生成在针叶林[村庄](村庄.md)中。

# = 常规 =
* 使用[命令](命令.md)时坐标可以用自动补全了。
* 为生物持久性加入了组件。
* 加入了新的聊天设置选项以提高可访问性。

# 更改
# = 方块 =
* *[营火](营火.md)**
* 现在能够被[喷溅药水](喷溅药水.md)熄灭，以匹配。

* *[砂土](砂土.md)**
* 当树苗在其上方生长为树木时不再会变为泥土。

* *[结构方块](结构方块.md)**
* 现在可以使用它了，就像Java版中那样。
* 保存和加载功能需要开启[实验性玩法](实验性玩法.md)后才可用。

* *[活塞](活塞.md)**
* 移除了数据值为6或7的活塞。
* 修复了纹理。

# = 物品 =
* *[摄像机](摄像机.md)**
* 不再能通过命令获得。
* 加入了功能。拍摄的照片现在会储存在文件夹里。

* *[地图](地图.md)**
* 填充的地图和已上锁的地图有了新的纹理。

# = 生物 =
* *幼年[猪](猪.md)**
* 现在被闪电击中时会变为幼年[僵尸猪人](僵尸猪人.md)，而不是成年僵尸猪人。

* *[袭击队长](袭击队长.md)**
* 玩家在杀死袭击队长后现在会正确获得[不祥之兆](不祥之兆.md)效果。

* *[村民](村民.md)**
* 村民的职业等级现在有5级而不是3级，以匹配Java版。（）
* 制图师现在收购11块玻璃板而不是10块。

# = 常规 =
* 加入了一条消息，用来通知玩家市场的[资源包](资源包.md)是否与其Minecraft版本兼容。（即若它包含了一个新版本的方块的话）
* iOS版Minecraft将不再拥有“是否关闭Minecraft”的弹框，因为iOS不支持这种应用操作。
