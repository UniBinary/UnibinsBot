# Java版Classic 0.29

*页面ID: 35627* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.29**是[Java版Classic](Java版Classic.md)的一次更新，发布于2009年10月29日。<ref></ref>

# 新内容
# = 常规 =
* *[控制](控制.md)**
* 在[多人游戏](多人游戏.md)开启或停止[降雨](降雨.md)。

# 更改
# = 物品 =
* *[箭](箭.md)**
* 在[创造模式](创造模式.md)中被移除。

# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 多人游戏中其他[玩家](玩家.md)现在会面朝正确的方向。

# 修复
* *修复了2个漏洞**
* 修复了管理员不可破坏管理员放置的基岩的漏洞。
* 在创造模式中，绵羊不能再被剪羊毛了。</onlyinclude>
