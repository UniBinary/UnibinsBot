# Java版18w30b

*页面ID: 35641* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w30b**是[Java版1.13.1](Java版1.13.1.md)的第2个快照，发布于2018年7月26日<ref></ref>，修复了一些漏洞。

== 修复 ==
召唤的闪电坐标会偏移+0.5x、+0.5z。
|74764|粒子不会在第三人称正面视角（按两次）时显示。
|123880|客户端侧的游戏数据包0x0C（Boss条）对两个不同的布尔值都使用了相同的字节。
|123586|Debug的饼形图使用了本地化的特定数字格式。
|120780|区块数据包有时会被多余地创建。
|120664|工具耐久度被允许低于1。
|119856|黏液块模型的<code>cullface</code>参数丢失。
|114218|发射器和投掷器在面向顶部或底部时不会对喷出的粒子作出偏移。
|75465|在GUI隐藏时，黑边效果的可见性并不会根据亮度等级来变化。
|105512|裂纹出现在龙首内部而非外部。
|;1.13的漏洞
|134274|地图上会显示其他拿着不同地图的玩家。
|134273|断开连接的玩家仍会在地图上显示。
|133294|地图上的标记变黑。
|;previous
|134915|在超平坦的玩家或在改变维度后的玩家会在走动、跳跃以及从高处掉落时会变得很快。
|134905|世界游戏刻异常。
|134903|即使游戏规则<code>mobGriefing</code>为false，实体仍然可以站在海龟蛋上破坏它。
|134858|TNT的方块状态<code>explode</code>没有被转换为1.13.1的<code>unstable</code>方块状态。
|134833|移动速度变快。
|134828|服务器崩溃——Ticking world entities
|134826|在删除世界后并不会将世界立即从世界列表中移除，除非在重新进入世界选择列表。
|134819|有时在进入下界后游戏的运行速度会变得更快。
}}</onlyinclude>
