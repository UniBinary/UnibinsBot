此命令用于管理[服务器](服务器.md)中白名单。

服务器的管理员**永远**能够登录开启白名单验证的服务器，无论他们的名字是不是在白名单上。

若开启白名单验证，则玩家必须在白名单中才能进入服务器，而与其管理员权限无关。

白名单储存在或}}文件。

# 语法
   <code>whitelist add <targets></code>（）
   <code>allowlist add <name: string></code>（）
  : 将玩家档案添加到白名单。指定的玩家不需要在线上。
   <code>whitelist list</code>（）
   <code>allowlist list</code>（）
  : 列出白名单中的玩家档案。
   <code>whitelist off</code>（）
  : 在此服务器上禁用白名单验证。
   <code>whitelist on</code>（）
  : 在此服务器上启用白名单验证。
   <code>whitelist reload</code>（）
   <code>allowlist reload</code>（）
  : 从硬盘中重新读取<samp>whitelist.json</samp>或中的白名单列表（当其在Minecraft外被修改时使用）。
   <code>whitelist remove <targets></code>（）
   <code>allowlist remove <name: string></code>（）
  : 将玩家档案从白名单中移除。指定的玩家不需要在线上。

# 参数

  指定要从白名单中添加或删除的玩家档案。



  指定要从白名单中添加或删除的玩家名。
