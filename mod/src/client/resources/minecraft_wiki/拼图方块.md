# 拼图方块

*页面ID: 37205* | *来源: Minecraft Wiki*

* *拼图方块（Jigsaw Block）**是用于生成一些[结构](结构.md)的技术性[方块](方块.md)。

# 生成
拼图方块不会生成在世界中。虽然部分结构包含拼图方块（如[掠夺者前哨站](掠夺者前哨站.md)和[村庄](村庄.md)等），但这些拼图方块在结构自然生成时被转换为了其他方块，故不会生成在世界中。

玩家手动使用[结构方块](结构方块.md)加载包含拼图方块的结构会正常地生成拼图方块。

# 获取

拼图方块无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，拼图方块可以通过”，或“”中有拼图方块）|JE}}、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
拼图方块不能被挖掘破坏。

拼图方块被破坏后不会掉落。

拼图方块是一种允许游戏使用较小模板生成结构的拼接方块。

拼图方块的用户界面有如下输入字段，可配置其生成结构的方法：

   默认为。

;
   该拼图方块的名称。
   默认为。

;

   默认为。

;
   成功生成结构后，拼图方块转变为的方块（可指定方块状态）。
   默认为<code>minecraft:air</code>。

   用于定义某结构模板中各拼图方块的顺序，以便生成连接部件。


;

}}

;
   只在方块朝上或朝下放置时出现。
   含有两种和。
  * ：生成时，拼图方块会随机将目标结构或实体置于与该拼图方块处于同一XZ轴的结构方块的边界内。默认为此类型。
  * ：生成时，拼图方块会直接把目标结构或实体置于自身所朝的方向（上方或下方）。可用于连接结构和固定的实体。
;

;

   默认为“开启”。
;
   可用来生成后续的结构部件。
   使用“层数”中填写的参数来生成结构的后续部分。

拼图方块目前仅用于生成[掠夺者前哨站](掠夺者前哨站.md)、[村庄](村庄.md)、[堡垒遗迹](堡垒遗迹.md)、[远古城市](远古城市.md)、[古迹废墟](古迹废墟.md)和[试炼密室](试炼密室.md)。这些结构的生成开始于包含拼图方块的模板。每个拼图方块都使用下列流程来生成另一个模板：
# 在目标池内随机选择一个模板。
# 在同一个连接类型中，至少存在1个拼图方块来生成模板。如果有多个方块符合条件，那么会随机选择其中的一个。
# 这会使2个拼图方块“连接”。放置模板后使第2个拼图方块朝向第1个拼图方块并与之相邻。
# 最后，两个拼图方块会被替换为对应的“转变为”中设置的方块。
初始模板和附加模板里的拼图方块都会重复上述流程，直到没有剩余的拼图方块（或者游戏认为结构已经足够大）为止。然而，使用[结构方块](结构方块.md)加载结构不能复现上述过程，结构仍会包含拼图方块。

提示：要使拼图方块在上述流程中可靠地连接，需要符合以下两个条件之一：
* 拼图方块的正面必须紧贴在当前结构的边界上，这样新生成的结构就会完全位于当前结构边界的外部。这对源拼图方块和目标拼图方块都适用。
* 新生成的结构完全位于当前结构边界的内部。

在单人游戏中打开拼图方块GUI会暂停游戏。
