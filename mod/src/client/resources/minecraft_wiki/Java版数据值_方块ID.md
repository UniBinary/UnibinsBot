# Java版数据值/方块ID

*页面ID: 94357* | *来源: Minecraft Wiki*

大多数方块都有对应的物品，可以用来放置这个方块，或者是仅仅用来表示这个方块。比如[超平坦](超平坦.md)的自定义屏幕、[末影人](末影人.md)搬运方块时的掉落物。下方表格中使用不同的颜色来表示不同情况，如果方块具有对应的物品但ID不同，则会在“物品形式”一列中标明其对应的物品ID。
