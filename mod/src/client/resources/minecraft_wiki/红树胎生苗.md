* *红树胎生苗（Mangrove Propagule）**是一种能够生长为[红树](红树.md)的[植物](植物.md)。

# 生成
# = 自然生成 =
随机成熟程度的红树胎生苗会作为[红树](红树.md)的一部分生成，悬挂在[红树树叶](红树树叶.md)下方。

# = 人为生成 =
对红树树叶[骨粉](骨粉.md)，其下表面会开始生长红树胎生苗，共有4个生长阶段，每对胎生苗使用一次骨粉可以增加1个阶段。最后一个生长阶段时被破坏会掉落为物品。

# 破坏
红树胎生苗被挖掘时会立刻被破坏。

红树胎生苗被破坏后会掉落自身。

# 用途
# = 生长 =
红树胎生苗可被种植在[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[草方块](草方块.md)、[灰化土](灰化土.md)、[砂土](砂土.md)、[菌丝体](菌丝体.md)、[耕地](耕地.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[泥巴](泥巴.md)和[沾泥的红树根](沾泥的红树根.md)和[黏土](黏土.md)上，且能在[水](水.md)中生长。被允许种植到的方块标签控制，且黏土上总是可以种植红树胎生苗。}}标签控制。}}

红树胎生苗的生长由[随机刻](随机刻.md)控制。在长成树木之前，红树胎生苗有2个生长阶段（在视觉上没有差异）。处于第2个生长阶段的红树胎生苗尝试生长时，游戏会指定树的高度，然后检查生长条件。若不符合条件，则取消这次生长。红树胎生苗的生长没有亮度等级要求。对红树胎生苗[骨粉](骨粉.md)有45%概率使其进入下一个生长阶段而无视亮度等级，但是仍要求有足够的空间才能长成树木。

红树胎生苗上方的[树叶](树叶.md)、标签的方块}}、通常不会阻止其生长，但有一些例外。长出的树木会穿过这些方块，有时还能将它们替换掉。阻止树根部分生长的方块类型与树干部分有所不同。

如无特殊说明，下文中的“空间”指的是一个仅包含**不阻止红树胎生苗生长**的方块的区域。

# == Java版 ==
红树胎生苗需要上方至少有5×4×5的空间，且在根须延伸范围（胎生苗XZ轴5格距离内、下方13格内）内有足以触及的方块（泥巴、[红树根](红树根.md)和沾泥的红树根除外）。

# == 基岩版 ==
单个红树胎生苗生长检测的空间范围是红树胎生苗上方（不含红树胎生苗）的<math>3\times(n-2)\times3</math>以及前者上方的5×3×5。

# = 生成蜂巢 =
红树胎生苗长成的红树有/的概率悬挂着蜂巢。每个由此生成的蜂巢都会容纳1-3只[蜜蜂](蜜蜂.md)。

# = 蜜蜂 =
红树胎生苗可用于繁殖[蜜蜂](蜜蜂.md)及加速幼年蜜蜂成长。蜜蜂也会采集它的花粉。

# = 装饰 =
红树胎生苗可以被放在[花盆](花盆.md)里。

# = 燃料 =
红树胎生苗可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个红树胎生苗可[烧炼](烧炼.md)0.5个物品。

# = 堆肥 =
将红树胎生苗放进[堆肥桶](堆肥桶.md)里有30%概率增加1个堆肥层。
