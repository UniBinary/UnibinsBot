# 携带版0.8.0.b4

*页面ID: 31520* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.8.0 alpha build 4**是[v0.8.0 alpha](携带版0.8.0.md)的第4个测试版，发布于2013年11月27日，修复了一些漏洞。

# 新内容
# = 方块 =
* *[地毯](地毯.md)**
* 加入了[红色地毯](红色地毯.md)至[生存模式](生存模式.md)的[合成](合成.md)菜单。

# = 常规 =
* *[GUI](GUI.md)界面**
* 加入了版本水印来说明截图来自预览版本。

# 更改
# = 方块 =
* *[火](火.md)和[熔岩](熔岩.md)**
* [创造模式](创造模式.md)中，[玩家](玩家.md)从火或熔岩中出来会瞬间停止燃烧。

* *[TNT](TNT.md)**
* 现在[水](水.md)与[熔岩](熔岩.md)阻隔[TNT](TNT.md)的能力更强了。

# = 物品 =
* *[马铃薯](马铃薯.md)与[胡萝卜](胡萝卜.md)**
* 将草方块转化为耕地时不再会掉落。

# = 常规 =
* *启动界面**
* 在Android系统上能更快地从后台响应。

# 修复

* *其他**
* 修复了Minecraft Realms的一些崩溃问题。
* 添加了烤马铃薯的描述。
* 添加了木炭的描述。
* 修正了铁栏杆描述中的错别字。
* 修复了箭的一些问题。
* 修复了仙人掌顶部的纹理。
* 修复了捡起火中的箭会导致崩溃的问题。
* 修复了图形错误。
* 删除了创造模式物品栏中的骨粉。</onlyinclude>
