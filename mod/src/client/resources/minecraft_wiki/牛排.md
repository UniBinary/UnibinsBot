# 牛排

*页面ID: 6717* | *来源: Minecraft Wiki*

* *牛排（Steak）**是一种由[牛](牛.md)和[哞菇](哞菇.md)着火时死亡获得的或由[生牛肉](生牛肉.md)烹饪而成的[食物](食物.md)。

# 获取
# = 生物掉落物 =

# = 烹饪 =
牛排可通过用[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或[营火](营火.md)烹饪生牛肉获得。

# = 礼物 =

[屠夫](屠夫.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷牛排。

# = 箱子战利品 =

# 用途
# = 食物 =

手持牛排按住键即可食用，每个牛排可以回复。

# = 狼 =
牛排能用来吸引、治疗或繁殖驯服的[狼](狼.md)，也可以使已驯服的幼年狼的剩余生长时间加快10%。
