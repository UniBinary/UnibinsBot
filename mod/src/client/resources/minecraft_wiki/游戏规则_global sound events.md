# 游戏规则/global sound events

*页面ID: 127316* | *来源: Minecraft Wiki*

* *global_sound_events**是控制是否播放全局声音事件的[游戏规则](游戏规则.md)。

# 行为
当global_sound_events为<samp>false</samp>时，以下声音事件不再无视距离和[维度](维度.md)限制对世界中所有玩家播放：

* [末影龙](末影龙.md)死亡时的音效。
* [凋灵](凋灵.md)生成后10秒产生爆炸时播放的生成音效。
* [末地传送门](末地传送门.md)激活时的音效。
