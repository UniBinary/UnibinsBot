# Java版Combat Test 2

*页面ID: 46433* | *来源: Minecraft Wiki*

}}<onlyinclude>

* *Combat Test 2**是未来的战斗改版的第2个公开的实验性版本，发布于2019年8月15日<ref></ref>，虽然它是未来版本的测试版，但这个战斗实验版是[Java版1.14.4](Java版1.14.4.md)的分支。此版本只发布在[Reddit](wzh:Reddit.md)上，因此其并不出现在[启动器](启动器.md)版本列表或[Minecraft.net](Minecraft.net.md)的文章中。

# 更改
# = 物品 =
* *[盾牌](盾牌.md)**
* 现在又会抵挡暴击伤害了。
* *[剑](剑.md)**
* 减慢[剑](剑.md)的攻击速度至2.5。
* *[三叉戟](三叉戟.md)**
* 将伤害增加至。

# = 游戏内容 =
* *[战斗](Tutorial:战斗.md)**
* 在潜行时攻击将会暂时放下[盾牌](盾牌.md)。
* * 在武器攻击的冷却时间达到200%后，盾牌将被重新举起。
* 移除了按住键来一直攻击的特性。<ref group="注">按住攻击键来一直攻击的特性仍会适用于手柄或触摸板。</ref>
* 武器的攻击距离适用于所有情况，在特殊攻击的过程中攻击距离会多出0.5格。
* *[HUD](HUD.md)**
* 攻击指示器现在只会在冷却时间达到100%后出现，不再展示完整的冷却时间达到200%的过程。

# 修复
* 修复了新战斗机制在创造模式下破坏方块时依旧生效的漏洞。
* 修复了攻击指示器被置于快捷栏时的缩放问题。</onlyinclude>
