# 启动器2.3.228

*页面ID: 96675* | *来源: Minecraft Wiki*

<onlyinclude>

* *2.3.228**是一次[启动器](启动器.md)更新，发布于2022年6月8日。

# 新内容
* 加入了用于使新的捆绑包正常工作的代码。
* 使启动器支持M1芯片的Mac设备。

# 更改
* 做了各种用户权利、离线模式和稳定性方面的改进。

# 修复
* 修复了游戏安装过程的漏洞。
*  - 无法在系统文件选择器中打开使用相对路径的游戏目录。
*  - 3种游戏页面上的“开始游戏”按钮的大小不一致。
*  - 无法更新启动器。
*  - 显示加载动画时启动器窗口经常会快速闪动。</onlyinclude>
