# 调试模式

*页面ID: 13104* | *来源: Minecraft Wiki*

[缩略图|350px|调试模式下的世界](File:Debug World.png.md)

* *调试模式（Debug mode）**通常指一种[世界预设](世界预设.md)，是一种用于调试[方块状态](方块状态.md)、[模型](模型.md)及[纹理](资源包#纹理.md)的世界预设。

调试模式也可以指一种维度的生成器类型（<code>minecraft:debug</code>），该生成器类型将会生成出方块网格。

调试模式也可以指世界的一种状态，如果主世界使用了“调试”生成器，那么世界会进入调试模式状态。在此状态下无法通过任何方式更改、破坏或放置方块。

# 调试模式世界预设

若要选择调试模式，按住键，并点击世界创建菜单中的“世界类型”按钮。调试模式将在[单一生物群系](自选世界类型.md)后、[默认预设](世界预设.md)前出现。

一旦选择调试模式，“”和“”等选项将不可用。游戏模式被锁定为[旁观模式](旁观模式.md)（但是进入世界后可通过命令或按下打开[游戏模式切换器](游戏模式切换器.md)来切换游戏模式），[难度](难度.md)被锁定为和平（尽管在创建新的世界时可以选择，但进入世界后仍然是和平），且启用[命令](命令.md)。游戏规则强制为，而其余游戏规则强制设为默认值。

# 调试生成器
调试模式在单个世界中展示所有[方块](方块.md)的不同[方块状态](方块状态.md)，并自动更新新注册的[方块](Java版数据值.md)。因此，此模式不仅对[Mojang](Mojang.md)开发人员有用，而且对[资源包](资源包.md)和[Mod](Mod.md)的创建者也有用。

# = 方块网格 =
[缩略图|350px|从上空俯视整个网格。图中向上为东](File:DebugOverview.png.md)

每个方块状态只生成一次，在[高度](高度.md)为Y=70的网格中按照方块ID进行排序，第一个方块是坐标X=0，Y=70，Z=0处的[空气](空气.md)。网格会根据可用的方块与方块状态的数量改变大小，大致为一个正方形，占据+X，+Z（东南）象限。<ref>由于，方块网格不是一个完美的正方形，且在某些版本中最南侧和最北两列方块会出现重复，是否会发生重复与方块总数量有关。</ref>

Y=60处生成的[屏障](屏障.md)层延伸到[世界边界](世界边界.md)处，覆盖整个世界的Y=60层。除此以外，其余部分皆为空气。

# 调试模式状态
调试模式可以指世界的一种状态，如果主世界使用了“调试”生成器，那么世界会进入调试模式状态。

# = 世界生成 =
玩家可以使用[下界传送门方块](下界传送门方块.md)、[末地传送门方块](末地传送门方块.md)或命令进入对应维度。

在此状态下，任何维度都会强制使用“调试”生成器。地形会正常生成但不会渲染，调试模式原有的方块即使被地形覆盖也仍会渲染。这时，在这些维度中可能不会自动更新区块渲染，导致需要右键一个方块才能渲染新区块。

在[下界](下界.md)中，[炽足兽](炽足兽.md)仍会生成。在[末地](末地.md)中，[末影龙](末影龙.md)及[末地水晶](末地水晶.md)仍会生成，尽管末影龙不能与方块进行交互。末影龙死亡后[返回传送门](返回传送门.md)也不会生成。

# = 世界行为 =
玩家在正常情况下无法通过任何方式更改、破坏或放置方块，但如果将游戏模式切换到旁观模式以外的游戏模式，玩家仍能与方块进行互动，但不能破坏它们。方块的[计划刻](计划刻.md)、区块的[区块刻](区块刻.md)（包括随机刻）也不会执行。生物不会自然生成。

任何交互不改变其方块状态的方块仍然可以使用（例如[箱子](箱子.md)、床等等）。它们的[方块实体](方块实体.md)数据是可变的，可以进行正常的互动。

这些调试模式的独特性质会导致特定的方块表现出一些异常情况，比如：
* [水](水.md)和[熔岩](熔岩.md)不能用[铁桶](铁桶.md)移除，但可以填充空桶。
* 作差模式的[红石比较器](红石比较器.md)时，其<code>facing</code>方向的需要支撑的方块将以物品形式掉落。
* * 如果掉落物品的方块是红石比较器，其将会掉落32位整数限制个物品，并导致游戏崩溃。
* 尝试[栅栏门](栅栏门.md)、[红石比较器](红石比较器.md)、未激活的[按钮](按钮.md)、[拉杆](拉杆.md)、未激活的[压力板](压力板.md)、[门](门.md)或者[活板门](活板门.md)等方块不会改变其方块状态，但会播放对应音效。
* [下落的方块](下落的方块.md)在落地时总会以物品形式掉落。
* 可以从堆肥等级为满的[堆肥桶](堆肥桶.md)（<code>level</code>为<code>8</code>）中无限获得[骨粉](骨粉.md)。
* [龙蛋](龙蛋.md)被后只会产生[粒子效果](粒子效果.md)而不会瞬移。
* 在空[唱片机](唱片机.md)上使用[音乐唱片](音乐唱片.md)不会改变其方块状态，但仍能正常播放音乐。其中[熔炉](熔炉.md)也与唱片机类似，在熔炼[物品](物品.md)时并不会改变其方块状态，但仍能正常熔炼物品。
* [试炼刷怪笼](试炼刷怪笼.md)和[宝库](宝库.md)会不断尝试改变方块状态，并频繁发出声音。<ref></ref>
* 在此模式下对[告示牌](告示牌.md)和[悬挂式告示牌](悬挂式告示牌.md)输入文字，破坏后，其上面的文字不会消失。但再次告示牌则会让文字消失。

# 你知道吗
* 在此模式下，[主世界](主世界.md)的[生物群系](生物群系.md)为默认的[平原](平原.md)。
* 使用[地图](地图.md)并不能精确地绘制所有方块的位置。
* 把世界类型设置为调试模式后，游戏模式按钮会被锁定在[旁观模式](旁观模式.md)，在按钮下面还有一行字：“”
* [末影人](末影人.md)在此模式下仍然可以搬运或放置方块。但是，方块被末影人搬运后，该方块所在位置会重新生成一个相同方块；末影人放置的任何方块都会被清除。
