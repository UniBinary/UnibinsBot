# 皮肤包

*页面ID: 15870* | *来源: Minecraft Wiki*

* *皮肤包（Skin pack）**是[原主机版](原主机版.md)和[基岩版](基岩版.md)中的一个可购买内容，皮肤包会提供额外的皮肤来供玩家选择。这些皮肤通常是由其他电子游戏、电影和电视剧为原型而设计的，有些还是原创设计。

# 跨平台
跨平台皮肤包是在[原主机版](原主机版.md)和[基岩版](基岩版.md)上所提供皮肤包的非官方名称，但这个类别的皮肤包可能在不同平台上有些许差异。

# == 默认皮肤包（Default Skin pack） ==
* *默认皮肤包**是原主机版的免费皮肤包，包含16种皮肤。联机游戏中，每个皮肤被随机分配给每个玩家。

# == 皮肤包1（Skin Pack 1） ==
[缩略图|300px|皮肤包 1 的宣传图片。从左到右：狂刀杰克、克莱顿·卡迈因 、巴尼奥、爆炸人女士、囚犯](File:Xbox Skin Pack Promo 3.jpg.md)

皮肤包1于2012年7月16日正式发布。它提供了45种皮肤可供选择。<ref>http://playxbla.com/minecraft-skins-coming-monday-july-16th</ref>它可以通过在 [Xbox 360 Marketplace](http://marketplace.xbox.com/en-GB/Product/Skin-Pack-1/551dafc8-d8db-4f7c-ba33-ad83e96b291b) 作为游戏可下载内容进行购买，并且需要花费 $1.99 美金。其试用版已经可以[免费下载](http://marketplace.xbox.com/en-US/Product/Skin-Pack-1-Trial/4c0d90a4-4045-4c83-8716-3cec1a2608d3)，试用版可以使用全部原创的皮肤，但试用版不包含基于正版游戏角色设计的皮肤，这当中包括了Minecraft的原创皮肤。
