# 气球

*页面ID: 34273* | *来源: Minecraft Wiki*

* *气球（Balloon）**是一种拴在实体上时会使实体飘浮的物品。

# 用途
手持气球对着实体、栅栏按下键可将气球与实体、栅栏相连，类似于[拴绳](拴绳.md)。未被拴住的气球会以比玩家飞行还要快的速度向上飘浮，但气球若被绑在栅栏上，则不会向上飘浮。当气球被拴在栅栏上时，玩家可以从任意方向点击气球，气球不会因此而炸裂，并且气球会略微向玩家点击它的方向飘去。绑着实体的气球会连同实体一起向上飘浮，直到飞到Y=320处才会炸裂。被骑乘的生物无法和气球相连。

如果气球被三叉戟或箭射中、碰到方块或到达Y=320处，它会炸裂并消失。被弹射物刺破的气球不会掉落任何东西。

# 你知道吗
* 在现实中，由于[氦气](wzh:氦气.md)的密度低于空气且比[氢气](wzh:氢气.md)更安全，氦气常用于填充气球以使气球在空气中上浮。这也反映到了游戏的合成配方当中。
