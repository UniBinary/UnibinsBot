# 教育版1.12.0

*页面ID: 47220* | *来源: Minecraft Wiki*

* *1.12.0**是**[返校更新](返校更新.md)**的首个正式版，也是的一次更新，在Windows、macOS和iOS上发布于2019年8月14日，而在iPadOS上发布于2019年9月24日。<ref name=release></ref>此版本加入了来自[基岩版1.10.0](基岩版1.10.0.md)和[1.11.0](基岩版1.11.0.md)的[村庄与掠夺](村庄与掠夺.md)的特性，以及课堂体验和性能改进。<ref>https://education.minecraft.net/en-us/blog/back-to-school-update-now-available-for-all-users </ref>

# 新内容

此版本添加了[基岩版1.10.0](基岩版1.10.0.md)和[基岩版1.11.0](基岩版1.11.0.md)的所有功能，实验功能除外。

# = 常规 =
* *导出**
* 学生现在可以使用导出功能将[书与笔](书与笔.md)中的内容保存为PDF。
* * 支持评估，除了帮助学生记录和分享他们的工作。

* *沉浸式阅读器**
* 一种游戏内工具，支持阅读和翻译游戏内文本，为学生提供格式化选项，并提供带有特定于Minecraft图像的图片字典。

* *简单登录**
* 用户可以选择根据其凭据自动登录，或者随时注销，并根据需要以其他用户身份登录。

# 更改
# = 常规 =
* *共享库内容**
* 使分配或共享从学习管理系统到世界的链接变得更容易。

* *网站地图**
* 增加了更多的视觉网站地图帮助教育工作者和学生找到Minecraft世界在图书馆或导航到一个课程。

* *[多人游戏](多人游戏.md)**
* 学生们现在可以邀请其他人加入世界使用加入代-{}-码。
* * 学生必须被邀请来参与一个多人的世界。
* 更改了玩家如何加入彼此世界的权限。
* * 其他玩家可以邀请加入作为访客或正式成员的权限。
