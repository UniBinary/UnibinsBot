# 海草

*页面ID: 33655* | *来源: Minecraft Wiki*

* *海草（Seagrass）**是一种生成于[河流](河流.md)和[海洋](海洋.md)等[生物群系](生物群系.md)的[植物](植物.md)方块。

* *高海草（Tall Seagrass）**是两格高的海草。

# 生成
# = 自然生成 =
海草和高海草可以在[河流](河流.md)、[沼泽](沼泽.md)、[红树林沼泽](红树林沼泽.md)、[海洋](海洋.md)、[深海](深海.md)、[暖水海洋](暖水海洋.md)、[温水海洋](温水海洋.md)、[温水深海](温水深海.md)、[冷水海洋](冷水海洋.md)和[冷水深海](冷水深海.md)生成，生成时可能取代木板<ref></ref>。其中高海草在深海类生物群系生成的概率稍微高一些。

# = 骨粉 =
在水下使用[骨粉](骨粉.md)可以生成海草。海草能生成在上表面支撑形状完整，并且不是[岩浆块](岩浆块.md)的方块上面；骨粉只能在[泥土](泥土.md)、[砂土](砂土.md)、[沙子](沙子.md)、[红沙](红沙.md)、[沙砾](沙砾.md)或[黏土](黏土.md)上使用，不在至少两格深的水中使用则不会生成海草，并消耗骨粉。该方块上方的一格水不能为流动的水。当满足这些条件时，一株一格高的海草会生成在该方块上，如果环境允许，海草还会生成在周围的方块上。

# 破坏
海草和高海草被挖掘时会立刻被破坏。

没有被[剪刀](剪刀.md)挖掘破坏时，海草或高海草被破坏后不会掉落。

被[剪刀](剪刀.md)挖掘破坏时，海草被破坏后会掉落自身，高海草被破坏后会掉落两个海草。

# 用途
海草只能放置在上表面支撑形状完整，并且不是[岩浆块](岩浆块.md)和的方块上面。

类似[草丛](草丛.md)、[雪](雪.md)和其他具有[可替代](方块基本属性.md)性的方块，在海草内放置方块会将海草替换为所放置的方块。海草内不能放置[珊瑚扇](珊瑚扇.md)。

# = 繁殖 =
海草可用来吸引和繁殖[海龟](海龟.md)，也可喂食给幼年个体以减少其10%的剩余成长时间。

# = 骨粉 =
对着一格高的海草使用[骨粉](骨粉.md)，可使其生长至两格高，前提是有足够的空间。如果没有足够的生长空间，则不会消耗骨粉<ref></ref>。

# = 堆肥 =
将海草放入[堆肥桶](堆肥桶.md)有30%概率增加1个堆肥层。
