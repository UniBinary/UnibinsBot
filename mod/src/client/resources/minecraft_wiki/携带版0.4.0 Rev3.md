# 携带版0.4.0 Rev3

*页面ID: 44691* | *来源: Minecraft Wiki*

* *v0.4.0 alpha rev 3**是[携带版](携带版.md)的一个次要更新，发布于2012年9月17日<ref>https://www.minecraftforum.net/forums/minecraft-pocket-edition/mcpe-discussion/1967778-0-4-0-rev-3</ref>。此次更新仅在iOS平台上发布，以修复一些漏洞和崩溃。

# 修复
* 修复了iOS平台上的更多的漏洞和崩溃。
