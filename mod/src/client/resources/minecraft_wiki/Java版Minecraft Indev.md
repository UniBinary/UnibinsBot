# Java版Minecraft Indev

*页面ID: 35440* | *来源: Minecraft Wiki*

* *Minecraft Indev**指的是[2010年2月6日](Java版Indev 20100206-2034.md)至[2月23日](Java版Indev 20100223.md)期间发布的11个**[Indev](Java版Indev.md)**版本。

# 新内容
# = 常规 =
;[昼夜更替](昼夜更替.md)
* 太阳和月亮在天空中移动。
;[耕种](耕种.md)
* 玩家可以种下[种子](种子.md)，种子可以长成[小麦](小麦.md)，小麦可用于合成[面包](面包.md)。
;第三人称视角
* 按来切换。

# = 方块 =
;[耕地](耕地.md)
* 农作物可种植于其上。
;[熔炉](熔炉.md)
* 用于烧炼物品。

# = 物品 =
;[锄](锄.md)
* 用于将[泥土](泥土.md)变为耕地。
* 当[泥土](泥土.md)变为耕地时有概率锄出种子。
;[面包](面包.md)
* 可以食用。
* 由小麦合成。
;[种子](种子.md)
* 可放置于耕地上。
* 会长成小麦。
;[小麦](小麦.md)
* 可合成为面包。
;[盔甲](盔甲.md)
* 可以穿戴。
* 起保护作用。

# = 非生物实体 =
; [画](画.md)
* 新的装饰性[实体](实体.md)。
* 目前有19种。
* 具有[物品](物品.md)形式。

# = 世界生成 =
;[地图主题](Java版已移除特性#Indev地图主题.md)
[alt=Hell map theme. No grass, the ocean is lava, always night.|thumb|251x251px|地狱地图主题](File:Indev Hell Theme.png.md)
* 普通
* 地狱
* 天堂
* 树林

# 更改
# = 常规 =
;[音效](音效.md)
* 切换到OpenAL音效系统。

# = 方块 =
;[木头](原木.md)
* 现在掉落木头而非[木板](木板.md)。
;[圆石](圆石.md)
* 可烧炼为石头。

# = 生物 =
;[骷髅](骷髅.md)
* 现在在阳光下燃烧。
* 掉落[箭](箭.md)。
;[僵尸](僵尸.md)
* 现在在阳光下燃烧。
* 掉落[羽毛](羽毛.md)。
;[猪](猪.md)
* 掉落[生猪排](生猪排.md)。
;[苦力怕](苦力怕.md)
* 掉落[火药](火药.md)。
;[蜘蛛](蜘蛛.md)
* 掉落[线](线.md)。
