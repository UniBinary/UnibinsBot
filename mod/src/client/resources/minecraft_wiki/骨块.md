# 骨块

*页面ID: 21423* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *骨块（Bone Block）**是一种用于存储[骨粉](骨粉.md)的方块。

# 生成
# = 自然生成 =
骨块会作为[化石](化石.md)和[下界化石](下界化石.md)的一部分生成，前者出现于[沙漠](沙漠.md)、[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)生物群系，后者出现于[灵魂沙峡谷](灵魂沙峡谷.md)生物群系。骨块还会生成在[试炼密室](试炼密室.md)中生成[骷髅](骷髅.md)的[试炼刷怪笼](试炼刷怪笼.md)旁。

# 破坏
挖掘骨块的合适工具是镐。骨块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

骨块被破坏后会掉落自身。

# 用途
骨块是一种装饰性方块，能面朝不同的方向，也可以用来储存[骨粉](骨粉.md)。
