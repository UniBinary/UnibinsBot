* *世界（World）**，又稱**存檔（Level）**，是指游戏内所有[维度](维度.md)组成的游戏空间。每个未加载任何数据包的世界都由[主世界](主世界.md)、[下界](下界.md)和[末地](末地.md)三个维度组成。玩家可以通过在[主菜单](主菜单.md)中的[选择世界菜单](选择世界菜单.md)来进入世界，并且可以使用[创建新的世界](创建新的世界.md)按钮来创建一个世界。

# 性质
每个未加载任何数据包的世界都分为三个[维度](维度.md)，它们均由多种方块组成，所有方块都排列在[网格](Wzh:立方体堆砌.md)中。世界中还有[流体](流体.md)、[实体](实体.md)和[粒子](粒子.md)，以及亮度不同的[光照](光照.md)，同时也分布着各种[生物群系](生物群系.md)。方块和实体可以附带着其他属性，例如[物品](物品.md)、[状态效果](状态效果.md)以及[魔咒](魔咒.md)。”世界选项|je}}，世界各地还会生成不同的[结构](结构.md)，其内还会生成装有[战利品](战利品.md)的[箱子](箱子.md)。

# 储存
# = Java版 =

每个世界都保存在<code>[.minecraft](.minecraft.md)/saves</code>目录下的单独文件夹中。文件夹名称与世界最初创建时的名称一致（若与现有文件夹重名则会在名字的后面再加“(1)”“(2)”等带括号的数字）。主世界存储在中，下界则存储在中，末地则存储在中。每个维度都有其自己的文件夹。

# = 基岩版 =

每个世界都保存在<code>[com.mojang](com.mojang.md)/minecraftWorlds</code>目录下的单独文件夹中。文件夹名称为后加一个等于号的一串随机的字母，世界名则存放在世界文件夹下的<code>levelname.txt</code>和<code>level.dat</code>文件中。基岩版在对应世界文件夹的<code>db</code>文件夹中以LevelDB键值形式存储区块数据，不同维度的数据不分开。
