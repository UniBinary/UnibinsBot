# 异界传送门

* *异界传送门（Other Portal）**是一种人造的[结构](结构.md)，可将进入的生物传送至Y轴坐标大于500的位置。

# 创建

|完整版
}}

|简化版
}}
一个异界传送门由[荧石](荧石.md)框架构成（最小4×5，最大23×23）。边角上的四个荧石不是必须的。相邻的异界传送门可以共用框架上的荧石。

一旦构成了这个框架，就可以通过[水源方块](水源方块.md)来激活它，这会在框架里面创建漩涡状的[异界传送门方块](异界传送门（方块）.md)。水可以放在框架里面的任何位置，包括用[水桶](水桶.md)或者自然流动的水。只有水源方块才能激活异界传送门，水流无法激活异界传送门。

异界传送门可以在任意维度被激活。

# 行为

当一个玩家待在异界传送门内4秒后，就会被传送至X与Z轴坐标相同，Y轴坐标增加500的位置，但不会超过Y=650。玩家可以在传送动画结束前走出传送门来取消传送。如果玩家处于[创造模式](创造模式.md)，那么玩家会在进入传送门的瞬间被传送。

玩家被传送后时，聊天栏会出现一条消息“Error 404 Terrain Not Found”（404错误：未找到地形）。

大多数实体都能通过异界传送门传送，包括各种[生物](生物.md)（除了[凋灵](凋灵.md)和[末影龙](末影龙.md)）、[船](船.md)、[矿车](矿车.md)、[弹射物](弹射物.md)和[物品实体](物品实体.md)。生物有着比玩家长得多的传送“冷却时间”，它们在大约15秒内不能再次使用传送门。

与[下界传送门](下界传送门.md)不同，无论实体进入传送门朝向哪一方，实体穿过传送门后速度和朝向都不变。
