# 竹块

* *竹块（Block of Bamboo）**是一种由[竹子](竹子.md)合成的方块，可以分解为[竹板](竹板.md)。

# 生成
竹块不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘竹块的合适工具是斧。

竹块被破坏后会掉落自身。

# 用途
对竹块任意种类的[斧](斧.md)可以将其转化为[去皮竹块](去皮竹块.md)。

# = 合成材料 =

# = 燃料 =
竹块可以作为[熔炉](熔炉.md)、[高炉](高炉.md)和[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每块竹块可以烧炼1.5个单位的物品。
