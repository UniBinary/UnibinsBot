# 你知道吗
* 该曲目名称出自“[As above, so below](wikipedia:As above, so_below.md)”（其上如是，其下亦然），这是一句源于的箴言，同时也与炼金术高度相关。
* * 据[Lena Raine](Lena Raine.md)所说，曲目名指代游戏中下界相对于“上方”正常世界的神秘性质。<ref>https://web.archive.org/web/20220313054218/https://twitter.com/kuraine/status/1275489665345150977</ref>
