# 游戏规则/lava source conversion

*页面ID: 127314* | *来源: Minecraft Wiki*

* *lava_source_conversion**是控制[熔岩](熔岩.md)能否转化为熔岩源的[游戏规则](游戏规则.md)。

# 行为

当lava_source_conversion为<samp>true</samp>时，流动熔岩在水平方向上有至少2面与熔岩源相邻时会转化为熔岩源。
