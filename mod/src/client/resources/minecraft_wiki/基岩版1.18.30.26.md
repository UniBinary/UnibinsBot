* *beta 1.18.30.26**（Xbox/Windows/Android）、**Preview 1.18.30.27**（iOS/iPadOS/Xbox/Windows）是[基岩版1.18.30](基岩版1.18.30.md)的第8个测试版，发布于2022年3月16日<ref></ref>，在[实验性玩法](实验性玩法.md)中加入了[铜制号角](铜制号角.md)，并修复了一些漏洞。

# 更改
# = 方块 =
* *[隐形基岩](隐形基岩.md)**
* ID由更改为。

# = 物品 =
* *[斧](斧.md)**
* 现在使用斧的攻击能够禁用[盾牌](盾牌.md)5秒，以同步。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“香草实验”和“应用测试框架”子选项后才可使用。

# = 物品 =
* *[铜制号角](铜制号角.md)**
* 山羊角的镀铜变种。
* 可用3个[铜锭](铜锭.md)和1个山羊角合成。
* 能够发出三种不同的响声，分别可在抬头、[潜行](潜行.md)及所有其他动作下吹奏产生。

* *[山羊角](山羊角.md)**
* 加入了更多的吹奏音效。
* 现在每个山羊角仅具有一种吹奏音效。
* 现在山羊在撞击[石头](石头.md)、[浮冰](浮冰.md)、[铁矿石](铁矿石.md)、[铜矿石](铜矿石.md)、[绿宝石矿石](绿宝石矿石.md)和[原木](原木.md)时总是会掉落山羊角。

# = 生物 =
* *[山羊](山羊.md)**
* 现在有小概率生成独角山羊。

# = 世界生成 =
* *[掠夺者前哨站](掠夺者前哨站.md)**
* 在战利品表中加入了山羊角和铜制号角。

# = 技术性 =
* *GameTest框架**
* 加入了事件。
* * 开关拉杆时触发。
* 为函数加入了可选参数 true}}。

# 修复
* *游戏内容**
* 修复了在部分市场世界中玩家的饥饿值不会消耗的问题。（）
* 修复了玩家在杀死掠夺者队长后不会获得不祥之兆效果的问题。（）
* 生物的受伤音效和死亡音效不再会重叠在一起。（）
* 击退抗性现在会减弱铁傀儡攻击造成的垂直方向击飞。
* 存储模式的结构方块现在会正确检测Y坐标为负数的角落模式的结构方块。（）

* *原版趋同**
* 下界砖、铁粒、金粒、蘑菇方块、紫颂植株和紫颂花不再能够作为熔炉的燃料。（）
* 现在玩家受到伤害时其相机视角会像Java版一样逆时针晃动，而非顺时针晃动。（）

* *生物**
* 修复了大型生物在市场地图中可能会被卡住的问题。

* *用户界面**
* 在移动设备上使用新的触摸控制时，玩家现在可以在设置界面中拉动“按钮尺寸”滑块以调整摇杆大小。
* 修复了使用Pocket UI打开具有自定义UI的方块时，其中的物品会被错误丢弃的问题。同时调整了这种界面的比例大小，以允许玩家丢弃物品。
* 改进了多个UI元素的对比度。
* 为新的创建新世界UI启用了行为包选项卡。

* *技术性**
* 修复了击退意向的错误拥有者会被传递至过滤器计算函数的问题。
* 将CraftingTableComponent的字段中的元素数量限制为64。
* 修复了在1.18.30版本前存在实体的旧区块中加载实体时可能发生的崩溃。</onlyinclude>
