# 基岩版1.21.131

*页面ID: 178501* | *来源: Minecraft Wiki*

* *1.21.131**是的一次热修复更新，发布于2025年12月16日<ref></ref>，修复了一些漏洞。此版本与[1.21.130](基岩版1.21.130.md)相兼容。

# 更改
# = 技术性 =
* *API基础设施**
* 修复了使用多个附加包时可能会在存档加载或世界创建期间触发“Block”错误代码的漏洞。（）

* *图形**
* 修复了加载附加包或连接服务器时，Switch平台上的UI纹理会看起来不正确的问题。

# 修复
* *常规**
* “”成就不再会在PC上到达少于17个生物群系后解锁。（）

* *群骑纷争**
* 增加了矛在冲锋攻击时可以造成击退的持续时间。
* 现在矛的冲锋攻击动画与矛的各阶段（发动、疲劳、脱离）更加一致，以改进视觉反馈。

* *市场**
* 修复了可能导致键无法在搜索市场内容后返回至主菜单的漏洞。（）
