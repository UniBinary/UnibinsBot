# Java版15w39a

*页面ID: 18417* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w39a**是[Java版1.9](Java版1.9.md)的第26个快照，发布于2015年9月21日<ref></ref>，更改了一些生物的实体高度，并修复了一些漏洞。

# 更改
# = 生物 =
* *[苦力怕](苦力怕.md)**
* 高度从1.8格更改为1.7格。

* *[骷髅](骷髅.md)**
* 高度1.95格从更改为1.99格。

* *[凋灵骷髅](凋灵骷髅.md)**
* 尺寸从2.535格高、0.72格宽更改为2.4格高、0.7格宽。

* *[牛](牛.md)**
* 高度从1.3格更改为1.4格。

* *[哞菇](哞菇.md)**
* 高度从1.3格更改为1.4格。

* *[铁傀儡](铁傀儡.md)**
* 高度从2.9格更改为2.7格。

* *[鱿鱼](鱿鱼.md)**
* 边长大小从0.95格更改为0.8格。

* *[村民](村民.md)**
* 高度1.8格从更改为1.95格。

* *[狼](狼.md)**
* 高度从0.8格更改为0.85格。

# 修复
+鼠标左键将物品放置到已满的容器或背包中时，物品会丢失。
