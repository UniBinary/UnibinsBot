# 基岩版1.19.0.20

*页面ID: 94600* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.0.20**（Xbox/Windows/Android）、**Preview 1.19.0.21**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.0](基岩版1.19.0.md)的首个测试版，发布于2022年4月6日<ref></ref><ref></ref>，加入了[红树林沼泽](红树林沼泽.md)生物群系、[红树](红树.md)和[泥巴](泥巴.md)及其相关方块和物品，调整了一些特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[红树原木](红树原木.md)**
* 一种褐色外皮、朱红色内干的[原木](原木.md)。
* 有对应的去皮变种。

* *[紅樹林木塊](紅樹林木塊.md)**
* 红树原木的[木头](木头.md)变种，可用红树原木合成。
* 有对应的去皮变种。

* *[红树木板](红树木板.md)**
* 一种朱红色木板，可用红树原木或紅樹林木塊合成。
* 可用于合成对应的[按钮](按钮.md)、[门](门.md)、[栅栏](栅栏.md)、[栅栏门](栅栏门.md)、[压力板](压力板.md)、[告示牌](告示牌.md)、[台阶](台阶.md)、[楼梯](楼梯.md)和[活板门](活板门.md)。

* *[红树树叶](红树树叶.md)**
* 一种暗绿色的树叶。
* 对其[骨粉](骨粉.md)，其下表面会开始生长红树胎生苗。

* *[红树根](红树根.md)**
* 一种褐绿色的根须状方块，视觉上是透明的，类似于树叶。
* 可以[含水](含水.md)。
* 用[斧](斧.md)的挖掘速度最快。
* 被活塞移动时不会被破坏。若含水，其中的水会消失。

* *[红树胎生苗](红树胎生苗.md)**
* 一种新的树苗。
* 会在对红树树叶骨粉后在其下表面长出。
* * 共有4个生长阶段，使用骨粉可以加速生长。
* 可以种植在[泥土](泥土.md)及其变种、[黏土](黏土.md)和泥巴上，且能够种植在水下。
* 对其骨粉后会长成[红树](红树.md)。
* 可以放在[花盆](花盆.md)中。

* *[泥巴](泥巴.md)**
* 一种蓝黑色方块。
* 对[泥土](泥土.md)、[砂土](砂土.md)或[缠根泥土](缠根泥土.md)[水瓶](水瓶.md)或通过[发射器](发射器.md)发射水瓶会将其转化为泥巴。
* 方块[高度](碰撞箱.md)与[灵魂沙](灵魂沙.md)相同，会使上方的实体下陷，但不会造成减速。

* *[沾泥的红树根](沾泥的红树根.md)**
* 红树根的变种，可用1块红树根与1块泥巴合成。
* 与红树根不同，其不能含水，视觉上也不透明。
* 用斧的挖掘速度最快。

* *[泥坯](泥坯.md)**
* 一种土色的方块，可用1个泥巴与1个[小麦](小麦.md)合成。

* *[泥砖](泥砖.md)**
* 泥坯的砖类变种，可用[泥坯](泥坯.md)合成。
* 可用于合成对应的[台阶](台阶.md)、[楼梯](楼梯.md)和[墙](墙.md)。

# = 世界生成 =
* *[红树林沼泽](红树林沼泽.md)**
* [沼泽](沼泽.md)生物群系的新变种，水体呈灰色，水面上会生成[睡莲](睡莲.md)。
* 地表被[泥巴](泥巴.md)覆盖，偶尔会生成[草方块](草方块.md)斑簇和[枯萎的灌木](枯萎的灌木.md)。
* 仅会生成大量的红树。

* *[红树](红树.md)**
* 一种新的[树木](树木.md)。
* 生成于红树林沼泽中。
* 自然生成时有概率带有[蜂巢](蜂巢（方块）.md)。
* 包含[红树根](红树根.md)、[橡木原木](橡木原木.md)、[红树树叶](红树树叶.md)、[红树胎生苗](红树胎生苗.md)和[藤蔓](藤蔓.md)。
