# 墓碑

*页面ID: 149102* | *来源: Minecraft Wiki*

* *墓碑（Grave）**是用于[进度](进度.md)图标的技术性[物品](物品.md)。

# 获取
墓碑不能在生存模式中正常获得。其亦不存在于[创造模式物品栏](创造模式物品栏.md)中，但可以通过使用[命令](命令.md)等方法获得。

# 用途
墓碑仅用于在游戏内显示[“Oops”进度](进度/25w14craftmine#advancements-anchor-adventure.level_failed.md)的图标，没有实际用途。
