# 教育版1.19.51.0

*页面ID: 102075* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.19.51.0**是[教育版1.19.52](教育版1.19.52.md)的第2个开发版本，发布于2023年2月14日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *登录和切换账户**
* 将主菜单屏幕中的“切换账户”按钮改为“管理账户”，可以使用户选择是否记住账户的用户名和密码、退出登录以及切换账户。

* *导入**
* 向iOS的游玩屏幕中加入了“导入”按钮。</onlyinclude>
