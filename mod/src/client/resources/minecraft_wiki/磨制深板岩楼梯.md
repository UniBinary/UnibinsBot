# 磨制深板岩楼梯

*页面ID: 79566* | *来源: Minecraft Wiki*

* *磨制深板岩楼梯（Polished Deepslate Stairs）**是[磨制深板岩](磨制深板岩.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
磨制深板岩楼梯会自然生成在[远古城市](远古城市.md)中。

# 破坏
挖掘磨制深板岩楼梯的合适工具是镐。磨制深板岩楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

磨制深板岩楼梯被破坏后会掉落自身。
