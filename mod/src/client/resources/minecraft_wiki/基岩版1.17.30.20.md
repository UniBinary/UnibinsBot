# 基岩版1.17.30.20

*页面ID: 86688* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.17.30.20**是[基岩版1.17.30](基岩版1.17.30.md)的第5个测试版，发布于2021年8月4日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 生物 =
* *[恶魂](恶魂.md)**
* 略微增大了碰撞箱宽度。

* *[岩浆怪](岩浆怪.md)**
* 中型岩浆怪现在拥有更大的碰撞箱（1.04×1.02格），以近似匹配中型[史莱姆](史莱姆.md)。
* 更改了生成机制，现在使用与其他生物相同的方块碰撞检测功能。

* *[僵尸](僵尸.md)、[僵尸村民](僵尸村民.md)、[尸壳](尸壳.md)和[溺尸](溺尸.md)**
* 不再会捡起[荧光墨囊](荧光墨囊.md)。

# = 游戏内容 =
* *[设置](设置.md)**
* 为控制器设置加入了“清除热键”选项。
* 加入了“显示边框效果”世界选项。

# = 技术性 =
* *化学特性**
* 新的化学材料现可在JSON文件中定义缩略图。
* 黑板现在会在放置后始终保持渲染。

* *命令**
* 现在使用命令复制拉杆和红石时会一同复制其红石信号。
* 现在命令可将参数指定为Y小于0且大于等于最低高度的值。
* 为Intellisense选项加入了新功能：目标选择器的和游戏模式。
* 命令方块矿车现在可以在命令中使用目标选择器（@s）来指定自己。
* 现在命令可在时间参数大于24000或小于当前时间时正确设置时间（例如：将时间设置为0，将时间设置为1），并且命令现可设置或添加负数时间。

* *物品**
* 更新了物品组件文档的格式。
* 通过使用水桶获得生物桶的世界现在已被锁定，以防止世界模板受到损坏。

# 修复
* *性能与稳定性**
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了在市场下载大型世界时可能发生的崩溃。

* *辅助功能**
* 文本转语音现在会正确读出物品栏中的物品名称。
* 文本转语音不再重复计算物品栏中的插槽数量。

* *游戏内容**
* 现在当手持光源方块时，放置出的光源方块会渲染并且显示其亮度值。（）
* 修复了手持光源方块时无法破坏放置出的光源方块的问题。（）
* 修复了对着光源方块按下右键不会更改其亮度的问题。（）
* 修复了光源方块的判定箱不正确的问题。（）
* 修复了玩家在手上不持有屏障时可以破坏屏障的问题。
* 现在玩家在生存模式下将船放置在水上后，船会正确被消耗。（）

* *用户界面**
* 文本转语音现在又会正确读出聊天栏的聊天消息。（）
* 现在当加载新语言或切换当前语言时，侧边栏会正确本地化。
* 更新了“成就”按钮，将其从个人资料界面移动至主菜单和暂停界面。
* 为VR启用了新成就界面（不包括PSVR）。

* *原版趋同**
* 玩家使用鞘翅滑翔时食用紫颂果不再会受到摔落伤害。（）
* 修复了骷髅不使用两只手臂来拉弓的动画趋同问题。（）

* *生物**
* 修复了在结构方块的预览窗口查看生物时生物会显示为不正确的几何图形的问题。（）
* 实验性内容：现在凋灵可在高度为负数的区域生成。（）
* 恶魂不再生成于小于5×4×5的空间内。（）
* 岩浆怪不再生成于小于3×3×2的空间内。（）
* 中型岩浆怪现在拥有更大的碰撞箱。（）
* 现在发射器在世界最低高度向下放置潜影盒时会将潜影盒保留在其中。（）

* *方块**
* Unicode字体现在会在带有增亮字体的告示牌上正确突出显示。（）
* 含水方块不再有时会变成幽灵方块。（）
* 现在使用精准采集收集朝向南、西或东的南瓜可用于与农民交易。（）
* 悬空的蜡烛不再可以被添加蜡烛数量。（）

* *图形**
* 使用迷雾时天空不再可以在封闭空间透过墙壁渲染。

* *技术性**
* 修复了为组件生成的弹射物添加发射点位置偏移的功能。
* 修复了为组件生成的弹射物添加偏移角度至发射数量的功能。
* 修复了通过交互生成的弹射物无法生效的偏移量。
* 修复了弹射物的值仅在射手骑乘在另一实体上时才会反映的问题。
* 修复了指定弹射物的偏移量时其发射点围绕生物的旋转。
* 修复了拥有不正确缩放或反转结果的问题。</onlyinclude>
