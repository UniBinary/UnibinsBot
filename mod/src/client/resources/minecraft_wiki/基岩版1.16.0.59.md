# 基岩版1.16.0.59

*页面ID: 61119* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.0.59**是[基岩版1.16.0](基岩版1.16.0.md)的第11个测试版，发布于2020年4月30日<ref></ref>，更改了一些合成配方，并修复了一些漏洞。

# 更改
# = 方块 =
* *[锁链](锁链.md)**
* 现在能被合成了。

* *[发射器](发射器.md)**
* 现在可以给生物装备[盾牌](盾牌.md)了。

* *[磨制玄武岩](磨制玄武岩.md)**
* 现在可以将[玄武岩](玄武岩.md)放入切石机中制成了。
* 现在被合成时会给予4个，而不是1个。

* *[下界苗](下界苗.md)**
* 更改了纹理以匹配[Java版](Java版.md)。

* *[石英砖](石英砖.md)**
* 现在只能用[石英块](石英块.md)合成了。

* *[灵魂火](灵魂火.md)**
* 现在除了[灵魂土](灵魂土.md)外还会在[灵魂沙](灵魂沙.md)上燃烧了。
* 英文名称“Blue Fire”被重命名为“Soul Fire”。

* *[绯红木板](绯红木板.md)和[诡异木板](诡异木板.md)**
* 现在不再能用作熔炉的燃料。

* *[绯红木活板门](绯红木活板门.md)**
* ID从更改为。

* *[诡异疣块](诡异疣块.md)**
* ID从更改为。

=== 物品 ===
* *[旗帜图案](旗帜图案.md)**
* 将猪灵旗帜图案重命名为“猪鼻”（Snout）。

* *[刷怪蛋](刷怪蛋.md)**
* 更改了[猪灵](猪灵.md)和[疣猪兽](疣猪兽.md)刷怪蛋的纹理以匹配[Java版](Java版.md)。

# = 生物 =
* *[疣猪兽](疣猪兽.md)**
* 加入了转化为[僵尸疣猪兽](僵尸疣猪兽.md)的音效。
* 放大了幼年疣猪兽头部的尺寸，以匹配Java版。
* 现在会远离僵尸疣猪兽。
* 调整了生成速度。

* *[末影人](末影人.md)**
* 现在会生成于[灵魂沙峡谷](灵魂沙峡谷.md)。

* *[猪灵](猪灵.md)**
* 现在会远离僵尸疣猪兽。
* 现在走路时会正确摆动手臂了。
* 调整了生成速度。
* 现在可以在和平难度下存在。

* *[炽足兽](炽足兽.md)**
* 调整了幼年炽足兽的碰撞箱。

# = 世界生成 =
* *[废弃传送门](废弃传送门.md)**
* 在下界生成时会使用[黑石](黑石.md)，而不是[下界砖块](下界砖块.md)。
* [火焰弹](火焰弹.md)现在可以在箱子中找到。
* 调整了宝箱的战利品表。
* * 更改了物品堆叠数以匹配[Java版](Java版.md)。
* 降低了生成频率。

* *[堡垒遗迹](堡垒遗迹.md)**
* 生成[岩浆怪](岩浆怪.md)的[刷怪笼](刷怪笼.md)现在会出现在堡垒遗迹的宝藏室。
* 调整了宝箱的战利品表。

# 修复
* *修复了42个漏洞**<br>
* *崩溃**
* 修复了尝试堆叠台阶时可能发生的崩溃。（）

* *常规**
* 移除了加载提示中的引号。
* 修复了在下界中播放环境音效过于频繁的问题。（）
* 更改了部分方块的ID与英文名称并对其所对应的JSON文件进行了重命名。（）
* “更改表情”按钮现在在Android设备上完整显示。（）
* “Pigstep”音乐唱片中的单词首字母"p"现在会大写了。（）
* 更改了漏斗的碰撞箱。（）
* 下界苗在物品展示框中被旋转时不会再突出物品展示框的边界了。

* *游戏内容**
* 生物在地下生成时不再计入地表生物生成上限。（）
* 加入了诡异木板和绯红木板的合成配方，且它们现在不能在熔炉中充当燃料了。（）
* 火焰现在会正确地传播和熄灭了。（）
* 加入了锁链的合成配方。（）
* 加入了灵魂火的音效。（）
* 金矿石现在可被烧炼。（）
* 现在烧炼远古残骸时会正确地给予经验。（）
* 现在用玄武岩合成磨制玄武岩时会给予正确的数量。（）
* 巨型下界菌生长时不再替换方块。（）
* 时运魔咒现在能正确触发。（）
* 现在南瓜苗和西瓜苗在上方有不透明方块时也会生长。（）
* 修复了当玩家离开末影龙的战斗区域并返回后，末影龙会重置的漏洞。（）
* 修复了猫在村庄中生成过于频繁的漏洞。（）

* *生物**
* 疣猪兽在向下移动1格高时不再旋转。
* 修复了使用AI标识后实体在船上或者矿车中不能攻击的漏洞。
* 现在猪灵会正确地掉落金质装备。
* 现在猪灵在端详金锭时受到攻击后会丢弃金锭。
* 疣猪兽和炽足兽的拴绳现在会渲染在正确的位置。
* 僵尸猪灵现在免疫火焰伤害。（）
* * 并更改了实体定义属性使拥有此属性的生物不再受到火焰伤害。
* 凋灵骷髅现在会正确渲染盔甲了。
* 修复了实体在骑乘熔岩上方的另一实体时尽管未接触熔岩但骑乘者仍会着火的漏洞。
* 蜜蜂不会再卡在楼梯下。（）
* 调整了幼年炽足兽的碰撞箱。
* 像其他大部分幼年生物一样，幼年疣猪兽现在拥有更大的头部。（）
* 生物现在可以正确装备下界合金盔甲。
* 猪灵现在可以在和平模式中存在。（）
* 猪灵不再悬浮于矿车和船上。（）

* *世界生成**
* 更新了堡垒遗迹宝箱的战利品表。（和）
* 现在岩浆怪刷怪笼会在堡垒遗迹中正确生成了。（）
* 生成世界时所生成的墙现在会正确连接了。（）

* *图像**
* 现在金质工具在被猪灵端详时会被正确渲染了。（和）
* 现在猪灵走路时会正确地摆动手臂了。
* 现在当火在灵魂沙上燃烧时会变成灵魂火了。（）

* *用户界面**
* 修复了在iOS设备上输入时键盘会覆盖文本框的问题。（）</onlyinclude>
