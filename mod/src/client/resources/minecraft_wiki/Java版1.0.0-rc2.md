*页面ID: 32295* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.0.0-rc2**是[Java版1.0.0](Java版1.0.0.md)的第2个，也是最后一个候选版本，发布于2011年11月13日，更改了[物品栏](物品栏.md)中方块的照明，并修复了一个漏洞。

# 更改
* *[物品栏](物品栏.md)**
* 改进了物品栏中方块的照明。

# 修复
* *修复了1个漏洞**
* 修复了在RC1中加载旧存档时，存档中的所有工具很快就被使用至破损的漏洞。
