# 枯萎的灌木

*页面ID: 7744* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *枯萎的灌木（Dead Bush）**是在[沙漠](沙漠.md)、[恶地](恶地.md)等生物群系出现的类植物方块。

# 生成
# = 自然生成 =
枯萎的灌木会在下列方块上自然生成：
* [沙漠](沙漠.md)中的[沙子](沙子.md)；
* [恶地](恶地.md)、[风蚀恶地](风蚀恶地.md)和[疏林恶地](疏林恶地.md)中的[红沙](红沙.md)和[陶瓦](陶瓦.md)；
* 疏林恶地中的[草方块](草方块.md)和[砂土](砂土.md)；
* [原始针叶林](原始针叶林.md)中的[灰化土](灰化土.md)、[泥土](泥土.md)和砂土；
* [红树林沼泽](红树林沼泽.md)中的草方块和[泥巴](泥巴.md)。

[沼泽](沼泽.md)也可能生成枯萎的灌木<ref></ref>。

枯萎的灌木也可能会在[试炼密室](试炼密室.md)的“入口”结构中作为植物造景的一部分生成。

枯萎的灌木盆栽会在一些沙漠[村庄](村庄.md)房子和[试炼密室](试炼密室.md)中生成。

# 获取
# = 箱子战利品 =

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落枯萎的灌木。

# 破坏
枯萎的灌木被挖掘时会立刻被破坏，用于挖掘的工具的耐久度不会下降。

没有被[剪刀](剪刀.md)挖掘破坏时，枯萎的灌木被破坏后会掉落0-2个[木棍](木棍.md)。

被[剪刀](剪刀.md)挖掘破坏时，枯萎的灌木被破坏后会掉落自身。

# 用途
枯萎的灌木只能放置在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[沙子](沙子.md)、[红沙](红沙.md)、[可疑的沙子](可疑的沙子.md)、[陶瓦](陶瓦.md)上。枯萎的灌木还可以放在[花盆](花盆.md)里。

# = 燃料 =
枯萎的灌木可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个枯萎的灌木可以烧炼1个物品。

# = 环境音效 =
当枯萎的灌木下方两格均为[沙子](沙子.md)、[红沙](红沙.md)或任意[陶瓦](陶瓦.md)时，枯萎的灌木有概率发出特殊的环境音效。其中，当枯萎的灌木下方一格处为红沙或任意陶瓦时，其发出环境音效的概率会降低。
