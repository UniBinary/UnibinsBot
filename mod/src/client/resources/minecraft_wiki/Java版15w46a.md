# Java版15w46a

*页面ID: 18956* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w46a**是[Java版1.9](Java版1.9.md)的第40个快照，发布于2015年11月12日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[旗帜](旗帜.md)和[告示牌](告示牌.md)**
* 现在会替换可被替换的方块，而不是尝试却未能放在它们上面。

* *[耕地](耕地.md)**
* 当小于0.512立方米的生物在耕地上跳跃或落在耕地上时不再会使耕地变为泥土。
* * 这包含[兔子](兔子.md)、[鸡](鸡.md)、[蝙蝠](蝙蝠.md)、[豹猫](豹猫.md)、[狼](狼.md)、[洞穴蜘蛛](洞穴蜘蛛.md)、[末影螨](末影螨.md)、[蠹虫](蠹虫.md)、所有现有的幼年生物、小[史莱姆](史莱姆.md)以及小[岩浆怪](岩浆怪.md)。

* *[铁栏杆](铁栏杆.md)**
* 已定型的侧贴栏杆有了边缘的纹理。

* *[铁轨](铁轨.md)**
* [动力铁轨](动力铁轨.md)和[激活铁轨](激活铁轨.md)现在会互相传递能量。

* *[红石粉](红石粉.md)**
* 碰撞箱现在变得更小，并且基于它的连接方式，类似[栅栏](栅栏.md)。

# = 物品 =
* *[水桶](水桶.md)和[熔岩桶](熔岩桶.md)**
* 现在当在一层雪的顶部按下时会替换这层雪，而不是在这层雪上方的空气中放置水或熔岩。

# = 生物 =
* *常规**
* 生物不再能生成在透明方块中了，例如[树叶](树叶.md)。
* 生物不再能生成在[铁轨](铁轨.md)、[动力铁轨](动力铁轨.md)、[探测铁轨](探测铁轨.md)或[激活铁轨](激活铁轨.md)上。
* 生物不再能生成在按钮，绊线钩，压力板，拉杆，红石火把，红石中继器，红石比较器或红石粉中<ref></ref>。

* *[铁傀儡](铁傀儡.md)**
* 生成于15w46a及以后的铁傀儡带有100%的击退抗性。

* *[兔子](兔子.md)**
* 比以前更小了
* 掉落兔子脚的概率现在为<code>-{}-10% + 3% * 抢夺魔咒的等级</code>（之前为<code>-{}-2.5% + 1% * 抢夺魔咒的等级</code>）。
* 现在只会在沙漠、繁花森林、针叶林、大型针叶林、冷针叶林、冰原、冰山、冰刺之地，以及它们的“山脉”和“M”变种中生成。在这些群系中，生成的概率也下降了（权重为4/44-52而不是10/50-58）。
* 兔子当害怕时会跑得更快。
* 兔子不再会乞求食物来繁殖。
* 非杀手兔现在会躲避8格内的玩家和4格内的大多数敌对生物（除史莱姆，岩浆怪和恶魂外），并且当躲避时会跑得更快。同时，狼的躲避距离从16减到了10。
* 生命值从减为。
* 自然生成的兔子的皮肤现在基于生物群系生成，当繁殖时生成的幼年兔子会有5%的概率根据所在生物群系生成颜色而不是根据父母的颜色。
* * 当生成在有雪的生物群系中时，80%概率为白，20%概率为黑白。
* * 当生成在沙漠或者沙漠山群系时，100%概率为金色。
* * 其他情况，50%概率为棕色，40%概率为椒盐，10%概率为黑。
* <code>MoreCarrotTicks</code>不再有任何效果。
* * 当摧毁作物时，<code>MoreCarrotTicks</code>被设为40而不是100。
* 兔子吃胡萝卜作物时会将生长阶段减1，当生长阶段为0时吃作物会将其移除。

* *[雪傀儡](雪傀儡.md)**
* 当游戏规则<code>mobGriefing</code>为<code>false</code>时不会在脚下生成雪。

* *[狼](狼.md)**
* 驯服时项圈为红色，就像1.8之前的正式版，而不是橙色。

# = 世界生成 =
* *[海底神殿](海底神殿.md)**
* 现在需要16个半径内都为深海，而不仅仅是中央的一格。

# = 游戏内容 =
* *[经验](经验.md)**
* 现在会向玩家身体中央收集而不是在头部。
* * 这意味着如果正在收集大量的经验，它不再会阻碍玩家的视线。
* 当游戏规则<code>doTileDrops</code>为<code>false</code>时方块不再会掉落经验。
