* *1.4.0**是**[水域更新](水域更新.md)**第一阶段的首个正式版，也是的一次主要更新，发布于2018年5月16日<ref name=OutNow/><ref name=UpdateLog></ref>。此次更新加入了诸多水域更新的新特性，例如新的[海洋](海洋.md)、[海豚](海豚.md)、[沉船](沉船.md)、[鱼](鱼.md)、[三叉戟](三叉戟.md)、[埋藏的宝藏](埋藏的宝藏.md)、[海底废墟](海底废墟.md)，以及其他一些更改和修复，同时正式加入了[1.2.13](基岩版1.2.13.md)中除了[溺尸](溺尸.md)以外的[实验性玩法](实验性玩法.md)内容。<ref></ref><ref></ref>

该版本最初版本号定为***1.3.0***，但后来由于不同平台内部版本号的标签问题，版本号被更改。此外，由于基岩版的水域更新包含大量的内容，后来决定将该更新分为两部分，分批次更新；例如，[海龟](海龟.md)、[潮涌核心](潮涌核心.md)、[气泡柱](气泡柱.md)等内容推迟到了水域更新第二阶段（[1.5.0](基岩版1.5.0.md)）。来自Java版的水域更新的非水生特性（如[幻翼](幻翼.md)与[缓降](缓降.md)状态效果）也推迟到了[1.6.0](基岩版1.6.0.md)更新。

# 新内容
# = 方块 =
* *[蓝冰](蓝冰.md)**
* 自然生成于冰山和冰冻深海生物群系里。
* 会发出亮度为4的光。

* *[按钮](按钮.md)、[压力板](压力板.md)和[活板门](活板门.md)**
* 现在拆分为所有木板的6种变种。

* *[珊瑚](珊瑚.md)**
* 自然生成于暖水海洋生物群系里。
* 只能放置于水中。
* 有失活变种，生成方式与功能和常规珊瑚相同。
* 可用附有[精准采集](精准采集.md)魔咒的工具开采获得。

* *[珊瑚块](珊瑚块.md)**
* 自然生成于暖水海洋生物群系里。
* 离开水会失活。
* 可用附有精准采集魔咒的镐开采获得，若是普通的镐则会掉落失活变种。

* *[珊瑚扇](珊瑚扇.md)**
* 自然生成于暖水海洋生物群系里。
* 有失活变种，生成方式与功能和常规珊瑚扇相同。
* 可放置在方块的侧面或顶面。
* 可用附有精准采集魔咒的工具开采获得。

* *[干海带块](干海带块.md)**
* 通过9个干海带合成。
* 可作为燃料，烧炼20个物品。

* *[海带](海带.md)**
* 自然生成于海洋生物群系里。
* 只能放置于水中。
* 会生长至数个方块高。
* 拥有动态纹理。
* 可烧炼成干海带。

* *[海草](海草.md)**
* 自然生成于海洋、[河流](河流.md)和[沼泽](沼泽.md)生物群系中。
* 对着水下方块使用骨粉时会生成海草。
* 具有高海草变种。
* 拥有动态纹理。
* 颜色为深绿色。

* *[海泡菜](海泡菜.md)**
* 自然生成于暖水生物群系里。
* 一格内最多可以放置4个。
* 在水下放置时，每个海泡菜会增加3亮度等级。
* 可烧炼为[黄绿色染料](黄绿色染料.md)。
* 玩家不会与其碰撞。

* *[楼梯](楼梯.md)和[台阶](台阶.md)**
* 加入了所有[海晶石](海晶石.md)相关方块的楼梯和台阶。

* *[去皮原木](去皮原木.md)**
* 原木的去皮变种。
* 通过对着原木斧获得。

# = 物品 =
* *[鱼桶](鱼桶.md)**
* 用于填充或放置生物鱼。
* 河豚桶中的河豚是旧纹理的。
* 空桶也可以转化为鱼桶。

* *[干海带](干海带.md)**
* 通过海带烧炼而得。
* 可用于合成干海带块。
* 可食用，回复点饥饿值。

* *[海洋之心](海洋之心.md)**
* 暂时还没有任何用途。
* 在未来的更新中可用于合成[潮涌核心](潮涌核心.md)。<ref name=UpdateLog />

* *[鹦鹉螺壳](鹦鹉螺壳.md)**
* 属于[实验性玩法](实验性玩法.md)。
* 暂时还没有任何用途。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了[海豚](海豚.md)、[鳕鱼](鳕鱼.md)、[鲑鱼](鲑鱼.md)、[河豚](河豚.md)和[热带鱼](热带鱼.md)的刷怪蛋。

# = 生物 =
* *[海豚](海豚.md)**
* 自然生成于除了冻洋和冰冻深海外的海洋生物群系里。
* 一只海豚被激怒时，附近的海豚都会成群发起攻击。
* 可喂食[生鳕鱼](生鳕鱼.md)。
* 死亡后会掉落生鳕鱼。
* 玩家在海豚附近游泳时速度会得到提升。

* *[鱼](鱼.md)**
* [鳕鱼](鳕鱼.md)
* * 自然生成于冷水、常规和温水海洋生物群系中。
* [鲑鱼](鲑鱼.md)
* * 自然生成于冷水、常规、冻洋和温水海洋及其变种生物群系中。
* [河豚](河豚.md)
* * 仅自然生成于暖水海洋生物群系中。
* * 玩家靠近时会给予他们状态效果，并会变膨胀。
* [热带鱼](热带鱼.md)
* * 仅自然生成于暖水海洋及其深海变种生物群系中。
* * 有16种颜色和图案。
* 死亡后有25%的概率掉落[骨头](骨头.md)。

# = 世界生成 =
* *[海洋](海洋.md)**
* 加入了冷水、温水和暖水海洋及其深海变种。

* *[埋藏的宝藏](埋藏的宝藏.md)**
* 由一个战利品箱组成的结构。
* 可由[藏宝图](藏宝图.md)定位。

* *[珊瑚礁](珊瑚礁.md)**
* 自然生成于暖水生物群系里。
* 由珊瑚、珊瑚块和珊瑚扇构成。

* *[冰山](地形特征#冰山.md)**
* 自然生成于冻洋生物群系里。

* *[沉船](沉船.md)**
* 自然生成于海洋和沙滩生物群系里。
* 包含1-3个战利品箱。
* 生成时可能会直立、侧立或倒立。
* 部分沉船中会生成[去皮木头](原木.md)。

* *[海底废墟](海底废墟.md)**
* 有暖水变种和冷水变种。
* 自然生成于海洋生物群系里。
* 溺尸会自然生成于此。

* *[海洋峡谷](峡谷.md)**
* 自然生成于海洋生物群系里。

* *[水下洞穴](水下洞穴.md)**
* 自然生成于海洋生物群系里。

# = 游戏内容 =
* *[成就](成就.md)**
* 加入了更多成就，其中包括：
* * 亚特兰蒂斯？ - 找到一处[海底废墟](海底废墟.md)（20G）
* * 啊嘿！ - 找到一处[沉船](沉船.md)（20G）
* * 漂流者 - 不吃除了[干海带](干海带.md)以外的东西度过游戏中的三天（20G）
* * 掘金人！ - 挖出一处[埋藏的宝藏](埋藏的宝藏.md)（30G）
* * 替代性燃料 - 用一个[干海带块](干海带块.md)给熔炉供能（20G）
* * 纵横七海 - 访问所有的海洋生物群系（40G）
* * 和鱼一起同眠 - 不使用药水在水下度过一天（30G）
* * 我是一名海洋生物学家 - 用一个桶收集一条鱼（20G）

* *[游泳](游泳.md)**
* 加入了新的游泳动画。

# = 常规 =
* *[商城](商城.md)**
* 加入了“已购内容”部分，以管理玩家已获取的所有内容。
* 为搜索结果加入了排序和过滤功能。

* *[设置](设置.md)**
* 在世界设置选项中加入“[Education Edition](教育版.md)”开关。
* * 在现有世界中启用时，会复制一份世界并标注“<code>[EDU]</code>”来和原世界区分开，类似于实验性游戏内容。
* * 一旦世界创建完毕，便无法关闭。

# 更改
# = 方块 =
* *[床](床.md)**
* 现在玩家尝试在白天睡觉时，其重生点会被设置在床的附近。

* *[按钮](按钮.md)**
* 现在由[橡木木板](橡木木板.md)或[石头](石头.md)合成按钮会显示“橡木按钮”或“石头按钮”。

* *[铁轨](铁轨.md)**
* 现在可以放置在水下。

* *[水](水.md)**
* 现在拥有了新的纹理和颜色。
* 新行为：
* * 水源方块可放置在大多数非固体方块内。
* * 流动的水仍不能流过非固体方块。
* * 方块可以放置在水下，而不会在其周围产生空气。

# = 物品 =
* *[书与笔](书与笔.md)**
* 现在默认作者为“未知作者”。

* *[鱼](鱼.md)**
* 更改了[生鱼](生鱼.md)、[熟鱼](熟鱼.md)、[生鲑鱼](生鲑鱼.md)、[熟鲑鱼](熟鲑鱼.md)、[热带鱼](热带鱼（物品）.md)和[河豚](河豚（物品）.md)的纹理。

* *[拴绳](拴绳.md)**
* 现在可以连接到[船](船.md)上。

# = 生物 =
* *[僵尸](僵尸.md)**
* 幼年僵尸现在会在阳光下自燃。

* *[溺尸](溺尸.md)**
* 现在拥有独特的音效。
* 幼年溺尸现在会在阳光下自燃。
* 现在脸会在黑暗中发亮。

# = 非生物实体 =
* *[船](船.md)**
* 更改了使用键盘和鼠标操作船转向时的控制，现在是按向前移动，按向后翻转。

* *[物品](物品（实体）.md)**
* 现在会漂浮在水上。

# = 游戏内容 =
* *[游泳](游泳.md)**
* 玩家现在可以在1×1的空间中游泳。

* *[呼吸](呼吸.md)**
* 生物在可以呼吸时，氧气值每刻恢复，而不是立即恢复到最大值。

# = 常规 =
* *[控制](控制.md)**
* 微调了游戏指针的定向运动，以获得更可预测的运动。

* *[实验性玩法](实验性玩法.md)**
* [1.2.13](基岩版1.2.13.md)中加入的除[溺尸](溺尸.md)以外的游戏内容不再属于[实验性玩法](实验性玩法.md)。

# 修复
* *修复了40个漏洞**<br>
* *崩溃/性能**
* 修复了一些游戏过程中发生的严重崩溃。
* 修复了导入包含无效文件的附加包时发生的崩溃。
* 修复了对商城内容进行评分时发生的崩溃。
* 修复了在同一刻内执行命令后立即执行命令时发生的崩溃。
* 降低了放置或破坏方块时的延迟。
* 优化了进入皮肤选择器以及应用资源包时的加载时间延迟。
* 优化了存储加载时间的延迟。

* *常规**
* 现在玩家会在烹饪生鳕鱼并吃下熟鲑鱼后解锁“美味的鱼”成就。
* 现在在下载其他任意资源包后创建世界时，已启用的资源包会保持激活状态。
* 修复了Xbox One上的第二个玩家加入分屏游戏时的各种问题。
* 在Xbox One上使用键鼠输入来启动游戏时，分屏控制不再会被弄乱。
* 在输入文本期间断开控制器连接时，玩家不再可以继续输入，直至重连控制器。

* *游戏内容**
* 现在钓鱼时有正确的概率获得1个墨囊。
* 玩家不再能在多人游戏中通过快速丢弃物品来复制物品。
* 上方存在方块的熔岩不再会被阻止对实体造成火焰伤害，以修复鸡肉烹饪机。
* 抗火效果现在会使温暖生物群系中的雪傀儡免疫“融化”伤害。
* 灵魂沙和沙砾现在又会生成于下界了。
* 修复了海晶石砖和暗海晶石的合成配方被颠倒过来的问题。
* 在船上使用附魔击退的武器来攻击生物时，该生物不再总是会被向东击退。
* 现在僵尸和骷髅会在白天乘船时自燃。
* 现在玩家同时按下跳跃键和放置方块键时又会在正下方放置方块了。
* 修复了使用触摸控制时的村民交易会在某些情况下失效的问题。
* 玩家不再可以通过与图书管理员村民交易获得绑定诅咒或消失诅咒附魔书。

* *图形**
* 现在可可豆会在使用HD资源包时正确渲染。
* 从水下观察耕地和草径时不再会出现水的纹理。
* 彼此分开的流动的水不再会在视觉上显示为互相连接。
* 玻璃、黏液块和海晶灯附近的水源方块不再会变为流动的水。
* 被雪覆盖的树叶在禁用平滑光照时不再会渲染为红色。
* 修复了守卫者进行激光攻击时其附近会出现气泡的问题。

* *用户界面**
* 现在轻触设置中又会出现“摧毁方块（震动）”选项了。
* 纸娃娃不再会在主菜单中运作。
* 现在在生存模式中搜索烟花火箭时，其会在配方书中出现。
* 现在加载世界模板界面上会显示一个进度条。
* 修复了Gear TV上的“正在与服务器断开连接”提示会显示过大的问题。
* 修复了设置中的部分选项会在不应该高亮显示时保持高亮显示的问题。
* 现在可以正常使用Chroma Hills HD纹理包中的字体。

* *命令**
* 现在命令在经典UI下使用时会正确清除手持的物品。
* 现在连锁型命令方块在执行命令时，其毗邻的其他连锁型命令方块会按顺序执行命令。
* 现在指定命令的目标为玩家时，该玩家的名称会正确显示。

* *附加包**
* 实体现在会在应用组件时接收到定义效果。
