# 存档会话锁文件格式

*页面ID: 124273* | *来源: Minecraft Wiki*

* *存档会话锁文件**是保证一个存档仅能被一个游戏实例读取和写入的文件。

# 文件格式

存档会话锁文件位于存档根目录下，且文件名为。其内容不随存档变化，固定为一个字符<samp>U+2603</samp>（&#9731;），以UTF-8编码。

# 文件行为

当游戏进入[选择世界菜单](选择世界菜单.md)时，游戏对所有存档都进行下列操作，以确认存档是否被锁定。被锁定的存档不可以被加载，也无法进入对应的世界。
* 如果存档会话锁文件不存在，则此存档未被锁定，可以被加载。
* 如果存档会话锁文件存在，则尝试创建一个只写的文件通道（File Channel），并尝试对此文件施加[独占锁](wzh:排他锁.md)（Exclusive Lock），创建后立刻释放锁和文件通道。
* * 如果游戏成功创建文件通道和独占锁，则认为存档未被锁定，可以加载此存档。
* * 如果游戏不能创建文件通道，或不能施加独占锁，则认为存档被锁定，无法加载。

当游戏加载存档，或创建一个新的存档进入世界时，游戏会按照下列步骤以锁定存档：
# 如果存档目录不存在，创建存档目录。
# 创建一个不存在时创建、只写的文件通道，写入内容。
# 对文件施加独占锁。

如果在锁定存档的过程中发生了任何的I/O异常，或无法对文件施加独占锁，游戏会立刻中止加载存档，并给出相应的报错。

当游戏退出世界并保存存档时，游戏释放独占锁和文件通道，解除对存档的锁定。

如果游戏对此存档会话锁文件没有写权限，或此文件已经被其他程序锁定，那么游戏也会认为存档被锁定而无法加载存档。
