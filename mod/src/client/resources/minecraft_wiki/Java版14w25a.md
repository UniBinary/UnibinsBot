# Java版14w25a

*页面ID: 33980* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w25a**是[Java版1.8](Java版1.8.md)的第27个快照，发布于2014年6月18日<ref></ref>，加入了第二批[缤纷更新](缤纷更新.md)的内容，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[砂土](砂土.md)**
* 替代无草泥土。
* 纹理比[泥土](泥土.md)更暗些。
* 能用两个泥土与两个[沙砾](沙砾.md)交叉摆放合成。

* *[湿海绵](湿海绵.md)**
* 在海绵吸水之后出现。
* 在熔炉中烘干湿海绵能移除水，得到海绵。
* 散发出水的粒子。
* 在[远古守卫者](远古守卫者.md)被杀死时掉落。

* *[海晶石](海晶石.md)**
* 会在[海底神殿](海底神殿.md)中生成。
* 能使用[海晶碎片](海晶碎片.md)合成。
* 海晶石上的裂纹颜色似乎会慢慢在棕色，蓝色，灰色，和紫色之间变化。

* *[海晶石砖](海晶石砖.md)**
* 会在[海底神殿](海底神殿.md)中生成。
* 能使用[海晶碎片](海晶碎片.md)合成。

* *[暗海晶石](暗海晶石.md)**
* 会在[海底神殿](海底神殿.md)中生成。
* 能使用[海晶碎片](海晶碎片.md)与[墨囊](墨囊.md)合成。

* *[海晶灯](海晶灯.md)**
* 会在[海底神殿](海底神殿.md)中生成。
* 能使用[海晶碎片](海晶碎片.md)与[海晶砂粒](海晶砂粒.md)合成。
* 提供15级的亮度，并拥有动态的纹理。

# = 物品 =
* *[海晶碎片](海晶碎片.md)**
* 从[守卫者](守卫者.md)掉落。
* 能被用来合成三种海晶石与海晶灯。

* *[海晶砂粒](海晶砂粒.md)**
* 从[守卫者](守卫者.md)与海晶灯掉落。
* 能被用来合成海晶灯。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了守卫者刷怪蛋，用于生成新的[守卫者](守卫者.md)生物。

# = 生物 =
* *[守卫者](守卫者.md)**
* 在[海底神殿](海底神殿.md)中生成。
* 会用“射线”攻击[鱿鱼](鱿鱼.md)与玩家。
* 在陆地上时，守卫者会四处弹跳但不是像鱿鱼一样窒息。
* 掉落[海晶碎片](海晶碎片.md)，[海晶砂粒](海晶砂粒.md)和[生鱼](生鱼.md)。

* *[远古守卫者](远古守卫者.md)**
* 守卫者的Boss类型变种。
* 每个海底神殿中有3只。
* 靠近它时屏幕上会滑过它的“鬼影”粒子，并得到5分钟的挖掘疲劳III效果。
* 掉落[湿海绵](湿海绵.md)。

# = 世界生成 =
* *[海底神殿](海底神殿.md)**
* 新的水下结构，由[海晶石](海晶石.md)，[海晶石砖](海晶石砖.md)，[暗海晶石](暗海晶石.md)和[海晶灯](海晶灯.md)组成。
* 在神殿中心能找到8个[金块](金块.md)。
* 也会在旧的世界中生成。
* 可在[自定义](自定义.md)世界内切换。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* [深海探索者](深海探索者.md)
* * 允许玩家在水中移动更快。
* * 只能附魔在靴子上。
* * 最高等级为III。

# 更改
# = 方块 =
* *常规**
* 重写[方块数据](Java版数据值/扁平化前/方块ID.md)的处理。
* [移除](Java版已移除方块#Java版1.8之前可获得的方块.md)了以前可以获得的静态水和熔岩（8、9、10和11）、双木台阶和双石台阶（43和125）、[火](火.md)（51）、[下界传送门方块](下界传送门方块.md)和[末地传送门方块](末地传送门方块.md)（90和119）、[可可果](可可果.md)（127）和[马铃薯](马铃薯.md)和[胡萝卜](胡萝卜.md)农作物（141和142）的方块物品。玩家不再能通过或获得它们的方块物品，但仍可通过放置。

* *[海绵](海绵.md)**
* 向[生存模式](生存模式.md)重新加入海绵，有新的行为和纹理。
* 吸水以后会变成湿海绵。
* * 吸水的时候会有水的粒子效果。
* 海绵会破坏5格范围内的水方块。
* 海绵只有在接触到水的时候才会吸水。

* *[高草](高草.md)和[草](草.md)**
* 纹理变得更加明亮。

* *[红石火把](红石火把.md)**
* 不再随机修复自身。

* *[裂纹石砖](裂纹石砖.md)**
* 烧炼石砖能获得裂纹石砖。

* *[告示牌](告示牌.md)**
* 使用JSON文本组件<code>Text1</code>、<code>Text2</code>、<code>Text3</code>与<code>Text4</code>而不是纯文本。
* 可通过使用<code>selector</code>和<code>score</code>标签来显示玩家的分数。
* 在此之前，文本格式化只能通过使用[样式代码](样式代码.md)里的段符号完成。
* 字符限制基于字符宽度。
* 可能需要一段时间才能在生存模式内运作。

* *[巨型蘑菇](巨型蘑菇.md)**
* 通过[精准采集](精准采集.md)魔咒获得它们的相应的蘑菇质地（红色或棕色），而不是孢子。

* *[楼梯](楼梯.md)**
* 所有的楼梯在物品栏里的图标现在换了一个朝向。

* *[绊线](绊线.md)**
* 现在绊线破坏立即引起[绊线钩](绊线钩.md)的状态变化时，绊线的位置若被[空气](空气.md)以外的方块（一般是[液体](液体.md)）占据，会重新生成绊线。

# = 物品 =
* *[成书](成书.md)**
* 使用JSON文本组件和新的<code>pages</code>标签而不是纯文本。
* 能够使用<code>clickEvent</code>和<code>hoverEvent</code>标签。
* 在此之前，文本格式化只能通过使用[样式代码](样式代码.md)里的段符号完成。
* 可能需要一段时间才能在生存模式内运作。

# = 生物 =
* *[铁傀儡](铁傀儡.md)与[雪傀儡](雪傀儡.md)**
* 组成的方块可以以任何方向放置。

* *[凋灵](凋灵.md)**
* 现在可以在生成后的无敌阶段后立即移动。<ref></ref>
* 组成的方块可以以任何方向放置。

# = 非生物实体 =
* *[箭](箭.md)**
* 改变在水下的行为。
* * 它们飞不过几个方块就会缓慢掉落。
* * 火矢会被熄灭。

# = 命令格式 =

* 添加了三个[记分板](记分板.md)操作：<code><</code>、<code>></code>与<code>=</code>

# = 游戏内容 =
* *[状态效果](状态效果.md)**
* 在水下同时拥有夜视和水肺状态效果可以看得更清楚。<ref></ref>

# = 常规 =
* *玩家列表**
* 玩家列表现在显示玩家的脸部。

* *[调试屏幕](调试屏幕.md)**
* 按下+会以一条蓝线显示眼前的实体看的方向。

* *[选项](选项.md)**
* 移除了各向异性过滤选项。

* *[模型](模型.md)**
* 更改了模型格式。<ref></ref>
* * 新的<code>"textures"</code>用于指定模型使用的纹理。
* * 从uv定义中删除方向属性，并将其替换为显式纹理引用。
* ** <code>"textureFacing"</code>重命名为<code>"texture"</code>，前跟井号（<nowiki>#</nowiki>）
* * <code>"useAmbientOcclusion"</code>重命名为<code>"ambientocclusion"</code>
* * <code>"rotateVariantTextures"</code>重命名为<code>"UV lock"</code>
* * <code>"cull"</code>重命名为<code>"cullface"</code>，指定哪个相邻面导致发生剔除的相反面。
* ** 示例：将一个面向东方的面部沿着不同的轴线（如Z轴）进行剔除 ：<code>"cullface": "north"</code> 或 <code>"cullface": "south"</code>
* * 旋转变得更加冗长，更清楚地说，它只能出现在单个轴上。
* ** 示例：“十字”模型的两个面的其中一个的旋转现在为：<code>"rotation": { "origin": [ 8, 8, 8 ], "axis": "y", "angle": 45, "rescale": true },</code>
* * 文件夹被移除，模型文件现在储存在里。
* * 加入了文件夹，用于储存之前在找到的模型选择文件。

* *渲染**
* 所有的物品都拥有模型，有些仍由物品图标生成。
* 资源包可以自定义所有的物品模型。
* 重写方块渲染。
