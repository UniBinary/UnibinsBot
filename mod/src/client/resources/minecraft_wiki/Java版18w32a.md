# Java版18w32a

*页面ID: 35808* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w32a**是[Java版1.13.1](Java版1.13.1.md)的第4个快照，发布于2018年8月8日<ref></ref>，加入了失活的珊瑚以及骨粉的新特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[失活的珊瑚](失活的珊瑚.md)**
* 为珊瑚的失活变种。
* 可放置在方块的顶部。

# = 物品 =
* *[骨粉](骨粉.md)**
* 在暖水海洋生物群系里使用[骨粉](骨粉.md)有概率生成[珊瑚扇](珊瑚扇.md)。

# 更改
# = 方块 =
* *[珊瑚](珊瑚.md)**
* 现在可以放置在空气中。
* * 除非被充水，否则一段时间后会失活。

* *[紫珀柱](紫珀柱.md)**
* 现在可以合成[紫珀楼梯](紫珀楼梯.md)了。

# = 实体 =
* *常规**
* 实体处在方块内时不再掉出整个世界<ref></ref>。

# = 常规 =
* *性能**
* 优化了性能。
