# 音符盒

*页面ID: 7743* | *来源: Minecraft Wiki*

* *音符盒（Note Block）**是一种会在受到玩家或接受[红石信号](红石信号.md)后发出声音的方块。

# 生成
# = 自然生成 =
音符盒会在[远古城市](远古城市.md)的冰窖建筑中作为“门铃”生成。

# = 合成 =

# 破坏
挖掘音符盒的合适工具是斧。

音符盒被破坏后会掉落自身。

# 用途
# = 奏乐 =
# == 音符 ==
[275px|缩略图|右|一个正在发出声音的音符盒](File:Note-Block.png.md)

当被玩家<ref group="注">使用“”或“”控制模式时，可通过长按来敲击。</ref>或被红石信号激活，并且上方1格为[空气](空气.md)时，音符盒会奏出彩色的音符。

音符盒发出的声音最远能传播48格，音量随玩家与音符盒的距离增大而线性减小。

每当音符盒发声时，其上部都会弹出一个音符的粒子效果；音符的颜色仅取决于发出声音的音高。

每次音符盒都会让其下一个发出音符的音高提高半音。按照十二平均律，每个乐器总共有两个完整的八度音程（即从起始音到比其高两个八度的音），总共25个音。

以钢琴的音域为准，贝斯和迪吉里杜管比标准音域低两个八度，吉他比标准音域低一个八度，长笛、牛铃比标准音域高一个八度，而铃铛、管钟和木琴比标准音域高两个八度；因此，玩家可以通过组合不同乐器来获得六个八度（72个半音）的音域。音域不同的根本原因是不同乐器的采样在不同的音域。也就是说，如果使用命令来播放不同的音符声音，在音高参数相同时播放的音高其实是不一致的。

标准音域的范围是F♯<sub>3</sub>～F♯<sub>5</sub>。在提高至F♯<sub>5</sub>后再次点击音符盒就会复位至发出F♯<sub>3</sub>的状态。下面是具体的音高列表。<ref>[作者：cookingfat](http://www.minecraftforum.net/viewtopic.php?f=1020&t=136347)</ref><ref>[/playsound音高图表。作者：kwerti](http://www.minecraftforum.net/forums/mapping-and-modding/resource-packs/resource-pack-discussion/1255570)</ref>

# == 乐器 ==
音符盒放出的乐器声取决于音符盒下方方块的[乐器方块基本属性](方块基本属性#乐器.md)。

# == 生物音效 ==
若音符盒顶面上放置了以下生物的[生物头颅](生物头颅.md)，玩家敲击或红石激活音符盒时，音符盒会随机播放对应音效（除苦力怕外均为生物的空闲音效），：

没有与玩家的头相对应的专用音效ID。默认情况下，玩家的头不对应任何音效，但可通过方块NBT标签设置一个现存的音效ID，对应的字幕会在播放音效时显示。

上述音效均由音符盒发出，并受中的“”滑块控制。

# == 红石元件 ==
[275px|缩略图|连接着一个[[时钟电路](File:Note Block with Clock Circult.png.md)的交替播放的一对音符盒]]

音符盒是[机械元件](红石元件#机械元件.md)，可被下列形式激活：
* 毗邻的开启的**[电源](红石元件#电源.md)**（例外：[红石火把](红石火把.md)不会激活其所附着的音符盒，[侦测器](侦测器.md)只会激活指向的音符盒）。
* 毗邻的**[充能方块](红石电路/充能与激活.md)**。
* 毗邻的指向音符盒且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)（包括音符盒上方的红石粉）；毗邻但未指向音符盒的红石粉不会激活音符盒。

音符盒被点击、信号上升沿或下降沿后，其会立刻发出[方块更新](方块更新.md)，并在[启动延迟](活塞#启动延迟.md)后发出声音。
* 因此将音符盒和侦测器或[方块更新检测器](Tutorial:方块更新感应器.md)组合可构建一个可静音的“按钮”。

音符盒上方为空气或生物头颅才能发声，在上方布置任意其他方块均会静音。

音符盒是[红石导体](红石导体.md)，因此可以充能音符盒，被充能的音符盒也能作为充能方块激活毗邻的其他元件。

# = 悦灵 =
音符盒奏响时会向半径16格以内的所有[悦灵](悦灵.md)发送[振动粒子](粒子#vibration.md)。且在奏响后30秒内，悦灵会在该音符盒周围搜寻物品，并将物品带到此音符盒处，而不是带给其信任的玩家。

音符盒向悦灵发送的信号可被[羊毛](羊毛.md)阻断。

# = 燃料 =
音符盒可以被用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个音符盒可烧炼1.5个物品。

# 你知道吗
* 默认状态下音符盒的音符起于F♯，然而现实中F♯调的乐器极为罕见。
* 音符盒上方有方块堵住时，玩家仍能给它调音，不过音符盒不会发声，也不会出现音符。
