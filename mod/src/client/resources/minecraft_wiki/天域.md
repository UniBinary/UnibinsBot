# 天域

*页面ID: 8158* | *来源: Minecraft Wiki*

* *天域（Sky Dimension，简称Sky）**是一个曾经的计划加入Minecraft的[维度](维度.md)，与[下界](下界.md)相对。

# 进入
天域无法通过常规方法进入，只能通过在Beta 1.6.6中修改wr.class、在Beta 1.7.3中修改xa.class或在Beta 1.8.1中修改acz.class来进入天域。

# 环境
[缩略图|Beta 1.8中的天域](File:Sky Dimension 03.png.md)

天域由许多岛屿构成，方块构成与[主世界](主世界.md)类似，矿石和主世界的一些结构仍会在天域中生成，高于Y=65的区域则会被[顶层雪](顶层雪.md)覆盖。

天域没有昼夜更替和天气变化，时间永远为正午，天气默认为晴天。云层高度为Y=9，玩家若从天域掉下来，就会因落入虚空而死亡。

天域中只会自然生成[鸡](鸡.md)一种生物。

# Beta 1.9-pre3中的天域
[缩略图|多人游戏中的地形漏洞](File:SkylandsError.png.md)

最初，天域的代码被隐藏在了0区域内，也就是主世界的区域。但自从[Beta 1.9-pre3](Java版Beta 1.9-pre3.md)开始，它有了独立的区域：2区域。然而，在服务器里主世界中可能会错误地生成一部分天域地形，而不是在自己的维度内生成。这很可能是由于世界生成和保存的问题，导致天域区块为了节省资源而生成在主世界，而不是像下界那样生成独有的维度中。这就导致了主世界的生成可能会突然断裂，在一片虚空中出现天域的浮岛景观。
