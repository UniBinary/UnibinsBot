* *喷溅药水（Splash Potion）**是[药水](药水.md)的可投掷变种。

# 获取
# = 酿造 =

向普通药水加入[火药](火药.md)能酿造喷溅药水。酿造出的喷溅药水显示的时长（若有）与原药水相同。

、无法通过酿造获得，只能通过命令或[创造模式物品栏](创造模式物品栏.md)获得。

# = 自然生成 =
在[雪屋](雪屋.md)地下室的[酿造台](酿造台.md)中可以找到一瓶喷溅型虚弱药水。

# = 填充玻璃瓶 =

对着含有喷溅药水的[炼药锅](炼药锅.md)玻璃瓶，可以得到一瓶喷溅药水，这会消耗炼药锅中的水量。

# = 以物易物 =
成年[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予[玩家](玩家.md)一瓶喷溅型抗火药水。

# = 箱子战利品 =

由于喷溅药水的最大堆叠数量为1，数量大于1的堆叠会被展开为对应数量的单个物品堆叠。

# 用途
# = 酿造 =

向喷溅药水加入龙息能酿造滞留药水。

# = 投掷 =
喷溅药水可以将其投掷出去，生成弹射物。

[发射器](发射器.md)也可以射出喷溅药水。

喷溅药水被投掷后会破裂而不会返还空瓶。

# = 和泥 =
对[泥土](泥土.md)、[缠根泥土](缠根泥土.md)或[砂土](砂土.md)喷溅型水瓶可使其转变为[泥巴](泥巴.md)，并返还[玻璃瓶](玻璃瓶.md)。[发射器](发射器.md)对这些方块发射喷溅型水瓶仍会生成弹射物，而非将其转变。

# = 填充炼药锅 =

对[炼药锅](炼药锅.md)喷溅药水可使炼药锅提升两级药水位，同时把手持的喷溅药水变为玻璃瓶。如果炼药锅盛有[状态效果](状态效果.md)、效果等级与该喷溅药水不同的药水，或是其他物质，进行此操作则会导致炼药锅被清空，并产生爆炸的音效和粒子。

# = 不可合成的喷溅型药水 =
不可合成的喷溅型药水是或的喷溅药水，它不能在生存模式获取。它也有药水、滞留药水和药箭的版本。

喷溅药水在没有药水效果或有游戏无法识别的药水效果ID时，其药水效果ID会或，变为不可合成的喷溅型药水。

# 行为
喷溅药水是一种[弹射物](弹射物.md)，可以触发[标靶](标靶.md)。

喷溅药水会受到重力影响和环境阻力的影响。

喷溅药水穿过[火](火.md)或[熔岩](熔岩.md)不会[着火](着火.md)，则会。

# = 施加状态效果 =
喷溅药水破裂时会影响药瓶碎裂中心的8.25×8.25×8.25内的所有生物，即以碎裂点为中心的半径4格的圆以内的生物会受到影响。<ref group="注">特别是它的西北角，像大多数投掷物一样，喷溅药水的实体大小是0.25×0.25×0.25。</ref>在同一水平面，药水能被玩家抛出的最大距离为6格，即最远影响距离约为10格。方块不能阻挡喷溅药水对生物产生影响。

实体受到的影响随距离<ref group="注">指喷溅药水在破裂时的判定箱与实体判定箱外扩0.3得到的判定箱之间的最短距离。</ref>增大而减少，受到的影响为中心的100%线性减少到4个方块外的0%。对于瞬间治疗和瞬间伤害，会影响其造成的治疗量和伤害量；对于其他效果，会影响效果的持续时间，如果持续时间小于则没有效果。

# = 造成伤害 =
[瞬间伤害](瞬间伤害.md)对非亡灵生物或[瞬间治疗](瞬间治疗.md)对亡灵生物产生影响时，喷溅药水会直接对这些实体造成魔法伤害，且伤害来源为喷溅药水的投掷者。

# = 喷溅型水瓶 =
喷溅型水瓶会扑灭扔中及与其水平相邻的方块上的[火](火.md)、[营火](营火.md)和[灵魂营火](灵魂营火.md)，且会在欧几里得距离4格内产生如下影响：
* 为[着火](着火.md)的生物灭火。
* 将点亮的[蜡烛](蜡烛.md)熄灭。
* 对烈焰人、末影人、雪傀儡和炽足兽造成的伤害。
* * 然而，如果喷溅型水瓶直接砸向末影人，末影人会瞬移而不被命中。
* 使[美西螈](美西螈.md)的氧气值恢复。

# = 与方块交互 =
喷溅药水可以触发其击中的[标靶](标靶.md)、敲响[钟](钟.md)或击塌[大型垂滴叶](大型垂滴叶.md)。

喷溅药水可以激活[木质压力板](木质压力板.md)和[绊线](绊线.md)。当喷溅药水穿过这些方块时，这些开关会保持开启状态。其他开关则不受喷溅药水的影响。

# 你知道吗
* 如果末影人即将被喷溅药水砸中，它会传送离开，但如果喷溅药水不是直接扔向它，而是扔在它的脚边，则末影人不会躲避，会受到药水影响。
* 如果玩家或驯服的[狼](狼.md)、[猫](猫.md)、[鹦鹉](鹦鹉.md)、被[发射器](发射器.md)/命令生成/自己使用的伤害药水杀死，那么它们的[死亡消息](死亡消息.md)就会是“*<玩家/生物>* 被魔法杀死了”。如果是被其他生物或玩家使用的喷溅型伤害药水杀死，则会显示“*<玩家/生物>*被*<玩家/实体>*使用的魔法杀死了”。
* 被投掷出的喷溅药水看起来会比小，因此在视觉上来说Java版的喷溅药水能投掷得比基岩版的远。
* 如果将一瓶喷溅药水喷溅至苦力怕，苦力怕会在爆炸时产生这种药水的滞留效果。
