# 基岩版1.16.230.56

*页面ID: 81478* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.230.56**是[基岩版1.17.0](基岩版1.17.0.md)的第4个测试版，发布于2021年4月15日<ref></ref>，加入了新的[洞穴](洞穴.md)生成机制，并修复了一些漏洞。

# 新内容
# = 世界生成 =
* *[洞穴](洞穴.md)**
* 加入了[噪声洞穴](噪声洞穴.md)，包含“意面洞穴”和“芝士洞穴”。
* 加入了[含水层](含水层.md)。
* 旧的[雕刻器洞穴](洞穴#雕刻器洞穴.md)仍会生成，并会与噪声洞穴相互连接。

* *[意面洞穴](意面洞穴.md)**
* 一种狭长的洞穴。
* 生成时使用了[噪声生成器](自定义世界生成.md)。
* 与地面相交时会生成洞穴入口。
* 目前属于[实验性玩法](实验性玩法.md)（Caves & Cliffs子选项）。

* *[芝士洞穴](芝士洞穴.md)**
* 生成时使用了[噪声生成器](自定义世界生成.md)。
* 通常会生成不同大小的洞穴。
* 与地面相交时会生成洞穴入口。
* 目前属于[实验性玩法](实验性玩法.md)（Caves & Cliffs子选项）。

* *[含水层](含水层.md)**
* 噪声洞穴中的水源。
* 含水层暂时只在主世界Y=31以下的区域自然生成，使得Y=31至63间的噪声洞穴暂时被[水](水.md)充满。
* 取代了旧的水下洞穴和水下峡谷。
* [鱼](鱼.md)、[美西螈](美西螈.md)和[发光鱿鱼](发光鱿鱼.md)会在[海洋](海洋.md)及[河流](河流.md)生物群系下方的含水层中自然生成。
* 目前属于[实验性玩法](实验性玩法.md)（Caves & Cliffs子选项）。

# 更改
# = 世界生成 =
* *[洞穴](洞穴.md)**
* 加入了[噪声洞穴](噪声洞穴.md)的生成机制。
* 加入了[含水层](含水层.md)的生成机制。

* *[废弃矿井](废弃矿井.md)**
* 现在桥梁下方离方块较远时会生成[锁链](锁链.md)来拉起桥梁，或者生成[橡木](木头.md)支柱来支撑桥梁。

* *[矿石](矿石.md)生成**
* 更改了矿石生成机制以匹配新的世界高度。

# = 游戏内容 =
* *[游泳](游泳.md)**
* 提高了在水下洞穴中游泳的能见度。

# 修复
* *游戏内容**
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了玩家在非主世界维度治愈僵尸村民后发生的崩溃。（）
* 修复了开启[实验性玩法](实验性玩法.md)（Caves & Cliffs子选项）后生成丛林生物群系发生的崩溃。

* *角色创建器**
* 修复了角色创建器上切换已拥有和未拥有的物件时可能发生的崩溃。
* 修复了角色创建器上无法使用物件来装饰角色的问题。（）</onlyinclude>
