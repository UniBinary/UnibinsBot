# Java版Alpha v1.2.0-preview

*页面ID: 35308* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.2.0-preview**是[Alpha v1.2.0](Java版Alpha v1.2.0.md)的特别的预发布版，该版本只作为预览版提供给[*PC Gamer*](https://www.pcgamer.com/minecraft-halloween-update-hands-on/)和[*Indiegames*](http://www.indiegames.com/2010/10/handson_with_the_minecraft_hal.html)。<ref></ref>

# 与Alpha v1.2.0的不同
# = 方块 =
* *[荧石](荧石.md)**
* 被破坏时掉落自身而不是一个荧石粉。

# = 生物 =
* *[僵尸猪人](僵尸猪人.md)**
* 身上有着最初的血纹理，而不是绿色的液体。<ref></ref>
* 行走时会发出[猪](猪.md)的音效，而受伤时会发出[僵尸](僵尸.md)的音效。
* 它们没有像僵尸那样抬起手臂，也没有手持金[剑](剑.md)。

* *[恶魂](恶魂.md)**
* 没有任何音效。

# = 世界生成 =
* *[下界](下界.md)**
* 被称为*the Slip*。<ref name="slip"></ref>

* *[下界传送门](下界传送门.md)**
* 被称为*Slip Gate*。<ref name="slip"/></onlyinclude>

# 你知道吗
* 在发布此版本的那天，Minecraft销售量突破500000。
