# Java版1.19.4-pre4

*页面ID: 102797* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.19.4-pre4**是[Java版1.19.4](Java版1.19.4.md)的第4个，也是最后一个预发布版，发布于2023年3月8日<ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[选项](选项.md)**
* 加入了按钮，用于查看[鸣谢名单](鸣谢名单.md)、和。

* *[标签](Java版标签.md)**
* 加入了以下伤害类型标签：
* * ：。

# 更改
# = 方块 =
* *[幽匿感测体](幽匿感测体.md)**
* 现在可以检测到潜影弹被摧毁。

# = 生物 =
* *[蜘蛛](蜘蛛.md)**
* 现在蜘蛛生成时附带的[状态效果](状态效果.md)拥有无限的持续时间，而不是之前的2<sup>31</sup>-1[游戏刻](游戏刻.md)（约3.4年）。

# = 非生物实体 =
* *[展示实体](展示实体.md)**
* 现在，新的插值会从当前状态而不是最终状态下开始。

# = 常规 =
* *[菜单屏幕](菜单屏幕.md)**
* 现在点击主菜单上的版权文本会进入页面，而不是直接打开鸣谢名单。

# 更改（实验性）
# = 方块 =
* *[樱花树叶](樱花树叶.md)和[樱花木告示牌](樱花木告示牌.md)**
* 更改了纹理。
