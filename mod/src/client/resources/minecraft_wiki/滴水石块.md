# 滴水石块

*页面ID: 72660* | *来源: Minecraft Wiki*

* *滴水石块（Dripstone Block）**是一种可用于培育[滴水石锥](滴水石锥.md)的岩石方块。

# 生成
# = 自然生成 =
滴水石块会常见地生成于[溶洞](溶洞.md)生物群系。

# 获取
# = 交易 =

# = 合成 =
滴水石块可以使用滴水石锥合成。

# 破坏
挖掘滴水石块的合适工具是镐。滴水石块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

滴水石块被破坏后会掉落自身。

# 用途
滴水石块能为[滴水石锥](滴水石锥.md)提供生长条件。

# = 培育滴水石锥 =

当滴水石块上方有[水](水.md)源且下方有[钟乳石](钟乳石.md)（由尖端朝下的滴水石锥组成）时，滴水石锥可以在其下缓慢地生长。
