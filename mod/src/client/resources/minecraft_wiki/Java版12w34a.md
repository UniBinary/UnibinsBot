# Java版12w34a

*页面ID: 32944* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w34a**是[Java版1.4.2](Java版1.4.2.md)的第2个快照，发布于2012年8月23日<ref></ref>。

# 新内容
# = 方块 =
* *木质[按钮](按钮.md)**
* 可以被[箭](箭.md)激活。

* *[圆石墙](圆石墙.md)和[苔石墙](苔石墙.md)**
* 行为和[栅栏](栅栏.md)相似。

* *[花盆](花盆.md)**
* 可将大部分植物放入花盆里并作装饰用途。
* *装饰物**
* [物品展示框](物品展示框.md)
* * 合成配方与[画](画.md)类似，只是用[皮革](皮革.md)替代[羊毛](羊毛.md)。

# = 物品 =
* *[胡萝卜](胡萝卜.md)**
* 加入了胡萝卜和[金胡萝卜](金胡萝卜.md)。
* 胡萝卜可以种植在[耕地](耕地.md)上。

* *[马铃薯](马铃薯.md)**
* 加入了马铃薯、[烤马铃薯](烤马铃薯.md)和[毒马铃薯](毒马铃薯.md)。
* 马铃薯可以种植在耕地上。

* *[药水](药水.md)**
* 加入了隐身药水。
* * 通过在酿造台中加入一个发酵蛛眼到夜视药水[酿造](酿造.md)而成。
* * 生物对拥有[隐身](隐身.md)效果的玩家的探测范围缩小。
* * 拥有隐身效果的玩家的名称会被隐藏。

# = 生物 =
* *[凋灵](凋灵.md)**
* 只能通过第三方软件获得，例如编辑[刷怪笼](刷怪笼.md)、使用[Mod](Mod.md)或者修改游戏。
* 会发射名为凋灵之首的弹射物并且会摧毁方块。
* 拥有Boss血量条。

# = 常规 =
* *[选项](选项.md)**
* 在视频选项中加入了全屏切换。
* 在视频选项中加入了垂直同步切换。
* 加入了一个未使用的纹理到。

# 更改
# = 方块 =
* *[信标](信标.md)**
* 从创造模式物品栏中移除了“Work in Progress”（建设中）方块。

* *[火](火.md)**
* 现在会根据难度而改变传播速度。

* *[刷怪笼](刷怪笼.md)**
* 生物磨床在持续刷经验时给予更少的经验。

* *[树苗](树苗.md)**
* 现在有了更小的碰撞箱。

* *[楼梯](楼梯.md)**
* 楼梯现在会自动连接角落，这是一个测试，可能会根据反馈而改变。

* *[TNT](TNT.md)**
* 着火的箭现在可以激活TNT。

* *[活板门](活板门.md)**
* 现在能够放置在最高位置（基于十字准星瞄准）。

# = 物品 =
* *[地图](地图.md)**
* 地图现在与网格对齐，从而更容易创建相邻的地图。
* 1个[指南针](指南针.md)和8张[纸](纸.md)现在用于创建空地图。
* * 右键单击空地图才能显示数据。右键点击的世界上的点是地图的中心。
* 地图（包括数据）现在可以被复制，复制的地图可以堆叠。
* 地图可以缩小，但不能放大。

* *[染料](染料.md)**
* 皮革[盔甲](盔甲.md)现在可以被染色。
* * [皮革](皮革.md)的默认颜色可以被更改。
* * 可以手持一个已经染色的盔甲对着装满水的[炼药锅](炼药锅.md)点击以移除染料。
* 已经驯服的[狼](狼.md)的项圈可以被染色。

* *[药水](药水.md)**
* 现在[夜视药水](夜视药水.md)可通过在[酿造台](酿造台.md)中给粗制的药水加入金胡萝卜酿造而成。

* *[刷怪蛋](刷怪蛋.md)**
* 蜘蛛刷怪蛋现在有概率生成[蜘蛛骑士](蜘蛛骑士.md)。

# = 生物 =
* *常规**
* 生物（包括其他实体）现在可以穿过传送门。

* *[村民](村民.md)**
* 更改了与村民完成交易时的粒子效果。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* F3调试屏幕里的<code>f:</code>现在显示玩家正在看着的方向，从南方到-180和180度之间。
* 按下使在窗口失去焦点时会自动暂停游戏（主要用于调试）。
* 按下会显示或隐藏物品的详细信息（也是用于调试）。

# 修复
* *修复了3个漏洞**
* 修复了僵尸在阳光下不会燃烧的问题。
* 修复了箱子和末影箱图像上的错误。
* 修复了信标导致崩溃的问题。</onlyinclude>
