# 蜂巢（方块）

*页面ID: 46815* | *来源: Minecraft Wiki*

* *蜂巢（Bee Nest）**是作为[蜜蜂](蜜蜂.md)巢穴的方块。

# 生成
# = 自然生成 =
[thumb|一只[[蜜蜂](File:Bee and bee nest.png.md)在蜂巢旁飞行]]

蜂巢在不同生物群系当中的生成情况如下表所示：

<references group="注" />

每个自然生成的蜂巢里都会容纳3只[蜜蜂](蜜蜂.md)。

# = 树苗 =
若白桦、樱花或[树苗](树苗.md)水平2格范围内存在[花](花.md)、，则该树苗长成的树会有5%的概率携带蜂巢。红树胎生苗长成的树也有1%的概率携带蜂巢。即使周围不存在花，橡树树苗长成的树也有5%的概率携带蜂巢<ref></ref>。

每个由此生成的蜂巢里都会容纳1-3只蜜蜂。

# 获取
蜂巢只能通过破坏蜂巢获得。

# 破坏
挖掘蜂巢的合适工具是[斧](斧.md)。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，蜂巢被破坏后不会掉落，蜂巢中的蜜蜂会以激怒状态被释放出来，同时还会激怒附近的所有蜜蜂。

被具有精准采集的工具挖掘破坏时，蜂巢被破坏后会掉落自身，并装着其中的蜜蜂。

在[创造模式](创造模式.md)下破坏装有蜜蜂的蜂巢时，该蜂巢会掉落并装着其中的蜜蜂，并保留其<code>honey_level</code>数据。<ref></ref>

# 用途
蜂巢有一项方块状态<code>honey_level</code>，可以取0至5中的一个值。新放置的蜂巢的<code>honey_level</code>为0。

<code>honey_level</code>为5的蜂巢会使用充满了蜂蜜的纹理，表明蜂巢可以收获。若该方块的下表面未被遮挡，还会产生滴落的蜂蜜[粒子](粒子.md)。

# = 容纳蜜蜂 =
蜂巢最多同时容纳3只蜜蜂。蜜蜂可以从蜂巢的任何一面进去，但只能从正面出来。

蜜蜂在工作完成后，会不带花蜜离巢，并使蜂巢的<code>honey_level</code>增加1，至多增加至5。

与蜂巢相邻的任何一个方块是[火](火.md)时，其中所有的蜜蜂都会逃离。

# = 收获 =
对<code>honey_level</code>为5的蜂巢[剪刀](剪刀.md)会使其掉落3个[蜜脾](蜜脾.md)，使用[玻璃瓶](玻璃瓶.md)则会使玻璃瓶变为[蜂蜜瓶](蜂蜜瓶.md)，随后其<code>honey_level</code>会变为0。

若玩家从蜂巢收获时，蜂巢的正下方6格内没有点燃的[营火](营火.md)或[灵魂营火](灵魂营火.md)，或二者之间被其他方块阻挡，则其中所有的蜜蜂都会被释放出来并与该玩家敌对。用[发射器](发射器.md)进行收集不会将蜜蜂释放出来。玩家在创造模式或[和平难度](难度#和平.md)下收获时，蜜蜂仍然会被释放出来，但不会攻击玩家。

# = 红石信号 =
当[红石比较器](红石比较器.md)连接至蜂巢时，会输出与其方块状态<code>honey_level</code>相同数值强度的红石信号。
