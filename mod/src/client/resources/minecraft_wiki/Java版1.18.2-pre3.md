# Java版1.18.2-pre3

*页面ID: 93298* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.18.2-pre3**是[Java版1.18.2](Java版1.18.2.md)的第3个，也是最后一个预发布版，发布于2022年2月23日<ref></ref>，修复了一些漏洞。

# 修复
命令不能正常工作。
|248618|每次重载资源包时，游戏计时器及其提醒也会被重载。
|248636|进入或创建世界时，游戏输出、服务器控制台和日志会被“Creating a MIN function between two non-overlapping inputs”刷屏。
|248637|由于在<code>net.minecraft.nbt.CompoundTag$1.skip</code>类中会<code>StackOverflowError</code>异常，打开单人游戏界面时游戏会崩溃。
|248680|在超平坦世界中使用命令定位掠夺者前哨站时，游戏会卡住。
|;previous
|248748|指向自定义结构的探险家地图会导致服务器被挂起。
}}</onlyinclude>
