# 携带版0.16.0

*页面ID: 22689* | *来源: Minecraft Wiki*

* *v0.16.0**是**[Boss更新](Boss更新.md)**<ref name=MojangPEPost>http://mojang.com/2016/08/sneak-peek-boss-update-is-coming-to-pocket-and-windows-10/</ref>的首个正式版，也是的一次主要更新，在Android、FireOS、Windows Phone和Windows 10上发布于2016年10月21日，而在iOS上发布于10月25日。此次更新加入了许多新特性，例如[命令](命令.md)、[信标](信标.md)、[海底神殿](海底神殿.md)、[守卫者](守卫者.md)、[远古守卫者](远古守卫者.md)和[凋灵](凋灵.md)，并修复了一些漏洞<ref></ref>。

# 新内容
# = 方块 =
* *[信标](信标.md)**
* 通过建造矿物块金字塔可以激活信标。
* 给信标加入铁锭、金锭、钻石和绿宝石可以激活增益，给予玩家一些正面[状态效果](状态效果.md)。

* *[海晶灯](海晶灯.md)**
* 自然生成于海底神殿。
* 会发出等级为15的亮度。

* *[海晶石](海晶石.md)、[暗海晶石](暗海晶石.md)和[海晶石砖](海晶石砖.md)**
* 自然生成于海底神殿。

* *[湿海绵](湿海绵.md)**
* 自然生成于海底神殿。
* 可以使用熔炉烘干。
* 已经加入的海绵吸水后会变成湿海绵。

# = 物品 =
* *[海晶砂粒](海晶砂粒.md)**
* 通过杀死[守卫者](守卫者.md)或挖掘[海晶灯](海晶灯.md)掉落。

* *[海晶碎片](海晶碎片.md)**
* 通过杀死[守卫者](守卫者.md)或[远古守卫者](远古守卫者.md)掉落。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了守卫者和远古守卫者刷怪蛋。

* *[下界之星](下界之星.md)**
* 通过杀死凋灵获得。
* 不会被爆炸摧毁。

* *[药水](药水.md)**
* 衰变[药水](药水.md)
* * 喷溅型衰变[药水](药水.md)

* *[药箭](药箭.md)**
* 衰变之[箭](箭.md)

# = 生物 =
* *[守卫者](守卫者.md)**
* 自然生成于海底神殿。

* *[远古守卫者](远古守卫者.md)**
* 被认定为Boss生物。<ref name=MojangPEPost/>
* 每个海底神殿只会生成3个。
* 会给予附近的玩家[挖掘疲劳](挖掘疲劳.md)III效果。

* *[凋灵](凋灵.md)**
* 新的Boss生物。
* 当生命值降至50%时生成3-4个[凋灵骷髅](凋灵骷髅.md)。
* * 不会在简单难度下生成。
* 制作、生命值降至50%和被杀死时有新的动画。
* 新的声音。

# = 世界生成 =
* *[海底神殿](海底神殿.md)**
* 自然生成于[深海](深海.md)生物群系里。
* 包含了8个金块和海绵房间。
* 会生成[守卫者](守卫者.md)和[远古守卫者](远古守卫者.md)作为护卫。

# = 常规 =
* *[成就](成就.md)**
* 加入了更多成就。

* *[设置](设置.md)**
* 自定义键盘控制的键位。
* 为[创造模式物品栏](创造模式物品栏.md)加入了搜索栏。（仅Windows 10版）
* 在VR选项下加入鼠标UI敏感度的选项。（仅Oculus Rift的Windows 10版）
* 选项菜单的新UI。
* 新的世界选项和创建世界UI。
* 更多选项。
* * 切换式潜行。
* 加入了退出游戏前的警告。
* 现在可以在移动设备上通过双击来导入Add-on（行为包）、资源包或世界（暂时不在Android平台上运作）。

# 更改
# = 方块 =
* *[海绵](海绵.md)**
* 重新加入到生存模式中。
* 可以吸水了。
* 更改为Java版1.8的纹理。

* *[床](床.md)**
* 放置时有了新的音效。

* *[熔炉](熔炉.md)**
* 对于不使用控制器的设备有了更好的描述（输入、燃料及产品）。

* *[怪物蛋](怪物蛋.md)**
* 加入到[创造模式物品栏](创造模式物品栏.md)。

* *[箱子](箱子.md)**
* 自定义名称不再出现在GUI中。

* *[草径](草径.md)**
* 加入了制作时的音效。

# = 物品 =
* *[铁桶](铁桶.md)**
* 使用时有了新音效。

* *[地图](地图.md)**
* 不同生物群系有不同颜色。

* *[时钟](时钟.md)**
* 调整时钟的纹理以纠正全部的错误像素。

* *[可可豆](可可豆.md)**
* 移除了原有的合成配方。

# = 生物 =
* *[尸壳](尸壳.md)**
* 加入了新的音效。

* *[流浪者](流浪者.md)**
* 加入了新的音效。

* *[苦力怕](苦力怕.md)**
* 添加了空闲的音效。

* *[鱿鱼](鱿鱼.md)**
* 添加了新的音效。

* *[凋灵骷髅](凋灵骷髅.md)**
* 当凋灵的生命值降至50%时生成。

* *[铁傀儡](铁傀儡.md)**
* 会在和平难度下伤害玩家。

* *[狼](狼.md)**
* 会在和平难度下伤害玩家。

# = 非生物实体 =
* *[矿车](矿车.md)**
* 玩家不能破坏他们坐着的矿车了。

* *[摄像机](摄像机.md)**
* 被完全移除，它现在仅存于教育版中。

# = 常规 =
* *[HUD](平视显示器.md)**
* 更改了经验条的纹理。
* *性能**
* 性能优化。
* 为有余力的GPU提升视野距离。（仅Windows 10版与教育版）

* *[菜单屏幕](菜单屏幕.md)**
* 皮肤选择器在选择自定义皮肤时不再在皮肤后显示轮廓。
* 调整UI界面下Oculus Rift的传感器的纵向横向运动比例的鼠标敏感度。（仅Oculus Rift的Windows 10版）
* 进入下界时不再出现“生成世界中”的界面了。

# 修复

# 你知道吗
* 在[MINECON 2016](MINECON 2016.md)大会上，此次更新计划在2016年10月12日全平台发布，但临近发布日期却出现了一个致命漏洞，导致发布被推迟，并且iOS版因审核流程在其余平台发布4天后才正式发布。
