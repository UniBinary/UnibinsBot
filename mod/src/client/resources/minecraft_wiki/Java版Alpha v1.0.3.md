# Java版Alpha v1.0.3

*页面ID: 32484* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.3**是的一次更新，发布于2010年7月7日<ref></ref>，加入了洞穴音效和生物音效。

# 新内容
# = 游戏内容 =
* *[音效](音效.md)**
* 加入了[洞穴音效](洞穴音效.md)。
* 为[僵尸](僵尸.md)、[蜘蛛](蜘蛛.md)、[苦力怕](苦力怕.md)和[骷髅](骷髅.md)加入了单独的音效。
* * 在此之前，它们受伤会发出玩家受伤时的声音。

# 更改
# = 生物 =
* *常规**
* 现在寻路系统在山丘地形也能工作了。
* * 蜘蛛除外。
* 生物的行为变得更自然了。它们会更频繁地停下脚步，然后环顾四周。</onlyinclude>
