# 携带版0.9.0.b3

*页面ID: 31489* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.9.0 alpha build 3**是[v0.9.0 alpha](携带版0.9.0.md)的第3个测试版，发布于2014年6月11日，修复了一些漏洞。

# 更改
# = 方块 =
* *[睡莲](睡莲.md)**
* [睡莲](睡莲.md)在[物品栏](物品栏.md)中更亮了。

* *[花](花.md)**
* 为[花](花.md)加入染料合成配方。

# = 生物 =
* *[绵羊](绵羊.md)**
* [绵羊](绵羊.md)现在也吃高草丛。

# = 世界生成 =
* *[村庄](村庄.md)**
* 村庄建筑不再形成“摩天大楼”。

# = 常规 =
* *性能**
* 优化了使用低渲染距离时的体验。

# 修复
* *修复了13个漏洞**
* 僵尸不会主动攻击玩家。
* 生成熔岩时游戏崩溃。
* 与熔岩有关的照明问题。
* 与洞穴交叉生成的水源方块会在悬空而不会流下。
* 蜘蛛在被玩家攻击后立即反击。
* 金合欢木和深色橡木可以互相合成为对应的木板。
* 无法通过点击门的顶部来开/关门。
* 在Y=127处放置方块时游戏崩溃。
* 末影人没有音效。
* 绿宝石块被归入“装饰”一栏中。
* 平滑石台阶没有使用正确的石头类型。
* 顶层雪在下方方块被破坏时不会被一同破坏。
* 花岗岩、闪长岩和安山岩无法正确掉落。</onlyinclude>
