# Java版1.21.5-pre3

*页面ID: 147616* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21.5-pre3**是[Java版1.21.5](Java版1.21.5.md)的第3个，也是最后一个预发布版，发布于2025年3月18日<ref></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[牛](牛.md)**
* 更改了寒带牛模型，现在左侧角不再使用右侧角的镜像纹理。

* *[玩家](玩家.md)**
* 存档崩溃报告中，现在还可能包含玩家的UUID、坐标、游戏模式和权限等级。
