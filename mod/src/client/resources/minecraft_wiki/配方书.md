# 配方书

*页面ID: 29085* | *来源: Minecraft Wiki*

</ref>|Maria Lemón Mojang avatar.png}}

* *配方书（Recipe book）**是[Minecraft](Minecraft.md)中指导玩家进行[合成](合成.md)、[烧炼](烧炼.md)或制作[旗帜图案](旗帜图案.md)的机制。

# 界面
# = Java版 =
配方书会在[物品栏](物品栏.md)、[工作台](工作台.md)、[熔炉](熔炉.md)、[高炉](高炉.md)和[烟熏炉](烟熏炉.md)的GUI里显示。按下有[知识之书](知识之书.md)图标的按钮即可打开配方书。

配方会在不同的标签栏里展示：

; 物品栏及工作台
*  - 顶部第一个标签栏包含所有已解锁的配方。
*  - 第二个标签栏包含工具、武器和盔甲。
*  - 第三个标签栏包含建筑方块。
*  - 第四个标签栏包含[食物](食物.md)和杂项。
*  - 第五个标签栏包含[红石](红石.md)元件。

; 熔炉
*  - 顶部第一个标签栏包含所有已解锁的配方。
*  - 第二个标签栏包含食物。
*  - 第三个标签栏包含建筑方块和装饰性方块。
*  - 第四个标签栏包含绝大多数[矿石](矿石.md)和杂项。

; 高炉
*  - 顶部第一个标签栏包含所有已解锁的配方。
*  - 第二个标签栏包含[红石矿石](红石矿石.md)。<ref></ref>
*  - 第三个标签栏包含[粗金属](粗金属.md)、矿石和金属装备。

; 烟熏炉
*  - 顶部第一个标签栏包含所有已解锁的配方。
*  - 第二个标签栏包含食物。

[thumb|right|350px|通过选取物品来展示所有合成配方](File:RecipeBookRightClick.png.md)

按下配方书里的物品会在网格里显示它的配方。如果原材料足够的话，就可以进行合成或烧炼操作，否则缺失的原材料会标红。若存在几种合成方法（例如使用不同颜色的[羊毛](羊毛.md)来合成[旗帜](旗帜.md)），每次点击同一个物品都会显示相同配方的不同合成方法。右键点击物品会显示其所有合成方法。

长按然后右键点击一个物品会将放入网格里。

右上角的按钮用于切换“”和“”两种模式，后者只会显示目前玩家因拥有足够的原材料而可以进行合成或烧炼的配方。上方的搜索栏可以用于搜索配方。

[营火](营火.md)的烧炼配方和[切石机](切石机.md)配方是存在的，但不能通过配方书查看。

# = 基岩版 =
玩家处于[生存模式](生存模式.md)和[冒险模式](冒险模式.md)时，配方书会在打开[物品栏](物品栏.md)和使用[工作台](工作台.md)时显示，可以通过右上方（）或左侧（）的按钮切换显示或关闭。

玩家处于[创造模式](创造模式.md)时，配方书会被[创造模式物品栏](创造模式物品栏#基岩版.md)代替。

使用时，配方书显示在物品栏或工作台[GUI](GUI.md)的左侧。可以点击或按手柄左右扳机键切换右上方的[35px|class=pixel-image](File:BE Recipe Book and Inventory icon.png.md)和[20px|class=pixel-image](File:BE Inventory icon.png.md)来开启和关闭。

使用时，配方书显示在屏幕的左半部分，查看时会替换玩家的物品栏界面。

配方会在不同的标签栏里展示，这些标签栏与[创造分类](创造模式物品栏#基岩版.md)相同：
* “[px|class=pixel-image](File:BE icon recipe construction.png.md)建筑”标签栏，包含建筑材料。
* “[20px|class=pixel-image](File:BE icon recipe equipment.png.md)装备”标签栏，包含战斗用品、部分工具和熟食。
* “[20px|class=pixel-image](File:BE icon recipe item.png.md)物品”标签栏，包含功能方块、交通工具、[红石元件](红石元件.md)和原材料。
* “[20px|class=pixel-image](File:BE icon recipe nature.png.md)自然”标签栏，包含自然方块、[农作物](农作物.md)、[染料](染料.md)和生食。
* 另有“[20px|class=pixel-image](File:BE icon recipe all.png.md)全部”标签栏用于搜索配方和显示所有已解锁的配方。使用经典UI时显示在最右侧。使用携带版UI时显示在左上方。

配方书中会显示玩家已解锁的配方中，所有当前可合成的配方，以及部分缺失原材料的配方。点击一个配方会预览该配方，如果物品栏中有对应的物品则会放入其中。

* 使用键盘和鼠标或手柄时，对一个配方按左键或“”键会合成一个该物品，并放入物品栏中。在按住时对一个配方按左鍵，或按“”键会合成最多一组该物品（向下取整），并放入物品栏。不可堆叠的物品只会合成一个。
* * 使用手柄时，在工作台界面，将光标移至一个配方上即可预览该配方。

右上角的开关用于切换显示哪些缺失原材料的配方。关闭时会显示当前标签栏中所有已解锁的配方。开启时，只有玩家物品栏中有至少一件物品能用于合成该配方时才会显示该配方。

# 获取
新配方解锁时出现的弹窗}}

当玩家符合某些标准时（例如收集材料、进入水体、具有一定数量的填充好的物品栏槽位等），配方会解锁。使用一个未解锁的合成配方，或是一本包含指定配方的[知识之书](知识之书.md)也会解锁。游戏规则的值为<code>true</code>时，玩家无法使用未解锁的配方。

配方能够通过命令给予或剥夺。

# 你知道吗
* 如果玩家在配方书里搜索“**excitedze**”，游戏语言会被切换成海盗语。<ref></ref>
* * ExcitedZE是[Maria Lemón](Maria Lemón.md)的Minecraft用户名，她的Mojang头像是一个海盗。
* 解锁火把的合成配方需要获得石镐，即使合成火把所需的煤炭只需木镐即可挖掘。
