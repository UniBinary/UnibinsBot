* *青蛙（Frog）**是一种生成于[沼泽](沼泽.md)和[红树林沼泽](红树林沼泽.md)的[友好生物](友好生物.md)。

# 生成
# = 自然生成 =
溫帶青蛙自然生成于[沼泽](沼泽.md)生物群系，熱帶青蛙自然生成于[红树林沼泽](红树林沼泽.md)生物群系。

青蛙生成无亮度要求，空间检测范围为2×2×2。

# = 蝌蚪 =
[蝌蚪](蝌蚪.md)会在生成20分钟后成长为青蛙，这是生存模式中寒帶青蛙唯一的生成途径。给其喂食[黏液球](黏液球.md)可加速成长，每次缩短10%的剩余成长时间。

# = 肤色 =
青蛙有寒帶、熱帶、溫帶3种變種，分別為绿色、白色、橙色，青蛙的變種取决于其生成时（包括蝌蚪成长为青蛙）所处的生物群系。

游戏通过判断[标签](Java版标签.md)以确定生成的青蛙类型，标签<code>#spawns_warm_variant_frogs</code>会使生物群系生成熱帶青蛙，<code>#spawns_cold_variant_frogs</code>会生成寒帶青蛙，其余则是溫帶青蛙。

# 掉落物
青蛙被[玩家](玩家.md)或驯服的[狼](狼.md)杀死时会掉落。

# 行为
[thumb|青蛙捕食小型岩浆怪后掉落蛙明灯](File:WithOurPowersCombined.gif.md)
[thumb|三种青蛙与其对应的蛙明灯](File:Three types of frog and froglight.png.md)
青蛙在陆地上会漫无目的地缓慢游荡、四处跳跃，在水中则会游泳。在水中，青蛙的移动速度要快得多，且通常会向上游动并停留在水面上。它们的四肢脱离地面时会微微张开。它们还时常鼓动鸣囊。

青蛙最高可以跳8格高。与[山羊](山羊.md)相似，青蛙在摔落时受到的伤害相较正常水平少。青蛙会倾向于跳上[大型垂滴叶](大型垂滴叶.md)和[睡莲](睡莲.md)。

青蛙可以走上1格高的方块而无需跳跃。

青蛙可以被[拴绳](拴绳.md)拴住。

青蛙不会溺水。

# = 捕食 =
青蛙会捕食[小型史莱姆](史莱姆.md)。它们发现目标时会提高移动速度，伸出舌头迅速将其吸入口中，并掉落1个[黏液球](黏液球.md)。

青蛙也会以相同的方式捕食[小型岩浆怪](岩浆怪.md)。寒帶、溫帶、熱帶的青蛙吞食岩浆怪后分别会掉落1个青翠、赭黄和珠光变种的[蛙明灯](蛙明灯.md)。

青蛙捕食时会对猎物造成的基础攻击伤害直到其死亡，猎物因此而死亡时没有死亡动画。

被青蛙吞食的实体会瞬间消失，而没有死亡动画。

# = 繁殖 =

青蛙会跟随/手持[黏液球](黏液球.md)的玩家。

给两只青蛙喂食黏液球会使其[繁殖](繁殖.md)，掉落。繁殖/后才能再次繁殖。其中一只青蛙会搜寻上方有空气的[水源](水源.md)，并在其上方产下[青蛙卵](青蛙卵.md)。

# 你知道吗
* 熱帶青蛙的原型为现实中的非洲[大灰攀蛙](wikipedia:grey foam-nest tree frog.md)，<ref></ref>溫帶青蛙的原型为现实中的。<ref></ref>
* 青蛙最初被设计为吃掉萤火虫来产生[蛙明灯](蛙明灯.md)，但在开发者发现一些种类的萤火虫在现实生活中对一些种类的青蛙有毒后，这项计划就被取消了。<ref></ref>
* 青蛙和[美西螈](美西螈.md)都是两栖动物，但是青蛙离开[水](水.md)后不会因为脱水而受到伤害并死亡。
* 可以通过修改让青蛙主动攻击大部分[生物](生物.md)，包括[玩家](玩家.md)和其他青蛙。对于[盔甲架](盔甲架.md)、[末影龙](末影龙.md)，青蛙会不断尝试吞食它，但无法对其造成伤害也无法吞食。
