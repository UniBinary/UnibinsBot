* *牡丹（Peony）**是一种[大型花](大型花.md)。

# 生成

# = 自然生成 =
牡丹会在[森林](森林.md)、[桦木森林](桦木森林.md)、[原始桦木森林](原始桦木森林.md)、[黑森林](黑森林.md)和[繁花森林](繁花森林.md)生物群系自然生成。

# 获取
# = 骨粉 =
对着牡丹[骨粉](骨粉.md)会掉落1株新的牡丹。

# 破坏
牡丹被挖掘时会立刻被破坏。

牡丹被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 堆肥 =
将牡丹放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。

# 你知道吗
* 在现实中，牡丹（Peony）泛指（*Paeonia*）的任何开花植物。
* [芍药](芍药.md)（Paeonias）是最初计划加入的一种[小型花](小型花.md)，最终被牡丹所取代。
* * 同时在文件中，牡丹又被称为“**Paeonia**”。
* [Jeb](Jeb.md)曾提及牡丹是他婚礼上使用的花。<ref>http://instagram.com/p/dE8ljlJMLb/</ref>
