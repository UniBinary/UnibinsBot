# 基岩版1.11.0.4

*页面ID: 41262* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.11.0.4**是[1.11.0](基岩版1.11.0.md)的第3个测试版，发布于2019年3月7日<ref></ref>，更新了[交易](交易.md)系统，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[聊天](聊天.md)**
* 当玩家进入世界时会显示一条“Press T，返回，or Gamepad 按钮8 to open chat”的信息。

* *[交易](交易.md)**
* 为每种[村民](村民.md)类型更新了交易系统。
* * 加入了经验栏，会向玩家展示村民的等级以及可用的交易数量。
* 当玩家拥有状态效果时在与村民交易时可以获得折扣。

* *[袭击](袭击.md)**
* [掠夺者](掠夺者.md)和[卫道士](卫道士.md)现在在袭击中会掉落战利品。
* 当袭击开始时，当前维度下的所有玩家都会听见一个来源于袭击生成点的号角声。

# = 常规 =
* *皮肤包**
* 当从皮肤包中选择皮肤时，所选的皮肤将在使用相同账户的设备之间都可用。

* *[设置](设置.md)**
* 在设置中加入选项“”（Accessibility）。
* * 可以启用文本转语音进行聊天。
* * 用户界面屏幕阅读器可以读出控件的名称及其当前状态。

# 更改
# = 方块 =
* *[制图台](制图台.md)**
* 现在能用玻璃板来锁定地图。
* * 锁定的地图不会更新，未探索的区域会保持未探索。
* * 锁定的地图不能扩展，但仍然可以被复制。

* *[脚手架](脚手架.md)**
* 将脚手架从支持处伸出的数量从4增加至6。

# = 生物 =
* *[流浪商人](流浪商人.md)**
* 不再位于[实验性玩法](实验性玩法.md)。
* 不再会补充交易，当交易用完后会消失。

* *[僵尸村民](僵尸村民.md)**
* 当不属于模板世界的一部分时，僵尸村民现在会更新到新的僵尸村民。

* *[村民](村民.md)**
* 村民将在到达工作点后重新供应交易。
* 村民现在在袭击时躲在房子里。
* 村民在袭击中不再可以交易，并且会流出“汗水”粒子。
* 改进寻路机制。
* 更改了[图书管理员](图书管理员.md)的叠层纹理。

* *[铁傀儡](铁傀儡.md)**
* 改进寻路机制。

# = 世界生成 =
* *[村庄](村庄.md)**
* 改进了村庄的生成机制。
* 增加了工作点的半径，这样村民可以更频繁地到达工作点，也更少会愤怒。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
* 现在可以通过击败[袭击](袭击.md)获得，持续3个游戏日。
* 加入了用途，与村民交易时会获得折扣。

* *选项**
* 在游戏指南中加入村庄与掠夺的提示。

* *[袭击](袭击.md)**
* 更新了袭击的Boss栏。

# 修复
* *修复了40个漏洞**<br>
* *崩溃**
* 在可以看见末影龙的情况下，重新进入世界使得游戏崩溃。
* 打开针叶林村庄制箭小屋里的箱子时游戏崩溃。
* 修复了游戏进行时的崩溃现象。
* 安卓设备里暂停游戏时出现黑屏现象。
* 打开含有自定义村庄的模板世界导致游戏崩溃。
* 在告示牌上面输入无效字符导致游戏崩溃。（）

* *常规**
* 在不同的驱动器里安装Windows 10版游戏会提示“空间不足”的信息，即使该驱动器有足够多的空间进行安装。（）

* *游戏内容**
* 提升了离开村庄时的袭击进度条的可视距离。
* 袭击胜利后，现在会给予3个游戏日的村庄英雄效果（而不是此前的1个）。
* 袭击发生时，钟现在会随机响起。
* 玩家睡觉时会悬空在床上。（）
* 不祥之兆效果现在会持续5个游戏日，除非玩家饮用牛奶或者死亡。

* *世界生成**
* 睡莲无法生成。（）
* 部分村庄建筑里的箱子不会生成战利品。
* 海平面层的方块会移除村庄部分建筑的地基。
* 床现在会更普遍地生成在村庄里。

* *生物**
* 来自1.10版的村庄现在可以正确转换为新版村民。
* 村民不再困在堆肥桶里。
* 村民现在会随手关门。（）
* 村民不再过度工作。
* 幼年村民不再沉迷于嬉戏打闹。
* 村民不再因为钟声响起而打断与玩家的交易。
* 水下的生物不再生成在陆地上。（）
* 调整了流浪商人的行为反应，因此它们不再容易遭受攻击。
* 袭击生物在寻找村庄期间现在会优先攻击村民或玩家。
* 袭击事件内的唤魔者现在会生成正确数量。
* 图书管理员村民的肩膀不再有白色条纹。
* 骷髅在射击时现在会朝向玩家。
* 猫在床上睡觉时现在会躺下。（）

* *方块**
* 堆肥桶看起来太亮。（）
* 灯笼现在可以放在楼梯下方。
* 砂轮的破坏粒子不正确。
* 村民工作时，现在会播放正确的工作音效。
* 使用高分辨率纹理时，营火的外观出现错误。
* 使用+选取方块键时，复制后的床不再出现多余的工具提示信息。（）

* *物品**
* 无法使用合成方格来复制旗帜。（）
* 旗帜现在可以被新加入的玩家看见，且在物品栏内查看旗帜不再导致游戏崩溃。（）

* *用户界面**
* 在铁砧的UI里，移除输入槽里的物品不会导致输出槽被更新。（）
* 在状态效果界面里，不祥之兆现在会显示持续时间。</onlyinclude>
