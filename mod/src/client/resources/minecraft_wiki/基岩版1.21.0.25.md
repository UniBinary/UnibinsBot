# 基岩版1.21.0.25

*页面ID: 119835* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.0.25**（ChromeOS/Android）、**Preview 1.21.0.25**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.0](基岩版1.21.0.md)的第6个测试版，发布于2024年5月8日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[石化橡木台阶](石化橡木台阶.md)**
* ID由与普通橡木台阶相同的更改为。
* * 这意味着石化橡木台阶再次能通过命令放置或获取。

# = 常规 =
* *[服务器列表](服务器列表.md)**
* 在新的服务器列表UI中加入了今日消息（MOTD），会在[精选服务器](精选服务器.md)的详情中显示。

# 修复
* *性能与稳定性**
* 修复了部分纹理包无法加载到世界中的问题。（）

* *试炼刷怪笼**
* 现在被进入不祥状态的试炼刷怪笼移除的生物会掉落之前从地上捡起的物品。
* 现在配置为幼年僵尸的试炼刷怪笼会正确生成幼年僵尸。

* *石化橡木台阶**
* 的橡木外观变种（值为）现在被扁平化为新的方块。（）
* * 该修复不会将之前测试版本中已被转换的台阶还原为石化橡木台阶。

* *物品**
* 修复了在部分市场世界中放置画时可能导致纹理丢失的问题。现在放置画时不会选择版本高于当前会话版本的画作。</onlyinclude>
