# 基岩版1.21.51

*页面ID: 138027* | *来源: Minecraft Wiki*

* *1.21.51**是的一次热修复更新，在ChromeOS/Android平台上发布于2024年12月9日，在Fire和iOS/iPadOS平台上发布于2024年12月10日，在除Nintendo Switch外的其他平台上发布于2024年12月11日<ref></ref>，在Nintendo Switch平台上发布于2024年12月16日，更新了游玩屏幕，并修复了一些漏洞。此版本与[1.21.50](基岩版1.21.50.md)相兼容。

此版本于2024年12月11日重新上传至Google Play商店，以修复处理器架构为ARM64的Android设备启用了旧版本的HAL着色器的问题。

# 更改
# = 世界生成 =
* *[苍白之园](苍白之园.md)**
* 现在[嘎枝之心](嘎枝之心.md)会在自然生成的[苍白橡树](苍白橡树.md)中更频繁地生成。

# = 常规 =
* *游玩屏幕**
* 更新了游玩屏幕，目前仅在部分设备上可用。
* * 世界选项卡：查看并进入已保存的本地和局域网世界。
* * Realms选项卡：进入已拥有或已加入的Realms服务器。
* * 服务器选项卡：进入[精选服务器](精选服务器.md)，添加或进入外部服务器。
* * 从模板创建：使用已拥有的市场模板创建世界并对其进行评价，发现Minecraft创作者制作的内容。
* * 好友：联系Minecraft好友（位于屏幕的右上角）。

# 修复
* *常规**
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了无法正确解析某些有序配方的问题。
* 修复了旧的数据驱动方块不会应用来自材质实例组件的渲染层的问题。

* *世界生成**
* 现在嘎枝之心会在自然生成的苍白橡树中更频繁地生成。（）
