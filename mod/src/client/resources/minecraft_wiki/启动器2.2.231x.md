# 启动器2.2.231x

*页面ID: 80328* | *来源: Minecraft Wiki*

* *2.2.2311**（）、**2.2.2310**（）或**2.2.2313**（）是一次[启动器](启动器.md)更新，发布于2021年3月10日。

# 新内容
* 添加了关闭启动器硬件加速的选项。关闭硬件加速可以解决混合显卡与分流相关的问题。

# 修复
* 修复了Minecraft Dungeons的“配置”按钮可能无响应的问题。
*  - 随着GTK 4.0的发布，GTK 2已不再被支持。
*  - “开始游戏”界面的游戏徽标动画出现卡顿。
*  - 使用专用GPU时，启动器窗口是空白或黑色的。
*  - 启动器不使用<code>HOME</code>环境变量。
*  - 在自定义配置中使用一个Mod实例会导致启动器硬崩溃。
*  - Linux版启动器出现崩溃。
*  - .minecraft文件夹不再可是符号链接。
*  - Ubuntu上的Linux版启动器无法启动。
