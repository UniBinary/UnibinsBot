# 蘑菇

*页面ID: 6553* | *来源: Minecraft Wiki*

* *蘑菇（Mushroom）**是在黑暗区域生长和传播的菌类方块。

# 生成
蘑菇能够生成蘑菇（见）。

# = 自然生成 =
蘑菇可以自然生成在：
* [主世界](主世界.md)亮度低于13的区域。
* * 若亮度条件满足，则每个[区块](区块.md)有概率生成红色蘑菇、概率生成棕色蘑菇。
* [沼泽](沼泽.md)、[原始针叶林](原始针叶林.md)、[蘑菇岛](蘑菇岛.md)生物群系。
* [下界](下界.md)的任何区域。
* [林地府邸](林地府邸.md)的“[蘑菇农场房间](林地府邸/结构/农场#蘑菇农场.md)”里。
* [沼泽小屋](沼泽小屋.md)的花盆中（红色蘑菇）。
* 倒下的[橡树](橡树.md)、[云杉](云杉.md)、[白桦](白桦.md)和[丛林树](丛林树.md)的[原木](原木.md)上方。
* * 生成的数量为0-2。
* [试炼密室](试炼密室.md)中生成[沼骸](沼骸.md)和[洞穴蜘蛛](洞穴蜘蛛.md)的[试炼刷怪笼](试炼刷怪笼.md)旁（红色蘑菇）。

# 破坏
蘑菇被挖掘时会立刻被破坏。

蘑菇被破坏后会掉落自身。

# 用途
蘑菇可种植在[亮度](亮度.md)等级低于13且不直接暴露在天空下的方块上，也可无视亮度种植在[菌丝体](菌丝体.md)、[灰化土](灰化土.md)或[菌岩](菌岩.md)上。

蘑菇在以下条件下会掉落为物品：
* 下面的方块被移动或摧毁；
* 被[流体](流体.md)冲刷；
* 种植在亮度等级高于12的地方，未种植在[菌丝体](菌丝体.md)、[灰化土](灰化土.md)或[菌岩](菌岩.md)上且其相邻[方块](方块.md)发生更新。

# = 巨型蘑菇 =
蘑菇满足以下条件时，对其[骨粉](骨粉.md)有概率使之成长为对应的[巨型蘑菇](巨型蘑菇.md)：

* 种植在适当的方块（[泥土](泥土.md)、[砂土](砂土.md)、[草方块](草方块.md)）上且亮度等级低于13，或在任意亮度等级下种植在[菌丝体](菌丝体.md)、[灰化土](灰化土.md)或[菌岩](菌岩.md)上。
* 生长空间充足（长宽各7格，高6-8格）。
* 蘑菇不[含雪](含雪.md)。

# = 传播 =
蘑菇每次接收[随机刻](刻#随机刻.md)时，会有4%的概率**尝试**传播。此时，系统会选中一个与该蘑菇相邻的方块，若为可传播方块，则该处会长出蘑菇，否则此次尝试失败。传播位置的选择并非完全随机，其算法分为多个步骤，且与该蘑菇周围的可传播方块有关。

传播算法的部分关键机制如下：
* 蘑菇最多可传播到5格远的位置（直线沿任意坐标轴方向），但其间的方块必须都为可传播方块。而且传播5格远的概率极低，绝大多数情况下蘑菇的传播距离不会超过2格，且只传播1格远的概率最高。
* 可传播位置与原蘑菇位置的y坐标差距越小，该位置就越有可能传播蘑菇。
* * 这让蘑菇难以传播到不同高度。

可传播方块的判定条件如下：
* 该方块为空气。
* 该方块下方的方块为[完全固体渲染方块](判定箱#遮挡形状.md)。
* 该方块的亮度等级不高于12，或者其下方的方块为[菌丝体](菌丝体.md)、[灰化土](灰化土.md)或[菌岩](菌岩.md)。

另外，蘑菇在周围9×3×9的范围内存在5个及以上的同种蘑菇时不会尝试传播。<ref name="使用BUD开关收割机对在不同亮度等级的蘑菇生长的全自动测试">https://www.youtube.com/watch?feature=player_detailpage&v=ALkf-b7MbBI&t=864s</ref><ref name="Large scale automated test with additional info"></ref>

# = 光源 =
棕色蘑菇会发出[亮度](亮度.md)等级为1的光，但种植在[花盆](花盆.md)内的棕色蘑菇不会发光。

# = 装饰 =
棕色和红色蘑菇都可以种植在[花盆](花盆.md)里。

# = 堆肥 =
将蘑菇放入[堆肥桶](堆肥桶.md)里有65%概率增加1个堆肥层。

# = 喂食 =
[僵尸马](僵尸马.md)会跟随/内手持红色蘑菇的玩家，给僵尸马喂食红色蘑菇可以增加僵尸马的好感度或治疗僵尸马。

# 你知道吗
* 红色蘑菇与[毒蝇伞](wzh:毒蝇伞.md)外形相近。食用未经煮熟毒性未减的毒蝇伞会导致精神错乱和迷幻状态甚至死亡。与此类似的是，在Minecraft的[生存测试](生存测试.md)中食用红色蘑菇会对玩家造成伤害。
