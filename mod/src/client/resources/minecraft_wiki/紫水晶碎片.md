# 紫水晶碎片

*页面ID: 71730* | *来源: Minecraft Wiki*

* *紫水晶碎片（Amethyst Shard）**是从[紫水晶簇](紫水晶簇.md)中掉落的[矿物](矿物.md)。

# 获取
# = 紫水晶簇 =
没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[紫水晶簇](紫水晶簇.md)被破坏后会掉落4个紫水晶碎片，没有使用镐时则是2个。挖掘工具是镐且附有[时运](时运.md)魔咒会增加紫水晶碎片的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

# 用途
# = 合成材料 =

# = 悦灵 =
当[悦灵](悦灵.md)在跳舞时获得1个紫水晶碎片，其所在的位置会生成另一只悦灵，并发出爱心粒子和紫水晶音效。

# 你知道吗
