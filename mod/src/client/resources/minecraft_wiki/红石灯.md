* *红石灯（Redstone Lamp）**是一种在被红石信号激活后能发[光](光.md)的[方块](方块.md)。

# 生成
# = 自然生成 =
[远古城市](远古城市.md)的中心会生成红石灯柱，可由其上方的[幽匿感测体](幽匿感测体.md)激活。

远古城市中心的地下室内也会生成红石灯。

# 破坏
没有工具可以加速对红石灯的挖掘。

红石灯被破坏后会掉落自身。

# 用途
红石灯是[机械元件](红石元件#机械元件.md)，可被下列形式激活：
* 毗邻的开启的**[电源](红石元件#电源.md)**（例外：[红石火把](红石火把.md)不会激活其所附着的红石灯，[侦测器](侦测器.md)只会激活指向的红石灯）。
* 毗邻的**[充能方块](红石电路/充能与激活.md)**。
* 毗邻的指向红石灯且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)（包括红石灯上方的红石粉）；毗邻但未指向红石灯的红石粉不会激活红石灯。

在同一红石刻内，电容器更新阶段前存在，但在电容器更新阶段被取消的信号无法激活红石灯。

红石灯收到红石信号会立刻被点亮。失去红石信号供给后需要才能熄灭。
* 红石灯失去信号后会创建一个4游戏刻后的[计划刻](计划刻.md)，执行计划刻时若无红石信号则熄灭。
* 红石灯失去信号后会创建一个4游戏刻后的计划刻，若接收到新信号则会覆盖原有计划刻。在计划刻执行时若无红石信号则熄灭。<!--测试流程:堆积大量计划刻以延后红石灯熄灭,同时激活并取消激活两个红石灯A和B,随后在红石灯尚未熄灭时快速激活并取消激活红石灯A,然后等待红石灯熄灭。可观察到红石灯B先熄灭,红石灯A后熄灭,推测是红石灯A原先的计划刻被以某种方式覆盖,因此熄灭取决于最后一次下降沿产生的计划刻而非所有计划刻-->

红石灯搭配侦测器可构建极简的“脉冲倍频器”，将一个脉冲转变为两个脉冲（但有冷却）。

红石灯是[红石导体](红石导体.md)，因此可以充能红石灯，被充能的红石灯也能作为充能方块激活毗邻的其他元件。

# = 光源 =
红石灯是一种可控光源。

点亮的红石灯会发出亮度等级为15的光。
