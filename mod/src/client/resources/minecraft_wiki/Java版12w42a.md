# Java版12w42a

*页面ID: 33292* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w42a**是[Java版1.4.2](Java版1.4.2.md)的第14个快照，发布于2012年10月17日<ref></ref>。

# 更改
# = 方块 =
* *[铁砧](铁砧.md)**
* 新的合成配方，现在只需要31块铁锭而不是55个。
* 修改了纹理。
* 玩家可以使用原材料[修复](修复.md)相应的[工具](工具.md)和[盔甲](盔甲.md)（锄除外）。要想把一个几乎要损毁的工具恢复至完好如初将消耗4个制作材料（木板/圆石/铁/钻石）。
* 减少了所需的[经验值](经验值.md)。

* *[红石中继器](红石中继器.md)**
* 更改了纹理。
* 当中继器左右的一面被另一个中继器直接充能，它将锁住另一个中继器的当前状态，直至充能的中继器被关闭
* * 如果中继器在开启时被锁定，它将保持开启
* * 如果中继器在关闭时被锁定，它将不能传输信号
* 当锁定时，中继器的第二个火把将消失并有一个有类似[基岩](基岩.md)纹理的横条会出现。

# = 生物 =
* *[蝙蝠](蝙蝠.md)**
* 蝙蝠不再能踩踏[耕地](耕地.md)，触发[压力板](压力板.md)或[绊线](绊线.md)。

# = 常规 =
* *[语言](语言.md)文件**
* 升级了[语言](语言.md)文件。

* *[服务器](服务器.md)**
* 服务器IP现在可以被单独隐藏。

# 修复
* *修复了9个漏洞**
* 修复了严重损坏的铁砧从至少6格高处坠落时会变成一个有问题的实体，且在地图重载之前不能被清除。
* 再次修复了玩家直接向下挖方块会使自己陷入方块中的问题。
* 修复了关闭了PvP的服务器中，玩家可以使用附有火焰附加的剑使其他玩家着火的问题。
* 修复了在特定情况下从较低的高处摔落受到伤害的问题。
* 修复了铁砧掉落到末地水晶上导致崩溃的问题。
* 修复了使用键显示物品耐久并同时将鼠标移到一张非空白地图上时有时会导致游戏崩溃的问题。
* 修复了在打开了铁砧界面的同时最大化游戏导致游戏崩溃的问题。
* 修复了发射器尝试将水或熔岩发射进固体方块时导致堆栈溢出的问题。
* 修复了沼泽小屋中生成的工作台和炼药锅会生成在房顶的问题。</onlyinclude>
