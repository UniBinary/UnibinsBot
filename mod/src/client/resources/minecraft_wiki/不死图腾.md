# 不死图腾

*页面ID: 24978* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *不死图腾（Totem of Undying）**是一种可以使手持者受到致命伤害时免于死亡的物品。

# 获取
# = 唤魔者 =

# 用途
生物在受到致命[伤害](伤害.md)时，若主手或副手持有不死图腾，且伤害不是或[虚空](虚空.md)造成的伤害，不死图腾可以阻止该生物死亡。若玩家将其放入物品栏或快捷栏内而不选中，不死图腾将不会生效。

不死图腾生效时，会发出响亮的声音并产生大量[黄绿色粒子](粒子#totem_of_undying.md)，持有者的生命值会变为，原有的[状态效果](状态效果.md)会被清除，并获得40秒[抗火](抗火.md)、45秒[生命恢复](生命恢复.md)II、5秒[伤害吸收](伤害吸收.md)II。若该生物是玩家，不死图腾会在其视野中掠过，与玩家受到[远古守卫者](远古守卫者.md)的诅咒、时显示的动画相似。

每个不死图腾只能使用一次，生效后即消失。

生物持有不死图腾时，不能通过将其击杀来使不死图腾掉落。玩家可以通过投掷[食物](食物.md)换下[狐狸](狐狸.md)持有的不死图腾，通过投掷武器换下敌对生物持有的不死图腾。玩家也可以直接取走[悦灵](悦灵.md)手中的不死图腾。

# 你知道吗
* Minecraft官方系列视频中提及，玩家能从[袭击](袭击.md)中获取不死图腾而免于探索[林地府邸](林地府邸.md)是一个巨大的游戏设计缺陷。<ref></ref>
* 如果使用-{}-者受到[药箭](药箭.md)造成的致命伤害，则药箭所带有的[状态效果](状态效果.md)在不死图腾生效后仍会作用于该使用-{}-者；药箭伤害分为两部分，先结算药水的瞬间伤害（或瞬间治疗伤害亡灵生物）效果再结算箭的伤害，如果在第一段伤害时触发了不死图腾，则箭本身的伤害在不死图腾触发后仍作用于该使用-{}-者。
