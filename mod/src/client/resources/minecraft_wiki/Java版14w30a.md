# Java版14w30a

*页面ID: 32656* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w30a**是[Java版1.8](Java版1.8.md)的第38个快照，发布于2014年7月23日<ref></ref>，加入了旗帜、新的NBT标签和新的统计信息，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[旗帜](旗帜.md)**
* 一种装饰性方块，拥有16种底色。
* 使用6个对应[羊毛](羊毛.md)和[木棍](木棍.md)合成。
* 能够通过在[工作台](工作台.md)上用某种方式排列染料来为其添加大多数图案。
* * 可使用[苦力怕的头](苦力怕的头.md)、[凋灵骷髅头颅](凋灵骷髅头颅.md)、[红砖块](红砖块.md)和[滨菊](滨菊.md)分别添加4种特殊图案：苦力怕盾徽、头颅盾徽、砖纹和花朵盾徽。若添加特殊图案时没有放置染料则会添加上黑色的图案，若有则添加染料对应的颜色。
* * 图案可以层叠至6层。
* * 拥有超过16×400<sup>6</sup>（6.5536×10<sup>16</sup>）可能的图案组合。
* * 最上层的图案可以对装有水的[炼药锅](炼药锅.md)使用以去除。
* 可以用一个空白的拥有相同底色的旗帜来复制。
* 可以堆叠至16个。
* 可以放置在方块的侧面和顶面上。

# = 命令格式 =
* *[NBT标签](NBT标签.md)**
* 给予生物新的<code>Silent</code>标签。
* * 设置为可禁用由该实体产生的音效，例如空闲和伤害的音效。

# = 常规 =
* *[统计](统计.md)**
* <code>stat.talkedToVillager</code>
* * 检测玩家与[村民](村民.md)交谈的次数（打开交易GUI）。
* <code>stat.tradedWithVillager</code>
* * 检测玩家与村民交易的次数。

# 更改
# = 方块 =
* *[生物头颅](生物头颅.md)**
* 现在[苦力怕](苦力怕.md)、[骷髅](骷髅.md)、[凋灵骷髅](凋灵骷髅.md)和[僵尸](僵尸.md)在被闪电苦力怕杀死后会掉落对应的头颅。
* 戴在头上的头颅现在更大了，所以第二层的皮肤也不再显示了。
* 玩家和生物在物品栏中，由生物/玩家控制，现在显示实际的头部。

# = 命令格式 =
* ***
* 现在可以用召唤闪电。

# = 游戏内容 =
* *亮度**
* 完全修复了黑点存在的漏洞。
* 需要重新加载旧的世界让它们修复。<ref></ref>

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 现在可以显示当前正在显示多少区块，以及百分比视图、OpenGL版本、显示尺寸、供应商和GPU。
* “Vanilla”添加到版本号之后，指代[原版](教程:游戏术语.md)游戏，例如：“Minecraft 14w30b (14w30b/Vanilla)”
* * 若游戏被[模组化](加载器Mod.md)，则显示可能会不同。
* 工具按键现在会显示一个物品有多少NBT标签。
* 方块名称不再包含在名称旁边的括号内的方块状态数据（在屏幕右侧的方块名称和数据的视图中）。
* * 数据仍然显示在名称下面的单独行中。

* *[设置](设置.md)**
* 视频设置
* * 当使用64位Java时，最高渲染距离会上升到32个区块。
* ** 需要分配2GB的内存。
* * 移除了高级OpenGL（Advanced OpenGL）选项。
* 性能改进：
* * 重写区块排序。
* * 通过携带版的可见性选择代码进行移植，以避免呈现不可见的内容。
* * 多线程区块重建。
