* *绒球葱（Allium）**是一种[小型花](小型花.md)。

# 生成

# = 自然生成 =
绒球葱会在[繁花森林](繁花森林.md)和[草甸](草甸.md)生物群系自然生成。

绒球葱也会在[林地府邸](林地府邸.md)中生成。

# = 骨粉 =
在繁花森林和生物群系中对[草方块](草方块.md)[骨粉](骨粉.md)后，绒球葱有概率代替[矮草丛](矮草丛.md)生成。

对着不[含雪](含雪.md)的绒球葱使用骨粉会出现更多的绒球葱，而不会出现草丛。

# 获取
# = 交易 =

# = 林地府邸 =
[林地府邸](林地府邸.md)的[盆栽房](林地府邸#盆栽房.md)内总是会生成1个[箱子](箱子.md)，当中有8株绒球葱。

# 破坏
绒球葱被挖掘时会立刻被破坏。

绒球葱被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 谜之炖菜 =

使用绒球葱合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家3s的[抗火](抗火.md)效果。

# = 堆肥 =
将绒球葱放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
