# 高草丛

*页面ID: 171904* | *来源: Minecraft Wiki*

* *高草丛（Tall Grass）**是一种两格高的非固体植物方块。

# 生成
# = 自然生成 =
高草丛生成在[平原](平原.md)、[向日葵平原](向日葵平原.md)、[草甸](草甸.md)、[樱花树林](樱花树林.md)、[繁茂洞穴](繁茂洞穴.md)、[溶洞](溶洞.md)、[深暗之域](深暗之域.md)、[热带草原](热带草原.md)和[热带高原](热带高原.md)里，平均每个[区块](区块.md)中会生成约8.6棵高草丛。

高草丛也会生成在[繁茂洞穴](繁茂洞穴.md)的[苔藓块](苔藓块.md)和[苍白之园](苍白之园.md)的[苍白苔藓块](苍白苔藓块.md)上。

高草丛也会在[平原](平原.md)和[热带草原](热带草原.md)[村庄](村庄.md)中生成。

# = 骨粉 =
* *草方块**

对着一片上方为空气的[草方块](草方块.md)[骨粉](骨粉.md)会使其自身和附近7格内（[切比雪夫距离](切比雪夫距离.md)）随机选取的草方块上方生成高草丛。

* *矮草丛**

对矮草丛骨粉会使其生长为高草丛。

* *苔藓块**

对一个上方为空气的[苔藓块](苔藓块.md)骨粉分别有31.25%和6.25%的概率使其水平切比雪夫半径3格，垂直切比雪夫半径5格范围内已有或转化得到的苔藓块上生成高草丛。

* *苍白苔藓块**

对一个上方为空气的[苍白苔藓块](苍白苔藓块.md)骨粉分别有25%和10%的概率使其水平切比雪夫半径3格，垂直切比雪夫半径5格范围内已有或转化得到的苍白苔藓块上生成高草丛。

# 获取
高草丛被破坏后不会掉落其[方块物品](方块物品.md)，其唯一的获取方式是仅在世界生成时生成的热带草原[村庄](村庄.md)的[箱子战利品](箱子战利品.md)，这导致了高草丛是[不可再生资源](不可再生资源.md)。

# 破坏
高草丛被挖掘时会立刻被破坏。

没有被[剪刀](剪刀.md)挖掘破坏时，高草丛被破坏后有12.5%的概率会掉落1个[小麦种子](小麦种子.md)，挖掘工具的[时运](时运.md)魔咒每有1级，上限增加2。

被剪刀挖掘破坏时，高草丛被破坏后会掉落2个矮草丛。

# 用途
高草丛可以种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。

# = 堆肥 =
将高草丛放入堆肥桶里有50%的概率增加1个堆肥等级。
