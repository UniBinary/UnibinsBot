# 携带版0.7.2

*页面ID: 21258* | *来源: Minecraft Wiki*

* *v0.7.2 alpha**是[携带版](携带版.md)的一次次要更新，发布于2013年7月4日，添加了玩家列表和玩家昵称，修复了[v0.7.1 alpha](携带版Alpha 0.7.1.md)中的一些漏洞与崩溃。

# 新内容
# = 游戏内容 =
* 多人游戏的玩家名称
* 玩家列表
* 在世界选择屏幕按下“编辑”（Edit）后会显示[种子](种子（世界生成）.md)。

# 更改
# = 游戏内容 =
* [聊天](聊天.md)现在更易于使用了（支持Unicode字符）。
* * 输入[Emoji](wzh:Emoji.md)会导致游戏崩溃（）。
* 对[GUI](GUI.md)进行了轻微更改。
* 在Android平台，创造模式飞行时会有更多阻力。
* 为[僵尸猪人](僵尸猪人.md)加入了新的音效。
* 为在聊天中使用的Minecraft字体加入了符号。
* 减少了[睡觉](睡觉.md)的时间，以与同步。
* 现在多人服务器在“游戏”（Play）菜单顶部而非底部显示了。
