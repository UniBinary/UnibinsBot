* *小麦（Wheat）**是一种主要通过种植获取的[物品](物品.md)。

# 获取
# = 种植 =

当完全成熟的小麦植株被收获，它会掉落1个小麦和/[小麦种子](小麦种子.md)。

# = 箱子战利品 =

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)和[海底废墟](海底废墟.md)里的[可疑的方块](可疑的方块.md)有概率掉落小麦。

# = 合成 =

# = 狐狸 =
成年[狐狸](狐狸.md)自然生成时有4%的概率在嘴里叼着小麦，且其死亡时叼着的小麦总是会掉落。

# 用途
# = 繁殖 =
小麦能用来吸引和繁殖[牛](牛.md)、[绵羊](绵羊.md)、[哞菇](哞菇.md)和[山羊](山羊.md)，也可喂食给幼年个体以减少其10%的剩余成长时间。

[村民](村民.md)会收集在其范围内的小麦，并制作成面包，当它拥有三块面包时就会产生繁殖意愿。

# = 喂食 =
小麦能治疗[马](马.md)、[驴](驴.md)、[骡](骡.md)生命、提高3%驯服概率和加速20秒幼年马、幼年驴、幼年骡的成长速度。

小麦还能治疗[羊驼](羊驼.md)生命、提高3%驯服概率和加速或幼年羊驼的成长速度。
