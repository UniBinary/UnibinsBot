# 竹马赛克楼梯

*页面ID: 99232* | *来源: Minecraft Wiki*

* *竹马赛克楼梯（Bamboo Mosaic Stairs）**是[竹马赛克](竹马赛克.md)制作的[楼梯](楼梯.md)。

# 生成
竹马赛克楼梯不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘竹马赛克楼梯的合适工具是斧。

竹马赛克楼梯被破坏后会掉落自身。

# 用途

# = 燃料 =
竹马赛克楼梯可被用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个竹马赛克楼梯可烧炼1.5个物品。
