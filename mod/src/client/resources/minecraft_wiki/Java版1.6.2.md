* *1.6.2**是的一次次要更新，发布于2013年7月8日<ref name="blogpost_1.6.2"></ref>，主要修复了[Java版1.6.1](Java版1.6.1.md)中的漏洞。虽然它不是1.6的最终版本，却是1.7.2首个快照发布前的最后一个正式版。此版本不兼容1.6.1的服务端。

# 新内容
# = 生物 =
* *[僵尸](僵尸.md)和[僵尸猪人](僵尸猪人.md)**
* 幼年变种现在会自然生成，也有概率通过使用[刷怪蛋](刷怪蛋.md)生成。

# 更改
# = 生物 =
* *[马](马.md)**
* 现在能够记住驯服它的玩家。

* *[猪人](Java版已移除特性#猪人.md)**
* 移除了猪人的纹理。
