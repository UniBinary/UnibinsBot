* *大脑（Big Brain）**是一种用于储存[经验](经验.md)的方块。

# 生成
大脑不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘大脑的合适工具是斧。

大脑被破坏后会掉落自身和一个[知识之薯](知识之薯.md)。

# 用途

# = 获取知识之薯 =
大脑会吸收附近的[经验球](经验球.md)。被破坏时，其会掉落与其吸收经验值等同经验的[知识之薯](知识之薯.md)。吸收经验球后，如果其已吸收的经验值达到1000，每1000储存的经验值会掉落一个包含1000经验的知识之薯。
