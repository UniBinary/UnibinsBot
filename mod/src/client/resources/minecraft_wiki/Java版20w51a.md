# Java版20w51a

*页面ID: 73460* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w51a**是[Java版1.17](Java版1.17.md)的第5个快照，发布于2020年12月16日<ref></ref>，加入了[美西螈](美西螈.md)，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[美西螈桶](美西螈桶.md)**
* 通过对美西螈使用[水桶](水桶.md)获得。
* 按下键可放出美西螈。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了美西螈刷怪蛋。

# = 生物 =
* *[美西螈](美西螈.md)**
* 尚不可自然生成。
* 可用[水桶](水桶.md)捕捉。
* 对玩家表现被动。
* 可使用[热带鱼](热带鱼（物品）.md)或[热带鱼桶](热带鱼桶.md)繁殖。
* 受到伤害后有概率装死，并获得[生命恢复](生命恢复.md) I。
* 共有青色、金色、粉红色、棕色和蓝色5种变种。
* * 其中蓝色为稀有变种，只有的生成概率。
* 会攻击溺尸、守卫者、鱿鱼和鱼类生物。
* * 总是对鱿鱼和鱼类生物敌对，且仅当玩家手持热带鱼或热带鱼桶时可引诱美西螈攻击[守卫者](守卫者.md)和[溺尸](溺尸.md)。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了物品标签。
* * 包含[热带鱼（物品）](热带鱼（物品）.md)和[热带鱼桶](热带鱼桶.md)。
* * 此标签中的物品可以用于驯服美西螈。
* 加入了物品标签。
* * 包含物品标签。
* * 作为抛出实体，该标签中的物品将不会触发振动。
* 加入了实体类型标签。
* * 包含热带鱼、河豚、鲑鱼、鳕鱼及鱿鱼。
* * 美西螈始终与此标签中的实体敌对。
* 加入了实体类型标签。
* * 包含溺尸与守卫者。
* * 被热带鱼吸引的美西螈与此标签中的实体敌对。

# 更改
# = 方块 =
* *[幽匿感测体](幽匿感测体.md)**
* 不再检测开始进食的振动。
* 不再检测在[羊毛](羊毛.md)上行走的振动。
* 不再检测羊毛掉在地上的振动。
* 含水时不再发出振动。
* 更改了多项振动的振动频率。

# = 物品 =
* *[收纳袋](收纳袋.md)**
* 现在以[物品实体](物品实体.md)的形式被摧毁时，其内容物会被释放。
* 界面更改：
* * 当收纳袋未被填满时，将会显示部分空槽位，填满后会在最后的槽位显示一个“X”。
* * 第一槽位中的物品会以高亮显示。

* *[潜影盒](潜影盒.md)**
* 现在以[物品实体](物品实体.md)的形式被摧毁时，其内容物会被释放。

# = 命令格式 =
* ***
* 加入了新的游戏规则<code>playersSleepingPercentage</code>。
* * 默认值为100。
* * 用于设置跳过夜晚所需的入睡玩家所占百分比。
* * 设置为0时，1个玩家入睡即可跳过夜晚，同时睡眠动画也会被跳过。
* * 设置为超过100的值时，玩家入睡将无法跳过夜晚。

# = 常规 =
* *[资源包](资源包.md)**
* [收纳袋](收纳袋.md)现在使用独立纹理图标。

* *[标签](Java版标签.md)**
* 从游戏事件标签中移除游戏事件。
