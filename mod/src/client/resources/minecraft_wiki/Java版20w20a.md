# Java版20w20a

*页面ID: 62115* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w20a**是[Java版1.16](Java版1.16.md)的第16个快照，发布于2020年5月13日<ref name="20w20a"></ref>，加入了10个新进度、游戏模式切换的快捷键以及新的物品标签，并修复了一些漏洞。

# = 常规 =
* *[游戏模式](游戏模式.md)切换**
* 加入了游戏模式切换快捷键。
* * 按住的同时按下以打开游戏模式切换菜单。此后可通过按或使用鼠标切换游戏模式，然后松开即可更改模式。
* * 上次更改的游戏模式会被保存，成为下次切换游戏模式的首选项。因此可以通过直接按下来在两个游戏模式之间快速切换。
* * 可按下来在旁观模式和玩家之前所用的游戏模式之间快速切换。

* ***
* 现拥有属性。

* *[标签](Java版标签.md)**
* 添加物品标签。
* * 包含[金锭](金锭.md)、金工具、金[盔甲](盔甲.md)、[金苹果](金苹果.md)、[附魔金苹果](附魔金苹果.md)、[金马铠](金马铠.md)、[金胡萝卜](金胡萝卜.md)、[金块](金块.md)、[金矿石](金矿石.md)、[下界金矿石](下界金矿石.md)、[轻质测重压力板](轻质测重压力板.md)、[钟](钟.md)、[闪烁的西瓜片](闪烁的西瓜片.md)和[时钟](时钟.md)。
* * [猪灵](猪灵.md)“喜爱”含有此标签的物品，并且会主动寻找它们。它们也会将持有此标签物品的玩家视为持有“喜爱”的物品。
* * 用于“金光闪闪”进度。

# 更改
# = 游戏内容 =
* *[进度](进度.md)**
* 更改了“”的进度需求。
* * 现在只在30格外击中[标靶](标靶.md)的靶心时达成。
* * 现在为挑战进度并给予50经验值。
* * 描述从“用箭射中标靶方块的靶心”更改为“从至少30米外射中标靶的靶心”。
* “”进度现在需要通过获得[下界合金锄](下界合金锄.md)来达成。
* * 描述从“用坏一把钻石锄，然后重新考虑你的人生抉择”更改为“用下界合金锭升级一把锄，然后重新考虑你的人生抉择”。
* 炽足兽加入“”进度需求。
* 获得黑石也会达成“”进度。
* “”进度描述从“用盾牌弹开一根箭或三叉戟”更改为“用盾反弹一个弹射物”。
* “”进度描述从“创造并挖掘一块黑曜石”更改为“获得一块黑曜石”。
* 移除进度触发器，因为它在中冗余。

* *[以物易物](以物易物.md)**
* 猪灵不再给予下界合金锄。

# = 生物 =
* *[潜影贝](潜影贝.md)**
* 用命令生成的带有<code>NoAI</code>的潜影贝现在会转向了。
