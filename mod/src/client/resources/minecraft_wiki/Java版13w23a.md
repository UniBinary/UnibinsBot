# Java版13w23a

*页面ID: 33537* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w23a**是[Java版1.6.1](Java版1.6.1.md)的第11个快照，发布于2013年6月7日<ref></ref>，加入了命令和1条新的[游戏规则](游戏规则.md)，以及2条新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 从一个点上散布一些[玩家](玩家.md)。
* 可设定玩家间最小和最大距离。
* 可用于将队伍散布到同一地方。

* ***
* 加入了玩家是否能在[饥饿值](饥饿值.md)足够时自然恢复[生命值](生命值.md)的游戏规则：<code>naturalRegeneration</code>。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了2条新的闪烁标语：
* * “HURNERJSGER”
* * “What's up Doc?”

# 更改
# = 物品 =
* *[闪烁的西瓜片](闪烁的西瓜片.md)**
* 配方从使用1个[金粒](金粒.md)变为至8个。

* *[金苹果](金苹果.md)**
* 配方从使用8个金粒变为使用8块[金锭](金锭.md)。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
* 平衡了[药水](药水.md)和[饥饿](饥饿.md)机制。
* * [瞬间治疗](瞬间治疗.md)效果减少33%（第1级只恢复）。
* * [生命恢复](生命恢复.md)效果减少50%（第1级每2.5秒恢复，之后每等级间隔减半）。
* * 自然生命恢复现在会消耗[饥饿值](饥饿值.md)或[饱和度](饱和度.md)，每恢复增加3点[消耗度](消耗度.md)。

# = 常规 =
* *[资源包](资源包.md)**
* 继续[资源包](资源包.md)的开发。
* * 仍未完成。
