# 附魔金苹果

*页面ID: 13434* | *来源: Minecraft Wiki*

* *附魔金苹果（Enchanted Golden Apple）**是一种特殊的[食物](食物.md)，能给予比[金苹果](金苹果.md)更强的增益效果，但无法合成。

# 用途
# = 食物 =

手持附魔金苹果按住键即可食用，每个附魔金苹果可以回复，并获得2分钟的[吸收](吸收.md)IV效果（提供[伤害吸收值](伤害吸收值.md)）、，每秒×0.4，共回复）}}或，每秒×0.4，共回复）}}、5分钟[抗火](抗火.md)和5分钟[抗性](抗性.md)I（绝大多数类型的伤害减少20%）。

玩家在饥饿值满时也能食用附魔金苹果。

# = 马、驴、骡 =
附魔金苹果能将驯服[马](马.md)、[驴](驴.md)、[骡](骡.md)的概率增加10%，使其恢复点生命值，同时使马和驴进入[繁殖](繁殖.md)模式。给幼年马、幼年驴、幼年骡喂食附魔金苹果可使其成长加速4分钟。

# 你知道吗
* 如果在创造模式下使用[铁砧](铁砧.md)给[金苹果](金苹果.md)附魔，金苹果会显示和附魔金苹果一样的外观，但食用的效果和普通金苹果相同。
* 附魔金苹果必须通过[不祥宝库](不祥宝库.md)战利品才能实现可再生。这是因为宝库可以被每个玩家打开无限次数<ref></ref>，且[不祥试炼钥匙](不祥试炼钥匙.md)是[可再生资源](可再生资源.md)。
