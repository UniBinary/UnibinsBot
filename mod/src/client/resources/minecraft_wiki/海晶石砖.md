# 海晶石砖

*页面ID: 12714* | *来源: Minecraft Wiki*

* *海晶石砖（Prismarine Bricks）**是自然生成于[海底神殿](海底神殿.md)的一种砖类方块。

# 生成
# = 自然生成 =
海晶石砖会在[海底神殿](海底神殿.md)中生成，构成了神殿的主要结构和神殿下方的23根柱子。

# 破坏
挖掘海晶石砖的合适工具是镐。海晶石砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

海晶石砖被破坏后会掉落自身。

# 用途
# = 潮涌核心 =

海晶石砖可以用于组成[潮涌核心](潮涌核心.md)需要的启动框架。
