# Java版21w13a

*页面ID: 80905* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w13a**是[Java版1.17](Java版1.17.md)的第15个快照，发布于2021年3月31日<ref name=article-21w13a></ref>，加入了[山羊](山羊.md)、[光源方块](光源方块.md)、纯黑背景的Mojang Studios加载页面，调整了洞穴和矿石的生成机制，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[光源方块](光源方块.md)**
* 可自定义方块亮度等级的方块，同步自基岩版。
* 能够[含水](含水.md)。
* 右键点击可以调整亮度等级。
* 性质类似于空气，不会阻挡实体。
* 手持该方块时可以看见已放置的光源方块，类似于[屏障](屏障.md)。
* 只能使用命令来获得。

# = 生物 =
* *[山羊](山羊.md)**
* 仅在[山地](风袭丘陵.md)、[繁茂的山地](繁茂的山地.md)、[沙砾山地](沙砾山地.md)、[沙砾山地+](沙砾山地+.md)和[山地边缘](山地边缘.md)生成。
* 没有任何[掉落物](掉落物.md)。
* 会利用自身超强的跳跃能力来爬山。
* 可以通过[小麦](小麦.md)来繁殖。
* 可以产奶。
* 有2%的概率生成尖叫山羊，拥有不同于一般山羊的叫声。

# = 常规 =
[thumb|right|启用黑白徽标选项时出现的备用Mojang Studios加载屏幕](File:Monochrome Mojang Studios Logo.png.md)
* *辅助功能**
* 加入了纯黑背景的Mojang Studios加载页面，可以通过辅助功能内的“黑白徽标”选项来选择是否使用。

* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 包含[泥土](泥土.md)、[砂土](砂土.md)、[灰化土](灰化土.md)和[缠根泥土](缠根泥土.md)。
* * [草](草.md)、[高草丛](高草丛.md)、[蕨](蕨.md)、[大型蕨](大型蕨.md)、[甜浆果丛](甜浆果丛.md)、[树苗](树苗.md)、[花](花.md)、[杜鹃花丛](杜鹃花丛.md)、[甘蔗](甘蔗.md)和[枯萎的灌木](枯萎的灌木.md)能被放置在拥有此标签的方块上方。
* * 南瓜茎和西瓜茎能在拥有此标签的方块上方产生南瓜或西瓜。
* * 末影人能够搬起拥有此标签的方块。
* 加入了方块标签。
* * 包含[雪](雪.md)、[雪块](雪块.md)和[细雪](细雪.md)。
* * 被拥有此标签的方块覆盖的草方块、灰化土和菌丝体会变成覆雪的纹理。
* 加入了实体类型标签。
* * 包含[热带鱼](热带鱼.md)、[河豚](河豚.md)、[鲑鱼](鲑鱼.md)、[鳕鱼](鳕鱼.md)、[鱿鱼](鱿鱼.md)和[发光鱿鱼](发光鱿鱼.md)。
* * 美西螈杀死拥有此标签的实体后会有2分钟的冷却时间。
* 加入了实体类型标签。
* * 包含[炽足兽](炽足兽.md)、[烈焰人](烈焰人.md)和[岩浆怪](岩浆怪.md)。
* * 拥有此标签的实体受到的冰冻伤害为原先的5倍。
* 加入了实体类型标签。
* * 包含[流浪者](流浪者.md)、[北极熊](北极熊.md)和[雪傀儡](雪傀儡.md)。
* * 拥有此标签的实体免疫冰冻伤害。

# 更改
# = 方块 =
* *[蜡烛](蜡烛.md)**
* 现在可被[喷溅型水瓶](喷溅型水瓶.md)和[滞留型水瓶](滞留型水瓶.md)熄灭。

* *[深板岩](深板岩.md)**
* 现在会在Y=0至16的高度以[团簇](团簇.md)形式生成。

* *[滴水石块](滴水石块.md)和[滴水石锥](滴水石锥.md)**
* 现在会罕见地生成于常规世界的[洞穴](洞穴.md)中。

* *[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)**
* 略微更改了侧面纹理，并对内部纹理做了镜像处理。

* *盛开的杜鹃花丛和[盛开的杜鹃树叶](盛开的杜鹃树叶.md)**
* 现在具有[花](花.md)的部分性质。
* * [蜜蜂](蜜蜂.md)会采集它的花粉。
* * 可用于吸引和繁殖蜜蜂。
* * 可用于合成无状态效果的[谜之炖菜](谜之炖菜.md)。
* ** 然而不能通过喂食棕色[哞菇](哞菇.md)后[碗](碗.md)获得该谜之炖菜。
* * 若它们位于橡树或白桦[树苗](树苗.md)水平2格范围内，则该树苗长成的树会有5%的概率悬挂着[蜂巢](蜂巢（方块）.md)。

* *[缠根泥土](缠根泥土.md)**
* 现在顶部纹理会随机旋转。
* 现在使用[锹](锹.md)开采是最快的。
* 现在任意种类的锹可将缠根泥土转化为[土径](土径.md)。
* [草](草.md)、[蕨](蕨.md)、[花](花.md)、[树苗](树苗.md)、[竹子](竹子.md)和[枯萎的灌木](枯萎的灌木.md)现在可以种植在缠根泥土上了。
* * 也可以在其上种植[小型垂滴叶](小型垂滴叶.md)，但仅限在[水](水.md)下。
* 现在[创造模式物品栏](创造模式物品栏.md)里缠根泥土与[泥土](泥土.md)及其部分变种陈列在一起。

* *[细雪](细雪.md)**
* 硬度由0.1变为0.25。
* 现在进入[冰冻](冰冻.md)状态所需时长减少到7秒，冰冻伤害频率减少到2秒。
* 现在被[着火](着火.md)的[实体](实体.md)触碰时会融化消失。
* 提高了[玩家](玩家.md)在其中垂直移动的速度。
* 现在生物进入冰冻状态后会颤抖。
* 对其内部纹理做了镜像处理。

* *[小麦](小麦种子.md)、[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)、[甜菜](甜菜.md)、[下界疣](下界疣.md)、[锁链](锁链.md)、[梯子](梯子.md)、[藤蔓](藤蔓.md)和[发光地衣](发光地衣.md)**
* 对其背面纹理做了镜像处理。

* *[绊线](绊线.md)和[大型垂滴叶](大型垂滴叶.md)**
* 对其底面纹理做了镜像处理。

* *[绊线钩](绊线钩.md)**
* 对绊线钩与绊线的连接部分的底面纹理做了镜像处理。

* *[灯笼](灯笼.md)、[切石机](切石机.md)、[海泡菜](海泡菜.md)和[小型垂滴叶](小型垂滴叶.md)**
* 对灯笼纹理上的锁链部分、切石机的刀片和海泡菜顶部绿色部分的背面纹理做了镜像处理。
* 小型垂滴叶的叶片的背面纹理现在正确旋转。

# = 物品 =
* *[皮革靴子](皮革靴子.md)**
* 现在可以消除实体掉落到细雪上时承受的[摔落伤害](摔落伤害.md)，以此与同步。<ref></ref>

* *[皮革马铠](皮革马铠.md)**
* 现在可以使[马](马.md)免疫冰冻伤害。
* * 使用[命令](命令.md)将其放入其他[生物](生物.md)的装备栏也能够起到该效果。

* *[谜之炖菜](谜之炖菜.md)**
* 现在玩家在满[饥饿](饥饿.md)值状态下也可以食用了。

# = 生物 =
* *[美西螈](美西螈.md)**
* 现在会自然生成在地下水源中。
* 现在会主动攻击[鱿鱼](鱿鱼.md)、[发光鱿鱼](发光鱿鱼.md)、[热带鱼](热带鱼.md)、[鳕鱼](鳕鱼.md)、[鲑鱼](鲑鱼.md)、[河豚](河豚.md)、[溺尸](溺尸.md)、[守卫者](守卫者.md)和[远古守卫者](远古守卫者.md)。
* * 优先攻击敌对型生物。
* * 美西螈的攻击会打断守卫者与远古守卫者的激光充能。
* 现在杀死非敌对目标（例如鱼、鱿鱼等）后会有2分钟的冷却时间。
* 略微更改了蓝色、青色、金色、粉红色变种的尾巴和头部纹理。
* 现在被装入铁桶中后会保留其[NBT标签](NBT标签.md)信息（如生长阶段、颜色和[生命值](生命值.md)）。

* *[发光鱿鱼](发光鱿鱼.md)**
* 现在会自然生成在地下水源中。

* *[蜜蜂](蜜蜂.md)**
* 蜜蜂现在会把盛开的杜鹃花丛和盛开的杜鹃树叶视为[花](花（消歧义）#可以视为花的方块.md)。

* *[守卫者](守卫者.md)、[远古守卫者](远古守卫者.md)和[北极熊](北极熊.md)**
* 现在被火烧死时会掉落[熟鳕鱼](熟鳕鱼.md)或[熟鲑鱼](熟鲑鱼.md)，而不是[生鳕鱼](生鳕鱼.md)或[生鲑鱼](生鲑鱼.md)。

* *[尸壳](尸壳.md)、[僵尸](僵尸.md)和[僵尸村民](僵尸村民.md)**
* 现在被火烧死时会掉落[烤马铃薯](烤马铃薯.md)，而不是生的[马铃薯](马铃薯.md)。

* *[流浪商人](流浪商人.md)**
* 为流浪商人加入了以下交易选项：
* * 以1个[绿宝石](绿宝石.md)的价格出售2个[滴水石锥](滴水石锥.md)。
* * 以1个绿宝石的价格出售2个[缠根泥土](缠根泥土.md)。
* * 以1个绿宝石的价格出售2个[苔藓块](苔藓块.md)。

* *[村民](村民.md)**
* 为石匠村民加入了以下交易选项：
* * 以1个绿宝石的价格出售4个[滴水石块](滴水石块.md)。

* *[流浪者](流浪者.md)、[北极熊](北极熊.md)和[雪傀儡](雪傀儡.md)**
* 现在免疫冰冻伤害。

* *[烈焰人](烈焰人.md)、[岩浆怪](岩浆怪.md)和[炽足兽](炽足兽.md)**
* 现在受到的冰冻伤害为其他生物的5倍。

* *[骷髅](骷髅.md)**
* 现在处于细雪中后就会开始转变为[流浪者](流浪者.md)（不可逆），以前这个过程需要。
* * 也就是说，现在骷髅转化为流浪者需要的完整时间被缩短到。

# = 世界生成 =
* *[洞穴](洞穴.md)**
* 现在[雕刻器洞穴](雕刻器洞穴.md)不太可能由于过于平坦而无法穿过了。
* 提高了巨型[芝士洞穴](芝士洞穴.md)的生成频率。
* 降低了牙签状柱子（高的1格宽柱子）的生成频率。

* *[矿石](矿石.md)分布**
* 现在[铜矿石](铜矿石.md)改为在Y=0至63的区域间均匀生成。
* 稍微提高了[铁矿石](铁矿石.md)团簇的生成频率。
* 增加了大型[钻石矿石](钻石矿石.md)团簇，生成范围和方法与普通钻石矿石团簇相同。

* *[废弃矿井](废弃矿井.md)**
* 增加了[原木](原木.md)支柱和[锁链](锁链.md)的最大长度。
