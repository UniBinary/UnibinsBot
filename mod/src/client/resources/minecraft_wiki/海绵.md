# 海绵

*页面ID: 20614* | *来源: Minecraft Wiki*

</ref>||Tom_Stone_Mojavatar.png}}

* *海绵（Sponge）**是一种能够将[水](水.md)吸掉的方块。吸了水的海绵会变成**湿海绵（Wet Sponge）**。

# 生成
海绵不会生成在世界中。

# = 自然生成 =
[海底神殿](海底神殿.md)可能生成装有湿海绵的房间，每个房间平均有30个湿海绵。

# 获取
干海绵只能通过烘干湿海绵来获取。

# = 掉落物 =
[远古守卫者](远古守卫者.md)死亡时掉落1个湿海绵，其数量和概率皆不受[抢夺](抢夺.md)魔咒影响。然而远古守卫者生成后不能再次生成，使得海绵不能再生。

# 破坏
海绵的合适挖掘工具是锄。

海绵被破坏后会掉落自身。

# 用途
[缩略图|一块吸收了池中的水的海绵](File:SpongeUsage.png.md)
海绵可以把[水](水.md)变成[空气](空气.md)，把[含水](含水.md)方块变成不含水状态（通俗地说就是“吸水”）。要使用海绵，对着要放置海绵的方块旁按键即可。

在附近有水或与水接触（在海绵旁放置水或是水朝海绵流过来）时，海绵会瞬间把这些水吸干。之后海绵会立刻变为湿海绵，并且在被蒸干前不再吸收任何水。湿海绵会落下小的水滴粒子。海绵的[物品实体](物品（实体）.md)不会吸收任何水，也不会因此变为湿海绵。

海绵会吸掉其自身周围六个方向的[曼哈顿距离](曼哈顿距离.md)不超过7格的[水](水.md) （水源方块或流动的水）。而由于游戏广泛地使用了曼哈顿距离作计算，在吸水之后，被吸水的空间实际上会形成一个各方向顶点与中心的距离为7个单位长度的[八面体](wzh:八面体.md)，而非立方体或圆球。不过，海绵最多只会吸收65个方块的水，且离海绵最近的水会首先被吸收。这种吸收只会在相邻的水方块之间扩散性地计算，且不会从一个区域的水“跳过”不是水的方块（包括空气）而吸收另一区域的水。

# = 烘干 =
</ref>||Michael_Stoyke_Mojang_avatar.png}}

湿海绵可以在熔炉中被烘干，变成干海绵。

# = 蒸干 =
放置在[下界](下界.md)由[环境属性](环境属性.md)<code>gameplay/water_evaporates</code>控制。}}中的湿海绵会被立即蒸干，并产生蒸汽粒子变为干海绵。

放置在[主世界](主世界.md)的[干旱类生物群系](干旱类生物群系.md)（例如[沙漠](沙漠.md)和[恶地](恶地.md)）中的湿海绵会在几分钟后被蒸干，成为干海绵。

如果-{}-干海绵在干旱生物群系接触到水，那么海绵会在吸水的瞬间被蒸干，并产生蒸汽粒子变为干海绵。
