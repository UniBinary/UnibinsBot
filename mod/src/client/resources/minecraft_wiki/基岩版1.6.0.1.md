# 基岩版1.6.0.1

*页面ID: 34992* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.6.0.1**是[1.6.0](基岩版1.6.0.md)的首个测试版，发布于2018年6月14日<ref></ref>，加入了幻翼和屏障，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[屏障](屏障.md)**
* 跟[隐形基岩](隐形基岩.md)一样透明。
* 只能通过命令获得。
* 能够在创造模式中放置，并在生存模式和冒险模式中不可见。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了[幻翼](幻翼.md)刷怪蛋。

# = 生物 =
* *[幻翼](幻翼.md)**
* 在玩家连续3个游戏日没有入睡后生成。
* 死亡后不会掉落任何物品。
* 声音受水的影响。

# 更改
# = 常规 =
* *[控制](控制.md)**
* 书和笔中的页面现在可以使用手柄的保险杠按钮进行翻页。
* 菜单和物品栏选项现在可以使用  和  键来切换（可以在设置中重新映射）。

# 修复
* *修复了27个漏洞**
* 修复游戏过程中发生的一些崩溃。
* 修复了当生物刚死亡时使用选取方块键发生的崩溃。
* 提高了菜单的加载速度。
* 修复水从含有水源的楼梯不正确的流动。
* 顶层雪一旦遇到水就会被破坏。
*  - 修复用重命名的物品和村民交易后，得到的物品消失不见。
*  - 再次修正地图在主手上的显示。
* 玩家如果出生点在末地传送门上现在能够返回主世界了。
* 降低“punching air”（鞘翅冲击空气）音效的音量。
*  - 修复守卫者即使在禁用生物生成下自然生成。
* 修复流浪者和骷髅难离开水去攻击玩家。
*  - 食物的粒子在游泳之后不再逐渐变换位置，总是从玩家嘴的位置出来。
* 侦测器现在可以侦查到投掷器、发射器、酿造台、耕地、树苗、甘蔗、火和草方块的变化。
* 现在玩家又能在关闭“可合成”过滤器且拥有的材料只能合成一份物品的情况下使用配方书合成物品了。
* 修复了玩家装备深海探索者靴子时，海豚给予的提速效果不够明显的漏洞。
* 狼在攻击水下的骷髅时不再会被卡住。
*  - 驴和骡现在被驯服后只能由玩家骑乘。
*  - 烈焰人现在会攻击雪傀儡。
*  - 使用生成的红石元件现在会正确地更新和激活与之相邻的红石元件。
*  - 命令方块现在会正确地传导红石信号。
* 当创建一个信任玩家权限为操作员的世界时，将给予操作员权限。
* 当从合成输出中弹出时，漏斗可以正确堆叠了。
* 使用命令生成的经验球将给予玩家经验。
* 控制器的光标现在可以用于导航村民交易。
* 修复物品栏内龙首重叠问题。
* 工作台的输出字段悬停状态现在匹配字段的大小。
* 使用无法合成配方时的输出不再导致输出项消失了。</onlyinclude>
