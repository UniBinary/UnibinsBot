# Xbox 360版1.66.0035.0

*页面ID: 101317* | *来源: Minecraft Wiki*

* *Build 0035**是的一个开发者版本。此版本基于[Java版Beta 1.6.6](Java版Beta 1.6.6.md)制作。

# 更改
* 移除了世界菜单中刷新在线游戏列表的选项，因为它在被按下时游戏会崩溃。

# 修复
* 修复了伽马值滑块卡在0的问题。
* 修复了破坏方块后方块会随机出现的问题。

# 你知道吗
* 这个版本在内部被称为“Minecraft”，而不是像移植版那样的“Minecraft：Xbox 360 Edition”。
