# 携带版0.11.0.b6

*页面ID: 27992* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 6**是[v0.11.0 alpha](携带版0.11.0.md)的第6个测试版，发布于2015年4月22日，修复了一些漏洞。

# 更改
# = 物品 =
* *常规**
* 物品快捷栏中的物品可交换位置。

# = 游戏内容 =
* *[皮肤](皮肤.md)**
* [皮肤](皮肤.md)选择界面中的模型预览现在可旋转。

# 修复

* *其他漏洞**
* 退出游戏后，箱子里的内容物不会保存。
* 切换创造或生存模式时出现错误。
* “总是白天”按钮不会正常运作。
* 无法编辑世界世界名称。
* 多人游戏下可以复制实体。
* 玩家首次生成时的朝向不正确。
* 连接服务器后，创造模式下的物品栏显示不正确。
* 网络连接不佳导致游戏卡顿。
* 服务器列表内的服务器可以受到攻击。
* 多次死亡和重生使得游戏崩溃。
* 从服务器断开连接后游戏崩溃。
* 在多人游戏下骑乘不存在的实体使得游戏崩溃。
* 死亡后氧气值会自动填充，即使玩家在水下。</onlyinclude>
