* *珊瑚扇（Coral Fan）**是一类非固体方块，有管珊瑚扇、脑纹珊瑚扇、气泡珊瑚扇、火珊瑚扇和鹿角珊瑚扇五个变种。

# 生成
# = 自然生成 =
珊瑚扇会自然生成在[珊瑚礁](珊瑚礁.md)结构中。

# = 骨粉 =
在或生物群系的[水](水.md)中[骨粉](骨粉.md)会有一定概率生成珊瑚扇。

# 获取
珊瑚扇只能通过破坏珊瑚扇获得。

# 破坏
珊瑚扇被挖掘时会立刻被破坏。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，珊瑚扇被破坏后不会掉落。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，珊瑚扇被破坏后会掉落自身。

# 用途
# = 放置 =
珊瑚扇及其失活变种可以放置在方块的侧面和顶部，但不能放置在底部。

# = 失活的珊瑚扇 =
若要使珊瑚扇保持存活，至少要使其一面接触[水](水.md)，否则会在60-99[游戏刻](游戏刻.md)后变成对应[失活的珊瑚扇](失活的珊瑚扇.md)。

若要使珊瑚扇保持存活，只能将其放置在水源中，否则会立刻变成对应失活的珊瑚扇。
