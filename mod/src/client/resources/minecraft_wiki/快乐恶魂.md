* *快乐恶魂（Happy Ghast）**是一种可被玩家骑乘的[友好生物](友好生物.md)。

* *小恶魂（Ghastling）**是快乐恶魂的幼年形态，由[失水恶魂](失水恶魂.md)浸水转化而来。

# 生成

失水恶魂被放置在[水](水.md)中大约20分钟后，会转变成小恶魂。

# 掉落物
快乐恶魂在死亡时会掉落所装备的[挽具](挽具.md)。若被[玩家](玩家.md)或驯服的[狼](狼.md)杀死，快乐恶魂还会掉落。

与其他幼年动物一样，小恶魂死亡后不会掉落任何经验或物品。

# 行为
小恶魂会在生成后成长为快乐恶魂，对其喂食[雪球](雪球.md)可以加快生长进度，每次喂食可减少约10%的剩余生长时间。

对小恶魂[金蒲公英](金蒲公英.md)可以阻止其成长为快乐恶魂，再次对其金蒲公英将使其重新开始成长。被阻止成长的小恶魂无法被喂食除金蒲公英外的其他物品。

与[恶魂](恶魂.md)不同，快乐恶魂和小恶魂不免疫[火焰伤害](火焰伤害.md)<ref></ref>，也不会发射[火球](火球.md)，会受到[僵尸疣猪兽](僵尸疣猪兽.md)、[“Johnny”卫道士](卫道士#“Johnny”卫道士.md)和[凋灵](凋灵.md)的攻击以及[山羊](山羊.md)的冲撞，受到火球的伤害和其他生物相同。

快乐恶魂和小恶魂被攻击后不会尝试逃跑。

小恶魂不会溺水，但快乐恶魂仍会溺水。<ref></ref>快乐恶魂会更快进入溺水状态。

快乐恶魂每会自然恢复。在[主世界](主世界.md)中，处于[雨](雨.md)或[雪](降雪.md)中时或飞行高度与[云](云.md)的高度（Y=192至196）相同时则每自然恢复。

快乐恶魂无法乘坐[船](船.md)，乘坐船的小恶魂会在成长为快乐恶魂时脱离船。

不同于其他生物，被拴绳拴住的快乐恶魂需要移动到或之外才会使[拴绳](拴绳.md)断裂。

快乐恶魂和小恶魂处于[水](水.md)或[熔岩](熔岩.md)中（还需未被骑乘或提供支撑）时会上浮。

快乐恶魂和小恶魂会更频繁地发出空闲声音。

# = 骑乘 =
[thumb|200px|[[史蒂夫](File:Steve_Riding_Happy_Ghast.gif.md)骑乘着快乐恶魂]]
玩家可对快乐恶魂[挽具](挽具.md)，使其可被骑乘，并在无玩家骑乘时使用[剪刀](剪刀.md)将挽具移除。也可使用[发射器](发射器.md)为其装备挽具。挽具被装备在快乐恶魂上时，其镜框会在无乘客时抬起，而在有乘客时落回眼前。状态下的快乐恶魂仍会显示其身上的挽具。

快乐恶魂最多可以承载4名[玩家](玩家.md)，座位分别位于其上表面的四个边缘。第一个骑乘快乐恶魂的玩家会坐在前部，后来骑乘的玩家会坐在其余侧面的槽位上，以第一个骑乘的玩家开始顺时针排序，而只有坐在前部的玩家可以控制快乐恶魂。

当坐在前部的玩家移动视角时，快乐恶魂会在短暂延迟后以自身（而不是该玩家）为中心在水平方向上旋转至与该玩家视角相同的方向。控制飞行时，和键分别使快乐恶魂沿着控制者面向的方向（包括垂直方向）前进或后退，和会使其直接在水平方向上平移。按下可以使其垂直上升，但上升速度略慢于在视角垂直向上时按下。

按下可以脱离乘坐，这时玩家会站在快乐恶魂的上表面。快乐恶魂或会使所有乘客脱离骑乘。

快乐恶魂被骑乘时不能被[拴绳](拴绳.md)移动，不会被持有[雪球](雪球.md)的玩家吸引。快乐恶魂受到的[击退](伤害#击退.md)效果会被降低。

骑乘快乐恶魂时会加长玩家的第三人称[](属性/镜头距离.md)。

# = 提供支撑 =
当快乐恶魂头顶或范围内有不骑乘它的非[旁观模式](旁观模式.md)玩家时，快乐恶魂会停止自主移动并转向正东、正南、正西或正北方向，并忽略骑乘它的玩家（若有）的视角和操作。此时，快乐恶魂的全身会具有与方块类似的[碰撞箱](碰撞箱.md)，能够为实体提供支撑。
* 除[弹射物](弹射物.md)、<ref></ref>外的实体可以停留在其上方。
* * 站在其上方的[生物](生物.md)的部分寻路系统会失效，导致它们在多数情况下不会移动。
* * 弹射物仍然可以击中快乐恶魂，但因为击中头顶的[滞留药水](滞留药水.md)产生的[区域效果云](区域效果云.md)的碰撞箱与快乐恶魂的碰撞箱没有重合部分，击中头顶的滞留药水不会对快乐恶魂产生影响。
* * 快乐恶魂移动时，站在其上方的玩家和生物不会跟随快乐恶魂而水平移动。
* 玩家可以在其边缘潜行而不掉下去，可以攻击它或对它使用拴绳，但不能在它身上放置方块、船或使用刷怪蛋。
* 生物能够在其上方摔落并受到摔落伤害。
* 在其上方着陆和摔落时会播放方块通用的着陆和摔落音效。
* 提供支撑时，快乐恶魂不会受击退效果影响，还不能被拴绳移动。

# = 拴住实体 =
[thumb|200px|一艘船通过拴绳连接在快乐恶魂下方](File:Happy_ghast_carrying_a_boat.png.md)
使用拴绳将[船](船.md)、[运输船](运输船.md)、[马](马.md)、[驴](驴.md)、[骡](骡.md)、[骷髅马](骷髅马.md)、[僵尸马](僵尸马.md)、[骆驼](骆驼.md)、[骆驼尸壳](骆驼尸壳.md)和[嗅探兽](嗅探兽.md)拴在快乐恶魂上时，会有四条类似拴绳的线从快乐恶魂下方的四个角连接到被拴住的实体上（只是视觉效果，实际只需一条拴绳）。如果快乐恶魂装备了挽具，快乐恶魂身上还会出现特殊的纹理。

如果有玩家骑乘与快乐恶魂相连接的可骑乘实体并且能够控制它，该实体将不会跟随快乐恶魂飞行，而会受到重力影响开始下坠，并可能导致拴绳断开连接。<ref></ref>若玩家坐在与快乐恶魂连接的船中的、装备了[鞍](鞍.md)的[猪](猪.md)或[炽足兽](炽足兽.md)上面而不是船上面，上述效果就不会触发。

# = 跟随与游荡 =
快乐恶魂会主动跟随半径16格内手持[雪球](雪球.md)的玩家。未装备挽具的快乐恶魂也会跟随手持挽具的玩家。若附近没有合适的可跟随生物，快乐恶魂会在其原点位置64格内游荡，已装备挽具时则会在原点位置32格内游荡。快乐恶魂游荡时会尝试靠近最近的至少为4&times;4格的平台或至少有20个方块的位置，否则会总体保持向下飞行。

小恶魂会尝试跟随半径16格内的玩家以及非水生成年友好生物，并优先跟随手持雪球的玩家。若附近没有合适的可跟随生物，小恶魂会在其原点位置32格内游荡。

快乐恶魂和小恶魂会在下列情况下设置或重置原点位置至此刻自身位置：
* 生成；
* 被移动至原游荡范围之外；
* 被装备或卸下挽具；
* 拴住它的拴绳被切断；
* 停止被骑乘。

小恶魂被雪球吸引时会更靠近玩家，而快乐恶魂被雪球或挽具吸引时会在距离玩家较远处停止。

快乐恶魂游荡时的速度与玩家控制飞行时相同。快乐恶魂游荡时的速度显著快于玩家控制飞行时的速度。<ref></ref>

# 你知道吗
* 快乐恶魂的首个概念来自[Minecraft Legends](Minecraft Legends.md)中飞行恶魂坐骑的概念艺术。<ref>https://www.youtube.com/watch?v=jGNgh5zEFkY</ref>
* [LadyAgnes](LadyAgnes.md)表示，快乐恶魂的设计灵感来自热气球。<ref>https://www.youtube.com/watch?v=gOusaq5i-f0&t=108</ref>
* 小恶魂在外观上有鳃，且为双层纹理；成年后的快乐恶魂没有鳃，且为单层纹理。与此对应，小恶魂不会溺水，而快乐恶魂会溺水。
* 快乐恶魂的护目镜在落下时的纹理被略微上下拉长，且眼镜架的位置比Java版低一格像素。
* 装备挽具后，快乐恶魂的模型会略微缩小以保持整体模型大小不变。<ref></ref><ref></ref>
* 在[minecraft.net](minecraft.net.md)的一篇文章中出现了快乐恶魂的集合名词“A chuckle of happy ghasts”。<ref></ref>
