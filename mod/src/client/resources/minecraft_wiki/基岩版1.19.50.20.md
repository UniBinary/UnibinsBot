# 基岩版1.19.50.20

*页面ID: 98838* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.50.20**（Android）、**Preview 1.19.50.20**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.50](基岩版1.19.50.md)的首个测试版，发布于2022年10月13日<ref></ref>，更新了触摸控制，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[设置](设置.md)**
* 在设置中加入了“延迟区块破坏(仅限创意)”选项。
* * 用于控制创造模式下是否存在破坏方块延时。

* *<samp>[server.properties](server.properties.md)</samp>**
* 加入了服务器属性。
* * 用于启用与禁用服务器的显式局域网发现。

* *用户界面**
* 加入了玩家将要丢失在[创建新的世界](创建新的世界.md)界面做出的更改时出现的警告。

# 更改
# = 方块 =
* *[泥巴](泥巴.md)和[灵魂沙](灵魂沙.md)**
* 将方块高度降低至0.875格。

# = 生物 =
* *[末影人](末影人.md)**
* 将跟随范围由32格更改至64格。

# = 常规 =
* *[触摸控制](触摸控制.md)**
* 重新加入了新的拆分物品功能。
* 将拖拽物品前按住物品的停顿时长由120毫秒增加至180毫秒，以更轻松地滚动物品栏界面。
* 改进了新的触控模式下同时按下按钮并移动视角的方式。

* *[实验性玩法](实验性玩法.md)**
* 移除了“旁观模式”子选项。

* *[旁观模式](旁观模式.md)**
* 现在开启作弊后，玩家可以在游戏设置中将个人游戏模式切换为旁观模式。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[专用服务器](基岩版专用服务器.md)**
* 更改了服务器日志中的端口使用错误信息。

* *用户界面**
* 更改了复制世界的错误处理流程，现在会显示一个错误弹窗而不是弹出警告。
* 更改了“”选项的文字颜色，以提升阅读体验。

# 修复
* *旁观模式**
* 现在开启作弊后，玩家可以通过设置菜单中的个人游戏模式或命令来进入或退出旁观模式。（）
* 旁观模式现在会在设置中的个人游戏模式列表中正常显示。（）
* 现在当玩家进入旁观模式时，容器、命令方块或结构方块界面会被正常关闭。

* *方块**
* 土径和耕地的方块碰撞现在下调了1个像素。（）
* 玩家在泥巴上方游泳时不再会使屏幕被覆盖住。（）
* 落在泥巴上的弹射物不再会反复抖动。（）
* 泥巴旁的两栖生物不再会出现寻路问题。（）
* 现在玩家放置出的泥巴和灵魂沙的边界框与视觉上的边界框相匹配。（）
* 甘蔗现在会在周围水源被移除后的下一随机刻中被破坏。（）
* 修复了即使选中光源方块时放置出的光源方块仍会不可见的漏洞。

* *游戏内容**
* 修复了方块被活塞移动后的抖动问题。
* 修复了繁殖带有状态效果的动物后，幼崽会永久带有该效果的问题。（）
* 现在活塞头的伸缩动画更加流畅了。（）
* 现在活塞推动的方块的移动动画更加流畅了。（）
* 修复了玩家离开传送门后还会被传送回去的问题。（）
* 修复了放置告示牌时的音效缺失问题。
* 地图上的黑色像素现在可以通过经过对应区域来修复。在之前的版本中出现此漏洞的地图现在可以通过拿在主手或副手上来修复此漏洞。（）

* *常规**
* 修复了世界高度为负数时蝙蝠休息位置错误的问题。
* 修复了蓄力完毕的物品会在玩家进入传送门后消失的漏洞。（）
* 现在水下的岩浆块上的气泡柱可以正常生成。
* 现在音效事件中设定的最大/最小衰减距离只会影响该事件，而不会影响其他使用该音效的事件。（）
* 向<samp>server.properties</samp>中加入了布尔值设置。

* *图形**
* 现在被活塞移动的方块也会拥有环境光照。（）
* 修复了使用RTX时的夜空亮度问题。（）

* *物品**
* 现在新合成的工具和盔甲在首次使用时可以正常工作。（）
* 现在武器、工具和盔甲可以在第一次被重命名后被玩家丢弃。（）
* 修复了当坐标有实体时无法在其周围放置压力板的问题。（）

* *生物效果**
* 跳跃提升现在会持续对玩家骑乘的生物产生影响。（）
* 缓降现在会持续对玩家骑乘的生物产生影响。（）

* *移动数据**
* 为Android/iOS设备加入了移动数据可用但在游戏中被禁用时出现的移动数据被阻止的屏幕。

* *生物**
* 将末影人的跟随范围由32格提高至64格。（）

* *触摸控制**
* “分离控制”选项现在仅会在经典控制方案下出现，且仅影响经典控制方案。
* 修复了启用十字准星和触摸控制方案时，某些情况下会无法触摸快捷栏槽位的问题。
* 解除了“锁定摇杆”、“摇杆始终可见”和“未使用时摇杆可见”选项之间的联系。
* 修复了在高刷新率屏幕上难以双击触摸控制按钮的问题。（）
* 现在使用十字准星控制来乘船时，操作按钮会正确显示出来。（）

* *用户界面**
* 修复了Boss栏在Boss被重命名后不会及时更新的问题。
* 加入了玩家将要丢失在创建新的世界界面做出的更改时出现的警告。
* 更改了复制世界的错误处理流程，现在会显示一个错误弹窗而不是弹出警告。
* 修复了在VR模式下乘船时HUD无法跟随玩家朝向旋转的漏洞。
* 更改了“”选项的文字颜色，以提升阅读体验。（）
* 快捷栏物品的背景现在会受“文字背景透明度”滑块的影响。（）

* *命令**
* 使用命令来为物品施加相同等级的魔咒不再会将增加魔咒等级。（）
* 修复了过滤器在未提供数据值时无法正确侦测到带有相应数据值的物品的问题。（）

* *网络**
* 加入了服务器属性，用于启用与禁用服务器的显式局域网发现。禁用此项可以防止在同一主机上运行多个专用服务器时可能出现的端口冲突。
* 更改了服务器日志中的端口使用错误信息。（）

* *性能与稳定性**
* 修复了刷怪蛋的超限时发生的崩溃。现在出现这种情况时会出现内容日志错误。
* 加入了获取活动对象时的空指标检查以防止崩溃。
* 修复了末影龙的龙息攻击没能接触方块或落入虚空时发生的崩溃。（）
* 修复了使用键盘滚动村民交易界面时可能发生的崩溃。</onlyinclude>
