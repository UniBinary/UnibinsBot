# 世界加载屏幕

*页面ID: 72912* | *来源: Minecraft Wiki*

* *世界加载屏幕（Loading World Screen）**是生成或加载[世界](世界.md)时显示的屏幕，显示了世界加载的进度。

# Java版
[thumb|使用“0”为种子时生成的区块颜色图](File:Chunk colormap.gif.md)

世界加载屏幕显示了一张**颜色图**和上方的世界加载进度条。颜色图可视化地显示了玩家周围区块的状态。区块加载时，其中的彩色像素点不断变色并扩展。每个像素点都代表着一个区块，其颜色显示了区块的状态。

# 基岩版

世界加载屏幕以[菜单屏幕](菜单屏幕.md)背景全景图为背景，徽标下方的白色区域会显示带有加载动画的“”文本，若启用了[行为包](行为包.md)则会变为“”；黑色区域顶部会显示[加载提示](加载提示.md)，黑色区域底部会显示一个[经验](经验.md)进度条表示加载进度。进度条加载完毕后，加载提示和进度条消失。若游戏模式为[生存模式](生存模式.md)或[创造模式](创造模式.md)，则黑色区域顶部会短暂显示玩家的游戏模式；若为创建新的世界时无法选择的模式，则会短暂显示“”文本。

# 原主机版
[alt=|thumb|原主机版的加载屏幕](File:Loading Screen Legacy Console Edition.png.md)
世界加载屏幕以[菜单屏幕](菜单屏幕.md)背景全景图为背景，在其上显示一个纯绿进度条以及一些文字，屏幕底部也会显示[加载提示](加载提示.md)。
