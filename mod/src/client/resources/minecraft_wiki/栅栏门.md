* 丛林木栅栏门自然生成在沙漠村庄
* 金合欢木栅栏门自然生成在热带草原村庄
* 深色橡木栅栏门自然生成在[林地府邸](林地府邸.md)

# 用途
# = 放置 =
[栅栏门可提供栅栏围闭区域的出入口|缩略图](File:Wheat farm with fences.png.md)

栅栏门放置后朝向和玩家相同。

[栅栏](栅栏.md)和[墙](墙.md)会自动连接栅栏门，但[玻璃板](玻璃板.md)和[铁栏杆](铁栏杆.md)不会。与墙连接时，栅栏门的位置会变低一些。

# = 障碍 =
[关闭的栅栏门|缩略图](File:Closed Gate.png.md)
[开启的栅栏门|缩略图](File:Open Gate.png.md)

栅栏门是一种可手动、用[风爆](爆炸#风爆.md)或[红石电路](红石电路.md)开关的障碍物。

对着栅栏门即可打开或关闭它，处于[风爆](爆炸#风爆.md)影响范围中时也会改变其开关状态。开关栅栏门不会对方块空间中的任何[实体](实体.md)造成影响。

栅栏门被手动打开时会根据本次打开方向调整其朝向，被红石信号或风爆打开时向朝向打开。

虽然看上去只有1格高，但栅栏门的碰撞箱其实有1.5格高，这使得大部分生物不能跳过栅栏门，而站在栅栏门上的实体会在栅栏门上悬浮0.5格。

开启的栅栏门处于完全无碰撞箱的状态，包括两扇打开的门板。实体可以在开启的栅栏门之间随意移动，仿佛栅栏门不存在一般。

栅栏门关闭时，其碰撞箱厚度为0.25格，与栅栏一致。

敌对生物将栅栏门看作一个不透明的障碍物，无法透过栅栏门发现玩家。

像大多数生物的声音一样，栅栏门的开合声音最多可以传到16格远。

# = 红石电路元件 =

栅栏门可以通过红石电路信号控制。

栅栏门是[机械元件](红石元件#机械元件.md)，可被下列形式激活：
* 毗邻的开启的**[电源](红石元件#电源元件.md)**（例外：侦测器只会激活指向的栅栏门）。
* 毗邻的**[充能方块](红石电路/充能与激活.md)**。
* 毗邻的指向栅栏门且激活的[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)或[红石粉](红石粉.md)；毗邻但未指向栅栏门的红石粉不会激活栅栏门。

在同一红石刻内，电容器更新阶段前存在，但在电容器更新阶段被取消的信号无法激活栅栏门。

栅栏门被红石信号激活（收到上升沿）后会立即打开；取消激活（收到下降沿）后会立即关闭。

激活状态的栅栏门仍然可以被玩家手动关闭，但在接收到新的上升沿或之前，栅栏门不会再次自动打开（也就是说需要将红石信号关闭再开启才能重新控制栅栏门）。

# = 燃料 =
主世界木栅栏门和竹栅栏门可以作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个栅栏门可以烧炼1.5个物品。

# 你知道吗
<div style='float:right'></div>
* 使用命令将栅栏门放入玩家的头盔槽会使其在视觉上变成一副眼镜。可在了解更多此类彩蛋。
* 手动打开栅栏门时，若水平面上玩家视角方向与栅栏门原先开启方向的夹角大于135°，门板的开启方向会反转。
* 与其他栅栏门不同，竹栅栏门的模型使用单独的[纹理](纹理.md)，而不是使用对应的木板纹理。
