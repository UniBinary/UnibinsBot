# 携带版0.12.1.b13

*页面ID: 18055* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.12.1 alpha build 13**是[v0.12.1 alpha](携带版0.12.1.md)的第13个测试版，发布于2015年9月1日，修复了一些漏洞。

# 更改
* 优化了使用水梯越过墙的过程。
* 优化了在[栅栏](栅栏.md)中的[生物](生物.md)的寻路机制。
* 更改了一些[音效](音效.md)的音量。
* 优化了存档中的[区块](区块.md)索引。
* 重新加入了[恶魂](恶魂.md)的音效。

# 修复

* *其他**
* 加入一个暂停运行的服务器使得游戏崩溃。
* 部分按钮在按下时不再回弹。
* 无法在颠倒放置的楼梯或台阶上放置花盆。
* 创建旧世界类型的世界时游戏崩溃。
* 玩家在雪层上跳跃时不会播放音效。
* 客户端里进入下界传送门在加载世界时出错。
* 第三人称下玩家手持部分物品会出现渲染错误。
* 僵尸的步行音效不正确。
* 无法在多人游戏里钓鱼。
* 浮漂消失在熔岩里。</onlyinclude>
