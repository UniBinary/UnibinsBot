# Java版Indev 0.31 20091231-1856

*页面ID: 171774* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2009年12月31日18:56（UTC）<ref>[Adura的IRC记录](#logs.md): "(13:56:48) <Notch> indev = updated"</ref>，加入了[物品栏](物品栏.md)并移除了[创造模式](创造模式.md)。<ref></ref>

# 新内容
# = 游戏内容 =
* *[物品栏](物品栏.md)**<ref name="additions and mouse control">[Adura的IRC记录](#logs.md): "(13:57:21) <Notch> you can use the inventory and F7, but you can't look around"</ref>
* 玩家统计在物品栏界面中作为占位符被加入。
* [拉娜](拉娜.md)在物品栏界面作为占位符来展示玩家的形象。

# = 常规 =
* *[控制](控制.md)**
* 按可以拍摄等距水平渲染截图。<ref name="additions and mouse control"/>

# 更改
# = 方块 =
* *[火把](火把.md)**
* 更改了纹理。

# = 游戏内容 =
* *[游戏模式](游戏模式.md)**
* 游戏现在默认为[生存模式](生存模式.md)。

* *常规**
* [玩家](玩家.md)出生时带有99个[圆石](圆石.md)、[TNT](TNT.md)、[书架](书架.md)和[树叶](树叶.md)。<ref></ref>
* 更改了快捷栏中方块的阴影。

# = 世界生成 =
* *[树木](树木.md)**
* 周围不再会出现[泥土](泥土.md)。</onlyinclude>
