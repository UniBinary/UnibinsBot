# 铜栏杆

*页面ID: 161803* | *来源: Minecraft Wiki*

* *铜栏杆（Copper Bars）**是一种与[玻璃板](玻璃板.md)性质类似的装饰性[方块](方块.md)。

# 生成
铜栏杆不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘铜栏杆的合适工具是镐。铜栏杆需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

铜栏杆被破坏后会掉落自身。

# 用途
# = 放置 =
铜栏杆在周围没有连接支撑面完整的方块表面（[潜影盒](潜影盒.md)和、除外）、[墙](墙.md)、[玻璃板](玻璃板.md)、其他铜栏杆或[铁栏杆](铁栏杆.md)时，呈细长的柱状；否则，它们会根据周围方块的连接情况呈平面矩形、[text-top|class=pixel-image|link=](File:Curve.png.md)形、 [text-top|class=pixel-image|link=](File:T junction.png.md)形或[text-top|class=pixel-image|link=](File:Cross.png.md)形。

# = 氧化 =

铜栏杆受氧化机制影响，能够在不同变种之间转化。
