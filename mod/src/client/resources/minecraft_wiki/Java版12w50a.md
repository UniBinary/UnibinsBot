# Java版12w50a

*页面ID: 33300* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w50a**是[Java版1.4.6](Java版1.4.6.md)的第2个快照，发布于2012年12月13日<ref></ref>。

# 新内容
# = 方块 =
* *[箱子](箱子.md)**
* 加入了，和纹理。
* * 将箱子的纹理改成类似于一个红色礼物。
* * 将大箱子的纹理改成类似于一个绿色礼物。
* * 是一个未使用的纹理。Dinnerbone说他把这个文件以红鲱鱼形式加入了。<ref></ref>
* * 箱子将在12月25日使用这些纹理。

* *[蜘蛛网](蜘蛛网.md)**
* 现在可使用[精准采集](精准采集.md)魔咒获得。

# = 物品 =
* *[剪刀](剪刀.md)**
* 精准采集魔咒现在能通过[铁砧](铁砧.md)应用到剪刀上。

* *[工具](工具.md)**
* 在快捷栏上替换物品时会出现物品的名字。
* * 已经重命名的项目将显示更改后的名称。
* * 如想禁用，打开，然后将<code>heldItemTooltips</code>改为<code>false</code>。

# = 生物 =
* *[村民](村民.md)**
* 村民现在会出售附魔书。

# = 世界生成 =
* *[地牢](地牢.md)**
* 将[附魔书](附魔书.md)加入至地牢的[箱子](箱子.md)内。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* 加入了“荆棘”魔咒。
* * 当生物攻击玩家时能对其给予伤害，此魔咒能附到盔甲上。

# 更改
# = 物品 =
* *常规**
* 物品实体在高品质视频模式中被渲染为3D物品。
* * 这包括在物品展示栏内的物品。
* 掉落在地上的物品现在会显示它们的魔咒。

* *[烟花火箭](烟花火箭.md)**
* 调整了烟花火箭的效果和声音。

# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 从创造模式物品栏中移除[烟花火箭](烟花火箭.md)。

* *[魔咒](魔咒.md)**
* 基本的保护魔咒的保护效果现已不如其他全部保护魔咒合起来有效。
* 耐久魔咒能通过附魔书来应用到所有有耐久值的物品。

# = 常规 =
* *[控制](控制.md)**
* 当按下时，玩家会掉落整组物品而非一个。

* *警告**
* 对仍在使用PowerPC或Java 5（Java 1.5）的用户添加了一个提醒/警告。
* * Mojang计划在1.6停止对Java 5的支持。<ref>http://help.mojang.com/customer/portal/articles/884921</ref> 这是由于LWJGL的最新版本不再支持Java 5，PowerPC也不再被Apple支持以与Java 6或更新版本兼容。<ref></ref>
