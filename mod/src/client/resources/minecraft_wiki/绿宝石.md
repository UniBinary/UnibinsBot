# 绿宝石

*页面ID: 8068* | *来源: Minecraft Wiki*

* *绿宝石（Emerald）**是一种主要用作[交易](交易.md)货币的物品。

# 获取
# = 挖掘 =
[绿宝石矿石](绿宝石矿石.md)或[深层绿宝石矿石](深层绿宝石矿石.md)被[铁镐](铁镐.md)或品质更好的镐挖掘后会掉落1个绿宝石。使用带有[时运](时运.md)魔咒的镐挖掘会每等级增加1个最大掉落数量，时运III最多会掉落4个绿宝石。如果使用带有[精准采集](精准采集.md)魔咒的镐挖掘，它会掉落自身而非绿宝石。

# = 交易 =

通过与[村民](村民.md)和[流浪商人](流浪商人.md)交易可以获得绿宝石。

# = 生物掉落物 =
成年[狐狸](狐狸.md)自然生成时有1%的概率在嘴里叼着绿宝石，且其死亡时叼着的绿宝石总是会掉落。

# 用途
# = 交易 =

绿宝石主要用作与[村民](村民.md)和[流浪商人](流浪商人.md)交易的货币。

# = 信标 =
绿宝石可用于从[信标](信标.md)中选择并激活[状态效果](状态效果.md)。玩家必须选择一种可用的状态效果，然后在物品槽中放入一个绿宝石。

绿宝石可以代替[铁锭](铁锭.md)、[金锭](金锭.md)、[钻石](钻石.md)或[下界合金锭](下界合金锭.md)为信标选择状态效果。
