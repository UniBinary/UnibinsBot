* *13w01b**是[Java版1.5](Java版1.5.md)的第2个快照，发布于2013年1月4日<ref></ref>，发布以修复[13w01a](13w01a.md)快照中的一些漏洞和崩溃。

# 更改
# = 方块 =
* *[箱子](箱子.md)**
* 当一个[红石比较器](红石比较器.md)被直接放置时，所有的容器都会输出一个红石信号。它的强度取决于容器的充满程度。<ref></ref>
* * 这也适用于陷阱箱，这意味着它可以同时提供两个不同原因的红石信号。

* *[漏斗](漏斗.md)**
* 现在可以在铁轨上点击[漏斗](漏斗.md)来清空[运输矿车](运输矿车.md)。

* *[上锁的箱子](上锁的箱子.md)**
* 纹理加入了额外的红石块的纹理。
