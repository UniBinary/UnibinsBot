# 苍白垂须

*页面ID: 126845* | *来源: Minecraft Wiki*

* *苍白垂须（Pale Hanging Moss）**是一种生成于[苍白之园](苍白之园.md)生物群系的方块。

# 生成
# = 自然生成 =
苍白垂须会自然生成于[苍白之园](苍白之园.md)生物群系中[苍白橡树](苍白橡树.md)的树干和树叶下方。

# 获取
# = 交易 =

# 破坏
没有工具可以加速对苍白垂须的挖掘。<ref></ref>

没有被[剪刀](剪刀.md)或具有[精准采集](精准采集.md)的工具挖掘破坏时，苍白垂须被破坏后不会掉落。

被剪刀或具有精准采集的工具挖掘破坏时，苍白垂须被破坏后会掉落自身。

# 用途
# = 环境音效 =
当放置在[苍白橡木原木](苍白橡木原木.md)]]、[去皮苍白橡木原木](去皮苍白橡木原木.md)、[去皮苍白橡木](去皮苍白橡木.md)}}或[苍白橡树树叶](苍白橡树树叶.md)下方时，苍白垂须会发出特殊的环境音效。

# = 骨粉 =
对苍白垂须使用骨粉会使其向下生长一格。

# = 堆肥 =
将苍白垂须放入[堆肥桶](堆肥桶.md)会有30%的概率增加一层堆肥层。

# 你知道吗
* 据开发者所述，苍白垂须的灵感来源于[松萝凤梨](wzh:松萝凤梨.md)<ref></ref>，英文中俗称“西班牙藓”（Spanish moss），也被称作“”（Grandpa's beard）。但这种植物与[苔藓](苔藓.md)（Moss）并无关联。
