* *Minecraft 4k**是[Minecraft](Minecraft.md)专为Java 4K游戏编程大赛（Java 4K Game Programming Contest）而制作的特殊版本。<ref name="m4k"></ref>

2009年12月2日发布的初版比Minecraft已公开发布的任何其他版本（包含可从[Java版](Java版.md)启动器获得的[pre-Classic](Java版pre-Classic.md)版）更加受限：只能移动和跳跃，只有一种没有[纹理](纹理.md)的方块，并且需要按住左键才能移动视角。随后12月4日发布的更新修改了控制、添加了宽支持、更多方块以及放置和破坏方块的功能，但与当时的正式版本相比，游戏功能仍然十分受限。<ref>http://www.java-gaming.org/topics/minecraft-4k-very-early-build/21638/msg/177585/view.html#msg177585</ref>

原本的和[官方](https://www.mojang.com/notch/j4k/minecraft4k/)的Minecraft 4k链接已于2014年11月被移除。该页面仍然可以使用[页面存档](https://web.archive.org/web/20141101124251/https://mojang.com/notch/j4k/minecraft4k/)，但[小程序](wzh:Java applet.md)不会加载。

# 游戏内容
# = 常规 =
玩家能够放置和破坏[方块](方块.md)。玩家唯一能够放置的方块是[草方块](草方块.md)。[树叶](树叶.md)并不会因原木的缺失而消失。

# = 世界 =
每次游戏加载时都会生成相同的64×64×63大小的世界。游戏中存在的方块只有[空气](空气.md)、[草方块](草方块.md)、[泥土](泥土.md)、[石头](石头.md)、[红砖块](红砖块.md)、[木头](原木.md)和[树叶](树叶.md)，这些方块散布在整个世界中。不存在[实体](实体.md)等游戏机制。

在一堵隐形的墙环绕着世界，防止玩家走出地图以外，这与[隐形基岩](隐形基岩.md)类似。在2009年12月2日的初版并没有隐形的墙。

# = 控制 =
玩家可以使用默认的键进行移动和键进行跳跃。

鼠标左键和中键用于放置方块，右键能用于破坏方块。类似于中的“电影视角”，移动鼠标能使屏幕平滑移动。

镜头行为与Minecraft不同。其之后在玩家把光标从游戏的[视口](Wikipedia:viewport.md)中心移动到一个比较远的距离时镜头才会移动。由光标选择世界中的方块而不是视口中心。

此版本没有任何的菜单屏幕或[HUD](HUD.md)。

# 图像
在低分辨率的情况下，图像会被游戏渲染为像素点。每当在高分辨率运行时，游戏不会适当地按分辨率缩放，图像仍然是密密麻麻的像素点。方块的纹理类似于[Classic](Java版Classic.md)版，其中最像那时候的[Classic 0.30（创造模式）](Classic 0.30（创造模式）.md)。这些方块比它们在对应的版本中要更多，尽管一些方块特别是石头有很大的不同。由于缺乏天空盒子，天空是黑色的。

当光标移到一个方块上时，这个方块会用粗白的线条突出，与Minecraft中细灰线的突出选择的方块不同。

# 方块
在2009年12月2日的初版游戏版本只有一种无纹理的“XOR”方块，这是Minecraft 4k的第一个版本仅有的非空气方块，方块ID为1。

在2009年12月4日Notch发布的第二个版本中，方块ID使用4 bit存储，因此产生了16个可能的ID，其中大部分空余ID由纹理稍有不同的泥土替代，而“XOR”方块被草方块替代。

游戏中一共有16个方块ID。然而并不是所有的方块ID对应不同的方块，游戏内可用的方块只有几种，剩下皆为泥土。
