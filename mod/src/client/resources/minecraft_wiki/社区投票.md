# 社区投票

*页面ID: 163398* | *来源: Minecraft Wiki*

* *社区投票（Community Vote）**是在[Minecraft年度活动](Minecraft年度活动.md)中举行的社区活动，包括**生物投票（Mob Vote）**和**生物群系投票（Biome Vote）**。

# 历史
在[Minecraft Live 2022](Minecraft Live 2022.md)之前，投票是在[Twitter上的Minecraft官方页面](https://twitter.com/Minecraft)的现场直播期间进行的，投票结果在现场直播过程中公布。

从Minecraft Live 2022开始，投票在节目直播前进行，玩家们可以从[基岩版](基岩版.md)的[服务器](活动服务器.md)、[Minecraft启动器](Minecraft启动器.md)和[minecraft.net](minecraft.net.md)这三个地方进行投票。在[2023年生物投票](Minecraft Live 2023#生物投票.md)中，玩家们还可以在[中国版](中国版.md)启动器中进行投票。

2024年9月9日，官方宣布停止社区投票，使[Minecraft Live 2023](Minecraft Live 2023.md)成为最后一次进行生物投票的官方Minecraft活动。<ref></ref>

# 结果
社区投票的胜出者将会在未来的更新中加入游戏，而落选者会被抛弃或暂时搁置。

2017年生物投票中落选的生物D最终在 [1.14.1.0](MCD:1.14.1.0.md)中作为小Boss加入，名为[野火](MCD:野火.md)（Wildfire）。

2019年生物群系投票中落选的沼泽最终在[荒野更新](荒野更新.md)中更新。

2021年生物投票中落选的[铜傀儡](铜傀儡.md)最终在[铜器时代](铜器时代.md)小更新中更新。

# 服务器活动

在2022和2023年的生物投票中，玩家们可以从[基岩版](基岩版.md)的[活动服务器](活动服务器.md)中参加投票。

# 你知道吗
* 在2018年9月，中国版在[MINECON Earth 2018](MINECON Earth 2018.md)正式开始前举行了一次“[国宝投票活动](MCCN:媒体#国宝投票.md)”，并称胜出者会被加入游戏。
* 2016年7月26日，[Jeb](Jeb.md)在推特举行了一次投票，让用户决定是将现实中的[](wzh:大羊驼.md)（Llama）还是[羊-{}-驼](wzh:羊驼.md)（Alpaca）加入游戏。最终二者得票分别为58%和42%。<ref></ref>
* 在[MINECON Earth 2018](MINECON Earth 2018.md)直播中，Jeb透露猫的另一种新纹理将由社区玩家选出后加入。最终，[GoodTimesWithScar](https://www.youtube.com/user/GoodTimesWithScar)的猫“Jellie”获胜，其皮肤在[Java版1.14](Java版1.14.md)和[基岩版1.10.0](基岩版1.10.0.md)中加入。<ref></ref><ref></ref><ref></ref>
