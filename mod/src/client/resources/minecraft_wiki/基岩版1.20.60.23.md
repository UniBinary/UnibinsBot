# 基岩版1.20.60.23

*页面ID: 110317* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.60.23**（ChromeOS/Android）、**Preview 1.20.60.23**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.60](基岩版1.20.60.md)的第4个测试版，发布于2023年12月13日<ref></ref><ref></ref>，在[实验性玩法](实验性玩法.md)中加入了[犰狳](犰狳.md)、[犰狳鳞甲](犰狳鳞甲.md)和[狼铠](狼铠.md)，更新了编辑世界屏幕，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“犰狳和狼铠”子选项。
* * 用于启用[犰狳](犰狳.md)和[狼铠](狼铠.md)相关特性。

* *[Realms](Realms Plus.md)**
* 加入了Realms故事功能。
* * 新的Realm社交中心，包括下列功能：
* ** “”
* *** 用于与Realm成员分享最精彩的游戏时刻。
* ** “时间线”
* *** 用于查看其他Realm成员何时在Realm上进行游戏。
* ** “成员”选项卡
* *** 用于显示所有Realm成员及其权限等级的列表。
* * 目前仅测试版本可用。

# 更改
# = 方块 =
* *[向日葵](向日葵.md)、[丁香](丁香.md)、[玫瑰丛](玫瑰丛.md)和[牡丹](牡丹.md)**
* 现在使用带有[时运](时运.md)的[附魔书](附魔书.md)挖掘时不再会增加物品的掉落概率。

# = 常规 =
* *图形**
* 为Xbox Series主机加入了对4K分辨率的支持。

* *用户界面**
* 现在可以通过新的游玩屏幕的好友抽屉式菜单中的加入按钮来加入好友的世界。

* *编辑世界屏幕**
* 更新了编辑世界屏幕。
* * 优化了使用体验。
* * 加入了更多描述。
* * 观感现在与新的[创建新的世界](创建新的世界.md)屏幕相匹配。
* * 目前仅对部分玩家推出。

# = 技术性 =
* *[附加包](附加包.md)和脚本引擎**
* 为方块组件加入了标识符。
* * 标识符会产生一个居中的1×1×1立方体。
* * 配合带有的组件一同使用时，该标识符能够启用组件中包含的仅渲染功能，包括：
* ** 原版和自定义毗邻完整方块的遮挡面。
* ** 毗邻原版和自定义毗邻完整方块以提升渲染性能的剔除面。
* 加入了用以帮助创作者识别每个方块的状态位或置换已达到或超过计数的内容的内容日志错误。（）

* *常规**
* 更新了文档中原版方块状态的列出值。

* *API**
* 为原版元数据生成加入了生物群系注册表的生物群系名称和枚举。

* *组件**
* 为组件加入了字段。
* * 允许指定活动对象可以被喂食时的条件。

* *[基岩版编辑器](基岩版编辑器.md)**
* 现在所选工具中的的默认方块是。
* 脚本化属性窗格现在会在达到一定高度时变得可滚动。
* 编辑器游玩测试窗格现在支持在测试存档时设置一天的时间和天气，以及对布局做出小调整。
* * 编辑器游玩窗格支持Minecraft时间（0-23999）和24小时制时间（0:00-23:59）。
* 为脚本加入了新的绑定和支持，以能够将作为负载推送到事务堆栈，并注册一组会在事务系统收到撤销或重做事件时接收负载的处理程序函数。
* 加入了浏览记录系统。
* 为加入了导出，以便其被用于内部和外部创作者扩展。
* 加入了新的线条工具。
* 编辑器UI现在会根据屏幕分辨率而非游戏窗口大小进行缩放。
* 属性选项现在会在游戏重新加载时保留原来的值。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“”、“犰狳和狼铠”、“”、“即将推出的创作者功能”、“测试版 API”、“Molang 功能”和“”子选项后才可使用。

# = 方块 =
* *[铜格栅](铜格栅.md)**
* 修复了涂蜡的铜格栅的透明度问题。（）

* *[发射器](发射器.md)**
* 现在可以使用刷子刷扫犰狳以获得犰狳鳞甲。

* *[试炼刷怪笼](试炼刷怪笼.md)**
* 现在每次试炼只会为所有玩家随机抽取一次战利品表。

# = 物品 =
* *[犰狳鳞甲](犰狳鳞甲.md)**
* 由犰狳掉落，可用于合成狼铠。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了犰狳刷怪蛋。

* *[狼铠](狼铠.md)**
* 对已驯服的成年[狼](狼.md)狼铠可为其穿戴，[剪刀](剪刀.md)可卸下狼铠。
* * 仅可由狼的主人为其装备和卸下。
* 可为狼提供[护甲值](护甲值.md)。

# = 生物 =
* *[犰狳](犰狳.md)**
* [Minecraft Live 2023](Minecraft Live 2023.md)生物投票的获胜生物，属于友好生物。
* 自然生成于[热带草原](热带草原.md)、[热带高原](热带高原.md)和[风袭热带草原](风袭热带草原.md)生物群系。
* 有生命值。
* 可以使用[蜘蛛眼](蜘蛛眼.md)来繁殖。
* 被玩家或驯服的狼杀死后会掉落1-3点经验值。
* * 杀死幼年犰狳不会掉落任何物品和经验。
* 每隔5-10分钟掉落一个犰狳鳞甲。
* 使用[刷子](刷子.md)刷扫犰狳则会立即掉落一个犰狳鳞甲，同时消耗刷子16点耐久度。
* 遇到下列威胁时会在原地蜷缩成一团：
* * 正在疾跑的玩家
* * [骑乘](骑乘.md)在实体上的玩家
* * [亡灵生物](亡灵生物.md)
* 威胁离开3秒以后不再蜷缩。
* 处于逃窜状态、在水中、在空中或被[拴绳](拴绳.md)拴住时无法蜷缩。

* *[旋风人](旋风人.md)**
* 调整了渲染。
* 更改了已有的音效。
* 加入了空闲时旋转和跳跃前蓄力的音效。

# = 非生物实体 =
* *[风弹](风弹（实体）.md)**
* 调整了渲染。

# = 世界生成 =
* *[试炼密室](试炼密室.md)**
* 现在会生成[涂蜡的斑驳铜灯](涂蜡的斑驳铜灯.md)、[涂蜡的锈蚀铜灯](涂蜡的锈蚀铜灯.md)和[涂蜡的氧化铜灯](涂蜡的氧化铜灯.md)，而不是[斑驳的铜灯](斑驳的铜灯.md)、[锈蚀的铜灯](锈蚀的铜灯.md)和[氧化的铜灯](氧化的铜灯.md)。（）

* *图形**
* 现在启用延迟渲染预览功能后玩家的身体会在第一人称视角下投射阴影。
* * 部分手持物品不会投射阴影。
* 在启用延迟渲染预览功能的情况下进入支持PBR的世界时，Android平台上的加载屏幕不再会变黑。
* 漏斗矿车中的漏斗在启用延迟渲染预览时不再会出现幽灵图形缺陷。

# 修复
* *游戏内容**
* 修复了在不同维度之间频繁切换时发生的崩溃。（）
* 修复了在Y=62等特定高度进行交互时，玩家在某些情况下会错误受到摔落伤害的问题。（）
* 再次修复了玩家站在方块上放置方块时偶尔会错误受到摔落伤害的问题。（）
* 修复了在明显没有从其上摔落下来的方块支柱附近时，玩家在某些情况下可能会错误受到摔落伤害的问题。（）

* *生物**
* 修复了僵尸等生物无法捡起地上的整组物品的问题。</onlyinclude>
