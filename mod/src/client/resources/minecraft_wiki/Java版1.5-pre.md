# Java版1.5-pre

*页面ID: 33502* | *来源: Minecraft Wiki*

<onlyinclude>
* *1.5（预发布版）**是[Java版1.5](Java版1.5.md)的唯一一个预发布版，发布于2013年3月7日<ref></ref>，修复了一些漏洞。

此预发布版后来被重新上传，成为完整的1.5正式版版本。

一个该预发布版的实验性版本在2013年3月12日被[Dinnerbone](Nathan Adams.md)发布在[漏洞追踪器](漏洞追踪器.md) ，以尝试修复一个白线漏洞。<ref>[MC-1794 (comment 51987)](https://bugs.mojang.com/browse/MC-1794?focusedCommentId=51987#comment-51987) – [Nathan Adams](Nathan Adams.md) on Mojira, March 12, 2013.</ref>

# 你知道吗
* 最初Mojang计划于2013年2月28日发布[红石更新](红石更新.md)的预发布版，并且在三月第一周正式发布该更新。<ref>http://www.mojang.com/2013/02/minecraft-snapshot-13w09a/</ref>但是，Mojang为了能在发布前修复更多的漏洞，保证游戏的稳定性，导致了预发布版的推迟。<ref></ref><ref>http://mojang.com/2013/03/minecraft-snapshot-13w09c/</ref>
