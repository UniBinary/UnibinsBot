# 雕纹红砂岩

*页面ID: 99476* | *来源: Minecraft Wiki*

* *雕纹红砂岩（Chiseled Red Sandstone）**是[红砂岩](红砂岩.md)制作的装饰性方块，四个侧面上都有一个[凋灵](凋灵.md)的图案。

# 生成
雕纹红砂岩不会生成在世界中。

# 破坏
挖掘雕纹红砂岩的合适工具是镐。雕纹红砂岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

雕纹红砂岩被破坏后会掉落自身。
