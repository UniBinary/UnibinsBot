# Minecraft体验版

*页面ID: 26024* | *来源: Minecraft Wiki*

可免费游玩的官方**Minecraft体验版（Minecraft demo）**包括：

* Minecraft当前版本的[演示模式](演示模式.md)，可供未购买游戏的玩家免费尝试。在单个世界中仅能游玩100分钟。
* [原主机版](原主机版.md)中的[教程世界](原主机版教程.md)。
* *[PC Gamer演示版](PC Gamer演示版.md)* （历史版本） - 拥有诸多限制的[Beta 1.3](Java版Beta 1.3.md)版Minecraft。同样只能于单个世界中游玩100分钟。
* [Java版Classic](Java版Classic.md) （历史版本） - Minecraft的初期开发版本，可以单人或多人模式免费游玩。
* *[Minecraft 4k](Minecraft 4k.md)* （独立于Minecraft的创作） - 内容非常有限的Minecraft模拟游戏，使用[Java 4K](wikipedia:Java 4K.md)开发。正如其名，体积小于4k。
