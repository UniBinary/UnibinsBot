# 蓄风

*页面ID: 115116* | *来源: Minecraft Wiki*

* *蓄风（Wind Charged）**是一种让生物[死亡](死亡.md)时产生[风爆](爆炸#风爆.md)的[状态效果](状态效果.md)。

# 效果
受影响的生物死亡时会产生[风爆](爆炸#风爆.md)。风爆会在尸体消失后产生；风爆会在生物死亡时立即产生。

# 来源
激活的[不祥试炼刷怪笼](不祥试炼刷怪笼.md)每在玩家或距离不祥试炼刷怪笼14格内的生物头顶生成不祥之物生成器来随机选取生成带有此状态效果的[滞留药水](滞留药水.md)。
