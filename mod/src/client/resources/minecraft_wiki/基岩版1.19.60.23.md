# 基岩版1.19.60.23

*页面ID: 100521* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.60.23**（Android）、**Preview 1.19.60.23**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.60](基岩版1.19.60.md)的第3个测试版，发布于2022年12月7日至8日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[营火](营火.md)**
* 不再会引燃站在其上的实体。

* *[重生锚](重生锚.md)**
* 使用[精准采集](精准采集.md)附魔镐开采或功能获得的重生锚不再会保存其能量。

* *[幽匿尖啸体](幽匿尖啸体.md)**
* 将激活音效的衰减距离更改为32格。

# = 技术性 =
* *组件**
* 扩展了组件，以定义多个可指定不同弹射物定义和条件过滤器的弹射物。
* 向组件公开了更多字段，以允许对弹射物进行更多自定义，例如投掷力度、音效，以及定义攻击是否为魔法攻击。

* *[Molang](Molang.md)**
* 修复了Molang中的任意值被除以动态确定的负数变量时会导致被除以正数值（绝对值）的漏洞。
* * 该Molang版本化更改仅对使用为1.19.60或更高版本的包有效。

* *弹射物**
* 能够传送拥有者的弹射物不再会在拥有者睡觉时将其传送走。（）

# 修复
* *方块**
* 使用精准采集附魔镐开采或选取方块功能获得的重生锚不再会保存其能量。（）
* 脚手架现在会在其下方方块被破坏时显示粒子效果并产生振动。（）
* 现在幽匿尖啸体发出的尖啸声能够在32格距离之外听见。（）

* *游戏内容**
* 放置竹笋时不再能够替换掉双层植物。（）
* 营火不再会引燃玩家和生物。（）
* 营火不再会摧毁矿车和船。（）
* 末影珍珠不再能够将睡觉的玩家传送走。（）

* *图形**
* 骑着马、驴或骡的玩家不再可以在2格高空间的边缘透视地形。（）

* *物品**
* 现在当需要方块支撑的方块放置在不完整方块上或浮在空中时，地图上会正确显示对应方块。（）

* *生物**
* 劫掠兽现在能够攻击到泥巴之类的不完整方块上的生物。（）
* 现在生成在水体外的发光鱿鱼会产生粒子效果。

* *用户界面**
* 修复了与结构方块UI相关的问题，因此现在仅需使用键盘即可存取Y字段。（）</onlyinclude>
