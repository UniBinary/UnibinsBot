# 闪长岩楼梯

*页面ID: 44273* | *来源: Minecraft Wiki*

* *闪长岩楼梯（Diorite Stairs）**是[闪长岩](闪长岩.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
闪长岩楼梯会自然生成于雪原[村庄](村庄.md)。

# 破坏
挖掘闪长岩楼梯的合适工具是镐。闪长岩楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

闪长岩楼梯被破坏后会掉落自身。
