# 携带版0.14.0.b4

*页面ID: 19913* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.14.0 alpha build 4**是[v0.14.0 alpha](携带版0.14.0.md)的第4个测试版，发布于2016年2月2日<ref>http://pocketbeta.minecraft.net/2016/02/changelog-for-014-build-4.html?m=0</ref>，修复了一些漏洞。

# 更改
* 大型蕨现在在任何寒冷生物群系生成。
* 大型针叶林中生成的苔石堆更圆了。
* 玩家点击生成的[船](船.md)的位置更精确。
* [苦力怕](苦力怕.md)的爆炸威力更大更连贯。
* 自然生成的[村民](村民.md)的职业更多样。
* 更新了语言翻译。

# 修复
* *[修复了25个漏洞](https://bugs.mojang.com/browse/MCPE/fixforversion/15502)**
* 游戏暂停时，重新进入游戏会使得游戏崩溃。
* 试图将物品展示框放在箱子上时游戏崩溃。
* 在破坏红石脉冲电路上的红石火把使得游戏崩溃。
* 安卓设备下的系统栏现在会正确隐藏。
* 修复了炼药锅状态不同步的漏洞。
* 修复了死循环漏洞。
* 下船时，玩家的身体会陷进船里。
* 修复了漏斗的光照漏洞。
* 在生物的寻路路径上放置台阶会使其原地转圈。
* 物品展示框不会记住同一个物品的旋转角度。
* 漏斗循环红石钟现在会给予开关信号。
* 红砂岩使用了错误的音效。
* 矿车的装载物是黑色的。
* 物品展示框展示的物品不可见。
* 修复了圆石墙的纹理显示错误。
* 移除了部分物品多余的黑色像素。
* 在玩家顶部的苦力怕不会爆炸。
* 无法喂养幼年豹猫。
* 僵尸会被瞬间伤害药水所伤害。
* 在重新加载世界后，门的红石开关状态不会被保存。
* 语言界面显示错误。
* 破坏两格高的方块时，粒子只会在一半部分显示。
* 大型陷阱箱不会给予红石信号。
* 在远处查看装有地图的物品展示框时不再闪烁。
* 红石线的纹理拉伸。</onlyinclude>
