# 教育版1.21.05

*页面ID: 125904* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21.05**是的一次次要更新，发布于2024年9月3日<ref></ref>，为macOS和iOS/iPadOS平台加入了对云世界备份的支持，并修复了一些漏洞。

# 更改
# = 常规 =
* *云世界备份与上传**
* 现在macOS和iOS/iPadOS平台支持在OneDrive上备份云世界。

# 修复
* 优化了编写代码时的性能。
* 修复了各种性能与稳定性漏洞。
