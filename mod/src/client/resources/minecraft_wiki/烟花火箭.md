# 烟花火箭

*页面ID: 9383* | *来源: Minecraft Wiki*

{{redirect|火-{箭}-|着火的箭|箭#着火|魔咒|火矢}}

* *烟花火箭（Firework Rocket）**是一种能够生成大量[粒子](粒子.md)、能对生物造成伤害的[物品](物品.md)和[实体](实体.md)，可以用作[弩](弩.md)的弹药或用来加速正在使用[鞘翅](鞘翅.md)滑翔的玩家。

# 生成
当[袭击](袭击.md)以胜利结束时，[村民](村民.md)会在露天处发射有1级飞行时间和1个“喷发状”随机颜色的[烟火之星](烟火之星.md)的烟花火箭来庆祝，这也是村民唯一的攻击方式。

# 获取
烟花火箭能通过合成和[命令](命令.md)获取。没有爆裂效果的烟花火箭也可在[创造模式物品栏](创造模式物品栏.md)中获得。

# 用途
# = 发射烟花 =
烟花火箭可以在方块上按下键进行燃放，也可被[发射器](发射器.md)和[弩](弩.md)发射。

# = 滑翔 =
当玩家使用[鞘翅](鞘翅.md)滑翔时，手持烟花火箭按下键可以加快滑翔速度。加速的持续时间和强度取决于烟花火箭的飞行时间。如果所用的烟花火箭合成时使用了[烟火之星](烟火之星.md)，烟花火箭会爆裂，使玩家受到伤害。

滑翔的玩家使用烟花火箭后会生成一个不可见的烟花火箭实体，此烟花火箭实体始终位于玩家持有烟花火箭的手的一侧，玩家会和其同步移动。

# = 弩 =
玩家可以使用[弩](弩.md)来发射烟花火箭进行远程攻击，但如果烟花火箭没有爆裂效果，它不会造成任何伤害。用多个烟火之星进行合成可以增加伤害。附魔[多重射击](多重射击.md)的弩可以单次射出3支效果相同的烟花火箭，但[穿透](穿透.md)魔咒并不能使烟花火箭穿过实体。

如果由弩发射的烟花火箭击中实体，烟花火箭会无视飞行持续时间而瞬间爆裂。这样做只会让烟花火箭穿过实体而爆裂<ref></ref>，且撞到方块时会在其上滑行，因此玩家需要精准把控烟花火箭的飞行时间和与目标的距离。

# 行为

烟花火箭点燃后会向上飞。它的飞行轨迹在水平方向上会随机偏移。没有烟火之星的烟花火箭在飞行[一段时间](#持续时间和方向.md)或后会消失，碰到方块上会在方块上继续滑行，但在碰到方块的同时碰到实体不会消失；有烟火之星的烟花在飞行[一段时间](#持续时间和方向.md)或后会爆裂，并根据合成材料的不同产生各种色彩缤纷的爆裂效果。如果合成时使用多个烟火之星，所有效果将会同时出现。

烟花火箭的爆裂会造成[爆炸伤害](伤害#爆炸伤害.md)。烟花火箭合成时每增加一个烟火之星，就会额外造成伤害。一个烟花火箭最多能加入七个烟火之星，此时能造成点伤害。尽管并非[爆炸](爆炸.md)现象，烟花火箭造成爆炸伤害，会受到[爆炸保护](爆炸保护.md)的伤害减少效果，但其伤害值不像爆炸那样总是受到难度影响。

烟花火箭引爆一段时间后玩家才会听到声音，以此来模拟真实的烟花效果，但这声音的传播速度比现实的声音慢得多。<ref></ref><ref></ref>

烟花火箭的爆裂不会摧毁方块、点燃[TNT](TNT.md)或摧毁[末地水晶](末地水晶.md)。

烟花粒子最多只能有4000个。如果超出了限制，在出现新的粒子之前会移除最旧的粒子，导致烟花的质量或持续时间被降低。一个烟花火箭最多只能有3个踪迹，超过3个会浪费钻石、烟火之星或其他烟花火箭。以下是每个烟花的粒子：

闪烁效果增加2个粒子。

就像大部分的实体，烟花火箭会被[水](水.md)或[爆炸](爆炸.md)移动。烟花火箭飞行时遇到[下界传送门](下界传送门.md)可能会传送。

# = 持续时间和方向 =
合成烟花火箭时加入越多火药，烟花火箭的平均飞行距离就会越远，每次合成最多加入三份火药。火药的数量在物品的信息栏中标记为“飞行时间”，飞行时间的单位为秒（20刻）。烟花飞行的距离会根据其使用的火药量在一个射程范围中随机判定。

在这个射程范围中，烟花火箭的爆裂点分布概率存在以下规律：若把射程四等分，通常在前三个部分都有一个范围的概率明显高于其他范围，也就是其爆裂概率类似于波函数图像。第一部分、第二部分和第三部分各有一个波峰，其中第二部分波峰最高，另外两个波峰高度近似，第四部分概率渐归于零。

简单来说，烟花火箭较容易在其1/4，2/4，3/4射程处爆裂，其中2/4射程处爆裂概率最高，3/4射程以外概率越来越低。

烟花火箭飞行的距离在加入1个火药时是8.40-19.84格，2个火药时是18.60-34.44格，3个火药时是32.80-53.04格。

烟花火箭的飞行距离遵循以下规律：

* 加入1个火药时为14-30格，其中1/4处波峰为14-16格，2/4处波峰为18-22格，3/4处波峰为24-26格；
* 加入2个火药时为29-63格，其中1/4处波峰为31-35格，2/4处波峰为39-44格，3/4处波峰为50-52格；
* 加入3个火药时为67-116格。

当烟花火箭生成时，它会具有0.05的垂直速度和一个随机的X轴和Z轴的运动速度（数值接近零，标准偏差为0.001）。飞行过程中，每经过一刻，烟花的X轴和Z轴的横向运动速度就会变为上一刻1.15倍，。烟花的生命周期为<code>-{}-10 &times; (*合成时所用的火药* + 1) + *0至5的随机数* + *0至6的随机数*</code>[刻](刻.md)。生命周期结束后，烟花火箭会立即爆裂。

在流动的水下燃放的烟花火箭会朝不同方向飞行，随后其运动方向会迅速地朝水平方向弯曲，传播距离会增加到比高度更远的一点。

# 你知道吗
* 在[木质压力板](木质压力板.md)上点燃烟花火箭时，压力板会激活。由发射器弹到木质压力板上然后发射的烟花火箭不会激活压力板。
* [Jeb](Jeb.md)加入烟花的灵感来源于2012新年。<ref></ref>
* 如果把一个烟花火箭射入[传送门](传送门.md)，被传送的烟花火箭将失去爆裂性并横着飞上去消失。
* 一共有约2&times;10种不同的烟花火箭，这个数字远比Java版和基岩版的世界种子数加起来还要多。
