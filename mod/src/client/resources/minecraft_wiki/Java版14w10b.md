# Java版14w10b

*页面ID: 33896* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w10b**是[Java版1.8](Java版1.8.md)的第15个快照，发布于2014年3月6日<ref></ref>，发布以修复[14w10a](14w10a.md)里的漏洞和崩溃。

# 修复
命令时，显示的错误信息显示了不正确的选项。
|50232|小麦显示为无效纹理。
|50233|双层石台阶显示为无效纹理。
|50241|不能为离线玩家或“假”玩家添加或设置计分值。
|50242|被充能的红石中继器中的红石火把周围不能发出粒子。
|50246|当床的左边或右边有一个箱子，另一边有一个实心的木块时，床的腿会消失。
|50250|下界疣的纹理损坏。
|50254|雪方块显示为无效纹理。
|50259|朝上的发射器显示为无效纹理。
|50267|<code>Hopper: java.lang.ClassCastException: atf cannot be cast to aoc</code>。
|50270|<code>Hopper: java.lang.ClassCastException: atf cannot be cast to arj</code>。
|50273|<code>Hopper: java.lang.ArrayIndexOutOfBoundsException: -1</code>。
|50284|命令不能工作。
|50287|如果在上一次崩溃时手持地图，则下次进入世界时，游戏也会崩溃。
}}</onlyinclude>
