# Sarah Boeving

*页面ID: 123449* | *来源: Minecraft Wiki*

* *Sarah Boeving**在[Mojang Studios](Mojang Studios.md)担任艺术家，负责Minecraft相关纹理的绘制。

# 关于
Sarah Boeving在十岁时就痴迷于像素艺术和在MS Paint上涂鸦。此后，她在高中时选修了绘画、油画和数字艺术课程。在创意研究学院中，她进一步精进了技艺，并初步尝试了3D创作。

她主要使用Aesprite、Photoshop和Paint Tool Sai等软件进行创作。<ref>https://sarahboeving.squarespace.com/sb-about</ref>

2022年11月，Sarah Boeving加入Mojang担任艺术家，

她为[棘巧试炼](棘巧试炼.md)更新绘制了5幅画作，分别为Mediditative、Prairie Ride、Baroque、Humble和Unpacked。她还为[追逐天空](追逐天空.md)更新绘制了画作Dennis。

她还参与了[犰甲狼兵](犰甲狼兵.md)更新中[狼](狼.md)变种纹理和[苍白橡木门](苍白橡木门.md)、[鹦鹉螺](鹦鹉螺.md)、[僵尸鹦鹉螺](僵尸鹦鹉螺.md)纹理的制作。
