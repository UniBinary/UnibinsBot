* *小型垂滴叶（Small Dripleaf）**是一种生成于[繁茂洞穴](繁茂洞穴.md)的2格高的植物[方块](方块.md)，可被[骨粉](骨粉.md)催熟成[大型垂滴叶](大型垂滴叶.md)。

# 生成
# = 自然生成 =
小型垂滴叶会自然生成于[繁茂洞穴](繁茂洞穴.md)生物群系的[多叶黏土层](多叶黏土层.md)上。

# = 交易 =

# 破坏
小型垂滴叶被挖掘时会立刻被破坏。

没有被[剪刀](剪刀.md)挖掘破坏时，小型垂滴叶被破坏后不会掉落。

被[剪刀](剪刀.md)挖掘破坏时，小型垂滴叶被破坏后会掉落自身。

# 用途
小型垂滴叶可以直接种在[黏土](黏土.md)或[苔藓块](苔藓块.md)上，也可以在至少1格深的[水源](水源.md)中种在黏土、苔藓块、[苍白苔藓块](苍白苔藓块.md)、[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)或[沾泥的红树根](沾泥的红树根.md)上。

对小型垂滴叶骨粉可使之成长为2-5格高的[大型垂滴叶](大型垂滴叶.md)。若小型垂滴叶上方3格内有方块阻挡，则催熟成的大型垂滴叶最高只能长到该方块的下方。

# = 堆肥 =
将小型垂滴叶放进[堆肥桶](堆肥桶.md)有30%的概率使堆肥层数加1。
