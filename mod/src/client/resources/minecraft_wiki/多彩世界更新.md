# 多彩世界更新

*页面ID: 28453* | *来源: Minecraft Wiki*

[缩略图|由Mojang发布的多彩世界更新图片](File:World of Color Update Artwork.png.md)
* *多彩世界更新（World of Color Update）**是[Java版](Java版.md)的一次主要更新，发布于2017年6月7日。此次更新的名称是在[Owen Jones](Owen Jones.md)于2017年3月13日发的一条Reddit中公布的。<ref>https://www.reddit.com/r/Minecraft/comments/5z5c7f/submit_your_colourful_builds_and_get_featured_in/</ref>

此次更新的开发始于[17w06a](17w06a.md)，其发布于2017年2月8日。

# 重要特性

# = 新内容 =
* 加入了新的彩色方块：
* * [混凝土](混凝土.md)
* * [混凝土粉末](混凝土粉末.md)
* * [带釉陶瓦](带釉陶瓦.md)
* 多种颜色的[鹦鹉](鹦鹉.md)<ref></ref>
* 复述功能可以朗读聊天栏的文字（按下+激活）
* [床](床.md)可以被染色，总共有16种颜色<ref></ref>
* 新的灾厄村民：[幻术师](幻术师.md)
* 新的声音
* 新的命令：、、和。
* [函数](Java版函数.md)
* [快捷栏](快捷栏.md)现在可以在创造模式中保存和加载（按+保存，按+加载）

# = 更改 =
* 更新了绝大部分[染色](染色.md)方块的调色使其更鲜艳
* [配方书](配方书.md)和[知识之书](知识之书.md)
* [进度](进度.md)取代了[成就](成就/Java版.md)<ref></ref>
* 命令中的[NBT](NBT.md)格式更加严格

# 跟进版本
* [Java版1.12.1](Java版1.12.1.md)更新了游戏制作人员名单，修复了一个安全性漏洞。
* [Java版1.12.2](Java版1.12.2.md)将标题名称从Minecraft改为了*Minecraft: Java Edition*。
