* *亮度（Light/Lighting）**会影响视觉、[生物](生物.md)生成及[植物](植物.md)的生长。它包括三个方面：光照等级，内部光照等级和渲染亮度。

# 光照等级
调试屏幕上会显示光照等级。有两种类型的光照：天空光照和方块光照。**光照等级（Light level）**共有16级，以0（最小）至15（最大）的整数表示。

# = 方块光照 =
* *方块光照（Block Light）**即方块发出的光，它会按照[Flood Fill](wzh:Flood fill.md)算法传播。

光源产生方块光照向毗邻的六个方块传播时会衰减1光照等级，直到衰减为0。由此可知，光照衰减依照方块坐标的“[曼哈顿距离](曼哈顿距离.md)”（两个点在坐标系上的绝对轴距总和）计算。例如：
* 假如地上插着一支火把（光照等级14），则在同一平面上，火把四周的方块的光照等级均为13，火把对角的方块的光照等级均为12。
* 假如在地面上方一格的墙上插一支火把，则地板上方且与火把斜对角的方块（即不接触墙壁的方块）的光照等级为11（譬如，西北下方方块的光照等级为，14-1（向西）-1（向北）-1（向下））。

上述这种衰减特性会使光源周围光照的扩散近似呈正八面体。半透明方块可以使方块光照衰减更多（详见下文）。

在计算光照时，光照系统会检查方块是否是[透明](#光照透明方块.md)的。如果是，则可以通过这个方块传播光线；如果不是，则光线被遮挡。有些方块在一些位置上可以透过光照，而有些位置不能，这类部分透明的方块会检查光线射入或射出方块的方向是否是方块的完整[遮挡面](遮挡形状.md)。如果遮挡面完整，光线就不能从这个面射入，同样也不能从这个面射出，即计算方块光照时不考虑遮挡面完整方向上的光照输入，也不会向遮挡面完整的方向上传播光照。

# = 天空光照 =
所有露天位置的**天空光照（Sky Light）**等级为15，之后会按照[Flood Fill](wzh:Flood fill.md)算法传播，光照计算类似于方块光照。和内部天空光照不同，**天空光照与时间无关，它在夜晚不会减弱**。

如果一个等级为15的天空光照向下穿过一个散射天空光的方块，那么它的光照等级会减1；当穿过一个非散射天空光的光照透明方块，它的光照等级不变。

# = 光照透明方块 =
每个方块都有能否遮挡光照的属性。如果一个方块完全不能遮挡光照，它就是**光照透明方块**。入射光照和出射光照不受遮挡穿过这些方块传播。如果一个方块遮挡形状完整，那么它就是**光照不透明方块**，或**完全固体渲染方块**。

所有没有[碰撞箱](碰撞箱.md)和绝大多数[遮挡形状](遮挡形状.md)不完整的方块都是光照透明方块。另外以下方块也不会进行光照遮挡计算：

# = 半透明方块 =

一些方块会对通过的光照造成不同程度的削减，它们是**半透明方块**。

天空光通过这些方块后也会开始像方块提供的光照那样衰减。

# 内部光照
* *内部光照等级**用于游戏的内部计算。游戏采用一个方块的位置的内部光照等级来计算游戏内容，包括生物生成、植物生长、阳光探测器的输出等。它同样也是一个整数，最大等级为15，最小为0。

[thumb|400px|内部天空光照与时间和天空光照的关系图像](File:Internal light with time and sky light.gif.md)

游戏使用天空光照、时间和天气来计算**（internal sky-light）**，然后取方块光照<math>L_b</math>和内部天空光照<math>L_i</math>二者等级的较大值作为内部光照等级（公式：<math>\max \left\{ L_b, L_i \right\}</math>） 。

# = 内部光照的影响 =
* *注意：**光照等级只是影响生物[生成](生成.md)和植物生长的其中一个因素。

# 渲染亮度
[缩略图|右|亮度曲线。水平坐标轴为方块光照，垂直坐标轴为天空光照](File:1.9 lighting curves (gamma=0).png.md)
方块或实体渲染出的亮度取决于光照等级、天空光照颜色、时间和天气。

正如上文所述，天空光照并不是白天高晚上低，它不随时间变化，随时间变化的是亮度曲线本身。[生物](生物.md)也会产生一个圆形的影子，但这与方块的渲染无关。

总体而言，同样等级中，方块光照显得比天空光照更亮，但方块光照最高也只能到14级（固体方块光源的发光等级是15，但仅仅是光源本身所在位置是这个等级），而露天处的天空光照会到15级，因此可以实现平衡。方块光照在中等级时偏橙，而[主世界](主世界.md)白天的天空光照是白色的。

在亮度设置为“昏暗”的[主世界](主世界.md)中，日光最强时亮度<ref name="luma" group="luma">此处的明亮度指[ITU-R BT.601](wikipedia:Rec. 601.md)中的明亮度（Luminance, Luma），亦即灰阶值。</ref>达到98%，夜晚时降至17%<ref name="luma" group="luma"/>且泛蓝。完全黑暗时的明亮度约为5%<ref name="luma" group="luma"/>。

在[下界](下界.md)中，由于本来就没有天空光照，因此也不再产生影响（如果有，会达到约99%的明亮度<ref name="luma" group="luma"/>）。在亮度设置为“昏暗”下，完全黑暗时的明亮度约为25%<ref name="luma" group="luma"/>，此值仅比主世界中光照等级7、无天空光照的情况稍微黑一点，且会像方块光照一样泛橙。

在[末地](末地.md)中，天空光照无论是否存在都不会造成任何影响（可以通过在末地中召唤[闪电](闪电.md)观察到，末地中不会出现其他维度中出现的天空闪烁效果）。在亮度设置为“昏暗”下，完全黑暗时的明亮度大约为28%<ref name="luma" group="luma"/>，且有些偏蓝绿色。

# = 平滑光照 =
[有框|开启和关闭平滑光照的差别](File:SmoothAnimSmal.gif.md)

平滑光照（其中包括[环境光遮蔽](Wikipedia:Ambient occlusion.md)以及方块间的插值照明）是一个平滑亮度差、加黑方块边角从而实现更真实的阴影和光线的光照引擎。平滑光照只会对世界渲染到屏幕的过程有影响，不会对亮度等级造成影响。因此平滑光照不会对生物生成或农作物生长造成影响。平滑光照默认是开启的。

[画](画.md)不受平滑光照的影响。<ref></ref>

平滑光照可以在[选项](选项.md)菜单的“视频设置”中将其设置为开启或关闭。

# 你知道吗
* 发光方块的六个面亮度一致，与略有不同，这样看上去更有发光的感觉。烈焰人也是如此。
* 在游戏代码中，“明亮度（Luminescence）”被定义为浮点型。匪夷所思的是，这些数值均为16的商，但却被乘以15得到最终的整数光照等级。
* * 这意味着0/16和1/16（0.0和0.0625）均对应光照等级0。
* 发光方块被[活塞](活塞.md)推动时会变成[移动的活塞](移动的活塞.md)，此时它们会短暂停止发光。
