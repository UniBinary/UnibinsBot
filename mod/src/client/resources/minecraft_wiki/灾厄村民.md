* *民|災厄村民}}（Illager）**是一类[敌对生物](敌对生物.md)族群，外观与[村民](村民.md)、[流浪商人](流浪商人.md)、[女巫](女巫.md)和[僵尸村民](僵尸村民.md)相似，它们会主动攻击[玩家](玩家.md)、成年村民、流浪商人和[铁傀儡](铁傀儡.md)。

# = 袭击队长 =

任何灾厄村民都有较小概率成为[袭击队长](袭击队长.md)，未使用的幻术师也可以成为袭击队长；只有掠夺者能成为袭击队长，卫道士袭击队长也存在，但不会自然生成。

灾厄村民有其专属的“旗帜”。所有[袭击队长](袭击队长.md)会佩戴着象征“不祥”的[不祥旗帜](不祥旗帜.md)，不祥旗帜也用于掠夺者前哨站中的装饰。

# 生成
灾厄村民通常会成群结队地生成在[袭击](袭击.md)中。掠夺者会生成在[灾厄巡逻队](灾厄巡逻队.md)中。

灾厄村民也会生成在一些特定的[结构](结构.md)当中：卫道士和唤魔者会自然生成于[林地府邸](林地府邸.md)中，除灾厄巡逻队外，掠夺者也会生成在[掠夺者前哨站](掠夺者前哨站.md)附近。

[幻术师](幻术师.md)是Java版独有的生物，由于其未被使用，因此不会生成在世界中。

# 行为
灾厄村民具有以下特征：
* 与[村民](村民.md)、[流浪商人](流浪商人.md)、[铁傀儡](铁傀儡.md)、[玩家](玩家.md)敌对，但无视幼年村民。
* 能够加入和袭击。
* 不会相互攻击，即使发生了误伤。
* 不会被[唤魔者](唤魔者.md)的尖牙伤害。
* 不会被[劫掠兽](劫掠兽.md)的咆哮伤害，但会被击退。
* 不会被[“Johnny”卫道士](卫道士#行为.md)攻击。
* 会主动远离[嘎枝](嘎枝.md)。

# = 支-{}-援 =

在所有难度中，类似于[僵尸猪灵](僵尸猪灵.md)，如果一个灾厄村民被其他生物攻击，附近非攻击状态的同种类灾厄村民也会攻击该生物。但如果同一个灾厄村民受伤多次，其他灾厄村民增援的概率会逐次减少。

不处于袭击且正在巡逻中受到伤害的[掠夺者](掠夺者.md)和[卫道士](卫道士.md)会召唤半径8格内的所有灾厄村民、[女巫](女巫.md)和[劫掠兽](劫掠兽.md)攻击伤害它们的生物。

# 你知道吗
[右|300px](File:MCDRunes.png.md)
* 在[21w37a](21w37a.md)中加入了一种名为“[illageralt](Minecraft Dungeons:illageralt.md)”的新字体（取自Minecraft Dungeons的符文），与灾厄村民有关联。
* 灾厄村民的建筑由大量[深色橡木](深色橡木.md)原木和木板所建造。
* 所有的灾厄村民、[劫掠兽](劫掠兽.md)与[恼鬼](恼鬼.md)都不会攻击幼年村民，而除了被命名为“Johnny”的[卫道士](卫道士.md)以外的所有灾厄村民、劫掠兽与恼鬼都不会攻击幼年村民。<ref></ref>
* 除了唤魔者，其他灾厄村民眼睛原本被设计为蓝色，包括不祥旗帜上绘制的灾厄村民图案、掠夺者最初设计图和[衍生游戏Minecraft Dungeons的变种](MCD:掠夺者.md)以及未使用的幻术师。
* * 在[纹理更新](纹理更新.md)后，所有灾厄村民的眼睛颜色被统一改为绿色；在后续的版本中，只有卫道士的眼睛颜色被回退为蓝色。
* 敲[钟](钟.md)会给予附近的劫掠兽、灾厄村民和女巫的[发光](发光.md)效果。
* 女巫不属于灾厄村民，不会攻击村民，但也会与它们在[袭击](袭击.md)中合作。开发者[Cory Scheviak](Cory Scheviak.md)说女巫“只是跟着凑热闹而已”。<ref></ref>
* 灾厄村民[冰术师](MCD:冰术师.md)是[Minecraft Live 2020](Minecraft Live 2020.md)生物投票中的候选生物之一，计划生成在高山生物群系。它在第二轮投票中被淘汰。
