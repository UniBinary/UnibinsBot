# Java版标签/兴趣点类型

*页面ID: 161629* | *来源: Minecraft Wiki*

* *兴趣点标签（POI Tags）**是[兴趣点类型](兴趣点#兴趣点类型.md)的组合。

# 使用
兴趣点标签在游戏内部用于快速定位，与兴趣点类似。其也可以被命令定位。

# 当前版本

# = acquirable_job_site =
* 村民可获取职业的点。

# = bee_home =
* 蜜蜂的栖息地。

# = village =
* 村庄需具备的兴趣点。
