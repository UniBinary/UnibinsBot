# Java版25w04a

*页面ID: 139530* | *来源: Minecraft Wiki*

<onlyinclude>

* *25w04a**是[Java版1.21.5](Java版1.21.5.md)的第3个快照，发布于2025年1月22日<ref></ref>，加入了[数据包](数据包.md)定义猫和青蛙变种的功能，扩展了[物品堆叠组件](物品堆叠组件.md)控制[格挡](格挡.md)、物品损坏音效、[物品模型](物品模型.md)和[物品提示框](物品提示框.md)的能力，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[语言](语言.md)**
* 加入了对吉尔吉斯语的支持。

* *[数据包](数据包.md)**
* [猫](猫.md)和[青蛙](青蛙.md)变种现在由数据包定义。

* *[注册表](注册表.md)**
* 加入了固有注册表。

* *[物品堆叠组件](物品堆叠组件.md)**
* 加入了组件。
* * 玩家持拥有此组件的物品能像[盾牌](盾牌.md)一样抵挡攻击。
* * 格式如下：
<div class="treeview">

  :** ：（，默认为<code>0</code>）成功抵挡攻击前需要按住右键的秒数。
  :** ：（，默认为<code>1</code>）被可停用抵挡的攻击击中时，物品冷却时长的乘数。为<code>0</code>时，此物品不能被攻击禁用。
  :** ：控制可抵挡多少伤害。未指定时，可抵挡一切伤害。
  :*** ：控制可挡下的伤害量和伤害类型。抵挡成功时，伤害减少<code>-{}-clamp(base + factor * *所受攻击伤害*, 0, *所受攻击伤害*)</code>。
  :**** ：（默认为<code>0</code>）固定抵挡的伤害。
  :**** ：（默认为<code>1</code>）应被抵挡的伤害比例。
  :**** ：可抵挡的伤害类型。允许单个ID、列表或标签。未指定则表示对所有伤害有效。
  :** ：控制攻击对物品造成的耐久损耗。未指定时，每次攻击损耗物品1点耐久。物品耐久最终损耗<code>-{}-floor(threshold, base + factor * *所受攻击伤害*)</code>。最终值可以为负数以使物品修复。
  :*** ：（，默认为<code>1</code>）攻击对此物品造成的最低耐久度损耗。
  :*** ：（默认为<code>0</code>）损耗物品固定耐久度。
  :*** ：（默认为<code>1</code>）所受攻击伤害的乘数。
  :** ：成功抵挡攻击时播放的声音事件。
  :** <ref>更新日志中称为<code>disable_sound</code></ref>：此物品被攻击停用时播放的声音事件。
</div>
* 加入了组件。
* * 存在时，物品因耐久耗尽而损坏时播放此声音事件。
* * 不存在时，物品损坏时不会播放任何音效。
* * 此组件是每个物品类型的默认组件之一。
* * 示例：<code>break_sound'item.wolf_armor.break'</code>
* 加入了组件，需为一个包含旗帜图案ID的标签。<ref>尽管更新日志称需要前缀，但实际上不需要，见</ref>
* * 存在时，物品可被放入[织布机](织布机.md)的图案槽位，并且可以为旗帜绘制标签内的图案。
* * 示例：<code>provides_banner_patterns'minecraft:pattern_item/globe'</code>
* 加入了组件，需为一个包含盔甲纹饰材料ID的标签。
* * 存在时，物品将向盔甲纹饰配方提供指定的纹饰材料。
* * 在内置锻造配方中使用时，此物品必须在<code>#trim_material</code>标签中。
* * 因此，盔甲纹饰材料注册表定义不再指定物品ID。
* * 示例：<code>provides_trim_material'minecraft:iron'</code>
* 加入了组件，以隐藏由任何组件提供的提示框文本。
* * 因此，字段、和组件被取代。
* * 此组件是每个物品类型的默认组件之一。
* * 格式如下：
<div class="treeview">
  :*  物品堆叠组件
  :** ：（默认为<code>false</code>）物品提示框是否总是隐藏。
  :** ：（默认为<code>[]</code>）一个物品组件ID列表，列表内的所有组件提供的提示框文本都会被隐藏。如果组件不提供提示框文本，则对其没有效果。
  :*** ：一个物品堆叠组件ID。
</div>

* *[猫变种定义格式](猫变种定义格式.md)和[青蛙变种定义格式](青蛙变种定义格式.md)**

* 青蛙的变种可通过{{filepath|-{}-data/<*命名空间*>/frog_variant/<*id*>.json}}来添加。
* 文件格式如下：

* *[粒子数据格式](粒子数据格式.md)**
* 粒子类型<code>tinted_leaves</code>现在具有新参数<code>color</code>，可以为一个整数或一个4浮点数列表。

* *[纹理图集](纹理图集.md)**
* 向<code>paletted_permutations</code>纹理图集源中加入了新字段：
* * ：（默认为<code>_</code>）连接原始纹理和置换调色板以生成精灵图名称时使用的分隔符。

* *[标签](Java版标签.md)**
* 加入了实体标签<code>#can_wear_horse_armor</code>：<code>horse</code>。
* * 表示会在其马类实体[物品栏](物品栏.md)中显示马铠[槽位](槽位.md)的实体。

# 更改
# = 物品 =
* *[弩](弩.md)**
* 现在其物品提示框中会显示装填的所有物品，而非只有首个物品。
* * 其中装填的所有物品也会将它们的完整提示框以分段形式加入。

* *[容器](容器.md)**
* 所有容器方块物品现在会像[潜影盒](潜影盒.md)一样在提示框中显示其中的前5个物品（若有）。

* *[地图](地图.md)**
* 没有<code>map_id</code>组件的地图不再在其提示框中显示“”。
* * 无效ID仍会产生此提示。

* *[蜂巢](蜂巢（方块）.md)和[蜂箱](蜂箱.md)**
* 现在其方块物品默认具有<code>block_state</code>组件。

# = 非生物实体 =
* *[喷溅药水](喷溅药水.md)和[滞留药水](滞留药水.md)**
* 移除了<code>potion</code>实体类型。现在代表喷溅药水和滞留药水的实体被拆分为。

# = 游戏内容 =
* *[移动](移动.md)**
* 由于考虑到和的修复对跑酷、和移动造成了太多副作用，因此回退了这2项修复。

# = 命令格式 =
* *[SNBT](SNBT.md)**
* SNBT现在接受异构列表，即接受不同类型元素的列表。
* * 为保持兼容性，NBT格式未变化。
* * 从SNBT转换到NBT时（如作为或的参数），会将异构列表转换为可被NBT格式接受的形式。
* ** 例如，<code>['a', {'b':3}]</code>会存储为<code>[{'<nowiki/>': 'a'},{'b':3}]</code>。
* ** 从NBT转换到SNBT时（如使用显示），上述转换不会逆向进行。

# = 常规 =
* *[进度定义格式](进度定义格式.md)**
* <code>background</code>字段不再需要<code>textures/</code>前缀和<code>.png</code>后缀。

* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[注册表](注册表.md)**
* 注册表现在变为可写注册表。
* 移除了注册表。

* *[物品堆叠组件](物品堆叠组件.md)**
* 对<code>weapon</code>组件进行以下更改：
* * 移除了字段。
* * 加入了字段（，默认为<code>0</code>），非零时，用此武器进行的成功攻击将会禁用[盾牌](盾牌.md)指定秒数。
* 移除了<code>hide_additional_tooltip</code>组件。
* * 世界升级时，此组件将被组件取代，由此组件隐藏的组件提示框将加入列表中，这些组件包括：
* **
* 组件中的字段已被移除，现在它们总是使用简化形式。
* 移除了组件中的字段。
* 移除了<code>hide_tooltip</code>组件。
* 对实体应用的组件现在会从物品转移到所生成的实体上：
* * <code>custom_name</code>→任何实体
* * <code>potion_contents</code>→滞留药水→区域效果云
* * <code>potion_duration_scale</code>→滞留药水→区域效果云

* *[物品模型映射](物品模型映射.md)**
* <code>component</code>枚举属性：
* * 如果选择的值来自注册表但当前数据包未提供此值，则此项将被静默忽略。
* * 此前，无法识别的元素导致整个物品模型都被忽略。

* *[配方](配方.md)**
* <code>smithing_transform</code>配方中的<code>base</code>字段现在是必选的。
* <code>smithing_trim</code>配方：
* * 字段现在是必选的。
* * 加入了字段，控制配方中应用哪个纹饰图案。
* ** 示例：<code>"pattern": "minecraft:bolt"</code>。

* *[战利品表函数](战利品表函数.md)**
* <code>toggle_tooltips</code>的<code>toggles</code>映射表中现在支持任意组件ID。
* * 现在会在<code>tooltip_display</code>组件中切换所指定的组件。

* *[盔甲纹饰定义格式](盔甲纹饰定义格式.md)**
* 不再包含字段。

* *[狼变种定义格式](狼变种定义格式.md)**
* 现已合并到，且分别重命名为、和。
* 加入了字段，详见[上文](#通用变种选择器.md)。

* *[猪变种定义格式](猪变种定义格式.md)**
* 字段现已分别被和取代。

* *[测试实例定义格式](测试实例定义格式.md)**
* 现被重命名为。

* *[测试环境定义格式](测试环境定义格式.md)**
* 现在接受<code>weather</code>而非<code>raining</code>。

* *[标签](Java版标签.md)**
* 将伤害类型<code>#bypasses_shield</code>重命名为<code>#bypasses_blocking</code>。
* 将均添加到方块标签中。
* 移除了猫变种标签。

* *[资源包](资源包.md)**
* 将资源包版本号更改为。
