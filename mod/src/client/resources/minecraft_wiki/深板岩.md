* *深板岩（Deepslate）**是一种在主世界深处代替[石头](石头.md)生成的方块。

# 生成
# = 自然生成 =
在主世界中，深板岩会在Y=-64至0的高度完全取代石头作为基石生成。在Y=1到Y=7之间，深板岩会逐渐向石头过渡。

深板岩自然生成于[远古城市](远古城市.md)中。

# 获取
# = 自然生成 =
远古城市中心的一种地下室房间内会生成一个[熔炉](熔炉.md)，其输出槽有24个深板岩。

# = 烧炼 =
深板岩可以通过烧炼[深板岩圆石](深板岩圆石.md)获取。

# 破坏
挖掘深板岩的合适工具是镐。深板岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，深板岩被破坏后会掉落1个[深板岩圆石](深板岩圆石.md)。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，深板岩被破坏后会掉落自身。

# 用途
类似于[玄武岩](玄武岩.md)和[石英柱](石英柱.md)，深板岩可以朝向任意水平或垂直方向，这取决于[玩家](玩家.md)放置它们时的方向。

# = 转变 =
对上方为空气的[苔藓块](苔藓块.md)或[苍白苔藓块](苍白苔藓块.md)[骨粉](骨粉.md)会使周围7×11×7范围内，最上方的深板岩转变为苔藓块或苍白苔藓块。

# = 蠹虫 =
[蠹虫](蠹虫.md)会蛀蚀深板岩，使其转变为[虫蚀深板岩](虫蚀深板岩.md)。

# 你知道吗
* 深板岩的原名是“阴沉石”（Grimstone），它被更改是因为“Grim”这个词负面情绪相关的含义太过明显，没有准确描述出该方块。而“深板岩”这个名称既表达出该方块在世界中的位置（深），又说明了它是一种板岩。<ref></ref>
