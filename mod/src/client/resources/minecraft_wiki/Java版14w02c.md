# Java版14w02c

*页面ID: 33650* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w02c**是[Java版1.8](Java版1.8.md)的第3个快照，发布于2014年1月10日<ref></ref>，发布以修复[14w02a](14w02a.md)和[14w02b](14w02b.md)里的漏洞和崩溃。

# 修复
命令始终无法在多人服务器控制台上工作。
|9787|与村民交易时游戏崩溃。
|14617|单人游戏中，不同世界的难度设置是共用的。
|17624|楼梯破坏动画有错误。
|29588|<code>Hopper: java.lang.NullPointerException - Invalid Biome id</code>。
|30135|<code>Hopper: java.lang.NullPointerException: Getting biome</code>。
|33071|错误：<code>Data tag parsing failed: Unbalanced quotation</code>在解析含有分号的字符串时出现。
|37075|<code>Hopper: java.lang.NullPointerException: Exception generating new chunk</code>。
|38637|通过物品展示框放置的地图，位于方块西面和东面的比位于方块南面和北面的要暗。
|;dev
|44371|不能清除箭矢。
|44390|<code>@a</code>在所有命令中都不能工作。
|;previous
|44370|物品实体掉落在耕地上时会破坏耕地。
|44400|命令当“最大数量”大于0时，不遵守其对于此的定义。
|44409|在命令方块中使用命令时不造成变化。
|44442|水和熔岩的流动不正确。
|44468|在记分板中使用<code>@a</code>会显示UUID而不是用户名。
|44680|丛林神庙在平原群系中生成。
}}</onlyinclude>

# 你知道吗
* 此版本曾经在[启动器](启动器.md)中移除，但在2018年9月重新加入。
* 该版本的宣传截图中出现了[Grum](Grum.md)的Minecraft皮肤。
