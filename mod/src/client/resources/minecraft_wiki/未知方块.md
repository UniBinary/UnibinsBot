# 未知方块

*页面ID: 89366* | *来源: Minecraft Wiki*

* *未知方块（Unknown）**是[基岩版](基岩版.md)独有的占位符方块。

# 生成
未知方块通常不会生成在世界中。

有无效ID的方块存在于世界中时，该方块将被加载为未知方块。

# 获取

未知方块无法在其他未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取，不存在于[创造模式物品栏](创造模式物品栏.md)中，且是不可通过获取的物品。在[创造模式](创造模式.md)中对已有的未知方块使用可以获得未知方块；否则，未知方块只能通过存档编辑或[附加包](附加包.md)获得。

# 破坏
未知方块被挖掘时会立刻被破坏。

未知方块被破坏后会掉落自身。

# 用途
未知方块是未知ID的加载结果。未知方块的一个常见来源是卸载[附加包](附加包.md)后遗留的非原版方块，没有实际作用。

# = 占位 =
[thumb|与无效ID方块加载成的未知方块的交互](File:Interaction of Unknown from Invalid Block.gif.md)
重新进入世界时，如果无效ID重新变得有效（如重新加载包含对应ID的方块的附加包），那么使用该ID的未知方块、未知方块物品和未知方块物品实体会重新加载为对应的方块、方块物品和物品实体。

使用无效ID的未知方块物品实体被玩家捡起时可能会丢失原有的ID，变为普通的未知方块。

# = 滑行 =
未知方块像[冰](冰.md)一样拥有光滑的表面，但实体在其上方的滑行速度比冰慢。

# = 交互 =
手持由有无效ID的方块加载而来的未知方块时，玩家可以破坏方块，但是无法放置方块，无法进行攻击，无法与任何可交互方块或实体（如门、箱子、村民、船等）交互，也无法使用键将其丢弃（表现为执行上述操作后立即被游戏回退）。

由有无效ID的方块加载而来的未知方块本身也会阻止玩家在其表面上使用任何物品。
