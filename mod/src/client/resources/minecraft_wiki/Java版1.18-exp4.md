* *1.18-exp4（1.18 experimental snapshot 4）**是[Java版1.18](Java版1.18.md)的第4个实验性快照，发布于2021年8月17日<ref></ref><ref></ref>，调整了部分[生物群系](生物群系.md)和一些[岩石](岩石.md)类方块的生成。此版本单独发布，故不出现在[启动器](启动器.md)版本列表中。

# 更改
# = 世界生成 =
* *[生物群系](生物群系.md)**
* 调整了生物群系生成的位置，以降低它们之间出现剧烈反差的可能性。
* 现在生物群系分布更平滑，变化度更低；微型生物群系的生成概率会更低。
* 排除了在较热的生物群系中表层水会结冰的现象，并提高了生成[雪](雪.md)层的高度。

* *[恶地](恶地.md)**
* 现在会更大片地生成，降低了以小斑块形式出现的可能性。
* 现在[陶瓦](陶瓦.md)层会生成得更高。
* 现在[繁茂的恶地高原](繁茂的恶地高原.md)中的植被层会在更高处开始生成。

* *[沙漠](沙漠.md)**
* 现在会更大片地生成，降低了以小斑块形式出现的可能性。

* *[峭壁](峭壁.md)**
* 现在地形变化更加极端。
* 总体上调整了碎地形和峭壁的生成方式，使其更适应地形。

* *[河流](河流.md)**
* 降低了河流被截断并在山区变为无水峡谷的可能性。
* * 相反，河流往往会在山脉中形成峡湾；或是抬高地形，在山间形成一个鞍形的谷地，使地形更易于步行或划船。

* *[积雪山坡](积雪山坡.md)**
* 降低了地表生成[泥土](泥土.md)的概率，使其更加美观。

* *[石岸](石岸.md)**
* 现在地表有时会生成条带状的[安山岩](安山岩.md)、[闪长岩](闪长岩.md)、[花岗岩](花岗岩.md)和[沙砾](沙砾.md)地层。

* *[裸岩山峰](裸岩山峰.md)**
* 现在地表有时会生成条带状的[方解石](方解石.md)、安山岩和花岗岩地层。

* *[沼泽](沼泽.md)**
* 微调了沼泽的生成方式。
* 降低了其从海岸线向内陆延伸得较远的可能性。

* *[沙漠神殿](沙漠神殿.md)**
* 现在更易以部分被掩埋的方式生成。
* 不再在水上生成。

* *[丛林神庙](丛林神庙.md)**
* 不再在水上生成。

* *[矿石](矿石.md)分布**
* 减少了地表安山岩、闪长岩和花岗岩[团簇](团簇.md)的数量。
* 现在[溶洞](溶洞.md)中[铜矿石](铜矿石.md)的团簇会更大。
* 增加了山地中[铁矿石](铁矿石.md)的生成数量。</onlyinclude>
