# Java版Alpha v1.0.2 01

*页面ID: 32481* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.2_01**是的一次更新，发布于2010年7月6日<ref></ref>，更改了[红石](红石.md)相关物品。

# 更改
# = 方块 =
* *[红石线](红石线.md)**
* 现在不会再被踩坏了。
* 现在不会透过固体方块连接斜下方的红石粉。
* 现在会发出[粒子效果](粒子效果.md)。
* 更改了纹理。

* *[红石火把](红石火把.md)**
* 现在只会充能其上方和周围的[方块](方块.md)。</onlyinclude>
