# Al version

*页面ID: 86034* | *来源: Minecraft Wiki*

* *al_version（AppletLoader版本）**是[Alpha](Java版Alpha.md)版本之前用于唯一识别客户端版本的数字。

# 用途
al_version是一个正浮点数，是<code>[minecraft.net](minecraft.net.md)/play.jsp</code>的HTML代码中LWJGL AppletLoader的参数。<ref>[Minecraft.net/play.jsp](https://web.archive.org/web/20090525130611/http://minecraft.net/play.jsp) (source) – Wayback Machine，2009年5月25日 "*。&lt;param name="al_version" value="5.17"&gt;*".</ref>它用于为每个.jar文件指定一个唯一的版本号，并缓存它们以重复使用。如果本地的al_version参数与最新的.jar文件相匹配，则该.jar文件将继续使用，否则将下载新版本的.jar文件。
