# 火焰附加

*页面ID: 28998* | *来源: Minecraft Wiki*

* *火焰附加（Fire Aspect）**是一种用于[剑](剑.md)、[重锤](重锤.md)和[矛](矛.md)的[魔咒](魔咒.md)，可以使持有物品时进行的近战攻击导致目标[着火](着火.md)。

# 获取

# 用途
# = 造成实体着火 =

持有具有火焰附加魔咒的物品近战攻击实体，，会将使其剩余着火时间被设置为<code>-{}-*等级*×</code>，该效果受到[火焰保护](火焰保护.md)魔咒的影响。

# = 与方块和实体互动 =

玩家持有具有火焰附加魔咒的物品时不含水的[蜡烛](蜡烛.md)、[插上蜡烛的蛋糕](插上蜡烛的蛋糕.md)、不含水的[营火](营火.md)、不含水的[灵魂营火](灵魂营火.md)时可以将其点燃，[TNT](TNT.md)或[TNT矿车](TNT矿车.md)可以将其激活。
