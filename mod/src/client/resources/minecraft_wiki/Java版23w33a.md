# Java版23w33a

*页面ID: 105374* | *来源: Minecraft Wiki*

<onlyinclude>

* *23w33a**是[Java版1.20.2](Java版1.20.2.md)的第3个快照，发布于2023年8月17日<ref></ref>，加入了玩家皮肤和用户名举报系统，更改了生物攻击距离的计算方法，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[选项](选项.md)**
* 加入了“”选项，用于控制是否在按组合键时切换的状态，默认为开。

* *<samp>[options.txt](options.txt.md)</samp>**
* 加入了<code>narratorHotkey</code>，默认为<code>true</code>。

* *[社交屏幕](社交屏幕.md)**
* 现在可以举报玩家皮肤和名称。
* * 与聊天举报一样，玩家皮肤和名称的举报由真人处理。
* * 如果皮肤和名称被举报，且被认为违反了，工作人员可以采取以下措施：
* ** 封禁此皮肤，且不再能被任何玩家使用。
* ** 封禁此名称，且不再能被任何玩家使用。
* ** 暂停反复违反的玩家的在线游戏权限。
* * 如果玩家使用的皮肤被封禁，此玩家会在启动游戏时获得通知，其皮肤会被移除并被自动分配一个默认皮肤。玩家的游戏权限不受影响，且仍可使用其他自定义皮肤。
* * 如果玩家使用的名称被封禁，此玩家会在启动游戏时获得通知，且被要求更改名称，否则不能进行在线游戏。
* * 未来，被封禁的皮肤和名称不能被任何玩家使用。

# 更改
# = 方块 =
* *[唱片机](唱片机.md)和[绊线钩](绊线钩.md)**
* 现在会发出木板而非石头的声音。

* *[拉杆](拉杆.md)、[红石中继器](红石中继器.md)和[红石比较器](红石比较器.md)**
* 现在会发出石头而非木板的声音。

* *[海绵](海绵.md)和[湿海绵](湿海绵.md)**
* 现在有其独特的声音。

# = 物品 =
* *[紫颂果](紫颂果.md)**
* 现在食用紫颂果会重置摔落距离。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 现在会从[紫颂花](紫颂花.md)和[孢子花](孢子花.md)上收集花粉。

* *[近战攻击](近战攻击.md)**
* 更改了生物近战攻击的攻击距离的计算方法。
* * 水平方向上，生物的攻击距离现在由其边界箱在水平方向上向外延伸得到，而非由水平宽度决定。
* ** 例如，劫掠兽不再能穿过几格厚的墙壁而攻击到目标。
* * 垂直方向上，生物的攻击距离即为其边界箱的垂直范围。如果它的边界箱不与其目标的边界箱在垂直方向上重叠，其就无法攻击到目标。比如：
* ** 骑乘中型生物（如马）可以免受小型生物（如幼年僵尸）的攻击。
* ** 骑乘体型较高的生物（如骆驼）可以免受一般大小的生物（如僵尸）的攻击。
* ** 一些生物的攻击高度变高（如末影人，攻击它的安全高度由1.5格变为3格）。

# = 常规 =
* *[数据包](数据包.md)**
* 向盔甲纹饰中加入了<code>decal</code>字段，默认为<code>false</code>。
* * 如果设为<code>true</code>，其纹饰会根据其底层的盔甲来遮罩，与23w32a中的行为一致。

* *[调试屏幕](调试屏幕.md)**
* 将“Debug”一行改为“Debug charts”，并更改了其格式。
* * 原先的“Pie”图表现在被称为“Profiler”图表。
* 将打开/关闭性能评测图表、帧生成时间图表和网络性能图表的组合键由、和分别改为、和。
* 切换图表时，调试屏幕不再关闭。
* 如果相互间没有冲突，多个图表可以同时显示。
* 关闭调试屏幕时，图表布局会被保留。

* *[社交屏幕](社交屏幕.md)**
* 更改了下列举报类型的名称和描述：
* * 诽谤（原名称：）
* ** 旧描述：
* ** 新描述：
* * 自残或自杀（原名称：）
* ** 描述未更改。
* * （原名称：）
* ** 描述未更改。

* *[标签](Java版标签.md)**
* 向方块和物品标签中添加了。
