# 基岩版1.12.0.6

*页面ID: 43344* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.12.0.6**是[1.12.0](基岩版1.12.0.md)的第4个测试版，发布于2019年5月22日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[灾厄旗帜](灾厄旗帜.md)**
* 更改了纹理。

* *[钟](钟.md)**
* 更改了纹理映射。

# = 物品 =
* *[画](画.md)**
* 现在可以使用已染色的羊毛合成：


# = 常规 =
* *[附加包](附加包.md)**
* 去除了函数文件开头的“字节序标记”（如果存在）。
* 更新了ScriptHotbarContainerComponent的generateDocumentation函数来表示其已检查玩家快捷栏的第一格而非第三格。

# 修复
* *修复了46个漏洞**<br>
* *崩溃**
* 修复了检查已下载内容时的游戏崩溃。
* 修复了Windows 10版退出游戏时的游戏崩溃。
* 修复游戏加载时的崩溃。
* 修复了投掷鸡蛋或雪球时的游戏崩溃。（）
* 修复了创建着火的箭实体时的游戏崩溃。
* 修复了安卓设备在启动游戏时的游戏崩溃。
* 修复了与村民交易时的游戏崩溃。

* *性能**
* 改进了新版村庄的运行性能。
* 减少了加载纹理所需的内存大小。
* 实体进入水中并产生水花粒子时游戏性能不再下降。
* 改进了阻挡方块时的性能。
* 改进了加载区块时的性能。

* *常规**
* 现在可以正确应用自定义皮肤而无需重启游戏。（）
* 移除了物品的前缀来实现命名规则一致性。
* 第三方服务器里的“邀请游戏”按钮不再被启用。
* 改进了皮肤漫游功能，在重新登录时现在可以正确加载。
* 自定义皮肤在重启游戏后不再被重置。（）

* *游戏内容**
* “钢铁侠”成就现在又可以解锁了。（）
* 金合欢木板可以正确合成了。（）
* 被玩家使用的村民工作站点方块现在有了正确的音量。
* 使用控制器与村民交易时，玩家现在可以持续获取物品。
* 玩家在使用鞘翅飞行时，现在会正确显示纸娃娃模型。（）
* 对着甜浆果丛使用“拾取方块”功能时现在会给予正确的物品。（）
* 或命令给予的烟花火箭现在能正确用于加速鞘翅飞行。
* 对着草使用骨粉时现在会正确消耗骨粉。
* 现在可以使用已染色的羊毛来合成画。
* 玩家在替换已经被交易过的村民绑定的职业站点方块时不再使得该方块的位置丢失。
* 物品栏已满时，不再能使用织布机来复制旗帜图案。
* 不同生长状态的仙人掌现在都可用于烧炼为绿色染料。（）
* 修复了Nintendo Switch版里的游戏指南按钮图标丢失的问题。
* 在制图台UI里按下控制器Y按钮现在会给予正确数量的输出物品。
* 修复了旧版交易选项丢失的问题。
* 流浪商人死亡后，行商羊驼身上的拴绳现在会正确掉落。（）

* *生物**
* 站立或睡觉的猫或村民现在有了正确的头部位置。（）
* 坐下的猫不再出现位置偏移。（）
* 盔甲架的副手手持的物品渲染现在正确了。
* 失业村民现在遵循一般的行程安排。
* 飞行时，鹦鹉的腿部位置现在正确了。
* 修复了部分市场内容地图里的苦力怕模型。

* *图形**
* 更新了灾厄旗帜的纹理。
* 空刷怪笼不再出现火焰粒子。
* VR设备里的箭渲染时间现在正确了。
* 修复了钟的纹理错误。

* *命令**
* 同时杀死骑乘的实体和骑乘者时不再使得骑乘者重生。
* 命令现在可以对部分修改后的物品本地化名称起作用。

* *附加包和脚本引擎**
* 自定义水下生物现在可以正常生成。</onlyinclude>
