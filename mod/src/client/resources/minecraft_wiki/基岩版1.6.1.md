# 基岩版1.6.1

*页面ID: 36542* | *来源: Minecraft Wiki*

* *1.6.1**是的一次热修复更新，发布于2018年9月17日<ref name=changelog></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[基岩版专用服务器](基岩版专用服务器.md)**
* 正式发布。<ref></ref><ref></ref>

# 更改
# = 常规 =
* *[设置](设置.md)**
* 为微软账户登录失败的任天堂Switch上添加一个按钮来清除登录凭据。

# 修复
* *修复了4个漏洞**
* 幻翼现在会正常俯冲攻击玩家。（）
* 方块在被破坏后放置或出现后不再经常消失。（）
* iOS设备上的性能提高。
* 进行了一些修复以在多人游戏和Realms中减少延迟。
