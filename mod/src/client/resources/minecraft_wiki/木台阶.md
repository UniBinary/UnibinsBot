# 生成
红树木台阶、樱花木台阶、竹台阶、绯红木台阶、诡异木台阶和苍白橡木台阶不会生成在世界中。

# = 自然生成 =
*  云杉木台阶会自然生成在[雪屋](雪屋.md)的地下室里。
*  橡木、白桦木台阶会自然生成在[林地府邸](林地府邸.md)里。
*  深色橡木台阶会自然生成在[掠夺者前哨站](掠夺者前哨站.md)里。
*  橡木、白桦木、云杉木、丛林木、和深色橡木台阶都能在[沉船](沉船.md)中自然生成。
*  橡木台阶会自然生成在[平原](平原.md)村庄中。
*  金合欢木台阶自然生成在[热带草原](热带草原.md)村庄里。
*  云杉木台阶自然生成于[针叶林](针叶林.md)和[积雪针叶林](积雪针叶林.md)村庄中。
*  橡木台阶会自然生成在[试炼密室](试炼密室.md)中。

# 破坏
挖掘木台阶的合适工具是斧。

木台阶被破坏后会掉落自身，双台阶被破坏后会掉落两个组成自身的台阶。
