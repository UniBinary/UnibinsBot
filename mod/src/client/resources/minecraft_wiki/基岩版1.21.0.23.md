# 基岩版1.21.0.23

*页面ID: 119288* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.0.23**（ChromeOS/Android）、**Preview 1.21.0.23**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.0](基岩版1.21.0.md)的第4个测试版，发布于2024年4月24日<ref></ref>，调整了可导致生物惊慌的[伤害类型](伤害类型.md)，同步了一些的特性，并修复了一些漏洞。

* 加入了4种洞穴环境音效。

# 修复
* *方块**
* 现在试炼密室中由陶片制成的饰纹陶罐朝向正确的方向。（）
* 铜活板门现在会随着时间推移而氧化。
* 为下列方块加入了缺失的合成配方。（）
* * 2个斑驳的切制铜台阶合成为1个斑驳的雕纹铜块。
* * 2个涂蜡的切制铜台阶合成为1个涂蜡的雕纹铜块。

* *游戏内容**
* 繁花森林现在会生成所有预期种类的花。（）
* 修复了死亡后返回极限模式世界时的旁观模式会禁用穿墙和飞行能力的问题。（）
* 修复了任何种类的石质台阶均可与绯红木板、红树木板或诡异木板合成为砂轮的漏洞。现在砂轮的合成只接受普通的石头台阶，而不接受其他种类的石质台阶。

* *图形**
* 修复了火把的图标在物品栏槽位中垂直居中显示的问题。（）

* *重锤**
* 重锤现在可以附上耐久、锋利、火焰附加和节肢杀手。（）
* 调整了在附魔台上施加重锤独有魔咒时的耗费。

* *不祥之瓶**
* 通过饮用不祥之瓶获得的不祥之兆不再会在玩家身边发出粒子。

* *传送门**
* 现在再次可以在使用触摸控制时通过破坏传送门的表面来破坏下界传送门。

* *试炼刷怪笼**
* 现在试炼刷怪笼进入不祥状态时会发出试炼之兆粒子，而不是幽匿灵魂粒子。

* *原版趋同**
* 喷溅药水现在拥有与可饮用药水相同的时长。

* *生物**
* 移除了沼骸的JSON文件中会损坏资源包的不必要的。（）
* 旋风人现在会在射击玩家时瞄准得略高一些。
* 旋风人风弹现在可以伤害船和矿车上的生物。
* 限制了可导致生物惊慌的伤害类型。（）

* *宝库**
* 更新了宝库和不祥宝库的战利品表以匹配Java版。（）
* 修复了不能使用试炼钥匙来解锁宝库的漏洞。（）

* *风弹**
* 修复了使用风弹后摔落在黏液块或细雪上时不会抵消摔落伤害的问题。（、）</onlyinclude>
