# 青金石

*页面ID: 7492* | *来源: Minecraft Wiki*

</ref>||Alex Wiltshire Mojang avatar.png}}

* *青金石（Lapis Lazuli）**是一种在[附魔台](附魔台.md)中用于附魔的物品。

# 获取
# = 挖掘 =
使用石镐或更好的[镐](镐.md)挖掘[青金石矿石](青金石矿石.md)或[深层青金石矿石](深层青金石矿石.md)会掉落4-9个青金石。使用附有[时运](时运.md)魔咒的镐挖掘会提高其掉落数量，时运III最多会掉落36个。

# 用途
# = 附魔 =

青金石可被用于在[附魔台](附魔台.md)上附魔物品，每次消耗1-3个。

# = 合成材料 =
青金石在合成配方（给[旗帜](旗帜.md)添加图案除外）中可被用作蓝色染料。
