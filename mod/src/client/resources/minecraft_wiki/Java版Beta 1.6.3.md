# Java版Beta 1.6.3

*页面ID: 32742* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.6.3**是的一次次要更新，发布于2011年5月26日，修复了[Beta 1.6.2](Java版Beta 1.6.2.md)里的漏洞和崩溃。

# 更改
* 渲染器在生成[区块](区块.md)时会保持100帧。多余的时间将用于生成区块而不是渲染帧。
* “限制帧率”选项现在将游戏限制为40帧，每帧睡眠时间至少为10毫秒。
* 所有玩家的“限制帧率”选项已被重置为“关闭”，但仍可手动开启。
* 2格[水](水.md)不再阻止[玩家](玩家.md)受到坠落伤害，至少需要3格水才能完全消除。

# 修复
* *修复了3个漏洞**
* 修复了一些方块更新时，在一些情况下不能正确更新光照的问题。这个修复是通过回退在1.6中作出的修复实现的，这使得方块数据不总是会被发送。
* 修复了服务器上的CPU负载问题，这个问题是因为过于密集的循环导致其他的线程都被“饿死”导致的。
* 修复了熔炉会在它们从熄灭和点燃过程中会掉落它们里面的物品或复制物品的漏洞。</onlyinclude>
