# Java版2.0

* *2.0**是一个[愚人节玩笑](愚人节玩笑.md)版本，发布于2013年4月1日<ref name="post">https://www.mojang.com/2013/04/its-finally-coming-minecraft-2-0/</ref>。该版本基于[Java版1.5.1](Java版1.5.1.md)开发。

# 新内容
# = 方块 =

* 数据值为160，其变种“双层Etho台阶”的数据值为159。在[扁平化](扁平化.md)前，这两个数据值分别对应[染色陶瓦](染色陶瓦.md)（159）与[染色玻璃板](染色玻璃板.md)（160）。
* 可使用3个TNT合成，合成配方如下：

* 与其他台阶相同，它可被放置在方块的上半部分或下半部分。
* 它具备与TNT相同的功能，但爆炸后有概率会在爆炸范围内的玩家上方生成一个[铁砧](铁砧.md)。

* *[火把（燃尽）](火把（燃尽）.md)**
* 数据值为161。在[扁平化](扁平化.md)前，该数据值对应[树叶](树叶.md)（金合欢木树叶/深色橡木树叶）。
* 可使用[打火石](打火石.md)重新点燃。

* *[煤炭块](煤炭块（Minecraft 2.0）.md)**
* 数据值为162。在[扁平化](扁平化.md)前，该数据值对应[木头](原木.md)（金合欢木/深色橡木）。
* 与其他矿物方块类似，它需使用9个[煤炭](煤炭.md)合成，合成配方如下：

* 其纹理由[红石块](红石块.md)调整颜色得到。
* 但将其放入[工作台](工作台.md)分解为煤炭时，分解所得的煤炭无法与其他煤炭堆叠，原因是分解产物与普通煤炭的物品数据值不同：前者为32767，后者为0。
* 烧炼时间为720秒，且本身不可燃。
* 煤炭块在[13w18a](13w18a.md)中重新加入游戏，当时使用的纹理与2.0相同；但在后续的[13w19a](13w19a.md)中，其纹理被修改；在[18w43a](18w43a.md)的[纹理更新](纹理更新.md)中，纹理再次被调整。
* 在之后的版本中，煤炭块的合成方式与本版本保持一致。

* *[有色玻璃](有色玻璃.md)**
* 数据值为163。在[扁平化](扁平化.md)前，该数据值对应[金合欢木楼梯](金合欢木楼梯.md)。
* 本版本中，[玻璃](玻璃.md)可被[染色](染色.md)，每次合成可得到8个有色玻璃，合成配方如下：

* 其渲染方式是以白色有色玻璃为基础进行着色，而非使用16张独立的贴图。
* 在[Java版1.7.2](Java版1.7.2.md)中，有色玻璃重新加入游戏，并更名为[染色玻璃](染色玻璃.md)。
* * 在首个相关版本[13w41a](13w41a.md)中，它使用的纹理与2.0相同；但在紧接着的[13w42a](13w42a.md)中，纹理被修改；在[19w08a](19w08a.md)的[纹理更新](纹理更新.md)中，纹理被调整为当前样式。
* [Java版1.17](Java版1.17.md)的首个快照[20w45a](20w45a.md)中加入了[遮光玻璃](遮光玻璃.md)，其英文名称“Tinted glass”与本版本中的有色玻璃完全一致。

# = 生物 =
* *马**
* 与1.6.1中的[马](马.md)不同，此处的马分为两种：一种是[设德兰矮种马](wzh:设德兰矮种马.md)（实际为更换纹理的[猪](猪.md)），另一种是普通马（实际为更换纹理的[牛](牛.md)）。
* 纹理名称为。
* 被喂食后会逐渐发胖。
* 被喂食10次后，会发生爆炸。

* *[粉红凋灵](粉红凋灵.md)（友好凋灵）**
* 在粉红色羊毛上方放置装有玫瑰的[花盆](花盆.md)，即可生成粉红凋灵。
* 与普通凋灵相同，它会掉落[下界之星](下界之星.md)。
* 粉红凋灵会被[糖](糖.md)吸引，能自动治疗周围所有[生物](生物.md)，还会在周围符合条件的方块上自动使用[骨粉](骨粉.md)。
* * 因此，它可在[草方块](草方块.md)上生成[玫瑰](玫瑰.md)、[蒲公英](蒲公英.md)、[草丛](草丛.md)和[蕨](蕨.md)。
* 粉红凋灵刚生成时仅有1个头，喂食糖后会再长出一个头（最多拥有3个头），其作用范围也会随之扩大。
* 尽管粉红凋灵不攻击玩家，但仍属于敌对型生物。
* 粉红凋灵属于亡灵生物，由于其实体ID与普通凋灵一致，因此瞬间伤害[药水](药水.md)会治疗它们，治疗药水则会对它们造成伤害。
* 粉红凋灵没有[Boss栏](Boss栏.md)。
* 在本版本的文件中，其纹理命名为。

* *[钻石鸡](钻石鸡.md)**
* 一种生成概率极低、极为稀有的鸡。
* 不会下[鸡蛋](鸡蛋.md)，而是会下[钻石](钻石.md)和[青金石](青金石.md)。
* * 它们下钻石和青金石的速度，远慢于普通[鸡](鸡.md)下鸡蛋的速度。
* 被激怒后会发生爆炸。
* 其他行为与本版本中的[鸡](鸡.md)保持一致。

* *[红石虫](红石虫.md)**
* 当[红石线](红石线.md)信号强度增加时，有1%的概率生成红石虫。
* * 若7×7×7范围内存在其他红石虫，每只红石虫都会使生成概率提升5%。
* 外形和行为与[蠹虫](蠹虫.md)相同，但颜色与[红石线](红石线.md)相近。
* * 实际上，它是带有标签的蠹虫，通过修改该标签可让其呈现多种颜色，并非仅限于红石色。

# 更改
# = 方块 =
* *[投掷器](投掷器.md)**
* 被重命名为“Floppers”。
* 会将投掷出的所有物品转换为[鱼](生鳕鱼.md)。

* *[熔炉](熔炉.md)**
* 有随机概率过热（产生大量烟雾）并最终发生爆炸。
* 爆炸威力为5，大于[TNT](TNT.md)，且会产生火。
* 即使处于水中，其发生的爆炸仍能破坏周围方块。
* 爆炸前可熔炼约3-7件物品。
* 爆炸概率取决于燃料燃烧时间，而非烧炼的[物品](物品.md)，因此使用[煤炭](煤炭.md)或[木炭](木炭.md)作为燃料时，熔炉必定会发生爆炸。
* 加入了标签，数值范围为0到700，用于控制熔炉的爆炸机制。
* * 处于燃烧状态时，每刻有50%概率使该数值加1。
* * 处于熄灭状态时，每刻有25%概率使该数值减1。
* * 该数值越高，产生烟雾的概率越大。
* * 当数值达到700时，每刻有25%概率使熔炉发生爆炸。

* *[火把](火把.md)**
* 现在会在若干个[随机刻](随机刻.md)后熄灭。

# = 生物 =
[thumb|超级敌对模式](File:Minecraft 2.0 Spawn.png.md)

* *常规**
* [末影龙](末影龙.md)現在处于无敌状态，这使得击败末影龙成为不可能。[返回传送门](返回传送门.md)会转变为一根[黑曜石柱](黑曜石柱.md)。
* 生物现在有概率从[栅栏](栅栏.md)和[玻璃板](玻璃板.md)内部逃脱。
* * 体积较小的生物逃脱概率更高。
* 存在不常见事件（红色及紫色版本中每2-5分钟发生一次）：“超级敌对模式”。
* * 该事件发生时，玩家周围会生成[雷暴](雷暴.md)（通常至少会击中玩家一次），事件范围内会生成大量强大怪物，同时玩家会获得[失明](失明.md)效果。这些怪物不仅包括穿戴强力盔甲的[僵尸](僵尸.md)、[骷髅](骷髅.md)，还包含[闪电苦力怕](苦力怕#闪电苦力怕.md)，有时甚至会生成[烈焰人](烈焰人.md)及其他通常不会在主世界生成的怪物。
* * 这一设定可能参考了[Vechs](http://www.youtube.com/user/Vechz)的超级敌对系列地图。

* *[鸡](鸡.md)**
* 鸡现在属于[条件敌对生物](生物#条件敌对.md)，有时在被杀死后会重生。
* 与末影人类似，当玩家注视鸡或攻击鸡时，鸡会变得具有敌对性。

* *[猪](猪.md)、[哞菇](哞菇.md)和[牛](牛.md)**
* 这些生物被喂食后会逐渐发胖。
* 当它们被喂食10次后，会发生爆炸。

* *[绵羊](绵羊.md)**
* 给绵羊喂食[金苹果](金苹果.md)会使其能够飞行。
* 绵羊可被喂胖，机制与猪、马、哞菇和牛类似。
* 当绵羊被喂食10次后，会发生爆炸。

* *[僵尸猪人](僵尸猪人.md)**
* 僵尸猪人现在持有“战斗[告示牌](告示牌.md)”。

# 你知道吗

* 若系统时间晚于2013年4月2日00:00（不区分时区），2.0版的[闪烁标语](闪烁标语.md)将仅显示为紫色的“”字样，且大小随机（但始终比普通闪烁标语大）。
* Etho台阶的爆炸威力比TNT更大。
* 有色玻璃使用了滤镜效果。
* 哞菇采用了牛的纹理。
* 普通凋灵不会攻击粉红凋灵，因为二者属于同一种生物。
* 简单[难度](难度.md)下更易触发超级敌对模式。
* * 但如果玩家将难度改为“和平”，超级敌对模式会被禁用（不过仍会落下闪电）。这是因为和平难度无法生成敌对生物，且会让已存在的敌对生物消失。
* 粉红凋灵的存档ID为<code>WitherHug</code>，其凋灵之首的存档ID为<code>WitherLove</code>。
* “超级敌对模式”参考了[Vechs](http://www.youtube.com/user/Vechz)超级敌对系列中的“完成纪念碑”地图。玩家需找到彩色羊毛并放置到胜利纪念碑上，这也是部分生物生成时头盔栏会随机出现羊毛的原因。这些怪物被称为“毛茸茸的怪物”，源自Vechs制作的热门超级敌对地图“黑沙漠2”及空岛地图。
* 粉红凋灵无法飞行。
* 有色玻璃、钻石鸡和红石虫的纹理均被硬编码到游戏中，同时在纹理文件夹内还发现了其他生物的纹理。
* 红石虫是一个双关笑话，指代[红石](红石元件列表.md)产生的漏洞（Bug）。
* 更新日志中包含大量未加入游戏的内容。
* Etho台阶的名称参考了YouTube用户EthosLab，这一名称源于[误听](wikipedia:mondegreen.md)（即把原本的语句听成其他单词的语言现象）。
* 语句“YOU NO TAKE... COBBLE!”疑似参考《魔兽世界》，该游戏中的种族“狗头人”在产生仇恨时，常说“你不能拿走我的蜡烛！（YOU NO TAKE CANDLE!）”。
* 在该版本的愚人节公告中，Mojang称其为一款已开发两年的新游戏，并表示“这将把Minecraft这款沙盒游戏提升到新高度”。公告内还附带了一份包含大量无意义更改的更新日志。
