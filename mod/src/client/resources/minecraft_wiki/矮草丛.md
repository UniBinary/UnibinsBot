# 矮草丛

*页面ID: 8205* | *来源: Minecraft Wiki*

* *矮草丛（Short Grass）**是一种常见的非[固体](固体方块.md)植物方块。

# 生成
# = 自然生成 =
矮草丛生成在大多数[生物群系](生物群系.md)的[草方块](草方块.md)和[泥土](泥土.md)上。

矮草丛也会生成在[繁茂洞穴](繁茂洞穴.md)的[苔藓块](苔藓块.md)和[苍白之园](苍白之园.md)的[苍白苔藓块](苍白苔藓块.md)上。

矮草也会在[平原](平原.md)、[热带草原](热带草原.md)和[雪原](雪原.md)类型的[村庄](村庄.md)中生成。

# = 骨粉 =
* *草方块**

对着一片上方为空气的[草方块](草方块.md)[骨粉](骨粉.md)会使其自身和附近7格内（[切比雪夫距离](切比雪夫距离.md)）随机选取的草方块上方生成矮草丛。

* *苔藓块**

对一个上方为空气的[苔藓块](苔藓块.md)骨粉分别有31.25%和6.25%的概率使其水平切比雪夫半径3格，垂直切比雪夫半径5格范围内已有或转化得到的苔藓块上生成矮草丛。

* *苍白苔藓块**

对一个上方为空气的[苍白苔藓块](苍白苔藓块.md)骨粉分别有25%和10%的概率使其水平切比雪夫半径3格，垂直切比雪夫半径5格范围内已有或转化得到的苍白苔藓块上生成矮草丛。

# 获取
# = 箱子战利品 =

# 破坏
矮草丛被挖掘时会立刻被破坏。

没有被[剪刀](剪刀.md)挖掘破坏时，矮草丛破坏后有12.5%的概率会掉落1个[小麦种子](小麦种子.md)，挖掘工具的[时运](时运.md)魔咒每有1级，上限增加2。

被剪刀挖掘破坏时，矮草丛被破坏后会掉落自身。

# 用途
矮草丛可以种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。

# = 绵羊 =

游戏规则为<code>true</code>时，[绵羊](绵羊.md)能够将矮草丛吃掉。且被剪毛的绵羊会在吃掉矮草丛后重新长出羊毛。

# = 堆肥 =
将矮草丛放入[堆肥桶](堆肥桶.md)里有30%的概率增加1个堆肥等级。

# 你知道吗
* 草丛不能被直接点燃，然而在其旁边的火却可以传播到它。蔓延到草丛上方的火看起来是浮空的。
* 矮草丛有时会稍微偏离它所在的方块，这使大片矮草丛看起来更加自然、不拘束。
* 矮草丛的首个纹理来自[Notch](Notch.md)制作的另一款游戏[Legend of the Chambered](Legend of the Chambered.md)。
