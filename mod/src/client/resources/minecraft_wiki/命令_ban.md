# 命令/ban

*页面ID: 39639* | *来源: Minecraft Wiki*

这类命令能控制服务器的[封禁列表](封禁列表.md)。封禁操作将取消已有的白名单。

封禁列表存储在文件。

# ban

将玩家档案列入封禁列表。在封禁列表中的玩家档案阻止具有相同UUID的玩家进入服务器。

# = 语法 =
   <code>ban <targets> [<reason>]</code>

# = 参数 =

   需要封禁的玩家档案。


   要展示给被封禁玩家、其他管理员以及服务器日志中的信息。若未指定，默认为<code>Banned by an operator.</code><!--无本地化-->。


# = 结果 =

# = 输出 =

# ban-ip

把一个IP地址加入封禁列表。将指定IP地址或服务器中在线上的指定玩家的IP地址添加到服务器封禁列表中，阻止任何人从该IP地址连接到服务器。

# = 语法 =
  <code>ban-ip <target> [<reason>]</code>

# = 参数 =

   一名在线的玩家的名称或IP地址。
   这导致通过此命令封禁IPv6地址成为不可能。<ref></ref>

   要展示给被封禁玩家、其他管理员以及服务器日志中的信息。若未指定，默认为<code>Banned by an operator.</code><!--无本地化-->。


# = 结果 =

# = 输出 =

# banlist

显示服务器的封禁列表。

# = 语法 =
   <code>banlist ips</code>
   <code>banlist players</code>

# = 结果 =

# = 输出 =

# banip

封禁一个IP地址。不能在游戏中撤销。必须手动更改。

此命令是Classic时期的等价命令。

# = 语法 =
   <code>banip (<address>|<name>) [<reason>]</code>
