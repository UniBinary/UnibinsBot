# 彩蛋

*页面ID: 9912* | *来源: Minecraft Wiki*

* *彩蛋（Easter Eggs）**指在计算机程序、网页、电子游戏、电影、书籍和填字游戏等内容中，被故意隐藏的有趣信息、玩笑或功能特性。在[Minecraft](Minecraft.md)中，同样存在一些这样的彩蛋。

# 特殊节日
# = 愚人节 =

许多具有玩笑性质的特性和更新会在4月1日发布。其中部分内容，如[染色玻璃](染色玻璃.md)、[煤炭块](煤炭块.md)和[马](马.md)，在之后的正式版游戏中成为了正式内容。

# = 万圣节 =
# == Java版 ==
在万圣夜（10月31日）当天，[僵尸](僵尸.md)、[僵尸村民](僵尸村民.md)、[尸壳](尸壳.md)、[溺尸](溺尸.md)、[僵尸猪灵](僵尸猪灵.md)、[骷髅](骷髅.md)、[流浪者](流浪者.md)、[凋灵骷髅](凋灵骷髅.md)、[沼骸](沼骸.md)和[焦骸](焦骸.md)生成时，有22.5%的概率戴上[雕刻南瓜](雕刻南瓜.md)，2.5%的概率戴上[南瓜灯](南瓜灯.md)，但杀死它们后，雕刻南瓜和南瓜灯不会掉落<ref></ref>。该特性在[12w37a](12w37a.md)中为2012年万圣节加入，此后每年万圣节均会出现。

此外，万圣夜当天仅显示一条[闪烁标语](闪烁标语.md)：“OOoooOOOoooo! Spooky!”（呜呜呜呜呜呜呜！怕怕！）。

# == 启动器 ==
2023年10月27日至11月3日，[Minecraft启动器](Minecraft启动器.md)开启“SPOOKYMODE”（吓人模式），主界面会随机出现一只[恶魂](恶魂.md)。玩家可通过鼠标指针引诱恶魂吐出火球，也可让火球在恶魂附近爆炸将其消灭。

2025年10月28日至11月5日，Minecraft启动器开启“TRICKS”按钮，启动器界面会随机出现一只[末影人](末影人.md)。一段时间无操作后，末影人会尝试搬起启动器的部分元素并移动到随机位置。玩家重新操作启动器后，启动器会恢复布局，同时末影人消失。

通过侧边栏上的按钮，可开启或关闭上述彩蛋，也能单独开关其音效。

# = 圣诞节 =

每年12月24日至26日，[箱子](箱子.md)、大型箱子、[陷阱箱](陷阱箱.md)、大型陷阱箱、和[运输矿车](运输矿车.md)的纹理会变为圣诞节礼物包裹纹理。由于游戏会读取电脑数据，玩家可以通过更改游戏文件和时间来看到圣诞节纹理。该彩蛋于Java版1.4.6版本为2012年圣诞节加入。

纹理“skis.png”也随圣诞节箱子一同加入1.4.6版本的同一文件夹中，这是[Dinnerbone](Dinnerbone.md)为转移玩家关注点而添加的。2013年圣诞节，该纹理重新加入，同时新增了“[猪](猪.md)骑[鸡](鸡.md)”的特性（计划未完全实现）<ref></ref>。此后每年圣诞节，这些内容都会再次出现，主菜单还会显示新的闪烁标语——“Merry X-Mas!”（“Merry Christmas”的简写，意为“圣诞快乐！”）。

# 语言
<!--文言文不被认为是彩蛋，请勿添加-->

[语言](语言.md)菜单中有5种玩笑式的英语：“Pirate Speak”（海盗语）、“LOLCAT”（“小猫皮钦语”）、“ɥsᴉꞁᵷuƎ (uʍoᗡ ǝpᴉsd∩)”（上下颠倒的英式英语）、Shakespearean English（莎士比亚风格英语）、Anglish（纯粹英语）。

此外，Minecraft还被翻译为多种<strong>人工语言</strong>：tlhIngan Hol语（《星际迷航》中的克林贡语）、Quenya语（《》中的精灵语之一——昆雅语）、[逻辑语](https://mw.lojban.org/index.php?title=Lojban&setlang=zh)（Lojban，由逻辑语言群（Logic Language Group）创造的人工语言）以及[世界语](http://ttt.esperanto.org/us/USEJ/world/index.html)（Esperanto，由[柴门霍夫](wzh:柴门霍夫.md)创造的人工语言）。

在[配方书](配方书.md)的搜索栏中输入“**excitedze**”，可将游戏语言切换为海盗语。“ExcitedZe”是Mojang员工[Maria Lemón](Maria Lemón.md)的用户名。<ref></ref>

# 生物名称
部分[生物](生物.md)在拥有特定名称时，会呈现出特别的效果。对于非玩家生物，可通过[命名牌](命名牌.md)命名来触发这些彩蛋。

由于生物只能拥有一个名称，因此绵羊、兔子和卫道士无法同时激活颠倒彩蛋与其独有的彩蛋。

# = 倒立的生物 =
[缩略图|336x336px|一只被命名为“Dinnerbone”的骷髅](File:Upsidedownskele.jpg.md)
 Dinnerbone]||Nathan Adams Mojang avatar.png}}

从[Java版1.6](Java版1.6.md)开始，通过重命名的[刷怪蛋](刷怪蛋.md)、[命名牌](命名牌.md)或命令生成的名称为“[Dinnerbone](Dinnerbone.md)”或“[Grumm](Grumm.md)”（首字母必须大写）的生物，都会呈现上下颠倒的状态</ref>}}。

这一特性还使得Dinnerbone和Grumm在游戏中的头像上下颠倒，可通过“自定义皮肤”选项中的“披风”按钮进行切换。<ref></ref>该功能是有意加入的。<ref></ref>

# = “jeb_”绵羊 =
[缩略图|一只被命名为“jeb_”的绵羊](File:Jeb Sheep.gif.md)
通过命名牌或重命名的刷怪蛋生成名为“[jeb](jeb.md)_”的[绵羊](绵羊.md)，其毛色会循环遍历所有可染色的颜色。但用[剪刀](剪刀.md)剪下的[羊毛](羊毛.md)颜色仍是绵羊原本的颜色，而非当前显示的颜色，且绵羊皮肤上剩余的羊毛会继续在所有颜色间循环。

# = “Toast”兔子 =
[thumb|128px|一只被命名为“Toast”的兔子<br>](File:Toast Rabbit JE2 BE2.png.md)
[thumb|128px|一只被命名为“Toast”的兔子<br>](File:Toast Rabbit JE3 BE3.png.md)
[Ryan Holtz](Ryan Holtz.md)制作[兔子](兔子.md)生物时，玩家xyzen420希望他为自己女朋友丢失的兔子Toast制作一款皮肤。如今，通过命名牌或重命名的刷怪蛋生成的名为“Toast”的兔子，其皮肤会变成Toast的样子，以此作为纪念。

“Toast”兔子不能通过[繁殖](繁殖.md)来繁殖出一只“Toast”幼年兔子。

# = “Johnny”卫道士 =
若[卫道士](卫道士.md)被命名为“Johnny”，或其<code>Johnny</code>标签被设为<code>1b</code>，它会攻击周围除[灾厄村民](灾厄村民.md)之外的绝大多数生物。这一彩蛋致敬了电影》}}中男主角持斧破门时的台词“Here's Johnny!”。

# = “Deadmau5”的耳朵 =
[缩略图|293x293像素|Deadmau5的皮肤](File:Deadmau5.png.md)
Notch为音乐艺术家[Deadmau5](wzh:Deadmau5.md)授予披风时，还亲自为其绘制并添加了耳朵。这些耳朵是“没有价值的物品，只是玩家皮肤的额外部分”，其纹理包含在[deadmau5的皮肤](http://textures.minecraft.net/texture/48db3fbf18e5f0ef266b47f5e6b54126a55f331558ff34cb17468753d84d096)中。

由于皮肤纹理的透明部分会自动转换为黑色，因此deadmau5无法隐藏他的耳朵。

耳朵的显示取决于用户名是否为deadmau5，而非玩家的UUID。这意味着如果deadmau5更改名字，就无法再拥有这些耳朵了。

在[Java版1.21.9-pre2](Java版1.21.9-pre2.md)前，无论耳朵是否显示，所有名称为“deadmau5”的生物，其名称标签的显示位置比常规高10像素。

# 闪烁标语


# = 永不出现的闪烁标语 =
“texts”目录下的“splashes.txt”文件包含了主菜单中显示的所有闪烁标语。其中有一条标语为“This message will never appear on the splash screen, isn't that weird?”（“这条信息永远不会显示在标题画面上，是不是很神奇呢？”）。正如其名，这条标语不会在主菜单中显示。

# = missingno =
若删除或修改文件，但未删除签名文件夹，启动游戏后[闪烁标语](闪烁标语.md)会变为“missingno”字样。这源自游戏《宝可梦 红/绿》中[一个著名的漏洞](https://wiki.52poke.com/wiki/MissingNo.)。

# = 节日标语 =
在各类节日期间，游戏会出现对应的闪烁标语。例如，每年1月1日会显示“Happy New Year！”（新年快乐！），圣诞节期间会出现“Merry X-mas!”（圣诞快乐！）。这些标语每年可能会有细微改动。

# = COVID-19 =
COVID-19肆虐期间，游戏中会显示特殊标语，包括“Wash your hands!（勤洗手！）”“Support elderly relatives and friends!（支持长辈和朋友！）”以及“Soap and water!（肥皂和水！）”等。

# 致敬Technoblade

2022年6月30日，知名Minecraft YouTuber [Technoblade](Technoblade.md)因癌症去世后，Mojang为纪念他，在Java版的艺术形象中，将其皮肤皇冠添加到猪身上；并在[Java版1.19.1](Java版1.19.1.md)和[基岩版1.19.10](基岩版1.19.10.md)中新增了闪烁标语“Technoblade never dies!”。此外，Technoblade猪还出现在[A Minecraft Movie](A Minecraft Movie.md)中。

# = 物品模型 =

通过命令，可将不可直接穿戴的[物品](物品.md)或[方块](方块.md)放在盔甲槽，但这些物品和方块仅在放在[玩家](玩家.md)、[铜傀儡](铜傀儡.md)及一些人-{}-形生物的头盔槽时，才会显示在外观上。

物品栏图标为3D模型的方块会框住穿戴者的头部；物品栏图标为2D纹理的方块和物品则会出现在后脑勺的上端。

以下方块和物品会显示在独特位置：
* 会像独角兽的角一样从生物额头伸出来。
* 和末地烛类似，但以平直的方式伸出。
* 会像天线或耳机一样倒置在右脸。
* 看起来像是左脸的头戴话筒。
* 会被衔在嘴上。
* 戴上后形似面具。
* 会像单片眼镜的镜框那样环绕着生物右眼。
* 会插在生物的后脑勺上，[袭击队长](袭击队长.md)也会如此装备旗帜。
* 与旗帜类似，竖直地插在后脑勺。
* 会像[冕旒](wzh:冕冠.md)一样戴在头顶。
* 会像首饰一样戴在头部前侧的上端。
* 和会被顶在头上。
* 会插在玩家下巴的左侧。

# 已移除的彩蛋

部分彩蛋已从Minecraft中移除，仅在旧版本中存在。

# = 蝙蝠生成 =
10月20日至11月3日期间，[蝙蝠](蝙蝠.md)在[亮度](亮度.md)等级≤6时即可生成；其他时间则需亮度等级≤3才能生成。该特性在[Java版25w44a](Java版25w44a.md)被移除。

# = Notch之死 =
当名为“[Notch](Notch.md)”的玩家在游戏中死亡时，除物品栏物品外，还会额外掉落一颗[苹果](苹果.md)<ref></ref>。该彩蛋在[Java版12w18a](Java版12w18a.md)中被移除，目前尚不清楚这一变化是有意为之还是无意导致。

# = Searge说 =
在命令方块中运行（帮助命令），“最近的输出”处会显示以“Searge says:”（Searge说：）为开头的信息，内容包括：
* "Yolo<ref group="注">是**Y**ou **o**nly **l**ive **o**nce的缩写，寓意事情应当大胆去做。</ref>"<br>“你只能活一次”
* "/[achievement](命令/achievement.md) take achievement.understandCommands @p"<br>（命令：剥夺距离最近玩家的“懂得使用命令”成就）
* "Ask for help on twitter"<br>“去推特找人帮忙”
* "/[deop](命令/deop.md) @p"<br>（命令：剥夺距离最近玩家的服务器管理员权限）
* "Scoreboard deleted, commands blocked"<br>“记分板已删除，命令系统已屏蔽”
* "Contact helpdesk for help"<br>“去服务台找人帮忙”
* "/testfornoob @p"<br>（命令：测定距离最近玩家是否为菜鸟）
* "/[trigger](命令/trigger.md) warning"<br>（命令：触发“警告”触发器）
* "Oh my god, it's full of stats"<br>“我的天呀，全是数据”<ref group="注">引用自《太空漫游2001》，原句是“我的天啊，全是星星（stars）”。</ref>
* "/[kill](命令/kill.md) @p[name=!Searge]"<br>（命令：将最近的名称不是Searge的玩家清除）
* "Have you tried turning it off and on again?"<br>“你试过重启了么？”
* "Sorry, no help today"<br>“不好意思，今天没有帮助”

该彩蛋在[Java版18w02a](Java版18w02a.md)之后无法触发<ref></ref>。此后，命令恢复正常运行，但“上一个输出”仅显示最后一行（“/[xp](命令/xp.md) -> experience”），因为其仅有一行显示空间。

# = Java版启动器 =
[缩略图|300px|此图片同时展示了2个彩蛋](File:Easter Egg Launcher.png.md)
在[启动器2.1.497x](启动器2.1.497x.md)之前的Java版启动器中有2个彩蛋。将鼠标悬停在“开始游戏”按钮上，界面右下角会出现一只随机生物，这是第一个彩蛋。第二个彩蛋位于界面左上角，仔细观察可发现一张[苦力怕](苦力怕.md)的脸，这张脸有大约的概率变成耸肩表情“¯\_(ツ)_/¯”，点击可将其点亮。此外，按下会播放[经验球](经验球.md)被捡起的声音。这些彩蛋在启动器版本[2.1.497x](启动器2.1.497x.md)中被移除。

# = “超级秘密”设置 =
在[Java版1.7.2](Java版1.7.2.md)的快照[13w36a](13w36a.md)中，Dinnerbone添加了一个“Super Secret Settings<!--请勿翻译，因为它在13w36a中就是叫这个名字-->”按钮，可在选项菜单中找到。点击该按钮会发出一个随机的低音量声音，并改变屏幕上的[着色器](着色器/Java版1.9前.md)。在显卡不支持OpenGL 2.1的电脑上，这种效果可能失效。此功能在1.9快照[15w31a](15w31a.md)中被移除。
