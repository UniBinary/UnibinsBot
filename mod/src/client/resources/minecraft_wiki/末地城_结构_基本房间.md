# == 逐层构造 ==

结构蓝图中的羊毛不存在于实际的结构中，它们作为辅助方块而出现，作用如下：
* 黑色羊毛作为基准点，位于0x 0y。
* 与绿色羊毛相邻的楼梯被翻转且上下颠倒。
* 与红色羊毛相邻的楼梯为正常朝向。
