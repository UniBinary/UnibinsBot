* *1.9.0**是[基岩版](基岩版.md)的一次主要更新，发布于2019年2月6日。此次更新加入了更多[村庄与掠夺](村庄与掠夺.md)特性。<ref name="website"/><ref></ref>

# 新内容
# = 方块 =
* *[木桶](木桶.md)、[钟](钟.md)、[高炉](高炉.md)、[制图台](制图台.md)和[烟熏炉](烟熏炉.md)**
* 当前没有功能。
* 可通过开启[实验性玩法](实验性玩法.md)获得。
* *[制箭台](制箭台.md)**
* 可用[工作台](工作台.md)和[箭](箭.md)合成。
* 当前没有功能。
* 可通过开启[实验性玩法](实验性玩法.md)获得。
* *[花](花.md)**
* 加入了[矢车菊](矢车菊.md)。
* * 能合成[蓝色染料](蓝色染料.md)。
* * 出现在[平原](平原.md)生物群系。
* 加入了[铃兰](铃兰.md)。
* * 能合成[白色染料](白色染料.md)。
* * 出现在[森林](森林.md)生物群系。
* *[砂轮](砂轮.md)**
* 当前没有功能。
* 使用[Java版18w44a](18w44a.md)里的旧纹理。
* 可通过开启[实验性玩法](实验性玩法.md)在创造模式中获得。
* *[灯笼](灯笼.md)**
* 充当新光源。
* 可通过开启[实验性玩法](实验性玩法.md)获得。
* *[告示牌](告示牌.md)**
* 加入了云杉木告示牌、白桦木告示牌、金合欢木告示牌、丛林木告示牌和深色橡木告示牌。
* *[锻造台](锻造台.md)**
* 可用[工作台](工作台.md)和[圆石](圆石.md)合成。
* 当前没有功能。
* 使用[Java版18w44a](18w44a.md)里的旧纹理。
* 可通过开启[实验性玩法](实验性玩法.md)获得。
* *平滑方块**
* 加入了[平滑石头](平滑石头.md)、[平滑砂岩](平滑砂岩.md)、[平滑红砂岩](平滑红砂岩.md)和[平滑石英块](平滑石英块.md)。
* *[台阶](台阶.md)**
* 加入了石台阶、安山岩台阶、磨制安山岩台阶、闪长岩台阶、磨制闪长岩台阶、花岗岩台阶、磨制花岗岩台阶、苔石砖台阶、苔石台阶、平滑砂岩台阶、切制砂岩台阶、平滑红砂岩台阶、切制红砂岩台阶、平滑石英台阶、红色下界砖台阶和末地石砖台阶。
* 加入了切制砂岩台阶和切制红砂岩台阶。
* *[楼梯](楼梯.md)**
* 加入了石楼梯、安山岩楼梯、磨制安山岩楼梯、闪长岩楼梯、磨制闪长岩楼梯、花岗岩楼梯、磨制花岗岩楼梯、苔石砖楼梯、苔石楼梯、平滑砂岩楼梯、平滑红砂岩楼梯、平滑石英楼梯、红色下界砖楼梯和末地石砖楼梯。
* *[墙](墙.md)**
* 加入了砖块墙、安山岩墙、闪长岩墙、花岗岩墙、海晶石墙、石砖墙、苔石砖墙、砂岩墙、红砂岩墙、下界砖墙、红色下界砖墙和末地石砖墙。

# = 生物 =
* *[掠夺者](掠夺者.md)**
* 敌对生物，是[灾厄村民](灾厄村民.md)的一种。
* 有生命值。
* 手持[弩](弩.md)。
* 被杀死时有概率掉落随机耐久的[弩](弩.md)（受抢夺魔咒影响）。
* 会袭击或占领[村庄](村庄.md)并杀死[村民](村民.md)。
* 不能穿戴盔甲。
* 可通过开启[实验性玩法](实验性玩法.md)获得。

# = 世界生成 =
* *竹林**
* [丛林](丛林.md)的新变种。
* 包含[竹子](竹子.md)，[灰化土](灰化土.md)和[熊猫](熊猫.md)。
* 可通过开启[实验性玩法](实验性玩法.md)获得。

* *[游戏规则](游戏规则.md)**
* 通过新游戏规则（默认为10,000）可以限制通过函数运行的命令数量，以限制性能问题。

# = 常规 =
* *暂停菜单**
* 加入了新的“反馈”按钮。
* * 显示Minecraft的反馈页面、漏洞追踪器、和Mojang帮助页面的链接。
* “游戏指南”按钮现在在游戏中的设置菜单中可见。

* *Minecraft Script Engine**
* 使用编写。
* 脚本可以被编写并与行为包绑定，以便监听和响应游戏事件、获取和修改实体组件、影响游戏行为。
* 只能通过Windows 10并从[实验性玩法](实验性玩法.md)获得。

# 更改
# = 方块 =
* *[苔石](苔石.md)**
* 英文名被重命名为“Mossy Cobblestone”。

* *[下界砖栅栏](下界砖栅栏.md)**
* 下界砖栅栏的[合成](合成.md)配方从4块[下界砖](下界砖.md)变成2块。
* * 以前的合成配方现在用于合成下界石砖墙。

* *[平滑砂岩](平滑砂岩.md)和[平滑红砂岩](平滑红砂岩.md)**
* 分别被重命名为切制砂岩和切制红砂岩。

* *[告示牌](告示牌.md)**
* 被重命名为“橡木告示牌”。
* * 现在只能通过使用橡木木板合成，而不是任意变种的木板。

* *[石头台阶](石头台阶.md)**
* 被重命名为平滑石头台阶，且需要平滑石头合成，而不是之前的常规石头。
* * 以前的合成配方现在被用于合成石头台阶。

* *[砂岩](砂岩.md)、[红砂岩](红砂岩.md)楼梯及台阶**
* 合成时不再能使用任何除了普通砂岩和红砂岩以外的砂岩变种。

* *[炼药锅](炼药锅.md)**
* 现在可以盛[熔岩](熔岩.md)。
* * 现在会把在内的实体点燃，并且发光。

* *[绊线](绊线.md)**
* 现在在破坏时被激活，除非使用[剪刀](剪刀.md)。

* *[羊毛](羊毛.md)**
* 白颜色羊毛（White colored wool）被重命名为白色羊毛（white wool）。

# = 生物 =
* *友好生物**
* 现在会随机进入[繁殖](繁殖.md)模式。

# = 游戏内容 =
* 在加载屏幕中加入几个新的社区提出的提示。
* 当被驯服的生物死后，玩家会在聊天记录里收到一条信息。（）
* 提高了使用函数命令时的性能，它们现在在世界加载时预编译。

# = 常规 =
* *多人游戏**
* 玩家现在可以加入并游玩小版本不匹配的游戏。（）

# 修复
* *修复了115个漏洞**<br>
* *崩溃/性能**
* 修复了游戏过程中出现的崩溃现象。
* 用铁门替代木门放置时游戏崩溃。（）
* 对着装有成书的箱子使用“拾取方块功能”时游戏崩溃。
* 活塞推动方块时游戏崩溃。
* Nintendo Switch版里更改连接方式时游戏崩溃。
* 修复了一个导致Gear VR断开手柄连接的漏洞。
* 迅速登入和登出Xbox Live账户时游戏崩溃。
* 在移动端下暂停或继续游戏时游戏崩溃。
* 在Windows 10 Mobile版里暂停或继续游戏时游戏崩溃。
* 退出选项界面时游戏崩溃。
* 从多人游戏断开连接时，无法再继续进行游戏。
* 物品展示框里的潜影盒导致游戏崩溃。
* 优化了客户端和服务端的区块同步流程。

* *常规**
* 多人游戏下，玩家不再能自定义玩家权限。

* *游戏内容**
* 加载世界时，玩家不再生成在高空中。（）
* 使用触摸屏时，在水下的玩家会保持潜行姿势。（）
* 使用触摸屏时，玩家的朝向会意外选择。（）
* 末地折跃门在已经生成的区域里现在可以正常运作。（）
* 末地折跃门的生成距离太短，导致玩家无法返回末地主岛。
* 在转换后的世界里，杀死末影龙不会掉落正确数量的经验值和生成龙蛋。（）
* 步行穿过脚手架时，自动跳跃功能出现错误。（）
* 使用触摸屏时，试图发射弩会导致玩家挖掘方块。（）
* 使用触摸屏时，“交换潜行和跳跃”选项现在能够对脚手架正确运作。（）
* 罕见情况下，玩家在水附近走动时被传送到船中。

* *物品**
* 修复了在满背包情况下，从合成-{}-书制作时可能导致物品丢失的漏洞。（）
* 由精准采集工具采集而来的藤蔓现在可以用于旗帜合成配方。（）
* 掉落物会卡在台阶和玻璃里。（）
* 多人游戏下，末影龙的龙息不能收集。（）
* 使用触摸屏时，手持弩与方块进行互动时会意外射箭。（）
* 手持弩时无法使用近战攻击。（）

* *生物**
* 猫现在可以生成在1.8.0以前生成的村庄里。
* 潜影盒在打开时不能推动实体。（）
* 熊猫着火时仍会继续进食。
* 史莱姆不会正常生成在史莱姆区块里。（）
* 末影人在被激怒是不会播放愤怒音效。（）
* 被火焰附加武器杀死的幻翼不会掉落幻翼膜。（）
* 骷髅骑士现在会正确地坐在蜘蛛和骷髅马上。（）
* 修复了骑乘者的位置，从而允许多个骑乘者骑乘同一个生物。

* *方块**
* 步行穿过脚手架时，自动跳跃功能出现错误。
* 现在可以将更多方块放置在脚手架的上面，例如生物头颅和花盆。（）
* 水平方向流动的水不再使得下面放置的灵魂沙生成气泡柱。

* *Realms/专用服务器**
* 编辑现在会给予正确的玩家权限。
* 重新进入专用服务器时候，玩家的权限不再会重置。
* 在存储空间不足的情况下，下载体积较大的Realms世界出现问题。
* 改进了专用服务器里的光照计算。
* Xbox One版里Realms订阅无法购买。
* 服务器主人按下“开始游戏”按钮后，改动后的Realms游戏设置现在会被套用。

* *图形**
* 资源包里的手持物品的纹理现在会正确显示。（）
* 加入世界后，时钟和指南针无法正常运作。（）
* 修复了纹理抗锯齿，使地形区块现在具有更清晰的纹理
* 手持的物品有时会变成白色。
* 信标光束会再次使用合适的纹理。（）
* 修复了在加勒比海盗混搭包里的“Syrena”皮肤的动画效果损坏问题。
* 修复了在皮肤包里只有单腿的形象的腿部渲染问题。
* 熊猫的喂食动画出错。
* 潜影贝攻击玩家时会变黑。
* 使用刷怪蛋生成后，绵羊和猫不再出现黑色。
* 已驯服的羊驼在打开它们身上的物品栏时不再发光。手持的物品有时会变成白色。
* 流浪者现在再次具有正确的纹理层。（）
* 燃烧的熔炉现在可以使用+选取方块键而获取。
* 紧挨树叶的脚手架会出现纹理深度冲突。（）
* 女巫发出黑色的粒子，而不是紫色的。（）
* 三叉戟的投掷动画与弩的发射动画重叠。（）

* *用户界面**
* Nintendo Switch版的手持模式下，“保存到微软账户”信息丢失。
* 创造模式物品栏里，台阶被视作“半个台阶”。（）
* 改进了部分文本显示，文本框现在能够使用键盘来高亮选择。
* 更新了存储可用空间太低的信息。
* 改进了玩家在没有许可证的情况下进行游戏的警告信息。
* 试图加入不可用的世界时，弹出的错误信息现在更加详细。
* 分屏模式下暂停游戏时，闪烁标语的缩放显示错误。
* 角色创建器界面现在会显示加载动画。
* 改进了在市场界面里使用控制器或键盘时的导航操作。
* 市场内容现在可以正确下载而不会卡死。（）
* 自定义模型格式现在支持双行操作。（）

* *命令**
* 在复制循环型命令方块时，“保持激活”选项会重置。（）
* 命令方块里的命令不再拓展到其他维度里，但此项修复不对已经存在的命令方块起作用。（）
* 使用命令时，现在可以显示特殊字符。
* 无法使用命令清除下落的方块。（）
* 复了部分命令的相对坐标低于y3值的错误。（）

* *附加包**
* 在行为包中未指明时，马将生成不同的变体（而不仅仅是一种类型）。
* 使用组件的可骑乘实体会导致游戏崩溃。
* 物品栏中的方块现在再次使用中的纹理。
