# 基岩版1.21.2

*页面ID: 123204* | *来源: Minecraft Wiki*

* *1.21.2**是的一次热修复更新，发布于2024年7月9日<ref></ref>，修复了一些漏洞。此版本不兼容[1.21.0](基岩版1.21.0.md)和[1.21.1](基岩版1.21.1.md)。

# 更改
# = 方块 =
* *[不祥宝库](不祥宝库.md)**
* 更改了战利品表的抽取概率以匹配。
* * 将普通战利品表被抽取到的概率由80%更改为20%。
* * 将稀有战利品表被抽取到的概率由20%更改为80%。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“测试版 API”子选项后才可使用。

# = 技术性 =
* *API**
* 为的版本加入了类和对象。

# 修复
* *不祥试炼刷怪笼**
* 现在由不祥试炼刷怪笼生成的生物会掉落其所捡起的物品。（）

* *不祥宝库**
* 现在稀有战利品被抽取到的概率为80%，而不是20%。（）

* *试炼刷怪笼**
* 修复了试炼刷怪笼不会在旧版世界中弹出战利品的问题。（）
