# Clark

*页面ID: 169451* | *来源: Minecraft Wiki*

* *Clark**是一首由[C418](C418.md)创作的音乐。

# 播放条件
Clark会在玩家处于[生存模式](生存模式.md)或时播放。

# 描述

[File:Clark.ogg](File:Clark.ogg.md)

Clark以一些安静、悲伤的弦乐和弦开场，钢琴、合成贝斯和钢片琴演奏悲伤的旋律。共振、温暖的合成器演奏和弦结束，然后突然停止并响起。

Clark的结尾与[Chris](Chris.md)相连。
