# Debug fourj item

*页面ID: 101417* | *来源: Minecraft Wiki*

<samp>**debug_fourj_item**</samp>是[原主机版](原主机版.md)独有的物品，只能通过修改游戏获得。

# 获取
<samp>debug_fourj_item</samp>目前不能在原版游戏中正常获得，只能通过编辑物品栏获得。其不存在于[创造模式物品栏](创造模式物品栏.md)中，亦无法使用[命令](命令.md)获得。

# 用途
<samp>debug_fourj_item</samp>的用途未知，且无法放置。它的ID<ref name="youtube"></ref>表明它用于调试和测试目的。其在物品栏中使用[屏障](屏障.md)的纹理，既没有“这是什么？”的提示，也没有显示名称。
