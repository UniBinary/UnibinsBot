# Java版22w16a

*页面ID: 95160* | *来源: Minecraft Wiki*

<onlyinclude>

* *22w16a**是[Java版1.19](Java版1.19.md)的第6个快照，发布于2022年4月20日<ref></ref>，加入了[唱片残片](唱片残片.md)、[音乐唱片](音乐唱片.md)*5*和新的[音乐](音乐.md)曲目以及新的游戏规则，调整了[悦灵](悦灵.md)的行为和一些游戏特性，修复了一些漏洞。

# 新内容
# = 物品 =
* *[唱片残片](唱片残片.md)**
* 一种残片物品，可以罕见地在[远古城市](远古城市.md)的战利品箱子中找到。

* *[音乐唱片](音乐唱片.md)**
* 加入了音乐唱片5，作者为[Samuel Åberg](Samuel Åberg.md)。
* * 只能通过9个唱片残片合成得到。

# = 非生物实体 =
* *[画](画.md)**
* 加入了中的4种画：<code>earth</code>、<code>wind</code>、<code>fire</code>和<code>water</code>，目前未被使用。
* * 这些画默认情况下不会被放置出来，可以通过[命令](命令.md)（例如{{cmd|summon painting ~ ~ ~ {variant:"water"}<nowiki/>}}）或[数据包](数据包.md)放置它们。

# = 命令格式 =
* *[游戏规则](游戏规则.md)**
* 加入了游戏规则<code>doWardenSpawning</code>。
* * 用于设置是否生成[监守者](监守者.md)。
* * 默认值为<code>true</code>。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 加入了堆内存分配指标。

* *[音乐](音乐.md)**
* 加入了4首新的音乐<ref group="注">发布到了所有1.19快照中。</ref>，作者为[Lena Raine](Lena Raine.md)：
* * “Ancestry”仅会在[深暗之域](深暗之域.md)中播放。
* * “Aerie”“Firebugs”和“Labyrinthine”会在[繁茂洞穴](繁茂洞穴.md)、所有种类的[沼泽](沼泽.md)、[森林](森林.md)和[丛林](丛林.md)中以及[菜单屏幕](菜单屏幕.md)中播放。

* *[标签](Java版标签.md)**
* 加入了以下[方块标签](Java版标签/方块.md)：
* * ：。
* 加入了以下[画变种标签](Java版标签/画变种.md)（新类型）：
* * ：。
* ** 此标签用于决定哪些画会在生存模式下出现。

# 更改
# = 方块 =
* *[蛙明灯](蛙明灯.md)**
* 现在可以被[活塞](活塞.md)移动。

# = 生物 =
* *[悦灵](悦灵.md)**
* 生命值由提升到。
* 掷出物品后再次搜寻物品前的间隔由5秒降为3秒。
* 搜寻物品的范围由9格增至32格。
* 降低了空闲时飞行的速度，提高了收集物品、飞向玩家或[音符盒](音符盒.md)时的飞行速度。
* 修改了投掷物品的曲线。

* *[青蛙](青蛙.md)**
* 现在可以在[草方块](草方块.md)、[泥巴](泥巴.md)、[覆地苔藓](覆地苔藓.md)、[红树根](红树根.md)和[沾泥的红树根](沾泥的红树根.md)上生成。

# = 常规 =
* *[LWJGL](wikipedia:LWJGL.md)**
* 将LWJGL的版本升级到3.3.1。

* *[音乐](音乐.md)**
* 更改了以下音乐可播放的位置：<ref group="注">所有1.19快照均受此改动影响。</ref>
* * “Stand Tall”“Wending”和“Infinite Amethyst”现在不再会在菜单屏幕上播放。
* * “Left to Bloom”和“One More Day”现在不再会在菜单屏幕上播放，会在所有种类的森林、丛林和[原始针叶林](原始针叶林.md)中播放。
* * “Floating Dream”和“Comforting Memories”现在会在所有种类的森林、丛林和原始针叶林中播放。

* *[粒子](粒子.md)**
* 移除了<code>allay_dust</code>粒子。

* *随机化游戏事件**
* 以下随机化的游戏事件的可预测性被提高，不再会出现极端行为：
* * [投掷器](投掷器.md)或[发射器](发射器.md)掷出物品的位置和速率
* * 容器被破坏后弹出物品[实体](实体.md)的位置和速率
* * 生物的随机<code>follow_range</code>[属性](属性.md)
* * [骷髅陷阱](骷髅陷阱.md)生成的[骷髅马](骷髅马.md)的移动速率
* * [烈焰人](烈焰人.md)的随机生成位置和投射物速度
* * [箭](箭.md)伤害中的随机值部分以及飞行速率
* * [烟花火箭](烟花火箭.md)的随机飞行轨迹
* * [钓鱼](钓鱼.md)时气泡粒子的样式和钓到鱼的等待时间

* *[标签](Java版标签.md)**
* 将加入了标签。
