# Java版25w02a

*页面ID: 138779* | *来源: Minecraft Wiki*

<onlyinclude>

* *25w02a**是[Java版1.21.5](Java版1.21.5.md)的首个快照，发布于2025年1月8日<ref></ref>，加入了[猪](猪.md)的新变种、[野花簇](野花簇.md)和[枯叶堆](枯叶堆.md)，更改了[磁石](磁石.md)的合成配方，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[野花簇](野花簇.md)**
* 一种花，自然生成于[桦木森林](桦木森林.md)、[原始桦木森林](原始桦木森林.md)和[草甸](草甸.md)。
* 类似于[粉红色花簇](粉红色花簇.md)，同一格空间内最多可以容纳4株野花簇。
* 对野花簇[骨粉](骨粉.md)会掉落1个新的野花簇。
* 有4种方向。
* 可以放入[堆肥桶](堆肥桶.md)中堆肥。
* 可以用于合成[黄色染料](黄色染料.md)。
* 能用于引诱、喂食[蜜蜂](蜜蜂.md)。

* *[枯叶堆](枯叶堆.md)**
* 一种装饰性方块，自然生成于[森林](森林.md)、[黑森林](黑森林.md)和[疏林恶地](疏林恶地.md)。
* 类似于粉红色花簇，同一格空间内最多可以容纳4个枯叶堆。
* 有4种方向。
* 有独特方块音效。
* 可由烧炼[树叶](树叶.md)获得，也可以作为燃料用于[烧炼](烧炼.md)。
* * 每个枯叶堆可烧炼0.5个物品。

* *[结构方块](结构方块.md)**
* <code>load</code>模式下的结构方块现在具有新选项<code>Strict Placement</code>。
* * 新选项为<code>true</code>时，被放置的结构中的方块将不会触发方块更新、方块实体副效果或形状更新。

* * 比如，[活塞](活塞.md)将可推动方块转变为[移动的活塞](移动的活塞.md)时，被推动方块不再产生余留更新。这一更改在被活塞推动的[侦测器](侦测器.md)的行为变化上尤为明显。<ref></ref>

* * 注：文本组件嵌入NBT时，布尔值会被视为数字。若要将布尔值参数传递到翻译，则需要使用字符串形式。
* * <code>nbt</code>类型和<code>interpret</code>设置为<code>true</code>的文本组件，将直接按给定的nbt解析文本组件，而非先转换为字符串再解析为JSON。
* 更新了悬停事件格式：
* * <code>hoverEvent</code>字段现在重命名为<code>hover_event</code>。
