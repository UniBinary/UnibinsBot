# 磨制黑石砖楼梯

*页面ID: 58303* | *来源: Minecraft Wiki*

* *磨制黑石砖楼梯（Polished Blackstone Brick Stairs）**是[磨制黑石砖](磨制黑石砖.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
磨制黑石砖楼梯会自然生成在[堡垒遗迹](堡垒遗迹.md)和下界的[废弃传送门](废弃传送门.md)中。

# 破坏
挖掘磨制黑石砖楼梯的合适工具是镐。磨制黑石砖楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

磨制黑石砖楼梯被破坏后会掉落自身。
