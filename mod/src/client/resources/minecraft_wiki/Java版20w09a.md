# Java版20w09a

*页面ID: 55602* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w09a**是[Java版1.16](Java版1.16.md)的第4个快照，发布于2020年2月26日<ref name="20w09a"></ref>，加入了[哭泣的黑曜石](哭泣的黑曜石.md)、[标靶](标靶.md)、新的进度、新的配方书和新的粒子，重命名[僵尸猪人](僵尸猪人.md)为[僵尸猪灵](僵尸猪灵.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[哭泣的黑曜石](哭泣的黑曜石.md)**
* 目前只有装饰作用，但会在将来实现功能。<ref></ref>
* 可通过与[猪灵](猪灵.md)进行[以物易物](以物易物.md)获得。
* 会发出[亮度](亮度.md)等级为10的光。
* 会发出紫色粒子。
* 可被[活塞](活塞.md)移动。

* *[标靶](标靶.md)**
* 新的红石元件，被[弹射物](弹射物.md)击中后会发出红石信号。
* * 弹射物击中的位置越接近靶心，其发出的红石信号越强。
* 可使用4个[红石粉](红石粉.md)和1个[干草捆](干草捆.md)合成。

# = 游戏内容 =
* *[进度](进度.md)**
* 加入了新进度“”。
* * 玩家需用弹射物击中[标靶](标靶.md)的靶心来完成此进度。

* *[配方书](配方书.md)**
* 加入了绯红与诡异木[告示牌](告示牌.md)的合成配方，可通过获取对应种类的木板解锁。

* *[标签](Java版标签.md)**
* 加入了新的方块标签。
* * 包含[梯子](梯子.md)、[藤蔓](藤蔓.md)、[脚手架](脚手架.md)和[垂泪藤](垂泪藤.md)。
* * 用于辨别哪些方块可以攀爬。
* 加入了新的实体标签。
* * 应用于[箭](箭.md)、[雪球](雪球.md)、[火焰弹](火焰弹.md)、[恶魂火球](恶魂火球.md)、[鸡蛋](鸡蛋.md)、[三叉戟](三叉戟.md)、[末影龙火球](末影龙火球.md)和[凋灵之首](凋灵之首.md)上。
* * 用于辨别哪些实体可以在击中[紫颂花](紫颂花.md)时将其破坏。

* *[统计](统计.md)**
* 加入了击中[标靶](标靶.md)次数的统计信息。

# = 常规 =
* *[粒子](粒子.md)**
* 为[哭泣的黑曜石](哭泣的黑曜石.md)加入了3种粒子：。

# 更改
# = 方块 =
* *[绯红木告示牌和诡异木告示牌](告示牌.md)**
* 现在可以被合成。

* *[下界菌](下界菌.md)**
* 英文名称由“Fungi”重命名为“Fungus”。
* 现在可以种在[花盆](花盆.md)里。
* 现在只能在对应变种的[菌岩](菌岩.md)上长成[巨型下界菌](巨型下界菌.md)。

* *[熔岩](熔岩.md)**
* 现在能够推动[实体](实体.md)。

* *[下界苗](下界苗.md)**
* 现在属于可替代植物[材料](材料.md)。

* *[紫珀柱](紫珀柱.md)**
* 更改了顶面纹理，以与[基岩版](基岩版.md)统一。

* *[菌索](菌索.md)**
* 现在可以种在[花盆](花盆.md)里。
* 诡异菌索现在属于可替代植物[材料](材料.md)。

* *[去皮绯红与诡异菌柄](原木.md)**
* 更改了顶面纹理。

* *[垂泪藤](垂泪藤.md)**
* 现在可以攀爬垂泪藤了。
* 现在属于可替代植物[材料](材料.md)。

# = 物品 =
* *[钻石斧](钻石斧.md)、[钻石靴子](钻石靴子.md)、[钻石头盔](钻石头盔.md)、[钻石锄](钻石锄.md)、[钻石护腿](钻石护腿.md)、[钻石镐](钻石镐.md)、[钻石锹](钻石锹.md)、[钻石剑](钻石剑.md)、[金锄](金锄.md)、[金镐](金镐.md)、[下界合金镐](下界合金镐.md)、[木锄](木锄.md)和[木镐](木镐.md)**
* 对纹理进行了细微的更改，以与[基岩版](基岩版.md)统一。

* *[锄](锄.md)**
* 现在能够快速破坏[下界疣块](下界疣块.md)和[诡异疣块](诡异疣块.md)。

# = 生物 =
* *[疣猪兽](疣猪兽.md)**
* 轻微调整了纹理。

* *[猪灵](猪灵.md)**
* 现在拥有了<code>IsImmuneToZombification</code>数据值，可防止其在主世界中僵尸化。
* 幼年猪灵现在会骑乘幼年[疣猪兽](疣猪兽.md)。

* *[骷髅马](骷髅马.md)和[僵尸马](僵尸马.md)**
* 现在可以被[拴绳](拴绳.md)牵引。

* *[僵尸猪人](僵尸猪人.md)**
* 被重命名为“僵尸猪灵”（zombified piglin）。
* 更新了[模型](模型.md)与纹理。

# = 非生物实体 =
* *[矿车](矿车.md)**
* 现在会检测实体下车位置的空间高度是否能够容下该实体。

# = 游戏内容 =
* *[以物易物](以物易物.md)**
* 重新设置了以物易物的战利品，使之更吸引生存玩家。<ref name="20w09a"/>
* 新的以物易物战利品的具体组成包括：
* * 常见交换物（，或约8.85%）：6-10个[菌光体](菌光体.md)、1个[火焰弹](火焰弹.md)、8-16个[沙砾](沙砾.md)、4-10个[皮革](皮革.md)、4-10个[诡异菌](诡异菌.md)、4-16个[下界砖](下界砖.md)、1个[黑曜石](黑曜石.md)或1-3个[哭泣的黑曜石](哭泣的黑曜石.md)。
* * 少见交换物（，或约4.42%）：8-16个[下界石英](下界石英.md)、5-12个[荧石粉](荧石粉.md)、2-6个[岩浆膏](岩浆膏.md)、4-8个[末影珍珠](末影珍珠.md)或8-24个[线](线.md)。
* * 稀有交换物（，或约2.21%）：1个[诡异菌岩](诡异菌岩.md)、1个[药水](药水.md)或1个[喷溅药水](喷溅药水.md)。
* * 超稀有交换物（，或约0.44%）：1个[下界合金锄](下界合金锄.md)。
* 但由于一个漏洞，每次以物易物所得的物品都以1-5个为一组。
* *[配方书](配方书.md)**
* 染色玻璃的合成配方现在只会在玩家在物品栏中获得相应颜色的[玻璃](玻璃.md)时解锁。

* *[标签](Java版标签.md)**
* 为[绯红菌](绯红菌.md)、[诡异菌](诡异菌.md)、[绯红菌索](绯红菌索.md)和[诡异菌索](诡异菌索.md)加入了方块标签。

# = 常规 =
* *下界迷雾**
* 颜色现在在[生物群系](生物群系.md)之间平滑过渡。
* *[下界](下界.md)**
* 下界的光现在变得更昏暗了。
* *纹理**
* 删除了[去皮诡异菌柄](去皮诡异菌柄.md)的重复和未使用的纹理。
