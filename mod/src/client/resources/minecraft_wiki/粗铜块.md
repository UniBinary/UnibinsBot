# 粗铜块

*页面ID: 81409* | *来源: Minecraft Wiki*

* *粗铜块（Block of Raw Copper）**是用于储存[粗铜](粗铜.md)的方块。

# 生成
# = 自然生成 =
粗铜块有较小的概率自然生成在[铜矿脉](铜矿脉.md)中。

# 获取
# = 合成 =

# 破坏
挖掘粗铜块的合适工具是镐。粗铜块需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

粗铜块被破坏后会掉落自身。

# 用途
粗铜块主要用于储存粗铜。
