# Java版18w10c

*页面ID: 33967* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w10c**是[Java版1.13](Java版1.13.md)的第26个快照，发布于2018年3月8日<ref></ref>，加入了含水特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[水](水.md)**
* 新的水的物理性质。
* * 水能在以下方块中放置：楼梯、台阶、木栅栏、石墙、铁栏杆、玻璃板。
* ** 水可以流出这些方块，但不能流进。
* ** 当充满水时，方块会被所有游戏内容算为水方块（如游泳）。
* ** 水会流出方块的所有表面。
* * 移除<code>flowing_water</code>与<code>flowing_lava</code>方块。
* * 移除方块标签<code>water_hacked</code>与<code>waterlogged</code>。
* * 所有可以被放进水的方块现在拥有标签<code>waterlogged</code>了。
* * 诸如气泡柱和海带的方块现在总会被计为水源。

# 更改
# = 生物 =
* *[幻翼](幻翼.md)**
* 现在是亡灵生物。
* * 这说明该生物可以被治疗药水伤害，被伤害药水治愈，不受凋灵攻击，会被亡灵杀手魔咒影响。
