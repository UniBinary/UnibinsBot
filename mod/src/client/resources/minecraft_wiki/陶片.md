# 获取
# = 考古战利品 =
用[刷子](刷子.md)刷扫下列结构和地物里的[可疑的方块](可疑的方块.md)有概率掉落陶片。

# = 饰纹陶罐 =
被不具有[精准采集](精准采集.md)的[剑](剑.md)、[锹](锹.md)、[镐](镐.md)、[斧](斧.md)、[锄](锄.md)、[三叉戟](三叉戟.md)或[重锤](重锤.md)挖掘破坏，或是被[箭](箭.md)、[三叉戟](三叉戟.md)、[掷出的鸡蛋](掷出的鸡蛋.md)、[雪球](雪球.md)、[小火球](小火球.md)、[恶魂火球](恶魂火球.md)、[末影龙火球](末影龙火球.md)、[凋灵之首](凋灵之首.md)、[风弹](风弹（实体）.md)、[烟花火箭](烟花火箭.md)或击毁时，附有陶片的[饰纹陶罐](饰纹陶罐.md)会掉落对应陶片。

[试炼密室](试炼密室.md)中生成的饰纹陶罐会随机附有涡流、旋风或刮削纹样陶片。

# 你知道吗
* 游戏中陶片的英文曾由Pottery Sh**a**rd更名为Pottery Sh**e**rd。据[韦氏词典的解释](https://www.merriam-webster.com/dictionary/shard)，尽管在英文语境下shard和sherd基本同义，但考古学上更偏好“sherd”这一词形。即，sherd一词可特指考古发掘出的陶片。
