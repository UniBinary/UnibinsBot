# 生成
[流浪者](流浪者.md)、[沼骸](沼骸.md)和[焦骸](焦骸.md)可以使用[弓](弓.md)来发射药箭，其中流浪者会发射延长版迟缓之箭，沼骸会发射剧毒之箭，[焦骸](焦骸.md)会发射虚弱之箭，以上生物不需要拥有箭就可以无限发射箭。由非玩家生物发射的药箭不能被回收。

[发射器](发射器.md)在使用药箭时会将其发射。

[玩家](玩家.md)使用弓或弩可以发射药箭。

# = 炼药锅 =

对装有[药水](药水.md)的[炼药锅](炼药锅.md)使用箭可得到药箭，得到药箭的数量取决于炼药锅中的药水。当炼药锅是满时可以得到16支药箭，当炼药锅是满的时候可以得到32支药箭，而当炼药锅是全满的时候可以获得整整一组64支药箭。这比使用滞留药水制作药箭更有效率，平均每瓶药水可制作21.33支药箭。

# 用途

具有[无限](无限.md)魔咒的弓在使用药箭射击时，药箭会被正常消耗。

# 行为

药箭具有与箭相同的行为。

药箭在卡进方块30秒后，会集中散发一次药水粒子效果，随后丢失所有的药水效果数据。此时再次捡起只会获得普通的箭。

# == 造成状态效果 ==
药箭在命中生物时会对其施加对应的状态效果。
* 伤害之箭与治疗之箭在击中瞬间，其药水效果生效的时序优先于箭矢本身的伤害，且可对小范围内实体施加伤害/治疗效果。若射出药箭的药水效果造成的魔法伤害大于被击中实体生命值，该药箭不会消失。

# 箭伤害

或（伤害亡灵生物时）击中生物时，伤害计算并非简单取最高值，具体计算方式详见[受击后伤害免疫](受击后伤害免疫.md)。
