# 火焰保护

*页面ID: 35001* | *来源: Minecraft Wiki*

* *火焰保护（Fire Protection）**是一种用于[盔甲](盔甲.md)的[魔咒](魔咒.md)，能减少火焰伤害。

# 获取

# 用途
火焰保护与其任何不共存魔咒被应用在同一个物品上时，每个魔咒都会互不干扰地产生效果。

# = 减少伤害 =

火焰保护可以减少火焰伤害，包括[火](火.md)，[熔岩](熔岩.md)，[岩浆块](岩浆块.md)和[火焰弹](火焰弹.md)造成的伤害。

每魔咒等级提供2点魔咒保护系数（EPF），即8%伤害减免。

# = 降低设置的着火时间最低值 =

穿戴具有火焰保护的盔甲的生物，受到任何设置生物着火时间最低值的效果时，被施加的着火时间将减少<code>-{}-*等级*×15%</code>。计算魔咒等级时取所有装备的魔咒等级的总和。等级达到7级时，生物不能着火。

持续身处[火](火.md)中或在火中移动而获得的着火时间不被这一魔咒减少。

已经着火的[生物](生物.md)穿上具有火焰保护的盔甲，着火时间不能降低。

# 你知道吗
* 如果火焰保护的等级是负数，玩家穿上那件盔甲受到的火焰伤害如常，但是着火的时间会增加。着火时间不会增加，但受到的火焰伤害会增加。
