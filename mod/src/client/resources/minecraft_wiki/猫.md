* *猫（Cat）**是一种可驯服的友好生物。

# 生成
在世界生成时，一个[女巫](女巫.md)和一只未驯服的黑猫固定生成于[沼泽小屋](沼泽小屋.md)的红色蘑菇[盆栽](盆栽.md)前，它们不会自然消失。

通过[刷怪蛋](刷怪蛋.md)或未指定种类的命令在沼泽小屋7×7×9格的区域内生成的猫都是黑猫。

# = 村庄生成 =
# == Java版 ==
猫会在一个拥有5张已被使用的[床](床.md)的[村庄](村庄.md)或沼泽小屋中生成。

每个[维度](维度.md)每隔，游戏会随机选择一名非死亡状态下的[玩家](玩家.md)（包含[旁观模式](旁观模式.md)），然后基于该玩家的位置，在X轴和Z轴方向分别随机偏移8-32格作为生成位置。

如果该生成位置合法且半径48格范围内有5张以上已被认领的床，且水平[切比雪夫距离](切比雪夫距离.md)48格内、竖直距离8格内的猫的数量小于5，则在该位置生成一只随机外观的猫。非满月期间，猫在生成时会随机挑选除黑猫外的10种外观；满月期间，猫在生成时会随机挑选所有11种外观。

若生成位置虽合法但周围不具有足够的床或周围已存在的猫过多，且该位置位于沼泽小屋中标签控制}}，则在该位置生成一只黑猫标签控制}}。

# == 基岩版 ==
村庄会不定期随机生成未驯服的猫以满足每4个村民1只猫的配额，最多达到5只。所有村庄边界以内的猫都会被计入，包括幼年猫、从村庄以外进入的猫甚至被玩家驯服的猫。如果猫的数量不够配额，村庄就会尝试生成直到满足配额数量。村庄生成的猫的生成范围总是与[铁傀儡](铁傀儡.md)的生成范围一致，即生成在围绕由床、钟或其他工作方块构建的村庄范围的中心的17×13×17范围内的最高可生成位置。

猫在村庄生成时，有25%概率是幼年猫；满月期间在村庄生成时，有50%概率是黑猫。

# 行为
猫不会受到[摔落伤害](摔落伤害.md)，但仍会像大多数生物那样避免掉下正常情况下会造成摔落伤害的悬崖。

猫能看到[隐身](隐身.md)的玩家。

除了移动速度较快外，幼年猫的行为与成年猫没有差别。

猫会对正在追赶玩家的[幻翼](幻翼.md)发出嘶嘶声。

[苦力怕](苦力怕.md)会与猫保持6格的距离。不过已经开始引爆的苦力怕不会远离猫，除非玩家不在其爆炸半径内。

[幻翼](幻翼.md)会与猫保持16格距离。

猫会浮在水中，而幼年猫在获救前可能会溺水死亡。

# = 流浪猫 =
流浪猫默认是未驯服的。自然生成的猫都是流浪猫。

与[狼](狼.md)不同，流浪猫会消失。

流浪猫会寻找并攻击15格内的[兔子](兔子.md)和幼年[海龟](海龟.md)。在发动攻击之前，它们会先以[潜行](潜行.md)姿态接近猎物。

流浪猫可以透过[方块](方块.md)定位目标。

尽管流浪猫自然生成在村庄中，它们也不一定会留在那里，它们更喜欢到处探索。

流浪猫会主动远离16格以内、非创造或旁观模式的玩家，并且当玩家显著移动（大于等于0.1格/刻，玩家正常行走会触发，潜行时移动则不会）或晃动视角（大于等于5°/刻）时，流浪猫会以更快的速度逃跑（1.33倍原本移动速度）。流浪猫没有处于逃跑状态时，可以主动慢慢接近6格以内、手持[生鳕鱼](生鳕鱼.md)或[生鲑鱼](生鲑鱼.md)的玩家，最终停留并进入乞食状态。驯服前如果玩家有发生显著移动、晃动视角，或手持物品变为前述以外物品的情况，也会立即使流浪猫进入逃跑状态。

# = 繁殖 =

[300px|缩略图|两只成年猫和一只刚出生的幼年猫](File:Cats and kitten.png.md)

当给两只生命值已满的已驯服的猫喂[生鳕鱼](生鳕鱼.md)或[生鲑鱼](生鲑鱼.md)时，它们会进入繁殖模式。且其中至少有一只猫未坐着时，才会繁殖出一只幼年猫，并掉落，且在或内无法再次繁殖。幼年猫会随机遗传双亲某一方的毛色，项圈的颜色为双亲项圈颜色的[有效混色](染料#混色机制.md)，如果有效混色不存在则随机遗传一方的项圈颜色。

繁殖出的幼年猫会出生在其中一只猫的[判定箱](判定箱.md)内，并选择该猫的主人作为自己的主人，出生在哪只猫的判定箱内与幼猫的毛色没有关系。
* 如果两只猫属于同一个玩家，那么其繁殖出的猫也会属于这个玩家。
* 两只猫所属的玩家不同时，若喂食后其中一只猫被下令坐下，则繁殖出的幼年猫属于另一只猫的主人；否则幼年猫将属于更早被加载的猫的主人。

可以给幼年猫喂生鳕鱼或生鲑鱼来加快其生长。每条生鱼可以减少约剩余成长时间的10%。

对幼年猫[金蒲公英](金蒲公英.md)可以阻止其成长为成年猫，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年猫无法被喂食除金蒲公英外的其他物品。

# = 治疗 =
猫的主人给受伤的猫喂食[生鳕鱼](生鳕鱼.md)和[生鲑鱼](生鲑鱼.md)能恢复它们的生命值，其他玩家给猫喂食不能恢复生命值。

与驯服的[狼](狼.md)不同，驯服的猫的尾巴并不会反映其生命值。

# 驯服
[150px|right|upright|缩略图|一只坐着的已驯服的黑猫](File:Tamed black cat.png.md)

流浪猫可以用[生鳕鱼](生鳕鱼.md)或[生鲑鱼](生鲑鱼.md)驯服。与野生的[狼](狼.md)不同的是，流浪猫即使正在攻击其他生物，也可以被驯服。驯服后，猫会跟随驯服它们的[玩家](玩家.md)。已被驯服的猫不会消失，也不会害怕玩家，并经常性地发出咕噜咕噜或喵~的声音。与[狼](狼.md)类似，且如相同的条件，它们会在玩家离开超过12格远时[传送](#传送.md)到玩家处。

在不拿着[生鳕鱼](生鳕鱼.md)、[生鲑鱼](生鲑鱼.md)或[拴绳](拴绳.md)的情况下，玩家可以对猫按键来让它们坐下并且可以再次按键来让它站起来。同时猫也会主动坐在某些方块上（详见下方）。

[291px|左|缩略图|坐在床上的猫](File:Cats Sitting on Bed.png.md)

除非被命令坐下，否则猫不会长时间保持不动，它们喜欢围着玩家转悠。

没有坐下的猫会在水平4格半径方形水平范围内的当前Y轴下尝试跳到[箱子](箱子.md)、[床](床.md)的下半部分和燃烧的[熔炉](熔炉.md)上，并且会在没有玩家命令的情况下立刻坐下。当猫坐在箱子或大型箱子上时猫坐在其上的判定条件为猫的[边界箱](边界箱.md)是否与该箱子或大型箱子上方方块相交<ref></ref>}}，会导致该箱子或大型箱子无法被打开。自行坐下的猫可被命令站起，玩家手持生鱼靠近它们也可以让它们站起来。也可以通过移除其下面的[方块](方块.md)或推开它们的办法使猫下来。如果猫在地面层（地表的一部分）或顶部有方块时，猫不会尝试坐在这些方块上。猫可能会趴在空床上睡觉。

当玩家被敌对生物伤害（或被药水伤害，但不包括自然伤害）后一段时间，站立且驯服的猫不可被命令坐下。

与其他可驯服生物一样，驯服的猫死亡时会给或显示一条[死亡消息](死亡消息.md)。

# = 传送 =
除了以下例外，猫会在与玩家距离12格以上时传送到玩家身边。猫有可能传送到一些例如[冰](冰.md)层下的危险区域以至于受到窒息、溺水等伤害。

猫在下列情况下**不会**传送：
* 猫已经被命令坐下。
* * 例外：当坐下的猫受到攻击时，它很可能会传送（传送后不会坐下）。一个戏剧性的例子：如果一只猫坐在室外并被[闪电](闪电.md)击中，它将浑身是火地出现在主人面前。
* 猫正在尝试坐上箱子、床或者熔炉。
*
* 猫坐在[矿车](矿车.md)或[船](船.md)里。
* 猫被[拴绳](拴绳.md)拴到[栅栏](栅栏.md)上。
* 猫位于一个未载入的[区块](区块.md)里。
* 玩家为中心的5×5×1的区域边缘的方块都不是下面为固体方块、上面为透明方块的透明方块。
* 玩家在其他[维度](维度.md)中。猫会待在所在的维度，直到玩家回到该维度。
* 玩家在[水](水.md)中。猫会在玩家离开水后立即尝试传送到玩家旁边。

猫的传送过程不会有任何音效。<ref></ref>

# 你知道吗
* 在[MINECON Earth 2018](MINECON Earth 2018.md)直播中，Jeb透露猫的另一种新纹理将由社区玩家选出后加入。最终，[GoodTimesWithScar](https://www.youtube.com/user/GoodTimesWithScar)的猫“Jellie”获胜，其皮肤在[Java版1.14](Java版1.14.md)和[基岩版1.10.0](基岩版1.10.0.md)中加入。“Jellie”猫已于2024年1月5日去世。<ref></ref>
* 现实生活中，猫[从高空坠落时自动调整姿态的能力](Wikipedia:Cat righting reflex.md)十分著名（虽然还是有可能摔伤）。这一点也反映到了Minecraft中——猫与豹猫对坠落伤害完全免疫。
* 在[Java版1.14](Java版1.14.md)和[基岩版1.10.0](基岩版1.10.0.md)前，猫是从豹猫驯服而来的，而现实中的猫是从生活在稀树草原的[非洲野猫](wzh:亚非野猫.md)进化而来的。
* 对着已驯服的猫猫[刷怪蛋](刷怪蛋.md)，生成的幼年猫也是已驯服的。
* 早在花猫加入原版Minecraft游戏之前，在[Minecraft: Story Mode](Minecraft: Story Mode.md)第六章“通往神秘国度的传送门”中，就出现了一只名为“Winslow”的花猫，且二者的皮肤十分相似。
* [西服猫](Wikipedia:Tuxedo cat#Tuxedo cats.md)是基于[Jeb](Jeb.md)的宠物，母猫“牛顿”（Newton）设计的。<ref></ref>它已于2014年去世。<ref></ref>
* 白猫的皮肤外观基于[泰国御猫](wikipedia:Khao Manee.md)，泰国的一个稀有猫品种。
* 黑猫的皮肤外观基于[孟买猫](wzh:孟买猫.md)。其祖先品种是[缅甸猫](wzh:缅甸猫.md)和[美国短毛猫](wzh:美国短毛猫.md)。
* 游戏中的花猫和白猫表现出了异瞳特征（即两只眼睛颜色不同）。
* 在游戏中可以让两只花猫繁殖，但在现实生活中是行不通的。这是因为绝大部分[三花猫](wzh:三花猫.md)都是母猫，而此类极少数的公猫却不具备生育能力。
* 猫的音效是基于[Samuel Åberg](Samuel Åberg.md)的宠物Odi录制的。<ref></ref>
