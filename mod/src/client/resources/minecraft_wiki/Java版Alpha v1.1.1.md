# Java版Alpha v1.1.1

*页面ID: 32522* | *来源: Minecraft Wiki*

</ref>}}
<onlyinclude>

* *Alpha v1.1.1**是的一次秘密更新，发布于2010年9月18日<ref name="seecret"></ref>，加入了[潜行](潜行.md)、新的[画](画.md)和[钓鱼竿](钓鱼竿.md)。

# 新内容
# = 物品 =
* *[钓鱼竿](钓鱼竿.md)**
* 目前没有用途。
* 可以堆叠。

# = 非生物实体 =
* *[画](画.md)**
* 加入了5幅新的画：
* * Graham
* * Creebet
* * Donkey Kong
* * Skeleton
* * Pigscene

# = 游戏内容 =
; [潜行](潜行.md)
* 一种新的游戏机制，按住触发。

# = 常规 =
* 现在能改变鼠标的灵敏度。
* 加入了滑动条以改变音乐和音效的音量大小。
* 增加了音轨。

# 更改
# = 非生物实体 =
* *[画](画.md)**
* 更改了Sea和Stage的纹理。

# = 常规 =
* 调整FPS/调试屏幕的设置已经被键取代。可重新加载所有网络上的资源。
* 昼夜更替现在更加流畅。

* *[无限世界预览器](无限世界预览器.md)**
* 现在不再可用。

# 修复
* *修复了2个漏洞**
* 修复了刷雪球的漏洞。
* 雪块现在只会掉落4个雪球。</onlyinclude>

# 你知道吗
* 由于技术原因，周末可免费游玩该版本，其因是登录服务器不能正确工作。
