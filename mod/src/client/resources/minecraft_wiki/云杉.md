云杉和松树是生成于低温生物群系的植被[地物](地物.md)，分为**普通云杉（Spruce）**、**普通松树（Pine）**、**大型云杉（Mega Spruce）**、**大型松树（Mega Pine）**、和**倒下的云杉（Fallen Spruce）**。

# 种类
[缩略图|右|普通云杉、大型云杉、两棵普通松树、大型松树](File:Taiga Trees.png.md)

# = 普通云杉 =
普通云杉的树叶趋向于分层独立生长，而非橡树和白桦的团状。

其整体高度为6-11格，树干高5-8格；整体高度为5-13格，树干高4-11格。

# = 普通松树 =
普通松树的树叶都聚集在树顶，树冠中心密集、末端稀疏，树叶稀少时形如火柴头，多则近似于八面体。

其整体高度为7-11格，树干高3-5格；整体高度为8-13格，树干高3-5格。

# = 大型云杉与大型松树 =
大型云杉呈高大的锥形，树冠与普通云杉一样分层。大型松树如直指天空的箭头，树冠为较扁的锥形。

这两类树木高14-30格，树干横截尺寸都为2×2格，且树干西北角的原木顶端总是比其他3列原木高出1格。

# = 覆藤云杉 =

覆藤云杉又称濒死的云杉。除了其暴露的原木爬满[藤蔓](藤蔓.md)外，它与普通云杉在外观上并无差别。

# = 倒下的云杉 =
倒下的云杉包含一个单独的纵向原木作为树桩，距其一两格远的地方另有0-8块平躺的原木。有时这些原木上会出现[蘑菇](蘑菇.md)，但树桩处不会出现藤蔓。

# 生成
[缩略图|右|大型云杉/松树使土类方块转变为灰化土的最大范围（上方是北）](File:PodzolPattern.png.md)
所有云杉和松树生成时都会将下方1格的方块转变为[泥土](泥土.md)。

大型云杉和大型松树生成时会将下方的4个方块替换为[灰化土](灰化土.md)，同时将周围的[草方块](草方块.md)、泥土、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[菌丝体](菌丝体.md)、[苔藓块](苔藓块.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苍白苔藓块](苍白苔藓块.md)和转化为灰化土。
