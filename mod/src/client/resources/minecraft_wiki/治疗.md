# 治疗

*页面ID: 30531* | *来源: Minecraft Wiki*

* *治疗（Healing）**是一种恢复[生命](生命.md)的机制。

# 自然恢复
将[游戏规则](游戏规则.md)设为<code>false</code>可以禁用生命值的自然恢复机制。

# = 饥饿值 =
当玩家的[饥饿值](饥饿值.md)大于等于时，他们就可以每4秒恢复生命。这种生命恢复的方式每恢复生命会使玩家的[消耗度](消耗度.md)增加6，而每4点消耗度将会扣除饥饿值。优先消耗玩家积累的食物饱和度。

# = 饱和度 =
当玩家的饥饿值**全满**并有[饱和度](饱和度.md)盈余，则会消耗饱和度，并以每秒的速度恢复生命值。与前述的基于饥饿值的生命恢复一样，每恢复生命值增加6点消耗度。当玩家的食物饱和度处于最高水平时，可以快速恢复最多生命值。

# = 和平难度 =
当游戏[难度](难度.md)设为“和平”时，玩家每秒恢复生命值，饥饿值全满时每4秒额外恢复。[金苹果](金苹果.md)这种在饥饿值全满时还能吃的食物会进一步提升玩家的生命恢复速度。不过，这种生命恢复的方式仍然会消耗玩家的食物饱和度，无论玩家是否从其他难度切换至和平难度。

# 主动恢复
# = 药水 =
玩家可以饮用部分[药水](药水.md)来立即或逐渐恢复生命值。

# == 治疗药水 ==
治疗药水立即恢复生命值。被[荧石粉](荧石粉.md)加强的治疗药水恢复量提升至。

# == 再生药水 ==
再生药水在45秒内每2.5秒恢复生命值，累计。经过荧石粉加强后的再生药水恢复速率提升至每1.25秒恢复；经过[红石粉](红石粉.md)延长后的再生药水持续时间增至1:30。

# == 药箭 ==
由[弓](弓.md)、[弩](弩.md)或[发射器](发射器.md)射出的[药箭](药箭.md)会导致箭的伤害与状态效果叠加。治疗之箭的效果与其药水效果相同（效果为[瞬间治疗](瞬间治疗.md)的治疗之箭可恢复，效果为瞬间治疗II的治疗之箭可恢复）。再生之箭的效果持续时间比其药水要短。效果为[生命恢复](生命恢复.md)的再生之箭可持续5秒（可恢复），延长版则是或（可恢复}}或}}），效果为生命恢复II的再生之箭可持续2秒。

# = 金苹果 =
[金苹果](金苹果.md)通过以下方式治疗玩家：

* 与药水类似，金苹果会给予[生命恢复](生命恢复.md)状态效果。普通的金苹果赋予5秒的生命恢复II，附魔金苹果的生命恢复II持续或，分别累计恢复和}}或}}。附魔金苹果也会给予[抗火](抗火.md)和[抗性提升](抗性提升.md)。
* 普通的金苹果可由8个[金锭](金锭.md)和1个[苹果](苹果.md)合成，也可从战利品箱中找到；附魔金苹果无法合成，只能从战利品箱中找到。

# = 不死图腾 =
当玩家持有[不死图腾](不死图腾.md)受到来源不为或虚空的致命伤害时，不死图腾就会生效。生效时，使用-{}-者的生命值变为，原有的状态效果被全部清除。随后，使用-{}-者会获得40秒的[抗火](抗火.md)与45秒的[生命恢复](生命恢复.md)II（共恢复）以及5秒的[伤害吸收](伤害吸收.md)II状态效果。

# = 谜之炖菜 =
由[滨菊](滨菊.md)合成的[谜之炖菜](谜之炖菜.md)可给予玩家或的[生命恢复](生命恢复.md)I效果（可恢复}}或}}）。

# = 信标 =
最高等级的[信标](信标.md)可设置为提供生命恢复I效果。当玩家持续处于信标作用范围内时，信标给予的生命恢复效果平均每恢复生命值<ref></ref>。

# = 美西螈 =
玩家击杀与[美西螈](美西螈.md)战斗的生物后，附近20格内每只美西螈都会**分别**给予玩家的I效果，效果时长的叠加或。此外美西螈还会移除玩家身上的效果。

# 治疗生物
与玩家相反，大部分[生物](生物.md)不会治疗自身。但游戏中存在治疗生物的方法。

# = 药水 =
大部分生物可像玩家一样从治疗药水和再生药水中获得治疗。

[亡灵生物](亡灵生物.md)会被治疗药水**伤害**，要治疗它们需要使用伤害药水。再生药水和剧毒药水对亡灵生物完全无效。

普通药水只能对玩家自身使用，要治疗生物，应使用[喷溅药水](喷溅药水.md)、[滞留药水](滞留药水.md)或[药箭](药箭.md)。

[女巫](女巫.md)也会饮用治疗药水，因此属于少数的几种会自我治疗的生物，在[袭击](袭击.md)中女巫也会使用喷溅药水治疗[灾厄村民](灾厄村民.md)和[劫掠兽](劫掠兽.md)。

# = 自然恢复 =
[马](马.md)、[驴](驴.md)、[骡](骡.md)、[骷髅马](骷髅马.md)、[僵尸马](僵尸马.md)、[羊驼](羊驼.md)、[行商羊驼](行商羊驼.md)、[骆驼](骆驼.md)和[骆驼尸壳](骆驼尸壳.md)会以每分钟约的速度缓慢恢复生命值。

[悦灵](悦灵.md)每秒恢复生命值。

[快乐恶魂](快乐恶魂.md)每30秒恢复生命值。在[主世界](主世界.md)中，处于[雨](雨.md)或[雪](降雪.md)中时或飞行高度与[云](云.md)的高度（Y=192至196）相同时则每秒恢复生命值。

# = 使用物品 =
持有某些物品对以下生物时可以使其恢复一定量的生命值：

驯服[狼](狼.md)可治疗它因伤失去的生命值，同时驯服后狼的最高生命值由增至。

驯服后的[猫](猫.md)的最高生命值由增至。

[狐狸](狐狸.md)可通过给它们投喂效用性的物品进行治疗，若该物品是食物，则狐狸会在一段时间后吃掉，并获得食物带来的效果。但具备治疗能力的食物只有[金苹果](金苹果.md)、[附魔金苹果](附魔金苹果.md)和使用[滨菊](滨菊.md)合成的[谜之炖菜](谜之炖菜.md)。叼着[不死图腾](不死图腾.md)的狐狸受到致命伤害时不死图腾也会生效，并治疗狐狸。

# = 装死 =
[美西螈](美西螈.md)在[水](水.md)中受到来自其他实体的伤害时有概率“装死”以回复[生命](生命.md)值。装死时，美西螈会获得I效果，一次装死会回复生命值。

# = 村民 =
[村民](村民.md)在解锁新[交易](交易.md)时会获得10秒生命恢复I效果。

若村民成功入睡，它们的生命值会在黎明醒来时回满。

# = 蜘蛛 =

在[困难](困难.md)难度下，[蜘蛛](蜘蛛.md)在生成时有概率获得无限时长的生命恢复I效果。

# = Boss的治疗 =
# == 末影龙 ==
[末影龙](末影龙.md)可被末地黑曜石塔顶的[末地水晶](末地水晶.md)治疗。若正在治疗末影龙的末地水晶遭到破坏，则末影龙会因此受伤。

# == 凋灵 ==
[凋灵](凋灵.md)会无限持续恢复其生命值。

当凋灵50格内没有玩家时，会持续恢复生命值。
