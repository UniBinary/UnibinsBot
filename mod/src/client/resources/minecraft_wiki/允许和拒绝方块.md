# 允许和拒绝方块

*页面ID: 27051* | *来源: Minecraft Wiki*

* *允许方块（Allow）**和**拒绝方块（Deny）**是能够用于改变玩家在其上方放置和挖掘方块的权限的方块。

# 生成
允许和拒绝方块不会生成在世界中。

# 获取

允许和拒绝方块无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，允许和拒绝方块可以通过、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
没有工具可以加速对允许和拒绝方块的挖掘。

游戏模式不是创造模式、或在“玩家权限”屏幕中的“操作员命令”开关未打开的玩家，不能挖掘破坏允许和拒绝方块。

没有世界建造者权限的玩家，即使处于创造模式也不能挖掘破坏允许和拒绝方块。

允许和拒绝方块被破坏后不会掉落。

# 用途
允许和拒绝方块不能被[凋灵](凋灵.md)和[末影龙](末影龙.md)破坏。

只有或（下文称有权限的玩家）能放置允许和拒绝方块。

# = 改变放置和挖掘方块的权限 =
允许和拒绝方块会改变有权限的玩家以外的玩家（下文称无权限的玩家）在其上方放置和挖掘方块的权限。

允许方块允许无权限的玩家在其上方放置和挖掘方块，拒绝方块阻止无权限的玩家在其上方放置和挖掘方块；两种方块都不会影响其下方的区域。允许和拒绝方块本身对于无权限的玩家总是不可挖掘的，即使其下方有允许方块。

一个位置是否能放置和挖掘方块取决于其下方最近的一个允许或拒绝方块。通过在允许方块上方放置拒绝方块，可以使无权限的玩家只能编辑两者之间的区域。

有权限的玩家不受允许和拒绝方块的限制，总是可以放置和破坏方块，包括破坏允许和拒绝方块。
