# 携带版0.1.3

*页面ID: 21244* | *来源: Minecraft Wiki*

* *v0.1.3 alpha**是[携带版](携带版.md)的一次次要更新，在Android平台上发布于2011年12月2日<ref name=":0"></ref>，在iOS平台上发布于2011年12月14日<ref>https://web.archive.org/web/20120106171013/http://itunes.apple.com/us/app/minecraft-pocket-edition/id479516143</ref>，进行了一些更改，并修复了一些漏洞。

# 新内容
* *[数据更新方块](数据更新方块.md)**
* 用作未支持方块种类的占位符。

# 更改
* 更好的平板设备支持。
* 更少的游戏内过大的UI元素。
* 改进性能，尤其是无精美图像模式。
* 在[沙漠](沙漠.md)中加入了[仙人掌](仙人掌.md)。
* 加入了控制灵敏度的设置。
* 改进了网络的[区块](区块.md)加载。

# 内部版本
* 0.1.3有2个修订版本，区别仅在于版本号不同。
* * 0.1.3(1035)，大小1.58MB。
* * 0.1.3(1036)，大小1.58MB。

# J版本
[thumb|v0.1.3 alpha的J版本](File:Pocket Edition 0.1.3j.png.md)
* *v0.1.3j alpha**在Google Play上于未知日期发布，发布给较旧的Android设备提供支持，<ref name=":0" />并加入了更多音效。其内部版本号为0.1.3(1033)，大小为2.00MB。

# 演示版
v0.1.3 alpha的免费“lite”演示版曾在Google Play上发布，发布日期未知。2014年中旬，其被从Google Play和App Store中移除。<ref>https://www.youtube.com/watch?v=Rkd65MFCtsk</ref>其内部版本号现未知。

# J版本演示版
v0.1.3 alpha的免费J版本“lite”演示版曾在Google Play上发布，发布日期未知。2014年中旬，其被从Google Play和App Store中移除。<ref>https://www.youtube.com/watch?v=Q7LwcjKb_Qo</ref>其内部版本号现未知。

# 修复
* 修复了Android设备在连接到某些iOS服务器地图时的崩溃。
* 修复了Android设备在[雪](雪.md)上放置的方块在多人游戏中放置错误的问题。
* 改进了iOS设备上网络[区块](区块.md)的加载。
* 修复了iOS设备上在关闭选项菜单后开启对话的漏洞。
