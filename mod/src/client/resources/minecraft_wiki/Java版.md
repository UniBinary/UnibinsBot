* *Minecraft：Java版（*Minecraft: Java Edition*）**是[Minecraft](Minecraft.md)的初始版本，由[Mojang Studios](Mojang Studios.md)为、和系统开发。[Notch](Notch.md)于2009年5月10日启动该游戏的开发工作，并在同年5月17日公开发布了首个版本。游戏的完整正式版则在2011年11月18日的[MINECON 2011](MINECON 2011.md)上正式发布。

# 独有特性

Mojang Studios直接负责Java版的销售工作，因此无需经过平台持有者的认证。

Java版拥有独立的[启动器](启动器.md)。除最新版本和最新快照外，启动器还支持启动大多数旧版本的Java版。同时，启动器允许单独配置启动文件，这一功能对[Mod](Mod.md)、[开发版本](Java版版本记录/开发版本.md)和旧版本的使用十分友好。

相较于其他版本，Java版的代码更易于修改，且因提供了混淆映射表<ref></ref>和未经混淆的版本，使其成为目前拥有最多[Mod](Mod.md)和[定制服务器](定制服务器.md)的版本。不过，Java版内置的[Realms](Realms.md)是一项独立服务，与基岩版的对应服务并不相同。

2018年10月19日之前购买Java版的玩家，可免费获取[Windows 10版](Windows 10版.md)兑换码，但该兑换码需在2020年4月20日前使用。<ref></ref><ref></ref>

自2020年10月起，新购买Java版的玩家无需注册Mojang账户，而是直接与微软账户绑定。2021年初开始，Mojang账户逐步迁移至微软账户，完成迁移的玩家会获赠适用于Windows平台的基岩版和[迁移者披风](迁移者披风.md)。迁移完成后，玩家需通过微软账户登录启动器，Mojang账户不再适用。<ref></ref>2023年9月19日，Mojang账户迁移工作终止。此后，玩家若想游玩Minecraft，要么重新购买游戏，要么联系微软工作人员申请解冻Mojang账户以完成迁移。<ref></ref>

# 开发

# = 创作过程 =

[300px|缩略图|右|[[Java版pre-Classic rd-131655|Cave Game](File:CaveGame.png.md)]]

2009年，[Notch](Notch.md)在与TIG Source论坛的其他成员一同游玩[无尽矿工](无尽矿工.md)后，萌生了开发Minecraft的想法。<ref>http://forums.tigsource.com/index.php?topic=6273.0</ref>其他影响因素包括《[矮人要塞](wzh:矮人要塞.md)》《[地下城守护者](wzh:地牢守护者.md)》<ref></ref>，以及Notch自己之前的项目*[RubyDung](RubyDung.md)*<ref></ref>。

Notch刚开始开发Minecraft时，原本以为这只是一个小型项目。因此，当他在2009年5月13日上传第一个Minecraft的YouTube视频时，尚未确定正式名称，只是临时起了“*Cave Game*”这个名字。<ref></ref><ref>https://www.youtube.com/watch?v=F9t3FREAZ-k</ref>但在15日，可能是受到TIGSource论坛某用户在IRC聊天中的建议启发<ref>http://forums.tigsource.com/index.php?topic=6273.msg201261#msg201261</ref>，他宣布采用“*Minecraft: Order of the Stone*”这一名称（源自网络漫画*[The Order of the Stick](wikipedia:The_Order_of_the_Stick.md)*）<ref></ref>。不过次日其就被简化为“Minecraft”，原因是它更为简洁，且不会与*Order of the Stick*产生混淆。2009年5月16日，Notch发布了“早期个人单机Alpha”版本。<ref></ref>

# = Classic =

[300px|缩略图|右|Classic](File:Classic.png.md)

游戏最终于2009年5月17日首次公开发布。发布后的第三天就获得了IndieGames.com的反馈。<ref>http://www.indiegames.com/blog/2009/05/browser_game_pick_minecraft_ma.html</ref>除此之外，游戏还引入了创造模式的概念，该模式允许玩家使用几乎所有类型且无限的方块进行建造与破坏。2009年5月31日，游戏开始对多人游戏进行测试，并于6月7日正式对外公开。同年7月，游戏采用[Lightweight Java Gaming Library（LWJGL）](http://lwjgl.org/)进行了重写。<ref></ref>2009年9月1日，游戏开始引入生存模式并对其测试，在该模式中，玩家拥有生命条，需要采集方块、应对[生物](生物.md)。若玩家死亡，世界就会被删除，玩家只能创建新的世界重新开始游戏，这与之后加入的[极限模式](极限模式.md)较为相似。2009年10月27日，游戏重新引入创造模式。

# = Indev =

[缩略图|300px|右|[[Java版Indev|Indev](File:Indev.png.md)]]

Indev最初以“0.31”的方式于2009年12月23日发布，其源于Notch收到了让社区试用他在生存测试中新增功能的请求。但与Classic不同的是Indev仅限购买游戏的玩家游玩。

Indev的更新较为频繁，其有两个版本“0.31”与“Minecraft Indev”，前者加入了更完善、更真实的[亮度](亮度.md)系统和早期的世界类型，并重新引入了生存模式以取代创造模式，后者则引入了游戏的基本机制与玩法，生存模式日趋完善。

# = Infdev =

[缩略图|[[Minecraft Infdev](File:wowc.png.md)]]

Infdev于2010年2月27日发布，顾名思义该阶段的主要目的是为了测试无限世界。

Infdev前期主要用于稳定无限世界，并移除了Indev时期的世界类型。中期引入Alpha世界格式和新的地形生成器，并测试了一些新特性，比如大型树和玩家的重生能力。后期致力于加入新特性，例如3D[云](云.md)、[楼梯](楼梯.md)与更真实的[流体](流体.md)系统。此阶段还引入了[秘密更新](秘密更新.md)，这加入了更多的游戏特性，例如[矿车](矿车.md)和[地牢](地牢.md)。

# = Alpha =

[缩略图|300x300像素|[[Java版Alpha|Alpha](File:Old Nether.png.md)]]
Alpha阶段于2010年6月29日从Infdev阶段渐进而来，该阶段标志着游戏正式可以在独立客户端上游玩。

该阶段沿用了Infdev阶段的秘密更新，其加入了红石系统、甘蔗、船、史莱姆等新特性。此阶段还重新引入了多人游戏。

游戏于2010年10月31日发布了[万圣节更新](万圣节更新.md)，此次更新主要引入了[生物群系](生物群系.md)、[下界](下界.md)、新的生物、方块与物品，并在游戏外创造了[主题更新](主题更新.md)的概念，这一概念最终被延续至今，秘密更新最终亦被其取代。

# = Beta =

[缩略图|300x300px|[[Java版Beta|Beta](File:Beta.png.md)]]
游戏于2010年12月20日进入Beta阶段。该阶段加入了诸多新内容，包括新的Logo、启动器、[成就](成就/Java版.md)、[统计](统计.md)、[天气](天气.md)、[平滑光照](平滑光照.md)、[染料](染料.md)、[狼](狼.md)与[鱿鱼](鱿鱼.md)、[床](床.md)以及其他方块、生物和物品等。

[冒险更新](冒险更新.md)是Beta阶段的主要更新，其重点在于探索与战斗。由于更新内容较多，冒险更新被推迟并被分为两部分，Beta阶段部分的冒险更新主要加入了新的地形生成器、现代生物群系系统、繁殖系统、新的战斗系统、经验值、疾跑，还加入了[村庄](村庄.md)、[要塞](要塞.md)、[废弃矿井](废弃矿井.md)等结构。同时重新引入了创造模式。

该阶段同时引入了预发布版与发布候选，2011年9月9日起，Mojang开始公开发布预发布版以供玩家尝鲜测试新特性。现在的游戏开发流程亦逐步开始确立。

# = 正式版 =
[350px|缩略图|右|在[[末地](File:TheEnderdragon.png.md)中的[末影龙](末影龙.md)]]

Minecraft的正式发布版——Minecraft 1.0.0于MINECON 2011期间，即2011年11月18日下午9时54分（[UTC](wzh:格林尼治標準時間.md)），由Notch在主题演讲仪式上发布。Jeb在一条推特中证实了版本号为1.0.0，同时宣布游戏正式脱离Beta阶段。<ref></ref>此次更新加入的最核心的内容是玩家在[末地](末地.md)击败[末影龙](末影龙.md)后的游戏结局。

这也是Minecraft开始向新玩家收取全额费用的版本（定价为19.95欧元、16.95英镑、26.95美元、210港元、165元人民币），而Alpha和Beta版的玩家可通过正常更新获取该版本。正式版发布后，Notch在一次采访中表示，对于发布一款会被评分和评价的游戏，他感到十分紧张。不过，该版本发布后反响极佳，获得了众多游戏网站和玩家群体的高度评价。

自正式版发布以来，后续更新陆续加入了更多的新的游戏内容、生物及生物群系。若想了解Minecraft 1.0.0之后的完整更新列表，可参见[Java版版本记录](Java版版本记录.md)。

2017年9月18日发布的[1.12.2](Java版1.12.2.md)中，Java版被重命名为“Minecraft：Java版”，以与跨平台的[基岩版](基岩版.md)相区分。

2018年10月6日，Mojang开源了Java版的部分代码，主要包括[Brigadier](Brigadier.md)命令引擎和Data Fixer Upper。完全重写的游戏渲染引擎（名为“Blaze3D”）正考虑开源。<ref></ref>

# = 演示模式 =
[演示模式](演示模式.md)是为未购买Java版的玩家提供的，但其存在一些限制：

* 演示版始终处于[生存模式](生存模式.md)。
* 只能创建一个世界（Demo_World）。
* 世界只能使用同一个[种子](种子（世界生成）.md)生成：。
* 玩家游玩世界的时间有限（当计时器归零时，玩家仍可进入世界，但无法与世界进行交互）。
* 玩家名称固定为。
* 创建新的演示世界时，玩家会在出生点附近找到并获得一个[奖励箱](奖励箱.md)。

# 控制

Java版通过键盘和鼠标/触控板进行控制。

# 系统需求
# = 硬件需求 =
根据[Minecraft官方网站](https://www.minecraft.net/en-us/store/minecraft-deluxe-collection-pc?tabs=%7B%22details%22%3A1%7D#accordionv1-b6c8df09da-item-7739893325:~:text=Java%20System%20Requirements)：

; 最低配置
* **CPU**：Intel Core i3-3210 3.2GHz、AMD A8-7600 APU 3.1GHz、Apple M1或同等性能的CPU
* **芯片架构**：ARM、x64、x86
* **内存**：2GB
* **显卡（集成）**：支持OpenGL 4.4的Intel HD Graphics 4000（Ivy Bridge）或AMD Radeon R5系列（Kaveri）
* **显卡（独立）**：支持OpenGL 4.4的Nvidia GeForce 400系列或AMD Radeon HD 7000系列
* **存储设备**：至少需要1GB用于存储游戏核心文件、世界及其他文件

需要注意的是，配置低于“最低配置”时并非一定无法运行游戏，只是流畅性和游戏体验会较差。

; 推荐配置
* **CPU**：Intel Core i5-4690 3.5GHz、AMD A10-7800 APU 3.5GHz、Apple M1或同等性能的CPU
* **芯片架构**：ARM、x64、x86
* **内存**：4GB
* **显卡**：支持OpenGL 4.45的GeForce 700系列或AMD Radeon Rx 200系列（不包括集成芯片组）
* **存储设备**：4GB（推荐使用SSD）

# = 软件需求 =
; 最低配置
* **系统**：
* * Windows：需为Windows 7及更高版本
* * macOS：需为macOS 10.14.5 Mojave及更高版本
* * Linux：需为2014年及之后推出的现代发行版

; 推荐配置
* **系统**：
* * Windows：推荐使用Windows 10及更高版本
* * macOS：推荐使用macOS 10.14.5 Mojave及更高版本
* * Linux：推荐使用2017年及之后推出的现代发行版

; Java配置
* 自[1.12](Java版1.12.md)（[17w13a](17w13a.md)）起，运行Minecraft的最低要求为Java 8。若玩家不确定设备是否已安装Java 8，安装程序会默认自动安装并使用支持Minecraft运行的Java版本。
* 自[1.17](Java版1.17.md)（[21w19a](21w19a.md)）起，运行Minecraft的最低要求为Java 16。
* 自[1.18](Java版1.18.md)（[1.18-pre2](Java版1.18-pre2.md)）起，运行Minecraft的最低要求为Java 17。
* 自[1.20.5](Java版1.20.5.md)（[24w14a](24w14a.md)）起，运行Minecraft的最低要求为Java 21，且操作系统须为64位。
* 自[26.1](Java版26.1.md)（[26.1-snapshot-1](Java版26.1-snapshot-1.md)）起，运行Minecraft的最低要求为Java 25。

需要注意的是，若使用的Java版本与操作系统位数不匹配（32位或64位）、使用部分Java 7版本，或安装多个Java版本来运行Minecraft Java版，可能会出现一些运行问题。

运行Java版需要稳定的互联网连接，用于下载游戏文件、验证用户名以及连接多人游戏服务器。至少需要连接一次互联网以完成Java版的下载和运行；之后可在断开互联网连接的情况下游玩，但接收更新或联机需在联网状态下进行。

Java版无法在Windows RT平板上运行。

Java版无法在Chromebook上原生运行，但在设置Crouton后可运行Java（及Java版Minecraft）。

关于运行Java版服务器的系统需求信息，可参考[此处](服务器/需求.md)。

# 公众反应

Java版自2009年6月首次发售以来，销量已超过3000万份。

Minecraft获得了评论家的高度评价，一跃成为最具影响力且发售最成功的独立游戏之一。游戏因其赋予玩家的自由创造空间和整体的动态性而广受赞誉。PC Gamer将Minecraft评选为“忙里偷闲的好游戏”第四名。<ref>http://www.pcgamer.com/2010/07/05/50-games-to-play-at-work/5/</ref>Scott Munro在日志中重新审视了Alpha版，称其“已经颇具特色”，并力荐读者购买。<ref>http://blogs.dailyrecord.co.uk/gaming/2010/07/minecraft-alpha-review.html|work=</ref>Jim Rossignol在Rock, Paper, Shotgun网站上也推荐了该游戏的Alpha版本，将其形容为“一种新生的八位元乐高”“类似《S.T.A.L.K.E.R：切尔诺贝利之影》的体验”。<ref>http://www.rockpapershotgun.com/2010/08/10/chockablock-minecraft-revisited/</ref>2010年9月17日，游戏网络漫画家Penny Arcade推出了一系列关于该游戏的漫画，并发布了有关此游戏成瘾性的相关内容。<ref>http://www.penny-arcade.com/2010/9/17/</ref>视频游戏脱口秀《Good Game》为其打出了7.5分和9分（满分10分），称赞其创造性和自定义功能，但也指出其缺少新手教程的不足。<ref>http://www.abc.net.au/tv/goodgame/stories/s3016636.htm</ref>

2011年5月5日，Minecraft入选史密森美国艺术博物馆“视频游戏艺术”展览的80款游戏之列，并于2012年3月16日展出。<ref>http://kotaku.com/#!5799017/the-smithsonian-has-picked-the-games-of-its-art-of-video-games-exhibit</ref><ref>http://americanart.si.edu/exhibitions/archive/2012/games/</ref>
