# Java版1.16-pre6

*页面ID: 64900* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.16-pre6**是[Java版1.16](Java版1.16.md)的第6个预发布版，发布于2020年6月15日<ref></ref>，加入了7种新的材料颜色和新的进度触发器，调整了地图上绯红和诡异材料的颜色，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[进度](进度.md)**
* 加入了<code>player_interacted_with_entity</code>进度触发器。
* * <code>item</code>匹配互动时玩家手中的物品。
* * <code>entity</code>匹配与玩家互动的实体。

# 更改
# = 生物 =
* *[疣猪兽](疣猪兽.md)和[僵尸疣猪兽](僵尸疣猪兽.md)**
* 现在两根獠牙可分别使用独立的纹理。

* *[猪灵](猪灵.md)**
* 现在可在生成时装备附魔[盔甲](盔甲.md)。

* *[僵尸猪灵](僵尸猪灵.md)**
* 将僵尸猪灵愤怒的字幕由“僵尸猪灵：愤怒”改为“僵尸猪灵：愤怒地呼噜”。

# = 世界生成 =
* *[僵尸村庄](僵尸村庄.md)**
* 在僵尸村庄内作为结构怪物生成的[僵尸村民](僵尸村民.md)不再消失。

# = 游戏内容 =
* *[进度](进度.md)**
* 进度“”现在也会在玩家手持金质物品对[猪灵](猪灵.md)按下键时达成。

# = 常规 =
* *[游戏模式](游戏模式.md)切换**
* 现在如果玩家在某世界中还未更改过其他游戏模式，则打开游戏模式切换器也会有默认切换选项。
* * 玩家会在处于其他任意模式时默认选中创造模式，在处于创造模式时默认选中生存模式。

* *[配方书](配方书.md)**
* 在配方书中加入了内容为“...”的文本。
