# 基岩版1.20.30.24

*页面ID: 105467* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.20.30.24**（ChromeOS/Android）、**Preview 1.20.30.24**（Xbox/Windows/iOS/iPadOS）是[基岩版1.20.30](基岩版1.20.30.md)的第9个测试版，发布于2023年8月23日<ref></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[骆驼](骆驼.md)和[嗅探兽](嗅探兽.md)**
* 现在可以被[气球](气球.md)拴住。

* *[溺尸](溺尸.md)、[尸壳](尸壳.md)、[僵尸](僵尸.md)和[僵尸村民](僵尸村民.md)**
* 现在在[着火](着火.md)时攻击会使攻击目标着火。

# = 游戏内容 =
* *[声音](声音.md)**
* 加入了玩家进入或离开水中的音效。

=== 技术性 ===
* *API**
* 将更改为即使实体被杀死后也会有效。

* *物品**
* 修复了最新格式版本中的物品的内容日志错误会因其他物品而出现的问题。

* *生物**
* 为组件公开了新的数据参数，以指定着火的生物在攻击时能否将目标设置为着火状态。（）

* *图形**
* 在延迟渲染预览功能中使用延迟渲染或光线追踪时，禁用美丽的天空和平滑光照后不再会影响视觉效果。
* 现在延迟渲染预览功能中的“美丽的天空”和“平滑光照”按钮仅显示在简易图像和精致图像的图形菜单中。
* 在延迟渲染预览功能中移除了简易图像、精致图像和光线追踪菜单中的“光泛”选项。

# 修复
* *用户界面**
* 修复了新的游玩屏幕中的反馈按钮不会链接至反馈页面的问题。
* 新的死亡屏幕现在支持部分格式化代码（彩色和静态混淆）。
* 修复了HUD屏幕上的各种像素缩放问题。
* 现在游戏手柄的游戏菜单快捷方式会在新的死亡屏幕中正常运作。
* 加入了3个关于用户好友断开连接的错误消息，并改进了另外2个同样的错误消息。

* *音频**
* 现在玩家进入或离开水中会播放正确的音效。（）

* *方块**
* 修复了除非玩家跳跃否则方块渲染不会更新的问题。（）
* 绊线钩不再会在南边和西边延迟解除触发。（）
* 现在混凝土粉末在之前版本导入的世界中拥有正确的颜色。

* *游戏内容**
* 同一刻内发送的命令不再会被忽略。（）
* 与其他仍然可见的玩家一同潜行时，玩家名称不再会完全不可见。（）

* *生物**
* 现在溺尸、尸壳、僵尸和僵尸村民在着火时攻击会使攻击目标着火。（）

* *教育版特性**
* 现在海豚被气球拴住时会正确上浮。
* 现在骆驼和嗅探兽可以被气球拴住。</onlyinclude>
