# 原主机版TU53、CU43、1.49、1.50、Patch 23、1.0.3

*页面ID: 66364* | *来源: Minecraft Wiki*

* *TU53/CU43/1.49/1.50/Patch 23/1.0.3**是[原主机版](原主机版.md)的一次更新，发布于2017年5月30日，加入了许多[探索更新](探索更新.md)的特性。<ref></ref><ref></ref>此次更新等价于[携带版1.1.0](携带版1.1.0.md)。

# 新内容
# = 常规 =
* *混搭包**
* 加入了Adventure Time混搭包。
* 加入了万智牌皮肤包。
* [NS](Nintendo Switch版.md)：加入了中国神话战斗地图。
* [NS](Nintendo Switch版.md)：加入了辐射对战地图包。

* *小游戏**
* 加入了新的小游戏大厅。
* 添加了寺庙，以及一个免费的滑翔轨道。
* [NS](Nintendo Switch版.md)：添加了Glide小游戏。
* 在Glide的纪录会被记录（少于五分钟）。
* [NS](Nintendo Switch版.md)：加入Glide Beasts Track组合包（Dragon, Kraken 和 Yeti Glide 道路）。
* [NS](Nintendo Switch版.md)：玩家在到达终点前需要通过所有关口。
* [NS](Nintendo Switch版.md)：在退回到主菜单之前，玩家可以在Glide单人模式玩更长时间。
* [NS](Nintendo Switch版.md)：减少Glide的重生延迟。
* [NS](Nintendo Switch版.md)：在冲过终点显示有颜色的粒子。
* [NS](Nintendo Switch版.md)：在Glide里面的Showdown现在显示“Hurry Up”。

* *选项**
* 默认控件已稍微更改，现在可以在选项菜单中定义自己的控件模式。

# = 游戏内容 =
* *[控制](控制.md)**
* 添加了选取方块键，但不在默认设置下显示。

* *[双持](双持.md)**
* 加入了副手槽，但只可放地图或箭。

* *[音乐](音乐.md)**
* [NS](Nintendo Switch版.md)：加入新的Glide Tracks音乐。

* *[混凝土粉末](混凝土粉末.md)**
* 有16种不同颜色。

* *[混凝土](混凝土.md)**
* 有16种不同颜色。

* *[带釉陶瓦](带釉陶瓦.md)**
* 有16种不同图案。

# = 物品 =
