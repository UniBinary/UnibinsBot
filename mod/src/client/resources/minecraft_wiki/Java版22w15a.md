# 更改
# = 方块 =
* *[发光地衣](发光地衣.md)和[幽匿脉络](幽匿脉络.md)**
* 现在可被放置在[灵魂沙](灵魂沙.md)、[泥巴](泥巴.md)和全高的[雪](雪.md)的顶面与侧面上。

* *[红树树叶](红树树叶.md)**
* 更改了纹理。

* *[红树根](红树根.md)**
* 现在可用于堆肥。

* *[泥巴](泥巴.md)**
* 现在[甘蔗](甘蔗.md)、[竹子](竹子.md)和[大型垂滴叶](大型垂滴叶.md)可以被放置在其顶面上。

* *[沾泥的红树根](沾泥的红树根.md)**
* 现在[花](花.md)、[树苗](树苗.md)和[草丛](草丛.md)可以被放置在其顶面上。

* *[音符盒](音符盒.md)**
* 回退了[22w13a](22w13a.md)仅让羊毛和羊毛地毯可以阻止音符盒发出声音的更改。

* *[幽匿尖啸体](幽匿尖啸体.md)**
* 更改了模型以及侧面纹理，现在其上半部分的高度减小了1个像素。

* *[藤蔓](藤蔓.md)**
* 现在可被放置在灵魂沙、泥巴和全高的雪的侧面上。

* *羊毛[地毯](地毯.md)**
* 现在放置羊毛地毯时，其被放置、被破坏以及以物品形式掉落时所产生的振动会被减弱，与[羊毛](羊毛.md)一样。
* 羊毛地毯现在还可以减弱在其上面跑和跳跃所产生的振动。

# = 物品 =
* *[船](船.md)和[运输船](运输船.md)**
* 更改了所有种类的船和运输船的物品纹理。

# = 生物 =
* *[悦灵](悦灵.md)**
* 现在每秒会恢复生命值。

* *[流浪商人](流浪商人.md)**
* 现在有概率以5个[绿宝石](绿宝石.md)的价格出售1个[红树胎生苗](红树胎生苗.md)。

* *[监守者](监守者.md)**
* 现在若其目标的位置在近战范围外或有方块阻隔，会尝试蓄力并发起远程攻击。
* * 攻击时，一道形如幽匿尖啸体尖啸粒子的攻击波粒子<code>sonic_boom</code>会自其胸前发出，并有胸口张开的动画。
* * 此远程攻击可击中距离监守者15格内的生物，并造成和该难度下近战攻击相等的伤害。
* * 此远程攻击一次只能击中一个目标，且可以攻击到在墙后的生物。
* 增加了靠嗅觉侦测目标的范围。
* 靠嗅觉侦测时垂直方向的敌对范围由6格改为20格。

# = 非生物实体 =
* *[运输船](运输船.md)**
* 现在，当运输船中已有乘客时，箱子可以直接按键打开。

* *[物品展示框](物品展示框.md)**
* 现在判定箱大小会随着地图的放入而变化。

# = 世界生成 =
* *[红树林沼泽](红树林沼泽.md)**
* 增加了红树林沼泽的[泥巴](泥巴.md)层厚度，现在[石头](石头.md)层的上方皆为泥巴。
* 现在红树林沼泽里的高红树生成频率远高于普通红树。
* 现在[热带鱼](热带鱼.md)会在水中生成。
* 水下迷雾的颜色由与普通沼泽一致的黄色改为青色。

* *[红树](红树.md)**
* 现在会有[覆地苔藓](覆地苔藓.md)生成在红树根的上方。

# = 游戏内容 =
* *[进度](进度.md)**
* 进度“[](进度#advancements-anchor-nether.all_effects.md)”现在还要求玩家具有[黑暗](黑暗.md)状态效果。
* 进度“[](进度#advancements-anchor-husbandry.froglights.md)”的上游进度由“[](进度#advancements-anchor-husbandry.tadpole_in_a_bucket.md)”改为“[](进度#advancements-anchor-husbandry.leash_all_frog_variants.md)”。
* 进度“[](进度#advancements-anchor-husbandry.allay_deliver_cake_to_note_block.md)”的命名空间ID由<code>allay_deliver_cake_to_noteblock</code>改为<code>allay_deliver_cake_to_note_block</code>。
* 移除了<code>item_delivered_to_player</code>进度触发器，改用<code>thrown_item_picked_up_by_player</code>替代。

# = 常规 =
* *[菜单屏幕](菜单屏幕.md)**
* 背景更改为红树林沼泽。

* *[标签](Java版标签.md)**
* 将游戏事件标签重命名为。
* 将物品标签重命名为，并向其中加入了。
* 从方块标签中移除了泥巴。
* 向方块和物品标签中加入了泥巴和沾泥的红树根。
* 向方块标签中加入了覆地苔藓和藤蔓。
* 向方块标签中加入了覆地苔藓、藤蔓、红树胎生苗和雪。
