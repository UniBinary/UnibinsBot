# 原主机版TU30、CU18、1.21、Patch 1

*页面ID: 74212* | *来源: Minecraft Wiki*

* *TU30/CU18/1.21/Patch 1**是[原主机版](原主机版.md)的一次更新，也是[Wii U版](Wii U版.md)的首次更新，发布于2015年10月23日与12月17日，修复了一些漏洞。<ref></ref><ref></ref>

# 更改
# = 常规 =
* *[混搭包](混搭包.md)**
* 为2015年万圣节混搭包中的火把增加了彩色光。
* XBONE、PS3、PS4、PSV、Wii U：增加了2015年万圣节混搭包试用内容。
* XBONE：为Halo混搭包增加了新的Halo 5: Guardians皮肤。
* XBONE、PS3、PS4、PSV、Wii U：增加了星球大战前传皮肤包的使用内容。

# 修复
* *修复了1个漏洞**
