# 基岩版1.17.30.21

*页面ID: 87029* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.17.30.21**是[基岩版1.17.30](基岩版1.17.30.md)的第6个测试版，发布于2021年8月12日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[刷怪笼](刷怪笼.md)**
* 不再会发光，以同步。

# = 游戏内容 =
* *[实验性玩法](实验性玩法.md)**
* 重新加入了“实验 Molang 功能”子选项。

=== 技术性 ===
* *图形**
* 加入了DragonFX材质，以支持光线追踪资源包启用光棚化几何缓冲器预传。

* *数据驱动物品**
* 更新了DamageableItemComponent文档。

* *[Molang](Molang.md)**
* 将Molang实验性查询（活动对象属性相关的查询除外）移动至“实验 Molang 功能”实验性玩法子选项。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“实验 Molang 功能”子选项后才可使用。

# = 技术性 =
* *数据驱动方块**
* 加入了BlockPartVisibilityComponent。
* * 允许创建者为几何JSON中列出的“骨骼”指定Molang条件，会根据方块状态打开或关闭骨骼动画。

* *Molang**
* 加入了实验性查询和。
* * 获取方块的相对位置和标签。
* * 返回0或1。

# 修复
* *性能与稳定性**
* 修复了一些游戏过程中可能发生的崩溃。
* 修复了在市场下载大型世界时可能发生的崩溃问题。
* 修复了部分Android 11设备加载或创建世界时可能会卡死或导致崩溃的问题。（）

* *原版趋同**
* 玩家起床时不再会站在能够造成伤害的方块上，以匹配Java版的起床行为。
* 现在玩家在一侧有方块阻挡时起床会站在床的另一侧，以匹配Java版的起床行为。（）
* 刷怪笼不再会发光（趋同Java版）。

* *生物**
* 修复了贴近细雪的亡灵生物在阳光下仍然会自燃的问题。（）

* *角色创建器**
* 在皮肤包的描述界面中按下“查看市场中的包”按钮后不再会无限地加载。

* *用户界面和HUD**
* 修复了资源包中对物品分类文本颜色的修改与物品的文本颜色不匹配的问题。
* 修复了使用部分资源包后织布机中的图案无法正确显示的问题。

* *技术性**
* 修复了实验性查询以使其获取正确的Y轴平移和缩放结果。
* 使用包含的资源包进入世界时不再会导致崩溃。（）
* 修复了编辑NPC对话框时的控制器支持问题。
* 现在UI json字段解析无效时会抛出内容错误。</onlyinclude>
