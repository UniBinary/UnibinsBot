# Java版Classic 0.0.17a

*页面ID: 35379* | *来源: Minecraft Wiki*

<onlyinclude>
* *0.0.17a**是的一次更新，发布于2009年6月10日<ref></ref>，加入了新的[命令](命令.md)，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 按下可以打开玩家登入列表。
* 内服务端验证。
* * 设置为可以让玩家通过<code>-{}-http<nowiki/>://www.minecraft.net/play.jsp?ip=<ip>&port=<端口></code>直接登入服务器。
* 在服务器内加入了。

# = 命令格式 =
* ***
* 管理员命令。
* 用于将当前位置设置为新玩家的默认出生点。

# 更改
# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 现在在输入聊天信息时会出现聊天日志。
* 玩家不能再滥发ping请求。
* 个人服务器地址行为的更改。
* * 服务器运行时会生成一个文件。
* 在单人游戏中禁用了聊天功能。

# = 常规 =
* *[字体](字体.md)**
* 区别显示字符<code>0</code>和<code>O</code>。

# 修复
* *修复了3个漏洞**
* 修复了命令（它能正常工作，但是不直观）。
* 修复了登录时出生位置会恢复到默认位置的问题。
* 服务器泛洪攻击保护。
* * 不再会出现熔岩泛滥了。
* * 现在玩家放置不能通过合法途径得到的方块会被踢出游戏。</onlyinclude>
