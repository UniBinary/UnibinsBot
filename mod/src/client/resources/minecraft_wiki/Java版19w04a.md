# Java版19w04a

*页面ID: 39425* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w04a**是[Java版1.14](Java版1.14.md)的第17个快照，发布于2019年1月24日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[营火](营火.md)**
* 现在会在[针叶林](针叶林.md)村庄内生成。
* * 可以出现在地上。
* * 可以作为楼房的烟囱。

* *[堆肥桶](堆肥桶.md)**
* 现在会在[村庄](村庄.md)的农场内生成。

* *[切石机](切石机.md)**
* 现在可以通过三个[石头](石头.md)和一个[铁锭](铁锭.md)合成。
* 现在可以作为更简单的合成各种石质方块（楼梯、台阶、砖或墙等）的方式。
* * 原材料为圆石、各种类型的石头、平滑石头、砂岩、砖、下界砖、下界石英、各种类型的海晶石、末地石、末地石砖和苔石变种。
* 加入了切石机合成方块时的声音事件。

# = 世界生成 =
* *[僵尸村庄](村庄#僵尸村庄.md)**
* 更新了沙漠和针叶林的僵尸村庄。

# = 常规 =
* *世界生成**
* 新的处理信息：“升级结构数据中”。

* *其他**
* 改进了碰撞代码。
