* *闪电束（Lightning Bolt**，简称**闪电）**是一种会在[雷暴](雷暴.md)中因多种原因而生成的实体，作为雷暴的标志性危险因素，会在落下时产生多次**雷击（Lightning Strike）**，对实体造成伤害并生成[火](火.md)。

# 生成
# = 雷暴 =
雷暴期间，对每一个已加载的区块，在每个游戏刻，会有概率尝试生成一次闪电束。在这个概率下，如果有大约201个已加载的区块（对应玩家到区块中心的距离为128格），那么90%的情况下，每分钟都会产生0到5道闪电束，平均值约每分钟2.4道闪电束。

尝试生成闪电束时，闪电束会随机选中区块内的X和Z坐标，并选定此坐标上Y值最高的液体方块或有碰撞箱的方块。随后若在3×*h*×3区域内（这个区域以世界最高高度为上限，以选定的方块往下3格为下限）有暴露在天空下的[生物](生物.md)，则会随机选择其中之一，将闪电束的目标转移到该生物脚下的方块。

游戏会再次确认目标位置是否符合下列条件：
* 目标[方块](方块.md)暴露在天空下
* 该方块上存在降雨，不含降雪或无雨
* * 因此，闪电束不会发生在不下雨的炎热[生物群系](生物群系.md)，或降雪的寒冷生物群系。
若以上条件确认通过，闪电束就会劈下。

若选中的位置在半径128格内或64×64×64的区域有[避雷针](避雷针.md)，闪电束会改为劈中避雷针的位置。

# = 三叉戟 =

如果处于露天处的或在[雷暴](雷暴.md)天气时被由玩家掷出的具有[引雷](引雷.md)魔咒的[三叉戟](三叉戟.md)击中（近身攻击时无效），则会在被击中的目标所在处召唤一道闪电。

如果处于露天处的[避雷针](避雷针.md)在或天气时被由玩家掷出的具有引雷魔咒的三叉戟击中，则会在该避雷针的顶部召唤一道闪电。

# = 骷髅陷阱 =

玩家接近并触发[骷髅陷阱](骷髅陷阱.md)马时，会出现一道特殊的装饰性闪电束。此闪电束无碰撞箱，不能造成伤害，不能生成火，不能转化生物，但可以降低周围铜质方块的锈蚀程度，可以使被击中的避雷针输出红石信号。<!--因为不能生成火，所以可以使玩家达成进度。-->

# 行为
闪电束的主要效果是对实体造成伤害和在方块上生成火。在闪电束落下后，会发出响亮的雷声并使天空闪烁片刻。天空闪烁效果可以在辅助功能设置中关闭。

# = 造成伤害 =
闪电束生成时，会对范围内6×6×12区域（水平中心为目标方块的西北角，底边在目标方块下方三格）内的所有实体造成伤害。闪电束会在此区域进行数次击打，击打次数不固定，且击打次数多也会相应延长闪电束的存在时间。[受击后伤害免疫](受击后伤害免疫.md)通常会防止生物受到以上的伤害，但物品实体、船、盔甲架和矿车可能会迅速被击打摧毁。闪电束只会进行一次击打。

闪电束造成的伤害不会造成[着火](着火.md)，但生成的[火](火.md)可以。

闪电束造成的伤害还会设置实体的剩余着火时间为。

[海龟](海龟.md)被闪电束击中时会受到3.4×10<sup>38</sup>（ × 1.7×10<sup>38</sup>）伤害。

海龟和[美西螈](美西螈.md)受到的来自闪电束的伤害为2000倍，被闪电束击中时会受到伤害。

被闪电束击杀的海龟会掉落1个[碗](碗.md)。<ref></ref><ref></ref>但闪电束通常会迅速将掉落的碗清除。<ref></ref>

# = 生成火 =
[缩略图|200px|闪电束制造的[[火](File:Lightning fire.png.md)]]

在普通和困难难度下，闪电束在以击中点为中心、2格为半径（即3×3）的区域产生火。由此产生的火会正常地点燃任何可燃物品，引爆[TNT](TNT.md)，甚至激活[下界传送门](下界传送门.md)。但是，闪电束本身不会对方块造成任何破坏。大多数火很快会被雨扑灭，但某些遮住雨的地方可能会让火扩散。若火焰点燃了[下界岩](下界岩.md)、[岩浆块](岩浆块.md)、[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)，则火焰也不会熄灭。

# = 转化生物 =
闪电束会对部分生物造成特殊的效果：
* 被闪电束击中的[猪](猪.md)会变成[僵尸猪灵](僵尸猪灵.md)。
* 被闪电束击中的[苦力怕](苦力怕.md)会变成[闪电苦力怕](闪电苦力怕.md)。
* 被闪电束击中的[村民](村民.md)会变成[女巫](女巫.md)。
* 被闪电束击中的红色[哞菇](哞菇.md)会变成棕色哞菇，反之亦然。
* 被闪电束击中的[铜傀儡](铜傀儡.md)会降低锈蚀程度。

以上生物被闪电束击中时，假设在承受闪电伤害后该生物的生命值仍然大于或等于0，则该生物不会受到闪电伤害或附加[着火](着火.md)效果，且立即转化。反之，假设在承受闪电伤害后该生物的生命值将小于0，则该生物会受到闪电伤害并直接死亡，无法转化。

被用附有[引雷](引雷.md)魔咒的[三叉戟](三叉戟.md)击中时，即使该生物（除[苦力怕](苦力怕.md)外）在受到两次伤害后生命值将小于0，该生物仍然会在死亡后于[闪电束](闪电束.md)落下的位置重新生成一个新实体。

除[苦力怕](苦力怕.md)在转化时仅修改实体数据，[猪](猪.md)、[村民](村民.md)及[哞菇](哞菇.md)都会在转化时删除本体并生成一个新实体。

# = 避雷针 =
以任何原因被生成的闪电束在击中[避雷针](避雷针.md)后，避雷针会输出[红石信号](红石信号.md)。

# = 铜质方块 =

以任何原因被生成的闪电束在击中铜质方块或附着于铜质方块的避雷针后，铜质方块的锈蚀程度会降低。

# = 生成骷髅陷阱 =

[缩略图|右|250px|雷暴中生成的一个[[骷髅马#生成|骷髅陷阱](File:SkeletonRiderGroup.png.md)]]
自然生成的闪电束在落下且未击中[避雷针](避雷针.md)时，有概率生成[骷髅陷阱马](骷髅陷阱马.md)，生成概率分别为0.75–1.5%（简单难度）、1.5–4%（普通难度）、2.8125–6.75%（困难难度），具体值取决于[区域难度](区域难度.md)。

当玩家移动到骷髅陷阱马的10格以内时，就会触发陷阱，生成装饰性的闪电束，且骷髅陷阱马会变成四个[骷髅骑士](骷髅骑士.md)。未触发的陷阱马将在15分钟后自动消失。

# = 雷声 =
* *雷声（Thunder）**是每次闪电束发生时随之发生的声音事件。以闪电束为中心，渲染距离范围之内的玩家都可以同时听到雷声。

# 你知道吗
* 闪电束不像游戏中的多数效果和实体，不具有相关的图像文件，而是被直接编码入游戏引擎中来制造动态、逼真的闪电束。
* 由于生成范围的限制，与相比，玩家更容易被闪电束击中。
* 当多个闪电束同时击中一个村民时，生成的女巫数量和闪电束的数量是相等的，所以可以由一个村民生成多个女巫；这对猪转变成僵尸猪灵同样有效。
* * 但这对苦力怕转变成闪电苦力怕无效。这是因为后者只是修改了数据值，而并非生成新实体。
* 在游戏中无法透过闪电束看见实体、生物、水、玻璃等等。
* 闪电束看上去是从云层生成的，然而闪电束的动画从击中的地方起有128格长（巧合的是这也是云层与海平面之间的距离），例如在海平面上（Y=63）的闪电束是从Y=191处劈下来的。这也就是说从云层产生的“现实的”闪电束只会出现在海平面处。
* 在[Java版1.16-pre1](Java版1.16-pre1.md)前，利用闪电束仅会发生在已加载区块且雷声能在极远距离被听见的特性，玩家可以通过被修改过的客户端或抓包来获取雷声发生位置的准确坐标，导致有其他玩家的位置泄漏，即知名的雷声漏洞。
