* *丁香（Lilac）**是一种[大型花](大型花.md)。

# 生成

# = 自然生成 =
丁香会在[森林](森林.md)、[桦木森林](桦木森林.md)、[原始桦木森林](原始桦木森林.md)、[黑森林](黑森林.md)和[繁花森林](繁花森林.md)生物群系自然生成。

# 获取
# = 骨粉 =
对着丁香[骨粉](骨粉.md)会掉落1株新的丁香。

# 破坏
丁香被挖掘时会立刻被破坏。

丁香被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 堆肥 =
将丁香放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
