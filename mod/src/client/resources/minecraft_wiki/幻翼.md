* *幻翼（Phantom）**是一种会因[玩家](玩家.md)长时间不睡觉而生成的飞行[亡灵](亡灵.md)敌对生物。

# 生成
[thumb|夜里的两只幻翼](File:Phantom at night.png.md)

幻翼会在玩家未睡眠时在主世界的玩家上空自然生成。在床上睡眠（无需跳过夜晚）或死亡会重置这一时间，当玩家头上有阻碍天空光照的方块（例如[树叶](树叶.md)、[蜘蛛网](蜘蛛网.md)，[水](水.md)；但[玻璃](玻璃.md)不会）时，会阻止幻翼生成。

幻翼在关闭[游戏规则](游戏规则.md)时不会自然生成。

# = Java版 =
幻翼的生成不依赖任何[生物群系](生物群系.md)，其拥有独特的生成方式。

幻翼只会在夜间或雷暴期间生成，每~尝试生成一次。对于每个不是[旁观模式](旁观模式.md)的玩家，如果这个玩家上方不能看见天空（即正上方有[光照不透明方块](亮度#光照透明方块.md)）或者玩家低于海平面（Y<64），则幻翼不会生成。幻翼成功生成的概率会随着这个玩家没有睡觉的时间的增加而增加，计算公式为，x为玩家自上次上床经过的[刻](刻.md)数。如果玩家自上次上床时间小于72000[刻](刻.md)，则幻翼不会生成。

如果生成判定成功，幻翼将在以玩家为中心21×21格的区域，距离头顶20-34格的某一个位置生成。生成数量与[难度](难度.md)有关，在简单难度下生成1-2只，普通难度下1-3只，困难难度下是1-4只。

幻翼计入敌对生物数量上限，但在生成时无视上限。它的生成是基于在游戏中的玩家的位置，而不是像普通怪物[生成](生成.md)那样随机选择一个玩家附近的方块。

# = 基岩版 =
幻翼的生成类似于其他怪物，受到敌对生物数量上限限制。幻翼的生物密度上限为**5**。

生成幻翼需要在当前模拟距离下的生物生成范围内，亮度≤7且符合苦力怕空间检测条件的**可生成方块**作为生成尝试点位，并且玩家上方没有[光照不透明方块](亮度#光照透明方块.md)。若玩家的高度大于或等于世界建筑高度限制，幻翼将无法生成。

若生成尝试成功，幻翼会生成于玩家上方28格为中心的21×15×21区域内符合其空间检测，且亮度为0的某个不阻挡幻翼生成的方块处。

# 行为
幻翼空闲时会以恒定的高度绕圈飞行，同时其双翅会产生灰烟粒子。幻翼的飞行速度可达每秒20.83格，是目前游戏中移动速度最快的非Boss生物，且不受水的阻碍。水中的幻翼会试图飞出水面。

幻翼只与玩家敌对，且不会尝试反击任何生物。它们发现玩家时，会在距玩家水平距离15-25格、垂直距离24-35格的范围内徘徊飞行，并尝试攻击。幻翼会查找水平半径16格，垂直半径64格的玩家并优先攻击高度更高的玩家，并且每8到11秒会进行俯冲攻击。幻翼每20秒搜寻半径64格和高度80格内的玩家，并且每10到20秒会进行俯冲攻击。若幻翼攻击到了玩家，或者俯冲时突然失去目标、突然受到攻击，则会试图直升到俯冲前的飞行高度，即使上方被方块阻挡。

幻翼的眼睛拥有发亮的纹理，在暗处也清楚可见，但不会影响周围方块的实际[亮度](亮度.md)。幻翼[隐身](隐身.md)时身体会消失，但眼睛和烟雾粒子仍然可见，这一点与[末影人](末影人.md)和[蜘蛛](蜘蛛.md)相同。

幻翼与[僵尸](僵尸.md)和[骷髅](骷髅.md)一样会在阳光下自燃。

幻翼会尝试待在猫[切比雪夫距离](切比雪夫距离.md)16格以外的地方。幻翼也会在同样的情况下避开[豹猫](豹猫.md)。

# = 生物族群 =

幻翼是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，不被[凋灵](凋灵.md)攻击。

与多数亡灵生物不同，幻翼能够飞行，不会不受控地沉入水底。

幻翼会在阳光下[着火](着火.md)，但幻翼不会寻找阴凉处、水域或细雪来避免着火。

# 你知道吗
[thumb|200px|被弃用的红色幻翼](File:Unused Red Phantom.jpg.md)
* 在[18w10a](18w10a.md)发布前，幻翼曾有一个红色版本的纹理，因看起来太像[下界](下界.md)生物而被弃用。<ref name="meetphantom"/>
* * 在[Minecraft Dungeons](Minecraft Dungeons.md)中，红色幻翼作为2022年万圣节活动限定[宠物](Dungeons:宠物.md)加入。
* [生物投票](MINECON_Earth_2017.md)中的“夜空之怪”素描是有嘴巴的，该设计因实装后使幻翼看起来像是布偶玩具而被弃用。<ref name="meetphantom" />
* 幻翼的音效取自[Samuel Åberg](Samuel Åberg.md)小儿子的尖叫声。<ref>https://www.asoundeffect.com/minecraft-dungeons-game-audio/</ref>
