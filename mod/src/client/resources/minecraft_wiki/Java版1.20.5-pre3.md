# Java版1.20.5-pre3

*页面ID: 119058* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.20.5-pre3**是[Java版1.20.5](Java版1.20.5.md)的第3个预发布版，发布于2024年4月16日<ref></ref>，修复了一些漏洞。

# 更改
# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为。

* *[标签](Java版标签.md)**
* 将实体类型标签<code>#punchable_projectiles</code>重命名为<code>#redirectable_projectile</code>。

* *[属性](属性.md)**
* 回退了上个预发布版对<code>generic.step_height</code>的更改。

# 修复
设置时屏幕反复闪烁。

|270609|客户端需要之间的一刻来储存cookie。
|270634|由发射器发射的烟花火箭飞的比以前高。
|270668|物品数据序列化明显比以前慢。
