# 毒马铃薯附加包

*页面ID: 170914* | *来源: Minecraft Wiki*

[thumb|宣传图](File:POIP Thumbnail 0.jpg.md)

* *毒马铃薯附加包（Poisonous Potato Add-On）**是由[Jigarbov Productions](https://www.jigarbov.net/)开发的官方[附加包](附加包.md)，发布于2024年4月1日，作为2024年[愚人节玩笑](愚人节玩笑.md)的一部分。<ref> [Poisonous Potato Add-On in Minecraft Marketplace <nowiki>&#124;</nowiki> Minecraft](https://www.minecraft.net/en-us/marketplace/pdp?id=790be090-9bce-4870-85e7-cd868402c3e5)</ref>

# 内容
# = 物品 =
; [32px|class=pixel-image](File:Poisonous Potato Bundle.png.md) 毒马铃薯收纳袋（Poisonous Potato Bundle）

; [32px](File:Baked Poisonous Potato.png.md) 烤毒马铃薯（Baked Poisonous Potato）
* 通过在[熔炉](熔炉.md)烹饪[毒马铃薯](毒马铃薯.md)获得。
* 无法通过[烟熏炉](烟熏炉.md)和[营火](营火.md)烹饪。
* 可以回复并给予玩家3-4种5级的正面状态效果，这些状态效果会持续30秒。

; [32px](File:Explosive Poisonous Potato.png.md) 爆炸毒马铃薯（Explosive Poisonous Potato）
* 时会被抛出并产生巨大的爆炸。
* 由1个毒马铃薯、4个火药和4个红石粉合成。

; [32px](File:Poisonous Potato Nubs.png.md) 毒马铃薯块（Poisonous Potato Nubs）
* 由毒马铃薯合成。
* 与[药水](药水.md)类似，投掷后会造成[中毒](中毒.md)状态效果。

; [32px](File:Explosive Poisonous Potato Nubs.png.md) 爆炸马铃薯块（Explosive Poisonous Potato Nubs）
* 由7个毒马铃薯块、1个火药和1个红石粉合成。
* 投掷后会造成小型爆炸。

; [32px|class=pixel-image](File:Sprouted Poisonous Potato Nubs.png.md) 发芽毒马铃薯块（Sprouted Poisonous Potato Nubs）

; [32px|class=pixel-image](File:Sprouted Explosive Poisonous Potato Nubs.png.md) 发芽爆炸毒马铃薯块（Sprouted Explosive Poisonous Potato Nubs）

; 毒马铃薯盔甲
* [32px](File:Poisonous Potato Helmet.png.md) 毒马铃薯头盔（Poisonous Potato Helmet）
* [32px](File:Poisonous Potato Chestplate (add-on).png.md) 毒马铃薯胸甲（Poisonous Potato Chestplate）
* [32px](File:Poisonous Potato Leggings.png.md) 毒马铃薯护腿（Poisonous Potato Leggings）
* [32px](File:Poisonous Potato Boots.png.md) 毒马铃薯靴子（Poisonous Potato Boots）
* 提供护甲值。

; [32px](File:Poisonous Potato Guide.png.md) 毒马铃薯指南（Poisonous Potato Guide）
* 指导玩家如何制作烤毒马铃薯和制作毒马铃薯方块、毒马铃薯剑、毒马铃薯盔甲和毒马铃薯矿车。
* 包含附加包的制作人员名单。

*  毒马铃薯剑
* 攻击力为普通剑的2倍。

; [32px](File:Poisonous Potato Stew.png.md) 毒马铃薯炖菜（Poisonous Potato Stew）

; [32px](File:Wrench.png.md) 扳手（Wrench）
* Jigarbov Productions制作的所有附加包中都包含的物品。

; 刷怪蛋
* [32px](File:Mutato Item.png.md) Mutato刷怪蛋
* [32px|class=pixel-image](File:Mashacre Item.png.md) Mashacre刷怪蛋

# == 生物 ==
; [32px](File:Mutato.png.md) Mutato
* 一种被动生物, 在破坏马铃薯植株时有2%的概率生成。
* 拥有生命值和的攻击力。
* 在攻击时会给予目标15秒的[中毒](中毒.md)效果。
* 可通过马铃薯或毒马铃薯驯服。

; [32px](File:Tubber Trekkers.png.md) 块茎行者（Tuber Trekkers）
* 可以被骑乘。
* 死亡时掉落其刷怪蛋。

; [32px](File:Mashacre.png.md) Mashacre
* Mutato的敌对变种。
* 拥有生命值和的攻击力。
