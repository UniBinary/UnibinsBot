# 用途
[物品实体](物品实体.md)形式的下界合金锄会漂浮在[熔岩](熔岩.md)上，且不会被[火](火.md)和熔岩摧毁。

# = 转化方块 =
对着[泥土](泥土.md)、[草方块](草方块.md)或[土径](土径.md)锄可将其变为[耕地](耕地.md)。

对着[砂土](砂土.md)锄可将其变为泥土。

对着[缠根泥土](缠根泥土.md)锄可将其变为泥土，并且会掉落一个[垂根](垂根.md)。

# = 挖掘工具 =

锄是一种挖掘工具，每次成功挖掘了任何硬度不为0的方块会消耗1耐久度。

# = 近战攻击 =
锄每成功进行一次[近战攻击](近战攻击.md)会减少2点耐久度。

# == Java版 ==
不同品质的锄有不同的攻击速度。

# == 基岩版 ==
锄没有攻击冷却。

# 你知道吗
* 耕耘上方有泥土方块的[泥土](泥土.md)方块也会被变为[耕地](耕地.md)，即使其无法使用。如果在水平相邻的[方块](方块.md)上使用锄，则第一个方块会变成泥土，而所选的方块并不会被耕耘。
