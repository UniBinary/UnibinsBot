* *21w16a**是[Java版1.17](Java版1.17.md)的第18个快照，发布于2021年4月21日<ref></ref>，为[滴水石锥](滴水石锥.md)加入了生长机制，在快照[21w06a](21w06a.md)至[21w14a](21w14a.md)的基础上于[单独的数据包](洞穴与山崖预览数据包.md)中加入了[熔岩含水层](含水层.md)和[矿脉](矿脉.md)，并修复了一些漏洞。

# 新内容
# = 世界生成 =
* *[滴水石](滴水石.md)生长机制**
* 现在若[钟乳石](钟乳石.md)悬挂在[滴水石块](滴水石块.md)下，且滴水石块上方有水源，则钟乳石正下方能够缓慢长出[石笋](石笋.md)，且钟乳石自身也会逐渐生长并延长。
* * 生长速度随机且非常缓慢，每生长一个阶段都需要花费数个游戏日。
* 钟乳石最长生长到7格。
* 仅当钟乳石的下端距地面或石笋上端不多于10格时，石笋才会生长。
* 如果钟乳石的尖端在[液体](液体.md)中，则无滴水现象，因此不会生长。
* 如果石笋的尖端在液体中，则其无法收到来自钟乳石的水滴，因此也不会生长。
* * 同理，在钟乳石和石笋之间的任何液体都会阻碍它们的生长。
* 钟乳石和石笋都不会长入液体中。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 包含、和方块标签。

* *[语言](语言.md)**
* 加入了俄语（革命前）语言翻译。
* 加入了繁体中文（香港）语言翻译。

# 更改
# = 方块 =
* *[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)**
* 现在在使用[骨粉](骨粉.md)后可以长出[杜鹃树](杜鹃树.md)。

* *[粗铁块](粗铁块.md)和[粗金块](粗金块.md)**
* 更改了纹理。

* *[绿宝石矿石](绿宝石矿石.md)**
* 显著提高了生成频率。现在在[山地](山地.md)生物群系中每[区块](区块.md)尝试生成6-24次，而非先前的1次。

* *[苔藓块](苔藓块.md)、[草方块](草方块.md)和[菌丝体](菌丝体.md)**
* 现在属于标签。这意味着：
* * [草](草.md)、[高草丛](高草丛.md)、[蕨](蕨.md)、[大型蕨](大型蕨.md)、[甜浆果丛](甜浆果丛.md)、[树苗](树苗.md)、[花](花.md)、[杜鹃花丛](杜鹃花丛.md)、[甘蔗](甘蔗.md)和[枯萎的灌木](枯萎的灌木.md)能被放置在其上方。
* * [南瓜茎](南瓜茎.md)和[西瓜茎](西瓜茎.md)能在其上方产生[南瓜](南瓜.md)或[西瓜](西瓜.md)。
* * [末影人](末影人.md)可以移动这些方块。

* *[虫蚀深板岩](虫蚀深板岩.md)**
* 现在和[深板岩](深板岩.md)一样拥有随机旋转的纹理，并且可沿不同坐标轴方向放置。

* *[小型垂滴叶](小型垂滴叶.md)**
* 稍微更改了模型。

# = 物品 =
* *[粗金属](粗金属.md)**
* 更改了纹理。

# = 世界生成 =
本段落介绍的内容需加载[数据包](洞穴与山崖预览数据包.md)启用。

* *[含水层](含水层.md)**
* 在主世界Y=0以下区域生成的含水层现在有概率完全由[熔岩](熔岩.md)组成。

* *[矿石](矿石.md)分布**
* 加入了大型且罕见的蛇形[矿脉](矿脉.md)，区别于常见的较小矿石[团簇](团簇.md)。
* * 在主世界Y=0以上的区域，[铜矿脉](铜矿脉.md)伴随[花岗岩](花岗岩.md)生成。
* * 在主世界Y=0以下的区域，[铁矿脉](铁矿脉.md)伴随[凝灰岩](凝灰岩.md)生成。

# = 常规 =
* *[标签](Java版标签.md)**
* 移除了标签。
* 向标签中添加了[沙子](沙子.md)和[沙砾](沙砾.md)，并将其中的替换为。
* 向标签中加入了苔藓块、草方块和菌丝体，并从一些已经包含的标签中移除了重复出现的方块。

* *[统计](统计.md)**
* “游玩时间”统计项的本地化键名被重命名为<code>play_time</code>。
* 即使游戏暂停，“世界打开时间”统计项 (<code>total_world_time</code>) 也会计算时间。

* *资源包提示**
* 若用户曾永久性拒绝使用服务器资源包，如果此资源包需要强制使用，则现在依然会展示资源包提示信息（而非直接让用户断开连接）。
