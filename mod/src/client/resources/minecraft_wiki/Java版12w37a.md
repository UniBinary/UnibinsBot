# Java版12w37a

*页面ID: 33076* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w37a**是[Java版1.4.2](Java版1.4.2.md)的第5个快照，发布于2012年9月13日<ref></ref>。

# 新内容
# = 物品 =
* *[南瓜派](南瓜派.md)**
* 使用南瓜、鸡蛋和糖来合成。
* 回复。

# = 命令格式 =
* ***
* 用于清除物品栏。

# = 常规 =
* *重建世界**
* 在世界选栏菜单中添加了“重建”选项。
* * 能够在不改变原有世界的情况下创造一个新的世界。其种子等将和原世界一样，但可以重新设定一些选项（如：作弊、奖励箱、模式）。

* *超平坦**
* [超平坦](超平坦.md)地图自定义界面：
* * 预设7种世界：经典平坦、、水世界、主世界、、无底深渊（已损坏）<ref></ref>和沙漠。
* * 自定义将从经典平坦开始并带有三个选项：添加层，编辑层，移除层。添加并编辑选项尚未加入。
* ** 可以通过使用预设列表的种子来定制超平坦世界。

# 更改
# = 方块 =
* *[按钮](按钮.md)**
* 红石信号时间被延长到12个红石刻。

* *[头颅](头颅.md)**
* 现在会正确居中。
* 现在可通过编辑NBT标签自定义。

# = 物品 =
* *[面包](面包.md)、[生鸡肉](生鸡肉.md)、[熟鸡肉](熟鸡肉.md)、[生牛肉](生牛肉.md)、[牛排](牛排.md)、[生猪排](生猪排.md)、[熟猪排](熟猪排.md)、[苹果](苹果.md)和[下界之星](下界之星.md)**
* 不再有黑色轮廓。

* *[盔甲](盔甲.md)**
* 皮革盔甲现在有了一层未染色层。

* *[烤马铃薯](烤马铃薯.md)**
* 不再有代表热气的纹理。

* *[胡萝卜](胡萝卜.md)**
* 调整为单个形式以匹配其单数名称。

* *[金胡萝卜](金胡萝卜.md)**
* 更改了纹理以与普通胡萝卜相匹配。

# = 生物 =
* *常规**
* 攻击性生物在困难难度时将变得更加无畏。
* * 这主要区别在怪物会不会冒险跳下悬崖攻击玩家。

* *[凋灵](凋灵.md)**
* 第一次达到满血后，会在其周围制造大爆炸。
* 空闲时，凋灵会随机发射蓝色凋灵之首。

* *[凋灵骷髅](凋灵骷髅.md)**
* 增加了下界要塞生成凋灵骷髅的概率，

* *[猪](猪.md)**
* 猪现在能在玩家骑着时跳跃，
* * 被骑着的猪不会在水上移动。（可能是玩家质量或者漏洞）。

# = 常规 =
* *[钓鱼](钓鱼.md)**
* 钓鱼现在会给予玩家经验值。</onlyinclude>
