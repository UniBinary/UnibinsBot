# 火球（消歧义）

*页面ID: 7545* | *来源: Minecraft Wiki*

* *火球**可以指：

== 实体 ==
*  - 由[恶魂](恶魂.md)生成的弹射物实体。
*  - 由[发射器](发射器.md)使用[火焰弹](火焰弹.md)生成或由[烈焰人](烈焰人.md)生成的弹射物实体。
*  - 由[末影龙](末影龙.md)生成的弹射物实体。

# 物品
*  - 一种可以在方块上以生成[火](火.md)、或放入发射器发射为小火球的物品。
