# 磨制花岗岩楼梯

*页面ID: 51029* | *来源: Minecraft Wiki*

* *磨制花岗岩楼梯（Polished Granite Stairs）**是[磨制花岗岩](磨制花岗岩.md)制作的[楼梯](楼梯.md)。

# 生成
磨制花岗岩楼梯不会生成在世界中。

# 破坏
挖掘磨制花岗岩楼梯的合适工具是镐。磨制花岗岩楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

磨制花岗岩楼梯被破坏后会掉落自身。
