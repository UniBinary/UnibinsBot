# 经验/旧版2

*页面ID: 29698* | *来源: Minecraft Wiki*

<noinclude></noinclude>
前16级的经验曲线呈线性（每等级17点经验），17级以后每等级的经验需求逐渐上涨。

值得注意的是，附魔直接扣除经验等级，而非经验总量。这对30级以上的升级牵涉很大：越高的等级需求经验量越大，但这在附魔时不会有所保留。举例来说，在进行30级附魔时：如果你首先积累经验值升级到31级，然后进行附魔，最终你只会回到1级；如果你在30级时先进行附魔，然后再积累同样多的从30级到31级的经验值，你实际上最后会升级到将近4级。因此，提升到39级以后的等级是毫无意义的，在此之后，铁砧会提示“过于昂贵”并拒绝附魔或修复。

# 公式与表格
提升1级所需的经验由以下函数决定：
<syntaxhighlight lang=c++>
int expCost(int currentLevel) {
    if (currentLevel >= 30) {
        return 62 + (currentLevel - 30) * 7;
    } else if (currentLevel >= 15) {
        return 17 + (currentLevel - 15) * 3;
    } else {
         return 17;
    }
}
</syntaxhighlight>
亦即：
* 若当前等级为14或更低，提升1级需要17点经验值。
* 若当前等级为15-29级，每提升1级所需经验值会比上一级增加**3**点，即从当前等级需要 (17 + (*当前等级* - 15) × 3) 点经验值来提升到下一等级。
* 当前等级为30级及以上时，每提升1级所需经验值比上一级增加**7**点即从当前等级需要 (62 + (*当前等级* - 30) * 7) 点经验值来提升到下一等级。

达到 (*x*) 等级所需经验值总量由以下公式计算：
* *x*<15 时：17*x*
* 16≤*x*<30 时：1.5*x*² - 29.5*x* + 360
* *x*≥30 时：3.5*x*² - 151.5*x* + 2220

# 实用数据
* 击杀一只大型[史莱姆](史莱姆.md)及其产生的全部中、小型史莱姆可得到12-28点经验值，平均值为19。
* 一次附魔中消耗的最大等级数是3，而铁砧接受39级及以下等级消费的操作（创造模式中没有限制）。
* 16级时的经验值只是30级的四分之一，而22级才是30级之路的一半；30级则只是39级之路的一半。
* 升到某一级所需经验值总量的计算公式如下：
* * 0-15级：总经验值 = 17[等级]
* * 16-30级：1.5[等级]<sup>2</sup> - 29.5[等级] + 360
* * 31级以上：3.5[等级]<sup>2</sup> - 151.5[等级] + 2220
* ** 此公式不考虑当前已累积到经验条中的经验值。
* 升到下一级所需经验值的计算公式如下：
* * 当前0-14级：需要经验值 = 17
* * 当前15-29级：3[当前] -28
* * 当前30级以上：7[当前] - 148
* 击杀末影龙给予的经验值可升至大约78经验等级。末影龙的死亡实际上掉落10个价值1000的经验球，以及1个价值2000的经验球。独立考虑下，较小的经验球可以将玩家从0级升至32级，而较大的经验球可从0级升级至41级。
* 通过命令可以得到的经验等级最大值是2147483647。（即 2^31-1，32位有符号整型变量的最大值。）
* 经验等级最大值为24791。
