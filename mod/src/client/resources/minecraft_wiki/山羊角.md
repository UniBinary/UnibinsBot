* *山羊角（Goat Horn）**是在成年[山羊](山羊.md)撞击特定[固体方块](固体方块.md)时掉落的物品。

# 获取
# = 山羊 =
成年山羊撞击到[石头](石头.md)、[浮冰](浮冰.md)、[铁矿石](铁矿石.md)、[煤矿石](煤矿石.md)、[铜矿石](铜矿石.md)、[绿宝石矿石](绿宝石矿石.md)或[原木](原木.md)时会掉落1个山羊角。每只山羊最多会掉落2个山羊角。

普通山羊仅掉落“”“”“”和“”，尖叫山羊仅掉落“”“”“”和“”。

# 用途
[thumb|正在吹奏山羊角的玩家](File:Player using goat horn.png.md)
玩家手持山羊角时，按住会显示吹奏动画并发出其对应的吹奏音效，并引发}}或}}的山羊角物品冷却时间，期间受影响玩家不可使用山羊角。

山羊角的吹奏音效可以在半径256格内听见。

# 你知道吗
[thumb|Java版中手持山羊角的僵尸](File:Zombie holding goat horns.png.md)
* 玩家和一些人-{}-形生物右手持有的山羊角[物品模型](物品模型.md)是镜像翻转的，使得山羊角的吹口端靠近生物头部。
* 山羊角“”音效与[袭击](袭击.md)中的“不祥号角”音效之一相同。
* 山羊角的音效是用长木管（类似于）录制的。<ref></ref>
* [Brandon Pearce](Brandon Pearce.md)提到，山羊角的设计意图更偏向社交功能（远距离传声）。<ref></ref>
