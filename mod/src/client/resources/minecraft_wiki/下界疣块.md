* *下界疣块（Nether Wart Block）**是一种可由[下界疣](下界疣.md)合成、会自然生成于[绯红森林](绯红森林.md)的装饰性方块。

# 生成
# = 自然生成 =
下界疣块会组成[绯红森林](绯红森林.md)中[巨型绯红菌](巨型绯红菌.md)的菌盖。

绯红森林的天花板处放置[垂泪藤](垂泪藤.md)地物之前，会尝试在附近生成下界疣块。

# = 人为生成 =
对[绯红菌](绯红菌.md)[骨粉](骨粉.md)长成的巨型绯红菌也包含下界疣块。

# = 合成 =

# 破坏
挖掘下界疣块的合适工具是锄。

下界疣块被破坏后会掉落自身。

# 用途
[猪灵](猪灵.md)、[僵尸猪灵](僵尸猪灵.md)、[疣猪兽](疣猪兽.md)、无法生成在下界疣块上。

# = 堆肥 =
将下界疣块放入[堆肥桶](堆肥桶.md)都有85%的概率使堆肥等级增加1。

# 你知道吗
* [绯红森林](绯红森林.md)和[诡异森林](诡异森林.md)在实装前曾被统称为“下界疣森林”，也许是因为它们生长着由下界疣块和[诡异疣块](诡异疣块.md)组成的[巨型下界菌](巨型下界菌.md)。
* 和常见的可以被合成为方块的物品不同，下界疣可以合成下界疣块，但下界疣块不能被拆解成下界疣。
