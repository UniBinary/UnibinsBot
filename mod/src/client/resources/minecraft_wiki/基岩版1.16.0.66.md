# 基岩版1.16.0.66

*页面ID: 63572* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.0.66**是[基岩版1.16.0](基岩版1.16.0.md)的第16个测试版，发布于2020年6月4日<ref></ref>，更新了服务器列表的UI，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[服务器列表](服务器列表.md)**
* 更新了UI。

* *[表情](表情.md)**
* 加入了在那儿（Over There!）和拍手（Simple Clap）表情。

# 修复
* *修复了12个漏洞**<br>
* *崩溃**
* 修复了试图用热带城市度假村混搭包创建世界时可能发生的崩溃。
* 修复了打开部分世界时可能发生的崩溃。

* *常规**
* 修复弹射物在没有造成伤害时过早清除的问题。给弹射物添加了2个新的可选组件。
* *游戏内容**
* 修复了箱子不生成战利品的漏洞。（）

* *图形**
* 修复了乘坐坐骑时的渲染问题。

* *附加包和脚本**
* 修复了移动组件被移除时可能会出现的问题，这意味着一个生物的速度必须重新从0开始提升。
* 修改了组件和，现在可设置为false使弹射物即使未造成伤害也会将其清除。默认为true以兼容旧版行为包。

* *命令**
* 向加入了和参数，分别代表当有物品占用该槽位时会取代原有物品或保留原有物品并报错。
* 修复了当所有目标被删除时，不会删除生物目标的漏洞。
* 修复了循环播放带有时间线的粒子，声音，事件和非零长度的动画可能发生的错误。

* 修复了使用命令给予指定级别的经验时，会显示格式错误的漏洞。
* 修复了“A Nightmare in Candyland”地图无法正确传送玩家的问题。</onlyinclude>
