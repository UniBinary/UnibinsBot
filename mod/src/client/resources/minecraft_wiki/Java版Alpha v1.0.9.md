# Java版Alpha v1.0.9

*页面ID: 32507* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.9**是的一次更新，发布于2010年7月21日<ref></ref>，更改了动画和[声音](声音.md)，并修复了一个漏洞。

# 更改
# = 生物 =
* *[玩家](玩家.md)、[生物](生物（已移除实体）.md)和[怪物](怪物（已移除实体）.md)**
* 其手臂不再来回摆动。

* *[牛](牛.md)**
* 更改了音效。

# = 常规 =
* *[暂停菜单](暂停菜单.md)**
* 调暗了背景。

# 修复
* *修复了1个漏洞**
* 修复了一个游戏无故卡顿的问题。<!--原文用词是stuttering--></onlyinclude>
