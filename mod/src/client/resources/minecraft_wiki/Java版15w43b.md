# Java版15w43b

*页面ID: 18704* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w43b**是[Java版1.9](Java版1.9.md)的第35个快照，发布于2015年10月22日<ref></ref>，加入了字幕，并修复了前一个快照的多人游戏问题以及使战利品表生效。

# 新内容
# = 常规 =
* *[字幕](字幕.md)**
* 字幕会为听力障碍或失聪人士显示每个声音。
* * 一个例子就是“苦力怕的嘶嘶声”。
* * 会有“<”或“>”展现声音的方向和来源。

# 更改
# = 方块 =
* *[水](水.md)**
* 在直接流动到玻璃旁时不会展现动态动画。

# = 生物 =
* *[远古守卫者](远古守卫者.md)**
* 掉落生鱼与海晶碎片的概率再次更改。现在鱼有50%的概率，海晶碎片有33%，16.7%的概率什么都没有，且数量通过抢夺魔咒依旧会增加。

* *[骷髅](骷髅.md)**
* 掉落物恢复为0–2根箭和0–2根骨头，通过抢夺依旧递增。

* *[凋灵骷髅](凋灵骷髅.md)**
* 关于煤炭的掉落变为0–2个煤炭，通过抢夺依旧递增，对于[15w42a](15w42a.md)仍是一次提升。
* 骨头恢复为0–2根骨头，通过抢夺依旧递增。

* *[鱿鱼](鱿鱼.md)**
* 现在掉落0–2个墨囊，通过抢夺依旧递增。

* *[恶魂](恶魂.md)**
* 掉落恢复为0–2个火药和0–1个恶魂之泪，通过抢夺依旧递增。

* *[兔子](兔子.md)**
* [兔子脚](兔子脚.md)重新变为稀有掉落物。
* 掉落物不再受抢夺影响。

* *[僵尸猪人](僵尸猪人.md)**
* 掉落物恢复为0–1个腐肉和0–1个金粒，通过抢夺依旧递增。

# = 世界生成 =
* *[雪屋](雪屋.md)**
* [金苹果](金苹果.md)现在会经常出现，并在打开箱子前区块未加载时不会消失。
