# Java版Indev 0.31 20100124-2119

*页面ID: 172450* | *来源: Minecraft Wiki*

<onlyinclude>
* *0.31**的一个版本发布于2010年1月24日21:19（UTC），加入了一些新特性。<ref></ref>

# 新内容
# = 方块 =
* *[箱子](箱子.md)**
* 用于存储[方块](方块.md)和[物品](物品.md)。
* 在两个箱子中间放置箱子会形成三重箱子。

# = 非生物实体 =
* *[箭](箭.md)**
* 加入了新的音效。

# = 游戏内容 =
* *常规**
* 一次可扔掉一整组物品，而非之前的一个。

# = 世界生成 =
* *[Indev房子](Indev房子.md)**<ref></ref>
* 一种新的结构，自然生成于世界中心。
* [玩家](玩家.md)生成于此，内有装着几乎每种方块和所有可用[工具](工具.md)的箱子。

# 更改
# = 方块 =
* *[熔岩](熔岩.md)**
* 再次可以点燃易燃物体。

# = 物品 =
* *[斧](斧.md)**
* 更改了纹理。

* *常规**
* 堆叠方块最大限制变回99。

# = 非生物实体 =
* 方块[掉落物](掉落物.md)现在会旋转。</onlyinclude>
