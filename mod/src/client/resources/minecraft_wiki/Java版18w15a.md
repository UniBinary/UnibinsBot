# Java版18w15a

*页面ID: 34232* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w15a**是[Java版1.13](Java版1.13.md)的第31个快照，发布于2018年4月11日<ref></ref>，加入了蓝冰、潮涌核心、海洋之心、鹦鹉螺壳，以及海豚和冰山，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[蓝冰](蓝冰.md)**
* 生成于[冰山](冰山.md)。
* 比一般的[冰](冰.md)和[浮冰](浮冰.md)更滑。

* *[潮涌核心](潮涌核心.md)**
* 合成配方：1个[海洋之心](海洋之心.md)+8个[鹦鹉螺壳](鹦鹉螺壳.md)。
* 可以在它周围放置海晶石、海晶石砖或海晶灯来启动。
* * 启动之后将会给予周围处于水中或雨中的[玩家](玩家.md)潮涌能量[状态效果](状态效果.md)。
* ** 依据潮涌能量等级将会停止氧气条的消耗、给予水下视野并提高挖掘速率。
* 完整的结构能够使潮涌核心被完全充能。
* * 当启动一个被完整充能的潮涌核心将使周围敌对[生物](生物.md)受到伤害。
* 放出15光照等级的强光。

# = 物品 =
* *[海洋之心](海洋之心.md)**
* 用于制作潮涌核心。
* [生存模式](生存模式.md)中暂时无法获得。

* *[鹦鹉螺壳](鹦鹉螺壳.md)**
* 用于制作潮涌核心。
* 可以从钓鱼获得。
* [溺尸](溺尸.md)偶尔会带着鹦鹉螺壳生成。

# = 实体 =
* *[海豚](海豚.md)**
* 在除了[冻洋](冻洋.md)的水域生成。
* 友好生物，就像[狼](狼.md)、[僵尸猪人](僵尸猪人.md)一般，[海豚](海豚.md)也会在被激怒时成群地攻击。
* 可以喂食[生鳕鱼](生鳕鱼.md)，但并不因此交配。
* 会捡起[物品](物品.md)来玩耍，并且会在一小段时间后丢弃。
* 能追逐船只与跳出海面。
* 会因为待在陆地上太久而窒息而死。

# = 世界生成 =
* *结构**
* [冰山](冰山.md)
* * 会在[封冻深海](封冻深海.md)生物群系生成。

# = 常规 =
* *[选项](选项.md)**
* 在显示选项加入了生物群系过渡距离。

# 更改
# = 方块 =
* *[水](水.md)**
* 拥有新的纹理
* 现在每格一个等级的光照而非三个等级的光照。
* * 这只影响了最近一段时间生成的水。
* * 明亮的水下视野已经被移除，现在处于水深处时会更加黑暗。
* 海洋生物群系的变种现在有着自己的水体颜色，此外沼泽的水体颜色被更改了。
* 在比较新的生成区块中，会更少在温水海洋旁边生成冻洋（包含变种）。

# = 生物 =
* *常规**
* 生物现在可以生成在[冰](冰.md)上，而不是只有北极熊才可以。

# = 游戏内容 =
* *[游泳](游泳.md)**
* 玩家现在可以游过1×1的洞。
* 游泳与一般状态的转换现在更加圆滑。
* 在水面上冲刺不再会使玩家浮出水面，而是维持在同样的水平面上。

# = 常规 =
* *性能**
* 优化了雾的渲染。
