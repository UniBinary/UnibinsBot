# PlayStation 4版1.90

*页面ID: 59649* | *来源: Minecraft Wiki*

* *1.90**是[PlayStation 4版](PlayStation 4版.md)的一个更新，发布于2019年4月15日，加入了许多[村庄与掠夺](村庄与掠夺.md)的特性。<ref></ref>此次更新等价于[基岩版1.10](基岩版1.10.md)，仅缺少实验性玩法的游戏内容，例如新村庄。<ref> ("R10" means "Release 1.10")</ref>

# 新内容
# = 方块 =
* *[织布机](织布机.md)**
* 用于轻松地为[旗帜](旗帜.md)制作图案。
* *[讲台](讲台.md)**
* 放置[书与笔](书与笔.md)或[成书](成书.md)在讲台上以供多个玩家阅读。
* * [红石比较器](红石比较器.md)功能暂无。
* *[灯笼](灯笼.md)**
* 充当新的可悬挂光源。
* *[木头与去皮木头](木头.md)**
* 有6面[原木](原木.md)的侧面纹理。

# = 物品 =
* *[弩](弩.md)**
* 新[武器](武器.md)。
* 可以使用三个新的[魔咒](魔咒.md)。
* 比弓强，但装弹时间更长。
* *[旗帜图案](旗帜图案.md)**
* 用于织布机
* 可以用于设计旗帜。
* *[盾牌](盾牌.md)**
* [潜行](潜行.md)用盾牌[防御](防御.md).
* 旗帜还不能用于盾牌。

# = 生物 =
* *[掠夺者](掠夺者.md)**
* 敌对生物，属于[灾厄村民](灾厄村民.md)。
* 拥有24点生命。
* 生成时手持弩。
* 被杀死后掉落箭和弩（受抢夺影响）。
* 会袭击或占领[村庄](村庄.md)、杀害[村民](村民.md)。
* 无法装备任何[盔甲](盔甲.md)。
* 只能在[创造模式](创造模式.md)使用。

* *[猫](猫.md)**
* 加入了新的皮肤：Jellie——社区猫比赛冠军。

# = 游戏内容 =
* *[魔咒](魔咒.md)**
* [快速装填](快速装填.md)
* * 用于减少弩的装弹时间。
* [多重射击](多重射击.md)
* * 用于让弩射出3支箭或烟花但只消耗1支。
* [穿透](穿透.md)
* * 用于弩上射击生物。

# = 常规 =
* *纹理包**
* 加入了Minecraft Classic纹理包（内置），其中包含[纹理更新](纹理更新.md)前的纹理。
* *奖杯**
* 加入了扩展包9，其中包含5个新奖杯
* * （银杯）亚特兰蒂斯？——找到一处水下遗迹。
* * （铜杯）组织向导——用铁砧给一只潜影盒命名。
* * （铜杯）鲜果旗帜——使用附魔金苹果来合成旗帜
* * （银杯）吸猫体质——与二十只流浪猫交朋友。
* * （金杯）纵横七海——访问所有的海洋生物群系

# 更改
# = 方块 =
* *[紫颂果](紫颂果.md)**
* 现在可以被箭射破。
* *[枯萎的灌木](枯萎的灌木.md)**
* 现在可以作为熔炉的燃料。
* *[发射器](发射器.md)**
* 激活带有剪刀的发射器可以剪羊毛。
* *[树叶](树叶.md)**
* 现在树叶枯萎会掉落木棍。
* *[海绵](海绵.md)**
* 将湿海绵放在下界与温暖生物群系中一段时间后会被烘干。
* *未染色的[地毯](地毯.md)、[玻璃](玻璃.md)与[玻璃板](玻璃板.md)**
* 现在可以通过在工作台上用染料包围来进行染色。
* *[原木](原木.md)与[去皮原木](去皮原木.md)**
* 重命名自木头与去皮木头。

# = 物品 =
* *[兔肉煲](兔肉煲.md)与[甜菜汤](甜菜汤.md)**
* 现在有无序的合成表。

# = 生物 =
* *[猫](猫.md)**
* 现在可以通过喂鱼来回复生命值。
* *[苦力怕](苦力怕.md)**
* 现在被[流浪者](流浪者.md)或骷髅杀死会掉落音乐唱片。

# = 常规 =
* *纹理**
* 添加[纹理更新](纹理更新.md)的纹理作为默认纹理。
