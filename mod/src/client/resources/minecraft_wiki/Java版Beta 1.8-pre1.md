# Java版Beta 1.8-pre1

*页面ID: 32462* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.8-pre1**是[Java版Beta 1.8](Java版Beta 1.8.md)的首个预发布版，发布于2011年9月8日，加入了首批[冒险更新](冒险更新.md)的特性，加入了[饥饿系统](饥饿.md)，并调整了[战斗机制](战斗.md)和[生物群系](生物群系.md)分布。

# 新内容
# = 方块 =
* *[玻璃板](玻璃板.md)**
* [玻璃](玻璃.md)的更薄版本，可以自动连接。
* 由6块玻璃合成，一次可以合成16个。
* 破坏后掉落自身。

* *[铁栏杆](铁栏杆.md)**
* 作用与玻璃板相似，但使用铁质材质。
* 由6块[铁锭](铁锭.md)合成，一次可以合成16个。
* 自然生成于[要塞](要塞.md)以及[村庄](村庄.md)的铁匠铺中。

* *[栅栏门](栅栏门.md)**
* 出入口方块，可通过按下键自由开关。
* 由4块[木板](木板.md)和2个[木棍](木棍.md)合成，一次只能合成1个。
* 会与[栅栏](栅栏.md)无缝连接。

* *[石砖](石砖.md)**
* 包含三个变种：普通石砖、裂纹石砖和雕纹石砖。它们在游戏内的名称均为“石砖”。
* 自然生成于要塞中。
* 普通石砖可用于合成对应的台阶和楼梯。

* *[藤蔓](藤蔓.md)**
* 植物方块，可以在[固体方块](固体方块.md)上自行生长。
* 受生物群系颜色影响。
* 破坏后掉落自身。

* *[虫蚀方块](虫蚀方块.md)**
* [石头](石头.md)、[圆石](圆石.md)和普通石砖的虫蚀版本。
* 被破坏时会生成蠹虫。
* 目前无游戏内名称。

* *[台阶](台阶.md)和[楼梯](楼梯.md)**
* 加入了砖块和普通石砖对应的台阶和楼梯方块。
* 破坏台阶会使之掉落自身，而破坏楼梯会使之掉落对应的完整方块。

* *[蘑菇方块](蘑菇方块.md)**
* 包含三个变种：棕色蘑菇方块、红色蘑菇方块和蘑菇柄。
* 破坏后掉落对应[蘑菇](蘑菇.md)植株。

* *[西瓜](西瓜.md)**
* 作物方块，类似于[南瓜](南瓜.md)。
* 由西瓜茎长出，必须长在[耕地](耕地.md)上。
* 破坏后掉落若干[西瓜片](西瓜片.md)。

* *[西瓜茎](西瓜茎.md)和[南瓜茎](南瓜茎.md)**
* 分别由西瓜种子和南瓜种子种植长成，必须长在耕地上。
* 分别可以结出西瓜和[南瓜](南瓜.md)。

* 可用于种植西瓜和南瓜。

# = 生物 =
* *[末影人](末影人.md)**
* 瘦长的黑色人-{}-形生物，有着绿色的眼睛，散发着灰色的烟雾[粒子](粒子.md)。

* *[蠹虫](蠹虫.md)**

* [蜘蛛](蜘蛛.md)的洞穴变种，会对玩家造成[中毒](中毒.md)效果。

* *[蕨](蕨.md)**
* 不再自然生成。

* 现在作为实体渲染。这也使得其不再显示方块损坏中的纹理效果。
* [32px](File:Chest JE2 BE3.gif.md) [32px](File:Large Chest JE2 BE2.gif.md) 向箱子的实体模型加入了开启和关闭的动画。
* 纹理从转至文件夹下的和。
* 现在会随玩家摆放时的朝向更改方向了。
* 现在可以在废弃矿井和要塞中找到。

* *[熔岩](熔岩.md)**

* 现在可以用[铁镐](铁镐.md)开采了。

# = 物品 =
* *[剪刀](剪刀.md)**
* 现在可以用于采集和蕨。

* *[熟猪排](熟猪排.md)**
* 将纹理从 [32px](File:Cooked Porkchop JE1.png.md) 更改为 [32px](File:Cooked Porkchop JE2 BE1.png.md) ，以与牛排区分。

* *[苹果](苹果.md)**
* 现在在[要塞](要塞.md)储藏室的箱子里生成。
