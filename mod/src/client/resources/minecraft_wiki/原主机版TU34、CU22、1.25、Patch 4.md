# 原主机版TU34、CU22、1.25、Patch 4

*页面ID: 68910* | *来源: Minecraft Wiki*

* *TU34/CU22/1.25/Patch 4**是[原主机版](原主机版.md)的一次更新，发布于2016年4月6日，修复了一些漏洞。<ref></ref><ref></ref>

# 新内容
# = 常规 =
* *[皮肤包](皮肤包.md)**
* 加入了Minecraft Story Mode皮肤包。

* *[选项](选项.md)**
* 在声音选项中加入了“Minecraft声音”选项。

# = 游戏内容 =
* *[成就](成就/原主机版与New Nintendo 3DS版.md)**
* XB360、XBONE、PS3、PS4、PSV：加入了6个成就。
* WIIU：加入了成就系统。

* *[物品栏](物品栏.md)**
* 在创造模式与超平坦菜单中加入了巨型蘑菇方块。

# 更改
* 优化分屏控制。

# 修复
* *修复了19个漏洞**
* 一个在末影龙免疫攻击时的问题。
* 修复史莱姆不生成在某些沼泽和史莱姆区块的问题。
* 迅捷药水，迟缓药水和信标的速度加成对玩家无效。
* 玩家在床上睡觉不正常工作时会瞬移。
* 多人游戏中主世界一些区块生成错误。
* 经验球在村民交易中不可获得的问题。
* 荆棘效果不对玩家起作用。
*  - TNT大炮不工作。
*  - 门打开时顶部有一个奇怪的纹理（还有其他的面）。
*  - 修复了草的纹理。
*  - 白郁金香描述不正确。
*  - 沼泽小屋的边框太小。
*  - 被淹没的沼泽小屋。
*  - 看着玩家站着的箱子时，屏幕抖动并且玩家不能移动。
*  - 地图不工作（除非"View Hand"是开着的）。
*  - 史莱姆生成在沼泽小屋里。
*  - 物品展示框里的地图没有图标。
*  - 物品展示框在奇怪的距离消失。
* PS3：一个内存问题导致出现“加载失败”的提示。
