# Java版Classic服务器1.5

*页面ID: 45309* | *来源: Minecraft Wiki*

* *1.5**<ref>[IRC记录](#logs.md): "*P6:00:57 <AlLnAtuRalX> server software on website is 1.5*" (2009年6月20日 23:00:57 UTC)</ref>是[Classic](Java版Classic.md)服务器的一次更新，发布于2009年6月20日。<ref></ref>

# 新内容
# = 游戏内容 =
* *[聊天](聊天.md)**
* 加入了聊天冷却。
* * 在聊天栏中刷屏的玩家会被禁言，持续8秒。

* *常规**
* 加入了移动冷却。
* * 服务器每一刻只会处理不超过一次移动命令。
* * 站着不动可以在客户端滞后时更新。
* 允许玩家通过<code>stdin</code>发送大多数的管理员[命令](命令.md)。

# = 常规 =
* *其他**
* 在中加入<code>max-connections</code>。
* * 这个数字代表每个IP到这个服务器的连接的最大数量。
* * 默认值为3。
