# 下界合金升级

*页面ID: 156685* | *来源: Minecraft Wiki*

* *下界合金升级（Netherite Upgrade）**是一种[锻造模板](锻造模板.md)，用于将钻石质装备升级为下界合金质装备，可使用[下界岩](下界岩.md)复制自身。

# 获取
# = 箱子战利品 =

# = 合成 =
尽管下界合金升级本身不能合成获得，但可以利用特定的合成配方来复制自身。

# 用途

下界合金升级可在[锻造台](锻造台.md)上与和[下界合金锭](下界合金锭.md)相结合，将部分[钻石装备](装备.md)升级为对应的下界合金装备。
