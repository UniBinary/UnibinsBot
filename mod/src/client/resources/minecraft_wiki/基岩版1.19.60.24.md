# 基岩版1.19.60.24

*页面ID: 100620* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.60.24**（Android）、**Preview 1.19.60.24**（Xbox/Windows/iOS/iPadOS）是[基岩版1.19.60](基岩版1.19.60.md)的第4个测试版，发布于2022年12月14日<ref></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[史莱姆](史莱姆.md)和[岩浆怪](岩浆怪.md)**
* 将生成所需空间更改为2.08×2.08×2.08。

# = 技术性 =
* *命令**
* 移除了将原始文本JSON对象的属性设置为JSON对象数组的非预期功能。

* *生物**
* 为组件加入了新属性。
* * 当拥有的生物被玩家控制时，该属性会覆写属性。
* * 该属性的优先级低于。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”、“即将推出的创作者功能”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[雕纹书架](雕纹书架.md)**
* 现在可以与[投掷器](投掷器.md)交互。（）

# = 技术性 =
* *API**
* 加入了方法。
* * 用于返回含有指定实体上所有有效效果的数组。

* *命令**
* 修复了启用“即将推出的创作者功能”实验性选项后，选择器会无法使用的漏洞。（）

# 修复
* *游戏内容**
* 史莱姆和岩浆怪不再会生成于2格高或更小的空间内。（）

* *袭击**
* 现在拥有不祥之兆效果的玩家骑着马或使用鞘翅滑翔进入村庄时会正确触发袭击。（）

* *物品**
* 修复了快速攻击生物时物品耐久会不正确损耗的问题。（）

* *漏斗**
* 漏斗尝试吸入多种物品类型时不再会无法收集物品。（）

* *生物**
* 被推动的马不再能跨过上方放有地毯的栅栏。（）
* 恼鬼的碰撞箱现在会与其模型保持垂直居中。（）
* 恼鬼现在会在空手状态下使用独立的蓄力动画。（）
* 恼鬼现在会渲染其副手物品。
* 恼鬼和悦灵现在能够在船或矿车中正常地坐着。（）

* *触摸**
* 修复了无法在携带版UI下将物品在创造模式物品栏和玩家展开的物品栏之间间接移动的漏洞。

* *触摸控制**
* 修复了按住向左或向右移动的按钮时，向前移动的触控方向按钮会失效的问题。

* *用户界面**
* 现在主菜单上的反馈按钮会在导向网络浏览器前提示玩家。</onlyinclude>
