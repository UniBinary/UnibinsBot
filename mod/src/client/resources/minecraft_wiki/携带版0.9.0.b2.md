# 携带版0.9.0.b2

*页面ID: 31486* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.9.0 alpha build 2**是[v0.9.0 alpha](携带版0.9.0.md)的第2个测试版，发布于2014年6月10日。此次更新加入了新的声音，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[村民](村民.md)、[史莱姆](史莱姆.md)、[狼](狼.md)和[末影人](末影人.md)**
* 加入了新的声音。

# 更改
# = 方块 =
* *[刷怪笼](刷怪笼.md)**
* 现在被加入至创造模式物品栏中。
* 可以用[刷怪蛋](刷怪蛋.md)改变刷怪笼的类型。
* 刷怪笼放置时不再有默认的实体类型，此前默认为猪。

# = 生物 =
* *[末影人](末影人.md)**
* 末影人现在会瞬移以躲避[箭](箭.md)。

# 修复
* *修复了17个漏洞**
* 世界加载过程中不再会崩溃。
* 修复了一个罕见的崩溃以及一个世界损坏问题。
* 修复了退出当前界面时可能发生的崩溃。
* 移除了分屏控制上的灰色四边形图案。
* 玩家行走时农作物不再会闪烁。
* 加入了灰化土的名称。
* 现在沙漠类型村庄由砂岩构成。
* 现在丛林和枝繁叶茂的森林中的火会熄灭得更快，以避免其失控蔓延。
* 修复了超平坦世界的区块中会出现黑色边框的问题。
* 红沙在下落过程中不再会变为普通沙子。
* 渲染距离为64个方块时，生物不再渲染为蓝色。
* 放置在方块下方的荧石不再会旋转其纹理。
* 蘑菇不再会发光。
* 现在闪长岩、花岗岩和安山岩会以正确的资源类型掉落。
* 现在深色橡树、金合欢树叶及其对应木头会被火点燃。
* 玩家现在可以在刷怪笼上放置火把。
* 刷怪笼现在会正确保存。</onlyinclude>
