# 命令/event

*页面ID: 70299* | *来源: Minecraft Wiki*

触发实体事件。

# 语法
   <code>event entity <target: target> <eventName: string></code>

# 参数

   必须为玩家名称或[目标选择器](目标选择器.md)。
   指定实体事件的作用对象。

   必须为单词（其间不能夹杂空格）或用引号标记的字符串。
   指定命令触发的实体事件。应使用[生成事件](生成事件.md)。

# 结果

# 输出

# 示例
* 所有[炽足兽](炽足兽.md)重新自然生成：<code>/event entity @e[type=strider] minecraft:entity_spawned</code>

* 所有的[村民](村民.md)变成[僵尸村民](僵尸村民.md)：<code>/event entity @e[type=villager] become_zombie</code>
