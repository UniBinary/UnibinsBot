# 钥匙（3D Shareware v1.34）

*页面ID: 143963* | *来源: Minecraft Wiki*

* *红色钥匙（Red Key）**、**黄色钥匙（Yellow Key）**和**蓝色钥匙（Blue Key）**是一类没有实际用途的[物品](物品.md)。

# 获取
# = 生物掉落物 =

|
|
|notes=
red_key = 掉落红色钥匙
yellow_key = 掉落黄色钥匙
blue_key = 掉落蓝色钥匙
}}

# = 作弊码 =
输入作弊码<code>IDKFA</code>可以分别各获得1个钥匙。

# = 箱子战利品 =

# = 钓鱼 =
在[钓鱼](钓鱼.md)时，蓝色钥匙有概率作为[宝藏](钓鱼#垃圾与宝藏.md)被钓上来。

# 用途
钥匙没有实际用途。

# 你知道吗
* [32px](File:Green Key.png.md) [Notch](Notch.md)于2009年开发的游戏*The Europa Arcology Incident*中有一个纹理相似的“绿色钥匙”。
* 这三种钥匙及其作弊码可能是在致敬游戏*Doom*。
