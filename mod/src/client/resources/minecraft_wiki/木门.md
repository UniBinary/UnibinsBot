# 生成
红树木门、樱花木门、苍白橡木门、竹门、绯红木门和诡异木门不会生成在世界中。

# 破坏
挖掘木门的合适工具是斧。

木门被破坏后会掉落自身。

# 用途

玩家、[村民](村民.md)、[铜傀儡](铜傀儡.md)、、[猪灵](猪灵.md)和[猪灵蛮兵](猪灵蛮兵.md)可以开关木门。

对着木门按下键即可将其打开或关闭，处于[风爆](爆炸#风爆.md)影响范围中时也会改变其开关状态。

在困难[难度](难度.md)下，[僵尸](僵尸.md)及其变种有或的概率具有打破木门的能力，但只有在尝试接近目标生物时才会那么做。作为袭击的一部分生成的卫道士在普通和困难难度中也会破坏木门，但只会在锁定一个目标后才会这样做。有时候卫道士也会直接打开木门而不是破坏它。僵尸和卫道士会尝试冲破处于“关闭”状态的门，门处于“开启”状态时即使阻挡通过也不会尝试打破（例如，靠在门道右侧面对左侧放门，门处于关闭状态时允许通过，开启状态时则不允许通过）。

# = 红石元件 =

被激活的木门仍然可以被玩家或村民手动关闭，但在接收到新的上升沿或之前，门不会再次自动打开（即需要将红石信号关闭再开启才能重新控制门）。使门的上下部分之中的一部分激活或撤销激活，而另一部分保持激活，门也会重新自动打开（该行为会主要信号源，并使门立刻自身开关状态）。

# = 燃料 =

主世界木质门和竹门能用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个门可以烧炼1个物品。

# 你知道吗
* 反向放置木门可以让其表现为开启状态（默认为关闭），使得其关闭与开启的表现相反，这时关着的门被僵尸检测为开着的门，不会尝试对其进行破坏，即一扇“僵尸无法破坏的木门”。村民的行为与其类似，其会将开着的门检测为关着的门，从而将其打开（无法通过）。
