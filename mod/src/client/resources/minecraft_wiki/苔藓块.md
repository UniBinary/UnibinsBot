# 苔藓块

*页面ID: 77855* | *来源: Minecraft Wiki*

}}

* *苔藓块（Moss Block）**是一种生成于[繁茂洞穴](繁茂洞穴.md)、能在[骨粉](骨粉.md)的作用下快速蔓延的植物方块。

# 生成
# = 自然生成 =
苔藓块会自然生成于[繁茂洞穴](繁茂洞穴.md)生物群系以及[试炼密室](试炼密室.md)中生成[史莱姆](史莱姆.md)的[试炼刷怪笼](试炼刷怪笼.md)旁。

# 破坏
挖掘苔藓块的合适工具是锄。

苔藓块被破坏后会掉落自身。

# 用途
[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)、[蕨](蕨.md)、[大型蕨](大型蕨.md)、[大型蕨](大型蕨.md)、[甜浆果丛](甜浆果丛.md)、[树苗](树苗.md)、[花](花.md)、[粉红色花簇](粉红色花簇.md)、[野花簇](野花簇.md)、[灌木丛](灌木丛.md)、[杜鹃花丛](杜鹃花丛.md)、[盛开的杜鹃花丛](盛开的杜鹃花丛.md)、[甘蔗](甘蔗.md)、[竹子](竹子.md)、[枯萎的灌木](枯萎的灌木.md)、[小型垂滴叶](小型垂滴叶.md)、[大型垂滴叶](大型垂滴叶.md)、[下界菌](下界菌.md)、[菌索](菌索.md)和[下界苗](下界苗.md)能被放置在苔藓块上方。

苔藓块无法被[活塞](活塞.md)拉动，被活塞推动时会被破坏并成为掉落物。

# = 骨粉 =
上方一格为空气的苔藓块被玩家或[发射器](发射器.md)[骨粉](骨粉.md)后，以苔藓块为中心，水平切比雪夫半径3格，垂直[切比雪夫半径](切比雪夫距离.md)5格范围内，最上方且上方一格为空气<ref>；</ref>的[草方块](草方块.md)、[泥土](泥土.md)、[砂土](砂土.md)、[灰化土](灰化土.md)、[缠根泥土](缠根泥土.md)、[菌丝体](菌丝体.md)、[苍白苔藓块](苍白苔藓块.md)、[石头](石头.md)、[深板岩](深板岩.md)、[凝灰岩](凝灰岩.md)、[花岗岩](花岗岩.md)、[闪长岩](闪长岩.md)、[安山岩](安山岩.md)、<ref></ref>、和[洞穴藤蔓](洞穴藤蔓.md)有概率转变为苔藓块，转变后的苔藓块上有概率出现[覆地苔藓](覆地苔藓.md)、[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[杜鹃花丛](杜鹃花丛.md)或[盛开的杜鹃花丛](盛开的杜鹃花丛.md)中的一种。

; 生成细节
进行转变时，游戏会以苔藓块为中心选取转换区域，其长和宽分别从5和7中独立选取。该区域内，水平方向顶角处被选中的概率为0%，边缘处为75%，其余位置为100%。对于被选中的位置，游戏从比苔藓块高一格处开始搜寻上方为空气的方块；如初始位置为空气，则向下搜寻，否则向上搜寻，但均集中在5格内。游戏将试图转变各个位置找到的首个方块。转变成功的方块上还有概率生成植物。不同植物的生成概率参见下表。

# = 转变 =
部分树苗以及杜鹃花丛长成为[树木](树木.md)后会使其下方的苔藓块转变。
* 以2×2放置的云杉树苗长成[大型云杉](大型云杉.md)后，云杉树苗下方的4个苔藓块以及周围的苔藓块会转变为[灰化土](灰化土.md)。
* 杜鹃花丛长成为[杜鹃树](杜鹃树.md)后会将其下方的苔藓块转变为[缠根泥土](缠根泥土.md)。
* 除大型云杉、杜鹃树、[红树](红树.md)及[珍异橡树](珍异橡树.md)外的树木长成后，下方的苔藓块会被转变为[泥土](泥土.md)。

# = 嗅探兽蛋 =
苔藓块能够加快[嗅探兽蛋](嗅探兽蛋.md)的孵化。放置于苔藓块上的嗅探兽蛋的孵化时长将由20分钟减少为10分钟。

# = 合成材料 =

# = 堆肥 =
将苔藓块放入[堆肥桶](堆肥桶.md)会有65%的概率增加一层堆肥层。
