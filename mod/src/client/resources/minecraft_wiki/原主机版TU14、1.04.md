# 更改
# = 常规 =
* *主机选项**
* 加入了玩家的飞行隐身等效果的主机选项。
* 加入了传送玩家的功能。
* *[原主机版教程](原主机版教程.md)**
* 加入了新教程。
* 更改了音乐唱片的位置。
* *[语言](语言.md)**
* PS3：加入了丹麦语、芬兰语、拉丁美洲西班牙语、荷兰语、挪威语、波兰语、瑞典语和土耳其语。
* *[纹理包](纹理包.md)**
* XB360：更新所有纹理包以适配TU14更新。
* XBONE：更改城市纹理包中灰色羊毛的纹理使之更像路面。
* *[混搭包](混搭包.md)**
* XB360：更新所有混搭包以适配TU14更新。

# = 方块 =
* *[砂岩](砂岩.md)**
* 加入了平滑砂岩和雕纹砂岩的合成配方。
* *[原木](原木.md)**
* 现在能横向放置。
* *[台阶](台阶.md)**
* 更改了台阶和台阶上方块的位置。
* *[楼梯](楼梯.md)**
* 更改了颠倒楼梯的位置。
* *木质[压力板](压力板.md)**
* 可以用箭激活。
* *木质[按钮](按钮.md)**
* 可以用箭激活。
* *[冰](冰.md)**
* 可以使用带有[精准采集](精准采集.md)的工具开采。
* 下界的冰会融化。
* *[玻璃板](玻璃板.md)**
* 可以使用带有[精准采集](精准采集.md)的工具开采。
* *[门](门.md)**
* 僵尸正在破坏的门现在会显示裂缝。
* *[炼药锅](炼药锅.md)**
* 暴露在雨中的炼药锅现在会装满水。
* *[活塞](活塞.md)**
* 活塞的状态更新需要以前两倍的时间。
* *[树叶](树叶.md)**
* 会被雨水穿透。
* *[拉杆](拉杆.md)**
* 可以放置在方块的底部。
* *[TNT](TNT.md)**
* 会根据难度不同造成不同的杀害。
* *[睡莲](睡莲.md)**
* 船会摧毁睡莲，而不是被睡莲摧毁。
* *[熔炉](熔炉.md)**
* 熔岩桶烧制完后会归还铁桶。

# = 物品 =
* *[皮革盔甲](皮革盔甲.md)**
* 可以染色。
* *木质[工具](工具.md)**
* 可以作为熔炉的燃料。
* *[鞍](鞍.md)**
* 有鞍的猪死亡后会掉落鞍。
* *[线](线.md)**
* 可以被放置了。
* *[书](书.md)**
* 合成配方发生了改变。

# = 生物 =
* 创造模式中，生物被玩家攻击后一会儿就会恢复到非敌对状态。
* *[狼](狼.md)**
* 可以对驯服的狼的项圈进行染色。
* *[猪](猪.md)**
* 可以使用胡萝卜钓竿控制猪。
* 会掉落更多猪排。
* *[村民](村民.md)**
* 添加不同职业的村民。
* 刷怪蛋生成的村民会拥有随机的职业。
* *[下界](下界.md)生物**
* 能在主世界的下界传送门附近生成了。
* *[苦力怕](苦力怕.md)**
* 现在会敌对于最后一个攻击它的玩家了。
* 爆炸伤害会根据难度递增，且会产生更多的击退。
* *[蜘蛛](蜘蛛.md)**
* 现在会敌对于最后一个攻击它的玩家了。
* *[史莱姆](史莱姆.md)**
* 超平坦世界中史莱姆的生成更少了。

# = 世界生成 =
* *[末地](末地.md)**
* 天空的颜色改变了。

# = 游戏内容 =
* *[附魔](附魔.md)**
* 移除了水下[击退](击退.md)的效果。
* *[奖励箱](奖励箱.md)**
* 有更多物品了。

# 修复
* *修复了15个漏洞**
* 修复了末影人不张嘴的漏洞。
* PS3：网络问题修复。
* XB360：修复了当玩家在下界或末地时，物品展示框里地图崩溃的漏洞。
* XB360：修复了可以透过墙看到箱子的漏洞。
* XB360：修复了一些与玩家黑名单相关的崩溃。
* XB360：一些光照修复。
* XB360：修复烈焰使者以便它们在喷火之前着火。
* XB360：修复以允许在创造模式下喝牛奶。
* XB360：修复以允许萤幕分享玩家看到喷溅药水粒子。
* XB360：修复以阻止在退出末地时使用快速选择栏中的第一个物品替换持有的物品。
* XB360：修复了在前往下界或末地时投掷末影珍珠的漏洞。
* XB360：修复了按钮的激活时间。
* XB360：修复了发射器和火焰弹的崩溃。
* XB360：修复了“帮助和选项”菜单中本地配置文件的崩溃。
* XB360：修正了在丛林树上使用丝绸之触获得的叶子。
