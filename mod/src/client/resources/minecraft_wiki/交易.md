* *交易（Trading）**系统是一种允许[玩家](玩家.md)与[村民](村民.md)或[流浪商人](流浪商人.md)交互，实现[绿宝石](绿宝石.md)和其他[物品](物品.md)间相互交换的机制。

# 机制
交易允许玩家用[绿宝石](绿宝石.md)与村民交换[物品](物品.md)，反之也可以用物品交换绿宝石。对拥有职业的成年[村民](村民.md)或[流浪商人](流浪商人.md)按下键会弹出交易的GUI界面，并显示它们提供的交易选项，村民的交易界面还会显示它们的职业和级别。它们的交易选项多种多样，不同的物品种类和数量对应不同数量的绿宝石，反之亦然。

村民会依其职业提供不同的交易选项，且只会进行它们所提供的交易选项的交易。如果存在不止一个交易选项，在交易界面左侧可以看到其他的选项。交易选项中的一些物品与村民的职业有关。交易系统可以帮助玩家方便地获取一些稀有物品，比如[锁链盔甲](锁链盔甲.md)和部分[附魔书](附魔书.md)。交易成功时，村民会发出同意的声音，并发出绿色粒子。但如果玩家选取了已锁定的交易，或是未能给出足够的交换物，村民就会发出拒绝的声音。

只有拥有职业的成年村民可以进行交易，玩家不能与傻子村民、失业村民和幼年村民进行交易。若尝试与一个傻子村民、失业村民或幼年村民交易会使其摇头并发出拒绝的声音；与其则不会有任何反应。打开交易界面时，村民或流浪商人会暂停寻路，如果它们处在交易中时受到伤害，交易界面则会关闭。

同一交易选项交易了一定次数之后，村民就会锁定交易，在下一次补货前不再提供此交易；村民可以升级并解锁新的交易选项。详见。

# = 言论与声望 =

玩家在每个村民处都有独立的**声望**。声望等于该村民持有的针对此玩家的各个言论的强度值乘以其对应的声望倍率后相加。

声望将会影响村民交易的价格，声望越高价格就越低，反之价格升高。价格降低的值为声望值乘以对应交易的价格乘数（）值，结果向下取整。常见的价格乘数为<code>0.2</code>或<code>0.05</code>，当声望为负值时，此值也变为负值，代表价格升高。

# = 供需关系 =
交易的价格会随需求量发生变化。若玩家成功进行了一项交易并且达到交易上限次数，那么村民补货后，该项交易的价格或。价格升高后，若玩家未再进行该项交易，则村民补货后，该项交易的价格就会有所下跌。

需求与每项交易绑定，而非与村民绑定，因此一个村民可以为某样物品提供一个高价的交易，而其他物品的交易却以低价进行。部分交易不受需求影响。

对于大部分交易，玩家声誉提供的降价足以使交易保持原价或降价。

# = 村庄英雄 =

当一个玩家获得[村庄英雄](村庄英雄.md)效果时，此玩家会在所有村民的交易中获得折扣。村庄英雄效果能降低的价格公式为<math>\max \left\{ 1, \lfloor 0.3 + 0.0625 (a - 1) \rfloor \times c \right\}</math>，其中<math>a</math>是村庄英雄效果的等级，<math>c</math>是某项交易第一项物品的基础价格，此降价会与声望影响的降价一起影响交易最终的价格。村民也会给予玩家特定的礼物作为回报，礼物取决于村民的职业。

# = 新增交易项与补货 =
村民的职业决定了关系其交易选项的交易池。村民的职业取决于其认领的[工作站点方块](工作站点方块.md)，可通过村民的外观和交易界面的名称识别。村民需要等级和经验来解锁下一级的交易，1-5的等级分别对应新手、学徒、老手、专家和大师，村民在每次升级时会获得10秒生命恢复I效果，总计恢复生命值。村民可通过在自己的工作站点工作来为交易**补货**。

村民有5个职业等级。玩家可在村民的交易界面查看其等级，也可通过其佩戴的徽章来识别：石质代表新手、铁质代表学徒、金质代表老手、绿宝石代表专家、钻石代表大师。村民与玩家交易时会获得经验，其经验条达到满值时会提升一个等级。即使经验值足够提升多个等级，村民也只会在完成交易且关闭交易界面后尝试提升一个等级。<ref></ref>升级时，村民会获得[生命恢复](生命恢复.md)效果，且身边会生成数秒紫色和绿色的[粒子](粒子.md)效果。村民每次升级都会解锁最多2项新交易，同时保留其原有的交易。

每项交易选项有次数限制，完成某项交易的次数达到限制时，村民会暂时停用这项交易，此时交易界面会出现一个红色的“×”。每项交易的次数限制不同（见下表）。在村民回到其[工作站点方块](工作站点方块.md)补货后，被停用的选项会恢复交易，每项交易每天最多恢复2次。

每次村民交易都会给予玩家，当村民有[繁殖](繁殖.md)意愿时则给予玩家。[流浪商人](流浪商人.md)交易时，玩家也会获得一些经验。

每个村民最多有10个交易选项。每次升级村民就会解锁最多2项新交易。若所达到的等级有2个以上的可解锁交易，则村民会从中随机解锁2个交易。

# = 交易展示 =
[缩略图|几个村民向玩家展示交易物品](File:VillagerOfferingItems.jpg.md)
在未发生[袭击](袭击.md)的情况下，当玩家手持物品走到村民附近时，该村民也会手持自己希望和玩家进行交易的物品。例如，一个农民想要以1个绿宝石换20个[小麦](小麦.md)，且玩家手持小麦，则该农民就会手持绿宝石。如果村民对玩家的物品有不止一个交易，村民会根据自己的交易项目，每几秒更换一次手上的物品。这使玩家更容易地分辨出哪一个村民会提供哪一种交易，然而玩家仍需要打开交易界面来参考完整的交易信息。

# == 傻子 ==

傻子是穿着绿色袍子的村民。自然生成以及刷怪蛋生成的傻子不会提供任何交易。与失业村民不同的是，傻子不能获得以及改变职业。

# == 失业 ==

没有穿着职业着装，只有对应生物群系的衣服的村民为失业村民，它们无法进行交易。

失业村民可以通过靠近并绑定[工作站点方块](工作站点方块.md)来获得职业。

# == 幼年 ==
幼年村民的外观和对应的成年失业村民一致，但体型较小。其无法获得职业并进行交易。

# 你知道吗
* 可以使用特定命令生成能够提供自定义交易的村民。
* * 如果自定义交易的村民是傻子或失业村民，那么这些交易能够正常进行，但不会给予村民经验值；失业村民也会在认领工作站点后使用对应职业的新手交易替换掉自定义交易。
* 供需关系中的需求（Demand）可以小于0并继续不断变小，因此长期不交易的选项很难涨价（即需要大量的交易才能使为负且绝对值很大的需求大于0）。
* 愚人节快照[25w14craftmine](25w14craftmine.md)中加入了[叛徒](叛徒.md)（Traitor）职业，出售一部分[矿境效果](矿境效果.md)。
