# Java版Beta 1.9-pre3

*页面ID: 32285* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.9-pre3**是[Java版1.0.0](Java版1.0.0.md)的第3个预发布版，发布于2011年10月6日，加入了[附魔台](附魔台.md)、[酿造台](酿造台.md)和幼年动物，改进了酿造系统，并修复了一个漏洞。

# 新内容
# = 方块 =
* *[炼药锅](炼药锅.md)**
* 拥有了方块ID，但它只能装水，而不是用于制作药水。

* *[附魔台](附魔台.md)**
* 用于[附魔系统](附魔机制.md)。

* *[末地传送门框架](末地传送门框架.md)**
* 暂无用途。
* 没有正式名称。

* *[末地传送门方块](末地传送门方块.md)**
* 暂无用途。
* 由于没有末地传送门方块的名称，所以将鼠标放到上面会使游戏崩溃。

* *[末地石](末地石.md)**
* 加入了未使用的纹理。

* *[酿造台](酿造台.md)**
* 用来酿造药水。
* 酿造时间为30秒。

# = 物品 =
* *[末影之眼](末影之眼.md)**
* 要塞里未完成的[末地传送门](末地传送门.md)。破碎的[末地传送门框架](末地传送门框架.md)方块能够用末影之眼修复，虽然没有事情会进一步发生。

# = 生物 =
* *常规**
* 加入了幼年动物：
* * 幼年鸡
* * 幼年牛
* * 幼年哞菇
* * 幼年猪
* * 幼年绵羊

# = 游戏内容 =
* *[酿造](酿造.md)**
* 完全重做了[药水](药水.md)系统。

* *[附魔](附魔.md)**
* 已附魔的物品会发光，拥有蓝色的[提示框](提示框.md)并且在其上方有“Enchanted!!”字样。

* *[物品修复](物品修复.md)**

# = 常规 =
; [调试屏幕](调试屏幕.md)
* 加入了饼图。

# 更改
# = 方块 =
* *[箱子](箱子.md)**
* [箱子](箱子.md)在地牢里会更多地随机放置。

* *[书架](书架.md)**
* 破坏[书架](书架.md)会掉落3本[书](书.md)。

# = 物品 =
* *[苹果](苹果.md)**
* 现在可在[要塞](要塞.md)走廊的箱子里生成。

# = 游戏内容 =
* *[经验](经验.md)**
* 经验等级会在经验条上方展示。

# = 常规 =
* *[提示框](提示框.md)**
* 稀有物品（金苹果和音乐唱片）的提示框名称现在是品红色的。

* *调试特性**
* 1×1的玻璃柱会从地面伸出到天空，以此定位要塞的位置。

# 修复
* *修复了1个漏洞**
* 修复了雪傀儡可以进入繁殖模式的漏洞。</onlyinclude>
