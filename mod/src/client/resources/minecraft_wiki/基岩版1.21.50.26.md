# 基岩版1.21.50.26

*页面ID: 128223* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.50.26**（ChromeOS/Android）、**Preview 1.21.50.26**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.50](基岩版1.21.50.md)的第5个测试版，发布于2024年10月30日<ref></ref>，调整了一些特性，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 加入了“”子选项。
* * 用于在[附加包](附加包.md)中启用数据驱动拼图结构。

* *[设置](设置.md)**
* 在设置中加入了“”选项。
* * 用于在[创造模式](创造模式.md)下启用[选取方块](选取方块.md)按钮。

* *[粒子](粒子.md)**
* 加入了粒子。

* *[闪烁标语](闪烁标语.md)**
* 为[试玩模式](试玩模式.md)加入了下列闪烁标语：
* * Try before you buy!
* * Try for free
* * The first taste's free
* * Welcome home
* * Dairy and gluten free (trial)
* * Like a demo, but better
* * Try now, stay later

* *[触摸控制](触摸控制.md)**
* 加入了选取方块按钮 [30px|class=pixel-image](File:Pick block BE1.png.md) 。
* * 仅开启“”选项后可用。

# 更改
# = 方块 =
* *[黑石](黑石.md)**
* 现在可用于在[铁砧](铁砧.md)上修复石质工具。

* *[眼眸花](眼眸花.md)**
* 现在会在张开和闭合时发出音效和粒子。
* 现在放置在苍白苔藓块上的张开的眼眸花会发出环境音效。
* 现在可用于喂食[哞菇](哞菇.md)。

* *[苍白苔藓块](苍白苔藓块.md)、[苍白覆地苔藓](苍白覆地苔藓.md)和[苍白垂须](苍白垂须.md)**
* 调整了可燃性。
* * 现在会被更快地引燃，但燃烧时间会更长。
* * 现在可以被[熔岩](熔岩.md)引燃。

* *[苍白橡树树叶](苍白橡树树叶.md)**
* 现在会在下方产生落叶粒子。

* *[树脂团](树脂团.md)**
* 将从嘎枝之心能够蔓延的距离减少1格。
* 现在只能蔓延至[苍白橡木原木](苍白橡木原木.md)、[去皮苍白橡木原木](去皮苍白橡木原木.md)、[](苍白橡木.md)和[去皮苍白橡木](去皮苍白橡木.md)。

* *[树脂砖台阶](树脂砖台阶.md)和[树脂砖墙](树脂砖墙.md)**
* 现在合成时会给予6个。

* *[树脂砖楼梯](树脂砖楼梯.md)**
* 现在合成时会给予4个。

* *[树苗](树苗.md)**
* 现在所有树苗均可穿过[树叶](树叶.md)而生长，但樱花树苗无法穿过樱花树叶而生长。
* 现在所有树苗均可在泥土类方块上生长。

* *[黏液块](黏液块.md)**
* 现在玩家在潜行状态下摔落在其上时不会受到摔落伤害，并能以此阻止继续弹跳。

* *[缠怨藤](缠怨藤.md)和[垂泪藤](垂泪藤.md)**
* 现在使用[藤蔓](藤蔓.md)的音效，而不是[菌索](菌索.md)的音效。<ref></ref>

# = 生物 =
* *[嘎枝](嘎枝.md)**
* 降低了无攻击目标的嘎枝的速度。
* 只有脚部被观察到或脚部位于[灵魂沙](灵魂沙.md)或[泥巴](泥巴.md)上时，嘎枝不再能够移动。
* 现在可以靠近向下看的玩家，只有进入玩家视野内后才会停止追逐。
* 现在被[弹射物](弹射物.md)击中时会摇摆。
* 平滑处理了攻击动画，使其动作更加自然。

* *[流浪商人](流浪商人.md)**
* 现在会出售[苍白橡树树苗](苍白橡树树苗.md)、[张开的眼眸花](张开的眼眸花.md)、[苍白苔藓块](苍白苔藓块.md)和[苍白垂须](苍白垂须.md)。

# = 世界生成 =
* *[苍白之园](苍白之园.md)**
* 现在进入苍白之园时，[音乐](音乐.md)的音量会逐渐降低至0，离开时则会恢复正常。

* *[大型云杉](大型云杉.md)和[大型松树](大型松树.md)**
* 现在在生成时会将下方的[菌丝体](菌丝体.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[泥巴](泥巴.md)和[沾泥的红树根](沾泥的红树根.md)转化为[灰化土](灰化土.md)。

# = 游戏内容 =
* *[声音](声音.md)**
* 将嘎枝的（脚步声）音效的音量由1.0更改为0.8。

# 修复
* *生物群系**
* 为流浪商人的交易项加入了苍白橡树树苗、眼眸花、苍白苔藓块和苍白垂须。（）

* *方块**
* 现在苍白垂须和嘎枝之心环境音效的衰减下降率是线性的，以允许在更远处听到这些音效。（）
* 藤蔓、洞穴藤蔓、缠怨藤和垂泪藤现在会发出正确的音效，而不是下界疣的音效。
* 苍白垂须现在拥有与Java版相同的模型。（）
* 现在放置在世界中和花盆中的眼眸花会在绽开和闭合时发出粒子。
* 现在树脂砖台阶、树脂砖楼梯和树脂砖墙的合成配方会给予与下界砖块相同的方块数量。（、、）
* 生物现在会在树脂团上正确寻路。（）

* *命令**
* 现在与非数字化格式（）相比，带有额外百分号的翻译原始文本不再会为数字化格式（）不一致地进行扩展。（）
* 命令现在会在添加效果后正确在显示消息中以秒为单位显示持续时间。（）

* *地物**
* 统一了树木生长时可替换的方块，但有少数例外。（、）
* * 现在所有树木均可穿过树叶而长成，但樱花树无法穿过樱花树叶而长成。（）
* * 现在所有树木均可在泥土类方块上长成。（）
* 现在高草丛在苍白之园生物群系中会正确生成上半部分。（）
* 现在高草丛在繁茂洞穴生物群系中会正确生成上半部分。（）

* *游戏内容**
* 摔落在黏液块上时按住跳跃键不再会取消弹跳。（）
* 潜行时着陆在黏液块上不再会造成摔落伤害。
* 修复了玩家放置一个方块，然后在服务器处理方块放置前更改其所选的槽位时，方块会放置失败的问题。这种情况会拒绝放置，因为服务器不会预料到槽位会发生更改。（）

* *图形**
* 现在在不同生物群系之间穿梭时，天空颜色会逐渐过渡，而不是突然改变。（）

* *物品**
* 树脂团和树脂砖不再会在第三人称视角下飘浮在玩家手中。
* 现在可以对哞菇使用张开的眼眸花和闭合的眼眸花，以对在挤奶时获得对应的谜之炖菜。（）
* 黑石现在可用于修复石质工具和石质武器。（）

* *生物**
* 驯服的狼的攻击不再能阻止嘎枝攻击玩家。
