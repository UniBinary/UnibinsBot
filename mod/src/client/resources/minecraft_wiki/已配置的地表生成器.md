# 已配置的地表生成器

*页面ID: 96358* | *来源: Minecraft Wiki*

* *已配置的地表生成器（Configured Surface builder）**控制了地形的表面如何生成，以及方块如何生成。它以[JSON](JSON.md)文件的格式存储在[数据包](数据包.md)的{{filepath|-{}-data/<命名空间>/worldgen/configured_surface_builder}}目录下。地表生成器用于[世界生成](世界生成.md)。

# JSON格式
<div class="treeview">
* 根标签
* *：所使用的地表生成器类型。
* *：地表生成器的配置。
* **：海平面上地形最高层所使用的方块。
* ***：所使用的方块的命名空间ID。
* ***：方块状态。
* ****：一个方块状态的键值对。
* **：地形最高层在海平面上时的除顶层外的表面几层和地形最高层在海平面下约10格内时的表面几层所使用的方块。
* ***：所使用的方块的命名空间ID。
* ***：方块状态。
* ****：一个方块状态的键值对。
* **：海平面下约10格外的顶层所使用的方块。
* ***：所使用的方块的命名空间ID。
* ***：方块状态。
* ****：一个方块状态的键值对。
</div>

# 地表生成器类型
地表生成器类型决定了游戏是否进行以及如何进行额外修饰。不论哪种类型，都可能在雕刻器雕刻过的方块上执行<code>top_material</code>字段。

对于类型，海平面下的表面几层始终使用<code>under_material</code>字段的方块，且除<code>nether_forest</code>类型外海平面附近均会随机填充沙砾。

# = 使用config字段的类型 =
* <code>default</code>：默认
* <code>swamp</code>：沼泽
* *若Y=63处为与空气直接接触的地形最高层，则随机替换为维度默认流体。
* <code>frozen_ocean</code>：冻洋
* *随机放置冰山。
* *深水表层为沙砾。
* <code>lofty_peaks</code>：尖峭山峰
* *同<code>default</code>。
* <code>nether</code>：下界
* *海平面附近额外随机填充灵魂沙。
* <code>nether_forest</code>：绯红、诡异森林
* *地形最高层概率生成的方块。
* <code>badlands</code>：恶地
* *海平面上约7格内的区域正常执行<code>top_material</code>。
* *海平面下表面一层使用<code>under_material</code>的方块。
* *海平面下除表层的几层和其他区域随机填充各种陶瓦。
* <code>wooded_badlands</code>：疏林恶地
* *与<code>badlands</code>相比：
* **约Y>100的地形最高层随机填充砂土和草方块。
* <code>eroded_badlands</code>：风蚀恶地
* *与<code>badlands</code>相比：
* **随机放置陶瓦岩柱。
* <code>nope</code>：无
* *什么都不执行。

# = 不使用config字段的类型 =
下列类型类似随机选择配置，无视<code>config</code>字段。
* <code>mountain</code>：山地
* <code>shattered_savanna</code>：破碎的热带草原
* <code>gravelly_mountain</code>：风袭沙砾丘陵
* <code>giant_tree_taiga</code>：原始松木针叶林
* <code>soul_sand_valley</code>：灵魂沙峡谷
* <code>basalt_deltas</code>：玄武岩三角洲
* <code>grove</code>：雪林
* <code>snowcapped_peaks</code>：冰封山峰
* <code>snowy_slopes</code>：积雪山坡
* <code>stone_shore</code>：石岸
* <code>stony_peaks</code>：裸岩山峰

标记为“是”代表此地表生成器可能选择此配置，标记为“否”代表不选择。
