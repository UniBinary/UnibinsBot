* *潜影盒（Shulker Box）**是一种可以储存和[运输](运输.md)物品的[方块](方块.md)。

# 生成
潜影盒不会生成在世界中。

# 破坏
挖掘潜影盒的合适工具是镐。

潜影盒被破坏后会掉落自身，并装着其中的内容物。

被[爆炸](爆炸.md)破坏的潜影盒总是会掉落。

如果潜影盒中存有物品，在创造模式中挖掘破坏潜影盒也会掉落。

# 用途
[thumb|潜影盒的开合动画](File:Shulker Box Opening.gif.md)

潜影盒被放置在方块顶部、侧面或底部时，它的朝向会相应地变为朝上、朝四周或朝下。

世界中的潜影盒可以尝试将其打开。如果或，那么它无法被打开。例如，对于一个朝下放置的潜影盒，若其下方有一个红石导体方块，那么它就不能被打开。

成功打开潜影盒后，其朝向方向的长度会在内逐渐从1格增加至1.5格，每增加0.05格。这会引起其碰撞箱和轮廓箱的变化，推开这些方向上的实体。潜影盒关闭后会以同样的速度在内关闭。

潜影盒在完全关闭时是红石导体，打开后不是红石导体。

潜影盒在完全关闭时是窒息方块，打开后不是窒息方块；潜影盒不是窒息方块。

潜影盒打开时会变为[光照透明方块](亮度#光照透明方块.md)，允许亮度通过潜影盒传播。

可使用[发射器](发射器.md)放置潜影盒。

# = 容器 =
潜影盒有27格储存槽位，和[箱子](箱子.md)相同。在物品栏中，潜影盒的[提示框](提示框.md)包含其内容物的信息。

与其他容器不同的是，潜影盒被破坏时仅掉落自身，内容物仍然装在其中，可以在重新放置潜影盒后查看。若潜影盒的[物品实体](物品实体.md)受到[伤害](伤害.md)而被摧毁，其内容物会以物品实体的形式被释放出来。

潜影盒可储存在其他容器中，但无法储存在其他潜影盒和[收纳袋](收纳袋.md)中。

与其他容器类似，潜影盒可以使用[漏斗](漏斗.md)来移入或移出物品。

[红石比较器](红石比较器.md)能够检测潜影盒存储物品的数量。

潜影盒界面的标题默认为“潜影盒”，可在放置前使用[铁砧](铁砧.md)重命名来进行更改，也可以通过使用命令修改潜影盒的<code>CustomName</code>标签进行更改。

# = 染色与褪色 =
用任意颜色的潜影盒与任意的[染料](染料.md)可以合成与染料同色的潜影盒。

染色的潜影盒能通过[炼药锅](炼药锅.md)洗去其上的颜色，做法是对着一个装有[水](水.md)的炼药锅。这会令炼药锅中的水减少1层，并将潜影盒变回未染色的状态。

# = 猪灵 =
在非和平[难度](难度.md)下，成年[猪灵](猪灵.md)会与附近打开或破坏潜影盒的玩家敌对。<ref></ref>

# 你知道吗
* 当物品栏、快捷栏、副手槽37个格全部用潜影盒填满，并且每个都用堆叠64件的物品填充里面的27格，那么玩家能够持有999组总计63936件的物品。当其中有36个潜影盒和1个末影箱时（且其中同样填满潜影盒），玩家能够持有1701组总计108864件的物品。
* * 若是玩家骑着或牵着装备有箱子的驴或骡，且箱子全部用潜影盒填满时，每只驴或骡能多提供405组共计25920件物品。
* * 若是玩家同时牵着全部由力量值为5、装备着箱子的[羊驼](羊驼.md)组成的驼队，并且箱子全部用潜影盒填满时，每个驼队能多提供4050组总计259200件的物品。
* 如果距离64格外，潜影盒会变得不可见，这不受[视频设置](选项#视频设置.md)中的“渲染距离”和“实体渲染距离”的影响。
* 潜影盒为俯视顺时针旋转打开、逆时针旋转关闭；为俯视逆时针旋转打开、顺时针旋转关闭，且旋转速度在接近打开时变慢，接近关闭时变快。
* 与活塞类似，若任意实体与朝上放置的潜影盒位置重合，则打开潜影盒会将该实体推至潜影盒的顶部。
