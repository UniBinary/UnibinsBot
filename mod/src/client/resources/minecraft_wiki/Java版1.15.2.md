# Java版1.15.2

*页面ID: 51277* | *来源: Minecraft Wiki*

* *1.15.2**是的一次次要更新，发布于2020年1月21日<ref></ref>，加入了2条新的游戏规则和在线游戏的免责声明，并修复了一些漏洞。此版本不兼容1.15和1.15.1的服务端。

# 新内容
# = 命令格式 =
* *[游戏规则](游戏规则.md)**
* <code>doPatrolSpawning</code>
* * 决定[灾厄巡逻队](灾厄巡逻队.md)是否生成。
* * 默认值为。
* <code>doTraderSpawning</code>
* * 决定[流浪商人](流浪商人.md)是否生成。
* * 默认值为。

# = 常规 =
[thumb|点击多人游戏时出现的免责声明](File:Multiplayer disclaimer.png.md)
* *[多人游戏](多人游戏.md)**
* 第一次在[菜单](菜单.md)中点击多人游戏按钮时会出现“在线游戏未分级”的免责声明。

# 更改
# = 方块 =
* *[树苗](树苗.md)**
* 若橡树和白桦树苗水平2格范围内存在[花](花.md)，则该树苗长成的树会有5%的概率悬挂着[蜂巢](蜂巢（方块）.md)。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 蜜蜂不再会在附近的蜂巢或蜂箱被带有[精准采集](精准采集.md)魔咒的工具破坏后被激怒。

* *[马](马.md)**
* 马的[GUI](GUI.md)中的装备槽纹理现在会对应该马当前装备的物品的纹理。

# = 世界生成 =
* *[蜂巢](蜂巢（方块）.md)**
* 现在在[繁花森林](繁花森林.md)生物群系中生成的概率为2%。
* 现在有0.2%的概率在[森林](森林.md)、[繁茂的丘陵](繁茂的丘陵.md)、[桦木森林](桦木森林.md)、[高大桦木森林](高大桦木森林.md)、[桦木森林丘陵](桦木森林丘陵.md)及[高大桦木丘陵](高大桦木丘陵.md)生物群系当中生成。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
* 现在状态效果被更高等级的同类效果覆盖时会被存储。例如，[信标](信标.md)所给予的状态效果只会暂时覆盖较低等级的药水效果，信标效果作用结束后，药水效果会继续产生作用。

# = 常规 =
* *方块模型**
* 加入了模型选项，可以控制方块在GUI中渲染时的光照条件。
* * 如果设置为，则方块模型会被渲染得有一定立体感。
* * 如果设置为，则方块模型的外观会较为扁平。

* *游戏窗口**
* 现在窗口标题会显示类型，如“单人游戏”或“多人游戏”。
* * 它也能确定玩家进入的多人游戏的类型，如“局域网”或“第三方”。
* * 如果标题中的“Minecraft”后接一个星号（*），那么就表明客户端被修改过，客户端JAR文件的签名无效。

* *分析器报告**
* 现在能够捕获有关性能问题的更多信息。<ref name="slicedlime"></ref>

* *纹理**
* 移除了暴击[粒子](粒子.md)右下角的一个孤立像素。
