# 法棍

*页面ID: 138623* | *来源: Minecraft Wiki*

* *法棍（La Baguette）**是一种类似[剑](剑.md)的武器。

# 获取
# = 自动获取 =
在开启规则的瞬间，所有玩家会自动获得一个法棍。

# 用途

法棍的用途与[木剑](木剑.md)基本相同。

# = 近战攻击 =
法棍的攻击速度是1.6，需要来[恢复](近战攻击#攻击冷却.md)。

使用法棍攻击玩家时，被攻击的玩家会恢复。

# = 挖掘工具 =

与剑相同，法棍是一种挖掘工具，每次成功挖掘了任何硬度不为0的方块会消耗2耐久度。
