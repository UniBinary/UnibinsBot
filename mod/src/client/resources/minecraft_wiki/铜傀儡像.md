* *铜傀儡像（Copper Golem Statue）**是一种由[铜傀儡](铜傀儡.md)完全氧化后形成的可[氧化](氧化.md)金属[方块](方块.md)。

# 生成
铜傀儡像不会生成在世界中。

# = 铜傀儡 =
处于氧化阶段且未涂蜡的[铜傀儡](铜傀儡.md)每刻有0.58%的概率完全氧化并转变为氧化的铜傀儡像。若所在位置不为空气，铜傀儡不会尝试转变。转变后，铜傀儡会以随机姿势保持静止，并掉落手持物品，也会保留转变前通过[命名牌](命名牌.md)获得的名字。

# 破坏
挖掘铜傀儡像的合适工具是镐。

铜傀儡像被破坏后会掉落自身。

# 用途
# = 姿势 =
铜傀儡像一共有4种姿势：“站立”“坐下”“奔跑”和“大字”。玩家空手对着铜傀儡像按下键可改变其姿势。

[红石比较器](红石比较器.md)与铜傀儡像连接时会发出红石信号，上述姿势分别对应1-4的信号强度。

# = 氧化 =

铜傀儡像受氧化机制影响，能够在不同变种之间转化。

对未[涂蜡](涂蜡.md)且未氧化的铜傀儡像[斧](斧.md)会生成[铜傀儡](铜傀儡.md)。
