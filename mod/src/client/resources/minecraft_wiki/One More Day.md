# 描述

[File:One more day.ogg](File:One more day.ogg.md)

One More Day是一首缓慢而平静的乐曲，主要由钢琴演奏。中段出现了一些演奏弦乐和辅助旋律的乐器的声音，随后这些声音随着时间推移逐渐消失。
