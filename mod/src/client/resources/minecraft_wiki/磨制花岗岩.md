# 磨制花岗岩

*页面ID: 162922* | *来源: Minecraft Wiki*

* *磨制花岗岩（Polished Granite）**是[花岗岩](花岗岩.md)制作的装饰性方块。

# 生成
# = 自然生成 =
磨制花岗岩会生成在[海底废墟](海底废墟.md)中。

# 破坏
挖掘磨制花岗岩的合适工具是镐。磨制花岗岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

磨制花岗岩被破坏后会掉落自身。
