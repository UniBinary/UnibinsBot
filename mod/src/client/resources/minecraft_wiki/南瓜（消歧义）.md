# 南瓜（消歧义）

*页面ID: 21782* | *来源: Minecraft Wiki*

* *南瓜（Pumpkin）**可以指：

# Minecraft
*  - 一个自然生成或从南瓜种子种植出来的方块。
*  - 用剪刀雕刻-{}-南瓜得到的方块。
*  - 一个可合成的发光方块。
*  - 由南瓜制作的食物。
*  - 用于种植南瓜的物品。
*  - 当在[耕地](耕地.md)上使用南瓜种子时被种在耕地上的方块。
*  - 由南瓜和南瓜灯堆叠而成的地物，生成于针叶林村庄。

# Minecraft Dungeons
# = 物品 =
*  - 一种盔甲，[冷酷战甲](MCD:冷酷战甲.md)的特殊活动变种。
*  - 一种法器，[腐化信标](MCD:腐化信标.md)的独特变种。

# = 关卡 =
*  - 主大陆中的关卡。

# = 生物 =
*  - 已移除的敌对生物。
