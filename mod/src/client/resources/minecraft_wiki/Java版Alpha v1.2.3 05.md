# Java版Alpha v1.2.3 05

*页面ID: 32548* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.2.3_05**是的一次次要更新，发布于2010年11月30日。<ref name="_05"></ref><ref name="TWON"></ref>

# 新内容
* 为[玩家](玩家.md)和[生物](生物.md)加入正确的受伤动画和音效。

# 更改
* 多人服务器的加入屏幕现在会记录最后输入的IP。
* [苦力怕](苦力怕.md)爆炸前会有动画播放。
* 提高了[服务器](服务器.md)上的区块保存频率。
* 现在可以看见[潜行](潜行.md)的玩家了。潜行的玩家的名字不再可以被透过墙看见，并在更短的距离内才可见。
* [按钮](按钮.md)、[拉杆](拉杆.md)和[压力板](压力板.md)被激活时有了正确的动画。

# 修复
* *修复了8个漏洞**
* 离开潜行模式时，不再播放在潜行时静音而在走路时播放的所有声音。
* 剑以及其他武器现在可以正确产生伤害。
* 修复了死亡玩家登录后不可见的漏洞。
* 使得箭矢可见，并且可以造成伤害。
* 不再有无限的免费箭矢。
* 锄现在可以产生正确的种子。
* 服务器日志现在是追加到<code>server.log</code>的末尾，而不是覆盖它。
* 修复了骑乘矿车和猪时，可以获得两倍移动速度的漏洞。</onlyinclude>

# 你知道吗
* 该版本在Notch的博文中被称为“Alpha v1.2.4”<ref name="TWON"/>，这也是该版本下一个版本是[Alpha v1.2.4_01](Java版Alpha v1.2.4_01.md)而非Alpha v1.2.4的原因。游戏内名称为“Alpha v1.2.4”的版本并不存在。
