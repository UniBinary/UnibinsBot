# 奶桶

*页面ID: 6631* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *奶桶（Milk Bucket）**是一种从[牛](牛.md)、[山羊](山羊.md)或[哞菇](哞菇.md)处获得的桶装可饮用[物品](物品.md)。

# 获取
# = 挤奶 =
奶桶能通过对着[牛](牛.md)、[哞菇](哞菇.md)或[山羊](山羊.md)[铁桶](铁桶.md)来收集。

# = 生物掉落物 =
若[流浪商人](流浪商人.md)在喝奶时被击杀，则它有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落奶桶。

# = 箱子战利品 =

# 用途
奶桶就能饮用奶，无论玩家的饥饿值是否已满。奶桶被饮用后会变成[空桶](空桶.md)。

成功饮用后，[玩家](玩家.md)身上所有的[状态效果](状态效果.md)会解除，包括由[信标](信标.md)、[潮涌核心](潮涌核心.md)、[海豚](海豚.md)、[远古守卫者](远古守卫者.md)、[幽匿尖啸体](幽匿尖啸体.md)和[监守者](监守者.md)造成的区域性状态效果以及[不祥之兆](不祥之兆.md)、[袭击之兆](袭击之兆.md)、[试炼之兆](试炼之兆.md)和[村庄英雄](村庄英雄.md)几种与不祥事件相关的状态效果。但是处在造成效果的区域内饮奶的情况下，对应的状态效果可能在去除后会被重新赋予。
