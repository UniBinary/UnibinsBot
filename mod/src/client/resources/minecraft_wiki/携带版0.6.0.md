* *v0.6.0 alpha**是[携带版](携带版.md)的一次主要更新，发布于2013年1月30日。加入了幼年[动物](动物.md)、[云](云.md)、新的[下界](下界.md)相关方块与物品，并修复了一些漏洞。

此次更新之后，游戏不再支持Android 2.1和2.2，需要Android 2.3或更高的系统版本。

# 新内容
# = 方块 =
* *[下界岩](下界岩.md)**
* 类似石头的方块，通过激活[下界反应器](下界反应器.md)生成。

* *[下界砖块](下界砖块.md)**
* 通过[下界砖](下界砖.md)合成的装饰性方块。

* *[石英块](石英块.md)**
* 通过[下界石英](下界石英.md)合成的装饰性方块。

* *[雕纹石英块](雕纹石英块.md)**
* 无法在生存模式中获得。

* *[石英柱](石英柱.md)**
* 无法在生存模式中获得。

* *[裂纹石砖](裂纹石砖.md)**
* 无法在生存模式中获得。

* *[苔石砖](苔石砖.md)**
* 无法在生存模式中获得。

* *[切石机](切石机（MATTIS）.md)**
* 用于合成与石头相关的方块。

* *[雕纹砂岩](雕纹砂岩.md)**
* 砂岩的装饰性变种，可以通过切石机由砂岩合成。

* *[平滑砂岩](平滑砂岩.md)**
* 砂岩的装饰性变种，可以通过切石机由砂岩台阶合成。

* *楼梯**
* [下界砖楼梯](下界砖楼梯.md)
* * 不阻挡光线。
* [砂岩楼梯](砂岩楼梯.md)
* * 不阻挡光线。
* [石砖楼梯](石砖楼梯.md)
* * 不阻挡光线。
* [石英楼梯](石英楼梯.md)
* * 不阻挡光线。

* *[石砖台阶](石砖台阶.md)**
* 使用石砖合成。

# = 物品 =
* *[盔甲](盔甲.md)**
* 为玩家提供不同级别的保护以免受到伤害的物品。
* 包括五种不同品质的[头盔](头盔.md)、[胸甲](胸甲.md)、[护腿](护腿.md)和[靴子](靴子.md)。
* 皮革、铁、钻石和金质的盔甲都可以用各自的材料制作。锁链盔甲无法正常获得。
* 穿戴过程和烧炼相似：在左边选择盔甲，在右边会显示玩家穿戴盔甲的模样。

* *[下界砖](下界砖.md)**
* 由下界岩[烧炼](烧炼.md)而成，可[合成](合成.md)为[下界砖块](下界砖块.md)。

* *[下界石英](下界石英.md)**
* 平滑的白色矿物，通过激活[下界反应器](下界反应器.md)获得。

# = 游戏内容 =
* *[云](云.md)**
* 目前还是二维的平面图形。
* 在启用“Fancy graphics”（精美图像）时才会显示。

# 更改
# = 方块 =
* *[工作台](工作台.md)**
* 无法再使用其合成以下方块：
* * [石台阶](石台阶.md)
* * [圆石台阶](圆石台阶.md)
* * [圆石楼梯](圆石楼梯.md)
* * [石砖](石砖.md)
* * [砂岩](砂岩.md)
* * [砖块](砖块.md)
* * [砖块](砖块.md)
* * [砖楼梯](砖楼梯.md)

* *[台阶](台阶.md)**
* [台阶](台阶.md)的合成配方从获得3个改为6个了。
* 现在可向下放置（小屏幕设备需要测试）。

* *[楼梯](楼梯.md)**
* 现在可以上下颠倒放置。
* 现在可以作为拐角连接相邻的楼梯。

* *[西瓜](西瓜.md)**
* 现在可以用9个[西瓜片](西瓜片.md)合成了。

* *[沙子](沙子.md)**
* 现在受重力影响。

* *[沙砾](沙砾.md)**
* 现在受重力影响。
* 在生成时，如果其下方生成的是空气，则会直接下落。

* *[告示牌](告示牌.md)**
* 在生存和创造模式中都可以获得了。

* *[砂岩台阶](砂岩台阶.md)**
* 在生存和创造模式中都可以获得了。

# = 物品 =
* *[皮革](皮革.md)**
* 现在可以在生存模式中获得了。

# = 生物 =
* *[绵羊](绵羊.md)**
* 可以使用[染料](染料.md)染色了。
* 模型从[32px](File:White Sheep BE1.png.md)更改为[32px](File:White Sheep BE2.png.md).

* *[牛](牛.md)**
* 现在[牛](牛.md)被击杀时会掉落[皮革](皮革.md)了。

* *幼年[动物](动物.md)**
* 可以自然生成了，但是只在新的世界生成。

# = 世界生成 =
* *[下界塔](下界塔.md)**
* [下界塔](下界塔.md)现在由[下界岩](下界岩.md)构成，而不是[黑曜石](黑曜石.md)。
* 下界塔现在会生成更多物品了。

# = 游戏内容 =
* 在一些特定的Android设备上，返回暂停菜单的图标是（◀）而非（|=|）。

* *[雾](雾.md)**
* 现在是更鲜艳的蓝色而非原先的蓝灰色。
* 如果启用了精美图形，可以透过雾看到天空了。

* *[快捷栏](快捷栏.md)**
* 当按住快捷栏的一个格子时把物品扔出时，物品格的边框也会变绿。

* *方向键**
* 按钮现在有纹理并且不再圆润了。
* 当玩家飞行时，跳跃键的图标会变成“翅膀”。
* 当上键被按住时，左、右及下键的纹理会变淡，同时会显示左上及右上的两个按键。

* *[下界反应器](下界反应器.md)**
* 用[下界岩](下界岩.md)代替构成[下界塔](下界塔.md)的[黑曜石](黑曜石.md)。
* 现在可以在其生成周期中额外生成[下界石英](下界石英.md)。

* *[创造模式物品栏](创造模式物品栏.md)**
* 新增：

* * [下界砖楼梯](下界砖楼梯.md)
* * [石英楼梯](石英楼梯.md)
* * [砂岩台阶](砂岩台阶.md)
* * [石砖台阶](石砖台阶.md)
* * [石英块](石英块.md)
