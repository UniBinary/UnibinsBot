# 混凝土

* *混凝土（Concrete）**是有16种颜色的固体方块。

# 生成
# = 自然生成 =
红色混凝土和白色混凝土会自然生成在[试炼密室](试炼密室.md)中。

# = 混凝土粉末 =

[混凝土粉末](混凝土粉末.md)与[水](水.md)接触就会固化成混凝土方块，即便其仍在下落。[降雨](降雨.md)、[炼药锅](炼药锅.md)、[喷溅型水瓶](喷溅型水瓶.md)和[粒子](粒子.md)不会影响混凝土粉末。

# 获取
混凝土只能通过破坏混凝土获得。

# 破坏
挖掘混凝土的合适工具是镐。混凝土需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

混凝土被破坏后会掉落自身。

# 用途
混凝土明亮而纯净的色彩适合用于装饰与建筑用途。混凝土的颜色比染色的[陶瓦](陶瓦.md)更为浓厚，同时混凝土又不像[羊毛](羊毛.md)一样易燃。

在稳固性方面，混凝土的[硬度](硬度.md)比石头稍高，但其[爆炸抗性](爆炸抗性.md)比石头低得多。
