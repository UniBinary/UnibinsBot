# Java版1.14.3-pre1

*页面ID: 43966* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14.3-pre1**是[Java版1.14.3](Java版1.14.3.md)的首个预发布版，发布于2019年6月3日<ref></ref>，略微修改了村民的特性，优化了性能，并修复了一些漏洞。

# 更改
# = 生物 =
* *[村民](村民.md)**
* 慌张的村民现在有更高的概率生成[铁傀儡](铁傀儡.md)。
* 农民村民现在工作时会花更多时间在耕种上。
* 农民村民现在总是会给予食物，即使其他村民并不一定需要。

# = 常规 =
* *性能**
* 性能改进。
