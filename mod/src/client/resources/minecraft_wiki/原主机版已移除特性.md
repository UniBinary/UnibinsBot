# 原主机版已移除特性

*页面ID: 20916* | *来源: Minecraft Wiki*

本页面记录了所有从[原主机版](原主机版.md)中移除的特性。这些特性可能已被替换，或者开发者可能已经决定重新加入该特性。

请注意此页面只记录被移除的特性；被移除的特定游戏元素的特性在该元素的历史中被注明。有一些特性是在原主机版中意外添加的，但这些功能在不久之后就被移除了。

# 生物群系
[缩略图](File:Rainforest.jpg.md)
[缩略图](File:SeasonalForest.jpg.md)

在，地形生成器被重设，导致雨林、季节性森林、草原、灌木林和苔原生物群系被移除。雨林和季节性森林实际上一样，所以它们合并为现在的森林。

# 环境
# = 虚空 =
因为基岩变得不可破坏，虚空于TU5被移除。游戏中有一个漏洞允许玩家在虚空建造，而且就像在视频中看到的，基岩下方的虚空不再是黑色的。<ref>https://m.youtube.com/watch?v=wG3jYHOK_Sc</ref>
