# 失活的珊瑚扇

*页面ID: 163001* | *来源: Minecraft Wiki*

* *失活的珊瑚扇（Dead Coral Fan）**是一种由[珊瑚扇](珊瑚扇.md)转变的装饰性方块。

# 生成
# = 自然生成 =
失活的珊瑚扇会自然生成在[珊瑚礁](结构#珊瑚礁.md)结构中。

# = 珊瑚扇 =
如果珊瑚扇没有接触[水](水.md)，其会在60-99[游戏刻](游戏刻.md)后变成对应失活的珊瑚扇。

如果珊瑚扇没有放置在水源中，其会立刻变成对应失活的珊瑚扇。

# 获取
失活的珊瑚扇只能通过破坏失活的珊瑚扇获得。

# 破坏
失活的珊瑚扇被挖掘时会立刻被破坏。

失活的珊瑚扇需要木镐或品质更好的镐来挖掘，否则不会掉落。<ref></ref>

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，失活的珊瑚扇被破坏后不会掉落。

被具有精准采集的工具挖掘破坏时，失活的珊瑚扇被破坏后会掉落自身。

# 用途
# = 放置 =
失活的珊瑚扇可以放置在方块的侧面和顶部，但不能放置在底部。
