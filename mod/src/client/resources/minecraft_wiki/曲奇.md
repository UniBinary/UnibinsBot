# 曲奇

*页面ID: 6635* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *曲奇（Cookie）**是一种恢复较少[饥饿值](饥饿值.md)和[饱和度](饱和度.md)的[食物](食物.md)类物品。

# 获取
# = 交易 =

# = 礼物 =

[农民](农民.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷曲奇。

# = 合成 =

# 用途
# = 食物 =

手持曲奇按住键即可食用，每个曲奇可以回复。

# = 鹦鹉 =
给[鹦鹉](鹦鹉.md)喂食曲奇会使其获得的[中毒](中毒.md)效果并受到3.4×10<sup>38</sup>（ × 1.7×10<sup>38</sup>）伤害。

给鹦鹉喂食曲奇会使其获得的[中毒（致命）](中毒（致命）.md)效果。

# = 堆肥 =
将曲奇放入[堆肥桶](堆肥桶.md)中会有85%的概率增加一层堆肥层。

# 你知道吗
* 游戏中[鹦鹉](鹦鹉.md)食用含有可可豆的曲奇会中-{}-毒死亡的特性参考自现实。在现实中，可可豆中含有的[可可碱](wzh:可可碱.md)对鹦鹉有较强的毒性。
* 由于2个[小麦](小麦.md)和1个[可可豆](可可豆.md)即可合成8个曲奇，并且曲奇成功增加堆肥层数的概率较高（85%），将小麦和可可豆合成为曲奇再堆肥获得的骨粉数是分开堆肥的约3.5倍。
