* *1.7**是[Java版1.7.2](Java版1.7.2.md)的首个预发布版，发布于2013年10月23日<ref></ref>，加入了金合欢和深色橡树对应的楼梯和台阶，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[楼梯](楼梯.md)**
* 金合欢楼梯
* 深色橡木楼梯

* *[台阶](台阶.md)**
* 金合欢台阶
* 深色橡木台阶

# 更改
# = 方块 =
* *[奖励箱](奖励箱.md)**
* 向奖励箱的战利品表加入金合欢木。

* *[原木](原木.md)**
* 木头的顶部和底部现在具有不同的纹理（橡木除外）。

* *[树苗](树苗.md)**
* 2×2的云杉[树苗](树苗.md)现在能长成大云杉树。

# = 生物 =
* *[蜘蛛](蜘蛛.md)**
* 现在被创造模式下的玩家攻击时不会被激怒。

# = 世界生成 =
* *[深色橡树](树.md)**
* 有顶盖的橡木现在被重命名为“深色橡木”。

# = 常规 =
* *[音效](音效.md)**
* 游戏暂停时音乐也会暂停。
