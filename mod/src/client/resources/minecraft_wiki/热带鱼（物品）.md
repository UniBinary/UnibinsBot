# 热带鱼（物品）

*页面ID: 35843* | *来源: Minecraft Wiki*

* *热带鱼（Tropical Fish）**是一种食物。

# 获取
# = 钓鱼 =
热带鱼可以在[钓鱼](钓鱼.md)时作为[鱼](钓鱼#垃圾与宝藏.md)被钓上来。钓上热带鱼的概率会随着[海之眷顾](海之眷顾.md)魔咒的等级减少。

# = 生物掉落物 =

# 用途
# = 食物 =

手持热带鱼按住键即可食用，每个热带鱼可以回复。

# = 交易 =

# = 狼 =
热带鱼可用于给[狼](狼.md)回复的生命值。然而和其他狼可以吃的食物不同，热带鱼不能用于繁殖或者加快幼年狼的生长，因此只能在狼未处于满血状态下食用。

# = 鹦鹉螺和殭屍鸚鵡螺 =
热带鱼可用于喂食驯服的[鹦鹉螺](鹦鹉螺.md)和[殭屍鸚鵡螺](殭屍鸚鵡螺.md)，使生命值已满的成年鹦鹉螺进入繁殖模式，治疗生命值未满的成年鹦鹉螺和殭屍鸚鵡螺的生命值，加速幼年鹦鹉螺约10%的成长时间。
