# Java版Indev 0.31 20091223-1457

*页面ID: 171683* | *来源: Minecraft Wiki*

<onlyinclude>
* *0.31**的一个版本发布于2009年12月23日14:57（UTC），加入了[火把](火把.md)。<ref></ref>

# 新内容
# = 方块 =
* *[火把](火把.md)**<ref name="torches">[minecraft.20091222的IRC记录](#logs.md): "(09:00:31) <Iguana> What's in the new update? "..." (09:01:10) <08Notch> torches"</ref>
* 一种装饰性方块。
* 不会自然生成在世界中。
* 可以提供光照。

# 更改
# = 方块 =
* *[草方块](草方块.md)**
* 现在在光线稍暗的地方也可以蔓延。

* *[树苗](树苗.md)**
* 现在在较暗处不会消失。

* *[水](水.md)**
* 更改了侧面纹理。
* * 现在有竖直的线条向下流动。

* *[树叶](树叶.md)**
* 现在会产生阴影。
* * 正因如此，树附近的草方块会变成[泥土](泥土.md)。</onlyinclude>
