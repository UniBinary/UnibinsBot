# 2023年生物投票服务器活动

*页面ID: 106138* | *来源: Minecraft Wiki*

* *2023年生物投票服务器活动（Mob Vote 2023 Server Event）**是作为[Minecraft Live 2023](Minecraft Live 2023.md)活动一部分的限时开放的官方[活动服务器](活动服务器.md)，玩家可以在服务器中参与一年一度的生物投票。<ref name="minecraft-live-2023-announcement"></ref>

# 描述
服务器包含“投票岛”（Voting Island）和“冒险群岛”（Adventure Isles）两个[世界](世界.md)。玩家可在警戒浮标围着的区域内活动，位于警戒线外的玩家会在8秒后被传送回出生点。

世界中的方块和NPC外观皆为生物投票视频中的风格，每个NPC名称都带“小”（Tiny）字前缀。

在Minecraft Live 2023播出前，玩家的屏幕右上方会显示Minecraft Live 2023倒计时和当前投票支持的生物；在开始直播后，玩家的屏幕右上方会显示Minecraft Live 2023的链接；直播结束后，当时投票支持的生物图标会变为获胜的生物图标。

走至可交互区域时，屏幕左方会播放小Jens的来电动画，并出现一段介绍文字。

玩家的屏幕顶部会显示当前的生物搜寻进度和拥有的“绿宝石券”（Emerald Ticket）数量。
* 9只在往届生物投票或生物群系选举/投票中落选的生物，其2D形象隐藏于服务器世界的各个角落。每找到一只可获得15绿宝石券。可以在[生物博物馆](#生物博物馆.md)中查看提示和是否找到。
* 绿宝石券可通过接触券箱、射击不断刷新的苦力怕气球和游玩小游戏获得，用于兑换商品。

# 投票岛
[thumb|螃蟹、企鹅和犰狳雕像](File:2023 Mob Vote Server Spawn.jpg.md)
投票岛的中心有浮空的生物投票徽标和3个巨大的候选生物雕像。

雕像内部为对应生物群系主题的跑酷游戏场地。终点设在雕像的顶端，每个雕像顶端各有一个供玩家远眺的观察点。

# = 投票广场 =
玩家可在生物雕像正前方的投票广场参与[2023年生物投票](Minecraft Live 2023#生物投票.md)。拉下对应拉杆即可确定投票对象，票选对象可以更改。

Minecraft Live 2023播出15分钟后，投票将被封锁，玩家无法再参与投票，并会在直播过程中实时显示生物投票淘汰状况。

# = 过山车 =
过山车（Rollercoaster）的起点位于投票广场右边，玩家可乘坐矿车环岛观光。

# = 螃蟹跑酷 =

“螃蟹跑酷”（Crab Parkour）是一个低难度的计时跑酷区域，途经7个记录点。每次完成奖励10绿宝石券。

# = 企鹅跑酷 =
“企鹅跑酷”（Penguin Parkour）是一个高难度的计时跑酷区域，途经4个记录点。每次完成奖励40绿宝石券。

# = 犰狳跑酷 =
“犰狳跑酷”（Armadillo Parkour）是一个中等难度的计时跑酷区域，途经5个记录点。每次完成奖励20绿宝石券。

# = 山地跑酷 =
“山地跑酷”（Mountain Parkour）是出生点右侧的一个中等难度的计时跑酷区域，途经3个记录点。每次完成奖励20绿宝石券。

# = 生物水立方 =

“生物水立方”（Mob Drop）是位于出生点上方的计时坠落游戏，要求玩家躲避障碍物（如[蜂蜜块](蜂蜜块.md)和[灵魂沙](灵魂沙.md)）尽快地从高空落到最底端的水池。每次完成奖励10绿宝石券。

# = 生物打地鼠 =

[thumb|生物打地鼠](File:MV2023-WAM.jpg.md)
“生物打地鼠”（Whack-a-Mob）是螃蟹雕像前的排队游玩项目。玩家需要在竞技场内留意特定刷怪点出现的小怪物，用锤敲击它们来赚取积分。

每局游戏持续40秒，允许多名玩家进入场地比拼。最终积分越高，奖励的绿宝石券就越多。

玩家也可以站在竞技场四周的观察点上观战。

# = 平顶山峭壁 =
[thumb|平顶山峭壁](File:MV2023-MesaCliff.jpg.md)

# = 红树林迷宫 =
“红树林迷宫”（Mangrove Maze）是螃蟹雕像后的双层石砖迷宫，围墙的顶端缠绕着一些[红树根](红树根.md)。玩家进入迷宫后，相机视角会变为鸟瞰。抵达迷宫中央的玩家可领取25绿宝石券。

# = 灯塔 =
[thumb|在灯塔上用望远镜眺望玩家的小Jens](File:MV2023-Lighthouse.jpg.md)

灯塔是小Jens与玩家通话时所处的位置，位于投票岛边界的一处陡崖上。食用至少2个棉花糖悦灵后能飘浮至灯塔顶端，与小Jens对话可获得一个[32px](File:Spyglass Mob Vote Server.png.md) [望远镜](望远镜.md)。

# = 码头 =
[thumb|码头](File:MV2023-Dock.jpg.md)

码头有一艘出现于2023年生物投票视频的帆船。与码头的小Lydia对话可以前往冒险群岛，到达后再次对话可以返航。

# 冒险群岛
[thumb|俯瞰冒险群岛](File:MV2023-Isles.jpg.md)

[thumb|生物博物馆外观](File:MV2023-CherryHouse.jpg.md)

“冒险群岛”包括樱花树林主岛、丛林岛、针叶林岛和蘑菇岛。码头处有生物投票区。

樱花树林主岛上有两栋房屋，正门分别通往“隐匿处”和“生物博物馆”。后者的外观与[足迹与故事官方预告片](https://www.youtube.com/watch?v=Rla3FUlxJdE)里的房屋相似。

# = 隐匿处 =

隐匿处（Hideout）位于一个大型洞穴中，有一处连接生物博物馆地下室的暗门；还有一扇实体仿制的[雕纹书架](雕纹书架.md)活塞门，往里面走可以找到小灾厄村民。

# = 生物派对 =
[thumb|生物派对](File:MV2023-MobParty.jpg.md)

“生物派对”（Mob Party）是隐匿处旁边的一个排队游玩项目，类似于“色盲派对”小游戏。玩家需记下九宫格内出示的生物，在系统指定某一生物后站在正确的一格上，否则会掉入熔岩湖中直接被淘汰。

每局游戏总共有6个回合，允许多名玩家进入场地游玩。每一回合会新增一种生物来增加难度。成功的回合越多，奖励的绿宝石券就越多。

# = 硬核跑酷 =
“硬核跑酷”（Hardcore Parkour）是“生物派对”旁边的一个高难度的计时跑酷区域，途中没有记录点。每次完成奖励80绿宝石券。

# 奖励
进入服务器后可获得[角色创建器](角色创建器.md)物品“樱花披风”（Cherry Cape）。

找到所有9种隐藏生物后可获得“生物投票高帽”（Mob Vote Top Hat）。
