# Library更新

*页面ID: 126020* | *来源: Minecraft Wiki*

[缩略图|Library更新的更新横幅](File:Library Update Banner.png.md)

* *Library更新（Library Release）**是的一次次要更新，其正式版[1.12.5](教育版1.12.5.md)发布于2019年11月12日。<ref name=release></ref><ref>https://education.minecraft.net/en-us/blog/the-library-update-is-now-available-for-minecraft-education-edition</ref>

# 重要特性

* *Library**
* 经用户的反馈，更新了Library菜单。可将课程内容引入游戏中，提供课程的计划及分类，以简化课程、世界、建筑挑战和教程。

* *演示课程**
* 为没有Office 365教育版账号的使用者加入了演示模式。
* 拥有Office 365教育版账号的使用者可以在world library中存取演示课程中的世界。

# 跟进版本
* [1.12.60](教育版1.12.60.md)发布以修复一些漏洞。
