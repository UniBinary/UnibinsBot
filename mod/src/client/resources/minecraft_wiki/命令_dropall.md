# 命令/dropall

*页面ID: 56596* | *来源: Minecraft Wiki*

让智能体在指定的方向上掉落所有的掉落物。

# 语法
   <code>-{}-dropall <*方向：字符串*></code>

# 参数
<code>-{}-*方向：字符串*</code>
   必须为以下之一：
  * <code>forward</code>——向前掉落。
  * <code>back</code>——向后掉落。
  * <code>left</code>——向左掉落。
  * <code>right</code>——向右掉落。
