# 基岩版开发者命令

*页面ID: 40108* | *来源: Minecraft Wiki*

* *开发者命令（Developer Commands）**一般情况下仅在游戏的开发和测试环境下才能被启用，在正式版本中玩家通常无法看见并执行这些命令。然而，在iOS平台的中，这些命令被意外地保留了下来，随后在中被移除。<ref></ref><ref>https://feedback.minecraft.net/hc/en-us/articles/360004167311-Minecraft-1-2-14-iOS-Only-</ref>

# 使用方法
开发者命令的执行方法与普通命令的执行方法相同，但在聊天屏幕中显示的提示里，这些命令大多标为天蓝色，且未标记其用途。
