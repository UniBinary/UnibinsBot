* *探险更新（Exploration Update）**是[Java版](Java版.md)的一次主要更新，发布于2016年11月14日。此次更新的名称于2016年9月24日在[MINECON 2016](MINECON 2016.md)开幕式上公布。<ref></ref>

此次更新的开发始于[16w32a](16w32a.md)，其发布于2016年8月10日。

# 重要特性

# = 新内容 =
* 3个新的[闪烁标语](闪烁标语.md)。
* 新的[村民](村民.md)职业：
* * 制图师
* * 傻子
* 新的粒子效果：<code>spit</code>和<code>totem</code>。
* 新的NBT标签：
* * <code>LocName</code>，<code>CustomPotionColor</code>和<code>ColorMap</code>。
* 新的游戏规则：<code>doWeatherCycle</code>和<code>maxEntityCramming</code>。
* 新命令：。
* 诅咒类[魔咒](魔咒.md)（绑定诅咒和消失诅咒）。
* 新生物：
* * [卫道士](卫道士.md)，[唤魔者](唤魔者.md)，[恼鬼](恼鬼.md)和[羊驼](羊驼.md)。
* 新方块：[侦测器](侦测器.md)和[潜影盒](潜影盒.md)。
* 8种新的刷怪蛋。<!-- only counting the mobs that previously did not have spawn eggs, not the new mobs that were added -->
* 4种新物品：
* * [潜影壳](潜影壳.md)，[不死图腾](不死图腾.md)以及两种[探险家地图](探险家地图.md)。
* [林地府邸](林地府邸.md)

# = 更改 =
* 实体ID、方块ID、方块实体ID和物品ID不再区分大小写。另外，一些名字被下划线或被完全重写。
* 大量关于NBT标签的更改内容。
* 聊天消息现在最多支持256个字符。
* 一些木质物品，如告示牌、木门等，现在可以当做熔炉里的燃料使用了。
* 盾牌现在在近战中防御100%的伤害。

# 跟进版本
* [Java版1.11.1](Java版1.11.1.md)加入了[铁粒](铁粒.md)和横扫之刃魔咒，并修复了很多漏洞。
* [Java版1.11.2](Java版1.11.2.md)又随后发布，修复了一个关于[鸡骑士](鸡骑士.md)的崩溃。
