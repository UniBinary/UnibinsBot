# = 眼睛 =
所有眼睛的稀有度都为“普通”，并且全部已经免费解锁。

# = 嘴部 =
所有嘴部的稀有度都为“普通”，并且全部已经免费解锁。

# = 胡子 =

# = 手臂 =
左右两侧不可单独装备手臂，当右侧手臂为空时，左侧手臂会镜像装备到右侧手臂（以前装备过单侧手臂的角色，会在打开角色创建器编辑手臂时显示之前装备过的左侧手臂为装备状态，但是在角色的预览和实际游戏中均显示为默认手臂）。

# = 腿部 =
左右两侧不可单独装备腿部，当右侧腿部为空时，左侧手臂会镜像装备到右侧腿部（以前装备过单侧腿部的角色，会在打开角色创建器编辑腿部时显示之前装备过的左侧腿部为装备状态，但是在角色的预览和实际游戏中均显示为默认腿部）。
