# MINECON 2011

*页面ID: 36342* | *来源: Minecraft Wiki*

[缩略图|200px|MineCon 2011预告片截图](File:Minecon11trailer.png.md)

* *MINECON 2011**于2011年11月18日在美国内华达州拉斯维加斯市的曼德勒海湾举行，恰好与正式版游戏的发布日期契合。<ref></ref>

本次MINECON包含了很多激动人心的项目，如Minecraft的发布仪式、Minecraft团队成员的主题演讲（Notch也做了一篇演讲）、建筑比赛、Minecraft不同主题的课程、Cosplay大赛、展览、与世界各地的Minecraft爱好者交流和纪念商品等等。

总计超过4500人参加了2011年的MINECON盛会，参与人遍及24个国家，年龄从新生儿至105岁高龄不等。活动以开幕派对为伊始，所有人均可参加；以及下界派对，邀请到了[Deadmau5](wzh:电子鼠 (DJ).md)，只允许21岁以上的参与者出席。

# 地点
曼德勒海湾度假区

地-{}-址：内华达州，拉斯维加斯市，南拉斯维加斯大道3950号

# 门票
MINECON的门票于其举办日期11月18日前的99天，亦即2011年8月11日开始发售。首批票价定为99美元并发售至9月30日。在此之后票价升至139美元（其中包括门票），然而在10月28日门票已然售罄<ref>http://mojang.com/2011/10/28/minecon-is-sold-out/</ref>。其中门票价格不包括宾馆住宿、往返机票以及任何在MineCon中的额外开销。在门票开始销售的日期，Notch在推特上发表了这样的意见：“无论我们销售多少门票，MINECON对我们来说都是一种金钱损失。但是情感胜利！;D”<ref></ref>

前500位购票者可以参加绘画比赛用以角逐"终极爱好者体验"。获胜者可以获得曼德勒海湾赌场宾馆的免费房间、主题演讲和展示的VIP席位以及与Mojang团队共进晚宴的机会。最终由名叫Joseph的爱好者摘得桂冠。<ref>http://mojang.com/2011/09/01/minecon-update/</ref>

# 披风
[thumb|225px|首个赠送给MINECON 2011参与者的披风截图](File:Creeper_Cloak.png.md)
Notch宣布所有出席MINECON 2011的爱好者可以获得MINECON 2011[披风](披风.md)。他随即移除这一声明，并宣称这本应是一个秘密。在9月27日，官方发布了参加MINECON 2011的爱好者所可以获得披风的[图片](http://mojang.com/wp-content/uploads/2011/09/creepercloak.png)以及其他信息。<ref>http://mojang.com/2011/09/27/minecon-speakers-the-yogscast/</ref>披风于10月10、11日向所有出席者发放完毕。
