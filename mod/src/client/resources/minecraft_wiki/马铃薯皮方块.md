* *马铃薯皮方块（Block of Potato Peels）**是用9个[马铃薯皮](马铃薯皮.md)合成的方块。

# 生成
# = 自然生成 =
黄绿色马铃薯皮方块会作为[马铃薯村庄](马铃薯村庄.md)的一部分生成，同时也会在[薯饼](薯饼（生物群系）.md)生物群系中自然生成，用于模仿[仙人掌](仙人掌.md)的外观。

黑色、灰色、淡灰色和绿色马铃薯皮方块会在[废土](废土.md)生物群系的地表自然生成。

# = 毒马铃薯块 =
对[毒马铃薯块](毒马铃薯块.md)（不包括其压缩变种）[马铃薯削皮刀](马铃薯削皮刀.md)可以分解出9个[毒马铃薯](毒马铃薯/24w14potato.md)，并在原地留下一个普通马铃薯皮方块。

# = 破坏 =
没有工具可以加速对马铃薯皮方块的挖掘。

马铃薯皮方块被破坏后会掉落自身。

# 用途
# = 削皮 =
马铃薯皮方块可以通过放置后对其[马铃薯削皮刀](马铃薯削皮刀.md)来分解为马铃薯皮。

# 你知道吗
* 由于对毒马铃薯方块削皮不会消耗原料中的9个毒马铃薯，因此每消耗一个马铃薯削皮刀就可以制造238个普通马铃薯皮方块。
* 如果对制造的普通马铃薯皮方块再次削皮分解为普通马铃薯皮，每个马铃薯削皮刀可削出1071个普通马铃薯皮，使用不消耗燃料的[营火](营火.md)或[煎炸台](煎炸台.md)煎炸为[薯饼](薯饼.md)食用一共可恢复2142饥饿值。
