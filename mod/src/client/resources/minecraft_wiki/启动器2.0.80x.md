# 启动器2.0.80x

*页面ID: 63554* | *来源: Minecraft Wiki*

* *2.0.806**（[Windows](wzh:Microsoft Windows.md)）或**2.0.805**（[macOS](wzh:macOS.md)）是一次[启动器](启动器.md)更新，发布于2017年2月9日，修复了一些漏洞。

# 修复
*  - 可以以访客身份登录。
*  - 不常见的Unicode字符会被显示为问号。
*  - 启动器不更新Minecraft版本的下载状态。
*  - 更改配置的操作在事件调度线程上执行。
*  - 启动器打开位置过低（超出屏幕）。
*  - 配置编辑器中，过长的JVM参数会跨显示屏显示。
*  - 配置名称无长度限制，导致按钮会出现在启动游戏按钮的下方。
*  - 尝试选择配置时或Mojang服务器离线/无网络连接时会有很严重的卡顿，或者卡死。
*  - 离线模式下不能切换用户。
*  - 按Windows快捷键会使启动器变成白屏。
*  - 可见性选项有一个复选框。
*  - 游戏输出滚动错误。
*  - 启动器创建目录失败时没有提示。
*  - 启动器输出<code>Completely ignored arguments - [--nativeLauncherVersion, ###]</code>。
*  - 按开始游戏按钮后不禁用操作配置文件的选项。
*  - 在同一账户中选择多个配置时，总是会返回第一个可用配置文件。
*  - 将<code>_JAVA_OPTIONS</code>设置为环境变量中的任意内容时，启动器会崩溃。
*  - <code>Minecraft.exe</code>文件上Mojang的数字签名过期。
*  - 启动器输出<code>java.io.IOException - Stream closed multiple times in Launcher Log after closing game</code>。
*  - 按了开始游戏按钮后，启动器会卡在准备中的状态。
