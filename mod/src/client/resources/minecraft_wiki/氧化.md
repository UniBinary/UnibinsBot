# 氧化

*页面ID: 106651* | *来源: Minecraft Wiki*

[thumb](File:All Oxidizing Blocks.png.md)

铜质方块会随时间流逝而逐渐**氧化（Oxidation）**。不同氧化程度的铜质方块有着不同的纹理和名称。

[铜傀儡](铜傀儡.md)的氧化行为见。

# 机制
# = 氧化 =
铜质方块有4种氧化阶段（包括尚未氧化阶段）。铜质方块在名称上，后3个阶段依次体现为“**斑驳（Exposed）**”“**（Weathered）**”和“**氧化（Oxidized）**”。随着氧化程度加深，铜质方块的外观逐渐由棕色过渡到绿色。

铜质方块的氧化速度与自身氧化程度、周围[曼哈顿距离](曼哈顿距离.md)小于等于4（下文简写为“周围”）且未涂蜡的铜质方块的氧化程度和数量有关：
   铜质方块每接收到一个[随机刻](随机刻.md)，都有}}或}}的概率进入“预氧化”状态。
* 若周围其他铜质方块的氧化程度更低，则该铜质方块不会进一步氧化。
* 若周围没有氧化程度更低的铜质方块，则该铜质方块有<math>\frac{m(b + 1)^2}{(a + 1)^2}</math>的概率氧化到下一阶段。
* * <math>b</math>为周围氧化程度更严重的铜质方块数量，<math>a</math>为周围所有铜质方块的数量。
* * 若该铜质方块尚未被氧化，系数<math>m</math>为0.75；其他则为1。
因此被单独放置的铜质方块氧化速度最快；而被未氧化的铜质方块完全包裹住的铜质方块氧化速度最慢。

# = 涂蜡 =
涂蜡可以维持铜质方块的氧化程度，防止继续氧化或被[闪电束](闪电束.md)消除锈蚀。涂蜡变种与对应的未涂蜡变种在纹理上没有差异。

玩家可以通过消耗[蜜脾](蜜脾.md)来为铜质方块涂蜡：
* 在合成方格中结合铜质方块与蜜脾
* 对铜质方块蜜脾
* 在装有蜜脾的[发射器](发射器.md)前方摆放铜质方块并将其激活

# = 斧 =
对铜质方块[斧](斧.md)可以除锈，每次操作使铜质方块减轻一个氧化阶段。若是涂蜡变种则先进行脱蜡。

# = 闪电束 =
[thumb|闪电束击中铜块后为其除锈](File:Electric spark.png.md)
未涂蜡的铜质方块被[闪电束](闪电束.md)击中时会清除所有锈蚀。其附近的铜质方块也会被减轻锈蚀，减轻概率随离闪电束击中点距离的增加而降低。

本段落所述的铜质方块都需要排除涂蜡变种。

[thumb|闪电束击中避雷针后为下方的铜块除锈](File:Lightning oxidizing anim.gif.md)
闪电束在击中铜质方块或附着于铜质方块的[避雷针](避雷针.md)后，会将该铜质方块直接清理为未氧化变种，并将这里设置为起始点，进行3-5次除锈操作，其中每次除锈操作进行1-8次寻路尝试：每次寻路尝试会在起始点的3×3×3范围内的27个方块中随机搜索10次，若搜索到铜质方块，就将其锈蚀程度减轻一级，并将起始点设置为这里；若没有搜索到，则这次寻路尝试失败。因此避雷针最多可以清理雷击点或避雷针根部17×17×17范围的铜质方块，一次雷击最多清理41块铜质方块。前提是这些铜质方块相连在一起，因为寻路是无法跨过间隔的。

在平面单层铜质方块的情况下模拟<ref group="注">使用程序模拟雷击2500万次，雷击点在深绿色1.36处。</ref>，下列是得到的一次雷击每个位置的期望除锈次数。也就是说在4格距离已经平均需要上百次雷击才能除锈，[切比雪夫距离](切比雪夫距离.md)8格的边缘铜质方块被寻路到的可能性微乎其微。

# 你知道吗
* 在现实中，绿色铜锈的主要成分通常是[碱式碳酸铜](wzh:碱式碳酸铜.md)[<chem>Cu2(OH)2CO3</chem>]，俗称铜绿。
* 在现实中，绿色铜锈仅生成于金属表层且相当容易刮除，游戏中以斧除锈的机制与之相对应。
* 游戏中铜块的闪电除锈机制源自现实中将铜作为阴极的电解除锈原理。
