# 可再生资源

*页面ID: 5769* | *来源: Minecraft Wiki*

* *可再生资源（Renewable Resources）**是指至少有一种可以不消耗仅在世界生成时生成的资源的获取方式、从而可以实现无限获取的资源。

# 定义
资源的可再生性由该资源在[生存模式](生存模式.md)中不利用游戏漏洞、不使用[命令](命令.md)作弊、不使用存档编辑的情况下的**获取方式**决定。

对于一个获取方式，若满足以下所有条件，则该获取方式是**可再生的获取方式**，否则是**不可再生的获取方式**：
* 该获取方式不消耗仅在[世界生成](世界生成.md)时生成的资源。
* 该获取方式需要的（无论是否消耗）资源必须是存在的，即存在获取方式。

只要一种资源有至少一个可再生的获取方式，该资源就是**可再生资源**，否则为**不可再生资源**。

资源的可再生属性不是一种基本属性，而是随世界而变化的属性；对于不同的世界，例如改变了世界规则或添加了额外游戏内容，资源的可再生属性可能是不同的。

虽然“可再生资源”的概念可以推广至任何类型的资源上，包括[方块](方块.md)、[物品](物品.md)、[实体](实体.md)、[魔咒](魔咒.md)、[状态效果](状态效果.md)、[物品耐久](物品耐久.md)、甚至是[生命值](生命值.md)、[袭击](袭击.md)、[天气](天气.md)和[末影龙战斗](末影龙战斗.md)。不过，玩家实际可以掌握并管理的资源是物品，因此可再生资源属性通常仅用于描述物品；在提及“方块”的可再生属性时，通常指的是该方块的[方块物品](方块物品.md)的可再生属性。

在此页的剩余部分及中文Minecraft Wiki上所有条目中列出的物品可再生属性，除非特殊说明，均是在和中、每一种[实验性内容](实验性内容.md)或[实验性玩法](实验性玩法.md)的组合下、原版游戏中的“默认”[世界类型](世界类型.md)、默认的[游戏规则](游戏规则.md)、简单、普通和困难[难度](难度.md)中物品资源的可再生属性。若游玩的世界与此不同，玩家需要自行总结该世界中的资源的可再生属性。

# = 定义的延伸 =
没有任何获取方式的物品，如[基岩](基岩.md)、[刷怪笼](刷怪笼.md)、[紫水晶母岩](紫水晶母岩.md)、[命令方块](命令方块.md)、[调试棒](调试棒.md)，是不可再生资源。

如果一个物品的全部获取途径都是在世界生成时生成的，或需要消耗只在世界生成时生成的资源，这个物品是不可再生资源。

如果一个物品无需通过搜索世界中生成的资源即可获取，那么这个物品就有可再生方式，是可再生资源。

物品的再生性会传播，被推广至更多物品上：
* 对于一个有多种获取方式的物品，只要其中任何一种获取方式是可再生的，那么该物品就是可再生的。
* * 虽然[末地石](末地石.md)有许多不可再生的获取方式，但仍然有至少一种可再生方式，因此末地石是可再生的。
* 对于一种获取方式，只要有任何需要消耗的资源是不可再生的，这种获取方式就是不可再生的。
* * 反之，如果一个[合成](合成.md)、[烧炼](烧炼.md)、[酿造](酿造.md)或[锻造](锻造.md)配方中的所有材料都是可再生的，那么配方产品就是可再生的。
* * 例如，合成[下界合金锭](下界合金锭.md)需要[下界合金碎片](下界合金碎片.md)和[金锭](金锭.md)，尽管金锭可再生，但下界合金碎片不可再生，因此下界合金锭也不可再生。
* * 获取前需要消耗不可再生资源，但此后不再消耗即可获取的获取方式也不一定是不可再生的。例如[旗帜](旗帜.md)的一些图案需要不可再生资源制作的[旗帜图案](旗帜图案.md)，但旗帜图案不会被消耗，且旗帜制作后可以复制，因此任何图案的旗帜都是可再生的。

可再生方式要求需要的（无论是否消耗）资源存在，这意味着：
* 对于一个不存在且不可获取[沙子](沙子.md)的世界，[仙人掌](仙人掌.md)不可通过种植在沙子上来实现可再生。
* 对于一个不存在且不可获取[工作台](工作台.md)和[合成器](合成器.md)的世界，任何基于需要工作台的合成配方的获取方式都会不可用。
* [化学设备](化学设备.md)可以无限量地制造[元素](元素.md)，然而化学设备没有获取方式，这导致了虽然元素可以通过化学设备实现无限获取，但不是可再生资源。

# = 可再生性的改变 =
[thumb|200px|由于丛林树叶被破坏后掉落丛林树苗的低概率，在只有一个有64个丛林树叶的丛林树的封闭环境中，丛林树苗有近20%的概率在第一代就绝迹，直到通过流浪商人或其他来源重新引入丛林树苗](File:Jungle Tree.png.md)
对世界生成和游戏规则的改变会影响物品的可再生属性，其中绝大多数更改都会导致资源绝迹而变得不可再生，例如：
* [和平](和平.md)难度会导致许多仅来自敌对生物掉落物的资源不可获取。
* 关闭[生成结构](生成结构.md)会导致玩家不能进行[酿造](酿造.md)，因为[酿造台](酿造台.md)的所有来源都涉及至少一种生成结构，进一步导致几乎所有[药水](药水.md)都不可获取。
* 关闭生成结构会导致玩家不能访问[末地](末地.md)，因为世界中没有会生成[末地传送门](末地传送门.md)的[要塞](要塞.md)，进一步导致来自末地的资源都不可获取。
* 对于一个没有定义[下界](下界.md)维度的自定义世界，来自下界的资源都是不可获取且不可再生的。
* [超平坦](超平坦.md)和[单一生物群系](自选世界类型.md)世界通常不具有完整的资源获取方式。
* “虚空”超平坦预设极度贫瘠，玩家在其中几乎不能获得任何物品。

在非常极端的情况下，一个世界可能会完全耗尽某一个资源，并导致了在不改变世界规则的情况下，使资源从可再生变为不可再生。例如，通过摧毁所有[要塞](要塞.md)箱子战利品，导致[眼眸盔甲纹饰锻造模板](眼眸盔甲纹饰锻造模板.md)的绝迹。

# = 默认世界的可再生方式 =
一些资源（如[农作物](农作物.md)）的再生手段比较常见；而有些资源的再生手段则较为独特（如通过[末影龙](末影龙.md)收集[龙息](龙息.md)、建造[刷石机](Tutorial:刷石机.md)收集[圆石](圆石.md)）。再生手段未必是资源最安全、简易或高效的收集手段。

以下的再生方法大致按从简单到困难的次序排列：
* [耕种](耕种.md)作物
* [繁殖](繁殖.md)动物
* 使用可再生资源进行[合成](合成.md)/[烧炼](烧炼.md)/[酿造](酿造.md)
* [生物](生物.md)死亡后的常见掉落物
* 与[村民](村民.md)或[流浪商人](流浪商人.md)进行[交易](交易.md)
* 与[猪灵](猪灵.md)进行[以物易物](以物易物.md)
* [钓鱼](钓鱼.md)
* 收到[猫](猫.md)的礼物
* 战胜[袭击](袭击.md)后收到[村民](村民.md)的礼物
* 稀有掉落物
* [宝库](宝库.md)战利品

通过交易、以物易物、钓鱼可获得的大多数物品可以通过其他方式获得。其他方式尽管可能更容易，但可能不可再生。

建造自动杀死大量生物的[刷怪塔](Tutorial:刷怪塔.md)可以大量获取掉落物。

任何可以通过交易或以物易物获取的物品都是可再生的，因为绿宝石和金锭是可再生的。

所有不需要消耗不可再生资源就能生成的生物，它们的掉落物通常都是可再生的。
* 获取只在世界生成时生成的生物的掉落物是一种不可再生的物品获取方式，如[远古守卫者](远古守卫者.md)掉落[湿海绵](湿海绵.md)。
* 生物本身不需要消耗不可再生资源就能生成，但掉落物需要消耗不可再生资源，也是一种不可再生的物品获取方式，如通过杀死[末影龙](末影龙.md)生成[龙蛋](龙蛋.md)。

宝库只会阻止最后128-{}-位解锁了该宝库的玩家解锁宝库，因此宝库可以被每个玩家打开无限次数<ref name="MC-274049"></ref>。由于[试炼钥匙](试炼钥匙.md)和[不祥试炼钥匙](不祥试炼钥匙.md)是[可再生资源](可再生资源.md)，所以通过宝库获取物品是一种可再生的获取方式。

# 你知道吗
* 利用任意物品复制漏洞，如[Tutorial:方块和物品复制](Tutorial:方块和物品复制.md)，可以使所有可以正常获取的资源都变为可再生资源。
* 可再生的定义排除了[创造模式](创造模式.md)、存档编辑、作弊[命令](命令.md)和漏洞，因为这些方式可以产出**所有物品**，导致可再生属性失去意义，因此这些方法不被认为是合理的可再生手段。
* 除了上面列出的物品外，[经验](经验.md)、所有生存模式中能得到的[状态效果](状态效果.md)和[魔咒](魔咒.md)（除[迅捷潜行](迅捷潜行.md)以外）都是可再生的。
