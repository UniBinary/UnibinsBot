# 铜灯笼

*页面ID: 161855* | *来源: Minecraft Wiki*

* *铜灯笼（Copper Lantern）**是使用[铜粒](铜粒.md)和[铜火把](铜火把.md)合成的[灯笼](灯笼.md)变种。

# 生成
铜灯笼不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘铜灯笼的合适工具是镐。

铜灯笼被破坏后会掉落自身。

# 用途
# = 放置 =

# = 光源 =
铜灯笼会发出光照等级为15级的[光](光.md)，比[火把](火把.md)的光照等级高1级。它也可以融化3格内的[冰](冰.md)和[雪](雪.md)。

# = 氧化 =

铜灯笼受氧化机制影响，能够在不同变种之间转化。

铜灯笼的亮度等级不会随氧化程度变化。
