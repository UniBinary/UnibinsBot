# 生成
悬挂式告示牌不会生成在世界中。

# 获取
# = 合成 =

# = 箱子战利品 =

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落悬挂式告示牌。

# 破坏
挖掘悬挂式告示牌的合适工具是斧。

悬挂式告示牌被破坏后会掉落自身。

# 用途
# = 放置 =

悬挂式告示牌必须放置在[中心完整](方块支撑形状.md)的方块底面或完整的方块侧面，或者其他悬挂式告示牌的底部或侧面。

放置在方块侧面的悬挂式告示牌有4个朝向，带有一根横杆，杆与牌之间由两条平行铁链相连。

放置在方块底面的悬挂式告示牌，其铁链直接固定于该面。若该面完整，则两条铁链平行，玩家能以4个朝向放置此悬挂式告示牌，还有未使用的12个朝向<ref></ref>；若该面仅中心完整，或玩家在潜行状态下放置，则两条铁链相交于面中心，玩家能以16个朝向放置此悬挂式告示牌。

放置在方块底面的悬挂式告示牌，会在其附着的方块移动或被移除的情况下破坏并掉落自身。

# = 文本 =

悬挂式告示牌可被用于显示文本，最多可输入4行文本。

对有文字的悬挂式告示牌[染料](染料.md)可以改变文本颜色。对其[荧光墨囊](荧光墨囊.md)可以提高文本亮度，使用[墨囊](墨囊.md)可以移除发亮效果。

# = 交互 =
放在方块侧面的悬挂式告示牌有[碰撞箱](碰撞箱.md)，但仅包含上方的横杆，放置后可以不依赖于该方块侧面而独立存在。放在方块底面的悬挂式告示牌没有碰撞箱。

悬挂式告示牌被[活塞](活塞.md)推动时会掉落为物品；活塞无法推动悬挂式告示牌。悬挂式告示牌被活塞拉动时不会有反应（除非它附在伸出的活塞头表面）。

[水](水.md)和[熔岩](熔岩.md)会绕开悬挂式告示牌流动。悬挂式告示牌不会被[火](火.md)燃尽。

# = 燃料 =
竹质和主世界木质悬挂式告示牌能用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料。每个悬挂式告示牌可以烧炼4个物品。

# = 安全保护 =

悬挂式告示牌属于“仅管理员可设置数据”的方块。

非管理员玩家对悬挂式告示牌按下+时不会复制方块实体数据，放置物品栏中已有的带有方块实体数据的悬挂式告示牌也不会将数据实际加载。

管理员玩家的物品栏中带有方块实体数据的悬挂式告示牌的物品[提示框](提示框.md)中会显示警告信息。

# 你知道吗
* 悬挂式告示牌的首个概念图出自[Agnes Larsson](Agnes Larsson.md)的女儿。<ref></ref>
* 对[告示牌](告示牌.md)和悬挂式告示牌[荧光墨囊](荧光墨囊.md)后文本的发光描边，其实是在原文本的图层下偏移生成数个发光文本营造出的假象。游戏总共会渲染文本9次，因此会对性能造成严重的负面影响。<ref></ref><ref></ref>
* 可以通过观察悬挂式告示牌的底面纹理来区分正反面，颜色较深的一侧与正面共边。
