# 力量（状态效果）

*页面ID: 41284* | *来源: Minecraft Wiki*

* *力量（Strength）**是一种增加[近战攻击](近战攻击.md)伤害的[状态效果](状态效果.md)。

# 效果
# = Java版 =
受影响生物的基础近战攻击伤害增加×效果等级，结算在[暴击](近战攻击#暴击.md)和[魔咒](魔咒.md)之前。

# = 基岩版 =
受影响生物的受力量效果影响后的近战攻击伤害结算在[魔咒](魔咒.md)之后，[暴击](近战攻击#暴击.md)之前。

伤害大小可以由递推公式<math>d_n=1.3d_{n-1}+1</math>或通项公式<math>d_n=1.3^nd_0+\frac{1.3^n-1}{0.3}</math>计算，其中<math>d_0</math>是输入的攻击力，<math>d_n</math>是输出的攻击力，<math>n</math>为力量状态效果的等级。<ref></ref>

当力量和[虚弱](虚弱.md)状态效果同时存在时，会先使用力量的计算公式，并将得出的值以虚弱效果的计算公式处理。

[铁傀儡](铁傀儡.md)和已驯服的狼的近战攻击伤害不受力量状态效果影响。<ref></ref>
