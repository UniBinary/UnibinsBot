# 基岩版1.7.0.2

*页面ID: 36195* | *来源: Minecraft Wiki*

<onlyinclude>
* *beta 1.7.0.2**是[1.7.0](基岩版1.7.0.md)的首个测试版，发布于2018年8月23日<ref></ref>，在[实验性玩法](实验性玩法.md)中加入了基本的[记分板](记分板.md)，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 与基本的[记分板](记分板.md)的功能一同加入，作为[实验性玩法](实验性玩法.md)的一部分。

* *[游戏规则](游戏规则.md)**
* 加入了新的游戏规则：<code>commandblocksenabled</code>。

# 更改
# = 物品 =
* *[食物](食物.md)**
* 现在可以在[创造模式](创造模式.md)或[和平](难度#和平.md)难度下吃东西了。<!-- 不应移动到 § 修复吗？ -->
* [紫颂果](紫颂果.md)从自然分类移动到物品分类。

# = 常规 =
* 聊天中所提到的玩家名称将会以黄色高亮。
* 聊天中输入会显示玩家名称列表补全命令。
* 商城界面的顶部搜索、回到主页和查询已购项目更方便了。

# = 生物 =
* 生物鱼现在可能会掉落[骨粉](骨粉.md)而不是[骨头](骨头.md)<ref></ref>。

# 修复
* *修复了60个漏洞**
* 修复了游戏中发生的多次崩溃现象。
* 修复在多个村民尝试开门或进门时破坏门发生的崩溃。（）
* 修复了当与制图师交易地图时所发生的崩溃。
* 修复引雷三叉戟在雷雨天从发射器发射出并击中生物或玩家发生的崩溃。
* 在超平坦世界下，现在可以更容易看见水下的视野。（和）
* 如果已驯服生物忘记了主人，它会坐下来等待有玩家与之互动，然后这个玩家将会成为新主人且不再需要重新驯服。（）
* 刷怪笼爆炸后不再掉落物品。（）
* 打开物品栏或暂停菜单不再终止在梯子上潜行。（）
* 铁轨再次可以被流动的水破坏。
* 陆地生物现在可以在水下播放音效。
* 修复了当抛出附魔的激流的三叉戟时动画不会播放的问题。（）
* 在iOS设备上收到系统通知之后声音会再度恢复。（）
* 除非它们刚好合适，否则生物再也不能在小缺口中生成。（）
* 燃烧的箭再次可以点燃TNT矿车。（）
* 修复了使用触摸输入时某些物品在物品栏和箱子中不会正确堆叠的问题。（）
* 屏障不会被末影龙摧毁了。（）
* 现在击退效果可以对生物造成击退伤害。（）
* 附魔无限的弓轻微拉弓射出的箭不再立刻被玩家捡起。（）
* 末影人不再能生成于两个台阶之间的两格高的空间里。（）
* 现在可以对已经治愈的僵尸村民进行交易。（）
* 生物现在可以步行穿过灵魂沙和下界疣。（）
* 旗帜现在有正确的放置和破坏的音效。（）
* 重命名的刷怪蛋现在会生成重命名的生物。
* 活板门在被命令复制或移动时不再丢失方向。
* 方块的“可以放置”和“可以破坏”工具提示现在会显示它们的翻译。
* 结构不再能穿过海底神殿生成。
* 附魔台UI里的文本信息不再覆盖生成。
* 生鳕鱼和熟鳕鱼物品的名称现在是正确的。
* 拥有凋灵护甲的凋灵现在不会被投掷出的三叉戟造成伤害。
* 在分屏里调整了弓和三叉戟的手持机制。
* 游戏里的命令方块矿车现在会保存输入结果。
* 有鞍的猪现在当穿过2格高的水时，会把玩家从背上扔下去。
* 玩家不再在有限世界的边缘或者虚空里被困。
* 在骑乘生物时，其余玩家不再能打开骑乘生物的物品栏。
* Xbox One平台下现在能正确显示云端存档的列表。
* 在使用铁砧重命名一本附魔书并添加不兼容的附魔之后，附魔书不再丢失。
* 将带有忠诚的三叉戟投掷到虚空里时现在可以收回。
* 当溺尸乘船时不再有游泳动画。
* 高亮铁砧的输出槽位时，移除了“拿起一半”的工具提示。
* 从铁桶中放出热带鱼不再放出一条随机纹理的鱼而是最初捕获的那条。
* 快捷栏里存在空槽位时，现在可以使用快速移动功能来将同种物品的不同个堆叠移入快捷栏里。
* 幻翼刷怪蛋现在可以使用选取方块键获得。
* 命令现在可以在显示了主标题后执行。（）
* 海泡菜现在在生存模式下可以秒挖。（）
* 当重新进入世界时，拴绳结不再消失。（）
* 当使用触摸屏游泳时不再打破方块。（）
* 命令的自动填充功能现在会将玩家的名字放入引号里。
* 玩家不可能在他们站着的地方放置方块。（）
* 命令现在会正确地传送玩家和他们正在骑乘的实体。
* 玩家不再传送到在玩家渲染距离内被玩家的末影珍珠击中的载具或生物。
* 只有骑马的玩家才能打开马的物品栏。
* TNT矿车在4格或更高的地方下落时会自爆。
* 使用控制器的玩家骑乘矿车时现在可以丢弃物品。
* 当玩家头部装备一个雕刻的南瓜时,玩家的标记会从其他玩家的定位器地图上消失。
* 如果生物在行为包里被移除了所有运动组件，那么它们会停止移动。
* 使用行为包来更改弹射物的发射位置时不再使得该弹射物丢失目标。
* 在船上对准前方的方块时，挖掘不再使得船上的马受伤。（）
* 在船上现在可以丢弃物品。
* 重新启动时，“检测到崩溃”信息现在会提供简要原因。
* 在Windows Phone版下，访问DLC时游戏崩溃。</onlyinclude>
