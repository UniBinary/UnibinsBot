# 启动器0.9.4

*页面ID: 49329* | *来源: Minecraft Wiki*

* *0.9.4**是一个2013年6月18日发布的[启动器](启动器.md)版本。

# 新增
* 在选择档案面板中加入了“新增档案”和“编辑档案”。

# 修复
*  - 在游戏文件夹不存在的情况下无法启动游戏。
*  - 不能在档案列表中对档案进行右键操作。
