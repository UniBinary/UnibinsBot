# 雕纹凝灰岩

*页面ID: 106650* | *来源: Minecraft Wiki*

* *雕纹凝灰岩（Chiseled Tuff）**是[凝灰岩](凝灰岩.md)制作的装饰性方块，四个侧面上都有旋风图案。

# 生成
# = 自然生成 =
雕纹凝灰岩会生成在[试炼密室](试炼密室.md)的墙壁和天花板上以及生成[旋风人](旋风人.md)的[试炼刷怪笼](试炼刷怪笼.md)旁。

# 破坏
挖掘雕纹凝灰岩的合适工具是镐。雕纹凝灰岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

雕纹凝灰岩被破坏后会掉落自身。

# 用途
雕纹凝灰岩目前仅用于装饰。
