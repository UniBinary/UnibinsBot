# Java版19w05a

*页面ID: 39563* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w05a**是[Java版1.14](Java版1.14.md)的第19个快照，发布于2019年1月30日<ref></ref>，加入了流浪商人和行商羊驼以及对应的刷怪蛋，新的方块标签和音效，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了流浪商人和行商羊驼的刷怪蛋。

# = 生物 =
* *[行商羊驼](行商羊驼.md)**
* 长相和普通[羊驼](羊驼.md)相同，但拥有蓝色和金色的装饰。
* * 可以像普通的羊驼一样配备地毯。当地毯被取下时，原来的装饰会重新出现。
* 与对所有[灾厄村民](灾厄村民.md)（除了[劫掠兽](劫掠兽.md)）、[僵尸](僵尸.md)、[僵尸猪人](僵尸猪人.md)、[僵尸村民](僵尸村民.md)、[尸壳](尸壳.md)和[溺尸](溺尸.md)敌对。
* 和羊驼是不同的实体。
* 在玩家旁边容易发怒。

* *[流浪商人](流浪商人.md)**
* 可在世界中的随机地点找到。
* 在不同生物群系中提供不同的随机交易。
* * 交易次数有限制，被锁定的交易不能通过进行其他交易解锁。
* * 一共有6个交易内容，所有交易内容均已开放，交易次数耗尽不会解锁。
* 身旁总是会有几个[行商羊驼](行商羊驼.md)。
* 和村民是不同的实体。
* 它们看起来像是村民，但它们的生成地点、声音和交易不同。
* 每个世界只有一个，并在后消失。

# = 命令 =
* 两个新的方块标签：和。

# = 常规 =
* *[声音](声音.md)**
* 为[灯笼](灯笼.md)加入了新的放置和破坏音效。
* 为[甜浆果丛](甜浆果丛.md)加入了新的放置音效。

# 更改
# = 方块 =
* *[堆肥桶](堆肥桶.md)**
* 更改了玩家堆肥的速率。
* 10%概率的物品变成30%；20%变成50%；50%变成65%；80%变成85%。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 刷怪蛋重命名为劫掠兽刷怪蛋。
* 刷怪蛋的ID改为。

# = 生物 =
* *劫掠兽**
* （Illager beast）重命名为劫掠兽。
* ID更改为。

# = 命令 =
* 现在能在命令方块和函数中执行。
