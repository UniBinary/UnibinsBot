# Java版1.8.5

*页面ID: 16518* | *来源: Minecraft Wiki*

* *1.8.5**是的一次次要更新，发布于2015年5月22日<ref></ref>，加入了1条新的闪烁标语。此版本解决了安全和记分板的各种问题<ref></ref><ref></ref>。此版本兼容1.8到1.8.4的服务端。

# 新内容
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* “GNU Terry Pratchett”

# 更改
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 移除对Notch和ez的“Happy birthday（生日快乐）”祝福标语
* 移除了“Notch <3 ez!”
* 更改标语“Cooler than Spock!（比斯波克还要酷！）”为“Not as cool as Spock!（还没斯波克酷！）”
