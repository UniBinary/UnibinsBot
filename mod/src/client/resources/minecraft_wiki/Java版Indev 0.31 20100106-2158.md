# Java版Indev 0.31 20100106-2158

*页面ID: 35297* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2010年1月6日21:58（UTC），加入了世界类型和世界形状。<ref></ref>

# 新内容
# = 世界生成 =
* *[虚空](虚空.md)**
* 世界最底层不再生成无限大的熔岩海，现在被无尽的[基岩](基岩.md)所取代。

# = 游戏内容 =
* *[世界类型](Indev世界选项#世界类型.md)**
* 加入了世界类型，共有岛屿（Island）、浮岛（Floating）、平坦（Flat）和原始（Original）四种世界类型，可由[创建新的世界](创建新的世界.md)屏幕控制。
* * 岛屿：世界为一座岛屿，其上通常会有较小的山丘。
* * 浮岛：世界为许多大大小小的浮岛，浮空的沙砾和沙子随处可见，而水比较罕见。
* * 平坦：世界为一座平地，类似于超平坦世界，同时会生成一些树和花朵。
* * 原始：世界整体类似于岛屿世界类型，会生成一些丘陵，同时世界被水包围。

* *[世界形状](Indev世界选项#世界形状.md)**
* 加入了世界形状，共有方型（Square）、长型（Long）和深型（Deep）三种世界形状，可由[创建新的世界](创建新的世界.md)屏幕控制。
* * 方型：世界的长度和宽度相等，高度为64。
* * 长型：世界的长度×2，宽度÷2，高度为64。
* * 深型：世界的长度和宽度相等，高度为256。

# 更改
# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 现在物品栏中的[方块](方块.md)会像[生存模式](生存模式.md)那样被消耗。

# = 常规 =
* *[创建新的世界](创建新的世界.md)**
* 现在可以选择要创建世界的[世界类型](Indev世界选项#世界类型.md)和[世界形状](Indev世界选项#世界形状.md)。</onlyinclude>
