# Java版13w39b

*页面ID: 33628* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w39b**是[Java版1.7.2](Java版1.7.2.md)的第9个快照，发布于2013年9月27日<ref></ref>，以修复[13w39a](13w39a.md)中的漏洞和崩溃。

# 更改
# = 非生物实体 =
* *[命令方块矿车](命令方块矿车.md)**
* 在[激活铁轨](激活铁轨.md)上的[命令方块矿车](命令方块矿车.md)只会每过4刻激活一次。
* 更改了命令方块矿车的物品名称（使用命令时的方块或物品ID），从<code>minecraft:hopper_command_block</code>变为<code>minecraft:command_block_minecart</code>。

# = 命令格式 =
* *语法**
* 加入了一个警告，提醒玩家在[命令](命令.md)中使用物品ID获得物品时应使用其ID对应的名称，因为它们对应的ID很快就要被弃用。

# = 常规 =
* *[成就](成就/Java版.md)**
* “给你钻石！”成就可通过向一个[玩家](玩家.md)或拥有<code>CanPickUpLoot</code>[NBT](NBT.md)标签的[僵尸](僵尸.md)扔一个[钻石](钻石.md)获得。

* *[主菜单](主菜单.md)**
* 在主菜单的一个不同的警告会提醒未来的一些更改，因为以后运行Minecraft需要OpenGL 2.1或更高的版本。
