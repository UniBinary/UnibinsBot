* *马铃薯（Potato）**是一种可种植的[食物](食物.md)，可以直接生吃，也可以用[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)或[营火](营火.md)烤制为[烤马铃薯](烤马铃薯.md)。

* *马铃薯（Potatoes）**是物品形式的马铃薯种植在[耕地](耕地.md)上形成的方块。

# 生成
# = 自然生成 =
马铃薯植株会自然生成在[平原](平原.md)、[针叶林](针叶林.md)和[雪原](雪原.md)类型的[村庄](村庄.md)里[农田](农田.md)结构的[耕地](耕地.md)上。

# 破坏

马铃薯被挖掘时会立刻被破坏。

生长阶段没有达到第8阶段的马铃薯被破坏后会掉落1个马铃薯。

生长阶段达到第8阶段的马铃薯植株被破坏后会掉落或个马铃薯，还有2%的概率会额外掉落1个[毒马铃薯](毒马铃薯.md)。其中<math>X</math>为挖掘工具的[时运](时运.md)等级。然后系统会尝试进行3次掉落，每次有约）}}或）}}的概率掉落1个马铃薯。挖掘工具的时运魔咒每增加1级，尝试进行掉落的次数增加1。

# 用途
# = 食用 =

手持马铃薯按住键即可食用，每个马铃薯可以回复。

# = 种植 =

对[耕地](耕地.md)的顶面马铃薯即可种植出马铃薯植株。马铃薯植株会经历8个生长阶段（有4个可视的阶段）。[亮度](亮度.md)等级≥9时，马铃薯植株才能生长到下一个阶段；亮度等级≤7时无法对耕地马铃薯，已种植的马铃薯植株也会在接收到[方块更新](方块更新.md)时掉落为[物品实体](物品实体.md)。

马铃薯植株在湿润的耕地上生长得更快。对马铃薯植株[骨粉](骨粉.md)会使其增加2-5个生长阶段，忽视亮度等级。已有巢且采集了花粉的[蜜蜂](蜜蜂.md)飞过马铃薯植株时，植株也有概率增加1个生长阶段。

马铃薯植株的四周都为马铃薯植株且都种植在湿润的耕地上会比单独种植在湿润的耕地的马铃薯植株生长速度快约16.7%；而按一排间种马铃薯植株，中间没有作物或为其他作物会比单独种植在湿润的耕地的马铃薯植株生长速度快133%。

# = 繁殖 =
马铃薯可用于吸引及繁殖[猪](猪.md)，也可喂食给幼年猪以减少其10%的剩余成长时间。

[村民](村民.md)可以通过拾起至少12个马铃薯来产生繁殖意愿。
