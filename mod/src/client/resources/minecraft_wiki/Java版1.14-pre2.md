# Java版1.14-pre2

*页面ID: 42231* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14-pre2**是[Java版1.14](Java版1.14.md)的第2个预发布版，发布于2019年4月12日<ref></ref>，加入了新的进度，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[进度](进度.md)**
* 加入了2项新进度：
* * *自我放逐* – 杀死一名袭击队长。
* * *村庄英雄* – 成功在一场袭击中保卫[村庄](村庄.md)。

# 更改
# = 物品 =
* *[](灾厄旗帜.md)**
* 被重命名为“不祥旗帜”（Ominous Banner）。

# = 常规 =
* *选项**
* 灵敏度、鼠标翻转、触屏模式现在归入“鼠标设置”分区。
* 加入滚轮灵敏度和离散滚动选项，也置入了“鼠标设置”分区，这些选项用于修复。
* * 滚轮灵敏度是滚动程度的倍率；这些设置最早于[18w21a](18w21a.md)中加入，但只能通过编辑[options.txt](options.txt.md)中的<code>mouseWheelSensitivity</code>修改。
* * 离散滚动使游戏忽略操作系统给予的滚动程度，而是按照被给予−1或+1处理。<!-- 即 signum(input) -->如果有必要的话，滚动程度之后会被滚动灵敏度影响。

* *[控制](控制.md)**
* 现在跳跃和下落时视角不再会上下晃动<ref></ref>。

* *统计信息**
* 加入了新的统计项：
* * 鸣钟次数
* * 与制图台交互次数
* * 与织布机交互次数
* * 与切石机交互次数
* * 触发袭击场数
* * 赢得袭击场数

* *性能**
* 改进了性能。
