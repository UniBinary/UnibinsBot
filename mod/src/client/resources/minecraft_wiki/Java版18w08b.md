# Java版18w08b

*页面ID: 33804* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w08b**是[Java版1.13](Java版1.13.md)的第22个快照，发布于2018年2月22日<ref></ref>，加入了鳕鱼、鲑鱼和河豚，以及对应的刷怪蛋和鱼桶，并修复了一些漏洞。

# 新内容
# = 生物 =
* *生物[鱼](鱼.md)**
* [鳕鱼](鱼.md)
* * 生成于冷水海洋、温水海洋和常规的海洋生物群系中。
* * 以最多9条集群游动。
* [鲑鱼](生鲑鱼.md)
* * 生成于冻洋、冷水海洋和河流生物群系中。
* * 以最多6条集群游动。
* [河豚](河豚（物品）.md)
* * 生成于温水海洋和暖水海洋生物群系中。
* * 当玩家接近时它们体积会膨胀。
* * 会给予玩家7秒钟的中毒效果。
* 它们死后会掉落对应的鱼的物品形式。
* 它们只能在水中活动，若离开水，会四处乱跳随后窒息。
* 它们可以被水桶盛放。

# = 物品 =
* *[鱼桶](鱼桶.md)**
* 鳕鱼桶
* 鲑鱼桶
* 河豚桶
* 小丑鱼桶的纹理存在，但未加入到游戏中。
* 时会放置一个带有一条对应的鱼的水源方块。

* *[刷怪蛋](刷怪蛋.md)**
* 鳕鱼
* 鲑鱼
* 河豚

# = 游戏内容 =
* *合成**
* [干海带](干海带.md)现在可以合成[干海带块](干海带块.md)，并且可以拆分成干海带。

# 更改
# = 世界生成 =
* *[生物群系](生物群系.md)**
* 暖水海洋和温水海洋[生物群系](生物群系.md)现在会在海底生成一层沙子。
* 移除了暖水深海[生物群系](生物群系.md)。

# = 游戏内容 =
* *常规**
* 更改了水下能见度
* * 玩家在水下待得越久，在水下的视力将会越好。
* * 水肺[药水](药水.md)和[魔咒](魔咒.md)不再会增强水下视力。
