# 地形特征

*页面ID: 47704* | *来源: Minecraft Wiki*

此页面列出了Minecraft的世界里生成的各种**地形特征（Terrain Features）**。

# 主世界
# = 山脉 =

* *山脉（Mountain）**是具有陡峭的山的地形。有时，一些[洞穴](洞穴.md)会穿过山脉。在[放大化](放大化.md)世界中，山脉是极其常见的（除了在[海洋](海洋.md)和[沼泽](沼泽.md)生物群系）。

File:OverhangMountain.png|一个突出、悬空的巨型结构，常出现在极高的山脉上
File:Yoshismountain.png|山脉上悬崖与浮岛
</gallery>

# = 浮岛 =
* *浮岛（Floating Island）**是一种飘浮在空中，不与地面、海洋、山脉和悬崖连接的结构。浮岛通常只是在悬崖附近的随机[泥土](泥土.md)和[石头](石头.md)，但在极其罕见的情况下，它们会非常巨大，以至于飘浮在半空中，甚至有[涌泉](涌泉.md)和[树木](树木.md)在上面。浮岛通常能在[风袭丘陵](风袭丘陵.md)、[雪原](雪原.md)、[山地](山地.md)和[蘑菇岛](蘑菇岛.md)生物群系被发现，但其实在任何地方都有可能生成，尤其是在[风袭热带草原](风袭热带草原.md)生物群系中。

File:LargeFloatingIsland.png|自然生成的浮岛
File:Minecraft floating island.png|另一个浮岛
File:Floating Land.png|小而高的浮岛，有水流下
</gallery>

# = 空洞 =
* *空洞（Hollow）**与浮岛相反。它们看起来像[洞穴](洞穴.md)，但与洞穴生成无关（尽管它们可能与洞穴交叉）。当有许多悬崖时，它们会靠在一起并创造出一个空洞。它们的高度与地形一致，这取决于它们所在的[生物群系](生物群系.md)，而不像洞穴那样。洞穴没有特定的高度。有趣的是，即使没有光，[草方块](草方块.md)也可以在空洞中生成。当空洞生成在低于海平面的高度上时，它们会被[水](水.md)填充。空洞在[主世界](主世界.md)中非常罕见，但在[自定义](自定义.md)世界中很常见。

<gallery widths="200px">
File:Hollow 2.png|默认世界的一个空洞，火把由玩家放置
File:Hollow 1.png|另一个空洞
</gallery>

# = 丘陵 =

* *丘陵（Hill）**是地图中陆地上随机产生的地形。像[楼梯](楼梯.md)一样，丘陵不会很陡峭，每层总是会有地方可以登上更高一层，这意味着[玩家](玩家.md)可以一层一层爬上山顶而不必借助任何工具。不能徒步爬上的丘陵是很稀有的。

<gallery widths="200px">
File:SmallForestHill.png|一个长着[树木](树木.md)和[草丛](草丛.md)的随机生成的丘陵
</gallery>

# = 地表层 =
* *地表（Surface Layer）**的最顶层会依据[生物群系](生物群系.md)被转换成其他方块，通常是[草](草.md)和[泥土](泥土.md)，或者是沙漠、沙滩上的[沙子](沙子.md)。[灰化土](灰化土.md)通常存在于[原始针叶林](原始针叶林.md)地表，[菌丝体](菌丝体.md)通常在[蘑菇岛](蘑菇岛.md)生物群系上，[红沙](红沙.md)则是在[恶地](恶地.md)生物群系上。[砂岩](砂岩.md)通常垫于沙子层之下。

# = 盆地 =
有的时候，地形的表面不会被转换成其他方块，而是被直接移除，留下[石头](石头.md)裸露的**盆地（Basin）**。游戏中的盆地与“[地盾](wzh:地盾.md)” （构造稳定的岩石地区，由于其非常古老的原因而长期遭受侵蚀）相似，和地理学上的“[盆地](wzh:盆地.md)”不同。<!--它们更多地在森林和平原中生成，偶尔被水淹没，玩家可以在其中发现矿石（通常为[煤矿石](煤矿石.md)和[铁矿石](铁矿石.md)）。如果这个地形生成在恶地生物群系中，也可以在其中发现[金矿石](金矿石.md)。-->它们如今只能在冻洋和冰冻深海生成。<ref name=MC-264579></ref>

# = 条带 =
* *条带（Strip）**是由同种方块组成的不规则蛇形结构，它们会替换掉一些生物群系中的地表方块。

<gallery widths="200px">
File:Calcite Strips.png|裸岩山峰上的方解石条带
</gallery>

# = 岩柱 =
* *岩柱（Bryce Pillar或Hoodoo）**是生成在[风蚀恶地](风蚀恶地.md)生物群系里的刺状的结构，由6种颜色的陶瓦组成。这种结构从地面突出，有时能超过海拔100层。

<gallery widths="200px">
File:Bryce Pillars Eroded Mesa.png|风蚀恶地里的岩柱
File:Mesa bryce.png
</gallery>

# = 冰山 =

* *冰山（Iceberg）**是生成在冻洋和冰冻深海生物群系海面上由浮冰与雪组成的地形特征。冰山拥有十分迥异的形状和尺寸，小到“微岛”，大到山脉。它们亦会生成“洞穴”一样的洞，这些洞可能贯穿整座冰山。与[冰山地物](冰山.md)不同，冰山地形特征不会生成[蓝冰](蓝冰.md)。

</gallery>

# = 含水层 =

* *含水层（Aquifer）**是采用噪声生成器生成的拥有独立高度的水体，能够在主世界形成水位、大小各异的湖。

# = 峡谷 =

* *峡谷（Canyon或Ravine）**是地下高而长的裂缝。峡谷的深度约为27-62格，峡谷通常能直接延伸至基岩层。峡谷有时会深入[海底](海洋.md)，形成海沟。

# = 矿脉 =

* *矿脉（Ore Vein）**是由[矿石](矿石.md)和[岩石](岩石.md)构成的罕见大型结构，形状类似于[意面洞穴](洞穴#噪声洞穴.md)，生成于主世界的地下。其分为铁矿脉和铜矿脉两种。

# 下界
# = 熔岩海 =
* *熔岩海（Lava Sea）**是下界31层以下出现的广阔的熔岩海域。熔岩海十分常见，是下界的主要光源之一。熔岩海可以在四面延伸数百米，海岸一般由[下界岩](下界岩.md)组成，有时候是[灵魂沙](灵魂沙.md)或[岩浆块](岩浆块.md)。

<gallery widths="200px">
File:Mobs on Lava Sea.png|[恶魂](恶魂.md)在熔岩海上
</gallery>

# = 下界盆地 =
* *下界盆地（Nether Basin）**的大小和形状与主世界的盆地相同。但不同的是，下界盆地使用[下界岩](下界岩.md)代替地面，而不是石头。下界盆地有时也会暴露出[下界石英矿石](下界石英矿石.md)和[下界金矿石](下界金矿石.md)。

值得注意的是，下界盆地的生成与y坐标无关。两个完全相同的盆地可能会在相同的x和z坐标，不同的y坐标处生成。

File:Warped Forest Basin.png|[诡异森林](诡异森林.md)的一个盆地
File:Nether Wastes Basin.png|[下界荒地](下界荒地.md)的一个大盆地
</gallery>

# 末地
# = 中央岛屿 =

末地的中央是一片行星状的大型岛屿，主要由[末地石](末地石.md)组成，悬浮在[虚空](虚空.md)中。

<gallery widths="200px">
File:TheEnd.png|末地中央岛屿
</gallery>

# = 外部岛屿 =

外部岛屿距离中央岛屿有大约1000米远，岛屿大小不一。[末地城](末地城.md)、[紫颂树](紫颂树.md)和[末地船](末地船.md)会生成在此处。玩家可以通过[末地折跃门](末地折跃门.md)传送到此处。

<gallery widths="200px">
File:ChorusFields.png|生长着紫颂树的外部岛屿
</gallery>

# = 黑曜石平台 =

* *黑曜石平台（Obsidian Platform）**是实体通过末地传送门进入末地时生成的平台，由5×1×5的[黑曜石](黑曜石.md)底座和上方5×3×5的[空气](空气.md)组成。

黑曜石平台始终生成于(100, 49, 0)。

通过末地传送门进入末地的玩家会被传送到黑曜石平台中心上方一格，其他实体则会被传送到(100.5, 50, 0.5)处。

当任何实体进入末地时，黑曜石平台会尝试复原，包括补全黑曜石和将上方5×3×5空间中的所有方块替换为空气，该空间中已有的实体不会因此被移除。

有时黑曜石平台会生成在岛中，只有5×3×5的空间，周围有[末地石](末地石.md)环绕。有时黑曜石平台会生成在空中。

通过末地传送门之外的方式进入末地时，黑曜石平台不会生成。

[回归折跃门](回归折跃门.md)也会将实体传送至黑曜石平台的位置，但该行为不会触发黑曜石平台生成。

<gallery widths="200px">
File:End-Platform-inGround.png|生成于岛中的黑曜石平台
</gallery>

# = 末地盆地 =
像在主世界和下界那样，**末地盆地（End basin）**会在末地生成。盆地可以在中央岛屿和外部岛屿生成。[紫颂树](紫颂树.md)偶尔会植根于盆地中。

<gallery widths="200px">
File:End Central Island Basin.png|生成于中央岛屿的盆地
File:End Outer Island Basin.png|外部岛屿的大盆地
</gallery>
