# 电子脚镣

*页面ID: 150792* | *来源: Minecraft Wiki*

* *电子脚镣（Ankle Monitor）**是一种能戴在[靴子](靴子.md)槽并且会对[玩家](玩家.md)行动造成限制的[物品](物品.md)。

# 获取
穿戴电子脚镣生成的人形生物被玩家或驯服的[狼](狼.md)击杀时有8.5%（[抢夺](抢夺.md)魔咒每级增加1%）的概率掉落电子脚镣。

# 用途
当玩家带上电子脚镣时，会给予玩家[](缓慢.md)I效果。

若玩家距离[出生点](出生点.md)过远，则[聊天框](聊天框.md)在晚上会显示：
“CURFEW WARNING! You are violating your house arrest! Get back by *[数字]* meters!”（宵禁警告！你已违反宵禁规定！往回走*[数字]*米！）

电子脚镣仅能在[创造模式](创造模式.md)中脱下。

当玩家不在[主世界](主世界.md)时，聊天框会按顺序循环显示以下消息：

# 音效

# 数据值
# = ID =

# 你知道吗
* 电子脚镣的想法最终在[16w39a](16w39a.md)中的[绑定诅咒](绑定诅咒.md)实现。
