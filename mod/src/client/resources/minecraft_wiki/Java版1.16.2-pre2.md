# Java版1.16.2-pre2

*页面ID: 67719* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.16.2-pre2**是[Java版1.16.2](Java版1.16.2.md)的第2个预发布版，发布于2020年8月5日<ref></ref>，更改了[菌索](菌索.md)的破坏方式，并修复了一些漏洞。

# 更改
# = 方块 =
* *[菌索](菌索.md)**
* 现在可使用任意工具采集，而不再需要使用[剪刀](剪刀.md)采集。

* *下界植物**
* 不再可燃。

* *[探测铁轨](探测铁轨.md)**
* 若放在[活板门](活板门.md)上，在活板门开启时锁定信号，直接输出的信号不再变化。锁定在未激活的不能激活[红石比较器](红石比较器.md)，会在活板门关闭时恢复。锁定在激活的能被红石比较器检测但发不出[比较器更新](比较器更新.md)，被[活塞](活塞.md)移动才能恢复。

# = 物品 =
* *[河豚](河豚（物品）.md)**
* 现在给予I效果，而不是II。
* * 这不会影响实际游戏效果，因为反胃状态效果的实际效果与其等级基本无关（实际上反胃的眩晕效果随等级提升变快，但是每一级间的差异微弱）。

# = 命令格式 =
* ***
* <code>in</code>子命令现在对于相对坐标和局部坐标会遵循不同维度的坐标缩放。比如，在主世界使用模拟在下界执行命令时，命令环境执行位置的X轴与Z轴坐标会被除以8。反过来，执行位置的X轴与Z轴坐标会被乘8。
* * 需要注意的是，如果先执行子命令，再在（或者其他命令）的参数后面加了一个数字（例如），那么游戏会先计算缩放（主世界到下界除以8，下界到主世界乘8），再计算。
* * 例如，在主世界处执行，现在会被传送到下界处。
* ** 相对地，在下界处执行，现在会被传送到主世界处。
* ** 在主世界处执行，现在会被传送到下界处。
* ** 在主世界处执行，依然会被传送到下界处。
* * 此版本之前的行为可以通过执行实现。
* * 同样适用于[自定义维度](自定义维度.md)。

# = 常规 =
* *[自定义维度](自定义维度.md)类型**
* 参数现在被参数替代。
* * 例如，维度类型的是1.0，是8.0，因此上述往主世界的命令实际上是把执行位置的X/Z坐标乘了（反过来就是乘），也就等于8（反过来就是0.125）。
* * 假设有两个自定义维度类型，类型（为2.33）和类型（为3.14），那么类似上述前往的命令就会将执行位置的X/Z坐标乘（反过来就是）。
