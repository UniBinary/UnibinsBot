# 薄煎饼披风

*页面ID: 186034* | *来源: Minecraft Wiki*

* *薄煎饼披风（Pan cape或The Pan Cape!）**是免费发放给所有玩家的披风。

# 外观
披风为淡蓝色背景，上面有一个盘子，盘上叠放煎饼，顶上有一块黄油，糖浆沿着煎饼流下。对应的鞘翅合上时看起来像一张煎饼。

# 描述
# = 标准版本 =
这件披风最初被用作制作其他披风的占位符，如[创始人披风](创始人披风.md)。<ref></ref>

最初参与基岩版beta的玩家可以获得薄煎饼披风。[基岩版1.16.0](基岩版1.16.0.md)发布后，此披风发放给所有基岩版玩家。2025年5月8日，薄煎饼披风发放给在基岩版拥有此披风的Java版玩家。

在Java版获得此披风必须先购买并游玩基岩版。

# = 重复版本 =

这款披风的第二个版本最初是[Mojang Studios披风](Mojang Studios披风.md)。然而，由于一个漏洞允许非Mojang员工领取该披风，其纹理和名称被更改为这款披风的样式，导致领取其的玩家在库中会看到这款披风的重复版本。其稀有度也从传奇变为普通。

能够领取到该重复版本披风的玩家仍然可以在[角色创建器](角色创建器.md)中装备。
