# 生鳕鱼

*页面ID: 33829* | *来源: Minecraft Wiki*

* *生鳕鱼（Raw Cod）**是一种[食物](食物.md)，可以被烹饪成[熟鳕鱼](熟鳕鱼.md)。

# 获取
# = 钓鱼 =
生鳕鱼可以在[钓鱼](钓鱼.md)时作为[鱼](钓鱼#垃圾与宝藏.md)被钓上来。钓上生鳕鱼的概率会随着[海之眷顾](海之眷顾.md)魔咒的等级增加而减少。

# = 礼物 =

[渔夫](渔夫.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷生鳕鱼。

# 用途
# = 食物 =

手持生鳕鱼按住键即可食用，每个生鳕鱼可以回复。

# = 烹饪 =
将生鳕鱼放入[营火](营火.md)、[烟熏炉](烟熏炉.md)或[熔炉](熔炉.md)中烹饪，可以获得熟鳕鱼。

# = 猫和豹猫 =
生鳕鱼可以用于驯服流浪[猫](猫.md)，每条有的概率驯服成功。它们也可用于把猫从[箱子](箱子.md)和[床](床.md)等方块上引诱下来、繁殖猫和豹猫、取得[豹猫](豹猫.md)的信任、减少幼年猫和豹猫10%的剩余生长时间。另外，每条生鳕鱼可以为猫恢复。

# = 海豚 =
可以用生鳕鱼喂食[海豚](海豚.md)。这样做可以提升它们对玩家的信任并更多地与它们互动。然而，与大多数动物不同的是，这不会使它们繁殖。

此外，当给海豚喂食生鳕鱼时，海豚会游到最近[海底废墟](海底废墟.md)或[沉船](沉船.md)结构的箱子。如果最近结构中的箱子被破坏，它们将游到最近的有箱子的结构。

# = 鹦鹉螺和殭屍鸚鵡螺 =
生鳕鱼可用于喂食驯服的[鹦鹉螺](鹦鹉螺.md)和[殭屍鸚鵡螺](殭屍鸚鵡螺.md)，使生命值已满的成年鹦鹉螺进入繁殖模式，治疗生命值未满的成年鹦鹉螺和殭屍鸚鵡螺的生命值，加速幼年鹦鹉螺约10%的成长时间。

# = 交易 =

# = 狼 =
生鳕鱼能用于给[狼](狼.md)恢复的生命值。然而和其他狼可以吃的食物不同的是，生鳕鱼不能用于加快幼年狼的成长，也不能用于繁殖，因此只能在狼未处于满血状态下食用。
