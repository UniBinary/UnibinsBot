# 命令/collect

*页面ID: 56581* | *来源: Minecraft Wiki*

使用[智能体](智能体.md)的物品栏中的1个方块收集3个维度中的物品。<!-- Collects all items within a one block from Agent in three dimensions. -->

# 语法
   <code>-{}-collect <*物品：字符串*></code>

# 参数
<code>-{}-<*物品：字符串*></code>
   指定智能体的物品栏中的1个方块所需要收集的物品。字符串必须是[物品ID](基岩版数据值#物品ID.md)或者是物品形式存在的[方块ID](基岩版数据值#方块ID.md)（例如<code>golden_sword</code>）。
