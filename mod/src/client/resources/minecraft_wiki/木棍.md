# 木棍

*页面ID: 7375* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *木棍（Stick）**是一种[合成](合成.md)配方中的常见物品。

# 获取
# = 合成 =

# = 箱子战利品 =

# = 考古战利品 =
用[刷子](刷子.md)刷扫[沙漠水井](沙漠水井.md)里的[可疑的沙子](可疑的沙子.md)有概率掉落木棍。

# = 钓鱼 =
木棍可以在[钓鱼](钓鱼.md)时作为“[垃圾](钓鱼#垃圾与宝藏.md)”物品获得。

# = 女巫 =

# = 枯萎的灌木 =
没有被[剪刀](剪刀.md)挖掘破坏时，枯萎的灌木被破坏后会掉落0-2个木棍。

# = 树叶 =
[树叶](树叶.md)枯萎或没有被剪刀或具有[精准采集](精准采集.md)的工具挖掘破坏时会掉落0-2根木棍。

# 用途
# = 合成材料 =

# = 燃料 =
木棍可以作为[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，一个木棍可以烧炼0.5个物品。
