# 命令/testforblock

*页面ID: 39826* | *来源: Minecraft Wiki*

探测某个方块是否在特定位置。

# 语法
   <code>testforblock <position: x y z> <tileName: Block> [blockStates: block states]</code>

# 参数

   指定待探测的方块的坐标。
   不可超出正常游戏范围。

   指定要探测的方块类型。


   指定要探测的方块状态。

# 输出

# 示例
* 检测坐标(0,64,0)处是否为箱子：<code>/testforblock 0 64 0 chest</code>

* 检测下方方块是否为点亮的[铜灯](铜灯.md)：<code>/testforblock ~ ~-1 ~ copper_bulb["lit"=true]</code>
