* *locator_bar**或**locatorBar**是控制是否显示[定位栏](定位栏.md)的[游戏规则](游戏规则.md)。

# 行为
# = Java版 =
当locator_bar为时，游戏可以创建和更新[玩家](玩家.md)与路径点源的连接，以允许路径点被创建、更新以及被玩家接收。这进而表现为玩家数量不少于2时，定位栏会显示。

反之，游戏会断开所有玩家与路径点源的连接，移除路径点，但不会移除路径点源。

# = 基岩版 =
当locatorBar为时，若游戏中的[玩家](玩家.md)不少于2人，则会向所有玩家显示定位栏。
