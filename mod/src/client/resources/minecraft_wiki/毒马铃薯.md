* *毒马铃薯（Poisonous Potato）**是一种可能使玩家-{[中毒](中毒.md)}-的[食物](食物.md)类[物品](物品.md)。

# 获取
毒马铃薯是收成[马铃薯](马铃薯.md)时的稀有掉落物，成熟的马铃薯有2%概率额外掉落1个毒马铃薯。使用带有[时运](时运.md)魔咒的工具破坏并不会改变其掉落数量和概率。

# = 自然生成 =

# 用途
毒马铃薯不能被种植或[烹饪](烹饪.md)，同样也不能置在[堆肥桶](堆肥桶.md)中堆肥。<ref></ref>

# = 食物 =

手持毒马铃薯按住键即可食用，每个毒马铃薯可以回复，并有60%概率获得5秒的效果，共造成伤害。

# 你知道吗
* 尽管毒马铃薯在纹理上表现为“发芽”状态，但实际上不可以种植。
* 现实中发芽的马铃薯含有[龙葵素](wzh:龙葵素.md)，这是一种剧毒物质。
* 在游戏中，毒马铃薯能恢复的饥饿值和饱和度是普通马铃薯的两倍。<ref></ref>
