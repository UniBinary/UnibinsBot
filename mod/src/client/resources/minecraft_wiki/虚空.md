# 虚空

*页面ID: 7527* | *来源: Minecraft Wiki*

[缩略图|350px|主世界下方的虚空，使用[[夜视](File:The Void beneath Bedrock.png.md)照亮]]
* *虚空（Void）**是可建造世界之外的区域。

# 机制
[缩略图|350px|[[液体](File:WaterFlowingIntoVoid.png.md)，比如水，不能流到虚空内]]

世界内的不可建造的区域均是虚空，这包括高于建造高度上限的区域、低于建造高度下限的区域、世界界限以外的区域、以及区块未加载的区域。

虚空中的方块不可被改变。这意味着：[水](水.md)和[熔岩](熔岩.md)不能流入虚空；[活塞](活塞.md)不能将它的活塞头和其他方块推入虚空；[结构](结构.md)、[地物](地物.md)在生成成功时，只有不在虚空的部分会保留；方块不能被放置在虚空中。但是，打开[潜影盒](潜影盒.md)可以使其[判定箱](判定箱.md)延伸至虚空。

进入虚空会导致多种基于位置的属性不可获取，如[生物群系](生物群系.md)。这也会导致[调试屏幕](调试屏幕.md)中所有和生物群系有关的调试信息消失。

一部分虚空被游戏有意设置的障碍阻挡，使其不能被轻易进入。不过，通过[创造模式](创造模式.md)或等方式，玩家通常可以逾越这些障碍。

不同类型的虚空有不同的属性，例如只有底层虚空会引发实体删除和伤害。

虚空中的方块均是或。

# 虚空的类型
# = 顶层虚空 =
顶层虚空存在于高于建造高度的位置。

玩家在尝试向顶层虚空中放置方块时，或上会显示文本”}}或}}。

[实体](实体.md)通常不能抵达[下界](下界.md)的顶层虚空，因为下界的顶部被[基岩层](基岩.md)封闭。

通过持续的[支柱跳跃](支柱跳跃.md)，玩家最终会抵达顶层虚空，并不再能够增加高度。因此顶层虚空也是玩家最容易抵达的一种虚空。

当[风弹](风弹.md)高于[最高建造高度](高度#建筑高度限制.md)30格以上时会立刻爆炸。

# = 底层虚空 =
底层虚空存在于低于建造高度的位置。

实体通常不能抵达[主世界](主世界.md)和[下界](下界.md)的底层虚空，因为这些维度的底部被[基岩层](基岩.md)封闭。

在[末地](末地.md)，世界底部没有基岩层，实体很容易就会从空岛之间的空隙或者空岛的边缘落入底层虚空。

大多数落入虚空的实体都没有返回建造高度的能力，受重力影响而失控地下落。在逾越了临界高度之后，游戏会将其直接清除或造成伤害来将它们从世界中移除。

# == Java版 ==
底层虚空的临界高度在[主世界](主世界.md)中为-128，在[下界](下界.md)和[末地](末地.md)为-64，在自定义世界为。低于临界高度的非生物实体会被立刻删除，低于临界高度的生物会持续受到伤害。由於[受擊後傷害免疫](受擊後傷害免疫.md)生物一般最多每受到一次傷害。

虚空造成虚空伤害，能够无视一切伤害减免效果（包括[护甲值](护甲值.md)、[保护](保护.md)、[抗性提升](抗性提升.md)）和生物对伤害的免疫能力。因虚空伤害而死亡的生物不能触发[不死图腾](不死图腾.md)。

虚空能对处于[创造模式](创造模式.md)和[旁观模式](旁观模式.md)的玩家造成伤害。[凋灵](凋灵.md)低于临界高度时会每都减少生命值。[末影龙](末影龙.md)即使低于临界高度也不会受到伤害。

主世界的虚空为黑色；下界的虚空颜色按照[生物群系](生物群系.md)改变；末地的虚空为黑色。

# == 基岩版 ==
底层虚空的临界高度在[主世界](主世界.md)中为-82，在[下界](下界.md)和[末地](末地.md)为-18。低于临界高度22格的非生物实体会被立刻删除，低于临界高度的生物会持续受到伤害。

虚空造成虚空伤害，能够无视一切伤害减免效果（包括[护甲值](护甲值.md)、[保护](保护.md)、[抗性提升](抗性提升.md)）和生物对伤害的免疫能力。因虚空伤害而死亡的生物不能触发[不死图腾](不死图腾.md)。

处于[创造模式](创造模式.md)和[旁观模式](旁观模式.md)中的玩家免疫虚空伤害，可以在虚空中自由地飞行。[NPC](NPC.md)低于临界高度时会立刻死亡。[凋灵](凋灵.md)低于临界高度时会每都减少生命值，若在临界高度之下生成则会立即死亡。[末影龙](末影龙.md)即使低于临界高度也不会受到伤害。

玩家在尝试向底层虚空中放置方块时，聊天栏上会显示文本“”。

在Y=-105（仅主世界）或Y=-41（仅下界和末地）处有一层由硬编码编成的单向的移动阻挡平面，即**虚空地板（Void Floor）**，没有在虚空中死亡的生物会受其阻挡而不能继续下落，且摔落在其上方时不会受到摔落伤害。通过或旁观模式，玩家能逾越这层障碍，之后就能无限地下落，若越过虚空地板后向上飞，则不会被虚空地板限制。然而，如果玩家到达任何X或Z坐标超过±8,388,608的地方，由于[基岩版距离现象](基岩版距离现象.md)，这里的区块已不再包含任何类型的固体方块，虚空地板也不再能够接住玩家。

主世界的虚空中有随时间变动而显示的日光、[太阳](太阳.md)和[月亮](月亮.md)，与天空的颜色相同；下界的虚空是暗红色的；末地的虚空是黑色的。

# = 世界界限 =

超过第三层级的[世界界限](世界界限.md)（X/Z=±30,001,056）后，游戏就不再生成区块，在这之外的空间均是虚空。玩家进入这种虚空会导致游戏立刻崩溃。

# = 旧世界的边界 =

超过[旧世界类型](旧世界类型.md)的世界的边界（X/Z=±256）后，游戏就不再生成区块，在这之外的空间均是由[隐形基岩](隐形基岩.md)构成的虚空。隐形基岩会在建造高度内生成，因此如果玩家抵达了建造高度，就能站在这种虚空的顶部向外行走。

# = 未加载的区块 =
未加载的区块也是一种虚空，玩家进入其中后会观察到许多虚空的特征，如或的存在和生物群系属性的消失。不过，游戏通常会在进行任何进一步的计算前加载区块，玩家则不被视为进入过虚空。

若玩家尝试进入未加载的区块，会被阻挡而无法进入，这种情况一般发生在使用[鞘翅](鞘翅.md)飞行过快，使用带有[激流](激流.md)魔咒的[三叉戟](三叉戟.md)对着空中发射等情况下。

# 你知道吗
* 拥有生命值且在落入虚空后没有恢复过生命的玩家，在落入虚空2.5秒内就会死亡。在Java版中，如果玩家在低于临界高度处保持下落，那么玩家最终会死在低于临界高度约135.1格的位置。
* * 在虚空中得到治疗可以推迟死亡的时间。如果[瞬间治疗](瞬间治疗.md)或[生命恢复](生命恢复.md)效果足够强大，如持续不间断地食用[附魔金苹果](附魔金苹果.md)，或拥有6级及以上的[生命恢复](生命恢复.md)，就能在虚空中一直活下去。
