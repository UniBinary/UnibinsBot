# Java版18w43b

*页面ID: 36838* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w43b**是[Java版1.14](Java版1.14.md)的第2个快照，发布于2018年10月24日<ref></ref>，更改了一些纹理，并修复了一些漏洞。

# 更改
# = 常规 =
* *[服务器](服务器.md)**
* 清除了客户端的内存溢出。

* *纹理**
* 更改了所有[鱼桶](鱼桶.md)和[河豚](河豚（物品）.md)的纹理。
* 移除了[迅捷](迅捷.md)、[缓慢](缓慢.md)、[急迫](急迫.md)、[挖掘疲劳](挖掘疲劳.md)、[力量](力量.md)、[生命恢复](生命恢复.md)、[虚弱](虚弱.md)、[中毒](中毒.md)、[缓降](缓降.md)、[潮涌能量](潮涌能量.md)、[海豚的恩惠](海豚的恩惠.md)效果图标的背景并修复了部分错误纹理。
