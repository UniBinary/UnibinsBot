# 自定义

*页面ID: 62468* | *来源: Minecraft Wiki*

[333px|缩略图|使用自定义生成设置在[[主世界](File:Warped Forest Overworld.png.md)生成的[诡异森林](诡异森林.md)生物群系]]
* *自定义（Custom）**是一种[世界类型](世界类型.md)，允许玩家更改主世界、下界和末地的生成设置并添加新维度，可以通过修改在世界选项界面中导出的[JSON](JSON.md)文件来实现。

# 访问
自定义世界生成需使用JSON文件进行，创建世界时可以导入这些文件。玩家也可以随时从已有世界中导出这些JSON文件。

在[创建新的世界](创建新的世界.md)菜单中，进入“更多选项”界面，点击“导入世界”按钮，选择用于自定义世界生成的JSON文件。如果JSON文件中包含有非默认的生成设置，那么此时会弹出一个警告弹窗，警告该功能目前还处于**实验性阶段**；点击“是”以继续，然后设置界面中世界类型变成了不可更改的“自定义”，即导入设置成功。

在世界的“编辑世界”屏幕，可以选择导出设置，设置文件位于存档的下。

访问自行添加的维度的唯一方法是通过命令，比如，这会将玩家传送到指定的维度。

{{collapse|title=JSON内容|content=
<syntaxhighlight lang="json" style="display:table;">
{
  "seed": 0,
  "bonus_chest": false,
  "generate_features": false,
  "dimensions": {
    "minecraft:overworld": {
      "type": "minecraft:overworld",
      "generator": {
        "type": "minecraft:debug"
      }
    }
  }
}
</syntaxhighlight>
}}

# = 自定义超平坦维度 =

  "generator": {
    "type": "minecraft:flat",
    "settings": {

        "minecraft:villages"
      ],
      "layers": [
        {
          "height": 5,
          "block": "minecraft:basalt"
        },
        {
          "height": 4,
          "block": "minecraft:coarse_dirt"
        },
        {
          "height": 1,
          "block": "minecraft:grass_block"
        }
      ],
      "biome": "minecraft:plains"
    }
  }
}
</syntaxhighlight>
}}
