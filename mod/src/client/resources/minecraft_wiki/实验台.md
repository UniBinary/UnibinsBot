# 实验台

*页面ID: 34358* | *来源: Minecraft Wiki*

* *实验台（Lab Table）**是一个用于[化学](化学.md)的[方块](方块.md)，在其中组合[元素](元素.md)和[化合物](化合物.md)可以合成产品。

# 生成
实验台不会生成在世界中。

# 获取
实验台不能在生存模式中正常获得，但可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)获得。

# 破坏
挖掘实验台的合适工具是镐。

实验台被破坏后会掉落自身。

# 用途
[缩略图](File:LabTableBeaker.gif.md)
[缩略图](File:LabTableFlask.gif.md)
[缩略图](File:LabTableJar.gif.md)
实验台中有9个输入槽。将[元素](元素.md)和[化合物](化合物.md)放入槽内后，点击“合成”按钮后产品就会出现在台上。此后页面就会关闭，以便于玩家观察实验结果。

如果组合出了可合成的产品，页面顶部图像就会播放动画。元素和化合物的摆放顺序不会影响结果。如果组合的材料不能合成产品，点击“合成”后实验台上会出现一个[废物](废物.md)，并且出现燃烧、爆炸、附魔台符文或“[大象牙膏](大象牙膏.md)”[粒子](粒子.md)，实验台的顶部可能会因此着火。当实验台顶部着火时，实验台将无法使用。
