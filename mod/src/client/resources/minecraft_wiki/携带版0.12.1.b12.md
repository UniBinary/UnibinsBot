# 携带版0.12.1.b12

*页面ID: 17992* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.12.1 alpha build 12**是[v0.12.1 alpha](携带版0.12.1.md)的第12个测试版，发布于2015年8月28日<ref></ref>，修复了一些漏洞。

# 更改
* [钓鱼竿](钓鱼竿.md)现在发出更少重复的声音。
* 挖掘和行走的声效更类似Java版。
* [蠹虫](蠹虫.md)在移动时不再发出声音。
* [骷髅](骷髅.md)和[凋灵骷髅](凋灵骷髅.md)现在有新的死亡音效。
* 下界中的[熔岩](熔岩.md)现在流动方式类似Java版。
* [甜菜汤](甜菜汤.md)现在可回复而不是。
* 致命攻击散发的粒子更多了。
* [僵尸猪人](僵尸猪人.md)现在攻击铁傀儡。
* 僵尸[刷怪蛋](刷怪蛋.md)现在有概率生成[僵尸村民](僵尸村民.md)。
* [活板门](活板门.md)现在可以在方块上方或下方放置。
* [火把](火把.md)现在能放置在[下界砖栅栏](下界砖栅栏.md)上了。

# 修复

* *其他**
* 史莱姆的音效不正确。
* 箱子的开裂纹理只显示在一边。
* 破坏两格高的植物不会使得设备震动。
* 箱子在使用后不会关闭。
* 骷髅的持弓姿势不正确。
* 物品的魔咒在客户端和服务端之间不同步。
* 打开切石机界面时游戏崩溃。
* 钓鱼时获得无限数量的墨囊。
* 浮漂在鱼咬钩后不会下沉。
* 收割甜菜时发出石头的音效。
* 多人游戏下破坏两格高的植物出现显示错误。
* 末影人不会躲开箭。
* 狼会攻击玩家攻击过的猫。
* 被雪覆盖的冰不会使得玩家加速。
* 铁傀儡或雪傀儡可以被玩家推进墙里。
* 活板门会使生物窒息。
* 苦力怕在被打火石点燃时不会闪烁。
* 在栅栏上激活的TNT的爆炸范围太小。
* 苹果不会从枯萎的树叶上掉落。
* 第三人称模式下的玩家持弓姿势错误。
* 第三人称模式下的玩家持甘蔗姿势错误。</onlyinclude>
