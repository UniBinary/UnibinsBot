# 携带版0.12.0.1

*页面ID: 21164* | *来源: Minecraft Wiki*

* *v0.12.0.1 alpha**是携带版的一次次要更新，发布于2015年8月11日<ref>https://web.archive.org/web/20150813225008/https://www.mojang.com/2015/08/windows-10-edition-beta-0-12-2-0/</ref>。此版本修复了一些在Windows 10版[v0.12.0 alpha](携带版0.12.0.md)的漏洞，同时也包含了对x86/32位系统的支持。

# 更改
# = 方块 =
* *[铁砧](铁砧.md)**
* 改进了GUI。
* * 当修复或命名时可以使用主要GUI。
* * 可在第二个槽中放置[物品](物品.md)。

* *[下界砖台阶](下界砖台阶.md)**
* 现在可以合成。

# = 游戏内容 =
* *[疾跑](疾跑.md)**
* 修改了疾跑动作以近似匹配[Java版](Java版.md)。

# = 常规 =
* *窗口**
* 可以启用全屏。

* *存档**
* 创造世界存档可以导入到试用版。

* *[聊天](聊天.md)**
* 可以在[船](船.md)上聊天。

* *其他更改**
* 现在支持x86处理器架构和32位系统。

# 修复
* *修复了10个漏洞**
* 修复了"种群恢复"成就的获得方法。
* 修复下界与超平坦世界生物的生成/再生。
* 修正开采绿宝石矿的镐限制。
* 修复自定义皮肤选项卡。
* 修复在一些地方写告示牌会导致游戏崩溃的问题。
* 修复熔炉和箱子不工作的问题。
* 修复玩家进入或离开下界时崩溃的问题。
* 修复音频文件。
* 修复玩家名称为非ASCII码时崩溃。
* 修复保存世界的问题。
