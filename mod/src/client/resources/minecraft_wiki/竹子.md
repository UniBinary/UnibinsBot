# 竹子

*页面ID: 36739* | *来源: Minecraft Wiki*

* *竹子（Bamboo）**是一种能在[丛林](丛林.md)和[竹林](竹林.md)里找到的[植物](植物.md)。

* *竹笋（Bamboo Shoot）**是由竹子物品种植出的植株方块。

# 生成
竹笋不会生成在世界中。

竹笋和竹子能够生成竹子，并将竹笋变为竹子（见）。

# = 自然生成 =
竹子大量且密集地生成于[竹林](竹林.md)生物群系中。

竹子还会以单根的形式广泛生成于[丛林](丛林.md)生物群系中。

# 破坏
挖掘竹子的合适工具是斧和剑。竹子被剑挖掘时会立刻被破坏。

挖掘竹笋的合适工具是剑。竹笋被剑挖掘时会立刻被破坏。

竹子和竹笋被破坏后会掉落1个竹子。

# 用途
[缩略图|竹子生长的不同阶段](File:Bamboo stages.png.md)

竹子的外观随着它的生长而变化。对着方块上表面竹子物品将放置竹笋，竹笋没有[碰撞箱](碰撞箱.md)。长高一格时其会变为2×2像素的竹子，且最顶部的竹子会出现叶子。在3格高时，顶端的2格竹子有叶子。在4格高时，竹子扩展到3×3像素，同时顶端的3格竹子都有叶子。随着竹子的生长，叶子会向上移动并停留在顶端的3格竹子。破坏一格竹子并不会影响其下方竹子的外观。

竹子放置出时会有随机偏移，而不是位于该方块空间的正中心，这个偏移只与方块的水平位置有关。竹子的碰撞箱会与其宽度一同改变。

竹子被破坏时，自身及上方的所有竹子都会被破坏并掉落。竹笋会被流动的水冲毁，但竹子不会。

不同于大多数植物，竹子不能用于[堆肥](堆肥.md)。

# = 生长 =

竹子可以种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[沙砾](沙砾.md)、[可疑的沙砾](可疑的沙砾.md)、[沙子](沙子.md)、[红沙](红沙.md)和[可疑的沙子](可疑的沙子.md)上，也能种植在竹子和竹笋上，只有当竹子中的最高一格或竹笋上方一格的[亮度](亮度.md)等级≥9，且上方一格为空气方块时，竹子和竹笋才会生长。

竹子是Minecraft中生长速度最快的植物。某株竹子中的最高一格收到随机刻更新后，该株竹子有的概率长高一格，因此在默认的随机刻速度下，每株竹子平均每生长一次。竹子最多只可以长到12-16格高；高于11格时，竹子每次生长都有的概率终止后续生长，且在达到16格时必定会终止后续生长；破坏植株上的任意一格竹子都可能改变其生长高度。

对未终止生长的竹子[骨粉](骨粉.md)可使其向上生长1-2格。

# = 嫁接 =
在已完成生长但高度低于15格的竹子顶部放置竹子，可使放置出的部分继续生长，但同样不超过16格。额外生长的部分会有自己的叶子，原植株顶部的两个方块中的较高的一格标签从退化为，较低的一格从、退化为；较高的一格标签从退化为，较低的一格从、退化为。

在竹笋顶部放置竹子，会将竹笋变成竹子。

# = 熊猫 =
[熊猫](熊猫.md)会捡起掉落的竹子[物品](物品.md)并吃掉。

竹子可用于吸引和繁殖熊猫。当或时，此时喂食竹子可使其繁殖出幼年熊猫。给幼年熊猫喂食竹子可加速其成长，每次减少10%的剩余成长时间。

# = 燃料 =
竹子可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个竹子可烧炼0.25个[物品](物品.md)。

# = 花盆 =
竹子可以种植在[花盆](花盆.md)内。
