# Java版21w10a

*页面ID: 80263* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w10a**是[Java版1.17](Java版1.17.md)的第13个快照，发布于2021年3月10日<ref></ref>，加入了[繁茂洞穴](繁茂洞穴.md)和新的[深板岩](深板岩.md)变种，更新了[着色器](着色器.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[裂纹深板岩砖](裂纹深板岩砖.md)**
* [深板岩砖](深板岩砖.md)的裂纹变种。
* 可通过烧炼深板岩砖获得。

* *[裂纹深板岩瓦](裂纹深板岩瓦.md)**
* [深板岩瓦](深板岩瓦.md)的裂纹变种。
* 可通过烧炼深板岩瓦获得。

* *[虫蚀深板岩](虫蚀深板岩.md)**
* [深板岩](深板岩.md)的虫蚀变种。

* *[深层绿宝石矿石](深层绿宝石矿石.md)、[深层铜矿石](深层铜矿石.md)、[深层煤矿石](深层煤矿石.md)**
* 绿宝石矿石、铜矿石和煤矿石的深层变种。
* 不会自然生成，加入游戏只是为了地图和数据包制作者使用。
* 可以像普通矿石一样被烧炼，类似于其他深层矿石。

# = 世界生成 =
* *[杜鹃树](杜鹃树.md)**
* 一种[树木](树木.md)，自然生成于繁茂洞穴生物群系的地表部分。
* 由[橡木原木](橡木原木.md)、[杜鹃树叶](杜鹃树叶.md)和[盛开的杜鹃树叶](盛开的杜鹃树叶.md)组成。
* 原木下方会生成[缠根泥土](缠根泥土.md)团簇；其所正对的繁茂洞穴洞顶会生成[垂根](垂根.md)。

* *[繁茂洞穴](繁茂洞穴.md)**
* 新的[生物群系](生物群系.md)，以多种洞穴植物为特征。
* * 洞顶和地面由[苔藓块](苔藓块.md)覆盖，[覆地苔藓](覆地苔藓.md)也在洞穴内密布。
* * [孢子花](孢子花.md)和[洞穴藤蔓](洞穴藤蔓.md)在洞穴顶部生长。
* * 地面会生成由[黏土](黏土.md)、[水](水.md)、[大型垂滴叶](大型垂滴叶.md)和[小型垂滴叶](小型垂滴叶.md)组成的[多叶黏土层](多叶黏土层.md)。
* * [杜鹃花丛](杜鹃花丛.md)、[盛开的杜鹃花丛](盛开的杜鹃花丛.md)和杜鹃树会在此生成。
* * 目前不会自然生成在常规的世界中，仅能通过在[自选世界](自选世界类型.md)界面中选择“繁茂洞穴”生物群系，或是选用[自定义](自定义.md)世界类型等方式生成。

# = 常规 =
* *[着色器](资源包#着色器.md)**
* 加入了支持所有渲染状态的着色器。
* 除去位块传送（blit）着色器之外的任意着色器均可被资源包中的着色器替换。
* 目前并未加入对替换着色器的官方支持，且将来其工作方式可能改变。
* 目前的渲染引擎采用类似后处理渲染管线的系统。两种系统之间因需求略有不同而存在一些差异。
* *[标签](Java版标签.md)**
* 加入了方块和物品标签。
* * 应用于对应的普通和深层变种。
* 加入了方块标签。
* * 应用于方块标签、黏土和苔藓块。

# 更改
# = 方块 =
* *[深板岩圆石](深板岩圆石.md)及对应的[楼梯](楼梯.md)、[台阶](台阶.md)和[墙](墙.md)变种**
* 更改了纹理。
* 现在深板岩圆石可被烧炼成[深板岩](深板岩.md)。

* *[深板岩](深板岩.md)**
* 更改了顶部和底部纹理。
* 现在可沿不同坐标轴方向放置，且自然生成时朝向是随机的。

* *[深板岩砖](深板岩砖.md)和[深板岩瓦](深板岩瓦.md)**
* 现在拥有合成配方了。

* *[矿石](矿石.md)**
* 更改了[煤矿石](煤矿石.md)、[铁矿石](铁矿石.md)、[金矿石](金矿石.md)、[钻石矿石](钻石矿石.md)、[深层铁矿石](深层铁矿石.md)、[深层金矿石](深层金矿石.md)、[深层钻石矿石](深层钻石矿石.md)、[深层青金石矿石](深层青金石矿石.md)和[深层红石矿石](深层红石矿石.md)的纹理。
* * 铁矿石和深层铁矿石不再具有条形矿粒纹理。
* * 现在钻石矿石的矿粒纹理更接近深层钻石矿石。

# = 物品 =
* *[望远镜](望远镜.md)**
* 物品形式重新变为2D，且使用新的物品纹理。
* * 被持在手中时仍会展示3D的模型，类似于[三叉戟](三叉戟.md)。

# = 生物 =
* *[史莱姆](史莱姆.md)**
* 现在最大生成尺寸是128。

# = 世界生成 =
* *[化石](化石.md)**
* 在深板岩层中生成的化石会夹杂[深层钻石矿石](深层钻石矿石.md)而非此前的[煤矿石](煤矿石.md)。

* *[裂隙](裂隙.md)**
* 现在变得更加罕见。

[450px|thumb|矿石分布变化](File:21w10a approximate ore distribution.png.md)
* *[矿石](矿石.md)分布**
* 再次调整了矿石分布。
* * 提高了[山地](山地.md)的[绿宝石矿石](绿宝石矿石.md)生成频率。
* * 提高了[青金石矿石](青金石矿石.md)的生成频率。
* * 降低了[铜矿石](铜矿石.md)、[金矿石](金矿石.md)和[红石矿石](红石矿石.md)的生成频率。
* * 缩小了[钻石矿石](钻石矿石.md)的矿脉规模，同时略微提高了生成频率。钻石矿石的总生成量与之前相比略微下降。
* * 降低了[铁矿石](铁矿石.md)的生成频率，同时调低了分布范围。
* ** 较深处等量生成的铁矿石的生成范围从Y=-64到-8改为Y=-64到-32。
* ** 稍高处不等量生成的铁矿石的生成范围从Y=-16到80（32处最多）改为Y=-24到56（16处最多）。
* * 减少了裸露[煤矿石](煤矿石.md)的生成。

# = 常规 =

* *游戏运行库**
* 游戏现在基于OpenGL 3.2 core profile运行。
* * 这意味着要想运行游戏，显卡必须支持统一渲染架构（USM），包括Nvidia 8系列及以后的显卡、AMD/ATI HD 2000系列及以后的显卡、AMD 760G及以后的、以及Intel Ivy Bridge/Bay Trail以后的。由于驱动原因，基于Sandy Bridge架构的Intel CPU可能可以在macOS及Linux下运行游戏，但可能无法在Windows下运行游戏。
* * 这是Java版第四次更改OpenGL运行库版本，上次为[14w06a](14w06a.md)。
* * 由于运行库更新，此版本可能在部分机器上存在较不明显的显示问题。

* *[闪烁标语](闪烁标语.md)**
* 将闪烁标语“OpenGL 2.1 (if supported)!”改为“Now on OpenGL 3.2 core profile!”。

* *[字幕](字幕.md)**
* [荧光物品展示框](荧光物品展示框.md)现在使用独立的字幕，而不再和普通物品展示框共用同一组字幕。

* *[标签](Java版标签.md)**
* 方块标签里移除了苔藓块、方块标签、草丛、高草丛、覆地苔藓、小型垂滴叶、大型垂滴叶、大型垂滴叶茎和藤蔓。
* 移除了方块标签。
