# PlayStation 4版1.93

*页面ID: 59651* | *来源: Minecraft Wiki*

* *1.93**是[PlayStation 4版](PlayStation 4版.md)的一个更新，发布于2019年6月25日，修复了一些漏洞。<ref></ref>

# 新内容
# = 常规 =
* *[混搭包](混搭包.md)**
* 加入了《玩具总动员》混搭包。

# 修复
* *修复了8个漏洞**
* 修复了在村庄附近时发生的崩溃。
* 修复了当玩家从下界进入主世界时发生的崩溃。
* 修复了村民在保存/补货后有概率改变交易的问题。
* 修复了缩放地图后会给你一个远离你当前位置的地图。
* 修复了铁傀儡不会在加载过的村庄里生成。
* 修复了箱子分开作为单独箱子时发挥作用。
* 修复了石台阶的配方在经典合成中不正确。
* 修复了村民在一个玩家在末地或下界交易。
