# Java版21w11a

*页面ID: 80666* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w11a**是[Java版1.17](Java版1.17.md)的第14个快照，发布于2021年3月17日<ref></ref>，完善了铜块锈蚀的相关特性，加入了与铜块相关的粒子，并修复了纹理和相关问题为主的大量漏洞。

# 新内容
# = 常规 =
* *[控制](控制.md)**
* 加入了生成、性能分析数据的快捷键。
* * 数据文件保存在<samp>[.minecraft](.minecraft.md)/debug/profiling/<*时间戳*>.zip</samp>

* *[粒子](粒子.md)**
* 加入了新的粒子：、、和。

* *[标签](Java版标签.md)**
* 加入了物品标签。
* * 包含所有的镐。

# 更改
# = 方块 =
* *[紫水晶簇](紫水晶簇.md)**
* 现在使用木、石、金[镐](镐.md)破坏也会掉落4个[紫水晶碎片](紫水晶碎片.md)，使用除镐以外的方式破坏则只会掉落2个[紫水晶碎片](紫水晶碎片.md)。

* *[杜鹃花丛](杜鹃花丛.md)**
* 现在可被用作[熔炉](熔炉.md)的[燃料](燃料.md)，每个可烧炼0.5个物品。

* *[大型垂滴叶](大型垂滴叶.md)**
* 现在破坏大型垂滴叶茎也会掉落大型垂滴叶。

* *[氧化](氧化.md)**
* 现在对铜块、切制铜块、[切制铜台阶](切制铜台阶.md)、[切制铜楼梯](切制铜楼梯.md)及其斑驳与锈蚀变种[蜜脾](蜜脾.md)可对其涂蜡，同时产生黄色的粒子效果。
* * 装有蜜脾的[发射器](发射器.md)被激活后也可以为其前方的铜块涂蜡。
* 现在对铜块[斧](斧.md)可以脱蜡或除锈，分别产生白色和铜绿色的粒子效果。
* * 每次操作使锈蚀程度减轻一级。
* * 若是涂蜡变种则优先进行脱蜡。
* 现在被[闪电](闪电.md)击中可以减轻锈蚀程度。
* * 锈蚀的减轻程度及其概率随与闪电击中点距离的增加而降低。
* 现在涂蜡的铜块可被分解为4个[铜锭](铜锭.md)。

* *[酿造台](酿造台.md)**
* 更改了GUI中的药水图标使之契合纹理更新后的玻璃瓶纹理。
* 移除了GUI中多余的像素点。

* *[炼药锅](炼药锅.md)**
* 现在对装满对应物体的炼药锅[熔岩桶](熔岩桶.md)或[细雪桶](细雪桶.md)会将该桶倒空。

* *[洞穴藤蔓](洞穴藤蔓.md)**
* 将“Cave Vines Head”和“Cave Vines Body”分别改名为“Cave Vines”和“Cave Vines Plant”，同时也更改了ID。
* 现在其尖端会发出14级的光，而不是10级。
* 现在会使穿过它的玩家减速。
* 现在可以攀爬。

* *[镶金黑石](镶金黑石.md)**
* 更改了纹理。

* *[发光地衣](发光地衣.md)**
* 现在如果无法扩散，则不能对其使用骨粉。
* 现在可用于[堆肥](堆肥.md)。
* * 将其放进堆肥桶有50%的概率使堆肥层数加1。

* *[草方块](草方块.md)**
* 更改了覆雪时侧面的泥土纹理。

* *[垂根](垂根.md)**
* 现在模型的渲染位置会有随机偏移。
* 移除依附的方块不再可使其浮空。

* *[避雷针](避雷针.md)**
* 现在属于可[含水](含水.md)方块。
* 被闪电击中时会完全变白。
* 现在当[方块状态](方块状态.md)为“true”时，将显示为全白的纹理。
* 和雨接触时会发出粒子。

* *[讲台](讲台.md)**
* 更改了模型。

* *[苔藓块](苔藓块.md)**
* 现在可与[圆石](圆石.md)或[石砖](石砖.md)合成为其对应的生苔变种。
* * 苔石和苔石砖原有的合成配方未移除。
* 除[斧](斧.md)外，现在使用[锄](锄.md)也可以加速破坏。

* *[南瓜](南瓜.md)**
* 更改了南瓜顶部纹理的一个像素点，以避免摆放时可能出现的[卐字](wzh:卐字.md)图案。

* *[缠根泥土](缠根泥土.md)**
* 现在对其[骨粉](骨粉.md)会使其底部长出垂根。

* *[告示牌](告示牌.md)**
* 更改了所有主世界木质告示牌的纹理，使之契合[纹理更新](纹理更新.md)后的木板纹理。

* *[小型垂滴叶](小型垂滴叶.md)**
* 小型垂滴叶的朝向现在取决于玩家摆放该方块时面朝的方向。

* *[烟熏炉](烟熏炉.md)**
* 更改了顶部纹理。

* *[孢子花](孢子花.md)**
* 移除孢子花依附的方块不再会使其浮空。

* *[遮光玻璃](遮光玻璃.md)**
* 不再使生物窒息。
* 现在生物无法在其上面生成。

# = 物品 =
* *[丛林木门](丛林木门.md)**
* 更改了物品纹理。

* *[甘蔗](甘蔗.md)**
* 更改了物品纹理。

# = 生物 =
* *[猫](猫.md)**
* 更改了暹罗猫的纹理。

* *[守卫者](守卫者.md)和[远古守卫者](远古守卫者.md)**
* 移除了纹理文件当中多余的像素。

* *[村民](村民.md)和[僵尸村民](僵尸村民.md)**
* 更改了图书管理员变种的纹理。

# = 非生物实体 =
* *[画](画.md)**
* 更改了背面的纹理，使之契合纹理更新后的木板纹理。

* *[光灵箭](光灵箭.md)**
* 射出的光灵箭现在是金色的，和物品纹理。

# = 世界生成 =
* *[洞穴](洞穴.md)**
* 调整了洞穴的大小。

* *[繁茂洞穴](繁茂洞穴.md)**
* 减少了浮空水的生成。

* *[矿石](矿石.md)分布**
* 略微提高了[钻石矿石](钻石矿石.md)团簇的生成频率。

* *[超平坦世界](超平坦世界.md)**
* 现在[填充层](填充层.md)以世界最低建筑高度为起始高度进行放置，而不是之前那样使用Y=0。

# = 游戏内容 =
* *[冰冻](冰冻.md)**
* 极限模式下的冰冻心现在使用独立的纹理。

* *[旁观模式](旁观模式.md)**
* 旁观模式下的玩家现在可在[熔岩](熔岩.md)和[细雪](细雪.md)当中透视。

* *[字幕](字幕.md)**
* 加入了紫水晶“chime”音效的字幕。
* 加入了为铜块涂蜡和脱蜡的字幕。
* * 由于存在漏洞，这些字幕暂时无法触发。<ref name="subtitle"></ref>
* 将为原木和木头去皮的字幕由“Axe scrapes”更改为“Axe strips”。
* * 将字幕“Axe scrapes”改用于铜块，但由于存在漏洞，该字幕暂时无法触发。<ref name="subtitle"/>

# = 常规 =
* *[标签](Java版标签.md)**
* 将洞穴藤蔓和洞穴藤蔓植株加入到方块标签当中。
* 将凝灰岩加入到方块标签当中。
* 将遮光玻璃加入到方块标签当中。
* 将凝灰岩从方块标签当中移除。
