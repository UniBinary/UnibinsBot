# Java版1.16-pre2

*页面ID: 63604* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.16-pre2**是[Java版1.16](Java版1.16.md)的第2个预发布版，发布于2020年6月5日<ref></ref>，修复了一些漏洞。

# 更改
# = 世界生成 =
* *浮岛**
* [守卫者](守卫者.md)和[掠夺者](掠夺者.md)现在可以正确地在浮岛世界类型中生成了。

* *[村庄](村庄.md)**
* [“Jellie”猫](猫.md)现在会在村庄中随世界生成而自然生成了。

* *[维度](维度.md)**
* 进入一个未知的维度（由禁用一个加入了指定维度的[数据包](数据包.md)导致）现在会将玩家置于[主世界](主世界.md)的相同坐标处。
