# 海带

*页面ID: 33662* | *来源: Minecraft Wiki*

</ref>||Jasper Boerstra Mojang avatar.png}}
* *海带（Kelp）**是一种生成于大部分[海洋](海洋.md)生物群系的可生长的非固体[植物](植物.md)方块。其物品形式可以被烹饪成[干海带](干海带.md)。

是海带下方的茎杆部分。

# 生成
海带能够生成海带和海带植株（见）。

# = 自然生成 =
海带和海带植株会自然生成于除[暖水海洋](暖水海洋.md)、[冻洋](冻洋.md)和[冰冻深海](冰冻深海.md)外的所有[海洋](海洋.md)生物群系，常和[海草](海草.md)一起生成。每一个[区块](区块.md)有的概率自然生成海带植物。

# 破坏
海带和海带植株被挖掘时会立刻被破坏，用于挖掘的工具的耐久度不会下降。

海带和海带植株被破坏后会掉落1个海带。

# 用途
海带可以被放置于上表面[方块支撑形状](判定箱#方块支撑形状.md)完整（[岩浆块](岩浆块.md)除外）的方块上。玩家放置的海带拥有0到或间随机的<code>age</code>值。海带只能被放置于水源或向下流动的水中，不能放在水平流动的水中。

除了作为装饰外，海带可以把向下流动的水转换成水源。任何建筑[方块](方块.md)都可以被放置在海带植株的顶端。

破坏海带植株会摧毁植株其上方所有海带植株和海带。

# = 堆肥 =
将海带放入[堆肥桶](堆肥桶.md)中，会有30%的概率增加一层堆肥层。

# = 生长 =

海带可在多种方块上种植，但必须在水下，其上方一格为水源或流动的水时才会生长。当其上方一格为流动的水时，海带会在生长至这一格时将其转化为水源。玩家或发射器皆不能移除生长有海带的水方块，除非先破坏其内的海带。

海带的生长没有光照等级的要求，它们可以在完全黑暗的环境中生长。它们也不需要露天的空间。对海带骨粉可使其生长一格。

自然生成的海带拥有20-23的值，玩家放置的海带拥有或的值，使用命令放置的海带的默认为0，来查看|JE}}。海带生长时，新长出的海带的值增加1，海带值为25时不再生长，也就说海带可以生长的长度介于2（当底部海带的值为24）至26（当底部海带的值为0）之间。而海带只能自然生长到15格。

当海带被破坏时，其下方的海带植株会变为随机<code>age</code>值的海带。

海带每次接受[随机刻](刻#区块刻.md)尝试生长时会有14%的概率成功。

# = 种植 =

尽管海带必须种植在水中，但其自动化种植与[甘蔗](甘蔗.md)十分相似。由于物品会在水中上浮，其自动化收集更加简单。

# = 阻止生长 =
对海带的顶部[剪刀](剪刀.md)可使海带的或状态变为25，阻止其继续生长。
