# 滴水石（消歧义）

*页面ID: 111277* | *来源: Minecraft Wiki*

* *滴水石（Dripstone）**可以指：
# 方块
*  - 一种构成钟乳石、石笋和石柱的方块。
*  - 一种可用于培育滴水石锥的岩石方块。

# 生物群系
*  - 一种充满滴水石块和滴水石锥的洞穴生物群系。

# 地物
*  - 一类在溶洞中常见的地物，由滴水石锥和滴水石块组成。
