# 携带版0.11.0.b3

*页面ID: 28049* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 3**是[v0.11.0 alpha](携带版0.11.0.md)的第3个测试版，发布于2015年4月14日，加入了洞穴蜘蛛刷怪蛋，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了[洞穴蜘蛛](洞穴蜘蛛.md)刷怪蛋。

# 更改
# = 方块 =
* *[熔炉](熔炉.md)**
* 现在会放出堆叠的物品而不是将其简单地拆分。

# 修复

* *其他漏洞**
* 摧毁AddEntityPacket时游戏崩溃。
* 同时浏览两个皮肤选择窗口时游戏崩溃。
* 在一定情况下，破坏带有物品的熔炉使得游戏崩溃。
* 进入世界时，云的渲染机制使得游戏崩溃。
* 修复了多个由代码漏洞导致的游戏崩溃。
* 末影人的愤怒动画只会在客户端中显示。
* 腿部模型不会正常放大或缩小。
* 部分翻译字符串会被代码原文取代。
* 实体在移动时不会发生相应的数据包。
* 创造模式下，活动的玩家使得下落的方块不会变成掉落物。
* 修复了数据包的接收漏洞（和批处理有关）。</onlyinclude>
