# Java版18w07b

*页面ID: 33645* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w07b**是[Java版1.13](Java版1.13.md)的第19个快照，发布于2018年2月15日<ref></ref>，加入了新的标签，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* *[标签](Java版标签.md)**
* 加入了方块标签：<code>minecraft:waterlogged</code>。
* 加入了方块和物品标签：<code>minecraft:rails</code>和<code>minecraft:sand</code>。

# 更改
# = 方块 =
* *[干海带块](干海带块.md)**
* 干海带块现在可燃了。

* *[海草](海草.md)和[海带](海带.md)**
* 生物不能在[海带](海带.md)或[海草](海草.md)中生成或者补充呼吸了。

* *[气泡柱](气泡柱.md)**
* 减慢了气泡柱里物品向上移动的速度。

# = 物品 =
* *[鳞甲](鳞甲.md)**
* 将“海龟壳片（Turtle shell piece）”重命名为“鳞甲（Scute）”。

# = 生物 =
* *[海龟](海龟.md)**
* 繁殖[海龟](海龟.md)现在需要[海草](海草.md)而非生鳕鱼。<ref></ref>

# = 游戏内容 =
* *[呼吸](呼吸.md)**
* 生物在可以呼吸时，氧气值每刻恢复，而不是立即恢复到最大值。
