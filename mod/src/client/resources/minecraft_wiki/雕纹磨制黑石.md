# 雕纹磨制黑石

*页面ID: 99474* | *来源: Minecraft Wiki*

* *雕纹磨制黑石（Chiseled Polished Blackstone）**是[磨制黑石](磨制黑石.md)制作的装饰性方块，每个面都有着猪鼻图案。

# 生成
# = 自然生成 =
雕纹磨制黑石作为[堡垒遗迹](堡垒遗迹.md)和下界的[废弃传送门](废弃传送门.md)的一部分自然生成。

# 破坏
挖掘雕纹磨制黑石的合适工具是镐。雕纹磨制黑石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

雕纹磨制黑石被破坏后会掉落自身。

# 用途
雕纹磨制黑石目前仅用于装饰。
