# 基岩版1.21.60.24

*页面ID: 138050* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.60.24**（ChromeOS/Android）、**Preview 1.21.60.24**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.60](基岩版1.21.60.md)的第3个测试版，发布于2024年12月12日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[水](水.md)和[熔岩](熔岩.md)**
* 现在流动受随机刻影响。

# = 物品 =
* *[树脂砖](树脂砖.md)**
* 不再可以在[林地府邸](林地府邸.md)的战利品箱中找到。
* 将[树脂团](树脂团.md)烧炼为树脂砖时给予的经验值由0.3减少至0.1。

# = 世界生成 =
* *[峡谷](峡谷.md)**
* 现在会更频繁地生成。

# = 游戏内容 =
* *[睡觉](睡觉.md)**
* 更改了不能跳过夜晚时显示的消息。

* * 新表述：

* ** 对于世界拥有者：“”

# = 常规 =
* *[创建新的世界](创建新的世界.md)**
* 将“”选项重命名为“”。

* *[设置](设置.md)**
* 在设置中加入了与[Realms](Realms.md)功能相关的额外调试信息。

* *[暂停菜单](暂停菜单.md)**
* 现在多人游戏面板顶部会显示“*世界名称* ”文本。

# = 技术性 =
* *方块**
* 修复了旧的数据驱动方块不会应用来自材质实例组件的渲染层的问题。
* 修复了会出现虚假的内容日志错误的问题。
* 门现在使用方块状态，而不是。该状态使用字符串值。
* 将组件从为1.21.60及更高版本的即将推出的创作者功能实验性内容中移出。

* *碰撞**
* 没有碰撞箱但带有组件的实体不再会有时无法交互。

* *组件**
* 公开了组件，以允许将属性继承给子代实体。
* * 加入了新的字段，用于获取属性名称键入的对象。
* * 中的对象可以包含，用于给予其不应继承自亲代的概率。
* * 还可以包含数组，值在发生变异且组件拥有随机变异集时选择。

* *[基岩版编辑器](基岩版编辑器.md)**
* 将方块缩略图居中放置在快捷栏、方块选取器和列表中。
* 为编辑器方块图像加入了数据驱动渲染。
* * 为告示牌加入了方块名称别名。
* * 为协议加入了对命名空间方块名称的支持。
* 玩家模型现在会在工具模式下被完全隐藏。

* *迷雾**
* 修复了中的会在资源包堆栈的第一个内容上被忽略的问题。（）

* *游戏内容**
* 修复了在命令滥发消息时打开箱子会导致服务器崩溃的问题。

* *图形**
* 资源包中的单通道纹理现在会被解读为灰色，而不是红色。
* * 此更改不适用于单通道UI纹理，这类纹理已经被如此解读。
* JSON文件现在支持组件中的字段。
* * 此更改同时将（沼泽）和（暖水海洋）的地表不透明度恢复至最近引入JSON文件前的数值。

* *物品**
* 修复了非房主的客户端加入多人游戏时会缺失具有重复物品的包的图标的问题。

# 修复
* *成就**
* “”成就现在可以在嘎枝之心已生成嘎枝时通过破坏该嘎枝之心来解锁。

* *方块**
* 在苔藓块或苍白苔藓块上使用骨粉时生成的高草丛不再只会渲染其下半部分。（）

* *游戏内容**
* 船上的第二个乘客在向西旋转时不再会出现剧烈的相机视角抽搐。

* *物品**
* 更新了打开的收纳袋的纹理，以使其不再缺失一个抽绳像素。（）
* 树脂砖不再可以在林地府邸的箱子中找到。（）

* *生物**
* 现在由嘎枝之心生成的嘎枝会在重载世界时始终保持存在。（）
* 现在当生成其的嘎枝之心被破坏时，嘎枝的眼睛会正常闪烁。

* *Realms**
* 现在若可加入的好友世界是Realm世界而非可加入的Realm，则游玩屏幕的好友选项卡上会隐藏该世界。
* 修复了离开Realm管理屏幕后玩家权限不再会恢复至默认状态的问题。
* 修复了即使Realm拥有具有有效游戏模式的世界，Realm选项卡上的游戏模式也仍会显示为未知的问题。

* *性能与稳定性**
* 现在使Minecraft应用程序进入休眠状态并恢复后，Switch平台上的玩家会保持他们Microsoft账户的登录状态。

* *结构**
* 部分热带草原村庄不再会出现应为土径的坑洞。

* *用户界面**
* PlayStation®5：“启用屏幕阅读器”辅助功能设置现在用于在首次启动时初始化文本转语音。
* 修复了在玩家死亡前进入暂停屏幕时，游戏可能会在某些情况下卡死的漏洞。

* *原版趋同**
* 嗅探兽蛋现在仅会在顶面和底面提供中心支撑。（）
* 现在可以在潜行时对洞穴藤蔓、海带、缠怨藤和垂泪藤使用剪刀。（）
* 现在对洞穴藤蔓、海带、缠怨藤和垂泪藤使用剪刀时会播放手臂摆动动画。（）
* 紧靠长出发光浆果的洞穴藤蔓放置水或熔岩时，水或熔岩不再会停留在世界中。
* 手持剪刀采集发光浆果时不再会同时进行采摘和修剪。（）
* 嗅探兽蛋不再会为任何方块提供侧面支撑。

* *世界生成**
* 嘎枝之心现在会在自然生成的苍白橡树中更频繁地生成。（）
* 峡谷现在再次可以延伸到地表。（）
* 峡谷现在再次可以生成在海底。
* 峡谷现在会穿过大型铜矿脉和其他大多数方块。（）
* 峡谷现在会与含水层正确相接，填充为水而非生成断开的片段。</onlyinclude>
