# Java版Infdev 20100327

*页面ID: 36013* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年3月27日。<ref></ref>

# 新内容
# = 常规 =
* *[选择世界菜单](选择世界菜单.md)**
* 点击“Single player”按钮可进入。
* 可以新建、加载和删除世界。
* 只能同时存档五个世界。

* *[生命](生命.md)**
* 玩家现在可以重生。

* *其他**
* 游戏现在会自动保存。

# 更改
# = 方块 =
* *[熔炉](熔炉.md)**
* 现在烧炼的速度更快了。
* * 现在烧炼一个物品仅需4秒而非8秒。

* *[花](花.md)**
* 不再自然生成。

# = 游戏内容 =
* *常规**
* 玩家生成时不再携带任何物品。
* 现在玩家死亡会重生在[出生点](出生点.md)，而不是强制使玩家重新载入最后一次保存。
* 现在玩家死亡后会导致其携带的[物品](物品.md)全部掉落。

# = 世界生成 =
* *[红砖块金字塔](红砖块金字塔.md)**
* 被移除。

* *[洞穴](洞穴.md)**
* 不再自然生成。

* *常规**
* 改进了地形生成器，让地形看起来更加真实。

# = 常规 =
* *[世界加载屏幕](世界加载屏幕.md)**
* 改进了世界保存界面。

* *[主菜单](主菜单.md)**
* “创建新的世界（generate new level...）”按钮现在被“单人游戏（single player）”按钮所取代，用于打开选择世界菜单。
* “加载世界（load level...）”按钮现在被“多人游戏（Multi player）”按钮所取代，但目前为不可用状态。
* 移除了控制[世界类型](Indev世界选项#世界类型.md)、[世界形状](Indev世界选项#世界形状.md)、[世界大小](Indev世界选项#世界大小.md)和[世界主题](Indev世界选项#世界主题.md)的对应的四个按钮。

* *存档格式**
* 世界格式从[Indev世界格式](Indev世界格式.md)升级到[Alpha世界格式](Alpha世界格式.md)。

# 修复
* *修复了1个漏洞**
* 游戏的性能不再逐渐降低。</onlyinclude>
