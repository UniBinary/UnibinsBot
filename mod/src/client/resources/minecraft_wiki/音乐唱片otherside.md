# 音乐唱片otherside

*页面ID: 156615* | *来源: Minecraft Wiki*

* *otherside**是一张[音乐唱片](音乐唱片.md)，可用于播放由[Lena Raine](Lena Raine.md)创作的同名曲目。

# 用途
# = 音乐 =

[noicon](File:Otherside.ogg.md)

Otherside是一段具有高扬欢快的大调复古风格旋律的音乐。

乐曲有清晰的鼓点和节奏，整体氛围轻松悠闲，而后歌曲转为小调，旋律略转向低沉，最后在时钟滴答作响的声音中戛然而止。

# = 红石 =

音乐唱片otherside放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为14的信号。
