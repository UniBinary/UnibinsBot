* *骆驼尸壳（Camel Husk）**是[骆驼](骆驼.md)的亡灵变种，外观呈现[尸壳](尸壳.md)般的黑褐色。

# 生成
[thumb|200px|一隻持有矛的屍殼與一隻焦骸騎在骆驼尸壳上](File:Camel Husk Jockey.png.md)
当[屍殼](屍殼.md)自然生成并且其生成空间可以容纳骆驼尸壳的[碰撞箱](碰撞箱.md)时，有10%的概率生成骆驼尸壳作为屍殼的坐骑，並同時生成一個[焦骸](焦骸.md)作為骆驼尸壳的第二個乘客，此时屍殼將手持[铁矛](铁矛.md)。这是骆驼尸壳唯一的自然生成方式。

骆驼尸壳会自然生成于沙漠生物群系。其自然生成时会同时生成一个手持矛的尸壳和一个焦骸，分别作为第一个和第二个乘客。骆驼尸壳不会在和平难度下自然生成。

# 行为

骆驼尸壳可以像骆驼那样上鞍，上鞍之后可以骑乘，骑乘时的行为和骆驼一致。

即使骆驼尸壳的乘客中仍然有[尸壳](尸壳.md)或[焦骸](焦骸.md)，这不会阻止玩家与骆驼尸壳的任何互动，玩家可以正常地骑乘。

与其他大多数生物不同的是，骆驼尸壳可以缓慢地恢复损失的生命值，其恢复速度和普通骆驼一样。

与骆驼不同，骆驼尸壳无法繁殖。

骆驼尸壳属于友好生物，但会占用怪物的[生物上限](生成#生物上限.md)。

# = 喂食 =
骆驼尸壳会跟随/手持[兔子脚](兔子脚.md)的玩家。

给骆驼尸壳喂食兔子脚可使其恢复点生命值。

# = 生物族群 =

骆驼尸壳是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，不被[凋灵](凋灵.md)攻击。

与多数亡灵生物不同，骆驼尸壳能够游泳，在任何情况下都不会沉入水底。

骆驼尸壳不会在阳光下[着火](着火.md)。
