# 音乐唱片Tears

*页面ID: 156631* | *来源: Minecraft Wiki*

* *Tears**是一张[音乐唱片](音乐唱片.md)，可用于播放由[Amos Roddy](Amos Roddy.md)创作的同名曲目。

# 获取
# = 恶魂 =
[恶魂](恶魂.md)被玩家反弹的[火球](火球.md)杀死后会额外掉落一张音乐唱片Tears。

# 用途
# = 音乐 =

[noicon](File:Tears.ogg.md)

Tears是一首由与[Pigstep](Pigstep.md)的风格相似的乐曲，时长2分55秒。

乐曲节奏强烈、节拍类似嘻哈风格、旋律狂野、空灵，时不时伴随着恶魂的叫声。

# = 红石 =

音乐唱片Tears放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为10的信号。
