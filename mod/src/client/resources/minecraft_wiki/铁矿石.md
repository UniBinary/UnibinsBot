# 铁矿石

*页面ID: 6468* | *来源: Minecraft Wiki*

* *铁矿石（Iron Ore）**是一种可以在地下找到的[矿石](矿石.md)方块，其成品[铁锭](铁锭.md)可用于制造各种工具和盔甲。

* *深层铁矿石（Deepslate Iron Ore）**是以[深板岩](深板岩.md)作为容矿岩的铁矿石变种。

# 生成
# = 自然生成 =
# == 矿团 ==
铁矿石会以[矿团](矿团.md)的形式生成于[主世界](主世界.md)Y=-64至72、以及80至320高度范围内的石头之间，不同高度生成情况不同。

生成于[深板岩](深板岩.md)或[凝灰岩](凝灰岩.md)间的铁矿石会被替换为深层铁矿石。

# == 矿脉 ==
在Y=-60至-8的高度范围间，铁矿石还会在罕见的[铁矿脉](铁矿脉.md)中伴随凝灰岩生成。

# 获取
铁矿石和深层铁矿石只能通过破坏对应方块获得。

# 破坏
挖掘铁矿石和深层铁矿石的合适工具是镐。铁矿石和深层铁矿石需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，铁矿石和深层铁矿石被破坏后会掉落1个[粗铁](粗铁.md)，挖掘工具的[时运](时运.md)魔咒会增加粗铁的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，铁矿石和深层铁矿石被破坏后会掉落自身。

# 你知道吗
* 现实中铁矿石的颜色有黑色（[磁铁矿](wzh:磁铁矿.md)）、红色（[赤铁矿](wzh:赤铁矿.md)）和金黄色（[黄铁矿](wzh:黄铁矿.md)）等，但没有与游戏中类似的米黄色。
