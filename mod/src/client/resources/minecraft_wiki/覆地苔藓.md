# 覆地苔藓

*页面ID: 77856* | *来源: Minecraft Wiki*

}}

* *覆地苔藓（Moss Carpet）**是一种有[苔藓块](苔藓块.md)纹理的装饰性方块，形态与[地毯](地毯.md)相同。

# 生成
# = 自然生成 =
覆地苔藓自然生成于[繁茂洞穴](繁茂洞穴.md)生物群系。

[红树](红树.md)生成时，覆地苔藓会生成在一些[红树根](红树根.md)之上。

覆地苔藓也可能会在试炼密室的“入口”结构中作为植物造景的一部分生成。

# = 骨粉 =
对着上方为空气的[苔藓块](苔藓块.md)[骨粉](骨粉.md)有15.625%的概率在其水平[切比雪夫半径](切比雪夫.md)3格，垂直[切比雪夫半径](切比雪夫.md)5格范围内随机生成覆地苔藓。

# 破坏
挖掘覆地苔藓的合适工具是锄。

覆地苔藓被破坏后会掉落自身。

# 用途
覆地苔藓的碰撞箱为格。

覆地苔藓可以放在任何非[空气](空气.md)方块上，包括[结构空位](结构空位.md)和[光源方块](光源方块.md)。

覆地苔藓可以放在[栅栏](栅栏.md)和[墙](墙.md)的顶部，使玩家能够在上面跳跃。

覆地苔藓无法被[活塞](活塞.md)拉动，并且伸出的[活塞头](活塞头.md)或流动的[水](水.md)经过覆地苔藓时会破坏覆地苔藓使其变成掉落物。

覆地苔藓是[光照透明方块](亮度#光照透明方块.md)。

# = 堆肥 =
将覆地苔藓放进[堆肥桶](堆肥桶.md)有30%的概率使堆肥层数加1。
