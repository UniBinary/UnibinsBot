# Java版12w22a

*页面ID: 32402* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w22a**是[Java版1.3.1](Java版1.3.1.md)的第8个快照，发布于2012年5月31日<ref></ref>，加入了绿宝石块以及绊线钩，加入了丛林神庙以及冒险模式，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[绿宝石块](绿宝石块.md)**
* 装饰性的储存方块，由9个[绿宝石](绿宝石.md)合成。

* *[绊线](绊线.md)和[绊线钩](绊线钩.md)**
* 线现在可以放置，变成绊线，如果绊线钩与它首尾相连的话，生物经过绊线会激活红石信号。

# = 命令格式 =
* 加入了。

# = 世界生成 =
* *[丛林神庙](丛林神庙.md)**
* 生成于丛林生物群系。
* 主要由[圆石](圆石.md)和[苔石](苔石.md)构成。
* 拥有发射器、绊线陷阱和战利品箱子。

# = 游戏内容 =
* *[冒险模式](冒险模式.md)**
* 新的游戏模式，只能通过切换。
* 玩家不能打破和放置任何方块。
* 玩家可以与任意方块互动，例如门和拉杆，并且可以从[村民](村民.md)交易获得。
* 玩家仍然可以伤害生物。

* *[创造模式](创造模式.md)物品栏**
* 药水加入进创造模式物品栏中，位于“酿造”类别。
* 在创造模式中加入删除[物品](物品.md)或[盔甲](盔甲.md)和[合成](合成.md)系统到删除模式物品栏中。
* 在创造模式物品栏中加入了圆石和石砖[怪物蛋](怪物蛋.md)。

# 更改
# = 方块 =
* *[附魔台](附魔台.md)**
* 重新平衡了附魔台。
* * 附魔台提供的最大附魔等级从50降至30。
* ** 因此现在[附魔台](附魔台.md)只需要放置15个书架在其周围就能获得最大附魔等级。
* * 拥有至少15书架围着附魔台提供的3个附魔选项中，第3个选项总是30级。
* * 使用30级附魔，玩家会变得更幸运；几乎所有物品可得到至少2种魔咒。

* *[树叶](树叶.md)**
* 现在暴露在[雨](雨.md)中时，底部会缓慢出现水滴[粒子](粒子.md)。

* *[炼药锅](炼药锅.md)**
* 现在暴露在雨中时会缓慢填充[水](水.md)。

* *[台阶](台阶.md)**
* 现在单个台阶能直接放置在方块旁边的上半部分。

* *[绿宝石矿石](绿宝石矿石.md)**
* 现在1个[矿团](矿团.md)只生成1个矿石。

# = 游戏内容 =
* *[经验](经验.md)**
* 现在各种动作会给予玩家[经验值](经验值.md)，例如挖矿（除了[金矿石](金矿石.md)和[铁矿石](铁矿石.md)）、使用[熔炉](熔炉.md)和获得[成就](成就/Java版.md)。
* 经验等级现在呈线性，每升一级需要多17经验。

* *[交易](交易.md)**
* 村民现在可以和玩家交易各种物品（例如：1绿宝石 + 10沙砾 → 3燧石）。
* 一些村民会出售已附魔的物品（例如：3绿宝石 + 1铁镐 → 1时运I铁镐）。

* *[烧炼](烧炼.md)**
* 使用熔岩桶烧炼现在会返还玩家一个空桶。

* *[单人游戏](单人游戏.md)**
* 暂停机制现在在单人游戏重新工作。

* *[下界传送门](下界传送门.md)**
* 在其附近拥有很小的概率生成[僵尸猪人](僵尸猪人.md)。

* *[物品栏](物品栏.md)**
* 物品栏中看到的方块现在面向右侧，而不是左侧。

* *调试特性**
* 按下会重新加载区块。

# 修复
* *修复了10个漏洞**
* 现在，创造模式物品栏中红石标签页里的红石火把现在显示的是其亮着的样子，而不是暗的。
* 现在把红石火把从创造模式物品栏的装饰方块页上删掉了。
* 修复了在上一个快照中，史莱姆大小有时有错误的问题。
* 完全蓄力的箭矢现在能再次显示它们的粒子效果了。
* 箭矢现在会正确卡在它们射入方块的位置上了。
* 语言“English (US)”现在再次可用了。
* 修复了末影人被看到时它们不摇动和打开下颚的问题。<ref></ref>
* 修复了加载含有中继器的区块时，中继器有时会被卡住的问题。<ref></ref>
* 现在，除非玩家按了聊天键，否则搜索页不会自动打开。这允许玩家可以使用背包键关闭背包。
* 修复了使用一叠铁桶挤奶时它们会消失的问题。</onlyinclude>
