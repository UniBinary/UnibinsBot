# Java版14w06a

*页面ID: 33832* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w06a**是[Java版1.8](Java版1.8.md)的第10个快照，发布于2014年2月6日<ref></ref>，加入了命令并更新了记分板，此外还加入了新的NBT标签、成就和闪烁标语，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 语法：
* 与或的功能相同，但只能修改带有<code>trigger</code>准则的目标（被称为触发器）和只能修改执行命令的玩家的分数。
* 可以被非管理员玩家使用。
* 要想使玩家执行命令，触发器首先得对那个玩家启用。
* * 将对指定玩家启用指定的触发器目标。
* * 触发器的可用状态是对每个玩家和每个触发器是独立的。
* ** 一个玩家也许不能使用一个触发器，但那个玩家可以使用别的触发器。
* ** 一个玩家也许不能使用一个触发器，但别的玩家可以使用那个触发器。
* * 触发器在被使用后将进入禁用状态（需要重新开启才能再次使用）。
* 主要与配合使用。

* *[记分板](记分板.md)**
* 新的参数：<code>-{}-[目标]</code>。
* * 允许目标一个个被重设。
* * 例子：。
* 为团队杀人数添加了新的目标准则，如：<code>teamkill.red, killedByTeam.blue</code>。
* 新的目标准则：<code>trigger</code>。
* * 与<code>dummy</code>准则行为相似。
* * 主要与配合使用。
* 使用<code>*</code>现在可以迭代所有记分板内的玩家。

* *NBT标签**
* <code>CanPlaceOn</code>
* * 在冒险模式内指定此方块能放置在哪些方块之上。
* * 例子：{{cmd|give @p minecraft:stone 16 0 {CanPlaceOn:[minecraft:diamond_block]} }}
* <code>HideFlags</code>
* * 允许隐藏标签中的一些内容。
* * 位段为<code>1/enchantments, 2/modifiers, 4/unbreakable, 8/candestroy, 16/canplace</code>。
* <code>ShowParticles</code>
* * 显示或隐藏所有状态效果所产生的粒子效果，而不是像<code>Ambient</code>标签仅会使粒子变半透明。1为显示，0为隐藏。
* <code>PickupDelay</code>
* * 设置物品能被捡起前所需等待的时间。
* * 将其设置为32767将阻止时间减少，使物品完全不能被捡起。

# 更改
# = 方块 =
* *[屏障](屏障.md)**
* 现在会在玩家处于创造模式中并拿着屏障时显示。
* * 方块本身并未渲染，粒子会在其地方出现。
* 现在使用[红石块](红石块.md)的纹理来作为破坏粒子。

# = 物品 =
* *常规**
* 当物品被捡起时，物品现在先会移动到玩家的脚部而不是飞到玩家身上。

# = 生物 =
* *常规**
* 所有的生物现在使用“新”的AI系统。<ref></ref>
* 生物受伤时现在会展示稍微不同的颜色。
* 能乘船的生物现在能控制[船](船.md)。
* * [蝙蝠](蝙蝠.md)和[恶魂](恶魂.md)除外。

* *[烈焰人](烈焰人.md)**
* 在和玩家间隔着固体方块时仍会向玩家攻击。

* *[巨人](巨人.md)**
* 穿着的盔甲现在会被渲染了。
* 移除了AI。
* 稍微变得更高（现在是11.7格高而不是10.8）。

* *[史莱姆](史莱姆.md)和[岩浆怪](岩浆怪.md)**
* 现在会游泳，并时常随机更改方向，减少了卡在墙内或角落里的概率。
* 如果任何玩家不在半径32以内它们会随机消失。
* 稍微变得更小（长宽0.51格而不是0.6）（这是最小变种的值，其他的仍能计算）。

* *[蜘蛛](蜘蛛.md)和[洞穴蜘蛛](洞穴蜘蛛.md)**
* 视野不再能穿过非透明方块。
* *[末影人](末影人.md)**
* 被激怒时会寻找玩家。

* *[僵尸猪人](僵尸猪人.md)**
* 被激怒时会寻找玩家。
* 稍微变得更高（1.95格高而不是1.8）。

* *[雪傀儡](雪傀儡.md)**
* 体积显著变大（1.9格高和0.7格宽而不是1.8和0.4）。

* *[蠹虫](蠹虫.md)**
* 体积显著变小（0.3格高和0.4格宽而不是0.7格高0.4格宽）。

* *[僵尸](僵尸.md)、[僵尸村民](僵尸村民.md)、[骷髅](骷髅.md)和[女巫](女巫.md)**
* 稍微变得更高（1.95格高而不是1.8）。

* *[凋灵骷髅](凋灵骷髅.md)**
* 稍微变得更高（2.353格高而不是2.34）。

* *[凋灵](凋灵.md)**
* 稍微变得更矮（3.5格高而不是4.0）。

* *[豹猫](豹猫.md)**
* 稍微变得更矮（0.7格高而不是0.8）。

* *[鸡](鸡.md)**
* 稍微变得更高（0.4格高而不是0.3）。

* *[生物](生物（已移除实体）.md)**
* 移除了残留的AI。

* *[怪物](怪物（已移除实体）.md)**
* 移除了残留的AI。

# = 非生物实体 =
* *[末地水晶](末地水晶.md)**
* 现在会以1格更低生成，并且没有基岩在其下方。

# = 命令格式 =
* ***
* 现在可以指定是否显示粒子：
* 用法：
* * true时将隐藏粒子，false时显示；未设置时则默认为false。

* ***
* 加入了<code>barrier</code>粒子。
* * 使用屏障的物品形式纹理。
* * 用于显示屏障的位置。

* *NBT标签**
* <code>Age</code>
* * 设定为-32768时将使物品永远不会消失。

# = 游戏内容 =
* *[旁观模式](旁观模式.md)**
* 加入了用于在旁观时显示玩家轮廓的可选热键。
* * 可对队伍进行彩色编码。
* * 可在设置内设置/取消。
* * 轮廓将在按下按键时显示。

# = 常规 =
* *方块ID**
* 关于方块/物品的统计数据现在可以用名字来代替数字ID。
* * 例子：<code>stat.mineBlock.minecraft.stone</code>

* *[调试屏幕](调试屏幕.md)**
* X，Y，Z标题从上个快照的'Feet'改为'XYZ'。
* 加入了天数计时器。
* * 每天黎明时增加1。
* 现在会显示[区域难度](区域难度.md)。
* * 和平-0.00，简单-0.75，普通-1.50，困难-2.25（当玩家待在一个区域内，数字会缓慢增加）。
* 现在又会显示玩家的旋转角度。
* * 但现在是以度数和象限显示。

* *[资源包](资源包.md)**
* 在资源包内的方块模型现在可以被自定义。
* 在内替换文件。
* 在加载纹理包后，可能需要重启游戏。

* *[闪烁标语](闪烁标语.md)**
* “OpenGL 1.2!”更改为“OpenGL 2.1 (if supported)!”。

* *实体碰撞箱**
* 现在会显示以红色显示实体的视线水平。
