* *骷髅马（Skeleton Horse）**是[马](马.md)的亡灵变种，拥有骷髅般的骨架外观。

# 生成

[缩略图|一群由骷髅陷阱马产生的骷髅骑手](File:SkeletonRiderGroup.png.md)
[thumb|一只由骷髅和骷髅马组成的骷髅骑手](File:Skeleton Trap.png.md)

在[雷暴](雷暴.md)天气中，每道自然生成的且不击中避雷针的闪电有概率（取决于[区域难度](区域难度.md)，简单为0.75–1.5%，普通为1.5–4%，困难为2.25–6.75%）生成一只带有骷髅陷阱的骷髅马，称之为骷髅陷阱马。如果没有被激活成骷髅骑手，骷髅陷阱马会在后消失。

当[玩家](玩家.md)与骷髅陷阱马的距离小于等于10格时，一道[闪电](闪电.md)会击中这只马。这道闪电不会使方块着火或者对附近实体造成伤害。被闪电击中后，骷髅陷阱马会变成骷髅骑手（骑着骷髅马的[骷髅](骷髅.md)），并且在它的附近会额外生成三个骷髅骑手。每个骷髅骑手带有附魔的[铁头盔](铁头盔.md)和[弓](弓.md)，并且生成后有3秒钟的[受击后伤害免疫](受击后伤害免疫.md)效果（骷髅马和骷髅骑手都对闪电免疫）。骷髅骑手移动速度很快，它们的行动方式和普通骷髅一样，。
* 骷髅默认会戴上铁头盔，除非它生成时随机带有其他种类的头盔。
* 如果按照[附魔台](附魔台.md)的机制来计算，骷髅装备的附魔等级为5-22级（视区域难度而定）。在简单难度中附魔等级总是5级。
* 幼年骷髅陷阱马会长大成年。
* 骷髅陷阱马被闪电劈中时会变为驯服状态，另外三个骷髅马生成时即为驯服状态。驯服后的骷髅马没有主人。
* 骷髅陷阱生成的骷髅不会自然消失。
* 骷髅陷阱马可以在普通马无法生成的区域（例如海洋）生成。
* 在天气晴朗时，骷髅陷阱马仍然能被正常激活。
* 骷髅会掉落更多的经验。
* 如果难度设置为和平，骷髅会消失，但骷髅马不会。
* 骷髅陷阱马激活时的闪电可以穿过方块。

使用命令{{cmd|summon minecraft:skeleton_horse ~ ~ ~ {SkeletonTrap:1b}<nowiki/>}}或可以在当前位置生成一只骷髅陷阱马。

幼年骷髅马不会自然生成。

骷髅马还可以由刷怪蛋生成。不对着骷髅马使用的刷怪蛋生成的骷髅马总是成年的<ref></ref>；而使用刷怪蛋生成幼年骷髅马的概率为20%。

# 掉落物
在死亡时，骷髅马会掉落：

}}
* ，被玩家或驯服的[狼](狼.md)杀死时。

如果骷髅马装备了鞍，则会掉落鞍。

杀死幼年骷髅马不会掉落任何经验或物品。

# 行为
与其他大多数生物类似，骷髅马可以坐在[矿车](矿车.md)里，幼年骷髅马还可以坐在[船](船.md)上。幼年骷髅马成年后会脱离船。

与马类似，骷髅马会缓慢恢复生命值。但骷髅马无法被喂食或繁殖，幼年骷髅马也无法成长为成年个体。

与其他可驯服生物不同，驯服的骷髅马死亡时不会向玩家显示[死亡消息](死亡消息.md)。

骷髅马的移动速度固定为0.1958个内部单位（8.43格/秒），跳跃力量与普通马相同，在0.4-1.0之间，趋于平均值0.7。骷髅马不能通过1格宽的间隙。驯服的骷髅马可被玩家骑乘。

骷髅马可在水下任何深度骑乘，也可以在海平面或河流表面上骑乘。

骷髅马可以被[拴绳](拴绳.md)牵引。

刷怪蛋生成的幼年骷髅马需20分钟才能成长为成年个体。

# = 生物族群 =

骷髅马是亡灵生物，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，免疫[生命恢复](生命恢复.md)和[中毒](中毒.md)，不会溺水，在水下会缓缓下沉直到接触水底且不能在任何情况下上浮，不被[凋灵](凋灵.md)攻击。

骷髅马不会在阳光下着火。

# = 装备 =

成年骷髅马有以下可用的槽：
* 鞍槽：用来装备[鞍](鞍.md)。对每种骷髅马都有效。

玩家手上拿着鞍对着骷髅马按下键，就可以给骷髅马装上鞍，或者可以打开骷髅马的物品栏并把鞍放入鞍槽。骷髅马的物品栏可以通过骑乘在其身上并打开玩家的物品栏来打开，或者按下键打开。

使用刷怪蛋生成的骷髅马以及使用命令生成的没有任何附加属性的骷髅马不能和玩家交互。<ref name="MC-102949"></ref>

骷髅马没有物品栏，也不能装备鞍或马铠。

# = 骑乘 =

玩家可以通过对着骑在驯服的成年骷髅马按下键并通过方向键来控制它的行动。玩家可通过按下下马。

玩家无法骑乘用命令生成的没有任何附加属性的骷髅马和用刷怪蛋生成的骷髅马<ref name="MC-102949"/>。

玩家可以控制没有装备鞍的骷髅马，而只有装备了鞍的骷髅马才可以被玩家控制。

玩家骑乘骷髅马时会显示骷髅马的生命条，其纹理与玩家的生命条不同。玩家的饥饿条被骷髅马的生命条代替，经验条也会被骷髅马的跳跃蓄力条代替；玩家的饥饿条和经验条会正常显示，只有在蓄力时，经验条才会被跳跃蓄力条取代，且上方经验等级的数值不会消失。

玩家可以在骑骷髅马时使用物品、与方块或其他生物交互。

被骑乘的骷髅马可以自动走上而不是跳上1格高的方块。骑骷髅马的玩家可以通过2.75格高的空间。如果骑手的头进入一个窒息方块时，骑手就会受到窒息伤害。骷髅马本身可以穿过1.625格高的空间，但是当高度小于1.75格时，骷髅马仍会受到窒息伤害。骷髅马不能通过一格宽的缝隙。

骷髅马是自然生成最慢的马。骷髅马仍然可以通过长按跳跃来蓄力。骷髅马不会受到[信标](信标.md)的跳跃加成效果。它会受到跌落伤害。

玩家无法在骑骷髅马时使用[下界传送门](下界传送门.md)，但是未被玩家骑乘的骷髅马可以进入下界，比如使用拴绳拉着骷髅马。

与普通的马不同，骷髅马在沉入水下两格或更深的地方时玩家不会从骷髅马上下来，它可以在不受到溺水伤害的情况下在水下骑乘。它们的行走和跳跃速度和在陆地上的差不多，只是在水中下沉的速度有些许下降。这使得骷髅马可以成为一种有效的水下交通工具，但在水下骑乘骷髅马的玩家[氧气值](氧气值.md)仍会减少，因此仅骑乘骷髅马跨海并不合适。

# 统计

所有的骷髅马都有3种“马匹统计”：生命值、（最大）移动速度和跳跃力量。这些数据是在骷髅马生成后固定不变的。

# = 生成条件 =
当骷髅马以命令、骷髅陷阱或刷怪蛋的方式生成时，会根据骷髅马的类型在特定范围内分配其属性。

# == 生命值 ==
骷髅马的生命值总是，它的最后半颗心不会显示。

# == 移动速度 ==
骷髅马的速度总是0.2，而玩家正常行走的速度为0.1。此速度不包括[状态效果](状态效果.md)。

另见[运输](运输#方式.md)以对其他实体的速度进行比较。

# == 跳跃力量 ==
跳跃力量为0.4-1.0，倾向于均值0.7。每个骷髅陷阱生成的四个骷髅马中至少有一只骷髅马的跳跃力量为0.7。

跳跃力量为0.5时能跳格。跳跃力量为1.0时能跳格。

# 你知道吗
* 马的模型（包含骷髅马）由Mo' Creatures Mod的作者Dr.Zhark（John Olarte）协助设计，Minecraft中马的模型是以这个Mod里面的马作为基准的。<ref></ref>Dr.Zhark因此出现在了[鸣谢名单](鸣谢名单.md)中。
* 在[多人游戏](多人游戏.md)中，可在两匹由不同玩家骑乘的骷髅马中选出较快的那匹。每个骑在骷髅马上的玩家需要用[拴绳](拴绳.md)拴住对方的骷髅马，然后进行拔河比赛，更容易被拉动的骷髅马就是较慢的那匹。
* 可以使用[命令](命令.md){{cmd|summon skeleton_horse ~ ~ ~ {Tame:1, equipment:{saddle:{id:saddle,count:1}<nowiki>}}</nowiki>}}生成可骑乘的骷髅马。以此命令生成的骷髅马会自动装备鞍。
* 骷髅马虽然是亡灵生物无法被喂食，但还是会进行低头吃草的动作，这可能是开发团队有意保留的。
* 骷髅骑手骑乘控制骷髅马时不需要装备鞍，但玩家骑乘控制时却需要，这可能是[骷髅](骷髅.md)和玩家的骑乘需求不同导致，因为[骷髅骑乘控制蜘蛛](蜘蛛骑士.md)时也不需要装备鞍。
* 如果有大量骷髅骑手在一个地方同时生成，一些骷髅可能会被挤下马。
* 与[骷髅](骷髅.md)及其变种不同，[狼](狼.md)并不会主动攻击骷髅马。
* * 而这个特性使得骷髅骑手容易在玩家没有介入的情况下被未驯服的狼群围剿，最后只剩下骷髅马幸存下来。
