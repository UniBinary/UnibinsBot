# 旧世界类型

*页面ID: 13317* | *来源: Minecraft Wiki*

[缩略图|350px|俯瞰旧世界](File:OldWorldType.jpg.md)

* *旧世界类型（Old）**是[基岩版](基岩版.md)和[教育版](教育版.md)独有的[世界类型](世界类型.md)。这个世界类型是为不能很好运行[无限的地图](世界类型#无限.md)的低配设备设计的。

# 世界生成
# = 主世界 =
以旧世界类型创建的世界是一个有限的长宽均为256个方块、高度限制为128的地图。[隐形基岩](隐形基岩.md)会在旧世界的边界及[高度限制](高度限制.md)范围外（包括Y=-41的位置）生成。

[黑森林](黑森林.md)和[黑森林丘陵](黑森林丘陵.md)不能在旧世界类型中生成。

由于世界大小有限，一个世界里只能生成少量的生物群系。同时，这些生物群系会被缩小为原来的（面积为原来的）从而允许生成更多的生物群系。因此，使用相同种子生成的旧世界和无限世界的整体特征相同，只是在地形和地物等方面稍有区别。如果生成时选择携带初始地图生成，地图的缩放比例为而不是。此外，旧世界类型的模拟距离最多可以是16个区块，而不是无限世界的8个。

由于生成世界时总是以玩家的出生点为世界中心，世界中心的坐标不一定为（0,0）。这意味着游戏会先寻找有效的出生点，之后将世界大小限制为256×256。通过编辑世界NBT可以在同一个[种子](种子（世界生成）.md)里移动旧世界的世界中心，在[1.18.32](基岩版1.18.32.md)及以后进入旧世界会将世界中心强制移动至（0,0），在[1.21.60](基岩版1.21.60.md)及以后进入旧世界会将旧世界的大小扩大96格。

在旧世界中，一些结构或地物永远不会生成：
* [废弃矿井](废弃矿井.md)、[海底神殿](海底神殿.md)、[林地府邸](林地府邸.md)、[要塞](要塞.md)、[地牢](地牢.md)、[沙漠神殿](沙漠神殿.md)、[丛林神庙](丛林神庙.md)、[沼泽小屋](沼泽小屋.md)、[雪屋](雪屋.md)、[海底废墟](海底废墟.md)、[沉船](沉船.md)、[掠夺者前哨站](掠夺者前哨站.md)和[废弃传送门](废弃传送门.md)不会生成。
* [洞穴](洞穴.md)和[峡谷](峡谷.md)这些地下结构不会生成，但[紫晶洞](紫晶洞.md)仍可以生成在地下。
* [草](草.md)和[蕨](蕨.md)在大部分地方均不会生成，但[高草丛](高草丛.md)和[大型蕨](大型蕨.md)会作为村庄的一部分生成；[竹林](竹林.md)中也会生成普通的草和大型蕨。

其他结构或地物可以在[主世界](主世界.md)正常生成：
* [村庄](村庄.md)。其有时候会生成在边界附近，从而导致一些结构（例如房子、会合点）不会生成或被截断，[村民](村民.md)因此可能会卡到边界的外边。
* 地表的湖可以正常生成，但地下不会生成任何种类的湖。
* [沙漠水井](沙漠水井.md)会稀有地生成。
* [埋藏的宝藏](埋藏的宝藏.md)和[化石](化石.md)也会稀有地生成。
* 在[1.16.220.50](基岩版1.16.220.50.md)至[1.18.0.20](基岩版1.18.0.20.md)启用“洞穴及悬崖”[实验性玩法](实验性玩法.md)后，新加入的山地生物群系可以正常生成，但由于建筑高度限制仍为Y=128，较高的地形会在此处被截断。

由于很多结构不能在旧世界生成，导致许多[资源](资源.md)无法在[生存模式](生存模式.md)下正常获得，一些生物也不能自然生成。

[水](水.md)总是会在旧世界生成，但[熔岩](熔岩.md)不总是会。如果一个旧世界不生成任何熔岩，会导致[圆石](圆石.md)成为不可再生资源。

如果在[1.18.32](基岩版1.18.32.md)及以后将旧世界类型世界的区块数据强行删除后重新加载世界时，会按照[1.17.30](基岩版1.17.30.md)的生成机制生成世界。

# = 下界和末地 =
在旧世界中，[下界](下界.md)和[末地](末地.md)不能正常通过[传送门](传送门.md)进入，但可以通过[命令](命令.md)放置对应的传送门方块进入。同时下界和末地也会被限制为256×128×256的有限世界。进入下界和末地可能会导致游戏出现漏洞，如所有的方块均不显示。

下界1格距离等于主世界8格距离的机制会在适当范围内保留，而当玩家在超过主世界范围的下界位置返回时，游戏会在主世界世界界限内寻找已有传送门或生成新的传送门进行传送。

[下界要塞](下界要塞.md)可以在下界生成，但由于世界大小的限制，也可能会被移除大部分结构。下界的其他群系也会正常生成。在下界的下界传送门无法正常激活，强行通过命令放置的传送门方块进行传送会在主世界的某个位置生成一个新的激活的下界传送门（因为使用命令放置的下界传送门会被忽略计数），且被破坏后无法再次激活。

末地只能生成不完整的主岛，外部岛屿因为地图限制而无法生成。有时[返回传送门](返回传送门.md)会被边界切除，[末影龙](末影龙.md)也会因试图飞越世界边界而被卡住。[末地折跃门](末地折跃门.md)不能正常运作，进入末地折跃门会被传送至返回传送门旁。但[末地城](末地城.md)也能被命令定位。

# 无法正常运作的机制
一些机制在旧世界里不能正常运作，一部分是因为机制没有适配有限的世界，另一部分是因为旧世界不会加载一切1.17.30以后的原版[附加包](附加包.md)。
* [创造模式物品栏](创造模式物品栏.md)中不会出现1.17.30以后的任何物品，存在的物品使用1.17.30的纹理。但1.17.30以后的附魔书会出现在创造模式物品栏中。
* [传送门](传送门.md)无法被正常激活。
* 解锁制图师[村民](村民.md)最后一个交易等级会导致[游戏刻](游戏刻.md)停止运作。
* 使用命令获得[林地探险家地图](林地探险家地图.md)会导致游戏刻停止运作，并输出一条错误信息。
* 喂食[海豚](海豚.md)可能会使它试图游到世界边界之外。
* 大部分[弹射物](弹射物.md)会卡在边界上。
* * [箭](箭.md)或[末影珍珠](末影珍珠.md)等投掷物可以穿过边界，但是没有效果。多次投掷[末影珍珠](末影珍珠.md)可能会被卡在边界内。
* [玩家](玩家.md)在[旁观模式](旁观模式.md)下的[第三人称视角](第三人称视角.md)不会渲染成半透明头颅，而是渲染成整个玩家实体。且手中拿着物品时有动作，但不显示物品。
* 使用定位[结构](结构.md)坐标会显示为世界之外，这是因为旧世界是以无限世界为基础的。
* 无法传送实体到边界外，或者传送边界外的实体。
* [地图](地图.md)不能显示世界外的地形。
* 无法启用，当默认图形模式为“”时，进入世界自动切换为“”。

# 转换
若要把一个旧世界类型的世界转换成无限类型，在选择世界界面中点击对应世界旁的铅笔图标，然后在底部找到并点击“创造无限！”按钮。这会创建一个新世界，并复制旧的世界所有已保存的数据（[物品栏](物品栏.md)、地形、结构等）到新的[无限](世界类型#无限.md)世界，然后保留原来旧世界的名称；旧的世界则会重命名为<code>-{}-<世界名称>-有限</code>。

旧世界类型所生成的较小的生物群系会用区块边界将其与无限世界分隔开，而无限类型的世界的其余部分会按照1.17.30的生成机制正常生成生物群系和其他[结构](结构.md)等。
