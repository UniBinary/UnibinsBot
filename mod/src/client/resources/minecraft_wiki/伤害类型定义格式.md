# 伤害类型定义格式

*页面ID: 102765* | *来源: Minecraft Wiki*

* *伤害类型定义文件**是[伤害类型](伤害类型.md)在[数据包](数据包.md)中的数据驱动定义文件。

# 定义格式
伤害类型在游戏内使用<code>DAMAGE_TYPE</code>[注册表](注册表.md)，数据包路径为，即所有伤害类型定义文件都需要在{{filepath|-{}-data/<*命名空间*>/damage_type}}目录内定义，伤害类型标签则需要在{{filepath|-{}-data/<*命名空间*>/tags/damage_type}}目录内定义。

伤害类型定义文件使用JSON格式，并具有下列结构：

<div class="treeview">
*  JSON文件根对象
* * ：（默认为<code>default</code>）用于定义生物受此伤害类型的伤害而死亡时的[死亡消息](死亡消息.md)，见下文。
* * ：（默认为<code>hurt</code>）生物受到此伤害类型的伤害后播放的音效，具体取值见下文。
* * ：受到此伤害类型的伤害且实际造成生命值下降的玩家增加的饥饿[消耗度](饥饿#饥饿因素.md)。
* * ：用于定义生物受此伤害类型的伤害而死亡时的死亡消息，见下文。
* * ：此伤害类型的伤害在不同难度下的调整行为，见下文。
</div>

# 定义行为
伤害类型定义数据仅在服务端启动时被加载一次，使用命令不可以使伤害类型定义被重新加载，而必须重启服务端。

<code>DAMAGE_TYPE</code>注册表中所有原版游戏内置的元素均不能被移除，否则游戏会崩溃。<ref></ref>

# = 死亡消息 =
伤害类型可以决定受到其类型伤害而死亡的实体的死亡消息。根据的不同，游戏会使用不同的翻译键以适配不同的情况。在下文中，的值被简写为*msgId*：
* 当为<code>default</code>（同时此值也为缺省值）时：
* * 如果伤害具有实体来源（例如来自生物的直接攻击或被生物射出的箭击中，这两种条件下生物作为实体来源），则检查生物的主手是否具有被命名的物品（即物品具有<code>custom_name</code>组件）：
* ** 如果实体来源不为生物，则使用<code>death.attack.<*msgId*></code>作为死亡消息，其中翻译的第一个参数为死亡实体的显示名称，第二个参数为直接执行伤害的实体的显示名称。如果直接执行伤害的实体没有显示名称，则使用实体来源的显示名称。
* ** 如果实体来源为生物，但主手没有物品或物品没有被命名，则与上一种条件相同。
* ** 其他情况下，使用<code>death.attack.<*msgId*>.item</code>作为死亡消息，除上述两个参数外，翻译的第三个参数使用物品的名称。
* * 如果伤害没有实体来源，但死亡实体在内受到过生物的伤害，则使用<code>death.attack.<*msgId*>.player</code>作为死亡消息，其中翻译的第一个参数为死亡实体的显示名称，第二个参数为最后伤害生物的显示名称。
* * 如果伤害没有实体来源，且内也没有受到生物的伤害，则使用<code>death.attack.<*msgId*></code>作为死亡消息，其中翻译的唯一参数为死亡实体的显示名称。
* 当为<code>fall_variants</code>时，使用摔落死亡消息，此时死亡消息与*msgId*无关。
* 当为<code>intentional_game_design</code>时，游戏会使用翻译键<code>death.attack.<*msgId*>.message</code>作为死亡消息，翻译的第一个参数是死亡实体名称，第二个参数为翻译键<code>death.attack.<*msgId*>.link</code>，且游戏自动为这个参数的文本组件增加相应样式和悬浮行为。

# = 伤害值调整 =
当**玩家**受到伤害时，游戏会检查伤害的伤害类型的和当前游戏难度，以调整初始伤害值。

有三种取值：
* <code>always</code>：伤害值总受到游戏难度影响。
* <code>never</code>：伤害值不会受到游戏难度影响。
* <code>when_caused_by_living_non_player</code>：当伤害实体来源为生物时受难度影响，其他情况下伤害值不发生变化。

当伤害值受到难度影响时，假设此伤害攻击其他实体的伤害值为*d*，则根据难度，玩家受到的伤害值按下列算法调整：
* 和平难度下，伤害值直接设置为0，与原始伤害值*d*无关。
* 简单难度下，伤害值调整为<math>\text{min}\{0.5d+1,d\}</math>。
* 普通难度下，伤害值不会调整，直接为*d*。
* 困难难度下，伤害值调整为<math>1.5d</math>。

# = 伤害音效 =
当**玩家**受到伤害，且伤害没有触发受击后伤害免疫时，游戏会在玩家位置播放对应的伤害音效。伤害音效由值控制。
