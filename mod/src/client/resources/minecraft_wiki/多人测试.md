# 多人测试

*页面ID: 35259* | *来源: Minecraft Wiki*

* *Classic多人测试（Multiplayer Test）**指的是发布于2009年5月31日至7月11日的23个**[Classic](Java版Classic.md)**版本。正如版本的名字所指的那样，这些版本的发布主要是为了实现和开发[多人游戏](多人游戏.md)。

# 新内容
# = 方块 =
; [海绵](海绵.md)
* 能吸收周围5×5×5体积的水。
; [玻璃](玻璃.md)
* 一种视觉透明的装饰性方块。
; [布料](羊毛.md)
* 存在16种颜色。
; [黄花](蒲公英.md)
* 一种小型花。
* 在黑暗中会消失。
; [玫瑰](虞美人.md)
* 一种小型花。
* 在黑暗中会消失。
; [蘑菇](蘑菇.md)
* 加入了红色蘑菇和棕色蘑菇。
; [金块](金块.md)
* 一种装饰性方块。

# = 游戏内容 =
; [多人游戏](多人游戏.md)
* 玩家的上方会显示其用户名。
* 按下列出已登录玩家的名单。
* 加入了自定义[皮肤](皮肤.md)。
; [聊天](聊天.md)
* 玩家可以与服务器上的其他玩家聊天了。
; [命令](命令.md)
* 加入了、、、、、、、、和。
* 仅限于管理员。
; [物品栏](物品栏.md)
* 按下键打开。
* [快捷栏](快捷栏.md)拥有9个物品格。
; [音效](音效.md)
* 为破坏方块加入了多个<code>.ogg</code>音效文件。
