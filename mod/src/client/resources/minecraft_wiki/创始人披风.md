# 创始人披风

*页面ID: 186251* | *来源: Minecraft Wiki*

* *创始人披风（Founder's Cape）**是[MINECON Live 2019](MINECON Live 2019.md)期间可在[市场](市场.md)免费领取的披风。

# 描述
创始人披风最初在作为[角色创建器](角色创建器.md)的促销品发布，于[MINECON Live 2019](MINECON Live 2019.md)期间可在[市场](市场.md)领取。<ref>https://marketplace.minecraft.net/en-us/pdp?id=b3b50166-5612-4ff1-8f03-9af0b01cb4da</ref>

拥有此披风的玩家于2025年5月8日后收到创始人披风。
