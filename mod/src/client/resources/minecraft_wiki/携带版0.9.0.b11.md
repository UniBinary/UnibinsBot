# 携带版0.9.0.b11

*页面ID: 28888* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.9.0 alpha build 11 (RC3)**是[v0.9.0 alpha](携带版0.9.0.md)的第11个测试版，也是第3个发布候选，修复了一些漏洞。

# 更改
# = 方块 =
* *[雪](雪.md)和[草丛](草丛.md)**
* 上方有雪或草丛的方块被破坏时会破坏其上的方块而不是本身。

* *[台阶](台阶.md)**
* 加入了丛林木台阶的合成配方。

* *[告示牌](告示牌.md)**
* 现在告示牌能够阻止沙子的掉落。

* *[陶瓦](陶瓦.md)**
* 加入陶瓦的合成和烧制配方。

# 修复
* *修复了9个漏洞**
* 加入了烤马铃薯的显示名称。
* 修复了村民身上会出现黑色纹理的问题。
* 修复了幼年生物的碰撞箱与成年生物相同的问题。
* 苦力怕现在可以被正确点燃。
* 修复了门、火把等方块上会出现黑色纹理的问题。
* 修复了关于床的粒子的问题。
* 修复了多人游戏中关于爆炸的问题。
* 现在门会在多人游戏中正确同步。
* 修复了多人游戏客户端上会出现内存泄漏的严重问题。</onlyinclude>
