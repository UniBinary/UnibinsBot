# 苦力怕的头

*页面ID: 166356* | *来源: Minecraft Wiki*

* *苦力怕的头（Creeper Head）**是一种[生物头颅](生物头颅.md)。

# 生成
苦力怕的头不会生成在世界中。

# 获取
# = 掉落 =
只有每只[闪电苦力怕](闪电苦力怕.md)杀死的第一个苦力怕会掉落苦力怕的头。

# 破坏
没有工具可以加速对苦力怕的头的挖掘。

苦力怕的头被破坏后会掉落自身。

被爆炸破坏的苦力怕的头总是会掉落。

# 用途
苦力怕的头会被液体破坏。

# = 装饰 =
苦力怕的头被放置在方块顶面时可以呈16种不同的方向，而放置在方块侧面时可以呈4种不同的方向。苦力怕的头不需要方块支撑，且可以放置在其他头颅的上方或侧边。

# = 穿戴 =
<div style='float:right'></div>

玩家能将苦力怕的头装备在头盔槽位。[发射器](发射器.md)也可以将苦力怕的头装备给没有头戴物品的玩家、[盔甲架](盔甲架.md)和一些人-{}-形生物，且其必须恰好位于发射器前的方块内。

当苦力怕的头戴在玩家头上时，苦力怕的头的纹理将会覆盖玩家头部的第二层纹理。

# = 伪装 =
玩家戴上[苦力怕](苦力怕.md)的头会将苦力怕探测玩家的默认半径减少50%。这可以与[潜行](潜行.md)时或拥有[隐身](隐身.md)效果时减少探测半径的特性叠加。

[多人游戏](多人游戏.md)中，穿戴苦力怕的头的玩家不会在[定位栏](定位栏.md)上显示。

穿戴任意种类苦力怕的头的玩家不会出现在其他玩家的定位器[地图](地图.md)上。
