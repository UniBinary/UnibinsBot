# Java版1.4.6

*页面ID: 31637* | *来源: Minecraft Wiki*

</ref>}}
<onlyinclude>

* *1.4.6**是的一次次要更新，发布于2012年12月20日<ref></ref>，加入了[烟花火箭](烟花火箭.md)、[附魔书](附魔书.md)和[荆棘](荆棘.md)魔咒，并修复了一些漏洞。此版本不兼容1.4.2到1.4.5的服务端。

# 新内容
# = 游戏内容 =
* *[荆棘](荆棘.md)**
* [盔甲](盔甲.md)的[魔咒](魔咒.md)。
* 根据魔咒等级对攻击者造成不等量伤害。
* 会使盔甲损耗加剧。

# = 方块与物品 =
* *[下界砖台阶](下界砖台阶.md)**
* 使用下界砖块合成，配方类似于其他台阶。
* *[附魔书](附魔书.md)**
* 将书附魔会添加1个魔咒。
* 可以用铁砧施加到其他物品，消耗附魔书——创造模式下可以把魔咒添加到任意物品。
* 可以通过战利品箱子或与村民交易得到。
* 耐久可以施加给任何有耐久度的物品。
* 效率与精准采集可以施加给剪刀，允许采集蜘蛛网。
* 锋利、亡灵杀手、节肢杀手可以施加给斧。
* *[烟火之星](烟火之星.md)**
* 用来合成烟花火箭。
* 用[火药](火药.md)与染料合成，获得放出对应颜色的烟火之星。
* 另外可加入[荧石](荧石.md)、[火焰弹](火焰弹.md)、[钻石](钻石.md)、[金粒](金粒.md)、[羽毛](羽毛.md)，或者[生物头颅](生物头颅.md)，对应产生闪烁、加大、轨迹、星形、喷发或苦力怕状效果。
* 用烟火之星与染料再合成一次可以更改烟花的火星渐变淡化到的颜色。
* *[烟花火箭](烟花火箭.md)**
* 无破坏性，发射器或玩家使用时升到空中并会产生彩色图案。
* 用[纸](纸.md)与[火药](火药.md)合成烟花火箭。
* 另外可加入烟火之星改变图案，或者加入火药提高飞行时间。

# 更改
# = 常规 =
* *显示**
* 添加默认分辨率设置——：<code>overrideWidth:0</code>与<code>overrideHeight:0</code>

# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 可以拖曳并丢弃物品——拖曳前长按以选择半组。
* *魔咒**
* 火焰保护现在更快使[火](火.md)熄灭。
* 爆炸保护现在减少[爆炸](爆炸.md)击退效果。
* 保护的保护效果被削弱，使得某些魔咒价值上升。
* *调整**
* 使[物品](物品（实体）.md)和[物品展示框](物品展示框.md)在[精美画质](选项#video.md)下渲染成3D。
* 物品在快捷栏切换时会显示名称。
* * 可以在中把<code>heldItemTooltips</code>设为禁用。
* [潜行](潜行.md)时右击会使用物品而非使用选定[方块](方块.md)。
* 按住丢出物品现在会丢下整组。
* 死亡消息在服务器日志文件中出现。

# = 世界生成 =
* *[地牢](地牢.md)与[村庄](村庄.md)**
* 现在有随机可能在[箱子](箱子.md)里出现附魔书。

# = 方块与物品 =
* *[刷怪笼](刷怪笼.md)**
* 生成时会有不等概率生成每种特定生物。
* *[弓](弓.md)**
* 用弓箭射中玩家时会有提示音。
* [箭](箭.md)在远处也会渲染。

# = 生物 =
* *[恶魂](恶魂.md)**
* 火球爆炸半径可以被定义。
* *[骷髅](骷髅.md)、[僵尸](僵尸.md)与[僵尸猪人](僵尸猪人.md)**
* 在更困难的难度下，盔甲与其魔咒会更加强。
