# 用途
# = 格挡 =

盾牌的用途是格挡敌方的攻击。可以通过长按键|java|short=1}}或键|bedrock|short=1}}来使用。盾牌会使玩家的速度减至[潜行](潜行.md)的速度。使用盾牌5[刻](刻.md)（0.25秒）之后，来自玩家前方的所有可被格挡的攻击都会被盾牌抵挡，不造成伤害；盾牌会立即生效。

生效时，盾牌能格挡在水平方向与玩家视线成小于90°角的攻击，换言之，其保护范围包含玩家前方几乎整个半圆。玩家的垂直旋转角通常对格挡范围没有影响。

攻击如果被盾牌抵挡，那么来自这次攻击的击退也会被减弱。大部分常规的击退会消除（比如大部分生物的近战攻击、没有附魔冲击的弓射出的箭等），而较大的击退会大幅降低（爆炸、冲击波、等），[风爆](爆炸#风爆.md)造成的击飞不受影响。

如果盾牌挡下的|JE}}伤害，那么它的耐久会减少<math>\lfloor \text{攻击伤害} \rfloor +1</math>点。

盾牌具有以下特性：
* 会在格挡近战攻击后将攻击者反方向击退约1方块远。<ref group="注">末影龙等特殊生物发起近战攻击时不受影响。</ref>
* 对爆炸攻击无死角抵挡。
* 如果创造模式的玩家打到其他玩家的盾牌也会被击退。
* 当玩家进行挥手、拉弓、进食、饮用等行为时，盾牌无法激活，直到玩家的挥手动画结束或完成当前动作。
* 当玩家骑乘[实体](实体.md)时，盾牌会保持激活状态，因为潜行通常会使玩家离开被骑乘的实体。

能被盾牌格挡的攻击类型：
* [近战](近战.md)
* [箭](箭.md)、药箭和[光灵箭](光灵箭.md)
* 着火的箭
* [三叉戟](三叉戟.md)
* [雪球](雪球.md)和[鸡蛋](鸡蛋.md)
* [河豚](河豚.md)、[蜜蜂](蜜蜂.md)的刺
* [潜影弹](潜影弹.md)
* [火球](火球.md)
* [羊驼唾沫](羊驼唾沫.md)
* [苦力怕](苦力怕.md)、[恶魂火球](恶魂火球.md)、[末地水晶](末地水晶.md)、[床](床.md)、[重生锚](重生锚.md)和[TNT](TNT.md)引发的[爆炸](爆炸.md)
* [鹦鹉螺](鹦鹉螺.md)的冲刺攻击

不能被盾牌格挡的攻击类型：
* 由带有[穿透](穿透.md)魔咒的[弩](弩.md)射出的箭
* 来自[守卫者](守卫者.md)和[远古守卫者](远古守卫者.md)的激光
* 来自[状态效果](状态效果.md)和龙息药水云的伤害
* 传送和坠落伤害
* 来自非格挡范围内的伤害
*
* [监守者](监守者.md)的远程攻击

当盾牌被箭或三叉戟击中时，这些弹射物会被弹开而可能伤害到其他实体（包括攻击者自己）。

# = 停用 =
盾牌在抵挡了来自[卫道士](卫道士.md)、[猪灵蛮兵](猪灵蛮兵.md)或其他玩家等持有[斧](斧.md)的生物的近战攻击，或抵挡了来自[监守者](监守者.md)的近战攻击后会被停用，在5秒内无法使用于防御，同时还会发出与耐久度耗尽相同的音效。

# = 添加图案 =
可以通过合成盾牌和[旗帜](旗帜.md)来给盾牌装饰上旗帜的图案。

使用不祥旗帜会恢复盾牌的耐久度。<ref></ref>
}}

[150px|thumb|一个印有颜色的盾牌](File:Cyan shield screenshot.png.md)

与旗帜不同，盾牌不能在[炼药锅](炼药锅.md)洗掉图案。盾牌的分辨率是旗帜的一半，所以盾牌上的图案看起来会和旗帜上的有些差别。<ref>https://www.bilibili.com/video/BV1YJ411A743</ref>

有图案的盾牌也能通过使用和旗帜相同的命令来获得，除了<code>banner</code>要用<code>shield</code>来代替。

# 盾牌实体

盾牌在激活时变成实体形态。若想要单独生成盾牌实体，只能将行为包文件的值修改为时才能通过输入命令来生成。

使用命令生成后的盾牌不会移动。盾牌实体渲染模型的位置会随着玩家的位置而变化，但是实体仍会保持在原来的位置。当它被攻击后，它会瞬间穿过它上面的方块飞上天空，相反，它的渲染模型会瞬间向下掉落。
