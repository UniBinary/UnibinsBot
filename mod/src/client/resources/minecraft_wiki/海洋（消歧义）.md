# Minecraft
# = 生物群系 =
*  - 基础的海洋生物群系。
*  - 类似于海洋生物群系，但其深度是海洋生物群系的两倍。
*  - 较为温暖的海洋生物群系。
*  - 类似于暖水海洋，但其深度是暖水海洋生物群系的两倍。
*  - 温暖的海洋生物群系，珊瑚礁会在此处生成。
*  - 较为寒冷的海洋生物群系。
*  - 类似于冷水海洋，但其深度是冷水海洋生物群系的两倍。
*  - 寒冷的海洋生物群系，北极熊会在此处生成。
*  - 类似于冻洋，但其深度是冻洋生物群系的两倍。
