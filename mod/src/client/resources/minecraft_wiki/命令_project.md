# 命令/project

*页面ID: 124241* | *来源: Minecraft Wiki*

该命令包含用于管理[编辑器](编辑器.md)项目的工具。

# 语法
   <code>project export <exportType: ExportTypes></code>

# 参数

   指定导出内容的类型，可用值有：
  * <code>project</code> — 项目
  * <code>template</code> — 世界模板
  * <code>world</code> — 世界

# 输出

# 示例
* 导出为世界：<code>/project export world</code>
