# 湖泊

*页面ID: 25122* | *来源: Minecraft Wiki*

* *湖泊（Lake）**是相对较小的封闭水体。在Minecraft中，湖泊由[水](水.md)或[熔岩](熔岩.md)组成，其地貌可以通过各种[生物群系](生物群系.md)、[地物](地物.md)和[地形特征](地形特征.md)生成。这些地貌通常被一概称为“湖泊”，但实际上其生成并非同一因素所致。

# 地形特征
*  - 一类拥有独立的大小和水位高度的水体，用于生成[主世界](主世界.md)中地表或地下的湖。
* *  - 一类充满熔岩的含水层，生成于主世界Y=0以下的洞穴。

# 生物群系
* 四面被陆地所包围的小型生物群系。
* 宽阔短小的生物群系。

# 地物
*  - 由[熔岩](熔岩.md)源方块构成的小型湖泊。
*  - [繁茂洞穴](繁茂洞穴.md)中环绕着[黏土](黏土.md)、生长有[垂滴叶](垂滴叶.md)的片状小水池。
*  - [玄武岩三角洲](玄武岩三角洲.md)中片状的小型熔岩池。

# 已移除特性
*  - 由[水](水.md)源方块构成的小型水体。
*  - 底部会生成[沙子](沙子.md)和黏土[圆盘](圆盘.md)的中型水体。
*  - [沙漠](沙漠.md)生物群系的不常见变种，以湖泊为特征。
