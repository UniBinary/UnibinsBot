# Java版1.15-pre3

*页面ID: 49811* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.15-pre3**是[Java版1.15](Java版1.15.md)的第3个预发布版，发布于2019年11月28日<ref></ref>，加入了新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了下列闪烁标语文本：
* * "In case it isn't obvious, foxes aren't players."<ref></ref>
* * "Buzzy Bees!"
* * "Minecraft Java Edition presents: Disgusting Bugs"

# 更改
# = 方块 =
* *[耕地](耕地.md)、[草径](草径.md)和[灵魂沙](灵魂沙.md)**
* 不再使生物窒息。

* *[告示牌](告示牌.md)**
* 使得其上的文本颜色外观与之前的版本对应。

# = 常规 =
* *[平视显示器](平视显示器.md)**
* 更改了热键栏的亮度。

* *性能**
* 进一步优化了区块加载和渲染性能。

* *纹理**
* 移除了[蜜脾](蜜脾.md)的透明部分的纹理。
