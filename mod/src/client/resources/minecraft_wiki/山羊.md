* *山羊（Goat）**是一种生成于[山地](山地.md)类[生物群系](生物群系.md)的[友好生物](友好生物.md)。

# 生成
山羊会自然生成于[积雪山坡](积雪山坡.md)、[尖峭山峰](尖峭山峰.md)和[冰封山峰](冰封山峰.md)生物群系的[雪](雪.md)、[雪块](雪块.md)、[细雪](细雪.md)、[浮冰](浮冰.md)、[沙砾](沙砾.md)和[石头](石头.md)上，且只会在亮度等级大于等于7时生成。山羊有5%的概率生成为幼年个体。

山羊有2%的概率生成为尖叫山羊，其声音与一般的山羊不同，且相比普通山羊有更高的频率发起冲撞攻击。

成年山羊有10%的概率以独角形式生成。

# 行为
山羊具有较强的跳跃能力，每隔30-60秒会高跳一次，最多能跳10格高，并且山羊受到的摔落伤害相较正常水平少。与其他生物相同，山羊无法在[蜂蜜块](蜂蜜块.md)上跳跃。

山羊会避免进入[细雪](细雪.md)。

山羊不会反击伤害它们的生物，其受到伤害时会四处逃窜。

类似于[水生生物](水生生物.md)，山羊不会受到[河豚](河豚.md)的伤害。

# = 冲撞 =
每隔30-300秒，山羊会随机选择半径16格内的玩家和生物（其他山羊和[恶魂](恶魂.md)除外）作为冲撞目标并开始蓄力。尖叫山羊会更加频繁地发起冲撞，每隔5-15秒就会试图冲撞一次。山羊发起冲刺需要满足以下条件：
* 山羊与某一可冲撞目标之间存在至少4格空间，且不被非空气方块阻挡；
* 冲撞目标在山羊蓄力期间不移动。
山羊快速冲向目标，并对撞到的生物（即使不是预期的冲撞目标）造成近战伤害和较强的击退。成年山羊的击退距离可达9格，幼年山羊则为4.5格。被山羊冲撞的生物不会因此反击，除了[监守者](监守者.md)、</ref>|be}}、</ref>|je}}。

在山羊蓄力期间，可冲撞目标可以离开山羊的冲撞路径。没有撞到目标的山羊会在几格内自行停下，除非它撞在方块上。

若山羊在蓄力和冲刺过程中受到攻击或是发现手持[小麦](小麦.md)的玩家，它就会瞬间停止冲刺。

山羊冲撞[潜影贝](潜影贝.md)时，脑袋总会在潜影贝的外壳卡住一段时间，且无法对其造成伤害和击退。

# == 山羊角 ==
成年山羊冲撞到[石头](石头.md)、[浮冰](浮冰.md)、[铁矿石](铁矿石.md)、[煤矿石](煤矿石.md)、[铜矿石](铜矿石.md)、[绿宝石矿石](绿宝石矿石.md)或[原木](原木.md)由标签控制。}}时会掉落1个[山羊角](山羊角.md)。

山羊掉落山羊角的同时，其外观上的角会减少一只，这意味着每只山羊最多会掉落2个山羊角。

# = 繁殖 =

山羊会跟随/手持[小麦](小麦.md)的玩家。给一对山羊喂食小麦，会使之进入[繁殖](繁殖.md)模式并产下幼年山羊。山羊繁殖后会给予玩家，且双亲有/的繁殖冷却时间。繁殖出的幼年个体需20分钟才能成长为成年个体。可通过喂食小麦加速成长，每次减少约10%的剩余成长时间。

对幼年山羊[金蒲公英](金蒲公英.md)可以阻止其成长为成年山羊，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年山羊无法被喂食除金蒲公英外的其他物品。

繁殖一对普通山羊有2%的概率产下尖叫山羊，如有一方是尖叫山羊则大约为50%，双方均为尖叫山羊则为或。

# = 产奶 =
对成年山羊[铁桶](铁桶.md)可以挤奶，并获得[奶桶](奶桶.md)。

# 你知道吗
* 游戏中山羊的原型为现实中的[洛基山羊](wzh:雪羊.md)，而其音效取自现实中的。<ref></ref>
* 尖叫山羊并非游戏中虚构的变种，而是根据现实中某些山羊的尖叫行为设计的。<ref></ref>
* 虽然山羊的冲撞具有伤害，但开发者表示，山羊的冲撞行为并非蓄意伤害，而是调皮的恶作剧。<ref></ref>
* 山羊的模型是使用[Blockbench](https://blockbench.net/)3D建模软件制作的。<ref></ref>
* 在洞穴与山崖第一部分官方预告片的[0:24](https://youtu.be/0maWbr0FHKY?t=24)处（山羊摔下山崖的片段），左边的夜空出现了（Capricornus）星座，它代表着海山羊。同时“Capricornus”也是[山羊角](山羊角.md)的拉丁语名称。
* 山羊的第4个准备冲撞音效复用自[Minecraft Earth](Minecraft Earth.md)中[角羊](角羊.md)的一个冲撞音效。
