# 基岩版1.18.33

*页面ID: 96048* | *来源: Minecraft Wiki*

* *1.18.33**是的一次热修复更新，仅发布到Nintendo Switch平台，发布于2022年5月13日<ref></ref>，加入了一个新按钮，并修复了一些漏洞。此版本与其他平台上的[1.18.30](基岩版1.18.30.md)到[1.18.32](基岩版1.18.32.md)相互兼容。

# 新内容
# = 常规 =
* *[设置](设置.md)**
* 在存储设置中加入了“清除市场缓存”按钮。
* * 用于清除本地缓存数据，并不会删除已保存的游戏数据。

# 修复
* 启用了部分后端服务的配置更改。
