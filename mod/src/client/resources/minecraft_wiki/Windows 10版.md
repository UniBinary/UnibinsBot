* *Minecraft: Windows 10版（*Minecraft: Windows 10 Edition*）**是一个已经发布的[基岩版](基岩版.md)的分支版本，运行于[Windows 10](wzh:Windows 10.md)平台。<ref name="Windows10Minecraft">https://mojang.com/2015/07/announcing-minecraft-windows-10-edition-beta/</ref><ref></ref> <ref name="Windows Store">商店页面：https://www.microsoft.com/store/apps/Minecraft-Windows-10-Edition-Beta/9NBLGGH2JHXJ</ref>它包含与基岩版相同的内容，以及一些额外内容<ref>https://www.reddit.com/r/Minecraft/comments/3c3e5m/announcing_minecraft_windows_10_edition_beta/csry0j5</ref>，并且能够在诸如[HoloLens](wzh:Microsoft HoloLens.md)之类的设备上运行。<ref name="TommasoReddit">https://www.reddit.com/r/Minecraft/comments/3c3e5m/announcing_minecraft_windows_10_edition_beta/csry0j5</ref><ref name="TommasoTweet"></ref><ref name="Minecon2015 BehindTheScenes">http://www.twitch.tv/mojang/v/6949826</ref>

此版本在2015年7月4日宣布。Beta版于2015年7月29日在Windows Store发布，价格为7.99英镑、9.99美元、9.89欧元、71人民币、78港币或335新台币。在北京时间2018年10月19日18点之前购买过[Java版](Java版.md)的用户能免费获得Windows 10版的兑换码，<ref></ref>该兑换码的有效期限为2020年4月20日。Windows 10版在2016年12月19日完成测试并发布1.0正式版。现在其在Microsoft商店需要花费26.95美元、71人民币、78港币或335新台币。

Windows 10版能与对应的基岩版进行局域网联机。<ref name="Windows10Minecraft"/>

# 开发
早在[Mojang博客](Mojang博客.md)的官方宣告出现之前，微软就释出各种有关Minecraft在HoloLens上的宣传影片<ref name="HoloLensPromotion">https://www.youtube.com/watch?v=aThCr0PsyuA</ref>稍后的[2015电子娱乐展](wzh:E3 2015.md)上，[Lydia Winters](Lydia Winters.md)与某微软员工分别使用[Surface Pro](wzh:Microsoft Surface.md)与HoloLens展出了在Windows 10平台上运行的Minecraft并与之互动。<ref name="HoloLens-E32015">https://www.youtube.com/watch?v=3TJEuSiMo0A&t=1h42m53s</ref>

Minecon 2015上，有关于Windows 10版开发进程的消息又被放出，并解释其发布的原因：由于微软通用应用框架不支持Java程序，故不可能将Java版作为通用应用。<ref name="Minecon2015 BehindTheScenes" />

在基岩版特性以外，Windows 10版也可以通过Xbox Live与最多7人进行在线游戏，或使用在[Realms](Realms.md)与其他基岩版玩家一起游戏。<ref>https://www.youtube.com/watch?v=szAKnJLmCKU</ref>

另一些额外独占特性包括多控制计划，一个玩家反馈特性，使用系统内建GameDVR来记录并分享游戏内容。<ref name="Windows10Minecraft"/><ref></ref>

# 其他平台
# = Microsoft HoloLens =
[350px|缩略图|E3 2015上的Minecraft HoloLens版，在一张桌子上运行于“实感”模式呈现出[[Lydia Winters](File:MinecraftHoloLens-RealityMode-E32015.png.md)的世界]]
在微软的Windows 10会后，[Jens Bergensten](Jens Bergensten.md)最早发推宣布Holograpic版的Minecraft将被开发是在2015年1月21日。他表示两个Minecraft项目将进行，其中一个是“玩具”，另一个则“更接近游戏”。<ref name="JebHoloLensTweet"></ref>

E3 2015展会的微软展区中可以看见正在演示Windows 10版Minecraft的[HoloLens](wzh:Microsoft HoloLens.md)与Surface Pro 3在同步运行。<ref name="HoloLens-E32015" />

有两种模式已被展出，其一为“墙壁”模式，玩家可以使用Xbox控制器来互动，常规的Minecraft世界将被全息映射进一堵墙。玩家可以调整视野范围并锁定，使得玩家可以左右观察，类似不需要控制器的窗口模式。<ref name="EngadgetMineconDemo">http://www.engadget.com/2015/07/08/minecraft-hololens-minecon/</ref>另一个为“实感”模式，玩家可以不使用控制器，并将3D世界映射到一个现实物件上，例如一张桌子。

实感模式下，玩家可以使用声控命令或者手势等头戴机械支持的方式与世界交互。它是可能的目标语音命令的地图的特定区域对他们的一瞥，例如，直接在一个对象，使用一个命令，如“Lighting bolt”会召唤一道[闪电](闪电.md)。另一个例子是能力的“标记”区域通过看一个对象创建一个垂直的光柱，类似[信标](信标.md)。语音命令还可以用来改变世界的视图，并允许以下一种模式，如“关闭”或“概述”改变如何关闭相机是玩家的玩家。可以用像是用智能手机一样的用手势放大与缩小世界的视图。

# = Oculus Rift =
2015年9月15日，Minecraft将适配[Oculus Rift](wzh:Oculus Rift.md)的消息被放出。此版本是Windows 10版的分支，在包括全部既有特性之余，还将会是完整的3D。此版本将在Windows Store和Oculus Store发售，计划在2016年春季发布。<ref></ref><ref>http://news.xbox.com/2015/09/games-minecraft-windows-10-edition-coming-to-oculus-rift?linkId=17303547</ref>
