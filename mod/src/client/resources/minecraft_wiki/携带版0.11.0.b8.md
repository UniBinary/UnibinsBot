# 携带版0.11.0.b8

*页面ID: 27985* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.11.0 alpha build 8**是[v0.11.0 alpha](携带版0.11.0.md)的第8个测试版，发布于2015年4月29日，加入了岩浆怪和恶魂的刷怪蛋，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了[岩浆怪](岩浆怪.md)和[恶魂](恶魂.md)的刷怪蛋。
* * 以前只能通过第三方程序修改并生成。

# 更改
# = 物品 =
* *[钓鱼竿](钓鱼竿.md)**
* 现在会断开在骑乘者与被骑乘者间的连接。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 更改了默认生物群系。

# 修复
0处。
|8221|无法使用钓鱼竿钓鱼。
|8258|无法在船上聊天。
|8282|所有的石英变种都使用了统一的名称“石英块”。
|8284|末影人刷怪蛋名称错误。
|8302|船上的钓鱼机制出现问题。
|8313|可以使用钓鱼竿勾住不在附近的玩家，甚至是不在视线内的玩家。
}}
* *其他漏洞**
* 骑乘时从服务器断开连接使得游戏崩溃。
* 从刷怪蛋处生成的生物会穿过方块坠落。
* 死亡后玩家会保留物品栏。
* 移除了多余的无序队列<!-- dirty queue -->以提升性能。
* 热带草原里过多高草丛生成。
* 改进了重新生成和传送机制。</onlyinclude>
