# 着火

*页面ID: 43330* | *来源: Minecraft Wiki*

[thumb|日出会以施加着火效果的方式清除户外的亡灵生物](File:Zombie Death.png.md)
* *着火（Burning）**是一种常见的影响实体的效果，通常使实体受到火焰伤害。

# 机制
当[实体](实体.md)的剩余着火时间（实体数据<code>Fire</code>）高于0时，实体便会进入着火状态。

# = 外观 =
着火的实体上会出现伪3D渲染的火纹理，着火的玩家的第一人称界面也会出现遮住界面的火纹理。

着火的生物会变为橙色，在它们的身体附近发出大的火[粒子](粒子.md)，当玩家着火时动画会和[Java版](Java版.md)的不同（当向下看时它会被部分遮挡）。

# = 剩余着火时间 =
当生物不再被增加剩余着火时间时，剩余着火时间会持续下降，生物的实体数据<code>Fire</code>每减少1。

一旦<code>Fire</code>不高于0，非[玩家](玩家.md)实体的<code>Fire</code>会被设置为-1，非[旁观模式](旁观模式.md)玩家的<code>Fire</code>会被设置为-20，而旁观模式玩家的<code>Fire</code>会保持在0。负数的着火时间可以提供短暂的对[火](火.md)或[灵魂火](灵魂火.md)的抵抗，使玩家短暂接触火时不会被长时间点燃。尝试使用命令或其他方式将生物的<code>Fire</code>设置到不高于0的任何值都会使其回到-1或-20到-1。

多种效果会影响剩余着火时间：
* 装备具有[火焰保护](火焰保护.md)魔咒的物品会降低对着火时间最低值的设置，所有装备的魔咒等级的总和每有1级使设置的时间减少15%，达到7级时无法因[火](火.md)或[灵魂火](灵魂火.md)以外的因素着火。
* 具有[抗火](抗火.md)效果的生物不能着火。
* [僵尸猪灵](僵尸猪灵.md)、[恶魂](恶魂.md)、[凋灵骷髅](凋灵骷髅.md)、[烈焰人](烈焰人.md)、[炽足兽](炽足兽.md)、[岩浆怪](岩浆怪.md)、[潜影贝](潜影贝.md)、[僵尸疣猪兽](僵尸疣猪兽.md)、[监守者](监守者.md)、[末影龙](末影龙.md)、[凋灵](凋灵.md)、与[嘎枝之心](嘎枝之心.md)绑定的[嘎枝](嘎枝.md)、[下界合金质物品实体](物品（实体）.md)不能着火，不会出现着火的外观，其剩余着火时间不能高于0。
* 处于[创造模式](创造模式.md)或旁观模式的玩家剩余着火时间不能高于1。
* 与[水](水.md)、[雨](雨.md)接触的生物，其剩余着火时间不能高于0。
* 与装有水的[炼药锅](炼药锅.md)接触的生物，其剩余着火时间不能高于0，并消耗一层水。
* 与装有[细雪](细雪.md)的炼药锅接触的生物，其剩余着火时间不能高于0，并将炼药锅内的细雪融化成少一层的水。
* 与细雪接触的生物，其剩余着火时间会被清除并回到最低值，并破坏这格细雪。

# 着火效果
着火的[实体](实体.md)每会受到火焰伤害。

着火的[弹射物](弹射物.md)可使其撞击到的[TNT](TNT.md)被点燃，也可摧毁其穿过的细雪。

着火的[僵尸](僵尸.md)、[僵尸村民](僵尸村民.md)、[尸壳](尸壳.md)或[溺尸](溺尸.md)的每次攻击有<code>-{}-[区域难度](区域难度.md)×30%</code>的概率会导致被攻击的目标着火，设置其剩余着火时间为<code>-{}-floor(区域难度) × 40</code>游戏刻。着火的僵尸、僵尸村民、尸壳或溺尸在普通或困难[难度](难度.md)下总会使受到攻击的生物着火，持续时间为2秒。

部分生物的部分掉落物会在该生物着火时死亡时转换为进行过[烧炼](烧炼.md)配方的结果：

能引发着火的伤害杀死与可以消除着火的环境接触的生物时（如使用带有[火焰附加](火焰附加.md)魔咒的武器杀死水中的鱼），会掉落对应的熟食，会掉落对应的生食。

此外，[火](火.md)或[灵魂火](灵魂火.md)持续增加生物的剩余着火时间，无视生物的具有[火焰保护](火焰保护.md)魔咒的盔甲。
* 当生物处于火或灵魂火中时，剩余着火时间不会下降。
* 当生物的剩余着火时间不高于0时，剩余着火时间将会每增加。
* 当生物的剩余着火时间高于0时，剩余着火时间将会每增加。
* 当生物在火或灵魂火中移动时，剩余着火时间将会额外每增加。

[火球](火球.md)和[小火球](小火球.md)默认是着火的，其着火状态不能被任何方式熄灭。

# 你知道吗
* [抗火](抗火.md)效果使生物免疫火焰伤害，但不影响着火机制，具有抗火效果的生物仍然会着火，持续到抗火效果结束的着火状态会正常地造成伤害。
* [烈焰人](烈焰人.md)的攻击使用与着火时一样的动画，使自身看上去像是着火了一样，尽管烈焰人实际上不能着火。
* 一些对火焰伤害免疫的生物被[闪电](闪电.md)击中后仍然会出现着火的外观。
* 玩家存档中不会保存着火信息。
