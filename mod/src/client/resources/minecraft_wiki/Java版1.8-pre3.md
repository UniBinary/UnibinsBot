# Java版1.8-pre3

*页面ID: 20529* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.8-pre3**是[Java版1.8](Java版1.8.md)的第3个，也是最后一个预发布版，发布于2014年8月28日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[绊线](绊线.md)**
* 绊线破坏立即引起[绊线钩](绊线钩.md)的状态变化时，绊线的位置只有被[空气](空气.md)以外的方块（一般是[液体](液体.md)）占据才会重新生成绊线。

# 修复
键全屏的效果不对。

|66511|苦力怕攻击铁傀儡的优先级比躲避猫（豹猫）的优先级高。
|69052|坐标值大于30,000,000时游戏进程被挂起。

|69638|多个放置在一起的TNT矿车爆炸并摧毁盔甲架时，盔甲架上的物品会被复制（另外有幽灵物品生成）。
