# Java版20w22a

*页面ID: 62940* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w22a**是[Java版1.16](Java版1.16.md)的第19个，也是最后一个快照，发布于2020年5月29日<ref name="20w22a"></ref>，加入了新的死亡消息和新的方块标签，更新了着色器，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[死亡消息](死亡消息.md)**
* 加入了玩家被实体发射的凋灵之首杀死的死亡消息：“”。

# = 常规 =
* *[着色器](着色器.md)**
* 加入了<code>assets/minecraft/shaders/post/transparency.json</code>。

* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 应用于全部8种栅栏门类型。
* 加入了方块标签。
* * 应用于方块标签。
* * 此标签下的方块底部不能连接[灯笼](灯笼.md)和[钟](钟.md)。

# 更改
# = 方块 =
* *[钟](钟.md)**
* 现在挂在方块的底部时，将与[灯笼](灯笼.md)的放置规则一致，它可以被挂在下列方块的底部：
* * [铁砧](铁砧.md)（所有开裂阶段）
* * [酿造台](酿造台.md)
* * [锁链](锁链.md)
* * [末影箱](末影箱.md)
* * [末地烛](末地烛.md)（朝上和朝下）
* * [栅栏](栅栏.md)（所有种类）
* * [花盆](花盆.md)（以及内含物体的变种）
* * [玻璃板](玻璃板.md)（以及染色变种）
* * [砂轮](砂轮.md)（连接到天花板的）
* * [漏斗](漏斗.md)（朝下）
* * [铁栏杆](铁栏杆.md)
* * [生物头颅](生物头颅.md)
* * [活塞](活塞.md)（朝侧面伸出）
* * [陷阱箱](陷阱箱.md)
* * [墙](墙.md)（所有种类）

* *[营火](营火.md)**
* 现在当营火被锹或水瓶扑灭后，其上面的食物会掉下来。

* *[菌岩](菌岩.md)**
* 现在必须使用带有[精准采集](精准采集.md)魔咒的工具采集，否则只会掉落[下界岩](下界岩.md)。

* *[锻造台](锻造台.md)**
* 将UI中的锤子图标稍微向左移动了一些。

* *[灵魂营火](灵魂营火.md)**
* 现在会造成普通营火的两倍伤害。

* *[拼图方块](拼图方块.md)**
* 加入了“保留拼图”选项，以控制生成结构后是否保留该拼图方块。
* * 默认为“开启”。

# = 生物 =
* *常规**
* 当玩家按住键时，将无法骑上可骑乘实体。

* *[猪灵](猪灵.md)**
* 现在有10%的概率会在杀死[疣猪兽](疣猪兽.md)之后“跳舞”。
* 如果它们有[剑](剑.md)，现在它们会在敌对状态下举起它。

* *[蜜蜂](蜜蜂.md)**
* 现在在蜂巢内也会生长以及计算繁殖冷却时间。

* *[末影人](末影人.md)**
* 手持方块时不会消失了。

* *[村民](村民.md)**
* 更改了村民工作站点的运作逻辑。
* * 多个村民现在不会试图在同一个站点工作。
* * 站点附近有着对应职业的经验值最高的村民会获得此工作站点。
* * 村民现在必须到达工作站点后才能获得对应职业以及开始工作。
* * 村民在其工作站点16格距离内时会始终检查并确保其工作站点有效。
* 现在经验栏会准确显示村民具有和需要的经验值了。
* [时钟](时钟.md)和[指南针](指南针.md)在村民交易界面里不再工作。

* *[女巫](女巫.md)**
* 曾进行过交易的村民被[闪电](闪电.md)击中后变成的女巫不会消失了。

* *[猪灵](猪灵.md)**
* 握着金剑的猪灵在敌对状态时会举起手臂。

* *[僵尸猪灵](僵尸猪灵.md)**
* 现在手臂会向前伸，类似于[僵尸](僵尸.md)。
* 更改了纹理。

# = 世界生成 =
* *[玄武岩柱](玄武岩柱.md)**
* 现在生成时底部会浸没在[熔岩](熔岩.md)海内，而不是在其上方。

* *[箱子战利品](箱子战利品.md)**
* 现在相同[种子](种子（世界生成）.md)下的箱子战利品不再会随机生成。

* *结构**
* [化石](化石.md)不再会生成于[沙漠神殿](沙漠神殿.md)内部。
* [地牢](地牢.md)内的[刷怪笼](刷怪笼.md)不再会被[圆石](圆石.md)替代。
* [要塞](要塞.md)内的[末地传送门](末地传送门.md)不再会被[化石](化石.md)、[海底神殿](海底神殿.md)或[地牢](地牢.md)替代。

# = 游戏内容 =
* *[进度](进度.md)**
* “”现在也可通过采集[蜂箱](蜂箱.md)中的蜂蜜来达成。

* *[修复](修复.md)**
* 现在可以用[黑石](黑石.md)修复石质工具。

# = 命令格式 =
* ***
* 现在可以清除合成格内的物品。

# = 常规 =
* *碰撞**
* 优化了碰撞箱的检测。

* *[数据包](数据包.md)**
* 略微更改了数据包的加载以防止自定义数据包发生崩溃。
* 如果数据包重新加载失败，将不会应用，游戏将继续使用以前的数据。
* * 只有在成功重新加载后，才会开始存储对数据包列表的更改。
* 如果现有的数据包阻止世界加载，游戏将提供在安全模式下加载世界的选项，该模式下只加载默认纹理数据包。
* 为服务端添加了<code>--safeMode</code>参数选项，启用此参数后，服务器只加载默认纹理数据包。
* 游戏现在将检测任何关键的数据包问题，例如所需的标签丢失，游戏将阻止世界被加载。

* *[材料](材料.md)**
* 现在，方块的破坏工具不再取决于材料，而是按方块逐一指定。

* *寻路**
* 寻路时会自动缓存重复的方块类型和碰撞体积以提高性能。

* *[战利品表谓词](战利品表谓词.md)**
* 现在战利品表谓词函数中的顶级元素可以是数组（添加了<code>and</code>方法）。

* *渲染**
* 对图形渲染进行实验性更改。
* 添加了用于访问深度缓冲区的着色器的支持。
* 渲染器现在对一些透明元素使用逐像素混合层。
