* *绊线钩（Tripwire Hook）**是一种可用于在[绊线](绊线.md)线路中检测[实体](实体.md)的[方块](方块.md)。

# 生成
# = 自然生成 =
[丛林神庙](丛林神庙.md)中会生成4个绊线钩。

[试炼密室](试炼密室.md)的柱廊结构及<code>encounter_4</code>结构中会生成绊线钩。

# 破坏
绊线钩被挖掘时会立刻被破坏，用于挖掘的工具的耐久度不会下降。

绊线钩被破坏后会掉落自身。

绊线钩被破坏时（放置后立即被来自对侧绊线钩的[方块更新](方块更新.md)破坏的除外）计算绊线线路当前的正确状态，并依次放置相应状态的对侧绊线钩和绊线，放置绊线时不检查绊线线路是否再次改变状态。

# 用途
绊线钩可以用作合成材料或红石元件。

绊线钩在如下情况会被破坏并掉落自身：
* 其附着的方块被移动或移除。
* [水](水.md)流到其所在位置。
* [活塞头](活塞头.md)推入其位置或活塞将方块推入其位置。

若[熔岩](熔岩.md)流过绊线钩，绊线钩将会被摧毁而不会掉落物品。

# = 红石元件 =

绊线钩可用于在大面积区域中检测生物、物品和其他[实体](实体.md)。

; 放置
   绊线钩可以附着在任何固体方块的**侧面**。
   要使绊线钩正常运作，其必须构成“绊线线路”：在一条直线上，两端为附着在方块上的绊线钩，中间用1-40个[绊线](绊线.md)连接。

   在无效绊线线路中的绊线钩会显现出“折叠”的样子，而在有效绊线线路中的绊线钩则会显现出“伸直”的样子。不同绊线线路的绊线可以并排放置，也可以上下堆叠，甚至可以交叉放置。
   绊线钩被放置时计算绊线线路当前的正确状态，并依次放置相应状态的对侧绊线钩、本侧绊线钩和绊线，放置本侧绊线钩和绊线时不检查绊线线路是否再次改变状态和绊线钩是否已被破坏。

; 触发
   在有效绊线线路中的绊线钩会在特定[实体](实体.md)（玩家、生物、物品等）与绊线钩的绊线“碰撞箱”交互时被触发。
   不会触发绊线线路的实体包含一些[箭](箭.md)、扔出的[药水](药水.md)、[末影珍珠](末影珍珠.md)和[末影之眼](末影之眼.md)等。
   绊线钩在绊线线路中的任何一个绊线被摧毁时会持续触发。

   但是用[剪刀](剪刀.md)摧毁绊线不会触发绊线钩，破坏绊线钩也不会产生脉冲信号。不过它们都会更改绊线钩的方块状态（其“附着”状态从<code>true</code>变为 <code>false</code>），这个变更可以用侦测器探测到。绊线自身不会产生信号，但其状态更改也可以用[侦测器](侦测器.md)探测到。

   绊线钩被触发或结束触发时计算绊线线路当前的正确状态，并依次放置相应状态的对侧绊线钩、本侧绊线钩和绊线，放置本侧绊线钩和绊线时不检查绊线线路是否再次改变状态和绊线钩、绊线是否已被破坏。

; 行为
[缩略图|绊线钩被触发时输出信号以及强充能其附着方块，绊线不会输出信号](File:Tripwire hook as power source.png.md)

激活时，绊线钩会向下折叠并且会：
  * 激活毗邻的[红石粉](红石粉.md)至[信号强度](红石电路.md)15。
  * 向背对着绊线钩的[红石比较器](红石比较器.md)或[红石中继器](红石中继器.md)提供15等级的信号。
  * 强充能其附着方块至充能等级15。
  * 激活毗邻的机械元件（例外：活塞不会被其活塞臂朝向的电源激活）。

# 你知道吗
* 绊线线路状态变化时，绊线钩先记录线路的状态，再依次设置对侧绊线钩和自身的状态以及绊线的状态（若绊线钩的状态有变化）；若绊线钩附着[门](门.md)或[活板门](活板门.md)，线路中绊线钩信号的变化可以激活或取消激活门或活板门，从而破坏附着在门上的绊线钩，并引起绊线钩和绊线状态的变化，但这些变化可以被先更新线路状态的绊线钩后续设置的状态覆盖。
* 若绊线线路中的一个绊线被破坏后迅速插入一个绊线钩，线路东、北侧绊线钩和所有绊线的状态不会更新。
