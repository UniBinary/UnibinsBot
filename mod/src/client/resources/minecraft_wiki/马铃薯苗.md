* *马铃薯苗（Potato Sprouts）**是一种能够生长为[马铃薯树](马铃薯树.md)的[植物](植物.md)。

# 生成
# = 自然生成 =
马铃薯苗会在[马铃薯维度](马铃薯维度.md)的[腐败区](腐败区.md)生物群系自然生成。

# 获取
# = 马铃薯树叶 =
当[马铃薯树叶](马铃薯树叶.md)自然枯萎消失或被破坏（不使用[精准采集](精准采集.md)附魔工具或[剪刀](剪刀.md)）时，它们有5%的概率掉落1个马铃薯苗。

[时运](时运.md)魔咒会增加马铃薯苗的掉落概率，等级I为6.25%，等级II为8.33%，等级III为10%。

# = 箱子战利品 =

# 破坏
马铃薯苗被挖掘时会立刻被破坏。

马铃薯苗被破坏后会掉落自身。

# 用途
# = 生长 =
马铃薯苗可被种植在[马铃薯泥土](马铃薯泥土.md)、[薯皮草方块](薯皮草方块.md)和[腐败的薯皮草方块](腐败的薯皮草方块.md)上。

马铃薯苗的生长由[随机刻](随机刻.md)控制。马铃薯苗上方1格的[亮度](亮度.md)等级（在方块光照和天空光照中取较大值）至少为9时，马铃薯苗才能生长成[马铃薯树](马铃薯树.md)。

马铃薯苗上方的[树叶](树叶.md)、原木、带有标签的方块通常不会阻止其生长，但有一些例外。长出的树木会穿过这些方块，有时还能将它们替换掉。

# = 堆肥 =
将马铃薯苗放进[堆肥桶](堆肥桶.md)里有30%概率增加1个堆肥层。
