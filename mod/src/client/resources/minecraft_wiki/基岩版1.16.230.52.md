# 基岩版1.16.230.52

*页面ID: 80901* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.230.52**是[基岩版1.17.0](基岩版1.17.0.md)的第2个测试版，发布于2021年3月31日<ref></ref><ref></ref>，加入了[美西螈](美西螈.md)和[深板岩](深板岩.md)相关方块，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[深板岩](深板岩.md)**
* 目前仅在主世界Y=-4至16处以[团簇](团簇.md)的形式生成。
* 硬度比[石头](石头.md)高，但可用任何镐开采。
* 破坏后掉落[深板岩圆石](深板岩圆石.md)。
* 可用附有[精准采集](精准采集.md)魔咒的镐开采获得。
* 共拥有20个变种：

* 目前属于[实验性玩法](实验性玩法.md)（子选项）。
* 对于深板岩圆石而言：
* * 深板岩圆石可用未附有精准采集魔咒的镐开采深板岩获得。
* * 深板岩圆石、[磨制深板岩](磨制深板岩.md)、[雕纹深板岩](雕纹深板岩.md)、[深板岩砖](深板岩砖.md)和[深板岩瓦](深板岩瓦.md)可用于合成对应的楼梯、台阶和墙变种。
* ** 深板岩砖和深板岩瓦可通过熔炉烧炼获得对应的裂纹变种。
* * 可在熔炉中重新烧炼为深板岩。

* *[深层矿石](深层矿石.md)**
* 加入了所有主世界矿石的深层变种，包括铁、金、铜、煤、钻石、红石、绿宝石和青金石。
* 开采时间为浅层矿石的2倍。
* 纹理上以深板岩替换石头作为容矿岩。
* 在深板岩团簇中生成。
* 可用于像浅层矿石一样烧炼为矿物。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了美西螈刷怪蛋。
* * 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# = 生物 =
* *[美西螈](美西螈.md)**
* 目前无法自然生成。
* 会跟随手持[热带鱼桶](热带鱼桶.md)的玩家。
* * 无法驯服，但可以用热带鱼桶繁殖。
* 会主动攻击鱼、[鱿鱼](鱿鱼.md)、[溺尸](溺尸.md)和[守卫者](守卫者.md)。
* 拥有多种颜色变种，除了蓝色变种之外会等概率生成。
* * 幼年蓝色美西螈会在繁殖时小概率生成。
* 可在离开水的情况下存活数分钟，此后便会开始脱水并持续受到伤害直到重新进入水中。
* 受到伤害时有一定概率装死，此时其会恢复生命值并且不会受到其他生物攻击。
* 玩家杀死美西螈的攻击目标生物时会获得[生命恢复](生命恢复.md)效果。若玩家同时带有[挖掘疲劳](挖掘疲劳.md)效果，则该效果会被移除。
* 可像鱼一样被[铁桶](铁桶.md)或[水桶](水桶.md)装起。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# 修复
* *常规**
* 提高了水中的能见度，特别是在水下洞穴中。
* 现在可以为氧化的铜块涂蜡。
* 调整了可放置在滴水石锥上的方块以匹配Java版。（、和）
* 滴水石锥现在被活塞推动时会被破坏。（）
* 现在在滴水石块和滴水石锥上行走和跳跃会正确播放音效。（）
* 发光地衣现在位于创造模式物品栏的自然分类中。（）
* 闪电劈中避雷针时现在会正确被侦测器侦测。
* 大型垂滴叶现在可以含水了。
* 大型垂滴叶现在被弹射物击中会正确倾斜。（）
* 小型垂滴叶现在可以放置在上方为水的泥土、草方块、苔藓块和灰化土上。
* 苔藓块现在可以将水替换掉。（）
* 梯子、藤蔓、缠怨藤、垂泪藤、甜浆果丛、下界苗和火现在可以放置在苔藓块上。（）
* 现在孢子花被破坏后会正确掉落其自身。（）
* 生物现在可以在苔藓块上正确寻路。（）
* 现在繁茂洞穴中会生成普通藤蔓。
* 修复了屏幕阅读器不会读取部分屏幕上的焦点按钮的漏洞。
* 修复了屏幕阅读器将英文“A button”读作“a button”的漏洞，现在将“A button”重命名为“Button A”。
* 手持三叉戟的玩家和生物现在在各个角度都会正确渲染。（）
* 修改了第一人称视角下投掷三叉戟的动画以使其与之前同步。
* 水桶现在可以正常装起鱼了。（）

* *生物**
* 兔子现在会偷吃胡萝卜作物。（）
* 繁殖动物之前不再能够无限喂食它们了。（）</onlyinclude>
