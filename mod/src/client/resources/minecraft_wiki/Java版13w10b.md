# Java版13w10b

*页面ID: 33501* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w10b**是[Java版1.5](Java版1.5.md)的第15个，也是最后一个快照，发布于2013年3月6日<ref></ref>，更新了发射器和投掷器的发射机制，并修复了[13w10a](13w10a.md)里的漏洞和崩溃。

# 更改
# = 方块 =
* *[发射器](发射器.md)和[投掷器](投掷器.md)**
* 现在只会在收到红石信号时发射。要想再次发射，信号必须关闭并再次开启。（之前它们会在有信号和旁边有方块更新时就发射）。
