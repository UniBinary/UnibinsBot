* *末地烛（End Rod）**是一种装饰性[光源](亮度#发光方块.md)，会产生白色粒子。

# 生成
# = 自然生成 =
末地烛自然生成于[末地城](末地城.md)中。

# = 合成 =

# 破坏
末地烛被挖掘时会立刻被破坏。

末地烛被破坏后会掉落自身。

# 用途
[缩略图|末地烛在[[紫珀块](File:EndRodPositions.png.md)上的不同朝向]]

末地烛具有朝向，且当尝试在另一个末地烛的灯柱顶面上放置末地烛时，游戏会放置方向相反的末地烛，使二者的灯柱对接。

末地烛主要用于装饰和充当光源，会发出亮度等级为14的[光](光.md)。它可以放置在任何方块的表面，且不会因支撑它的方块被破坏而掉落。在[末地城](末地城.md)里，它们被设计为螺旋楼梯的一部分供玩家爬上塔顶。

[下落的方块](下落的方块.md)（比如[沙子](沙子.md)、[铁砧](铁砧.md)和[沙砾](沙砾.md)）掉落在竖直的末地烛上不会被破坏，但掉落到水平朝向的末地烛上会被破坏。无论朝向，末地烛都可被[活塞](活塞.md)推拉。

末地烛会被流动的和[熔岩](熔岩.md)破坏。

末地烛可以[含水](含水.md)（流动或水源），且在竖直朝向时可以作为[红石中继器](红石中继器.md)、[红石比较器](红石比较器.md)、[火把](火把.md)、[灵魂火把](灵魂火把.md)、[红石火把](红石火把.md)、[灯笼](灯笼.md)、[灵魂灯笼](灵魂灯笼.md)、[压力板](压力板.md)、[蜡烛](蜡烛.md)、[砂轮](砂轮.md)等方块的支撑。
