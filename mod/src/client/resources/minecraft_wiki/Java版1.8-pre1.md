# Java版1.8-pre1

*页面ID: 15786* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.8-pre1**是[Java版1.8](Java版1.8.md)的首个预发布版，发布于2014年8月22日<ref></ref>，加入了1种新的默认皮肤和1条新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[皮肤](皮肤.md)**
* 新的默认皮肤：Alex<ref>https://help.mojang.com/customer/portal/articles/979200-minecraft-skins</ref>
* * Alex的皮肤特点似是姜黄色头发的女性穿着一个绿上衣，棕色的裤子和黑色的靴子以及3像素宽臂。
* * 所有的账户将被随机分配Steve或Alex的皮肤。
* 未来能在minecraft.net/profile选择4或3像素的手臂。
* * 然而，在预览版本有一个会显示错误模型的漏洞。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了闪烁标语“Any computer is a laptop if you're brave enough!”。

# 更改
# = 生物 =
* *[杀手兔](杀手兔.md)**
* 纹理不再包含血。

# = 常规 =
* *[Realms](Realms.md)**
* 现在Realms不可以上传[极限模式](极限模式.md)世界。
