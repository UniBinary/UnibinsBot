# 基岩版1.5.0.4

*页面ID: 34752* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.5.0.4**是[1.5.0](基岩版1.5.0.md)的第3个测试版，发布于2018年5月16日<ref></ref>，加入了首批[水域更新](水域更新.md)（第二部分）的特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[气泡柱](气泡柱.md)**
* 通过在水中放置[灵魂沙](灵魂沙.md)或[岩浆块](岩浆块.md)生成。
* * 岩浆块气泡柱会将实体向下拉；灵魂沙气泡柱会将实体向上推。
* 默认情况下，气泡柱的纹理与[Java版](Java版.md)不同。可以通过设置让它看起来与[Java版](Java版.md)的外观相似。

* *[海龟蛋](海龟蛋.md)**
* 通过繁殖[海龟](海龟.md)生成。

# = 物品 =
* *[鳞甲](鳞甲.md)**
* 会在幼年海龟长大时掉落。
* 可以用来合成海龟壳。

* *[海龟壳](海龟壳.md)**
* 合成配方：

* 可以用作头盔，会增加护甲值。
* * 装备时，玩家在空气中会获得10秒的[水下呼吸](水下呼吸（状态效果）.md)状态效果。<!-- While equipped and in air, it will give the player the [Water Breathing](Water Breathing.md) effect for 10 seconds. -->

* *[神龟药水](神龟药水.md)**
* 用海龟壳酿造而成。
* 给予玩家[](缓慢.md)IV和[抗性提升](抗性提升.md)III状态效果。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了[海龟](海龟.md)刷怪蛋。

# = 生物 =
* *[海龟](海龟.md)**
* 一种水生生物，在各种生物群系的岸边产卵。
* 可以使用[海草](海草.md)繁殖。
* 以一小群的形式在温暖的海滩上生成。
* 在它们作为家的海滩上产卵。
* 死亡时会掉落0-2个海草。

# = 常规 =
* *[全景图](全景图.md)**
* 更新为水域更新全景图。

# 更改
# = 方块 =
* *[珊瑚块](珊瑚块.md)**
* 现在只要接触到水就不会死亡。

* *[海带](海带.md)**
* 更改了顶部纹理。

# = 物品 =
* *[熟鳕鱼](熟鳕鱼.md)**
* 更改了纹理。

# = 常规 =
* *[设置](设置.md)**
* 默认视野从70更改为60。

# 修复
* *修复了44个漏洞**
* 修复了一些在游戏过程中经常出现的漏洞。
* 活塞推动方块时游戏崩溃。
* 区块内放置过多数量的海泡菜使得游戏崩溃。
* 改进了末影龙的攻击时出现的粒子效果。
* 守卫者和远古守卫者会停留在海底不动。
* 玩家在1×1的空隙内游泳时，无法获得潮涌能量效果。
* 存储界面里的缓存数据无法显示。
* 移除资源包后重新进入世界时，玩家会继承世界主人的出生地和物品栏信息。
* 安卓设备里的热带鱼纹理不正确。
* 使用命令提供的埋藏的宝藏的坐标不正确。
* 按下控制器里的向下键使得聊天区域处于非活动状态。
* 洞穴和峡谷里的水不会流动或者流动不同步。
* 信标和潮涌核心没有音效。
* 命令方块不能切换“重复”和“保持激活”。
* 熔岩流到被水浸没的海草或海带时不再生成石头。
* 红石线，火把和红石火把可以替代水下的海草放置。
* 三叉戟可以一次性伤害多个实体。
* 船上的生物可以免疫坠落伤害。
* 在游泳时很难攻击生物。
* 在水面挖掘方块时，开裂纹理不会显示。
* 转换世界时，已染色的马铠会失去染色。
* 热带高原和恶地高原生物群系在转换世界时生成错误。
* 变种生物群系里的水的颜色不正常。
* 暂停游戏然后更改资料后，控制器断开连接。
* 使用命令时，地图物品现在有了正确的名称。
* 区块渲染时，玩家可以在特定角度下透视地下的地形。
* 掉落物在坠落时动画有延迟。
* 经验球无法被玩家捡起。
* 溺尸有时会原地旋转。
* 转化成溺尸的僵尸在死后不会掉落其手持的物品。
* 在成群游泳时，海豚和鳕鱼会交缠。
* 蠹虫无法钻进石头里。
* 由骷髅和流浪者射出的箭无法伤害凋灵。
* 在游泳时，物品栏内的玩家形象会冻结。
* 由发射器发射出的三叉戟不会损失耐久度，且轨迹出现错误。
* 开启教育版选项后，低端设备会丢失纹理。
* 僵尸在寻路时出现错误。
* 水平放置的活塞的底部纹理出现错误。
* TNT在水下放置在非全体积方块上时，仍然可以造成伤害和摧毁方块。
* 珊瑚扇的判定箱不正确。
* 资料选项“管理可发送邀请的好友”按钮位置出现错误。
* 远古守卫者生成不正确。
* 部分热带鱼变种的拼写不正确。
* 游戏指南的“控制”选项在重新映射潜行按钮时不会更新。</onlyinclude>
