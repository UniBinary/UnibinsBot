# Java版Infdev 20100616-1808

*页面ID: 45436* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年6月16日。<ref></ref>

# 新内容
# = 世界生成 =
* *[洞穴](洞穴.md)**
* 被重新加入。
* 区域性的洞穴。
* * 现在某些地区的洞穴多于其他地区。

* *[涌泉](涌泉.md)**
* 会流出[水](水.md)或[熔岩](熔岩.md)。

# 更改
# = 常规 =
* *[树叶](树叶.md)**
* 现在会受流畅/高品质图形选项影响了。

* *[液体](液体.md)**
* 改进了流动机制。
[水](水.md)现在有了更多的棱锥状模型，而不再只有平整的方块形。

* *[基岩](基岩.md)**
* 现在在世界最下方5层生成。

* *[花](花.md)**
* 现在会自然生成了。

* *[蘑菇](蘑菇.md)**
* 现在会自然生成了。

# = 世界生成 =
* *常规**
* 海岸线现在更加渐进，使得海洋总体上减小了。</onlyinclude>
