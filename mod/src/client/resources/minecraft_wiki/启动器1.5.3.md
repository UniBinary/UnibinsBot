# 启动器1.5.3

*页面ID: 50800* | *来源: Minecraft Wiki*

* *1.5.3**是2014年9月1日发布的一个[启动器](启动器.md)小更新。

# 修复
*  - Windows 8.1安装其他字体会使启动器停止运行。
*  - 启动器在可以游玩在线服务器时仍然显示离线。
*  - Realms 1.5.8校验失败。
*  - 客户端中的更新日志网页代码中忘记打了“<”。
