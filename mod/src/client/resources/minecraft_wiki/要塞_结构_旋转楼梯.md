# = 逐层构造 =
旋转楼梯间的入口和出口可以有多种生成方式，因此逐层构造图分成多个版本，如“1层a”和“1层b”。“a”表示木门入口，“b”表示铁门入口，“c”表示带有铁栏杆的入口，“d”表示普通入口。
