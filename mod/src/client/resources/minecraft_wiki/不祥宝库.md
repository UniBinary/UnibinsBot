# 不祥宝库

*页面ID: 169579* | *来源: Minecraft Wiki*

* *不祥宝库（Ominous Vault）**是[宝库](宝库.md)的不祥变种，被[不祥试炼钥匙](不祥试炼钥匙.md)解锁后会喷出战利品。

# 生成

# = 自然生成 =
不祥宝库自然生成于试炼密室的决斗室、交叉口、柱廊中庭和廊尾。

# 获取

不祥宝库的[方块物品](方块物品.md)是[宝库](宝库.md)，无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。

# 破坏
没有工具可以加速对不祥宝库的挖掘。

不祥宝库被破坏后不会掉落。

# 用途

未激活的不祥宝库的半径4格内存在可以解锁该不祥宝库的玩家时，它会被激活并播放燃起音效；激活的不祥宝库的半径4.5格内不存在可以解锁该不祥宝库的玩家时，不祥宝库又会熄灭。

不祥宝库从未激活状态转为激活状态时，[亮度](亮度.md)会增加，其下端的灰色边角变为青色，正面的双眼纹理变红、嘴部纹理向下张开，并且有[微小的橙色粒子](粒子#vault_connection.md)从玩家身上运动到不祥宝库的嘴部。此外，不祥宝库的内部会出现火焰粒子和展示其战利品表的旋转[物品实体](物品实体.md)，每秒随机更换一次物品，此时展示的物品与实际喷出的战利品无关。

# = 光源 =
未激活的不祥宝库会发出亮度等级为6的光。

激活的不祥宝库会发出亮度等级为12的光。

# = 解锁战利品 =
对激活的不祥宝库使用[不祥试炼钥匙](不祥试炼钥匙.md)可以将其解锁。

不祥宝库会在方块实体数据中存储最后128-{}-位解锁了宝库的玩家，只有不在该记录中的玩家可以解锁不祥宝库。在记录长度达到128时，解锁不祥宝库会在添加新记录时删除最早的记录，使被删除了记录的玩家可以再次解锁这个不祥宝库。<ref name="MC-274049"></ref><ref name="MCPE-226578"></ref>

每次解锁时，宝库都会从战利品表中随机抽取物品，具体如下：
* 首先，有80%的概率从稀有战利品表抽取1次，20%概率从普通战利品表抽取1次；
* 总是从普通战利品表抽取1-3次；
* 有75%的成功概率从独有战利品表抽取1次。

# 你知道吗
* 不祥宝库可以被每个玩家打开无限次数<ref name="MC-274049"/><ref name="MCPE-226578"/>，这与Mojang声称的“每个宝库只能被每个玩家打开一次”相悖。
* * 由于[试炼钥匙](试炼钥匙.md)和[不祥试炼钥匙](不祥试炼钥匙.md)是[可再生资源](可再生资源.md)，所以通过[宝库](宝库.md)和不祥宝库获取物品是一种可再生的获取方式。这也是[钻石](钻石.md)、[附魔金苹果](附魔金苹果.md)、[沉重核心](沉重核心.md)、[涡流旗帜图案](涡流旗帜图案.md)、[旋风旗帜图案](旋风旗帜图案.md)和[风爆](风爆.md)[附魔书](附魔书.md)唯一的[可再生获取方式](可再生资源#宝库战利品.md)。
* 不祥宝库的默认方块实体数据与普通宝库一致。因此，使用命令放置的未指定任何方块实体数据的不祥宝库，其行为与普通宝库一致。<ref></ref>
