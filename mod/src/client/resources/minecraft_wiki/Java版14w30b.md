# Java版14w30b

*页面ID: 32653* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w30b**是[Java版1.8](Java版1.8.md)的第39个快照，发布于2014年7月23日<ref></ref>，修复了快照[14w30a](14w30a.md)中的一些漏洞和崩溃。

# 更改
# = 生物 =
* *[苦力怕](苦力怕.md)、[骷髅](骷髅.md)和[僵尸](僵尸.md)**
* 闪电苦力怕的爆炸产生的生物头颅不再多于一个。
