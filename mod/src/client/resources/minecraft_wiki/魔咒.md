# 魔咒

*页面ID: 6549* | *来源: Minecraft Wiki*

<!---->

[thumb|带光效的附魔铁镐](File:Enchanted Iron Pickaxe.gif.md)

* *魔咒（Enchantment）**是适用于[物品](物品.md)的额外效果，能够为物品提供多种功能。具有魔咒的物品被称为**附魔物品（Enchanted Item）**。

# 机制
魔咒是普适于所有物品的机制，存储在物品的物品数据中。

所有物品都可以具有任意魔咒并生效，但为物品添加魔咒会受到许多因素的限制。

常见的可附魔物品包括[盔甲](盔甲.md)、[工具](工具.md)、[武器](武器.md)；[附魔书](附魔书.md)、[磁石指针](磁石指针.md)等其他物品也可以获得一些魔咒。

具有魔咒的物品会获得[稀有度](稀有度.md)提升和[光效](光效.md)。

# = 魔咒属性 =
魔咒有以下基本属性：
* 魔咒的**适用物品**限定了哪些物品可被添加上该魔咒；该魔咒是这些物品的**适用魔咒**，而这些物品也即该魔咒的**适用物品**。
* 魔咒的**可附魔物品**限定了哪些物品在经过附魔后可添加上该魔咒。该属性仅限定了该魔咒在“附魔”情境下所被附加到的载体，在其他情境下，通过某种方法，该魔咒可能被允许附加到任何载体上。
* * 绝大多数魔咒的可附魔物品与适用物品是相同的；有以下例外：
* ** [锋利](锋利.md)、[亡灵杀手](亡灵杀手.md)、[节肢杀手](节肢杀手.md)排除了[斧](斧.md)。
* ** [火焰附加](火焰附加.md)、[亡灵杀手](亡灵杀手.md)、[节肢杀手](节肢杀手.md)排除了[重锤](重锤.md)。
* ** [荆棘](荆棘.md)排除了[头盔](头盔.md)、[护腿](护腿.md)、[靴子](靴子.md)。
* 魔咒不能与**不共存魔咒**被添加到同一个物品上。
* 魔咒的等级不能超过**最大等级**。
* * 魔咒的最大等级为I级时，I级的该魔咒不会在[提示框](提示框.md)中显示等级。
* 魔咒的**出现条件**限制了为物品添加该魔咒的方式。
* * **宝藏魔咒**意味着附魔台、村民售卖的装备、生物天然装备的附魔过程不能提供该魔咒。
* * **无法交易获得**意味着村民的交易选项不能提供具有该魔咒的物品。
* * **无法以战利品获得**意味着战利品生成（如[箱子战利品](箱子战利品.md)和[钓鱼](钓鱼.md)）的附魔过程不能提供该魔咒。
* ** 部分战利品会直接生成包含指定魔咒的物品，不使用附魔过程，从而使该魔咒可以通过战利品获取。
* 魔咒的每个等级的**修正附魔等级范围**由**最小修正附魔等级**和**最大修正附魔等级**构成，决定了在[附魔](附魔（物品修饰）.md)过程中，根据附魔操作的修正附魔等级，该魔咒的这个等级是否会可以被附魔选中；最小修正附魔等级还决定了[砂轮](砂轮.md)移除该魔咒时提供的[经验值](经验值.md)。
* * 一部分魔咒的高等级具有极高的最小修正附魔等级，导致物品无法通过附魔台的30级附魔得到它们，如[锋利](锋利.md)V和[荆棘](荆棘.md)III，但其他方式（如[末地城](末地城.md)战利品的39级附魔、村民交易选项、或通过[铁砧](铁砧.md)直接添加魔咒）仍然可以提供这些魔咒。
* * [快速装填](快速装填.md)III的修正附魔等级范围为52–50，因此也无法通过附魔获得。
* 魔咒的**挑选权重**决定了在附魔过程中，根据修正附魔等级决定了可选魔咒后，魔咒最终会被选中的相对权重。
* 魔咒的**合并魔咒花费**决定了在铁砧上为其他物品添加该魔咒需要消耗的[经验等级](经验等级.md)。
* 少数魔咒是**诅咒**，在提示框中的文本颜色为红色，且不能通过通常的方式从物品上移除。

物品上的每一个魔咒仅有一个属性：
* **等级**决定了许多魔咒的效果强度。
* * 該等級可以超過魔咒本身的最大等級，但只能以或修改NBT等方式達到。
* * 魔咒数据能存储的最高等级是或，不論何種手段皆不可超過。

# = 附魔书 =

[附魔书](附魔书.md)是专门用于存储魔咒的物品。所有魔咒都可以被添加到附魔书上，无论其适用物品。

附魔书的主要用途是在[铁砧](铁砧.md)上作为牺牲物品来为目标物品添加魔咒。

在[铁砧](铁砧.md)中使用附魔书来获得同样的魔咒所需要的经验消耗要比结合物品少得多。但因为制作附魔书本身也需要消耗经验等级，且附魔书的附魔能力不高，而直接附魔物品有概率同时得到多个魔咒，所以**不建议**有意制作附魔书后将其与物品合并。

附魔书的最大优势在于可以将针对某类工具的魔咒囤积起来日后使用，或从[图书管理员](图书管理员.md)购买大量需要的魔咒。而且附魔书可以进行**受控**的魔咒组合，例如，“精准采集”附魔书可以为斧、镐或锹附魔，玩家可以随意选择将该附魔书用在哪一种工具上。

附魔书存储魔咒的实现与其他具有魔咒的物品有诸多不同：
* 附魔书使用自己专有的物品数据来存储魔咒，物品本身并不是附魔物品，因此附魔书存储的魔咒不会产生效果。
* 附魔书直接具有魔咒，但魔咒不在附魔书上生效。

# = 自然生成 =
许多物品在生成时就具有魔咒：

以下途径获得的物品具有单一的魔咒。这些途径生成的魔咒不使用[附魔（物品修饰）](附魔（物品修饰）.md)机制。若无特殊说明，则所有魔咒出现的概率相同，可以施加的宝藏型魔咒有[经验修补](经验修补.md)、[冰霜行者](冰霜行者.md)、[绑定诅咒](绑定诅咒.md)和[消失诅咒](消失诅咒.md)，魔咒出现概率与魔咒的等级无关。
* 搜寻[废弃矿井](废弃矿井.md)、[地牢](地牢.md)、[沙漠神殿](沙漠神殿.md)、[掠夺者前哨站](掠夺者前哨站.md)、[林地府邸](林地府邸.md)、大型[海底废墟](海底废墟.md)、[远古城市](远古城市.md)等[结构](结构.md)中的[箱子](箱子.md)，获得其中的[附魔书](附魔书.md)。
* [图书管理员](图书管理员.md)村民的许多[交易](交易.md)选项会提供附魔书。
* [废弃传送门](废弃传送门.md)的箱子中的金质装备、[试炼密室](试炼密室.md)柱廊木桶中的[铁斧](铁斧.md)、[试炼密室](试炼密室.md)交叉口木桶中的[钻石斧](钻石斧.md)附有随机魔咒。
* 在袭击中生成的[掠夺者](掠夺者.md)携带的[弩](弩.md)可能会附有[快速装填](快速装填.md)I（第4-5波）或[快速装填](快速装填.md)II（第6-8波）；袭击中生成的[卫道士](卫道士.md)携带的[铁斧](铁斧.md)可能会附有[锋利](锋利.md)I（第1-5波）或[锋利](锋利.md)II（第6-8波）。
* 搜寻[堡垒遗迹](堡垒遗迹.md)结构中的箱子，获得附有随机等级的[灵魂疾行](灵魂疾行.md)的附魔书。
* 使用[金锭](金锭.md)与[猪灵](猪灵.md)进行[以物易物](以物易物.md)有概率获得附有随机等级的[灵魂疾行](灵魂疾行.md)的[铁靴](铁靴.md)或[附魔书](附魔书.md)。
* 搜寻[远古城市](远古城市.md)结构中的箱子，获得附有随机等级的[迅捷潜行](迅捷潜行.md)的附魔书。
* 解锁[试炼密室](试炼密室.md)结构中的[不祥宝库](不祥宝库.md)，获取附有[风爆](风爆.md)I的附魔书。
* 解锁[试炼密室](试炼密室.md)结构中的[宝库](宝库.md)或搜寻其中的奖品箱，获得附有特定魔咒、等级随机的附魔书。
* * [宝库](宝库.md)和[不祥宝库](不祥宝库.md)中的附魔书均可能附有[激流](激流.md)、[忠诚](忠诚.md)、[引雷](引雷.md)、[穿刺](穿刺.md)或[经验修补](经验修补.md)。
* * [宝库](宝库.md)中的附魔书还可能附有[锋利](锋利.md)、[节肢杀手](节肢杀手.md)、[效率](效率.md)、[时运](时运.md)、[精准采集](精准采集.md)或[摔落缓冲](摔落缓冲.md)。
* * [不祥宝库](不祥宝库.md)中的附魔书还可能附有[破甲](破甲.md)、[致密](致密.md)。

以下途径获得的物品可能会具有多个魔咒。这些途径生成的魔咒使用[附魔（物品修饰）](附魔（物品修饰）.md)机制，且[附魔等级](附魔等级.md)各不相同。通常来说，附魔等级越高，魔咒的等级越高，魔咒的数量也越多。
* 部分生物在生成时会持有附魔物品（如[僵尸](僵尸.md)、[尸壳](尸壳.md)、、[溺尸](溺尸.md)、[卫道士](卫道士.md)、[掠夺者](掠夺者.md)、[骷髅](骷髅.md)、[流浪者](流浪者.md)、[沼骸](沼骸.md)、[焦骸](焦骸.md)、[僵尸猪灵](僵尸猪灵.md)和[猪灵](猪灵.md)）；杀死生物有机会使其天然装备掉落，获取其附魔物品。这些物品可以进行5-22级附魔，具体等级取决于[副区域难度](副区域难度.md)，不能附有宝藏型魔咒。
* [盔甲匠](盔甲匠.md)村民售卖的[钻石盔甲](钻石盔甲.md)、[渔夫](渔夫.md)村民售卖的[钓鱼竿](钓鱼竿.md)、[制箭师](制箭师.md)村民售卖的[弓](弓.md)和[弩](弩.md)、[工具匠](工具匠.md)村民售卖的铁质或钻石质[工具](工具.md)、[武器匠](武器匠.md)村民售卖的铁质或钻石质[武器](武器.md)、流浪商人售卖的[铁镐](铁镐.md)。这些物品可以进行5-19级附魔，不能附有宝藏型魔咒。
* [钓鱼](钓鱼.md)有概率得到附魔的[钓鱼竿](钓鱼竿.md)、[弓](弓.md)、[附魔书](附魔书.md)。这些物品可以进行30级附魔，可以附有宝藏型魔咒。
* 搜寻[要塞](要塞.md)、[丛林神庙](丛林神庙.md)、[末地城](末地城.md)、[远古城市](远古城市.md)、[试炼密室](试炼密室.md)等[结构](结构.md)中的[箱子](箱子.md)，获取其[箱子战利品](箱子战利品.md)。
* * [要塞](要塞.md)、[丛林神庙](丛林神庙.md)的箱子中的[附魔书](附魔书.md)可以进行30级附魔。可以附有宝藏型魔咒。
* * [末地城](末地城.md)的箱子中的铁质、钻石质[装备](装备.md)和[远古城市](远古城市.md)的箱子中的[铁护腿](铁护腿.md)可以进行20–39级附魔。可以附有宝藏型魔咒。
* * [试炼密室](试炼密室.md)的箱子战利品和[宝库](宝库.md)战利品中的铁胸甲、铁斧可以进行0–10级附魔，[弓](弓.md)可以进行5-15级附魔，弩可以进行5-20级附魔，钻石胸甲、钻石斧可以进行5-15级附魔。特别地，[不祥宝库](不祥宝库.md)中的钻石胸甲、钻石斧可以进行10-20级附魔，无附魔的弓和铁质装备。可以附有宝藏型魔咒。
* * [远古城市](远古城市.md)的箱子战利品中的钻石锄、钻石护腿可以进行30–50级附魔。可以附有宝藏型魔咒。

# = 附魔 =

* *附魔（Enchanting）**是一种为不具有魔咒的物品随机生成一个或多个魔咒的方式。

附魔得到的魔咒取决于参数**附魔等级**和物品的属性**附魔能力**。一般来说，这两个参数越大，物品得到的附魔品质趋于更好，数量趋于更多。

[附魔台](附魔台.md)提供了玩家可操作的附魔方式，通过消耗[青金石](青金石.md)和[经验等级](经验等级.md)，可以为大多数**没有魔咒**的物品添加一个或数个魔咒。为了提供更多和高等级的魔咒，附魔台还需要在附近设置[书架](书架.md)。

然而，附魔台无法为物品添加[宝藏型魔咒](宝藏型魔咒.md)或最小修正附魔等级过高的魔咒，如钻石剑无法被添加[锋利](锋利.md)V，钻石胸甲无法被添加[荆棘](荆棘.md)III等。某魔咒的适用物品，但不是可附魔物品，无法添加该魔咒，详见上文。一些没有附魔能力的物品，如[盾牌](盾牌.md)、[剪刀](剪刀.md)、[刷子](刷子.md)、[打火石](打火石.md)、[胡萝卜钓竿](胡萝卜钓竿.md)、[诡异菌钓竿](诡异菌钓竿.md)、[鞘翅](鞘翅.md)等无法使用附魔的方式添加魔咒。这些情况下，玩家可以使用[铁砧](铁砧.md)为物品添加魔咒。

附魔台、多数附魔战利品、生物天然装备均使用附魔来为物品添加魔咒。[书](书.md)可以通过附魔变为[附魔书](附魔书.md)，用于在[铁砧](铁砧.md)上提供魔咒。

# = 铁砧 =

[铁砧](铁砧.md)通过消耗[经验等级](经验等级.md)和一个**牺牲物品**，可以为一个物品（称作**目标物品**）添加牺牲物品的魔咒。

在铁砧上使用的牺牲物品必须和目标物品完全相同（例如，铁镐和钻石镐不能合并）或者是一个[附魔书](附魔书.md)。牺牲物品是附魔书时，合并魔咒需要的经验等级更少。

用附魔为物品添加魔咒的方式存在随机性和局限性，通常难以满足玩家的需求。此时通过铁砧操作来为物品添加魔咒是必要的。然而，即使使用铁砧，也无法为目标物品添加不适用的魔咒或与原有魔咒不共存的魔咒。

在铁砧上进行操作会为物品增加“累积惩罚”，导致物品在铁砧上进行操作需要消耗的经验等级大量增加。[生存模式](生存模式.md)中，当一次操作需要的经验等级大于等于40级时，铁砧会拒绝进行此操作，并提示“过于昂贵！”，[创造模式](创造模式.md)则无视此限制。因此，玩家要合理规划自己的操作以节省经验等级。

在创造模式中使用[铁砧](铁砧.md)结合魔咒可以让魔咒被添加到不适用的物品上，但仍不能添加与原有魔咒不共存的魔咒。

# = 物品修复 =
通过[合成](合成.md)和[砂轮](砂轮.md)进行的[物品修复](物品修复.md)会合并两个物品的魔咒，不过绝大多数魔咒都会被物品修复移除，因此物品修复只能用于合并两个物品的诅咒魔咒。

# = 作弊与命令 =
在[创造模式物品栏](创造模式物品栏.md)中可以获取所有魔咒的对应[附魔书](附魔书.md)。

可以为执行者的主手物品添加魔咒，且受到魔咒的适用物品、最大等级、不共存魔咒的限制。

在给予玩家物品时，可以通过指定物品的或[数据组件](数据组件.md)来指定该物品的魔咒。该方法不受以上限制。

可以通过某些[物品修饰器](物品修饰器.md)来修改方块或生物的槽位中的物品具有的魔咒，或为物品添加随机等级、随机种类的魔咒，或使用[附魔（物品修饰）](附魔（物品修饰）.md)机制进行附魔。该方法不受以上限制。

可以通过修改方块（如箱子、熔炉）或生物[物品栏](物品栏.md)的某[槽位](槽位.md)中的物品的数据组件修改该物品的魔咒。该方法不受以上限制。

# 移除物品魔咒
物品上所有不是诅咒的魔咒可以通过以下方式被移除：
* 通过[合成](合成.md)来合并两个物品。
* 通过[砂轮](砂轮.md)进行祛魔或合并两个物品，并根据移除的魔咒的修正附魔等级提供[经验值](经验值.md)。

# 所有魔咒

下表列出了所有的魔咒及其适用的物品。

# = 宝藏型魔咒 =
宝藏型魔咒是无法从附魔台等常见来源获取的魔咒。若要将这些魔咒应用到玩家预期的物品上，唯一的方式是获取拥有这些魔咒的物品，并使用铁砧来进行物品合并。不同的宝藏型魔咒有不同的获取方式：

; [经验修补](经验修补.md)、[冰霜行者](冰霜行者.md)、[绑定诅咒](绑定诅咒.md)、[消失诅咒](消失诅咒.md)
  * [交易](交易.md)以获取具有这些魔咒的工具或附魔书。图书管理员提供的具有宝藏型魔咒的附魔书，相较于其会提供的其他附魔书，价格会增加一倍。
  * [钓鱼](钓鱼.md)时获得的物品或附魔书有可能具有这些魔咒。
  * 一部分[箱子战利品](箱子战利品.md)会包含有概率出现这些魔咒的物品或附魔书。
  * [袭击](袭击.md)中生成的[掠夺者](掠夺者.md)和[卫道士](卫道士.md)有可能会额外掉落具有宝藏型魔咒的附魔书。

; [灵魂疾行](灵魂疾行.md)
  * 进行[以物易物](以物易物.md)有概率得到具有灵魂疾行的附魔书或铁靴子。
  * 探索[堡垒遗迹](堡垒遗迹.md)的战利品箱有概率找到灵魂疾行附魔书。

; [迅捷潜行](迅捷潜行.md)
  * 探索[远古城市](远古城市.md)的战利品箱有概率找到具有迅捷潜行的附魔书。

; [风爆](风爆.md)
  * 解锁[试炼密室](试炼密室.md)的不祥宝库有概率找到具有风爆的附魔书。
