# 拉杆

*页面ID: 6190* | *来源: Minecraft Wiki*

* *拉杆（Lever）**是一种可打开和关闭的[电源](红石元件.md)。

# 生成
# = 自然生成 =
拉杆会生成在[林地府邸](林地府邸.md)的监狱门边。

每个[丛林神庙](丛林神庙.md)会自然生成3个拉杆。

拉杆还会生成在[远古城市](远古城市.md)中，作为地下室红石电路的元件和冰窖的开关生成。

# 破坏
没有工具可以加速对拉杆的挖掘。

拉杆被破坏后会掉落自身。

# 用途
[缩略图|可能方向中的其中五种，拉杆为关闭状态](File:Lever positions.png.md)

拉杆是可打开及关闭的红石[电源](红石元件#电源.md)。

拉杆在下列情况中被破坏并掉落为物品：
* 拉杆的附着位置变得不可附着（被移动、替换或被破坏等）
* 有[水](水.md)或[熔岩](熔岩.md)（不会掉落为物品）流过
* [活塞](活塞.md)尝试推动拉杆或把方块推入拉杆的位置

; 放置
对着要附着拉杆的方块表面按下键即可放置拉杆。

拉杆可附着在所有[方块支撑形状](方块支撑形状.md)完整的面。当把拉杆放在方块的上面或底面时，拉杆的柄大致朝向玩家。当把拉杆放置在方块的侧面时，拉杆向下为*开*状态，向上则为*关*状态。共有12种可能的放置方向。

拉杆可附着在方块（例如石头、泥土、金块等）的**顶部**、**侧面**以及**底面**，或者是上下颠倒的[台阶](台阶.md)或上下颠倒的[楼梯](楼梯.md)（但不是台阶或楼梯右拐角向上的底部）的**顶部**，还能附着在栅栏、石墙和漏斗的顶部。当把拉杆放在方块的上面或底面时，拉杆会的方向会与玩家大致朝向方向在同一直线。当把拉杆放置在方块的侧面时，拉杆向下为*开*状态，向上则为*关*状态。当拉杆在方块的顶部或底面时，拉杆在*开*状态时朝向北边或西边，*关*状态为南方或东边。共有8种可能的放置方向。

; 开关
对着拉杆按下键即可打开或关闭它。拉杆处于[风爆](爆炸#风爆.md)影响范围中时也会改变其开关状态。

; 行为
当打开时，拉杆会：
* 激活任何毗邻的[红石线](红石线.md)至[信号等级](红石电路#信号强度.md)至15级。
* 给任何四周背对拉杆的[红石比较器](红石比较器.md)或[红石中继器](红石中继器.md)提供信号等级15级。
* 强充能拉杆附着的红石导体至充能等级15级。
* 激活毗邻的[机械元件](红石元件#机械元件.md)（面向拉杆的[活塞](活塞.md)除外）。
* 会产生[红石粉粒子](粒子#dust.md)。
