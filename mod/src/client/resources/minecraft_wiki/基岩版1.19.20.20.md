# 基岩版1.19.20.20

*页面ID: 97042* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.20.20**（Android）、**Preview 1.19.20.20**（Xbox/Windows）、**Preview 1.19.20.21**（iOS/iPadOS）<ref></ref>是[基岩版1.19.20](基岩版1.19.20.md)的首个测试版，发布于2022年6月29日至30日<ref></ref>，同步了一些的特性，对[专用服务器](基岩版专用服务器.md)做出了一些技术性更改，并修复了一些漏洞。

# 新内容
# = 常规 =
* *<samp>[server.properties](server.properties.md)</samp>**
* 加入了服务器属性，用于停止玩家之间的交互。
* 加入了服务器属性，用于限制所有连接到服务器的玩家的聊天。它可以在中更改，有着、和三个可能值。

# 更改
# = 方块 =
* *[末地传送门框架](末地传送门框架.md)**
* 英文名称由“End Portal”重命名为“End Portal Frame”以匹配。

* *[木板](木板.md)、[楼梯](楼梯.md)和[台阶](台阶.md)**
* 将橡木、云杉木、白桦木、丛林木、金合欢木和深色橡木质的木板、楼梯和台阶的英文名称中的单词“Wood”移除，以匹配。

* *[幽匿感测体](幽匿感测体.md)**
* 更改了一些振动的振动频率以匹配：
* * [苦力怕](苦力怕.md)爆炸的振动频率现在为15。
* * [末地水晶](末地水晶.md)爆炸的振动频率现在为15。
* * 放置[生物桶](生物桶.md)的振动频率现在为12。
* * [发射器](发射器.md)发射[TNT](TNT.md)的振动频率现在为12。

# = 生物 =
* *[猪灵](猪灵.md)**
* 现在当玩家穿上金质[盔甲](盔甲.md)时，猪灵的轻度敌对状态会被解除。

* *[劫掠兽](劫掠兽.md)**
* 现在能够摧毁[红树树叶](红树树叶.md)、[杜鹃花丛](杜鹃花丛.md)、[杜鹃树叶](杜鹃树叶.md)、[洞穴藤蔓](洞穴藤蔓.md)、[大型垂滴叶](大型垂滴叶.md)、[小型垂滴叶](小型垂滴叶.md)、[孢子花](孢子花.md)和[垂根](垂根.md)。

* *[僵尸](僵尸.md)**
* 现在在困难难度下有10%的概率破门，而不是总会破门。

# = 游戏内容 =
* *振动**
* 振动接收者（如[幽匿感测体](幽匿感测体.md)、[幽匿尖啸体](幽匿尖啸体.md)和[监守者](监守者.md)）现在改为侦测最近的振动信号，而非之前的1刻内的首个振动信号。

# = 常规 =
* *[控制](控制.md)**
* 为iOS/iPadOS平台加入了对单击鼠标中键的支持。

# = 技术性 =
* *方块**
* 服务端开发者现在可以在客户端和服务端中查看方块注册表的校验值，以检查是否匹配（在输出日志中搜索“方块注册表校验值”并进行比较）。

* *生物桶**
* 在放置自定义生物桶后可以生成对应的生物。
* 修复了在放置生物桶时生成顺序的问题，现在所有被施加的活动对象属性都可以正常加载。

* *图形**
* 在数据驱动方块被镶嵌后，基于轴心点旋转的几何箱现在会围绕着正确的轴心点旋转。
* 为大型图标嵌入纹理（如玩家手中的物品）的操作加入了内容日志警告。

* *性能与稳定性**
* 客户端现在可以自己生成，这使得服务端无需生成并遍历当前视图中的每个区块。服务器只能生成时间刻范围内的，并保存在磁盘上。
* * 在客户端上创建了可以生成区块的和。
* * 加入了，用于向客户端发送中的内容。
* * 将大多数加入到中，让客户端能更加合理地对生物群系进行后期处理。
* * 加入了“客户端生成”地物选项。
* * 更改了已有的遥测功能，以拆分服务端和客户端的。
* * 加入了一些代码以修复客户端的光照系统，并与服务端保持一致。

# 修复
* *原版趋同**
* 现在僵尸在困难难度下有10%的概率破门。（）
* 移除了红树木板、红树木楼梯和红树木台阶的英文名称中的单词“Wood”。（）
* 更改了流浪商人的生成机制以匹配Java版，其不再会生成于水中、熔岩中或地下。（）
* 末地传送门框架的英文名称由“End Portal”更改为“End Portal Frame”。（）
* 蝌蚪在陆地上的扑腾速度现在和Java版以及其他鱼类更加接近。（）
* 北极熊在受到攻击时不再会逃跑。
* 现在玩家穿戴上金质盔甲后，猪灵会停止攻击。（）

* *旁观模式（实验性）**
* 玩家现在可以在旁观模式玩家所在的位置放置方块。
* 现在当玩家手持一张地图且在另一只手上持有其他物品时，玩家的手臂会正常渲染。（）

* *音频**
* 修复了在创造模式下新的荒野更新音乐不能在对应生物群系中播放的问题。

* *方块**
* 现在即使随机刻速度被设置为0，缠怨藤和垂泪藤也会在没有附着方块时掉落。（）
* 幽匿催发体现在会在没有经验的生物在其附近死亡时蔓延。
* 在没有完全成熟时，悬挂的红树胎生苗被精准采集附魔工具采集时不再会掉落任何物品。（）
* 沾泥的红树根现在可以横向放置。（）
* 在周边放置方块时，悬挂的红树胎生苗不再会改变颜色。（）

* *游戏内容**
* 修复了通过下界传送门传送到主世界时可能出现的问题。（）

* *VR**
* “转动视角”的提示现在会显示玩家重新设置的热键而不是默认的按键。

* *红树树叶和杜鹃树叶**
* 红树树叶和杜鹃树叶不再会阻止对应树木的生长。（）

* *生物效果**
* 修复了在退出世界后从生命提升效果中得到的额外生命值无法保留的问题。（）
* 修复了当玩家在拥有迅捷效果的情况下疾跑时视场角会出现的卡顿问题。

* *生物**
* 无职业的僵尸村民现在可以搭乘矿车或船。（）
* 劫掠兽现在可以摧毁红树树叶、杜鹃花丛、杜鹃树叶、洞穴藤蔓、垂滴叶、孢子花以及垂根。（、）

* *幽匿感测体**
* 如果两个事件同时发生，幽匿感测体现在会优先感应距离较近的那个。（）
* 如果两个事件同时发生且距离相同，幽匿感测体现在会优先感应振动频率较高的那个。
* 幽匿感测体现在感测到苦力怕爆炸的振动频率为15。
* 幽匿感测体现在感测到末地水晶爆炸的振动频率为15。（）
* 幽匿感测体现在感测到生物桶放置的振动频率为12。
* 幽匿感测体现在感测到发射器发射TNT的振动频率为12。

* *性能与稳定性**
* 修复了同时传送和杀死一个实体时可能发生的崩溃。
* 现在在实体死亡后它们在世界中的数据会被删除。（）
* 修复了从下界和末地返回主世界时可能发生的崩溃。
* 进入新手硬币包界面时游戏不再会崩溃。

* *用户界面**
* 重新设计了切换开关的样式，使开关状态之间的差别更明显。
* 猪装备上鞍后的骑乘提示的英文名称由“Mount”更改为“Ride”，以匹配其他可骑乘动物。

* *交易**
* 修复了渔夫村民无法在最大等级下收购船的问题。

* *技术性**
* 修复了使用物品操作被取消或失败时，客户端状态可能会与服务端不同步的问题。</onlyinclude>
