* *资源包（Resource Pack）**系统允许玩家自定义游戏内绝大多数的视觉、听觉效果，而不需要修改游戏的。

# 使用资源包

资源包可以使用[选项](选项.md)菜单中的“”进行设置。在游戏加载资源包时，会按照列表上的顺序依次加载它们的资源。上层资源包可以替代、合并或移除下层资源包的资源，因此资源包的位置顺序会影响游戏对某些资源的读取和使用。

# = 全局资源包 =
全局资源包需要放置在内的文件夹，每个全局资源包都必须是一个子文件夹或一个[文件](wzh:ZIP格式.md)，其他文件格式会被忽略。全局资源包可以被禁用、启用或者调整位置。资源包的显示名称即为该文件夹或文件的名称（含扩展名），可使用[格式化代码](格式化代码.md)。

# = 世界指定资源包 =
资源包可以与[世界](世界.md)捆绑在一起。将资源包重命名为，再将这个文件放入或|je 26.1}}中，这个资源包就会成为世界指定资源包。

当玩家进入这个世界时，这个资源包将作为最上层资源包被加载，且无法被禁用或调整位置。其名称将显示为“”。

# = 服务器指定资源包 =
在服务器属性文件中指定<code>resource-pack</code>更改为一个文件的下载链接就能设置服务器的指定资源包。玩家可以选择使用资源包或不下载这个资源包。

如果选择使用资源包，这个资源包将作为最上层资源包被加载，且无法被禁用或调整位置。其名称将显示为“”。

# = 默认资源包 =
[32px](File:Default pack.png.md) <code></code>资源包即游戏内默认的外观资源包。它无法被禁用，仅可以调整位置。

# = 内置资源包 =
游戏提供了两个内置的资源包，玩家可以选择启用、禁用和调整位置。

[32px](File:Programmer Art pack.png.md) <code></code>资源包是一个还原[纹理更新](纹理更新.md)前纹理和模型的资源包。这些内容的视觉效果不会随着版本而更新。

[32px](File:HC pack.png.md) <code></code>资源包为游戏的GUI提供了高对比度版本的纹理。此资源包亦可在辅助功能设置中开启。

# = 资源包图标 =
[thumb|未知资源包的纹理](File:Unknown pack.png.md)
资源包根目录下可以添加一个作为资源包的图标，这个图标会在选项菜单中资源包列表中渲染。

在游戏读取资源包时，资源包的图标会在游戏内分配一个独特的命名空间ID，其命名格式为<code>-{}-minecraft:pack/<*去除非[a-z0-9-_./]的资源包名称*>/<*资源包名称的[SHA-1](wzh:SHA-1.md)散列字符串*>/icon</code>。当游戏导出动态纹理时，游戏会按照此图标文件的命名空间ID，将<code>/</code>和<code>:</code>替换为<code>_</code>，以此字符串加上后缀名<code>.png</code>作为导出纹理的名称。

如果资源包没有图标，或图标加载错误，游戏会使用未知资源包纹理作为此资源包的图标。

# 资源包内容
# = 纹理 =

资源包内可以定义许多纹理，用于修改游戏内各种方块、物品、实体、GUI的显示。纹理都位于{{filepath|-{}-assets/<*命名空间*>/textures}}的各个子目录内。

# = 模型 =

模型是以JSON格式保存的文件，位于{{filepath|-{}-assets/<*命名空间*>/models}}内，它可以修改方块和物品的形状和对应的纹理绑定。

而装备模型使用预置的装备模型预设层定义装备的纹理，位于{{filepath|-{}-assets/<*命名空间*>/equipment}}内。

# = 字体 =

资源包可以修改已有的[字体](字体.md)和添加自定义字体，修改各处文本的渲染。字体都在{{filepath|-{}-assets/<*命名空间*>/font}}的各个子目录下。

# = 粒子 =

资源包可以修改粒子使用的纹理，但不能添加新的粒子类型或修改粒子的生成、着色等。特定ID的粒子类型可以使用的纹理由资源包的{{filepath|-{}-assets/minecraft/particles/<*粒子类型ID*>.json}}控制，格式如下：

<div class="treeview">
* ：根对象
* * ：此粒子类型可以使用的纹理。
* ** ：（命名空间ID）一个粒子纹理。
</div>

# = 着色器 =

着色器是资源包改变游戏渲染方式的一种方式，使用OpenGL着色器语言（GLSL）编写，位于。

# = 声音 =

资源包可以修改游戏内的声音和对应的声音事件定义。资源包可以定义以修改原版的声音，也可以在{{filepath|-{}-assets/<*命名空间*>/sounds}}内修改声音文件。

# = 语言 =

资源包可以添加或修改语言。每个语言文件都按照下面的格式定义：

<div class="treeview">
*  JSON文件根元素
* * ：设置对应本地化键名的文本。
</div>

本地化键名是游戏读取一个文本所需要的标识符，通常具有一定的命名格式。例如，游戏在读取石头的名称时就会使用到<code>block.minecraft.stone</code>这个本地化键名，假设当前语言环境是<code>en_us</code>，在查找语言文件后，游戏就可以找出此本地化键名对应的文本<code>Stone</code>，并将这个文本作为石头的名称。

每个本地化键名对应的文本也有它的格式要求。因为文本可能带有参数，所以文本本身是一个格式化字符串。格式可以参考[Java文档](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Formatter.html)。然而，游戏实际上通常并没有使用上述Java标准库；如果格式化字符串内包含有<code>%f</code>或者<code>%d</code>及它们的带序号形式，游戏在加载语言文件时会自动将这些格式字符串中的<code>f</code>和<code>d</code>替换为<code>s</code>。所以，真正起效的格式字符串只有<code>%s</code>和<code>%%</code>和它们的带有序号的形式。游戏不会替换其他格式字符串，但游戏在解析这些字符串时会产生<code>TranslatableFormatException</code>异常，报错信息为<code>-{}-Unsupported format: '<*格式字符串*>'</code>。

当有多个资源包同时定义了同一个语言文件时，例如多个资源包内都存在，那么游戏就会按照资源包的顺序从上到下找到第一个定义了某个本地化键名的语言文件，并将对应的文本作为最终的翻译文本。如果所有资源包内都不存在这个本地化键名，游戏会直接使用本地化键名本身作为翻译文本。这种读取模式使得资源包不必要定义所有本地化键名，只需要定义需要的本地化键名就可以达到效果，未定义的本地化键名将自动使用其他资源包的文本。

与修改或添加本地化键名不同，添加一个语言需要两个步骤：
# 在资源包元数据中定义要添加的语言。
# 编写对应的语言文件。

假设在资源包元数据中定义了<code>zh_meme</code>语言，那么需要定义{{filepath|-{}-assets/<*命名空间*>/lang/zh_meme.json}}语言文件，其中命名空间是什么不会影响语言加载，游戏会遍历所有可能的命名空间以加载语言文件。

# == 键排除与替换 ==

除英语（美国）的语言文件外，游戏自带的语言文件以[散列资源文件](散列资源文件.md)的形式在多个游戏版本间共享。为在各游戏版本中选择正确的翻译内容，各版本[客户端文件](客户端核心文件.md)中存在一个文件，位于，标记了此版本中被替换或排除的语言文件中的翻译键名。此文件无法被资源包更改。该文件的格式如下：

<div class="treeview">
*  根元素
* * ：将排除的键。
* ** ：该键的名称。
* * ：将替换的键。
* ** ：将替换到的新键名。
</div>

加载各语言的语言文件时，游戏会先将中的键全部排除，然后依次替换中的各项键名。替换过程中，如旧键不存在，即便新键已存在，游戏也不会应用新键。

# = 文本 =

在内有4个文件，分别为3个文本文件和1个JSON文件。游戏会从上到下扫描资源包，找到第一次出现的对应文件进行加载，而下层资源包的文件会被忽略。

控制了游戏的[标题屏幕](标题屏幕.md)内的[闪烁标语](闪烁标语.md)，内部的每句闪烁标语都以行分隔符分隔开。闪烁标语在解析时会自动去除两端的空白字符，并且可以使用[格式化代码](格式化代码.md)为文本添加格式。如果一行闪烁标语的[哈希码](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/String.html#hashCode())为125780783，那么这一句闪烁标语将永远无法显示。

包含[终末之诗](终末之诗.md)，即玩家第一次从末地进入末地传送门返回主世界时显示的文本。包含[鸣谢名单](鸣谢名单.md)显示完毕后出现的引言。这两个文件具有同样的格式：文本内的所有<code>PLAYERNAME</code>都会被替换为当前玩家的名称，且可以使用格式化代码为文本添加格式。如果一行内的显示宽度超出了256，则游戏在解析时自动换行以保证不会超出屏幕渲染。

包含了Minecraft的[制作人员名单](制作人员名单.md)，并且有以下的格式：

<div class="treeview">
*  JSON文件根数组
* * ：制作人员名单中的一个部分。
* ** ：此部分的标题。
* ** ：各个部门。
* *** ：一个部门的信息。
* **** ：部门名称。
* **** ：职位列表。
* ***** ：职位列表中的一个职位。
* ****** ：此职位的名称。
* ****** ：职员列表。
* ******* ：一位职员的姓名。
</div>

<div class="treeview">
*  JSON文件根元素
* * ：当渲染器名称匹配内部任何一个时，游戏将给出渲染器警告。
* ** ：一条正则表达式。
* * ：当渲染器版本匹配内部任何一个正则表达式时，游戏将给出渲染器版本警告。
* ** ：一条正则表达式。
* * ：当渲染器厂商名称匹配内部任何一个正则表达式时，游戏将给出渲染器厂商警告。
* ** ：一条正则表达式。
</div>
