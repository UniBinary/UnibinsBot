# 基岩版1.21.120.23

*页面ID: 167176* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.120.23**（ChromeOS/Android）、**Preview 1.21.120.23**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.120](基岩版1.21.120.md)的第4个测试版，发布于2025年9月23日<ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[设置](设置.md)**
* 在设置中加入了“”选项。
* * 用于启用玩家视角靠近生物时该生物会变透明的功能。

# 更改
# = 方块 =
* *[铜活板门](铜活板门.md)**
* 现在合成铜活板门时会给予1个，而不是2个。

# = 生物 =
* *[溺尸](溺尸.md)**
* 现在生成时携带的[三叉戟](三叉戟.md)有概率是[附魔](附魔.md)的。

# = 常规 =
* *[实验性玩法](实验性玩法.md)**
* 移除了“”子选项。

# = 技术性 =
* *AI意向**
* 修复了生物运行AI意向时发生的崩溃。

* *API**
* 修复了在之前捕获异常后错误消息的额外上下文信息会在某些情况下不准确的问题。
* 将上的方法开放至。
*
* * 将由移动至版本。

* *生物群系**
* 修复了最近部分测试版本对地表生成器的使用问题，生物群系不再需要地表生成器。现在在Realms上游玩时远距离区块中的地表会正确显示。

* *方块组件**
* 为方块组件加入了字段，带有下列要求：
* * 世界需要启用“即将推出的创作者功能”[实验性玩法](实验性玩法.md)以使自发光面生效。
* * 方块的必须大于或等于。

* *[基岩版编辑器](基岩版编辑器.md)**
* 加入了对双击左键的支持，因此可以通过双击左键在图表上打开颜色选取器和可编辑窗口。
* 为带有可选参数的复选框变种加入了自定义图标支持。
* 加入了新的缩放工具，用于调整选区的大小。
* * 启用了沿着X、Y、Z轴单独或均匀地缩放的功能。
* * 加入了带有分数比例因子的分数化缩放功能；在放大/收缩期间会保持结构形状。
* * 加入了在套用更改前显示缩放大小的预览可视化功能。
* * 将工具与撤销和重做行为整合在一起。
* * 若当前体积或结果体积中的较大者超出（目前为200,000），则禁用缩放。
* 加入了“方向”设置，允许用于确定方块应该放置的方向。
* 为所有铅笔“模式”（模式、绘制模式、方向模式）加入了键盘快捷键和附带的提示框。
* 加入了无法将放置在适当的游戏规则时的错误消息（日志和通知）。
* 更新了铅笔工具，现在进行擦除时，若处于面选择模式则会切换至方块选择模式（实际上可以因此擦除内容），然后在回到绘画模式时切换回去。
* 更新了设置/惯例以使其能够在多个之间持续存在。
* 更新了铅笔功能以使更具磨光性。
* 修复了打开快捷栏管理面板时会创建多个快捷键的漏洞。
* 修复了导致去除的交互式提示框不运作的漏洞。
* 现在方块选取器图像的布局会在不同的窗口大小之间以及在退出测试世界后保持一致。
* 修复了快捷栏对话框中确认按钮的问题，以使其在开始键入时立即变绿，提供合适的视觉反馈。
* 修复了使用“”模式时撤销行为的问题。

* *物品组件**
* 为物品组件加入了字段，用于控制物品是否在开始或停止使用时发出振动。

* *结构**
* 开放了数据驱动拼图结构。现在可以在不开启[实验性玩法](实验性玩法.md)的情况下使用数据驱动拼图结构。

# 修复
* *方块**
* 现在由铜傀儡转变的铜傀儡像会采用铜傀儡的自定义名称。（）
* 修复了铜活板门配方会额外给予一个铜活板门的问题。（）

* *常规**
* 在Windows平台上加入了先前缺失的文件关联（如）。（）
* 修复了无法在游戏窗口未获得焦点时按下按钮的问题。（）
* 修复了通过按下键来暂停游戏时会导致鼠标无法移动的漏洞。（）

* *图形**
* 修复了玩家在开启的情况下在处于洞穴中的水下时，光照会显得过亮的漏洞。（）
* 修复了下的“生物群系混合”系统会忽略非地表生物群系的漏洞。现在多个生物群系会在水平方向和垂直方向上混合，这意味着如深暗之域和繁茂洞穴等生物群系的自定义渲染配置现在会正确生效。
* * 仅对大气、颜色分级、光照和颜色分级作出了修复，水配置仍然受此问题影响。
* 修复了天空在部分Android设备上显示为黑色的问题。（）

* *物品**
* 现在可以使用快捷键将物品转移至相应的快捷栏。（）

* *生物**
* 现在由铜傀儡像转变的铜傀儡会采用铜傀儡像的自定义名称。（）
* 溺尸不再会丢弃三叉戟而去捡起鹦鹉螺壳。（）
* 现在鹦鹉模仿敌对生物的声音受设置中的“”音效滑块影响。

* *用户界面**
* 修复了即使已禁用文本转语言功能，在使用游戏手柄或键盘进行无效导航后，部分屏幕上仍会播放音效的问题。
* 现在物品栏中的纸娃娃会看向光标。（）</onlyinclude>
