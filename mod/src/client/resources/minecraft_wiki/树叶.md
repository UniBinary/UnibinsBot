* *树叶（Leaves）**是一类生长在[树木](树木.md)上的[方块](方块.md)。

# 生成
# = 自然生成 =
树叶在[主世界](主世界.md)的[树木](树木.md)上自然生成。

橡树树叶可以在平原[村庄](村庄.md)的会合点自然生成。

深色橡树树叶可以在[林地府邸](林地府邸.md)里的“[伐木房](林地府邸/结构/农场#伐木房.md)”“[单人房](林地府邸/结构#单人房.md)”和“[生态屋](林地府邸/结构/装饰品房间#生态屋.md)”中自然生成。

橡树树叶或红树树叶可能会在[试炼密室](试炼密室.md)的“入口”结构中作为植物造景的一部分生成。

丛林树叶会伴随生成于[丛林](丛林.md)及其变种的[废弃传送门](废弃传送门.md)生成。

# 获取
树叶的物品形式只能通过使用剪刀或具有精准采集的工具挖掘破坏树叶获得。

# 破坏
挖掘树叶的合适工具是锄、剑和剪刀。

没有被剪刀或具有[精准采集](精准采集.md)的工具挖掘破坏时，树叶被破坏后会掉落以下物品：

被剪刀或具有精准采集的工具挖掘破坏时，树叶被破坏后会掉落自身。

# 用途
对于[照明](照明.md)而言，树叶总是透明的，但当[图像品质](选项#视频设置.md)被设置为“流畅”时，树叶纹理中透明的区域会被与树叶相近的颜色代替；而当“精美图像”和“花俏的树叶”选项被关闭时，树叶纹理的透明区域会被该种树叶的对应颜色代替。树叶会散射天空光线，并在树下投下阴影。

树叶可以[含水](含水.md)。不像多数可含水的方块，树叶是一个完整方块且没有任何一个表面允许水的流出或流入，可作为极度廉价且透明的防爆墙使用。

橡树、深色橡树、丛林、金合欢及红树树叶的色调取决于其所在的[生物群系](生物群系.md)。

# = 枯萎 =
自然生成和[树苗](树苗.md)生成的树叶会枯萎，但伴随[废弃传送门](废弃传送门.md)生成的丛林树叶不会，而玩家或[末影人](末影人.md)放置的树叶方块永远不会枯萎。

每当树上的树叶接收到一个或时，无论是直接连接还是通过其他树叶间接连接，若在6个方块内没有连接到[原木](原木.md)，就会自动消失（枯萎）。

除红树树叶外，每当树叶自然枯萎时，或不使用剪刀和带有精准采集魔咒的工具摧毁树叶时，会有5%（）的概率掉落[树苗](树苗.md)，2.5%（）的概率掉落[木棍](木棍.md)。丛林树叶会有2.5%（）的概率掉落树苗。橡树和深色橡树树叶有额外的0.5%（）的概率掉落1个[苹果](苹果.md)。概率会随[时运](时运.md)魔咒等级的增加而增加。因燃烧而消失的树叶不会掉落树苗和苹果。

# = 红树胎生苗 =
对红树树叶[骨粉](骨粉.md)，其下表面会开始生长[红树胎生苗](红树胎生苗.md)。

# = 红石元件 =

树叶方块（包括玩家放置的）在距其水平或垂直方向6格内，通过其他的树叶方块连接的最近的原木或木头方块的距离发生变化或连接所用树叶发生变化时会在收到[PP更新](方块更新#PP更新.md)后1游戏刻后改变其方块状态。朝向树叶的侦测器能侦测到这种变化，并在相同的游戏刻输出一个红石信号。因此树叶可用于传输红石信号。

# = 堆肥 =
盛开的杜鹃树叶有50%的概率将[堆肥桶](堆肥桶.md)的堆肥层数增加1。其他树叶的概率是30%。

# = 蜜蜂 =

盛开的杜鹃树叶和樱花树叶可用于吸引、繁殖[蜜蜂](蜜蜂.md)以及加速幼年蜜蜂的成长。蜜蜂也会采集它们的花粉。

# = 生成蜂巢 =

若橡树、白桦和樱花[树苗](树苗.md)水平2格范围内存在盛开的杜鹃树叶，则该树苗长成的树会有5%的概率悬挂着[蜂巢](蜂巢（方块）.md)，每个由此生成的蜂巢都会容纳1-3只蜜蜂。

# = 产生粒子 =
所有类型的树叶都会在下方没有固体方块和树叶时产生缓缓飘落的粒子。

落叶粒子的颜色与树叶一致，橡树树叶、丛林树叶、金合欢树叶、深色橡树树叶和红树树叶的落叶粒子颜色会随群系变换。除杜鹃树叶、盛开的杜鹃树叶、樱花树叶和苍白橡树树叶外的树叶的落叶粒子颜色还会随[降雪](降雪.md)变换。

暴露在[雨](雨.md)中的树叶会缓慢出现水滴粒子。

# = 结霜 =

<div style="float: right"></div>
树叶在降雪时会结霜（不包括杜鹃树叶、盛开的杜鹃树叶<ref></ref>、樱花树叶<ref></ref>和苍白橡树树叶），这种效果只在[冻洋](冻洋.md)、[冰冻深海](冰冻深海.md)、[雪原](雪原.md)、[冻河](冻河.md)、[积雪沙滩](积雪沙滩.md)、[积雪针叶林](积雪针叶林.md)及上述生物群系的变种中出现。

只有当开启“[花俏的树叶](设置#Video.md)”选项（移动端则需“[图形模式](设置#Video.md)”为“”及以上）时树叶才会结霜。

# = 起初的树叶枯萎算法 =

[thumb|[[Classic 0.0.15a（多人测试1）](File:Classic Leaves.png.md)版本里的树叶。此版本的树叶在它们直立时不会枯萎]]

在Alpha版本中，树叶是否枯萎取决于该树叶方块下方是否有固体方块（或者树叶方块），或者是该树叶方块附近有没有固体方块。如果该树叶附近没有固体方块，或者下方没有树叶方块存在，那么该树叶方块必须由连接的树叶串（树枝）中，距离5格以内的其他不会枯萎的树叶方块来提供支撑。

# 你知道吗
* 树叶方块偶尔会穿过其他方块生长出来，就像是它们仍旧连接在树上。它们也有可能覆盖掉它们生长路径上的其他方块。
* 树叶不会阻止[箱子](箱子.md)被打开。
* 有些树看似会自动地从树上掉落[苹果](苹果.md)或者[树苗](树苗.md)；那是因为这个新生成的树叶方块并没有被树干方块支撑。
* 树叶结霜时的外表不是瞬间转换的，而是拥有慢慢从原来的颜色渐变到冷淡颜色时的动画。同样地，在转变回正常状态时也有类似的渐变过程。
* 当被[活塞](活塞.md)推动时，树叶会被破坏。
* 树叶会和放在它上面的某些方块（如地毯）出现[深度冲突](Wikipedia:z-fighting.md)现象。<ref></ref>
