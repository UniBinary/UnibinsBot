# Java版18w20b

*页面ID: 34749* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w20b**是[Java版1.13](Java版1.13.md)的第36个快照，发布于2018年5月16日<ref></ref>，加入了盆栽植物的翻译和新的闪烁标语，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[花盆](花盆.md)**
* 加入盆栽植物的翻译（“橡树树苗盆栽”、“仙人掌盆栽”等）。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 加入了“All rumors are true!”（所有谣言都是真的！）。

# 更改
# = 方块 =
* *常规**
* 更改了一些[物品](物品.md)的名称和ID：

* *[潮涌核心](潮涌核心.md)**
* 潮涌核心的眼睛现在会表示它是否在寻找[敌对生物](敌对生物.md)：当它在寻找敌对生物时，将会显示一个睁开的眼睛，否则将显示一个闭上的眼睛。
