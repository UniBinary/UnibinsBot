* *滴水石锥（Pointed Dripstone）**是一种构成钟乳石、石笋和石柱的方块。

# 生成
滴水石锥能够生成滴水石锥（见）。

# = 自然生成 =
滴水石锥会常见地生成于[溶洞](溶洞.md)生物群系。

滴水石锥也会作为陷阱的一部分生成于[试炼密室](试炼密室.md)。

# 破坏
挖掘滴水石锥的合适工具是镐。

滴水石锥被破坏后会掉落自身。

# 用途
滴水石锥有钟乳石、石笋和石柱三种形态。滴水石锥可以[含水](含水.md)。

滴水石锥只能被放置在一个完整方块的上表面、下表面或其他滴水石锥上。如果尝试将其放置在不符合要求的表面上，滴水石锥就会试图“滑入”一个合理的位置。

为时，滴水石锥被[三叉戟](三叉戟.md)击中时会被破坏。

# = 钟乳石 =
当放置在方块下侧（倒挂）时，滴水石锥会形成钟乳石。

如果一个钟乳石的长度小于11格，在它接收到[随机刻](刻#随机刻.md)时，它会检查自身所附着的方块**上方1格**是否为[水](水.md)源方块或[含水](含水.md)方块（仅仅是附着的方块本身为含水方块则不算），以及钟乳石末梢下方10格以内是否有[炼药锅](炼药锅.md)，且中间没有任何空气方块之外的方块。<ref></ref>当满足以上两个条件时，炼药锅的水位会有（约17.6%）的概率上升一级。而如果上述情况中钟乳石附着的方块上方为[熔岩](熔岩.md)源方块，则下方的炼药锅会有（约5.9%）的概率被熔岩填满，这使熔岩成为了[可再生资源](可再生资源.md)。

如果钟乳石附着的方块上方为[泥巴](泥巴.md)，则泥巴每随机刻有（约17.6%）的概率转化为[黏土](黏土.md)。泥巴在[下界](下界.md)由[环境属性](环境属性.md)<code>gameplay/water_evaporates</code>控制。}}中不会转化。<ref></ref>

如果一根长度小于11格的钟乳石上方没有水源或熔岩源，其末梢也会出现水滴粒子（在[下界](下界.md)中则是熔岩粒子），但相较于有水源或熔岩源时粒子较少且出现频率较低，同时这种粒子无法填充炼药锅。另外，如果钟乳石的末梢含水，则此钟乳石不会产生滴落的粒子，也无法填充炼药锅。

破坏钟乳石的上层结构会使未受支撑的滴水石锥掉落成为[下落的方块](下落的方块.md)，并对其下方的玩家和生物造成伤害，类似于[铁砧](铁砧.md)。

# = 石笋 =
当放置在方块上侧（正放）时，滴水石锥会形成石笋。

生物摔落到石笋尖端时，受到的[摔落伤害](摔落#摔落结算.md)会增加，表现为在计算时摔落高度增加2，且摔落伤害翻倍。若摔落高度为h，则对于玩家和大多数生物来说摔落伤害为<math>\lceil(h+2-3)*2\rceil</math>，而非一般的<math>\lceil h-3 \rceil</math>。
* 大多数情况下，生物的跳跃高度约为1.25格，因此石笋能够伤害在其上原地跳跃的生物。
* 由于[鞘翅](鞘翅.md)在水平滑翔时仅能将下落距离重置为1，因此玩家滑翔并降落在其上时也会受伤。
* 所有免疫摔落伤害的生物掉落在石笋上时都不会受到伤害。如果游戏规则设为<code>false</code>，玩家也不会被石笋伤害。

只有方块状态<code>thickness</code>为<code>tip</code>的石笋尖才能造成上述的高额跌落伤害，石笋下层结构无此效果。[含水](含水.md)石笋尖的水位会高于石笋本身，因此从高处落在其上方不会受到摔落伤害。

石笋不会影响玩家在滑翔状态下于侧面高速撞击它时所受到的[动能伤害](鞘翅#动能伤害.md)。

破坏石笋的下层结构会摧毁上方所有未受支撑的石笋，使其掉落为滴水石锥物品。

# = 石柱 =

在钟乳石和石笋的尖端之间不[潜行](潜行.md)而放置滴水石锥会使上下的滴水石锥相连形成石柱。

潜行时放置的滴水石锥不会形成石柱。

# = 生长 =

当[钟乳石](#钟乳石.md)悬挂在[滴水石块](滴水石块.md)下方，且滴水石块上方一格是[水源方块](水源方块.md)（不能为水流或含水方块）时，钟乳石可以逐渐向下生长（表现为向下延长，最长可生长到7格），并在正下方的非[液体](液体.md)方块上产生逐渐向上生长的[石笋](#石笋.md)，或使下方已有的石笋生长。钟乳石和石笋会因生长而相接形成[石柱](#石柱.md)。需要注意：
* 当钟乳石长度超过7格，钟乳石和石笋都不会生长。
* 当钟乳石的尖端到下方的方块或石笋尖端的距离大于10格时，石笋不会生长。
* 当钟乳石和下方的石笋或其他方块间存在液体阻挡时，石笋不会生长。
* 当钟乳石下方的方块上表面不完整时，石笋不会生长。
* 钟乳石或石笋在其尖端[含水](含水.md)时不能继续生长，且不会生长到水中。

滴水石锥的生长基于[随机刻](刻#随机刻.md)，且速度非常缓慢。每接收到一个随机刻，便有1.138%（）的概率生长一格，生长一格的期望时间为5个[游戏日](游戏日.md)（100分钟）。

# = 下落的方块 =

破坏钟乳石的上层结构会使未受支撑的滴水石锥会变为[下落的方块](下落的方块.md)。

下落的滴水石锥会对实体造成伤害。令下落的滴水石锥下落的高度为<math>h</math>，组成原钟乳石结构的滴水石锥数量为<math>a</math>，则下落的滴水石锥造成伤害为{{only|je|for=<math>\min\{\max(a,\;6) \times (h-2),\;40\}</math>}}或{{only|be|for=<math>\min\{h\times\min(a,\;1),\;40\}</math>}}。装备任意[头盔](头盔.md)可以减少的伤害，但头盔的耐久度会严重损失。令原始伤害为m，则头盔减少的耐久度为{{only|je|for=<math>\lfloor \max(1,\;\frac{m}{4}) \rfloor</math>}}或{{only|be|for=<math>\lfloor \max(1,\;\frac{m}{4}) \rfloor+\lfloor (4 \sim 6) \times m \rfloor</math>}}。

下落的滴水石锥必定会在落地后掉落为物品，即使被爆炸或命令送入一个有合适上表面的位置，也不会重新成为方块。
