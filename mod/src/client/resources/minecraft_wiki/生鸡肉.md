# 生鸡肉

*页面ID: 6959* | *来源: Minecraft Wiki*

* *生鸡肉（Raw Chicken）**是一种[食物](食物.md)，可以被烹饪成[熟鸡肉](熟鸡肉.md)。

# 获取
# = 鸡 =

# = 礼物 =

已驯服的[猫](猫.md)赠予[玩家](玩家.md)礼物时，礼物有（约为16.129%）的概率是1个生鸡肉。

# 用途
# = 食物 =

手持生鸡肉按住键即可食用，每个生鸡肉可以回复，同时有30%概率获得30秒的效果。

# = 烹饪 =
将生鸡肉放入[营火](营火.md)、[烟熏炉](烟熏炉.md)或[熔炉](熔炉.md)中烹饪，可以获得熟鸡肉。

# = 狼 =
生鸡肉能用来吸引、治疗或繁殖驯服的[狼](狼.md)，也可以使已驯服的幼年狼的剩余生长时间减少10%。狼不会因食用生鸡肉获得效果。
