* *唤魔者（Evoker）**是一种施展法术进行尖牙攻击和召唤[恼鬼](恼鬼.md)的[灾厄村民](灾厄村民.md)。它们是[不死图腾](不死图腾.md)的唯一来源。

# 生成
# = 自然生成 =
唤魔者会自然生成于[林地府邸](林地府邸.md)，且在最初生成后不会再次生成。

在林地府邸生成的唤魔者不会自然消失。

# = 袭击 =

唤魔者可以作为袭击事件的一部分生成。

# 行为
</ref>||Marsh Davies Mojang avatar.png}}

唤魔者会主动施法攻击或内的玩家、成年[村民](村民.md)、[铁傀儡](铁傀儡.md)、和[流浪商人](流浪商人.md)，还能够施法改变[绵羊](绵羊.md)的颜色。如果玩家在10格半径内，且唤魔者不在攻击状态时，它会尝试避开玩家以防止受到攻击。

唤魔者受到攻击时会进行反击，。唤魔者不会反击[灾厄村民](灾厄村民.md)、。

唤魔者有两种攻击方式：尖牙攻击和召唤[恼鬼](恼鬼.md)。攻击时，基岩版的唤魔者每次攻击都有75%的概率使用尖牙攻击，25%的概率召唤恼鬼。而Java版里唤魔者首次攻击必定召唤[恼鬼](恼鬼.md)，接下来的攻击由技能冷却插空决定。当唤魔者准备攻击时，它会举起并挥动手臂，并根据攻击类型产生不同颜色的[粒子](粒子.md)。

在林地府邸里生成的唤魔者死亡之后就不会再重新生成，但它们也不会在非和平难度下自然消失。

如果在[袭击](袭击.md)中所有[村民](村民.md)死亡或所有村民的[床](床.md)被摧毁，则或唤魔者会跳动并挥舞双臂以庆祝胜利。

发射器可以给唤魔者装备[盔甲](盔甲.md)，但盔甲不会显示，且唤魔者被杀死也不会掉落盔甲。

敲[钟](钟.md)会给予半径48格内的唤魔者的[发光](发光.md)效果。

# = 生物族群 =

唤魔者是[灾厄村民](生物#灾厄村民.md)，不会被唤魔者的尖牙伤害，不会被[劫掠兽](劫掠兽.md)的咆哮伤害，不会被[“Johnny”卫道士](卫道士#“Johnny”卫道士.md)攻击。唤魔者可以加入正在发生的袭击，即使不是在袭击事件中被生成的。唤魔者与其他灾厄村民之间即使发生了误伤也不会相互攻击。唤魔者会主动远离[嘎枝](嘎枝.md)。

# = 尖牙攻击 =

在发动尖牙攻击前，唤魔者会伸出双臂，冒出淡紫色的粒子（），并发出声调较低、似号角的声音作为警告。接着一些尖牙突然从地上冒出，然后合上并消失。除[灾厄村民](灾厄村民.md)和外的[生物](生物.md)会受到尖牙的伤害（或）。尖牙伤害值无视盔甲，但[保护](保护.md)魔咒可以抵挡部分伤害。

唤魔者通常会在自己与玩家所在的直线上召唤16个尖牙，蔓延至20格的距离。尖牙攻击的施法时间为，距唤魔者最近的第一个尖牙在延迟后出现，接着其他尖牙以的时间间隔连续出现。而如果目标离唤魔者的距离少于3格，唤魔者会以自身为中心召唤两圈尖牙。这两圈尖牙出现的时间不同，玩家会被连续攻击两次。外圈为8个尖牙，在1.15秒的延迟后同时出现；内圈为5个尖牙，在1秒的延迟后同时出现。

尖牙只会生成在不低于位置最低的目标的脚、不高于位置最高的目标的脚上方1格的位置。尖牙会尝试在这一区域的上表面完整的方块上生成，但当这个方块被其他具有碰撞箱的方块挡住时会生成失败。这意味着召唤的尖牙无法生成在深坑里或高墙顶，但如果唤魔者在深坑的底部而目标在上方，它会试图走到顶部以发动攻击，反之亦然。

尖牙攻击的冷却时间为5秒。冷却从抬手施法的一瞬间开始计时，在施法结束后的冷却期间唤魔者可召唤恼鬼；冷却在施法结束后开始计时，在此期间唤魔者不可召唤恼鬼。

# = 召唤恼鬼 =
[缩略图|250px|一个唤魔者正在生成[[恼鬼](File:EvokerSummonsVexes.png.md)]]

当以唤魔者为中心的33×34×33矩形范围存在的恼鬼数小于8时，唤魔者才可能召唤恼鬼。在召唤[恼鬼](恼鬼.md)前，唤魔者会伸出双臂，冒出白色的粒子()，并发出声调较高、似号角的声音作为警告，施法时长为5秒，附近会生成3只恼鬼。恼鬼在被唤魔者召唤出的一段时间后会开始受到伤害，最终死亡。不论上次召唤的恼鬼是否存活，唤魔者仍可能召唤新的恼鬼。

召唤恼鬼的冷却时间为17秒。唤魔者在抬手施法1秒后生成恼鬼，并在原地继续施法，冷却从抬手施法的一瞬间开始计时，在施法结束后的冷却期间唤魔者可使用尖牙攻击；唤魔者在施法结束后，在以其为中心水平方向3x3的范围内根据目标和自身站位寻找具有完整侧面的方块，检测其正上方1格是否存在具有完整侧面的方块，如果有，则停止此点位尝试，如果没有，则选择此点进行生成，尝试生成1-3只恼鬼，在施法结束后进入冷却时间，在此期间唤魔者不可使用尖牙攻击。

# = 改变绵羊的颜色 =
当唤魔者在非战斗状态中，且[游戏规则](游戏规则.md)被设置为<code>true</code>时，唤魔者会把16格以内的所有[蓝色绵羊](绵羊.md)变成红色绵羊，一次仅改变一只。在此之前唤魔者会抬手并冒出橙色的粒子（），发出“呜噜噜”的声音作为警告。施法时长为3秒，羊毛颜色会在2秒后改变。唤魔者在被设置为时仍然会改变绵羊的颜色。

改变绵羊颜色的冷却时间为7秒，冷却从抬手施法的一瞬间开始计时；改变绵羊颜色的冷却时间为5秒，冷却在施法结束后开始计时。在施法结束后的冷却期间唤魔者可使用其他咒语。

# 你知道吗
* 官网文章“Meet the Evoker”展示了唤魔者戴着帽子的图片，帽子的模型类似于幻术师。<ref name="meet-evoker"/>
* * 这个帽子的模型也可以在未使用的女巫、卫道士纹理和[村庄与掠夺](村庄与掠夺.md)前未使用的傻子村民、图书管理员村民、牧师村民纹理上看到。
* 蓝色绵羊变红色绵羊的咒语彩蛋来源于游戏《[](wzh:世紀帝國系列.md)》（微软品牌IP）中的牧师的招降术，在该游戏中蓝色是预设友方色，而红色是预设敌方色，意味着绵羊被唤魔者转变为敌方生物。
* * 唤魔者施咒时的“呜噜噜”音效同样取自该牧师。
* 与其他灾厄村民不同，唤魔者不会追逐目标。
* 据[minecraft.net](minecraft.net.md)所说，唤魔者没有手持不死图腾来避免死亡，可能是因为其在设定上必须空出双手才能施展咒语<ref></ref>。但实际上通过命令手持物品的唤魔者也能施展咒语。
