# 幻翼膜

*页面ID: 34151* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *幻翼膜（Phantom Membrane）**是一种由[幻翼](幻翼.md)掉落的[酿造](酿造.md)原材料，也可用于修复鞘翅。

# 获取
# = 幻翼 =

# = 礼物 =

已驯服的[猫](猫.md)赠予玩家礼物时，礼物有3.226%的概率是1个幻翼膜。

# 用途
# = 修补 =
[鞘翅](鞘翅.md)可以在[铁砧](铁砧.md)中用幻翼膜修复，每个幻翼膜会给予108耐久度（即鞘翅完整耐久度的25%）。修复前后鞘翅的[魔咒](魔咒.md)会保持不变。

# = 酿造材料 =
幻翼膜可以用来酿造[缓降药水](缓降药水.md)。然而，与许多酿造原料不同，幻翼膜不能用来酿造[平凡的药水](平凡的药水.md)。
