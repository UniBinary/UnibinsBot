# Java版1.21.9-pre2

*页面ID: 166897* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.21.9-pre2**是[Java版1.21.9](Java版1.21.9.md)的第2个预发布版，发布于2025年9月19日<ref></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[铜傀儡](铜傀儡.md)**
* [氧化](氧化.md)计时现在使用游戏时间而非[昼夜更替](昼夜更替.md)时间。
* * 因此游戏规则被设为<code>false</code>时铜傀儡也会氧化。
* * 这也导致不再能使用或来加速其氧化。
* 更改了变为[铜傀儡像](铜傀儡像.md)的行为，以匹配。
* * 更改了转化条件，不再要求所在位置距方块中心较近。
* * 进入完全氧化阶段时每刻有0.58%概率直接转变为铜傀儡像。

# = 常规 =
* *[数据包](数据包.md)**
* 将数据包版本号更改为，以匹配[1.21.9-pre1](Java版1.21.9-pre1.md)中对和所作的破坏性更改。
