# Java版15w31b

*页面ID: 17238* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w31b**是[Java版1.9](Java版1.9.md)的第2个快照，发布于2015年7月30日<ref></ref>，修复了[15w31a](15w31a.md)中的一些漏洞。

# 更改
# = 物品 =
* *[喷溅型水瓶](喷溅型水瓶.md)**
* 现在可用于灭火，并创造一个小水坑。

# = 命令格式 =
* ***
* 现在能清空副手格。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
*
* * 不再导致玩家被服务器踢出。
*
* * 拿着的物品模型的高亮从一个盒子改为了贴边。
* * 穿着的盔甲和拿着的物品现在也会根据队伍转换颜色。
