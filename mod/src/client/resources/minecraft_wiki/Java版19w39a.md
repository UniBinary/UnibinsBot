# Java版19w39a

*页面ID: 48406* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w39a**是[Java版1.15](Java版1.15.md)的第7个快照，发布于2019年9月27日<ref name="article_19w39a"></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *常规**
* 选择方块时出现的轮廓现在回退至[19w38a](19w38a.md)前。

* *[铁门](铁门.md)**
* 现在需要[镐](镐.md)挖掘以变成掉落物。

* *[铁轨](铁轨.md)**
* 摆放时现在会根据玩家的朝向而改变方向，而不是一直都为南北朝向。

# = 命令 =
* *[NBT](NBT.md)聊天组件**
* 为NBT storage加入了变种：<code>-{}-{"nbt": <path>, "storage": "<资源ID>"}</code>。可以使用类似于<code>-{}-/data merge storage <资源ID> ....</code>的命令来操作NBT storage。

# = 常规 =
* *[纹理](纹理.md)**
* [末影龙](末影龙.md)翅膀的底部不再有单独的纹理了 。
* [光效](光效.md)纹理的外观现在和游戏内相同。
* *[方块模型](方块模型.md)**
* 物品栏内的方块光照被更改，现在是左侧为暗面。
