# Minecraft: The Wild Update (Original Game Soundtrack)

*页面ID: 95451* | *来源: Minecraft Wiki*

* **Minecraft: The Wild Update (Original Game Soundtrack)*（《Minecraft：荒野更新（游戏原声带）》）**是[Lena Raine](Lena Raine.md)与[Samuel Åberg](Samuel Åberg.md)合作为[荒野更新](荒野更新.md)创作的专辑，也是Lena Raine为Minecraft创作的第三张专辑。专辑于2022年4月20日在Spotify上发布。

本专辑包含4首乐曲，时长总计18分钟32秒，包括3首在[主世界](主世界.md)生存模式及[菜单屏幕](菜单屏幕.md)播放的曲目，以及1首[音乐唱片](音乐唱片.md)*5*的曲目。
