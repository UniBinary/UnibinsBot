# Java版Realms内容创作者计划

*页面ID: 180273* | *来源: Minecraft Wiki*

[alt=Atlas所使用的网站徽标。|border|right](File:Atlas_blue.svg.md)
* *Java版Realms内容创作者计划（Java Realms Content Creator Program）**<ref name=":0">https://www.minecraft.net/en-us/article/realms-page-content-creator</ref>，通常简称为**Java Creators**<ref>https://www.linkedin.com/in/oskar-thysell-4ba41bba/</ref>，是一个由[Mojang](Mojang Studios.md)运营的计划，旨在让地图制作者能够将自己制作的地图发布到[Realms](Realms.md)上，供[Java版](Java版.md)玩家游玩。通过该计划发布的地图会被添加到一个内容库中，Realms订阅者可以下载并游玩。

该计划由[Marc Watson](Marc Watson.md)创立于2013年，目前由Oskar Thysell管理。

# 提交地图
申请加入此计划，需要在Reddit的Realms子版块[r/realms](https://reddit.com/r/realms)上提交一张自制的地图。提交的地图会进入一个队列，等待Mojang的内容协调员审核。每位用户在任一时刻只能有一张地图位于队列中。

提交的地图经过审核并获得批准后，提交者将获得访问[Atlas提交门户](https://atlas.minecraft.net)以及供项目成员使用的Slack工作区和Discord服务器的权限。之后，提交者可以通过Atlas提交任何地图，这些地图将在Atlas中等待内容协调员的完整审核。地图通过完整审核后，将会被安排在本月或下个月发布，并在[minecraft.net](https://minecraft.net)进行公告。

如果提交的地图涉及多名作者，他们可能会获得访问Slack工作区和Discord服务器的权限，但除非他们自己也在Reddit子板块上有已被批准的地图，或者因创作了足够数量的地图而获得过[Realms地图制作者披风](披风#Java版披风.md)，否则他们无法访问Atlas。

所有提交的地图都必须遵守[Realms地图指南](https://atlas.minecraft.net/guidelines)。截至2025年4月，内容协调员为Oskar和[Nadja](Nadja Anderberg.md)。

# = 分类 =
通过该计划发布的地图分为以下五类<ref name=":0" />：

* **小游戏** - 流程简短、内容独立且可重复游玩的地图。
* **世界模板** - 为生存模式提供附加内容的地图，例如一座城堡或一个村庄。
* **冒险地图** - 侧重于线性叙事和探索的完整长流程地图。
* **体验地图** - 无明确通关目标，以提供环境互动体验为主的地图，例如主题公园。*（2025年9月起，不再接受提交此类别的地图，现有地图将逐步移至其他类别。）*
* **灵感建筑** - 以展示建筑技巧和创意为主的地图。

# = Java Realms Day =
Java Realms Day是一个“完全合法的年度十二月传统”，标志着该年度最后一批地图的发布。该活动固定于十二月的第三个星期五举行<ref>https://www.minecraft.net/en-us/article/new-on-java-realms-december-20250</ref>，这通常是Mojang开启假期前的最后一个工作日。其余月度发布则安排在各月的最后一个星期五（非假日）。

# 披风

发布了特定数量地图的作者可能有资格获得一个专属披风。所需地图数量根据地图所属类别有所不同，通常在2至4张之间。

2019年<ref></ref>至2023年，每年都会组织披风持有者的合影活动，Mojang会尽可能多地召集披风持有者在同一服务器内拍摄集体照。2024年起，此活动允许所有地图制作者（无论是否拥有披风）参加。

# 地图制作比赛
* *地图制作比赛（Map Jam）**是一项要求参与者在规定时间内，围绕指定的一个或多个主题创作地图的活动。自2024年起，地图制作者计划每年举办一届地图制作比赛，前三名的地图将发布至Realms。可通过[此邀请链接](https://discord.gg/bKHvJusFUa)加入官方Discord服务器。

# = Java版Realms内容创作者计划10周年地图制作比赛 =
作为Java版Realms内容创作者计划十周年庆典的一部分，**Java版Realms内容创作者计划10周年地图制作比赛（Java Realms Creators 10th Anniversary Mapjam）**于2024年4月6日12:00至4月11日12:00(UTC)举行。<ref>https://www.reddit.com/r/realms/comments/1bq01rr</ref><ref name=":1">https://docs.google.com/document/d/1ornjKlMOZ4HZBWh8l1HET--A09U2FY5JT6bTug-5LXo/edit?tab=t.0#heading=h.dqp5a17hxj00</ref> 同一地图至多可由3名参赛者完成。地图由Oskar、Aandel、Edou_和Flcme依据四个标准评审：创意、视觉效果、完成度与体验。每项标准分值为0至40分，总分最高为160分，排名前三的地图将发布至Realms。

除官方评审外，还设有社区投票环节，社区投票选出的前三名的地图的作者可获得Discord Nitro礼品作为奖励。

比赛主要主题为“宇宙”与“神话”，次要主题为“古董”与“奥德赛”。<ref name=":2"></ref>参赛作品须至少包含一个主要主题和一个次要主题。<ref name=":1" />

活动期间共收到28份有效提交。获胜的三张地图于[2024年11月29日](https://www.minecraft.net/en-us/article/new-on-realms-november-2024)公布。

# = Java创作者地图制作比赛 =
继上年比赛取得成功后，新一轮地图制作比赛于2025年5月23日02:00至5月27日02:00(UTC)举行。规则与上年类似，同一地图至多可由3名参赛者完成。地图由[Oskar](Oskar Thysell.md)、Flcme、TheWorfer27和[Nadja](Nadja Anderberg.md)根据四个标准评判：建筑、玩法、功能与主题契合度。每项标准分值为0至10分，总分最高为40分，最终成绩取平均分。

比赛开始时公布了五个主题，所有提交的作品须至少包含其中两个。这五个主题（及包含该主题的作品数量）为：**以寡敌众**（7）、**成双成对**（15）、**深潜之下**（18）、**重建**（6）与**突变**（6）。

共计158位参与者组成了80支队伍报名。活动期间共收到**39**份提交（其中2份因使用预制资源被取消资格）。其中四张仅支持多人游戏的地图由评审团队于2025年6月4日在[Nadja的Twitch频道](https://www.twitch.tv/violinetries)进行了直播试玩。

# Realms地图制作奖
2025年11月19日的一次会议宣布将于2026年2月4日举办首届官方的**Realms地图制作者奖**颁奖典礼，旨在表彰广受欢迎与具有代表性的Realms地图及其作者。活动宗旨为“嘉奖创意、独特性与一贯性”。颁奖典礼将进行公开直播。

# 你知道吗
在Realms早期阶段，地图制作者无法主动申请添加地图，而是由Mojang直接联系邀请。现行的申请流程大约确定于2014年。<ref name=":1" />
