# Java版20w15a

*页面ID: 58131* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w15a**是[Java版1.16](Java版1.16.md)的第11个快照，发布于2020年4月8日<ref name="20w15a"></ref>，加入了玄武岩三角洲、黑石以及相关特性、新的物品与方块标签和新的音乐，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[黑石](黑石.md)**
* 生成于[玄武岩三角洲](玄武岩三角洲.md)生物群系。
* 类似于[圆石](圆石.md)，可用于制作[熔炉](熔炉.md)和石质工具。
* 可用于合成对应的台阶、楼梯和墙。

* *[黑石台阶](黑石台阶.md)、[黑石楼梯](黑石楼梯.md)、[黑石墙](黑石墙.md)**
* 由黑石合成而来的装饰性方块。

* *[雕纹下界砖块](雕纹下界砖块.md)**
* [下界砖块](下界砖块.md)的新变种。
* 由2个下界砖台阶合成。

* *[雕纹磨制黑石](雕纹磨制黑石.md)**
* 由磨制黑石合成而来的装饰性方块。

* *[裂纹下界砖块](裂纹下界砖块.md)**
* [下界砖块](下界砖块.md)的新变种。
* 由下界砖块经过熔炉烧炼获得。

* *[裂纹磨制黑石砖](裂纹磨制黑石砖.md)**
* 由[磨制黑石砖](磨制黑石砖.md)烧制而来的装饰性方块。

* *[镶金黑石](镶金黑石.md)**
* 挖掘后有概率掉落2~5颗金粒（该数字可被时运魔咒增加），若不掉落金粒则掉落它本身。
* 目前不会自然生成，只能通过创造模式物品栏或命令获得。

* *[磨制黑石](磨制黑石.md)**
* 由4个[黑石](黑石.md)合成而来。
* 有雕纹、台阶、楼梯和墙变种。
* 可用于制作压力板和按钮。

* *[磨制黑石砖](磨制黑石砖.md)**
* 由4个[磨制黑石](磨制黑石.md)合成而来。
* 有裂制、台阶、楼梯和墙变种。

* *[磨制黑石砖台阶](磨制黑石砖台阶.md)、[磨制黑石砖楼梯](磨制黑石砖楼梯.md)、[磨制黑石砖墙](磨制黑石砖墙.md)**
* 由[磨制黑石砖](磨制黑石砖.md)合成而来的装饰性方块。

* *[磨制黑石按钮](磨制黑石按钮.md)、[磨制黑石压力板](磨制黑石压力板.md)**
* 由[磨制黑石](磨制黑石.md)合成而来的红石元件。
* 性质与其石质变种相同。

* *[磨制黑石台阶](磨制黑石台阶.md)、[磨制黑石楼梯](磨制黑石楼梯.md)、[磨制黑石墙](磨制黑石墙.md)**
* 由[磨制黑石](磨制黑石.md)合成而来的装饰性方块。

* *[石英砖](石英砖.md)**
* 由4个[石英块](石英块.md)合成而来。

* *[灵魂营火](灵魂营火.md)**
* 营火的灵魂火变种。
* 亮度等级为10。
* 与营火伤害数值相同。
* 用灵魂沙或灵魂土替代煤制成。
* 灵魂营火可以驱赶猪灵。

# = 物品 =
* *[旗帜图案](旗帜图案.md)**
* 新增猪灵样的旗帜图案。
* 看起来像猪灵的鼻子，在一个中心矩形内有两条垂直线。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* [玄武岩三角洲](玄武岩三角洲.md)
* * 下界的火山类生物群系，拥有火山灰样的浓雾效果。
* * 充斥着柱状[玄武岩](玄武岩.md)和大面积的[黑石](黑石.md)。
* * [恶魂](恶魂.md)、[岩浆怪](岩浆怪.md)和[炽足兽](炽足兽.md)会在此生物群系生成。

# = 常规 =
* *辅助功能**
* 现在可以调节聊天内容的行间距。
* 可设置0-6秒的聊天延迟，默认为0。

* *[音乐](音乐.md)**
* 为[下界](下界.md)加入了3首新的音乐：“Rubedo”，“Chrysopoeia”和“So Below”。作者是Lena Raine。
* * “Rubedo”会在[下界荒地](下界荒地.md)生物群系播放。
* * “So Below”会在[灵魂沙峡谷](灵魂沙峡谷.md)和[玄武岩三角洲](玄武岩三角洲.md)生物群系播放。
* * “Chrysopoeia”会在[绯红森林](绯红森林.md)播放。

* *[声音](声音.md)**
* 为玄武岩三角洲加入了[环境音效](环境音效.md)。

* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 包含营火和灵魂营火。
* * [蜜蜂](蜜蜂.md)、[鹦鹉](鹦鹉.md)和[海龟](海龟.md)将此标记的方块视为造成火焰伤害并相应地进行路径查找。
* * 营火使用这个标签来确定它们是否被点燃。
* * 打火石用这个标签来确定它是否能点燃营火。
* 加入了方块标签。
* * 包含：
* ** 容器（[木桶](木桶.md)、[箱子](箱子.md)、[末影箱](末影箱.md)、[陷阱箱](陷阱箱.md)和拥有方块标签的方块）。
* ** 金制品（[金块](金块.md)、[镶金黑石](镶金黑石.md)和拥有方块标签的方块）。
* * [猪灵](猪灵.md)将与开启或摧毁拥有这个标签的方块的玩家敌对。
* 加入了物品标签。
* * 包含[圆石](圆石.md)和[黑石](黑石.md)。
* * 此标签中的物品可用于制造熔炉，并将解锁配方书中的配方。
* 加入了物品标签。
* * 包含[圆石](圆石.md)和[黑石](黑石.md)。
* * 此标签中的物品可用于制作石质工具，并将解锁配方书中的配方。
* 加入了物品标签。
* * 包含[灵魂沙](灵魂沙.md)和[灵魂土](灵魂土.md)。
* * 此标签中的物品可用于制造灵魂营火和灵魂火把，并将解锁配方书中的配方。

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 现在发射器可以：
* * 给[猪](猪.md)和[马](马.md)配鞍；
* * 给马配马铠；
* * 给[羊驼](羊驼.md)配地毯；
* * 给羊驼、驴和骡配箱子；
* * 修剪[哞菇](哞菇.md)；
* * 修剪[雪傀儡](雪傀儡.md)。

* *[熔炉](熔炉.md)**
* 现在可使用[黑石](黑石.md)合成。

* *[灵魂火把](灵魂火把.md)**
* 现在可由[灵魂沙](灵魂沙.md)合成。

* *[墙](墙.md)**
* 现在可连接[铁栏杆](铁栏杆.md)和[玻璃板](玻璃板.md)。

# = 物品 =
* *石[斧](斧.md)、[锄](锄.md)、[镐](镐.md)、[锹](锹.md)和[剑](剑.md)**
* 可使用黑石合成。

* *[锄](锄.md)**
* 现在是破坏[树叶](树叶.md)的默认工具。
* * [剪刀](剪刀.md)仍是收集树叶**方块**的工具。

* *[下界菌](下界菌.md)、[下界苗](下界苗.md)、[菌索](菌索.md)、[缠怨藤](缠怨藤.md)、[下界疣](下界疣.md)、[下界疣块](下界疣块.md)、[诡异疣块](诡异疣块.md)和[垂泪藤](垂泪藤.md)**
* 现在可用于堆肥。

# = 生物 =
* *常规**
* 生物现在会避免走上[岩浆块](岩浆块.md)和点燃的[营火](营火.md)。

* *[疣猪兽](疣猪兽.md)**
* 幼年疣猪兽不再掉落战利品。

* *[岩浆怪](岩浆怪.md)**
* 现在可生成于玄武岩三角洲生物群系。

* *[猪灵](猪灵.md)**
* 现在会远离灵魂营火。
* 现在对任何一个破坏箱子、陷阱箱、末影箱、木桶、金矿石、下界金矿石、镶金黑石或金块的玩家敌对。
* *[炽足兽](炽足兽.md)**
* 在熔岩外会变成蓝紫色。
* * 在熔岩外，它们的面部表情会稍微改变。
* 现在只能在熔岩上面是空气的情况下生成。
* 幼年炽足兽可骑在成年炽足兽上。

* *[僵尸疣猪兽](僵尸疣猪兽.md)**
* 现在是[亡灵生物](亡灵生物.md)。

# = 常规 =
* *[标签](Java版标签.md)**
* 在方块和物品标签中加入磨制黑石和（如适用）黑石。
* 为灵魂营火加入了方块标签。
* 加入方块标签，并将灯笼和灵魂灯笼从方块标签中移除。

* *纹理**
* 移除了[炽足兽](炽足兽.md)纹理文件中未使用的鳍。

# 你知道吗
* 单词“[Rubedo](wikipedia:wikt:rubedo.md)”是拉丁语中的“redness”，可能与下界的红色调环境有关。
* 单词“[Chrysopoeia](wikipedia:wikt:chrysopoeia.md)”是一个炼金术术语，描述了点石化金的嬗变过程。
