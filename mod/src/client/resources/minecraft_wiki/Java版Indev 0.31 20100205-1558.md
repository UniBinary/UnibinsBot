# Java版Indev 0.31 20100205-1558

*页面ID: 172710* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2010年2月5日15:58（UTC），加入了[巨人](巨人.md)和[难度](难度.md)。<ref></ref>

# 新内容
# = 生物 =
* *[巨人](巨人.md)**
* 使用[僵尸](僵尸.md)的模型，但大小是僵尸的数倍。
* 会向[玩家](玩家.md)移动并攻击玩家。
* * 只能在玩家在其正下方时攻击到玩家。

# = 游戏内容 =
* *[难度](难度.md)**
* 新的选项。
* * 和平、简单、普通和困难。

* *[物品栏](物品栏.md)**
* 物品栏中的玩家可以正常显示了。
* 右键单击[物品](物品.md)现在将拿起物品数的一半。<ref name="Forum"></ref>
* 现在只要合成台中还有剩余材料，就可以连续合成多次同一物品，而不需要每次将其放入到物品栏中。<ref name="Forum2"></ref>
* 方块阴影被再次修改。</onlyinclude>

# = 常规 =
* *其他**
* 改进了性能。
