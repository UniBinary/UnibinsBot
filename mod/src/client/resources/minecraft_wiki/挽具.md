# 挽具

*页面ID: 148735* | *来源: Minecraft Wiki*

* *挽具（Harness）**是一种能够装备在[快乐恶魂](快乐恶魂.md)身上的物品，有16种颜色。

# = 快乐恶魂 =
装备着挽具的快乐恶魂在死亡时会掉落所装备的挽具。对着装备着挽具且未被骑乘的快乐恶魂[剪刀](剪刀.md)也可将挽具移除。

# 用途

未装备挽具的快乐恶魂会主动跟随半径16格内手持挽具的玩家。

对快乐恶魂挽具或者使用[发射器](发射器.md)为其装备挽具后，快乐恶魂可以被玩家骑乘。

挽具被装备在快乐恶魂上时，其镜框会在无乘客时抬起，而在有乘客时落回眼前。
