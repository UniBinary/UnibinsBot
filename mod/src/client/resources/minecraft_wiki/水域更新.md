# 水域更新

*页面ID: 33193* | *来源: Minecraft Wiki*

[缩略图|Mojang发布的水域更新主视觉图](File:Update Aquatic Artwork.jpg.md)
* *水域更新（Update Aquatic）**是一次主要更新，以改造[海洋](海洋.md)为更新主题。

[Java版](Java版.md)的此次更新以[Java版1.13](Java版1.13.md)版本的形式于2018年7月18日发布。<ref name=merge></ref><ref></ref>在[基岩版](基岩版.md)中，此次更新因其内容数量而被分为两次更新，包含大多数特性的第一阶段于2018年5月16日以[1.4.0](基岩版1.4.0.md)发布<ref></ref>，其余特性于2018年7月10日以[1.5.0](基岩版1.5.0.md)发布<ref></ref>，随后又补充了一些内容于2018年8月28日以[1.6.0](基岩版1.6.0.md)发布。[原主机版](原主机版.md)已在2018年9月11日更新。<ref></ref>[Nintendo Switch版](Nintendo Switch版.md)玩家会得到此次更新的补丁包，并且可以免费安装新版本。这将是除PlayStation 4之外原主机版的最后一次更新。<ref></ref>此外，发布于[教育版](教育版.md)的水域更新已经在[1.4.0](教育版1.4.0.md)于2018年6月12日发布<ref></ref>，随后又补充了一些内容在[1.7.0](教育版1.7.0.md)于2018年11月12日发布。

在[Java版](Java版.md)上，此次更新的开发始于[17w43a](17w43a.md)，其发布于2017年10月25日。第一个预发布版[Java版1.13-pre1](Java版1.13-pre1.md)发布于2018年6月4日，[第十个](Java版1.13-pre10.md)（也是最后一个）发布于2018年7月17日。

在[基岩版](基岩版.md)上，此次更新的第一阶段开发始于[基岩版1.2.14.2](基岩版1.2.14.2.md)，其发布于2018年3月28日；第二阶段开发始于[基岩版1.5.0.0](基岩版1.5.0.0.md)，其发布于2018年4月25日。

2018年7月10日，Mojang发布了此次更新的[预告片](https://www.youtube.com/watch?v=hcutClmY1pI)。

# = 更改 =
* [岩浆块](岩浆块.md)现在生成于海洋里并会导致向下气泡柱出现
* 更改了[南瓜](南瓜.md)的纹理，并将旧的纹理命名为“雕刻南瓜”，可通过使用[剪刀](剪刀.md)右键点击南瓜获得
* 水源方块现在能够放置在半透明的方块的里面，例如楼梯和台阶，称之为[充水](充水.md)
* 掉落物现在会在水面浮动
* 取代和更改了许多命令
* [扁平化](扁平化.md)
* 新的[马](马.md)的[模型](模型.md)
* 新的[水](水.md)的纹理
* [物品展示框](物品展示框.md)现在能够放置在地板或天花板上
* [鱿鱼](鱿鱼.md)被攻击时会产生墨汁
* 离开水体时[玩家](玩家.md)的氧气槽不再瞬间恢复
* 更改了在水下时的视野
* 地图现在能通过[旗帜](旗帜.md)进行标记
* [潜影盒](潜影盒.md)现在能通过使用[炼药锅](炼药锅.md)洗去颜色

# 跟进版本
# = Java版 =
* [Java版1.13.1](Java版1.13.1.md)加入了一个选择世界屏幕的搜索栏，还重新加入挖掘以引爆[TNT](TNT.md)的能力，允许[鱼](鱼.md)掉落[骨粉](骨粉.md)，增加[失活的珊瑚](失活的珊瑚.md)，添加新的命令，明显地更改了[鱿鱼](鱿鱼.md)的生成机制，并且修复了大量漏洞。
* [Java版1.13.2](Java版1.13.2.md)修复了若干漏洞，并且提升了性能。

# = 基岩版 =
# == 1.4（第一阶段） ==
* [1.4.1](基岩版1.4.1.md)发布于Android、Fire OS和Fire TV平台以修复一个涉及玩家失去之前购买的物品的漏洞。
* [1.4.2](基岩版1.4.2.md)发布以修复一些导致游戏崩溃的漏洞。
* [1.4.3](基岩版1.4.3.md)发布于iOS平台以修复一些漏洞以及加入一个由Blockceptions制作的地图。
* [1.4.4](基岩版1.4.4.md)发布于Android、Fire OS和Fire TV平台以修复一个有关遥测技术的漏洞。

# == 1.5（第二阶段） ==
* [1.5.1](基岩版1.5.1.md)发布以修复1.5正式版中的若干漏洞。
* [1.5.2](基岩版1.5.2.md)仅修复了低端设备上的一个有关位图的漏洞。
* [1.5.3](基岩版1.5.3.md)修复了物品栏丢失物品的漏洞及其他若干漏洞。

# 你知道吗
* 水域更新最初在[MINECON Earth 2017](MINECON Earth 2017.md)直播期间被决定作为[1.14](Java版1.14.md)发布，而[1.13](Java版1.13.md)則作為**技术更新（Technically Updated）**。但由于世界生成大改所需时间超过了Mojang的预期，兩者被合併，水域更新后来改作为1.13发布。<ref></ref>
* [Jeb](Jeb.md)在2011年的一次采访中表示他希望在游戏中实现更多的海洋生物。<ref></ref>
