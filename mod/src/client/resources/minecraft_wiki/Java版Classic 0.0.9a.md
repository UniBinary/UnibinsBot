# Java版Classic 0.0.9a

*页面ID: 34842* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.9a**<ref name="Tigsource"/><ref>["castle.png"](http://i382.photobucket.com/albums/oo269/jwaap/castle.png) （[存档](https://web.archive.org/web/20150402230943/http://i382.photobucket.com/albums/oo269/jwaap/castle.png)） – jwaap, PhotoBucket; as mentioned in [Tigsource](https://forums.tigsource.com/index.php?topic=6273) and [IRC logs](#logs.md) ("*(16:34:37) jw: http://i382.photobucket.com/albums/oo269/jwaap/castle.png*")</ref><ref name=":0">[视频存档](http://web.archive.org/web/20101227155640/http://www.youtube.com:80/watch?v=3XpSaBZchEs&feature=related) (非功能性)</ref>是2009年5月16日19:15（UTC）制作完成的[Classic](Java版Classic.md)版本，<ref name="new version out">[TigIRC logs](#logs.md): "*(15:15:08) notch: new version out, you can't build in a space you're occupying, and I fixed a small graphical glitch with preview tiles*" [...] "*(16:11:54) jw: minecraft is awesome D;*", "*(16:11:57) jw: and in your browser*" [...] "*(16:15:06) jw: I am so building a castle*" [...] "*(16:34:37) jw: http://i382.photobucket.com/albums/oo269/jwaap/castle.png*" (19:15 to 20:34 UTC)</ref><ref name="last night">[lwjgl IRC logs](#lwjgl logs.md): "*[13:15:36] <Notch_> i did a small update late last night, but nothing that should fix that, I think*" (May 17, 11:15 UTC)</ref>加入了新的建筑模式，显示帧率和区块更新的计数器，更改了分辨率，并修复了一些漏洞。

Notch没有表示制作过0.0.4a到0.0.8a之间的版本，甚至也不清楚是否编译过这些版本。

# 新内容
# = 游戏内容 =
* *[平视显示器](平视显示器.md)**
* 加入了帧率和区块更新计数器，位于左上角。

# = 常规 =
* *[控制](控制.md)**
* 单击右键会在放置和破坏模式之间切换。<ref>[TigIRC logs](#logs.md): "*(14:49:37) notch: I'm switching so that rmb = toggle edit mode now*"</ref>

# 更改
# = 方块 =
* *[木板](木板.md)**
* 更改了纹理。

# = 游戏内容 =
* *常规**
* 现在选中方块会显示其轮廓。

# = 常规 =
* *其他**
* 游戏的分辨率从1024×768改为640×480。

# 修复
; 修复了2个漏洞
   修复在建造模式中预览方块引起图像卡顿的问题。
   玩家无法和之前一样在自己身体的位置放置方块了。</onlyinclude>
