# 基岩版标签

*页面ID: 169213* | *来源: Minecraft Wiki*

在[行为包](行为包.md)，**标签**（也被称为**注册表标签**）允许玩家将不同的游戏元素组织到一起。

# 使用
# = JSON格式 =
<div class="treeview">
* 根对象
* *：要定义的标签类型。必须为、或。
* **
* ***（仅对生物群系和物品）
* ****：标签列表。
* *****：标签名。
* ***：（仅对方块）应被替换为标签名。该必须为空。
</div>

一个方块、物品或生物群系可能有多个标签。自定义和原版标签都可使用。

标签可用于在命令和行为包中执行查询操作。<!--
