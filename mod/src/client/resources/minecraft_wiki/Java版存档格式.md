# Java版存档格式

*页面ID: 9268* | *来源: Minecraft Wiki*

* *存档（Level）**是游戏保存世界的持久化形式。

# 存档位置
游戏客户端内的所有存档均在（存档存储目录）下，每一个目录代表一个存档。

游戏不会将所有目录都视为存档，而是会检查每个目录内的或以确认这是一个有效的游戏存档，确认后的目录才会在[选择世界菜单](选择世界菜单.md)中出现。

对于客户端，名称为*w*的存档，其存档根目录就是。

对于服务端，存档位置由两个参数决定：
* 服务端启动参数<code>--universe</code>（默认为，即当前运行目录）：指定存档存储目录，下文简化为*u*。
* 服务端启动参数<code>--world</code>、中<code>level-name</code>项（按顺序尝试获取）：指定存档名称，下文简化为*w*。

根据这两个参数，服务端的存档根目录路径是。

# 存档结构
每个存档都有相应的文件保存数据，这些文件按照一定的存储格式，在特定的路径上起到作用。下文中**粗体**代表文件一定存在，未标注粗体则代表文件不一定存在，备份文件不以显示。假定存档已经初始化完成、且至少有一名玩家进入过存档。

所有和[维度](维度.md)无关的数据其存储文件都直接和存档根目录相对应，下列是所有维度无关的数据存储文件：

# = 过时文件目录 =
不包括区块数据相关的文件。区块数据从Alpha阶段开始采用“区域”的概念存储，此时每个区块都存储于[独立的文件夹中](Alpha世界格式#区块格式.md)；自[Beta 1.3](Beta 1.3.md)起，区块数据使用MCRegion格式存储，随后在[12w07a](Java版12w07a.md)中改为[Anvil文件格式](Anvil文件格式.md)，并使用至今。
