* *烈焰人（Blaze）**是生成在[下界要塞](下界要塞.md)的飞行敌对生物，同时也是[烈焰棒](烈焰棒.md)的唯一来源。

# 生成
烈焰人可以自然生成在[下界要塞](下界要塞.md)中[亮度](亮度.md)等级小于等于或的地方。

# = 刷怪笼 =
烈焰人[刷怪笼](刷怪笼.md)会在[下界要塞](下界要塞.md)中自然生成。

# 行为
烈焰人会飞，不过处在空闲状态时它们会原地不动或者从空中缓缓下降。烈焰人在熔岩或水中时不会在液体表面游泳。

与多数下界生物一样，烈焰人免疫[火焰伤害](伤害#火焰伤害.md)。

与[悦灵](悦灵.md)和[发光鱿鱼](发光鱿鱼.md)类似，烈焰人拥有发亮的纹理，在暗处也清楚可见，但不会影响周围方块的实际[亮度](亮度.md)。

烈焰人还会在一些特有的情况下受到伤害：烈焰人被[雪球](雪球.md)击中时受到伤害，被[喷溅型水瓶](喷溅型水瓶.md)喷溅时受到伤害；当烈焰人处于[雨](雨.md)或[水](水.md)中时，每0.5秒受到伤害；在[细雪](细雪.md)中进入冰冻状态的烈焰人每2秒受到伤害，这是多数生物所受伤害的5倍。

尽管烈焰人会被水伤害，但它们在水中时不会试图从中脱离以自保。烈焰人不会避开火，但会避开水。

# = 攻击 =
[thumb|烈焰人发射小火球的动画](File:Blaze Shooting.gif.md)

烈焰人会搜寻48格内的玩家，远超大多数生物的16格搜索范围。当目标距离烈焰人48格时，烈焰人会发动远程攻击。它们也会对2格内的攻击目标进行近战攻击，但不会点燃目标。烈焰人被非玩家生物攻击时会进行反击，。当烈焰人有攻击目标时，它会试图保持在比目标高度高0.5-3.5格的地方并慢慢接近目标。

烈焰人可以从远距离发射以三个为一组的[小火球](小火球.md)。使用这种攻击时，它们会先着火3秒钟，接着在0.9秒中发射3个小火球，然后火焰熄灭并等待5秒后继续攻击。

烈焰人发射的小火球会在击中的地点生成[火](火.md)。被小火球命中的实体会受到弹射物伤害/火焰伤害，并[着火](着火.md)5秒，通常受到额外的火焰伤害。小火球的弹道不能像[火球](火球.md)一样被偏转，但是能被盾牌阻挡，这可以防止玩家受到火球的伤害。

小火球造成的伤害同时属于弹射物伤害和火焰伤害，并同时受到[弹射物保护](弹射物保护.md)和[火焰保护](火焰保护.md)的减免，也会被[抗火](抗火.md)效果无效化。

# 你知道吗
* 受[隐身](隐身.md)效果影响的烈焰人身上的黑烟仍然可见。
* 据Jeb说，Minecraft世界中所有生物都是方的，所以为了使烈焰人看起来有“燃烧”效果和魔幻色彩，他把它们做成了这种“棒棒绕着核心转”的样子，又给它们加了眼睛使它们看起来更类人。<ref name="minecraft.net"/>
* 尽管没有可见的脚，烈焰人仍然可以产生脚步声。<ref></ref>
