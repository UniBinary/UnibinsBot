# 砂土

*页面ID: 13200* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *砂土（Coarse Dirt）**是泥土的变种，它不会被附近的[草方块](草方块.md)扩散而长草。

# 生成
# = 自然生成 =
砂土能在[原始松木针叶林](原始松木针叶林.md)、[原始云杉针叶林](原始云杉针叶林.md)、[疏林恶地](疏林恶地.md)和[风袭热带草原](风袭热带草原.md)生物群系中大片地生成。

砂土也会在[林地府邸](林地府邸.md)的蘑菇房间中生成。

砂土也会作为[古迹废墟](古迹废墟.md)的一部分生成，随机替换掉结构中原有的[沙砾](沙砾.md)。

# 破坏
挖掘砂土的合适工具是锹。

砂土被破坏后会掉落自身。

# 用途
[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)、[灌木丛](灌木丛.md)、[花](花.md)、[野花簇](野花簇.md)、[粉红色花簇](粉红色花簇.md)、[枯萎的灌木](枯萎的灌木.md)、[大型垂滴叶](大型垂滴叶.md)、[下界菌](下界菌.md)、[绯红菌索](绯红菌索.md)、[诡异菌索](诡异菌索.md)、[下界苗](下界苗.md)、[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)都能被放置在砂土上。[树苗](树苗.md)、[竹子](竹子.md)和[甜浆果丛](甜浆果丛.md)能在砂土上生长。[甘蔗](甘蔗.md)和[蘑菇](蘑菇.md)也会在符合条件的情况下在砂土上生长。

[草方块](草方块.md)和[菌丝体](菌丝体.md)无法扩散至砂土上。

[末影人](末影人.md)可以搬起及放下砂土。关闭[游戏规则](游戏规则.md)将阻止该行为。

# = 转变 =
对着砂土[锄](锄.md)可将其转变为泥土，并使锄消耗掉1点耐久。

对着砂土[锹](锹.md)可将其转变为[土径](土径.md)，并使锹消耗掉1点耐久。

[大型云杉](大型云杉.md)长成后会将其下方及周围的砂土转变为[灰化土](灰化土.md)。

[杜鹃树](杜鹃树.md)长成后会将其下方的砂土转变为[缠根泥土](缠根泥土.md)。

对上方为空气的[苔藓块](苔藓块.md)或[苍白苔藓块](苍白苔藓块.md)[骨粉](骨粉.md)会使周围7×11×7范围内，最上方的砂土转变为苔藓块或苍白苔藓块。

对着砂土[水瓶](水瓶.md)或发射器发射水瓶会将砂土转化为[泥巴](泥巴.md)。
