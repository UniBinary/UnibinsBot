# 磨制玄武岩

*页面ID: 56406* | *来源: Minecraft Wiki*

* *磨制玄武岩（Polished Basalt）**是[玄武岩](玄武岩.md)制作的装饰性方块。

# 生成
# = 自然生成 =
磨制玄武岩会作为[堡垒遗迹](堡垒遗迹.md)和[远古城市](远古城市.md)的一部分自然生成。

# 破坏
挖掘磨制玄武岩的合适工具是镐。磨制玄武岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

磨制玄武岩被破坏后会掉落自身。

# 用途
磨制玄武岩目前仅用于装饰。

类似于[原木](原木.md)和[石英柱](石英柱.md)等方块，磨制玄武岩可以朝向任意水平或垂直方向，这取决于玩家放置它们时的方向。
