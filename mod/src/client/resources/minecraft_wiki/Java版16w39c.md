# Java版16w39c

*页面ID: 25049* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w39c**是[Java版1.11](Java版1.11.md)的第9个快照，发布于2016年9月30日<ref></ref>，修复了[16w39a](16w39a.md)和[16w39b](16w39b.md)中的一些漏洞与崩溃。

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 发射[船](船.md)时，船会和发射器朝向同一方向，而不是对着发射器。

* *[潜影盒](潜影盒.md)**
* 将银色潜影盒重命名为浅灰色潜影盒，以保持染色方块命名的一致性。

# = 生物 =
* *[潜影贝](潜影贝.md)**
* 能够通过使用[刷怪蛋](刷怪蛋.md)在方块旁边和底部生成潜影贝。
