# 原主机版TU57、CU49、1.57、1.56、Patch 27、1.0.7

*页面ID: 64119* | *来源: Minecraft Wiki*

* *TU57/CU49/1.57/1.56/Patch 27/1.0.7**是[原主机版](原主机版.md)的一次更新，发布于2017年8月29日，修复了一些漏洞。<ref></ref><ref></ref>

# 新内容
# =常规=
* *混搭包**
* 添加格雷特神话混搭包。

* *皮肤包**
* 添加“陌生人 - 生物群系的移民3”皮肤包。

# 更改
# =常规=
* [XB360](Xbox 360版.md)：更新了UI渲染。
* [WIIU](Wii U版.md)：可以将数据传输到Nintendo Switch版。
* [NS](Nintendo Switch版.md)：可以将数据传输到Wii U版。

# = 方块 =
* *[船](船.md)**
* 现在需要一把木[锹](锹.md)来合成。

* *[石台阶](石台阶.md)**
* 可以通过[石头](石头.md)、[安山岩](安山岩.md)、[闪长岩](闪长岩.md)、[花岗岩](花岗岩.md)以及其磨制形式来合成。

* *[红石中继器](红石中继器.md)**
* 可以通过[石头](石头.md)、[安山岩](安山岩.md)、[闪长岩](闪长岩.md)、[花岗岩](花岗岩.md)以及其磨制形式来合成。

* *[红石比较器](红石比较器.md)**
* 可以通过[石头](石头.md)、[安山岩](安山岩.md)、[闪长岩](闪长岩.md)、[花岗岩](花岗岩.md)以及其磨制形式来合成。

* *[侦测器](侦测器.md)**
* 现在可以侦测[物品展示框](物品展示框.md)、[门](门.md)、[花盆](花盆.md)的状态更新。
* 不可再侦测[火](火.md)的变更。
* 不会在侦测到液体方块时输出多个信号。

* *[活塞](活塞.md)**
* 可以推动[阳光传感器](阳光传感器.md)。

# = 物品 =
* *[药水](药水.md)**
* 一些药水的持续时间有所改变。

# = 生物 =
* *[末影人](末影人.md)与[末影螨](末影螨.md)**
* 现在互相敌对。

* *[北极熊](北极熊.md)**
* 现在不会在和平难度下攻击玩家。

* *[凋灵骷髅](凋灵骷髅.md)**
* 不再害怕白天。
* 会攻击任何生物。

* *[僵尸马](僵尸马.md)**
* 可以被驯服了。

* *[骷髅马](骷髅马.md)**
* 可以被驯服了。

* *[骷髅](骷髅.md)**
* 不会主动攻击村庄中的[铁傀儡](铁傀儡.md)。
* 现在会逃离野生狼。

* *[狼](狼.md)**
* 不会攻击不在其视线范围之内的生物。

# 修复
* *修复了9个漏洞**
* 修复了生物在水中行走缓慢的漏洞。
* 修复了农民村民种植种子的频率不够高的漏洞。
* 修复了玩家在回合开始时位于迷你游戏大厅，会导致玩家在迷你游戏中不受伤害的漏洞。
*  - 在创造模式选择方块。
* XB360、XBONE、PS3、PS4和NS： - 快捷栏不在分屏战斗中居中。
*  - 僵尸沉入水中。
*  - 飘浮效果应该在顶部。
* XB360： - 唤魔者尖牙。
* XBONE： - 无法获得自由潜水员成就。
