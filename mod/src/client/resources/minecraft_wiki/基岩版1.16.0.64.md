# 基岩版1.16.0.64

*页面ID: 62888* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.0.64**是[基岩版1.16.0](基岩版1.16.0.md)的第15个测试版，发布于2020年5月28日<ref></ref>，修复了一些漏洞。

# 修复
* *修复了11个漏洞**

* *常规**
* 旧版本的世界不会生成新的下界生物群系、方块和结构，并被游戏更新方块代替。（）
* 修复了导致玩家无法加入专用服务器的问题。

* *游戏**
* 修复了可能导致加载区块中的方块实体丢失数据的问题。（）

* *生物**
* 被治愈的僵尸村民可以再次繁殖了。（）
* 寻路的生物将能够走到路的尽头了。
* 兔子在移动时会再次正确跳动了。（）

* *图形**
* 从空中下落时，纹理现在可以正确地被加载。（）

* *附加包和脚本**
* 基本包中使用玩家的内容现在会正确地游泳了。
* 当使用带有记分板的假玩家时，函数不再提供内容日志错误了。
* 名称中带有数字的音效现在可以正确地被播放。
* 修复了不会施加垂直击退力的问题。</onlyinclude>
