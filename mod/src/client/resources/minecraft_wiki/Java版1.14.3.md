# Java版1.14.3

*页面ID: 43561* | *来源: Minecraft Wiki*

* *1.14.3**是的一次次要更新，发布于2019年6月24日<ref></ref>，加入了新的游戏规则和新的语言，并修复了一些漏洞。此版本**不**兼容1.14到1.14.2的服务端。

# 新内容
# = 命令格式 =
* ***
* 加入了，设为时禁用[袭击](袭击.md)。
* * 设为时，不祥之兆不会在玩家进入村庄后消失。
* * 若在袭击进行时将其设为，袭击会中断，但之前生成的袭击生物（[灾厄村民](灾厄村民.md)、[劫掠兽](劫掠兽.md)等）并不会消失。

# = 常规 =
* *[控制](控制.md)**
* 在按住时按下会把除创造模式外的所有模式切换成创造模式。

* *[语言](语言.md)**
* 加入了巴什基尔语（Башҡортса）。
* 加入了哥特语（Gutrazda）。

# 更改
# = 方块 =
* *[灯笼](灯笼.md)**
* 可以放置于[铁栏杆](铁栏杆.md)和[玻璃板](玻璃板.md)上方和下方了。

* *[压力板](压力板.md)和[火把](火把.md)**
* 可以放置于[铁栏杆](铁栏杆.md)和[玻璃板](玻璃板.md)上。

# = 物品 =
* *常规**
* 物品现在又可以通过将它们合成在一起来修复了，就像[Java版1.14](Java版1.14.md)前那样。

# = 生物 =
* *[村民](村民.md)**
* 村民处于慌张中时有更高的概率生成[铁傀儡](铁傀儡.md)。
* 农民村民现在会花更长时间来耕种。
* 农民村民仍会给其他村民食物，即使它们并不需要<!-- ????  -->。
* 受惊的[村民](村民.md)现在会工作和睡眠，而不会一直处于恐慌状态。
* [村民](村民.md)的“最后一次睡眠”和“最后一次工作”属性现在会正确保存<!-- ????  -->。

# = 游戏内容 =
* *[灾厄巡逻队](灾厄巡逻队.md)**
* [卫道士](卫道士.md)不再是[灾厄巡逻队](灾厄巡逻队.md)的一部分了。
* 延长了最小生成时间，从5+（最大为1）分钟到10+（最多为1）分钟。
* 如果[光照](光照.md)等级不能满足怪物生成的条件，那么[灾厄巡逻队](灾厄巡逻队.md)也不会生成。
* [灾厄巡逻队](灾厄巡逻队.md)现在会在除[蘑菇岛](蘑菇岛.md)以外的任何[生物群系](生物群系.md)生成。

* *[魔咒](魔咒.md)**
* [保护](保护.md)、[弹射物保护](弹射物保护.md)、[火焰保护](火焰保护.md)和[爆炸保护](爆炸保护.md)现在不再兼容。

* *[进度](进度.md)**
* “”进度不再需要[饱和](饱和.md)状态效果。

# = 常规 =
* *性能**
* 性能优化。
