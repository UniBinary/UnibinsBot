# Java版24w11a

*页面ID: 114562* | *来源: Minecraft Wiki*

<onlyinclude>

* *24w11a**是[Java版1.20.5](Java版1.20.5.md)的第12个快照，发布于2024年3月14日<ref></ref>，加入了新的[战利品表函数](战利品表函数.md)，在内置实验性数据包中加入了[重锤](重锤.md)、[旋风棒](旋风棒.md)、[沉重核心](沉重核心.md)、2种新的[锻造模板](锻造模板.md)和[旗帜图案](旗帜图案.md)、3种新的[陶片](陶片.md)，修改了内置实验性数据包中[试炼密室](试炼密室.md)的结构及[旋风人](旋风人.md)和[宝库](宝库.md)的[战利品表](战利品表.md)，并修复了一些漏洞。

# = 命令格式 =
* ***
* 现在执行环境为自定义维度也可以生效。

* *谓词**
* 删除了实体子谓词<code>any</code>。
* 现在指定组件的物品谓词属性被移动到<code>predicates</code>字段中。
* 为[物品展示框](物品展示框.md)、[物品展示实体](物品展示实体.md)等仅有单个槽位的实体加入了槽位名称<code>contents</code>。
* 现在实体数据<code>item</code>被<code>contents</code>包含。
* 现在部分物品谓词字段被移入可选字段<code>predicates</code>中，它们的格式与[物品堆叠组件](物品堆叠组件.md)相似。
* * 这为未来添加谓词提供便利，且让子谓词与其匹配的组件更相似。
* * 将以下谓词移动为子谓词：
* ** <code>enchantments</code> → <code>minecraft:enchantments</code>
* ** <code>stored_enchantments</code> → <code>minecraft:stored_enchantments</code>
* ** <code>potions</code> → <code>minecraft:potion_contents</code>
* ** <code>custom_data</code> → <code>minecraft:custom_data</code>
* * <code>durability</code>被扩展为谓词<code>minecraft:damage</code>。
* ** 现在会对拥有<code>minecraft:damage</code>组件的任意物品生效；如果物品没有<code>minecraft:damage</code>组件，它将永不匹配。
* ** 现在不再能检测物品是否含有组件，而需获取该组件的值。
* ** 格式：
<div class="treeview">
  ::*
  ::** ：（可选）组件的精确值。
  ::** ：（可选）耐久的精确值，为最大损伤值减的值。
</div>
  * 谓词现在需要物品具有匹配的组件。
  ** 具有默认值的组件可能总是符合条件。
  * 示例：
  : <syntaxhighlight lang="json">{
	"item": {
		"predicates": {
			"minecraft:enchantments": [
				{
					"enchantment": "minecraft:silk_touch",
					"levels": {
						"min": 1
					}
				}
			]
		}
	}
}</syntaxhighlight>

# 新内容（实验性）
# = 方块 =
* *[沉重核心](沉重核心.md)**
* 一种[碰撞箱](碰撞箱.md)不完整且不[含水](含水.md)<ref></ref>的方块。
* 可从[试炼密室](试炼密室.md)的[宝库](宝库.md)或柱廊入口密室的奖励箱获得。
* 具有金属音效。
* [硬度](硬度.md)和[爆炸抗性](爆炸抗性.md)均为30，没有合适的[挖掘](挖掘.md)工具，不能被任何工具加速挖掘，但被非创造模式玩家破坏时总会掉落。
* 不可被[活塞](活塞.md)推拉，被活塞推动时会被破坏。
* 会被水流破坏。
* 用于合成[重锤](重锤.md)。

# = 物品 =
* *[旋风棒](旋风棒.md)**
* 由[旋风人](旋风人.md)掉落。
* 可以合成为4个[风弹](风弹（物品）.md)，也可以与沉重核心合成重锤。

* *[重锤](重锤.md)**
* 一种重型武器。
* 使用1个沉重核心和1个[旋风棒](旋风棒.md)合成。
* 可以加速破坏任意方块。<ref></ref>
* * 与[剑](剑.md)和[三叉戟](三叉戟.md)一样，创造模式下主手持重锤的玩家不能破坏方块。
* 击中生物前，玩家<ref></ref>的摔落高度越大，造成的伤害越高。
* * 如果成功击中目标，则会抵消累积的摔落伤害，并会击退目标周围的其他实体。
* 具有250点[耐久度](耐久度.md)，可以在[铁砧](铁砧.md)上使用旋风棒修复。
* 在非创造模式下无法添加魔咒。<ref></ref>

* *[旗帜图案](旗帜图案.md)**
* 加入了涡流和旋风2种旗帜图案。
* * 可从试炼密室的宝库获得。

* *[锻造模板](锻造模板.md)**
* 加入了镶铆和涡流2种盔甲纹饰锻造模板。
* * 可从试炼密室的宝库获得。
* * 镶铆盔甲纹饰锻造模板可使用[铜块](铜块.md)复制。
* * 涡流盔甲纹饰锻造模板可使用[旋风棒](旋风棒.md)复制。

* *[陶片](陶片.md)**
* 加入了涡流、旋风和刮削3种纹样陶片。
* * 试炼密室中会生成带有这些纹样的[饰纹陶罐](饰纹陶罐.md)。

* 将其战利品表拆分为<code>reward_common</code>（普通）、<code>reward_rare</code>（稀有）和<code>reward_unique</code>（独有）。

* * 从战利品表中移除了[马铠](马铠.md)和[鞍](鞍.md)。
