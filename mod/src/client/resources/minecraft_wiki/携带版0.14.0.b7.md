# 携带版0.14.0.b7

*页面ID: 20045* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.14.0 alpha build 7**是[v0.14.0 alpha](携带版0.14.0.md)的第7个测试版，发布于2016年2月12日<ref>http://pocketbeta.minecraft.net/2016/02/changelog-for-014-build-7.html</ref>，加入了新的[皮肤包](皮肤包.md)，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[皮肤](皮肤.md)**
* 加入了[红石专家皮肤包](皮肤包#红石专家皮肤包.md)。

# 更改
# = 物品 =
* *[地图](地图.md)**
* 将[地图](地图.md)初始尺寸改回1:1，避免[物品展示框](物品展示框.md)中放置地图变得无意义。

# 修复
* *修复了7个漏洞**
* 修复了村民没有职业的崩溃。
* 修正了进入下界和物品展示框中的地图之间的交互导致的崩溃。
* 修复了当大箱子的第二部分在箱子打开时被破坏导致的崩溃。
* 修正了大箱子物品重复的问题。
* 运输矿车可以再次打开。
* 多人游戏中船实际生成在玩家面前。
* 运输矿车中的物品不再重复或丢失。</onlyinclude>
