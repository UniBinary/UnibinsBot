* *1.5.0**是**[水域更新](水域更新.md)**第二阶段的首个正式版，也是[基岩版](基岩版.md)的一次主要更新，发布于2018年7月10日。此次更新加入了水域更新第一阶段（[1.4.0](基岩版1.4.0.md)）中未增加的特性，如[海龟](海龟.md)和[潮涌核心](潮涌核心.md)，并修复了一些漏洞。<ref>https://twitch.tv/videos/261329927</ref><ref></ref>

# 新内容
# = 方块 =
* *[潮涌核心](潮涌核心.md)**
* 通过使用1个海洋之心和8个鹦鹉螺壳合成。
* 激活后给予玩家[潮涌能量](潮涌能量.md)效果。
* 像[生物头颅](生物头颅.md)一样有16种朝向。

* *[气泡柱](气泡柱.md)**
* 自然生成于海洋生物群系，或者[海底废墟](海底废墟.md)里。
* 默认情况下，它将显示为一个透明的完整方块，低端设备可以使用它。
* * 可以让它看起来与[Java版](Java版.md)的外观相似。

* *[海龟蛋](海龟蛋.md)**
* 一个方块最多包含4个海龟蛋。
* 用于孵化幼年[海龟](海龟.md)。
* 亡灵生物会主动踩踏和破坏海龟蛋。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了[海龟](海龟.md)刷怪蛋。

* *[鳞甲](鳞甲.md)**
* 幼年海龟成年后掉落1个鳞甲。

* *[海龟壳](海龟壳.md)**
* 合成配方：

* 可作为头盔佩带，当玩家没有沉入水底时，会持续给予玩家10秒[水下呼吸](水下呼吸（状态效果）.md)效果。
* 可作为酿造材料，酿造[神龟药水](神龟药水.md)。

* *[药水](药水.md)**
* [神龟药水](神龟药水.md)

* *[药箭](药箭.md)**
* [神龟之箭](神龟之箭.md)

# = 生物 =
* *[海龟](海龟.md)**
* 是一种水生生物，能在岸上产下海龟蛋。
* 可使用[海草](海草.md)繁殖。
* 生成在温暖的生物群系。
* 可在[沙滩](沙滩.md)上产卵。
* 死后掉落0-2海草。
* 与其有关的物品英文名都叫“Sea Turtles”而不是“Turtle”。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
*
* * 给予玩家水下呼吸、夜视和急迫效果。

* *[成就](成就.md)**
* 更多的成就，其中包括：
* * 做一个桶滚动作 - 使用[激流](激流.md)给自己加速 (30G)
* * 一个海泡菜，两个海泡菜，海泡菜，四个 - 在一个组中放置四个[海泡菜](海泡菜.md) (20G)
* * 回声定位 - 对一只[海豚](海豚.md)进行喂食来让它将您引向宝藏 (20G)
* * 默斯肯漩涡 - 激活一个[潮涌核心](潮涌核心.md) (50G)

# 更改
# = 方块 =
* *[蓝冰](蓝冰.md)**
* 变得更滑。

* *[珊瑚块](珊瑚块.md)**
* 只要有一面接触到水就不会死亡。

* *[海带](海带.md)**
* 更改了[海带](海带.md)顶部的纹理。

# = 物品 =
* *[鹦鹉螺壳](鹦鹉螺壳.md)**
* 不再属于[实验性玩法](实验性玩法.md)。

* *[三叉戟](三叉戟.md)**
* 现在可以附魔经验修补和耐久。
* 加入了使用激流[魔咒](魔咒.md)时在第一人称模式下的动画。
* 在创造模式下不能再破坏方块。
* 更新了激流的旋转纹理。

* *[熟鳕鱼](熟鳕鱼.md)**
* 更新了熟鳕鱼的纹理。

# = 生物 =
* *所有亡灵生物**
* 现在会潜入水中并在底部走动。

* *[尸壳](尸壳.md)**
* 沉入水中会变成[僵尸](僵尸.md)。

* *[僵尸](僵尸.md)**
* 沉入水中会变成[溺尸](溺尸.md)。

* *[骷髅马](骷髅马.md)**
* 可以在水下骑乘。

* *[骷髅](骷髅.md)和[流浪者](流浪者.md)**
* 在水下时会切换成近战攻击，离开水时会切换回远程攻击。

* *[海豚](海豚.md)**
* 被给予生鳕鱼或生鲑鱼后会游到最近的海底废墟或沉船。

* *[溺尸](溺尸.md)**
* 现在有概率携带一个鹦鹉螺壳生成。
* 不再属于[实验性玩法](实验性玩法.md)。

# = 非生物实体 =
* *[船](船.md)**
* 更改了使用键鼠控制船只的转向方式，按向前移动，向后移动。

# = 世界生成 =
* *[海底峡谷](峡谷.md)**
* 生成于[海底峡谷](峡谷.md)的[岩浆块](岩浆块.md)现在会自然产生[气泡柱](气泡柱.md)。

# = 常规 =
* *[全景图](全景图.md)**
* 更新为水域更新全景图。

* *[设置](设置.md)**
* 默认视野从70°减少到60°，可以在设置-视频中进行调整。
* 将主界面的设置按钮和商店按钮移动到彼此下方。
* 新的弹出窗口来询问你是否喜欢[Minecraft](Minecraft.md)。

* *[市场](市场.md)**
* 库存按钮移至市场页面的顶部。

# 修复
* *修复了120个漏洞**<br>
* *崩溃/性能**
* 修复了游戏进行时出现的崩溃现象。
* 生成世界时，暂停游戏使得游戏崩溃。
* 活塞推动方块时游戏崩溃。
* 游玩Truffletop Town地图时，使用鞘翅和烟花火箭飞行时游戏崩溃。
* 使用Oculus Rift或VR设备在市场中搜索时游戏崩溃。
* 改进了末影龙的攻击时出现的粒子效果。
* 安卓设备下，靠近海底神殿会损失性能。（）

* *常规**
* 从生存模式切换为创造模式后，个人游戏模式不会随之切换。
* 在对按键重新映射后，首次鼠标点击现在可以正常运作。
* 移除资源包后重新进入世界时，玩家会继承世界主人的出生地和物品栏信息。
* 玩家不能加入此前加入过另一个世界的玩家的世界。
* 暂停游戏然后更改资料后，控制器断开连接。
* “信任玩家等级”选项更改后无法保存。
* Xbox One平台下无法正确同步世界的保存状态、
* 没有Xbox Live会员身份的玩家无法加入本地局域网世界。
* 在Realms里恢复备份内容或替换世界时，资源包和行为包不能正常启用或禁用。
* Xbox One平台下游戏规则不会正确转换。
* “漂流者”成就会提前完成。
