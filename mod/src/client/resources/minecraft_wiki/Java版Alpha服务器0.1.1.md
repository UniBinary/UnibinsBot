# Java版Alpha服务器0.1.1

*页面ID: 45472* | *来源: Minecraft Wiki*

* *0.1.1**是[Alpha](Java版Alpha.md)的服务器版本，与[客户端Alpha v1.0.16](Java版Alpha v1.0.16.md)对应，发布于2010年8月12日。<ref name="blogpost"></ref>

# 新内容
# = 命令格式 =
* 加入了和，用于封禁或解封某个玩家。
* 加入了和，用于封禁或解封某个IP。
* 加入了和，用于给予或移除玩家管理员身份。

# = 常规 =
* 为在线服务器加入了在线验证（正版验证）。
* * 服务器现在可以以两种模式启动：在线/安全模式或离线/不安全模式。安全的服务器（开启在线验证的服务器）要求所有连接到该服务器的玩家在进入服务器之前，先在[minecraft.net](minecraft.net.md)上完成验证，然后再检查验证是否匹配。而关闭以后服务器将不会作出任何检查，也不会要求客户端进行验证，但是无法确认玩家的身份是否与其ID对应。离线模式是为了局域网连接而设计的，即开启服务器的人知道连接到服务器的人的身份。
* 加入了玩家管理员，可以执行服务器命令。
* * 管理员也可以在[出生点区块](出生点区块.md)附近放置或摧毁方块。

# 更改
* 服务器保存地图的频率更加频繁了。
