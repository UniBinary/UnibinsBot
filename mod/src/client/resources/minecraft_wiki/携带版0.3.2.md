# 携带版0.3.2

*页面ID: 21250* | *来源: Minecraft Wiki*

* *v0.3.2 alpha**是[携带版](携带版.md)的一个次要更新，发布于2012年7月16日<ref>https://web.archive.org/web/20120717115310/http://itunes.apple.com/us/app/minecraft-pocket-edition/id479516143?mt=8</ref><ref>http://web.archive.org/web/20120803220009/https://play.google.com/store/apps/details?id=com.mojang.minecraftpe</ref>，加入了[熔炉](熔炉.md)，[金](金.md)、[铁](铁.md)、[钻石](钻石.md)质材料以及其他更改与修复。<ref> （注：1.和2.是关于MINECON的，3.是关于携带版的）</ref>

# 新内容
# = 方块 =
* *[熔炉](熔炉.md)**
* 用于熔炼[方块](方块.md)和[物品](物品.md)的存储方块。
* 能够用[圆石](圆石.md)合成。

* *[树苗](树苗.md)**
* 可以长成它们对应种类的[树](树.md)的非固体[方块](方块.md)。
* 有概率会在[树叶](树叶.md)破损或腐烂时掉落。

* *[玻璃板](玻璃板.md)**
* 透明的[方块](方块.md)，可以用作[玻璃](玻璃.md)的较为有效的替代品。
* 能够用[玻璃](玻璃.md)合成。

* *[箱子](箱子.md)**
* 没有功能。
* 目前还无法获得。
* 无法合并成大型箱子。

# = 物品 =
* *[金锭](金锭.md)**
* 通过烧炼[金矿石](金矿石.md)获得。
* 能够合成[金块](金块.md)或[金质工具](金质工具.md)。

* *[铁锭](铁锭.md)**
* 通过烧炼[铁矿石](铁矿石.md)获得。
* 能够合成[铁块](铁块.md)、[剪刀](剪刀.md)或[铁质工具](铁质工具.md)。

* *[钻石](钻石.md)**
* 通过使用[铁镐](铁镐.md)或更好的镐的挖掘[钻石矿石](钻石矿石.md)获得。
* 能够合成[钻石块](钻石块.md)或[钻石质工具](钻石质工具.md)。

* *钻石、金和铁质的[镐](镐.md)、[锹](锹.md)、[斧](斧.md)、[剑](剑.md)**
# = 游戏玩法 =
* *[烧炼](烧炼.md)**
* 一种获得制成物品的方法。
* 通过[熔炉](熔炉.md)完成。

# 更改
# = 方块 =
* *[树叶](树叶.md)**
* 现在有概率会在被破坏时掉落[树苗](树苗.md)。

* *[黏土](黏土.md)**
* 现在被破坏时会掉落4个[黏土球](黏土球.md)。

* *[青金石块](青金石块.md)**
* 现在能够合成[青金石](青金石.md)。

# = 物品 =
* *[红砖](红砖.md)**
* 现在能够合成[红砖块](红砖块.md)。

* *[黏土球](黏土球.md)**
* 现在能够合成[黏土](黏土.md)。

* *[青金石](青金石.md)**
* 现在能够合成[青金石块](青金石块.md)。

# = 游戏玩法 =
* *[生存](生存.md)**
* 所有可用的方块和物品现在都可以通过收集、合成或[烧炼](烧炼.md)得到。
* 玩家不再随着无限堆叠的[剪刀](剪刀.md)、[红砖](红砖.md)和[玻璃](玻璃.md)生成。

* *[创造模式物品栏](创造模式物品栏.md)**
* 新增：
* * [圆石台阶](圆石台阶.md)
* * [玻璃板](玻璃板.md)
* * [云杉树叶](云杉树叶.md)
* * [白桦树叶](白桦树叶.md)
* * [青金石块](青金石块.md)
* * [熔炉](熔炉.md)
* * [煤矿石](煤矿石.md)
* * [铁矿石](铁矿石.md)
* * [金矿石](金矿石.md)
* * [钻石矿石](钻石矿石.md)
* * [青金石矿石](青金石矿石.md)

# 修复
* *修复了5个漏洞**
* 在某些设备上的闪烁/拼接更少了。
* 拿着1个物品或方块时不再显示“1”。
* 生物现在有正确的生命值了。
* 修复了手中的栅栏门和台阶的渲染。
* 当使用剪刀剪云杉和白桦树叶时不再会掉落有错误的方块。

# 你知道吗
v0.3.1 alpha似乎并不存在，版本号从0.3.0直接跳到了0.3.2。由于0.3.0的第二次重新发布增加了功能，而非像大多数其他重新发布一样只解决了崩溃问题，所以其可能会被追溯为0.3.1。
