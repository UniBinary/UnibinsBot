# 穿透

*页面ID: 39112* | *来源: Minecraft Wiki*

* *穿透（Piercing）**是一种用于[弩](弩.md)的[魔咒](魔咒.md)，可使射出的[箭](箭.md)击穿多个[实体](实体.md)。

# 获取

# 用途
穿透可使弩射出的箭（包括光灵箭和药箭）击穿多个[实体](实体.md)，可击穿的实体数量和魔咒等级相同（即最多可对<code>-{}-*等级* + 1</code>个实体造成伤害）。但当等级超过127级时，射出的箭将无法击穿实体。箭击穿实体后仍可以被捡起。穿透箭也会击穿玩家的盾牌，但仍然会被闭合外壳的[潜影贝](潜影贝.md)弹开。

穿透魔咒不能使[烟花火箭](烟花火箭.md)击穿实体。

穿透与[多重射击](多重射击.md)被应用在同一个物品上时，由多重射击额外产生的箭也会被应用穿透数。
