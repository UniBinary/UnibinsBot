# Java版Beta 1.5

*页面ID: 32754* | *来源: Minecraft Wiki*

<onlyinclude>
* *Beta 1.5**是的一次主要更新，发布于2011年4月19日，加入了完善的[统计](统计.md)和[成就](成就/Java版.md)功能、新的变种[铁轨](铁轨.md)以及[树苗](树苗.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[白桦树苗](白桦树苗.md)**
* 可以长成[白桦树](白桦树.md)。

* *[蜘蛛网](蜘蛛网.md)**
* 暂时只能通过编辑[物品栏](物品栏.md)获得。

* *[探测铁轨](探测铁轨.md)**
* 一种功能类似于[压力板](压力板.md)的[铁轨](铁轨.md)。

* *[动力铁轨](动力铁轨.md)**
* 一种能使[矿车](矿车.md)加速或停止的铁轨。

* *[云杉树苗](云杉树苗.md)**
* 可以长成[云杉树](云杉树.md)。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 当被雷电击中时成为闪电苦力怕，并且会增大爆炸的威力。

* *[猪](猪.md)**
* 当被雷电击中时成为[僵尸猪人](僵尸猪人.md)。

# = 游戏内容 =
* *[成就](成就/Java版.md)**
* 现在可以在存档间同步。

* *[天气](天气.md)**
* 加入了[降雨](降雨.md)、[降雪](降雪.md)和[雷暴](雷暴.md)。

# = 常规 =
* *[控制](控制.md)**
* 打开容器后使用可以将该物品进行快速转移。

* *[设置](设置.md)**
* 允许修改GUI大小（小、中、大、自动）。
* 提升了OpenGL的性能（遮挡剔除：不对玩家视野外的方块进行渲染，在显卡支持的情况下会提升表现）。

* *[统计信息](统计信息.md)**
* 现在可以在存档间同步。

# 更改
# = 方块 =
* *[哭泣的黑曜石](哭泣的黑曜石.md)**
* 从游戏内移除了纹理。

* *[草方块](草方块.md)**
* 现在当图像品质为“高品质”时，草方块顶部和侧面具有草的部分的颜色相同，但图像品质为“流畅”时仍然使用此前的模型。

* *[梯子](梯子.md)**
* 现在合成配方一次提供2个梯子，以弥补修复的梯子间隔放置仍能在其上正常上下移动的漏洞。

* *[树苗](树苗.md)**
* 现在可作为[熔炉](熔炉.md)的燃料。
* * 与[木棍](木棍.md)的燃烧时间相同。

* *[红石粉](红石粉.md)**
* 现在可以在[雪块](雪块.md)上放置。

# = 物品 =
* *常规**
* 丢到流动的[水](水.md)中的物品被冲走的速度比之前更快。

# = 生物 =
* *[猪](猪.md)**
* 被烧死时掉落[熟猪排](熟猪排.md)。

* *[狼](狼.md)**
* 现在更加常见，即使不在[针叶林](针叶林.md)或[森林](森林.md)生物群系。

* *[玩家](玩家.md)**
* 空手伤害从改为。

# = 世界生成 =
* *白桦树叶和云杉树叶**
* 现在它们会分别掉落[白桦树苗](白桦树苗.md)和[云杉树苗](云杉树苗.md)。

# = 常规 =
* *[控制](控制.md)**
* 按下可切换输入框。
* 不能再使用+来创建36450×17700分辨率的截图。

# 修复
* *修复了15个漏洞**
* 现在只有玩家的下半身在梯子上时，才判定玩家“在梯子上”（可以向上攀爬和缓慢下降），而不是以前玩家的任意身体部位都可以。
* * 现在不再能爬上有间隔放置的梯子和从玩家眼睛高度开始的梯子。
* 在高画质下，草方块侧边草的颜色会随群系变化而变化，与其顶部的色调相匹配。
* 玩家穿过水时的移动速度更改为以前的速度。
* 狼的寻路算法现在能更好的处理门的影响。大多数时候它们会直接穿过门，但有时它们会卡在3像素厚的门上。
* 修复了使用平滑光照时下界传送门以及冰的光照计算问题。
* 台阶不再对光透明。
* 现在在多人游戏中，狼的生命值会在服务端和客户端之间同步，使得狼只会在生命值较低时哀鸣，不再会一直哀鸣。
* 未充能状态的红石粉现在改回了红色。
* 修复了树苗长大后可能会突破世界建筑高度限制的漏洞。
* 被水冲毁的小麦作物现在会掉落种子和小麦，不像以前一样只掉落小麦。
* 世界关闭时，移动中的矿车不再能继续运动。
* 当客户端窗口最大化时，Mojang的徽标是正确的大小。
* 修复了通过放置水源并将箱子放置在水源中可以使箱子并排三个或更多个的漏洞。
* 按+键不再能创建巨大的.tga屏幕截图。
* 甘蔗现在不能放置在除泥土以外的方块上。</onlyinclude>
