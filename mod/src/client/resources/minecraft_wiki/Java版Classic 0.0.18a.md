# Java版Classic 0.0.18a

*页面ID: 35380* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.18a**是的一次更新，发布于2009年6月13日<ref>[6月13日的IRC日志](#0613日志.md): "*P4:59:57 * Notch changes topic to 'http://www.minecraft.net/  |  http://www.minecraft.net/skin/  |  Client 0.0.18a is up with skin support'<nowiki/>*" (21:59:57 UTC)</ref>，加入了命令和自定义[皮肤](皮肤.md)。

# 新内容
# = 游戏内容 =
* *[皮肤](皮肤.md)**
* 加入了自定义皮肤的功能。<ref>[6月13日的IRC日志](#0613日志.md)：*P5:03:05 <Notch> only paying customers can upload new skins*</ref></onlyinclude>

# = 命令格式 =
* *<ref>[6月14日的IRC日志](#0614日志.md)：“*A5:57:41 <Notch> there is a teleport command in the new server. =)*”、“*A5:57:48 <Notch> /teleport <name>*”（10:57 UTC）</ref><ref>[6月13日的IRC日志](#0613日志.md)：“*A8:31:14 <checkers> does it need a new client?*”、“*A8:31:22 <Notch> no*”、“*A8:31:32 <Notch> well, the /teleport command does, so you can't use that yet*”（13:31 UTC）</ref>**
* 用于传送玩家到其他玩家所在位置。
