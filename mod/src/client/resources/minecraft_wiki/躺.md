# 躺

*页面ID: 47804* | *来源: Minecraft Wiki*

<div style='float:right'></div>
* *躺（Lying）**是一种可以由[玩家](玩家.md)或其他一些生物在睡觉等情况下做出的动作。

# 机制
# = 玩家 =
玩家可以在使用[床](床.md)时躺下，而目前这也是能够使玩家做出此动作的唯一方式。与动作[坐](坐.md)不同的是，玩家躺下时无法自主移动，也不能使用物品。

含水的床无法使用，但玩家带有水下呼吸或潮涌能量时能够使用含水的床。躺下的玩家不会因为床含水而停止躺下。

# = 猫 =
<div style='float:right'></div>[猫](猫.md)会在其主人在床上睡觉时躺在该床上并入睡。此时猫会还发出咕噜声。

# = 狐狸 =
<div style='float:right'></div>
[狐狸](狐狸.md)偶尔会在白天寻找有方块遮挡的地方并躺下睡觉。狐狸睡觉时，其上方必须要有方块遮挡。如果正在睡觉的狐狸因上方的遮荫方块被破坏而受阳光直射，它将会立即醒来，然后尝试寻找其他适合睡觉的地方。

# = 熊猫 =
[150px|right](File:Lying Lazy Panda.png.md)
懒惰的[熊猫](熊猫.md)偶尔会仰面朝天地躺在地上。但与其他生物不同的是，这只是一种被动行为，与睡觉无关。

=== 村民 ===
[村民](村民.md)在晚上会尝试走近自己认领的床并躺下。玩家可以将村民推下床、通过或来唤醒村民。
