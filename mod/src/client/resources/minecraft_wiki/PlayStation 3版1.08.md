# PlayStation 3版1.08

*页面ID: 83041* | *来源: Minecraft Wiki*

* *1.08**是[PlayStation 3版](PlayStation 3版.md)的一次更新，发布于2014年9月18日。

# 新内容
# = 常规 =
* *[纹理包](纹理包.md)**
* 加入Fantasy纹理包。
* 加入Cartoon纹理包。
* *[皮肤包](皮肤包.md)**
* 加入皮肤包3。

# 修复
* *修复了3个漏洞**
* 修复了玩家可以破坏基岩的漏洞。
* 修复了玩家可以像治疗僵尸村民一样治疗僵尸猪人的漏洞。
* 修复了玩家乘船或矿车时有时不被较远的玩家所看见的漏洞。
