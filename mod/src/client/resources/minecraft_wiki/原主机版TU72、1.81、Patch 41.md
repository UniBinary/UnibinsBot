# 原主机版TU72、1.81、Patch 41

*页面ID: 62286* | *来源: Minecraft Wiki*

* *TU72/1.81/Patch 41**是[原主机版](原主机版.md)的一次更新，发布于2018年10月31日至11月14日期间，修复了一些漏洞。<ref></ref>

# 修复
* *修复了7个漏洞**
* PS3：修复草方块侧面的错误颜色显示。
* PS3：修复末地没有音乐的漏洞。
* PS3和PSV：修复在Tumble游戏中公共游戏选项显示灰色。
* 修复了当黏性活塞移动附着在另一个黏性活塞上的黏液块时客户端玩家可能发生的崩溃。
* 修复玩家自动跳跃不能带在水中的漏洞。
* 修复玩家在矿车中的头部旋转。
* 修复在海底神殿中不能生成守卫者的漏洞。
