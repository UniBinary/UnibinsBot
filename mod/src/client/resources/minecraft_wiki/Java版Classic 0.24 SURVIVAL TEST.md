# Java版Classic 0.24 SURVIVAL TEST

*页面ID: 35537* | *来源: Minecraft Wiki*

/开发者版本}}
<onlyinclude>

* *0.24_SURVIVAL_TEST**是[生存测试](生存测试.md)的首个版本，也是的一次更新，发布于2009年9月1日<ref></ref><ref>[IRC记录](#logs.md): "*A11:54:53 <08Notch> http://www.minecraft.net/survivaltest/*" (16:54:53 UTC)</ref><ref name="creeper"></ref>，加入了[生存模式](生存模式.md)，[箭](箭.md)、[告示牌](告示牌.md)等实体和[苦力怕](苦力怕.md)、[猪](猪.md)、[骷髅](骷髅.md)、[僵尸](僵尸.md)等生物。

# 新内容
# = 非生物实体 =
* *[箭](箭.md)**
* 按下发射。
* * 消耗7支箭可以杀死一个[生物](生物.md)。每支箭造成伤害。

* *[告示牌](告示牌.md)<ref></ref>**
* 通过按下生成。
* 告示牌上的文本总是“This is a test of the signs. Each line can be 15 chars!（这是测试文本，每行最多可以有15个字！）”且无法被编辑。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 一种敌对生物，通过近战攻击[玩家](玩家.md)。
* 会自然生成在世界中。
* 攻击力为至，死亡后爆炸造成最多的伤害。
* 外观比正常更黑。
* * 攻击时恢复正常。
* 玩家杀死后会给予250点分数。

* *[猪](猪.md)**
* 一种友好生物。
* 会自然生成在世界中。
* 玩家杀死后会给予10点分数。

* *[骷髅](骷髅.md)**
* 一种敌对生物，通过近战攻击[玩家](玩家.md)。
* 会自然生成在世界中。
* 攻击力为至。
* 玩家杀死后会给予100点分数。

* *[僵尸](僵尸.md)**
* 一种敌对生物，通过近战攻击[玩家](玩家.md)。
* 会自然生成在世界中。
* 攻击力为至。
* 玩家杀死后会被给予100点分数。

# = 游戏内容 =
* *[生存模式](生存模式.md)**
* 一种拥有[生命值](生命值.md)，且只能使用有限方块的[游戏模式](游戏模式.md)。
* 生命值为零后玩家就会死亡，只能新建世界来重新游戏。

* *[暂停菜单](暂停菜单.md)**
* “生成新世界”下，地图大小的选项间距减小。

* *分数**
* 只有在玩家死亡后才可看到。

* *[盔甲](盔甲.md)**
* 没有保护作用。
* 仅会在僵尸或骷髅生成时随机穿戴头盔或胸甲。

# = 常规 =
* *[粒子](粒子.md)**
* 重新为树苗加入了粒子，尽管现在比之前颜色更深。

* *[选项](选项.md)**
* 加入了视角摇晃选项。
* 加入了3D效果选项。

# 更改
# = 方块 =
* *[水](水.md)和[熔岩](熔岩.md)**
* 不再能流动。

# = 物品 =
* *[蘑菇](蘑菇.md)**
* 食用[棕色蘑菇](棕色蘑菇.md)会回复。
* 食用[红色蘑菇](红色蘑菇.md)会造成伤害。
* 蘑菇在黑暗中不再会消失。

* *[树苗](树苗.md)**
* 当放置在[草方块](草方块.md)上且有足够空间时可以生长成[树](树.md)。

# = 生物 =
* *常规**
* 生物和玩家受伤后会向后跳并闪白色光，且拥有了死亡动画。
* 敌人死亡后会倒下。

* *[人类](生物（已移除实体）.md)**
* 不再能够通过按下键生成。
* 更改了纹理。
* 更改了AI系统，现在的行为与之前略有不同。

* *[玩家](玩家.md)**
* 将玩家的头发纹理移至外层。

# = 游戏内容 =
* *[游戏模式](游戏模式.md)**
* 移除了[创造模式](创造模式.md)。

* *[轮廓箱](轮廓箱.md)**
* 移除了选中方块时的白色框。
* * 因此在黑暗中选择[树苗](树苗.md)和[花](花.md)不再会使其消失。

# = 世界生成 =
* *常规**
* 更新了地图生成器。
* * 更多的悬崖。
* * 更为狭长的洞穴。
* ** 越靠近世界底部，洞穴越大。
* * 基岩层上方会生成一层[熔岩](熔岩.md)。<ref>[IRC记录](#logs.md): "*P1:23:30 <Drakim> yeah, guys, the bottom is all lava*"</ref>

# = 常规 =
* *[控制](控制.md)**
* 右键单击放置[方块](方块.md)，左键单击破坏方块。
* 现在又可以自动跳跃了。
* 玩家在跳跃和下落时视角会上下晃动。
* 玩家的可触及范围缩短了1个方块。

* *其他**
* 更快的渲染速度。</onlyinclude>
