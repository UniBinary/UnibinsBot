* *马铃薯芽（Potato Bud）**是一种类似于[滴水石锥](滴水石锥.md)的[方块](方块.md)。

# 生成
# = 自然生成 =
马铃薯芽自然生成在[腐败区](腐败区.md)生物群系中。

# = 生长 =
马铃薯芽会生成马铃薯芽。

# 获取
马铃薯芽只能通过破坏马铃薯芽获得。

# 破坏
挖掘马铃薯芽的合适工具是[剑](剑.md)。

马铃薯芽被破坏后会掉落自身。

# 用途

马铃薯芽的生长速度远快于滴水石锥，且最高可生长至25格。

马铃薯芽只能附着于[马铃薯泥土](马铃薯泥土.md)、[薯皮草方块](薯皮草方块.md)、[腐败的薯皮草方块](腐败的薯皮草方块.md)和[马铃砂](马铃砂.md)。

# = 堆肥 =
将马铃薯芽放入[堆肥桶](堆肥桶.md)有30%的概率使堆肥层数增加1。
