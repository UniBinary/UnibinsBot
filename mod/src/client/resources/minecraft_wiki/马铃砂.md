* *马铃砂（Gravtater）**是马铃薯维度常见的类似[沙子](沙子.md)的方块。

# 生成
# = 自然生成 =
马铃砂主要在[薯饼](薯饼（生物群系）.md)生物群系的表面大量生成。同时也会以[团簇](团簇.md)的形式生成于整个马铃薯维度，类似于[沙砾](沙砾.md)在主世界的生成方式。

# 获取

[流浪商人](流浪商人.md)有概率出售马铃砂（以[琥珀宝石](琥珀宝石.md)替代[绿宝石](绿宝石.md)，马铃砂替代[沙子](沙子.md)）。

# 破坏
挖掘马铃砂的合适工具是锹。

马铃砂被破坏后会掉落自身。

# 用途
马铃砂与沙子的部分用途相似。

# = 下落的方块 =

马铃砂在下方没有不可替代的方块时会变为[下落的方块](下落的方块.md)。

马铃砂在没有得到支撑时，会在方块下方产生[粒子](粒子.md)。
