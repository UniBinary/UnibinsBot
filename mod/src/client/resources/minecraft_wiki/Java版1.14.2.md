# Java版1.14.2

*页面ID: 43166* | *来源: Minecraft Wiki*

* *1.14.2**是的一次次要更新，发布于2019年5月27日<ref></ref>，加入了更多字体，并修复了一些漏洞。此版本不兼容1.14和1.14.1的服务端。

# 新内容
# = 常规 =
* *[字体](字体.md)**
* 加入了默认的越南文字体。
* 更改了默认亚美尼亚文字体中的一个字符。
* 加入了默认的希伯来语和亚美尼亚语字体中缺少的字形。
* 在默认字体中添加了符文字母。

# 更改
# = 方块 =
* *[营火](营火.md)**
* 含水的[营火](营火.md)不再能被着火的[箭](箭.md)点燃。
* *[潜影盒](潜影盒.md)**
* 空的潜影盒在创造模式下被破坏时，不会再掉落其自身。

# = 生物 =
* *[鹦鹉](鹦鹉.md)**
* 不再生成在[草丛](草丛.md)上，而是生成在[草方块](草方块.md)上。

# = 游戏内容 =
* *[袭击](袭击.md)**
* 袭击生物现在只生成在完全加载的[区块](区块.md)中。

* *[光照](光照.md)**
* 现在首次打开以前版本保存的世界时会重新计算光照。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 现在包含服务器端的区块数量。

* *错误信息**
* 加载区域时遇到的错误现在会在日志文件中输出更多诊断信息了。

* *[闪烁标语](闪烁标语.md)**
* 移除了“Woo, minecraftforum!”（正如论坛所宣布的那样，它将很快被存档。）
