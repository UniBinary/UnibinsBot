# 雕纹树脂砖块

*页面ID: 128239* | *来源: Minecraft Wiki*

* *雕纹树脂砖块（Chiseled Resin Bricks）**是[树脂砖块](树脂砖块.md)制作的装饰性方块，每个面都有着[嘎枝](嘎枝.md)图案。

# 生成
雕纹树脂砖块不会生成在世界中。

# 破坏
挖掘雕纹树脂砖块的合适工具是镐。雕纹树脂砖块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

雕纹树脂砖块被破坏后会掉落自身。

# 用途
雕纹树脂砖块目前仅用于装饰。
