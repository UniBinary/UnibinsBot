# Java版19w07a

*页面ID: 39885* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w07a**是[Java版1.14](Java版1.14.md)的第21个快照，发布于2019年2月13日<ref></ref>，加入了狐狸及其刷怪蛋和剩下3种僵尸村庄，并修复了一些漏洞。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了狐狸刷怪蛋。

# = 生物 =
* *[狐狸](狐狸.md)**
* 一种夜间生物，在白天睡觉，晚上活动。
* 被杀死时不掉落任何东西。
* 会远离玩家。
* * 速度与[豹猫](豹猫.md)一样快。
* 可以用[甜浆果](甜浆果.md)使其繁殖。
* * 新生的小狐狸信任且不会远离玩家。
* 生成时能叼着物品，例如[小麦](小麦.md)和[皮革](皮革.md)。
* * 会用嘴叼起掉落物，在找到食物时会丢弃。
* 会在村庄周围生成，并四处游走。
* 会攻击[鸡](鸡.md)、[兔子](兔子.md)、[鱼](鱼.md)与幼年[海龟](海龟.md)。
* * 能跳得很高，并可以跨越栅栏内攻击[鸡](鸡.md)。
* * 即使[鸡](鸡.md)离狐狸有一定距离，狐狸也会跳起攻击它们。
* 会被未驯服的[狼](狼.md)攻击，但跑得更快。
* 睡觉时会蜷缩起来。
* 在会生成白色变种。
* 普通狐狸会优先攻击鸡和兔子，而白色变种狐狸会优先攻击鱼和幼年海龟。

# = 世界生成 =
* *[僵尸村庄](村庄#僵尸村庄.md)**
* 加入了剩下的3种僵尸村庄：热带草原、平原和积雪的冻原僵尸村庄。

# 更改
# = 方块 =
* *[木桶](木桶.md)**
* 加入了方块状态。
* * 打开木桶时会出现新的纹理。

# = 非生物实体 =
* *[画](画.md)**
* 画现在被分解为单独的纹理。
* * 支持动态纹理。

# = 世界生成 =
* *[村庄](村庄.md)**
* 带有铁盔甲的[盔甲架](盔甲架.md)现在可以在[针叶林](针叶林.md)村庄里生成。
* 向缺少光照的热带草原、平原和沙漠村庄中加入了一些[火把](火把.md)。
* 为村庄的渔夫小屋加入了[战利品表](战利品表.md)，位于小屋内的[木桶](木桶.md)内。

# = 常规 =
* *[复述功能](复述功能.md)**
* 复述功能会复述鼠标指针悬停的按钮（不包括[进度](进度.md)）。
* *启动界面**
* 标题现在可用资源包自定义。
