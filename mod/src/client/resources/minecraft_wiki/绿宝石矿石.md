# 绿宝石矿石

*页面ID: 8069* | *来源: Minecraft Wiki*

* *绿宝石矿石（Emerald Ore）**是一种只会生成于[风袭丘陵](风袭丘陵.md)类和[山地](山地.md)类生物群系的[矿石](矿石.md)方块，开采后会掉落[绿宝石](绿宝石.md)。

* *深层绿宝石矿石（Deepslate Emerald Ore）**是以[深板岩](深板岩.md)作为容矿岩的绿宝石矿石变种。

# 生成
# = 自然生成 =
绿宝石矿石只在[风袭丘陵](风袭丘陵.md)、[风袭森林](风袭森林.md)、[风袭沙砾丘陵](风袭沙砾丘陵.md)、[草甸](草甸.md)、[樱花树林](樱花树林.md)、[雪林](雪林.md)、[积雪山坡](积雪山坡.md)、[尖峭山峰](尖峭山峰.md)、[冰封山峰](冰封山峰.md)和[裸岩山峰](裸岩山峰.md)生物群系中以[矿团](矿团.md)形式生成，在取代[深板岩](深板岩.md)或[凝灰岩](凝灰岩.md)生成时会生成为深层变种。

大小为1-3方块的矿团于高度Y=-16至320处在每个[区块](区块.md)中最多尝试生成100次，且在Y=232处达到最大值，在范围边缘处达到最小值。

# 获取
绿宝石矿石和深层绿宝石矿石只能通过破坏对应方块获得。

# 破坏
挖掘绿宝石矿石和深层绿宝石矿石的合适工具是镐。绿宝石矿石和深层绿宝石矿石需要铁镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，绿宝石矿石和深层绿宝石矿石被破坏后会掉落1个[绿宝石](绿宝石.md)和，挖掘工具的[时运](时运.md)魔咒会增加绿宝石的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，绿宝石矿石和深层绿宝石矿石被破坏后会掉落自身。

# 用途
# = 烧炼配方 =

# = 山羊冲撞 =
[山羊](山羊.md)在冲撞浅层绿宝石矿石时会掉落[山羊角](山羊角.md)。
