# 再生药水

*页面ID: 180978* | *来源: Minecraft Wiki*

* *再生药水**是提供[生命恢复](生命恢复.md)状态效果的[药水效果](药水效果.md)。

该药水效果可以制成[药水](药水.md)**再生药水（Potion of Regeneration）**、[喷溅药水](喷溅药水.md)**喷溅型再生药水（Splash Potion of Regeneration）**、[滞留药水](滞留药水.md)**滞留型再生药水（Lingering Potion of Regeneration）**和[藥水箭](藥水箭.md)**再生之箭（Arrow of Regeneration）**。

此药水效果有对应的延长版和增强版。

# 生成
# = 生物 =
[女巫](女巫.md)会对生命值高于的[灾厄村民](灾厄村民.md)或[劫掠兽](劫掠兽.md)投掷喷溅型再生药水。

# = 箱子战利品 =

由于药水的最大堆叠数量为1，数量大于1的堆叠会被展开为对应数量的单个物品堆叠。

# = 交易 =

# = 礼物 =

[制箭师](制箭师.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷再生之箭。

# = 炼药锅 =

对装有再生药水的炼药锅使用[玻璃瓶](玻璃瓶.md)可获得再生药水、喷溅型再生药水或滞留型再生药水，具体形式取决于炼药锅内容物。

对装有再生药水的炼药锅使用[箭](箭.md)可获取再生之箭，最大数量随内容物水位增加依次为16、32和64。
