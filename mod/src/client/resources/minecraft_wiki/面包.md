* *面包（Bread）**是一种常见的[食物](食物.md)类[物品](物品.md)。

# 获取
# = 合成 =

# = 箱子战利品 =

# = 交易 =

# = 村民 =
农民村民会把它们收割的[小麦](小麦.md)合成为面包并丢给其他村民。

# = 礼物 =

[农民](农民.md)可能会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷面包。

# 用途
# = 食物 =

手持面包按住键即可食用，每个面包可以回复。

# = 村民 =

村民获得至少3个面包后会有“意愿”繁殖。有多余面包的村民会将面包丢给其他村民。

# = 堆肥 =
将面包放入[堆肥桶](堆肥桶.md)中有85%的概率使堆肥层数增加1。
