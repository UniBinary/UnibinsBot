# 定位栏

*页面ID: 149448* | *来源: Minecraft Wiki*

* *定位栏（Locator Bar）**用于显示其他玩家的粗略方位。

# 显示
[thumb|class=pixel-image|生存模式的定位栏](File:Survival Locator Bar.png.md)
游戏规则为时，如果世界中存在非自身且不是自身正在骑乘的生物的路径点，玩家的动作栏下方位置会显示定位栏。

生存模式或冒险模式的玩家如果[经验值](经验值.md)发生了变化，或关闭了[铁砧](铁砧.md)、[附魔台](附魔台.md)界面，则游戏会暂时隐藏定位栏以显示[经验条](经验条.md)。正在使用[铁砧](铁砧.md)或[附魔台](附魔台.md)时定位栏也会被经验条代替。<!--基岩版开GUI会隐藏背景里的HUD-->骑乘生物时，如果该生物有“蓄力”机制（如[马](马.md)、[驴](驴.md)、[骡](骡.md)、[骆驼](骆驼.md)等），定位栏会代替蓄力条显示，而蓄力条只在不为空（玩家按下蓄力、蓄力后的、骆驼的冲刺冷却）时显示。

[thumb|class=pixel-image|玩家远离样式为的路径点目标时路径点图标的变化情况](File:Locator Bar Style Change.gif.md)
与玩家连线和玩家视线夹角在30°内，即玩家正前方60°内的路径点会在定位栏中用有色的点状指示器标记。玩家俯仰角偏离路径点达到垂直视场角度数的一半时，路径点的纵向位置超出屏幕显示的范围，指示器上/下方便会显示垂直指向路径点的不断跳动的箭头。

随着距离（本段中距离指路径点所在方块中心与玩家的[欧几里得距离](欧几里得距离.md)）逐渐增大，指示器的图标会逐级变小。样式的路径点图标共有4级，在距离增加到或时，图标会变小一级；样式的路径点图标在前者的首端插入了一个形似领结的图标，因此共有5级，在距离增加到64格、153.33格、242.66格、332格时，图标会变小一级。这些距离均在其范围内[线性插值](wzh:线性插值.md)分布。

默认情况下，指示器颜色将被随机分配。若某个实体处于[队伍](队伍.md)内，且队伍具有指定的颜色，则重新加载后此生物的图标颜色为队伍的颜色。

[潜行](潜行.md)、戴上[生物头颅](生物头颅.md)或[雕刻南瓜](雕刻南瓜.md)或带有[隐身](隐身.md)状态效果的玩家的指示器不会显示在其他玩家的定位栏中。代表旁观模式玩家的指示器不会显示在非[旁观模式](旁观模式.md)玩家的定位栏中。

当接受者的小于源的时，源的指示器不会显示在接受者的定位栏中；但这两个属性不会影响指示器图标样式变小时二者的距离。所有玩家的这两个属性默认值都为，即通常情况下玩家的路径点不会随距离增加而消失。

# 路径点
* *路径点（Waypoint）**用于构建连接，以将生物位置和路径点颜色等设置投射到玩家定位栏中。使用命令可以列出或更改路径点。

路径点随生物移动而实时更新。

[路径点样式](路径点样式.md)会影响该路径点显示的图标纹理。游戏内置有两种路径点样式：和。所有生物都默认使用前者，后者只能使用命令得到。[资源包](资源包.md)可以更改或添加路径点样式。

只有玩家会创建和更新路径点。不为0的生物可以创建和更新路径点，但因为除玩家外的生物该属性值都为0，默认情况下只有玩家会创建和更新路径点。

潜行的玩家，戴上生物头颅或雕刻南瓜、或带有隐身状态效果的生物会直接移除对应的路径点。
