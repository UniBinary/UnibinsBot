# 霜冰

*页面ID: 18623* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *霜冰（Frosted ice）**是[水](水.md)被[冰霜行者](冰霜行者.md)魔咒转化而生成的方块。

# 生成
霜冰不会生成在世界中。

# = 冰霜行者 =
穿着带有[冰霜行者](冰霜行者.md)魔咒的盔甲的生物在行走时会将附近的[水](水.md)变为霜冰。

冰霜行者不能替换[含水](含水.md)方块。若水里有可推动实体，或水上方有方块阻挡，霜冰将不会生成。

# 获取
霜冰没有对应的物品形式。

霜冰的物品形式不能在生存模式中正常获得。其亦不存在于[创造模式物品栏](创造模式物品栏.md)中，但可以通过使用[命令](命令.md)等方法获得。

# 破坏
没有工具可以加速对霜冰的挖掘。<ref></ref>

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，霜冰被破坏后不会掉落，并且在下界由[环境属性](环境属性.md)<code>gameplay/water_evaporates</code>控制。}}以外的维度中会变成[水](水.md)。

被具有精准采集的工具挖掘破坏时，霜冰被破坏后仍不会掉落，但不会变成水。<ref></ref><ref></ref><ref></ref>

# 用途
霜冰有着和[冰](冰.md)和[浮冰](浮冰.md)一样的滑动阻力系数，可以让实体在上面滑行。

霜冰在生成后会开始迅速融化。每一个霜冰有一个方块数据，起始为0。末地方块光照等级或其他维度的[内部天空光照](内部天空光照.md)等级至少为时，每过1-2秒若某个霜冰周围有至少4个的霜冰，则该霜冰有的概率使增加1，否则直接增加1。如果为3，即将增加为4，则霜冰会变为水，且与其相邻的霜冰的增加1。

由于霜冰需要亮度才能开始融化，在黑暗的环境如夜晚的河流或洞穴中，霜冰不会融化。

当一个霜冰融化或被破坏时，若与其相邻的霜冰不超过1个则也会立刻融化。

[甘蔗](甘蔗.md)可以种在霜冰旁边，[睡莲](睡莲.md)可以放置于霜冰上，因此霜冰替换掉这些方块依赖的水时不会将其破坏。

霜冰在下界融化仍然会变为水。
