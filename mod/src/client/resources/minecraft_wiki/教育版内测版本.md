# 教育版内测版本

*页面ID: 34388* | *来源: Minecraft Wiki*

<onlyinclude>

* *教育版内测版本（Education Edition early access）**是的开发版本。<ref>https://www.mojang.com/2016/06/minecraft-education-edition-early-access-is-now-available/</ref><ref>https://education.minecraft.net/blog/announcing-early-access/</ref>其中，**0.14.2**发布于2016年6月28日，**0.16.0**发布于2016年10月2日。

# 特性
# = 常规 =
; [课堂模式](课堂模式.md)
* 支持简单、安全的登录方式。
* * 学生与教师的个人登录功能，可识别游戏内每位玩家身份，并在游玩[教育版](教育版.md)时保障数据的私密性与安全性。
* * 支持单点登录（SSO）功能，无需额外设置密码或创建账户。
