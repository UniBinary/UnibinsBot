# Java版Classic 0.0.23a 01（重制）

*页面ID: 43165* | *来源: Minecraft Wiki*

}}

为了庆祝Minecraft十周年，一份用JavaScript重制的**[Classic 0.0.23a_01](Java版Classic 0.0.23a 01.md)**被上传到了Minecraft网站（使用了Babylon.js库），在网站上被称为**Minecraft Classic**。该版本可在[classic.minecraft.net](https://classic.minecraft.net)在线游玩。<ref name="classic.minecraft.net"></ref>在Minecraft十五周年之际，其入口被上传至位于Minecraft官方网站的十五周年专题页中。

# 特性
[缩略图|有着所有可用方块的物品栏](File:0.0.23a 01 (remake) inventory.png.md)

# = 方块 =

# = 生物 =
* *[人类](生物（已移除实体）.md)**
* 按键生成。
* 可以穿过[世界界限](世界界限.md)并掉入界限外的海洋中。
* 只出现在客户端，不会在[多人游戏](多人游戏.md)中显示给其他玩家。
* 模型存在问题，由于其头部向下平移了四个像素，腿部向上平移了四个像素，导致其看起来有些矮小。
* 由玩家生成的人类会在1分钟后消失。

# = 世界生成 =
* *地形**
* 生成带有山和湖的地形，地面下有小型洞穴。

* *[生成结构](生成结构.md)**
* [树](树.md)，由[原木](原木.md)和[树叶](树叶.md)组成。
* 即使刷新网页，游戏也会记录并保存由玩家放置的方块和其位置。

# = 游戏内容 =
* *[方块](方块.md)**
* 可放置和破坏方块；通过按键切换这两种模式。

* *[多人游戏](多人游戏.md)**
* 最多可与9名玩家同时进行游戏，但因性能问题，该功能已于2019年5月8日暂停使用。<ref></ref>

* *[物品栏](物品栏.md)**
* 默认按键打开。
* 可找到并选择除[煤矿石](煤矿石.md)、[铁矿石](铁矿石.md)、[金矿石](金矿石.md)、[水](水.md)与[熔岩](熔岩.md)以外的所有方块。

* *[音乐](音乐.md)**
* Calm1、Calm2和Calm3三首音乐会随机播放。一首音乐结束后，下一首大约会在5分钟后开始播放。

# = 世界生成 =
* *[世界大小](Indev世界选项#世界大小.md)**
* 共有三种世界大小：小型（Small）、普通型（Normal）和大型（Huge）。
* * 小型世界大小为128×128，普通型世界大小为256×256，大型世界大小为512×512。

# = 常规 =
* 2D的[云](云.md)。
