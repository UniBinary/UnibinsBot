# 雕纹深板岩

*页面ID: 99472* | *来源: Minecraft Wiki*

* *雕纹深板岩（Chiseled Deepslate）**是[深板岩圆石](深板岩圆石.md)制作的装饰性方块。

# 生成
# = 自然生成 =
雕纹深板岩自然生成于[远古城市](远古城市.md)中。

# 破坏
挖掘雕纹深板岩的合适工具是镐。

雕纹深板岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

雕纹深板岩被破坏后会掉落自身。

# 用途
雕纹深板岩目前仅用于装饰。
