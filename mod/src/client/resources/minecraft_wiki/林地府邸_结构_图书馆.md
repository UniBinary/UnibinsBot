# 林地府邸/结构/图书馆

*页面ID: 98244* | *来源: Minecraft Wiki*

<noinclude></noinclude>
; 小型图书馆
所有深色橡木楼梯都是朝内倒置的。

此结构的技术性名称为“1x1_b4”。

; 中型图书馆
在此结构底部中间的橡木楼梯是朝外倒置的；顶部的橡木楼梯是朝内倒置的。

此结构的技术性名称为“1x2_c4”。
