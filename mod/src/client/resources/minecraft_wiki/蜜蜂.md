* *蜜蜂（Bee）**是居住在[蜂巢](蜂巢（方块）.md)或[蜂箱](蜂箱.md)的友好生物，但会在被激怒后成群结队地反击。

# 生成
每个自然生成的蜂巢都容纳着3只蜜蜂。

若、白桦或樱花[树苗](树苗.md)水平2格范围内存在[花](花.md)，则该树苗长成的树会有5%的概率悬挂着蜂巢；即使周围不存在花，橡树树苗长成的树也有5%的概率悬挂着蜂巢<ref></ref>；红树胎生苗长成的红树也有/的概率悬挂着蜂巢。每个由此生成的蜂巢都会容纳1-3只蜜蜂。

# 掉落物
成年蜜蜂在被[玩家](玩家.md)或驯服的[狼](狼.md)杀死时会掉落。

与其他幼年动物一样，杀死幼年蜜蜂不会掉落任何经验。

# 行为
无论是否被激怒，蜜蜂都可以被[拴绳](拴绳.md)牵引。但即使被拴绳牵引，它们仍会尝试进行攻击。

蜜蜂通常会在其栖息的蜂巢周围22个方块以内的位置寻找能采集花粉的植物或需要攻击的对象。

蜜蜂在飞行路径上会尽量远离[水](水.md)，它们在水中会立即受到伤害。

虽然蜜蜂在雨天不会因为雨水而受伤，但蜜蜂也会因为雨天或阴天而停止外出，即便是在不下雨的沙漠地区。

蜜蜂在[甜浆果丛](甜浆果丛.md)中移动时不会受到伤害和。

# = 采粉、授粉和产蜜 =

[thumb|中蜜蜂采集花粉](File:Bee Pollinating.gif.md)
在白天，蜜蜂们会陆续离开它们的[巢](蜂巢（方块）.md)。它们会在巢的周围飞行，且会受到花（闭合的眼眸花、除外）、盛开的杜鹃花丛、盛开的杜鹃树叶、[樱花树叶](樱花树叶.md)、、[粉红色花簇](粉红色花簇.md)、[野花簇](野花簇.md)、[仙人掌花](仙人掌花.md)和红树胎生苗的吸引。蜜蜂会在花朵上或以采集花粉。花粉采集完成后，蜜蜂尾部的纹理会看起来沾满花粉，同时蜜蜂身上会产生花粉粒子。

蜜蜂对张开的眼眸花采粉时会获得1.25秒的[中毒](中毒.md)效果，对凋灵玫瑰采粉时会获得2秒的[凋零](凋零.md)效果。且蜜蜂不会尝试接触闭合的眼眸花和。蜜蜂只会对[向日葵](向日葵.md)的上半部（花盘）采粉。蜜蜂会在[含雪](含雪.md)的花附近徘徊，但无法采集成功。

已有巢且采集了花粉的蜜蜂有概率给它们飞过的[小麦植株](小麦植株.md)、[火把花植株](火把花植株.md)、[瓶子草植株](瓶子草植株.md)、[马铃薯植株](马铃薯植株.md)、[胡萝卜植株](胡萝卜植株.md)、[甜菜植株](甜菜植株.md)、[西瓜茎](西瓜茎.md)、[南瓜茎](南瓜茎.md)、[甜浆果丛](甜浆果丛.md)和[洞穴藤蔓](洞穴藤蔓.md)授粉。[作物](作物.md)经授粉后会直接进入下一生长阶段，其效果与使用[骨粉](骨粉.md)相似。每只蜜蜂每次采集花粉后，都最多可以给作物进行10次授粉，而每两次授粉间又都有一段较短的冷却时间。

采集花粉后，蜜蜂会飞回它所在的蜂巢或蜂箱内产蜜约2分钟，随后蜜蜂可以离巢，且该巢的会增加1。当蜂巢的达到5时，其纹理表现为充满蜂蜜的状态，且会向下滴落蜂蜜粒子。玩家此时可从中收集蜜脾或蜂蜜瓶。

# = 栖息 =
蜜蜂通常会群居，并且会将任何尚未住满的蜂巢或蜂箱认作自己的栖息地。每个蜂巢或蜂箱最多容纳3只蜜蜂。尚未认领任何栖息地的蜜蜂会四处游荡，以寻找可供居住的蜂巢。蜜蜂可以从蜂巢的任意一面进入，但只能从正面出去，并且不能有方块阻挡。

蜜蜂会在夜间或[下雨](下雨.md)时归巢休息，即使在[沙漠](沙漠.md)等并不会下雨的生物群系中也会如此。而在[下界](下界.md)和[末地](末地.md)这样没有[昼夜更替](昼夜更替.md)和天气变化的维度当中蜜蜂不会休息。离巢前，每只蜜蜂都会在巢内停留至少。蜜蜂完成归巢和离巢的流程后，其数据（如名称、[生命值](生命值.md)等）保持不变。

破坏容纳着蜜蜂的蜂巢会将其中的蜜蜂以敌对状态全部放出，而使用带有[精准采集](精准采集.md)魔咒的工具采集蜂巢可以将其中的蜜蜂（包括其对应的数据值）和该巢一同取走。将该巢摆放出来，即可让其中的蜜蜂重新出巢。

蜜蜂会立即离开着[火](火.md)的蜂巢，并且也不会认领或试图进入任意着火的蜂巢。

# = 攻击 =

[right](File:Bee stings.gif.md)

蜜蜂会反击对其造成伤害的任何生物（[山羊](山羊.md)和[恶魂](恶魂.md)除外），附近所有不在巢内的蜜蜂都会被激怒并反击该生物，除非这个蜜蜂被生物一击杀死。

如果蜂巢被破坏，其中所有的蜜蜂都会以被激怒的状态释出，且附近所有不在巢内的蜜蜂都会被激怒。因蜂巢被破坏而被激怒的蜜蜂会无差别地攻击任何玩家，即使这个玩家并没有参与对蜂巢的破坏。若使用带有精准采集魔咒的工具挖掘蜂巢，该巢内的蜜蜂会随巢被采下而不会被释出，且不会激怒附近不在巢内的蜜蜂。

从为5的蜂巢或蜂箱中收集[蜂蜜瓶](蜂蜜瓶.md)或[蜜脾](蜜脾.md)也会使其中的蜜蜂在激怒状态下被弹出，但可以通过在蜂巢或蜂箱正下方6格内放置[营火](营火.md)或[灵魂营火](灵魂营火.md)（二者之间不能有其他方块阻挡），或在蜂巢或蜂箱周围的方块点火使蜜蜂逃离蜂巢或蜂箱，以此避免激怒它们。

和野生的[狼](狼.md)一样，蜜蜂被激怒时眼睛会变为红色，并成群结队地涌向目标展开攻击。被激怒的蜜蜂在完成攻击或一定时间内未能成功攻击到目标时会恢复未激怒的状态。

如果目标使用[盾牌](盾牌.md)阻挡蜜蜂的攻击，它会持续攻击，直到它成功攻击到目标，而它攻击一段时间后会恢复未激怒的状态。

被激怒且带有针的蜜蜂与目标距离缩短至2格以内时，会向前翻转半圈作出准备螫刺的姿态，期间其他行为保持正常。蜜蜂会在目标移动至2格以外或解除激怒状态后恢复正常飞行姿势。

蜜蜂的攻击在普通难度下会额外造成10秒[中毒](中毒.md)I，在困难难度下会额外造成18秒中毒I。

在和平难度下，蜜蜂受击后不会被激怒；和平难度下破坏蜜蜂的巢或采蜜虽然会激怒蜜蜂，但它们无法成功攻击玩家。

<div style="float:right"></div>

蜜蜂在**攻击成功**后会失去它的螫针，此后将无法进行攻击。失去螫针的蜜蜂的行为与正常蜜蜂不同：漫无目的地急躁飞行，不会回巢，不会主动繁殖。在失去螫针后，系统将以为周期尝试伤害蜜蜂，尝试成功的概率<math>P = \frac{1}{\operatorname{clamp}(1200 - t, 1, 1200)}</math>{{note|<math>\operatorname{clamp}(x, min, max) = \begin{cases} min, & x < min \\ max, & x > max \\ x, & min \leq x \leq max \end{cases}</math>}}，每次伤害的大小等于蜜蜂现在的生命值，也就是说，没有任何[状态效果](状态效果.md)的蜜蜂将在失去螫针后的内死亡。

失去螫针的蜜蜂可以被重新激怒，尽管它们无法再次攻击。

蜜蜂攻击玩家后失去的螫针会转移到玩家身上，在一段时间后消失。

在足够快的情况下，有可能让一只愤怒的蜜蜂与其他蜜蜂繁殖，哪怕那只蜜蜂（或者两只都）失去了螫针。繁殖完毕以后，它们依然保持愤怒，在一段时间后依然会由于失去螫针而死亡。

# = 生物族群 =

蜜蜂是[节肢生物](生物#节肢生物.md)，被具有[节肢杀手](节肢杀手.md)魔咒的武器近战攻击时会受到额外的伤害并被施加数秒的[](缓慢.md)IV效果。

# = 繁殖 =

蜜蜂会跟随/手持花（闭合的眼眸花、除外）、盛开的杜鹃花丛、盛开的杜鹃树叶、樱花树叶、、粉红色花簇、野花簇、仙人掌花或红树胎生苗的玩家。如果玩家站着不动，跟随的蜜蜂会飞到该玩家身边，然后面对玩家在玩家周围停驻，直到玩家再次移动。

玩家可以对蜜蜂上述物品以喂食蜜蜂。喂食凋灵玫瑰会使蜜蜂获得或的[凋零](凋零.md)效果，喂食张开的眼眸花会使蜜蜂获得或的[中毒](中毒.md)效果，喂食其他物品（下文称为合适的食物）则会[繁殖](繁殖.md)蜜蜂或加速幼年蜜蜂的成长。

如果对2只成年蜜蜂喂食合适的食物，它们会进入繁殖模式并结对交配，生出一只幼年蜜蜂，并掉落。繁殖后，蜜蜂双亲在/之内不能再次繁殖。繁殖出的幼年蜜蜂会在20分钟（1[游戏日](游戏日.md)）后长大。

对幼年蜜蜂喂食合适的食物可以加速其成长，每次使用可以减少约10%的剩余生长时间。

对幼年蜜蜂[金蒲公英](金蒲公英.md)可以阻止其成长为成年蜜蜂，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年蜜蜂无法被喂食除金蒲公英外的其他物品。

与愤怒的狼不同，蜜蜂被激怒时仍然可以繁殖。
