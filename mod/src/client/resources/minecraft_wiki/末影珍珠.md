# 末影珍珠

*页面ID: 6180* | *来源: Minecraft Wiki*

* *末影珍珠（Ender Pearl）**是一种可以投掷以传送使用-{}-者的物品。

* *掷出的末影珍珠（Thrown Ender Pearl）**是一种可以传送投掷者的弹射物。

# 获取
# = 生物掉落物 =

# = 箱子战利品 =

# == 林地府邸 ==
[林地府邸](林地府邸.md)的[伪末地传送门房间](林地府邸#伪末地传送门房.md)内总是会生成1个[陷阱箱](陷阱箱.md)，当中总有2个末影珍珠。

# = 交易 =

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家2-4个末影珍珠。

# 用途
# = 投掷 =
末影珍珠可以将其投掷出去，生成弹射物，并引发的末影珍珠物品冷却时间，期间受影响玩家不可使用末影珍珠。

末影珍珠被垂直往上扔时，能竖直向上穿越约30格。末影珍珠被以40&deg;角扔出时，能水平向前穿越最远，约52格或92格。

# = 合成材料 =

# 行为
掷出的末影珍珠是一种[弹射物](弹射物.md)，可以触发[标靶](标靶.md)。

掷出的末影珍珠会受到重力影响和环境阻力的影响。

掷出的末影珍珠会在掷出该珍珠的玩家下线时移除，并在玩家上线时重新在原位置生成。

# = 着火 =
掷出的末影珍珠可以[着火](着火.md)。掷出的末影珍珠在穿过[火](火.md)或[熔岩](熔岩.md)会着火，穿过[雨](雨.md)或[水](水.md)时会熄灭。

着火的掷出的末影珍珠会不受阻碍地穿过[TNT](TNT.md)并使其激活，可以点燃熄灭的[营火](营火.md)，可以破坏其穿过的[细雪](细雪.md)。

# = 造成伤害 =
掷出的末影珍珠在直接击中实体时，会对其造成伤害。该伤害可以产生击退。虽然不能对大多数生物的生命值造成影响，生物仍然会将其视为一种攻击行为并做出相应的反应。

和[末影龙](末影龙.md)的受伤害行为使其免疫掷出的末影珍珠造成的伤害。

# = 传送实体 =
掷出的末影珍珠击中物体并破裂后，会将投掷者传送到其破裂位置并在这一位置生成许多聚拢的[紫色粒子](粒子#portal.md)，同时对被传送的玩家造成摔落伤害。穿戴具有[保护](保护.md)或[摔落缓冲](摔落缓冲.md)魔咒的盔甲能减少掷出的末影珍珠造成的伤害。

通过掷出的末影珍珠传送只会伤害玩家，使用掷出的末影珍珠传送任何其他实体均不会使其受到伤害。

当掷出的末影珍珠把玩家传送到高度不足1.5格的空隙中时，玩家会进入[爬行](爬行.md)状态。

被[虚空](虚空.md)摧毁的掷出的末影珍珠不会传送实体。

若掷出的末影珍珠被丢入[末地折跃门方块](末地折跃门方块.md)，那么这些方块传送实体的功能会直接对投掷者激活，并移除掷出的末影珍珠，而不会产生摔落伤害或其他效果。

若玩家投掷了一个掷出的末影珍珠，并在掷出的末影珍珠着陆前死亡，则掷出的末影珍珠会消失，且玩家不会被传送；[游戏规则](游戏规则.md)设为时，掷出的末影珍珠不会消失。该掷出的末影珍珠也不会消失。

末影珍珠以特定位置、角度和速度下击中物体时不会破裂（亦不会传送实体），同时可以被该物体改变其动量。

# = 与方块交互 =
掷出的末影珍珠可以触发其击中的[标靶](标靶.md)，可以敲响[钟](钟.md)。

掷出的末影珍珠可以激活[木质压力板](木质压力板.md)和[绊线](绊线.md)。当掷出的末影珍珠穿过这些方块时，这些开关会保持开启状态。其他开关则不受掷出的末影珍珠的影响。

# = 加载区块 =

由玩家掷出的末影珍珠会在其所在区块放置一个基础加载等级为31的[加载标签](区块#标签.md)，以保持其所在区块被强加载，从而维持末影珍珠的运动。当掷出的末影珍珠移动到其他区块或其他维度时，会在相应位置放置新的加载标签。

# 你知道吗
* 通过贴在方块上并不断地向玩家的脚部使用末影珍珠可以让玩家穿过非[固体方块](固体方块.md)。
* 可以使用命令生成抛出的末影珍珠，但它只会显示一个末影珍珠网格并立即消失。
* 如果使用命令生成抛出的末影珍珠并修改它的标签为一个实体的UUID，那么它将会传送那个实体。
* 如果一次性投掷多个末影珍珠，玩家在一秒的时段内只会受到一次摔落伤害，这是因为[受击后伤害免疫](受击后伤害免疫.md)机制。
* 末影珍珠的投掷是有随机偏差的，即使朝同一个方向投掷多个末影珍珠，它们的抛物线也是不同的。
