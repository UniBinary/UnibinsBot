# 教育版1.21.01.0

*页面ID: 122309* | *来源: Minecraft Wiki*

<onlyinclude>

* *Preview 1.21.01.0**（Android/ChromeOS/Windows）、**beta 1.21.01.0**（iOS/iPadOS/macOS/Windows）是[教育版1.21.03](教育版1.21.03.md)的第4个预览版、首个测试版，在iOS/iPadOS平台上发布于2024年6月13日，在其他平台上发布于2024年6月18日<ref></ref><ref></ref>，加入了[犰甲狼兵](犰甲狼兵.md)和[棘巧试炼](棘巧试炼.md)的特性。

# 新内容

* 加入了[犰甲狼兵](犰甲狼兵.md)和[棘巧试炼](棘巧试炼.md)的特性。

# 更改
# = 游戏内容 =
* *[创造模式物品栏](创造模式物品栏.md)**
* [气球](气球.md)和[荧光棒](荧光棒.md)等[化学](化学.md)相关物品现在会出现在创造模式物品栏中。

# = 常规 =
* *[主菜单](主菜单.md)**
* 将“管理帐户”按钮移动至屏幕右下角。

* *其他**
* 更新了相机API。

# 修复
* 优化了游戏的性能与稳定性。</onlyinclude>
