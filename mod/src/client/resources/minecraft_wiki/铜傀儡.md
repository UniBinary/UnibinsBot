* *铜傀儡（Copper Golem）**是一种可以帮助玩家将[铜箱子](铜箱子.md)的物品分类到普通[箱子](箱子.md)或[陷阱箱](陷阱箱.md)的友好生物。

# 生成
# = 建造 =
|铜傀儡的一种建造方法}}
|铜傀儡的另一种建造方法}}
将[雕刻南瓜](雕刻南瓜.md)或[南瓜灯](南瓜灯.md)放置在[铜块](铜块.md)的任意一面（如图所示），铜傀儡就会在放置雕刻南瓜或南瓜灯的位置上生成。由此生成的铜傀儡的氧化程度与铜块相同。生成铜傀儡后，铜块会转变为对应的[铜箱子](铜箱子.md)。使用[涂蜡的铜块](涂蜡的铜块.md)生成铜傀儡时，铜傀儡不会被涂蜡。<ref></ref><ref></ref>

雕刻南瓜或南瓜灯必须最后放置。雕刻南瓜可以被[末影人](末影人.md)和[发射器](发射器.md)放置。南瓜灯也能被发射器放置。放置[南瓜](南瓜.md)不能生成铜傀儡，但用[剪刀](剪刀.md)修剪后可以生成。

# == 更新区域 ==

|用平滑石头标出的更新区域（上方是北）}}
当已存在一个完整的铜傀儡结构，但由于放置顺序不正确而没有生成铜傀儡时，玩家能在特定区域再放置一个雕刻南瓜或南瓜灯来“更新”结构生成铜傀儡。更新区域的具体范围如图所示。

若发射器周围有完整的铜傀儡结构或是一个铜块，且发射器面对的位置在更新区域内，发射器就能将雕刻南瓜放置在面前，即使这样做可能无法生成铜傀儡。

# = 铜傀儡像 =
对未涂蜡且未氧化的[铜傀儡像](铜傀儡像.md)使用[斧](斧.md)会生成铜傀儡。

# 行为
空闲状态下的铜傀儡会漫无目的地四处游荡，并会避开熔岩、悬崖等危险环境。在水中，铜傀儡会沉入水底，但仍然能够在水下自由移动。

铜傀儡免疫[摔落伤害](摔落伤害.md)，但仍会避免从高处跌下。

铜傀儡能够开关[木门](木门.md)和[铜门](铜门.md)。

铜傀儡可以走上1格高的方块而无需跳跃。

铜傀儡的眼睛拥有发亮的纹理，在暗处也清楚可见，但不会影响周围方块的实际[亮度](亮度.md)。

# = 分类物品 =
[thumb|200px|铜傀儡从[[铜箱子](File:Copper golem take item BE1.gif.md)中收集物品]]
未手持物品时，铜傀儡会尝试搜寻并打开最近的[铜箱子](铜箱子.md)，从中收集物品并拿在手上，每次最多可以收集16个相同物品。若找到的铜箱子是空的，铜傀儡会将其记住并搜寻下一个未记住的铜箱子。

接著，铜傀儡会尝试搜寻并打开最近的普通[箱子](箱子.md)或[陷阱箱](陷阱箱.md)，将手持的物品放入其中。。这个箱子或陷阱箱必须是空的，或包含与其手持物品完全相同的物品（包括名称和耐久度与其手持物品不同的同种物品）。若箱子或陷阱箱不满足条件或无法放入物品，铜傀儡会将其记住并搜寻下一个未记住的箱子或陷阱箱。铜傀儡无法与向上超过1格或向下超过2格的箱子或陷阱箱交互。

铜傀儡每次交互的耗时为3秒。如果容器无法打开（如[猫](猫.md)坐在箱子上或容器被破坏等），铜傀儡会将此位置标记为已访问并搜寻下一个目标。铜傀儡不能打开被其他非玩家实体打开的容器。

铜傀儡会按顺序记住最多10个种类相同的容器。如果300秒内铜傀儡没有找到任何容器，或在记住10个容器后仍未能找到匹配的容器，则铜傀儡会进入7秒的空闲状态并遗忘所有记住的容器，随后再次进行尝试。

铜傀儡的搜寻范围为自身位置水平方向32格，竖直方向8格，所有物品均可收集。

# = 交互 =
[玩家](玩家.md)与铜傀儡时，铜傀儡会掉落其手持物品。

# = 彩蛋 =
[缩略图|铁傀儡和头上插有虞美人的铜傀儡](File:CopperGolemFlower.png.md)

[铁傀儡](铁傀儡.md)有概率把[虞美人](虞美人.md)插到铜傀儡的头上。

对铜傀儡[剪刀](剪刀.md)会剪去其头上的虞美人，同时掉落1个虞美人。

虞美人也会在铜傀儡转变为铜傀儡像或死亡时掉落。

# = 氧化 =
铜傀儡存在未氧化、斑驳、锈蚀和氧化四个氧化阶段。铜傀儡的氧化计时受游戏时间影响，每隔至，铜傀儡会进入下一氧化阶段。

不同氧化阶段的铜傀儡纹理不同：斑驳阶段会先变色并出现绿色斑点；锈蚀阶段全身变为绿色且带有棕色斑点；氧化阶段则全身呈蓝绿色，带有几个绿色斑点。

处于氧化阶段且未涂蜡的铜傀儡每刻有0.58%的概率完全氧化并转变为[氧化的铜傀儡像](氧化的铜傀儡像.md)。若所在位置非空气，铜傀儡不会尝试转变。转变后，铜傀儡会以随机姿势保持静止，掉落手持物品。

铜傀儡转变成氧化的铜傀儡像后，自定义名字会保留到方块实体数据中，并在挖掘破坏后会保留，但其他实体数据会被丢弃。

铜傀儡转变成氧化的铜傀儡像后，会保留转变前通过[命名牌](命名牌.md)获得的名字。

[雷击](闪电束.md)和[斧](斧.md)可降低铜傀儡的氧化阶段。对其[蜜脾](蜜脾.md)可涂蜡，以防止继续氧化。与铜质方块不同，为铜傀儡涂蜡或脱蜡不会获得“”或“”[进度](进度.md)。<ref></ref><ref></ref>

# 你知道吗
* 资源文件中存在锈蚀或氧化状态的铜傀儡的特殊动画，但目前它们使用与普通的铜傀儡相同的动画。
* 铜傀儡在[2022年生物投票服务器活动](2022年生物投票服务器活动.md)、[2023年生物投票服务器活动](2023年生物投票服务器活动.md)和怪异Mojang办公室派对的[活动服务器](活动服务器.md)中作为彩蛋出现。
* 铜傀儡的头顶与[避雷针](避雷针.md)相似，但这仅仅是装饰，并没有实际功能。
* * 在官方公布的初期设计的概念艺术图中可以看出，铜傀儡头顶的部分最初被设计为可以吸引[闪电](闪电.md)，并使铜傀儡在空闲和未激活状态之间转换。<ref>https://www.youtube.com/watch?v=542rY0DQHIM</ref>
