* *石头（Stone）**是在[主世界](主世界.md)中大量存在的方块。

# 生成
# = 自然生成 =
[thumb|[[平原](File:Generated Stone in Plains.png.md)中石头的生成位置]]
在主世界中，石头会在Y=0以上的高度生成。在Y=1到Y=7之间，石头会逐渐向[深板岩](深板岩.md)过渡。在多数生物群系内，[区块](区块.md)生成时会将石头布置在表层的方块（如[草方块](草方块.md)和[泥土](泥土.md)、[沙子](沙子.md)和[砂岩](砂岩.md)等）之下。在有些生物群系，如[山地](山地.md)，还能够看到暴露在外的石头。

石头也会作为[雪屋](雪屋.md)、主世界的[废弃传送门](废弃传送门.md)、[古迹废墟](古迹废墟.md)的一部分以及[试炼密室](试炼密室.md)中生成[蜘蛛](蜘蛛.md)和[洞穴蜘蛛](洞穴蜘蛛.md)的[试炼刷怪笼](试炼刷怪笼.md)旁自然生成。

# = 水与熔岩接触 =
[thumb|简易的石头生成器](File:Stone generator.png.md)

当[熔岩](熔岩.md)从上方流入[水](水.md)时，被流入的水会变成石头。

# 破坏
挖掘石头的合适工具是镐。石头需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，石头被破坏后会掉落1个[圆石](圆石.md)。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，石头被破坏后会掉落自身。

# 用途
# = 蠹虫 =
[蠹虫](蠹虫.md)能进入石头并在石头里隐藏起来，使石头变成[虫蚀石头](虫蚀石头.md)。
