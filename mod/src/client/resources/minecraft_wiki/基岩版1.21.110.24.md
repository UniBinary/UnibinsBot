# 基岩版1.21.110.24

*页面ID: 163211* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.110.24**（ChromeOS/Android）、**Preview 1.21.110.24**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.111](基岩版1.21.111.md)的第4个测试版，发布于2025年8月12日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[铜火把](铜火把.md)**
* 现在合成铜火把时会给予4个，而不是1个。

* *[展示架](展示架.md)**
* 更改了模型，以移除重叠的纹理UV。

# = 生物 =
* *[铜傀儡](铜傀儡.md)**
* 现在使用[剪刀](剪刀.md)剪掉铜傀儡头上的[虞美人](虞美人.md)时会掉落1个虞美人。

# = 常规 =
* *[声音](声音.md)**
* 将的衰减距离更改为12格。
* 将的分类由更改为。

# = 技术性 =
* *命令**
* 修复了命令无法在超平坦世界中正常运作的问题。

* *AI意向**
* 运输物品意向
* * 若为true，现在拥有该意向的生物会在玩家与其目标容器交互时排队等候。

* *[基岩版编辑器](基岩版编辑器.md)**
* 加入了弹窗通知支持。
* * 通过在类中引入新属性和新字段，加入了对弹窗通知的支持。
* * 现在带有弹窗通道的日志消息会在发生错误时在视口中显示为弹窗通知。
* * 字段允许在弹窗中显示额外的上下文信息。
* 加入了一个新设置“显示弹窗通知”。
* * 为设置面板加入了新的复选框设置“显示弹窗通知”。
* * 启用时，除了错误之外，信息和警告消息也会显示为弹窗通知。
* 更新了方块选取器，以在筛选模式为名称时为搜索栏给予输入焦点。
* 修复了启用后仍会保留选区画笔指示器的漏洞。
* 更新了召唤工具，以能够使用 + 鼠标滚轮来旋转实体。
* 更新了一些消息，以使其显示为弹窗通知。

# 修复
* *方块**
* 墙现在不会与绯红菌、诡异菌和竹子相连接。
* 现在对铜傀儡像使用选取方块功能时会获得相同姿势的铜傀儡像。（）
* 修复了铜火把的配方会给予一个铜火把而不是四个的问题。
* 现在只有物品发生变化的展示架会发出方块毗邻更新，如供侦测器侦测。（）

* *生物**
* 铜傀儡现在会在箱子或铜箱子被玩家打开时在旁边排队等候。
* 铜傀儡现在会看向其走向的容器。

* *音效**
* 将不可装备在手上的物品拿在手上时，生物不再会播放装备音效。（）
* 现在铜箱子的关闭音效会与其动画正确同步。（）
* 现在铜箱子的打开和关闭音效最多只能在12格范围内听到。（）
* 现在铜傀儡的音效最多只能在16格范围内听到。（）
* * 铜傀儡更频繁播放的脚步声和旋转音效范围更小，只有12格。

* *物品**
* 现在“Tears”音乐唱片的音效由游戏设置中的“音乐方块”音频滑块控制。（）
* 现在“Lava Chicken”音乐唱片的音效由游戏设置中的“音乐方块”音频滑块控制。（）

* *游戏内容**
* 修复了在对着生物的情况下装备盔甲时会产生“幽灵”复制物品的问题。（）
* 修复了通过命令设置的控制方案在后来激活的相机视角不支持其时不会被保留的问题。自游戏基版本起，此类方案会按预期保持存在，直到通过命令明确清除。
* 修复了熔炉/高炉/烟熏炉的进度条会在没有烧炼进度时卡住的问题。（）

* *编辑器**
* 现在详细结构面板中的复制到剪贴板按钮会在被按下时切换为粘贴预览。
* 现在编辑器中的铅笔能够在场景中放置“对象”。对象是指有意义的Minecraft要素，如床、门、植物等。

* *用户界面**
* 修复了锈蚀的铜块在创造模式物品栏中排序不正确的问题。（）
* 更新了各板块和购买按钮上的Marketplace Pass的V形图标，以使其拥有正确的缩放。
* 调整了市场侧边栏图标的大小，以与图标的适当大小相匹配。
* 调整了库存分类选择图标的大小，以与图标的适当大小相匹配。
* 加入了大小合适的我的游戏库按钮，以供顶栏使用。
* 更改了出现信息灯泡的部分位置，以使用正确的分辨率。
* 更新了市场错误动画，以使其以正确分辨率显示。
* 为促销横幅加入了新图标，以适应UI的像素化样式。

* *图形**
* 修复了展示架的方块破坏纹理会以两倍大小显示的问题。</onlyinclude>
