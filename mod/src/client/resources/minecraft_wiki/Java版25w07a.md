# Java版25w07a

*页面ID: 144754* | *来源: Minecraft Wiki*

<onlyinclude>

* *25w07a**是[Java版1.21.5](Java版1.21.5.md)的第6个快照，发布于2025年2月13日<ref></ref>，将“”的部分特性从[实验性内容](实验性内容.md)中移出，进一步调整了制图师和流浪商人的交易项，更改了绵羊的生成机制，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[标签](Java版标签.md)**
* 加入了方块标签：。
* * 上方可以生成[骆驼](骆驼.md)的方块。

# 更改
# = 方块 =
* *[灌木丛](灌木丛.md)**
* 现在只会在被[剪刀](剪刀.md)或附有[精准采集](精准采集.md)魔咒的工具破坏时掉落。
* 现在可以被方块直接替换。

* *[萤火虫灌木丛](萤火虫灌木丛.md)**
* 降低了[斑块](斑块.md)生成萤火虫灌木丛的概率。
* 对其[骨粉](骨粉.md)时，现在会与灌木丛一样蔓延，而不是掉落自身物品。
* * 同样，如果无法蔓延，骨粉不会消耗。

* *[枯叶堆](枯叶堆.md)**
* 降低了其音效文件（破坏、在上方移动、放置）的音量。

* *[草丛](草丛.md)**
* 降低了其音效文件（挖掘）的音量。

* *[沙子](沙子.md)、[红沙](红沙.md)、所有[陶瓦](陶瓦.md)、[枯萎的灌木](枯萎的灌木.md)、[眼眸花](眼眸花.md)、[苍白垂须](苍白垂须.md)、[矮枯草丛](矮枯草丛.md)和[高枯草丛](高枯草丛.md)**
* 产生的闲置音效分类现在由“方块”改为“环境”。

* *[移动的活塞](移动的活塞.md)**
* 方块实体数据中存储的不再允许指定为空对象。

* *[末地折跃门方块](末地折跃门方块.md)**
* 方块实体数据中的不再在被移除时保留。

* *[熔炉](熔炉.md)、[烟熏炉](烟熏炉.md)和[高炉](高炉.md)**
* 方块实体数据中的不再在被移除时保留。

* *[头颅](头颅.md)**
* 方块实体数据中的不再在被移除时保留。

# = 非生物实体 =
* *[下落的方块](下落的方块.md)**
* 实体数据中的字段现在可以为<code>air</code>，并会导致其立刻消失。
* 现在在未指定或无效时默认为<code>sand</code>。
* 不再允许指定为空对象。

* *[物品展示实体](物品展示实体.md)**
* 现在变换规则的渲染效果与手持时相同。

* *[物品实体](物品实体.md)**
* 在地面上时，模型大小现在会影响悬停运动。
* * 因此，模型大小不会使其卡进下方的方块中。
* 物品堆叠在地面上悬停的位置现在取决于模型大小和模型类型。
* * 模型深度（Z轴）小于方块的时，物品显示为平面堆叠。
* * 否则，模型将渲染为一组从中心全方向偏移的物品。
* * 之前，平面堆叠只在使用父级模型时渲染。
* 实体数据和字段不再在被移除时保留。

* *[被激活的TNT](被激活的TNT.md)**
* 现在在未指定或无效时默认为<code>tnt</code>。
* 不再允许指定为空对象。

* *[潜影弹](潜影弹.md)**
* 和不再在移除时保留。

* *[唤魔者尖牙](唤魔者尖牙.md)、[区域效果云](区域效果云.md)和所有[弹射物](弹射物.md)**
* 实体数据字段不再在被移除时保留。

* *[物品展示框](物品展示框.md)、[荧光物品展示框](荧光物品展示框.md)、[画](画.md)和[拴绳结](拴绳结.md)**
* 、和字段现已合并为字段。

* *[箭类弹射物](弹射物#箭类弹射物.md)**
* 和字段不再在被移除时保留。
* 不再允许指定为空对象。

* *[矿车](矿车.md)及其变种**
* 移除了冗余的字段。
* 已指定的现在会覆盖默认展示的方块状态。
* 不再允许指定为空对象。
* 现在即使没有自定义展示方块状态设置，也可以指定来覆盖默认偏移量。

* *[展示实体](展示实体.md)**
* 字段不再在被移除时保留。
* 方块展示实体的不再允许指定为空对象。
