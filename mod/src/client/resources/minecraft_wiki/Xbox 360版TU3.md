# Xbox 360版TU3

*页面ID: 62948* | *来源: Minecraft Wiki*

* *TU3**是[Xbox 360版](Xbox 360版.md)的一次更新，发布于2012年7月13日。此次更新等价于[Java版Beta 1.7.3](Java版Beta 1.7.3.md)。

# 新内容
# = 方块 =
* *[活塞](活塞.md)**
* 可以被[红石信号](红石信号.md)激活，可推动大多数方块。

* *[黏性活塞](黏性活塞.md)**
* 和普通活塞的功能相同，但当红石信号结束时也能拉回被移动的方块，而普通活塞只会将方块留在原处。

* *[栅栏](栅栏.md)**
* 是一种一般情况下无法跳跃过的墙方块。

# = 物品 =
* *[剪刀](剪刀.md)**
* 可以用来修剪[绵羊](绵羊.md)羊毛和开采一些方块的工具。

# = 常规 =
* *皮肤选择器**
* 加入了皮肤选择器，允许玩家更换默认皮肤或[皮肤包](皮肤包.md)中的皮肤。

* *自动保存**
* 加入了保存文件缓存，以提高显示保存列表的速度。

* *封禁列表**
* 加入了封禁列表功能，允许玩家封禁那些令人不适的内容。

* *教程**
* 在游戏指南中加入了封禁列表章节。

* *[多人游戏](多人游戏.md)**
* 为房主加入了一个选项，可将房间设为仅好友可见。

* *关卡加载屏幕**
* 在加载屏幕中显示世界[种子](种子.md)（需要保存过一次世界才能生效）。

* *加载/保存界面**
* 加入了更多提示与你知道吗内容。

# 更改
# =方块=
* *[TNT](TNT.md)**
* 现在需要使用[打火石](打火石.md)或[红石](红石.md)来触发。

* *[红石](红石.md)**
* 现在可以和[红石中继器](红石中继器.md)连接。

* *[圆石](圆石.md)**
* 更改了纹理。

* *[苔石](苔石.md)**
* 更改了纹理。

* *[矿石](矿石.md)**
* [32px](File:Block of Iron.png.md)在[铁矿石](铁矿石.md)的纹理上加入了棱线。
* 使用了在[Java版1.0.0](Java版1.0.0.md)中更新其他矿石的新纹理。

# = 物品 =
* *[红砖](红砖.md)**
* 更改了纹理。

* *[32px](File:Cooked Porkchop JE2 BE1.png.md)[熟猪排](熟猪排.md)**
* 使用了在[Java版Beta 1.8](Java版Beta 1.8.md)中更新的新纹理。

* *[32px](File:Dispenser.png.md)[发射器](发射器.md)**
* 使用了在[Java版1.2.1](Java版1.2.1.md)中更新的新纹理。

# = 常规 =
* *[光照](光照.md)**
* 改进了光照（从[Java版Beta 1.8.1](Java版Beta 1.8.1.md)向后移植）。

* *[雨](雨.md)**
* 进行了改进。

* *[雪](降雪.md)**
* 进行了改进。

* *[选项](选项.md)**
* 将工具提示显示设置更改为游戏中工具提示显示，以便工具提示始终显示在菜单中。

* *[平视显示器](平视显示器.md)**
* 将十字准星添加到受不透明度滑块影响的列表中。
* * 在使用快速选择条时，快速选择，提示，分屏游戏玩家名称显示和十字准星的可见度会设置为80，并会在闲置6秒后渐渐恢复回到玩家的可见度设置值。

* *[教程](原主机版教程.md)**
* 在可选教程内加入了活塞和红石。
* 在城堡下加入了活塞自动桥。
* 在世界里加入了一些[甘蔗](甘蔗.md)、[仙人掌](仙人掌.md)和[黏土](黏土.md)。
* 加入一些其他的东西，等玩家来发现。

* *[纹理](纹理.md)**
* 对[Java版1.0.0](Java版1.0.0.md)的方块纹理进行了修改。

# 修复
* *修复了11个漏洞**
* 修复了当玩家在重生点附近放置熔岩时，只会在主机弹出对话框的漏洞。
* 修复了打火石的工具提示。
* 修复了音符盒不显示音符粒子效果。
* 修复了排行榜读取时间过长。
* 修复当玩家被踢出游戏后重新加入时会被阻止，直到主机端重新开始游戏才可进入的问题。
* 修复了当玩家不是其他游戏中玩家的好友时，阻止其加入游戏的漏洞。
* 修复下界岩开采后重新出现的问题。
* 修复了进入下界时罕见的崩溃问题。
* 修复在不同的高度攻击敌人时，无法造成伤害的问题（例如，当你击打一个猪时，若猪站在草中，现在可以打到它了）。
* 修复了一些已保存的游戏存档无法加载游戏的漏洞。
* 修复了当开采时无法拾起石头的漏洞。
