# 基岩版1.16.220.51

*页面ID: 80464* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.220.51**是[基岩版1.16.220](基岩版1.16.220.md)的第2个测试版，发布于2021年3月11日<ref></ref>，做出了一些技术性更改，并修复了一些漏洞。

# 更改
# = 技术性 =
* *GameTest框架**
* 将活动对象的所有引用重命名为。
* 将重命名为。
* 在GameTest中加入了，允许对高级测试序列进行更好的控制。
* GameTest序列回调不再将参数视为初始测试对象，因为其现在与整个测试一样有效。
* 更新了行为包以在使用其他本地模块时明确定义其依赖关系。

# 修复
* *常规**
* 使用桶放置细雪/装起细雪的音效现在被划分至正确的音效分类中。（）
* 玩家着火时进入细雪后再次着火不再会不断产生粒子。（）
* 细雪不再会出现于创造模式物品栏中。（）
* 修复了溺尸攻击时三叉戟会向后偏移的问题。（）
* 启用Xbox界面上的“寻找好友”按钮。

* *性能与稳定性**
* 修复了Windows 10版中开启垂直同步后输入和操作出现延迟的漏洞。（）

* *辅助功能**
* 修复了UI屏幕阅读器无法读取默认控制器的焦点和在线游戏未评级弹窗的漏洞。

* *技术性**
* 如果没有匹配的渲染控制器名称，则中的标识符将被视为错误内容。
* 1.16.100版本前的实体json不再会给弃用字段提供错误内容。
* 修改了中的条件以允许生物进入。（）
* 修复了加载到世界中围绕“未处理的未知变量请求”会导致频繁出现MoLang错误的问题。</onlyinclude>
