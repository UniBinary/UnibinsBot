# Java版18w06a

*页面ID: 33554* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w06a**是[Java版1.13](Java版1.13.md)的第17个快照，发布于2018年2月9日<ref></ref>，加入了技术性更新的内容，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[洞穴空气](洞穴空气.md)和[虚空空气](虚空空气.md)**
* 均与空气拥有完全相同的特性。
* 洞穴空气在[洞穴](洞穴.md)中生成。
* 虚空空气在内部用于世界上方（Y≥256）和下方（Y<0）的方块，以及未加载的[区块](区块.md)。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 加入了<code>minecraft:sky_island_low</code>（[末地](末地.md) - 浮岛）、<code>minecraft:sky_island_medium</code>（末地 - 中型岛屿）、<code>minecraft:sky_island_high</code>（末地 - 高岛）和<code>minecraft:sky_island_barren</code>（末地 - 荒岛）。

# = 命令格式 =
* ***
* 重新加入了，且取消了用取而代之的计划。

* *[实体选择器](实体选择器.md)**
* 为实体选择器加入了命令建议。

# = 常规 =
* *[配方书](配方书.md)**
* 为[熔炉](熔炉.md)加入了配方书。
* * 熔炉的配方已被移至json文件。
* ** 它们使用<code>"type": "smelting"</code>。
* ** <code>cookingtime</code>用来判定在熔炉中[烧炼](烧炼.md)物品所花费的时间。
* ** <code>experience</code>用来判定玩家从熔炉中手动取出输出物品时应获得的[经验值](经验值.md)。
* ** [燃料](燃料.md)不在其列，仍为硬编码。
* “解锁配方”的推送通知现在在左上角显示一个图标，来指明解锁的是合成配方还是烧炼配方。

* *[标签](Java版标签.md)**
* 加入了新的普通方块标签。
* * 。
* 加入了新的普通物品标签。
* * 。

# 更改
# = 世界生成 =
* *世界生成系统**
* 重写了世界生成系统。

* *大型[云杉树](云杉树.md)**
* 现在在生长时会将附近的[草方块](草方块.md)变为[灰化土](灰化土.md)。

* *[自定义](自定义/Java版1.13前.md)世界类型**
* 被移除。

# = 命令格式 =
* *[目标选择器](目标选择器.md)**
* 现在允许在实体选择器和方块状态参数中出现空格。

* ***
* 现在接受之前在<code>Temple</code>分组下所有结构的不同名称。
* * 。
* * 分别是[沙漠神殿](沙漠神殿.md)、[雪屋](雪屋.md)、[丛林神庙](丛林神庙.md)和[沼泽小屋](沼泽小屋.md)。
