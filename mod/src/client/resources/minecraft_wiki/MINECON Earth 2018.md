# MINECON Earth 2018

*页面ID: 36348* | *来源: Minecraft Wiki*

[thumb|MINECON Earth 2018的动画徽标](File:MINECON Earth 2018.gif.md)

* *MINECON Earth 2018**是于2018年9月29日16：00－17：30（UTC）期间举行的一次直播活动。<ref></ref>Erin “Aureylian” Wayne、Martyn “InTheLittewood” Littlewood、Yasmin “Yammy” Ayesha、Chad “OMGchad” Johnson和Anthony “Big B Statz”是此节目的主持人。<ref></ref>

8月27日，据ChronicleLiveUK报道，[Nethermined](https://www.nethermined.com)是一个纽卡斯尔的MINECON组织，并将首次成为“[官方社区活动](MINECON Earth 2017#社区活动.md)”。这是该活动第五次举行。<ref>https://www.chroniclelive.co.uk/whats-on/whats-on-news/minecraft-players-treat-newcastles-minecon-15077929</ref>

# 展区
总共有5个展区，在与Minecraft开发者的展览期间的一个展区和展览后的四个社区展区：

# = Modded Minecraft: Playing with Power =
Minecraft [mods](mods.md)开发者谈论如何使用mods可以为玩家提供更多的选择、机会和乐趣。

小组成员将讨论什么是mod，以及如何实现它，所以它适合初学者。他们将讨论Minecraft的好的mod的历史，甚至如何制作mods。

* *出席嘉宾：**[Drullkus](https://twitter.com/drullkus)、[KingLemmingCoFH](https://twitter.com/kinglemmingcofh)、[Direwolf20](https://www.youtube.com/channel/UC_ViSsVg_3JUDyLS3E2Un5g)、[kingbdogz](https://twitter.com/kingbdogz)、[Amadornes](https://twitter.com/amadornes)和[Vazkii](https://vazkii.us/)。

# = Breaking Minecraft =
[AntVenom](https://www.youtube.com/AntVenom)会讲如何突破Minecraft的边界。

AntVenom将会讲到如何把Minecraft推向绝对极限，以及打破元素如何创造有趣的新方式来享受游戏。他将以全新的视角审视Minecraft。

# = Hermitcraft展示了创建、维护和发展多人游戏 =
* *嘉宾：**[Rendog](https://www.youtube.com/channel/UCDpdtiUfcdUCzokpRWORRqA)、[iskall85](https://www.youtube.com/channel/UCZ9x-z3iOnIbJxVpm1rsu2A)、[MumboJumbo](https://www.youtube.com/channel/UChFur_NwVSbUozOcF_F2kMg)、[cubfan135](https://www.youtube.com/channel/UC9lJXqw4QZw-HWaZH6sN-xw)和[Stressmonster](https://www.youtube.com/Stressmonster101)。

# = 用MCEdit做一张地图 =
* *嘉宾：**[Podshot](https://twitter.com/podshot_)、[naor2013](https://twitter.com/naor2012)、[TrazLander](https://www.youtube.com/user/TrazLander)、[gentlegiantJGC](https://twitter.com/gentlegiantjgc)和[abrightmoore](https://twitter.com/abrightmoore)。

# 生物群系投票
[无框|右](File:Biome chooser logo.png.md)
在直播过程中，观众投票选出了一个即将更新的生物群系。拥有最高票数的生物群系将在未来的更新中获得新的特性，比如地形变化和新的[生物](生物.md)。其他两个生物群系也将获得新的特征，但是它们将在更久以后更新。

[针叶林](针叶林.md)生物群系最终在投票中胜出，并成为[村庄与掠夺](村庄与掠夺.md)更新的一部分。

# = 沙漠 =
计划添加榈树和狐獴。[沙漠](沙漠.md)在第一轮投票中淘汰，成为三个选项中最后一个被更新的生物群系。和热带草原与恶地一样，目前没有更多关于该群系更新的消息。

# = 针叶林 =
计划添加[甜浆果](甜浆果.md)、[营火](营火.md)和[狐狸](狐狸.md)。在第二轮投票中，[针叶林](针叶林.md)被选为第一个更新的生物群系，成为[村庄与掠夺](村庄与掠夺.md)更新的一部分。

# = 热带草原 =
计划添加猴面包树、白蚁和鸵鸟。在第二轮投票中，[热带草原](热带草原.md)被选为第二个更新的生物群系。和恶地与沙漠一样，目前没有更多关于该群系更新的消息。
