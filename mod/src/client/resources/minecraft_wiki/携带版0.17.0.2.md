# 携带版0.17.0.2

*页面ID: 26392* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.17.0.2 alpha**是[1.0.0](携带版1.0.0.md)的第2个测试版，发布于2016年11月18日<ref></ref>，加入了混搭包、种子选择器和可下载的音乐，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[音效](音效.md)**
* 加入了TNT[矿车](矿车.md)和[苦力怕](苦力怕.md)的点火声音。

# = 常规 =
* *[商城](商城.md)**
* 加入了在游戏中可下载的音乐。

* *[混搭包](混搭包.md)**
* 加入了混搭包（此时还未使用）。

* *[种子选取器](种子选取器.md)**
* 加入了[种子选取器](种子选取器.md)。

# 更改
# = 生物 =
* *[史莱姆](史莱姆.md)和[岩浆怪](岩浆怪.md)**
* 修正了掉落物。

* *[烈焰人](烈焰人.md)**
* 修改了烈焰人的攻击蓄力时间，使其与其他平台的版本统一。

# = 世界生成 =
* *常规**
* 在生成地图前会检查是否有足够可用的存储空间。

# = 命令格式 =
* *[命令](命令.md)**
* 暂时移除了命令。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* 由于末影龙已在游戏中实现并且游戏已脱离Alpha测试，“100% dragon free”与“It's alpha”被从[闪烁标语](闪烁标语.md)中移除。

* *[纹理包](纹理包/DLC.md)**
* 调整了自然纹理包的介绍。

* *[渲染](设置#Video.md)**
* 最低能见度调整为3个[区块](区块.md)（当低于3时尝试加载会导致卡顿）。
* 调整渲染机制。

* *语言**
* 对话框文本中Realms中的“r”显示为大写。
* 由“Save world to device”改为“Download World”。
* * 文本调整到正常位置。
* 由“Create new world”改为“Create New”。
* 调整了叙述可及性的方式。
* Rift启动器更新（仅限于Win 10 Oculus Rift）。

* *GUI**
* 在[Realms](Realms.md)屏幕中调整了UI。
* 调整错误验证屏幕，以更好地传达有关失败的附加包的信息。
* 游戏屏幕布局与成就界面调整。
* “起床”的按钮更新。

# 修复

* *其他**
* 在已经加载过的世界里，生物群系的外观非常怪异。
* 在试图导入已经导入过的附加包时显示错误信息。
* 在导入名称或描述过长的附加包时，不会显示错误信息。
* 清单内出现语法错误的0.16.0附加包不会在1.0.0内显示错误。
* 成年后的幼年豹猫不能驯服。
* 末地城内找到的附魔物品的附魔等级在版本间不同。

* 朝着末影人投掷喷溅水瓶使得游戏崩溃。

* 切换资源包时，纹理不会更新。
