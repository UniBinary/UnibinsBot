# Java版Infdev

*页面ID: 6620* | *来源: Minecraft Wiki*

* *Infdev**（或**<u>Inf</u>inite <u>Dev</u>elopment**，即无限开发）是Minecraft的第四个[开发阶段](版本记录.md)，该阶段加入了无限世界。Infdev仅支持单人[生存模式](生存模式.md)游玩。

Infdev继承自[Indev](Java版Indev.md)版本，是[Notch](Notch.md)决定重写代码以实现地图无限且程序化生成（而非此前有限地图）的开发阶段。这种地图生成原理与如今的Minecraft类似。Infdev及后来的[Beta](Java版Beta.md)版本理论上可生成约为地球大小8倍的超级地图，同时也首次出现了[边境之地](边境之地.md)的概念。地图长宽各为64,000,000方块（40.96亿平方公里），相比之下，地球的总表面积（含海洋）为5.1亿平方公里。

# 特点
[200px|右|缩略图|Infdev的一个早期版本，背景中可看到一座红砖块金字塔](File:OldInfdev.png.md)

* 巨大的[红砖块金字塔](红砖块金字塔.md)会在[Infdev 20100227](Java版Infdev 20100227-1433.md)的世界中生成，其生成位置固定在每个世界的X=512、Z=512处。这些金字塔从地面延伸至世界顶部（有趣的是，在[20100227-1414](Java版Infdev 20100227-1414.md)版本中，由于该版本的世界高度限制，金字塔的塔顶会被削去，变成四棱台，这一问题在[下一个版本](Java版Infdev 20100227-1433.md)中得到修复），且塔的底部不会替换除水和空气以外的任何正常地形。由于年代久远，这种结构的相关信息较少，或许是用于测试的。
* 遮天蔽日的[Infdev大树](Infdev大树.md)，以及Infdev从20100413版本开始加入的险峻地形生成器。
* Infdev包含[边境之地](边境之地.md)。边境之地并非Infdev独有，但在Infdev中首次出现。在Infdev早期版本中，当X或Z轴坐标超过±12,550,820后，原本的地形会被巨大的石墙或石柱阻断，这与后来的边境之地有所不同。
* 地图大小现在无限大。
* 增加了更多可[合成](合成.md)的[物品](物品.md)。
* 出现3D且带有特殊纹理的[云](云.md)。
* 拥有更复杂的[洞穴](洞穴.md)系统。
* 加入动态的[液体](液体.md)系统。
* 新增[告示牌](告示牌.md)、[梯子](梯子.md)和[门](门.md)。
* 加入[矿车](矿车.md)及铁轨。
* 加入[地牢](地牢.md)。
* 在非常早期的Infdev版本中，天空盒为完全蓝色（色彩为）。
* 存在[黑曜石墙](黑曜石墙.md)（仅出现于[Java版Infdev 20100227-1414](Java版Infdev 20100227-1414.md)和[Java版Infdev 20100227-1433](Java版Infdev 20100227-1433.md)两个版本中）。

# Infdev的阶段
Infdev分为三个阶段：
* 第一阶段始于2010年2月27日，止于2010年3月25日。由于玩家生成时物品栏中存在大量特定物品，这一阶段的Infdev主要用于测试，红砖块金字塔、黑曜石墙等测试结构在世界中广泛生成。此阶段的游戏将Indev的所有特性与Infdev的无限地形相适配。
* 第二阶段始于2010年3月27日，止于2010年4月20日。该阶段主要致力于修复漏洞，树木与地形生成器在此期间被反复修改，同时引入了新的存储格式，允许玩家在同一客户端存储最多5个世界，Infdev大树也在此时加入。
* 第三阶段始于2010年6月7日，止于2010年6月30日。这是Infdev的“额外阶段”，由于此时[Indev](Java版Indev.md)的特性已全部与无限地形适配，因此该阶段侧重于添加新特性，加入了门、告示牌、梯子、楼梯等诸多新内容，还引入了[秘密更新](秘密更新.md)，新增了[矿车](矿车.md)、[铁轨](铁轨.md)、[地牢](地牢.md)和[刷怪笼](刷怪笼.md)。2010年6月29日，Notch开始开发游戏离线客户端，这意味着玩家无需再通过浏览器游玩Minecraft。由于这些版本仅专注于添加新特性，有人将其视为早期的[Alpha](Java版Alpha.md)版本。

# Alpha取代Infdev
Infdev的主要目标是让Indev的内容与无限地形相适配，这一目标在2010年6月左右达成。之后，[Alpha](Java版Alpha.md)作为更具标志性的进展取代了Infdev版本，Infdev不再更新，其相关链接也从Minecraft官方网站中移除。

2010年9月，Indev和Infdev一同从Minecraft.net上撤下。如今若想游玩Infdev，玩家需在新启动器中选择相应版本。

# 你知道吗
* Infdev沿用了Indev的文字游戏（Indev指代In Development），其中“Inf”代表“Infinite（无限）”，“dev”代表“Development（开发）”。
* 由于Infdev的资源包从minecraft.net/resources中移除（除非对资源包使用代理服务器），游戏的背景音乐也随之消失，但这一情况在[Indev](Java版Indev.md)中并未出现。
* 在里，树苗纹理下方有一个奇怪的纹理，是红色、橙色与白色像素的混合，后来被替换为一个写有“fire tex”的红色方块。
