# 携带版0.12.1.b11

*页面ID: 17820* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.12.1 alpha build 11**是[v0.12.1 alpha](携带版0.12.1.md)的第11个测试版，发布于2015年8月21日，修复了一些漏洞。

# 更改
* [潜行](潜行.md)时可以在玩家下方放置方块。
* 现在放置[末地传送门框架](末地传送门框架.md)时，方向对应与玩家放置时所朝的方向。
* 锹挖[灵魂沙](灵魂沙.md)和[草径](草径.md)的速度更快。
* 精准采集[附魔书](附魔书.md)加入创造模式物品栏。
* [僵尸猪人](僵尸猪人.md)有概率生成时携带附魔剑。
* 飞行的方向键在进入主菜单时保留。
* 修复[创造模式](创造模式.md)时消耗饥饿值。
* [附魔](附魔.md)现在与Java版相同。
* [狼](狼.md)被[弓](弓.md)击中时会攻击。
* [附魔台](附魔台.md)可以在[工作台](工作台.md)上制作。
* 精准采集对[冰](冰.md)和[浮冰](浮冰.md)有效了。

# 修复

* *其他**
* 熔炉界面出现红石纹理。
* 下雪时的雪花闪烁。
* 蘑菇方块不能使用精准采集获得。
* 卸下带有的盔甲后，玩家的氧气值不会消耗。
* 部分音效有回声。
* 荧石和栅栏门有纹理深度冲突（Z-fighting）。
* 饮用两种获得相反的状态效果的药水使得游戏崩溃。
* 钻石矿石的生成高度不正确。
* 可以通过重命名物品来实现物品复制。
* 鸡的行为不会同步。
* 多人游戏下的仙人掌不会刺伤玩家。
* 在火中逗留不会烧伤。
* 苦力怕的嘶嘶声不会同步。
* 藤蔓免疫燃烧。
* 幼年狼出生时没有项圈。
* 使用刷怪蛋生成的恶魂不会发光。
* 无法在冰上放置生物头颅。
* 无法将火把放置在刷怪笼侧面。</onlyinclude>
