# 霜炙更新

*页面ID: 21965* | *来源: Minecraft Wiki*

[缩略图|300px|Mojang发布的霜炙更新的图片](File:Frostburn Update.png.md)
* *霜炙更新（Frostburn Update）**是[Java版](Java版.md)的一次主要更新，发布于2016年6月8日。此次更新的名称在2016年6月8日在Mojang网站的一篇博客帖子中与更新同日被揭露。<ref>http://mojang.com/2016/06/minecraft-110-an-update-of-fire-and-ice/</ref>此次更新添加了一些诸如僵尸与骷髅在落雪生物群系和沙漠的变种、北极熊、加载保存结构的结构方块以及自动跳跃等等的新特性。

此次更新的开发始于[16w20a](16w20a.md)，其发布于2016年5月18日。

# 重要特性

# = 新内容 =
* 18种新声音事件与2种新环境音效。
* 4条新闪烁标语。
* “自动跳跃”选项（默认开启），使玩家自动跳跃。
* 1种新粒子：<code>fallingdust</code>
* 1条新命令：
* 4个新NBT标签
* * <code>FallFlying</code>、<code>ZombieType</code>、<code>ParticleParam1</code>与<code>ParticleParam2</code>
* [化石](化石.md)
* 5种新方块
* * [结构空位](结构空位.md)、[岩浆块](岩浆块.md)、[下界疣块](下界疣块.md)、[红色下界砖块](红色下界砖块.md)和[骨块](骨块.md)
* 3种新生物
* * [北极熊](北极熊.md)、[尸壳](尸壳.md)和[流浪者](流浪者.md)

# = 更改 =
* 命令的Y轴范围增加。
* 世界生成中的大量更改。
* [结构方块](结构方块.md)可在游戏中使用。
* [紫颂果](紫颂果.md)和[末影珍珠](末影珍珠.md)现在会传送骑乘中的玩家。
* 生物在船上时也可以射击。
* [末影人](末影人.md)在下界生成。
* [岩浆怪](岩浆怪.md)生成率翻倍。
* [骷髅](骷髅.md)会射它们副手拿着的箭。
* [狼](狼.md)不再被清除。
