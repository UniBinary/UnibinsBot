# 携带版0.9.0.b9

*页面ID: 28891* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.9.0 alpha build 9 (RC1)**是[v0.9.0 alpha](携带版0.9.0.md)的第9个测试版，发布于2014年6月25日，回退了之前一些版本中对生物AI的更改，并修复了一些漏洞。

# 更改
# = 方块 =
* *[刷怪笼](刷怪笼.md)**
* 刷怪笼现在发光。

# = 生物 =
* *[苦力怕](苦力怕.md)**
* 回退了[build 8](携带版0.9.0.b8.md)中对AI的更改。

* *[骷髅](骷髅.md)**
* 回退了[build 8](携带版0.9.0.b8.md)中对AI的更改。

* *[狼](狼.md)**
* 为狼添加驯服与命令（坐下或站起）按钮。

# = 游戏内容 =
* *[合成](合成.md)**
* 合成界面不再在当前合成无法完成时跳转到下一个了。

# 修复
* *修复了13个漏洞**
* 狼相关的崩溃。
* 破坏铁轨下方方块时的崩溃。
* 方块被错误放置在玩家所在位置。
* 生成位置问题。
* 无法正确保存实体。
* 可合成无数量限制的物品。
* 雪层和地毯缺失平滑光照。
* 坐下的狼能够行走。
* 有时已驯服生物会繁殖出未驯服的幼年生物。
* 苦力怕会在地面上悬浮。
* 狼的项圈颜色不正确。
* 交互按钮在松开按住时不会被“按下”。
* 破坏火把时的粒子上出现黑色边框。
* 玩家会重生在虚空。</onlyinclude>
