# 世界生成
; [世界类型](世界类型.md)
* 因为没有无限世界（Xbox One和PS4包含经典），所以会有大、中、小的选项。
; [生物群系](生物群系.md)
* 有小、中、大的选项。由于缺乏无限世界，小型是默认的，所以一个世界能容纳更多的生物群系。
* 有一个“自动输入合适种子”选项，默认选中，这使得游戏随机选择有一个更好的拥有各种生物群系的种子。
; [超平坦](超平坦.md)界面
* 一个用来生成超平坦世界的界面。
; [下界](下界.md)
* 具有有限的大小，并与一个更大的世界规模稍大。
* 根据世界大小，下界比例更大：经典世界和小型世界的比例为1：3；中型世界的比例为1：6； 像其他版本的Minecraft一样，大型世界比例为1：8。
* 下界的边缘由基岩组成。
* 当使用超平坦世界时，下界也是平坦的。
; [末地](末地.md)
* [末地折跃门](末地折跃门.md)的最大数量是四个，而不是二十个。
* 每一个末地折跃门都通向一个岛，它和主岛一样大。四个外岛中的一个将会生成一个[末地城](末地城.md)。
* 世界规模大小并没有变化。 即使在经典世界，这些岛屿仍然相距甚远，以至于它们都在不同的地图上。
* 五个岛屿中的每一个都被看不见的屏障所包围，这使得它们不可能在不使用折跃门的情况下进入它们之间。

# 方块与物品
; [蛋糕](蛋糕.md)
* 可以堆叠至64。
; [下界疣](下界疣.md)
* 随机在[下界](下界.md)中的[灵魂沙](灵魂沙.md)上生成，而不只是在[下界要塞](下界要塞.md)。
; [地图](地图.md)
* 在开始一个新世界时，[玩家](玩家.md)便会拿到一张地图。在版本中改成了一张空白地图。
* 地图能够显示玩家所在的坐标。
* 地图仅能提供1024×1024面积的（比例为1：8，缩放比例3）地图。
* 不能放大或缩小比例。
* 网格不同于Java版和基岩版。
; [霜冰](霜冰.md)
* 可使用精准采集镐来得到此方块。
; [旗帜](旗帜.md)
* 拥有一个自动制作选项。
; [音乐唱片](音乐唱片.md)
* 音乐唱片Wait被命名为“Where are we now?”，与Java版1.4.3之前的名称一致。
* 音乐唱片cat播放完毕后，音轨“Dog”开始播放。
; <samp>[Debug_fourj_item](Debug_fourj_item.md)</samp>
* 不可放置。
* 用途未知。
* 仅能通过物品栏编辑器和其他外部工具获得。
; 圆环方块
“滑翔”小游戏包含一种独有方块类型：圆环方块。其分为绿色、黄色、蓝色的变种，并构成供玩家飞跃的圆环。

# 生物与实体
; [凋灵骷髅](凋灵骷髅.md)
* 在下界所有地方生成，而不是仅生成于下界要塞中。
; [烈焰人](烈焰人.md)
* 杀死烈焰人会获得0-2个荧石粉。
; [矿车](矿车.md)
* 比Java版的矿车快2倍。
