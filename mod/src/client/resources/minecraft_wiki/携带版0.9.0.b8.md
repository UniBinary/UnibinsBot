# 携带版0.9.0.b8

*页面ID: 31498* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.9.0 alpha build 8**是[v0.9.0 alpha](携带版0.9.0.md)的第8个测试版，发布于2014年6月24日，优化了游戏性能，并修复了一些漏洞。

# 更改
# = 生物 =
* *[末影人](末影人.md)**
* 更改了末影人的攻击力以匹配。

# = 常规 =
* *优化**
* 更快的纹理加载。
* 不再向level.dat写入玩家标签。

# 修复
* *修复了11个漏洞**

* 熔炉引起的两个崩溃。
* 当加载空世界时，游戏会无限循环。
* 玩家无法与所有方块进行互动。
* 草方块无法蔓延到泥土上。
* 沉浸模式无法正常工作。
* 狼不会记录其坐姿。
* 树叶会错误地变成原木。
* 再次移动物品时，熔炉不会显示进度条。
* 旧世界中未使用的正确生成位置。
* 生物不会走向创造模式的玩家。
* 僵尸和蜘蛛使用旧的生物AI。</onlyinclude>
