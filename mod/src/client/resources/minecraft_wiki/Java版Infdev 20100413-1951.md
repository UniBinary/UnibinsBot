# Java版Infdev 20100413-1951

*页面ID: 35945* | *来源: Minecraft Wiki*

<onlyinclude>
* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年4月13日19:51（UTC），加入了Infdev大树。<ref>[IRC logs](#logs.md): "(15:51:10) <Notch> I think infdev's been updated"..."(15:52:13) <revenant> nice new trees Notch..."</ref>

# 新内容
# = 世界生成 =
* *[树木](树木.md)**
* 加入了Paul Spooner使用脚本实现的Infdev大树。<ref>[Paul Spooner's Minecraft Scripting Story](http://www.peripheralarbor.com/minecraft/minecraftscriptphotojournal.html)</ref><ref></ref>

# 更改
# = 方块 =
* *[沙子](沙子.md)和[沙砾](沙砾.md)**
* 现在会再次自然生成了。

* *[树叶](树叶.md)**
* 现在不再枯萎。

# = 非生物实体 =
* *[箭](箭.md)**
* 不再在击中[方块](方块.md)时生成[生物](生物.md)。

# = 世界生成 =
* *常规**
* 更新了世界生成器。

# 修复
* *修复了3个漏洞**
* 方块不再能放置在玩家所在的位置。
* 之前，放置方块可能会导致消耗两个方块，现已被修复。
* 光照漏洞已经被修复。有些区域的光照过去较暗，除非有方块更新。这项修复只应用于新生成的区块中。</onlyinclude>
