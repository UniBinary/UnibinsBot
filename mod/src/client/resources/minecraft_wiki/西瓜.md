# 西瓜

*页面ID: 6659* | *来源: Minecraft Wiki*

</ref>||Tom Stone Mojavatar.png}}

* *西瓜（Melon）**是种植[西瓜种子](西瓜种子.md)后从完全生长的西瓜茎中长出来的方块。

# 生成
# = 自然生成 =
西瓜自然生成于：
* 生物群系的地表；
* [林地府邸](林地府邸.md)的“[瓜房](林地府邸/结构/农场#瓜房.md)”；
* [热带草原](热带草原.md)村庄的[西瓜堆](西瓜堆.md)。

# = 种植 =

[西瓜茎](西瓜茎.md)生长至成熟后会尝试在它毗邻的4个位置生成一个西瓜，并且要求该方块为空气并且下方是[泥土](泥土.md)、[草方块](草方块.md)、[耕地](耕地.md)、[砂土](砂土.md)、[灰化土](灰化土.md)、[菌丝体](菌丝体.md)、[缠根泥土](缠根泥土.md)、[苔藓块](苔藓块.md)、[苍白苔藓块](苍白苔藓块.md)、[泥巴](泥巴.md)或[沾泥的红树根](沾泥的红树根.md)。如果收割了西瓜但没有破坏西瓜茎，西瓜茎则会尝试生成另外一个西瓜，而不用重新种植或等待西瓜茎再次成熟。

西瓜需要[光照等级](光照等级.md)为9或以上才能够生长。

# 获取
# = 合成 =

# = 末影人 =
[末影人](末影人.md)可以搬起西瓜，死亡时会掉落手持的西瓜。

# 破坏
挖掘西瓜的合适工具是斧和剑。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，西瓜被破坏后会等概率掉落3-7个[西瓜片](西瓜片.md)。挖掘工具的[时运](时运.md)魔咒会使西瓜额外等概率掉落0-<魔咒等级>个西瓜片，但掉落总数不会超过9个。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，西瓜被破坏后会掉落自身。

# 用途
# = 交易 =

# = 堆肥 =
将西瓜放入[堆肥桶](堆肥桶.md)中会有65％的概率将堆肥层数增加1。

# 你知道吗
* Minecraft的西瓜与现实中的方形西瓜非常相似。
* 用于堆肥时，1个西瓜平均可以产生0.0929个骨粉，但9个西瓜片平均可以产生0.6429个骨粉。
