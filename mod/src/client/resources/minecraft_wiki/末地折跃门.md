* *末地折跃门（End Gateway Portal）**是一种在击败[末影龙](末影龙.md)后在末地岛屿的边缘随机生成或自然生成于末地外岛内的[地物](地物.md)，用于快速传送，往返于末地中央岛屿与末地外岛之间。

# 生成
[缩略图|信标光柱标记了20个末地折跃门的位置](File:EndGatewayComplete.png.md)
[缩略图|300px|末地折跃门对应关系的一个例子。蓝色的点是主岛的末地折跃门，红色的点是外岛的末地折跃门。对应的末地折跃门互相用线连接起来](File:EndGatewayGeneration.png.md)
有三类末地折跃门会生成在末地中。

# = 主岛末地折跃门 =
[末影龙](末影龙.md)每被击败一次生成一个末地折跃门。它会生成于Y=75且距离末地中心（0,0）96格半径固定位置的空中。生成20个末地折跃门后，再击败末影龙不会再生成末地折跃门。

# = 外岛末地折跃门 =
在主岛激活一个末地折跃门之后，将在一个外岛上生成另一个末地折跃门，与主岛的门相连通。这些入口生成在Y=30以上，且始终在末地石上方生成。生成时会以末地中心（0,0）为原点与主岛折跃门产生一条射线，检查射线的第1024格处所在的区块是否为空。如果第1024格处的区块不是空的，那么就沿射线倒退16格并继续检查区块是否为空，直到检查的位置距离末地中心768格远或找到一个空的区块，最后在搜索结束的那个区块生成折跃门；如果第1024格处的区块是空的，那么就沿射线前进16格并继续检查区块是否为空，直到检查的位置距离末地中心1280格远或找到一个非空的区块，最后在搜索结束的那个区块生成折跃门。

# = 回归折跃门 =
在末地外岛会自然生成**回归折跃门（Return gateway）**，其传送目的地是[黑曜石平台](黑曜石平台.md)。与[末地传送门](末地传送门.md)不同，实体通过回归折跃门传送时不会导致黑曜石平台重新生成。<ref></ref>

# 结构

末地折跃门由一个[末地折跃门方块](末地折跃门方块.md)和包围它的12个基岩构成。

# 行为

当折跃门生成时，一道品红色的光柱会从它的顶部和底部垂直地射出，并在后消失。当一个实体进入末地折跃门时，折跃门也发出一道紫色的光柱，这道光柱后消失。折跃门自身每隔也会发出一次光柱。光柱存在的这段时间内实体不能通过折跃门传送。

基岩构成的外部结构阻止了玩家和大多数生物直接走入其中。为了使用末地折跃门，玩家可以向末地折跃门方块中投掷[末影珍珠](末影珍珠.md)，或使用[鞘翅](鞘翅.md)直接滑翔进末地折跃门，或进行[游泳](游泳.md)或[爬行](爬行.md)来进入。任何进入末地折跃门方块的实体也会被传送。

通过折跃门的实体会创建一个传送门区块加载标签，详见。

首次使用主岛末地折跃门传送时，其对应的外岛末地折跃门将在实体在外岛着陆的地点附近生成，它可以将实体传送回主岛中的折跃门，提供了回到主岛的方法。

传送之后玩家或实体“着陆”的位置生成基于一种有规律的运算：折跃门先在地图的最高点（Y=255处），围绕它5格的半径之内，从这一区域的西北角（图中金块位置）开始寻找具有完整碰撞箱的方块（除基岩外）。如果在这一区域有符合要求的方块，那么实体将被传送至它的上方。如果没有，那么它会沿着Z轴（向南）继续寻找（下一个搜索位置由右图中青金石块标记）。这一步骤将会在这个高度相同的11×11的区域的每一列持续进行（除了在传送门方块正上面、正下面的方块）。如果还是没有符合要求的方块，它将在下一高度（Y=254处）继续进行上面的步骤。传送门会持续进行这些步骤，直到每一高度都被检查。一旦在区域内的任何地方都没有具有完整碰撞箱的方块，折跃门方块会把实体传送至距它上方2个方块的位置（折跃门最顶部的一块基岩的上方）。

在一定范围内寻找任意一个末地石方块，并将玩家传送至该末地石方块上方。若在一定范围内没有找到末地石方块，则会在折跃门下方生成一定大小的浮空-{}-岛，并将玩家传送至该上方。若生成的地方有非末地石方块，则会用末地石方块直接替换该方块，替换过程不产生任何掉落物。

# = 区块加载 =

每当一个实体被折跃门传送时，目标折跃门所在的区块会得到加载等级为30的一个加载标签，如果实体被回归折跃门传送，那么[黑曜石平台](黑曜石平台.md)中心的方块所在的区块会得到上述加载标签，这意味着该区块会被完全地加载并且其中的实体会被运算。这一加载等级也会向邻近的区块传播，但是这会随[切比雪夫距离](切比雪夫距离.md)的增大而递增。最终，会有9个（3×3）的区块被强加载，更远处的区块会被更弱地加载。

这些区块会被加载15秒，每次有实体穿过折跃门该计时就会被重置。
