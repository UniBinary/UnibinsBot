# 击退

*页面ID: 28777* | *来源: Minecraft Wiki*

* *击退（Knockback）**是一种应用于[剑](剑.md)和[矛](矛.md)的[魔咒](魔咒.md)，可以增加[击退](伤害#击退.md)距离。

# 获取

# 用途
击退魔咒会在击中实体时产生额外的击退效果。该效果的作用方向为玩家所视方向而非以玩家为中心远离玩家的方向。魔咒等级为1时，击退距离为1.552格（与玩家进行冲刺攻击造成的击退效果相同），随后每级增加2.586格。击退魔咒同时会使垂直方向的击退距离增加，由0.8125格变为1格，与水平方向的击退不同，垂直方向的击退增加适用于被[横扫之刃](横扫之刃.md)魔咒击中的实体，且与玩家所视方向无关，仅在Y轴方向增加击退效果。

与常规击退相同，如果造成的伤害被[无懈可击](伤害#无懈可击.md)抵消，那么击退魔咒造成的击退效果也会无效。
