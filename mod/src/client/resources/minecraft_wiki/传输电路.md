# 传输电路

*页面ID: 9716* | *来源: Minecraft Wiki*

* *传输电路（Transmission Circuit）**是最基本的[红石电路](红石电路.md)之一，使得信号从一处传到另一处。

# 简介
对于不同的红石电路，需要根据实际情况选择简单或复杂的传输电路与传输形式。

在传输类型上通常分为两类：**数字传输**和**模拟传输**。
* 在数字传输中，又能根据其传输形式分为：独热码<!--需要确认该名词在繁体中文中的名称-->传输、二进制传输和脉冲传输（边沿传输）等。
* 在模拟传输中，又能根据其传输形式分为：3-16进制传输、偏移传输（类似于数字边沿传输）等。

在传输规模上通常分为两类：**并行传输**和**串行传输**。
* 在并行传输中，数据所对应的信号被“一起”传输，需要使用大量导线，导线通常超过4条。
* 在串行传输中，数据所对应的信号被“逐个”传输，需要使用少量导线和专用的发送端和接收端，导线通常只有2条甚至1条。

两者可以混用（数据所对应的信号被“逐批次”传输），恰当的设计可以收获最高的效率。

例如使用8条线路传输128位数据（每一条线路串行传输8位数据）：
* 相较于纯串行传输（使用1条线路），**延迟可缩减**。
* * 且由于收发端复杂度降低，体积可能不变或更小。
* 相较于纯并行传输（使用128条线路），**体积显著降低**。
* * 且由于减少线路数量可能减少线路的长度，速度可能因此更快。

有时需要更换信息的表达规则（表达方式），该过程称为**转码**。分为两种：
# 直接转码，例如使用双边沿触发器直接将常规二进制信号串转换为边沿信号串。
# 间接转码，经过多次直接计算/转换步骤来转换。

# 传输类型
# = 数字传输 =
* *数字（Digital）**传输只关心信号有无，但有时也能利用信号强度的不同来优化传输过程。

传输红石信号的方法很多。有些方法具有较为特殊的适用范围，效率仅在适用范围内时较高（甚至极高）。如[单稳态传输](脉冲电路#单稳态传输电路.md)常用于传输触发控制信号。

# == 红石粉 ==

直接用红石粉传输信号最简单且最灵活。但由于红石线的信号等级变化会造成大量方块更新，因此在一些元件状态变化极为频繁且规模庞大的装置中可能会造成服务端明显的卡顿，但有时不会去考虑这一问题。

* *版本特有性质**

大量使用红石粉会导致较高卡顿，主要原因是红石粉每次减弱信号时，由于相邻的红石线的信号强度只比它低1级，因此每次处理，信号强度至多只能降低2级，就像一滩越来越浅的[液体](液体.md)。减少相关卡顿的方法有：
# 减少红石粉使用（如各类无粉电路）；
# 在红石线之间设[绝缘二极管](#二极管.md),提升衰减能量的速度；
# 预充能（预先以特定强度激活线路，减少红石粉衰减能量的次数）。

红石电路基于有向图系统，但图搜索算法的逻辑和硬编码红石线模型均已年久失修，配合极差。因此有时切勿相信你所**看到**的线路连接，它与实际的连接可能大相径庭。

# == 绊线传输 ==

* *原理**<ref>"Minecraftwithdummies" (28 March 2013). [//www.youtube.com/watch?v=2FHIyTR1CT8 "Smart Wire, Faster Than Redstone &#x5B;Overhead Power Line&#x5D;"] (Video). *YouTube*.</ref>

通过移动实体接触绊线（图中以矿车为例），最远可激活40格之外的绊线钩。

* *注意事项**

活塞移动实体时，实体每游戏刻均会刷新自身位置。因此矿车被活塞推动后会马上接触到绊线并激活远方的绊线钩，**故上升沿时绊线传输延迟极低**。但活塞缩回时，实体无法被拉回，**而是受重力影响落下**，**因此下降沿时会有3rt的延迟**。这会导致正脉冲会被本电路加长3rt，负脉冲减短3rt，可能会抹去较短的负脉冲（即[低通滤波特性](wzh:低通滤波器.md)），因此绊线传输不宜传输短脉冲。

绊线传输必须隔离其他实体，例如生物、玩家等。避免干扰。

* *特点：**
* 快速长距离传输。
* 上下沿时序不平衡。
* 持续传输（双稳态传输）。

# == 活塞链传输 ==
活塞可推动方块；[黏性活塞](黏性活塞.md)可拉动方块；[黏液块](黏液块.md)和[蜂蜜块](蜂蜜块.md)可带动方块。

通过移动红石块，或将方块推拉到被充能或[压线](红石粉#形状.md)的位置，或推动比较器与容器之间的方块，实现传输。

方块被推动后会马上转化为[移动的活塞](移动的活塞.md)，因此信号下降沿可瞬时传输。

信号计算严格分阶段（详见[红石系统](红石电路#红石系统.md)），在两个**电容器元件**间使用活塞线时可瞬时传输信号下降沿。

* *特点：**
* 时序复杂。
* 灵活性高。
* 持续传输（双稳态传输）。

# == [阳光探测器](阳光探测器.md)传输 ==
通过遮挡光照实现数据传输。简称为**光电**。<!--这玩意儿是不是篇幅太长了,要不单开一个教程页详细介绍-->

在适用时间上分为**全时段传输**和**仅白日传输**，后者要求世界光照强度为15（时间必须为白天且天气必须为晴天）。在传输方向上分为**竖直传输**和**立体传输**。

* *竖直传输**

利用在晴天且为白天时，无遮挡时世界光照恒为15，可直接构建一条**竖直**传输路径且**无视竖直距离**的**无延迟**传输通路，称为“竖直光路”。

* *立体传输**

通过控制遮挡以及构建“光管道”来构建合理的“立体光路”，实现曼哈顿距离15格以内的**任意走向**传输。

只需要使用活塞推拉方块或发射器（组）控制流体来控制光路的遮挡，就能无延迟控制在此光路中的阳光探测器（即控制光路信号）。<u>光路遮挡控制器</u>也被称为**光控**。

* *全时段传输**

全时段传输需要在接收端额外使用1个阳光探测器（不能被遮挡）作为基准信号，使用比较器检查光路中的阳光探测器的输出（光路输出）是否低于基准信号，若是则意味着光路被遮挡，此时输出信号。

; 用途
   **竖直传输**<br>极小体积（仅白日传输）地无视距离无延迟竖直下传信号。
   **立体传输**<br>利用其可在[曼哈顿距离](曼哈顿距离.md)15格内任意走向传输信号的性质，与普通传输电路灵活组合实现特别的传输走线。

* *版本差异**

若玩家不进行干预（切换阳光探测器模式），那么阳光探测器每1s改变一次输出，因此光控仅需：1个黏性活塞；2个活塞或者1个发射器与流体桶。

阳光探测器每1rt都会改变输出。普通的光控使用黏性活塞即可，边沿时序平衡的光控（带宽5Hz或以下）需要2个黏性活塞或者1个发射器与流体桶，而带宽最高的10Hz光控（绝对边沿时序平滑）需要2个黏性活塞或3个发射器与流体桶。

* *特点：**
* 持续传输（双稳态传输）。
* 体积极小地无视竖直距离快速下传或是曼哈顿距离15格内灵活走线。

* *你知道吗**

在特殊情况下活塞线可直接作为光控使用。光电亦可传输模拟信号，但需要更复杂精巧的光控。

# == [实体](实体.md)传输 ==
通过实体实现传输，这种传输技术被称为**实体传输**。

* *原理**

利用弹射、坠落、[气泡柱](气泡柱.md)升降移动实体到感应位置实现传输。

可自带复位（两个单向的收发端互为反向传输），可**穿墙**传输，延迟计算相对复杂。需对游戏机制有一定了解。实体传输的卡顿通常稍高但能极大拓展布线可能性。

有时会和绊线传输组合使用。

* *特点**
* 可穿墙。
* 灵活性极高。
* 复位时间较长。

# == 物品流传输 ==
通过传输物品（流）实现数据传输。这种传输技术属于**物电**和**储电**。

* *原理**

首先使用物品编码器将数据编码为**特定形式**的物品流（如特定物品，特定数量）。然后使用漏斗链（传输**物品**）或是水道与冰道（传输**物品实体**）来传输物品流，通常混用（效率更高）。最后使用物品解码器将物品流解码为原有的数据。

* *用途**

高带宽地传输数据。

物品流传输的带宽通常只取决于物品编解码器的吞吐量（因为水道可以**不限量**快速运送物品），足够强大的物品编解码器甚至可一次性传递**512字节**数据。但大量掉落物会带来较高卡顿。

* *特点：**
* 延时高。
* 传输带宽极大。

# == [墙](墙.md)传输 ==
通过Minecraft墙体的模型机制实现数据传输。简称为**墙电**。

* *原理**

使用墙体搭建一条竖直下传线路并用[活板门](活板门.md)控制，使用侦测器检测墙体模型更新，输出信号。

* *用途**

小体积地下传信号。

* *版本差异：**
* 墙电是无延迟下传的。
* 墙电1gt下传1格，侦测器的输出延时按每rt下传2格计算。

* *特点：**
* 边沿传输（单稳态传输）。
* 仅下传。

# == [气泡柱](气泡柱.md)传输 ==
通过气泡柱实现传输，被简称为**水电**或**泡电**。

* *原理**

侦测器可以检测气泡柱变化，可以通过搭建一条完全竖直的水柱并于底部通过活塞或黏性活塞控制[灵魂沙](灵魂沙.md)或[岩浆块](岩浆块.md)控制气泡柱进行上传传输。

* *版本差异：**
* 泡电是无延迟上传的。
* 泡电1gt上传1格，侦测器的输出延时按每rt上传2格计算。

* *特点：**
* 边沿传输（单稳态传输）。
* 仅上传。

# == [树叶](树叶.md)传输 ==

通过树叶连接或断连[原木](原木.md)传输数据，简称为**树电**。

* *原理**

利用[侦测器](侦测器.md)可检测树叶连接或断连[原木](原木.md)造成的方块更新。可用树叶搭建一条任意走向的传输线路，用[活塞](活塞.md)或黏性活塞与原木作为输入，侦测器作为输出。

* *用途**

小体积地在7曼哈顿范围内传输数据，在一些立体结构中有巨大用途。

* *特点：**
* 边沿传输（单稳态传输）。
* 任意方向传输。

# == 图扰动无线电 ==

通过图更新阶段的扰动实现信号传输，这种传输技术被称为**图扰动无线电**（因其类似无线电，不需要实际存在的传输线路）。因其需要[红石火把](红石火把.md)组接收信号，也称**火把无线电**。

* *原理**

同维度中，**全部已加载区块**中的**上游元件链接更新**事件（无视距离，无延迟）可干扰特定烧毁状态的红石火把组，因此产生该事件即可发送信号，并用红石火把组接收。

* *用途**

一条**全维度共用**的1位10Hz通信总线，可实现无视距离无延迟传输。

恰当的高频时钟和两个活塞或发射器就可“完全屏蔽”图扰动无线电（即使用大量无效信号堵塞无线电频道，导致有效信号无法传输），类似于现实中的**全频段阻塞干扰**。

* *特点：**
* 连续传输（双稳态传输）。
* 同维度无视距离无延迟传输
* 易受干扰
* 带宽低。

# = 模拟传输 =
* *模拟**传输电路，或称“十六进制导线”。为输出端保持输入端信号强度的电路。因为信号强度有16种（0~15），模拟传输线可以在一条线内传输16种状态（等效于4位二进制线路）。

“模电”并不“模拟”。“[模拟](wzh:模拟信号.md)”意为“连续变化”。但Minecraft的红石信号实际在强度和时间上都是离散的（例如没有11.5强度的信号；也没有长度无法度量的信号），在现实中称为多电平逻辑（归属于数字电路）。此处使用“模拟”一词仅为区分**信号有无**和**信号强度**的传输与计算。在现实生活中，数字电子技术（一般是二电平逻辑，仅有高或低电平）与模拟电子技术（重在连续变化的电势）间的区别与其最为相似，因此“模拟”与“数字”的叫法被广泛采用，但请记住其和现实中有所区别，切勿混为一谈。

* *横向传输 **

若需要**无损**传输模拟信号（即保留原有信号强度）。直接使用比较器的常规传输方案自然是首选。

[300px](File:Redstone HexPower line2.jpg.md)

若需上下传输模电信号，可利用红石粉可以充能其下方的红石导体的性质，让信号无损下传；上传线路则需要通过比较器强充能输出处的红石导体并充能上方红石粉来完成（无法2高堆叠，线路会串扰）。

[300px](File:HexDownloadWire.jpg.md)

# 白色设计：每横向移动两格纵向下降一格的模电导线设计。允许2高堆叠（淡灰色导线为示例）。

* *特点：**
* 灵活性极高。
* 但速度较慢。
* 耗材稍高。

# == 模拟减法导线 ==

* *原理**

若数字X的状态数量少于15，那么可将这N个状态编码到较高的N个信号强度中,规避衰减强度导致的失真。例如：
* 对于10进制（传输数字0-9），可将对应数字编码到信号强度6-15中，即可用强度衰减6为代价让信号多传输6格。
* 对于3进制（传输数字0-2），可将对应数字编码到信号强度13-15中，即可用强度衰减13为代价让信号多传输13格。

* *中继**

传输过程中衰减丢失的信号称为S，中继信号需要为信号补充S（<code>-{}-衰减后信号强度+衰减值</code>），以供下一次传输衰减。

由于<code>A-(B-C) = A-B+C</code>，可得<code>15-(X-S) = 15-X+S</code>。虽然编码区域被翻转了（原本“0到N”编码为“S到N+S”，被翻转后“0到N”编码为“N+S到S”），但数据并未丢失，且已经被衰减掉的S在翻转过程中被补充。

因此每<code>(17-N)</code>个红石粉使用一个红石比较器，任意可为红石比较器输入15强度的方块作为主输入，用上一个比较器的输出在线上衰减后的值作为侧输入即可。如图所示。

在红石比较器的输出强充能方块可让信号每次多传递一格.

* *注意，由于每用一个红石比较器都会翻转一次信号，故这种结构重复次数为偶数时输出原值D，为奇数时输出反相值15-D。**

# = 二进制传输 =
* *二进制（Binary）**传输使用[数字传输线](#数字传输.md)。传输二进制数。

每条线都传输二进制数的一位，数值范围为<code>0 ~ 2ⁿ-1</code>的二进制数需要N条线路传输。通常直接使用线路数量（即“**位宽**”）来表达一条二进制线路的传输量（如8位、16位、32位等）。每条传输线的命名按照该位的权重而定，类似十进制的个位、十位、百位、千位，二进制就是个位、二位、四位、八位，以此类推。

当二进制传输用于输出十进制数值（例如7段显示），这种情况被称为“二进制编码十进制（Binary-Coded Decimal，BCD编码）”。BCD编码使用4位2进制表达1位10进制（8位2进制表达2位10进制，以此类推）。若要在2进制与BCD编码间转换，请参考[https://zhuanlan.zhihu.com/p/268927255?utm_id=0]。

* *扩展：**
* 4位二进制编码的最大携带数据量与[模拟传输线的最大携带数据量](#模拟传输.md)相同。
* 在各类数字电路中通常需要8位（1字节）甚至更高的二进制传输

# 中继器
“中继”信号的意思是延长信号的传输距离。红石信号在连续的红石粉上传导时，信号会逐渐衰减，因此每经过15个红石粉至少需要中继一次。中继元件与电路可以加长信号传输距离。

# = 基本中继器 =
一些红石元件可以中继信号。

; 红石中继器

最简单常用的中继方法就是使用[红石中继器](红石中继器.md)。

需要长距离传输信号时，可为中继器输入端和输出端添加红石导体，利用[强弱充能特性](红石电路/充能与激活.md)提升传输距离。
* 这样每隔17格才需要1个红石中继器而非一般的15格，最大速度也能提升到18格/rt。

; 火把中继器

红石火把亦能实现对信号的中继，但它是一个非门，会翻转[信号极性](红石电路#信号有效极性/正负逻辑.md)。

若要保证信号原样到达，总共使用的火把数量须是**偶数**。

若有可能，可以翻转传输前或传输后的电路的所需信号极性，传输时就可以使用奇数个火把。

火把中继器的耗材比红石中继器稍低（每17格16个红石），但最大速度略低（17格/rt）。

每次中继时一次性使用两根红石火把就无需考虑中继次数对信号的影响了。但由于每次中继的延迟被扩大为2rt，传输速度显著降低。

等效于一种低效的单火把中继器的使用形式。

# = 瞬时中继器 =
* *瞬时中继器（Instant repeater）**指可以无延迟中继信号的电路。瞬时中继器与红石粉的序列通常被称为“瞬时线”。

详见[无延迟科技](Tutorial:无延迟科技#无延迟中继器、非门.md)页面。

# = 双向中继器 =
* *双向中继器（Two-way repeater）**可**双向**中继传来的信号。

双向中继器具有2个端口，均可为输入和输出，取决于哪一侧先接收到信号。

双向中继器在中继信号时，同时会阻断该信号反向输入自身，否则会产生永远激活的中继器环路。由于阻断环路会导致延迟，因此双向中继器存在“双向复位时间”，即一个方向的输入信号消失后，需要复位才能允许另一个方向信号输入。“瞬时双向中继器”同理，只是复位时间有时小于1刻。

* *中继器锁存双向中继器**<ref>"rapamaro" (21 December 2012). ["the most compact 2 way repeater (1.4.7)"](http://www.youtube.com/watch?v=zoY330YXT6E) (Video). *YouTube*.</ref>

原理：某一侧输入信号时，对应方向的中继器将信号中继到另一侧，同时锁定对向中继器来阻断信号回流。

极端输入条件下，两个方向的中继器均会被锁定在激活状态，导致该电路被损坏，双向常态输出且无法主动复位。

* *比较器双向中继器**<ref>"DvirWi" (16 February 2013). ["Two way repeater"](http://www.youtube.com/watch?v=nsX39FxaXIw) (Video). *YouTube*.</ref>

原理：通过巧妙操作信号强度，利用比较器的比较功能，允许信号直接输入的同时阻断信号回流。

因此不建议在未理解的情况下调整输入位置。

特殊结构的比较器双向中继器可输出15信号强度，即不存在中继衰减。

* *火把双向中继器**

原理：使用**方向相反**的两个双火把中继器。某一侧向另一侧传输信号时，对应方向的双火把中继器输出的信号，会截断另一方向的双火把中继器，从而阻止信号回流。

由于红石火把易烧毁，极端输入条件下红石火把可能会烧毁，导致传输的信号失真。

* *传统双向中继器**

是火把双向中继器未经优化的形式，相对其他设计几乎不具备任何优势，但更适合初学者理解原理。

由于红石火把易烧毁，极端输入条件下红石火把可能会烧毁，导致传输的信号失真。

# 二极管
“二极管”具有单向导通性。用于保证信号传输的方向正确，避免信号回流串扰。

# = 元件二极管 =

中继器与比较器都能作为数字二极管，比较器则还能作为模拟二极管，均会引入1rt延迟。

# = 绝缘二极管 =

某些允许红石粉附着的方块仅允许红石信号斜向上传输（禁止斜向下传输）。
* 可重复运用的有：[荧石](荧石.md)、倒置的[台阶](台阶.md)与[楼梯](楼梯.md)、[漏斗](漏斗.md)、[信标](信标.md)、[玻璃](玻璃.md)（包括[遮光玻璃](遮光玻璃.md)）、[海晶灯](海晶灯.md)、开启的[潜影盒](潜影盒.md)、[活塞](活塞.md)、8层[雪](雪.md)、[冰](冰.md)、[霜冰](霜冰.md)、[脚手架](脚手架.md)与[杜鹃花丛](杜鹃花丛.md)。不可重复运用（工作后红石粉会掉落）的有：向上的[活塞头](活塞头.md)、收到信号但未开启的[活板门](活板门.md)和部分[移动的方块](移动的活塞.md)。
* 有：倒置的[台阶](台阶.md)与[楼梯](楼梯.md)、[漏斗](漏斗.md)。

简单地用此类方块将线路抬高一格即可实现极其简单的**无延迟**二极管，但需要注意能量强度损耗。

通常上半台阶最常用，但偶尔为与物流管道交叠而采用漏斗。

# 线路交叉

有时需要让线路互相交叉穿过而互不串扰。

一般的最简单的办法是让线路错开，保证互相隔绝。也可以通过巧妙地设计线路长度和信号强度，令线路即便串联也不会串扰。

设计线路交叉的思维模式具有巨大的可拓展性，在其他场景中亦可大展拳脚，如：
* 减少线路绕行以缩短线路长度。
* 在不引入延迟的前提下，压缩多条线路占用的空间。

也可以使用[绊线传输](#绊线传输.md)让线路直接交叉。

# = 红石线桥 =
红石线桥只使用红石线完成线路交叉，它的结构类似于现实中的道路立交桥，让线路在不同的高度互相穿过。
