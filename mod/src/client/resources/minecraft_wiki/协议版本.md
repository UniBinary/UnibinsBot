# 协议版本

*页面ID: 44131* | *来源: Minecraft Wiki*

* *协议版本（Protocol Version Number**，简称**PVN）**<ref>[:en:Minecraft_Wiki:Projects/wiki.vg_merge/Protocol_version_numbers](:en:Minecraft_Wiki:Projects/wiki.vg_merge/Protocol_version_numbers.md)</ref>是用于检查与服务器版本之间是否不兼容的整数。

# 用法
一个过时的客户端试图连接到一个新版本的服务器}}
具有相同协议版本的客户端和服务器版本彼此兼容。<ref group="注">特殊情况下，协议版本相同的原版客户端和服务端也不能彼此兼容，例如[23w51a](23w51a.md)和[Java版1.20.4-rc1](Java版1.20.4-rc1.md)有着相同的协议版本，但无法兼容，不能连接。</ref>例如，运行[Java版1.21.10](Java版1.21.10.md)的客户端可以连接到运行[Java版1.21.9](Java版1.21.9.md)的服务器，这是因为两者的协议版本都是773。

当尝试加入[多人游戏](多人游戏.md)服务器时，游戏将检查客户端是否有比所选服务器更新或更旧的协议版本；如果是这样，游戏就会显示消息“”<ref group="注">协议版本更新和更旧使用两条不同的消息，本地化键名分别为和。其本地化文本相同，此处省略其中之一。</ref>，来提醒玩家的客户端（或服务器）已过期。

# 版本管理
所有版本，包括上的次要版本和开发版本，都有自己的协议版本。与客户端版本不同，协议版本是一个不断增长的正整数。协议版本可能偶尔会在主要版本之间略过几个数字。

# 储存位置
# = Java版 =
自[18w47b](18w47b.md)起，协议版本可以在当前游戏版本的内找到，该文件位于客户端的和服务端的内。
<div class="treeview">
*  version.json
* * : 此游戏版本的协议版本。
</div>

# = 基岩版 =
自[1.2.0.22](基岩版1.2.0.22.md)起，当前的协议版本可以在设置的“档案”界面（[1.19.40.20](基岩版1.19.40.20.md)起为“通用”界面）中滚动至底部来查看。协议版本的数值会出现在“协议版本：”字样后，也会出现在beta提示文本的“cli-p*n*”字样后。
