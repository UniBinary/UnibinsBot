# Java版12w21a

*页面ID: 32372* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w21a**是[Java版1.3.1](Java版1.3.1.md)的第6个快照，发布于2012年5月24日<ref></ref>。

# 新内容
# = 方块 =
* *[绿宝石矿石](绿宝石矿石.md)**
* 开采时掉落1个绿宝石。
* 生成于多达10个矿石的绿宝石[矿团](矿团.md)中。

* *[末影箱](末影箱.md)**
* 使用8个[黑曜石](黑曜石.md)和1个[末影之眼](末影之眼.md)合成。
* 一个世界中的所有末影箱拥有同样的内容，改变一个会改变所有。
* 在多人游戏中，一个服务器中所有玩家的末影箱的内容都为一样。

* *[砂岩楼梯](砂岩楼梯.md)**
* 拥有和其他楼梯同样的功能和配方，使用[砂岩](砂岩.md)合成。

# = 物品 =
* *[绿宝石](绿宝石.md)**
* 挖掘绿宝石矿石获得。
* 用于与村民[交易](交易.md)。

* *[附魔金苹果](附魔金苹果.md)**
* 由[金块](金块.md)和[苹果](苹果.md)制作而成的第二种金苹果。
* 使用后，玩家会获得30秒的生命恢复IV[状态效果](状态效果.md)，加上5分钟的抗性提升和抗火状态效果。
* 游戏内称“金苹果”。

# = 世界生成 =
* *[村庄](村庄.md)**
* 生成于沙漠生物群系的村庄现在会用砂岩代替木板和圆石。

* *[沙漠神殿](沙漠神殿.md)**
* 沙漠生物群系中新的结构，类似于金字塔。
* 拥有[TNT](TNT.md)陷阱和战利品宝箱。

# = 游戏内容 =
* *[交易](交易.md)**
* 村民会以[绿宝石](绿宝石.md)为货币收购或出售玩家一些物品。
* 右键点击村民以进行交易，会打开GUI界面，有2个购买槽和1个出售槽。

# = 命令格式 =
* *常规**
* 加入了。
* * 用于显示当前世界的种子。

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 发射器会发射出铁桶内装着的液体的源块。
* 在有空桶的情况下也会吸收液体的源块。

* *[沙砾](沙砾.md)**
* 更改了纹理。

* *[上锁的箱子](上锁的箱子.md)**
* 移除了旧的[箱子](箱子.md)纹理，从而导致上锁的箱子现在看起来像紫色的默认纹理方块。

# = 物品 =
* *[铁桶](铁桶.md)**
* 现在可堆叠到16个。

# = 生物 =
* *被动型[生物](生物.md)**
* 现在可以通过简单的走动来轻松地推动它们，这可能是为了帮助玩家更容易地在动物农场进行引路。

# = 非生物实体 =
* *[船](船.md)**
* 现在可以在不破坏船的情况下穿过[睡莲](睡莲.md)，被穿过的睡莲会被破坏并变成[掉落物](掉落物.md)。

* *[矿车](矿车.md)**
* 坐在矿车里面按下方向键时，它会使玩家移动至所按下的方向，这只能在矿车在轨道上的情况下工作。

# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 在创造模式物品栏中加入了[雪层](雪层.md)。

* *[单人游戏](单人游戏.md)**
* 移除了服务器jar文件在单人游戏的依赖性。

* *[星星](星星.md)**
* 星星变得更加真实。
* * 稍微变小和变亮。

# = 常规 =
* *[选项](选项.md)**
* 改进了选项菜单。

* *[调试屏幕](调试屏幕.md)**
* 移除了帧时间统计图。</onlyinclude>

# 你知道吗
* 在此版本中，加载单人游戏世界时，需先将中的（服务端）手动放置到下才能继续加载世界。
* 在此版本中，绿宝石矿石使用的是红宝石矿石的纹理，因为Jeb忘记把新纹理提交到快照中了。<ref></ref>
