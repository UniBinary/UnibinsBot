# 驯服
驯服机制使得玩家可以将生物从野生状态转化为驯服状态，驯服生物的玩家即此生物的主人。

通常而言，具有驯服机制的生物首先需要被驯服，才能被玩家喂食以[繁殖](繁殖.md)或恢复生命值。

驯服的生物死亡后也会给玩家发送[死亡消息](死亡消息.md)。
* 被驯服的猫、狼、鹦鹉、鹦鹉螺和僵尸鹦鹉螺死亡时会给主人发送死亡消息。<ref></ref>
* 被驯服的狼、猫、鹦鹉、鹦鹉螺、僵尸鹦鹉螺、马、驴、骡、僵尸马、羊驼和行商羊驼死亡时会给服务器的所有玩家发送死亡消息。

# = 宠物 =

[thumb|鹦鹉坐在玩家的肩膀上](File:ParrotsOnShoulders.gif.md)
猫、狼和鹦鹉可以被驯服为宠物，它们都需要玩家对其物品来驯服。

猫需要玩家使用[生鳕鱼](生鳕鱼.md)或[生鲑鱼](生鲑鱼.md)来驯服，每次有1/3的概率驯服成功；狼需要玩家使用[骨头](骨头.md)来驯服，每次有1/3的概率驯服成功；鹦鹉需要玩家使用[小麦种子](小麦种子.md)、[西瓜种子](西瓜种子.md)、[南瓜种子](南瓜种子.md)、[甜菜种子](甜菜种子.md)、[火把花种子](火把花种子.md)或[瓶子草荚果](瓶子草荚果.md)来驯服，每次有1/10的概率驯服成功。

被驯服的猫、狼和鹦鹉可以被主人命令坐下或起身，坐下时不再能自主移动。若可以移动，且距离主人超过12格远时，则会尝试直接传送到主人周围横向6格、纵向3格内不会阻挡[寻路](寻路.md)的非[树叶](树叶.md)方块上。它们不会因主人使用[重锤](重锤.md)猛击产生的气场而被击退。

被驯服的猫和狼会显示出项圈，可以被主人染色，且会停止其在未驯服状态下主动攻击其他生物的行为，拥有独特的驯服后音效。它们被驯服后的后代也是驯服状态，其主人取决于双亲加载顺序靠前的一方。

被驯服的鹦鹉会坐到主人的肩膀上。

被驯服的猫不再主动逃离玩家，会在主人醒来时给予玩家[礼物](猫#礼物.md)，且会尝试坐在[箱子](箱子.md)、[熔炉](熔炉.md)和[床](床.md)上，并阻止玩家使用这些方块。

被驯服的狼仍然具有攻击能力，且生命值会增加到。当主人攻击某生物后，被驯服的狼会将攻击目标切换到主人攻击的生物上，且狼的攻击视为主人的攻击（造成伤害的实体仍然是狼），使得生物被驯服的狼杀死后可以同被玩家杀死一样掉落[经验](经验.md)和稀有战利品。主人也可以给狼装备[狼铠](狼铠.md)，使用[剪刀](剪刀.md)卸下狼铠，给狼铠修复或染色等。被驯服的狼不会主动远离羊驼或行商羊驼，也不会被羊驼或行商羊驼主动攻击。

# = 鹦鹉螺 =
鹦鹉螺和僵尸鹦鹉螺可以通过玩家对其使用[河豚](河豚.md)或[河豚桶](河豚桶.md)来驯服。被驯服的鹦鹉螺的后代也是驯服状态，其主人取决于双亲加载顺序靠前的一方。

鹦鹉螺和僵尸鹦鹉螺被驯服后可以被玩家[骑乘](骑乘.md)。玩家可以打开它们独有的物品栏为其装备[鞍](鞍.md)或[鹦鹉螺铠](鹦鹉螺铠.md)，操纵它们的移动，即使在岸上也可以缓缓移动。它们被驯服后也不再主动攻击[河豚](河豚.md)，且不会因主人使用重锤猛击产生的气场而被击退。

# = 类马生物 =
[thumb|自然生成的马群](File:HorseHerd.jpg.md)
类马生物包括马、驴、骡、僵尸马、骷髅马、骆驼、骆驼尸壳、羊驼和行商羊驼，它们拥有很多共通的行为。其中骆驼和骆驼尸壳默认被驯服，因此无法被玩家驯服。

骷髅马不能被驯服。骷髅马会在[骷髅陷阱](骷髅陷阱.md)触发时被游戏直接设置为驯服状态，随同生成的三匹骷髅马也均为已驯服状态。这是骷髅马唯一的“驯服”方式，且不存在驯服骷髅马的玩家。

马、驴、骡、僵尸马、羊驼和行商羊驼需要通过[骑乘](骑乘.md)来驯服。玩家空手与其交互后，每游戏刻有2%的概率触发一次驯服检测，初次骑乘时会从0至最大好感度中随机取一个数字，如果生物的好感度高于该数字，则该生物会被驯服，否则将玩家甩下来，并增加5点好感度。玩家手持物品时无法进行骑乘驯服。

马、驴、骡和僵尸马的最大好感度是100，羊驼和行商羊驼的最大好感度是30。这些生物也可以通过喂食增加好感度，不同食物增加的好感度不同。

马、驴、骡和僵尸马在喂食上使用同一个好感度算法，但僵尸马只能被喂食红色蘑菇；其他生物也不会接受红色蘑菇。

类马生物被驯服后可以被玩家装备各种物品，如[鞍](鞍.md)、[箱子](箱子.md)、[马铠](马铠.md)、[地毯](地毯.md)等。玩家也可以打开它们独有的物品栏以替换装备或存放物品等。

有乘客的僵尸马默认不能被[拴绳](拴绳.md)拴住，但被驯服后即使有乘客也可以。

# 信任
豹猫和狐狸无法被玩家驯服，但可以信任玩家。

豹猫通过喂食生鳕鱼或生鲑鱼来获得信任，每次喂食有1/3的概率信任玩家，信任玩家的同时也会冒出爱心粒子。信任玩家的豹猫不会主动远离所有玩家，也不会在距离玩家过远时消失。

已生成的狐狸无法信任玩家，但若玩家使两只狐狸繁殖，则产生的幼年狐狸会信任繁殖狐狸的玩家，一只狐狸最多只能信任两名玩家（仅当其双亲分别由不同玩家喂食进入繁殖状态而生成）。信任玩家的狐狸不会主动远离玩家（尽管产生的幼年狐狸可能跟随成年狐狸远离玩家），会主动攻击伤害了信任的玩家的生物。
