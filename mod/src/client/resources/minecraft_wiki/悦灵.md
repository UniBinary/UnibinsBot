* *悦灵（Allay）**是一种会飞行的[友好生物](友好生物.md)，能够寻找附近的同种[掉落物](掉落物.md)并投掷到[玩家](玩家.md)或[音符盒](音符盒.md)旁。

# 生成
# = 自然生成 =
# == 掠夺者前哨站 ==
[掠夺者前哨站](掠夺者前哨站.md)的深色橡木笼子里有概率自然生成或<ref></ref>悦灵。

# == 林地府邸 ==
[thumb|林地府邸监狱房中的两只悦灵](File:Two allays1.jpg.md)
[林地府邸](林地府邸.md)的3种[监狱房](林地府邸/结构/监狱房.md)中有概率自然生成悦灵，每间牢房可生成或。

# = 人为生成 =
当对跳舞中的悦灵[紫水晶碎片](紫水晶碎片.md)时，其所在的位置会生成另一只悦灵，并发出爱心粒子和紫水晶音效。其后，两只悦灵在5分钟内都不能再生成其他悦灵。

# 掉落物
悦灵死亡时只会掉落其持有的物品，不会掉落[经验](经验.md)。

# 行为
与[发光鱿鱼](发光鱿鱼.md)相似，悦灵（及其手持的物品）拥有发亮的纹理，在暗处也清楚可见，但不会影响周围方块的实际[亮度](亮度.md)。

悦灵每秒会恢复生命值。

受到伤害的悦灵会短暂地处于惊慌状态。

# = 跳舞 =
[thumb|100px|跳舞的悦灵](File:Allay Dancing.gif.md)

悦灵会在距其10格以内的[唱片机](唱片机.md)播放音乐时跳舞。悦灵会在或后停止跳舞。

# = 手持物品 =
悦灵在未持有物品时会漫无目的地飞行。玩家对悦灵大多数物品时，悦灵会手持该物品并在64格范围内跟随该玩家，同时搜寻周围32格范围内相同类型的[物品实体](物品实体.md)（仅识别物品的ID，忽略物品堆叠组件）。悦灵会移向物品实体并捡起，随后继续搜寻。当范围内已找不到同种物品，或悦灵已经捡够1组物品时，它会飞到该玩家旁，将捡起的物品投掷出去。悦灵投掷完物品后会有3秒的冷却时间才能再次捡拾新物品。空手与悦灵交互可以收回先前给予它的物品，使其恢复为空闲状态。悦灵在收集物品的过程中移动速度更快。

悦灵无法进入水中，但它们会试图捡起水中的物品。

游戏规则设为<samp>false</samp>时，悦灵依然会搜寻物品并待在旁边，但不能捡起来。

[音符盒](音符盒.md)奏响时会向半径16格以内的所有悦灵发送[振动粒子](粒子#vibration.md)。且在奏响后30秒内，悦灵会改为将物品带到此音符盒处，并在此音符盒周围搜寻物品。在此30秒内，其他[音符盒](音符盒.md)奏响时无法再向该悦灵发送[振动粒子](粒子#vibration.md)并影响其行为。音符盒向悦灵发送的信号可被[羊毛](羊毛.md)阻断。

玩家无法给予悦灵[拴绳](拴绳.md)或，对悦灵这些物品会发挥物品的功能。

玩家在非潜行时对未持有物品的悦灵已命名的[命名牌](命名牌.md)时会使悦灵手持该物品，在潜行时使用则会发挥物品的功能。

悦灵不会受到给予它物品的玩家造成的伤害。

手持[不死图腾](不死图腾.md)的悦灵在生命值降为时，不死图腾也会正常生效。

未乘坐船、矿车且未被拴绳拴住的悦灵在给予其物品的玩家进入[下界传送门](下界传送门.md)、[末地传送门](末地传送门.md)或[返回传送门](返回传送门.md)后，会被传送至该玩家附近。

# 你知道吗
* 悦灵虽然外观类似于[恼鬼](恼鬼.md)，但不能像恼鬼一样穿过方块。
* 悦灵的最初设计“[精灵](MCD:精灵.md)（Wisp）”在[Minecraft Dungeons](Minecraft Dungeons.md)中也有出现。它会在[林地监狱](MCD:林地监狱.md)中生成，指引玩家寻找秘密区域。
* * 其生成地点也与悦灵设定相同。
* * 精灵也爱好音乐，其吸引玩家的音效也和背景音乐的声调一致。
* 悦灵的英文名“allay”是指“使减轻或缓解”，与之对应，恼鬼的英文名“vex”表示“使恼怒或担忧”。
* 将[紫水晶碎片](紫水晶碎片.md)作为生成悦灵的物品主要考虑到其属于可再生资源，且与其相关的方块[紫水晶块](紫水晶块.md)和[紫水晶母岩](紫水晶母岩.md)能发出适合悦灵的音乐声，这同时也能为[紫晶洞](紫晶洞.md)增加更多的用处。<ref></ref><ref></ref>
* 根据官网博文，玩家给予悦灵物品时会“形成一种防止悦灵被误伤的魔法连接”。<ref name="mcnet"></ref>
* 最初，Mojang计划使悦灵在[森林](森林.md)生物群系中自然生成，但他们最终选择使其在掠夺者前哨站的笼子和[林地府邸](林地府邸.md)的监狱中生成是为了突出友谊方面的内容。<ref name="mcnet"/>
