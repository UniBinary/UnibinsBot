# 基岩版1.6.0.6

*页面ID: 35365* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.6.0.6**是[1.6.0](基岩版1.6.0.md)的第3个测试版，发布于2018年7月11日<ref></ref>
，加入了<code>doInsomnia</code>游戏规则，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[游戏规则](游戏规则.md)**
* 加入了<code>[doInsomnia](游戏规则/doInsomnia.md)</code>游戏规则。
* * 用于切换[幻翼](幻翼.md)是否自然生成。

# 更改
# = 物品 =
* *[三叉戟](三叉戟.md)**
* 改进了投掷动画。

# 修复
* *修复17个漏洞**
* 修复了游戏过程中发生的一些崩溃。
* 水下植物现在可以放置在水源在它们之上的水柱中。
* 屏障不再阻挡雨和雪下落。
* 修复了破坏船、矿车、画和盔甲架时会播放两次破坏音效的问题。
* 改进了三叉戟的投掷动画。
* 流浪者再次穿着破衣服。
* 当用刷怪蛋生成的幻翼不再出现在天空。
* 玩家不再在矿车上浮空。（）
* 修复了携带鹦鹉螺壳的溺尸死后不掉落鹦鹉螺壳的问题。
* 珊瑚装饰物品组不再显示占位符名称。
* 修复了末影龙异常消失或死亡的问题。
* 现在可以从村民交易输出槽中收集多个物品。（）
* 破坏海带时顶部的海带也会跟着被打破。
* 修复了末影人的头部在隐形状态下保持可见的问题。
* 鱼物品在玩家收集它们时会再次向玩家飞去。
* 击退魔咒再次对生物有效。（）
* 在聊天中输入<nowiki>#</nowiki>符号不再导致语法错误。</onlyinclude>
