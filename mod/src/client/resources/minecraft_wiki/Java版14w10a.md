# Java版14w10a

*页面ID: 33894* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w10a**是[Java版1.8](Java版1.8.md)的第14个快照，发布于2014年3月6日<ref></ref>，加入了新的游戏规则、闪烁标语和统计信息，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 加入了<code>showDeathMessages</code>参数。
* * 切换死亡消息是否会在聊天内出现。

# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* “So sweet, like a nice bon bon!”
* “Popping tags!”

* *[统计](统计.md)**
* <code>stat.crouchOneCm</code>
* * 记录玩家在潜行时移动了多少厘米。
* <code>stat.sprintOneCm</code>
* * 记录玩家在疾跑时移动了多少厘米。
* <code>stat.timeSinceDeath</code>
* * 记录了从上次死亡后过了多长时间（单位为[刻](刻.md)）。

# 更改
# = 方块 =
* *方块[模型](模型.md)**
* 转换了更多方块：中继器，比较器，床，漏斗，门，西瓜/南瓜梗，蛋糕和睡莲。
* 旋转现在放宽至22.5度的倍数。
* 现在不仅能覆盖一个方块的模型，而且能覆盖一个具体方块变种的模型。
* 按下或来刷新模型。

* *[画](画.md)**
* 改进了的定位处理。

# = 生物 =
* *[猫](猫.md)**
* 死后会向主人展示死亡消息。

* *[骷髅](骷髅.md)**
* 在被狼攻击时会开始逃窜而不是反击。

* *[狼](狼.md)**
* 现在会自动攻击骷髅，就像它们会自动攻击羊一样。

# = 非生物实体 =
* *[物品展示框](物品展示框.md)**
* 改进了的定位处理。

# = 命令格式 =
* ***
* 进行小幅度改动来使其更可靠。

* *[记分板](记分板.md)**
* 测试分数现在也可以用于<code>@e</code>实体选择器了。
*  添加了记分板队伍属性是否禁用死亡消息：选项为<code>never</code>，<code>hideForOtherTeams</code>，<code>hideForOwnTeam</code>，<code>always</code>。
* 命令现在会由NBT数据过滤。

# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 在创造模式的玩家能对标为无敌的实体造成伤害。

* *物品标签**
* 药水NBT数据<code>HideFlags</code>现在有了第5个位元（数值32）来隐藏药水效果。

* *[交易](交易.md)**
* 新的[NBT](NBT.md)标签<code>rewardExp</code>来控制村民在交易后是否会给予经验

# = 常规 =
* *Twitch转播**
* 现在会询问是否要进行转播。

* *UUID**
* 所有的玩家列表现在会自动转换成UUID制。

* *其他修复**
* 修复了许多物品的<code>stat.useItem</code>。
* * 食物、牛奶、药水、弓、胡萝卜钓竿以及钓鱼竿可以使用<code>stat.useItem</code>。
* * 对于空桶来说，<code>stat.useItem</code>在舀水和盛熔岩时会增加，而挤奶时不增加。
* * 盔甲、拴绳、鞍、驯服、繁殖、熔岩桶、水桶以及木碗的仍然无法使用<code>stat.useItem</code>。
* 修复了许多实体边界框的调试渲染。
* 修复了在命令方块中命令潜在的“无限递归”问题。</onlyinclude>
