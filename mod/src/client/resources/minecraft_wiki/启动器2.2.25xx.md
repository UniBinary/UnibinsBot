# 启动器2.2.25xx

*页面ID: 80820* | *来源: Minecraft Wiki*

* *2.2.2529**（）、**2.2.2530**（）或**2.2.2528**（）是一次[启动器](启动器.md)更新，发布于2021年3月25日。

# 新内容
* 加入了<code>--disableGPU</code>和<code>--debugGPU</code>命令行标志。
* 加入了“管理档案”菜单项（如果购买了Java版），可以进入Mojang网站。<!--没找到对应功能，直接按字面意思翻译的-->
* * 如果使用的是微软账户，这样应该可以让管理Minecraft档案更简单（例如改名字）。<!--没找到对应功能，直接按字面意思翻译的-->

# 更改
* 现在微软账户登录窗口会随着启动器主窗口的关闭而关闭。
* 调整了“配置”选项卡中的搜索框，使其看起来与其他页面中的一致。“新配置”按钮现在往下移了一点。
* 优化了有很长文本字符串的语言在登录界面上的显示效果。
* 现在，高亮文本仅在一定时间间隔内显示。因此不再显示“两个游戏，一个启动器”的内容。

# 修复
* 修复了启动器检测不到磁盘上已安装的Minecraft Dungeons，并要求重新安装的问题。
* 修复了Minecraft Dungeons安装按钮可以无响应的问题。
* 修复了暂停和取消按钮可能在卸载并重新安装Minecraft Dungeons后消失的问题。
*  - 在第一次切换到设置页面后，不播放页面切换动画的问题。
*  - 启动器窗口会一直缩小，直到不可见。
*  - <code>.minecraft</code>不再能是一个符号链接。
*  - 2.2.25xx版本更新日志的修复部分末尾带有额外的句号。
*  - 启动器无法加载。
