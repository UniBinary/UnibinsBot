* *仙人掌（Cactus）**是一种自然生长于干旱区域的[植物](植物.md)。

# 生成
仙人掌能够生成仙人掌（见）。

# = 自然生成 =
仙人掌自然生成于[沙漠](沙漠.md)与[恶地](恶地.md)生物群系。它们通常生成为1格（的概率）、2格（的概率）或3格（的概率）高。出现更高的高度是因为在生成时生成器继续选择在已经生长仙人掌的方块上继续生成仙人掌，导致高度叠加。

在拥有地下室的[雪屋](雪屋.md)里和沙漠村庄的部分房屋中也可以找到[仙人掌盆栽](仙人掌盆栽.md)。

仙人掌也可能会在试炼密室的“入口”结构中作为植物造景的一部分生成。

# 破坏
没有工具可以加速对仙人掌的挖掘。

仙人掌被破坏后会掉落自身。

# 用途
仙人掌只能放置在沙子、红沙、可疑的沙子或其他仙人掌上。如果仙人掌的4个方向中存在与其相邻的/或熔岩，那么仙人掌会被破坏（并掉落为物品）。在沙子上面的仙人掌在其上方有水和熔岩时也会被破坏。

当仙人掌所处的位置不适宜，比如有固体方块置于其侧方，或者下方的方块被移走或掉落，仙人掌方块会被迫掉落成物品。

仙人掌也会在[活塞](活塞.md)试图将其推动，或推入一个方块到其位置时被移除并掉落成物品。仙人掌无法被[黏性活塞](黏性活塞.md)拉动。

尝试在仙人掌侧面放置[告示牌](告示牌.md)会导致仙人掌和告示牌一起掉落。

仙人掌可以被放进[花盆](花盆.md)里作为盆栽，此时盆栽中的仙人掌不会造成任何伤害。

仙人掌（不包括它的棘状突起）宽为格（与[箱子](箱子.md)相同），高1格，然而它的[碰撞箱](碰撞箱.md)高格。

# = 造成伤害 =
当包括[玩家](玩家.md)和[生物](生物.md)的任何[实体](实体.md)接触到仙人掌时，仙人掌会对其造成每一次的伤害（然而[受击后伤害免疫](受击后伤害免疫.md)会将其减慢至每0.5秒受到一次伤害），但玩家挖掘仙人掌时不会受到伤害。[盔甲架](盔甲架.md)不受仙人掌影响。[盔甲](盔甲.md)可吸收仙人掌造成的部分伤害。一些生物在寻找路径时不会避开仙人掌。

仙人掌也会摧毁任何接触它的[物品](物品（实体）.md)，包括它们上面被收割的仙人掌和[仙人掌花](仙人掌花.md)，甚至还包括无法被爆炸摧毁的[下界之星](下界之星.md)和无法被[火](火.md)和[熔岩](熔岩.md)摧毁的[下界合金](下界合金.md)物品。

当[矿车](矿车.md)碰到仙人掌时，矿车会掉落为物品，但是通常情况下此物品也会被摧毁。由于[漏斗](漏斗.md)会更快地捡起物品，可以通过漏斗防止矿车物品被摧毁。

# = 生长 =

当顶端仙人掌方块累计接收到16个[随机刻](随机刻.md)（平均时间为18分钟）时就会生长一格，直至长到三格的最大高度；不过，玩家可以通过在顶端放置仙人掌来将其堆叠得更高。[骨粉](骨粉.md)对仙人掌的生长没有作用。仙人掌不需要[光](光.md)来生长。如果仙人掌上方有空间且未达到最大高度时就会生长；但如果新生长的仙人掌方块侧边上有固体方块，它就会在生长之后立即破坏并掉落成物品。这可以用于自动收割仙人掌。

当生成位置四面均无方块时，仙人掌能够生成[仙人掌花](仙人掌花.md)，格高的仙人掌柱有10%概率尝试在上方生成仙人掌花并停止生长，3格及更高的仙人掌柱有25%概率尝试在上方生成仙人掌花。

# = 繁殖 =
仙人掌可用于吸引[骆驼](骆驼.md)。当玩家在/以内手持仙人掌时，骆驼会跟随玩家，但已经坐下的骆驼不会跟随。

给成年骆驼喂食仙人掌可使其恢复点生命值，同时进入[繁殖](繁殖.md)模式。给幼年骆驼喂食仙人掌可缩短其成长时间。

# 你知道吗
* 如果将一个白色像素看作一个刺，仙人掌有刺的五个面共有82个刺：顶面10个刺，每个侧面10个刺，每条棱上有8个刺。而仙人掌的每条棱上只有4个刺，因此共有66个刺。
* * 如果将相连接的白色像素看作同一个刺，仙人掌在基岩版中共有75个刺，在Java版中共有54个刺。
* 仙人掌方块的底部并不会对玩家造成伤害。
* 在[15w49a](15w49a.md)前，仙人掌可在满足其他条件（被放在沙子、红沙或其他仙人掌，且四个方向上没有其他固体方块）时被放置在[水](水.md)下，且可以生长到水面。
* 仙人掌可以放在[树苗](树苗.md)旁边，但树生长时仙人掌将被破坏。
* [末影人](末影人.md)可以移动并放置仙人掌。因此，它们可以通过移动仙人掌方块增加在沙漠里的仙人掌的数量。
* 仙人掌可以通过结构生成在沙子以外的方块上。
* 可以通过仙人掌的生长状况判断所在区块是否是新生成的，如果多数的仙人掌都是1格高，那么很有可能这是一片新生成的区块。
* [红石粉](红石粉.md)和[紫颂花](紫颂花.md)不是固体方块，因此它们可以直接放置在仙人掌旁边而不使其掉落为物品。
