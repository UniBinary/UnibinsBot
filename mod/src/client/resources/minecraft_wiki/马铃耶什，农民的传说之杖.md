# 马铃耶什，农民的传说之杖

*页面ID: 137946* | *来源: Minecraft Wiki*

* *马铃耶什，农民的传说之杖（-{Potatiesh}-, Greatstaff of the Peasant）**，以下简称马铃耶什，是一种用于放置[马铃薯传送门](马铃薯传送门.md)的物品。

# 用途
# = 马铃薯传送门 =
已获得“”（Non Plus Ultra）进度的玩家或创造模式玩家马铃耶什会放置一个马铃薯传送门。

# = 爆炸 =
未获得“”（Non Plus Ultra）进度的生存模式玩家马铃耶什会在自身处产生威力为5且带[火](火.md)的[爆炸](爆炸.md)，同时显示消息“<u>**使用-{}-者**</u> was unworthy of -{Potatiesh}-, Greatstaff of the Peasant”（<u>**使用-{}-者**</u>配不上马铃耶什，农民的传说之杖）。

若玩家或被驯服的生物因此死亡，会显示[死亡消息](死亡消息.md)“”。

# = 堆肥 =
将马铃耶什放入[堆肥桶](堆肥桶.md)中，会有100%的概率增加一层堆肥层。
