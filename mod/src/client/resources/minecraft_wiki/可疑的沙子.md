# 可疑的沙子

*页面ID: 171647* | *来源: Minecraft Wiki*

* *可疑的沙子（Suspicious Sand）**是一种使用[刷子](刷子.md)后会弹出[物品](物品.md)并变为[沙子](沙子.md)的方块。

# 生成
# = 自然生成 =
可疑的沙子自然生成于[沙漠神殿](沙漠神殿.md)内部的地窖中、沙漠水井下方、热带[海底废墟](海底废墟.md)中。

# 获取

可疑的沙子只能通过使其生成的[下落的方块](下落的方块.md)存在超过30秒后掉落获得。<ref name="MC-260073"></ref>

可疑的沙子无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，可疑的沙子可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
挖掘可疑的沙子的合适工具是锹。

可疑的沙子被破坏后不会掉落。

# 用途
# = 容纳物品 =
可疑的沙子可以容纳一个物品，存储在其方块数据中。玩家只能通过等命令来修改此物品。如果可疑的沙子被破坏，其中的物品会消失而不会掉落。

从[创造模式物品栏](创造模式物品栏.md)中获得的可疑的沙子内没有物品。生成在世界中的可疑的沙子会包含物品，物品的种类取决于它们所属的结构或地物。

对着可疑的沙子持续[刷子](刷子.md)时，其纹理上的裂缝会不断扩大，经过三个阶段，全程4-5秒时间，最终变为[沙子](沙子.md)。若中途停止，可疑的沙子会在停止扫刷后或恢复原状。

如果可疑的沙子中有物品，最先被刷子刷扫的一面会逐渐露出其中的物品，物品会以物品实体的外形，从可疑的沙子的面的中心，以一个与表面近似垂直的角度逐渐露出，并在可疑的沙子被清扫完毕后在该面掉落该物品。

# = 种植 =
可疑的沙子上方可以种植[仙人掌](仙人掌.md)、[甘蔗](甘蔗.md)、[竹子](竹子.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)和[枯萎的灌木](枯萎的灌木.md)。

# = 下落的方块 =

可疑的沙子在下方没有[不可替代的方块](方块基本属性#可替代.md)时会变为[下落的方块](下落的方块.md)。在转化为下落的方块时，其中的物品和战利品表就已经消失。

可疑的沙子未得到支撑且未下落时，会在方块下方产生[尘土粒子](粒子#falling_dust.md)。

下落的可疑的沙子在落地后不会重新成为方块，也不会掉落任何物品。

如果下落的可疑的沙子自生成后存在了至少，或在建造高度外且自生成后存在了至少，如被[蜘蛛网](蜘蛛网.md)或[涌流气泡柱](涌流气泡柱.md)影响而不能落地，下落的可疑的沙子就会直接消失并掉落本身。<ref name="MC-260073" />
