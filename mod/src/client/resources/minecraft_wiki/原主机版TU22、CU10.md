# 原主机版TU22、CU10

*页面ID: 81547* | *来源: Minecraft Wiki*

* *TU22/CU10**是[原主机版](原主机版.md)的一次更新，发布于2015年2月25日至27日期间，修复了一些漏洞。<ref></ref><ref></ref>

# 新内容
# = 物品 =
* *[音乐唱片](音乐唱片.md)**
* 在生存模式中加入了*Where Are We Now*音乐唱片。

# = 游戏内容 =
* *[控制](控制.md)**
* 加入马的物品栏的快速移动。

# 更改
# = 方块 =
* *[青金石块](青金石块.md)**
* 更新了纹理。

# = 生物 =
* *[僵尸](僵尸.md)**
* 修正了幼年僵尸判定箱大小。

# = 游戏内容 =
* *主机权限<!-- en: Host privileges -->**
* 修改了玩家权限。

# 修复
* *修复了4个漏洞**
* 修复了放置活塞、发射器、投掷器的问题。
* 修复了箱子被摧毁却未消失的漏洞。
* 修复了玩家在船上受到摔落伤害的漏洞。
* 修复了狼可以传送到船上的玩家并杀死玩家的漏洞。
