# 磨制黑石砖

*页面ID: 58184* | *来源: Minecraft Wiki*

* *磨制黑石砖（Polished Blackstone Bricks）**是由[磨制黑石](磨制黑石.md)合成的一种装饰性方块。
# 生成
# = 自然生成 =
磨制黑石砖会在[堡垒遗迹](堡垒遗迹.md)和下界的[废弃传送门](废弃传送门.md)中自然生成。

# 破坏
挖掘磨制黑石砖的合适工具是镐。磨制黑石砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

磨制黑石砖被破坏后会掉落自身。
