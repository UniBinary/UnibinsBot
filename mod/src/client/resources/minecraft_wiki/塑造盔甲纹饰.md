# 塑造盔甲纹饰

*页面ID: 156953* | *来源: Minecraft Wiki*

* *塑造盔甲纹饰（Shaper Armor Trim）**是一种[盔甲纹饰锻造模板](盔甲纹饰锻造模板.md)，可使用[陶瓦](陶瓦.md)复制自身。

# 获取
# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落塑造盔甲纹饰。

# = 合成 =
尽管塑造盔甲纹饰本身不能合成获得，但可以利用特定的合成配方来复制自身。

# 用途
塑造盔甲纹饰可在锻造台上与[盔甲](盔甲.md)和锻造原材料相结合，给盔甲添加纹饰。
