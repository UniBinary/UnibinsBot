# Java版1.9-pre4

*页面ID: 20413* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.9-pre4**是[Java版1.9](Java版1.9.md)的第4个，也是最后一个预发布版，发布于2016年2月26日<ref></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[玩家](玩家.md)**
* 在维度变换的时候无敌。

# = 非生物实体 =
* *[弹射物](弹射物.md)**
* 弹射物变小。

# = 命令格式 =
* *常规**
* 更改实体选择器<code>r=</code>的处理方式。
* * 现在基于实体的位置，而不是方块的中心。意味着<code>r=0</code>只会选择完全重合的实体。

# 修复

* 玩家实体在服务器上tick两次。
