# 世界边界

*页面ID: 12131* | *来源: Minecraft Wiki*

[缩略图|右|世界边界](File:Worldborderanimation.gif.md)
* *世界边界（World border）**是[Minecraft](Minecraft.md)世界的当前定义边界。

# 外观
世界边界由一种动态的、相互平行的对角线密集排列而成。当世界边界处于静止状态时，这些斜线显示为半透明的亮蓝色；若边界正在扩展，则斜线会变成绿色；若边界正在收缩，则斜线会变成红色。

在极佳图像品质下，世界边界会渲染得更暗一些。<ref></ref>

# = 大小 =
世界边界本质上是一个巨大的边界框。默认情况下，世界边界的中心位于坐标x=0, z=0处，长宽均为59,999,968格。理论上其造成的效果在高度上是无上限的。

使用[命令](#命令.md)可以修改世界边界的大小及位置。世界边界的造成的效果以1格为最小单位，无论数据中是否有小数点。默认情况下的世界边界基于[坐标](坐标.md)轴对称。

# 效果
# = 对于实体 =
大部分[实体](实体.md)无法移动至世界边界之外。

若[发射器](发射器.md)和[投掷器](投掷器.md)的出口直接紧挨世界边界，则物品、弹射物、TNT等均可被发射至世界边界之外。所有被发射器发射的物品均会悬浮在半空中；若物品是从玩家的物品栏中掉落的，则会正常落地。

若使用发射器发射[刷怪蛋](刷怪蛋.md)在世界边界之外生成[生物](生物.md)，则该生物表现正常。[蜘蛛](蜘蛛.md)可以攀爬世界边界，而[末影人](末影人.md)可以传送出边界外。

在世界边界外仍然可以用末影珍珠生成一只在边界外的正常末影螨。

使用命令也可以在世界边界外生成生物。

所有位于世界边界之外的[玩家](玩家.md)（除[创造模式](创造模式.md)和[旁观模式](旁观模式.md)外）都会受到持续伤害。

虽然玩家无法直接走过世界边界，但可以通过其他方式越过，包括：
* 让正在收缩的世界边界越过自身
* 使用诸如等命令

位于世界边界外的生物可以横向穿过边界墙回到里面，但是不能从边缘纵向穿过或从角落进入。

# = 对于方块 =
玩家无法正常放置和破坏世界边界之外的方块，也无法和边界外的对象进行互动，因为不会显示其碰撞箱。但如果要在边界外放置方块，仍然是可以做到的，因为可以通过对边界内方块的侧面放置方块、或者通过命令来实现。

大多数方块在世界边界外仍然能正常工作，大多数[红石](红石.md)结构也可以正常运行。例外情况包括正在下落的方块（譬如[沙子](沙子.md)和[沙砾](沙砾.md)），它们会掉落成[物品](物品（实体）.md)；[活塞](活塞.md)和[黏性活塞](黏性活塞.md)会停止工作，[TNT](TNT.md)和其他来源的[爆炸](爆炸.md)会正常工作，改变世界边界外的地形。[火把](火把.md)和其他来源的[光](光.md)不会受到影响。

如果使用活塞尝试将一个方块推出边界外，活塞臂会正常伸出，这个方块会与活塞臂重合，并且边界外不会显示任何方块。而如果玩家尝试将用活塞同时推动2个方块来使相对远离活塞的那个方块被推到边界外面，那么这两个方块会重合，且边界外还是不会显示任何方块。如果尝试破坏重合的方块，则会破坏当时距离边界较远的方块，而当时距离边界较近的方块会保留贴图和碰撞箱，但无法与其互动，即使其在边界里面。重载世界后方块会都回到正确的位置。

[缩略图|200px|源头放置在世界边界之内的液体可以流出边界外](File:liquids flow thru border.png.md)

[液体](液体.md)可以流出世界边界之外，直至达到其流动限制。液体无法放置于世界边界之外。通过[发射器](发射器.md)放置在边界外的液体会正常流动。在液体交汇时，仍然会生成石头、黑曜石、圆石等方块（即使没有碰撞箱）。

# 命令

使用命令可以修改世界边界的大小、中心位置以及持续伤害的大小与缓冲距离，也可以使其尺寸动态扩展和收缩。
