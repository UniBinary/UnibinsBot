# 生成
、去皮红树原木、去皮樱花原木、去皮苍白橡木原木、去皮绯红菌柄、去皮诡异菌柄不会生成在世界中，只能通过对其未去皮变种斧来产生。

# = 自然生成 =
# == 沉船 ==
去皮橡木、云杉、白桦、丛林、金合欢和深色橡木原木会作为[沉船](沉船.md)的桅杆生成。

# == 其他结构 ==
去皮橡木原木也会作为平原[村庄](村庄.md)房屋的一部分生成。

去皮云杉原木会在雪原村庄生成。

# 获取
去皮原木和去皮菌柄只能通过破坏对应方块获得。

# 破坏
挖掘去皮原木和去皮菌柄合适工具是斧。

去皮原木和去皮菌柄被破坏后会掉落自身。

# 用途

# = 合成材料 =

# == 进一步合成 ==

去皮原木和去皮菌柄与原木和菌柄类似，可以合成出木板以进一步合成出更多木质产品。

# = 烧炼配方 =

去皮菌柄不可烧炼制得木炭。

# = 燃料 =
去皮原木可以作为[熔炉](熔炉.md)、[高炉](高炉.md)和[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每块去皮原木可以烧炼1.5个单位的物品。

去皮菌柄不能作为燃料使用。
