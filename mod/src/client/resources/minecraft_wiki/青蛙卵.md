* *青蛙卵（Frogspawn）**是一种可孵化出[蝌蚪](蝌蚪.md)的非固体方块。

# 生成
# = 繁殖青蛙 =
给两只[青蛙](青蛙.md)喂食[黏液球](黏液球.md)使之繁殖后，其中一只青蛙会搜寻上方有空气的[水源](水源.md)，并在其上方产下青蛙卵。

# 获取

青蛙卵无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，青蛙卵可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
青蛙卵被挖掘时会立刻被破坏。

青蛙卵被破坏后不会掉落。

# 用途
青蛙卵可放置于[水源](水源.md)和[含水](含水.md)方块上方。青蛙卵下方水的消失会破坏青蛙卵。青蛙卵也会被[下落的方块](下落的方块.md)和伸出的[活塞头](活塞头.md)破坏。

青蛙卵无法被[黏性活塞](黏性活塞.md)拉动。

# = 孵化 =
青蛙卵的孵化时长为至之间的随机数，且仅在其下方1格为水源或含水方块时能孵出蝌蚪，孵化时间不受[游戏规则](游戏规则.md)影响<ref></ref>。每格青蛙卵可孵出2-5只[蝌蚪](蝌蚪.md)。
