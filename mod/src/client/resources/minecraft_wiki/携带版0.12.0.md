# 携带版0.12.0

*页面ID: 21293* | *来源: Minecraft Wiki*

* *v0.12.0 alpha**是携带版的一次主要更新，发布于2015年7月29日<ref></ref>。此次更新仅在Windows 10发布，加入了许多独有特性，完善了酿造机制，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[铁砧](铁砧.md)**
* 所有3种受损形式。
* [熔炉](熔炉.md)和[酿造台](酿造台.md)在GUI中不显示自定义名字。

* *[酿造台](酿造台.md)**
* [熔炉](熔炉.md)和[酿造台](酿造台.md)在GUI中不显示自定义名字。

* *[生物头颅](生物头颅.md)**
* [物品栏](物品栏.md)图标不是3D的。
* 不能创造[凋灵](凋灵.md)。
* 不能佩戴。

* *[花盆](花盆.md)**
* 可以将花、仙人掌和枯萎的灌木放进花盆里作为装饰。

* *[灵魂沙](灵魂沙.md)**
* 自然生成于下界。

* *[下界砖栅栏](下界砖栅栏.md)**
* 通过使用[下界砖](下界砖.md)合成。

* *[下界砖台阶](下界砖台阶.md)**
* 通过使用[下界砖](下界砖.md)合成。

* *[下界石英矿石](下界石英矿石.md)**
* 自然生成于下界。

# = 物品 =
* *[玻璃瓶](玻璃瓶.md)**
* 通过使用玻璃合成。
* 可以装水，变成水瓶。

* *[药水](药水.md)**
* 加入了所有的药水。

* *[喷溅药水](喷溅药水.md)**
* 加入了所有的效果。

* *[金胡萝卜](金胡萝卜.md)**
* 用于酿造夜视药水。

* *[下界疣](下界疣.md)**
* 用于酿造粗制药水。

* *[闪烁的西瓜片](闪烁的西瓜片.md)**
* 用于酿造治疗药水。

* *[金苹果](金苹果.md)**
* 通过使用金锭和苹果合成。
* 自然生成于战利品箱子里。
* 食用后获得正面[状态效果](状态效果.md)。

* *[附魔金苹果](附魔金苹果.md)**
* 自然生成于战利品箱子里。
* 食用后获得正面[状态效果](状态效果.md)。

* *[兔子脚](兔子脚.md)**
* 仅在创造模式下可用。
* 用于酿造跳跃药水。

* *[烈焰棒](烈焰棒.md)**
* 由[烈焰人](烈焰人.md)掉落。
* 可以作为燃料烧炼12个物品。

* *[烈焰粉](烈焰粉.md)**
* 通过使用[烈焰棒](烈焰棒.md)合成。
* 用于酿造力量药水。

* *[恶魂之泪](恶魂之泪.md)**
* 由[恶魂](恶魂.md)掉落。
* 用于酿造再生药水。

* *[蜘蛛眼](蜘蛛眼.md)**
* 由[蜘蛛](蜘蛛.md)掉落。
* 用于酿造剧毒药水。

* *[发酵蛛眼](发酵蛛眼.md)**
* 通过使用蜘蛛眼合成。
* 用于酿造隐身和虚弱药水。

* *[毒马铃薯](毒马铃薯.md)**
* 收割成熟的马铃薯后有概率掉落。

# = 生物 =
* *[铁傀儡](铁傀儡.md)**
* 自然生成于村庄。
* 可以通过建造生成。

* *[雪傀儡](雪傀儡.md)**
* 可以通过建造生成。

* *[豹猫](豹猫.md)**
* 自然生成于[丛林](丛林.md)里。
* 可使用生鱼驯服。

* *[僵尸村民](僵尸村民.md)**
* 村民被僵尸感染后仍然保留它们的所属的衣服和职业。
* 加入了幼年僵尸村民。

* *[烈焰人](烈焰人.md)**
* 自然生成于下界要塞里。
* 死后有概率掉落[烈焰棒](烈焰棒.md)。

* *[凋灵骷髅](凋灵骷髅.md)**
* 自然生成于下界要塞里。

* *[闪电苦力怕](闪电苦力怕.md)**
* 雷暴时闪电击中苦力怕生成。

# = 世界生成 =
* *[下界](下界.md)**
* 和Java版一样，是无限大小的。

* *[下界传送门](下界传送门.md)**
* 用于进入或离开下界。
* 最大可以建到23×23格。
* 原来通过[下界反应器](下界反应器.md)可以获得的所有物品现在都能通过各自正常途径获取了。

* *[下界要塞](下界要塞.md)**
* 自然生成于下界。

# = 游戏内容 =
* *[饥饿](饥饿.md)**
* 进食不再直接回复[生命](生命.md)值。

* *[天气](天气.md)**
* 加入了下雨、下雪和雷暴天气。

* *[疾跑](疾跑.md)**
* 通过双击方向键激活。

* *[酿造](酿造.md)**
* 加入了完整的酿造系统。

* *[难度](难度.md)**
* 和平、简单、普通、困难

* *[物品修复](物品修复.md)**
* 使用[铁砧](铁砧.md)进行。

* *动画**
* 加入了切换快捷栏中的物品时的动画。

# = 常规 =
* *[控制](控制.md)**
* 支持手柄和键盘。
* * 可在选项中更改控制。

* *[设置](设置.md)**
* 加入了禁用自动跳跃的选项。
* 交换潜行和跳跃按钮的选项。
* 跳跃按钮被移到屏幕右侧。
* 在原跳跃按钮的位置加入了潜行按钮，并变成默认设置。

# 更改
# = 方块 =
* *[雪层](雪层.md)**
* 在降雪时堆积。
* 受重力影响。

* *[下界反应核](下界反应核.md)**
* 仍可用，但被从合成菜单中移除。当玩家破坏下界反应核时，其会掉落3个钻石和6块铁锭。

# = 物品 =
* *[船](船.md)**
* 新的物品栏图标。
* 现在包含桨。
* 用不同种木板纹理合成的船，有不同种颜色。

* *[食物](食物.md)**
* 现在恢复[饥饿值](饥饿值.md)而不是[生命值](生命值.md)。

* *[书](书.md)**
* 更改了合成配方。

# = 生物 =
* *常规**
* 燃烧的生物在身上的火被灭掉时会发出烧灼的粒子效果。
* 创造模式中敌对生物不再攻击玩家。
* 生物在死后现在掉落经验球。

* *[史莱姆](史莱姆.md)**
* 史莱姆跳跃时会有粒子生成。

* *[岩浆怪](岩浆怪.md)**
* 岩浆怪和恶魂会在下界自然生成。
* 岩浆怪会在死后分裂。

* *[僵尸猪人](僵尸猪人.md)**
* 僵尸猪人成为了条件敌对生物。
* 僵尸猪人会在下界生成。

* *[村民](村民.md)**
* 有了新的AI，不会总是逃离怪物（如[蜘蛛](蜘蛛.md)、[骷髅](骷髅.md)）。

# = 常规 =
* *图标**
* 更新了游戏图标。

* *图像**
* 水的色彩 - 从远处看从浅绿色变成深绿色。
* 在[覆雪针叶林](生物群系.md)中，树叶会“结霜”。

# Windows 10版独有特性

# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 快捷栏现在有9格，而不是5–7格。

# = 常规 =
* *[控制](控制.md)**
* 暂停键和聊天键的位置更改了。
* 滚动条有了新的纹理。
* 玩家现在可以在[熔岩](熔岩.md)中游泳。

* *菜单屏幕**
* 按钮现在是石质的纹理。
* 现在展示旋转的玩家模型，含有当前[皮肤](皮肤.md)和玩家名字。
* 选项按钮在“游戏”按钮左下方。
* * 按钮现在显示“选项”而不是扳手图标。
* 皮肤选择按钮从选项移动到菜单屏幕上选项按钮的右边。
* 语言按钮的图标现在和Java版一样。
* 按钮更小使“游戏”按钮有了现在的大小。

* *[设置](设置.md)**
* 第6个可视距离选项。

* *GUI**
* Java版样式的生存模式物品栏与合成UI。

* *[控制](控制.md)**
* 支持键盘。

# 修复
* *修复了5个漏洞**

* 索尼Xperia Play上修复的触摸板实现
*  – 玩家无法从熔岩中出来<ref></ref>
*  – 删除格式后无法输入新文本<ref></ref>
*  – 幼年僵尸会骑牛
*  – 使用键盘和鼠标时无法驯服豹猫

# 你知道吗
* Windows 10版的发布日期本来与其他携带版的发布日期相同，为2015年7月29日，但是由于开发中遇到的一些困难，发布日期被强制推迟<ref name=Delay></ref>。
* 0.12的宣传图在后来的携带版及基岩版中被用于建议玩家注册的窗口中。
