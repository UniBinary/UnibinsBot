# 边界

*页面ID: 24515* | *来源: Minecraft Wiki*

* *边界（Border）**方块是一种能够阻止生物通过其上方或下方的方块。<ref>https://education.minecraft.net/support/knowledge-base/using-border-blocks/</ref>

# 生成
边界不会生成在世界中。

# 获取

边界无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)，边界可以通过、[创造模式](创造模式.md)中使用或[命令](命令.md)等方式获得。

# 破坏
挖掘边界的合适工具是镐。边界需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

游戏模式不是创造模式、或在“玩家权限”屏幕中的“操作员命令”开关未打开的玩家，不能挖掘破坏边界。

没有世界建造者权限的玩家，即使处于创造模式也不能挖掘破坏边界。

边界被破坏后不会掉落。

# 用途
只有或（下文称有权限的玩家）能放置边界。

尽管具有类似[墙](墙.md)的外观，边界具有完整的[轮廓箱](判定箱#轮廓箱.md)和1×1.5×1大小的[碰撞箱](判定箱#碰撞箱.md)。

当游戏规则<code>showBorderEffect</code>为<code>true</code>时，边界会在其上方生成<code>risingborderdust</code>[粒子](粒子.md)，下方生成<code>fallingborderdust</code>粒子。

# = 阻止大部分实体通过 =
边界会使有权限的玩家以外的生物无法通过其所在位置的所有高度，表现为一个固体阻挡的表面。

边界无法阻挡使用穿透方块的飞行移动方式的生物（如[末影龙](末影龙.md)、[恼鬼](恼鬼.md)和[旁观模式](旁观模式.md)的玩家等）和弹射物。[凋灵](凋灵.md)和末影龙也无法破坏边界。

玩家可以通过投掷[末影珍珠](末影珍珠.md)、食用[紫颂果](紫颂果.md)或使用[命令](命令.md)越过边界。
