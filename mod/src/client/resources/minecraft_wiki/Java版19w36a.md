# Java版19w36a

*页面ID: 47301* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w36a**是[Java版1.15](Java版1.15.md)的第3个快照，发布于2019年9月4日<ref></ref>，加入了5条新的游戏规则和1条新的实体标签，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* *[游戏规则](游戏规则.md)**
* <code>doInsomnia</code>
* * [幻翼](幻翼.md)是否能够在[夜晚](昼夜更替#夜晚.md)生成。
* <code>doImmediateRespawn</code>
* * [玩家](玩家.md)死后立即重生，不显示[死亡画面](死亡画面.md)。
* <code>drowningDamage</code>
* * 玩家是否会受到[溺水伤害](溺水伤害.md)。
* <code>fallDamage</code>
* * 玩家是否会受到[摔落伤害](摔落伤害.md)。
* <code>fireDamage</code>
* * 玩家是否会受到[火焰伤害](火焰伤害.md)。

* *[标签](Java版标签.md)**
* 加入了实体标签。

# 更改
# = 方块 =
* *[床](床.md)**
* 现在尝试在[白天](昼夜更替#白天.md)睡觉会将[玩家](玩家.md)的重生点设置在该床旁边。

* *[蜂巢](蜂巢（方块）.md)**
* 在创造模式下破坏蜂巢或蜂箱会使之以物品形式掉落。

* *[钟](钟.md)**
* 现在会在接收红石信号时鸣钟。

* *[发射器](发射器.md)**
* 现在由发射器发射的[烟花火箭](烟花火箭.md)的飞行方向与该发射器的朝向相同。

* *[湿海绵](湿海绵.md)**
* 现在在下界放置湿海绵会令其直接变干。

# = 物品 =
* *[蜂蜜瓶](蜂蜜瓶.md)**
* 可回复的[饱和度](饱和度.md)从9.6降至1.2。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 现在属于[节肢生物](节肢生物.md)。

# = 常规 =
* *[编写Mod](Mods.md)**
* 混淆映射表在将来的所有版本都会对外公布，也包括此版本。
* * 然而，这并不意味着[Mojang Studios](Mojang Studios.md)更改了已有的对游戏代码和游戏资源的版权限制。
* * 该混淆表的下载链接会作为version manifest json的一部分，其文件名为{{cd|-{}-<版本号>.json}}。

* *[区块存储格式](区块存储格式.md)**
* [生物群系](生物群系.md)信息现在会存储Y坐标，使得生物群系能够以高度为基础而变化。此前，生物群系只会存储X和Z坐标的信息。
* * 标签中为每个区块排列的能够容纳的整数从256个更改为1024个。
