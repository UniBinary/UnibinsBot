# Java版Alpha服务器0.2.4

*页面ID: 45538* | *来源: Minecraft Wiki*

* *0.2.4**是一个[Alpha](Java版Alpha.md)服务器版本，发布于2010年11月10日。<ref></ref>

# 添加
* 新的服务器配置选项：<code>no-animals</code>。

# 修复
* <code>hellworld=true</code>不再覆盖旧的被保存的区块。
* 船现在对其他玩家可见。
* 玩家现在可以坐在矿车和船里。
* 矿车现在移动得更流畅了。
* 钓鱼现在可以工作了。
* 铁桶现在可以拾起流体了。
* 绵羊和牛看着更像绵羊和牛了。
* 现在可以驾驶服务器端的船了。
* 修复了楼梯难以破坏的问题。
* 增加了“花费太长时间登入（took too long to log in）”的提示出现前的超时时长。
