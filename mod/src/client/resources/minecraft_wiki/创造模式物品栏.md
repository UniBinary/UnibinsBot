# 创造模式物品栏

*页面ID: 104119* | *来源: Minecraft Wiki*

* *创造模式物品栏（Creative Inventory）**是[创造模式](创造模式.md)的玩家无限获取[物品](物品.md)的基本方式。

# 机制
处于创造模式的玩家按下键或时，会打开创造模式物品栏。创造模式物品栏中包含了在生存模式能够得到的几乎所有物品，以及一些无法在生存模式中获得的物品，如[刷怪蛋](刷怪蛋.md)和[基岩](基岩.md)。玩家可以从这里获得几乎任何物品，并且可以无限使用。

# = Java版 =

创造模式物品栏的基本分组方式是**创造标签页（Creative tab）**。物品的创造标签页是物品的基本属性之一，且物品可以有任意数量的创造标签页。大多数物品都有一个创造标签页，部分物品有多个，极少数物品如[知识之书](知识之书.md)没有创造标签页。

对创造模式物品栏中的物品单击鼠标左键可以抓取一个物品，并且抓取该物品的堆叠个数会随着单击该物品次数的增加而增加。对准堆叠物品单击左键和右键会分别抓取单个物品和一组物品，这时鼠标单击其他物品将会对鼠标单击的物品和开头抓取的物品进行位置交换。右键单击一组物品也将只抓取一个物品，但第二次右击时将会把那个物品放下，而不是拾起更多。按住单击物品可抓取一组物品。在将鼠标悬停在某个物品上方时按下数字键，则会立即将鼠标悬停的整堆物品放入与该数字相对应的准备栏中。

将物品放入创造模式物品栏会摧毁这一堆叠的物品，包括直接点击物品将其拖入或按住点击物品堆叠。

# == 搜索物品 ==
创造模式物品栏的右上角有一个搜索页，在搜索页以外的创造标签页按下可以切换到搜索页。在右上角输入栏中直接输入物品在当前语言中的名称或其[物品提示框](物品提示框.md)中可能出现的文字即可搜索到此物品。输入栏为空时，所有物品都会在此显示。除此以外，输入<code>-{}-<*命名空间*>:<*物品ID*></code>能以英文ID搜索指定命名空间下的物品，命名空间可省略，但“:”不可省略；输入<code>-{}-#<*物品标签的命名空间ID*></code>会呈现这个[物品标签](Java版标签/物品.md)内的所有物品，命名空间也可省略。

搜索物品提示框时，物品栏会忽略由[属性修饰符](属性修饰符.md)带来的特殊属性文本，而直接匹配常规ID下的原文。如搜索“5”时会显示下界合金镐（6 攻击伤害），因为非特殊属性修饰符会将其显示为“+5 攻击伤害”；搜索“+”或“-”时，所有的剑、镐、斧、锹、锄、重锤、三叉戟都会显示，即使它们的提示框中不包含“+”、“-”字符。

# == 已保存的快捷栏 ==
创造模式物品栏中有**已保存的快捷栏**。在创造模式中按下+会将当前的快捷栏保存至“”选项卡中，并且可通过按下+加载。

已存储的快捷栏存储在客户端的文件中，因此可以用于在不同世界之间复制物品。

# == 物品销毁 ==
在创造模式物品栏的“生存模式物品栏”一栏右下角有一个打叉的红色格子。将物品放入其中会摧毁这个堆叠的物品。按住时点击该格子会清除物品栏中的所有物品。

# = 基岩版 =
创造模式物品栏的基本分组方式是**创造分类（Creative category）**。物品的创造分类是物品的基本属性之一，物品只能有一个创造分类。大多数物品都有一个创造分类，少数物品如[命令方块](命令方块.md)和[结构方块](结构方块.md)没有创造分类。

创造模式物品栏共有5个标签页：4个创造分类标签页（“[20px|class=pixel-image](File:BE icon recipe construction.png.md)建筑”、“[20px|class=pixel-image](File:BE icon recipe equipment.png.md)”、“[20px|class=pixel-image](File:BE icon recipe item.png.md)物品”和“[20px|class=pixel-image](File:BE icon recipe nature.png.md)自然”）和1个“[20px|class=pixel-image](File:BE icon recipe all.png.md)全部”标签页。创造分类标签页会显示所有对应分类的物品，“全部”标签页则会显示所有物品，同时在顶部提供一个搜索栏。

玩家处于[创造模式](创造模式.md)时，创造模式物品栏会代替[配方书](配方书#基岩版.md)出现。
