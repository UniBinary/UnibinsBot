# 判定箱

*页面ID: 63233* | *来源: Minecraft Wiki*

* *判定箱（Hitbox）**定义了[方块](方块.md)和[实体](实体.md)的物理边界（或其近似值），用于计算碰撞和选取。

和方块模型不同的是，所有方块和大部分实体的判定箱都是硬编码的，无法通过数据包修改，只能通过[Mod](Mod.md)改变。

# 方块
# = 轮廓箱 =
* *轮廓箱（Outline Box）**会在玩家看向指定方块时显示。当十字准星指向方块时，会有黑框线描出该方块的轮廓。

一个方块的轮廓箱并不是固定的，在不同的方块状态下可能具有不同的轮廓箱。例如上半台阶和下半台阶属于同一种方块，但具有不同的轮廓箱。、液体、[空气](空气.md)不具有轮廓箱。

# = 互动箱 =
[*上面*：视线与铁砧轮廓箱的某一个上表面碰撞，选择方向为上方。<br>*下面*：视线与堆肥桶轮廓箱的某一个水平表面碰撞，但由于堆肥桶有一个完整方块大小的互动箱，且视线与互动箱上表面碰撞，所以最终选择方向为上方。|thumb](File:Interaction box usage.png.md)

* *互动箱（Interaction Box）**用于处理选中方块后的选择方向。如果一个方块可以被选中（由轮廓箱判定），并且视线与方块的互动箱相交，那么选择方向不取决于轮廓箱与视线的碰撞面，而是取决于互动箱与视线的碰撞面。

绝大多数方块的互动箱都不存在，选择方向只取决于轮廓箱。只有下方这些方块具有互动箱：
* ：炼药锅内的空间是互动箱。
* ：堆肥桶的互动箱是整个方块。
* ：漏斗的互动箱与方块状态有关。当漏斗指向下方，互动箱为漏斗内部的空间；当漏斗指向某一个水平方向，互动箱位于对应漏斗方向上，覆盖漏斗的指向部分。
* ：脚手架的互动箱是整个方块。

# = 方块支撑形状 =
[漏斗的支撑面（蓝色正方体上的各个面）|thumb](File:Block support shape of hopper.png.md)

* *方块支撑形状（Block Support Shape）**主要用于判断一个方块表面是否可以附着另一个依附型方块。

方块支撑形状默认与碰撞箱相同，但下列方块不同：
* ：方块支撑形状与轮廓箱相同。
* ：方块支撑形状在各个方向上都比轮廓箱小格。
* ：打开时方块支撑形状不存在，关闭时为碰撞箱下方缩减格。
* ：方块支撑形状不存在。
* ：方块支撑形状为完整的方块。
* ：关闭时方块支撑形状为完整的方块，开启时方块支撑形状向对应方向拉伸。
* ：方块支撑形状与轮廓箱相同。
* ：方块支撑形状为完整的方块。

方块支撑形状和一个与坐标网格对齐的1×1×1正方体的某个面重合的所有面的并集就是这个方块在某个方向上的**支撑面**。
* 如果某个方向上的支撑面是一个1×1的正方形，则这个面**完整**。
* 如果某个方向上的中心×的正方形都属于支撑面，则这个面**中心完整**。
* 如果某个方向上的宽度为的边缘都属于支撑面，则这个面**边缘完整**。
* 如果一个方块的所有支撑面都完整，则这个方块是方块支撑形状完整的方块，简称****，否则为****。

例如漏斗的上表面是不完整的，因为上表面中间缺失了×的区域，同时它的上表面中心不完整，但边缘完整，而漏斗这个方块是不完整方块。

依附型方块判断支撑面的类型来决定它们是否能依附于要依附方块的某个面上。直立的[火把](火把.md)、[灯笼](灯笼.md)等方块只能放置于上表面中心完整的方块上；[红石比较器](红石比较器.md)、[红石中继器](红石中继器.md)、[铁轨](铁轨.md)等方块只能放置于上表面边缘完整的方块上；[按钮](按钮.md)、[拉杆](拉杆.md)等方块只能放置于完整的支撑面上。

绝大多数上表面不完整的方块上方不能生成任何生物。

# = 遮挡形状 =
* *遮挡形状（Occlusion Shape）**主要用于计算[亮度](亮度.md)和方块的某一面是否可见。

遮挡形状默认与轮廓箱相同，但下列方块不同：
* ：栅栏的遮挡形状比轮廓箱高度更低、宽度更小，并且下方是空的。
* ：栅栏门的遮挡形状取决于它是否连接到了其他的栅栏或墙上。如果没有连接，遮挡形状会更高；如果连接了其他的栅栏或墙，那么遮挡形状也会相应降低。
* ：讲台的遮挡形状只包含下面的底座和支柱，上面的桌面不属于遮挡形状。
* ：滴水石锥没有遮挡形状。
* ：细雪没有遮挡形状。
* ：幽匿尖啸体的遮挡形状与碰撞箱相同。
* ：生物头颅没有遮挡形状。

如果一个方块的遮挡形状不能和一个与坐标网格对齐的1×1×1的正方体完全重合，那么无论遮挡形状大小如何，这个遮挡形状都被认为是不完整的，而这个方块就是**遮挡形状不完整方块**。所有可以遮挡光线且遮挡形状完整的方块都是**完全固体渲染方块**。

与方块支撑形状类似，遮挡形状也有对应**遮挡面**的属性。它主要用于剔除方块多余的渲染面。如果一个方块的某个渲染面被另一个方块的遮挡面完全遮挡，那么这个渲染面就不会渲染。

# = 视觉遮挡形状 =
* *视觉遮挡形状（Visual Shape）**用于判断视角能否透过方块观察到自身，确定第三人称视角的最佳位置。

视觉遮挡形状默认与碰撞箱相同，但下列这些方块是例外：
* 、、：所有类型的玻璃都不存在视觉遮挡形状。
* ：栅栏的视觉遮挡形状与轮廓箱相同。
* ：铁栏杆没有视觉遮挡形状。
* ：泥巴的视觉遮挡形状是一个完整的方块。
* ：细雪没有视觉遮挡形状。
* ：雪的视觉遮挡形状与轮廓箱相同。
* ：灵魂沙的视觉遮挡形状是一个完整的方块。

# 实体

所有实体的判定箱都是一个以正方形为底的长方体，无视实体的实际形状。比如，[女巫](女巫.md)的判定箱不包括顶部的帽子，而[凋灵](凋灵.md)的判定箱不包括两侧的头。[末影龙](末影龙.md)除本体外还有8个身体构件，所以末影龙本质上是多个实体的组合，它的判定箱也由这些子实体组合而成。

# = 边界箱 =
实体的**边界箱（Boundary Box）**可以通过调试快捷方式查看。当玩家选中实体的边界箱后才能与其交互。同时，实体的边界箱也是它们的碰撞箱。

# = 视平线 =
* *视平线（Eye Level）**具有红色的轮廓，且只会出现在实体的判定箱中。视平线负责判定窒息和溺水伤害，当一个生物的视平线处于窒息方块或水中时，该生物就会受到窒息伤害或因耗尽氧气而溺水。当视平线位于[水](水.md)或[熔岩](熔岩.md)中时，屏幕也会产生不同的渲染效果。
