# Java版Combat Test 7b

*页面ID: 85138* | *来源: Minecraft Wiki*

}}<onlyinclude>

* *Combat Test 7b**是未来的战斗改版的一个秘密的实验性版本，发布于2020年8月13日。此版本是[Java版1.16.2](Java版1.16.2.md)的分支。

# 更改
# = 游戏内容 =
* *[战斗](Tutorial:战斗.md)**
* 将基础攻击距离改回2.5格。

* *[击退](伤害.md)**
* 略微减少了向上的击退。

* *[盾牌](盾牌.md)**
* 盾牌在使用时现在会增加50%的击退抗性。

# 修复
* 修复了使击退抗性有时能完全抵挡击退的漏洞。
* 修复了旁观者可以使用附有横扫之刃魔咒的武器进行攻击的漏洞。</onlyinclude>

# 你知道吗
* 即使不兼容，Combat Test 7b与[21w11a](21w11a.md)的[数据版本](数据版本.md)是一致的。
