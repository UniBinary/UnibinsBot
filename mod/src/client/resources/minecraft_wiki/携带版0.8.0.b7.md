# 携带版0.8.0.b7

*页面ID: 31529* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.8.0 alpha build 7**是[v0.8.0 alpha](携带版0.8.0.md)的第7个测试版，发布于2013年12月5日，修复了一些漏洞。

# 更改
# = 方块 =
* *[羊毛](羊毛.md)**
* 将灰色羊毛移动到正确的分类中。

* *[冰](冰.md)**
* 冰在物品栏中不再透明。

* *[铁轨](铁轨.md)**
* [动力铁轨](动力铁轨.md)在手上与物品栏上显示为充能状态。

# = 物品 =
* *[工具](工具.md)**
* 现在木质工具能作为燃料了。

* *[矿车](矿车.md)**
* 加入了乘坐矿车的UI消息。
* 移除了乘坐矿车时显示的无功能方向键。

# = 常规 =
* *AI**
* AI表现提升。

# 修复
* *修复了10个漏洞**

* 修复了Android设备上的文本输入。
* 修复了云杉和桦树树叶被交换的问题。
* 修复了熔炉和砂岩台阶的侧面纹理。
* 修复了攻击组合型生物会使骑行与被骑行生物都受到伤害的问题。
* 修复了熔炉的GUI。
* 现在TNT不会再把矿车中的玩家炸入轨道。
* 修复了盔甲栏中没有生命值的问题。
* 修复了矿车中的自动跳跃问题。
* 修复了离开矿车玩家会摔落的问题。</onlyinclude>
