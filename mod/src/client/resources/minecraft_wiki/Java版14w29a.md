# Java版14w29a

*页面ID: 32779* | *来源: Minecraft Wiki*

<onlyinclude>

* *14w29a**是[Java版1.8](Java版1.8.md)的第36个快照，发布于2014年7月16日<ref></ref>，添加了1条新的游戏规则和游戏规则变量的机制，此快照大幅优化了加载性能，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* *[游戏规则](游戏规则.md)**
* <code>reducedDebugInfo</code>
* * 可以启用/禁用按时是否显示调试屏幕简略信息的游戏规则。
* * 与“简化调试信息”在多人游戏设置中切换不同。
* * 在客户端中重写设置“简化调试信息”。
* 创建游戏规则变量的能力。<ref>http://www.reddit.com/r/Minecraft/comments/2aw5nh/new_queryresults_and_gamerule_variables/</ref>
* * 这些假的游戏规则不会实质上影响世界，但是能被使用<code>QueryResults</code>检测来基于游戏规则的值更新记分板目标的参数。
* * 使用创建。
* * 使用访问。

# = 常规 =
* *[设置](设置.md)**
* 多人游戏设置
* * “简化调试信息”设置在启用时简化[调试屏幕](调试屏幕.md)（）的调试信息。
* 视频设置
* * “使用顶点缓冲器”设置为启用时启用顶点缓冲。
* * 当设置为启用时，可提供大约10%的性能提升。

# 更改
# = 方块 =
* *[告示牌](告示牌.md)、[箱子](箱子.md)、[信标](信标.md)、[床](床.md)、[头颅](头颅.md)和[末影箱](末影箱.md)**
* 现在显示破坏动画。
* 床之前确实显示了破坏动画，但顶部和底部没有显示。

* *[楼梯](楼梯.md)**
* 将物品栏里的纹理翻转到原始方向。

# = 世界生成 =
* *[矿石生成](矿石生成.md)**
* 矿石生成数量增加了两倍。<ref></ref>
