* *花盆（Flower Pot）**是一种可用于放置[植物](植物.md)的装饰性[方块](方块.md)。

# 生成
蕨盆栽、橙色郁金香盆栽、粉色郁金香盆栽、矢车菊盆栽、铃兰盆栽、凋灵玫瑰盆栽、火把花盆栽、闭合的眼眸花盆栽、张开的眼眸花盆栽、、橡树树苗盆栽、丛林树苗盆栽、金合欢树苗盆栽、深色橡树树苗盆栽、红树胎生苗盆栽、樱花树苗盆栽、苍白橡树树苗盆栽、棕色蘑菇盆栽、竹子盆栽、杜鹃花丛盆栽、盛开的杜鹃花丛盆栽、绯红菌盆栽、绯红菌索盆栽、诡异菌盆栽、诡异菌索盆栽不会生成在世界中。

# = 自然生成 =
[沼泽小屋](沼泽小屋.md)会生成一个红色蘑菇盆栽。

[雪屋](雪屋.md)地下室中会生成一个仙人掌盆栽。

[林地府邸](林地府邸.md)里会生成白桦树苗、蒲公英、虞美人、兰花、绒球葱、蓝花美耳草、滨菊、红色郁金香以及白色郁金香盆栽。

[村庄](村庄.md)中也会生成花盆：蒲公英盆栽生成于[平原](平原.md)的肉铺1和制箭师房屋，以及[热带草原](热带草原.md)的中型房屋2；仙人掌盆栽生成于沙漠的制箭师房屋，牧羊人房屋，工具匠房屋，皮匠屋，图书馆，铁匠铺，教堂，会合点1和3，中型房屋，小型房屋1、2、3、5、7；枯萎的灌木盆栽生成于沙漠的会合点3；云杉树苗盆栽生成于[针叶林](针叶林.md)的石匠屋；虞美人盆栽生成在针叶林的教堂。

普通花盆和枯萎的灌木盆栽还会生成在[试炼密室](试炼密室.md)中。

# 破坏
花盆被挖掘时会立刻被破坏。

花盆被破坏后会掉落自身和内容物。

# 用途
花盆放置时可以不依附于其底部方块。花盆只能放置在大多数面中心完整的方块上，且其底部方块被移除时会掉落为物品。

花盆高格，并且生物可以站上去。玩家可以站在花盆上按下越过旁边与花盆同一Y轴高度的[墙](墙.md)、[栅栏](栅栏.md)或[栅栏门](栅栏门.md)。

花盆会被[水](水.md)流、[熔岩](熔岩.md)流和[活塞](活塞.md)破坏。

# = 盆栽 =
花盆中可以放置、、、、、、、、、以及。手持上述植物对花盆按下键将其放进花盆，对着植物盆栽按键则将该植物移除并收入物品栏。

花盆中的杜鹃花丛、仙人掌、竹子和菌索显示的纹理为原先的缩小版。

花盆中的任何植物都没有[碰撞箱](碰撞箱.md)。花盆中的仙人掌和凋灵玫瑰不具有其本身危险的特性。

[疣猪兽](疣猪兽.md)会远离诡异菌盆栽7格。<ref></ref>

[眼眸花](眼眸花.md)盆栽会像眼眸花一样[转化](花#眼眸花.md)，但盆栽之间以及眼眸花和盆栽之间不会发送[计划刻](计划刻.md)加快同向转化。
