# Java版19w09a

*页面ID: 40891* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w09a**是[Java版1.14](Java版1.14.md)的第24个快照，发布于2019年2月27日<ref></ref>，加入了新的音符盒音效和流浪商人音效，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[音符盒](音符盒.md)**
* 加入了5种新的音效：“Iron Xylophone（钢片琴）”、“Cow Bell（牛铃）”、“Didgeridoo（迪吉里杜管）”、“Bit”（八位游戏音乐或比特音乐）和“Banjo（班卓琴）”。
* * 分别可以通过使用[铁块](铁块.md)、[灵魂沙](灵魂沙.md)、[南瓜](南瓜.md)、[绿宝石块](绿宝石块.md)、[干草捆](干草捆.md)播放。
* 1个先前存在但未使用的音效现在可用：“Pling”（重音的竖琴）。
* * 可以通过使用[荧石](荧石.md)播放。

# = 常规 =
* *[声音](声音.md)**
* 加入了[流浪商人](流浪商人.md)饮用隐身药水和牛奶的音效。

# 更改
# = 方块 =
* *[石英块](石英块.md)**
* 底部一面现在使用顶部的纹理。

# = 生物 =
* *[掠夺者](掠夺者.md)**
* 现在能用[弩](弩.md)发射副手中的药箭和烟花火箭。

* *[狐狸](狐狸.md)**
* 当狐狸吃下一些食物（如[紫颂果](紫颂果.md)和[蜘蛛眼](蜘蛛眼.md)）时会受到相应的效果。
* 现在会攻击[河豚](河豚.md)和[热带鱼](热带鱼.md)了。

# = 常规 =
* *[粒子](粒子.md)**
* 粒子的图标现在可以在[资源包](资源包.md)中配置。
* * 游戏仍控制它们的使用方式，这意味着不能加入新的粒子。
