# 启动器2.2.21xx

*页面ID: 79806* | *来源: Minecraft Wiki*

* *2.2.2161**（）、**2.2.2162**（）或**2.2.2159**（）是一次[启动器](启动器.md)更新，发布于2021年3月1日。

# 更改
* 对启动器进行了一次大修，其中包含Chromium的新版本。
* 为Linux版本启动器增加了自动更新功能（类似于之前macOS和Windows中的功能）。
* 由于Chromium的更新，此版本停止支持Mac OS 10.9。

# 修复
*  - 启动器登录界面使用的Chrome版本过低。
*  - 游戏启动后直接崩溃（由OptiFine导致）。
*  -  “下界之焰”DLC新闻页的大小不正确。
*  - 标签页“开始游戏”按钮的动画会导致此按钮的功能损坏。
