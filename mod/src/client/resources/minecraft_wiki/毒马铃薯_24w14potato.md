* *毒马铃薯（Poisonous Potato）**是一种可能使玩家-{[中毒](中毒.md)}-的[食物](食物.md)类[物品](物品.md)，也是多种物品的[合成](合成.md)材料。

# 获取
# = 收成 =

毒马铃薯是收成[马铃薯](马铃薯.md)时的稀有掉落物，成熟的马铃薯有2%概率额外掉落1个毒马铃薯。使用带有[时运](时运.md)魔咒的工具破坏并不会改变其掉落数量和概率。

# = 合成 =

# = 腐败的马铃薯皮方块 =

当一个上方没有[生物](生物.md)的[腐败的马铃薯皮方块](腐败的马铃薯皮方块.md)接收到[随机刻](随机刻.md)时，有5%的概率在方块顶部生成一个随机的指定[实体](实体.md)，生成的实体为毒马铃薯物品的概率是8%，即使尝试生成的位置被完全阻挡也可以生成。

# = 挖掘 =
使用石镐或更好的[镐](镐.md)挖掘[毒马铃薯矿石](毒马铃薯矿石.md)或[深层毒马铃薯矿石](深层毒马铃薯矿石.md)会掉落1个毒马铃薯。使用时运魔咒的镐挖掘会每等级增加1的最大毒马铃薯数量，时运III最多会掉落4个毒马铃薯。

# = 薯化工具 =

使用具有[薯化](薯化.md)魔咒的物品挖掘方块后会使其有概率额外掉落毒马铃薯。

# = 交易 =
此版本中，[交易](交易.md)得到的[绿宝石](绿宝石.md)被更改为毒马铃薯。

# = 削皮 =

对[毒马铃薯方块](毒马铃薯方块.md)马铃薯削皮刀可以削下9个毒马铃薯，并将其转化为[马铃薯皮方块](马铃薯皮方块.md)。

# 用途
# = 食物 =

手持毒马铃薯按住键即可食用，每个毒马铃薯可以回复，并有60%概率获得5秒的效果（减少）。

# = 精炼材料 =
毒马铃薯可以在[马铃薯精炼炉](马铃薯精炼炉.md)中精炼出[毒马铃薯油](毒马铃薯油.md)，获得，需要。

# = 烫手洋芋 =
将毒马铃薯丢入[熔岩](熔岩.md)，可使其变为[烫手洋芋](烫手洋芋.md)。

# = 谜之炖菜 =

可以使用毒马铃薯合成后给予最多随机[状态效果](状态效果.md)的[谜之炖菜](谜之炖菜.md)，状态效果可能是[挖掘疲劳](挖掘疲劳.md)、[急迫](急迫.md)、[非常滑](非常滑.md)、[幸运](幸运.md)、[霉运](霉运.md)、[缓降](缓降.md)、[村庄英雄](村庄英雄.md)或[发光](发光.md)。

# = 激活传送门 =
对着[主世界](主世界.md)或[马铃薯维度](马铃薯维度.md)中的[传送门底座](传送门底座.md)毒马铃薯后，如果传送门底座上方是可替代的方块，则会生成[马铃薯传送门](马铃薯传送门.md)，并消耗一个毒马铃薯。
