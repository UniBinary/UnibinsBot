# 缠怨藤

*页面ID: 56259* | *来源: Minecraft Wiki*

* *缠怨藤（Twisting Vines）**是一种生成在[下界](下界.md)的[诡异森林](诡异森林.md)的可生长的植物。

是缠怨藤下方的茎杆部分。

# 生成
缠怨藤能够生成缠怨藤和缠怨藤植株（见）。

# = 自然生成 =
缠怨藤和缠怨藤植株会自然生成在[诡异森林](诡异森林.md)生物群系的[诡异疣块](诡异疣块.md)、[诡异菌岩](诡异菌岩.md)和[下界岩](下界岩.md)上。

# = 骨粉 =
对[诡异菌岩](诡异菌岩.md)[骨粉](骨粉.md)有的概率会在其上方和附近的两种菌岩上生成1格高的缠怨藤。

# 获取
缠怨藤只能通过破坏缠怨藤和缠怨藤植株获得。

# 破坏
缠怨藤和缠怨藤植株被挖掘时会立刻被破坏，用于挖掘的工具的耐久度不会下降。

没有被具有[精准采集](精准采集.md)的工具（[剪刀](剪刀.md)除外）挖掘破坏时，有33%的概率掉落1个缠怨藤，若挖掘工具具有[时运](时运.md)I则掉落缠怨藤的概率提升至55%，时运II提升至77%，时运III提升至100%。

使用具有[精准采集](精准采集.md)的工具或使用剪刀挖掘时，总是掉落1个缠怨藤。

因失去支撑方块而被破坏的缠怨藤和缠怨藤植株只有33%的概率掉落，因此获取缠怨藤时最好按照从顶部往下的顺序挖掘。

# 用途
缠怨藤可以放置在上表面[方块支撑形状](判定箱#方块支撑形状.md)完整的方块顶部。

# = 攀爬 =
站在缠怨藤或缠怨藤植株内部并按住可以爬上它。如果缠怨藤或缠怨藤植株后面有方块，按下也可以攀爬。

# = 堆肥 =
缠怨藤有50%概率将[堆肥桶](堆肥桶.md)堆肥等级增加1。

# = 生长 =

缠怨藤上方为空气方块时，它会向上生长。

自然生成的缠怨藤拥有17-25的值，玩家放置的缠怨藤拥有0-24的值，使用和放置的缠怨藤为0，该值可以使用来查看。缠怨藤生长时，新长出的缠怨藤的值增加1，缠怨藤值为25时不再生长。

当缠怨藤被破坏时，其下方的缠怨藤植株会变为随机<code>age</code>值的缠怨藤。

使用[骨粉](骨粉.md)可以加速缠怨藤生长。

# = 阻止生长 =
对着缠怨藤的顶部剪刀可使其变为25，阻止其继续生长。
