# Java版20w12a

*页面ID: 56480* | *来源: Minecraft Wiki*

<onlyinclude>

* *20w12a**是[Java版1.16](Java版1.16.md)的第7个快照，发布于2020年3月18日<ref name="20w12a"></ref>，加入了[重生锚](重生锚.md)、[磨制玄武岩](磨制玄武岩.md)和新的方块标签，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[磨制玄武岩](磨制玄武岩.md)**
* 通过烧炼普通的玄武岩获得。
* 像普通的玄武岩一样拥有xyz三种朝向，仅用于装饰。

* *[重生锚](重生锚.md)**
* 由[哭泣的黑曜石](哭泣的黑曜石.md)和[荧石](荧石.md)合成。
* 用于在[下界](下界.md)设置重生点，可使用[荧石](荧石.md)添加能量。
* 最大能量点数为4，每次重生都会消耗1点能量。
* 发出微弱的光，光照强度随着能量点数增加而增强。
* 在[主世界](主世界.md)和[末地](末地.md)使用将会导致爆炸，同时点燃周围的方块，就像在下界和末地使用床一样。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 应用于[灵魂沙](灵魂沙.md)和[灵魂土](灵魂土.md)。
* * 决定何种方块上方能够燃烧[灵魂火](灵魂火.md)。

# 更改
# = 方块 =
* *[下界金矿石](下界金矿石.md)**
* 现在可以使用任意的[镐](镐.md)来挖掘。
* 现在挖掘时会掉落2-6个[金粒](金粒.md)，而非它本身。
* * 如同其他矿石一样受[时运](时运.md)魔咒影响，当使用时运III魔咒时最大可掉落24个金粒。
* * 用精准采集获取的下界金矿石仍可以单独烧炼成1个[金锭](金锭.md)。

* *[灵魂火](灵魂火.md)**
* 现在也可以在[灵魂沙](灵魂沙.md)上燃烧。

* *[缠怨藤](缠怨藤.md)和[垂泪藤](垂泪藤.md)**
* 尝试向缠怨藤和垂泪藤所在位置放置方块时，无法再取代它们了。

# = 物品 =
* *[下界菌](下界菌.md)、[菌索](菌索.md)和[下界苗](下界苗.md)**
* 对[菌岩](菌岩.md)使用[骨粉](骨粉.md)时会在其上生长。
* * 绯红菌岩会在[绯红森林](绯红森林.md)里生长植物。
* * 诡异菌岩会在[绯红森林](绯红森林.md)和[诡异森林](诡异森林.md)里生长植物。

* *[锄](锄.md)**
* 现在可用于快速采集[海绵](海绵.md)和[湿海绵](湿海绵.md)。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 降低蜜蜂在游荡时远离蜂巢的最大距离至22格。

* *[疣猪兽](疣猪兽.md)**
* 调整攻击范围。

* *[鹦鹉](鹦鹉.md)**
* 降低了模仿敌对生物的频率。
* 不再会在和平难度下随机模仿敌对生物了。

* *[猪灵](猪灵.md)**
* 幼年猪灵现在可以坐在其他骑着[疣猪兽](疣猪兽.md)的幼年猪灵上。

# = 命令格式 =
* ***
* 现在可以在任意维度中使用了。

# = 游戏内容 =
* *[进度](进度.md)**
* 现在完成“成双成对”进度还需要繁殖疣猪兽。

* *[环境音效](环境音效.md)**
* 新的洞穴音效的氛围检测算法。
* * 氛围用于确定洞穴环境音效播放的概率。
* * 玩家在地下停留越久，氛围增长越多。
* ** 玩家所处位置的天空[光照](光照.md)和方块光照也会影响氛围。
* * 在[调试屏幕](调试屏幕.md)中可以在声音一栏中看见氛围百分比。

* *[钓鱼](钓鱼.md)**
* 钓鱼时，宝藏战利品现在只能通过在开阔水域钓鱼获得。
* * 如果满足以下条件，则认为钓鱼地点处于开阔水域：
* ** 浮漂所在位置至少需要：所在高度及下方1格共5×2×5区域以及上方5×2×5区域（即总共5×4×5的区域）内除水和[空气](空气.md)外无其他方块。
* ** 只有水源方块和没有[碰撞箱](碰撞箱.md)的含水方块，如[告示牌](告示牌.md)和[珊瑚](珊瑚.md)算作水。但是，气泡柱不算。

* *[配方书](配方书.md)**
* 告示牌的配方现在会在同一组内显示。
* 下界合金锭的配方现在会在同一组内显示。

# = 常规 =
* *[聊天](聊天.md)信息**
* 将“你的床已遗失或被阻挡”更改为“你的床或重生锚不存在或已被阻挡”。

* *[战利品表](战利品表.md)**
* 实体谓词
* * 加入了子谓词。
*
* * 检查鱼钩的属性。
* * 参数用于匹配钓鱼位置是否是开阔水域。

* *[材料](材料.md)**
* 缠怨藤和垂泪藤现在材料种类为“植物”。
* [菌光体](菌光体.md)现在材料种类为“草”。

* *[标签](Java版标签.md)**
* 方块标签不再用于设置要求的镐[品质](品质.md)。

* *[粒子](粒子.md)**
* [File:Glint.png](File:Glint.png.md)[骨粉](骨粉.md)粒子
* * 现在使用64位浮点数生成，不再是32位了。<ref></ref>
* ** 这意味着在离世界原点距离远时使用骨粉，粒子效果将在正确的位置显示，而非偏离目标位置。

* *UUID**
* NBT中存储的UUID现在以一个有4个整数的数组形式表示。
* * 示例：<code>{UUID:[I;1498693494,1027158888,1898994005,860320107]}</code>
* * 更名了一些字段：
* ** 驯服的动物、效果云实体、唤魔者尖牙和投掷物的现在是。
* ** 狐狸的现在是。
* ** 潮涌核心的现在是。
