* *滨菊（Oxeye Daisy）**是一种[小型花](小型花.md)。

# 生成

# = 自然生成 =
滨菊会在[平原](平原.md)、[向日葵平原](向日葵平原.md)、[繁花森林](繁花森林.md)、[草甸](草甸.md)、[溶洞](溶洞.md)和[深暗之域](深暗之域.md)生物群系自然生成。

滨菊也会在平原[村庄](村庄.md)中生成。

# = 骨粉 =
在可自然生成滨菊的生物群系中对[草方块](草方块.md)[骨粉](骨粉.md)后，滨菊有概率代替[矮草丛](矮草丛.md)生成。

对着不[含雪](含雪.md)的滨菊使用骨粉会出现更多的滨菊，而不会出现草丛。

# 破坏
滨菊被挖掘时会立刻被破坏。

滨菊被破坏后会掉落自身。

# 用途

# = 合成材料 =

# = 谜之炖菜 =

使用滨菊合成或喂食棕色[哞菇](哞菇.md)得到的谜之炖菜会给予玩家7s的[生命恢复](生命恢复.md)效果。

# = 堆肥 =
将滨菊放入[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数增加1。
