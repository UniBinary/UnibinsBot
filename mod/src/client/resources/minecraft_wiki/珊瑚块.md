# 珊瑚块

*页面ID: 34217* | *来源: Minecraft Wiki*

* *珊瑚块（Coral Block）**是一类固体方块，有管珊瑚块、脑纹珊瑚块、气泡珊瑚块、火珊瑚块和鹿角珊瑚块五个变种。

# 生成
# = 自然生成 =
珊瑚块会自然生成在[珊瑚礁](珊瑚礁.md)结构中，它们可以在[暖水海洋](暖水海洋.md)中被找到。

# 破坏
挖掘珊瑚块的合适工具是[镐](镐.md)。珊瑚块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，珊瑚块被破坏后将掉落为对应的失活的珊瑚块。

被具有精准采集的工具挖掘破坏时，珊瑚块被破坏后会掉落自身。

# 用途
珊瑚块只能放置在上表面完整的方块上。<ref></ref>

|珊瑚块失活的情况示意图}}

# = 种植海泡菜 =
若[海泡菜](海泡菜.md)被种在珊瑚块上，在其上施用[骨粉](骨粉.md)可以增加海泡菜的数量，并蔓延到临近的珊瑚块上。特别地，它们可以蔓延到其原有高度及其下一格，最多向外延伸两个方块的距离。这是唯一的通过种植使海泡菜再生的方法。

# = 失活的珊瑚块 =
若要使珊瑚块保持存活，要使其至少一面接触[水](水.md)或[含水](含水.md)方块，否则会在或后变成对应[失活的珊瑚块](失活的珊瑚块.md)。

如果珊瑚块的六面都不为[空气](空气.md)方块，则也能保持存活。<ref></ref>

# 你知道吗
* 珊瑚在一个开玩笑的快照[12marc40awesome](Java版提及特性#开玩笑的特性.md)中与[鱼](鱼.md)和“鱼方块”一起被提及。<ref></ref>
* 尽管在游戏里被算作植物，但在现实中珊瑚是珊瑚虫分泌的碳酸钙外壳。
* 当[玩家](玩家.md)在中[水](水.md)下放置了1000万个珊瑚块后，Mojang向[The Nature Conservancy](wikipedia:The Nature Conservancy.md)捐赠了100,000美元用于保护和恢复全世界的珊瑚礁。<ref>https://minecraft.net/article/you-helped-us-help-oceans</ref>
