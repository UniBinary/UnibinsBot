# 基岩版1.19.40.21

*页面ID: 98560* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.40.21**（Android）、**Preview 1.19.40.21**（iOS/iPadOS/Xbox/Windows）是[基岩版1.19.40](基岩版1.19.40.md)的第2个测试版，发布于2022年9月14日<ref></ref>，同步了一些的特性，并修复了一些漏洞。

# 更改
# = 方块 =
* *[泥巴](泥巴.md)**
* 现在会使其上方实体略微下陷。

* *[甜浆果丛](甜浆果丛.md)**
* 现在可以种植在[耕地](耕地.md)上。

# = 生物 =
* *[劫掠兽](劫掠兽.md)**
* 不再属于[灾厄村民](灾厄村民.md)。
* * 因此现在会受到[唤魔者尖牙](唤魔者尖牙.md)造成的伤害，且[“Johnny”卫道士](卫道士#“Johnny”卫道士.md)现在会主动攻击劫掠兽。
* 增大了碰撞箱以匹配。

# = 技术性 =
* *数据驱动方块**
* 不再公开为数据驱动方块的。方块会在使用命名空间时抛出内容日志错误。

* *GameTest框架**
* 移除了内置的GameTest行为包。

* *常规**
* 在中加入了旗标以控制方块是否可以在命令中使用。

# 修复
* *旁观模式（实验性）**
* 旁观模式玩家的水雾效果不再会被移除。（）

* *游戏内容**
* 修复了气泡柱上方的活板门中的玩家会积累摔落伤害的问题。（）

* *生物**
* 修复了攻击范围较远的生物能够穿墙攻击玩家的漏洞。（）
* 劫掠兽现在会受到唤魔者尖牙造成的伤害。
* 增大了劫掠兽的碰撞箱以匹配Java版。（、）
* 提高了劫掠兽的移动速度以匹配Java版。（）

* *用户界面**
* 修复了在携带版UI下的工作台界面中，物品方格附近的深灰色区域可能会使物品被丢弃的漏洞。
* 修复了在携带版UI下的马、驴、骡和羊驼的物品栏中，物品方格附近的深灰色区域可能会使物品被丢弃的漏洞。
* 修复了游戏规则设置为false时仍会显示死亡消息的漏洞。

* *原版趋同**
* 甜浆果丛现在可以种植在耕地上。（）
* 更改了气泡柱的推拉强度以匹配Java版。（）

* *方块**
* 土径和耕地的方块碰撞现在下调了1个纹素。（）
* 玩家现在会在灵魂沙和泥巴上下陷。（）
* 玩家在泥巴上方游泳时不再会使屏幕被覆盖住。（）
* 落在泥巴上的弹射物不再会反复抖动。（）
* 泥巴旁的部分水生和两栖生物不再会出现寻路问题。（）

* *性能与稳定性**
* 修复了使用选择器并为物品数据指定负数值时可能发生的崩溃。（）</onlyinclude>
