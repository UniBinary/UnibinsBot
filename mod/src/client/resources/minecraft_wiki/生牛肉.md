# 生牛肉

*页面ID: 6547* | *来源: Minecraft Wiki*

* *生牛肉（Raw Beef）**是一种[食物](食物.md)，可以被烹饪成[牛排](牛排.md)。

# 获取
# = 生物掉落物 =

# = 箱子战利品 =

# 用途
# = 食物 =

手持生牛肉按住键即可食用，每个生牛肉可以回复。

# = 烹饪 =
将生牛肉放入[营火](营火.md)、[烟熏炉](烟熏炉.md)或[熔炉](熔炉.md)中烹饪，可以获得牛排。

# = 狼 =
生牛肉能用来吸引、治疗或繁殖驯服的[狼](狼.md)，也可以使已驯服的幼年狼的剩余生长时间加快10%。
