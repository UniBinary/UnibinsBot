# 音乐（消歧义）

*页面ID: 13976* | *来源: Minecraft Wiki*

* *音乐（Music）**指游戏中的[音乐](音乐.md)。

* *音乐**也可以指：
* [环境音效](环境音效.md) - 在玩家在昏暗处、水下或下界的时候会被触发的一种声音。
* [音乐唱片](音乐唱片.md) - 能在[唱片机](唱片机.md)中被播放的物品。
* [Minecraft - Volume Alpha](Minecraft - Volume Alpha.md) - 于2011年3月4日发布的第一张Minecraft主题唱片。
* [Minecraft - Volume Beta](Minecraft - Volume Beta.md) - 于2013年11月9日发布的第二张Minecraft主题唱片。
* [Minecraft: Nether Update (Original Game Soundtrack)](Minecraft: Nether Update (Original Game Soundtrack).md) - Minecraft[下界更新](下界更新.md)的原声专辑。
* [Minecraft: Caves & Cliffs (Original Game Soundtrack)](Minecraft: Caves & Cliffs (Original Game Soundtrack).md) - Minecraft[洞穴与山崖](洞穴与山崖.md)更新的原声专辑。
* [Minecraft: The Wild Update (Original Game Soundtrack)](Minecraft: The Wild Update (Original Game Soundtrack).md) - Minecraft[荒野更新](荒野更新.md)的原声专辑。
* [Minecraft: Trails & Tales (Original Game Soundtrack)](Minecraft: Trails & Tales (Original Game Soundtrack).md) - Minecraft[足迹与故事](足迹与故事.md)更新的原声专辑。
* [Minecraft: Tricky Trials (Original Game Soundtrack)](Minecraft: Tricky Trials (Original Game Soundtrack).md) - Minecraft[棘巧试炼](棘巧试炼.md)更新的原声专辑。
* [Minecraft: Chase the Skies (Original Game Soundtrack)](Minecraft: Chase the Skies (Original Game Soundtrack).md) - Minecraft[追逐天空](追逐天空.md)更新的原声专辑。
* [Minecraft: Lava Chicken (Original Game Soundtrack)](Minecraft: Lava Chicken (Original Game Soundtrack).md) - [Hyper Potions](Hyper Potions.md)为Minecraft创作的原声专辑。
* [音符盒](音符盒.md) - 名字叫做“Music”的方块实体。
* [Minecraft Dungeons音乐](Minecraft Dungeons:音乐.md) - [Minecraft Dungeons](Minecraft Dungeons.md)中的音乐。
