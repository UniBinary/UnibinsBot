* *代码连接（Code Connection）**是一个允许教育工作者和学生探索，创造和体验身临其境的Minecraft世界的扩展——一切通过编写代码。

# 代码连接

# = 连接 =
代码连接会弹出一个指定的窗口，玩家可以在那里选择需要的环境。

# = 支持的平台 =
* [Code.org](https://code.org)
* [Microsoft MakeCode](https://minecraft.makecode.com)
* [Tynker](https://www.tynker.com/minecraft/learn-to-code/)
* 其他支持的平台

选择服务后，玩家就可以使用代码连接了。游戏会在玩家面前生成[智能体](智能体.md)，它可以被编程以进行各种活动，例如采矿、建造和耕种。

# 代码构建器

# = 连接 =
通过在游戏内输入命令或按键即可访问**代码构建器（Code Builder）**。

# = 支持的平台 =
* [Microsoft MakeCode](https://minecraft.makecode.com)
* Microsoft notebooks
* [Tynker](https://tynker.com/minecraft/learn-to-code)

选择服务后，玩家就可以使用代码构建器了。游戏会在玩家面前生成[智能体](智能体.md)，它可以被编程以进行各种活动，例如采矿、建造和耕种。

# 游戏内教程
游戏内教程涵盖以下主题：
* 向前走
* 使用命令移动你的智能体
* 掌握垂直运动
* 将定向运动放在一起以获得全范围
* 教导智能体移动和摧毁物品
* 农业以及自动化种植和收获
* 收集材料
* 与智能体一起建一个简单的庇护所
* 建造沙盒区域
