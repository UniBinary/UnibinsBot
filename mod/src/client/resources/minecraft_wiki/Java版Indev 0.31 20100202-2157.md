# 更改
# = 方块 =
* *[水](水.md)**
* 在水中游泳时会产生飞溅颗粒。

* *[熔岩](熔岩.md)**
* 现在会推出物品。
* 不会生成在普通主题世界的表面。

* *[TNT](TNT.md)**
* 现在会对[生物](生物.md)造成伤害。
* * [掉落物](掉落物.md)仍然不会被TNT摧毁。
* 会推开[实体](实体.md)。

* *[矿石](矿石.md)和[石头](石头.md)**
* 现在不需要用镐来开采了，尽管用镐会更快一些。
* * 现在又可以使用除镐以外的其他工具来开采与石头有关的方块了。
* * 矿物块（煤炭、金、钻石）与它们对应的矿石性质相似。

* *常规**
* 硬度更大的方块不再需要更好的工具。

# = 物品 =
* *[工具](工具.md)**
* 降低了在水下或在空中破坏方块的速度。
* 降低了[剑](剑.md)的伤害。
* 可以使用开采工具攻击生物，造成的伤害取决于工具的种类和品质。

* *常规**
* 重新加载存档后物品不再会进入到隐藏的[物品栏](物品栏.md)槽位。

# = 生物 =
* *[人类](生物（已移除实体）.md)**
* 无法自然生成，现在只能使用Mod或地图编辑器来生成。
* 在加载世界时不再生成保存到世界内的生物。

# = 非生物实体 =
* *[箭](箭.md)**
* 更改了[箭](箭.md)和掉落物的拾取动画。
* * 它们会在[玩家](玩家.md)靠近时被吸起来。

* *[掉落物](掉落物.md)**
* 不会被[火](火.md)或熔岩摧毁了。
* 现在会产生阴影。

# 修复
* *修复了2个漏洞**
* 花在生成时，它们的下方不再会变成泥土。
* 玩家的-{}-头处于非固体方块中时不再产生雾。</onlyinclude>
