# 命令/kick

*页面ID: 39788* | *来源: Minecraft Wiki*

}}

将玩家踢出服务器。

# 语法
* **Java版**
  <code>kick <targets> [<reason>]</code>

* **基岩版**
  <code>kick <name: target> <reason: message></code>

# 参数

   指定要踢出的玩家。

   也可以是玩家的XUID（Xbox UID）。

   指定将显示给被踢出玩家的消息。若未指定则使用默认消息“”。


# 结果

</ref>|N/A|success}}

# 输出

# 示例
* 踢出名为player的玩家：<code>/kick player</code>
* 踢出名为player的玩家，原因为“违反服务器规则”：<code>/kick player 违反服务器规则</code>
* 踢出XUID为“123456”的玩家：<code>/kick "123456"</code>
