# 裂纹石砖

*页面ID: 98577* | *来源: Minecraft Wiki*

* *裂纹石砖（Cracked Stone Bricks）**是[石砖](石砖.md)制作的装饰性方块。

# 生成
# = 自然生成 =
裂纹石砖会生成在[要塞](要塞.md)、[海底废墟](海底废墟.md)、[雪屋](雪屋.md)地下室、[主世界](主世界.md)的部分[废弃传送门](废弃传送门.md)和[古迹废墟](古迹废墟.md)中。

# 获取
# = 烧炼 =

# = 虫蚀裂纹石砖 =
被具有[精准采集](精准采集.md)的工具挖掘破坏时，[虫蚀裂纹石砖](虫蚀裂纹石砖.md)被破坏后会掉落裂纹石砖，不会生成蠹虫。

# 破坏
挖掘裂纹石砖的合适工具是镐。裂纹石砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

裂纹石砖被破坏后会掉落自身。

# 用途
# = 蠹虫 =
[蠹虫](蠹虫.md)能够进入裂纹石砖并隐藏起来，使之变成一个[虫蚀裂纹石砖](虫蚀裂纹石砖.md)。

# 你知道吗
* 当烧炼[圆石](圆石.md)来修复[石头](石头.md)的裂纹时，裂开的石头会变成平滑的。但当[烧炼](烧炼.md)没有裂缝的普通石砖时，它们会变成破裂的变种。这可能参考了2个不同的过程：当[岩石](wzh:岩石.md)受热膨胀时，会导致[裂纹](wikipedia:Fracture (geology).md)的产生，而这会让石砖裂开；而另一种只是简单地烧炼圆石，因此它变回[火成岩](wzh:岩浆岩.md)。
