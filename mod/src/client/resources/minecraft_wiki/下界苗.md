# 下界苗

*页面ID: 54710* | *来源: Minecraft Wiki*

* *下界苗（Nether Sprouts）**是一种生成于[诡异森林](诡异森林.md)生物群系的非固体植物方块。

# 生成
# = 自然生成 =
下界苗自然生成于[诡异森林](诡异森林.md)生物群系。

# = 骨粉 =
对[诡异菌岩](诡异菌岩.md)[骨粉](骨粉.md)有概率会在其上方和附近的两种菌岩上生成下界苗。

# 获取
下界苗只能通过破坏下界苗获得。

# 破坏
下界苗被挖掘时会立刻被破坏。

没有被剪刀挖掘破坏时，下界苗被破坏后不会掉落。

被剪刀挖掘破坏时，下界苗被破坏后会掉落自身。

# 用途
下界苗可放置在[菌岩](菌岩.md)、[灵魂土](灵魂土.md)、[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。

# = 堆肥 =
将下界苗放入堆肥桶中有50%的概率将堆肥层数增加1。
