# 西瓜片

*页面ID: 6661* | *来源: Minecraft Wiki*

* *西瓜片（Melon Slice）**是一种能被[玩家](玩家.md)食用的[食物](食物.md)。

# 获取
# = 掉落物 =

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[西瓜](西瓜.md)被破坏后会掉落3-7个西瓜片。用手、使用工具或被[活塞](活塞.md)移动破坏后，平均每个西瓜可得到5片西瓜片。使用附有[时运](时运.md)魔咒的工具破坏会额外等概率掉落0-<魔咒等级>个西瓜片，但掉落总数不会超过9个。

# 用途
# = 食物 =

手持西瓜片按住键即可食用，每个西瓜片可以回复。

# = 合成材料 =

# = 堆肥 =
西瓜片有50%概率将[堆肥桶](堆肥桶.md)堆肥等级增加1。
