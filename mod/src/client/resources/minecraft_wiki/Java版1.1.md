# Java版1.1

*页面ID: 15029* | *来源: Minecraft Wiki*

* *1.1**是的一次主要更新，发布于2012年1月12日<ref></ref>，加入了[刷怪蛋](刷怪蛋.md)、[超平坦](超平坦.md)世界类型、[沙滩](沙滩.md)以及对多种[语言](语言.md)的支持。

# 新内容
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 时生成一个[生物](生物.md)。
* 有20种刷怪蛋，分别产生其各自的生物。
* * 种类有[哞菇](哞菇.md)、[苦力怕](苦力怕.md)、[骷髅](骷髅.md)、[蜘蛛](蜘蛛.md)、[僵尸](僵尸.md)、[史莱姆](史莱姆.md)、[恶魂](恶魂.md)、[村民](村民.md)、[僵尸猪人](僵尸猪人.md)、[末影人](末影人.md)、[猪](猪.md)、[洞穴蜘蛛](洞穴蜘蛛.md)、[绵羊](绵羊.md)、[蠹虫](蠹虫.md)、[牛](牛.md)、[烈焰人](烈焰人.md)、[鸡](鸡.md)、[岩浆怪](岩浆怪.md)、[鱿鱼](鱿鱼.md)和[狼](狼.md)。
* 为仅限于[创造模式](创造模式.md)的物品。

# = 世界生成 =
* *[生物群系](生物群系.md)**
*
* * 在[Beta 1.8](Java版Beta 1.8.md)的移除后重新添加了沙滩。
* ** 现在是独立的[生物群系](生物群系.md)而非原先的[地形特征](地形特征.md)了。

*
* * [沙漠](沙漠.md)的丘陵变种。

*
* * 生成在[山地](山地.md)的边缘。

*
* * [森林](森林.md)的丘陵变种。

*
* * [针叶林](针叶林.md)的丘陵变种。

* *[超平坦](超平坦世界.md)**
* 世界类型的选项。
* 超平坦完全由[草方块](草方块.md)、[泥土](泥土.md)以及[基岩](基岩.md)组成。

# = 游戏内容 =
* *[附魔](附魔.md)**
* 加入了4个新的魔咒：[](力量（魔咒）.md)、[冲击](冲击.md)、[火矢](火矢.md)和[无限](无限.md)。

# = 常规 =
* *[语言](语言.md)**
* 56种新的语言。
* 这其中包括一些虚构的语言，比如说海盗语、克林贡语，以及昆雅语。

* *[server.properties](server.properties.md)**
* 新的设置：
* * <code>level-type</code>
* * <code>spawn-npcs</code>
* * <code>generate-structures</code>

# 更改
# = 方块 =
* *[梯子](梯子.md)**
* 移除了[碰撞箱](碰撞箱.md)。

* *[栅栏门](栅栏门.md)**
* 现在栅栏门的碰撞箱与[栅栏](栅栏.md)相同。
* [栅栏门](栅栏门.md)现在可以用[红石](红石.md)控制。

* *[橡树树叶](橡树树叶.md)**
* 橡树树叶现在有的概率掉落[苹果](苹果.md)。

* *[西瓜](西瓜.md)和[南瓜](南瓜.md)**
* 西瓜和南瓜现在还可以在[泥土](泥土.md)上生长,而不仅仅是[耕地](耕地.md)上。

* *[耕地](耕地.md)**
* 耕地只能被玩家在耕地上跳跃或掉落造成踩踏，走上耕地不再造成踩踏。其他生物也同样只能通过跳跃而不是走上去踩踏耕地。

# = 物品 =
* *[弓](弓.md)**
* 弓现在可以被[附魔](附魔.md)了。

* *[箭](箭.md)**
* 现在燃烧的箭会点燃射中的实体。

* *[金苹果](金苹果.md)**
* 现在[金苹果](金苹果.md)使用[金粒](金粒.md)合成而不是[金锭](金锭.md)。
* 现在金苹果会恢复[饥饿值](饥饿值.md)并提供5秒[生命恢复](生命恢复.md)。

* *[小麦](小麦.md)**
* 现在小麦吸引生物的距离从2~3个方块增加到8~9个方块。

* *[音乐唱片](音乐唱片.md)**
* 现在所有唱片除音乐唱片11外均可在[苦力怕](苦力怕.md)被[骷髅](骷髅.md)射杀后掉落。

# = 生物 =
* *[生物AI](生物AI.md)**
* 改进了生物AI。
* * 允许比以前更复杂的行为。
* * 这些行为还未被使用。

* *[绵羊](绵羊.md)**
* 现在绵羊会通过吃草来恢复羊毛。
* 现在每次剪羊毛会掉落1-3个羊毛。

* *[岩浆怪](岩浆怪.md)**
* 现在岩浆怪会掉落[岩浆膏](岩浆膏.md)。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 相较于先前平坦的地形,现在有更多样化的海拔。
* 生物群系之间草、树叶和水的颜色过渡更加平滑。
* 现在[针叶林](针叶林.md)有雪和冰。

* *[村庄](村庄.md)**
* 现在每一个铁匠铺都会有一个装着东西的箱子。

# = 游戏内容 =
* *[酿造](酿造.md)**
* 酿造时间从30秒减少为20秒。

* *[附魔](附魔.md)**
* 缩小附魔等级的可能性。

* *[虚空](虚空.md)**
* 移除创造模式虚空的迷雾。

# = 常规 =
* *[服务器](服务器.md)**
* 非管理员玩家如果在聊天里过多的滥发消息将会被服务器自动踢出。
* 这不会通知被踢出的玩家，所以管理员必须提醒玩家滥发消息将会被自动踢出。

# 修复
* *修复了3个漏洞**
* 修复了“狙击手的对决”成就无法达成的问题。
* 修复了动力铁轨不降低红石能量的问题。
* 修复了动力铁轨在放置时不更新的问题。
