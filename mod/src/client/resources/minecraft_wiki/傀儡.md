# 傀儡

*页面ID: 9675* | *来源: Minecraft Wiki*

* *傀儡（Golem）**可以指：

# Minecraft
*  - 一种友好生物，可使用[雪块](雪块.md)和[雕刻南瓜](雕刻南瓜.md)制作。会主动向敌对生物扔[雪球](雪球.md)。
*  - 一种友好生物，在[村庄](村庄.md)自然生成，也可使用[铁块](铁块.md)和雕刻南瓜制作。会主动攻击大部分敌对生物和[声望](声望.md)过低的玩家。
*  - 一种友好生物，可使用[铜块](铜块.md)和雕刻南瓜制作。它是在[Minecraft Live 2021](Minecraft Live 2021.md)生物投票活动中的落选生物。
*  - 愚人节玩笑版本[15w14a](15w14a.md)加入的一种友好生物，和铁傀儡的行为类似。

# = 提及特性 =
*  - 在[Minecraft Live 2022](Minecraft Live 2022.md)生物投票活动中的落选生物。

# Minecraft Dungeons
*  - 一种被动生物，使用[傀儡用具](MCD:傀儡用具.md)召唤。会主动攻击敌对生物。
*  - 一种被动生物。用来解开锁住的门。
*  - 在[红石矿山](MCD:红石矿山.md)中为最终Boss，在其他关卡中作为小Boss。
*  - [嚎风山巅](MCD:嚎风山巅.md)DLC的敌对生物。
*  - 嚎风山巅DLC的最终Boss。
* [铁傀儡披风](Minecraft Dungeons:披风.md)

# Minecraft Earth
*  - 一种中立的功能性生物，可通过[可点击物](MCE:可点击物.md)获取。会主动向攻击型生物射出[瓜籽弹](MCE:瓜傀儡#瓜籽弹.md)。
*  - 一种中立的功能性生物，可通过可点击物获取。会主动攻击敌对生物。

# Minecraft Legends

*  - 一种友好生物，可对敌方建筑造成较大伤害。
*  - 一种友好生物，攻击会对敌方生物造成眩晕效果。
*  - 一种被动生物，会释放治愈友方生物的水流。
*  - 一种友好生物，会射出箭矢进行攻击。
