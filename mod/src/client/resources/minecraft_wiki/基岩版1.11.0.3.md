# 基岩版1.11.0.3

*页面ID: 40895* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.11.0.3**是[1.11.0](基岩版1.11.0.md)的第2个测试版，发布于2019年2月28日<ref></ref>，修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[袭击](袭击.md)**
* 为袭击加入了Boss血量条。
* * 目前为临时样式，在随后的版本会进行更换。

# = 命令格式 =
* ***
* 开启或关闭诸如[袭击](袭击.md)、[灾厄巡逻队](灾厄巡逻队.md)的事件发生和[流浪商人](流浪商人.md)的生成。

# 更改
# = 方块 =
* *[制箭台](制箭台.md)和[锻造台](锻造台.md)**
* 不再属于实验性玩法。

* *[钟](钟.md)**
* 更改了纹理。

* *[平滑石英块](平滑石英块.md)和[雕纹石英块](雕纹石英块.md)**
* 不再能横向放置。

# = 物品 =
* *[甜浆果](甜浆果.md)**
* 不再属于实验性玩法。

# = 生物 =
* *[猫](猫.md)**
* 现在会根据村庄中床的数量重新生成。
* * 每四张[床](床.md)会使猫的生成上限增加1。
* * 每个村庄最多生成5只猫。

* *[劫掠兽](劫掠兽.md)**
* 不再属于实验性玩法。

* *[行商羊驼](行商羊驼.md)**
* 不再能被喂养。
* 不再能作为幼年羊驼生成。
* 现在会对与它们的主人敌对的生物啐唾沫。
* * 玩家的攻击会激怒羊驼，但不会使流浪商人逃跑。

* *新[村民](村民.md)**
* 不再属于实验性玩法。
* 现在将会在早晨起床时被治疗。

* *[流浪商人](流浪商人.md)**
* 现在腿部纹理是对称的。
* 现在会在黄昏时喝下[隐身药水](隐身药水.md)。
* 现在会在逃离攻击型生物、被弹射物或魔法攻击时喝下一瓶隐身药水。
* 现在会在玩家手持绿宝石时展示它们愿意进行交易的物品。

* *新[僵尸村民](僵尸村民.md)**
* 不再属于实验性玩法。

# = 结构生成 =
* *[掠夺者前哨站](掠夺者前哨站.md)和新[村庄](村庄.md)**
* 不再属于实验性玩法。

# = 游戏内容 =
* *[状态效果](状态效果.md)**
* 更改了和效果的图标。
* [漏斗](漏斗.md)现在可以与[堆肥桶](堆肥桶.md)互动。
* 喷溅水瓶现在可用来扑灭[营火](营火.md)。

* *[袭击](袭击.md)**
* 现在玩家能通过在拥有状态效果时进入村庄来引发袭击。
* * 现在玩家在杀死一个[灾厄队长](灾厄队长.md)时将会得到不祥之兆效果。
* 袭击状态将被定时读取和储存。
* 袭击中生成的劫掠兽有时会被一个掠夺者或卫道士骑乘。
* 现在游戏使用“dweller component”来引导参与袭击的生物，即使当它们被卸载时也是如此。
* 袭击中生成的掠夺者、卫道士、女巫和劫掠兽将根据“dweller component”的指示向它们的目标村庄前进。

# 修复
* *修复了40个漏洞**<br>
* *崩溃**
* Windows 10版启动游戏时游戏崩溃。（）
* 修复了游戏进行时的崩溃现象。
* 对着下界传送门方块使用“选取方块”键时使得游戏崩溃。（）
* 给予玩家墙的变种使得游戏崩溃。（）
* Xbox One版里登入或登出Xbox Live账户时游戏崩溃。
* 连接服务器时，取消暂停游戏使得游戏崩溃。
* 在西瓜茎或南瓜茎上面践踏时游戏崩溃。
* 安卓设备里暂停或继续游戏时游戏崩溃。

* *常规**
* Xbox One版里已经登入的玩家仍然会受到要求登入的提示信息。
* 生成世界时，玩家卡进地里并窒息而亡。（）

* *游戏内容**
* 玩家现在能正确进入末地传送门里而不会导致窒息或者无法生成地形。（和）
* 无法采摘甜浆果。（和）
* 无法烧炼平滑石头。（）
* 烧炼平滑石头不会给予经验值。（）
* 在床上放置台阶或楼梯后，村民不再将床视作可用。
* 使用VR设备时，取消游泳会使得玩家进入飞行状态。（）
* 附有精准采集的工具在耐久度只剩下1点时无法采集方块。（）
* 杀死袭击队长不会给予玩家不祥之兆效果。（）

* *世界生成**
* 修复了村庄的大部分生成漏洞：
* * 建筑里缺失完整的梯子。
* * 地下室生成不正确。
* * 类似于雪屋的房子生成不正确。
* * 房子的地板缺失方块。
* * 圈养的动物不再能离开围栏。

* *生物**
* 下雨时，村民现在可以在室内工作。
* 袭击生物在寻找村庄时不再卡住不动。
* 袭击队长不再能离开前哨站来追逐玩家。
* 流浪商人现在可以手持感兴趣的交易物品。
* 生物在离开船时，朝向不正确。（）
* 由僵尸转变而来的溺尸不会攻击玩家。
* 村民会卡在灯笼里。

* *方块**
* 珊瑚和海草的支撑方块被移除后现在会随之破坏。
* 盔甲架和砂轮不能合成。（）
* 平滑和雕纹石英块放置时不再有朝向。（）

* *图形**
* 钟的纹理不正确。
* 流浪商人的腿部纹理不对称。

* *用户界面**
* 在物品栏或合成网格里的物品现在可以正确拆分。（）
* Xbox One版里使用书与笔时，键盘输入不再导致文本被覆盖。

* *命令**
* 命令提示里的图标出现偏移。（）

* *附加包和脚本引擎**
* 使用命令将物品放置在副手槽时，现在会取决于选择器参数。</onlyinclude>
