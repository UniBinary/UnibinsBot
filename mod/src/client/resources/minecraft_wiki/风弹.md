* *风弹（Wind Charge**，下文称**风弹物品）**是一种时能发射出风弹弹射物的物品。

* *风弹（Wind Charge**，下文称**风弹弹射物）**是一种能够产生[风爆](爆炸#风爆.md)并对实体造成轻微伤害的[弹射物](弹射物.md)。有两种同名实体使用此名称：
* <code>wind_charge</code>：由风弹物品发射的风弹，具有较小爆炸威力和较强击飞效果，下文称**风弹物品风弹**。
* <code>breeze_wind_charge</code>：由[旋风人](旋风人.md)发射的风弹，具有较大爆炸威力和较弱击飞效果，下文称**旋风人风弹**。

# 生成
[玩家](玩家.md)或[发射器](发射器.md)使用风弹物品会朝面向的方向发射风弹物品风弹。[不祥试炼刷怪笼](不祥试炼刷怪笼.md)也有概率在周围[生物](生物.md)头顶丢掷风弹物品风弹。

[旋风人](旋风人.md)会向攻击目标发射旋风人风弹。

# 用途
[发射器](发射器.md)或[玩家](玩家.md)风弹可以朝着面向的方向发射风弹。

玩家使用风弹会引发的风弹物品冷却时间，期间受影响玩家不可使用风弹。

# 行为
风弹是一种[弹射物](弹射物.md)，可以触发[标靶](标靶.md)，並拥有不受重力影响且无限远的直线弹道。

风弹可以被其他弹射物击中或玩家使用近战攻击让它们转向。当风弹与另一个风弹或[火球](火球.md)相撞时，其中一个风弹或火球的移动会偏移到随机方向，而另一个会爆炸。

静止的风弹与[实体](实体.md)碰撞不会发生爆炸，且可以通过近战攻击和风弹以外的弹射物使之重新开始运动。

# = 着火 =
风弹可以[着火](着火.md)。风弹在穿过[火](火.md)或[熔岩](熔岩.md)会着火，穿过[雨](雨.md)、[水](水.md)或[细雪](细雪.md)时会熄灭。着火的风弹会点燃其命中的实体。

着火的风弹会不受阻碍地穿过[TNT](TNT.md)并使其激活，可以点燃熄灭的[营火](营火.md)，可以破坏其穿过的[细雪](细雪.md)。

# = 造成爆炸 =
风弹与方块的碰撞箱碰撞，或是与除其他风弹和[末地水晶](末地水晶.md)以外的实体碰撞时会造成[风爆](爆炸#风爆.md)。该爆炸可以击退生物、更改[特定方块的方块状态](#与方块交互.md)，但不破坏方块、不具有爆炸伤害。

旋风人风弹造成威力为3的风爆。风弹物品风弹造成威力为1.2的风爆，且造成实体击退的速度增加10%。

风弹物品风弹造成的风爆会给予玩家伤害减免效果，只有从该玩家上一次受到风爆起的[下落高度](摔落#下落高度.md)才会计算摔落伤害。旋风人风弹造成的风爆会清除摔落伤害减免效果。
风爆本身不会重置实体的下落高度，但如果它能影响玩家向上运动，玩家的下落高度也会被重置。

当风弹高于所在维度的[最高建筑高度](高度#建筑高度限制.md)30格以上时会立刻爆炸。

# = 造成伤害 =
风弹直接击中实体时，会对其造成伤害。

使用[盾牌](盾牌.md)可以抵挡风弹造成的直接伤害，且不会消耗耐久度。但盾牌无法阻止[风爆](爆炸#风爆.md)，也无法消除由此带来的击退效果。

# = 与方块交互 =
风弹可以触发其接触的[标靶](标靶.md)，敲响[钟](钟.md)，激活[木质压力板](木质压力板.md)和[绊线](绊线.md)，使[大型垂滴叶](大型垂滴叶.md)倾斜，以及破坏[紫颂花](紫颂花.md)和[饰纹陶罐](饰纹陶罐.md)。

风弹造成的风爆还可以更改下列方块的[方块状态](方块状态.md)，模拟“被风吹动”的效果：
* 开关和
* 开关和
* 开关
* 按下
* 开关
* 敲响
* 熄灭和
