# Minecraft: The Lost Journals

*页面ID: 42705* | *来源: Minecraft Wiki*

* **Minecraft: The Lost Journals***（中国大陆译作“**我的世界：失落的日记**”）是第3部Minecraft小说，作者是[Mur Lafferty](wikipedia:Mur Lafferty.md)，由[Del Rey Books](wikipedia:Del Rey Books.md)出版。它于2019年7月9日发布。<ref>https://www.amazon.com/Minecraft-Lost-Journals-Mur-Lafferty/dp/0399180699</ref>有声读物预定在同一天发行，由[Emily Shaffer](wikipedia:Emily Shaffer.md)朗读。<ref>https://www.penguinrandomhouse.com/books/552069/minecraft-the-lost-journals-by-mur-lafferty/9780399180699/</ref>其简体中文版由王翼瑞和丁卓祥翻译。

由人民邮电出版社发行的简体中文版小说在2020年10月1日发布，可在[此处](https://item.jd.com/13026344.html)购买。

# 概要
马克斯和艾莉森证明差异不能阻挡友情。马克斯总是尝试新的冒险，尽管会制造麻烦；艾莉森则比较墨守成规。然而他们两个都被马克斯发现的旧日记的秘密作家附魔师（Enchanter）所描述的奇怪的门所着迷：一个通往另一个称为下界的危险境界的传送门。

在他们参考日记来搭建好传送门后，马克斯和艾莉森争论着他们是否应该待在安全的主世界，还是进入到下界来寻找那位附魔师……直到一个改变命运的偶然事件帮他们做出了决定。

两位主人公被困在了恐怖的新世界，遇到了一位名为弗雷娅的帮手。弗雷娅是一个凶悍的战士，和她心爱的狼“狂咬兔兔”在下界中相依为命。在她的帮助下，他们找到了神秘日记背后的线索。从此，他们走上了寻找附魔师的征程，而下界会不断挑战他们的能力和友谊。
