# 携带版0.10.0.b9

*页面ID: 28506* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.10.0 alpha build 9 (RC1)**是[v0.10.0 alpha](携带版0.10.0.md)的第9个测试版，发布于2014年11月11日，修复了一些漏洞。

# 更改
# = 方块 =
* *[床](床.md)**
* 现在放置时可以替换原有的高[草丛](草丛.md)。

# 修复
* *修复了5个漏洞**
* 快捷栏内不会显示部分的方块和物品的图标。
* 打开多人游戏世界里的箱子或熔炉时，关闭服务器会导致客户端崩溃。
* 多人游戏世界里部分实体出现渲染漏洞。
* 客户端世界内的门在打开或关闭时出现漏洞。
* 打开箱子的动画丢失。</onlyinclude>
