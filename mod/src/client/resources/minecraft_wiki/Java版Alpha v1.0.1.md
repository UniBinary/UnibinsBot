# Java版Alpha v1.0.1

*页面ID: 32478* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.1**是的一次[秘密更新](秘密更新.md)，发布于2010年7月2日<ref></ref><ref></ref>，加入了红石相关方块，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[铁门](铁门.md)**
* 一种功能性方块。
* 收到红石信号时会打开。
* 可由6个[铁锭](铁锭.md)合成。

* *[拉杆](拉杆.md)**
* 一种功能性方块。
* 拉下拉杆时会发出红石信号。
* 可由1个[木棍](木棍.md)和1个[圆石](圆石.md)合成。

* *[红石线](红石线.md)**
* 一种功能性方块。
* 可通过放置[红石粉](红石粉.md)来生成。

* *[红石矿石](红石矿石.md)**
* 自然生成在世界中。
* 被破坏会掉落红石粉。

* *[红石火把](红石火把.md)**
* 一种功能性方块。
* 用于提供红石信号。
* 提供一定等级的亮度。
* 可由1个木棍和1个红石粉来合成。

* *[按钮](按钮.md)**
* 加入了石质按钮。
* * 可由2个圆石合成。
* 一种功能性方块，用于发出红石信号。

* *[压力板](压力板.md)**
* 加入了木质和石质压力板。
* * 可分别由3个[木板](木板.md)或圆石合成。
* 有实体在其上方时会发出红石信号。

# = 物品 =
* *[红石粉](红石粉.md)**
* 可放置为红石线。

# 更改
# = 方块 =
* *[楼梯](楼梯.md)**
* 更改了物品栏中的模型，现在是3D的。

* *[木门](木门.md)**
* 更改了其物品纹理。

* *[蘑菇](蘑菇.md)**
* 会在任意区域生成。
* 如果在阳光下生成，它会在一段时间后掉落。
* * 暗处生成的蘑菇不会掉落。

* *[告示牌](告示牌.md)**
* 现在可以放置在[方块](方块.md)的侧面。

* *[刷怪笼](刷怪笼.md)**
* 被开采后不再掉落自身。

* *[熔炉](熔炉.md)**
* 开采燃烧的熔炉现在只会掉落一个普通的熔炉。

* *[齿轮](齿轮.md)**
* 现在被红石代替。
* * 之前版本的世界中的所有齿轮都会变成红石线或掉落成为红石粉。

# = 生物 =
* *常规**
* 改进了[生物](生物.md)AI。

# = 世界生成 =
* *[洞穴](洞穴.md)**
* 变得比原来更大。

* *[团簇](团簇.md)**
* [煤](煤.md)矿团现在会以随机大小生成。</onlyinclude>
