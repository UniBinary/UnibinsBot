* *灵魂火（Soul Fire）**是蓝色的类似[火](火.md)的方块，存在于[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)<ref group="注">该特性由标签控制。</ref>的上方。

# 生成
# = 火 =

任何方式将要在一个下方是[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)的位置放置[火](火.md)时，会改为放置灵魂火。

火下方的方块变为灵魂沙或灵魂土时，会转变为灵魂火。

# = 自然生成 =
灵魂火以[随机斑块](随机斑块.md)的形式在[灵魂沙峡谷](灵魂沙峡谷.md)中生成。

灵魂火也会自然生成于[远古城市](远古城市.md)中心雕像的底部和营房中。

# 获取
灵魂火没有对应的方块物品。

灵魂火的方块物品只能通过编辑物品栏获得。

# 破坏
灵魂火被挖掘时会立刻被破坏。[剪刀](剪刀.md)用于挖掘灵魂火时，耐久度不会下降。

灵魂火被破坏后不会掉落。

# 用途
灵魂火几乎没有任何更新行为，不会传播火或灵魂火、不会烧毁方块、不会自行熄灭。[蜂箱](蜂箱.md)或[蜂巢](蜂巢（方块）.md)与灵魂火相邻不会导致[蜜蜂](蜜蜂.md)逃离该方块。

灵魂火没有任何有效的方块状态。灵魂火仅有在方块上方的外观，不具有在方块侧面或下面的外观。

灵魂火会在下方不是[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)时消失，即使毗邻可燃方块也不会转变为火。

[水](水.md)和[熔岩](熔岩.md)在流动时会冲毁沿途的灵魂火。在灵魂火方块的位置放置方块也能将灵魂火取代掉。

[喷溅型水瓶](喷溅型水瓶.md)和[滞留型水瓶](滞留型水瓶.md)会扑灭范围内的灵魂火。

# = 光源 =
灵魂火发出亮度为10级的光，不能融化[冰](冰.md)或[雪](雪.md)。

# = 伤害实体 =
灵魂火会对身处其中的实体持续造成火焰伤害。

[僵尸猪灵](僵尸猪灵.md)、[恶魂](恶魂.md)、[凋灵骷髅](凋灵骷髅.md)、[烈焰人](烈焰人.md)、[炽足兽](炽足兽.md)、[岩浆怪](岩浆怪.md)、[潜影贝](潜影贝.md)、[僵尸疣猪兽](僵尸疣猪兽.md)、[监守者](监守者.md)、[末影龙](末影龙.md)、[凋灵](凋灵.md)、绑定[嘎枝之心](嘎枝之心.md)的[嘎枝](嘎枝.md)、[下界合金质物品实体](物品（实体）.md)和具有[抗火](抗火.md)效果的生物不会受到灵魂火造成的火焰伤害。

# = 使实体着火 =

生物在接触到灵魂火时，其**剩余着火时间**会持续增加，无视生物的具有[火焰保护](火焰保护.md)魔咒的盔甲。
* 当生物处于灵魂火中时，剩余着火时间不会下降。
* 当生物的剩余着火时间不高于0时，剩余着火时间将会每增加。
* 当生物的剩余着火时间高于0时，剩余着火时间将会每增加。
* 当生物在灵魂火中移动时，剩余着火时间将会额外每增加。

一旦生物的剩余着火时间高于0，其剩余着火时间将被设置为至少，该效果受到[火焰保护](火焰保护.md)魔咒的影响。

# = 猪灵 =
灵魂火可以驱离非战斗状态的[猪灵](猪灵.md)。

# = 激活下界传送门 =

在合法的下界传送门框架内生成灵魂火可以将其激活。目前这只可能通过做到。

# 你知道吗
* 灵魂火的外焰和内焰使用两种不同的纹理。
* 蓝色的灵魂火对应现实中硫燃烧产生的火焰。能生成灵魂火的方块——灵魂土和灵魂沙，可能对应现实中通常含大量硫元素的火山灰。
* 降雨时露天的灵魂火无法烧毁[经验球](经验球.md)。
