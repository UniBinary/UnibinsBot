# 经验

*页面ID: 7121* | *来源: Minecraft Wiki*

* *经验（Experience）**是[玩家](玩家.md)在战斗和生产活动中获得的可消耗资源，由**经验值（Experience Point, EXP, XP）**和**经验等级（Experience Level）**构成，能被消耗并用于改造[物品](物品.md)。

# 监测

[缩略图|玩家的HUD，其中包含一个横跨整个界面的经验条](File:Hotbar with xp.png.md)
经验的测量和监控基于经验条，后者是一个进度条外观的黄绿色长条。

# 机制
经验值可经由各种途径获得，包括[挖矿](挖矿.md)、[烧炼](烧炼.md)、杀死或[繁殖](繁殖.md)生物、[钓鱼](钓鱼.md)、使用[砂轮](砂轮.md)移除[魔咒](魔咒.md)、使用[附魔之瓶](附魔之瓶.md)。与大部分游戏类似，经验值的积累会获得经验等级的提升；但不同之处在于，经验等级的提升不会直接给予玩家角色的能力提升。经验值是一种可消耗资源，经验等级消耗在[附魔台](附魔台.md)和[铁砧](铁砧.md)上，用于制作和[修复](修复.md)具有各种特殊能力的[武器](武器.md)、[盔甲](盔甲.md)和[工具](工具.md)。

当玩家的经验值达到了下一等级的需求时，玩家的经验等级就会提升。[游戏规则](游戏规则.md)为<code>false</code>时，玩家死亡后会掉落“经验等级×7”点经验，最高不超过100点，其余的经验值会遗失。

玩家每升级到一个为5的整倍数的等级，一段特殊的升级音效会播放。

# 经验球

绝大多数获取经验值的方式，都是通过[经验球](经验球.md)来提供。

# 经验值来源
经验可以通过多个不同的来源获得。大多数经验以[经验球](经验球.md)的形式被玩家所获，任何玩家都可以领取这些经验，而少数经验在完成动作时被直接奖励给玩家。

用于提供经验值的经验球可经由几种不同的途径获得：
* 杀死[生物](生物.md)。
* * 生物死亡时，若其死亡前内受到过[伤害来源](伤害来源.md)为玩家或/的伤害，则会掉落对应数量的经验球。因此，以下情况也可以掉落经验球：
* **将怪物击落山崖并将其摔死。
* **对燃烧的怪物进行合适时机的攻击，使其在5秒内烧死（[火](火.md)5秒只会造成最多的伤害，不过玩家也可以反复攻击）。
* * 经验球会和掉落物同时生成在生物被杀死的位置。
* * 掉落物会生成在生物被击杀的位置，但经验球在生物实体消失且烟雾出现之前不会出现。
* * 若炸死生物的[TNT](TNT.md)是玩家通过使用[打火石](打火石.md)、[火焰弹](火焰弹.md)或点燃的，则掉落经验球；但由火、红石信号和非玩家导致的爆炸而引燃的TNT不会带来任何经验球。
* * 生物掉落的经验球数量是随机的，且这些经验球的价值也会有所不同。但是，生物掉落的总经验值是给定的，且不受[游戏难度](游戏难度.md)的影响。
* * 敌对生物掉落的经验值通常比友好生物多。幼年动物（幼年[疣猪兽](疣猪兽.md)除外）、[悦灵](悦灵.md)、[蝙蝠](蝙蝠.md)、[铁傀儡](铁傀儡.md)、[雪傀儡](雪傀儡.md)、[铜傀儡](铜傀儡.md)、[村民](村民.md)、[嘎枝](嘎枝.md)、、和[流浪商人](流浪商人.md)不会掉落经验值。击杀获得经验值最多的生物是末影龙，第一次杀死[末影龙](末影龙.md)会掉落12,000点经验值。复活后的末影龙被击杀会掉落500点经验值，在击杀生物获得途径中仅次于“第一次打败末影龙”获得的经验值。
* * 一些敌对生物生成时会携带武器或盔甲。这些生物每一件自带或额外随机掉落。生物生成后再捡起的装备不计入其内。
* * 驯服的狼即使是被玩家击杀的也不会掉落经验值，如果它们在[幽匿催发体](幽匿催发体.md)附近死亡，仍然会蔓延出其他[幽匿](幽匿.md)类方块。
* 破坏部分方块，如[刷怪笼](刷怪笼.md)、[矿石](矿石.md)、[幽匿](幽匿.md)方块，经验球会与采下的物品一同掉落。
* * 若使用附有[精准采集](精准采集.md)魔咒的工具开采，且方块能够被[精准采集](精准采集.md)影响而掉落自身，则不掉落经验球。
* ** 无论是否被具有精准采集的工具挖掘破坏，自然生成的[嘎枝之心](嘎枝之心.md)被破坏后都会掉落。
* * 若方块要求特定工具进行挖掘，未满足工具要求的挖掘会破坏方块而不掉落经验球和物品。
* * 在遭[爆炸](爆炸.md)破坏时仍然会掉落经验球。
* [烧炼](烧炼.md)物品。
* * 烧炼所有矿石都会得到一些经验值，但一般只有烧炼[远古残骸](远古残骸.md)才有价值。
* * 烧炼其他材料可获得中量的经验值：[黏土球](黏土球.md)、[黏土](黏土.md)、[仙人掌](仙人掌.md)、[木头](木头.md)、[沙子](沙子.md)和[圆石](圆石.md)，以及烹饪[食物](食物.md)。
* * 直接从[熔炉](熔炉.md)、[高炉](高炉.md)、[烟熏炉](烟熏炉.md)取出成品可以获得经验值，如果使用[漏斗](漏斗.md)收集成品，则经验值会“储存”在方块中，直到玩家手动从方块取出成品时释放储存的经验值。方块被破坏后，其中积累的经验值会以经验球的形式掉落出来。
* [繁殖](繁殖.md)家畜，经验球与幼年个体一同在双亲处出现。
* * 砸碎[鸡蛋](鸡蛋.md)产生的幼年[鸡](鸡.md)的过程不会掉落经验值。
* 玩家[钓鱼](钓鱼.md)钓到物品时会获得经验球，无论钓上来的物品是否被捡起。
* [附魔之瓶](附魔之瓶.md)破碎时释放经验球。
* 与[村民](村民.md)或进行交易。
* 使用[砂轮](砂轮.md)洗去已附魔物品的非诅咒魔咒。
* [游戏规则](游戏规则.md)为<code>false</code>时杀死经验等级不为0的玩家。

不通过经验球、直接添加给玩家的经验值可经由几种不同的途径获得：
* 通过完成挑战[进度](进度.md)获得，这些经验直接给予玩家。
* 通过使用}}或命令。

# 经验等级

[790px](File:XP Per Level 14w02a.svg.md)

设<math>L</math>为当前等级，则升到下一级所需经验值<math>XP_{next}</math>的计算公式为：

<math>
\begin{align}
XP_{next} = \begin{cases}
  2 L + 7,\phantom{00} &\phantom{0}0 \le L \le 15\\
  5 L - 38,\phantom{0} &16 \le L \le 30\\
  9 L - 158, &L \ge 31
\end{cases}
\end{align}
</math>

升到某一级<math>L</math>所需经验值总量<math>XP_{total}</math>的计算公式为：

<math>
\begin{align}
XP_{total} = \begin{cases}
  L^2 + 6L,\phantom{------0} &\phantom{0}0 \le L \le 16\\
  2.5L^2 - 40.5L + 360,\phantom{00} &17 \le L \le 31\\
  4.5L^2 - 162.5L + 2220, &L \ge 32
\end{cases}
\end{align}
</math>

# = 实用数据 =
*
* 由0级升到30级需要1395点经验值。
* 由27级升到30级需要306点经验值。
* 完全消灭一只大型[史莱姆](史莱姆.md)可得到12-28点经验值，平均值大约为20。
* 一次附魔台附魔中消耗的最大等级数是3，而[铁砧](铁砧.md)接受39级及以下等级消费的操作（[创造模式](创造模式.md)中没有限制）。
* 16级时的经验值只是22级的一半（30级的四分之一），而22级只是30级的一半；30级则只是39级的一半。
* 击杀末影龙最多（吸取到所有经验值而没有被返回传送门传送）大约可以将等级从0提升到68级。每波小经验球可以分别将等级从0提升到26级，而一波大经验球可以将等级从0提升到34。其中掉落的价值最高的经验球含有1237经验值，吸取一个就可以将等级从0提升到28级。
* 通过命令可以得到的单个经验球的最高价值为1,277,951。
* 通过获取经验值能合法提升的最高经验等级为238,609,312（再往上升级所需的经验值超过2,147,483,647），此时经验条会消失。通过命令可将等级修改至最高2,147,483,647，但此时玩家的经验条可能会不停闪烁。

# 分数

* *分数（Score）**是玩家在本次生命中收集到的经验值数。分数是玩家收集到的经验值总量，而不是玩家死亡时的拥有的经验值总量，消耗经验不会使分数下降。当玩家死亡时，分数会以黄色（§e）颜色显示在死亡界面上。

等级提升和经验值数量的关系在快照[12w22a](12w22a.md)和[12w23a](12w23a.md)中发生了巨大改变。在此快照之前，升级到50级（单次附魔的最大等级消耗量）需要4,625点经验值，对应需要杀死925只“普通”怪物。此快照改变后，提升等级需要的经验有了可观的减小（以前升到30级所需的经验值现在足够升级到39级）。相比之前，高等级的升级需求比低等级要高，但总体来说难度比[1.2.5](Java版1.2.5.md)要小。现在附魔最高等级是30级，只需要猎杀165只“普通”怪物，小于原先所需的。

# 你知道吗
* 通过命令提升经验值，在不溢出的情况下所得到的最高经验等级为2,147,483,647。这是Java中整型数据类型的最大值（即()-1，32位有符号整型变量的最大值），被用于存储经验值数值。
* 在[Java版Beta 1.9-pre2](Java版Beta 1.9-pre2.md)之前，分数会被显示为&e0。
* * 这是因为游戏在渲染彩色文字时出现了错误。§e0原本应该显示成一个亮黄色的0，但从[Indev 0.31](Java版Indev.md)（在这个版本，经验值系统的前身——[生存测试](生存测试.md)中加入的计分系统——被移除）起，&e0会被原封不动地显示出来。Minecraft使用样式代码时经常出现这种问题（除非在服务器中用插件覆盖了这一问题）。
