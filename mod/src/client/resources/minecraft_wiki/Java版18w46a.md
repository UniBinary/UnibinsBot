# Java版18w46a

*页面ID: 37196* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w46a**是[Java版1.14](Java版1.14.md)的第6个快照，发布于2018年11月15日<ref></ref>，加入了灯笼和拼图方块，更改了一些纹理，改进了生物AI，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[灯笼](灯笼.md)**
* 新的光源方块。
* 可用8个[铁粒](铁粒.md)围绕1根[火把](火把.md)合成。
* 可以放在方块顶部或底部。
* 发出亮度等级15的光。

* *[拼图方块](拼图方块.md)**
* 技术性方块。
* 无法在[生存模式](生存模式.md)中获得。
* 一个允许使用较小模板以外的结构进行建造的拼接方块。
* * “目标池”指拼图方块能用于绘制的元素的池（例如：下个要放置的模板）。
* * “连接类型”指拼图方块的“名称” ，拥有相同名称的拼图方块可以相互连接。
* * “转变为”指拼图方块在整个功能被放置后会转变的方块状态。

# 更改
# = 方块 =
* *[制图台](制图台.md)、[制箭台](制箭台.md)和[锻造台](锻造台.md)**
* 更改了纹理。

* *[脚手架](脚手架.md)**
* 可向外延伸格数由4格改为6格。

* *[切石机](切石机.md)**
* 更改了纹理。
* 现在齿轮是动态的。

* *[潜影盒](潜影盒.md)**
* 现在闭合时是[红石导体](红石导体.md)，且[方块支撑形状](方块支撑形状.md)的上表面完整。

* *[](灾厄旗帜.md)**
* 更改了图案。

# = 生物 =
* *[掠夺者](掠夺者.md)**
* 改进了AI。

# = 游戏内容 =
* *[灾厄巡逻队](灾厄巡逻队.md)**
* 现在以5个随机[灾厄村民](灾厄村民.md)为一组生成。
* 巡逻队中移除了[](灾厄之兽.md)。

# = 常规 =
* *[光照](光照.md)系统**
* 增加了对方块[遮挡形状](遮挡形状.md)遮挡[光照](光照.md)的支持。
* * 适用于[地毯](地毯.md)、[附魔台](附魔台.md)、[末地传送门框架](末地传送门框架.md)、[耕地](耕地.md)、[草径](草径.md)、[活塞](活塞.md)伸出后的底座、[台阶](台阶.md)、[雪](雪.md)和[楼梯](楼梯.md)——它们的完整遮挡面会阻挡光线，不完整遮挡面会让光线通过，如果两个遮挡面交集封锁了整个交合面则光线也无法通过。
* * 不适用于[炼药锅](炼药锅.md)、[红石比较器](红石比较器.md)、[阳光探测器](阳光探测器.md)、[漏斗](漏斗.md)、[红石中继器](红石中继器.md)和[切石机](切石机.md)——这些方块不会遮挡光线，会让光线穿过任何一个面，包括完整的面。

* *[战利品表](战利品表.md)**
* 为[幻术师](幻术师.md)加入了战利品表。
