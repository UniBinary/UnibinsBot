# Java版13w19a

*页面ID: 33529* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w19a**是[Java版1.6.1](Java版1.6.1.md)的第7个快照，发布于2013年5月10日<ref></ref>，加入了16种颜色的染色陶瓦，更改了一些方块的纹理，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[染色陶瓦](染色陶瓦.md)**
* 加入了16种颜色的染色陶瓦。

# 更改
# = 方块 =
* *[煤炭块](煤炭块.md)**
* 更改了纹理。

* *[命令方块](命令方块.md)**
* 在生存模式中不再可挖掘。

* *[青金石块](青金石块.md)**
* 更改了纹理。

# = 物品 =
* *[木炭](木炭.md)**
* 更改了纹理。

* *[马铠](马铠.md)**
* 最大堆叠数从32增加至64。

# = 生物 =
* *常规**
* [生物](生物.md)又会成群生成了。

* *[驴](驴.md)和[骡](骡.md)**
* 拥有箱子的驴和骡现在可以在潜行时右键开启。
* * 驴和骡的名字将会像重命名过的容器出现在箱子GUI内。

# 修复
</onlyinclude>

# 你知道吗
* 该版本的宣传截图中出现了[Grum](Grum.md)的Minecraft皮肤。
