# Java版19w34a

*页面ID: 46716* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w34a**是[Java版1.15](Java版1.15.md)的首个快照<ref></ref><ref></ref>，发布于2019年8月22日<ref name="19w34a"></ref>，加入了[蜜蜂](蜜蜂.md)和关于蜜蜂的物品，例如[蜂蜜瓶](蜂蜜瓶.md)、[蜂箱](蜂箱.md)、[蜂巢](蜂巢（方块）.md)和[蜜脾](蜜脾.md)，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[蜂巢](蜂巢（方块）.md)**
* 一种方块实体，无法被活塞推动。
* 自然生成于、和生物群系里的树周围。
* 可以储存蜂蜜和为蜜蜂提供住所。
* * 当采粉完毕的蜜蜂成功归巢并完成酿蜜时，其内储存的蜂蜜会增加。
* * 玩家可以从中获取蜂蜜瓶和蜜脾。
* * 若玩家破坏了蜂巢或收获蜂蜜瓶或蜜脾，视该巢为家的蜜蜂会与该玩家敌对。
* ** 若玩家使用带有[精准采集](精准采集.md)魔咒的工具采集蜂巢，其内的蜜蜂将不会进入敌对状态，并且会保存在物品形式的蜂巢内（但外面的蜜蜂仍会与玩家敌对）。除此以外，其<code>honey_level</code>值也会保留。
* ** 若在蜂巢下方放置[营火](营火.md)，那么玩家收获蜂蜜瓶或蜜脾时，蜜蜂不会与该玩家敌对。

* *[蜂箱](蜂箱.md)**
* 可用6个木板和3个蜜脾合成。
* 功能与蜂巢相似，但无需带有精准采集魔咒的工具即可采集。
* 无法被活塞推动。

# = 物品 =
* *[蜂蜜瓶](蜂蜜瓶.md)**
* 回复。
* 可用于合成3个[糖](糖.md)。
* 可通过对为5的蜂箱或蜂巢使用[玻璃瓶](玻璃瓶.md)获得。

* *[蜜脾](蜜脾.md)**
* 可通过对为5的蜂箱或蜂巢使用[剪刀](剪刀.md)获得。
* 可用于合成[蜂箱](蜂箱.md)。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了[蜜蜂](蜜蜂.md)的刷怪蛋。

# = 生物 =
* *[蜜蜂](蜜蜂.md)**
* 拥有生命值。
* 会成群地在[蜂箱](蜂箱.md)和[蜂巢](蜂巢（方块）.md)周围活动。
* * 如果蜜蜂没有将任何蜂箱或蜂巢视为家，它将会一直游荡，直到其找到一个。
* * 可以进入蜂箱或蜂巢中。
* ** 每个蜂箱或蜂巢一次最多容纳3只蜜蜂。
* 受到攻击时，同一蜂箱或蜂巢中的蜜蜂将会尝试反击攻击者。
* * 当它们的蜂箱或蜂巢被破坏时也会如此。
* ** 在蜂箱或蜂巢下方放置[营火](营火.md)会使蜜蜂进入被动状态。
* * 蜜蜂拥有NBT标签，其默认值为0，受到攻击时会上升到700刻左右。
* * 受到攻击时，蜜蜂会给予目标10秒的[中毒](中毒.md)效果，此后再过50-60秒，蜜蜂将会死亡。
* * 蜜蜂攻击玩家时，眼睛会变为红色。
* 可以通过喂食任何种类的[花](花.md)来繁殖，包括[凋灵玫瑰](凋灵玫瑰.md)。
* * 像其他动物那样，蜜蜂会跟随任何手持花的玩家。
* ** 如果玩家站在原地不动，蜜蜂将会落在该玩家附近的地面。
* 蜜蜂会落在花上，进入“采粉”状态，然后蜜蜂身上会出现灰白色的粒子，同色的粒子效果也会随之出现。
* * 蜜蜂也会采集凋灵玫瑰的花粉，尽管这会使它们受到[凋零](凋零.md)效果影响。
* * 蜜蜂采粉时，可以听到微小的振动声。
* * 采粉完毕后，蜜蜂会归巢并开始“酿蜜”。
* * 采粉完毕的蜜蜂经过的作物会加速成长，类似骨粉。
* * 当足够多的完成授粉的蜜蜂进入巢并完成酿蜜后，巢将充满蜂蜜。
* 玩家被蜜蜂蛰死时会显示这样一条[死亡消息](死亡消息.md)：“<玩家>被蛰死了”。

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 现在可以对充满了蜂蜜的[蜂巢](蜂巢（方块）.md)和[蜂箱](蜂箱.md)使用[剪刀](剪刀.md)来收获[蜜脾](蜜脾.md)。
* * 蜜脾会掉落在地面上。
* 现在可以对充满了蜂蜜的蜂巢和蜂箱使用[玻璃瓶](玻璃瓶.md)来收集[蜂蜜瓶](蜂蜜瓶.md)。
* 现在可以对水源发射玻璃瓶来收集[水瓶](水瓶.md)。

* *[红石比较器](红石比较器.md)**
* 可以使用红石比较器来检测[蜂巢](蜂巢（方块）.md)和[蜂箱](蜂箱.md)内蜂蜜的含量。
* * 输出强度等于蜂巢中蜂蜜的量。
