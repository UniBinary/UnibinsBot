# 铜箱子

*页面ID: 156350* | *来源: Minecraft Wiki*

* *铜箱子（Copper Chest）**是铜傀儡生成时产生的容器方块，用途和[箱子](箱子.md)类似。

# 生成
铜箱子不会生成在世界中。

# = 铜块 =
将[雕刻南瓜](雕刻南瓜.md)或[南瓜灯](南瓜灯.md)放在[铜块](铜块.md)的任意一面时，铜块会转变为未涂蜡的铜箱子。铜箱子的[氧化](氧化.md)程度与铜块相同。

# = 转化 =
两个不同的铜箱子合并成大型铜箱子时，会合并两个箱子的氧化程度和涂蜡状态，见。

# 破坏
挖掘铜箱子的合适工具是镐。铜箱子需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

铜箱子被破坏后会掉落自身和内容物。

如果一个大型铜箱子（由2个相邻的铜箱子组成）的其中一个铜箱子破坏，那么将会掉落最后27个储存格的物品。

# 用途
# = 容器 =

将任意氧化程度、无论是否涂蜡的两个铜箱子相邻放置时会合并成大型铜箱子，大型铜箱子的氧化程度与合并之前氧化程度最轻的铜箱子相同，且合并之前存在任一未涂蜡的铜箱子都会使大型铜箱子变为未涂蜡变种。<ref></ref><ref></ref>

铜箱子界面的标题默认为“铜箱子”，可以在放置前使用[铁砧](铁砧.md)重命名来进行更改，也可以通过使用命令修改铜箱子的<code>CustomName</code>标签进行更改（例如，要把位于(0,64,0)的铜箱子标记为“杂物箱”，则使用命令{{cmd|data merge block 0 64 0 {CustomName:"杂物箱"} }}）。若大型铜箱子的一半被重命名，那么整个大型铜箱子界面上的名字都会改变，但若重命名的那一半被摧毁，剩下的一半会恢复到默认状态；若两个部分的名字不同，铜箱子根据朝向优先选择北侧或西侧的那一半的名字（即X轴或Z轴上坐标最小的那一半）；若均无重命名则会显示“大型铜箱子”。大型铜箱子界面上的名字取决于被打开的大型铜箱子的一半的名称；若打开的大型铜箱子的一半无名称，则会显示“大铜箱子”。铜箱子和大型铜箱子界面的标题的改变均不受其氧化和涂蜡状态改变的影响。

# = 铜傀儡 =
未持有物品的[铜傀儡](铜傀儡.md)会尝试搜寻并打开附近的铜箱子。找到有物品的铜箱子时，铜傀儡会收集其中的物品并拿在手上。

# = 猪灵 =
在非和平[难度](难度.md)下，成年[猪灵](猪灵.md)会与附近打开或破坏铜箱子的玩家敌对。

# = 氧化 =

铜箱子受氧化机制影响，能够在不同变种之间转化。

飞行时无法为铜箱子涂蜡、脱蜡和除锈，而只能打开它们，即使玩家已在空中保持潜行。<ref></ref>

# = 圣诞节 =

每年12月24日至26日，铜箱子、[箱子](箱子.md)和[陷阱箱](陷阱箱.md)会共用圣诞节礼物包裹纹理，因而无法从外观分辨。由于游戏会读取电脑数据，玩家可以通过更改游戏文件和时间来看到圣诞节纹理。
