# 萤火虫灌木丛

*页面ID: 144050* | *来源: Minecraft Wiki*

* *萤火虫灌木丛（Firefly Bush）**是一种装饰性方块，会在它周围产生萤火虫粒子。

# 生成
# = 自然生成 =
萤火虫灌木丛会自然生成在大多数主世界[生物群系](生物群系.md)中[水](水.md)边的[草方块](草方块.md)上，还会少见地生成在[红树林沼泽](红树林沼泽.md)、[恶地](恶地.md)、[疏林恶地](疏林恶地.md)和[风蚀恶地](风蚀恶地.md)的水源旁。[蘑菇岛](蘑菇岛.md)内的萤火虫灌木丛可能生成在水边的[菌丝体](菌丝体.md)上。

在[沼泽](沼泽.md)中，萤火虫灌木丛可以在任何位置生成，而不仅限于[水](水.md)边。

# = 骨粉 =
对着萤火虫灌木丛骨粉会在[曼哈顿距离](曼哈顿距离.md)为1的随机可种植方块上生成一个新的萤火虫灌木丛。

# 破坏
萤火虫灌木丛被挖掘时会立刻被破坏，用于挖掘的工具的耐久度不会下降。

萤火虫灌木丛被破坏后会掉落自身。

# 用途
萤火虫灌木丛可以种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。

萤火虫灌木丛可以[含雪](含雪.md)。含雪的萤火虫灌木丛不会产生萤火虫粒子，也不会发出环境音效。

# = 光源 =
[thumb|萤火虫灌木丛在夜晚产生发光的粒子](File:Firefly Bushes at Night.gif.md)

萤火虫灌木丛会发出等级为2的[光照](光照.md)。

在[内部天空光照](内部天空光照.md)≤13时，发光的萤火虫粒子在每一[刻](刻.md)都有70%的概率会在萤火虫灌木丛的上方和水平方向/内生成。萤火虫粒子的存在时间为到。萤火虫粒子会从透明变为不透明的淡黄色，然后变为透明，最后消失。

# = 堆肥 =
将萤火虫灌木丛放入[堆肥桶](堆肥桶.md)里有30%的概率增加1个堆肥等级。
