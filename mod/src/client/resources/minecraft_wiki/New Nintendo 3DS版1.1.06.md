# New Nintendo 3DS版1.1.06

*页面ID: 39518* | *来源: Minecraft Wiki*

* *1.1.06**是[New Nintendo 3DS版](New Nintendo 3DS版.md)发布于2017年11月8-9日的一次更新，改进了性能并修复了一些漏洞。<ref></ref>

# 更改
* 改进了全局保存/加载时间。
* 拓展了快速移动UI的功能。
* 各种UI调整和修复。
* [经验值](经验值.md)现在可以通过[烧炼](烧炼.md)和[交易](交易.md)获得。
* 更小更精致的罗马字母语言字体。
* 各种稳定性和性能的改进。

# 修复
* 修复了物品栏和热键栏有关物品堆叠的漏洞。
* 修复了关于各种实体大量存在的崩溃漏洞。
* 修复了使用附魔之瓶时游戏崩溃的漏洞。
