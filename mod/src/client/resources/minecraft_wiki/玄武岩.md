# 玄武岩

*页面ID: 53487* | *来源: Minecraft Wiki*

* *玄武岩（Basalt）**是一种生成于[下界](下界.md)的[岩石](岩石.md)。

# 生成
# = 自然生成 =
玄武岩会作为[灵魂沙峡谷](灵魂沙峡谷.md)生物群系中[玄武岩柱](玄武岩柱.md)的一部分自然生成，也会大量生成于[玄武岩三角洲](玄武岩三角洲.md)生物群系。

玄武岩会作为[堡垒遗迹](堡垒遗迹.md)的一部分自然生成。

# = 熔岩 =
[缩略图|一个简单的玄武岩生成器](File:Basalt generator.gif.md)

流至[灵魂土](灵魂土.md)上方且与[蓝冰](蓝冰.md)相邻的[熔岩](熔岩.md)会转变成玄武岩。

# 获取
玄武岩只能通过破坏玄武岩获得。

# 破坏
挖掘玄武岩的合适工具是镐。玄武岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

玄武岩被破坏后会掉落自身。

# 用途
类似于[原木](原木.md)和[石英柱](石英柱.md)等方块，玄武岩可以朝向任意水平或垂直方向，这取决于玩家放置它们时的方向。

# 你知道吗
* 在现实中，[玄武岩](wzh:玄武岩.md)和[花岗岩](花岗岩.md)都属于岩浆火成岩，然而它们在Minecraft中分布的范围却截然不同，且玄武岩的挖掘用时也比花岗岩短。
