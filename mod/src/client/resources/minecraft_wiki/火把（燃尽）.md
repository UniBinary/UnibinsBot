* *火把（燃尽）（Torch (Burnt-out)）**是熄灭的[火把](火把.md)，不会提供亮度。

# 生成
[火把](火把.md)被放置后，会在几个[随机刻](随机刻.md)后变为火把（燃尽）。

# 获取
火把（燃尽）只能通过破坏对应方块获得。

# 破坏
火把（燃尽）被挖掘时会立刻被破坏。

|0|none
}}

火把（燃尽）被破坏后会掉落自身。

# 用途

火把（燃尽）不会发光，也不能用于融化[雪](雪.md)和[冰](冰.md)。

# = 点燃 =
对着火把（燃尽）打火石可以将其变为火把。使用[发射器](发射器.md)发射打火石不能将其变为火把。
