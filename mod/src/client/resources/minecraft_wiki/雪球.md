# 雪球

*页面ID: 6379* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *雪球（Snowball）**是一种可抛掷的物品。

# 获取
# = 雪 =
使用没有[精准采集](精准采集.md)魔咒的[锹](锹.md)破坏[雪块](雪块.md)会掉落4个雪球。[时运](时运.md)魔咒并不影响掉落数量。

使用没有精准采集魔咒的锹破坏[雪](雪.md)时，每层雪掉落1个雪球；1-3层掉落1个雪球，4-5层掉落2个雪球，6-7层掉落3个雪球，8层掉落4个雪球。时运魔咒并不影响掉落数量。

雪层被[爆炸](爆炸.md)、破坏时也会掉落为雪球。

下落的雪层落地但没有变成方块时也会掉落为雪球。

# 用途
# = 投掷 =
雪球可以将其投掷出去，生成弹射物。

[发射器](发射器.md)也可以射出雪球。

# = 合成材料 =

# = 快乐恶魂 =

雪球可以用于喂食[小恶魂](小恶魂.md)以加速其成长为[快乐恶魂](快乐恶魂.md)。

雪球还可以用于吸引小恶魂和快乐恶魂。

# 行为
雪球是一种[弹射物](弹射物.md)，可以触发[标靶](标靶.md)。

雪球会受到重力影响和环境阻力的影响。

# = 着火 =
雪球可以[着火](着火.md)。雪球在穿过[火](火.md)或[熔岩](熔岩.md)会着火，穿过[雨](雨.md)或[水](水.md)时会熄灭。

着火的雪球会不受阻碍地穿过[TNT](TNT.md)并使其激活，可以点燃熄灭的[营火](营火.md)，可以破坏其穿过的[细雪](细雪.md)。着火的雪球会点燃其命中的[实体](实体.md)。

# = 造成伤害 =
雪球在直接击中实体时，会对其造成伤害。该伤害可以产生击退。虽然不能对大多数生物的生命值造成影响，生物仍然会将其视为一种攻击行为并做出相应的反应。

雪球会对[烈焰人](烈焰人.md)造成伤害。

和[末影龙](末影龙.md)的受伤害行为使其免疫雪球造成的伤害。<ref></ref>

# = 与方块交互 =
雪球可以触发其击中的[标靶](标靶.md)、敲响[钟](钟.md)或击塌[大型垂滴叶](大型垂滴叶.md)。

雪球可以激活[木质压力板](木质压力板.md)和[绊线](绊线.md)。当雪球穿过这些方块时，这些开关会保持开启状态。其他开关则不受雪球的影响。
