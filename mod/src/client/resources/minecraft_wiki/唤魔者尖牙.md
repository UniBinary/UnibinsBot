# 唤魔者尖牙

*页面ID: 127950* | *来源: Minecraft Wiki*

* *唤魔者尖牙（Evoker Fang）**是[唤魔者](唤魔者.md)在尖牙攻击时使用的[实体](实体.md)。

# 生成
唤魔者会向其攻击目标召唤唤魔者尖牙。

# 行为
唤魔者召唤的尖牙间有一定延迟。延迟结束前，[玩家](玩家.md)无法看见尖牙，但它不像标签为1的实体，此时它仍然拥有[判定箱](判定箱.md)。延迟结束后，尖牙开始扩展，并咬合、缩小再消失，同时对站在尖牙上的生物造成伤害。

唤魔者召唤的尖牙不会对和[灾厄村民](灾厄村民.md)造成伤害，且[伤害类型](伤害类型.md)为<code>indirect_magic</code>。不由唤魔者召唤的尖牙仍会对灾厄村民造成伤害，且[伤害类型](伤害类型.md)为<code>magic</code>。尖牙伤害值无视盔甲，但[保护](保护.md)魔咒可以抵挡部分伤害。

唤魔者尖牙只会生成在具有完整侧面的方块的西北角上，如果生成的位置正上方存在具有完整侧面的方块，则停止在此方块上尝试生成；如果存在没有完整侧面的方块，尖牙可受到此方块的挤压。唤魔者尖牙的蔓延距离最长为20。

唤魔者尖牙不会被[和平难度](难度.md)所影响。它也会触发[压力板](压力板.md)、[绊线钩](绊线钩.md)等红石物品。

唤魔者尖牙无法被伤害。
