* *切制铜楼梯（Cut Copper Stairs）**是[切制铜块](切制铜块.md)制作的[楼梯](楼梯.md)。

# 生成
切制铜楼梯、斑驳的切制铜楼梯、锈蚀的切制铜楼梯、氧化的切制铜楼梯、涂蜡的斑驳切制铜楼梯、涂蜡的锈蚀切制铜楼梯不会生成在世界中，只能通过[氧化](氧化.md)机制生成。

# = 自然生成 =
涂蜡的切制铜楼梯、涂蜡的氧化切制铜楼梯会自然生成于[试炼密室](试炼密室.md)的楼道。

# 破坏
挖掘切制铜楼梯的合适工具是镐。切制铜楼梯需要石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

切制铜楼梯被破坏后会掉落自身。

# 用途

# = 氧化 =

切制铜楼梯受氧化机制影响，能够在不同变种之间转化。
