# Java版Indev 0.31 20100122-2251

*页面ID: 35321* | *来源: Minecraft Wiki*

<onlyinclude>
* *0.31**的一个版本发布于2010年1月22日22:51（UTC）<ref>[Adura的IRC记录](#logs.md): "(17:51:45) <Notch> there we go, indev's been updated"</ref>，加入了[无限熔岩源](无限熔岩源.md)，并修复了一些漏洞。<ref name="Load/save"></ref>

# 新内容
# = 方块 =
* *[无限熔岩源](无限熔岩源.md)**
* 放置后，无限熔岩源会无限复制以占据所有同一格或低于所处Y轴的数值的所有可用空间。
* 会在玩家出生时携带。

# = 物品 =
* *[弓](弓.md)**
* 可以射出箭。
* 会在玩家出生时携带。

* *[箭](箭.md)**
* 加入了[物品](物品.md)形式。
* 需要使用弓射出。
* 快捷栏上方的箭计数器被移除。
* 不会对玩家或[生物](生物.md)造成伤害。
* 被添加到物品栏。
* 当击中方块时有抖动效果，并且其停止的位置略有偏差。

# = 非生物实体 =
* *[箭](箭.md)**
* 射入[熔岩](熔岩.md)中可以着火。

# = 游戏内容 =
* *[亮度](亮度.md)**
* 新的亮度系统，可以防止在巨大深浮岛地图中出现堆栈溢出问题。

# = 世界生成 =
* *常规**
* 世界生成器中的“液体生成”选项
* 流体可以在海平面以上和浮岛上生成。
* 现在可以生成花。
* 洞穴被淹没的概率降低。

# 更改
# = 方块 =
* *[熔岩](熔岩.md)**
* 熔岩的流动机制现在和[水](水.md)一样，但是速度更慢。

* *[无限水源](无限水源.md)和[无限熔岩源](无限熔岩源.md)**
* 玩家出生时会携带5个。<ref name="Load/save"/><ref name="Forum"></ref>

* *常规**
* [方块](方块.md)现在可以被放置在资源物品上。
* 堆叠大小上限从99减小到50。

# = 物品 =
* *[斧](斧.md)**
* 更改了纹理。

# = 非生物实体 =
* *常规**
* 掉落物和点燃的[TNT](TNT.md)在撞到地面后不再反弹。

# = 游戏内容 =
* *[爆炸](爆炸.md)**
* 爆炸现在拥有更大的半径。
* 现在可以破坏[石头](石头.md)。

* *常规**
* 重新加入了捡起物品时快捷栏中的脉冲效果。<ref name="Forum4"></ref>
* 重新加载世界后，当物品栏已满时捡起物品会将其移动到隐藏的不可访问槽位中。<ref group="注" name="FullInv">这些槽位仅能使用NBT编辑器访问或查看。</ref>
* * 如果没有重新加载世界，多余物品都会移动到盔甲槽。当盔甲槽满后不再能捡起更多物品。
* 现在用[Indev世界格式](Indev世界格式.md)在本地保存和加载世界。<ref></ref>
* 玩家的攻击距离增长。<ref name="Forum5"></ref>

# 修复
* *修复了1个漏洞**
* 拾取已具有完整一组的物品将不再在物品栏中单个堆积，而是能够正常地堆积成一组。</onlyinclude>
