# Java版18w50a

*页面ID: 37721* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w50a**是[Java版1.14](Java版1.14.md)的第12个快照，发布于2018年12月12日<ref></ref>，加入了新品种的流浪猫、石匠村民、新的统计信息及音效，并修复了一些漏洞。

# 新内容
# = 生物 =
* *[流浪猫](流浪猫.md)**
* 加入了“Jellie”品种，由社区成员选出。<ref></ref><ref></ref>

* *[村民](村民.md)**
* 加入了石匠村民。
* * 用绿宝石交易各种磨制石头。

# = 常规 =
* *[声音](声音.md)**
* 加入了[钟](钟.md)的音效。
* 加入了袭击号角音效。

* *[统计](统计.md)**
* 新的统计“打开木桶次数”。

# 更改
# = 方块 =
* *[木桶](木桶.md)**
* 用于装载物品。
* 与箱子不同，木桶在上方有方块时也可使用。
* 使用6块木板和2个木台阶来合成。

* *[床](床.md)、[圆石](圆石.md)、[绿宝石块](绿宝石块.md)、[末地石](末地石.md)、[草丛](草丛.md)、[拼图方块](拼图方块.md)、[苔石](苔石.md)、[下界石英矿石](下界石英矿石.md)、[石英柱](石英柱.md)、[红色下界砖块](红色下界砖块.md)、[红砂岩](红砂岩.md)、[砂岩](砂岩.md)、[云杉木板](云杉木板.md)、[基岩](基岩.md)**
* 更改了纹理。

* *[钟](钟.md)**
* 加入了音效。
* 当按键击打它时，会有摇动的动画。
* * 根据方块的位置和方向，钟方块只能在特定方向被敲响，而且只会朝特定方向震动。
* 更改了纹理。
* 更改了的方块模型，并加入的方块模型。
* 现在可以放在墙上了。
* 将方块状态更改为。

* *[高炉](高炉.md)**
* 更改了功能，现在烧炼速度是普通熔炉的两倍。
* * 只能烧炼矿石和熔炼金属。
* 使用3个平滑石头，1个熔炉和5个铁锭来合成。

* *[附魔台](附魔台.md)**
* 更改了纹理（黑曜石的侧面和底部）。

* *[烟熏炉](烟熏炉.md)**
* 更改了功能，现在烧炼速度是普通熔炉的两倍。
* * 只能烹饪食物。
* 使用4个原木和1个熔炉来合成。

* *去皮丛林[原木](原木.md)**
* 更改了顶部纹理。

# = 物品 =
* *[马铠](马铠.md)、[马铃薯](马铃薯.md)、[烤马铃薯](烤马铃薯.md)、[毒马铃薯](毒马铃薯.md)、[兔肉煲](兔肉煲.md)、[发酵蛛眼](发酵蛛眼.md)、[光灵箭](箭#光灵箭.md)、[剑](剑.md)**
* 更改了纹理。

# = 生物 =
* *[流浪猫](流浪猫.md)**
* 现在会在[村庄](村庄.md)中自然生成。

* *[巨人](巨人.md)**
* 现在使用僵尸的AI。
* 现在幼年巨人可以使用NBT标签生成了。

[缩略图|右|250px|所有平原村民的职业，对应相匹配的效用型方块](File:All Professions In 18w50a.png.md)
[缩略图|右|250px|由村民衣物的徽章指示五种村民职业级别](File:All Profession Levels.png.md)

* *[村民](村民.md)**
* 村民和[僵尸村民](僵尸村民.md)现在拥有七种皮肤，分别对应以下的生物群系：
* * 平原
* * 沙漠
* * 热带草原
* * 针叶林
* * 积雪的冻原 / 积雪针叶林
* * 丛林
* * 沼泽
* 村民现在有五个职业级别，其衣服上不同材料的徽章显示已解锁的交易层数。
* * 第一层是石头徽章，下一层是铁，然后是黄金、绿宝石，最后是钻石。
* * 有些职业的交易层数少于五。
* ** 如果由命令生成的村民拥有的交易层数比自然生成的村民的最高层数高，其徽章仍可见，但玩家不能与其互动。
* 被治愈的僵尸村民在转换回普通的村民时会保留交易内容。

* *[女巫](女巫.md)**
* 现在是条件敌对生物。
* 更改了外观。<ref></ref>

# = 非生物实体 =

# = 世界生成 =
* *[村庄](村庄.md)**
* 更新了[针叶林](针叶林.md)和[沙漠](沙漠.md)村庄。
* 更新了平原、热带草原和积雪的村庄的一部分结构。
* 为制箭师的房子加入了战利品箱子，包含：绿宝石、箭、羽毛、鸡蛋、燧石和木棍。

# = 游戏内容 =
* *[袭击](袭击.md)**
* 现在杀死巡逻队队长会给予1-3级的效果，杀死在[掠夺者前哨站](掠夺者前哨站.md)的队长只会给予1级的效果。
* 队长现在会生成在[掠夺者前哨站](掠夺者前哨站.md)。
* [](灾厄之兽.md)会在第2波开始出现，[女巫](女巫.md)在第4波，[唤魔者](唤魔者.md)在第10波。

# = 常规 =
* *[进度](进度.md)**
* “百猫全书”进度现在需要新加入的猫皮肤。
