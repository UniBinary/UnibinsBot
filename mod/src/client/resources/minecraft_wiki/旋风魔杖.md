# 旋风魔杖

*页面ID: 149882* | *来源: Minecraft Wiki*

* *旋风魔杖（Wind Wand）**是一种可以向前方发射[风弹](风弹.md)的[物品](物品.md)。

# 获取
# = 解锁 =
解锁“[橡树之心（Heart of the Oak）](可解锁项目#wind_wand.md)”后，挑战矿境时会自动获得1个旋风魔杖。

# 用途
旋风魔杖具有[光效](光效.md)。

旋风魔杖会向前方发射[风弹](风弹.md)，使用后冷却。
