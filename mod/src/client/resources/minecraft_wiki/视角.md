# 视角

*页面ID: 127938* | *来源: Minecraft Wiki*

* *视角（Perspective）**即游戏中[玩家](玩家.md)的相机视角，其包括第一人称视角、第三人称视角正面和第三人称视角背面。此外，中也存在用于运镜的电影视角功能。

# 用法
所有世界共用同一视角，并且退出世界后视角会保存以便下次进入游戏时使用。

视角可以通过按、来激活。按一次将会在第三人称视角中显示出玩家的后面，第二次将从前往后看，第三次回到第一人称视角。

视角也可以在游戏中设置切换。

# = 第一人称 =
玩家首次进入世界时默认为第一人称视角，此时屏幕上会显示玩家的主手，不会渲染玩家自己的模型。按下或设置中启用“隐藏 HUD”}}可以隐藏玩家主手。

# = 第三人称 =
第三人称视角允许从[玩家](玩家.md)的外部的视角来看玩家自身。在第三人称视角时，玩家可在0°角以及鼠标与地面在同一水平面时从玩家前方180°角（Y轴）被观察到。

[窒息](窒息.md)状态会使玩家从第三人称视角转换回第一人称视角。

在打开玩家[物品栏](物品栏.md)时，也可以看到第三人称视角的玩家模型。在这种情况下，玩家模型始终朝向鼠标指针所在的位置；只有当使用键盘与鼠标或手柄，且使用时，玩家模型才会朝向指针所在的位置，否则会固定朝向正前方。

# 电影视角

电影视角是一种特殊的视角，在此视角下玩家移动视角会变得更慢，更顺畅，更像电影运镜。

电影视角需要在[控制](控制.md)中绑定****的按键才能正常使用，其在任何相机视角下都能生效。
