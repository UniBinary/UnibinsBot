# Java版1.15-pre2

*页面ID: 49756* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.15-pre2**是[Java版1.15](Java版1.15.md)的第2个预发布版，发布于2019年11月25日<ref></ref>，加入了新的统计信息和新的方块标签，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[统计](统计.md)**
* 加入了玩家与[铁砧](铁砧.md)和[砂轮](砂轮.md)互动次数的统计数据。

* *[标签](Java版标签.md)**
* 加入了新的方块标签。

# 更改
# = 方块 =
* *[床](床.md)**
* 现在使用床设置[重生点](重生点.md)时会在聊天框内显示一条消息。

* *[耕地](耕地.md)、[草径](草径.md)和[灵魂沙](灵魂沙.md)**
* 现在会使生物窒息。

# = 常规 =
* *性能**
* 调整了[区块](区块.md)加载算法。

* *[数据包](数据包.md)**
* 将数据包的版本升级为5。
