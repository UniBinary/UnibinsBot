* *生物群系（Biome）**是[Minecraft](Minecraft.md)世界中形态各异的区域，具有多样的地理特征，例如[植物群](植物.md)、[海拔高度](海拔高度.md)、温度、湿度，以及不同的天空、水域和植被颜色。生物群系将生成的[世界](世界.md)划分为不同的自然环境，例如森林、丛林、沙漠和针叶林。

一个位置的生物群系种类不会自行改变，即便[玩家](玩家.md)清除所有[方块](方块.md)，或将其他生物群系的方块和地形复制至此，也不会改变其原有生物群系。

# 种类
# = 主世界 =
根据地形、水陆及植被特征，主世界的54种生物群系可大致分为以下7个类型。该分类方式并非官方认定。

# == 海洋类生物群系 ==
海洋类生物群系以广阔开放为特点，占据世界小半部分面积，主体为水域，海床多由[沙砾](沙砾.md)或[沙子](沙子.md)构成，会生成[海底废墟](海底废墟.md)和[沉船](沉船.md)。部分区域有植被稀疏的小岛屿，岛上仅自然生成敌对生物。因水陆特征与生成机制相近，蘑菇岛也被归入此类。

# == 山地类生物群系 ==
山地类生物群系海拔较高，地形崎岖，行走难度大，雪线之上会出现积雪山峰。这类生物群系是唯一会生成[绿宝石矿石](绿宝石矿石.md)的类型，同时也会较多生成[煤矿石](煤矿石.md)和[铁矿石](铁矿石.md)，部分[石头](石头.md)和[深板岩](深板岩.md)会被替换为它们对应的[虫蚀方块](虫蚀方块.md)。

山地类生物群系还可细分为狭义上的山地类和风袭丘陵类两类。前者可生成[掠夺者前哨站](掠夺者前哨站.md)，且地形通常更高，详见[山地](山地.md)。

# == 森林类生物群系 ==

森林类生物群系植物丰富，[树木](树木.md)、花与[草丛](草丛.md)构成地表植物群。其是理想出生地之一，能提供大量木-{}-材资源，但树木密集会遮挡视线，使夜晚行动较危险。

# == 湿地类生物群系 ==
湿地类生物群系包括河流、沼泽与海滩，拥有丰富的水资源。河流起到分隔各类生物群系的作用，海滩则生成于海洋与陆地之间，作为过渡区域。

# == 平原类生物群系 ==
平原类生物群系地形平坦、地势平缓、视野开阔，树木生成较少，湖泊与水洼较为常见。

# == 干旱类生物群系 ==
干旱类生物群系炎热干燥，不会降雨，地表覆盖稀少植被，或被沙子、红沙覆盖。

# == 洞穴类生物群系 ==
洞穴类生物群系生成于主世界地下，在[洞穴](洞穴.md)地形基础上各有独特地形特征。

# = 下界 =
[下界](下界.md)是与主世界不同的[维度](维度.md)，该维度所有生物群系均干燥炎热，玩家放置的[水](水.md)会立即蒸发，但[冰](冰.md)、[浮冰](浮冰.md)、[蓝冰](蓝冰.md)、[雪](雪.md)、[雪块](雪块.md)和[细雪](细雪.md)可正常放置。

# = 末地 =
末地是与主世界和下界不同的维度，自然生成的生物只有[末影人](末影人.md)、[末影龙](末影龙.md)和[潜影贝](潜影贝.md)。

# 生成

# = 主世界 =

主世界生物群系的生成与6个值相关：**温度**、**湿度**、**大陆性**、**侵蚀度**、**奇异性**与**深度**，分别对应中NoiseRouter行的T、V、C、E、W和D，由6个不同的[密度函数](密度函数.md)计算得出。其中，除深度外，其余5个值仅与水平坐标有关。

# = 下界 =
与主世界类似，下界使用温度、湿度和偏移这3个密度函数生成生物群系。不同之处在于，下界生物群系采用参数点，而主世界使用参数区间。

# = 末地 =
末地与主世界、下界不同，仅使用侵蚀度一项数据生成生物群系。末地只有一种生物群系。

# 气候
所有生物群系都具备温度（）、降水（）和降水类型（）三个基本属性。

# = 温度 =
每个生物群系都有“基础温度”（详见[气候列表](#气候列表.md)），但生物群系内各位置的温度还会受所处高度影响。在Y=80及以下区域，位置温度等于所在生物群系的基础温度；在Y=81处，温度会通过XZ平面上的噪声函数，在基础温度上随机浮动-0.00875（-）至0.01125（）；以此为基础，在Y=81及以上区域，每比Y=80升高1格，温度就下降0.00125（）。

位于和内的部分随机区域，会受另一个XZ平面上的噪声函数影响，这些区域的基础温度始终被视为0.2，其他温度计算方式与其他区域一致。

# = 降水 =
生物群系的降水值是0.0至1.0之间的浮点数（详见[气候列表](#气候列表.md)），但它与降水类型无关，也无法用于判断一个位置是否会降水。当降水值大于0.85时，生物群系会被标记为湿润（为），该值与生物群系中[火](火.md)的[随机熄灭机制](火#熄灭.md)相关。

# = 降水类型 =
生物群系的降水类型分为无降水和有降水。降水类型为无降水时，生物群系内任何位置都不会有雨雪；降水类型为有降水时，若位置温度≥0.15，会被标记为可[降雨](降雨.md)（为），否则被标记为可[降雪](降雪.md)（为）。

对于有降水的生物群系，基础温度<0.15时，虚空以上位置均可降雪；否则仅雪线以上位置会降雪，雪线高度如下表：

生物群系的最大积雪高度可通过[游戏规则](游戏规则.md)设置。

生物群系下雪时的积雪高度（）预设在包含生物群系生成数据的JSON文件中，通常为长度2的浮点数组，依次代表最小和最大积雪高度（0.0为不积雪，1.0为一格全高）。

# 着色
# = 植物颜色 =
生物群系中植物的颜色通常由该生物群系的温度值和降水值决定。

大多数植物的颜色由目录}}或目录}}下尺寸为256×256的颜色图来确定。

计算生物群系在颜色图中的颜色坐标时，基础温度值会先被钳位到0.0至1.0范围（小于0.0则设为0.0，大于1.0则设为1.0）；降水值经钳位后，还需乘以钳位后的温度值，以控制在颜色图的下三角形区域。若钳位后的温度值为<math>AdjTemperature</math>，钳位后的降水值为<math>AdjDownfall</math>，以颜色图左上角为原点，该生物群系植物在对应颜色图中的颜色坐标为<math>(\lfloor(1-AdjTemperature)\times 255\rfloor, \lfloor(1-AdjDownfall)\times 255\rfloor)</math>。

# = 环境颜色 =
[thumb|温度影响天空的颜色，从左到右温度依次降低](File:Sky temperature.png.md)
主世界生物群系中的天空颜色会根据该生物群系的基础温度值进行改变。在计算时首先将基础温度值除以3.0，然后钳位至-1.0到1.0的范围。若将更改后的基础温度值记为<math>T</math>，那么三元组<math>(0.62222224-0.05T, 0.5+0.1T, 1)</math>通过自定义的方法转换后即为最终的十六进制颜色。

此外，生物群系中的[水体](水#颜色.md)、水下[迷雾](迷雾.md)及迷雾颜色也被预设在原版数据包中。<!-- 是否需要将它们添加到气候列表中 -->

# = 颜色过渡 =
当植物或水处于多个生物群系的边界时，颜色由此方块与同一水平面的周围方块的生物群系共同决定。参与计算的方块范围由[选项](选项.md)中的“”决定，选取以此方块为中心，水平范围为生物群系过渡距离的正方形内所有位置的生物群系的植物或水的颜色，并计算它们的平均值，得到最终的混合颜色。

、迷雾颜色使用以此方块为中心，5×5×5范围内的所有生物群系的天空或迷雾颜色做处理得到最终的混合颜色。

# 你知道吗
* 在科学界的定义中，（Biome）由诸如植物集群、动物集群和土壤生物集群的各种生物群落组成，是生态学上气候条件相似并按照气候和地理划分的区域。生物群系属于大尺度的生态环境，亦被认为是生态系统。
* 游戏中[下界](下界.md)和[末地](末地.md)中的生物群系、[深暗之域](深暗之域.md)、[苍白之园](苍白之园.md)以及拥有巨型蘑菇的生物群系是虚构的。其余生物群系中的内容则是完全或大部分参照现实世界设计的。
* 若在[超平坦](超平坦.md)世界中应用[下界](下界.md)的生物群系，则主世界只会生成下界生物（[恶魂](恶魂.md)、[僵尸猪灵](僵尸猪灵.md)群、[猪灵](猪灵.md)群和零落的[岩浆怪](岩浆怪.md)），不会下雨，也不会生成下界的地物和结构（如[下界石英](下界石英.md)和[荧石](荧石.md)团簇，以及[下界要塞](下界要塞.md)），但是仍然会生成[废弃矿井](废弃矿井.md)。
* 一个方块中可能会生成一个独立的生物群系。<ref></ref>
