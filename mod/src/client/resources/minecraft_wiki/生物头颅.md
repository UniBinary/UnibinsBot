# 生成
凋灵骷髅头颅、僵尸的头、玩家的头、苦力怕的头和猪灵的头不会生成在世界中。

# = 自然生成 =
[末地船](末地船.md)头会生成一个龙首。

[远古城市](远古城市.md)的营房内和中型石柱上各会生成一个骷髅头颅。

# 获取
玩家的头不能在生存模式中正常获得，但可以通过[创造模式物品栏](创造模式物品栏.md)、[创造模式](创造模式.md)中使用或[命令](命令.md)获得。

# = 掉落 =
[骷髅](骷髅.md)（不包括其变种）、[凋灵骷髅](凋灵骷髅.md)、[僵尸](僵尸.md)（不包括其变种）、[苦力怕](苦力怕.md)（包括闪电苦力怕）和[猪灵](猪灵.md)（不包括[猪灵蛮兵](猪灵蛮兵.md)）被[闪电苦力怕](闪电苦力怕.md)杀死时会各自掉落对应的生物头颅。只有每只闪电苦力怕杀死的第一个生物会掉落对应的生物头颅。

* *凋灵骷髅头颅**

# 破坏
没有工具可以加速对生物头颅的挖掘。

生物头颅被破坏后会掉落自身。

被爆炸破坏的生物头颅总是会掉落。

# 用途
生物头颅会被液体破坏。

# = 装饰 =
生物头颅被放置在方块顶面时可以呈16种不同的方向，而放置在方块侧面时可以呈4种不同的方向。生物头颅不需要方块支撑，且可以放置在其他生物头颅的上方或侧边。

龙首收到红石信号时会像[末影龙](末影龙.md)那样反复开合嘴部，猪灵的头收到红石信号时会像[猪灵](猪灵.md)那样扇动耳朵。若生物穿戴着龙首或猪灵的头，，相同的动画也会在该生物水平移动时出现。

# = 穿戴 =
<div style='float:right'></div>

玩家能将头颅装备在头盔槽位。[发射器](发射器.md)也可以将头颅装备给没有头戴物品的玩家、[盔甲架](盔甲架.md)和一些人-{}-形生物，且其必须恰好位于发射器前的方块内。

当头颅戴在玩家头上时，头颅的纹理将会覆盖玩家头部的第二层纹理。

# = 伪装 =
玩家戴上[苦力怕](苦力怕.md)、[僵尸](僵尸.md)、[骷髅](骷髅.md)或[猪灵](猪灵.md)的头会将对应的生物探测玩家的默认半径减少50%。这可以与[潜行](潜行.md)时或拥有[隐身](隐身.md)效果时减少探测半径的特性叠加。

[多人游戏](多人游戏.md)中，穿戴头颅的玩家不会在[定位栏](定位栏.md)上显示。

穿戴任意种类头颅的玩家不会出现在其他玩家的定位器[地图](地图.md)上。

# = 凋灵 =

|召唤凋灵的结构图示}}
将4个[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)呈T字形排列，并在其顶端放置3个[凋灵骷髅头颅](凋灵骷髅头颅.md)（也可以使用[发射器](发射器.md)放置头颅，头颅的朝向取决于发射器的朝向），即可召唤凋灵。灵魂沙和灵魂土可以混用。结构可任意旋转。

最后放置的方块必须是凋灵骷髅头颅。T形的两个角落必须是空气方块。

# = 音符盒 =
若[音符盒](音符盒.md)顶面上放置了生物头颅（玩家的头除外），玩家敲击或红石激活音符盒时，音符盒会随机播放对应生物[特定类型的音效](音符盒#生物音效.md)。若是玩家的头，则播放中设置的音效（默认为空）。

# 玩家皮肤

玩家的头可以添加特定的[物品堆叠组件](物品堆叠组件.md)让它显示任何Minecraft正版玩家的皮肤。这意味着如果你想要获得某个人的头，你可以通过修改NBT数据获得它。

若要自己获得某位带有皮肤的玩家的头，可通过这个命令实现。

* 其中<code><玩家名></code>的英文大小写不被区分，按照实际玩家名自动修正。
* * 如填入<code>JEb_</code>变为<code>jeb_</code>，填入<code>notch</code>变为<code>Notch</code>。

当玩家的头被创建时，若未直接指定完整的游戏档案，其纹理（即玩家皮肤）会被保存，这意味着即使对方更换了皮肤，头颅依旧显示原来的纹理。<ref></ref>

# 你知道吗
[thumb|Java版中“套”在僵尸手臂上的龙首](File:Zombie holding dragon heads.png.md)
* 生物头颅是为数不多的没有自身纹理、从其他目标获取纹理的方块之一。
* * 当玩家[采集](挖掘.md)头颅时，其破裂的[粒子效果](粒子效果.md)与[灵魂沙](灵魂沙.md)相同。
* 如果玩家戴上自己的头颅，会发现头颅比实际[皮肤](皮肤.md)中头部的体积更大。
* 来自世界各地的玩家们在[FreshCoal Heads](https://freshcoal.com/maincollection.php)和[Minecraft Heads](https://minecraft-heads.com/)等网站上留下了各种头颅作品。
* 玩家和一些人-{}-形生物手持龙首时，龙首的[物品模型](物品模型.md)会套在其手臂上。
* 不同于其他生物头颅，骷髅头颅和凋灵骷髅头颅的底端开口，可以从底面看到中空的内部。
