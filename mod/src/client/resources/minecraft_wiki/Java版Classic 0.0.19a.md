# Java版Classic 0.0.19a

*页面ID: 35280* | *来源: Minecraft Wiki*

/开发者版本}}
<onlyinclude>

* *0.0.19a**是的一次更新，发布于2009年6月19日<ref>[June 19 IRC logs](#6/19 logs.md): "*P5:35:47 * Notch changes topic to 'http://www.minecraft.net/  |  Client 0.0.19a is up, a server update is required!'<nowiki/>*" (22:35:47 UTC)</ref><ref name="blog"></ref>，加入了[海绵](海绵.md)和[玻璃](玻璃.md)。

# 新内容
# = 方块 =
* *[海绵](海绵.md)**
* 可以吸收周围5格宽的[水](水.md)。<ref>[6月19日的IRC记录](#6/19 logs.md): "*P5:40:07 <wingboy> whats the area the sponge defloods?*" [...] "*P5:40:13 <Notch> wingboy, 5^3*" (22:40 UTC)</ref>
* 一段时间后会消失。<ref>[6月19日的IRC记录](#6/19 logs.md): "*P5:39:42 <Tiralmo> Spange dissappears after a time period?*" [...] "*P5:39:48 <Notch> yes, it "dries out". ;)*" (20:39 UTC)</ref>
* 不会吸收熔岩，但会阻止熔岩流入其可吸收范围。<ref>[6月19日的IRC记录](#6/19 logs.md): "*P5:56:56 <Droqen> Notch: Sponge doesn't take lava away but it stops it from flowing into the area :D*" (20:56 UTC)</ref>

* *[玻璃](玻璃.md)**
*  玻璃具有纹理，但是是半透明的。<ref>[6月19日的IRC记录](#6/19 logs.md): "*P5:42:40 <Syndlig> Make the background color on the grass (the gray/white) empty [...] And then make the streaks 50% opaque*" [...] "*P6:00:20 <UBOA> remove the pixel lines and windows would be perfect*" (23:00 UTC)</ref>
* 在物品栏和水下不渲染。<ref>[6月20日的IRC记录](#6/20 logs.md): "*A5:48:22 <Snowman> the old glass looked better [...] but [...] it was invisible under water*"</ref>

# = 游戏内容 =
* *[快捷栏](快捷栏.md)**
* 用于展示当前可放置的方块。

# 更改
# = 方块 =
* *[水](水.md)和[熔岩](熔岩.md)**
* 现在拥有动态纹理，且稍有不同。<ref>[6月19日的IRC记录](#6/19 logs.md): "*P5:39:20 <wingboy> notch new lava is awesome*" [...] "*P5:39:54 <Evil-Ville> New water looks nice*" [...] "*P5:41:55 <Droqen> Whoa, water animation o_o*" [...] "*P5:46:06 <Droqen> Water is animated*" (22:39至22:46 UTC)</ref>

# = 游戏内容 =
* *[物品栏](物品栏.md)**
* 由于空间不足，在物品栏中移除了[圆石](圆石.md)和[沙子](沙子.md)。<ref></ref><ref>[6月19日的IRC记录](#6/19 logs.md): "*P5:38:29 <Notch> NaiiveMelody: They didn't fit in the inventory. They will come back in the next update*" (22:33:29 UTC)</ref>

# = 常规 =
* *[服务器](服务器.md)**
* 不再能够在服务器上生成新的世界或存储服务器端的世界。

* *其他**
* 限制了帧率。

# 修复
* *修复了1个漏洞**
* 修复了聊天时客户端崩溃的漏洞。

# 你知道吗
* Notch于2003年开发的*[Wurm Online](Wurm Online.md)*的一个版本也叫做0.0.19a。
