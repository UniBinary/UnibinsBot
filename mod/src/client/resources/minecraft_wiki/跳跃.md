# 跳跃

*页面ID: 122171* | *来源: Minecraft Wiki*

* *跳跃（Jumping）**是绝大多数[生物](生物.md)可以进行的移动方式，通常用于跨越垂直方向上的障碍。

不受到效果影响时，绝大多数生物可以跳约1.2522格高。

# 机制
生物站立在地面上时，可以进行跳跃。从结果上看，跳跃的本质是设置了生物在垂直方向上的初始移动速度（即起跳速度）。
* 所有生物都具有****，在中由的计算值决定。
* * 默认情况下为0.42，[马](马.md)及其变种见
* 所有方块都具有**[跳跃乘数](跳跃乘数.md)**，影响在此方块上的跳跃力度。[蜂蜜块](蜂蜜块.md)的跳跃乘数为0.5，显著降低了上方生物的跳跃高度。

玩家可以按下键进行跳跃。打开“”选项时，即将走上方块的玩家在能够登上方块时会向前跳跃。玩家不疾跑时每次跳跃会增加0.05[消耗度](消耗度.md)，疾跑时每次跳跃会增加0.2[消耗度](消耗度.md)。玩家每次成功跳跃时，[统计信息](统计信息.md)<code>minecraft:jump</code>增加1，总跳跃次数可以在统计界面中查看。

大多数生物都具有跳跃的能力，但它们不会随意跳跃。生物会在以下场景中进行跳跃：
* 大多数生物在[寻路](寻路.md)时会将高出最多1格的方块列入路径，在穿越时若不能[走上方块](走上方块.md)，会通过跳跃并向前移动来登上方块。
* [兔子](兔子.md)、[史莱姆](史莱姆.md)和[岩浆怪](岩浆怪.md)的行走动作完全被跳跃代替。
* 幼年[村民](村民.md)白天会随机在床上蹦跳。
* [灾厄村民](灾厄村民.md)、[劫掠兽](劫掠兽.md)和[女巫](女巫.md)在[袭击](袭击.md)事件判定失败且自身存活时，会跳跃庆祝。
* 成年[熊猫](熊猫.md)会在附近有幼年熊猫打喷嚏时因为受惊而跳起。
* [山羊](山羊.md)脚下方块不是[蜂蜜块](蜂蜜块.md)时，有时会随机跳上另一个方块，从而跨越障碍（下文以“长跳”指代）。
* [青蛙](青蛙.md)会随机跳跃，并倾向于跳上大型垂滴叶和睡莲。
* [旋风人](旋风人.md)移动和尝试攻击时均会尝试跳跃。

正在飞行或游泳的生物无法跳跃。

=== 起跳速度 ===

生物在进行跳跃时，游戏会赋予生物一个向上的速度。生物从地面起跳一瞬间的垂直速度被称为起跳速度。

跳跃力度属性可以影响生物的起跳速度。游戏按照下列步骤计算起跳速度：
# 获取生物跳跃力度*j*，生物脚下方块的跳跃乘数*f*。
# 获取生物的跳跃蓄力程度*p*：
# * 对于兔子，跳跃蓄力程度是。
# * 对于玩家骑乘的[马](马.md)、[骷髅马](骷髅马.md)、[僵尸马](僵尸马.md)、[驴](驴.md)、[骡](骡.md)、[羊驼](羊驼.md)和[行商羊驼](行商羊驼.md)，跳跃蓄力程度由当前跳跃蓄力条的进度决定，最小时为0，最大时为1。
# * 对于其他生物，跳跃蓄力程度为1。
# 初步计算起跳速度*v*：<math>v=pjf</math>。
# 如果生物具有[跳跃提升](跳跃提升.md)状态效果，等级为*l*，则继续增加起跳速度：<math>v \leftarrow v+0.1l</math>。
# 如果生物是[岩浆怪](岩浆怪.md)，尺寸为<math>s</math><ref group="注" name="size">为了方便表述，定义**尺寸** <math>s</math> 的值为岩浆怪的NBT标签<code>Size</code>加上1后的值。其中，<code>Size</code>由岩浆怪的小型、中型、大型依次对应1、2、4。</ref>，则继续增加起跳速度：<math>v \leftarrow v+0.1s</math>。

当起跳速度小于0.00001时，生物就无法跳跃。如果生物跳跃力度属性计算值为0，则只有在生物具有跳跃提升状态效果时生物才可以跳起。

除普通跳跃外，起跳速度还决定了[山羊](山羊.md)长跳时的初始速度，而不只是垂直速度。

关于利用起跳速度计算跳跃高度的方式，请见。

# = 替代跳跃 =

跳跃输入的结果并不总是跳跃。一些情况下，生物有跳跃输入时，会改为进行其他移动，而不是跳跃。

在[水](水.md)或[熔岩](熔岩.md)中的生物有跳跃输入（对玩家而言是按下键）时，会改为以固定的速度上升。
* 对于绝大多数生物，上升的速度为0.04格每游戏刻。
* 对于[蜜蜂](蜜蜂.md)，上升的速度为0.01格每游戏刻。
* 对于熔岩中的[岩浆怪](岩浆怪.md)，上升的速度为<math>0.22+0.05s</math>格每游戏刻。<ref group="注" name="size"/>

与[梯子](梯子.md)、[藤蔓](藤蔓.md)、[垂泪藤](垂泪藤.md)、[缠怨藤](缠怨藤.md)等可攀爬方块接触的生物、与[脚手架](脚手架.md)内部接触的[玩家](玩家.md)、与任何方块边缘接触的[蜘蛛](蜘蛛.md)在有跳跃输入时，会改为在方块中向上攀爬。

玩家骑乘生物且具有对生物的直接移动控制时，操作会改为进行“跳跃蓄力”；骆驼以外的生物在跳跃蓄力后会跳跃，骆驼在跳跃蓄力后会冲刺。

穿戴鞘翅的玩家在空中按下时将会滑翔；[创造模式](创造模式.md)的玩家连按两次时将会飞行。

# 你知道吗
* 以下情况中生物虽然也有类似跳跃的动作，但并没有进行跳跃，因此不受其跳跃力度、脚下方块的跳跃乘数等因素的影响：
* * 生物被[击退](伤害#击退.md)或[爆炸击退](爆炸击退.md)影响而飞离地面。
* * [蜘蛛](蜘蛛.md)、[洞穴蜘蛛](洞穴蜘蛛.md)、[狼](狼.md)、[猫](猫.md)、[豹猫](豹猫.md)、[狐狸](狐狸.md)在攻击前扑向目标的动作。
* ** 特别地，狐狸在捕食鸡、兔子等动物前的飞扑动作也不受跳跃提升效果影响，最多上升2-5格。
* * 大多数[水生生物](水生生物.md)在搁浅时的“扑腾”动作。
* * [海豚](海豚.md)跃出水面的动作。
* * [僵尸](僵尸.md)及其变种踩碎海龟蛋的动作<ref></ref>。
* 接触[蜘蛛网](蜘蛛网.md)或[甜浆果丛](甜浆果丛.md)会持续覆盖生物的垂直速度，导致其中的生物跳跃后只能移动非常小的距离。[蜘蛛](蜘蛛.md)和[洞穴蜘蛛](洞穴蜘蛛.md)不受蜘蛛网的影响，[狐狸](狐狸.md)和[蜜蜂](蜜蜂.md)不受甜浆果丛的影响。
