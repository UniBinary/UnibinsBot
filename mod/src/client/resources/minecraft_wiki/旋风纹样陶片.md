# 旋风纹样陶片

*页面ID: 156725* | *来源: Minecraft Wiki*

* *旋风纹样陶片（Guster Pottery Sherd）**是图案形似[旋风人](旋风人.md)的[陶片](陶片.md)。

# 获取
# = 饰纹陶罐 =
被不具有[精准采集](精准采集.md)的工具挖掘破坏或被[弹射物](弹射物.md)击毁时，附有旋风纹样陶片的[饰纹陶罐](饰纹陶罐.md)会掉落旋风纹样陶片。

[试炼密室](试炼密室.md)中生成的饰纹陶罐会随机附有旋风纹样陶片。
