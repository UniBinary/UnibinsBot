# 下界合金块

*页面ID: 52395* | *来源: Minecraft Wiki*

* *下界合金块（Block of Netherite）**是一种由[下界合金锭](下界合金锭.md)合成的方块，其[物品实体](物品实体.md)形式不会被[火](火.md)或[熔岩](熔岩.md)烧毁。

# 生成
下界合金块不会生成在世界中。

# 破坏
挖掘下界合金块的合适工具是镐。下界合金块需要钻石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

下界合金块被破坏后会掉落自身。

# 用途
下界合金块可用于存储[下界合金锭](下界合金锭.md)，以此来节约空间。

下界合金块的[爆炸](爆炸.md)抗性高达1200，与[黑曜石](黑曜石.md)、[哭泣的黑曜石](哭泣的黑曜石.md)、[远古残骸](远古残骸.md)、[附魔台](附魔台.md)、[铁砧](铁砧.md)和[重生锚](重生锚.md)的爆炸抗性相同，因此下界合金块在正常情况下无法被爆炸摧毁。

与黑曜石不同，下界合金块和远古残骸一样可被[活塞](活塞.md)和[黏性活塞](黏性活塞.md)推拉，因此其在[红石电路](红石电路.md)中有特殊用途，如防爆[活塞门](Tutorial:活塞使用#门.md)和活塞盾构机。但下界合金块正在被活塞移动时可被爆炸摧毁。

下界合金块会被[蓝色凋灵之首](蓝色凋灵之首.md)、[凋灵](凋灵.md)的接触和[末影龙](末影龙.md)破坏。[物品实体](物品实体.md)形式的下界合金块会漂浮在[熔岩](熔岩.md)上，不会被[火](火.md)和熔岩摧毁。但和大多数物品一样，下界合金块的物品实体形式仍可被[仙人掌](仙人掌.md)摧毁。

# = 信标 =

下界合金块可作为激活[信标](信标.md)的底座方块。
