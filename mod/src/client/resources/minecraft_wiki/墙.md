# 墙

# 获取
# = 合成 =
所有墙的合成方式都相同，使用6个相同的石质方块即可合成6个对应种类的墙。

# = 切石 =
墙也可以使用切石机制作，1个石质方块可以切出1个对应种类的墙。另外，若甲方块可以切石为乙方块，则甲方块也可以切石为乙方块所对应的墙。

# 用途
[thumb|300px|由于墙上部的碰撞箱高1.5个方块，因此这只兔子看起来像在空中悬浮着](File:FloatingRabbit.png.md)

尽管墙看起来只有1格高且只占据1格的空间，它的[碰撞箱](碰撞箱.md)却有1.5格高（类似于[栅栏](栅栏.md)）。这使得玩家和大多数生物不能直接越过墙。

墙占据着方块的中心位置，大小为0.5×0.5格，较栅栏要更宽，连接的墙宽度则略低为0.375格，所以若两个墙呈对角关系错开放置，玩家不能从它们中间的缝隙通过。

虽然一格墙可以比起两格方块更经济且美观地阻止生物通过，但[骷髅](骷髅.md)仍可以隔着墙朝玩家射箭，[蜘蛛](蜘蛛.md)可以爬上墙。若玩家离得足够近，[苦力怕](苦力怕.md)也会隔着墙爆炸。

墙还可以[含水](含水.md)。

# = 连接 =

与墙相邻的方块与墙相邻的面如果是完整的面，那么墙会自动与之连接，但不会连接[屏障](屏障.md)、[南瓜](南瓜.md)、[雕刻南瓜](雕刻南瓜.md)、[南瓜灯](南瓜灯.md)、[西瓜](西瓜.md)、任何类型的[树叶](树叶.md)和[潜影盒](潜影盒.md)，墙也不会连接栅栏<ref></ref>。

墙会连接侧面与之相邻的[栅栏门](栅栏门.md)。栅栏门与墙相连时会降低高度以适应与墙连接处的外观。

在上方放有底面能完整覆盖墙的中心和墙面的方块时，其会提升墙面的高度以填补与上方方块的空隙。

若墙恰与两个对侧相连或四侧全部相连，则墙的中心柱会消失。但如果墙的上方为以下方块，则墙的中心柱不会消失：
* [火把](火把.md)、[灵魂火把](灵魂火把.md)、[红石火把](红石火把.md)、[绊线](绊线.md)、[告示牌](告示牌.md)、[压力板](压力板.md)、[旗帜](旗帜.md)和[仙人掌花](仙人掌花.md)。<ref group="注">无碰撞箱的特例，由标签控制。</ref>
* [碰撞箱](碰撞箱.md)与墙的中心柱相连的方块。

若某个墙的连接变化会导致其他墙的连接变化，这种变化可以在1游戏刻内连锁传递到每个连接的墙；会以每游戏刻1个墙的速度连锁传递。該特性可以被利用以[傳輸訊號](传输电路#墙传输.md)。
