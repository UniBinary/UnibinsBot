# 大型蕨

*页面ID: 171934* | *来源: Minecraft Wiki*

* *大型蕨（Large Fern）**是两格高的[蕨](蕨.md)。

# 生成
# = 自然生成 =
大型蕨会生成在[针叶林](针叶林.md)、[积雪针叶林](积雪针叶林.md)、[原始松木针叶林](原始松木针叶林.md)和[原始云杉针叶林](原始云杉针叶林.md)生物群系的草方块上。

大型蕨也会在针叶林村庄和中生成。

# = 骨粉 =
对蕨[骨粉](骨粉.md)会使其生长为大型蕨。

# 获取
大型蕨被破坏后不会掉落其[方块物品](方块物品.md)，其唯一的获取方式是仅在世界生成时生成的针叶林[村庄](村庄.md)的[箱子战利品](箱子战利品.md)，这导致了大型蕨是[不可再生资源](不可再生资源.md)。

# = 箱子战利品 =

# 破坏
大型蕨被挖掘时会立刻被破坏。

没有被[剪刀](剪刀.md)挖掘破坏时，大型蕨被破坏后有的概率会掉落1个[小麦种子](小麦种子.md)，挖掘工具的[时运](时运.md)魔咒每有1级，上限增加2。

被剪刀挖掘破坏时，大型蕨被破坏后会掉落2个蕨。

# 用途
大型蕨可以种植在[草方块](草方块.md)、[菌丝体](菌丝体.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[缠根泥土](缠根泥土.md)、[砂土](砂土.md)、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、[苔藓块](苔藓块.md)和[苍白苔藓块](苍白苔藓块.md)上。

# = 堆肥 =
将大型蕨放入堆肥桶里有65%的概率增加1个堆肥等级。
