# Java版Indev 0.31 20100131-2157

*页面ID: 172535* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.31**的一个版本发布于2010年1月31日21:57（UTC）<ref>DBN's logs: (21:57:47) <08Notch> ok, all the old models are in the game now, yay</ref>，修复了一些漏洞。<ref></ref>

# 新内容
# = 生物 =
* *常规**
* 添加了对旧的[生物](生物.md)模型的支持。

# = 常规 =
* *[菜单屏幕](菜单屏幕.md)**
* 含有主菜单和暂停菜单的所有按钮和文字。
* 现在具有游戏logo和缓慢滚动的[泥土](泥土.md)背景。

* *[闪烁标语](闪烁标语.md)**
* 加入了闪烁标语：
* * Pre-Beta!

# 更改
# = 方块 =
* *[水](水.md)**
* 当在水下时，可看见水的纹理。
* 游泳时会产生气泡[粒子](粒子.md)。

* *[棕色蘑菇](棕色蘑菇.md)**
* 现在会发光。<ref></ref>

* *[无限水源](无限水源.md)**
* 现在即使附着的[水](水.md)被移除也会继续生成水。

* *[无限熔岩源](无限熔岩源.md)**
* 现在即使附着的[熔岩](熔岩.md)被移除也会继续生成熔岩。

* *[工作台](工作台.md)**
* 现在底部使用[木板](木板.md)纹理而不是[原木](原木.md)纹理。

# = 物品 =
* *[剑](剑.md)**
* 现在会造成更多的[伤害](伤害.md)：
* * 钻石剑：
* * 铁剑：
* * 石剑：
* * 金剑、木剑：
* 越高等级的工具挖掘速度越快。

* *[工具](工具.md)**
* 现在具有[耐久度](耐久度.md)：
* * 钻石质：257点耐久；
* * 铁质：129点耐久；
* * 石质：65点耐久；
* * 金质、木质：33点耐久；
* * 打火石：65点耐久。
* 剑在击中生物时损耗1点耐久，在破坏方块时损耗2点耐久。

* *常规**
* 现在又会被[火](火.md)和[熔岩](熔岩.md)摧毁了。

# = 生物 =
* *[史蒂夫](Indev_MD3格式生物.md)、[黑史蒂夫](黑史蒂夫.md)和[野兽小子](野兽小子.md)**
* 从游戏中移除。

* *[人类](生物（已移除实体）.md)**
* 现在重新出现。
* 死亡时随机掉落0-2个[火药](火药.md)，[羽毛](羽毛.md)或[线](线.md)。
* 大幅降低了生物自然生成。

# = 游戏内容 =
* *[亮度](亮度.md)**
* 再次修改了方块侧边的阴影。

* *常规**
* 徒手现在只造成伤害。
* 玩家生成时不再携带[打火石](打火石.md)。

# = 世界生成 =
* *常规**
* [基岩](基岩.md)现在出现在世界最底部的2层。
* 熔岩海只会在洞穴切入基岩上层时生成。
* * 下层基岩有极低概率出现缝隙。

# = 常规 =
* *用户界面**
* 全屏模式下，GUI、快捷栏和文本略微增大。

# 修复
* *修复了2个漏洞**
* 拾取新物品时，快捷栏上物品数字不再产生脉冲效果。
* 修复了一些小漏洞。</onlyinclude>
