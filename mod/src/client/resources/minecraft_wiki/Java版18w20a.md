# Java版18w20a

*页面ID: 34745* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w20a**是[Java版1.13](Java版1.13.md)的第35个快照，发布于2018年5月15日<ref></ref>，为命令加入了前缀和后缀，并修复了一些漏洞。

# = 非生物实体 =
* *[闪电](闪电.md)**
* 更改了闪电的名称，从<code>Bolt of Lightning</code>变为<code>Lightning Bolt</code>。

# = 世界生成 =
* *常规**
* 所有在老一些的快照创建的世界应该可以重新打开了。

# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 创造模式下的玩家现在可以在附近有怪物时睡觉。

# = 常规 =
* *文件**
* 更改了许多数据和内部，例如纹理和结构文件。
