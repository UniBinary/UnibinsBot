* *Alpha v1.2.1**是的一次次要更新，发布于2010年11月5日<ref></ref>，修复了一些漏洞。

# 更改
# = 生物 =
* *[敌对生物](敌对生物.md)**
* 现在无论高度如何，敌对生物只会在[光照等级](光照等级.md)小于等于7的区域生成，机制类似于[Alpha v1.2.0](Java版Alpha v1.2.0.md)之前的版本。

# = 方块 =
* *[树叶](树叶.md)**
* [树叶](树叶.md)不再根据灰阶显示纹理，而是根据[生物群系](生物群系.md)显示。

# 修复
* *修复了3个漏洞**
* 仙人掌侧面上的告示牌不会再导致游戏崩溃。
* 优化了生成生物时的CPU使用率。
* 音乐现在会在多人游戏中播放。</onlyinclude>

# 启动器版
Alpha v1.2.1并不存在于启动器中，启动器中的“a1.2.1”实际上是Alpha v1.2.1_01。<ref></ref>
