# 合成

*页面ID: 6334* | *来源: Minecraft Wiki*

* *合成（Crafting）**是一种在[Minecraft](Minecraft.md)中获得多种[方块](方块.md)、[工具](工具.md)和其他资源的方法。合成时，玩家必须先把物品从[物品栏](物品栏.md)移入合成方格中。2×2的简易合成方格可以直接在物品栏中找到，而3×3的合成方格需要使用[工作台](工作台.md)或[合成器](合成器.md)来打开。

# 合成系统
[缩略图|class=pixel-image|alt=2×2 Grid|2×2合成方格（[[物品栏](File:Crafting2x2.png.md)中）]]
[缩略图|class=pixel-image|alt=3×3 Grid|3×3合成方格（[[工作台](File:Crafting3x3.png.md)上）]]

在、[生存模式](生存模式.md)、[冒险模式](冒险模式.md)和中游戏的玩家，其物品栏都会有一个2×2合成方格，可以用来合成长宽都不超过2的配方，如[木板](木板.md)、[木棍](木棍.md)、[工作台](工作台.md)、[火把](火把.md)，或一些无序配方（见下文）。要取得3×3合成方格，必须先制作一个工作台，将其放置在世界中并它后，即可在物品栏中看到3×3合成方格。任何合成配方都能在工作台上完成。

对于一些物品的合成，其原材料的排放位置无关紧要。这些配方称为**无序配方（Shapeless Recipes）**<ref group="注">在本Wiki上，无序配方用配方图像上一对交错的箭头标注，而该符号不会出现在游戏中。</ref>。譬如，[发酵蛛眼](发酵蛛眼.md)、[蘑菇煲](蘑菇煲.md)和[下界合金锭](下界合金锭.md)的合成配方就是无序配方，其原材料可以随意放置在合成方格中任何位置。

但是，许多重要的配方要求原材料以一定规律排列，这些配方称为**有序配方（Shaped Recipes）**。不过，在原材料之间的相对位置保持不变的情况下，原材料排列的整体可以在合成方格内随意移动。例如，一个3×1的配方，如[面包](面包.md)的配方，其原材料三个[小麦](小麦.md)可以排在3×3合成方格的最顶行、中间行或最底行，但却不能在2×2合成方格中合成，因为这种方格不能提供三个小麦横排的位置。这种“有序配方”的位置除了可以平移外，甚至还可以镜像翻转：[弓](弓.md)的配方中，作为“弓弦”的三条竖直排列的线，既可以放在左侧，也可以放在右侧。<!--

有些配方无法以这种方式移动或者镜像翻转，这些配方称为**固定配方（Fixed Recipes）**<ref group="注">在本Wiki上，固定配方用配方图像上一个感叹号标注。该符号不会出现在游戏中。</ref>。原版Minecraft中没有固定配方。

有些配方改变一个物品的类型并保留此物品的所有物品数据，通常还需要额外的原材料，其原材料的排放位置无关紧要，这些配方称为**嬗变配方（Transmute Recipes）**<ref group="注">在本Wiki上，嬗变配方用配方图像上一个从方形指向菱形的箭头标注。该符号不会出现在游戏中。</ref>。使用染料为[收纳袋](收纳袋.md)染色的合成配方是嬗变配方。-->

有些配方不是基于指定物品数量或指定物品排列来输出指定物品，而是处理配方中每一个物品的物品数据和位置来提供合成产品，以进行常规配方无法实现的复杂行为，这些配方称为或<ref group="注">在本Wiki上，定制配方用配方图像上一对花括号标注。该符号不会出现在游戏中。</ref>。[物品修复](物品修复.md)、、[皮革盔甲](皮革盔甲.md)和[收纳袋](收纳袋.md)染色、合成[烟火之星](烟火之星.md)、合成[烟花火箭](烟花火箭.md)、[旗帜](旗帜.md)复制、[成书](成书.md)复制、[地图](地图.md)复制、为[旗帜](旗帜.md)添加图案的合成配方是定制配方。许多定制配方不会显示在配方书中。

一些配方由于需要枚举，被硬编码在代码中，被称为**硬编码配方（Hardcoded Recipes）**。如合成[床](床.md)、使用染料为[潜影盒](潜影盒.md)染色。

# = 合成方格 =
* *合成方格（Crafting Grid）**是一个使用可能的合成[配方](配方.md)子集进行一些基础[合成](合成.md)的方式。2×2方格位于玩家自己的[物品栏](物品栏.md)（默认使用打开）。3×3方格则可通过工作台使用。

2×2方格经常用来将[原木](原木.md)合成为[木板](木板.md)，然后再把木板合成为[工作台](工作台.md)。有时候也会用来将损坏的同种工具或装备合成到一起来修复它们，但是工具和装备上原有的非诅咒魔咒将随着合成而消失。由于在工作台上能使用更多种类的配方，所以玩家在合成工作台之后便通常在工作台上合成物品。

# = 配方书 =

配方书是Minecraft中的[配方](配方.md)目录机制，用于指导玩家合成。此机制显示了所有玩家拥有其原料的配方。

合成配方以多个分类显示：

* ***
* 第一个标签包括所有的已解锁配方。
* 第二个标签包括[工具](工具.md)、[武器](武器.md)与[盔甲](盔甲.md)。
* 第三个标签包括建筑材料。
* 第四个标签包括[食物](食物.md)与杂项[物品](物品.md)。
* 第五个标签包括[红石元件](红石元件.md)。

* ***
分类与[创造分类](创造模式物品栏#基岩版.md)相同：
* 第一个标签栏包含建筑材料。
* 第二个标签栏包含战斗用品、部分[工具](工具.md)和熟食。
* 第三个标签栏包含功能方块、交通工具、[红石元件](红石元件.md)和原材料。
* 第四个标签栏包含自然方块、[农作物](农作物.md)、[染料](染料.md)和生食。
* 第五个“搜索”标签栏包含所有已解锁的配方。

# = 配方系统 =

许多合成配方都可以通过或来添加到游戏中。

# 原主机版的合成系统
[原主机版](原主机版.md)可以使用设置菜单中“用户界面”中的“经典合成”选项来切换到Java版的合成系统。

默认情况下，原主机版引用了一个简化了的合成系统。这个系统不使用标准的合成界面，但跟Java版本的2×2、3×3合成方格有一定的相似。这种界面不需要[玩家](玩家.md)将原材料放置到指定位置，而是像[MATTIS](合成#画廊.md)（Minecraft Advanced Touch Technology Interface System）一样简单地显示配方所需的原材料列表，玩家只需收集齐需要的原材料即可合成。配方被分成7个类别：结构、[工具](工具.md)、[武器](武器.md)、[食物](食物.md)、[盔甲](盔甲.md)、[机械](Tutorial:机械.md)、[运输](运输.md)以及装饰。两个位于两侧的栏可以用于合成[旗帜](旗帜.md)和[烟花火箭](烟花火箭.md)，第三个栏用于合成染色[盔甲](盔甲.md)和一些方块。

按下或也可以打开2×2合成方格，看着工作台时会打开3×3合成方格。由于所有盔甲都需要3×3合成方格来合成，因此在2×2合成方格中没有盔甲栏。

PlayStation Vita版和Wii U版无法使用触控输入来合成。

# 完整配方清單
为了减少空间占用，本wiki显示的一些配方为动画（需要）。无序配方会使用工作台界面中的交叉箭头标记<!--，而固定配方则使用感叹号“！”标记-->，定制配方使用一对花括号标记。

# = 已移除的合成配方 =

一些[物品](物品.md)在旧版本中的[Minecraft](Minecraft.md)里可以合成，但现在已无法合成。
