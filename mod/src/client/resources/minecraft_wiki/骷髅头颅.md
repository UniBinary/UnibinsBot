# 骷髅头颅

*页面ID: 163604* | *来源: Minecraft Wiki*

* *骷髅头颅（Skeleton Skull）**是一种[生物头颅](生物头颅.md)。

# 生成
# = 自然生成 =
[远古城市](远古城市.md)的营房内和中型石柱上各会生成一个骷髅头颅。

# 获取
# = 掉落 =
只有每只[闪电苦力怕](闪电苦力怕.md)杀死的第一个骷髅会掉落骷髅头颅。

# 破坏
没有工具可以加速对骷髅头颅的挖掘。

骷髅头颅被破坏后会掉落自身。

被爆炸破坏的骷髅头颅总是会掉落。

# 用途
骷髅头颅会被液体破坏。

# = 装饰 =
骷髅头颅被放置在方块顶面时可以呈16种不同的方向，而放置在方块侧面时可以呈4种不同的方向。骷髅头颅不需要方块支撑，且可以放置在其他头颅的上方或侧边。

# = 穿戴 =
<div style='float:right'></div>

玩家能将骷髅头颅装备在头盔槽位。[发射器](发射器.md)也可以将骷髅头颅装备给没有头戴物品的玩家、[盔甲架](盔甲架.md)和一些人-{}-形生物，且其必须恰好位于发射器前的方块内。

当骷髅头颅戴在玩家头上时，骷髅头颅的纹理将会覆盖玩家头部的第二层纹理。

# = 伪装 =
玩家戴上骷髅头颅会将骷髅探测玩家的默认半径减少50%。这可以与[潜行](潜行.md)时或拥有[隐身](隐身.md)效果时减少探测半径的特性叠加。

[多人游戏](多人游戏.md)中，穿戴骷髅头颅的玩家不会在[定位栏](定位栏.md)上显示。

穿戴骷髅头颅的玩家不会出现在其他玩家的定位器[地图](地图.md)上。
