# Java版1.16-pre3

*页面ID: 63869* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.16-pre3**是[Java版1.16](Java版1.16.md)的第3个预发布版，发布于2020年6月10日<ref></ref>，加入了新的方块标签，更新了战利品表，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[战利品表](战利品表.md)**
* 为[下界传送门方块](下界传送门方块.md)加入了战利品表。

# = 常规 =
* *[标签](Java版标签.md)**
* 加入了方块标签。
* * 应用于[下界岩](下界岩.md)与[岩浆块](岩浆块.md)。
* * 火会在主世界中使用该标签的方块上无限燃烧。
* 加入了方块标签。
* * 包含方块标签。
* * 火会在下界中使用该标签的方块上无限燃烧。
* 加入了方块标签。
* * 包含方块标签与[基岩](基岩.md)。
* * 火会在末地中使用该标签的方块上无限燃烧。

# 更改
# = 方块 =
* *[熔岩](熔岩.md)**
* 现在当玩家拥有[抗火](抗火.md)状态效果时，在熔岩中的能见度会略有提高。

* *[侦测器](侦测器.md)**
* 更改了被激活时方块背面的纹理。

* *[仙人掌盆栽](仙人掌盆栽.md)**
* 顶面现在使用仙人掌的顶面纹理，而不再使用其侧面纹理。
* 不再装有泥土。

* *[告示牌](告示牌.md)**
* 在英语语言中对GUI中的文本进行了大小写修正，由“Edit sign message”改为“Edit Sign Message”。

# = 物品 =
* *[食物](食物.md)**
* 现在可放在未点燃的[营火](营火.md)上。

* *[菌光体](菌光体.md)**
* 现在可用于堆肥。

# = 生物 =
* *[猪灵](猪灵.md)**
* 即使玩家不在视线范围内，猪灵现在也会在听见玩家破坏箱子、金块或其他类似方块时被激怒。
* 不再拥有专有的头盔纹理。

* *[炽足兽](炽足兽.md)**
* 现在更加常见。

* *[僵尸猪灵](僵尸猪灵.md)**
* 大幅修改了仇恨机制。
* * 被激怒后，每隔到会向附近的僵尸猪灵发出仇恨信号。
* 如在被激怒时死亡，无论其死因如何，现在都有机会掉落只能由玩家击杀所获得的掉落物。<ref></ref>

# = 世界生成 =
* *[堡垒遗迹](堡垒遗迹.md)**
* 此前无法生成的部分内部结构现在可以正常生成了。
* * 包括。
* 移除了部分未使用的内部结构。
* * 包括。
* 移除了中的绿宝石块。

* *[下界要塞](下界要塞.md)**
* 略微提高了生成频率。

# = 游戏内容 =
* *[进度](进度.md)**
* 进度“”不再能通过用金质物品吸引幼年猪灵达成。

* *调试**
* 将快捷键的输出信息中对的描述由“F3 + N = Cycle creative <-> spectator”改为“F3 + N = Cycle previous gamemode <-> spectator”。

# = 常规 =
* *聊天**
* 对文本“Click to copy to Clipboard”进行了大小写更正，改为“Click to Copy to Clipboard”。

* *[制作人员名单](制作人员名单.md)**
* 更新了制作人员名单。

* *[区域文件](区域文件.md)**
* 区域文件现在只能在Windows系统上以同步模式打开，但不影响其他操作系统。这可以下选项进行手动控制：
* * 对于专用服务器：<code>server.properties</code>中的<code>sync-chunk-writes</code>。
* * 对于客户端：<code>options.txt</code>中的<code>syncChunkWrites</code>。

* *[闪烁标语](闪烁标语.md)**
* 将闪烁标语“Sexy!”改为“Moderately attractive!”。
* * 此更改在该快照发布时对实际显示内容没有任何影响，因为2019冠状病毒病大流行（COVID-19 pandemic）相关闪烁标语仍在使用当中。

* *[实体](实体.md)**
* 条件敌对生物现在对任意实体愤怒时都使用<code>AngryAt</code>NBT标签，而不再只对于玩家使用。

* *[标签](Java版标签.md)**
* 物品标签不再应用于金粒。
* <code>sand</code>方块标签现在用于确定海龟蛋是否能在该方块上孵化。

* *创建世界**
* 游戏现在会尝试恢复在[1.16-pre1](Java版1.16-pre1.md)中损坏的世界。
* 现在在加载、创建或重建世界时，读取世界数据的过程中会显示加载界面。
* 在游戏规则界面当中，[游戏规则](游戏规则.md)的描述现在会在必要时以多行显示。
* 修改了部分字符串的大小写。
* * 将“Create backup and load”改为“Create Backup and Load”。
* * 将“Safe mode”改为“Safe Mode”。
* * 将“Edit game rules”改为“Edit Game Rules”。
* * 将“Import settings”改为“Import Settings”。
* * 将“Floating islands”改为“Floating Islands”。
* * 将“Go back”改为“Go Back”。
* * 将“Reset to default”改为“Reset to Default”。

* *选项**
* 将副手的快捷键本地化键名由<code>key.swapHands</code>改为<code>key.swapOffhand</code>。
* 将高品质画质的描述改为“‘高品质’图形会在大多数设备上平衡性能和。[换行]天气、云和粒子可能不会在半透明方块和水的后面显示。”
* * 修改前的文本为“‘高品质’画质将为大部分机器平衡画质和性能。”
* 将极佳画质的描述改为“‘极佳’画质使用屏幕着色器绘制天气、云以及半透明方块和水后面的粒子。[换行]这也许会在便携设备和4K上造成严重的性能负担。”
* * 修改前的文本为“‘极佳’画质将允许画面着色器以像素精度绘制半透明物体。[换行]这也许会在便携设备和4k上造成严重的性能负担。”
* 将控制菜单中切换副手物品键的描述由“交换手中的物品”改为“与副手交换物品”。

* *[袭击存储文件](袭击存储格式.md)**
* 将下界的数据文件从<code>raids_nether.dat</code>重命名为<code>raids.dat</code>。
* * 但是，游戏既不会移动旧文件，也不会从旧文件导入数据。
