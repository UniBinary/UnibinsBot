# 附魔之瓶

*页面ID: 7373* | *来源: Minecraft Wiki*

* *附魔之瓶（Bottle o' Enchanting）**是投掷后会生成[经验球](经验球.md)的物品。

* *掷出的附魔之瓶（Thrown Bottle o' Enchanting）**是投掷附魔之瓶后产生的弹射物。

# = 交易 =

# = 箱子战利品 =

# 用途
附魔之瓶可以将其投掷出去。

[发射器](发射器.md)也可以发射出附魔之瓶。

# 行为
掷出的附魔之瓶属于[弹射物](弹射物.md)，其飞行轨迹会受到重力和环境阻力的影响。

掷出的附魔之瓶穿过[火](火.md)或[熔岩](熔岩.md)不会[着火](着火.md)。

掷出的附魔之瓶不能造成任何伤害。

掷出的附魔之瓶触碰到方块或实体时，会破裂并生成，产生蓝色[粒子](粒子.md)。

# = 与方块交互 =
掷出的附魔之瓶可以触发其击中的[标靶](标靶.md)、敲响[钟](钟.md)或击塌[大型垂滴叶](大型垂滴叶.md)。

掷出的附魔之瓶可以激活[木质压力板](木质压力板.md)和[绊线](绊线.md)。当掷出的附魔之瓶穿过这些方块时，这些开关会保持开启状态。其他开关则不受掷出的附魔之瓶的影响。
