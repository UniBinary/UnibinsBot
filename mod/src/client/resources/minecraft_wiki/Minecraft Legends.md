* *Minecraft Legends**，又名《Minecraft：传奇》，是一款由[Mojang Studios](Mojang Studios.md)、和开发的[即时动作战略游戏](Wzh:即时战略游戏.md)，发布于2023年4月18日。<ref name="mcl"/><ref></ref>

2024年1月10日，Mojang宣布该游戏不再更新，[1.18.19068](MCLG:1.18.19068.md)成为该游戏的最后一个版本。<ref></ref>

# 官方游戏介绍
发掘全新动作策略游戏Minecraft Legends中的奥秘。探索这片拥有富饶资源和繁茂群系，却濒于毁灭的温和大地。猪灵的肆虐正在逼近，您需要鼓舞并带领盟友作战，拯救主世界！

# 游戏内容
Minecraft Legends基于一个很久以前的在村民之间口耳相传的传说故事。传说一位伟大的英雄在下界腐化吞噬主世界之前，团结所有生物对抗贪婪的猪灵的入侵，从而拯救了主世界。<ref name="mcl"/>

游戏背景设置在Minecraft世界，原版[Minecraft](Minecraft.md)游戏中的玩家被平行世界的三位领主（远见、学识和行动）指引至一个正在遭遇下界猪灵联军腐化侵袭的主世界。玩家以第三人称视角扮演一位英雄，保卫村庄和基地并与成群结队的猪灵战斗以阻止它们来自下界的腐败继续传播，联合主世界的盟友、召唤上古留存的傀儡共同捍卫这个田园诗般的世界。游戏允许玩家指挥盟友进行战斗。游戏具有随机的世界生成，并包含不同于Minecraft世界的生物和生物群系。玩家还需要在地图中收集资源以建造基地、建设改进。游戏支持最多4人团队与猪灵作战，支持最多8人两队的PvP对战。

# = 战役模式 =

* *战役模式**是游戏的主线模式，首次进入游戏的玩家将在其中接受新手教学。玩家作为拯救世界的英雄接受领主的召唤，手持钻石剑进入被猪灵侵袭的主世界。玩家需要守护世界生命力量的源泉——**命运之井**、击退猪灵不断的袭击、摧毁日益逼近的前哨，最终击败猪灵三大族群的首领和猪灵王，将主世界净化至曾经温和富饶的土地。

# = 对战模式 =

* *对战模式**是游戏的PVP模式，允许最高8人的橙、蓝两队玩家进行作战。玩家以摧毁对手的基地为胜利目标，但同时仍需抵御世界各处猪灵的威胁。这一模式中，玩家需要默契的团结协作和高超的游戏策略，兼顾基地防御与进攻，取-{}-得最终胜利。游戏发起者可限制游戏人数和玩家来源，匹配模式下可选择匹配用户的地区和平台。最终游戏胜负不会对玩家进行奖惩。

# = 失落的传奇 =

* *失落的传奇**是游戏的附加玩法，由官方制作人员在市场中提供。游戏保持更新时，每月发布一部免费的失落的传奇，共有9部。玩家可在商店中下载对应DLC后开始单人游戏或发起最多4人的多人游戏，游戏胜利后可获得玩法对应的奖励。

# = 神话 =

* *神话**是商店中提供的另一类付费的附加游戏玩法，由市场创作者“House of How”制作，共有7部神话可供购买。神话不能进行多人游戏，神话启动时游戏会自动断开在线连接，即便联机玩家均购买了DLC。

# = 生物 =

* *生物**是Minecraft Legends中一类重要的实体，包含很多[原版游戏](Minecraft.md)中未出现的生物。玩家阵营的生物主要包括领主、主世界生物、傀儡生物，猪灵阵营的生物包括三大族群生物和猪灵首领。玩家阵营生物需要在对应的生成器上消耗一定资源和青金石生成。

# = 建筑结构 =

* *建筑结构**是由玩家演奏鲁特琴命令黄色的建造型悦灵搭建而成的一类方块结构。玩家使用不同资源建造不同类型的建筑，有些用于基地防御，抵御敌人进攻；有些可用于召唤我方生物单位；有些可为己方提供增益效果和游戏改进；有些可帮助玩家行动和进攻等。同时猪灵阵营也具有多种建筑结构，这些结构会自动生成，玩家不干预的条件下可能无限蔓延。

# = 生物群系 =

主世界大陆四面环海，陆地上划出为多种不同区域。这些区域有着地形、外观、资源等方面的显著差异，称为生物群系。对于未被猪灵占领的土地，地图上会标记为森林、草地、恶地等群系；猪灵占领后显示为对应族群的据点种类。

# 开发
Minecraft Legends原本是Mojang的一个想法，后来Mojang决定和曾参与开发[Minecraft Earth](Minecraft Earth.md)的合作，来开发一个Minecraft的战略游戏。<ref name="mcl"/>
