# 基岩版1.18.20.25

*页面ID: 92807* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.18.20.25**（Xbox/Windows/Android）、**Preview 1.18.20.26**（iOS/iPadOS/Xbox/Windows）是[基岩版1.18.30](基岩版1.18.30.md)的第3个测试版，发布于2022年2月9日<ref></ref>，在[实验性玩法](实验性玩法.md)中调整了一些特性，并修复了一些漏洞。

# 新内容

* 由于此命令尚未完全实现，下个测试版有可能会移除此命令。<ref></ref>

# 更改
# = 物品 =
* *[船](船.md)**
* 更改了云杉木船的物品纹理。
* * 新纹理暂时不会在游戏中显示。<ref></ref>

# = 生物 =
* *[海龟](海龟.md)**
* 现在会跟随垂直方向上手持[海草](海草.md)的玩家。

# = 游戏内容 =
* *[饥饿](饥饿.md)**
* 调整了玩家饥饿值的消耗速度以匹配。

* 现在可以在行为包中调整饥饿值的消耗速度。

# = 常规 =
* *[RenderDragon](RenderDragon.md)**
* 再次禁用（仅Android平台）。

# 修复
* *游戏内容**
* 现在放置紫水晶簇时会将其附着方块上的流动的水移除。（）
* 回退了对生物在珊瑚扇上的寻路问题的修复。
* 调整了玩家饥饿值的消耗速度以匹配Java版。（）
* * 现在玩家疾跑或游泳时会以正确的速度消耗饥饿值。
* * 显著降低了玩家跳跃时消耗的饥饿值。
* * 现在可以在行为包中调整饥饿值的消耗速度。

* *生物**
* 修复了拥有抗火效果的生物无法免疫火焰伤害的问题。
* 如乘船等情况下的生物不再能应用JumpToBlockGoal。（）

* *用户界面**
* 现在玩家死亡时会重置其潜行状态，以防止玩家重生后一直保持潜行状态。
* 新的创建新世界UI中的资源包选项卡现已可用。

* *原版趋同**
* 渔夫村民现在会根据其生物群系服饰而出售不同种类的船。
* 牧师村民现在会出售荧石而不是荧石粉。
* 武器匠出售附魔铁剑所需的级别更改为新手级别。
* 盔甲匠收购钻石所需的级别更改为老手级别。

* *命令**
* 现在使用命令时，纸娃娃和物品栏中的玩家会正确更新。（）

* *技术性**
* 现在覆盖迷雾设置时会默认使用原版的生物群系特定迷雾设置。
* 在客户端完成加入前触发的标题命令现在会正确显示，而不是被忽略。
* 修复了光线追踪资源包会在退出已开启RTX的存档时过早被卸载的问题。</onlyinclude>
