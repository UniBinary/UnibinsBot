# 足迹与故事活动

*页面ID: 104832* | *来源: Minecraft Wiki*

* *足迹与故事活动（Trails & Tales Event）**<ref group="注">[主菜单](主菜单.md)上称作**夏季活动（Summer Event）**，游戏内聊天栏称作**足迹与故事主题公园（Trails and Tales Theme Park）**。</ref>是在2023年6月23日10:00（PST）至6月25日22:00（PST）限时开放的官方[活动服务器](活动服务器.md)，游戏内容和[足迹与故事](足迹与故事.md)的新增特性有关。

# 足迹与故事主题公园
玩家的活动区域是整个主题公园的内部。

主题公园主要分为广场、“樱花树林”（Cherry Grove）、“骆驼峡谷”（Camel Canyon）和“失落世界”（The Lost World）4个区域，其中包含多种娱乐设施和供多人游玩的小游戏。与工作人员NPC对话即可参加游戏。竞赛类游戏会在结束时公布参与者的排名。

园区的路边有垃圾箱和能坐的长椅。[骆驼](骆驼.md)、[鸡](鸡.md)、[苦力怕](苦力怕.md)、[恶魂](恶魂.md)、[山羊](山羊.md)、[铁傀儡](铁傀儡.md)、[熊猫](熊猫.md)、[绵羊](绵羊.md)、[嗅探兽](嗅探兽.md)和[监守者](监守者.md)10种生物公仔隐藏在公园的各个角落。

# = 广场 =
[嗅探兽草雕|thumb](File:Sniffer_Hedge_(Trails_and_Tales_Summer_Event)_Render.png.md)
广场靠近主题公园的大门，四周环绕着多个房屋。商品区的中心有一个[嗅探兽](嗅探兽.md)形状的草艺雕塑。

; 疯狂矿车
[木质矿车|thumb](File:Minecart_(Trails_and_Tales_Summer_Event)_Render.png.md)

“疯狂矿车”（Minecart Madness）的起点位于玩家出生点的左侧。玩家可乘坐木质纹理的[矿车](矿车.md)行驶在主题公园的边界，依次路过“樱花树林”“骆驼峡谷”和“失落世界”，最后在起点的对面下车。矿车经过[气泡柱](气泡柱.md)水洼时会被向上抬升。

玩家经过[沙漠神殿](沙漠神殿.md)时可发现隐藏的苦力怕公仔。

; 商店

每个商店内都有一个服务员NPC。与NPC对话或与店中陈列的商品实体交互可获得对应的物品。物品无法从[物品栏](物品栏.md)中丢出，但会在玩家退出服务器时消失。

饮用火把花茶可获得[夜视](夜视.md)效果，其他食物和饮品则会给予玩家[迅捷](迅捷.md)效果。面具和帽子可以放入头盔槽来戴在头上。

# = 樱花树林 =
[thumb|“樱花树林”门牌](File:Sign_Cherry_Grove_(Trails_and_Tales_Summer_Event)_Render.png.md)

大量的[樱花树](樱花树.md)和樱花木建筑是“樱花树林”区域的特色。

; 竹筏漂流竞速

; 生物群系踪迹迷宫
“生物群系踪迹迷宫”（Biome Trail Maze）是一个中等难度的计时迷宫，结构类似于[洞穴](洞穴.md)，环境设计成微缩的[海底神殿](海底神殿.md)、[绯红森林](绯红森林.md)、[沙漠](沙漠.md)、[深暗之域](深暗之域.md)、[要塞](要塞.md)和[末地](末地.md)。

玩家可在迷宫中发现隐藏的监守者和恶魂公仔。

; 樱花树跑酷
“樱花树跑酷”（Cherry Tree Parkour）是一个中等难度的计时跑酷区域，途经大型樱花树、仿日式建筑和2个记录点。

; 热气球
[thumb|热气球](File:Hot_Air_Balloon_(Trails_and_Tales_Summer_Event)_Render.png.md)
玩家可乘坐热气球（Hot Air Balloon）实体原地上升，以俯瞰整个主题公园。热气球能同时搭载4名玩家。

; 竹筏露脸展板
“竹筏露脸展板”（Raft Cutout）上画着正在划竹筏的Zuri和Efe。玩家站在展板背面的台子上时，相机视角会对准展板正面，以供玩家留影。

# = 骆驼峡谷 =
[“骆驼峡谷”门牌|thumb](File:Sign_Camel_Canyon_(Trails_and_Tales_Summer_Event)_Render.png.md)

“骆驼峡谷”是主题公园中的沙漠风格区域，有风蚀柱景观、[沙漠神殿](沙漠神殿.md)及[沙漠村庄](村庄.md)风格的小镇。

; 沙漠快跑

“沙漠快跑”（Desert Dash）竞速游戏要求玩家在2分钟内骑乘[骆驼](骆驼.md)环绕沙地赛道两圈。赛道上飘浮的蓝色气球会施予骆驼3秒的[迅捷](迅捷.md)II效果。

# = 失落世界 =
[“失落世界”门牌|thumb](File:Sign_Lost_World_(Trails_and_Tales_Summer_Event)_Render.png.md)

“失落世界”是一个[嗅探兽](嗅探兽.md)主题的植被繁茂区域。

; 生物脑袋迷

“生物脑袋迷”（Mob Head Mania）共有4个游玩场地，每个场地限一名玩家游玩。在每轮游戏中，玩家会听到由[苦力怕](苦力怕.md)、[猪灵](猪灵.md)、[末影龙](末影龙.md)、[骷髅](骷髅.md)和[僵尸](僵尸.md)的音效拼接而成的“旋律”，接着要按顺序点击带有对应[生物头颅](生物头颅.md)的[音符盒](音符盒.md)上的按钮，以复现这段旋律。回答正确可继续游玩下一轮，回答错误会立即终止游戏。头一轮只播放一种生物的音效，接下来的每轮会多加一种音效。

; 丛林树跑酷
“丛林树跑酷”（Jungle Tree Parkour）是一个中等难度的计时跑酷区域，途经2个记录点。

; 远古洞穴跑酷
“远古洞穴跑酷”（Ancient Cave Parkour）是一个高难度的计时跑酷区域，途经3个记录点。

; 嗅探兽露脸展板
“嗅探兽露脸展板”（Sniffer Cutout）上画着夕阳下的两只嗅探兽。玩家站在展板背面的台子上时，相机视角会对准展板正面，以供玩家留影。
