# Java版Alpha v1.0.16 02

*页面ID: 32520* | *来源: Minecraft Wiki*

<onlyinclude>

* *Alpha v1.0.16_02**是[Alpha v1.0.16](Java版Alpha v1.0.16.md)的一个漏洞修复版本，发布于2010年8月13日，修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 用于[玩家](玩家.md)与玩家进行联络。

* ***
* 用于显示在线玩家列表。

# 更改
# = 游戏内容 =
* *[多人游戏](多人游戏.md)**
* 管理员现在可在玩家出生点附近放置[方块](方块.md)。

# = 常规 =
* *[服务器](服务器.md)**
* 现在会记录管理员做了什么事，并将所有管理日志都广播给所有在线的服务器管理员。

# 修复
* *修复了2个漏洞**
* 修复了命令的漏洞。
* 修复了一个与玩家（以及生物）死亡有关的漏洞。</onlyinclude>
