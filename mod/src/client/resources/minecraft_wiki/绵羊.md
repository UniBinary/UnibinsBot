* *绵羊（Sheep）**是[主世界](主世界.md)中一种常见的友好生物。它们是[羊毛](羊毛.md)和[羊肉](羊肉.md)的来源。

# 生成
生成的大多数绵羊都是白色、淡灰色、灰色、黑色或者棕色的，粉红色绵羊只有极小的概率生成。所有的绵羊又有5%的概率生成为幼年个体。

# = 自然生成 =
绵羊会在主世界亮度等级大于等于7，且上方空间大于等于2格的[草方块](草方块.md)上生成。

在不同的[生物群系](生物群系.md)中，绵羊会以特定的毛色生成，具体如下表所示：

尽管在所有生物群系中生成的绵羊都有对应变种，但它们只会在[苍白之园](苍白之园.md)以外的[森林类生物群系](森林类生物群系.md)、[沙漠](沙漠.md)以外的[干旱类生物群系](干旱类生物群系.md)、[平原](平原.md)、[向日葵平原](向日葵平原.md)、[沼泽](沼泽.md)、[草甸](草甸.md)、[樱花树林](樱花树林.md)、[风袭丘陵](风袭丘陵.md)、[风袭森林](风袭森林.md)、[风袭沙砾丘陵](风袭沙砾丘陵.md)中自然生成。

绵羊还可以在[村庄](村庄.md)的牧羊人小屋、肉铺和牲畜栏里生成。

[剪刀](剪刀.md)给绵羊剪羊毛，会掉落1-3个对应颜色的，并且不会造成任何伤害。幼年绵羊无法被剪毛。

幼年绵羊死亡后不会掉落任何物品和经验。

# 行为
绵羊会漫无目的地游荡和避免从高处掉落以防止受到摔落伤害。它们还会避开[水](水.md)和[熔岩](熔岩.md)。

它们会尝试跳过一格高的障碍物，这导致它们会在[栅栏](栅栏.md)和[墙](墙.md)旁徘徊，但始终跳不上去。由于成年绵羊的体型较大，它们不能从两个呈对角关系错开放置的栅栏之间通过。

# = 染色 =
[thumb|16种颜色的绵羊，及其对应的羊毛颜色](File:Wool Colors.png.md)
对绵羊[染料](染料.md)可以改变其羊毛的颜色，并且在剪羊毛时获得相应颜色羊毛。在羊毛重新长出来之前，绵羊不能被染色。

绵羊被剪毛后身上剩余的毛斑块会保留剪毛前染的颜色。

绵羊的羊毛颜色是永久的，并且会遗传给幼年绵羊。

# = 吃草 =
[thumb|一只绵羊在吃草](File:Sheep Eating Grass.gif.md)

成年和幼年绵羊每2个游戏刻分别有和的概率尝试吃一次草，它们每游戏刻都分别有和的概率尝试吃一次草。它们会吃[草方块](草方块.md)上的草皮，使其变成[泥土](泥土.md)；或是吃掉[矮草丛](矮草丛.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)和。如果一个草方块上方长有这些植物，绵羊会优先选择吃掉它们。绵羊能透过不足1格高的方块（如[蜂蜜块](蜂蜜块.md)）吃草。被剪毛的成年绵羊只会在吃草后重新长出羊毛，幼年绵羊每次吃草可以使成长用时减少1分钟。如果绵羊吃草时[游戏规则](游戏规则.md)设为，草方块、矮草丛或不会变化，而绵羊仍会长毛或成长。<ref></ref>

# = 被命名为jeb_的绵羊 =

[左|thumb|一只被命名为“jeb_”的绵羊](File:Jeb Sheep.gif.md)
如果命名牌将一只绵羊命名为“jeb_”，则羊毛的颜色会渐变地显示所有可以染色的颜色。这种渐变效果类似于[海晶石](海晶石.md)。但这只是一个视觉上的效果，剪毛时只会掉落命名前的对应颜色的羊毛。

# = 唤魔者 =
[thumb|唤魔者对一只绵羊施展咒语](File:EvokerWololo.gif.md)
当[唤魔者](唤魔者.md)处于非战斗状态中时，唤魔者会把16格以内的所有蓝色绵羊的羊毛颜色变成红色。在此之前唤魔者会冒出橙色的粒子（），并发出“呜噜噜”的声音作为警告。唤魔者在[游戏规则](游戏规则.md)设置为时不能改变绵羊的颜色；即便是设置为，它仍然能改变绵羊的颜色。

# = 繁殖 =

[缩略图|一只混合了父母双方颜色的幼年绵羊](File:SheepBreedingColor.png.md)

绵羊会跟随/手持[小麦](小麦.md)的玩家。

给两只绵羊喂食小麦能让它们[繁殖](繁殖.md)出一只幼年绵羊，繁殖之后会给予玩家，并且双亲在/内不再能繁殖。

[幼年绵羊](繁殖#幼年生物.md)会在20分钟后长大，每次喂食小麦可减少约10%的剩余生长时间。

对幼年绵羊[金蒲公英](金蒲公英.md)可以阻止其成长为成年绵羊，再次对其金蒲公英将使其重新开始成长。被阻止成长的幼年绵羊无法被喂食除金蒲公英外的其他物品。

幼年绵羊的毛色为双亲羊毛颜色的[有效混色](染料#混色机制.md)，如果有效混色不存在则随机遗传一方的毛色。

# 你知道吗
* 如果通过放置绵羊刷怪笼，在刷怪笼里面旋转的模型会是一只黑色的绵羊，生成的绵羊只会是自然生成的绵羊的颜色；除非向NBT标签加入了指定的颜色。往NBT标签里添加了指定的颜色之后，仍然有机会生成其他颜色的绵羊。
* 绵羊可以通过局部的方块吃草，即使在移动的矿车里时也是如此。
* 绵羊体型较大，不能通过2个斜对角放置的栏杆之间的缝隙，然而玩家（和其他多数生物）却可以轻松通过。
