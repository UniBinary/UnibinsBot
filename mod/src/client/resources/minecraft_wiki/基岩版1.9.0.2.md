# 基岩版1.9.0.2

*页面ID: 37486* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.9.0.2**是[1.9.0](基岩版1.9.0.md)的第2个测试版，发布于2018年11月28日<ref></ref>，加入了多种装饰性方块，在暂停菜单中加入了反馈按钮，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[制图台](制图台.md)、[制箭台](制箭台.md)、[砂轮](砂轮.md)、[钟](钟.md)、[木桶](木桶.md)、[锻造台](锻造台.md)、[烟熏炉](烟熏炉.md)、[高炉](高炉.md)**
* 可通过开启[实验性玩法](实验性玩法.md)获得，暂时没有实际用途。
* *[灯笼](灯笼.md)**
* 新的光源。
* 可以放在方块顶部或底部。
* 发出亮度等级15的光。
* 可通过开启[实验性玩法](实验性玩法.md)获得，暂时无法合成。

# = 命令 =
* *[游戏规则](游戏规则.md)**
* 通过函数运行的命令数量可以用一个新的选项来限制（默认为10000），以限制性能
* *[函数](基岩版函数.md)**
* 现在可以每刻运行，用于创建一个更新循环。
* *[标签](基岩版标签.md)**
* 自定义标签可以应用到实体和玩家，以创建更灵活的选择器分组。
* 在组件中添加了过滤器，以允许检查实体是否具有指定的标签。
* 自动完成可用于标签。
* ***
* 控制实体的储存的标签。
* ***
* 现在[命令](命令.md)可以杀死[创造模式](创造模式.md)下的[玩家](玩家.md)了。

# = 常规 =
* *[暂停菜单](暂停菜单.md)**
* 加入了一个新的“反馈”按钮。
* * 显示Minecraft反馈网站，Mojira漏洞追踪器和Mojang的支持链接。
* “游戏指南”按钮在游戏内设置菜单可见。
* *其他**
* 加入了“fish barrel”方块的未使用的纹理。

# 更改
# = 方块 =
* *[炼药锅](炼药锅.md)**
* 现在能用来储存[熔岩](熔岩.md)。
* *[告示牌](告示牌.md)**
* 将默认文字颜色改回黑色。
* 变种现在被分组到“告示牌”分类下。

# = 生物 =
* *[掠夺者](掠夺者.md)**
* 现在有了拉弦动画和声音。
* *[被动型生物](被动型生物.md)**
* 现在会随机进入繁殖模式。

# = 世界生成 =
* *[丛林神庙](丛林神庙.md)和[村庄](村庄.md)**
* 将[石头楼梯](石头楼梯.md)替换为[圆石楼梯](圆石楼梯.md)。

# = 常规 =
* *[多人游戏](多人游戏.md)**
* 玩家现在可以加入和玩一个次要版本不匹配的游戏。（）

# 修复
* *修复了47个漏洞**
* 物品展示框里的潜影盒导致游戏崩溃。
* 服务器商店里的单项内容显示错误。
* 幼年僵尸的-{}-头部尺寸不正确。
* 活塞推动方块时游戏崩溃。
* 暂停或继续游戏时游戏崩溃。
* 改进了玩家在没有许可证的情况下进行游戏的警告信息。
* 铁傀儡的手臂位置不正确。
* 熊猫着火时仍会继续进食。
* 安卓设备里暂停然后继续游戏时使得游戏崩溃。
* 使用鼠标点击物品或文本框时出现错误。（）
* 末地折跃门的生成距离太短，导致玩家无法返回末地主岛。
* 史莱姆不会正常生成在史莱姆区块里。（）
* 末影人在被激怒是不会播放愤怒音效。（）
* 被火焰附加武器杀死的幻翼不会掉落幻翼膜。（）
* 步行穿过脚手架时，自动跳跃功能出现错误。（）
* 脚手架不能放置在玻璃上面。
* 现在可以将更多方块放置在脚手架的上面，例如生物头颅和花盆。（）
* 水平方向流动的水不再使得下面放置的灵魂沙生成气泡柱。
* 修复了一个导致Gear VR断开手柄连接的漏洞。
* 暂停然后继续游戏时出现崩溃现象。
* 修复了在皮肤包里只有单腿的形象的腿部渲染问题。
* 迅速登入和登出Xbox Live账户时游戏崩溃。
* 多人游戏下，末影龙的龙息不能收集。（）
* 着火的熊猫不会表现出惊慌。
* 现在可以听见掠夺者填充弩的音效和看见动画效果。（）
* 丛林神庙和村庄里的圆石楼梯被石头楼梯取代。（）
* 燃烧的熔炉现在可以使用+选取方块键而获取。
* 自定义模型格式现在支持双行操作。（）
* 使用命令时，现在可以显示特殊字符。
* 使用触摸屏时，“交换潜行和跳跃”选项现在能够对脚手架正确运作。（）
* 女巫发出黑色的粒子，而不是紫色的。（）
* 创造模式物品栏里，台阶被视作“半个台阶”。（）
* 紧挨树叶的脚手架会出现纹理深度冲突。（）
* 船上的生物在注视玩家时不再摇晃身体。
* 气泡柱会越过水面生成。（）
* 使用触摸屏时，可以从快捷栏里快速丢弃物品。（）
* 破坏平滑石头时会掉落圆石。（）
* 门被破坏时掉落双份掉落物。（）
* 分屏模式下暂停游戏时，闪烁标语的缩放显示错误。
* 恶魂火球的发射动画不正确。
* 命令方块里的命令不再拓展到其他维度里，但此项修复不对已经存在的命令方块起作用。（）
* 从多人游戏断开连接时，无法再继续进行游戏。
* 修复了Xbox One版的崩溃现象。
* 切换多人游戏选项时，玩家会困在离线状态。（）
* 在重新加载世界时，台阶无法相互放置。（）
* 更改游戏模式并重新进入世界时使得资源包被卸载。
* “Mutant Battle Arena”资源包里的手位置不正确。</onlyinclude>
