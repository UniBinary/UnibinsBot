* *13w23b**是[Java版1.6.1](Java版1.6.1.md)的第12个快照，发布于2013年6月7日<ref></ref>，发布以修复[13w23a](13w23a.md)里的漏洞和崩溃，加入了[生命提升](生命提升.md)状态效果，更新了僵尸的生物AI，并修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[状态效果](状态效果.md)**
* 加入了[生命提升](生命提升.md)效果。
* * 新的生命属性拥有同样的效果。

# 更改
# = 物品 =
* *[金苹果](金苹果.md)**
* 现在会给予新加入的[生命提升](生命提升.md)效果。
* 现在会给予10秒的生命恢复II效果。

# = 生物 =
* *[僵尸](僵尸.md)**
* 新的机制和AI。
* * 能从更远的距离锁定玩家。
* * 有目标的僵尸现在即使离玩家32米外也能继续移动。
* * 在没有被注视的时候会生成额外的僵尸。

# 修复
参数的刷怪笼会导致游戏崩溃。
