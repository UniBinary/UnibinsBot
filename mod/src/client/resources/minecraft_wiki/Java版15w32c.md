# Java版15w32c

*页面ID: 17324* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w32c**是[Java版1.9](Java版1.9.md)的第6个快照，发布于2015年8月7日<ref></ref>，修复了[15w32a](15w32a.md)和[15w32b](15w32b.md)中的漏洞。

# 更改
# = 结构生成 =
* *[末地船](末地城#末地船.md)**
* 不再与[信标](信标.md)一同生成。
* * 被[南瓜](南瓜.md)代替了。
* 现在会在船头生成一个龙首。

# = 游戏内容 =
* *[粒子](粒子.md)**
* 不再是实体了。
* * 这将会降低内存使用来提高游戏表现效率。
* 拓宽了数量和范围限制。
* * 粒子的数量被限制为16384个（见[调试屏幕](调试屏幕.md)中P的下方）。
* * 范围限制是31（当命令伴随着<code>force</code>模式被使用，将不会有范围限制）。

# = 常规 =
* *世界选择界面**
* 按下编辑按钮后会出现2个新的选项：
* * 重设图标：允许玩家不需要进入文件夹就能删除世界图标。
* * 打开文件夹：按下后打开<code>.minecraft</code>里的世界文件夹。
