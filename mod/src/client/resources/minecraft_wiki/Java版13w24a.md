# Java版13w24a

*页面ID: 33556* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w24a**是[Java版1.6.1](Java版1.6.1.md)的第13个快照，发布于2013年6月13日<ref></ref>，加入了一条新的游戏规则，加入了资源包以取代纹理包，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 为[昼夜更替](昼夜更替.md)加入了新的游戏规则<code>doDaylightCycle</code>。
* * 设为<code>false</code>将停止在当前的时间，使天空暂停移动。

# 更改
# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 现在可在[水](水.md)上使用。

# = 生物 =
* *[蜘蛛](蜘蛛.md)**
* 现在有概率在生成时带着药水效果。

# = 常规 =
* *[资源包](资源包.md)**
* 移除了[纹理包](纹理包.md)的支持，现在被[资源包](资源包.md)取代。
