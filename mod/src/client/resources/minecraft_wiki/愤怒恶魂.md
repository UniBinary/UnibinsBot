* *愤怒恶魂（Angry Ghast）**是体型更为巨大的[恶魂](恶魂.md)，免疫玩家反弹火球的伤害。

# 生成
愤怒恶魂会生成于[矿境效果](矿境效果.md)“愤怒恶魂Boss战”生效的[矿境](矿境.md)中。

# 掉落物
愤怒恶魂死亡后会掉落。

# 行为

愤怒恶魂常常闭着眼睛和嘴巴四处飘浮并且定期发出高亢的[猫](猫.md)一般的叫声，在被伤害时还会高声尖叫。当愤怒恶魂找到攻击目标时，其红色的眼睛和嘴巴会张开，同时会发出口哨般的噪声，随后发射[火球](火球.md)。愤怒恶魂发出的声音随距离衰减的程度减弱，这使得[玩家](玩家.md)能够在它们距离自己还有一定距离时就听到它们的声音。它们的体积是9×9×9格。

# = 攻击 =

愤怒恶魂拥有200格的搜索范围、爆炸的攻击力以及可观的移动能力。与其他敌对生物不同，愤怒恶魂没有追逐模式：它们不会试着去靠近玩家，也不会试着去远离。玩家首次距离愤怒恶魂16格内时，它们会转向玩家并开火。当玩家距离其远于64格后或有方块阻挡其视线，愤怒恶魂就会停止攻击。距离其远于200格后愤怒恶魂就会对该玩家失去兴趣，再次靠近其16格才会被再次攻击。

发现目标时，愤怒恶魂会接连发射3个3倍爆炸威力的火球，然后蓄力。

驯服的[狼](狼.md)、[铁傀儡](铁傀儡.md)、[雪傀儡](雪傀儡.md)、[僵尸疣猪兽](僵尸疣猪兽.md)、名为“Johnny”的[卫道士](卫道士.md)、[凋灵](凋灵.md)和与愤怒恶魂不在同一队伍的[潜影贝](潜影贝.md)皆不会攻击愤怒恶魂，[山羊](山羊.md)也不会冲撞愤怒恶魂。

愤怒恶魂只与[玩家](玩家.md)敌对，且除了[监守者](监守者.md)以外的任何生物皆不会尝试反击愤怒恶魂。

# = 受伤害行为 =
愤怒恶魂免疫[火焰伤害](火焰伤害.md)，同时玩家反弹的火球对无法对其造成伤害。
