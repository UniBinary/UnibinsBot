# Java版12w03a

*页面ID: 32312* | *来源: Minecraft Wiki*

<onlyinclude>

* *12w03a**是[Java版1.2.1](Java版1.2.1.md)的首个快照，发布于2012年1月19日<ref></ref>，加入了[丛林](丛林.md)生物群系和丛林树，并更新了[僵尸](僵尸.md)的AI。

# 新内容
# = 方块 =
* *[丛林树叶](丛林树叶.md)**
* 在丛林树上生成。

* *[丛林木](丛林木.md)**
* 略苔藓棕色的纹理与水平翻转的树皮。
* 在丛林树上生成。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 加入了[丛林](丛林.md)生物群系。
* * 拥有厚树冠的丛林树、藤蔓、蕨和亮绿色的草。

# 更改
# = 方块 =
* *[梯子](梯子.md)**
* 重新加入了碰撞箱。

* *[藤蔓](藤蔓.md)**
* 藤蔓后面有固体方块的情况下玩家可以攀爬。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* [发射器](发射器.md)发射刷怪蛋时可以直接生成对应的生物。
* 现在可堆叠至64个。

# = 生物 =
* *[狼](狼.md)**
* 被驯服后可以通过喂食[生鸡肉](生鸡肉.md)、[熟鸡肉](熟鸡肉.md)、[生猪排](生猪排.md)、[熟猪排](熟猪排.md)、[生牛肉](生牛肉.md)、[牛排](牛排.md)和[腐肉](腐肉.md)使其繁殖。

* *[僵尸](僵尸.md)**
* 有了新的寻路AI。

# = 常规 =
* *语言文件**
* 更新了语言文件。</onlyinclude>
