# 携带版0.16.1

*页面ID: 26163* | *来源: Minecraft Wiki*

* *v0.16.1 alpha**是携带版的一次次要更新，发布于2016年11月5日<ref></ref>，修复了[v0.16.0 alpha](携带版Alpha 0.16.0.md)中的一些漏洞与崩溃。

# 修复
拼写错误。
|16173|通过Xbox Live进行多人游戏时无法聊天。
|16491|创造模式物品栏里的剑的纹理错误。
|16497|可以在栅栏或墙上面放置红石组件方块。
|16609|火把放置时出现错误。
|16766|断开USB连接导致游戏崩溃。
|;0.16.0开发版本的漏洞
|17114|亮度大于12时，刷怪笼仍然可以生成敌对生物。
|17352|工具的耐久度不会下降。
|17454|漏斗矿车在激活铁轨上出现漏洞。
|17480|剪刀只能在满耐久度的情况下使用。
|;0.16.0的漏洞
|17613|为地图重命名时游戏崩溃。
|17669|被生物攻击的苦力怕不会爆炸。
|17695|使用iOS 9.3打开世界时游戏崩溃。
|17818|使用物品展示框时游戏崩溃。
}}
* *其他**
* 使用命令生成喷溅药水时游戏崩溃。
* 在存档路径里存在UTF-8字符时，玩家不能删除世界或者保存资源包。
* 物品栏槽位有时不会更新。
* 放置物品展示框时，Realm世界崩溃。
* 为地图重命名时游戏崩溃。
* 被雪傀儡攻击的苦力怕不会爆炸。
* 教育版里导出文件时，物品栏数据不会保存。
* 新建存档时游戏崩溃。
* 射箭时游戏崩溃。
* iOS版暂停游戏时游戏崩溃。
