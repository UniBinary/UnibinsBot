# 更改
# = 常规 =
* *[原主机版教程](原主机版教程.md)**
* 新的教程世界。

* *[高度](高度.md)**
* 高度限制由128格调整为256格。

* *[环境音效](环境音效.md)**
* 新的洞穴音效。

* *[选项](选项.md)**
* 在皮肤选择器菜单中加入收藏栏以存储最近使用的皮肤。

# = 方块 =
* *[楼梯](楼梯.md)**
* 有倒置和转角的变种。
* 可以倒置放置在方块底部。

* *[台阶](台阶.md)**
* 可以倒置放置在方块底部。

* *[发射器](发射器.md)**
* 可以发射船和矿车以放置了。

* *[梯子](梯子.md)**
* 合成能获得3个而非2个梯子。

* *[草](草.md)**
* 尝试在草上放置方块会替换掉草。

* *[熔岩](熔岩.md)**
* 有微弱的低沉而持续的声音，溅射出的大粒子可能会产生爆裂声。

* *[门](门.md)**
* 可以更好地由红石操控。

# = 物品 =
* *物品**
* 丢弃的物品是3D的了。

# = 生物 =
* *生物**
* 新的AI。
* 加入了罕见的掉落物。

* *[村民](村民.md)**
* 村庄里有房子时村民会繁殖。

* *[僵尸](僵尸.md)**
* 困难模式下僵尸可以破坏门。

* *[雪傀儡](雪傀儡.md)**
* 下界中，雪傀儡会如沙漠中般融化死亡。

# = 非生物实体 =
* *[船](船.md)**
* 一个世界中最多有40条船。

# = 世界生成 =
* *[废弃矿井](废弃矿井.md)**
* 穿过洞穴矿道时会生成木桥。

# 修复
* *修复了17个漏洞**
* 修复了本地玩家阴影不显示的漏洞。
* 修复了一些权限设置漏洞。
* 修复了云中的缝隙。
* 修复了第三人称视角水下滤镜被随机删除的漏洞。
* 修复了世界边缘的结构。
* 修复了摧毁装有附魔物品的运输矿车会移除附魔的漏洞。
* 修复了弓不适当的动画。
* 修复以使矿车以正确的速度行驶。
* 修复了一些内存泄漏。
* 修复了“可以打开容器”选项的漏洞。
* 修复了“可以建造和挖掘”选项的漏洞。
* 修复了关闭“TNT爆炸”选项TNT仍会爆炸的漏洞。
* 修复了玩家手上有骨头时狼不会歪头的漏洞。
* 修复了药水的状态效果粒子颜色以匹配药水颜色。
* 修复了门的漏洞。
* 修复了第一人称视角火焰边缘的漏洞。
* 修复了许多光照问题。
