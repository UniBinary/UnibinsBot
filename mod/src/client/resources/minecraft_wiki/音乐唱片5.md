# = 音乐 =

[noicon](File:Five.ogg.md)

Five是一首风格类似[11](音乐唱片11#音乐.md)的音乐。

中间夹杂着一段轻缓的音乐。其环境可能位于远古城市，因为曲中有深板岩、凝灰岩、紫水晶和监守者的音效。

音乐唱片5放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为15的信号。

# 你知道吗
* 此唱片中可以听到一些来自[Minecraft Dungeons](Minecraft Dungeons.md)的音效，包括[末影遣使](MCD:末影遣使.md)的叫声、[复仇末影之心](MCD:复仇末影之心.md)的音效和[末影人](MCD:末影人.md)的音效。
* * 此唱片中还可以听到其他一些音效，按出现顺序排列为：[打火石](打火石.md)点火，[蝙蝠](蝙蝠.md)，[凝灰岩](凝灰岩.md)，熔岩迸裂，[紫水晶簇](紫水晶簇.md)被破坏，[幽匿尖啸体](幽匿尖啸体.md)，[石头](石头.md)，[沙子](沙子.md)，幽匿尖啸体与[监守者](监守者.md)叠加，[幽匿感测体](幽匿感测体.md)惊动和监守者咆哮。
