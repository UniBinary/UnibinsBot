# 携带版0.10.0.b6

*页面ID: 28516* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.10.0 alpha build 6**是[v0.10.0 alpha](携带版0.10.0.md)的第6个测试版，发布于2014年11月5日，修复了一些漏洞。

# 更改
# = 常规 =
* *动画**
* 每个行走动画动作都被修改以使其略微变快。

* *渲染**
* 针对于云优化雾，雾开始的地方更远了并且遵从天空颜色。

# 修复
* *修复了9个漏洞**
* 区块有时不会被保存。
* 再次修复了安卓设备上出现黑屏的漏洞。
* 修复了服务端关闭世界时，已连接的客户端会崩溃的漏洞。
* 农作物在生长时不被保存生长进度。
* 废弃矿井和要塞生成空的箱子和刷怪笼。
* 客户端在多人联机世界下会重置出生点。
* 客户端世界里设置成和平模式不会使得敌对生物消失。
* 多人联机世界下为普通模式时，客户端设置成和平模式会自动恢复生命值。
* 沼泽水体出现错误的水雾。</onlyinclude>
