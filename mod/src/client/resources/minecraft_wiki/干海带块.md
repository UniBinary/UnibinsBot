# 干海带块

*页面ID: 33696* | *来源: Minecraft Wiki*

</ref>||Tom Stone Mojavatar.png}}

* *干海带块（Dried Kelp Block）**是一种主要用作[燃料](燃料.md)以及储存[干海带](干海带.md)的方块。

# 生成
干海带块不会生成在世界中。

# 获取
# = 合成 =

# 破坏
挖掘干海带块的合适工具是锄。

干海带块被破坏后会掉落自身。

# 用途

干海带块可用于储存[干海带](干海带.md)，以此来节约空间。

# = 合成材料 =

# = 燃料 =
干海带块可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料。一个干海带块可烧炼200.05秒<ref></ref>，即可烧炼20.005个物品。这约为煤炭和木炭的2.5倍。

# = 堆肥 =
干海带块有50%概率将[堆肥桶](堆肥桶.md)堆肥等级增加1。
