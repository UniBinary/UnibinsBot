# 圆石

*页面ID: 10047* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}
* *圆石（Cobblestone）**是一种常见的[方块](方块.md)，可以通过破坏[石头](石头.md)获得，纹理类似于表面粗糙、有裂缝的石头。

# 生成
# = 自然生成 =
圆石会在[地牢](地牢.md)、[丛林神庙](丛林神庙.md)、[掠夺者前哨站](掠夺者前哨站.md)和[村庄](村庄.md)中生成，此类生成的圆石有概率被替换为[苔石](苔石.md)。

圆石也会在[海底废墟](海底废墟.md)、[要塞](要塞.md)、[林地府邸](林地府邸.md)、[古迹废墟](古迹废墟.md)和[试炼密室](试炼密室.md)中生成[幼年僵尸](僵尸.md)的[试炼刷怪笼](试炼刷怪笼.md)旁生成。

# = 水和熔岩接触 =

当[水](水.md)与流动的[熔岩](熔岩.md)接触时，流动的熔岩会被圆石替代；如果熔岩从上面与水接触，则会生成[石头](石头.md)。

# 获取
# = 石头 =
没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，[石头](石头.md)被破坏后会掉落1个圆石。

# = 虫蚀圆石 =
被具有[精准采集](精准采集.md)的工具挖掘破坏时，[虫蚀圆石](虫蚀圆石.md)被破坏后会掉落1个圆石。

# 破坏
挖掘圆石的合适工具是镐。圆石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

圆石被破坏后会掉落自身。

# 用途
# = 蠹虫 =
[蠹虫](蠹虫.md)能进入并隐藏在圆石里，使其变成一个[虫蚀圆石](虫蚀圆石.md)。
