# Java版Combat Test 7

*页面ID: 85137* | *来源: Minecraft Wiki*

}}<onlyinclude>

* *Combat Test 7**是未来的战斗改版的一个秘密的实验性版本，发布于2020年8月13日。此版本是[Java版1.16.2](Java版1.16.2.md)的分支。

# 更改
# = 物品 =
* *[斧](斧.md)**
* 现在可以通过在铁砧上通过与书合并的方式把之前只能附在[剑](剑.md)上的魔咒附在斧上。

* *[药水](药水.md)**
* 现在一组可以堆叠到16瓶。

# = 游戏内容 =
* *[战斗](Tutorial:战斗.md)**
* 再次加入了“200%冷却时间”攻击（下称“蓄力攻击”）这一设定。<!--<ref group="注" name=attacks>[Jeb](Jeb.md)给出的理由："*Feedback from PvP players was that it added a tactical layer and options when fighting. Since the charged attacks were reintroduced, I had to redesign how the "quick misses" work. A miss will not count as a charged attack - you need to wait for the full duration of the weapon's original delay. Because of code organization, the penalty for auto-attacking is now specifically 1 tick, instead of 20% of the current weapon's delay. Note: Base reach is still 3, it has not been reverted to 2.5 as in v5.*"</ref>-->
* 再次加入了只有在拥有横扫之刃魔咒且进行蓄力攻击的情况下才会产生横扫攻击的特性。<!--<ref group="注" name=attacks />-->
* 再次加入了攻击指示器。
* 移除了玩家潜行时蓄力攻击的攻击距离加成。

* *[弓](弓.md)**
* 移除了拉弓时间过长会使精准度逐渐降低的特性。<!--<ref group="注">[Jeb](Jeb.md)给出的理由："*Every feature adds complexity and this didn't have enough payoff in either PvP or PvE. The feedback was also that the mechanic was inverted (accuracy should increase the longer you aim), but that way the game would get too slow*".</ref>-->

* *[饥饿](饥饿.md)**
* 移除了玩家在进食时受到攻击会使进食中断这一特性。<!--<ref group="注">[Jeb](Jeb.md)给出的理由："*I liked the interruption mechanic, but it was inconsistent. Particularly since honey bottles also are drinkable (with fairly high nutrition value)*".</ref>-->

* *[盾牌](盾牌.md)**
* 现在总是可以立即举起盾牌。
* 盾牌现在可以抵御100%的爆炸伤害。

# 修复
* 修复了下界合金质工具伤害值的问题，因为它们以前使用的是1.15的数值。
* 修复了持盾下蹲时的速度漏洞。</onlyinclude>
