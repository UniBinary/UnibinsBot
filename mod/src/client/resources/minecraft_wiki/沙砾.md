# 沙砾

* *沙砾（Gravel）**是一种生成在[主世界](主世界.md)和[下界](下界.md)的多种地形中、可以提供[燧石](燧石.md)的[方块](方块.md)。

# 生成
# = 自然生成 =
在[主世界](主世界.md)，沙砾会：
* 以[团簇](团簇.md)的形式生成于Y=320以下。
* * 单个团簇包含的沙砾数量为1至33，每区块会进行14次生成尝试。
* * 生成时可以取代的方块有[石头](石头.md)、[花岗岩](花岗岩.md)、[安山岩](安山岩.md)、[闪长岩](闪长岩.md)、[凝灰岩](凝灰岩.md)和[深板岩](深板岩.md)。
* 生成于[风袭沙砾丘陵](风袭沙砾丘陵.md)生物群系，覆盖其表面的大部分。
* 生成于[石岸](石岸.md)生物群系，以条带状地层生成。
* 生成于河流或湖泊的岸边或水底的[圆盘](圆盘.md)结构中。
* 生成于除[暖水海洋](暖水海洋.md)和[温水海洋](温水海洋.md)及其深海变种外的所有[海洋](海洋.md)类生物群系的水底。
* 作为寒带[海底废墟](海底废墟.md)和[古迹废墟](古迹废墟.md)的一部分生成。

在[下界](下界.md)，沙砾会：
* 以团簇的形式取代[下界岩](下界岩.md)生成于第5至41层除[玄武岩三角洲](玄武岩三角洲.md)外的任何生物群系。
* * 单个团簇包含的沙砾数量为1至160，每区块会进行2次生成尝试。
* 以1格厚的大片沙砾层的形式生成在[熔岩海](熔岩海.md)岸。

# = 可疑的沙砾 =
[可疑的沙砾](可疑的沙砾.md)被[刷子](刷子.md)刷扫后会转换为沙砾。

# 获取
# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家8-16个沙砾。

# 破坏
挖掘沙砾的合适工具是锹。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，沙砾被破坏后有10%的概率掉落1个[燧石](燧石.md)，若挖掘工具具有[时运](时运.md)I则掉落燧石的概率提升至约14.29%，时运II提升至25%，时运III提升至100%，如果没有掉落燧石则掉落自身。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，沙砾被破坏后会掉落自身。

# 用途
沙砾上方可以种植[竹子](竹子.md)。

# = 下落的方块 =

沙砾在下方没有不可替代的方块时会变为[下落的方块](下落的方块.md)。

沙砾在没有得到支撑时，会在方块下方产生[粒子](粒子.md)。

# 你知道吗
* 沙砾有时会掉落在一个洞穴里，看起来像是一个“死胡同”。因此，如果玩家在采矿时遇到沙砾而没有其他路线的话，挖掉沙砾可能会找到其他的洞穴。
