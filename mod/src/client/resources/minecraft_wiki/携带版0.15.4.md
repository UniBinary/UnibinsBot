# 携带版0.15.4

*页面ID: 23571* | *来源: Minecraft Wiki*

* *v0.15.4 alpha**是携带版的一次次要更新，在Android、iOS和FireOS上发布于2016年7月28日，在Windows Phone和Windows 10上发布于7月29日，修复了[Alpha 0.15.3](携带版Alpha 0.15.3.md)中的一些漏洞和崩溃。对除Android以外的版本而言，此版本包含了0.15.3的漏洞修复<ref></ref>。

# 新内容
# = 常规 =
* *[皮肤包](皮肤包.md)**
* 加入了[反派皮肤包](皮肤包#反派皮肤包（Villains Skin pack）.md)。

* *动画**
* 加入了登录Xbox Live账户的动画。

# 更改
# = 生物 =
* *常规**
* 修复在VR设备中骑乘动物时平视显示的移动。

# = 常规 =
* *[语言](语言.md)**
* 更多本地化修复。

* *[纹理](纹理.md)**
* 修复一些纹理问题。

* *性能**
* 部分调整Gear VR版本的性能与体验。
* 在Windows 10版中增加渲染距离。

# 修复

* *其他**
* 使用VR时，下雨或下雪的效果引起玩家不适。
* 使用VR时，拴绳在视觉上被断开。
* 使用VR时，拴绳使得游戏崩溃。
* 打开物品栏时游戏崩溃。
* 马的装备界面显示多余的标签名称。
* 生存模式下可以无限次使用骨粉和刷怪蛋。
* 在Windows 10版里按下B按钮弹出退出游戏的提示。
* 进入新创建的存档时游戏崩溃。
* 将渲染距离设置到最大时，快速探索新地形使得游戏崩溃。
* Windows 10版中不会正确显示带有UTF-8字符的存档名称。
* 创建Realms世界时游戏崩溃。
