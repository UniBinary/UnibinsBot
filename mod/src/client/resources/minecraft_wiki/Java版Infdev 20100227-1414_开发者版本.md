# Java版Infdev 20100227-1414/开发者版本

*页面ID: 90987* | *来源: Minecraft Wiki*

一些被标记为**Minecraft Indev**的Infdev开发版本于2010年2月26日至27日之间被编译，引入了后来在[Java版Infdev 20100227-1414](Java版Infdev 20100227-1414.md)中出现的部分特性。<ref></ref>

# 无限地形测试（2010年2月26日）
[缩略图](File:Infdev dev build.png.md)

# = 新内容 =
; [金苹果](金苹果.md)
* 一种[食物](食物.md)。
* 可以将玩家的生命值恢复至满格。

# = 更改 =
; 常规
* 移除了所有[世界界限](世界界限.md)，现在世界无限生成。
* * 处于早期测试阶段。
* * 测试性地生成以4×4位单位的重复地形。
* * 由于无限地形，游戏存在以下漏洞：
* ** 如果玩家距离世界中心走得太远，就会出现严重的[距离现象](距离现象/Java版.md)。
* ** 挖掘方块时会出现深度冲突。
* ** 位于负坐标的区块不会更新。
* ** 光照、实体和许多其他主要功能不再生效。

# = 你知道吗 =
* 该版本仍然被标记为"Minecraft Indev"。
* 由于浓密的雾，玩家往往看不到[云](云.md)。

# 无限地形测试（2010年2月27日）
[thumb](File:Indev Minecraft Indev dev 0227.png.md)

* *[Word of Notch帖子](https://web.archive.org/web/20100303072349/http://notch.tumblr.com/post/414322017/progress-update-on-infinite-maps)**
# = 更改 =
; 常规
* 更新了地形生成器，现在会生成比较常规的地形。
* 世界高度限制更改为256。
* 将雾的距离更改为128。
* * 这导致云层更加难以看到了。

# = 你知道吗 =
* 该版本仍然被标记为"Minecraft Indev"。
