# 脚手架

*页面ID: 36750* | *来源: Minecraft Wiki*

* *脚手架（Scaffolding）**是一种用[竹子](竹子.md)和[线](线.md)合成的方块，能够帮助玩家在建筑时到达高处，也能让玩家从高处安全降落而不受伤害。

# 生成
脚手架不会生成在世界中。

# 破坏
脚手架被挖掘时会立刻被破坏。

脚手架被破坏后会掉落自身。

# 用途
类似于[紫颂植株](紫颂植株.md)，当脚手架底部的方块被破坏时，所有需要被破坏方块支撑，且没有其他方块可提供支撑的脚手架方块都会一并破坏，这使得玩家更容易建造临时的结构。

[缩略图|仅通过点击底部脚手架方块的侧面而放置的一组脚手架](File:Scaffolding building.gif.md)

与其他方块一样，脚手架可以用键来放置，但其有独特的放置方式：

脚手架的轮廓箱不完整，玩家可以隔着脚手架与其他方块互动，但当玩家手持脚手架时，客户端中脚手架的轮廓箱将会变成一个完整方块，方便玩家点击脚手架的侧面。

* 当玩家的视角不在脚手架中时，对着脚手架的顶面放置会将其放置在与玩家面向相同的等高侧面上，对着脚手架的其余部位放置会将其放置在该位置上最高的脚手架的顶部，使玩家可以在地面向更高处建造脚手架结构。

* 当玩家的视角处于脚手架中时，脚手架的放置位置取决于玩家的俯角：如果玩家的俯角大于等于45度，脚手架会放置在与玩家面向相同的等高侧面上；其他情况下，脚手架会放置在该位置上最高的脚手架的顶部。

* 当玩家且视角不在脚手架中时，脚手架的放置规则与其他方块相同。

* 当玩家且视角处于脚手架中时，如果俯角大于45度，无法在原位置堆叠脚手架；如果仰角大于等于45度，脚手架会放置在该位置上最高的脚手架的顶部；其他情况下，脚手架会放置在与玩家面向相同的等高侧面上。

脚手架的轮廓箱不完整，玩家可以隔着脚手架与其他方块互动。与[Java版](Java版.md)不同，玩家与否与脚手架的放置位置无关。

* 当玩家对着任意脚手架底部（这包括了悬空的脚手架和多个脚手架中的一个）放置，或者对着支撑脚手架的地面放置，又或者对着与脚手架相邻的方块放置时，不论视角如何，都会将脚手架放置在该位置上最高的脚手架的顶部。其他情况下有通用的放置规则：

  * 当玩家的视角不在脚手架中时，脚手架的放置规则与其他方块相同。

  * 当玩家的视角处于脚手架中时，如果选中了脚手架的轮廓箱，脚手架会放置在该位置上最高的脚手架的顶部或相邻侧面。

[玩家](玩家.md)可以在脚手架中按住键向上移动或按住键向下移动。当生物位于脚手架顶部时，脚手架碰撞箱只有顶部，当生物位于脚手架内部即脚所处的方块，则脚手架的碰撞箱只有底部，当生物位于脚手架下时，脚手架会忽略所有碰撞箱，当玩家在脚手架中上下移动时会按上面所述影响所处脚手架的碰撞判定。依附在其他脚手架上的悬空脚手架的底部有碰撞判定。

脚手架被[活塞](活塞.md)推动时会被破坏。

[缩略图|脚手架最多只能向外延伸6格](File:ScaffoldingHowToPlayFile.png.md)

脚手架只能放置在有支撑的脚手架方块水平方向6格内，放置在6格以外的脚手架会下落。脚手架放在非脚手架方块侧面而下方没有支撑的方块时也会下落。

脚手架不能放置在熔岩中。如果脚手架旁边有熔岩或火，脚手架会被立即破坏。如果脚手架下落到熔岩或火中，它也会被立即破坏。如果脚手架下方的方块可生成生物，生物可以在脚手架方块的空间内生成。

脚手架可以放置在熔岩里，但一段时间后会被点燃。如果脚手架下方的方块可生成生物，体积较小的生物（如鸡）可以在脚手架方块的空间内生成。

脚手架可以重置[潜行](潜行.md)状态玩家的下落距离，即可用于减免摔落伤害。在脚手架中上下移动时，所有生物和玩家的速度都会减慢。

# = 下落的方块 =

在放置时没有得到支撑的脚手架会变为[下落的方块](下落的方块.md)。

# = 燃料 =
脚手架可以用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个脚手架可以[烧炼](烧炼.md)0.25个物品。
