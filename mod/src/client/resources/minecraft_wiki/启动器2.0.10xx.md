# 启动器2.0.10xx

*页面ID: 65092* | *来源: Minecraft Wiki*

* *2.0.1049**（[Windows](wzh:Microsoft Windows.md)）或**2.0.1051**（[macOS](wzh:macOS.md)）是一个[启动器](启动器.md)更新，发布于2018年5月8日，修复了一些漏洞。

# 更改
* 删除了“允许Mojang收集用户数据”的开关。
* 更改了对Minecraft版本的访问方式。

# 修复
*  - “忘记密码”页面不会在默认浏览器中打开。
*  - 皮肤页面中的“需要帮助吗？”选项无法打开。
