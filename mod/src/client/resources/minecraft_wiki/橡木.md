# 橡木

*页面ID: 22548* | *来源: Minecraft Wiki*

* *橡木（Oak Wood, Oak）**可以指：

# Minecraft
*  - 自然生成于橡树的方块，主要用于合成橡木木板。
* *  - 橡木原木的去皮变种。
*  - 六面皆为树皮材质的方块，可由橡木原木合成。
* *  - 橡木的去皮变种。
*  - 分解橡木原木或橡木塊得到的方块，可以合成诸多木制品。
*  - 由橡木原木和橡树树叶组成的地物。
*  - 自然生成于橡树的方块，能掉落橡树树苗。
*  - 能够种出橡树的方块。
*  - 未使用的方块，纹理与相同。

# Minecraft Dungeons
# = 物品 =
*  - 中的消耗品，可提高玩家防御力。

# Minecraft Legends
# = 生物 =
*  - 一种首领生物，玩家的盟友。

# = 建筑 =
*  - 用于生成橡树之首的建筑。
