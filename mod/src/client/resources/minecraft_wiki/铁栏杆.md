# 铁栏杆

*页面ID: 7220* | *来源: Minecraft Wiki*

* *铁栏杆（Iron Bars）**是一种与[玻璃板](玻璃板.md)性质类似的装饰性[方块](方块.md)。

# 生成
# = 自然生成 =
铁栏杆会自然生成于：
* [要塞](要塞.md)的空牢房和传送门房间；
* [林地府邸](林地府邸.md)的[大型监狱](林地府邸/结构/监狱房#大型监狱.md)；
* 除[针叶林](针叶林.md)类型外的[村庄](村庄.md)的铁匠铺；
* [雪屋](雪屋.md)的地下室；
* [主世界](主世界.md)的部分[废弃传送门](废弃传送门.md)；
* [末地](末地.md)主岛的两个较矮、较细的[黑曜石柱](黑曜石柱.md)上方（包围着[末地水晶](末地水晶.md)）；
* [古迹废墟](古迹废墟.md)的匠铺。

# = 事件生成 =
复活[末影龙](末影龙.md)时，包含铁栏杆的[黑曜石柱](黑曜石柱.md)在重新生成时会生成铁栏杆。

# 破坏
挖掘铁栏杆的合适工具是镐。铁栏杆需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

铁栏杆被破坏后会掉落自身。

# 用途
铁栏杆的默认纹理看上去是有缝隙的，但箭不能从中穿出，它们只会插在上面，虽然看上去就像悬浮在缝隙中。箭可以从铁栏杆上方或下方射入。<ref></ref>

铁栏杆不能被[末影龙](末影龙.md)破坏。

# = 放置 =
铁栏杆在周围没有连接支撑面完整的方块表面（[潜影盒](潜影盒.md)和、除外）、[墙](墙.md)、[玻璃板](玻璃板.md)、[染色玻璃板](染色玻璃板.md)、其他铁栏杆和[铜栏杆](铜栏杆.md)时，呈细长的柱状；否则，它们会根据周围方块的连接情况呈平面矩形、[text-top|class=pixel-image|link=](File:Curve.png.md)形、 [text-top|class=pixel-image|link=](File:T junction.png.md)形或[text-top|class=pixel-image|link=](File:Cross.png.md)形。

# = 治愈 =

铁栏杆可用于加速治愈[僵尸村民](僵尸村民.md)。

# 你知道吗
[thumb|240px|用2×2铁栏杆围成的缝隙](File:Underwater_iron_bars.png.md)
[thumb|240px|用铁栏杆和门能够制造让箭穿过的小空隙](File:Arrow Slits.png.md)
* 2×2铁栏杆围成的缝隙可以提供一个足够容纳玩家的空间，但雨、水等则无法穿过。[玻璃板](玻璃板.md)也有着同样的效果。
* 如果一个[告示牌](告示牌.md)或[画](画.md)被放置在铁栏杆上，它会显示为浮在空中。
* 铁栏杆也可以防止火焰蔓延。
* 尽管看起来很细，铁栏杆仍会保护它们下面的方块（在其他方向受到保护）不被[恶魂](恶魂.md)制造的爆炸波及。
* 铁栏杆和[床](床.md)都可以加速[僵尸村民](僵尸村民.md)的治愈，而这两种方块都常见于牢房。
* 由于铁栏杆的碰撞箱只有1格高，玩家可以直接跳过它们，而不像栅栏那样。
