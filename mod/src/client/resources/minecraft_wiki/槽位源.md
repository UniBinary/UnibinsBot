# 槽位源

*页面ID: 170389* | *来源: Minecraft Wiki*

* *槽位源（Slot Source）**允许玩家使用数据包指定任何[槽位](槽位.md)的位置。

# 定义格式
目前槽位源可以在[战利品表](战利品表.md)中使用。槽位源的格式如下：

<div class="treeview">
*  槽位源
* * 为}}：则表示单个槽位源，格式如下：}}
* * ：槽位源类型。
* * 其他字段与槽位源类型相关。
* * 为}}：则为多个槽位源组成的，行为同槽位源类型<code>group</code>的行为。}}
* * ：单个槽位源，递归定义。
</div>

# 槽位源类型
# = empty =
不选择任何槽位。

<div class="treeview">
*  槽位源
* * ：<code>empty</code>
</div>

# = group =
将多个槽位源合并为一个槽位源。此槽位源会提供一个槽位源列表，游戏会按列表顺序拼接合并槽位源。即使出现了相同的槽位，游戏也会照常拼接，而不是只出现一次。

例如，若列表内的两个槽位源的槽位分别是<code>[a, b]</code>和<code>[a, c]</code>，则拼接后的槽位源是<code>[a, b, a, c]</code>。

实际上，对于所有列表格式指定的多个槽位源，游戏都会拼接合并为一个槽位源。

<div class="treeview">
*  槽位源
* * ：<code>group</code>
* * ：槽位源列表。
* ** ：一个槽位源，递归定义。
</div>

# = slot_range =
从实体或方块实体的槽位范围里选择槽位。

<div class="treeview">
*  槽位源
* * ：<code>slot_range</code>
* * ：作为来源的实体或方块实体，从[战利品上下文](战利品上下文.md)获取。取值可以为<code>block_entity</code>、<code>this</code>、<code>attacking_entity</code>、<code>last_damage_player</code>、<code>direct_attacker</code>、<code>target_entity</code>或<code>interacting_entity</code>。
* * ：槽位范围，见。格式为<code>-{}-<*槽位类型*></code>或<code>-{}-<*槽位类型*>.<*槽位编号*></code>，例如<code>armor.chest</code>和<code>container.*</code>。
</div>

# = contents =
从容器组件中选择槽位。

游戏不会直接使用字段的槽位源获取的槽位，而是从这些槽位的物品中获取容器组件的槽位。

<div class="treeview">
*  槽位源
* * ：<code>contents</code>
* * ：要获取槽位的容器组件。取值可以为<code>bundle_contents</code>、<code>charged_projectiles</code>或<code>container</code>。
* * ：一个槽位源，递归定义。游戏将从这些槽位的物品的容器组件中获取槽位。
</div>

# = filtered =
对目标槽位进行过滤，排除所有测试失败的槽位。

<div class="treeview">
*  槽位源
* * ：<code>filtered</code>
* * ：测试每个槽位的物品谓词。如果某个槽位的物品测试失败，则丢弃此槽位。
* **
* * ：一个槽位源，递归定义。表示即将进行过滤的槽位。
</div>

# = limit_slots =
限制槽位的数量，生成的可选择结果最多包含这些数量个槽位。任何在限制数量之外的槽位都将被排除，按提供顺序排列。

例如，如果限制数量为3，则<code>[a, b, c, d]</code>将限制为<code>[a, b, c]</code>。

<div class="treeview">
*  槽位源
* * ：<code>limit_slots</code>
* * ：槽位的最大数量。
* * ：一个槽位源，递归定义。表示即将限制数量的槽位。
</div>

# 示例
以下为示例，这个槽位源会选择实体快捷栏和盔甲栏所有物品堆叠数量超过16的槽位。

<syntaxhighlight lang="json">{
    "type": "minecraft:filtered",
    "item_filter": {
        "count": {
            "min": 16
        }
    },
    "slot_source": [
        {
            "type": "minecraft:slot_range",
            "source": "this",
            "slots": "hotbar.*"
        },
        {
            "type": "minecraft:slot_range",
            "source": "this",
            "slots": "armor.*"
        }
    ]
}</syntaxhighlight>
