# 红砖

*页面ID: 7471* | *来源: Minecraft Wiki*

* *红砖（Brick）**是用来合成[红砖块](红砖块.md)与[陶器](陶器.md)的物品。

# 获取
# = 烧炼 =

# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)和[沙漠水井](沙漠水井.md)里的[可疑的方块](可疑的方块.md)有概率掉落红砖。

# = 饰纹陶罐 =
被不具有[精准采集](精准采集.md)的[剑](剑.md)、[锹](锹.md)、[镐](镐.md)、[斧](斧.md)、[锄](锄.md)或[三叉戟](三叉戟.md)挖掘破坏，或是被[箭](箭.md)、[三叉戟](三叉戟.md)、[鸡蛋](鸡蛋.md)、[雪球](雪球.md)、[小火球](小火球.md)、[恶魂火球](恶魂火球.md)、[末影龙火球](末影龙火球.md)、[凋灵之首](凋灵之首.md)、[风弹](风弹（实体）.md)、[烟花火箭](烟花火箭.md)或击毁时，含无纹样面的[饰纹陶罐](饰纹陶罐.md)会掉落对应数量的红砖。
