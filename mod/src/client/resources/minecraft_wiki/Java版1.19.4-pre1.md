# Java版1.19.4-pre1

*页面ID: 102473* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.19.4-pre1**是[Java版1.19.4](Java版1.19.4.md)的首个预发布版，发布于2023年2月22日<ref></ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[选项](选项.md)**
* 加入了“高对比度”选项，用于启用高对比度UI。

* *[Realms](Realms.md)**
* 加入了Realms通知系统，用于提醒玩家关于Realms的重要消息。

* *[资源包](资源包.md)**
* 加入了内置资源包“高对比度”，用于提高UI控件的对比度。
* * 该资源包可在选项中或资源包菜单中手动启用。
* * 目前仅适用于菜单。

* *[标签](Java版标签.md)**
* 加入了下列方块和物品标签：

* ** 此处定义的方块和物品可以被[烧炼](烧炼.md)成[玻璃](玻璃.md)。
* 加入了下列实体标签：

* ** 此处定义的实体不会受到摔落伤害。

* ** 此处定义的伤害类型会在造成伤害后跳过攻击冷却时间。

# 更改
# = 方块 =
* *[蛙明灯](蛙明灯.md)**
* 调小了放置和破坏蛙明灯的声音。

* *[幽匿感测体](幽匿感测体.md)**
* 将游戏事件的振动频率由14调整为2。

# = 物品 =
* *[药水](药水.md)**
* 移除了药水的附魔光效，以避免玩家混淆颜色相近的药水。

* *常规**
* 现在物品的附魔光效更明显。

# = 常规 =
* *[创建新的世界](创建新的世界.md)**
* 更改了标签页栏的样式。
* * 现在使用新的标签页设计，取代了之前的按钮式标签页。
* * 现在标签页在屏幕上居中对齐。
* * 现在标签页内容在屏幕顶端对齐。

* *[选项](选项.md)**
* 将“附魔光效闪烁强度”选项的默认值降低至75%。
* 减小了选项按钮长文本的滚动幅度。

* *[资源包](资源包.md)**
* 将资源包版本更新至。
* 附魔光效现在使用两个不同的纹理文件：。

* *[标签](Java版标签.md)**
* 将添加到伤害类型标签中。

# 更改（实验性）
# = 方块 =
* *[樱花树叶](樱花树叶.md)**
* 现在可用于吸引及繁殖[蜜蜂](蜜蜂.md)。

* *[粉红色花簇](粉红色花簇.md)**
* 现在可被瞬间破坏。
* 现在可用于吸引及繁殖蜜蜂。

* *[火把花](火把花.md)**
* 现在被视为小型[花](花.md)。
* * 可用于合成[谜之炖菜](谜之炖菜.md)，给予玩家[夜视](夜视.md)效果。
* * 可用于喂食[棕色哞菇](棕色哞菇.md)。
* * 可以被[末影人](末影人.md)拾起。
* * 可用于吸引及繁殖蜜蜂。
* * 蜜蜂会采集它的花粉。

* *[火把花植株](火把花植株.md)**
* 现在蜜蜂可为其授粉，使其生长一个阶段。

# = 物品 =
* *[刷子](刷子.md)**
* 更改了合成配方，现在需将[羽毛](羽毛.md)、[铜锭](铜锭.md)和[木棍](木棍.md)依次排成一列来合成。

* *[刷怪蛋](刷怪蛋.md)**
* 更改了[嗅探兽](嗅探兽.md)刷怪蛋的颜色，使其与[鲑鱼](鲑鱼.md)刷怪蛋有所区别。

* *[火把花种子](火把花种子.md)**
* 现在可用于吸引及喂食[鸡](鸡.md)和[鹦鹉](鹦鹉.md)。

# = 世界生成 =
* *[樱花树林](樱花树林.md)**
* 现在[猪](猪.md)会生成于此。
* [驴](驴.md)不再生成于此。

# = 游戏内容 =
* *[进度](进度.md)**
* 现在可通过种植火把花种子来达成进度“”。
* 将嗅探兽加入到了进度“”的达成要求当中。
* 现在可通过繁殖嗅探兽来达成进度“”。

* *[创造模式物品栏](创造模式物品栏.md)**
* 将火把花种子移动至其他种子旁边。

# = 常规 =
* *[配方书](配方书.md)**
* 现在可以在配方书中找到仅使用红砖合成的[饰纹陶罐](饰纹陶罐.md)。
