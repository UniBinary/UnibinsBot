* *堡垒遗迹（Bastion Remnant）**是[下界](下界.md)中一种少见的城堡状[结构](结构.md)。

堡垒遗迹能在除了以外的下界[生物群系](生物群系.md)中发现，但可能有部分结构会延伸进该生物群系。

为了生成这一结构，游戏首先将下界按照一定的方式分割成一些区域，每个区域中只会生成堡垒遗迹或[下界要塞](下界要塞.md)之间的一种。区域的大小为432×432（27×27个区块）；而区域的大小则是480×480（30×30个区块）。每个区域的南侧和东侧有宽度为64（4个区块）的区域，在这个区域中下界要塞与堡垒遗迹都无法生成。这就代表着只有368×368的区域能够生成这两种结构；该区域的大小则是416×416。两个结构不会在同一个区域中生成，尽管它们可能会在两个区域的边缘生成，从而产生重叠的可能。每区域中堡垒遗迹的生成概率为（60%）；堡垒遗迹的生成概率为（66.6%）。

在堡垒遗迹中生成的[猪灵](猪灵.md)、[猪灵蛮兵](猪灵蛮兵.md)和[疣猪兽](疣猪兽.md)既不会自然消失，也不会互相攻击。其中猪灵蛮兵只随堡垒遗迹的生成而生成，除非被杀死，或者将难度设置为和平，否则它们不会消失。与[末地城](末地城.md)中的[潜影贝](潜影贝.md)类似，猪灵蛮兵被杀死后不会再生成新的个体，但堡垒遗迹依旧会依据所处的生物群系生成其他生物。

# 结构
堡垒遗迹的结构有4种类型：桥、疣猪兽棚、居住区和藏宝室。一座堡垒遗迹只由4种结构中的一种构成。

猪灵、猪灵蛮兵和疣猪兽会在堡垒遗迹大量生成。

与下界要塞不同，如果堡垒遗迹位于熔岩海的上方，它不会生成一条直通地面的固体支柱，而是悬浮在海上。

堡垒遗迹是唯一能自然找到[音乐唱片](音乐唱片.md)*Pigstep*、[猪鼻旗帜图案](猪鼻旗帜图案.md)和[下界合金升级](下界合金升级.md)与[猪鼻盔甲纹饰](猪鼻盔甲纹饰.md)锻造模板的地方。此外，这里也能找到[钻石工具](钻石工具.md)（[钻石斧](钻石斧.md)和[钻石锄](钻石锄.md)除外）和[钻石盔甲](钻石盔甲.md)。

# = 结构目录 =
堡垒遗迹的结构文件存储在<samp>[client.jar](client.jar.md)/data/minecraft/structure/bastion</samp>或<samp>data/behavior_packs/vanilla/structures/bastion</samp>当中。

# = 桥 =
桥的较近侧是一面损毁的大型墙壁，形如一张猪灵的脸，其“嘴部”有[磨制玄武岩](磨制玄武岩.md)组成的“獠牙”，内部地面高度不一且两侧被[熔岩](熔岩.md)包围。而桥是从它的“嘴”延伸出去的，桥的较远侧有一座[金块](金块.md)雕塑，桥下方有立柱支撑。

# = 疣猪兽棚 =
疣猪兽棚由一个两边都受损的开放房间组成。

# = 居住区 =
居住区包含了中央庭院以及围绕中央庭院的墙壁，中央庭院中种有[下界疣](下界疣.md)，并包含1个战利品箱。

# = 藏宝室 =
这个结构由被扶壁支撑的大型墙组成，一座桥梁连接了扶壁与藏宝室本身。

藏宝室结构中包含多座悬挂在熔岩上方的桥。在藏宝室的底部，有一个[岩浆怪](岩浆怪.md)刷怪笼和一个中心战利品区域。中心战利品区域由金块组成，同时会生成1或2个箱子。

# 你知道吗
* 堡垒遗迹可能会和临近的下界要塞连通，此时凋灵骷髅和猪灵之间的敌对关系将导致一场永无休止的恶斗。
* 在[基岩版1.16.0.59](基岩版1.16.0.59.md)之前，基岩版的堡垒遗迹战利品表中包含光灵箭，但光灵箭在基岩版中并不存在。
* * 但这似乎不是因复制[Java版](Java版.md)的战利品表而出现的错误，因为当时这两个版本的战利品有很大的差别。
