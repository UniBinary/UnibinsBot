# Minecraft: Glide Mini Game (Original Soundtrack)

*页面ID: 144692* | *来源: Minecraft Wiki*

* **Minecraft: Glide Mini Game (Original Soundtrack)*（《Minecraft：滑翔小游戏（原声带）》）**是[Gareth Coker](Gareth Coker.md)为[原主机版](原主机版.md)[滑翔](小游戏#滑翔.md)小游戏创作的专辑。其作为更新的一部分于2017年5月29日发布到原主机版，而原声带发布于2020年12月22日。
