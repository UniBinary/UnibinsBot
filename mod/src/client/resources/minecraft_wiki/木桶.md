* *木桶（Barrel）**是一种用于储存物品的[方块](方块.md)。

# 生成
# = 自然生成 =
木桶会生成在[村庄](村庄.md)的渔夫小屋中以及[试炼密室](试炼密室.md)中。

# 破坏
挖掘木桶的合适工具是斧。

木桶被破坏后会掉落自身和内容物。

# 用途
木桶的放置方式类似于[活塞](活塞.md)，放置后其有桶盖的一面会朝向玩家。

# = 容器 =
每个木桶有27格的存储空间，与单个[箱子](箱子.md)相同。它们可以由[投掷器](投掷器.md)填充，也可以由[漏斗](漏斗.md)填充和清空。对着木桶按下即可打开木桶的容器界面。木桶在打开时，其桶盖面会变为打开的纹理。

不同于[箱子](箱子.md)，木桶不能合并，其使用也不会被阻挡。

[红石比较器](红石比较器.md)可以检测木桶存储物品的数量。

木桶界面的标题默认为“木桶”，可在放置前使用[铁砧](铁砧.md)重命名来进行更改，也可以通过使用命令修改木桶的<code>CustomName</code>标签进行更改。

木桶可以被<code>lock</code>标签上锁。若木桶的该标签不是空白的，那么这个木桶必须使用符合该标签表示的物品谓词的物品打开。

# = 燃料 =
木桶能被用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个木桶可以烧炼1.5个物品。

# = 更改村民职业 =
如果木桶没有被[村民](村民.md)认领，则附近的失业村民将有机会认领木桶并转变职业为[渔夫](渔夫.md)。

# = 猪灵 =
在非和平[难度](难度.md)中，成年[猪灵](猪灵.md)会与附近打开或破坏木桶的玩家敌对。

# 你知道吗
* 木桶与[箱子](箱子.md)比较每块木板的利用率提升了14.3%（3.375→3.857），同时木桶无需顶部预留空间即可进行交互，但缺点是木桶不能像箱子一样合并起来。
