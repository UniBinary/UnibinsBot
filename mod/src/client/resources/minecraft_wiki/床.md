* *床（Bed）**是一种可以用来在[主世界](主世界.md)睡觉并设置[个人出生点](个人出生点.md)的方块。

# 生成
品红色床、淡蓝色床、粉红色床、灰色床、淡灰色床、棕色床和黑色床不会生成在世界中。

# = 自然生成 =
; 雪屋
[雪屋](雪屋.md)里会自然生成一张红色床。
; 村庄
不同生物群系的[村庄](村庄.md)里会自然生成不同颜色的床。

; 试炼密室
所有颜色的床都可能生成在试炼密室中；只有蓝色床、绿色床、紫色床、红色床和白色床可能会生成在[试炼密室](试炼密室.md)中。

# 破坏
没有工具可以加速对床的挖掘。

床被破坏后会掉落自身。

# 用途
床占据2格空间。放置床需要从玩家面前算起两格的空间。放置床时，床尾将面向放置者。床只能放置在完整上表面的方块上。床不会因为下方没有方块而被移除。

床不能被[活塞](活塞.md)拉动，被活塞推动时会掉落。

玩家床的结果取决于所在的位置：
* 在[主世界](主世界.md)中使用床，床可以允许玩家睡觉和设置出生点。（，）
* 在[主世界](主世界.md)以外的维度中使用床，，使用床会导致床爆炸。（）

玩家能否使用床睡觉直接由[环境属性](环境属性.md)<code>gameplay/bed_rule</code>控制。

# = 睡觉 =

陷入睡眠时的动画}}

[240px|thumb|陷入睡眠时的动画（新UI）](File:Sleep Animation Bedrock 1.21.51.gif.md)
在主世界中，玩家可以对着床按下来睡觉；在其他维度这么做会导致床[爆炸](爆炸.md)。

在雷暴[天气](天气.md)或夜晚（晴天时|je}}或|be}}，即天空中有[星星](星星.md)的时间段；[降雨](降雨.md)时|je}}或|be}}）时使用床即可睡觉。在其余时间使用床，会显示“”或“”。玩家经过的睡眠时间后，进入第二天，见。

如果睡觉所需的条件都达成了（见），玩家会被安置在床上，玩家躺在床上的样子就好像玩家在“床单”上面那样。玩家如果在上床前有动量，玩家上床后仍然会朝着原来的方向移动一段距离，可能会从床上掉下来，如果掉下来之后离床太远，会被重新安置在床上。

开始睡觉后，玩家的视野会淡出至黑色，这个淡出过程持续5秒。

睡觉的动画会缓慢将玩家视角降低到床上。

在睡觉期间，玩家可以按、}}或点击“”按钮起床。睡觉时聊天窗口会一直拥有焦点。睡觉时若有足够多的玩家上床睡觉，则界面上会显示“”，否则会显示“”

只要玩家在床上睡觉的时间达到了5秒，就视为玩家进行过了睡觉，重置玩家的未睡觉时间统计，推迟[幻翼](幻翼.md)的生成，允许玩家在多人游戏中睡觉而不跳过夜晚。

如果一个玩家占用的床被摧毁（例如被其他玩家挖掘、或被爆炸破坏），该玩家会醒来。

如果玩家在睡觉时受到伤害，玩家会立刻醒来。

玩家主动起床或从床上醒来后会站在睡前所处的那一侧的床头边，面朝或。

# == 阻止睡觉的因素 ==
如果以床头为中心水平8格，垂直5格的范围内有敌对生物存在，玩家就不能睡觉。在这种情况下尝试睡觉会显示“”的消息。这些生物只要在范围内，即使无法到达床的位置，都会阻止睡觉。但在玩家已处于睡觉状态时，这些生物走进范围不会使玩家醒来。下面的表格展示了生物能否阻止玩家睡觉。

生物不会阻止[创造模式](创造模式.md)下的玩家睡觉。

玩家必须在床的任意方块或范围内才能睡觉。如果玩家能够点击床，但距离不足以入睡，会显示一条消息”}}或”}}。

玩家不能在被占用的床上睡觉，尝试睡觉会显示“”消息。

如果床的上方有可使生物[窒息](窒息.md)的方块，尝试睡觉会显示“”的错误消息。<ref></ref>

如果占用了床的生物是村民而非玩家，玩家也可以对着床的上表面未被村民碰撞箱覆盖的区域按直接上床，与此同时村民会醒来。

玩家不能在[着火](着火.md)、具有[中毒](中毒.md)、或[饥饿](饥饿.md)耗尽等状态下入睡，这是因为玩家会在这些情况下持续受到伤害。

[含水](含水.md)的床不能被使用，除非玩家或村民有[水下呼吸](水下呼吸（状态效果）.md)或[潮涌能量](潮涌能量.md)状态效果。

# == 度过夜晚 ==
如果世界中睡觉的玩家数量达到了度过夜晚的需求，5秒（100刻）后时间就会变为白天，所有玩家都会醒来。

如果关闭[游戏规则](游戏规则.md)，那么时间就不会被跳到白天，玩家会在夜里醒来。

睡觉会改变太阳升起的时间，如果在降雨或雷暴时睡觉则会使天气被重设为晴朗。

睡觉并不会加速与时间有关的过程，比如[掉落物品](物品（实体）.md)的消失、植物生长和[烧炼](烧炼.md)。

[游戏规则](游戏规则.md)控制了跳过夜晚所要求的入睡玩家百分比例。该值默认为100，即所有处于主世界的玩家都睡觉时才能跳过夜晚。如果值为0，一个玩家睡觉即可跳过夜晚；如果值大于100，则不能通过睡觉来跳过夜晚。

# == 幻翼 ==

如果玩家在内没有睡觉或[死亡](死亡.md)，幻翼会在玩家周围生成。距离上次睡觉或死亡时间越久生成概率越高。可以通过关闭游戏规则来禁止幻翼生成。

# == 猫 ==

当玩家睡觉的时候，驯服的[猫](猫.md)会走向它们的主人并在玩家的身上睡觉。当玩家醒来时，驯服的猫也会醒来。被驯服的猫有70%的概率在玩家从床上醒来后给予玩家[礼物](猫#礼物.md)，但只在玩家在夜晚睡觉时发生（如在白天的雷暴天气中入睡，则没有礼物）。没有坐下的猫会在水平4格半径方形水平范围内的当前Y轴下尝试跳到床的下半部分上，并且会立刻坐下，即使坐下的命令不是来自玩家。已入睡玩家不足以跳过夜晚的情况下，玩家躺在床上直到自然起床依然可以获得礼物。<ref></ref>

# = 设置出生点 =
在主世界中，玩家可以对着床按下来将出生点设置为该床的位置；在其他维度这么做会导致床[爆炸](爆炸.md)。

如果玩家能够在床上睡觉，那么这个互动也会使玩家睡觉。即使玩家不能睡觉，也可以将床设置为[出生点](生成#个人出生点.md)。

成功更改出生点后，聊天栏中将显示消息“”。多个玩家可以在同一张床上设置重生点。

只有当玩家重生时，游戏才会检查床的位置。这意味着床可以被破坏和更换，甚至调整方向，但只要有一张床存在于同一位置，玩家就可以在那里重生。如果玩家的床不在，或者床周围的区域不适合重生（见下文），则会显示一条消息：“”，同时玩家会在世界出生点重生。

在选择玩家重生的地点时，游戏会优先选择床头附近七个方块的西北（即X和Z坐标最小）的位置，其次是向南（+Z），再次是向东（+X）。若床头周围的七个位置都被阻挡，则会从剩下的三个与床脚相邻的位置当中选择。

重生点的位置取决于玩家进入床的一侧，初始选择为床头的左右相邻位置中与进入床同侧的位置；若该位置被方块占据，则从该位置开始，沿从床尾到床头的方向依次环绕检测可用位置以确定重生点；若与床同高度相邻10个位置均被方块占据，则优先选择床头所在位置，其次选择床尾所在位置。若这两个位置也被方块占据，则重生后会显示“你的床或已充能的重生锚不存在或已被阻挡”并在世界出生点重生。玩家重生时，在保证安全的前提下，会重生在下方方块上表面的中心位置，只有当该位置高于床1格时重生点会被阻挡。因此，重生点被阻挡主要取决于：该方块的碰撞箱高度至少为1格、上表面中心处碰撞箱高度大于等于1格、该方块会对玩家造成伤害（包括重生点下方）、重生点下方方块中心处碰撞箱高度低于1格、重生空间不足（即玩家在该空间内无法直立）。

* 例如：
* * 在重生点位置放置一个花盆，但其碰撞箱高度低于1格，故该玩家会重生在花盆上方中心处；
* * 在重生点位置的下方放置一个灵魂沙、土径或耕地，由于其碰撞箱高度低于1格，故此处重生点被阻挡；
* * 在重生点位置放置一个灵魂沙，由于其碰撞箱高度低于1格，故玩家会重生在灵魂沙上方中心处，但是如果在灵魂沙上方放置一层地毯或一个花盆，由于该位置上表面中心处高于床1格，故此处重生点被阻挡；
* * 在重生点位置放置一个蜘蛛网，由于其不具有碰撞箱，且不会对玩家造成伤害，故此处重生点不会被阻挡；
* * 在重生点位置放置仙人掌或在重生点的下方放置岩浆块，即使仙人掌碰撞箱高度低于1格、岩浆块上方为空气方块，由于会对玩家造成伤害，故此处重生点被阻挡；
* * 在重生点位置放置一个花盆，在花盆上方放置一个碰撞箱完整的方块（如石头），此时花盆与石头之间的纵向空间不足，故此处重生点被阻挡；
* * 需要注意的是，雪的碰撞箱高度比轮廓箱低<sup>1</sup>⁄<sub>8</sub>格，单层雪无碰撞箱，故只有当雪堆叠至1格+2层后才能阻挡重生点。

* 此外，以下方块属于特例：
* * 堆肥桶、炼药锅虽然中心处碰撞箱低于1格，但其仍然阻挡重生点，不会使玩家重生至堆肥桶或炼药锅中心处；
* * 活板门被放置在方块底部、向上开启或向下开启后，不会阻挡重生点；只有当活板门被放置在方块顶部且未被开启时会阻挡重生点；
* * 门无论是否开启均阻挡重生点；
* * 栅栏门开启时不阻挡重生点，关闭时阻挡重生点。
此外，若互动床设置重生点后将床的方向改变，则重生点的选择会根据原先床头所在位置依次选择合适的重生点，与改变方向后的床头位置无关，除非再次互动床设置重生点。

为了避免阻挡玩家在床边的重生位置，与床处于同一高度的方块必须是[空气](空气.md)或非固体方块（例如火把，但不可以是[玻璃](玻璃.md)），并且床所处的空间必须满足以下条件：空间正下方有一个固体方块，下方0-2格内有两个可供玩家站立的无碰撞箱方块。床的上方是否有方块并不重要。如果床被阻挡，则玩家重生后，其在该床边的出生点会被清除。也就是说，即使清理掉阻挡床周围出生点的方块，玩家下次也无法在床周围重生，除非其再次使用该床并设置重生点。

# = 爆炸 =
尝试在主世界以外的维度中床会导致其[爆炸](爆炸.md)。无论使用床的任何位置，爆炸总是发生在床头所在方块的中心位置。

床导致的爆炸的爆炸威力为5，并且可以生成[火](火.md)。

被床炸死的生物的[死亡消息](死亡消息.md)为“]}}”或“”。“[]”文本可以点击并跳转至。

# = 弹起 =
[摔落](摔落.md)在床上的玩家只会受到50％的掉落伤害，并会被弹起。弹起后的速率是弹起前速率的66％。

幼年村民在白天可能会在床上跳跃并弹起。

# = 住所 =
床用于在[村庄](村庄.md)中标记房屋数量。

# = 村民 =
[村民](村民.md)可以在床上睡觉，即使床不在主世界。

玩家可以使村民醒来并使用床。欲如此做，玩家需要首先唤醒村民（对着村民按），然后在村民重新躺下前使用床。对床按即可唤醒村民并使用这张床。虽然玩家使用床时村民会取消和床的绑定，玩家醒来后村民仍可以重新与此床绑定。

若村民成功入睡，其生命值会在其自然醒来时回满。

# = 治愈 =

床可用于加速治愈[僵尸村民](僵尸村民.md)。

# 你知道吗
<div style='float:right'></div>
* 如果玩家在睡觉时退出世界，重新进入该世界时，即使没有进入白天，玩家也将在床边醒来。
* 如果有东西在手里，玩家会略微从床中露出，脚也会从床的边缘伸出。
* 当玩家在[唱片机](唱片机.md)播放时睡觉，声音的方向不会根据玩家位置的改变而调整，直至他们起床。
* 在不同颜色的床被加入以前，使用6种不同类型的木头和16种不同颜色的羊毛合成床，共有3456种不同的方式来合成床。
* 当使用放置床时，只会放置床的一半，因为床是2格宽的。1格床可以当一整张床那样睡上去。
* 玩家躺在床上时无法看地图。
* 床拥有独特的2D物品纹理，然而这些纹理仍然使用着[多彩世界更新](多彩世界更新.md)前的配色方案，与床的实际颜色不匹配。<ref></ref>
* 若使用命令将床放入玩家的头盔槽，床会出现在玩家头顶，看起来像一顶冕旒。可在了解更多此类彩蛋。
* 粉红色床在[试炼密室](试炼密室.md)的交叉口生成的概率小于其他颜色的床。<ref></ref>
* 床合成配方中的所有材料都可以用作[燃料](燃料.md)，但床不能用作燃料。
