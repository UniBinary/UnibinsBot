# 游戏规则/players nether portal default delay

*页面ID: 127318* | *来源: Minecraft Wiki*

* *players_nether_portal_default_delay**是控制非[创造模式](创造模式.md)下[玩家](玩家.md)穿过[下界传送门](下界传送门.md)需要等待的[刻](刻.md)数的[游戏规则](游戏规则.md)。

# 行为
非创造模式下的玩家通过下界传送门前往其他[维度](维度.md)前，需要站在其中等待players_nether_portal_default_delay刻的时间。

players_nether_portal_default_delay的值不能低于0。
