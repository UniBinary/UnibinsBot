# 马铃薯维度

*页面ID: 143784* | *来源: Minecraft Wiki*

* *马铃薯维度（Potato/Potato Dimension/Poisonous Potato Dimension）**是地形均为浮空岛屿的维度。

# 进入
|自然生成的传送门底座}}
对着自然生成的传送门底座使用[毒马铃薯](毒马铃薯.md)会生成[马铃薯传送门](马铃薯传送门.md)，进入马铃薯传送门会进入马铃薯维度。

# 环境
[thumb|256px|太阳在马铃薯维度的样子](File:Potato sun.png.md)

马铃薯维度的地形均为浮空的岛屿。但是，生成这类浮岛的地形生成器与[末地](末地.md)的截然不同。马铃薯维度的建筑高度上限为256，下限为0。就像末地一样，如果不够小心，玩家很容易坠入虚空，但其他任何落入虚空的实体都不会受到虚空的伤害，而是无限期地持续坠落。玩家在该维度掉入虚空后会出现类似[终末之诗](终末之诗.md)的“马铃薯之诗”，同时播放音轨。马铃薯之诗储存在中的，其与终末之诗不同的是，玩家掉入虚空时就会播放，且没有次数限制。播放结束后，玩家会回到出生点附近，向上蹦起约100格后下落。此时玩家的靴子槽物品会被替换为[毒马铃薯鞋](毒马铃薯鞋.md)，因此玩家落地时生成大量[毒马铃薯糊](毒马铃薯糊.md)，而免受摔落伤害并获得[胶着](胶着.md)状态效果。

; 马铃薯之诗

昼夜更替、天气与主世界同步。天空、雨和水呈青绿色。[太阳](太阳.md)的纹理有绿斑，类似于毒马铃薯。玩家可以使用[床](床.md)，但尝试使用充能的[重生锚](重生锚.md)则会导致其爆炸。[猪灵](猪灵.md)、[猪灵蛮兵](猪灵蛮兵.md)和[疣猪兽](疣猪兽.md)不会僵尸化。下界传送门不能激活。[袭击](袭击.md)不能被触发。

# 生成
# = 生物群系 =
类似于[主世界](主世界.md)，马铃薯维度也被划分成多个生物群系，每个都有独特的地形、生物、结构和环境音效等等。

在马铃薯维度中一共有5种生物群系，它们有以下相同之处：
* 环境音效命名空间ID为“这里没有什么可看的，继续前进（Nothing to see here, move along）”。
* 空中会生成悬浮马铃薯构成的马铃薯云。
* 会生成[沉船](沉船.md)、[埋藏的宝藏](埋藏的宝藏.md)、[紫晶洞](紫晶洞.md)和[地牢](地牢.md)。

# = 地形特征 =
在主世界的所有类型的[树](树.md)和[巨型蘑菇](巨型蘑菇.md)，都可以在马铃薯维度中生成。[马铃薯树](马铃薯树.md)作为马铃薯维度中独特的树也在此生成。通常的[马铃薯](马铃薯.md)植物可以被常见的生成在任何生物群系（特别在田野生物群系）。例如可生长在皮草、腐烂的皮草、毒农田或重力植物上。大多数[花](花.md)也可以在马铃薯维度中产生。

[紫晶洞](紫晶洞.md)、[马铃薯晶洞](马铃薯晶洞.md)、[薯饼水井](薯饼水井.md)和[地牢](地牢.md)也可以在这生成。

除了正常的云，由[悬浮马铃薯](悬浮马铃薯.md)构成的马铃薯云生成在两座岛之间。
