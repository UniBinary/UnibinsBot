# 作物机制

*页面ID: 125916* | *来源: Minecraft Wiki*

* *作物**是一类依靠[随机刻](随机刻.md)生长、成熟后可以收获作物物品的植物。本页面介绍了不同作物的生长与收获机制。

# 作物生长
种植后，作物方块在收到随机刻时会判断周围环境和自身数据值，执行不同的运算，以进行不同的生长尝试。类型相似的作物有时会共用一套生长机制。在玩家放置或自然生成作物方块时，这些方块的数据值也有着不同的设置情况。

# = 耕地作物 =
[thumb|两种影响作物生长的布局与唯一不影响作物生长的布局示例](File:Planting Methods.png.md)
种植在耕地上的作物在游戏中使用同一套作物生长机制，该机制通过周围的耕地和作物分布计算生长速度。这类作物直接或间接地调用<code>CropBlock.getGrowthSpeed</code>方法。

每棵作物将会根据周围环境设置**生长速度**，按照下列方式计算：
# 生长速度的初始值为1。
# 若作物下方为湿润的[耕地](耕地.md)，生长速度+3；若为干燥的耕地，生长速度+1。
# 对耕地周围的8个方块，每存在一个湿润的耕地，生长速度+；若为干燥的耕地，生长速度+；若为其他方块，不作操作。
# * 也就是说，湿润的耕地可以加快作物生长；在作物周围开垦耕地也能加快作物生长。
# 将东、西、南、北称为正向，将东南、东北、西南、西北称为斜向，如果作物的斜向毗邻方块有至少一棵同种作物，或正向毗邻方块上的同种作物形成了至少一个直角，生长速度÷2。
# * 唯一不影响作物生长的布局是将作物排成一排，且每排间留出空隙。
# * 不同种的作物不影响判定。如果想将田地种满，可以交替种植两种作物，这样二者的生长速度均不会下降。

作物的生长由随机刻驱动。每次随机刻时，游戏会先判定作物方块的[亮度](亮度.md)等级；若亮度至少为9，作物有<math>\frac{1}{\left\lfloor1+25/g\right\rfloor}</math>的概率提升一级生长等级，其中<math>g</math>表示生长速度。

; 作物应用情况
[小麦](小麦.md)、[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)的最高生长等级为7，[瓶子草](瓶子草.md)的最高生长等级为4，完全遵循上述机制。[甜菜](甜菜.md)的最高生长等级为3，[火把花](火把花.md)的最高生长等级为2，但这两种作物每次随机刻仅有的概率执行上述机制。[西瓜茎](西瓜茎.md)和[南瓜茎](南瓜茎.md)的最高生长等级为7，在成熟前完全遵循上述机制，在成熟后会以相同的概率尝试在随机方向生成果实。

; 骨粉行为
对这些作物骨粉时，[小麦](小麦.md)、[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)、未成熟的[西瓜茎](西瓜茎.md)、[南瓜茎](南瓜茎.md)的生长等级随机增加2~5，[火把花](火把花.md)、[瓶子草](瓶子草.md)的生长等级固定增加1，[甜菜](甜菜.md)的生长等级以的概率增加1。若未成熟的[西瓜茎](西瓜茎.md)和[南瓜茎](南瓜茎.md)在催熟后达到最大生长等级，还会额外执行一次果实生长尝试。
如果使用骨粉把生长等级为0的胡萝卜、土豆、小麦完全催熟，有37.5％概率使用2个骨粉，56.25％概率使用3个骨粉，6.25％概率使用4个骨粉。

; 放置行为
耕地作物在被放置时生长等级均为0。

# = 多层作物 =
* *部分**可以单向生长若干格的作物在游戏中使用同一套作物生长机制。这类作物在生长方向有一个**前端方块**；在作物任意一处使用骨粉均会转化为对前端方块使用骨粉，但只有前端方块上的随机刻会执行生长尝试。这类作物继承<code>GrowingPlantHeadBlock</code>抽象类。需要注意的是，尽管生长方式形似，[甘蔗](甘蔗.md)、[仙人掌](仙人掌.md)、[竹子](竹子.md)**并不符合**该机制。

前端方块拥有0~25的**生长度**。此外，每种作物有着固定的**生长概率**<math>p</math>。如生长度已达到25，将不会继续生长；否则，随机刻时，前端方块将以<math>p</math>的概率进行生长尝试，即试图向生长方向延伸一格，如成功则将新的前端方块的生长度提升1。

; 作物应用情况
[海带](海带.md)的生长概率为0.14，[垂泪藤](垂泪藤.md)、[缠怨藤](缠怨藤.md)和[洞穴藤蔓](洞穴藤蔓.md)的生长概率为0.10，这些作物均符合上述生长机制。[洞穴藤蔓](洞穴藤蔓.md)每次成功生长时，新的前端方块有0.11的概率结有[发光浆果](发光浆果.md)。

; 骨粉行为
使用骨粉催熟时，游戏会先确定本次将要生长的格数<!--override getBlocksToGrowWhenBonemealed-->，然后试图执行这么多次生长。每次生长都会增加生长度；如已达到25，游戏将会把后续生成的作物的生长度限制在25。

海带、洞穴藤蔓的催熟格数为1。

垂泪藤、缠怨藤的催熟格数由一个循环计算，第<math>i</math>次循环有<math>0.826^{i-1}</math>的概率将催熟格数+1并进入下一次循环。按照该规则，催熟格数的分布如下：

; 放置行为
多层作物在放置和自然生成时，其生长度会设置为随机数值。由玩家放置的作物的随机值。作为[地物](地物.md)自然生成时，[海带](海带.md)的生长度为20~23，[垂泪藤](垂泪藤.md)和[缠怨藤](缠怨藤.md)的生长度为17~25，[洞穴藤蔓](洞穴藤蔓.md)的生长度为23~25。自然生成的洞穴藤蔓有的概率生成发光浆果。

# = 简单概率生长 =
[可可豆](可可豆.md)、[下界疣](下界疣.md)、[甜浆果丛](甜浆果丛.md)使用的生长机制较为简单，没有耕地作物的周遭条件牵制与多层作物的随机生长度。每次随机刻时，这些作物有固定的概率进行生长尝试，直到达到最大生长等级为止。

; 作物应用情况
[可可豆](可可豆.md)、[甜浆果丛](甜浆果丛.md)的生长概率为0.2，[下界疣](下界疣.md)的生长概率为0.1，其中甜浆果丛的生长还需要其上方方块的[亮度](亮度.md)等级至少为9。可可豆的最高生长等级为2，甜浆果丛、下界疣的最高生长等级为3。

; 骨粉行为
使用骨粉催熟时，[可可豆](可可豆.md)、[甜浆果丛](甜浆果丛.md)的生长等级+1。[下界疣](下界疣.md)不能被骨粉催熟。

; 放置行为
上述作物在放置时生长等级均为0。

# = 累积刻生长 =
[甘蔗](甘蔗.md)和[仙人掌](仙人掌.md)使用完全相同的生长机制，该机制在累计收到若干次随机刻后执行生长尝试。

作物的每个方块都有<code>age</code>属性记录**随机刻次数**，但只有最高一格方块才会执行随机刻。每次随机刻时，对最高方块，如<code>age</code>未达固定值，则将其+1；否则，如果作物未达3格高，将在其上方生成新的作物方块，并将新方块与原方块的<code>age</code>属性设置为0。

; 作物应用情况
[甘蔗](甘蔗.md)、[仙人掌](仙人掌.md)累计收到16个随机刻时进行一次生长尝试。

当仙人掌的最高方块<code>age</code>达到8时，在下一次随机刻时，如上方一格处水平方向上无相邻[固体方块](固体方块.md)，其将有概率尝试在上方生成[仙人掌花](仙人掌花.md)。如所在仙人掌柱的高度不超过2，上述尝试的概率为10%，否则为25%。

; 放置行为
上述作物在放置和自然生成时<code>age</code>均为0。由于生长机制，同一棵作物中非最高格方块的<code>age</code>也为0。

# = 紫颂花 =
[紫颂花](紫颂花.md)使用特殊的生长机制，在生长时随机分叉。

紫颂花将会记录其**分叉次数**，范围为0-5。次数达到5的紫颂花将不再生长。其他紫颂花方块会在随机刻时执行生长尝试，具体执行情况与该方块在植株中的相对位置有关。

下表列出了紫颂花下方的若干方块与各参量的关系。其中的方块图标分别表示紫颂花、紫颂植株、末地石、空气。

每次生长尝试中，紫颂花首先按上表中的概率尝试向上生长。如目标方块及其上方和水平相邻方块均为空气，则生长成功，新的紫颂花的分叉次数不变。否则，向上生长失败。

若向上生长失败，或未执行向上生长尝试，当分叉次数不超过3时，紫颂花将尝试分叉。

分叉过程会执行若干次分叉尝试。每次分叉尝试会随机选择一个水平方向尝试生长；如目标方块及其下方及其他水平方向均为空气，则生长成功，新的紫颂花的分叉次数+1。

分叉尝试次数从0-3中等概率选取；然而，紫颂花会根据相对位置在此基础上选择性地增加一次尝试，也就是等概率执行1~4次尝试。是否增加尝试的具体情况也在前表中列出。

如所有生长尝试均失败，则该紫颂花的生长失败，其分叉次数将被置为5，以终止生长。

; 放置行为
由玩家放置的紫颂花的分叉次数为0。作为地物自然生成时，紫颂花的分叉次数为5，即不再生长。

# = 竹子 =
与其他多层作物不同，[竹子](竹子.md)使用了特殊的生长机制，以引入随机的最大生长高度。竹子的各个方块均可以使用骨粉催熟，但只有最高方块才运行随机刻。

竹子将会记录其**是否终止生长**。对停止生长或高度达到16格的竹子，随机刻将不起作用。否则，若竹子所在方块及上方一格的亮度等级至少为9，竹子将有的概率生长一格。如果生长前竹子的高度达到11格，新生长出的竹子将有的概率终止生长，在将要达到16格时也会强制终止生长。

; 骨粉行为

玩家放置的竹笋没有特殊属性。作为地物自然生成时，若竹子的高度达到4格，其最高方块将终止生长，否则为未终止生长。

# 作物收获
对大多数作物而言，收获指的是破坏作物方块，并收集其掉落物。然而，对于甜浆果丛等作物，玩家可以按下键以收集作物，而无需破坏方块。

作物的收成由相应方块的战利品表定义。对于部分方块，采集工具附有的[魔咒](魔咒.md)，如[时运](时运.md)和[精准采集](精准采集.md)，可以影响掉落物的种类和数量。

# = 自身掉落 =
这类作物方块在收获时固定掉落单个自身。这通常适用于多层作物。
; 作物应用情况
[海带](海带.md)、[竹子](竹子.md)、[甘蔗](甘蔗.md)、[仙人掌](仙人掌.md)、[南瓜](南瓜.md)会固定掉落自身。部分作物在特定条件下才会固定掉落自身，包括使用附有精准采集的工具采集[西瓜](西瓜.md)，使用剪刀或附有精准采集的工具采集[垂泪藤](垂泪藤.md)、[缠怨藤](缠怨藤.md)，以及由玩家采集[紫颂花](紫颂花.md)（或紫颂花被弹射物破坏）。

# = 固定收成 =
这类作物根据生长等级固定地掉落若干作物物品。

; 作物应用情况
[火把花](火把花.md)和[瓶子草](瓶子草.md)在成熟时固定掉落一个相应作物，否则固定掉落一个相应的种子。结有浆果的[洞穴藤蔓](洞穴藤蔓.md)固定掉落一个[发光浆果](发光浆果.md)，但不会掉落自身。[可可豆](可可豆.md)在成熟时固定掉落3个可可豆，否则掉落一个可可豆。

# = 耕地收获 =

耕地作物根据其生长等级按二项分布或均匀分布掉落成熟的作物或种子。然而，由于无法回收种子，两种古代作物不属于这类作物。

未成熟时，作物固定掉落一份种子。成熟时，作物固定掉落一份成熟作物物品；此外，还会按照二项分布<math>B(n+l,p)</math>增添若干份种子，其中<math>l</math>为收获用工具的时运魔咒等级，<math>n</math>与<math>p</math>为作物固有的参量。

; 作物应用情况
[甜菜](甜菜.md)、[小麦](小麦.md)完全适用上述机制，<math>n=3</math>、<math>p=</math>}}或}}。[西瓜茎](西瓜茎.md)和[南瓜茎](南瓜茎.md)以<math>n=3</math>、<math>p=</math>固定掉落若干种子，不受时运影响，其中<math>m</math>为生长等级。

[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)的收获机制与甜菜与小麦类似，但掉落的“种子”被替换为作物自身。这些作物会先均匀掉落0~<math>l+1</math>个作物，再按照<math>B\left(n+l,\frac{8}{15}\right)</math>掉落作物，其中l为时运等级。
