* *刷怪蛋（Spawn Egg）**是一种用于直接生成[生物](生物.md)的物品。

# 获取

刷怪蛋无法在未开启[作弊](作弊.md)的[生存模式](生存模式.md)的世界中获取。使用[创造模式](创造模式.md)或启用[作弊](作弊.md)时，除末影龙刷怪蛋和凋灵刷怪蛋以外的刷怪蛋可以通过[创造模式物品栏](创造模式物品栏.md)获取，所有刷怪蛋均可以通过[创造模式](创造模式.md)中对<ref></ref>有着对应刷怪蛋的[生物](生物.md)使用或[命令](命令.md)等方式获取。

# 用途
对一个方块的任意一面刷怪蛋可以生成一个相应的生物。若刷怪蛋被用在方块的上表面，生物生成时脚会直接接触地面，并且会播放对应生物的[环境音效](环境音效.md)。在[生存模式](生存模式.md)下，使用刷怪蛋会将其消耗，但在创造模式下不会。刷怪蛋生成的生物具有随机朝向。玩家使用刷怪蛋生成的生物总是朝向该玩家。

用刷怪蛋在和平[难度](难度.md)下生成除以下生物外的[敌对生物](敌对生物.md)时，生物不会生成；在生存模式下使用会消耗刷怪蛋。
* [末影龙](末影龙.md)
* [疣猪兽](疣猪兽.md)
* [猪灵](猪灵.md)
* [潜影贝](潜影贝.md)

刷怪蛋在纹理上有三种大小，以表示生物的体积。水生生物对应的刷怪蛋纹理下部有水渍。

# = 发射器 =
用[发射器](发射器.md)发射刷怪蛋会直接在发射器前生成生物。在[和平](和平.md)难度下，尝试发射无法存在于和平难度的生物时会或。发射器使用刷怪蛋生成的生物具有随机朝向。发射器使用刷怪蛋生成的生物总是朝向南方。

# = 幼年生物 =
对于存在幼年形态的生物，对着该种生物其刷怪蛋会生成该种生物的幼年形态。

# = 刷怪笼和试炼刷怪笼 =
对着[刷怪笼](刷怪笼.md)或[试炼刷怪笼](试炼刷怪笼.md)刷怪蛋，会改变它们所生成的生物类型，但不会写入刷怪蛋中生物的附加数据。

若游戏规则为<code>false</code>，会提示玩家“”，而不会改变它们所生成的生物类型。

# = 重命名 =

刷怪蛋可以用[铁砧](铁砧.md)重命名，刷怪蛋的名字会附加到生成的生物的[实体数据](实体数据.md)。它们的名字仅能在4格以内被指着时才能看见。当生物杀死玩家时它的名字也会出现在[死亡消息](死亡消息.md)中。
* 如果将[兔子](兔子.md)刷怪蛋重命名为“Toast”，那么使用后会生成一只特殊纹理的兔子。
* 如果将任意刷怪蛋重命名为“Dinnerbone”或“Grumm”会在使用后生成倒立的生物。
* 如果将[绵羊](绵羊.md)刷怪蛋重命名为“jeb_”，那么生成的绵羊会一直变色（但不影响取得羊毛时的颜色）。
* 如果将[卫道士](卫道士.md)刷怪蛋重命名为“Johnny”，则生成的卫道士会攻击除[灾厄村民](灾厄村民.md)、[恶魂](恶魂.md)、</ref>、幼年[村民](村民.md)<ref></ref><ref></ref>|JE}}和外的一切生物。

# = 安全保护 =

[下落的方块](下落的方块.md)、[命令方块矿车](命令方块矿车.md)和[刷怪笼矿车](刷怪笼矿车.md)属于“仅管理员可设置数据”的实体。

组件中的实体类型属于以上实体的刷怪蛋会在[权限等级](权限等级.md)大于等于2的玩家的物品[提示框](提示框.md)中显示警告信息。

无论刷怪蛋最终会生成哪种实体，非管理员玩家或发射器使用刷怪蛋生成的实体都不会加载组件中的自定义实体数据。

刷怪蛋依靠<code>entity_data</code>组件生成实体，实体类型由决定，如果该组件不存在则不会生成任何实体。

例如使用<code>/give <玩家名> creeper_spawn_egg[entity_data = {id:"minecraft:iron_golem"}]</code>会得到一个[苦力怕](苦力怕.md)的刷怪蛋，但生成的实体却是[铁傀儡](铁傀儡.md)。

# 你知道吗
* 在不同的运行平台上，刷怪蛋的数据值有差异，但ID相同。
* [右|75px|class=pixel-image](File:Egg mask.png.md)在[基岩版1.21.70](基岩版1.21.70.md)前，[村庄与掠夺](村庄与掠夺.md)以及后续更新加入的生物（例如掠夺者、蜜蜂和劫掠兽）的刷怪蛋是通过对这一纹理自动染色得到的。<ref name="mask"></ref>且曾在物品栏中移动这三种刷怪蛋的瞬间，染色会失效，从而展示原始的mask纹理。<ref></ref>
* * 基岩版行为包自定义实体亦可通过提供不含alpha数据的16进制颜色码来应用染色后的。<ref name="mask"/>
