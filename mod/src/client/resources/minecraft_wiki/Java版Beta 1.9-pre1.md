# Java版Beta 1.9-pre1

*页面ID: 32277* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.9-pre1**是[Java版1.0.0](Java版1.0.0.md)的首个预发布版，发布于2011年9月22日，加入了[下界要塞](下界要塞.md)、[蘑菇岛](蘑菇岛.md)生物群系、[睡莲](睡莲.md)、[村民](村民.md)、[烈焰人](烈焰人.md)和[岩浆怪](岩浆怪.md)。

# 新内容
# = 方块 =
* *[菌丝体](菌丝体.md)**
* 生成于[蘑菇岛](蘑菇岛.md)生物群系。

* *[](下界砖块.md)**
* 构成[下界要塞](下界要塞.md)的方块。

* *[下界砖楼梯](下界砖楼梯.md)**
* [下界砖块](下界砖块.md)的楼梯变种。
* 自然生成于[下界要塞](下界要塞.md)中。

* *[下界砖栅栏](下界砖栅栏.md)**
* 由[下界砖](下界砖.md)和[下界砖块](下界砖块.md)合成的栅栏。
* 构成[下界要塞](下界要塞.md)的方块。

* *[下界疣](下界疣.md)**
* 自然生长在[下界要塞](下界要塞.md)中。

* *[睡莲](睡莲.md)**
* 生成于[沼泽](沼泽.md)生物群系中。

# = 物品 =
* *[烈焰棒](烈焰棒.md)**
* 由[烈焰人](烈焰人.md)掉落。
* *[恶魂之泪](恶魂之泪.md)**
* 由[恶魂](恶魂.md)掉落。
* *[金粒](金粒.md)**
* 由[僵尸猪人](僵尸猪人.md)掉落。
* 可合成[金锭](金锭.md)。

* *[下界疣](下界疣.md)**
* 此时还没有其他用途。
* 自然生成于[下界要塞](下界要塞.md)。

# = 生物 =
* *[哞菇](哞菇.md)**
* 生成于[蘑菇岛](蘑菇岛.md)生物群系中。
* 对其使用[碗](碗.md)可以获得[蘑菇煲](蘑菇煲.md)。

* *[村民](村民.md)**
* 村民拥有和[猪](猪.md)相同的[AI](AI.md)，并在多人游戏中在其头上显示为“TESTIFICATE（测试版生物）”。

* *[雪傀儡](雪傀儡.md)**
* 可以用两个[雪块](雪块.md)和一个[南瓜](南瓜.md)生成。
* 在炎热的[生物群系](生物群系.md)会持续受到伤害。
* 会在走过的完整方块上留下[雪](雪.md)。
* 对[玩家](玩家.md)保持被动，但会对敌对生物投掷[雪球](雪球.md)。

* *[岩浆怪](岩浆怪.md)**
* 敌对型下界生物。
* 行为类似[史莱姆](史莱姆.md)，但是免疫火焰[伤害](伤害.md)。

* *[烈焰人](烈焰人.md)**
* 敌对型下界生物。
* 能够飞行，会对玩家发射[火球](火球.md)进行攻击。
* 免疫火焰[伤害](伤害.md)。
* 会受到[水](水.md)和[雪球](雪球.md)的伤害。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* 加入了蘑菇岛生物群系。

* *[下界要塞](下界要塞.md)**
* 生成于下界。

# 更改
# = 物品 =
* *[箭](箭.md)**
* 击中生物时，不再在视觉上插在它们身上，箭对玩家来说依然可见。

* *[盔甲](盔甲.md)**
* 护甲值不再受到耐久影响。
* 不再抵御摔落伤害。

# = 生物 =
* *[僵尸猪灵](僵尸猪灵.md)**
* 僵尸猪灵的掉落物由[熟猪排](熟猪排.md)改为[腐肉](腐肉.md)。

# = 常规 =
* *调试特性**
* 跳跃会增加[经验值](经验值.md)。</onlyinclude>
