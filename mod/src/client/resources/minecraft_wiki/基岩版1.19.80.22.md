# 基岩版1.19.80.22

*页面ID: 103038* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.19.80.22**（ChromeOS/Android）、**Preview 1.19.80.22**（Xbox/Windows/iOS/iPadOS）是[基岩版1.19.80](基岩版1.19.80.md)的第3个测试版，发布于2023年3月22日<ref></ref><ref></ref>，在[实验性玩法](实验性玩法.md)中加入了[紫水晶块](紫水晶块.md)的共振功能、[校频幽匿感测体](校频幽匿感测体.md)、5种新的[锻造模板](锻造模板.md)、[古迹废墟](古迹废墟.md)和新的[陶片](陶片.md)，并修复了一些漏洞。

# 更改
# = 物品 =
* *[药水](药水.md)**
* 暂时回退了上个版本对药水粒子颜色和药水在[炼药锅](炼药锅.md)中的颜色做出的更改。

# = 常规 =
* *[市场](市场.md)**
* 加入了收藏夹功能。
* * 用于存储玩家想要购买的市场内容。

* *触摸控制**
* 重新启用了新的物品拆分UI。

# = 技术性 =
* *基岩版编辑器**
* 修复了当分辨率或窗口大小更新时，用户界面无法正确缩放的问题。
* 禁用了物品掉落，以使撤销/恢复和剪切/复制/粘贴功能可以正常使用。
* 修复了从十字准星模式进入工具模式后视图会使用第三人称的激活相机的漏洞。
* 修复了十字准星模式下使用下界或末地传送门时相机控制无法使用的问题。
* 移除了方块选择器中的旧版切石机和下界反应核。

* *图形**
* 更改了测试版和预览版中的调试HUD文本，现在在RTX内容播放时才会将添加到渲染信息中。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“下一个主要更新”和“测试版 API”子选项后才可使用。

# = 方块 =
* *[校频幽匿感测体](校频幽匿感测体.md)**
* 幽匿感测体的新变种，无法自然生成。
* 可以使用1个幽匿感测体与3个[紫水晶碎片](紫水晶碎片.md)合成。
* 有一面可以接收[红石信号](红石信号.md)，使其只能检测到频率与该红石信号强度相等数值的振动。

* *[紫水晶块](紫水晶块.md)**
* 现在放置在幽匿感测体旁时具有共振功能。
* * 当幽匿感测体接收到振动时，紫水晶块会在其位置发送一个频率相同的振动。
* * 可以在不重新创造振动源的情况下远程传递振动。

* *[樱花树叶](樱花树叶.md)**
* 更新了花瓣粒子。

* *[粉红色花簇](粉红色花簇.md)**
* 现在将粉红色花簇放置在同一格内时会发出音效。（）
* 音效现在属于“玩家”分类，而不是“方块”分类。（）

* *[告示牌](告示牌.md)**
* 现在在放置后可以通过与其交互来重新编辑文字。
* 现在告示牌的两面可以分别显示独立的文字和文字颜色。
* * 在首次放置时会默认编辑正面。
* * 编辑反面时需要走到告示牌的后方并于反面交互。
* 现在可以使用[蜜脾](蜜脾.md)涂蜡，涂蜡后的告示牌无法再进行编辑。

* *[可疑的方块](可疑的方块.md)**
* 现在[海底废墟](海底废墟.md)中的[可疑的沙子](可疑的沙子.md)和[可疑的沙砾](可疑的沙砾.md)拥有独立的战利品表。
* 现在其中的物品会在被刷扫时正确显示。（）
* 现在会在古迹废墟中生成。

# = 物品 =
* *[陶片](陶片.md)**
* 加入了垂钓、利刃、佳酿、烈焰、危机、探险、挚友、爱心、心碎、狼嚎、采矿、悲恸、富饶、麦捆、树荫和嗅探16种变种。
* * 除采矿<ref></ref>变种外的陶片可以在以下5个考古地点中找到：[沙漠水井](沙漠水井.md)、[沙漠神殿](沙漠神殿.md)、热带[海底废墟](海底废墟.md)、寒带海底废墟、古迹废墟。
* 更改了举臂、珍宝和头颅纹样陶片的纹理以匹配。

* *[锻造模板](锻造模板.md)**
* 加入了向导、牧民、塑造、雇主和幽静五种盔甲纹饰锻造模板。
* * 幽静盔甲纹饰锻造模板可在[远古城市](远古城市.md)中找到，其余可在[古迹废墟](古迹废墟.md)中的可疑的方块中生成。
* 更改了沙丘盔甲纹饰锻造模板的物品纹理和实际应用后的盔甲纹理，其盔甲纹理以及物品纹理中的图标被哨兵盔甲纹饰锻造模板使用。
* 原有的哨兵盔甲纹饰锻造模板的盔甲纹理和物品纹理中的图标现在被塑造盔甲纹饰锻造模板使用。

# = 世界生成 =
* *[沙漠水井](沙漠水井.md)**
* 现在底部会生成沙子，而不是砂岩。
* 可疑的沙子的生成数量由1增加至2。

* *[古迹废墟](古迹废墟.md)**
* 一种被掩埋的陶瓦建筑群[结构](结构.md)。
* 自然生成于[丛林](丛林.md)、[针叶林](针叶林.md)、[积雪针叶林](积雪针叶林.md)、[原始松木针叶林](原始松木针叶林.md)、[原始云杉针叶林](原始云杉针叶林.md)和[原始桦木森林](原始桦木森林.md)。
* 主要由[泥砖](泥砖.md)、各色[陶瓦](陶瓦.md)和[带釉陶瓦](带釉陶瓦.md)以及一些功能方块构成。
* 不包含[箱子](箱子.md)，但会生成[可疑的沙子](可疑的沙子.md)和[可疑的沙砾](可疑的沙砾.md)。

# 修复
* *辅助功能**
* 由于不兼容自定义内容、药水和药箭的纹理，暂时回退了上个版本对药水颜色作出的更改。（）
* 现在使用键盘时的选中指示器会自动显示在菜单物品上。

* *游戏内容**
* 玩家持续疾跑或游泳时，其相机视角不再会卡进方块内部。（）
* 现在玩家进入1.5格高的空间时会自动停止飞行。
* 未开启[实验性玩法](实验性玩法.md)时的潜行不再会覆盖自定义碰撞箱。

* *原版趋同**
* 重新向[实验性玩法](实验性玩法.md)中沉船补给箱的战利品表加入苔藓块。（）

* *方块**
* 修复了漏斗内部的截断错误。（）

* *生物**
* 现在站在营火旁的不完整方块上的生物再次会受到伤害。（）

* *图形**
* 修复了启用光线追踪时告示牌不会显示其文本的问题。（）

* *用户界面**
* 修复了在拥有受损包的情况下打开“我的包”选项卡时发生的崩溃。（）
* 玩家未登录时，首次登录屏幕不再会在非首次启动的情况下出现。
* 修复了游戏手柄图标会与“反馈”窗口相重叠的问题。
* 修复了选择创造模式物品栏中的物品时，鼠标光标会移动至搜索栏的问题。（）
* 修复了使用触摸控制在物品栏中选择物品时会出现重复的工具提示的问题。（）
* 修复了新的死亡屏幕中会显示十字准星的漏洞。
* 修复了新的死亡屏幕中会显示文本格式化代码的漏洞。</onlyinclude>
