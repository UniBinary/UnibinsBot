# 物品模型映射

*页面ID: 128477* | *来源: Minecraft Wiki*

* *物品模型映射**，官方称之为**物品模型（Item Model）**<ref></ref>，是根据物品堆叠的各项条件以选择物品应用哪种[烘焙模型](烘焙模型.md)的机制。

# 定义格式
物品模型映射定义文件都在目录内，且均为JSON文件。如果物品模型映射文件定义无效，则游戏会自动使用[无效模型](无效模型.md)渲染。在原版游戏下，每个物品都使用作为自己的模型映射。

物品模型映射定义文件包含两部分：物品模型的选择机制和客户端渲染物品的基础属性。此文件的格式如下：

* * ：（默认为<code>false</code>）在GUI内渲染时是否允许物品渲染超出槽位大小。

# 类型
物品模型映射有下列类型，不同的映射类型决定了游戏在渲染指定物品堆叠时将使用的物品模型和参数。

# = bundle/selected_item =
此物品模型映射类型会让游戏渲染当前收纳袋内被选中的物品堆叠。

此渲染器要求渲染的物品堆叠必须具有<code>bundle_contents</code>组件，否则这个渲染器不会渲染任何东西。

<div class="treeview">
*
* * ：<code>bundle/selected_item</code>。
</div>

# = composite =
此物品模型映射类型会先计算数组内所有物品模型映射，再根据数组次序从后向前依次渲染。

<div class="treeview">
*  物品模型映射
* <section begin="codec_item_model_composite" />
* * ：<code>composite</code>。
* * ：从后向前依次渲染的物品模型映射。
* ** ：一个物品模型映射。
* *** 递归定义物品模型映射。
* <section end="codec_item_model_composite" />
</div>

在原版资源包中，该类型的物品模型映射用于将收纳袋的前、中、后三层纹理进行组合。其中，中间层纹理由类型的物品模型映射定义。

# == has_component ==
检查物品堆叠是否有给定的物品堆叠组件。

<div class="treeview">
*  物品模型映射
* *
* * ：<code>has_component</code>。
* * ：（物品堆叠组件类型）检查物品堆叠是否具有此组件。
* * ：（默认为<code>false</code>）若当前的物品堆叠组件内容与物品默认物品堆叠组件内容一致时是否认为此组件不存在而返回假。

    },
    "on_true": {
      ... 当lodestone_tracker组件存在时，指南针相对磁石的朝向，根据朝向选取不同的烘焙模型。
    }
  }

# = range_dispatch =
值调配型物品模型映射类型。此物品模型映射类型会先计算并返回物品堆叠内给定的一个数值属性，游戏会按照给定阈值从小到大排序，找到数值属性第一个超过或等于的阈值，并使用对应物品模型映射。如果数值属性小于所有阈值，则使用回落映射。

<div class="treeview">
*  物品模型映射
* * <section begin="codec_item_model_range_dispatch" />
* * ：<code>range_dispatch</code>。
* * ：定义各个阈值和对应的物品模型映射，此列表不需要排序，游戏会在运行时对这个列表排序。
* ** ：一项阈值和对应的物品模型映射。
* *** ：阈值对应的物品模型映射。
* **** 递归定义物品模型映射。具体格式详见上文。
* *** ：阈值。
* * ：回落物品模型映射。如果检查数值小于所有阈值则使用此映射。如果此项不存在，且检查数值小于所有阈值，则使用无效模型。
* ** 递归定义物品模型映射。具体格式详见上文。

# == count ==
读取物品堆叠的物品数量作为返回值。如果物品数量大于物品最大堆叠数量，则返回物品最大堆叠数量。

<div class="treeview">
*  物品模型映射
* *
* * ：<code>count</code>。
* * ：（默认为<code>true</code>）返回物品数量和物品最大堆叠数量之比，而不是当前的物品数量。
</div>

# == damage ==
读取物品堆叠的损坏值（<code>damage</code>组件）。如果物品没有损坏或无法损坏，则返回0。如果损坏值大于最大耐久度（<code>max_damage</code>组件），则返回最大耐久度。

<div class="treeview">
*  物品模型映射
* *
* * ：<code>damage</code>。
* * ：（默认为<code>true</code>）返回物品的损坏进度（即损坏值除以最大耐久度，取值为0-1闭区间），而不是当前的损坏值。
</div>

* * ：<code>time</code>。
* * ：时间获取源。可以为<code>daytime</code>（昼夜时间）、<code>random</code>（随机数）或<code>moon_phase</code>（[月相](月相.md)）。所有数字均在0到1的闭区间内。

# == use_cycle ==
读取当前物品堆叠的剩余使用时间，并对给定的周期取模作为返回值。如果物品堆叠不在任何生物身上，或生物没有使用这个物品堆叠，则返回0。

<div class="treeview">
*  物品模型映射
* *
* * ：<code>use_cycle</code>。
* * ：（，默认为1）周期。
</div>

{{collapse|title=示例|content=
原版刷子物品模型映射JSON文件如下。这里对物品堆叠的剩余使用时间取关于10.0的模，然后乘以0.1，然后根据三种阈值选取不同烘焙模型。item/brush_brushing_0到item/brush_brushing_2的刷子模型仅改变了第三人称下的模型角度，模拟第三人称下的刷子摆动动画效果。
<syntaxhighlight lang="json">
{
  "model": {
    "type": "minecraft:range_dispatch",
    "period": 10.0,
    "property": "minecraft:use_cycle",
    "scale": 0.1,
    "entries": [
      {

# == component ==
读取物品堆叠的可持久化组件数据，获取此组件的数据作为返回值。指定不可持久化的组件或枚举值不符合对应组件的数据要求时此模型映射会直接加载失败。

游戏会完全匹配物品模型映射指定的组件值和物品的组件值。例如，对于<code>[custom_data](数据组件#custom_data.md)</code>组件而言，<code>{a:data,b:true}</code>和<code>"{\"a\":\"data\",\"b\":true}"</code>最终都会被序列化为<code>{"a":"data","b":true}</code>，因此这两种写法尽管形式不同，但会被视为相同的组件值：枚举值同时指定会被游戏警告重复的枚举值，物品数据定义和枚举值定义使用任何一种形式都被视为匹配成功。由于游戏会完全匹配，因此不能单独筛选组件中某个键值对的精确值<ref></ref>，例如枚举值<code>{"a":"data"}</code>不会匹配上述示例。

<div class="treeview">
*  物品模型映射
* *
* * ：<code>component</code>。
* * ：获取物品堆叠的指定组件。
</div>

====  custom_model_data ====
读取物品堆叠的<code>custom_model_data</code>组件中的，获取指定下标的字符串。如果下标超过的长度范围，或物品堆叠不存在<code>custom_model_data</code>组件，则返回null，无法匹配。

<div class="treeview">
*  物品模型映射
* *
* * ：<code>custom_model_data</code>。
* * ：（，默认为0）获取给定物品堆叠<code>custom_model_data</code>组件中对应下标的字符串。
</div>

====  local_time ====
读取当前时间，并根据指定时区、地区设置和日期格式获得日期字符串。此字符串每秒最多获取一次。

<div class="treeview">
*  物品模型映射
* *
* * ：<code>local_time</code>。
* * ：（默认为空字符串）时间格式化为字符串时使用的地区设置。格式可参照[此文档](https://unicode-org.github.io/icu-docs/apidoc/dev/icu4j/com/ibm/icu/util/ULocale.html#ULocale-java.lang.String-)和[RFC3066](https://www.ietf.org/rfc/rfc3066.txt)。
* * ：根据时区获取当前时间后，游戏将时间格式化为字符串的日期格式。日期格式可参照[此文档](https://unicode-org.github.io/icu-docs/apidoc/dev/icu4j/com/ibm/icu/text/SimpleDateFormat.html)。
* * ：（默认为系统设置的时区）获取时间使用的时区。格式可参照[此文档](https://unicode-org.github.io/icu-docs/apidoc/dev/icu4j/com/ibm/icu/util/TimeZone.html#getTimeZone-java.lang.String-)和[此条目](wikipedia:List of tz database time zones.md)。
</div>

{{collapse|title=示例|content=
原版箱子的物品模型JSON文件如下。这里pattern为MM-dd，表示“月-日”格式。通过when设定仅在每年12月24到26日使用圣诞箱子模型，否则使用普通箱子模型。
<syntaxhighlight lang="json">
{
  "model": {
    "type": "minecraft:select",
    "pattern": "MM-dd",
    "property": "minecraft:local_time",
    "cases": [
      {
        "model": {
          "type": "minecraft:special",
          "base": "minecraft:item/chest",
          "model": {
            "type": "minecraft:chest",
            "texture": "minecraft:christmas"
          }
        },
        "when": [
          "12-24",
          "12-25",
          "12-26"
        ]
      }
    ],
    "fallback": {
      "type": "minecraft:special",
      "base": "minecraft:item/chest",
      "model": {
        "type": "minecraft:chest",
        "texture": "minecraft:normal"
      }
    }
  }
}
</syntaxhighlight>
}}
