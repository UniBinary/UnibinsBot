# 基岩版1.16.100.54

*页面ID: 68938* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.100.54**是[基岩版1.16.100](基岩版1.16.100.md)的第5个测试版，发布于2020年9月3日<ref></ref>，同步了更多的特性，将RenderDragon移植到Windows 10上，以及修复漏洞。

# 更改
# = 方块 =
* *[蜂巢](蜂巢（方块）.md)**
* 现在在地图上显示为黄色。

* *[锁链](锁链.md)**
* 现在可以向所有三个方向放置。

* *[灯笼](灯笼.md)和[灵魂灯笼](灵魂灯笼.md)**
* 现在可以[含水](含水.md)。

* *[下界金矿石](下界金矿石.md)**
* 现在在地图上显示为“下界”色。

* *[营火](营火.md)**
* 现在营火可以引燃实体。

* *[灵魂营火](灵魂营火.md)**
* 现在造成的伤害为普通营火的2倍。
* 现在会掉落[灵魂土](灵魂土.md)，而不再掉落[木炭](木炭.md)。
* 现在灵魂营火可以引燃实体。

* *[甜浆果丛](甜浆果丛.md)**
* 现在会对触碰它的玩家和生物造成伤害了。

# = 物品 =
* *[蘑菇](蘑菇.md)**
* 现在可以放置并生长在[菌岩](菌岩.md)上。

* *[下界菌](下界菌.md)**
* 现在可以放置在[菌丝体](菌丝体.md)上。
* * 仍然只能在对应种类的菌岩上才能长成[巨型下界菌](巨型下界菌.md)。

* *[磁石指针](磁石指针.md)**
* 现在可以附上[消失诅咒](消失诅咒.md)。

* *[不死图腾](不死图腾.md)**
* 现在给予[抗火](抗火.md)I而不是II。

# = 生物 =
* *[疣猪兽](疣猪兽.md)**
* 现在会远离[重生锚](重生锚.md)。
* 幼年疣猪兽现在会造成正确的伤害。
* 现在幼年疣猪兽被玩家杀死会掉落经验。

* *[铁傀儡](铁傀儡.md)**
* 现在会攻击疣猪兽和僵尸疣猪兽。

* *[猪灵](猪灵.md)**
* 现在在转化为[僵尸猪灵](僵尸猪灵.md)后会掉落物品栏内的物品。
* 现在可以装备[盾牌](盾牌.md)、[鞘翅](鞘翅.md)、[海龟壳](海龟壳.md)和各种[生物头颅](生物头颅.md)。

* *[猪灵蛮兵](猪灵蛮兵.md)**
* 现在被玩家杀死会掉落，而不是。
* 生成时不再有概率携带附魔[金斧](金斧.md)。

* *[僵尸猪灵](僵尸猪灵.md)**
* 骑乘炽足兽的僵尸猪灵现在在生成时会手持[诡异菌钓竿](诡异菌钓竿.md)。

* *炽足兽**
* 生命值从调整至以同步Java版。
* 现在每条腿都可分别使用独立的纹理。

* *[凋灵骷髅](凋灵骷髅.md)**
* 现在会主动攻击猪灵和猪灵蛮兵。

* *[僵尸疣猪兽](僵尸疣猪兽.md)**
* 现在会被瞬间治疗效果伤害、被瞬间伤害效果治疗。
* 现在幼年僵尸疣猪兽拥有掉落物。

# = 世界生成 =
* *[下界](下界.md)**
* [灵魂沙峡谷](灵魂沙峡谷.md)的天花板现在会被[灵魂沙](灵魂沙.md)和[灵魂土](灵魂土.md)覆盖。
* [玄武岩三角洲](玄武岩三角洲.md)现在会生成[玄武岩](玄武岩.md)的天花板。

* *[废弃传送门](废弃传送门.md)**
* 现在会生成4-12个[闪烁的西瓜片](闪烁的西瓜片.md)，而不仅仅是1个。

# = 游戏内容 =
* *[以物易物](以物易物.md)**
* 调整了一些物品的权重使其和Java版的相匹配，除了[光灵箭](光灵箭.md)。
* [黑石](黑石.md)、[箭](箭.md)和[水瓶](水瓶.md)现在可以通过以物易物获得。
* [下界合金锄](下界合金锄.md)、[荧石粉](荧石粉.md)和[岩浆膏](岩浆膏.md)不再能通过以物易物获得。

* *[附魔](附魔.md)**
* [灵魂疾行](灵魂疾行.md)附魔书现在无法从钓鱼、箱子战利品或袭击获得了。

* *[地图](地图.md)颜色**
* 更新了一些地图颜色。
* * 诡异菌柄、去皮诡异菌柄和诡异木板现在使用颜色而不是。
* * 诡异菌核和去皮诡异菌核现在使用而不是。
* * 诡异菌岩现在使用颜色而不是。
* * 诡异菌和缠怨藤现在使用颜色而不是。
* * 诡异疣块现在使用颜色而不是。
* * 绯红菌柄和去皮绯红菌柄现在使用颜色而不是。
* * 绯红菌核和去皮绯红菌核现在使用颜色而不是。
* * 绯红菌岩现在使用颜色而不是。
* * 绯红菌和垂泪藤现在使用颜色而不是。
* * 绯红木板现在使用颜色而不是。

# = 常规 =
* *[设置](设置.md)**
* 移除了“粒子渲染距离”，因为其和重复。

* *[RenderDragon](RenderDragon.md)**
* Windows 10现在使用新的RenderDragon渲染引擎。

* *[闪烁标语](闪烁标语.md)**
* 移除了“mixer.com/minecraft”，因为[Mixer](wzh:Mixer.md)流媒体服务不再可用。

# 修复
* *性能与稳定性**
* 修复了玩家在睡眠状态下退出游戏后，再次进入游戏会引起崩溃的问题。（）
* 修复了杀死远古守卫者或守卫者可能引起崩溃的漏洞。（）
* 修复了用烟花火箭助推鞘翅飞行可能引起崩溃的问题。

* *原版趋同**
* 锁链现在可以水平放置和连接。
* 地面与天花板的生成现在与Java版相同。
* * 灵魂沙峡谷的天花板现在会被灵魂沙和灵魂土覆盖。（）
* * 玄武岩三角洲现在会生成玄武岩的天花板。（）
* 被骑乘的炽足兽现在可以被诡异菌吸引。
* 猪灵现在会在转化为僵尸猪灵后掉落物品栏内的物品。（）
* 将玩家杀死猪灵蛮兵后获得的经验由10提升至20。（）
* 猪灵转化为僵尸猪灵后会保留身上的装备。（）
* 灯笼现在可以在水下放置，且在灯笼上放置水源不会将其冲掉。
* 猪灵以物易物的内容现在与Java版相似。（）
* 灵魂火不再能融化冰和雪。（）
* 灵魂营火造成的伤害现在为普通营火的2倍。（）
* 僵尸猪灵骑乘炽足兽时不再会悬空。（）
* 诡异菌现在能够在绯红森林中生长。
* 猪灵以物易物时不再会给予玩家下界砖块。（）
* 幼年僵尸疣猪兽和幼年疣猪兽现在拥有掉落物。
* 凋灵骷髅现在会主动攻击猪灵和猪灵蛮兵。（）
* 疣猪兽现在会远离重生锚。（）
* 铁傀儡现在会攻击疣猪兽。（）
* 僵尸疣猪兽现在会被瞬间治疗效果伤害、被瞬间伤害效果治疗。
* 废弃传送门战利品箱中不再只会出现一片闪烁的西瓜片。（）
* 僵尸猪灵现在作为炽足兽骑士生成时会手持诡异菌钓竿。
* 猪灵蛮兵不再会持有附魔金斧。
* 下界苗又可以用于堆肥了。（）
* 灵魂疾行附魔物品不再会生成在堡垒遗迹以外的结构中的战利品箱内。
* 玩家站在岩浆块上时，其装备的下界合金盔甲不再会损失耐久度。（）
* 灵魂营火现在会掉落灵魂土，而不再掉落木炭。（）
* 将炽足兽的生命值调整至与Java版统一。（）
* 猪灵现在能够装备盾牌、鞘翅、海龟壳和多种生物头颅。（）
* 猪灵蛮兵不再会被敲击特定方块的声音激怒。（）
* 幼年僵尸猪灵手持的物品现在会正确显示。
* 诡异木板和绯红木板现在可以快速合成活塞。（）
* 幼年疣猪兽现在会造成正确的伤害值。
* 猪灵现在会在和平难度下自然生成在下界荒地生物群系中。

* *常规**
* 更新了闪烁标语文本和加载提示。
* 为主菜单中的手柄键位提示加入了屏幕文本阅读器支持。
* 修正了多个方块在地图中的显示颜色。（和）
* 创造模式物品栏中的下界疣块和诡异疣块不再被折叠。
* 现在不死图腾在死亡后会给予正确的状态效果。（）
* 现在加载提示会带有标点符号。（）

* *游戏内容**
* 现在矿车内的生物不再会使该矿车行进。（）
* 修复了玩家和生物穿过甜浆果丛时不会受到伤害的漏洞。
* 史莱姆又可以爬梯子了。
* 修复了特定情况下相邻放置的梯子无法显示的漏洞。
* 现在使用弹射物击杀敌对生物后，其身上的战利品会正常掉落。（）
* 现在带有自定义名称的指南针在转化为磁石指针后会保留其名称。
* 现在可以使用铁砧为磁石指针附上消失诅咒魔咒。（）
* 现在带有消失诅咒魔咒的指南针在转化为磁石指针后会保留该魔咒。
* 史莱姆现在会正常生成于积雪生物群系的史莱姆区块内。（）
* 现在铁镐可在袭击中掉落。（）
* 现在红色和棕色蘑菇可以放置并生长在菌岩上。
* 现在绯红和诡异菌可以放置在菌丝体上。

* *图形**
* 现在炽足兽的每条腿都有独立的纹理贴图且都能够正确地镜像翻转。
* 更新了<samp>biomes_client.json</samp>文件以适配迷雾的定义标识符。
* 加入了命令来管理玩家的迷雾设置。这些设置会取代客户端的迷雾设置。
* 为各迷雾的定义创建了一个JSON文件，其中包含设置，以便与先前的数据和硬编码值同步。
* 加入了子对象，其中包含对象。这些对象可用于控制体积迷雾所使用的数据值。</onlyinclude>
