* *21w20a**是[Java版1.17](Java版1.17.md)的第22个，也是最后一个快照，发布于2021年5月19日<ref></ref>，加入了新的NBT标签和方块标签，降低了[紫晶洞](紫晶洞.md)的生成频率，并修复了[美西螈](美西螈.md)行为、世界生成等方面的若干漏洞。

# 新内容
# = 常规 =
* *[NBT格式](NBT格式.md)**
* 加入了<code>HasVisualFire</code>NBT标签。
* * 拥有此标签的实体看起来已着火，但实际上未着火。

* *[标签](Java版标签.md)**
* 加入了<code>features_cannot_replace</code>方块标签。
* * 包含[基岩](基岩.md)、[刷怪笼](刷怪笼.md)、[箱子](箱子.md)和[末地传送门框架](末地传送门框架.md)。

# 更改
# = 方块 =
* *[发光地衣](发光地衣.md)**
* 现在用剪刀开采单个方块空间内的多个发光地衣会掉落正确的数量了。

* *[缠根泥土](缠根泥土.md)**
* 现在对其[锄](锄.md)会将其转化为[泥土](泥土.md)，并掉落1个[垂根](垂根.md)。

* *[结构方块](结构方块.md)**
* 现在储存模式的结构方块会在其GUI中的“显示隐形方块”选项开启时将所有显示为一个小方块。<ref></ref><ref></ref>
* * 空气的3个变种不会被区分。<ref></ref>

* *[大型垂滴叶](大型垂滴叶.md)**
* 略微更改了在物品栏里的图标。

* *[光源方块](光源方块.md)**
* 更改了在物品栏中的纹理上亮度等级的显示位置。

# = 生物 =
* *[美西螈](美西螈.md)**
* 现在只会在[水](水.md)中装死。
* 现在只能对美西螈喂食[热带鱼桶](热带鱼桶.md)，而不能喂食[热带鱼](热带鱼（物品）.md)物品。
* 现在用热带鱼桶喂食美西螈后得到的是[水桶](水桶.md)而不是[铁桶](铁桶.md)。

* *[羊驼](羊驼.md)**
* 不再在[和平难度](难度#和平.md)下攻击玩家。

# = 世界生成 =
* *[紫晶洞](紫晶洞.md)**
* 显著降低了生成频率。

# = 常规 =
* *[复述功能](复述功能.md)**
* GUI旁白现在包括悬停或焦点元素的位置和用法。<!--GUI narration now includes position and usage of hovered or focused element.-->
* *协议**
* 现在客户端登录服务器时，握手包中主机名和端口字段会直接按照地址栏中填写的内容填充，而不会先把它们转换成实际地址和端口。
