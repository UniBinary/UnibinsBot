# 基岩版1.16.210.57

*页面ID: 77592* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.16.210.57**是[基岩版1.16.210](基岩版1.16.210.md)的第7个测试版，发布于2021年1月28日<ref></ref>，加入了[铜](铜.md)相关的方块与物品，并修复了一些漏洞。<ref></ref>

# 新内容
# = 方块 =
* *[铜块](铜块.md)**
* 可用4块铜锭合成获得，也可以重新分解为4块铜锭。
* 随着时间流逝会逐渐锈蚀并改变纹理。
* 可与蜜脾合成涂蜡的铜块以阻止其进一步锈蚀。
* 可用于合成切制铜块。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

* *[铜矿石](铜矿石.md)**
* 在地下以小型[团簇](团簇.md)的形式随机生成，目前仅作为占位符使用。
* 稀有度与铁矿石相同。
* 生成高度与铁矿石相同。
* 可烧炼为铜锭。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

* *[切制铜块](切制铜块.md)**
* 可用于合成切制铜楼梯和台阶。
* 随着时间流逝会逐渐锈蚀并改变纹理。
* 可与蜜脾合成切制涂蜡的铜块以阻止其进一步锈蚀。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

* *[切制铜台阶](切制铜台阶.md)**
* 随着时间流逝会逐渐锈蚀并改变纹理。
* 可与蜜脾合成切制涂蜡铜台阶以阻止其进一步锈蚀。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

* *[切制铜楼梯](切制铜楼梯.md)**
* 随着时间流逝会逐渐锈蚀并改变纹理。
* 可与蜜脾合成切制涂蜡铜楼梯以阻止其进一步其锈蚀。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

* *[避雷针](避雷针.md)**
* 可用3块铜锭合成获得。
* 能够吸引半径64格范围内的闪电。
* 被闪电击中时会发出强度为15级的红石信号。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# = 物品 =
* *[铜锭](铜锭.md)**
* 通过烧炼铜矿石或杀死溺尸掉落获得。
* 可用于合成铜块和避雷针。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# 更改
# = 方块 =
* *[发射器](发射器.md)**
* 现在可以使用蜜脾给未完全锈蚀的铜块涂蜡。

* *[红石粉](红石粉.md)**
* 英文名称重命名为“Redstone Dust”，以与Java版统一。

# = 生物 =
* *[溺尸](溺尸.md)**
* 现在死亡后会掉落铜锭，而不是金锭。
* * 该功能仅在打开[实验性玩法](实验性玩法.md)（子选项）后才会启用。

# 修复
* *辅助功能**
* 当鼠标光标在UI框架外面时，可用键盘调整使用滑块的设置。
* 当“聊天设置”菜单被打开时，屏幕阅读器会提示玩家相关内容。
* 修复了UI屏幕阅读器不会读取权限界面的权限开关选项的问题。
* 屏幕阅读器现在会读取Whisper和公告类消息。

* *性能与稳定性**
* 在一些设备上优化了UI过渡动画的平滑度。（）
* 优化了活动对象使用TemptGoal时的性能。

* *常规**
* 修复了使用命令复制大箱子后导致玩家无法互动的问题。（）
* 使用命令复制相同类型的方块不再显示没有方块被复制。（）
* 修复了玩家在打开潜影盒时会受到掉落伤害的问题。（）
* 玩家现在可以通过烧炼下界砖来获得经验值。（）
* 恢复了所有使用近战攻击的生物攻击其上方或下方目标的能力。
* * 该目标仍然必须在近战攻击距离内才能被攻击。
* * 仅影响大于或等于1.16.210的世界版本。
* 红石粉的英文名称现在显示为“Redstone Dust”而不是“Redstone”。

* *图形与用户界面**
* 现在在配方表中选择工具和盔甲配方时会显示所选物品的背景。
* 主世界中的结构方块的界线框不再会渲染于下界或末地中。（）
* 现在鼠标停留在声音设置滑块会使该滑块变得高亮。
* 现在在窗口中拖动耐久度受损的物品会显示该物品的耐久度条。（）
* 为支持光线追踪以及不支持光线追踪的平台加入了更多有用的视频设置信息。

* *结构方块**
* 取消选择结构方块的结构名称文本框时，结构方块不再会自动保存数据。（）
* 实体被传送到世界的未加载区域时，不再删除该实体的记分板数据。
* 结构动画传送至卸载状态时不再导致游戏崩溃。

* *命令、脚本与附加包**
* 尝试把锁定的物品从容器中取出或放入容器时，将会出现警告。 </onlyinclude>
