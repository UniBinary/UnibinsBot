# 甜菜汤

*页面ID: 11415* | *来源: Minecraft Wiki*

* *甜菜汤（Beetroot Soup）**是一种用[碗](碗.md)盛装的液体[食物](食物.md)类[物品](物品.md)。

# 用途

手持甜菜汤按住键即可食用，每个甜菜汤可以回复。食用完毕后，类似于[蘑菇煲](蘑菇煲.md)和[兔肉煲](兔肉煲.md)，[碗](碗.md)将会留下。
