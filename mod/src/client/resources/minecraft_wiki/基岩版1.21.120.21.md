# 基岩版1.21.120.21

*页面ID: 166466* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.120.21**（ChromeOS/Android）、**Preview 1.21.120.21**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.120](基岩版1.21.120.md)的第2个测试版，发布于2025年9月9日至10日<ref></ref>，更新了[暂停菜单](暂停菜单.md)的UI，并修复了一些漏洞。

# 更改
# = 方块 =
* *[铜灯笼](铜灯笼.md)和[铜火把](铜火把.md)**
* 更改了纹理，以更易于与普通[灯笼](灯笼.md)和[火把](火把.md)区分。

# = 生物 =
* *[铜傀儡](铜傀儡.md)**
* 现在会在转变为[铜傀儡像](铜傀儡像.md)时掉落其头上的[虞美人](虞美人.md)。

# = 常规 =
* *[暂停菜单](暂停菜单.md)**
* 更新了UI。
* * 现在使用新的布局和设计。

* *图形**
* 现在当相机视角过于靠近[玻璃](玻璃.md)和[玻璃板](玻璃板.md)及其染色变种时，这些方块会变得略微透明。

# = 技术性 =
* *AI意向**
* 现在会在解析且无法加载在1.21.120及更高版本中包含无效数据的实体JSON文件时更加严格。

* *方块纹理**
* 加权纹理在自定义方块上运作时不再需要开启即将推出的创作者功能实验性内容。

* *[基岩版编辑器](基岩版编辑器.md)**
* 为颜色时间轴加入了旗标，以便有条件地隐藏选取器的alpha元素。
* 为属性窗格加入了API。
* 加入了，用于表示可以支持嵌套子菜单的汉堡式菜单。
* 修复了滚动条会在AGFX Graph Color组件中短暂出现的漏洞。

* *Windows上的GDK更新**
* Minecraft Preview现在在最新的GDK（游戏开发工具包）上运行。
* * 此项更新会使游戏与Windows平台上的标准分发模型保持一致。
* 更新了文件路径，现在首次安装并加载新版本的Minecraft Preview时，现有的Minecraft世界会转移到：。
* 部分玩家仍然会接收到UWP版本的Minecraft Preview，因为这是逐步推进的。

* *物品**
* 更新了点光源追踪功能，以能够关联自定义方块。

# 修复
* *方块**
* 锈蚀的铜栏杆不再会有看起来不协调的像素。
* 耕耘砂土时，砂土不再有时会由于被耕耘两次而直接转变为耕地。
* 铜傀儡像物品不再会在掉落时偏移。（）
* 现在放在荧光物品展示框中的铜傀儡像会发亮。
* 现在放在荧光物品展示框中的盾牌、饰纹陶罐和地图会发亮。（）

* *图形**
* 降低了在开启的情况下拥有反胃效果期间水面反射效果的扭曲强度。（）
* 修复了启用中的水波功能时，水面会显得杂乱和怪异的问题。（）
* 移除了水配置JSON文件中的参数，该文件会因此使用新的格式并升级至1.21.120版本。

* *生物**
* 拴绳现在会连接在铜傀儡的躯干上，而不是“避雷针”上方。（）
* 现在铜傀儡像的判定箱与Java版相趋同。（）
* 现在蝌蚪的阴影大小与Java版相趋同。（）

* *用户界面**
* 铜箱子不再有时会在UI中被称为“箱子”。（）
* 修复了无法在存储管理屏幕中删除各种内容的漏洞。（）
* 修复了使用床后可能会短暂显示死亡屏幕的漏洞。（）</onlyinclude>
