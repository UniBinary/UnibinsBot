# 服务端文件目录

*页面ID: 175313* | *来源: Minecraft Wiki*

* *服务端文件目录**是游戏运行[服务端核心文件](服务端核心文件.md)的目录。本文只介绍服务端启动主类下的目录结构，[数据生成器](数据生成器.md)和[测试服务端](游戏测试#测试服务端.md)主类下的目录结构请参见对应条目。

# 启动流程

服务端启动时，游戏会先解压库文件并添加类路径，如果对应文件的SHA-256散列值不同则尝试重新解压并在日志中输出警告信息。初始化完毕后，生成和[服务端配置文件](服务端配置文件.md)并检查玩家是否同意EULA，如果未同意则立刻中止服务端并提醒玩家需要同意EULA。

玩家同意EULA后，服务器会正常启动并生成存档，并自动生成服务端配置文件和白名单等玩家文件。通常而言这些文件如果不存在，则服务端会自动生成新文件，等重要文件除外。

# = eula.txt =
是判断玩家是否同意[EULA](EULA.md)（Minecraft最终用户许可协议）的文件。

服务端启动时会检查此文件，如果不存在则立刻生成新文件，其内容如下：

如果最后一行<code>eula=false</code>，则游戏日志会输出<code>You need to agree to the EULA in order to run the server. Go to eula.txt for more info.</code>并中止服务端运行。

如果最后一行<code>eula=true</code>，则检查成功，正常启动服务端。

# = 服务器行为准则文件 =
* *服务器行为准则文件**位于，描述了服务器行为准则。

当服务端配置文件[<code>enable-code-of-conduct</code>](服务端配置文件格式#enable-code-of-conduct.md)属性为<code>true</code>时，服务端会向所有注册表同步完毕的玩家发送服务器准则屏幕，屏幕中的准则内容即来自服务器行为准则文件。

游戏会按照下列顺序获取准则内容：
* 文件必须以<code>.txt</code>结尾。
* 如果文件是符号链接，则其指向的文件必须存在，且也是目录下的文件。
* 文件名称均不区分大小写，游戏会自动转为小写格式。
* 如果存在与客户端语言代码相同名称的准则文件，则读取此文件的内容。
* 如果不存在与客户端语言代码相同名称的准则文件，则使用美式英语的准则文件（）。
* 如果不存在美式英语的准则文件，则根据文件的加载顺序选择任意一个准则文件显示。

服务器准则文件使用UTF-8编码，游戏会原样显示其内容，不支持[格式化代码](格式化代码.md)。在此规范下，尽管目录下的任何文件都可以被游戏加载并显示在屏幕上，但仍然推荐直接使用资源包元数据内的语言代码作为文件名，以防止游戏加载不确定的文件。
