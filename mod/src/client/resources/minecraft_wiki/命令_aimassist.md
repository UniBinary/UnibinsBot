# 命令/aimassist

*页面ID: 128118* | *来源: Minecraft Wiki*

修改玩家的瞄准辅助。

# 语法
   <code>aimassist <players: target> clear</code>
  : 清除瞄准辅助。
   <code>aimassist <players: target> set [x angle: float] [y angle: float] [max distance: float] [target mode: AimAssistTargetMode] [preset id: string]</code>
  : 设定瞄准辅助。

# 参数

   指定将被修改瞄准辅助的玩家。


   指定X轴角度，默认为50。
   且必须在10和90之间（含）。

   指定Y轴角度，默认为50。
   且必须在10和90之间（含）。

   指定最大距离，默认为8。
   且必须在1和16之间（含）。

   指定瞄准模式，默认为。必须为以下其中之一：
  *  — 角度
  *  — 距离

   指定预设ID。
