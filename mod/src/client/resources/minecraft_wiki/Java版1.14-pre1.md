# Java版1.14-pre1

*页面ID: 42198* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.14-pre1**是[Java版1.14](Java版1.14.md)的首个预发布版，发布于2019年4月10日<ref name="article_1.14-pre1"></ref>，优化了游戏性能，并修复了一些漏洞。

# 更改
# = 生物 =
* *[村民](村民.md)**
* 制箭师不再出售幸运之箭。

# = 常规 =
* *[调试屏幕](调试屏幕.md)**
* 加入了“Sounds”部分，用于侦测距离玩家半径247格内的声音事件数量和8格内的音乐（例如[唱片机](唱片机.md)和背景音乐）数量。

* *优化**
* 进行了一些优化。
* 现在在优化世界屏幕中有一个选项，用于清理已缓存的世界数据（如高度图和亮度），在下次载入时会重新计算。

* *[标签](Java版标签.md)**
* 移除了在之前快照加入的所有<code>poi</code>方块标签。
