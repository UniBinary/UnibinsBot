* *垂泪藤（Weeping Vines）**是一种生成在[下界](下界.md)的[绯红森林](绯红森林.md)的可生长的植物。

是垂泪藤上方的茎杆部分。

# 生成
垂泪藤能够生成垂泪藤和垂泪藤植株（见）。

# = 自然生成 =
垂泪藤和垂泪藤植株会自然生成在[绯红森林](绯红森林.md)生物群系，具体生成于[巨型绯红菌](巨型绯红菌.md)的[下界疣块](下界疣块.md)菌盖下沿，以及绯红森林天花板处的[下界岩](下界岩.md)和下界疣块底部。

# = 人为生成 =
对[绯红菌](绯红菌.md)[骨粉](骨粉.md)长成的巨型绯红菌上也可能会生成垂泪藤。

# 获取
垂泪藤只能通过破坏垂泪藤和垂泪藤植株获得。

# 破坏
垂泪藤和垂泪藤植株被挖掘时会立刻被破坏，用于挖掘的工具的耐久度不会下降。

没有被具有[精准采集](精准采集.md)的工具（[剪刀](剪刀.md)除外）挖掘破坏时，有33%的概率掉落1个垂泪藤，若挖掘工具具有[时运](时运.md)I则掉落垂泪藤的概率提升至55%，时运II提升至77%，时运III提升至100%。

使用具有[精准采集](精准采集.md)的工具或使用剪刀挖掘时，总是掉落1个垂泪藤。

# 用途
垂泪藤可以被放置于下表面[方块支撑形状](判定箱#方块支撑形状.md)完整的方块底部。

破坏垂泪藤植株会摧毁植株其下方所有垂泪藤植株和垂泪藤。

# = 攀爬 =
站在垂泪藤或垂泪藤植株内部并按住可以爬上它。如果垂泪藤或垂泪藤植株后面有方块，按下也可以攀爬。

# = 堆肥 =
垂泪藤有50%概率将[堆肥桶](堆肥桶.md)堆肥层数增加1。

# = 生长 =

垂泪藤下方为空气方块时，它会向下生长。

自然生成的垂泪藤拥有17-25的值，玩家放置的垂泪藤拥有0-24的值，使用和放置的垂泪藤为0，该值可以使用来查看。垂泪藤生长时，新长出的垂泪藤的age值增加1，垂泪藤age值为25时不再生长。

当垂泪藤被破坏时，其上方的垂泪藤植株会变为随机<code>age</code>值的垂泪藤。

使用[骨粉](骨粉.md)可以加速垂泪藤生长。

# = 阻止生长 =
对着垂泪藤的底部[剪刀](剪刀.md)可使其变为25，阻止其继续生长。
