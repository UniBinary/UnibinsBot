# Java版18w11a

*页面ID: 34019* | *来源: Minecraft Wiki*

<onlyinclude>

* *18w11a**是[Java版1.13](Java版1.13.md)的第28个快照，发布于2018年3月13日<ref></ref>，加入了珊瑚扇、沉船和溺尸，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[珊瑚扇](珊瑚扇.md)**
* 暂时还不会自然生成。
* 可以放置在方块的侧面。

# = 物品 =
* *[刷怪蛋](刷怪蛋.md)**
* 加入了溺尸刷怪蛋。

# = 生物 =
* *[溺尸](溺尸.md)**
* 生成于所有种类的海洋与河流之中。
* [僵尸](僵尸.md)在溺水后将会变成溺尸。
* 溺尸可能会生成时带持有[三叉戟](三叉戟.md)，这允许你在生存模式中取得该武器。
* 它们可以游泳，但不会浮在水面上。
* 所有溺尸都能近战攻击，而持三叉戟的溺尸将能远程攻击。
* 类似僵尸，溺尸也会攻击小海龟，以及在[海龟蛋](海龟蛋.md)上跳跃以将其破坏。

# = 世界生成 =
* *[沉船](沉船.md)**
* 可以在海中与沙滩上发现。
* 根据船的种类具有三种不同的战利品。
* 可以向上、横向或倒置着生成。

# = 常规 =
* *[控制](控制.md)**
* 加入了，用于将玩家当前的坐标位置复制到剪贴板。
