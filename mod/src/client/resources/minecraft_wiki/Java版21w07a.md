# Java版21w07a

*页面ID: 78173* | *来源: Minecraft Wiki*

<onlyinclude>

* *21w07a**是[Java版1.17](Java版1.17.md)的第10个快照，发布于2021年2月17日<ref></ref>，加入了阴沉石及其变种，更新了数据包，调整和更新了洞穴生成和矿物分布，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[阴沉石](阴沉石.md)**
* 一种新的石头。
* 在Y=0以下生成。
* * 从Y=-1至Y=-7处，[石头](石头.md)逐渐会向阴沉石过渡。
* * 从Y=-8处开始会完全替换掉石头。
* 与[黑石](黑石.md)功能一致，可作为[圆石](圆石.md)的替代品，用于合成石质[工具](工具.md)、[熔炉](熔炉.md)和[酿造台](酿造台.md)。
* 可以合成其磨制、雕纹、石砖及砖瓦版本，以及它们对应的[台阶](台阶.md)、[楼梯](楼梯.md)和[墙](墙.md)类变种。
* 硬度大于石头，不过仍可以使用任意[镐](镐.md)挖掘。
* 爆炸抗性与石头相同。

# = 常规 =
* *[数据包](数据包.md)**
* 将布尔值加入至<code>worldgen\noise_settings\*.json</code>文件中。

# 更改
# = 方块 =
[缩略图|300px|一些主世界矿石的新旧纹理对比图](File:1.17 Ore textures changes.png.md)

* *[矿石](矿石.md)**
* 更改了[煤矿石](煤矿石.md)、[铁矿石](铁矿石.md)、[红石矿石](红石矿石.md)、[金矿石](金矿石.md)和[钻石矿石](钻石矿石.md)的纹理。
* * 其中，除钻石矿石外，上述所有矿石的矿物部分均有了与之前不同的形状。这在很大程度上是为了方便色盲玩家区分不同的矿石。

* *[黑石](黑石.md)、[磨制黑石砖](磨制黑石砖.md)及对应的[楼梯](楼梯.md)、[台阶](台阶.md)和[墙](墙.md)变种**
* 略微更改了纹理。

* *[裂纹磨制黑石砖](裂纹磨制黑石砖.md)**
* 略微更改了纹理。

* *[大型垂滴叶](大型垂滴叶.md)**
* 略微更改了模型。

* *[发光地衣](发光地衣.md)**
* 现在会自然生成在阴沉石上。

* *[信标](信标.md)**
* 现在信标光柱会在源方块的1343格范围内被渲染，而不是之前的256格。

# = 世界生成 =
[缩略图|450px|主世界矿石分布变化对比图](File:1.17 Ore distribution changes.png.md)

* *[洞穴](洞穴.md)**
* 降低了噪声洞穴和含水层的出现频率。

* *[矿石](矿石.md)分布**
* 通过为所有种类的矿石设置一个类似于之前[青金石矿石](青金石矿石.md)的蔓延（spread）值，更改了它们的生成机制。
* * 一些矿石既有了新的“蔓延”式生成机制，同时又保留着之前的线性生成机制。
* [煤矿石](煤矿石.md)、[绿宝石矿石](绿宝石矿石.md)和[铜矿石](铜矿石.md)不再会在Y=0以下生成。
* * 煤矿石会尝试生成两次：一次会在Y=136至Y=256之间均匀生成；另一次则使用“蔓延”机制在Y=0至Y=192之间生成，在Y=96处生成最多。
* * 铜矿石会使用“蔓延”机制在Y=0至Y=96之间生成，在Y=48处生成最多。
* * 绿宝石矿石会使用“蔓延”机制在Y=32至Y=480（尽管常规世界生成无法达到此高度）之间生成，在Y=256处生成最多，并随高度的降低而递减。
* 其他矿石的生成机制也各不相同。
* * [铁矿石](铁矿石.md)会尝试生成两次：一次会使用“蔓延”机制在Y=128至Y=384（尽管常规世界生成无法达到此高度）之间生成，在Y=256处生成最多；另一次则使用“蔓延”机制在Y=-16至Y=80之间生成，在Y=32处生成最多。
* * [金矿石](金矿石.md)会使用“蔓延”机制在Y=-64至Y=32之间生成，在Y=-16处生成最多。[恶地](恶地.md)中额外的金矿生成机制尚未改变。
* * [青金石矿石](青金石矿石.md)会尝试生成两次：一次会使用“蔓延”机制在Y=-32至Y=32之间生成，在Y=0处生成最多；另一次则在Y=-64至Y=64之间均匀生成，且以这种方式生成的青金石矿石会像[远古残骸](远古残骸.md)一样埋藏在方块之中。
* * [红石矿石](红石矿石.md)会尝试生成两次：一次会在Y=-64至Y=15之间均匀生成；另一次则使用“蔓延”机制在Y=-96（尽管常规世界生成无法达到如此低的高度）至Y=-32之间生成，在Y=-64处生成最多。
* * [钻石矿石](钻石矿石.md)会使用“蔓延”机制在Y=-64至Y=16之间生成，且在Y=-64处生成最多。

* *[闪长岩](闪长岩.md)、[安山岩](安山岩.md)和[花岗岩](花岗岩.md)**
* 调整了生成团簇的大小以及生成位置。
* * 每次生成的闪长岩、花岗岩和安山岩会更多且更像一个球型，但它们的生成频率会更低。
* 闪长岩和花岗岩不再在Y=0以下生成。

* *[泥土](泥土.md)**
* 不再在Y=0以下生成。

* *[阴沉石](深板岩.md)**
* 在Y=0以下，阴沉石会作为主要岩石生成。
* * 与石头、闪长岩、花岗岩和泥土不同，安山岩在此高度下仍会随机替换[阴沉石](深板岩.md)生成。

* *[要塞](要塞.md)**
* 现在根据深度会被石头或阴沉石完全包裹住。

* *[废弃矿井](废弃矿井.md)**
* 现在在有必要时会出现用于拉起废弃矿井的廊道的[锁链](锁链.md)。
* 用[原木](原木.md)替代了原先的[木头](木头.md)支柱。
