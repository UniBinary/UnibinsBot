* *凋灵（Wither）**是一种由玩家召唤，会浮在空中且向玩家和生物发射凋灵之首的[亡灵](生物#亡灵生物.md)敌对生物，同时也是[下界之星](下界之星.md)的唯一来源。

# 生成
|可生成凋灵的结构图示|style=max-width:106px}}

如图所示的结构可以召唤凋灵：将4个[灵魂沙](灵魂沙.md)或[灵魂土](灵魂土.md)在任意方向上摆成T形，然后在T形上部的3块灵魂沙或灵魂土上各放置一个[凋灵骷髅头颅](凋灵骷髅头颅.md)。T形的两个角落不能有任何方块阻挡。最后一个放置的方块必须是凋灵骷髅头颅，可以由[玩家](玩家.md)或[发射器](发射器.md)放置。灵魂沙和灵魂土可以混用，凋灵骷髅头颅以及整个结构也可以朝任意的方向放置。

和平难度下不会生成凋灵，即使结构摆放正确。

凋灵总是会在结构底端处生成（向X+偏移最多3个方块来寻找合法生成点），生成位置只与头颅位置有关。

# = 更新区域 =

当已存在一个完整的凋灵结构但没有生成凋灵时（由于方块放置顺序或先前有多余方块干扰），玩家能在特定区域再放置一个凋灵骷髅头颅来“更新”结构生成凋灵。

更新区域的具体范围为：以凋灵结构的头部一行方块为起点，向X轴负方向（西）、Z轴负方向（北）以及向下各扩展2格。除开结构本身所需的空气方块。

若[发射器](发射器.md)周围有完整的凋灵结构，或是仅缺失头部的凋灵结构（头部位置为空气或其他方块，其余位置满足要求），且发射器面对的位置在更新区域内（也包括结构本身空气方块的位置），发射器就能将凋灵骷髅头颅放置在面前，即使这样做可能无法生成凋灵。

# 行为

# = 生成 =
在生成后的11秒内，凋灵在其Boss栏上表现为生命值从0开始逐渐提升。在此期间，凋灵不会受到任何常规类伤害，也无法移动和攻击。凋灵会在此过程的开始获得一个暂时的“凋灵护甲”效果，其视觉体积会在此过程中逐渐增大（但判定箱保持不变），呈现出蓝色外观并产生蓝色粒子效果；而凋灵的外观会在此过程中由纯白色平滑过渡到蓝色正常纹理，并不断旋转。在[生命值](生命值.md)即将充满时，凋灵会在蓝色和黑色之间闪烁，随后创造一场以自身为中心、爆炸威力为7的大[爆炸](爆炸.md)，摧毁附近的方块并对附近的生物造成至多的伤害，同时播放一段生成音效。此音效属于全局声音事件，当游戏规则被设为时，同一世界内的所有玩家在任何维度、任何位置都能听到此音效。在此之后，凋灵会开始攻击邻近的生物，并且可以受到伤害。

通过[刷怪蛋](刷怪蛋.md)或命令生成的凋灵不会有上述行为，而是直接发起攻击。

凋灵不会自然消失。

# == Java版 ==
[alt=凋灵的蓝色护盾|thumb|凋灵生成时出现的蓝色护盾](File:Blue Wither 2.png.md)

凋灵有两种主要行为状态：**平静**和**战斗**。

* *平静**
* 当凋灵没有锁定攻击目标时，其处于**平静**状态。
* 在此状态下，凋灵会以贴地飞行的方式四处游荡。如果游戏难度为普通或困难，凋灵的左右两个附属头会向随机方向发射蓝色[凋灵之首](凋灵之首.md)。当凋灵受到伤害时，随机发射蓝色凋灵之首的频率会提高。此效果仅与受到伤害的频率有关，与受到伤害的数值大小无关。
* 凋灵在尝试以随机方向发射蓝色凋灵之首时，更倾向于水平线向上偏移30度，向下偏移60度的扇形范围方向，而与任何一个凋灵头的朝向无关。

* *战斗**
* 凋灵会主动追逐并攻击侦测范围内的目标。当凋灵找到攻击目标并开始攻击时，其进入**战斗**状态。
* 在发现目标后，凋灵会在目标上方徘徊并快速发射[凋灵之首](凋灵之首.md)。它的每个头颅都可以独立攻击，这使得它可以同时攻击三个生物或玩家。中间的头控制着凋灵的移动。在普通或困难难度下，中间的头有0.1％的概率发射与黑色凋灵之首不同的蓝色凋灵之首。
* 凋灵的攻击范围是以自身尾尖坐标为圆心，水平半径20，垂直半径12的椭球体。虽然凋灵的三个头可以独立攻击，但其攻击范围相同，当攻击范围内存在可攻击目标时会共同攻击。需要注意的是，若修改生物[属性](属性.md)来限制这个范围，则只有中间控制移动的头的侦测范围会受到限制，两个附属头的侦测范围（也即是攻击范围）不会受其影响。
* 在战斗状态下，只有当凋灵受到无来源伤害（如窒息、[闪电](闪电.md)、[喷溅型治疗药水](喷溅型治疗药水.md)等造成的伤害），且游戏[难度](难度.md)为普通或困难时，两个附属头才会尝试随机发射蓝色凋灵之首，但相比于平静状态下积极尝试发射，战斗状态下的尝试频率会消极许多。与**平静**状态下类似，随机发射这一行为仅与受到伤害的频率有关，与受到伤害的数值大小无关。

凋灵每秒恢复生命值。凋灵每通过发射凋灵之首杀死一个生物将恢复生命值。

当生命值减至一半（）以下时，凋灵会获得“凋灵护甲”效果。该效果使凋灵免疫射出的[箭](箭.md)和投掷的[三叉戟](三叉戟.md)对它的伤害，但凋灵仍会受到[潜影弹](潜影弹.md)和[羊驼唾沫](羊驼唾沫.md)的伤害。在此状态下，凋灵只能以与目标相同的高度飞行。当凋灵的生命值恢复到一半以上，“凋灵护甲”效果会自动消失，凋灵会重新尝试在竖直方向上与目标保持距离。

凋灵有发光的纹理，在暗处也清楚可见，但这不会影响其周围方块的实际亮度。

# == 基岩版 ==
凋灵生成后，天空光照会立即下降至11，黑暗的云会出现，类似于雷暴天气，直至凋灵死后才会恢复正常。这只是视觉效果，不会对环境产生实际影响，能自燃的[亡灵生物](亡灵生物.md)仍会自燃。

凋灵的攻击范围是以自身尾尖坐标为圆心，水平半径20，垂直半径12的椭球体。在发现目标后，凋灵会飞向一个随机位置并在适当的位置徘徊。在飞向另一个位置之前，如果此时凋灵生命值未下降到一半以下，将向目标发射3个黑色[凋灵之首](凋灵之首.md)和1个蓝色凋灵之首；如果此时凋灵生命值降至一半以下，则将向目标发射3个黑色凋灵之首和1个蓝色凋灵之首以后，再向目标发射3个黑色凋灵之首和1个蓝色凋灵之首。同时，除简单难度外，随着凋灵生命值的降低，其攻击速度会逐渐加快。

不论是否发现目标，在普通及更高难度时，凋灵会往随机方向发射蓝色凋灵之首。

当目标为非玩家实体时，凋灵总是会瞄准目标脚下射击，以使凋灵之首的爆炸伤害最大化。当目标为玩家时，凋灵发射凋灵之首的角度会有所偏移，因此凋灵攻击玩家时，凋灵之首难以造成最大的爆炸伤害。

当目标为非玩家实体时，凋灵的飞行高度比目标为玩家时低。

在普通和困难[难度](难度.md)下，即使凋灵未察觉到[隐身](隐身.md)的玩家，凋灵仍然会朝隐身的玩家发射黑色凋灵之首，但是攻击频率较低。

当生命值未降至一半以下的凋灵有攻击目标时，如果该目标在较远处或隔着障碍物对凋灵造成了伤害，凋灵会立即暂停所有行为并直接开始位移，且必会移动至目标周围，之后会继续之前被暂停的行为，比如发射了三个凋灵之首后触发了该现象，剩下的那个凋灵之首总是会在位移之后补齐。如果生命值已降至一半以下，位移会被直接替换成冲撞。

在生命值降至一半以下时，凋灵会获得“凋灵护甲”效果，快速落到地面并制造一场大[爆炸](爆炸.md)，同时生成3只[凋灵骷髅](凋灵骷髅.md)（简单[难度](难度.md)下除外），由此生成的凋灵骷髅并不会援助凋灵，但被生成出它们的凋灵误伤后不会进行反击。而此时的凋灵免受射出的[箭](箭.md)、投掷的[三叉戟](三叉戟.md)、[潜影弹](潜影弹.md)以及[羊驼唾沫](羊驼唾沫.md)的伤害。在这种状态下，凋灵会降低飞行高度，进行冲撞攻击，它会放平它的身体，对目标发起冲撞，同时破坏挡道的大部分方块。由于一个漏洞，当凋灵位于Y正坐标时，如果凋灵持续上下浮动，那么生命值降至一半以下时它就会向下冲刺数十格，并破坏水平方向6×6范围内的方块。<ref></ref>

当游戏重新渲染凋灵时，凋灵会重新播放生成动画（这只是视觉上的效果，不会影响凋灵的行为），若该凋灵处于第二阶段，那么在生成动画结束后将不会显示“凋灵护甲”。退出重进世界后，凋灵冲撞前的准备时间将永久地从约5秒降为约3秒。用结构方块保存并加载出的二阶段凋灵也会出现这种现象。

当凋灵半径50格以内没有玩家（包括[创造模式](创造模式.md)和[旁观模式](旁观模式.md)玩家<ref></ref>）时，凋灵每秒恢复生命值。凋灵的生命值恢复到一半以上时，“凋灵护甲”效果不会消失。

当凋灵死亡时，其外观由蓝色正常纹理平滑过渡到纯白色，同时蓝白相间“凋灵护甲”时而穿插浮现，身体不断收缩膨胀，其死亡音效被反复播放。凋灵完全死亡后会制造一场和其生成时一致的大爆炸。

# = Boss栏 =
凋灵有与其相关的[Boss栏](Boss栏.md)显示其生命值，出现在游戏界面的上面。其Boss栏显示时，天空会稍稍变暗。每一只凋灵都会在屏幕上分别显示各自的Boss栏。凋灵的Boss栏会在其距玩家水平距离76格及以内时出现，水平距离80格及以外时消失；凋灵的Boss栏会在其距玩家55格以内时显示。

# = 免疫 =
凋灵免疫火、熔岩、溺水和冰冻[伤害](伤害.md)。虽然凋灵能够摧毁它接触的大多数方块，但凋灵不能免疫窒息伤害。凋灵免疫一切来源于亡灵生物的伤害，但受到来自凋灵自身以外的所有伤害时都会[破坏方块](#破坏方块.md)，尽管对其免疫。

凋灵免疫所有的[状态效果](状态效果.md)。

# = 生物族群 =

凋灵是[亡灵生物](生物#亡灵生物.md)，被具有[亡灵杀手](亡灵杀手.md)魔咒的武器近战攻击时受到额外伤害，被[瞬间伤害](瞬间伤害.md)治疗，被[瞬间治疗](瞬间治疗.md)伤害，不被其他凋灵攻击。

与多数亡灵生物不同，凋灵能够飞行，不会不受控地沉入水底。

凋灵不会在阳光下[着火](着火.md)。

# 你知道吗
* 据[Jeb](Jeb.md)说，凋灵的设计灵感来自《[泰拉瑞亚](wzh:泰拉瑞亚.md)》中玩家主动召唤boss的机制。“Wither”这个名字则来源于*Whispers in Akarra*（Jeb制作的一个游戏）里的一个中-{}-毒咒语。<ref>https://minecraft.net/en-us/article/meet-wither</ref>
* 凋灵的简体中文译名“凋-{}-灵”为该生物引发的[状态效果](状态效果.md)“凋-{}-零”与“亡-{}-灵”的谐音混成词。但凋-{}-灵对应英文原名并非混成词，英文的凋-{}-灵“Wither”与状态效果凋-{}-零“Wither”为同一词，一语双关。
* 有一幅[画](画.md)上画有[灵魂沙](灵魂沙.md)和[凋灵骷髅头颅](凋灵骷髅头颅.md)搭成的凋灵生成结构，暗示了召唤凋灵的方法。
* 如果凋灵受到虚空伤害，它会狂乱地发射蓝色凋灵之首。
* 凋灵的生命高于上限的一半时，其会尝试在目标生物的几格高处悬停。这意味着试图建造或是攀爬到高处以用剑攻击凋灵几乎不可能。
* * 如果凋灵与[烈焰人](烈焰人.md)交战，烈焰人会尝试向上飞，飞到凋灵上面，凋灵也会飞上去来保持与烈焰人的距离，这样造成了两个生物一起攀升，直到到达世界高度限制处（凋灵之首不再生成处）、碰到天花板、任意一方受到伤害或者烈焰人消失。
* 尽管凋灵高3.5格，长3格，宽1格，但是它的碰撞箱只有3.5格高，1格长，1格宽。
* * 准确数据为：2.844格高（可变）、3格长、1.719格宽（亦可变）。
* 凋灵的图案出现在了[雕纹红砂岩](雕纹红砂岩.md)的四个侧面中。
* 凋灵两侧较小的头攻速稍慢。较小的头每2-3秒攻击一次，而中间的头总是每2秒攻击一次。
* [Minecraft: Story Mode](Minecraft: Story Mode.md)里有一个叫做“[](Story Mode:凋灵风暴.md)”的怪物。它的生成结构中心的灵魂沙方块被[命令方块](命令方块.md)取代。
* 尽管凋灵没有可见的脚，其仍能产生脚步声。<ref></ref>
* 在Java版的愚人节玩笑版本[3D Shareware v1.34](Java版3D Shareware v1.34.md)中，凋灵会掉落红色钥匙。
* 据市场合作伙伴经理Quinn所述，凋灵的名字为“Simmons?”，这与末影龙的名字“Jean?”类似。<ref>https://www.minecraft.net/en-us/article/ask-mojang-episode--4</ref>
* * 该名字是“Summon”（召唤）的谐音双关，因为凋灵是由玩家召唤生成的。
* 凋灵的“凋灵护甲”会叠加显示[闪电苦力怕](闪电苦力怕.md)的蓝色电弧纹理；凋灵的“凋灵护甲”不会显示此纹理。
* 当使用特殊手段（如命令）使凋灵被黑色凋灵之首伤害时，会导致凋灵的飞行能力暂时瘫痪从而不受控制地落下，约4秒后恢复正常。
