# 红砂岩楼梯

*页面ID: 44282* | *来源: Minecraft Wiki*

* *红砂岩楼梯（Red Sandstone Stairs）**是[红砂岩](红砂岩.md)制作的[楼梯](楼梯.md)。

# 生成
红砂岩楼梯不会生成在世界中。

# 获取
# = 合成 =
可以使用任意三种红砂岩混合合成，只能只用单种方块合成。

# 破坏
挖掘红砂岩楼梯的合适工具是镐。红砂岩楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

红砂岩楼梯被破坏后会掉落自身。
