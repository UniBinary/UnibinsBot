# 调试屏幕

*页面ID: 8539* | *来源: Minecraft Wiki*

[缩略图|默认配置并未开启“简化调试信息”调试屏幕](File:DebugScreen.png.md)

[缩略图|默认配置并开启了“简化调试信息”调试屏幕](File:DebugScreen without coordinates.png.md)

* *调试屏幕（Debug screen）**可以通过键呼出，会显示[区块](区块.md)缓存、内存使用、玩家的当前[坐标](坐标.md)、当前游戏帧率图表等各种参数。调试屏幕会在需要向其他玩家描述自己位置或监测游戏性能时发挥很大用处。

# 调试选项屏幕

按下可以打开调试选项屏幕，该屏幕用于配置哪些调试信息需隐藏/仅在调试屏幕中显示/始终可见。其他的一些调试组合键也可通过此屏幕开关。

该屏幕顶部有搜索框和一串警告文字。底部有“”和“”两种配置。其中后者会在前者的基础上只保留某些选项及其元素，具体见下方表格。

根据具体用途，各个选项在调试选项屏幕中被分为“调试屏幕文本”和“调试渲染器”两部分，并按首字母顺序排列。

若[游戏规则](游戏规则.md)设为<code>true</code>，或者在[聊天设置](选项#聊天设置.md)中开启了“”选项，则调试屏幕只显示下面表格里带<code>*</code>标记的元素，并在调试选项屏幕内在不显示的元素上显示“”。

调试选项的配置存储在中。

所有的调试快捷键均可在[控制](控制.md)中重新绑定，本文将以默认配置描述。

# = 调试屏幕文本 =

只要调试屏幕具有可渲染元素，游戏就会渲染下列元素。这些元素不受调试选项屏幕控制。

# == NoiseRouter ==
显示用于生成地形和生物群系的噪声值。

* T（Temperature）：温度。用于生物群系的放置，不影响地形。

* V（Vegetation）：植被，即湿度。用于生物群系的放置，不影响地形。

* C（Continents）：大陆性。用于区分海洋与陆地，决定生物群系的放置。

* E（Erosion）：侵蚀度。决定地形的平缓程度，此值越高表示地形越平缓。

* D（Depth）：深度，随高度变化，用于生物群系放置。

* W（Weirdness）：奇异性。此值影响山脊性进而影响了地形的起伏，也用于决定一些生物群系的放置位置，例如向日葵平原和冰刺之地。

* PV（Peaks and Valleys）：山脊性。即地形为山谷或山峰，与奇异性有关。

* AS：原始密度值（即不加粗糙度）。

* N：最终密度值（即加粗糙度）。

# == Biome builder ==
显示噪声值所对应的类别。

* PV（Peaks and Valleys）：地形类型，与山脊性有关。值可为Valley（仅河流生物群系）、Low、Mid、High或Peak。

* C（Continents）：陆地类型，与大陆性有关。值可为Mushroom fields、Deep ocean、Ocean、Coast、Near inland、Mid inland或Far inland。

* E（Erosion）：侵蚀度。值可为0-6。

* T（Temperature）：温度。值可为0-4。

* H（Humidity）：湿度。值可为0-4。

# == SC ==
显示生物生成的详细信息。

* SC：当前可生成生物的区块数。

* M（Monster）：当前生物容量中敌对生物的数量。

* C（Creature）：当前生物容量中动物的数量。

* A（Ambient）：当前生物容量中环境生物的数量。

* A（Axolotls）：当前生物容量中美西螈的数量。

* U（Underground water creature）：当前生物容量中地底水生动物的数量。

* W（Water creature）：当前生物容量中水生动物的数量。

* W（Water ambient）：当前生物容量中水生环境动物的数量。

* M（Misc）：当前生物容量中其他生物的数量。

# == CH ==
客户端[高度图](高度图.md)。描述当前在玩家当前X/Z坐标处存在的最高特定方块的Y坐标。

* CH：指客户端高度图。

* S：在此X/Z坐标处最高非空气方块的Y坐标。

* M：在此X/Z坐标处最高的**任意液体**或**材料阻止运动的方块**的Y坐标。

# == SH ==
服务端[高度图](高度图.md)。描述当前在玩家当前X/Z坐标处存在的最高特定方块的Y坐标。

* SH：指服务端高度图。

* S：在此X/Z坐标处最高非空气方块的Y坐标。若非内置服务端，此值以问号显示。

* O：该X/Z坐标处最高的**[材料](材料.md)阻止运动的方块**的Y坐标。若非内置服务端，此值以问号显示。

* M：在此X/Z坐标处最高**任意液体**或**[材料](材料.md)阻止运动的方块**的Y坐标。若非内置服务端，此值以问号显示。

* ML：该X/Z坐标处最高**任意液体**或**[材料](材料.md)阻止运动且非树叶的方块**的Y坐标。若非内置服务端，此值以问号显示。

# = 调试渲染器 =

# == visualize_block_light_levels ==
[thumb|300px](File:Visualize Block Light Levels.png.md)
* 子区块未计算天空光照时为<code>2</code>，计算天空光照且子区块内全部为空气且天空光均为15时为<code>1</code>，无天空光照计算时为<code>n/a</code>，其他条件下为<code>0</code>。
* 如果方块位置上的方块光不为0，则以黄色到红色字渲染光照等级。
* 游戏只会渲染摄像机周围切比雪夫距离小于10的信息。

# == visualize_chunks_on_server ==
[thumb|300px](File:Debug Feature debug chunks.png.md)
启用时，若调试屏幕正在渲染（即必须有一个调试屏幕的元素正在渲染），则显示玩家周围区块的状态，颜色与[世界加载屏幕](世界加载屏幕.md)中的颜色图相同，并使用红框标记玩家所在区块。同时，在每个区块上方渲染带有区块信息的文字，按照行的顺序分别为：
* 客户端区块信息：如果区块还没有获取到信息，为<code>0n/a</code>；如果区块为空，则为<code>E</code>；其他情况下此项为空字符串。
* 服务端区块加载等级。
* 服务端区块状态。
* 服务端区块当前持久化到存储的区块状态。
* 服务端区块当前的计算状态。

专用服务端中此调试渲染器无效。

# == visualize_entity_supporting_block ==
[thumb|300px](File:Debug Feature debug support blocks.png.md)
实体支撑方块是用于计算方块对实体效果的数据，例如受伤行为和行走速度等。游戏以红色画出玩家自身的主支撑方块，以绿色画出周围实体的主支撑方块，以青色画出实体下方0.2格的方块（如果此方块与主支撑方块不一致）。如果实体没有支撑方块则不进行渲染。

# == visualize_height_map ==
[thumb|300px](File:Debug Feature debug heightmap.png.md)
若各高度图的高度相同，则游戏渲染的标记方块在同一方块内自上而下排列，顺序如下：
* <code>MOTION_BLOCKING_NO_LEAVES</code>：（<code>[0, 0.5, 0.5]</code>）
* <code>MOTION_BLOCKING</code>：（<code>[0, 0.3, 0.3]</code>）
* <code>OCEAN_FLOOR</code>：（<code>[0, 0, 0.5]</code>）
* <code><s>OCEAN_FLOOR_WG</s></code>：（<code>[1, 0, 1]</code>）
* <code>WORLD_SURFACE</code>：（<code>[0, 0.7, 0]</code>）
* <code><s>WORLD_SURFACE_WG</s></code>：（<code>[1, 1, 0]</code>）

# == visualize_sky_light_levels ==
[thumb|300px](File:Visualize Sky Light Levels.png.md)
* 子区块状态计算参见。
* 如果方块位置上的天空光不为15，则以蓝色字渲染光照等级。
* 游戏只会渲染摄像机周围切比雪夫距离小于10的信息。

# 图表
# =  =
使用会在屏幕右侧呼出这个图表。

[150px|缩略图|饼图](File:F3 Profiler Graph.png.md)
* *（Profiler graph）**，亦称**性能分析器图表**或**饼图（Pie chart）**，可用于实时显示各项分析信息。使用1-9键放大查看某一项的详细信息。使用0键返回至上一视图。目前无法查看序号高于9的选项，同时或依次按下两个数字键都只会进入序号不高于9的选项。<ref></ref>

# =  =
使用会在屏幕下方呼出这两个图表，其中刻速率图表只有在玩家游玩[单人游戏](单人游戏.md)或作为一个[服务器](服务器.md)里的[管理员](管理员.md)时才会出现。

[150px|缩略图|帧生成时间图表](File:F3 Frametime Graph.png.md)
左下角的是**帧生成时间图表（Frame rate graph）**，亦称**FPS图表（FPS graph）**，附有每帧1/60秒和1/30秒的参考线。数据柱形的颜色从绿色到黄色再到红色，表示帧生成时间越来越长。

[150px|缩略图|刻速率图表](File:TPS.png.md)
右下角的是**刻速率图表（Tick rate graph）**，亦称**TPS图表（TPS graph）**，在其顶部附有最后240刻的最小、平均和最大刻时间。该柱状图显示了游戏的最后的240刻，数据柱形从低到高，表示游戏运行越来越慢。

# =  =
也被称为**网络性能图表**。使用会在屏幕下方呼出这两个图表。

[150px|缩略图|传输速率柱状图](File:F3 Bandwith Graph.png.md)
左下角的是**传输速率柱状图（Bandwidth graph）**，附有64B/s、1.0KiB/s、16.0KiB/s、1.0MiB/s参考线以及最小、平均、最大速率。数据柱形的颜色取决于上行和下行数据所占比例，颜色越接近紫色表示下行数据占比越高，越接近蓝色表示上行数据占比越高。

[150px|缩略图|网络延迟柱状图](File:F3 Ping Graph.png.md)
右下角的是**网络延迟柱状图（Ping graph）**，附有500ms的参考线以及最小、平均、最大延迟。数据柱形的颜色从绿色到黄色再到红色，表示网络延迟越来越大。
