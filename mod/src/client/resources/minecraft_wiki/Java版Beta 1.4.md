* *Beta 1.4**是的一次主要更新，发布于2011年3月31日，加入了[狼](狼.md)和[曲奇](曲奇.md)，更改了Minecraft徽标，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[上锁的箱子](上锁的箱子.md)**
* 一个[愚人节玩笑](愚人节玩笑.md)。
* * 能够链接到“[Minecraft商店](Minecraft商店.md)”。

# = 物品 =
* *[曲奇](曲奇.md)**
* 一种新的食物。
* 可以恢复[生命值](生命值.md)。

# = 生物 =
* *[狼](狼.md)**
* 新的友好[生物](生物.md)。
* [玩家](玩家.md)可以将其驯服。
* 杀死它不会掉落任何东西。

# = 常规 =
* *[徽标](徽标.md)**
* 用新的Minecraft徽标替换了原来的3D石头方块徽标。

# 更改
# = 方块 =
* *[床](床.md)**
* 在床上睡觉将会重置玩家的重生点，但是大多数情况下无法工作。
* * 只有在玩家于多人游戏中点击“起床”的时候，出生点才有可能于无意中被更改。

* *[小麦](小麦.md)**
* 增加了其成长速度。

# = 物品 =
* *[可可豆](可可豆.md)**
* 现在可以在[地牢](地牢.md)的[箱子](箱子.md)中找到。

# = 生物 =
* *[绵羊](绵羊.md)**
* 现在会以较小的概率自然生成粉红色或棕色的绵羊。

* *[蜘蛛](蜘蛛.md)**
* 不再会践踏作物。
* 移除了蜘蛛爬行时的声音。

# = 游戏内容 =
* *[成就](成就/Java版.md)**
* 已实现大部分的基础功能。

# = 常规 =
* *[控制](控制.md)**
* 打开[物品栏](物品栏.md)的热键现在是。

* *[多人游戏](多人游戏.md)**
* 现在架设服务器时可以在中自定义世界种子。

* *[设置](设置.md)**
* 现在UI大小可以在本地的档案下的中更改。

* *[统计信息](统计信息.md)**
* 已实现大部分的基础功能。

# 修复
* *修复了4个漏洞**
* 现在僵尸和蜘蛛能在所有情况下对玩家造成伤害，而之前只有当它们比玩家高1格时才能造成伤害。
* 修复了多人游戏客户端中史莱姆的生成。
* 现在当玩家不能放置方块时，手臂不会摆动。
* 在多人游戏中，玩家“摆动”时，快速打开和关闭物品栏不再中断玩家的“摆动”动画，之前可以利用此漏洞更快地破坏方块。<!-- 英文原文仅有“swinging”，没有指出具体“摆动”的部位 -->
