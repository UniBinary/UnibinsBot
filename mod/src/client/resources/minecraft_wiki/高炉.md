* *高炉（Blast Furnace）**是专用于烧炼[矿石](矿石.md)、[工具](工具.md)和[盔甲](盔甲.md)的[熔炉](熔炉.md)变种。

# 生成
# = 自然生成 =
高炉可以生成于[古迹废墟](古迹废墟.md)的匠铺以及[村庄](村庄.md)的盔甲房里。

# 破坏
挖掘高炉的合适工具是镐。高炉需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

高炉被破坏后会掉落自身、内容物和储存的经验值。

# 用途
高炉不能被[活塞](活塞.md)推动。

# = 烧炼 =

高炉只能[烧炼](烧炼.md)矿物、金属工具、武器和盔甲。速度为每烧炼一个物品，即每分钟烧炼12个物品，是[熔炉](熔炉.md)的2倍。

高炉可以打开它的界面。下方的槽位为“燃料槽”，用于放置燃料（最多1组）；上方的槽位为“烧炼槽”，用于放置烧炼物（最多1组）；右侧的槽位为“成品槽”，烧炼成品会存放于此（最多1组）。

连接到高炉上面的[漏斗](漏斗.md)会向烧炼槽中添加烧炼物，连接到高炉侧面的漏斗会向燃料槽中添加燃料，高炉下面的漏斗会取走成品槽中的成品和燃料槽中的[铁桶](铁桶.md)，如果铁桶与成品槽的成品同时存在会优先吸取或。

烧炼产生的经验会存储在高炉中，当玩家取出成品槽中的成品或高炉被破坏时一并给予玩家。

燃烧中的高炉会生成烟雾和火焰[粒子](粒子.md)。

# = 红石比较器 =
[红石比较器](红石比较器.md)可检测高炉的内容物占空比，烧炼槽、燃料槽和成品槽都会被统计。

# = 光源 =
燃烧中的高炉会发出13级的光。

# = 自定义名称 =
高炉界面的标题默认为“高炉”，可以在未放置之前使用[铁砧](铁砧.md)重命名来进行更改，也可以通过使用命令修改高炉的<code>CustomName</code>标签进行更改。

# = 锁定 =

高炉可以被<code>lock</code>标签上锁。如果高炉的该标签不是空白的，那么这个高炉必须使用符合该标签表示的物品谓词的物品打开。

# = 更改村民职业 =

如果一个高炉没有被[村民](村民.md)认领，则附近的任意一个失业村民有机会转变职业为[盔甲匠](盔甲匠.md)。
