# Java版Classic 0.0.18a 02

*页面ID: 35267* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.0.18a_02**是的一次更新，发布于2009年6月14日<ref name="blog"></ref><ref>[IRC日志](#日志.md): "*A4:54:18 <Notch> ok, new client up, with fixed font so you can tell an I from an l, the ability to say @, |, \ and $ in the chat, and probably better framerate*" (09:54:18 UTC)</ref>，修复了一些漏洞。

# 新内容
# = 常规 =
* *[字体](字体.md)**
* 支持字符<code>|</code>、<code>@</code>和<code>$</code>。<ref name="blog"/>

# 更改
# = 常规 =
* *[字体](字体.md)**
* 修改了字符的显示。<ref name="blog"/>

# 修复
* *修复了2个漏洞**
* 修复了0.0.18a中帧率不稳定的问题。<ref name="blog"/>
* 修复了在方块角落里的水有图像错误的问题。</onlyinclude>
