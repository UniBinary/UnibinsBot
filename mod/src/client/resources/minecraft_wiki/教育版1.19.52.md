# 教育版1.19.52

*页面ID: 100337* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.19.52**是**[荒野更新](荒野更新.md)**的首个正式版，也是的一次主要更新，发布于2023年4月11日。此次更新加入了对应版本的特性。<ref></ref>

# 新内容

* 加入了[荒野更新](荒野更新.md)的特性。

# = 常规 =
* *游戏库**
* 加入了“Computer Science”文件夹。

# 更改
# = 常规 =
* *登录和切换账户**
* 将主菜单屏幕中的“切换账户”按钮改为“管理账户”，可以使用户选择是否记住账户的用户名和密码、退出登录以及切换账户。

* *导入**
* 向iOS的游玩屏幕中加入了“导入”按钮。

* *验证库**
* 用于微软账户登录的验证库由Azure Active Directory Authentication Library（ADAL）切换至Microsoft Authentication Library（MSAL）。

* *游戏库**
* 优化了按功能标签搜索的功能以及更好的非英语搜索功能等。<!-- Improved Search featuring tag search, better non-English searching, and more! -->

* *用户体验**
* 提升了在游玩过程中使用提示框和控制提示的体验，使其用起来更简单。

* *最低配置**
* 更改了最低配置，新的如下：
* * macOS Big Sur（11.0）
* * Windows 8.1
* * iOS 11
