# Java版1.18-pre7

*页面ID: 90925* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.18-pre7**是[Java版1.18](Java版1.18.md)的第7个预发布版，发布于2021年11月23日<ref></ref>，修复了一些漏洞。

# 更改
# = 方块 =
* *[土径](土径.md)**
* 更改了侧面纹理，将其中的泥土部分上移了1个像素，以与[泥土](泥土.md)一致。

* *[原木](原木.md)**
* 再次更改了去皮深色橡木原木的纹理。

# = 世界生成 =
* *[溶洞](溶洞.md)和[繁茂洞穴](繁茂洞穴.md)**
* 地物数量再次有所增加。
