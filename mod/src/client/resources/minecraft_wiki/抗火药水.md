# 抗火药水

*页面ID: 181534* | *来源: Minecraft Wiki*

* *抗火药水**是提供[抗火](抗火.md)状态效果的[药水效果](药水效果.md)。

该药水效果可以制成[药水](药水.md)**抗火药水（Potion of Fire Resistance）**、[喷溅药水](喷溅药水.md)**喷溅型抗火药水（Splash Potion of Fire Resistance）**、[滞留药水](滞留药水.md)**滞留型抗火药水（Lingering Potion of Fire Resistance）**和[藥水箭](藥水箭.md)**抗火之箭（Arrow of Fire Resistance）**。

此药水效果有对应的延长版。

# = 礼物 =

[制箭师](制箭师.md)会向带有[村庄英雄](村庄英雄.md)效果的玩家投掷抗火之箭。

# = 以物易物 =

[猪灵](猪灵.md)获得[金锭](金锭.md)后有的概率给予玩家1瓶抗火药水。

# = 女巫 =
[女巫](女巫.md)在受到[火焰伤害](火焰伤害.md)后會饮用抗火药水。若飲用时被杀死，该药水有/（[抢夺](抢夺.md)魔咒每级增加1%）的概率作为装备掉落物掉落。

# = 自然生成 =

[沼泽小屋](沼泽小屋.md)的[炼药锅](炼药锅.md)内可能装有抗火药水。

# = 炼药锅 =

对装有抗火药水的炼药锅使用[玻璃瓶](玻璃瓶.md)可获得抗火药水、喷溅型抗火药水或滞留型抗火药水，具体形式取决于炼药锅内容物。

对装有抗火药水的炼药锅使用[箭](箭.md)可获取抗火之箭，最大数量随内容物水位增加依次为16、32和64。
