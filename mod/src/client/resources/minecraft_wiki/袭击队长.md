* *袭击队长（Raid Captain）**被称为**Raid Captain**。被称为**Illager Captain（灾厄村民队长）**。}}是头顶戴有[不祥旗帜](不祥旗帜.md)的[灾厄村民](灾厄村民.md)，任何灾厄村民都可以是袭击队长；只有掠夺者和卫道士可以是袭击队长。

# 生成
袭击队长的生成条件与灾厄村民相同，生成完全随机。

它们可以使用命令附加[生成事件](生成事件.md)生成，例如生成一个掠夺者袭击队长（非巡逻队队长）为。使用可以使一个掠夺者或卫道士晋升为袭击队长（例如，使一个掠夺者晋升为袭击队长）。

它们可以使用命令生成，例如生成一个掠夺者袭击队长为{{cmd|long=1|summon minecraft:pillager ~ ~ ~ {PatrolLeader: 1b,equipment: {head: {components: {"minecraft:item_name": {translate: "block.minecraft.ominous_banner"}, "minecraft:tooltip_display": {hidden_components: ["minecraft:banner_patterns"]}, "minecraft:rarity": "uncommon", "minecraft:banner_patterns": [{color: "cyan", pattern: "minecraft:rhombus"}, {color: "light_gray", pattern: "minecraft:stripe_bottom"}, {color: "gray", pattern: "minecraft:stripe_center"}, {color: "light_gray", pattern: "minecraft:border"}, {color: "black", pattern: "minecraft:stripe_middle"}, {color: "light_gray", pattern: "minecraft:half_horizontal"}, {color: "light_gray", pattern: "minecraft:circle"}, {color: "black", pattern: "minecraft:border"}]}, count: 1, id: "minecraft:white_banner"<nowiki>}}}</nowiki>}}。

虽然幻术师不会自然生成，但是使用命令生成的幻术师也有概率成为袭击队长。卫道士袭击队长不会自然生成，但可以使用命令生成。

# = 灾厄巡逻队 =
袭击队长作为[灾厄巡逻队](灾厄巡逻队.md)的一部分生成，成员皆为[掠夺者](掠夺者.md)。

# = 袭击 =
在的[袭击](袭击.md)中，袭击队长可以作为一组掠夺者的一员生成，有时还会骑着劫掠兽生成。处于袭击中的袭击队长在被击杀时不会掉落[不祥之瓶](不祥之瓶.md)，但当它的旗帜掉落时，其他灾厄村民会尝试捡起旗帜并成为新的袭击队长。

袭击队长不会在袭击中自然生成，但是代码中有相应的内容。

# = 掠夺者前哨站 =
[掠夺者前哨站](掠夺者前哨站.md)内会生成1-3个袭击队长，且总会是[掠夺者](掠夺者.md)。

# 掉落物
# = 常规 =

当袭击队长死亡时，会掉落:
* 1个，总会掉落，且[抢夺](抢夺.md)魔咒对其无效。
* 1个，仅当袭击队长为不在袭击中的掠夺者或时掉落，且抢夺魔咒对其无效，每种等级掉落概率相同。

# = 参与袭击者 =
袭击中生成的袭击队长会额外掉落：

# 行为
袭击队长的行为与普通[灾厄村民](灾厄村民.md)相同，但其他灾厄村民会在其后跟随（这不包括掠夺者前哨站生成的队长），表现为队长在前面领队。袭击期间，若袭击队长因死亡而掉落，附近的灾厄村民将会尝试捡起该旗帜并成为下一个队长。
# = 传播攻击目标 =

袭击队长会将自己当前的攻击目标传播给周围8×8×8范围内其他同属于灾厄巡逻队的成员，这一过程无视[隐身](隐身.md)效果。

若袭击队长是带有<code>Johnny</code>标签的卫道士，可能会导致同灾厄巡逻队的成员错误地自相残杀，罕见情况下会导致生物攻击自己。
