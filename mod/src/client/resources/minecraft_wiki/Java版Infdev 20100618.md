# Java版Infdev 20100618

*页面ID: 35981* | *来源: Minecraft Wiki*

<onlyinclude>
* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本是一次[秘密更新](秘密更新.md)，发布于2010年6月18日<ref></ref>，加入了铁轨、矿车和下落的方块。此版本也被称作**秘密周五更新1**。

# 新内容
# = 方块 =
* *[铁轨](铁轨.md)**
* 可用于为矿车铺设轨道。
* 可由6个[铁锭](铁锭.md)和1个[木棍](木棍.md)合成。

# = 非生物实体 =
* *[矿车](矿车.md)**
* 可用来存放[物品](物品.md)。
* 右键单击矿车可像打开箱子一样打开（称为“矿车”的容器）。将它们填满会使其内部的“泥土”层上升。

* *[下落的方块](下落的方块.md)**
* 会在沙子或沙砾失去支撑时出现。
* 落到地面上后会对应地转变为[沙子](沙子.md)或[沙砾](沙砾.md)。

# 更改
# = 方块 =
* *[黑曜石](黑曜石.md)**
* 被破坏后现在会掉落自身而不是圆石。

* *[门](门.md)**
* 更改了纹理。

* *[沙砾](沙砾.md)和[沙子](沙子.md)**
* 现在失去方块支撑时转化为下落的方块。

# = 游戏内容 =
* *[虚空](虚空.md)**
* 现在[玩家](玩家.md)掉入虚空后会受到伤害。

# = 世界生成 =
* *天空**
* 调整了渲染。</onlyinclude>

# 启动器版
该版本是[启动器](启动器.md)中唯一可用的Infdev版本，版本号被标记为inf-20100618。
