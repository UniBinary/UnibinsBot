# Java版17w18b

*页面ID: 29686* | *来源: Minecraft Wiki*

<onlyinclude>

* *17w18b**是[Java版1.12](Java版1.12.md)的第11个，也是最后一个快照，发布于2017年5月4日<ref></ref>，加入了新的进度触发器，并修复了一些漏洞。

# 新内容
# = 常规 =
* *[进度](进度.md)**
* 增加了一个新的“”标签和一些新的进度：
* *  -
* *  -
* *  -
* *  -
* 添加了新的进度触发器：
* * <code>consume_item</code>
* * <code>placed_block</code>
* * <code>arbitrary_player_tick</code> - 每一刻只有一个玩家能运行它。

# 更改
# = 常规 =
* *[进度](进度.md)**
* 进度“”和“”现在使用22种生物而不是23种，从列表中移除了[幻术师](幻术师.md)。
* 在[17w18a](17w18a.md)中添加的进度被移动至标签。

* *[复述功能](复述功能.md)**
* 使复述功能（也许）能在任何地方运行（Linux系统需要[Flite](http://www.festvox.org/flite/)来运行）。
