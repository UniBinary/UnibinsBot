# Java版15w37a

*页面ID: 18107* | *来源: Minecraft Wiki*

<onlyinclude>

* *15w37a**是[Java版1.9](Java版1.9.md)的第23个快照，发布于2015年9月10日<ref></ref>，加入了一条新的游戏规则，新的NBT标签以及一种新的超平坦预设，将虚空的性质改为生物群系，并修复了一些漏洞。

# 新内容
# = 命令格式 =
* ***
* 新的游戏规则：<code>spectatorsGenerateChunks</code>。
* * 禁止旁观模式的玩家生成区块。

* *NBT标签**
* 关于实体<code>MinecartHopper</code> （漏斗矿车）：
* * <code>Enabled</code> (byte型)：决定矿车的漏斗是否会将物品收到它的物品栏中。
* ** 例子：<code>/summon MinecartHopper ~ ~1 ~ {Enabled:1b}</code>。

# = 世界生成 =
* *[超平坦](超平坦.md)**
* 新的超平坦预设：虚空。
* * 将玩家生成在[虚空平台](虚空平台.md)上，由33×33的石头平面组成（中间是圆石），且不再生成其他结构。
* * 虚空现在是一种生物群系了（数字ID为127）。

# 更改
# = 物品 =
* *[金苹果](金苹果.md)**
* 提供的生命恢复等级从II削减为I。

* *[附魔金苹果](附魔金苹果.md)**
* 提供的生命恢复等级从V削减为II。
* 提供的生命恢复时间从30秒削减为20秒。
* 提供的伤害吸收等级从I提升为IV以达成平衡。

* *[紫颂果](紫颂果.md)**
* 传送区间从±32削减为±8。

# = 游戏内容 =
* *战斗机制**
* 弓可在副手使用了。
* 对[盾牌](盾牌.md)再平衡。
* * 有了新的合成配方。
* * 不再有基础颜色。
* * 纹理为木质平面。
* * 将盾牌与[旗帜](旗帜.md)合成仍然可以做出有图案的盾牌。
* * 箭可以从盾牌上弹射来伤害到别的实体。
* 剑的攻速从1.45提升到1.6。
* 斧的攻速将取决于类型，不再全类型为0.8。
* * 木斧和石斧是0.8。
* * 铁斧是0.9。
* * 金斧和钻石斧为1。
* 修改斧的攻击伤害
* * 石斧和钻石斧会造成9点伤害，原本分别为8和10。

* *[极限模式](极限模式.md)**
* 如果玩家在极限模式中死亡，他们可以选择进入旁观模式而防止地图被删除。
