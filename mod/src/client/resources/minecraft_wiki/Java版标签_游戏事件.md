# Java版标签/游戏事件

*页面ID: 161617* | *来源: Minecraft Wiki*

* *游戏事件标签（Game Event Tags）**是[游戏事件](游戏事件.md)的组合。

# 使用
游戏事件标签不可被主动调用，它们被游戏用来控制振动系统中的各项检测条件。

# 当前版本

# = allay_can_listen =
* [悦灵](悦灵.md)可以检测的游戏事件。
* 添加其他游戏事件不影响悦灵的AI活动，默认游戏事件被移除后悦灵将不能被音符盒吸引。

# = ignore_vibrations_sneaking =
* 潜行的实体产生这些游戏事件时，不会被振动监听器检测。

# = shrieker_can_listen =
* [幽匿尖啸体](幽匿尖啸体.md)可以检测的游戏事件。

# = vibrations =
* [幽匿感测体](幽匿感测体.md)和[校频幽匿感测体](校频幽匿感测体.md)可以检测的游戏事件。
* 游戏事件只能移除，游戏不会检测非默认的游戏事件。

# = warden_can_listen =
* [监守者](监守者.md)可以检测的游戏事件。

# 已移除的标签
# = dampenable_vibrations =

添加于：[22w13a](22w13a.md)。移除于：[22w17a](22w17a.md)。
