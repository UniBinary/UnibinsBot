# 音乐唱片Precipice

*页面ID: 156618* | *来源: Minecraft Wiki*

* *Precipice**是一张[音乐唱片](音乐唱片.md)，可用于播放由[Aaron Cherof](Aaron Cherof.md)创作的同名曲目。

# = 音乐 =

[noicon](File:Precipice.ogg.md)

Precipice是一首打击乐，由清脆的铃为主调，夹杂着播放器的电流声。

# = 红石 =

音乐唱片Precipice放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为13的信号。

# 你知道吗
* 音乐唱片Precipice必须通过[宝库](宝库.md)战利品才能实现可再生。这是因为宝库可以被每个玩家打开无限次数<ref></ref>，且[试炼钥匙](试炼钥匙.md)是[可再生资源](可再生资源.md)。
* 此唱片中3分10秒至结尾的琶音与“Moog City”的主旋律相似。
