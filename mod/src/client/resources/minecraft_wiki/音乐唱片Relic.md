# 音乐唱片Relic

*页面ID: 156617* | *来源: Minecraft Wiki*

* *Relic**是一张[音乐唱片](音乐唱片.md)，可用于播放由[Aaron Cherof](Aaron Cherof.md)创作的同名曲目。

# 获取
# = 考古战利品 =
用[刷子](刷子.md)刷扫[古迹废墟](古迹废墟.md)里的[可疑的沙砾](可疑的沙砾.md)有概率掉落音乐唱片Relic。

# 用途
# = 音乐 =

[noicon](File:Relic.ogg.md)

Relic是一首具有低音质的欢快的8-bit曲调的音乐。

曲中夹杂着轻微的唱片颗粒声和嘶嘶声。C混合利底亚调式，部分旋律基于[Minecraft Legends](Minecraft Legends.md)的曲目A Time of Legends和The Well of Fate。

# = 红石 =

音乐唱片Relic放于[唱片机](唱片机.md)中可使[红石比较器](红石比较器.md)输出强度为14的信号。
