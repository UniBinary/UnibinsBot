# Java版Infdev 20100316

*页面ID: 36000* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年3月16日，并修复了一些漏洞。<ref></ref>

# 新内容
# = 生物 =
* *[怪物](怪物（已移除实体）.md)**
* 一种敌对生物，行为与[僵尸](僵尸.md)类似。
* 外观与[生物](生物（已移除实体）.md)完全相同。
* 只能通过使用Mod或地图编辑器来生成。

# 更改
# = 方块 =
* *[TNT](TNT.md)**
* 现在会被点燃了，但不会爆炸。

# = 生物 =
* *常规**
* 现在生物能够重新工作了。

# = 非生物实体 =
* *[箭](箭.md)**
* 现在击中非液体方块时，会等概率生成以下[生物](生物.md)中的一个：[绵羊](绵羊.md)、[猪](猪.md)、[骷髅](骷髅.md)、[苦力怕](苦力怕.md)、[蜘蛛](蜘蛛.md)和[僵尸](僵尸.md)。

* *常规**
* 现在实体能够重新工作了。

# = 游戏内容 =
* *[昼夜更替](昼夜更替.md)**
* 现在为20分钟一个周期。

* *[第三人称视角](第三人称视角.md)**
* 现在会再次显示玩家。

* *常规**
* 现在玩家会携带999个[钻石斧](钻石斧.md)、999个[钻石锹](钻石锹.md)、999个[钻石镐](钻石镐.md)、999个[火把](火把.md)、999个[打火石](打火石.md)、999个[木板](木板.md)、999个[玻璃](玻璃.md)、999个[弓](弓.md)和999个[箭](箭.md)生成。

# 修复
* *修复了2个漏洞**
* 打开物品栏不再使游戏崩溃。
* 不完整方块（如火把、树苗、蘑菇等）在很大的坐标处不再被渲染成二维的了。</onlyinclude>
