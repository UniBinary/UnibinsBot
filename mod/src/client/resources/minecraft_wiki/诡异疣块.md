# 诡异疣块

*页面ID: 54558* | *来源: Minecraft Wiki*

* *诡异疣块（Warped Wart Block）**是自然生成于[诡异森林](诡异森林.md)的装饰性方块。

# 生成
# = 自然生成 =
诡异疣块会生成于组成[巨型诡异菌](巨型诡异菌.md)的菌盖。

# 获取
诡异疣块只能通过破坏诡异疣块获得。

# 破坏
挖掘诡异疣块的合适工具是锄。

诡异疣块被破坏后会掉落自身。

# 用途
# = 堆肥 =
将诡异疣块放入[堆肥桶](堆肥桶.md)都有85%的概率使堆肥等级增加1。
