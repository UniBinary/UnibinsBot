# 命令/setmaxplayers

*页面ID: 39812* | *来源: Minecraft Wiki*

设置可加入多人游戏的玩家数量上限。

# 语法
  <code>setmaxplayers <maxPlayers: int></code>

# 参数

  指定要设置的玩家数量上限值。若此值比当前在线玩家总数要小，或者比服务器容许的最大连接数要大，则此值会被修正至上述约束范围内。
  且最大值为40。

# 结果

# 示例
* 设置可加入多人游戏的玩家数量上限为2：<code>/setmaxplayers 2</code>
