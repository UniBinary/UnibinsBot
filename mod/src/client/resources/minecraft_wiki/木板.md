* *木板（Planks）**是一类在众多[合成](合成.md)配方中常用的[方块](方块.md)。

* *竹板（Bamboo Planks）**是由竹块制成的方块，功能上与木板类似。

# 生成
红树木板、樱花木板、苍白橡木木板、竹板、绯红木板、诡异木板不会生成在世界中。

# 破坏
挖掘木板的合适工具是斧。

木板被破坏后会掉落自身。

# 用途
[不同种类木板颜色的过渡|缩略图](File:Planks_Chart.png.md)

木板可用于建筑、合成和烧炼物品。

# = 合成材料 =
木板在许多合成配方中都会被用到。

[门](门.md)、[栅栏](栅栏.md)、[栅栏门](栅栏门.md)、[台阶](台阶.md)、[楼梯](楼梯.md)、[船](船.md)、[活板门](活板门.md)、[压力板](压力板.md)、[按钮](按钮.md)和[告示牌](告示牌.md)都必须用相同类型的木板合成来获得对应木板类型的方块。

其他成品不同类型的木板自由混合不会对结果造成影响。

# = 燃料 =
非下界木板可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的燃料，每个木板可烧炼1.5个物品。

# = 修复 =
木质工具（[木剑](木剑.md)、[木镐](木镐.md)、[木斧](木斧.md)、[木锄](木锄.md)、[木锹](木锹.md)和[木矛](木矛.md)）以及盾牌可在[铁砧](铁砧.md)中用木板[修复](修复.md)。

# 你知道吗
* [Dinnerbone](Dinnerbone.md)曾经开玩笑说要加入[染色木板](染色木板.md)。
* 大多数可由任意木板制作的方块和物品都使用橡木木板纹理，[物品展示框](物品展示框.md)和[制箭台](制箭台.md)使用白桦木板纹理，[制图台](制图台.md)使用深色橡木木板纹理，[盾牌](盾牌.md)和[木桶](木桶.md)使用云杉木板纹理。
* 1个[原木](原木.md)或[木头](木头.md)可作为[熔炉](熔炉.md)燃料烧炼1.5个物品，但将其分解成4个木板后则可以烧炼6个物品。
