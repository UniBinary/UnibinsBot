# 2026年第1次小更新

*页面ID: 181233* | *来源: Minecraft Wiki*

* *2026年第1次小更新**是一次即将到来的小更新，发布时间待定。

# 重要特性

# = 方块 =
* *[32px](File:Golden Dandelion JE1 BE1.png.md) [金蒲公英](金蒲公英.md)**
* 一种新的花，可用于阻止幼年[动物](动物.md)成长或使其重新开始成长。
* 使用1个[蒲公英](蒲公英.md)和8个[金粒](金粒.md)合成：


* *[32px](File:Note Block JE2 BE2.png.md) [音符盒](音符盒.md)**
* 加入了新的音色“小号”（Trumpet），对应的乐器方块为[铜块](铜块.md)、[雕纹铜块](雕纹铜块.md)、[切制铜块](切制铜块.md)、及其氧化和涂蜡变种。
* * 音色会随着[氧化](氧化.md)程度的不同而改变。

# = 物品 =
* *[32px](File:Name Tag JE2 BE2.png.md) [命名牌](命名牌.md)**

* *[刷怪蛋](刷怪蛋.md)**
* 现在对对应的生物时总会生成幼年生物，以与[Java版](Java版.md)保持一致。
