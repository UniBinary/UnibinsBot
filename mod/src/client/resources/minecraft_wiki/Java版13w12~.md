# Java版13w12~

*页面ID: 33504* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w12~**是[Java版1.5.1](Java版1.5.1.md)的第2个，也是最后一个快照，发布于2013年3月19日<ref></ref>，修复了一个漏洞。

# 修复

# 重新上传
该版本在14:39（UTC）被重新上传以成功修复开启平滑光照会使帧数严重降低的漏洞<ref name="13w12 debug"></ref>，因为原始版本未能成功修复该漏洞。<ref></ref>

# 你知道吗
* 该版本在Mojira上作为临时快照被发布，这是该快照不遵循常规命名方式的原因。
