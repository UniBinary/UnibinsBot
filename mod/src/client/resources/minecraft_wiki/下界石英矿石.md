# 下界石英矿石

*页面ID: 9518* | *来源: Minecraft Wiki*

</ref>||Duncan Geere Mojavatar.png}}

* *下界石英矿石（Nether Quartz Ore）**是一种生成于[下界](下界.md)的[矿石](矿石.md)，是[下界石英](下界石英.md)的来源之一。

# 生成
# = 自然生成 =
下界石英矿石会以[矿团](矿团.md)的形式生成于[下界](下界.md)Y=10至117高度范围间的[下界岩](下界岩.md)之间，矿团大小为1-14个方块。矿团在[玄武岩三角洲](玄武岩三角洲.md)生物群系之外每[区块](区块.md)生成16次，在玄武岩三角洲每区块生成32次。

# 获取
下界石英矿石只能通过破坏下界石英矿石获得。

# 破坏
挖掘下界石英矿石的合适工具是镐。下界石英矿石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，下界石英矿石被破坏后会掉落1个[下界石英](下界石英.md)和，挖掘工具的[时运](时运.md)魔咒会增加下界石英的掉落，时运I有概率掉落2倍（概率），时运II有概率掉落2或3倍（各概率），时运III有概率掉落2、3或4倍（各概率）。

被具有[精准采集](精准采集.md)的工具挖掘破坏时，下界石英矿石被破坏后会掉落自身。

# 你知道吗
* 下界石英矿石原本计划在[MINECON 2013](MINECON 2013.md)上作为探索[下界](下界.md)的动力在下界生成。
* 下界石英矿石在下界大量生成，且会掉落较多的经验，这使得挖掘它成为在Minecraft中获取经验最快的方法之一。
* 下界石英矿石作为维度的一部分生成，而[下界岩](下界岩.md)是作为生物群系的一部分生成的。
* * 如果下界生物群系生成在主世界中，那么下界岩和下界石英矿石都不会生成，地形只会完全由石头组成，并有基岩组成的天花板。
* 在现实中，由于石英会产生[压电效应](wzh:压电效应.md)，金矿常伴生于石英矿。而Minecraft的下界中恰好同时出产这两种矿物。
