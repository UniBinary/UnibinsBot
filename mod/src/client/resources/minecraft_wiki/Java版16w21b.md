# Java版16w21b

*页面ID: 21548* | *来源: Minecraft Wiki*

<onlyinclude>

* *16w21b**是[Java版1.10](Java版1.10.md)的第3个，也是最后一个快照，发布于2016年5月26日<ref></ref>，加入了新的闪烁标语，并修复了一些[16w21a](16w21a.md)中的崩溃与漏洞。

# 新内容
# = 常规 =
* *[闪烁标语](闪烁标语.md)**
* “Rule #1: it's never my fault”
* “Replaced molten cheese with blood?”
* “Absolutely fixed relatively broken coordinates”
* “Boats FTW”

# 更改
# = 命令格式 =
* ***
* 相对坐标现在基于命令执行者，而非受传送实体。
* *  可以用作使用原算法的替代。
* 可以将玩家传送到Y坐标-4096至4096的位置（取代原先-512至512）。
