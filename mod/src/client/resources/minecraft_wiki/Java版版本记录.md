*页面ID: 34142* | *来源: Minecraft Wiki*

Minecraft自从2009年5月10或11日以来仍在持续开发中。

# 正式版
Minecraft的[正式版](Java版1.0.0.md)开发阶段从2011年11月18日开始并持续至今。在这个开发阶段，游戏可以说已经“完成”，有了“结尾”并已准备好被评测。游戏的价格与Beta相比也有所增加，但是已经购买了游戏的玩家无需付出额外费用。

# Beta

[Beta](Java版Beta.md)开发阶段从2010年12月20日开始并结束于2011年11月18日。此开发阶段的目标是优化游戏内容、添加特性并增强稳定性。<ref></ref>游戏的价格与Alpha相比也有所增长，但是已经购买了游戏的玩家无需付出额外费用。

# Alpha

[Alpha](Java版Alpha.md)开发阶段从2010年6月29日开始并结束于2010年12月20日。此版本将游戏模式锁定为生存，但相对地，多人游戏重新被加入游戏。此时，[Notch](Notch.md)开始全职开发游戏，由此更新而更加频繁。虽然在之后的开发阶段价格有所增长，但这也第一次含有需要购买的版本。

# Infdev

[Infdev](Java版Infdev.md)开发阶段始于2010年2月27日，终于2010年6月30日。在此阶段期间，游戏仅可游玩单人[生存模式](生存模式.md)，版本没有编号，其名称均为**[Minecraft Infdev](Minecraft Infdev.md)**。此时[Notch](Notch.md)重写了游戏代码以允许无限地形生成。

# Indev

[Indev](Java版Indev.md)开发阶段始于2009年12月23日，终于2010年2月27日。它继承了先前的[生存测试](生存测试.md)，并继续扩充游戏的生存模式特性，这使其与目前的游戏内容更为相似。此阶段的版本要么未被编号，要么使用相同的版本号。

# Classic

[Classic](Java版Classic.md)是Java版的第一个长期开发阶段。在2009年5月16日-12月23日这几个月的时间里，游戏得到不断更新。此阶段引入了游戏模式的概念：最初的游戏模式[创造模式](创造模式.md)得到了不断完善，[生存模式](生存模式.md)也于2009年9月1日起开始开发。

# pre-Classic

[Java版pre-Classic](Java版pre-Classic.md)是Java版第一个的开发阶段。该开发阶段在不到一周的时间里引入了游戏的基本机制。最初此阶段并没有被公开发布，但现在其中的一些版本可以通过[启动器](启动器.md)来游玩。
