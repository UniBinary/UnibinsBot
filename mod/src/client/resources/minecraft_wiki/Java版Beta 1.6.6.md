# Java版Beta 1.6.6

*页面ID: 32751* | *来源: Minecraft Wiki*

<onlyinclude>

* *Beta 1.6.6**是的一次次要更新，发布于2011年5月31日，修复了[Beta 1.6.5](Java版Beta 1.6.5.md)里的漏洞和崩溃。

# 新内容
# = 常规 =
* *[选项](选项.md)**
* 在视频设置中加入了性能选项，可以设置为最大FPS、平衡和节能。

# 更改
# = 方块 =
* *[荧石](荧石.md)**
* 材料类型变为“石头”，这意味着需要用镐开采才能掉落物品。同时也能放置[火把](火把.md)、[红石火把](红石火把.md)、[拉杆](拉杆.md)等方块。
* 现在被破坏后掉落[荧石粉](荧石粉.md)的数量增加到2-4。
* 改由2×2放置的荧石粉合成。

# = 物品 =
* *[骨粉](骨粉.md)**
* 现在能够使[草方块](草方块.md)上面的高草和花生长。

# = 非生物实体 =
* *[船](船.md)**
* 现在在水面浮起得更快。
* 落入水中的船现在会更快地失去垂直动量。

# 修复
* *修复了3个漏洞**
* 修复了床不能很好的在多人游戏中工作的问题。
* 现在破坏船不会把玩家生成在很低的地方了，这个问题会导致玩家有时会落入地里。
* 键点击将工具放入箱子时，不再会将它的耐久度恢复到初始值。</onlyinclude>
