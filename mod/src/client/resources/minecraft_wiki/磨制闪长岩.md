# 磨制闪长岩

*页面ID: 162969* | *来源: Minecraft Wiki*

* *磨制闪长岩（Polished Diorite）**是[闪长岩](闪长岩.md)制作的装饰性方块。

# 生成
# = 自然生成 =
磨制闪长岩会生成在[海底废墟](海底废墟.md)中。

# 破坏
挖掘磨制闪长岩的合适工具是镐。磨制闪长岩需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

磨制闪长岩被破坏后会掉落自身。
