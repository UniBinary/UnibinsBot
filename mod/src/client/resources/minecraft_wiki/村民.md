* *村民（Villager）**是一种生活在[村庄](村庄.md)中的友好生物，它们会依自己的职业而工作，能够繁殖、与[玩家](玩家.md)以[绿宝石](绿宝石.md)为货币[交易](交易.md)。它们的外观由其职业和村民本身所生成在的生物群系而定。

# 生成
# = 自然生成 =
村民会在[村庄](村庄.md)内（僵尸村庄除外）带有[床](床.md)的房屋里或[会合点](村庄#会合点.md)处生成，以此方式生成的村民为无业村民。而村庄可以生成在多种[生物群系](生物群系.md)当中，如[平原](平原.md)、[雪原](雪原.md)、[热带草原](热带草原.md)、[沙漠](沙漠.md)、[针叶林](针叶林.md)和[积雪针叶林](积雪针叶林.md)，在生成时可能部分建筑物会生成在其他不会主动生成村庄的[生物群系](生物群系.md)，如[沼泽](沼泽.md)和[丛林](丛林.md)。

[雪屋](雪屋.md)的地下室中也会自然生成村民。其中包含一个或。

# = 治愈 =

玩家可对拥有效果的僵尸村民[金苹果](金苹果.md)来治愈它。金苹果喂食成功时，僵尸村民会发出嘶嘶声并开始颤抖，同时它会获得I（简单、普通或）或II（困难）}}效果。治愈过程需要3-5分钟，在此阶段僵尸村民仍会有和[僵尸](僵尸.md)一样的行为。

初始的治愈时间为一个在3600与6000之间的随机整数，每[游戏刻](游戏刻.md)治愈时间都会减少1，且每刻有1%的概率在以此僵尸村民为中心的9×9×9的空间内搜索[铁栏杆](铁栏杆.md)和[床](床.md)（床的各半分别计算）。每搜索到一个，都有30%的概率使治愈时间额外减少1，最多搜索14个。故在放满14个的情况下可以使治疗速度提升4.2%。治疗时间减至0时，僵尸村民就会被治愈。治愈后，僵尸村民生成时自带的盔甲和手持物品会消失，捡起的盔甲和物品则会掉落。

治愈后的村民在与治愈它的玩家交易时，交易会有较高的永久折扣。多次治愈村民不会叠加折扣。被治愈的村民周围的其他村民也会提供较小幅度的少量折扣。中以该村民为中心33×33×33大小范围内的其他村民会根据被治愈村民的数量，提供成比例的折扣。被治愈且未交易过的村民也有可能变成傻子，这意味着该村民无法提供打折的交易。同时傻子僵尸村民也或被治愈为失业村民。被治愈的村民会产生与言论，其中无法传播。

治愈后的村民会获得10秒效果，但反胃效果不会影响其行为。

生成为鸡骑士的僵尸村民被治愈后仍会骑在鸡身上，无法控制鸡的行动，即使成年或变成女巫后也无法主动从鸡身上脱离。<ref></ref>

如果骑乘者是幼年[僵尸村民](僵尸村民.md)，将其治愈成幼年村民时会将它与鸡分离开来。

# 变种
# = 僵尸村民 =

僵尸村民是村民的僵尸化变种，在[主世界](主世界.md)中，僵尸有5%的概率作为僵尸村民生成，也会在[僵尸村庄](僵尸村庄.md)和[雪屋](雪屋.md)地下室生成。僵尸及其变种杀死村民时，有可能将其转换成僵尸村民。在简单、普通和困难难度下，转换概率分别为0%、50%和100%。

# = 灾厄村民 =
[thumb|一个正在追赶村民的[[卫道士](File:Vindication.png.md)]]
[thumb|right|一个正在攻击村民的[[幻术师](File:Wizard.png.md)]]

* *灾厄村民（Illager）**是一类形似村民的敌对生物的统称，包括[卫道士](卫道士.md)、[唤魔者](唤魔者.md)、[掠夺者](掠夺者.md)和，可生成在[林地府邸](林地府邸.md)、[掠夺者前哨站](掠夺者前哨站.md)、[灾厄巡逻队](灾厄巡逻队.md)以及[袭击](袭击.md)中。

灾厄村民会主动攻击成年村民、[流浪商人](流浪商人.md)、[铁傀儡](铁傀儡.md)和。幼年村民不会被主动攻击，但仍会试图逃跑。[“Johnny”卫道士](卫道士#“Johnny”卫道士.md)仍会攻击幼年村民。<ref></ref><ref></ref>

# = 女巫 =

女巫是一种形似村民的敌对生物，在[主世界](主世界.md)中[亮度](亮度.md)等级等于0的地方少量生成，也会在[沼泽小屋](沼泽小屋.md)和[袭击](袭击.md)中生成。在非和平[难度](难度.md)如果[闪电](闪电.md)劈中村民或其3-4格范围内的位置，村民会变成女巫，无论其是否成年。

女巫即使处于袭击之中也不会主动攻击村民，它们只在袭击中为[劫掠兽](劫掠兽.md)和灾厄村民提供支-{}-援。

# = 流浪商人 =

流浪商人是一种与村民类似的友好生物，会在玩家附近随机生成，并牵着两只一同生成的[行商羊驼](行商羊驼.md)。流浪商人拥有与村民相似的交易系统。

# 掉落物
杀死村民不会掉落任何[物品](物品.md)和[经验](经验.md)。

# 行为

# = 运动模式 =

若不在会合，2个村民可能会相遇，并互相注视4-5秒，以独特的语言交谈。

当玩家足够接近时，村民会一直注视玩家，除非这个村民正在试图收割农作物、工作、躲避僵尸与灾厄村民或者在夜间回到其认领的床。

即使村庄足够大，村民也往往不会远离它们的床，除非它们的工作站点或最近的会合点（[钟](钟.md)）离它们的床很远。

受到伤害时，村民会逃跑。在夜晚、下雨或钟被敲响时，村民会跑到其认领的床的附近，没有认领床的村民会跑到最近的床。

|睡觉的村民}}
在夜晚，有认领床的村民会返回自己的床并试图睡觉，若它们无法睡觉，则会待在屋内直至早晨。没有认领床的村民会不断寻找一个未被认领的床，直至早晨。对睡觉的村民按下键会使其起床。听到钟声的村民会立即起床。

村民可以在[下界](下界.md)和[末地](末地.md)睡觉，床不会因此爆炸。

村民会尝试与[僵尸](僵尸.md)及其变种、[僵尸疣猪兽](僵尸疣猪兽.md)、[卫道士](卫道士.md)、[掠夺者](掠夺者.md)、<ref></ref>和[恼鬼](恼鬼.md)保持至少8格距离，而对[唤魔者](唤魔者.md)和则是12格。

若村民发现它走到村庄边界以外，或村民检测到32个方块范围内有村庄，它会快速回到村庄界内。若村民离开村庄32格外，它会在后忘记该村庄。无论村民是否在村庄中，它们都不会被[清除](生成#清除.md)。

村民可以开关任何的木质门和铜门，并寻找门后使它们感兴趣的路径或方块。但是，它们无法打开[活板门](活板门.md)、[栅栏门](栅栏门.md)和[铁门](铁门.md)。村民可以攀爬[梯子](梯子.md)和[脚手架](脚手架.md)，但不会将梯子认作路径，并且不会刻意使用梯子。村民攀爬梯子的行为似乎是一种被其他生物尝试推入梯子附着的方块内的意外后果（常常是因为其他村民）。不幸的是，这个行为将会让它们滞留在二楼或是一些结构的屋顶上（例如平原村庄的教堂），因为它们缺乏从梯子下降的必要AI。

# == 首选路径 ==

村民在规划路径时会考虑路线中方块的“成本”，并选择成本尽可能低的移动路线。

就结果而言，村民会更倾向于在组成村庄中道路的方块上行走，并尽量避免跨越工作站点方块。同时，成年村民还会尝试减少跳跃的次数。

# = 工作站点与床 =

成年村民（傻子除外）会检测球面半径48个方块内的工作站点与床并尝试认领。无论这个工作站点或床是否为人为放置、是否可到达甚至是否可见，都可以被检测到，只要它在范围内并且未被认领，该村民就可以准备认领这个工作站点或床。

准备认领工作站点或床后，村民会尝试到达要认领的方块。如果准备认领的是床，并且村民认为自己能够到达床，就会绑定成功并发出绿色粒子效果；如果准备认领工作方块，村民会动身前往工作站点附近，其他村民将不能认领有村民正在准备认领的工作站点，成功到达选定的工作站点后，该村民会发出绿色粒子并成功绑定工作站点，然后根据所认领的工作站点更改自己的职业。除非所有者主动放弃，否则其他村民不可以再次认领同一个工作方块或床。

当村民长时间认为自己无法到达已绑定的工作站点或床时，村民会放弃绑定该工作站点或床。

当一个工作站点或床被破坏或毁坏时，其所有者（若有）会丢失对应方块的绑定。村民传送到其他维度后同样会丢失与工作站点或床的绑定。未与玩家交易过的村民丢失工作站点后会变为失业村民；与玩家交易过的村民丢失工作站点后不会失业，而是尝试认领其他未被认领的该职业工作站点。

睡觉中的村民失去职业时会从床上醒来。睡觉中的村民失去职业时会短暂从床上醒来，并重新入睡。

工作站点或床的高度必须和村民脚部高度相同或在其下方一格内才能被认领，换言之，悬空或是村民脚部无法碰触到的工作站点或床无法被认领。此外，村民和工作站点方块的寻路路径上若存在村民无法行走的方块（如[岩浆块](岩浆块.md)），可能会导致村民无法认领该工作站点或床。

村民起床会出现在起床位置正中间，不一定起床在碰撞箱上，而是起床位置的底部，甚至可能起床过后下落，如果村民睡觉的床在同高度被完全包围，村民会在床头起床。如果起床位（起床位是竖直方向2个方块大小）上面的方块不为空气方块，则无法起床。
特别地，村民起床会优先判定床下方周围的12格方块是否是有碰撞箱的方块（无论碰撞箱大小且不包含伤害方块），即使村民完全无法站立在该方块上，村民也会在方块上方起床。

村庄会以**言论（Gossip）**的形式储存对玩家的特定记忆。村民会在交谈时接收各种各样的言论，随后将其传播给其他村民。每条言论都有五种类型，并存储一个目标（<code>Target</code>）和强度值（）。

言论的类型一共有5种：。这些言论的一些基本特性如下表所示：

当任意一条成因被满足时，相关村民将会产生对应的言论，言论的目标就是使得该言论成因被满足的玩家。当村民在村庄中心的钟附近聚集时，将会相互分享彼此所拥有的言论。言论被其他村民接收时，这些村民收到的言论强度会与在传播者处的相比有所降低，降低程度因言论的类型而异。

当前强度不大于传播衰减的言论将无法被成功传播，因此，言论永远不会传播。

产生或接收一条与已经有言论的类型和目标都相同的言论时，新的言论将会和已有对应言论合并，强度相加，但不会超过最大值。

在游戏中，每过20分钟，现有的言论会以不同的降幅自然衰减一次，其中不会随时间自然减少。

玩家在每个村民处都有独立的**声望**。声望等于该村民持有的针对此玩家的各个言论的强度值乘以其对应的声望倍率后相加。

声望将会影响村民交易的价格，声望越高价格就越低，反之价格升高。价格降低的值为声望值乘以对应交易的价格乘数（）值，结果向下取整。常见的价格乘数为<code>0.2</code>或<code>0.05</code>，当声望为负值时，此值也变为负值，代表价格升高。

声望还会影响[铁傀儡](铁傀儡.md)是否攻击玩家。如果附近有村民对某个玩家的声望小于-100，则该村庄的铁傀儡会与此玩家敌对。

# = 拾取物品 =
村民拥有8个隐藏的[物品栏](物品栏#生物物品栏.md)，自然生成时是空的。

所有村民都可以捡起[面包](面包.md)、[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)、[小麦](小麦.md)、[小麦种子](小麦种子.md)、[甜菜根](甜菜根.md)、[甜菜种子](甜菜种子.md)、[火把花种子](火把花种子.md)和[瓶子草荚果](瓶子草荚果.md)，农民村民还可以捡起[骨粉](骨粉.md)，即使它们一开始在睡觉（此时它们会起床捡东西，然后接着睡觉）。

有职业的成年村民可以捡起[面包](面包.md)、[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)、[甜菜根](甜菜根.md)；失业的成年村民可以捡起[面包](面包.md)、[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)、[甜菜根](甜菜根.md)、[小麦](小麦.md)、[小麦种子](小麦种子.md)、[甜菜种子](甜菜种子.md)；农民村民可以捡起[面包](面包.md)、[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)、[甜菜根](甜菜根.md)、[小麦](小麦.md)、[小麦种子](小麦种子.md)、[甜菜种子](甜菜种子.md)、[火把花种子](火把花种子.md)、[瓶子草荚果](瓶子草荚果.md)、[骨粉](骨粉.md)；幼年村民不会捡起任何物品。

玩家可以通过或强制将其他物品放入村民的物品栏。如果玩家和村民同时在一个物品的拾取范围内，/总是会先捡起物品。玩家扔出的物品2秒后才能被村民捡起。村民会立即捡起玩家扔出的物品。

村民死亡后不会掉落物品栏中的物品。

如果村民变成僵尸村民或女巫，则它们的物品将一律丢失且不掉落，因为这些生物没有物品栏。

游戏规则设为时，村民将不能捡起物品。

可以用发射器给村民装备盔甲，虽然看不见盔甲模型（南瓜和生物的头除外），但是实际上有相应的效果。例如，装备具有[荆棘](荆棘.md)魔咒的盔甲的村民会对任何攻击它的生物造成荆棘伤害。

# = 分享食物 =
[thumb|right|Java版中一个村民正在将食物分享给另一个村民](File:Villager Sharing Bread JE.gif.md)
[thumb|right|基岩版中一个皮匠正在将面包分享给另一个村民](File:Villager Sharing Bread.gif.md)
如果村民的1个物品格有比较充足的食物，即至少6块[面包](面包.md)或24个[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)、[甜菜根](甜菜根.md)，或18个[小麦](小麦.md)（仅农民），并且看见有村民的物品格没有足够的食品（非农民：3块面包或12个胡萝卜、马铃薯或甜菜根；农民：15块面包、60个胡萝卜、马铃薯或甜菜根，或45个小麦）的话，它可能会决定把食物分享给那个村民。

如果要分享，村民会找到它第一个至少有4个面包，胡萝卜、马铃薯或甜菜根，或者至少6个小麦的物品格，然后向着目标村民的方向扔去一半数量的物品（向下舍入）。

村民会将想要分享的食物一次性地投给另一个村民；村民会将食物一组一组地投出。

# = 耕作 =
农民村民会照料村庄界限内里的农作物，距离任意村庄界限外足够远的村民也会照料它附近的农作物。

需要照料的耕地是通过寻找距离村民X和Z坐标方向最多15格，Y方向最多1格（总体积31×31×3）的特定方块。
* 如果一个农民村民找到已成熟的小麦、胡萝卜、马铃薯或甜菜，村民就会移动到这些作物并采集它们。
* 如果一个农民村民的物品栏里有小麦种子、胡萝卜、马铃薯、甜菜种子、火把花种子或瓶子草荚果，并且在耕地上方1格找到空气方块，它会移动到那片农田并种下作物。它们总会种下在物品栏中第一个可以种植的作物。
* 农民村民会捡起并使用[骨粉](骨粉.md)，还会用种子填满[堆肥桶](堆肥桶.md)。
* 如果游戏规则设为，那么村民将不能耕作。
* 农民村民不能将泥土、草方块、土径转化为耕地，也不能捡起任何锄来锄地。
* * 即使通过命令将锄放置在村民的主手或副手上，村民仍然不会锄地。
* 如果一个有职业的村民手中有骨粉，村民会尝试用这些骨粉催熟附近的作物。
农民村民如果有额外的作物和食物，会分享给其他的村民。

# = 繁殖 =
[thumb|两个相爱的村民](File:VillagerInLove.png.md)

成年村民会根据当天的时间进行繁殖，且需要有“意愿”（见下文）来生成幼年村民，需要[床](床.md)且上方至少有两个空的方块。村民繁殖不需要工作站点。在20分钟后，幼年村民将长大。

如果一个村民死于非生物、非玩家来源，而玩家在16格（球面半径）内，或者如果一个怪物杀死一个村民，那么村庄中的村民将停止繁殖大约3分钟。

繁殖取决于有效床的数量。如果村民有意愿，且人口少于有效床的数量（即在村庄范围内有无人认领的床），村民才会繁殖。所有的幼年村民最初都是没有职业的。只要在村庄范围内有无人认领的床，村民就会重新繁殖。

村庄会定期确定村庄内的当前人口。村庄水平边界内的所有村民都在村庄人口计算范围内，以确定是否允许继续进行村民繁殖。但是，只要边界内至少有一个村民，村庄水平边界内和村庄球形边界内的任何村民都将尝试进入繁殖模式。如果两个村民彼此靠近且都进入繁殖模式，它们就会繁殖并生成一个幼年村民。

如果有足够的食物让它自己和另一个村民“有意愿”，村民可能会进入繁殖模式（村民头上会出现红色的心型[粒子](粒子.md)）。它们会根据它们的食物数量进入繁殖模式，而不是人口上限（根据床的数量），但只有有多余的床让它们繁殖出的幼年村民认领才能繁殖出幼年村民。如果/，它们的繁殖就会被阻止，且它们头上会出现愤怒粒子（与红色心型粒子一起）。当两个村民处于繁殖模式并且能够看到对方时，它们会互相靠近并对视几秒钟，接着就会在它们的旁边生成一个幼年村民。繁殖村民不会掉落经验。幼年村民的穿着有50%概率取决于当前生物群系，25%概率跟随亲代之一，还有25%概率为平原村民穿着；其穿着由其所在村庄所属的生物群系决定。此村民成年后，如果它靠近有一个有效的、无人认领的工作站点方块，它就会获得与该工作站点方块对应职业。

# == 意愿 ==
村民必须有**意愿（Willing）**才能繁殖。村民会在繁殖后失去意愿，时长，需再次进入有意愿的状态才能进行下次繁殖；村民在繁殖后不会失去意愿，但每次繁殖成功必定消耗对应的食物量。

在村民[物品栏](物品栏#生物物品栏.md)的一个槽位中放入3个[面包](面包.md)、12个[胡萝卜](胡萝卜.md)、12个[马铃薯](马铃薯.md)或12个[甜菜根](甜菜根.md)，它们就会有意愿。任何有多余食物的村民（通常是农民）都会向其他村民扔食物，让它们捡起食物并获得足够的食物来变得有意愿。玩家还可以向村民扔面包、胡萝卜、甜菜根或马铃薯，以促进它们繁殖。村民在没有意愿的情况下会消耗所需的食物来变得有意愿。如果游戏规则设为，则村民将不会捡起食物。而食物不足的村民将不会产生繁殖的意愿。

# = 幼年村民 =
幼年村民会奔跑，并经常随意进出房子。它们没有职业。有时它们会停下来看着[铁傀儡](铁傀儡.md)。如果铁傀儡手里拿着[虞美人](虞美人.md)，幼年村民会小心地拿走它。幼年村民会聚在一起并相互追逐，也会在床上跳跃。

灾厄村民和[劫掠兽](劫掠兽.md)不会攻击幼年村民，直到它们成年。

幼年村民会将虞美人和小麦种子给予有效果的玩家。

不同于大部分[幼年生物](幼年生物.md)，中的幼年村民的外观只是成年村民的等比缩小，而的幼年村民的头部比Java版中的略大，但也小于成年村民。

幼年村民可以通过1×1方块的空间。

幼年村民在出生20分钟后就会变成成年村民。没有AI的幼年村民不会长大。

# = 惊慌状态 =

村民会在遇到[僵尸](僵尸.md)、[僵尸村民](僵尸村民.md)、[尸壳](尸壳.md)、[溺尸](溺尸.md)、[僵尸疣猪兽](僵尸疣猪兽.md)、[灾厄村民](灾厄村民.md)、[恼鬼](恼鬼.md)和[劫掠兽](劫掠兽.md)时进入**惊慌（Panicking）**状态并迅速逃跑，有时村民也会躲进房屋。村民观察到这些生物的前提是其视线和该生物之间不能有障碍物遮挡，且其直线距离（两足足底中点的距离）必须在一定范围内<ref name="gnembon-iron-farms" />：

村民在惊慌状态下会尝试。

# = 生成铁傀儡 =

村民可以生成[铁傀儡](铁傀儡.md)。

# == Java版 ==
村民生成铁傀儡的过程与其职业和上次工作的时间无关，如果村民在前内睡过觉且在前内没有观察到铁傀儡，则该村民产生生成铁傀儡的意愿。<ref name="gnembon-iron-farms"></ref>村民每过就会观察一次周围是否存在铁傀儡，存在铁傀儡的[边界箱](边界箱.md)与该村民边界箱各个方向膨胀16格形成的包围盒相交，就算观察到周围存在铁傀儡。

村民每内最多传播一次言论，若该村民有生成铁傀儡的意愿，且还存在另外4个边界箱与该村民边界箱各个方向膨胀10格的包围盒相交的有意愿的村民（合计5名村民为一组单位），在言论传播时铁傀儡就会尝试在以此村民脚部为中心的17×13×17的范围内生成。铁傀儡生成后，该村民及其周围10格内的所有其他村民会进入的冷却时间，在冷却时间内它们也会继续观察周围是否存在铁傀儡。

如果村民受伤或处在惊慌状态下，且在20分钟内有睡过一次觉，也会每尝试生成一次铁傀儡，这种情况下只需要3名有意愿的村民而非5名为一组单位。这种生成方式一样会受到16格范围内的铁傀儡侦测和冷却的限制。

# == 基岩版 ==
铁傀儡的生成具有以下条件：
* 村庄中至少存在20张床和10个村民。
* 每多10个村民，村庄可存在的铁傀儡上限加1，但不影响铁傀儡生成速度。
* 村庄中75%的村民必须在过去的一天里工作过。
* [村庄](村庄.md)内的所有村民都必须与[床](床.md)绑定，且村民的数量少于或等于床的数量。如果村民数量多于床，则铁傀儡不会生成。

满足条件后每[刻](刻.md)都有的概率尝试生成（平均每35秒1次），随后在村庄范围的中心的17×13×17范围内的最高可生成位置进行10次选点，选中可生成点后就会立刻生成一个铁傀儡。生成点上方2×3×2的空间上（即铁傀儡所在生成方块的西北角处水平居中点）需满足碰撞箱检测，当碰撞箱不足以生成铁傀儡时生成失败。铁傀儡生成点所在生成方块的上方一格必须全部为[真空气方块](生成#空气检测.md)（即空气、流体）才能生成。

村庄范围的中心由[兴趣点](基岩版存档格式/其他数据格式#兴趣点.md)方块（可以为[床](床.md)、[工作站点方块](工作站点方块.md)或[钟](钟.md)）确定。随着其他村民认领兴趣点方块或与之解除关系，村庄的边界与中心会相应发生变化。

# = 袭击 =

在袭击中，村民会逃离灾厄村民并跑向其认领的[床](床.md)，没有认领床的村民会跑向最近的床，类似于[僵尸围城](僵尸围城.md)。如果有条件，村民会进入有门的房子。

在第一波袭击之前，至少会有一个村民敲响村庄中心的钟（如果它们相距足够近的话）。钟会自行响起，以便提醒其他村民袭击来临。

村民会一直待在床的附近，。[玩家](玩家.md)仍然可以在[袭击](袭击.md)发生时与村民交易。

村民身上会随机出现水[粒子](粒子.md)，以表现流汗的效果。

当一场袭击以玩家和村民的胜利为结束时，村民每隔2-7秒会发射[烟花火箭](烟花火箭.md)来庆祝，持续30秒。与此同时玩家会获得状态效果，村民会降低交易价格。

村民也会向玩家赠送礼物。关于礼物的详细列表，请见。

# = 烟花火箭 =
村民发射的烟花火箭有1级飞行时间和1个[烟火之星](烟火之星.md)，爆裂时能造成至多伤害。

如果烟花火箭被挡在树下或屋檐下，这个烟花火箭就有可能炸伤地面上的生物。

由于烟花火箭有发射者信息，且其造成的伤害视为发射者造成的伤害，这有可能导致一些生物试图反击村民，如铁傀儡。

# = 工作 =
拥有职业的村民会将大部分时间都花在它们的工作站点方块旁边。它们会不时地游荡一段距离来“收集物品”，然后返回。

一些职业还有其他特定于工作的目标，这些目标是它们工作日程的一部分：
* 农民会收割和播种作物。
* * 农民有时候会在[堆肥桶](堆肥桶.md)使用多余的作物用于制造[骨粉](骨粉.md)，并且会在耕地上使用骨粉催熟作物。除此之外，农民还会将自身物品栏里的小麦制作成[面包](面包.md)。
* 图书管理员会检查[书架](书架.md)。
* 渔夫会站在村庄自然生成的码头上（若有）。

即使村民无法执行上列动作，它们仍能正常进行其他活动。

当一个村民到达其工作站点方块时，它将会“工作”，“工作”行为会自动恢复供应商品（解锁其锁定的交易，也称为补货），一天最多补给两次，即使没有床或坐在矿车内。如果工作站点方块位于它们脚部的高度水平围绕其8个直接相邻或对角的方块空间内，或者位于其正下方的9个方块内，即视为村民“到达”了其工作站点方块。村民仍然可以斜向地“到达”它，即使它实际上无法看到或触碰到方块的任意一个面。

# = 游荡 =
所有村民会不时游荡，但对于失业村民来说，游荡是它们的主要目标，因为它们希望找到工作站点方块，从而获得职业。一个游荡的村民会选择一个随机的方块向它走去，然后站在那里一段时间后再次游荡。如果在任何时候它检测到它可以认领的工作方块，那么它会将自己的皮肤更改成对应职业的皮肤，并立即开始遵循对应职业的适当的时间表。

拥有职业的村民会试图寻找一个与其职业对应的工作站点方块，并寻找一个通往它的路径，当无法到达时会显示愤怒粒子。若村民多次到达工作站点方块的尝试均失败，会显示愤怒粒子，并解除与该站点的绑定。如果村民未与玩家成功进行过交易并且附近没有其他可用的工作站点方块，那么它就会放弃该工作站点方块，最终失去工作。附近的任何其他的失业村民都有机会成为该工作站点方块的新拥有者。如果附近没有失业的村民，那么失去工作站点的村民会寻找另一个无人认领的工作站点，或者重新认领刚刚无法认领的工作站点从而进入一个无限循环（这同样也可以用于寻找床）。

游荡行程包含了一个特定于职业的目标，称为“探索外围”，这使得村民会到村庄边缘游荡。这可以让村民发现扩展村庄的新床、工作站点方块和钟。

# = 聚集 =
当游戏时间到达或时，成年村民会聚集在[钟](钟.md)的周围。当两个村民相遇时，它们会互动（看着对方，用独特的声音“交谈”）和分享食物，在双方有“意愿”的情况下[繁殖](繁殖.md)。聚集的村民会发出和玩家成功进行交易后同样的音效，作为互相交谈的方式。

如果村民的附近没有钟，它会随机游荡来寻找一个钟。

# = 玩耍 =
[缩略图|一群幼年村民正在互相追逐](File:ChildrenTag.png.md)
幼年村民会到处游荡寻找玩伴。当它找到一个玩伴时，它们会互相跟随一段时间，有时还会追逐对方。

幼年村民会随机寻找床，然后在床上跳跃。

# = 回家 =
除了傻子以外的大多数村民会在日落前不久回家，但傻子村民直到日落后才回家。村民们会四处游荡，直到走向它们床边的一个方块。一旦它们到达那个方块，它们在睡觉之前不会出门。

村民会检测以其脚所在的方块为基准32×8×32长方体范围内的床。没有床的村民会四处游荡，直到寻找到一张没有被占用的床为止。

# = 睡觉 =
[缩略图|正在睡觉的傻子村民](File:Villager sleeping.png.md)
日落时分，大多数村民会躺在[床](床.md)上，一直睡到次日早晨（傻子村民会熬夜和赖床）。如果村民被玩家按下键叫醒、被攻击、、床被破坏、玩家它们的床或附近有钟被敲响时，那么它们会提前起床。如果可能的话，它们会在被叫醒后回到床上继续睡觉。

没有床的村民会一直游荡以寻找空闲的床。

若村民成功入睡，它们会在黎明醒来时回满生命值。

# 职业

[缩略图|所有平原村民的职业（失业村民除外）和分别对应的工作站点方块](File:All Professions In 18w50a.png.md)
每个成年村民都可以拥有职业，其具体职业可以通过村民的衣着以及交易界面顶部的标题来判断。村民可以通过认领工作站点方块来选择它们的职业。当村民工作时，它们会到各自的工作站点方块附近，进行各自的日程安排。

未被占用工作站点方块可以被村民认领。如果村民之前没有与玩家进行交易，则破坏已被认领的工作站点方块会导致其所有者转换成其他职业或失业；如果村民先前有过交易，则其职业会得到保留，并认领与其职业相匹配的新工作站点方块（如果有机会）。

傻子和幼年村民不能改变职业。

使用[刷怪蛋](刷怪蛋.md)或无附加条件的命令生成的村民总是失业村民，直到它找到一个工作站点方块；而使用上述方法生成的村民拥有随机职业<ref></ref>，但仍可以通过工作站点方块改变职业。

新手级别且与玩家尚未交易成功的村民可能会失去职业并转变为失业的村民。

失业的成年村民会积极寻找无人认领的工作站点方块，并转变为相应的职业。

# = 傻子 =
[thumb|128px|摇头（拒绝交易）的傻子村民](File:Nitwit_refusing.gif.md)
</ref>|Jens Bergensten Mojang avatar.png}}

* *傻子（Nitwit）**，在基岩版中称为**不熟练的村民（Unskilled Villager）**，是一种穿着绿色的平原长袍的村民，它们无法工作、[交易](交易.md)，也不会在[钟](钟.md)周围会合，但它们仍可以繁殖。因为它们无法交易，所以它们不会有徽章。

对傻子村民会使其向玩家摇头，就像失业村民那样。

其他村民入睡后，傻子村民还要在村内游荡约2000个游戏刻才会去寻找床来入睡，而且拥有床的傻子村民比其他村民的起床时间要晚2000个游戏刻。

傻子以外职业的村民的职业不能变成傻子，同样傻子也不会变成其他职业。

只有自然生成的村民和僵尸村民会是傻子村民，而[治愈](僵尸村民#治愈.md)傻子幼年僵尸村民是生成傻子幼年村民的唯一方式。每个幼年村民有10%的概率会在长大后变成傻子村民。

傻子村民被感染成傻子僵尸村民后再治愈会变成失业村民。

# 外观
[缩略图|128px|未应用任何服装时的村民的外观，该外观不会出现在游戏内](File:Villager Base.png.md)
[缩略图|根据职业和[[生物群系](File:Villager Skins.png.md)区分的每种村民的皮肤]]

村民和[僵尸村民](僵尸村民.md)的皮肤是由多层服装构成的，这些服装包括生物群系服装、职业服装、徽章。村民的服装会逐层覆盖在村民的基础纹理上。

村民在生成时所处的生物群系决定了村民的生物群系服装，这包括在世界生成时生成，作为僵尸村民而在敌对生物生成过程中生成，以及村民繁殖而生成。尽管村庄不会生成在沼泽和丛林中，如果有村民或僵尸村民生成时处于这些生物群系，那么也会使用这些生物群系服装。村民在生成后，其生物群系服装永远不会改变。

* 沙漠着装：、及其变种
* 热带草原着装：及其变种
* 针叶林着装：、、及其变种
* 雪原着装：任何积雪的生物群系（包括、和）
* 沼泽着装：及其变种
* 丛林着装：及其变种
* 平原着装：和其他所有上面未列出的生物群系

根据村民的职业，村民还会获得职业服装，覆盖在生物群系服装的上层。失业村民没有职业服装。

# 交易

中村民的交易界面}}
[缩略图|中村民的交易界面](File:Bedrock Trading GUI.png.md)

交易为游戏内容之一，允许玩家用[绿宝石](绿宝石.md)与村民交换[物品](物品.md)等资源，反之亦然。

交易价格的涨落会随多个因素而变化。高价格乘数（0.2）的物品会比低价格乘数（0.05）的物品受影响程度更大。价格变化只影响交易中的第一个物品（玩家提供的物品）。例如，对于32个木棍换1个绿宝石的原始交易，价格可能变化为1-64个木棍换1个绿宝石，但不会变为2个绿宝石。另外，所有物品的数量也不会小于1或大于最大堆叠数。

第一个因素是玩家购买需求。玩家将商品买空的交易在补货后价格将会上涨；而对于涨价后没有被交易的物品则会在下次补货时降价。需求量信息是按物品进行存储的，而不是按村民进行存储，因此单个村民提供的交易中会出现价格贵贱兼有的情况。

第二个因素是效果，村民会根据效果等级对玩家给予交易折扣。

第三个因素是玩家对该村民的声誉值，玩家进行[交易](交易.md)、[治愈](#治愈.md)、攻击或杀死村民时，会使附近的村民产生各种各样的言论，并最终影响玩家在各个村民处的声誉。基于玩家的声誉，村民可能会在交易中降价或涨价。

# 你知道吗
* 与其他大多数和村民相似的生物不同，村民骑乘其他实体（如[矿车](矿车.md)和[船](船.md)）时不会显示坐下的动作，这是开发者有意为之的<ref></ref>。女巫和流浪商人也是如此。
* 村民的灵感来源于《[迷宫魔兽2](wzh:迷宫魔兽.md)》中的店主。<ref>https://www.reddit.com/r/Minecraft/comments/xfzdg/i_am_markus_persson_aka_notch_creator_of/c5m0p26</ref>
* 用[命名牌](命名牌.md)给村民命名后，交易界面的标题会变为村民的名称。
* 村民进入交配模式时走得很慢。然而夜晚降临或袭击开始时，它仍然会快速地跑进屋子里。
* 与玩家不同，村民可以在参数为的维度（原版中为下界和末地）使用[床](床.md)睡觉而不引发爆炸，因此在这类维度建立村庄是可行的。
* * 基于上述特性，玩家在这类维度中可以通过村民是否睡觉来了解主世界的日夜循环情况。
* [村庄与掠夺](村庄与掠夺.md)更新的新村民服饰受到2018年时装秀的启发，比如[Gucci](wzh:古馳.md)。<ref></ref>
* 村民偶尔会在夜间以奇怪的方式睡在床上，有时会挂在床的半边，甚至卡在墙里。
* * 即使村民在睡觉，也能通过“平移”的方式捡起附近的食物并回到床上。此时更容易触发上述的奇怪睡姿。
* 尽管[积雪针叶林](积雪针叶林.md)村庄生成的是积雪群系变种的村民，但村庄建筑本身的类型却与普通针叶林村庄相同。
* 启用“Programmer Art”资源包后，所有村民都会戴上绿色的兜帽。<ref></ref>
* * 这是因为该资源包中的傻子村民纹理与[村庄与掠夺](村庄与掠夺.md)更新以来村民底层纹理的文件路径及名称（）完全一致。
* * 村庄与掠夺前的傻子村民纹理原本即包含兜帽，但在之前的版本不会被渲染。
* 启用来自[市场](市场.md)的经典纹理包后，村民的纹理并不会变回[纹理更新](纹理更新.md)前的版本。<ref></ref>
* * 这是因为旧版村民纹理文件位于目录，而新版则位于目录内。
* 使用命令将物品放置在村民手上的显示效果和其正常交易展示的效果相同，但是并不会让村民出售该物品。
* 渔夫村民的服饰上有着[水域更新](水域更新.md)前的青色生鱼纹理，这是纹理绘制者[Jasper Boerstra](Jasper Boerstra.md)有意保留的。<ref></ref>
* 大师级屠夫村民收购[甜浆果](甜浆果.md)的交易选项可能参考自瑞典人吃肉食佐以浆果果酱的饮食习惯。
* 虽然村民有屠夫和渔夫职业，但根据繁殖用的食物（[面包](面包.md)、[胡萝卜](胡萝卜.md)、[马铃薯](马铃薯.md)、[甜菜根](甜菜根.md)）来看，村民可能是素食主义者，肉类食物可能只是为了与玩家交易之用。
* * 这个设计可能不是偶然，在《[ Ask Mojang #1]》采访影片中提到，Mojang团队中有不少的纯素主义成员。
* * 在*[A Minecraft Movie](A Minecraft Movie.md)*中，史蒂夫的台词也提到了这一点。
* 村民喜欢[猫](猫.md)。如果有猫出现在村民附近，村民会低头看着这只猫，有时候会尝试跟随它。
* 村民只会主动看着玩家、猫或其他村民，而不会看向其他任何生物（包括铁傀儡）。
* 村民的逃跑[属性](属性.md)各有不同，它们逃跑的速度为2.16格/秒。村民的逃跑速度是的0.6倍，使得村民很容易被卫道士追杀（袭击中除外）。村民的逃跑速度则比卫道士快0.65格/秒。
* 自然生成的有职业僵尸村民被治愈后会变成无业村民，这可能是游戏预设其交易内容没有绑定的缘故。
* 生成为鸡骑士的幼年僵尸村民被治愈后仍会骑在鸡身上，即使幼年村民成年，甚至转变成[女巫](女巫.md)也不会主动从鸡身上脱离；<ref></ref>幼年僵尸村民被治愈后就会从鸡身上脱离。
* 即使在船上，认领了床的村民（包括幼年村民）在靠近床时仍然可以睡觉。
* 在Minecraft官方账号的幼年生物新外观宣传视频中，幼年村民出现了模型错误。<ref></ref>

# = 愚人节玩笑 =

2014年4月1日，Mojang以一个愚人节玩笑宣布村民已经全面接管玩家皮肤网络内容交互系统（CDN）：

玩家的皮肤变成了各种职业的村民（包括傻子村民）皮肤，并且不能改变，除非玩家修改[启动器](启动器.md)的json文件。游戏标题被改为“Game of Thrones”（权力的游戏）。

大多数音效都变成了类似村民交谈的声音（带有单词，而不是它们普通交谈的哼哼声），游戏背景音乐也被改为村民吵闹的声音。原始音效资源包由Element Animation创建，全称为The Element Animation Villager Sound Resource Pack（T.E.A.V.S.R.P），新音效是基于他们粉丝的视频而制作的。村民音效由Dan Lloyd、Element Animation录制。

皮肤和音效于2014年4月2日恢复。之后即使自行将计算机的日期设置为2014年4月1日，也无法激活此愚人节玩笑。
