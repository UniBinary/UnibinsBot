# 杜鹃花丛

*页面ID: 77735* | *来源: Minecraft Wiki*

* *杜鹃花丛（Azalea）**是一种生成于[繁茂洞穴](繁茂洞穴.md)且能在[骨粉](骨粉.md)的作用下生长为[杜鹃树](杜鹃树.md)的植物方块。

# 生成
# = 自然生成 =
杜鹃花丛会自然生成于[繁茂洞穴](繁茂洞穴.md)中。

# = 骨粉 =
若一个上方为空气的[苔藓块](苔藓块.md)周围的方块是[草方块](草方块.md)、[砂土](砂土.md)、[灰化土](灰化土.md)、[泥土](泥土.md)、[沙子](沙子.md)、[沙砾](沙砾.md)、[石头](石头.md)、[花岗岩](花岗岩.md)、[闪长岩](闪长岩.md)、[安山岩](安山岩.md)、[黏土](黏土.md)、[深板岩](深板岩.md)、[苍白苔藓块](苍白苔藓块.md)或其他苔藓块，且这些方块上方为空气，对着该苔藓块骨粉有概率使其7×11×7格的范围内出现一些杜鹃花丛。

# 获取
# = 杜鹃树叶 =
当[杜鹃树叶](杜鹃树叶.md)被破坏或枯萎时，有5%的概率掉落杜鹃花丛。使用具有[时运](时运.md)I、II、III魔咒的工具破坏时掉落的概率分别为6.25%、8.33%和10%。

# 破坏
杜鹃花丛被挖掘时会立刻被破坏。

杜鹃花丛被破坏后会掉落其自身。

# 用途
杜鹃花丛只能放置在草方块、[菌丝体](菌丝体.md)、灰化土、泥土、[缠根泥土](缠根泥土.md)、砂土、[耕地](耕地.md)、[泥巴](泥巴.md)、[沾泥的红树根](沾泥的红树根.md)、苔藓块、苍白苔藓块、黏土上或[花盆](花盆.md)里。

若活塞头推入其位置或[活塞](活塞.md)将方块推入其位置，杜鹃花丛会被破坏并掉落。

杜鹃花丛可[含水](含水.md)。<ref></ref>

[液体](液体.md)在水平流动时能破坏路径上的杜鹃花丛，但在竖直流动时无法破坏路径上的杜鹃花丛。

# = 种植杜鹃树 =
与[树苗](树苗.md)不同，杜鹃花丛不会自然生长为杜鹃树。

对上方存在至少3×5×3的空间的杜鹃花丛骨粉可以使其生长为杜鹃树，并将其下方1格的方块转变为[缠根泥土](缠根泥土.md)。

# = 堆肥 =
将杜鹃花丛放进[堆肥桶](堆肥桶.md)有65%的概率使堆肥层数加1。

# = 燃料 =
杜鹃花丛可用作[熔炉](熔炉.md)、[高炉](高炉.md)或[烟熏炉](烟熏炉.md)的[燃料](燃料.md)，每个杜鹃花丛可烧炼0.5个物品。
