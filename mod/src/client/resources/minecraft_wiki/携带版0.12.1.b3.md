# 携带版0.12.1.b3

*页面ID: 27846* | *来源: Minecraft Wiki*

<onlyinclude>

* *v0.12.1 alpha build 3**是[v0.12.1 alpha](携带版0.12.1.md)的第3个测试版，发布于2015年7月31日，修复了一些漏洞。

# 更改
* 在物品的介绍中添加更多有关于[药水](药水.md)和[附魔](附魔.md)的信息。
* 添加视场选项（30°至110°）。
* 添加了[金苹果](金苹果.md)的合成配方。
* 减少了[烧炼](烧炼.md)获得的经验值。
* 工具栏会利用全部空位。
* [雪傀儡](雪傀儡.md)的[南瓜](南瓜.md)现在能通过使用[剪刀](剪刀.md)来移除。

# 修复

; 其他
   多人模式下铁砧机制不同步。
   删除世界后，世界不会从列表中消失。
   在下界死亡时，不会在主世界里正常重生。
   触摸板覆盖在快捷栏上方。
   矿车不能传送到下界。
   客户端岩浆怪的音效丢失。
   手持物品的动画不可见。
   创造模式下不可以打开熔炉和附魔台。</onlyinclude>
