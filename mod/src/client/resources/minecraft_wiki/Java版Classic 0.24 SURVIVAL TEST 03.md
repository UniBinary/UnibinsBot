# Java版Classic 0.24 SURVIVAL TEST 03

*页面ID: 35583* | *来源: Minecraft Wiki*

<onlyinclude>

* *0.24_SURVIVAL_TEST_03**是的一次更新，发布于2009年9月1日<ref>[IRC记录](#logs.md): "*P1:22:12 <Marach> now it is _03 version!*" (18:22 UTC)</ref>，修复了一些漏洞。

# 修复
* *修复了3个漏洞**
* 修复了当苦力怕炸毁液体时，液体会掉落自己的漏洞。
* 修复了一个允许玩家将方块复制到快捷栏中的漏洞。
* 修复了大多数0.24 SURVIVAL TEST中的其他漏洞。</onlyinclude>
