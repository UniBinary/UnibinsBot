# Java版1.9.3-pre3

*页面ID: 21139* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.9.3-pre3**是[Java版1.9.3](Java版1.9.3.md)的第3个，也是最后一个预发布版，发布于2016年5月3日<ref name="blogpost_1.9.3-pre3"></ref>。

# 更改
# = 常规 =
* *[服务器](服务器.md)**
* 移除在[1.9.3-pre2](1.9.3-pre2.md)中加入的查询[https://sessionserver.mojang.com/blockedservers](https://sessionserver.mojang.com/blockedservers)<ref>[ "The Mojang EULA /blockedservers check was removed in this release."] — /u/openfiber，2016年4月3日</ref>黑名单行为。

# 修复

* *其他修复**
* 修复了一个潜在的流动的水或熔岩的崩溃漏洞。<ref name="blogpost_1.9.3-pre3" /></onlyinclude>
