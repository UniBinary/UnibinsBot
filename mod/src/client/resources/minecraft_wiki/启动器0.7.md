# 启动器0.7

*页面ID: 49105* | *来源: Minecraft Wiki*

* *0.7**是在2013年5月2日和2013年5月13日（2013年5月13日为降级版本）发布的一个[启动器](启动器.md)版本。

# 修复
*  - 启动器页面中只显示了新闻消息。
*  - 启动动画会马上消失，游戏无法启动。
*  - 启动器页面下方有残留的。
*  - 启动器无法启动1.5.1和1.5.2。
*  - 启动器无法在Linux上运行。
*  - 无法退出登录或切换账户。
*  - 无法下载/启动快照。
*  - 启动器在启动时无法处于屏幕中央。
*  - 在带视网膜显示器的Mac OS X上运行启动器会导致其被像素化。
*  - 按键会报错。
*  - 窗口尺寸过小，使得按键无法显示。
*  - 在下载文件/启动游戏后启动器窗口会自动关闭。
*  - 原生模块在被其他进程占用时无法拆解。
*  - 启动器无法适配自定义的Windows 7主题。
*  - 关闭启动器后对应进程仍然在运行。
*  - Windows 7/XP经典主题会覆盖登录界面的按钮文字。
*  - Linux上的NVIDIA Optimus技术无法兼容启动器中的下载方式。
*  - 无法下载快照，只会显示等待下载的提示。
*  - Linux版本无法运行快照。
*  - 资源文件夹中的垃圾文件导致游戏崩溃。
*  - 任务栏中的图标使用了LWJGL的默认图标。
*  - .minecraft文件夹不存在时，控制台中会输出调试内容。
*  - 含有带分音符的字母的密码无法使用。
