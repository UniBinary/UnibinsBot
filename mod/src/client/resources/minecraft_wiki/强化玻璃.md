# 强化玻璃

*页面ID: 34661* | *来源: Minecraft Wiki*

* *强化玻璃（Hardened Glass）**是一种在[化学](化学.md)成分上增强的[玻璃](玻璃.md)。

# 生成
强化玻璃不会生成在世界中。

# 破坏
没有工具可以加速对强化玻璃的挖掘。

强化玻璃被破坏后会掉落自身。

# 用途
当透过强化玻璃看时，与该强化玻璃相邻的其他强化玻璃不可见，但在普通玻璃上能看见。
