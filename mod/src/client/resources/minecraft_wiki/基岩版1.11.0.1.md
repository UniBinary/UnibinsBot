# 基岩版1.11.0.1

*页面ID: 40281* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.11.0.1**是[1.11.0](基岩版1.11.0.md)的首个测试版本，发布于2019年2月21日，加入了[袭击](袭击.md)机制和新的村民[交易](交易.md)系统，并且修复了一些漏洞。<ref></ref>

# 新内容
# =命令=
* ***
* 用于更新村民的经济交易供给。

# = 方块 =
* *[灾厄旗帜](灾厄旗帜.md)**
* 一种独特的旗帜。
* 生成于掠夺者前哨站，可由[灾厄村民](灾厄村民.md)队长掉落。
* 也能在创造模式物品栏中找到。

# = 生物 =
* *[灾厄队长](灾厄队长.md)**
* 在掠夺者前哨周围的[灾厄巡逻队](灾厄巡逻队.md)和袭击者中生成。
* [灾厄村民](灾厄村民.md)队长是头上戴着特殊旗帜的[掠夺者](掠夺者.md)、[卫道士](卫道士.md)或者[唤魔者](唤魔者.md)。
* 杀死时给玩家一个的负面效果。
* 可通过开启[实验性玩法](实验性玩法.md)获得。

# = 游戏内容 =
* *[袭击](袭击.md)**
* 当具有的玩家进入村庄时触发。
* 一大群[灾厄村民](灾厄村民.md)会袭击[村庄](村庄.md)并杀死[村民](村民.md)。
* 袭击者以每波的形式出现——每当等级的增加，袭击者数量和波的长度都会增加。
* “袭击”Boss栏将会显示剩余敌人数量。
* 在每次[袭击](袭击.md)之前，战斗号角和其他任何声音都会消失。
* 可通过开启[实验性玩法](实验性玩法.md)获得。

* *[灾厄巡逻队](灾厄巡逻队.md)**
* 在世界上生成一组5个随机的[灾厄村民](灾厄村民.md)，通常在村庄附近生成。
* 其中一个灾厄村民将成为[灾厄村民](灾厄村民.md)队长。

* *[状态效果](状态效果.md)**
* 加入了和的状态效果。
* 两者都可通过开启[实验性玩法](实验性玩法.md)获得。

* *[音效](音效.md)**
* 为[钟](钟.md)、[劫掠兽](劫掠兽.md)、[甜浆果丛](甜浆果丛.md)、[营火](营火.md)、 [袭击](袭击.md)、[砂轮](砂轮.md)和[灯笼](灯笼.md)加入了音效。

* *[村民](村民.md)**
* 更改了村民交易UI界面。
* 加入了村庄新经济供需体系（仍在开发中）。
* * 只有当村民有机会在自己的工作站点工作时才能恢复供应。
* ** 此功能尚未完成，但可以通过命令使村民恢复供应。
* * 当村民的交易完全恢复时，需要用尽所有的供应（交易数量），并将其转换为称为需求的价格上涨。需求量增加，供空应量增加，而未使用的供空应量将减少。
* * 村民完成交易后会获得经验，获得足够的经验后会升级并解锁新的交易。
* ** 目前升级一次只会解锁一个交易。

# 更改
# = 方块 =
* *[木桶](木桶.md)、[堆肥桶](堆肥桶.md)、[切石机](切石机.md)、[钟](钟.md)、[烟熏炉](烟熏炉.md)和[高炉](高炉.md)**
* 加入了功能。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[砂轮](砂轮.md)和[制图台](制图台.md)**
* 加入了功能。
* 现在可以用多种类型的木板合成。
* 不再属于[实验性玩法](实验性玩法.md)。

* *[营火](营火.md)**
* 更改了模型和纹理。
* 加入了烟雾粒子、音效和熄灭效果。
* 加入了食物烹饪功能。

* *[讲台](讲台.md)**
* 当书翻页时会发出红石信号。

# = 生物 =
* *[](灾厄之兽.md)**
* 更名为劫掠兽（Ravager）。
* 加入了攻击、咆哮反击动作和音效。
* 现在会在玩家用[盾牌](盾牌.md)格挡时眩晕。
* 现在可以被[卫道士](卫道士.md)和[掠夺者](掠夺者.md)骑乘。
* 现在能破坏[农作物](农作物.md)和[树叶](树叶.md)，并且会避开[仙人掌](仙人掌.md)和[甜浆果丛](甜浆果丛.md)。

* *[卫道士](卫道士.md)**
* 现在可以破坏[木门](木门.md)了。

* *[村民](村民.md)**
* 现存世界里的旧村民将被转换为新村民。
* 当村民睡觉时不再会被困在墙里或传送穿过墙。
* 对村民进行了一些调整和修复：
* * 农民会选择[堆肥桶](堆肥桶.md)作为工作站点，而不是[耕地](耕地.md)。
* * 农民和图书管理员正确地工作。
* * 在工作计划更改后正确清理工作目标。
* * 增加冷却时间、最长活动时间和更好范围的工作目标。

* *[铁傀儡](铁傀儡.md)**
* 铁傀儡现在正确生成在掠夺者前哨站的笼子里。
* 村庄现在总是生成一个铁傀儡。

# = 世界生成 =
* *[生物群系](生物群系.md)**
* [竹林](竹林.md)不再属于[实验性玩法](实验性玩法.md)。

* *[掠夺者前哨站](掠夺者前哨站.md)**
* [淡灰色旗帜](淡灰色旗帜.md)现在会出现在掠夺者前哨站，代替了原来的黑色旗帜。
* 掠夺者前哨站的笼子里现在总会生成一只[铁傀儡](铁傀儡.md)。
* 掠夺者前哨站现在变得更罕见。
* 掠夺者前哨站不会再陷到地下了。

* *[村庄](村庄.md)**
* 现在所有村庄的宝箱里都会有战利品。

# = 常规 =
* *给地图与附加包制作者的更新**
* 加入可改变的熔炉合成配方。
* * 可以使用JSON将定制熔炉配方加入到游戏中。
* * 熔炉合成配方为每个文件1个，就像所有其他配方一样。
* * 为熔炉配方加入了标签，并使用UI让它们来过滤配方。
* 合成配方现在有标签，因此可以通过创建类型进行过滤。
* 如果包中没有指定，拴绳位置现在使用原始位置。
* 在市场内容中更改幼年僵尸猪人持剑的错误。
* 声音事件现在显示在脚本文件中。
* 资源包中重命名的方块现在会保留其自定义名称。

* *[粒子](粒子.md)**
* 移除了所有带有前缀<code>example_</code>的粒子。

# 修复
* *修复了75个漏洞**<br>
* *崩溃**
* 修复了游戏进行时的崩溃现象。
* 开启纹理抗锯齿时游戏崩溃。
* 村民的交易价格太昂贵导致游戏崩溃。
* 使用“奢华生活”市场资源包生成村民时游戏崩溃。
* 生成新版村民时游戏崩溃。
* 与流浪商人交易时游戏崩溃。
* 将世界替换为未同步的世界时游戏崩溃。
* 渲染生物的几何模型时游戏崩溃。
* 使用自定义交易选项时与村民互动使得游戏崩溃。

* *常规**
* 已选的全局资源包在重启游戏后被卸载。
* 盾牌在快捷栏内的图标现在只会在掉耐久度时闪烁。
* 浮漂的位置和动作不正确。（）
* 将藏宝图放在副手槽时，“宝藏猎人”成就不会解锁。（）
* 在部分设备里，全局资源包重置的信息现在会在加载界面停留过长时显示。
* 下载市场捆绑包时，“空间不足”的信息不再意外出现。
* 自定义名称后的空地图在绘制后不会保留其名称。

* *游戏内容**
* 分屏模式下的玩家在水下拥有无限远的视野。（）
* 放置在虚空里的脚手架现在可以支撑玩家。（）
* 食用紫颂果后，现在会正确播放传送音效。
* 农民村民在接收玩家的物品后，会合成无限多的面包。（）
* 告示牌不能作为熔炉的燃料使用。
* 现在可以使用跳跃键来攀爬藤蔓或梯子。
* 闪电可以穿过方块来劈中地下的实体。
* 创造模式下的玩家使用铁桶装液体时不再获得额外的液体桶。
* 使用铁砧重命名物品不再使得累积惩罚增加。（）
* 甜浆果丛不再一次给予无限多数量的甜浆果。（）

* *世界生成**
* 废弃矿井不再重叠生成，并且生成方式与Java版相匹配。（）
* 恶地高原生物群系的生成方式现在与Java版相匹配。

* *生物**
* 熊猫的动画播放速度太慢。（）
* 使用附有抢夺的剑杀死潜影贝时，现在会给予正确数量的潜影壳。（）
* 恼鬼不再攻击幼年村民。
* 重命名后的卫道士变为被动生物。（）
* 玩家手持特定物品时，幼年村民变得可以交易。
* 守卫者可以离开水而生成。（）
* 减少了村民的闲逛时间。
* 草、钟和活板门的放置位置判定不正确。
* 村庄的中心集合点可以生成在海平面以下。
* 减少了沙子的悬空生成现象。
* 村庄可以埋在地下生成。
* 平衡了村庄里的工作站点方块生成数量。
* 村庄里不再生成流水。
* 村庄铁匠铺里的熔岩不再导致房子被点燃。
* 村庄里现在可以生成动物。
* 带釉陶瓦的放置朝向判定不正确。
* 海泡菜的生成数量不正确。
* 钟和农作物方块出现问题。
* 雪层生成时出现问题。
* 沙漠村庄会生成在峡谷里。
* 贪玩的熊猫在生成时不再翻滚进导致危险的方块里。
* 北极熊的攻击动画不正确。
* 修复了船上的北极熊位置不正确的问题。（）
* 凋灵护甲的渲染不正确。
* 苦力怕在即将爆炸前现在会闪烁白色。（）
* 北极熊的模型太小。
* 雪傀儡穿过点燃的营火时不会受伤。
* 苦力怕现在可以生成在1.8格高的空隙里。（）
* 农民村民和图书管理员村民不再游手好闲。
* 更改日程安排时，村民的工作目标不会重置。
* 村民的工作目标现在有了冷却和最大响应时间，以及更合理的范围判定。
* 村民在被叫醒时，会传送到离床太远的地方。

* *方块**
* 砂轮不再能支持脚手架。
* 草皮现在能传播到泥土上，而不是砂土。（）

* *物品**
* 重命名的烟火之星和烟花火箭现在会显示其新名称。
* 皮革盔甲现在能正确染色。（）
* 手持旗帜时，不再显示为墙上变种。（）
* 副手槽上的盔甲不再看起来是倒置的。（）

* *图形**
* 盔甲匠村民和牧师村民的外观不正确。
* 盔甲匠手臂的纹理不正确。
* 树叶的着色不正确。

* *用户界面**
* 使用触摸屏时，现在能将合成原料均匀放置在合成网格里。
* 使用切石机后会播放正确的音效。

* *命令**
* 使用命令给予的炼药锅不再互相独立放进玩家的物品栏里。

* *附加包和脚本引擎**
* 组的第二次激活现在会正确移除组件群。
* 目标选择器出现问题。
* 记分板的记分项在退出世界时不再提前保存。</onlyinclude>
