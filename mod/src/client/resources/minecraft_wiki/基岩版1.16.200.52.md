# 基岩版1.16.200.52

*页面ID: 71551* | *来源: Minecraft Wiki*

<onlyinclude>
* *beta 1.16.200.52**是[基岩版1.16.200](基岩版1.16.200.md)的第2个测试版，发布于2020年10月28日<ref></ref>，加入了首批[洞穴与山崖](洞穴与山崖.md)的特性，并修复了一些漏洞。

# 新内容
# = 方块 =
* *[细雪](细雪.md)**
* 目前仅能从创造模式物品栏中获取。
* 实体可以进入细雪。
* * 在内部时实体移动速度降低，掉落伤害会被忽略。
* * 细雪可以攀爬，类似于[梯子](梯子.md)和[脚手架](脚手架.md)，且向下移动时不能加速。
* 纹理和常规的雪块略有不同。
* 玩家可在方块内部攻击生物。
* 当玩家进入方块内部时，会在其周围渲染霜花并在其上渲染纹理叠层。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# = 物品 =
* *[山羊角](山羊角.md)**
* 当山羊冲撞到方块上时掉落。
* 一段时间后会发出[袭击](袭击.md)中的号角声。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

* *[刷怪蛋](刷怪蛋.md)**
* 加入了山羊刷怪蛋。
* * 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# = 生物 =
* *[山羊](山羊.md)**
* 生成在[山地](风袭丘陵.md)、[繁茂的山地](繁茂的山地.md)、[沙砾山地](沙砾山地.md)、[沙砾山地+](沙砾山地+.md)和[山地边缘](山地边缘.md)生物群系。
* 受到的掉落伤害会减少。
* 好斗，有时会冲撞其他生物和玩家。
* * 目标最远可以在16格外，但冲撞过程只有9格。山羊会尝试接近距离太远的目标。
* * 两次冲撞之间有10-15秒的冷却间隔。
* * 不会冲撞其他山羊和[潜影贝](潜影贝.md)。
* 撞上树木时会掉落山羊角。
* 类似于疣猪兽，小山羊也会攻击玩家，但它们攻击后会远离玩家（包括成年山羊）。
* 可以用[小麦](小麦.md)来喂养和繁殖。
* * 会繁殖出3-8只幼年山羊。
* 有生命值。
* 死亡时不会掉落任何物品，但成年山羊会掉落经验值。
* 可以用[铁桶](铁桶.md)挤奶，类似于[牛](牛.md)。
* 可以用[拴绳](拴绳.md)拴住。
* 目前属于[实验性玩法](实验性玩法.md)（子选项）。

# 更改
# = 方块 =
* *[草径](草径.md)**
* 重命名为土径。
* 现在当[泥土](泥土.md)、[砂土](砂土.md)、[菌丝体](菌丝体.md)或[灰化土](灰化土.md)的上方没有方块时，对其顶部或侧面锹也能将其变为土径了。

# = 物品 =
* *[下界合金护腿](下界合金护腿.md)**
* 更改了穿着时的护腿模型纹理。

# = 常规 =
* *脚本、附加包和技术性内容**
* 更改了指定时的和，现在使用。
* 带有物品锁组件的物品不再导致配方书显示无效的配方结果。

* *方块**
* 加入了来获取水平方向而不会返回上或下的值。
* 在models/blocks文件夹里加入了放置方块模型的能力。
* 加入了物品触发器给互动的方块发送事件的能力（例如）。
* 加入了查询方块和使用了的物品的互动面<!-- interacted face -->的能力。可通过查询。

* *事件响应**
* 和使用有效的效果名称时，不再抛出内容错误
* 的文档说明，使得创作者明白他们能使用有效值“all”来移除目标内所有实体的状态效果。

# 修复
* *性能和稳定性**
* 修复了一些游戏过程中可能发生的崩溃。
* 现在当大量方块更新事件产生时游戏不再崩溃了。（）
* 修复了使用传送门或飞行时偶尔造成的崩溃。
* 修复了在游戏世界中移动或者飞行时偶尔造成的崩溃。

* *常规**
* 使用控制器自动合成物品时只有预览的物品会展示，从而阻止配方书更新过于频繁。
* 修复了末地传送门框架被破坏后末地传送门没有消失的问题。末地传送门方块以外的已填充的方块会保留。
* 修复了纸娃娃问题，现在它能够在皮肤编辑页面用鼠标转动了。（）

* *辅助功能**
* 表情轮盘现在支持屏幕阅读器了。
* 修复了UI屏幕阅读器未读取“邀请进入游戏”屏幕上的屏幕标题和快捷键按钮的问题。
* 修复了在一些设备里屏幕阅读器不会足够频繁复述更新信息的问题。
* 修复了带有控制器图标的信息不会被正确复述的问题。
* UI界面阅读器现在会复述“打开聊天信息”，当“启用聊天文本转语音”选项关闭时。

* *游戏内容**
* 现在大箱子内的物品不会在重载世界时丢失。（）
* 现在在创造模式中对磁石使用指南针后，指南针不再被消耗。（）
* 现在在丛林中的可可豆会拥有正确的生成方向。（）
* 当放置在同一位置时，告示牌不再替代装饰性方块。
* 使用锹右键点击雪块不再摧毁它。
* 土径现在可用锹对着泥土、草方块、灰化土、菌丝体和砂土以制作。
* 更新了下界合金护腿的纹理。（）
* 缠怨藤现在不能在潜行时被放置在堆肥桶上了。（）

* *生物**
* 村民不再会互相认领其他村民的工作方块。（）
* 生物不再会随机性的停止攻击、跟随它们的目标。（）
* 紧密靠近的猪灵不再会捡起同一物品
* 生物不再能够在凋灵玫瑰中生成。（）
* 蜜蜂现在只会在蜂巢或蜂箱的前面进出。

* *命令**
* 命令现在会正确地向距离内的所有玩家播放音效。
* 命令现在最大可以设置1000000秒。（）
* 命令在相同的刻中现在不允许以相同的名称加入同样的地点。
* 允许成功后的占位符文本信息不再返回给玩家。（）
* 命令不再忽略参数。

* *图形、纹理和用户界面**
* 更改了僵尸猪灵的纹理，移除了闪烁的腰带（）
* 在VR控制器菜单下的“Classic Controls - Intense”文本颜色现在与其周围的文本是匹配的。
* 使用控制器时，聊天设置里的X按钮不再出现。
* 改进了档案界面，加载时的字符现在是可见的，并且能设置和修改。
* 修复了指示器在悬停在选项卡上方时消失的漏洞。
* 荧光棒不再使用占位符纹理。（、）
* 加载页面的提示不再显示为。
* 如果玩家在“需要购买历史记录”对话框勾选取消，现在会阻止玩家购买Realms。</onlyinclude>
