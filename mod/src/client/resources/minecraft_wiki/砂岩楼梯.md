# 砂岩楼梯

*页面ID: 44280* | *来源: Minecraft Wiki*

* *砂岩楼梯（Sandstone Stairs）**是[砂岩](砂岩.md)制作的[楼梯](楼梯.md)。

# 生成
# = 自然生成 =
砂岩楼梯会自然生成在沙漠[村庄](村庄.md)、[沙漠神殿](沙漠神殿.md)和热带[海底废墟](海底废墟.md)。

# 获取
# = 合成 =
可以使用任意三种砂岩混合合成，只能只用单种方块合成。

# 破坏
挖掘砂岩楼梯的合适工具是镐。砂岩楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

砂岩楼梯被破坏后会掉落自身。
