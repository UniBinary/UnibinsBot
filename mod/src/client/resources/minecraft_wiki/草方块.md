* *草方块（Grass Block）**是一种在[主世界](主世界.md)地表大量生成的方块。

# 生成
# = 自然生成 =
草方块会自然生成在[主世界](主世界.md)大多数[生物群系](生物群系.md)的地表。

草方块也会自然生成在[村庄](村庄.md)中和[远古城市](远古城市.md)中心的隐藏房间。

# 获取
# = 末影人 =
手中搬着草方块的[末影人](末影人.md)死亡时总是掉落1个草方块。

# 破坏
挖掘草方块的合适工具是[锹](锹.md)。

没有被具有[精准采集](精准采集.md)的工具挖掘破坏时，草方块被破坏后会掉落1个[泥土](泥土.md)。

被具有精准采集的工具挖掘破坏时，草方块被破坏后会掉落自身。

# 用途
[缩略图|草方块的色调在[[平原](File:Grass hues in plains and forest.png.md)（左）和[森林](森林.md)（右）之间平滑过渡]]

[缩略图|100px|顶部未着色的覆雪草方块](File:Snow covered Grass block.png.md)
草方块上的草皮色彩会因它们所在的[生物群系](生物群系.md)而异，这一点与[草丛](草丛.md)、[树叶](树叶.md)和[藤蔓](藤蔓.md)相同。这些方块根据生物群系改变的颜色会显示在[地图](地图.md)上。在特殊情况（例如使用[调试棒](调试棒.md)或自然生成错误）会导致草皮纹理未着色而呈现出纹理原本的灰白色，被[雪](雪.md)覆盖的草方块的草皮纹理是灰白色的原因如此。参见。

# = 扩散 =
草方块的扩散取决于[随机刻](随机刻.md)，不能用[骨粉](骨粉.md)加速此流程。

得到随机刻时，草方块会以下方的方块为扩散中心，在该中心3×5×3的范围内随机挑三次方块尝试传播。要使[泥土](泥土.md)接受附近草方块的扩散，必须达到下列要求：
* 草方块的上方必须至少有9级的[亮度](亮度.md)，泥土则不需要。
* 泥土上方不能被任何下表面[遮挡形状](遮挡形状.md)完整的方块覆盖，但可以是或的[雪](雪.md)。
* * 其遵循光照遮挡的计算方式，故[光照透明方块](光照透明方块.md)不影响其传播。
* 泥土上方不能是[水](水.md)或[熔岩](熔岩.md)，包括[含水](含水.md)的方块。

草方块传播时不要求与目标方块连接，故可以越过中间的空隙或方块，从而传播到远处的泥土上。且因为草可以传播至该草方块下方3格内的泥土，所以山上的草方块向下传播比向上传播快得多。

# = 转变 =
如果草方块满足以下任何条件，草方块将会在收到随机刻后变为[泥土](泥土.md)：
* 被任何下表面[遮挡形状](遮挡形状.md)完整的方块覆盖，但不能是或的[雪](雪.md)。
* * 其遵循光照遮挡的计算方式，故[光照透明方块](光照透明方块.md)不影响。
* 亮度小于9并且上方是[水](水.md)或[熔岩](熔岩.md)源方块，包括含水方块。
* 上方是[水](水.md)或[熔岩](熔岩.md)，不包括含水方块，且上方有至少7级的[亮度](亮度.md)。

[绵羊](绵羊.md)能够吃掉草方块上的草皮，使其变为泥土。关闭[游戏规则](游戏规则.md)将阻止其转化泥土。

对着草方块[锄](锄.md)会将其转变为[耕地](耕地.md)，并使锄消耗掉1点耐久。

对着草方块[锹](锹.md)会将其转变为[土径](土径.md)，并使锹消耗掉1点耐久。

[大型云杉](大型云杉.md)长成后会将其下方及周围多格草方块转变为[灰化土](灰化土.md)。

[杜鹃树](杜鹃树.md)长成后会将其下方的草方块转变为[缠根泥土](缠根泥土.md)。

除大型云杉、杜鹃树、[红树](红树.md)外的[树木](树木.md)长成后，下方的草方块被会转变为[泥土](泥土.md)。

若草方块被顶层[雪](雪.md)、[雪块](雪块.md)或[细雪](细雪.md)覆盖，其纹理上的草皮也会变成被雪覆盖的样子。将其上方的雪移除后便会立即恢复原样。

对上方为空气的[苔藓块](苔藓块.md)或[苍白苔藓块](苍白苔藓块.md)[骨粉](骨粉.md)会使周围7×11×7范围内，最上方的草方块转变为苔藓块或苍白苔藓块。

# = 生物 =
一些常见的[友好生物](友好生物.md)（如[猪](猪.md)、[牛](牛.md)和[绵羊](绵羊.md)）偶尔会在亮度等级大于等于7的草方块上生成，这要求其生成的[区块](区块.md)内只有少量生物。而这些友好生物在大多数情况下是随着世界生成时出现的。

友好生物会更倾向于在草方块上漫步。

被剪毛的绵羊会在对着草方块吃草后重新长出[羊毛](羊毛.md)，不受游戏规则影响。

[末影人](末影人.md)可以搬起及放下草方块。关闭游戏规则将阻止该行为。

# = 种植 =
[矮草丛](矮草丛.md)、[高草丛](高草丛.md)、[矮枯草丛](矮枯草丛.md)、[高枯草丛](高枯草丛.md)、[蕨](蕨.md)、[大型蕨](大型蕨.md)、[花](花.md)、[粉红色花簇](粉红色花簇.md)、[野花簇](野花簇.md)、[灌木丛](灌木丛.md)、[枯萎的灌木](枯萎的灌木.md)、[大型垂滴叶](大型垂滴叶.md)、[下界菌](下界菌.md)、[绯红菌索](绯红菌索.md)、[诡异菌索](诡异菌索.md)、[下界苗](下界苗.md)、[杜鹃花丛](杜鹃花丛.md)和[盛开的杜鹃花丛](盛开的杜鹃花丛.md)都能被放置在草方块上。[树苗](树苗.md)、[竹子](竹子.md)和[甜浆果丛](甜浆果丛.md)能在草方块上生长。[甘蔗](甘蔗.md)和[蘑菇](蘑菇.md)也会在符合条件的情况下在草方块上生长。

# = 骨粉 =
对着草方块[骨粉](骨粉.md)后，草方块会以其上方为起始位置，并尝试128次以起始位置为基础，以在三个方向上随机偏移格的方式偏移次作为新位置，如果某次偏移后的方块是完整方块或偏移后的方块的下方的不是草方块，则此次尝试失败。否则，进一步判断：如果该方块是[矮草丛](矮草丛.md)则有的概率将其成长为[高草丛](高草丛.md)；如果该方块是空气，则开始尝试生成[地物](地物.md)<code>minecraft:single_piece_of_grass</code>或有的概率根据该方块所处的生物群系生成花。

# = 堆肥 =

草方块有30%的概率将[堆肥桶](堆肥桶.md)的堆肥等级增加1。

# = 颜色列表 =

放置在世界中的草方块会根据生物群系着色，详情参见上述条目。

# 你知道吗
* 草方块与[泥土](泥土.md)之间的互相转化是产生[方块更新](方块更新.md)的最常见原因之一。
* 草方块是Minecraft中最具代表性的方块之一，被广泛用于各处作为Minecraft的象征。
* * 正式版和当前的图标即基于草方块设计。
* * 草方块曾经还是[Minecraft网站](Minecraft网站.md)和[启动器](启动器.md)的图标。
* * [Minecraft - Volume Alpha](Minecraft - Volume Alpha.md)的专辑图片使用了草方块。
* 草方块连同[苦力怕](苦力怕.md)、[钻石](钻石.md)和[玩家](玩家.md)的可折叠装饰都曾在[MINECON](MINECON.md)的礼包中被送出。
* 草方块最初的纹理来自[Notch](Notch.md)的另一款游戏[RubyDung](RubyDung.md)。
