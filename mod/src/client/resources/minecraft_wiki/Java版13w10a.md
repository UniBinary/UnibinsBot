# Java版13w10a

*页面ID: 33500* | *来源: Minecraft Wiki*

<onlyinclude>

* *13w10a**是[Java版1.5](Java版1.5.md)的第14个快照，发布于2013年3月4日<ref></ref>，加入了探测铁轨的纹理和史莱姆生成率根据月相改变的特性。

# 新内容
# = 方块 =
* *[探测铁轨](探测铁轨.md)**
* 加入了激活的[探测铁轨](探测铁轨.md)的纹理。

# 更改
# = 生物 =
* *[史莱姆](史莱姆.md)**
* 生成率现在会根据当前月相而改变。
