# 携带版0.4.0 Rev2

*页面ID: 21253* | *来源: Minecraft Wiki*

* *v0.4.0 alpha rev 2**是[携带版](携带版.md)的一个次要更新，发布于2012年9月14日<ref>https://web.archive.org/web/20120917074331/http://itunes.apple.com:80/hu/app/minecraft-pocket-edition/id479516143?mt=8</ref>。此次更新仅在iOS发布以加入对iPhone 5分辨率的支持，并修复了[v0.4.0 alpha](携带版Alpha 0.4.0.md)中的一些漏洞和崩溃。

# 更改
# = 游戏内容 =
* *[创造模式](创造模式.md)**
* 向创造模式加入了以下内容：
* * [TNT](TNT.md)
* ** 无法引爆，因为[打火石](打火石.md)尚未加入创造模式中。
* * [活板门](活板门.md)
* * [石砖](石砖.md)

# = 常规 =
* *分辨率**
* 加入了对iPhone 5分辨率的支持。

# 修复
* *修复了1个漏洞**
* 爆炸现在会损坏地表。
