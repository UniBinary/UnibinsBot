# 临时披风

*页面ID: 186255* | *来源: Minecraft Wiki*

* *临时披风（Temporary capes）**是仅在特定时间内发放给所有玩家，并且不加入到账户中的披风。

# Java版
# = 2010圣诞节披风 =
[60px|right](File:ChristmasCape.png.md)
2010年12月24-25日，所有正版玩家都有此披风。披风并不加入到账户中。

# = 新年披风 =
[60px|right](File:Newyearscloak.png.md)
2010新年年夜，所有正版玩家都有此披风。披风并不加入到账户中。

# Xbox 360版
# = Xbox 1周岁披风 =
[60px|right](File:MicrosoftXbox360 Cape.png.md)
从2013年5月9日到13日，所有Xbox 360玩家都会有这套生日蛋糕披风（除了使用自己披风的玩家）以庆祝Minecraft的Xbox版的一周年。<ref></ref><ref></ref>这个披风并没有添加到他们的账户。
