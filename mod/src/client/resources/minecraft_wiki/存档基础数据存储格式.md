* *存档基础数据存储文件**是存档的核心文件，存储各种存档基础信息、[维度](维度.md)信息和[世界生成](世界生成.md)信息。

# 存储行为
每个存档都至少有一个存档基础数据存储文件。如果一个目录下不存在和文件，那么这个目录就不会被作为存档识别。

游戏有两种读取存档基础数据存储文件的方式：
* 在[选择世界菜单](选择世界菜单.md)中，游戏会读取游戏存档目录，查找所有带有存档基础数据存储文件的目录作为存档，并读取这些文件的部分基础信息显示在菜单内。
* 在游戏加载存档时，游戏会将存档基础数据存储文件的数据全部加载，并根据世界生成数据创建区块生成器等。

由于存档基础数据存储文件是存档最重要的文件，此文件在保存时会留下一个备份以减少数据损坏的可能性：
# 先将新的数据写入到{{filename|-{}-level<*随机字符串*>.dat}}内。
# 将原先的移动到。
# 删除。
# 将刚才写入的{{filename|-{}-level<*随机字符串*>.dat}}移动到。
# 如果有任何一步出错，都将移动回。

备份文件与主文件的结构相同，当主文件损坏时，游戏会自动尝试恢复：
# 先将原先的移动到{{filename|-{}-level.dat_corrupted_<*时间戳*>}}。
# 删除。
# 将移动到。
# 如果有任何一步出错，都将{{filename|-{}-level.dat_corrupted_<*时间戳*>}}移动回。
