# 山羊角乐器定义格式

*页面ID: 138189* | *来源: Minecraft Wiki*

* *山羊角乐器定义文件**是**[山羊角](山羊角.md)乐器（Instrument）**定义数据在数据包中的数据驱动定义文件。

# 定义格式
山羊角乐器定义数据在游戏内使用注册表，数据包路径为，即所有山羊角乐器定义文件都需要在{{filepath|-{}-data/<*命名空间*>/instrument}}目录内定义。

山羊角乐器定义文件使用JSON格式，并具有下列结构：

# 定义行为

山羊角乐器定义数据仅在服务端启动时被加载一次，使用命令不可以使山羊角乐器定义被重新加载，而必须重启服务端。

当玩家吹奏带有<code>instrument</code>[物品堆叠组件](物品堆叠组件.md)的山羊角时，游戏会读取组件内的山羊角乐器信息，并进行播放。

山羊角播放的声音归属<code>record</code>（）分类，声音实例音量为的16分之一，实例音高为1，立刻播放，音量线性衰减。玩家能听到山羊角声音的最远距离（假设声音播放期间没有移动）为声音事件引用定义的值、山羊角乐器定义内的值和声音事件中的值中的最小值。
