* *磁石（Lodestone）**是一种能够将[指南针](指南针.md)变为[磁石指针](磁石指针.md)的方块。

# 生成
磁石不会生成在世界中。

# 获取
# = 合成 =

# = 箱子战利品 =

# 破坏
挖掘磁石的合适工具是镐。磁石需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

磁石被破坏后会掉落自身。

# 用途
# = 磁石指针 =

对磁石指南针可将指南针的指向点设置为该磁石的位置，同时该指南针会转化为磁石指针。磁石指针会在其物品数据中储存磁石的坐标和[维度](维度.md)。若玩家传送到其他维度或磁石被破坏，则该磁石指针会随机旋转。
