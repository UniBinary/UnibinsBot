# 格式化代码

*页面ID: 9143* | *来源: Minecraft Wiki*

[thumb|一本展示了Java版中所有的格式化代码和字符的书|class=pixel-image](File:Minecraft Formatting.gif.md)

* *格式化代码（Formatting code）**，又称**颜色代码（Color code）**，能使在游戏中加入含颜色和格式信息。

在[Minecraft](Minecraft.md)中，可以以（）产生带色文字。分节符号能被输入进[告示牌](告示牌.md)、世界名称、[重命名栏](铁砧#重命名.md)及聊天栏，它们在非[Ore UI](Ore UI.md)界面中产生带色文字。

然而，格式化代码已被弃用，且计划于未来删除。较新的文本系统将不再为格式化代码提供支持。<ref>见相关评论</ref>

# 用法

|Slicedlime Twitter avatar.jpg}}
可以在分节符（§）后加某个字符来格式化文本。如果字符是十六进制数字，在客户端里可用于显示文本时切换颜色。分节符可以用在任何能输入文字的地方；而则可以用在<samp>[server.properties](server.properties.md)</samp>、<samp>pack.mcmeta</samp>、语言文件、世界标题和[服务器](服务器.md)名称中。

如果在格式代码后使用颜色代码，则格式代码的作用范围只能持续到颜色代码之前。例如，<code>§cX§nY</code>会显示为<span class="format-c" style="font-family: Minecraft;">X<u>Y</u></span>，而<code>§nX§cY</code>会显示为<span class="format-f" style="font-family: Minecraft"><u>X</u><span class="format-c">Y</span></span>。因此，当使用颜色代码与格式代码一起使用时，确保首先使用颜色代码，并在更改颜色时重用格式代码。

[200px|thumb|§a§o§lDedicated Ser§rver§c§k 的效果](File:Bedrock server motd.jpg.md)
在颜色代码后面的格式代码仍然生效。此外，如果用了混淆代码而没有在行尾使用重置代码，客户端GUI会继续模糊MOTD传过来的文字和版本号显示：

<code>§r</code>可以用于重置文字样式。例如：<code>§nXXX§rYYY</code>会显示为<span style="font-family:Minecraft;"><u>XXX</u>YYY</span>。

# = 格式代码 =

使用**§k**循环出现的随机字符会与原有字符的宽度相同。例如，如果是“m”则随机字符都是宽字符，而如果是“i”则都是窄字符。

Unicode输入法}}

* 在Windows上，大多数美式/英式英语键盘可以用（在代码页437上为）或输入“§”。如果是其他键盘，通常可以用输入，或按并切换至符号栏输入。
* 如果在Windows注册表中启用了<code>EnableHexNumpad</code>，也可以用（“A”是主键盘上的）。因为分节符在Unicode内，所以任何语言下这种方式都可用。
* 在Mac美式键盘上可以按（也可以按来调出扩展符号），其他键盘则要换成。
* 在Linux上，可以按组合键或使用Unicode快捷键。
* 在Nintendo Switch上，选择语言（地球图标），滑至底部找到“符号”一栏，“§”在第2页最后一行右侧。
* 在Android上：
* * Gboard：“§”在“更多符号”中，先点击数字和符号按钮 (?123)，然后点击更多符号按钮 (=\<)。需要注意的是，在早期版本中，“§”在段落符号“¶”下方，需要先按住“¶”再滑动到“§”上。
* * 三星：“§”在“s”下方，需要先按住“s”再滑动到“§”上。
* 在iOS/iPadOS上：
* * 在iPad上，“§”在“%”下方，需要点击数字/符号按钮，然后向下滑动“%”。
* * 在iPhone上，“§”在“&”下方，需要点击数字/符号按钮，然后按住“&”并滑动到“§”上。
* 在Xbox上：
* * 在Xbox One上，“§”位于“¶”下方，用选中¶时，按住直到出现其他选项，将光标移至“§”并用选择。
* * 也可以选中标准字母数字键盘上的键，然后按住显示若干个包括“§”的“替代”字符。此方法也适用于Windows 10。

# 用途
# = [server.properties](server.properties.md)和pack.mcmeta =
如果要得到彩色[告示牌](告示牌.md)，或者格式化文本，需输入<code>\u00A7</code>代替§。例如，§5会变成<code>\u00A75</code>。颜色与格式可以结合使用，注意必须在添加颜色**之后**添加格式。

* *旧版本兼容性**

格式化代码可以在<code>motd</code>文件里使用, 但分节符必须被转换为<code>\u00A7</code>。如果直接输入分节符，服务器会自动将其转换为<code>\u00C2\u00A7</code>（），客户端则会显示为错误标记。删除在Motd里的代码会引发一连串的问题，这些问题会在一些不兼容的版本上发生。

# = 自定义语言与文字文件 =
格式化代码可用于[语言描述文件](资源包#语言.md)中的任意字符前，使得物品名称或界面文本等具有自定义样式。这也被用于<samp>end.txt</samp>和<samp>credits.txt</samp>等[文字文件](资源包#文字.md)中。例如，<code>{"item.minecraft.diamond":"§dDiamond§r"}</code>可以使钻石的名称显示为。

# = 世界名称 =
使用外部工具（如[NBTExplorer](辅助程序与编辑器/NBTExplorer.md)）可以自定义在游戏中世界名称显示的颜色和格式。要修改名称，可以选择[level.dat](level.dat.md)中的LevelName标签。在这个例子中，LevelName设置为：

<code>§1R§2e§3d§4s§5t§6o§7n§8e §9C§ar§be§ca§dt§ei§fo§1n§2s</code>

[class=pixel-image](File:ColouredLevel.png.md)

除此之外，也可以在存档的文件夹里更改世界名称。然后在选择世界的时候就可以看见指定的颜色效果是否生效。

还可以使用资源包和来改变世界的名称的颜色，而在创建世界的时候创建者只需要用设置世界的名称的颜色的标记。

# = 服务器名称 =
随着如[NBTExplorer](辅助程序与编辑器/NBTExplorer.md)的第三方工具的使用，服务器名称可以自定义颜色。利用这个功能，可以使用第三方工具编辑Minecraft目录的servers.dat文件来修改Name属性。下面是一个编辑好的例子：

<code>§4§lMinecraft §6§l Server</code>

# 你知道吗
* 颜色代码在游戏中几乎完全匹配1981年发布的[彩色图形适配器（CGA）](wzh:彩色图形适配器.md)的16种颜色，只有颜色6不同 – <div style="display:inline-block; background: #FFAA00; border-radius: 1em; height:1em; width:1em; border: 1px solid #aaa; vertical-align: middle; margin-top: -0.1em;"></div> #FFAA00 – 不同于CGA – <div style="display:inline-block; background: #AA5500; border-radius: 1em; height:1em; width:1em; border: 1px solid #aaa; vertical-align: middle; margin-top: -0.1em;"></div> #AA5500。
* Minecoin金（§g）在PlayStation上无法正常显示，会显示为无格式或透明。
* 如果使用除Mojangles之外的任何字体，随机字符（§k）会显示为点。
