# Java版Alpha服务器0.1.2 01

*页面ID: 45474* | *来源: Minecraft Wiki*

{{DISPLAYTITLE|Java版Alpha服务器0.1.2_01}

* *0.1.2_01**是一个[Alpha](Java版Alpha.md)服务器版本，与[客户端1.0.16_01](Java版Alpha v1.0.16 01.md)在2010年8月12日一起发布。

# 修复
* 修复了验证方案的一个缺陷。<ref></ref>登录密钥现在变成了真正的临时密钥，每给服务器发送一个新的TCP连接时都会改变。

# 重新上传
该版本于2010年8月12日晚些时候被重新上传，以此修复认证方案的缺陷。登录密钥现在变成一个适当的随机数，每当与服务器建立新的[TCP](wzh:传输控制协议.md)连接时，该密钥会发生变化。
