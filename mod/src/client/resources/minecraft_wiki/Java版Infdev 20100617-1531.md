# Java版Infdev 20100617-1531

*页面ID: 35995* | *来源: Minecraft Wiki*

<onlyinclude>

* *[Minecraft Infdev](Java版Minecraft Infdev.md)**的一个版本发布于2010年6月17日，修复了一些漏洞。

# 新内容
# = 游戏内容 =
* *[窒息](窒息.md)**
* 重新加入了窒息伤害。

# = 世界生成 =
* *[涌泉](涌泉.md)**
* 加入了地表涌泉。

# 更改
# = 方块 =
* *[水](水.md)**
* 改进了水的流动。

* *[熔岩](熔岩.md)**
* 现在会传播4格远，而不是8格。

* *[液体](液体.md)**
* 现在[水](水.md)碰到[熔岩](熔岩.md)流会生成[圆石](圆石.md)，水流碰到熔岩源会使熔岩源变成[黑曜石](黑曜石.md)。

# = 游戏内容 =
* *[高度](高度.md)**
* 现在可以在Y=0放置方块了。
* 移除了世界底部的无限熔岩海，被[虚空](虚空.md)代替。

* *[刻](刻.md)**
* 对计划中的方块刻逻辑进行了大量调整，主要用于流体和火。
* * 可能是用于修复一个崩溃漏洞。

# = 世界生成 =
* *[洞穴](洞穴.md)**
* 改进了洞穴：
* * 洞穴更具区域性，“瑞士奶酪”形状的区域可以生成，但罕见。
* * 水或熔岩涌泉现在变得更加常见。
* * 增加隧道厚度的多样性，增加分支的概率。
* * 在地下加入了自然生成的[沙砾](沙砾.md)和[泥土](泥土.md)，从而使洞穴多样化。

# 修复
* *修复了3个漏洞**
* 修复了液体传播代码中的一些漏洞。
* 修复了隐形的瀑布。
* 修复了玩家的手不显示的漏洞。</onlyinclude>
