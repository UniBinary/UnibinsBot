# Java版1.11.2

*页面ID: 26784* | *来源: Minecraft Wiki*

* *1.11.2**是的一次次要更新，发布于2016年12月21日<ref></ref>，修复了一些漏洞。此版本不兼容1.11的服务端，兼容1.11.1的服务端。
