# Java版Alpha v1.0.6

*页面ID: 32491* | *来源: Minecraft Wiki*

<onlyinclude>
* *Alpha v1.0.6**是的一次[秘密更新](秘密更新.md)，发布于2010年7月16日<ref></ref>，加入了[船](船.md)、[仙人掌](仙人掌.md)和[树木](树木.md)。

# 新内容
# = 方块 =
* *[仙人掌](仙人掌.md)**
* 当[玩家](玩家.md)右键点击、破坏或站在仙人掌上时会连续受到的[伤害](伤害.md)。

# = 非生物实体 =
* *[船](船.md)**
* 可用于水上航行。

# = 世界生成 =
* *[树木](树木.md)**
* 重新加入大型树。

# 更改
# = 方块 =
* *[树叶](树叶.md)**
* 树叶不再会枯萎。

* *[雪块](雪块.md)**
* 现在合成雪块只需要4个雪球，而非之前的9个。

# = 物品 =
* *[雪球](雪球.md)**
* 雪球现在可堆叠到16个。
* 抛出的雪球不再会消失。

# = 生物 =
* *[生成](生成.md)**
* 动物现在只能在草地上生成。

# = 游戏内容 =
* *[第三人称视角](第三人称视角.md)**
* 现在在第三人称视角时可以看到手持的[方块](方块.md)或[物品](物品.md)，它们被渲染得很大。

# = 常规 =
* *[昼夜更替](昼夜更替.md)**
* 延长了黑夜的时间。

# 修复
* *修复了1个漏洞**
* 修复了雪会穿过雪块落下的漏洞。</onlyinclude>
