# Java版19w11b

*页面ID: 41478* | *来源: Minecraft Wiki*

<onlyinclude>

* *19w11b**是[Java版1.14](Java版1.14.md)的第26个快照，发布于2019年3月14日<ref></ref>，修复了一些漏洞。

# 更改
# = 物品 =
* *[可可豆](可可豆.md)**
* 英文名称由“Cocoa”（可可）变回“Cocoa Beans”（可可豆）。

# = 常规 =
* *[菜单](菜单.md)**
* 自动跳跃现在也同时存在于无障碍设置中了。
* 透明度设置的名称现在由“聊天不透明度”变为“聊天文本不透明度”。
