# Java版1.11-pre1

*页面ID: 26276* | *来源: Minecraft Wiki*

<onlyinclude>

* *1.11-pre1**是[Java版1.11](Java版1.11.md)的唯一一个预发布版，发布于2016年11月8日<ref></ref>，修复了一些漏洞。

# 更改
# = [方块](方块.md) =
* *[侦测器](侦测器.md)**
* 将前面（侦测面）纹理变成一个“侦测脸”。
* * 上下纹理也使用此纹理。面朝下时：面上的点朝北。面朝上时：面上的点朝南。
* * 这个纹理是[携带版](携带版.md)和以前的纹理中侦测器的混合纹理（[|24px](File:Observer_(front_texture)_pre-BE.png.md)）。
* * 纹理由Tommasso Checchi（@_tomcc）制作。<ref></ref>
* 红石的输出端在输出信号时会闪烁。

# = [物品](物品.md) =
* *[附魔书](附魔书.md)**
* 消失诅咒、耐久III和经验修补的附魔书现在出现在[创造模式物品栏](物品栏.md)的工具和战斗标签中。

# = 常规 =
* *警告**
* 现在对使用Java 8以下的玩家会发出警告。

* *语言文件**
* 清理语言文件不再使用<code>%d</code>。
