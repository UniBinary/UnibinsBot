# 命令/executeasother

*页面ID: 56695* | *来源: Minecraft Wiki*

以指定的目标而执行其他命令。

# 语法
   <code>-{}-executeasother <*来源：目标*> <*位置：x y z*> <*命令：字符串*></code>

# 参数
<code>-{}-*来源：目标*</code>
   指定命令的执行者。必须是玩家的名称或者是目标选择器。如果选择了多个实体，那么每个实体都会运行一次命令。

<code>*位置：x y z*</code>
   指定命令执行的位置。*x*和*z*必须在[-30,000,000到30,000,000](世界边界.md)（含）范围内。使用的与目标所处的位置有关，而不是命令的执行位置。

<code>-{}-*命令：字符串*</code>
   指定要运行的命令。
