# 花（消歧义）

*页面ID: 112273* | *来源: Minecraft Wiki*

* *花（Flower）**可以指：

# Minecraft
# = 可以视为花的方块 =
凡是能使、[白桦树苗](白桦树苗.md)、[樱花树苗](樱花树苗.md)生成[蜂巢](蜂巢（方块）.md)或能使[蜜蜂](蜜蜂.md)繁殖和采粉的方块都可以视为花。

# = 其他与花有关的方块和物品 =
*  - 可以容纳花的方块。
*  - 用于自定义[旗帜](旗帜.md)的物品，可由[滨菊](滨菊.md)合成。
*  - 能够种出火把花植株的物品。
* *  - 种植在[耕地](耕地.md)上的作物方块，成熟时能掉落火把花。
*  - 能够种出瓶子草植株的物品。
* *  - 种植在耕地上的作物方块，成熟时能掉落瓶子草。

# = 生物群系 =
*  - 能够生成樱花树和粉红色花簇的生物群系。
*  - 能够生成大量花的生物群系。
*  - 能够生成向日葵的生物群系。

# = 地物 =
*  - 由花组成的地物。
*  - 可由种植樱花树苗生成的地物，包含樱花原木和樱花树叶。
*  - 可由种植杜鹃花丛生成的地物，包含杜鹃树叶。

# Minecraft Earth
# = 方块 =
*  - 可从哞花获得的黄色小型花。
*  - 可从哞金香获得的小型花。

# = 生物 =
*  - [哞菇](哞菇.md)长有毛茛的变种，可从中获取毛茛、蒲公英和向日葵。
*  - 哞菇长有粉红雏菊的变种，可从中获取粉红雏菊、绒球葱、丁香和牡丹。

# Minecraft Dungeons
# = 生物 =
*  - 可在主大陆获取的宠物。

# = 场景结构 =
* [花盆布景](Minecraft Dungeons:花盆布景.md) - [赛季三：动物狂欢](MCD:赛季.md)的主题内容。

# = 特效 =
*  - 赛季二：辉光暗夜的治疗特效。
