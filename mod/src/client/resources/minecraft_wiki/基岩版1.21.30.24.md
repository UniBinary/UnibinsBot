# 基岩版1.21.30.24

*页面ID: 125572* | *来源: Minecraft Wiki*

<onlyinclude>

* *beta 1.21.30.24**（ChromeOS/Android）、**Preview 1.21.30.24**（Xbox/Windows/iOS/iPadOS/PlayStation）是[基岩版1.21.30](基岩版1.21.30.md)的第4个测试版，发布于2024年8月21日<ref></ref>，同步了一些的特性，在[实验性玩法](实验性玩法.md)中对[收纳袋](收纳袋.md)作出了一些调整，并修复了一些漏洞。

# 更改
# = 方块 =
* *[瓶子草](瓶子草.md)**
* 现在再次能合成出2个[青色染料](青色染料.md)，而不是1个。

# = 物品 =
* *[重锤](重锤.md)**
* 现在所有手持重锤的生物均可进行猛击。

# = 生物 =
* *[狐狸](狐狸.md)**
* 生命值由减少至。

# = 世界生成 =
* *[试炼密室](试炼密室.md)**
* 暂时回退了[1.21.30.21](基岩版1.21.30.21.md)中作出的修复和更改，[漏斗](漏斗.md)和[木桶](木桶.md)相关的更改除外。

# = 游戏内容 =
* *[粒子](粒子.md)**
* 粒子现在拥有了音效。

* *[状态效果](状态效果.md)**
* 效果图标现在会根据GUI比例改变大小。

# = 常规 =
* *[极限模式](极限模式.md)**
* 现在如果玩家在极限模式世界中死亡，该世界会在新的[选择世界菜单](选择世界菜单.md)UI中显示灰色边框（仅测试版本）。

* *世界模板屏幕**
* 更新了新UI中的世界模板屏幕。
* * 现在与世界模板相关的内容分为3个选项卡：
* ** “Marketplace Pass”：Marketplace Pass中包含的一系列世界模板。
* ** “精选创作者”：由Minecraft创作者设计的一系列世界模板（可选择在市场中发现更多世界模板）。
* ** “”：已购买的世界模板。玩家可以在此处通过世界模板创建世界，以及为世界模板评分。
* * 现在可以使用搜索栏来快速搜索世界模板，并可以使用过滤器和排序顺序来优化结果。
* * 现在可以发现Marketplace Pass的所有内容，并轻松进行注册。

# = 技术性 =
* *[附加包](附加包.md)和脚本引擎**
* 修复了UI中所有的自定义方块都会旋转180度的漏洞。
* * 字段的默认值现在为，而不是。
  : <syntaxhighlight lang="json">
     "item_display_transforms": {
          "gui" : {
               "translation": [0, 0, 0],
               "rotation": [30, 45, 0],
               "scale": [0.625, 0.625, 0.625],
                "rotation_pivot": [0, 0, 0],
               "scale_pivot": [0, 0, 0],
               "fit_to_frame": true
          }
     }
</syntaxhighlight>

* *[基岩版编辑器](基岩版编辑器.md)**
* 移除了编辑器暂停菜单中的截图和个人资料按钮。

* *物品**
* 组件现在向创作者公开。

* *音效**
* 现在在文件中指定无效声音事件时会触发内容日志错误。

# 实验性
本段落的内容需要开启[实验性玩法](实验性玩法.md)中的“”、“测试版 API”、“”和“”子选项后才可使用。

# = 物品 =
* *[收纳袋](收纳袋.md)**
* 现在获得[皮革](皮革.md)或[线](线.md)时会解锁收纳袋的合成配方。
* 现在使用触摸屏设备在收纳袋中加入或移除物品时会显示正确的动画。
* 现在将包含多个物品的物品堆叠移入收纳袋时，收纳袋内已有的相同物品会正确移至顶部。
* 未染色的[潜影盒](潜影盒.md)不再能被放入收纳袋中。（）
* 现在使用游戏手柄右摇杆“向上”方向进行操控时可以在收纳袋的子菜单中正常移动。
* 现在收纳袋物品提示框最多显示3行物品而非2行，使得折叠部分物品的收纳袋至少能展示8种物品。

# = 技术性 =
* *游戏内容**
* 聚焦目标相机：在自由相机预设JSON加入了，以控制瞄准实体时的旋转速度。
* * 此值为浮点数，表示每秒转动的度数。
* 聚焦目标相机：在自由相机预设JSON加入了布尔值，以能够在第一刻时捕捉所瞄准的实体。

* *图形**
* 在启用延迟渲染预览功能的Android设备上，SSR不再会在错误方向泄漏。

# 修复
* *音效**
* 现在粒子拥有音效。
* 凋灵骷髅现在拥有自己的“脚步声”。（）

* *Realms**
* Realms备份列表现在会显示备份创建的日期，而不是备份的时间。

* *性能与稳定性**
* 修复了加载纹理时可能发生的崩溃。（）

* *用户界面**
* 效果图标现在会根据GUI比例改变大小。（）
* 修复了创建新的世界屏幕中可能会缺少种子模板按钮的问题。

* *原版趋同**
* 玩家现在可以使用1个瓶子草合成2个青色染料。（）
* 狐狸现在拥有点生命值。（）
* 村民在睡觉时不再会发出空闲声音。</onlyinclude>
