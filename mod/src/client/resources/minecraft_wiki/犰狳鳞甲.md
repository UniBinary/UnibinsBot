# 犰狳鳞甲

*页面ID: 110351* | *来源: Minecraft Wiki*

* *犰狳鳞甲（Armadillo Scute）**是由[犰狳](犰狳.md)产出的物品，可以用于合成和修复[狼铠](狼铠.md)。

# 获取
# = 犰狳 =
[犰狳](犰狳.md)每隔5-10分钟会掉落一个犰狳鳞甲。

玩家或[发射器](发射器.md)对成年犰狳[刷子](刷子.md)时，犰狳会立即掉落一个犰狳鳞甲。

# 用途
# = 合成材料 =

# = 修复 =
犰狳鳞甲可以用来在[铁砧](铁砧.md)上修复狼铠。

玩家对坐下的<ref></ref><ref></ref>装备了受损的狼铠的狼犰狳鳞甲也可以修复狼身上的狼铠，每个犰狳鳞甲可增加8点耐久度。
