# Java版Minecraft Infdev

*页面ID: 35540* | *来源: Minecraft Wiki*

* *Minecraft Infdev**指的是**[Infdev](Java版Infdev.md)**的所有27个版本，包括从[2010年2月27日](Java版Infdev 20100227-1414.md)到[2010年6月30日](Java版Infdev 20100630-1835.md)的所有30个以“Minecraft Infdev”命名的版本。

# 新内容
# = 常规 =
; [云](云.md)
* 现在可设置为立体。
; [选项](选项.md)
* 快速/高质量<!-- fancy -->渲染切换。
; 窒息
* 玩家被困在方块内会窒息。

# = 方块 =
;[沙子](沙子.md)
* 重新加入。
;[沙砾](沙砾.md)
* 重新加入。
;[告示牌](告示牌.md)
* 可以书写。
; [梯子](梯子.md)
* 可以攀爬。
; [门](门.md)
* 可以打开或关闭。
;[刷怪笼](刷怪笼.md)
* 生成在地牢的箱子里。

# = 物品 =
;[金苹果](金苹果.md)
* 可以食用。
;[铁桶](铁桶.md)
* 可以装起液体。
;[鞍](鞍.md)
* 生成在地牢里。

# = 非生物实体 =
;[箭](箭.md)
* 重新加入。
; 阴影
* 加入。
; [矿车](矿车.md)
* 可以骑乘。
; [铁轨](铁轨.md)
* 可以将矿车放在其上面。

# = 世界生成 =
; 结构
* 红砖块金字塔
; 黑曜石墙
* 由黑曜石组成，向X轴和Z轴无限延伸。
; [树](树.md)
* 重新实现。
; 矿团
* 现在会自然生成。
; [地牢](地牢.md)
* 携带刷怪笼和战利品箱子生成。

# 更改
# = 常规 =
; [玩家](玩家.md)
* 死后掉落自身物品。
* 掉出世界后会死亡。
; [昼夜更替](昼夜更替.md)
* 白天现在会比黑夜稍微长一点。

# = 方块 =
; [火](火.md)
* 现在会传播到可燃烧的方块上。
; [草](草.md)
* 现在会传播到邻近的[泥土](泥土.md)上。
; [圆石](圆石.md)
* 水接触到熔岩后会生成。
; [黑曜石](黑曜石.md)
* 水接触到熔岩源后会生成。
; [熔岩](熔岩.md)
* 熔岩现在只会向外传播4格方块，而不是8格。
; [基岩](基岩.md)
* 现在生成于Y=0层。
; [沙子](沙子.md)
* 有了掉落动画。

# = 生物 =
; 实体
* 在世界重新载入前会保存。

# = 世界生成 =
; 无限世界
* 世界现在在每个方向上都是无限生成的。
; [Indev房子](Indev房子.md)
* 被移除。
; [洞穴](洞穴.md)
* 现在有1-5个出口，而不仅仅是1个，成为自然枢纽。
* 洞穴更具区域性，真正的瑞士奶酪区域<!-- Swiss cheese areas -->可以生成，但罕见。
* 水或熔岩涌泉现在变得更加常见。
* 增加隧道厚度的多样性，增加分支的概率。
* 在地下加入了自然生成的沙砾和泥土，从而使洞穴多样化。
