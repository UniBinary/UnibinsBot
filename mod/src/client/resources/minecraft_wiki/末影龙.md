* *末影龙（Ender Dragon）**是玩家初次进入[末地](末地.md)时生成的飞行敌对生物，同时也是最广为人知的Minecraft最终[Boss](Boss.md)。

# 生成
末影龙会在实体首次到达末地后生成。如果末影龙战斗处于激活状态，而末影龙实体失踪，游戏会生成新的末影龙。

末影龙在和平[难度](难度.md)下不会消失，但无法对玩家造成伤害。

# = 重生 =

[右|缩略图|一种重生末影龙的摆放末地水晶的方式](File:End_Crystals_on_the_Exit_portal.png.md)
与末影龙的战斗结束后，当[返回传送门](返回传送门.md)的四个边上各放置了至少一个[末地水晶](末地水晶.md)时，末影龙会开始重生。

末影龙重生时，返回传送门会先被关闭，返回传送门的基岩平台的四个边上的每个末地水晶都会向正上方发射末影龙利用末地水晶恢复生命值时的光线。在后，这些光线将依次聚焦在主岛外围黑曜石柱的顶端，爆炸后会重置[黑曜石柱](黑曜石柱.md)、[铁栏杆](铁栏杆.md)（若有）和末地水晶。每重置完一个黑曜石柱后，每道光线会聚焦在下一个黑曜石柱顶端，重复上述过程，一直到所有黑曜石柱都被重置为止，这个过程共持续。

在所有黑曜石柱重置完毕后，所有黑曜石柱顶端和返回传送门四周的每个末地水晶会向<code>0 128 0</code>处发射光线，聚焦到这个点上，后末影龙在那里重生。如果强制将返回传送门角落旁的末地石更改，末影龙重生时将把角落更改的部分改为末地石。

末影龙重生的过程中，如果发出光线的末地水晶被破坏，复活末影龙的过程会被中止，返回传送门将重新激活；如果继续往返回传送门边上放置末地水晶，新放置的末地水晶不会发出光线。

# 掉落物
末影龙的生命值降为0后，会回到[返回传送门](返回传送门.md)上方（除非距离太远），然后或，身体支离破碎，并迸出多条光束，然后爆炸。末影龙死亡并消失后，[返回传送门](返回传送门.md)会打开。

首次击杀末影龙时，末影龙死亡过程中会掉落11波[经验球](经验球.md)，先掉落10波960经验值，最后掉落1波2400经验值，总计12000经验值，足够让玩家从0级升到68级。之后击杀的末影龙只会掉落1波500经验值。

首次击杀末影龙，且返回传送门激活后，[龙蛋](龙蛋.md)会出现在返回传送门顶端。返回传送门的中心的正上方如果有方块，那么龙蛋会生成在最高的方块上方1格处。如果最高的方块触及了世界高度限制，则龙蛋不会生成。

即使并非被玩家或驯服的狼杀死，末影龙也会掉落经验值。

第二次击杀末影龙有概率再次获得龙蛋和12000经验值。<ref></ref>

每杀死末影龙一次，围绕着返回传送门75-100格范围内会生成一个[末地折跃门](末地折跃门.md)，最多可以生成20个。

# 行为

末影龙会被附近的[末地水晶](末地水晶.md)治疗，体现在末影龙与末地水晶相连的白色光柱上。摧毁正在治疗末影龙的末地水晶会对末影龙造成伤害。

末影龙只能受到爆炸和玩家的伤害，见。它免疫所有的[状态效果](状态效果.md)。[喷溅型治疗药水](喷溅型治疗药水.md)和[喷溅型伤害药水](喷溅型伤害药水.md)会直接施加其效果而不添加[瞬间治疗](瞬间治疗.md)或[瞬间伤害](瞬间伤害.md)状态效果，但由于末影龙巨大的碰撞箱，需要砸中末影龙碰撞箱的底面中心点附近才能对末影龙造成影响。

末影龙不会在[虚空](虚空.md)中因低于临界高度而受到伤害。

不能对末影龙使用[命名牌](命名牌.md)。

玩家的[近战攻击](近战攻击.md)无法对末影龙造成暴击。

被|je}}或的伤害|be}}杀死的末影龙会跳过其漫长的死亡动画并立刻消失和激活[返回传送门](返回传送门.md)；被杀死的末影龙不会飞回返回传送门，而是留在原地并显示死亡动画。

当玩家在以(0,128,0)为中心半径190格的范围内、且正在进行与末影龙的战斗时：
* 游戏会播放名为[Boss](Boss（音乐）.md)的音乐。
* 末影龙的[Boss栏](Boss栏.md)会显示。
* [距离迷雾](迷雾#距离迷雾.md)范围被降低且不会超过96格，阻止设置了极高区块加载距离的玩家在末地主岛上直接看见外围岛屿。

末影龙有与其相关的Boss栏显示其生命值，其颜色为粉色，出现在游戏界面的上方。末影龙的Boss栏是由游戏的末影龙战斗系统控制的，而非末影龙实体控制的，因此只有被游戏追踪的末影龙会显示其Boss栏，同一时间只会显示至多一个末影龙Boss栏；末影龙的Boss栏会在其距玩家125格以内时显示，多只末影龙的Boss栏可以同时显示。

# = 末影龙部件 =

[thumb|在Java版中观察到的末影龙的碰撞箱](File:Ender dragon hitboxes.png.md)

末影龙由8个**末影龙部件**（Java类名：<code>EnderDragonPart</code>）构成。尽管末影龙有巨大的判定箱，但只有攻击这些末影龙部件才能够对末影龙造成伤害。

使用快捷键可以显示末影龙的边界框，其中同时显示的8个绿色的[碰撞箱](Tutorial:利用碰撞箱.md)是末影龙的末影龙部件：头部、尾部、躯干以及两翼。

玩家可以对准末影龙部件的判定箱并使用命令补全来获取到末影龙部件的UUID，但尝试使用这些UUID会导致命令找不到实体。

[调试组合键](调试屏幕#调试组合键.md)无法获取末影龙部件的实体数据。

[目标选择器](目标选择器.md)无法选中末影龙部件。

末影龙部件不会被存储在世界中，而是在每一次加载末影龙时生成。

大多数方块与末影龙部件接触时会被破坏，被破坏的方块不会掉落，但容器的内容物（[潜影盒](潜影盒.md)和[末影箱](末影箱.md)例外）会掉落。

# = 移动 =
末影龙在与玩家战斗时会绕着主岛飞行。

末影龙使用穿透方块的飞行移动方式，类似于[恼鬼](恼鬼.md)和[旁观模式](旁观模式.md)的[玩家](玩家.md)，不受重力影响、穿过方块、不能在可站立表面上站立且不会[窒息](窒息.md)。

尽管末影龙的末影龙部件会破坏多数方块，末影龙仍然可以被流动的[水](水.md)、[熔岩](熔岩.md)以及[气泡柱](气泡柱.md)影响。

# = 攻击 =

末影龙只与玩家敌对。其他生物被末影龙的攻击波及后可能会攻击末影龙，但末影龙永远不会将玩家以外的生物作为攻击目标。

末影龙在盘旋时，会使从侧面接近其判定箱的或被施加强力的远离末影龙的方向的动量，不受生物的击退抗性影响且可以影响免疫伤害的生物，同时还会持续对这个范围内的或造成伤害。

末影龙在俯冲时，任何或被末影龙头部从正面撞击会持续受到伤害，<!-- 尽管该漏洞的状态目前为Fixed,但实际上并未修复。--></ref>}}。这个伤害能够造成异常夸张的强力击退，并且导致生物被甩向高空中或几十米远处。末影龙的冲撞攻击没有Java版中的击退效果。

末影龙有四种主要行为状态：

; 盘旋
* 这是末影龙的初始姿态。末影龙会在末地水晶未被破坏时环绕黑曜石柱外围飞行，末地水晶被破坏后则会环绕黑曜石柱内侧飞行。
* 破坏越多的末地水晶，末影龙就会越频繁地切换到其他行为状态。
  ; 寻敌
  * 末影龙距离当前攻击目标近于10格或远于150格时会尝试选择新的攻击目标。
  * 受伤后，末影龙会飞向别处，寻找新的攻击目标。
; 轰炸
* 末影龙会在末地水晶受到破坏时立即进入此状态，向玩家发射[末影龙火球](末影龙火球.md)。
* 末影龙会瞄准距中央返回传送门64格以内的玩家，并在飞至距离玩家64格内的范围时发射火球。
* 该行为状态结束后，末影龙会重新进入盘旋状态。
; 俯冲
* 末影龙会选择目标玩家，然后向该玩家的位置加速俯冲。
* 无论末影龙是否击中玩家，末影龙都会在俯冲后重新进入盘旋状态。
;
* 末影龙会飞向返回传送门（若可能的话会从与玩家相对的方向飞向传送门），然后降落。此时，末影龙不能被[箭](箭.md)或[三叉戟](三叉戟.md)击中，射向末影龙的箭或三叉戟会被弹开并[着火](着火.md)。
  ;
  * 1.25秒后，若有玩家在返回传送门20格范围内，末影龙会咆哮并使用龙息攻击，产生一片紫色的[区域效果云](区域效果云.md)。在非和平难度下，其效果与滞留型伤害药水相似，有效时间为或。
  * 玩家可以对着该区域效果云[玻璃瓶](玻璃瓶.md)来收集[龙息](龙息.md)。每收集一次龙息，该区域效果云的范围就会减少一些。
  * 在和平[难度](难度.md)下，该区域效果云对玩家没有伤害。然而，末影龙死亡后，该区域效果云会对玩家产生伤害。<ref></ref>
  ; 冲刺
  * 末影龙在返回传送门上停驻后的5秒内，如果玩家仍距离返回传送门较远，末影龙会向距其150格内的玩家冲刺。
  ; 起飞
  * 末影龙会在连续进行4次龙息攻击后，或者未能在150格范围内找到玩家时飞离返回传送门。
  * 此后，末影龙会进入盘旋状态。
  ; 逃逸
  * 若末影龙在栖息期间累计受到超过的伤害，它会飞离返回传送门，伤害累计也会随之清零。栖息期间的累计伤害不会因行为状态的改变等其他因素而清零。
  * 此后，末影龙会进入盘旋状态。

末影龙的生命值降为后，若距离返回传送门大于10格，末影龙会强制飞回，此时末影龙实体仍然存在并可被正常检测，只有飞到距离返回传送门10米以内的位置才真正死亡，除非末影龙距离传送门150米以外，或正接触方块。飞回时全身纹理会常亮实体受击时的红色。飞回时身上会不断冒出爆炸粒子。

# 末影龙战斗
* *末影龙战斗（Dragon fight）**是一个控制末影龙的生成、战斗和死亡的系统。

末影龙战斗会记录当前末影龙，当前是否是末影龙已被杀死的状态，已经生成的末地折跃门，返回传送门的位置，以及末影龙是否曾经被杀死过。

末影龙战斗的数据存储在或中，而非存储在末影龙的实体数据中。

末影龙战斗会在末影龙未被杀死，但当前末影龙记录的末影龙实体不存在时，重新生成新的末影龙。首个末影龙也是如此生成。

# 你知道吗
* 若通过循环执行命令，阻止濒死的末影龙接近返回传送门，末影龙无法开始死亡动画。
* 如果末影龙生命值足够大，在没有濒死的时候仍然会犹如破裂般地发出光束。
* 末影龙的碰撞箱比它的自身生物模型要大，这使得玩家能更容易在远处射击命中它，但也使玩家会更容易被末影龙推动和撞击。
* 玩家不能直接在[旁观模式](旁观模式.md)进入末影龙视角。如果通过命令进入末影龙的视角，玩家的视角会在末影龙身体上方1格处。
* 组合键显示的碰撞箱表明末影龙头部的朝向数据与其真实的朝向相反。这解释了[刷怪笼](刷怪笼.md)末影龙模型中的头朝向错误的现象。
* * 显示碰撞箱后能发现末影龙的碰撞箱并不是一直都和身体各部位动画同步对齐，在末影龙于空中转向时会更为明显，这可能导致玩家击中了末影龙的模型，却因为没有击中碰撞箱而无法造成伤害。
* 如果在主世界用命令召唤出末影龙，末影龙会飞到坐标X=0, Z=0的水平位置并将围绕X=0, Z=0盘旋，就像在末地里的那样。在主世界放置末地水晶，水晶会正常治疗末影龙，但末影龙不会在水晶周围停留，而是会四处飞。
* 骑乘末影龙时会加长玩家的第三人称[](属性/镜头距离.md)。
* 末影龙是在《任天堂明星大乱斗特别版》Steve/Alex DLC中的一个命魂。末影龙作为传说级命魂，在每次战斗开始时会让玩家喷火喷很长时间。

# = 与Notch有关 =
* 在Reddit上，Notch用“她”来指代末影龙，并且称呼末影龙为“Jean?”，这种命名方法类似于称呼[玩家](玩家.md)名字（“Steve?”）<ref></ref>
* * Dinnerbone晚些时候表示他认为“Jean?”就是末影龙的官方名称。<ref></ref>
* * Xbox头像物品“Ender Dragon Pet”的描述如下：比它的Minecraft姐姐更可爱、更友好、更调皮。这证明了末影龙的性别是雌性。
* 在为末影龙添加纹理之前，Notch说他很害怕为末影龙添加纹理，因为末影龙的模型非常复杂。<ref></ref>最后，Notch觉得末影龙的模型实在太复杂，便放弃了手动制作纹理，而用他自己写的纹理打包工具将纹理添加到模型里面。Notch上传了打包工具的代码供他人使用。<ref> Twitter：纹理打包工具</ref><ref>[纹理打包工具的链接](http://pastebin.com/0AcY6YV2)</ref>
* * 当deadmau5提到这个时，Notch开玩笑说Minecraft“正在进化到新一代”。<ref></ref>
* 关于控制末影龙的难度，Notch在推特上说“（如果）我可以完全击败它，那就太容易了。”
* Notch上传了一个视频，解释了为什么末影龙不会在主世界中生成。因为末影龙会将其接触到的所有方块破坏掉。<ref>https://www.youtube.com/watch?v=XTpFDRZExAg</ref>
* * Notch还在Reddit论坛解释，由于当时的末影龙存在撞到墙面会转向的弱点，且没有时间再设计一个让它顺利穿过任意地形的AI，于是末影龙拥有了破坏方块的能力。<ref></ref>
